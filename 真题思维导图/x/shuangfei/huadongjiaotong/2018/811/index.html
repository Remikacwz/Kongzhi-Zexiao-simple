一简答题：系统组成、校正性质与频段划分15 分#

思路
  • 按简答分点作答：列反馈系统组成与性能要求，辨 PI 与 PD 校正性质，再划分三个频段
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出反馈系统基本组成与三项性能要求
本卷实例
  • 关键一步：按给定元件逐个对应反馈回路环节
  • 中间结果：稳定性、快速性、准确性为三项基本要求
  • 卡点：组成元件与性能要求的对应关系易混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指出反馈系统基本组成与三项性能要求
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把被控量与操纵量张冠李戴
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
PID 控制器与参数整定 系统校正
本卷考法
  • 判别 PI 与 PD 各属何种校正并说明特点
本卷实例
  • 关键一步：从积分与微分作用分别判断校正性质
  • 中间结果：PI 提高系统型别、PD 只改善动态
  • 卡点：两种校正对稳态误差的影响相反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过判别 PI 与 PD 各属何种校正并说明特点
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 本卷考过把 PI 的相位影响误说成超前
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

开环对数频率特性的绘制 频域分析
本卷考法
  • 说明对数幅频三个频段的划分依据与作用
本卷实例
  • 关键一步：以第一个与最后一个转折频率为界划分三段
  • 中间结果：中频段对应稳定裕度与动态性能
  • 卡点：各频段对性能的影响需分条作答
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过说明对数幅频三个频段的划分依据与作用
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 本卷考过把转折频率与截止频率混为一谈
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

二信号流图求传递函数20 分#

思路
  • 由结构图画信号流图，用梅森公式列全部回路与前向通路，写特征式后求传函
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图用梅森公式求闭环传函
本卷实例
  • 关键一步：从输入到输出找全前向通路并标出增益
  • 中间结果：特征式由各回路与不接触回路乘积组成
  • 卡点：各回路接触关系决定余子式，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图用梅森公式求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路找漏或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

三二阶系统参数与速度反馈25 分#

思路
  • 由开环传函写闭环特征式，对比标准二阶形式求参数，再按速度反馈后的阻尼比反求系数
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由开环传函求阻尼系数与无阻尼振荡角频率
本卷实例
  • 关键一步：写闭环特征方程并与标准二阶式对比系数
  • 中间结果：无阻尼振荡角频率由常数项开方得到
  • 卡点：开环增益与闭环特征式系数的换算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由开环传函求阻尼系数与无阻尼振荡角频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过化为标准形式时忘记归一化 s 平方项系数
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求给定阻尼比下的超调量与调整时间
本卷实例
  • 关键一步：代入欠阻尼二阶性能指标公式
  • 中间结果：超调量只由阻尼比决定
  • 卡点：调整时间取五个百分点误差带的系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求给定阻尼比下的超调量与调整时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过峰值时间与调整时间公式混用
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

  • 由期望阻尼比反求速度反馈系数

  • 把 ξ 的可行域方向取反

四根轨迹绘制与欠阻尼范围15 分#

思路
  • 按根轨迹法则求分离点、渐近线与虚轴交点，再由欠阻尼条件确定开环增益范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则作根轨迹草图并定实轴段
本卷实例
  • 关键一步：先标开环零极点再判实轴段
  • 中间结果：有一对根轨迹趋于无穷远
  • 卡点：渐近线夹角公式中的取值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则作根轨迹草图并定实轴段
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴段判据中的零极点个数算错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

分离点与会合点 根轨迹法

  • 确定分离点处的临界增益
  • 判断解的取舍

  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

五非线性系统描述函数法判自振15 分#

思路
  • 画线性部分奈氏图与负倒描述函数曲线，由有无交点判断自振，再由交点条件解频率与振幅
描述函数法基础 非线性系统
本卷考法
  • 由给定描述函数求负倒描述函数表达式
本卷实例
  • 关键一步：先化简负倒描述函数并写其幅相形式
  • 中间结果：负倒曲线是过原点的一条射线
  • 卡点：描述函数含相角时的复数运算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
