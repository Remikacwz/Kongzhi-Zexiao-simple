思路

  • 中间结果：闭环分母为 s² 加 τ 加一乘 s 加 K

  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角

减小稳态误差的措施 稳态误差
本卷考法
  • 设计前馈环节使给定或扰动下稳态误差为零
本卷实例
  • 关键一步：令误差传函的分子恒为零反解补偿环节
  • 中间结果：G1 与 G2 分别消除输入误差和扰动误差
  • 卡点：两个通道各自独立，不能用一个环节兼顾
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计前馈环节使给定或扰动下稳态误差为零

  • 说明为何单纯提高增益不可行

  • 把题给负倒描述函数写成只含振幅的显式，再与线性部分的幅相曲线画在同一复平面，由是否有交点判断自振并匹配频率与振幅
用描述函数法分析自振 非线性系统
本卷考法
  • 用描述函数法判断系统是否产生自持振荡
本卷实例
  • 关键一步：在同一复平面画线性部分与负倒描述函数并找交点
  • 中间结果：负倒描述函数随振幅增大从负实轴单调变化
  • 卡点：需回原卷核对图 7 非线性环节与线性部分的连接
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过用描述函数法判断系统是否产生自持振荡
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 本卷考过画的是描述函数而不是负倒描述函数
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过由给定负倒描述函数判断自振条件并求交点
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错

  • 把描述函数当成频率的函数
