一结构图求双输入传递函数15 分#

思路
  • 由结构图分别对参考输入与误差输出列写通路，用逐层化简或梅森公式求两个传函
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简求传函
本卷实例
  • 关键一步：先合并串联环节再消去内环
  • 中间结果：化简后得一个前向通路与两个回路
  • 卡点：回路与通路的交叉关系需看图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简求传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过化简时把前向通道与反馈通道搞混
  • 化简内环时把外环的信号当成常数处理
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求误差对参考输入的传递函数
本卷实例
  • 关键一步：以误差为输出重新列信号通路
  • 中间结果：误差传函分母与输出传函相同
  • 卡点：比较点前移后引出点位置变化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求误差对参考输入的传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 本卷考过求误差传函时没有把输出反馈考虑进去
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

二根轨迹与稳态误差参数范围20 分#

思路
  • 按根轨迹法则绘轨迹并求稳定增益范围，再由极点实部约束与组合输入误差要求定各系数
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则作根轨迹草图
本卷实例
  • 关键一步：标开环零极点并判实轴段
  • 中间结果：有一条渐近线与实轴重合
  • 卡点：分离点与虚轴交点位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则作根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴段判据中的零极点个数算错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及系统稳定范围
本卷实例
  • 关键一步：令纯虚根代入特征方程
  • 中间结果：由实部虚部为零解出频率与增益
  • 卡点：稳定范围由穿越点划分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及系统稳定范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 本卷考过只代一组解就下结论
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由闭环极点实部位置确定增益
本卷实例
  • 关键一步：按极点实部要求写期望特征式
  • 中间结果：对比系数直接解出增益
  • 卡点：极点实部绝对值条件的处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由闭环极点实部位置确定增益
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 本卷考过把等实部线画成垂直线
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

系统型别与静态误差系数 稳态误差
本卷考法
  • 判断系统型别并写静态误差系数
本卷实例
  • 关键一步：由开环传函积分环节个数定型别
  • 中间结果：型别决定各误差系数是否有限
  • 卡点：开环增益与根轨迹增益的换算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断系统型别并写静态误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 本卷考过数错积分环节个数导致型别判错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由组合输入稳态误差要求确定系数取值范围
本卷实例
  • 关键一步：把组合输入拆成阶跃、斜坡、抛物线分量
  • 中间结果：各分量误差分别由对应误差系数决定
  • 卡点：误差有界要求排除某分量非零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由组合输入稳态误差要求确定系数取值范围
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过输入为组合信号时漏掉某一分量
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量

三劳斯判据与极点实部约束20 分#

思路
  • 由开环传函写闭环特征方程，列劳斯表求稳定增益范围，再用平移代换把极点实部约束转为稳定判据
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据确定系统稳定增益范围
本卷实例
  • 关键一步：写出闭环特征多项式并补全缺项
  • 中间结果：由首列同号解出增益上界
  • 卡点：劳斯表首列出现零需特殊处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据确定系统稳定增益范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过系数缺项时不补零直接列劳斯表
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

参数稳定域的确定 稳定性分析

通用考法

  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 本卷考过直接在原特征方程上套用稳定判据
  • 只列出部分首列元素的不等式，漏掉某个约束

四对数渐近线反求传函与性能指标20 分#

思路
  • 由渐近线斜率变化写开环传函，由幅频特性定转折频率关系，再求闭环阻尼比与动态指标
开环对数频率特性的绘制 频域分析
本卷考法
  • 由低频段斜率与高度判断型别与增益
本卷实例
  • 关键一步：从最低频段斜率读积分环节个数
  • 中间结果：各转折频率处斜率变化对应一阶环节
  • 卡点：转折频率需由图读出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过由低频段斜率与高度判断型别与增益
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 本卷考过斜率逐段累加时误作替换
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数渐近线写出最小相位系统传函
本卷实例
  • 关键一步：按转折频率从小到大写各环节
  • 中间结果：传函由积分环节与若干惯性环节组成
  • 卡点：低频段高度与增益的换算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数渐近线写出最小相位系统传函
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 本卷考过把延长线交点误当增益未折算型别
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由闭环阻尼比求超调量与调节时间
本卷实例
  • 关键一步：由开环传函写闭环特征式求阻尼比
  • 中间结果：超调量只与阻尼比有关
  • 卡点：调节时间的误差带取值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由闭环阻尼比求超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过超调量公式中漏乘百分比
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

五频域裕度与参数调整20 分#
