华东交通大学 811 自动控制理论 2025 年真题思维导图

强势双非共 3 题

难度：中等　仅 3 道大题：离散采样系统求输出 z 变换与终值、由含右半平面零点的开环求幅值穿越频率并画对数幅频渐近线、含右半平面极点开环的广义奈氏图与判稳。三题都落在离散域与频域，题面短而计算集中，其中两题的传递函数分别含右半平面零点与右半平面极点。

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

1采样系统输出的 z 变换与终值#

思路
  • 先按零阶保持器与连续部分求开环 z 传函，再按反馈公式写闭环脉冲传函，乘单位阶跃的 z 变换得到输出 z 变换，最后用终值定理求输出终值
脉冲传递函数 离散控制系统
本卷考法
  • 由连续部分传函与采样周期求开环与闭环脉冲传递函数
本卷实例
  • 关键一步：把连续部分拆成部分分式后逐项求 z 变换
  • 中间结果：闭环脉冲传函由开环 z 传函按反馈公式组合
  • 卡点：采样周期为一秒，指数项要按该采样周期折算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过由连续部分传函与采样周期求开环与闭环脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 本卷考过把两个没有采样开关隔开的连续环节直接相乘
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)

z 变换与 z 反变换 离散控制系统
本卷考法
  • 求典型环节的 z 变换为写出输出序列做准备
本卷实例
  • 关键一步：对连续传函的部分分式逐项查 z 变换表
  • 中间结果：输出 z 变换等于闭环脉冲传函乘输入的 z 变换
  • 卡点：题给指数近似值用于化简 z 传函的系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • z 变换是离散信号的拉氏变换，令 z=e^{Ts} 得到
  • 常用函数的 z 变换要熟记
  • z 反变换可用部分分式法、幂级数法或留数法
  • 左半 s 平面映射到 z 平面单位圆内
步骤
  • 将连续传递函数展开为部分分式
  • 逐项查表做 z 变换
  • 需要时做 z 反变换求时间序列
通用考法
  • 本卷考过求典型环节的 z 变换为写出输出序列做准备
  • 求给定函数的 z 变换
  • 求 z 反变换得到采样序列
  • 说明 s 平面与 z 平面的映射关系
常见易错
  • 本卷考过把 z 变换结果中的指数项写成不含采样周期的形式
  • 把 z 变换结果中的 e^{-aT} 写成 e^{-a}
  • 部分分式分解时漏项导致反变换出错

离散系统的稳态误差 离散控制系统
本卷考法
  • 用终值定理求采样系统输出的终值
本卷实例
  • 关键一步：先看闭环极点是否全在单位圆内再套终值定理
  • 中间结果：终值取 z 趋于一时输出 z 变换与 z 减一之积的极限
  • 卡点：终值是否收敛取决于闭环极点的位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差由输入类型与开环脉冲传函中 z=1 处极点的个数决定
  • 型别由 G(z)H(z) 中 z=1 处极点的重数确定
  • 用终值定理求稳态误差，前提是系统稳定
  • 采样周期也影响稳态误差大小
步骤
  • 求误差脉冲传递函数
  • 数出 z=1 处极点重数确定型别
  • 查表或用终值定理求稳态误差
  • 分析采样周期变化对误差的影响
通用考法
  • 本卷考过用终值定理求采样系统输出的终值
  • 求离散系统在典型输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 分析采样周期对稳态精度的影响
常见易错
  • 本卷考过未判稳就用终值定理
  • 直接用 s 域静态误差系数公式处理离散系统
  • 未判稳就用终值定理

2幅值穿越频率与对数幅频渐近线#

思路
  • 把开环传函化成标准因式形式，先看开环零点是否落在右半平面判定是否最小相位，再由幅值条件求幅值穿越频率，最后按各转折频率逐段累加斜率画渐近线
频率特性的物理意义与求法 频域分析
本卷考法
  • 由开环传函写出幅频与相频表达式并求幅值穿越频率
本卷实例
  • 关键一步：把开环传函化成各典型环节的标准乘积形式
  • 中间结果：幅值穿越频率由幅频表达式取一的方程解出
  • 卡点：分子含右半平面零点使相角随频率的变化规律反常
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由开环传函写出幅频与相频表达式并求幅值穿越频率
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过求幅值时忘记先把分母复数取模再相除
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

开环对数频率特性的绘制 频域分析
本卷考法
  • 确定对数幅频渐近曲线的各段斜率并绘制曲线
本卷实例
  • 关键一步：按转折频率从小到大逐段累加斜率
  • 中间结果：低频段起始斜率由开环中积分环节的个数确定
  • 卡点：转折频率处斜率的变化量由对应环节的阶数决定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过确定对数幅频渐近曲线的各段斜率并绘制曲线
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 本卷考过逐段改斜率时忘记累加而非替换
  • 逐段改斜率时忘记累加而非替换

最小相位系统与非最小相位系统 频域分析
本卷考法
  • 判断系统是否最小相位并说明其对频率特性的影响
本卷实例
  • 关键一步：检查开环零点是否落在虚轴右侧
  • 中间结果：右半平面零点只改变相频而不改变幅频
  • 卡点：幅频与相频不再一一对应，判断稳定性时的口径要随之调整
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法

  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 本卷考过把右半平面极点与右半平面零点混为一谈
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈

3广义奈氏图与判稳#

思路
  • 先数开环右半平面极点个数，再按各环节相角在起止频率处的叠加画幅相曲线，最后用奈氏判据算右半平面闭环根的个数判断稳定性
奈奎斯特判据 稳定性分析
本卷考法
  • 绘开环广义幅相曲线并用奈氏判据判断稳定性
本卷实例
  • 关键一步：先定开环右半平面极点数，再画增补后的幅相曲线
  • 中间结果：由包围临界点的圈数算右半平面闭环根的个数
  • 卡点：开环含右半平面极点时判据关系式要随之改变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过绘开环广义幅相曲线并用奈氏判据判断稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过没有先数开环右半平面极点数
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
