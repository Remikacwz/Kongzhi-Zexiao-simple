一1信号流图求传递函数10 分#

思路
  • 用梅森增益公式列全部回路、前向通路与两两不接触回路，写特征式后求指定输入输出比
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图用梅森公式求两节点间传递函数
本卷实例
  • 关键一步：从输入节点到输出节点找全前向通路
  • 中间结果：特征式由四条回路增益与一对不接触回路乘积组成
  • 卡点：各回路相互接触关系决定余子式，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤

  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法

  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错

  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路

一3结构图求阻尼比与自然频率10 分#

思路
  • 由结构图写闭环传函，化为标准二阶形式后对比系数求阻尼比与自然振荡频率
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由结构图求阻尼比与无阻尼自然振荡频率
本卷实例
  • 关键一步：由结构图化简出闭环传递函数
  • 中间结果：闭环分母为 s² 加 4s 加 10
  • 卡点：对比标准形式时 s² 项系数须归一，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由结构图求阻尼比与无阻尼自然振荡频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过把开环增益误当成闭环传递函数的系数
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
