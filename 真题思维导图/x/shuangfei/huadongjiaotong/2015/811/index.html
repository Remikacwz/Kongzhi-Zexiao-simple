思路

本卷实例

二二阶系统参数与稳态误差20 分#

思路
  • 由结构图写开环与闭环传函，对比标准二阶形式求阻尼比与自然频率，再按指标反求参数
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函求阻尼比与无阻尼自然振荡频率
本卷实例
  • 关键一步：先由结构图求出含 K1 与 Kf 的闭环传函
  • 中间结果：闭环分母为 s² 加 (3+Kf)s 加 K1
  • 卡点：第(3)问要同时满足阻尼比与稳态误差两条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函求阻尼比与无阻尼自然振荡频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过化标准形式时未把 s² 项系数归一
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

本卷考法

步骤

  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
