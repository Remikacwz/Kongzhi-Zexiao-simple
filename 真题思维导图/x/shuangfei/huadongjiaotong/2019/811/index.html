二二阶系统动态指标与顺馈补偿18 分#

思路
  • 由给定阶跃响应定闭环传函，按标准二阶式求动态指标与稳态误差，再按扰动全补偿求顺馈装置
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由闭环传函求超调量、调节时间与稳态误差
本卷实例
  • 关键一步：由阶跃响应反求阻尼比与自然频率
  • 中间结果：闭环传函化为标准二阶形式
  • 卡点：响应表达式取自原卷图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由闭环传函求超调量、调节时间与稳态误差
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过调节时间取错误差带系数
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

思路
  • 由结构图写闭环特征方程，列劳斯表并令首列全正，解不等式组得参数范围
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断系统稳定性
本卷实例
  • 关键一步：由结构图写出闭环特征多项式
  • 中间结果：劳斯表首列符号决定右半平面根数
  • 卡点：参数含在系数中需逐步代入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断系统稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过首列出现零后仍按常规继续算
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
