南京邮电大学 812 自动控制理论（含现控） 2022 年真题思维导图

强势双非共 9 题

难度：中等　全卷 9 道大题：第一题 6 个判断小问，其余八道为计算与分析题。覆盖由阶跃响应反求传函、根轨迹与幅相条件判点、给定与扰动共同作用下的稳态误差、劳斯判据与平移变换、Bode 图反求传函、串联超前校正和状态空间响应。未考离散、最优控制与电力拖动。

1一、判断题（6 小问）#

思路
  • 六小问逐条判断，先把题干还原成对应结论再判正误：积分环节与误差、附加零点与稳定、李雅普诺夫第二法的充分性、阻尼比与超调、采样与稳定、脉冲输入与传递函数定义。
减小稳态误差的措施 稳态误差
本卷考法
  • 判断系统稳定时增加积分环节能否减小误差
本卷实例
  • 关键一步：从积分环节提高系统型别入手分析
  • 中间结果：提高型别可减小稳态误差但可能破坏稳定性
  • 卡点：结论只在原系统稳定这一前提下成立
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过判断系统稳定时增加积分环节能否减小误差
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 判断增加开环零点能否提高系统稳定性
本卷实例
  • 关键一步：先看附加零点落在左半平面还是右半平面
  • 中间结果：只有左半平面零点可能改善稳定性
  • 卡点：右半平面零点反而使系统不稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过判断增加开环零点能否提高系统稳定性
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 判断找不到李雅普诺夫函数能否判系统不稳定
本卷实例
  • 关键一步：回忆李雅普诺夫第二法只是充分条件
  • 中间结果：找不到函数不能作为系统不稳定的判据
  • 卡点：充分条件与必要条件的区别是本小问核心
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过判断找不到李雅普诺夫函数能否判系统不稳定
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 判断欠阻尼时增大阻尼比对超调量的影响
本卷实例
  • 关键一步：由超调量随阻尼比单调下降的关系判断
  • 中间结果：欠阻尼范围内阻尼比增大则超调量减小
  • 卡点：该结论只在欠阻尼范围内成立
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过判断欠阻尼时增大阻尼比对超调量的影响
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
离散系统稳定性分析 离散控制系统
本卷考法
  • 判断采样开关的引入是否降低系统稳定性
本卷实例
  • 关键一步：把采样周期看作影响离散系统极点的参数
  • 中间结果：采样周期取值不同可能使系统从稳定变不稳定
  • 卡点：稳定性变化取决于采样周期，不能一概而论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过判断采样开关的引入是否降低系统稳定性
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒
公式
传递函数的定义与基本性质 传递函数
本卷考法
  • 判断脉冲输入下输出拉氏变换与传函相同的条件
本卷实例
  • 关键一步：回到传递函数的零初始条件定义
  • 中间结果：只有零状态且输入为单位脉冲时两者才相同
  • 卡点：题干省略了零初始条件与单位脉冲两个前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过判断脉冲输入下输出拉氏变换与传函相同的条件
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式

2二、由单位阶跃响应反求传函、脉冲响应与模态#

思路
  • 零初始条件下把单位阶跃响应乘 s 得闭环传函；对传函作部分分式后逐项拉氏反变换得单位脉冲响应，再由极点位置读出响应的模态。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应反求闭环传递函数
本卷实例
  • 关键一步：零初始下把阶跃响应乘 s 得闭环传函
  • 中间结果：闭环传函分母为两个实极点对应的一次因式
  • 卡点：阶跃响应与传函之间差一个 s 分之一的因子
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应反求闭环传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
零极点分布与响应模态 传递函数
本卷考法
  • 由极点分布写出单位脉冲响应与响应模态
本卷实例
  • 关键一步：对闭环传函作部分分式后逐项反变换
  • 中间结果：两个实极点对应两个衰减指数模态
  • 卡点：模态指极点对应的指数项，不是各项系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由极点分布写出单位脉冲响应与响应模态
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

3三、二阶系统根轨迹与指定点判定#

思路
  • 两个开环极点系统的根轨迹由实轴段、分离点与渐近线确定；对指定点先用相角条件判断是否在根轨迹上，满足后再用幅值条件求对应增益。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制两个开环极点的闭环根轨迹
本卷实例
  • 关键一步：标出实轴段并求分离点与渐近线
  • 中间结果：两个极点的根轨迹实轴段位于两极点之间
  • 卡点：分离点由对根轨迹增益求导的方程解出
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制两个开环极点的闭环根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 用相角条件判断指定点是否在根轨迹上
本卷实例
  • 关键一步：把指定点代入相角条件看是否为负一百八十度
  • 中间结果：相角条件成立说明该点位于根轨迹上
  • 卡点：相角条件与幅值条件用途不要混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过用相角条件判断指定点是否在根轨迹上
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
分离点与会合点 根轨迹法
本卷考法
  • 用幅值条件求指定点对应的增益
本卷实例
  • 关键一步：由幅值条件令各距离乘积的倒数为增益
  • 中间结果：增益等于该点到各开环极点距离之积
  • 卡点：算距离前先确认点确实落在根轨迹上
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过用幅值条件求指定点对应的增益
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式

4四、给定与扰动共同作用下的稳态误差（含图）#

思路
  • 由结构图分别写出给定到误差与扰动到误差的传递函数；阶跃给定分量用终值定理，正弦扰动分量用频率特性的物理意义求同频正弦误差，最后叠加。
误差定义与误差传递函数 稳态误差
本卷考法
  • 由结构图写给定与扰动到误差的传递函数
本卷实例
  • 关键一步：分别在另一输入置零的条件下求误差传函
  • 中间结果：给定与扰动两条通道的误差传函分母相同
  • 卡点：结构图未读，需回原卷核对图确认两条通道
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意

6六、由 Bode 图反求传函与相角裕度（含图）#

思路
  • 由低频段斜率与高度确定积分环节个数与开环增益，再由两处斜率变化点确定转折频率并组合成传递函数；最后按幅频条件求截止频率再算相角裕度。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由 Bode 图低频段与转折频率反求传递函数
本卷实例

  • 卡点：Bode 图未读，需回原卷核对图确认转折频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 每个转折频率对应一个一阶或二阶环节

校正的基本概念与性能指标 系统校正

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 时域指标与频域指标存在对应关系

  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错

  • 只盯相角裕度而忽略带宽要求
