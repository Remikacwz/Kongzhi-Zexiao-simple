1一、判断题（10小问）#

思路
  • 逐条判断10个概念命题：极点实部与响应衰减、阻尼比与超调、测速反馈与稳态误差、二阶特征方程系数、根轨迹幅相条件、含积分环节幅相曲线起点、滞后网络频率特性、调速与随动系统要求、输出稳定与状态稳定、状态空间与传函的对应。
零极点分布与响应模态 传递函数
本卷考法
  • 判断高阶闭环极点负实部越大对应响应分量衰减是否越快
本卷实例
  • 关键一步：由极点负实部大小判断对应模态衰减快慢
  • 中间结果：极点离虚轴越远对应模态衰减越快
  • 卡点：还要看零点是否使该模态权重为零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过判断高阶闭环极点负实部越大对应响应分量衰减是否越快
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 判断二阶系统阻尼比越大时超调量是否越小
本卷实例
  • 关键一步：由超调量随阻尼比变化的公式判断
  • 中间结果：典型二阶系统超调量随阻尼比增大而减小
  • 卡点：须先限定无零点的典型二阶系统
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过判断二阶系统阻尼比越大时超调量是否越小
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 判断施加测速反馈且不增大开环增益时稳态误差是否变大
本卷实例
  • 关键一步：比较加测速反馈前后开环增益的变化
  • 中间结果：测速反馈降低开环增益，稳态误差随之增大
  • 卡点：测速反馈改善阻尼却牺牲稳态精度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过判断施加测速反馈且不增大开环增益时稳态误差是否变大
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

劳斯判据 稳定性分析
本卷考法
  • 判断二阶系统闭环特征方程各项系数全正能否保证稳定
本卷实例
  • 关键一步：对二阶系统看特征方程系数是否同号
  • 中间结果：二阶系统系数全正即可判稳
  • 卡点：该结论只适用于二阶，高阶还要列劳斯表
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过判断二阶系统闭环特征方程各项系数全正能否保证稳定
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 判断幅值条件是否为确定根轨迹的充要条件
本卷实例
  • 关键一步：区分幅值条件与相角条件的作用
  • 中间结果：相角条件决定根轨迹，幅值条件只定增益
  • 卡点：满足幅值条件的点未必在根轨迹上
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过判断幅值条件是否为确定根轨迹的充要条件
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 判断开环含积分环节时幅相曲线是否起始于无穷远
本卷实例
  • 关键一步：看积分环节在频率趋于零正时的幅值
  • 中间结果：含积分环节时幅相曲线起点在无穷远
  • 卡点：起点对应频率趋于零正而非等于零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过判断开环含积分环节时幅相曲线是否起始于无穷远
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
滞后校正 系统校正
本卷考法
  • 判断滞后网络对低频有用信号和高频噪声是否都衰减
本卷实例
  • 关键一步：看滞后网络低频段与高频段的幅频渐近线
  • 中间结果：滞后网络低频不衰减而高频段幅值降低
  • 卡点：高频段衰减正是其抑制噪声的依据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过判断滞后网络对低频有用信号和高频噪声是否都衰减
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
直流调速系统的调速指标 电力拖动与运动控制
本卷考法
  • 比较调速系统与随动系统对稳态精度和快速性的要求侧重
本卷实例
  • 关键一步：按两类系统控制目标的差别区分性能侧重
  • 中间结果：调速重平稳与稳态精度，随动重快速性
  • 卡点：两类系统的性能侧重容易互换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 调速范围 D = 最高转速 / 最低转速（额定负载下）
  • 静差率 s = 转速降 / 理想空载转速，越低越好
  • D 与 s 互相制约：s 越小，能达到的 D 越小
  • 调速指标 D 和 s 一起提要求时，先求允许的稳态速降
步骤
  • 由题给 D 与 s 计算允许的稳态速降 Δn
  • 计算电枢回路总电阻 R_Σ = 电枢电阻 + 整流装置内阻
  • 求开环时的实际稳态速降，与允许值比较
  • 若开环不满足，说明必须采用闭环调速
通用考法
  • 本卷考过比较调速系统与随动系统对稳态精度和快速性的要求侧重
  • 计算满足调速范围与静差率要求所允许的稳态速降
  • 判断开环系统能否满足调速要求
  • 分析 D 与 s 之间的矛盾
常见易错
  • 静差率的分母用了实际转速而不是理想空载转速 n₀
  • 电枢回路总电阻漏掉整流装置内阻
  • 把额定转速 n_N 直接当成理想空载转速 n₀

状态空间与传递函数的关系 状态空间分析
本卷考法
  • 判断输出稳定是否等于状态稳定、状态空间能否唯一确定传函
本卷实例
  • 关键一步：由状态空间表达式求传递函数矩阵
  • 中间结果：状态稳定必输出稳定，反之未必
  • 卡点：发生零极点对消时内部状态可能不稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过判断输出稳定是否等于状态稳定、状态空间能否唯一确定传函
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

2二、由微分方程求传函、模态与全响应（3小问）#

思路
  • 对给定二阶微分方程作拉氏变换得传递函数；由特征根写出运动模态；再代入非零初值求单位阶跃下的全响应。
传递函数的定义与基本性质 传递函数
本卷考法
  • 由二阶微分方程直接写出闭环传递函数
本卷实例
  • 关键一步：对微分方程两边取拉氏变换并整理比值
  • 中间结果：分子为输入系数、分母为特征多项式
  • 卡点：注意零初始条件前提，别把初值带进传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由二阶微分方程直接写出闭环传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 带非零初值求单位阶跃下的系统全响应
本卷实例
  • 关键一步：用含初值的拉氏变换式代回求输出像函数
  • 中间结果：响应分解为稳态项与初值决定的暂态项
  • 卡点：含初值时不能直接用零状态传函相乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
