1一、用梅森公式求闭环传函（含图）#

思路
  • 先找出结构图的全部独立回路并写出回路增益，确认有无互不接触回路；再列各前向通路及其余子式，按梅森增益公式写出闭环传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求结构图的闭环传递函数
本卷实例
  • 关键一步：先列全部回路增益并检查有无互不接触回路
  • 中间结果：特征式等于一减各回路增益之和
  • 卡点：结构图未读，回路与前向通路编号需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求结构图的闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 识别多回路系统的回路与前向通路结构
本卷实例
  • 关键一步：按信号流向逐个确定独立回路
  • 中间结果：无互不接触回路时各前向通路的余子式取一
  • 卡点：易把回路增益与前向通路增益混记
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过识别多回路系统的回路与前向通路结构
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2二、无人机二阶系统指标反求参数与时间指标#

思路
  • 由闭环传函写出标准二阶形式，把超调量与峰值时间分别对应到阻尼比与自然频率，联立求出两个参数；再由阻尼比与自然频率计算上升时间和调节时间。
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间求阻尼比与自然频率
本卷实例
  • 关键一步：由超调量公式反解阻尼比，再由峰值时间求自然频率
  • 中间结果：阻尼比只由超调量决定，自然频率由峰值时间确定
  • 卡点：超调量公式中百分比与小数要统一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与峰值时间求阻尼比与自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由标准二阶系数与性能指标反求两个参数
本卷实例
  • 关键一步：令一次项系数等于两倍阻尼比乘自然频率
  • 中间结果：常数项等于自然频率的平方，两方程解两个参数
  • 卡点：一次项系数由开环参数组合而成，不要看漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由标准二阶系数与性能指标反求两个参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式

本卷实例

3三、劳斯判据求参数范围与极点区间#

思路
  • 先列劳斯表求系统稳定的两个参数范围；再把 s 平移使指定区间变成左半平面，对新特征方程用劳斯判据求满足极点区间的参数范围。
劳斯判据 稳定性分析
本卷考法
  • 列劳斯表求系统稳定的两个参数范围
本卷实例
  • 关键一步：写出闭环特征方程并按降幂排列列劳斯表
  • 中间结果：由首列元素同号得到两参数的不等式
  • 卡点：两个参数同时出现时要消元后判范围
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过列劳斯表求系统稳定的两个参数范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 用平移变换求极点落在指定区间的参数范围
本卷实例
  • 关键一步：令 s 等于 s1 减 1 代入特征方程并整理
  • 中间结果：对新多项式列劳斯表得参数不等式并取交集
  • 卡点：区间是负 1 到 0，平移后判的是 s1 左半平面
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过用平移变换求极点落在指定区间的参数范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

4四、五阶系统根轨迹绘制#

思路
  • 标出五个开环极点与一个开环零点后判实轴段，求四条渐近线与复数极点出射角；再由分离点方程筛选有效分离点，并用劳斯表求根轨迹与虚轴的交点。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制含一个零点的五阶根轨迹
本卷实例
  • 关键一步：标零极点后判实轴段并求四条渐近线
  • 中间结果：实轴根轨迹段由该段右侧零极点总数为奇数判断
  • 卡点：五阶系统有一条分支终止于有限零点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制含一个零点的五阶根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹分离点并按实轴段筛选有效解
本卷实例
  • 关键一步：由分子乘分母导数等于分母乘分子导数列方程
  • 中间结果：分离点方程的解需按实轴根轨迹段筛选
  • 卡点：本题要求分离点取整数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹分离点并按实轴段筛选有效解
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
出射角与入射角 根轨迹法
本卷考法
  • 求共轭复数开环极点的出射角
本卷实例
  • 关键一步：按相角条件累加其余零极点的相角
  • 中间结果：两支共轭极点的出射角大小相等符号相反
  • 卡点：出射角累加时不要算该极点自身
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求共轭复数开环极点的出射角
  • 求复数极点的出射角
  • 根据出射角画出根轨迹起始方向
  • 由入射角确定根轨迹终止方向
常见易错
  • 累加相角时把该极点自身的相角也算进去
  • 忘记判断象限导致角度差 180°

本卷考法
  • 求根轨迹与虚轴交点及临界增益
本卷实例

  • 中间结果：临界增益下由辅助方程解出虚轴交点频率
  • 卡点：辅助方程系数要用临界增益代入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 把 s=jω 代入闭环特征方程

通用考法
  • 本卷考过求根轨迹与虚轴交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

5五、非最小相位系统幅相曲线与奈氏判稳#

思路
  • 写出开环频率特性后由起点、终点与负实轴交点画概略幅相曲线；量出交点处幅值后用奈奎斯特判据列不等式求使系统稳定的增益范围。
频率特性的物理意义与求法 频域分析
本卷考法
  • 由开环传函写频率特性并画概略幅相曲线
本卷实例
  • 关键一步：令 s 等于 jω 代入并分离实部与虚部
  • 中间结果：由虚部为零求与负实轴交点频率与幅值
  • 卡点：起点与终点的相角要按非最小相位环节确定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由开环传函写频率特性并画概略幅相曲线
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

8八、非线性系统李雅普诺夫第二法判稳#

思路
  • 先求系统的唯一平衡点；取正定二次型作李雅普诺夫函数，沿状态方程求其导数并判断定号性，由半负定给出李雅普诺夫意义下稳定的结论。
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 用李雅普诺夫第二法判断非线性系统稳定性
本卷实例
  • 关键一步：取正定函数后沿状态方程求其导数
  • 中间结果：导数化为负的第二个状态的四次方，属半负定
  • 卡点：导数半负定对应稳定而不是渐近稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数

  • 据此得出稳定性结论

  • 用李雅普诺夫方程判断系统稳定性

  • 分析非线性系统的稳定性范围

  • 只判断 V 正定就下结论而未检查导数
