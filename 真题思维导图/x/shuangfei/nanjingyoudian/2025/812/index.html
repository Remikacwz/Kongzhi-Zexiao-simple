南京邮电大学 812 自动控制理论（含现控） 2025 年真题思维导图

强势双非共 9 题

难度：中等　全卷共 9 题、满分 150 分。第一题为 5 小问判断题，覆盖闭环极点与零点对模态的影响、状态反馈任意配置极点的前提、状态反馈与能控性、PD 的作用；第二至九题为计算与综合分析：由前向通路与反馈环节求闭环传函并比较动态响应、正弦输入下的稳态误差、李雅普诺夫第一与第二方法判稳、含图三阶系统的阻尼与稳定域及极点配置、含开环零点的根轨迹、测速反馈下阻尼比与参数范围、由阶跃响应反求传函及组合输入稳态误差、状态转移矩阵与零初值输出响应。未考离散控制系统、非线性系统与频域串联校正。

1一、判断题（5 小问）#

思路
  • 五小问逐条判断：极点是否决定模态类别、状态反馈任意配置极点的前提条件、状态反馈与能控性的关系、PD 的实质作用、闭环零点对阻尼与超调的影响。判断时先把题干翻译成对应的教材结论，再判正误。
零极点分布与响应模态 传递函数
本卷考法
  • 判断闭环极点是否决定响应模态的类别
本卷实例
  • 关键一步：从极点位置决定响应包含哪些模态这一点切入判断
  • 中间结果：极点决定模态类别，零点只改各模态的权重
  • 卡点：题干把模态类别与模态权重混在一起表述，要区分开
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过判断闭环极点是否决定响应模态的类别
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

PID 控制器与参数整定 系统校正
本卷考法
  • 判断 PD 对阻尼、超调与稳态误差的作用
本卷实例
  • 关键一步：把 PD 写成比例项加微分项，看其零点带来的影响
  • 中间结果：微分项引入零点，比例项主要影响稳态误差
  • 卡点：PD 不等同于单纯增大阻尼，零点可能使超调增大
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过判断 PD 对阻尼、超调与稳态误差的作用
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

2二、前向通路与反馈环节求闭环传函并比较响应#

思路
  • 先由负反馈等效公式写出含 K、τ 的闭环传函，再分别代入两组参数化成标准二阶形式，由 ξ 与 ξωn 比较阶跃响应的超调与快慢。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由前向通路和反馈环节求闭环传函
本卷实例
  • 关键一步：把前向通道与反馈通道代入负反馈等效公式
  • 中间结果：闭环分母整理成二次项加一次项加常数项的标准结构
  • 卡点：反馈通道含 τs，等效时不要漏掉它与前向增益的乘积项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由前向通路和反馈环节求闭环传函
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函求阻尼比和无阻尼自然频率
本卷实例
  • 关键一步：把闭环传函的二次项系数归一后与标准二阶形式比对
  • 中间结果：一次项系数对应两倍 ξωn，常数项对应 ωn 的平方
  • 卡点：K=10 的两组 τ 使 ωn 相同而 ξ 不同，需分别求 ξ
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函求阻尼比和无阻尼自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 比较两组参数下超调量与调节时间的变化
本卷实例
  • 关键一步：分别由 ξ 判断超调、由 ξωn 判断调节时间
  • 中间结果：ξ 越大超调越小，ξωn 越大调节越快
  • 卡点：题干说画出响应轨迹，只需给出响应形状与关键指标即可
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过比较两组参数下超调量与调节时间的变化
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3三、正弦输入下的稳态误差与增益范围#

思路
  • 单位负反馈下写出误差传函，令 s 等于 jω 得误差的幅频与相频；正弦输入下的稳态误差仍是同频正弦量，其幅值由误差幅频乘输入幅值决定，据此列增益不等式并叠加稳定条件。
误差定义与误差传递函数 稳态误差
本卷考法
  • 由误差传函求正弦输入下的稳态误差
本卷实例
  • 关键一步：写出误差传函并把正弦输入代入求稳态分量
  • 中间结果：正弦稳态误差仍为同频正弦，幅值由误差幅频决定
  • 卡点：不能用终值定理求正弦输入的稳态误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由误差传函求正弦输入下的稳态误差
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由误差幅频特性列幅值上限的增益不等式
本卷实例
  • 关键一步：令 s 等于 jω 求出误差传函的幅频表达式
  • 中间结果：把误差幅值不超过给定输入倍数写成关于 K 的不等式
  • 卡点：解出的 K 范围要与闭环稳定条件取交集
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由误差幅频特性列幅值上限的增益不等式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

4四、李雅普诺夫第一、第二方法判稳#

思路
  • 两种方法对照使用：第一法由系数矩阵特征值的实部判断稳定性；第二法构造李雅普诺夫函数或解代数李雅普诺夫方程，由矩阵正定性或函数导数定号得结论。
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 分别用李雅普诺夫第一、第二方法判断稳定性
本卷实例
  • 关键一步：第一法先求特征方程根，第二法再构造能量函数或解矩阵方程
  • 中间结果：第一法看特征值实部符号，第二法看 P 阵或函数导数的定号
  • 卡点：用 AᵀP+PA=-I 解 P 时三个方程要选线性无关的组合
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过分别用李雅普诺夫第一、第二方法判断稳定性
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

思路
