南京邮电大学 812 自动控制理论（含现控） 2015 年真题思维导图

强势双非共 9 题

难度：中等　全卷九道大题：第一题六个填空小问，其余为计算与分析题。覆盖超前与滞后校正原理、二阶系统指标逆运算、根轨迹绘制与临界参数、正弦稳态输出、串联超前校正设计、状态空间综合计算、状态反馈极点配置、离散系统临界增益与稳态误差、李雅普诺夫第二法。未考最优控制与电力拖动。

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

1一、填空题（6小问）#

思路
  • 六个填空小问逐空作答：消除稳态误差的手段、超前与滞后校正的原理、低高频段对应的性能、状态方程的可控可观判别、自动控制系统的分类、影响稳态误差的因素。
减小稳态误差的措施 稳态误差
本卷考法
  • 填出消除稳态误差的前馈或积分环节手段
本卷实例
  • 关键一步：从系统型别与误差传递函数找可改造的环节
  • 中间结果：前馈补偿或串联积分可按型别削弱稳态误差
  • 卡点：提高型别的同时要检查闭环是否仍然稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过填出消除稳态误差的前馈或积分环节手段
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式
超前校正 系统校正
本卷考法
  • 填出超前校正利用相角超前原理
本卷实例
  • 关键一步：把超前网络看作在中频段提供正相角的环节
  • 中间结果：超前校正靠抬高相角裕度改善动态性能
  • 卡点：超前校正会把截止频率后移，需复核裕度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过填出超前校正利用相角超前原理
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
滞后校正 系统校正
本卷考法
  • 填出滞后校正利用高频幅值衰减原理
本卷实例
  • 关键一步：看滞后网络在中高频段降低幅值的作用
  • 中间结果：滞后校正以牺牲带宽换取相角裕度
  • 卡点：转折频率取高会抵消增益改善效果
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过填出滞后校正利用高频幅值衰减原理
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 填出低频段与高频段各自影响的性能
本卷实例
  • 关键一步：低频段对应型别与开环增益，高频段对应抗扰能力
  • 中间结果：低频段决定稳态精度，高频段决定抗干扰
  • 卡点：动态性能主要由中频段决定而非高频段
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过填出低频段与高频段各自影响的性能
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
能控性与能观性 状态空间分析
本卷考法
  • 填出由状态方程判断可控与可观的判据
本卷实例
  • 关键一步：分别构造能控性与能观性判别矩阵
  • 中间结果：判别矩阵满秩则对应性质成立
  • 卡点：能观性矩阵要竖着堆叠 C、CA 等行块
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过填出由状态方程判断可控与可观的判据
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 填出自动控制系统按给定信号的分类
本卷实例
  • 关键一步：按给定信号随时间的规律划分系统类型
  • 中间结果：除恒值系统外还有随动系统与程序控制系统
  • 卡点：分类依据是给定信号的规律而非扰动形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过填出自动控制系统按给定信号的分类
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
系统型别与静态误差系数 稳态误差
本卷考法
  • 填出影响稳态误差的主要因素
本卷实例
  • 关键一步：从误差传递函数看输入与开环参数的作用
  • 中间结果：输入信号、开环增益与系统型别共同决定误差
  • 卡点：型别数与开环增益都要数对才不误判
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过填出影响稳态误差的主要因素
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式

2二、反馈系数为a的负反馈二阶系统（含图）#

思路
  • 由结构图写闭环传函并化成标准二阶形式，用阶跃响应的超调量与峰值时间反解阻尼比和自然频率，再由一次项系数定时间常数，最后由速度误差系数反求反馈系数a。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由阶跃响应曲线反求闭环传函与三个参数
本卷实例
  • 关键一步：先由响应终值读出闭环增益
  • 中间结果：闭环传函可写成含 k、T、a 的标准形式
  • 卡点：结构图与响应曲线都以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由阶跃响应曲线反求闭环传函与三个参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间求阻尼比与自然频率
本卷实例
  • 关键一步：由超调量公式反解阻尼比 ξ
  • 中间结果：把 ξ 代入峰值时间公式解出自然频率
  • 卡点：峰值时间分母含根号下一减 ξ 的平方
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与峰值时间求阻尼比与自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函一次项系数确定时间常数
本卷实例
  • 关键一步：把开环参数代入标准二阶分母后逐项比对
  • 中间结果：一次项系数对应两倍阻尼比乘自然频率
  • 卡点：开环增益不等于闭环增益，不能混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函一次项系数确定时间常数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由速度误差系数反求反馈系数
本卷实例
  • 关键一步：对 I 型开环写出速度误差系数表达式
  • 中间结果：速度误差系数与反馈系数 a 成倒数关系
  • 卡点：求误差系数前要先确认闭环稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由速度误差系数反求反馈系数
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、由开环传函绘制根轨迹并求临界参数#

思路
  • 写出闭环特征方程，按绘制法则确定实轴段、分离点与渐近线，再令 s=jω 或列劳斯表求根轨迹与虚轴交点，得到临界增益与对应闭环极点。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制三极点系统的根轨迹
本卷实例
  • 关键一步：标出开环零极点后判实轴根轨迹段
  • 中间结果：三条渐近线夹角为六十度、一百八十度与三百度
  • 卡点：实轴段按该段右侧零极点总数为奇数判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°

9九、李雅普诺夫第二法判原点渐近稳定#

思路
  • 把平衡点确定在原点，取正定二次型作李雅普诺夫函数，解李雅普诺夫方程得到对称阵 P，由 P 的正定性判断原点是否渐近稳定。
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 用李雅普诺夫方程判断系统稳定性
本卷实例
  • 关键一步：取正定 Q 后解转置 P 加 P 乘 A 等于负 Q
  • 中间结果：由 P 的各阶主子式符号判断其正定性
  • 卡点：要回代检查李雅普诺夫函数导数的定号性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过用李雅普诺夫方程判断系统稳定性
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数
