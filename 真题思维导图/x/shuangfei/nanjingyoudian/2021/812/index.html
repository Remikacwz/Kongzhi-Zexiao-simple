南京邮电大学 812 自动控制理论（含现控） 2021 年真题思维导图

强势双非共 10 题

难度：中等　全卷 10 道大题：第一题 10 个判断小问，其余九道为计算与分析题。覆盖根轨迹绘制与阻尼比定参、奈奎斯特判据、Bode 相角裕度、离散采样系统稳定性与稳态误差、状态反馈极点配置、李雅普诺夫稳定性和非线性线性化。未考离散数字控制器、最优控制与电力拖动。

1一、判断题（10 小问）#

思路
  • 十小问逐条判断，先把题干翻译成对应的教材结论再判正误：极点与模态、超调与调节时间、特征方程系数与稳定、附加零点与根轨迹、稳态误差与稳定、积分环节与扰动、低频段与性能、离散采样周期、状态转移矩阵可逆、状态反馈与能控性。
零极点分布与响应模态 传递函数
本卷考法
  • 判断闭环极点为左半平面两个实根时是否无超调
本卷实例
  • 关键一步：从极点决定响应模态、零点只改模态权重切入
  • 中间结果：两个实根本身不保证无超调，还要看零点与重根
  • 卡点：题干把模态类别与模态权重混在一起表述
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过判断闭环极点为左半平面两个实根时是否无超调
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 判断超调量不变时减小自然频率对过程快慢的影响
本卷实例
  • 关键一步：由超调量只与阻尼比有关，先固定阻尼比
  • 中间结果：阻尼比不变时调节时间与自然频率成反比
  • 卡点：不要把超调量与调节时间的自变量混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过判断超调量不变时减小自然频率对过程快慢的影响
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
劳斯判据 稳定性分析
本卷考法
  • 判断闭环特征方程某项系数为负与稳定性的关系
本卷实例
  • 关键一步：由劳斯判据或稳定必要条件逐项看系数符号
  • 中间结果：系数不全为正时系统不能稳定
  • 卡点：系数全为正只是必要条件，不能据此判稳
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过判断闭环特征方程某项系数为负与稳定性的关系
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

附加开环零极点的影响 根轨迹法
本卷考法
  • 判断增加开环负实数零点对根轨迹走向的影响
本卷实例
  • 关键一步：把附加零点看作根轨迹新的终止点
  • 中间结果：附加负实零点使根轨迹向左半平面弯曲
  • 卡点：零点在右半平面时结论相反，需先判零点位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过判断增加开环负实数零点对根轨迹走向的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
系统型别与静态误差系数 稳态误差
本卷考法
  • 判断稳态误差趋于无穷是否等价于系统不稳定
本卷实例
  • 关键一步：先分型别看典型输入下的稳态误差
  • 中间结果：0 型系统跟踪斜坡时误差为无穷但仍可稳定
  • 卡点：把稳态精度与稳定性两个概念混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断稳态误差趋于无穷是否等价于系统不稳定
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 判断前向通道串联积分环节对阶跃扰动的影响
本卷实例
  • 关键一步：写出扰动到输出的传递函数再看型别
  • 中间结果：积分环节提高扰动误差的型别，可抑制阶跃扰动
  • 卡点：提高型别可能破坏稳定，不能只说误差变小
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过判断前向通道串联积分环节对阶跃扰动的影响
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

开环对数频率特性的绘制 频域分析
本卷考法
  • 判断开环幅频特性低频段与系统性能的关系
本卷实例
  • 关键一步：把低频段斜率与高度对应到型别与开环增益
  • 中间结果：低频段主要反映稳态精度，稳定性还要看中高频段
  • 卡点：题干把稳态性能写成稳定性能，表述含混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过判断开环幅频特性低频段与系统性能的关系
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

离散系统的稳态误差 离散控制系统
本卷考法
  • 判断采样周期减小对离散系统跟随精度的影响
本卷实例
  • 关键一步：比较采样周期变化对离散误差系数的影响
  • 中间结果：采样周期减小时离散系统更接近连续系统
  • 卡点：结论建立在系统仍然稳定的前提下
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差由输入类型与开环脉冲传函中 z=1 处极点的个数决定
  • 型别由 G(z)H(z) 中 z=1 处极点的重数确定
  • 用终值定理求稳态误差，前提是系统稳定
  • 采样周期也影响稳态误差大小
步骤
  • 求误差脉冲传递函数
  • 数出 z=1 处极点重数确定型别
  • 查表或用终值定理求稳态误差
  • 分析采样周期变化对误差的影响
通用考法
  • 本卷考过判断采样周期减小对离散系统跟随精度的影响
  • 求离散系统在典型输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 分析采样周期对稳态精度的影响
常见易错
  • 直接用 s 域静态误差系数公式处理离散系统
  • 未判稳就用终值定理

状态转移矩阵 状态空间分析
本卷考法
  • 判断线性定常系统状态转移矩阵是否可逆
本卷实例
  • 关键一步：由状态转移矩阵的逆对应反向时间矩阵切入
  • 中间结果：状态转移矩阵行列式恒不为零，故可逆
  • 卡点：时变系统结论不同，题干限定了线性定常
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 求拉氏反变换得到 e^{At}

通用考法

  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错

状态反馈与极点配置 状态空间分析
本卷考法
  • 判断状态反馈能否改变系统的能控性
本卷实例
  • 关键一步：比较状态反馈前后能控性判别矩阵的秩
  • 中间结果：状态反馈不改变能控性，但可能改变能观性
  • 卡点：能控性与能观性的变化结论不能互推
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过判断状态反馈能否改变系统的能控性
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反

2二、由单位脉冲响应求传函与带初值响应#

思路
  • 先对单位脉冲响应取拉氏变换得闭环传函并写出微分方程；把非零初始条件代入拉氏变换的微分定理求全响应；再反求开环传函，按型别求单位斜坡输入下的稳态误差。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位脉冲响应求闭环传递函数与微分方程
本卷实例
  • 关键一步：对单位脉冲响应取拉氏变换得闭环传函
  • 中间结果：闭环传函分母的系数对应系统微分方程系数
  • 卡点：单位脉冲响应的拉氏变换才是闭环传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位脉冲响应求闭环传递函数与微分方程
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 含非零初值的单位阶跃全响应求解
本卷实例
  • 关键一步：对微分方程作拉氏变换时保留初值产生的项
  • 中间结果：全响应由零输入自由响应与零状态响应叠加
  • 卡点：把非零初值当零初始条件会漏掉自由响应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
