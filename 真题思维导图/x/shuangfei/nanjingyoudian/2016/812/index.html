南京邮电大学 812 自动控制理论（含现控） 2016 年真题思维导图

强势双非共 10 题

难度：中等　全卷十道大题：信号流图求传函、含内外反馈的二阶系统指标与误差、根轨迹与最小阻尼比、含右半平面极点的奈奎斯特判稳、超前校正设计、由频率特性表求裕度、离散系统稳定范围、由状态转移矩阵反求系统、状态空间求传函与极点配置、李雅普诺夫直接法求参数条件。未考最优控制与电力拖动。

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

1一、由结构图用信号流图求传函（含图）#

思路
  • 把结构框图改画成信号流图，找出全部独立回路与两两不接触回路写出特征式，再列出各前向通道及其余子式，用梅森增益公式合成传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式由信号流图求系统传函
本卷实例
  • 关键一步：先数清独立回路并找互不接触的回路对
  • 中间结果：特征式为一减各回路增益加不接触回路增益积
  • 卡点：前向通道与余子式需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式由信号流图求系统传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图的逐层等效化简
本卷实例
  • 关键一步：把结构图逐层化成信号流图再套梅森公式
  • 中间结果：回路与通路编号要与原图一一对应
  • 卡点：结构框图以图给出，回路接触关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图的逐层等效化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2二、负反馈二阶系统指标与误差（含图）#

思路
  • 由结构图化简得闭环传函并化为标准二阶形式，按给定 Kf、Ka 求阻尼比、自然频率和斜坡稳态误差；第二问反用指标与误差条件解出反馈系数与放大系数。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函求阻尼比与自然频率
本卷实例
  • 关键一步：把闭环传函分母归一成标准二阶形式
  • 中间结果：一次项系数等于两倍阻尼比乘自然频率
  • 卡点：内外反馈都存在的结构图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：按系统型别写出速度误差系数
  • 中间结果：稳态误差等于速度误差系数的倒数
  • 卡点：先判闭环稳定再套终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由指标与误差条件反求两个参数
本卷实例
  • 关键一步：联立阻尼比条件与误差条件两个方程
  • 中间结果：消元后先解出放大系数再求反馈系数
  • 卡点：放大系数与反馈系数不是同一个量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由指标与误差条件反求两个参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

3三、由开环传函绘制根轨迹并求最小阻尼比点#

思路
  • 写出闭环特征方程，按法则画根轨迹并判定复数部分是一段圆弧，再用韦达定理与几何关系求最小阻尼比对应的闭环极点和增益。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制含一个零点的根轨迹
本卷实例
  • 关键一步：标出两极点一零点后判实轴段与渐近线
  • 中间结果：分离点方程由各极点零点倒数关系给出
  • 卡点：零点不在两极点之间会改变渐近线方向
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制含一个零点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 求最小阻尼比对应的闭环极点与增益
本卷实例
  • 关键一步：过原点作根轨迹切线取最小阻尼比点
  • 中间结果：由韦达定理可导出复数部分是一段圆弧
  • 卡点：阻尼比最小处是切点而不是分离点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过求最小阻尼比对应的闭环极点与增益
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式

4四、含右半平面极点的奈奎斯特判稳#

思路
  • 写出开环频率特性的实部与虚部，求幅相曲线与负实轴的交点以及起点终点走向，注意开环右半平面极点个数，按奈奎斯特判据判稳并求临界增益。
频率特性的物理意义与求法 频域分析
本卷考法
  • 求开环幅相曲线的实虚部与关键交点
本卷实例
  • 关键一步：代入 s 等于 jω 分离出实部与虚部
  • 中间结果：令虚部为零可解出与负实轴的交点
  • 卡点：开环含右半平面极点使起点相角特殊
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求开环幅相曲线的实虚部与关键交点
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点个数 P
  • 中间结果：由曲线包围负一点的圈数算闭环右极点个数
  • 卡点：忽略 P 等于一会得出相反的稳定性结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

5五、按相角裕度与截止频率要求设计超前校正#

思路
  • 分情况求未校正系统的截止频率与相角裕度，按所需补偿角设计超前校正网络的参数，再复核校正后的截止频率与相角裕度是否达标。
稳定裕度 频域分析
本卷考法
  • 求未校正系统的截止频率与相角裕度
本卷实例
  • 关键一步：分情况假设截止频率与转折频率的大小关系
  • 中间结果：由幅频特性等于一解出截止频率
  • 卡点：假设与结果矛盾时要换另一种情况
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求未校正系统的截止频率与相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
超前校正 系统校正
本卷考法
  • 设计串联超前校正网络满足相角裕度
本卷实例
  • 关键一步：由所需相角补偿量求最大超前角
  • 中间结果：由最大超前角解出参数 a 与时间常数 T
  • 卡点：补偿角要留裕量抵消截止频率后移
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过设计串联超前校正网络满足相角裕度
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

6六、由频率特性表求裕度并定增益变化#

思路
  • 在给定频率特性表上找幅值等于一处的相角求相角裕度，找相角等于负一百八十度处的幅值求幅值裕度，再按幅值裕度要求反求开环增益应变化的倍数。
稳定裕度 频域分析
本卷考法
  • 由表格数据求相角裕度与幅值裕度
本卷实例
  • 关键一步：在表中定位幅穿与相穿两个频率
  • 中间结果：相角裕度等于一百八十度加幅穿处相角
  • 卡点：幅值裕度取幅值倒数的分贝值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
