1一、判断题（10小问）20 分#

思路
  • 十小问逐条判断：传递函数性质、一阶系统惯性、稳定性与输入无关、开环增益与稳定性、截止频率与快速性、附加零点作用、采样周期与增益、状态方程唯一性、非奇异变换与能控性、状态反馈与能观性。先把题干翻成教材结论再判正误。
传递函数的定义与基本性质 传递函数
本卷考法
  • 判断传递函数能否反映系统固有性质、不同物理系统能否同传函
本卷实例
  • 关键一步：从传函由系统结构参数决定、与物理实现无关切入
  • 中间结果：不同物理系统可抽象为同一传递函数
  • 卡点：把物理实现不同误当作传函也不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过判断传递函数能否反映系统固有性质、不同物理系统能否同传函
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 判断一阶系统惯性大小与响应快慢的关系
本卷实例
  • 关键一步：把惯性大小直接对应到时间常数
  • 中间结果：时间常数越大调节时间越长
  • 卡点：把惯性大误判为响应更快
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过判断一阶系统惯性大小与响应快慢的关系
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
劳斯判据 稳定性分析
本卷考法
  • 判断系统稳定性是否只由结构与参数决定
本卷实例
  • 关键一步：回到稳定性是系统自身固有属性
  • 中间结果：改变输入不改变特征方程与极点
  • 卡点：把输出幅值变化误当作稳定性变化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过判断系统稳定性是否只由结构与参数决定
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
稳定裕度 频域分析
本卷考法
  • 判断开环增益增大对稳定性与幅值裕度的影响
本卷实例
  • 关键一步：把增益变化折算为对数幅频曲线上移
  • 中间结果：曲线上移使幅值裕度减小
  • 卡点：把稳态精度提高与稳定变好混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过判断开环增益增大对稳定性与幅值裕度的影响
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
闭环频率特性与性能指标 频域分析
本卷考法
  • 判断开环截止频率与过渡过程时间的关系
本卷实例
  • 关键一步：由频域指标与时域指标的换算关系判断
  • 中间结果：截止频率越大过渡过程通常越短
  • 卡点：题干把快慢的方向写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过判断开环截止频率与过渡过程时间的关系
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 判断增加左半平面开环零点对裕度与快速性的影响
本卷实例
  • 关键一步：把附加零点看作根轨迹新的终止点
  • 中间结果：左半平面零点使根轨迹向左偏移
  • 卡点：右半平面零点结论相反，需先判零点位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过判断增加左半平面开环零点对裕度与快速性的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
离散系统稳定性分析 离散控制系统
本卷考法
  • 判断采样周期固定时开环增益对离散稳定性的影响
本卷实例
  • 关键一步：把增益变化归到离散特征方程的系数
  • 中间结果：增益过大使闭环极点移出单位圆
  • 卡点：离散判稳看极点模而非实部
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过判断采样周期固定时开环增益对离散稳定性的影响
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒
公式
状态空间表达式的建立 状态空间分析
本卷考法
  • 判断同一系统的状态方程是否唯一
本卷实例
  • 关键一步：由状态变量选取不唯一切入
  • 中间结果：换一组状态变量得到另一组等价方程
  • 卡点：把状态方程不唯一误当作系统特性不唯一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过判断同一系统的状态方程是否唯一
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式
能控性与能观性 状态空间分析
本卷考法
  • 判断非奇异线性变换是否保持能控性
本卷实例
  • 关键一步：对能控判别阵作满秩线性变换
  • 中间结果：满秩变换不改变矩阵的秩
  • 卡点：把能控性与能观性的结论互相套用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断非奇异线性变换是否保持能控性
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
状态反馈与极点配置 状态空间分析
本卷考法
  • 判断状态反馈配置极点时能否改变能观性
本卷实例
  • 关键一步：写出加入反馈后的能观判别阵
  • 中间结果：反馈阵使能观矩阵的秩可能变化
  • 卡点：把能控性不变误推为能观性也不变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过判断状态反馈配置极点时能否改变能观性
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反

2二、由动态结构图用梅森公式求传函（含图）10 分#

思路
  • 在给定动态结构图上找全部独立回路与互不接触回路写特征式，再列出各前向通道及其余子式，用梅森增益公式写出 C(s)/R(s)；误差传函按 E=R-C 的定义另取前向通道求。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式由结构图求闭环传递函数
本卷实例
  • 关键一步：先数全部独立回路与互不接触回路对
  • 中间结果：特征式为一减回路增益加不接触回路增益积
  • 卡点：结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式由结构图求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 由误差定义求误差传递函数
本卷实例
  • 关键一步：按输出与输入的差写出误差传函
  • 中间结果：误差传函与闭环传函共用同一特征式
  • 卡点：误差定义与输出定义混用会差一个环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由误差定义求误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
