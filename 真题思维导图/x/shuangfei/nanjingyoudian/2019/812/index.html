南京邮电大学 812 自动控制理论（含现控） 2019 年真题思维导图

强势双非共 10 题

难度：中等　全卷十道大题：第一题3个判断小问，其余九道为计算与分析题。覆盖信号流图与梅森公式、输入与扰动共同作用下的稳态误差、根轨迹绘制与分离点、奈奎斯特判据求稳定K范围、由微分方程求正弦稳态输出、串联校正网络设计、离散系统稳定性、状态反馈极点配置、李雅普诺夫第一法与第二法。未考最优控制、电力拖动与过程控制。

1一、判断题（3小问）#

思路
  • 三小问逐条判断：传函一定时输入变化是否改变稳定性、传函与状态方程的唯一性、三频段理论中各频段对应的性能。先把题干翻成教材结论再判正误。
劳斯判据 稳定性分析
本卷考法
  • 判断系统稳定性是否随外界输入变化
本卷实例
  • 关键一步：回到稳定性由系统自身结构与参数决定
  • 中间结果：输入只改变响应大小不改变特征根
  • 卡点：把输出幅值变化误当作稳定性变化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过判断系统稳定性是否随外界输入变化
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
状态空间表达式的建立 状态空间分析
本卷考法
  • 判断传递函数与状态空间方程的唯一性
本卷实例
  • 关键一步：由状态变量选取不唯一切入
  • 中间结果：传函唯一而状态方程可有多组等价形式
  • 卡点：把状态方程不唯一误当作系统不唯一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过判断传递函数与状态空间方程的唯一性
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 判断三频段理论中各频段对应的系统性能
本卷实例
  • 关键一步：把低中高频段分别对应稳态、动态与抗扰
  • 中间结果：低频段决定稳态精度、中频段决定动态性能
  • 卡点：题干把低频与中频的作用对调
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过判断三频段理论中各频段对应的系统性能
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式

2二、由结构图用梅森公式求传函与二阶参数（含图）#

思路
  • 把给定动态结构图改画成信号流图，数出独立回路与互不接触回路写特征式，再由前向通道用梅森公式求 C(s)/R(s)，最后对照标准二阶形式取出阻尼比与自然频率。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图作信号流图并用梅森公式求传函
本卷实例
  • 关键一步：先由结构图改画信号流图再数回路
  • 中间结果：特征式含两回路与不接触回路修正项
  • 卡点：结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图作信号流图并用梅森公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函求阻尼比与自然频率
本卷实例
  • 关键一步：把闭环传函分母与标准二阶形式对照
  • 中间结果：一次项系数与常数项分别对应两个参数
  • 卡点：常数项开方前要确认分子增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式

3三、输入与扰动下的稳态误差（3小问，含图）#

思路
  • 由结构图分别写出误差对输入的传函和误差对扰动的传函，输入分量用静态误差系数或终值定理，扰动分量用终值定理，最后按叠加求总稳态误差。
误差定义与误差传递函数 稳态误差
本卷考法
  • 按输出与输入之差求误差传递函数
本卷实例
  • 关键一步：由结构图写误差对输入的传函
  • 中间结果：误差传函分母即系统特征式
  • 卡点：误差定义要与题给一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过按输出与输入之差求误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求输入作用下系统的稳态误差
本卷实例
  • 关键一步：先判稳再用终值定理求误差终值
  • 中间结果：稳态误差由误差传函在零频附近的留数决定
  • 卡点：用静态误差系数法的前提是单位负反馈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求输入作用下系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动作用下系统的稳态误差
本卷实例
  • 关键一步：把参考输入置零后求扰动到误差的传函
  • 中间结果：扰动误差等于扰动传函乘阶跃输入的终值
  • 卡点：扰动通道不能套用静态误差系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求扰动作用下系统的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式

4四、根轨迹绘制与分离点K值#

思路
  • 写出闭环特征方程，标出两个开环极点与一个开环零点，按法则判实轴段、求渐近线与分离点，再由幅值条件求分离点处的根轨迹增益。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则粗略绘制两极点一零点的根轨迹
本卷实例
  • 关键一步：先标零极点再判实轴段与渐近线
  • 中间结果：实轴段按右侧零极点数奇偶判断
  • 卡点：渐近线夹角公式用二k加一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则粗略绘制两极点一零点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 列分离点方程求分离点坐标及对应增益
本卷实例
  • 关键一步：由闭环特征方程写增益的显式表达式
  • 中间结果：分离点处用幅值条件回代求根轨迹增益
  • 卡点：两个候选分离点都要给出对应增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过列分离点方程求分离点坐标及对应增益
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式

5五、奈奎斯特图与稳定K范围#

思路
  • 把开环传函代入 s 等于 jω 写幅频与相频，由起点终点和与负实轴的交点画概略幅相曲线，再按奈奎斯特判据列不等式求闭环稳定时的 K 范围。
频率特性的物理意义与求法 频域分析
本卷考法
  • 由开环传函写幅频相频并画概略幅相曲线
本卷实例
  • 关键一步：代入 s 等于 jω 后分离实部与虚部
  • 中间结果：令虚部为零求曲线与负实轴的交点
  • 卡点：开环含积分环节时曲线起点在无穷远
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由开环传函写幅频相频并画概略幅相曲线
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据求闭环稳定的K范围
本卷实例
  • 关键一步：先数开环右半平面极点数再定判据形式
  • 中间结果：曲线不包围负一点时闭环稳定
  • 卡点：包围圈数的正负号定义要对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据求闭环稳定的K范围
  • 由开环幅相曲线判断闭环稳定性
