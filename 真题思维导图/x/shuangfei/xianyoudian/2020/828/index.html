1一、结构图求闭环传函20 分#

思路
  • 由结构图列全部回路与前向通路，用梅森公式或逐步化简求闭环传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求多回路系统闭环传函
本卷实例
  • 关键一步：先列出系统全部独立回路
  • 中间结果：特征式由各回路增益组合而成
  • 卡点：回路是否互不接触要逐对判断
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求多回路系统闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由结构图逐层化简求总传函
本卷实例
  • 关键一步：从最内环开始向外等效
  • 中间结果：内环化简后成为单个方框
  • 卡点：化简时不要漏掉局部反馈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由结构图逐层化简求总传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 用串并联与反馈等效合并环节
本卷实例
  • 关键一步：先合并串联与并联支路
  • 中间结果：等效传函为各环节乘积或求和
  • 卡点：负反馈分母符号取加号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过用串并联与反馈等效合并环节
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、二阶系统参数与静态误差系数25 分#

思路
  • 由阻尼比与调节时间定二阶参数，列劳斯表判稳，再求静态误差系数与组合输入稳态误差。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由调节时间确定自然频率并写闭环传函
本卷实例
  • 关键一步：先由阻尼比与调节时间定自然频率
  • 中间结果：闭环传函代入参数化为标准形式
  • 卡点：调节时间公式的误差带要与题目一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由调节时间确定自然频率并写闭环传函
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由给定性能指标反求系统参数
本卷实例
  • 关键一步：把调节时间要求写成频率约束
  • 中间结果：阻尼比与自然频率由指标确定
  • 卡点：反解后要代回指标校验
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由给定性能指标反求系统参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
劳斯判据 稳定性分析
本卷考法
  • 列劳斯表判断二阶系统稳定性
本卷实例
  • 关键一步：写出闭环特征方程并排劳斯表
  • 中间结果：首列各项同号则系统稳定
  • 卡点：系数有缺项时要补零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过列劳斯表判断二阶系统稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 求静态位置、速度与加速度误差系数
本卷实例
  • 关键一步：先由开环传函判断系统型别
  • 中间结果：各系数由开环传函的极限定出
  • 卡点：型别数错会让各系数全错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过求静态位置、速度与加速度误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求组合输入下的稳态误差
本卷实例
  • 关键一步：把输入拆成阶跃与斜坡分量
  • 中间结果：误差由两分量按系数叠加
  • 卡点：先判稳再使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求组合输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

3三、参数根轨迹与动态性能25 分#

思路
  • 把含时间常数的特征式整理成等效开环形式，画参数根轨迹并分析参数对性能的影响。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以时间常数 T 为变量绘制参数根轨迹
本卷实例
  • 关键一步：把含 T 的项整理到开环形式
  • 中间结果：等效开环零点来自含 T 多项式
  • 卡点：参数根轨迹仍用 180 度相角条件
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以时间常数 T 为变量绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按根轨迹法则画渐近线与分离点
本卷实例
  • 关键一步：先求等效开环极点与零点分布
  • 中间结果：渐近线交点由极零点重心给出
  • 卡点：重极点处根轨迹条数按重数算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按根轨迹法则画渐近线与分离点
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 分析参数变化对动态性能的影响
本卷实例
  • 关键一步：按特征根实部与虚部分段讨论
  • 中间结果：实部变大则衰减加快、超调减小
  • 卡点：要区分单调收敛与衰减振荡两段
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过分析参数变化对动态性能的影响
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

4四、奈奎斯特判据判稳20 分#

思路
  • 由开环传函写频率特性，定奈氏曲线起终点，再用奈氏判据判断闭环稳定性。
频率特性的物理意义与求法 频域分析
本卷考法
  • 写频率特性并定奈氏曲线起终点
本卷实例
  • 关键一步：分别求幅频与相频表达式
  • 中间结果：由起终点相角判断绕行象限
  • 卡点：积分环节使低频幅值趋于无穷
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过写频率特性并定奈氏曲线起终点
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈氏判据判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数
  • 中间结果：按包围负一点情况算闭环右极点
  • 卡点：曲线与负实轴交点要预先求出
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈氏判据判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
