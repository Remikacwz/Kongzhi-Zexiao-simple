1一、结构图求输入与扰动传函20 分#

思路
  • 由结构图列回路与前向通路，分别求参考输入与扰动到输出的传函再叠加。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求两路输入到输出的传函
本卷实例
  • 关键一步：先找全回路并判断是否两两接触
  • 中间结果：两路传函共用同一特征式
  • 卡点：互不接触回路的乘积分量易漏
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求两路输入到输出的传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由结构图逐层化简求闭环传函
本卷实例
  • 关键一步：先化简内环再向外逐层合并
  • 中间结果：内环等效后整体结构变简单
  • 卡点：比较点或引出点移动要补乘因子
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由结构图逐层化简求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求扰动到输出的传递函数
本卷实例
  • 关键一步：求扰动传函时令参考输入为零
  • 中间结果：扰动通路含反馈环节的传递
  • 卡点：多输入叠加前先确认系统线性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求扰动到输出的传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

2二、二阶系统指标与参数反求25 分#

思路
  • 由结构图求闭环与误差传函，按给定指标反求阻尼比与参数，再算调节时间与稳态误差。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由结构图求闭环传函并化为二阶标准形式
本卷实例
  • 关键一步：先由结构图写出闭环特征多项式
  • 中间结果：特征式一次项含反馈系数乘积
  • 卡点：分子分母按 s 幂次降幂排列
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由结构图求闭环传函并化为二阶标准形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 写出误差传递函数并化为有理分式
本卷实例
  • 关键一步：误差取参考输入减反馈信号
  • 中间结果：误差传函分子分母同阶
  • 卡点：非单位反馈时误差定义要一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写出误差传递函数并化为有理分式
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间反求参数 K 与 τ
本卷实例
  • 关键一步：把两项动态指标写成两个方程
  • 中间结果：指标式分别约束阻尼比与自然频率
  • 卡点：反求后要代回原指标校验
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量与峰值时间反求参数 K 与 τ
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 按误差带计算闭环调节时间
本卷实例
  • 关键一步：先由特征式确定阻尼比与自然频率
  • 中间结果：调节时间近似公式随误差带变化
  • 卡点：题目未注明误差带时要分别说明
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过按误差带计算闭环调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡输入下的稳态误差
本卷实例
  • 关键一步：先判稳再用终值定理
  • 中间结果：斜坡误差由速度误差系数决定
  • 卡点：输入幅值不为一时要乘上幅值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、根轨迹绘制与稳定范围20 分#

思路
  • 由开环传函按法则画根轨迹，求分离点与临界增益，定使闭环稳定的 K 范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则概略绘制闭环根轨迹
本卷实例
  • 关键一步：先定开环零极点与实轴根轨迹段
  • 中间结果：渐近线交于开环极点重心
  • 卡点：渐近线条数与夹角由极零点数差决定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则概略绘制闭环根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点坐标
本卷实例
  • 关键一步：令对增益的导数为零列分离点方程
  • 中间结果：分离点方程化为 d 的有理方程
  • 卡点：求出根后要剔除不在轨迹上的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点坐标
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求临界增益与稳定 K 取值范围
本卷实例
  • 关键一步：由劳斯表首列临界条件定临界 K
  • 中间结果：临界时特征式有一对纯虚根
  • 卡点：还要核对辅助方程给出的频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求临界增益与稳定 K 取值范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式

4四、由 Bode 图反求传函与相角裕度25 分#

思路
  • 由渐近幅频曲线识别环节反求开环传函，再由相频算相角裕度并判别稳定性。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由渐近幅频特性反求开环传函
本卷实例
  • 关键一步：按各段斜率变化识别串联环节
  • 中间结果：低频段延长线与零分贝线定增益
  • 卡点：斜率变化量对应环节重数
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由渐近幅频特性反求开环传函
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 计算相角裕度并据此判稳
本卷实例
  • 关键一步：先由幅频曲线定截止频率
  • 中间结果：相角裕度为截止处相角加 180 度
  • 卡点：截止频率须从原图逐段读出
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过计算相角裕度并据此判稳
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
