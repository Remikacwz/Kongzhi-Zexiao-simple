1结构图求闭环传递函数20 分#

思路
  • 由方框图列信号流图或逐层等效化简，求从输入到输出的闭环传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 由方框图列信号流图并用梅森公式求 C(s)/R(s)
本卷实例
  • 关键一步：先把方框图翻译成信号流图，数清全部回路
  • 中间结果：特征式由一加各独立回路增益构成
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由方框图列信号流图并用梅森公式求 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路找漏，余子式未剔除接触回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 用框图等效由内向外化简多回路系统
本卷实例
  • 关键一步：由最内层反馈环开始逐层消去中间变量
  • 中间结果：等效成单回路后套用反馈连接公式
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过用框图等效由内向外化简多回路系统
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过化简内环时把外环信号当成常数处理
  • 化简内环时把外环的信号当成常数处理

2二阶指标与稳态误差反求参数20 分#

思路
  • 把闭环化为二阶标准形式，由超调量、调节时间与斜坡稳态误差三组要求反求 K 与 T
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与调节时间要求定出阻尼比与自然频率范围
本卷实例
  • 关键一步：由超调量公式反解阻尼比下界
  • 中间结果：由调节时间要求得阻尼比与自然频率之积下界
  • 卡点：两组约束方向相反要联立
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与调节时间要求定出阻尼比与自然频率范围
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过调节时间两种误差带的系数取混
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

  • 中间结果：闭环写成二阶标准形式后系数一一对应
  • 卡点：增益与时间常数须同时满足两条

  • 多个指标同时给出时需求参数可同时满足的公共区域

通用考法
  • 本卷考过综合动态指标与稳态误差要求反求开环增益与时间常数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现

  • 只满足单项指标就下结论，未做交叉验证

典型输入下的稳态误差计算 稳态误差
本卷考法

本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差

  • 写出输入信号的拉氏变换

3根轨迹与临界参数20 分#

思路
  • 写出等效开环后按法则画根轨迹，求分离点与虚轴交点，再由已知闭环极点反求参数
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制参数变化时系统的根轨迹
本卷实例
  • 关键一步：写出等效开环的零极点后按法则定实轴段与渐近线
  • 中间结果：实轴段位于开环零点与最右开环极点之间
  • 卡点：三极点一零点，渐近线有两条
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制参数变化时系统的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴根轨迹段的零极点个数算错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

稳定裕度 频域分析
本卷考法
  • 求系统的相角裕度
本卷实例
  • 关键一步：先由幅值条件求截止频率，再代入相频表达式
  • 中间结果：相角裕度由一百八十度加该点相角得
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求系统的相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过截止频率与相角穿越频率混用
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

奈奎斯特判据 稳定性分析
本卷考法
  • 绘制奈奎斯特图并判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点个数再定包围圈数
  • 中间结果：曲线与负实轴无交点时右半平面根数为零
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
