1一、结构图求闭环传递函数20 分#

思路
  • 观察结构图回路与前向通路，用梅森公式或逐层等效化简求输出的闭环传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求输入到输出的传函
本卷实例
  • 关键一步：找全前向通路与各回路并写出余子式
  • 中间结果：特征式由各回路及其不接触组合构成
  • 卡点：余子式要剔除与前向通路接触的回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求输入到输出的传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由多回路结构图逐层化简
本卷实例
  • 关键一步：先化简最内层回路再向外合并
  • 中间结果：化简后得到单回路闭环形式
  • 卡点：外环信号化简时不能当常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由多回路结构图逐层化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 按串联、并联与反馈等效合成传函
本卷实例
  • 关键一步：反馈回路按极性写分母加减
  • 中间结果：负反馈分母为 1 加回路增益
  • 卡点：并联支路相减时符号要取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过按串联、并联与反馈等效合成传函
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式

2二、由阻尼比与调节时间反求参数25 分#

思路
  • 由结构图求闭环传函并化为标准二阶形式，用阻尼比与调节时间两条件联立反求增益与反馈系数。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函求阻尼比与自然频率
本卷实例
  • 关键一步：把闭环特征方程化为标准二阶形式
  • 中间结果：一次项给出阻尼比、常数项给出自然频率
  • 卡点：反馈系数与增益同时出现在两个系数中
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由调节时间条件建立方程
本卷实例
  • 关键一步：按误差带取调节时间与实部的关系式
  • 中间结果：由调节时间解出阻尼比与自然频率之积
  • 卡点：误差带 2% 与 5% 的系数不能混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由调节时间条件建立方程
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由阻尼比与调节时间联立反求两参数
本卷实例
  • 关键一步：把两个条件写成两元方程组
  • 中间结果：先定阻尼比与自然频率再解参数
  • 卡点：题意限定参数间不等式，解要按此筛选
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由阻尼比与调节时间联立反求两参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式

3三、参数根轨迹法确定参数范围25 分#

思路
  • 把特征方程整理成以待求参数为根轨迹增益的等效开环形式，画参数根轨迹并找根全为实数对应的参数区间。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 把特征方程整理成参数根轨迹的等效开环传函
本卷实例
  • 关键一步：把含参数项与不含参数项分离并写成比值形式
  • 中间结果：等效开环的零极点由分离后的式子给出
  • 卡点：参数需完整提到分子位置再作根轨迹
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过把特征方程整理成参数根轨迹的等效开环传函
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制参数根轨迹并分析根的分布
本卷实例
  • 关键一步：按等效开环零极点画根轨迹
  • 中间结果：根全为实数对应根轨迹落在实轴上的区间
  • 卡点：参数根轨迹仍按 180 度相角条件绘制
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制参数根轨迹并分析根的分布
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求分离点确定参数临界值
本卷实例
  • 关键一步：用分离点方程求出参数临界值
  • 中间结果：由临界值两侧根的实虚性确定参数范围
  • 卡点：舍去不在根轨迹上的分离点解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求分离点确定参数临界值
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式

4四、奈奎斯特曲线与右半平面极点数20 分#

思路
  • 由结构图写出开环传函，画奈氏曲线并标出与负实轴交点，用奈氏判据计算闭环右半平面极点数。
频率特性的物理意义与求法 频域分析
本卷考法
  • 由开环传函写幅频与相频表达式
本卷实例
  • 关键一步：令 s=jω 后分实部虚部整理
  • 中间结果：幅频为各环节模之积、相频为相角之和
  • 卡点：含右半平面极点时起始相角要按实际计算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由开环传函写幅频与相频表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 确定奈氏曲线起点、终点与负实轴交点
本卷实例
  • 关键一步：由低频与高频极限确定首末走向
  • 中间结果：令虚部为零求与负实轴交点频率
  • 卡点：非最小相位环节会使低频段相角异常
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过确定奈氏曲线起点、终点与负实轴交点
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈氏判据求闭环右半平面极点数
本卷实例
  • 关键一步：数开环右半平面极点数并求包围次数
  • 中间结果：由 Z 等于 P 减两倍包围数得闭环极点数
  • 卡点：包围圈数正负号的定义要与教材一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈氏判据求闭环右半平面极点数
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式

5五、Bode 图分析与串联超前校正25 分#

思路
  • 由开环传函画 Bode 图求截止频率与相角裕量，再按给定校正装置画校正后 Bode 图并讨论性能变化。
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制开环对数幅频渐近特性
本卷实例
  • 关键一步：按各环节转角频率逐段累加斜率
  • 中间结果：低频段高度由开环增益与型别确定
  • 卡点：改斜率是累加不是替换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
