1一、结构图求闭环传递函数20 分#

思路
  • 观察结构图的两条回路与前向通路，用梅森公式分别求输入到输出的闭环传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求输入到输出的传函
本卷实例
  • 关键一步：找全两条回路与前向通路并写余子式
  • 中间结果：特征式为 1 减各回路增益之和
  • 卡点：前向通路增益要按信号流向逐级相乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求输入到输出的传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由多回路结构图逐层化简
本卷实例
  • 关键一步：先合并并联支路再作回路化简
  • 中间结果：化简后得到单回路闭环传函
  • 卡点：化简时外环信号不能当常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由多回路结构图逐层化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 按串联、并联与反馈等效合成传函
本卷实例
  • 关键一步：反馈回路按极性写分母加减
  • 中间结果：输出端两个前向通路相加
  • 卡点：通分时公分母要取两个回路之和
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过按串联、并联与反馈等效合成传函
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、二阶系统参数与单位斜坡稳态误差25 分#

思路
  • 由结构图求闭环传函化为标准二阶形式，再由给定阻尼比反求参数，最后用速度误差系数求单位斜坡稳态误差。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函求阻尼比与自然振荡频率
本卷实例
  • 关键一步：把闭环特征方程化为标准二阶形式
  • 中间结果：一次项与常数项分别给出阻尼比与自然频率
  • 卡点：参数 a 同时进入阻尼项，要单独分离
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函求阻尼比与自然振荡频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由给定阻尼比反求结构图参数
本卷实例
  • 关键一步：令阻尼比表达式等于题给值
  • 中间结果：反解出补偿参数 a 的取值
  • 卡点：反解后要代回核对自然频率是否改变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由给定阻尼比反求结构图参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 写出误差传递函数并判别误差定义
本卷实例
  • 关键一步：按给定输入到误差的通道写出误差传函
  • 中间结果：误差传函由闭环传函补成 1 减 Φ
  • 卡点：非单位反馈时误差定义要按题意选择
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写出误差传递函数并判别误差定义
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：先判稳再用速度误差系数
  • 中间结果：稳态误差与开环增益及补偿参数有关
  • 卡点：误差定义分母若含反馈环节需一并代入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、根轨迹绘制与稳定范围25 分#

思路
  • 由前向通道与反馈通道传函合成开环传函，绘根轨迹并求分离点与虚轴交点，据此确定闭环稳定的增益范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制含开环右半平面零点的根轨迹
本卷实例
  • 关键一步：合成开环传函后确定零极点
  • 中间结果：实轴根轨迹段按右侧零极点个数判定
  • 卡点：开环右半平面零点使根轨迹走向反常
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制含开环右半平面零点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 用相角条件判断根轨迹分支走向
本卷实例
  • 关键一步：由各零极点相角验证走向
  • 中间结果：根轨迹向右半平面延伸导致稳定域有限
  • 卡点：起点在原点与实数极点处需分别说明
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过用相角条件判断根轨迹分支走向
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点
本卷实例
  • 关键一步：用 dK/ds 等于零列方程
  • 中间结果：解出分离点后剔除不在轨迹上的根
  • 卡点：先化成根轨迹增益的显式再求导
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤

  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

  • 求根轨迹与虚轴的交点及临界增益

4四、概略幅相曲线与奈氏判稳20 分#

思路
  • 由开环传函写幅频相频表达式，画概略开环幅相曲线，再用奈氏判据判断闭环稳定性。
频率特性的物理意义与求法 频域分析
本卷考法
  • 求开环频率特性的幅频与相频表达式
本卷实例
  • 关键一步：令 s=jω 后分别取模与相角
  • 中间结果：幅频为各环节模之积、相频为相角之和
  • 卡点：相角累加时勿漏两个积分环节的 180 度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求开环频率特性的幅频与相频表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 确定概略开环幅相曲线的起点、终点与走向
本卷实例
  • 关键一步：由低频与高频极限确定首末位置
  • 中间结果：相角随频率单调下降时曲线按此走向
  • 卡点：与负实轴是否相交要由相角条件单独判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
