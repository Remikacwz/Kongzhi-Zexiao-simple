1一、结构图求输入与扰动传函20 分#

思路
  • 由结构图列出回路与前向通路，分别求 R(s)、N(s) 到 C(s) 的传函再叠加。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求两路输入到输出的传函
本卷实例
  • 关键一步：先找全回路并判断是否接触
  • 中间结果：两路传函共用同一特征式
  • 卡点：互不接触回路的乘积分量不要漏
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求两路输入到输出的传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由结构图逐层化简求总传函
本卷实例
  • 关键一步：先求内环等效再向外合并
  • 中间结果：内环等效后回路结构变简单
  • 卡点：比较点移动时要补乘相应因子
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由结构图逐层化简求总传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求扰动 N(s) 到输出的传递函数
本卷实例
  • 关键一步：求扰动传函时令 R(s) 为零
  • 中间结果：扰动通路可能经过反馈环节
  • 卡点：叠加前先确认系统是线性的
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求扰动 N(s) 到输出的传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

2二、二阶系统参数与稳态误差反求20 分#

思路
  • 由结构图求闭环传函，先代入给定 a、K 求指标与误差，再按指标反求 a 与 K。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函求阻尼比与自然频率
本卷实例
  • 关键一步：二次项系数归一后再对系数
  • 中间结果：一次项给出阻尼比与自然频率之积
  • 卡点：前置增益影响常数项
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由给定阻尼比与误差反求参数
本卷实例
  • 关键一步：把两组指标写成两个方程
  • 中间结果：联立后可解出 a 与 K
  • 卡点：反解结果要代回原指标校验
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由给定阻尼比与误差反求参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：按单位斜坡取误差系数 Kv
  • 中间结果：误差等于斜坡幅值除以 Kv
  • 卡点：先判稳再使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

3三、测速反馈校正参数设计15 分#

思路
  • 由结构图求校正后闭环传函，按速度误差系数与阻尼比反求 K1、K2，再校验调节时间。
反馈校正与复合控制 系统校正
本卷考法
  • 用测速反馈改善系统阻尼
本卷实例
  • 关键一步：把测速反馈看作局部速度反馈
  • 中间结果：反馈系数进入闭环一次项
  • 卡点：反馈极性接反会使阻尼变负
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过用测速反馈改善系统阻尼
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
公式
由性能指标要求反求参数 时域响应与动态性能

本卷实例
  • 关键一步：由标准二阶形式匹配一次项
  • 中间结果：阻尼比与反馈系数成线性关系
  • 卡点：反求时别把开环与闭环增益混用

  • 多个指标同时给出时需求参数可同时满足的公共区域

  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现

  • 只满足单项指标就下结论，未做交叉验证

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率校验调节时间
本卷实例
  • 关键一步：按 5% 误差带算调节时间
  • 中间结果：调节时间满足给定上限即可
  • 卡点：误差带不同结果差别较大
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率校验调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

4四、参数根轨迹与闭环极点20 分#

思路
  • 把含 τ 的特征方程整理成参数根轨迹形式，按法则画图定稳定范围，再由幅值条件求 τ。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以时间常数 τ 为变量画参数根轨迹
本卷实例
  • 关键一步：把含 τ 项整理到分子位置
  • 中间结果：等效开环零点来自原特征式 τ 项
  • 卡点：参数根轨迹仍是 180 度轨迹
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以时间常数 τ 为变量画参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹确定参数稳定范围
本卷实例
  • 关键一步：找轨迹穿越虚轴的临界条件
  • 中间结果：稳定范围由虚轴交点给出
  • 卡点：只讨论参数取正值的区间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹确定参数稳定范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 由幅值条件求指定极点的参数
本卷实例
  • 关键一步：把 s=-3 代入幅值条件
  • 中间结果：幅值条件给出 τ 的大小
  • 卡点：余下极点再由特征方程分解求
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过由幅值条件求指定极点的参数
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式

5五、奈奎斯特判稳与稳定 K 范围20 分#

思路
  • 由开环传函求幅相曲线，按奈氏判据判稳并求使闭环稳定的 K 取值范围。
频率特性的物理意义与求法 频域分析
本卷考法
  • 写出幅频与相频表达式
本卷实例
  • 关键一步：令 s=jω 得到频率特性
  • 中间结果：幅频分母含 s 的幂次
  • 卡点：相角中积分环节贡献负 180 度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过写出幅频与相频表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
