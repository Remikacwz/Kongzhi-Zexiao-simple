1结构图求输入与扰动传函20 分#

思路
  • 用梅森公式或框图等效分别求输入作用下的 C(s)/R(s) 与扰动作用下的 C(s)/N(s)
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求输入作用下与扰动作用下的闭环传递函数
本卷实例
  • 关键一步：分别令另一输入为零，用梅森公式或框图化简求传函
  • 中间结果：两条通道分母相同、前向通路不同
  • 卡点：系统结构图需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 扰动误差与输入误差分别计算后再叠加
步骤

  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法

  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 本卷考过求扰动传函时没有把参考输入置零
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

2一阶系统时域指标与稳态误差20 分#

思路
  • 由 G1(s) 的阶跃响应定其传递函数，再在输入为二十倍阶跃时求稳态输出、调节时间与稳态误差
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应表达式求 G1(s)
本卷实例
  • 关键一步：对阶跃响应作拉氏变换后除以输入的拉氏变换
  • 中间结果：稳态项定增益，指数项定时间常数
  • 卡点：输入阶跃幅值为二十，要一并代入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤

  • 判断系统是一阶还是二阶（看有无振荡）

  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应表达式求 G1(s)
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错

  • 未判断系统阶数就直接套用二阶公式

本卷考法

本卷实例

  • 求阶跃输入下的稳态误差
本卷实例

  • 中间结果：零型系统在阶跃输入下误差为有限值

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差

  • 写出输入信号的拉氏变换

通用考法

  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力

  • 未判稳就使用终值定理

3根轨迹与分离点20 分#

思路
  • 由闭环特征方程整理成等效开环画根轨迹，求分离点坐标，再确定阶跃响应非振荡时参数的范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制闭环特征方程的根轨迹
本卷实例
  • 关键一步：把含参数项归到分子写成等效开环再按法则画
  • 中间结果：实轴段、渐近线与分离点由等效零极点定
  • 卡点：等效开环与原系统开环不同，别混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制闭环特征方程的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错

  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

4开环幅相分类讨论稳定性25 分#

思路
  • 按 T1 与 T2 的大小分情形画开环幅相曲线，再用奈氏判据分析闭环稳定性
奈奎斯特判据 稳定性分析
本卷考法
  • 按 T1 与 T2 大小关系绘制开环幅相曲线并判断稳定性
本卷实例
  • 关键一步：写幅频与相频，按两个转折频率先后分情形画曲线
  • 中间结果：两个积分环节使低频相角从负一百八十度出发
  • 卡点：画的是开环幅相曲线而不是闭环响应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过按 T1 与 T2 大小关系绘制开环幅相曲线并判断稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过含积分环节时未补画无穷大圆弧
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

频率特性的物理意义与求法 频域分析
本卷考法
  • 求开环传递函数的幅频与相频表达式
本卷实例
  • 关键一步：把 s 换成正弦频率后分别取模与取相角
  • 中间结果：幅频为各环节模相乘，相频为各环节相角相加
  • 卡点：积分环节贡献负九十度相位
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求开环传递函数的幅频与相频表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过求幅值时忘记先对分母复数取模
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

思路

由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频渐近曲线写出 G0(s) 与 Gc(s) 的传递函数
本卷实例
  • 关键一步：由低频段高度与转折频率、斜率变化确定环节
  • 中间结果：每段斜率变化对应一个典型环节
  • 卡点：G0 与 Gc 的对数幅频曲线需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频渐近曲线写出 G0(s) 与 Gc(s) 的传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 本卷考过延长线交点没有折算型别就当增益
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

本卷考法

  • 中间结果：校正后低频段斜率与高度基本不变
