1一、RC 无源网络求传递函数（12分）12 分#

思路
  • 由电路复阻抗关系列写输入输出关系，消去中间变量求电压传递函数并化为标准有理分式。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由 RC 无源网络列复阻抗方程求电压传递函数
本卷实例
  • 关键一步：用复阻抗分压或回路电流关系写输出与输入之比
  • 中间结果：整理成关于 s 的有理分式并把常数项归一
  • 卡点：电容阻抗写成 Cs 会把量纲与频率关系弄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由 RC 无源网络列复阻抗方程求电压传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由电路网络结构建立输入输出传递函数
本卷实例
  • 关键一步：先判别是否为无源网络，再决定是否用虚短虚断
  • 中间结果：两级 RC 网络存在级间负载效应、不能简单相乘
  • 卡点：需回原卷核对图
  • 卡点：元件连接与级间关系写在图里
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由电路网络结构建立输入输出传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

2二、由传递函数求阻尼比与动态性能指标（12分）12 分#

思路
  • 由结构图写闭环传函并代入给定增益，化成二阶标准形式读出阻尼比与自然频率，再算超调量与调节时间。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传递函数求阻尼比与无阻尼振荡频率
本卷实例
  • 关键一步：把闭环分母与标准二阶特征式逐项对照
  • 中间结果：常值项为自然频率平方、一次项系数为两倍阻尼比乘频率
  • 卡点：需回原卷核对图
  • 卡点：化标准形式时要把最高次项系数归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传递函数求阻尼比与无阻尼振荡频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率计算超调量与调节时间
本卷实例
  • 关键一步：超调量只与阻尼比有关，调节时间还与自然频率有关
  • 中间结果：按给定误差带选择调节时间的系数
  • 卡点：两种误差带对应系数不同，要注明所取误差带
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率计算超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3三、含共轭复零点的根轨迹与稳定域（15分）15 分#

思路
  • 由开环传函写出零极点分布，按法则绘根轨迹，求分离点、出射角与虚轴交点，再由走向确定稳定增益域。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制含共轭复零点的根轨迹草图
本卷实例
  • 关键一步：先定实轴段，再算渐近线、分离点与虚轴交点
  • 中间结果：分支数等于开环极点数，终点为零点或无穷远
  • 卡点：实轴段按右侧零极点个数之奇偶判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制含共轭复零点的根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点或会合点并取舍
本卷实例
  • 关键一步：令特征方程重根条件成立解出坐标
  • 中间结果：淘汰不在根轨迹上的增根
  • 卡点：含复零点时求导方程次数高，需逐根验证
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点或会合点并取舍
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
出射角与入射角 根轨迹法
本卷考法
  • 求复数零点的入射角或复数极点的出射角
本卷实例
  • 关键一步：按相角条件累加其余零极点相角后取补角
  • 中间结果：入射角与出射角的相角条件互为反向
  • 卡点：累加时不把待求极点或零点自身的相角算进去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求复数零点的入射角或复数极点的出射角
  • 求复数极点的出射角
  • 根据出射角画出根轨迹起始方向
  • 由入射角确定根轨迹终止方向
常见易错
  • 累加相角时把该极点自身的相角也算进去
  • 忘记判断象限导致角度差 180°
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点确定临界增益与稳定域
本卷实例
  • 关键一步：令 s 等于 jω 代入特征方程分离实部与虚部
  • 中间结果：解出交点频率与临界增益后结合走向定稳定区间
  • 卡点：稳定域下界由另一个实轴交点增益决定、别只取上界
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹与虚轴交点确定临界增益与稳定域
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式

4四、由对数幅频特性反求开环传函（14分）14 分#

思路
  • 由最小相位系统的对数幅频特性各频段斜率与转折频率识别环节，由截止频率处幅值为零分贝定增益。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由给定对数幅频特性曲线写出开环传递函数
本卷实例
  • 关键一步：按各频段斜率变化识别积分与惯性环节
  • 中间结果：用截止频率处幅值等于 1 的条件列方程定增益
  • 卡点：需回原卷核对图
  • 卡点：转折频率与高度写在图里
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由给定对数幅频特性曲线写出开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
典型环节的对数频率特性 频域分析
本卷考法
  • 由典型环节的对数频率特性识别环节类型
本卷实例
  • 关键一步：比较相邻频段斜率变化量确定环节增减
  • 中间结果：低频段斜率决定积分环节个数
  • 卡点：把惯性环节高频渐近线斜率写错会改变型别判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例环节是水平线，积分与微分分别是 -20 与 +20 dB/dec 的斜线
  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec
  • 一阶微分环节与惯性环节幅频互为镜像
  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤
  • 把传递函数分解为典型环节乘积
  • 逐环节画出对数幅频渐近线与相频曲线
  • 代数相加得到总特性
通用考法
  • 本卷考过由典型环节的对数频率特性识别环节类型
  • 画出某一典型环节的 Bode 图
  • 由 Bode 图识别环节类型
  • 说明转角频率处的幅值与相角
常见易错
  • 把惯性环节高频渐近线的 -20 写成 -40
  • 振荡环节谐振峰位置误当作 ωn

5五、串联校正设计与验证（22分）22 分#

思路
  • 先由速度误差系数要求串联比例环节定增益并检验相角裕度，不满足时再串联滞后网络，最后校验截止频率与裕度。
滞后校正 系统校正
本卷考法
  • 在比例校正基础上设计串联滞后校正装置
本卷实例
  • 关键一步：先按误差系数要求定比例增益，再选新截止频率
  • 中间结果：滞后网络分度系数小于 1，两个转折频率均低于新截止频率
  • 卡点：转折频率取得接近截止频率会抵消相角改善
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过在比例校正基础上设计串联滞后校正装置
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
稳定裕度 频域分析
本卷考法
  • 求校正前后系统的截止频率与相角裕度并验证
本卷实例
  • 关键一步：分别令校正前后幅频等于 1 求截止频率
  • 中间结果：校正后相角裕度应大于给定要求
