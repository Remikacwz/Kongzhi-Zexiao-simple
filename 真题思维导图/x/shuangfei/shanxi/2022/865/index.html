山西大学 865 自动控制原理 2022 年真题思维导图

强势双非共 8 题合计 150 分

难度：中等　8 道大题：单选 5 题（每题 5 分共 25）、简答 3 题（每题 5 分共 15）、RC 电路终值、结构图求传函、高阶系统降阶与动态性能、180 度根轨迹、奈氏判据判稳、由对数幅频特性反求传函；三至八题均印个性化分值。

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

1~5一、单选题五小题（每题5分，共25分）25 分#

思路
  • 五道小题依次考典型环节识别、负反馈闭环特征方程、传递函数基本性质、根轨迹相同的含义与超前校正的最大超前角，按基本概念逐项判断。
典型环节及其特性 传递函数
本卷考法
  • 由给定传递函数判断它属于哪个典型环节（第1小题）
本卷实例
  • 关键一步：把分子或分母对照典型环节的时间常数形式
  • 中间结果：一次多项式可归为一阶微分环节或惯性环节
  • 卡点：比例、积分、惯性、一阶微分四类易混，看是否含 s
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过由给定传递函数判断它属于哪个典型环节（第1小题）
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由开环传函写单位负反馈的闭环特征方程（第2小题）
本卷实例
  • 关键一步：令分母 1 加 GH 为零即得闭环特征方程
  • 中间结果：特征方程由开环分母与分子相加整理得到
  • 卡点：负反馈取加号、正反馈取减号，符号不要写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由开环传函写单位负反馈的闭环特征方程（第2小题）
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
传递函数的定义与基本性质 传递函数
本卷考法
  • 判断关于传递函数的说法中哪一条错误（第3小题）
本卷实例
  • 关键一步：逐条对照传递函数只适用于线性定常系统等前提
  • 中间结果：传递函数只由系统自身结构与参数决定
  • 卡点：把与输入有关当成正确说法是常见误判
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过判断关于传递函数的说法中哪一条错误（第3小题）
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 由两系统根轨迹相同推断其共有的特征（第4小题）
本卷实例
  • 关键一步：根轨迹描述闭环极点随增益变化的移动轨迹
  • 中间结果：根轨迹相同意味着闭环极点集合相同
  • 卡点：根轨迹相同不等于开环零点相同，两者不要混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过由两系统根轨迹相同推断其共有的特征（第4小题）
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
超前校正 系统校正
本卷考法
  • 选出在 ωc 等于 1 处提供最大相位超前角的装置（第5小题）
本卷实例
  • 关键一步：对每个装置的分子分母一次项反算最大超前角频率
  • 中间结果：最大超前角频率为两转折频率的几何平均
  • 卡点：把最大超前角频率与截止频率混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过选出在 ωc 等于 1 处提供最大相位超前角的装置（第5小题）
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式

2二、简答题三小题（每题5分，共15分）15 分#

思路
  • 三小问分别考自动控制的定义、用劳斯判据判断给定特征方程系统的稳定性、以及组合输入下的稳态误差，计算误差前先判稳。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 表述自动控制的定义（第1小题）
本卷实例
  • 关键一步：从无人直接参与、按预定规律运行两方面作答
  • 中间结果：核心是使被控量按预定要求自动变化
  • 卡点：只答反馈概念而漏掉无人直接参与会答不全
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过表述自动控制的定义（第1小题）
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
劳斯判据 稳定性分析
本卷考法
  • 对给定四阶特征方程用劳斯判据判断稳定性（第2小题）
本卷实例
  • 关键一步：按四阶系数列劳斯表并观察首列符号变化
  • 中间结果：首列出现负值说明右半平面存在正实根
  • 卡点：系数缺项时要补零，符号变化次数等于右半平面根数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过对给定四阶特征方程用劳斯判据判断稳定性（第2小题）
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环传函判断系统型别并求静态误差系数（第3小题）
本卷实例
  • 关键一步：按开环中积分环节个数确定系统型别
  • 中间结果：Ⅰ型系统的速度误差系数由开环增益决定
  • 卡点：把开环增益直接当成静态误差系数是常见错误
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由开环传函判断系统型别并求静态误差系数（第3小题）
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求组合输入 3t 加 t 平方下的稳态误差（第3小题）
本卷实例
  • 关键一步：把组合输入拆成斜坡与抛物线两项分别求误差
  • 中间结果：加速度误差分量与静态加速度误差系数有关
  • 卡点：未先判稳就用终值定理会得出错误结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求组合输入 3t 加 t 平方下的稳态误差（第3小题）
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

3三、RC 无源网络求电容电压终值15 分#

思路
  • 由 RC 无源网络写电容电压与电源电压的关系，结合电容初始电压作拉氏变换，再由终值定理求电容电压的稳态值。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由 RC 无源网络求电容电压对电源电压的传递函数
本卷实例
  • 关键一步：按电容电压与电阻压降之和等于电源电压列方程
  • 中间结果：得到一阶惯性形式传函，时间常数为阻容乘积
  • 卡点：电路以图给出，电容与电阻接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由 RC 无源网络求电容电压对电源电压的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由微分方程与电容初始电压求全响应并取终值
本卷实例
  • 关键一步：把初始电容电压代入拉氏变换写成含初值的像函数
  • 中间结果：初值项使响应多出与初值成正比的衰减分量
  • 卡点：漏掉初始条件对应项会算错电容电压的过渡过程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由微分方程与电容初始电压求全响应并取终值
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上
公式

4四、由结构图求传递函数15 分#

思路
  • 由结构图找出全部前向通路与闭合回路，用梅森公式写出输出对输入的传递函数，并写出主要化简步骤。
梅森增益公式与信号流图 传递函数
本卷考法

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例环节是水平线，积分与微分分别是 -20 与 +20 dB/dec 的斜线
  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec
  • 一阶微分环节与惯性环节幅频互为镜像
  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤
  • 把传递函数分解为典型环节乘积
  • 逐环节画出对数幅频渐近线与相频曲线
  • 代数相加得到总特性
通用考法

  • 振荡环节谐振峰位置误当作 ωn

最小相位系统与非最小相位系统 频域分析
本卷考法
  • 利用最小相位条件确定开环传函的零点相位
本卷实例
  • 关键一步：最小相位系统的幅频与相频一一对应，可由幅频唯一确定
  • 中间结果：无右半平面零极点，故各环节符号取正
  • 卡点：非最小相位时不能用幅频唯一确定传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过利用最小相位条件确定开环传函的零点相位
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈
