山西大学 865 自动控制原理 2023 年真题思维导图

强势双非共 8 题

难度：中等　8 道大题：单选 5 题（印每题 5 分共 25 分）、结构图求传函、RC 电路终值、二阶系统动态性能与稳态误差、劳斯判据求参数范围、180 度根轨迹、幅相曲线与稳定裕度、由开环幅频特性求闭环频率特性并作奈奎斯特分析与正弦稳态误差；除第一大题外其余题未印分值。

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

1~5一、单选题五小题（每题5分，共25分）25 分#

思路
  • 五道小题依次考控制系统组成与扰动判断、微分方程线性定常判别、由单位阶跃响应反求微分方程、结构图对应根轨迹形状、由开环幅相曲线判断闭环稳定，按基本概念逐项判断。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 由图判断被控对象、被控量与控制方式并识别扰动信号（第1小题）
本卷实例
  • 关键一步：按给定值与反馈量比较确定被控量，再定操纵量与被控对象
  • 中间结果：控制方式看有无反馈通道，扰动是不希望的外部输入
  • 卡点：原理图以图给出，被控对象与扰动位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过由图判断被控对象、被控量与控制方式并识别扰动信号（第1小题）
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
非线性系统的特点 非线性系统
本卷考法
  • 由微分方程判断系统是线性还是非线性、定常还是时变（第2小题）
本卷实例
  • 关键一步：看方程是否满足叠加原理，再看各系数是否随时间变化
  • 中间结果：含输入导数与积分的常系数线性方程属线性定常系统
  • 卡点：含积分或微分项易被误判为非线性，两者都是线性运算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过由微分方程判断系统是线性还是非线性、定常还是时变（第2小题）
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
由响应曲线反求传递函数 传递函数
本卷考法
  • 由零初始条件下的单位阶跃响应反求系统微分方程（第3小题）
本卷实例
  • 关键一步：先求阶跃响应各分量的拉氏变换得到传递函数
  • 中间结果：把传函写成输出与输入的多项式比后再还原微分方程
  • 卡点：阶跃响应的常数项对应负一次幂分量，容易漏掉
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由零初始条件下的单位阶跃响应反求系统微分方程（第3小题）
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 由结构图判断增益由零到无穷变化时的根轨迹形状（第4小题）
本卷实例
  • 关键一步：先由结构图写出开环零极点，再套实轴段与渐近线法则
  • 中间结果：由零极点分布定分支数、起点终点与走向
  • 卡点：结构图与选项均以图给出，零极点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过由结构图判断增益由零到无穷变化时的根轨迹形状（第4小题）
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 已知开环无右半平面极点，由幅相曲线判断哪个闭环稳定（第5小题）
本卷实例
  • 关键一步：数开环右半平面极点数，再看曲线对临界点的包围次数
  • 中间结果：闭环右半平面极点数由开环极点数与包围次数之差判别
  • 卡点：幅相曲线以图给出，包围方向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过已知开环无右半平面极点，由幅相曲线判断哪个闭环稳定（第5小题）
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式

2二、由结构图求传递函数#

思路
  • 由结构图先找全部回路写特征式，再用梅森公式列前向通路及其余子式，求输出对输入的传递函数并写出主要步骤。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式由结构图求输出对输入的传递函数
本卷实例
  • 关键一步：先枚举全部单独回路并判断两两是否接触，再列前向通路
  • 中间结果：特征式为 1 减各回路增益之和，不接触回路按要求计入
  • 卡点：结构图以图给出，回路与前向通路需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式由结构图求输出对输入的传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 用逐层化简结构图的方法求传递函数
本卷实例
  • 关键一步：从最内层反馈环开始逐层向外合并
  • 中间结果：内环合并后再作串并联得到总传递函数
  • 卡点：化简内环时不可把外环信号当作常数处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过用逐层化简结构图的方法求传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

3三、RC 无源网络求电容电压终值#

思路
  • 由 RC 无源网络写电容电压对电源电压的传递函数，结合电容初始电压作拉氏变换，再取终值求电容电压的稳态值。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由 RC 无源网络求电容电压对电源电压的传递函数
本卷实例
  • 关键一步：用复阻抗分压写出电容电压与电源电压之比
  • 中间结果：得到一阶惯性形式传函，时间常数为阻容乘积
  • 卡点：电路以图给出，电容位置与初值方向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由 RC 无源网络求电容电压对电源电压的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由微分方程与电容初始电压求全响应并取终值
本卷实例
  • 关键一步：把初始电压代入拉氏变换得到含初值的代数方程
  • 中间结果：初值项为电容电压初值与电容的乘积
  • 卡点：漏掉初始条件对应的常数项会算错全响应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由微分方程与电容初始电压求全响应并取终值
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上
公式

4四、二阶系统动态性能与稳态误差#

思路
  • 由单位负反馈开环传函写闭环传函并化为二阶标准形式读出阻尼比与自然频率，再算超调量与调节时间；第二问由组合输入的稳态误差反求开环增益。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由开环传函求闭环传函并读出阻尼比与自然频率（第1问）
本卷实例
  • 关键一步：把开环写成时间常数形式后求闭环再与标准式对照
  • 中间结果：闭环特征式为二次三项式，可直接读阻尼比与自然频率
  • 卡点：化标准形式时要把开环增益折进闭环常数项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由开环传函求闭环传函并读出阻尼比与自然频率（第1问）
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 计算欠阻尼二阶系统的超调量与调节时间（第1问）
本卷实例
  • 关键一步：超调量只与阻尼比有关，调节时间还与自然频率有关
  • 中间结果：把阻尼比与自然频率代入欠阻尼公式即可
  • 卡点：调节时间按百分之五误差带取值，系数别取错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过计算欠阻尼二阶系统的超调量与调节时间（第1问）

  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过绘制概略奈奎斯特曲线并由判据判断系统稳定性（第2、3问）
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

稳定裕度 频域分析
本卷考法
  • 在奈奎斯特曲线上标注相角裕度与幅值裕度（第2问）
本卷实例
  • 关键一步：相角裕度对应幅值穿越频率处到负实轴的相角差
  • 中间结果：幅值裕度对应相位穿越处幅值倒数，由单位圆与负实轴交点读出
  • 卡点：曲线以图给出，两处交点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过在奈奎斯特曲线上标注相角裕度与幅值裕度（第2问）
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

误差定义与误差传递函数 稳态误差
本卷考法
  • 求正弦输入下系统的稳态误差（第3问）
本卷实例
  • 关键一步：写出误差对输入的传递函数后换成频率量取幅值与相角
  • 中间结果：稳态误差为输入幅值乘误差频率特性幅值、相角叠加
  • 卡点：误差定义取参考减输出，非单位反馈不要漏掉反馈环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过求正弦输入下系统的稳态误差（第3问）
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
