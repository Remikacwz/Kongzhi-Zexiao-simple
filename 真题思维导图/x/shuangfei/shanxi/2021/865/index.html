1~8一、选择题八小题（40分）40 分#

思路
  • 八道小题覆盖负反馈作用、典型环节辨识、阻尼状态、开环与闭环稳定性、型别与稳态误差、积分环节幅频特性，逐个按基本概念判断。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断负反馈连接后对稳定性、动态性能与干扰误差的作用
本卷实例
  • 关键一步：从负反馈只改变系统结构与参数、不会自动改善性能切入
  • 中间结果：负反馈可减小干扰误差，但需合理选参才能保证稳定
  • 卡点：选项把负反馈的作用说过头，属常见干扰项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断负反馈连接后对稳定性、动态性能与干扰误差的作用
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
典型环节及其特性 传递函数
本卷考法
  • 由传递函数负 1 除以 5s 加 1 辨识典型环节类型
本卷实例
  • 关键一步：把该传函与惯性、积分、微分环节标准式逐个对照
  • 中间结果：分母为一次式且常数项为 1，属惯性环节
  • 卡点：分子负号只改变增益符号，不改变环节类型
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过由传递函数负 1 除以 5s 加 1 辨识典型环节类型
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由二阶系统所处状态判断阻尼比的取值
本卷实例
  • 关键一步：记住无阻尼、欠阻尼、临界阻尼与过阻尼对应的分界
  • 中间结果：无阻尼对应阻尼比为零，此时闭环极点在虚轴上
  • 卡点：容易把无阻尼与临界阻尼的分界记混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由二阶系统所处状态判断阻尼比的取值
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
劳斯判据 稳定性分析
本卷考法
  • 判断开环稳定与闭环稳定的关系及特征根分布
本卷实例
  • 关键一步：用劳斯判据看特征方程首列的符号变化次数
  • 中间结果：开环稳定与闭环稳定之间没有固定因果关系
  • 卡点：劳斯表首列出现负号即说明存在右半平面根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过判断开环稳定与闭环稳定的关系及特征根分布
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由抛物线输入下的稳态误差判断系统型别
本卷实例
  • 关键一步：把静态加速度误差系数写成 s 趋于零时的极限
  • 中间结果：稳态误差为无穷说明加速度误差系数等于零
  • 卡点：型别要数开环积分环节个数，不能只看误差结果
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由抛物线输入下的稳态误差判断系统型别
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求积分环节的幅频特性表达式
本卷实例
  • 关键一步：把传递函数中的 s 换成 jω 后取模
  • 中间结果：积分环节幅频为增益除以角频率
  • 卡点：积分环节幅值随频率反比下降，相频恒为负 90 度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求积分环节的幅频特性表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 区分根轨迹增益与开环增益并分别求解（第3小题）
本卷实例
  • 关键一步：把开环传函化成首 1 型与尾 1 型两种标准形式
  • 中间结果：首 1 型的比例系数是根轨迹增益，尾 1 型的为开环增益
  • 卡点：两个增益不要混答，换算时要用各环节时间常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过区分根轨迹增益与开环增益并分别求解（第3小题）
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

3三、由结构图求传递函数（15分）15 分#

思路
  • 由系统结构图用梅森公式找出全部回路与各前向通路，写出特征式后求输出对输入的传递函数，并写出步骤。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式由结构图求闭环传递函数
本卷实例
  • 关键一步：先枚举全部回路并判断两两是否接触，再列前向通路
  • 中间结果：特征式为 1 减各回路增益之和再加互不接触回路乘积
  • 卡点：结构图以图给出，回路与前向通路需回原卷核对图

  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环对数幅频特性反求开环传递函数并定增益
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
