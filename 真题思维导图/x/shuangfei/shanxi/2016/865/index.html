1一、由动态性能指标反求参数与稳态误差（15分）15 分#

思路
  • 由结构图写开环与闭环传函并化成二阶标准形式，由超调量与峰值时间求阻尼比与自然频率，再定参数与稳态误差。
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间求阻尼比与自然频率
本卷实例
  • 关键一步：超调量只由阻尼比决定，峰值时间还含自然频率
  • 中间结果：两式联立可分别解出阻尼比与自然频率
  • 卡点：二阶公式仅适用典型二阶系统，带零点时要解响应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与峰值时间求阻尼比与自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由期望动态性能指标反求开环增益与时间常数
本卷实例
  • 关键一步：把指标解出的阻尼比与自然频率与标准式系数对应
  • 中间结果：自然频率定增益、一次项系数定反馈支路时间常数
  • 卡点：需回原卷核对图
  • 卡点：反馈支路时间常数出现在闭环一次项中
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由期望动态性能指标反求开环增益与时间常数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位阶跃输入下系统的稳态误差
本卷实例
  • 关键一步：先由阻尼比判断系统稳定再求位置误差系数
  • 中间结果：含积分环节时位置误差系数为无穷、阶跃误差为零
  • 卡点：未判稳就用终值定理会得到错误结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位阶跃输入下系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

2二、由闭环极点反求参数并绘零度根轨迹（15分）15 分#

思路
  • 由给定闭环极点写期望特征多项式并与实际特征方程比较定参数，再按零度根轨迹条件绘根轨迹并确定稳定增益范围。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 由负时间常数引入的右半平面零点绘制零度根轨迹
本卷实例
  • 关键一步：先把开环传函化为含根轨迹参数的标准形式
  • 中间结果：含右半平面零点时相角条件为 2kπ，属零度根轨迹
  • 卡点：需回原卷核对图
  • 卡点：零度根轨迹不能沿用 180 度的实轴段判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过由负时间常数引入的右半平面零点绘制零度根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制增益由零到无穷变化时的根轨迹
本卷实例
  • 关键一步：先定实轴段与渐近线，再定起点与终点
  • 中间结果：分支数等于开环极点数
  • 卡点：零度根轨迹的实轴段按偶数个零极点判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制增益由零到无穷变化时的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点或会合点并取舍
本卷实例
  • 关键一步：由特征方程重根条件求导为零解出坐标
  • 中间结果：保留位于根轨迹上的解、舍去增根
  • 卡点：零度根轨迹分离点方程的符号与常规不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点或会合点并取舍
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴的交点及临界增益
本卷实例
  • 关键一步：令 s 等于 jω 代入特征方程分离实部与虚部
  • 中间结果：由实部与虚部方程解出交点频率与临界增益
  • 卡点：交点频率要结合根轨迹走向判断稳定区间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴的交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

3三、劳斯判据求稳定范围与实部限制#

思路
  • 由开环传函写闭环特征方程列劳斯表求稳定增益范围，再用变量平移把极点实部限制化为新变量下的稳定问题。
劳斯判据 稳定性分析
本卷考法
  • 列劳斯表求使系统稳定的开环增益范围
本卷实例
  • 关键一步：按降幂排列系数并列劳斯表，要求首列同号
  • 中间结果：稳定范围由首列各元为正的不等式交集确定
  • 卡点：本题题头含分值在源文 OCR 中缺失
  • 卡点：系数缺项要先补零再列劳斯表
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过列劳斯表求使系统稳定的开环增益范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 用变量平移求闭环极点实部不超过给定值的范围
本卷实例
  • 关键一步：令新变量等于原变量加偏移量后代回特征方程
  • 中间结果：新特征方程下稳定即原极点实部不超过给定界
  • 卡点：平移量符号取反会把实部限制方向弄错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过用变量平移求闭环极点实部不超过给定值的范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式

4四、由对数幅频特性反求传函与相角裕度（15分）15 分#

思路
  • 由最小相位系统对数幅频特性斜率变化识别环节并定增益，再求截止频率、相角裕度与幅值裕度判断闭环稳定性。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由给定对数幅频特性曲线写出开环传递函数
本卷实例
  • 关键一步：按各频段斜率变化识别积分与惯性环节
  • 中间结果：低频段高度或某频率处幅值条件用来定增益
  • 卡点：需回原卷核对图
  • 卡点：转折频率与高度写在图里，需读图确认
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由给定对数幅频特性曲线写出开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 由开环传函求截止频率、相角裕度与幅值裕度
本卷实例
  • 关键一步：令幅频等于 1 求截止频率，再算相角与 180 度之和
  • 中间结果：最小相位系统裕度均为正时闭环稳定
  • 卡点：相位穿越频率处幅值要取倒数才是幅值裕度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由开环传函求截止频率、相角裕度与幅值裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

5五、串联超前校正设计与验证（15分）15 分#

思路
  • 由速度误差要求定增益，求未校正系统的相角裕度，再按最大超前角公式设计超前网络参数并校验。
超前校正 系统校正
本卷考法
  • 设计串联超前校正装置使相角裕度与截止频率达标
本卷实例
  • 关键一步：先算需补偿相角并留附加量，再由公式定分度系数
  • 中间结果：最大超前角频率等于新截止频率处定时间常数
  • 卡点：补偿角要含截止频率提高带来的附加相角损失
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
