山西大学 865 自动控制原理 2025 年真题思维导图

强势双非共 16 题

难度：中等　逐题清点共16题（卷首印本试卷共10题，与实际编号不符）。第1至8题为选择与简答性质的基础题：稳定性决定因素、校正类型判断、奈氏判据辅助函数辨析、一阶阶跃响应、由脉冲响应求传函、实轴根轨迹、PID 积分作用、最大超前角比较。第9至16题为计算与综合题：有源网络求传函、结构图参数对稳定性动态性能与斜坡误差的影响、复合控制稳定条件与校正装置、三阶系统根轨迹、由渐近对数幅频特性反求传函与相角裕度、水温过程控制系统方框图、开环幅相曲线、相角裕度要求下的增益与串联滞后校正。含图题较多，第9、10、11、13、14题题面含原卷插图。卷面与答案册均未逐题标注分值。

1一、线性系统稳定性的决定因素#

思路
  • 四个选项围绕稳定性是系统固有属性展开，判断其只由系统结构与参数决定，与外部输入和初始状态无关。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断线性系统稳定性由结构参数还是输入初值决定
本卷实例
  • 关键一步：从稳定性是系统固有属性、与外部作用和初值无关切入
  • 中间结果：四个选项中只有系统结构与参数属于系统自身固有属性
  • 卡点：非线性系统的稳定性与初始条件有关，不能套用线性结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断线性系统稳定性由结构参数还是输入初值决定
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

2二、由传递函数判断校正类型#

思路
  • 把给定传函化成分子分母各为一阶的标准形式，比较零极点相对位置判断校正特性。
滞后校正 系统校正
本卷考法
  • 由传递函数分子分母系数判断是超前还是滞后
本卷实例
  • 关键一步：把传函写成分子一次项系数小于分母一次项系数的形式
  • 中间结果：零点比极点更靠近原点，低频增益抬高，属滞后特性
  • 卡点：零极点同处左半平面时靠相对位置区分，不能只看阶次
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过由传递函数分子分母系数判断是超前还是滞后
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

3三、奈氏判据中辅助函数的零极点辨析#

思路
  • 由辅助函数与开环传函的关系出发，辨析零点对应闭环特征根、极点对应开环极点。
奈奎斯特判据 稳定性分析
本卷考法
  • 辨析辅助函数 F(s) 零极点对应的闭环与开环极点
本卷实例
  • 关键一步：写出辅助函数与开环传函相加后与闭环特征式的关系
  • 中间结果：辅助函数的极点是开环极点，零点是闭环特征根
  • 卡点：辅助函数极点数为开环极点数，与闭环极点个数不必相同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过辨析辅助函数 F(s) 零极点对应的闭环与开环极点
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式

4四、一阶系统单位阶跃响应#

思路
  • 对一阶惯性传函作部分分式分解后逐项反变换，得到单调上升的指数响应。
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 求一阶惯性系统在单位阶跃输入下的响应
本卷实例
  • 关键一步：把输出拉氏变换拆成两项便于逐项反变换
  • 中间结果：响应为从零单调上升并趋于稳态的指数曲线
  • 卡点：输出初值为零、稳态值为一，时间常数决定上升快慢
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过求一阶惯性系统在单位阶跃输入下的响应
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式

5五、由单位脉冲响应求传递函数#

思路
  • 传递函数是单位脉冲响应的拉氏变换，把给定的指数项逐项变换即可。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位脉冲响应直接写出系统传递函数
本卷实例
  • 关键一步：对给出的单位脉冲响应逐项取拉氏变换
  • 中间结果：各指数项各对应一个一阶环节，求和即为传函
  • 卡点：脉冲响应与传递函数是一对拉氏变换，不要误作阶跃响应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位脉冲响应直接写出系统传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式

6六、实轴根轨迹段的判断#

思路
  • 在开环零极点图上按实轴段判别规则：某段右侧开环零极点总数为奇数时该段属于根轨迹。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 判断含原点重极点的系统在实轴上的根轨迹段
本卷实例
  • 关键一步：按实轴上某段右侧开环零极点总数为奇数判定该段属根轨迹
  • 中间结果：原点三重极点与负实轴单极点把实轴分成三段逐一判定
  • 卡点：重极点要按重数累加，右侧个数为奇数的段才保留
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过判断含原点重极点的系统在实轴上的根轨迹段
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式

7七、PID 中积分环节的作用#

思路
  • 从积分作用对误差的累积效应出发，说明它提高系统型别、消除稳态误差并影响稳定性。
PID 控制器与参数整定 系统校正
本卷考法
  • 说明 PID 中积分环节 I 的作用
本卷实例
  • 关键一步：从积分作用使误差累积并抬高系统型别切入
  • 中间结果：积分环节把有差系统变为无差，代价是稳定性下降
  • 卡点：积分作用同时带来相位滞后与超调增大
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过说明 PID 中积分环节 I 的作用
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

8八、超前网络最大超前角的比较#

思路
  • 把每个网络化成零点与极点之比的形式读出分度系数，用最大超前角随分度系数增大的规律比较。
超前校正 系统校正
本卷考法
  • 比较各超前网络能提供的最大超前角
本卷实例
  • 关键一步：把各选项写成分子一次项与分母一次项之比的形式
  • 中间结果：分子系数相对分母越大，网络的最大超前角越大
  • 卡点：分子一次项系数要尽量大、分母尽量小才有大超前角
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过比较各超前网络能提供的最大超前角
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式

9九、有源网络求传递函数 图1#

思路
  • 对有源网络用运放虚短虚断与复阻抗法列电流方程，消去中间电压后整理成输出比输入。
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由运放有源网络列写电流与电压关系
本卷实例
  • 关键一步：用虚短虚断把运放两端电压取零，再按复阻抗列节点方程
  • 中间结果：输入支路为电阻，反馈支路为电阻与电容并联
  • 卡点：图未读图，电阻电容的接法与反馈支路连接需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由运放有源网络列写电流与电压关系
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由复阻抗关系整理出网络传递函数
本卷实例
  • 关键一步：把复阻抗表达式代入电流平衡式并消去中间量
  • 中间结果：整理后分母为电阻乘电容乘 s 再加一的一阶形式
  • 卡点：反相输入引入负号，反馈阻抗是电阻并电容而非相加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由复阻抗关系整理出网络传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

10十、结构图参数对稳定性动态性能与斜坡误差的影响 图2#

思路
  • 先由结构图求闭环传函并化成二阶标准形式读出自然频率与阻尼比，再分问讨论参数增大对稳定、动态性能与斜坡稳态误差的影响。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图求闭环传递函数并化成标准二阶形式
