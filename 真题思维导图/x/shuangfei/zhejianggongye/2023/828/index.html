一一、信号流图求传函与误差传函#

思路
  • 由系统信号流图找出全部回路与前向通路，写特征式后用梅森公式求输出对输入及误差对输入的传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 用信号流图与梅森公式求输出对输入的传递函数
本卷实例
  • 关键一步：先找全部单独回路写特征式，再列前向通路及其余子式
  • 中间结果：传函等于各前向通路增益乘余子式之和除以特征式
  • 卡点：信号流图以图给出，回路与前向通路需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用信号流图与梅森公式求输出对输入的传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 求误差对输入的传递函数
本卷实例
  • 关键一步：按误差等于输入减输出写出误差传函
  • 中间结果：误差传函由前向通路的余子式组合表示
  • 卡点：非单位反馈时误用单位反馈的误差定义
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过求误差对输入的传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

二二、扰动作用下的闭环传函与顺馈补偿#

思路
  • 由单位反馈系统结构图分别求扰动作用下的闭环传函，用终值定理求阶跃扰动稳态输出，再引入顺馈通道使扰动对输出的稳态影响最小
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求误差扰动作用下的闭环传递函数
本卷实例
  • 关键一步：把参考输入置零，只保留扰动通道求输出对扰动的传函
  • 中间结果：扰动传函分母为闭环特征式，分子由扰动接入点决定
  • 卡点：求扰动传函时没有把参考输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求误差扰动作用下的闭环传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求单位阶跃扰动作用下系统的稳态输出
本卷实例
  • 关键一步：先判稳，再用终值定理由扰动传函求稳态值
  • 中间结果：稳态输出由扰动传函在零频处的极限决定
  • 卡点：未判稳就使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求单位阶跃扰动作用下系统的稳态输出
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
反馈校正与复合控制 系统校正
本卷考法
  • 设计顺馈补偿通道使扰动对输出的稳态影响最小
本卷实例
  • 关键一步：在扰动到输出的通道上并联补偿支路，令合成传函零频为零
  • 中间结果：补偿参数使扰动传函分子在零频处为零
  • 卡点：前馈补偿器含高阶微分不可实现却直接采用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过设计顺馈补偿通道使扰动对输出的稳态影响最小
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

三三、由校正后Bode图反求校正装置#

思路
  • 由固有部分传函与校正后开环对数幅频图反求校正后传函与校正装置，画其渐近线，再求相角裕度并判别校正形式
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由校正后对数幅频图反求开环传递函数
本卷实例
  • 关键一步：按各段斜率变化识别积分与惯性环节，由转折频率定时间常数
  • 中间结果：低频段斜率与高度确定型别与增益
  • 卡点：把延长线交点高度直接当增益，未按型别折算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由校正后对数幅频图反求开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
期望特性法与综合法 系统校正
本卷考法
  • 由校正后开环传函减去固有部分求校正装置并画其渐近线
本卷实例
  • 关键一步：校正后传函除以固有部分得校正装置传函
  • 中间结果：校正装置由比例与一阶环节组成
  • 卡点：相减后得到的特性不可物理实现却未检查
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 期望特性法直接按指标画出希望的开环对数幅频特性
  • 用期望特性减去未校正特性得到校正装置特性
  • 关键是确定低频段高度、中频段宽度与高频段斜率
  • 中频段斜率一般取 -20 dB/dec 并保持足够宽度
步骤
  • 按稳态要求确定低频段斜率与高度
  • 按相角裕度要求确定中频段宽度与截止频率
  • 按抗噪要求确定高频段斜率
  • 相减求得校正装置并检验可实现性
通用考法
  • 本卷考过由校正后开环传函减去固有部分求校正装置并画其渐近线
  • 用期望特性法设计校正装置
  • 说明中频段宽度与相角裕度的关系
  • 由校正装置特性反写传递函数
常见易错
  • 期望特性的中频段取窄导致裕度不足
  • 相减后得到的特性不可物理实现却未检查
公式
稳定裕度 频域分析
本卷考法
  • 求校正后系统的相角裕度并判断校正形式
本卷实例
  • 关键一步：由截止频率处的相角与负一百八十度之差求相角裕度
  • 中间结果：相角裕度大于零对应闭环稳定
  • 卡点：把截止频率与相角交越频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求校正后系统的相角裕度并判断校正形式
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式

四四、比例与PD校正下的奈氏判据#

思路
  • 针对开环传函含右半平面极点的情况，分别绘比例校正与 PD 校正下的奈奎斯特图，用奈氏判据求使系统稳定的参数范围
频率特性的物理意义与求法 频域分析
本卷考法
  • 写开环幅频与相频表达式并绘制奈奎斯特图
本卷实例
  • 关键一步：把 s 换成 jω 后分别取模与相角
  • 中间结果：曲线起点、终点与穿越负实轴情况由环节决定
  • 卡点：未补画无穷大半径圆弧就数包围圈数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过写开环幅频与相频表达式并绘制奈奎斯特图
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈氏判据判断加比例或 PD 校正后系统的稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数，再数曲线对负一临界点的包围
  • 中间结果：由包围圈数与极点数关系得稳定条件
  • 卡点：开环含右半平面极点时未按穿越数修正判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈氏判据判断加比例或 PD 校正后系统的稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

五五、采样系统稳态误差反求K范围#

思路
  • 由含零阶保持器与延迟的采样系统结构求开环脉冲传函，再由组合输入下的稳态误差要求反求增益范围
脉冲传递函数 离散控制系统
本卷考法
  • 求含零阶保持器与延迟的采样系统开环脉冲传递函数
本卷实例
  • 关键一步：先求连续部分脉冲传函，再乘零阶保持器对应因子
  • 中间结果：开环脉冲传函含 z 的延迟因子与对象极点
  • 卡点：漏乘零阶保持器的一减 z 的负一次幂
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过求含零阶保持器与延迟的采样系统开环脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)
公式
离散系统的稳态误差 离散控制系统
本卷考法
  • 由组合输入下稳态误差要求反求增益范围
本卷实例
  • 关键一步：按输入分量分别求稳态误差并相加，令其小于给定值
  • 中间结果：稳态误差表达式中含开环增益的倒数
  • 卡点：直接用 s 域静态误差系数处理离散系统
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
