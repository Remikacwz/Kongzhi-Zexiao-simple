一一、RLC电路传函与频率特性15 分#

思路
  • 用复阻抗法对 R-L-C 电路列电流与电压方程求传递函数，再令 s 等于 jω 得频率特性，由正弦稳态响应求通过电阻的稳态电流
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由 R-L-C 电路求输出对输入的传递函数
  • 由电路求电阻电流对输入电压的频率特性
本卷实例
  • 关键一步：对节点列电流方程、对回路列电压方程，消去中间电流得传函
  • 中间结果：传函分母为电感电容乘积的二次项与电感电阻之比的一次项之和
  • 卡点：电容复阻抗误写成 Cs，应为 sC 的倒数
  • 卡点：电路接法以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由 R-L-C 电路求输出对输入的传递函数
  • 本卷考过由电路求电阻电流对输入电压的频率特性
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 把电流传函中的 s 换成 jω，求正弦稳态电流
本卷实例
  • 关键一步：令 s 等于 jω 后分别取模与相角，得电流对电压的幅频与相频
  • 中间结果：稳态电流幅值等于输入幅值乘幅频值，相角由相频决定
  • 卡点：求幅值时忘记对分母复数整体取模再相除
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过把电流传函中的 s 换成 jω，求正弦稳态电流
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

二二、参数β对稳定性与动态性能的影响20 分#

思路
  • 由含内环的结构图逐层化简求开环与闭环传函，再用劳斯判据判稳、用二阶指标分析参数对动态性能的影响，最后由误差传函求斜坡输入下的稳态误差
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 逐层化简含内环与多回路的系统结构图，求开环与闭环传函
本卷实例
  • 关键一步：先化简内环得等效前向环节，再与外层环节串联求闭环
  • 中间结果：闭环特征式的一次项系数由内环反馈参数决定
  • 卡点：化简内环时把反馈极性或回路增益写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过逐层化简含内环与多回路的系统结构图，求开环与闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
劳斯判据 稳定性分析
本卷考法
  • 分析参数取值对闭环系统稳定性的影响
本卷实例
  • 关键一步：列劳斯表并令首列各元素均为正，得参数应满足的不等式
  • 中间结果：参数取零对应临界稳定，存在一对纯虚根
  • 卡点：把参数取零判成稳定，实际为临界稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过分析参数取值对闭环系统稳定性的影响
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 分析参数对二阶系统阶跃响应动态性能的影响
本卷实例
  • 关键一步：把闭环特征式化为标准二阶形式，读出阻尼比与自然频率
  • 中间结果：阻尼比随该参数增大而增大，超调量与调节时间随之变化
  • 卡点：只答超调量变化，漏答调节时间的变化趋势
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过分析参数对二阶系统阶跃响应动态性能的影响
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求参数变化对系统斜坡响应稳态性能的影响
本卷实例
  • 关键一步：先判稳，再由静态速度误差系数求单位斜坡下的稳态误差
  • 中间结果：速度误差系数由开环增益与型别共同决定
  • 卡点：未判稳就直接代入终值定理求稳态误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求参数变化对系统斜坡响应稳态性能的影响
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

三三、微分方程组系统的误差与稳定条件15 分#

思路
  • 对给定微分方程组取零初始条件下的拉氏变换，消去中间变量得误差传函，再用劳斯判据求闭环稳定的参数条件，最后由斜坡输入下稳态误差上限反求参数范围
误差定义与误差传递函数 稳态误差
本卷考法
  • 由微分方程组求误差传递函数 E(s)/R(s)
本卷实例
  • 关键一步：对方程组逐式取拉氏变换，消去中间变量得误差对输入的传函
  • 中间结果：误差传函由反馈通道与前向通道传函组合而成
  • 卡点：忽略零初始条件，把初值带进变换结果
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由微分方程组求误差传递函数 E(s)/R(s)
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

四四、离散系统脉冲传函与稳定性15 分#

思路
  • 由离散系统结构图与给定差分方程分别求两个环节的脉冲传函，再写闭环特征方程，用 z 域稳定判据判断系统稳定性
脉冲传递函数 离散控制系统
本卷考法
  • 求离散系统两个环节的脉冲传递函数并写闭环特征方程
本卷实例
  • 关键一步：对差分方程取 z 变换并利用零初始条件求脉冲传函
  • 中间结果：闭环特征方程为 z 的多项式方程
  • 卡点：把两个无采样开关隔开的连续环节直接相乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过求离散系统两个环节的脉冲传递函数并写闭环特征方程
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)

五五、模拟电路状态空间建模与判稳15 分#

思路
  • 由模拟电路图选状态变量写状态方程与输出方程，画出系统结构图，再用李雅普诺夫第二法分析平衡点稳定性
状态空间表达式的建立 状态空间分析
本卷考法
