1传递函数定义与典型输入响应关系#

思路
  • 由零初始条件定义传函，再由拉氏变换关系说明输出
传递函数的定义与基本性质 传递函数
本卷考法
  • 叙述传递函数的定义及其物理含义
本卷实例
  • 关键一步：强调零初始条件下输出与输入拉氏变换之比
  • 中间结果：传函只由系统结构与参数决定，与输入无关
  • 卡点：忽略零初始条件这一前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过叙述传递函数的定义及其物理含义
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
典型输入信号 基本概念与信号
本卷考法
  • 说明典型输入信号与输出响应之间的变换关系
本卷实例
  • 关键一步：分别写出阶跃、斜坡与加速度输入的拉氏变换
  • 中间结果：输出响应对应传函与输入拉氏变换的乘积
  • 卡点：把加速度输入的拉氏变换幂次写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 常用典型输入有冲激、阶跃、斜坡、抛物线（加速度）与正弦五类
  • 阶跃信号用于考查快速性与稳定性，斜坡与抛物线用于考查稳态精度
  • 正弦信号用于频域分析，冲激响应就是系统的传递函数
  • 各典型信号的拉氏变换是分析全响应的起点
步骤
  • 按题意写出输入信号的时域表达式
  • 对输入取拉氏变换得到该信号的复域形式
  • 由输入类型判断考查的是动态性能还是稳态精度
  • 把输入代入误差或响应公式计算
通用考法
  • 本卷考过说明典型输入信号与输出响应之间的变换关系
  • 写出典型输入信号的拉氏变换
  • 说明某一典型输入信号用于考查哪类性能
  • 由输入类型判断稳态误差是否为有限值
常见易错
  • 把斜坡与抛物线信号的阶次写错
  • 阶跃的拉氏变换漏掉系数（幅度不为 1 时）

2串联超前校正的实质与影响#

思路
  • 用超前网络提供的正相角补偿原系统的滞后相角
超前校正 系统校正
本卷考法
  • 说明串联超前校正的实质及对系统性能的影响
本卷实例
  • 关键一步：超前网络在中频段提供正相角
  • 中间结果：相角裕度与截止频率提高，响应加快
  • 卡点：只答稳定性改善，漏答动态性能变化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过说明串联超前校正的实质及对系统性能的影响
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

3采样信号表达式与采样定理#

思路
  • 写出冲激采样表达式，再由采样定理确定周期上限
采样过程与香农采样定理 离散控制系统
本卷考法
  • 写出采样信号的数学表达式并说明采样定理
本卷实例
  • 关键一步：采样信号表示为冲激序列与连续信号的乘积
  • 中间结果：采样频率须不小于信号最高频率的二倍
  • 卡点：把采样定理中的二倍关系写成相等
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过写出采样信号的数学表达式并说明采样定理
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后
公式
信号采样与频谱的基本概念 基本概念与信号
本卷考法
  • 说明如何根据信号最高频率选取采样周期
本卷实例
  • 关键一步：由最高频率确定采样频率下限
  • 中间结果：采样周期上限等于采样频率下限的倒数
  • 卡点：把最高频率与频谱延拓周期混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 周期信号可展开为傅里叶级数，各次谐波的幅值构成频谱
  • 冲激采样信号的频谱是原信号频谱的周期延拓
  • 频谱延拓的周期由采样频率决定，不重叠才能由理想低通恢复原信号
  • 恢复用的理想低通截止频率取在采样频率的一半处
步骤
  • 先求连续信号的频谱或按给定波形求谐波幅值
  • 按采样频率写出延拓后频谱的周期与各次副本的位置
  • 检查最高频率是否小于采样频率的一半，判断能否无失真恢复
  • 需要恢复时选取截止频率与增益合适的理想低通滤波器
通用考法
  • 本卷考过说明如何根据信号最高频率选取采样周期
  • 由采样频率判断给定信号能否无失真恢复
  • 写出冲激采样后信号的频谱表达式
  • 确定恢复滤波器的截止频率
常见易错
  • 把采样定理里的两倍关系记成相等，或漏掉两倍
  • 把最高频率与频谱延拓的周期混为一谈

4一阶系统单位阶跃响应#

思路
  • 把阶跃输入拉氏变换与一阶传函相乘后反变换
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 求一阶系统在单位阶跃输入下的响应表达式
本卷实例
  • 关键一步：将一减指数形式的传函与输入拉氏变换相乘
  • 中间结果：部分分式展开后作拉氏反变换
  • 卡点：把开环传函误当作闭环传函使用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过求一阶系统在单位阶跃输入下的响应表达式
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

5劳斯判据数右半平面特征根#

思路
  • 列闭环特征方程，由劳斯表首列变号次数得根数
劳斯判据 稳定性分析
本卷考法
  • 用劳斯表判断右半平面闭环特征根的个数
本卷实例
  • 关键一步：由开环传函写出闭环特征方程并降幂排列
  • 中间结果：劳斯表首列符号改变次数等于右半平面根数
  • 卡点：系数缺项时不补零就直接列表
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯表判断右半平面闭环特征根的个数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

6前馈补偿使扰动影响最小#

思路
  • 列扰动到输出的传递函数，令其分子为零求参数
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求使阶跃扰动对输出影响最小的前馈参数
本卷实例
  • 关键一步：分别写扰动通道与前馈通道到输出的传函
  • 中间结果：令扰动到输出传函的分子为零解参数
  • 卡点：只处理扰动项，未说明对给定信号的影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求使阶跃扰动对输出影响最小的前馈参数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
反馈校正与复合控制 系统校正
本卷考法
  • 说明前馈补偿在复合控制系统中的作用
本卷实例
  • 关键一步：前馈按扰动测量直接补偿，不进入闭环特征方程
  • 中间结果：补偿后扰动项被对消，闭环稳定性不受影响
  • 卡点：把前馈补偿与反馈校正的结构混同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过说明前馈补偿在复合控制系统中的作用
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

系统型别与静态误差系数 稳态误差
本卷考法

本卷实例

步骤

  • 按型别选择对应的静态误差系数公式
  • 代入求值

  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

8奈氏曲线负实轴穿越次数#

思路
  • 令相角为负一百八十度求交点，再数穿越负实轴的次数
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环传函求奈氏曲线对负实轴的穿越次数
本卷实例
  • 关键一步：将 s 换成 jω 后令虚部为零求交点
  • 中间结果：完整曲线关于实轴对称，穿越次数要乘二
  • 卡点：开环含积分环节时未补画无穷大半径圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
