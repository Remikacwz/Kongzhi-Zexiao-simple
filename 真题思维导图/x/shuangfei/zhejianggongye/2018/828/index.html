1图示电路的传递函数15 分#

思路
  • 用复阻抗法列分压关系，逐步化简得输出与输入之比
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由 RLC 网络求输出电压对输入电压的传递函数
本卷实例
  • 关键一步：把电感与电容写成复阻抗后列节点分压
  • 中间结果：先求中间节点电压再乘后级分压比
  • 卡点：电路拓扑由插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由 RLC 网络求输出电压对输入电压的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

2PID控制器的参数稳定域15 分#

思路
  • 写含控制器参数的闭环特征方程，用劳斯判据解参数不等式
PID 控制器与参数整定 系统校正
本卷考法
  • 分析P、PI、PID控制器参数对闭环稳定性的影响
本卷实例
  • 关键一步：分别写出三种控制器下的开环传函
  • 中间结果：把控制器与对象串联后求闭环特征式
  • 卡点：被控对象的结构以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过分析P、PI、PID控制器参数对闭环稳定性的影响
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

本卷考法

  • 中间结果：联立劳斯表首列各元的不等式取交集

3二阶系统超调条件与超调量15 分#

思路
  • 由结构图化闭环传函，对照标准二阶形式得阻尼比与自然频率
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函化为标准二阶形式求阻尼比与自然频率
本卷实例
  • 关键一步：令分母一次项等于两倍阻尼乘自然频率
  • 中间结果：由分母常数项开方得到自然频率
  • 卡点：结构图含局部反馈，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函化为标准二阶形式求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比判断是否存在超调并计算超调量
本卷实例
  • 关键一步：按阻尼比是否小于一判断有无超调
  • 中间结果：把阻尼比代入二阶超调量计算式
  • 卡点：把阻尼比与超调量公式的对应关系记反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比判断是否存在超调并计算超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

4阶跃输入下稳态误差为零的补偿#

思路
  • 用梅森公式写误差对输入的传函，令其零点抵消常数项
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求阶跃输入下系统的稳态误差
本卷实例
  • 关键一步：先用终值定理前判断系统稳定性
  • 中间结果：写出误差传函后取 s 趋于零的极限
  • 卡点：结构含补偿支路，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求阶跃输入下系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

反馈校正与复合控制 系统校正
本卷考法
  • 由误差传函分子为零确定补偿支路增益
本卷实例
  • 关键一步：用梅森公式求误差对参考输入的传函
  • 中间结果：令常数项分子等于零解补偿增益
  • 卡点：补偿通道符号取反会使结果差一负号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过由误差传函分子为零确定补偿支路增益
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

6奈氏判据与临界增益、相位裕量#

思路
  • 画奈氏曲线求与实轴交点，按穿越条件定临界增益再算裕量
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环传函画奈氏曲线并求临界稳定增益
本卷实例
  • 关键一步：令 s 等于虚频率变量分离实部与虚部
  • 中间结果：曲线过临界点时对应开环增益为临界值
  • 卡点：含积分环节未补画无穷大半径圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环传函画奈氏曲线并求临界稳定增益
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
稳定裕度 频域分析
本卷考法
  • 由截止频率求开环增益并计算相位裕量
本卷实例
  • 关键一步：令开环幅值等于一解出截止频率处增益
  • 中间结果：相角裕量为该处相角加一百八十度
  • 卡点：把截止频率与相角穿越频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由截止频率求开环增益并计算相位裕量
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

7离散系统脉冲传函与稳定性#

思路
  • 按采样开关位置求开环脉冲传函，再用 z 域判据判闭环稳定
脉冲传递函数 离散控制系统
本卷考法
  • 求含零阶保持器离散系统的开环脉冲传递函数
本卷实例
  • 关键一步：先写连续部分与零阶保持器的串联传函
  • 中间结果：对连续部分作 z 变换得到脉冲传函
  • 卡点：采样开关位置以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
