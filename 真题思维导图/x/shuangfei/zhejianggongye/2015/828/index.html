1惯性微分代替纯微分的原因#

思路
  • 从纯微分对高频噪声的放大与工程实现困难两点说明
校正的基本概念与性能指标 系统校正
本卷考法
  • 说明工程中用带惯性环节的微分代替纯微分的原因
本卷实例
  • 关键一步：比较纯微分与带惯性微分对高频噪声的不同影响
  • 中间结果：惯性环节抑制高频，微分作用仍可提供超前
  • 卡点：只写微分超前作用，漏答高频噪声抑制
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过说明工程中用带惯性环节的微分代替纯微分的原因
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求

2减小或消除稳态误差的方法#

思路
  • 按误差来源分为型别不足与增益不足，分别给出措施
减小稳态误差的措施 稳态误差
本卷考法
  • 归纳减小或消除控制系统稳态误差的常用措施
本卷实例
  • 关键一步：先判断误差由型别不足还是开环增益不足引起
  • 中间结果：提高开环增益、增加积分环节或加入顺馈补偿
  • 卡点：只提高增益而不校验稳定性是否被破坏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过归纳减小或消除控制系统稳态误差的常用措施
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

3滞后校正装置的特点与作用#

思路
  • 从幅值衰减压低中频、降低截止频率这一机理说明
滞后校正 系统校正
本卷考法
  • 说明滞后校正装置的特点、作用及适用系统
本卷实例
  • 关键一步：抓住高频幅值衰减压低中频段这一核心特征
  • 中间结果：降低截止频率以挖掘系统自身相角储备
  • 卡点：未说明适用对象是截止频率足够大而相角裕度不足
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过说明滞后校正装置的特点、作用及适用系统
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

4最小相位系统奈氏判据判稳#

思路
  • 先由最小相位确定开环右半平面极点数，再数包围圈
奈奎斯特判据 稳定性分析
本卷考法
  • 由最小相位系统的开环幅相曲线判断闭环稳定性
本卷实例
  • 关键一步：先由最小相位条件确定开环右半平面极点数
  • 中间结果：按曲线对临界点的包围方向与圈数代入判据
  • 卡点：开环含积分环节时未补画无穷大半径圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由最小相位系统的开环幅相曲线判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
最小相位系统与非最小相位系统 频域分析
本卷考法
  • 说明最小相位条件在判稳中所起的作用
本卷实例
  • 关键一步：由最小相位条件直接取开环右半平面极点数
  • 中间结果：频率曲线形状与极零点分布一一对应
  • 卡点：把最小相位误当成开环极点都在左半平面
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过说明最小相位条件在判稳中所起的作用
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈

5状态完全能控的条件#

思路
  • 由状态方程构造能控性判别矩阵，按满秩条件求参数
能控性与能观性 状态空间分析
本卷考法
  • 由状态方程判别系统的完全能控性
本卷实例
  • 关键一步：构造能控性判别矩阵并考察其秩
  • 中间结果：判别矩阵满秩等价于系统完全能控
  • 卡点：把能控性矩阵与能观性矩阵的构造方式弄混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过由状态方程判别系统的完全能控性
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

6稳定性的定义#

思路
  • 从受扰后能否回到平衡状态给出稳定性定义
劳斯判据 稳定性分析
本卷考法
  • 给出控制系统稳定性的定义并说明其意义
本卷实例
  • 关键一步：以受扰后输出能否复原到平衡状态为判据
  • 中间结果：线性定常系统稳定对应闭环极点均在左半平面
  • 卡点：只写输出有界，未说明是否回到原平衡状态
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过给出控制系统稳定性的定义并说明其意义
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式

7由阶跃响应z变换求采样值#

思路
  • 把闭环脉冲传函乘阶跃输入z变换后展开成幂级数
z 变换与 z 反变换 离散控制系统
本卷考法
  • 由输出响应的 z 变换求各采样时刻的值
本卷实例
  • 关键一步：先由 C(z) 与 R(z) 之比得到脉冲传函
  • 中间结果：用长除或反变换展开成 z 的幂级数
  • 卡点：长除次序颠倒导致采样时刻与系数错位
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • z 变换是离散信号的拉氏变换，令 z=e^{Ts} 得到
  • 常用函数的 z 变换要熟记
  • z 反变换可用部分分式法、幂级数法或留数法
  • 左半 s 平面映射到 z 平面单位圆内
步骤
  • 将连续传递函数展开为部分分式
  • 逐项查表做 z 变换
  • 需要时做 z 反变换求时间序列
通用考法
  • 本卷考过由输出响应的 z 变换求各采样时刻的值
  • 求给定函数的 z 变换
  • 求 z 反变换得到采样序列
  • 说明 s 平面与 z 平面的映射关系
常见易错
  • 把 z 变换结果中的 e^{-aT} 写成 e^{-a}
  • 部分分式分解时漏项导致反变换出错
公式

8由输出响应辨识闭环极点#

思路
  • 把输出响应的指数项与振荡项对应到闭环极点
零极点分布与响应模态 传递函数
本卷考法
  • 由输出响应的组成反推闭环系统的极点
本卷实例
  • 关键一步：把指数衰减项与正弦振荡项分别对应实极点与复极点
  • 中间结果：振荡项的衰减快慢由复极点实部决定
  • 卡点：只看振荡频率，漏掉复极点的实部信息
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由输出响应的组成反推闭环系统的极点
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

9结构图求闭环传递函数#

思路
  • 按结构图化简规则合并串联、并联与反馈支路
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构框图求闭环传递函数 C(s)/R(s)
本卷实例
  • 关键一步：先合并局部反馈回路，再逐层向输入端化简
  • 中间结果：反馈支路分母出现一加或一减回路增益
  • 卡点：比较点与引出点移动时乘除关系取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由结构框图求闭环传递函数 C(s)/R(s)
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式校验结构图化简结果
本卷实例
  • 关键一步：数清前向通路与各回路，写出特征式
  • 中间结果：不接触回路在特征式中单独成项
  • 卡点：余子式中未剔除与前向通路接触的回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式校验结构图化简结果
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式

10由输入输出求传函与脉冲响应#

思路
  • 由输入与输出响应分别取拉氏变换，按定义求传函
由响应曲线反求传递函数 传递函数
本卷考法
  • 由已知输入输出响应反求系统传递函数与脉冲响应
本卷实例
  • 关键一步：分别对输入与输出取拉氏变换，再作比值
  • 中间结果：传递函数的拉氏反变换即单位脉冲响应
  • 卡点：漏写输入的拉氏变换，直接把输出当传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出

  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由理想运放电路求调节器的传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
