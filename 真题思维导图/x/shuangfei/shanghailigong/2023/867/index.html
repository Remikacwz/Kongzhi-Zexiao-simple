一1、一2反馈控制基本概念填空#

思路
  • 填空：前向通路与反馈通路的定义；自动控制系统按控制方式的分类
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 填出前向通路与反馈通路的定义
  • 填出自动控制系统按控制方式的分类
本卷实例
  • 关键一步：从输入端沿箭头方向到输出端的通路叫前向通路
  • 关键一步：输出量经测量元件回到输入端的通路叫反馈通路
  • 关键一步：按控制方式分为开环、闭环、复合控制
  • 中间结果：通路名称要与信号流向一致，别把两条说反
  • 卡点：把前向通路与反馈通路说反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过填出前向通路与反馈通路的定义
  • 本卷考过填出自动控制系统按控制方式的分类
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

一3系统型别与静态误差系数填空#

思路

系统型别与静态误差系数 稳态误差
本卷考法
  • 判断系统型别并求静态速度误差系数 Kv
本卷实例
  • 关键一步：分母中纯积分环节的个数说明系统型别
  • 关键一步：Kv=lim(s→0) sG(s)
  • 中间结果：答案段按 Ⅰ 型系统处理，说明开环含一个纯积分环节
  • 卡点：把开环增益直接当成 Kv
  • 卡点：源文 G(s) 分子 OCR 疑为 s，型别与 Kv 要回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤

通用考法

  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错

一4由微分方程写传函与幅频特性#

思路
  • 由二阶微分方程在零初始条件下写传递函数，再由传函写频率特性与幅频特性
传递函数的定义与基本性质 传递函数
本卷考法
  • 由二阶微分方程在零初始条件下写传递函数
本卷实例
  • 关键一步：两边取拉氏变换，初始条件全部置零
  • 关键一步：按输出比输入整理成降幂有理分式
  • 中间结果：分母为 T1T2s²+(2T1+T2)s+2，分子为 1
  • 卡点：漏掉零初始条件这一前提
  • 卡点：分子分母系数按升幂抄写
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由二阶微分方程在零初始条件下写传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由传递函数写频率特性与幅频特性
本卷实例
  • 关键一步：令 s=jω 得 G(jω)
  • 关键一步：分母复数取模得幅频 A(ω)
  • 关键一步：分子相角减分母相角得相频
  • 中间结果：A(ω)=1/√[(2-T1T2ω²)²+((2T1+T2)ω)²]
  • 卡点：求幅值时没把分母复数取模
  • 卡点：整理分母实部虚部时符号弄错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由传递函数写频率特性与幅频特性
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式

  • 填出状态反馈与输出反馈可任意配置极点的充要条件
本卷实例

  • 关键一步：输出反馈任意配置极点则要求系统完全能控且完全能观
  • 中间结果：两条条件一宽一严，输出反馈多了能观这一要求

能控性与能观性 状态空间分析
本卷考法
  • 填出非奇异线性变换下能控性、能观性的不变性
本卷实例
  • 关键一步：非奇异线性变换下系统的能控性、能观性保持不变
  • 中间结果：秩判据在相似变换下不变，这是坐标变换的前提
  • 卡点：误以为坐标变换会改变能控能观性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过填出非奇异线性变换下能控性、能观性的不变性

二1大范围与小范围稳定性简答#

思路
  • 简答：什么是大范围渐近稳定，什么是小范围稳定
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 阐释大范围渐近稳定与小范围稳定的含义
本卷实例
  • 关键一步：大范围渐近稳定：任意初态都能收敛到唯一平衡点
  • 关键一步：小范围稳定：只在平衡点某个小邻域内的初态才稳定
  • 中间结果：两者的差别在初态允许的范围，而非平衡点本身
  • 卡点：把大范围稳定误说成局部结论
  • 卡点：把稳定与渐近稳定混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过阐释大范围渐近稳定与小范围稳定的含义
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

二2根轨迹与零度/180度区别#

思路
  • 简答：根轨迹的定义；零度根轨迹与 180° 根轨迹的区别
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 答出根轨迹的定义
本卷实例
  • 关键一步：根轨迹是某参数从 0 变到 +∞ 时闭环特征根在 s 平面的移动轨迹
  • 关键一步：根轨迹依据开环传函 G(s)H(s) 绘制
  • 中间结果：定义要抓住「闭环特征根」与「参数变化」两点
  • 卡点：写成开环极点的轨迹
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过答出根轨迹的定义
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 说明零度根轨迹与 180° 根轨迹的区别
本卷实例
  • 关键一步：零度根轨迹的相角条件为 0°+360°l，180° 根轨迹为 180°+360°l
  • 关键一步：实轴段判据：零度看右侧零极点数为偶数，180° 看奇数
  • 关键一步：渐近线夹角公式也由 2k 与 2k+1 区分
  • 中间结果：正反馈或参数根轨迹常引出零度根轨迹
  • 卡点：零度根轨迹仍用 180° 相角条件
  • 卡点：渐近线夹角公式用错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过说明零度根轨迹与 180° 根轨迹的区别
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

二3奈氏稳定判据简答#

思路
  • 简答：简述奈氏稳定判据
奈奎斯特判据 稳定性分析
本卷考法
  • 简述奈氏稳定判据
本卷实例
  • 关键一步：闭环稳定要求半闭合曲线不穿过 (-1,j0) 点
  • 关键一步：且逆时针包围该点的圈数等于开环右半平面极点数 P
  • 关键一步：即 Z=P-R=0
  • 中间结果：须先数 P，再补画积分环节对应的无穷大圆弧
  • 卡点：开环含积分环节时忘记补画圆弧
  • 卡点：把包围圈数的符号约定用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
