一一、结构图求传递函数16 分#

思路
  • 由结构图列回路与前向通路，用梅森公式求 C(s)/R(s)，也可用多回路逐层化简核对
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图用梅森公式求 C(s)/R(s)
本卷实例
  • 关键一步：列全部独立回路与前向通路及余子式
  • 中间结果：特征式等于 1 减回路增益之和
  • 卡点：结构图以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图用梅森公式求 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过互不接触回路漏算或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 用多回路逐层化简核对梅森结果
本卷实例
  • 关键一步：从最内层回路向外逐层等效
  • 中间结果：内环化成 G/(1+GH) 再参与外层
  • 卡点：比较点与引出点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法

  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过化简内环时把外环信号当常数
  • 化简内环时把外环的信号当成常数处理

二二、控制器参数稳定域与阶跃响应20 分#

思路
  • 由特征方程列劳斯表求 Ka 稳定范围，再判单位阶跃稳态误差能否为零，最后求 Ka=2 时的单位阶跃响应
劳斯判据 稳定性分析
本卷考法
  • 求使闭环系统稳定的 Ka 范围
本卷实例
  • 关键一步：列劳斯表并令第一列各元素大于零
  • 中间结果：由两条不等式交集得 Ka 范围
  • 卡点：Ka>0 的条件由题面限定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过求使闭环系统稳定的 Ka 范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过首列出现零仍按常规继续算
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 判断能否使单位阶跃稳态误差为零
本卷实例
  • 关键一步：先写静态位置误差系数表达式
  • 中间结果：由闭环误差传函判断能否取到零误差
  • 卡点：开环传函含右半平面零点，注意符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过判断能否使单位阶跃稳态误差为零
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过未先判稳就谈稳态误差
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由闭环传函求单位阶跃响应
本卷实例
  • 关键一步：对闭环输出作拉氏反变换
  • 中间结果：部分分式分解后逐项反变换
  • 卡点：借位：本题按线性系统时域求解处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由闭环传函求单位阶跃响应
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 本卷考过只求零状态响应漏掉初值影响
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

三三、根轨迹与振荡及阻尼比22 分#

思路
  • 由开环传函画概略根轨迹，求分离点、虚轴交点，确定产生振荡的 K 范围和指定阻尼比下的 K
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制 K 增大时的概略根轨迹
本卷实例
  • 关键一步：标开环零极点并确定实轴根轨迹段
  • 中间结果：按 n-m 求渐近线交点与夹角
  • 卡点：根轨迹图以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制 K 增大时的概略根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过渐近线夹角中的 2k+1 写成 2k
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

四四、Bode 图反求传函与裕度22 分#

思路
  • 由最小相位系统对数幅频渐近线反求开环传函，再算截止频率、相角裕度并判闭环稳定性
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由 Bode 图反求开环传递函数
本卷实例
  • 关键一步：由低频段斜率定型别、高度定增益
  • 中间结果：按转折频率写出各一阶或二阶环节
  • 卡点：Bode 图以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由 Bode 图反求开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 本卷考过把延长线交点误当增益未折算型别
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

稳定裕度 频域分析
本卷考法
  • 计算截止频率与相角裕度并判稳
本卷实例
  • 关键一步：由幅值条件求截止频率
  • 中间结果：相角裕度等于 180 度加截止频率处相角
  • 卡点：相角裕度为正才判闭环稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过计算截止频率与相角裕度并判稳
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过把 ωc 与 ωg 两个频率用反
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

五五、采样系统稳定性与输出20 分#

思路
  • 由采样器与零阶保持器求脉冲传函，判闭环稳定性并求稳定采样周期范围，再算单位阶跃下的输出 C(z)
离散系统稳定性分析 离散控制系统
本卷考法
  • 判断采样系统稳定性并求稳定采样周期范围
本卷实例
  • 关键一步：求闭环特征根并令其落在单位圆内
  • 中间结果：由 |z|<1 解出采样周期或增益范围
  • 卡点：z 变换结果随 T 变化，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
