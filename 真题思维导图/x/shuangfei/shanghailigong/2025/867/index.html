1、2、3基本概念填空（控制方式·传递函数·型别）#

思路

校正的基本概念与性能指标 系统校正
本卷考法
  • 写出自动控制系统的基本控制方式
本卷实例
  • 关键一步：按有无反馈分：开环控制、闭环（反馈）控制；另有复合控制
  • 关键一步：若题目问的是「按给定信号」分类则是恒值/随动/程序控制——要看题干问的是哪种口径
  • 中间结果：按有无反馈口径：开环、闭环（反馈）、复合共三类
  • 中间结果：若按给定信号口径：恒值、随动、程序共三类
  • 卡点：把「按信号类型分类」与「按有无反馈分类」混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过写出自动控制系统的基本控制方式
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求

传递函数的定义与基本性质 传递函数
本卷考法
  • 填出传递函数概念只适用于什么系统、仅与系统的什么有关
本卷实例
  • 关键一步：只适用于线性定常系统（更严格地说是零初始条件下的线性定常系统）
  • 关键一步：仅与系统本身的结构与参数有关，与输入信号的形式和大小无关
  • 中间结果：三个空依次落在「适用系统」「结构」「参数」上
  • 中间结果：适用系统限定为线性定常，影响因素归为结构与参数
  • 卡点：漏掉「线性」只说「定常」；或把「结构与参数」写成「输入与输出」
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过填出传递函数概念只适用于什么系统、仅与系统的什么有关
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

系统型别与静态误差系数 稳态误差
本卷考法
  • 由 G(s)=10/(s(2s+1)(s+4)) 判断型别并求 Kp、Kv、Ka
本卷实例
  • 关键一步：分母里 s 的幂次即积分环节个数 → v=1，为 Ⅰ 型系统
  • 关键一步：Kp=lim(s→0)G(s)=∞，Ka=lim(s→0)s²G(s)=0
  • 关键一步：Kv=lim(s→0)sG(s)=10/4=2.5
  • 中间结果：Kv=10/(1×4)=2.5，注意分母两个惯性环节在 s→0 时都趋于 1
  • 卡点：把开环增益 10 直接当成 Kv
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由 G(s)=10/(s(2s+1)(s+4)) 判断型别并求 Kp、Kv、Ka
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

4、5、6、7主导极点·根轨迹·频率特性概念#

思路
  • 四道填空：主导极点的判定、根轨迹的定义、渐近线条数与角度、幅频相频表达式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 填出主导极点的判定条件
本卷实例
  • 关键一步：标准答案：「距离虚轴最近，且其附近没有零点」的极点起主导作用
  • 关键一步：「附近没有零点」这一条最容易漏——零点会把该极点的影响削弱甚至抵消
  • 中间结果：判定要同时满足：离虚轴最近、附近没有零点
  • 中间结果：零点会削弱甚至抵消该极点的作用，故必须加这条限定
  • 卡点：只写「离虚轴最近」而漏掉「附近没有零点」
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过填出主导极点的判定条件
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 填出根轨迹的定义
本卷实例
  • 关键一步：当系统中某一参数从 0→+∞ 变化时，闭环特征根在 s 平面上移动的轨迹
  • 关键一步：关键词是「闭环特征根」而不是「开环极点」
  • 中间结果：定义抓住两点：参数从 0 变到 +∞、对象是闭环特征根
  • 中间结果：根轨迹画的是闭环极点随参数变化的路径
  • 卡点：写成「开环极点的轨迹」
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过填出根轨迹的定义
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 由开环极点 4 个、零点 2 个求渐近线条数与与实轴夹角
本卷实例
  • 关键一步：渐近线条数 = n−m = 4−2 = 2 条
  • 关键一步：夹角 φa=(2k+1)×180°/(n−m)，取 k=0,1
  • 关键一步：两条渐近线夹角为 90° 与 270°（即 ±90°）
  • 中间结果：n−m=2 → 夹角为 ±90°，两条渐近线垂直于实轴
  • 卡点：把 2k+1 写成 2k；或忘记 n−m 才是条数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过由开环极点 4 个、零点 2 个求渐近线条数与与实轴夹角
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 写出 G(s)=(2s+1)/(s(s+1)) 的幅频与相频特性表达式
本卷实例
  • 关键一步：令 s=jω 代入，分子分母分别取模得幅频，分子相角减分母相角得相频
  • 关键一步：幅频 |G(jω)|=√(4ω²+1)/(ω·√(ω²+1))
  • 关键一步：相频 ∠G=arctan(2ω) − 90° − arctan(ω)
  • 中间结果：分母的 s 贡献 −90°，两个一阶环节各贡献 −arctan
  • 卡点：求幅值时把分子分母的实数部分直接相除，没有先取模
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过写出 G(s)=(2s+1)/(s(s+1)) 的幅频与相频特性表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

校正的基本概念与性能指标 系统校正
本卷考法
  • 填出常用的校正方式
本卷实例
  • 关键一步：题目给出「……和复合校正 4 种」→ 前三种是串联校正、反馈校正（并联校正）、前馈校正
  • 关键一步：「复合校正」= 反馈 + 前馈的组合
  • 中间结果：题干已写明「和复合校正 4 种」，前三个空填三种基本校正
  • 中间结果：基本校正：串联、反馈（并联）、前馈
  • 卡点：只答串联、反馈两种，凑不满 4 种

稳定裕度 频域分析
本卷考法
  • 阐释相角裕度与幅值裕度的含义
本卷实例
  • 关键一步：相角裕度：在幅值穿越频率 ωc 处，使系统达到临界稳定还需增加的附加相位滞后量
  • 关键一步：幅值裕度：在相位穿越频率 ωg 处，系统达到临界稳定还可增加的增益倍数
  • 中间结果：相角裕度在幅值穿越频率 ωc 处定义
  • 中间结果：幅值裕度在相位穿越频率 ωg 处定义，两个频率要对号入座
  • 中间结果：两者都表示离临界稳定还差多少余量
  • 卡点：只说公式不给物理含义；题目问的是「含义」
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过阐释相角裕度与幅值裕度的含义
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

滞后校正 系统校正
本卷考法
  • 阐述无源滞后校正装置的特点、串联校正时的作用及不足之处
本卷实例
  • 关键一步：特点：高频段幅值衰减、低频段增益不变；本身带来相位滞后
  • 关键一步：作用：利用高频衰减把截止频率往左移，从而提高相角裕度；同时提高低频增益改善稳态精度
  • 关键一步：不足：截止频率降低 → 响应速度变慢；若转折频率取得过高，相位滞后会抵消增益带来的好处
  • 中间结果：转折频率要远低于新的截止频率（一般取新 ωc 的 0.1~0.2 倍）
  • 卡点：只说优点不说「响应变慢」这个主要代价
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过阐述无源滞后校正装置的特点、串联校正时的作用及不足之处
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

14、15梅森公式与劳斯判据#

思路
  • 第 14 题用梅森公式求信号流图传函；第 15 题由特征方程 s⁴+2s³+ks²+10s+100=0 求稳定 k 范围
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求信号流图的传递函数 Y(s)/R(s)
本卷实例
  • 关键一步：先求特征式 Δ=1−ΣL+ΣLL−…（注意找互不接触回路）
  • 关键一步：再逐条找前向通路 P_k 与余子式 Δ_k，代入 P=ΣP_kΔ_k/Δ
  • 中间结果：Δ 的符号随回路个数交替：1−ΣL+ΣLL−…
  • 中间结果：每个前向通路 Pk 的余子式 Δk 要删去与它接触的回路
  • 卡点：余子式中未剔除与前向通路接触的回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求信号流图的传递函数 Y(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

劳斯判据 稳定性分析
本卷考法
  • 由特征方程求使系统稳定的 k 取值范围
本卷实例
  • 关键一步：对 s⁴+2s³+ks²+10s+100=0 列完整劳斯表，逐行算到 s⁰
  • 关键一步：令首列各元素全部大于零，解不等式组取交集
  • 中间结果：s³ 行首列为 2；s² 行首列为 (2k−10)/2 = k−5
  • 中间结果：该行首列大于零即给出 k>5 的下界
  • 中间结果：s¹ 行首列含 k 的一次分式，这一项通常给出上界
  • 卡点：只算到 s² 行就下结论；s¹ 行首列的分母里含 k，还要额外要求它不为零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由特征方程求使系统稳定的 k 取值范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

16阻尼状态与幅相曲线判稳#

思路
  • 前半问给定二阶模型 M 求阻尼比、自然振荡频率与三种阻尼状态的判据；后半问由两条幅相曲线与 P、v 判断闭环稳定性
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由二阶模型写出阻尼比与自然振荡频率，并说明欠阻尼/临界阻尼/过阻尼的判据
本卷实例
  • 关键一步：由标准式 s²+2ξωn s+ωn² 直接读出 ωn 与 ξ
  • 关键一步：判据：0<ξ<1 欠阻尼、ξ=1 临界阻尼、ξ>1 过阻尼（ξ=0 无阻尼）
  • 中间结果：把闭环传函与 s²+2ξωn s+ωn² 对照，读 ωn² 与 2ξωn
  • 中间结果：ξ 与 1 的大小关系分三段：欠阻尼、临界、过阻尼
  • 卡点：把临界阻尼与过阻尼的响应特点说反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由二阶模型写出阻尼比与自然振荡频率，并说明欠阻尼/临界阻尼/过阻尼的判据
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

奈奎斯特判据 稳定性分析
本卷考法
  • 由幅相曲线、开环右半平面极点数 P 与积分环节数 v 分析闭环稳定性
本卷实例
  • 关键一步：v 的作用是提示要补画无穷大半径圆弧，补画后曲线才闭合
  • 关键一步：闭环稳定判据 Z=N+P：P 是开环右半平面极点数
  • 关键一步：N 是补画后曲线绕 (−1,j0) 的净包围圈数，题已给 P
  • 关键一步：两条曲线分别数 N 再算 Z，比较 Z 是否为零
  • 中间结果：逆时针包围为负、顺时针为正（或按题目采用的符号约定）——先确认符号约定再数
  • 卡点：看到 v≥1 就忘记补无穷大圆弧；或符号约定用反导致结论整体反掉
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由幅相曲线、开环右半平面极点数 P 与积分环节数 v 分析闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

17可控标准型与状态变量图#

思路
  • G(s)=(3s−8)/(2s³+10s²+15s+2)，先化成首一分母，再写能控（可控）标准型并画状态变量图
由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 由传递函数写出可控标准型状态空间表达式并绘制状态变量图
本卷实例
  • 关键一步：先把分母首项系数 2 归一化：G(s)=(1.5s−4)/(s³+5s²+7.5s+1)
  • 关键一步：能控标准型 A 为友矩阵，末行是分母系数的相反数
  • 关键一步：B=[0,0,1]ᵀ，C 为分子系数按次幂排列
  • 关键一步：状态变量图按「n 个积分器串联 + 反馈系数 + 前馈系数」画
  • 中间结果：分母归一化后：s³+5s²+7.5s+1；分子归一化后：1.5s−4
  • 中间结果：分子阶数 1 < 分母阶数 3 → 真分式，D=0
  • 卡点：忘记先把分母首项系数归一化，友矩阵末行系数全错
  • 卡点：分子系数要从高次到低次对应 C 阵，不能按升幂写
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法
  • 本卷考过由传递函数写出可控标准型状态空间表达式并绘制状态变量图
  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反

18李雅普诺夫法判稳#

思路
  • 方程组 ẋ₁=−x₁+2x₂、ẋ₂=−2x₂，用李雅普诺夫方法判断稳定性
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 用李雅普诺夫方法判断给定系统的稳定性
本卷实例
  • 关键一步：该方程已是线性定常形式 ẋ=Ax，A=[[−1,2],[0,−2]] → 可直接看特征值
  • 关键一步：λ₁=−1、λ₂=−2 全在左半平面 → 系统渐近稳定，且是大范围渐近稳定
  • 关键一步：若要按李雅普诺夫方程做：取 Q=I，解 AᵀP+PA=−Q，验证 P 正定
  • 中间结果：A 是上三角矩阵 → 特征值直接读对角线 −1 与 −2
  • 卡点：构造 V(x)=x₁²+x₂² 后直接说 V̇<0，却没真算导数
  • 卡点：本题这个 V̇ 对该 V 并非恒负定，结论要再核
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过用李雅普诺夫方法判断给定系统的稳定性
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数
