一1、一2、一4基本概念填空（控制方式·连接·输入信号）#

思路
  • 填空：三种控制方式、结构图三种基本连接方式、常用的四种单位输入信号
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 填出自动控制系统的三种控制方式
本卷实例
  • 关键一步：按有无反馈分：开环控制、闭环控制、复合控制
  • 中间结果：复合控制等于反馈控制与按扰动控制相结合
  • 卡点：把按给定信号分类的恒值、随动、程序误答进去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过填出自动控制系统的三种控制方式
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 填出结构图的三种基本连接方式
本卷实例
  • 关键一步：串联、并联、反馈连接三种
  • 中间结果：串联相乘、并联相加、反馈按 G/(1±GH) 等效
  • 卡点：把三种连接方式写成开环、闭环、复合
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过填出结构图的三种基本连接方式
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

典型输入信号 基本概念与信号
本卷考法
  • 填出常用的四种单位输入信号
本卷实例
  • 关键一步：单位阶跃、单位斜坡、单位脉冲、单位加速度（抛物线）
  • 中间结果：四类输入分别用于考查动态性能与稳态精度
  • 卡点：把斜坡与加速度信号的阶次写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 常用典型输入有冲激、阶跃、斜坡、抛物线（加速度）与正弦五类
  • 阶跃信号用于考查快速性与稳定性，斜坡与抛物线用于考查稳态精度
  • 正弦信号用于频域分析，冲激响应就是系统的传递函数
  • 各典型信号的拉氏变换是分析全响应的起点

  • 对输入取拉氏变换得到该信号的复域形式
  • 由输入类型判断考查的是动态性能还是稳态精度
  • 把输入代入误差或响应公式计算
通用考法
  • 本卷考过填出常用的四种单位输入信号
  • 写出典型输入信号的拉氏变换
  • 说明某一典型输入信号用于考查哪类性能
  • 由输入类型判断稳态误差是否为有限值
常见易错
  • 把斜坡与抛物线信号的阶次写错
  • 阶跃的拉氏变换漏掉系数（幅度不为 1 时）

一3、一5、一6、一7数学模型与频域填空#

思路
  • 填空：无阻尼响应特点、单位负反馈三种传函、最小相位系统定义、一阶积分加惯性环节的幅频相频
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 填出 ζ=0 时二阶系统单位阶跃响应的特点
本卷实例
  • 关键一步：ζ=0 时特征方程有一对纯虚根
  • 关键一步：响应为等幅振荡，即无阻尼情形
  • 中间结果：无阻尼时振荡频率等于自然频率 ωn
  • 卡点：把等幅振荡与衰减振荡说反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过填出 ζ=0 时二阶系统单位阶跃响应的特点
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 由前向通道 G(s) 写单位负反馈的开环、闭环与误差传函
本卷实例
  • 关键一步：开环传函即 G(s)
  • 关键一步：闭环传函为 G/(1+G)
  • 关键一步：误差传函为 1/(1+G)
  • 中间结果：单位负反馈时误差取在输入端，E/R=1/(1+G)
  • 卡点：把闭环传函写成 G/(1-G)
  • 卡点：误差传函写成 G/(1+G)
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由前向通道 G(s) 写单位负反馈的开环、闭环与误差传函
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
最小相位系统与非最小相位系统 频域分析
本卷考法
  • 填出最小相位系统的定义
本卷实例
  • 关键一步：最小相位系统的全部零点和极点都位于左半平面
  • 中间结果：同类系统中最小相位系统的相位滞后最小
  • 卡点：只说零点在左半平面而漏掉极点
  • 卡点：把右半平面极点与右半平面零点混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过填出最小相位系统的定义
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈
频率特性的物理意义与求法 频域分析
本卷考法
  • 由 G(s)=1/[s(Ts+1)] 写幅频与相频特性
本卷实例
  • 关键一步：令 s=jω 代入，分母取模得幅频
  • 关键一步：分子相角减分母相角得相频
  • 中间结果：A(ω)=1/[ω√((Tω)²+1)]，φ(ω)=-90°-arctan(Tω)
  • 卡点：求幅值时没把分母复数取模
  • 卡点：漏掉积分环节的 -90°
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由 G(s)=1/[s(Ts+1)] 写幅频与相频特性
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式

思路

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 写出二阶系统标准形式及其两个结构参数
本卷实例

  • 关键一步：结构参数为阻尼比 ξ 与自然频率 ωn
  • 中间结果：ξ 决定超调与响应类型，ωn 决定时间尺度
  • 卡点：化为标准形式时忘记把 s² 项系数归一化

  • 按 ξ 的取值判断响应类型
通用考法

  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 写出欠阻尼二阶系统各动态性能指标的计算公式
本卷实例
  • 关键一步：σ%=e^(-πξ/√(1-ξ²))×100%
  • 关键一步：tp=π/(ωn√(1-ξ²))
  • 关键一步：ts≈3.5/(ξωn)（5% 带）或 4.4/(ξωn)（2% 带）
  • 中间结果：超调量只由 ξ 决定，各时间指标与 ωn 成反比
  • 卡点：把两种误差带的调节时间系数搞混

  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子

  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过写出欠阻尼二阶系统各动态性能指标的计算公式
  • 给定 ξ 与 ωn 求全部动态性能指标

  • 分析 ωn 变化时各指标如何变化

  • 峰值时间与上升时间混用

二4三种数学模型及转换关系#

思路
  • 简答：常用三种数学模型（微分方程、传递函数、频率特性）及它们之间的转换关系
传递函数的定义与基本性质 传递函数
本卷考法
  • 答出常用三种数学模型并写它们之间的转换关系
本卷实例
  • 关键一步：三种模型为微分方程、传递函数、频率特性
  • 关键一步：微分方程在零初始下取拉氏变换得传递函数
  • 关键一步：传递函数令 s=jω 得频率特性
  • 中间结果：转换链为微分方程到传递函数再到频率特性
  • 卡点：漏掉零初始条件这一前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过答出常用三种数学模型并写它们之间的转换关系
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数

本卷实例

  • 关键一步：第二法取 V=x1²+½x2²，算 V̇ 并判其负定性
  • 关键一步：第一法求 A 的特征值，由实部符号判稳
