一1、一2、一3反馈控制与 PID 填空#

思路
  • 填空：反馈控制系统比较的量、复合控制的组成、PID 三项作用、改善二阶性能的常用方法
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 填出反馈控制系统所比较的量与复合控制的组成
本卷实例
  • 关键一步：反馈控制按偏差控制，被控量与给定值比较后得偏差
  • 关键一步：复合控制=反馈控制与按扰动控制相结合
  • 中间结果：第一空为「给定值」
  • 中间结果：复合控制的两路由按偏差控制与按扰动控制组成
  • 卡点：把被控量与给定值混用
  • 卡点：复合控制漏掉按扰动控制这一路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过填出反馈控制系统所比较的量与复合控制的组成
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
PID 控制器与参数整定 系统校正
本卷考法
  • 填出 PID 中 P、I、D 三项各自的作用
  • 填出改善二阶系统性能的两种常用方法
本卷实例
  • 关键一步：比例项 P 加快响应、提高调节精度
  • 关键一步：积分项 I 消除稳态误差
  • 关键一步：微分项 D 改善动态性能；PD 控制与测速反馈可改善二阶性能
  • 中间结果：三项作用对号：P 管快速性、I 管稳态精度、D 管动态性能
  • 卡点：把积分项说成加快响应
  • 卡点：把微分项与积分项的作用对调
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过填出 PID 中 P、I、D 三项各自的作用
  • 本卷考过填出改善二阶系统性能的两种常用方法
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

一4、一6二阶系统与动态性能填空#

思路
  • 填空：由阻尼比判断特征根形式与响应类型；欠阻尼二阶系统 tr、tp、σ% 的公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由 0<ξ<1 与 ξ=1 判断特征根形式和响应类型
本卷实例
  • 关键一步：0<ξ<1 时特征方程有一对负实部共轭复根，响应为欠阻尼振荡
  • 关键一步：ξ=1 时有两个相等负实根，响应为临界阻尼
  • 中间结果：按 ξ 与 1 的大小对号：欠阻尼、临界、过阻尼、无阻尼
  • 卡点：把临界阻尼与过阻尼的特征根形式说反
  • 卡点：漏掉「负实部」只写共轭复根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由 0<ξ<1 与 ξ=1 判断特征根形式和响应类型
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 写出欠阻尼二阶系统上升时间、峰值时间与超调量的公式
本卷实例
  • 关键一步：tr=(π-β)/(ωn√(1-ξ²))，β=arccosξ
  • 关键一步：tp=π/(ωn√(1-ξ²))
  • 关键一步：σ%=e^(-πξ/√(1-ξ²))×100%
  • 中间结果：三个公式都含 ωn√(1-ξ²)，即阻尼振荡频率 ωd
  • 卡点：峰值时间与上升时间公式混用
  • 卡点：超调量公式漏乘 100%
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过写出欠阻尼二阶系统上升时间、峰值时间与超调量的公式
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

一5极点配置与状态反馈条件填空#

思路
  • 填空：极点配置的含义，状态反馈与输出反馈可任意配置极点的充要条件
状态反馈与极点配置 状态空间分析
本卷考法
  • 填出状态反馈与输出反馈可任意配置极点的充要条件
本卷实例
  • 关键一步：状态反馈任意配置极点 ⇔ 被控系统完全能控
  • 关键一步：输出反馈任意配置极点 ⇔ 系统完全能控且完全能观
  • 中间结果：「极值配置」是 OCR 误写，应为「极点配置」，即把闭环极点移到希望位置
  • 卡点：把输出反馈的条件也写成只需能控
  • 卡点：漏掉能观这一条
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过填出状态反馈与输出反馈可任意配置极点的充要条件
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反

二1传递函数与零初始条件简答#

思路
  • 简答：微分方程转传递函数的条件限制，以及零初始状态两方面的含义
传递函数的定义与基本性质 传递函数
本卷考法
  • 答出微分方程转传递函数的条件限制与零初始状态的两方面含义
本卷实例
  • 关键一步：核心条件：系统线性、定常，且按零初始条件定义
  • 关键一步：零初始一是输入及其各阶导数在 t=0- 为零
  • 关键一步：零初始二是输出及其各阶导数在 t=0- 也为零
  • 中间结果：传递函数只由结构参数决定，与输入形式无关
  • 卡点：只答「线性」漏掉「零初始」
  • 卡点：把零初始只理解成输入为零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过答出微分方程转传递函数的条件限制与零初始状态的两方面含义
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式

二2、二4、二5频域概念（谐振·裕度·频段）#

思路
  • 简答：谐振现象与 Mr、ωr 公式；相角裕度与幅值裕度含义；开环频率特性各频段含义
闭环频率特性与性能指标 频域分析
本卷考法
  • 简述谐振现象、出现谐振的阻尼比范围，并写 Mr、ωr 公式
本卷实例
  • 关键一步：谐振是系统在特定频率下输出幅值达到极大的现象
  • 关键一步：出现谐振要求 0<ξ<0.707
  • 关键一步：Mr=1/(2ξ√(1-ξ²))，ωr=ωn√(1-2ξ²)
  • 中间结果：谐振频率低于自然频率 ωn，ξ 越小 Mr 越大
  • 卡点：把出现谐振的范围写成 0<ξ<1
  • 卡点：ξ 大于 0.707 时仍套用 Mr 公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过简述谐振现象、出现谐振的阻尼比范围，并写 Mr、ωr 公式
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈
公式
稳定裕度 频域分析
本卷考法
  • 阐释相角裕度与幅值裕度的含义
本卷实例
  • 关键一步：相角裕度：在幅值穿越频率 ωc 处再滞后多少度就到临界
  • 关键一步：幅值裕度：在相位穿越频率 ωg 处还能放大多少倍才到临界
  • 中间结果：相角裕度在 ωc 处定义，幅值裕度在 ωg 处定义，两个频率要对号
  • 卡点：只说公式不给物理含义，题目问的是含义
  • 卡点：把 ωc 与 ωg 用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过阐释相角裕度与幅值裕度的含义
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 说明开环频率特性低、中、高频段各自表征的含义（借 fd_03 的频率分段结论）
本卷实例
  • 关键一步：低频段表征稳态性能，由型别与开环增益决定
  • 关键一步：中频段表征动态性能，与 ξ、ωc 相关
  • 关键一步：高频段表征抗高频干扰能力
  • 中间结果：三段分别对应稳、快、抗噪三件事
  • 卡点：把中频段与高频段的表征说反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过说明开环频率特性低、中、高频段各自表征的含义（借 fd_03 的频率分段结论）
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

二3能控性与能观性含义简答#

思路
  • 简答：说明系统可控（能控）与可观测（能观）的含义
能控性与能观性 状态空间分析
本卷考法
  • 简述系统可控与可观测的含义
本卷实例
  • 关键一步：能控：存在输入能在有限时间内把任意初态驱动到原点
  • 关键一步：能观：能由输出在有限时间内唯一确定初始状态
  • 中间结果：两个概念都从状态方程出发，判据靠相应矩阵的秩
  • 卡点：把能控说成输出可跟随输入
  • 卡点：把能观说成状态能测到
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过简述系统可控与可观测的含义

三10LQR 最优控制#

思路
  • 由性能指标 J=∫(x2²+u²/4)dt 求最优控制 u*(t) 与最优性能指标
线性二次型最优控制 最优控制
本卷考法
  • 由二次型性能指标求最优控制 u*(t) 与最优性能指标
本卷实例
  • 关键一步：把性能指标配成标准二次型 xᵀQx+uᵀRu 的形式，定出 Q、R
  • 关键一步：解黎卡提代数方程取正定解 P
  • 关键一步：由 u*=-R⁻¹BᵀPx 得最优反馈，J*=½xᵀ(0)Px(0)
  • 中间结果：B=[1, 0]ᵀ，Q 只在 x2² 上有权重
  • 中间结果：黎卡提方程展开为三个代数方程联立
  • 卡点：黎卡提方程各项顺序写错导致 P 不对称
  • 卡点：取到非正定解而舍去正定解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 性能指标由状态量的二次型与控制量的二次型加权求和
  • 最优控制是状态的线性反馈，反馈阵由黎卡提方程的解给出
  • 加权阵对状态惩罚越重，闭环响应越快、控制量越大
  • 无限时间问题中黎卡提方程取稳态解
步骤
  • 写出性能指标与状态方程，确定加权阵
  • 写出黎卡提代数方程并列写矩阵元素方程
  • 解出正定的解阵，再由反馈公式得到最优反馈增益
  • 校验闭环稳定性与加权阵的对称正定性
通用考法
  • 本卷考过由二次型性能指标求最优控制 u*(t) 与最优性能指标
  • 由性能指标求最优控制律与闭环系统
  • 解黎卡提方程求反馈增益阵
  • 分析加权阵变化对响应快慢与控制量的影响
常见易错
  • 黎卡提方程里的项顺序写错，导致解阵不对称
  • 只找到解阵的非正定解而舍去正定解
