一一、传递函数定义与多输入总输出15 分#

思路
  • 先答传递函数定义，再分别求参考输入与扰动到输出的传递函数，叠加得系统总输出 C(s)
传递函数的定义与基本性质 传递函数
本卷考法
  • 简述传递函数的定义与适用前提
本卷实例
  • 关键一步：从零初始条件下的拉氏变换比定义
  • 中间结果：输入输出及各自各阶导数初值均为零
  • 卡点：概念题答全线性定常与零初始条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过简述传递函数的定义与适用前提
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过忽略零初始条件这一前提
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求 R(s) 与 N(s) 共同作用下的总输出 C(s)
本卷实例
  • 关键一步：分别令 N=0 与 R=0 求两路传函再叠加
  • 中间结果：总输出等于两路传函分别乘输入的叠加
  • 卡点：结构图以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求 R(s) 与 N(s) 共同作用下的总输出 C(s)
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 本卷考过求扰动传函时未把参考输入置零
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

本卷考法

本卷实例

  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项

通用考法

  • 由信号流图求 C(s)/R(s)

  • 把前向通路的增益写成了回路增益

二二、二阶系统参数、稳态误差与 β 影响22 分#

思路
  • 由闭环传函求 ζ 与 ωn；再求单位斜坡稳态误差；按 ζ=0.707 反求 β；最后分析 β 对稳定性与误差的影响
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函求阻尼比与自然频率
本卷实例
  • 关键一步：先写出闭环特征方程再与标准式比对
  • 中间结果：一次项系数对应 2ξωn、常数项对应 ωn²
  • 卡点：系统框图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过未把 s² 项系数归一化就比对标准式
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

本卷实例

  • 中间结果：误差传函乘输入拉氏变换后取终值
  • 卡点：题面部分公式 OCR 残缺，需回原卷核对

  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤

  • 求给定输入下的稳态误差

  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过未判稳就直接用终值定理
  • 未判稳就使用终值定理

劳斯判据 稳定性分析
本卷考法
  • 分析参数 β 对系统稳定性的影响
本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法

  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

思路

根轨迹的绘制法则 根轨迹法
本卷考法

本卷实例

要点

  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤

  • 计算渐近线交点与夹角

  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按步骤绘制 K 变化时的根轨迹
  • 按法则绘制根轨迹草图

思路
  • 分别用幅相曲线和对数渐近幅频特性判断非最小相位系统的闭环稳定性并说明理由
奈奎斯特判据 稳定性分析
本卷考法
  • 由幅相曲线判断非最小相位系统闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数 P
  • 中间结果：按 Z=P-2N 判右半平面闭环极点数
  • 卡点：幅相曲线以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由幅相曲线判断非最小相位系统闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错

  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
