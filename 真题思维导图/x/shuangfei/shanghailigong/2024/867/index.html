一1一1、系统基本要求（稳准快）#

思路
  • 填空：自动控制系统对被控量变化全过程提出的基本要求
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 填出控制系统稳、准、快三项基本要求
本卷实例
  • 关键一步：由被控量变化全过程这一提示定位到三项基本要求
  • 中间结果：按稳定性、准确性、快速性依次作答
  • 卡点：三者的顺序在答案段有固定写法，需照原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过填出控制系统稳、准、快三项基本要求
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把快速性与准确性两项要求混为一谈
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

  • 求使系统稳定的参数范围

  • 本卷考过把必要性当作充分性，只验证特征根实部符号
  • 系数有缺项时不补零，直接套用判据

一4一4、根轨迹分支数与渐近线#

思路
  • 填空：开环极点 n 个、零点 m 个且 n>m 时，根轨迹的分支数与渐近线条数

本卷考法
  • 填出根轨迹分支数与渐近线条数
本卷实例
  • 关键一步：由根轨迹起于开环极点这一法则定分支数
  • 中间结果：渐近线条数由极点与零点个数之差确定
  • 卡点：n>m 时分支数取 n 而不是 n 减 m
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过填出根轨迹分支数与渐近线条数
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过把渐近线条数写成极点数 n
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

二1二1、欠阻尼条件与动态指标#

思路
  • 简答：二阶系统处于欠阻尼的条件及该条件下上升时间、峰值时间、调节时间与超调量的公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 写出二阶系统处于欠阻尼状态时阻尼比的范围
本卷实例
  • 关键一步：由标准二阶系统阻尼比取值范围定欠阻尼
  • 中间结果：阻尼比介于零与一之间即为欠阻尼
  • 卡点：特征根为一对共轭复根时可从极点位置判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
