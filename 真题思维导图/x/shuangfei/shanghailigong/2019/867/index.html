自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 写出闭环控制系统的基本要求为稳、准、快
本卷实例
  • 关键一步：按稳、准、快三条主线归类各项要求
  • 中间结果：说明三条基本要求对应的性能含义
  • 卡点：填空编号(1)(2)(3)需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过写出闭环控制系统的基本要求为稳、准、快
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把快速性指标误当成准确性指标
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

  • 正弦信号用于频域分析，冲激响应就是系统的传递函数

常见易错

  • 把斜坡与抛物线信号的阶次写错
  • 阶跃的拉氏变换漏掉系数（幅度不为 1 时）

传递函数的定义与基本性质 传递函数
本卷考法
  • 写出经典控制系统的三种常用数学模型
本卷实例
  • 关键一步：按微分方程、传递函数、结构图三类归纳
  • 中间结果：说明三种模型之间的等价转换关系
  • 卡点：填空编号(12)~(14)需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过写出经典控制系统的三种常用数学模型
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过把结构图与信号流图重复计入
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

  • 卡点：题面条件仅一条填空，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 状态反馈不改变系统的零点

步骤

  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 写出根轨迹法所依据的开环与闭环传函
本卷实例
  • 关键一步：明确根轨迹由开环传函的零点极点绘制
  • 中间结果：写出相角条件与幅值条件
  • 卡点：填空编号(16)(17)需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过写出根轨迹法所依据的开环与闭环传函
  • 判断给定点是否在根轨迹上

  • 说明相角条件与幅值条件各自的作用
常见易错

  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

奈奎斯特判据 稳定性分析
本卷考法
  • 写出反馈系统稳定的充要条件与奈氏判据
本卷实例
  • 关键一步：由奈奎斯特曲线包围(-1,j0)的圈数判断
  • 中间结果：写出 Z=P-2N 中各项的含义
  • 卡点：填空编号(18)~(20)需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过写出反馈系统稳定的充要条件与奈氏判据
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过把包围圈数的正负号记反
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

频率特性的物理意义与求法 频域分析
本卷考法
  • 由开环传函求频率特性 G(jω)
本卷实例
  • 关键一步：令 s=jω 代入传递函数

  • 幅频特性表示各频率正弦输入下的幅值放大倍数

通用考法
