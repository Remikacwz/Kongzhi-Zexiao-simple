自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 写自动控制系统的基本要求与基本控制方式
本卷实例
  • 关键一步：按稳、准、快三条主线归纳基本要求
  • 中间结果：区分反馈、开环、复合三种控制方式
  • 卡点：填空均不印分值，仅 7 个小题编号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法

  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错

  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
劳斯判据 稳定性分析
本卷考法
  • 写线性系统稳定的充分必要条件
本卷实例

  • 中间结果：说明特征根实部与稳定性的对应

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤

  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过写线性系统稳定的充分必要条件

  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过把充要条件误写成只对开环成立
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分

通用考法

  • 说明微分项对噪声的影响
常见易错

  • 把 PI 的相位影响说成超前

稳定裕度 频域分析
本卷考法
  • 写幅值裕度 h 与相角裕度 γ 的含义
本卷实例
  • 关键一步：从临界稳定状态反推两裕度的定义
  • 中间结果：给出裕度与闭环稳定性的关系
  • 卡点：定义为文字表述，不依赖题图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过写幅值裕度 h 与相角裕度 γ 的含义
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过把再放大 h 倍与再滞后 γ 度的表述写反
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

二2二2、减小或消除稳态误差的措施#

思路
  • 从提高开环增益与增加积分环节两方面归纳减小或消除稳态误差的措施及其代价。
减小稳态误差的措施 稳态误差
本卷考法
  • 归纳减小或消除稳态误差的措施
本卷实例
  • 关键一步：分别从提高增益与增加积分环节入手
  • 中间结果：说明各措施对误差与稳定性的双重影响
  • 卡点：措施应与所给控制方式一并作答
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过归纳减小或消除稳态误差的措施
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 本卷考过只谈减小误差而不检查稳定性
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析

  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路

三2三2、持续振荡参数求解（同类题）#

思路

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由持续振荡条件确定系统的参数取值
本卷实例
  • 关键一步：令 s=jω 代入闭环特征方程
  • 中间结果：令实部与虚部分别为零得方程组
  • 卡点：本题系编者补的同类练习，非原卷真题
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由持续振荡条件确定系统的参数取值
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过把振荡频率当成闭环极点的实部
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

思路

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差

思路
  • 按静态速度误差系数定增益，选取滞后校正装置满足相角裕度并比较校正前后截止频率。
滞后校正 系统校正
本卷考法
  • 设计串联滞后校正满足 Kv 与相角裕度指标
本卷实例
  • 关键一步：按目标相角裕度确定校正后截止频率
  • 中间结果：由幅值条件求滞后环节的时间常数
  • 卡点：校正题系编者补充的同类练习
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过设计串联滞后校正满足 Kv 与相角裕度指标
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响

  • 本卷考过把滞后校正参数 b 当成大于 1
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
