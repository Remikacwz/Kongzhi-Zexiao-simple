一一、结构图求 C/R 与 C/N10 分#

思路
  • 由结构图分别求参考输入与扰动到输出的传递函数，用梅森公式列回路、前向通路与余子式
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图用梅森公式求 C(s)/R(s)
本卷实例
  • 关键一步：列独立回路与前向通路
  • 中间结果：特征式含回路增益与不接触回路乘积
  • 卡点：结构图以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图用梅森公式求 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过互不接触回路漏算或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

思路

误差定义与误差传递函数 稳态误差
本卷考法
  • 按定义 e(t)=r(t)-c(t) 写误差传函
本卷实例

  • 中间结果：写出 E(s) 与 R、N 的关系
  • 卡点：系统框图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意

步骤

  • 由结构图写出误差传递函数

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 选择 Kd 使输出与期望输入无稳态误差
本卷实例
  • 关键一步：令误差传函中斜坡相关项抵消
  • 中间结果：由总误差首项系数为零解出 Kd

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤

  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过选择 Kd 使输出与期望输入无稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过忽略扰动分量对总误差的贡献
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

三三、负反馈根轨迹与闭环传函20 分#

思路
  • 由开环传函画 K 从 0 到无穷的根轨迹，用劳斯表求稳定 K 范围，再由已知闭环极点反求 K 与闭环传函
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制 K 从 0 到无穷的根轨迹
本卷实例
  • 关键一步：标开环零极点并确定实轴根轨迹段
  • 中间结果：按 n-m 求渐近线交点与夹角
  • 卡点：根轨迹图以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制 K 从 0 到无穷的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过渐近线夹角中的 2k+1 写成 2k
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

思路

本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤

  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）

  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据判断系统稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错

  • 开环含有积分环节时未补画无穷大半径圆弧
