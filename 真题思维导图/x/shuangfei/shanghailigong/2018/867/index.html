一一、信号流图求多输入传函10 分#

思路
  • 由信号流图分别对两个输入求输出传函，用梅森公式列回路、前向通路与余子式。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图求 C(s)/R1(s) 的传函
  • 识别前向通路与两两不接触回路
本卷实例
  • 关键一步：标出全部独立回路与各条前向通路
  • 中间结果：写出特征式 Δ 及各通路的余子式
  • 卡点：信号流图以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图求 C(s)/R1(s) 的传函
  • 本卷考过识别前向通路与两两不接触回路
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过互不接触回路漏算或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求另一输入 R2(s) 单独作用下的传函
本卷实例
  • 关键一步：令 R1(s)=0，只保留 R2 的前向通路
  • 中间结果：按梅森公式写该通道的回路与余子式
  • 卡点：支路增益与节点连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求另一输入 R2(s) 单独作用下的传函
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 本卷考过求 R2 通道时未把 R1 置零
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

二二、二阶系统振荡与极点区域20 分#

思路
  • 由持续振荡条件代入纯虚根求参数；再作变量平移用劳斯判据求极点位置的参数约束。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由系统以给定频率持续振荡推断存在纯虚根
本卷实例
  • 关键一步：由持续振荡判定闭环存在一对纯虚根
  • 中间结果：实部与虚部分别为零得到两个方程
  • 卡点：题面三阶特征方程系数需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由系统以给定频率持续振荡推断存在纯虚根
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过把振荡频率误当成闭环极点的实部
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求极点全部位于 s=-1 左侧的参数范围
本卷实例
  • 关键一步：令 s=s1-1 把边界平移到虚轴
  • 中间结果：对平移后的特征方程列劳斯表
  • 卡点：平移后各阶系数需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求极点全部位于 s=-1 左侧的参数范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过未作变量平移就直接列劳斯表
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由劳斯表首列不等式确定参数稳定域
本卷实例
  • 关键一步：令劳斯表首列各项均大于零
  • 中间结果：取各不等式交集得到参数范围
  • 卡点：范围端点是否包含需回代验证
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由劳斯表首列不等式确定参数稳定域
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 本卷考过只取部分首列元素的不等式
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

三三、根轨迹绘制与反馈零点效应25 分#

思路
  • 按绘制法则画根轨迹并判稳；改变反馈通道引入零点后重画并分析稳定性变化。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 概略绘制增益变化时的闭环根轨迹
本卷实例
  • 关键一步：标开环零极点并定实轴上的根轨迹段
  • 中间结果：计算渐近线交点、夹角与分离点
  • 卡点：根轨迹草图以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过概略绘制增益变化时的闭环根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过渐近线夹角与实轴根轨迹段判断出错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴的交点及临界增益
本卷实例
  • 关键一步：令 s=jω 代入闭环特征方程
  • 中间结果：由实部虚部为零解出 ω 与临界增益
  • 卡点：特征方程系数受 OCR 影响，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴的交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 本卷考过只代入一组 ω 就下结论
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 反馈通道改为 H(s)=2s+1 后分析零点的影响
本卷实例
  • 关键一步：把 H(s) 并入开环写出等效传递函数
  • 中间结果：比较改动前后根轨迹在右半平面的走向
  • 卡点：反馈通道接法以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过反馈通道改为 H(s)=2s+1 后分析零点的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 本卷考过把附加开环零点当成附加极点
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反

四四、对数幅频反求传函与裕度25 分#

思路
  • 由渐近线斜率与转折频率写开环传函，求相角裕度判稳，再算斜坡输入下的稳态误差。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频渐近线反求开环传递函数
本卷实例
  • 关键一步：按低频段斜率确定积分环节个数与增益
  • 中间结果：逐个转折频率补入一阶或二阶环节
  • 卡点：渐近线图以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频渐近线反求开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 本卷考过转折频率处斜率变化量记错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 求相角裕度并据此判断闭环稳定性
本卷实例
  • 关键一步：由幅值条件先求截止频率
  • 中间结果：把截止频率代入相频表达式求裕度
  • 卡点：截止频率的近似取值需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求相角裕度并据此判断闭环稳定性
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过相频表达式遗漏某一环节的相角
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡输入作用下系统的稳态误差
本卷实例
  • 关键一步：确认闭环稳定后再用终值定理
  • 中间结果：由开环增益写出静态速度误差系数
  • 卡点：输入斜坡的系数以题面为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大

  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法

  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力

  • 未判稳就使用终值定理

  • Ⅰ型系统求阶跃误差时误代入速度误差公式

五五、采样系统脉冲传函与稳定20 分#

思路
  • 按采样开关位置分别求开环与闭环脉冲传函，再由特征根的模判定系统稳定性。
脉冲传递函数 离散控制系统
本卷考法
  • 求采样系统的开环与闭环脉冲传递函数
本卷实例
  • 关键一步：按采样开关位置划分各 z 变换单元
  • 中间结果：用部分分式展开后查表求 G(z)
  • 卡点：采样系统结构以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
