1一、自动调压系统有差与无差比较10 分#

思路
  • 对比两个调压系统的反馈通道：分析偏差信号是否参与励磁调节，判断系统属于有差还是无差，并据此说明带上负载后端电压能否保持不变。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法

本卷实例

  • 中间结果：判断偏差信号是否参与励磁电流调节
  • 卡点：两个调压系统以插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤

  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量

2二、二阶系统动态指标与初始条件全响应20 分#

思路
  • 由闭环传函求 ωn 与 ξ 并算超调量与调节时间；再在非零初值下对微分方程作拉氏变换，求单位阶跃全响应及给定时刻的函数值。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函化为标准二阶形式求 ωn 与 ξ
本卷实例
  • 关键一步：对照标准式读出 2ξωn 与 ωn²
  • 中间结果：解出 ξ 与 ωn 并判定为欠阻尼
  • 卡点：读参数时须与闭环分母系数对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤

  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法

4四、奈奎斯特判据与劳斯判据验证20 分#

思路
  • 对含右半平面开环极点的系统画奈奎斯特曲线，按包围圈数与 P、Z 关系判稳并数右半平面闭环极点数；再用劳斯判据复核结论。
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据判断含右半平面开环极点的系统
本卷实例
  • 关键一步：数开环右半平面极点数 P 并画 G(jω) 曲线
  • 中间结果：由包围圈数 N 与 P 求闭环右半平面极点数 Z
  • 卡点：判稳须正确判断曲线包围 -1 点的方式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据判断含右半平面开环极点的系统
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
