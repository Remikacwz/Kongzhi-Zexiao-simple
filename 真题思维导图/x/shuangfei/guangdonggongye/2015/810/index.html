1一、锅炉汽包水位复合控制系统10 分#

思路
  • 系统由按偏差的反馈调节回路与按扰动的前馈调节回路组成；说明水位偏离给定时的调节过程以及两个回路各自的作用。
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 指出被控量、操纵量与主要扰动量并说明复合系统工作过程
本卷实例
  • 关键一步：区分反馈调节回路与扰动调节回路各自检测与作用的量
  • 中间结果：反馈回路按水位偏差动作，扰动回路按给水流量顺馈补偿
  • 卡点：两回路连接关系为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过指出被控量、操纵量与主要扰动量并说明复合系统工作过程
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 本卷考过把被控量与操纵量搞反
  • 本卷考过只说明反馈回路而漏掉扰动补偿回路
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半
前馈与比值控制 过程控制与检测仪表
本卷考法
  • 说明扰动前馈补偿回路的作用及为何不改变闭环稳定性
本卷实例
  • 关键一步：按主要扰动给水流量设置顺馈补偿通道
  • 中间结果：扰动补偿作用为消除给水流量扰动引起的稳态误差
  • 卡点：前馈补偿器与对象动态连接为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 前馈按扰动直接补偿，属于开环控制，不改变原回路稳定性
  • 完全不变性条件要求前馈通道传递函数等于扰动通道与调节通道之比的倒数
  • 比值控制保持两个流量成给定比例，常用开环比值与双闭环比值
  • 前馈与反馈组合成复合控制系统
步骤
  • 写出扰动通道与调节通道的传递函数
  • 按不变性条件求前馈补偿器
  • 对两个需配比的量确定比值系数与乘除环节位置
  • 画出复合或比值控制系统方框图
通用考法
  • 本卷考过说明扰动前馈补偿回路的作用及为何不改变闭环稳定性
  • 求前馈补偿器使扰动对被控量不产生影响
  • 设计比值控制系统并计算比值系数
  • 说明前馈为什么不影响稳定性
常见易错
  • 本卷考过把前馈补偿回路误当成反馈回路
  • 本卷考过忽略前馈补偿器的物理可实现条件
  • 前馈补偿器求出含高阶微分、不可实现却直接采用
  • 比值系数没有换算成仪表量程

2二、无源RC网络传递函数10 分#

思路
  • 用复阻抗与基尔霍夫电压定律列网络方程求 Uo(s)/Ui(s)，再与两个RC网络传递函数相乘的结果比较，判断直接级联是否等效。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由无源网络复阻抗模型求 Uo(s) 与 Ui(s) 的传递函数
本卷实例
  • 关键一步：把电容写成 1/(sC) 后用KVL列网络方程
  • 中间结果：网络函数为含两个RC时间常数的二阶有理分式
  • 卡点：网络拓扑为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由无源网络复阻抗模型求 Uo(s) 与 Ui(s) 的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过复阻抗法把电容阻抗误写成 Cs
  • 本卷考过列KVL时漏掉级间耦合项
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 判断两级RC直接级联是否等于两个一阶传函相乘
本卷实例
  • 关键一步：比较整体网络函数与两级单独传函乘积的分母结构
  • 中间结果：整体分母多出级间耦合项，故两者不等效
  • 卡点：两级RC连接方式为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过判断两级RC直接级联是否等于两个一阶传函相乘
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 本卷考过忽略级联时的负载效应
  • 本卷考过直接把两个RC网络的传函相乘
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

3三、结构图求输入输出传函10 分#

思路
  • 由结构图找前向通路与独立回路，用梅森增益公式写输入输出传递函数；也可逐层化简结构图验证。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求结构图的输入输出传递函数
本卷实例
  • 关键一步：标出两条前向通路与三个独立回路
  • 中间结果：分母为1减各回路增益，分子按余子式展开
  • 卡点：结构图支路为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求结构图的输入输出传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路漏算或重复计数
  • 本卷考过余子式未剔除与通路接触的回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 对多回路结构图逐层化简并求闭环传函
本卷实例
  • 关键一步：从最内层反馈环开始逐层等效化简
  • 中间结果：每步保留完整输入输出关系再向上合并
  • 卡点：比较点与引出点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过对多回路结构图逐层化简并求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过化简内环时把外环信号当成常数处理
  • 化简内环时把外环的信号当成常数处理

4四、主导极点判别与暂态性能25 分#

思路
  • 由闭环极点分布看主导极点是否成立；再用主导极点对估算超调量、峰值时间与调节时间，并说明主导极点法的工程实用意义。
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 由闭环极点分布判断是否存在主导极点
本卷实例
  • 关键一步：比较共轭极点实部到虚轴距离与第三个实极点距离
  • 中间结果：距虚轴最近的共轭极点对可近似为主导极点
  • 卡点：主导极点法要求其余极点远离虚轴且附近无闭环零点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过由闭环极点分布判断是否存在主导极点
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 本卷考过只看极点距离而忽略闭环零点影响
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由主导极点对估算超调量、峰值时间与调节时间
本卷实例
  • 关键一步：把主导极点对写成标准二阶共轭极点形式
  • 中间结果：由实部与虚部读出阻尼比和自然频率
  • 卡点：工程意义需结合主导极点近似的适用条件说明
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由主导极点对估算超调量、峰值时间与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过2%与5%误差带的调节时间系数用错
  • 本卷考过峰值时间与上升时间混用
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

5五、根轨迹与阻尼比对应极点30 分#

思路
  • 按法则画 G(s)H(s)=K/[s(s+4)(s+6)] 的根轨迹；在阻尼比0.5的等阻尼线上找与根轨迹交点求增益；再用根之和求第三个闭环极点并判断主导极点。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制三个开环极点无零点的根轨迹
本卷实例
  • 关键一步：标出开环极点0、-4、-6并确定实轴根轨迹段
  • 中间结果：三条分支起点为三个开环极点，终点均为无穷远
  • 卡点：根轨迹形状为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制三个开环极点无零点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴段判据中的零极点个数算错
  • 本卷考过渐近线夹角公式写错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由阻尼比0.5的等阻尼线确定闭环极点及对应增益
本卷实例
  • 关键一步：画等阻尼线与根轨迹交点，交点即主导极点
  • 中间结果：由交点实部与虚部可反算对应根轨迹增益
  • 卡点：第三个闭环极点用根之和定理求得
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由阻尼比0.5的等阻尼线确定闭环极点及对应增益
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错

  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

6六、滞后校正设计30 分#

思路
  • 先画原系统 Bode 图并求截止频率与相角裕度，判断需要滞后校正；再按相角裕度45度选择滞后网络参数，画补偿前后幅相频特性并验算。
滞后校正 系统校正
本卷考法
  • 按相角裕度要求设计串联滞后校正装置
本卷实例
  • 关键一步：由原系统相角缺口选择滞后网络转折频率
  • 中间结果：滞后网络传函写成 (bTs+1)/(Ts+1) 形式
  • 卡点：校正网络接入位置为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
