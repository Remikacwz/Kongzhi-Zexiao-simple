1倒立摆控制系统方框图与工作原理#

思路
  • 倒立摆是非线性不稳定对象；设计控制策略使其稳定，要求绘制系统方框图并叙述工作原理。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 说明倒立摆控制系统的基本组成与控制方式
本卷实例
  • 关键一步：先明确被控量是摆杆角度，再按负反馈构成闭环
  • 中间结果：按给定、比较、控制器、执行、对象、检测列环节
  • 卡点：倒立摆原理图的信号连接关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过说明倒立摆控制系统的基本组成与控制方式
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过方框图漏掉检测与反馈通道
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 绘制含给定、比较、控制器、对象与反馈的方框图
本卷实例
  • 关键一步：用负反馈把输出摆角与给定角度作差得误差
  • 中间结果：控制器输出经执行机构作用于小车与摆杆
  • 卡点：方框图各环节命名与信号流向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过绘制含给定、比较、控制器、对象与反馈的方框图
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过反馈通道的取号与比较点方向画错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2机械系统建模与由响应反求参数#

思路
  • m=1 的机械系统先按牛顿第二定律建模；再由单位阶跃响应图读稳态值、超调与峰值时间，反求 K1、K2、B、K
机械系统建模 建模与机电系统
本卷考法
  • 对质量-弹簧-阻尼系统列运动方程并求传函
本卷实例
  • 关键一步：对质量 m=1 列牛顿第二定律，弹簧力与阻尼力都取 u−y 方向的相对量
  • 中间结果：整理后传函为 G(s)=(Bs+k)/(s²+Bs+k)
  • 卡点：阻尼力究竟按 B(u̇−ẏ) 还是 B u̇，需回原卷核对机械原理图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

3劳斯判据与相对稳定度#

思路
  • 三问层层递进：基础稳定域 → 虚轴交点（等幅振荡）→ 极点左移一个单位（相对稳定度）
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据确定使系统闭环稳定的 K 范围
本卷实例
  • 关键一步：由结构图写开环传函，再列闭环特征方程和劳斯表
  • 中间结果：特征式为 s³+14s²+40s+40k
  • 卡点：原卷第三题题面缺失，开环传函系数需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据确定使系统闭环稳定的 K 范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过首列出现 0 时未用 ε 法
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

思路
