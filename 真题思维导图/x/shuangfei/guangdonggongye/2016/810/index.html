1一、角度跟踪系统工作原理10 分#

思路
  • 角度跟踪系统由给定电位器、比较、电压放大、功率放大、直流电动机与减速器组成；输出角度经反馈电位器送回输入端形成偏差，驱动电动机使输出跟踪输入。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出角度跟踪系统的给定、反馈与执行环节并说明工作原理
本卷实例
  • 关键一步：由输入输出角度经电位器形成偏差电压
  • 中间结果：偏差电压经电压与功率放大后驱动直流电动机
  • 卡点：系统原理图为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指出角度跟踪系统的给定、反馈与执行环节并说明工作原理
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把被控量与操纵量搞反
  • 本卷考过只画方框图不指认环节
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 说明负反馈连接方式并画系统结构框图
本卷实例
  • 关键一步：把输出角度检测后反馈到输入端比较
  • 中间结果：框图含给定、比较、放大、执行、对象与反馈检测
  • 卡点：反馈检测元件与减速器连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过说明负反馈连接方式并画系统结构框图
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过反馈极性接反
  • 本卷考过方框图中漏画反馈检测环节
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、力臂机械系统求传函10 分#

思路
  • 把A点力按力臂比折算到A'点，对质量块列牛顿第二定律，经拉氏变换并令初值为零求 Y(s)/F(s)。
机械系统建模 建模与机电系统
本卷考法
  • 由力臂和弹簧阻尼列质量块动力学方程求传函
本卷实例
  • 关键一步：把A点力按力臂比折算到A'点
  • 中间结果：对质量块列 M y'' 等于折算力减弹簧力减阻尼力
  • 卡点：力臂与受力方向为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过由力臂和弹簧阻尼列质量块动力学方程求传函
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 本卷考过弹簧力与阻尼力方向取反
  • 本卷考过力臂折算关系写错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由机械系统牛顿方程经拉氏变换得 Y(s)/F(s)
本卷实例
  • 关键一步：对微分方程两边取拉氏变换并令初值为零
  • 中间结果：整理成二阶机械系统标准传函形式
  • 卡点：力臂长度与质量块连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由机械系统牛顿方程经拉氏变换得 Y(s)/F(s)
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过零初始条件未说明
  • 本卷考过阻尼项漏乘s
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

3三、结构图化简求传函10 分#

思路
  • 对含多回路的系统结构图从内到外逐层化简，求出闭环传递函数 C(s)/R(s)，再用梅森公式校验。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 对多回路结构图逐层化简求出闭环传递函数
本卷实例
  • 关键一步：先合并最内层反馈环
  • 中间结果：逐层保留输入输出关系再向上合并
  • 卡点：比较点与引出点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过对多回路结构图逐层化简求出闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过化简内环时把外环信号当常数处理
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式校验结构图化简结果
本卷实例
  • 关键一步：标出前向通路与各独立回路
  • 中间结果：用梅森公式写出闭环传函并与化简结果对照
  • 卡点：结构图连接为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式校验结构图化简结果
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过回路增益符号写错
  • 本卷考过前向通路漏算
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

4四、扰动与输入稳态误差25 分#

思路
  • 由结构图分别求参考输入和扰动作用下的误差传函；利用斜坡输入无稳态误差确定参数关系，再由扰动稳态误差绝对值小于0.05求另一约束。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡输入无稳态误差确定参数关系
本卷实例
  • 关键一步：先求误差传函并判断系统型别
  • 中间结果：令斜坡稳态误差为零得到参数关系
  • 卡点：误差定义为 E=R-C 要按单位反馈处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位斜坡输入无稳态误差确定参数关系
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过未判稳就用终值定理
  • 本卷考过组合输入漏算分量
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动 n(t)=t 作用下的稳态误差并限制其绝对值
本卷实例
  • 关键一步：令参考输入为零单独求扰动误差传函
  • 中间结果：由扰动稳态误差绝对值不等式求参数下界
  • 卡点：扰动作用点为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法

  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 本卷考过把扰动误差直接当总误差
  • 本卷考过求扰动传函时未令参考输入为零
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

通用考法

  • 两个输入同时存在时直接叠加却未验证系统的线性性

5五、根轨迹与临界稳定30 分#

思路
  • 按法则画 G(s)H(s)=K(s+1)/[s(s-3)] 的根轨迹；由虚轴交点求临界稳定K与闭环极点；再结合分离点求稳定且欠阻尼的K范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制含一个零点两个极点的根轨迹
本卷实例
  • 关键一步：标出开环极点0、3与零点-1
  • 中间结果：两条分支分别终于零点-1与无穷远
  • 卡点：实轴段与渐近线需按法则判定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制含一个零点两个极点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴段判据算错
  • 本卷考过渐近线交点与夹角写错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界稳定K值
本卷实例
  • 关键一步：令闭环特征方程中s=jω并分离实虚部
  • 中间结果：虚轴交点与临界K由实虚部方程联立求得
  • 卡点：原点处交点需判断是否舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界稳定K值
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 本卷考过只代一个ω就下结论
  • 本卷考过得到K值后未回原题核对参数定义
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
