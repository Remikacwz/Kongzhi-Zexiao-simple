1转向角度控制系统的组成与分类#

思路
  • 由原卷转向机构图指认主要部件并画出方框图，按输入量类型判断系统类别，再由转向虚位分析传动间隙的影响。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指认转向控制系统的主要部件并按输入量类型判断系统类别
本卷实例
  • 关键一步：从方向盘到轮胎按给定、比较、放大、执行、对象、检测逐环节指认
  • 关键一步：按给定转角随时间的变化形式区分恒值、随动与程序控制
  • 中间结果：转向角随驾驶操作连续变化，按给定信号分类归入随动系统
  • 卡点：转向机构图为原卷插图，部件与连接关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指认转向控制系统的主要部件并按输入量类型判断系统类别
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 按信号流向画出转向角度控制系统的方框图
本卷实例
  • 关键一步：把检测、比较、控制、执行与被控对象按负反馈关系连成闭环
  • 中间结果：方框图中给定量为方向盘转角，被控量为轮胎转角
  • 卡点：转向机构图为原卷插图，画方框图前需回原卷核对部件连接
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法

  • 判断反馈极性对分母符号的影响
常见易错

  • 并联环节相减时符号取反

典型非线性特性及其影响 非线性系统
本卷考法
  • 分析转向虚位对应的非线性特性及其产生原因
本卷实例
  • 关键一步：把方向盘小范围变化而轮胎不跟随对应为传动机构的间隙或死区
  • 中间结果：小范围输入被间隙吞掉，输出出现不灵敏区
  • 卡点：除齿轮间隙外，电动机启动电压与传感器精度也会造成小信号不灵敏
  • 卡点：转向机构图为原卷插图，间隙位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 饱和特性降低等效增益，可能引起系统不稳定或自振
  • 死区特性使小信号时增益为零，产生稳态误差
  • 间隙特性引起相位滞后，导致波形畸变与自振
  • 继电特性使系统出现持续振荡并可能产生颤振
步骤
  • 识别非线性环节类型
  • 写出其描述函数或分段数学表达式
  • 分析其对等效增益与稳定性的影响
通用考法
  • 本卷考过分析转向虚位对应的非线性特性及其产生原因
  • 分析饱和或死区对系统性能的影响
  • 求典型非线性的描述函数表达式
  • 说明间隙为何容易引起自振
常见易错
  • 认为饱和总是使系统更稳定
  • 忽略死区在原点附近造成的小信号失效

  • 求扰动传函时没有把参考输入置零

3二阶系统超调量反求与动态指标#

思路
  • T=0 时求闭环传函，由超调量 9.5% 反求阻尼比与参数，再求峰值时间、调节时间与稳态值；T=1 时重求闭环传函与阶跃响应。
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量 9.5% 反求阻尼比 ξ
本卷实例
  • 关键一步：由二阶欠阻尼超调量公式反解阻尼比
  • 中间结果：超调量指百分比，反解时须先写成小数
  • 卡点：公式中指数为负阻尼比与根号之比
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量 9.5% 反求阻尼比 ξ
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过超调量公式中漏乘 100%
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

零极点分布与响应模态 传递函数
本卷考法
  • 由闭环传函求闭环极点
  • T=1 时重新求闭环传函
本卷实例
  • 关键一步：由闭环特征方程求特征根作为闭环极点
  • 中间结果：前馈增益变化时闭环特征式随之改变
  • 卡点：极点是否稳定还要结合零点影响一起看
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由闭环传函求闭环极点
  • 本卷考过T=1 时重新求闭环传函
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 本卷考过只由极点判稳却忽略零点影响
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 求峰值时间、调节时间（±2%）与稳态值并绘制阶跃响应
本卷实例
  • 关键一步：由阻尼比与自然频率求峰值时间与调节时间
  • 中间结果：稳态值由闭环传函在原点处取值得到
  • 卡点：调节时间按百分之二误差带取四点四
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过求峰值时间、调节时间（±2%）与稳态值并绘制阶跃响应
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 本卷考过用 5% 误差带的系数 3.5
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

4双环系统根轨迹#

思路
  • 先画内环根轨迹定内环极点，把内环等效成一个环节后再画外环根轨迹；ξ=0.5 用图解法找主导极点
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 逐层化简内外环结构
本卷实例
  • 关键一步：先独立化简内环再把它当作外环中的一个环节
  • 中间结果：内环闭环传函乘外环前向环节构成外环开环
  • 卡点：化简内环时外环变量不是常数，不能直接代入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤

  • 把内环替换为等效环节

  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过逐层化简内外环结构
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过化简内环时把外环信号当成常数
  • 化简内环时把外环的信号当成常数处理
根轨迹的绘制法则 根轨迹法
本卷考法
  • 分别绘制内环与外环的根轨迹
本卷实例
  • 关键一步：分别按内环与外环的开环零极点画根轨迹
  • 中间结果：内环闭环极点成为外环根轨迹的起点
  • 卡点：实轴段判据的零极点计数按右数奇偶
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过分别绘制内环与外环的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴段判据中的零极点个数算错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

与虚轴的交点及临界参数 根轨迹法
本卷考法

本卷实例

通用考法

  • 求根轨迹与虚轴的交点及临界增益

  • 判断根轨迹穿越虚轴的方向
常见易错

  • 只代一个 ω 就下结论，漏掉另一组交点

思路

闭环频率特性与性能指标 频域分析
本卷考法
  • 由 ±3dB 定义确定系统频带并求使频带最宽的 a 与谐振频率 ω
本卷实例
