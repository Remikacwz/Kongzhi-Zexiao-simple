1开环与闭环控制概念#

思路
  • 瓦特飞轮调速器靠离心力带动套筒改变进汽量，属于按偏差调节的闭环系统；优缺点要对照「精度 vs 稳定性」回答
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 画出瓦特调速器的控制框图
本卷实例
  • 关键一步：把给定转速与飞球检测的转速比较，偏差经杠杆调节进汽阀
  • 中间结果：框图含给定、比较、放大执行、对象与反馈检测环节
  • 卡点：调速器原理图未读，套筒与阀门动作方向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过画出瓦特调速器的控制框图
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过方框图中漏画反馈测量环节
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

  • 卡点：改开环要断开反馈检测通道，改闭环需增加转速检测与比较

3由时域指标反推开环传函#

思路
  • 三阶无闭环零点；斜坡 ess=1.125 定型别与增益，σ%=16.3% 与 tp=3.6363s 定 ξ、ωn，再拼出 G(s)
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡 ess=1.125 确定开环增益
本卷实例
  • 关键一步：先由开环传函判断系统型别为一型
  • 中间结果：一型系统单位斜坡误差等于静态速度误差系数的倒数
  • 卡点：由误差反解的是开环增益，不是闭环增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位斜坡 ess=1.125 确定开环增益
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过把开环增益与静态误差系数混为一谈
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由 σ%=16.3% 与 tp=3.6363s 反求 ξ 与 ωn
本卷实例
  • 关键一步：先由超调量公式反解阻尼比，再代入峰值时间公式求自然频率
  • 中间结果：超调量只与阻尼比有关，峰值时间由阻尼振荡频率决定
  • 卡点：反解阻尼比时取小于一的正根，另一根不符合欠阻尼
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由 σ%=16.3% 与 tp=3.6363s 反求 ξ 与 ωn
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过超调量公式中漏乘 100%
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

4根轨迹与阻尼比#

思路
  • G=Kr/(s(s+1)(s+2))；ξ=0.5 对应 β=60° 的等阻尼线，与根轨迹交点即主导极点
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制系统根轨迹并求稳定时 Kr 的取值范围
本卷实例
  • 关键一步：由三个开环极点定实轴段、渐近线交点与分离点
  • 中间结果：令 s 等于 jω 求根轨迹与虚轴交点即临界增益
  • 卡点：无开环零点，实轴根轨迹段由右侧奇数个极点判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制系统根轨迹并求稳定时 Kr 的取值范围
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过渐近线夹角公式中的 2k+1 写成 2k
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
