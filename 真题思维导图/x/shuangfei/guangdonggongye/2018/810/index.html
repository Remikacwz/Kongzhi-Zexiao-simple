1一、方框图求 Y/R 与 Y/N15 分#

思路
  • 对同一方框图分别求参考输入与扰动作用下的传递函数：列出各回路增益与前向通路增益，用梅森公式求 Δ 及余子式 Δk，R 与 N 分别单独作用。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求方框图输入输出传函
本卷实例
  • 关键一步：设 R、N 分别单独作用并标出全部回路
  • 中间结果：Y(s)/R(s) 为单前向通路双回路结构
  • 卡点：回路接触关系依赖框图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求方框图输入输出传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路找漏或重复计数
  • 本卷考过余子式未剔除与通路接触的回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求扰动作用下的 Y(s)/N(s)
本卷实例
  • 关键一步：求 Y/N 时令参考输入 R(s) 为零
  • 中间结果：扰动侧有多条前向通道，需分别求余子式
  • 卡点：扰动与前向通路是否接触须看框图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求扰动作用下的 Y(s)/N(s)
  • 求扰动引起的输出或误差

常见易错
  • 本卷考过求扰动传函时未把参考输入置零
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

2二、劳斯判据求稳定范围与等幅振荡频率15 分#

思路
  • 由系统结构图写出闭环特征方程，列劳斯表求使首列全正的 K 范围；再令特征方程在 s=jω 成立，由实部、虚部分别为零求等幅振荡角频率。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求闭环稳定的 K 取值范围
本卷实例
  • 关键一步：由结构图化简写出闭环特征方程
  • 中间结果：对劳斯表首列各元素列出不等式组
  • 卡点：闭环特征方程的系数须先由框图化简得到
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求闭环稳定的 K 取值范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过系数缺项时未补零
  • 本卷考过首列出现 0 后未用 ε 法
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

参数稳定域的确定 稳定性分析
本卷考法

本卷实例
  • 关键一步：令 s=jω 代入特征方程并分离实部虚部
  • 中间结果：由虚部方程解出等幅振荡的角频率
  • 卡点：临界点即特征方程在虚轴上的根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求使系统稳定的参数范围并定位临界点
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 本卷考过只列出部分首列不等式，漏掉某个约束
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

3三、二阶系统动态指标与初始条件全响应25 分#

思路
  • 由闭环特征多项式求 ωn 与 ξ，按欠阻尼公式算上升时间与超调量；求组合输入下的稳态误差；再在非零初值下解微分方程求全响应。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函化为标准二阶形式求 ωn 与 ξ
本卷实例
  • 关键一步：对照标准式读出 2ξωn 与 ωn² 后解出 ξ、ωn
  • 中间结果：由 ξ、ωn 判定系统为欠阻尼
  • 卡点：读参数时须与闭环分母系数对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法

  • 由闭环传递函数求 ωn 与 ξ

  • 在 s 平面上标出闭环极点的位置

  • 化为标准形式时忘记把 s² 项系数归一化

4四、根轨迹绘制与阻尼比确定 K25 分#

思路
  • 按法则画 K/[s(s²+8s+20)] 的根轨迹，求渐近线、分离点与虚轴交点；由全实极点的分离点增益定 K 范围；由阻尼比 0.707 定共轭极点后用根之和求 K。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制三个开环极点的根轨迹
本卷实例

  • 中间结果：三条分支终点均为无穷远，求渐近线交点与夹角
  • 卡点：根轨迹形状为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制三个开环极点的根轨迹
  • 按法则绘制根轨迹草图
