1一、结构图求闭环传函#

思路
  • 由结构图找前向通路与独立回路，用梅森增益公式写出闭环传递函数 C(s)/R(s)。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求结构图的闭环传递函数 C(s)/R(s)
本卷实例
  • 关键一步：找出三条独立回路与一条前向通路
  • 中间结果：分母为 1 减各回路增益，分子剥离接触回路
  • 卡点：结构图连接为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求结构图的闭环传递函数 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路漏算或余子式未剔除接触回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、机械系统建模与全响应#

思路
  • 由牛顿第二定律列质量块动力学方程，拉氏变换后代入两路斜坡输入，部分分式反变换求 y(t)，再代 t=2s。
机械系统建模 建模与机电系统
本卷考法
  • 由两输入机械系统列动力学方程求输出
本卷实例
  • 关键一步：对质量块列合力等于质量乘加速度
  • 中间结果：整理出以两路输入为自变量的输出传函
  • 卡点：机械系统结构为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过由两输入机械系统列动力学方程求输出
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 本卷考过阻尼力与弹簧力的方向或合力关系写错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由拉氏变换与部分分式求全响应并代时刻值
本卷实例
  • 关键一步：部分分式展开后逐项拉氏反变换
  • 中间结果：响应含常数项与两个衰减指数项
  • 卡点：代入时刻前先确认响应表达式适用区间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由拉氏变换与部分分式求全响应并代时刻值
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 本卷考过只求稳态而漏掉自由响应分量
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

3三、单位反馈时域指标与稳态误差#

思路
  • 由结构图化简得闭环传函并与标准二阶对比：无超调要求阻尼比不小于 1；组合输入稳态误差用终值定理；给定参数后算超调量与调节时间。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由单位阶跃无超调条件求两参数关系
本卷实例
  • 关键一步：闭环特征式与标准二阶形式逐项对比
  • 中间结果：阻尼比不小于 1 对应单位阶跃无超调
  • 卡点：无超调条件还要同时满足系统稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由单位阶跃无超调条件求两参数关系
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过把无超调条件写成阻尼比小于 1
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由阶跃加斜坡输入的稳态误差上界求参数关系
本卷实例
  • 关键一步：写误差传函后对阶跃与斜坡用终值定理
  • 中间结果：稳态误差为两个输入分量误差之和
  • 卡点：须在稳定域内使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由阶跃加斜坡输入的稳态误差上界求参数关系
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过组合输入漏算斜坡分量
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由两参数求超调量与调节时间
本卷实例
  • 关键一步：先由参数定自然频率，再由参数乘积定阻尼比
  • 中间结果：把阻尼比代入超调量与调节时间公式
  • 卡点：调节时间按题给误差带 2% 取系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由两参数求超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过误差带 2% 对应的调节时间系数用错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

4四、根轨迹绘制、降阶与相角条件#

思路
  • 先画开环根轨迹；再由根之和定理找三根实部相等点定临界增益，用主导极点判断降阶；最后让待定极点在根轨迹上，用相角条件解校正参数。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制含一对共轭极点与一个零点的根轨迹
本卷实例
  • 关键一步：标开环零极点并定实轴段、渐近线与起始角
  • 中间结果：三条分支始于 0 与共轭极点，终于零点与无穷远
  • 卡点：根轨迹形状以插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制含一对共轭极点与一个零点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴段判据中零极点个数算错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由主导极点求系统可降阶的参数范围
本卷实例
  • 关键一步：由根之和定理令三个根实部相等求临界增益
  • 中间结果：临界增益两侧主导极点分别为实根与共轭根
  • 卡点：参数等于临界值时系统不可降阶
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由主导极点求系统可降阶的参数范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 本卷考过只比较实部大小而忽略极点类型
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 由待定极点在根轨迹上用相角条件求校正参数
本卷实例
  • 关键一步：要求待定点处各向量相角之和为 180 度
  • 中间结果：由校正环节应提供的相角反解参数
  • 卡点：原系统在新极点处的相角要先算准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过由待定极点在根轨迹上用相角条件求校正参数
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 本卷考过相角条件各向量正负号写错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

5五、正弦响应与 Nyquist 判稳#

思路
  • 先写频率特性求正弦输入下的输出响应；再分离实虚部求 Nyquist 曲线与负实轴交点；最后按包围条件求闭环稳定的参数范围。
频率特性的物理意义与求法 频域分析
本卷考法
  • 由频率特性求正弦输入下的输出响应
本卷实例
  • 关键一步：分别求给定角频率处的幅值与相角
  • 中间结果：输出为同频正弦，幅值等于输入幅值乘幅频
  • 卡点：相位应加上相频后再写正弦表达式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由频率特性求正弦输入下的输出响应
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过相频漏掉积分环节的负 90 度
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 画 Nyquist 曲线并求与负实轴的交点
本卷实例
  • 关键一步：令频率特性虚部为零求与负实轴交点频率
  • 中间结果：交点坐标为负实轴上一点
  • 卡点：起点与终点相角由积分环节个数决定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过画 Nyquist 曲线并求与负实轴的交点
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过含积分环节时未补画无穷大半径圆弧
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由 Nyquist 判据求闭环稳定时的参数范围
本卷实例
