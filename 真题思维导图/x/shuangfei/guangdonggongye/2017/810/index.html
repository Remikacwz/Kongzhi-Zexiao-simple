1一、电梯速度控制系统连接与分类10 分#

思路
  • 电梯电动机速度控制系统以速度规划曲线为给定，测速发电机反馈实际转速，二者比较得到偏差电压，经放大后驱动电动机调节负载转速；按输入量类型属于随动控制系统。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 由输入量类型判断控制系统类别并简述工作原理
本卷实例
  • 关键一步：由速度规划曲线与电动机反馈判断输入输出量
  • 中间结果：输入为速度给定，输出为负载转速
  • 卡点：接线端子a、b与c、d位置为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过由输入量类型判断控制系统类别并简述工作原理
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过按有无传感器判断而不看反馈回路
  • 本卷考过把随动系统与恒值系统混为一谈
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 把给定、比较、放大、执行与反馈环节连成负反馈系统并画方框图
本卷实例
  • 关键一步：将测速发电机输出与给定电压反向比较
  • 中间结果：偏差经放大器驱动电动机改变负载转速
  • 卡点：元件连接关系为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过把给定、比较、放大、执行与反馈环节连成负反馈系统并画方框图
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过反馈极性连接错误
  • 本卷考过方框图中漏画测速反馈
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、电流源电路求传函10 分#

思路
  • 开关按下后确定电流源与RLC元件的联接关系，列电路方程求 Uo(s)/Io(s)。
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由含开关的电路求 uo 对 io 的传递函数
本卷实例
  • 关键一步：开关按下后确定输入电流源与RLC的联接方式
  • 中间结果：用导纳与阻抗关系列节点方程
  • 卡点：电路拓扑为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由含开关的电路求 uo 对 io 的传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 本卷考过开关按下后拓扑判断错误
  • 本卷考过复阻抗法把电容阻抗写成Cs
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由电路方程经拉氏变换求传递函数 Uo(s)/Io(s)
本卷实例
  • 关键一步：对电路方程两边取拉氏变换
  • 中间结果：整理为二阶有理分式
  • 卡点：RLC参数与连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由电路方程经拉氏变换求传递函数 Uo(s)/Io(s)
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过初始条件未按零处理
  • 本卷考过电感与电容复阻抗写反
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

3三、结构图求闭环传函10 分#

思路
  • 由结构图找前向通路与独立回路，用梅森公式求 C(s)/R(s)，并用逐层化简校验。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求结构图的闭环传递函数 C(s)/R(s)
本卷实例
  • 关键一步：找出一条前向通路与三个独立回路
  • 中间结果：分母为1减回路增益，分子含前向通路余子式
  • 卡点：结构图连接为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求结构图的闭环传递函数 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过独立回路漏算
  • 本卷考过余子式未剔除接触回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简
本卷实例
  • 关键一步：从最内层回路开始等效
  • 中间结果：逐层保留输入输出关系再合并
  • 卡点：比较点与引出点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过化简内环时把外环信号当常数
  • 化简内环时把外环的信号当成常数处理

4四、由动态指标反求参数25 分#

思路
  • 由系统结构图写闭环传函并与二阶标准形式对比；由超调量和峰值时间确定阻尼比与自然频率，再反求K和τ，最后求斜坡输入稳态误差。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由结构图写闭环传函并与二阶标准形式对比
本卷实例
  • 关键一步：由结构图求闭环特征式
  • 中间结果：与标准二阶形式比较得自然频率与阻尼比关系
  • 卡点：系统结构图为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由结构图写闭环传函并与二阶标准形式对比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过忘记把s平方项系数归一化
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量和峰值时间求阻尼比与自然频率
本卷实例
  • 关键一步：由超调量公式反解阻尼比，再代入峰值时间公式求自然频率
  • 中间结果：阻尼比由超调量唯一确定，自然频率由峰值时间确定
  • 卡点：反解阻尼比取小于1的正根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量和峰值时间求阻尼比与自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过超调量公式漏乘100%
  • 本卷考过峰值时间与上升时间混用
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由动态性能指标反求开环增益与时间常数
本卷实例
  • 关键一步：把闭环传函系数与自然频率、阻尼比关系对应
  • 中间结果：由系数关系解出K与τ
  • 卡点：求出的参数需同时满足超调量与峰值时间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由动态性能指标反求开环增益与时间常数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 本卷考过只满足单项指标就下结论
  • 本卷考过未做交叉验证
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求输入 r(t)=1.5t 时系统的稳态误差
本卷实例
  • 关键一步：先由闭环特征方程判断系统稳定
  • 中间结果：单位斜坡误差由静态速度误差系数确定
  • 卡点：输入幅度1.5不要漏乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求输入 r(t)=1.5t 时系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过未判稳就用终值定理
  • 本卷考过把误差系数与开环增益混为一谈
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

5五、根轨迹临界稳定与临界阻尼30 分#

思路
  • 按法则画 G(s)H(s)=K/[s(0.01s+1)(0.02s+1)] 的根轨迹；由虚轴交点求临界稳定Kc；再由分离点求临界阻尼比对应的K。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制三个开环极点无零点的根轨迹
本卷实例
  • 关键一步：标出开环极点0、-50、-100并确定实轴段
  • 中间结果：三条分支起点为三个开环极点，终点均为无穷远
  • 卡点：根轨迹形状为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制三个开环极点无零点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴段判据算错
  • 本卷考过渐近线参数写错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
