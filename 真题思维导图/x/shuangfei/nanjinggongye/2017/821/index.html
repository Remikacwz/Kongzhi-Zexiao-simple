南京工业大学 821 自动控制原理 2017 年真题思维导图

强势双非共 6 题合计 150 分

难度：中等偏上　一、填空题10空（每空3分共30分）考基本概念；二至六为五道大题，覆盖多输入结构图求传函、二阶系统指标与谐振、根轨迹与稳态误差、期望特性法串联校正、描述函数法自振分析

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

1~10填空题（共10空）30 分#

思路
  • 十空覆盖控制方式分类、由微分方程定阶、非线性判别、惯性时间常数与快速性、附加闭环零点对超调量的影响、由误差响应求闭环传函、积分控制作用、奈氏判据求闭环右极点数、中频段斜率、超前校正装置最大超前角
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断雷达跟踪系统所属的控制系统类别
本卷实例
  • 关键一步：按给定值的变化规律区分控制系统类别
  • 中间结果：给定值随目标变化且未知，属随动系统
  • 卡点：题干只给一个应用场景，须据特征归类
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断雷达跟踪系统所属的控制系统类别
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把随动系统与恒值或程序控制系统混为一谈
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
传递函数的定义与基本性质 传递函数
本卷考法
  • 由一阶微分方程判断系统阶数
本卷实例
  • 关键一步：把微分方程写成传递函数看分母最高次
  • 中间结果：分母最高次为一，故为一阶系统
  • 卡点：方程中时间常数与增益符号易混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由一阶微分方程判断系统阶数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过把方程右边输入系数当成阶数
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

非线性系统的特点 非线性系统
本卷考法
  • 由微分方程含非线性运算判断系统类别
本卷实例
  • 关键一步：检查方程中是否存在变量乘积等非线性项
  • 中间结果：输入与其导数的乘积出现即为非线性系统
  • 卡点：逐年该方程后项OCR连写，已据同年宝典段校正
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过由微分方程含非线性运算判断系统类别
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 本卷考过只看方程阶数而忽略非线性项
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由惯性时间常数大小判断系统快速性
本卷实例
  • 关键一步：由一阶系统调节时间与时间常数成正比判断
  • 中间结果：时间常数越大调节时间越长、快速性越差
  • 卡点：题干给出差与好两个相反选项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由惯性时间常数大小判断系统快速性
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 本卷考过把时间常数越大快速性越好记反
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 判断二阶系统串入闭环零点后超调量的变化
本卷实例
  • 关键一步：由附加零点提升响应初始斜率理解其影响
  • 中间结果：串入闭环零点使超调量变大
  • 卡点：零点作用与附加极点作用方向相反，勿混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过判断二阶系统串入闭环零点后超调量的变化
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 本卷考过忽略附加零点对超调量的放大作用
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

误差定义与误差传递函数 稳态误差
本卷考法
  • 由误差响应反求单位反馈系统闭环传函
本卷实例
  • 关键一步：先由误差响应求误差传函再利用其与闭环传函关系
  • 中间结果：单位负反馈下闭环传函等于一减误差传函
  • 卡点：误差响应含两个指数项，需先合并再变换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由误差响应反求单位反馈系统闭环传函
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 本卷考过把误差传函与闭环传函混为一谈
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

PID 控制器与参数整定 系统校正
本卷考法
  • 指出积分控制作用的最大优点
本卷实例
  • 关键一步：从积分项对误差随时间累积的作用理解
  • 中间结果：积分控制可减少或消除稳态误差
  • 卡点：积分作用会降低稳定性，本题只问优点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过指出积分控制作用的最大优点
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 本卷考过把积分作用与微分作用的功能说反
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

奈奎斯特判据 稳定性分析
本卷考法
  • 由Nyquist曲线与开环右极点数求闭环右极点个数
本卷实例
  • 关键一步：按闭环右极点数等于P减二倍净穿越次数代入
  • 中间结果：正穿越与负穿越按穿越方向分别取正负号
  • 卡点：曲线与实轴只相交未穿过时净穿越记半次
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由Nyquist曲线与开环右极点数求闭环右极点个数
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过把包围圈数的正负号定义搞反
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

期望特性法与综合法 系统校正
本卷考法
  • 指出系统设计中频段幅频特性宜取的斜率
本卷实例
  • 关键一步：由中频段以负二十穿越零分贝可获较大相角裕度
  • 中间结果：中频段幅频斜率宜设计成负二十
  • 卡点：题干只留一个斜率填空，注意单位分贝每十倍频
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 期望特性法直接按指标画出希望的开环对数幅频特性
  • 用期望特性减去未校正特性得到校正装置特性
  • 关键是确定低频段高度、中频段宽度与高频段斜率
  • 中频段斜率一般取 -20 dB/dec 并保持足够宽度
步骤
  • 按稳态要求确定低频段斜率与高度
  • 按相角裕度要求确定中频段宽度与截止频率
  • 按抗噪要求确定高频段斜率
  • 相减求得校正装置并检验可实现性
通用考法
  • 本卷考过指出系统设计中频段幅频特性宜取的斜率
  • 用期望特性法设计校正装置
  • 说明中频段宽度与相角裕度的关系
  • 由校正装置特性反写传递函数
常见易错
  • 本卷考过把中频段斜率与高频段斜率记混
  • 期望特性的中频段取窄导致裕度不足
  • 相减后得到的特性不可物理实现却未检查

超前校正 系统校正
本卷考法
  • 由超前校正装置传函求最大相位超前角
本卷实例
  • 关键一步：把装置化为标准超前形式读出分度系数
  • 中间结果：最大超前角由分度系数按反正弦公式求得
  • 卡点：须先把分子分母一次项系数写成同一时间常数形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过由超前校正装置传函求最大相位超前角
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 本卷考过计算补偿角时忽略分子分母一次项系数之比
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

二多输入结构图求给定与扰动传函16 分#

思路
  • 先用梅森公式由同一特征式分别求给定输入与扰动输入到输出的前向通道，再由结构图逐层化简作互校，注意扰动传函须把参考输入置零
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图用梅森公式求给定输入到输出的传函
本卷实例
  • 关键一步：分别列写从给定输入到输出的前向通道与余子式
  • 中间结果：特征式由两条互不接触回路之外的部分组成
  • 卡点：第二题结构图接线为原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图用梅森公式求给定输入到输出的传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过余子式中未剔除与前向通路接触的回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求扰动作用下的闭环传函
本卷实例
  • 关键一步：令参考输入为零，仅保留扰动到输出的通道
  • 中间结果：扰动传函与给定传函共用同一特征多项式
  • 卡点：两输入同时存在时须分别置零后叠加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加

  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求校正后系统剪切频率与相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过把剪切频率与相位穿越频率用反
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

本卷考法

本卷实例

  • 中间结果：两曲线有交点即满足自振条件

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过由两曲线交点判断自振并求频率与振幅

  • 求自振频率与自振幅值

  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
