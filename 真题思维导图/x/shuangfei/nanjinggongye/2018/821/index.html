一结构图化简与梅森公式求给定与扰动传函20 分#

思路
  • 分别令扰动与参考输入为零，用梅森公式或结构图等效求 C(s)/R(s) 与 C(s)/N(s)，再按线性叠加写出给定与扰动共同作用下的输出。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式分别求给定通道与扰动通道的闭环传函
本卷实例
  • 关键一步：先令N为零求C(s)/R(s)，再令R为零求C(s)/N(s)
  • 中间结果：两条通道各有1条前向通路、2个独立回路且无互不接触回路
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式分别求给定通道与扰动通道的闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错

  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 非线性系统只有局部稳定性概念，与初始条件有关
  • 极限环的稳定性可由相轨迹收敛或发散判断
  • 减小非线性影响可用加大线性部分增益或引入校正
  • 用描述函数或相平面结果指导参数选择
步骤
  • 判断系统是否存在极限环并确定其稳定性
  • 分析非线性环节参数对自振幅值频率的影响
  • 通过调整线性部分增益或加入校正削弱自振
  • 重新分析确认自振消除或幅值达标
通用考法
  • 本卷考过求系统稳定时线性部分开环增益的范围
  • 提出消除自振的工程措施
  • 分析增益变化对极限环幅值的影响
  • 比较不同方案对稳定性与动态性能的利弊
