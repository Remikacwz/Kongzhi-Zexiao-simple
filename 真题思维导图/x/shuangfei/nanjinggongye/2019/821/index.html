南京工业大学 821 自动控制原理 2019 年真题思维导图

强势双非共 6 题合计 150 分

难度：中等　一、填空题十道共15空（45分）加二至六共5道大题；覆盖恒值控制、线性定常判定、反馈对性能影响、奈奎斯特数右半平面极点数、幅频相频、主导极点、最大相位超前角、梅森公式、稳态输出反求指标与顺馈补偿、参数根轨迹、由频率特性反求传函与串联校正、描述函数法自振

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

1~10填空题（共10题）45 分#

思路
  • 十道小题共15个空，覆盖恒值控制、线性定常判定、反馈对动态与稳态性能的影响、由幅相曲线数右半平面极点数、幅频相频表达式、响应模态的决定因素、由脉冲响应反求传函、主导极点与近似响应、最大相位超前角、中频段对动态性能的决定作用。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 由液位保持恒定判断系统属恒值控制系统
本卷实例
  • 关键一步：按给定信号是常量还是变化量分类
  • 中间结果：给定值恒定不变对应恒值控制系统
  • 卡点：括号内已给三个备选项需三选一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过由液位保持恒定判断系统属恒值控制系统
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把恒值控制与随动控制的概念混淆
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
传递函数的定义与基本性质 传递函数
本卷考法
  • 由微分方程含时变系数判定系统为线性时变系统
本卷实例
  • 关键一步：先用齐次性与叠加性判线性，再看系数是否含时间
  • 中间结果：输入前系数含 cosωt 说明系统是时变系统
  • 卡点：两空分别对应线性与非线性、定常与时变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由微分方程含时变系数判定系统为线性时变系统
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过把时变系数导致的时变性与非线性混为一谈
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

串联、并联与反馈等效 结构图与方框图
本卷考法
  • 分析测速负反馈对超调量、响应速度与稳态误差的影响
本卷实例
  • 关键一步：写出反馈前后闭环特征方程的阻尼比对比
  • 中间结果：附加微分负反馈使阻尼比增大而自然频率不变
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过分析测速负反馈对超调量、响应速度与稳态误差的影响
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过认为引入负反馈会改变系统型别从而改变稳态误差
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅相曲线判断闭环右半平面极点数
本卷实例
  • 关键一步：由曲线包围情况套奈奎斯特公式
  • 中间结果：开环右半平面极点数为零时由半包围次数定右半平面闭环极点数
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环幅相曲线判断闭环右半平面极点数
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过开环含积分环节时未补画无穷大半径圆弧
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

频率特性的物理意义与求法 频域分析
本卷考法
  • 写含纯延迟惯性环节的幅频与相频表达式
本卷实例
  • 关键一步：分母取模得幅频、各环节相角相加得相频
  • 中间结果：延迟环节贡献与频率成正比的滞后相角
  • 卡点：相频要注明角度制
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过写含纯延迟惯性环节的幅频与相频表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过相位中漏掉延迟环节的线性相移项
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

零极点分布与响应模态 传递函数
本卷考法
  • 指出系统时间响应类型由闭环极点决定
本卷实例
  • 关键一步：由闭环特征方程的根判断响应模态
  • 中间结果：特征方程即闭环传函分母，其根为闭环极点
  • 卡点：括号内已给四个备选项需四选一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过指出系统时间响应类型由闭环极点决定
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 本卷考过误认为由开环极点或开环零点决定响应模态
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

  • 中间结果：两项指数对应两个一阶环节之积

通用考法

  • 由实验阶跃响应曲线求传递函数

常见易错

  • 把稳态值当成了增益而漏掉输入幅值

高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 由闭环传函判断主导极点并写近似单位脉冲响应
本卷实例
  • 关键一步：比较各极点实部绝对值，挑出最靠近虚轴的一对
  • 中间结果：高阶系统近似为由主导极点构成的二阶系统
  • 卡点：源文该小题传函分母有OCR粘连
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过由闭环传函判断主导极点并写近似单位脉冲响应
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 本卷考过忽略离虚轴较远的极点仍有一定权重
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

超前校正 系统校正
本卷考法
  • 由超前校正装置传函求最大相位超前角
本卷实例
  • 关键一步：把校正装置化为超前网络标准形式
  • 中间结果：由分度系数代入反正弦公式求最大超前角
  • 卡点：题干只给两个时间常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过由超前校正装置传函求最大相位超前角
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 本卷考过把超前角公式中的分子分母取反
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

开环对数频率特性的绘制 频域分析
本卷考法

本卷实例
  • 关键一步：按低频段精度、中频段动态、高频段抗噪分工记忆

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过判断闭环动态性能主要取决于对数幅频特性的哪一段
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 本卷考过把中频段与低频段的作用颠倒
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求给定输入下的输出
本卷实例
  • 关键一步：先数独立回路并求特征式
  • 中间结果：回路间是否存在不接触关系决定特征式形式

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤

  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求给定输入下的输出
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路找漏或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
