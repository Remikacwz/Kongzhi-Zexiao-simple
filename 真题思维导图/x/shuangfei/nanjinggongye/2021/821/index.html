思路
  • 十道小题以基本概念与简单计算为主：稳准快三要求、积分环节、系统型别、拉氏变换、由闭环传函反求开环判型别、单位阶跃稳态误差、根轨迹起点、相频特性、由误差响应反求参数、最大相位超前角
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 由自动控制原理的基本要求填出稳定性
本卷实例
  • 关键一步：按稳、准、快三条归纳控制系统的性能要求
  • 中间结果：题干已给快速性与准确性，空缺项对应稳定性
  • 卡点：源文该句有OCR噪声，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过由自动控制原理的基本要求填出稳定性
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把快速性、准确性与稳定性三者混淆
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

本卷考法

本卷实例

  • 中间结果：积分环节传递函数为s的负一次方
  • 卡点：源文只留空白待填，未给多余条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤

  • 逐环节写出幅频与相频表达式

通用考法

  • 比较两个系统的时间常数大小
常见易错

传递函数的定义与基本性质 传递函数
本卷考法
  • 由单位负反馈闭环传函反求开环传函并判型别
本卷实例

  • 中间结果：开环传函等于闭环传函与一减闭环传函之比
  • 卡点：源文分母有OCR缺项，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法

  • 由最大超前角公式求 α

  • 写出校正装置传递函数并校验
