传递函数的定义与基本性质 传递函数
本卷考法
  • 由零初始条件判断传递函数定义式
本卷实例
  • 关键一步：回到传递函数定义的原始表述
  • 中间结果：零初始下输出拉氏变换比输入拉氏变换
  • 卡点：选项把信号之比与拉氏变换之比混排
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由零初始条件判断传递函数定义式
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过把输出与输入的方向写反
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

  • 卡点：选项以分贝每十倍频表示，注意符号

  • β=arccos ξ 是极点与负实轴的夹角
步骤

  • 比对系数求出 ωn 与 ξ

  • 按 ξ 的取值判断响应类型
通用考法
