  • 中间结果：液位控制的被控量是液位，目标是保持恒定
  • 卡点：该小题含示意图，需回原卷核对，本图不读图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口

传递函数的定义与基本性质 传递函数
本卷考法
  • 由微分方程最高阶次判断系统阶数
本卷实例
  • 关键一步：比较微分方程两侧的最高阶导数
  • 中间结果：系统阶数由输出侧最高阶导数决定
  • 卡点：输入侧阶次高于输出侧时需按真分式另行处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由微分方程最高阶次判断系统阶数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过只看输入侧阶次而漏掉输出侧最高阶次
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

奈奎斯特判据 稳定性分析
本卷考法
  • 用奈氏判据判断两系统的稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数再数包围临界点的圈数
  • 中间结果：由包围圈数与开环右半平面极点数判断闭环稳定性
  • 卡点：源文第10题印「题干不全」，需回原卷核对两个系统
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈氏判据判断两系统的稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况

  • 开环含有积分环节时未补画无穷大半径圆弧
