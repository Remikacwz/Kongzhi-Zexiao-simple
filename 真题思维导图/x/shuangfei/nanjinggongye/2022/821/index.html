思路

含纯延迟环节的系统稳定性 稳定性分析
本卷考法
  • 由含延迟系统求使系统稳定的延迟时间范围
本卷实例
  • 关键一步：按相频扣除延迟引起的附加相位滞后
  • 中间结果：由相角裕度大于零得到延迟时间的上界
  • 卡点：源文题干用符号写延迟因子，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 延迟环节 e^{-τs} 的幅值为 1、相位为 -τω，只恶化相位
  • 延迟会显著缩小稳定域，τ 越大越难稳定
  • 频域判据需用相位裕度扣除延迟引起的附加滞后
步骤
  • 写出含延迟的开环传递函数
  • 分别求幅值与相位表达式
  • 在相频特性中扣除 τω 的滞后量
  • 按稳定裕度或奈氏判据求临界 τ 或临界 K
通用考法
  • 本卷考过由含延迟系统求使系统稳定的延迟时间范围
  • 求使系统稳定的最大延迟时间
  • 求含延迟系统的临界开环增益
  • 分析延迟对稳定裕度的影响
常见易错
  • 本卷考过把延迟环节当成惯性环节处理
  • 把延迟环节当成惯性环节处理
  • 相位计算时忘记角度与弧度换算

零极点分布与响应模态 传递函数
本卷考法
  • 说明偶极子对系统动态性能是否有影响
本卷实例
  • 关键一步：把偶极子理解为靠得很近的零极点对
  • 中间结果：零极点近似对消后对动态性能影响很小
  • 卡点：源文只有一问，未给具体零极点位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过说明偶极子对系统动态性能是否有影响
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 本卷考过把偶极子与普通零极点同等对待
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

  • 把描述函数当成频率的函数

奈奎斯特判据 稳定性分析
本卷考法
  • 由开环右极点数与包围圈数求闭环右极点数
本卷实例
  • 关键一步：按闭环右极点数等于P加包围圈数的奈氏关系代入
  • 中间结果：包围圈数按逆时针为正、顺时针为负计
  • 卡点：题干P与正负包围圈数均已给出，只需代数相加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环右极点数与包围圈数求闭环右极点数
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过忘记先数开环右半平面极点数P
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

传递函数的定义与基本性质 传递函数
本卷考法
  • 由开环极点与部分闭环极点反求另一闭环极点
本卷实例
  • 关键一步：由开环传函写闭环特征方程并代入已知闭环极点
  • 中间结果：特征方程次数由开环极点个数决定
  • 卡点：已知的是一对共轭闭环极点，剩一个实极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由开环极点与部分闭环极点反求另一闭环极点
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过把开环极点个数与闭环极点个数混为一谈
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

思路

  • 系数有缺项时不补零，直接套用判据

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
