自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 由自动控制系统工作的首要条件填空
本卷实例
  • 关键一步：按闭环控制能正常工作的前提是稳定
  • 中间结果：首要条件是系统必须稳定
  • 卡点：括号内为空白需自主填答
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过由自动控制系统工作的首要条件填空
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把准确性、快速性与稳定性的主次颠倒
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
传递函数的定义与基本性质 传递函数
本卷考法
  • 由微分方程含时变系数判定线性时变系统
本卷实例
  • 关键一步：用齐次性与叠加性判线性
  • 中间结果：输入前系数含 cosωt 说明是时变系统
  • 卡点：两空分别对应线性与时变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由微分方程含时变系数判定线性时变系统
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过把时变性与非线性混为一谈
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

频率特性的物理意义与求法 频域分析
本卷考法
  • 由正弦稳态输出反求一阶微分环节的时间常数
本卷实例
  • 关键一步：由输出幅值与相位算幅频和相频
  • 中间结果：两式联立解出时间常数
  • 卡点：输入频率为给定常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由正弦稳态输出反求一阶微分环节的时间常数
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过把幅值比与相角关系用反
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

通用考法

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 各典型信号的拉氏变换是分析全响应的起点
步骤

  • 对输入取拉氏变换得到该信号的复域形式

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定

  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤

  • 比对系数求出 ωn 与 ξ

奈奎斯特判据 稳定性分析
本卷考法
  • 由奈奎斯特曲线数闭环右半平面极点数
本卷实例
  • 关键一步：由曲线包围情况套奈奎斯特公式
  • 中间结果：开环右半平面极点数为1时纳入公式
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由奈奎斯特曲线数闭环右半平面极点数
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过开环含积分环节时未补画无穷大圆弧
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

稳定裕度 频域分析
本卷考法
  • 分析对数幅频特性右移对剪切频率与相角裕量的影响
本卷实例
  • 关键一步：平移相当于频率轴缩放而幅频形状不变
  • 中间结果：剪切频率随之改变而相角裕度不变
  • 卡点：结论要落到剪切频率与裕度各变不变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过分析对数幅频特性右移对剪切频率与相角裕量的影响
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过把幅频平移与转折频率平移混为一谈
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

超前校正 系统校正
本卷考法
  • 由校正装置传函判断超前滞后并求最大超前角频率与角度
本卷实例
  • 关键一步：把校正装置化为 (1+aTs)/(1+Ts) 标准形式
  • 中间结果：最大超前角出现在两转折频率的几何中点
  • 卡点：最大超前角用反正弦公式求
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过由校正装置传函判断超前滞后并求最大超前角频率与角度
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 本卷考过把最大超前角频率与转折频率几何中心记错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
