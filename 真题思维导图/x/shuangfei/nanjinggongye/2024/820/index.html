一控制系统组成与开环闭环判断#

思路
  • 由转台转速控制示例指认被控对象、执行机构与控制器，判断控制方式，并说明提高精度的措施与相应框图
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 由示例指认被控对象、执行机构与控制器并判断控制方式
本卷实例
  • 关键一步：从被控量出发沿信号流向前后指认各环节
  • 中间结果：转台转速是被控量，电机是执行机构，直流放大器是控制器
  • 卡点：判断开环或闭环看有无被控量的反馈通道
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过由示例指认被控对象、执行机构与控制器并判断控制方式
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
减小稳态误差的措施 稳态误差
本卷考法
  • 说明提高系统准确精度的方法并画对应框图
本卷实例
  • 关键一步：增加测速装置把被控量反馈回去构成闭环
  • 中间结果：闭环可减小前向通道参数变化带来的误差
  • 卡点：只答措施不画框图会漏答一半
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过说明提高系统准确精度的方法并画对应框图
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

电路网络与有源网络建模 建模与机电系统
本卷考法

  • 中间结果：两网孔通过公共支路电流相互耦合
  • 卡点：电路以图给出，元件连接与网孔划分需回原卷核对图

多回路系统的逐层化简 结构图与方框图
本卷考法
  • 用结构图等效变换求输出对输入的传函
本卷实例
  • 关键一步：按信号流向逐层化简比较点与反馈支路
  • 中间结果：化简后分母由各回路时间常数组合而成
  • 卡点：化简内环时不能把外环信号当成常数处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法

  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 用信号流图与梅森公式求传函
本卷实例
  • 关键一步：找出各回路、两两互不接触回路与前向通路
  • 中间结果：特征式含互不接触回路的乘积项
  • 卡点：余子式中与通路接触的回路要剔除
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用信号流图与梅森公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

三三阶系统稳定性、指定极点与阶跃响应#

思路
  • 由结构图写闭环传函与特征方程，用劳斯判据求参数稳定范围；再由指定闭环特征根反求参数、分解出其余根，最后求单位阶跃响应
劳斯判据 稳定性分析
本卷考法
  • 由三阶特征方程用劳斯判据求参数稳定范围
本卷实例
  • 关键一步：写特征多项式并列劳斯表，令首列元素同号
  • 中间结果：由首列不等式解出参数的下界
  • 卡点：劳斯表首列含参时要单独讨论符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由三阶特征方程用劳斯判据求参数稳定范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 由已知一个闭环极点求其余极点
本卷实例
  • 关键一步：把已知根对应的一次因子从特征多项式除出来
  • 中间结果：余下的二次因子直接给出另外两个根
  • 卡点：分解前须先用已知根把参数解出来
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过由已知一个闭环极点求其余极点
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 求闭环系统的单位阶跃响应时域表达式
本卷实例
  • 关键一步：把闭环传函展开为部分分式再逐项反变换
  • 中间结果：阶跃响应含常数项与三个衰减指数项
  • 卡点：部分分式系数须与各极点一一对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过求闭环系统的单位阶跃响应时域表达式
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

四参数根轨迹与动态性能分析#

思路
  • 把开环传函含参数a的项整理成等效开环传函，按180度参数根轨迹法则绘制轨迹，再由轨迹走向分析a变化对动态性能的影响
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 把含参数a的方程整理成参数根轨迹形式
本卷实例
  • 关键一步：把含a的项归并成a乘某等效开环传函
  • 中间结果：等效开环传函的零点与极点决定轨迹形状
  • 卡点：参数根轨迹仍按180度相角条件绘制
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过把含参数a的方程整理成参数根轨迹形式
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制参数根轨迹的起点、实轴段与渐近线
本卷实例
  • 关键一步：先定等效开环极点、零点与实轴上的根轨迹段
  • 中间结果：轨迹起于等效开环极点，止于零点或无穷远
  • 卡点：实轴段判据要数右侧零极点的个数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制参数根轨迹的起点、实轴段与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹分析参数变化对动态性能的影响
本卷实例
  • 关键一步：由闭环极点在实轴或复平面的分布判断响应形式
  • 中间结果：极点离虚轴越远，系统响应越快
  • 卡点：闭环极点全部位于左半平面系统才稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹分析参数变化对动态性能的影响
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

五奈氏判据求K与T范围#

思路
  • 由开环传函写幅频与相频，先求相位穿越频率与临界幅值，再分别固定T、固定K或两者同时变化，用奈氏判据列稳定条件求参数范围
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈氏判据求闭环稳定时K或T的取值范围
本卷实例
  • 关键一步：由相频为负180度定穿越频率，再代入幅频
  • 中间结果：临界幅值等于一，据此写出参数不等式
  • 卡点：含积分环节的幅相曲线要补画无穷大圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P

稳定裕度 频域分析
本卷考法
  • 由对数幅频条件求截止频率与相角裕度
本卷实例
  • 关键一步：由幅频为零分贝定截止频率，再累加各环节相角
  • 中间结果：相角裕度等于180度加截止频率处的相角
  • 卡点：截止频率与相位穿越频率易用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由对数幅频条件求截止频率与相角裕度
  • 求系统的相角裕度与幅值裕度

  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

思路
  • 画线性部分的奈氏图，求非线性环节的负倒描述函数曲线，由两曲线交点判断是否存在自振，并联立方程求参数a的范围
描述函数法基础 非线性系统
本卷考法
  • 由非线性环节描述函数求负倒描述函数
本卷实例
  • 关键一步：把描述函数取倒数再加负号，分析A变化时的走向
  • 中间结果：负倒描述函数随A单调变化，端点对应A趋于0与无穷
  • 卡点：判断自振要画负倒描述函数而不是描述函数本身
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过由非线性环节描述函数求负倒描述函数
  • 求饱和、死区、继电特性等典型非线性的描述函数

  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

本卷考法

本卷实例
