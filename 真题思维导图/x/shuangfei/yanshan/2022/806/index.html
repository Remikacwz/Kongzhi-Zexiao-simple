1直流电动机调速系统分析#

思路
  • 先明确被控制的是转速；结构框图按「给定-比较-放大-变换器-电动机-测速反馈」画；第 3 问考的是有静差系统必然存在偏差
转速负反馈单闭环调速系统 电力拖动与运动控制
本卷考法
  • 指出系统的被控制物理量
  • 画出系统结构框图
  • 说明稳态时偏差不为零的原因
本卷实例
  • 关键一步：先锁定被控量是电动机转速、反馈量是测速电压
  • 关键一步：按给定、比较、放大、变换器、电动机、反馈的顺序连结构图
  • 关键一步：由比例调节器的有差特性说明偏差须存在
  • 中间结果：稳态偏差电压用于维持调节器输出
  • 卡点：原卷系统图为插图未读，环节顺序与反馈点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 被控量是转速，反馈量是测速发电机输出电压
  • 属于有差系统，稳态时偏差 e=U_n*−U_n 必须不为零才能维持输出
  • 闭环后稳态速降减小为开环的 1/(1+K) 倍
  • 闭环放大倍数 K 越大，静差率越小，但稳定性越差
步骤
  • 确定被控制量与反馈量
  • 按信号流向画出给定、比较、放大、变换器、电动机、测速反馈各环节
  • 写出稳态关系式并求闭环静特性
  • 比较开环与闭环的稳态速降
通用考法
  • 本卷考过指出系统的被控制物理量
  • 本卷考过画出系统结构框图
  • 本卷考过说明稳态时偏差不为零的原因
  • 指出系统的被控量与反馈量
  • 画出系统结构框图
  • 解释稳态时偏差不为零的原因
  • 计算闭环稳态速降并比较开环
常见易错
  • 误以为有差系统稳态可以做到零偏差
  • 把被控量与反馈量混为一谈
  • 求闭环静特性时漏掉 (1+K) 因子

4相对稳定度与临界振荡#

思路
  • G(s)=Ks/24/(s(s²/24+10s/24+1))；持续振荡＝特征根在虚轴；「全在 s=-1 左侧」= 做 s=z-1 平移后用劳斯判据
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求产生持续振荡时的振荡频率与开环放大倍数
本卷实例
  • 关键一步：把闭环特征方程按降幂排列并列劳斯表
  • 关键一步：令首列某元素为零求临界增益，再解辅助方程得振荡频率
  • 中间结果：临界点对应一对纯虚根，辅助方程给出频率平方
  • 卡点：只代一个频率会漏掉另一组交点，虚轴交点要成对取
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求产生持续振荡时的振荡频率与开环放大倍数
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 本卷考过只代一个 ω 漏掉另一组交点
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求闭环极点全在 s=-1 垂直线左侧时 K 的范围
本卷实例
  • 关键一步：令 s 等于 z 减一作坐标平移，把边界移到虚轴
  • 关键一步：对平移后的特征多项式列劳斯表，令首列同号
  • 中间结果：平移后常数项与一次项都含 K，两个不等式取交集
  • 卡点：直接对原特征方程用劳斯判据会得到错误的 K 范围
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求闭环极点全在 s=-1 垂直线左侧时 K 的范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 本卷考过直接对原特征方程用劳斯判据而未作坐标平移
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

5由对数幅频特性反求参数#

思路
  • 把结构框图与渐近对数幅频特性对应起来：低频段高度定增益，转折频率与环节时间常数一一对应
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由结构框图与对数幅频特性曲线确定 K1、K2、T1、T2
本卷实例
  • 关键一步：把结构图化简约成开环传函，再与渐近对数幅频对应
  • 关键一步：低频段高度定增益，转折频率定时间常数
  • 中间结果：开环可整理成含一个积分与二阶环节的标准形式
  • 卡点：斜率变化负四十不能当成一阶；框图与幅频图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由结构框图与对数幅频特性曲线确定 K1、K2、T1、T2
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 本卷考过斜率变化为 -40 时直接写成一阶环节
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

开环对数频率特性的绘制 频域分析
本卷考法
  • 由转折频率读各环节时间常数
本卷实例
  • 关键一步：在每个转折频率处看斜率变化量判断环节类型
  • 中间结果：负二十对应惯性环节，正二十对应一阶微分环节
  • 卡点：转折频率与时间常数互为倒数；转折频率需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过由转折频率读各环节时间常数
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

6超调与误差反求参数及补偿#

思路
  • KR=0 时系统等价于给定结构，先由 σp=16.3% 反求 ξ、由斜坡 ess=0.25 反求增益；再设计 KR 使斜坡误差为零
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由最大超调量 16.3% 反求阻尼比
本卷实例
  • 关键一步：把最大超调量公式反解，得到含阻尼比的超越方程
  • 关键一步：由工程常用取值范围判断应取的阻尼比
  • 中间结果：超调量只与阻尼比有关，与自然频率无关
  • 卡点：超调量公式右边是百分数，别漏乘；结构图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由最大超调量 16.3% 反求阻尼比
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过超调量公式中漏乘 100%
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由 r(t)=t 时 ess=0.25 反求 Kr 和 K
本卷实例
  • 关键一步：由闭环特征式与标准二阶对照，用超调量先定阻尼比
  • 关键一步：再由斜坡误差系数与稳态误差条件反求参数
  • 中间结果：斜坡误差等于输入幅值除以速度误差系数
  • 卡点：未判稳不能用终值定理；系统结构图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由 r(t)=t 时 ess=0.25 反求 Kr 和 K
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过未判稳就用终值定理
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

反馈校正与复合控制 系统校正

思路

根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制系统根轨迹并标注关键点
本卷实例

本卷考法

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过计算校正后系统的相角裕度
  • 求系统的相角裕度与幅值裕度

  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
