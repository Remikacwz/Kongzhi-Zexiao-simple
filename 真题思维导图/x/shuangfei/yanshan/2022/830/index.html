1方框图求系统传递函数#

思路
  • 已知系统框图，用梅森公式或逐层化简求 C(s)/R(s)
梅森增益公式与信号流图 传递函数
本卷考法
  • 由系统框图用梅森增益公式求闭环传递函数
本卷实例
  • 关键一步：从框图数出独立回路、两两不接触回路和前向通路
  • 中间结果：按特征式和各前向通路余子式写出总传输
  • 卡点：本题系统框图以图给出，回路与通路需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由系统框图用梅森增益公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 逐层化简多回路系统框图
本卷实例
  • 关键一步：由最内层回路向外逐级求等效传递函数
  • 中间结果：内环等效后再参与外层串并联化简
  • 卡点：结构图以图给出，化简层级需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过逐层化简多回路系统框图
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2由特征方程反求传函与性能指标#

思路
  • D(s)=s³+9s²+18s+K₁：求无零点 I 型开环传函与根轨迹；给定实极点求超调量与时间指标；由阻尼比与误差上界定参数
系统型别与静态误差系数 稳态误差
本卷考法
  • 由闭环特征方程反求无零点 I 型系统的开环传函
本卷实例
  • 关键一步：I 型无零点系统的开环分母对应特征式去掉常数项
  • 中间结果：开环传函为常增益除以含三个极点的分母
  • 卡点：开环极点由特征方程因式分解得到，注意零是其中一个
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由闭环特征方程反求无零点 I 型系统的开环传函
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制根轨迹增益由零到正无穷时的根轨迹
本卷实例
  • 关键一步：标出开环极点并判断实轴上的根轨迹段
  • 中间结果：渐近线交点和夹角由极点个数与位置算出
  • 卡点：实轴段判据要数该段右侧零极点总数为奇数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制根轨迹增益由零到正无穷时的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由给定闭环极点求最大超调量与调节时间等指标
本卷实例
  • 关键一步：先判断主导极点，把高阶系统降阶为二阶
  • 中间结果：由降阶后的二阶系统读出阻尼比和自然频率
  • 卡点：调节时间要区分百分之五和百分之二两种误差带
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由给定闭环极点求最大超调量与调节时间等指标
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由斜坡输入下的稳态误差上界反求参数
本卷实例
  • 关键一步：I 型系统的速度误差系数等于开环增益除以常数
  • 中间结果：由误差不等式得到参数的下界
  • 卡点：斜坡误差不要套成阶跃输入的位置误差公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由斜坡输入下的稳态误差上界反求参数
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 用劳斯判据求参数的稳定上界
本卷实例
  • 关键一步：列劳斯表并令首列各元素大于零
  • 中间结果：由不等式组得到参数的稳定区间
  • 卡点：稳定域还要与误差要求取交集
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过用劳斯判据求参数的稳定上界
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

奈奎斯特判据 稳定性分析
本卷考法
  • 绘制奈奎斯特图并标注两处穿越频率与稳定裕度
本卷实例
  • 关键一步：写出开环幅相表达式，二重积分环节使起点相角为负 180 度
  • 中间结果：随频率增大幅值趋于零而相角继续下降
  • 卡点：含二重积分环节要补画无穷大半径圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过绘制奈奎斯特图并标注两处穿越频率与稳定裕度
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
稳定裕度 频域分析
本卷考法
  • 求系统稳定时开环增益的取值范围
本卷实例
  • 关键一步：由幅值裕度大于一或劳斯表首列条件列增益不等式
  • 中间结果：两种方法得到不同上界时应取更严格的那个
  • 卡点：答案段指出奈奎斯特法所得范围更小，两法不一致要取交集
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求系统稳定时开环增益的取值范围
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

4组合系统的状态空间与能控能观#

思路
  • 两个 SISO 子系统反馈连接（图给出）：列组合状态空间表达式、判能控能观、求传递函数
状态空间表达式的建立 状态空间分析
本卷考法
  • 由两个子系统的反馈连接列写组合状态空间表达式
本卷实例
  • 关键一步：按反馈关系把中间输入代入各自状态方程消元
  • 中间结果：组合系统的矩阵呈按子系统分块的形式
  • 卡点：本题反馈连接以图给出，连接极性需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由两个子系统的反馈连接列写组合状态空间表达式
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式
能控性与能观性 状态空间分析
本卷考法
  • 判断组合系统的能控性与能观性
本卷实例
  • 关键一步：分别构造能控与能观判别矩阵并求秩
  • 中间结果：两个判别矩阵都满秩说明既完全能控又完全能观
  • 卡点：能控和能观判别矩阵的构造方式不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断组合系统的能控性与能观性
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由状态空间表达式求系统的传递函数
本卷实例
  • 关键一步：用输出矩阵左乘状态矩阵的逆再右乘输入矩阵
  • 中间结果：先算状态矩阵的逆再按顺序相乘
