1第一题 选择题（基本要求与根轨迹）12 分#

思路
  • 逐项判断自动控制系统基本要求、根轨迹与稳定性、开环增益对性能的影响、能控系统与能观的关系。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出自动控制系统的基本要求
本卷实例
  • 关键一步：按稳定性准确性快速性三点逐项对应
  • 中间结果：基本要求为稳准快且稳定优先
  • 卡点：选项以原卷文字为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指出自动控制系统的基本要求
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把稳准快三项要求的含义混淆
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 由根轨迹所在半平面判断系统稳定性
本卷实例
  • 关键一步：根轨迹在左半平面即闭环极点实部为负
  • 中间结果：根轨迹全在左半平面时系统稳定
  • 卡点：零度根轨迹的判据不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过由根轨迹所在半平面判断系统稳定性
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 本卷考过把相角条件的 180 度写成 0 度
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

开环对数频率特性的绘制 频域分析
本卷考法
  • 分析增大开环增益对系统性能的影响
本卷实例
  • 关键一步：由低频段高度判断增益与稳态精度关系
  • 中间结果：增益增大提高精度但降低稳定性
  • 卡点：需结合具体开环传函判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过分析增大开环增益对系统性能的影响
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 本卷考过认为增益增大只会变好
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

能控性与能观性 状态空间分析
本卷考法
  • 判断能控系统与能观系统的关系
本卷实例
  • 关键一步：由对偶原理理解能控与能观的对应关系
  • 中间结果：能控与能观一般互不蕴含
  • 卡点：需结合对偶系统判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断能控系统与能观系统的关系
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 本卷考过认为能控就一定能观
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

思路

典型环节及其特性 传递函数
本卷考法
  • 简述控制系统常见的五种数学模型
本卷实例
  • 关键一步：按时域频域与状态空间分类列举
  • 中间结果：五种模型之间可相互转换
  • 卡点：需说明各自的区别与联系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过简述控制系统常见的五种数学模型
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 本卷考过把微分方程与传函当成两种独立模型
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减

3第三题 二阶系统阻尼比与动态性能#

思路
  • 由闭环极点阻尼比要求列特征方程解出开环增益，再按二阶公式求超调量与峰值时间。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由阻尼比要求确定结构参数
本卷实例
  • 关键一步：写闭环特征方程并与二阶标准形式对照
  • 中间结果：阻尼比条件给出结构参数的关系式
  • 卡点：开环增益与根轨迹增益的换算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由阻尼比要求确定结构参数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过化为标准形式时未归一化二次项系数
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比求超调量与峰值时间
本卷实例
  • 关键一步：先由阻尼比求超调量再由自然频率求峰值时间
  • 中间结果：超调量只与阻尼比有关
  • 卡点：峰值时间随自然频率变化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比求超调量与峰值时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过超调量公式中漏乘 100 percent
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由性能指标要求反求开环增益
本卷实例
  • 关键一步：用阻尼比条件解出增益再回代校验
  • 中间结果：给定阻尼比对应唯一增益
  • 卡点：需确认该增益下闭环为主导二阶

  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由性能指标要求反求开环增益
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 本卷考过只满足单项指标就下结论
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 用根轨迹等阻尼线理解本题
本卷实例
  • 关键一步：由等阻尼线确定闭环复极点位置
  • 中间结果：共轭复极点实部虚部与阻尼比相关
  • 卡点：由极点位置估指标时忽略零点作用

  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上

  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能

  • 本卷考过用根轨迹等阻尼线理解本题
  • 求满足给定阻尼比的参数值

  • 分析提高增益对性能的影响
常见易错
  • 本卷考过把等阻尼线画成垂直线
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

4第四题 由频率响应反求传函与稳态误差#

思路
  • 由正弦输入的幅值比与相角差写出频率特性，反求闭环传函，再求稳态误差与阶跃下的超调量。
频率特性的物理意义与求法 频域分析
本卷考法
  • 由正弦稳态输出的幅值与相角求频率特性
本卷实例
  • 关键一步：用幅值比得幅频相角差得相频
  • 中间结果：某一频率处的幅值与相角确定一个复数值
  • 卡点：需先判断系统为线性定常
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
