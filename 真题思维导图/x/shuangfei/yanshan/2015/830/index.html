1一、状态空间与频域综合简答#

思路
  • 4 小问简答：状态空间与传递函数模型的关系、开环频域性能指标与串联超前校正的改善作用、输出反馈能否任意配置极点、状态空间结构分解的目的。
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 比较状态空间模型与传递函数模型的异同
本卷实例
  • 关键一步：从外部输入输出描述与内部状态描述两方面对比
  • 中间结果：传递函数只反映零初始外部特性，状态空间含内部状态
  • 卡点：只答能控能观而不点明两者描述角度不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过比较状态空间模型与传递函数模型的异同
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消
公式
稳定裕度 频域分析
本卷考法
  • 列举开环频域性能指标并说明超前校正的作用
本卷实例
  • 关键一步：按剪切频率、相角裕度、幅值裕度分条列举
  • 中间结果：超前校正抬高中频段相角从而提高相角裕度
  • 卡点：漏答幅值裕度或把对高频噪声的影响说反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过列举开环频域性能指标并说明超前校正的作用
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
超前校正 系统校正
本卷考法
  • 说明串联超前校正改善动态性能的机理
本卷实例
  • 关键一步：用超前网络在剪切频率附近提供正相角
  • 中间结果：相角裕度提高后超调量与调节时间下降
  • 卡点：未指出截止频率上移会降低抗高频噪声能力
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过说明串联超前校正改善动态性能的机理
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
状态反馈与极点配置 状态空间分析
本卷考法
  • 回答输出反馈能否任意配置极点并说明原因
本卷实例
  • 关键一步：对比状态反馈与输出反馈可调参数的个数
  • 中间结果：状态反馈可任意配置极点，输出反馈一般只能沿根轨迹族改变
  • 卡点：误答输出反馈完全不能改变闭环极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过回答输出反馈能否任意配置极点并说明原因
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
公式
能控性与能观性 状态空间分析
本卷考法
  • 说明状态空间结构分解的目的
本卷实例
  • 关键一步：按能控性与能观性把状态空间分为四个子空间
  • 中间结果：分出能控能观、能控不能观、不能控能观与其余部分
  • 卡点：只答能控性分解而漏掉能观性分解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过说明状态空间结构分解的目的
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式

2二、RC 网络方框图与传递函数#

思路
  • 由图 1 的无源 RC 网络列电流电压关系，画出方框图并用梅森公式求以 u_r 为输入、u_C 为输出的传递函数。
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由无源 RC 网络求传递函数
本卷实例
  • 关键一步：对电容取 1/(sC) 复阻抗并按节点列电流方程
  • 中间结果：以各支路电压为中间变量可整理出输入输出关系
  • 卡点：网络拓扑与元件连接方式需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由无源 RC 网络求传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求多回路方框图的传递函数
本卷实例
  • 关键一步：由方框图数出独立回路、不接触回路与前向通路
  • 中间结果：特征式由一减各回路和加不接触回路积构成
  • 卡点：回路与前向通路的接触关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求多回路方框图的传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

3三、状态反馈镇定与状态观测器#

思路
  • 已知二阶线性系统的状态矩阵、输入矩阵与输出矩阵：第 1 问判断能否用状态反馈镇定此系统并说明理由，第 2 问设计状态观测器重构状态。
能控性与能观性 状态空间分析
本卷考法
  • 由能控性判别矩阵判断能否镇定系统
本卷实例
  • 关键一步：构造能控性判别矩阵并计算它的秩
  • 中间结果：不完全能控时再看不能控模态是否已落在左半平面
  • 卡点：把能控与能镇定混为一谈，漏判不能控子系统稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过由能控性判别矩阵判断能否镇定系统
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
状态观测器设计 状态空间分析
本卷考法
  • 设计状态观测器重构状态
本卷实例
  • 关键一步：对偶系统作极点配置求观测器增益阵
  • 中间结果：观测器误差方程的特征值由配置极点确定
  • 卡点：观测器增益阵与状态反馈增益阵的构造方向易混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态观测器用输出与输入重构状态，前提是系统能观
  • 极点配置法与龙伯格观测器是两种常用形式
  • 观测器误差动态由 A-LC 的特征值决定
  • 观测器极点通常取得比系统极点快若干倍
步骤
  • 验证系统能观性
  • 写出观测器方程并求误差动态矩阵
  • 按期望特征多项式比较系数求出 L
  • 校验观测器收敛速度是否合适
通用考法
  • 本卷考过设计状态观测器重构状态
  • 设计全维状态观测器
  • 由期望观测器极点求反馈增益阵 L
  • 分析观测器与状态反馈组合后的系统极点
常见易错
  • 把观测器增益阵写成了状态反馈增益阵的形式
  • 忽略观测器极点过快会放大噪声

4四、由幅频特性确定串联校正装置#

思路
  • 图 2 同时给出校正前（虚线）与校正后（实线）的开环对数幅频特性，先辨识校正前开环，再相除得校正装置并判别其类型。
期望特性法与综合法 系统校正
本卷考法
  • 由校正前后特性反写校正装置传递函数
本卷实例
  • 关键一步：由各转折频率与斜率变化写出校正前后传函
  • 中间结果：校正装置传函等于校正后开环除以校正前开环
  • 卡点：转折频率与增益变化量需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 期望特性法直接按指标画出希望的开环对数幅频特性
  • 用期望特性减去未校正特性得到校正装置特性
  • 关键是确定低频段高度、中频段宽度与高频段斜率
  • 中频段斜率一般取 -20 dB/dec 并保持足够宽度
步骤
  • 按稳态要求确定低频段斜率与高度
  • 按相角裕度要求确定中频段宽度与截止频率
  • 按抗噪要求确定高频段斜率
  • 相减求得校正装置并检验可实现性
通用考法
  • 本卷考过由校正前后特性反写校正装置传递函数
  • 用期望特性法设计校正装置
  • 说明中频段宽度与相角裕度的关系
  • 由校正装置特性反写传递函数
常见易错
  • 期望特性的中频段取窄导致裕度不足
  • 相减后得到的特性不可物理实现却未检查
公式
滞后-超前校正 系统校正
本卷考法
  • 判别校正装置类型并说明其作用
本卷实例
  • 关键一步：比较校正装置低频段与高频段的幅频特征
  • 中间结果：兼具超前与滞后特征即判为滞后-超前校正
  • 卡点：只凭相角符号判断而漏看幅频分段
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 兼顾稳态精度与动态性能，适合指标要求较高的场合
  • 低频段用滞后部分提高增益，中高频段用超前部分提高裕度
  • 设计时先确定超前部分，再确定滞后部分
步骤
  • 按稳态精度要求确定开环增益
  • 选择新的截止频率并计算超前部分参数
  • 计算为把低频增益抬到要求值所需的滞后部分参数
  • 合并写出校正装置并校验
通用考法
  • 本卷考过判别校正装置类型并说明其作用
  • 设计滞后-超前校正装置
  • 说明为何单一校正无法满足指标
  • 分析校正后系统的低频与高频特性
常见易错
  • 先设计滞后部分导致截止频率反复调整
  • 两部分的转折频率分布重叠，互相削弱
公式

5五、开环 Bode 图判稳与正弦稳态误差#

思路
  • 图 3 给出最小相位开环对数幅频渐近线：第 1 问判稳并求相角裕度，第 2 问求正弦输入下的稳态误差，第 3 问绘奈奎斯特曲线并标出相角裕度。
开环对数频率特性的绘制 频域分析
本卷考法
  • 由渐近线反写开环传递函数并求剪切频率
本卷实例
  • 关键一步：按低频段斜率高与各转折频率逐段改斜率
  • 中间结果：由幅值为 1 的条件求剪切频率
  • 卡点：逐段改斜率时忘累加而写成替换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线

  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根之和确定第三个极点并反求开环增益
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

本卷考法
  • 由闭环极点求超调量与峰值时间
本卷实例
  • 关键一步：由共轭极点读出阻尼比与自然频率
  • 中间结果：按二阶欠阻尼公式计算超调量与峰值时间
  • 卡点：峰值时间与上升时间公式混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由闭环极点求超调量与峰值时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
