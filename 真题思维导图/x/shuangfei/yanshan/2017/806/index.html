1填空题：传函定义与时频基本概念15 分#

思路
  • 五个空分别考传函定义、由脉冲响应求传函、响应组成、系统型别与阶数、串联校正环节的类型与相角极值。
传递函数的定义与基本性质 传递函数
本卷考法
  • 写出零初始条件下传递函数的定义
本卷实例
  • 关键一步：把定义写成输出与输入拉氏变换之比
  • 中间结果：该定义只在零初始条件下成立
  • 卡点：概念题，直接考定义与其成立前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过写出零初始条件下传递函数的定义
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过漏掉零初始条件这一前提
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
由响应曲线反求传递函数 传递函数
本卷考法

本卷实例
  • 关键一步：先用拉氏变换把脉冲响应化为闭环传递函数
  • 中间结果：再由前向传函与闭环传函的关系反解
  • 卡点：本题脉冲响应表达式 OCR 残缺，须回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤

  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法

  • 由实验阶跃响应曲线求传递函数

常见易错

  • 把稳态值当成了增益而漏掉输入幅值

线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 说明线性系统时域响应的组成部分
本卷实例
  • 关键一步：按无输入时的初值响应与输入引起的响应划分
  • 中间结果：时域响应由瞬态分量与稳态分量两部分组成
  • 卡点：两空分别对应瞬态与稳态，勿与自由强迫混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过说明线性系统时域响应的组成部分
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 本卷考过把瞬态稳态与自由强迫两组概念混用
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

超前校正 系统校正
本卷考法
  • 判断串联超前环节并求相角极值频率
本卷实例
  • 关键一步：把环节化成标准超前形式读出衰减系数与时间常数
  • 中间结果：相角极值出现在两个转折频率的几何中点
  • 卡点：几何中点频率用两个转折频率之积开方求
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过判断串联超前环节并求相角极值频率
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 本卷考过把时间常数与衰减系数对应错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

3方框图求传递函数（原卷有图）#

思路
  • 用梅森公式：先数独立回路并判断是否互不接触，再写各前向通路及其余子式，最后求输入到输出的传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求方框图传递函数
本卷实例
  • 关键一步：先写出全部独立回路，再判断有无互不接触回路
  • 中间结果：特征式等于一减去各回路增益之和
  • 卡点：前向通路要与回路逐条比对是否接触
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤

  • 找出全部单独回路，求特征式 Δ

通用考法

  • 由信号流图求 C(s)/R(s)

  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路找漏或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

4根轨迹绘制与无超调增益范围#

思路
  • 由开环零极点按法则绘根轨迹，用相角条件判定给定复点是否在轨迹上，再由分离点确定无超调无振荡的增益范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画根轨迹的实轴段与渐近线
本卷实例
  • 关键一步：先标出开环零极点并求渐近线交点与夹角
  • 中间结果：实轴根轨迹段在零极点交替区间的左侧
  • 卡点：该题只有一条趋向无穷远的根轨迹
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画根轨迹的实轴段与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过渐近线条数与夹角算错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 用相角条件判断给定复点是否在根轨迹上
本卷实例
  • 关键一步：把给定点的各个开环零极点矢量相角求和
  • 中间结果：相角和等于奇数倍 180 度则在轨迹上
  • 卡点：点在轨迹上时再由幅值条件定增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过用相角条件判断给定复点是否在根轨迹上
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 本卷考过相角条件中对零点与极点符号取反
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

分离点与会合点 根轨迹法
本卷考法
  • 求分离点并由此定无超调增益边界
本卷实例
  • 关键一步：由分离点方程解出候选点再回特征方程求增益
  • 中间结果：分离点对应的增益是无超调与振荡的分界
  • 卡点：要注意两个分离点给出两段增益区间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤

奈奎斯特判据 稳定性分析
本卷考法
  • 画奈奎斯特图并在图上标出相角裕度
本卷实例
  • 关键一步：把开环传函写成实部与虚部再求起点与终点

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过画奈奎斯特图并在图上标出相角裕度
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过起点幅值与相角对应关系写反
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

超前校正 系统校正
本卷考法
  • 保持剪切频率不变设计超前校正参数
本卷实例
  • 关键一步：由要求的相角裕度算所需最大超前角
  • 中间结果：最大超前角频率与时间常数由几何中点关系定
  • 卡点：剪切频率不变意味着该频率处幅值仍为一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过保持剪切频率不变设计超前校正参数
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 本卷考过补偿角未计入原系统在剪切频率处的相角
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

稳定裕度 频域分析
本卷考法
  • 校验校正后相角裕度是否达到要求
本卷实例
  • 关键一步：把校正后开环传函在剪切频率处求相角
  • 中间结果：校正后相角裕度应不小于给定要求
  • 卡点：幅值条件与相角条件要同时满足
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过校验校正后相角裕度是否达到要求
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过校验时仍用校正前的截止频率
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
