1一、由模拟结构图列状态空间表达式#

思路
  • 图 1 给定系统的模拟结构图，取图中积分器输出为状态变量，列写一阶微分方程组并整理成状态空间表达式。
状态空间表达式的建立 状态空间分析
本卷考法
  • 由模拟结构图列写状态空间表达式
本卷实例
  • 关键一步：每个积分器输出取一个状态变量并写一阶方程
  • 中间结果：消去中间变量后整理成 A、B、C 矩阵
  • 卡点：模拟结构图以图给出，连接系数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由模拟结构图列写状态空间表达式
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式
直流电机等机电系统 建模与机电系统
本卷考法
  • 对含电机与机械环节的系统建模
本卷实例
  • 关键一步：按图识别转动惯量、反馈系数等参数与耦合关系
  • 中间结果：系统矩阵中出现转动惯量与其他系数之比
  • 卡点：机电耦合项与反馈项的正负号需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由电枢回路电压方程与转矩平衡方程联立
  • 反电动势与转速成正比，电磁转矩与电枢电流成正比
  • 机电时间常数由电气与机械两方面参数共同决定
步骤
  • 写出电枢回路电压平衡方程
  • 写出转矩平衡方程（含负载与粘性摩擦）
  • 消去电枢电流，得到转速或转角对电压的传递函数
通用考法
  • 本卷考过对含电机与机械环节的系统建模
  • 求直流电机转速或位置对电枢电压的传递函数
  • 分析机电时间常数与电气时间常数的数量级关系
常见易错
  • 漏掉反电动势与电磁转矩的耦合项
  • 把电气时间常数与机电时间常数混淆

2二、结构图求闭环传函#

思路
  • 图 2 结构图：数出独立回路、判断两两不接触关系与前向通路，用梅森公式求闭环传递函数 C(s)/R(s)。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求多回路系统的闭环传函
本卷实例
  • 关键一步：先数全部独立回路并检查两两不接触回路
  • 中间结果：特征式为一减各回路和加不接触回路积
  • 卡点：回路之间的接触关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求多回路系统的闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图的等效化简
本卷实例
  • 关键一步：从最内层回路逐级向外作等效
  • 中间结果：每化简一层得到更简单的等效结构
  • 卡点：移动比较点或引出点时乘除关系易反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图的等效化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

3三、PI 控制系统的劳斯判据与稳态误差#

思路
  • 图 3 的 PI 控制系统，已知 ξ=0.2、ωn=86.6：第 1 问用劳斯判据求稳定时 K1 范围，第 2 问求闭环极点全在 s=-1 垂线之左的 K1 范围，第 3 问求抛物线输入下的稳态误差。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求参数稳定范围
本卷实例
  • 关键一步：由闭环特征方程列劳斯表并令首列全为正
  • 中间结果：由首列不等式解出 K1 的上下限
  • 卡点：系数有缺项时不补零而直接套用判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求参数稳定范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求闭环极点全位于某垂线之左的参数范围
本卷实例
  • 关键一步：作坐标平移把垂线边界移到虚轴
  • 中间结果：对平移后的特征方程再用劳斯判据
  • 卡点：平移方向写反会得到相反的参数范围
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求闭环极点全位于某垂线之左的参数范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求抛物线输入下的稳态误差
本卷实例
  • 关键一步：先判稳再用终值定理与静态加速度误差系数
  • 中间结果：系统型别不足时稳态误差为无穷大
  • 卡点：输入为 t²/2 时漏掉系数二分之一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求抛物线输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

4四、根轨迹绘制与稳定参数范围#

思路
  • 开环传函 2K*/[s(s+1)(s+2)]：第 1 问绘制根轨迹图，第 2 问确定系统稳定时 K* 的取值范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制三阶系统根轨迹
本卷实例
  • 关键一步：先定开环零极点、渐近线与实轴段
  • 中间结果：三条分支分别起于 0、-1、-2 并趋向无穷远
  • 卡点：渐近线夹角公式中 2k+1 与 2k 易写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制三阶系统根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界增益
本卷实例
  • 关键一步：令特征方程中 s=jω 并分离实部虚部
  • 中间结果：由虚轴交点得临界 K* 与等幅振荡频率
  • 卡点：漏掉另一组对称交点导致范围不全
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式

5五、奈奎斯特判据分析稳定性#

思路
  • 开环传函 K(-τs+1)/[s(Ts+1)]（K、τ、T 均大于零）：绘制奈奎斯特图并用判据分析系统稳定的参数条件（小问题干 OCR 丢失，据同册答案段补）。
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据分析系统稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数再数曲线包围临界点圈数
  • 中间结果：由实轴交点位置分稳定、临界与不稳定三种情形
  • 卡点：包围圈数的正负定义容易搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据分析系统稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
稳定裕度 频域分析
本卷考法
  • 由幅相曲线求与负实轴的交点
本卷实例
  • 关键一步：令虚部为零求曲线与实轴的交点频率
  • 中间结果：实轴交点位置决定系统稳定性结论
  • 卡点：相位穿越频率与截止频率混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由幅相曲线求与负实轴的交点
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式

6六、按速度误差系数与相角裕度设计串联校正#

思路
  • 开环传函 K/[s(0.2s+1)(0.0625s+1)]，要求校正后 Kv 不小于 40、相角裕度为 50°：设计串联校正装置并画出校正前后的 Bode 图。
校正的基本概念与性能指标 系统校正
本卷考法
  • 把稳态误差与相角裕度指标折算为设计目标
本卷实例
  • 关键一步：由速度误差系数先定开环增益再算校正前相角裕度
  • 中间结果：校正前相角裕度为负，单靠调增益无法满足要求
  • 卡点：只满足一项指标就选定方案而未交叉校验
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过把稳态误差与相角裕度指标折算为设计目标
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
