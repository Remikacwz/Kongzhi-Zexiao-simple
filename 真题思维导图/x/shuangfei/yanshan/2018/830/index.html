1第一题 填空题：内部稳定、超前校正、状态反馈、频域指标12 分#

思路
  • 四小问概念填空：内部稳定与外部稳定的关系、超前校正装置最大相移、状态反馈与输出反馈改造能力、频域指标与时域指标的关系
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 简述内部稳定与外部稳定的关系（第1小题）
本卷实例
  • 关键一步：内部稳定指系统本身渐近稳定
  • 中间结果：内部稳定蕴含外部稳定
  • 卡点：外部稳定不要求所有内部状态收敛
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过简述内部稳定与外部稳定的关系（第1小题）
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
超前校正 系统校正
本卷考法
  • 判断给定校正网络的类型并求最大相移（第2小题）
本卷实例
  • 关键一步：由传函零极点位置判断超前或滞后
  • 中间结果：最大相移由分度系数α决定
  • 卡点：求最大相移角须先由α算中间量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过判断给定校正网络的类型并求最大相移（第2小题）
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
状态反馈与极点配置 状态空间分析
本卷考法
  • 比较状态反馈与输出反馈改造系统的能力（第3小题）
本卷实例
  • 关键一步：从能否任意配置极点的能力比较
  • 中间结果：状态反馈可实现极点任意配置
  • 卡点：输出反馈受能观测性限制
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过比较状态反馈与输出反馈改造系统的能力（第3小题）
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
公式
闭环频率特性与性能指标 频域分析
本卷考法
  • 说明相位裕度、截止频率与时域指标的关系（第4小题）
本卷实例
  • 关键一步：把频域裕度对应到超调与调节时间
  • 中间结果：截止频率高一般对应响应快
  • 卡点：相位裕度大不一定单调无超调
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过说明相位裕度、截止频率与时域指标的关系（第4小题）
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈
公式

2第二题 由正弦稳态输出反求参数与稳态误差#

思路
  • 由r=sin t作用下的稳态输出反求系统参数，再求r=t作用下的稳态误差
频率特性的物理意义与求法 频域分析
本卷考法
  • 由正弦输入的稳态输出反求幅频与相频关系
本卷实例
  • 关键一步：稳态正弦输出的幅值比与相角差即A(ω)、φ(ω)
  • 中间结果：由ω=1处的幅相值反求K与a
  • 卡点：曲线读数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由正弦输入的稳态输出反求幅频与相频关系
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由响应特征反求开环传函参数
本卷实例
  • 关键一步：把幅相条件化为关于K、a的方程
  • 中间结果：两组幅相数据可解两个参数
  • 卡点：幅值比与相角差要分别列式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由响应特征反求开环传函参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求r=t作用下的稳态误差
本卷实例
  • 关键一步：先定系统型别再求速度误差系数
  • 中间结果：稳态误差与开环增益有关
  • 卡点：未判稳就求误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求r=t作用下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

3第三题 结构图化简求闭环传递函数#

思路
  • 先移动比较点或引出点、再逐层化简，或用梅森公式求C(s)/R(s)
比较点与引出点的移动 结构图与方框图
本卷考法
  • 化简含交叉比较点与引出点的结构图
本卷实例
  • 关键一步：先化解交叉的内环再化外环
  • 中间结果：化简后化为单回路结构
  • 卡点：连接与移动方向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过化简含交叉比较点与引出点的结构图
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求C(s)/R(s)
本卷实例
  • 关键一步：找出全部前向通路与回路
  • 中间结果：无互不接触回路时特征式直接相加
  • 卡点：回路增益的负号易漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式

4第四题 根轨迹与主导极点估算动态性能#

思路
  • 由根轨迹图与已知闭环极点s=-4求开环增益，再确定主导极点并估算调整时间与超调量
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹上已知闭环极点求开环增益（第1问）
本卷实例
  • 关键一步：用幅值条件由极点位置反求增益
  • 中间结果：根轨迹增益与开环增益仅差比例
  • 卡点：极点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹上已知闭环极点求开环增益（第1问）
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 由根轨迹图判断开环零极点分布
本卷实例
  • 关键一步：由根轨迹起点与终点读开环零极点
  • 中间结果：已知一个闭环极点可推其余极点
  • 卡点：读图精度受分辨率影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过由根轨迹图判断开环零极点分布
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 确定主导极点并估算ts与Mp（第2问）
本卷实例
  • 关键一步：忽略远离虚轴的闭环极点
  • 中间结果：由主导极点实部估算调整时间
  • 卡点：套超调公式前须确认主导极点对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过确定主导极点并估算ts与Mp（第2问）
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

5第五题 奈奎斯特判稳与稳定增益范围#

思路
  • 由最小相位系统奈氏图与单位圆交点求相角裕度、幅值裕度，再求系统稳定时开环增益范围
稳定裕度 频域分析
本卷考法
  • 由奈氏图与单位圆交点求相角裕度与幅值裕度（第1问）
本卷实例
  • 关键一步：用交点模值与相角定义两种裕度
  • 中间结果：相角裕度取180°加交点相角
  • 卡点：交点坐标需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由奈氏图与单位圆交点求相角裕度与幅值裕度（第1问）
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由奈氏判据求系统稳定的开环增益范围（第2问）
本卷实例
  • 关键一步：看曲线是否包围-1点
  • 中间结果：增益变化使曲线按比例缩放
  • 卡点：最小相位系统P=0，判据化简为不包围-1
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由奈氏判据求系统稳定的开环增益范围（第2问）
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

6第六题 由校正后渐近线反求增益并调整衰减#

思路
  • 由校正后开环频率特性渐近线求开环增益，再判断能否通过调整增益使暂态分量衰减更快
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环对数幅频渐近线反求开环增益（第1问）
本卷实例
  • 关键一步：用低频段延长线与0dB线交点定增益
  • 中间结果：由各段斜率与转折频率还原环节
  • 卡点：渐近线读数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环对数幅频渐近线反求开环增益（第1问）
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
