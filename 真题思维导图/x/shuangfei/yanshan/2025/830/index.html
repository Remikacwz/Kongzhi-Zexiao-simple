1梅森公式、状态空间与能控能观#

思路
  • 一题三问：先用梅森公式求 Y(s)/U(s)，再把它写成能控标准型，最后算秩判能控能观
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式或方框化简求闭环传递函数
本卷实例
  • 关键一步：从信号流图数出前向通路、各回路及互不接触组
  • 中间结果：特征式等于一减各回路和加两两不接触回路积
  • 卡点：余子式要剔除与前向通路接触的回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式或方框化简求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过余子式中未剔除与前向通路接触的回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

3根轨迹与闭环化简#

思路
  • G=K₁/(s(s²+9s+18)) 的极点在 -3、-6，渐近线交点在 -3；「衰减振荡」要求极点共轭复且实部非零
根轨迹的绘制法则 根轨迹法
本卷考法
  • 画出根轨迹并标注渐近线
本卷实例
  • 关键一步：由开环极点定实轴段、分离点与渐近线
  • 中间结果：三个极点对应三条趋于无穷的轨迹分支
  • 卡点：渐近线夹角公式中分子是二 k 加一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过画出根轨迹并标注渐近线
  • 按法则绘制根轨迹草图

  • 判断某段实轴是否属于根轨迹
常见易错

  • 实轴段判据中的零极点个数算错

4Nyquist 曲线与相角裕度#

思路
  • G=K(τs+1)/s² 有两个积分环节，Nyquist 曲线从负实轴无穷远处出发；K>0 恒稳定由包围圈数说明
奈奎斯特判据 稳定性分析
本卷考法
  • 绘制开环频率特性的 Nyquist 曲线并说明 K>0 时闭环稳定
本卷实例
  • 关键一步：按积分环节补画无穷大圆弧后数曲线包围临界点的圈数
  • 中间结果：开环无右半平面极点时包围圈数为零即稳定
  • 卡点：起点相角由积分环节个数决定，别画错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过绘制开环频率特性的 Nyquist 曲线并说明 K>0 时闭环稳定
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过开环含积分环节时未补画无穷大半径圆弧
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

稳定裕度 频域分析
本卷考法
  • 由 γ=45° 反求 τ 的取值
本卷实例
  • 关键一步：由相角裕度目标在相频曲线上反求剪切频率
  • 中间结果：再令该频率处幅值为一定时间常数
  • 卡点：幅值裕度与相角裕度定义不同，不要混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
