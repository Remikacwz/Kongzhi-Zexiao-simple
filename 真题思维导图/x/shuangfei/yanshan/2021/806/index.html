燕山大学 806 控制原理 2021 年真题思维导图

强势双非共 5 题

难度：中等　5 道大题：填空 5 小问、恒力小车建模、结构图求传函与判稳、对数幅频渐近线反求传函与校正、根轨迹绘制；第 2/4/5 题的关键图依赖原卷

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

1一、填空题：基本概念与频域时域15 分#

思路
  • 5 个小填空依次考系统设计三大要求、传函定义、根轨迹相角条件、系统型别与稳态误差、频率特性与正弦稳态响应，按定义直接作答。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 线性系统设计需兼顾哪三方面要求
本卷实例
  • 关键一步：从控制系统性能要求切入，对应稳定性、准确性、快速性
  • 中间结果：三项要求分别对应稳定、稳态精度与动态响应
  • 卡点：三方面为并列要求，漏答任一项都会失分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过线性系统设计需兼顾哪三方面要求
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过只答稳定性而漏掉准确性与快速性
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
传递函数的定义与基本性质 传递函数
本卷考法
  • 填出传递函数定义的前提条件
本卷实例
  • 关键一步：明确讨论前提是零初始条件下的线性定常系统
  • 中间结果：传函等于输出与输入拉氏变换之比
  • 卡点：前提条件与线性定常缺一不可
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过填出传递函数定义的前提条件
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 填出绘制根轨迹的充要条件
本卷实例
  • 关键一步：根轨迹是所有满足相角条件的点集
  • 中间结果：相角条件是绘制根轨迹的充要条件
  • 卡点：幅值条件用于定 K，不是充要条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过填出绘制根轨迹的充要条件
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由含积分环节的开环传函判断系统型别与阶数
本卷实例
  • 关键一步：数开环传函分母中 s 的幂次定型别
  • 中间结果：两个积分环节即为 II 型，分母最高次为阶
  • 卡点：型别与阶数要分开数，勿混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由含积分环节的开环传函判断系统型别与阶数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求多项式输入下的稳态误差
本卷实例
  • 关键一步：先判稳再用终值定理逐分量求误差
  • 中间结果：阶跃、斜坡与抛物线分量误差叠加
  • 卡点：未判稳直接用终值定理会出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求多项式输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求频率特性、相频特性及正弦输入下稳态输出
本卷实例
  • 关键一步：令 s 等于 jω 代入传函得幅频与相频表达式
  • 中间结果：稳态输出幅值等于输入幅值乘幅频
  • 卡点：开环传函以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求频率特性、相频特性及正弦输入下稳态输出
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式

2二、恒力小车机械系统建模#

思路
  • 由 F=10N 恒力与位移时间图象，用牛顿第二定律列动力学方程，再取拉氏变换求传函；由图读稳态与时间特征反求参数。
机械系统建模 建模与机电系统
本卷考法
  • 由恒力小车的位移图象建立微分方程与传函
本卷实例
  • 关键一步：对小车用牛顿第二定律列合力等于 ma
  • 中间结果：整理成输入力到输出位移的二阶微分方程
  • 卡点：位移-时间图象为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过由恒力小车的位移图象建立微分方程与传函
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 本卷考过阻尼力与弹簧力的方向或合力关系写反
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由位移时间响应曲线反求传函参数
本卷实例
  • 关键一步：从曲线读稳态值、峰值时间估计参数
  • 中间结果：由稳态位移与恒力之比定静态增益
  • 卡点：曲线读数依赖原图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由位移时间响应曲线反求传函参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式

3三、结构图求传函、判稳与正弦稳态输出#

思路
  • 先用梅森公式求多回路结构图的闭环传函，再用劳斯判据判稳，最后按叠加原理分别求直流与正弦分量的稳态输出。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求多回路结构图的闭环传函
本卷实例
  • 关键一步：找出独立回路与前向通路并写 Δ 与 Δk
  • 中间结果：闭环分母为 1 减去各回路增益之和
  • 卡点：回路接触关系与图有关，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求多回路结构图的闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路漏算或余子式未剔除接触回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
劳斯判据 稳定性分析
本卷考法
  • 由闭环特征方程用劳斯判据判断稳定性
本卷实例
  • 关键一步：整理闭环特征多项式按降幂列劳斯表
  • 中间结果：劳斯表首列同号则闭环系统稳定
  • 卡点：先因式分解化简再判稳可减少计算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由闭环特征方程用劳斯判据判断稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过系数缺项时不补零直接套判据
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求直流加正弦输入的稳态输出
本卷实例
  • 关键一步：直流用终值定理，正弦用频率特性
  • 中间结果：稳态输出为直流分量与同频正弦分量叠加
  • 卡点：输入含常数项时勿只算正弦分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求直流加正弦输入的稳态输出
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式

4四、对数幅频渐近线反求传函与校正#

思路
  • 由渐近线低频高度定增益、转折频率与斜率变化定环节；再求相角裕度与稳态输出；相角裕度不足时用超前校正补相角。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环对数幅频渐近线求开环传函
本卷实例
  • 关键一步：低频段高度定增益，转折频率定时间常数
  • 中间结果：按每段斜率变化正负二十识别环节
  • 卡点：渐近线为插图，读数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环对数幅频渐近线求开环传函
  • 由给定 Bode 图写出传递函数

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝

步骤

  • 由相频特性求 ∠G=-180° 对应的频率 ωg

  • 由裕度符号判断稳定性

  • 非最小相位系统仍用同一判据

5五、开环传函根轨迹绘制#

思路
  • 开环 G(s)=K(s+5)/(s(s+1)(s+2))，按根轨迹法则定实轴段、渐近线、分离点与会合点，再令特征方程求虚轴交点与临界增益。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制给定开环传函的根轨迹草图
本卷实例
  • 关键一步：先标开环零极点并定实轴上根轨迹段
  • 中间结果：n 减 m 等于二，两条渐近线趋于无穷远
  • 卡点：开环传函以图给出，零极点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制给定开环传函的根轨迹草图
  • 按法则绘制根轨迹草图

  • 实轴段判据中的零极点个数算错

与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界增益 K
本卷实例
  • 关键一步：令 s 等于 jω 代入特征方程分离实部虚部
  • 中间结果：联立实部虚部方程解 ω 与临界 K
  • 卡点：虚轴交点要成对取，勿只代一个 ω
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界增益 K

  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
