1无源电路网络建模#

思路
  • 用复阻抗逐级分压，既要画方框图也要给出 Uo(s) 表达式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 求无源电路网络的传递函数 Uo(s)
本卷实例
  • 关键一步：用复阻抗表示各电阻电容，按节点电压列电流方程
  • 中间结果：逐级消去中间节点电压得到输出比输入的传函
  • 卡点：电路图为原卷插图，元件连接与节点编号需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过求无源电路网络的传递函数 Uo(s)
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过电容复阻抗误写成 Cs
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 把电路画成方框图并逐级化简
本卷实例
  • 关键一步：把每个复阻抗分压关系看成独立方框再按信号流向连接
  • 中间结果：方框图含多个反馈回路，用梅森公式或逐步化简求总传函
  • 卡点：电路转方框图时串并联与节点连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤

  • 分别套用串联、并联或反馈等效公式

常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

思路
  • 由曲线读稳态值、超调量与峰值时间反求 K、ξ、ωn；第 2 问要求 ωn 不变而改变 ξ，需串联一个能改变阻尼的环节
由响应曲线反求传递函数 传递函数
本卷考法
  • 由二阶单位负反馈阶跃响应曲线求开环传递函数
本卷实例
  • 关键一步：从阶跃响应曲线读稳态值、超调量与峰值时间
  • 中间结果：由超调量反解阻尼比，由峰值时间求自然频率
  • 卡点：响应曲线为原卷插图，峰值与稳态读数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法

  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错

  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法

本卷实例
  • 关键一步：保持自然频率不变，在回路中加入只改变阻尼项的环节
  • 中间结果：附加环节应引入与 s 一次项相关但不改变常数项的结构
  • 卡点：校正装置接入点影响闭环分母，需按原卷结构图核对

要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角

  • 比对系数求出 ωn 与 ξ

  • 按 ξ 的取值判断响应类型

超前校正 系统校正
本卷考法
  • 用超前环节提高阻尼比
本卷实例
  • 关键一步：超前环节在剪切频率附近提供正相角，等效增大系统阻尼
  • 中间结果：超前网络零点在极点左侧，零极点频率比决定最大超前角
  • 卡点：超前校正抬高阻尼的同时可能放大高频噪声
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过用超前环节提高阻尼比
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 本卷考过α 的取值与超前角公式方向取反
  • 计算补偿角时忽略截止频率变化带来的附加相角损失

3一阶系统与斜坡输入工程计算#

思路
  • 温度计是一阶惯性环节，T 由「120s 达到 95%」定出（3T=120 → T=40s）；再用一阶系统对斜坡输入的响应求第 6min 读数
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由「达到稳态 95% 所需时间」求时间常数 T
本卷实例
  • 关键一步：一阶系统响应达到稳态值百分之九十五对应三倍时间常数
  • 中间结果：由给定时间除以三得到时间常数
  • 卡点：百分之九十五对应三倍时间常数，勿与百分之九十八的对应值混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由「达到稳态 95% 所需时间」求时间常数 T
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 本卷考过把 95% 对应的时间记成 4T
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
典型环节及其特性 传递函数
本卷考法
  • 识别温度计为一阶惯性环节并写 G(s)=1/(Ts+1)
本卷实例
  • 关键一步：温度计动态用一阶惯性环节描述，其静态增益为一
  • 中间结果：时间常数由阶跃响应达到百分之九十五的时间确定
  • 卡点：静态增益为一的前提是稳态读数等于实际水温
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过识别温度计为一阶惯性环节并写 G(s)=1/(Ts+1)
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 本卷考过把一阶微分环节与纯微分环节混为一谈
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求线性升温（斜坡）输入下经过一段时间后的读数
本卷实例
  • 关键一步：把线性升温看作斜坡输入，代入一阶系统响应公式求输出
  • 中间结果：输出落后输入一个时间常数，稳态时读数趋于输入减速度误差
  • 卡点：加热五分钟后温度仍在上升，第 6 分钟要先算该时刻水温
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求线性升温（斜坡）输入下经过一段时间后的读数
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过忽略一阶系统对斜坡输入存在稳态滞后
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

4由根轨迹反设计控制器#

思路

根轨迹的绘制法则 根轨迹法
本卷考法
  • 由给定的根轨迹图反推系统开环传递函数
本卷实例
  • 关键一步：从根轨迹起点读开环极点，从终点读有限零点
  • 中间结果：由重根位置与渐近线确定极点重数和增益形式
  • 卡点：根轨迹图为原卷插图，极点读数与重根位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过由给定的根轨迹图反推系统开环传递函数
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过渐近线交点算错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

  • 期望特性的中频段取窄导致裕度不足

附加开环零极点的影响 根轨迹法
本卷考法
  • 说明为保证闭环极点个数不变，控制器只能是零阶或一阶

  • 分析根轨迹整体移动方向

  • 分析为何某系统需要引入零点

  • 只讨论渐近线是否左移右移，忽略分离点变化
