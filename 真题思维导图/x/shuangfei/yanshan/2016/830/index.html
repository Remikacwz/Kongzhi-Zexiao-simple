1一、由传函与初值求全响应与正弦稳态响应#

思路
  • 已知闭环传函 C(s)/R(s)=2/(s²+3s+2)、初始条件 c(0)=-1、c'(0)=0：第 1 问求单位阶跃输入下的输出响应，第 2 问求正弦输入下的稳态响应。
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由传递函数与初始条件求系统全响应
本卷实例
  • 关键一步：先由传函反写微分方程再作拉氏变换
  • 中间结果：零输入响应由初值定，零状态响应由输入定
  • 卡点：只求零状态响应而漏掉初值引起的自由响应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由传递函数与初始条件求系统全响应
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求正弦输入下系统的稳态响应
本卷实例
  • 关键一步：用频率特性在输入频率处的模与相角
  • 中间结果：稳态输出与输入同频，幅值比与相位差由频率特性给出
  • 卡点：把初值引起的暂态分量混入稳态响应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求正弦输入下系统的稳态响应
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

2二、结构图化简求闭环传函#

思路
  • 图 1 为多回路结构图，逐层化简或用梅森公式求系统闭环传递函数 C(s)/R(s)。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图的逐层化简
本卷实例
  • 关键一步：从最内层回路开始逐级等效
  • 中间结果：每化简一层就得到更简单的等效结构
  • 卡点：化简顺序与交叉点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图的逐层化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求闭环传递函数
本卷实例
  • 关键一步：数独立回路与前向通路并判断接触关系
  • 中间结果：特征式与余子式代入梅森公式求传函
  • 卡点：不接触回路漏算或重复导致特征式出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

3三、衰减振荡、稳态误差与降阶判据#

思路
  • 图 2 结构图：第 1 问求阶跃响应存在衰减周期分量时的开环增益范围，第 2 问由斜坡稳态误差求增益裕度，第 3 问按 ξ=0.707 选取增益并判断能否降为二阶系统。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征多项式判断响应是否含衰减周期分量
本卷实例
  • 关键一步：由结构图先写开环传函再求闭环特征方程
  • 中间结果：特征根为共轭复根时响应含衰减振荡分量
  • 卡点：判别式条件与增益范围的边界取向易错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征多项式判断响应是否含衰减周期分量
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由稳态误差要求反求开环增益
本卷实例
  • 关键一步：先判型别写出静态速度误差系数
  • 中间结果：斜坡输入误差等于静态速度误差系数的倒数
  • 卡点：未判稳就使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由稳态误差要求反求开环增益
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
稳定裕度 频域分析
本卷考法
  • 由幅相特性求系统的增益裕度
本卷实例
  • 关键一步：令相频特性为 -180° 求相位穿越频率
  • 中间结果：幅值裕度为相位穿越频率处幅值的倒数
  • 卡点：把幅值裕度取倒数后与 1 的比较方向写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由幅相特性求系统的增益裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 判断高阶闭环能否降阶为二阶系统
本卷实例
  • 关键一步：比较第三个实极点与主导复极点的实部距离
  • 中间结果：远极点对应的留数小时可按二阶近似
  • 卡点：只看极点距离而不看留数大小
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过判断高阶闭环能否降阶为二阶系统
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

4四、临界阻尼下的最短调节时间#

思路
  • 图 3 随动系统：要求单位阶跃响应无超调且调整时间尽可能短，选取增益 K 并求最短调整时间（Δ=±5%）。
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由无超调与调节时间最短反求增益
本卷实例
  • 关键一步：把无超调转化为阻尼比不小于 1，取临界阻尼使调节时间最小
  • 中间结果：临界阻尼时闭环为等根二阶系统，响应单调且最快
  • 卡点：用欠阻尼调节时间公式处理临界阻尼
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由无超调与调节时间最短反求增益
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

5五、开环 Bode 图与相角裕度反求增益#

思路
  • 开环传函 K/[s(2s+1)(5s+1)]：第 1 问绘制 K=10 时的 Bode 图；第 2 问求相角裕度不小于 45° 的 K 范围（第 2 问题干 OCR 丢失，据同册答案段补）。
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制开环对数渐近幅频特性
本卷实例
  • 关键一步：低频段按积分环节斜率起画，在各转折频率处改斜率
  • 中间结果：各环节转折频率处斜率变化量决定折线走向
  • 卡点：转折频率处的斜率变化量容易算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过绘制开环对数渐近幅频特性
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

稳定裕度 频域分析
本卷考法
  • 由相角裕度要求反求开环增益范围
本卷实例
  • 关键一步：写出相角裕度表达式并令其不小于要求值
  • 中间结果：解三角不等式得截止频率上限再换算为增益上限
  • 卡点：解反正切不等式时忽略角度范围
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由相角裕度要求反求开环增益范围
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
