思路

本卷实例

3劳斯判据、等幅振荡与主导极点法#

思路
  • G=K/(s(s+3)(s+4))；稳定范围用劳斯表首列＞0；等幅振荡令 s=jω 代入；K=10 且已知一根为 -5 时用主导极点法降阶
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求系统稳定时开环增益的范围
本卷实例
  • 关键一步：写出闭环特征方程，并注意开环增益与根轨迹增益差一系数
  • 关键一步：列劳斯表令首列同号，再把结果折算成开环增益
  • 中间结果：特征方程 s³+7s²+12s+K=0，首列给两个约束
  • 卡点：首列出现零时要用 epsilon 法，且两种增益要区分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求系统稳定时开环增益的范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过首列出现 0 时未用 ε 法
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
