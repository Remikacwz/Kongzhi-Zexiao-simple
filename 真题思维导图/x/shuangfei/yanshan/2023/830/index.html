1判断题（状态反馈与能控能观）15 分#

思路
  • 5 个判断：状态反馈对零点的影响、最小实现的性质、输出反馈能否任意配置极点、状态反馈对能控能观的影响、不完全能控能否镇定
状态反馈与极点配置 状态空间分析
本卷考法
  • 判断状态反馈是否改变零点以及能否任意配置极点
本卷实例
  • 关键一步：状态反馈只改变系统矩阵，输出矩阵和零点不受影响
  • 中间结果：状态反馈可任意配置极点但不改变零点
  • 卡点：判断输出反馈能否任意配置极点时要看它受根轨迹约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过判断状态反馈是否改变零点以及能否任意配置极点
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
公式
能控性与能观性 状态空间分析
本卷考法
  • 判断最小实现与不完全能控系统的相关结论
本卷实例
  • 关键一步：最小实现不存在零极点对消，其阶数等于特征多项式阶数
  • 中间结果：最小实现同时满足完全能控和完全能观
  • 卡点：不完全能控系统能否镇定取决于不能控部分是否稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断最小实现与不完全能控系统的相关结论
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

2方框图求传递函数 C(s)#

思路
  • 已知系统结构图，用梅森公式求 C(s)/R(s)
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求多回路结构图的传递函数
本卷实例
  • 关键一步：数出八个独立回路、两组两两不接触回路和两条前向通路
  • 中间结果：特征式由一减回路和再加上不接触回路乘积组成
  • 卡点：本题结构图以图给出，回路与通路需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求多回路结构图的传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

3稳态误差反求参数与动态性能#

思路
  • 开环为常增益除以三个一阶因子之积：由斜坡输入稳态误差求参数；答案段另有给定参数估算超调量、以及画根轨迹两问
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由斜坡输入下的稳态误差求开环增益
本卷实例
  • 关键一步：I 型系统的速度误差系数等于开环增益
  • 中间结果：由输入幅度除以误差得到速度误差系数
  • 卡点：求出参数后要回代劳斯判据确认系统稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由斜坡输入下的稳态误差求开环增益
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据确认所求参数下系统稳定
本卷实例
  • 关键一步：把闭环特征方程按降幂排列后列劳斯表
  • 中间结果：令首列各元素大于零得到参数的稳定区间
  • 卡点：系数缺项要补零，否则首列条件会漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据确认所求参数下系统稳定
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 由主导极点降阶估算系统超调量
本卷实例
  • 关键一步：先求闭环极点，把远离虚轴的极点略去后降阶
  • 中间结果：由降阶二阶系统读出阻尼比再代入超调量公式
  • 卡点：该小问题面未印，仅见答案段第2问，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过由主导极点降阶估算系统超调量
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制该系统的根轨迹
本卷实例
  • 关键一步：开环极点为零、负二、负五，无零点，三条分支趋向无穷远
  • 中间结果：实轴根轨迹段和分离点由极点分布确定
  • 卡点：该小问题面未印，仅见答案段第3问；开环增益与根轨迹增益差一个倍数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制该系统的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式

4PID 极点配置与超调估算#

思路

PID 控制器与参数整定 系统校正
本卷考法
  • 由期望极点配置求 PID 控制器的三个参数
本卷实例
  • 关键一步：先写出含 PID 参数的闭环特征方程
  • 中间结果：把期望极点展开成特征多项式后与含参式子比较系数
  • 卡点：本题结构图以图给出，PID 接法与对象需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过由期望极点配置求 PID 控制器的三个参数
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

5Bode 图反求传函与 Nyquist 判稳#

思路
  • 根据 Bode 图：求开环传递函数；画奈氏图并用奈氏判据判断稳定性
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由 Bode 图反求系统开环传递函数
本卷实例
  • 关键一步：低频段斜率为负 40 说明有二重积分环节
  • 中间结果：由转折频率处斜率变化判断一阶微分与一阶惯性环节
  • 卡点：该 Bode 图以图给出，转折频率与增益需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由 Bode 图反求系统开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 绘制奈奎斯特图并用奈奎斯特判据判断稳定性
本卷实例
  • 关键一步：写出幅相表达式并判断曲线位于实轴的上方还是下方
  • 中间结果：开环右半平面极点数为零且包围圈数为零
  • 卡点：二重积分环节起点相角为负 180 度，要补无穷大圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过绘制奈奎斯特图并用奈奎斯特判据判断稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

6Bode 截止频率与串联超前校正#

思路
  • 开环为四倍的一阶微分与惯性环节比：画伯德图求截止频率；设计串联校正使截止频率变为根号二倍，求校正前后相角裕度与校正参数
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制伯德图并求系统截止频率
本卷实例
  • 关键一步：用抓大放小的方法分段试算幅频特性的模等于一
  • 中间结果：确定截止频率落在哪个频段后再取该段的近似式
  • 卡点：分段试算出的根要回到对应频段校验，假根要舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率

稳定裕度 频域分析
本卷考法
  • 求校正前后系统的相角裕度
本卷实例
  • 关键一步：把各自的截止频率代入相角裕度的定义式
  • 中间结果：校正后截止频率为原来的根号二倍
  • 卡点：两处截止频率不同，相角裕度必须分别计算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求校正前后系统的相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

  • α 的取值与超前角公式方向取反
