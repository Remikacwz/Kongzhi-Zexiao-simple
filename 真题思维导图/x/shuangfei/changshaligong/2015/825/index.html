1一、填空题：系统组成、传递函数与频域指标15 分#

思路
  • 填空：自动控制系统的组成、传递函数与输入无关、时域性能三点要求、由脉冲响应反求闭环传函、根轨迹定义、频域法依据及Nyquist与负虚轴交点
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 补全自动控制系统的组成环节
本卷实例
  • 关键一步：沿反馈回路依次指认组成环节
  • 中间结果：系统由控制装置与被控对象两部分组成
  • 卡点：控制装置与被控对象的界限易混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过补全自动控制系统的组成环节
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把控制装置与被控对象混淆
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
传递函数的定义与基本性质 传递函数
本卷考法
  • 指出传递函数与输入信号形式无关
本卷实例
  • 关键一步：由传函定义确认只取决于系统结构参数
  • 中间结果：传递函数与输入信号形式无关
  • 卡点：同一系统不同输入输出传函不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过指出传递函数与输入信号形式无关
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过把传函与输入信号的形式挂钩
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 填出对控制系统性能的三点要求
本卷实例
  • 关键一步：按时域响应把指标分为动态与稳态
  • 中间结果：三点要求为稳定性快速性与准确性
  • 卡点：稳定性是系统工作的首要条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过填出对控制系统性能的三点要求
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过把快速性与准确性归属说反
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由脉冲响应表达式求闭环传递函数
本卷实例
  • 关键一步：对脉冲响应取拉氏变换得闭环传函
  • 中间结果：脉冲响应的拉氏变换即闭环传函
  • 卡点：需确认给的是闭环脉冲响应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由脉冲响应表达式求闭环传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 本卷考过忘记先对响应作拉氏变换
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 补出根轨迹定义中的开环参数
本卷实例
  • 关键一步：由定义确认变化的是开环某参数
  • 中间结果：根轨迹随开环参数由零到无穷变化
  • 卡点：轨迹是闭环特征根的运动路径
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过补出根轨迹定义中的开环参数
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 本卷考过把开环参数与闭环参数搞混
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 说明频域法依据哪种频率特性
本卷实例
  • 关键一步：明确频域法使用开环频率特性
  • 中间结果：由开环频率特性间接判断闭环性能
  • 卡点：开环与闭环频率特性需分清
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过说明频域法依据哪种频率特性
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过写成闭环频率特性判断闭环性能
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式

2二、单项选择题：稳定性、时域与频域概念15 分#

思路
  • 单选：积分环节对相对稳定性的影响、执行机构的作用方式、一阶系统时间常数、Ⅰ型系统阶跃误差、劳斯判据、二阶响应形态、低频段高度、校正类型
减小稳态误差的措施 稳态误差
本卷考法
  • 判断增加积分环节对相对稳定性的影响
本卷实例
  • 关键一步：看积分环节引入的相位滞后
  • 中间结果：增加积分环节使相对稳定性变坏
  • 卡点：积分环节同时改变型别与相角
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过判断增加积分环节对相对稳定性的影响
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 本卷考过只看到精度提高而忽略稳定性
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由阶跃响应特定时刻值反求时间常数
本卷实例
  • 关键一步：利用一阶响应在特定时刻的特征值
  • 中间结果：该时刻输出为稳态值的百分之六十三点二
  • 卡点：稳态值不等于一时需先归一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由阶跃响应特定时刻值反求时间常数
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 本卷考过把百分之六十三点二对应时刻记错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 判断Ⅰ型系统单位阶跃下的稳态误差
本卷实例
  • 关键一步：按积分环节个数确定系统型别
  • 中间结果：Ⅰ型系统在阶跃输入下误差为零
  • 卡点：阶跃下型别至少为一即无差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过判断Ⅰ型系统单位阶跃下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过把系统型别数错导致结论相反
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断特征方程的稳定性
本卷实例
  • 关键一步：列劳斯表首列并观察符号变化
  • 中间结果：首列元素不全为正即不稳定
  • 卡点：首列出现零需用辅助方程处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断特征方程的稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过系数缺项时不补零就直接套用
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由二阶开环传函判断阶跃响应形态
本卷实例
  • 关键一步：写出闭环特征式并与标准式比对
  • 中间结果：阻尼比介于零与一时响应衰减振荡
  • 卡点：阻尼比须由闭环特征式求得
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
