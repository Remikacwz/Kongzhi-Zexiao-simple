自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 补出两种控制方式并指出最基本的一种
本卷实例
  • 关键一步：按有无反馈通路区分控制方式
  • 中间结果：开环是最基本的控制方式
  • 卡点：闭环需检测偏差并回送
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过补出两种控制方式并指出最基本的一种
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把开环与闭环的位置写反
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
传递函数的定义与基本性质 传递函数
本卷考法
  • 说明拉氏变换把微分方程化为何种方程
本卷实例
  • 关键一步：对微分方程两边取拉氏变换
  • 中间结果：微分运算化为变量s的代数关系
  • 卡点：初始条件为零时代数方程才最简洁
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过说明拉氏变换把微分方程化为何种方程
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过忽略零初始条件对变换结果的影响
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

频率特性的物理意义与求法 频域分析
本卷考法
  • 求最小相位Ⅰ型系统极坐标曲线的起点
本卷实例

  • 中间结果：一个积分环节给出负九十度相角
  • 卡点：起点幅值是否无穷取决于型别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求最小相位Ⅰ型系统极坐标曲线的起点
  • 求给定传递函数的幅频与相频表达式

  • 说明频率特性的物理含义
常见易错

  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
