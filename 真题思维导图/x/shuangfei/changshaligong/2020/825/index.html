1一、填空题：响应反求、阻尼分类与频域基础10 分#

思路
  • 四个填空，覆盖由阶跃响应反求脉冲与速度响应、阻尼比分类、校正方式、惯性环节Bode斜率
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由单位阶跃响应求单位脉冲响应与单位速度响应
本卷实例
  • 关键一步：对阶跃响应求导得脉冲响应
  • 中间结果：对阶跃响应积分得速度响应
  • 卡点：积分常数由零初始条件定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由单位阶跃响应求单位脉冲响应与单位速度响应
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 本卷考过把脉冲响应与阶跃响应的关系搞反
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应表达式反求系统传递函数
本卷实例
  • 关键一步：对响应取拉氏变换
  • 中间结果：由输出与输入的比值得传函
  • 卡点：初始条件影响积分常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应表达式反求系统传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 本卷考过求速度响应时未用零初始条件定常数
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 按阻尼比判断过阻尼、临界与欠阻尼
本卷实例
  • 关键一步：写出二阶系统标准式
  • 中间结果：由阻尼比与一比较定类型
  • 卡点：三种阻尼状态要成对记
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过按阻尼比判断过阻尼、临界与欠阻尼
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过把阻尼比与一的大小关系搞反
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
校正的基本概念与性能指标 系统校正
本卷考法
  • 按校正装置与原系统的连接方式填写校正类型
本卷实例
  • 关键一步：按连接位置分类
  • 中间结果：串联校正接在前向通路
  • 卡点：复合校正含前馈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过按校正装置与原系统的连接方式填写校正类型
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 本卷考过把串联校正与反馈校正搞混
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求
公式
典型环节的对数频率特性 频域分析
本卷考法
  • 填出惯性环节Bode图低频与高频渐近线斜率
本卷实例
  • 关键一步：写出惯性环节频率特性
  • 中间结果：低频斜率零、高频斜率负二十
  • 卡点：转折频率处斜率转折
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例环节是水平线，积分与微分分别是 -20 与 +20 dB/dec 的斜线
  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec
  • 一阶微分环节与惯性环节幅频互为镜像
  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤
  • 把传递函数分解为典型环节乘积
  • 逐环节画出对数幅频渐近线与相频曲线
  • 代数相加得到总特性
通用考法
  • 本卷考过填出惯性环节Bode图低频与高频渐近线斜率
  • 画出某一典型环节的 Bode 图
  • 由 Bode 图识别环节类型
  • 说明转角频率处的幅值与相角
常见易错
  • 本卷考过把惯性环节高频斜率写成负四十
  • 把惯性环节高频渐近线的 -20 写成 -40
  • 振荡环节谐振峰位置误当作 ωn

思路

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由开环传函判断闭环阶跃响应的振荡性
本卷实例
  • 关键一步：求闭环传函并列标准二阶式
  • 中间结果：由阻尼比判断是否振荡
  • 卡点：开环与闭环系数别混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤

  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由开环传函判断闭环阶跃响应的振荡性
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过把开环参数直接当成闭环参数
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
劳斯判据 稳定性分析
本卷考法
  • 由高次特征方程用劳斯判据判断稳定性
本卷实例
  • 关键一步：按系数列劳斯表
  • 中间结果：由首列符号判断稳定性
  • 卡点：缺项要补零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由高次特征方程用劳斯判据判断稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过首列出现零未作处理
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
稳定裕度 频域分析
本卷考法
  • 识别开环对数幅频与横轴交点频率的名称
本卷实例
  • 关键一步：按交点定义定位
  • 中间结果：幅频过一的频率为截止频率
  • 卡点：截止频率属开环指标
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过识别开环对数幅频与横轴交点频率的名称
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过把截止频率与谐振频率搞混
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由奈奎斯特曲线起始方向判断系统型别
本卷实例
  • 关键一步：由低频段幅相走向判型别
  • 中间结果：起始平行负虚轴对应一型
  • 卡点：型别由积分环节数决定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由奈奎斯特曲线起始方向判断系统型别
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 本卷考过把起始方向与型别的对应关系记反
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断热水器温度控制系统所属的控制类型
本卷实例
  • 关键一步：看给定量是否变化
  • 中间结果：给定量恒定为恒值控制
  • 卡点：与程序控制区分看给定量规律
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断热水器温度控制系统所属的控制类型
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把恒值控制与随动控制搞混
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 由响应表达式判断闭环主导极点
本卷实例
  • 关键一步：把响应写成模态叠加
  • 中间结果：衰减最慢的模态对应主导极点
  • 卡点：主导极点决定响应形态
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过由响应表达式判断闭环主导极点
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 本卷考过只看极点距离而忽略零点与留数
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

最小相位系统与非最小相位系统 频域分析
本卷考法
  • 由奈奎斯特曲线起始终止选最小相位系统传函
本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过由奈奎斯特曲线起始终止选最小相位系统传函
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 本卷考过以为非最小相位也满足频域判据
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈
PID 控制器与参数整定 系统校正
