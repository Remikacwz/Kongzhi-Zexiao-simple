1一、填空题：时域指标、典型环节与校正分类10 分#

思路
  • 填空：时域性能指标分动态与稳态两类、传递函数零初始条件、惯性与振荡环节典型传函、串联校正按相位关系分类
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 把时域性能指标分为动态与稳态两大类
本卷实例
  • 关键一步：按响应过程分段区分动态段与稳态段
  • 中间结果：动态看调节时间与平稳性，稳态看控制精度
  • 卡点：两类指标各自包含哪几个量需按题面一一对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过把时域性能指标分为动态与稳态两大类
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过把调节时间与稳态误差的归属搞反
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

传递函数的定义与基本性质 传递函数
本卷考法
  • 补出传递函数定义中的零初始条件前提
本卷实例
  • 关键一步：由定义回忆成立前提
  • 中间结果：定义式要求输入输出初始值均为零
  • 卡点：非零初始条件会多出自由响应分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过补出传递函数定义中的零初始条件前提
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过忽略零初始条件把初值带进变换结果
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

典型环节及其特性 传递函数
本卷考法
  • 写出惯性环节与振荡环节的典型传递函数
本卷实例
  • 关键一步：按典型环节标准形式直接书写
  • 中间结果：惯性环节分母一次，振荡环节分母二次
  • 卡点：振荡环节须保留阻尼比与自然频率两个参数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过写出惯性环节与振荡环节的典型传递函数
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 本卷考过把一阶微分环节与惯性环节混为一谈
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减

校正的基本概念与性能指标 系统校正
本卷考法
  • 按相位关系对串联校正装置分类
本卷实例
  • 关键一步：从校正装置的相频特性正负入手
  • 中间结果：相位关系分为超前、滞后与超前滞后三类
  • 卡点：分类依据是相频而非幅频
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过按相位关系对串联校正装置分类
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 本卷考过把超前与滞后校正的相频符号取反
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求

2二、多项选择题：概念与频域指标10 分#

思路
  • 多选：由二阶开环传函判断阶跃响应与稳态误差、幅相曲线与单位圆交点频率的名称、由阶跃响应表达式判断主导极点和稳定性、PID串联校正的作用、恒值控制系统的辨识
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由开环传函求闭环特征式并判断阻尼状态
本卷实例
  • 关键一步：先写出闭环特征多项式
  • 中间结果：比较判别式可定阻尼状态
  • 卡点：临界阻尼时阶跃响应无超调且单调
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由开环传函求闭环特征式并判断阻尼状态
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过未把分母首项系数归一就直接比对标准式
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 判断单位负反馈系统阶跃输入下的稳态误差
本卷实例
  • 关键一步：先看开环是否含积分环节定系统型别
  • 中间结果：含一个积分环节时阶跃稳态误差为零
  • 卡点：系统型别由原点开环极点重数决定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过判断单位负反馈系统阶跃输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过未判稳就直接用终值定理
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

频率特性的物理意义与求法 频域分析
本卷考法
  • 指出幅相曲线与单位圆交点频率的名称
本卷实例
  • 关键一步：从幅频等于一的定义出发
  • 中间结果：该频率即开环截止频率
  • 卡点：截止频率处相角决定相位裕量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过指出幅相曲线与单位圆交点频率的名称
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过把截止频率与谐振频率混用
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 由阶跃响应各指数项判断主导极点与稳定性
本卷实例
  • 关键一步：找出离虚轴最近且衰减最慢的一对极点
  • 中间结果：距虚轴最近的共轭极点为主导极点
  • 卡点：所有极点实部为负才能判稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过由阶跃响应各指数项判断主导极点与稳定性
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 本卷考过只比极点实部而忽略各模态权重
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

PID 控制器与参数整定 系统校正
本卷考法
  • 说明PID串联校正对稳态与动态性能的作用
本卷实例
  • 关键一步：分别写出比例、积分、微分三项的作用
  • 中间结果：积分提精度、微分提平稳、比例调增益
  • 卡点：校正后稳定性变化须重新判定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过说明PID串联校正对稳态与动态性能的作用
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 本卷考过把积分项的相位影响说成超前
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 从若干系统中辨识恒值控制系统
本卷实例
  • 关键一步：看被控量是否为恒定给定量
  • 中间结果：给定量恒定的系统属恒值控制
  • 卡点：随动系统的给定量随时间变化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过从若干系统中辨识恒值控制系统
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把随动系统当成恒值控制系统
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

3三、判断题：基本概念与稳定性10 分#

思路
  • 判断：积分环节对稳定性影响、传递函数适用对象、串联等效、闭环极点与稳定性、主导极点、积分与稳态误差、超前校正频域特征、特征方程判稳、零型系统低频渐近线、Ⅱ型系统斜坡误差
劳斯判据 稳定性分析
本卷考法
  • 用特征方程判断系统是否稳定
本卷实例
  • 关键一步：列出劳斯表首列并看符号变化
  • 中间结果：首列有非正元素即不稳定
  • 卡点：首列出现零需用辅助方程或小量法处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用特征方程判断系统是否稳定
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过系数缺项时不补零直接套判据
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 判断Ⅱ型系统在斜坡输入下的稳态误差
本卷实例
  • 关键一步：按积分环节个数确定系统型别
  • 中间结果：Ⅱ型系统含两个积分环节
  • 卡点：斜坡输入下误差是否为零取决于型别高低
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
