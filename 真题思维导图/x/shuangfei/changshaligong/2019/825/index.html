1一、单项选择题：控制方式、稳定性与频域概念10 分#

思路
  • 十个单选，覆盖控制方式分类、稳态指标、劳斯判据、脉冲响应、阻尼判断、渐近线斜率、校正与根轨迹概念
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断属于程序控制系统的系统
本卷实例
  • 关键一步：按给定量是否按预定程序变化判断
  • 中间结果：给定量随时间按规律变化者为程序控制
  • 卡点：与恒值控制的区分在给定量特征
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断属于程序控制系统的系统
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把恒值控制与程序控制搞混
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 识别描述稳态性能的时域指标
  • 求一阶系统的超调量与稳态误差
本卷实例
  • 关键一步：按稳态误差定义定位指标
  • 中间结果：稳态误差表征稳态性能
  • 卡点：超调量与稳态误差分开算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过识别描述稳态性能的时域指标
  • 本卷考过求一阶系统的超调量与稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过把频域指标当作时域指标
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

劳斯判据 稳定性分析
本卷考法
  • 由特征方程用劳斯判据判断系统稳定性
本卷实例
  • 关键一步：列出劳斯表
  • 中间结果：看首列符号变化次数
  • 卡点：首列出现零需特殊处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由特征方程用劳斯判据判断系统稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过特征方程有缺项时不补零
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由单位阶跃响应求单位脉冲响应
本卷实例
  • 关键一步：对阶跃响应求导
  • 中间结果：脉冲响应是阶跃响应的导数
  • 卡点：初值处导数要核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由单位阶跃响应求单位脉冲响应
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 本卷考过把脉冲响应与阶跃响应直接等同
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由二阶特征多项式判断阻尼类型
本卷实例
  • 关键一步：对照标准二阶特征式
  • 中间结果：由一次项系数求阻尼比
  • 卡点：与一比较定阻尼类型
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由二阶特征多项式判断阻尼类型
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过阻尼比公式的系数弄错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 由低频段渐近线斜率判断系统型别
本卷实例
  • 关键一步：看低频段斜率
  • 中间结果：斜率为负二十的整数倍对应型别
  • 卡点：型别由积分环节重数决定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过由低频段渐近线斜率判断系统型别
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 本卷考过把型别与低频斜率的对应关系记反
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 判断不属于时域性能指标的选项
本卷实例
  • 关键一步：按定义区分时域与频域指标
  • 中间结果：上升时间与调节时间属时域指标
  • 卡点：相位裕度属频域指标
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过判断不属于时域性能指标的选项
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过把相位裕度当成时域指标
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
超前校正 系统校正
本卷考法
  • 识别相位超前环节的传递函数
本卷实例
  • 关键一步：由零点与极点位置判断
  • 中间结果：零点在极点左侧为超前环节
  • 卡点：分子分母时间常数大小要比较
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过识别相位超前环节的传递函数
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 本卷考过把超前网络与滞后网络结构搞混
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 判断负反馈系统根轨迹的相角条件
本卷实例
  • 关键一步：由负反馈判相角条件
  • 中间结果：负反馈对应一百八十度根轨迹
  • 卡点：正反馈才是零度根轨迹
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过判断负反馈系统根轨迹的相角条件
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 本卷考过把零度与一百八十度根轨迹搞混
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
