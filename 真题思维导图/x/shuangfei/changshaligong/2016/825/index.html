1一、单项选择题：数学模型、校正与频域概念10 分#

思路
  • 单选：不属于动态数学模型的选项、相位超前校正环节传函、积分环节对稳态性能的影响、Ⅰ型最小相位系统Nyquist起点、闭环频域性能指标
传递函数的定义与基本性质 传递函数
本卷考法
  • 辨识不属于动态数学模型的选项
本卷实例
  • 关键一步：按是否描述输入输出动态关系判断
  • 中间结果：频率特性根轨迹与传函均属动态模型
  • 卡点：信号流图也属动态数学模型
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过辨识不属于动态数学模型的选项
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过把频率特性或根轨迹当成静态模型
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
超前校正 系统校正
本卷考法
  • 辨识相位超前校正环节的传递函数
本卷实例
  • 关键一步：比较分子与分母一次项系数
  • 中间结果：分子时间常数更大者呈超前特性
  • 卡点：含增益的环节需先化成标准形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过辨识相位超前校正环节的传递函数
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 本卷考过把分子分母时间常数的大小关系判反
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 判断增加积分环节对稳态性能的影响
本卷实例
  • 关键一步：按积分环节提高系统型别来分析
  • 中间结果：增加积分环节可减小或消除稳态误差
  • 卡点：精度提高的同时稳定性可能变差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断增加积分环节对稳态性能的影响
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 本卷考过把稳态精度与稳定性变化混为一谈
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 判断Ⅰ型最小相位系统Nyquist曲线的起点
本卷实例
  • 关键一步：由原点开环极点重数确定起点方向
  • 中间结果：一个积分环节使起点在负实轴方向无穷远
  • 卡点：起点方向由型别与增益符号共同决定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过判断Ⅰ型最小相位系统Nyquist曲线的起点
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过漏画积分环节对应的无穷大圆弧
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
闭环频率特性与性能指标 频域分析
本卷考法
  • 辨识属于闭环频域性能的指标
本卷实例
  • 关键一步：区分开环与闭环频率特性指标
  • 中间结果：谐振峰值等属闭环频域性能
  • 卡点：相位裕量与增益裕量属开环指标
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过辨识属于闭环频域性能的指标
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 本卷考过把开环频域指标当成闭环指标
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

2二、填空题：系统组成、校正依据与性能指标10 分#

思路
  • 填空：自动控制系统的组成环节、以频域指标给出时应采用的校正方法、暂态与稳态性能指标、Ⅱ型系统斜坡输入下的稳态误差
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 补全自动控制系统的组成环节
本卷实例
  • 关键一步：按比较反馈测量执行四部分梳理
  • 中间结果：系统由比较反馈测量与执行环节组成
  • 卡点：各环节的信号流向易混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过补全自动控制系统的组成环节
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把测量环节与执行环节混淆
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
校正的基本概念与性能指标 系统校正
本卷考法
  • 指出以频域指标给出时应采用的校正方法
本卷实例
  • 关键一步：由给定量判断属频率特性法
  • 中间结果：频域指标下一般用频率特性法校正
  • 卡点：需先明确未校正系统的主要缺陷
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过指出以频域指标给出时应采用的校正方法
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 本卷考过把时域指标与频域指标对应错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 填出暂态与稳态性能指标
本卷实例
  • 关键一步：按响应过程区分暂态与稳态
  • 中间结果：上升时间与调节时间表征暂态过程
  • 卡点：稳态误差反映系统的控制精度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过填出暂态与稳态性能指标
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过把上升时间与调节时间的归属说反
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 判断Ⅱ型系统单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：按积分环节个数确定系统型别
  • 中间结果：Ⅱ型系统在斜坡输入下误差为零
  • 卡点：型别至少为二时斜坡输入无差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过判断Ⅱ型系统单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过把系统型别数错导致结论相反
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、方框图等效变换求传函10 分#

思路
  • 对多回路结构图用等效变换逐步化简，求出闭环传递函数
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 用串联并联与反馈等效化简方框图
本卷实例
  • 关键一步：从最内环开始逐层化简
  • 中间结果：内环化为单一传函后与外环合并
  • 卡点：反馈极性以原卷结构图为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过用串联并联与反馈等效化简方框图
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过负反馈分母漏写为一加
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
比较点与引出点的移动 结构图与方框图
本卷考法
  • 在化简中处理比较点与引出点移动
本卷实例
  • 关键一步：把交叉的比较点移出公共通路
  • 中间结果：移动后需补乘或补除相应环节
  • 卡点：比较点与引出点移动规则易混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过在化简中处理比较点与引出点移动
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 本卷考过移动方向与乘除关系搞反
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 化简含局部反馈的多回路系统
本卷实例
  • 关键一步：先断开最内环求等效传函
  • 中间结果：逐层向外替换并整理分母
  • 卡点：图较复杂，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过化简含局部反馈的多回路系统
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过化简内环时把外环信号当常数
  • 化简内环时把外环的信号当成常数处理

4四、信号流图与梅逊公式求传函10 分#

思路
  • 由结构图改画信号流图，再用梅逊增益公式求闭环传递函数
