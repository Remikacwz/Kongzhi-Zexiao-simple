1闭环频域性能指标#

思路

闭环频率特性与性能指标 频域分析
本卷考法
  • 列举反映闭环频域性能的指标
本卷实例
  • 关键一步：从闭环幅频曲线的特征量入手找指标
  • 中间结果：带宽、谐振频率与谐振峰值构成闭环频域三指标
  • 卡点：开环截止频率不属于闭环频域性能指标
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过列举反映闭环频域性能的指标
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 本卷考过把开环指标与闭环指标混为一谈
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

思路
  • 填空题：问Ⅱ型系统对数幅频低频段渐近线的斜率
开环对数频率特性的绘制 频域分析
本卷考法
  • 由系统型别写出开环对数幅频低频段斜率
本卷实例
  • 关键一步：按开环积分环节个数决定低频段斜率
  • 中间结果：每个积分环节贡献负二十 dB/dec
  • 卡点：型别数等于积分环节个数，不是开环极点数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤

  • 逐点叠加得到幅频与相频曲线
通用考法

  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 本卷考过低频段起始高度漏乘型别对应的负斜率
  • 逐段改斜率时忘记累加而非替换

3闭环传递函数的错误说法判断#

思路
  • 选择题：给出闭环传函，判断闭环增益、阻尼、稳定性、开环零点四项中哪个说法错误
传递函数的定义与基本性质 传递函数
本卷考法
  • 由闭环传函读出增益、极点与开环零点
本卷实例
  • 关键一步：先把闭环传函化成尾一标准形式
  • 中间结果：尾一形式的常数项即闭环增益
  • 卡点：开环零点要由闭环传函反推开环传函后才能判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由闭环传函读出增益、极点与开环零点
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过把闭环增益直接当成开环增益
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由分母系数判断系统的阻尼状态
本卷实例
  • 关键一步：把闭环特征式对照典型二阶形式定阻尼比
  • 中间结果：由阻尼比大于一或等于一区分过阻尼与临界阻尼
  • 卡点：阻尼比大于一时为过阻尼，等于一时为临界阻尼
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由分母系数判断系统的阻尼状态
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过只比较两个实根大小却不看相等情形
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

4根轨迹相同的条件#

思路
  • 填空/选择：问两系统根轨迹相同，则它们一定共有哪些量
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 说明根轨迹的起点、终点与形状由哪些量决定
本卷实例
  • 关键一步：从根轨迹的幅相条件出发找共同决定量
  • 中间结果：根轨迹相同意味着开环零极点与闭环极点都相同
  • 卡点：根轨迹描述闭环极点随增益移动，起点是开环极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过说明根轨迹的起点、终点与形状由哪些量决定
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 本卷考过把开环极点与闭环极点混为一谈
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

思路

频率特性的物理意义与求法 频域分析
本卷考法
  • 由相频表达式反求给定相角处的角频率
本卷实例
  • 关键一步：把频率特性看成两个一阶惯性环节之积
  • 中间结果：相角等于负二倍的反正切

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由相频表达式反求给定相角处的角频率
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义

  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

  • 指认采样与信号恢复两个环节的器件
本卷实例
  • 关键一步：按信号流向区分采样、保持与放大
  • 中间结果：采样器把连续变离散，保持器把离散变连续
  • 卡点：零阶保持器还会引入半个采样周期的相位滞后
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
