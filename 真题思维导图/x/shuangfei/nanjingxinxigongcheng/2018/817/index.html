1结构图求闭环传递函数#

思路
  • 列回路与前向通路，用梅森公式求闭环传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 由多回路结构图求 C(s)/R(s)
本卷实例
  • 关键一步：先标出全部独立回路，再找前向通路
  • 中间结果：特征式由各回路增益叠加而成
  • 卡点：回路极性决定特征式符号；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由多回路结构图求 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路漏计或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 三环以上结构图逐层等效化简
本卷实例
  • 关键一步：由内到外逐层等效，或统一用梅森公式
  • 中间结果：两次反馈等效后化为单回路形式
  • 卡点：引出点与比较点位置需辨认；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过三环以上结构图逐层等效化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过化简内环时把外环信号当常数处理
  • 化简内环时把外环的信号当成常数处理

2劳斯判据确定稳定K范围#

思路
  • 列闭环特征方程，用劳斯判据求使系统稳定的k取值范围
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据确定使系统稳定的k取值范围
本卷实例
  • 关键一步：由结构图写出闭环特征方程再列劳斯表
  • 中间结果：稳定条件归结为劳斯表首列全为正
  • 卡点：首列元素的不等式取交集；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据确定使系统稳定的k取值范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过首列出现零后未用 ε 法继续判别
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求使闭环稳定的参数上界与下界
本卷实例
  • 关键一步：逐行列写劳斯表并整理各不等式
  • 中间结果：稳定域由若干不等式共同限定
  • 卡点：端点是否包含需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求使闭环稳定的参数上界与下界
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 本卷考过漏掉某个首列约束致稳定域偏大
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

3开环根轨迹绘制#

思路
  • 由开环传函的零极点分布按法则绘制根轨迹
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画根轨迹草图并求渐近线
本卷实例
  • 关键一步：先标零极点与实轴段，再求渐近线
  • 中间结果：渐近线条数与交点、夹角可由零极点定
  • 卡点：实轴根轨迹段的取舍需核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画根轨迹草图并求渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴段判据的零极点个数算错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹在实轴上的分离点
本卷实例
  • 关键一步：由特征方程极值条件求分离点候选
  • 中间结果：分离点坐标须回幅值条件验证取舍
  • 卡点：分离点可能不止一个，需逐个验证
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹在实轴上的分离点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 本卷考过求得候选点后未筛选不在轨迹上的解
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴的交点及临界增益
本卷实例
  • 关键一步：令 s 取纯虚数代入特征方程分离实虚部
  • 中间结果：由实虚部为零联立解出频率与增益
  • 卡点：穿越虚轴的方向由增益变化判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴的交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 本卷考过只代一个角频率值就下结论而漏解
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

4最小相位系统Bode图反求传函#

思路
  • 由对数渐近幅频特性的低频段与转折频率反写开环传函
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频渐近线反求开环传递函数
本卷实例
  • 关键一步：由低频段斜率定型别，由高度定增益
  • 中间结果：各转折频率对应一个一阶环节
  • 卡点：斜率变化量决定环节阶次；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频渐近线反求开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 本卷考过把延长线交点当增益而未折算型别
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式

本卷考法

本卷实例

  • 卡点：最小相位系统无右半平面零极点

  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大

步骤

通用考法

  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数

  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈

5串联超前与滞后校正方案比较#

思路
  • 分别写出超前、滞后校正前后开环传函并比较作用与优缺点
超前校正 系统校正
本卷考法
  • 写出超前校正后的开环传递函数
本卷实例
  • 关键一步：固定部分与超前装置相乘得校正后传函
  • 中间结果：超前校正抬高截止频率与相角裕度
  • 卡点：校正前后的稳态增益要分别核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过写出超前校正后的开环传递函数
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 本卷考过计算补偿角忽略截止频率变化的影响
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
滞后校正 系统校正
本卷考法
  • 写出滞后校正后的开环传递函数
本卷实例
  • 关键一步：在原开环上串入滞后网络改写传函
  • 中间结果：滞后校正压低高频增益而少动低频段
  • 卡点：滞后校正牺牲响应速度需权衡
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过写出滞后校正后的开环传递函数
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 本卷考过滞后网络两转折频率的顺序写反
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
