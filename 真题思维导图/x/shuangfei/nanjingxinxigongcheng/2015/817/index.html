一（1~8）填空：二阶系统与频域指标#

思路
  • 八道填空覆盖二阶系统参数、频率特性、临界稳定、频域指标、速度误差与最小相位概念
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由给定二阶传递函数求自然频率与阻尼比
本卷实例
  • 关键一步：与二阶标准形式对号入座读出两个待求量
  • 中间结果：分母常数项对应自然频率的平方
  • 卡点：传递函数未作首一化时不能直接对比系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由给定二阶传递函数求自然频率与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过把分母一次项系数直接当作阻尼比
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求一阶微分环节在指定频率处的相频特性值
本卷实例
  • 关键一步：把 s 换成 jω 后取虚部与实部之比
  • 中间结果：相频特性写为反正切的形式
  • 卡点：需先明确该频率与环节时间常数的关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求一阶微分环节在指定频率处的相频特性值
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过忘记把给定频率代入而只写一般式
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求使闭环系统达到临界稳定的参数值
本卷实例
  • 关键一步：列闭环特征方程后写出劳斯表首列
  • 中间结果：临界值对应首列某个元素取零
  • 卡点：含参首列元素为零时要单独讨论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求使闭环系统达到临界稳定的参数值
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 本卷考过把临界稳定与渐近稳定两个条件混淆
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
闭环频率特性与性能指标 频域分析
本卷考法
  • 列举常用的闭环频域性能指标
本卷实例
  • 关键一步：从闭环幅频特性的峰与带宽两个角度列指标
  • 中间结果：常见指标含谐振峰值与谐振频率
  • 卡点：带宽与截止频率不是同一概念
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过列举常用的闭环频域性能指标
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 本卷考过把开环频域指标与闭环指标混答
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位负反馈系统单位斜坡输入下的速度误差
本卷实例
  • 关键一步：先用型别判断速度误差是否为有限值
  • 中间结果：误差等于速度误差系数的倒数
  • 卡点：开环积分环节个数决定速度误差是否有限
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位负反馈系统单位斜坡输入下的速度误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过未判稳就直接对误差取终值
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
滞后校正 系统校正
本卷考法
  • 比较串联滞后校正前后截止频率的大小关系
本卷实例
  • 关键一步：从滞后网络压低高频幅值的角度分析
  • 中间结果：校正后截止频率通常低于校正前
  • 卡点：结论要结合校正后相角裕度是否提升
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过比较串联滞后校正前后截止频率的大小关系
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 本卷考过把滞后校正与超前校正的频率变化方向搞反
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
劳斯判据 稳定性分析
本卷考法
  • 说明判断线性系统稳定性的常用方法
本卷实例
  • 关键一步：按代数判据与频域判据两条线梳理
  • 中间结果：劳斯判据与奈氏判据各有适用场合
  • 卡点：李雅普诺夫方法针对非线性或状态空间模型
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过说明判断线性系统稳定性的常用方法
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过只答时域判据而漏掉频域判据
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

最小相位系统与非最小相位系统 频域分析
本卷考法
  • 给出最小相位系统在零极点分布上的定义
本卷实例
  • 关键一步：从开环零极点实部符号描述最小相位性
  • 中间结果：最小相位系统不含右半平面零极点
  • 卡点：仅凭幅频特性不能唯一确定非最小相位系统
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过给出最小相位系统在零极点分布上的定义
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 本卷考过把闭环与开环的最小相位条件相混
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈

2结构图化简求闭环传函#

思路
  • 用结构图等效变换或梅森公式求图示多回路系统的闭环传递函数
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 用结构图等效变换逐层化简多回路系统
本卷实例
  • 关键一步：由最内层回路向外逐层合并
  • 中间结果：每个回路化为前向与反馈之比
  • 卡点：比较点与引出点的极性判别需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过用结构图等效变换逐层化简多回路系统
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过化简内环时把外环信号当成常数
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求系统的闭环传递函数
本卷实例
  • 关键一步：先找全部回路再找指定输入输出的前向通路
  • 中间结果：特征式含互不接触回路的乘积项
  • 卡点：回路与前向通路的增益勿混写
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求系统的闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过余子式中未剔除与前向通路接触的回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 增加积分环节可提高型别，代价是相位滞后与超调增大

步骤

  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
