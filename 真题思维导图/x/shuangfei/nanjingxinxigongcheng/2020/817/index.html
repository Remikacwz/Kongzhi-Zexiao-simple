1结构图参考与扰动传函及总输出25 分#

思路
  • 分别求参考输入与扰动作用下的闭环传函，再求总输出
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求参考输入下的闭环传函
本卷实例
  • 关键一步：标出全部回路与前向通路再求特征式
  • 中间结果：特征式由各回路叠加得到
  • 卡点：回路极性决定特征式符号；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求参考输入下的闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过互不接触回路漏计或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2根轨迹绘制与欠阻尼增益范围30 分#

思路
  • 绘制概略根轨迹，再求欠阻尼与稳态误差两项指标共同限定的增益范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制概略根轨迹并指明渐近线与分支数
本卷实例
  • 关键一步：先标零极点分布与实轴根轨迹段
  • 中间结果：渐近线条数等于极点数减零点数
  • 卡点：渐近线夹角与交点公式须核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制概略根轨迹并指明渐近线与分支数
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴段判据零极点个数算错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界增益
本卷实例
  • 关键一步：令 s 取纯虚数代入特征方程分离实虚部
  • 中间结果：联立解得临界频率与增益
  • 卡点：增益增大时根轨迹穿越方向
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 本卷考过只代一个角频率值而漏掉另一组解
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

由根轨迹分析性能与确定参数 根轨迹法
本卷考法

本卷实例
  • 关键一步：在 s 平面画等阻尼比射线与轨迹求交
  • 中间结果：交点的模长对应临界增益
  • 卡点：欠阻尼区间由射线夹角界定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹确定满足欠阻尼的增益范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 本卷考过把等阻尼线画成竖直线
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

  • 中间结果：斜坡输入下误差与开环增益成反比
  • 卡点：误差上界与欠阻尼区间取交集

  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差

  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表

  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力

3Bode反求传函与串联校正设计30 分#

思路
  • 由对数幅频曲线反求开环传函并判断稳定性，再据校正曲线写校正装置传函
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频特性反求开环传递函数
本卷实例
  • 关键一步：由低频段斜率与高度确定型别和增益
  • 中间结果：各转折频率对应一个惯性或微分环节
  • 卡点：转折频率处斜率变化量决定阶次
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频特性反求开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 本卷考过把延长线交点当增益而未折算型别
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 求校正前系统的相角裕度并判断稳定
本卷实例
  • 关键一步：由截止频率读相角求相角裕度
  • 中间结果：裕度为正表示闭环稳定
  • 卡点：非最小相位系统慎用同一判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求校正前系统的相角裕度并判断稳定
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过把截止频率与相位穿越频率用反
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

滞后校正 系统校正
本卷考法
  • 据校正装置幅频曲线写出其传递函数
本卷实例
  • 关键一步：由校正曲线低频与高频段斜率定环节
  • 中间结果：固定部分与校正装置相乘得新开环
  • 卡点：校正后截止频率会移动需重新核算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过据校正装置幅频曲线写出其传递函数
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 本卷考过滞后网络两个转折频率次序写反
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

思路

奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅相曲线确定闭环稳定的增益范围
本卷实例

  • 中间结果：曲线与负实轴交点决定临界增益

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤

  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环幅相曲线确定闭环稳定的增益范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过含积分环节时未补画无穷大半径圆弧
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

离散系统稳定性分析 离散控制系统
本卷考法
  • 由闭环特征方程判断离散系统稳定性
本卷实例
  • 关键一步：先判断特征根是否都在单位圆内
  • 中间结果：可用双线性变换后套用劳斯判据
  • 卡点：高阶方程宜先做双线性变换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
