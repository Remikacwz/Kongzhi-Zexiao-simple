1信号流图与梅森公式#

思路

本卷考法

本卷实例

  • 卡点：图为原卷结构图，需回原卷核对比较点与引出点位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项

  • 代入公式求总传输

  • 由信号流图求 C(s)/R(s)

  • 不接触回路找漏或重复计数

  • 先由相角裕度条件反求截止频率，再用滞后校正降低截止频率把相角裕度抬到60度
稳定裕度 频域分析
本卷考法
  • 由给定相角裕度反求截止频率
本卷实例
  • 关键一步：在相频曲线上令相角等于负180度加相角裕度
  • 中间结果：由相角方程解出截止频率
  • 卡点：校正结构图不在文本中，需回原卷核对，本图不读图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg

  • 由裕度符号判断稳定性

  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错

  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
