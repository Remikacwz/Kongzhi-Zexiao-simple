1结构图信号流图与梅森公式#

思路
  • 由结构图绘制信号流图，用梅森公式求参考输入和扰动两个闭环传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图先画信号流图再用梅森增益公式求传函
本卷实例
  • 关键一步：先找出全部回路再确定各前向通路
  • 中间结果：特征式由两个回路的接触关系组合得到
  • 卡点：从扰动到输出的前向通路增益含负号；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图先画信号流图再用梅森增益公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过前向通路与回路数漏计
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求扰动作用下的输出传递函数
本卷实例
  • 关键一步：把扰动视为独立输入单独找通路
  • 中间结果：扰动通路与回路的接触关系决定余子式
  • 卡点：扰动接入点的极性决定通路增益符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求扰动作用下的输出传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 本卷考过求扰动传函时未把参考输入置零
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

2单位反馈二阶系统参数与稳态误差#

思路
  • 由结构图求闭环二阶模型，先按给定增益求动态参数，再由双指标反求两个结构参数
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把含速度反馈的结构等效为典型二阶系统
本卷实例
  • 关键一步：先求开环传函再求闭环传函对照标准形
  • 中间结果：闭环分母一次项系数含反馈系数
  • 卡点：参数对应关系须逐项比对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把含速度反馈的结构等效为典型二阶系统
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过化简时反馈支路的 s 项处理错误
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡输入下的系统稳态误差
本卷实例
  • 关键一步：先列劳斯条件再取速度误差系数
  • 中间结果：误差表达式由开环增益决定
  • 卡点：稳定条件下误差公式才成立
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位斜坡输入下的系统稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过未判稳就直接取稳态误差
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由阻尼比与稳态误差双指标反求两个参数
本卷实例
  • 关键一步：把两个指标写成两个独立方程联立
  • 中间结果：先由误差条件消去一个未知量
  • 卡点：解需回代稳定条件检验
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由阻尼比与稳态误差双指标反求两个参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 本卷考过只满足单项指标就定参数
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

3幅相曲线与奈氏稳定K范围#

思路
  • 由开环传递函数画概略幅相曲线，用奈氏判据按时间常数正负讨论稳定增益范围
频率特性的物理意义与求法 频域分析
本卷考法
  • 求三阶开环系统的幅频与相频特性
本卷实例
  • 关键一步：求幅相曲线与负实轴交点对应频率
  • 中间结果：交点处相角为负一百八十度
  • 卡点：时间常数符号改变曲线走向
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求三阶开环系统的幅频与相频特性
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过相角中积分环节的九十度漏算
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈氏判据分情况讨论使系统稳定的增益范围
本卷实例
  • 关键一步：按时间常数正负分区间数包围圈数
  • 中间结果：临界点由交点幅值等于一确定
  • 卡点：时间常数为负时开环含右半平面极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈氏判据分情况讨论使系统稳定的增益范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过不先数开环右半平面极点就套判据
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 给出参数稳定域的上下界
本卷实例
  • 关键一步：分别对时间常数正负列稳定条件
  • 中间结果：时间常数为负时系统恒不稳定
  • 卡点：时间常数为零的分界点需单独说明
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过给出参数稳定域的上下界
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 本卷考过取交集时端点遗漏
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

4Bode图反求传函与相角裕度#

思路
  • 由对数幅频渐近线反求开环传递函数与增益，再求截止频率和相角裕度
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由低频段斜率和高度反求型别与开环增益
本卷实例
  • 关键一步：由低频段所过点折算开环增益
  • 中间结果：转折频率处斜率变化对应各环节
  • 卡点：转折频率需从图线读出；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由低频段斜率和高度反求型别与开环增益
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 本卷考过把低频延长线交点直读为增益
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 求系统的截止频率与相角裕度
本卷实例
  • 关键一步：在转折频率区间内列幅值近似方程
  • 中间结果：截止频率由低频段近似式解出
  • 卡点：近似区间与转折频率须自洽
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求系统的截止频率与相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过截止频率与相位穿越频率用反
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

5特征多项式稳定性与根分布10 分#

思路
  • 对两个高阶特征多项式列劳斯表，判断稳定性并给出特征根分布
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断高阶系统稳定性并指出根的分布
本卷实例
  • 关键一步：列劳斯表并数首列符号变化次数
  • 中间结果：符号变化次数对应右半平面根个数
  • 卡点：首列出现全零行需借助辅助方程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断高阶系统稳定性并指出根的分布
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过首列出现零元时不作特殊处理
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

6非最小相位根轨迹与稳定K范围#

思路
  • 绘制含右半平面极点的系统根轨迹，求分离点与虚轴交点并确定稳定开环增益范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制含右半平面极点与零点的系统根轨迹
本卷实例
  • 关键一步：先定实轴段与渐近线方向
  • 中间结果：两条分支起于两个开环极点
  • 卡点：复数部分的轨迹形态需结合韦达定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称

本卷考法

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）

步骤

  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
