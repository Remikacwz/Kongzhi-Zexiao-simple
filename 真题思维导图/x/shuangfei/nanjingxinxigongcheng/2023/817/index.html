1方程组绘制结构图与传函#

思路
  • 把四个拉氏变换方程按因果关系逐项搭成比较点与环节组成结构图，再用梅森公式求闭环传函
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 由给定方程组画出系统的结构图
本卷实例
  • 关键一步：按每个方程的输出等于各输入项代数和逐个画环节
  • 中间结果：把X1、X2、X3、C依次作为节点逐级连接
  • 卡点：方程组的反馈极性决定比较点正负号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过由给定方程组画出系统的结构图
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把比较点的反馈极性接反
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图用梅森公式求闭环传递函数
本卷实例
  • 关键一步：数出全部回路与前向通路再写特征式
  • 中间结果：特征式中互不接触回路的乘积项不要漏
  • 卡点：前向通路与回路的接触关系需按结构图核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图用梅森公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过余子式中未剔除与前向通路接触的回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2劳斯判据与主导极点法20 分#

思路
  • 由结构图写开环传函与闭环特征式，用劳斯判据求稳定Kb范围；由指定闭环极点反求参数并求其余根，再用主导极点法降阶求调节时间与稳态误差
参数稳定域的确定 稳定性分析
本卷考法
  • 由闭环特征式列劳斯表求使系统稳定的Kb范围
本卷实例
  • 关键一步：写闭环特征式后列劳斯表并令首列同号
  • 中间结果：由首列不等式组取交集得参数稳定域
  • 卡点：含参首列元素作分母时要单独讨论符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法

  • 求使系统稳定的参数上界或下界

  • 比较不同参数对稳定域大小的影响
常见易错

  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法

本卷实例

  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤

通用考法

  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由

  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 在指定增益下求单位阶跃响应的稳态误差
本卷实例
  • 关键一步：由开环传函判断型别再取静态误差系数
  • 中间结果：单位负反馈且开环含积分环节时阶跃误差为零
  • 卡点：稳态误差须在闭环参数确定后计算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差

  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法

  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力

  • 未判稳就使用终值定理

3参数根轨迹与临界阻尼20 分#

思路
  • 把闭环特征式整理成以参数a为可变增益的根轨迹形式，按参数根轨迹法则绘图，再由重极点条件求临界阻尼对应的a值
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 由特征式整理出以参数a为变量的广义根轨迹
本卷实例
  • 关键一步：把含a的项归并成a乘某传函的形式再套根轨迹法则
  • 中间结果：等效开环传函的零点与极点决定轨迹形状
  • 卡点：本法按一百八十度相角条件绘制
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过由特征式整理出以参数a为变量的广义根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 本卷考过整理时没有把参数完整提到分子位置
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

分离点与会合点 根轨迹法
本卷考法
  • 由根轨迹分离点求临界阻尼对应的a值
本卷实例
  • 关键一步：临界阻尼对应闭环特征方程出现重根
  • 中间结果：令特征式与其导数同时为零解出参数
  • 卡点：重根位置须落在实轴根轨迹段上
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0

步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由根轨迹分离点求临界阻尼对应的a值
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 本卷考过求出根后不筛选就全部保留
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

由根轨迹分析性能与确定参数 根轨迹法

  • 把等阻尼线画成了垂直线

4奈氏图反求与稳定K范围#

思路
  • 由最小相位典型二阶系统的奈氏曲线与虚轴交点反求Ga(s)，再画G(s)等于K比s乘Ga(s)的幅相曲线并用奈氏判据求稳定K范围
频率特性的物理意义与求法 频域分析
本卷考法
  • 由奈氏曲线与虚轴交点反求典型二阶环节
本卷实例
  • 关键一步：把交点频率处的幅值与相角代入二阶环节表达式
  • 中间结果：由实部虚部为零的条件解出阻尼比与自然频率
  • 卡点：奈氏图不在文本中，需回原卷核对交点坐标与幅值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由奈氏曲线与虚轴交点反求典型二阶环节
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过幅值与相角的复数关系写错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

奈奎斯特判据 稳定性分析
本卷考法
  • 用奈氏判据求使闭环稳定的K值范围
本卷实例
  • 关键一步：由幅相曲线包围临界点的圈数结合P判稳
  • 中间结果：使曲线不包围临界点的K区间即稳定范围
  • 卡点：临界增益处为临界稳定，区间端点按题目口径取
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈氏判据求使闭环稳定的K值范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过含积分环节时未补画无穷大半径圆弧
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

5对数幅频反求与超前校正#

思路
  • 由对数幅频渐近线低频段与转折频率反求开环传函，判断Gc等于一时系统稳定性，最后设计超前校正使相角裕度大于给定值
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环对数幅频渐近线反求传递函数
本卷实例
  • 关键一步：由低频段斜率与高度定型别和增益
  • 中间结果：各转折频率处斜率变化对应典型环节
  • 卡点：负四十分贝每十倍频程要判断是一阶还是二阶环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环对数幅频渐近线反求传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 本卷考过延长线交点未折算型别就当开环增益
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

稳定裕度 频域分析
本卷考法
