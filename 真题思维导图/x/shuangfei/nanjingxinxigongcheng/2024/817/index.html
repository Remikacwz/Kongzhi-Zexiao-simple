1信号流图、梅森公式与稳定K范围#

思路
  • 由结构图画出信号流图并用梅森公式求闭环传函，再由闭环特征式列劳斯表求使系统稳定的K范围
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图绘制信号流图并用梅森公式求闭环传函
本卷实例
  • 关键一步：数出全部回路与前向通路，写特征式与余子式
  • 中间结果：特征式为各回路增益之和，本题无互不接触回路
  • 卡点：结构图以图给出，回路与前向通路需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图绘制信号流图并用梅森公式求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

参数稳定域的确定 稳定性分析
本卷考法
  • 由闭环特征式列劳斯表求使系统稳定的K范围
本卷实例
  • 关键一步：写闭环特征多项式并列劳斯表，令首列同号
  • 中间结果：由首列不等式组取交集得K的范围
  • 卡点：首列含参元素作分母时须单独讨论符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由闭环特征式列劳斯表求使系统稳定的K范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

2由阶跃响应反求参数与正弦稳态误差#

思路
  • 由单位阶跃响应表达式的衰减率与振荡角频率定阻尼比与自然频率，再由稳态值定开环增益与参数；最后用误差频率特性求正弦输入下的稳态误差
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应表达式反求系统参数
本卷实例
  • 关键一步：把响应式与欠阻尼二阶阶跃响应标准形式对应
  • 中间结果：由衰减指数与振荡角频率定阻尼比与自然频率
  • 卡点：响应式中相位与系数须与标准式逐项对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应表达式反求系统参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由阶跃响应求阻尼比、自然频率并定闭环参数
本卷实例
  • 关键一步：由响应稳态值与标准式系数关系反求开环增益
  • 中间结果：闭环常数项与一次项系数决定两个待求参数
  • 卡点：先由响应定阻尼比与自然频率再对应传函系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由阶跃响应求阻尼比、自然频率并定闭环参数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

频率特性的物理意义与求法 频域分析
本卷考法
  • 求正弦输入下系统的稳态误差
本卷实例
  • 关键一步：由误差传函在输入频率处取幅值与相角
  • 中间结果：稳态误差为同频正弦，幅值相位由误差传函决定
  • 卡点：求稳态误差要用误差传函，不是闭环传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求正弦输入下系统的稳态误差
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

3根轨迹绘制与衰减振荡K范围#

思路
  • 由开环传函整理出180度根轨迹方程，按法则求极点、实轴段、渐近线、分离点与虚轴交点，再据衰减振荡条件定K范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制给定开环传函的根轨迹
本卷实例
  • 关键一步：先定开环极点与实轴段，再算渐近线与分离点
  • 中间结果：三条轨迹起于三个开环极点，两条渐近线在正负60度
  • 卡点：实轴段判据要数该点右侧的零极点个数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制给定开环传函的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 由分离点确定系统由单调转为振荡的临界增益
本卷实例
  • 关键一步：令增益对s的导数为零求分离点，再代回特征方程
  • 中间结果：分离点处的增益是衰减振荡区间的下界
  • 卡点：求出的分离点要判是否落在实轴根轨迹段上
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由分离点确定系统由单调转为振荡的临界增益
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴的交点及临界增益
本卷实例
  • 关键一步：令s取纯虚数代入特征方程，分离实部虚部求解
  • 中间结果：交点频率与临界增益由两个方程联立确定
  • 卡点：与虚轴交点对应临界稳定，区间端点按开区间取
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴的交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹分析衰减振荡对应的K范围
本卷实例
  • 关键一步：以分离点与虚轴交点为界划分增益区间
  • 中间结果：两界之间增益对应闭环共轭复根
  • 卡点：衰减振荡要求闭环复根的实部为负
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹分析衰减振荡对应的K范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

奈奎斯特判据 稳定性分析
本卷考法
  • 用奈氏判据判断闭环系统稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数，再数包围临界点的圈数
  • 中间结果：曲线不包围临界点时闭环稳定
  • 卡点：含积分环节时要补画无穷大半径圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈氏判据判断闭环系统稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

5斜坡稳态误差、Bode图与幅值裕度#

思路
  • 由结构图写开环传函，先由劳斯判据定稳定K范围，再由斜坡稳态误差要求确定增益并画对数渐近幅频特性；最后求幅值裕度
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡稳态误差要求反求开环增益
本卷实例
  • 关键一步：由型别写出速度误差系数，令误差倒数满足要求
  • 中间结果：稳态误差等于速度误差系数的倒数
  • 卡点：先判稳再取稳态误差，增益的上下界要同时满足
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
