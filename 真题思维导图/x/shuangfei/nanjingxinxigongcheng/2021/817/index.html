梅森增益公式与信号流图 传递函数
本卷考法

本卷实例

2二阶系统参数与阶跃响应#

思路
  • 由结构图求开环与闭环传函，与二阶标准式对照解出阻尼比与自然频率，再用部分分式与拉氏反变换求单位阶跃响应
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征多项式对照二阶标准式求阻尼比与自然频率
本卷实例
  • 关键一步：把闭环特征多项式与二阶标准式对应系数进行比较
  • 中间结果：由系数关系列出求阻尼比与自然频率的方程
  • 卡点：开环特征式与闭环特征式不要混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征多项式对照二阶标准式求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过未把二次项系数归一化就直接读参数
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

思路

本卷考法

本卷实例
