哈尔滨理工大学 810 自动控制原理 2021 年真题思维导图

强势双非共 8 题

难度：中等　全卷 8 题。第 1 题结构图化简求闭环传函，第 2 题四阶特征方程劳斯判据判稳并数右半平面根，第 3 题二阶系统动态指标与参数反求，第 4 题绘根轨迹并求稳定 K 范围，第 5 题由对数幅频渐近线反求传函并说明中频段特点，第 6 题饱和非线性描述函数法分析增益对稳定性影响，第 7 题按静态误差系数与相角增益裕量要求设计超前校正，第 8 题离散系统朱莉判据求临界增益。第 1、3、4、5、6、8 题题面含原卷插图。

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

1一、结构图化简求闭环传递函数（图）#

思路
  • 对多回路结构图先做比较点等效移动消除交叉，再按串联、并联与反馈公式逐层化简；也可先用梅森增益公式列全部独立回路与前向通路，两者结果应一致。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简求闭环传递函数
本卷实例
  • 关键一步：从最内层回路入手求等效环节，再并入外层逐级化简
  • 中间结果：内环等效后化为若干串联并联支路，再套单回路反馈公式
  • 卡点：回路层数与连接关系在原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简求闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
比较点与引出点的移动 结构图与方框图
本卷考法
  • 移动比较点或引出点消除交叉连接
本卷实例
  • 关键一步：按前移用除、后移用乘的规则移动点，保持变量关系不变
  • 中间结果：移动后各支路关系与原图等价，再套串并联反馈等效
  • 卡点：哪些点需要移动、移动方向如何由原图决定，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过移动比较点或引出点消除交叉连接
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 用串并联与反馈等效公式化简无交叉回路
本卷实例
  • 关键一步：对已消除交叉的局部回路套用前向除一加开环的等效
  • 中间结果：各等效环节相乘相加后代入整个系统的闭环表达式
  • 卡点：反馈极性判断错会把分母写成一减开环，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过用串并联与反馈等效公式化简无交叉回路
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式由信号流关系求闭环传函
本卷实例
  • 关键一步：先数清全部独立回路并判断两两是否接触，再求特征式
  • 中间结果：特征式为各回路增益代数和，前向通路与余子式相乘后相加
  • 卡点：不接触回路易找漏或重复计数，余子式要剔除接触回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式由信号流关系求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式

2二、劳斯判据判稳定与右半平面根个数#

思路
  • 把四阶特征方程按降幂排列列劳斯表，观察首列符号变化次数即右半平面根个数；首列出现符号不一致即判系统不稳定。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断给定特征方程系统是否稳定
本卷实例
  • 关键一步：把特征式按降幂排列逐行列劳斯表，缺项补零
  • 中间结果：首列出现由正变负，符号变化两次即不稳定
  • 卡点：系数缺项不补零会漏判，首列为零要改用辅助方程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断给定特征方程系统是否稳定
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
赫尔维茨判据 稳定性分析
本卷考法
  • 比较代数判据并核对不稳定根个数
本卷实例
  • 关键一步：用赫尔维茨行列式与劳斯首列符号变化次数互相印证
  • 中间结果：两种判据给出的右半平面根个数应相同
  • 卡点：只验证到低阶主子式就下结论，会漏掉高阶结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由特征方程系数构造赫尔维茨行列式
  • 各阶主子式全部大于零 ⇔ 系统稳定
  • 与劳斯判据等价，适合阶数较低时使用
步骤
  • 由特征方程系数写出赫尔维茨行列式
  • 依次计算各阶主子式
  • 令全部主子式大于零得到稳定条件
通用考法
  • 本卷考过比较代数判据并核对不稳定根个数
  • 用赫尔维茨判据判断稳定性
  • 比较两种代数判据的适用场合
常见易错
  • 行列式构造时系数下标写错
  • 只验证到二阶主子式就下结论
公式

3三、二阶系统动态性能与参数反求#

思路
  • 先由闭环传函化为标准二阶式得自然频率与阻尼比，代入峰值时间、超调量与调节时间公式；第(2)问由给定阻尼比反解增益。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为标准二阶形式求阻尼与自然频率
本卷实例
  • 关键一步：闭环分母首项归一化后与标准式逐项比对系数
  • 中间结果：由一次项系数与常数项分别解出阻尼比与自然频率
  • 卡点：首项系数未归一化会使参数比对出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为标准二阶形式求阻尼与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼与自然频率求峰值时间、超调量与调节时间
本卷实例
  • 关键一步：分别代入峰值时间、超调量与调节时间公式，误差带取题给值
  • 中间结果：超调量只与阻尼比有关，调节时间与衰减系数成反比
  • 卡点：2% 与 5% 误差带的调节时间系数不同，要看清题给 Δ
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼与自然频率求峰值时间、超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由给定阻尼比要求反求开环增益
本卷实例
  • 关键一步：令闭环分母一次项系数等于二倍阻尼比乘自然频率
  • 中间结果：由该等式反解出满足阻尼比要求的增益
  • 卡点：反解前要确认自然频率不随该增益变化，否则需联立
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由给定阻尼比要求反求开环增益
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式

4四、根轨迹绘制与稳定 K 范围#

思路
  • 由开环极点确定根轨迹分支数、实轴段与三条渐近线，求分离点并令 s 等于 jω 解虚轴交点，最后由穿越虚轴的临界增益给出稳定范围。
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 用相角与幅值条件说明根轨迹上的点与增益
本卷实例
  • 关键一步：判断点是否在根轨迹上用相角条件，求对应增益用幅值条件
  • 中间结果：满足相角条件的点构成根轨迹，幅值条件定该点增益
  • 卡点：负反馈用 180 度相角条件，正反馈才用零度条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过用相角与幅值条件说明根轨迹上的点与增益
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则定实轴段、渐近线交点与夹角
本卷实例
  • 关键一步：由三个开环极点位置定实轴根轨迹段与三条渐近线
  • 中间结果：渐近线交点为极点实部均值，夹角按奇数等分 180 度
  • 卡点：实轴段按右侧零极点总数为奇数判断，易漏复极点贡献
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则定实轴段、渐近线交点与夹角
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹分离点并筛选合法解
本卷实例
  • 关键一步：对开环传函列分离点方程，得关于 d 的一元二次方程并求解
  • 中间结果：两个根中只有一个落在实轴根轨迹段上
  • 卡点：不在根轨迹段上的根要舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求校正后系统的相角裕度与幅值裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
