哈尔滨理工大学 810 自动控制原理 2025 年真题思维导图

强势双非共 8 题

难度：中等　全卷 8 题、满分 150 分，卷面未逐题标分值。第 1 题结构图化简求传函，第 2 题劳斯判据判等幅振荡，第 3 题一阶系统斜坡误差与二阶动态指标，第 4 题以 a 为参变量的参数根轨迹与稳定域，第 5 题由对数幅频渐近线反求传函并算剪切频率，第 6 题描述函数法判非线性稳定性，第 7 题串联滞后-超前校正选型与相位裕度，第 8 题采样系统脉冲传函与零阶保持器。含图题较多，第 1、5、6、7、8 题题面含原卷插图。

1一、方框图变换求传递函数（图 1）#

思路
  • 对多回路结构图按最内层回路逐层化简；含交叉比较点或引出点时先做等效移动，最终化为单回路求得 C(s)/R(s)。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简求闭环传递函数
本卷实例
  • 关键一步：从最内层回路入手，先求内环等效环节再参与外层化简
  • 中间结果：内环等效后化为单回路，分子分母由各支路增益组合
  • 卡点：回路层数与交叉点位于原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简求闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
比较点与引出点的移动 结构图与方框图
本卷考法
  • 移动交叉比较点或引出点以消除交叉连接
本卷实例
  • 关键一步：按前移用除、后移用乘的规则移动点，保持变量关系不变
  • 中间结果：移动后各支路关系与原图等价，再套串并联反馈等效
  • 卡点：原图未读，哪些点需要移动需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过移动交叉比较点或引出点以消除交叉连接
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 用串并联与反馈等效公式化简无交叉回路
本卷实例
  • 关键一步：对已消除交叉的局部回路套用 G/(1+GH) 等效
  • 中间结果：各等效环节相乘相加后代入整个系统的闭环表达式
  • 卡点：反馈极性判断错会把分母写成 1-GH，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过用串并联与反馈等效公式化简无交叉回路
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、劳斯判据判等幅振荡#

思路
  • 对四阶闭环特征方程列劳斯表，令 s¹ 行元素为零得临界增益，再由辅助方程求虚轴交点得振荡频率。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据确定等幅振荡的临界增益
本卷实例
  • 关键一步：把特征式按降幂排列逐行列劳斯表，注意含 K 的行
  • 中间结果：s¹ 行元素含 K 的一次式，令其为零即临界条件
  • 卡点：系数缺项要补零，含 K 的行不能直接约去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据确定等幅振荡的临界增益
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由辅助方程求临界时的振荡频率
本卷实例
  • 关键一步：临界时改用辅助方程，解出一对纯虚根得角频率
  • 中间结果：辅助方程只保留临界行的元素，对应虚轴上的根
  • 卡点：端点对应临界稳定，继续列劳斯表会出现零首列
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由辅助方程求临界时的振荡频率
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式

3三、单位负反馈系统稳态误差与动态性能#

思路
  • 先写闭环与误差传函并判稳，斜坡输入用终值定理求稳态误差；再把闭环化为标准二阶形式，由阻尼比与自然频率求超调量和 5% 调节时间。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求一型系统斜坡输入下的稳态误差
本卷实例
  • 关键一步：写出闭环误差传函，确认闭环稳定后用终值定理
  • 中间结果：误差传函分子含 s 的一次项，斜坡误差为增益倒数形式
  • 卡点：未先判定 T1、K1 为正就使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求一型系统斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为标准二阶形式求阻尼与自然频率
本卷实例
  • 关键一步：闭环分母首项归一化后与标准式逐项比对系数
  • 中间结果：由一次项系数与常数项分别解出阻尼比与自然频率
  • 卡点：首项系数 T1 未归一化会使参数比对出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为标准二阶形式求阻尼与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼与自然频率求超调量和 5% 调节时间
本卷实例
  • 关键一步：分别代入超调量与调节时间公式，误差带取 5%
  • 中间结果：超调量只与阻尼比有关，调节时间与衰减系数成反比
  • 卡点：5% 与 2% 误差带的调节时间系数不同，题给 5%
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼与自然频率求超调量和 5% 调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

4四、以 a 为参变量的参数根轨迹与稳定域#

思路
  • 把含参数 a 的特征方程整理成 1 加 a 乘等效开环传函的形式，按常规法则画参数根轨迹，依次求极点、渐近线、分离点、出射角与虚轴交点，再由虚轴交点定稳定范围。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 把含参数 a 的特征方程化为等效开环传函
本卷实例
  • 关键一步：把含参数 a 的项单独留出，其余部分作为等效开环传函
  • 中间结果：等效开环有三个极点、无零点，可套常规根轨迹法则
  • 卡点：参数 a 的系数 2 要一并提出，不能漏掉
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过把含参数 a 的特征方程化为等效开环传函
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则定实轴段、渐近线交点与夹角
本卷实例
  • 关键一步：由三个开环极点位置定实轴根轨迹段与三条渐近线
  • 中间结果：渐近线交点为极点实部均值，夹角按奇数等分
  • 卡点：实轴段按右侧零极点总数为奇数判断，易漏复极点贡献
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则定实轴段、渐近线交点与夹角
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求参数根轨迹的分离点并筛选
本卷实例
  • 关键一步：用分离点方程列出关于 d 的一元二次方程并求解
  • 中间结果：两个根中只有一个落在实轴根轨迹段上
  • 卡点：不在根轨迹段上的根要舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求参数根轨迹的分离点并筛选
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
出射角与入射角 根轨迹法
本卷考法
  • 求共轭复数极点的出射角
本卷实例
  • 关键一步：对复数极点列相角条件，代入其余零极点的相角贡献
  • 中间结果：两个共轭极点的出射角互为相反数
  • 卡点：累加相角时不能把该极点自身算进去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求共轭复数极点的出射角
  • 求复数极点的出射角
  • 根据出射角画出根轨迹起始方向
  • 由入射角确定根轨迹终止方向
常见易错
  • 累加相角时把该极点自身的相角也算进去
  • 忘记判断象限导致角度差 180°

  • 卡点：采样开关位置决定脉冲传函写法，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置

采样过程与香农采样定理 离散控制系统
本卷考法
  • 说明零阶保持器的作用与相位滞后
本卷实例
  • 关键一步：从连续信号恢复与频率特性两方面说明保持器作用
  • 中间结果：零阶保持器把每个采样值保持一个采样周期后输出
  • 卡点：保持器带来半个采样周期的延迟，答题时要提到
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过说明零阶保持器的作用与相位滞后
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后
