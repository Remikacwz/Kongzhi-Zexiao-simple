哈尔滨理工大学 810 自动控制原理 2022 年真题思维导图

强势双非共 8 题

难度：中等　全卷 8 题。第 1 题结构框图求传函，第 2 题四阶开环传函劳斯判据判稳并求等幅振荡增益与频率，第 3 题由超调量与峰值时间反求 K、τ 及上升调节时间，第 4 题含参数 a 的参数根轨迹与欠阻尼参数范围，第 5 题由对数幅频特性反求传函并求剪切频率与相角裕度，第 6 题按稳态误差与裕量要求设计超前校正，第 7 题由描述函数法分析非线性系统稳定性，第 8 题离散系统两小问比较不同采样周期下的稳定增益范围。第 1、3、4、5、7、8 题题面含原卷插图。

1一、结构框图求传递函数（图）#

思路
  • 对多回路结构框图先用梅森增益公式数独立回路与前向通路求闭环传函；回路间若存在交叉再配合比较点等效移动与逐层化简交叉验证。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简求闭环传递函数
本卷实例
  • 关键一步：先找最内层回路求等效环节，再逐层向外交互化简
  • 中间结果：内环等效后化为串联并联支路，再套单回路反馈公式
  • 卡点：回路层数与连接关系在原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简求闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式由回路与前向通路求闭环传函
本卷实例
  • 关键一步：先数清独立回路并判断是否两两接触，再求特征式
  • 中间结果：特征式为各回路增益代数和，前向通路乘余子式后相加
  • 卡点：不接触回路找漏或重复计数，余子式要剔除接触回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式由回路与前向通路求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
比较点与引出点的移动 结构图与方框图
本卷考法
  • 移动比较点消除交叉连接
本卷实例
  • 关键一步：按前移用除、后移用乘的规则移动点，保持关系不变
  • 中间结果：移动后各支路关系与原图等价，再套串并联反馈等效
  • 卡点：哪些点需要移动由原图连接决定，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过移动比较点消除交叉连接
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 用串并联与反馈等效公式化简无交叉回路
本卷实例
  • 关键一步：对已消除交叉的局部回路套用前向除一加开环等效
  • 中间结果：各等效环节相乘相加后代入整个系统的闭环表达式
  • 卡点：并联环节相减时符号取反会改变闭环结果
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过用串并联与反馈等效公式化简无交叉回路
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、劳斯判据判稳与等幅振荡参数#

思路
  • 按四阶开环传函写闭环特征方程列劳斯表，令含增益的临界行元素为零得等幅振荡增益，再用该行构造辅助方程解出纯虚根频率。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求使系统稳定的增益范围
本卷实例
  • 关键一步：把闭环特征式按降幂排列逐行列劳斯表，缺项补零
  • 中间结果：首列各元素同号才稳定，含增益的临界元素给增益上界
  • 卡点：含增益的行不能直接约去，否则丢临界条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求使系统稳定的增益范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由辅助方程求等幅振荡的频率与临界增益
本卷实例
  • 关键一步：令劳斯表临界行元素为零得增益，再由该行写辅助方程
  • 中间结果：辅助方程为一对纯虚根的方程，解出得振荡角频率
  • 卡点：临界时继续按常规列劳斯表会出现全零行，须改用辅助方程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由辅助方程求等幅振荡的频率与临界增益
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式

3三、二阶系统指标反求 K 与时间常数#

思路
  • 由闭环传函写出标准二阶式，把超调量与峰值时间要求代入指标公式反解阻尼比与自然频率，再与分母系数比对求 K 和 τ，最后算上升时间与调节时间。
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由一阶环节时间常数与增益说明响应快慢
本卷实例
  • 关键一步：先由传函识别惯性环节时间常数与增益的量级
  • 中间结果：时间常数越小响应越快，但增益影响稳态值
  • 卡点：把增益直接当成时间常数代入会使指标全错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由一阶环节时间常数与增益说明响应快慢
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由指标反求阻尼比与自然频率并与系数比对
本卷实例
  • 关键一步：把超调量与峰值时间公式联立解出阻尼比与自然频率
  • 中间结果：闭环分母一次项与常数项分别对应二倍阻尼乘频率与频率平方
  • 卡点：闭环分母要先归一化再与标准式逐项比对系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由指标反求阻尼比与自然频率并与系数比对
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求上升时间与调节时间
本卷实例
  • 关键一步：上升时间由阻尼角与阻尼振荡频率算，调节时间取题给误差带
  • 中间结果：上升时间与阻尼振荡频率成反比，调节时间与衰减系数成反比
  • 卡点：5% 与 2% 误差带的调节时间系数不同，题给 5%
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求上升时间与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

4四、参数根轨迹与欠阻尼范围（图）#

思路
  • 把含参数 a 的特征方程整理成一加 a 乘等效开环传函，按常规法则依次求极点、实轴段、渐近线、分离点与虚轴交点画参数根轨迹，再由欠阻尼要求定 a 范围。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 把含参数 a 的特征方程化为等效开环传函
本卷实例
  • 关键一步：把含参数 a 的项单独留出，其余部分作为等效开环传函
  • 中间结果：等效开环含三个开环极点、无零点，可套常规根轨迹法则
  • 卡点：参数 a 的系数要一并提出，漏掉会使等效开环差一个常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过把含参数 a 的特征方程化为等效开环传函
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则定实轴段、渐近线交点与夹角
本卷实例
  • 关键一步：由开环极点位置定实轴根轨迹段与渐近线条数
  • 中间结果：渐近线交点为极点实部均值，夹角按奇数等分 180 度
  • 卡点：实轴段按右侧零极点总数为奇数判断，易漏复极点贡献
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则定实轴段、渐近线交点与夹角
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求参数根轨迹的分离点并筛选合法解
本卷实例
  • 关键一步：用分离点方程列出关于 d 的方程并求解全部根
  • 中间结果：解得两个实根，其中只有一个落在实轴根轨迹段上
  • 卡点：不在根轨迹段上的根要舍去，取舍后还要再验增益为正
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
