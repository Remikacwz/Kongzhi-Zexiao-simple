1一、由RC电路求微分方程与传递函数（图）20 分#

思路
  • 对 RC 网络用回路电流或节点法列微分方程，消去中间变量得输入输出关系，再在零初始条件下取拉氏变换求传递函数。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由含电阻电容的网络求传递函数
本卷实例
  • 关键一步：选定回路电流作中间变量，按 KCL 与 KVL 列方程
  • 中间结果：消去中间变量后化为含输入输出各阶导数的微分方程
  • 卡点：元件连接与回路走向在原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由含电阻电容的网络求传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • RC 网络建模并列写微分方程
本卷实例
  • 关键一步：电容电压与电流关系按所设方向取微分形式
  • 中间结果：整理成输入输出各阶导数分别归并的形式
  • 卡点：并联支路分流关系判错会写错方程，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过RC 网络建模并列写微分方程
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

传递函数的定义与基本性质 传递函数
本卷考法
  • 由微分方程在零初始条件下写传递函数
本卷实例
  • 关键一步：对方程两边取拉氏变换并设全部初始条件为零
  • 中间结果：整理成输出比输入的 s 有理分式
  • 卡点：初始条件非零时直接相除会得到错误传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由微分方程在零初始条件下写传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

2二、由指标反求二阶参数并算稳态误差（图）10 分#

思路
  • 把单位负反馈闭环传函化为标准二阶式，由超调量定阻尼比、由峰值时间定自然频率，再与分母系数比对反解 K 与时间常数，最后由速度误差系数求斜坡输入的稳态误差。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为标准二阶形式求阻尼与自然频率
本卷实例
  • 关键一步：分母首项归一化后与标准二阶式逐项对照系数
  • 中间结果：一次项系数对应二倍阻尼乘自然频率
  • 卡点：首项系数未归一化会使系数比对出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为标准二阶形式求阻尼与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间求二阶动态指标
本卷实例
  • 关键一步：超调量式只含阻尼比，可先由它单独解出阻尼比
  • 中间结果：再代峰值时间公式解自然频率并回代系数
  • 卡点：峰值时间与上升时间公式用错会得到错误频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与峰值时间求二阶动态指标
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由两指标列方程反求系统参数
本卷实例
  • 关键一步：两个指标给两个方程，联立反解增益与时间常数
  • 中间结果：阻尼比与自然频率确定后回代闭环分母系数
  • 卡点：题给指标在源文有 OCR 残缺，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由两指标列方程反求系统参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡输入下的稳态误差
本卷实例
  • 关键一步：先写速度误差系数，再取输入幅值除以该系数
  • 中间结果：误差与输入幅值成正比、与开环增益成反比
  • 卡点：未判稳就套终值定理会得到错误的有限值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、方框图化简求传递函数（图）20 分#

思路
  • 多回路结构图先做比较点等效移动消除交叉，再按串联、并联与反馈公式逐层化简求闭环传函；也可用梅森增益公式一次列全独立回路与前向通路。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简求闭环传函
本卷实例
  • 关键一步：从最内层回路求等效环节，再逐层向外并接
  • 中间结果：内环等效后化为串并联支路再套单回路反馈式
  • 卡点：回路层数与连接关系在原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
比较点与引出点的移动 结构图与方框图
本卷考法
  • 移动比较点消除交叉连接
本卷实例
  • 关键一步：按前移用除、后移用乘移动点并保持关系不变
  • 中间结果：移动后各支路关系与原图等价再套等效化简
  • 卡点：哪些点需移动由原图连接决定，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过移动比较点消除交叉连接
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 用串并联与反馈等效公式化简局部回路
本卷实例
  • 关键一步：对已消除交叉的局部回路套前向除一加开环
  • 中间结果：各等效环节相乘相加后代入整体闭环表达式
  • 卡点：反馈极性判错会把分母写成一减开环
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过用串并联与反馈等效公式化简局部回路
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式由回路与前向通路求传函
本卷实例
  • 关键一步：先数清独立回路并判断两两是否接触再列特征式
  • 中间结果：特征式为回路增益代数和，通路乘余子式相加
  • 卡点：不接触回路易找漏，两条通路的余子式不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式由回路与前向通路求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

4四、绘制根轨迹并求稳定K范围（图）20 分#

思路
  • 把开环传函化为尾一型定开环极点，按右侧零极点个数定实轴段，求渐近线交点与夹角、解分离点方程并筛去不在轨迹上的根，再令 s 等于 jω 求虚轴交点与临界增益。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则定起点终点、实轴段与渐近线
本卷实例
  • 关键一步：先定各支起点再按右侧零极点个数定实轴段
  • 中间结果：渐近线交点为诸极点和的平均，夹角由分支数推得
  • 卡点：复数极点不参与实轴段判断，易多算一段
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则定起点终点、实轴段与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹

  • 分析提高开环增益对误差与裕度的双重影响
本卷实例
  • 关键一步：提高增益改善精度但同时压低相角裕度
  • 中间结果：精度与裕度的矛盾正是引入超前校正的动因
  • 卡点：只谈误差减小而不复核稳定性会顾此失彼
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过分析提高开环增益对误差与裕度的双重影响
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

脉冲传递函数 离散控制系统
本卷考法
  • 由连续环节与保持器求开环脉冲传函
本卷实例
  • 关键一步：先对连续部分部分分式展开再逐项查 z 变换表
  • 中间结果：脉冲传函分母含 z 减一与 z 减衰减因子两项
  • 卡点：两个连续环节间有采样开关时不能直接相乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过由连续环节与保持器求开环脉冲传函
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)

离散系统稳定性分析 离散控制系统
本卷考法
  • 求离散系统临界稳定时的增益
本卷实例
  • 关键一步：令特征多项式的朱利判据边界条件取等号
  • 中间结果：临界增益由某条边界条件恰好为零解出
  • 卡点：稳定条件是模小于一而不是实部小于零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过求离散系统临界稳定时的增益
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒
