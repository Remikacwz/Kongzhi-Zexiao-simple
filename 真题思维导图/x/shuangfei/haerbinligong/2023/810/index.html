1一、结构图化简求闭环与扰动传函（图）#

思路
  • 由结构图先做比较点等效移动消除交叉，再按串联、并联与反馈等效逐层化简，分别令参考输入与扰动单独作用于求闭环传函；也可用梅森增益公式分别对两个输入列前向通路。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简求闭环传递函数
本卷实例
  • 关键一步：从最内层回路入手求等效环节，再逐层向外化简
  • 中间结果：内环等效后化为串并联支路，再套单回路反馈公式
  • 卡点：回路层数与连接关系在原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简求闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求扰动作用下的传递函数
本卷实例
  • 关键一步：求扰动传函时令参考输入为零，再从前向通路求
  • 中间结果：扰动传函由扰动到输出的前向通路除以同一特征式
  • 卡点：两个输入同时存在时不能直接叠加，须先验证线性性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求扰动作用下的传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
比较点与引出点的移动 结构图与方框图
本卷考法
  • 移动比较点消除交叉连接
本卷实例
  • 关键一步：按前移用除、后移用乘的规则移动点，保持关系不变
  • 中间结果：移动后各支路关系与原图等价，再套串并联反馈等效
  • 卡点：哪些点需要移动由原图连接决定，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过移动比较点消除交叉连接
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式由回路与前向通路求传函
本卷实例
  • 关键一步：先数清独立回路并判断是否两两接触，再求特征式
  • 中间结果：特征式为各回路增益代数和，两个输入各有自己的前向通路
  • 卡点：扰动通路与参考通路的余子式不同，不能共用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式由回路与前向通路求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、由等幅振荡频率反求增益与参数#

思路
  • 等幅振荡说明闭环特征方程有纯虚根，把 s 等于 jω 代入特征式，令实部虚部分别为零，联立解出增益与未知参数。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断等幅振荡条件
本卷实例
  • 关键一步：对含参数特征式列劳斯表，令临界行元素为零
  • 中间结果：临界行元素为零给出增益与参数的联立方程
  • 卡点：首列为零时要改用辅助方程，不能按常规继续
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断等幅振荡条件
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由纯虚根条件求参数并与振荡频率联立
本卷实例
  • 关键一步：把 s 等于 jω 代入特征式，实部虚部分别为零
  • 中间结果：虚部方程给出增益与参数关系，实部方程给出另一关系
  • 卡点：已知振荡频率时要代回方程定参数，勿另设未知
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由纯虚根条件求参数并与振荡频率联立
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

3三、二阶系统指标反求参数与影响分析（图）#

思路
  • 由结构图求闭环传函并化为标准二阶式，把超调量与峰值时间要求代入指标公式反解阻尼比与自然频率，与分母系数比对求两参数；再按参数变化分析超调量走向。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为标准二阶形式求阻尼与自然频率
本卷实例
  • 关键一步：由结构图求闭环分母，按标准二阶式逐项比对系数
  • 中间结果：一次项系数对应二倍阻尼乘频率，常数项对应频率平方
  • 卡点：第(1)问要同时反解增益与反馈系数两个未知，需两个方程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为标准二阶形式求阻尼与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间求动态性能指标
本卷实例
  • 关键一步：超调量公式只含阻尼比，峰值时间公式含频率，联立求解
  • 中间结果：由超调量先定阻尼比，再代峰值时间定自然频率
  • 卡点：超调量公式中函数指数上的阻尼比与根号项易抄错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与峰值时间求动态性能指标
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由指标要求反求参数并分析参数变化影响
本卷实例
  • 关键一步：增益不变时自然频率不变，反馈系数只影响阻尼比
  • 中间结果：反馈系数增大使阻尼比增大，超调量随之减小
  • 卡点：结论要说明是反比关系且分增大减小两种情形
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由指标要求反求参数并分析参数变化影响
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求给定输入下的稳态误差
本卷实例
  • 关键一步：写出误差传函后先用终值定理，前提是闭环稳定
  • 中间结果：输入含阶跃与斜坡两项，误差为两分量之和
  • 卡点：组合输入时易漏掉某一分量，且未判稳就套终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求给定输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

4四、根轨迹绘制与衰减振荡范围（图）#

思路
  • 由开环传函的极点确定分支数、实轴段与渐近线，求分离点并用根之和关系求虚轴交点，画出根轨迹后由实轴分离点与虚轴交点对应增益围成衰减振荡范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则定起点终点、实轴段、渐近线与分离点
本卷实例
  • 关键一步：先定三支根轨迹起点与终点，再依次定实轴段与渐近线
  • 中间结果：渐近线交点为极点实部均值，分离点由求导条件解出
  • 卡点：实轴段按右侧零极点总数为奇数判断，易漏重极点贡献
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则定起点终点、实轴段、渐近线与分离点
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求分离点坐标并定对应增益
本卷实例
  • 关键一步：由分离点方程解出坐标，再代幅值条件求对应增益
  • 中间结果：分离点处增益给出衰减振荡增益范围的下界
  • 卡点：求出方程根后要筛选，只保留落在根轨迹段上的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值

  • 极限环的稳定性可由相轨迹收敛或发散判断
  • 减小非线性影响可用加大线性部分增益或引入校正
  • 用描述函数或相平面结果指导参数选择
步骤
  • 判断系统是否存在极限环并确定其稳定性
  • 分析非线性环节参数对自振幅值频率的影响
  • 通过调整线性部分增益或加入校正削弱自振
  • 重新分析确认自振消除或幅值达标
通用考法
  • 本卷考过分析自振稳定性并求不产生自持振荡的条件
  • 提出消除自振的工程措施
  • 分析增益变化对极限环幅值的影响
  • 比较不同方案对稳定性与动态性能的利弊
常见易错
  • 仅调整增益而不检查是否引入新的自振点
  • 把不稳定极限环误判为可观测的自振

8八、离散系统朱莉判据求稳定增益范围（图）#

思路
  • 由含零阶保持器的结构图求开环脉冲传函，代采样周期写闭环特征方程，用朱莉判据列稳定不等式组求增益范围。
脉冲传递函数 离散控制系统
本卷考法
  • 求含零阶保持器的开环与闭环脉冲传函
本卷实例
  • 关键一步：把保持器与连续部分合并做 z 变换，再写闭环特征方程
  • 中间结果：开环脉冲传函为 z 的有理分式，分子分母均含采样周期
  • 卡点：采样开关位置决定脉冲传函写法，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过求含零阶保持器的开环与闭环脉冲传函
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)

z 变换与 z 反变换 离散控制系统
本卷考法
  • 用部分分式与常用 z 变换对求脉冲传函
本卷实例
  • 关键一步：把连续部分展开为部分分式再逐项查表做 z 变换
  • 中间结果：各部分分式分别对应幂函数、阶跃与指数项的 z 变换
  • 卡点：指数项中的采样周期不能漏掉，部分分式分解不可漏项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • z 变换是离散信号的拉氏变换，令 z=e^{Ts} 得到
  • 常用函数的 z 变换要熟记
  • z 反变换可用部分分式法、幂级数法或留数法
  • 左半 s 平面映射到 z 平面单位圆内
步骤
  • 将连续传递函数展开为部分分式
  • 逐项查表做 z 变换
  • 需要时做 z 反变换求时间序列
通用考法
  • 本卷考过用部分分式与常用 z 变换对求脉冲传函
  • 求给定函数的 z 变换
  • 求 z 反变换得到采样序列
  • 说明 s 平面与 z 平面的映射关系
常见易错
  • 把 z 变换结果中的 e^{-aT} 写成 e^{-a}
  • 部分分式分解时漏项导致反变换出错

离散系统稳定性分析 离散控制系统
本卷考法
  • 用朱莉判据求使系统稳定的增益范围
本卷实例

  • 中间结果：稳定条件为三式交集，给出增益的上下界
  • 卡点：离散稳定条件是闭环极点模小于一，不是实部小于零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过用朱莉判据求使系统稳定的增益范围
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒
