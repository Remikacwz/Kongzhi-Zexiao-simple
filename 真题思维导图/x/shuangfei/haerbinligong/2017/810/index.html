哈尔滨理工大学 810 自动控制原理 2017 年真题思维导图

强势双非共 7 题

难度：中等　全卷 7 题，均为简答与分析计算，卷面未印逐题分值。第 1 题简答开环与闭环系统的特点，第 2 题由单位阶跃响应曲线反求开环传函，第 3 题由方框图绘根轨迹，第 4 题求输入与扰动共同作用下的稳态误差，第 5 题由 Bode 图反求开环传函，第 6 题设计串联超前校正，第 7 题分析离散系统稳定性。第 2、3、4、5、7 题题面含原卷插图。

1一、开环系统与闭环系统的特点#

思路
  • 按被控量是否反馈回来参与控制区分开环与闭环，再从结构繁简、抗干扰能力、精度要求与稳定性风险四方面对比作答。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 对比开环系统与闭环系统的结构特点
本卷实例
  • 关键一步：抓住被控量是否反馈回来参与控制这条主线
  • 中间结果：开环靠输入直接驱动，闭环按偏差进行调节
  • 卡点：只答结构不答抗扰与精度会丢分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过对比开环系统与闭环系统的结构特点
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
劳斯判据 稳定性分析
本卷考法
  • 说明闭环系统为何存在稳定性问题
本卷实例
  • 关键一步：闭环把偏差反馈回来，增益过大时可能自激
  • 中间结果：闭环精度高但须先判稳，开环不存在该风险
  • 卡点：把闭环稳定性风险说成开环的固有缺陷
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过说明闭环系统为何存在稳定性问题
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

2二、由阶跃响应曲线反求开环传函（图）#

思路
  • 由单位阶跃响应曲线读出超调量、峰值时间与稳态值，先由超调量定阻尼比、由峰值时间定自然频率，再由稳态值定增益，最后把闭环传函还原成开环传函。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由响应曲线读特征量反求传递函数
本卷实例
  • 关键一步：从曲线读超调量、峰值时间与稳态值三个特征量
  • 中间结果：由三个特征量分别定阻尼比、自然频率与增益
  • 卡点：曲线读数依赖原图刻度，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由响应曲线读特征量反求传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由标准二阶形式反求阻尼比与自然频率
本卷实例
  • 关键一步：闭环传函化为标准二阶式后逐项比对系数
  • 中间结果：分母一次项与常数项给出阻尼比和自然频率
  • 卡点：峰值时间公式中的自然频率并非开环增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由标准二阶形式反求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间求二阶系统指标
本卷实例
  • 关键一步：超调量只与阻尼比有关，可单独解出阻尼比
  • 中间结果：稳态值等于闭环直流增益与输入幅值之积
  • 卡点：把超调量百分比漏乘一百或把稳态值读错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与峰值时间求二阶系统指标
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3三、由方框图绘根轨迹（图）#

思路
  • 先对含局部反馈的方框图化简得到开环传函，再定分支数、实轴段、渐近线与出射角，据此描出两条共轭分支的走向。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 化简局部反馈支路求开环传函
本卷实例
  • 关键一步：先化简局部负反馈支路再与前向通道相乘
  • 中间结果：开环传函化为含一对共轭极点与增益之积
  • 卡点：局部反馈分母的正负号错误会使极点位置偏移
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过化简局部反馈支路求开环传函
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 定根轨迹分支数、实轴段与渐近线
本卷实例
  • 关键一步：先定两条分支起于共轭极点、终于无穷远
  • 中间结果：无有限零点时渐近线夹角为正负九十度
  • 卡点：极点全为复数时实轴上没有根轨迹段
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过定根轨迹分支数、实轴段与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
出射角与入射角 根轨迹法
本卷考法
  • 求共轭复数极点的出射角
本卷实例
  • 关键一步：用相角条件对复极点列各向量夹角之和求出射角
  • 中间结果：一对共轭极点的出射角关于实轴反向对称
  • 卡点：累加时把该极点自身相角计入会差一百八十度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求共轭复数极点的出射角
  • 求复数极点的出射角
  • 根据出射角画出根轨迹起始方向
  • 由入射角确定根轨迹终止方向
常见易错
  • 累加相角时把该极点自身的相角也算进去
  • 忘记判断象限导致角度差 180°
公式

4四、输入与扰动共同作用下的稳态误差（图）#

思路
  • 分别令扰动为零求输入作用下的误差传函、令输入为零求扰动作用下的误差传函，各自用终值定理算出稳态误差，最后按线性叠加求总误差。
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动单独作用下的稳态误差
本卷实例
  • 关键一步：求扰动误差时把参考输入置零，单列扰动到误差的通路
  • 中间结果：扰动误差传函由扰动前向通路除以同一特征式
  • 卡点：把扰动误差直接当总误差会漏掉输入分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求扰动单独作用下的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡输入作用下的稳态误差
本卷实例
  • 关键一步：输入为斜坡信号时用静态速度误差系数求误差
  • 中间结果：斜坡输入误差与开环增益成反比，为有限值
  • 卡点：输入为斜坡却误套阶跃的位置误差公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求斜坡输入作用下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 统一误差传函以支持两分量叠加
本卷实例
  • 关键一步：误差传函统一取自给定端到误差端以便叠加
  • 中间结果：两分量基于同一特征式，线性系统可直接相加
  • 卡点：扰动点位置决定其误差传函分子，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过统一误差传函以支持两分量叠加
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

5五、由 Bode 图反求开环传函（图）#

思路
  • 由低频段渐近线斜率与高度确定积分或微分环节及增益，再按各转折频率处的斜率变化定出对应惯性环节，串联写出开环传递函数。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频曲线反求开环传递函数
本卷实例
  • 关键一步：先读低频段斜率定型别，再由过零频点关系定增益
  • 中间结果：各转折频率处斜率下降对应一个惯性环节
  • 卡点：低频段斜率与型别的正负对应关系易搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
