哈尔滨理工大学 810 自动控制原理 2015 年真题思维导图

强势双非共 9 题

难度：中等　全卷 9 题。第 1 题结构图化简求闭环传函，第 2 题由超调量与峰值时间反求二阶系统参数并算调节时间，第 3 题由闭环特征方程求两参数稳定域，第 4 题求阶跃与正弦输入下的稳态误差，第 5 题绘制三阶系统根轨迹，第 6 题由对数渐近幅频特性反求传函，第 7 题求给定增益下的幅值裕度与相角裕度，第 8 题设计串联超前校正，第 9 题用朱利判据分析离散系统稳定性。第 1、3、6、9 题题面含原卷插图。

1一、结构图化简求闭环传递函数（图）#

思路
  • 多回路结构图先做比较点等效移动消除交叉，再按串联、并联与反馈公式逐层化简求闭环传函；也可用梅森增益公式一次列全独立回路与前向通路，两种做法结果应一致。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简求闭环传递函数
本卷实例
  • 关键一步：从最内层回路求等效环节，再逐层向外并接
  • 中间结果：内环等效后化为串并联支路，再套单回路反馈式
  • 卡点：回路层数与连接关系在原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简求闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
比较点与引出点的移动 结构图与方框图
本卷考法
  • 移动比较点消除交叉连接
本卷实例
  • 关键一步：按前移用除、后移用乘移动点，保持关系不变
  • 中间结果：移动后各支路关系与原图等价，再套等效化简
  • 卡点：哪些点需移动由原图连接决定，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过移动比较点消除交叉连接
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 用串并联与反馈等效公式化简局部回路
本卷实例
  • 关键一步：对已消除交叉的局部回路套前向除一加开环
  • 中间结果：各等效环节相乘相加后代入整体闭环表达式
  • 卡点：反馈极性判错会把分母写成一减开环，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过用串并联与反馈等效公式化简局部回路
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式由回路与前向通路求传函
本卷实例
  • 关键一步：先数清独立回路并判断两两是否接触再列特征式
  • 中间结果：特征式为回路增益代数和，前向通路乘余子式相加
  • 卡点：不接触回路易找漏，两条前向通路的余子式不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式由回路与前向通路求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、由超调量与峰值时间反求二阶参数#

思路
  • 把单位负反馈开环传函化为标准二阶闭环式，由超调量定阻尼比、由峰值时间定自然频率，再与分母系数比对反解时间常数与增益，最后按给定误差带求调节时间。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为标准二阶形式求阻尼与自然频率
本卷实例
  • 关键一步：闭环分母归一化后与标准式逐项对照系数
  • 中间结果：一次项系数对应二倍阻尼乘频率，常数项对应频率平方
  • 卡点：首项系数未归一化会使系数比对出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为标准二阶形式求阻尼与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼与自然频率求峰值时间与调节时间
本卷实例
  • 关键一步：超调量式只含阻尼比，可先由它单独解出阻尼比
  • 中间结果：再代峰值时间公式解自然频率，最后算调节时间
  • 卡点：百分之二与百分之五误差带的调节时间系数不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼与自然频率求峰值时间与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由给定动态指标反求系统参数
本卷实例
  • 关键一步：两个指标给两个方程，联立反解增益与时间常数
  • 中间结果：阻尼比与自然频率确定后即可回代分母系数
  • 卡点：题给指标 OCR 数值与答案段不符，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由给定动态指标反求系统参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

3三、由特征方程求参数稳定域（图）#

思路
  • 由结构图写开环传函与闭环特征方程，把含两参数的三阶特征式列劳斯表，令首列各元素大于零得到两参数不等式，取交集即得稳定域。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断含参数系统的稳定性
本卷实例
  • 关键一步：三阶特征式按降幂列劳斯表，缺项按零处理
  • 中间结果：首列各元素均大于零给出参数的联立不等式
  • 卡点：首列元素只列部分会漏掉一个稳定约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断含参数系统的稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求使系统稳定的双参数取值范围
本卷实例
  • 关键一步：对两参数分别写约束再取交集确定稳定域
  • 中间结果：稳定域由两条直线边界围成的角形区域
  • 卡点：边界端点是否包含要按严格不等号判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求使系统稳定的双参数取值范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图写开环传函再列闭环特征式
本卷实例
  • 关键一步：先合并局部反馈再乘前向通道得开环传函
  • 中间结果：特征方程由一加开环传函得到，系数含两参数
  • 卡点：结构连接与开环式在原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由结构图写开环传函再列闭环特征式
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

4四、阶跃与正弦输入下的稳态误差#

思路
  • 第(1)问由开环传函写误差传函，用终值定理对阶跃输入求稳态误差；第(2)问把误差传函换成频率特性，由正弦输入的幅值比与相位差写稳态误差表达式。
误差定义与误差传递函数 稳态误差
本卷考法
  • 写误差传递函数再求给定输入下的误差
本卷实例
  • 关键一步：单位负反馈下误差传函等于一除以一加开环
  • 中间结果：误差传函化简为一阶有理式，阶跃时用终值定理
  • 卡点：未判稳就套终值定理会得到错误的有限值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写误差传递函数再求给定输入下的误差
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求典型输入信号下的稳态误差
本卷实例
  • 关键一步：阶跃输入先算静态位置误差系数再取倒数
  • 中间结果：阶跃输入稳态误差与输入幅值成正比
  • 卡点：输入带系数时漏乘幅值会使结果差一个倍数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求典型输入信号下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 用频率特性求正弦输入下的稳态误差
本卷实例
  • 关键一步：把误差传函的 s 换成 jω 求幅频与相频

减小稳态误差的措施 稳态误差
本卷考法
  • 分析提高开环增益对误差与裕度的双重影响
本卷实例
  • 关键一步：提高增益改善精度但同时压低相角裕度
  • 中间结果：精度与裕度的矛盾正是引入超前校正的动因
  • 卡点：只谈误差减小而不复核稳定性会顾此失彼
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过分析提高开环增益对误差与裕度的双重影响
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

  • 必要时分析采样周期对稳定域的影响

  • 判断离散系统是否稳定

  • 用 w 变换后套用劳斯判据
