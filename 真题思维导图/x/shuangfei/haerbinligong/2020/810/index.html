1一、方框图化简求闭环传递函数（图）20 分#

思路
  • 先做比较点与引出点的等效移动消除交叉，再按梅森增益公式一次列全独立回路与前向通路，写出闭环传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式由信号流图求闭环传函
本卷实例
  • 关键一步：先数清全部独立回路并写出回路增益之和
  • 中间结果：特征式另含两两不接触回路增益之积
  • 卡点：第(2)问图与本卷不一致时须按原图重数回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式由信号流图求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简求闭环传函
本卷实例
  • 关键一步：先合并内层局部回路再逐层向外等效
  • 中间结果：逐层等效后化为单回路再套反馈公式
  • 卡点：回路层数与连接关系在原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
比较点与引出点的移动 结构图与方框图
本卷考法
  • 移动比较点或引出点消除交叉连接
本卷实例
  • 关键一步：比较点跨越方框移动时在相应支路补偿
  • 中间结果：移动前后系统输入输出关系保持不变
  • 卡点：移动方向与乘除关系取反会导致多出支路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过移动比较点或引出点消除交叉连接
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用

2二、二阶系统动态指标与参数（图）20 分#

思路
  • 由给定的超调量与调节时间两个指标，先用超调量公式单独解出阻尼比，再由调节时间公式解出自然频率，最后回代标准二阶闭环传函核对参数。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函标准式确定阻尼比与自然频率
本卷实例
  • 关键一步：先判断为欠阻尼再套标准二阶形式对照系数
  • 中间结果：闭环分母一次项含阻尼比与自然频率之积
  • 卡点：反馈通道有参数时对照系数易漏项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函标准式确定阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与调节时间解出二阶动态参数
本卷实例
  • 关键一步：超调量式只含阻尼比故可先解出它
  • 中间结果：再按所给误差带取调节时间系数解自然频率
  • 卡点：所给调节时间对应的误差带须回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与调节时间解出二阶动态参数
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由动态指标反求系统参数并核对可实现性
本卷实例
  • 关键一步：两指标给两方程联立解出阻尼比与自然频率
  • 中间结果：把解出的参数回代闭环分母核对量级是否合理
  • 卡点：第(2)问文字 OCR 残缺，所求须回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由动态指标反求系统参数并核对可实现性
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

3三、劳斯判据判稳10 分#

思路
  • 把四阶特征方程按降幂列劳斯表，逐行计算首列各元素并检查是否变号，出现符号变化即判不稳定并指出右半平面根数。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判别高阶系统稳定性
本卷实例
  • 关键一步：按降幂补全系数后逐行列劳斯表
  • 中间结果：首列元素出现变号即说明存在右半平面根
  • 卡点：首列某行算出负值后仍继续套用会判错结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判别高阶系统稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式

4四、根轨迹绘制与稳定K范围（图）20 分#

思路
  • 由三个开环极点定实轴段与渐近线，求分离点，再令 s 等于 jω 求虚轴交点与临界增益，稳定范围由闭环极点全在左半平面对应的那一段给出。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则定根轨迹起点、实轴段与渐近线
本卷实例
  • 关键一步：由三个开环极点定三条分支的起点
  • 中间结果：渐近线交点为极点平均值、夹角按分支数分配
  • 卡点：实轴段判据的右侧零极点个数易数错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则定根轨迹起点、实轴段与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求分离点坐标并筛去不在轨迹上的根
本卷实例
  • 关键一步：列分离点方程解出实根再按轨迹段取舍
  • 中间结果：三极点系统的分离点方程为一元二次式
  • 卡点：解得的根不在轨迹段上时必须舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求分离点坐标并筛去不在轨迹上的根
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界增益
本卷实例
  • 关键一步：令 s 等于 jω 代入特征方程分离实虚部
  • 中间结果：实部为零给出交点频率，虚部为零给出临界增益
  • 卡点：只代一个频率会漏掉另一组纯虚根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹确定系统稳定的增益范围
本卷实例
  • 关键一步：取使闭环极点全位于左半平面的增益区间
  • 中间结果：稳定区间由零到临界增益之间构成
  • 卡点：端点是否包含要按开环极点数与虚轴关系判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹确定系统稳定的增益范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

5五、由幅频曲线反求传函并分析增益影响（图）20 分#

思路
  • 由低频段斜率与起始高度定型别和增益、由各转折频率定环节，写出开环传函；再分析增大增益对稳定裕度与稳态精度造成的相反影响。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频曲线反求开环传递函数
本卷实例
  • 关键一步：低频段高度与斜率共同定型别与增益
  • 中间结果：按转折频率逐段还原惯性或一阶微分环节
  • 卡点：曲线刻度读数与原图相关，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数

  • 采样周期增大会使稳定性变差
