哈尔滨理工大学 810 自动控制原理 2016 年真题思维导图

强势双非共 8 题合计 150 分

难度：中等　全卷 8 大题，含选择、填空两小节与 6 道计算题。第 1 题十道单项选择，第 2 题十道填空，第 3 题方框图化简求闭环传函，第 4 题由超调量与峰值时间反求二阶参数，第 5 题绘制含开环零点的根轨迹，第 6 题画对数渐近幅频特性并求相角与幅值裕度，第 7 题设计串联迟后校正，第 8 题离散系统求稳定增益范围。第 3、4、6、8 题题面含原卷插图。

1一、单项选择题（10小题）10 分#

思路
  • 十道单选覆盖自控基本概念、传递函数性质、环节连接等效、一阶响应、型别与加速度误差、奈氏包围判据、根轨迹分支数与串联校正装置类型，逐小题按定义与公式比对选项。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断自动控制系统的基本组成与性能要求
本卷实例
  • 关键一步：从被控量、操纵量与控制装置三要素辨认系统
  • 中间结果：性能要求归结为稳定、快速、准确三条
  • 卡点：把被控量与操纵量对号入座时最易互换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断自动控制系统的基本组成与性能要求
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
传递函数的定义与基本性质 传递函数
本卷考法
  • 判断传递函数取决于结构与参数
本卷实例
  • 关键一步：传递函数只由系统结构与参数决定，与输入形式无关
  • 中间结果：极点由分母决定，零点由分子决定
  • 卡点：把输入信号形式误当成影响传递函数的因素
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过判断传递函数取决于结构与参数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由连接方式判断等效传递函数
本卷实例
  • 关键一步：并联环节的等效式为各传递函数代数和
  • 中间结果：串联为相乘、反馈为前向除一加开环
  • 卡点：并联与串联的等效运算易张冠李戴
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由连接方式判断等效传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 辨认一阶系统单位阶跃响应形状
本卷实例
  • 关键一步：一阶系统单位阶跃响应为单调上升的指数曲线
  • 中间结果：时间常数越大上升越慢但稳态值不变
  • 卡点：把它与二阶欠阻尼的振荡曲线混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过辨认一阶系统单位阶跃响应形状
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由系统型别判断加速度输入下的误差
本卷实例
  • 关键一步：数开环积分环节个数来判断系统型别
  • 中间结果：零型系统跟踪加速度输入的误差趋于无穷
  • 卡点：型别号与静态误差系数的对应关系记反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由系统型别判断加速度输入下的误差
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由奈氏曲线包围圈数判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数，再看包围负一点的圈数
  • 中间结果：包围圈数与开环极点数的关系定右半平面闭环根数
  • 卡点：积分环节未补画无穷大圆弧会数错包围次数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由奈氏曲线包围圈数判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 由开环零极点数目判断根轨迹条数
本卷实例
  • 关键一步：根轨迹条数等于开环极点数，终止于零点或无穷远
  • 中间结果：趋于无穷远的条数为极点数减零点数
  • 卡点：把有限零点数与无穷远终点条数混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过由开环零极点数目判断根轨迹条数
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
超前校正 系统校正
本卷考法
  • 判断超前校正对应的控制器类型
本卷实例
  • 关键一步：超前校正提供正相角，近似微分加比例作用
  • 中间结果：串联超前校正装置等价于比例微分控制
  • 卡点：把滞后校正误判为比例微分作用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过判断超前校正对应的控制器类型
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式

2二、填空题（10小题）20 分#

思路
  • 十个小空考查典型环节判别、方框图的连接方式、负反馈等效式、梅森公式依据、无静差控制器、闭环主导极点、稳定的首要条件、根轨迹相角条件、稳态误差定义与频率特性含义。
典型环节及其特性 传递函数
本卷考法
  • 判别简单RC网络属于哪种典型环节
本卷实例
  • 关键一步：由电容电压与电源电压关系式对照典型环节形式
  • 中间结果：一阶RC网络的输出对输入呈惯性环节特性
  • 卡点：把惯性环节与一阶微分环节的时间常数位置写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过判别简单RC网络属于哪种典型环节
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减

  • 卡点：把负反馈等效分母误写成一减开环

  • 反馈等效的前提是单回路、无交叉
步骤

  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法

  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

梅森增益公式与信号流图 传递函数
本卷考法
  • 指出应用梅森增益公式的依据
本卷实例
  • 关键一步：梅森公式依据系统的结构参数与回路接触关系
  • 中间结果：特征式与余子式均可由结构图直接读出
  • 卡点：把依据写成输入信号形式，混淆适用条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过指出应用梅森增益公式的依据
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 选择实现无静差控制的控制器类型
本卷实例
  • 关键一步：无静差要求开环含积分环节，故选积分控制器
  • 中间结果：积分作用可消除阶跃输入下的稳态误差
  • 卡点：积分作用同时降低相角裕度，不能只看精度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过选择实现无静差控制的控制器类型
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
