1一、方框图双输入求闭环传函（原卷有图）#

思路
  • 对参考与扰动分别用梅森公式求 C/R 与 C/N，再按叠加写出 C(s) 表达式。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求参考输入与扰动输入两条通道的闭环传函
本卷实例
  • 关键一步：分别令 R 为零与 N 为零，拆成两条独立通道
  • 中间结果：两条通道共用同一个闭环特征式
  • 卡点：方框图以原卷插图给出，回路走向需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求参考输入与扰动输入两条通道的闭环传函
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 本卷考过求扰动传函时未把参考输入置零
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式写特征式与各前向通路
本卷实例
  • 关键一步：先数全部单独回路写出特征式，再逐条找前向通路
  • 中间结果：无互不接触回路时特征式为一加各回路增益之和
  • 卡点：扰动到输出的前向通路可能不止一条
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式写特征式与各前向通路
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路找漏或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 按反馈等效写各回路的闭环增益
本卷实例
  • 关键一步：每个反馈回路按分子比一加回路增益处理
  • 中间结果：并联前向支路在分子相加
  • 卡点：化简结果应与整体信号流图自洽
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过按反馈等效写各回路的闭环增益
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过负反馈分母误写成减回路增益
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征多项式求阻尼比与自然频率
本卷实例
  • 关键一步：把特征多项式与二阶标准式逐项对应
  • 中间结果：常数项开根得自然频率，一次项系数对应二倍乘积
  • 卡点：k1 变化时自然频率与阻尼比同时改变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征多项式求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过二阶项系数未归一就取常数项
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求超调量与调节时间
本卷实例
  • 关键一步：按欠阻尼公式代入阻尼比与自然频率
  • 中间结果：超调量只由阻尼比决定
  • 卡点：调节时间按百分之五误差带取三倍半除实部
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过调节时间按不同误差带取了错误系数
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

本卷考法

本卷实例

  • 求给定输入下的稳态误差

  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过未判稳就使用终值定理
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

滞后校正 系统校正
本卷考法
  • 设计串联滞后校正装置并写出传函
本卷实例
  • 关键一步：在满足相角裕度的频率处令幅值下降量为衰减量
  • 中间结果：衰减量定衰减系数，转折频率按新截止频率的十分之一与十倍取
  • 卡点：新截止频率处要留出补偿角
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过设计串联滞后校正装置并写出传函
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 本卷考过转折频率取得过高抵消增益改善
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
稳定裕度 频域分析
本卷考法
  • 校验校正后的相角裕度
本卷实例
  • 关键一步：把校正后开环传函在新截止频率处求相角
  • 中间结果：相角裕度等于一百八十度加该相角
  • 卡点：忽略截止频率变化会高估相角裕度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过校验校正后的相角裕度
  • 求系统的相角裕度与幅值裕度

8八、最小相位系统奈氏判稳（原卷有图）#

思路
  • 由开环幅相曲线数包围临界点的圈数与开环右半平面极点数，用奈氏判据判稳，再由交点增益求稳定范围。
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈氏判据判断系统闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数，再数曲线包围临界点的圈数
  • 中间结果：由包围圈数与极点数之差确定右半平面闭环极点数
  • 卡点：正负穿越要按曲线走向分别统计
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈氏判据判断系统闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过三个积分环节未补画无穷大半径圆弧
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

频率特性的物理意义与求法 频域分析
本卷考法
  • 由开环幅相曲线读取交点的幅值信息
本卷实例
  • 关键一步：由低频与高频段相角判断起点与终点走向

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由开环幅相曲线读取交点的幅值信息
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错

  • 求幅值时忘记把分母复数取模后再相除

通用考法
  • 本卷考过由最小相位条件说明幅频与相频的关系

  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
