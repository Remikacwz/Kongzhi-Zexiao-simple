天津工业大学 811 自动控制理论（含现控） 2021 年真题思维导图

一（1~4）一、选择题（4 小题）#

思路
  • 4 道小题分别考查二阶系统超调量比较、劳斯判据判稳、由单位斜坡响应求稳态误差、线性定常系统的判别。
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 比较四个二阶系统单位阶跃响应的超调量大小
本卷实例
  • 关键一步：把各选项化为二阶标准式，比较一次项系数定阻尼比
  • 中间结果：四个选项自然频率相同，超调量随阻尼比减小而增大
  • 卡点：源文 D 选项传递函数 OCR 串入噪声，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过比较四个二阶系统单位阶跃响应的超调量大小
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过把超调量与稳态增益挂钩，其实二者无关
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函的常数项与一次项系数求自然频率与阻尼比
本卷实例
  • 关键一步：将闭环传函分母逐项对应二阶标准式
  • 中间结果：常数项开根给出自然频率，一次项系数给二倍乘积
  • 卡点：自然频率相同才能只比较阻尼比
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函的常数项与一次项系数求自然频率与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过未把二阶项系数归一就直接读常数项
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断给定特征多项式对应系统的稳定性
本卷实例
  • 关键一步：先按各项系数为正筛除，再列劳斯表看首列符号
  • 中间结果：首列出现变号即闭环不稳定，有零元素用 ε 法
  • 卡点：选项 B 的最高次项 OCR 误印为 s 的五次方
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断给定特征多项式对应系统的稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过系数缺项时不补零直接列劳斯表
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡响应求系统的稳态误差
本卷实例
  • 关键一步：写出误差响应等于参考响应减去输出响应
  • 中间结果：误差响应含衰减项与常数项，稳态误差取常数项
  • 卡点：指数衰减项在时间趋于无穷时消失
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位斜坡响应求系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过把斜坡响应的稳态值本身当成稳态误差
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
传递函数的定义与基本性质 传递函数
本卷考法
  • 由微分方程判断系统是否线性定常
本卷实例
  • 关键一步：检查方程中是否含变量乘积、非线性函数或时变系数
  • 中间结果：变量与导数均一次且系数为常数才属线性定常
  • 卡点：含时间乘导数项属时变而非定常
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由微分方程判断系统是否线性定常
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过只看方程阶次就判为线性
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

二二、系统结构图求 C(s)/R(s)（原卷有图）#

思路
  • 对照结构图找出全部单独回路与前向通路，由梅森增益公式求闭环传递函数。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 化简含交叉比较点与引出点的结构图
本卷实例
  • 关键一步：按回路逐层合并或直接列回路方程联立
  • 中间结果：各回路增益的符号由反馈极性决定
  • 卡点：结构图以原卷插图给出，连接走向需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过化简含交叉比较点与引出点的结构图
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过内环化简时把外环信号当成常数
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式写特征式与各前向通路
本卷实例
  • 关键一步：先列全部单独回路得特征式，再逐条找前向通路
  • 中间结果：无互不接触回路时特征式等于一减各回路增益之和
  • 卡点：前向通路的增益与回路增益勿混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式写特征式与各前向通路
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过余子式未剔除与通路接触的回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 按反馈等效关系写出每条回路的闭环增益
本卷实例
  • 关键一步：把每个反馈回路写成分子比一加回路增益的形式
  • 中间结果：并联的前向支路增益在分子相加
  • 卡点：化简结果要能还原成单一前向通道
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过按反馈等效关系写出每条回路的闭环增益
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过负反馈的分母误写成一减回路增益
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

参数稳定域的确定 稳定性分析
本卷考法
  • 求使四阶系统稳定的参数 T 取值范围
本卷实例
  • 关键一步：把劳斯表首列各元素写成 T 的不等式组
  • 中间结果：对不等式组取交集得到稳定域

  • 检查端点是否为临界稳定
通用考法

  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 本卷考过只列出部分首列元素的不等式
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

欠阻尼动态性能指标 时域响应与动态性能
