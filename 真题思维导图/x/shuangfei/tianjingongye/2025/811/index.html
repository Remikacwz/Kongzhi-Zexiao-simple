天津工业大学 811 自动控制理论（含现控） 2025 年真题思维导图

1一、方框图双输入求误差 E(s)（图 1）#

思路
  • 对参考输入 r(t)=t² 与扰动 n(t)=1(t) 分别列梅森公式，得到参考到误差与扰动到误差两条传函，再把两个输入的拉氏变换代入并叠加成总误差 E(s)。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 同图分别求参考与扰动到误差的传函再叠加
本卷实例
  • 关键一步：令 N(s) 为零与 R(s) 为零，拆成两条独立误差通道
  • 中间结果：两条通道共用同一个闭环特征式
  • 卡点：图 1 未读，扰动注入点与回路走向需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过同图分别求参考与扰动到误差的传函再叠加
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式写参考到误差与扰动到误差的传函
本卷实例
  • 关键一步：先找全部单独回路写出特征式，再数各前向通路
  • 中间结果：以误差点作终点的通路与输出到误差的通路不同
  • 卡点：余子式要剔除与该前向通路接触的回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式写参考到误差与扰动到误差的传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 明确 E(s) 取在误差点并写误差传函
本卷实例
  • 关键一步：按误差点列方程确定 E 与参考、扰动的关系
  • 中间结果：误差等于参考通道与扰动通道两条支路之和
  • 卡点：误差定义取输入端还是反馈端，本题以原卷图为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过明确 E(s) 取在误差点并写误差传函
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
典型输入信号 基本概念与信号
本卷考法
  • 写出抛物线参考与阶跃扰动的拉氏变换
本卷实例
  • 关键一步：把 r(t)=t² 与 n(t)=1(t) 分别取拉氏变换
  • 中间结果：抛物线输入对应 2 除以 s 的三次方
  • 卡点：抛物线输入的系数 2 漏掉会使整个结果差倍
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 常用典型输入有冲激、阶跃、斜坡、抛物线（加速度）与正弦五类
  • 阶跃信号用于考查快速性与稳定性，斜坡与抛物线用于考查稳态精度
  • 正弦信号用于频域分析，冲激响应就是系统的传递函数
  • 各典型信号的拉氏变换是分析全响应的起点
步骤
  • 按题意写出输入信号的时域表达式
  • 对输入取拉氏变换得到该信号的复域形式
  • 由输入类型判断考查的是动态性能还是稳态精度
  • 把输入代入误差或响应公式计算
通用考法
  • 本卷考过写出抛物线参考与阶跃扰动的拉氏变换
  • 写出典型输入信号的拉氏变换
  • 说明某一典型输入信号用于考查哪类性能
  • 由输入类型判断稳态误差是否为有限值
常见易错
  • 把斜坡与抛物线信号的阶次写错
  • 阶跃的拉氏变换漏掉系数（幅度不为 1 时）

2二、二阶系统动态性能与参数反求（图 2）#

思路
  • 由图 2 化简得二阶闭环传函并化为标准形式，先用阻尼比与自然频率求调节时间与稳态输出；再由调节时间和单位斜坡稳态误差两条要求联立反求 k、a、ξ。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由图 2 化简出二阶闭环传递函数
本卷实例
  • 关键一步：按内环到外环的顺序逐层做反馈等效
  • 中间结果：闭环分母化为二次多项式，含参数 a 与 k
  • 卡点：图 2 未读，参数 a 所在反馈支路位置需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由图 2 化简出二阶闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为标准形式读自然频率与阻尼比
本卷实例
  • 关键一步：令分母与标准二阶分母逐项对应
  • 中间结果：常数项对应自然频率的平方，一次项对应二倍乘积
  • 卡点：s 平方项系数要先归一，否则两个参数全错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为标准形式读自然频率与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率算 5% 误差带调节时间
本卷实例
  • 关键一步：按欠阻尼调节时间公式代入衰减因子
  • 中间结果：调节时间只由阻尼比与自然频率的乘积决定
  • 卡点：5% 与 2% 误差带的系数不同，不能混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率算 5% 误差带调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位阶跃稳态输出与单位斜坡稳态误差
本卷实例
  • 关键一步：用终值定理把稳态量写成输出或误差传函的极限
  • 中间结果：一型系统的斜坡误差与速度误差系数成反比
  • 卡点：用终值定理前先确认闭环在所得参数下稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位阶跃稳态输出与单位斜坡稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由调节时间与斜坡误差联立反求参数
本卷实例
  • 关键一步：把两条性能要求化成含衰减因子与 k、a 的方程
  • 中间结果：先由误差式定 k，再回代定阻尼比与 a
  • 卡点：反求结果要回代校验 k 与 a 的稳定条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由调节时间与斜坡误差联立反求参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

3三、串联校正装置选型与参数设计（图 3）#

思路
  • 先由单位加速度输入下的稳态误差确定系统需保持二型并求出所需开环增益；再由相角裕度要求比较三个备选装置的相频特性，选定能提供超前相角的装置并解出校正参数。
系统型别与静态误差系数 稳态误差
本卷考法
  • 由加速度误差要求判断型别并求开环增益
本卷实例
  • 关键一步：用静态加速度误差系数把误差指标写成增益等式
  • 中间结果：二型系统对加速度输入才有有限误差
  • 卡点：先数积分环节个数定型别，再筛能保二型的装置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由加速度误差要求判断型别并求开环增益
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
校正的基本概念与性能指标 系统校正
本卷考法
  • 比较三个串联装置对型别与相角的影响
本卷实例
  • 关键一步：按稳态精度与相角裕度两项要求筛选装置
  • 中间结果：保积分环节可稳型别，加超前项可补相角
  • 卡点：选型要同时兼顾稳态精度与动态裕度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过比较三个串联装置对型别与相角的影响
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求
公式
PID 控制器与参数整定 系统校正
本卷考法
  • 选定比例积分型装置并求校正参数
本卷实例
  • 关键一步：把所选装置相频写成反正切形式再列裕度方程
  • 中间结果：相角裕度方程只含穿越频率与超前时间常数
  • 卡点：装置提供的超前相角有限，解出参数后要校验可实现
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过选定比例积分型装置并求校正参数
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式

思路
  • 先求开环幅相曲线的起点、终点与负实轴交点，再按奈氏判据由交点相对临界点的位置确定闭环稳定的开环增益范围。
最小相位系统与非最小相位系统 频域分析
本卷考法
  • 识别右半平面零点与负增益对相角的影响
本卷实例
  • 关键一步：分别累加负号、零点与二重极点的相角
  • 中间结果：相频化简为相角随频率单调变负的表达式
  • 卡点：右半平面零点使相角从 180 度起算，不能漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位

通用考法

奈奎斯特判据 稳定性分析
本卷考法
  • 由幅相曲线求闭环稳定的开环增益范围
本卷实例
  • 关键一步：先数开环右半平面极点数再数包围圈数
  • 中间结果：实轴交点落在临界点左侧与否决定包围
  • 卡点：包围圈数的正负号要与曲线走向对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由幅相曲线求闭环稳定的开环增益范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
