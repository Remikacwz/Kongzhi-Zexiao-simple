1一、结构图化简求 C(s)/R(s) 与 C(s)/N(s)（原卷有图）#

思路
  • 由系统结构图化简求参考输入通道与扰动输入通道的闭环传递函数 C(s)/R(s) 与 C(s)/N(s)。题面以图给出。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 对多回路结构图逐层等效化简求闭环传函
本卷实例
  • 关键一步：从最内环开始用反馈等效公式逐层化简
  • 中间结果：逐层合并后分别得到两路闭环传递函数
  • 卡点：反馈极性决定分母，接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过对多回路结构图逐层等效化简求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过化简内环时把外环信号当成常数
  • 化简内环时把外环的信号当成常数处理
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求参考输入与扰动输入作用下的闭环传函
本卷实例
  • 关键一步：分别令 N(s)=0 与 R(s)=0 求两路传递函数
  • 中间结果：两路传函分母相同，分子由各自通道的前向通路决定
  • 卡点：扰动作用点位置以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤

  • 令 N(s)=0，求输入到输出的传递函数

通用考法

  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

2二、稳态误差与相对稳定度反求开环增益#

思路
  • 单位负反馈开环传函 G(s)=K/[s(s+3)(s+6)]，K>0。(1)输入 r(t)=3+t/3、稳态误差小于0.3时求开环增益 K*；(2)要求闭环根实部都位于 s=−2 之左，求 K*。
系统型别与静态误差系数 稳态误差
本卷考法
  • 判断系统型别并求静态速度误差系数
本卷实例
  • 关键一步：按开环 s 的幂次定型别，令 s 趋于 0 求速度误差系数
  • 中间结果：I 型系统的速度误差系数由开环增益与相关时间常数决定
  • 卡点：输入含阶跃与斜坡两项，别只盯一项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断系统型别并求静态速度误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 本卷考过把开环增益与静态误差系数混为一谈
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法

本卷实例
  • 关键一步：把阶跃与斜坡误差分量分别代入对应误差系数
  • 中间结果：I 型系统对阶跃误差为零，斜坡项决定总误差
  • 卡点：输入幅度 3 与 1/3 容易代错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤

  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法

  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过组合输入漏分量或未先判稳
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量

思路

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函求无阻尼自然频率 ωn 与阻尼比 ξ
本卷实例
  • 关键一步：列闭环特征方程并与标准二阶形式对照
  • 中间结果：ωn 与 ξ 各由一个系数关系式确定
  • 卡点：系统结构以图给出，参数位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函求无阻尼自然频率 ωn 与阻尼比 ξ
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过化为标准形式时忘记把 s² 项系数归一化
  • 化为标准形式时忘记把 s² 项系数归一化

4四、根轨迹绘制#

思路
  • 已知单位负反馈闭环传递函数 G(s)=K*/[s(s²+6s+10)+K*]，据此写开环传函并绘制根轨迹。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 由闭环传函反推开环传函并按法则绘根轨迹
本卷实例
  • 关键一步：由闭环传函分母中含 K* 的项反推开环传函
  • 中间结果：开环有三个极点、无开环零点
  • 卡点：实轴段与渐近线按开环极零点分布确定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过由闭环传函反推开环传函并按法则绘根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过把闭环特征式直接当成开环分母
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
