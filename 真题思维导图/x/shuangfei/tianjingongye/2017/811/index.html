1一、结构图化简求 C(s)/R(s)（原卷有图）#

思路
  • 由系统结构图用结构图化简或梅森增益公式求闭环传递函数 C(s)/R(s)，并画出化简过程。题面以图给出。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 对多回路结构图从内环向外逐层等效化简
本卷实例
  • 关键一步：按反馈等效公式先化最内环、再逐层向外合并
  • 中间结果：每化简一层回路数递减，直到留下单个闭环
  • 卡点：反馈极性决定分母取 1±GH，接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过对多回路结构图从内环向外逐层等效化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过内环化简时误把外环信号当成常数处理
  • 化简内环时把外环的信号当成常数处理

本卷考法

本卷实例

  • 中间结果：特征式与各前向通路的余子式相乘再求和
  • 卡点：不接触回路判定依赖结构，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项

3三、系统型别判断与抛物线输入稳态误差#

思路
  • 单位负反馈开环传函含两个积分环节与一个二阶振荡环节；先判稳，再定系统型别与静态加速度误差系数，求 r(t)=t² 时的稳态误差。
系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环传函数积分环节定系统型别并求加速度误差系数
本卷实例
  • 关键一步：数开环积分环节个数定型别，再令 s 趋于 0 求误差系数
  • 中间结果：型别由开环 s 的幂次决定，加速度系数取相应极限
  • 卡点：二阶振荡环节在 s 趋于 0 时取 1，不要当成积分环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤

4四、根轨迹绘制#

思路
  • 开环传函 G(s)=K/[s(0.2s+1)(0.5s+1)]，按根轨迹绘制法则画根轨迹草图，含实轴段、渐近线、分离点与虚轴交点。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制三阶系统根轨迹草图
本卷实例
  • 关键一步：先化成根轨迹增益形式，再数实轴段并求渐近线
  • 中间结果：三阶系统有三条渐近线，交点为极点和减零点和
  • 卡点：渐近线夹角按 (2k+1)π/(n−m) 取
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法

5五、幅相曲线绘制与稳定性判断#

思路
  • 开环传函 G(s)=k/(Ts−1)（默认 T>0）含右半平面极点；画幅相特性曲线，并按 k 的不同取值用奈奎斯特判据判断闭环稳定性。
频率特性的物理意义与求法 频域分析
本卷考法

本卷实例
  • 关键一步：令 s=jω 分离实部虚部，定起点、终点与变化趋势
  • 中间结果：起点在负实轴 k 处，终点趋于原点
  • 卡点：相角从 −180° 单调增到 −90°，与最小相位系统不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
