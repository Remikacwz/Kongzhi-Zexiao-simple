一一、RLC 无源网络的微分方程、传函与状态空间（原卷有图）#

思路
  • 由回路电压方程得微分方程，取拉氏变换求传函；按给定状态变量列写状态方程与输出方程。
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由 RLC 无源网络列回路电压方程
本卷实例
  • 关键一步：按基尔霍夫电压定律对回路列方程
  • 中间结果：输入电压等于电感、电阻、电容三元件电压之和
  • 卡点：电路以原卷插图给出，元件连接方式需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由 RLC 无源网络列回路电压方程
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 本卷考过把电容电压与电感电压的伏安关系写反
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

由电路或机械系统求传递函数 传递函数
本卷考法

本卷实例
  • 关键一步：用复阻抗分压写出输出电压与输入电压之比
  • 中间结果：电容阻抗为一比 sC，输出取电容两端电压

  • 含运算放大器的有源网络求传递函数

  • 复阻抗法把电容阻抗误写成 Cs

二二、串联校正装置类型判断与参数设计（原卷有图）#

思路
  • 由稳态误差要求定开环增益，算校正前相角裕度与幅值裕度判断缺陷，确定超前校正并设计参数。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由斜坡稳态误差要求求开环增益
本卷实例
  • 关键一步：把误差要求写成速度误差系数倒数的关系
  • 中间结果：一型系统的斜坡误差由开环增益直接确定
  • 卡点：串联校正保持低频增益故稳态误差先定增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由斜坡稳态误差要求求开环增益
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过未先判稳就套用稳态误差公式
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

校正的基本概念与性能指标 系统校正
本卷考法
  • 计算校正前相角裕度与幅值裕度并判断缺陷
本卷实例
  • 关键一步：由开环传函求截止频率处的相角得相角裕度
  • 中间结果：二阶开环幅相不穿负实轴则幅值裕度为无穷
  • 卡点：截止频率低于指标要求说明快速性不足
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过计算校正前相角裕度与幅值裕度并判断缺陷
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 本卷考过把截止频率与相位穿越频率混用
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求

超前校正 系统校正
本卷考法
  • 确定采用超前校正并设计校正参数
本卷实例
  • 关键一步：由要求截止频率处的幅值条件定出衰减系数
  • 中间结果：最大超前角由衰减系数确定
  • 卡点：校正装置的两个转折频率由最大超前角频率定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过确定采用超前校正并设计校正参数
  • 设计串联超前校正装置

  • 分析超前校正的局限性
常见易错
  • 本卷考过补偿角未计入截止频率升高带来的相角损失
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

稳定裕度 频域分析
本卷考法
  • 校验校正后系统的相角裕度
本卷实例
  • 关键一步：把校正后开环传函在新截止频率处求相角
  • 中间结果：校正后相角裕度应不小于指标要求
  • 卡点：新截止频率要取满足幅值条件的那个值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过校验校正后系统的相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过校验时仍用原开环传函
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

三三、描述函数法分析自振（原卷有图）#

思路
  • 求负倒描述函数并判断其在负实轴上的单调范围，再与线性部分幅相曲线比较，分别讨论两个增益下的自振。
描述函数法基础 非线性系统
本卷考法
  • 由描述函数求负倒描述函数并判断单调性
本卷实例
  • 关键一步：对描述函数取负倒数并化简为幅值的函数
  • 中间结果：负倒描述函数落在负实轴且随振幅单调变化
  • 卡点：要先写出振幅趋于零与无穷时的端点值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过由描述函数求负倒描述函数并判断单调性
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 本卷考过忽略一次谐波近似的适用条件
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件
公式
用描述函数法分析自振 非线性系统
本卷考法
  • 判断给定增益下系统是否存在自振并求参数
本卷实例
  • 关键一步：把线性部分曲线与负倒描述函数画在同一复平面找交点
  • 中间结果：交点给出自振频率与振幅
  • 卡点：穿越方向决定自振是稳定还是发散
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过判断给定增益下系统是否存在自振并求参数
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 本卷考过未标出振幅增大方向就判断稳定性
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率
公式
典型非线性特性及其影响 非线性系统
本卷考法
  • 分析增益变化时系统稳定性的变化
本卷实例
  • 关键一步：比较线性部分曲线与负倒特性是否相交或包围
  • 中间结果：无交点且曲线包围负倒特性时系统不稳定
  • 卡点：增益增大可能把不稳定区穿越到稳定区
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 饱和特性降低等效增益，可能引起系统不稳定或自振
  • 死区特性使小信号时增益为零，产生稳态误差
  • 间隙特性引起相位滞后，导致波形畸变与自振
  • 继电特性使系统出现持续振荡并可能产生颤振
步骤
  • 识别非线性环节类型
  • 写出其描述函数或分段数学表达式
  • 分析其对等效增益与稳定性的影响
通用考法
  • 本卷考过分析增益变化时系统稳定性的变化
  • 分析饱和或死区对系统性能的影响
  • 求典型非线性的描述函数表达式
  • 说明间隙为何容易引起自振
常见易错
  • 本卷考过把相交与包围两种情形的结论混为一谈
  • 认为饱和总是使系统更稳定
  • 忽略死区在原点附近造成的小信号失效

频率特性的物理意义与求法 频域分析
本卷考法

思路

能控性与能观性 状态空间分析
本卷考法

  • 按法则求起点终点、实轴段、渐近线、分离点与出射角，画根轨迹并据图确定稳定范围与两实两复极点的增益上界。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画给定四阶系统的根轨迹
本卷实例
  • 关键一步：按极点分布画实轴段并按渐近线走向延伸
  • 中间结果：四条轨迹起于四个极点，渐近线交于实轴一点
  • 卡点：渐近线夹角由极点数与零点数之差决定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画给定四阶系统的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过共轭复极点的出射角方向判错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求分离点坐标与对应增益
本卷实例
  • 关键一步：由闭环特征方程对 s 求导得分离点方程
  • 中间结果：分离点方程有一个实根与一对共轭复根，只取实根
  • 卡点：该实根对应的增益即实极点分裂的边界
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求分离点坐标与对应增益
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 本卷考过把共轭复根当成实轴上的分离点
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
出射角与入射角 根轨迹法
本卷考法
  • 求复数极点的出射角
本卷实例
  • 关键一步：按相角条件求其他零极点对该极点的相角之和
  • 中间结果：共轭两极点出射角互为相反数
  • 卡点：出射角要补足到一百八十度的整数倍
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求复数极点的出射角
  • 求复数极点的出射角
  • 根据出射角画出根轨迹起始方向
  • 由入射角确定根轨迹终止方向
常见易错
  • 本卷考过相角求和时把该极点自身的相角计入
  • 累加相角时把该极点自身的相角也算进去
  • 忘记判断象限导致角度差 180°

与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及稳定增益范围
本卷实例
  • 关键一步：令特征方程代入纯虚根并分离实部虚部
  • 中间结果：虚轴交点对应使系统临界稳定的增益
  • 卡点：交点增益即稳定范围的上界
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及稳定增益范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 本卷考过交点频率取了负值那一组
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由分离点确定两实两复极点对应的增益上界
本卷实例
  • 关键一步：在分离点处求增益，该值即全为实极点的边界
  • 中间结果：增益小于分离点增益时闭环有一对实极点和一对复极点
  • 卡点：极点类型说明要结合根轨迹实轴段判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由分离点确定两实两复极点对应的增益上界
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 本卷考过分离点前后极点个数的变化方向判反
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
