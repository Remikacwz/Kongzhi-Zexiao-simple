1选择题：基本概念与性能5 分#

思路
  • 5个小题覆盖稳定性前提、系统分类、一阶响应、闭环零点与低频段作用。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 选择题第1小题：稳定性是系统正常工作的先决条件（借位）
本卷实例
  • 关键一步：按自动控制系统正常工作的前提判断稳定性的地位
  • 中间结果：稳定性、准确性、快速性是系统基本要求
  • 卡点：把动态特性或稳态特性误当作正常工作的先决条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过选择题第1小题：稳定性是系统正常工作的先决条件（借位）
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
非线性系统的特点 非线性系统
本卷考法
  • 选择题第2小题：由微分方程含输入平方项判断系统为非线性
本卷实例
  • 关键一步：看方程是否满足叠加性与齐次性
  • 中间结果：含输入平方项时不满足线性叠加
  • 卡点：线性时变系统仍有叠加性，不要与非线性混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过选择题第2小题：由微分方程含输入平方项判断系统为非线性
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 选择题第3小题：由一阶系统阶跃响应0.632对应时刻确定时间常数
本卷实例
  • 关键一步：把0.632与一阶响应在t等于T时的值对应
  • 中间结果：一阶响应在t等于T时达到稳态值的63.2%
  • 卡点：把0.632对应到2T或3T
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过选择题第3小题：由一阶系统阶跃响应0.632对应时刻确定时间常数
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
零极点分布与响应模态 传递函数
本卷考法
  • 选择题第4小题：说明闭环零点由前向通路零点与反馈通路极点组成
本卷实例
  • 关键一步：把闭环传函分子分母因式分解后看零点来源
  • 中间结果：前向通路零点直接成为闭环零点，反馈极点也贡献零点
  • 卡点：不要与闭环极点来源混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过选择题第4小题：说明闭环零点由前向通路零点与反馈通路极点组成
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 选择题第5小题：由开环对数幅频低频段判断系统型别与开环增益
本卷实例
  • 关键一步：低频段斜率对应型别，延长线高度对应增益
  • 中间结果：型别与增益共同决定稳态误差
  • 卡点：只看型别不看增益，或把高频段当作低频段
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过选择题第5小题：由开环对数幅频低频段判断系统型别与开环增益
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 选择题第5小题：由型别与开环增益判断稳态误差能力
本卷实例
  • 关键一步：先数积分环节个数确定型别，再看开环增益
  • 中间结果：低频段决定稳态误差而非动态性能
  • 卡点：把抗干扰能力误当作低频段唯一决定因素
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过选择题第5小题：由型别与开环增益判断稳态误差能力
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式

2二阶系统标准形式与指标20 分#

思路
  • 由给定闭环传函化标准二阶形式求参数，再算全部动态性能指标。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传递函数求阻尼比与无阻尼自然频率
本卷实例
  • 关键一步：先把分母写成标准二阶形式再逐项对照系数
  • 中间结果：由常数项开方得自然频率，由一次项系数得阻尼比
  • 卡点：不要忘记把二次项系数归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传递函数求阻尼比与无阻尼自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求上升时间、峰值时间、超调量与调节时间
本卷实例
  • 关键一步：先由阻尼比判断欠阻尼，再逐项代入指标公式
  • 中间结果：各指标都由阻尼比与自然频率组合表示
  • 卡点：题目误差带为加减2%，调节时间系数不要套加减5%
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求上升时间、峰值时间、超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3结构图求输出与误差传函15 分#

思路
  • 由图1结构图分别求输出与误差对输入的闭环传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由图1方框图用梅森增益公式求闭环传递函数
本卷实例
  • 关键一步：列前向通路、独立回路与不接触回路后套梅森公式
  • 中间结果：余子式只去掉与前向通路接触的回路
  • 卡点：结构图为原卷插图，回路走向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由图1方框图用梅森增益公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图化简求闭环传递函数与误差传递函数
本卷实例
  • 关键一步：从内环向外逐层化简，再套串联并联反馈公式
  • 中间结果：化简时保持反馈极性，分母为一加减开环传函
  • 卡点：负反馈分母不要写成一减开环传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由结构图化简求闭环传递函数与误差传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 写出误差传递函数E(s)/R(s)并说明误差定义
本卷实例
  • 关键一步：先确定误差取自输入端还是比较端，再按结构图写比值
  • 中间结果：非单位反馈时两种误差定义相差一个反馈传函
  • 卡点：误差定义选错会让结果整体差一个环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写出误差传递函数E(s)/R(s)并说明误差定义
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

4劳斯判据判断闭环稳定性15 分#

思路
  • 由开环传函得闭环特征方程，列劳斯表判断稳定性。
劳斯判据 稳定性分析
本卷考法
  • 对四阶闭环特征方程用劳斯判据判断稳定性
本卷实例
  • 关键一步：按特征方程系数完整列写劳斯表
  • 中间结果：首列元素全部同号则系统稳定，变号则不稳定
  • 卡点：系数缺项时先补零，首列为零时需特殊处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过对四阶闭环特征方程用劳斯判据判断稳定性
