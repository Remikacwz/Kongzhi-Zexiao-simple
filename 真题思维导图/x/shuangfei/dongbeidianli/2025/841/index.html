1无源网络建模#

思路
  • 先求复阻抗形式的传函，再交叉相乘还原成时域微分方程
由电路或机械系统求传递函数 传递函数
本卷考法
  • 求无源网络的 Uc(s)/Ur(s)
本卷实例
  • 关键一步：用复阻抗表示电阻与电容，按分压或节点电流列方程
  • 中间结果：复阻抗形式的传函交叉相乘即可还原时域微分方程
  • 卡点：无源网络图为原卷插图，元件串并联关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过求无源网络的 Uc(s)/Ur(s)
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过电容复阻抗误写成 Cs
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由传函写出以 Ur(t) 为输入、Uc(t) 为输出的微分方程表达式
本卷实例
  • 关键一步：把 Uc(s)/Ur(s)=N(s)/D(s) 交叉相乘
  • 关键一步：得 D(s)Uc(s)=N(s)Ur(s)，再逐项还原时域
  • 关键一步：再把 s^k 还原成 d^k/dt^k，即得时域微分方程
  • 中间结果：设 Uc(s)/Ur(s)=N(s)/D(s)，交叉相乘得 D(s)Uc=N(s)Ur
  • 中间结果：s^k 逐项换成 d^k/dt^k，即得时域微分方程
  • 卡点：只给传函不给微分方程；题目两问都要，第二问常被漏掉
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由传函写出以 Ur(t) 为输入、Uc(t) 为输出的微分方程表达式
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

2结构图求传函与误差传函#

思路
  • 同一结构图要求两个传递函数：C(s)/R(s) 与 E(s)/R(s)，后者是误差传递函数
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由动态结构图求 C(s)/R(s)
本卷实例
  • 关键一步：按比较点列写误差关系，沿前向通道写到输出
  • 中间结果：各支路增益相乘、回路相加后整理成输出比输入的型式
  • 卡点：结构图未读，交叉反馈支路的走向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法

  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过把负反馈的分母写成 1-GH
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

误差定义与误差传递函数 稳态误差
本卷考法
  • 求误差传递函数 E(s)/R(s)
本卷实例
  • 关键一步：误差取在比较点：E(s)=R(s)−B(s)=R(s)−C(s)H(s)
  • 关键一步：整理后 E/R=1/(1+GH)，单位反馈时 H=1 更简单
  • 关键一步：也可用 E/R = 1 − C/R 的关系直接推
  • 中间结果：误差取自比较点，E(s)=R(s)−C(s)H(s)
  • 中间结果：先求出 C(s)/R(s)，再用 E/R 与 C/R 的关系整理
  • 卡点：把误差定义取错位置（输入端 vs 反馈端），结果差一个 H(s)
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过求误差传递函数 E(s)/R(s)
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

3二阶系统指标与谐振#

思路
  • G=4/(s(s+1)) 求闭环标准二阶参数，再算阻尼状态、阶跃响应、调节时间；最后一问由谐振条件求 ωr 与 Mr
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 确定阻尼比 ξ、无阻尼自然振荡频率 ωn 与阻尼状态
本卷实例
  • 关键一步：先由开环传函写出闭环传函，再化成标准二阶形式
  • 中间结果：由开环增益与时间常数读出自然频率与阻尼比的表达式
  • 卡点：阻尼状态按阻尼比与 1 的大小关系分欠阻尼、临界与过阻尼
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角

  • 按 ξ 的取值判断响应类型

  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过化为标准形式时忘记把 s² 项系数归一化
  • 化为标准形式时忘记把 s² 项系数归一化

本卷考法

本卷实例

  • 中间结果：再把同一组 ξ 代入 Mr=1/(2ξ√(1−ξ²))
  • 卡点：题目要求「角度只需写表达式、开方化为最简」，不要真的算小数

  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性

  • 按经验公式估计超调量与调节时间
通用考法

  • 只列出部分首列元素的不等式，漏掉某个约束

扰动作用下的稳态误差 稳态误差
本卷考法
  • r(t)=t·1(t)、n(t)=1(t) 同时作用时求总稳态误差 ess
本卷实例
  • 关键一步：线性系统按叠加原理：输入引起的误差 + 扰动引起的误差
  • 关键一步：输入是斜坡、扰动是阶跃，两者分别套自己型别下的误差公式，最后相加
  • 中间结果：总误差按叠加拆成输入引起的误差与扰动引起的误差两项
  • 中间结果：斜坡输入误差与型别和开环增益有关；阶跃扰动误差另按扰动点前后传函算
  • 卡点：只算输入误差或只算扰动误差，漏掉另一半

  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法

  • 求扰动引起的稳态误差

  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

5复极点根轨迹与稳定域#

思路
  • G=k/((s²+2s+2)(s²+2s+5))，两组复极点、无零点；要算渐近线、分离点、虚轴交点与出射角
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制 k 从 0→∞ 的闭环根轨迹，写出开环零极点并计算渐近线、分离点、虚轴交点
本卷实例
  • 关键一步：开环极点是两组共轭复极点的并集，无零点 → n=4、m=0、渐近线 4 条
  • 关键一步：渐近线交点 σa=Σp/n
  • 关键一步：夹角 (2k+1)180°/4 = 45°、135°、225°、315°
  • 中间结果：s²+2s+2 的根 −1±j；s²+2s+5 的根 −1±2j
  • 中间结果：Σp = (−1−1−1−1) = −4 → σa = −1
  • 卡点：复数极点的实部和要全部算进去，漏一个交点就错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
