1热电炉温度系统方框图5 分#

思路
  • 由给定温度与热电偶反馈确定被控量与操纵量，按闭环结构画方块图。
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 说明热电炉温度控制系统的工作过程并绘制方块图
  • 指出被控量、操纵量与扰动作用
本卷实例
  • 关键一步：先由工艺要求确定被控量为炉温、操纵量为调压器电压
  • 中间结果：沿给定、比较、放大、执行、对象、反馈串成闭环方框图
  • 卡点：系统原理图以原卷插图给出，元件符号与连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过说明热电炉温度控制系统的工作过程并绘制方块图
  • 本卷考过指出被控量、操纵量与扰动作用
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出系统由比较、放大、执行、被控对象与检测反馈环节组成
本卷实例
  • 关键一步：按原理图逐块识别各环节的输入输出关系
  • 中间结果：把温度偏差经放大与执行机构作用到调压器写成信号流
  • 卡点：被控量与操纵量容易互换，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指出系统由比较、放大、执行、被控对象与检测反馈环节组成
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

2数学模型与方框图求传函25 分#

思路
  • 两小题：无源网络用复阻抗求输出比输入与微分方程；方框图用梅森公式求闭环传函。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由图2无源网络求Uo(s)/Ui(s)并写微分方程
本卷实例
  • 关键一步：把电容写成1/(sC)，按复阻抗分压或节点电流列方程
  • 中间结果：先得复阻抗分压式，再交叉相乘还原为s的多项式比
  • 卡点：网络为原卷插图，串并联关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由图2无源网络求Uo(s)/Ui(s)并写微分方程
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

电路网络与有源网络建模 建模与机电系统
本卷考法

本卷实例

  • 中间结果：写出回路或节点方程后消去中间变量
  • 卡点：无源网络按分压处理，不要套用运放的虚短虚断

梅森增益公式与信号流图 传递函数
本卷考法
  • 由图3方框图用梅森增益公式求C(s)/R(s)
本卷实例
  • 关键一步：列全部独立回路、前向通路并写特征式
  • 中间结果：余子式只去掉与前向通路接触的回路
  • 卡点：图形需回原卷核对图，不接触回路易漏算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由图3方框图用梅森增益公式求C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

3二阶系统阶跃响应与指标20 分#

思路
  • 由图4单位阶跃响应曲线读超调与峰值时间，反求阻尼比与自然频率，再算各动态指标。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由阶跃响应曲线读取超调量与峰值时间反求二阶参数
本卷实例
  • 关键一步：先从曲线读出超调量与峰值时间，再按二阶公式联立
  • 中间结果：由超调反求阻尼比，再由峰值时间反求自然频率
  • 卡点：曲线为原卷插图，峰值与稳态值读数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由阶跃响应曲线读取超调量与峰值时间反求二阶参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 化闭环传函为标准二阶形式并确定阻尼比与自然频率
本卷实例
  • 关键一步：把闭环特征多项式与标准二阶形式逐项对照
  • 中间结果：由一次项与常数项系数联立解出两个参数
  • 卡点：不要把开环增益直接当作闭环标准形式系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过化闭环传函为标准二阶形式并确定阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求上升时间、峰值时间、超调量与调节时间
本卷实例
  • 关键一步：先判断为欠阻尼，再逐项代入对应指标公式
  • 中间结果：各指标都由阻尼比与自然频率组合表示
  • 卡点：题目误差带为加减5%，调节时间系数不要套加减2%
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求上升时间、峰值时间、超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

4劳斯判据与特征根分布15 分#

思路
  • 列劳斯表，由首列变号次数判断右半平面根数。
劳斯判据 稳定性分析
本卷考法
  • 对给定五阶特征方程用劳斯判据判断稳定性与右半平面根数
本卷实例
  • 关键一步：按特征方程系数完整列写劳斯表，首列出现零时需处理
  • 中间结果：首列元素变号次数对应右半平面特征根个数
  • 卡点：系数有缺项时先补零，首列为零时不能按常规继续
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过对给定五阶特征方程用劳斯判据判断稳定性与右半平面根数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式

5根轨迹绘制与欠阻尼参数20 分#

思路
  • 绘制根轨迹并标出起止点、分离点、渐近线、虚轴交点，再求稳定范围和指定阻尼比下的参数。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制K从0到无穷的180度根轨迹并标出特征点
本卷实例
  • 关键一步：先求开环零极点，再定实轴段、渐近线与分离点
  • 中间结果：渐近线交点和夹角由零极点个数差决定
  • 卡点：渐近线夹角公式中的2k+1不要写成2k
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制K从0到无穷的180度根轨迹并标出特征点
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹分离点及对应临界参数
本卷实例
  • 关键一步：由dK/ds等于零求分离点候选，再筛选在根轨迹上的解
  • 中间结果：把分离点代入幅值条件求对应参数
  • 卡点：两个数学解中只有一个落在根轨迹实轴段上
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹分离点及对应临界参数
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及使系统稳定的参数范围
本卷实例
  • 关键一步：将s等于jω代入闭环特征方程，分离实部与虚部
  • 中间结果：令实部虚部同时为零即可求交点频率与临界参数
  • 卡点：只取一组交点容易漏掉另一组
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
