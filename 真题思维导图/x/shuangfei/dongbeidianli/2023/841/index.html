1运放模拟电路与典型环节#

思路
  • 由运放电路列KCL并利用虚短虚断，先求各级传函再求总传函并判断典型环节。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由运放模拟电路求 U2(s)/U1(s)
  • 由多级运放电路求总传函 U0(s)/Ui(s)
本卷实例
  • 关键一步：把运放输入与反馈支路写成复阻抗，逐级列输出比输入
  • 中间结果：多级串联时把各级传函相乘，再整理成 s 的有理分式
  • 卡点：运放电路为原卷插图，电阻电容接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由运放模拟电路求 U2(s)/U1(s)
  • 本卷考过由多级运放电路求总传函 U0(s)/Ui(s)
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 对运放电路列KCL并利用虚短虚断求解
本卷实例
  • 关键一步：利用虚短使两输入端电压相等，虚断使输入电流为零
  • 中间结果：按节点列KCL方程，解出输出与输入电压的关系
  • 卡点：含多级运放时逐级求解，不要一次把所有节点写进同一方程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过对运放电路列KCL并利用虚短虚断求解
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

典型环节及其特性 传递函数
本卷考法
  • 判断所得环节属于哪种典型环节
  • 说明一阶惯性环节的增益与时间常数
本卷实例
  • 关键一步：把所得传函与典型环节标准式对照，先看分母阶次
  • 中间结果：一阶惯性标准式分母为 Ts+1，分子的常数为增益
  • 卡点：环节判断要基于整理后的标准形式，不能只看原始电路形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过判断所得环节属于哪种典型环节
  • 本卷考过说明一阶惯性环节的增益与时间常数
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减

2结构图与二阶动态指标#

思路
  • 先由单位阶跃响应反求 G1(s)，再由结构图求闭环传函并计算二阶指标。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应 1−e^{−t} 反求 G1(s)
本卷实例
  • 关键一步：由响应形式判断系统为一阶惯性环节，稳态值对应增益
  • 中间结果：指数项系数对应时间常数的倒数，据此写出 G1(s)
  • 卡点：先判阶数再写传函，不要直接把响应拉氏变换当成传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应 1−e^{−t} 反求 G1(s)
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由结构图求闭环传函并化为标准二阶形式
  • 确定阻尼比与自然频率
本卷实例
  • 关键一步：先把结构图化简成闭环传函，再把分母化成标准二阶形式
  • 中间结果：由一次项系数与常数项分别读出 ξ 与 ωn 的表达式
  • 卡点：结构图为原卷插图，G1(s) 在回路中的位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由结构图求闭环传函并化为标准二阶形式
  • 本卷考过确定阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求 σ%、tr、tp 与 ts（Δ=±5%）
本卷实例
  • 关键一步：先由 ξ 判断欠阻尼，再按对应公式逐项计算
  • 中间结果：σ% 只由 ξ 决定，tr 与 tp 还取决于 ωn
  • 卡点：ts 按题目指定的 5% 误差带取系数，不要用 2% 的系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求 σ%、tr、tp 与 ts（Δ=±5%）
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3劳斯判据与稳态误差#

思路
  • 先列劳斯表判稳，再由型别求加速度误差系数，最后用误差频率特性求正弦输入稳态误差。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断系统稳定性
本卷实例
  • 关键一步：写出闭环特征方程并按降幂排列，检查系数是否缺项
  • 中间结果：列劳斯表后看首列是否全为正
  • 卡点：首列有零时要用辅助方程或ε法，不能直接下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断系统稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 判断系统型别并求加速度误差系数
本卷实例
  • 关键一步：由开环传函分母中积分环节个数判断系统型别
  • 中间结果：型别决定常用静态误差系数中哪一个有限
  • 卡点：求加速度误差系数时要把开环增益与剩余因子的极限分开看
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断系统型别并求加速度误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求 r(t)=t² 时系统的稳态误差
本卷实例
  • 关键一步：先确认系统稳定，再用终值定理或静态误差系数求误差
  • 中间结果：r(t)=t² 对应加速度输入，应使用加速度误差系数
  • 卡点：答案段把加速度与速度误差系数符号混用，按输入类型判据理解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求 r(t)=t² 时系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求正弦输入下误差的幅值与相角
  • 由误差传递函数 E(jω) 求稳态误差
本卷实例
  • 关键一步：先写误差传递函数，再令 s=jω 代入输入角频率
  • 中间结果：把 E(jω) 整理成幅值与相角形式，对应正弦稳态误差
  • 卡点：正弦输入下稳态误差仍是同频正弦量，不能只算幅值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求正弦输入下误差的幅值与相角
  • 本卷考过由误差传递函数 E(jω) 求稳态误差
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

4根轨迹绘制与临界参数#

思路
  • 由开环传函画根轨迹，求分离点、起始角、虚轴交点及欠阻尼与稳定范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制 K 从 0→∞ 的闭环根轨迹
  • 写开环零极点、实轴段与渐近线
本卷实例
  • 关键一步：先写开环极点与零点，判断实轴根轨迹段和渐近线条数
  • 中间结果：渐近线交点与夹角按 n−m 计算，再在草图上标注
  • 卡点：画图前先核对开环传函的极零点，避免把重极点分开数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制 K 从 0→∞ 的闭环根轨迹
  • 本卷考过写开环零极点、实轴段与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹分离点及该点对应 K
本卷实例
  • 关键一步：由闭环特征方程重根条件列分离点方程
  • 中间结果：解出候选实根后要检验是否位于根轨迹实轴段上
  • 卡点：分离点对应两条根轨迹分支交汇，K值由幅值条件回代
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根

9状态空间传函与能控能观#

思路
  • 由状态空间表达式求传递函数，并分别构造能控、能观判别矩阵判断性质。
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由状态空间表达式求G(s)=Y(s)/U(s)
本卷实例
  • 关键一步：按G(s)=C(sI−A)⁻¹B计算，先求逆矩阵再左右乘
  • 中间结果：若输出方程含直接传递项，最后还要加上D
  • 卡点：矩阵求逆后先核对维数，再进行C与B的乘法
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过由状态空间表达式求G(s)=Y(s)/U(s)
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

能控性与能观性 状态空间分析
本卷考法
  • 判断系统的能控性与能观性
本卷实例
  • 关键一步：能控性矩阵取[B AB]，观测性矩阵取[C; CA]
  • 中间结果：分别求秩并与状态维数比较判断是否满秩
  • 卡点：能控与能观使用不同的判别矩阵，不能互相替代
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断系统的能控性与能观性
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
