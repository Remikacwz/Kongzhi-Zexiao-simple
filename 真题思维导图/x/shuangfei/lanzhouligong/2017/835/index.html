1直流发电机励磁调压系统的组成与方框图（原卷有图）10 分#

思路
  • 读系统工作原理图，画出工作原理方框图；说明输出电压的调节过程；分析引起输出电压波动的主要干扰源。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 画出给定系统的方框图并说明控制方式
本卷实例
  • 关键一步：按给定环节与反馈通路画比较、放大、执行、对象与测量
  • 中间结果：被调量经测量环节反馈到输入端参与比较
  • 卡点：系统原理图以插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过画出给定系统的方框图并说明控制方式
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把执行机构与被控对象的位置画反
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 由系统原理说明被调量与调节过程
本卷实例
  • 关键一步：找出给定输入、被调量与执行变量
  • 中间结果：改变给定就改变误差电压进而改变励磁
  • 卡点：分析干扰源要从误差通道与负载两侧看
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过由系统原理说明被调量与调节过程
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 本卷考过把扰动当成给定值
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半

2方框图求 C(s)/R(s) 与 C(s)/N(s)（原卷有图）6 分#

思路
  • 分别令扰动与参考输入为零，按信号流图列回路与前向通路，用梅森公式求两路传递函数。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求参考输入与扰动分别作用下的传递函数
本卷实例
  • 关键一步：分别置零另一输入再各求一次传递函数
  • 中间结果：两路传函的分母相同、前向通路不同
  • 卡点：信号流图以插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求参考输入与扰动分别作用下的传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 本卷考过求扰动传函时忘了把参考输入置零
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求两输入两输出的传递函数
本卷实例
  • 关键一步：先写全部独立回路再写各前向通路
  • 中间结果：特征式由回路增益及其不接触组合构成
  • 卡点：扰动到输出可能有不只一条前向通路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求两输入两输出的传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过把回路增益写成前向通路增益
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

3由闭环特征方程求开环增益、型别与稳态误差15 分#

思路
  • 由给出的闭环特征方程列劳斯表判稳，求出开环增益与系统型别，再算三个静态误差系数与单位阶跃的稳态误差。
劳斯判据 稳定性分析
本卷考法
  • 由闭环特征方程列劳斯表判断稳定性
本卷实例
  • 关键一步：按特征方程系数列劳斯表并令首列全为正
  • 中间结果：首列符号条件化为两个参数不等式
  • 卡点：稳定条件是两个简单不等式的交
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由闭环特征方程列劳斯表判断稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过系数缺项时未补零就套判据
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环传函定系统型别与静态误差系数
本卷实例
  • 关键一步：看开环传函中积分环节个数定系统型别
  • 中间结果：型别决定哪几个静态误差系数为零或无穷
  • 卡点：开环增益由低频段表达式取极限得到
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由开环传函定系统型别与静态误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 本卷考过型别与阶数混用
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位阶跃输入下的稳态误差
本卷实例
  • 关键一步：用静态位置误差系数求阶跃输入的稳态误差
  • 中间结果：一型系统的阶跃输入稳态误差为零
  • 卡点：第三题大题头与题图在逐年册中缺失，据同年答案段还原
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位阶跃输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过未判稳就套终值定理
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

4根轨迹为圆及最小阻尼比14 分#

思路
  • 由闭环特征方程用韦达定理证明增益变化时复数根轨迹为圆并求圆心半径；代入具体参数画根轨迹，再求最小阻尼比及对应闭环极点。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制该开环系统的根轨迹
本卷实例
  • 关键一步：先标出开环零极点再求实轴段与渐近线
  • 中间结果：分离点由根轨迹方程对增益求极值得到
  • 卡点：根轨迹与虚轴的交点是稳定边界
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制该开环系统的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过渐近线夹角与实轴夹角写反
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 证明根轨迹复数部分为圆并由圆求阻尼比
本卷实例
  • 关键一步：把复数根的实部虚部关系消去增益得到圆方程
  • 中间结果：圆心由开环零点与开环极点确定
  • 卡点：最小阻尼比对应从原点向圆所作切线的切点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过证明根轨迹复数部分为圆并由圆求阻尼比
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 本卷考过把根轨迹圆的圆心当成开环零点
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环极点求阻尼比与自然频率
本卷实例
  • 关键一步：由极点的实部虚部算阻尼角再取余弦得阻尼比
  • 中间结果：极点到原点的距离即自然频率
  • 卡点：阻尼比越小系统振荡衰减越慢
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环极点求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过把阻尼比与阻尼角混淆
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

5由对数幅频求校正后传函与校正装置（原卷有图）20 分#

思路
  • 由校正后对数幅频低频段的斜率与转折频率写出校正后开环传函，算相角裕度；再用校正后传函除以校正前传函得校正装置，画其幅频并说明作用。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频近似特性曲线反求开环传函
本卷实例
  • 关键一步：低频段斜率定积分环节个数、折点定转折频率
  • 中间结果：曲线延长线过零分贝的频率定开环增益
  • 卡点：对数幅频曲线以插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频近似特性曲线反求开环传函
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 本卷考过低频段延长线的位置读错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
