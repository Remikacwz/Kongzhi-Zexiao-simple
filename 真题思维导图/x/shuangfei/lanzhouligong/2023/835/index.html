2根轨迹绘制与极点及动态性能#

思路
  • 对G(s)=K除以s(s+2)(s+4)画根轨迹，由闭环极点-5求其余极点，再算超调与调节时间
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制三阶系统根轨迹
本卷实例
  • 关键一步：定开环零极点、渐近线与实轴段
  • 中间结果：由分离点条件求根轨迹与实轴交点
  • 卡点：三条渐近线的夹角与交点要算对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制三阶系统根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由已知一个闭环极点反求其余极点
本卷实例
  • 关键一步：用闭环特征式除以已知极点对应因式
  • 中间结果：商式为其余闭环极点对应的因式
  • 卡点：已知闭环极点代入特征式可直接定增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由已知一个闭环极点反求其余极点
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由闭环极点算超调量与调节时间
本卷实例
  • 关键一步：由其余极点读出ξ与ωn再套指标公式
  • 中间结果：化为标准二阶形式后套用动态指标公式
  • 卡点：用主导极点近似前要判断适用性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由闭环极点算超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3由Bode图求传函并判稳与超前校正#

思路
  • 由图反求校正前传函并判稳，再作串联超前校正并绘校正后幅频，说明影响
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频图反求开环传递函数
本卷实例
  • 关键一步：由低频段斜率与基准点定型别与增益
  • 中间结果：按转折频率处斜率变化定各对应环节
  • 卡点：题面配原卷Bode图，转折频率与高度需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频图反求开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由相频曲线与负穿越判断闭环稳定性
本卷实例
  • 关键一步：由图读正负穿越次数并数右半平面开环极点
  • 中间结果：按Z等于P减2N判断右半平面闭环极点数
  • 卡点：正负穿越的定义与方向勿弄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由相频曲线与负穿越判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制校正后开环对数幅频渐近线
本卷实例
  • 关键一步：先定校正后各转折频率再逐段改斜率
  • 中间结果：低频段高度按增益与型别确定
  • 卡点：逐段斜率是累加而非替换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过绘制校正后开环对数幅频渐近线
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
超前校正 系统校正
本卷考法
  • 由校正装置传函判断超前或滞后及对性能影响
本卷实例
  • 关键一步：比较校正装置分子分母转折频率大小判断类型
  • 中间结果：超前校正抬高中频段并右移截止频率
  • 卡点：超前与滞后对调节时间的影响方向相反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过由校正装置传函判断超前或滞后及对性能影响
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

4滞后串联校正装置设计#

思路
  • 按K不小于5、γ不小于40度、ωc不小于0.5，设计滞后串联校正装置
滞后校正 系统校正
本卷考法
  • 按相角裕度与截止频率指标设计串联滞后校正
本卷实例
  • 关键一步：由未校正相角裕度与补偿角定新ωc
  • 中间结果：用滞后网络在ωc处拉低增益以满足裕度
  • 卡点：题面与第五题被OCR挤在同段，需回原卷核对题面
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过按相角裕度与截止频率指标设计串联滞后校正
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
稳定裕度 频域分析
本卷考法
  • 计算未校正系统相角裕度作为设计依据
本卷实例
  • 关键一步：抓大放小求ωc再累加相角得γ
  • 中间结果：未校正相角裕度为负需大幅补偿
  • 卡点：校正后需回代重算相角裕度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过计算未校正系统相角裕度作为设计依据
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

5最少拍数字校正器设计#

思路
  • ZOH与三阶对象、采样周期0.2s下，按无稳态误差与有限拍设计D(z)并画输出
脉冲传递函数 离散控制系统
本卷考法
  • 求含零阶保持器的开环脉冲传函
本卷实例
  • 关键一步：用(1-z负一次)乘连续部分再部分分式取z变换
  • 中间结果：脉冲传函为含三个极点的有理式
  • 卡点：零阶保持器必须计入G(z)
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过求含零阶保持器的开环脉冲传函
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
