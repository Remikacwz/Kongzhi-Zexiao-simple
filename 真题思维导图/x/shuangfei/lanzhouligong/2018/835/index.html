一恒温箱温度控制系统（组成与方框图）10 分#

思路
  • 由温度控制系统图识别被控对象与反馈通路，用偏差调节过程说明恒温原理，再指认被控对象与被控量。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 据题一图指出恒温箱系统的被控对象与被控量
  • 画出闭环方框图并说明恒温调节过程
本卷实例
  • 关键一步：沿热电偶反馈电压与给定电压比较得偏差，勾出闭环方框图
  • 中间结果：偏差经放大器驱动伺服电机，经减速器调压器改变炉温
  • 卡点：恒温箱系统原理以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过据题一图指出恒温箱系统的被控对象与被控量
  • 本卷考过画出闭环方框图并说明恒温调节过程
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把加热电阻丝当成被控对象，或把调压器电压当成被控量
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 指认该温度控制系统的被控量、操纵量与主要扰动
本卷实例
  • 关键一步：按过程控制组成把电炉、热电偶、放大器、电机、调压器逐一归位
  • 中间结果：被控对象为电炉、被控量为炉温，执行机构含电机与调压器
  • 卡点：系统组成以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过指认该温度控制系统的被控量、操纵量与主要扰动
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 本卷考过把操纵量调压器电压与扰动量炉门散热混为一谈
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半

二方框图求C(s)/R(s)与C(s)/N(s)（原卷有图）10 分#

思路
  • 用梅森增益公式分别对参考输入与扰动输入求传函，注意扰动通路前向增益的符号与回路接触关系。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 由题二图求扰动N(s)引起的C(s)/N(s)
本卷实例
  • 关键一步：令R(s)为零，只保留N(s)到C(s)的前向通路
  • 中间结果：扰动通路与唯一回路相接触，余子式取1
  • 卡点：信号流图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过由题二图求扰动N(s)引起的C(s)/N(s)
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 本卷考过求扰动传函时未把参考输入置零
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求C(s)/R(s)与C(s)/N(s)
本卷实例
  • 关键一步：找出回路L1=-G2G3，分别写两条前向通路的余子式
  • 中间结果：特征余子式Δ=1+G2G3，两个传函分母相同
  • 卡点：通路与回路关系以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求C(s)/R(s)与C(s)/N(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路漏计或余子式取错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

三由结构图与阶跃响应反求K1、K2、T（原卷有图）13 分#

思路
  • 先由图3(a)化简求闭环传函并化为二阶标准形式，再由图3(b)的超调量与峰值时间反求ξ、ωn，最后比较系数解出三参数。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由图3(a)内环反馈化简求闭环传函C(s)/R(s)
本卷实例
  • 关键一步：先化内环K2/[s(Ts+1)]，再与K1串成闭环
  • 中间结果：闭环传函为K1K2与(Ts²+s+K2)之比
  • 卡点：结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由图3(a)内环反馈化简求闭环传函C(s)/R(s)
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过把负反馈分母写成1-GH，或化内环时把外环信号当常数
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为二阶标准形式并与响应图对参数
本卷实例
  • 关键一步：把分母化为s²+(1/T)s+K2/T，与标准式系数对应
  • 中间结果：ωn²=K2/T，2ξωn=1/T
  • 卡点：阶跃响应曲线以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为二阶标准形式并与响应图对参数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过化标准形式时未把s平方项系数归一化
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由图3(b)阶跃响应的超调量与峰值时间反求ξ、ωn
本卷实例
  • 关键一步：从曲线读超调量约两成、峰值时间约0.6s
  • 中间结果：由σ%与tp两个公式分别解出ξ与ωn
  • 卡点：曲线峰值与稳态值需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 峰值时间、上升时间、调节时间都与 ωn 成反比

  • 振荡次数与 ξ 直接相关
步骤

  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法

  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错

  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

四关于K和T的多参数根轨迹12 分#

思路
  • 把含两个参数的开环传函按参数分组，先讨论辅助方程极点随K的分布，再对固定K作以T为变量的广义根轨迹。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以T为参数绘制G0(s)=K(Ts+1)/[s(s+1)(s+2)]的广义根轨迹
本卷实例
  • 关键一步：把特征方程按K与T分组，构造只含T的等效开环
  • 中间结果：等效开环为KT乘s与(s³+3s²+2s+K)之比
  • 卡点：需先讨论辅助方程极点随K的分布再作轨迹
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以T为参数绘制G0(s)=K(Ts+1)/[s(s+1)(s+2)]的广义根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 本卷考过整理等效开环时未把参数完整提到分子
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

根轨迹的绘制法则 根轨迹法
本卷考法
  • 由根之和定理讨论辅助方程三极点随K的位置
本卷实例
  • 关键一步：由根之和恒为-3判断三极点分布随K的变化
  • 中间结果：K小于0.38时三实极点，反之一对复极点
  • 卡点：根轨迹草图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤

  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过由根之和定理讨论辅助方程三极点随K的位置
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴根轨迹段判据里的零极点个数算错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

分离点与会合点 根轨迹法
本卷考法
  • 求等效根轨迹的分离点
本卷实例

  • 中间结果：分离点约为-0.42

  • 代回求分离点处的 K 值
通用考法

  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍

  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 能控性与能观性经非奇异线性变换保持不变
步骤

  • 构造能观性矩阵并求秩
