一恒温箱温度控制系统（组成与方框图）10 分#

思路
  • 由温度控制系统图识别被控对象与反馈通路，用偏差调节过程说明恒温原理，再指认被控对象与被控量。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 据题一图指出恒温箱系统的被控对象与被控量
  • 画出闭环方框图并说明恒温调节过程
本卷实例
  • 关键一步：沿热电偶反馈电压与给定电压比较得偏差，勾出闭环方框图
  • 中间结果：偏差经放大器驱动伺服电机，经减速器调压器改变炉温
  • 卡点：恒温箱系统原理以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量

  • 画出给定系统的闭环方框图并说明工作过程

  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

三由稳态误差与闭环极点反求开环传函13 分#

思路
  • 设开环传函为K/[s(s²+bs+c)]的I型三阶形式，先由单位斜坡稳态误差为2建立K与c的关系，再由一对闭环复极点-1±j1确定二次因子，比较系数解出各参数。
系统型别与静态误差系数 稳态误差
本卷考法
  • 判定系统型别并写出静态速度误差系数Kv
本卷实例
  • 关键一步：按I型三阶假设Kv等于s趋于0时sG(s)的极限
  • 中间结果：单位斜坡稳态误差为c与K之比
  • 卡点：须由稳态误差要求先建立K与c的关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值

  • 分析增加积分环节对精度的影响

  • 把开环增益与静态误差系数混为一谈

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型

  • 最小实现要求系统既能控又能观

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过设计状态反馈把闭环极点配置到-2、-4、-7

  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
