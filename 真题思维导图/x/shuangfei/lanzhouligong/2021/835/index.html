1恒温箱温度控制系统（组成与方框图）10 分#

思路
  • 由图给出恒温箱温度控制系统，画方框图、说明工作原理并指认被控对象与被控变量
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 画恒温箱温度闭环方框图并说明调温工作原理
本卷实例
  • 关键一步：以热电偶测炉温、偏差经放大驱动电机调压
  • 中间结果：给定电压与反馈电压比较得偏差信号
  • 卡点：题面配原卷系统图，元件接法与信号流向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过画恒温箱温度闭环方框图并说明调温工作原理
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 指认被控对象、被控变量与执行元件
本卷实例
  • 关键一步：按炉温为被控变量、电阻丝加热为操纵手段
  • 中间结果：被控对象为加热炉，输出为炉温
  • 卡点：题面配原卷系统图，被控对象标注需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过指认被控对象、被控变量与执行元件
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半

2结构图求动态性能与稳态误差（微分反馈）10 分#

思路
  • 由结构图求闭环传函，算欠阻尼指标与斜坡稳态误差，再定微分反馈系数
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由含微分反馈的结构图求闭环传递函数
本卷实例
  • 关键一步：先化简内环得到等效开环再写闭环特征式
  • 中间结果：闭环化为二阶标准形式并读出ξ与ωn
  • 卡点：微分反馈系数出现在特征式一次项，勿与开环增益混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由含微分反馈的结构图求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由ξ与ωn计算超调量与调节时间
本卷实例
  • 关键一步：把闭环特征式归一化成二阶标准形式再套指标公式
  • 中间结果：据ξ与ωn查超调量与调节时间的对应公式
  • 卡点：调节时间误差带取5%还是2%要按题给，勿混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由ξ与ωn计算超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 单位斜坡输入下的稳态误差计算
本卷实例
  • 关键一步：先判稳再用终值定理求静态速度误差系数
  • 中间结果：由速度误差系数写出误差与开环增益的关系
  • 卡点：非单位反馈时误差定义要先明确
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过单位斜坡输入下的稳态误差计算
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
PID 控制器与参数整定 系统校正
本卷考法
  • 用PD控制同时满足阻尼比与稳态误差要求
本卷实例
  • 关键一步：在原微分反馈上改用PD控制器同时兼顾误差与ξ
  • 中间结果：由闭环特征式比对标准形式求PD参数
  • 卡点：保持ξ不变又要减小误差，单靠比例增益不可行
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过用PD控制同时满足阻尼比与稳态误差要求
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

3参数a的根轨迹绘制10 分#

思路
  • 由含参数a的开环传函化等效开环，按法则画参数a的根轨迹
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以参数a为变量绘制参数根轨迹
本卷实例
  • 关键一步：把特征式整理成a为参变量的等效开环形式
  • 中间结果：等效开环写成 a 除以 s 乘(2s+1)的平方
  • 卡点：参数根轨迹要先分离出参数a的乘子再画
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以参数a为变量绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按基本法则绘制根轨迹草图
本卷实例
  • 关键一步：由开环零极点定实轴段、渐近线与分离点
  • 中间结果：三条根轨迹有两条趋向无穷远并交于实轴
  • 卡点：实轴段判据按零极点个数计，重极点勿漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按基本法则绘制根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

4由Bode图反求传函与串联超前校正20 分#

思路
  • 由图3反求校正后开环传函，算相角裕量，再分离校正装置并说明作用
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频渐近线反求开环传递函数
本卷实例
  • 关键一步：先由低频段斜率与高度定型别与开环增益
  • 中间结果：按各转折频率处斜率变化识别对应环节
  • 卡点：题面配原卷图3，转折频率与高度需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频渐近线反求开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 计算校正后系统的相角裕量
本卷实例
  • 关键一步：用抓大放小分段近似求截止频率
  • 中间结果：在ωc处累加各环节相角得相角裕量
  • 卡点：分段近似取得的ωc要回代对应频段校验
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过计算校正后系统的相角裕量
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

超前校正 系统校正
本卷考法
  • 由校正前后传函求校正装置并判断类型
本卷实例
  • 关键一步：用校正后传函除以未校正传函得校正装置
  • 中间结果：由校正装置零极点判断超前或滞后校正
  • 卡点：分子转折频率高于分母才属超前校正
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过由校正前后传函求校正装置并判断类型
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

5滞后串联校正装置设计15 分#

思路
  • 给K不小于5、γ不小于40度、ωc不小于0.5，设计滞后串联校正装置
滞后校正 系统校正
本卷考法
  • 按相角裕度要求设计串联滞后校正装置
本卷实例
  • 关键一步：由未校正相角裕度与补偿角定新截止频率
  • 中间结果：用滞后网络在低频段抬升增益以满足K要求
  • 卡点：滞后网络分子转折频率应低于分母，勿写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
