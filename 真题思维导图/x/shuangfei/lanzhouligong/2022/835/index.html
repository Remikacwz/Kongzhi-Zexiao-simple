1人工液位控制系统（开环闭环与方框图）#

思路
  • 由图判断人工阀门控制的开环或闭环性质，画方框图，再用装置替代人构成自动液位控制并指认输入输出
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断人工液位控制系统是开环还是闭环并画方框图
本卷实例
  • 关键一步：看有无反馈：仪表显示高度供操作员比较即构成闭环
  • 中间结果：人眼与手分别替代比较环节与执行环节
  • 卡点：题面配原卷系统示意图，元件接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断人工液位控制系统是开环还是闭环并画方框图
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 用控制器替代人工并指认输入量与输出量
本卷实例
  • 关键一步：用液位变送器与调节器替代人眼和手构成闭环
  • 中间结果：由液位偏差驱动调节阀改变进液量
  • 卡点：被控量与操纵量勿写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过用控制器替代人工并指认输入量与输出量
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半

2含参数β反馈系统的稳定与性能分析#

思路
  • 由结构图求闭环传函，分析β对稳定性、阶跃动态性能与斜坡稳态误差的影响
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求含β反馈的闭环传递函数
本卷实例
  • 关键一步：找独立回路与前向通路，写特征式与余子式
  • 中间结果：闭环特征式为二阶并含β相关一次项
  • 卡点：两回路是否接触要先判断再写不接触乘积
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求含β反馈的闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据分析β对系统稳定性的影响
本卷实例
  • 关键一步：列劳斯表看第一列符号判断稳定条件
  • 中间结果：β为零时特征根为共轭虚根，处于临界
  • 卡点：β为零时劳斯表首列出现0，需单独讨论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据分析β对系统稳定性的影响
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 分析β对阶跃响应动态性能的影响
本卷实例
  • 关键一步：把闭环特征式比对标准二阶式读出ξ与ωn
  • 中间结果：β增大时ξ增大而ωn不变
  • 卡点：超调与调节时间随ξ的变化方向勿弄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过分析β对阶跃响应动态性能的影响
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 分析β对斜坡响应稳态误差的影响
本卷实例
  • 关键一步：判稳后用终值定理求斜坡误差
  • 中间结果：斜坡误差与β成正比、与开环增益成反比
  • 卡点：不同类型输入要用对应的静态误差系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过分析β对斜坡响应稳态误差的影响
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3根轨迹绘制与阻尼比反求参数15 分#

思路
  • 对G(s)=K(s+10)除以s(s+5)画根轨迹，求ξ为0.707时的K与闭环根，并分析K对性能影响
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按基本法则绘制给定开环传函的根轨迹
本卷实例
  • 关键一步：列出开环零极点，定实轴段与渐近线
  • 中间结果：由分离、汇合条件求根轨迹与实轴交点
  • 卡点：本例根轨迹为圆，需由闭环复根条件验证
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按基本法则绘制给定开环传函的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由阻尼比要求反求增益K与闭环极点
本卷实例
  • 关键一步：把闭环特征式与标准二阶式比对ξ与ωn关系
  • 中间结果：联立解得满足ξ的增益与闭环特征根
  • 卡点：最小阻尼比对应根轨迹的切线点，需求切点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由阻尼比要求反求增益K与闭环极点
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征根判断系统阻尼状态
本卷实例
  • 关键一步：按特征根实部与虚部判断过阻尼或欠阻尼
  • 中间结果：分离点与汇合点对应临界增益取值
  • 卡点：区间端点处的阻尼状态要按根类型判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征根判断系统阻尼状态
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

4参数T对相角裕度的影响#

思路
  • 对两种开环传函分别求截止频率与相角裕度，讨论T变化对相角裕度的影响
稳定裕度 频域分析
本卷考法
  • 求截止频率并讨论参数T对相角裕度的影响
本卷实例
  • 关键一步：由幅值为1解出截止频率再代入相角求γ
  • 中间结果：两种结构中γ与T的单调关系相反
  • 卡点：题面两个传函被OCR吞掉，需回原卷核对题面
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求截止频率并讨论参数T对相角裕度的影响
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 写出含参数T的幅频与相频表达式
本卷实例
  • 关键一步：把s=jω代入传函分别取幅值与相角
  • 中间结果：惯性环节相角为负而微分环节相角为正
  • 卡点：积分环节恒带负90度相角，勿漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过写出含参数T的幅频与相频表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

5滞后串联校正装置设计#

思路
  • 按K不小于5、γ不小于40度、ωc不小于0.5，设计滞后串联校正装置
滞后校正 系统校正
本卷考法
  • 设计串联滞后校正装置满足相角裕度与截止频率
本卷实例
  • 关键一步：由未校正相角裕度与补偿角定新的ωc
  • 中间结果：用滞后网络在低频段提供增益满足K要求
  • 卡点：滞后网络分子转折频率应低于分母，勿写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
