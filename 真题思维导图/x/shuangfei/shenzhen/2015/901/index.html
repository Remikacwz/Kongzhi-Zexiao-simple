1结构图求传函与扰动误差#

思路
  • 先由结构图画出信号流图，再用梅森公式分别求参考输入与扰动输入下的传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构框图画信号流图后求闭环传函
  • 用梅森公式求参考输入到输出的传函
本卷实例
  • 关键一步：先按比较点与引出点标出节点和各支路增益
  • 中间结果：多路传函共用同一特征多项式作分母
  • 卡点：引出点与比较点的合并规则需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构框图画信号流图后求闭环传函
  • 本卷考过用梅森公式求参考输入到输出的传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路找漏或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

思路

二阶系统标准形式与阻尼比 时域响应与动态性能
