思路
  • 由二阶微分方程写传递函数并化为标准形式，再由拉氏反变换求单位脉冲与单位阶跃响应
传递函数的定义与基本性质 传递函数
本卷考法

本卷实例

  • 中间结果：分母为特征多项式、分子为常数项

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）

  • 整理成 C(s)/R(s) 的降幂形式
