本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

本卷考法
  • 由校正后相角裕度判断稳定性优劣并折算噪声频率
本卷实例
  • 关键一步：比较三种网络校正后的相角裕度大小
  • 中间结果：把十二赫兹折算为角频率再比高频衰减
  • 卡点：频率折算与曲线读数需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由校正后相角裕度判断稳定性优劣并折算噪声频率
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过把剪切频率与相位穿越频率两个频率用反
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
