思路

由电路或机械系统求传递函数 传递函数
本卷考法
  • 由无源网络复阻抗求输出对输入的传递函数
本卷实例
  • 关键一步：对电感电容分别用复阻抗列分压关系
  • 中间结果：整体网络传函为二阶有理分式
  • 卡点：网络元件连接方式需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤

  • 按 KVL/KCL 或牛顿第二定律列出微分方程组

  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错

  • 复阻抗法把电容阻抗误写成 Cs

典型环节及其特性 传递函数
本卷考法
  • 识别RC与RL网络各自对应的一阶典型环节
本卷实例
  • 关键一步：把两网络分别化为时间常数形式的一阶环节
  • 中间结果：叠加后整体为二阶系统而非两个一阶相乘
  • 卡点：环节类型与时间常数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤

  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过识别RC与RL网络各自对应的一阶典型环节
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 本卷考过把一阶微分环节与惯性环节混为一谈
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减

2二阶系统性能指标反求传函与参数15 分#

思路
  • 由超调量与峰值时间反求阻尼比和自然频率，对照结构图写闭环传函并定参数，再求等速输入稳态误差
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间求阻尼比和自然频率
本卷实例
  • 关键一步：先由超调量解阻尼比再代峰值时间求自然频率
  • 中间结果：两个指标分别对应阻尼比与自然频率
  • 卡点：峰值时间单位与数值两源不一致，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与峰值时间求阻尼比和自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过超调量公式漏乘100%
  • 本卷考过峰值时间公式中漏乘根号项
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由响应曲线反求传递函数 传递函数
本卷考法

本卷实例
  • 关键一步：由结构图写开环再化闭环并与标准形式对比
  • 中间结果：闭环分母的s项与常数项对应两个待定参数
  • 卡点：结构图反馈支路含微分环节，需回原卷核对图

要点

  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤

通用考法
  • 本卷考过由结构图对照标准二阶形式写出闭环传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数

由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由已定阻尼比与自然频率反求结构图参数
本卷实例
  • 关键一步：令标准式系数与实际闭环系数对应相等
  • 中间结果：常数项对应增益、一次项对应微分时间常数

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差

  • 必要时按叠加原理分别计算各分量

  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过等速输入时误用位置误差系数
  • 未判稳就使用终值定理

本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

根轨迹的绘制法则 根轨迹法
本卷考法
  • 按起止点、实轴段与渐近线绘制根轨迹
本卷实例
  • 关键一步：先标三个开环极点再定实轴根轨迹段
  • 中间结果：根轨迹有三条分支且无有限零点
  • 卡点：根轨迹走向需自行作图并核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
