1信号流图、梅森公式与误差传递函数15 分#

思路
  • 由系统方框图（图1）画信号流图，用梅森公式求闭环传函，再按输入端定义写出误差传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 把方框图化为信号流图并用梅森公式求传函
本卷实例
  • 关键一步：先辨认回路与前向通路再列特征式
  • 中间结果：闭环传函等于前向通道增益和比特征式
  • 卡点：回路与前向通路接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过把方框图化为信号流图并用梅森公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路漏数导致特征式出错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

思路

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函对照二阶标准形式求自然频率与阻尼比关系
本卷实例
  • 关键一步：由结构图写出含积分环节的闭环传函
  • 中间结果：二阶标准形式对照后得自然频率与阻尼比表达式
  • 卡点：系统结构由原卷图2给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤

  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函对照二阶标准形式求自然频率与阻尼比关系
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过把开环增益误当闭环传函的系数
  • 化为标准形式时忘记把 s² 项系数归一化
