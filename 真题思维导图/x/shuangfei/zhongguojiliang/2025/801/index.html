1位置随动系统的工作原理与组成#

思路
  • 从给定输入与反馈量的比较出发，按信号流向说明偏差经放大后驱动执行元件带动被控对象，再由反馈元件把被控量送回比较；据此补全原理方框图，并逐项指认被控对象、反馈元件、执行元件、被控量与扰动量。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 分析位置随动系统的工作原理并指认各组成环节
本卷实例
  • 关键一步：按给定、比较、放大、执行、对象、检测的闭环顺序串起信号流
  • 中间结果：被控量是输出轴角位移，反馈元件把角位移转成电信号
  • 卡点：原卷结构图为插图，各环节位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过分析位置随动系统的工作原理并指认各组成环节
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

2结构图化简与误差传递函数#

思路
  • 由结构图改画信号流图，用梅森公式写出特征式、各前向通路及其余子式，再分别求 C(s)/R(s) 与按 E 等于 R 减 C 定义的 E(s)/R(s)
梅森增益公式与信号流图 传递函数
本卷考法
  • 由多回路结构图用梅森公式求闭环传递函数
本卷实例
  • 关键一步：数清独立回路与前向通路，再判断互不接触组合
  • 中间结果：特征式等于一减各回路增益之和加两两不接触回路增益积
  • 卡点：图题不读图，回路个数与前向通路增益需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项

3二阶系统阻尼比与扰动稳态误差#

思路
  • 由结构图写闭环特征方程并化成二阶标准形式，用阻尼比条件解出反馈系数；再把参考输入置零，由扰动到误差的传函按终值定理求扰动稳态误差，最后分别讨论两个可调参数对误差的影响。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由阻尼比要求反求结构图中的可调参数
本卷实例
  • 关键一步：先由结构图写闭环特征方程并化成二阶标准形式
  • 中间结果：阻尼比只由一次项系数与自然频率之比决定
  • 卡点：两参数同时出现在一次项与常数项，须联立求解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由阻尼比要求反求结构图中的可调参数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

减小稳态误差的措施 稳态误差
本卷考法
  • 分析可调参数对扰动稳态误差的影响
本卷实例
  • 关键一步：把扰动误差表达式对两个参数分别求极限或判单调性
  • 中间结果：提高前向增益可减小扰动误差，但会改变阻尼与稳定性
  • 卡点：只讲误差减小而不说明对阻尼或稳定性的影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过分析可调参数对扰动稳态误差的影响
  • 分析提高开环增益对误差与稳定性的双重影响

  • 说明为何单纯提高增益不可行
常见易错

4参数根轨迹与阻尼振荡条件#

思路
  • 把闭环特征式整理成以参变量为变量的等效开环形式，按根轨迹法则求分离点、渐近线与虚轴交点，再由共轭复根段定阻尼振荡对应的参数范围
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以参变量为变量列等效开环并绘制参数根轨迹
本卷实例
  • 关键一步：由闭环特征式分离出含参数项，写成等效开环形式
  • 中间结果：等效开环的分母是原特征式中不含参数的那部分
  • 卡点：等效开环的极点由原特征式系数定，不等同于原开环极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤

  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°

  • 整理时没有把参数完整地提到分子位置
