1第一题、冰箱温度控制系统#

思路
  • 由家用电冰箱控制系统示意画出原理方框图，再逐项指出控制任务、被控对象、被控量、给定输入、干扰输入与执行元件
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 画出家用电冰箱温度控制系统原理方框图
本卷实例
  • 关键一步：按给定、比较、控制器、执行器、对象、检测反馈逐个对号
  • 中间结果：方框图需含温度设定、检测变送与继电器控制回路
  • 卡点：系统示意图以图给出，环节位置须回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过画出家用电冰箱温度控制系统原理方框图
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 指出控制任务与被控对象、被控量、给定输入、干扰输入、执行元件
本卷实例
  • 关键一步：先定被控量箱温再沿控制链找操纵量与执行元件
  • 中间结果：给定输入为用户设定温度干扰为环境温度与开门等
  • 卡点：被控对象与被控量容易互换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过指出控制任务与被控对象、被控量、给定输入、干扰输入、执行元件
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半

2第二题、方框图求传函与减小扰动措施#

思路
  • 由方框图用梅森公式求 C 比 R 与 E 比 N，再从负反馈、增益调节与前馈三方面说明减小扰动对稳态性能影响的措施
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求 C(s) 比 R(s)
本卷实例
  • 关键一步：先数清两个回路并判断是否接触再写特征式
  • 中间结果：两条前向通道的余子式都为 1
  • 卡点：方框图以图给出，回路与前向通道须回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求 C(s) 比 R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动 N(s) 到误差的传递函数 E(s) 比 N(s)
本卷实例
  • 关键一步：令参考输入为零单独沿扰动到误差的前向通道求传函
  • 中间结果：误差传函的分母为系统特征式
  • 卡点：求扰动传函时没有把参考输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求扰动 N(s) 到误差的传递函数 E(s) 比 N(s)
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 说明减小扰动对稳态性能影响的措施
本卷实例
  • 关键一步：从负反馈抑制扰动、提高控制器增益与前馈补偿三方面作答
  • 中间结果：前馈可在扰动影响输出之前提前抵消
  • 卡点：只谈提高增益不检查稳定性是否被破坏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过说明减小扰动对稳态性能影响的措施
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

3第三题、二阶性能指标反求参数与稳定性影响#

思路
  • 由结构图写闭环传函化为二阶标准形式，由超调量与峰值时间反求增益与测速反馈系数，再用劳斯判据讨论反馈系数对稳定性的影响
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由结构图写含测速反馈的闭环传函并化为二阶标准形式
本卷实例
  • 关键一步：列含局部速度反馈的闭环传函再整理成标准二阶
  • 中间结果：自然频率平方等于开环增益而阻尼项由反馈系数决定
  • 卡点：化为标准形式时忘记把二次项系数归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由结构图写含测速反馈的闭环传函并化为二阶标准形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间反求增益与速度反馈系数
本卷实例
  • 关键一步：由超调量定阻尼比再由峰值时间定自然频率
  • 中间结果：两式联立解出增益与速度反馈系数的表达式
  • 卡点：只满足单项指标就下结论而未交叉验证
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量与峰值时间反求增益与速度反馈系数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
劳斯判据 稳定性分析
本卷考法
  • 讨论测速反馈系数取值对系统稳定性的影响
本卷实例
  • 关键一步：列劳斯表令首列各项都大于零
  • 中间结果：常数项恒正时稳定性由一次项系数的符号决定
  • 卡点：系数缺项时不补零直接套用判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过讨论测速反馈系数取值对系统稳定性的影响
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

4第四题、根轨迹绘制与衰减振荡范围#

思路
  • 按法则绘制三条分支根轨迹，求虚轴交点定稳定增益范围，由已知闭环极点回代求增益与其余极点，再由分离点定衰减振荡的增益范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制三个开环极点无零点系统的根轨迹
本卷实例
  • 关键一步：由开环零极点定分支数、实轴段与渐近线
  • 中间结果：三条分支都趋于无穷远渐近线夹角为正负六十度与一百八十度
  • 卡点：实轴段判据中零极点个数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制三个开环极点无零点系统的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及闭环稳定的增益范围
本卷实例
  • 关键一步：令特征式出现纯虚根同时定出交点频率与临界增益
  • 中间结果：稳定范围为原点与虚轴交点增益之间的区间
  • 卡点：只代一个频率求解会漏掉另一组交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及闭环稳定的增益范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由已知闭环极点求增益与其余极点并定衰减振荡范围
本卷实例
  • 关键一步：把已知极点回代特征方程求增益再由分离点幅值条件定下界
  • 中间结果：衰减振荡区间介于分离点处增益与虚轴交点处增益之间
  • 卡点：求出多个分离点后不筛选保留了不在轨迹上的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由已知闭环极点求增益与其余极点并定衰减振荡范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

5第五题、奈氏图与奈氏判据#

思路
  • 由开环结构图写频率特性画奈氏图，数开环右半平面极点与包围圈数后用奈氏判据判稳
