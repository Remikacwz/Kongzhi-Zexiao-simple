思路

梅森增益公式与信号流图 传递函数
本卷考法

  • 用梅森公式写出闭环传递函数
本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k

  • 本卷考过用梅森公式写出闭环传递函数

  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路漏数或重复计数
  • 本卷考过余子式未剔除与通路接触的回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路

2位置随动系统动态性能与增益调整15 分#

思路
  • 由位置随动系统结构图与给定K、T求闭环传函并归一，对照二阶标准形式求自然频率与阻尼比，再算超调量等指标，最后按指定阻尼比反求开环增益
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函对照标准形式求自然频率与阻尼比
本卷实例
  • 关键一步：先由结构图写闭环传函并归一化
  • 中间结果：分母与标准二阶多项式逐项对照
  • 卡点：系统结构由原卷图2给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函对照标准形式求自然频率与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过未把s平方项系数归一就套标准形式
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

  • 本卷考过把峰值时间与上升时间混用

3三阶系统稳定性与等幅振荡临界K15 分#

思路
  • 由开环传函写闭环特征方程并列劳斯表求稳定K范围，再令特征方程有纯虚根求等幅振荡的K值与振荡频率
劳斯判据 稳定性分析
本卷考法
  • 列劳斯表判断三阶系统稳定的K范围
本卷实例
  • 关键一步：由开环传函展开闭环特征多项式
  • 中间结果：劳斯表首列各元素须同号
  • 卡点：首列含参数K，不等式方向易写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过列劳斯表判断三阶系统稳定的K范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过系数有缺项时不补零就套判据
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由劳斯表首列不等式求稳定K区间与临界值
本卷实例
  • 关键一步：把首列元素大于零写成K的不等式组
  • 中间结果：各组不等式取交集得稳定区间
  • 卡点：等幅振荡点对应首列某元素恰为零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由劳斯表首列不等式求稳定K区间与临界值
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 本卷考过只列部分首列不等式导致约束不全
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

4根轨迹绘制与稳定范围、给定调节时间求K15 分#

思路
  • 按开环零极点画以K为参数的根轨迹，由与虚轴交点定稳定范围与临界K，再由调节时间在根轨迹上定复根与对应K
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按起点、终点、渐近线与实轴段绘根轨迹草图
本卷实例
  • 关键一步：先标开环零极点再定实轴上的根轨迹段
  • 中间结果：开环两个极点一个零点，分支数取极点数
  • 卡点：零点位置与实轴段需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按起点、终点、渐近线与实轴段绘根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹

  • 本卷考过渐近线夹角公式中的2k加1写成2k
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

频率特性的物理意义与求法 频域分析
本卷考法

本卷实例
