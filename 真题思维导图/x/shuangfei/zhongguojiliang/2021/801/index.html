1微分方程组建模与多输入传递函数15 分#

思路
  • 按各微分方程确定变量间关系画出结构框图，再用梅森公式分别求 Y(s)/R(s) 与 Y(s)/N(s)
传递函数的定义与基本性质 传递函数
本卷考法
  • 由微分方程组在零初始条件下写传递函数
本卷实例
  • 关键一步：对各方程取零初始拉氏变换后再消元
  • 中间结果：每个方程对应一个积分环节或比例环节
  • 卡点：题目未给初始条件，按零初始处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由微分方程组在零初始条件下写传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过设初始值为零是取拉氏变换的前提
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
