1结构图等效变换与梅森公式求传函15 分#

思路
  • 对图1多回路结构图先做等效变换合并，再画信号流图用梅森公式求闭环传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 先画信号流图再求闭环传递函数
  • 判断各回路与前向通路是否接触
本卷实例
  • 关键一步：先数清独立回路与前向通路再套梅森公式
  • 中间结果：三条回路均与前向通路接触，余子式为1
  • 卡点：回路与前向通路个数及接触关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过先画信号流图再求闭环传递函数
  • 本卷考过判断各回路与前向通路是否接触
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过余子式漏剔除与通路接触的回路
  • 本卷考过回路或前向通路漏数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二阶系统性能指标反求参数与减小超调措施15 分#

思路
  • 由最大超调量与调节时间两个指标联立求阻尼比与自然频率，再写开环传函并说明减小超调的办法
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与调节时间公式联立求阻尼比与自然频率
本卷实例
  • 关键一步：先由超调量解出阻尼比，再代调节时间式求自然频率
  • 中间结果：两式为关于阻尼比与自然频率的联立方程
  • 卡点：调节时间取5%误差带，系数须用对应值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与调节时间公式联立求阻尼比与自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过超调量公式漏乘100%
  • 本卷考过两种误差带的调节时间系数混用
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3单位负反馈系统稳定性与稳态误差15 分#

思路
  • 先写开环传函列劳斯表判断闭环稳定性，再用静态误差系数法求单位阶跃输入下的稳态误差
劳斯判据 稳定性分析
本卷考法
  • 列劳斯表判断三阶单位负反馈系统稳定性
本卷实例
  • 关键一步：由开环传函写闭环特征方程再列劳斯表
  • 中间结果：特征方程为三阶多项式，需检查系数是否齐全
  • 卡点：开环传函由原卷图2给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过列劳斯表判断三阶单位负反馈系统稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过系数缺项时不补零直接套判据
  • 本卷考过首列出现0仍按常规继续算
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

本卷考法

本卷实例

  • 中间结果：型别决定单位阶跃输入下误差是否为零

  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响

思路

本卷考法
