11、结构图求C(s)/R(s)与C(s)/N(s)#

思路
  • 两输入分别置零，用结构图等效化简或梅森增益公式分别求两路传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求两输入系统的传递函数
本卷实例
  • 关键一步：分别令N(s)与R(s)为零各求一路
  • 中间结果：两路传函分母同为闭环特征式
  • 卡点：回路互不接触判断易错，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求两输入系统的传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 扰动作用下的输出传递函数求解
本卷实例
  • 关键一步：求扰动传函时把参考输入置零
  • 中间结果：扰动通道与给定通道的前向通路不同
  • 卡点：把扰动误差与给定误差混在一起算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过扰动作用下的输出传递函数求解
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

22、二阶系统参数选择与正弦稳态输出#

思路
  • 由闭环传函对照标准二阶形式定参数τ，再算单位阶跃指标与正弦输入下的稳态输出。
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比要求求参数并计算超调量与峰值时间（第1问）
本卷实例
  • 关键一步：把闭环传函化成标准二阶形式再读ξ与ωn
  • 中间结果：超调量由ξ决定、峰值时间由ωn与ξ共同决定
  • 卡点：两种误差带的调节时间系数容易用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比要求求参数并计算超调量与峰值时间（第1问）
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征多项式比对标准二阶形式
本卷实例
  • 关键一步：把s一次项系数与ωn²分别对应
  • 中间结果：待定参数由阻尼比方程唯一确定
  • 卡点：化标准形式时忘记把s²项系数归一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征多项式比对标准二阶形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由闭环频率特性求正弦输入下的稳态输出（第2问）
本卷实例
  • 关键一步：把输入频率代入闭环幅频与相频
  • 中间结果：稳态输出为正弦，幅值比与相位差由闭环频率特性给出
  • 卡点：相频计算时忘记判断分母所在象限
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由闭环频率特性求正弦输入下的稳态输出（第2问）
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式

33、劳斯判据求稳定K与等幅振荡条件#

思路
  • 写闭环特征方程列劳斯表求稳定域，再令虚轴上有极点求等幅振荡的K与频率。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求使系统稳定的K范围（第1问）
本卷实例
  • 关键一步：按特征方程系数逐行构造劳斯表
  • 中间结果：首列符号变化次数等于右半面极点数
  • 卡点：特征方程缺项时未补零就开始列表
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求使系统稳定的K范围（第1问）
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求系统发生持续等幅振荡时的增益与角频率（第2问）
本卷实例
  • 关键一步：令特征方程出现一对纯虚根
  • 中间结果：振荡频率由特征方程实部虚部同时为零解出
  • 卡点：只求增益而漏求对应振荡角频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求系统发生持续等幅振荡时的增益与角频率（第2问）
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式

44、根轨迹绘制及开环零点移动的影响#

思路
  • 按法则画常规根轨迹，再讨论开环零点左移对闭环极点分布与动态性能的影响。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画出给定系统的根轨迹（第1问）
本卷实例
  • 关键一步：先判断实轴段与渐近线再画草图
  • 中间结果：根轨迹起于开环极点、止于开环零点或无穷远
  • 卡点：实轴段奇偶判据容易数错零极点个数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画出给定系统的根轨迹（第1问）
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 分析开环零点向无穷远移动对闭环性能的影响（第2问）
本卷实例
  • 关键一步：比较零点移动前后闭环极点的走向
  • 中间结果：零点左移通常使根轨迹左弯、稳定性与快速性改善
  • 卡点：附加零点与附加极点的作用容易说反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过分析开环零点向无穷远移动对闭环性能的影响（第2问）
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反

55、由对数幅频渐近线反求开环传函#

思路
  • 由低频段斜率定型别，由各转折频率定对应环节，再由某频率处幅值定增益。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由最小相位系统对数渐近幅频曲线写开环传函
本卷实例
  • 关键一步：按斜率变化逐段识别积分与一阶环节
  • 中间结果：传函由型别、增益和若干一阶环节串乘组成
  • 卡点：延长线交点高度需要折算型别才是增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由最小相位系统对数渐近幅频曲线写开环传函
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式

66、含纯延迟系统的奈氏图与稳定τ范围#

思路
  • 画K e的负τs次方比s的奈氏图，用奈氏判据求临界延迟并确定稳定τ范围。
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据判定含延迟系统稳定性（第2问）
本卷实例
  • 关键一步：先数开环右半面极点数P再数包围圈数
  • 中间结果：稳定条件由包围圈数与P的关系给出
  • 卡点：积分环节需要补画无穷大半径圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据判定含延迟系统稳定性（第2问）
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
含纯延迟环节的系统稳定性 稳定性分析
本卷考法
  • 求纯延迟环节下使闭环稳定的延迟范围
本卷实例
  • 关键一步：把延迟相位并入开环相频再套判据
  • 中间结果：临界延迟由相频等于负180度且幅值为1确定
  • 卡点：相位计算中角度与弧度换算容易出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 延迟环节 e^{-τs} 的幅值为 1、相位为 -τω，只恶化相位
  • 延迟会显著缩小稳定域，τ 越大越难稳定
