11、由结构图求C(s)/R(s)与C(s)/D(s)10 分#

思路
  • 两个输入分别置零，用结构图等效化简或梅森增益公式分别求出两路传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求两输入系统的两路传递函数
本卷实例
  • 关键一步：先求C(s)/R(s)，再把扰动输入置零求C(s)/D(s)
  • 中间结果：两路传函共用同一个特征式分母
  • 卡点：回路与不接触回路计数易漏，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求两输入系统的两路传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 多输入作用下分别求各输入的传递函数
本卷实例
  • 关键一步：求某一路传函时必须把另一路输入清零
  • 中间结果：输出等于参考分量与扰动分量之和
  • 卡点：两路输入同时保留则无法套单入单出公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过多输入作用下分别求各输入的传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

22、带测速反馈的伺服系统稳定范围15 分#

思路
  • 由结构图写闭环特征方程，列劳斯表，按首列不变号求K与Kh的稳定域。
参数稳定域的确定 稳定性分析
本卷考法
  • 求使系统稳定的增益与测速反馈系数取值范围
本卷实例
  • 关键一步：列劳斯表并令首列各元同号
  • 中间结果：稳定域由关于K与Kh的不等式组给出
  • 卡点：需分Kh大于、小于五分之一两种情形讨论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求使系统稳定的增益与测速反馈系数取值范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据分析含两个参数的稳定性
本卷实例
  • 关键一步：把闭环特征方程系数逐行排成劳斯表
  • 中间结果：首列不变号对应闭环极点全在左半面
  • 卡点：参数不等式端点是否取等号容易写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据分析含两个参数的稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

33、阶跃稳态误差与主导极点法求响应15 分#

思路
  • 由开环传函与已知闭环极点写闭环传函，先求稳态误差，再用主导极点降阶估算响应。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 单位反馈系统单位阶跃输入下的稳态误差（第1问）
本卷实例
  • 关键一步：先判稳再用终值定理求误差
  • 中间结果：误差由误差传递函数在原点附近的行为决定
  • 卡点：未先判稳就直接套终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过单位反馈系统单位阶跃输入下的稳态误差（第1问）
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 用主导极点把三阶系统降阶估算阶跃响应（第2问）
本卷实例
  • 关键一步：保留主导极点对并保持低频增益不变
  • 中间结果：降阶后的响应形式由一对共轭极点确定
  • 卡点：舍去非主导极点时容易丢掉原增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过用主导极点把三阶系统降阶估算阶跃响应（第2问）
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

44、绘制根轨迹并求渐近线与虚轴交点15 分#

思路
  • 由开环零极点按绘制法则画根轨迹，再求渐近线、分离点与虚轴交点。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则概略画出根轨迹草图
本卷实例
  • 关键一步：先定实轴根轨迹段与渐近线条数
  • 中间结果：根轨迹条数等于开环极点数
  • 卡点：渐近线夹角公式中的2k+1易写成2k
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则概略画出根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求给定分离点处的根轨迹特征
本卷实例
  • 关键一步：用分离点方程并检验解是否在根轨迹上
  • 中间结果：分离点对应特征方程出现重根的位置
  • 卡点：不在根轨迹上的实根不能当分离点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求给定分离点处的根轨迹特征
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界增益
本卷实例
  • 关键一步：令特征方程中s等于纯虚数jω
  • 中间结果：虚轴交点由实部与虚部同时为零确定
  • 卡点：只解虚部方程会漏掉实部约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

55、由对数幅频渐近线写传函并求相角裕度15 分#

思路
  • 由低频段斜率与各转折频率写出开环传函，再在剪切频率处求相角裕度。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环对数幅频特性图反求传递函数（第1问）
本卷实例
  • 关键一步：由低频斜率定积分环节数、由转折频率定时间常数
  • 中间结果：传函由型别、增益与各一阶环节串乘构成
  • 卡点：渐近线交点高度不是单纯的增益值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环对数幅频特性图反求传递函数（第1问）
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 求系统的相角裕度（第2问）
本卷实例
  • 关键一步：先求剪切频率再代入相频特性
  • 中间结果：相角裕度等于剪切频率处相位加180度
  • 卡点：剪切频率与穿越频率容易混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求系统的相角裕度（第2问）
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

66、绘制奈氏图并用判据判稳15 分#

思路
  • 写开环频率特性求起点终点与负实轴交点，用奈氏判据判断闭环稳定性与右半平面极点数。
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半面极点数再数包围圈数
  • 中间结果：包围圈数与P的关系决定闭环右半面极点数
  • 卡点：开环含积分环节时勿忘补画无穷大圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
