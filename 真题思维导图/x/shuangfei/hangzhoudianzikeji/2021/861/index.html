杭州电子科技大学 861 自动控制理论（含现控） 2021 年真题思维导图

强势双非共 11 题合计 150 分

难度：中等　卷面分选择、简答、计算三大题：选择 10 小题、简答 6 小题、计算 9 小题；覆盖基本概念、劳斯与奈氏判据、根轨迹、频域校正、采样系统数字控制器、描述函数法、能观性与状态反馈极点配置

1~10一、单项选择题十小题（每小题3分，共30分）30 分#

思路
  • 十道小题覆盖系统线性与时变判别、开环型别与阶数、二阶峰值时间、稳态误差、根轨迹渐近线交点、超前校正最大超前角、采样系统闭环脉冲传函、系统定常性判别、状态变量非奇异变换、线性变换不变特性，按基本概念逐项判断
系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环传递函数判断系统型别与阶数（第2小题）
本卷实例
  • 关键一步：看开环传函中积分环节个数定型别，看特征方程次数定阶数
  • 中间结果：型别由积分环节个数决定，阶数由特征多项式次数决定
  • 卡点：把开环增益大小误当成系统型别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由开环传递函数判断系统型别与阶数（第2小题）
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由二阶系统传函求单位阶跃响应峰值时间（第3小题）
本卷实例
  • 关键一步：把传函化为标准二阶形式后读自然频率与阻尼比
  • 中间结果：峰值时间等于阻尼频率乘以圆周率的倒数
  • 卡点：把峰值时间与上升时间公式混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由二阶系统传函求单位阶跃响应峰值时间（第3小题）
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由开环传函与组合输入求闭环稳态误差（第4小题）
本卷实例
  • 关键一步：分别按恒值分量与斜坡分量求稳态误差再相加
  • 中间结果：Ⅰ型系统对阶跃无差、对斜坡误差由速度误差系数决定
  • 卡点：组合输入时漏掉恒值分量贡献
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由开环传函与组合输入求闭环稳态误差（第4小题）
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

根轨迹的绘制法则 根轨迹法
本卷考法
  • 由开环传函求根轨迹渐近线与实轴交点（第5小题）
本卷实例
  • 关键一步：用极点之和减零点之和除以极零个数之差求交点
  • 中间结果：渐近线交点位于实轴上，条数由极零个数之差决定
  • 卡点：渐近线夹角公式中的二 k 加一写成二 k
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过由开环传函求根轨迹渐近线与实轴交点（第5小题）
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
超前校正 系统校正
本卷考法
  • 求超前校正装置的最大超前相角（第6小题）
本卷实例
  • 关键一步：按最大超前角与分度系数的反正弦关系求取
  • 中间结果：分度系数大于一时表达式为反正弦与反正切两种写法
  • 卡点：把反正弦与反正切两种表达式记混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过求超前校正装置的最大超前相角（第6小题）
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

脉冲传递函数 离散控制系统
本卷考法
  • 由采样系统结构图写闭环脉冲传递函数（第7小题）
本卷实例
  • 关键一步：按采样开关位置分别写前向与反馈通道脉冲传函
  • 中间结果：闭环脉冲传函由前向通道除以一加开环脉冲传函
  • 卡点：把无采样开关隔开的连续环节直接相乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过由采样系统结构图写闭环脉冲传递函数（第7小题）
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)

状态空间表达式的建立 状态空间分析
本卷考法
  • 由 RLC 电路状态变量求非奇异变换矩阵 P（第9小题，借位）
本卷实例
  • 关键一步：写出两组状态变量之间的坐标变换关系式
  • 中间结果：变换矩阵由新旧状态变量对应关系直接读出
  • 卡点：把变换矩阵与其逆矩阵用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由 RLC 电路状态变量求非奇异变换矩阵 P（第9小题，借位）
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

能控性与能观性 状态空间分析
本卷考法
  • 判断线性变换后特征值与能控能观性是否保持（第10小题）
本卷实例
  • 关键一步：看变换后系统矩阵与原矩阵是否相似
  • 中间结果：相似变换下特征值、能控性、能观性均不变
  • 卡点：误以为状态变换会改变系统能控性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断线性变换后特征值与能控能观性是否保持（第10小题）
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

1~6二、简答题六小题（每小题5分，共30分）30 分#

思路
  • 六道小题覆盖劳斯判据判稳与右半平面极点数、由脉冲响应求传函、惯性环节频率特性与奈氏图、校正装置伯德图、离散特征方程判稳、状态能控性矩阵，按定义计算
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断稳定性并求右半平面极点数目（第1小题）
本卷实例
  • 关键一步：列劳斯表并观察首列符号变化次数
  • 中间结果：首列符号变化次数等于右半平面根的个数
  • 卡点：系数缺项时不补零就列劳斯表
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断稳定性并求右半平面极点数目（第1小题）
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

传递函数的定义与基本性质 传递函数
本卷考法
  • 由单位脉冲响应求系统传递函数（第2小题）
本卷实例
  • 关键一步：对脉冲响应各项分别取拉氏变换再通分
  • 中间结果：脉冲响应的拉氏变换就是系统传递函数
  • 卡点：把脉冲响应与阶跃响应的关系用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由单位脉冲响应求系统传递函数（第2小题）
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 写惯性环节的幅频与相频表达式并绘奈奎斯特图（第3小题）
本卷实例
  • 关键一步：把频率特性分解为幅值与相角两个表达式
  • 中间结果：幅值随频率单调下降，相角由零趋于负九十度
  • 卡点：把惯性环节相角范围写成零到正九十度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过写惯性环节的幅频与相频表达式并绘奈奎斯特图（第3小题）
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
典型环节的对数频率特性 频域分析
本卷考法
  • 画校正装置的对数幅频特性（第4小题）
本卷实例
  • 关键一步：由分子分母时间常数定两个转折频率
  • 中间结果：幅频渐近线由低频水平段与负二十斜率段组成
  • 卡点：把转角频率处的斜率变化量记错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例环节是水平线，积分与微分分别是 -20 与 +20 dB/dec 的斜线
  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec
  • 一阶微分环节与惯性环节幅频互为镜像
  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤
  • 把传递函数分解为典型环节乘积
  • 逐环节画出对数幅频渐近线与相频曲线

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

本卷考法

  • 中间结果：两曲线不相交则系统稳定，相交则可能有自持振荡
