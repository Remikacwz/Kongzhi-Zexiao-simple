杭州电子科技大学 861 自动控制理论（含现控） 2016 年真题思维导图

强势双非共 11 题合计 150 分

难度：中等　11 个板块：判断题 10 小题、单项选择题 10 小题，第三至十一大题共 9 道计算题；覆盖一阶系统时间常数、二阶动态性能指标、劳斯判据、根轨迹、奈氏判据、由 Bode 图反求传函、描述函数法、状态响应与能控能观判别，含离散采样与非线性内容。

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

1~10一、判断题十小题（每小题1分，共10分）10 分#

思路
  • 十句辨析覆盖控制量与被控对象的区分、传递函数定义、过阻尼系统特性、ωn 变化对动态指标的影响、根轨迹起止点、相对稳定性判据、相角裕度与超调量的对应、滞后校正作用、保持器作用与采样过程的物理本质。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断水箱液位系统中控制量是液位高度还是进水量（第1小题）
本卷实例
  • 关键一步：按被控量、控制量与扰动量的定义逐一对应
  • 中间结果：被控量是液位高度，控制量是进水量
  • 卡点：把被控量与控制量当成同一个物理量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断水箱液位系统中控制量是液位高度还是进水量（第1小题）
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
传递函数的定义与基本性质 传递函数
本卷考法
  • 判断传递函数定义是否漏掉零状态前提（第2小题）
本卷实例
  • 关键一步：回到传递函数定义的零状态前提核对说法
  • 中间结果：传递函数是零状态条件下输出与输入的拉氏比
  • 卡点：把零状态前提漏掉仍判为正确
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过判断传递函数定义是否漏掉零状态前提（第2小题）
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 判断过阻尼系统是否存在振荡及是否应避免（第3小题）
本卷实例
  • 关键一步：由阻尼比大于一判断二阶系统根的分布
  • 中间结果：过阻尼时两实根对应单调响应且无振荡
  • 卡点：把过阻尼与欠阻尼的响应特征互换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过判断过阻尼系统是否存在振荡及是否应避免（第3小题）
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 判断减小自然频率后上升时间与峰值时间是否增大（第4小题）
本卷实例
  • 关键一步：由两个时间指标与自然频率的反比关系判断变化方向
  • 中间结果：阻尼比不变时两时间指标随自然频率减小而增大
  • 卡点：把阻尼比与自然频率对指标的作用混记
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过判断减小自然频率后上升时间与峰值时间是否增大（第4小题）
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 判断根轨迹是否起于开环极点终于开环零点（第5小题）
本卷实例
  • 关键一步：由幅值条件在增益趋于无穷时的极限判断终点
  • 中间结果：根轨迹起于开环极点，终于开环零点或无穷远
  • 卡点：漏掉零点不足时要延伸到无穷远的情形
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过判断根轨迹是否起于开环极点终于开环零点（第5小题）
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

稳定裕度 频域分析
本卷考法
  • 判断相对稳定性应由开环还是闭环幅相特性衡量（第6小题）
本卷实例
  • 关键一步：按奈氏判据所用曲线判断该说法
  • 中间结果：相对稳定性由开环幅相特性靠近临界点的程度衡量
  • 卡点：把开环与闭环幅相特性的作用颠倒
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过判断相对稳定性应由开环还是闭环幅相特性衡量（第6小题）
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
闭环频率特性与性能指标 频域分析
本卷考法
  • 判断相角裕度对应时域的超调量还是稳态误差（第7小题）
本卷实例
  • 关键一步：按频域与时域性能指标的对应关系判断
  • 中间结果：相角裕度主要对应超调量而非稳态误差
  • 卡点：把相角裕度与稳态误差错误对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过判断相角裕度对应时域的超调量还是稳态误差（第7小题）
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

滞后校正 系统校正
本卷考法
  • 判断滞后校正是否靠高频衰减减小剪切频率（第8小题）
本卷实例
  • 关键一步：由滞后校正高频段幅值衰减判断剪切频率走向
  • 中间结果：滞后校正降低剪切频率并提高稳定裕度
  • 卡点：把滞后校正的幅频作用方向记反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过判断滞后校正是否靠高频衰减减小剪切频率（第8小题）
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

采样过程与香农采样定理 离散控制系统
本卷考法
  • 判断采样系统是否需要在被控对象前引入保持器（第9小题）
本卷实例
  • 关键一步：从被控对象只能接受连续信号判断保持器必要性
  • 中间结果：保持器把离散信号复原为连续信号再送入对象
  • 卡点：认为离散信号可直接作用于连续被控对象
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过判断采样系统是否需要在被控对象前引入保持器（第9小题）
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后
公式
信号采样与频谱的基本概念 基本概念与信号
本卷考法
  • 判断采样过程是否可理解为脉冲调制过程（第10小题）
本卷实例
  • 关键一步：把采样看成周期脉冲序列对连续信号的作用
  • 中间结果：采样过程等价于连续信号与脉冲序列相乘
  • 卡点：把采样与量化两个概念混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 周期信号可展开为傅里叶级数，各次谐波的幅值构成频谱
  • 冲激采样信号的频谱是原信号频谱的周期延拓
  • 频谱延拓的周期由采样频率决定，不重叠才能由理想低通恢复原信号
  • 恢复用的理想低通截止频率取在采样频率的一半处
步骤
  • 先求连续信号的频谱或按给定波形求谐波幅值
  • 按采样频率写出延拓后频谱的周期与各次副本的位置
  • 检查最高频率是否小于采样频率的一半，判断能否无失真恢复
  • 需要恢复时选取截止频率与增益合适的理想低通滤波器
通用考法
  • 本卷考过判断采样过程是否可理解为脉冲调制过程（第10小题）
  • 由采样频率判断给定信号能否无失真恢复
  • 写出冲激采样后信号的频谱表达式
  • 确定恢复滤波器的截止频率
常见易错
  • 把采样定理里的两倍关系记成相等，或漏掉两倍
  • 把最高频率与频谱延拓的周期混为一谈

1~10二、单项选择题十小题（每题2分，共20分）20 分#

思路
  • 十道选择覆盖一阶系统时间常数、一阶系统斜坡稳态误差、二阶阻尼比、劳斯判据、组合输入稳态误差、开环增益对稳定裕度的影响、最大相位迟后角、描述函数法适用条件、典型信号 Z 变换、状态响应求解。
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由一阶惯性环节达到稳态值98%所用时间求时间常数（第1小题）
本卷实例
  • 关键一步：把百分之九十八对应到二百分点误差带的调节时间
  • 中间结果：二百分点误差带下调节时间约为时间常数的四倍
  • 卡点：把百分之六十三点二对应的时间当成调节时间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由一阶惯性环节达到稳态值98%所用时间求时间常数（第1小题）
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
