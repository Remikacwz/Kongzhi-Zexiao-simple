11、无源网络建模求传递函数#

思路
  • 按串联电路电流相同与分压关系列方程，在s域整理成输出电压与输入电压之比。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由R、C无源网络求输入输出传递函数
本卷实例
  • 关键一步：用串联分压关系写出输出端与总电压之比
  • 中间结果：传函为一阶形式，分子分母各含一个时间常数
  • 卡点：电容复阻抗容易误写成Cs
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由R、C无源网络求输入输出传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 用复阻抗法建立电路网络模型
本卷实例
  • 关键一步：在s域把各元件写成复阻抗后列回路关系
  • 中间结果：输出电压等于串联支路分压
  • 卡点：元件连接只以图给出，需回原卷核对图

  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过用复阻抗法建立电路网络模型

22、系统结构图求传递函数#

思路
  • 用梅森增益公式或结构图等效化简求闭环传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由多回路结构图求闭环传递函数
本卷实例
  • 关键一步：先找全部单独回路再写特征式
  • 中间结果：特征式等于一减各回路增益加不接触回路增益积
  • 卡点：多回路结构图的回路辨识需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由多回路结构图求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 用等效化简法求闭环传递函数
本卷实例
  • 关键一步：按串并联与反馈关系逐层合并
  • 中间结果：负反馈闭环分母为1加开环乘积
  • 卡点：反馈极性判断错误会使分母符号反号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过用等效化简法求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

33、测速反馈参数选择与扰动稳态误差#

思路
  • 由结构图写闭环传函并对照二阶标准形式求反馈系数，再写扰动误差传函求稳态误差。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由阻尼比要求确定测速反馈系数（第1问）
本卷实例
  • 关键一步：把闭环传函化成标准二阶形式再对应系数
  • 中间结果：反馈系数由阻尼比与自然频率的关系解出
  • 卡点：结构图只以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由阻尼比要求确定测速反馈系数（第1问）
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动信号引起的稳态误差（第2问）
本卷实例
  • 关键一步：把参考输入置零后写扰动误差传函
  • 中间结果：扰动误差由误差传函与扰动拉氏变换的乘积决定
  • 卡点：把扰动误差与给定误差混在一起求
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求扰动信号引起的稳态误差（第2问）
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 分析反馈系数对扰动误差的影响（第3问）
本卷实例
  • 关键一步：观察误差传函中参数出现的位置
  • 中间结果：扰动误差是否可消除由扰动信号阶次与误差传函零点共同决定
  • 卡点：只调整增益而不检查误差传函结构
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过分析反馈系数对扰动误差的影响（第3问）
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

44、闭环极点全部位于s=-1左侧的K范围#

思路
  • 作变量代换把相对稳定度条件化为原点稳定问题，再对代换后的特征方程用劳斯判据。
参数稳定域的确定 稳定性分析
本卷考法
  • 求使闭环极点全部位于指定竖线左侧的参数范围
本卷实例
  • 关键一步：令s等于z减1把竖线条件平移到虚轴
  • 中间结果：参数范围由平移后特征方程的劳斯表首列决定
  • 卡点：代换后忘记把常数项重新整理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求使闭环极点全部位于指定竖线左侧的参数范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
劳斯判据 稳定性分析
本卷考法
  • 对平移后的特征方程使用劳斯判据
本卷实例
  • 关键一步：按z的特征方程系数逐行列劳斯表
  • 中间结果：首列全正等价于全部特征根位于s等于负1左侧
  • 卡点：端点是否可取的判断容易漏掉
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过对平移后的特征方程使用劳斯判据
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

55、根轨迹绘制与特征点求解#

思路
  • 按法则画常规根轨迹，再求实轴段、渐近线、分离点与虚轴交点。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画出闭环根轨迹
本卷实例
  • 关键一步：先由根轨迹条数与渐近线定大致走向
  • 中间结果：三条根轨迹起始于三个开环极点
  • 卡点：渐近线交点计算时极点与零点求和要分清
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画出闭环根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点坐标
本卷实例
  • 关键一步：用分离点方程求出根后逐一筛选
  • 中间结果：只有落在实轴根轨迹段上的根才是分离点
  • 卡点：舍弃解的理由必须写清否则容易误判
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点坐标
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴的交点
本卷实例
  • 关键一步：令特征方程中s等于jω并拆实虚部
  • 中间结果：交点的频率与临界增益由两个方程联立确定
  • 卡点：求交点时容易只保留频率解而漏掉增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴的交点
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

66、由对数渐近幅频曲线反求传函#

思路
  • 由低频段斜率确定型别，由各转折频率确定对应环节，再由某点幅值确定增益。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由最小相位系统开环对数渐近幅频曲线写传递函数
本卷实例
  • 关键一步：按各段斜率变化识别积分与一阶微分、惯性环节
