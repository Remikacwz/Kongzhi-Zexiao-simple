反馈校正与复合控制 系统校正
本卷考法
  • 判断按输入前馈与按扰动前馈是否为复合控制的基本形式（第1小题）
本卷实例
  • 关键一步：按复合控制定义区分前馈通道与反馈通道各自的作用
  • 中间结果：复合控制由前馈补偿与反馈控制两部分组合而成
  • 卡点：把前馈复合控制误当成纯反馈控制
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过判断按输入前馈与按扰动前馈是否为复合控制的基本形式（第1小题）
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

传递函数的定义与基本性质 传递函数
本卷考法
  • 判断传递函数的拉氏反变换是否为单位脉冲响应（第2小题）
本卷实例
  • 关键一步：联系传递函数的零初始条件定义来辨析该说法
  • 中间结果：零初始条件下传递函数等于脉冲响应的拉氏变换
  • 卡点：忽略零初始条件这一前提直接判对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过判断传递函数的拉氏反变换是否为单位脉冲响应（第2小题）
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 判断闭环极点离虚轴越远是否快速性越好（第3小题）
本卷实例
  • 关键一步：由调节时间与极点实部的关系判断快速性
  • 中间结果：极点实部越负则衰减越快、调节时间越短
  • 卡点：只比较虚部而忽略实部对衰减速度的决定作用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过判断闭环极点离虚轴越远是否快速性越好（第3小题）
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

稳定裕度 频域分析
本卷考法
  • 判断仅凭开环幅频特性能否判定稳定性（第4小题）
本卷实例
  • 关键一步：稳定判据需同时用到幅频与相频两条曲线
  • 中间结果：幅值裕度与相角裕度共同刻画相对稳定性
  • 卡点：把幅频特性单独当成判稳的充分条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过判断仅凭开环幅频特性能否判定稳定性（第4小题）
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

超前校正 系统校正
本卷考法
  • 判断超前校正是否使剪切频率减小（第5小题）
本卷实例
  • 关键一步：由超前校正抬高高频段幅值来推断剪切频率走向
  • 中间结果：超前校正提高剪切频率并加大稳定裕度
  • 卡点：把超前与滞后校正对剪切频率的影响用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过判断超前校正是否使剪切频率减小（第5小题）
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

PID 控制器与参数整定 系统校正
本卷考法
  • 判断 PI 控制器积分环节能否改善动态性能（第6小题）
本卷实例
  • 关键一步：由 PI 传函中积分项的相位滞后分析其作用
  • 中间结果：积分作用消除稳态误差但降低动态快速性
  • 卡点：把积分作用对稳态与动态的影响混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过判断 PI 控制器积分环节能否改善动态性能（第6小题）
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

离散系统稳定性分析 离散控制系统
本卷考法
  • 判断离散系统稳定极点是否位于 Z 平面左半平面（第7小题）
本卷实例

  • 中间结果：稳定域为 Z 平面单位圆内部而非左半平面
  • 卡点：把连续系统的左半平面条件照搬到 Z 平面
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过判断离散系统稳定极点是否位于 Z 平面左半平面（第7小题）
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

描述函数法基础 非线性系统
本卷考法
  • 判断相平面法与描述函数法各自适用的系统阶次（第8小题）
本卷实例
  • 关键一步：按两种方法对系统阶次与非线性类型的要求区分
  • 中间结果：相平面法限于一、二阶，描述函数法适用面更宽
  • 卡点：把两种非线性分析方法的适用范围互换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振

  • 本卷考过判断相平面法与描述函数法各自适用的系统阶次（第8小题）

  • 指出描述函数与频率特性的区别

  • 忽略一次谐波近似带来的误差条件

状态空间与传递函数的关系 状态空间分析
本卷考法
  • 判断传递函数矩阵是否与状态变量选择无关（第9小题）
本卷实例
  • 关键一步：看状态变量的非奇异变换是否改变传递函数矩阵
  • 中间结果：传递函数矩阵在相似变换下保持不变
  • 卡点：误以为换一组状态变量就换一个传递函数矩阵
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过判断传递函数矩阵是否与状态变量选择无关（第9小题）
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消
