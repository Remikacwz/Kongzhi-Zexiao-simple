二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由二阶系统传递函数判断其阻尼状态（第1小题）
本卷实例
  • 关键一步：把传递函数分母与标准二阶特征式逐项对照
  • 中间结果：由一次项与常数项读出阻尼比与自然频率
  • 卡点：阻尼状态由阻尼比与一的大小关系决定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由二阶系统传递函数判断其阻尼状态（第1小题）
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

滞后校正 系统校正
本卷考法
  • 由校正装置传递函数判断其校正类型（第2小题）
本卷实例
  • 关键一步：比较分子分母两个时间常数的大小定超前或滞后
  • 中间结果：分子时间常数小于分母时间常数时为滞后校正
  • 卡点：容易把滞后校正误判为超前校正
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过由校正装置传递函数判断其校正类型（第2小题）
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

劳斯判据 稳定性分析
本卷考法
  • 由特征方程求临界稳定增益并判别不稳定系统（第3、10小题）
本卷实例
  • 关键一步：列劳斯表并令首列出现全零行或首个元素为零
  • 中间结果：全零行对应一对纯虚根，即临界稳定
  • 卡点：判别不稳定要同时看极点位置、特征方程与响应是否收敛
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由特征方程求临界稳定增益并判别不稳定系统（第3、10小题）
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅相曲线判断稳定性并辨析奈氏判据辅助函数（第4、6小题）
本卷实例
  • 关键一步：先数开环右半平面极点数，再看曲线对临界点的包围
  • 中间结果：辅助函数的零点为闭环极点、极点为开环极点
  • 卡点：曲线以图给出，包围次数与方向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环幅相曲线判断稳定性并辨析奈氏判据辅助函数（第4、6小题）
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 由开环传递函数求系统开环增益（第5小题）
本卷实例
  • 关键一步：把各环节都化成尾一形式后再取比例系数
  • 中间结果：尾一形式的比例系数就是开环增益
  • 卡点：根轨迹增益与开环增益不同，换算要用各环节时间常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过由开环传递函数求系统开环增益（第5小题）
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

PID 控制器与参数整定 系统校正
本卷考法
  • 判断比例积分控制器各组成部分的作用（第7小题）
本卷实例
  • 关键一步：分别分析比例项与积分项对稳定与稳态的作用
  • 中间结果：积分项提高系统型别、减小或消除稳态误差
  • 卡点：积分项改善稳态但可能降低动态性能与稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过判断比例积分控制器各组成部分的作用（第7小题）
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

根轨迹的绘制法则 根轨迹法
本卷考法
  • 判断实轴上属于根轨迹的区段（第8小题）
本卷实例
  • 关键一步：按右侧实数零极点总数为奇数判断实轴段
  • 中间结果：三个开环极点分别为零、负一、负二
  • 卡点：实轴段端点是否包含由奇偶判据确定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过判断实轴上属于根轨迹的区段（第8小题）
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

附加开环零极点的影响 根轨迹法
本卷考法
  • 判断对提高系统稳定性没有效果的措施（第9小题）
本卷实例
  • 关键一步：分别分析增加开环极点与零点对根轨迹走向的影响
  • 中间结果：增加开环极点使根轨迹右移、稳定性变差
  • 卡点：增加开环零点或引入超前校正都能改善稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过判断对提高系统稳定性没有效果的措施（第9小题）
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反

传递函数的定义与基本性质 传递函数
本卷考法
  • 由零初始条件下的脉冲响应求系统传递函数（第1小题）
本卷实例
  • 关键一步：对脉冲响应的各项分别取拉氏变换
  • 中间结果：把各项变换结果通分写成有理分式
  • 卡点：脉冲响应的拉氏变换就是系统传递函数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由零初始条件下的脉冲响应求系统传递函数（第1小题）
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

超前校正 系统校正
本卷考法
  • 求超前校正装置的最大超前角频率并说明其作用（第4、9小题）
本卷实例
  • 关键一步：最大超前角出现在两个转折频率的几何中点
  • 中间结果：由两个转折频率开方求出最大超前角对应频率
  • 卡点：超前校正主要改善稳定性，同时提高快速性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过求超前校正装置的最大超前角频率并说明其作用（第4、9小题）
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错

三11三、计算题第11题：状态反馈改变能观性10 分#

思路
  • 设状态反馈阵为待定行向量，写出加入状态反馈后的系统矩阵与输出矩阵，计算能观性矩阵；令其行列式为零，得到使系统能观性发生改变的反馈阵条件。
能控性与能观性 状态空间分析
本卷考法
  • 分析状态反馈对系统能观性的影响
本卷实例
  • 关键一步：写出加入状态反馈后的系统矩阵，再算能观性矩阵
  • 中间结果：能观性矩阵行列式为零时能观性改变
  • 卡点：状态反馈改变系统矩阵但不改变输出矩阵，能观性可能变化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过分析状态反馈对系统能观性的影响
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
