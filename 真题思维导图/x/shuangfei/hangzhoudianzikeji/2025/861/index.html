杭州电子科技大学 861 自动控制理论（含现控） 2025 年真题思维导图

强势双非共 10 题

难度：中等　全卷 10 题、满分 150 分，卷面未逐题标分值。第 1 题信号流图求传函，第 2 题等幅振荡求参数，第 3 题根轨迹绘制与圆形证明，第 4 题由幅频图求校正装置并用劳斯判据与稳态误差定参数范围，第 5 题超前校正类型判别与相角裕度，第 6 题离散系统稳定性与稳态误差，第 7 题描述函数法自激振荡，第 8 题由状态响应反求系统矩阵，第 9 题全维观测器与状态响应，第 10 题李雅普诺夫判稳。含图题较多。

1一、求系统传递函数（信号流图）#

思路
  • 由题给系统信号流图，标出全部独立回路与前向通路，用梅森增益公式写特征式并求总传输。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图用梅森公式求 C(s)/R(s)
本卷实例
  • 关键一步：按信号流图标出全部独立回路与前向通路，写出特征式 Δ
  • 中间结果：各回路两两接触，特征式只保留一阶回路项
  • 中间结果：总传输等于前向通路增益与特征式之比
  • 卡点：信号流图未读图，回路编号与支路增益须回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图用梅森公式求 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、等幅振荡求参数#

思路
  • 由题给系统结构写闭环特征方程，把 s=jω 代入并分离实部与虚部，令两式为零联立求持续振荡时的参数。
参数稳定域的确定 稳定性分析
本卷考法
  • 由 s=jω 代入特征方程求持续振荡参数
本卷实例
  • 关键一步：把给定频率下的等幅振荡看成虚轴上有一对闭环极点，代入 s=jω
  • 中间结果：特征方程分离实部与虚部后得到两个含参数的方程
  • 卡点：题图给出的对象与反馈结构须回原卷核对，卷面只印振荡频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由 s=jω 代入特征方程求持续振荡参数
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

3三、根轨迹绘制与圆形证明#

思路
  • 按绘制法则画开环增益从零到无穷的根轨迹并求分离点，再令 s=x+yj 代入特征方程消去参数证明轨迹是圆。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则画出由开环零极点确定的根轨迹草图
本卷实例
  • 关键一步：标出开环极点与零点后先判实轴上的根轨迹段
  • 中间结果：实轴段由右侧零极点总数的奇偶判定，渐近线条数等于极点数减零点数
  • 卡点：实轴段判据要逐段数右侧零极点总数，易把两段都算反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则画出由开环零极点确定的根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 用分离点方程求根轨迹与实轴的交点
本卷实例
  • 关键一步：由幅值条件把开环增益写成关于 s 的显式表达式，再令其对 s 的导数为零
  • 中间结果：分离点方程化为一元二次方程，两根一取一舍
  • 卡点：两根中只有落在实轴根轨迹段上的才保留
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过用分离点方程求根轨迹与实轴的交点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 由幅相条件说明根轨迹的几何形状
本卷实例
  • 关键一步：把 s=x+yj 代入闭环特征方程并分离实部与虚部
  • 中间结果：消去可变参数后得到圆的方程，圆心落在负实轴上
  • 卡点：证明的是圆，但真正属于根轨迹的只是满足相角条件的弧段
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过由幅相条件说明根轨迹的几何形状
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式

4四、由幅频图求校正装置与参数范围#

思路
  • 先由幅频图低频斜率与转折频率还原校正装置传函，再对校正后系统用劳斯判据求稳定域，最后按组合输入稳态误差要求反解参数并取交集。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由给定幅频图写出校正装置传递函数
本卷实例
  • 关键一步：读低频段斜率与高度确定型别和增益，再按转折频率确定环节
  • 中间结果：低频段水平，两个转折频率处斜率各变化一次
  • 卡点：幅频图未读图，转折频率与高频段高度须回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由给定幅频图写出校正装置传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
劳斯判据 稳定性分析
本卷考法
  • 由劳斯判据确定使闭环稳定的参数范围
本卷实例
  • 关键一步：写出校正后开环对应的闭环特征方程并按降幂排列
  • 中间结果：劳斯表首列各元素给出关于开环增益的不等式组
  • 卡点：首列含参元素作分母时要讨论其正负
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由劳斯判据确定使闭环稳定的参数范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环传函求静态速度与加速度误差系数
本卷实例
  • 关键一步：先数开环传函中积分环节个数确定系统型别
  • 中间结果：速度误差系数为无穷，加速度误差系数与开环增益同阶
  • 卡点：型别判错会把组合输入各项的误差公式用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由开环传函求静态速度与加速度误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡与加速度组合输入下的稳态误差
本卷实例
  • 关键一步：按叠加原理把组合输入拆成斜坡与加速度两项分别求误差
  • 中间结果：组合误差化简为加速度项系数与开环增益之比
  • 卡点：列误差要求前要先确认系统在所得参数范围内稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求斜坡与加速度组合输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

5五、校正类型判别与相角裕度#

思路
  • 由校正装置传函判断超前或滞后，画校正前后与装置的幅频图，分别求相角裕度，再从稳定性、准确性与动态性能说明校正作用。
超前校正 系统校正
本卷考法
  • 由校正装置传函判断是否为超前校正
本卷实例
  • 关键一步：把校正装置写成零点时间常数与极点时间常数的标准形式
  • 中间结果：零点转折频率高于极点转折频率，说明相位超前
  • 卡点：时间常数大小要与零极点位置对应，不能只看分子分母次数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过由校正装置传函判断是否为超前校正
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 画校正前后开环与校正装置的幅频图
本卷实例
  • 关键一步：把各传函写成典型环节乘积，从低频段开始逐段叠加斜率
  • 中间结果：校正后低频段高度不变，转折频率按新增环节增减
  • 卡点：校正装置图与校正前后图要分开画，不能混成一条曲线
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过画校正前后开环与校正装置的幅频图
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
稳定裕度 频域分析
本卷考法
  • 求校正前后的相角裕度
本卷实例
