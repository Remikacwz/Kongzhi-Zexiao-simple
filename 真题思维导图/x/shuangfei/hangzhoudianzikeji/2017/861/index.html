一一、画信号流图并用梅森公式求传递函数15 分#

思路
  • 由结构图先画信号流图，数出全部单独回路与两两不接触回路写特征式，再找前向通路及其余子式，代入梅森公式求传函。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用信号流图与梅森增益公式求系统传递函数（第1、2问）
本卷实例
  • 关键一步：先数清全部回路与两两不接触回路写特征式
  • 中间结果：特征式等于一减各回路增益加不接触回路增益积
  • 卡点：系统结构图只以图给出，回路与前向通路需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用信号流图与梅森增益公式求系统传递函数（第1、2问）
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由系统结构图改画信号流图（第1问）
本卷实例
  • 关键一步：把比较点与引出点分别映射为节点与支路
  • 中间结果：结构图的每个环节对应信号流图的一条有向支路
  • 卡点：把比较点与引出点的节点含义画反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由系统结构图改画信号流图（第1问）
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

二二、由差分输入放大器电路求传递函数10 分#

思路
  • 按理想运放虚短虚断列出输入节点与反馈回路的电流关系，整理成输出电压与差模输入电压之比。
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由运算放大器电路列方程求传递函数
本卷实例
  • 关键一步：用虚短虚断写出各输入支路的电流平衡式
  • 中间结果：输出电压由两路输入按电阻比叠加得到
  • 卡点：电路图只以图给出，电阻接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由运算放大器电路列方程求传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 求有源网络的输入输出传递函数
本卷实例
  • 关键一步：把各元件写成复阻抗后代入手推关系
  • 中间结果：差模输入下传函由反馈阻抗与输入阻抗之比决定
  • 卡点：把差模与共模输入的传函混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过求有源网络的输入输出传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

三三、由系统结构图求动态性能并反求参数10 分#

思路
  • 由结构图写闭环传函化为标准二阶形式，先按给定参数算超调量与调节时间，再按阻尼比与速度误差要求反求两个参数。
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由已定参数计算超调量与调节时间（第1问）
本卷实例
  • 关键一步：化标准二阶形式后读阻尼比与自然频率
  • 中间结果：超调量由阻尼比决定，调节时间由阻尼比与自然频率共同决定
  • 卡点：把调节时间两种误差带的系数写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由已定参数计算超调量与调节时间（第1问）
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由阻尼比与速度误差要求反求系统参数（第2问）
本卷实例
  • 关键一步：由稳态误差条件补充另一个关于参数的方程
  • 中间结果：两个待求参数由阻尼比与误差两条件联立确定
  • 卡点：只用一个指标就下结论导致参数不定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由阻尼比与速度误差要求反求系统参数（第2问）
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式

四四、确定系统稳定时的 K 值范围10 分#

思路
  • 写闭环特征方程，列劳斯表，令首列元素同号并联立参数不等式求稳定区间。
参数稳定域的确定 稳定性分析
本卷考法
  • 求使系统稳定的参数取值范围
本卷实例
  • 关键一步：令劳斯表首列各元素大于零并联立求解
  • 中间结果：稳定域由各不等式取交集给出
  • 卡点：遗漏首列某个元素带来的约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求使系统稳定的参数取值范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据分析含参数系统稳定性
本卷实例
  • 关键一步：由特征方程系数逐行构造劳斯表
  • 中间结果：首列符号变化次数等于右半平面极点数
  • 卡点：特征方程缺项时未补零直接列表
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据分析含参数系统稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式

五五、由开环零极点分布概略绘制根轨迹9 分#

思路
  • 按绘制法则由零极点分布确定根轨迹条数、渐近线与实轴段，概略画出两支根轨迹图。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 由零极点分布概略绘制根轨迹
本卷实例
  • 关键一步：按极点数与零点数定渐近线条数与夹角
  • 中间结果：实轴上零极点右侧个数为奇数的区段是根轨迹
  • 卡点：零极点分布只以图给出，坐标需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过由零极点分布概略绘制根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式

六六、以 a 为可变参数的根轨迹及特征点10 分#

思路
  • 把特征方程整理成参数根轨迹标准形式，按法则求分离点、渐近线与虚轴交点。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 绘制以 a 为可变参数的根轨迹
本卷实例
  • 关键一步：把特征方程整理成参数根轨迹标准乘积形式
  • 中间结果：等效开环传函的极零点即根轨迹起点与终点
  • 卡点：未把参数提成乘积形式就套常规根轨迹法则
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过绘制以 a 为可变参数的根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点
本卷实例
  • 关键一步：用分离点方程求实轴上的重根位置
  • 中间结果：分离点由特征多项式对参数求导后联立方程确定
  • 卡点：把不在根轨迹上的实根也当成分离点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴的交点
本卷实例
  • 关键一步：令特征方程中 s 等于纯虚数求交点频率
  • 中间结果：虚轴交点由实部与虚部同时为零的条件确定
  • 卡点：只解虚部方程而漏掉实部约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解

步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴的交点
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

七七、绘制奈氏图并据图判断系统稳定性15 分#

思路

本卷考法

本卷实例
  • 关键一步：先数开环右半平面极点数再判包围圈数
  • 中间结果：稳定判据为包围圈数等于右半平面极点数

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负

  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）

  • 由 Z=N+P 判断闭环稳定性
