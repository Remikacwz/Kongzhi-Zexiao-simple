1~10一、单项选择题十小题#

思路
  • 十道小题覆盖系统线性定常与时变判别、拉氏变换初值定理、通道断开时输出为零、增加开环极点对根轨迹与稳定性的影响、含延迟环节的开环幅相曲线判稳、前馈复合校正前馈装置、描述函数法适用条件、状态向量非奇异线性变换、李雅普诺夫渐近稳定条件、状态反馈对能控性与能观性的影响；按基本概念逐项判断。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断系统线性定常性与通道断开时输出（第1、3小题，借位）
本卷实例
  • 关键一步：看输入输出关系里是否含随时间切换的系数
  • 关键一步：线性系统在输入为零时输出必为零
  • 中间结果：输出是输入的时变倍数即为线性时变
  • 中间结果：通道断开时输出恒为零
  • 卡点：线性与定常是两种独立性质，须分别判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断系统线性定常性与通道断开时输出（第1、3小题，借位）
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
传递函数的定义与基本性质 传递函数
本卷考法
  • 用拉氏变换初值定理求时间信号在零时刻的值（第2小题，借位 tf_01）
本卷实例
  • 关键一步：按初值定理对 s 乘 F(s) 后取 s 趋于无穷
  • 中间结果：比较各选项里对 F(s) 取极限的自变量
  • 卡点：初值定理取 s 趋于无穷，别与终值定理混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过用拉氏变换初值定理求时间信号在零时刻的值（第2小题，借位 tf_01）
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

附加开环零极点的影响 根轨迹法
本卷考法
  • 判断增加开环极点后根轨迹移动方向及稳定性变化（第4小题）
本卷实例
  • 关键一步：比较增加极点前后根轨迹渐近线与实轴走向
  • 中间结果：增加开环极点使根轨迹右移、稳定性变差
  • 卡点：增加开环零点或引入超前校正才改善稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过判断增加开环极点后根轨迹移动方向及稳定性变化（第4小题）
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
含纯延迟环节的系统稳定性 稳定性分析
本卷考法
  • 由含纯延迟环节的幅相曲线判断稳定性与参数关系（第5小题）
本卷实例
  • 关键一步：把延迟环节写成 e 的负 τs 次幂再求幅相特性
  • 中间结果：幅相曲线是半径随 ω 衰减的螺旋线
  • 卡点：延迟环节只改相位不改幅值，判稳要数包围
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 延迟环节 e^{-τs} 的幅值为 1、相位为 -τω，只恶化相位
  • 延迟会显著缩小稳定域，τ 越大越难稳定
  • 频域判据需用相位裕度扣除延迟引起的附加滞后
步骤
  • 写出含延迟的开环传递函数
  • 分别求幅值与相位表达式
  • 在相频特性中扣除 τω 的滞后量
  • 按稳定裕度或奈氏判据求临界 τ 或临界 K
通用考法
  • 本卷考过由含纯延迟环节的幅相曲线判断稳定性与参数关系（第5小题）
  • 求使系统稳定的最大延迟时间
  • 求含延迟系统的临界开环增益
  • 分析延迟对稳定裕度的影响
常见易错
  • 把延迟环节当成惯性环节处理
  • 相位计算时忘记角度与弧度换算

反馈校正与复合控制 系统校正
本卷考法
  • 求使输出完全复现输入的前馈补偿器（第6小题）
本卷实例
  • 关键一步：令闭环传函恒等于一，反解前馈装置传函
  • 中间结果：完全复现时前馈装置为反馈通道传函的倒数
  • 卡点：注意前馈信号接入点的正负号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过求使输出完全复现输入的前馈补偿器（第6小题）
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

描述函数法基础 非线性系统
本卷考法
  • 判断用描述函数法分析非线性系统需满足的条件（第7小题）
本卷实例
  • 关键一步：对照描述函数法三条适用条件逐项排除
  • 中间结果：线性部分须具低通滤波特性且非线性可分离
  • 卡点：非线性输出含直流分量时不满足一次谐波近似
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过判断用描述函数法分析非线性系统需满足的条件（第7小题）
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

状态空间表达式的建立 状态空间分析
本卷考法
  • 写出非奇异状态变换前后状态向量的关系（第8小题，借位 sp_01）
本卷实例
  • 关键一步：由状态变换定义写出新旧状态向量的关系
  • 中间结果：非奇异变换下新状态向量等于 P 的逆乘旧向量

  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过写出非奇异状态变换前后状态向量的关系（第8小题，借位 sp_01）

常见易错

  • 输出方程中漏掉直接传递项 D

李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 由李雅普诺夫第二法判断渐近稳定所需条件（第9小题）
本卷实例
  • 关键一步：按李雅普诺夫第二法判断 V 与 V 导数的正负定
  • 中间结果：V 正定且 V 导数负定时原点渐近稳定
  • 卡点：V 导数半负定一般只能判稳定，不能判渐近稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过由李雅普诺夫第二法判断渐近稳定所需条件（第9小题）
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

  • 中间结果：状态反馈不改变能控性，但未必保持能观性

  • 特征多项式比较系数时符号写反

一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 求一阶系统单位阶跃响应进入 2% 误差带的调节时间（第2小题）
本卷实例
  • 关键一步：把一阶传函与标准形式对照读出时间常数
  • 中间结果：2% 误差带的调节时间等于四倍时间常数
  • 卡点：63.2% 对应时间常数，勿与调节时间混记
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过求一阶系统单位阶跃响应进入 2% 误差带的调节时间（第2小题）
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

与虚轴的交点及临界参数 根轨迹法
本卷考法
