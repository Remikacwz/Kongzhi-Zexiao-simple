1~6一、选择题（6小题）30 分#

思路

开环对数频率特性的绘制 频域分析
本卷考法
  • 判断开环对数幅频中频段参数对哪类性能无影响（第1小题）
本卷实例
  • 关键一步：由三频段理论看中频段主要对应动态性能与相对稳定性
  • 中间结果：中频段不直接决定稳态精度，故选稳态性能项
  • 卡点：中频段与快速性、稳定性有关，别与稳态精度混答
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过判断开环对数幅频中频段参数对哪类性能无影响（第1小题）
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由二阶系统特征根为负实部复根判断阻尼比范围（第2小题）
本卷实例
  • 关键一步：由根在左半平面且为一对复根判断欠阻尼
  • 中间结果：欠阻尼对应ξ大于0且小于1
  • 卡点：负实部复根是欠阻尼，勿选ξ等于0或ξ不小于1
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由二阶系统特征根为负实部复根判断阻尼比范围（第2小题）
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

劳斯判据 稳定性分析
本卷考法
  • 由闭环特征方程临界稳定条件求反馈系数Kh（第3小题）
本卷实例
  • 关键一步：写出开环传函后列特征方程，令一次项系数为零
  • 中间结果：临界稳定时劳斯表某临界行出现零，据此解Kh
  • 卡点：Kh出现在反馈通道，整理特征式时不要漏项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由闭环特征方程临界稳定条件求反馈系数Kh（第3小题）
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 判断哪种措施对提高系统稳定性没有效果（第4小题）
本卷实例
  • 关键一步：逐项比较增加开环极点、加单位反馈、增加开环零点、串超前校正的作用
  • 中间结果：增加开环极点提高型别却使稳定性变差
  • 卡点：增加开环极点与增加开环零点对稳定性的影响相反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过判断哪种措施对提高系统稳定性没有效果（第4小题）
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由抛物线输入下稳态误差为无穷判断系统状态（第5小题）
本卷实例
  • 关键一步：按型别与静态误差系数表逐一对照抛物线输入
  • 中间结果：型别不足或系统不稳定都会使稳态误差趋于无穷
  • 卡点：误差无穷可能因型别不足也可能因不稳定，须结合选项判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由抛物线输入下稳态误差为无穷判断系统状态（第5小题）
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环传函求开环增益（第6小题）
本卷实例
  • 关键一步：把各环节化成尾1型后取常数之比
  • 中间结果：开环增益等于尾1型化后分子与分母常数之比
  • 卡点：不能直接取分子与分母最高次系数之比
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由开环传函求开环增益（第6小题）
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

思路

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函分母与标准二阶形式对应求ωn与ξ的关系（第(1)(2)问）

  • 关键一步：把分母各项系数与标准二阶形式逐项对比
  • 中间结果：ωn等于1/T，2ξωn等于2ξ/T

  • β=arccos ξ 是极点与负实轴的夹角

  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式

  • 本卷考过由闭环传函分母与标准二阶形式对应求ωn与ξ的关系（第(1)(2)问）

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 在不同ξ、T下计算单位阶跃响应的超调量与调节时间（第(1)(2)问）
  • 讨论ξ、T对阶跃响应性能的影响（第(3)问）
本卷实例
  • 关键一步：分别用超调量与调节时间的欠阻尼公式代入ξ、ωn计算
  • 中间结果：σ%只由ξ决定；ts由ξ与ωn共同决定
  • 卡点：ξ不变时改变T只改变ts不改变σ%
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过在不同ξ、T下计算单位阶跃响应的超调量与调节时间（第(1)(2)问）
  • 本卷考过讨论ξ、T对阶跃响应性能的影响（第(3)问）
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

4四、结构图判稳与稳态误差25 分#

思路
  • 由含扰动输入的结构图求稳定条件，再分别求参考输入与扰动输入作用下的稳态误差
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 由含给定与扰动的结构图写特征式与各通道传函（第1、2、3问）
本卷实例
  • 关键一步：令各输入分别作用、其余为零，逐个写通道传递函数
  • 中间结果：特征式由两条回路增益确定，各通道分子不同
  • 卡点：扰动作用点不同，到输出与到误差的通道要分别写
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过由含给定与扰动的结构图写特征式与各通道传函（第1、2、3问）
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 确定K与Kt满足闭环系统稳定的条件（第1问）
本卷实例
  • 关键一步：把特征式整理成关于s的多项式后列劳斯判据
  • 中间结果：由劳斯表各元同号得K与Kt的不等式组
  • 卡点：Kt出现在回路中会改变特征式系数，不能漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过确定K与Kt满足闭环系统稳定的条件（第1问）
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求r(t)=t、n(t)=0时系统的稳态误差（第2问）
本卷实例
  • 关键一步：由参考输入到误差的传函用终值定理求极限
  • 中间结果：I型系统的斜坡误差由速度误差系数决定
  • 卡点：须在稳定域内求稳态误差才有意义
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求r(t)=t、n(t)=0时系统的稳态误差（第2问）
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

扰动作用下的稳态误差 稳态误差
本卷考法
  • 求r(t)=0、n(t)=1(t)时系统的稳态误差（第3问）
本卷实例
  • 关键一步：先写扰动到误差的传函再取终值
  • 中间结果：扰动稳态误差由扰动作用点前后的增益决定
  • 卡点：扰动误差可能与参考误差反号，注意符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求r(t)=0、n(t)=1(t)时系统的稳态误差（第3问）
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

5五、由对数幅频特性求传函与裕度25 分#

思路
  • 由最小相位系统开环对数幅频特性反求传函，再求幅值穿越频率、相频特性与相位裕量判稳
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频特性求系统的型别、开环增益及传函G(s)（第1问）
本卷实例
  • 关键一步：由低频段斜率定型别、延长线交点定增益、转折频率写环节
  • 中间结果：各转折频率分别对应一阶微分环节或惯性环节
  • 卡点：转折频率与增益取自图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频特性求系统的型别、开环增益及传函G(s)（第1问）
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 求幅值穿越频率、相频特性与相位裕量并判断稳定性（第2、3问）
本卷实例
  • 关键一步：令开环幅频等于1求穿越频率，再代入相频求相位裕量
  • 中间结果：相位裕量大于零时闭环系统稳定
  • 卡点：穿越频率落在不同频段会影响相频近似方式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求幅值穿越频率、相频特性与相位裕量并判断稳定性（第2、3问）
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

6六、离散系统脉冲传函与稳定性20 分#

思路
  • 由离散系统结构图求输出与误差的脉冲传函，再用z域特征方程求稳定的K与T关系
脉冲传递函数 离散控制系统
本卷考法
  • 由离散结构图求C(Z)/R(Z)和E(Z)/R(Z)（第1问）
本卷实例
  • 关键一步：列z域方程消去中间采样信号，分别对输出与误差求解
  • 中间结果：输出与误差脉冲传函共用同一闭环特征式
  • 卡点：误差传函与输出传函分子不同，不能混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过由离散结构图求C(Z)/R(Z)和E(Z)/R(Z)（第1问）
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)
公式
离散系统稳定性分析 离散控制系统
本卷考法
  • 由稳定性要求求K与T应满足的关系（第2问）
本卷实例
  • 关键一步：写出z域特征方程后套朱利判据
  • 中间结果：由D(1)大于0、D(−1)大于0及首末系数条件得不等式
  • 卡点：T留在指数项，须整理成对z的多项式再判
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过由稳定性要求求K与T应满足的关系（第2问）
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒
