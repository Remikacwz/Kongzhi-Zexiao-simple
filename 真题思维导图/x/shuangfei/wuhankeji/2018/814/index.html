1一、填空题（8小题）40 分#

思路
  • 8小题分别考ωn与ξ对动态指标的影响、系统型别、主导极点、由闭环传函求开环传函、开环增益、对称最佳系统、劳斯判据判稳、一阶系统调节时间与稳态输出
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 说明ωn降低、ξ增大时调节时间与超调量的变化（第1小题）
本卷实例
  • 关键一步：从调节时间与超调量公式看ωn、ξ各自的影响方向
  • 中间结果：ts与ξωn成反比，σ%只由ξ决定
  • 卡点：ωn降低使ts增大，别把变化方向写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过说明ωn降低、ξ增大时调节时间与超调量的变化（第1小题）
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环传函中积分环节数目确定系统型别（第2小题）
  • 把开环传函化为尾1型求开环增益（第5小题）
本卷实例
  • 关键一步：数开环传函中1/s的幂次定型别；化尾1型后取常数之比得开环增益
  • 中间结果：含一个1/s即I型系统；开环增益是尾1型各环节常数之比
  • 卡点：开环增益不是最高次系数之比，须先化为尾1型
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由开环传函中积分环节数目确定系统型别（第2小题）
  • 本卷考过把开环传函化为尾1型求开环增益（第5小题）
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 填出高阶系统中起主导作用的闭环极点名称（第3小题）
本卷实例
  • 关键一步：从极点对瞬态分量的影响大小判断其主导地位
  • 中间结果：离虚轴最近且附近无闭环零点的极点称闭环主导极点
  • 卡点：主导极点还要求附近没有闭环零点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过填出高阶系统中起主导作用的闭环极点名称（第3小题）
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由单位负反馈与单位正反馈的闭环传函反求开环传函（第4小题）
本卷实例
  • 关键一步：按反馈连接的公式把闭环式解出前向通道G(s)
  • 中间结果：负反馈G=φ/(1−φ)，正反馈G=φ/(1+φ)
  • 卡点：正、负反馈的换算一个是1−φ一个是1+φ，不要写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由单位负反馈与单位正反馈的闭环传函反求开环传函（第4小题）
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

开环对数频率特性的绘制 频域分析
本卷考法
  • 填出对称最佳系统的开环对数幅频斜率特征（第6小题）
本卷实例
  • 关键一步：沿频率从小到大逐段看斜率变化识别对称最佳形状
  • 中间结果：对称最佳系统斜率依次为−40、−20、−40 dB/dec
  • 卡点：问的是整条对数幅频的斜率形状，不是单个环节斜率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过填出对称最佳系统的开环对数幅频斜率特征（第6小题）
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

劳斯判据 稳定性分析
本卷考法
  • 对特征方程5s⁴+10s³+5s²+3s+2=0用劳斯判据判稳（第7小题）
本卷实例
  • 关键一步：按特征方程系数列劳斯表并看第一列符号变化
  • 中间结果：第一列出现负值即判为不稳定
  • 卡点：劳斯表首列出现0要改用ε法，不能直接判稳
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过对特征方程5s⁴+10s³+5s²+3s+2=0用劳斯判据判稳（第7小题）
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由一阶闭环传函6/(s+3)求5%误差带调节时间与稳态输出（第8小题）
本卷实例
  • 关键一步：把传函化为尾1型取时间常数T，再按ts=3T计算
  • 中间结果：闭环增益决定稳态输出，时间常数决定调节时间
  • 卡点：5%误差带用ts=3T，2%误差带用ts=4T，不要用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由一阶闭环传函6/(s+3)求5%误差带调节时间与稳态输出（第8小题）
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

2二、求传递函数20 分#

思路
  • 把结构图化为信号流图，用梅森增益公式求闭环传函，注意互不接触回路的组合
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 对含多个回路的系统结构图逐层化简求C(s)/R(s)
本卷实例
  • 关键一步：先数清独立回路数与两两互不接触回路的组合
  • 中间结果：回路增益多为1/(RCs)量级，两两互不接触回路有6组
  • 卡点：互不接触回路乘积项的正负要按回路数确定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过对含多个回路的系统结构图逐层化简求C(s)/R(s)
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求闭环传递函数
本卷实例
  • 关键一步：列出1条前向通路、5个独立回路与6组互不接触回路
  • 中间结果：特征式由1加各回路增益及互不接触回路乘积组成
  • 卡点：前向通路增益与回路增益不要混淆，注意回路极性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求r(t)=3t+1下的稳态误差并反解K（第(2)问）
本卷实例
  • 关键一步：把输入拆成阶跃与斜坡两项分别叠加误差
  • 中间结果：ess等于阶跃误差加斜坡误差，是K的表达式
  • 卡点：误差要求反解出的K与稳定域无交集，应判无解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
