1~6一、选择题（6小题）30 分#

思路
  • 6道小题分别考二阶系统幅相曲线与虚轴交点频率、斜坡输入下的静态误差、由传函系数判断阻尼类型、微分方程组模型的稳定条件、由Bode图反求传函、开环零点对闭环稳定的影响
频率特性的物理意义与求法 频域分析
本卷考法
  • 判断二阶系统幅相曲线与虚轴交点处的频率（第1小题）
本卷实例
  • 关键一步：令幅相特性的实部为零求曲线与虚轴的交点
  • 中间结果：交点对应的角频率等于系统的固有频率
  • 卡点：谐振频率对应幅值最大处，不是虚轴交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过判断二阶系统幅相曲线与虚轴交点处的频率（第1小题）
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 判断斜坡输入下静态误差（第2小题）
本卷实例
  • 关键一步：先数开环传函中积分环节个数定系统型别
  • 中间结果：无积分环节为0型系统，斜坡误差趋于无穷
  • 卡点：不要把一阶惯性环节误当成积分环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断斜坡输入下静态误差（第2小题）
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由传函系数判断二阶系统阻尼类型（第3小题）
本卷实例
  • 关键一步：与标准二阶形式对比求ζ与ωn
  • 中间结果：阻尼比小于1时系统为欠阻尼
  • 卡点：一次项系数含二倍乘积，不要漏掉因子2
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由传函系数判断二阶系统阻尼类型（第3小题）
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由微分方程组求闭环稳定时参数范围（第4小题）
本卷实例
  • 关键一步：对微分方程组取拉氏变换并消去中间变量
  • 中间结果：得四阶闭环特征方程后列劳斯表求参数范围
  • 卡点：方程中导数阶次不同，消元时不要遗漏状态量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由微分方程组求闭环稳定时参数范围（第4小题）
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由Bode图判断系统传递函数（第5小题）
本卷实例
  • 关键一步：看低频段斜率定积分环节数、看转折频率定时间常数
  • 中间结果：转折频率处斜率的变化对应一阶环节
  • 卡点：非最小相位环节只在相频上体现，须回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由Bode图判断系统传递函数（第5小题）
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 判断使闭环稳定的开环时间常数关系（第6小题）
本卷实例
  • 关键一步：由相角裕度大于零列截止频率处的相角条件
  • 中间结果：分子时间常数足够大才能保证正相角裕度
  • 卡点：两个时间常数同名，须分清分子与分母
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过判断使闭环稳定的开环时间常数关系（第6小题）
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

2二、填空题（4小题）20 分#

思路
  • 4道小题分别考由特征方程求纯虚根、由截止频率处幅值为1求开环增益、由单位阶跃响应曲线求传函、按相位裕度与幅值裕度要求设计滞后校正
劳斯判据 稳定性分析
本卷考法
  • 由特征方程求系统的纯虚根（第1小题）
本卷实例
  • 关键一步：劳斯表出现全零行时取上一行系数写辅助方程
  • 中间结果：辅助方程的解即为系统的纯虚根
  • 卡点：全零行须用辅助方程求导后的系数代替再继续
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由特征方程求系统的纯虚根（第1小题）
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
稳定裕度 频域分析
本卷考法
  • 由给定截止频率求开环增益（第2小题）
本卷实例
  • 关键一步：令截止频率处开环幅值等于1列方程
  • 中间结果：把截止频率代入幅值式后即可解出增益
  • 卡点：分母两个惯性环节都要代入同一截止频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由给定截止频率求开环增益（第2小题）
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应曲线反求二阶传函（第3小题）
本卷实例
  • 关键一步：从曲线上读超调量与峰值时间反推ζ与ωn
  • 中间结果：用ζ与ωn组装标准二阶传递函数
  • 卡点：曲线以图给出，读数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应曲线反求二阶传函（第3小题）
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

滞后校正 系统校正
本卷考法
  • 按裕度要求设计串联滞后校正环节（第4小题）
本卷实例
  • 关键一步：按相位裕度要求选新的截止频率
  • 中间结果：由幅值衰减量定滞后网络的两个参数
  • 卡点：滞后校正把截止频率左移，不是右移
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过按裕度要求设计串联滞后校正环节（第4小题）
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

3三、无源网络求传递函数15 分#

思路
  • 由无源网络各元件复阻抗按节点列方程，逐层消去中间节点电压，最后求输出电压对输入电压的传递函数
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由无源网络复阻抗模型求传递函数
本卷实例
  • 关键一步：把电容电感换成复阻抗，按分压或节点法列方程
  • 中间结果：逐层代入化简得输出电压与输入电压的有理式之比
  • 卡点：网络拓扑以图给出，元件连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由无源网络复阻抗模型求传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 把电路方程整理成标准传递函数形式
本卷实例
  • 关键一步：消去中间节点电压后整理成s的多项式之比
  • 中间结果：分子分母最高次由网络阶数决定
  • 卡点：并联支路化简时不要漏掉接地支路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过把电路方程整理成标准传递函数形式

思路

稳定裕度 频域分析
本卷考法
  • 求最小相位系统的相角裕度并判稳
本卷实例
  • 关键一步：先按幅值等于1求截止频率，再代相频求相角
  • 中间结果：相角裕度等于180度加截止频率处相角

  • 求系统的相角裕度与幅值裕度
