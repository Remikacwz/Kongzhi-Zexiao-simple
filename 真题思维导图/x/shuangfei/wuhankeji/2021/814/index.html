武汉科技大学 814 自动控制理论（含现控） 2021 年真题思维导图

1~6一、选择题六小题#

思路
  • 六道小题分别考添加开环零点的影响、典型输入信号阶次、速度信号误差无穷的推论、消除稳态误差的环节、负反馈好处与研究对象，逐个按基本概念判断。
附加开环零极点的影响 根轨迹法
本卷考法
  • 判断增加开环零点对系统性能的影响（第1小题）
本卷实例
  • 关键一步：从开环零点改变根轨迹形状、增强相对稳定性切入
  • 中间结果：增加开环零点使根轨迹左移，相对稳定性提高
  • 卡点：开环零点与闭环零点作用不同，不要混答
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过判断增加开环零点对系统性能的影响（第1小题）
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
典型输入信号 基本概念与信号
本卷考法
  • 判断哪类典型输入信号要求系统阶数更高（第2小题）
本卷实例
  • 关键一步：按脉冲、阶跃、斜坡、加速度的阶次由低到高排列
  • 中间结果：加速度信号阶次最高，需要二阶以上系统才能跟踪
  • 卡点：第2小题题干在逐年 OCR 中丢失，只余四个选项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 常用典型输入有冲激、阶跃、斜坡、抛物线（加速度）与正弦五类
  • 阶跃信号用于考查快速性与稳定性，斜坡与抛物线用于考查稳态精度
  • 正弦信号用于频域分析，冲激响应就是系统的传递函数
  • 各典型信号的拉氏变换是分析全响应的起点
步骤
  • 按题意写出输入信号的时域表达式
  • 对输入取拉氏变换得到该信号的复域形式
  • 由输入类型判断考查的是动态性能还是稳态精度
  • 把输入代入误差或响应公式计算
通用考法
  • 本卷考过判断哪类典型输入信号要求系统阶数更高（第2小题）
  • 写出典型输入信号的拉氏变换
  • 说明某一典型输入信号用于考查哪类性能
  • 由输入类型判断稳态误差是否为有限值
常见易错
  • 把斜坡与抛物线信号的阶次写错
  • 阶跃的拉氏变换漏掉系数（幅度不为 1 时）
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由速度信号稳态误差为无穷判断其它输入下的误差（第3小题）
本卷实例
  • 关键一步：把系统型别与各典型输入下误差是否有穷对应起来
  • 中间结果：低阶信号误差为无穷时高阶信号误差也为无穷
  • 卡点：型别数字越大跟踪能力越强，方向不要记反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由速度信号稳态误差为无穷判断其它输入下的误差（第3小题）
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 判断哪种典型环节能消除稳态误差（第4小题）
本卷实例
  • 关键一步：从各环节对误差的积分或微分作用判断
  • 中间结果：积分环节对误差累积可把有限稳态误差压到零
  • 卡点：微分与比例环节都不能消除稳态误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过判断哪种典型环节能消除稳态误差（第4小题）
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断负反馈带来的好处与自动控制原理的研究对象（第5、6小题）
本卷实例
  • 关键一步：从负反馈提高抗扰性与稳定性、但降低开环增益切入
  • 中间结果：自动控制原理主要研究闭环控制系统
  • 卡点：负反馈不提高增益，选项常把增益列成好处
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断负反馈带来的好处与自动控制原理的研究对象（第5、6小题）
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

2二、简答题#

思路
  • 从时域指标与频域指标两方面说明阻尼比小的系统的表现，时域看超调与振荡，频域看相角裕度、幅值裕度与谐振峰值。
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 说明阻尼比小时时域指标的变化
本卷实例
  • 关键一步：由阻尼比减小推出超调量与振荡次数增大
  • 中间结果：调节时间变长而峰值时间变短
  • 卡点：峰值时间变短不等于响应更快，要结合调节时间说明
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过说明阻尼比小时时域指标的变化
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
稳定裕度 频域分析
本卷考法
  • 说明阻尼比小时相角裕度与幅值裕度的变化
本卷实例
  • 关键一步：把阻尼比与相角裕度、幅值裕度的关系理清
  • 中间结果：阻尼比减小使相角裕度减小、幅值裕度增大
  • 卡点：两个裕度变化方向相反，不要一并说成减小
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过说明阻尼比小时相角裕度与幅值裕度的变化
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
闭环频率特性与性能指标 频域分析
本卷考法
  • 说明阻尼比小时闭环频域指标的变化
本卷实例
  • 关键一步：由闭环谐振峰值与带宽判断频域表现
  • 中间结果：谐振峰值增大说明振荡加剧、抗扰能力下降
  • 卡点：谐振峰值与带宽变化方向不同，须分开表述
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过说明阻尼比小时闭环频域指标的变化
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈
公式

3三、由结构图求传递函数#

思路
  • 由系统结构图分别求参考输入下的 C(s)/R(s) 与扰动输入下的 C(s)/N(s)，用梅森公式枚举回路与前向通路。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求参考输入下的传递函数 C(s)/R(s)
本卷实例
  • 关键一步：先枚举全部回路再列前向通路并判断接触情况
  • 中间结果：特征式为 1 加回路增益，前向通路的余子式均为 1
  • 卡点：结构图以图给出，回路与前向通路需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求参考输入下的传递函数 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求扰动输入下的传递函数 C(s)/N(s)
本卷实例
  • 关键一步：求扰动传函时把参考输入置零后走同一框图
  • 中间结果：扰动通路只含一条前向通路，形式比参考通路简单
  • 卡点：两个输入不能直接叠加而未验证系统线性性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求扰动输入下的传递函数 C(s)/N(s)
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式

4四、二阶系统单位阶跃响应与动态性能#

思路
  • 由结构图求开环与闭环传函并化成二阶标准形式，按阻尼比取值分欠阻尼、临界阻尼与过阻尼三种情形写单位阶跃响应并给动态指标。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图求开环与闭环传递函数
本卷实例
  • 关键一步：先由框图写开环再按单位负反馈求闭环
  • 中间结果：闭环特征式为二阶，一次项系数含可变增益
  • 卡点：被控对象以图给出，接法与增益需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由结构图求开环与闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函求阻尼比与无阻尼振荡频率
本卷实例
  • 关键一步：把闭环分母与标准二阶特征式逐项对照
  • 中间结果：阻尼比随增益线性增大，自然频率与增益无关
  • 卡点：要按阻尼比取值分欠阻尼、临界阻尼与过阻尼讨论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼

  • β=arccos ξ 是极点与负实轴的夹角

  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型

  • 由闭环传递函数求 ωn 与 ξ

  • 在 s 平面上标出闭环极点的位置
常见易错

  • 把开环增益误当成闭环传递函数的系数
