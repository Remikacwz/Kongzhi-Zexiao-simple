1一、填空题（5小题）20 分#

思路
  • 5小题分别考反馈控制原理、PID与三种校正对应的控制律、含延迟因子的拉氏反变换、序列z变换、离散输出z变换
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 由反馈控制原理填出检测量、输出精度与抗扰性能（第1小题）
本卷实例
  • 关键一步：围绕反馈比较环节判断检测量与纠正量
  • 中间结果：闭环优点是精度高、抗干扰性能好
  • 卡点：检测的是被控量偏差而不是扰动本身
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过由反馈控制原理填出检测量、输出精度与抗扰性能（第1小题）
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
PID 控制器与参数整定 系统校正
本卷考法
  • 填出比例加积分加微分控制规律的简称（第2小题前段）
本卷实例
  • 关键一步：由比例、积分、微分三项合称判断控制律名称
  • 中间结果：三项全取时简称为PID控制律
  • 卡点：不要把微分项漏掉写成PI
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过填出比例加积分加微分控制规律的简称（第2小题前段）
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式
超前校正 系统校正
本卷考法
  • 指出串联超前、滞后、滞后-超前校正近似对应的控制律（第2小题后段）
本卷实例
  • 关键一步：按各校正网络的相位特性对应P、I、D的不同组合
  • 中间结果：超前网络偏微分作用、滞后网络偏积分作用
  • 卡点：超前与滞后的相位符号不能对调
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过指出串联超前、滞后、滞后-超前校正近似对应的控制律（第2小题后段）
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
典型输入信号 基本概念与信号
本卷考法
  • 求含系数因子的一阶分式的拉氏反变换（第3小题）
本卷实例
  • 关键一步：先做有理分式的反变换再乘系数因子
  • 中间结果：时域结果为一阶指数衰减形式
  • 卡点：分子上的常数因子要保留，不能只写分式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 常用典型输入有冲激、阶跃、斜坡、抛物线（加速度）与正弦五类
  • 阶跃信号用于考查快速性与稳定性，斜坡与抛物线用于考查稳态精度
  • 正弦信号用于频域分析，冲激响应就是系统的传递函数
  • 各典型信号的拉氏变换是分析全响应的起点
步骤
  • 按题意写出输入信号的时域表达式
  • 对输入取拉氏变换得到该信号的复域形式
  • 由输入类型判断考查的是动态性能还是稳态精度
  • 把输入代入误差或响应公式计算
通用考法
  • 本卷考过求含系数因子的一阶分式的拉氏反变换（第3小题）
  • 写出典型输入信号的拉氏变换
  • 说明某一典型输入信号用于考查哪类性能
  • 由输入类型判断稳态误差是否为有限值
常见易错
  • 把斜坡与抛物线信号的阶次写错
  • 阶跃的拉氏变换漏掉系数（幅度不为 1 时）
公式
z 变换与 z 反变换 离散控制系统
本卷考法
  • 求有限长序列2的n次方的z变换（第4小题）
本卷实例
  • 关键一步：按定义对n取1到3逐项求和
  • 中间结果：结果是以公比为2的有限项等比级数
  • 卡点：序列从n=1起，不要多算n=0那一项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • z 变换是离散信号的拉氏变换，令 z=e^{Ts} 得到
  • 常用函数的 z 变换要熟记
  • z 反变换可用部分分式法、幂级数法或留数法
  • 左半 s 平面映射到 z 平面单位圆内
步骤
  • 将连续传递函数展开为部分分式
  • 逐项查表做 z 变换
  • 需要时做 z 反变换求时间序列
通用考法
  • 本卷考过求有限长序列2的n次方的z变换（第4小题）
  • 求给定函数的 z 变换
  • 求 z 反变换得到采样序列
  • 说明 s 平面与 z 平面的映射关系
常见易错
  • 把 z 变换结果中的 e^{-aT} 写成 e^{-a}
  • 部分分式分解时漏项导致反变换出错
公式
脉冲传递函数 离散控制系统
本卷考法
  • 求离散结构图的输出z变换（第5小题）
本卷实例
  • 关键一步：在采样开关后列z域方程并消去中间变量
  • 中间结果：输出由前向通道除以一加开环脉冲传函
  • 卡点：采样开关位置决定环节之间能否直接相乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过求离散结构图的输出z变换（第5小题）
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)

2二、简述相对稳定性与稳定裕度10 分#

思路
  • 从时域与频域两个角度比较相对稳定性与稳定裕度的含义
稳定裕度 频域分析
本卷考法
  • 从频域说明相对稳定性与稳定裕度的含义
本卷实例
  • 关键一步：把稳定裕度与开环频率特性的穿越点联系起来
  • 中间结果：相角裕度和幅值裕度是频域的相对稳定性度量
  • 卡点：幅值裕度取倒数容易让大小关系反过来
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过从频域说明相对稳定性与稳定裕度的含义
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 从时域说明相对稳定性与稳定裕度的含义
本卷实例
  • 关键一步：用时域响应的振荡衰减程度理解相对稳定性
  • 中间结果：阻尼比越大响应超调越小、稳定程度越高
  • 卡点：稳定与相对稳定是两回事，别混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过从时域说明相对稳定性与稳定裕度的含义
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

3三、由结构图求传递函数20 分#

思路
  • 把结构图化为信号流图，用梅森公式求闭环传递函数
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 对含多条回路的系统结构图逐层化简
本卷实例
  • 关键一步：先找内环回路并求其等效传递函数
  • 中间结果：逐层向外合并得到单回路形式
  • 卡点：回路之间是否接触决定分母是否需要加项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过对含多条回路的系统结构图逐层化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求系统闭环传递函数
本卷实例
  • 关键一步：找全前向通路、回路与不接触回路组合
  • 中间结果：按公式写出前向通路与余子式之比
  • 卡点：余子式里要剔除与通路接触的回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求系统闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

4四、由动态指标反求参数20 分#

思路
  • 由超调量与峰值时间反推阻尼比和自然频率，再结合结构图写开环与闭环传函并定参数
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间反求阻尼比与自然频率
本卷实例
  • 关键一步：由超调量公式先解阻尼比
  • 中间结果：峰值时间与阻尼振荡频率互为倒数关系
  • 卡点：反三角计算时角度与弧度不要混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与峰值时间反求阻尼比与自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由性能指标要求反求结构图参数
本卷实例
  • 关键一步：把闭环特征多项式系数与标准二阶形式对应
  • 中间结果：结构参数由阻尼比及自然频率的平方表示
  • 卡点：结构图与参数对应依赖原图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由性能指标要求反求结构图参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
