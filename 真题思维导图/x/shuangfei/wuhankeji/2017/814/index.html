1一、填空题（5小题）20 分#

思路
  • 5小题分别考稳定条件与时域指标、由阶跃响应求脉冲响应与传函、含时移冲激的z变换、由速度误差系数求增益、超前校正最大超前角
劳斯判据 稳定性分析
本卷考法
  • 指出线性系统正常工作的首要条件（第1小题前段）
本卷实例
  • 关键一步：从系统自身结构参数与输入无关入手判断
  • 中间结果：稳定是系统能正常工作的前提
  • 卡点：稳定由系统结构与参数决定，与输入无关
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过指出线性系统正常工作的首要条件（第1小题前段）
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 填出描述系统输出量精度的时域指标（第1小题中段）
本卷实例
  • 关键一步：从时域精度与稳态跟踪能力入手
  • 中间结果：稳态误差用来衡量输出量的精度
  • 卡点：精度指标与快速性指标不要写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过填出描述系统输出量精度的时域指标（第1小题中段）
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 填出描述单位阶跃响应平稳性的时域指标（第1小题后段）
本卷实例
  • 关键一步：平稳性对应响应的振荡与超调程度
  • 中间结果：超调量与振荡次数用于描述平稳性
  • 卡点：振荡次数是平稳性指标不是快速性指标
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过填出描述单位阶跃响应平稳性的时域指标（第1小题后段）
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应求单位脉冲响应与系统传递函数（第2小题）
本卷实例
  • 关键一步：对阶跃响应求导得脉冲响应
  • 中间结果：对脉冲响应取拉氏变换得传函
  • 卡点：响应表达式在试题段有粘连，已据答案段还原
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应求单位脉冲响应与系统传递函数（第2小题）
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

z 变换与 z 反变换 离散控制系统
本卷考法
  • 求含时移冲激信号的z变换（第3小题）
本卷实例
  • 关键一步：用z变换的时移性质处理延迟因子
  • 中间结果：时移k步对应乘以z的负k次幂
  • 卡点：时移步数由序列下标换算，不要少乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • z 变换是离散信号的拉氏变换，令 z=e^{Ts} 得到
  • 常用函数的 z 变换要熟记
  • z 反变换可用部分分式法、幂级数法或留数法
  • 左半 s 平面映射到 z 平面单位圆内
步骤
  • 将连续传递函数展开为部分分式
  • 逐项查表做 z 变换
  • 需要时做 z 反变换求时间序列
通用考法
  • 本卷考过求含时移冲激信号的z变换（第3小题）
  • 求给定函数的 z 变换
  • 求 z 反变换得到采样序列
  • 说明 s 平面与 z 平面的映射关系
常见易错
  • 把 z 变换结果中的 e^{-aT} 写成 e^{-a}
  • 部分分式分解时漏项导致反变换出错
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由速度误差系数求开环增益（第4小题）
本卷实例
  • 关键一步：先判断系统型别再列速度误差系数定义式
  • 中间结果：速度误差系数等于极限式中的常数项
  • 卡点：型别判错会导致误差系数公式用错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由速度误差系数求开环增益（第4小题）
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
超前校正 系统校正
本卷考法
  • 由超前校正装置传递函数求最大超前角（第5小题）
本卷实例
  • 关键一步：由传函的零极点位置确定分度系数
  • 中间结果：最大超前角由分度系数按反正弦公式求得
  • 卡点：分度系数取分子与分母时间常数之比，不要取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过由超前校正装置传递函数求最大超前角（第5小题）
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

2二、简述三频段理论10 分#

思路
  • 说明开环对数频率特性低、中、高三个频段各自的特点及其与闭环性能的对应关系
开环对数频率特性的绘制 频域分析
本卷考法
  • 说明开环对数幅频特性三频段各自的特点与作用
本卷实例
  • 关键一步：从低频段高度与斜率看稳态精度
  • 中间结果：中频段决定平稳性与快速性
  • 卡点：高频段越陡抗干扰能力越强，别写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过说明开环对数幅频特性三频段各自的特点与作用
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
校正的基本概念与性能指标 系统校正
本卷考法
  • 说明设计合理系统对三频段的总体要求
本卷实例
  • 关键一步：把时域指标折算成对三个频段的要求
  • 中间结果：低频高、中频宽、高频陡是理想配置
  • 卡点：只强调中频段而忽略低频增益要求
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过说明设计合理系统对三频段的总体要求
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求

3三、由结构图求传递函数20 分#

思路
  • 把结构图化为信号流图，用梅森公式求闭环传递函数
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 对含三条回路的系统结构图逐层化简
本卷实例
  • 关键一步：先找互不接触回路并判断其组合
  • 中间结果：化简时注意回路之间的公共节点
  • 卡点：两条互不接触回路要在分母加乘积项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过对含三条回路的系统结构图逐层化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求闭环传递函数
本卷实例
  • 关键一步：列出全部前向通路与回路增益
  • 中间结果：余子式只保留不与通路接触的回路
  • 卡点：前向通路增益不要与回路增益混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

4四、由阶跃响应曲线求参数20 分#

思路
  • 由单位阶跃响应曲线读超调量与峰值时间反推阻尼比和自然频率，再确定结构参数
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由二阶系统结构图写出闭环传递函数并求阻尼比与自然频率
本卷实例
  • 关键一步：先按结构图列闭环特征多项式
  • 中间结果：把特征多项式与标准二阶形式对应
  • 卡点：反馈支路增益位置不同会改变标准形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由二阶系统结构图写出闭环传递函数并求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由响应曲线的特征反求结构参数
本卷实例
  • 关键一步：从曲线上读稳态值与峰值时间
  • 中间结果：由峰值时间与自然频率关系定参数
  • 卡点：曲线以图给出，读数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
