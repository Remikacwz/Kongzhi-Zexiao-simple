1~6一、选择题（6小题）#

思路
  • 6道小题分别考传递函数适用对象、系统稳定的含义、欠阻尼根的位置、型系统低频段斜率、延迟环节极坐标图、阻尼比不变时提高无阻尼振荡频率对动态指标的影响，逐题按基本概念判断
传递函数的定义与基本性质 传递函数
本卷考法
  • 判断哪类系统适合用传递函数描述（第1小题）
本卷实例
  • 关键一步：从传递函数只对线性定常、零初始条件系统定义切入
  • 中间结果：线性定常系统才可用传递函数描述
  • 卡点：线性时变与非线性系统都不满足适用条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过判断哪类系统适合用传递函数描述（第1小题）
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
劳斯判据 稳定性分析
本卷考法
  • 判断系统稳定的含义（第2小题；借位st_01）
本卷实例
  • 关键一步：从扰动去除后输出或误差是否收敛到平衡点判断
  • 中间结果：渐近稳定指扰动后误差逐渐收敛到零
  • 卡点：不同初始条件下响应一致说的是无差性，不等于稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过判断系统稳定的含义（第2小题；借位st_01）
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 判断欠阻尼系统闭环根的类型（第3小题）
本卷实例
  • 关键一步：由阻尼比在0与1之间对应特征根实部为负
  • 中间结果：欠阻尼时根为一对负实部共轭复根
  • 卡点：纯虚根是零阻尼，不要与欠阻尼混答
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过判断欠阻尼系统闭环根的类型（第3小题）
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

开环对数频率特性的绘制 频域分析
本卷考法
  • 判断Ⅱ型系统低频段渐近线斜率（第4小题）
本卷实例
  • 关键一步：按系统型别数积分环节个数再定低频段斜率
  • 中间结果：Ⅱ型含两个积分环节，低频段斜率为负40分贝每十倍频
  • 卡点：题面OCR漏印罗马数字Ⅱ，只余A选项，据答案段补题
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过判断Ⅱ型系统低频段渐近线斜率（第4小题）
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

频率特性的物理意义与求法 频域分析
本卷考法
  • 判断延迟环节频率特性的极坐标图形状（第5小题）
本卷实例
  • 关键一步：写出延迟环节频率特性，看幅值与相角随频率变化
  • 中间结果：幅值恒为1、相角随频率线性减小，轨迹为圆
  • 卡点：延迟环节幅值不衰减，常被误判为半圆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过判断延迟环节频率特性的极坐标图形状（第5小题）
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 判断ζ不变、ωn增大时上升与峰值时间的变化（第6小题）
本卷实例
  • 关键一步：把上升时间与峰值时间写成含ωn的表达式
  • 中间结果：ωn增大使上升时间与峰值时间减少，超调量不变
  • 卡点：超调量只由ζ决定，提高ωn不会改变它
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过判断ζ不变、ωn增大时上升与峰值时间的变化（第6小题）
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

典型环节的对数频率特性 频域分析

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

步骤
