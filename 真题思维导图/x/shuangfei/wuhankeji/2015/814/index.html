1一、填空题（5小题）25 分#

思路
  • 5小题分别考PD与PID控制规律、离散系统传递函数定义、指数信号的拉氏变换、序列z变换、由单位阶跃响应反求传函
PID 控制器与参数整定 系统校正
本卷考法
  • 填出PD控制器中文全称与PID中具有相位滞后特性的环节（第1小题）
本卷实例
  • 关键一步：由P、I、D各项在时域中的相位作用区分超前与滞后
  • 中间结果：微分项提供超前相位，积分项带来滞后相位
  • 卡点：PD是比例微分，不要与比例积分混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过填出PD控制器中文全称与PID中具有相位滞后特性的环节（第1小题）
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式
脉冲传递函数 离散控制系统
本卷考法
  • 叙述离散系统传递函数的定义（第2小题）
本卷实例
  • 关键一步：从零初始条件下输出采样信号与输入采样信号的关系入手
  • 中间结果：定义写成两路采样信号z变换之比的形式
  • 卡点：丢掉零初始条件会与连续系统定义混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过叙述离散系统传递函数的定义（第2小题）
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)

典型输入信号 基本概念与信号
本卷考法
  • 求两个指数信号之差乘单位阶跃后的拉氏变换（第3小题）
本卷实例
  • 关键一步：按拉氏变换线性性质逐项变换再合并
  • 中间结果：结果由两个一阶极点对应的一阶分式相减组成
  • 卡点：指数衰减项的系数要连同分子一起保留
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 常用典型输入有冲激、阶跃、斜坡、抛物线（加速度）与正弦五类
  • 阶跃信号用于考查快速性与稳定性，斜坡与抛物线用于考查稳态精度
  • 正弦信号用于频域分析，冲激响应就是系统的传递函数
  • 各典型信号的拉氏变换是分析全响应的起点
步骤
  • 按题意写出输入信号的时域表达式
  • 对输入取拉氏变换得到该信号的复域形式
  • 由输入类型判断考查的是动态性能还是稳态精度
  • 把输入代入误差或响应公式计算
通用考法
  • 本卷考过求两个指数信号之差乘单位阶跃后的拉氏变换（第3小题）
  • 写出典型输入信号的拉氏变换
  • 说明某一典型输入信号用于考查哪类性能
  • 由输入类型判断稳态误差是否为有限值
常见易错
  • 把斜坡与抛物线信号的阶次写错
  • 阶跃的拉氏变换漏掉系数（幅度不为 1 时）
公式
z 变换与 z 反变换 离散控制系统
本卷考法
  • 求指数序列(1/5)的2n次方的z变换（第4小题）
本卷实例
  • 关键一步：把序列化为公比的n次方后再套指数序列变换公式
  • 中间结果：分母为z减去该公比，可整理成分式形式
  • 卡点：指数上的系数2要并入公比，不能只取1/5
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • z 变换是离散信号的拉氏变换，令 z=e^{Ts} 得到
  • 常用函数的 z 变换要熟记
  • z 反变换可用部分分式法、幂级数法或留数法
  • 左半 s 平面映射到 z 平面单位圆内
步骤
  • 将连续传递函数展开为部分分式
  • 逐项查表做 z 变换
  • 需要时做 z 反变换求时间序列
通用考法
  • 本卷考过求指数序列(1/5)的2n次方的z变换（第4小题）
  • 求给定函数的 z 变换
  • 求 z 反变换得到采样序列
  • 说明 s 平面与 z 平面的映射关系
常见易错
  • 把 z 变换结果中的 e^{-aT} 写成 e^{-a}
  • 部分分式分解时漏项导致反变换出错
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由一阶系统单位阶跃响应反求系统传递函数（第5小题）
本卷实例
  • 关键一步：从响应表达式读出时间常数与稳态增益
  • 中间结果：传函整理为一阶惯性环节的标准形式
  • 卡点：不要把指数衰减系数误当成增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由一阶系统单位阶跃响应反求系统传递函数（第5小题）
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

2二、判断对错并说明理由（2小题）10 分#

思路
  • 两小题分别判断分子阶次高于分母的闭环传函是否合理、辨析单位阶跃响应导数与传递函数的关系
传递函数的定义与基本性质 传递函数
本卷考法
  • 第1小题判断分子高阶分式的可实现性，第2小题辨析阶跃响应导数与传函
本卷实例
  • 关键一步：第1小题先比较分子与分母的阶次高低
  • 中间结果：分子阶次不低于分母时不满足真有理条件
  • 卡点：第2小题的导数对应单位脉冲响应，别与阶跃响应混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过第1小题判断分子高阶分式的可实现性，第2小题辨析阶跃响应导数与传函
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

3三、方框图化简20 分#

思路
  • 用叠加原理分别令扰动与参考输入为零，逐层化简结构图求两条通道的传递函数
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求参考输入单独作用与扰动单独作用下的传递函数
本卷实例
  • 关键一步：按叠加原理每次只保留一个输入、另一个置零
  • 中间结果：C/R与C/N各由一条前向通道加反馈化简得到
  • 卡点：求扰动通道时容易漏掉参考输入支路的影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求参考输入单独作用与扰动单独作用下的传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 对多回路方框图逐层化简
本卷实例
  • 关键一步：由最内环开始合并，再把结果作为外层环节
  • 中间结果：内环等效环节与串联环节逐层合并
  • 卡点：支路连接以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过对多回路方框图逐层化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

4四、二阶系统极点与动态性能20 分#

思路
  • 由给定闭环共轭极点展开特征多项式，与标准二阶形式对照解出参数，再计算动态指标
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环共轭极点求时间常数、开环增益、阻尼比与自然频率
本卷实例
  • 关键一步：由共轭极点写出特征多项式后与标准二阶形式比系数
  • 中间结果：极点实部绝对值对应阻尼乘积，虚部对应阻尼振荡频率
  • 卡点：试题段极点表达式丢了虚部单位，已据答案段还原
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环共轭极点求时间常数、开环增益、阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率计算超调量和调节时间
本卷实例
  • 关键一步：在欠阻尼条件下套用超调量与调节时间公式
  • 中间结果：超调量只随阻尼比变化，调节时间还受自然频率影响
  • 卡点：调节时间公式的误差带系数随误差带取值不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率计算超调量和调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

五1五、劳斯判据判稳10 分#

思路
  • 对四阶特征方程列劳斯表，由首列符号变化判断稳定性并说明右半平面根数
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判定四阶特征方程的稳定性并说明根的分布
本卷实例
  • 关键一步：逐行计算劳斯表并观察首列符号的变化次数
  • 中间结果：首列符号跳变次数等于右半平面特征根个数
  • 卡点：系数有缺项时先补零再排劳斯表
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判定四阶特征方程的稳定性并说明根的分布
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

五2五、离散系统判稳5 分#

思路
  • 把离散闭环传函分母展开为z的多项式，解出特征根后按模判断稳定性
离散系统稳定性分析 离散控制系统
本卷考法
  • 由离散闭环传递函数判断系统稳定性
本卷实例
  • 关键一步：令特征式为零解出z根再与单位圆比较
  • 中间结果：全部特征根模小于1时离散系统稳定
  • 卡点：先整理成z多项式，不能直接用z的负幂形式求根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
