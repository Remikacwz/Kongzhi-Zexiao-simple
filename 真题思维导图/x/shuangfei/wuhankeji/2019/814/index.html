1一、填空题（6小题）30 分#

思路
  • 6小题分别考PI控制器全称与PID超前环节、z反变换、由阶跃响应求传函、开环零极点与闭环极点、超前校正最大超前角频率、频域指标与时域指标的对应
PID 控制器与参数整定 系统校正
本卷考法
  • 写PI控制器中文全称并指出PID中具有相位超前特性的环节（第1小题）
本卷实例
  • 关键一步：按比例、积分、微分三项的作用区分各环节
  • 中间结果：PI为比例积分；微分项产生超前相位
  • 卡点：相位超前是微分项，积分项相位滞后
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过写PI控制器中文全称并指出PID中具有相位超前特性的环节（第1小题）
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式
z 变换与 z 反变换 离散控制系统
本卷考法
  • 由E(z)的部分分式展开求原序列e(t)（第2小题）
本卷实例
  • 关键一步：先把E(z)/z分解为两项，再乘z查常用z变换对
  • 中间结果：含z/(z−1)与z/(z−2)分别对应阶跃与指数序列
  • 卡点：要先除z展开再乘回z，顺序不能颠倒
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • z 变换是离散信号的拉氏变换，令 z=e^{Ts} 得到
  • 常用函数的 z 变换要熟记
  • z 反变换可用部分分式法、幂级数法或留数法
  • 左半 s 平面映射到 z 平面单位圆内
步骤
  • 将连续传递函数展开为部分分式
  • 逐项查表做 z 变换
  • 需要时做 z 反变换求时间序列
通用考法
  • 本卷考过由E(z)的部分分式展开求原序列e(t)（第2小题）
  • 求给定函数的 z 变换
  • 求 z 反变换得到采样序列
  • 说明 s 平面与 z 平面的映射关系
常见易错
  • 把 z 变换结果中的 e^{-aT} 写成 e^{-a}
  • 部分分式分解时漏项导致反变换出错
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应求系统传递函数（第3小题）
本卷实例
  • 关键一步：对阶跃响应求导得脉冲响应，再取拉氏变换
  • 中间结果：脉冲响应的拉氏变换即为系统传函
  • 卡点：题干OCR残缺，据答案段还原为指数型脉冲响应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应求系统传递函数（第3小题）
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
零极点分布与响应模态 传递函数
本卷考法
  • 由G(s)=(as+1)/[s(s+b)]求开环零点、开环极点与闭环极点（第4小题）
本卷实例
  • 关键一步：分子零点与分母极点直接读，闭环极点由1加G(s)等于零求
  • 中间结果：开环零极点由传函因式定，闭环极点由特征方程根定
  • 卡点：开环极点与闭环极点不要混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由G(s)=(as+1)/[s(s+b)]求开环零点、开环极点与闭环极点（第4小题）
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零
公式
超前校正 系统校正
本卷考法
  • 由超前校正装置传函求最大超前角对应频率ωm（第5小题）
本卷实例
  • 关键一步：由传函零极点时间常数求分度系数a，再代ωm公式
  • 中间结果：ωm等于1/(根号a乘T)，与零极点位置有关
  • 卡点：分度系数取分子分母时间常数之比，不要取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过由超前校正装置传函求最大超前角对应频率ωm（第5小题）
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
校正的基本概念与性能指标 系统校正
本卷考法
  • 指出开环幅值穿越频率ωc对应的时域指标及其反映的动态特性（第6小题）
本卷实例
  • 关键一步：从频域指标与时域指标的对应关系出发判断
  • 中间结果：ωc对应调节时间，反映系统快速性
  • 卡点：ωc不反映平稳性，别写成超调量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过指出开环幅值穿越频率ωc对应的时域指标及其反映的动态特性（第6小题）
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求
公式

2二、光电纠偏器系统分析15 分#

思路
  • 由光电纠偏器原理图指出输入量、输出量与反馈量，说明闭环工作原理并画结构图
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出长距离走料纠偏系统的输入量、输出量与反馈量（第(1)问）
  • 说明反馈控制工作原理并画系统结构图（第(2)(3)问）
本卷实例
  • 关键一步：先找被控量即物料位置，再顺信号流向定输入、反馈与执行环节
  • 中间结果：系统为闭环位置随动系统，光电传感器构成反馈通道
  • 卡点：反馈量是传感器输出电压而非被控位置本身
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指出长距离走料纠偏系统的输入量、输出量与反馈量（第(1)问）
  • 本卷考过说明反馈控制工作原理并画系统结构图（第(2)(3)问）
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

3三、由结构图求传递函数10 分#

思路
  • 把结构图化为信号流图，用梅森公式分别求参考输入与扰动输入下的传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求参考输入下的传递函数C(s)/Rr(s)（第(1)问）
本卷实例
  • 关键一步：列出前向通路G₁G₂与两个回路L₁、L₂
  • 中间结果：无互不接触回路，特征式为1减两回路增益之和
  • 卡点：回路极性与符号要带进特征式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求参考输入下的传递函数C(s)/Rr(s)（第(1)问）
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求扰动输入单独作用下系统的传递函数（第(2)问）
本卷实例
  • 关键一步：令参考输入为零，从扰动作用点到输出重新找前向通路
  • 中间结果：扰动通道前向通路为两路叠加后除同一特征式
  • 卡点：扰动作用点不同，不能直接套参考输入的传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求扰动输入单独作用下系统的传递函数（第(2)问）
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式

4四、由稳态误差与动态指标反求参数30 分#

思路
  • 对G(s)=K/[s(τs+1)]，由斜坡稳态误差要求与单位阶跃动态性能要求分别列K、τ的不等式再取交集
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡输入下稳态误差要求反求开环增益K（条件①）
本卷实例
  • 关键一步：先判为I型系统，再按ess等于1/Kv代入要求
  • 中间结果：斜坡稳态误差是K的倒数形式，据此得K的下界
  • 卡点：先确认稳定条件再谈稳态误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位斜坡输入下稳态误差要求反求开环增益K（条件①）
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由单位阶跃响应的超调量与调节时间要求反求K与τ（条件②）
本卷实例
  • 关键一步：把闭环传函与标准二阶形式对应，写出ξ、ωn与K、τ的关系
  • 中间结果：ωn为根号(K/τ)，ξ为1/(2倍根号(τK))，由σ%和ts要求反推不等式
  • 卡点：两条件都化为K、τ不等式后取交集，并结合稳定性约束筛解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由单位阶跃响应的超调量与调节时间要求反求K与τ（条件②）
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由闭环特征方程给出参数稳定域作为筛选约束
本卷实例
  • 关键一步：令特征多项式各系数为正得稳定条件
  • 中间结果：τ大于零、K大于零是稳定域的基本要求
  • 卡点：稳定域与性能不等式须同时满足，不能只取其一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式

五3五、奈奎斯特判据判稳10 分#

思路
  • 绘出开环系统的Nyquist图，用奈氏判据判定闭环稳定性
频率特性的物理意义与求法 频域分析
本卷考法
  • 写出开环频率特性并绘制Nyquist图（第3小题）
本卷实例
  • 关键一步：求起止点、与负实轴交点及穿越方向
  • 中间结果：ω趋于零时相角为−90°，ω趋于无穷时相角为−270°
  • 卡点：与负实轴交点需令相角为−180°反解频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过写出开环频率特性并绘制Nyquist图（第3小题）
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由幅相曲线的负穿越次数与开环右半平面极点数判定闭环稳定性
本卷实例

  • 中间结果：由Z等于P减2N判断右半平面闭环极点数
  • 卡点：注意穿越方向，负穿越才增加不稳定根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤

  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）

  • 由 Z=N+P 判断闭环稳定性

思路

稳定裕度 频域分析
