一一、简答题：开环系统与反馈#

思路
  • 举出一种日常生活中的开环控制系统，指出被控量与被控对象，再加反馈环节比较其影响
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 举出一种日常生活中的开环控制系统并说明其工作原理
  • 画出方框图并指出被控量与被控对象
  • 加入反馈环节后画方框图并说明影响
本卷实例
  • 关键一步：按给定、控制装置、被控对象与输出的顺序串成开环通道
  • 中间结果：加入反馈后比较给定与反馈量并据此修正控制作用
  • 卡点：只画方框图而不指认环节会漏答一半
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过举出一种日常生活中的开环控制系统并说明其工作原理
  • 本卷考过画出方框图并指出被控量与被控对象
  • 本卷考过加入反馈环节后画方框图并说明影响
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把被控量与操纵量搞反
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

二二、结构图求传函与扰动不变性#

思路
  • 由结构图分别求 C(s)/R(s) 与扰动传函；再令扰动对输出的影响为零，反求满足不变性的环节
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图画信号流图并用梅森公式求 C(s)/R(s)
本卷实例
  • 关键一步：先数清独立回路与前向通路并写出特征式
  • 中间结果：前向通路增益乘各自余子式后求和再除以特征式
  • 卡点：回路与前向通路的接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图画信号流图并用梅森公式求 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过余子式中未剔除与前向通路接触的回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

三三、由阶跃响应反求系统参数#

思路
  • 由负反馈二阶系统的单位阶跃响应曲线求传递函数，读出阻尼比与自然频率并反求系统参数

本卷考法

本卷实例

  • 超调量只由阻尼比 ξ 决定

  • 时间常数由响应达到稳态值 63.2% 的时刻给出

  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益

  • 由实验阶跃响应曲线求传递函数

  • 未判断系统阶数就直接套用二阶公式

思路
  • 先把开环传函整理成标准形式，再按零极点分布绘根轨迹，由欠阻尼条件确定开环增益范围
根轨迹的绘制法则 根轨迹法
本卷考法

本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤

  • 计算渐近线交点与夹角

  • 按对称性连接各段并标出对应 K 值

  • 关键一步：把相频拆成积分环节与各惯性环节的相角之和

  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示

思路
  • 写出非线性环节的描述函数与线性部分的频率特性，由负倒描述函数与 G(jω) 的交点求自振频率与幅值
描述函数法基础 非线性系统
本卷考法
  • 写出给定非线性环节的描述函数
本卷实例
  • 关键一步：按非线性特性用一次谐波近似求描述函数
  • 中间结果：描述函数表现为输入幅值的函数
  • 卡点：把描述函数当成频率的函数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过写出给定非线性环节的描述函数
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

用描述函数法分析自振 非线性系统
本卷考法
  • 用描述函数法求系统的自激振荡频率与幅值
本卷实例
  • 关键一步：令负倒描述函数与线性部分频率特性相等
  • 中间结果：交点频率为自振频率、对应幅值为自振幅值
  • 卡点：未标注幅值增大方向就判断稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过用描述函数法求系统的自激振荡频率与幅值
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率

九九、离散系统传函与采样输出响应#

思路
  • 按零阶保持器求开环与闭环脉冲传函，再由 z 反变换求单位阶跃下的采样输出响应
脉冲传递函数 离散控制系统
本卷考法
  • 求离散系统的开环与闭环脉冲传递函数
本卷实例
  • 关键一步：对连续部分乘零阶保持器后取 z 变换再组合
  • 中间结果：开环脉冲传函代入单位反馈关系得闭环传函
  • 卡点：采样开关位置不同会使脉冲传函的写法不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过求离散系统的开环与闭环脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 本卷考过忘记把零阶保持器计入脉冲传函
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)

  • 常用函数的 z 变换要熟记

  • 左半 s 平面映射到 z 平面单位圆内
步骤

  • 求给定函数的 z 变换
  • 求 z 反变换得到采样序列
  • 说明 s 平面与 z 平面的映射关系
常见易错

  • 部分分式分解时漏项导致反变换出错
