一一、谷物湿度控制系统#

思路
  • 按闭环回路对号给定、被控量、被控对象与执行元件，再说明湿度偏差调节水流量的过程
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 画出谷物湿度控制系统方框图并指出被控量、被控对象与给定量
本卷实例
  • 关键一步：按给定、比较、控制器、执行器、对象、检测反馈逐个对号
  • 中间结果：被控量为谷物湿度，执行元件为加湿自动阀门
  • 卡点：系统示意图以图给出，被控量与操纵量须回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过画出谷物湿度控制系统方框图并指出被控量、被控对象与给定量
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 说明谷物湿度控制系统的工作原理
本卷实例
  • 关键一步：两个湿度测量装置分别测进出口湿度并反馈给调节器
  • 中间结果：调节器据偏差控制加湿阀门的水量
  • 卡点：只画方框图不指认环节或反之会漏答一半
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过说明谷物湿度控制系统的工作原理
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半

二二、RC 网络建模与环节识别#

思路
  • 由 RC 网络求传递函数并识别典型环节，再由单位阶跃响应的拉氏变换求响应并画图
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由 RC 电网络求输出对输入的传递函数
本卷实例
  • 关键一步：按串并联与分压关系用复阻抗列式再约分
  • 中间结果：传函为一阶惯性式，分母含 RC 时间常数
  • 卡点：电网络以图给出，元件接法须回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由 RC 电网络求输出对输入的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 用复阻抗法求一阶 RC 网络传递函数
本卷实例
  • 关键一步：电容用 1 比 Cs 代入后按分压列式
  • 中间结果：时间常数由电阻与电容的乘积给出
  • 卡点：把电容阻抗误写成 Cs
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过用复阻抗法求一阶 RC 网络传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
典型环节及其特性 传递函数
本卷考法
  • 指出所求传递函数属于哪种典型环节
本卷实例
  • 关键一步：把传函化为时间常数标准形式后与典型环节对照
  • 中间结果：分母一阶分子常数对应惯性环节
  • 卡点：把一阶微分环节与纯微分环节混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过指出所求传递函数属于哪种典型环节
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减
公式
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 求一阶系统的单位阶跃响应并画图像
本卷实例
  • 关键一步：阶跃响应的拉氏变换部分分式展开后反变换
  • 中间结果：响应由稳态分量与衰减指数分量组成
  • 卡点：增益不为一时仍直接读稳态值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过求一阶系统的单位阶跃响应并画图像
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式

三三、由阶跃响应反求传函与动态性能#

思路
  • 由给定阶跃响应反求传递函数，再按结构图化为二阶标准形式求峰值时间与调节时间，最后求阶跃输入下的稳态误差
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应表达式反求系统传递函数
本卷实例
  • 关键一步：由稳态值与时间常数或响应导数写传递函数
  • 中间结果：响应形式对应一阶或二阶传函
  • 卡点：题干有歧义，按开环或闭环阶跃响应理解会得到不同传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应表达式反求系统传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环特征式化为二阶标准形式读阻尼比与自然频率
本卷实例
  • 关键一步：由特征式一次项与常数项反解两个二阶参数
  • 中间结果：标准式二次项系数需归一化
  • 卡点：忘记归一化 s 平方项系数会读错参数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环特征式化为二阶标准形式读阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由二阶参数求峰值时间与调节时间
本卷实例
  • 关键一步：按给定误差带选取调节时间系数并代入
  • 中间结果：峰值时间由阻尼自然频率的虚部决定
  • 卡点：峰值时间与上升时间混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由二阶参数求峰值时间与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求阶跃输入下的稳态误差
本卷实例
  • 关键一步：由开环传函求静态位置误差系数再代入误差公式
  • 中间结果：稳态误差由开环增益与系统型别决定
  • 卡点：非单位反馈时误差定义不同会差一个反馈环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求阶跃输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

四四、由正弦稳态响应反求传函参数#

思路
  • 由结构和正弦输入输出关系写闭环频率特性，用输出幅值与相角反求增益与时间常数
频率特性的物理意义与求法 频域分析
本卷考法
  • 由正弦稳态响应的幅值与相角反求系统参数
本卷实例
  • 关键一步：代入输入频率用幅值比与相位差列两个方程
  • 中间结果：输出与输入的幅值比等于幅频相位差等于相频
  • 卡点：结构图以图给出，环节接法与反馈极性须回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由正弦稳态响应的幅值与相角反求系统参数
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
典型环节及其特性 传递函数
本卷考法
  • 由闭环频率特性识别一阶惯性环节形式
本卷实例
  • 关键一步：把闭环传函化为时间常数标准形式
  • 中间结果：闭环为一阶惯性环节，增益与时间常数待定
  • 卡点：把相位滞后与时间常数的关系记反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响

思路
  • 由非线性环节写负倒描述函数，求线性部分与实轴交点，再由奈氏判据定系统稳定的增益范围
描述函数法基础 非线性系统
本卷考法
  • 写出非线性环节的负倒描述函数并画其轨迹
本卷实例

  • 中间结果：负倒描述函数单调变化且起止点有限

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统

奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据判别含非线性环节系统的稳定性
本卷实例
  • 关键一步：按 Z 等于 P 减 2N 计算右半平面闭环极点数
  • 中间结果：开环右半平面极点数与包围圈数决定闭环稳定性
  • 卡点：没有先数开环右半平面极点数 P
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据判别含非线性环节系统的稳定性

常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
