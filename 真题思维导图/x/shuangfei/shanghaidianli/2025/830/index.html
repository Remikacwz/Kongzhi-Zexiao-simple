1控制系统基本方式与反馈系统设计15 分#

思路
  • 先判断「人按指定路线驾驶」属开环还是闭环，再设计自动驾驶反馈系统需要哪些部件
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 分析给定过程并用方框图表示，判断是开环还是闭环
本卷实例
  • 关键一步：关键看有没有「检测实际输出并反馈比较」的环节——没有就是开环
  • 关键一步：人凭眼睛观察路况不断修正方向，本质上存在反馈，但若题目描述为「按预设路线」则按给定描述判
  • 中间结果：方框图只有给定→控制器→执行→对象单向通道，无反馈支路
  • 卡点：只按「有没有人参与」判断，而不是按「有没有反馈回路」判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过分析给定过程并用方框图表示，判断是开环还是闭环
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 设计自动驾驶反馈控制系统的主要部件并画方框图
本卷实例
  • 关键一步：四要素：检测变送（位置/航向传感器）+ 控制器 + 执行器（转向机构）+ 被控对象（车辆）
  • 关键一步：还要有给定装置（期望路线）与比较环节
  • 中间结果：传感器测实际航向或位置，与期望路线比较后产生偏差信号
  • 卡点：漏掉检测变送环节，方框图不闭环
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过设计自动驾驶反馈控制系统的主要部件并画方框图
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半

2多输入系统的传函与扰动不变性15 分#

思路
  • R(s)、D₁(s)、D₂(s) 三个输入，线性系统可用叠加；第 3 问让 C 不受 D₁ 影响即令 D₁→C 通道的分子为零
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求 C/R、C/D₁、C/D₂ 三个传递函数并写出 C(s) 表达式
本卷实例
  • 关键一步：每次只保留一个输入、其余置零，逐个求传递函数
  • 关键一步：总输出按叠加原理把三项相加
  • 中间结果：三个传函分别令其余输入为零单独求，再按叠加写成 C 的表达式
  • 卡点：求扰动传函时没有把参考输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求 C/R、C/D₁、C/D₂ 三个传递函数并写出 C(s) 表达式
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

反馈校正与复合控制 系统校正
本卷考法
  • 设计 Gf(s) 使输出不受扰动 D₁(s) 影响
本卷实例
  • 关键一步：写出含 Gf 的 D₁→C 传函，令其分子为零 → 得到完全不变性条件
  • 关键一步：前馈补偿器不影响原回路特征方程，稳定性不变
  • 中间结果：Gf(s) 常写成两条通道传递函数之比的相反数
  • 卡点：求出的 Gf 含高阶微分不可实现，需要补惯性环节说明
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过设计 Gf(s) 使输出不受扰动 D₁(s) 影响
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

3由阶跃响应反求控制器与选型20 分#

思路
  • 第 1 问由单位阶跃响应 1−e^(−2t) 反求 Gc；第 2 问比例控制器下的阻尼与稳态；第 3 问按「扰动误差为零」选控制器类型
由响应曲线反求传递函数 传递函数
本卷考法
  • 由控制器单位阶跃响应 x(t)=1−e^{−2t} 求其传递函数 Gc(s)
本卷实例
  • 关键一步：x(t)=1−e^{−2t} 是典型一阶惯性响应，稳态值 1、时间常数 1/2
  • 关键一步：对 x(t) 取拉氏变换后除以 1/s（阶跃输入）即得 Gc(s)=2/(s+2)
  • 中间结果：阶跃响应拉氏变换 X(s)=2/[s(s+2)]，再除以阶跃的 1/s
  • 卡点：直接拿 x(t) 当传递函数，忘记除以 1/s
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由控制器单位阶跃响应 x(t)=1−e^{−2t} 求其传递函数 Gc(s)
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • Gc=4 时求闭环传函并分析阻尼状态
本卷实例
  • 关键一步：把 Gc=4 代入回路写闭环传函，再与二阶标准式逐项对照
  • 关键一步：先看 s² 项系数是否为 1，不为 1 时先归一化
  • 中间结果：对照 2ζωn 与 ωn² 两式可读出阻尼比和无阻尼频率
  • 卡点：化标准式时忘记把 s² 项系数归一化，ζ 与 ωn 会读错
  • 卡点：反馈点与扰动注入点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过Gc=4 时求闭环传函并分析阻尼状态
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过化为标准形式时忘记把 s² 项系数归一化
  • 化为标准形式时忘记把 s² 项系数归一化

典型输入下的稳态误差计算 稳态误差
本卷考法

本卷实例

PID 控制器与参数整定 系统校正
本卷考法
  • 从 P、PI、PD、PID 中选型使扰动稳态误差 essn=0，并说明理由
本卷实例
  • 关键一步：要稳态误差为零，控制器必须含积分作用——只有 PI 和 PID 满足
  • 关键一步：扰动作用点在控制器之后时，积分环节能把该点的常值扰动误差压到零
  • 关键一步：再结合有无微分说明 PID 为何比 PI 动态更好
  • 关键一步：但要说明 PI 已足够满足 essn=0
  • 中间结果：P 和 PD 对常值扰动都有残余误差，一票否决
  • 卡点：只答「选 PID 最好」而不说明 PI 也能满足零误差，答案不完整
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过从 P、PI、PD、PID 中选型使扰动稳态误差 essn=0，并说明理由
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

根轨迹的绘制法则 根轨迹法
本卷考法
  • 由根轨迹图写出开环传递函数 G₀(s) 及根轨迹方程
本卷实例
  • 关键一步：从图读实轴根轨迹的起点和终点，定开环极点与零点个数
  • 关键一步：由渐近线交点与夹角反推开环极点的重心位置
  • 中间结果：三条渐近线交于开环极点实部均值
  • 中间结果：无开环零点时根轨迹方程由 1+k·G₀(s)=0 给出
  • 卡点：渐近线交点算错会连带把开环极点重心和 G₀ 写错
  • 卡点：极点坐标与分离点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法

  • 判断某段实轴是否属于根轨迹
常见易错

  • 实轴段判据中的零极点个数算错
