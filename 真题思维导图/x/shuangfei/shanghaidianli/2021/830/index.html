一一、冰箱温度控制系统#

思路
  • 按闭环回路对号给定量、被控量与被控对象，再说明温度偏差驱动压缩机制冷的工作过程
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 画出冰箱温度控制系统方框图并指出被控量与被控对象
本卷实例
  • 关键一步：按给定、比较、控制器、执行器、对象、检测反馈逐个对号
  • 中间结果：被控对象为冰箱，被控量为箱内实际温度
  • 卡点：被控量与操纵量容易互换，须回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过画出冰箱温度控制系统方框图并指出被控量与被控对象
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 简述冰箱温度控制系统的工作原理
本卷实例
  • 关键一步：温度传感器检测箱温并与设定值比较得偏差
  • 中间结果：偏差经继电器控制压缩机启停以调节制冷量
  • 卡点：只画方框图不指认环节或反之会漏答一半
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过简述冰箱温度控制系统的工作原理
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半

二二、有源网络建模与特征方程#

思路
  • 用电路定律或复阻抗法求输出对输入的传函，再由分母多项式写特征方程并判断阶数
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由有源网络电路求输出电压对输入电压的传递函数
本卷实例
  • 关键一步：设电容电压为中间变量按电路方程消元整理
  • 中间结果：传函分母为二次多项式分子为常数
  • 卡点：网络以图给出，元件接法与电流方向须回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由有源网络电路求输出电压对输入电压的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 用复阻抗法求电路网络传递函数
本卷实例
  • 关键一步：把电容阻抗写成 1 比 Cs 后按串并联与分压列式
  • 中间结果：分母由两个时间常数的乘积构成
  • 卡点：复阻抗法把电容阻抗误写成 Cs
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过用复阻抗法求电路网络传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
传递函数的定义与基本性质 传递函数
本卷考法
  • 由传递函数分母写特征方程并指出系统阶数
本卷实例
  • 关键一步：令传递函数分母等于零得特征方程
  • 中间结果：分母最高次幂即系统阶数
  • 卡点：忽略零初始条件前提会把初值带入变换结果
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由传递函数分母写特征方程并指出系统阶数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

三三、结构图求传函与扰动不变性#

思路
  • 用梅森公式分别求 C 比 R、C 比 D 与 E 比 R，再由叠加写 C(s) 并令扰动通道为零解补偿环节
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求 C(s) 比 R(s) 与 E(s) 比 R(s)
本卷实例
  • 关键一步：先数清全部回路与前向通道再写特征式
  • 中间结果：两个回路均与各前向通道接触故余子式为 1
  • 卡点：不接触回路找漏或重复计数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求 C(s) 比 R(s) 与 E(s) 比 R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 由结构图写出误差传递函数 E(s) 比 R(s)
本卷实例
  • 关键一步：从主回路相加点取误差沿前向通道求传函
  • 中间结果：误差传函分母为系统特征式
  • 卡点：误差相加点取在输出端而不是主回路相加点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由结构图写出误差传递函数 E(s) 比 R(s)
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求扰动到输出的传函并求使影响为零的补偿环节
本卷实例
  • 关键一步：令参考输入为零单独求扰动通道传函再令它为零
  • 中间结果：补偿环节由扰动前向通道增益之比给出
  • 卡点：求扰动传函时没有把参考输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求扰动到输出的传函并求使影响为零的补偿环节
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

四四、由响应曲线反求二阶参数#

思路
  • 由闭环传函化为二阶标准形式，利用超调量与峰值时间反求增益、阻尼比与自然频率，再算调节时间
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应曲线反求闭环传递函数与系统参数
本卷实例
  • 关键一步：由响应曲线的稳态值、峰值与峰值时间读增益与二阶参数
  • 中间结果：闭环特征式可化为带反馈项的二次式
  • 卡点：响应曲线与结构图均以图给出，须回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应曲线反求闭环传递函数与系统参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环特征式化为二阶标准形式读阻尼比与自然频率
本卷实例
  • 关键一步：整理特征式后与二次标准式逐项对照
  • 中间结果：一次项系数定阻尼比常数项定自然频率平方
  • 卡点：二次项系数不为一时忘记归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环特征式化为二阶标准形式读阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率求调节时间并写出阶跃响应表达式
本卷实例
  • 关键一步：按给定的误差带选取调节时间系数
  • 中间结果：响应为衰减指数与正弦的乘积形式
  • 卡点：两种误差带对应的调节时间系数搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率求调节时间并写出阶跃响应表达式
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

五五、一阶系统稳态误差与正弦稳态响应#

思路
  • 由结构图写闭环传函，分别求阶跃输入下的稳态误差、正弦输入的稳态响应，再画阶跃响应曲线
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位负反馈系统在阶跃输入下的稳态误差
本卷实例
  • 关键一步：先判稳再用终值定理或误差系数求稳态误差
  • 中间结果：一阶系统对阶跃输入稳态误差为有限值
  • 卡点：未判稳就套用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查

十十、描述函数法分析自持振荡#

思路
  • 由非线性环节写负倒描述函数并画轨迹，与线性部分奈氏曲线比较判断自振并求频率与振幅
描述函数法基础 非线性系统
本卷考法
  • 写出非线性环节的描述函数与负倒描述函数并画轨迹
本卷实例
  • 关键一步：由描述函数取倒数取负令振幅从零到无穷观察轨迹走向
  • 中间结果：负倒描述函数随振幅单调变化
  • 卡点：画成描述函数本身而不是它的负倒数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过写出非线性环节的描述函数与负倒描述函数并画轨迹
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

用描述函数法分析自振 非线性系统
本卷考法
  • 由负倒描述函数与奈氏曲线判断是否自振并求参数
本卷实例
  • 关键一步：先令线性部分相位为负一百八十度求与实轴交点
  • 中间结果：两曲线交点处由振幅增大方向判断极限环稳定与否
  • 卡点：非线性环节以图给出，须回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过由负倒描述函数与奈氏曲线判断是否自振并求参数
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率
