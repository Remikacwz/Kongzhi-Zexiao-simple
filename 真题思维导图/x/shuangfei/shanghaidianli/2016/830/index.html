上海电力大学 830 自动控制理论（含现控） 2016 年真题思维导图

强势双非共 8 题

难度：中等　逐年试题册，选择 10 题加填空 10 题加计算 6 题；覆盖劳斯判据与稳定域、静态误差系数、串联校正装置识别、根轨迹实轴段、由 Bode 渐近线反求传函、二阶系统时域指标、幅值裕量、局部反馈与稳态误差以及传感器反馈。多题依附原卷插图。

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

一一、选择题（1~10）40 分#

思路
  • 以劳斯判据、静态误差系数、校正装置类型与根轨迹实轴段为主线，逐题对号入座
劳斯判据 稳定性分析
本卷考法
  • 用劳斯表判断给定特征方程的正实部根个数
  • 求使单位反馈系统临界稳定的开环增益
本卷实例
  • 关键一步：列出劳斯表并数第一列符号改变次数
  • 中间结果：符号改变次数等于右半平面特征根个数
  • 卡点：系数有缺项时不补零就套用判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯表判断给定特征方程的正实部根个数
  • 本卷考过求使单位反馈系统临界稳定的开环增益
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 判断系统型别并求单位阶跃输入下的位置误差
本卷实例
  • 关键一步：由开环传函中积分环节个数确定系统型别
  • 中间结果：零型系统阶跃输入下位置误差为有限非零值
  • 卡点：把开环增益当成静态位置误差系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断系统型别并求单位阶跃输入下的位置误差
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 写出稳态误差与误差信号象函数之间的极限关系
本卷实例
  • 关键一步：按终值定理写 ess 为 s 趋于零时 s 乘 E(s) 的极限
  • 中间结果：关系式由拉氏变换终值定理给出
  • 卡点：未判稳就套用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写出稳态误差与误差信号象函数之间的极限关系
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
滞后校正 系统校正
本卷考法
  • 识别给定串联校正装置属于超前还是滞后
本卷实例
  • 关键一步：比较传递函数零点与极点时间常数的相对大小
  • 中间结果：极点时间常数大于零点时间常数即属滞后
  • 卡点：把滞后网络两个转折频率顺序写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过识别给定串联校正装置属于超前还是滞后
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
超前校正 系统校正
本卷考法
  • 指出相位超前校正装置奈氏曲线的形状
本卷实例
  • 关键一步：写出超前网络在复平面上的幅相轨迹
  • 中间结果：超前网络的奈氏曲线为上半圆
  • 卡点：把超前与滞后网络的半圆方向搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过指出相位超前校正装置奈氏曲线的形状
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 判断给定开环传函在实轴上的根轨迹区间
本卷实例
  • 关键一步：按实轴段判据数该点右侧开环零极点总个数
  • 中间结果：右侧零极点个数之和为奇数即属于根轨迹
  • 卡点：实轴段判据中零极点个数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过判断给定开环传函在实轴上的根轨迹区间
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 指出提高稳定性最方便的措施及其代价
本卷实例
  • 关键一步：分析减小增益对稳定裕度与稳态误差的双向影响
  • 中间结果：减小增益提高稳定性但会增大稳态误差
  • 卡点：只谈稳定性提高而不提稳态精度变差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过指出提高稳定性最方便的措施及其代价
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出测速反馈环节在直流调速系统中检测的反馈量
本卷实例
  • 关键一步：按被控量判断反馈传感器测量的物理量
  • 中间结果：霍尔传感器用于检测转速并作速度反馈
  • 卡点：把反馈量与被控对象搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指出测速反馈环节在直流调速系统中检测的反馈量
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

二二、填空题（1~10）40 分#

思路
  • 以一阶与二阶系统基本概念、稳态误差、校正条件与频域特性为主，逐空填结论
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 求一阶系统单位斜坡响应的稳态误差与时间常数的关系
本卷实例
  • 关键一步：对一阶传函乘斜坡象函数后取时间响应
  • 中间结果：斜坡输入下的稳态误差等于时间常数
  • 卡点：把稳态值当成时间常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过求一阶系统单位斜坡响应的稳态误差与时间常数的关系
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
典型环节及其特性 传递函数
本卷考法
  • 指出惯性环节输入变化时输出不能突变的特点
本卷实例
  • 关键一步：由一阶惯性环节的时域响应判断输出变化规律
  • 中间结果：惯性环节输出按指数规律变化
  • 卡点：把惯性环节与一阶微分环节混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过指出惯性环节输入变化时输出不能突变的特点
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减

公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 由开环传函判断高频段对数幅频渐近线的斜率
本卷实例
  • 关键一步：数分子分母相对阶数确定高频段斜率
  • 中间结果：高频斜率等于分母与分子阶数差乘负二十
  • 卡点：逐段改斜率时忘记累加而非替换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法

要点

  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度

三6三6、局部反馈回路稳定性与稳态误差#

思路
  • 先逐层化简含局部反馈的结构图求闭环特征式，再判稳定范围并求加速度误差系数
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 化简含局部反馈的多回路结构图求闭环传函
本卷实例
  • 关键一步：先合并内环再与外环串联化简
  • 中间结果：闭环分母为含局部反馈增益的三次式
  • 卡点：化简内环时把外环信号当成常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过化简含局部反馈的多回路结构图求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简

本卷实例

  • 卡点：系数有缺项时不补零就套用判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由劳斯判据求局部反馈系数的稳定范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
