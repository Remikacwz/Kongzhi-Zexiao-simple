一一、简答题：PID、稳态误差与稳定判据#

思路
  • 分别回答 PID 各环节对性能的影响、稳态误差的定义与影响因素、判断系统稳定性的常用方法
PID 控制器与参数整定 系统校正
本卷考法
  • 分析比例、积分、微分控制对系统性能的影响与优缺点
本卷实例
  • 关键一步：按比例影响精度与稳定性、积分提高型别、微分改善快速性分类讨论
  • 中间结果：积分引入开环极点并产生相角滞后、微分对噪声敏感
  • 卡点：易把微分控制说成对稳态误差也有影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过分析比例、积分、微分控制对系统性能的影响与优缺点
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 本卷考过把 PI 的相位影响说成超前
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

思路

  • 采用扰动补偿可提高扰动不变性
步骤

  • 校验补偿后系统仍然稳定
