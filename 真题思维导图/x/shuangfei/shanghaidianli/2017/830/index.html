上海电力大学 830 自动控制理论（含现控） 2017 年真题思维导图

强势双非共 7 题合计 150 分

一一、选择题（1~10）40 分#

思路
  • 以负反馈性质、稳态误差、判稳与零度根轨迹、相角裕度、校正装置类型为主线，逐题定位
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出采用负反馈后对系统稳定性与动态性能的影响
本卷实例
  • 关键一步：负反馈降低增益并改变极点零点位置
  • 中间结果：适度负反馈提高稳定性与准确性但降低响应速度
  • 卡点：把负反馈的作用说成一定使闭环更稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指出采用负反馈后对系统稳定性与动态性能的影响
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
减小稳态误差的措施 稳态误差
本卷考法
  • 判断哪种措施对降低稳态误差没有效果
本卷实例
  • 关键一步：按系统型别与开环增益分析各措施对误差的影响
  • 中间结果：增加开环零点不改变型别故对消差无直接效果
  • 卡点：只谈误差减小而不检查稳定性是否被破坏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过判断哪种措施对降低稳态误差没有效果
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式
劳斯判据 稳定性分析
本卷考法
  • 由特征方程判断系统稳定性与右半平面极点数
本卷实例
  • 关键一步：分解特征方程或列劳斯表判断根的分布
  • 中间结果：特征方程分解为一阶与二阶因式便于判稳
  • 卡点：系数有缺项时不补零就套用判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由特征方程判断系统稳定性与右半平面极点数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由抛物线输入下稳态误差无穷判断系统型别
本卷实例
  • 关键一步：比较输入阶次与系统型别确定误差是否为有限值
  • 中间结果：型别小于输入阶次时误差趋于无穷
  • 卡点：数错积分环节个数导致型别判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由抛物线输入下稳态误差无穷判断系统型别
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 判断应当绘制零度根轨迹的情形
本卷实例
  • 关键一步：按根轨迹方程的相角条件区分零度与一百八十度
  • 中间结果：正反馈或根轨迹方程为加一对应零度根轨迹
  • 卡点：零度根轨迹仍沿用一百八十度相角条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过判断应当绘制零度根轨迹的情形
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
稳定裕度 频域分析
本卷考法
  • 指出相角裕度对应的时域性能指标与判稳条件
本卷实例
  • 关键一步：由相角裕度与幅值裕度共同判断稳定性
  • 中间结果：相角裕度大于零且幅值裕度大于零时系统稳定
  • 卡点：把相角裕度与幅值裕度两个频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过指出相角裕度对应的时域性能指标与判稳条件
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅频特性曲线判断哪个系统不稳定
本卷实例
  • 关键一步：判稳需同时看开环右半平面极点数与曲线包围次数
  • 中间结果：曲线包围临界点圈数不为零时闭环不稳定
  • 卡点：没有先数开环右半平面极点数 P
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环幅频特性曲线判断哪个系统不稳定
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
滞后校正 系统校正
本卷考法
  • 由传递函数判断串联校正装置属于超前还是滞后
本卷实例
  • 关键一步：比较分子分母一次项时间常数大小
  • 中间结果：极点时间常数大于零点时间常数即属滞后
  • 卡点：把滞后网络两个转折频率顺序写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过由传递函数判断串联校正装置属于超前还是滞后
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
超前校正 系统校正
本卷考法
  • 比较各超前网络在指定频率处提供的超前角大小
本卷实例
  • 关键一步：分别计算各网络微分环节在该频率的相角
  • 中间结果：微分环节时间常数越大提供的超前角越大
  • 卡点：计算补偿角时方向取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过比较各超前网络在指定频率处提供的超前角大小
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

传递函数的定义与基本性质 传递函数
本卷考法
  • 说明传递函数在零初始条件下的定义
  • 写出数学模型的影响因素
本卷实例
  • 关键一步：按零初始条件下输出与输入拉氏变换之比定义传函
  • 中间结果：传函由系统结构与参数决定与外作用和初值无关
  • 卡点：忽略零初始条件这一前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过说明传递函数在零初始条件下的定义
  • 本卷考过写出数学模型的影响因素
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 写出一阶与二阶系统传递函数的标准形式
本卷实例
  • 关键一步：把二阶传函分母归一后与标准式对照
  • 中间结果：二阶标准式由自然频率与阻尼比决定
  • 卡点：二次项系数不为一忘记归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
