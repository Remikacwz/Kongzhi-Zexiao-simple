上海电力大学 830 自动控制理论（含现控） 2018 年真题思维导图

强势双非共 7 题

难度：中等　逐年试题册，选择10题加填空10小空加计算5题；覆盖基本概念与控制元件、系统辨识、典型环节与传函标准形式、结构图化简与梅森公式、一阶与二阶动态指标、稳态误差、劳斯判据、正弦稳态输出、参数根轨迹与欠阻尼范围、由Bode渐近线反求传函以及扰动不变性补偿。三1、三3、三5题依附原卷插图。

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

一一、选择题（1~10）40 分#

思路
  • 以系统辨识与元件分类、典型环节、传函定义、梅森公式、一阶与二阶性能、频率特性为主线逐题定位。
由响应曲线反求传递函数 传递函数
本卷考法
  • 区分由输入输出数据确定系统结构与参数的过程名称
本卷实例
  • 关键一步：把已知输入输出反求模型归入系统辨识
  • 中间结果：系统辨识以实验数据反求模型，区别于对已知系统作性能分析
  • 卡点：把系统辨识与系统分析混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过区分由输入输出数据确定系统结构与参数的过程名称
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出对两路及多路信号作加减运算的元件
本卷实例
  • 关键一步：按元件功能把比较器与放大器、执行元件区分开
  • 中间结果：比较器完成输入与反馈信号的加减运算
  • 卡点：把比较元件说成放大元件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指出对两路及多路信号作加减运算的元件
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

典型环节及其特性 传递函数
本卷考法
  • 分解给定传递函数判断由哪些典型环节串联而成
本卷实例
  • 关键一步：把传函拆成比例、积分、微分、惯性等标准因子之积
  • 中间结果：出现 1/s 为积分环节、出现 s 为微分环节
  • 卡点：把一阶微分环节与纯微分环节混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过分解给定传递函数判断由哪些典型环节串联而成
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减

传递函数的定义与基本性质 传递函数
本卷考法
  • 由线性微分方程在零初始条件下写传递函数
本卷实例
  • 关键一步：对微分方程两边取拉氏变换并令初值为零
  • 中间结果：整理成输出比输入的多项式之比
  • 卡点：忽略零初始条件这一前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由线性微分方程在零初始条件下写传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 指出梅逊增益公式的主要用途
本卷实例
  • 关键一步：梅逊公式用于由信号流图求系统传递函数
  • 中间结果：把回路增益与前向通路代入公式求总传函
  • 卡点：把梅逊公式的用途说成判断稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过指出梅逊增益公式的主要用途
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 判断一阶系统增益对阶跃响应稳态值的影响
本卷实例
  • 关键一步：由终值定理求一阶系统阶跃响应的稳态值
  • 中间结果：稳态值随增益K减小而减小
  • 卡点：把增益K与时间常数T的作用混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过判断一阶系统增益对阶跃响应稳态值的影响
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 指出只与阻尼比有关的二阶欠阻尼性能指标
本卷实例
  • 关键一步：比较各性能指标表达式对自然频率的依赖
  • 中间结果：最大超调量只与阻尼比有关，其余指标还与自然频率有关
  • 卡点：把调节时间误认为只与阻尼比有关
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过指出只与阻尼比有关的二阶欠阻尼性能指标
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

频率特性的物理意义与求法 频域分析
本卷考法
  • 说明实验测取幅频特性时改变的量
本卷实例
  • 关键一步：按幅频特性为幅值比与频率的关系理解
  • 中间结果：改变输入信号的频率逐点测得输出幅值
  • 卡点：把改变幅值误当作改变频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过说明实验测取幅频特性时改变的量
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
