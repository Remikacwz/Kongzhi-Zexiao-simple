传递函数的定义与基本性质 传递函数
本卷考法
  • 说明线性系统的两层含义
本卷实例
  • 关键一步：按线性系统定义拆出两条性质
  • 中间结果：即可叠加性与齐次性
  • 卡点：线性性质是传递函数成立的前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过说明线性系统的两层含义
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过把叠加性与齐次性混为一谈
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

本卷考法

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 由相频特性求 ∠G=-180° 对应的频率 ωg

  • 由裕度符号判断稳定性

  • 把 ωc 与 ωg 两个频率用反
