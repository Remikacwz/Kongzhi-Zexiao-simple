一一、由微分方程求初值与终值并用实数域表达式验证15 分#

思路
  • 对一阶微分方程作拉氏变换求出输出的像函数，用初值定理与终值定理求两端值；再作部分分式展开与反变换得时域全响应，并用响应表达式复核两个端值
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 对给定一阶微分方程作拉氏变换求全响应
本卷实例
  • 关键一步：对方程两边作拉氏变换并代入零初始条件
  • 中间结果：解出输出像函数并按部分分式展开
  • 卡点：初值与终值定理成立的条件需先确认
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过对给定一阶微分方程作拉氏变换求全响应
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 本卷考过用终值定理前未检查输出是否收敛
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上
公式
传递函数的定义与基本性质 传递函数
本卷考法
  • 由微分方程写出系统传递函数
本卷实例
  • 关键一步：把输出与输入的微分算子之比写成传函
  • 中间结果：传函为输入输出算子多项式之比
  • 卡点：传函只在零初始条件下成立
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由微分方程写出系统传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过忽略零初始条件这一前提
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

思路

减小稳态误差的措施 稳态误差
本卷考法
  • 说明增大开环增益对误差与稳定性的双重影响
本卷实例
  • 关键一步：比较增益变化对误差与稳定裕度的影响
  • 中间结果：增益过大时稳定裕度下降
  • 卡点：设计需在精度与稳定之间折中
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过说明增大开环增益对误差与稳定性的双重影响
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错

  • 只谈误差减小而不检查稳定性是否被破坏

三三、根轨迹概念与正反馈系统的分离点、根轨迹及稳定范围#

思路
  • 先写出根轨迹的定义与相角、幅值条件；再对正反馈的开环传函按0度根轨迹求分离点，绘制闭环根轨迹并确定使系统稳定的增益范围。本题两个源均未印分值，按铁律3留空
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 写出根轨迹的定义及相角条件与幅值条件公式
本卷实例
  • 关键一步：由开环零极点写出相角与幅值条件
  • 中间结果：相角条件定轨迹形状、幅值条件定增益
  • 卡点：正反馈系统改用0度相角条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过写出根轨迹的定义及相角条件与幅值条件公式
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 本卷考过把正反馈的0度相角条件写成180度
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式

本卷考法
  • 设计串联PD控制器使根轨迹经过指定闭环极点
本卷实例
  • 关键一步：把期望极点代入特征方程并使实虚部为零
  • 中间结果：联立解出控制器的两个参数
  • 卡点：需同时满足稳定性与极点个数不变的要求
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过设计串联PD控制器使根轨迹经过指定闭环极点
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 本卷考过只满足相角条件而漏掉幅值条件
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 判断指定闭环极点对是否为主导极点
本卷实例
  • 关键一步：由根之和求出第三个闭环极点
  • 中间结果：比较各极点距虚轴的距离与留数
  • 卡点：离虚轴太近的第三个极点会主导响应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过判断指定闭环极点对是否为主导极点
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 本卷考过只看极点距虚轴远近而忽略其余极点
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
