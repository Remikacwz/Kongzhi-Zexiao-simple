重庆邮电大学 805 自动控制原理 2015 年真题思维导图

强势双非共 6 题合计 150 分

难度：中等　六道大题：填空9小空、按图形判断稳定性5小题、由阶跃响应定参数并求相角裕度、根轨迹与劳斯判据、由对数幅频特性反求传函并作超前校正、由渐近Bode图反求传函并画Nyquist曲线

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

一（1~9）一、填空题：反馈方框图、超前校正、响应反求、静态误差系数、等效开环、劳斯判稳、极点比较、非线性平衡点30 分#

思路
  • 9个独立小空：画负反馈方框图、超前校正的作用、由单位阶跃响应反求闭环传函与脉冲响应、正弦输入下的稳态输出、静态误差系数与斜坡误差、参数变化时的等效开环传函、四阶特征方程劳斯判稳、由极点分布比较超调、单摆非线性方程的平衡点
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由驾驶员制动过程画出负反馈控制系统的方框图
本卷实例
  • 关键一步：按给定、比较、放大、执行、对象、反馈的回路连线
  • 中间结果：反馈量取自被控量后再送回比较点
  • 卡点：方框图需按题意自画，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由驾驶员制动过程画出负反馈控制系统的方框图
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过把给定信号与反馈信号的接入点画反
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
超前校正 系统校正
本卷考法
  • 说明超前校正利用相角超前特性改善系统的哪项指标
本卷实例
  • 关键一步：由超前网络在剪切频率处提供最大超前相位
  • 中间结果：最大超前角应出现在校正后剪切频率处
  • 卡点：填空只考原理，无需算具体参数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过说明超前校正利用相角超前特性改善系统的哪项指标
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 本卷考过把超前校正的作用误说成提高稳态精度
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应反求闭环传递函数与单位脉冲响应
本卷实例
  • 关键一步：先扣掉响应的稳态分量得到零初值阶跃响应
  • 中间结果：阶跃响应的拉氏变换乘 s 即闭环传函
  • 卡点：题面响应含非零初值项，需先分离稳态
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应反求闭环传递函数与单位脉冲响应
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 本卷考过把含非零初值分量的响应直接当作零初值响应处理
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由闭环传递函数与正弦输入求稳态输出信号的幅值与表达式
本卷实例
  • 关键一步：将输入角频率代入闭环幅频与相频特性
  • 中间结果：输出幅值等于输入幅值乘闭环幅频值
  • 卡点：需先把闭环传函写成频率特性形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由闭环传递函数与正弦输入求稳态输出信号的幅值与表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过把输入角频率代入开环传函而非闭环传函
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环传递函数求静态位置、速度与加速度误差系数
本卷实例
  • 关键一步：按型别代入 s 趋于零的极限式求三个静态系数
  • 中间结果：型别由开环积分环节个数决定
  • 卡点：开环含一阶微分环节不影响型别判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由开环传递函数求静态位置、速度与加速度误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 本卷考过积分环节个数与系统型别的对应记错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡输入作用下的稳态误差
本卷实例
  • 关键一步：取速度误差系数的倒数得单位斜坡稳态误差
  • 中间结果：斜坡输入的误差只与速度误差系数有关
  • 卡点：须先判断系统型别再选误差公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位斜坡输入作用下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过把速度误差系数与误差的倒数关系写反
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 参数由零变到无穷时写出对应的等效开环传递函数
本卷实例
  • 关键一步：由特征方程分离出待变参数并整理成 1 加 K 乘等效开环等于零
  • 中间结果：等效开环由方程中其余项之比构成
  • 卡点：需把含待变参数的项整理到分母之外
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过参数由零变到无穷时写出对应的等效开环传递函数
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 本卷考过把参数根轨迹的等效开环写成了原开环
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断四阶特征方程系统的稳定性及右半平面极点数
本卷实例
  • 关键一步：排劳斯表并统计首列元素的变号次数
  • 中间结果：首列变号次数即右半平面闭环极点数
  • 卡点：首列出现零时需改用 ε 法处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断四阶特征方程系统的稳定性及右半平面极点数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过首列变号次数与右半平面极点数对应错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由两系统闭环极点分布比较超调量的大小
本卷实例
  • 关键一步：由极点到负实轴的夹角推阻尼比大小
  • 中间结果：阻尼比越大则超调量越小
  • 卡点：极点分布图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由两系统闭环极点分布比较超调量的大小
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过把极点距虚轴远近与超调量的关系弄反
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

  • 中间结果：平衡点由正弦项为零的条件给出
  • 卡点：稳定平衡点对应图中位置，需回原卷核对图

通用考法

  • 把增量符号去掉后与原始变量混用

二二、根据图形判断系统稳定性并说明理由（a~e五个小问）30 分#

思路
  • 五幅开环幅相曲线a~e逐一判断闭环稳定性：a、b、d需画增补线数包围临界点的净圈数，c为半次正穿越，e由对数幅频特性与相频穿越对照；统一按右半平面闭环极点数等于开环极点数减两倍净穿越数计算
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅相曲线判断闭环系统稳定性并说明理由
  • 含积分环节时补画无穷大半径圆弧后再数穿越
本卷实例
  • 关键一步：画增补线后数曲线在临界点左侧的净穿越次数
  • 中间结果：由开环极点数与净穿越数得右半平面闭环极点数
  • 卡点：五幅曲线均以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环幅相曲线判断闭环系统稳定性并说明理由
  • 本卷考过含积分环节时补画无穷大半径圆弧后再数穿越
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过未先数开环右半平面极点数
  • 本卷考过把正穿越与负穿越的符号取反
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由对数幅频特性与相频曲线的穿越关系判断闭环稳定性
本卷实例

频率特性的物理意义与求法 频域分析
本卷考法
  • 分析Nyquist曲线的起点、终点与实轴交点
本卷实例
  • 关键一步：分别取频率趋于零、零正与无穷分析幅值和相角

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过分析Nyquist曲线的起点、终点与实轴交点

常见易错
  • 本卷考过频率为零与频率零正两个端点混淆
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

稳定裕度 频域分析
本卷考法
  • 求相角裕度并判断系统稳定性
本卷实例
  • 关键一步：由开环幅频幅值等于1的条件求剪切频率
  • 中间结果：相角裕度由180度加该频率处的相角得到

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求相角裕度并判断系统稳定性
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
