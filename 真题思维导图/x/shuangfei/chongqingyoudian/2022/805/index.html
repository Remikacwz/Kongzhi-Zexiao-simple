传递函数的定义与基本性质 传递函数
本卷考法
  • 说明控制系统的数学模型取决于什么
本卷实例
  • 关键一步：按微分方程系数来源定位影响因素
  • 中间结果：取决于系统的结构与参数
  • 卡点：与外作用和初始条件无关
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过说明控制系统的数学模型取决于什么
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过把外作用与初始条件也当成影响因素
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

稳定裕度 频域分析
本卷考法

本卷实例
  • 关键一步：由 γ=180°+∠G(ωc)=45° 得 ∠G(ωc)=-135°
  • 中间结果：再由相频表达式反解 ωc
  • 卡点：注意各环节相角累加的符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由相频特性与相角裕度要求反求截止频率
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过把相角裕度写成∠G(ωc)本身
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 检查首列符号：全同号则稳定，有变号则数出个数

本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值

频率特性的物理意义与求法 频域分析
本卷考法
  • 求单位负反馈 G=1/s 在正弦输入下的稳态输出
本卷实例
  • 关键一步：由频率特性求幅值比与相位差
  • 中间结果：稳态输出仍为正弦、频率不变
  • 卡点：输入含初相时输出相角要叠加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求单位负反馈 G=1/s 在正弦输入下的稳态输出
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过只算幅值比而漏掉相角变化
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

二1二、1 两质量弹簧阻尼系统的动力学建模与传递函数#

思路
  • 分别对两质量块列牛顿运动方程并联立消元，得到输出位移对输入外力的传递函数 Y(s)/U(s)
机械系统建模 建模与机电系统
本卷考法
  • 对两个质量块分别列写运动微分方程
本卷实例
  • 关键一步：先对整体列一方程，再对 m2 列弹簧阻尼受力方程
  • 中间结果：两式联立可消去 x2 求 x1
  • 卡点：系统图未编号，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
