1填空题：组成、闭环传函、滞后环节、频域指标、非线性方法#

思路
  • 第1题为 5 个独立小空，分别考查控制系统的组成、单位负反馈闭环传函、典型环节、频域指标与时域指标的对应、非线性分析方法
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出锅炉液位控制系统的被控对象与被控量
本卷实例
  • 关键一步：按检测—比较—调节的工作原理定位被调量
  • 中间结果：被控对象是锅炉或水箱本体，被控量是液位
  • 卡点：逐年只写锅炉，宝典答案按锅炉、水箱液位作答
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指出锅炉液位控制系统的被控对象与被控量
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把检测变送元件误当被控对象
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 单位负反馈时由开环传函写出闭环传函
本卷实例
  • 关键一步：按闭环等于开环比上一加开环列式
  • 中间结果：闭环分母比开环分母多出一个常数项
  • 卡点：一阶开环化闭环时分母次数不变，常数项增加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过单位负反馈时由开环传函写出闭环传函
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过负反馈分母写成开环减一
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

典型环节及其特性 传递函数
本卷考法
  • 说明纯相位滞后环节等效成哪种典型环节
本卷实例
  • 关键一步：抓住滞后环节低频通过、高频抑制的频域特征
  • 中间结果：该特征与低通滤波环节一致
  • 卡点：滞后只描述相频，不能据此断定幅频也衰减
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过说明纯相位滞后环节等效成哪种典型环节
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 本卷考过把相位滞后与幅值衰减混为一谈
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减

闭环频率特性与性能指标 频域分析
本卷考法
  • 写出截止频率与相角裕度各自对应的时域指标
本卷实例
  • 关键一步：借助谐振峰值把开环频域指标折算到时域
  • 中间结果：截止频率联系响应快慢即调节时间，相角裕度联系超调量
  • 卡点：宝典答案用谐振峰值与超调、调节时间的经验公式折算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过写出截止频率与相角裕度各自对应的时域指标
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 本卷考过把两个指标的对应关系写反
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

非线性系统的特点 非线性系统
本卷考法
  • 列举非线性系统的常用分析方法
本卷实例
  • 关键一步：按系统阶次与有无外作用选择分析方法
  • 中间结果：常用描述函数法和相平面法
  • 卡点：描述函数法不限阶次，相平面法多用于一、二阶
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过列举非线性系统的常用分析方法
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 本卷考过只答一种方法而漏答其余
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
描述函数法基础 非线性系统
本卷考法
  • 说明描述函数法适合分析哪类问题
本卷实例
  • 关键一步：区分描述函数与线性系统频率特性的自变量
  • 中间结果：描述函数法用于无外作用时的稳定性与自振分析
  • 卡点：描述函数是振幅的函数，不是频率的函数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过说明描述函数法适合分析哪类问题
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 本卷考过把描述函数当成频率的函数
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

相平面法 非线性系统

本卷实例

步骤

  • 由等倾线法或解析法求相轨迹斜率

  • 把相轨迹与根轨迹混淆

3零极点对消下的二阶设计与斜坡误差#

思路
  • 由图2结构先列闭环特征式，消去一对零极点后降为二阶；由阻尼比反求 K，再算单位斜坡输入的稳态误差
零极点分布与响应模态 传递函数
本卷考法
  • 由闭环特征式的零极点分布判断能否降阶
本卷实例
  • 关键一步：把闭环特征多项式分解并识别可对消的因子
  • 中间结果：消去一个实极点后剩下二阶因子
  • 卡点：对消是否成立取决于图2结构，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由闭环特征式的零极点分布判断能否降阶
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 本卷考过只看极点分布就断定振荡而忽略零点
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由期望阻尼比反求开环增益
本卷实例
  • 关键一步：把降阶后的二阶因子写成标准形式并对照系数
  • 中间结果：阻尼比与自然频率分别由一次项、常数项决定
  • 卡点：阻尼比公式分子是二倍阻尼乘自然频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由期望阻尼比反求开环增益
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过化为标准形式时忘记把二次项系数归一
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：先写出误差传函再对斜坡输入取终值
  • 中间结果：由速度误差系数得到稳态误差表达式
  • 卡点：需先用闭环极点判稳再取终值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换

稳定裕度 频域分析
本卷考法
  • 求校正后系统的相角裕度
本卷实例
  • 关键一步：先由幅值等于一确定校正后的剪切频率
  • 中间结果：相角裕度等于该频率处相角加一百八十度
  • 卡点：校正后开环已化成标准形式，剪切频率可直接读出
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求校正后系统的相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过把剪切频率与相位穿越频率用反
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
