思路
  • 10个独立小空，覆盖数学模型分类、欠阻尼二阶根图、斜坡误差、PD与PID作用、正弦稳态、幅值裕度、带宽、滞后网络与描述函数
传递函数的定义与基本性质 传递函数
本卷考法
  • 按域列出系统数学模型
本卷实例
  • 关键一步：按时间域与复频域分类
  • 中间结果：时域补频率特性前先列微分方程
  • 卡点：题干空位多，按教材分类填
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过按域列出系统数学模型
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过混淆复数域与频域模型
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

本卷考法

本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由复数根图求阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过阻尼角与根相角关系写反
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由欠阻尼参数求调节时间
本卷实例
  • 关键一步：先定阻尼比与自然频率
  • 中间结果：调节时间与阻尼比乘自然频率成反比
  • 卡点：误差带题面已给0.02
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由欠阻尼参数求调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过2%误差带系数用错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

通用考法

  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过未判稳就用终值定理
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

PID 控制器与参数整定 系统校正
本卷考法
  • 说明PD与PID各环节的作用
本卷实例
  • 关键一步：按偏差及其累积和变化率分析
  • 中间结果：比例管快速积分消误差微分改善稳定
  • 卡点：微分过强会放大高频噪声
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过说明PD与PID各环节的作用
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 本卷考过把积分作用说成提高快速性
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

频率特性的物理意义与求法 频域分析
本卷考法
  • 由正弦稳态输出反求两参数
本卷实例
  • 关键一步：写闭环频率特性令频率为1
  • 中间结果：由幅值与相角条件联立
  • 卡点：输入幅值为2不能按1处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由正弦稳态输出反求两参数
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过漏掉输入幅值2
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

稳定裕度 频域分析
本卷考法
  • 由幅值裕度等于2求T与频率
本卷实例
  • 关键一步：先令相角等于负180度
  • 中间结果：由幅值裕度定义列时间常数方程
  • 卡点：题中T与τ符号易混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由幅值裕度等于2求T与频率
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过相位穿越与截止频率用反
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

闭环频率特性与性能指标 频域分析
本卷考法
  • 求一阶系统带宽并分析影响
本卷实例
  • 关键一步：令闭环幅值降到0.707倍
  • 中间结果：一阶系统带宽等于时间常数倒数
  • 卡点：带宽增大同时加快响应与放大噪声
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过求一阶系统带宽并分析影响
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 本卷考过带宽与开环截止频率等同
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

滞后校正 系统校正
本卷考法
  • 由滞后网络图求三参数
本卷实例
  • 关键一步：先写成标准滞后网络形式
  • 中间结果：最大滞后角在两转折频率几何中点
  • 卡点：网络图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过由滞后网络图求三参数
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 本卷考过两个转折频率顺序写反
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

用描述函数法分析自振 非线性系统
本卷考法
  • 由两曲线交点判断稳定自振点
本卷实例
  • 关键一步：比较交点处振幅增大方向
  • 中间结果：满足方向条件的交点为稳定自振
  • 卡点：两曲线以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过由两曲线交点判断稳定自振点
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 本卷考过未标振幅方向就下结论
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率
