思路
  • 10个独立小空覆盖稳定性/快速性/准确性、二阶超调与谐振指标、PI环节、复合控制、偶极子、频段斜率、非线性稳定性、相平面法、一阶系统带宽与斜坡误差、二阶幅相反求传函
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 写出自动控制系统的基本要求
本卷实例
  • 关键一步：按稳、快、准三条基本要求逐一对应
  • 中间结果：基本要求为稳定性、快速性与准确性
  • 卡点：概念填空，注意各要求措辞要准确
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过写出自动控制系统的基本要求
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把准确性误说成抗扰性
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由超调量 e^-π 反求二阶系统阻尼比
本卷实例
  • 关键一步：令 e^(-πξ/√(1-ξ²))=e^(-π) 反解 ξ
  • 中间结果：超调量指数与 πξ/√(1-ξ²) 的对应关系
  • 卡点：指数上的 π 要与给定超调量对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由超调量 e^-π 反求二阶系统阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过超调量公式指数写错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求自然频率为1时的峰值时间与谐振指标
本卷实例
  • 关键一步：把 ωn=1 代入二阶峰值时间公式
  • 中间结果：峰值时间与谐振峰值由 ξ、ωn 共同决定
  • 卡点：要注意给定阻尼比下谐振峰是否真的存在
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求自然频率为1时的峰值时间与谐振指标
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过把峰值时间与上升时间混用
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

PID 控制器与参数整定 系统校正
本卷考法
  • 写出 PI 控制器传递函数并说明积分环节作用
本卷实例
  • 关键一步：按比例项与积分项相加构成 PI 形式
  • 中间结果：积分环节改善系统稳态精度
  • 卡点：积分会减慢响应，注意与微分区分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过写出 PI 控制器传递函数并说明积分环节作用
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 本卷考过把积分作用说成提高稳定性
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

反馈校正与复合控制 系统校正
本卷考法
  • 写出复合控制的两种前馈形式
本卷实例
  • 关键一步：按补偿信号取自输入还是扰动分类
  • 中间结果：即按输入补偿与按扰动补偿
  • 卡点：前馈不改变闭环稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过写出复合控制的两种前馈形式
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 本卷考过把输入补偿与扰动补偿混为一谈
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

附加开环零极点的影响 根轨迹法
本卷考法
  • 说明引入偶极子对开环增益与性能的影响
本卷实例
  • 关键一步：把偶极子看成一对其靠近的零极点
  • 中间结果：增益可增大或减小，取决于其位置
  • 卡点：题干未加限制，结论不唯一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过说明引入偶极子对开环增益与性能的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 本卷考过断言偶极子必定增大增益
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
开环对数频率特性的绘制 频域分析
本卷考法
  • 写出频率特性低/中/高频段的典型斜率
本卷实例
  • 关键一步：按积分环节数与惯性环节数定各段斜率
  • 中间结果：低频段由型别定，中频段决定动态性
  • 卡点：高频段斜率影响抗高频噪声能力
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过写出频率特性低/中/高频段的典型斜率
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 本卷考过把中频段斜率与系统阶次直接等同
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

非线性系统的特点 非线性系统
本卷考法
  • 说明非线性系统稳定性与结构参数、初始条件的关系
本卷实例
  • 关键一步：区分线性与非线性系统稳定性判据
  • 中间结果：非线性稳定性与初始条件有关
  • 卡点：结构参数与初始条件两个空都要答
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过说明非线性系统稳定性与结构参数、初始条件的关系
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 本卷考过套用线性系统稳定性的结论
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
相平面法 非线性系统
本卷考法
  • 说明相平面法绘制相轨迹的作用与适用范围
本卷实例
  • 关键一步：由状态方程消去时间得相轨迹方程
  • 中间结果：相平面法适用于一、二阶非线性系统
  • 卡点：高阶系统需先作降维处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过说明相平面法绘制相轨迹的作用与适用范围
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 本卷考过把相轨迹与根轨迹混淆
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由一阶闭环传函求带宽频率
本卷实例
  • 关键一步：一阶系统带宽频率等于时间常数倒数
  • 中间结果：一阶系统带宽只由时间常数决定
  • 卡点：注意闭环传函分子是否含增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由一阶闭环传函求带宽频率
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 本卷考过把带宽频率与转折频率混用
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求一阶系统在单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：先写成含一个积分环节的1型系统
  • 中间结果：斜坡误差等于速度误差系数倒数
  • 卡点：注意开环增益与闭环传函的换算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求一阶系统在单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过未判稳就使用终值定理
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

频率特性的物理意义与求法 频域分析
本卷考法
  • 由二阶系统幅相特性与虚轴交点反求传函
本卷实例
  • 关键一步：由交点(0,-0.8j)与角频率2联立求 ωn、ξ
  • 中间结果：ωn=2，ξ=5/8
  • 卡点：幅相特性以图1给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由二阶系统幅相特性与虚轴交点反求传函
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
