重庆邮电大学 805 自动控制原理 2024 年真题思维导图

强势双非共 8 题合计 150 分

难度：中等　8 道大题：第1题含10个填空小空，第11~17题依次考倒摆建模、结构图与劳斯、稳态误差与超调、根轨迹、奈奎斯特判稳、滞后校正、PID设计

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

一（1~10）一、填空题：频域指标、被控对象、PID、根轨迹圆、稳定条件、响应反求、降阶、非线性法40 分#

思路
  • 10个独立小空，覆盖谐振峰值与谐振频率、被控对象、PID环节作用、根轨迹圆心半径、稳定必要条件、由脉冲响应反求传函、主导极点降阶、非线性分析方法、分离点与虚轴交点、结构图参数
闭环频率特性与性能指标 频域分析
本卷考法
  • 写出典型二阶系统谐振峰值与谐振频率的表达式
本卷实例
  • 关键一步：把闭环传函整理成二阶标准形式再对照公式
  • 中间结果：谐振峰值只由阻尼比决定，谐振频率还含自然频率
  • 卡点：二阶系统在阻尼比较大时没有谐振峰，公式不适用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过写出典型二阶系统谐振峰值与谐振频率的表达式
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 本卷考过阻尼比大于0.707时仍套用谐振峰值公式
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出锅炉液位控制系统的被控对象与被控量
本卷实例
  • 关键一步：按检测—比较—调节的回路定位被调量
  • 中间结果：被控对象是锅炉本体，被控量是液位
  • 卡点：锅炉流程以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指出锅炉液位控制系统的被控对象与被控量
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把检测变送元件误当成被控对象
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
PID 控制器与参数整定 系统校正
本卷考法
  • 说明PID中比例、积分、微分各环节的作用
本卷实例
  • 关键一步：按偏差大小、偏差累积、偏差变化率分别对应三项
  • 中间结果：比例管快速性，积分消稳态误差，微分改善稳定性
  • 卡点：微分作用过强会放大高频噪声，需折中取值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过说明PID中比例、积分、微分各环节的作用
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 本卷考过把积分环节的作用说成提高系统稳定性
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

根轨迹的绘制法则 根轨迹法
本卷考法
  • 求给定开环传函下根轨迹圆的圆心与半径
本卷实例
  • 关键一步：写闭环特征方程，令闭环根为复数并分离实虚部
  • 中间结果：消去增益后得到圆心在实轴上的圆方程
  • 卡点：开环含一阶微分环节，根轨迹圆方程需重新整理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过求给定开环传函下根轨迹圆的圆心与半径
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过把分离点坐标当成圆心坐标
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

劳斯判据 稳定性分析
本卷考法
  • 写出四阶特征方程系统稳定的必要条件
本卷实例
  • 关键一步：检查特征方程各项系数是否同号且无缺项
  • 中间结果：必要条件只要求各系数同号且均不为零
  • 卡点：必要条件满足后还需排劳斯表进一步检验
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过写出四阶特征方程系统稳定的必要条件
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过把必要条件当成充要条件直接下结论
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位脉冲响应反求开环传函与单位阶跃响应
本卷实例
  • 关键一步：脉冲响应的拉氏变换即闭环传函，再反解开环
  • 中间结果：单位负反馈下用 G=Φ/(1−Φ) 反解
  • 卡点：反解关系式只在单位负反馈前提下成立
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位脉冲响应反求开环传函与单位阶跃响应
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 本卷考过把脉冲响应直接当成阶跃响应去反解
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 由闭环传函判断主导极点并作降阶近似
本卷实例
  • 关键一步：比较各极点距虚轴距离与对应留数的大小
  • 中间结果：距虚轴最近且留数最大的极点为主导极点
  • 卡点：远离虚轴的极点能否略去要看时间常数之比
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过由闭环传函判断主导极点并作降阶近似
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 本卷考过只按极点距虚轴远近判断而忽略留数大小
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

非线性系统的特点 非线性系统
本卷考法
  • 列举分析非线性系统常用的方法
本卷实例
  • 关键一步：按系统阶次与有无外作用选择分析方法
  • 中间结果：工程上常用描述函数法与相平面法
  • 卡点：两种方法的适用条件不同，不能互相替代
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过列举分析非线性系统常用的方法
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 本卷考过把线性系统的分析方法直接套到非线性系统
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
描述函数法基础 非线性系统
本卷考法
  • 说明描述函数法适合分析哪类问题
本卷实例
  • 关键一步：区分描述函数与线性频率特性的自变量
  • 中间结果：描述函数法处理无外作用时的自振与稳定性
  • 卡点：描述函数的自变量是振幅而不是频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法

  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 本卷考过把描述函数当成频率的函数
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

  • 卡点：开环含右半平面极点，实轴段判据要重算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

步骤

  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法

  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍

  • 求出方程根后不筛选，保留了不在根轨迹上的解

与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴的交点坐标
本卷实例
  • 关键一步：把 s=jω 代入特征方程并拆开实部虚部
  • 中间结果：实部虚部同时为零可解出交点与临界增益
  • 卡点：与分离点题共用同一开环，注意区分两问
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
