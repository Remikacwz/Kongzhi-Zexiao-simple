一一、概念简答15 分#

思路
  • 逐条说明稳态误差、离散脉冲传函、幅值裕量、能控性与能观性的含义
误差定义与误差传递函数 稳态误差
本卷考法
  • 解释稳态误差的含义与产生原因
本卷实例
  • 关键一步：从误差是期望输出与实际输出之差入手
  • 中间结果：稳态误差反映系统的最终跟踪精度
  • 卡点：需说明误差与输入形式和系统型别有关
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过解释稳态误差的含义与产生原因
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 本卷考过把暂态偏差与稳态误差混为一谈
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
脉冲传递函数 离散控制系统
本卷考法
  • 写出离散系统脉冲传递函数的定义
本卷实例
  • 关键一步：用输出与输入脉冲序列 z 变换之比定义
  • 中间结果：采样开关位置会影响脉冲传函形式
  • 卡点：要交代零初始条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过写出离散系统脉冲传递函数的定义
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 本卷考过忽略零初始条件这一前提
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)

稳定裕度 频域分析
本卷考法
  • 说明幅值裕量的定义与几何含义
本卷实例
  • 关键一步：在奈氏图上找曲线与负实轴的交点
  • 中间结果：该交点幅值的倒数即幅值裕量
  • 卡点：需与相角裕量对照说明
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过说明幅值裕量的定义与几何含义
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过把幅值裕量与相角裕量的定义互换
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

能控性与能观性 状态空间分析
本卷考法
  • 分别说明能控性与能观性的物理含义
本卷实例
  • 关键一步：从输入能否左右状态与输出能否反映状态入手
  • 中间结果：两者分别是状态反馈与观测器设计的前提
  • 卡点：概念题只需定性说明，不必展开判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过分别说明能控性与能观性的物理含义
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 本卷考过两个判据的矩阵构造混淆
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

二二、方程组建结构图与响应20 分#

思路
  • 由三个代数方程画结构图，再按给定闭环传函求单位阶跃响应
梅森增益公式与信号流图 传递函数
本卷考法
  • 由方程组确定各环节连接关系并画结构图
本卷实例
  • 关键一步：把三个方程分别看作三个环节的输入输出关系
  • 中间结果：按变量关系逐层连接得到结构图
  • 卡点：连接关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由方程组确定各环节连接关系并画结构图
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过反馈支路的极性画反
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图求闭环传递函数
本卷实例
  • 关键一步：先化简内环再逐步外推
  • 中间结果：闭环传函为有理分式
  • 卡点：各局部反馈的符号要统一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由结构图求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过负反馈分母写成 1-GH
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由闭环传函求单位阶跃下的输出表达式
本卷实例
  • 关键一步：对 Y(s) 作部分分式分解后逐项反变换
  • 中间结果：输出由稳态分量与两个衰减模态叠加
  • 卡点：题给传函分母含两个实极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由闭环传函求单位阶跃下的输出表达式
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 本卷考过漏掉部分的分解项或稳态分量
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

三三、比例微分改善动态性能20 分#

思路
  • 以微分时间常数为参数整理根轨迹，再由调整时间要求反求参数范围
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以微分时间常数为变量整理根轨迹方程
本卷实例
  • 关键一步：把闭环特征方程整理成含参数的根轨迹形式
  • 中间结果：以该参数为变量的轨迹是一条圆弧
  • 卡点：题图以原卷插图给出
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以微分时间常数为变量整理根轨迹方程
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 本卷考过整理时未把参数完整提到分子位置
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为标准二阶形式
本卷实例
  • 关键一步：由分母一次项与常数项读出阻尼比
  • 中间结果：闭环无阻尼自然频率由常数项决定
  • 卡点：需先写出闭环传函再比较系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为标准二阶形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过化标准形式时忘记归一化二次项系数
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

常见易错
  • 本卷考过把两种误差带的调节时间系数搞混
  • 把两种误差带的调节时间系数搞混

四四、根轨迹定临界阻尼与误差12 分#

思路
  • 由根轨迹图反设开环传函，定临界阻尼参数后求正弦稳态响应
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹图反设开环传函并定临界阻尼参数
本卷实例
  • 关键一步：从图上读出分离点与开环极点位置
  • 中间结果：由临界阻尼条件列阻尼比方程
  • 卡点：根轨迹图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤

  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹图反设开环传函并定临界阻尼参数
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
