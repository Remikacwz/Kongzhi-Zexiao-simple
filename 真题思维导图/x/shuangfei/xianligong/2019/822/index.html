一一、概念简答10 分#

思路
  • 简述稳定性与稳态误差、频率特性与描述函数两组概念
劳斯判据 稳定性分析
本卷考法
  • 说明系统稳定性与平衡状态的关系
本卷实例
  • 关键一步：从扰动后能否回到平衡状态说明
  • 中间结果：线性定常系统由特征根实部判断
  • 卡点：要与稳态误差概念区分开
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过说明系统稳定性与平衡状态的关系
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过把有界输入有界输出稳定与渐近稳定混同
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

思路

  • 不接触回路才会计入高阶乘积项
步骤

减小稳态误差的措施 稳态误差
本卷考法
  • 说明引入积分环节对误差与稳定性的影响
本卷实例
  • 关键一步：从系统型别提高的角度说明
  • 中间结果：积分作用在消除静差的同时降低裕度
  • 卡点：要与扰动不变性一起作答
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过说明引入积分环节对误差与稳定性的影响
  • 分析提高开环增益对误差与稳定性的双重影响

  • 说明为何单纯提高增益不可行
