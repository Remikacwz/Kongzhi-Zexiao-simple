一一、概念简答12 分#

思路
  • 逐条解释传递函数、主导极点、频率特性与采样定理四个基本概念，注意各自前提与物理含义
传递函数的定义与基本性质 传递函数
本卷考法
  • 简述传递函数的定义与适用前提
本卷实例
  • 关键一步：先点明零初始条件再写输出与输入拉氏变换之比
  • 中间结果：定义只适用于线性定常系统
  • 卡点：要把零初始条件的含义说清
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过简述传递函数的定义与适用前提
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过忽略零初始条件这一前提
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 说明主导极点的含义及其在近似中的作用
本卷实例
  • 关键一步：先讲距虚轴最近且留数大的极点主导响应
  • 中间结果：高阶系统可降为二阶近似
  • 卡点：主导极点的判定要看两部分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法

  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 本卷考过只看极点离虚轴远近而忽略留数大小
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

频率特性的物理意义与求法 频域分析
本卷考法
  • 说明频率特性的物理含义并写出定义式
本卷实例
  • 关键一步：从正弦稳态输出与输入的幅值比和相位差入手
  • 中间结果：频率特性是稳态响应随频率的变化规律
  • 卡点：要与传递函数的复变量区分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法

常见易错
  • 本卷考过求幅值时忘记把复数取模
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

  • 卡点：采样定理的严格不等号要写对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠

常见易错

  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

二二、微分方程组建模与传函14 分#

思路
  • 对微分方程组逐式取拉氏变换画结构图，再用梅森公式分别求参考输入与扰动输入下的传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 由微分方程组画结构图并用梅森公式求传函
本卷实例
  • 关键一步：先逐式拉氏变换再按信号流向连接各环节
  • 中间结果：前向通路与回路需逐条列出
  • 卡点：结构图中反馈极性需核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由微分方程组画结构图并用梅森公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路的判断找漏或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

三三、临界增益与稳态误差12 分#

思路
  • 由闭环结构列特征式，用劳斯判据求等幅振荡的增益与振荡频率，再由加速度输入误差要求定增益范围
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求等幅振荡的增益与振荡频率
本卷实例
  • 关键一步：令劳斯表首列某元素为零并写辅助方程
  • 中间结果：临界增益对应首列元素为零
  • 卡点：振荡频率由辅助方程给出
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求等幅振荡的增益与振荡频率
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过出现全零行时未用辅助方程求虚根
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由加速度输入下的误差要求反求增益范围
本卷实例
  • 关键一步：先按系统型别写出加速度误差系数表达式
  • 中间结果：误差要求与稳定性条件需取交集
  • 卡点：输入端误差的定义需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由加速度输入下的误差要求反求增益范围
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过未判稳就代入稳态误差公式
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

四四、参数根轨迹与稳定度16 分#

思路
  • 以时间常数 τ 为参变量整理等效开环传函，绘制参数根轨迹，再由稳定度与超调量要求定 τ 范围
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以参数 τ 为变量整理等效开环并绘制参数根轨迹
本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以参数 τ 为变量整理等效开环并绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 本卷考过整理时未把参数完整提到分子位置
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
