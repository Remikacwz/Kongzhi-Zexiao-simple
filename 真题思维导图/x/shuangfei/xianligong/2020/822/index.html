一一、名词解释#

思路
  • 解释稳定性、动态性能、稳态性能、PID 各环节作用及能控能观的作用
劳斯判据 稳定性分析
本卷考法
  • 说明稳定性的基本概念
本卷实例
  • 关键一步：从受扰后能否回到平衡状态说明
  • 中间结果：线性定常系统由特征根实部判断
  • 卡点：需与动态、稳态性能并列说明
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过说明稳定性的基本概念
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过把渐近稳定与有界输入有界输出稳定混同
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
