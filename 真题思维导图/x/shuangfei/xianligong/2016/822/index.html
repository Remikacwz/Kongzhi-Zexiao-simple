一一、起搏器系统动态性能18 分#

思路
  • 把起搏器系统等效为二阶系统，由最佳阻尼比求增益，再由阶跃响应求指定时刻心速与瞬时最大心速
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由起搏器系统结构建立被控对象的传递函数
本卷实例
  • 关键一步：先写心脏等效积分环节再按反馈结构合成
  • 中间结果：对象含一个积分与一个惯性环节
  • 卡点：起搏器结构图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)

  • 复阻抗法把电容阻抗误写成 Cs

本卷实例

  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角

  • 按 ξ 的取值判断响应类型
通用考法

  • 由闭环传递函数求 ωn 与 ξ

  • 在 s 平面上标出闭环极点的位置
常见易错

  • 化为标准形式时忘记把 s² 项系数归一化

二二、根轨迹为圆的证明与阻尼范围15 分#

思路
  • 证明开环传函的非实轴根轨迹构成圆，再在给定零极点下确定阻尼比范围与振荡衰减的根轨迹增益范围
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 用相角条件证明非实轴根轨迹构成圆
本卷实例
  • 关键一步：令闭环特征式实部与虚部同时为零消去参数
  • 中间结果：消元后得到圆的方程即证
  • 卡点：零极点位置关系需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过用相角条件证明非实轴根轨迹构成圆
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 本卷考过用幅值条件去判点、搞混两个条件的用途
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

  • 根轨迹关于实轴对称

  • 实轴段判据中的零极点个数算错

三三、Nyquist曲线与参数影响14 分#

思路
  • 画开环幅相曲线，用奈氏判据分析两个时间常数的大小关系对闭环稳定性的影响
开环对数频率特性的绘制 频域分析
本卷考法
  • 求开环幅频相频表达式并画 Nyquist 曲线
本卷实例
  • 关键一步：先定幅相曲线的起点终点与中间穿越
  • 中间结果：含两个积分环节时起点相位特殊
  • 卡点：曲线绕向与渐近线需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过求开环幅频相频表达式并画 Nyquist 曲线
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 本卷考过低频段起始高度没有乘上型别的斜率
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据分析时间常数对稳定性的影响
本卷实例
  • 关键一步：先数开环右半平面极点数再统计包围圈数
  • 中间结果：由包围情况反推稳定所需参数条件
  • 卡点：补圆方向要与积分环节个数对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据分析时间常数对稳定性的影响
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过含积分环节时未补画无穷大半径圆弧
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

思路

由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频渐近线反求系统开环传递函数
本卷实例
  • 关键一步：先从低频段斜率与高度定出型别和开环增益

  • 卡点：转折频率顺序需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 每个转折频率对应一个一阶或二阶环节

步骤

  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频渐近线反求系统开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 本卷考过把延长线交点误当作增益值而未折算型别
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
