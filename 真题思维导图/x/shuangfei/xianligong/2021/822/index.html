一一、概念简答#

思路
  • 分别从动态性能改善、稳态性能改善以及经典与现代控制理论三方面作答
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 谈谈对系统动态响应的理解并说明改善动态性能的途径
本卷实例
  • 关键一步：先说明响应随输入变化的过程再给出改善手段
  • 中间结果：可从增益、控制器结构与校正方式三方面改善
  • 卡点：题干只要求定性说明
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过谈谈对系统动态响应的理解并说明改善动态性能的途径
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过只答指标定义而漏掉改善措施
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

减小稳态误差的措施 稳态误差
本卷考法
  • 谈谈对系统稳态响应的理解并说明改善稳态性能的途径
本卷实例
  • 关键一步：先区分稳态响应与稳态误差再给措施
  • 中间结果：提高开环增益或增加积分环节可减小误差
  • 卡点：改善精度与稳定性需要折中
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过谈谈对系统稳态响应的理解并说明改善稳态性能的途径
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 本卷考过只谈减小误差而不检查稳定性
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

传递函数的定义与基本性质 传递函数
本卷考法
  • 从研究对象与数学模型角度比较两类控制理论
本卷实例
  • 关键一步：先说明经典理论面向单输入单输出系统
  • 中间结果：经典用传递函数，现代用状态空间
  • 卡点：研究手段的异同要一并作答
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过从研究对象与数学模型角度比较两类控制理论
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过把两种描述的适用范围混淆
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

状态空间表达式的建立 状态空间分析
本卷考法
  • 从状态空间方法说明现代控制理论的特点
本卷实例
  • 关键一步：指出现代理论可处理多输入多输出与时变系统
  • 中间结果：状态空间便于揭示系统内部状态
  • 卡点：三个比较维度都要写到
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过从状态空间方法说明现代控制理论的特点
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 本卷考过只说多输入多输出而漏掉时变系统
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

思路

本卷考法

本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法

  • 由实验阶跃响应曲线求传递函数

三三、三种判据定临界增益#

思路
  • 分别用劳斯判据、根轨迹与奈氏判据求系统临界稳定时的增益
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求临界稳定时的增益与频率
本卷实例
  • 关键一步：列劳斯表并令出现全零行的条件成立
  • 中间结果：临界增益由首列元素为零给出
  • 卡点：辅助方程给出虚轴交点频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求临界稳定时的增益与频率
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过出现全零行时未用辅助方程求虚根
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 用根轨迹求与虚轴交点确定临界增益
本卷实例
  • 关键一步：由特征式实虚部为零联立求交点
  • 中间结果：临界增益与劳斯结果互相印证
  • 卡点：等效开环含一个零点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过用根轨迹求与虚轴交点确定临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 本卷考过漏掉另一组交点
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

奈奎斯特判据 稳定性分析
本卷考法
  • 用奈氏判据由幅相曲线求临界增益
本卷实例
  • 关键一步：求幅相曲线与负实轴交点的幅值
  • 中间结果：交点在临界处穿过负一临界点
  • 卡点：开环右半平面极点数为零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈氏判据由幅相曲线求临界增益
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过含积分环节时未补画无穷大圆弧
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

四四、串联校正设计#

思路
  • 由稳态误差要求定开环增益，求原系统裕度，再设计串联滞后校正并比较前后性能
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由斜坡稳态误差要求确定开环增益
本卷实例
  • 关键一步：由速度误差系数反求开环增益
  • 中间结果：增益确定后原系统相角裕度不足
  • 卡点：系统型别决定误差与增益的关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由斜坡稳态误差要求确定开环增益
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过未判稳就先代入误差公式
