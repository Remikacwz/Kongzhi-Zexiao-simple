一（1~7）简答题：概念与基本方法#

思路
  • 七小问分别问闭环极点与响应、开环增益与根轨迹增益、准确性影响因素、主导极点、频域性能指标、奈氏判据与Bode关系、采样定理
零极点分布与响应模态 传递函数
本卷考法
  • 说明闭环根的分布与单位阶跃响应形态之间的关系
本卷实例
  • 关键一步：按闭环极点在 s 平面上的位置判断响应单调还是振荡
  • 中间结果：欠阻尼对应共轭复根，临界与过阻尼对应负实根
  • 卡点：零点存在会改变超调量与上升时间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过说明闭环根的分布与单位阶跃响应形态之间的关系
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 本卷考过只看极点分布就断定振荡，忽略零点对模态权重的影响
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 说明开环增益与根轨迹增益的区别与联系
本卷实例
  • 关键一步：分别写出尾一型开环增益与首一型根轨迹增益的定义式
  • 中间结果：两者相差开环零极点常数的折算
  • 卡点：联系在于根轨迹增益由开环增益变换而来
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过说明开环增益与根轨迹增益的区别与联系
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 本卷考过把根轨迹增益直接当作开环增益使用
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

系统型别与静态误差系数 稳态误差
本卷考法
  • 说明系统准确性与哪些因素有关
本卷实例
  • 关键一步：从系统型别、开环增益和输入信号形式判断稳态误差
  • 中间结果：型别决定能否跟踪某类典型输入
  • 卡点：准确性与稳定性、输入形式都有关
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过说明系统准确性与哪些因素有关
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 本卷考过只强调开环增益而忽略系统型别与输入形式
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 给出主导极点的定义
本卷实例
  • 关键一步：找出距虚轴最近且附近无闭环零点、留数大的极点
  • 中间结果：主导极点对应的响应分量作用最突出
  • 卡点：要同时说距虚轴近与附近无零点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过给出主导极点的定义
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 本卷考过忽略附近无闭环零点这一条件
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

闭环频率特性与性能指标 频域分析
本卷考法
  • 列举频率分析法的性能指标
本卷实例
  • 关键一步：从闭环幅频特性上取零频幅值比、谐振幅值、谐振频率与带宽
  • 中间结果：四个量分别反映稳态精度与平稳性
  • 卡点：带宽与响应速度相关，谐振反映平稳性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过列举频率分析法的性能指标
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 本卷考过谐振幅值公式在小阻尼以外乱用
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

奈奎斯特判据 稳定性分析
本卷考法
  • 简述奈奎斯特判据并说明奈氏图与Bode图的关系
本卷实例
  • 关键一步：写出 Z 等于 P 减二 N 并说明各量含义
  • 中间结果：奈氏图与 Bode 图都是频率响应的表示形式
  • 卡点：奈氏图看包围圈数，Bode 图看裕度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过简述奈奎斯特判据并说明奈氏图与Bode图的关系
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过开环含积分环节时未补画无穷大圆弧
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

采样过程与香农采样定理 离散控制系统
本卷考法
  • 叙述采样定理的内容
本卷实例
  • 关键一步：写出采样频率不低于信号最高频率两倍这一条件
  • 中间结果：不满足时发生混叠，无法无失真恢复
  • 卡点：要说明信号带宽有限这一前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过叙述采样定理的内容
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 本卷考过把采样频率与最高频率的两倍关系记成相等
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

思路
  • 先用阶跃响应反求 G1(s)，再按扰动不变性求前馈校正使干扰 n 对输出没有影响
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应表达式反求 G1(s) 的传递函数
本卷实例
  • 关键一步：对阶跃响应作拉氏变换后除以输入的拉氏变换 1/s
  • 中间结果：稳态项定增益，指数衰减项定时间常数
  • 卡点：别把指数项的系数当成增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应表达式反求 G1(s) 的传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 本卷考过把稳态值直接当成增益而漏掉输入幅值
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

三二阶指标反求与稳态误差#

思路
  • 由超调量与峰值时间先定阻尼比与自然频率，再回代求 k 与 τ；第二问解特征方程得闭环根；第三问按型别求单位阶跃稳态误差
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间确定阻尼比和无阻尼自然频率
本卷实例
  • 关键一步：用超调量与峰值时间两条公式联立求阻尼比与自然频率
  • 中间结果：峰值时间与超调量只由阻尼比和自然频率决定
  • 卡点：闭环框图与参数位置需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与峰值时间确定阻尼比和无阻尼自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过超调量公式中漏乘百分号
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

  • 把 ξ 的可行域方向取反

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 求该条件下的闭环极点
本卷实例
  • 关键一步：解标准二阶特征方程得一对共轭复根
  • 中间结果：实部为负的阻尼乘自然频率，虚部含阻尼比平方
  • 卡点：极点位置要在 s 平面上标清楚
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
