1一、双参数系统稳定域与动态性能估算#

思路
  • 由结构图逐层化简写开环与闭环传函，列劳斯表求稳定时两参数范围；再由 s3=−4 求复极点，按主导极点近似估算超调量与调节时间。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 对含局部反馈的多回路结构图逐层化简
本卷实例
  • 关键一步：从最内环开始逐层等效，再写总开环传函
  • 中间结果：闭环分母展开为 s 的三次多项式
  • 卡点：化简内环时勿把外环信号当常数，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过对含局部反馈的多回路结构图逐层化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由反馈等效写闭环传递函数
本卷实例
  • 关键一步：定前向通道与反馈通道后套闭环公式
  • 中间结果：闭环分母为 1 加回路增益
  • 卡点：负反馈分母取加号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由反馈等效写闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求双参数的稳定条件
本卷实例
  • 关键一步：对三次特征式列劳斯表并令首列全正
  • 中间结果：得到两个参数的不等式组
  • 卡点：含参数的首列元素须讨论符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求双参数的稳定条件
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由复极点估算超调量与调节时间
本卷实例
  • 关键一步：由复极点实部与虚部求阻尼比和自然频率
  • 中间结果：套欠阻尼公式得超调量与调节时间
  • 卡点：调节时间的误差带按题给 Δ 取值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由复极点估算超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

高阶系统的降阶与主导极点 时域响应与动态性能

2二、含比例微分校正的根轨迹与阻尼比设计#

思路
  • 由 Gc、G0 乘积写开环传函并求闭环传函；列分离点方程求分离点及对应 K，画根轨迹并由虚轴交点求稳定范围，最后用等阻尼线求 ξ=0.707 时 K 与全部极点。
典型环节及其特性 传递函数
本卷考法
  • 指出 Gc 为比例加微分环节并识别其影响
本卷实例
  • 关键一步：把 Gc 拆成比例项与微分项
  • 中间结果：微分项引入一个开环零点
  • 卡点：一阶微分环节与纯微分环节勿混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过指出 Gc 为比例加微分环节并识别其影响
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减

3三、由对数幅频曲线反求传函、判校正类型与裕度#

思路
  • 由校正前 Bode 图低频段高度与斜率反求开环传函；再由校正后曲线读转折频率与高度写校正后传函，两式相除得校正环节并判类型，最后求截止频率与相角裕度。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频特性曲线反求开环传函
本卷实例
  • 关键一步：由低频段斜率定型别、由某频率处高度定增益
  • 中间结果：转折频率对应各惯性环节时间常数
  • 卡点：低频高度须按型别折算而非直接读交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
