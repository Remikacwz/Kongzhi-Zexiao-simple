1一、由微分方程与结构图求传递函数15 分#

思路
  • 对两个微分方程在零初始条件下取拉氏变换，写出各方框的传递函数，再按结构图的串联与反馈等效求输出与误差传递函数。
传递函数的定义与基本性质 传递函数
本卷考法
  • 由微分方程在零初始条件下写出各方框的传递函数
本卷实例
  • 关键一步：对每个微分方程取拉氏变换并把输出比输入写成传函
  • 中间结果：两个一阶微分方程分别给出一个一阶传递函数
  • 卡点：零初始条件的前提勿漏，否则会多出初值项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由微分方程在零初始条件下写出各方框的传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 按串联与反馈等效求闭环传递函数及误差传递函数
本卷实例
  • 关键一步：先定前向通道与反馈通道，再套闭环公式
  • 中间结果：闭环分母为 1 加两通道传函之积
  • 卡点：反馈通道为负，分母取加号，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过按串联与反馈等效求闭环传递函数及误差传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、电动机二阶系统的峰值与稳态误差15 分#

思路
  • 由电机参数写出开环与闭环传函，化成二阶标准形式读出阻尼比与自然频率，算阶跃响应的最大峰值；再数开环积分环节个数定型别，用静态速度误差系数求斜坡稳态误差。
直流电机等机电系统 建模与机电系统
本卷考法
  • 由电机参数与结构图求闭环传递函数
本卷实例
  • 关键一步：按放大器增益与电机时间常数写出开环传函
  • 中间结果：闭环化成二阶标准形式，二次项与一次项由时间常数决定
  • 卡点：机电时间常数与电气时间常数勿代错位置，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由电枢回路电压方程与转矩平衡方程联立
  • 反电动势与转速成正比，电磁转矩与电枢电流成正比
  • 机电时间常数由电气与机械两方面参数共同决定
步骤
  • 写出电枢回路电压平衡方程
  • 写出转矩平衡方程（含负载与粘性摩擦）
  • 消去电枢电流，得到转速或转角对电压的传递函数
通用考法
  • 本卷考过由电机参数与结构图求闭环传递函数
  • 求直流电机转速或位置对电枢电压的传递函数
  • 分析机电时间常数与电气时间常数的数量级关系
常见易错
  • 漏掉反电动势与电磁转矩的耦合项
  • 把电气时间常数与机电时间常数混淆
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化成二阶标准形式读出阻尼比与自然频率
本卷实例
  • 关键一步：把二次项系数归一后对照标准特征式
  • 中间结果：一次项系数对应两倍阻尼比乘自然频率，常值项对应其平方
  • 卡点：阻尼比小于一时才是欠阻尼振荡
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化成二阶标准形式读出阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 计算单位阶跃响应的最大峰值
本卷实例
  • 关键一步：由超调量与稳态值求峰值
  • 中间结果：峰值出现在峰值时刻，等于稳态值乘 1 加超调量
  • 卡点：最大峰值与峰值时间是两个量，勿混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过计算单位阶跃响应的最大峰值
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 判断开环系统的型别并求静态速度误差系数
本卷实例
  • 关键一步：数开环传函中积分环节的个数确定型别
  • 中间结果：一型系统的静态速度误差系数等于开环增益
  • 卡点：系统型别由开环积分环节个数定，与闭环阶数无关
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断开环系统的型别并求静态速度误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：用速度误差系数的倒数求斜坡稳态误差
  • 中间结果：斜坡误差与静态速度误差系数成反比
  • 卡点：用终值定理前须先确认闭环稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、奈奎斯特判据判稳与增益裕度20 分#

思路
  • 由开环传函写出幅相表达式，按频率从零到无穷画奈奎斯特曲线并补画积分环节的无穷大圆弧，由开环右半平面极点数与包围圈数判稳；再令虚部为零求相位穿越频率并算增益裕度。
奈奎斯特判据 稳定性分析
本卷考法
  • 画开环极坐标图并用奈奎斯特判据判别闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数，再看曲线对负一点的包围圈数
  • 中间结果：曲线与负实轴的交点是数包围圈数的关键位置
  • 卡点：含积分环节时须补画无穷大半径圆弧，勿漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过画开环极坐标图并用奈奎斯特判据判别闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
稳定裕度 频域分析
本卷考法
  • 估算相位穿越频率处的增益裕度
本卷实例
  • 关键一步：令开环相角等于负一百八十度求相位穿越频率
  • 中间结果：增益裕度为相位穿越频率处幅值的倒数
  • 卡点：幅值取倒数后勿忘换算成分贝
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过估算相位穿越频率处的增益裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式

4四、非最小相位开环的根轨迹与稳定范围20 分#

思路
  • 开环含一个右半平面极点，按根轨迹法则求实轴段、渐近线、分离点与虚轴交点，再由劳斯判据求使闭环稳定的增益范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 由开环极点求实轴根轨迹段、渐近线交点与夹角
本卷实例
  • 关键一步：按实轴段判据与渐近线公式逐项求取
  • 中间结果：三个极点无零点，渐近线夹角由奇数倍半周除以三给出
  • 卡点：含右半平面极点时实轴段判据仍按右侧零极点计数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过由开环极点求实轴根轨迹段、渐近线交点与夹角
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 由分离点方程求实轴上的分离点坐标
本卷实例
  • 关键一步：列出各开环极点倒数之和为零的方程
  • 中间结果：二次方程两根中只有落在实轴段上的才有效
  • 卡点：落在根轨迹段内的根才是真实分离点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由分离点方程求实轴上的分离点坐标
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴的交点及临界增益
本卷实例
  • 关键一步：令劳斯表首列元素为零解出临界增益
  • 中间结果：辅助方程给出穿越虚轴的共轭纯虚根
  • 卡点：增益为零时原点也是虚轴交点，勿漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益

  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过校验校正后系统的相角裕度是否达标
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

连续系统的离散化 离散控制系统
本卷考法
  • 用双线性变换把连续校正器离散为数字控制器（借位，ds_08 本为状态方程离散化）
本卷实例
  • 关键一步：按双线性公式把复变量替换为 z 的分式并整理
  • 中间结果：数字控制器化为两个 z 多项式的比，系数由采样周期决定
  • 卡点：双线性变换的采样周期代入方向不要写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离散化状态方程由状态转移矩阵在采样周期处的取值构成
  • 输入矩阵是状态转移矩阵与输入矩阵乘积在采样周期上的积分
  • 带零阶保持器时即按上述积分式离散化，输出矩阵不变
步骤
  • 求连续系统的状态转移矩阵
  • 把采样周期代入得到离散状态矩阵
  • 对输入矩阵做积分得到离散输入矩阵
  • 写出差分形式的离散状态方程并按递推求采样点上的响应
通用考法
  • 本卷考过用双线性变换把连续校正器离散为数字控制器（借位，ds_08 本为状态方程离散化）
  • 求连续系统在给定采样周期下的离散化状态方程
  • 由给出的状态响应反求系统矩阵再离散化
  • 计算采样点上的状态与输出序列
常见易错
  • 把采样周期直接当成时间常数代进连续传函
  • 积分上限写成采样周期以外的量，或忘记乘输入矩阵
