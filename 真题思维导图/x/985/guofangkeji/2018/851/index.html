1一、多输入与扰动下求输出20 分#

思路
  • 对结构图用梅森公式分别求参考输入到输出、干扰到输出的传递函数，再由线性叠加写出两输入共同作用下的输出。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求参考输入与干扰分别作用下的输出传递函数
本卷实例
  • 关键一步：先分别把另一输入置零，各求一条通道的传函
  • 中间结果：两输入各有独立输出传函，最后线性叠加
  • 卡点：求扰动通道时勿把参考输入算进去，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求参考输入与干扰分别作用下的输出传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 由系统框图/信号流图用梅森公式求传递函数
本卷实例
  • 关键一步：先找全部独立回路并判断两两是否接触
  • 中间结果：特征式由 1 减回路增益再加不接触回路乘积构成
  • 卡点：互不接触回路勿漏乘，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由系统框图/信号流图用梅森公式求传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、电气系统复阻抗建模求传递函数10 分#

思路
  • 把电容、电阻写成复阻抗，按串联分压或节点关系列 s 域网络方程，整理成 U0(s)/Ui(s)。
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由 RLC 电气网络求输出对输入的传递函数
本卷实例
  • 关键一步：把电容写成 1/(sC)、电阻写成 R，画 s 域复阻抗网络
  • 中间结果：分压比即输出与输入的复阻抗之比
  • 卡点：并联支路复阻抗不能直接相加，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由 RLC 电气网络求输出对输入的传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 用复阻抗法求电路传递函数
本卷实例
  • 关键一步：对节点列电流方程或用串联分压公式
  • 中间结果：整理后分子分母均为 s 的多项式
  • 卡点：电容阻抗写成 Cs 是常见错，应写 1/(sC)
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过用复阻抗法求电路传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

3三、等幅振荡参数与极点左移的稳定域20 分#

思路
  • 由闭环特征方程列劳斯表，令首列元素为零求持续等幅振荡的临界参数与角频率；再作虚轴平移 s=s1−1，对新特征式列劳斯表求全部极点位于 s=−1 左侧的范围。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求临界参数与辅助方程
本卷实例
  • 关键一步：列劳斯表并令含参数的首列元素为零
  • 中间结果：临界时辅助方程给出等幅振荡的角频率
  • 卡点：首列出现零须用辅助方程或 ε 法处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求临界参数与辅助方程
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求全部闭环极点位于指定垂线左侧的参数范围
本卷实例
  • 关键一步：令 s=s1−1 作虚轴平移后对新特征式列劳斯表
  • 中间结果：新劳斯表首列全正即给出参数不等式组
  • 卡点：平移后常数项随参数变化，勿沿用原特征方程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求全部闭环极点位于指定垂线左侧的参数范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由临界参数确定根轨迹与虚轴的交点
本卷实例
  • 关键一步：临界增益处闭环特征方程存在纯虚根
  • 中间结果：辅助方程解出的共轭纯虚根即虚轴交点
  • 卡点：交点频率与等幅振荡角频率含义一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由临界参数确定根轨迹与虚轴的交点
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式

4四、随动系统指标反求参数与斜坡稳态误差20 分#

思路
  • 由结构图写闭环传函并化成二阶标准式，用超调量与调节时间反解阻尼比、自然频率，进而定 K、τ；再定型别并由速度误差系数求 6t 输入的稳态误差。
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量与调节时间要求反求系统参数
本卷实例
  • 关键一步：由超调量定阻尼比、由调节时间定自然频率，再联立解参数
  • 中间结果：两个指标各给一个方程，可联立解两个未知参数
  • 卡点：调节时间的误差带系数须按题给 ±5% 取
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量与调节时间要求反求系统参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化成二阶标准形式
本卷实例
  • 关键一步：二次项系数归一后对照标准特征式
  • 中间结果：一次项系数对应两倍阻尼比乘自然频率
  • 卡点：增益 K 同时出现在分子，勿当无关量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化成二阶标准形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率写超调量与调节时间表达式
本卷实例
  • 关键一步：套欠阻尼二阶系统的超调量与调节时间公式
  • 中间结果：两式分别只含阻尼比与两参数之积
  • 卡点：两种误差带的调节时间系数勿混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率写超调量与调节时间表达式
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 判断系统型别并求静态速度误差系数
本卷实例
  • 关键一步：数开环传函中积分环节个数确定型别
  • 中间结果：一型系统的静态速度误差系数等于开环增益
  • 卡点：型别由开环积分环节定，与闭环阶数无关
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断系统型别并求静态速度误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求输入为 6t 时系统的稳态误差
本卷实例
  • 关键一步：用速度误差系数与输入幅度求斜坡稳态误差
  • 中间结果：稳态误差与静态速度误差系数成反比
  • 卡点：用终值定理前须先确认闭环稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求输入为 6t 时系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
