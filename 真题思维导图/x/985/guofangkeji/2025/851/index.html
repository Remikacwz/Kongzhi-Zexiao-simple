1一、简答题：传递函数与性能指标#

思路
  • 写出传递函数定义与五个典型环节的时间常数表达式，再分时域法与频域法列举典型输入信号及其性能评价指标
传递函数的定义与基本性质 传递函数
本卷考法
  • 默写传递函数的定义
  • 写出零初始条件下输入输出的拉氏变换之比
本卷实例
  • 关键一步：先点明零初始条件这一前提，再写输出与输入拉氏变换之比
  • 关键一步：可从单位脉冲响应的拉氏变换角度补充说明
  • 中间结果：定义强调的是变换之比只由系统结构与参数决定，与输入形式无关
  • 卡点：漏写零初始条件，把初始值带进变换结果会改变定义含义
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过默写传递函数的定义
  • 本卷考过写出零初始条件下输入输出的拉氏变换之比
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
典型环节及其特性 传递函数
本卷考法
  • 写出五个典型环节的名称及其时间常数形式的传递函数
本卷实例
  • 关键一步：按环节的输入输出关系逐类写出，时间常数形式要求分子分母都出现时间常数
  • 关键一步：把积分、惯性、一阶微分、振荡、二阶微分五类写成统一格式
  • 中间结果：时间常数形式下分母常数项归一，便于直接读出时间常数与阻尼比
  • 卡点：本题限定五个典型环节，比例环节不含时间常数，作答时不要多写
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过写出五个典型环节的名称及其时间常数形式的传递函数
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 列举时域法的典型输入信号与系统性能评价指标
本卷实例
  • 关键一步：时域常用信号按冲激、阶跃、斜坡、抛物线依次升高阶次
  • 关键一步：把评价指标归到超调量、调节时间、上升时间与峰值时间上
  • 中间结果：阶跃信号用得最多，其响应指标与二阶系统阻尼比密切相关
  • 卡点：容易只写信号而漏写指标，题目两个问题都要答
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过列举时域法的典型输入信号与系统性能评价指标
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

稳定裕度 频域分析
本卷考法
  • 列举频域法的典型输入信号与系统性能评价指标
本卷实例
  • 关键一步：频域法以正弦信号为典型输入，考察系统对不同频率的幅值与相位响应
  • 关键一步：评价指标从开环与闭环两条线给出，覆盖裕度与带宽两类
  • 中间结果：开环看剪切频率、相角裕度与幅值裕度，闭环看带宽与谐振峰值
  • 卡点：只写相角裕度会漏掉幅值裕度与带宽
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过列举频域法的典型输入信号与系统性能评价指标
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

2二、计算题：由结构图求传递函数#

思路
  • 由给定的多回路结构图求系统闭环传递函数，图未读，按梅森公式与逐层化简两条路线处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图改画信号流图并用梅森公式求传递函数
本卷实例
  • 关键一步：把结构图上的信号与方框分别对应成节点与支路
  • 关键一步：找出全部单独回路写特征式，再找前向通路及其余子式
  • 中间结果：特征式由回路增益按接触情况逐阶组合，余子式只保留与通路不接触的回路
  • 卡点：不接触回路易漏算或重复计数，具体回路需回原卷核对结构图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图改画信号流图并用梅森公式求传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简求闭环传递函数
本卷实例
  • 关键一步：从最内层回路起逐层合并成等效环节，再参与外层的串并联
  • 关键一步：可用逐层化简重算一遍，检验梅森公式得到的结果
  • 中间结果：逐层化简与梅森公式应得到同一个特征式，可互为校验
  • 卡点：移动比较点或引出点时要补上相应环节，否则回路增益写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简求闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

3三、计算题：根轨迹绘制与稳定域#

思路
  • 由开环传函画根轨迹，求渐近线中心点与夹角、根轨迹与虚轴交点及临界增益，再由图确定系统稳定的增益范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 求根轨迹的渐近线中心点与实轴夹角
本卷实例
  • 关键一步：先标出开环极点并判断实轴上哪些段属于根轨迹
  • 关键一步：渐近线条数等于极点数减零点数，中心点由零极点实部之和除以条数
  • 中间结果：本题为一个实极点加一对共轭复极点，条数为三，夹角按六十度等分
  • 卡点：复极点实部相同，求和时不要漏算；形状需回原卷核对根轨迹图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过求根轨迹的渐近线中心点与实轴夹角
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及此时的临界增益
本卷实例
  • 关键一步：写出闭环特征多项式后列劳斯表
  • 关键一步：令劳斯表首列出现零元素，再用辅助方程解出纯虚根与临界增益
  • 中间结果：临界增益下特征多项式含一对纯虚根，辅助方程的二次项决定交点频率
  • 卡点：只代入一个交点频率会漏解，穿越位置需回原卷核对根轨迹图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及此时的临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点确定系统稳定的增益范围
本卷实例
  • 关键一步：根轨迹全部位于左半平面时系统稳定，临界点对应虚轴交点
  • 关键一步：在起点增益与临界增益之间取区间即得稳定范围
  • 中间结果：本题增益从零增大时先稳定，越过临界值后进入右半平面
  • 卡点：稳定区间端点的开闭要看劳斯表首列是否含零，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹与虚轴交点确定系统稳定的增益范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

4四、计算题：二阶系统性能与稳态误差#

思路
  • 化闭环标准二阶形式，求单位阶跃超调量、欠阻尼且稳定时的参数范围、调节时间小于一秒的参数范围，以及单位斜坡稳态误差
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把单位负反馈系统化为标准二阶形式并读出阻尼比与自然频率
本卷实例
  • 关键一步：先由开环传函写闭环特征多项式，再与标准二阶形式逐项比对
  • 关键一步：一次项系数对应两倍阻尼比乘自然频率，常数项对应自然频率的平方
  • 中间结果：本题特征多项式的一次项与增益、第二个参数之差有关，常数项就是分子增益
  • 卡点：源文分子增益在公式里记为 K、小问却写 K₁，两者指同一参数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把单位负反馈系统化为标准二阶形式并读出阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求单位阶跃输入下的超调量
本卷实例
  • 关键一步：先按阻尼比取值分过阻尼与欠阻尼两种情况讨论
  • 关键一步：过阻尼无超调，欠阻尼再把阻尼比代入超调量公式

  • 由给定状态方程组写状态空间表达式并分析渐近稳定性，判断能控性与能观性，再设计状态反馈把闭环极点配置到三个负整数处
状态空间表达式的建立 状态空间分析
本卷考法
  • 由给定状态方程组写出状态空间表达式
本卷实例
  • 关键一步：按状态导数的系数直接拼出系统矩阵，输入矩阵取输入项所在的那一列为对应系数
  • 关键一步：输出方程只保留输出所涉及的那一个状态
  • 中间结果：系统矩阵的三行系数分别来自三个状态方程，第三个方程与第一个状态耦合
  • 卡点：第三个状态方程含第一个状态，拼矩阵时不要漏掉第一列的非零元素
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由给定状态方程组写出状态空间表达式
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 由系统矩阵特征值分析系统的渐近稳定性
本卷实例
  • 关键一步：先求特征方程并因式分解，再由特征值实部的符号判断渐近稳定性
  • 关键一步：只要有一个特征值实部不为负，系统就不是渐近稳定
  • 中间结果：本题特征方程可分解为一对重根与一个单根，特征值不全为负
  • 卡点：把渐近稳定与稳定混为一谈，虚轴上的根属于临界情况
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过由系统矩阵特征值分析系统的渐近稳定性
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

能控性与能观性 状态空间分析
本卷考法
  • 判断系统的能控性与能观性
本卷实例
  • 关键一步：三阶系统分别构造能控性矩阵与能观性矩阵，各含三个列或行
  • 关键一步：分别求秩并与系统阶数比较，都满秩才既可控又可观
  • 中间结果：本题两个矩阵的秩都与阶数相等，故既完全能控又完全能观
  • 卡点：能控性矩阵算到二阶就停会误判，三阶需要算到系统矩阵的二次幂乘输入矩阵
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断系统的能控性与能观性
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

状态反馈与极点配置 状态空间分析
本卷考法
  • 设计状态反馈使闭环极点配置到指定位置
本卷实例
  • 关键一步：先由三个期望极点写出期望特征多项式
  • 关键一步：再求带状态反馈后闭环系统的特征多项式，两个多项式逐项比较系数解出反馈增益
  • 中间结果：期望特征多项式为三个负整数根连乘，展开后各阶系数都是正整数
  • 卡点：反馈只作用在输入矩阵非零的那一行，比较系数时注意符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过设计状态反馈使闭环极点配置到指定位置
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
