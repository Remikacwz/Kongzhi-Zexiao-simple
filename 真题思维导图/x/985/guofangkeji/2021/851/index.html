1一、信号流图与梅森公式求传递函数#

思路
  • 由系统框图逐支路写出增益并画信号流图，找出全部回路与各前向通路，再用梅森公式写出闭环传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由系统框图画信号流图并用梅森公式求 T(s)
本卷实例
  • 关键一步：先按框图各支路定增益，再列举全部回路与各前向通路
  • 中间结果：特征式为 1 减各回路增益之和再加互不接触回路乘积
  • 中间结果：T(s) 为各前向通路增益乘其余子式之和再除以特征式
  • 卡点：框图以图给出，支路增益需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由系统框图画信号流图并用梅森公式求 T(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、二阶系统性能指标反求参数#

思路
  • 由闭环结构写出二阶标准形式，用超调量与峰值时间联立求 K1、Kt，再按欠阻尼公式算上升时间与调节时间。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化成二阶标准形式读出阻尼比与自然频率
本卷实例
  • 关键一步：把闭环传函分母与标准二阶特征式逐项对照
  • 中间结果：一次项系数对应 2ξωn，常值项对应 ωn 的平方
  • 卡点：框图以图给出，反馈支路含 Kt 的接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化成二阶标准形式读出阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由 σ% 与 tp 反求参数并计算 tr、ts
本卷实例
  • 关键一步：先用超调量求阻尼比，再由峰值时间求自然频率
  • 中间结果：上升时间由 π 减 arccosξ 再除以阻尼振荡频率得到
  • 卡点：上升时间与调节时间用的误差带系数不同，不要套同一公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由 σ% 与 tp 反求参数并计算 tr、ts
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由两项性能指标要求联立反求 K1 与 Kt
本卷实例
  • 关键一步：把两个指标分别代入二阶公式后联立求解
  • 中间结果：两式分别约束 ξωn 与 ωn，恰好解出两个未知量
  • 卡点：解出 ωn 后不要漏回代求微分反馈系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由两项性能指标要求联立反求 K1 与 Kt
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

3三、由阻尼比与斜坡稳态误差反求参数#

思路
  • 由结构图求开环与闭环传函，写出阻尼比与斜坡稳态误差两个表达式联立求 K、τ，并先确认系统稳定。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图求开环与闭环传递函数
本卷实例
  • 关键一步：先按反馈等效写开环，再按单位负反馈写闭环
  • 中间结果：开环为比例增益除以 s(s+2−Kτ) 的形式
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由结构图求开环与闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征式写出阻尼比表达式
本卷实例
  • 关键一步：把闭环特征式化成二阶标准形式读一次项系数
  • 中间结果：阻尼比由一次项系数与自然频率共同决定
  • 卡点：τ 为负时阻尼比反而增大，注意符号方向
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征式写出阻尼比表达式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由斜坡输入稳态误差条件反求参数
本卷实例
  • 关键一步：用终值定理先写出斜坡误差表达式
  • 中间结果：斜坡误差等于闭环一次项系数与常值项之比
  • 卡点：用终值定理前必须先确认闭环稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由斜坡输入稳态误差条件反求参数
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

4四、参数根轨迹绘制与性能分析#

思路
  • 把含 α 的闭环特征方程整理成以 α 为参数的等效开环，按参数根轨迹法则求渐近线、分离点、虚轴交点，再由它们划分稳定范围与欠阻尼范围。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 把含参数 α 的特征方程化为等效开环画参数根轨迹
本卷实例
  • 关键一步：把只含参数 α 的项分离出来作为等效开环分子
  • 中间结果：等效开环为 0.25α 除以 s(s+0.5) 平方的形式
  • 卡点：参数以分子增益形式出现，须按参数根轨迹处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过把含参数 α 的特征方程化为等效开环画参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 求根轨迹渐近线与实轴的交点及夹角
本卷实例
  • 关键一步：由极点个数减零点个数确定渐近线条数
  • 中间结果：交点取所有极点坐标平均值的相反数
  • 卡点：等效开环无零点，不能把参数零点算进极点数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过求根轨迹渐近线与实轴的交点及夹角
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹分离点坐标及该点对应的 α
本卷实例
  • 关键一步：由等效开环极点列出分离点方程
  • 中间结果：分离点是实轴上两段根轨迹相向会合的位置
  • 卡点：求出的根必须落在实轴根轨迹段上才有效
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹分离点坐标及该点对应的 α
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界参数
本卷实例
  • 关键一步：令 s 等于 jω 代入特征方程后分离实部与虚部
  • 中间结果：由劳斯表首列为零得到临界参数
  • 卡点：辅助方程的根才是虚轴交点，不要只取一半
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界参数
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹确定稳定范围与欠阻尼范围
本卷实例
  • 关键一步：用分离点对应参数与虚轴交点对应参数分段讨论
  • 中间结果：参数在两临界值之间时闭环极点位于左半平面
  • 卡点：欠阻尼范围从分离点对应参数算到临界参数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹确定稳定范围与欠阻尼范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

5五、由对数频率特性求传函并判稳#

思路
  • 由渐近幅频特性读转折频率与各段斜率，写出所含典型环节与开环传函，再求单位负反馈的闭环特征方程用劳斯判据判稳。
典型环节的对数频率特性 频域分析
本卷考法

本卷实例
  • 关键一步：按各频段斜率的变化量推出对应的环节类型
  • 中间结果：低频段斜率与 0dB 交点给出积分与比例环节信息
  • 卡点：Bode 图以图给出，转折频率与曲线高度需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例环节是水平线，积分与微分分别是 -20 与 +20 dB/dec 的斜线
  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec
  • 一阶微分环节与惯性环节幅频互为镜像
  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤
  • 把传递函数分解为典型环节乘积
  • 逐环节画出对数幅频渐近线与相频曲线
  • 代数相加得到总特性
通用考法
  • 本卷考过由渐近幅频特性识别系统所含典型环节
  • 画出某一典型环节的 Bode 图
  • 由 Bode 图识别环节类型
  • 说明转角频率处的幅值与相角
常见易错
  • 把惯性环节高频渐近线的 -20 写成 -40
  • 振荡环节谐振峰位置误当作 ωn

  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节

  • 由实验频率特性辨识系统模型

常见易错

思路

  • 把时域指标折算为频域指标

  • 忽略零阶保持器带来的相位滞后

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态观测器用输出与输入重构状态，前提是系统能观
  • 极点配置法与龙伯格观测器是两种常用形式
  • 观测器误差动态由 A-LC 的特征值决定
  • 观测器极点通常取得比系统极点快若干倍
步骤
  • 验证系统能观性
  • 写出观测器方程并求误差动态矩阵
  • 按期望特征多项式比较系数求出 L
  • 校验观测器收敛速度是否合适
通用考法
  • 本卷考过设计全维状态观测器使观测器极点都在 −10
  • 设计全维状态观测器
  • 由期望观测器极点求反馈增益阵 L
  • 分析观测器与状态反馈组合后的系统极点
常见易错
  • 把观测器增益阵写成了状态反馈增益阵的形式
  • 忽略观测器极点过快会放大噪声
