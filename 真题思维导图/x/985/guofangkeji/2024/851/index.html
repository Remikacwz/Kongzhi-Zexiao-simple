1一、简答题：时域性能指标与零阶保持器#

思路
  • 列举评价控制系统时域性能的指标并说明各自含义，再说明零阶保持器的定义、传递函数与频率特性
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 第(1)问列举评价控制系统时域性能的指标及含义
本卷实例
  • 关键一步：按阻尼程度与快速性两类归纳超调量、调节时间、峰值时间、上升时间
  • 中间结果：超调量描述阻尼程度，其余三个指标一起描述系统响应的快速性
  • 卡点：无振荡与有振荡两种响应的上升时间定义并不相同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过第(1)问列举评价控制系统时域性能的指标及含义
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

采样过程与香农采样定理 离散控制系统
本卷考法
  • 第(2)问说明零阶保持器的定义、传递函数与频率特性
本卷实例
  • 关键一步：从离散信号到连续信号的转换与采样点之间如何插值切入
  • 中间结果：零阶保持器的传递函数为括号内一减 e 的负 sT 次方再除以 s
  • 卡点：不要把它当成纯比例环节而漏掉半个采样周期的相位滞后
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过第(2)问说明零阶保持器的定义、传递函数与频率特性
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

2二、根轨迹绘制与稳定及欠阻尼范围#

思路
  • 由开环传函列闭环特征方程，按根轨迹法则求实轴段、分离点、虚轴交点与渐近线，再由这些临界点划分稳定与欠阻尼的 K 范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 第(1)(4)问求实轴根轨迹段与渐近线交点、夹角
本卷实例
  • 关键一步：无开环零点，三个开环极点分别落在原点与负实轴上
  • 中间结果：实轴根轨迹取相邻两极之间的线段，渐近线交点在极点坐标平均值处
  • 卡点：渐近线夹角要按奇数倍圆周率除以极零点个数差来取
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过第(1)(4)问求实轴根轨迹段与渐近线交点、夹角
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 第(2)问求根轨迹分离点坐标
本卷实例
  • 关键一步：由闭环特征方程把增益写成 s 的函数后令其导数为零
  • 中间结果：分离点方程的两个根中只有落在实轴根轨迹段上的那个有效
  • 卡点：不做取舍会把不在根轨迹上的根也当成分离点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过第(2)问求根轨迹分离点坐标
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 第(3)问求根轨迹与虚轴的交点
本卷实例
  • 关键一步：把 s 换成纯虚变量代入特征方程后分离实部与虚部
  • 中间结果：由劳斯表首列临界条件得到辅助方程，再解出交点频率
  • 卡点：只代一个频率会漏掉另一组对称的交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过第(3)问求根轨迹与虚轴的交点
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 第(5)(6)问由根轨迹确定稳定与欠阻尼的 K 范围
本卷实例
  • 关键一步：用分离点对应增益与虚轴交点对应增益作为分段的界点
  • 中间结果：系统稳定时增益位于两个临界值之间的一段区间
  • 卡点：欠阻尼区间从分离点对应增益算到虚轴交点对应增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过第(5)(6)问由根轨迹确定稳定与欠阻尼的 K 范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

3三、由阶跃响应峰值反求二阶系统参数#

思路
  • 由系统框图化简求闭环传函并化成二阶标准形式，用峰值时间与峰值反求阻尼比与自然频率，再算调节时间
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 第(1)问由系统框图求开环与闭环传递函数
本卷实例
  • 关键一步：先按反馈等效化简内环，再按单位负反馈写闭环传函
  • 中间结果：闭环化为一次项系数含 K2、常值项含 K1 的二阶标准式
  • 卡点：化简内环时不要把外环的信号当成常数处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过第(1)问由系统框图求开环与闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 第(1)问由阶跃响应峰值指标反求 K1 与 K2
本卷实例
  • 关键一步：先用峰值时间求自然频率，再由峰值与稳态值之比求阻尼比
  • 中间结果：把求得的阻尼比与自然频率代回系数关系解出两个参数
  • 卡点：峰值与稳态值之比对应超调量，分子分母不要倒置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过第(1)问由阶跃响应峰值指标反求 K1 与 K2
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式

4四、最小拍数字控制器与响应序列#

思路
  • 按最小拍设计取闭环脉冲传函为 z 的负一次方，反解数字控制器，再用长除法求输出与控制器的时间序列
数字控制器与最少拍设计 离散控制系统
本卷考法
  • 第(1)问在单位阶跃输入下设计最小拍控制器 D(z)
本卷实例
  • 关键一步：先按一拍到达取闭环脉冲传函，再由闭环与开环的关系反解 D(z)
  • 中间结果：设计出的控制器为两个一阶多项式之比，需检查物理可实现性
  • 卡点：忽略因果可实现条件会把做不到的控制器交出去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最少拍系统指在典型输入下经过有限拍达到无稳态误差
  • 设计需要满足可实现性与稳定性约束
  • 最少拍系统的闭环脉冲传递函数由输入类型确定
  • 最少拍设计通常导致很大的控制量，需加限制
步骤
  • 确定输入类型及对应的误差传函形式
  • 按无稳态误差要求构造闭环脉冲传递函数
  • 由 D(z)=Φ(z)/[G(z)(1-Φ(z))] 求数字控制器
  • 检验可实现性、稳定性与控制量大小
通用考法
  • 本卷考过第(1)问在单位阶跃输入下设计最小拍控制器 D(z)
  • 设计最少拍数字控制器
  • 比较不同输入类型下的最少拍数
  • 分析最少拍系统存在的问题
常见易错
  • 忽略 D(z) 必须是物理可实现的因果系统
  • 闭环传函构造时未满足稳定性约束条件
公式
脉冲传递函数 离散控制系统
本卷考法
  • 第(2)问由控制器与被控对象求输出的时间序列
本卷实例
  • 关键一步：写出闭环输出脉冲传函后作长除法逐拍展开
  • 中间结果：阶跃输入下输出从第二拍起保持为稳态值
  • 卡点：长除法得到的系数与采样拍号的对应容易错位
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过第(2)问由控制器与被控对象求输出的时间序列
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)

5五、由对数频率特性反求传函与稳定裕度#

思路
  • 由渐近幅频特性读转折频率与低频段高度写出开环传函，再求截止频率与相角裕度，并判断幅值裕度
由 Bode 图反求传递函数 频域分析
本卷考法
  • 第(1)问由对数渐近幅频特性反求开环传递函数
本卷实例
  • 关键一步：用低频段斜率定积分环节个数，用低频段高度定增益
  • 中间结果：某个转折频率处斜率减小对应串入一个惯性环节
  • 卡点：转折频率与斜率变化量看错会把环节阶数写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

思路

本卷考法
  • 第(1)问构造能观判别阵并判断是否能任意配置观测器极点
本卷实例
  • 关键一步：把输出矩阵及其与系统矩阵的乘积按行堆叠成判别阵
  • 中间结果：判别阵满秩说明系统完全可观测，观测器极点可任意配置

  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
