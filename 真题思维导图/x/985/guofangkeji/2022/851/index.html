1一、由传递函数求单位阶跃响应#

思路
  • 把传递函数与单位阶跃输入相乘得输出像函数，作部分分式展开后逐项取拉氏反变换，由极点位置确定各响应模态并写出时域响应的形式。
零极点分布与响应模态 传递函数
本卷考法
  • 由输出像函数的极点分布确定阶跃响应所含的响应模态
本卷实例
  • 关键一步：先对 c(s) 作部分分式分解，每一项对应一个极点模态
  • 中间结果：三个互异实极点各对应一个指数衰减项
  • 卡点：分子含一次项与常数项，分式系数符号容易抄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由输出像函数的极点分布确定阶跃响应所含的响应模态
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由传递函数与单位阶跃输入求系统全响应（借位）
本卷实例
  • 关键一步：把各模态系数求出后写成时间函数的线性组合
  • 中间结果：阶跃输入使一个极点移到原点，响应含等幅阶跃分量
  • 卡点：漏乘输入的 1/s 会少掉原点极点对应的稳态项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由传递函数与单位阶跃输入求系统全响应（借位）
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

2二、双输入结构图与扰动不变性#

思路
  • 先令扰动为零求参考输入到输出的传递函数，再令参考输入为零单独求扰动通道传函，最后令扰动传函的分子整体为零解出补偿环节，实现扰动不变性。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图用梅森公式求参考输入到输出的传递函数
本卷实例
  • 关键一步：先列举全部单独回路并判断两两是否接触，再列前向通路
  • 中间结果：特征式由各回路增益与互不接触回路组合而成
  • 卡点：结构图以图给出，回路接触关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图用梅森公式求参考输入到输出的传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求扰动到输出的传函并解出扰动不变性的补偿条件
本卷实例
  • 关键一步：求扰动通道传函时把参考输入置零后单独化简
  • 中间结果：使扰动传函分子为零即可解出补偿环节的表达式
  • 卡点：扰动注入点与补偿支路的极性以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求扰动到输出的传函并解出扰动不变性的补偿条件
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

3三、二阶系统性能指标反求参数#

思路
  • 由结构图求闭环传函并化成二阶标准形式，用超调量与峰值时间两式联立求 K1、K2，最后回代校验两个参数是否落在欠阻尼范围。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图求开环与闭环传递函数
本卷实例
  • 关键一步：按内环反馈再串联的顺序逐层写出开环传函
  • 中间结果：闭环特征式的一次项系数含内环反馈增益的乘积
  • 卡点：结构图以图给出，内外环的接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由结构图求开环与闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征式对照标准二阶形式读出阻尼比与自然频率
本卷实例
  • 关键一步：把一次项与常值项分别对应 2ξωn 与 ωn 的平方
  • 中间结果：由超调量反解阻尼比，再由峰值时间定自然频率
  • 卡点：特征式须先化成 s 平方项系数为 1 的标准形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征式对照标准二阶形式读出阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由两项性能指标要求联立反求 K1 与 K2
本卷实例
  • 关键一步：两个指标各给一个方程，恰好解出两个未知参数
  • 中间结果：先由 ξ、ωn 算出 K1，再回代一次项系数求 K2
  • 卡点：回代后应检查两参数是否满足欠阻尼的取值条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由两项性能指标要求联立反求 K1 与 K2
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

4四、正反馈零度根轨迹与动态性能#

思路
  • 对象含重零点与共轭极点且为单位正反馈，按零度根轨迹法则求分离点、虚轴交点和起始角，再用闭环极点近似估算超调量与调节时间。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 判断正反馈系统应按零度根轨迹绘制并写出等效开环
本卷实例
  • 关键一步：正反馈取 1 减 GH 为零，故相角条件用 0 度而非常规 180 度
  • 中间结果：等效开环分子为 K 乘重零点、分母为一对共轭极点
  • 卡点：零度与 180 度根轨迹的相角条件相反，不能混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过判断正反馈系统应按零度根轨迹绘制并写出等效开环
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹分离点坐标及该点对应的 K
本卷实例
  • 关键一步：由重零点与共轭极点列分离点方程并筛出有效根
  • 中间结果：分离点是实轴上两段根轨迹相向会合的位置
  • 卡点：解出的根须落在实轴根轨迹段上才是有效分离点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹分离点坐标及该点对应的 K
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及对应临界 K
本卷实例
  • 关键一步：对闭环特征式列劳斯表并令首列元素为零
  • 中间结果：临界 K 处出现纯虚根，对应等幅振荡
  • 卡点：共轭虚根总是成对出现，不要漏掉其中一个
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及对应临界 K
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹分区确定系统过阻尼时的 K 范围
本卷实例
  • 关键一步：以分离点与虚轴交点为界把参数分成几段讨论
  • 中间结果：闭环极点全落在负实轴时系统为过阻尼
  • 卡点：过阻尼区间与稳定区间不是同一个条件，不要等同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹分区确定系统过阻尼时的 K 范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由闭环共轭极点求超调量与 5% 误差带调节时间
本卷实例
  • 关键一步：由极点实部与虚部反算阻尼比和自然频率
  • 中间结果：超调量随阻尼比指数衰减，调节时间由实部绝对值定
  • 卡点：闭环零点会放大超调，按主导极点估算会偏小
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
