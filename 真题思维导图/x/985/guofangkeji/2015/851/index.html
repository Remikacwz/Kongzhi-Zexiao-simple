1一、倒立摆动力学建模、线性化与全响应20 分#

思路
  • 对绕铰点转动的圆球列转动定律建立入射角的动力学方程，在小角度下用正弦约等于角本身线性化，再由含初值的拉氏变换解出全响应。
机械系统建模 建模与机电系统
本卷考法
  • 对绕铰点转动的圆球列转动定律，建立入射角 θ 的动力学方程
本卷实例
  • 关键一步：对铰点取矩，忽略杆质量与转动惯量写转动方程
  • 中间结果：转动惯量按圆球绕铰点计，恢复力矩由重力分力给出
  • 卡点：勿把小球当质点平动处理，须按绕铰点转动建模
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过对绕铰点转动的圆球列转动定律，建立入射角 θ 的动力学方程
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
非线性模型的线性化 建模与机电系统
本卷考法
  • 在小角度条件下对倒立摆非线性方程做线性化
本卷实例
  • 关键一步：令正弦约等于角本身代入，只保留一次项
  • 中间结果：线性化后为角位移的二阶常系数齐次方程
  • 卡点：平衡点与正方向约定不同会使重力项符号相反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 在工作点附近作泰勒展开并忽略高阶项
  • 线性化模型只在小偏差范围内有效
  • 必须先求出平衡工作点
步骤
  • 由静态方程求平衡工作点
  • 在工作点处求偏导得到增量系数
  • 写出以增量表示的线性化方程
通用考法
  • 本卷考过在小角度条件下对倒立摆非线性方程做线性化
  • 对非线性微分方程在平衡点处线性化
  • 写出小偏差线性化模型的传递函数
常见易错
  • 未先求平衡点就直接展开
  • 把增量符号去掉后与原始变量混用

线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由线性化方程与两个初值求系统的全响应 θ(t)
本卷实例
  • 关键一步：把初值代入拉氏变换的微分性质再解出像函数
  • 中间结果：像函数由初值决定的自由响应项构成，含两个待定系数
  • 卡点：初值含一阶导，做二阶导变换时勿漏该项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由线性化方程与两个初值求系统的全响应 θ(t)
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

2二、扰动下的稳态误差与前馈、顺馈补偿20 分#

思路
  • 按叠加原理分别求参考输入与扰动单独作用下的误差传函，判稳后用终值定理算稳态误差；再按不变性原理设计前馈与顺馈补偿器，最后调前置增益使阶跃误差为零。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 令参考输入为零，求扰动到误差的传递函数
本卷实例
  • 关键一步：用叠加原理令参考输入为零，单独看扰动通道
  • 中间结果：扰动误差传函由扰动通道传函与开环传函共同决定
  • 卡点：求扰动通道时勿把参考输入分量混进来，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过令参考输入为零，求扰动到误差的传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 计算扰动单独作用下的稳态误差并核查稳定性
本卷实例
  • 关键一步：先用劳斯判据确认闭环稳定再对误差像函数用终值定理
  • 中间结果：稳态误差取拉氏变量趋于零时的极限
  • 卡点：未判稳就套终值定理会得到错误的稳态值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过计算扰动单独作用下的稳态误差并核查稳定性
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 分别算阶跃参考输入与阶跃扰动下的稳态误差并求总量
本卷实例
  • 关键一步：两种输入分别独立求误差后按线性叠加
  • 中间结果：总稳态跟踪误差为两项的代数和
  • 卡点：扰动误差的符号取决于作用点，勿只取绝对值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过分别算阶跃参考输入与阶跃扰动下的稳态误差并求总量
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

反馈校正与复合控制 系统校正
本卷考法
  • 按扰动不变性原理设计前馈与顺馈补偿器
本卷实例
  • 关键一步：令扰动到误差的传函恒为零，反解补偿器传函
  • 中间结果：补偿器由扰动通道与被控通道的传函之比给出
  • 卡点：补偿器含微分项时要检查物理可实现性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过按扰动不变性原理设计前馈与顺馈补偿器
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

减小稳态误差的措施 稳态误差
本卷考法
  • 设计前置比例放大器使系统对阶跃指令成为无差系统
本卷实例
  • 关键一步：写出阶跃误差表达式并令其分子中的常值项为零
  • 中间结果：前置增益由闭环分数中常数项的匹配条件定出
  • 卡点：提高增益前须核对该增益下系统仍稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计前置比例放大器使系统对阶跃指令成为无差系统
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

思路

反馈校正与复合控制 系统校正
本卷考法
  • 把内环反馈等效为输出反馈校正器并说明其类型
本卷实例
  • 关键一步：用框图等效把内环反馈折算到误差通道上
  • 中间结果：等效校正器分子含一阶微分、分母含积分，属比例积分形式
  • 卡点：内环反馈与串联校正的等效方向相反，勿写反，需回原卷核对图

多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路系统的逐层化简求闭环传递函数
本卷实例
  • 关键一步：先化简内环再化简外环，写成单一闭环形式
  • 中间结果：闭环分母为二阶多项式，增益只进入一次项系数
  • 卡点：化简内环时勿把外环信号当常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路系统的逐层化简求闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环特征式对照二阶标准形式读阻尼比与自然频率
本卷实例
  • 关键一步：把特征式二次项系数归一后逐项对照标准形式
  • 中间结果：自然频率与增益无关，阻尼比随增益增大而增大
  • 卡点：归一化时勿漏除二次项的系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环特征式对照二阶标准形式读阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 分析阻尼比与自然频率变化对超调量和调节时间的影响
本卷实例
  • 关键一步：由调节时间与超调量公式判断其随增益的变化趋势
  • 中间结果：自然频率不变而阻尼比增大时，超调与调节时间均下降
  • 卡点：调节时间的误差带取 2% 准则，系数与 5% 不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数

  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过由状态空间表达式求输入输出传递函数
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

8八、离散闭环系统的单位阶跃响应#

思路
  • 由给定闭环脉冲传函写出特征方程并求闭环极点，再乘阶跃输入的 z 变换用长除法逐拍求输出序列。
脉冲传递函数 离散控制系统
本卷考法
  • 由给定闭环脉冲传递函数分析离散闭环系统
本卷实例
  • 关键一步：由闭环脉冲传函写出特征方程并解出闭环极点
  • 中间结果：共轭复极点对应衰减振荡，输出为振荡序列
  • 卡点：离散极点按模与相角判断衰减与振荡快慢
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过由给定闭环脉冲传递函数分析离散闭环系统
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)

离散系统的动态性能与极点分布 离散控制系统
本卷考法
  • 由闭环极点分布判断离散系统响应形式
本卷实例
  • 关键一步：按极点在 z 平面单位圆内的位置判断是否衰减
  • 中间结果：共轭极点对应振荡，极点的模决定衰减速度
  • 卡点：勿把 z 平面极点当 s 平面极点直接读阻尼比
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点在 z 平面上的位置决定响应形式
  • 极点越靠近原点衰减越快，越靠近单位圆振荡越强
  • 极点的幅角决定振荡频率，幅值决定衰减速度
  • 采样周期增大会使动态性能变差甚至不稳定
步骤
  • 求闭环脉冲传递函数的极点
  • 按极点在单位圆内的位置判断响应形式
  • 由极点的模与幅角估算衰减与振荡频率
  • 与连续系统指标对应关系相互校验
通用考法
  • 本卷考过由闭环极点分布判断离散系统响应形式
  • 由闭环极点分布判断动态性能
  • 与连续域指标互相换算
  • 说明采样周期对动态性能的影响
常见易错
  • 把 z 平面极点当作 s 平面极点直接读阻尼比
  • 忽略单位圆上极点对应等幅振荡
