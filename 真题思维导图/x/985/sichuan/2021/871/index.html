4四、校正前后Bode图求传函与性能#

思路
  • 先由校正前幅频曲线求原系统传函，再由校正后曲线低频抬高、高频不变反求校正装置，并估算校正后性能
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由校正前开环对数幅频曲线求原系统传递函数
本卷实例
  • 关键一步：低频段斜率确定系统型别，某频率处的幅值或延长线交点确定开环增益
  • 关键一步：各转折频率处斜率的变化量确定环节类型与时间常数
  • 中间结果：原系统低频段斜率为负20dB/dec、型别为一，曲线给出一个转折频率
  • 卡点：曲线数值都由图读出，需回原卷核对图；低频段高度未折算型别会算错增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由校正前开环对数幅频曲线求原系统传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
滞后校正 系统校正
本卷考法
  • 由校正前后幅频曲线差异判断校正方式并求校正装置传函
本卷实例
  • 关键一步：低频段抬高而高频段不变是滞后校正；校正装置传函等于校正后除校正前
  • 关键一步：两个转折频率由两条曲线的分界点读出，据此定时间常数
  • 中间结果：本题校正装置为(bs+1)/(Ts+1)形式且b远小于1，两个转折频率都在低频段
  • 卡点：相除顺序写反；把抬高量直接当成增益比而未换算成分贝；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过由校正前后幅频曲线差异判断校正方式并求校正装置传函
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
稳定裕度 频域分析
本卷考法
  • 求校正后系统的幅值穿越频率与相角裕度
本卷实例
  • 关键一步：在对应渐近线段上令校正后幅频为1解出穿越频率
  • 关键一步：把穿越频率代入相频表达式得到相角裕度
  • 中间结果：穿越频率落在校正装置两个转折频率之间，据此选定参与计算的环节
  • 卡点：两个裕度用同一个频率计算；穿越频率落在哪一段判断错误
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求校正后系统的幅值穿越频率与相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
校正的基本概念与性能指标 系统校正
本卷考法
  • 从暂态、稳态与抗干扰三方面定性分析校正前后的变化
本卷实例
  • 关键一步：滞后校正抬高低频增益改善稳态精度并提高相角裕度，但降低穿越频率
  • 关键一步：代价是快速性下降，中高频段幅相特性基本不变
  • 中间结果：分析结论要逐条对应到幅频曲线的低频抬高与中高频不变
  • 卡点：把滞后校正说成能提高快速性；忽略相位滞后对裕度的消耗
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过从暂态、稳态与抗干扰三方面定性分析校正前后的变化
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求
公式

5五、状态空间模型求传函与极点配置25 分#

思路
  • 先由A、B、C求传递函数并判稳，再验证能控性后用状态反馈把极点配置到指定位置
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由状态空间模型求Y(s)/U(s)并判断系统稳定性
本卷实例
  • 关键一步：先算(sI-A)的逆，再按C(sI-A)^{-1}B求传函
  • 关键一步：系统稳定性由A的特征值实部是否全为负决定
  • 中间结果：本题A为三角形矩阵，特征值即对角元，可直接读出
  • 卡点：矩阵求逆的伴随阵写错；C与B的相乘次序颠倒
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过由状态空间模型求Y(s)/U(s)并判断系统稳定性
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消
公式
能控性与能观性 状态空间分析
本卷考法
  • 用能控性矩阵判断系统能否任意配置极点
本卷实例
  • 关键一步：二阶系统只需计算能控性矩阵[B AB]并判别其秩
  • 中间结果：本题能控性矩阵两列不成比例，秩等于系统阶数
  • 卡点：只算到B就下结论；能控与能观判据的矩阵构造搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过用能控性矩阵判断系统能否任意配置极点
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
状态反馈与极点配置 状态空间分析
本卷考法
  • 由期望极点设计状态反馈增益矩阵
本卷实例
  • 关键一步：先验证能控性，再写出期望极点的特征多项式
  • 关键一步：把|sI-(A-BK)|展开后与期望特征式逐项比较系数解出增益
  • 中间结果：本题A-BK的特征式含两个增益的一次式，正好两个方程解两个未知量
  • 卡点：未验证能控性就直接配置；比较系数时符号写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过由期望极点设计状态反馈增益矩阵
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
公式

6六、离散系统脉冲传函与稳定增益范围20 分#

思路
  • 含零阶保持器的离散系统，先求开环脉冲传函，再由闭环特征根落在单位圆内求稳定K范围
脉冲传递函数 离散控制系统
本卷考法
  • 求含零阶保持器的开环脉冲传递函数G(z)
本卷实例
  • 关键一步：把零阶保持器与被控对象合并成(1-e^{-Ts})G0(s)/s后整体做z变换
  • 关键一步：提出(1-z^{-1})因子后对剩余部分做部分分式并查表
  • 中间结果：本题被控对象为一阶，变换后化成含e^{-T}的一阶有理分式
  • 卡点：把两个连续环节分别变换再相乘；忘记保持器带来的(1-z^{-1})因子
  • 卡点：本题离散结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过求含零阶保持器的开环脉冲传递函数G(z)
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)
公式
离散系统稳定性分析 离散控制系统
本卷考法
  • 求使离散系统稳定的K取值范围
本卷实例
  • 关键一步：由开环脉冲传函按单位反馈写出闭环特征方程
  • 关键一步：令特征根模小于1解出K的上下界
  • 中间结果：本题特征根是z平面上含K的一次式，不等式落在实轴上
  • 卡点：把稳定条件写成实部小于零；解根后未回到闭环特征方程核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过求使离散系统稳定的K取值范围
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

7七、非线性系统的奇点与线性化20 分#

思路
  • 对含立方项的二阶非线性方程求奇点，在奇点附近线性化并按特征根判断类型
相平面法 非线性系统
本卷考法
  • 求非线性系统的奇点位置并在奇点附近线性化，判断奇点类型
本卷实例
  • 关键一步：令一阶与二阶导数同时为零解出奇点；在奇点处对非线性项线性化
  • 关键一步：按线性化特征根的类型判断奇点是焦点、节点还是鞍点
  • 中间结果：本题平衡方程为e减e的立方等于零，有三个实根，对应相平面上三个奇点
  • 卡点：只求出一个奇点；把鞍点误判为稳定奇点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过求非线性系统的奇点位置并在奇点附近线性化，判断奇点类型
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆
公式
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 用李雅普诺夫第一法判断各奇点附近的稳定性
本卷实例
  • 关键一步：线性化特征值实部全负则奇点渐近稳定，有正实部则不稳定
  • 关键一步：多个奇点要分别判断，不能用一点的结论概括整个系统
  • 中间结果：本题原点处特征值为负实部共轭复根，另两个奇点特征值一正一负
  • 卡点：把局部结论当成全局结论；出现纯虚根时第一法失效未说明

要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过用李雅普诺夫第一法判断各奇点附近的稳定性
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
