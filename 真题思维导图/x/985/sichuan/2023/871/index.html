1一、结构图求传函、扰动不变性与判稳#

思路
  • 用梅森公式求Y/R，再令N到Y的传函为零得到扰动不变条件，最后代入参数判稳
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式由结构图求Y(s)/R(s)
本卷实例
  • 关键一步：标出全部独立回路写特征式，再列前向通道与余子式代入公式
  • 中间结果：本题只有两条互不接触的回路，特征式为1加两条回路增益
  • 卡点：回路增益的符号写错；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式由结构图求Y(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求扰动到输出的传函并写出扰动对输出无影响的条件
本卷实例
  • 关键一步：求N到Y时把参考输入置零，找出全部前向通道
  • 关键一步：令N到Y的传函为零，解出补偿通道与主通道的关系
  • 中间结果：本题N到Y有两条前向通道，令其和的分子为零即得不变条件
  • 卡点：前向通道只找一条；不变条件里的负号漏写
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求扰动到输出的传函并写出扰动对输出无影响的条件
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

劳斯判据 稳定性分析
本卷考法
  • 代入给定环节后用劳斯判据判断闭环稳定性
本卷实例
  • 关键一步：由闭环传递函数写特征多项式，按劳斯表逐行计算看首列符号
  • 中间结果：本题特征式为三阶且各项齐全，劳斯表首列各元素都要判号
  • 卡点：列劳斯表时系数漏项；只算前两行就下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过代入给定环节后用劳斯判据判断闭环稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

2二、二阶系统K对阻尼与动态性能影响#

思路
  • 由闭环传函对照标准二阶形式写出阻尼比与自然频率随K的变化，再讨论欠阻尼范围与各项指标，最后由无超调条件反求K
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函写出阻尼比与自然频率关于K的表达式并讨论单调性
本卷实例
  • 关键一步：把闭环特征式与标准二阶形式对照，由对应系数解出阻尼比与自然频率
  • 关键一步：由表达式判断K增大时两者的变化方向
  • 中间结果：开环增益K只出现在常数项，故K增大时自然频率增大、阻尼比减小
  • 卡点：化标准形式时未归一化二次项系数；把开环增益当闭环系数
  • 卡点：本题方框图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函写出阻尼比与自然频率关于K的表达式并讨论单调性
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 讨论欠阻尼时K对超调量与调节时间的影响并给出欠阻尼K范围
本卷实例
  • 关键一步：超调量只由阻尼比决定，调节时间由阻尼比与自然频率的乘积决定
  • 关键一步：由阻尼比介于零与一之间解出欠阻尼的K范围
  • 中间结果：本题阻尼比与自然频率的乘积为常数，故调节时间与K无关
  • 卡点：两种误差带的调节时间系数搞混；超调量公式漏乘百分号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过讨论欠阻尼时K对超调量与调节时间的影响并给出欠阻尼K范围
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由无振荡、无超调且调节时间最短的条件反求K
本卷实例
  • 关键一步：无超调且调节时间最短对应临界阻尼，阻尼比等于一
  • 关键一步：把阻尼比等于一代入其与K的关系式解出K
  • 中间结果：临界阻尼时两个闭环实极点重合，响应不再振荡且调节时间最短
  • 卡点：把无超调误当成欠阻尼的极限；未联立调节时间最短这一条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由无振荡、无超调且调节时间最短的条件反求K
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 第(1)问由期望极点写出期望特征式，与原特征式比较系数求T与K
本卷实例
  • 关键一步：由期望极点写期望特征多项式，把原特征式整理成同次幂形式
  • 关键一步：对应系数列方程解出T与K
  • 中间结果：本题原特征式含T乘K的交叉项，需先按待定参数整理再比较
  • 卡点：期望极点为共轭复数时特征式展开出错；参数符号写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过第(1)问由期望极点写出期望特征式，与原特征式比较系数求T与K
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 第(2)问固定T后以K为变量绘制根轨迹
本卷实例
  • 关键一步：把特征方程整理成1加K乘某个有理分式等于零的显式
  • 关键一步：按幅值条件与相角条件绘制，注意等效开环的零极点
  • 中间结果：本题等效开环为一个零点两个极点，故根轨迹只有两条分支
  • 卡点：整理时未把K完整提到分子；相角条件用错
  • 卡点：本题传递函数以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过第(2)问固定T后以K为变量绘制根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

分离点与会合点 根轨迹法
本卷考法
  • 第(3)问求参数根轨迹的分离点并由模值条件求临界K
本卷实例
  • 关键一步：由分离点方程求根，舍去不在根轨迹上的根
  • 关键一步：分离点处用模值条件反求对应的临界K
  • 中间结果：本题两个分离点分别给出无超调K范围的上下两个临界值

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过第(3)问求参数根轨迹的分离点并由模值条件求临界K
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

由根轨迹分析性能与确定参数 根轨迹法
本卷考法

  • 本卷考过由根轨迹在负实轴上的部分确定无超调时的K取值范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错

  • 由极点位置估指标时忽略零点的作用

4四、由Bode图判定校正方式并求校正装置#

思路
  • 先由校正前曲线求原系统传函，再由校正前后差异判定校正方式并求校正装置，最后算校正前后的截止频率与相角裕度
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由校正前开环对数幅频曲线求原系统传递函数
本卷实例
  • 关键一步：低频段斜率定型别，某频率处的幅值或延长线交点定开环增益
  • 关键一步：转折频率处斜率变化量定环节类型
  • 中间结果：本题校正前低频段斜率为负20dB/dec、型别为一，曲线给出一个转折频率
  • 卡点：把曲线读数直接当增益而未折算型别；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
