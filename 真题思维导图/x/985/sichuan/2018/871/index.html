1一、双输入双输出结构图求传函20 分#

思路
  • 先用结构图等效法逐层化简求一路传函，再用梅逊公式求另一路输入到输出的传函
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 用结构图等效法逐层化简求一路闭环传函
本卷实例
  • 关键一步：先合并并联支路，再自内环向外环逐层消去反馈
  • 中间结果：比较点与引出点处的信号关系决定各支路增益
  • 卡点：引出点移动时乘除关系易写反；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过用结构图等效法逐层化简求一路闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅逊公式求另一路输入到输出的传函
本卷实例
  • 关键一步：列全部回路与前向通路，再找与通路不接触的回路
  • 中间结果：特征式等于1减各回路加两两不接触回路乘积
  • 卡点：不接触回路易漏计；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅逊公式求另一路输入到输出的传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 双输入双输出系统分别置零求两路传递函数
本卷实例
  • 关键一步：求某一路时把另一路输入置零，再用叠加求总输出
  • 中间结果：两路传函共用同一特征式但前向通路不同
  • 卡点：未验证线性性就直接叠加；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过双输入双输出系统分别置零求两路传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式

2二、控制器设计与扰动抑制20 分#

思路
  • 由斜坡误差恒定与稳定条件定控制器结构，再讨论扰动不变性与系统型别
劳斯判据 稳定性分析
本卷考法
  • 由闭环特征方程用劳斯判据定控制器稳定条件
本卷实例
  • 关键一步：把闭环特征方程列成劳斯表并令首列全正
  • 中间结果：稳定条件化成控制器参数的取值范围
  • 卡点：系数缺项时不补零就直接判稳
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由闭环特征方程用劳斯判据定控制器稳定条件
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由误差传函分析系统型别与静态误差系数
本卷实例
  • 关键一步：先写误差传函再由终值定理判断稳态误差
  • 中间结果：斜坡误差为常数要求误差传函在原点有一阶零点
  • 卡点：未判稳就用终值定理；积分环节数数错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由误差传函分析系统型别与静态误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 分析扰动单独作用下稳态误差为零的条件
本卷实例
  • 关键一步：令参考输入为零，写扰动到误差的传函
  • 中间结果：扰动误差是否为零取决于扰动传函的零点数
  • 卡点：求扰动传函时没有把参考输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过分析扰动单独作用下稳态误差为零的条件
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 判断系统能抑制哪类典型扰动信号
本卷实例
  • 关键一步：把扰动传函代入不同典型输入再比较终值
  • 中间结果：由传递函数在零点的阶次判断可抑制的信号类型
  • 卡点：把扰动误差与给定误差相加时符号搞错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过判断系统能抑制哪类典型扰动信号
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

3三、直流电机PI控制与二阶性能20 分#

思路
  • 由电机微分方程求各环节传函，再用期望特征根定PI参数并估算动态指标
直流电机等机电系统 建模与机电系统
本卷考法
  • 由电机微分方程求转速对电枢电压的传函
本卷实例
  • 关键一步：对含转速与负载转矩的微分方程取拉氏变换
  • 中间结果：按结构图把传函拆成前向与扰动两条支路
  • 卡点：反电动势与负载转矩项混在一起；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由电枢回路电压方程与转矩平衡方程联立
  • 反电动势与转速成正比，电磁转矩与电枢电流成正比
  • 机电时间常数由电气与机械两方面参数共同决定
步骤
  • 写出电枢回路电压平衡方程
  • 写出转矩平衡方程（含负载与粘性摩擦）
  • 消去电枢电流，得到转速或转角对电压的传递函数
通用考法
  • 本卷考过由电机微分方程求转速对电枢电压的传函
  • 求直流电机转速或位置对电枢电压的传递函数
  • 分析机电时间常数与电气时间常数的数量级关系
常见易错
  • 漏掉反电动势与电磁转矩的耦合项
  • 把电气时间常数与机电时间常数混淆
公式
PID 控制器与参数整定 系统校正
本卷考法
  • 写出PI控制器的传递函数形式
本卷实例
  • 关键一步：对含积分的控制律取拉氏变换整理成比例加积分
  • 中间结果：PI控制器传函为比例项与积分项之和
  • 卡点：误把PI的积分作用当成超前校正提供相位
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过写出PI控制器的传递函数形式
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由期望闭环特征根写出期望特征多项式
本卷实例
  • 关键一步：把闭环特征方程化为二阶标准形式读阻尼比与自然频率
  • 中间结果：比较实际与期望特征多项式系数可定控制器参数
  • 卡点：未把s平方项系数归一化就比较系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由期望闭环特征根写出期望特征多项式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率估算超调量和调节时间
本卷实例
  • 关键一步：由闭环极点实部与虚部读出阻尼比和自然频率
  • 中间结果：超调量只与阻尼比有关，调节时间与二者乘积有关
  • 卡点：两种误差带的调节时间系数搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率估算超调量和调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式

4四、超前校正装置设计20 分#

思路
  • 由校正环节幅相曲线判定为超前校正，按校正后截止频率要求求校正装置传函
超前校正 系统校正
本卷考法
  • 由幅相曲线判断为超前校正并设其传函形式
本卷实例
  • 关键一步：由曲线低频到高频的幅值变化判断零点在前极点在后
  • 中间结果：超前校正传函含一对转折频率，分母时间常数更大
  • 卡点：补偿角计算忽略截止频率右移的相角损失
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过由幅相曲线判断为超前校正并设其传函形式
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由校正前开环传函与目标截止频率求校正装置
本卷实例
  • 关键一步：在校正后截止频率处用幅值条件列方程
  • 中间结果：校正后截止频率处开环幅值等于1
  • 卡点：曲线数值靠读图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
