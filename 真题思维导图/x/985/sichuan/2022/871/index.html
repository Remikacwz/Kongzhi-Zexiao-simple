1一、结构图求传函（梅森公式与等效化简）#

思路
  • 同一张结构图分别用梅森增益公式与结构图等效化简求C(s)/R(s)，两法互校
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式由信号流图求闭环传递函数
本卷实例
  • 关键一步：先找出全部独立回路并判断两两是否接触，写出特征式
  • 关键一步：列出全部前向通道及其余子式，代入梅森公式
  • 中间结果：本题三条回路两两接触，特征式无互不接触回路乘积项
  • 卡点：不接触回路找漏或重复；余子式未剔除与通路接触的回路；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式由信号流图求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 用结构图逐层等效化简求传函并与梅森公式结果对照
本卷实例
  • 关键一步：从最内环向外逐层消去反馈环，再做串联与并联等效
  • 关键一步：化简结果与梅森公式结果互相校验
  • 中间结果：本题另有一条并联前向通道，化简后直接与主通道传函相加
  • 卡点：化简内环时把外环信号当常数处理；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过用结构图逐层等效化简求传函并与梅森公式结果对照
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2二、输入与扰动共同作用下的稳态误差#

思路
  • 分别求参考输入与扰动到误差的传函，各自用终值定理算分量后叠加
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求参考输入与扰动作用下的误差传递函数
本卷实例
  • 关键一步：求E/R时令扰动为零，求E/N时令参考输入为零，再分别套终值定理
  • 关键一步：两个分量按叠加原理相加得总稳态误差
  • 中间结果：本题两个误差传函的分母相同，都等于1加回路增益
  • 卡点：两个输入同时存在时未分别置零；求扰动传函没把参考输入置零；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求参考输入与扰动作用下的误差传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动引起的稳态误差并与输入分量叠加
本卷实例
  • 关键一步：先用劳斯判据确认闭环稳定，再对误差分量使用终值定理
  • 中间结果：扰动为负单位阶跃，其误差分量与斜坡输入分量量级相当，不能只算一个
  • 卡点：未判稳就用终值定理；把扰动误差当成总误差而漏掉输入分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求扰动引起的稳态误差并与输入分量叠加
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

3三、根轨迹与阻尼比确定Kg#

思路
  • 单位反馈系统开环有三个极点，按法则画根轨迹，再由衰减振荡与阻尼比条件确定Kg
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制Kg从零到无穷时的根轨迹并求与虚轴的交点
本卷实例
  • 关键一步：由开环零极点定分支数、实轴段与渐近线，再求分离点与虚轴交点
  • 关键一步：分离点方程求出的根要筛选，舍去不在根轨迹上的解
  • 中间结果：渐近线交点位于三个开环极点的算术平均处，夹角为六十度的奇数倍
  • 卡点：分离点求出后不筛选；求虚轴交点时只代一组角频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制Kg从零到无穷时的根轨迹并求与虚轴的交点
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 求闭环单位阶跃呈衰减振荡的Kg范围，并求使主导极点阻尼比等于给定值的Kg与闭环极点
本卷实例
  • 关键一步：衰减振荡对应闭环复数极点，Kg范围由分离点临界值与虚轴交点临界值夹出
  • 关键一步：给定阻尼比后引入第三个实极点，按主导极点假设列特征式并比较系数
  • 中间结果：第二问要联立阻尼比与实极点位置，解出自然频率后再回代求Kg
  • 卡点：只套二阶公式估指标而忽略第三个实极点；未检验主导极点假设是否成立
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过求闭环单位阶跃呈衰减振荡的Kg范围，并求使主导极点阻尼比等于给定值的Kg与闭环极点
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式

4四、极坐标图与奈奎斯特判据#

思路
  • 由开环传函写频率特性画极坐标图，再用奈奎斯特判据判稳并数不稳定极点数
频率特性的物理意义与求法 频域分析
本卷考法
  • 写开环频率特性表达式并绘制极坐标图
本卷实例
  • 关键一步：令s等于jω代入G(s)后分离出幅频与相频表达式
  • 关键一步：按角频率从零到无穷描点，标出起点、终点与实轴交点
  • 中间结果：本题开环含两个积分环节，起点幅值趋于无穷、相位由负一百八十度出发
  • 卡点：复数分母取模与相角分开算；积分环节的负九十度漏加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过写开环频率特性表达式并绘制极坐标图
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅相曲线判断闭环稳定性并指出不稳定极点数
本卷实例
  • 关键一步：先数开环右半平面极点数，再数曲线包围临界点的圈数
  • 关键一步：由包围圈数与开环极点数算出闭环右半平面极点数
  • 中间结果：本题开环无右半平面极点，曲线包围情况决定闭环是否稳定
  • 卡点：含积分环节时未补画无穷大圆弧；包围圈数的正负号定义搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环幅相曲线判断闭环稳定性并指出不稳定极点数
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

5五、由幅频曲线求模型与超前校正#

思路
  • 先由校正前幅频曲线求开环传函，再按截止频率与最大超前角条件设计超前装置
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由校正前开环对数幅频曲线求原系统传递函数
本卷实例
  • 关键一步：低频段斜率定型别，低频段高度或某频率处幅值定开环增益
  • 关键一步：转折频率处斜率变化量定环节类型与时间常数
  • 中间结果：本题低频段斜率为负20dB/dec、型别为一，曲线在一个转折频率处给出幅值
  • 卡点：低频段高度未折算型别；曲线读数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由校正前开环对数幅频曲线求原系统传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
超前校正 系统校正
本卷考法
  • 设计串联超前装置使校正后截止频率等于给定值且该点对应最大超前角
本卷实例
  • 关键一步：由最大超前角频率等于新截止频率这一条件先定出衰减系数a
  • 关键一步：再由最大超前角频率与时间常数的关系求出T，写出校正装置
  • 中间结果：校正装置形式为(aTs+1)/(Ts+1)，最大超前角出现在两个转折频率的几何中点
  • 卡点：未计及截止频率移动带来的附加相角损失；a与T的公式方向取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过设计串联超前装置使校正后截止频率等于给定值且该点对应最大超前角
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

6六、方框图状态空间建模与极点配置#

思路
  • 由方框图选状态变量写状态空间表达式与传函，再判稳、判能观并设计状态反馈
状态空间表达式的建立 状态空间分析
本卷考法
  • 由方框图选取状态变量，写出状态空间表达式并求传递函数
本卷实例
