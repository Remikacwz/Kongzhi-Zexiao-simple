1一、结构图等效化简与梅逊公式20 分#

思路
  • 分别用结构图等效法和梅逊公式求给定输入与扰动输入到输出的传函
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 用结构图等效化简法求给定输入下的闭环传函
本卷实例
  • 关键一步：先消去内环再自左向右合并串并联支路
  • 中间结果：比较点与引出点信号关系决定分子各项增益
  • 卡点：引出点移动时乘除关系易写反；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过用结构图等效化简法求给定输入下的闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅逊公式求扰动输入到输出的传递函数
本卷实例
  • 关键一步：令给定输入为零再列回路与前向通路
  • 中间结果：求扰动传函与求给定传函共用同一特征式
  • 卡点：不接触回路漏计；余子式未剔除接触回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅逊公式求扰动输入到输出的传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 多输入系统分路置零后用叠加求各自传函
本卷实例
  • 关键一步：求某一路传函时把其余输入全部置零
  • 中间结果：两路传函的分子由各自前向通路决定
  • 卡点：未验证线性性就直接叠加；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过多输入系统分路置零后用叠加求各自传函
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

2二、由响应求模型与扰动不变性20 分#

思路
  • 由断开反馈时的阶跃响应求控制对象传函，再设计控制器使扰动稳态误差为零
由响应曲线反求传递函数 传递函数
本卷考法
  • 由断开反馈时的阶跃响应反求控制对象传函
本卷实例
  • 关键一步：对响应表达式的各分量分别取拉氏变换
  • 中间结果：稳态分量为1，振荡项对应二阶环节的极点
  • 卡点：把响应中的常数项与增益混淆；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由断开反馈时的阶跃响应反求控制对象传函
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 设计控制器使扰动稳态误差为零并说明型别
本卷实例
  • 关键一步：写扰动到误差的传函，令其零点数匹配扰动阶次
  • 中间结果：由扰动传函在零点的零点个数确定所需积分环节数
  • 卡点：求扰动传函时没有令参考输入为零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过设计控制器使扰动稳态误差为零并说明型别
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 在满足扰动不变性条件下求单位阶跃稳态误差
本卷实例
  • 关键一步：用闭环误差传函代入单位阶跃并取终值
  • 中间结果：误差极限由闭环误差传函分子最低次项决定
  • 卡点：未判稳就用终值定理；型别判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过在满足扰动不变性条件下求单位阶跃稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、二阶指标反求参数与参数影响20 分#

思路
  • 由超调量与单位斜坡误差两个条件求二阶系统参数，再讨论参数对暂态性能的影响
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函化为二阶标准形式读参数关系
本卷实例
  • 关键一步：把闭环特征式写成含阻尼比与自然频率的标准形式
  • 中间结果：由超调量与斜坡误差两个条件联立解两个参数
  • 卡点：化标准形式时未把s平方项系数归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函化为二阶标准形式读参数关系
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量要求反求阻尼比取值范围
本卷实例
  • 关键一步：由超调量公式反解阻尼比
  • 中间结果：超调量只由阻尼比决定，与自然频率无关
  • 卡点：反解时忽略阻尼比取值范围只能取正值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量要求反求阻尼比取值范围
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 分析参数变化对暂态性能指标的影响趋势
本卷实例
  • 关键一步：写出阻尼比与参数的函数关系再代入指标公式
  • 中间结果：把阻尼比增减趋势映射到超调与调节时间
  • 卡点：两种误差带的调节时间系数搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过分析参数变化对暂态性能指标的影响趋势
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

通用考法
  • 本卷考过由单位斜坡稳态误差条件建立参数方程

4四、Bode图校正设计20 分#

思路
  • 由校正前后对数幅频曲线求各自传函与截止频率，再求校正装置并分析其作用
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频曲线反求校正前后开环传递函数
本卷实例
  • 关键一步：由低频段斜率与高度定系统型别与开环增益
  • 中间结果：各转折频率处斜率变化量对应串联环节类型
  • 卡点：曲线数值靠读图；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频曲线反求校正前后开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
超前校正 系统校正
本卷考法
  • 由校正前后开环传函求校正装置传递函数
本卷实例
  • 关键一步：校正装置传函等于校正后开环传函除以校正前传函
  • 中间结果：分子分母同阶相除后得到零极点与增益
  • 卡点：相除顺序写反；未检查校正装置的物理可实现性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过由校正前后开环传函求校正装置传递函数
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

校正的基本概念与性能指标 系统校正
本卷考法
  • 分析串联校正对暂态、稳态特性的影响
本卷实例
