1一、测速反馈系统根轨迹与阻尼分析（原卷图）15 分#

思路
  • 由结构图写等效开环传函画参数根轨迹，求出射角与分离点，再判断阻尼比随参数的变化趋势。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 由结构图化等效开环并画参数根轨迹、证明轨迹是圆弧
本卷实例
  • 关键一步：把内环与主回路整理成等效开环，按参数根轨迹求起点终点与出射角
  • 中间结果：等效开环有两个共轭开环极点与一个原点零点
  • 中间结果：由实部虚部分离消去参数可证轨迹为圆
  • 卡点：等效开环与原系统开环不同，渐近线与实轴段易判反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过由结构图化等效开环并画参数根轨迹、证明轨迹是圆弧
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹分离点并确定对应参数
本卷实例
  • 关键一步：用对参数求导为零或幅值条件列分离点方程
  • 中间结果：解出两根后只保留落在根轨迹上的那个
  • 卡点：增根必须剔除，导出解不一定是轨迹上的点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹分离点并确定对应参数
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 分析参数增大时阻尼比与动态性能的变化趋势
本卷实例
  • 关键一步：由闭环特征式写阻尼比与自然频率，再随参数讨论
  • 中间结果：自然频率不随参数变，阻尼比随参数单调增大
  • 卡点：阻尼比不可能接近零，参数很大时系统趋于过阻尼
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过分析参数增大时阻尼比与动态性能的变化趋势
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征方程求无阻尼自然频率与阻尼比
本卷实例
  • 关键一步：把特征方程首一化后与标准二阶形式对应
  • 中间结果：阻尼比由一次项系数比二倍自然频率给出
  • 卡点：结构图为原卷插图，内环反馈接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征方程求无阻尼自然频率与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

2二、多输入多输出结构图求四个传函（原卷图）#

思路
  • 把结构图改画为信号流图，用梅森公式分别求两个输入到两个输出的四个传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图画信号流图并用梅森公式求多输入多输出传函
本卷实例
  • 关键一步：按节点与支路列回路与前向通路，分别对每个输入求前向通路
  • 中间结果：特征式由单一回路给出，各通道前向通路增益不同
  • 卡点：求某一输入时要先把另一输入置零
  • 卡点：结构图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图画信号流图并用梅森公式求多输入多输出传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求多输入共同作用下各输出通道的传递函数
本卷实例
  • 关键一步：对每个输入单独作用时把其余输入置零再求传函
  • 中间结果：四组传函共用同一特征式，只有前向通路不同
  • 卡点：回路增益符号与交叉反馈方向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求多输入共同作用下各输出通道的传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

3三、二阶系统指标与微分负反馈设计（原卷图）20 分#

思路
  • 由结构图求闭环特征方程得自然频率与阻尼比，按指标公式求超调量与调节时间，再按阻尼比设计微分反馈。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征方程求无阻尼自然频率与阻尼比
本卷实例
  • 关键一步：把闭环传递函数分母与标准二阶形式对应
  • 中间结果：由常数项开方得自然频率，由一次项系数得阻尼比
  • 卡点：结构图有两张，加微分反馈前后接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征方程求无阻尼自然频率与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率求超调量与调节时间
本卷实例
  • 关键一步：超调量按阻尼比公式算，调节时间按误差带系数算
  • 中间结果：欠阻尼下超调量随阻尼比减小而增大
  • 卡点：调节时间系数与误差带有关，本题答案取三点五
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率求超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 按指定阻尼比与超调量要求反求开环增益和微分时间常数
本卷实例
  • 关键一步：由阻尼比与自然频率的关系式反解微分时间常数
  • 中间结果：加入微分负反馈后阻尼项系数增加而自然频率不变
  • 卡点：微分反馈改变阻尼不改变自然频率，须用两个条件联立
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过按指定阻尼比与超调量要求反求开环增益和微分时间常数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

4四、由对数幅频曲线求校正前后传函（原卷图）25 分#

思路
  • 由两条对数渐近幅频曲线读转折频率与高度反求校正前后传函，相除得校正装置并分析性能变化。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数渐近幅频曲线反求校正前后的开环传递函数
本卷实例
  • 关键一步：由低频段斜率与高度定型别与增益，再按各转折频率定环节
  • 中间结果：曲线斜率每次变化对应一个一阶环节或一阶微分环节
  • 卡点：曲线以原卷插图给出，转折频率与高度需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数渐近幅频曲线反求校正前后的开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 按转折频率逐段累加斜率并定截止频率
本卷实例
  • 关键一步：从低频段出发逐段改变斜率，再与零分贝线求交点
  • 中间结果：截止频率通常落在相邻两个转折频率之间
  • 卡点：斜率是累加不是替换，低频段起始高度要按型别修正
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过按转折频率逐段累加斜率并定截止频率
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
校正的基本概念与性能指标 系统校正
本卷考法
  • 分析校正前后稳定性、稳态精度与暂态性能的变化
本卷实例
  • 关键一步：比较校正前后开环增益、截止频率与相角裕度的变化
