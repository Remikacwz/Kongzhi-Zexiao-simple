1一、结构图求传函与状态空间建模15 分#

思路
  • 先由多回路结构图化简求闭环传函，再取指定变量建模并讨论两种模型的等价性
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 逐层消去多回路结构图的内环并化简为最简形式
本卷实例
  • 关键一步：从最内环向外逐层等效，再做串联与并联合并
  • 中间结果：四环结构先消两个内环，再合并两条并联通道
  • 卡点：化简内环时把外环信号当常数；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过逐层消去多回路结构图的内环并化简为最简形式
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
状态空间表达式的建立 状态空间分析
本卷考法
  • 取图中标注的变量为状态变量建立状态空间模型
本卷实例
  • 关键一步：取积分器输出为状态变量，在积分器输入端写一阶方程
  • 中间结果：本题四个环节均为一阶，状态维数由积分器个数决定
  • 卡点：状态变量个数与系统阶数不匹配；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过取图中标注的变量为状态变量建立状态空间模型
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由状态空间模型求传函并与输入输出模型比较是否等价
本卷实例
  • 关键一步：用C(sI减A)逆B求传函，再与原闭环传函逐项对照
  • 中间结果：若存在零极点对消则不满足最小实现，两模型不等价
  • 卡点：漏掉直接传递项D；只看特征多项式相等就判等价
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过由状态空间模型求传函并与输入输出模型比较是否等价
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消
公式

2二、扰动与正弦输入下的性能与误差20 分#

思路
  • 先按二阶系统估算暂态指标，再分别求正弦扰动与单位阶跃下的稳态误差与输出
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 按二阶系统估算调节时间与超调量
本卷实例
  • 关键一步：由闭环特征式定阻尼比与自然频率再套指标公式
  • 中间结果：阻尼比决定超调量，自然频率决定响应快慢
  • 卡点：把两种误差带的调节时间系数搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过按二阶系统估算调节时间与超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求正弦扰动作用下稳态误差的最大值
本卷实例
  • 关键一步：求扰动到误差的传函，再令s等于jω求其幅值
  • 中间结果：输出为同频正弦，误差最大值等于幅频特性的峰值
  • 卡点：求扰动传函时未把参考输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求正弦扰动作用下稳态误差的最大值
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由频率特性求阶跃输入下系统输出的表达式
本卷实例
  • 关键一步：分别写出各典型环节的幅频与相频再合成
  • 中间结果：稳态输出由闭环幅频与相频在输入频率处取值决定
  • 卡点：复数分母取模与相角分开算；漏加积分环节相角
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由频率特性求阶跃输入下系统输出的表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式

3三、闭环根轨迹与最小相位判定20 分#

思路
  • 由闭环传函构造参数根轨迹，并确定系统为最小相位时的K范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 由闭环特征式构造等效开环传函并绘制K大于零的根轨迹
本卷实例
  • 关键一步：把含K的项整理成标准根轨迹形式再逐条作图
  • 中间结果：等效开环有分子零点，根轨迹起点为极点、终点为零点
  • 卡点：等效开环零点位置求错；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过由闭环特征式构造等效开环传函并绘制K大于零的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
最小相位系统与非最小相位系统 频域分析
本卷考法
  • 由零点是否全在左半平面确定最小相位系统的K范围
本卷实例
  • 关键一步：分子多项式的根即开环零点，要求其实部全负
  • 中间结果：分子含与K有关的一次项，零点位置随K移动
  • 卡点：把右半平面极点与右半平面零点混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过由零点是否全在左半平面确定最小相位系统的K范围
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈

4四、Bode图分析与串联校正设计30 分#

思路
  • 先画开环对数幅频曲线估截止频率判稳，再按相角裕度要求设计串联校正
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制开环对数渐近幅频曲线并估算截止频率
本卷实例
  • 关键一步：由低频段斜率与转折频率逐段写出渐近线
  • 中间结果：本题开环为Ⅰ型，两个惯性环节转折频率相差较大
  • 卡点：逐段改斜率忘记累加；型别高度未折算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过绘制开环对数渐近幅频曲线并估算截止频率
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
稳定裕度 频域分析
本卷考法
  • 由相角裕度判断闭环稳定性并指出未校正系统的缺陷
本卷实例
  • 关键一步：在截止频率处计算相角裕度，与要求值比较
  • 中间结果：截止频率处相角接近负180度，裕度不足
  • 卡点：把幅值裕度取倒数未取导致结论相反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由相角裕度判断闭环稳定性并指出未校正系统的缺陷
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
超前校正 系统校正
本卷考法
  • 按相角裕度要求选择超前校正并确定校正装置传函
本卷实例
  • 关键一步：由需补偿的相角定衰减系数a，再定时间常数T
  • 中间结果：最大超前角出现在两转折频率的几何中点
  • 卡点：未计及截止频率移动带来的附加相角损失
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过按相角裕度要求选择超前校正并确定校正装置传函
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式

5五、离散系统脉冲传函与稳定范围15 分#

思路
  • 求闭环脉冲传函，定稳定K范围，再求K等于1时阶跃响应的稳态值
脉冲传递函数 离散控制系统
本卷考法
  • 由含零阶保持器的结构图求闭环脉冲传递函数
本卷实例
  • 关键一步：按采样开关位置确定先合并的连续环节再做z变换
  • 中间结果：环路脉冲传函含e的负aT项，需代入给定采样周期
  • 卡点：把无采样开关隔开的连续环节直接相乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
