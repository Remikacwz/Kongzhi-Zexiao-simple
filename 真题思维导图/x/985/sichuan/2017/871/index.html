1一、二阶系统脉冲响应辨识与正弦稳态15 分#

思路
  • 由单位脉冲响应曲线读参数求二阶传函，再求正弦输入下的稳态输出
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位脉冲响应曲线与给定特征量反求二阶系统参数
本卷实例
  • 关键一步：脉冲响应的峰值时刻与包络由阻尼比和自然频率决定
  • 中间结果：由峰值时刻与曲线面积可列两个方程解出两个参数
  • 卡点：未先把传函化为标准二阶形式；读图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位脉冲响应曲线与给定特征量反求二阶系统参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求正弦输入下系统的稳态输出表达式
本卷实例
  • 关键一步：把输入频率代入频率特性求幅值与相角
  • 中间结果：稳态输出为同频正弦，幅值按幅频特性放大
  • 卡点：相角单位为度与弧度换算出错；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求正弦输入下系统的稳态输出表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式

2二、结构图求传函与状态空间建模15 分#

思路
  • 由结构图求闭环传函，再以指定变量为状态建立状态空间模型
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由多回路结构图逐层化简求闭环传递函数
本卷实例
  • 关键一步：先合并并联支路，再逐层消去内环反馈
  • 中间结果：比较点处的信号关系决定分子各支路增益
  • 卡点：引出点移动时乘除关系搞反；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由多回路结构图逐层化简求闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
状态空间表达式的建立 状态空间分析
本卷考法
  • 以图中x1、x2、x3为状态变量建立状态空间模型
本卷实例
  • 关键一步：在积分器输入端写一阶微分方程再联立成矩阵形式
  • 中间结果：状态变量个数与系统中积分器的个数一致
  • 卡点：输出方程漏掉直接传递项；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过以图中x1、x2、x3为状态变量建立状态空间模型
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式

3三、Bode图与PI、PD控制分析#

思路
  • 先按比例控制画Bode图判稳，再用PI与PD分别讨论能否使系统稳定
开环对数频率特性的绘制 频域分析
本卷考法
  • 按步骤绘制开环对数幅频图并用对数判据判稳
本卷实例
  • 关键一步：由低频段斜率与转折频率逐段画渐近线
  • 中间结果：低频段高度决定开环增益，据此算截止频率
  • 卡点：型别判断错导致低频段高度算错；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过按步骤绘制开环对数幅频图并用对数判据判稳
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
PID 控制器与参数整定 系统校正
本卷考法
  • 分析PI与PD控制对系统稳定性的不同影响
本卷实例
  • 关键一步：PI引入积分环节使相位滞后，PD提供超前相角
  • 中间结果：稳定性改善与否取决于零极点配置对相频的作用
  • 卡点：把PI的相位影响说成超前
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过分析PI与PD控制对系统稳定性的不同影响
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 用根轨迹分析PD控制下系统能否稳定
本卷实例
  • 关键一步：把PD参数写进开环传函后按法则画根轨迹
  • 中间结果：引入开环零点后根轨迹左移，可能使系统稳定
  • 卡点：零度根轨迹与负反馈根轨迹条件混用；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过用根轨迹分析PD控制下系统能否稳定
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式

4四、高阶系统动态性能与斜坡误差10 分#

思路
  • 由闭环传函用主导极点估算动态指标，再求单位斜坡稳态误差
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 把高阶闭环传函降阶为主导极点二阶系统估算指标
本卷实例
  • 关键一步：比较各极点实部距离，取主导极点对并保留零点
  • 中间结果：闭环含零点使超调量比纯二阶系统偏大
  • 卡点：忽略零点对超调量的放大作用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过把高阶闭环传函降阶为主导极点二阶系统估算指标
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡输入下系统的稳态误差
本卷实例
  • 关键一步：由误差传函按系统型别套用速度误差系数
  • 中间结果：单位反馈下误差传函由闭环传函直接得出
  • 卡点：未判稳就用终值定理；把静态误差系数与型别判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位斜坡输入下系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

5五、可控可观条件与极点配置30 分#

思路
  • 由状态空间模型求可控可观条件，画状态变量图并讨论极点配置
能控性与能观性 状态空间分析
本卷考法
  • 求使系统既可控又可观时参数a、b的取值
本卷实例
  • 关键一步：分别列能控性矩阵与能观性矩阵并令其满秩
  • 中间结果：两组秩条件取交集才是同时可控可观的参数
  • 卡点：能控判据与能观判据的矩阵构造搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过求使系统既可控又可观时参数a、b的取值
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
状态空间表达式的建立 状态空间分析
本卷考法
  • 按状态方程画出系统的状态变量图
本卷实例
  • 关键一步：每个状态方程对应一个积分器，按系数接反馈支路
  • 中间结果：状态变量图直接反映A阵各行系数与B阵的接入点
  • 卡点：漏画某条前馈支路；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过按状态方程画出系统的状态变量图
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式
状态反馈与极点配置 状态空间分析
本卷考法
  • 判断能否配置给定极点并求相应参数
本卷实例
  • 关键一步：先由参数取值验证能控性，再比较特征多项式
  • 中间结果：期望特征多项式由给定极点相乘展开
  • 卡点：未验证能控性就下结论；系数比较符号写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过判断能否配置给定极点并求相应参数
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反

6六、非线性系统奇点与线性化20 分#

思路
  • 由自由运动微分方程求奇点位置，在奇点处线性化并判断类型
相平面法 非线性系统
本卷考法
