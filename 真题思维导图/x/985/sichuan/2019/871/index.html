1一、基本概念简答20 分#

思路
  • 比较线性与非线性、连续与离散系统的差别，写四阶数学模型并讨论误差与稳定性的关系
非线性系统的特点 非线性系统
本卷考法
  • 从叠加性与齐次性区分线性与非线性系统
本卷实例
  • 关键一步：从响应是否与输入成正比入手判断系统类别
  • 中间结果：题目还要求离散与连续系统各写一组对比
  • 卡点：把非线性系统一概判为不稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过从叠加性与齐次性区分线性与非线性系统
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 借位：写出连续与离散系统的四阶数学模型
本卷实例
  • 关键一步：连续模型用四阶微分方程、离散用四阶差分方程
  • 中间结果：方程两侧分别排输出与输入及其各阶项
  • 卡点：差分方程的阶数与采样点数对应关系写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过借位：写出连续与离散系统的四阶数学模型
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 借位：讨论误差趋于无穷与系统稳定性的关系
本卷实例
  • 关键一步：分别举稳定与不稳定系统说明误差无穷不反映稳定性
  • 中间结果：需分别讨论系统自身稳定与输入阶次两个因素
  • 卡点：把稳态误差大小直接当作稳定性判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过借位：讨论误差趋于无穷与系统稳定性的关系
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

2二、参数对稳定性与动态性能的影响30 分#

思路
  • 由结构图求闭环传函，用劳斯判据、二阶指标与误差公式讨论参数β的影响
劳斯判据 稳定性分析
本卷考法
  • 由劳斯判据求参数β对稳定性的条件
本卷实例
  • 关键一步：列劳斯表令首列各项为正再解参数不等式
  • 中间结果：稳定条件由劳斯表首列不等式给出
  • 卡点：非负常数取零时的临界情况处理漏掉
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由劳斯判据求参数β对稳定性的条件
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由参数对阻尼比的影响讨论阶跃响应趋势
本卷实例
  • 关键一步：把闭环特征式与二阶标准形式比较得阻尼比
  • 中间结果：把参数影响代入超调与调节时间公式讨论
  • 卡点：把两种误差带的调节时间系数搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由参数对阻尼比的影响讨论阶跃响应趋势
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡输入下稳态误差并分析参数影响
本卷实例
  • 关键一步：由误差传函在单位斜坡输入下用终值定理求极限
  • 中间结果：误差表达式由误差传函的分子最低次项决定
  • 卡点：未判断闭环稳定就直接用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位斜坡输入下稳态误差并分析参数影响
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

思路
  • 源文标注本题回忆残缺，仅提供两道例题供参考，按源文如实缺、保留题号并占位
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 占位：根轨迹与伯德图题回忆残缺，原题面缺失
本卷实例
  • 关键一步：保留题号成块并标注回忆残缺待回原卷核对
  • 中间结果：源文只给出根轨迹与伯德图两道参考例题
  • 卡点：非原题，例题仅供参考，题面缺失需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过占位：根轨迹与伯德图题回忆残缺，原题面缺失
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

4四、对角线标准型实现与能控性20 分#

思路
  • 由闭环传函部分分式展开写对角线标准型实现，再列能控性矩阵判完全能控
由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 由闭环传函部分分式展开写对角线标准型实现
本卷实例
  • 关键一步：先求特征根再按极点做部分分式展开定系数
  • 中间结果：重根项含一阶与二阶分式对应约当块结构
  • 卡点：重极点部分分式系数用留数法时漏求导项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法
  • 本卷考过由闭环传函部分分式展开写对角线标准型实现
  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反
公式
能控性与能观性 状态空间分析
本卷考法
  • 列能控性矩阵判断系统是否完全能控
本卷实例
  • 关键一步：由实现得到的A、B依次算AB直到A平方B
  • 中间结果：能控性矩阵秩等于系统阶数即为完全能控
  • 卡点：只算一阶乘积就下结论；矩阵列顺序排错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过列能控性矩阵判断系统是否完全能控
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式

5五、采样系统脉冲传函与稳态误差30 分#

思路
  • 由离散结构图求开环脉冲传函，再证明单位斜坡输入下的稳态误差形式
脉冲传递函数 离散控制系统
本卷考法
  • 由离散结构图求含零阶保持器的开环脉冲传函
本卷实例
  • 关键一步：对含零阶保持器的连续部分做z变换并整理
  • 中间结果：脉冲传函分子分母都含采样周期指数项
  • 卡点：漏掉零阶保持器因子；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过由离散结构图求含零阶保持器的开环脉冲传函
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)
公式
离散系统的稳态误差 离散控制系统
本卷考法
  • 用终值定理证明单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：写闭环误差脉冲传函再代入斜坡输入求z趋于1的极限
  • 中间结果：化简后误差只与开环增益有关
  • 卡点：未判稳就用终值定理；z变换公式用错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差由输入类型与开环脉冲传函中 z=1 处极点的个数决定
  • 型别由 G(z)H(z) 中 z=1 处极点的重数确定
  • 用终值定理求稳态误差，前提是系统稳定
  • 采样周期也影响稳态误差大小
步骤
  • 求误差脉冲传递函数
  • 数出 z=1 处极点重数确定型别
  • 查表或用终值定理求稳态误差
  • 分析采样周期变化对误差的影响
通用考法
  • 本卷考过用终值定理证明单位斜坡输入下的稳态误差
  • 求离散系统在典型输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 分析采样周期对稳态精度的影响
常见易错
  • 直接用 s 域静态误差系数公式处理离散系统
  • 未判稳就用终值定理
公式

6六、回忆残缺（相轨迹）#

思路
  • 源文标注本题回忆残缺，仅提供一道参考例题，按源文如实缺、保留题号并占位
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 占位：相轨迹题回忆残缺，原题面缺失，不臆造

  • 卡点：例题非原题，题面缺失需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过占位：相轨迹题回忆残缺，原题面缺失，不臆造
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
