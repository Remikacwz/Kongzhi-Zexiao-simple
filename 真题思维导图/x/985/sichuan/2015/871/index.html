1一、结构图求传函与环节微分方程10 分#

思路
  • 由结构图求闭环传函，再由给定环节写输入输出微分方程并用劳斯判据判稳
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图绘制信号流图并用梅森增益公式求闭环传函
本卷实例
  • 关键一步：先标出全部独立回路与前向通道，判断回路是否两两接触
  • 中间结果：特征式由回路增益与其不接触组合项构成
  • 卡点：回路漏找或把接触回路当成不接触；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图绘制信号流图并用梅森增益公式求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
典型环节及其特性 传递函数
本卷考法
  • 由环节传函写输入输出微分方程并识别典型环节
本卷实例
  • 关键一步：把G4(s)化为输出与输入的一次多项式之比再反变换
  • 中间结果：一阶惯性环节的微分方程必含输出的一阶导数项
  • 卡点：未限定零初始条件就不能直接反变换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过由环节传函写输入输出微分方程并识别典型环节
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减
公式
劳斯判据 稳定性分析
本卷考法
  • 对闭环特征多项式列劳斯表判定系统稳定性
本卷实例
  • 关键一步：先由闭环传函分母写出特征多项式再列劳斯表
  • 中间结果：首列元素符号决定闭环右半平面极点的个数
  • 卡点：系数缺项时未补零；首列出现零时未用ε法
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过对闭环特征多项式列劳斯表判定系统稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式

2二、参数根轨迹与PD控制器40 分#

思路
  • 对象含右半平面极点，用参数根轨迹分析τ对稳定与平稳性的影响，再求斜坡稳态误差
根轨迹的绘制法则 根轨迹法
本卷考法
  • 以τ为参数绘制根轨迹草图并写出渐近线与分离点依据
本卷实例
  • 关键一步：把含τ的项整理成等效开环传函，再按法则逐条作图
  • 中间结果：等效开环仅一个零点两个极点，故只一条分支趋向无穷
  • 卡点：实轴段判据中零极点个数算错；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过以τ为参数绘制根轨迹草图并写出渐近线与分离点依据
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹确定调节时间最短和无超调时的τ取值
本卷实例
  • 关键一步：分离点增益对应临界阻尼，据此找无超调时τ的边界
  • 中间结果：等效开环含复数极点对，起始角需按相角条件求
  • 卡点：由极点位置估指标时忽略闭环零点的影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹确定调节时间最短和无超调时的τ取值
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
PID 控制器与参数整定 系统校正
本卷考法
  • 判断Gc等于τs加1为PD控制器并分析τ增大的作用
本卷实例
  • 关键一步：由传函形式看出控制器含纯微分项即为PD控制
  • 中间结果：微分项提供超前相角，增大τ使超调量减小
  • 卡点：把PD的相位影响误说成滞后
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过判断Gc等于τs加1为PD控制器并分析τ增大的作用
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡输入下的稳态误差并说明使用前提
本卷实例
  • 关键一步：先判闭环稳定，再用终值定理计算斜坡误差
  • 中间结果：误差系数由开环积分环节个数与开环增益决定
  • 卡点：未判稳就套终值定理；把加速度误差公式误用到斜坡
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位斜坡输入下的稳态误差并说明使用前提
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

3三、串联滞后校正与Bode图20 分#

思路
  • 由给定校正装置判断类型，画校正前后Bode图并用对数判据判稳
滞后校正 系统校正
本卷考法
  • 由校正网络两个转折频率的高低判断其为滞后校正
本卷实例
  • 关键一步：把Gc写成标准滞后网络形式，比较两个转折频率高低
  • 中间结果：分子转折频率高于分母，故低频增益大、高频被衰减
  • 卡点：把两个转折频率顺序写反；未说明对截止频率的影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过由校正网络两个转折频率的高低判断其为滞后校正
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制校正前后开环对数渐近幅频特性并写出依据
本卷实例
  • 关键一步：低频段斜率定型别，各转折频率处逐段改变斜率
  • 中间结果：校正前开环为Ⅰ型，低频段斜率为负20dB每十倍频
  • 卡点：逐段改斜率时忘记累加；基准线未按型别折算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过绘制校正前后开环对数渐近幅频特性并写出依据
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
稳定裕度 频域分析
本卷考法
  • 由相角裕度判断校正前闭环的稳定性
本卷实例
  • 关键一步：先求截止频率，再由该点相角计算相角裕度
  • 中间结果：相角裕度为负说明闭环在右半平面有极点
  • 卡点：把截止频率与相位穿越频率用反；读图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由相角裕度判断校正前闭环的稳定性
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式

4四、状态空间判稳、极点配置与观测器30 分#

思路
  • 先判状态空间模型稳定性，再检验极点配置可行性并讨论输出至状态微分的观测器
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 由系统矩阵特征值判定状态空间模型的稳定性
本卷实例
  • 关键一步：求A阵的特征值，按实部符号判断渐近稳定性
  • 中间结果：A为三角阵，特征值即对角元，可直接读出
  • 卡点：只看A阵规模不看特征值分布就下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过由系统矩阵特征值判定状态空间模型的稳定性
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数
公式
状态反馈与极点配置 状态空间分析
本卷考法
  • 判断能否用状态反馈配置给定闭环极点并求反馈阵
本卷实例
  • 关键一步：先算能控性矩阵判满秩，再比较特征多项式系数
  • 中间结果：期望特征多项式由三个给定极点相乘展开
  • 卡点：未验证能控性就做极点配置；系数比较符号写反
