1一、方框图化简求传递函数#

思路
  • 先把 G3 的引出点后移，再从最内层回路逐层等效，最后合并成单回路写出 C(s)/R(s)
比较点与引出点的移动 结构图与方框图
本卷考法
  • 引出点后移时补出等效环节
本卷实例
  • 关键一步：把引出点从原位置后移，按后移用乘的规则补出等效环节
  • 中间结果：移动前后各支路信号关系保持不变
  • 卡点：方框图未读图，引出点位置与补入环节需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过引出点后移时补出等效环节
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路方框图从内到外逐层化简
本卷实例
  • 关键一步：先找最内层回路等效成一个环节，再处理外环
  • 中间结果：每化简一层回路数减少一个，结构式逐步简化
  • 卡点：内环化简时误把外环信号当成常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路方框图从内到外逐层化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 串联、并联与反馈等效合并
本卷实例
  • 关键一步：串联相乘、并联相加，单回路套用反馈公式
  • 中间结果：负反馈等效的分母为一加回路增益
  • 卡点：引出点后移补入的环节位置容易与比较点移动混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过串联、并联与反馈等效合并
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、输出与误差传递函数#

思路
  • 先求 C/R 与误差传函，用劳斯判据判稳后由终值定理求单位阶跃误差；再令参考输入为零，由扰动到误差的传函求扰动误差
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由开环与反馈通道写闭环传函
本卷实例
  • 关键一步：单位负反馈下闭环传函等于前向通道除以一加回路增益
  • 中间结果：闭环分母为 s 乘 s 加二再乘二次式后加五的展开式
  • 卡点：系统结构图未读图，反馈通道接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由开环与反馈通道写闭环传函
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 由误差定义写误差传递函数
本卷实例
  • 关键一步：由误差等于参考输入减输出，推出误差传函为一减闭环传函
  • 中间结果：误差传函与闭环传函共用同一分母多项式
  • 卡点：误差传函分子含负常数项，终值定理代入时符号易错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由误差定义写误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位阶跃输入下的稳态误差
本卷实例
  • 关键一步：先用劳斯表判稳，再对误差传函用终值定理求极限
  • 中间结果：开环无积分环节，单位阶跃下的稳态误差为有限值
  • 卡点：未判稳就直接套终值定理会得到无意义结果
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位阶跃输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动作用下的稳态误差
本卷实例
  • 关键一步：令参考输入为零，由扰动作用点到误差点写传递函数
  • 中间结果：把扰动传函乘扰动输入的拉氏变换，再由终值定理取极限
  • 卡点：扰动传函符号与误差定义方向相反，结论符号需核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求扰动作用下的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

3三、二阶指标反求参数#

思路
  • 把闭环传函化为标准二阶形式，由超调量定阻尼比、由调节时间定自然频率，再由系数关系反求 K 与 C
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函标准形式求阻尼比与自然频率
本卷实例
  • 关键一步：把一次项系数与常数项分别对应二倍阻尼比乘自然频率与自然频率平方
  • 中间结果：阻尼比由 C 的平方根给出，自然频率由 K 的平方根给出
  • 卡点：题面一次项符号有正负两版，宝典答案按正号自洽处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函标准形式求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与调节时间反求结构参数
本卷实例
  • 关键一步：先由超调量公式反解阻尼比，再由调节时间公式反解自然频率
  • 中间结果：超调量只含阻尼比，调节时间同时含阻尼比与自然频率
  • 卡点：调节时间系数按百分之五误差带取三点五，不能取二点八
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与调节时间反求结构参数
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由性能指标要求反求待定参数
本卷实例
  • 关键一步：把反解出的阻尼比与自然频率回代到系数关系式
  • 中间结果：K 由自然频率的平方给出，C 由阻尼比的平方给出
  • 卡点：先确认欠阻尼条件成立再套用超调量公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由性能指标要求反求待定参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

4四、含右半平面极点根轨迹与稳定域#

思路
  • 按开环极点 1、-2、-4 画根轨迹，求分离点与虚轴交点定临界增益，再由虚轴左半平面确定稳定增益区间
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制含右半平面极点的常规根轨迹
本卷实例
  • 关键一步：标出三个开环极点并确定实轴根轨迹段
  • 中间结果：渐近线与实轴交点由极点坐标平均得到，夹角按三条分支等分
  • 卡点：含右半平面极点时实轴段仍按该段右侧零极点个数之和判奇偶
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制含右半平面极点的常规根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求分离点并舍去不在根轨迹上的解
本卷实例
  • 关键一步：由闭环特征方程整理出增益的显式表达式后求导
  • 中间结果：驻点方程为一元三次，其中一实根落在实轴根轨迹段内
  • 卡点：三次方程的两个复根与根轨迹无关，必须舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求分离点并舍去不在根轨迹上的解
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴的交点及临界增益
本卷实例
  • 关键一步：把纯虚变量代入闭环特征方程并令实部虚部分别为零
  • 中间结果：虚部方程给出一组非零频率解，实部方程给出对应临界增益
  • 卡点：答案首行把特征方程多乘了一个 s，按自洽的极点多项式处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解

稳定裕度 频域分析
本卷考法
  • 由相角裕度判断闭环稳定性
本卷实例
  • 关键一步：先由幅频特性等于一求截止频率，再代入相频求相角裕度
  • 中间结果：最小相位系统相角裕度为正即闭环稳定
  • 卡点：截止频率由渐近线估算，与精确值有偏差需注意
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由相角裕度判断闭环稳定性
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
