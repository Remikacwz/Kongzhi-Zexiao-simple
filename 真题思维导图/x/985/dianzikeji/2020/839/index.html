1结构图求闭环传递函数#

思路
  • 由结构图用多回路逐层化简，再用梅森公式复核闭环传函 C(s)/R(s)。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由题一结构图求闭环传递函数C(s)/R(s)
本卷实例
  • 关键一步：由内向外合并各局部反馈回路
  • 中间结果：化简结果与梅森公式互为校核
  • 卡点：结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由题一结构图求闭环传递函数C(s)/R(s)
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过化简内环时把外环输入当成常量处理
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式由信号流图求总传函
本卷实例
  • 关键一步：定各独立回路与前向通路增益
  • 中间结果：分子为各前向通路与其余子式之积的和
  • 卡点：回路与前向通路接法以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式由信号流图求总传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路漏计，或余子式未剔除接触回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标

4参数根轨迹与稳定 T 范围#

思路
  • 把 T 视为可变参数整理成标准根轨迹形式，再按绘制法则作图，由根轨迹过虚轴的条件定稳定 T 范围。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以T为变量绘制G(s)=T(s+1)(s+3)/s^3的参数根轨迹
本卷实例
  • 关键一步：把特征方程整理成1加T乘某分式等于零的形式
  • 中间结果：等效开环的零极点决定根轨迹形状
  • 卡点：参数根轨迹须与常规根轨迹相区分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°

  • 比较零度与 180 度根轨迹的差别

  • 整理时没有把参数完整地提到分子位置
