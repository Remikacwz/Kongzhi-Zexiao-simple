一一、复合系统由Ⅰ型变为Ⅲ型的补偿参数#

思路
  • 先写误差传函并判稳，再令加速度输入的稳态误差为零、加加速度输入时误差不为零，联立确定两个前馈补偿参数。
减小稳态误差的措施 稳态误差
本卷考法
  • 设计前馈补偿器使系统由Ⅰ型升为Ⅲ型
本卷实例
  • 关键一步：写误差传函并令两个前馈系数对应型别要求
  • 中间结果：前馈补偿使低频误差系数满足加速度输入无差
  • 卡点：复合系统结构以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计前馈补偿器使系统由Ⅰ型升为Ⅲ型
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 本卷考过只谈误差减小而不检查稳定性是否被破坏
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

本卷考法

本卷实例

  • 中间结果：型别提高后跟踪能力增强但稳定性需另判
  • 卡点：型别与误差阶次须逐一对应

  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤

  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法

  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 本卷考过把开环增益与静态误差系数混为一谈
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

反馈校正与复合控制 系统校正
本卷考法

  • 前馈不改变闭环稳定性，可与反馈叠加使用

二二、对数频率特性、稳定裕度与判稳#

思路
  • 先由开环传函按转折频率逐段画对数幅频渐近线并作谐振修正，再在图上标出幅值裕度与相角裕度并据此判稳。
典型环节的对数频率特性 频域分析
本卷考法
  • 由振荡环节与惯性环节写各典型环节对数频率特性
本卷实例
  • 关键一步：按转折频率分段写各典型环节的渐近斜率
  • 中间结果：振荡环节在其自然频率附近出现谐振峰
  • 卡点：转折频率处的幅值与相角需逐段累加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例环节是水平线，积分与微分分别是 -20 与 +20 dB/dec 的斜线
  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec
  • 一阶微分环节与惯性环节幅频互为镜像
  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤
  • 把传递函数分解为典型环节乘积
  • 逐环节画出对数幅频渐近线与相频曲线
  • 代数相加得到总特性
通用考法
  • 本卷考过由振荡环节与惯性环节写各典型环节对数频率特性
  • 画出某一典型环节的 Bode 图
  • 由 Bode 图识别环节类型
  • 说明转角频率处的幅值与相角
常见易错
  • 本卷考过把振荡环节高频渐近线的斜率写成一阶的值
  • 把惯性环节高频渐近线的 -20 写成 -40
  • 振荡环节谐振峰位置误当作 ωn
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 画开环对数幅频渐近线并求截止频率
本卷实例
  • 关键一步：低频段按型别与增益定起始高度与斜率
  • 中间结果：每遇一个转折频率即改变一次斜率
  • 卡点：截止频率由幅频曲线与0dB线的交点确定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过画开环对数幅频渐近线并求截止频率
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 本卷考过逐段改斜率时忘记累加，低频起始高度未按型别折算
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
稳定裕度 频域分析
本卷考法
  • 在图示曲线上标出幅值裕度与相角裕度并判稳
本卷实例
  • 关键一步：由相频等于-180度求相位穿越频率与幅值裕度
  • 中间结果：由幅频等于0dB求ωc并算相角裕度
  • 卡点：Bode图与标注以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过在图示曲线上标出幅值裕度与相角裕度并判稳
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过把ωc与ωg两个频率用反，或幅值裕度取倒数错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

三三、机械系统建模与由阶跃响应反求参数#

思路
  • 先对质量块作受力分析建立微分方程，再由位移响应曲线读出稳态值与时间常数，反求质量、阻尼与刚度参数。
机械系统建模 建模与机电系统
本卷考法
  • 对质量块受力分析建立位移微分方程
本卷实例
  • 关键一步：按牛二定律写质量块的运动微分方程
  • 中间结果：整理得位移对力的二阶传递函数
  • 卡点：受力模型与响应曲线以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过对质量块受力分析建立位移微分方程
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 本卷考过阻尼力与弹簧力的正负方向取反
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由位移阶跃响应曲线反求系统传递函数与参数
本卷实例
  • 关键一步：由响应终值定稳态量，由时间常数定动态参数
  • 中间结果：对照标准二阶形式解出质量、阻尼与刚度
  • 卡点：需用响应曲线上的特征点定时间常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出

  • 判断系统是一阶还是二阶（看有无振荡）

  • 写出标准形式并补上增益
通用考法

  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错

  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

  • 把 63.2% 对应的时刻记成 50% 对应的时刻

五五、根轨迹绘制与稳定 K 范围#

思路
  • 先按根轨迹法则画出开环传函的轨迹并求与虚轴交点，再由交点对应的临界增益确定系统稳定的参数区间。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制G(s)=K*/[s(s^2+2s+2)]根轨迹
本卷实例
  • 关键一步：标开环极点0与一对共轭复极点，判实轴段
