1一、正弦稳态输出#

思路
  • 由单位负反馈写闭环传函并判稳，令 s=jω 求幅频与相频，再按正弦稳态的幅值比与相位差写输出
频率特性的物理意义与求法 频域分析
本卷考法
  • 求正弦输入下系统的稳态输出
本卷实例
  • 关键一步：先写单位负反馈闭环传函并确认极点位于左半平面
  • 关键一步：把 s=jω 代入闭环传函分别求幅频与相频
  • 中间结果：输出与输入同频，幅值按幅频特性缩放、相位按相频特性平移
  • 卡点：输入频率取2弧度每秒，须代入闭环传函而非开环传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求正弦输入下系统的稳态输出
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

2二、根轨迹与欠阻尼稳定域#

思路
  • 标出三个开环极点画常规根轨迹，求分离点与虚轴交点定临界增益，再取复根段的增益区间
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制三条分支的常规根轨迹
本卷实例
  • 关键一步：标出开环极点0、-1、-2，无开环零点
  • 关键一步：渐近线与实轴交点和三条分支夹角由极点个数决定
  • 中间结果：实轴根轨迹段为负无穷到负二与负一到零两段
  • 卡点：三条分支的渐近线夹角在圆周上等分，不要漏掉一百八十度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制三条分支的常规根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点并作取舍
本卷实例
  • 关键一步：由幅值条件把增益写成 s 的显式函数后对 s 求导
  • 关键一步：解出驻点后按实轴根轨迹段筛选有效解
  • 中间结果：分离点方程化简为二次式，两根中只有一个落在实轴段内
  • 卡点：另一个驻点在实轴根轨迹段之外，必须舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点并作取舍
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界增益
本卷实例
  • 关键一步：把纯虚变量代入闭环特征方程并令实部虚部为零
  • 中间结果：临界增益下辅助方程的纯虚根给出虚轴交点坐标
  • 卡点：辅助方程的零频解不对应穿越，要取非零频率解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹复根段确定欠阻尼稳定的增益范围
本卷实例
  • 关键一步：复根段位于分离点与虚轴交点之间，两端分别给出增益下界与上界
  • 中间结果：分离点处增益为下界，虚轴交点处增益为上界
  • 卡点：欠阻尼与稳定要同时满足，区间取两条件的交集
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹复根段确定欠阻尼稳定的增益范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

3三、组合输入下的稳态误差#

思路
  • 先列劳斯表判稳，再数开环积分环节定型别，由终值定理分别计算各输入分量的稳态误差
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断闭环系统稳定性
本卷实例
  • 关键一步：由一加开环传函为零展开闭环特征方程并降幂排列
  • 中间结果：特征方程各次幂系数齐全，劳斯表首列全部同号
  • 卡点：先判稳再算稳态误差，否则终值定理不成立
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断闭环系统稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 写误差传递函数并按叠加拆开输入分量
本卷实例
  • 关键一步：取参考输入与反馈量之差为误差并写出误差传函
  • 中间结果：误差传函分母与闭环特征多项式相同
  • 卡点：输入含三个分量，不能只取其中一项求误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写误差传递函数并按叠加拆开输入分量
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环积分环节个数判断系统型别
本卷实例
  • 关键一步：数开环分母中 s 的幂次得到系统型别
  • 中间结果：本题开环只含一个积分环节，属Ⅰ型系统
  • 卡点：把开环增益直接当成静态误差系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由开环积分环节个数判断系统型别
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求组合典型输入下的稳态误差
本卷实例
  • 关键一步：按型别分别判断阶跃、斜坡与抛物线分量的误差
  • 中间结果：阶跃与斜坡分量对Ⅰ型系统可跟踪，抛物线分量超出跟踪能力
  • 卡点：抛物线分量的拉氏变换系数是幅值的两倍，别漏乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求组合典型输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

4四、二阶系统动态性能指标#

思路
  • 由单位负反馈写闭环传函化标准二阶形式，读出阻尼比与自然频率，再代入超调量与时间指标公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函化标准二阶形式并求阻尼比
本卷实例
  • 关键一步：把闭环特征式与标准式比较一次项与常数项系数
  • 中间结果：自然频率由常数项开方，阻尼比由一次项系数与自然频率确定
  • 卡点：先确认平方项系数为一后再比较，避免归一化出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函化标准二阶形式并求阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求欠阻尼二阶系统的超调量与调节时间
本卷实例
  • 关键一步：先由阻尼比算阻尼角，再代入超调量与时间指标公式
  • 中间结果：峰值时间与自然频率成反比，调节时间按误差带取不同系数
  • 卡点：百分之五与百分之二误差带的调节时间系数不能混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求欠阻尼二阶系统的超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

5五、对数幅频曲线与稳定性#

思路
  • 把开环传函化为尾一标准型逐段画渐近线并在谐振处修正，由两个穿越频率求相角与幅值裕度后判稳
典型环节的对数频率特性 频域分析
本卷考法
  • 分解典型环节并求振荡环节的阻尼比
本卷实例
  • 关键一步：把二次三项式化成标准振荡环节形式比较系数
  • 中间结果：阻尼比小于二分之根号二时存在谐振，谐振频率由自然频率与阻尼比决定
  • 卡点：谐振峰值公式只在欠阻尼且阻尼比较小时成立
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例环节是水平线，积分与微分分别是 -20 与 +20 dB/dec 的斜线
  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec
  • 一阶微分环节与惯性环节幅频互为镜像
  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤
  • 把传递函数分解为典型环节乘积

稳定裕度 频域分析
本卷考法
  • 求相角裕度与幅值裕度并判断稳定性
本卷实例
  • 关键一步：由幅频特性等于一确定截止频率，由相频等于负一百八十度确定相位穿越频率
  • 中间结果：相角裕度为一百八十度加截止频率处相角，幅值裕度取幅值倒数
  • 卡点：两个穿越频率不能对调，否则裕度正负结论相反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求相角裕度与幅值裕度并判断稳定性
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

思路

梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求多回路系统的传递函数
本卷实例
  • 关键一步：先数出全部独立回路与前向通路，判断互不接触回路对
  • 中间结果：特征式为一加各回路增益，再减互不接触回路增益乘积
  • 卡点：结构图未读图，回路数与互不接触关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求多回路系统的传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
