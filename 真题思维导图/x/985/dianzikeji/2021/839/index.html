1结构图双输入求输出#

思路
  • 结构图含参考与扰动两个输入，分别令另一输入为零，用梅森公式求两条通道的输出传函
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求参考输入与扰动输入作用下的输出传函
本卷实例
  • 关键一步：对R、D两通道分别置零另一输入，画信号流图标回路
  • 中间结果：两通道闭环特征式相同，分子为各自前向通路与余子式之积
  • 卡点：结构图为原卷插图，交叉支路走向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求参考输入与扰动输入作用下的输出传函
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式列特征式与前向通路余子式
本卷实例
  • 关键一步：分别对R、D列前向通路并写出对应余子式
  • 中间结果：D通道有两条前向通路，其中一条经过局部反馈回路
  • 卡点：求D通道时未令R=0，或漏算局部回路的余子式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式列特征式与前向通路余子式
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2RLC电路参数与稳态误差#

思路
  • 由输出响应c(t)反求误差与闭环传函，再用KVL/KCL建电路传函，对比系数求L、C
由响应曲线反求传递函数 传递函数
本卷考法
  • 由给定单位阶跃响应表达式反求闭环传函与误差传函
本卷实例
  • 关键一步：由误差等于1减c(t)取拉氏变换得误差传函
  • 中间结果：误差传函分母即闭环特征多项式，由响应两个时间常数确定
  • 卡点：响应表达式两个指数项系数与闭环极点要一一对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由给定单位阶跃响应表达式反求闭环传函与误差传函
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由误差传函用终值定理求单位阶跃输入下的稳态误差
本卷实例
  • 关键一步：先用劳斯判据确认闭环稳定，再用终值定理求稳态误差
  • 中间结果：稳态误差等于s乘误差传函取s趋于零的极限
  • 卡点：未判稳就套用终值定理是常见错误
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由误差传函用终值定理求单位阶跃输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3稳态误差反求参数关系#

思路
  • I型系统对阶跃无差，仅斜坡项贡献稳态误差；先劳斯判据保稳定，再联立求两时间常数关系
系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环传函判断系统型别与静态速度误差系数
本卷实例
  • 关键一步：开环含一个积分环节定为I型，阶跃分量稳态误差为零
  • 中间结果：速度误差系数由开环增益与各时间常数乘积决定
  • 卡点：a、b两个输入分量要分别代入，不能合并幅值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由开环传函判断系统型别与静态速度误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

典型输入下的稳态误差计算 稳态误差
本卷考法

本卷实例

  • 中间结果：稳态误差与开环增益成反比，与时间常数乘积成正比
  • 卡点：误差要求与稳定要求是两条不等式，需取交集
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤

  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求复合输入下的稳态误差并令其小于给定值
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理

  • Ⅰ型系统求阶跃误差时误代入速度误差公式

劳斯判据 稳定性分析
本卷考法
  • 由三阶闭环特征方程列劳斯表求稳定条件
本卷实例
  • 关键一步：列劳斯表，令首列各元素同号得稳定不等式组
  • 中间结果：首列某行元素含两时间常数与开环增益的组合
  • 卡点：首列含待定参数时符号讨论易漏，需逐项检验
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由三阶闭环特征方程列劳斯表求稳定条件
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

4零度根轨迹与临界参数#

思路
  • 闭环方程可整理成开环传函等于1的零度根轨迹形式；由分离点与虚轴交点求重根与纯虚根对应参数
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制增益从0到正无穷的零度根轨迹概略图
本卷实例
  • 关键一步：把闭环特征方程整理成开环传函等于1的零度根轨迹形式
  • 中间结果：由开环零极点定实轴上根轨迹区间与渐近线
  • 卡点：零度根轨迹的相角条件与180度根轨迹不同，图需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制增益从0到正无穷的零度根轨迹概略图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 由分离点方程求系统出现重实根时的参数
本卷实例
  • 关键一步：对等效开环求导或列分离点方程，解出分离与会合点
  • 中间结果：分离点可能有两个，对应根轨迹两分支的实际交汇位置
  • 卡点：解出的分离点要代回根轨迹确认确实落在根轨迹上
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由分离点方程求系统出现重实根时的参数
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由s等于jω代入特征方程求纯虚根及临界参数
本卷实例
  • 关键一步：令特征方程实部与虚部分别为零，联立求频率与增益
  • 中间结果：临界增益由虚轴交点对应的振荡频率确定
  • 卡点：重实根与纯虚根对应两个不同参数，别混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由s等于jω代入特征方程求纯虚根及临界参数
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

5Bode图反求传函与非最小相位判稳#

思路
  • 由低频斜率定型别、转折频率定各环节，再由初始相角判非最小相位；用相角裕度判稳
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由渐近对数幅频特性反求开环传递函数
本卷实例
  • 关键一步：由低频段斜率定型别，各转折频率处斜率变化定环节
  • 中间结果：惯性、微分与含右半平面极点的一阶环节依次串接
  • 卡点：转折频率处斜率变化要按累加量求和，曲线读数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由渐近对数幅频特性反求开环传递函数
  • 由给定 Bode 图写出传递函数
