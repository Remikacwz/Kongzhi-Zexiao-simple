1电路网络传函与稳定性讨论#

思路
  • 列两电容两电阻网络的电压电流方程并消元求传函；再由传函分母系数讨论元件参数对稳定性的影响
由电路或机械系统求传递函数 传递函数
本卷考法
  • 第(1)问由电路列方程求传递函数
本卷实例
  • 关键一步：对电容用积分形式的伏安关系，列回路方程后消去中间电流
  • 中间结果：消元整理得含 s 的二阶分式传递函数
  • 卡点：电路为原卷插图，元件连接与电压参考方向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过第(1)问由电路列方程求传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 按电路网络建模的一般步骤整理传递函数
本卷实例
  • 关键一步：用复阻抗法与列时域方程变换两种途径交叉验证
  • 中间结果：传函分母为二阶多项式，系数由两阻两容组合而成
  • 卡点：复阻抗法把电容阻抗误写成电容乘 s
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过按电路网络建模的一般步骤整理传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 第(2)问讨论元件参数对系统稳定性的影响
本卷实例
  • 关键一步：看传函分母各项系数是否都为正，按劳斯判据给出条件
  • 中间结果：二阶系统稳定的条件化为两个系数不等式
  • 卡点：只看一个系数就判断系统是否稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过第(2)问讨论元件参数对系统稳定性的影响
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

2结构图求输出与误差传函#

思路
  • 用结构图化简或梅森公式求输出对输入、输出对误差的两个传函，注意两条通道输入不同
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 求多回路结构图的 C(s)/R(s) 与 C(s)/E(s)
本卷实例
  • 关键一步：分别以参考输入和误差为输入，按逐层化简求两条通道的传函
  • 中间结果：两条通道共用同一闭环特征式，区别在前向通路
  • 卡点：求输出对误差传函时没有把误差当独立输入处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过求多回路结构图的 C(s)/R(s) 与 C(s)/E(s)
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式列各前向通路及其余子式
本卷实例
  • 关键一步：从输入到输出枚举前向通路，逐条判断与回路的接触关系
  • 中间结果：特征式与各余子式相乘后求和再除以特征式
  • 卡点：余子式未剔除与通路接触的回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式列各前向通路及其余子式
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 说明输出对误差传函与误差定义的关系
本卷实例
  • 关键一步：区分误差取在输入端还是输出端对应的两种定义
  • 中间结果：输出对误差传函与误差对输入传函互为对应关系
  • 卡点：非单位反馈时两种误差定义相差一个反馈环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过说明输出对误差传函与误差定义的关系
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式

3正弦稳态与二阶指标综合#

思路
  • 由谐振数据定二阶参数求指标与误差，再由正弦稳态幅相关系反求参数
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 第(1)问求单位阶跃输入下的超调量与调节时间
本卷实例
  • 关键一步：由已定的阻尼比与自然频率代入欠阻尼指标表达式
  • 中间结果：超调量只由阻尼比决定，调节时间由两者乘积决定
  • 卡点：两种误差带的调节时间系数混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过第(1)问求单位阶跃输入下的超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 第(2)问求单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：由开环传函判断系统型别，再取静态速度误差系数
  • 中间结果：I 型系统的斜坡误差由开环增益与时间常数决定
  • 卡点：未判稳就使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过第(2)问求单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
闭环频率特性与性能指标 频域分析
本卷考法
  • 由闭环谐振数据反求二阶系统参数
本卷实例
  • 关键一步：把稳态输出最大值对应到谐振峰值，联立谐振频率条件求参数
  • 中间结果：谐振峰值为阻尼比的函数，谐振频率由两者共同决定
  • 卡点：把谐振峰值当成直流增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过由闭环谐振数据反求二阶系统参数
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 第(3)问由正弦输入的稳态输出反求阻尼比与自然频率
本卷实例
  • 关键一步：由输入输出幅值比与相位差写出幅频和相频方程
  • 中间结果：两个方程联立解出阻尼比与自然频率
  • 卡点：相位差的正负号与滞后方向取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过第(3)问由正弦输入的稳态输出反求阻尼比与自然频率
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

4非最小相位系统根轨迹#

思路
  • 把特征方程整理成一加参数倍开环传函等于零的形式，按非最小相位零点分布绘制根轨迹
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 由含右半平面零点的特征方程绘制参数根轨迹
本卷实例
  • 关键一步：先把含参数的项分离并整理成标准根轨迹方程形式
  • 中间结果：等效开环传函的零点落在右半平面，属非最小相位
  • 卡点：整理时没有把参数完整提到分子位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过由含右半平面零点的特征方程绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则说明根轨迹的走向与分支数
本卷实例
  • 关键一步：依开环零点极点数目定分支数与渐近线
  • 中间结果：实轴段的归属由该段右侧零点极点个数奇偶判定
  • 卡点：分支数不等于开环极点数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则说明根轨迹的走向与分支数
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 用相角条件核对候选点是否在根轨迹上
本卷实例
  • 关键一步：验证候选点处各零点极点相角之和是否满足条件
