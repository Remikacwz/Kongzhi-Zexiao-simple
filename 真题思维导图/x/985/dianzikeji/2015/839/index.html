1双输入结构图求输出#

思路
  • 两个输入同时作用，分别令另一输入为零，用梅森公式求各通道输出传函后再叠加
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求两个输入共同作用下系统的输出表达式
本卷实例
  • 关键一步：对两个输入分别置零，画出各自信号流图再列前向通路
  • 中间结果：两通道共用同一特征式，输出为各通道贡献之和
  • 卡点：结构图为原卷插图，交叉支路走向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求两个输入共同作用下系统的输出表达式
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式列回路与不接触回路
本卷实例
  • 关键一步：先数独立回路并找出互不接触的回路对，再写特征式
  • 中间结果：特征式含回路增益与两两不接触回路的乘积项
  • 卡点：漏掉互不接触回路是本题主要失分点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式列回路与不接触回路
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二阶系统斜坡误差与临界阻尼#

思路
  • 由结构图求闭环传函与误差传函，用终值定理求斜坡误差；无超调且调节时间最短对应临界阻尼
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 第(1)问求单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：先确认闭环稳定，再由终值定理写误差极限
  • 中间结果：误差极限化为与静态速度误差系数有关的形式
  • 卡点：未先判稳就直接套用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过第(1)问求单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 第(2)问由无超调和最短调节时间反求参数
本卷实例
  • 关键一步：无超调对应临界阻尼，把阻尼比取为一
  • 中间结果：将闭环特征多项式与标准二阶形式逐项比对系数
  • 卡点：把无超调当成阻尼比大于一，会错过最短调节时间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过第(2)问由无超调和最短调节时间反求参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

3电机随动系统反馈校正#

思路
  • 先由方块图求校正前传函与指标，再合并反馈支路求校正后传函与斜坡误差
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 第(1)问由开环传函求校正前的超调量与调节时间
本卷实例
  • 关键一步：把开环传函化为标准二阶形式，读出自然频率与阻尼比
  • 中间结果：由阻尼比与自然频率代入超调量和调节时间表达式
  • 卡点：反馈校正支路含原卷插图，元件接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过第(1)问由开环传函求校正前的超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
反馈校正与复合控制 系统校正
本卷考法
  • 第(2)问由高通滤波器反馈支路求校正后闭环传函
本卷实例
  • 关键一步：先列反馈支路传函，再按反馈校正把被包围环节等效化简
  • 中间结果：校正后闭环分母由原环节与反馈支路共同决定
  • 卡点：把反馈校正当成串联校正处理会写错结构
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过第(2)问由高通滤波器反馈支路求校正后闭环传函
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

4零度根轨迹与稳定K范围#

思路
  • 开环含正反馈形式的零点，需按零度根轨迹绘制；再由与虚轴交点定出使系统稳定的K范围
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 第(1)问绘制含右半平面开环零点的零度根轨迹
本卷实例
  • 关键一步：把开环传函整理成分子含参数的正反馈形式，改用零度相角条件
  • 中间结果：零度根轨迹的渐近线与实轴段判据与常规情形相反
  • 卡点：仍按一百八十度相角条件画会得出错误分支
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过第(1)问绘制含右半平面开环零点的零度根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 第(2)问求根轨迹与虚轴交点并定出稳定K范围
本卷实例
  • 关键一步：把 s 取 jω 代入闭环特征方程并分离实部与虚部
  • 中间结果：由虚部方程解出穿越频率，再由实部方程解出临界增益
  • 卡点：只代一个频率会漏掉另一组交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过第(2)问求根轨迹与虚轴交点并定出稳定K范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则说明零极点分布与实轴上的根轨迹
本卷实例
  • 关键一步：先标出开环极点与零点，再判实轴段归属
  • 中间结果：根轨迹起于开环极点、终于开环零点
  • 卡点：渐近线参数要与零点个数一起算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则说明零极点分布与实轴上的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

5参数稳定域与PD控制器作用#

思路
  • 由劳斯判据求参数稳定域，对组合输入分项求误差，再论PD参数影响
参数稳定域的确定 稳定性分析
本卷考法
  • 第(1)问用劳斯判据求参数保持稳定应满足的条件
本卷实例
  • 关键一步：由特征方程列劳斯表，令首列各项均大于零
  • 中间结果：把首列不等式取交集得到两个参数的联合约束
  • 卡点：只列一个不等式会漏掉另一参数的约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过第(1)问用劳斯判据求参数保持稳定应满足的条件
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
