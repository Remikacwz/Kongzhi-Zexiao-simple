1电路与框图建模#

思路
  • 电路用复阻抗分压，框图用串并反馈化简；两个系统分别独立算，别互相串味
由电路或机械系统求传递函数 传递函数
本卷考法
  • 给定 R、C 参数求电路传递函数
本卷实例
  • 关键一步：对运放节点用虚短、虚断列 KCL，不要直接做并联等效
  • 中间结果：两对 RC 支路结构相同，闭环比值化为常数
  • 卡点：元件编号在 OCR 中可能互换，需回原卷核对图 1
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过给定 R、C 参数求电路传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过电容复阻抗误写成 Cs
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由框图求闭环传递函数
本卷实例
  • 关键一步：由结构图标出三个独立回路，再用梅森公式写前向通路与余子式
  • 中间结果：特征式含三回路，且无互不接触项
  • 卡点：第二条前向通路的余子式等于 Δ，容易漏写
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由框图求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2由响应曲线求参数与调节时间#

思路
  • 稳态值定 h，超调量定 ξ，峰值时间定 ωn；调节时间注意题目给的是 ±2% 误差带
由响应曲线反求传递函数 传递函数
本卷考法
  • 由阶跃响应曲线求 a、k、h
本卷实例
  • 关键一步：稳态值定 h，超调量定 ξ，峰值时间定 ωn，三者联立
  • 中间结果：Φ(0)=1/h，超调量与 ξ 一一对应
  • 卡点：峰值 4.32、稳态 3、tp=6.49 s 的读数需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由阶跃响应曲线求 a、k、h
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 本卷考过未判断阶数就套二阶公式
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • Δ=±2% 时求调节时间
本卷实例
  • 关键一步：调节时间按 ±2% 误差带取 4.4/(ξωn)
  • 中间结果：ξ、ωn 已由第 1 问定出，直接代入
  • 卡点：不要用 5% 误差带的 3/ξωn 或 3.5 系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关

  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过Δ=±2% 时求调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错

  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3劳斯判据与参数稳定域#

思路
  • s⁴+2s³+s²+2s+K=0 列劳斯表，注意第三行首列可能为零，需要特殊处理
劳斯判据 稳定性分析
本卷考法
  • 讨论 K 对系统稳定性的影响
本卷实例
  • 关键一步：列劳斯表，第二行与第一行成比例使 s² 行首列为零，改用 ε 法
  • 中间结果：s¹ 行与 s⁰ 行的符号共同决定稳定性
  • 卡点：K 为零与 K 大于零要分情况讨论，不能只写一个区间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过讨论 K 对系统稳定性的影响
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过首列出现 0 时未用 ε 法
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求使系统稳定的 K 范围
本卷实例
  • 关键一步：由劳斯表首列同号得到 K 的不等式组
  • 中间结果：K 小于零与 K 大于零时首列变号次数不同
  • 卡点：本题 K 可取负值，稳定域可能为空或只含临界点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求使系统稳定的 K 范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

4正反馈根轨迹#

思路
  • 单位正反馈对应零度根轨迹，相角条件变成 0°+360°l；「无衰减振荡」即闭环极点为实数
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • k<0 时绘制正反馈（零度）根轨迹
本卷实例
  • 关键一步：单位正反馈对应零度根轨迹，相角条件改为 0°+360°l
  • 中间结果：k 从 0 到负无穷变化，根轨迹方向与常规相反
  • 卡点：零度根轨迹的渐近线夹角与 180° 情形不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过k<0 时绘制正反馈（零度）根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 本卷考过零度根轨迹仍沿用 180° 相角条件
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画根轨迹草图
本卷实例
  • 关键一步：起点为三个开环极点，终点为一个零点加两个无穷远零点
  • 中间结果：实轴根轨迹段由该段右侧零极点个数为偶数判定
  • 卡点：重极点 −1 的分离与汇合要单独处理，配图需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴段判据中的零极点个数算错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

与虚轴的交点及临界参数 根轨迹法
本卷考法

本卷实例
  • 关键一步：临界稳定对应劳斯表首列出现零或出现全零行
  • 中间结果：本题 k 小于零时首列不变号，故无虚轴交点

通用考法

  • 求根轨迹与虚轴的交点及临界增益

  • 判断根轨迹穿越虚轴的方向
常见易错

  • 只代一个 ω 就下结论，漏掉另一组交点

5频域反求传函与相角裕度#

思路
  • 低频段斜率定型别、高度定增益，转折频率逐个对应环节；相角裕度只看符号不要求算具体值
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环渐近对数幅频特性求传递函数
本卷实例
  • 关键一步：低频段 0 dB/dec 说明无积分环节，转折频率 1 处修正量定 ζ
  • 中间结果：设 G=k/((s²/ωn²+2ξs/ωn+1)(s/10+1))，由低频高度定 k
  • 卡点：转折频率处修正值与 ζ 的换算需回原卷核对图 6
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环渐近对数幅频特性求传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错

  • 把延长线交点误当作增益值而未折算型别

稳定裕度 频域分析
本卷考法
  • 粗略估算剪切频率 ωc
  • 用相角裕度判断稳定性
本卷实例
  • 关键一步：在 1 与 10 之间用 |G| 约等于 k/ω² 等于 1 估截止频率
  • 中间结果：ωc 落在两个转折频率之间，可用抓大放小
  • 卡点：相角裕度只判符号，但相角公式在 ω=1 处要接上
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
