本卷实例

  • 关键一步：分母通分后分子就是闭环特征多项式

本卷考法
  • 选择2 判断叠加原理不适用的系统
本卷实例
  • 关键一步：从齐次性与叠加性的定义检查系统是否线性
  • 中间结果：线性系统满足叠加原理，非线性系统不满足
  • 卡点：误以为非线性系统在小信号下仍满足叠加性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过选择2 判断叠加原理不适用的系统
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定

奈奎斯特判据 稳定性分析
本卷考法
  • 选择4 比较奈氏判据与劳斯判据的结论范围
本卷实例
  • 关键一步：分别明确两种判据能给出的是系统是否稳定还是根的分布
  • 中间结果：两种判据都能给出右半平面根个数，但不含根的相对分布
  • 卡点：把只能判断稳定与否误说成能判断根的相对分布
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过选择4 比较奈氏判据与劳斯判据的结论范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

劳斯判据 稳定性分析
本卷考法
  • 选择5 用劳斯判据判断闭环稳定性
本卷实例
  • 关键一步：由 1+G=0 展开闭环特征多项式并降幂排列
  • 中间结果：列劳斯表后检查首列元素是否全部同号
  • 卡点：开环有右半平面极点时仍按开环极点去数稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过选择5 用劳斯判据判断闭环稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 选择6 一阶系统时间常数与到达稳定的时间
本卷实例
  • 关键一步：一阶系统按指数趋近稳态，时间常数越大过程越慢
  • 中间结果：调节时间与时间常数成正比，比例系数由误差带决定
  • 卡点：把到达稳定理解成有限时刻内完全等于稳态值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过选择6 一阶系统时间常数与到达稳定的时间
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

本卷考法
  • 选择7 单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：先数开环积分环节个数判断型别，再选对应静态误差系数
  • 中间结果：开环为Ⅰ型，斜坡误差由速度误差系数决定

  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差

步骤

  • 写出输入信号的拉氏变换

通用考法
  • 本卷考过选择7 单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

滞后校正 系统校正
本卷考法
  • 选择9 由零极点位置判断校正类型
本卷实例
  • 关键一步：把校正环节化为标准一阶形式，比较零点与极点的转折频率
  • 中间结果：极点比零点更靠近原点，高频段幅值被压低
  • 卡点：只看分子分母时间常数的数值大小，忽略零极点相对位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法

  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错

  • 转折频率取得过高导致相位滞后抵消了增益改善

减小稳态误差的措施 稳态误差
本卷考法
  • 选择11 串联衰减增益对稳态性能的影响
本卷实例
  • 关键一步：把前向通道增益变化与静态误差系数的变化方向对应
  • 中间结果：增益减小使静态误差系数减小，稳态误差增大
  • 卡点：只看暂态快慢而忽略稳态精度随增益的变化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过选择11 串联衰减增益对稳态性能的影响
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
