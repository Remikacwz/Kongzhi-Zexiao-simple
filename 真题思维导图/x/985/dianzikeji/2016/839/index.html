1结构图多回路求闭环传函#

思路
  • 结构图含三条回路，用梅森公式列特征式与各前向通路的余子式，再作逐层化简核对
梅森增益公式与信号流图 传递函数
本卷考法
  • 由多回路结构图用梅森增益公式求闭环传递函数
本卷实例
  • 关键一步：先数独立回路并判断彼此是否接触
  • 中间结果：特征式由三条回路增益及其互不接触乘积项组成
  • 卡点：不接触回路漏算或重复计数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由多回路结构图用梅森增益公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 按逐层化简思路核对多回路系统的等效结构
本卷实例
  • 关键一步：从最内环开始逐层化简，保留外环信号关系
  • 中间结果：内环化简易为单环形式后再与外环合并
  • 卡点：化简内环时把外环信号当成常数处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过按逐层化简思路核对多回路系统的等效结构
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2二阶系统参数与动态指标#

思路
  • 由方块图求闭环传函，与标准二阶式对比系数反求K与τ；再由阻尼比和自然频率求调节时间与超调量
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 第(1)问由自然频率与阻尼比的要求确定闭环结构参数
本卷实例
  • 关键一步：先把闭环传函化为标准二阶形式，把参数与结构量一一对应
  • 中间结果：闭环特征多项式系数与标准形式逐项相等
  • 卡点：化标准形式时忘记把最高次项系数归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过第(1)问由自然频率与阻尼比的要求确定闭环结构参数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 第(1)问反求满足给定动态指标的结构参数
本卷实例
  • 关键一步：把给定的自然频率与阻尼比代入标准式解出两个结构参数
  • 中间结果：两个结构参数由两个系数方程联立解出
  • 卡点：只满足单项指标就下结论，未核另一个
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过第(1)问反求满足给定动态指标的结构参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 第(2)问求单位阶跃下的调节时间与最大超调量
本卷实例
  • 关键一步：先确认阻尼比为临界阻尼，再取对应的调节时间形式
  • 中间结果：临界阻尼下无超调，调节时间由自然频率单独决定
  • 卡点：对临界阻尼仍套用欠阻尼的峰值时间公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过第(2)问求单位阶跃下的调节时间与最大超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3特征根实部约束的参数范围#

思路
  • 要求闭环特征根实部均小于负一，属相对稳定度问题；作变量左移后套劳斯判据求参数条件
参数稳定域的确定 稳定性分析
本卷考法
  • 求闭环特征根实部均小于给定值时的参数条件
本卷实例
  • 关键一步：作变量代换把相对稳定度约束化为新变量下的稳定性问题
  • 中间结果：代入后按新特征方程列首列不等式
  • 卡点：直接对原特征方程用劳斯判据只能得绝对稳定条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求闭环特征根实部均小于给定值时的参数条件
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据列首列各项的约束
本卷实例
  • 关键一步：按代换后的特征方程列劳斯表并令首列全为正
  • 中间结果：多条不等式取交集得到参数可行域
  • 卡点：首列出现零时未用 ε 法继续判别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据列首列各项的约束
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

4Nyquist图绘制与判稳#

思路
  • 由开环传函画奈奎斯特曲线，数开环右半平面极点数，再按闭环右半平面极点数等于两者之差判稳
奈奎斯特判据 稳定性分析
本卷考法
  • 绘制 Nyquist 图并用奈奎斯特判据判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数，再看曲线包围负一点的圈数
  • 中间结果：由右半平面极点数与包围圈数之差判断闭环极点分布
  • 卡点：开环含右半平面极点时未正确取右半平面极点数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过绘制 Nyquist 图并用奈奎斯特判据判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求开环传函的幅频与相频表达式并描点绘图
本卷实例
  • 关键一步：按典型环节分解，分别写幅频与相频再合成
  • 中间结果：低频段幅值与相角由系统型别和开环增益决定
  • 卡点：相角累加时漏掉惯性环节的负九十度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求开环传函的幅频与相频表达式并描点绘图
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

5结构图列写状态空间表达式#

思路
  • 取图中积分器的输出为状态变量，按各支路关系列写状态方程与输出方程并整理成矩阵形式
状态空间表达式的建立 状态空间分析
本卷考法
  • 由结构框图选取状态变量并写出状态方程和输出方程
本卷实例
  • 关键一步：把每个积分器的输出定为状态变量，按支路写其导数关系
  • 中间结果：整理为标准矩阵形式，输出方程按取出点写出
  • 卡点：状态变量个数必须与系统阶数一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由结构框图选取状态变量并写出状态方程和输出方程
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

6根轨迹与阵风扰动误差#

思路
  • 先按绘制法则画根轨迹；再在给定K下求扰动到输出的传函，用终值定理求扰动稳态误差
根轨迹的绘制法则 根轨迹法
本卷考法
  • 第(1)问按绘制法则画出系统的根轨迹
本卷实例
  • 关键一步：先标开环零极点，按实轴段与渐近线法则画草图
  • 中间结果：渐近线交点与夹角由零点极点分布确定
  • 卡点：渐近线夹角公式中的系数记错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过第(1)问按绘制法则画出系统的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 第(2)问求阵风扰动作用下的稳态误差
本卷实例
  • 关键一步：令参考输入为零，单独求扰动到误差的传函
  • 中间结果：扰动误差由扰动传函在 s 趋于零时的极限得到
  • 卡点：把扰动误差与参考输入引起的误差混在一起
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过第(2)问求阵风扰动作用下的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错

8描述函数法判自振#

思路
  • 写负倒描述函数，与线性部分幅相曲线比较，按交点与稳定区走向判断自振并求频率振幅
用描述函数法分析自振 非线性系统
本卷考法
  • 由描述函数与线性部分判断稳定性并求自振频率和振幅
本卷实例
  • 关键一步：把线性部分幅相曲线与负倒描述函数曲线画在同一复平面上比较
  • 中间结果：交点对应自振频率与振幅，按走向判断振荡是否稳定
  • 卡点：未标出振幅增大方向就直接下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过由描述函数与线性部分判断稳定性并求自振频率和振幅
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率

状态反馈与极点配置 状态空间分析

本卷实例

  • 分析状态反馈对系统性能的影响
