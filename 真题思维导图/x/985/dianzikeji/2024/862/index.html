1一、方框图化简求传递函数#

思路
  • 多回路结构图从内到外逐层化简，串联并联与反馈环节依次合并，最终写出闭环传递函数并保留化简步骤
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由多回路结构图从内到外逐层化简求闭环传函
本卷实例
  • 关键一步：先化简最内层回路，再依次向外合并
  • 中间结果：各回路增益相乘后进入闭环分母
  • 卡点：方框图回路接法与反馈极性需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由多回路结构图从内到外逐层化简求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 串联、并联与反馈环节等效合并
本卷实例
  • 关键一步：同向并联相加，反馈用一加回路增益
  • 中间结果：两条并联支路可先合并成一条
  • 卡点：负反馈分母写成一加回路增益，别写成相减
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过串联、并联与反馈环节等效合并
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
比较点与引出点的移动 结构图与方框图
本卷考法
  • 必要时移动比较点或引出点整理交叉回路
本卷实例
  • 关键一步：按前移用除、后移用乘补等效环节
  • 中间结果：等效移动前后各支路信号关系不变
  • 卡点：比较点与引出点移动规则容易混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过必要时移动比较点或引出点整理交叉回路
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用

2二、判稳与组合输入稳态误差#

思路
  • 由开环传函写闭环特征方程并用劳斯表判稳，再把阶跃与斜坡输入分解，分别求稳态误差后叠加
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断三阶系统稳定性
本卷实例
  • 关键一步：列劳斯表后检查首列元素符号
  • 中间结果：首列全为正时系统稳定
  • 卡点：逐年册把分母0.1s+1印成0.5s+1，据宝典与答案取0.1
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断三阶系统稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环积分环节个数判断系统型别
本卷实例
  • 关键一步：数开环分母的积分环节个数定型别
  • 中间结果：分母含两个积分环节属二型系统
  • 卡点：型别只看积分环节，不要被分子零点干扰
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由开环积分环节个数判断系统型别
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 阶跃与斜坡组合输入分别求稳态误差再叠加
本卷实例
  • 关键一步：先判稳，再对每个输入分量用终值定理
  • 中间结果：二型系统对阶跃与斜坡的稳态误差均为零
  • 卡点：组合输入要逐项分解，不能把两种输入合并成一个
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过阶跃与斜坡组合输入分别求稳态误差再叠加
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、Bode图绘制与修正#

思路
  • 开环传函化尾一标准型，按转折频率逐段画对数渐近线，对振荡环节在谐振频率处作峰值修正
开环对数频率特性的绘制 频域分析
本卷考法
  • 由开环传函绘制对数渐近幅频特性
本卷实例
  • 关键一步：先化尾一标准型再逐段定转折频率
  • 中间结果：各转折频率处斜率依次变化
  • 卡点：各段斜率要累加，不能只记最后一个环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过由开环传函绘制对数渐近幅频特性
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
典型环节的对数频率特性 频域分析
本卷考法
  • 求振荡环节的阻尼比、谐振频率与谐振峰值
本卷实例
  • 关键一步：把二次项化为标准振荡环节形式比较系数
  • 中间结果：阻尼比小于二分之根号二时存在谐振
  • 卡点：修正量只加在谐振频率附近，不能抬高整条渐近线
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例环节是水平线，积分与微分分别是 -20 与 +20 dB/dec 的斜线
  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec
  • 一阶微分环节与惯性环节幅频互为镜像
  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤
  • 把传递函数分解为典型环节乘积
  • 逐环节画出对数幅频渐近线与相频曲线
  • 代数相加得到总特性
通用考法
  • 本卷考过求振荡环节的阻尼比、谐振频率与谐振峰值
  • 画出某一典型环节的 Bode 图
  • 由 Bode 图识别环节类型
  • 说明转角频率处的幅值与相角
常见易错
  • 把惯性环节高频渐近线的 -20 写成 -40
  • 振荡环节谐振峰位置误当作 ωn

4四、由对数幅频曲线反求传函与稳定裕度#

思路
  • 由低频段斜率与延长线交点定型别与增益，由转折频率识别各环节，再由幅值条件与相位条件求稳定裕度
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环对数幅频特性曲线反求传递函数
本卷实例
  • 关键一步：低频段斜率给积分环节个数，延长线交点给增益
  • 中间结果：转折频率依次对应一阶或振荡环节
  • 卡点：幅频曲线以图给出，转折频率与谐振峰需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环对数幅频特性曲线反求传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 求相角裕度与幅值裕度
本卷实例
  • 关键一步：分别由幅值条件与相位条件定两个穿越频率
  • 中间结果：相角裕度由截止频率处的相角决定
  • 卡点：相位穿越频率不存在时幅值裕度为无穷大
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求相角裕度与幅值裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式

5五、正弦输入下的稳态输出#

思路
  • 由开环传函写闭环传函，把输入频率代入求幅值与相角，按线性系统正弦稳态规律写出输出表达式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求闭环频率特性在输入频率处的幅值与相角
本卷实例
  • 关键一步：开环化为闭环后代入给定输入频率求模与相角
  • 中间结果：输出幅值等于输入幅值乘该频率处闭环幅值
  • 卡点：相位差要连同输入初相一起相加，别只取系统相角
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求闭环频率特性在输入频率处的幅值与相角
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

6六、根轨迹绘制与降阶范围#

思路
  • 画三条分支的180度常规根轨迹，求分离点与虚轴交点，再由主导极点条件说明可降阶并定出衰减振荡的K范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制三个开环极点的常规根轨迹
本卷实例
  • 关键一步：先标开环极点再做相角与渐近线分析
  • 中间结果：实轴根轨迹段为负无穷到负三与负二到负一
  • 卡点：渐近线夹角公式中的二k加一别写成二k
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
