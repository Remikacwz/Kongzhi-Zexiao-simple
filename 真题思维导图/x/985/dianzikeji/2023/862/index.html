1一、二阶系统参数与动态指标#

思路
  • 由 K=4、T=1 写闭环传函化标准二阶形式求阻尼比与自然频率，代入超调量、调节时间、上升时间公式；再由给定阻尼比反求 K
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函化标准形式求阻尼比与自然频率
本卷实例
  • 关键一步：先写闭环传函，再与标准二阶式比较一次项与常数项
  • 中间结果：闭环标准式中一次项与常数项分别由时间常数和增益决定
  • 卡点：阻尼比与自然频率的表达式要先约去公共因子再代入数值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函化标准形式求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求欠阻尼二阶系统的超调量、调节时间与上升时间
本卷实例
  • 关键一步：先由阻尼比算阻尼角，再分别代入三个时间指标公式
  • 中间结果：上升时间与阻尼角、自然频率都有关，峰值时间只与自然频率有关
  • 卡点：调节时间按百分之五与百分之二误差带取不同系数，按题指定的取
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求欠阻尼二阶系统的超调量、调节时间与上升时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由给定阻尼比反求开环增益
本卷实例
  • 关键一步：把阻尼比与增益、时间常数的关系式反解
  • 中间结果：阻尼比与增益乘时间常数的平方根成反比
  • 卡点：时间常数不变时增益随阻尼比减小而增大
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由给定阻尼比反求开环增益
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

2二、误差传函与无静差证明#

思路
  • 写出闭环与误差传函，由终值定理令斜坡输入下稳态误差为零，反解满足条件的 Ki；讨论时先判稳
误差定义与误差传递函数 稳态误差
本卷考法
  • 写误差传函并把补偿环节并入前向通道
本卷实例
  • 关键一步：把补偿环节与前向通道相乘后重新写误差传函
  • 中间结果：误差传函分母仍是闭环特征多项式
  • 卡点：系统结构图未读图，补偿环节接入位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写误差传函并把补偿环节并入前向通道
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由前向通道积分环节判断系统型别
本卷实例
  • 关键一步：数前向通道的积分环节个数判断型别
  • 中间结果：补偿环节不增加积分环节，靠分子零点抵消斜坡误差
  • 卡点：型别由分母积分环节决定，不要数错分子零点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由前向通道积分环节判断系统型别
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由终值定理证明斜坡输入下无稳态误差
本卷实例
  • 关键一步：令斜坡输入下误差极限为零，解出补偿增益与开环增益的关系
  • 中间结果：误差极限分子含一减两增益乘积的因子
  • 卡点：结论要求两增益满足特定乘积关系，不是任意取值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由终值定理证明斜坡输入下无稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 用零点补偿减小稳态误差
本卷实例
  • 关键一步：在误差传函分子引入零点以抵消斜坡输入引起的误差项
  • 中间结果：补偿只改分子不改分母，故不改变系统极点
  • 卡点：零点补偿会改变动态响应，需与稳定性一起检查
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过用零点补偿减小稳态误差
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

3三、根轨迹与稳定域#

思路
  • 把开环传函化成带根轨迹增益的标准形式画根轨迹，求分离点与虚轴交点，由左半平面确定稳定区间并换算回 K
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制三条分支的常规根轨迹
本卷实例
  • 关键一步：先做时间常数归一化，标出开环极点0、-1、-2
  • 中间结果：实轴根轨迹段为负无穷到负二与负一到零两段
  • 卡点：归一化后特征方程用根轨迹增益，别与原增益混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制三条分支的常规根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求分离点并筛选有效解
本卷实例
  • 关键一步：由幅值条件整理出根轨迹增益的显式表达式后求导
  • 中间结果：分离点方程的解中只有落在实轴根轨迹段内的有效
  • 卡点：另一个根在实轴段外，必须舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求分离点并筛选有效解
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界增益
本卷实例
  • 关键一步：把纯虚变量代入特征方程，或令劳斯表首列为零
  • 中间结果：临界根轨迹增益由辅助方程给出的非零纯虚根确定
  • 卡点：辅助方程的零频解不对应穿越，要取非零频率解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹确定系统稳定的增益范围
本卷实例
  • 关键一步：把临界根轨迹增益按二倍关系换算回原开环增益
  • 中间结果：根轨迹位于左半平面对应稳定区间
  • 卡点：题给的是 K 而特征方程用的是根轨迹增益，需换算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹确定系统稳定的增益范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

4四、方框图双输入化简#

思路
  • 分别令扰动为零求 C/R、令参考输入为零求 C/N，用引出点与比较点等效移动逐层化简
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 串联、并联与反馈等效求闭环传函
本卷实例
  • 关键一步：求 C/R 时令扰动为零，按单回路反馈公式合并
  • 中间结果：前向通道与反馈通道相乘构成回路增益
  • 卡点：方框图未读图，回路接法与反馈极性需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过串联、并联与反馈等效求闭环传函
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
比较点与引出点的移动 结构图与方框图
本卷考法
