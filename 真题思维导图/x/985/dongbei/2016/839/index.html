一简答：线性系统与反馈#

思路
  • 3 小问：如何判断线性系统、线性与非线性系统的区别、反馈控制系统的本质要求
非线性系统的特点 非线性系统
本卷考法
  • 如何判断一个系统是否为线性系统
  • 列举线性系统与非线性系统的主要区别
本卷实例
  • 关键一步：以齐次性与叠加性作为线性系统的判别条件
  • 关键一步：从数学模型、叠加性、稳定性与初值关系对比区别
  • 中间结果：线性系统运动方程可用线性微分方程描述
  • 卡点：只答定义不列区别，第二问丢分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过如何判断一个系统是否为线性系统
  • 本卷考过列举线性系统与非线性系统的主要区别
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 说明反馈控制系统的本质要求
本卷实例
  • 关键一步：反馈是把输出引回输入端与给定比较，用偏差消除偏差
  • 中间结果：从稳定性、准确性、快速性衡量，稳定性是首要
  • 卡点：把本质要求只答成稳定性一项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过说明反馈控制系统的本质要求
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

二结构图求四路传函#

思路
  • 同一结构图，分别令扰动或输入为零，用梅森公式求输出对给定、输出对扰动、误差对给定、误差对扰动四路传函
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求多输入多输出的传递函数
本卷实例
  • 关键一步：分别令扰动为零与给定为零，逐路找前向通路与特征余子式
  • 中间结果：四路传函的特征多项式相同，前向通路各不相同
  • 卡点：求某一路传函时忘记把另一输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求多输入多输出的传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求扰动作用下的输出传递函数
本卷实例
  • 关键一步：扰动到输出没有前向环节，靠反馈回路建立传递关系
  • 中间结果：扰动传函分母仍是同一特征多项式
  • 卡点：把扰动传函误当成 1 除以 1 加 GH，图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求扰动作用下的输出传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

误差定义与误差传递函数 稳态误差
本卷考法
  • 写出误差对给定与误差对扰动的传递函数
本卷实例
  • 关键一步：按误差定义列误差与输出关系，再代入输出表达式消去输出
  • 中间结果：误差传函分子含 1 加反馈通道乘积的那一项
  • 卡点：非单位反馈时误差传函漏掉反馈环节 H
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写出误差对给定与误差对扰动的传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

三一阶响应反求与二阶指标#

思路
  • 由一阶阶跃响应表达式反求 W1(s)，再求系统在给定阶跃输入下的稳态输出、超调量、调节时间与稳态误差
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由一阶阶跃响应表达式反求环节传递函数
本卷实例
  • 关键一步：由响应的稳态值定增益，由指数项的衰减快慢定时间常数
  • 中间结果：环节传函由稳态值与时间常数两个参数确定
  • 卡点：把阶跃响应的稳态值直接当增益，漏掉输入幅值折算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由一阶阶跃响应表达式反求环节传递函数
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求系统的超调量与调节时间
本卷实例
  • 关键一步：先写出闭环传函并与二阶标准形对比求 ξ 与 ωn
  • 关键一步：再代入超调量与调节时间的公式
  • 中间结果：阻尼比与自然频率由闭环特征方程的系数决定
  • 卡点：调节时间两种误差带的系数搞混，图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求系统的超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求给定输入下的稳态输出与稳态误差
本卷实例
  • 关键一步：先用劳斯判据确认闭环稳定，再对误差取终值
  • 中间结果：稳态输出由闭环传函零频值决定
  • 卡点：未判稳就套终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求给定输入下的稳态输出与稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

四根轨迹与稳定范围#

思路
  • 开环由两个二阶环节组成，先按法则画根轨迹并标虚轴交点与分离点，再由虚轴交点定使系统稳定的增益范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制四分式开环传递函数的闭环根轨迹
本卷实例
  • 关键一步：先求开环极点并确定渐近线条数与夹角
  • 关键一步：分离点由 dK/ds 为零的条件求并筛选
  • 中间结果：四个开环极点无零点，渐近线与实轴交于重极处
  • 卡点：渐近线夹角公式中把 2k 加 1 写成 2k
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制四分式开环传递函数的闭环根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及系统稳定的增益范围
本卷实例
  • 关键一步：把 s 等于 jω 代入闭环特征方程，实部与虚部分别为零
  • 关键一步：两式联立解出临界频率与临界增益
  • 中间结果：临界增益对应一对纯虚根，稳定范围由交点位置划界
  • 卡点：只代一个 ω 就下结论，漏掉另一组解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及系统稳定的增益范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
分离点与会合点 根轨迹法
本卷考法
  • 确定根轨迹的分离点位置
本卷实例
  • 关键一步：把特征方程化成增益的显式表达式后令其导数为零
  • 中间结果：分离点须位于实轴根轨迹段上才有效
  • 卡点：把不在根轨迹上的根也保留下来
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过确定根轨迹的分离点位置
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

五由开环Bode图反求与校正#

思路
  • 由校正前后两条对数幅频特性曲线反写各自开环传函，求校正后剪切频率与相位裕度，再评校正装置对性能的影响
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由校正前后对数幅频特性曲线反求两个开环传递函数
本卷实例
  • 关键一步：由低频段斜率与高度定型别与增益，再按各段转折频率写环节
  • 中间结果：两曲线逐段斜率变化对应串联校正装置的零极点
  • 卡点：把延长线交点当增益而未折算型别，图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K

稳定裕度 频域分析
本卷考法
  • 求校正后系统的剪切频率与相位裕度
本卷实例
  • 关键一步：由幅值条件解剪切频率，再代入相频求相角裕度
  • 中间结果：剪切频率落在中频段，由该段斜率与高度定位
  • 卡点：剪切频率与相位穿越频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求校正后系统的剪切频率与相位裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

思路

描述函数法基础 非线性系统
本卷考法
  • 写出继电型非线性环节的描述函数与负倒特性
本卷实例
  • 关键一步：先认非线性环节类型再套对应描述函数公式
  • 关键一步：负倒特性按输入幅值 A 的变化在复平面定位
  • 中间结果：继电型描述函数只含 A，负倒特性落在负实轴
  • 卡点：画的是描述函数而不是负倒描述函数，图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法

  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

用描述函数法分析自振 非线性系统
本卷考法
  • 判断有无稳定自振点并确定自振频率与振幅
本卷实例
  • 关键一步：令 1 加 N(A) 乘 G(jω) 为零，实部与虚部分别为零
  • 关键一步：先由虚部方程解频率，再代回解幅值，并判交点稳定性
  • 中间结果：交点处沿 A 增大方向是否进入稳定区决定自振

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过判断有无稳定自振点并确定自振频率与振幅

  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响

  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率

七离散系统脉冲传函与稳定性#

思路
  • 采样周期已知，先由连续环节与零阶保持器求开环脉冲传递函数，再求闭环极点并判稳
脉冲传递函数 离散控制系统
本卷考法
  • 求含零阶保持器的开环脉冲传递函数
本卷实例
  • 关键一步：把零阶保持器与连续环节的乘积部分分式展开后逐项查表
  • 中间结果：1 除以 s 平方对应 Tz 除以 z 减 1 的平方
  • 卡点：零阶保持器对应的 1 减 z 的负一次幂因子写错，图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过求含零阶保持器的开环脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)
