一简答：自动控制与闭环组成10 分#

思路
  • 2 小问：自动控制的定义、闭环系统的组成环节并画出结构图
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 说明自动控制的定义
  • 列出闭环系统的组成环节并画出结构图
本卷实例
  • 关键一步：先答自动控制的定义，再按给定、比较、放大、执行、对象、测量、校正列环节
  • 关键一步：画结构图时把输出经测量元件反馈回比较点
  • 中间结果：闭环结构由给定、测量、比较、放大、执行与校正等环节组成
  • 卡点：只答定义不画结构图，或组成环节漏项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过说明自动控制的定义
  • 本卷考过列出闭环系统的组成环节并画出结构图
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

二结构图求闭环传函#

思路
  • 结构图用等效化简或梅森公式求输出对参考输入的传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求闭环传递函数
本卷实例
  • 关键一步：找全部前向通路与独立回路，判接触关系后写特征式
  • 中间结果：不接触回路要单独计入特征式的乘积项
  • 卡点：不接触回路找漏或重复计数，图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 用串联、并联与反馈等效化简结构图
本卷实例
  • 关键一步：从最内环开始逐层化简，再做串并联合并
  • 中间结果：比较点与引出点移动时增益要同步补偿
  • 卡点：移动方向与乘除关系搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过用串联、并联与反馈等效化简结构图
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

三由稳态误差与主导极点反求传函#

思路
  • 三阶无开环零点，由斜坡稳态误差与主导极点定开环传函，再求动态指标
由响应曲线反求传递函数 传递函数
本卷考法
  • 由稳态误差与主导极点要求反求开环传递函数
本卷实例
  • 关键一步：按 I 型无零点系统设开环形式，再由主导极点列方程
  • 中间结果：开环增益与分母系数由稳态误差和极点同时约束
  • 卡点：未先判稳就套用极点条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由稳态误差与主导极点要求反求开环传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡下的稳态误差反求开环增益与型别
本卷实例
  • 关键一步：用终值定理把斜坡误差写成增益与系数的关系式
  • 中间结果：斜坡误差为有限非零值说明系统为 I 型
  • 卡点：未判稳就用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位斜坡下的稳态误差反求开环增益与型别
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由闭环主导极点求超调量、调节时间与峰值时间
本卷实例
  • 关键一步：由主导极点实部虚部反推阻尼比与自然频率
  • 中间结果：三个动态指标只由阻尼比与自然频率决定
  • 卡点：峰值时间与调节时间用错误差带
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由闭环主导极点求超调量、调节时间与峰值时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

四根轨迹为圆的证明#

思路
  • 绘制开环含右半平面极点的根轨迹，由幅值条件推证其为圆并求衰减振荡的 K 范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制含右半平面极点的根轨迹
本卷实例
  • 关键一步：先判实轴段与渐近线，再求分离点与虚轴交点
  • 中间结果：一个极点在正实轴、零点在负实轴，实轴段分布特殊
  • 卡点：实轴段判据中零极点个数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制含右半平面极点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹证明其为圆并求衰减振荡的 K 范围
本卷实例
  • 关键一步：设闭环复根由韦达定理消去实部，整理成圆的方程
  • 中间结果：共轭复根条件对应圆心在负实轴的圆
  • 卡点：证圆时未保留复根的虚部条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹证明其为圆并求衰减振荡的 K 范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

五由Bode图反求与相角裕度#

思路
  • 由渐进对数幅频特性反求开环传函，再在截止频率处求相角裕度
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环对数幅频特性反求传递函数
本卷实例
  • 关键一步：由低频段斜率与高度定型别与增益，再按转折频率写环节
  • 中间结果：各段斜率变化一次对应一个一阶环节
  • 卡点：延长线交点未折算型别就当增益，图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环对数幅频特性反求传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 求给定系统的相角裕度
本卷实例
  • 关键一步：先由幅频条件求截止频率，再代入相频求相角裕度
  • 中间结果：相角裕度等于一百八十度加截止频率处的相角
  • 卡点：截止频率与相位穿越频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求给定系统的相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式

六串联校正参数设计#

思路
  • 校正环节为 K(s+a)/s，按主导极点实部等于开环零点与给定阻尼比求参数
校正的基本概念与性能指标 系统校正
本卷考法
  • 按给定性能指标设计串联校正环节的参数
本卷实例
  • 关键一步：先由校正后开环写闭环特征方程，再代入期望极点
  • 中间结果：校正环节的零点与积分环节改变开环型别
  • 卡点：只盯相角裕度而忽略带宽要求
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过按给定性能指标设计串联校正环节的参数
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由阻尼比与主导极点约束反求校正参数
本卷实例
  • 关键一步：把给定阻尼比写成期望极点实部与虚部的关系
  • 中间结果：期望极点可由阻尼比与自然频率两个参数描述
  • 卡点：只满足单项指标就下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
