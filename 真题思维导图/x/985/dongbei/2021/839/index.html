1简答：校正方式与减小误差10 分#

思路
  • 纯概念题，两种问法：按「校正装置与系统不可变部分的连接方式」分类，以及「减小稳态误差的方法」
校正的基本概念与性能指标 系统校正
本卷考法
  • 按校正装置与系统不可变部分的连接方式给校正分类并说明特点
本卷实例
  • 关键一步：按连接方式分串联、反馈、前馈（复合）三类，逐条写特点
  • 关键一步：串联加在误差之后被控对象之前；反馈包围局部环节；前馈按扰动或给定直接补偿
  • 中间结果：特点：串联设计方便、反馈抑制参数波动、前馈按开环补偿、复合兼收优点
  • 卡点：只答串联校正，漏掉反馈与复合，直接丢一半分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过按校正装置与系统不可变部分的连接方式给校正分类并说明特点
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 列举减小或消除稳态误差的方法
本卷实例
  • 关键一步：三条主线：提高开环增益、增加积分环节提高型别、引入前馈或复合控制
  • 关键一步：每条都补一句代价：提高增益伤稳定性、加积分增大超调、前馈不改变稳定性
  • 中间结果：扰动误差要靠提高扰动作用点之前那段前向通道的增益
  • 卡点：只列措施不谈代价，答案不完整
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过列举减小或消除稳态误差的方法
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

2由运动方程组建模20 分#

思路

机械系统建模 建模与机电系统
本卷考法
  • 由描述系统的运动方程组建立动态结构图并求传递函数
本卷实例
  • 关键一步：先把每个微分方程单独取拉氏变换，写成「输出 = 增益 × 输入」的环节形式
  • 关键一步：再按方程组里变量之间的传递关系把环节连起来，不要急着整体消元
  • 中间结果：方程组含 X₁~X₅ 多个中间变量，全部消掉后阶次才对

  • 分别写出质量、阻尼、弹簧对应的力

  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错

串联、并联与反馈等效 结构图与方框图
本卷考法
  • 用等效变换法求 C(s)/R(s)
本卷实例
  • 关键一步：把每个方程看成环节，按 X₁~X₅ 传递关系连成结构图
  • 关键一步：再用梅森公式找前向通路与独立回路，并判接触关系
  • 中间结果：回路为 L₁=-1/(Ts)、L₂=-K₀K₁/(Ts²(s+1))，无互不接触回路
  • 卡点：回路增益的负号别丢，两回路接触则不计高阶项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过用等效变换法求 C(s)/R(s)
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过把负反馈的分母写成 1-GH
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

4根轨迹与性能变化趋势20 分#

思路

根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制 k 从 0→∞ 的闭环根轨迹图并标注关键点
本卷实例
  • 关键一步：先把开环传函化成标准形式，把可变参数提到分子，根轨迹增益里含 αk
  • 关键一步：零点 (0.5s−1)² 与极点 (2s−1) 都在右半平面，实轴段判据要重新推
  • 中间结果：标准形 k*(s−2)²/((s+2)(s−0.5))，实轴根轨迹段为 [−2, 0.5]
  • 卡点：把 (0.5s−1) 当成左半平面零点，根轨迹方向整条错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制 k 从 0→∞ 的闭环根轨迹图并标注关键点
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
