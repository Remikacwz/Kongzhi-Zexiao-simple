一简答：线性与非线性系统10 分#

思路
  • 纯概念题，先给线性与非线性的定义与判别方法，再从多个角度逐条列本质区别
非线性系统的特点 非线性系统
本卷考法
  • 如何区分线性系统与非线性系统
  • 列举线性系统与非线性系统的主要区别
本卷实例
  • 关键一步：以齐次性与叠加性作为线性系统的判别条件
  • 关键一步：从数学模型、叠加性、稳定性与初值关系三个方面对比区别
  • 中间结果：线性系统运动方程可用线性微分方程描述
  • 中间结果：非线性系统的运动与起始偏离大小有关
  • 卡点：只答定义却不列区别，第二问丢分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过如何区分线性系统与非线性系统
  • 本卷考过列举线性系统与非线性系统的主要区别
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定

二由微分方程组建结构图求传函20 分#

思路
  • 方程组逐个取拉氏变换写成环节，按变量传递关系连成结构图，再用梅森公式分别求输入与扰动两路传函
梅森增益公式与信号流图 传递函数
本卷考法
  • 由微分方程组先画结构图再用梅森公式求传递函数
本卷实例
  • 关键一步：先把每个方程写成输出等于增益乘输入的环节形式
  • 关键一步：再按中间变量的传递关系连结构图，找前向通路与回路
  • 中间结果：结构图含两条前向通路，各回路均互相接触
  • 卡点：中间变量漏消一个，分母阶次就少 1
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由微分方程组先画结构图再用梅森公式求传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求输入与扰动分别作用下的输出传递函数
本卷实例
  • 关键一步：求扰动传函时把参考输入置零，两路分别用梅森公式
  • 关键一步：两路共用同一特征多项式，前向通路不同
  • 中间结果：扰动到输出的前向通路与输入到输出不同
  • 卡点：求对扰动的传函时没把参考输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求输入与扰动分别作用下的输出传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

三结构图与阶跃响应反求参数20 分#

思路
  • 先由结构图写闭环传函并与二阶标准形对比，再由阶跃响应曲线读超调量与峰值时间反求三个参数
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应曲线反求系统参数 a、b、K
本卷实例
  • 关键一步：由曲线读出超调量与峰值时间，联立 ξ 与 ωn 两个方程
  • 关键一步：再把闭环传函与二阶标准形对比解出其余参数
  • 中间结果：闭环增益含 1/b 因子，读稳态值时要先折算
  • 卡点：结构图与响应曲线均为扫描图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应曲线反求系统参数 a、b、K
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传递函数化成二阶标准形式求 ξ 与 ωn
本卷实例
  • 关键一步：把分母写成 s² 加 2ξωn s 加 ωn² 后系数一一对应
  • 中间结果：一次项系数对应 2ξωn，常数项对应 ωn²
  • 卡点：未把 s² 项系数归一化就直接读 ξ
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传递函数化成二阶标准形式求 ξ 与 ωn
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过化为标准形式时忘记把 s² 项系数归一化
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

四根轨迹圆与最小阻尼比20 分#

思路
  • 开环零点数等于极点数，根轨迹是一条圆；最小阻尼比对应从原点作圆的切线，再由幅值条件定 Kg 与性能趋势
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制 Kg(s+2)(s+3)/(s(s+1)) 的闭环根轨迹
本卷实例
  • 关键一步：实轴根轨迹段按右侧零极点个数为奇数判断
  • 关键一步：分离点由 1/d 加 1/(d+1) 等于 1/(d+2) 加 1/(d+3) 求
  • 中间结果：零点数等于极点数，无渐近线，根轨迹为圆
  • 卡点：实轴段零极点个数算错会画错整条轨迹
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制 Kg(s+2)(s+3)/(s(s+1)) 的闭环根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 求最小阻尼比与对应闭环极点
  • 分析 Kg 变化对系统性能的影响
本卷实例
  • 关键一步：作原点向根轨迹圆的切线，切点即最小阻尼比处
  • 关键一步：由幅值条件求该点 Kg，再分段讨论动态与稳态性能趋势
  • 中间结果：切点的实部与虚部同时决定 ξ 与闭环极点
  • 中间结果：Kg 增大系统保持稳定，稳态误差减小
  • 卡点：把最小阻尼比点误当成实轴分离点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过求最小阻尼比与对应闭环极点
  • 本卷考过分析 Kg 变化对系统性能的影响
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

五非最小相位系统奈氏判据20 分#

思路
  • 开环含右半平面零点与右半平面极点，先画幅相曲线，再数 P 与包围圈数用奈氏判据判稳
频率特性的物理意义与求法 频域分析
本卷考法
  • 绘制给定开环传递函数的幅相频率特性曲线
本卷实例
  • 关键一步：由零极点分布定起点终点的幅值与相角
  • 关键一步：再令虚部为零求曲线与负实轴的交点
  • 中间结果：开环零点在右半平面，相角贡献与左半平面反号
  • 卡点：把右半平面零点当左半平面算相角，曲线形状全错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过绘制给定开环传递函数的幅相频率特性曲线
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数 P，再数曲线包围临界点的净圈数 N
  • 关键一步：按 Z 等于 P 减 2N 判断闭环右半平面极点数
  • 中间结果：开环有一个右半平面极点，P 为 1
  • 卡点：P 数错结论就反，包围圈数与方向不能搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过没有先数开环右半平面极点数 P
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

六反馈校正的误差与裕度20 分#

思路
  • 由图读开环增益与转折频率；第 1 问求校正前速度误差系数得稳态误差，第 2 问求校正后开环传函，第 3 问读截止频率求相位裕度
反馈校正与复合控制 系统校正
本卷考法
  • 由反馈校正系统方框图与对数幅频特性求校正后开环传函
本卷实例
  • 关键一步：把小闭环等效后与大环串联，按等效变换求校正后开环传函
  • 中间结果：校正后低频段斜率为负 20dB/dec，含三个转折频率
  • 卡点：反馈校正与串联校正的等效关系别混，图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过由反馈校正系统方框图与对数幅频特性求校正后开环传函
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求校正前系统单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：由对数幅频低频段高度定开环增益，再求速度误差系数
  • 关键一步：单位斜坡输入下稳态误差等于速度误差系数倒数
  • 中间结果：低频段延长线与零分贝线交点的频率等于开环增益
  • 卡点：把开环增益直接当成速度误差系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差

本卷考法
