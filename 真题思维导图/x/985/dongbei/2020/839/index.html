一简答：闭环控制与稳定性10 分#

思路
  • 2 小问：闭环控制的定义与特点、线性系统稳定性的定义与充要条件
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 说明闭环控制的定义与主要特点
本卷实例
  • 关键一步：从输出引回输入端与给定比较，用偏差进行控制
  • 中间结果：闭环具有抑制内外部扰动的能力
  • 卡点：把闭环的特点只答成结构复杂
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过说明闭环控制的定义与主要特点
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
零极点分布与响应模态 传递函数
本卷考法
  • 说明线性系统稳定性的定义与充要条件
本卷实例
  • 关键一步：用扰动消失后能否回到原平衡态定义稳定性
  • 中间结果：充要条件是特征根全具有负实部
  • 卡点：把临界稳定也算作稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过说明线性系统稳定性的定义与充要条件
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤

  • 按 KVL/KCL 或牛顿第二定律列出微分方程组

  • 取拉氏变换并整理成 C(s)/R(s)
通用考法

  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由特征根判断系统阻尼状态
本卷实例
  • 关键一步：比较特征根实部与虚部判断过阻尼或欠阻尼
  • 中间结果：一对共轭复根对应欠阻尼振荡
  • 卡点：未归一化就直接读阻尼比
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由特征根判断系统阻尼状态
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求单位阶跃响应的超调量与调整时间
本卷实例
  • 关键一步：由阻尼比与自然频率代入动态指标公式
  • 中间结果：调整时间按百分之五误差带计算
  • 卡点：两种误差带的调节时间系数搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求单位阶跃响应的超调量与调整时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

四重复极点与参数根轨迹20 分#

思路
  • 由开环极点有负实重根确定参数，再绘根轨迹判稳并判断给定点是否在根轨迹上
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 判断给定点是否在根轨迹上
本卷实例
  • 关键一步：把给定点代入相角条件检验，再用幅值条件求对应参数
  • 中间结果：相角条件满足后该点才位于根轨迹
  • 卡点：用幅值条件判点而搞混两个条件的用途
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过判断给定点是否在根轨迹上
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制以增益为参变量的根轨迹
本卷实例
  • 关键一步：先定实轴段与渐近线，再求分离点与出射角
  • 中间结果：开环极点分布决定根轨迹分支的起点与终点
  • 卡点：零极点个数算错使实轴段判断出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制以增益为参变量的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点判断稳定性
本卷实例
  • 关键一步：把纯虚根代入特征方程分离实部与虚部
  • 中间结果：交点对应的增益是系统稳定的边界值
  • 卡点：只取一组交点而漏掉另一组
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹与虚轴交点判断稳定性
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

五由Bode图反求与最大相角裕度20 分#

思路
  • 由渐进对数幅频特性求开环传函与相角裕度，再在固定转折频率下求最大相角裕度
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由渐进对数幅频特性反求开环传递函数
本卷实例
  • 关键一步：由低频段延长线定增益，再按各段斜率变化写环节
  • 中间结果：转折频率处斜率改变量对应零极点重数
  • 卡点：把延长线交点当增益而未折算型别，图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由渐进对数幅频特性反求开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
