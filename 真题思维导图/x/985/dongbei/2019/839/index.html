一简答：线性判定与校正装置10 分#

思路
  • 2 小问：判断线性系统与线性系统稳定的充要条件、校正装置的定义与作用
非线性系统的特点 非线性系统
本卷考法
  • 判断系统是否为线性系统并说明依据
本卷实例
  • 关键一步：从叠加性与齐次性两方面判断，并检查是否含非线性环节
  • 中间结果：含死区、饱和或继电特性时按非线性处理
  • 卡点：把含有非线性环节的系统仍当线性系统
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过判断系统是否为线性系统并说明依据
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
校正的基本概念与性能指标 系统校正
本卷考法
  • 说明校正装置的定义与作用
本卷实例
  • 关键一步：指出校正装置用来改变系统整体特性以满足指标
  • 中间结果：校正装置按连接方式分串联与反馈两类
  • 卡点：只答定义不答对性能指标的作用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过说明校正装置的定义与作用
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求
公式
零极点分布与响应模态 传递函数
本卷考法
  • 说明线性系统稳定的充要条件
本卷实例
  • 关键一步：由传递函数极点位置判断响应是收敛还是发散
  • 中间结果：极点全在左半平面时系统稳定
  • 卡点：把极点落在虚轴上也算作稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过说明线性系统稳定的充要条件
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

二结构图求闭环传函#

思路
  • 由结构图或信号流图求闭环传递函数，逐年题头丢失已据原卷补出
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求闭环传递函数
本卷实例
  • 关键一步：找全部独立回路与不接触回路组合，再写特征式
  • 中间结果：前向通道增益与余子式分别相乘后相加
  • 卡点：回路极性符号写错导致特征式出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 用等效化简法求闭环传递函数
本卷实例
  • 关键一步：从内环向外逐层合并，反馈支路作除法处理
  • 中间结果：负反馈分母为一加回路传函
  • 卡点：负反馈分母写成一减回路传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过用等效化简法求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

三由脉冲响应反求传函与阶跃响应20 分#

思路
  • 由单位脉冲响应反求闭环传函，再求单位阶跃输入下的输出响应
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位脉冲响应反求闭环传递函数
本卷实例
  • 关键一步：对脉冲响应作拉氏变换后再通分合并
  • 中间结果：分母给出系统极点，分子由留数确定
  • 卡点：未判断阶数就直接套二阶标准式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位脉冲响应反求闭环传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 求单位阶跃输入下的系统响应
本卷实例
  • 关键一步：把输出写成部分分式后逐项作拉氏反变换
  • 中间结果：两个实极点对应两个指数项之和
  • 卡点：把过阻尼系统仍按欠阻尼指标算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过求单位阶跃输入下的系统响应
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

四以T为参变量的根轨迹20 分#

思路
  • 开环含参数 T，整理成参数根轨迹，并求临界稳定与临界阻尼时的 T
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以时间常数 T 为参变量绘制参数根轨迹
本卷实例
  • 关键一步：把特征方程整理成一加 T 乘等效开环为零的标准形式
  • 中间结果：等效开环的零极点由原系统与参数项共同决定
  • 卡点：参变量未完整提到分子位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以时间常数 T 为参变量绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点并确定临界阻尼参数
本卷实例
  • 关键一步：对参变量求导并令其为零，再筛选落在根轨迹上的解
  • 中间结果：分离点处系统处于临界阻尼
  • 卡点：求出方程的根后不筛选就保留
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点并确定临界阻尼参数
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界稳定参数
本卷实例
  • 关键一步：把纯虚根代入特征方程，实部虚部分别为零
  • 中间结果：虚轴交点给出临界稳定时的参数值
  • 卡点：只代一个频率值就下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界稳定参数
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

五奈氏判据判稳#

思路
  • 由结构图求开环传函，再作奈氏曲线判断闭环稳定性
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据判断闭环系统稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数，再判曲线对临界点的包围圈数
  • 中间结果：含积分环节时需补画无穷大半径圆弧
  • 卡点：未补画圆弧导致包围圈数算错，图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据判断闭环系统稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求开环频率特性的幅频与相频表达式
本卷实例
  • 关键一步：把开环传函中的 s 换成 jω 后分别取模与取相角
  • 中间结果：幅值为各环节幅值之积、相角为各环节相角之和
  • 卡点：分母复数取模时漏掉平方和开方
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求开环频率特性的幅频与相频表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

六二阶系统校正参数#

思路

超前校正 系统校正
本卷考法
  • 比较两种校正方案对阻尼比的影响
本卷实例

思路

描述函数法基础 非线性系统
本卷考法
  • 求给定描述函数的负倒特性并画其轨迹
本卷实例
  • 关键一步：把描述函数取倒数并分离实部与虚部再化简
  • 中间结果：负倒特性是复平面上随幅值变化的一段曲线
  • 卡点：把描述函数当成频率的函数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式

  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过求给定描述函数的负倒特性并画其轨迹
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

本卷考法
  • 由给定闭环脉冲传递函数求输出响应
本卷实例
  • 关键一步：把输入 z 变换与脉冲传函相乘得输出 z 变换
  • 中间结果：输出序列由 z 反变换逐项写出

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 由连续传递函数求脉冲传递函数
常见易错
