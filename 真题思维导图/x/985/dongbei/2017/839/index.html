一简答：开闭环与采样定理10 分#

思路
  • 2 小问：开环与闭环控制系统的差别及适用对象、采样定理
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 比较开环与闭环控制系统的差别并说明适用对象
本卷实例
  • 关键一步：从有无反馈、抗扰能力、控制精度与结构复杂度逐项对比
  • 中间结果：扰动大、精度要求高时用闭环，简单场合用开环
  • 卡点：只答差别不答适用对象，第二问答不全
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过比较开环与闭环控制系统的差别并说明适用对象
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
采样过程与香农采样定理 离散控制系统
本卷考法
  • 简述采样定理
本卷实例
  • 关键一步：写出采样角频率须大于信号最高角频率的两倍
  • 中间结果：不满足两倍关系时频谱发生混叠
  • 卡点：把大于两倍写成相等，漏掉信号最高频率这一前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过简述采样定理
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

二结构图求给定与扰动总输出20 分#

思路
  • 结构框图给定，求输入与扰动同时作用下的总输出，分别求两路传函后叠加
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求给定与扰动同时作用下的总输出
本卷实例
  • 关键一步：分别令输入或扰动为零求两路传函再叠加
  • 关键一步：叠加前先确认系统为线性系统
  • 中间结果：两路传函共用同一特征多项式
  • 卡点：未把另一输入置零就直接叠加，图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求给定与扰动同时作用下的总输出
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求闭环传递函数
本卷实例
  • 关键一步：找全部前向通路与回路，判接触关系后写特征式
  • 中间结果：回路增益的负号不能丢
  • 卡点：不接触回路找漏或重复计数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

三高阶系统近似与动态指标20 分#

思路
  • 闭环为四阶，用近似方法按主导极点降为二阶，再求最大超调量、调节时间与峰值时间
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 用近似方法处理高阶系统并估算动态指标
本卷实例
  • 关键一步：比较各极点与零点到虚轴的距离，把可对消的零极点或远离虚轴的极点忽略
  • 关键一步：降为二阶后再套动态指标公式
  • 中间结果：闭环传函有一对靠近的零极点可近似对消
  • 卡点：忽略零点对超调量的放大作用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过用近似方法处理高阶系统并估算动态指标
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求最大超调量、调节时间与峰值时间
本卷实例
  • 关键一步：先由降阶后的二阶系统确定阻尼比与自然频率
  • 关键一步：再代入三个动态性能指标公式
  • 中间结果：三个指标都只由阻尼比与自然频率决定
  • 卡点：峰值时间与上升时间混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求最大超调量、调节时间与峰值时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

四微分负反馈广义根轨迹20 分#

思路
  • 以微分反馈系数为参变量作参数根轨迹，再由根轨迹说明微分反馈的作用与衰减振荡时的取值范围
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以微分反馈系数为参变量绘制系统的参数根轨迹
本卷实例
  • 关键一步：把特征方程整理成 1 加 τ 乘等效开环传函为零的根轨迹标准形式
  • 关键一步：再按 180 度根轨迹法则作图
  • 中间结果：等效开环的零极点由原系统与反馈通道共同决定
  • 卡点：整理时未把参变量完整提到分子，图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以微分反馈系数为参变量绘制系统的参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 说明微分反馈的作用及衰减振荡时的取值范围
本卷实例
  • 关键一步：由根轨迹走向看参变量增大时闭环极点实部与虚部的变化
  • 关键一步：用共轭复根条件确定取值范围
  • 中间结果：由等阻尼线或复根判据求参变量临界值
  • 卡点：把等阻尼线画成垂直线，图需回原卷核对图

  • 由极点位置估算动态性能

  • 由极点位置估指标时忽略零点的作用

五奈氏判据与幅值裕度20 分#

思路
  • 开环为积分环节串联两个惯性环节，用奈氏判据求稳定时增益范围，再在给定参数下求幅值裕度
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈氏判据求系统稳定时开环增益的取值范围
本卷实例
  • 关键一步：开环含一个积分环节，先补画无穷大半径圆弧
  • 关键一步：求曲线与负实轴交点，令交点位于临界点右侧得稳定条件
  • 中间结果：相角为负 180 度处对应幅值须小于 1
  • 卡点：含积分环节未补画圆弧，包围圈数就算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈氏判据求系统稳定时开环增益的取值范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
稳定裕度 频域分析
本卷考法
  • 确定给定参数下系统的幅值裕度
本卷实例
  • 关键一步：先求相位穿越频率，再代入幅频求该处幅值的倒数
  • 中间结果：幅值裕度以分贝表示时由该处幅值取对数再取负
  • 卡点：幅值裕度该取倒数却没有取，结论就反了
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过确定给定参数下系统的幅值裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

六最小相位校正环节反求20 分#

思路
  • 由最小相位校正环节的对数幅频特性反求其传函，再选可实现该特性的 RC 网络并写出时间常数与放大系数
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频特性曲线反求最小相位校正环节的传递函数
本卷实例
  • 关键一步：由低频段斜率与高度定增益，再按各段转折频率写零极点
  • 关键一步：最小相位系统的幅频可唯一确定相频与传函
  • 中间结果：转折频率与斜率变化一一对应
  • 卡点：把延长线交点当增益而未折算型别，图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频特性曲线反求最小相位校正环节的传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

  • 中间结果：二阶离散系统可用朱利判据或 w 变换判稳

离散系统的稳态误差 离散控制系统
本卷考法
  • 求单位斜坡输入下离散系统的稳态误差
本卷实例
  • 关键一步：先判稳，再用 z 域终值定理求误差极限
  • 关键一步：斜坡输入对应速度误差系数，由开环脉冲传函在 z 等于 1 处的值求
  • 中间结果：稳态误差与开环脉冲传函的型别和增益有关

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 型别由 G(z)H(z) 中 z=1 处极点的重数确定
  • 用终值定理求稳态误差，前提是系统稳定
  • 采样周期也影响稳态误差大小
步骤
  • 求误差脉冲传递函数
  • 数出 z=1 处极点重数确定型别
  • 查表或用终值定理求稳态误差
  • 分析采样周期变化对误差的影响

  • 求离散系统在典型输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 分析采样周期对稳态精度的影响

  • 未判稳就用终值定理
