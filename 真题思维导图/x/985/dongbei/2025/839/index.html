3含右半平面零点的根轨迹#

思路
  • Wk=k(1-s)/(s(s+2)) 的零点在右半平面，根轨迹整体右偏；欠阻尼对应闭环复极点，重根对应分离点，纯虚根对应虚轴交点
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制 k 从 0→∞ 的根轨迹并标注关键点
本卷实例
  • 关键一步：由开环零点极点定实轴段，求分离点、渐近线与虚轴交点
  • 中间结果：含右半平面零点，根轨迹为以零点为圆心的圆弧
  • 卡点：实轴段要按零度根轨迹判据确定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法

  • 按法则绘制根轨迹草图

思路

开环对数频率特性的绘制 频域分析
本卷考法

本卷实例

  • 中间结果：相位截止频率由三个惯性环节相角之和等于负九十度求得
