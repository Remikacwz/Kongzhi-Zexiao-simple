一一、由阶跃响应判反馈极性#

思路
  • 由两种单位阶跃响应形态反推两处反馈极性：输出收敛对应负反馈，振荡发散对应正反馈
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由输出的收敛或发散反判两处反馈的极性
  • 按两种接法分别写出闭环传递函数与特征方程
本卷实例
  • 关键一步：对主、副反馈的每种极性组合列出闭环特征方程，再比较特征根实部符号
  • 中间结果：均为负反馈时特征式各项系数同号，二阶系统稳定
  • 中间结果：任一反馈极性反转会改变特征式一次项符号
  • 卡点：只凭输出曲线形状下结论，未回代特征方程验证极性
  • 卡点：结构图与响应图均以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由输出的收敛或发散反判两处反馈的极性
  • 本卷考过按两种接法分别写出闭环传递函数与特征方程
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

二二、输入与扰动稳态误差#

思路
  • 由结构图列闭环误差传函，用终值定理分别求输入与扰动稳态误差，再选增益使两者同时较小
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 单位阶跃输入下由误差传函求稳态误差
本卷实例
  • 关键一步：先判闭环稳定，再由误差传函用终值定理求 s 趋于零的极限
  • 中间结果：误差传函分母与闭环特征多项式相同，分子由回路结构决定
  • 卡点：未先判稳就套终值定理，算出的稳态误差无意义
  • 卡点：回路接法以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过单位阶跃输入下由误差传函求稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动作用下的稳态误差
本卷实例
  • 关键一步：求扰动误差时把参考输入置零，单独列扰动到误差的通道
  • 中间结果：扰动误差传函的分子由反馈通道的传递函数构成
  • 卡点：把扰动误差直接当作总误差，遗漏输入引起的分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求扰动作用下的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 调整两个增益使输入与扰动稳态误差同时较小
本卷实例
  • 关键一步：把两项误差的绝对值之和写成两个增益的函数，再求偏导为零的驻点
  • 中间结果：驻点解出后要回代稳定条件筛选，剔除使系统不稳定的组合
  • 卡点：只求驻点不做稳定性筛选，选到不可用的增益组合
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过调整两个增益使输入与扰动稳态误差同时较小
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

三三、采样系统稳定采样周期#

思路
  • 先由超调量与调节时间反求二阶参数，再引入采样开关与零阶保持器，用朱利判据定采样周期上界
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量和调节时间反求二阶系统参数
本卷实例
  • 关键一步：超调量只由阻尼比决定，先反解阻尼比，再由调节时间确定自然频率
  • 中间结果：调节时间按百分之二误差带取系数，得阻尼比与自然频率之积
  • 卡点：百分之二与百分之五误差带的调节时间系数混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量和调节时间反求二阶系统参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
脉冲传递函数 离散控制系统
本卷考法
  • 求含零阶保持器的开环脉冲传递函数
本卷实例
  • 关键一步：把连续部分部分分式展开后逐项查 z 变换表，再乘一减 z 的负一次幂
  • 中间结果：脉冲传函分母出现 z 减一与 z 减指数衰减因子两个极点
  • 卡点：部分分式展开漏项，脉冲传函的极点写错
  • 卡点：采样开关位置以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过求含零阶保持器的开环脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)

离散系统稳定性分析 离散控制系统
本卷考法
  • 用朱利判据求使离散系统稳定的采样周期范围
本卷实例
  • 关键一步：写出闭环特征多项式后逐条代入朱利判据的稳定条件
  • 中间结果：稳定条件化为采样周期的不等式，得到其上界
  • 卡点：离散系统判据用特征根模小于一，勿套实部小于零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过用朱利判据求使离散系统稳定的采样周期范围
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

四四、以1/a为参数的根轨迹#

思路
  • 由状态方程求特征方程，把含参数的项移到一侧化为根轨迹标准形式，再按参数根轨迹法则绘图
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以状态方程中某系数为参数绘制根轨迹
本卷实例
  • 关键一步：先展开状态矩阵的特征多项式，把含参数项整理成等效开环传函
  • 中间结果：等效开环的零点极点由不含参数的多项式之比决定
  • 卡点：未把参数完整提到分子，等效开环形式写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以状态方程中某系数为参数绘制根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由状态方程求系统特征方程
本卷实例
  • 关键一步：特征方程为状态矩阵的 sI 减 A 的行列式，先展开成多项式
  • 中间结果：展开后含参数项与不含参数项可分离
  • 卡点：行列式展开时符号写错，特征方程多一个负号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过由状态方程求系统特征方程
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

五五、临界增益与幅值裕度#

思路
  • 先由临界的幅值条件求最大增益，再取一半增益处的相角交越频率算幅值裕度
稳定裕度 频域分析
本卷考法
  • 求给定开环增益下的幅值裕度
本卷实例
  • 关键一步：先由相角等于负一百八十度求相角交越频率，再算该频率处幅值的倒数
  • 中间结果：幅值裕度以分贝表示为负二十倍对数幅值
  • 卡点：增益交越频率与相角交越频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求给定开环增益下的幅值裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
劳斯判据 稳定性分析
本卷考法
  • 由临界稳定条件求最大开环增益
本卷实例
  • 关键一步：令幅频特性等于一对应临界增益，或令劳斯表首列边界为零求解
  • 中间结果：临界增益与两个转折频率的乘积成反比关系
  • 卡点：把临界增益直接当成稳定域上界使用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由临界稳定条件求最大开环增益
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

六六、离散二阶系统稳定域#

思路
  • 写出二阶离散特征方程后套朱利判据，把稳定条件化为两个系数的不等式并在平面上画稳定域
离散系统稳定性分析 离散控制系统
本卷考法

思路

用描述函数法分析自振 非线性系统
本卷考法
  • 用描述函数法求自激振荡的振幅与频率并判稳定性
本卷实例
  • 关键一步：画线性部分的频率特性与非线性环节的负倒描述函数曲线，求交点
  • 中间结果：交点给出振荡频率和输入振幅，需按振幅增大方向判稳定性
  • 卡点：未沿振幅增大方向判断，把不稳定自振点当成稳定自振
  • 卡点：非线性特性以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过用描述函数法求自激振荡的振幅与频率并判稳定性
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率

思路

本卷考法
  • 用李雅普诺夫第二法判断平衡点的稳定性
本卷实例

  • 李雅普诺夫函数正定且其导数为负定则渐近稳定

  • 用李雅普诺夫方程判断系统稳定性
