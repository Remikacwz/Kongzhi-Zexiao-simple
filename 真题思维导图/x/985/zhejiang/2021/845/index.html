1一、李雅普诺夫平衡点稳定性#

思路
  • 对给定二阶状态方程，用李雅普诺夫方程或直接求特征值判断平衡点稳定性
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 判断给定线性状态方程在平衡点处的稳定性
本卷实例
  • 关键一步：线性定常系统平衡点稳定与否，由系统矩阵特征值的实部符号决定
  • 关键一步：也可先设正定矩阵解李雅普诺夫方程，再由解的正定性反推稳定性
  • 中间结果：二阶矩阵的特征多项式为二次式，判别式大于零时得到两个同号实根
  • 卡点：把要判断的平衡点误当作原点以外的点，本题平衡点就在原点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过判断给定线性状态方程在平衡点处的稳定性
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

2二、结构图闭环传函与稳态误差#

思路
  • 由多回路结构图求闭环传递函数，先判稳再求给定阶跃输入下的稳态误差
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 化简含局部反馈的多回路结构图求闭环传递函数
本卷实例
  • 关键一步：按内环到外环的顺序逐层化简，先合并被局部反馈包围的环节
  • 关键一步：从误差定义点出发写出输入到误差的传递关系
  • 中间结果：整理后的特征多项式为高次多项式，可交给劳斯表判稳
  • 卡点：内环还没化简就直接写总传递函数，容易漏掉回路项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过化简含局部反馈的多回路结构图求闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求给定输入下的稳态误差
本卷实例
  • 关键一步：用终值定理前先检查闭环是否稳定，这是使用前提
  • 关键一步：闭环不稳定时系统没有有限稳态误差，终值定理不适用
  • 中间结果：参考输入幅度不为一，误差表达式里要保留这个幅度系数
  • 卡点：未判稳就套终值定理，会算出一个看似有限的错误结果
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求给定输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯表判断闭环系统稳定性
本卷实例
  • 关键一步：把闭环特征多项式按幂次排好，从最高次开始列劳斯表
  • 关键一步：首列元素全部大于零才稳定，首列出现变号即不稳定
  • 中间结果：本题首列含负元素，出现两次符号变化，对应两个右半平面极点
  • 卡点：首列出现零时要用小正数替换再继续，不能直接下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯表判断闭环系统稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式

3三、由响应特征反求传函参数#

思路
  • 依次用阶跃稳态值、斜坡有限误差、脉冲等幅振荡三个条件列方程，反求开环传函的增益与两个极点参数
由响应曲线反求传递函数 传递函数
本卷考法
  • 由多种响应特征反求传递函数中的待定参数
本卷实例
  • 关键一步：阶跃输入下的稳态值等于闭环直流增益乘以输入幅度，给出一个关系式
  • 关键一步：再由脉冲输入下的等幅振荡关系建立第二个方程
  • 中间结果：开环分母含参数的因子按型别要求变为带原点极点的形式
  • 卡点：把稳态值直接当成开环增益，忽略输入幅度与闭环直流的区别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由多种响应特征反求传递函数中的待定参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由稳态误差有限判断系统型别并确定参数
本卷实例
  • 关键一步：对照输入类型与型别对应表，斜坡下误差有限说明系统恰为 I 型
  • 关键一步：型别由开环积分环节个数决定，据此定出两个参数中必有一个为零
  • 中间结果：参数之一取零后，开环传函化为标准的 I 型结构
  • 卡点：把型别与开环增益混为一谈，误以为误差有限与增益无关
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由稳态误差有限判断系统型别并确定参数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由等幅振荡条件求增益与临界参数
本卷实例
  • 关键一步：输出为等幅正弦说明闭环特征方程含一对纯虚根
  • 关键一步：把纯虚根代入特征多项式，令实部与虚部分别为零得到两个方程
  • 中间结果：振荡周期换算成角频率后，与那对纯虚根对应的频率相等
  • 卡点：把周期直接当成角频率代入，漏掉二倍圆周率的换算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由等幅振荡条件求增益与临界参数
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

4四、三阶系统稳定条件与主导极点#

思路
  • 先用劳斯判据求三个增益乘积的稳定范围，再用主导极点近似按调节时间指标定增益并检验
参数稳定域的确定 稳定性分析
本卷考法
  • 求使闭环系统稳定的一组参数范围
本卷实例
  • 关键一步：三个增益只以乘积形式出现，可先合并成一个待求量再列劳斯表
  • 关键一步：令劳斯表首列各元素同号，得到关于该乘积的不等式组
  • 中间结果：上界由一个一次不等式给出，下界由增益取正的条件给出
  • 卡点：只取一条首列不等式，漏掉另一条会把稳定域判宽
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求使闭环系统稳定的一组参数范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 用主导极点近似把三阶系统降为二阶并确定参数
本卷实例
  • 关键一步：三阶系统有一对共轭主导极点和一个远离虚轴的实极点，可忽略后者
  • 关键一步：由调节时间反推主导极点的实部与阻尼，写出期望特征多项式
  • 中间结果：把期望特征多项式与含待求增益的特征多项式逐项比对可定出增益
  • 卡点：实极点距虚轴不够远时仍作降阶，近似结论偏差较大
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过用主导极点近似把三阶系统降为二阶并确定参数
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

5五、根轨迹绘制与阻尼比反求参数#

思路
  • 先按法则画根轨迹，再由阻尼比范围求增益区间，最后由指定闭环极点反求增益与稳态值
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画出给定开环传函的根轨迹
本卷实例
  • 关键一步：先定开环极点零点个数与实轴上的根轨迹段
  • 关键一步：再求分离点、渐近线与虚轴交点，据此勾勒草图
  • 中间结果：本题开环含一个位于右半平面的极点，实轴段方向按零极点个数判定
  • 卡点：实轴段判据中的零极点个数数错，导致实轴段方向画反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画出给定开环传函的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 求满足给定阻尼比范围的增益取值
本卷实例
  • 关键一步：欠阻尼对应闭环一对共轭复根，位于左半平面且不在实轴上
  • 关键一步：把特征方程化为标准二阶形式，令阻尼比落在给定开区间内
  • 中间结果：由稳定条件给出增益下界，由复根条件给出上界
  • 卡点：只由稳定条件给出下界就收尾，漏掉复根条件给出的上界
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过求满足给定阻尼比范围的增益取值
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
