浙江大学 845 自动控制理论（含现控） 2020 年真题思维导图

985 院校共 10 题

难度：中等偏难　10 道大题：一为 4 个填空选择小题，其后依次为根轨迹与奈氏、闭环稳定性论证、闭环传函反求、双输入双输出、状态空间与状态反馈、参数根轨迹、离散采样系统、离散稳态误差、状态转移矩阵与阶跃响应，题量大、模块跨度宽

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

一一、填空与选择（稳定性·线性化·稳态误差·标准型）20 分#

思路
  • 4 个小题分别考查稳定性决定因素、阀门特性在工作点的线性化、典型输入下的稳态误差与传函的标准型实现
劳斯判据 稳定性分析
本卷考法
  • 判断哪些因素与系统稳定性相关
本卷实例
  • 关键一步：稳定性由系统自身特征方程的特征值决定
  • 中间结果：与输入信号、初始条件无关
  • 卡点：特征是特征值实部的符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过判断哪些因素与系统稳定性相关
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

非线性模型的线性化 建模与机电系统
本卷考法
  • 对阀门流量与压差的非线性关系在工作点作线性化
本卷实例

  • 中间结果：增量表达式为导数值乘以自变量的增量
  • 卡点：增量符号勿丢，工作点值要代入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 在工作点附近作泰勒展开并忽略高阶项
  • 线性化模型只在小偏差范围内有效
  • 必须先求出平衡工作点
步骤
  • 由静态方程求平衡工作点
  • 在工作点处求偏导得到增量系数
  • 写出以增量表示的线性化方程
通用考法
  • 本卷考过对阀门流量与压差的非线性关系在工作点作线性化
  • 对非线性微分方程在平衡点处线性化
  • 写出小偏差线性化模型的传递函数
常见易错
  • 未先求平衡点就直接展开
  • 把增量符号去掉后与原始变量混用

系统型别与静态误差系数 稳态误差
本卷考法
  • 判断系统型别并写静态误差系数
本卷实例

  • 中间结果：由型别确定各静态误差系数是否存在
  • 卡点：先判稳再谈稳态误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关

  • 分析增加积分环节对精度的影响
常见易错

  • 中间结果：各分量误差由对应静态误差系数决定
  • 卡点：系统不稳定时稳态误差为无穷大

  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤

  • 写出输入信号的拉氏变换

通用考法

  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错

  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

二二、由根轨迹定幅值裕度·由对数频率特性画奈氏图#

思路
  • 由根轨迹与虚轴交点的已知增益求幅值裕度，再由 Bode 图画出对应奈奎斯特曲线并标注特征点
稳定裕度 频域分析
本卷考法
  • 由虚轴交点处的幅值反求幅值裕度
本卷实例
  • 关键一步：相角不变、幅值按增益比例缩放
  • 中间结果：幅值裕度等于幅值倒数取分贝
  • 卡点：幅值裕度要取倒数再取对数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由虚轴交点处的幅值反求幅值裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环对数频率特性画出奈奎斯特曲线
本卷实例
  • 关键一步：按幅值随频率单调变化、相角起止对应画出曲线
  • 中间结果：标出低频与高频端点的幅值和相角
  • 卡点：需标注给出的特征点与数值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环对数频率特性画出奈奎斯特曲线
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 由对数幅频特性曲线读取转折频率与增益
本卷实例
  • 关键一步：逐段读斜率变化确定转折频率
  • 中间结果：低频段斜率与高度决定型别与增益
  • 卡点：本题曲线以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过由对数幅频特性曲线读取转折频率与增益
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

参数稳定域的确定 稳定性分析
本卷考法
  • 由劳斯表首列不等式求参数稳定域
本卷实例
  • 关键一步：令首列各元大于零解参数范围
  • 中间结果：稳定域由各时间常数与增益联合确定

四四、由闭环传函求开环传函·极点与误差范围#

思路
  • 由给定闭环传函反求开环传函，由期望闭环极点定阻尼比与自然频率，再由误差上限求增益
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由期望闭环极点反求阻尼比与自然频率
本卷实例
  • 关键一步：把闭环特征式与标准二阶式比较系数
  • 中间结果：实部对应阻尼比与自然频率之积，模对应自然频率
  • 卡点：比较前需把 s² 项系数归一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由期望闭环极点反求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du

  • 状态变量个数与系统阶数不匹配

本卷考法
  • 由状态转移矩阵求给定初值与阶跃输入下的响应
本卷实例
  • 关键一步：先由矩阵求逆的拉氏反变换求状态转移矩阵
  • 中间结果：按状态响应公式叠加初始状态项与输入卷积项
  • 卡点：卷积积分的变量代换勿写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过由状态转移矩阵求给定初值与阶跃输入下的响应
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错
