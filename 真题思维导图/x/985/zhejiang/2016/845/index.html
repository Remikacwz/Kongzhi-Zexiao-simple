一一、由阶跃响应反求一阶延迟系统参数#

思路
  • 由一阶惯性加纯延迟系统的单位阶跃响应曲线，反求增益、时间常数与延迟时间
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应曲线求一阶惯性加纯延迟系统的参数
本卷实例
  • 关键一步：先由稳态值定增益，再由响应曲线上两点确定时间常数
  • 中间结果：响应起始滞后给出纯延迟时间
  • 卡点：响应曲线为原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应曲线求一阶惯性加纯延迟系统的参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 用一阶系统单位阶跃响应公式由两点响应值反求时间常数
本卷实例
  • 关键一步：取曲线上两个已知时刻的响应值代入指数响应式并联立
  • 中间结果：稳态值与时间常数分别由不同时刻的响应确定
  • 卡点：延迟环节使时间轴整体平移，先扣延迟再代公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过用一阶系统单位阶跃响应公式由两点响应值反求时间常数
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式

二二、含纯延迟的闭环传函与稳态误差#

思路
  • 含纯延迟的开环传函，先求单位负反馈闭环传函，再计算指定输入下的稳态误差
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由开环传函与单位负反馈求闭环传递函数
本卷实例
  • 关键一步：单位负反馈下闭环传函等于开环传函除以 1 加开环传函
  • 中间结果：闭环传函保留同一纯延迟环节
  • 卡点：延迟在闭环特征方程中为超越项，判稳需另用频域法
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由开环传函与单位负反馈求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求指定输入下闭环系统的稳态误差
本卷实例
  • 关键一步：先判闭环稳定，再用终值定理或静态误差系数求稳态误差
  • 中间结果：纯延迟只改变相角，不影响稳态误差幅值
  • 卡点：未判稳直接套终值定理会得到错误结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求指定输入下闭环系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

三三、差分方程求解与脉冲传函#

思路
  • 由差分方程求脉冲传递函数，再在单位阶跃输入下求差分方程的解及终值
z 变换与 z 反变换 离散控制系统
本卷考法
  • 由差分方程求脉冲传递函数
  • 由 z 反变换求差分方程的解
本卷实例
  • 关键一步：对差分方程两边作 z 变换并代入零初始条件
  • 中间结果：输出与输入的 z 变换之比为有理分式
  • 卡点：零初始条件要正确代入，避免漏掉初值项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • z 变换是离散信号的拉氏变换，令 z=e^{Ts} 得到
  • 常用函数的 z 变换要熟记
  • z 反变换可用部分分式法、幂级数法或留数法
  • 左半 s 平面映射到 z 平面单位圆内
步骤
  • 将连续传递函数展开为部分分式
  • 逐项查表做 z 变换
  • 需要时做 z 反变换求时间序列
通用考法
  • 本卷考过由差分方程求脉冲传递函数
  • 本卷考过由 z 反变换求差分方程的解
  • 求给定函数的 z 变换
  • 求 z 反变换得到采样序列
  • 说明 s 平面与 z 平面的映射关系
常见易错
  • 把 z 变换结果中的 e^{-aT} 写成 e^{-a}
  • 部分分式分解时漏项导致反变换出错
公式
脉冲传递函数 离散控制系统
本卷考法
  • 由差分方程写出脉冲传递函数并求单位阶跃下的输出序列
本卷实例
  • 关键一步：把 z 变换结果按部分分式展开后逐项反变换
  • 中间结果：单位阶跃下输出为逐拍递推的序列
  • 卡点：求终值前须判断 z 平面极点是否在单位圆内
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过由差分方程写出脉冲传递函数并求单位阶跃下的输出序列
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)
公式

四四、六阶特征方程的劳斯判据#

思路
  • 对给定六阶特征方程用劳斯判据判稳并统计左右半平面与虚轴上的根数
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断六阶系统稳定性
  • 求左半平面与右半平面根的个数
本卷实例
  • 关键一步：列劳斯表，按首列符号变化数确定右半平面根的个数
  • 中间结果：特征式有缺项，须补零后再列劳斯表
  • 卡点：首列出现 0 时要用无穷小量法处理，否则判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断六阶系统稳定性
  • 本卷考过求左半平面与右半平面根的个数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式

五五、非线性系统的平衡状态#

思路
  • 求给定非线性状态方程的各平衡状态，即令各状态导数为零联立求解
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 求非线性系统的平衡状态（借位：李雅普诺夫分析的第一步）
本卷实例
  • 关键一步：令各状态导数为零，联立解代数方程组求平衡点
  • 中间结果：第二个方程含状态的三次项，解可能有多个
  • 卡点：三次方程的解要逐个列出，不能只取零解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过求非线性系统的平衡状态（借位：李雅普诺夫分析的第一步）
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数
公式

六六、结构图参数与阻尼比·稳态误差#

思路
  • 由二阶系统结构图求阻尼比与自然频率，再按阻尼比与稳态误差要求反求结构参数
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函求阻尼比与无阻尼自然频率
  • 判断系统阻尼状态
本卷实例
  • 关键一步：把闭环特征式化为二阶标准形并比较系数
  • 中间结果：阻尼比与自然频率可由结构参数表达
  • 卡点：结构图为原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函求阻尼比与无阻尼自然频率
  • 本卷考过判断系统阻尼状态
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由给定阻尼比求结构参数 a
  • 由给定阻尼比与稳态误差联立求 a、K
本卷实例
  • 关键一步：先由阻尼比条件定一个参数，再由误差条件定另一个
  • 中间结果：两个条件分别对应一个方程，可联立求解
  • 卡点：联立时误差表达式随参数变化，须重新化简
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由给定阻尼比求结构参数 a
  • 本卷考过由给定阻尼比与稳态误差联立求 a、K
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡输入下的稳态误差
  • 由稳态误差要求反求结构参数
本卷实例
  • 关键一步：单位斜坡下稳态误差为速度误差系数的倒数
  • 中间结果：稳态误差与开环增益成反比关系
  • 卡点：须先确认闭环稳定再谈稳态误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位斜坡输入下的稳态误差
  • 本卷考过由稳态误差要求反求结构参数
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力

  • 未判稳就使用终值定理

七七、结构图稳定域与调节时间求增益#

思路
  • 由三阶结构图求使系统稳定的增益范围，再由调节时间要求确定增益并求特征根
参数稳定域的确定 稳定性分析
本卷考法
  • 求使系统稳定的开环增益范围
  • 由劳斯判据列增益的不等式组
本卷实例
  • 关键一步：列劳斯表，令首列各元为正得到增益不等式组
  • 中间结果：不等式组取交集即为稳定域
  • 卡点：三阶系统需同时满足多个不等式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 特征方程各项系数全为正只是必要条件，不充分

  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理

  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数

  • 求使系统稳定的参数范围

  • 首列出现 0 后仍按常规继续算，未用 ε 法

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态观测器用输出与输入重构状态，前提是系统能观
  • 极点配置法与龙伯格观测器是两种常用形式
  • 观测器误差动态由 A-LC 的特征值决定
  • 观测器极点通常取得比系统极点快若干倍
步骤
  • 验证系统能观性
  • 写出观测器方程并求误差动态矩阵
  • 按期望特征多项式比较系数求出 L
  • 校验观测器收敛速度是否合适
通用考法
  • 本卷考过设计闭环极点均为给定值的全维观测器
  • 本卷考过讨论观测器响应速度要求与最小维数
  • 设计全维状态观测器
  • 由期望观测器极点求反馈增益阵 L
  • 分析观测器与状态反馈组合后的系统极点
常见易错
  • 把观测器增益阵写成了状态反馈增益阵的形式
  • 忽略观测器极点过快会放大噪声
