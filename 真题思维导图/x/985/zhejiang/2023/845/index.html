一一、由状态转移矩阵反求传函8 分#

思路
  • 由给定状态转移矩阵反求系统矩阵，再用状态空间求传递函数
状态转移矩阵 状态空间分析
本卷考法
  • 由状态转移矩阵经拉氏变换反求系统矩阵
本卷实例
  • 关键一步：状态转移矩阵的拉氏变换即系统矩阵的预解矩阵
  • 关键一步：把预解矩阵的四个元素与转移矩阵各元素的变换结果逐一对照，解出系统矩阵
  • 中间结果：预解矩阵各元素的公共分母即特征多项式，可由转移矩阵的分母直接读出
  • 卡点：直接把状态转移矩阵当代入传函公式，忽略它与预解矩阵的拉氏关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过由状态转移矩阵经拉氏变换反求系统矩阵
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错
公式
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由状态空间表达式求传递函数
本卷实例
  • 关键一步：传递函数等于输出矩阵乘预解矩阵再乘输入矩阵
  • 关键一步：把已求出的系统矩阵与给定的输入、输出矩阵代入计算
  • 中间结果：分子与分母出现公因式相消后，传函只剩一个一阶极点
  • 卡点：相消后不约简就按二阶报传函，导致系统阶数判断错误
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过由状态空间表达式求传递函数
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

二二、差分方程解析解8 分#

思路
  • 用 z 变换超前定理把差分方程化为代数方程，再反变换求通项
z 变换与 z 反变换 离散控制系统
本卷考法
  • 由差分方程用 z 变换求解析解
本卷实例
  • 关键一步：对差分方程取 z 变换，用超前定理把相邻项表示成变换式与初始值
  • 关键一步：整理出输出的变换式后做部分分式展开，再逐项反变换
  • 中间结果：特征方程的两个根为一对实常数，部分分式系数由留数法求出
  • 卡点：超前定理里的初始值项漏写，导致解与给定初值不符
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • z 变换是离散信号的拉氏变换，令 z=e^{Ts} 得到
  • 常用函数的 z 变换要熟记
  • z 反变换可用部分分式法、幂级数法或留数法
  • 左半 s 平面映射到 z 平面单位圆内
步骤
  • 将连续传递函数展开为部分分式
  • 逐项查表做 z 变换
  • 需要时做 z 反变换求时间序列
通用考法
  • 本卷考过由差分方程用 z 变换求解析解
  • 求给定函数的 z 变换
  • 求 z 反变换得到采样序列
  • 说明 s 平面与 z 平面的映射关系
常见易错
  • 把 z 变换结果中的 e^{-aT} 写成 e^{-a}
  • 部分分式分解时漏项导致反变换出错

三三、稳态误差与稳定域取交集8 分#

思路
  • 先由劳斯判据求参数稳定域，再由静态位置误差系数写出误差不等式，取交集判断存在性
系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环传函求静态位置误差系数
本卷实例
  • 关键一步：开环没有积分环节时，静态位置误差系数等于开环直流增益
  • 关键一步：单位阶跃下的稳态误差由位置误差系数直接给出
  • 中间结果：误差表达式与参数成简单反比关系，可化为不等式
  • 卡点：把开环增益与静态位置误差系数混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由开环传函求静态位置误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求使闭环稳定的参数范围
本卷实例
  • 关键一步：写出闭环特征多项式并按幂次从高到低排列
  • 关键一步：令劳斯表首列全部为正，解出参数的不等式组
  • 中间结果：本题三条首列不等式合并后取最紧的一条
  • 卡点：漏掉某一条首列不等式，稳定域判宽
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求使闭环稳定的参数范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由稳态误差要求反求参数并判断是否存在
本卷实例
  • 关键一步：把误差小于给定值化为参数的不等式，再与稳定域求交集
  • 关键一步：交集非空说明存在满足要求的参数取值
  • 中间结果：稳定域下界比误差要求的下界更紧，交集由稳定域那一侧决定
  • 卡点：只由误差要求确定参数范围，未与稳定域取交集
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由稳态误差要求反求参数并判断是否存在
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

四四、由响应曲线反求传函并判稳10 分#

思路
  • 由阶跃响应曲线的超调量与峰值时间反求二阶传函，再分别判断闭环与开环的稳定性
由响应曲线反求传递函数 传递函数
本卷考法
  • 由二阶阶跃响应曲线反求传递函数
本卷实例
  • 关键一步：从响应曲线读出超调量与峰值时间，先用超调量反解阻尼比
  • 关键一步：再由峰值时间求自然频率，写出闭环二阶传函
  • 中间结果：题给对数用于把超调百分比换算成阻尼比，曲线数值要先归一化
  • 卡点：未把响应曲线数值归一化就直接代入超调量公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法

常见易错

思路
  • 按描述函数定义对图中非线性特性作一次谐波近似，分段积分求基波幅值
描述函数法基础 非线性系统
本卷考法
  • 求典型非线性环节的描述函数
本卷实例
  • 关键一步：按描述函数定义，对非线性环节输出作一次谐波近似
  • 关键一步：分别求输出基波分量的幅值与相位，再除以输入幅值
  • 中间结果：奇对称非线性的描述函数为实数，偶对称时还要计算余弦项
  • 卡点：把描述函数当成频率的函数，实际它只与输入幅值有关
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过求典型非线性环节的描述函数

  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

典型非线性特性及其影响 非线性系统
本卷考法
  • 由图判断非线性特性类型并分段积分求描述函数
