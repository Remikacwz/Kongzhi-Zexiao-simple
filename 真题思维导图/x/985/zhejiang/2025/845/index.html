1一、正弦信号的采样与 z 变换#

思路
  • 求正弦信号的拉氏变换、采样序列、z 变换以及对应的采样函数表达式
采样过程与香农采样定理 离散控制系统
本卷考法
  • 写出给定采样周期下的采样序列与采样函数表达式
本卷实例
  • 关键一步：把连续时间代入采样时刻的整数倍，得到以采样序号为自变量的序列
  • 关键一步：采样函数是序列与冲激串的乘积，写出来就是把每个采样值乘以对应时刻的冲激
  • 关键一步：采样周期的取值决定序列的书写形式，本题代入后可直接写出含常数角度的正弦序列
  • 中间结果：采样周期与信号的角频率相乘得到序列里每个样点之间的相位增量
  • 卡点：把采样序号与采样时刻混用；或采样函数里漏掉冲激串
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过写出给定采样周期下的采样序列与采样函数表达式
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后
公式
z 变换与 z 反变换 离散控制系统
本卷考法
  • 求采样序列的 z 变换
本卷实例
  • 关键一步：先写出采样序列的通项，再套用标准正弦与余弦序列的 z 变换公式
  • 关键一步：把指数形式拆成共轭两项相加，可以避免记错公式的分子形式
  • 关键一步：结果的分母是二次的，其根就是 z 平面上的极点，可用极点位置核对收敛域
  • 中间结果：采样周期代入后指数项变成常数，z 变换的分母系数就由这些常数确定
  • 卡点：把连续信号的拉氏变换当成 z 变换；或忘记采样周期与角频率相乘这一步
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • z 变换是离散信号的拉氏变换，令 z=e^{Ts} 得到
  • 常用函数的 z 变换要熟记
  • z 反变换可用部分分式法、幂级数法或留数法
  • 左半 s 平面映射到 z 平面单位圆内
步骤
  • 将连续传递函数展开为部分分式
  • 逐项查表做 z 变换
  • 需要时做 z 反变换求时间序列
通用考法
  • 本卷考过求采样序列的 z 变换
  • 求给定函数的 z 变换
  • 求 z 反变换得到采样序列
  • 说明 s 平面与 z 平面的映射关系
常见易错
  • 把 z 变换结果中的 e^{-aT} 写成 e^{-a}
  • 部分分式分解时漏项导致反变换出错

2二、参数稳定条件#

思路
  • 含两个增益参数的系统求闭环特征方程，用劳斯或赫尔维茨判据给出稳定条件
参数稳定域的确定 稳定性分析
本卷考法
  • 求使闭环系统稳定的参数组合条件
本卷实例
  • 关键一步：先按结构图写出闭环特征方程，含参数的项要单独整理出来
  • 关键一步：用劳斯判据令首列各元素大于零，得到一组关于参数的不等式
  • 关键一步：题目问的是两个增益乘积满足的条件，把不等式组化成乘积形式即可
  • 中间结果：本题开环含一个右半平面极点，特征方程的次数与参数出现的位置要写清楚，否则不等式方向容易反
  • 卡点：只列部分首列不等式；或把两个增益的乘积当成单个参数直接判稳
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求使闭环系统稳定的参数组合条件
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

3三、由状态空间求传函并定等幅振荡增益#

思路
  • 四阶状态空间先求传递函数，再令特征多项式含纯虚根求出使零输入响应等幅振荡的增益与频率
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由状态空间表达式求传递函数
本卷实例
  • 关键一步：本题系统矩阵是标准型形式，特征多项式可直接由最后一列系数写出
  • 关键一步：输出矩阵只取出最后一个状态，输入矩阵各分量都要参与，逐式代入消元即可得到传函
  • 关键一步：整理出的传函分母就是特征多项式，分子由输入矩阵各分量与结构共同决定
  • 中间结果：消元时从最后一个状态往前代，每一步只用一个方程，可以避免代数出错
  • 卡点：把特征多项式最后一列系数的符号写反；或只取输入矩阵的一个分量而漏掉其余
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过由状态空间表达式求传递函数
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消
公式
劳斯判据 稳定性分析
本卷考法
  • 求使系统零输入响应等幅振荡的参数值与振荡频率
本卷实例
  • 关键一步：零输入响应等幅振荡对应特征方程有纯虚根，也就是特征多项式含一个只带常数项与二次项的因式
  • 关键一步：把特征多项式按这个二次因式与另一个二次因式相乘展开，令各次项系数与原多项式逐项相等
  • 关键一步：由一次项系数与三次项系数先定出振荡频率，再由常数项定出待求增益
  • 中间结果：展开后一次项给出振荡角频率的平方，常数项给出增益与频率平方的乘积关系
  • 卡点：只令特征多项式某项为零而不检验其余项是否配得上；或求出频率后忘记它对应的是角频率还是频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过求使系统零输入响应等幅振荡的参数值与振荡频率
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式

4四、采样系统的输出序列与终值#

思路
  • 先求输出 z 变换，再在给定各环节传函与单位阶跃输入下算前几个采样点的值并判断稳定性求终值
脉冲传递函数 离散控制系统
本卷考法
  • 求采样系统的输出 z 变换表达式
本卷实例
  • 关键一步：按采样开关位置决定哪些环节先相乘再取 z 变换，中间没有采样开关的连续环节必须先合并
  • 关键一步：零阶保持器要与后续连续环节合并后再做 z 变换，不能单独变换后相乘
  • 关键一步：输出 z 变换等于闭环脉冲传函乘输入的 z 变换
  • 中间结果：把各环节代入后整理成 z 的有理分式，便于逐项做长除法求序列
  • 卡点：把保持器当成普通环节单独变换；或把开环脉冲传函当成了闭环
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过求采样系统的输出 z 变换表达式
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)
公式
离散系统的动态性能与极点分布 离散控制系统
本卷考法
  • 由输出 z 变换求各采样时刻的输出值
本卷实例
  • 关键一步：求前几个采样点的值可用长除法
  • 关键一步：也可以用部分分式展开后逐项做 z 反变换，再代入采样序号
  • 关键一步：初值可用初值定理核对，本题的第一个采样点应当由结构直接看出
  • 关键一步：把输出 z 变换按 z 的负幂次展开，商的各项系数就是输出序列
  • 中间结果：长除法每除一次得到一个采样值，除到题要求的序号即可停止
  • 卡点：把 z 的负幂次与正幂次展开方向弄反；或忘记把指数项代入数值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点在 z 平面上的位置决定响应形式
  • 极点越靠近原点衰减越快，越靠近单位圆振荡越强
  • 极点的幅角决定振荡频率，幅值决定衰减速度
  • 采样周期增大会使动态性能变差甚至不稳定
步骤
  • 求闭环脉冲传递函数的极点
  • 按极点在单位圆内的位置判断响应形式
  • 由极点的模与幅角估算衰减与振荡频率
  • 与连续系统指标对应关系相互校验
通用考法
  • 本卷考过由输出 z 变换求各采样时刻的输出值
  • 由闭环极点分布判断动态性能
  • 与连续域指标互相换算
  • 说明采样周期对动态性能的影响
常见易错
  • 把 z 平面极点当作 s 平面极点直接读阻尼比
  • 忽略单位圆上极点对应等幅振荡
公式
离散系统稳定性分析 离散控制系统
本卷考法
  • 判断采样系统稳定性并求单位阶跃下的终值
本卷实例
  • 关键一步：先看闭环脉冲传函的极点是否全部落在单位圆内，只有稳定才能用终值定理
  • 关键一步：终值定理的形式是 z 趋于一时一减 z 的负一次方乘以输出的 z 变换，再乘上输入的因子
  • 关键一步：若闭环含 z 等于一的极点，阶跃输入下终值应趋于一个有限值，可用这一点核对结果
  • 中间结果：本题保持器与积分环节串联，开环在 z 等于一处有极点，所以阶跃输入下系统无稳态误差
  • 卡点：未判稳就代终值定理；或把终值定理的因子与输入的 z 变换重复乘了一次
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过判断采样系统稳定性并求单位阶跃下的终值
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

5五、由响应反求模型并离散化#

思路
  • 由零输入响应与零状态响应反求系统矩阵与输入矩阵，再按给定采样周期和零阶保持器求离散化状态方程
状态转移矩阵 状态空间分析
本卷考法
  • 由零输入响应与零状态响应反求系统矩阵与输入矩阵
本卷实例
  • 关键一步：零输入响应里出现的指数项直接给出状态转移矩阵的形式，把初值代进去可验证
  • 关键一步：零状态阶跃响应是状态转移矩阵与输入矩阵的卷积，对时间求导可把输入矩阵分离出来
  • 关键一步：两组给出的初值响应互相印证，可用其中一组检验求出的矩阵是否正确
  • 中间结果：本题零输入响应是指数函数乘初值，说明系统矩阵只有一个特征值，状态转移矩阵是该指数乘常矩阵
  • 卡点：把零输入响应里的初值当成系数而不是状态；或求输入矩阵时忘记对时间求导
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过由零输入响应与零状态响应反求系统矩阵与输入矩阵
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错
公式
连续系统的离散化 离散控制系统
本卷考法
  • 按给定采样周期和零阶保持器求连续系统的离散化状态方程
本卷实例
  • 关键一步：把采样周期代入状态转移矩阵即得离散状态矩阵
  • 关键一步：离散输入矩阵是状态转移矩阵与输入矩阵乘积在采样周期上的积分，积分要逐项做
  • 关键一步：求出的离散方程再用递推公式算一两个采样点，与连续解在采样时刻的值比对即可确认

本卷实例
  • 关键一步：平衡点是让所有状态导数同时为零的点，把两个方程联立求解即可
  • 关键一步：本题第一个方程只含第二个状态量，可先解出它的两个取值，再代进第二个方程求第一个状态量
  • 关键一步：平衡点个数可能不止一个，求完要列全，不能只取一组解
  • 中间结果：第一个方程给出第二个状态量的两个相反取值，对应两组平衡点，两组都要继续判稳
  • 卡点：只解出一组平衡点就下结论；或把平衡点与原系统原点混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过求非线性系统的平衡点
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
