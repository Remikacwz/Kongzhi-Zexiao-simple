一一、选择题（稳定性·正弦稳态·根轨迹·采样定理·劳斯判据）#

思路
  • 5 道选择题分考稳定性判别、正弦输入下的稳态输出、根轨迹点归属、采样定理与劳斯判据判稳
劳斯判据 稳定性分析
本卷考法
  • 由特征方程、闭环极点或响应发散判断系统稳定性
  • 用劳斯判据数右半平面闭环极点数
本卷实例
  • 关键一步：响应含 e^t 增长项或闭环极点在右半平面即不稳定
  • 关键一步：劳斯表首列变号次数等于右半平面根数
  • 中间结果：s²+5s+5 的两根实部均为负，系统稳定
  • 中间结果：斜坡响应趋于定值说明系统稳定
  • 卡点：斜坡响应含正弦衰减项，勿只看 2t 项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由特征方程、闭环极点或响应发散判断系统稳定性
  • 本卷考过用劳斯判据数右半平面闭环极点数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

零极点分布与响应模态 传递函数
本卷考法
  • 由闭环极点实部符号判断响应是否衰减
本卷实例
  • 关键一步：先解特征方程定出各闭环极点
  • 中间结果：极点在左半平面则对应模态衰减
  • 卡点：含零极点对消时以实际闭环极点为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由闭环极点实部符号判断响应是否衰减
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

频率特性的物理意义与求法 频域分析
本卷考法
  • 由 G(s)=1/(s+1) 求正弦输入下的稳态输出
本卷实例
  • 关键一步：把 s=jω 代入得幅频与相频
  • 中间结果：稳态输出幅值为幅频、相角为相频叠加输入相角
  • 卡点：输入 sin(t+π/2) 的初相要计入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由 G(s)=1/(s+1) 求正弦输入下的稳态输出
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 由根轨迹相角与幅值条件判断给定点是否为闭环极点
本卷实例
  • 关键一步：把给定点代入特征方程求对应 k
  • 中间结果：k=1 时解出对应闭环极点
  • 卡点：要同时满足相角条件与幅值条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过由根轨迹相角与幅值条件判断给定点是否为闭环极点
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

采样过程与香农采样定理 离散控制系统
本卷考法
  • 由信号最高频率确定采样周期上限
本卷实例
  • 关键一步：按香农定理写出采样角频率不小于两倍最高频率
  • 中间结果：采样周期与最高频率成反比
  • 卡点：勿把 2π/ωmax 与 π/ωmax 混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过由信号最高频率确定采样周期上限
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

二二、由单位脉冲响应反求传函与静态误差10 分#

思路
  • 由闭环脉冲响应反求闭环传函，再求开环传函、误差传函与给定输入下的静态误差
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位脉冲响应 k(t) 反求系统传递函数
本卷实例
  • 关键一步：对 k(t) 取拉氏变换得闭环传函 Φ(s)
  • 中间结果：由 G=Φ/(1−Φ) 得开环传函
  • 卡点：脉冲响应的拉氏变换即闭环传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位脉冲响应 k(t) 反求系统传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 由闭环传函写误差传递函数
本卷实例
  • 关键一步：单位负反馈下误差传函为 1−Φ(s)
  • 中间结果：误差传函分子分母均为 s 的多项式
  • 卡点：先确认系统稳定再用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由闭环传函写误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由输入 1+(1/3)t 求静态误差
本卷实例
  • 关键一步：分别求阶跃与斜坡分量的稳态误差再叠加
  • 中间结果：一型系统阶跃误差为零、斜坡误差由速度误差系数定
  • 卡点：组合输入勿漏任一分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由输入 1+(1/3)t 求静态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

  • 由超调量与调节时间要求确定阻尼比与自然频率
本卷实例
  • 关键一步：由超调量反求阻尼比下界，由调节时间反求自然频率下界

  • 卡点：两个指标要同时满足
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与调节时间要求确定阻尼比与自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错

  • 峰值时间与上升时间混用

  • 判断给定指标组合是否可实现
常见易错

  • 把 ξ 的可行域方向取反
