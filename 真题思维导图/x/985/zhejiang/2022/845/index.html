一一、前馈反馈复合控制的前提#

思路
  • 按给定要求画复合控制框图，写出参考与扰动两条通道的传递函数，说明前馈通道成立的条件
反馈校正与复合控制 系统校正
本卷考法
  • 设计前馈—反馈复合控制并说明前馈通道成立的前提
本卷实例
  • 关键一步：前馈补偿器由被补偿量到被控量的传递关系反解，使其与被控通道相消
  • 关键一步：反馈回路仍按误差调节，前馈只负责抵消可测的扰动或给定
  • 中间结果：按扰动前馈时补偿器接在扰动进入点与操纵量之间
  • 卡点：误以为前馈可以替代反馈；前馈不改变闭环特征方程，只抵消失配
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过设计前馈—反馈复合控制并说明前馈通道成立的前提
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
公式
前馈与比值控制 过程控制与检测仪表
本卷考法
  • 分析前馈为什么能改善跟踪或抗扰却不影响稳定性
本卷实例
  • 关键一步：分别写出参考通道与扰动通道的传递函数，比较加前馈前后的分子
  • 关键一步：前馈项只影响分子，不进入分母的特征多项式
  • 中间结果：两条通道的传函分母相同，说明前馈不改变闭环极点
  • 卡点：前馈补偿器含高阶微分时不可实现，需要检验可实现性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 前馈按扰动直接补偿，属于开环控制，不改变原回路稳定性
  • 完全不变性条件要求前馈通道传递函数等于扰动通道与调节通道之比的倒数
  • 比值控制保持两个流量成给定比例，常用开环比值与双闭环比值
  • 前馈与反馈组合成复合控制系统
步骤
  • 写出扰动通道与调节通道的传递函数
  • 按不变性条件求前馈补偿器
  • 对两个需配比的量确定比值系数与乘除环节位置
  • 画出复合或比值控制系统方框图
通用考法
  • 本卷考过分析前馈为什么能改善跟踪或抗扰却不影响稳定性
  • 求前馈补偿器使扰动对被控量不产生影响
  • 设计比值控制系统并计算比值系数
  • 说明前馈为什么不影响稳定性
常见易错
  • 前馈补偿器求出含高阶微分、不可实现却直接采用
  • 比值系数没有换算成仪表量程

二二、线性时不变环节的判别#

思路
  • 按定义分别验证纯滞后环节与采样保持环节的线性性与时不变性
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 按定义判断给定环节是否线性且时不变（借位 bc_01）
本卷实例
  • 关键一步：线性性要验证可加性与齐次性，时不变性要验证输入时移后输出只作同样的时移
  • 关键一步：两个性质必须分别验证，不能由一个直接推出另一个
  • 中间结果：纯滞后环节的输入时移直接传给输出，环节参数不随绝对时间变化
  • 卡点：把线性与时不变当成同一个条件，只验其中一条就下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过按定义判断给定环节是否线性且时不变（借位 bc_01）
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
采样过程与香农采样定理 离散控制系统
本卷考法
  • 分析采样保持环节的输出规律及其与采样周期的关系
本卷实例
  • 关键一步：采样保持环节在采样区间内保持区间左端的采样值
  • 关键一步：采样区间的划分由采样周期与采样序号共同决定
  • 中间结果：采样周期为常值时，第 k 个区间端点随序号 k 线性平移
  • 卡点：把保持器在区间内的恒值输出误当成连续变化的信号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过分析采样保持环节的输出规律及其与采样周期的关系
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

三三、非奇异变换下的等价性#

思路
  • 由状态空间与对角规范型两组模型，用特征方程与传递函数不变的等价关系求待定参数
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由状态空间求传递函数并比较变换前后的等价性
本卷实例
  • 关键一步：非奇异线性变换不改变系统特征方程，也不改变传递函数
  • 关键一步：先由变换前后的特征方程逐项比对，解出矩阵中的待定参数
  • 中间结果：变换后的特征方程可读作两个对角元的乘积，对应两个已知特征值
  • 卡点：把变换前后的输入矩阵直接等同，忽略变换对输入与输出矩阵的影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过由状态空间求传递函数并比较变换前后的等价性
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消
公式
由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 由特征值或传递函数确定对角规范型实现
本卷实例
  • 关键一步：对角规范型的对角线元素即系统特征值，排列顺序可以任取
  • 关键一步：输入矩阵各分量由原坐标分量经变换矩阵作用后确定
  • 中间结果：两个实现传递函数相同是等价的必要条件，可用来交叉校验
  • 卡点：对角型仍保留耦合项，未把系统真正解耦
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法
  • 本卷考过由特征值或传递函数确定对角规范型实现
  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反
公式

四四、采样后的能控性#

思路
  • 先求矩阵指数完成离散化，再由能控性矩阵不满秩求采样周期满足的条件
连续系统的离散化 离散控制系统
本卷考法
  • 按给定采样周期求离散状态方程
本卷实例
  • 关键一步：离散状态矩阵取矩阵指数在采样周期处的值
  • 关键一步：离散输入矩阵是矩阵指数乘输入矩阵在采样周期上的积分
  • 中间结果：本题状态矩阵对应的矩阵指数元素含正弦与余弦函数
  • 卡点：把离散输入矩阵写成输入矩阵与采样周期的乘积，漏掉积分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离散化状态方程由状态转移矩阵在采样周期处的取值构成
  • 输入矩阵是状态转移矩阵与输入矩阵乘积在采样周期上的积分
  • 带零阶保持器时即按上述积分式离散化，输出矩阵不变
步骤
  • 求连续系统的状态转移矩阵
  • 把采样周期代入得到离散状态矩阵
  • 对输入矩阵做积分得到离散输入矩阵
  • 写出差分形式的离散状态方程并按递推求采样点上的响应
通用考法
  • 本卷考过按给定采样周期求离散状态方程
  • 求连续系统在给定采样周期下的离散化状态方程
  • 由给出的状态响应反求系统矩阵再离散化
  • 计算采样点上的状态与输出序列
常见易错
  • 把采样周期直接当成时间常数代进连续传函
  • 积分上限写成采样周期以外的量，或忘记乘输入矩阵
公式
能控性与能观性 状态空间分析
本卷考法
  • 判断离散系统能控性并求不完全能控的参数条件
本卷实例
  • 关键一步：不完全能控对应能控性矩阵不满秩，二阶系统只需行列式为零
  • 关键一步：对行列式化简后求采样周期满足的取值
  • 中间结果：化简后不完全能控条件化为采样周期正弦项为零
  • 卡点：二阶系统只算到一列就下结论，须算到系统矩阵乘输入那一列
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断离散系统能控性并求不完全能控的参数条件
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

五五、主导极点降阶与二阶指标#

思路
  • 先按主导极点把高阶闭环降为二阶并保持直流增益，再算上升时间、峰值时间、超调量与调节时间
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 用主导极点法把高阶闭环系统降为二阶并保持增益
本卷实例
  • 关键一步：先求闭环特征方程的根，挑出距虚轴最近的一对共轭极点作主导极点
  • 关键一步：降阶时保留原闭环直流增益，使阶跃稳态值不变
  • 中间结果：本题一对复极点靠近虚轴，另一对远离虚轴，可整体忽略
  • 卡点：降阶后不校核直流增益，导致稳态值与原系统不符
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过用主导极点法把高阶闭环系统降为二阶并保持增益
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由降阶后的二阶系统计算全部动态性能指标
本卷实例
  • 关键一步：先把降阶传函化为标准二阶形式，读出阻尼比与自然频率
  • 关键一步：再依次套用上升时间、峰值时间、超调量与调节时间的关系式
  • 中间结果：调节时间按百分之二误差带取四除以阻尼比与自然频率之积
  • 卡点：把两种误差带的调节时间系数搞混，或超调量结果漏写百分号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由降阶后的二阶系统计算全部动态性能指标
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

六六、由闭环极点反求结构图参数#

思路
  • 写出含参数的结构图闭环特征方程，按存在零极点相消的假设反求两个参数
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由含参数的结构图写闭环特征方程并化简
本卷实例

离散系统的动态性能与极点分布 离散控制系统
本卷考法
  • 由脉冲响应求前几个采样周期的输出
本卷实例
  • 关键一步：对输出 z 变换做长除法或部分分式展开，逐项求采样序列
  • 关键一步：题给区间到三倍采样周期，只需算到第三个采样点
  • 中间结果：初始状态为零时，输出序列即为脉冲响应序列
  • 卡点：把 z 的负幂次与正幂次展开方向弄反，导致序列次序颠倒
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点在 z 平面上的位置决定响应形式
  • 极点越靠近原点衰减越快，越靠近单位圆振荡越强
  • 极点的幅角决定振荡频率，幅值决定衰减速度
  • 采样周期增大会使动态性能变差甚至不稳定
步骤
  • 求闭环脉冲传递函数的极点
  • 按极点在单位圆内的位置判断响应形式
  • 由极点的模与幅角估算衰减与振荡频率
  • 与连续系统指标对应关系相互校验
通用考法
  • 本卷考过由脉冲响应求前几个采样周期的输出
  • 由闭环极点分布判断动态性能
  • 与连续域指标互相换算
  • 说明采样周期对动态性能的影响
常见易错
  • 把 z 平面极点当作 s 平面极点直接读阻尼比
  • 忽略单位圆上极点对应等幅振荡
