浙江大学 845 自动控制理论（含现控） 2019 年真题思维导图

985 院校共 8 题

难度：中等　8 道大题：一为 12 个填空小题，其后依次为等效开环传函、根轨迹与性能、Bode 反求、采样系统、状态空间建模与能控能观、观测器与状态反馈、非线性建模与线性化，覆盖经典与现代控制全模块

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

一一、填空题（传函·z变换·能控性·判稳·非线性·采样与频域）#

思路
  • 12 个填空分别考查状态反馈后传函与特征根、z 变换、能控子空间、劳斯判据、平衡点、转折频率、脉冲响应、正弦稳态、奈奎斯特判据等
零极点分布与响应模态 传递函数
本卷考法
  • 由状态反馈前后传函的零极点对消求实际特征方程与特征根
  • 由闭环极点位置说明参数变化对响应快慢的影响
本卷实例
  • 关键一步：先约去被对消的零极点再写实际特征方程
  • 关键一步：由极点实部离虚轴远近判断响应快慢
  • 中间结果：特征根为剩余极点
  • 卡点：被对消的极点不再出现在闭环传函中
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由状态反馈前后传函的零极点对消求实际特征方程与特征根
  • 本卷考过由闭环极点位置说明参数变化对响应快慢的影响
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由状态反馈前后传函变化分析零极点对消
本卷实例
  • 关键一步：比较反馈前后传函的分子分母
  • 中间结果：被约去的零点极点对应不能观或不能控模态
  • 卡点：传函约分后极点数可能少于状态维数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过由状态反馈前后传函变化分析零极点对消
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

z 变换与 z 反变换 离散控制系统
本卷考法
  • 由采样序列定义写 z 变换并判断终值存在条件
本卷实例
  • 关键一步：按常数与指数序列的 z 变换公式分别写各项
  • 中间结果：终值存在要求极点位于单位圆内
  • 卡点：指数序列中的采样周期不能漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • z 变换是离散信号的拉氏变换，令 z=e^{Ts} 得到
  • 常用函数的 z 变换要熟记
  • z 反变换可用部分分式法、幂级数法或留数法
  • 左半 s 平面映射到 z 平面单位圆内
步骤
  • 将连续传递函数展开为部分分式
  • 逐项查表做 z 变换
  • 需要时做 z 反变换求时间序列
通用考法
  • 本卷考过由采样序列定义写 z 变换并判断终值存在条件
  • 求给定函数的 z 变换
  • 求 z 反变换得到采样序列
  • 说明 s 平面与 z 平面的映射关系
常见易错
  • 把 z 变换结果中的 e^{-aT} 写成 e^{-a}
  • 部分分式分解时漏项导致反变换出错

能控性与能观性 状态空间分析
本卷考法
  • 由状态空间求能控子空间与不能控子空间的维数
本卷实例
  • 关键一步：构造能控性矩阵并求其秩
  • 中间结果：能控子空间维数等于矩阵秩
  • 卡点：能控性矩阵阶数要与状态维数匹配
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过由状态空间求能控子空间与不能控子空间的维数
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 由开环传函求闭环单位脉冲响应与误差传函
本卷实例
  • 关键一步：先由开环传函写出闭环传函
  • 中间结果：单位脉冲响应即闭环传函的拉氏反变换
  • 卡点：误差传函用 1 减闭环传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由开环传函求闭环单位脉冲响应与误差传函
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断含缺项特征方程的系统稳定性
本卷实例
  • 关键一步：系数缺项时补零后列劳斯表
  • 中间结果：缺项使首列符号不全为正
  • 卡点：系数缺项不能直接下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断含缺项特征方程的系统稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
非线性系统的特点 非线性系统
本卷考法
  • 构造具有三个指定平衡状态的非线性方程
本卷实例
  • 关键一步：让一阶微分方程的右端以三个指定值为根
  • 中间结果：取三次多项式即可产生三个平衡点
  • 卡点：平衡点要求右端为零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过构造具有三个指定平衡状态的非线性方程
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
典型环节的对数频率特性 频域分析
本卷考法
  • 由开环传函写最小转折频率
本卷实例
  • 关键一步：化成时间常数形式读各环节的转折频率
  • 中间结果：最小转折频率取各转折频率中的最小者
  • 卡点：分子零点同样贡献转折频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例环节是水平线，积分与微分分别是 -20 与 +20 dB/dec 的斜线
  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec
  • 一阶微分环节与惯性环节幅频互为镜像
  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤
  • 把传递函数分解为典型环节乘积
  • 逐环节画出对数幅频渐近线与相频曲线
  • 代数相加得到总特性
通用考法
  • 本卷考过由开环传函写最小转折频率
  • 画出某一典型环节的 Bode 图
  • 由 Bode 图识别环节类型
  • 说明转角频率处的幅值与相角
常见易错
  • 把惯性环节高频渐近线的 -20 写成 -40
  • 振荡环节谐振峰位置误当作 ωn
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求使系统稳定的开环增益 K 范围
本卷实例
  • 关键一步：列劳斯表并令首列各元大于零
  • 中间结果：解出 K 的稳定下界
  • 卡点：端点是否包含需按题意判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求使系统稳定的开环增益 K 范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由一阶微分方程的脉冲响应反求运动时刻
本卷实例
  • 关键一步：先写出一阶系统的传函再拉氏反变换
  • 中间结果：令脉冲响应等于给定值解出时刻
  • 卡点：初始状态为零是求解前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由一阶微分方程的脉冲响应反求运动时刻
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

频率特性的物理意义与求法 频域分析
本卷考法
  • 求正弦输入下单位负反馈系统的稳态输出
本卷实例
  • 关键一步：把 s=jω 代入闭环传函得幅频与相频
  • 中间结果：稳态输出为同频正弦，幅相由闭环频率特性决定
  • 卡点：相位要叠加输入初相
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求正弦输入下单位负反馈系统的稳态输出
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

奈奎斯特判据 稳定性分析
本卷考法
  • 由奈氏图判断系统型别、稳定性与不稳定极点数
本卷实例
  • 关键一步：由低频起点相位定型别，再数包围临界点的圈数
  • 中间结果：由右半平面闭环极点数判断稳定性
  • 卡点：开环右半平面极点数要先数清
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由奈氏图判断系统型别、稳定性与不稳定极点数
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式

二二、由等效开环传函求闭环与前向通道传函#

思路
  • 给定含多回路的等效开环传函，求闭环传函及指定反馈回路下的前向通道传函
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式由等效开环传函求闭环传函
本卷实例
  • 关键一步：写出前向通路增益、各回路增益与余子式
  • 中间结果：按梅森公式相除得闭环传函
  • 卡点：不接触回路勿漏计或重复计数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

七七、全维观测器与状态反馈控制器设计#

思路
  • 由状态方程判断能观性，设计全维观测器，再按根轨迹所示期望极点设计状态反馈
能控性与能观性 状态空间分析
本卷考法
  • 判断系统能观性以确认观测器存在
本卷实例
  • 关键一步：构造能观性矩阵并判别是否满秩
  • 中间结果：满秩则状态可由输出重构
  • 卡点：能观是设计观测器的前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断系统能观性以确认观测器存在
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
状态观测器设计 状态空间分析
本卷考法
  • 按观测误差衰减速率设计全维观测器增益
本卷实例
  • 关键一步：把期望观测器极点代入观测器特征式后比较系数
  • 中间结果：解出观测器增益阵的各个分量
  • 卡点：观测器极点取值应使误差衰减足够快
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态观测器用输出与输入重构状态，前提是系统能观
  • 极点配置法与龙伯格观测器是两种常用形式
  • 观测器误差动态由 A-LC 的特征值决定
  • 观测器极点通常取得比系统极点快若干倍
步骤
  • 验证系统能观性
  • 写出观测器方程并求误差动态矩阵
  • 按期望特征多项式比较系数求出 L
  • 校验观测器收敛速度是否合适
通用考法
  • 本卷考过按观测误差衰减速率设计全维观测器增益
  • 设计全维状态观测器
  • 由期望观测器极点求反馈增益阵 L
  • 分析观测器与状态反馈组合后的系统极点
常见易错
  • 把观测器增益阵写成了状态反馈增益阵的形式
  • 忽略观测器极点过快会放大噪声
公式
状态反馈与极点配置 状态空间分析
本卷考法
  • 按期望极点设计状态反馈控制器
本卷实例
  • 关键一步：由期望极点写期望特征多项式并与反馈后特征式比较系数
  • 中间结果：解出状态反馈矩阵
  • 卡点：需先验证能控性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过按期望极点设计状态反馈控制器
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹图读取期望闭环极点
本卷实例
  • 关键一步：由根轨迹图读阻尼比与自然频率
  • 中间结果：由阻尼比与自然频率写出期望极点
  • 卡点：图形需回原卷核对，勿据文字臆测
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹图读取期望闭环极点
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

八八、非线性系统建模·平衡点与线性化#

思路
  • 把二阶非线性方程写成状态方程，求全部平衡点，并在给定工作点处线性化
非线性系统的特点 非线性系统
本卷考法
  • 由非线性微分方程写状态方程并求全部平衡点
本卷实例
  • 关键一步：令状态为输出及其导数，消去高阶导数
  • 中间结果：令两个状态导数同时为零得平衡点
  • 卡点：平衡点与输入量取值有关
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过由非线性微分方程写状态方程并求全部平衡点
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
非线性模型的线性化 建模与机电系统
本卷考法
  • 在给定工作点对非线性系统作小偏差线性化
本卷实例
  • 关键一步：先求工作点，再计算雅可比矩阵
  • 中间结果：线性化模型由雅可比矩阵在平衡点取值决定
  • 卡点：必须先定工作点再作展开
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 在工作点附近作泰勒展开并忽略高阶项
  • 线性化模型只在小偏差范围内有效
  • 必须先求出平衡工作点
步骤
  • 由静态方程求平衡工作点
  • 在工作点处求偏导得到增量系数
  • 写出以增量表示的线性化方程
通用考法
  • 本卷考过在给定工作点对非线性系统作小偏差线性化
  • 对非线性微分方程在平衡点处线性化
  • 写出小偏差线性化模型的传递函数
常见易错
  • 未先求平衡点就直接展开
  • 把增量符号去掉后与原始变量混用
