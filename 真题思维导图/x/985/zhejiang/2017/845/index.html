11、网络微分方程建模与传函#

思路
  • 由给定的无源网络微分方程组画出结构图，再由结构图求输入到输出的传递函数
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由给定微分方程组画无源网络的结构图
本卷实例
  • 关键一步：把各微分方程按变量关系逐式对应为积分器与加减环节
  • 中间结果：各支路电流电压关系对应到结构图的连接方式
  • 卡点：网络含两个电容，积分器初值与连线需仔细对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由给定微分方程组画无源网络的结构图
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由无源网络的微分方程求输出与输入的传函
本卷实例
  • 关键一步：对微分方程组作零初始条件的拉氏变换后消去中间变量
  • 中间结果：传函的分子分母均为 s 的多项式
  • 卡点：电容的积分关系变换后带 1/s 因子，勿漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由无源网络的微分方程求输出与输入的传函
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

22、由Bode图反求传函并求裕度#

思路
  • 由最小相位系统的对数幅频特性曲线反求传递函数，再求相角裕度与幅值裕度并判稳
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数渐近幅频特性反求最小相位系统的传递函数
本卷实例
  • 关键一步：按各段斜率变化定转角频率与对应环节，再由低频段高度定增益
  • 中间结果：斜率依次变化对应一阶环节的陆续加入
  • 卡点：低频段高度需按型别折算后再定增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数渐近幅频特性反求最小相位系统的传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 求系统的相角裕度与幅值裕度
  • 由裕度判别闭环稳定性
本卷实例
  • 关键一步：由幅频特性求截止频率，再算相角裕度与幅值裕度
  • 中间结果：幅值裕度以分贝表示，需先求相位交越频率
  • 卡点：截止频率与相位交越频率不要混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求系统的相角裕度与幅值裕度
  • 本卷考过由裕度判别闭环稳定性
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

33、结构参数B对稳定与性能的影响#

思路
  • 含参数B的多回路结构图，分析B对稳定性、单位阶跃动态性能与单位斜坡稳态误差的影响
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 逐层化简含 B 的多回路结构图求闭环传函
本卷实例
  • 关键一步：先化简内环得等效传函，再与前向通路串联
  • 中间结果：化简后的闭环传函分母含 B 与 K2 的乘积项
  • 卡点：B 在反馈支路，化简时勿漏其与 K2 的乘积
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过逐层化简含 B 的多回路结构图求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
参数稳定域的确定 稳定性分析
本卷考法
  • 分析 B 值对系统稳定性的影响
本卷实例
  • 关键一步：由特征方程系数条件判断 B 对稳定的作用
  • 中间结果：B 作为阻尼项改变特征式的一次项系数
  • 卡点：B 取零时系统等幅振荡，需单独讨论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过分析 B 值对系统稳定性的影响
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 分析 B 值对单位阶跃响应动态性能的影响
本卷实例
  • 关键一步：把闭环传函化为二阶标准形，由阻尼比随 B 的变化判断振荡强弱
  • 中间结果：阻尼比随 B 增大而增大，超调随之减小
  • 卡点：需区分过阻尼与欠阻尼两个区间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过分析 B 值对单位阶跃响应动态性能的影响
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 分析 B 值对单位斜坡响应稳态误差的影响
本卷实例
  • 关键一步：先判系统型别，再由型别确定斜坡输入下的误差形式
  • 中间结果：系统为 I 型，斜坡误差与开环增益有关
  • 卡点：B 通过改变开环增益影响稳态误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过分析 B 值对单位斜坡响应稳态误差的影响
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

44、误差恒为零的条件与抛物线误差#

思路
  • 由闭环传函分析阶跃与斜坡误差恒为零的参数条件并证明，再求抛物线输入下的稳态误差
误差定义与误差传递函数 稳态误差
本卷考法
  • 写出误差传递函数并分析误差恒为零的条件
本卷实例

  • 中间结果：误差恒零要求误差传函在原点有足够高阶的零点
  • 卡点：阶跃与斜坡两种输入需分别列出条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写出误差传递函数并分析误差恒为零的条件
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

55、非奇异变换下传函不变性证明#

思路
  • 证明状态的非奇异线性变换不改变系统的传递函数
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 证明状态非奇异变换下传递函数不变
本卷实例
  • 关键一步：把变换后的四个矩阵代入传函公式并利用变换矩阵的可逆性化简
  • 中间结果：化简中变换矩阵与其逆相乘为单位阵
  • 卡点：结论要对任意非奇异变换矩阵都成立
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过证明状态非奇异变换下传递函数不变
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
