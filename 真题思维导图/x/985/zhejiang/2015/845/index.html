一一、填空题（过程控制·电路·结构图·判稳·二阶指标）60 分#

思路
  • 一大题含 5 个独立填空小题：过程控制辨识、电路网络建模、梅森求传函、劳斯与奈氏判稳、二阶指标反求
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指认蒸汽加热器系统的被控对象、被控变量、给定值、操纵量与主要扰动
  • 由指认结果画出该控制系统的方块图
本卷实例
  • 关键一步：从工艺流程图区分被控量、操纵量与扰动通道：先认物料与能量流
  • 中间结果：方块图需保留给定值、被控量、操纵量与扰动作用通道
  • 卡点：工艺流程图与方块图均为原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指认蒸汽加热器系统的被控对象、被控变量、给定值、操纵量与主要扰动
  • 本卷考过由指认结果画出该控制系统的方块图
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由给定电路网络的微分方程画结构图并补出缺失环节
  • 由结构图写出传递函数与微分方程模型
本卷实例
  • 关键一步：用复阻抗法列各支路电流与电压关系，再对应到结构图节点
  • 中间结果：电容复阻抗记为 1/(sC)，各支路电流满足节点关系
  • 卡点：电路图与结构图均为原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由给定电路网络的微分方程画结构图并补出缺失环节
  • 本卷考过由结构图写出传递函数与微分方程模型
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 由多回路结构图用梅森公式求输出 C(s) 的表达式
  • 列全独立回路与前向通路并判断接触关系
本卷实例
  • 关键一步：按回路增益写特征式 Δ，再对每条前向通路写其余子式 Δk
  • 中间结果：共 5 个负反馈回路且两两接触，无互不接触回路
  • 卡点：结构图以原卷插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由多回路结构图用梅森公式求输出 C(s) 的表达式
  • 本卷考过列全独立回路与前向通路并判断接触关系
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求参考输入与扰动输入作用下的输出传递函数
  • 分析两输入同时作用时能否线性叠加
本卷实例
  • 关键一步：求扰动传函时把参考输入置零，单独求 C(s)/N(s)
  • 中间结果：C(s)/R(s) 与 C(s)/N(s) 分母同为 1 加各回路增益
  • 卡点：易漏扰动作用下的前向通路，需回原卷核对结构图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求参考输入与扰动输入作用下的输出传递函数
  • 本卷考过分析两输入同时作用时能否线性叠加
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

劳斯判据 稳定性分析
本卷考法
  • 对给定六阶特征方程用劳斯判据判稳
  • 求左右半平面及虚轴上闭环极点的个数
本卷实例
  • 关键一步：列劳斯表，按首列符号变化数确定右半平面极点数
  • 中间结果：特征式有缺项，需补零后再列劳斯表
  • 卡点：求虚轴极点个数需用该行为零时的辅助方程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过对给定六阶特征方程用劳斯判据判稳
  • 本卷考过求左右半平面及虚轴上闭环极点的个数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由给出的 Nyquist 图判断开环型别与闭环稳定性
  • 由开环不稳定极点数 P 与包围圈数 N 定闭环不稳定极点数
本卷实例
  • 关键一步：先数开环右半平面极点数 P，再由 Z=N+P 求闭环不稳定极点数
  • 中间结果：需判别曲线是否包围及绕向，结合 P 给结论
  • 卡点：Nyquist 图以原卷插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由给出的 Nyquist 图判断开环型别与闭环稳定性
  • 本卷考过由开环不稳定极点数 P 与包围圈数 N 定闭环不稳定极点数
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间反求阻尼比与无阻尼自然频率
  • 再求上升时间与调节时间
本卷实例
  • 关键一步：由超调量求阻尼比、由峰值时间求无阻尼自然频率
  • 中间结果：峰值时间与阻尼比共同确定 ξωn，进而求 tr 与 ts
  • 卡点：系统结构与参数以原卷插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与峰值时间反求阻尼比与无阻尼自然频率
  • 本卷考过再求上升时间与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由给定动态性能指标要求反求开环增益与系统参数
  • 讨论使系统无振荡的参数取值范围
本卷实例
  • 关键一步：把闭环特征式化为二阶标准形，再套用无振荡条件
  • 中间结果：开环传函与闭环传函随 A、K 的表达式需先写出
  • 卡点：系统结构图以原卷插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由给定动态性能指标要求反求开环增益与系统参数
  • 本卷考过讨论使系统无振荡的参数取值范围
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位阶跃、斜坡、抛物线输入下的稳态误差
  • 由系统型别判定稳态误差是否有限
本卷实例
  • 关键一步：先判系统型别与闭环稳定性，再按静态误差系数求稳态误差
  • 中间结果：不同型别对各典型输入的稳态误差分别有限或无穷
  • 卡点：输入为组合信号时要分项求和，不能只看一种输入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位阶跃、斜坡、抛物线输入下的稳态误差
  • 本卷考过由系统型别判定稳态误差是否有限
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

二二、复合控制系统参数设计15 分#

思路
  • 复合控制（前馈加反馈）系统，先由闭环过阻尼条件定 K 范围，再用前馈补偿使斜坡稳态误差为零
反馈校正与复合控制 系统校正
本卷考法
  • 由闭环过阻尼要求确定参数 K 的取值范围
  • 设计前馈补偿器使斜坡输入下稳态误差为零
本卷实例
  • 关键一步：写出闭环特征方程，由实根或判别式条件列过阻尼不等式
  • 中间结果：前馈补偿后误差传函的零极点结构随之改变
  • 卡点：复合控制系统结构图以原卷插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过由闭环过阻尼要求确定参数 K 的取值范围
  • 本卷考过设计前馈补偿器使斜坡输入下稳态误差为零
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 用前馈补偿实现给定信号不变性
  • 比较提高开环增益与加前馈对稳态误差的不同作用
本卷实例
  • 关键一步：令误差对给定输入的传递函数在 s→0 时为零解出参数条件
  • 中间结果：斜坡输入下误差为零要求前馈支路引入给定的一阶导数项
  • 卡点：只加大开环增益不能消斜坡误差，须用前馈补偿
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定

  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过设计状态反馈阵使闭环传递函数为给定形式
  • 本卷考过由期望闭环极点用极点配置求反馈阵
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反

状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由状态空间实现求等效传递函数并作结构等效变换
  • 分析零极点对消与最小实现
本卷实例
  • 关键一步：用状态空间到传递函数的公式求等效传函
  • 中间结果：等效变换前后两个传函之间的代数关系
  • 卡点：等效变换图以原卷插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过由状态空间实现求等效传递函数并作结构等效变换
  • 本卷考过分析零极点对消与最小实现
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 比较单位阶跃与单位斜坡输入下的稳态偏差
  • 分析使阶跃输入下零稳态偏差的条件
本卷实例
  • 关键一步：由误差传函在 s 趋于 0 时的极限判断稳态偏差
  • 中间结果：斜坡输入下稳态偏差与系统型别有关
  • 卡点：须在闭环稳定前提下使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过比较单位阶跃与单位斜坡输入下的稳态偏差
  • 本卷考过分析使阶跃输入下零稳态偏差的条件
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
