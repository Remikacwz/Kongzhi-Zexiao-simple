1一、运算放大器电路的建模#

思路
  • 由运放电路的虚短虚断列写微分方程，零初始条件下求传递函数，再以电感电流与电容电压为状态变量写出状态空间表达式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由含运算放大器的电路列写微分方程
本卷实例
  • 关键一步：用虚短与虚断确定各节点电位及支路电流关系
  • 关键一步：对电感与电容分别列元件电压电流关系，消去其余中间变量
  • 中间结果：消元后得到只含输入量与输出量的高阶微分方程
  • 卡点：电路结构未读图，节点连接与元件值需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由含运算放大器的电路列写微分方程
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 求运算放大器电路的传递函数
本卷实例
  • 关键一步：对微分方程取拉氏变换，各初始条件全部置零
  • 关键一步：把输出量与输入量分别集项，整理成降幂分式
  • 中间结果：传递函数分母阶数等于电路中独立储能元件的个数
  • 卡点：容易漏掉运算放大器反相输入带来的负号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过求运算放大器电路的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

状态空间表达式的建立 状态空间分析
本卷考法
  • 以电感电流和电容电压为状态变量写状态空间表达式
本卷实例
  • 关键一步：电感电流与电容电压是独立储能变量，直接取作状态变量
  • 关键一步：由电感电压与电容电流的元件方程写出两个一阶微分方程
  • 中间结果：两个一阶方程配上题目指定输出即可拼出系统矩阵与输入矩阵
  • 卡点：消去非状态变量要用电路约束，连接方式需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过以电感电流和电容电压为状态变量写状态空间表达式
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

2二、结构图与二阶系统指标#

思路
  • 由结构图写出误差与输出对输入的传递函数，按自然频率与稳态误差条件反求增益与微分时间，再求调节时间与超调量
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图求闭环传递函数
本卷实例
  • 关键一步：把串联环节相乘、并联环节相加，再按负反馈公式合并回路
  • 关键一步：分别写出输出对输入的通路增益与回路增益
  • 中间结果：闭环传递函数的分母就是后续要比对的特征多项式
  • 卡点：闭环结构未读图，反馈极性需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由结构图求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 由结构图写出误差传递函数
本卷实例
  • 关键一步：先看清图上误差点取在输入端还是反馈端
  • 关键一步：单独写出误差点到输入点的传递关系，得到误差传递函数
  • 中间结果：单位反馈时两种误差定义结果一致，可直接使用
  • 卡点：非单位反馈时两种定义相差一个反馈环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由结构图写出误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 按自然频率与阻尼比整理闭环标准二阶形式
本卷实例
  • 关键一步：把闭环特征多项式与标准二阶形式逐项比对
  • 关键一步：一次项系数对应两倍阻尼比乘自然频率，常数项对应自然频率平方
  • 中间结果：题给自然频率为二，可先定出常数项，减少待求参数个数
  • 卡点：要先归一化二次项系数，不能直接拿开环增益比对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过按自然频率与阻尼比整理闭环标准二阶形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由稳态误差条件反求系统参数
本卷实例
  • 关键一步：先判断系统型别，再看输入属于哪一种典型信号
  • 关键一步：把型别对应的静态误差系数用待求参数表示，代入误差值列方程
  • 中间结果：稳态误差条件给出待求增益与微分时间的一个关系式
  • 卡点：列方程求误差前要先确认闭环系统是稳定的
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由稳态误差条件反求系统参数
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 在给定阻尼比与自然频率下求调节时间与超调量
本卷实例
  • 关键一步：超调量只由阻尼比决定，与自然频率无关
  • 关键一步：调节时间与阻尼比乘自然频率成反比，取题目约定的误差带
  • 中间结果：第二问定出的参数可直接代入两个指标公式
  • 卡点：调节时间两种误差带的系数容易取混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过在给定阻尼比与自然频率下求调节时间与超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3三、闭环特征方程的根轨迹#

思路
  • 把给定的闭环特征方程整理成一条通路上含可变增益的形式，确定开环零极点，按法则画根轨迹，求稳定增益范围，再由指定闭环极点反求增益
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按步骤绘制根轨迹草图
本卷实例
  • 关键一步：把特征方程整理成一条通路增益乘分子加分母等于零的形式
  • 关键一步：标出开环零极点，用实轴右侧零极点个数为奇数判断根轨迹段
  • 中间结果：分支数等于开环极点数，起点为开环极点，终点为开环零点
  • 卡点：源文特征方程字面高阶项缺失，需回原卷核对式子
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按步骤绘制根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求系统稳定时可变增益的取值范围
本卷实例
  • 关键一步：把整理后的特征多项式按降幂排列并列劳斯表
  • 关键一步：令劳斯表首列各元素同号，解出可变增益的不等式组
  • 中间结果：稳定域是增益的一个区间，区间端点对应根落在虚轴上
  • 卡点：漏列首列某个元素会少掉一个约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求系统稳定时可变增益的取值范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 已知一个闭环极点反求对应增益
本卷实例
  • 关键一步：把该极点代入特征方程，检验它是否落在根轨迹上
  • 关键一步：若在根轨迹上，由幅值条件求出对应的可变增益
  • 中间结果：极点与增益的对应关系取决于特征方程的写法
  • 卡点：该极点是否在根轨迹上，需回原卷核对特征方程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过已知一个闭环极点反求对应增益
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

4四、对数频率特性与超前校正#

思路
  • 由静态速度误差系数定出开环增益，画对数频率特性并求幅值穿越频率与相角裕量，再按相角裕量要求设计串联超前校正网络
系统型别与静态误差系数 稳态误差
本卷考法
  • 由静态速度误差系数反求开环增益
本卷实例
  • 关键一步：按系统型别写出速度误差系数的低频极限表达式
  • 关键一步：令它等于题给数值，解出开环增益
  • 中间结果：低频极限由开环增益与两个惯性环节的时间常数共同决定
  • 卡点：速度误差系数与开环增益之间差两个时间常数之积

8八、状态反馈极点配置#

思路
  • 由系统矩阵判断能否用状态反馈任意配置闭环极点，再按指定的三个期望极点设计状态反馈矩阵
能控性与能观性 状态空间分析
本卷考法
  • 由能控性判据说明能否用状态反馈任意配置极点
本卷实例
  • 关键一步：先构造能控性矩阵并判断其秩是否等于系统阶数
  • 关键一步：秩满则系统完全能控，才具备任意配置极点的前提
  • 中间结果：题给系统矩阵为友矩阵，能控性矩阵满秩的条件容易核对
  • 卡点：未验证能控性就去下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解

  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
