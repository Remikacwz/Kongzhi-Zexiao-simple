2微分方程与稳定类型16 分#

思路
  • 对微分方程取拉氏变换求输出与传函，据零极点对消判断稳定类型
传递函数的定义与基本性质 传递函数
本卷考法
  • 由微分方程求输出拉氏变换与传递函数
本卷实例
  • 关键一步：在零初始条件下对微分方程两端取拉氏变换
  • 中间结果：传函由输入输出导数的系数比给出
  • 卡点：初始条件非零时输出含自由响应项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法

  • 由微分方程直接写出传递函数

  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过忽略零初始条件把初始值带进变换结果
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

  • 只求零状态响应而漏掉由初值决定的自由响应
