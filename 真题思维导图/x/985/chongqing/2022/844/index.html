2二阶系统指标反求开环传函#

思路
  • 由超调量与上升时间定阻尼比和自然频率，再由稳态误差要求定开环增益，写出二阶开环传递函数
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 求二阶系统的阻尼比与自然频率
本卷实例
  • 关键一步：由超调量反解阻尼比再写标准形式
  • 中间结果：自然频率由阻尼比与上升时间共同确定
  • 卡点：无
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过求二阶系统的阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过把开环增益误当成闭环传函的系数
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

3根轨迹反求与附加零点影响#

思路
  • 由给定根轨迹图反推开环传函，再附加一个零点画出新根轨迹并讨论零点对系统的影响
根轨迹的绘制法则 根轨迹法
本卷考法
  • 由根轨迹图反推开环传递函数
本卷实例
  • 关键一步：由起点终点与渐近线反推开环零极点
  • 中间结果：渐近线交点给出极点和与零点和的差
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤

  • 计算渐近线交点与夹角

  • 按对称性连接各段并标出对应 K 值

  • 实轴段判据中的零极点个数算错

  • 分析为何某系统需要引入零点

思路

奈奎斯特判据 稳定性分析
本卷考法
  • 由幅相频率特性曲线判断闭环稳定性
本卷实例
  • 关键一步：由开环传函画幅相曲线并按奈氏判据计数

  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤

  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由幅相频率特性曲线判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错

  • 开环含有积分环节时未补画无穷大半径圆弧

稳定裕度 频域分析
本卷考法

本卷实例
  • 关键一步：由幅值条件求截止频率再算相角
  • 中间结果：相位裕量为该点相角与一百八十度之差
  • 卡点：无
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求截止频率与相位裕量
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错

  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

本卷实例
