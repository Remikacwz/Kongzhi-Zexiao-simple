1一、由结构图求闭环传递函数#

思路
  • 由给定结构图求 C(s)/R(s)
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由结构图求闭环传递函数
本卷实例
  • 关键一步：先找出所有回路以及两两互不接触的回路，把特征式写完整
  • 关键一步：前向通道从输入走到输出，通道上的环节依次相乘
  • 关键一步：比较点有多个输入时，正负号要在写方程时体现出来，不能只连线不写号
  • 中间结果：分母是同一个特征式，分子由前向通道乘其余子式求出，最后可以约分
  • 卡点：漏掉互不接触回路项；或把比较点的负号漏掉导致分子差一个符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由结构图求闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2二、汽车行驶控制系统的组成与方案设计#

思路
  • 先分析有人驾驶汽车的组成要素并画方框图，再给出无人自动驾驶控制系统的设计方案
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 写出系统各组成要素对应的具体器件并画方框图
  • 给出给定系统的控制方案设计
本卷实例
  • 关键一步：按被控对象、检测变送、控制器、执行器四大环节逐项对号
  • 关键一步：方框图按给定、比较、控制、执行、对象、反馈的顺序串起来，反馈量是实际行驶方向
  • 关键一步：无人驾驶方案要把眼睛换成人造感知（摄像头、雷达）
  • 关键一步：车身与行驶方向是被控对象，人眼是检测变送，大脑是控制器，手脚与转向机构是执行器
  • 关键一步：大脑换成控制器与算法，手脚换成电机与执行机构，再补感知到决策的信息链
  • 中间结果：有人驾驶方案里被控量是行驶方向或轨迹，操纵量是方向盘转角
  • 中间结果：无人驾驶方案还要说明感知、决策、执行三层如何闭环
  • 卡点：只写器件名称不给方框图；或把传感器与执行器对调，方案设计题一旦环节对错后面全错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过写出系统各组成要素对应的具体器件并画方框图
  • 本卷考过给出给定系统的控制方案设计
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半

3三、含参数零点的根轨迹#

思路
  • 开环含未定零点，画以该参数为变量的根轨迹
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 绘制以非开环增益参数为变量的根轨迹
本卷实例
  • 关键一步：先把特征方程整理成一加参数乘等效开环传函等于零的标准形式，参数必须完整地出现在分子位置
  • 关键一步：参数在零点里时，等效零点随参数移动，画图前要先把参数以外的零极点固定下来
  • 关键一步：按常规法则画图，但要记住实轴段判据里的零点个数会随参数改变
  • 中间结果：本题开环分母含一个右半平面极点，根轨迹的起始点分布与常规卷不同，实轴段要重新判断
  • 卡点：直接把参数当开环增益画而不做等效变换；或忘记参数所在的零点也是开环零点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过绘制以非开环增益参数为变量的根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画出根轨迹草图
本卷实例
  • 关键一步：零极点标全后先定实轴段，再算渐近线条数与夹角
  • 关键一步：有右半平面开环极点时，根轨迹出发后可能向虚轴方向移动，稳定范围需要单独算
  • 关键一步：分离点与虚轴交点算出来后在图上标注对应参数值
  • 中间结果：开环极点个数与零点个数之差决定渐近线条数，本题两者相差不大，渐近线较少
  • 卡点：实轴段判据里零极点个数算错；或忘记画出射角与渐近线导致图不完整
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画出根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式

4四、用奈奎斯特判据定特征根分布#

思路
  • 给定特征方程，用奈奎斯特稳定判据确定特征根在复平面上的分布
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特稳定判据确定特征根在复平面上的分布
本卷实例
  • 关键一步：先把特征方程拼成一加辅助函数等于零的形式，辅助函数的极点要能直接数出右半平面个数
  • 关键一步：画出辅助函数的幅相曲线，数它包围临界点的净圈数
  • 关键一步：特征方程含纯虚根时曲线正好穿过临界点，这种情形要单独判别并说明
  • 关键一步：由净圈数与右半平面极点数按判据反推右半平面特征根个数
  • 中间结果：本题特征方程可以因式分解成三个因式相乘，因式分别是两个一次式与一个二次式
  • 中间结果：分解后一眼看出：一个正实根落在右半平面，一个负实根落在左半平面，二次因式给出一对纯虚根
  • 卡点：只报右半平面的根数而不交代虚轴上的根；或因式分解时漏掉正实根，把结论判反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特稳定判据确定特征根在复平面上的分布
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式

5五、超前校正的表达式与作用分析#

思路
  • 写出串联超前校正的一般表达式与概略波特图，再从频域与根轨迹两个角度分析它对特定对象性能的改善
超前校正 系统校正
本卷考法
  • 写出串联超前校正装置的一般表达式并画出概略波特图
  • 从频域角度分析超前校正对系统性能的改善
本卷实例
  • 关键一步：超前校正的一般形式是分子时间常数大于分母时间常数的一阶环节，零点在极点右侧
  • 关键一步：波特图上幅频先平后升，高频段以二十倍频程抬升
  • 关键一步：频域上的作用是把穿越频率附近的相位抬高，从而在提高截止频率的同时保持甚至提高相角裕度
  • 关键一步：相频整体为正，最大超前角出现在两转折频率的几何中点
  • 中间结果：最大超前角出现在两个转折频率的几何平均值处，其正切由两个时间常数之比决定
  • 卡点：把超前与滞后网络的表达式写反；或说超前校正能提高低频增益（那是滞后的作用）
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过写出串联超前校正装置的一般表达式并画出概略波特图
  • 本卷考过从频域角度分析超前校正对系统性能的改善
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 从根轨迹角度分析超前校正对系统性能的改善
本卷实例
  • 关键一步：超前校正相当于在开环中增加一对零点与极点，且零点更靠近虚轴
  • 关键一步：零点使根轨迹向左半平面弯曲，极点的右拉作用弱于零点的左拉作用，总体结果是根轨迹左移
  • 关键一步：根轨迹左移意味着阻尼比增大、超调减小、稳定裕度提高
  • 中间结果：本题对象是两个积分环节，没有有限极点，加零点后根轨迹才可能离开虚轴进入左半平面
  • 卡点：只看零点不看极点，误以为任意加零点都能改善；或忽略纯积分对象的根轨迹原本就在虚轴上
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过从根轨迹角度分析超前校正对系统性能的改善
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反

6六、电路系统的状态方程与输出方程#

思路
  • 以电容电压与电感电流为状态变量，写出电路的状态方程与输出方程
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由电路结构列写以电容电压与电感电流为状态变量的状态方程
本卷实例
  • 关键一步：电容电压的导数由流过电容的电流决定
  • 关键一步：其余元件电压电流用状态变量与输入表示，通过节点电流或回路电压关系代入
  • 关键一步：输出方程只做代数代换，把输出量写成状态变量与输入的线性组合
  • 关键一步：电感电流的导数由电感两端电压决定，这两条是列方程的出发点
  • 中间结果：本题输出是某个电阻的端电压，可由电感电流或该支路电流乘电阻得到，属于纯代数关系，不含导数
  • 卡点：状态变量个数与储能元件个数不一致；或把输出方程写成微分方程形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由电路结构列写以电容电压与电感电流为状态变量的状态方程
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
状态空间表达式的建立 状态空间分析
本卷考法
  • 把电路方程整理成矩阵形式的状态空间表达式
本卷实例
  • 关键一步：把每个状态导数的表达式按状态变量与输入整理成线性组合，系数填入系统矩阵与输入矩阵
  • 关键一步：输出方程同理整理成输出矩阵与直接传递矩阵
  • 关键一步：矩阵维数要按状态数、输入数、输出数逐项核对
  • 中间结果：两个状态、一个输入、一个输出时，系统矩阵是二阶、输入矩阵是列向量、输出矩阵是行向量
  • 卡点：系数填错列；或矩阵维数与题目要求的状态变量组不一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过把电路方程整理成矩阵形式的状态空间表达式

本卷考法

本卷实例
  • 关键一步：零输入响应等于状态转移矩阵乘初态
  • 关键一步：两组初值给出两个特征方向与两个特征值

  • 中间结果：两个特征值都是负实数，系统矩阵相似于对角阵，解出的矩阵元素可用特征方程直接验算

8八、状态反馈解耦#

思路
  • 证明可用输入变换加状态反馈解耦，求出变换矩阵与反馈矩阵并写闭环传函矩阵
状态反馈解耦 状态空间分析
本卷考法
  • 证明系统能通过输入变换与状态反馈实现解耦
  • 求解耦矩阵与状态反馈阵并写出闭环传递函数矩阵
本卷实例
  • 关键一步：解耦条件看解耦矩阵是否非奇异：矩阵各行由对应输出对输入的相对阶次决定
  • 关键一步：相对阶的求法是逐次求输出的各阶导数，第一次在表达式中出现输入的阶数减一即为该通道的相对阶
  • 关键一步：解耦矩阵可逆时，输入变换矩阵取其逆，状态反馈矩阵由同一逆矩阵乘各通道系数矩阵得到
  • 中间结果：本题两个输出对两个输入的相对阶组合后解耦矩阵满秩，所以可以实现解耦
  • 中间结果：解耦后闭环传函矩阵是对角阵，每个对角元是相应通道积分阶数对应的简单传函，非对角元恒为零
  • 卡点：相对阶数差一阶导致解耦矩阵构造错误；或解耦后忘记校验传函矩阵确实是对角阵
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 解耦的目标是让每个输出只被对应的一个输入控制，闭环传递函数矩阵成为对角阵
  • 用输入变换加状态反馈控制律 u 等于负 Kx 加 Fv 实现解耦
  • 解耦矩阵由各通道输出的相对阶与输入矩阵组成，非奇异时才能解耦
  • 解耦后闭环传函矩阵的对角元由配置的极点决定，非对角元为零
步骤
  • 逐个求各输出的相对阶，即输出导数中首次出现输入的阶数减一
  • 用各通道的相对阶对应的行组成解耦矩阵，并检查其是否非奇异
  • 由解耦矩阵的逆求出输入变换矩阵，再由各通道系数求出状态反馈矩阵
  • 写出闭环传递函数矩阵，校验是否已对角化并满足期望极点
通用考法
  • 本卷考过证明系统能通过输入变换与状态反馈实现解耦
  • 本卷考过求解耦矩阵与状态反馈阵并写出闭环传递函数矩阵
  • 证明系统能通过输入变换与状态反馈实现解耦
  • 求解耦矩阵与状态反馈阵并写出闭环传递函数矩阵
  • 分析解耦后各通道的极点是否可任意配置
常见易错
  • 相对阶取成输出导数首次出现输入的阶数本身，差一阶
  • 解耦矩阵奇异时仍硬求解，忽略解耦条件不满足

9九、不能控系统的镇定与极点配置#

思路
  • 判断能否用状态反馈镇定以及能否把极点配置到指定位置，能则求出反馈矩阵
能控性与能观性 状态空间分析
本卷考法
  • 判断不能控系统能否用状态反馈镇定
本卷实例
  • 关键一步：先构造能控性矩阵求秩，秩小于状态维数说明存在不能控模态
  • 关键一步：能控性分解后看不能控模态对应的特征值：实部全为负则系统可镇定，有一个非负就不能镇定
  • 关键一步：本题有三个状态但能控性矩阵只有两个独立列
  • 关键一步：第三个状态对应不能控模态且特征值为负，因此可以镇定
  • 中间结果：本题系统矩阵是三角形形式，对角线元素就是特征值，不能控模态的稳定性一眼可判
  • 卡点：把可镇定与完全能控混为一谈；或只看能控性矩阵不满秩就断定不能镇定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断不能控系统能否用状态反馈镇定
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

状态反馈与极点配置 状态空间分析
本卷考法
  • 判断能否把闭环极点配置到指定位置并求出反馈矩阵
本卷实例
  • 关键一步：极点配置只能在能控子空间里进行，目标极点中必须包含全部不能控模态的特征值，否则不可实现
  • 关键一步：本题不能控模态的特征值为负一，而目标极点里恰好也有负一，所以可以配置
  • 关键一步：把能控子系统单独取出，按期望极点写特征多项式
  • 关键一步：与带反馈的特征多项式比较系数求增益，不能控状态对应增益置零
  • 中间结果：能控子系统与不能控状态之间有单向耦合，不能控状态不受反馈影响，因此它的增益取零即可
  • 卡点：对不可控状态也去配置极点，导致方程无解；或求完增益不回代验算闭环特征根

  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤

  • 比较系数解出反馈增益阵 K

  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错

  • 特征多项式比较系数时符号写反
