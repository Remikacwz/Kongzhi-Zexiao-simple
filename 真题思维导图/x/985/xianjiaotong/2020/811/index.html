难度：中等　5 道大题覆盖多回路结构图求总输出、由性能指标反求参数并作参数根轨迹、用劳斯与奈氏双判据求极点左移约束、由极点分布匹配阶跃响应曲线、由 Bode 图与运放电路求校正装置；参数根轨迹与双判据证明是难点

1一、多回路结构图求系统总输出#

思路
  • 把结构图化为信号流图，分别求参考输入与扰动到输出的传函，再按线性叠加写出总输出。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求多回路系统的两条输入通道传函
本卷实例
  • 关键一步：分别求 R 到 Y 与 N 到 Y，再线性叠加
  • 中间结果：参考通道有两条前向通路，扰动通道有一条
  • 卡点：求扰动通道时参考输入须置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求多回路系统的两条输入通道传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求参考输入与扰动同时作用下的系统输出
本卷实例
  • 关键一步：两个输入分别作用后按叠加原理相加
  • 中间结果：两通道共用同一特征多项式作分母
  • 卡点：扰动从比较点后进入，前向通道少经过部分环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求参考输入与扰动同时作用下的系统输出
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简求公共特征多项式
本卷实例
  • 关键一步：先并内环再串外环，整理出公共分母
  • 中间结果：两条回路均含 (1+H1) 因式
  • 卡点：回路增益中的括号项不要展开错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简求公共特征多项式
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2二、由性能指标定参数与参数根轨迹#

思路
  • 由超调量与峰值时间定闭环参数，再令开环增益为常数、反馈系数为变量画参数根轨迹，并分析其影响。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由标准二阶形式与性能指标反求阻尼比与自然频率
本卷实例
  • 关键一步：由超调量公式反解 ξ，再由峰值时间求 ωn
  • 中间结果：σ%=16.3% 对应 ξ=1/2
  • 卡点：峰值时间公式含 √(1−ξ²)，代入时不能漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由标准二阶形式与性能指标反求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由闭环指标反求开环增益与反馈系数
本卷实例
  • 关键一步：把 ωn² 与 2ξωn 分别对应到开环参数乘积
  • 中间结果：ωn² 与开环增益同量纲，2ξωn 含反馈系数
  • 卡点：先由 ωn 定增益，再回代定反馈系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由闭环指标反求开环增益与反馈系数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以反馈系数为参变量绘制参数根轨迹
本卷实例
  • 关键一步：由闭环特征方程整理成 1+Kh·G0(s)=0 标准形式
  • 中间结果：等效开环为 4Kh·s/(s²+4)
  • 卡点：参数根轨迹变量在分子，不能与常规增益根轨迹混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以反馈系数为参变量绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 分析反馈系数变化对阶跃响应形态的影响
本卷实例
  • 关键一步：按根在实轴与复平面的分布分区间讨论
  • 中间结果：分离点对应临界阻尼，虚轴交点对应无阻尼
  • 卡点：过阻尼时调节时间由靠近虚轴的极点决定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过分析反馈系数变化对阶跃响应形态的影响
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

3三、劳斯与奈氏双判据求极点左移约束#

思路
  • 令 s=s1−1 把极点左移约束化为新变量下的稳定性问题，分别用劳斯表和奈氏判据求 Kg 范围并互相印证。
劳斯判据 稳定性分析
本卷考法
  • 用平移变换加劳斯判据求参数范围
本卷实例
  • 关键一步：作 s=s1−1 坐标平移后重新列特征方程
  • 中间结果：新特征方程为 s1³+2s1²+(Kg−3)s1+Kg=0
  • 卡点：平移后常数项与一次项系数都含 Kg，约束要取交集
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用平移变换加劳斯判据求参数范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 确定闭环极点均位于指定垂线左侧的参数范围
本卷实例
  • 关键一步：对平移后系统列劳斯表并令首列全正
  • 中间结果：由劳斯表首列得到两个关于 Kg 的不等式
  • 卡点：两个不等式的交集才是最终参数范围
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过确定闭环极点均位于指定垂线左侧的参数范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈氏判据复核同一参数范围
本卷实例
  • 关键一步：把平移后特征方程写成等效开环传函再画幅相曲线
  • 中间结果：等效开环含一个右半平面极点，故 P=1
  • 卡点：曲线与负实轴交点须落在临界点左侧才稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈氏判据复核同一参数范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

4四、由极点分布匹配二阶阶跃响应#

思路
  • 由四组闭环极点的实部、虚部算出阻尼比、自然频率、超调量与调节时间，再与四条响应曲线一一匹配。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由极点坐标求各系统的阻尼比与自然频率
本卷实例
  • 关键一步：由极点到原点的距离定 ωn，由夹角余弦定 ξ
  • 中间结果：四组极点两两具有相同 ωn 或相同 ξ
  • 卡点：实部决定衰减快慢，虚部决定振荡频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由极点坐标求各系统的阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率比较四条响应曲线
本卷实例
  • 关键一步：由超调随阻尼比减小而增大、响应随实部左移而变化判断
  • 中间结果：两组曲线同 ξ 不同 ωn，两组同 ωn 不同 ξ
  • 卡点：曲线匹配要同时看峰值高度与振荡次数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率比较四条响应曲线
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

5五、Bode 图与运放电路的 P 校正#

思路
  • 由低频段高度与转折频率反求开环传函，由理想运放电路化简校正装置，再比较校正前后的截止频率、裕度与增益。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由 Bode 图的低频高度与转折频率反求开环传函
本卷实例
  • 关键一步：由低频段以 −20dB/dec 过点定型别与增益
  • 中间结果：开环含一个积分、一个微分与两个惯性环节
  • 卡点：转折频率的先后决定各段斜率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由 Bode 图的低频高度与转折频率反求开环传函
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由理想运放电路化简校正装置的传函
本卷实例
  • 关键一步：用虚短虚断与复阻抗写出两级反相电路传函
  • 中间结果：分子分母的 RC 乘积相等，两个网孔相互抵消
  • 卡点：两级反相各带一个负号，相乘后符号为正
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由理想运放电路化简校正装置的传函
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

稳定裕度 频域分析
本卷考法
  • 比较校正前后的相角裕度与开环放大系数
本卷实例
  • 关键一步：分别由幅值条件解出校正前后的截止频率
  • 中间结果：校正后开环增益整体放大，低频段抬高
  • 卡点：增益放大可能降低相角裕度，须重算截止频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过比较校正前后的相角裕度与开环放大系数
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

校正的基本概念与性能指标 系统校正
本卷考法
  • 说明比例校正环节对系统性能的作用
本卷实例
  • 关键一步：从低频段增益与稳态误差的关系说明其作用
  • 中间结果：比例校正在全频段等比例抬高幅频曲线
  • 卡点：比例校正不改变相频，只改变截止频率与增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过说明比例校正环节对系统性能的作用
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求
