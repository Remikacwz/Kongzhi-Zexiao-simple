西安交通大学 811 自动控制理论（含现控） 2015 年真题思维导图

985 院校共 5 题

难度：中等　5 道大题覆盖随动系统机电建模、复合前馈补偿与稳态误差、奈氏判据与实部约束、根轨迹与闭环极点配置、由对数幅频特性反求传函与相位裕量；全为经典控制内容，图题多、推导量大

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

1一、随动系统的方框图与传递函数#

思路
  • 由电位器比较得偏差电压，经放大器驱动电动机励磁绕组产生电磁转矩，按电气与机械两级方程联立，消去中间量后求输出角对输入角的传递函数。
直流电机等机电系统 建模与机电系统
本卷考法
  • 由电位器误差检测、放大器与直流电动机励磁绕组建立随动系统模型
本卷实例
  • 关键一步：按误差检测、放大、励磁回路、转矩平衡逐级列写方程
  • 中间结果：励磁电流经 (Rf+Lf s) 与转矩平衡联系
  • 中间结果：输出角由 ω/s 与传动比 n 折合
  • 卡点：系统物理结构以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由电枢回路电压方程与转矩平衡方程联立
  • 反电动势与转速成正比，电磁转矩与电枢电流成正比
  • 机电时间常数由电气与机械两方面参数共同决定
步骤
  • 写出电枢回路电压平衡方程
  • 写出转矩平衡方程（含负载与粘性摩擦）
  • 消去电枢电流，得到转速或转角对电压的传递函数
通用考法
  • 本卷考过由电位器误差检测、放大器与直流电动机励磁绕组建立随动系统模型
  • 求直流电机转速或位置对电枢电压的传递函数
  • 分析机电时间常数与电气时间常数的数量级关系
常见易错
  • 漏掉反电动势与电磁转矩的耦合项
  • 把电气时间常数与机电时间常数混淆
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 联立机电各环节微分方程消元求传递函数
本卷实例
  • 关键一步：先写各环节输入输出关系，再逐个代入消去中间变量
  • 中间结果：电磁转矩正比于励磁电流，机械方程含 Js+f
  • 卡点：电位器增益与放大器增益要分别标注，不能合并成一个
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过联立机电各环节微分方程消元求传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 画出方框图并求闭环传递函数
本卷实例
  • 关键一步：把比较点、放大器、电机与反馈按信号流向连成闭环
  • 中间结果：闭环分母为一级与二级环节相乘后加开环增益
  • 卡点：比较环节的负号不能漏，否则分母符号反了
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过画出方框图并求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、复合系统前馈补偿与稳态误差#

思路
  • 先写误差传递函数，再代入单位阶跃与斜坡输入求静态误差，最后讨论顺馈补偿参数对速度误差的影响并求其临界值。
误差定义与误差传递函数 稳态误差
本卷考法
  • 由复合系统结构求误差传递函数
本卷实例
  • 关键一步：由误差定义结合闭环关系化简误差传函
  • 中间结果：误差传函分母为 1+G1G2，分子含 1−G2G3
  • 卡点：前馈通道出现在误差传函分子，符号容易取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由复合系统结构求误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 判断系统型别并求静态位置、速度误差系数
本卷实例
  • 关键一步：按开环积分环节个数定型别，再取 s 趋于 0 的极限
  • 中间结果：含一个积分环节，属 I 型系统
  • 卡点：前馈不改变开环型别，只改变等效误差传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断系统型别并求静态位置、速度误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位阶跃与斜坡输入下的稳态误差
本卷实例
  • 关键一步：在系统稳定前提下由终值定理对误差传函取极限
  • 中间结果：阶跃误差为零；斜坡误差为 (1−K2τd)/(K1K2) 形式
  • 卡点：未判稳就用终值定理是最常见错误
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位阶跃与斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 讨论前馈参数对速度误差的影响并求临界值
本卷实例
  • 关键一步：令斜坡误差为零解出临界前馈参数
  • 中间结果：前馈参数等于 1/K2 时斜坡误差为零
  • 中间结果：超过临界值后误差反号并随参数增大
  • 卡点：前馈补偿可提升等效型别，但不能无限制增大
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过讨论前馈参数对速度误差的影响并求临界值
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式

3三、奈氏判据定稳定条件（实部约束）#

思路
  • 先用奈氏曲线与负实轴交点及右半平面极点数定稳定增益范围，再用劳斯判据验证；第(2)问平移虚轴，把实部约束化为新变量的左半平面判稳问题。
奈奎斯特判据 稳定性分析
本卷考法
  • 由奈氏曲线确定闭环稳定条件并用劳斯判据验证
本卷实例
  • 关键一步：先数开环右半平面极点数，再看曲线是否包围临界点
  • 中间结果：曲线在 ω=根号15 处与负实轴相交于 −K/120
  • 卡点：开环含积分环节，奈氏曲线需补画无穷大半径圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由奈氏曲线确定闭环稳定条件并用劳斯判据验证
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
劳斯判据 稳定性分析
本卷考法
  • 列劳斯表验证闭环稳定条件
本卷实例
  • 关键一步：写出闭环特征式后令劳斯表首列各项同号
  • 中间结果：特征式为 s³+8s²+15s+K，稳定条件 0<K<120
  • 卡点：首列含变量 K 时要分别讨论各因子的符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过列劳斯表验证闭环稳定条件
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求使全部闭环极点实部绝对值都大于 1 的参数范围
本卷实例
  • 关键一步：令 s=s1−1，把 s=−1 垂线映射为新虚轴
  • 中间结果：平移后特征式为 s1³+5s1²+2s1+(K−8)
  • 卡点：平移后等效开环出现右半平面极点，右半平面极点数不再是 0
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求使全部闭环极点实部绝对值都大于 1 的参数范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式

4四、根轨迹与闭环极点配置#

思路
  • 先由闭环特征方程求等效开环传函，按根轨迹法则作图；再由复极点实部定出参数，最后由主导极点确定单位阶跃响应形式并估算动态指标。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制增益从 0 到无穷的根轨迹
本卷实例
  • 关键一步：先求等效开环零极点，再定实轴段、渐近线与分离点
  • 中间结果：等效开环为 K(s+2)(s+0.5)/[s²(s+0.5)(s+20)]
  • 中间结果：渐近线交点为 σ=−9
  • 卡点：前向与反馈通道存在零极点对消，须先写闭环特征方程再等效
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制增益从 0 到无穷的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点与会合点
本卷实例
  • 关键一步：由 N(s)M'(s)−N'(s)M(s)=0 列分离点方程
  • 中间结果：方程 s(s²+13s+40)=0，解出 s=0、−5、−8
  • 卡点：求得的根要筛选，不在根轨迹上的解必须舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式

5五、由对数幅频特性反求传函与相位裕量#

思路
  • 由低频段斜率与高度定增益和型别，由转折频率与谐振峰定各环节参数，再求截止频率与相位裕量，最后讨论幅频特性整体右移对系统性能的影响。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环对数幅频特性反求传递函数
本卷实例
  • 关键一步：按低频段斜率定型别与增益，再逐段按转折频率配环节
  • 中间结果：低频段以 −20dB/dec 过 (1,20dB)，增益为 10
  • 卡点：振荡环节的谐振峰位置与 ωn、ξ 的关系要联立求解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节

  • 写出并验证传递函数
通用考法
  • 本卷考过由开环对数幅频特性反求传递函数
  • 由给定 Bode 图写出传递函数

  • 检验候选传递函数与曲线是否吻合
常见易错

稳定裕度 频域分析
本卷考法
  • 由截止频率求相位裕量
本卷实例
  • 关键一步：令开环幅值为 1 求截止频率，再代入相频表达式求相角
  • 中间结果：截止频率约 8.16 rad/s，算得的相角裕度为负

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg

  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由截止频率求相位裕量
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益

  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
