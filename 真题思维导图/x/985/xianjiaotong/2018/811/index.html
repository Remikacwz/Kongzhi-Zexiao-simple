难度：中等偏难　5 道大题覆盖多回路结构图梅森求传函、正弦与阶跃混合输入下的稳态误差、由时域响应辨识补偿位置并求二阶指标、含零极点对消的根轨迹绘制、由奈氏图反求传函与延迟裕度；图题多、推导量大

1一、多回路结构图求传递函数#

思路
  • 由结构图画出信号流图，找出全部回路与前向通路，再用梅森增益公式求 Y(s)/R(s)。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求多回路结构图的输出对输入传函
本卷实例
  • 关键一步：先把结构图转成信号流图，标出 6 条回路与 2 条前向通路
  • 中间结果：特征式为 1 与六条回路增益之和（无互不接触项）
  • 卡点：回路极性均为负，且每条前向通路与所有回路都接触
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求多回路结构图的输出对输入传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层等效后再套梅森公式
本卷实例
  • 关键一步：把交叉连接的多个回路整理成规整的信号流图
  • 中间结果：两条前向通路增益分别为 G1G2G4G6 与 G1G3G5G6
  • 卡点：回路取负号时易漏反馈极性，导致特征式符号出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层等效后再套梅森公式
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2二、正弦与阶跃混合输入下的稳态误差#

思路
  • 先判稳，再分别求参考输入与扰动到误差的传函；正弦输入用频率特性，阶跃扰动用终值定理。
误差定义与误差传递函数 稳态误差
本卷考法
  • 分别列写参考输入与扰动到误差的传递函数
本卷实例
  • 关键一步：把参考输入与扰动分开，各自列误差传函
  • 中间结果：E/R 为 s(s+6)/(s²+8s+16) 的有理式
  • 卡点：求扰动传函时须把参考输入置零后再化简
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过分别列写参考输入与扰动到误差的传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求阶跃扰动单独作用下的稳态误差
本卷实例
  • 关键一步：对扰动通道用终值定理求 sE(s) 的极限
  • 中间结果：阶跃扰动下稳态误差为负值，由扰动传函符号决定
  • 卡点：扰动引起的误差与参考输入引起的误差要分别叠加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求阶跃扰动单独作用下的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 用频率特性法求正弦输入下的稳态误差
本卷实例
  • 关键一步：把 s=jω 代入误差传函，取幅值与相角
  • 中间结果：正弦输入误差由幅频与相频在 ω=4 处的值合成
  • 卡点：正弦输入不满足终值定理条件，不能用静态误差系数法
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过用频率特性法求正弦输入下的稳态误差
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式

3三、由时域响应辨识补偿位置与二阶指标#

思路
  • 由两条响应曲线的稳态值判断三个环节的配置，写出两个闭环传函，再对系统 B 求阻尼比与峰值。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由响应稳态值判断串联与反馈通道的环节配置
本卷实例
  • 关键一步：比较 A、B 稳态值大小，反推哪个环节在反馈通道
  • 中间结果：两种配置分别为 H=s+6 与 H=5
  • 卡点：环节位置不同会改变闭环分母与零点分布
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由响应稳态值判断串联与反馈通道的环节配置
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由响应曲线稳态值写出两种情况的闭环传函
本卷实例
  • 关键一步：用终值定理令闭环传函的直流增益等于曲线稳态值
  • 中间结果：两个闭环特征方程同为 s²+8s+30
  • 卡点：A 系统闭环零点为 −6，B 系统无闭环零点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由响应曲线稳态值写出两种情况的闭环传函
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把系统 B 闭环传函化为标准二阶形式
本卷实例
  • 关键一步：先提取比例因子，再把分母归一化为标准二阶
  • 中间结果：ωn²=30 与 2ξωn=8 的对应关系
  • 卡点：比例环节不影响阻尼比与自然频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把系统 B 闭环传函化为标准二阶形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比求超调量并反推输出峰值
本卷实例
  • 关键一步：由超调量定义式把峰值与稳态值联系起来
  • 中间结果：超调量公式中的阻尼比由 ωn 与 ξ 关系代入
  • 卡点：峰值是输出绝对值，不要漏乘稳态值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比求超调量并反推输出峰值
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式

4四、含零极点对消的根轨迹绘制#

思路
  • 化简开环传函后按法则求实轴段、渐近线、分离点与虚轴交点，再由劳斯判据说明增益范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制含重极点系统的根轨迹
本卷实例
  • 关键一步：先化简开环传函，再定实轴段与渐近线
  • 中间结果：等效开环为 Kg(s+1)/[(s+5)²(s+15)]
  • 卡点：反馈通道的 (s+1) 与前向通道对消，须先化简再画
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制含重极点系统的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹分离点并判断取舍
本卷实例
  • 关键一步：由各零极点倒数之和为零列分离点方程
  • 中间结果：分离点方程为 2d²+18d−40=0
  • 卡点：舍去的根不落在根轨迹上，须逐根检验
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹分离点并判断取舍
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 判断根轨迹是否与虚轴相交并求临界参数
本卷实例
  • 关键一步：列劳斯表，看首列是否出现零元素
  • 中间结果：劳斯表首列各项均为正，故无纯虚根
  • 卡点：结论是系统恒稳定，不能想当然认为必与虚轴相交
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过判断根轨迹是否与虚轴相交并求临界参数
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式

5五、由奈氏图反求传函与延迟裕度#

思路
  • 由奈氏图的起点、终点相角与负虚轴交点反求开环传函；用 P=0 判稳；引入延迟后令相角裕度为 45° 反求 τ。
奈奎斯特判据 稳定性分析
本卷考法
  • 由奈氏图取点反求开环传函并用判据判稳
本卷实例
  • 关键一步：由 G(j0)、G(j∞) 的相角确定积分环节数与阶数
  • 中间结果：开环为 K(s/z1+1)/[s(s/p1+1)(s/p2+1)] 形式
  • 卡点：负虚轴交点对应 ωc²=p1p2−z1(p1+p2)
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由奈氏图取点反求开环传函并用判据判稳
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

频率特性的物理意义与求法 频域分析
本卷考法
  • 求开环频率特性在给定频率处的模值与相角
本卷实例
  • 关键一步：把 s=jω 代入并分离实部与虚部
  • 中间结果：由虚部为零得与负虚轴交点的频率
  • 卡点：相角由 −90° 先增后减，说明零极点交错分布
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求开环频率特性在给定频率处的模值与相角
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

稳定裕度 频域分析
本卷考法
  • 由相角裕度条件反求延迟时间
本卷实例
  • 关键一步：引入延迟只改变相频，幅频与截止频率不变
  • 中间结果：相角裕度条件中含 −τωc·57.3° 一项
  • 卡点：角度与弧度换算容易出错，须统一量纲
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由相角裕度条件反求延迟时间
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

含纯延迟环节的系统稳定性 稳定性分析
本卷考法
  • 分析纯延迟环节对相角裕度的影响
本卷实例
  • 关键一步：延迟在相频上额外附加与频率成正比的滞后
  • 中间结果：τ 越大附加滞后越大，裕度越小
  • 卡点：延迟不改变幅频，故截止频率保持不变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 延迟环节 e^{-τs} 的幅值为 1、相位为 -τω，只恶化相位
  • 延迟会显著缩小稳定域，τ 越大越难稳定
  • 频域判据需用相位裕度扣除延迟引起的附加滞后
步骤
  • 写出含延迟的开环传递函数
  • 分别求幅值与相位表达式
  • 在相频特性中扣除 τω 的滞后量
  • 按稳定裕度或奈氏判据求临界 τ 或临界 K
通用考法
  • 本卷考过分析纯延迟环节对相角裕度的影响
  • 求使系统稳定的最大延迟时间
  • 求含延迟系统的临界开环增益
  • 分析延迟对稳定裕度的影响
常见易错
  • 把延迟环节当成惯性环节处理
  • 相位计算时忘记角度与弧度换算
