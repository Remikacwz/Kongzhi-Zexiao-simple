1一、含右半平面极点的二阶响应与超调#

思路
  • 先由开环传函求闭环传函并判稳，再把输出像函数分解为部分分式后作拉氏反变换得阶跃响应；对响应求导求峰值时刻算超调量，并结合闭环零点的作用解释超调成因。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由负反馈开环传函求闭环传递函数
本卷实例
  • 关键一步：按单位负反馈闭环公式把开环传函代入
  • 中间结果：闭环分母为开环分母加开环分子后的多项式
  • 卡点：开环含右半平面极点，闭环稳定性要单独判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由负反馈开环传函求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
零极点分布与响应模态 传递函数
本卷考法
  • 由闭环零极点分布写出阶跃响应的时间函数形式
本卷实例
  • 关键一步：把输出像函数分解为极点对应的一阶分式之和
  • 中间结果：响应由稳态项与两个衰减指数项叠加
  • 卡点：分解前要先确认各极点互异
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由闭环零极点分布写出阶跃响应的时间函数形式
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由峰值时刻与稳态值计算超调量
本卷实例
  • 关键一步：对响应求导并令其为零求峰值时刻
  • 中间结果：峰值由各衰减指数项取值与常数项之差决定
  • 卡点：闭环传函不是标准二阶形式，不能直接套用公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由峰值时刻与稳态值计算超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

  • 中间结果：附加零点使响应峰值提前并抬高
  • 卡点：零点改变各模态比重，不能只看极点位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 闭环零点会增大超调、缩短峰值时间

  • 用主导极点对近似为二阶系统

通用考法

  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错

  • 只看极点距离而不管该极点的留数大小

2二、由传递函数与初值求全响应#

思路
  • 把传递函数写成微分方程并代入初值，得到含零输入初值项的像函数；再把正弦输入取拉氏变换后与传函相乘得输出像函数，用部分分式法反变换得响应表达式。
传递函数的定义与基本性质 传递函数
本卷考法
  • 由传递函数写出对应的微分方程
本卷实例
  • 关键一步：把传递函数分母系数对应输出各阶导数
  • 中间结果：分子含二阶导数项说明输入有前馈作用
  • 卡点：分子分母同阶时要先分离直通项再作反变换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由传递函数写出对应的微分方程
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由微分方程与初始条件求系统的全响应
本卷实例
  • 关键一步：对微分方程作拉氏变换并代入初值
  • 中间结果：响应分解为零输入与零状态两部分
  • 卡点：源文两个初值 OCR 都带导数点，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由微分方程与初始条件求系统的全响应
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

频率特性的物理意义与求法 频域分析
本卷考法
  • 由正弦输入与传递函数求零状态响应分量
本卷实例
  • 关键一步：先求正弦输入的拉氏变换再与传函相乘
  • 中间结果：输出含衰减振荡项与同频正弦稳态项
  • 卡点：正弦相位常数要按弧度参与三角函数展开
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由正弦输入与传递函数求零状态响应分量
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

3三、比例微分环节位置对超调的影响#

思路
  • 先在三种结构下分别求闭环传函，比较等效阻尼比与零点作用；再由原系统超调量反求阻尼比，按调节时间缩短倍数推出校正后的阻尼比，最后求该情况下的超调量。
串联、并联与反馈等效 结构图与方框图
本卷考法

本卷实例

  • 中间结果：反馈通道加零点只改变闭环阻尼项
  • 卡点：三种结构分母差异决定各自的等效阻尼比
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 反馈等效的前提是单回路、无交叉
步骤

  • 分别套用串联、并联或反馈等效公式

通用考法

二阶系统标准形式与阻尼比 时域响应与动态性能

本卷实例

  • 中间结果：三种结构的自然频率相同而阻尼比不同
  • 卡点：零点不改变自然频率但影响等效阻尼
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤

  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法

  • 把开环增益误当成闭环传递函数的系数

思路
  • 先算能控性与能观性判别矩阵的秩；再由对偶定义写出对偶系统；能观性不足时说明全维观测器存在的限制；最后按给定观测器极点与闭环极点分别配置观测器增益与状态反馈增益。
