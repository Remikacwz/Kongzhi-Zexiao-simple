1一、二阶系统性能与速度反馈校正#

思路
  • 由闭环传函化为标准二阶形式求阻尼比与自然频率，再算超调量与调节时间；第(2)问保持自然频率不变，用速度反馈提高阻尼比以满足超调量约束。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函求阻尼比与自然频率（第(1)问）
本卷实例
  • 关键一步：把开环传函化为标准二阶闭环形式，再与标准式逐项对应
  • 中间结果：自然频率由开环增益开方得到，阻尼比由一次项系数决定
  • 卡点：未先把特征式化为首一标准形式就直接对系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函求阻尼比与自然频率（第(1)问）
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求超调量与调节时间（第(1)问）
本卷实例
  • 关键一步：超调量只由阻尼比决定，调节时间由阻尼比与自然频率共同决定
  • 中间结果：按欠阻尼二阶响应写出超调量与调节时间的表达式
  • 卡点：把5%与2%两种误差带的调节时间系数搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求超调量与调节时间（第(1)问）
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量约束反求所需阻尼比（第(2)问）
本卷实例
  • 关键一步：由超调量上限反解阻尼比下限，再与自然频率不变的条件联立
  • 中间结果：阻尼比下限由超调量公式反解，自然频率不变即开环增益不变
  • 卡点：只调增益会同时改变自然频率，不满足题意
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量约束反求所需阻尼比（第(2)问）
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
反馈校正与复合控制 系统校正
本卷考法
  • 用速度反馈校正提高系统阻尼比（第(2)问）
本卷实例
  • 关键一步：加速度反馈后闭环一次项系数增大而常数项不变，只提高阻尼比
  • 中间结果：反馈系数由阻尼比下限与自然频率写出的不等式定范围
  • 卡点：速度反馈改变了开环结构，不能沿用原开环传函估指标
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过用速度反馈校正提高系统阻尼比（第(2)问）
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

2二、多输入结构图求稳态误差#

思路
  • 由结构图分别求误差对参考输入与扰动输入的传递函数，按斜坡输入与正弦输入叠加求稳态误差。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡输入作用下的稳态误差分量
本卷实例
  • 关键一步：先判稳，再由误差传函用终值定理求斜坡输入下的误差
  • 中间结果：斜坡误差由误差传函在原点附近的一次项系数决定
  • 卡点：未先判稳就直接用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求斜坡输入作用下的稳态误差分量
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求正弦扰动作用下的稳态误差分量
本卷实例
  • 关键一步：把扰动传函在扰动频率处的模与相角代入，写成同频正弦量
  • 中间结果：正弦扰动误差的幅值按扰动传函的模缩放、相角按相频移动
  • 卡点：把扰动传函在原点的取值当正弦扰动下的响应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求正弦扰动作用下的稳态误差分量
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 由多输入结构图分别写参考输入与扰动输入的传函
本卷实例
  • 关键一步：求某一输入的传函时把另一输入置零，再按结构图逐步化简
  • 中间结果：参考通道与扰动通道的误差传函分母相同、分子不同
  • 卡点：求扰动传函时没有把参考输入置零
  • 卡点：结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过由多输入结构图分别写参考输入与扰动输入的传函
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

3三、含右半平面极点的根轨迹#

思路
  • 由开环传函画根轨迹并求特征点，再由已知闭环极点用幅值条件反求增益与其余极点，最后按主导极点实部求最短调节时间。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 画含右半平面开环极点的根轨迹（第(1)问）
本卷实例
  • 关键一步：标出三个开环极点并判断实轴上的根轨迹区间
  • 中间结果：实轴段由右侧零极点个数判定，渐近线交于极点实部之和
  • 卡点：起点含右半平面极点，根轨迹形状与全左半平面系统不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过画含右半平面开环极点的根轨迹（第(1)问）
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 由已知闭环极点用幅值条件反求增益（第(2)问）
本卷实例
  • 关键一步：把已知闭环极点代入幅值条件，令开环传函的模等于一
  • 中间结果：另两个极点由特征多项式长除后解二次方程得到
  • 卡点：只用幅值条件求出增益却不求其余极点，漏答一半
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过由已知闭环极点用幅值条件反求增益（第(2)问）
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹上闭环极点位置分析动态性能（第(2)(3)问）
本卷实例

  • 中间结果：实部越负响应越快，超调量由极点的阻尼角决定
  • 卡点：把等阻尼线当作垂直线来确定极点位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹上闭环极点位置分析动态性能（第(2)(3)问）
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

4四、最小相位系统Bode反求与校正选择#

思路
  • 由图(b)的对数幅频特性反求被控对象传函；比较两个候选控制器，选超前校正以减小超调并提高响应速度；再估算校正前后的相角裕度。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频特性曲线反求被控对象传函（第(1)问）
本卷实例
  • 关键一步：由低频段斜率定积分环节个数与增益，由转折频率定环节类型
  • 中间结果：各转角频率处斜率的变化对应一阶、二阶或微分环节
  • 卡点：把渐近线延长线交点直接当作增益而未按型别折算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

思路

  • 由微分方程写能控标准型与对偶能观标准型（第(1)问）
本卷实例
  • 关键一步：由微分方程写传函，取分母系数排状态矩阵、分子系数定输出阵
  • 中间结果：能控标准型与能观标准型互为对偶，系数排列方向不同
  • 卡点：真分式化分时直接传递项的处理出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法
  • 本卷考过由微分方程写能控标准型与对偶能观标准型（第(1)问）
  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反

状态反馈与极点配置 状态空间分析
本卷考法
  • 按动态指标设计状态反馈增益阵（第(2)问）
本卷实例
  • 关键一步：由指标反求期望极点，再比较闭环特征多项式系数解出增益
  • 中间结果：期望极点为共轭复根，配置后闭环特征多项式随增益变化
  • 卡点：未验证能控性就直接做极点配置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过按动态指标设计状态反馈增益阵（第(2)问）
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反

由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量与调节时间反求期望极点参数（第(2)问）
本卷实例
  • 关键一步：超调量定阻尼比、调节时间定自然频率，再写出期望极点
  • 中间结果：二阶期望极点为阻尼比与自然频率对应的共轭复根
  • 卡点：只满足单项指标就下结论，未做交叉验证
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量与调节时间反求期望极点参数（第(2)问）
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

能控性与能观性 状态空间分析
本卷考法
  • 分析引入状态反馈后闭环系统的能观性（第(3)问）
本卷实例
  • 关键一步：用反馈后的状态矩阵与输出矩阵重算能观判别矩阵并求秩
  • 中间结果：状态反馈可能改变能观性，须以反馈后的矩阵重新判断
  • 卡点：直接用原系统的能观性当作反馈后的结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过分析引入状态反馈后闭环系统的能观性（第(3)问）
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
