1一、二阶系统性能与速度反馈校正#

思路
  • 由开环传函写闭环标准二阶形式求阻尼比与自然频率，再按欠阻尼公式求超调量与调节时间；第二问引入速度反馈，在保持自然频率不变的条件下调整阻尼满足超调要求。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函化为标准二阶形式求阻尼比与自然频率
本卷实例
  • 关键一步：写出单位负反馈闭环传函并与标准形式对照
  • 中间结果：一次项系数给出阻尼比与自然频率的乘积
  • 卡点：开环增益需先化为尾一标准形式再比较系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函化为标准二阶形式求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率求超调量和调节时间
本卷实例
  • 关键一步：把求得的阻尼比与自然频率代入欠阻尼指标公式
  • 中间结果：调节时间按给定误差带选择时间常数倍数
  • 卡点：误差带百分比不同，调节时间系数需相应改变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率求超调量和调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 保持自然频率不变使超调量满足要求
本卷实例
  • 关键一步：由超调量上限反解阻尼比下限
  • 中间结果：保持自然频率不变时只需调整阻尼项
  • 卡点：超调量上限对应阻尼比下限，不等式方向容易取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过保持自然频率不变使超调量满足要求
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
反馈校正与复合控制 系统校正
本卷考法
  • 用速度反馈校正改变阻尼而不改变自然频率
本卷实例
  • 关键一步：在开环通道中引入输出导数反馈构成内环
  • 中间结果：等效开环传函的一次项系数因反馈而增大
  • 卡点：速度反馈会同时改变开环增益，需保持穿越特性满足要求
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过用速度反馈校正改变阻尼而不改变自然频率
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

2二、前馈补偿使斜坡稳态误差为零#

思路
  • 由结构图求参考输入到误差的传函，把前馈补偿器并入分子；令斜坡输入下稳态误差的极限为零，整理出参数 b 的条件。
减小稳态误差的措施 稳态误差
本卷考法
  • 用前馈补偿器使斜坡输入下稳态误差为零
本卷实例
  • 关键一步：把前馈补偿器并入误差传函分子
  • 中间结果：令误差传函在零点的二阶留数为零得到补偿参数条件
  • 卡点：前馈补偿器含二阶微分，物理实现需另加滤波
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过用前馈补偿器使斜坡输入下稳态误差为零
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 在斜坡输入下用终值定理列稳态误差表达式
本卷实例
  • 关键一步：写出误差传函并乘以斜坡输入的拉氏变换
  • 中间结果：误差表达式的极限由分子低阶项系数决定
  • 卡点：系统必须稳定才能使用终值定理，题面已给稳定条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过在斜坡输入下用终值定理列稳态误差表达式
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求参考输入经前馈与反馈两路到误差的传函
本卷实例
  • 关键一步：分别求两条前向通道到误差的传递关系
  • 中间结果：误差传函分子包含前馈补偿项
  • 卡点：结构图为原卷插图，前馈接入点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求参考输入经前馈与反馈两路到误差的传函
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

3三、根轨迹与动态性能分析#

思路
  • 按开环零极点画根轨迹并求实轴段、渐近线、分离点和虚轴交点；由实部为 -5 的闭环极点用幅值条件求增益，再由主导极点和偶极子近似求超调量，最后分析最短调节时间。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按开环零极点绘制根轨迹并确定实轴段与渐近线
本卷实例
  • 关键一步：由零极点分布判断实轴根轨迹区段
  • 中间结果：渐近线交点由零极点重心决定
  • 卡点：根轨迹形状为原卷插图，分支走向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按开环零极点绘制根轨迹并确定实轴段与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 用分离点方程求根轨迹的分离点坐标
本卷实例
  • 关键一步：对闭环特征方程求导并令其为零
  • 中间结果：分离点方程的解需按实轴区段筛选
  • 卡点：解出复数分离点时应舍去，不能当作有效分离点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过用分离点方程求根轨迹的分离点坐标
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 用劳斯表辅助方程求根轨迹与虚轴交点及临界增益
本卷实例
  • 关键一步：令劳斯表首列出现零并写辅助方程
  • 中间结果：辅助方程给出临界频率与临界增益
  • 卡点：临界增益处根轨迹是否穿越虚轴需按两侧极点位置判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过用劳斯表辅助方程求根轨迹与虚轴交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 由闭环极点分布找主导极点并作偶极子近似
本卷实例
  • 关键一步：比较闭环极点与零点的相对位置判断偶极子
  • 中间结果：远极点与零点近似对消后可降为二阶系统
  • 卡点：偶极子近似是否成立还需看留数大小
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过由闭环极点分布找主导极点并作偶极子近似
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹上主导极点位置求最短调节时间
本卷实例
  • 关键一步：调节时间最小对应主导极点实部绝对值最大
  • 中间结果：沿根轨迹搜索使实部最负的可行工作点
  • 卡点：无穷远处实部趋于定值，最短时间不能简单取无穷大增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
