1一、由非零初值响应反求传递函数#

思路
  • 输出含常数项与两个衰减分量，先按非零初值写出响应的一般形式定出各分量系数，再对输出取拉氏变换，按响应变换与输入变换之比还原传递函数。
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由非零初始条件下的阶跃响应反求系统传递函数
本卷实例
  • 关键一步：输出含常数项与形如多项式乘指数的分量，先按非零初值写出响应的一般形式
  • 关键一步：用响应及其一阶导数在零时刻的取值联立定出各分量系数
  • 中间结果：常数项由稳态分量确定，两个指数分量的系数由初始状态条件决定
  • 卡点：题面初值条件文字有缺失，响应一般形式是否含多项式乘指数项需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由非零初始条件下的阶跃响应反求系统传递函数
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由已知的阶跃响应表达式还原系统传递函数
本卷实例
  • 关键一步：对输出作拉氏变换得到输出变换，再除以单位阶跃输入的拉氏变换
  • 中间结果：输出变换与输入变换约去公共因子后，传递函数分母整理为二次多项式
  • 卡点：非零初值会把与初始状态有关的项混入输出变换，不能直接当作零状态响应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由已知的阶跃响应表达式还原系统传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

2二、二阶系统时域指标与稳定裕度#

思路
  • 由单位阶跃稳态误差与正弦输入的稳态输出确定闭环传递函数参数，按标准二阶形式求超调量与调节时间，再由闭环传函反求开环传函求幅值穿越频率和相位裕度。
误差定义与误差传递函数 稳态误差
本卷考法
  • 由单位阶跃下的稳态误差确定闭环传递函数参数关系
本卷实例
  • 关键一步：单位负反馈的误差传函等于一减闭环传函，再用终值定理求阶跃稳态误差
  • 中间结果：稳态误差只与闭环传函的直流增益和常数项有关
  • 卡点：输入信号在题面中缺失，误差所用的输入类型需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由单位阶跃下的稳态误差确定闭环传递函数参数关系
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由正弦输入的稳态输出反求阻尼比与自然频率
本卷实例
  • 关键一步：把闭环频率特性在给定频率处的幅值与相角分别与标准二阶形式对应
  • 中间结果：相角给出自然频率与输入频率的关系，幅值进一步给出阻尼比
  • 卡点：题设无零点才可按标准二阶形式对应，有零点时相频形状会明显不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由正弦输入的稳态输出反求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率计算超调量和调节时间上界
本卷实例
  • 关键一步：由特征方程系数读出阻尼比与自然频率，再代入欠阻尼动态指标公式
  • 中间结果：调节时间按题目所给误差带选取对应的时间常数倍数
  • 卡点：误差带系数取错会把调节时间算成不同倍数，需按题目给的百分比选择
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率计算超调量和调节时间上界
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
稳定裕度 频域分析
本卷考法
  • 求幅值穿越频率与相位裕度
本卷实例
  • 关键一步：先由闭环传函反求开环传函，再令开环幅值等于一解出幅值穿越频率
  • 中间结果：在幅值穿越频率处把开环相角折算成相位裕度
  • 卡点：开环相频在转折频率两侧表达式不同，分段时容易漏掉负九十度基准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求幅值穿越频率与相位裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

3三、结构图参数求解与参数根轨迹#

思路
  • 由结构图写出闭环传递函数，用初值定理和终值定理联立求参数；再把特征方程中含待求参数的项移到一侧构造等效开环传函，绘制参数根轨迹并分析参数变化对动态性能的影响。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由含多个增益与积分环节的结构图写出闭环传递函数
本卷实例
  • 关键一步：标出前向通路与各反馈环，按反馈等效从内到外逐层化简
  • 中间结果：闭环分母含积分环节与对象极点，分子由前向通路增益构成
  • 卡点：结构图为原卷插图，回路层次、反馈极性与增益位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由含多个增益与积分环节的结构图写出闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 用初值定理与稳态条件联立求结构图参数
本卷实例
  • 关键一步：由输出初值及其一阶导数的极限确定积分环节个数与增益
  • 中间结果：稳态误差为零给出反馈系数与输出稳态值之间的关系
  • 卡点：初值定理要对输出变换取极限，直接对时域表达式取极限会漏掉冲激项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过用初值定理与稳态条件联立求结构图参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以待求参数为变量整理等效开环传函并绘制参数根轨迹
本卷实例
  • 关键一步：把特征方程中不含参数的项移到等式另一侧，构造等效开环传函
  • 中间结果：参数根轨迹起点为原开环极点，终点为开环零点与无穷远
  • 卡点：参数为正时相角条件与常规根轨迹相反，需先核对参数符号再画
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以待求参数为变量整理等效开环传函并绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由参数根轨迹分析参数变化对稳定性和动态性能的影响
本卷实例
  • 关键一步：找根轨迹与虚轴的交点得到临界参数，据此划分稳定区间
  • 中间结果：稳定区内参数变化时主导极点沿根轨迹移动，动态指标随之改变
  • 卡点：参数超出稳定区间后根轨迹进入右半平面，动态分析需先限定参数范围
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由参数根轨迹分析参数变化对稳定性和动态性能的影响
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

4四、由频率特性值求参数与奈氏判据#

思路
  • 把给定频率代入开环频率特性，按实部虚部分别与题给值对应求出对象参数；再画奈奎斯特曲线，数清右半平面极点数与包围临界点的圈数，用奈氏判据求使闭环稳定的增益范围。
频率特性的物理意义与求法 频域分析
本卷考法
  • 由指定频率处的开环频率特性值反求对象时间常数
本卷实例
  • 关键一步：把给定频率代入频率特性并分成实部与虚部，与给定值对应列方程
  • 中间结果：实部方程与虚部方程分别确定两个正时间常数
  • 卡点：分母含负实极点，代入后虚部符号容易写错，需按标准形式核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法

8八、对偶系统与全维状态观测器#

思路
  • 按对偶关系取各矩阵的转置写出对偶系统并求其传递函数；由能观性判别矩阵判断全维观测器可配置的条件；最后用对偶原理把观测器设计转化为对偶系统的状态反馈设计。
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 求对偶系统的传递函数
本卷实例
  • 关键一步：按对偶关系取系统矩阵的转置，输入矩阵与输出矩阵互换
  • 中间结果：对偶系统传函由输出矩阵转置、状态矩阵转置的预解式与输入矩阵转置相乘得到
  • 卡点：对偶系统输入输出矩阵互换，分子分母容易写反，需按传递函数定义核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
