1一、结构图传函与扰动不变性条件#

思路
  • 由结构图用梅森增益公式求输出对输入的传递函数；再令参考输入为零求输出对扰动的传递函数，令其分子为零得到扰动不变性条件。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求多回路系统输出对输入的传函
本卷实例
  • 关键一步：找出全部前向通路、回路与不接触回路后套梅森公式
  • 中间结果：特征式为 1+G1G2H1+G2G3H2+G1G2G3+G1
  • 卡点：回路数较多，不接触回路的余子式容易写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求多回路系统输出对输入的传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求扰动到输出的传递函数并令其为零
本卷实例
  • 关键一步：求扰动传函时把参考输入置零，只保留扰动通道
  • 中间结果：扰动到输出的传函分子为 1+G1G2H1 形式
  • 卡点：不变性条件来自分子为零，不是分母为零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求扰动到输出的传递函数并令其为零
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

2二、根轨迹绘制及增益变化的影响#

思路
  • 由开环极点和渐近线画根轨迹，求分离点与复数极点的出射角，再由与虚轴交点定临界增益，最后分析闭环响应形态随增益的变化。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制开环传函的根轨迹
本卷实例
  • 关键一步：由极点分布定实轴段、渐近线与分支数
  • 中间结果：极点为 0、−3±j，渐近线交点为 −2、夹角为 ±60° 与 180°
  • 卡点：复数极点分支的起始方向要由出射角确定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制开环传函的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点
本卷实例
  • 关键一步：由各极点倒数之和为零列分离点方程
  • 中间结果：方程为 3d²+12d+10=0，解得 d 约 −1.184 与 −2.816
  • 卡点：两个分离点要分别判断对应的临界增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
出射角与入射角 根轨迹法
本卷考法
  • 求复数极点的出射角并确定起始方向
本卷实例
  • 关键一步：对复数极点用相角条件累加其他零极点的相角
  • 中间结果：出射角约为负 71.57°，另一极点由对称性得正 71.57°
  • 卡点：相角累加时不能把该极点自身的相角算进去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求复数极点的出射角并确定起始方向
  • 求复数极点的出射角
  • 根据出射角画出根轨迹起始方向
  • 由入射角确定根轨迹终止方向
常见易错
  • 累加相角时把该极点自身的相角也算进去
  • 忘记判断象限导致角度差 180°
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界增益
本卷实例
  • 关键一步：用劳斯表首列元素为零求临界增益与交点频率
  • 中间结果：临界增益为 60，交点为正负 j 根号10，闭环等幅振荡
  • 卡点：增益超过临界值后系统不稳定，结论要与根轨迹分支对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 分析随增益增大闭环主导极点与响应形态的变化
本卷实例
  • 关键一步：按增益区间讨论实极点与共轭极点的相互转换
  • 中间结果：中间一段共轭极点重新出现并逐渐成为主导极点
  • 卡点：分段点的增益由分离点与虚轴交点确定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过分析随增益增大闭环主导极点与响应形态的变化
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

3三、由时域响应曲线定校正环节与传函#

思路
  • 由调节时间与超调量定标准二阶系统的参数，再由三条响应曲线的稳态值与振荡强弱判断所加环节类型，最后由稳态值反解环节参数并写出三个系统的传递函数。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由超调量与调节时间确定标准二阶系统参数
本卷实例
  • 关键一步：由超调量公式反解阻尼比，再由调节时间定自然频率
  • 中间结果：超调量 16.3% 对应阻尼比约 0.5，结合调节时间 1s 定自然频率
  • 卡点：调节时间的误差带取 5% 还是 2%，系数不同，要先确认
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由超调量与调节时间确定标准二阶系统参数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由三条响应曲线比较系统的动态性能
本卷实例
  • 关键一步：由稳态值与振荡强弱判断附加环节对高频分量的作用
  • 中间结果：微分环节放大高频使振荡加强，惯性环节抑制高频
  • 卡点：要同时看稳态值和振荡形态，不能只看一个
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由三条响应曲线比较系统的动态性能
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由响应曲线稳态值反求校正环节参数
本卷实例
  • 关键一步：由终值定理令稳态输出等于曲线读出的稳态值
  • 中间结果：微分环节参数为 1.5、惯性环节参数为 2
  • 卡点：惯性环节传递函数的直流增益为 1/b，不要漏掉
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由响应曲线稳态值反求校正环节参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 写出三种校正情形的闭环传递函数
本卷实例
  • 关键一步：把附加环节与标准二阶系统串联后写闭环传函
  • 中间结果：三个传函分别为原系统乘 1、(s+1.5)、1/(s+2)
  • 卡点：附加环节位置不同，闭环零点分布也不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过写出三种校正情形的闭环传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

4四、含右半平面零极点的奈氏判据#

思路
  • 画开环传函的极坐标图，求曲线与负实轴的交点，按右半平面极点数与包围圈数求使系统稳定的增益范围。
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈氏判据求使系统稳定的增益范围
本卷实例
  • 关键一步：先数开环右半平面极点数，再让交点位于临界点右侧
  • 中间结果：曲线交点为 −Kg/3，稳定条件为 Kg>3
  • 卡点：右半平面极点数为 2，稳定要求包围圈数为 1，不能按 0 处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈氏判据求使系统稳定的增益范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围

  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反

频率特性的物理意义与求法 频域分析
本卷考法
  • 求开环幅频与相频表达式并求与负实轴的交点
本卷实例
  • 关键一步：把 G(jω) 有理化后分离实部与虚部，令虚部为零
  • 中间结果：ω=2根号2 时曲线与负实轴相交于 −Kg/3
  • 卡点：分母展开后含右半平面极点，须按非最小相位处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求开环幅频与相频表达式并求与负实轴的交点
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

最小相位系统与非最小相位系统 频域分析
本卷考法
  • 说明非最小相位系统奈氏分析的注意事项
本卷实例
  • 关键一步：区分右半平面极点与右半平面零点对相频的影响
  • 中间结果：相频整体抬高，包围关系与最小相位系统不同
  • 卡点：非最小相位系统不能只用幅频判断稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过说明非最小相位系统奈氏分析的注意事项
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈

5五、Bode 图与极坐标图定校正环节#

思路
  • 由开环 Bode 图的低频段高度与转折频率定开环传函；由校正装置极坐标图的低频与高频模值定其传函，再判断校正类型并说明其作用。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环 Bode 图反求系统传递函数
本卷实例
  • 关键一步：由低频段以 −20dB/dec 过点高度定增益，再按转折频率配环节
  • 中间结果：开环传函为 25/[s(s+1)(s/50+1)]
  • 卡点：转折频率处斜率变化要逐段累加，不能只看末段
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环 Bode 图反求系统传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

稳定裕度 频域分析
本卷考法
  • 由校正装置极坐标图求其传函
本卷实例
  • 关键一步：由低频与高频两个幅值条件联立定校正装置参数
  • 中间结果：校正装置为 4(s+a)/(s+4a)，a 为任一正常数
  • 卡点：低频模值给出直流增益，高频模值给出高频增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由校正装置极坐标图求其传函
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

超前校正 系统校正
本卷考法
  • 判断校正类型并说明其作用
本卷实例
  • 关键一步：由校正装置零极点位置判断为超前校正
  • 中间结果：超前校正补足相角裕度并提高截止频率
  • 卡点：超前校正对低频段无影响，故不改善稳态性能
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过判断校正类型并说明其作用
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
