1一、结构图稳态误差与前馈补偿#

思路
  • 先由结构图分别求参考输入与扰动输入到误差的传函，判断稳定性后用终值定理求阶跃稳态误差；第二问令扰动误差为零解出 τ 条件。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由结构图内环向外环化简求误差传函
本卷实例
  • 关键一步：先合并内环反馈得到等效前向通道
  • 中间结果：误差传函分母为统一闭环特征多项式
  • 卡点：结构图为原卷插图，反馈极性与输入点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由结构图内环向外环化简求误差传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 单位阶跃输入下用终值定理求稳态误差
本卷实例
  • 关键一步：先判稳，再把输入变换与误差传函相乘取极限
  • 中间结果：阶跃输入下误差为误差传函的直流增益
  • 卡点：题面 H(s) 取值 OCR 有歧义，需按答案段自洽口径回原卷确认
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过单位阶跃输入下用终值定理求稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

扰动作用下的稳态误差 稳态误差
本卷考法
  • 扰动单独作用时令参考输入为零求误差
本卷实例
  • 关键一步：求扰动到误差的传函并取零频极限
  • 中间结果：令稳态误差为零可解出补偿参数条件
  • 卡点：扰动误差与输入误差传函不同，不能共用同一分子
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过扰动单独作用时令参考输入为零求误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

  • 中间结果：两路传函分母相同，分子随作用点变化
  • 卡点：叠加前需确认系统为线性系统

2二、等幅振荡瞬态分量求参数#

思路
  • 由闭环特征方程列劳斯表，等幅振荡对应首列出现零并用辅助方程给出振荡频率，再联立参数条件求出 a 与 K。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯表辅助方程确定等幅振荡时的参数关系
本卷实例
  • 关键一步：由闭环特征方程列劳斯表并令首列出现零
  • 中间结果：用零元素行的辅助方程求振荡频率
  • 卡点：辅助方程仅给出频率，参数还需代回零元素条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯表辅助方程确定等幅振荡时的参数关系
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由参数满足的临界条件反求 a 与 K
本卷实例
  • 关键一步：把频率条件代入辅助方程消去一个参数
  • 中间结果：参数关系化为可联立的代数方程
  • 卡点：稳定域端点与振荡点不同，不能把大于零条件误当等式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由参数满足的临界条件反求 a 与 K
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由等幅振荡分量判断系统存在一对纯虚闭环极点
本卷实例
  • 关键一步：等幅振荡对应阻尼比为零的一对共轭极点
  • 中间结果：振荡角频率即该对纯虚极点的虚部
  • 卡点：系统为三阶，等幅振荡只说明存在一对纯虚根，不能直接按二阶系统套公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由等幅振荡分量判断系统存在一对纯虚闭环极点
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

3三、由相频表达式反求传函与根轨迹#

思路
  • 由相频表达式逐项对应典型环节还原开环传函，再按零极点分布画根轨迹、求分离点，并用劳斯判据判断增益为正时是否恒稳定。
频率特性的物理意义与求法 频域分析
本卷考法
  • 由相频表达式反推开环传函的典型环节组成
本卷实例
  • 关键一步：把各 arctan 项与积分环节的九十度滞后对应到典型环节
  • 中间结果：分子零点项给出超前相角，分母极点项给出滞后相角
  • 卡点：最小相位条件下正切项才能唯一对应零极点位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由相频表达式反推开环传函的典型环节组成
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
典型环节的对数频率特性 频域分析
本卷考法
  • 按典型环节相频叠加还原开环传函
本卷实例
  • 关键一步：逐项识别惯性、比例与积分环节
  • 中间结果：各环节时间常数由 arctan 内系数倒数确定
  • 卡点：多个环节的相角叠加，漏掉积分环节会整体差九十度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例环节是水平线，积分与微分分别是 -20 与 +20 dB/dec 的斜线
  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec
  • 一阶微分环节与惯性环节幅频互为镜像
  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤
  • 把传递函数分解为典型环节乘积
  • 逐环节画出对数幅频渐近线与相频曲线
  • 代数相加得到总特性
通用考法
  • 本卷考过按典型环节相频叠加还原开环传函
  • 画出某一典型环节的 Bode 图
  • 由 Bode 图识别环节类型
  • 说明转角频率处的幅值与相角
常见易错
  • 把惯性环节高频渐近线的 -20 写成 -40
  • 振荡环节谐振峰位置误当作 ωn

根轨迹的绘制法则 根轨迹法
本卷考法
  • 按零极点分布绘制根轨迹并确定实轴段
本卷实例
  • 关键一步：数实轴段右侧零极点个数判断根轨迹归属
  • 中间结果：零极点个数相同则无渐近线
  • 卡点：开环零点位于左半平面时根轨迹分支走向需按区段判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按零极点分布绘制根轨迹并确定实轴段
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

4四、含右半平面极点系统的奈氏判据#

思路
  • 先数开环右半平面极点数并画奈氏曲线，再按包围临界点的圈数用判据公式判断闭环根分布，最后写出增益 K 的取值范围。

8八、对偶系统、能控能观与状态反馈观测器#

思路
  • 先求原系统与对偶系统传函，再分别构造能控、能观判别阵判断系统性质；最后按期望极点设计状态反馈与全维观测器。
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 求原系统与对偶系统的传递函数
本卷实例
  • 关键一步：对两个系统分别按传递函数定义作矩阵运算
  • 中间结果：单入单出时对偶系统与原系统传递函数相同
  • 卡点：对偶系统的输入输出矩阵互换，算式容易写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法

  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
