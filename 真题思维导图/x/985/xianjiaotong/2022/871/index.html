1一、由方块图求等幅振荡参数#

思路
  • 由方块图写闭环特征方程，等幅振荡对应特征根为纯虚根，用劳斯表某行首列为零和辅助方程求参数与振荡角频率
劳斯判据 稳定性分析
本卷考法
  • 由等幅振荡条件用劳斯判据求系统参数与振荡频率
本卷实例
  • 关键一步：由方块图写出闭环特征方程并列劳斯表
  • 中间结果：首列某行为零时取上一行写辅助方程，其根即纯虚根
  • 卡点：方块图以图给出，前向与反馈通路需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由等幅振荡条件用劳斯判据求系统参数与振荡频率
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

2二、由方块图求斜坡零误差参数#

思路
  • 由方块图求误差传递函数，按斜坡输入用终值定理写稳态误差表达式，令其为零解出待定参数
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由方块图求斜坡输入下稳态误差为零的参数条件
本卷实例
  • 关键一步：先用梅森公式写误差传函E(s)比R(s)
  • 中间结果：斜坡稳态误差由误差传函分子中s的零次项决定
  • 卡点：方块图以图给出，前馈支路接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由方块图求斜坡输入下稳态误差为零的参数条件
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、由阶跃与正弦响应求传函#

思路
  • 设二阶系统标准传函，由单位阶跃稳态输出定增益，由正弦输入的幅值放大与相移定阻尼比与自然频率，再算调节时间
频率特性的物理意义与求法 频域分析
本卷考法
  • 由正弦输入的稳态输出求系统频率特性参数
本卷实例
  • 关键一步：把正弦输出写成输入幅值乘幅频、相角加相频
  • 中间结果：输出幅值为输入的根号2倍、相角滞后90度
  • 卡点：二阶无零点系统稳态输出等于直流增益乘输入幅值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由正弦输入的稳态输出求系统频率特性参数
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由频域条件反求阻尼比与自然频率
本卷实例
  • 关键一步：令频率特性实部与虚部分别等于输出相量的实虚部
  • 中间结果：解出自然频率与阻尼比两个参数
  • 卡点：相角为负90度说明频率特性实部为零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由频域条件反求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率算调节时间
本卷实例
  • 关键一步：按5%误差带公式计算调节时间
  • 中间结果：调节时间与阻尼比和自然频率的乘积成反比
  • 卡点：串联比例环节不改变动态性能，不要重复计入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率算调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

4四、根轨迹与超调量约束求增益#

思路
  • 由开环传函画根轨迹，求分离点、出射角与与虚轴交点，据此得稳定增益范围；再由超调量要求定阻尼比下限，在根轨迹上求对应增益
根轨迹的绘制法则 根轨迹法
本卷考法
  • 画含右半平面开环极点的根轨迹（第(1)问）
本卷实例
  • 关键一步：标出三个开环极点并判断实轴上根轨迹区间
  • 中间结果：根轨迹关于实轴对称，有分离点与两条出射角
  • 卡点：一个开环极点在右半平面，根轨迹起点不全稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过画含右半平面开环极点的根轨迹（第(1)问）
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点求稳定增益范围（第(2)问）
本卷实例
  • 关键一步：列劳斯表求辅助方程对应的临界增益与交点频率
  • 中间结果：使首列变号的增益即稳定上界
  • 卡点：还有另一个使根落在原点的临界值要一并判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹与虚轴交点求稳定增益范围（第(2)问）
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由超调量要求确定增益范围（第(3)问）
本卷实例
  • 关键一步：把超调量换算成阻尼比下限再定阻尼角
  • 中间结果：阻尼角边界与根轨迹的交点对应所求增益
  • 卡点：阻尼比大于下限时增益落在两个临界值之间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由超调量要求确定增益范围（第(3)问）
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

5五、由Bode图求传函与相角裕量#

思路
  • 由低频段斜率与高度辨识积分环节与开环增益，由转折频率辨识一阶与二阶环节，再算截止频率与相角裕量并分析增益影响
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环对数幅频特性曲线反求传递函数（第(1)问）
本卷实例
  • 关键一步：由低频段斜率定环节个数、由高度定开环增益
  • 中间结果：转折频率处斜率的变化对应一阶或二阶环节
  • 卡点：幅频曲线以图给出，转折频率需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环对数幅频特性曲线反求传递函数（第(1)问）
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 求截止频率处的相角裕量（第(2)问）
本卷实例
  • 关键一步：令开环幅值等于1求截止频率再代相频
  • 中间结果：相角裕度等于180度加截止频率处相角
  • 卡点：二阶环节相角要按阻尼比代入而非直接取180度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求截止频率处的相角裕量（第(2)问）
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 分析开环增益对相角裕量的影响并求稳定增益边界（第(3)问）
本卷实例
  • 关键一步：由闭环特征方程列劳斯表求稳定增益边界
  • 中间结果：相角裕度随增益增大先增后减
  • 卡点：稳定增益最值来自劳斯判据的边界条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过分析开环增益对相角裕量的影响并求稳定增益边界（第(3)问）
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

6六、状态响应恒零条件#

思路
  • 先求状态转移矩阵，按状态方程解写含初始状态与输入的系统输出，令各模态系数同时为零解出输入参数与初始状态
状态转移矩阵 状态空间分析
本卷考法
  • 由状态转移矩阵与指数输入求输出恒零的条件
本卷实例

  • 中间结果：输出按不同衰减率展开为三个指数模态之和
