1一、使扰动对输出无影响的补偿条件#

思路
  • 由结构图分别写出参考输入与扰动到输出的传递函数，令扰动传函的分子为零，解出使扰动不影响输出的补偿环节。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求扰动到输出的传递函数并令其为零
本卷实例
  • 关键一步：求扰动传函时把参考输入置零，只保留扰动通道
  • 中间结果：令扰动到输出的传函分子为零解出补偿环节表达式
  • 卡点：多回路时要注意哪些回路与扰动前向通路不接触
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求扰动到输出的传递函数并令其为零
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求多回路系统传递函数
本卷实例
  • 关键一步：先列全部回路与前向通路，再写特征式和余子式
  • 中间结果：特征式为 1+G1G2+G1G2G4+G1G3G4
  • 卡点：无互不接触回路时余子式取值要逐一核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求多回路系统传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、由相频表达式反求传函与阶跃响应#

思路
  • 把题给分段相频表达式与一阶微分、惯性、二阶振荡的标准相频逐项对照定参数，再由给定频率处的幅值条件定增益，最后求单位阶跃响应的稳态值与最大值。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由相频表达式反求系统传递函数
本卷实例
  • 关键一步：按标准环节相频拆项，与题给分段式逐项比对定参数
  • 中间结果：解得 T1=1.1、T2=1、ξ=根号2/2、ωn=2根号2
  • 卡点：分段点在 ωn 处，属二阶振荡环节反正切的分支切换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由相频表达式反求系统传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
最小相位系统与非最小相位系统 频域分析
本卷考法
  • 判断最小相位系统并说明幅频与相频的对应关系
本卷实例
  • 关键一步：先由最小相位条件排除右半平面零极点
  • 中间结果：最小相位系统幅频与相频一一对应
  • 卡点：非最小相位系统幅频相同而相频不同，不能只凭幅频定传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过判断最小相位系统并说明幅频与相频的对应关系
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位阶跃输入下的稳态值
本卷实例
  • 关键一步：在稳定前提下由终值定理对闭环输出取 s 趋于 0 极限
  • 中间结果：稳态值等于闭环传函的直流增益
  • 卡点：必须先用劳斯判据确认闭环稳定再用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位阶跃输入下的稳态值
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求单位阶跃响应的最大值
本卷实例
  • 关键一步：对输出像函数作部分分式反变换后求导，令导数为零求峰值时刻
  • 中间结果：峰值由各衰减模态在峰值时刻叠加取值决定
  • 卡点：闭环含微分环节与零点，不能直接套标准二阶峰值公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求单位阶跃响应的最大值
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3三、根轨迹反求开环传函与参数范围#

思路
  • 由给出的根轨迹极点位置与渐近线方向反推开环传函；引入校正时间常数后重写闭环特征方程，用劳斯判据和稳态误差要求确定参数范围。
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹图反推开环传函并分析增益变化的影响
本卷实例
  • 关键一步：由根轨迹起点定开环极点、由渐近线方向判断根轨迹类型
  • 中间结果：开环极点为 −5、1、1，开环传函为 1/[(s+5)(s−1)²]
  • 卡点：根轨迹从右半平面极点出发，稳定性随增益变化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹图反推开环传函并分析增益变化的影响
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 引入校正环节后按参数根轨迹重新列特征方程
本卷实例
  • 关键一步：把含校正参数的项整理成参数形式再分析根轨迹
  • 中间结果：闭环特征式为 s³+3s²+(Kτ−9)s+(5+K)
  • 卡点：参数与增益同时出现，稳定域要分情况讨论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过引入校正环节后按参数根轨迹重新列特征方程
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位阶跃稳态误差要求反解开环增益
本卷实例
  • 关键一步：写出稳态误差表达式并令不等式成立
  • 中间结果：稳态误差为 5/(5+K)，解得 K 不小于 15
  • 卡点：解得的增益还须同时满足劳斯稳定条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位阶跃稳态误差要求反解开环增益
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据确定增益与校正参数的稳定范围
本卷实例
  • 关键一步：列劳斯表并令首列各项同号
  • 中间结果：稳定条件含 K>0 且 τ 大于 (32+K)/(3K) 等分支
  • 卡点：增益正负分两支讨论，最后结论要取交集
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据确定增益与校正参数的稳定范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

4四、含右半平面开环极点的奈氏判据#

思路
  • 画非最小相位开环的极坐标图，求曲线与负实轴的交点，按右半平面极点数与包围圈数求稳定条件；再由围线关系判断不稳定时右半平面闭环极点的个数。
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈氏判据求使系统稳定的参数范围
本卷实例
  • 关键一步：先数开环右半平面极点数，再令曲线不包围临界点
  • 中间结果：曲线与负实轴交于 −T1，稳定条件为 0<T1<1
  • 卡点：分子为非最小相位，ω 趋于 0 时相角从 90° 出发
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈氏判据求使系统稳定的参数范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求非最小相位开环的幅频与相频表达式
本卷实例
  • 关键一步：把 G(jω) 有理化后分离实部与虚部
  • 中间结果：实部为 −(T1+T2)/(1+(T2ω)²)，虚部含 1−T1T2ω²
  • 卡点：分子含右半平面零点的相角要写成 180° 减反正切形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤

5五、Bode 图反求传函与运放校正装置#

思路
  • 由低频段斜率与高度定增益及转折频率，写出开环传函；再按理想运放的复阻抗关系求校正装置传函，比较校正前后的裕度与增益并说明其作用。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环 Bode 图反求系统传递函数
本卷实例
  • 关键一步：由低频段斜率和过点高度定型别与增益，再按转折频率配环节
  • 中间结果：开环传函为 10(s/2+1)/[s(s+1)(s/20+1)]
  • 卡点：截止频率与转折频率要分别识别，不能混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环 Bode 图反求系统传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

开环对数频率特性的绘制 频域分析
本卷考法
  • 画校正后系统的开环 Bode 图
本卷实例
  • 关键一步：把校正装置与开环传函相乘后逐段叠加斜率
  • 中间结果：校正后开环相当于原特性整体抬高了分贝数
  • 卡点：比例放大只抬高度、不改变转折频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积

常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
