1一、多回路结构图与等效单位反馈#

思路
  • 先由结构图回路与前向通路求闭环传递函数，再由特征多项式判断稳定；最后把等效单位反馈的开环传函化为标准形式，按无差度阶数为 2 比较系数得 τ、b 条件。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式由结构图求闭环传递函数
本卷实例
  • 关键一步：标出各回路增益与前向通路并判断是否两两接触
  • 关键一步：按梅森公式写分母与各前向通路的余子式
  • 中间结果：闭环特征多项式由回路增益与不接触回路项组成
  • 中间结果：前向通路两条分别对应参考输入到输出的两条通道
  • 卡点：结构图为原卷插图，回路极性与增益位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式由结构图求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由含局部反馈的结构图逐层化简求闭环传函
本卷实例
  • 关键一步：从最内层反馈环开始向外交替化简
  • 中间结果：内环化简后等效为惯性环节，再与外环合并
  • 卡点：化简内环时外环信号不能当常数，需保留变量符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由含局部反馈的结构图逐层化简求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
系统型别与静态误差系数 稳态误差
本卷考法
  • 由等效单位反馈开环传函判断系统无差度阶数
本卷实例
  • 关键一步：把等效开环传函化为分子分母多项式之比
  • 关键一步：数分母中积分环节个数确定无差度阶数
  • 中间结果：无差度阶数由等效开环传函分母的 s 幂次决定
  • 卡点：题目要求对等效单位反馈判断，不能直接对原结构图套型别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由等效单位反馈开环传函判断系统无差度阶数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据列出闭环稳定时参数需满足的条件
本卷实例
  • 关键一步：由闭环特征多项式列劳斯表并令首列各项大于零
  • 中间结果：参数条件写成关于时间常数与增益的不等式组
  • 卡点：无差度条件与稳定条件需同时成立，不能只取其中一个
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据列出闭环稳定时参数需满足的条件
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

2二、参考输入与扰动同时作用下的稳态误差#

思路
  • 分别求 E/R 与 E/N 两个误差传函，先确认闭环稳定，再用终值定理把斜坡输入与阶跃扰动两路误差分量相加。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求参考输入与扰动输入到误差的传递函数
本卷实例
  • 关键一步：令另一路输入为零，分别列写 E/R 与 E/N
  • 中间结果：两路误差传函分母相同，分子随作用点变化
  • 卡点：结构图含两条输入通道，不能跳过分别求传函直接相加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求参考输入与扰动输入到误差的传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 按单位负反馈误差定义写出误差传递函数
本卷实例
  • 关键一步：先明确误差取参考输入与反馈信号之差
  • 中间结果：误差传函可用前向通路与回路增益表示
  • 卡点：非单位反馈时误差定义会差一个反馈环节，需按题面结构确认
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过按单位负反馈误差定义写出误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 在斜坡输入下用终值定理求稳态误差
本卷实例
  • 关键一步：将输入拉氏变换与误差传函相乘再令 s 趋于零
  • 中间结果：稳态误差由误差传函在零点的极限确定
  • 卡点：必须先确认闭环稳定，否则终值定理不适用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过在斜坡输入下用终值定理求稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

  • 求扰动引起的稳态误差

  • 求扰动传函时没有把参考输入置零

3三、根轨迹与闭环主导极点#

思路
  • 由单位斜坡稳态误差为常数且无闭环零点判定系统为 Ⅰ 型，补出开环增益；再画根轨迹并用幅值条件求指定闭环极点对应的参数，最后由主导极点近似求动态指标。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按开环零极点分布绘制根轨迹并确定实轴段
本卷实例
  • 关键一步：数实轴段右侧零极点个数判断根轨迹归属
  • 关键一步：由零极点个数差确定渐近线交点与夹角
  • 中间结果：实轴根轨迹分为两段，渐近线与实轴交于负三分之七
  • 卡点：题目未直接给开环传函，需先由稳态误差条件补出增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按开环零极点分布绘制根轨迹并确定实轴段
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 用分离点方程求根轨迹的分离点坐标
本卷实例
  • 关键一步：对闭环特征方程解 dK/ds 为零的方程
  • 中间结果：两个解中只有落在实轴根轨迹段上的那个有效
  • 卡点：分离点方程的解需按根轨迹区段筛选，不能全部保留
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过用分离点方程求根轨迹的分离点坐标
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 用劳斯表辅助方程求根轨迹与虚轴交点
本卷实例
  • 关键一步：令劳斯表首列出现零并写出辅助方程
  • 中间结果：辅助方程的纯虚根给出临界频率与临界增益
  • 卡点：交点代回特征方程核对后再用于画图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过用劳斯表辅助方程求根轨迹与虚轴交点
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 由闭环主导极点把三阶系统降为二阶近似
本卷实例
  • 关键一步：比较各闭环极点实部，保留靠近虚部的共轭极点
  • 中间结果：远极点与零点近似对消后可用二阶公式估算
  • 卡点：仅凭实部距离不足以判定偶极子，还需看留数大小
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过由闭环主导极点把三阶系统降为二阶近似
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
