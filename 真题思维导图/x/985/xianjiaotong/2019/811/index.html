1一、船舵随动系统的组成与工作原理#

思路
  • 按随动系统的基本组成指认给定量、被控对象、被控量与各功能元件，再画方块图并说明工作过程。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指认随动系统的被控量、被控对象与各组成元件
本卷实例
  • 关键一步：按给定—比较—放大—执行—被控对象顺序指认
  • 中间结果：被控对象为船舵、被控量为船舵转角
  • 卡点：测量元件与比较元件是两类元件，不要混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指认随动系统的被控量、被控对象与各组成元件
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 画出船舵位置随动系统的闭环方块图
本卷实例
  • 关键一步：把自整角机电压差作为误差信号画入闭环
  • 中间结果：回路含操纵杆、电位计组、放大器、电机与船舵
  • 卡点：方块图信号流向须与物理工作过程一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过画出船舵位置随动系统的闭环方块图
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、二阶系统特征根分布区域与性能指标#

思路
  • 由超调量要求反解阻尼比范围并在 s 平面画特征根区域；再由调节时间定 ωn 下界，最后写 tr、tp 与根的关系。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函写标准二阶形式并在 s 平面标极点
本卷实例
  • 关键一步：把闭环传函与标准二阶对照得 ωn 与 ξ 的表达式
  • 中间结果：特征根实部为 −ξωn、虚部为 ±ωn√(1−ξ²)
  • 卡点：超调量要求对应阻尼角边界，而非实部边界
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函写标准二阶形式并在 s 平面标极点
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与调节时间要求确定特征根分布区域
本卷实例
  • 关键一步：ξ 由超调量定、ωn 由调节时间定，共同约束极点
  • 中间结果：σ%=16.3% 对应 ξ=1/2，ts≤5s 对应 ωn 下界
  • 卡点：ξ≥1 时无超调，仍满足小超调量要求，不要漏掉
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与调节时间要求确定特征根分布区域
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由闭环极点写出上升时间与峰值时间的表达式
本卷实例
  • 关键一步：用 ωd 与 ωn 表示 tr、tp，再代入极点坐标
  • 中间结果：tr 与 tp 均与极点虚部成反比
  • 卡点：tr 公式分子是 π−β，不要写成 π
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由闭环极点写出上升时间与峰值时间的表达式
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式

3三、由极坐标图求参数与奈氏判稳#

思路
  • 由极坐标图的起点与负虚轴交点反求开环传函，按最小相位系统用奈氏判据判稳，再串入积分环节重判。
频率特性的物理意义与求法 频域分析
本卷考法
  • 由极坐标图的特征点反求开环频率特性
本卷实例
  • 关键一步：由 G(j0) 与 G(j∞) 的相角定积分环节数与阶数
  • 中间结果：开环可设为 K/[(s/ωn)²+2ξ(s/ωn)+1]
  • 卡点：G(j1)=−j2 同时给出实部为零与虚部大小两条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由极坐标图的特征点反求开环频率特性
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈氏判据判断最小相位系统稳定性
本卷实例
  • 关键一步：先由最小相位得 P=0，再数包围临界点的圈数
  • 中间结果：原系统 N+=N−=0，故无右半平面闭环极点
  • 卡点：串入积分环节后曲线起点相角改变，包围圈数随之变化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈氏判据判断最小相位系统稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
最小相位系统与非最小相位系统 频域分析
本卷考法
  • 说明最小相位条件对奈氏判稳的作用
本卷实例
  • 关键一步：由题给最小相位条件确认可用幅相曲线直接判稳
  • 中间结果：P=0 时只需看曲线是否包围临界点
  • 卡点：非最小相位时不能只凭幅频曲线判稳
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过说明最小相位条件对奈氏判稳的作用
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈

4四、含参根轨迹与等实部极点条件#

思路
  • τ=0 时按法则画根轨迹并求分离点与临界增益；τ≠0 时由三极点等实部的多项式恒等关系求 K、τ 条件。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制含三重极点的开环传函根轨迹
本卷实例
  • 关键一步：由极点分布定实轴段与三条渐近线
  • 中间结果：渐近线交点为 −4，夹角为 ±60° 与 180°
  • 卡点：重极点处根轨迹分支起始方向要单独判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制含三重极点的开环传函根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求分离点并筛除不在根轨迹上的解
本卷实例
  • 关键一步：由分离点方程的解逐一验证是否位于实轴段
  • 中间结果：分离点方程化简后只有一个实根
  • 卡点：该根落在实轴段右侧故舍去，说明无分离点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求分离点并筛除不在根轨迹上的解
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由劳斯表求根轨迹与虚轴交点及临界增益
本卷实例
  • 关键一步：令劳斯表首列出现全零行，用辅助方程求纯虚根
  • 中间结果：临界增益下辅助方程给出对称纯虚根
  • 卡点：纯虚根对应等幅振荡，是稳定边界而非稳定区
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由劳斯表求根轨迹与虚轴交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由三极点等实部的根分布反求参数关系
本卷实例
  • 关键一步：把等实部极点写成 (s+a)(s²+2as+a²+b²) 再比系数
  • 中间结果：由 s² 项系数直接定出 a，再联立其余两式
  • 卡点：b=0 的全实极点情形是复极点情形的特例
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由三极点等实部的根分布反求参数关系
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错

5五、由三张 Bode 图比较系统性能#

思路
  • 由低频段斜率与转折频率写三个开环传函，比较截止频率与相角裕度，再定性比较动态指标与斜坡稳态误差。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由 Bode 图低频段斜率与转折频率反求开环传函
本卷实例
  • 关键一步：由低频段斜率定系统型别，由转折频率配环节
  • 中间结果：I、II 为一型系统，III 为二型系统

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节

  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数

稳定裕度 频域分析
本卷考法
  • 比较三个系统的截止频率与相角、幅值裕度
本卷实例
  • 关键一步：由幅频高低与相频是否穿越 −180° 比较裕度
  • 中间结果：I、II 相频不达 −180°，故幅值裕度为无穷
  • 卡点：III 在 ω 趋于 0 处就已取 −180°，穿越频率在原点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过比较三个系统的截止频率与相角、幅值裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由系统型别比较斜坡输入下的稳态误差
本卷实例
  • 关键一步：一型系统斜坡误差与开环增益成反比，二型为零
  • 中间结果：由低频段高度比较两个一型系统的开环增益
  • 卡点：须先确认闭环稳定才能用静态误差系数法
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由系统型别比较斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

本卷考法

本卷实例
  • 关键一步：用频域与时域指标的近似关系作定性判断

  • 带宽频率 ωb 越大响应越快但抗噪能力下降

  • 本卷考过由频域指标定性比较超调量与调节时间

  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
