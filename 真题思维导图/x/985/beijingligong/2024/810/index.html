1一、电路系统建模15 分#

思路
  • 由图1的RLC电路按伏安关系列微分方程；取零初始拉氏变换求传函；再以电感电流和电容电压为状态写状态空间模型。题面含图未读图。
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由RLC电路的伏安关系建立微分方程
本卷实例
  • 关键一步：按电容电流等于电容乘电压导数、电感电压等于电感乘电流导数列方程
  • 关键一步：消去支路电流与中间电压，整理成输出对输入的微分方程
  • 中间结果：微分方程最高含输出的二阶导数，输入也含一二阶导数
  • 卡点：电路图未读图，元件连接与电压电流正方向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由RLC电路的伏安关系建立微分方程
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由电路微分方程求输出对输入的传递函数
本卷实例
  • 关键一步：对微分方程取零初始条件下的拉氏变换
  • 关键一步：整理成输出与输入象函数之比
  • 中间结果：传函分子分母均为s的多项式，阶次由电路阶数决定
  • 卡点：把电容复阻抗误写成电容乘s；忽略零初始条件的前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由电路微分方程求输出对输入的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

状态空间表达式的建立 状态空间分析
本卷考法
  • 以电感电流与电容电压为状态写状态空间模型
本卷实例
  • 关键一步：状态个数取储能元件个数，对每个状态写一阶导数方程
  • 关键一步：按状态与输入整理成矩阵形式，再写输出方程
  • 中间结果：状态矩阵为二阶方阵，输出含输入直通项
  • 卡点：输出方程漏掉直通项；把支路电流也当成状态变量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过以电感电流与电容电压为状态写状态空间模型
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

2二、状态空间方法20 分#

思路
  • 由最小多项式求矩阵幂；用PBH判据与反证法证明分块系统的能控性命题；再由给定状态矩阵设计状态反馈，把闭环传函化为指定一阶形式。
状态转移矩阵 状态空间分析
本卷考法
  • 由最小多项式把矩阵幂展开成有限项（借位）
本卷实例
  • 关键一步：由最小多项式知A减二倍单位阵为幂零阵
  • 关键一步：把A写成二倍单位阵加幂零阵后按二项式展开
  • 中间结果：幂零阵的平方为零，高次幂展开式只剩两项
  • 卡点：本题是矩阵幂而非状态转移矩阵，属借位；幂零阶数由最小多项式次数决定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过由最小多项式把矩阵幂展开成有限项（借位）
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错
公式
能控性与能观性 状态空间分析
本卷考法
  • 用PBH判据与反证法证明分块系统的能控性命题
本卷实例
  • 关键一步：假设子系统不能控，取不满足PBH判据的左特征向量
  • 关键一步：把它扩充到全系统，导出与全系统能控矛盾
  • 中间结果：矛盾说明原假设不成立，命题得证
  • 卡点：分块维数与题给记号要一一对应；反证方向容易写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过用PBH判据与反证法证明分块系统的能控性命题
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
状态反馈与极点配置 状态空间分析
本卷考法
  • 设计状态反馈使闭环传函化为给定一阶形式
本卷实例
  • 关键一步：先判能控性，再设状态反馈增益阵
  • 关键一步：把闭环特征多项式与目标分母多项式比较系数
  • 中间结果：闭环极点由一组系数方程确定，增益阵可解出
  • 卡点：目标传函为一阶，需借重极点配置实现；比较系数时符号易错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过设计状态反馈使闭环传函化为给定一阶形式
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
公式

3三、根轨迹方法15 分#

思路
  • 开环传函含可变参数T，整理成以T为参数的等效开环后按根轨迹法则绘制；再由给定阻尼比在根轨迹上定位闭环极点，写出闭环传函。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以时间常数T为参数绘制广义根轨迹
本卷实例
  • 关键一步：把闭环特征方程整理成1加T乘等效开环等于0的形式
  • 关键一步：以T为可变参数按根轨迹法则绘图
  • 中间结果：等效开环的零点为原点、极点为一对共轭复根
  • 卡点：参数未完整提到分子位置；零度与一百八十度根轨迹条件用错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以时间常数T为参数绘制广义根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由给定阻尼比在根轨迹上定位极点并写闭环传函
本卷实例
  • 关键一步：由阻尼比算等阻尼线与负实轴的夹角
  • 关键一步：在根轨迹上与等阻尼线求交点得闭环极点
  • 中间结果：交点对应一组T与闭环极点，代入即得闭环传函
  • 卡点：等阻尼线画成垂直线；写闭环传函时漏掉分子
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由给定阻尼比在根轨迹上定位极点并写闭环传函
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式

4四、频率响应分析20 分#

思路
  • 开环传函含校正环节；先令校正环节为1，定出满足相角裕度的增益；再按串联滞后校正，用斜坡稳态误差与相角裕度要求联立求参数。
稳定裕度 频域分析
本卷考法
  • 由相角裕度条件求开环增益
本卷实例
  • 关键一步：令相频在截止频率处等于负一百八十度加给定裕度
  • 关键一步：再由该频率处幅值等于一解出增益
  • 中间结果：截止频率由相角方程单独解出，增益由幅值条件给出
  • 卡点：题面印裕度150度、答案段按50度算，150度对该开环不可实现，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由相角裕度条件求开环增益
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
滞后校正 系统校正
本卷考法
  • 用斜坡稳态误差与相角裕度要求设计串联滞后校正
本卷实例
  • 关键一步：先由斜坡稳态误差要求定开环增益
  • 关键一步：再按截止频率处幅值条件定滞后网络转折频率比
  • 中间结果：滞后网络两个转折频率分别落在截止频率两侧
  • 卡点：校正环节在截止频率外的相角滞后按题给取负五度；两转折频率顺序易写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过用斜坡稳态误差与相角裕度要求设计串联滞后校正
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环积分环节个数与增益写速度误差系数
本卷实例
  • 关键一步：数开环积分环节个数定系统型别
  • 关键一步：按型别写速度误差系数与增益的关系
  • 中间结果：斜坡稳态误差等于速度误差系数的倒数
  • 卡点：把开环增益与速度误差系数混同；漏数积分环节个数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由开环积分环节个数与增益写速度误差系数

  • 构造哈密顿函数（性能指标的被积函数加上协态与状态方程的乘积）
  • 由哈密顿函数对控制量取极值解出最优控制与协态的关系
  • 写出协态方程与边界条件，与状态方程联立
  • 求状态与协态的解析解，再回代得最优控制与最优轨线
通用考法
  • 本卷考过由终端约束与能量指标用极大值原理求最优控制与轨线
  • 用极大值原理求使性能指标极小的最优控制与最优轨线
  • 构造哈密顿函数并写出正则方程组
  • 判断终端约束对应的横截条件
常见易错
  • 终端自由时仍把协态终值取零以外的值，或反之错把终端固定当自由
  • 解出控制量后忘记回代状态方程验证
