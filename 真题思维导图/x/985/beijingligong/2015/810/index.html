一一、电路状态空间与传函#

思路
  • 由 KCL、KVL 列写含两电容一电感的电路方程，消去中间变量后以电容电压与电感电流为状态写状态空间式；第二问用复阻抗法求等效阻抗再化出电压传函。题面含图未读图。
状态空间表达式的建立 状态空间分析
本卷考法
  • 由电路图列写三阶状态空间表达式并证明给定矩阵
本卷实例
  • 关键一步：取两电容电压与电感电流为状态，按节点和回路列一阶方程
  • 关键一步：用题给矩阵求逆提示反解状态导数
  • 中间结果：三个储能元件决定系统为三阶
  • 中间结果：系数矩阵元素由两支路电阻电容与电感组合
  • 卡点：电容电流方向与电感电压极性取反；元件连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由电路图列写三阶状态空间表达式并证明给定矩阵
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

电路网络与有源网络建模 建模与机电系统
本卷考法

本卷实例

  • 关键一步：把等效阻抗代回含电感的回路求输出传函
  • 中间结果：等效阻抗分母为两支路串联阻抗之和
  • 中间结果：传函分子分母都含时间常数乘积形式
  • 卡点：复阻抗法把电容阻抗误写成 Cs；电路图未读需回原卷核对图

  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤

  • 用分压公式或节点电流方程列写关系

通用考法

  • 求运算电路的输出表达式
常见易错

  • 把反相输入的负号漏掉

二二、时域响应与动态性能#

思路
  • 先由给定开环写闭环二阶标准形式读阻尼比与自然频率，代入公式求单位阶跃响应、峰值时间与超调量；再用叠加定理处理错位叠加的两段阶跃，证明峰值后输出恒定。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由给定开环传函写闭环传函并化为标准二阶形式
本卷实例
  • 关键一步：按单位负反馈写闭环传函，再归一分母首项系数
  • 关键一步：与标准二阶式逐项对照读参数
  • 中间结果：分母一次项系数对应两倍阻尼比乘自然频率
  • 卡点：不先归一分母首项系数就直接读系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由给定开环传函写闭环传函并化为标准二阶形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求单位阶跃响应、峰值时间与超调量
本卷实例
  • 关键一步：欠阻尼阶跃响应按衰减振荡加稳态一写出
  • 关键一步：峰值时间由阻尼自然频率取派
  • 中间结果：超调量只由阻尼比决定，与自然频率无关
  • 卡点：把峰值时间与上升时间公式用反；超调量漏乘百分号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求单位阶跃响应、峰值时间与超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 用叠加定理证明两段错位阶跃叠加后输出恒定
本卷实例
  • 关键一步：把输入写成两条阶跃之和，分别求响应再叠加
  • 关键一步：利用给定比例关系消去衰减余项
  • 中间结果：两段响应的振荡项系数相消，稳态分量相加为一
  • 卡点：错位阶跃的时移符号写错；未验证系统线性即用叠加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过用叠加定理证明两段错位阶跃叠加后输出恒定
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

三三、零极点对消与能控能观#

思路
  • 由第一题电路传函在时间常数相等时出现零极点对消，用特征多项式代入验证指定特征值；再用 PBH 判据分别检验能控性与能观性，并由对消推断能观性被破坏。
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由传函零极点对消说明能控性与能观性之一被破坏
本卷实例
  • 关键一步：把时间常数相等条件代入状态矩阵，构造并化简特征多项式
  • 关键一步：代入指定的负倒数验证其满足特征方程
  • 中间结果：该负倒数确为状态矩阵的一个特征值
  • 卡点：把零极点对消直接当成能控能观全部丧失
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过由传函零极点对消说明能控性与能观性之一被破坏
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消
公式
能控性与能观性 状态空间分析
本卷考法
  • 用 PBH 判据证明系统能控但不能观
本卷实例
  • 关键一步：对每个特征值构造能控与能观 PBH 矩阵
  • 关键一步：分别比较两矩阵的秩与状态维数
  • 中间结果：能控 PBH 矩阵满秩，能观 PBH 矩阵降秩
  • 卡点：只算一个特征值就下结论；把能控与能观矩阵构造搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过用 PBH 判据证明系统能控但不能观
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

四四、参数根轨迹与临界增益#

思路
  • 由闭环特征方程构造以开环增益为变量的根轨迹，先证明穿越虚轴的频率与临界增益公式，再按给定参数画根轨迹求临界增益与稳定范围，最后反求参数之间的稳定关系。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画含复数零极点的参数根轨迹
本卷实例
  • 关键一步：定开环零点与极点并数清分支数
  • 关键一步：按实轴段、渐近线、分离点逐条画
  • 中间结果：两条分支起于原点重极点，终止于两个开环零点
  • 卡点：渐近线夹角公式中把二 k 加一写成二 k；根轨迹草图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画含复数零极点的参数根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹分离点并由幅值条件定对应增益
本卷实例
  • 关键一步：列极点倒数和等于零点倒数和的分离点方程
  • 关键一步：把实轴上的解代回幅值条件
  • 中间结果：分离点方程给出一个实根与一对复根，复根舍去
  • 卡点：保留不在根轨迹实轴段上的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹分离点并由幅值条件定对应增益
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由虚轴交点证明临界频率与临界增益并判断稳定范围
本卷实例
  • 关键一步：令 s 等于 jω 代入特征方程，实部虚部分别为零
  • 关键一步：联立消去增益得到穿越频率表达式
  • 中间结果：临界增益由穿越频率与零极点位置组合而成
  • 卡点：只代一组解漏掉另一组；未回代核对增益正负
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由虚轴交点证明临界频率与临界增益并判断稳定范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

五五、奈奎斯特判据与稳定范围#

思路
  • 由开环频率特性证明奈奎斯特曲线穿越负实轴的条件与交点幅值，再由给定参数画曲线定闭环稳定增益范围，最后讨论三个时间常数的相互关系。
频率特性的物理意义与求法 频域分析
本卷考法
  • 求开环幅频相频表达式并定穿越负实轴条件
本卷实例
  • 关键一步：把 s 换成 jω 后整理实部与虚部
  • 关键一步：令虚部为零解出穿越频率
  • 中间结果：相频含两个正切项与一个负正切项，虚部为零给二次方程
  • 卡点：复数分式求模时忘记把分母取模；积分环节的负九十度漏算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)

本卷实例
  • 关键一步：构造哈密顿函数并对控制量求极值
  • 关键一步：写协态方程与哈密顿终值条件
  • 中间结果：协态为常数，控制亦为常数，状态轨线线性变化
  • 卡点：忽略终端时刻自由带来的哈密顿函数终值条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最优控制问题由状态方程、性能指标与控制量约束共同描述
  • 哈密顿函数对控制量取极值是极大值原理的核心条件
  • 协态方程与横截条件由哈密顿函数分别对状态量和终端条件给出
  • 终端自由时横截条件要求终端协态为零
步骤
  • 构造哈密顿函数（性能指标的被积函数加上协态与状态方程的乘积）
  • 由哈密顿函数对控制量取极值解出最优控制与协态的关系
  • 写出协态方程与边界条件，与状态方程联立
  • 求状态与协态的解析解，再回代得最优控制与最优轨线
通用考法
  • 本卷考过用极大值原理求最优控制、最优轨线与终端时刻
  • 用极大值原理求使性能指标极小的最优控制与最优轨线
  • 构造哈密顿函数并写出正则方程组
  • 判断终端约束对应的横截条件
常见易错
  • 终端自由时仍把协态终值取零以外的值，或反之错把终端固定当自由
  • 解出控制量后忘记回代状态方程验证
