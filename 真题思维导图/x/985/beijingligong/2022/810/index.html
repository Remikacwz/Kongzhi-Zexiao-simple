2二、状态空间法#

思路
  • 用最小多项式法或拉氏反变换求状态转移矩阵，判断能控性并对不完全能控系统作结构分解，最后对能控系统设状态反馈配置给定极点。
状态转移矩阵 状态空间分析
本卷考法
  • 用最小多项式法求状态转移矩阵
本卷实例
  • 关键一步：由最小多项式把矩阵指数写成前若干次幂的线性组合
  • 关键一步：各系数由特征值处的取值条件定出
  • 中间结果：三个互异特征值对应三个待定系数，解出后代入矩阵多项式
  • 卡点：特征值展开式系数解错；把最小多项式与特征多项式混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过用最小多项式法求状态转移矩阵
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错
公式
能控性与能观性 状态空间分析
本卷考法
  • 判断能控性并对不完全能控系统作能控性结构分解
本卷实例
  • 关键一步：构造能控性判别阵，秩小于阶数即不完全能控
  • 关键一步：取变换阵使变换后的输入阵只有前若干行非零
  • 中间结果：能控部分维数等于能控性矩阵的秩，不能控部分为一阶
  • 卡点：能控性矩阵少算一次幂；变换阵求逆算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断能控性并对不完全能控系统作能控性结构分解
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

状态反馈与极点配置 状态空间分析
本卷考法
  • 用状态反馈把闭环极点配置到指定位置并求反馈增益
本卷实例
  • 关键一步：先判断能控性，满秩方可配置极点
  • 关键一步：设增益行向量，写闭环特征多项式并与期望多项式比系数
  • 中间结果：期望多项式由三个指定极点写出，与展开式逐项对比得增益
  • 卡点：状态反馈矩阵的符号写反；未验证能控性就配置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过用状态反馈把闭环极点配置到指定位置并求反馈增益
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反

3三、根轨迹#

思路
  • 由开环传函写闭环特征方程，分离出零点参数构造等效开环传函，按法则画参数根轨迹，由与虚轴交点定稳定范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制零点参数由零变到正无穷的参数根轨迹
本卷实例
  • 关键一步：由特征方程写成 1 加参数乘等效开环传函的形式
  • 关键一步：按起点、实轴段、渐近线、分离点逐条画
  • 中间结果：等效开环有三个极点一个零点，渐近线一条
  • 卡点：实轴段判据算错；分离点求出后不筛选
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制零点参数由零变到正无穷的参数根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求参数根轨迹的分离点并与渐近线交点区分
本卷实例
  • 关键一步：写极点倒数之和等于零点倒数之和的分离点方程
  • 关键一步：解出后逐个代回实轴段判据筛选
  • 中间结果：三次方程的三个根中只有一个落在实轴根轨迹段上
  • 卡点：把渐近线交点当分离点；保留落在根轨迹外的根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求参数根轨迹的分离点并与渐近线交点区分
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点确定系统稳定的参数范围
本卷实例
  • 关键一步：令 s 等于 jω 代入特征方程，令实部虚部同时为零
  • 关键一步：由第二式定频率，再由第一式定临界参数
  • 中间结果：临界参数处一对共轭根落到虚轴上，据此划分稳定与不稳定区间
  • 卡点：漏掉零频的那组解；求得临界限后未与参数定义核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹与虚轴交点确定系统稳定的参数范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

4四、频域分析#

思路
  • 第一问对含右半平面零点的开环系统画奈奎斯特曲线，由实轴交点定稳定增益范围；第二问在截止频率处令幅值为一、相角裕度为给定值反求时间常数与幅值裕量。题面含图未读图。
奈奎斯特判据 稳定性分析
本卷考法
  • 对含右半平面零点的系统用奈氏判据确定稳定增益范围
本卷实例
  • 关键一步：把频率特性整理成实部加虚部，求与实轴交点
  • 关键一步：由开环右半平面极点数与包围圈数判断稳定
  • 中间结果：相频从负九十度单调降到负二百七十度，与实轴只有一个交点
  • 卡点：右半平面零点误当右半平面极点；包围圈数正负号取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过对含右半平面零点的系统用奈氏判据确定稳定增益范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
稳定裕度 频域分析
本卷考法
  • 由相角裕度要求反求时间常数并计算幅值裕量
本卷实例
  • 关键一步：截止频率处幅值等于一，相角裕度给出相频关系
  • 关键一步：两式联立解出时间常数与截止频率
  • 中间结果：联立后时间常数解出为负，需回到题面核对相角裕度数值
  • 卡点：只用一个方程解两个未知量；忽略时间常数必须为正的约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由相角裕度要求反求时间常数并计算幅值裕量
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

5五、时域分析#

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最优控制问题由状态方程、性能指标与控制量约束共同描述
  • 哈密顿函数对控制量取极值是极大值原理的核心条件
  • 协态方程与横截条件由哈密顿函数分别对状态量和终端条件给出
  • 终端自由时横截条件要求终端协态为零
步骤
  • 构造哈密顿函数（性能指标的被积函数加上协态与状态方程的乘积）
  • 由哈密顿函数对控制量取极值解出最优控制与协态的关系
  • 写出协态方程与边界条件，与状态方程联立
  • 求状态与协态的解析解，再回代得最优控制与最优轨线

  • 判断终端约束对应的横截条件
