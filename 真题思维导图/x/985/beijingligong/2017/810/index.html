一一、电路状态空间与传函#

思路
  • 以两支路电流的积分为状态变量，由回路电流关系列写状态方程与输出方程；第二问再由拉氏域方程消去中间变量求输出对输入传函。题面含图未读图。
状态空间表达式的建立 状态空间分析
本卷考法
  • 以电流积分为状态建立双回路电路的状态空间表达式
本卷实例
  • 关键一步：取两个回路电流的积分为状态变量
  • 关键一步：由 KCL、KVL 写回路方程并整理成状态方程
  • 中间结果：状态方程系数由两电阻两电容组合而成
  • 中间结果：输出取其中一个电容电压
  • 卡点：状态变量与原电流的导数关系写错；电路连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过以电流积分为状态建立双回路电路的状态空间表达式
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 用基本不等式证明系统为过阻尼
本卷实例
  • 关键一步：写出阻尼比表达式并把时间常数配对成整体
  • 关键一步：用两正数之和不小于其积的二倍
  • 中间结果：阻尼比不小于一，故系统为过阻尼
  • 卡点：把过阻尼判据写成阻尼比大于零；不等式取等条件用错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过用基本不等式证明系统为过阻尼
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 求过阻尼二阶系统的单位脉冲响应
本卷实例
  • 关键一步：把传函作部分分式分解为两个一阶项
  • 关键一步：逐项取拉氏反变换得响应
  • 中间结果：响应为两个不同衰减指数项的线性组合
  • 卡点：部分分式系数配错；把单位脉冲的拉氏变换当成一除以 s
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过求过阻尼二阶系统的单位脉冲响应
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

三三、状态转移矩阵与全维观测器#

思路
  • 第一问用拉氏反变换求矩阵指数；第二问用 PBH 判据判断能观性；第三问在系统不完全能观时检验不可观极点能否配置，再解观测器增益使极点落在指定位置。
状态转移矩阵 状态空间分析
本卷考法
  • 用拉氏反变换求上三角矩阵的状态转移矩阵
本卷实例
  • 关键一步：写 sI 减 A 并求其逆
  • 关键一步：逐元素作拉氏反变换得矩阵指数
  • 中间结果：矩阵指数含三个不同特征值的指数项
  • 卡点：矩阵求逆的伴随阵元素写错；遗漏对角的直接项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过用拉氏反变换求上三角矩阵的状态转移矩阵
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错

四四、根轨迹与稳定范围#

思路
  • 由开环传函画含一对共轭极点与一个负实零点的根轨迹，按法则求渐近线、分离点与虚轴交点，再由交点定使系统稳定的增益范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 画含共轭极点与负实零点的根轨迹
本卷实例
  • 关键一步：定开环零点极点与分支数
  • 关键一步：按实轴段与渐近线逐条画
  • 中间结果：三条分支中一条终止于有限零点，两条趋于无穷
  • 卡点：实轴段判据的零极点个数算错；根轨迹草图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过画含共轭极点与负实零点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

五五、奈奎斯特与稳定裕度#

思路
  • 由开环频率特性画奈奎斯特曲线，按不同增益判断包围情况与稳定性；再由伯德图求幅值裕度与相角裕度，讨论增益变化对幅值裕度的影响。
奈奎斯特判据 稳定性分析
本卷考法
  • 由奈奎斯特曲线判断不同增益下系统的稳定性
本卷实例
  • 关键一步：定曲线起点终点与负实轴交点
  • 关键一步：按曲线包围临界点的情况判断
  • 中间结果：增益较小时不包围临界点，增益较大时包围
  • 卡点：含积分环节时未补画无穷大半径圆弧；把包围圈数正负定义搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由奈奎斯特曲线判断不同增益下系统的稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

频率特性的物理意义与求法 频域分析
本卷考法
  • 求开环幅频相频表达式与关键频率
本卷实例
  • 关键一步：把 s 换成 jω 后按典型环节分解
  • 关键一步：各环节幅值相乘、相角相加
  • 中间结果：幅频在低频段由积分环节主导
  • 卡点：复数分式求模忘记分母取模；积分环节负九十度漏算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求开环幅频相频表达式与关键频率
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

稳定裕度 频域分析
本卷考法
  • 由伯德图求幅值裕度、相角裕度并讨论增益影响
本卷实例
  • 关键一步：在幅频穿越零分贝处读相角求相角裕度
  • 关键一步：在相频穿越负一百八十度处读幅值求幅值裕度
  • 中间结果：增益变化只平移幅频曲线，故幅值裕度随增益改变
  • 卡点：把截止频率与相位穿越频率用反；幅值裕度取倒数未取
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由伯德图求幅值裕度、相角裕度并讨论增益影响
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过判断各平衡点的稳定性质
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

九九、最短距离与最优控制#

思路
  • 第一问写两曲线间最短距离的泛函并求极值；第二问构造哈密顿函数，由极值条件、协态方程与哈密顿终值条件求最优控制、最优轨线与终端时刻。
泛函极值与变分法 最优控制
本卷考法
  • 求两条给定曲线之间的最短距离
本卷实例
  • 关键一步：把两曲线纵坐标之差写成单变量泛函
  • 关键一步：对泛函取极值求最近点参数
  • 中间结果：最近点处的距离函数导数为零
  • 卡点：把两曲线间的距离误写成竖直距离而不做极值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 泛函的极值由欧拉-拉格朗日方程给出，它是变分法的基本必要条件
  • 被积函数不显含自变量时可用首次积分降阶
  • 端点固定的横截条件由给定的边界条件直接给出
步骤
  • 写出被积函数（含状态量、状态量的导数、自变量）
  • 代入欧拉-拉格朗日方程并化简
  • 对被积函数不显含自变量的情形改用首次积分降阶
  • 代入两端边界条件定积分常数，得到极值函数
通用考法
  • 本卷考过求两条给定曲线之间的最短距离
  • 求给定泛函在给定边界条件下的极值函数
  • 写出欧拉-拉格朗日方程并化简
  • 说明横截条件的作用
常见易错
  • 边界条件有多个时只用两个，漏掉导数的端点条件
  • 含高阶导数的泛函仍套一阶的欧拉方程

最优控制的极大值原理 最优控制
本卷考法
  • 用极大值原理求最优控制、轨线与终端时刻
本卷实例
  • 关键一步：构造哈密顿函数并对控制量求极值
  • 关键一步：写协态方程与哈密顿终值条件
  • 中间结果：协态为常数，控制亦为常数，状态轨线线性变化
  • 卡点：忽略终端时刻自由带来的哈密顿函数终值条件；性能指标含终端时刻项时漏对终端求导
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最优控制问题由状态方程、性能指标与控制量约束共同描述
  • 哈密顿函数对控制量取极值是极大值原理的核心条件
  • 协态方程与横截条件由哈密顿函数分别对状态量和终端条件给出
  • 终端自由时横截条件要求终端协态为零
步骤
  • 构造哈密顿函数（性能指标的被积函数加上协态与状态方程的乘积）
  • 由哈密顿函数对控制量取极值解出最优控制与协态的关系
  • 写出协态方程与边界条件，与状态方程联立
  • 求状态与协态的解析解，再回代得最优控制与最优轨线
通用考法
  • 本卷考过用极大值原理求最优控制、轨线与终端时刻
  • 用极大值原理求使性能指标极小的最优控制与最优轨线
  • 构造哈密顿函数并写出正则方程组
  • 判断终端约束对应的横截条件
常见易错
  • 终端自由时仍把协态终值取零以外的值，或反之错把终端固定当自由
  • 解出控制量后忘记回代状态方程验证
