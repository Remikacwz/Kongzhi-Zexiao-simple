一一、系统建模#

思路
  • 由电路拓扑列写微分方程，以电感电流与电容电压为状态变量写状态空间表达式；再由复阻抗或状态空间求传递函数。
状态空间表达式的建立 状态空间分析
本卷考法
  • 由电路选取电感电流与电容电压为状态变量写状态空间表达式
本卷实例
  • 关键一步：按基尔霍夫定律列两式，把二阶方程拆成一阶方程组
  • 关键一步：状态变量个数等于储能元件个数
  • 中间结果：A 为二阶方阵，B 由输入接入点决定
  • 中间结果：输出方程取电容电压对应状态
  • 卡点：电路拓扑需回原卷核对图
  • 卡点：状态变量选取与输出不一致导致 C 阵写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由电路选取电感电流与电容电压为状态变量写状态空间表达式
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由电路微分方程或状态空间求输出对输入的传递函数
本卷实例
  • 关键一步：对微分方程在零初始条件下取拉氏变换后消去中间变量
  • 中间结果：传函分母为二阶特征式，分子由输出与输入通路决定
  • 卡点：复阻抗法把电容阻抗误写成 Cs
  • 卡点：忘记零初始条件把初值代入变换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由电路微分方程或状态空间求输出对输入的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

二二、状态空间问题#

思路
  • 先用拉氏反变换求矩阵指数；再构造能观性判别阵判断并作能观分解；最后设状态反馈把闭环极点配置到给定重根。
状态转移矩阵 状态空间分析
本卷考法
  • 求给定系统矩阵的矩阵指数 e^{At}
本卷实例
  • 关键一步：用 (sI-A)^{-1} 的拉氏反变换逐元素求矩阵指数
  • 关键一步：先用特征多项式化简预解矩阵
  • 中间结果：特征值为三重根，转移矩阵含 t 与 t² 因子
  • 卡点：重根时漏掉多项式因子
  • 卡点：矩阵求逆时未先判定行列式是否为零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过求给定系统矩阵的矩阵指数 e^{At}
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错
公式
能控性与能观性 状态空间分析
本卷考法
  • 判断系统能观性并对不可观系统作能观分解
本卷实例
  • 关键一步：构造能观性判别阵并求秩，秩小于阶数即不可观
  • 关键一步：取非奇异变换阵把可观与不可观状态分开
  • 中间结果：可观子空间阶数等于能观判别阵的秩
  • 卡点：把能控判据与能观判据的矩阵构造搞混
  • 卡点：变换阵取错使分解后仍不可观
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断系统能观性并对不可观系统作能观分解
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
状态反馈与极点配置 状态空间分析
本卷考法
  • 用状态反馈把闭环极点配置到指定位置并求反馈增益
本卷实例
  • 关键一步：设反馈增益行向量，写闭环特征多项式并与期望多项式比系数
  • 中间结果：期望极点为一对重根，期望多项式含 (s+10)²
  • 卡点：未验证能观性就直接配置
  • 卡点：系数比较时符号写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过用状态反馈把闭环极点配置到指定位置并求反馈增益
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反

三三、根轨迹问题#

思路
  • 开环传函含右半平面零点，先写成标准零极点形式按法则画根轨迹，再令 s=jω 由虚轴交点定稳定 K 范围；第二问求使闭环极点全落左半平面的 K。
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 由相角条件判断实轴上的根轨迹段
本卷实例
  • 关键一步：零点在右半平面时，实轴根轨迹段仍按右侧零极点个数为奇数判断
  • 中间结果：根轨迹起于开环极点、终于开环零点或无穷远
  • 卡点：把右半平面零点当成极点处理使实轴段画反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过由相角条件判断实轴上的根轨迹段
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制含右半平面零点的根轨迹草图
本卷实例
  • 关键一步：先求渐近线、实轴段，再算分离点与会合点
  • 中间结果：有两条分支，其中一条终点在有限零点
  • 卡点：渐近线夹角公式中的 2k+1 写成 2k
  • 卡点：实轴段判据零极点个数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制含右半平面零点的根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点并确定系统稳定的 K 取值范围
本卷实例
  • 关键一步：令 s=jω 代入闭环特征方程，实部虚部分别为零
  • 中间结果：临界 K 使一对共轭根落在虚轴上
  • 卡点：只代一组 ω 漏掉另一组解
  • 卡点：求得 K 后未回代核对参数方向
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点并确定系统稳定的 K 取值范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由闭环极点全部为负值的条件确定参数取值
本卷实例
  • 关键一步：在根轨迹实轴段上找出全部极点位于左半平面的增益区间
  • 中间结果：使所有闭环极点实部为负的 K 落在给定开区间
  • 卡点：把等阻尼线画成垂直线
  • 卡点：忽略右半平面零点对稳定段的影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由闭环极点全部为负值的条件确定参数取值
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

四四、频域问题#

思路
  • 由给出的对数幅频渐近特性反求开环传函的型别、转折频率与增益，进而求截止频率；再画奈奎斯特曲线判定闭环稳定性。
开环对数频率特性的绘制 频域分析
本卷考法
  • 由传函写出开环对数渐近幅频特性
本卷实例
  • 关键一步：低频段斜率定积分环节个数，各转折频率处逐段改斜率
  • 关键一步：各环节幅值相加、相角相加
  • 中间结果：低频段斜率为 -40dB/dec，某转折频率后斜率变化 +20dB/dec
  • 卡点：逐段改斜率时忘记累加而非替换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过由传函写出开环对数渐近幅频特性
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频渐近特性反求开环传递函数与截止频率
本卷实例
  • 关键一步：由低频段斜率定型别，由转折频率处斜率变化定环节类型
  • 关键一步：用某频率处的幅值条件定开环增益
  • 中间结果：传函由一个一阶微分环节与两个积分环节组成
  • 卡点：把延长线交点误当增益而未折算型别
  • 卡点：把斜率变化 -40 直接写成一阶环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数

  • 第一问对泛函写欧拉-拉格朗日方程求极值曲线；第二问构造哈密顿函数，由极值条件与横截条件联立求最优控制与轨线。
泛函极值与变分法 最优控制
本卷考法
  • 对给定泛函写欧拉方程并求满足边界条件的极值曲线
本卷实例
  • 关键一步：把被积函数代入欧拉-拉格朗日方程得到二阶常微分方程
  • 中间结果：通解含两个待定常数，由两端边界条件确定
  • 卡点：边界条件数与待定常数个数不一致
  • 卡点：含高阶导数的泛函仍套一阶欧拉方程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 泛函的极值由欧拉-拉格朗日方程给出，它是变分法的基本必要条件
  • 被积函数不显含自变量时可用首次积分降阶
  • 端点固定的横截条件由给定的边界条件直接给出
步骤
  • 写出被积函数（含状态量、状态量的导数、自变量）
  • 代入欧拉-拉格朗日方程并化简
  • 对被积函数不显含自变量的情形改用首次积分降阶
  • 代入两端边界条件定积分常数，得到极值函数
通用考法
  • 本卷考过对给定泛函写欧拉方程并求满足边界条件的极值曲线
  • 求给定泛函在给定边界条件下的极值函数
  • 写出欧拉-拉格朗日方程并化简
  • 说明横截条件的作用
常见易错
  • 边界条件有多个时只用两个，漏掉导数的端点条件
  • 含高阶导数的泛函仍套一阶的欧拉方程

最优控制的极大值原理 最优控制
本卷考法
  • 用极大值原理求使性能指标极小的最优控制与最优轨线
本卷实例
  • 关键一步：构造哈密顿函数，由对控制求极值把控制表成协态函数
  • 关键一步：写协态方程与横截条件，再回代状态方程
  • 中间结果：协态为常数，最优控制亦为常数
  • 卡点：终端自由时协态终值条件用错
  • 卡点：解出控制后忘记回代状态方程验证
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最优控制问题由状态方程、性能指标与控制量约束共同描述
  • 哈密顿函数对控制量取极值是极大值原理的核心条件
  • 协态方程与横截条件由哈密顿函数分别对状态量和终端条件给出
  • 终端自由时横截条件要求终端协态为零
步骤
  • 构造哈密顿函数（性能指标的被积函数加上协态与状态方程的乘积）
  • 由哈密顿函数对控制量取极值解出最优控制与协态的关系
  • 写出协态方程与边界条件，与状态方程联立
  • 求状态与协态的解析解，再回代得最优控制与最优轨线
通用考法
  • 本卷考过用极大值原理求使性能指标极小的最优控制与最优轨线
  • 用极大值原理求使性能指标极小的最优控制与最优轨线
  • 构造哈密顿函数并写出正则方程组
  • 判断终端约束对应的横截条件
常见易错
  • 终端自由时仍把协态终值取零以外的值，或反之错把终端固定当自由
  • 解出控制量后忘记回代状态方程验证
