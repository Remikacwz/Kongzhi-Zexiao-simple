1一、电路的状态空间建模与输入输出关系证明#

思路
  • 同一个 RLC 网络取两组不同状态变量（三阶与二阶），证两系统输入输出关系相同
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由电路结构列写以电容电压、电感电流为状态变量的状态方程
本卷实例
  • 关键一步：电容电压与电感电流是天然的状态变量，个数正好等于储能元件个数，也等于系统阶数
  • 关键一步：列方程时用元件伏安关系：电容电流等于电容乘电压的导数，电感电压等于电感乘电流的导数
  • 关键一步：对每个节点写电流平衡，把导数项留在左边、其余项移到右边，整理成矩阵形式
  • 中间结果：本题所有元件参数都为 1，A、B 矩阵里会出现 1 与 −1 这类整数元素，便于手工核对
  • 卡点：状态变量个数与储能元件个数不一致；或把中间变量（如某条支路电流）也当成状态变量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由电路结构列写以电容电压、电感电流为状态变量的状态方程
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
状态空间表达式的建立 状态空间分析
本卷考法
  • 写出状态空间表达式并确定各系数矩阵
本卷实例
  • 关键一步：输出方程由输出量与状态变量的关系直接给出，本题输出是某个节点的电压，用状态变量表示即可
  • 关键一步：若输出不含输入的直通项，则直接传递矩阵为零
  • 关键一步：两组状态变量维数不同时，注意各自的 A 矩阵阶数不同
  • 中间结果：三阶实现与二阶实现的结构不同，但输出方程都只用到少数几个状态变量
  • 卡点：输出方程里漏掉某一项状态变量；或把状态方程写成代数方程，导数关系不明确
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过写出状态空间表达式并确定各系数矩阵
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 证明两个阶数不同的系统具有相同的输入输出关系
本卷实例
  • 关键一步：输入输出关系相同等价于传递函数相同，而状态方程并不需要相同，这是证明的出发点
  • 关键一步：用传递函数公式分别算出两个系统，再把高阶那边的分子分母约分后比对
  • 关键一步：阶数不同却传递函数相同，说明高阶那边存在零极点对消，可用能控能观分解解释被消掉的那部分
  • 中间结果：约分后两者完全一致，说明高阶系统中有一个状态既不可控也不可观，对输入输出没有贡献
  • 卡点：去比较状态方程是否相同；或算出传递函数后没有约分就下结论说不相同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过证明两个阶数不同的系统具有相同的输入输出关系
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

2二、PID 控制器设计与闭环脉冲响应#

思路
  • 由单位阶跃响应反求闭环传函，再按 ess 与 PID 结构定三个参数，最后求闭环单位脉冲响应
由响应曲线反求传递函数 传递函数
本卷考法
  • 由阶跃响应表达式反求闭环传递函数
本卷实例
  • 关键一步：阶跃响应是闭环传函乘以 1/s 后的反变换，
  • 关键一步：响应里的 e^{−5t}、e^{−6t} 项说明闭环极点是 −5 与 −6，
  • 关键一步：用 t 趋于无穷时的响应值核对闭环传函的直流增益
  • 关键一步：所以先写出响应的拉氏变换再乘以 s 即得闭环传函
  • 关键一步：可用极点直接写出分母
  • 中间结果：闭环传函分母是 (s+5)(s+6)，即 s²+11s+30；
  • 中间结果：分子由响应各分量的系数合并得到
  • 卡点：忘记先乘 s；或把响应的稳态值当成直流增益后没有反查终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由阶跃响应表达式反求闭环传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
PID 控制器与参数整定 系统校正
本卷考法
  • 由闭环传函与控制器结构反求 PID 三个参数
本卷实例
  • 关键一步：先把控制器写成同一分母的形式：
  • 关键一步：由闭环传函反推开环传函：开环等于闭环除以「一减闭环」，这一步把控制器与对象分开
  • 关键一步：把开环传函化成控制器乘对象的形式，与已知控制器结构逐项比对系数
  • 关键一步：比例、积分、微分三项通分后分子是 k₁ 加 k₂ s 加 k₃ s²，分母是 s
  • 中间结果：开环传函的分子只到 s 的一次或二次项，说明三个参数都由分子系数比对确定，分母不提供新方程
  • 卡点：把积分增益与积分时间混为一谈；或反推开环时忘记先做除法，直接把闭环当开环
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过由闭环传函与控制器结构反求 PID 三个参数
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡下的稳态误差要求校核控制器参数
本卷实例
  • 关键一步：单位斜坡输入下，Ⅰ 型系统的稳态误差等于速度误差系数的倒数，
  • 关键一步：速度误差系数由开环传函在 s 趋于零时的极限给出，这时控制器里的积分项起决定作用
  • 关键一步：用阶跃响应得到的开环传函去算这个极限，正好等于 10，说明两个条件彼此相容而不是相互矛盾
  • 关键一步：要求误差为 0.1 就要求速度误差系数为 10
  • 中间结果：两条已知条件其实是自洽的：只由阶跃响应定出的开环传函就已经满足稳态误差要求
  • 卡点：把误差要求当成独立方程硬凑参数，结果与阶跃响应条件冲突；或不判型别直接套斜坡误差公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位斜坡下的稳态误差要求校核控制器参数
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
零极点分布与响应模态 传递函数
本卷考法
  • 由闭环极点分布写出闭环单位脉冲响应
本卷实例
  • 关键一步：单位脉冲响应就是闭环传函的拉氏反变换，把传函做部分分式分解成若干一阶项
  • 关键一步：每个极点对应一个指数模态，分子系数的正负决定该项是增长还是衰减
  • 关键一步：反变换后可用初值定理核对 t 取零时的值
  • 中间结果：本题两个极点都是实极点，脉冲响应是两个指数项的代数和，不含振荡项
  • 卡点：部分分式时把极点代入的对象搞错；或把阶跃响应与脉冲响应混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由闭环极点分布写出闭环单位脉冲响应
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

3三、根轨迹分离点与重极点增益#

思路
  • 开环含一个未知零点，先由根轨迹经过给定点定出零点位置，再写分离点方程筛选候选值并求重极点对应的增益
分离点与会合点 根轨迹法
本卷考法
  • 写出分离点方程并判断给定点哪个是根轨迹的分离点
  • 求重极点对应的开环增益
本卷实例
  • 关键一步：分离点方程是「各开环极点贡献的倒数之和等于各开环零点贡献的倒数之和」，
  • 关键一步：含未知零点时先用相角条件定零点：根轨迹经过某点意味着该点满足相角条件，由此反解零点位置
  • 关键一步：解出方程后要逐个代回筛选，同时确认该点确实落在根轨迹的实轴段上，不在实轴段上的根要舍去
  • 关键一步：对分离点求的是代数和为零
  • 中间结果：本题极点分布在原点到 −2 之间，
  • 中间结果：两个候选点里，满足分离点方程的那个才是真正的分离点，另一个只是方程的干扰根
  • 中间结果：给定点角度恰好是 120°、60°、45°、30° 这类特殊角，用正切关系可反解出零点位置
  • 卡点：不先定零点就直接写分离点方程，方程里带未知量无法判断；或只代一个候选点就下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过写出分离点方程并判断给定点哪个是根轨迹的分离点
  • 本卷考过求重极点对应的开环增益
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 画出增益由零到正无穷时的根轨迹
本卷实例
  • 关键一步：先标零极点并判断实轴段：某段右侧的零极点总数为奇数时该段属于根轨迹
  • 关键一步：渐近线交点为极点之和减零点之和再除以极点数减零点数，夹角按奇数倍 180° 除以该差值等分
  • 关键一步：分离点、虚轴交点都算出来之后，按对称性把各分支连起来并标注对应增益
  • 中间结果：本题极点比零点多三个，渐近线有若干条，实轴上会形成若干段交替的根轨迹段
  • 卡点：实轴段判据里零极点个数算错；或忘记分离点应该在两个相邻实极点之间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过画出增益由零到正无穷时的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

4四、频域分析三小问#

思路
  • 第一问由正弦稳态输出反求增益与时间常数，第二问由 Bode 图反求传函并算穿越频率，第三问画奈奎斯特曲线并判稳
频率特性的物理意义与求法 频域分析
本卷考法

  • 关键一步：分段系统要分区求奇点：各区令微分方程的右端为零解出的点，
  • 关键一步：再按各区线性系统的特征根判断奇点类型，不同区的类型可能完全不同
  • 关键一步：相轨迹在两个半平面之间切换，切换线上的走向要单独讨论，决定轨迹是穿过切换线还是沿它滑动
  • 关键一步：若落在该区之外就只是虚拟奇点，系统并不真的停在那里
  • 中间结果：本题两个区域各自解出的奇点都落在对方的区域内，
  • 中间结果：所以系统没有真正的平衡点，相轨迹只能在切换线上来回穿越
  • 卡点：把虚拟奇点当成真奇点，直接说轨迹收敛到它；或忽略轨迹在切换线上的行为

  • 关键一步：判断该交点是否稳定要看振幅增大时负倒描述函数曲线的移动方向：
  • 关键一步：从包围区外穿入包围区对应不稳定，穿出才稳定

8八、泛函极值与最优控制#

思路
  • 第一问用变分法求泛函极值，第二问用极大值原理求使性能指标极小的最优控制与最优轨线
泛函极值与变分法 最优控制
本卷考法
  • 求给定泛函在多个边界条件下的极值函数
本卷实例
  • 关键一步：先看被积函数含到几阶导数，含二阶导数的泛函对应的欧拉方程也要提到二阶，否则次数对不上
  • 关键一步：被积函数只含二阶导数时，欧拉方程化为四阶常微分方程，通解里会带四个待定常数
  • 关键一步：四个端点条件（两个给定函数值、两个给定导数值）刚好把四个常数定下来，
  • 关键一步：条件数与未知数个数要一致
  • 中间结果：被积函数只含二阶导数的平方时，四阶方程退化为最简单的一类，通解是三次多项式
  • 卡点：被积函数含高阶导数时仍套一阶欧拉方程；或端点条件数不足却硬凑常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 泛函的极值由欧拉-拉格朗日方程给出，它是变分法的基本必要条件
  • 被积函数不显含自变量时可用首次积分降阶
  • 端点固定的横截条件由给定的边界条件直接给出
步骤
  • 写出被积函数（含状态量、状态量的导数、自变量）
  • 代入欧拉-拉格朗日方程并化简
  • 对被积函数不显含自变量的情形改用首次积分降阶
  • 代入两端边界条件定积分常数，得到极值函数
通用考法
  • 本卷考过求给定泛函在多个边界条件下的极值函数
  • 求给定泛函在给定边界条件下的极值函数
  • 写出欧拉-拉格朗日方程并化简
  • 说明横截条件的作用
常见易错
  • 边界条件有多个时只用两个，漏掉导数的端点条件
  • 含高阶导数的泛函仍套一阶的欧拉方程

最优控制的极大值原理 最优控制
本卷考法
  • 用极大值原理求使性能指标极小的最优控制与最优轨线
本卷实例
  • 关键一步：先构造哈密顿函数：性能指标的被积函数加上协态与状态方程的乘积
  • 关键一步：由哈密顿函数对控制量求极值，把最优控制表示成协态的函数，本题里控制量与协态成线性关系
  • 关键一步：再写协态方程，与状态方程联立消去协态，得到一个只含状态的二阶方程，解出状态的最一般形式
  • 中间结果：终端时刻的状态自由，横截条件是终端时刻协态为零，这条条件用来定通解里的常数
  • 中间结果：本题消元后得到状态的二阶方程，
  • 中间结果：通解是一个指数增长项加一个指数衰减项，系数由初值与横截条件联立确定
  • 卡点：终端自由却把协态终值取零以外的值；或解出控制量后不回代状态方程验证边界条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最优控制问题由状态方程、性能指标与控制量约束共同描述
  • 哈密顿函数对控制量取极值是极大值原理的核心条件
  • 协态方程与横截条件由哈密顿函数分别对状态量和终端条件给出
  • 终端自由时横截条件要求终端协态为零
步骤

  • 写出协态方程与边界条件，与状态方程联立
  • 求状态与协态的解析解，再回代得最优控制与最优轨线
通用考法
  • 本卷考过用极大值原理求使性能指标极小的最优控制与最优轨线
  • 用极大值原理求使性能指标极小的最优控制与最优轨线
