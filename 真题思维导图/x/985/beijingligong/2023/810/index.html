1一、电路的建模与比例积分控制器#

思路
  • 对两电容一电感的电路列微分方程组，消元得输出对输入的传函；再串入比例积分控制器，由斜坡稳态误差要求与劳斯判据定增益范围；最后取电容电压与电感电流为状态写状态空间表达式。题面含图未读图。
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由含两个电容与一个电感的电路建立微分方程并求传递函数
本卷实例
  • 关键一步：按电容电流与电感电压的伏安关系列三式，逐步回代消去中间电流
  • 关键一步：整理成输出项在左、输入项在右的多项式等式
  • 中间结果：传函分子分母都是 s 的三次多项式
  • 卡点：把电容复阻抗写成 C 乘 s；电路图未读图，元件连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由含两个电容与一个电感的电路建立微分方程并求传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
状态空间表达式的建立 状态空间分析
本卷考法
  • 以两电容电压与电感电流为状态写状态空间表达式
本卷实例
  • 关键一步：状态变量个数等于储能元件个数，逐个写一阶导数方程
  • 中间结果：A 为三阶方阵，B 为列向量，输出含状态与输入的直通项
  • 卡点：输出方程漏掉直通项；把支路电流也当状态
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过以两电容电压与电感电流为状态写状态空间表达式
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式
PID 控制器与参数整定 系统校正
本卷考法
  • 设计比例积分控制器并求满足斜坡误差要求的增益范围
本卷实例
  • 关键一步：控制器写成 K 乘 (s+1)/s 的形式串入回路
  • 关键一步：先写闭环特征方程用劳斯判据定稳定增益范围，再由速度误差系数写误差不等式
  • 中间结果：稳定范围给出增益下界为零，误差要求给出增益的一个下界
  • 卡点：把积分增益与积分时间混谈；只解误差不等式不与稳定范围取交集
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过设计比例积分控制器并求满足斜坡误差要求的增益范围
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡输入的稳态误差要求反求比例积分控制器增益
本卷实例
  • 关键一步：先判稳，再由终值定理写速度误差系数与增益的关系
  • 关键一步：把误差要求化成关于增益的不等式
  • 中间结果：该系统为Ⅱ型，速度误差系数有限且正比于控制器增益
  • 卡点：未判稳就套终值定理；把斜坡误差当成与增益无关
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位斜坡输入的稳态误差要求反求比例积分控制器增益
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

2二、状态空间法#

思路
  • 第一问把一个可分解的矩阵拆成对角部分加幂零部分求 50 次幂；第二问判断能控性并作能控性结构分解；第三问判断能控能观性并用状态反馈配置给定极点。
状态转移矩阵 状态空间分析
本卷考法
  • 用特征值分解把矩阵幂展开成有限项（借位：本题是矩阵幂而非转移矩阵）
本卷实例
  • 关键一步：把矩阵拆成可对角化部分与幂零部分，展开后用幂零性截断级数
  • 关键一步：对可对角化部分用相似变换求幂
  • 中间结果：幂零部分的二次方为零，故展开式中只剩两项
  • 卡点：本题是借位挂到状态转移矩阵条目上，方法同源但对象是矩阵幂；不能对角化的矩阵硬做对角化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过用特征值分解把矩阵幂展开成有限项（借位：本题是矩阵幂而非转移矩阵）
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错
公式
能控性与能观性 状态空间分析
本卷考法
  • 判断能控性并对不完全能控系统作能控性分解
本卷实例
  • 关键一步：构造能控性判别阵并求秩
  • 关键一步：取变换阵使变换后输入阵只有第一行非零
  • 中间结果：能控子系统的阶数等于能控性矩阵的秩
  • 卡点：能控性矩阵少算一列；变换阵取错导致子系统不可控
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断能控性并对不完全能控系统作能控性分解
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
状态反馈与极点配置 状态空间分析
本卷考法
  • 判断能控能观性并用状态反馈配置极点
本卷实例
  • 关键一步：先分别构造能控与能观判别阵确认满秩
  • 关键一步：设增益阵，写闭环特征多项式与期望多项式比系数
  • 中间结果：三个期望极点对应三次期望多项式，未知增益由三个方程解出
  • 卡点：未验证能控性就配置；特征多项式展开符号错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过判断能控能观性并用状态反馈配置极点
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反

3三、圆形根轨迹的证明与增益区间#

思路
  • 含一个零点与两个极点的二阶系统，证明复数根轨迹为圆，再代入具体零极点画根轨迹并由幅值条件求根轨迹位于复平面的增益区间。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 证明增益变化时系统根轨迹的复数部分为圆并画出
本卷实例
  • 关键一步：写闭环特征方程，设一对共轭复根代入并用韦达定理
  • 关键一步：消去增益后得到圆心在零点处、半径只含零极点差的圆方程
  • 中间结果：圆的圆心为开环零点，半径为两个开环极点差乘积的平方根
  • 卡点：用韦达定理时根和根积的符号取反；把圆心取成极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过证明增益变化时系统根轨迹的复数部分为圆并画出
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 由圆与实轴交点即分离点求根轨迹位于复平面的增益区间
本卷实例
  • 关键一步：圆与实轴的两个交点即分离点与会合点
  • 关键一步：分别代回幅值条件求两个临界增益，再按根的性质定区间
  • 中间结果：两个分离点对称分布在零点两侧，各对应一个临界增益
  • 卡点：只求一个分离点；把临界增益区间端点开闭弄错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由圆与实轴交点即分离点求根轨迹位于复平面的增益区间
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

4四、频域分析#

思路
  • 含两个微分环节与一个惯性环节的Ⅱ型系统，先由相频分析奈奎斯特曲线与负实轴相交的条件，再由交点幅值定稳定增益范围，最后令相角裕度最大求增益。题面含图未读图。
奈奎斯特判据 稳定性分析
本卷考法
  • 由相频表达式求奈奎斯特曲线与负实轴的交点条件及稳定增益范围
本卷实例
  • 关键一步：把两个微分环节的相角合写，与积分的负一百八十度相减
  • 关键一步：令相角等于负一百八十度求交点频率，再由交点幅值定稳定范围
  • 中间结果：由相频表达式判断相角能否达到负一百八十度，据此写相交条件
  • 卡点：相角合并公式写错；不先判断相交条件就硬求交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由相频表达式求奈奎斯特曲线与负实轴的交点条件及稳定增益范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
稳定裕度 频域分析
本卷考法
  • 求使系统相角裕度最大的增益
本卷实例
  • 关键一步：写相角裕度关于频率的表达式并对其求导
  • 关键一步：令导数为零求使裕度最大的截止频率，再由该频率处的幅值条件定出增益
  • 中间结果：截止频率为两个时间常数乘积的负二分之一次方，增益由该频率处幅值条件给出
  • 卡点：把截止频率与相位穿越频率用反；求导时漏考虑幅值条件的约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
