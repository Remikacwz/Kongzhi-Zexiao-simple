一一、RLC网络状态空间与传函#

思路
  • 以电感电流与两电容电压为状态，由 KCL、KVL 列写三个一阶方程并整理成题给状态空间式；第二问用复阻抗法证等效阻抗并推导输出对输入的传函。题面含图未读图。
状态空间表达式的建立 状态空间分析
本卷考法
  • 由电路图列写三阶状态空间表达式并证明给定矩阵
本卷实例
  • 关键一步：取电感电流与两电容电压为状态，按节点列 KCL
  • 关键一步：消去电容电压导数写成状态方程形式
  • 中间结果：三个储能元件决定系统为三阶
  • 中间结果：输出方程含三个状态项与直接传递项
  • 卡点：状态变量个数与储能元件数不一致；电路连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由电路图列写三阶状态空间表达式并证明给定矩阵
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

二二、由脉冲响应求传函与指标#

思路
  • 对给定单位脉冲响应作拉氏变换得传递函数，化为标准二阶形式读阻尼比与自然频率，再代入公式求单位阶跃响应、峰值时间、超调量与调节时间。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位脉冲响应反求传递函数
本卷实例
  • 关键一步：对脉冲响应作拉氏变换即得传函
  • 关键一步：把分母整理成标准二阶形式
  • 中间结果：由一次项与常数项分别解出阻尼比与自然频率
  • 卡点：未判断系统阶数就套用二阶公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位脉冲响应反求传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由传函标准形式读阻尼比与自然频率
本卷实例
  • 关键一步：分母首项归一后与标准式逐项对照
  • 中间结果：阻尼比为一次项系数与两倍自然频率之比
  • 卡点：把开环增益误当闭环传函系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由传函标准形式读阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 计算阶跃响应、峰值时间、超调量与调节时间
本卷实例
  • 关键一步：峰值时间由阻尼自然频率取派
  • 关键一步：调节时间按误差带取对应系数
  • 中间结果：超调量仅由阻尼比决定
  • 卡点：两种误差带的调节时间系数取反；峰值时间与上升时间混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过计算阶跃响应、峰值时间、超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

三三、零极点对消与能控能观#

思路
  • 与第一题电路对应，在时间常数相等时用特征多项式验证给定量为特征值；再用 PBH 判据检验能控性与能观性，并由零极点对消推断能观性受损。
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由传函零极点对消说明能控性与能观性之一受损
本卷实例
  • 关键一步：把时间常数相等条件代入状态矩阵并化简特征多项式
  • 关键一步：代入指定负倒数验证其满足特征方程
  • 中间结果：该负倒数确为状态矩阵的特征值
  • 卡点：把零极点对消当成能控能观全部丧失
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过由传函零极点对消说明能控性与能观性之一受损
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消
公式
能控性与能观性 状态空间分析
本卷考法
  • 用 PBH 判据判定能控性与能观性
本卷实例
  • 关键一步：对每个特征值分别构造能控与能观 PBH 矩阵
  • 关键一步：比较两矩阵的秩与状态维数
  • 中间结果：能控 PBH 矩阵满秩，能观 PBH 矩阵降秩
  • 卡点：只算一个特征值就下结论；两矩阵构造方式搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过用 PBH 判据判定能控性与能观性
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

四四、根轨迹四重汇合与稳定范围#

思路
  • 先由闭环特征方程配方证明存在增益使四个根汇合于指定实数点，再按给定参数求分离汇合点、渐近线并画根轨迹，最后由与虚轴交点定稳定增益范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 画含一对共轭极点与原点重极点的根轨迹
本卷实例
  • 关键一步：定开环极点与分支数
  • 关键一步：按实轴段与渐近线逐条画
  • 中间结果：四条分支起于四个开环极点并沿渐近线趋于无穷
  • 卡点：渐近线夹角公式写错；根轨迹草图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过画含一对共轭极点与原点重极点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求四重汇合点处的增益与分离汇合坐标
本卷实例
  • 关键一步：由特征方程配方找重根条件
  • 关键一步：用分离点方程核对汇合坐标
  • 中间结果：四重汇合点位于指定负实数点
  • 卡点：把重根条件当成一般分离点方程；未回代核对增益正负
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求四重汇合点处的增益与分离汇合坐标
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由虚轴交点定临界增益与稳定范围
本卷实例
  • 关键一步：列劳斯表令首列出现零求临界条件
  • 关键一步：代回特征方程求虚轴交点坐标
  • 中间结果：临界增益使一对共轭根落在虚轴上
  • 卡点：只令一行为零漏掉其他约束；临界点后未判断稳定区间方向
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由虚轴交点定临界增益与稳定范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

五五、频域稳定判据#

思路
  • 由开环频率特性证明奈奎斯特曲线与负实轴交点的频率与幅值关系，再由该幅值的绝对值小于一列出闭环稳定增益条件。
频率特性的物理意义与求法 频域分析
本卷考法
  • 求开环频率特性并定与负实轴的交点
本卷实例
  • 关键一步：把 s 换成 jω 后整理实部与虚部
  • 关键一步：令虚部为零解出交点频率
  • 中间结果：交点频率由三个时间常数表示
  • 卡点：复数分式求模忘记分母取模；积分环节相角漏算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求开环频率特性并定与负实轴的交点
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由奈奎斯特曲线列闭环稳定条件
本卷实例
  • 关键一步：定曲线起点终点与负实轴交点
  • 关键一步：按包围临界点情况写幅值约束
  • 中间结果：开环无右半平面极点时，交点幅值在负一到零之间即稳定
  • 卡点：含积分环节时未补画无穷大半径圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

本卷实例
  • 关键一步：对每个未知函数分别写欧拉方程
  • 关键一步：由四个端点条件定通解常数
  • 中间结果：一个方程为二次导数的简谐形式，另一个为一次求积形式
  • 卡点：只对一个函数写欧拉方程；端点条件数与常数个数不一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最优控制问题由状态方程、性能指标与控制量约束共同描述
  • 哈密顿函数对控制量取极值是极大值原理的核心条件
  • 协态方程与横截条件由哈密顿函数分别对状态量和终端条件给出
  • 终端自由时横截条件要求终端协态为零
步骤
  • 构造哈密顿函数（性能指标的被积函数加上协态与状态方程的乘积）
  • 由哈密顿函数对控制量取极值解出最优控制与协态的关系
  • 写出协态方程与边界条件，与状态方程联立
  • 求状态与协态的解析解，再回代得最优控制与最优轨线
通用考法
  • 本卷考过对含两未知函数的泛函分别写欧拉方程并求极值函数
  • 用极大值原理求使性能指标极小的最优控制与最优轨线
  • 构造哈密顿函数并写出正则方程组
  • 判断终端约束对应的横截条件
常见易错
  • 终端自由时仍把协态终值取零以外的值，或反之错把终端固定当自由
  • 解出控制量后忘记回代状态方程验证
