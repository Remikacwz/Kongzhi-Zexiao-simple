一一、选择题20 分#

思路
  • 九道小题覆盖稳定性概念、线性定常系统判别、根轨迹上点的判断、由斜坡响应求稳态误差、带宽比较、重特征根独立特征向量数、状态转移矩阵性质、二次型符号、无源网络构成的校正器类型
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 识别描述系统受扰后恢复平衡能力的说法
本卷实例
  • 关键一步：稳定性指扰动后重新恢复平衡的能力
  • 中间结果：与快速性、准确性、抗干扰性并列
  • 卡点：抗干扰性与稳定性容易混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过识别描述系统受扰后恢复平衡能力的说法
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 判断微分方程描述的系统是否线性定常
本卷实例
  • 关键一步：逐项检查是否含变系数或非线性项
  • 中间结果：含时间因子乘导数项则时变，含根号或平方则非线性
  • 卡点：只按方程形式直觉判断而漏排查
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过判断微分方程描述的系统是否线性定常
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 判断给定复平面点是否在根轨迹上
本卷实例
  • 关键一步：用相角条件检验该点
  • 中间结果：不满足相角条件的点不在根轨迹上
  • 卡点：用幅值条件判点会误判
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过判断给定复平面点是否在根轨迹上
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡响应求系统的稳态误差
本卷实例
  • 关键一步：按定义取输入与输出之差的极限
  • 中间结果：稳态误差等于斜坡响应与输入之差
  • 卡点：误差定义是输入减输出
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位斜坡响应求系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

闭环频率特性与性能指标 频域分析
本卷考法
  • 由传递函数比较各系统带宽大小
本卷实例
  • 关键一步：由幅频降到零频的 0.707 倍求带宽频率
  • 中间结果：增益不同但时间常数相同则带宽相同
  • 卡点：只看增益大小而忽略时间常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过由传递函数比较各系统带宽大小
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

能控性与能观性 状态空间分析
本卷考法
  • 由状态矩阵求重特征根对应的独立特征向量个数
本卷实例
  • 关键一步：先求特征值重数再求矩阵的秩
  • 中间结果：独立特征向量数由重数与秩之差确定
  • 卡点：把几何重数与代数重数混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过由状态矩阵求重特征根对应的独立特征向量个数
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

状态转移矩阵 状态空间分析
本卷考法
  • 判断状态转移矩阵性质的表述是否正确
本卷实例
  • 关键一步：逐条核对状态转移矩阵的基本性质
  • 中间结果：乘性组合性质成立，加法性质不成立
  • 卡点：把加法性质误当成转移矩阵性质
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过判断状态转移矩阵性质的表述是否正确
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错

李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 判断二次型标量函数的符号性质
本卷实例
  • 关键一步：写出对应的实对称矩阵
  • 中间结果：由顺序主子式的符号判断正定性
  • 卡点：先化成对称矩阵再判符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过判断二次型标量函数的符号性质
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

PID 控制器与参数整定 系统校正
本卷考法
  • 由无源网络构成判断控制器类型
本卷实例
  • 关键一步：由网络零极点相对位置判断校正特性
  • 中间结果：极点比零点更靠原点者为滞后网络
  • 卡点：网络以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过由无源网络构成判断控制器类型
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

思路
  • 四道小题判断附加左半平面开环零点对快速性的影响、三阶系统能否降阶、稳定性是否与输入有关、线性定常系统的平衡状态是否恒为原点
附加开环零极点的影响 根轨迹法
本卷考法
  • 判断增加左半平面开环零点的影响
本卷实例
  • 关键一步：零点使根轨迹向左移动
  • 中间结果：超调量增大、调节时间减小
  • 卡点：快速性改善与超调增大同时出现
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过判断增加左半平面开环零点的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 判断三阶系统能否降阶为二阶近似
本卷实例
  • 关键一步：按主导极点与偶极子条件判断
  • 中间结果：远极点可忽略但须保持直流增益不变
  • 卡点：降阶前后直流增益要保持一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过判断三阶系统能否降阶为二阶近似
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 判断线性定常系统的平衡状态是否恒为原点
本卷实例

  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点

  • 能控性与能观性经非奇异线性变换保持不变

  • 构造能观性矩阵并求秩

  • 不可控或不可观时进一步做结构分解
