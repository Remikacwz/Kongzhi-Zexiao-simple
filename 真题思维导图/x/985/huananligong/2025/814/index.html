1一、单机械臂关节的建模与方块图#

思路
  • 对负载与电机轴分别列转动方程并消去负载转角，得到电机转角对转矩的传递函数；再由电枢回路、反电势与转矩关系搭出输入电压到负载转角的方块图
直流电机等机电系统 建模与机电系统
本卷考法
  • 由电机轴与负载的转矩平衡方程求传递函数
本卷实例
  • 关键一步：负载经扭转弹簧和粘性阻尼与电机轴耦合，两个转动方程要联立消元
  • 中间结果：负载方程先解出负载转角用电机转角表示，再代回电机轴方程
  • 卡点：图6未读图，弹簧与阻尼的连接位置和受力方向需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由电枢回路电压方程与转矩平衡方程联立
  • 反电动势与转速成正比，电磁转矩与电枢电流成正比
  • 机电时间常数由电气与机械两方面参数共同决定
步骤
  • 写出电枢回路电压平衡方程
  • 写出转矩平衡方程（含负载与粘性摩擦）
  • 消去电枢电流，得到转速或转角对电压的传递函数
通用考法
  • 本卷考过由电机轴与负载的转矩平衡方程求传递函数
  • 求直流电机转速或位置对电枢电压的传递函数
  • 分析机电时间常数与电气时间常数的数量级关系
常见易错
  • 漏掉反电动势与电磁转矩的耦合项
  • 把电气时间常数与机电时间常数混淆
公式
由电路或机械系统求传递函数 传递函数
本卷考法

本卷实例
  • 关键一步：零初始状态下逐项取拉氏变换，把两个方程整理成含两个转角的方程组
  • 中间结果：消去负载转角后分母同时含电机与负载的惯量和耦合刚度项
  • 卡点：忽略电枢电感时电枢回路只剩电阻，别把电感项写进方程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k

  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过对机械与机电耦合方程取拉氏变换并消去中间变量
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错

  • 并联环节相减时符号取反

2二、含前置滤波的反馈系统稳定性与误差校正#

思路
  • 由结构图写闭环特征方程，用劳斯判据判断参数增大时稳定性；再按标准二阶形式分析超调量与调节时间，最后按给定与扰动两条通道重设计补偿环节消除斜坡误差
参数稳定域的确定 稳定性分析
本卷考法
  • 用劳斯判据判断可变参数 η 增大时系统是否保持稳定
本卷实例
  • 关键一步：写出闭环特征方程后列劳斯表，首列各元素同号系统稳定
  • 中间结果：二阶系统的劳斯表首列含参数与环路增益，稳定条件与参数取值无关
  • 卡点：图8未读图，补偿环节在回路中的位置需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过用劳斯判据判断可变参数 η 增大时系统是否保持稳定
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函整理成标准二阶形式并读出阻尼比与自然频率
本卷实例
  • 关键一步：把闭环特征多项式与标准二阶形式逐项比对
  • 中间结果：自然频率由两条前向通道增益的乘积决定，阻尼比随反馈系数线性增大
  • 卡点：比对前要先把二次项系数归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函整理成标准二阶形式并读出阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 分析参数增大时超调量与调节时间的变化趋势
本卷实例
  • 关键一步：超调量只由阻尼比决定，调节时间与阻尼比乘自然频率成反比
  • 中间结果：参数增大使阻尼比增大而自然频率不变，两个指标随之变化
  • 卡点：把阻尼比增大对超调量的影响方向写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过分析参数增大时超调量与调节时间的变化趋势
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 参考输入与扰动同时为斜坡时分别求两条通道的稳态误差
本卷实例
  • 关键一步：用叠加原理分别令参考输入为零和扰动为零，写出两条误差传函
  • 中间结果：两条误差传函分母相同，都是同一个闭环特征式
  • 卡点：求扰动通道时忘记把参考输入置零；误差取样点需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过参考输入与扰动同时为斜坡时分别求两条通道的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 重设计前向与反馈补偿环节使斜坡输入下稳态误差减小或消除
本卷实例
  • 关键一步：按终值定理写出斜坡输入下稳态误差与两个补偿环节的关系
  • 中间结果：令稳态误差极限为零可解出前馈环节需提供的常数通道
  • 卡点：改设计后要回代检查系统仍稳定；补偿环节要物理可实现
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过重设计前向与反馈补偿环节使斜坡输入下稳态误差减小或消除
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

3三、参数根轨迹与相平面分析#

思路
  • 把含时间常数的闭环特征方程整理成等效开环形式，按参数根轨迹法则画轨迹并由根的位置判断无超调；再在给定时间常数下写出误差微分方程，画相平面草图判断稳态误差
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以时间常数 τ 为可变参数绘制参数根轨迹
本卷实例
  • 关键一步：把闭环特征方程写成 1 加 τ 乘等效开环等于零，把 τ 提到标准位置
  • 中间结果：等效开环的零点在原点，极点为两个左半平面共轭复根
  • 卡点：整理参数时不要把 τ 拆到分母；等效开环零点位置容易写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以时间常数 τ 为可变参数绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按渐近线与分离点法则绘制参数根轨迹草图
本卷实例
  • 关键一步：实轴段由右侧零极点个数为奇数判定，再算渐近线交点与分离点
  • 中间结果：极点比零点多一个，渐近线只有一条；复平面段满足两共轭根之积为常数
  • 卡点：分离点方程要用等效开环的极零点，别漏掉原点处的零点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按渐近线与分离点法则绘制参数根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹是否落在实轴判断阶跃响应无超调并反求 τ
本卷实例
  • 关键一步：闭环根全为实数时响应单调无振荡，故要求根轨迹只剩实轴分支
  • 中间结果：把实轴分离点代回幅值条件可定出 τ 的临界值
  • 卡点：只画轨迹不判断实根条件；临界值两侧的 τ 范围方向容易取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹是否落在实轴判断阶跃响应无超调并反求 τ
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

6六、双输入质点系统的解耦与轨迹跟踪#

思路
  • 用两输入之和与之差把平面两个通道解耦，对一阶的横坐标通道与二阶的纵坐标通道分别按闭环极点负一配置状态反馈，并把参考轨迹及其导数前馈进控制律
状态反馈解耦 状态空间分析
本卷考法
  • 用输入变换把两个位置的动力学解耦成互不影响的通道
本卷实例
  • 关键一步：取两输入之和与两输入之差为新的虚拟输入，使两个方程各自独立
  • 中间结果：解耦后两个虚拟输入由原控制输入的加减组合还原
  • 卡点：由虚拟输入反解原输入时加减号容易写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 解耦的目标是让每个输出只被对应的一个输入控制，闭环传递函数矩阵成为对角阵
  • 用输入变换加状态反馈控制律 u 等于负 Kx 加 Fv 实现解耦
  • 解耦矩阵由各通道输出的相对阶与输入矩阵组成，非奇异时才能解耦
  • 解耦后闭环传函矩阵的对角元由配置的极点决定，非对角元为零

  • 逐个求各输出的相对阶，即输出导数中首次出现输入的阶数减一
  • 用各通道的相对阶对应的行组成解耦矩阵，并检查其是否非奇异
  • 由解耦矩阵的逆求出输入变换矩阵，再由各通道系数求出状态反馈矩阵
  • 写出闭环传递函数矩阵，校验是否已对角化并满足期望极点
通用考法
  • 本卷考过用输入变换把两个位置的动力学解耦成互不影响的通道
  • 证明系统能通过输入变换与状态反馈实现解耦
  • 求解耦矩阵与状态反馈阵并写出闭环传递函数矩阵
  • 分析解耦后各通道的极点是否可任意配置

减小稳态误差的措施 稳态误差
本卷考法
  • 把参考轨迹及其导数作为前馈项实现渐近跟踪
本卷实例
  • 关键一步：把参考轨迹代入误差动态，反解出使误差方程齐次的虚拟输入

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差

  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法

常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

7七、周期信号的傅里叶级数与频谱关系#

思路

采样过程与香农采样定理 离散控制系统
本卷考法
  • 借助周期延拓与频谱离散的关系说明傅里叶级数与傅里叶反变换的联系
本卷实例
  • 关键一步：把周期信号看成非周期信号按周期平移叠加，级数项对应各次谐波
  • 中间结果：级数系数与单个周期信号频谱在谐波频率处的取值成比例
  • 卡点：考点库暂无傅里叶级数类考点，此处暂借离散频谱考点，需补建知识点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过借助周期延拓与频谱离散的关系说明傅里叶级数与傅里叶反变换的联系
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后
