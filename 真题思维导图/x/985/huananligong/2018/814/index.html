思路

自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出闭环系统中完成控制变量到被控变量转换的环节
本卷实例
  • 关键一步：按被控对象与执行机构、传感器、控制器的功能区分
  • 中间结果：闭环中被控对象直接承担被控变量的变化过程
  • 卡点：执行机构与控制器的作用容易互换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指出闭环系统中完成控制变量到被控变量转换的环节
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由闭环特征方程求产生等幅振荡的临界增益
本卷实例
  • 关键一步：令闭环特征方程的根为纯虚数 jω
  • 中间结果：将 s=jω 代入后令实部与虚部分别为零
  • 卡点：只令实部为零会漏掉临界频率条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由闭环特征方程求产生等幅振荡的临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 比较不同二阶系统的单位阶跃响应超调量
本卷实例
  • 关键一步：把各传递函数化为标准二阶形式
  • 中间结果：ωn 相同时阻尼比 ξ 越小超调量越大
  • 卡点：只看 ωn 大小而忽略阻尼比 ξ
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过比较不同二阶系统的单位阶跃响应超调量
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断特征多项式对应系统的稳定性
本卷实例
  • 关键一步：按降幂排列特征多项式并补齐缺项
  • 中间结果：首列元素符号变化次数等于右半平面根数
  • 卡点：首列出现零元时未按无穷小量处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断特征多项式对应系统的稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅相曲线及 P、ν 判断闭环稳定性
本卷实例
  • 关键一步：先按积分环节个数补画无穷大半径圆弧
  • 中间结果：由 Z=P−2N 计算右半平面闭环极点数
  • 卡点：补画方向或包围圈数正负号取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环幅相曲线及 P、ν 判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

滞后校正 系统校正
本卷考法
  • 由串联校正装置的传递函数判断校正类型
本卷实例
  • 关键一步：比较校正网络零点与极点相对位置
  • 中间结果：零点在极点右侧且低频增益衰减者为滞后校正
  • 卡点：把滞后校正的幅值衰减说成相位超前
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过由串联校正装置的传递函数判断校正类型
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

频率特性的物理意义与求法 频域分析
本卷考法
  • 由系统频率特性求余弦输入下的稳态输出
本卷实例
  • 关键一步：将余弦输入先写成同频率正弦形式
  • 中间结果：稳态输出幅值为输入幅值乘 |G(jω)|
  • 卡点：忘记余弦与正弦之间的相位换算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由系统频率特性求余弦输入下的稳态输出
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

闭环频率特性与性能指标 频域分析
本卷考法
  • 由谐振峰值变化判断二阶系统时域指标变化
本卷实例
  • 关键一步：利用 Mr=1/(2ξ√(1−ξ²)) 判断 ξ 变化
  • 中间结果：Mr 增大对应 ξ 减小、超调量 σ% 增大
  • 卡点：把谐振峰值与调节时间的变化方向搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过由谐振峰值变化判断二阶系统时域指标变化
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 由传递函数识别能控标准型的状态空间表达式
本卷实例
  • 关键一步：把传递函数化为首一真分式并读出系数
  • 中间结果：能控标准型中 A 取友矩阵形式、B 取末位为 1
  • 卡点：把能控标准型与能观标准型的 A、C 矩阵混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法
  • 本卷考过由传递函数识别能控标准型的状态空间表达式
  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反

二（1~4）二、判断题（1~4）#

思路
  • 四道小题判断时变/时不变、高阶降阶、状态空间与传函唯一性、非线性状态方程平衡点
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 判断微分方程描述的系统是否为时变系统
本卷实例
  • 关键一步：检查方程各项系数是否随时间变化
  • 中间结果：系数均为常数且无时间因子乘项时时不变
  • 卡点：把输入含 M(t) 误当作时变来源
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过判断微分方程描述的系统是否为时变系统
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 判断高阶系统能否降阶为二阶近似
本卷实例
  • 关键一步：比较远极点与主导极点的距离及留数
  • 中间结果：降阶前后直流增益必须保持不变
  • 卡点：只忽略远极点而未校验增益一致性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过判断高阶系统能否降阶为二阶近似
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

状态空间与传递函数的关系 状态空间分析
本卷考法
  • 判断状态空间表达式与传递函数是否唯一对应
本卷实例
  • 关键一步：状态变量选取不同则状态空间表达式不同
  • 中间结果：由 A、B、C、D 算出的传递函数是唯一确定的
  • 卡点：把状态空间表达式不唯一误解为传函不唯一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过判断状态空间表达式与传递函数是否唯一对应
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D

本卷考法

本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤

  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法

  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
