一一、单项选择#

思路
  • 三道小题查反馈元件职能、由脉冲响应求正弦稳态输出、非奇异变换对系统性质的影响
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出反馈控制系统中用于测量被控量的元件
本卷实例
  • 关键一步：按各环节职能区分校正、执行与反馈元件
  • 中间结果：反馈元件测量被控量并形成偏差
  • 卡点：校正与执行元件的职能易混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指出反馈控制系统中用于测量被控量的元件
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
频率特性的物理意义与求法 频域分析
本卷考法
  • 由单位脉冲响应求正弦输入下的稳态输出
本卷实例
  • 关键一步：零初态下脉冲响应即系统传递函数
  • 中间结果：由幅频与相频在该频率处写稳态输出
  • 卡点：稳态输出相角按反正切取负号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由单位脉冲响应求正弦输入下的稳态输出
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
状态空间表达式的建立 状态空间分析
本卷考法
  • 判断非奇异变换对系统性质的影响
本卷实例
  • 关键一步：非奇异变换只改变状态向量的表示
  • 中间结果：特征值不变故稳定性与能控性不变
  • 卡点：特征向量的长度会改变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过判断非奇异变换对系统性质的影响
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

二二、不定项选择#

思路
  • 四道小题分别判二阶响应振荡与无差、判高阶响应分量、比较两系统调节时间与超调、识别校正装置类型
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征式判断二阶系统阻尼状态
本卷实例
  • 关键一步：先由开环型别定稳态误差为零，再由闭环特征式算阻尼比
  • 中间结果：自然频率与阻尼比由闭环特征式系数对应读出
  • 卡点：阻尼比小于 1 才振荡，大于 1 属过阻尼
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征式判断二阶系统阻尼状态
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 由极点与零点相对位置判断阶跃响应分量
本卷实例
  • 关键一步：分量衰减快慢由极点距虚轴远近决定
  • 中间结果：某极点附近有零点时该分量系数小
  • 卡点：主导分量要同时看系数与衰减速度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过由极点与零点相对位置判断阶跃响应分量
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
稳定裕度 频域分析
本卷考法
  • 由开环对数幅频特性比较截止频率与相角裕度
本卷实例
  • 关键一步：两系统仅增益不同、相频相同，直接比较截止频率
  • 中间结果：截止频率越高调节时间越短
  • 卡点：相角裕度大者超调量未必单调更小
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由开环对数幅频特性比较截止频率与相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
滞后校正 系统校正
本卷考法
  • 由校正环节零极点位置判断超前或滞后
本卷实例
  • 关键一步：比较两个转折频率大小可判定滞后网络
  • 中间结果：分子零点比极点远离原点者为滞后校正
  • 卡点：滞后校正不提高稳态精度，勿与积分作用混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过由校正环节零极点位置判断超前或滞后
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

三三、判断对错#

思路
  • 判断脉冲响应式能否直接当传函、频率特性是否随输入类型变化、特征值均为负实根是否为渐近稳定充要条件
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 判断由单位阶跃响应直接相加写传递函数的做法
本卷实例
  • 关键一步：阶跃响应是传递函数与 1/s 的乘积
  • 中间结果：须先除以输入拉氏变换才是传递函数
  • 卡点：漏除输入变换会把响应当传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过判断由单位阶跃响应直接相加写传递函数的做法
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上
公式

李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 判断特征值均为负实根是否为渐近稳定的充要条件
本卷实例
  • 关键一步：用李雅普诺夫第一法按特征值实部符号判稳
  • 中间结果：复根只要实部为负同样渐近稳定
  • 卡点：把负实根误当成唯一条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过判断特征值均为负实根是否为渐近稳定的充要条件
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

四四、动力学方程与扰动分析#

思路
  • 由动力学方程求图中 A、B 的传函，再分析阶跃输入与扰动下稳态值是否受质量、阻尼与扰动幅值影响
机械系统建模 建模与机电系统
本卷考法
  • 由机械系统动力学方程求传递函数
本卷实例
  • 关键一步：对方程取零初始拉氏变换得代数关系
  • 中间结果：输出与输入的代数关系含扰动项
  • 卡点：扰动项含 s 因子，勿当常量处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过由机械系统动力学方程求传递函数
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求扰动作用下的输出传递函数
本卷实例
  • 关键一步：令参考输入为零，由结构图列 A、B 的传函
  • 中间结果：两条通道之比可定出 A 与 B
  • 卡点：求扰动传函必须把参考输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求扰动作用下的输出传递函数
  • 求扰动引起的输出或误差

要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控

  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法

  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
