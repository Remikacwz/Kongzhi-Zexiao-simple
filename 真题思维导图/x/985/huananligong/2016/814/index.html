一一、填空选择25 分#

思路
  • 四道小题查控制系统性能的基本要求、由脉冲响应求极点与阶跃稳态值、能跟踪抛物线信号的开环型别、图中校正是串联还是反馈校正
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 回答控制系统性能的基本要求
本卷实例
  • 关键一步：性能要求可概括为稳、准、快
  • 中间结果：稳定、准确、快速分别对应不同性能指标
  • 卡点：准确对应稳态误差，快速对应调节时间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过回答控制系统性能的基本要求
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由单位脉冲响应求极点与单位阶跃响应的稳态值
本卷实例
  • 关键一步：脉冲响应取拉氏变换即系统传递函数
  • 中间结果：极点由特征方程给出，稳态值由终值定理求
  • 卡点：求阶跃稳态值须先乘输入 1/s 再取极限
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由单位脉冲响应求极点与单位阶跃响应的稳态值
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 判断给定开环传递函数能否跟踪抛物线信号
本卷实例
  • 关键一步：跟踪抛物线要求开环型别不低于二阶
  • 中间结果：由开环含积分环节个数确定型别
  • 卡点：把系统型别与开环增益混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断给定开环传递函数能否跟踪抛物线信号
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
超前校正 系统校正
本卷考法
  • 由结构图判断校正环节的接入方式
本卷实例
  • 关键一步：按串联在前向通路还是并入反馈通道区分
  • 中间结果：按扰动补偿的校正只适用于扰动可测量
  • 卡点：结构图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过由结构图判断校正环节的接入方式
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

二二、判断对错12 分#

一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 比较两个系统的阶跃响应调节时间
本卷实例
  • 关键一步：先判系统是否稳定，不稳定系统无调节时间
  • 中间结果：一阶系统调节时间与时间常数成正比
  • 卡点：右半平面极点系统不存在调节时间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤

  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过比较两个系统的阶跃响应调节时间
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 判断含常数项微分方程描述的系统是否线性
本卷实例
  • 关键一步：按叠加原理逐项验证
  • 中间结果：方程含常数项会破坏线性
  • 卡点：可加性与齐次性须同时验证
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过判断含常数项微分方程描述的系统是否线性
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 判断附加左半平面开环极点对性能的影响
本卷实例
  • 关键一步：由根轨迹右移判断相对稳定性变化
  • 中间结果：附加极点使根轨迹右偏、快速性变差
  • 卡点：把附加极点与附加零点的影响记反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过判断附加左半平面开环极点对性能的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
减小稳态误差的措施 稳态误差
本卷考法
  • 判断前馈校正与增大增益对稳态精度的影响
本卷实例
  • 关键一步：前馈补偿可提高给定或扰动下的稳态精度
  • 中间结果：增大增益只能减小对应型别的误差
  • 卡点：增益过大会破坏系统稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过判断前馈校正与增大增益对稳态精度的影响
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

三三、简答23 分#

思路
  • 判断题给分式是否为最小相位系统，再由初始条件与导数条件判断两个矩阵能否作为状态转移矩阵
最小相位系统与非最小相位系统 频域分析
本卷考法
  • 判断给定传递函数是否为最小相位系统
本卷实例
  • 关键一步：分别对分子分母用劳斯判据查右半平面根
  • 中间结果：分子分母都不含右半平面根才是最小相位
  • 卡点：只查极点不查零点会漏判
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过判断给定传递函数是否为最小相位系统
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈
状态转移矩阵 状态空间分析
本卷考法
  • 用状态转移矩阵性质判断给定矩阵是否合法
本卷实例
  • 关键一步：先验转移矩阵在零时刻等于单位阵，再验导数条件
  • 中间结果：两个条件任一不满足即可否定
  • 卡点：转移矩阵零时刻不为单位阵时可直接排除
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过用状态转移矩阵性质判断给定矩阵是否合法
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错

四四、计算90 分#

思路
  • 四道计算小题依次为直流电机带动单关节机械臂建模与无差判断、根轨迹与期望闭环极点、Bode 图与稳定范围及校正设计、状态空间最小实现与状态反馈；均为独立成题的小题
直流电机等机电系统 建模与机电系统
本卷考法
  • 由直流电机转矩方程与电枢回路求传递函数
本卷实例
  • 关键一步：联立电枢电压平衡与转矩平衡消去电流
  • 中间结果：反电势项带来与转速成正比的阻尼
  • 卡点：电枢电阻与转矩系数易混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由电枢回路电压方程与转矩平衡方程联立
  • 反电动势与转速成正比，电磁转矩与电枢电流成正比
  • 机电时间常数由电气与机械两方面参数共同决定
步骤
  • 写出电枢回路电压平衡方程
  • 写出转矩平衡方程（含负载与粘性摩擦）
  • 消去电枢电流，得到转速或转角对电压的传递函数
通用考法
  • 本卷考过由直流电机转矩方程与电枢回路求传递函数
  • 求直流电机转速或位置对电枢电压的传递函数
  • 分析机电时间常数与电气时间常数的数量级关系
常见易错
  • 漏掉反电动势与电磁转矩的耦合项
  • 把电气时间常数与机电时间常数混淆

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 画闭环方块图并判断系统是否为无差系统
本卷实例
  • 关键一步：由开环含积分环节个数判断系统型别
  • 中间结果：含积分环节则对阶跃输入无差
  • 卡点：方块图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过画闭环方块图并判断系统是否为无差系统
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量

分离点与会合点 根轨迹法
本卷考法
  • 由根轨迹圆弧与期望闭环极点反求零点与增益
本卷实例
  • 关键一步：由期望点到零点的几何关系求零点位置
  • 中间结果：用幅值条件在期望点求对应增益
  • 卡点：先判零点取值范围再取舍
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由根轨迹圆弧与期望闭环极点反求零点与增益
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

稳定裕度 频域分析
本卷考法
  • 画 Bode 图求截止频率与相位裕度，求稳定增益范围
本卷实例
  • 关键一步：按系统型别与转折频率逐段画渐近线
  • 中间结果：相位裕度大于零即闭环稳定
  • 卡点：转折频率后斜率累加而非替换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过画 Bode 图求截止频率与相位裕度，求稳定增益范围
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

  • 中间结果：按相位裕度要求配置零点位置
  • 卡点：校正装置分子分母阶次受题设限制
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过设计使稳态误差为零且对任意阶数均稳定的校正装置
  • 设计串联超前校正装置

  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由状态空间判最小实现与状态反馈可达性
本卷实例
  • 关键一步：由能控性与能观性矩阵的秩判断最小实现条件
  • 中间结果：给定参数下判断能否出现指定阶跃响应
  • 卡点：输出反馈与状态反馈的可配置范围不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过由状态空间判最小实现与状态反馈可达性
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

本卷考法
  • 判断一个状态能控能观而另一个不能的条件
本卷实例
  • 关键一步：分别对两个状态列能控性与能观性条件
  • 中间结果：两个状态的可控性与可观性互不约束
  • 卡点：把能控性与能观性判据的矩阵构造搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断一个状态能控能观而另一个不能的条件
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
