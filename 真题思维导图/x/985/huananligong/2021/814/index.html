1一、选择题（回忆版仅存答案）#

思路
  • 八道选择题覆盖最小相位、稳态误差、二阶极点、奈奎斯特、超前校正、状态转移矩阵与离散滤波，题面选项缺失
最小相位系统与非最小相位系统 频域分析
本卷考法
  • 判断最小相位系统与相角裕度的关系
本卷实例
  • 关键一步：由最小相位定义判断开环零点极点是否全在左半平面
  • 中间结果：最小相位系统相角裕度大于零只是稳定条件之一
  • 卡点：题面与选项已丢失，只能由答案反推考点，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过判断最小相位系统与相角裕度的关系
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈
系统型别与静态误差系数 稳态误差
本卷考法
  • 分析提高开环增益与增加积分环节对精度和稳定性的影响
本卷实例
  • 关键一步：区分开环增益、开环型别与静态误差系数三者的作用
  • 中间结果：比例积分控制器同时影响动态性能与静态性能
  • 卡点：稳态误差还与输入信号型别有关，不能只看传递函数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过分析提高开环增益与增加积分环节对精度和稳定性的影响
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征根位置判断二阶系统阶跃响应形式
本卷实例
  • 关键一步：先求闭环特征方程的一对共轭复根
  • 中间结果：极点位于左半平面且为共轭复根对应振荡衰减
  • 卡点：答案段特征方程疑有OCR错排，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征根位置判断二阶系统阶跃响应形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

奈奎斯特判据 稳定性分析
本卷考法
  • 由开环右半平面极点数与包围圈数判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数，再数曲线包围临界点的圈数
  • 中间结果：由包围圈数公式推算闭环右半平面极点数
  • 卡点：包围圈数正负号定义易反，奈氏曲线需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环右半平面极点数与包围圈数判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

超前校正 系统校正
本卷考法
  • 由校正装置两个转折频率的大小判断超前或滞后校正
本卷实例
  • 关键一步：把装置写成含两个一阶因子的标准形式并比较转折频率
  • 中间结果：分子零点对应转折频率较低时属超前校正
  • 卡点：两个转折频率大小关系判断反了会得出相反结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过由校正装置两个转折频率的大小判断超前或滞后校正
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

状态转移矩阵 状态空间分析
本卷考法
  • 利用状态转移矩阵在零时刻的导数求系统矩阵
本卷实例
  • 关键一步：利用转移矩阵在零时刻导数等于状态矩阵这一性质
  • 中间结果：对给定转移矩阵元素逐项求导并取时间为零
  • 卡点：矩阵元素较多时逐项求导易抄错，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过利用状态转移矩阵在零时刻的导数求系统矩阵
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错

信号采样与频谱的基本概念 基本概念与信号
本卷考法
  • 由频移性质判断乘以负一的n次方后离散系统的滤波特性
本卷实例
  • 关键一步：把负一的n次方写成复指数形式，用频移性质搬移频率响应
  • 中间结果：频率响应搬移半个周期后低通与高通特性互换
  • 卡点：频移方向与高低通对应关系易混，本题属信号内容为近似挂靠
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 周期信号可展开为傅里叶级数，各次谐波的幅值构成频谱
  • 冲激采样信号的频谱是原信号频谱的周期延拓
  • 频谱延拓的周期由采样频率决定，不重叠才能由理想低通恢复原信号
  • 恢复用的理想低通截止频率取在采样频率的一半处
步骤
  • 先求连续信号的频谱或按给定波形求谐波幅值
  • 按采样频率写出延拓后频谱的周期与各次副本的位置
  • 检查最高频率是否小于采样频率的一半，判断能否无失真恢复
  • 需要恢复时选取截止频率与增益合适的理想低通滤波器
通用考法
  • 本卷考过由频移性质判断乘以负一的n次方后离散系统的滤波特性
  • 由采样频率判断给定信号能否无失真恢复
  • 写出冲激采样后信号的频谱表达式
  • 确定恢复滤波器的截止频率
常见易错
  • 把采样定理里的两倍关系记成相等，或漏掉两倍
  • 把最高频率与频谱延拓的周期混为一谈

2二、自控第一题：电机位置控制系统#

思路
  • 由给定各环节增益与电机时间常数逐段列写信号关系，画出多回路结构图，再用梅森公式求闭环传递函数
直流电机等机电系统 建模与机电系统
本卷考法
  • 由电枢电压与角速度关系建立直流电机环节
本卷实例
  • 关键一步：把电机写成一阶惯性环节，其增益与机电时间常数给定
  • 中间结果：电枢输入电压到角速度的传递函数为惯性形式
  • 卡点：题面缺失，各增益含义与电枢方程需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由电枢回路电压方程与转矩平衡方程联立
  • 反电动势与转速成正比，电磁转矩与电枢电流成正比
  • 机电时间常数由电气与机械两方面参数共同决定
步骤
  • 写出电枢回路电压平衡方程
  • 写出转矩平衡方程（含负载与粘性摩擦）
  • 消去电枢电流，得到转速或转角对电压的传递函数
通用考法
  • 本卷考过由电枢电压与角速度关系建立直流电机环节
  • 求直流电机转速或位置对电枢电压的传递函数
  • 分析机电时间常数与电气时间常数的数量级关系
常见易错
  • 漏掉反电动势与电磁转矩的耦合项
  • 把电气时间常数与机电时间常数混淆
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 按信号流向逐段串接并化简多回路结构图
本卷实例
  • 关键一步：误差信号经多级放大后加至电枢，速度信号构成内环反馈
  • 中间结果：内环为速度反馈，外环为位置反馈，构成双环结构
  • 卡点：内环与外环的输入输出关系接反会使传函完全改变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过按信号流向逐段串接并化简多回路结构图
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求位置反馈系统的闭环传递函数
本卷实例
  • 关键一步：找出前向通路与各回路，判断回路之间是否接触
  • 中间结果：闭环传函分母含时间常数平方项与开环增益项
  • 卡点：回路增益与余子式容易漏项，结构图需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求位置反馈系统的闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

通用考法
  • 本卷考过由期望极点配置求状态反馈增益矩阵
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反

8八、信号第一题：冲激响应求微分方程#

思路
  • 对单位冲激响应取拉氏变换得系统函数，反写微分方程；由输入变换与系统函数之积求输出，阶跃响应再除以复变量
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由单位冲激响应求微分方程及指定输入下的输出
本卷实例
  • 关键一步：对单位冲激响应作拉氏变换得到系统函数
  • 中间结果：系统函数为一次多项式之比，反写为含输入导数的方程
  • 卡点：阶跃响应等于系统函数除以复变量再反变换，本题属信号内容为近似挂靠
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由单位冲激响应求微分方程及指定输入下的输出
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

9九、信号第二题：理想低通与离散频谱#

思路
  • 用定义证明给定序列的傅里叶变换为理想低通；对输入序列作积化和差求频谱系数；再按通带判断哪些分量保留
信号采样与频谱的基本概念 基本概念与信号
本卷考法
  • 求离散信号频谱系数并分析通过理想低通后的输出
本卷实例
  • 关键一步：用积化和差把输入拆成两个正弦分量，读出各次谐波系数
  • 中间结果：只有频率落在低通通带内的分量才会保留
  • 卡点：理想低通频域为门函数，本题属信号内容为近似挂靠
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 周期信号可展开为傅里叶级数，各次谐波的幅值构成频谱
  • 冲激采样信号的频谱是原信号频谱的周期延拓
  • 频谱延拓的周期由采样频率决定，不重叠才能由理想低通恢复原信号
  • 恢复用的理想低通截止频率取在采样频率的一半处
步骤
  • 先求连续信号的频谱或按给定波形求谐波幅值
  • 按采样频率写出延拓后频谱的周期与各次副本的位置
  • 检查最高频率是否小于采样频率的一半，判断能否无失真恢复
  • 需要恢复时选取截止频率与增益合适的理想低通滤波器
通用考法
  • 本卷考过求离散信号频谱系数并分析通过理想低通后的输出
  • 由采样频率判断给定信号能否无失真恢复
  • 写出冲激采样后信号的频谱表达式
  • 确定恢复滤波器的截止频率
常见易错
  • 把采样定理里的两倍关系记成相等，或漏掉两倍
  • 把最高频率与频谱延拓的周期混为一谈
