1~10一、选择题（1~10）#

思路
  • 十道小题覆盖一阶调节时间、稳定条件、主导极点、根轨迹起止点、超前相位、能控性、李雅普诺夫函数，以及信号的系统性质与频谱说法
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由单位阶跃响应反求一阶系统的调节时间
本卷实例
  • 关键一步：把响应式与一阶阶跃响应标准式对应，读出一阶时间常数
  • 中间结果：时间常数由指数项的衰减率确定
  • 卡点：调节时间按5%误差带取三倍时间常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由单位阶跃响应反求一阶系统的调节时间
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

参数稳定域的确定 稳定性分析
本卷考法
  • 由闭环特征方程用劳斯判据求增益的稳定范围
本卷实例
  • 关键一步：按开环传函写闭环特征多项式并列劳斯表
  • 中间结果：首列元素须分别满足阻尼条件与增益条件
  • 卡点：含参首列元素作分母时要单独讨论符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由闭环特征方程用劳斯判据求增益的稳定范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 由主导极点判断参数变化对超调量的影响
本卷实例
  • 关键一步：比较两参数对应极点与虚轴的距离，定主导参数
  • 中间结果：离虚轴近的主导极点决定动态性能
  • 卡点：两时间常数数量级相差很大时小者影响可忽略
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过由主导极点判断参数变化对超调量的影响
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

根轨迹的绘制法则 根轨迹法
本卷考法
  • 由特征方程写等效开环传函并指出根轨迹起点与终点
本卷实例
  • 关键一步：把特征方程整理成等效开环传函，定零极点
  • 中间结果：起点为开环极点，终点为开环零点与无穷远
  • 卡点：起点个数等于开环极点数，勿把零点当起点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过由特征方程写等效开环传函并指出根轨迹起点与终点
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

典型环节的对数频率特性 频域分析
本卷考法
  • 比较各环节在某频率处的相位正负，判断超前环节
本卷实例
  • 关键一步：取一个具体频率逐式累加相角并比较正负
  • 中间结果：含一阶微分环节或振荡环节的式子可出现正相角
  • 卡点：相角须逐环节累加，不能只看其中一段
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例环节是水平线，积分与微分分别是 -20 与 +20 dB/dec 的斜线
  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec
  • 一阶微分环节与惯性环节幅频互为镜像
  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤
  • 把传递函数分解为典型环节乘积
  • 逐环节画出对数幅频渐近线与相频曲线
  • 代数相加得到总特性
通用考法
  • 本卷考过比较各环节在某频率处的相位正负，判断超前环节
  • 画出某一典型环节的 Bode 图
  • 由 Bode 图识别环节类型
  • 说明转角频率处的幅值与相角
常见易错
  • 把惯性环节高频渐近线的 -20 写成 -40
  • 振荡环节谐振峰位置误当作 ωn

能控性与能观性 状态空间分析
本卷考法
  • 判断关于能控性定义与判据的表述是否正确
本卷实例
  • 关键一步：能控判据是能控性矩阵满秩，只与A、B有关
  • 中间结果：不完全能控时不能任意配置状态反馈极点
  • 卡点：能控性由A、B决定，与C、D无关
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断关于能控性定义与判据的表述是否正确
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 判断给定函数能否作为李雅普诺夫函数
本卷实例
  • 关键一步：先验函数正定，再验沿轨线的导数半负定
  • 中间结果：对给定状态方程求导数后判断其符号
  • 卡点：只验证函数正定不够，须再验导数符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过判断给定函数能否作为李雅普诺夫函数
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

信号采样与频谱的基本概念 基本概念与信号
本卷考法
  • 判断输入输出关系式所描述系统的线性、时不变、因果与稳定
本卷实例
  • 关键一步：按定义分别验证可加齐次性、时移性与因果性
  • 中间结果：时间尺度变换或乘时间因子会破坏时不变性
  • 卡点：一条关系可同时不满足多种性质，须逐项判定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 周期信号可展开为傅里叶级数，各次谐波的幅值构成频谱
  • 冲激采样信号的频谱是原信号频谱的周期延拓
  • 频谱延拓的周期由采样频率决定，不重叠才能由理想低通恢复原信号
  • 恢复用的理想低通截止频率取在采样频率的一半处
步骤
  • 先求连续信号的频谱或按给定波形求谐波幅值
  • 按采样频率写出延拓后频谱的周期与各次副本的位置
  • 检查最高频率是否小于采样频率的一半，判断能否无失真恢复
  • 需要恢复时选取截止频率与增益合适的理想低通滤波器
通用考法
  • 本卷考过判断输入输出关系式所描述系统的线性、时不变、因果与稳定
  • 由采样频率判断给定信号能否无失真恢复
  • 写出冲激采样后信号的频谱表达式
  • 确定恢复滤波器的截止频率
常见易错
  • 把采样定理里的两倍关系记成相等，或漏掉两倍
  • 把最高频率与频谱延拓的周期混为一谈

二二、机电系统建模与传函#

思路
  • 由给定的机械系统结构图分别对两个质量块受力分析，列微分方程后取零初始条件拉氏变换，联立消元求输出对输入的传递函数
机械系统建模 建模与机电系统
本卷考法
  • 由机械系统结构图列写运动方程并求传递函数
本卷实例
  • 关键一步：按牛顿定律分别对两个质量块列受力平衡方程
  • 中间结果：两方程联立消去中间位移变量即得传函
  • 卡点：弹簧阻尼连接关系以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过由机械系统结构图列写运动方程并求传递函数
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 对微分方程组取拉氏变换并消元求传函
本卷实例
  • 关键一步：零初始条件下把每个微分方程化为代数方程
  • 中间结果：联立消元后分子分母均为s的多项式
  • 卡点：黏性摩擦项的符号方向易取反，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律

本卷考法

八八、离散周期信号的傅里叶级数#

思路
  • 由周期冲激串的傅里叶级数系数积分式，利用冲激抽样性质化为有限和，证明系数是周期的，再对给定余弦序列求系数
信号采样与频谱的基本概念 基本概念与信号
本卷考法
  • 证明周期冲激串的傅里叶级数系数是周期的
本卷实例
  • 关键一步：按定义积分并利用冲激抽样性质化为有限和
  • 中间结果：求和式恰为原序列的离散傅里叶级数系数
  • 卡点：本题属信号内容，考点库无对应，为借位挂靠
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 周期信号可展开为傅里叶级数，各次谐波的幅值构成频谱
  • 冲激采样信号的频谱是原信号频谱的周期延拓
  • 频谱延拓的周期由采样频率决定，不重叠才能由理想低通恢复原信号
  • 恢复用的理想低通截止频率取在采样频率的一半处
步骤
  • 先求连续信号的频谱或按给定波形求谐波幅值
  • 按采样频率写出延拓后频谱的周期与各次副本的位置
  • 检查最高频率是否小于采样频率的一半，判断能否无失真恢复
  • 需要恢复时选取截止频率与增益合适的理想低通滤波器
通用考法
  • 本卷考过证明周期冲激串的傅里叶级数系数是周期的
  • 由采样频率判断给定信号能否无失真恢复
  • 写出冲激采样后信号的频谱表达式
  • 确定恢复滤波器的截止频率
常见易错
  • 把采样定理里的两倍关系记成相等，或漏掉两倍
  • 把最高频率与频谱延拓的周期混为一谈
