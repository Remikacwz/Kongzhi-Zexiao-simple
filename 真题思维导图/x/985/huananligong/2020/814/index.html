三三、最小相位系统频响与采样9 分#

思路
  • 由对数幅频特性辨识二阶振荡环节参数；再按频率特性求两个正弦输入下的稳态输出
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由最小相位系统的对数幅频特性反求传递函数
本卷实例
  • 关键一步：由低频段高度读增益、由转折频率读时间常数
  • 中间结果：谐振峰高度对应阻尼比，二阶振荡环节参数随之确定
  • 卡点：幅频曲线以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由最小相位系统的对数幅频特性反求传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

本卷考法

  • 中间结果：稳态输出为同频率正弦，幅值乘 |G(jω)|、相位加 ∠G

  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤

  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)

  • 相角累加时漏掉积分环节的 -90°

四四、结构图求传函8 分#

思路
  • 列回路与前向通路，用梅森公式或逐层化简求闭环传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求多回路系统的闭环传递函数
本卷实例
  • 关键一步：找出全部前向通路、回路及互不接触回路
  • 中间结果：分别求各前向通路的余子式并代入梅森公式
  • 卡点：回路符号或互不接触关系判断错误
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求多回路系统的闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 按结构图逐层化简求总传递函数
本卷实例
  • 关键一步：先化简内环再逐步向外合并串联与并联环节
  • 中间结果：各回路共用同一特征式分母
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过按结构图逐层化简求总传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

五五、系统性能与扰动误差20 分#

思路
  • 由 G(s) 阶跃响应求传递函数，再化闭环为标准二阶形式求超调量；分析阶跃扰动下的稳态误差与可消除性
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由单位阶跃响应求传递函数并计算最大超调量
本卷实例
  • 关键一步：对阶跃响应求导得到传递函数，再化标准二阶形式
  • 中间结果：由闭环分母系数求 ωn 与 ξ，再代入超调量公式
  • 卡点：未把高阶项归一化就直接读标准参数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由单位阶跃响应求传递函数并计算最大超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求阶跃扰动作用下系统的稳态误差
本卷实例
  • 关键一步：令参考输入为零，写出扰动到误差的传递函数
  • 中间结果：用终值定理求扰动误差的极限表达式
  • 卡点：求扰动传函时没有把参考输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求阶跃扰动作用下系统的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

减小稳态误差的措施 稳态误差
本卷考法
  • 分析调节增益能否消除阶跃扰动引起的稳态误差
本卷实例
  • 关键一步：检查扰动误差表达式是否含可化为零的因子
  • 中间结果：改变增益只能减小误差，不能使其恒为零
  • 卡点：把减小稳态误差误说成完全消除
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过分析调节增益能否消除阶跃扰动引起的稳态误差
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

本卷考法

常见易错

稳定裕度 频域分析
本卷考法
  • 由相位裕度判断闭环系统的相对稳定性
本卷实例
  • 关键一步：相位裕度小于零说明闭环系统不稳定
  • 中间结果：裕度大小反映稳定程度与超调趋势
  • 卡点：把增益裕度和相位裕度的定义混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由相位裕度判断闭环系统的相对稳定性
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

  • 卡点：提高增益时未检查稳定性是否被破坏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分

  • 说明微分项对噪声的影响

七七、离散时间系统与 DTFT18 分#

思路
  • 用 DTFT 微分性质证明 n²x[n] 的变换；由输入输出频域关系判断线性与时不变性，并求给定输入的响应
z 变换与 z 反变换 离散控制系统
本卷考法
  • 用离散时间傅里叶变换的微分性质证明变换关系
本卷实例
  • 关键一步：对 DTFT 定义式两边关于 ω 连续求导
  • 中间结果：n²x[n] 的 DTFT 与 X(e^{jω}) 的二阶导数相差负号
  • 卡点：把导数阶数或符号对应错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • z 变换是离散信号的拉氏变换，令 z=e^{Ts} 得到
  • 常用函数的 z 变换要熟记
  • z 反变换可用部分分式法、幂级数法或留数法
  • 左半 s 平面映射到 z 平面单位圆内
步骤
  • 将连续传递函数展开为部分分式
  • 逐项查表做 z 变换
  • 需要时做 z 反变换求时间序列
通用考法
  • 本卷考过用离散时间傅里叶变换的微分性质证明变换关系
  • 求给定函数的 z 变换
  • 求 z 反变换得到采样序列
