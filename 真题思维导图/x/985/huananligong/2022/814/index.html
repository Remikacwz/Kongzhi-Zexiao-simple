思路
  • 八道填空覆盖电路传函、自振荡临界增益、超前校正、Bode穿越斜率、状态转移矩阵、离散频谱与前馈补偿
由电路或机械系统求传递函数 传递函数
本卷考法
  • 用复阻抗法由电路图求网络传递函数
本卷实例
  • 关键一步：把电容与外接电阻先并联再与输入阻抗串联分压
  • 中间结果：整理成两个一阶因子之比的传递函数形式
  • 卡点：电路图未读，元件连接方式需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过用复阻抗法由电路图求网络传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由自振荡条件求临界开环增益与振荡频率
本卷实例
  • 关键一步：自振荡即根轨迹与虚轴相交，令复变量等于纯虚数代入特征方程
  • 中间结果：实部虚部分别为零得到振荡频率与临界增益
  • 卡点：自振荡是临界稳定状态，增益取临界值而非区间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由自振荡条件求临界开环增益与振荡频率
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

超前校正 系统校正
本卷考法
  • 说明超前校正提供的相位符号并求最大补偿角频率
本卷实例
  • 关键一步：把校正装置写成两个一阶因子之比的标准超前形式
  • 中间结果：超前网络在转折频率的几何中点处提供最大相位
  • 卡点：分子分母哪个转折频率大要先看清，否则超前滞后判断反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过说明超前校正提供的相位符号并求最大补偿角频率
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

开环对数频率特性的绘制 频域分析
本卷考法
  • 由最小相位系统渐近线穿越零分贝的斜率判断闭环性能
本卷实例
  • 关键一步：中频段以负二十斜率穿越零分贝线时响应较平稳
  • 中间结果：穿越斜率过陡对应超调量增大
  • 卡点：低频段与高频段各有分工，不能只看穿越斜率一处
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过由最小相位系统渐近线穿越零分贝的斜率判断闭环性能
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

  • 求状态转移矩阵

  • 用性质验证转移矩阵是否正确

信号采样与频谱的基本概念 基本概念与信号
本卷考法
  • 由离散周期信号的周期与傅里叶级数求指定序号系数
本卷实例
  • 关键一步：先由周期确定基频，再用欧拉公式展开正弦分量
  • 中间结果：级数系数在正负一对序号上各取一半且以周期循环
  • 卡点：指定序号要按周期折回主值区间，本题属信号内容为近似挂靠
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 周期信号可展开为傅里叶级数，各次谐波的幅值构成频谱
  • 冲激采样信号的频谱是原信号频谱的周期延拓
  • 频谱延拓的周期由采样频率决定，不重叠才能由理想低通恢复原信号
  • 恢复用的理想低通截止频率取在采样频率的一半处
步骤
  • 先求连续信号的频谱或按给定波形求谐波幅值
  • 按采样频率写出延拓后频谱的周期与各次副本的位置
  • 检查最高频率是否小于采样频率的一半，判断能否无失真恢复
  • 需要恢复时选取截止频率与增益合适的理想低通滤波器
通用考法
  • 本卷考过由离散周期信号的周期与傅里叶级数求指定序号系数
  • 由采样频率判断给定信号能否无失真恢复
  • 写出冲激采样后信号的频谱表达式
  • 确定恢复滤波器的截止频率
常见易错
  • 把采样定理里的两倍关系记成相等，或漏掉两倍
  • 把最高频率与频谱延拓的周期混为一谈

2二、判断并改错18 分#

思路
  • 六道判断覆盖最小相位、二阶超调量比较、稳定性与初值关系、前馈校正适用条件与系统线性因果性，要求判断后改正
最小相位系统与非最小相位系统 频域分析
本卷考法
  • 判断给定分式是否表示最小相位系统
本卷实例
  • 关键一步：分别对分子与分母列劳斯表，检查是否有右半平面根
  • 中间结果：分子或分母存在右半平面根即为非最小相位
  • 卡点：分子也要判稳，不能只判分母
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过判断给定分式是否表示最小相位系统
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 比较两个二阶系统的最大超调量大小
本卷实例
  • 关键一步：同时把两个传递函数化成标准二阶形式读阻尼比
  • 中间结果：阻尼比越大超调量越小，据此比较两个系统
  • 卡点：比较前先归一化二次项系数，否则阻尼比读错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过比较两个二阶系统的最大超调量大小
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

劳斯判据 稳定性分析
本卷考法
  • 判断线性定常系统稳定性与初始状态是否有关
本卷实例
  • 关键一步：稳定性由系统结构与参数决定的特征根分布来判断
  • 中间结果：线性定常系统的稳定性与初始状态无关
  • 卡点：非线性系统结论不同，不要把两类系统混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过判断线性定常系统稳定性与初始状态是否有关
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

思路

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把含扰动通道的结构图化为标准二阶闭环形式
本卷实例
  • 关键一步：把给定通道与扰动通道分开化简，各求其传递函数
  • 中间结果：闭环分母为二次多项式，系数含开环增益
  • 卡点：结构图未读，扰动接入点位置需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由单位冲激响应求微分方程并在给定输入下求输出
本卷实例
  • 关键一步：对单位冲激响应取拉氏变换得到系统函数
  • 中间结果：由系统函数反写含输入导数的微分方程
  • 卡点：输入为指数信号时用部分分式展开再反变换，本题属信号内容为近似挂靠
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由单位冲激响应求微分方程并在给定输入下求输出
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上
