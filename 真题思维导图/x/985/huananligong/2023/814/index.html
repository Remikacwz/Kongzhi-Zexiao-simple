1一、填空#

思路
  • 三道填空覆盖反馈控制系统基本组成、高阶系统在多项式输入下的稳态误差，以及两个周期分量叠加的最小正周期
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 列举反馈控制系统的基本组成元件
本卷实例
  • 关键一步：按给定、比较、放大、执行、被控对象与检测反馈逐项列出
  • 中间结果：闭环系统必须含检测与比较环节才能构成反馈
  • 卡点：源文只印其中一空，其余空需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过列举反馈控制系统的基本组成元件
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环传递函数判断系统型别并求静态误差系数
本卷实例
  • 关键一步：从开环传函分母中数积分环节个数确定系统型别
  • 中间结果：由低频段增益与型别写出静态加速度误差系数
  • 卡点：型别数错会导致误差系数与稳态误差全都错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由开环传递函数判断系统型别并求静态误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求多项式输入下系统的稳态误差
本卷实例
  • 关键一步：把输入按阶跃、斜坡、加速度分量分别求误差再叠加
  • 中间结果：二次以上分量由静态加速度误差系数决定
  • 卡点：各分量系数要与输入多项式系数对应，容易漏项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求多项式输入下系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

信号采样与频谱的基本概念 基本概念与信号
本卷考法
  • 求两个不同频率周期分量叠加信号的最小正周期
本卷实例
  • 关键一步：分别求各分量的周期，再取两者的最小公倍数
  • 中间结果：周期之比化为最简整数比后求共同周期
  • 卡点：某分量角频率含分数时要先化最简，本题属信号内容为近似挂靠
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 周期信号可展开为傅里叶级数，各次谐波的幅值构成频谱
  • 冲激采样信号的频谱是原信号频谱的周期延拓
  • 频谱延拓的周期由采样频率决定，不重叠才能由理想低通恢复原信号
  • 恢复用的理想低通截止频率取在采样频率的一半处
步骤
  • 先求连续信号的频谱或按给定波形求谐波幅值
  • 按采样频率写出延拓后频谱的周期与各次副本的位置
  • 检查最高频率是否小于采样频率的一半，判断能否无失真恢复
  • 需要恢复时选取截止频率与增益合适的理想低通滤波器
通用考法
  • 本卷考过求两个不同频率周期分量叠加信号的最小正周期
  • 由采样频率判断给定信号能否无失真恢复
  • 写出冲激采样后信号的频谱表达式
  • 确定恢复滤波器的截止频率
常见易错
  • 把采样定理里的两倍关系记成相等，或漏掉两倍
  • 把最高频率与频谱延拓的周期混为一谈

2二、判断#

思路
  • 两道可见判断题分别考查状态转移矩阵的指数运算性质与理想低通滤波器的因果性
状态转移矩阵 状态空间分析
本卷考法
  • 判断状态转移矩阵指数运算性质是否成立
本卷实例
  • 关键一步：指数相加性质成立当且仅当两个矩阵可交换
  • 中间结果：题给指数相减的形式与正确性质不符
  • 卡点：不满足两矩阵相乘可交换时不能拆成指数相乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过判断状态转移矩阵指数运算性质是否成立
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错

3三、由微分方程求结构图与传函#

思路
  • 由给定各变量间微分方程逐式取拉氏变换，按信号流向画出含反馈的结构图，再用梅森公式求闭环传递函数
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由方程组画出含内环与外环的系统结构图
本卷实例
  • 关键一步：把每个方程整理成一个环节的输入输出关系
  • 中间结果：误差信号经各级放大到输出，输出经反馈系数回到输入
  • 卡点：方程中二阶导数对应两个积分器串联，结构图需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由方程组画出含内环与外环的系统结构图
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求多回路系统的闭环传递函数
本卷实例
  • 关键一步：找出前向通路、各回路以及回路之间的接触关系
  • 中间结果：闭环分母含各级增益乘积与反馈系数的乘积项
  • 卡点：余子式中与通路接触的回路要剔除，容易多算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求多回路系统的闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

  • 中间结果：总闭环分母为二次多项式，系数含增益与反馈系数
  • 卡点：结构图未读，内环反馈接入位置需回原卷核对

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由超调量反求二阶系统阻尼比
本卷实例
  • 关键一步：把闭环传函化为标准二阶形式，由超调量公式反查阻尼比
  • 中间结果：阻尼比确定后其余系数之间的关系随之确定
  • 卡点：标准形式归一化时二次项系数要同时除掉
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由超调量反求二阶系统阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率分析系统动态性能
本卷实例
  • 关键一步：由超调量定阻尼比，再代调节时间与峰值时间公式
  • 中间结果：自然频率由开环增益的平方根确定
  • 卡点：调节时间按误差带选系数，不能与峰值时间混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率分析系统动态性能
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

扰动作用下的稳态误差 稳态误差
本卷考法
  • 由斜坡扰动下的稳态误差要求反求参数
本卷实例
  • 关键一步：先求误差对扰动的传递函数，再代入斜坡扰动求极限
  • 中间结果：稳态误差为开环增益的倒数，据此定出增益
  • 卡点：误差传递函数分子分母约简时容易出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

8八、连续LTI系统冲激响应#

思路
  • 由冲激响应取拉氏变换得系统函数并反写微分方程；由给定输出与系统函数反求输入；对含积分关系的因果系统求冲激响应
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由冲激响应求微分方程并求指定输出对应的输入
本卷实例
  • 关键一步：对冲激响应取拉氏变换得系统函数，再由输出变换反求输入变换
  • 中间结果：系统函数为部分分式之和，反写为二阶微分方程
  • 卡点：由输出反求输入时要检查系统函数零点是否与输出零点相消
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由冲激响应求微分方程并求指定输出对应的输入
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

9九、离散周期信号频谱关系#

思路
  • 分别证明有限长截断序列的傅里叶变换在基频整数倍处取样等于原周期信号的傅里叶级数系数，以及序列插零后的频谱尺度关系
信号采样与频谱的基本概念 基本概念与信号
本卷考法
  • 证明周期信号截断后的变换与傅里叶级数系数的关系
本卷实例
  • 关键一步：对有限长截断序列按离散时间傅里叶变换定义求和
  • 中间结果：把变换在基频整数倍处取样即得傅里叶级数系数
  • 卡点：截断区间取一个周期且取样点与基频对应，本题属信号内容为近似挂靠
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 周期信号可展开为傅里叶级数，各次谐波的幅值构成频谱
  • 冲激采样信号的频谱是原信号频谱的周期延拓
  • 频谱延拓的周期由采样频率决定，不重叠才能由理想低通恢复原信号
  • 恢复用的理想低通截止频率取在采样频率的一半处
步骤
  • 先求连续信号的频谱或按给定波形求谐波幅值
  • 按采样频率写出延拓后频谱的周期与各次副本的位置
  • 检查最高频率是否小于采样频率的一半，判断能否无失真恢复
  • 需要恢复时选取截止频率与增益合适的理想低通滤波器
通用考法
  • 本卷考过证明周期信号截断后的变换与傅里叶级数系数的关系
  • 由采样频率判断给定信号能否无失真恢复
  • 写出冲激采样后信号的频谱表达式
  • 确定恢复滤波器的截止频率
常见易错
  • 把采样定理里的两倍关系记成相等，或漏掉两倍
  • 把最高频率与频谱延拓的周期混为一谈
