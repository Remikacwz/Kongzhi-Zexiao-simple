自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 自动控制的定义与实现方式
本卷实例
  • 关键一步：答出在没有人直接参与下按预定规律运行
  • 中间结果：靠控制装置使被控对象保持一定状态与性能
  • 卡点：填空限定语是无人直接参与，别漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过自动控制的定义与实现方式
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把被控量与操纵量搞反
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
传递函数的定义与基本性质 传递函数
本卷考法
  • 传递函数只与系统本身的结构与参数有关
本卷实例
  • 关键一步：由定义判断传递函数与哪些因素有关
  • 中间结果：只与内部结构参数有关，与输入量无关
  • 卡点：外部因素指输入量与初始条件等
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过传递函数只与系统本身的结构与参数有关
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过忽略零初始条件这一前提
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

劳斯判据 稳定性分析
本卷考法
  • 稳定性定义与劳斯表等比例变换性质
本卷实例
  • 关键一步：扰动消失后系统能回复到原平衡状态则稳定
  • 中间结果：劳斯表某行同乘或同除正数不影响判稳
  • 卡点：乘除的必须是正实数，负数会改变符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过稳定性定义与劳斯表等比例变换性质
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过把恢复原平衡状态写成任意状态
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 根轨迹利用开环传递函数零极点分布作图
本卷实例
  • 关键一步：由根轨迹法的作图依据确定填空内容
  • 中间结果：依据是开环传递函数的零极点分布
  • 卡点：根轨迹图上读的是闭环极点位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过根轨迹利用开环传递函数零极点分布作图
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 本卷考过把开环零极点与闭环极点混为一谈
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

根轨迹的绘制法则 根轨迹法
本卷考法
  • 实轴根轨迹右侧开环实零极点个数和的奇偶
本卷实例
  • 关键一步：数实轴段右侧实开环零极点的总个数
  • 中间结果：一百八十度根轨迹取奇数，零度根轨迹取偶数
  • 卡点：只数实轴上的零极点，复数对不计入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过实轴根轨迹右侧开环实零极点个数和的奇偶
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过零极点个数算错导致奇偶判反
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

附加开环零极点的影响 根轨迹法
本卷考法
  • 增加开环极点为何使根轨迹向右半平面弯曲
本卷实例
  • 关键一步：比较增加零点与增加极点对渐近线与分离点的影响
  • 中间结果：增加开环极点使根轨迹向右侧移动
  • 卡点：题问的是使根轨迹右弯，应填开环极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过增加开环极点为何使根轨迹向右半平面弯曲
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 本卷考过把附加零点与附加极点的影响搞反
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
描述函数法基础 非线性系统
本卷考法
  • 描述函数的定义
本卷实例
  • 关键一步：按描述函数法的谐波线性化定义作答
  • 中间结果：是非线性部件输出的一次谐波分量与正弦输入之比
  • 卡点：只取一次谐波分量，不是输出全量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过描述函数的定义
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 本卷考过把描述函数写成输出全量与输入之比
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

超前校正 系统校正
本卷考法
  • 超前校正网络最大相位超前量处的频率
本卷实例
  • 关键一步：由超前网络相频特性求导取极大值
  • 中间结果：最大超前角频率是两转折频率的几何平均
  • 卡点：公式里是根号下 a 乘 T，别漏根号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过超前校正网络最大相位超前量处的频率
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 本卷考过把最大超前角频率与转折频率混用
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

频率特性的物理意义与求法 频域分析
本卷考法
  • 幅频特性的定义
本卷实例
  • 关键一步：按频率特性定义判断填空内容
  • 中间结果：是正弦输入下输出与输入的幅值之比
  • 卡点：幅频看幅值之比，相频才看相位之差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过幅频特性的定义
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过把幅频特性与相频特性混为一谈
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 阻尼比越小超调量越大
  • 调整时间反映系统快速性
本卷实例
  • 关键一步：由二阶动态指标随阻尼比的变化趋势判断
  • 中间结果：阻尼比减小则超调量增大、振荡加剧
  • 卡点：稳定性由实部决定，超调量才看阻尼比
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
