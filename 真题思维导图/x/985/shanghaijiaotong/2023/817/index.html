一一、工作原理方框图与被控对象#

思路
  • 由给定装置画出工作原理方框图，指认被控对象、输入输出并说明系统工作过程
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 画控制系统工作原理方框图并指出被控对象与输入输出量
本卷实例

  • 中间结果：再按信息流向连成闭环方框图
  • 卡点：被控装置以图给出，环节与信号需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过画控制系统工作原理方框图并指出被控对象与输入输出量
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错

  • 把被控量与操纵量搞反
