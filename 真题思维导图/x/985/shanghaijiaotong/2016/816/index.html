一一、过程控制系统原理与框图#

思路
  • 由热交换器温度控制示意图说明闭环工作过程，画系统框图，并指认控制变量、被控对象与被控变量
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 说明热交换器温度系统的工作过程
本卷实例
  • 关键一步：按被控量、执行器与偏差梳理闭环
  • 中间结果：温度变送器测得热物料温度并与给定值比较
  • 卡点：系统结构以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）

  • 说明系统的工作过程

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口

三三、信号流图与梅森公式#

思路
  • 按信号流图找前向通路与独立回路，再由梅森增益公式写出总传输
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图用梅森公式求传函
本卷实例
  • 关键一步：找出全部独立回路与前向通路
  • 中间结果：特征式含互不接触回路乘积项
  • 卡点：流图以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图用梅森公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过互不接触回路漏算或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

四四、校正使阶跃稳态误差为零#

思路
  • 从单位阶跃输入下稳态误差为零反推系统所需型别，再在原系统前串入积分环节提升型别
系统型别与静态误差系数 稳态误差
本卷考法
  • 由稳态误差为零反推系统所需型别
本卷实例
  • 关键一步：单位阶跃误差为零要求系统至少 I 型
  • 中间结果：在原系统前串入积分环节提升型别
  • 卡点：待校正对象以框图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由稳态误差为零反推系统所需型别
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 本卷考过把型别与开环增益混为一谈
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法

本卷实例
  • 关键一步：令校正后开环含至少一个积分环节
  • 中间结果：校正装置取积分形式即可满足零误差
  • 卡点：题图未给全，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大

  • 写出输入信号的拉氏变换

五五、根轨迹与零度/180 度条件#

思路
  • 由特征方程整理等效开环传函，按参数正负区分零度与 180 度根轨迹，再由阻尼比确定 K
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 区分零度与 180 度根轨迹
本卷实例
  • 关键一步：由特征方程整理出等效开环传函
  • 中间结果：按开环传函符号判断用零度还是 180 度条件
  • 卡点：参数取值以符号给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过区分零度与 180 度根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 本卷考过零度根轨迹仍沿用 180 度相角条件
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由阻尼比 ζ=0.7 在根轨迹上确定 K
本卷实例
  • 关键一步：作 45 度等阻尼射线与轨迹求交
  • 中间结果：交点代入幅值条件反求 K
  • 卡点：根轨迹分支以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由阻尼比 ζ=0.7 在根轨迹上确定 K
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 本卷考过把等阻尼线画成垂直线
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

六六、滞后-超前校正设计#

思路
  • 比较未校正系统的截止频率与相角裕度，判断单一校正如不可行则设计滞后-超前装置
滞后-超前校正 系统校正
本卷考法
  • 设计滞后-超前校正使截止频率与相角裕度达标
本卷实例
  • 关键一步：先由截止频率要求定超前部分转折频率
  • 中间结果：由相角裕度差额确定 a 与 T
  • 卡点：Bode 图以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 兼顾稳态精度与动态性能，适合指标要求较高的场合
  • 低频段用滞后部分提高增益，中高频段用超前部分提高裕度
  • 设计时先确定超前部分，再确定滞后部分
步骤
  • 按稳态精度要求确定开环增益
  • 选择新的截止频率并计算超前部分参数
  • 计算为把低频增益抬到要求值所需的滞后部分参数
  • 合并写出校正装置并校验
通用考法
  • 本卷考过设计滞后-超前校正使截止频率与相角裕度达标
  • 设计滞后-超前校正装置
  • 说明为何单一校正无法满足指标
  • 分析校正后系统的低频与高频特性
常见易错
  • 本卷考过先设计滞后部分导致截止频率反复调整
  • 先设计滞后部分导致截止频率反复调整
  • 两部分的转折频率分布重叠，互相削弱

校正的基本概念与性能指标 系统校正
本卷考法
  • 判断单一超前或滞后校正是否可行
本卷实例
  • 关键一步：比较未校正与目标截止频率处的相角裕度
  • 中间结果：两者都不满足时改用滞后-超前装置
  • 卡点：未校正系统图以扫描图给出，需回原卷核对图

要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
