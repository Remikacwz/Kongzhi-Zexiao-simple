一一、液位控制系统建模与控制框图20 分#

思路
  • 由两容器流量平衡与液阻关系列微分方程，求第二个容器液位对输入流量的传函；再画控制框图说明按偏差调节阀门的工作过程
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 说明液位控制系统的工作过程与被控量
本卷实例
  • 关键一步：按给定值、被控量、执行器与偏差梳理闭环
  • 中间结果：浮子测液位并与期望值比较后调阀门开度
  • 卡点：控制系统框图以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过说明液位控制系统的工作过程与被控量
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 本卷考过只描述现象不指认被控量与操纵量
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半
由电路或机械系统求传递函数 传递函数
本卷考法

本卷实例
  • 关键一步：对两容器分别列流量平衡与液阻关系
  • 中间结果：消去中间液位与流量得输入输出传函
  • 卡点：液位系统按阻容网络类比，属借位

  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤

  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法

  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过把液阻与液容的定义式列反
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

思路
  • 对动态方程取拉氏变换，按状态变量关系画结构图，再由梅森公式求 Y(s)/R(s) 与 Y(s)/N(s)
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法

本卷实例

  • 卡点：方程 OCR 有重号，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤

  • 令 N(s)=0，求输入到输出的传递函数

通用考法

常见易错

  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

本卷实例

  • 余子式中未剔除与通路接触的回路

三三、二阶系统参数与动态指标20 分#

思路
  • 由闭环传函读二阶标准参数；求单位斜坡稳态误差；按阻尼比与误差要求反求 K1、Kf；最后算超调量、上升与调整时间
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函求阻尼比与自然频率
本卷实例
  • 关键一步：把闭环传函化成二阶标准形式再读系数
  • 中间结果：一次项系数对应 2ξωn，常数项对应 ωn²
  • 卡点：系统框图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过未把 s² 项系数归一化就比对标准式
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：先由开环传函判断系统型别
  • 中间结果：静态速度误差系数由开环传函极限给出
  • 卡点：误差定义取在输入端还是输出端要按题意
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过未判稳就直接用终值定理
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

四四、根轨迹绘制与阻尼比约束20 分#

思路
  • 以 K 为变量作根轨迹，求渐近线、分离点等特征量；再由主导极点阻尼比条件确定 K
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制 K 变化时的根轨迹
本卷实例
  • 关键一步：先标开环零极点并确定实轴根轨迹段
  • 中间结果：渐近线交点由开环极点实部均值给出
  • 卡点：根轨迹图以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制 K 变化时的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过渐近线夹角公式中的 2k+1 写成 2k
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

五五、Bode 图与 Nyquist 判据20 分#

思路
  • 由开环传函画 Bode 渐近线，找相位穿越频率，再用 Nyquist 判据讨论 K 与稳定性的关系
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制开环对数渐近幅频特性
本卷实例
  • 关键一步：由低频段斜率和各转折频率逐段画渐近线
  • 中间结果：各转折频率处斜率依次叠加
  • 卡点：题给传函 OCR 有误，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
