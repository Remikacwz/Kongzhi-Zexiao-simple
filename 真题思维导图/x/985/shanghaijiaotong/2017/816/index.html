本卷考法

二二、两图梅森公式求传函20 分#

思路
  • 对题给两幅结构图分别找前向通路与独立回路，用梅森公式写总传输，并可用等效化简核对
梅森增益公式与信号流图 传递函数
本卷考法
  • 对两幅图分别用梅森公式求 C(s)/R(s)
本卷实例
  • 关键一步：逐图列前向通路、独立回路与余子式
  • 中间结果：特征式含回路增益与互不接触回路乘积
  • 卡点：两幅结构图以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过对两幅图分别用梅森公式求 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过互不接触回路漏算或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

三三、由指标反求动态性能20 分#

思路
  • 由超调量与峰值时间先求阻尼比和自然频率，再算上升时间与调整时间
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间求上升与调整时间
本卷实例
  • 关键一步：先由超调量求阻尼比，再求自然频率
  • 中间结果：用 ξ 与 ωn 算上升和调整时间
  • 卡点：结构图以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法

  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过峰值时间与上升时间混用
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用

本卷实例

  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定

思路
  • 由开环零极点画根轨迹，求出射角、渐近线及与虚轴交点，确定临界增益
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制 K 变化时的根轨迹草图
本卷实例
  • 关键一步：先标开环零极点与实轴根轨迹段
  • 中间结果：按 n-m 定渐近线条数与夹角
  • 卡点：根轨迹图以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法

  • 按法则绘制根轨迹草图

  • 判断某段实轴是否属于根轨迹

  • 实轴段判据中的零极点个数算错

五五、Nyquist 图判稳#

思路
  • 对题给四幅奈氏图分别数开环右半平面极点并判断包围圈数，再判闭环稳定性
奈奎斯特判据 稳定性分析
本卷考法
  • 由四幅奈氏图分别判断闭环稳定性
本卷实例
  • 关键一步：先数每图开环右半平面极点数 P
  • 中间结果：按 Z=P-2N 判闭环右半平面极点数
  • 卡点：四幅奈氏图以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由四幅奈氏图分别判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过把包围圈数正负号定义搞反
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

六六、超前校正设计#

思路
  • 由速度误差系数与相角裕度要求确定开环增益和最大超前角，再设计串联超前装置并验证
超前校正 系统校正
本卷考法
  • 按相角裕度与截止频率设计串联超前校正
本卷实例
  • 关键一步：由速度误差系数定所需开环增益
  • 中间结果：由目标相角裕度与未校正裕度差求最大超前角
  • 卡点：Bode 图以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤

  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法

  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 本卷考过计算补偿角时忽略截止频率变化带来的相角损失
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
