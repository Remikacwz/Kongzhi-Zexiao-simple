1选择题：二阶系统与根轨迹基本结论#

思路
  • 三道选择题分别考：ζ 与 K 对超调/快速性的影响、三阶系统的稳定域与纯虚根、增加开环零极点对根轨迹走向的影响
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 判断 ζ 与 K 变化时超调量、快速性的变化方向
本卷实例
  • 关键一步：超调量只由 ζ 决定：ζ 增大 → σ% 减小；快速性看 ξωn 或 ωn
  • 关键一步：闭环增益 K 增大通常使 ζ 减小、ωn 增大 → 超调变大、响应变快
  • 中间结果：同一 K 同时改变 ζ 与 ωn，超调与快速性不能独立调整
  • 卡点：把「稳定性增强」与「快速性增强」当成同一件事——两者常常此消彼长
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过判断 ζ 与 K 变化时超调量、快速性的变化方向
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

参数稳定域的确定 稳定性分析
本卷考法
  • 判断 G=K*/(s(s+1)(s+2)) 的稳定域与纯虚根条件
本卷实例
  • 关键一步：列劳斯表得稳定条件 0 < K* < 6；K*=6 时出现纯虚根
  • 关键一步：纯虚根由劳斯表辅助方程 F(s)=0 解出，不是随便配出来的
  • 中间结果：临界 K* 由劳斯表首列某项为零给出，代回辅助方程得纯虚根
  • 卡点：纯虚根的具体数值要由辅助方程算出，凭直觉写数值容易错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过判断 G=K*/(s(s+1)(s+2)) 的稳定域与纯虚根条件
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

附加开环零极点的影响 根轨迹法
本卷考法
  • 判断增加开环极点/零点对稳定性和根轨迹推移方向的影响
本卷实例
  • 关键一步：增加开环零点 → 根轨迹左移，稳定性改善；增加开环极点 → 右移，稳定性变差
  • 关键一步：注意方向：向左半平面增加极点会让根轨迹朝右半平面推移
  • 中间结果：以零点吸引、极点排斥判断根轨迹左移还是右移
  • 卡点：把「增加零点改善稳定性」与「增加极点恶化稳定性」记反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过判断增加开环极点/零点对稳定性和根轨迹推移方向的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 判断 r(t)=½t² 时 K 变化对稳态误差的影响方向
本卷实例
  • 关键一步：先按开环积分环节个数判系统型别，再选误差系数
  • 关键一步：加速度输入对应静态加速度误差系数，不是速度误差系数
  • 中间结果：该型别系统的加速度误差系数为零，调 K 改不了误差发散
  • 卡点：把加速度输入误当速度输入，代入了速度误差公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过判断 r(t)=½t² 时 K 变化对稳态误差的影响方向
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过Ⅰ型系统求阶跃误差时误代入速度误差公式
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

2蒸汽加热过程控制#

思路
  • 由示意图描述加热过程的运行原理，再按「被控对象 / 被控变量 / 操纵变量」三要素拆分，最后画控制框图
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 叙述系统的运行过程
  • 指出被控对象、被控变量与操纵变量
  • 画出系统控制框图
本卷实例
  • 关键一步：先按「出口物料温度是最终要维持的量」锁定被控变量为出口温度
  • 关键一步：操纵变量是控制器能动的那个量（蒸汽流量）；被控对象是被加热的物料与换热器
  • 关键一步：运行过程按「测量—比较—调节蒸汽阀开度」的闭环逻辑描述
  • 中间结果：完整四要素：检测变送器（测温元件）+ 控制器 + 执行器（蒸汽调节阀）+ 被控对象
  • 卡点：把被控对象写成「蒸汽阀」——阀是执行器，不是被控对象
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过叙述系统的运行过程
  • 本卷考过指出被控对象、被控变量与操纵变量
  • 本卷考过画出系统控制框图
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半

3梅森公式与扰动补偿#

思路
  • 第 1 问按梅森增益公式求总传输；第 2 问让 N(s) 对输出无影响，即令 N→C 通道的分子为零
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求信号流图的 C(s)/R(s)
本卷实例
  • 关键一步：先找全部单独回路求和得 Δ=1−ΣL+ΣLL−…
  • 关键一步：再找前向通路 P_k 与各自余子式 Δ_k
  • 关键一步：有互不接触回路时才会有 ΣLL 项，别漏也别重
  • 中间结果：Δ=1−ΣL+ΣLL−…，本题回路与前向通路须按原卷流图标全
  • 卡点：余子式里没剔除与前向通路接触的回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求信号流图的 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求 G₄(s) 使扰动 N(s) 对系统输出无影响
本卷实例
  • 关键一步：令 R(s)=0，写出 N(s)→C(s) 的传递函数，再令其分子为零
  • 关键一步：这是「完全不变性」条件，不是让增益取无穷大
  • 中间结果：令 N→C 传函的分子恒为零，解出 G₄(s) 即完全不变性条件
  • 卡点：求扰动传函时没有把参考输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求 G₄(s) 使扰动 N(s) 对系统输出无影响
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

4奈氏判据求稳定 K 范围#

思路
  • 给的是最小相位系统的奈氏曲线，且已知 K=100、v=1；K 是纯放大倍数，只改变曲线的幅值缩放
奈奎斯特判据 稳定性分析
本卷考法
  • 由奈氏曲线求系统稳定时 K 的取值范围
本卷实例
  • 关键一步：v=1 说明开环有一个积分环节，曲线要补画无穷大半径圆弧才闭合
  • 关键一步：K 只做幅值缩放：把曲线按 K/100 比例伸缩
  • 关键一步：找刚好不包围 (−1,j0) 的两个临界 K
  • 中间结果：稳定 ⇔ Z=0 ⇔ 曲线不包围 (−1,j0)
  • 卡点：忘记补无穷大圆弧；或把包围方向（逆时针为正）记反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由奈氏曲线求系统稳定时 K 的取值范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

5根轨迹与主导极点#

思路
  • G=K*/(s(s+2)(s+4))，n−m=3；第 2 问只要求列算式不求结果，第 3 问是定性分析
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制 K* 从 0→∞ 的根轨迹图
本卷实例
  • 关键一步：先标开环极点 0、−2、−4，按右数奇数个极点定实轴段
  • 关键一步：无开环零点时，渐近线交于极点实部均值，夹角按奇数等分
  • 中间结果：实轴根轨迹段为 (−∞,−4) 与 (−2,0) 两段
  • 中间结果：分离点方程由重根条件化为关于 d 的一元二次方程
  • 卡点：渐近线夹角用 2k+1 而非 2k，且只取 0 到 π 内的三条
  • 卡点：分离点两根中只有落在实轴根轨迹段上的那个有效
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制 K* 从 0→∞ 的根轨迹图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过渐近线夹角公式中的 2k+1 写成 2k
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • ζ=√2/2 时用根轨迹法列式求 K*（不要求算出结果）
本卷实例
  • 关键一步：ζ=√2/2 对应等阻尼线 β=45°，与根轨迹的交点即主导极点
  • 关键一步：设 s=σ+jσ（45° 线），代入特征方程后由幅值条件列式
  • 中间结果：在根轨迹图上作 45° 等阻尼射线，与轨迹的交点即满足 ζ 的极点
  • 卡点：题目明确说「仅限用根轨迹法，列算式即可」，直接用代数法求解反而丢分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过ζ=√2/2 时用根轨迹法列式求 K*（不要求算出结果）
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过求使系统 BIBO 稳定时 m 的取值范围
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消
