武汉大学 856 自动控制理论 2015 年真题思维导图

985 院校共 8 题合计 150 分

难度：中等　8 道大题：一 电路状态空间建模，二 饱和非线性与叠加原理，三 由结构图与单位阶跃响应确定参数，四 增加开环零点对根轨迹的影响，五 由开环幅频渐近线求传函并判稳，六 由对数幅频特性反求原系统与串联校正装置并判稳，七 李雅普诺夫第二法判原点稳定性，八 采样系统单位斜坡稳态误差。多题依赖原卷插图，分值已逐题印出、合计 150。

1一、电路状态空间建模20 分#

思路
  • 以电感电流和电容电压为状态变量对电路列写状态方程，再把电阻R2上的电压用状态变量表示，得到输出方程。题面含图未读图。
状态空间表达式的建立 状态空间分析
本卷考法
  • 由电路图选定状态变量并列写状态方程与输出方程（第一题）
本卷实例
  • 关键一步：按电感电流与电容电压确定状态变量个数
  • 关键一步：对电感列回路方程、对电容列节点方程并消去非状态量
  • 中间结果：状态向量由两个电感电流与一个电容电压组成
  • 中间结果：输出方程是状态变量与输入的线性组合
  • 卡点：电路拓扑与元件接法以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由电路图选定状态变量并列写状态方程与输出方程（第一题）
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式

2二、饱和非线性与叠加原理10 分#

思路
  • 先给出饱和非线性的定义与输出特性，再分别从齐次性与加和性说明非线性系统不满足叠加原理。
典型非线性特性及其影响 非线性系统
本卷考法
  • 说明饱和非线性的定义与输出特性（第二题）
本卷实例
  • 关键一步：从输入超过限幅值后输出基本不变来描述饱和特性
  • 中间结果：饱和环节在小信号区近似线性，在大信号区输出受限
  • 卡点：饱和属于非线性特性，分析时不能套用线性叠加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 饱和特性降低等效增益，可能引起系统不稳定或自振
  • 死区特性使小信号时增益为零，产生稳态误差
  • 间隙特性引起相位滞后，导致波形畸变与自振
  • 继电特性使系统出现持续振荡并可能产生颤振
步骤
  • 识别非线性环节类型
  • 写出其描述函数或分段数学表达式
  • 分析其对等效增益与稳定性的影响
通用考法
  • 本卷考过说明饱和非线性的定义与输出特性（第二题）
  • 分析饱和或死区对系统性能的影响
  • 求典型非线性的描述函数表达式
  • 说明间隙为何容易引起自振
常见易错
  • 认为饱和总是使系统更稳定
  • 忽略死区在原点附近造成的小信号失效
公式
非线性系统的特点 非线性系统
本卷考法
  • 用饱和特性说明非线性系统不满足叠加原理（第二题）
本卷实例
  • 关键一步：取两个输入分别作用再加起来，比较输出之和与和输入的输出
  • 中间结果：饱和使输入成倍放大时输出不同倍放大，齐次性被破坏
  • 卡点：举一个反例只能说明该环节不满足，不能推广为全部环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过用饱和特性说明非线性系统不满足叠加原理（第二题）
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定

3三、由结构图与阶跃响应确定参数30 分#

思路
  • 由结构图用等效化简写出闭环传递函数并化为二阶标准形式；再从单位阶跃响应曲线读取稳态值、峰值与峰值时间，联立反解k1、k2和T。题面含图未读图。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图求闭环传递函数（第三题）
本卷实例
  • 关键一步：前向通道相乘后按单位负反馈写出闭环传函
  • 中间结果：闭环特征式为s的二次多项式加上开环增益
  • 卡点：结构图以图给出，反馈极性与环节位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由结构图求闭环传递函数（第三题）
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为二阶标准形式求阻尼比与自然频率（第三题）
本卷实例
  • 关键一步：把s平方项系数归一化后与二阶标准式逐项比较
  • 中间结果：阻尼比与自然频率均由待定结构参数表示
  • 卡点：不先归一化就直接读系数会把自然频率判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为二阶标准形式求阻尼比与自然频率（第三题）
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由单位阶跃响应的稳态值与峰值时间反求参数（第三题）
本卷实例
  • 关键一步：从响应曲线上读稳态值、峰值与峰值时刻后按公式反解
  • 中间结果：稳态值给出增益关系，峰值时间给出自然频率与阻尼比关系
  • 卡点：响应曲线以图给出，稳态值与峰值时刻需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由单位阶跃响应的稳态值与峰值时间反求参数（第三题）
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式

4四、增加开环零点对根轨迹的影响10 分#

思路
  • 从渐近线、实轴段、分离会合点与稳定性几方面比较增加开环零点前后的根轨迹变化，按论述题分点作答。
附加开环零极点的影响 根轨迹法
本卷考法
  • 论述增加开环零点对根轨迹形状与系统性能的影响（第四题）
本卷实例
  • 关键一步：从渐近线方向、分离点位置与稳定裕度三方面分别说明
  • 中间结果：增加开环零点使根轨迹整体左移、有利于改善稳定性
  • 卡点：只谈渐近线变化会漏掉分离点与实轴段的变化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过论述增加开环零点对根轨迹形状与系统性能的影响（第四题）
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
根轨迹的绘制法则 根轨迹法
本卷考法
  • 结合根轨迹绘制法则说明零点对渐近线与实轴段的影响（第四题）
本卷实例
  • 关键一步：按渐近线交点与夹角公式比较加零点前后的变化
  • 中间结果：增加一个开环零点会使渐近线条数与夹角随之改变
  • 卡点：实轴段判据要看该段右侧零极点个数，别漏算新零点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过结合根轨迹绘制法则说明零点对渐近线与实轴段的影响（第四题）
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式

5五、由开环幅频渐近线求传函并判稳10 分#

思路
  • 按频段逐段读渐近线斜率与高度，定出型别、增益和各转折频率对应的典型环节，写出开环传递函数；再由相角裕度或奈奎斯特判据说明稳定性。题面含图未读图。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环对数幅频渐近线反求系统传递函数（第五题）
本卷实例
  • 关键一步：由低频段斜率定型别、由低频高度定增益，再按转折频率补环节
  • 中间结果：各斜率变化点对应一阶或二阶典型环节的转折频率
  • 卡点：幅频渐近线以图给出，转折频率与低频高度需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环对数幅频渐近线反求系统传递函数（第五题）
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 按各段斜率写出开环对数幅频表达式（第五题）
本卷实例
  • 关键一步：从低频段起逐段累加斜率写出各频段的幅值表达式
  • 中间结果：同一频率在两个相邻频段的表达式在转折频率处应相等
  • 卡点：逐段改斜率时是累加不是替换，漏累加会把高频斜率算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过按各段斜率写出开环对数幅频表达式（第五题）
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
稳定裕度 频域分析
本卷考法
  • 由最小相位系统的频率特性说明闭环稳定性（第五题）
本卷实例
  • 关键一步：求幅值穿越频率处的相角裕度，据其正负判断稳定性
  • 中间结果：最小相位系统幅频与相频一一对应，可由幅频推出相频
  • 卡点：不要把幅值裕度与相角裕度的特征频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
