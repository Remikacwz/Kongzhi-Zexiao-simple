1一、名词解释#

思路
  • 四个名词依次解释非线性系统的自激振荡、随机系统、系统校正的含义，以及自动控制系统的几种基本控制方式，按定义作答并写全要素。
用描述函数法分析自振 非线性系统
本卷考法
  • 解释自激振荡的含义（第一题第1小问）
本卷实例
  • 关键一步：从非线性系统在无周期输入下产生持续振荡来定义
  • 中间结果：自激振荡的频率与幅值由系统参数与非线性特性共同决定
  • 卡点：自激振荡是孤立闭曲线，要与线性系统的等幅振荡区分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过解释自激振荡的含义（第一题第1小问）
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率

校正的基本概念与性能指标 系统校正
本卷考法
  • 解释校正的含义（第一题第3小问）
本卷实例
  • 关键一步：从引入附加装置改善系统性能来定义校正
  • 中间结果：按串联、反馈、前馈与复合等方式分类
  • 卡点：校正不等于反馈，别把两者混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过解释校正的含义（第一题第3小问）
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求

自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 列举自动控制系统的几种基本控制方式（第一题第4小问）
本卷实例
  • 关键一步：按开环、反馈闭环与复合三类依次作答
  • 中间结果：复合控制兼有开环快速性与反馈自适应性
  • 卡点：只答反馈控制会漏掉开环与复合两种方式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤

  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过列举自动控制系统的几种基本控制方式（第一题第4小问）
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

2二、含图计算：由误差传函求系统参数#

思路
  • 结构图含参考输入与扰动输入两条通道。按误差定义分别写两条通道的误差传函，再按给定条件令误差为零或限制其幅值，反解系统参数。题面含图未读图。
误差定义与误差传递函数 稳态误差
本卷考法
  • 写出误差对参考输入的传递函数（第二题第1问）
本卷实例
  • 关键一步：按误差定义分别写出两条通道的误差传函
  • 中间结果：误差传函的分母与闭环特征式相同
  • 卡点：结构图以图给出，误差引出点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写出误差对参考输入的传递函数（第二题第1问）
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

扰动作用下的稳态误差 稳态误差
本卷考法
  • 由扰动输入下的误差要求确定系统参数（第二题第2问）
本卷实例

  • 中间结果：扰动误差幅值随频率变化，由幅值条件约束参数
  • 卡点：求扰动通道时要把参考输入置零，正负号按图核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法

  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

3三、根轨迹绘制与分离会合点#

思路
  • 由给定开环传函（三个极点、无零点）按法则绘 180 度根轨迹，求三条渐近线、分离会合点，并令闭环特征方程的纯虚根代入求与虚轴交点。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制开环含三个极点无零点的根轨迹（第三题）
本卷实例
  • 关键一步：先定实轴段，再算三条渐近线交点与夹角
  • 中间结果：三条渐近线在实轴上相交于同一点
  • 卡点：极点零点是给定传函，无需借助图即可代入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制开环含三个极点无零点的根轨迹（第三题）
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离会合点（第三题）
本卷实例
  • 关键一步：由幅值条件写增益对根位置的函数并令导数为零
  • 中间结果：解方程得实轴上的分离会合点
  • 卡点：求得的根必须落在实轴根轨迹段上才有效
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离会合点（第三题）
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴的交点（第三题）
本卷实例
  • 关键一步：把纯虚根代入闭环特征方程，联立实部虚部为零
  • 中间结果：解得一对非零纯虚根与对应临界增益
  • 卡点：只取零频率解会漏掉真正的虚轴交点

  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解

步骤

  • 令实部与虚部分别为零，得到两个方程

  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴的交点（第三题）

  • 判断根轨迹穿越虚轴的方向

  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

4四、伯德图求截止频率与相角裕度#

思路
  • 由给出的开环对数频率特性图按各段斜率写出幅频表达式，令幅值等于一求截止频率，再把该频率代入相频表达式求相角裕度。题面含图未读图。
开环对数频率特性的绘制 频域分析
本卷考法
  • 由开环对数频率特性求截止频率（第四题）
本卷实例
  • 关键一步：按各段斜率写出幅频表达式，令幅值等于一求频率
  • 中间结果：截止频率落在哪一段由该段斜率与高度决定
  • 卡点：伯德图以图给出，转折频率与各段高度需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过由开环对数频率特性求截止频率（第四题）
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
稳定裕度 频域分析
本卷考法
  • 求给定截止频率处的相角裕度（第四题）
本卷实例
  • 关键一步：把截止频率代入相频表达式后加一百八十度
  • 中间结果：相角裕度反映系统相对稳定程度
  • 卡点：相角裕度与幅值裕度的特征频率不要用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求给定截止频率处的相角裕度（第四题）
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

5五、采样系统闭环脉冲传函与稳定性#

思路
  • 采样周期给定时，先求含零阶保持器的开环脉冲传函，再按闭环公式求闭环脉冲传函；第二问由闭环特征方程判稳。题面含图未读图。
脉冲传递函数 离散控制系统
本卷考法
  • 求采样系统的闭环脉冲传递函数（第五题第1问）
本卷实例

  • 中间结果：含零阶保持器时要整体做 z 变换
