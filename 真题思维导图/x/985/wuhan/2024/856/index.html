1~5一、简答五小题#

思路
  • 五道简答覆盖自动控制系统的定义与组成、传递函数的概念、比例积分控制器的作用、电气校正装置的三大分类、极限环的定义，按基本概念逐条作答。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 解释自动控制系统的基本组成与控制方式（第1小题）
本卷实例
  • 关键一步：答出被控对象、控制器与检测变送等环节
  • 中间结果：系统在无人直接参与下使被控量按规律运行
  • 卡点：别只写控制器，要补检测与执行环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过解释自动控制系统的基本组成与控制方式（第1小题）
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
传递函数的定义与基本性质 传递函数
本卷考法
  • 简述传递函数的定义与零初始条件前提（第2小题）
本卷实例
  • 关键一步：强调零初始条件下输出与输入的拉氏变换之比
  • 中间结果：传递函数只取决于系统结构与参数
  • 卡点：漏掉零初始条件会丢分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过简述传递函数的定义与零初始条件前提（第2小题）
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
PID 控制器与参数整定 系统校正
本卷考法
  • 说明比例积分控制器的作用及其改善的性能（第3小题）
本卷实例
  • 关键一步：分别说清比例项与积分项各自的作用
  • 中间结果：积分项使系统型别提高一级、改善稳态精度
  • 卡点：积分项同时带来相位滞后
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过说明比例积分控制器的作用及其改善的性能（第3小题）
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式
校正的基本概念与性能指标 系统校正
本卷考法
  • 说出电气校正装置的三大分类（第4小题）
本卷实例
  • 关键一步：按相位关系把校正分为三类
  • 中间结果：超前、滞后与滞后超前校正
  • 卡点：不要把超前与滞后写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过说出电气校正装置的三大分类（第4小题）
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求

相平面法 非线性系统
本卷考法
  • 解释极限环的定义及其与自持振荡的关系（第5小题）
本卷实例
  • 关键一步：抓住相平面上孤立闭合相轨迹这一特征
  • 中间结果：稳定极限环对应时间响应上的自持振荡
  • 卡点：只有稳定极限环才表现为自持振荡
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤

  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法

  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

二1二、计算题第1题：双输入结构图求闭环传函#

思路
  • 由含两个输入的结构图分别求 C(s)/R1(s) 与 C(s)/R2(s)，先标出各回路与前向通路，再用梅森公式写特征式。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求多输入结构图中各输入对输出的闭环传递函数
本卷实例
  • 关键一步：求某个输入的传函时把其余输入置零
  • 中间结果：按各输入分别列前向通路与余子式
  • 卡点：结构图以图给出，回路走向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求多输入结构图中各输入对输出的闭环传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式写双输入系统的特征式与传函
本卷实例
  • 关键一步：先找全部回路并判断哪些两两不接触
  • 中间结果：特征式为一减各回路增益加不接触回路增益积
  • 卡点：余子式里要剔除与该通路接触的回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式写双输入系统的特征式与传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式

二2二、计算题第2题：由阻尼比反求参数与超调量#

思路
  • 由结构图求闭环传函并化成标准二阶形式，与期望阻尼比对系数反求开环增益，再按阻尼比求超调量。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为标准二阶形式并反求结构参数
本卷实例
  • 关键一步：把闭环传函分母首项系数归一化为先
  • 中间结果：由一次项系数与常数项读出阻尼比与自然频率
  • 卡点：结构图以图给出，开环传函需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为标准二阶形式并反求结构参数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比计算二阶系统的超调量
本卷实例
  • 关键一步：按超调量公式代入给定阻尼比
  • 中间结果：超调量只由阻尼比决定
  • 卡点：超调量公式里不要漏乘百分之百
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比计算二阶系统的超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

二3二、计算题第3题：稳态误差条件与稳定域#

思路
  • 先由开环积分环节数定系统型别，按输入求静态误差系数与稳态误差，再列特征方程用劳斯判据求参数稳定条件，取二者交集。
系统型别与静态误差系数 稳态误差
本卷考法
  • 判断系统型别并写输入对应的静态误差系数
本卷实例
  • 关键一步：数开环积分环节个数确定系统型别
  • 中间结果：型别决定输入下稳态误差的有限与否
  • 卡点：型别与开环增益不要混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断系统型别并写输入对应的静态误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由稳态误差要求反求开环增益下界
本卷实例
  • 关键一步：由静态误差系数写出误差与增益的关系
  • 中间结果：把误差上界代入关系式得增益下界
  • 卡点：用误差公式前须先判稳
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由稳态误差要求反求开环增益下界
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 用劳斯判据求参数稳定域并与误差条件取交集
本卷实例
  • 关键一步：列劳斯表令首列各元素同号
  • 中间结果：稳定条件给出各参数之间的不等式约束
  • 卡点：取交集时端点是否包含要分清
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过用劳斯判据求参数稳定域并与误差条件取交集
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

思路

稳定裕度 频域分析
本卷考法
  • 由幅相数据求相角裕度与幅值裕度并反求增益倍数

  • 卡点：幅值裕度要取幅值倒数再取分贝
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝

  • 由裕度符号判断稳定性

  • 分析增益变化对裕度的影响
