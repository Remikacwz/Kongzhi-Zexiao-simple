武汉大学 856 自动控制理论 2025 年真题思维导图

985 院校共 7 题

难度：中等　全卷分两个大题：一为 5 道基本概念简答，二为 6 道计算题。计算题依次考双输入结构图求传函、含参数的根轨迹绘制、由峰值时间与单位斜坡稳态误差反求二阶参数、闭环极点配置与前馈误差补偿、最大相角裕度表达式的证明、零阶保持器采样系统稳定增益范围；多题附原卷插图，整体偏重基本方法与完整推导，纯计算量不大。

1、2、3、4、5一、简答题：线性性·自控系统·测量反馈·校正·极限环#

思路
  • 五道概念小题各自独立：先答线性系统加和性与齐次性的定义，再说明自动控制系统在无人直接参与下按预定规律运行及其组成，然后说明测量反馈元件检测被控量并送回比较的作用，接着给出校正的含义与常用装置，最后说明极限环的概念与稳定、半稳定、不稳定三种类型。
非线性系统的特点 非线性系统
本卷考法
  • 说明线性系统的加和性与齐次性（叠加原理）
本卷实例
  • 关键一步：从输入输出关系定义两条性质：输入相加对应输出相加，输入放大对应输出同比放大
  • 中间结果：两条性质合起来就是叠加原理，是线性系统与非线性系统的分界
  • 卡点：加和性与齐次性需同时成立，只满足其中一条仍不是线性系统
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过说明线性系统的加和性与齐次性（叠加原理）
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 说明自动控制系统的定义与基本组成环节
本卷实例
  • 关键一步：按被控对象、检测变送、控制器、执行器四个环节概括系统如何工作
  • 中间结果：被控量偏离给定值时，偏差经控制器与执行器作用后被控量回到预定规律
  • 卡点：题面只问定义，答题要落到组成与工作过程，不要只举某一种具体系统
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过说明自动控制系统的定义与基本组成环节
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半
误差定义与误差传递函数 稳态误差
本卷考法
  • 说明测量反馈元件检测被控量并形成反馈与偏差的作用
本卷实例
  • 关键一步：测量元件先检测被控量并转换为可比较的信号，再送回输入端与给定信号相比
  • 中间结果：反馈量由测量元件给出，偏差由给定减去反馈量后得到
  • 卡点：测量元件输出的是反馈量而不是给定，转换信号与比较偏差是两个不同作用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过说明测量反馈元件检测被控量并形成反馈与偏差的作用
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

校正的基本概念与性能指标 系统校正
本卷考法
  • 说明校正的含义并列出常用校正装置
本卷实例
  • 关键一步：从引入附加装置改善系统性能来定义校正
  • 中间结果：常用校正装置按形式分为超前、滞后、滞后超前三类
  • 卡点：把校正与反馈混为一谈，或只列装置不解释校正目的
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过说明校正的含义并列出常用校正装置
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求

相平面法 非线性系统
本卷考法
  • 说明极限环的概念并区分稳定、半稳定与不稳定极限环
本卷实例
  • 关键一步：把极限环定义为相平面上的孤立封闭曲线，再按附近相轨迹的走向分类
  • 中间结果：相轨迹渐近趋向的为稳定极限环，从曲线离开的为不稳定极限环
  • 卡点：极限环是孤立闭曲线，要与一族闭合相轨迹区分开
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过说明极限环的概念并区分稳定、半稳定与不稳定极限环
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

二1二1、双输入结构图求传递函数#

思路
  • 结构图含 R 与 N 两个输入、两条回路和多条前向通路。先由结构图改画信号流图，数出全部单独回路写特征式；再分别令另一个输入为零，用梅森公式求 R 到 C 与 N 到 C 两条传函，最后按叠加写成 C(s)。题面含图未读图。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图改画信号流图并用梅森公式求总传输
本卷实例
  • 关键一步：先数出全部单独回路并写出特征式，再逐条找前向通路及其余子式
  • 中间结果：两条回路不接触时的高阶乘积项要按梅森公式判断是否计入
  • 卡点：结构图未读图，回路条数与支路需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图改画信号流图并用梅森公式求总传输
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • R 与 N 双输入下分别求传函再按叠加合成输出
本卷实例
  • 关键一步：求 R 到 C 时令 N 为零，求 N 到 C 时令 R 为零
  • 中间结果：两条通道共用同一个由回路增益组成的特征式
  • 卡点：求扰动通道时没有把参考输入置零，相加时正负号要按结构图核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过R 与 N 双输入下分别求传函再按叠加合成输出
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

二2二2、含参数的根轨迹绘制#

思路
  • 开环传函含参数 a，先把闭环特征方程整理成含 a 的等效开环形式，把 a 提到标准位置化成参数根轨迹；再按常规法则判实轴段、求三条渐近线、分离点与虚轴交点，画出根轨迹草图并标出关键数值。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 把参数 a 从特征方程中提到标准位置化为参数根轨迹
本卷实例
  • 关键一步：由闭环特征方程通分，把含 a 的项提为分子，其余部分作等效开环
  • 中间结果：等效开环分母含一个原点极点与一对负实轴上的重极点
  • 卡点：整理时未把参数完整提到分子，参数根轨迹仍按 180 度相角条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过把参数 a 从特征方程中提到标准位置化为参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按实轴段判据与渐近线法则绘制三条根轨迹分支
本卷实例
  • 关键一步：先标出三个开环极点，再逐段数实轴右侧的零极点总数
  • 中间结果：三条渐近线交于实轴同一点，夹角按三支等分圆周
  • 卡点：重极点要按重数计入，否则实轴段与渐近线都会算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按实轴段判据与渐近线法则绘制三条根轨迹分支
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求参数根轨迹的分离点并筛选
本卷实例
  • 关键一步：由幅值条件把参数写成 s 的函数后令导数为零得分离点方程
  • 中间结果：分离点方程可化为关于分离点的一次方程，解出后要落在实轴根轨迹段上
  • 卡点：求出的驻点必须按实轴段判据筛选，不在根轨迹上的要舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求参数根轨迹的分离点并筛选
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴的交点及临界参数
本卷实例
  • 关键一步：对闭环特征方程列劳斯表，令首列出现零或代入纯虚变量
  • 中间结果：临界参数处辅助方程给出一对非零共轭纯虚根
  • 卡点：辅助方程要取非零频率解，参数的临界值算法需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴的交点及临界参数
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

二3二3、由峰值时间与斜坡误差反求参数#

  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过求含零阶保持器的开环与闭环脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)

本卷考法
  • 用朱里判据求使离散系统稳定的增益范围
本卷实例
  • 关键一步：写出闭环特征方程后按朱里判据列 D(1)、D(-1) 与行列式不等式
  • 中间结果：稳定条件由端点符号与常数项约束共同给出，可化成增益与采样周期乘积的范围
  • 卡点：稳定条件要写成极点模小于一而不是实部小于零，答案段分母有两套写法需核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过用朱里判据求使离散系统稳定的增益范围
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒
