一有源网络求传递函数#

思路
  • 由原卷插图读出运放与阻容反馈网络，用虚短虚断把反相输入端视为虚地，把反馈支路写成电阻电容的复阻抗组合，再按输出与输入之比等于负的反馈阻抗比输入阻抗写出传递函数。
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由含运放的阻容网络求传递函数
本卷实例
  • 关键一步：把电容写成复阻抗，反馈支路按串并联关系合并成一个等效阻抗
  • 中间结果：输入阻抗为单个电阻，反馈阻抗是电阻与串联阻容支路的并联
  • 卡点：反馈网络中电阻电容的串并联关系需回原卷核对图
  • 卡点：电容复阻抗应写成 1/(sC) 而不是 sC
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由含运放的阻容网络求传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

二根轨迹：单位反馈与附加零点对比#

思路
  • 第一问先按开环极点 0、-1、-4 画根轨迹，用实轴段判据、渐近线公式、分离点方程与虚轴交点求稳定域；第二问把补偿环节 s+2 并入开环，得到极点 0、-1、-4 与零点 -2，重画并比较。第一问还要求调节时间，但未给出对应增益，源文答案段已声明去掉该项。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制无零点与附加零点两种情形的根轨迹
本卷实例
  • 关键一步：先标出三个开环极点，逐段数右侧零极点总数判断实轴根轨迹段
  • 中间结果：三条渐近线在实轴上交于负三分之五处，夹角按正负六十度与一百八十度分布
  • 卡点：实轴段判据要把开环极点按重数计入，本题极点 0、-1、-4 均为单极点，容易漏数 -4
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制无零点与附加零点两种情形的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

分离点与会合点 根轨迹法
本卷考法
  • 求无零点根轨迹的分离点与会合点
本卷实例
  • 关键一步：由 dK/ds 为零得分离点方程，再用实轴根轨迹段筛选有效根
  • 中间结果：分离点方程为一元二次，两个根中只有落在实轴根轨迹段内的那个有效
  • 卡点：另一个根落在不属于根轨迹的区间，必须舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求无零点根轨迹的分离点与会合点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由虚轴交点求临界增益与稳定范围
本卷实例
  • 关键一步：把纯虚数代入闭环特征方程，令实部与虚部分别为零
  • 中间结果：由虚部方程解出穿越频率，再由实部方程得到临界增益，稳定域由首列同号给出
  • 卡点：穿越频率是正数，负根要舍去；临界增益是稳定的上界而不是失稳点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由虚轴交点求临界增益与稳定范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由闭环极点位置估算调节时间
本卷实例
  • 关键一步：调节时间由主导极点的实部衰减因子决定，按百分之五误差带取三点五除以衰减因子
  • 中间结果：要给出调节时间须先确定该问对应的增益值
  • 卡点：源文未给出该增益，答案段标注去掉调节时间并说明缺少给定增益，无法定值，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤

  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由闭环极点位置估算调节时间
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

附加开环零极点的影响 根轨迹法
本卷考法
  • 分析附加开环零点对稳定性、快速性与准确性的影响
本卷实例
  • 关键一步：把附加零点并入开环后重新统计零极点个数，比较根轨迹整体移动方向
  • 中间结果：附加零点后渐近线交点为负一点五，一条分支趋于该零点、两条趋于无穷远，实轴段也随之改变
  • 卡点：附加零点主要改变根轨迹形状与低频增益分布，对准确性的作用要单独说明
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过分析附加开环零点对稳定性、快速性与准确性的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反

三结构图：多输入叠加与扰动补偿#

思路
  • 先用回路增益与不接触回路写特征式，分别令参考输入与扰动之一为零求两条通道的传函，再按线性叠加写出输出；第二问令扰动到输出的传函为零，解出使扰动不变的前馈补偿环节。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求参考输入与扰动分别作用下的输出表达式
本卷实例
  • 关键一步：按叠加原理每次只保留一个输入，分别求参考通道与扰动通道的传函
  • 中间结果：两条通道共用同一个特征式，分子按各自前向通路与余子式写
  • 卡点：扰动通道有两条前向通路，其中一条经过补偿环节，容易漏掉带负号的那条
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求参考输入与扰动分别作用下的输出表达式
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求多回路系统的特征式与前向通路
本卷实例
  • 关键一步：先数出全部单独回路，判断是否互不接触，再找各前向通路及其余子式
  • 中间结果：本题两个回路互相接触，没有高阶不接触项，特征式为 1 减去两回路增益之和
  • 卡点：特征式中回路增益的负号容易丢；余子式要与前向通路接触的回路剔除
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求多回路系统的特征式与前向通路
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图判断串联、并联与反馈等效
本卷实例

  • 中间结果：可从结构图逐层化简的结果与梅森公式结果互相校验

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由结构图判断串联、并联与反馈等效
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

四由阶跃响应反求弹簧拉力系统参数#

思路
  • 先按牛顿第二定律对质量、阻尼与弹簧列力平衡方程得到传递函数，由阶跃响应的稳态值定刚度，再由超调量与峰值时间定阻尼比与自然频率，最后按系数对应关系反解质量与阻尼系数。
机械系统建模 建模与机电系统
本卷考法
  • 弹簧质量阻尼系统的建模与传递函数
本卷实例
  • 关键一步：按牛顿第二定律列出合力等于质量乘加速度，阻尼力与弹簧力都取与位移反向
  • 中间结果：整理后分母为质量乘二次项、阻尼乘一次项与刚度常数项
  • 卡点：阻尼力与弹簧力的正负号取反会让传递函数中系数符号出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过弹簧质量阻尼系统的建模与传递函数
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
由响应曲线反求传递函数 传递函数
本卷考法

  • 关键一步：零阶保持器与连续环节合并后再整体做 z 变换，连续部分先部分分式展开再查表

  • 卡点：零阶保持器不能与连续环节分别变换后相乘；采样开关位置需回原卷核对图

本卷考法
  • 用 z 变换表处理带零阶保持器的连续部分
本卷实例
  • 关键一步：先按 z 变换的延迟性质提出保持器因子，再把有理分式拆成部分分式逐项查表
  • 中间结果：本题连续部分拆成一个积分环节与一个惯性环节之差，两项分别对应 z 域的两个标准分式
  • 卡点：指数项中的采样周期不要漏；部分分式分解时容易漏掉常数项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 常用函数的 z 变换要熟记
  • z 反变换可用部分分式法、幂级数法或留数法
  • 左半 s 平面映射到 z 平面单位圆内
步骤
  • 将连续传递函数展开为部分分式

  • 求给定函数的 z 变换
  • 求 z 反变换得到采样序列
  • 说明 s 平面与 z 平面的映射关系

  • 中间结果：本题特征方程是一次的，特征根为一个含增益的实根，稳定范围由一个双边不等式给出
  • 卡点：稳定条件用模小于一而不是实部小于零；源文开环脉冲传函一处分母印错，按后文实际使用的形式理解

本卷考法
  • 求单位阶跃输入下离散系统的稳态输出
本卷实例
  • 关键一步：先在给定增益下判稳，再用终值定理由闭环脉冲传函求稳态输出
  • 中间结果：阶跃输入与闭环脉冲传函相乘后取 z 趋于一的极限
  • 卡点：未判稳就用终值定理没有意义；闭环脉冲传函分母的常数项容易抄错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差由输入类型与开环脉冲传函中 z=1 处极点的个数决定
  • 型别由 G(z)H(z) 中 z=1 处极点的重数确定
  • 用终值定理求稳态误差，前提是系统稳定
  • 采样周期也影响稳态误差大小
步骤
  • 求误差脉冲传递函数
  • 数出 z=1 处极点重数确定型别
  • 查表或用终值定理求稳态误差
  • 分析采样周期变化对误差的影响
通用考法
  • 本卷考过求单位阶跃输入下离散系统的稳态输出
  • 求离散系统在典型输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 分析采样周期对稳态精度的影响
常见易错
  • 直接用 s 域静态误差系数公式处理离散系统
  • 未判稳就用终值定理

数字控制器与最少拍设计 离散控制系统
本卷考法
  • 设计一拍最少拍数字控制器
本卷实例
  • 关键一步：先按最少拍原则构造闭环脉冲传函与误差脉冲传函，再由闭环传函除以开环传函与误差传函求控制器
  • 中间结果：本题开环脉冲传函在单位圆内无不稳定零极点，可按典型输入选闭环脉冲传函为一拍延迟形式
  • 卡点：控制器必须是物理可实现的因果系统；采样开关位置与最小拍拍数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最少拍系统指在典型输入下经过有限拍达到无稳态误差
  • 设计需要满足可实现性与稳定性约束
  • 最少拍系统的闭环脉冲传递函数由输入类型确定
  • 最少拍设计通常导致很大的控制量，需加限制
步骤
  • 确定输入类型及对应的误差传函形式
  • 按无稳态误差要求构造闭环脉冲传递函数
  • 由 D(z)=Φ(z)/[G(z)(1-Φ(z))] 求数字控制器
  • 检验可实现性、稳定性与控制量大小
通用考法
  • 本卷考过设计一拍最少拍数字控制器
  • 设计最少拍数字控制器
  • 比较不同输入类型下的最少拍数
  • 分析最少拍系统存在的问题
常见易错
  • 忽略 D(z) 必须是物理可实现的因果系统
  • 闭环传函构造时未满足稳定性约束条件
