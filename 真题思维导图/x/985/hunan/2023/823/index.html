思路

思路
  • 用梅森公式求给定输入到输出的传函；再令扰动量到输出的传函恒为零，反求补偿环节 G4
梅森增益公式与信号流图 传递函数
本卷考法

本卷实例

  • 中间结果：特征式由回路增益减去互不接触回路增益乘积
  • 卡点：回路与前向通路的接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项

  • 不接触回路找漏或重复计数

三三、含参系统稳定域与高阶降阶20 分#

思路
  • 由开环传函列闭环特征方程，用劳斯判据求参数 a 的稳定范围；再按主导极点判断能否降阶并估算指标
劳斯判据 稳定性分析
本卷考法
  • 由含参闭环特征方程列劳斯表求 a 的稳定范围
本卷实例
  • 关键一步：先写出单位反馈下的含参闭环特征方程
  • 中间结果：劳斯表首列各元大于零给出 a 的约束
  • 卡点：a 出现在多个首列元素中需取全部不等式的交集
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由含参闭环特征方程列劳斯表求 a 的稳定范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过系数缺项时不补零就直接套用判据
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

本卷考法

本卷实例

  • 中间结果：把两者代入欠阻尼性能指标公式即可

  • 用超调量公式先求 ξ

四四、含复数极点系统的根轨迹20 分#

思路
  • 按开环零极点画根轨迹：定实轴区段与渐近线，求分离点与复数极点的出射角，并判断走向
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按零极点分布绘制根轨迹并确定实轴区段与渐近线
本卷实例
  • 关键一步：由实轴上零极点右侧个数判定根轨迹区段
  • 中间结果：渐近线交点在零极点重心处、夹角为九十度
  • 卡点：实轴段与渐近线走向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按零极点分布绘制根轨迹并确定实轴区段与渐近线

  • 判断某段实轴是否属于根轨迹
常见易错

  • 实轴段判据中的零极点个数算错

五五、由幅频特性反求传函与相角裕度20 分#

思路
  • 由低频段斜率与高度定系统型别和开环增益、由转折频率定各环节类型；再按反馈结构求相角裕度
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由最小相位系统的对数幅频渐近线反求开环传函
本卷实例
  • 关键一步：由低频段斜率确定积分环节个数与型别
  • 中间结果：各转折频率对应时间常数、低频交点给出开环增益
  • 卡点：各转折频率与高度读数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由最小相位系统的对数幅频渐近线反求开环传函
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合

奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据判断含积分环节系统的闭环稳定性
本卷实例
  • 关键一步：令虚部为零求幅相曲线与负实轴的交点频率
  • 中间结果：由交点位置数出对临界点的包围圈数
  • 卡点：开环右半平面极点数需先数清再套判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据判断含积分环节系统的闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过开环含积分环节时未补画无穷大半径圆弧
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
