一（1~10）一、简答题（10小问）60 分#

思路
  • 十小问覆盖信号流图、二阶参数、劳斯判据、参数根轨迹、相角裕度、由Bode图反求传函、根轨迹稳态误差、离散稳定性、奇点类型与状态转移矩阵
梅森增益公式与信号流图 传递函数
本卷考法
  • 消除混合节点后画等效信号流图再求传函
本卷实例
  • 关键一步：先把混合节点拆成带单位支路的两个节点
  • 关键一步：保持各支路增益不变，重画通路与回路
  • 中间结果：等效图与原图用梅森公式得到的传函相同
  • 卡点：拆分时漏掉自环或把支路增益写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过消除混合节点后画等效信号流图再求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由单位反馈开环传函求闭环阻尼比与自然频率
本卷实例
  • 关键一步：先按单位负反馈写闭环特征式
  • 关键一步：与标准二阶式逐项对照系数
  • 中间结果：由一次项系数比与常数项开方分别定两个参数
  • 卡点：把开环增益直接当成闭环标准式系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由单位反馈开环传函求闭环阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

劳斯判据 稳定性分析
本卷考法
  • 由四阶特征方程列劳斯表判断稳定性
本卷实例
  • 关键一步：按降幂排列系数并补零后列劳斯表
  • 关键一步：看首列符号变化次数
  • 中间结果：首列出现不同号即存在右半平面根
  • 卡点：缺项时不补零，或首列出现零仍按常规继续
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由四阶特征方程列劳斯表判断稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以增益a为变量画参数根轨迹
本卷实例
  • 关键一步：把特征方程整理成等价开环的幅相条件
  • 关键一步：以a为可变参数确定等效开环零极点
  • 中间结果：等效开环的极点与零点决定根轨迹走向
  • 卡点：没有把参数完整提到分子位置，等效开环写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以增益a为变量画参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

稳定裕度 频域分析
本卷考法
  • 求截止频率并导出相角裕度与阻尼比的解析关系
本卷实例
  • 关键一步：令开环幅频等于一解出截止频率
  • 关键一步：把截止频率代入相频表达式求相角裕度
  • 中间结果：相角裕度最终表示成阻尼比的反正切函数
  • 卡点：截止频率与相位穿越频率混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求截止频率并导出相角裕度与阻尼比的解析关系
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由相同幅频、不同相频的两条Bode图反求开环传函
本卷实例
  • 关键一步：先由幅频转折频率定环节类型与时间常数
  • 关键一步：再按相频走向区分最小相位与非最小相位
  • 中间结果：同一幅频可对应不同的开环传函
  • 卡点：只凭幅频就认定传递函数唯一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由相同幅频、不同相频的两条Bode图反求开环传函
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由根轨迹求阶跃与斜坡输入下的稳态误差
本卷实例
  • 关键一步：先由根轨迹确定使系统稳定的增益范围
  • 关键一步：再由开环型别求静态误差系数
  • 中间结果：斜坡输入下误差随速度误差系数增大而减小
  • 卡点：未判稳就先套终值定理求误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由根轨迹求阶跃与斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
离散系统稳定性分析 离散控制系统
本卷考法
  • 由三阶差分方程判稳并数不稳定根个数
本卷实例
  • 关键一步：对差分方程两边取z变换写特征方程
  • 关键一步：用朱利判据或双线性变换检验单位圆外根
  • 中间结果：特征根模大于一的个数即不稳定根个数
  • 卡点：把离散稳定条件写成根实部小于零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过由三阶差分方程判稳并数不稳定根个数
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

相平面法 非线性系统
本卷考法
  • 求非线性方程的奇点并判断奇点类型
本卷实例
  • 关键一步：令各阶导数为零求平衡点
  • 关键一步：在各平衡点附近线性化后看特征根
  • 中间结果：特征根为共轭虚根对应中心点，异号实根对应鞍点
  • 卡点：线性化时漏掉平衡点平移后的线性项符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过求非线性方程的奇点并判断奇点类型
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

状态转移矩阵 状态空间分析
本卷考法
  • 由两组初始状态与响应反求状态转移矩阵和系统矩阵
本卷实例
  • 关键一步：把两组响应按状态转移关系写成矩阵方程
  • 关键一步：解出状态转移矩阵后再对时间求导取零时刻值
  • 中间结果：系统矩阵等于状态转移矩阵在零时刻的导数
  • 卡点：初始状态矩阵排列方向写反导致转移矩阵求错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过由两组初始状态与响应反求状态转移矩阵和系统矩阵
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错

参数稳定域的确定 稳定性分析
本卷考法
  • 在 T-K 平面上画出稳定区域并说明边界曲线
本卷实例
  • 关键一步：分别把两个参数作横纵轴，取各不等式交集
  • 关键一步：边界由首列元素为零的等式给出
  • 中间结果：稳定区域边界对应系统出现纯虚根

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 区间端点通常对应临界稳定，即根落在虚轴上

  • 卡点：只算到部分列就下结论，秩判不全
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过验证系统能控作为极点配置的前提
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
