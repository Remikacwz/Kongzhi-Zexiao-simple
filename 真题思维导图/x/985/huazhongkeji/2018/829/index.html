一一、选择题（10题）20 分#

思路
  • 选择题覆盖误差系数、控制方式、一阶响应、超调量、稳定条件与校正判别
系统型别与静态误差系数 稳态误差
本卷考法
  • 求速度误差系数并判断系统型别
本卷实例
  • 关键一步：按开环传函积分环节个数定系统型别
  • 中间结果：型别确定后再由静态误差系数公式求值
  • 卡点：开环增益与误差系数不是同一量，需区分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过求速度误差系数并判断系统型别
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 本卷考过把开环增益与速度误差系数混为一谈
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出闭环系统按偏差还是按输入进行控制
本卷实例
  • 关键一步：由闭环结构判断反馈量取自输入与输出的偏差
  • 中间结果：偏差经控制器作用于被控对象形成闭环
  • 卡点：开环与闭环控制方式的判别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指出闭环系统按偏差还是按输入进行控制
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把按偏差控制与按扰动补偿混为一谈
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 求一阶系统阶跃响应达到稳态值63.2%所需时间
本卷实例
  • 关键一步：一阶系统时间常数即达到稳态值63.2%的时间
  • 中间结果：由传函分母读出时间常数即得结果
  • 卡点：终值须按稳态值而非初值计算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过求一阶系统阶跃响应达到稳态值63.2%所需时间
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 本卷考过把63.2%对应时刻与50%对应时刻记混
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 写出典型二阶系统超调量的表达式
本卷实例
  • 关键一步：按二阶系统超调量公式挑选对应选项
  • 中间结果：公式只含阻尼比而与自然频率无关
  • 卡点：选项公式的符号与指数需逐项比对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过写出典型二阶系统超调量的表达式
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过超调量公式分子漏掉阻尼比或负号
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

劳斯判据 稳定性分析
本卷考法
  • 判断线性定常系统稳定的充分必要条件
本卷实例
  • 关键一步：稳定性由闭环特征根实部符号决定
  • 中间结果：闭环极点全在左半平面则系统稳定
  • 卡点：开环极点与闭环极点不可混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过判断线性定常系统稳定的充分必要条件
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过把开环极点位置当作稳定判据
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

超前校正 系统校正
本卷考法
  • 由校正环节传函判断超前还是滞后校正
本卷实例
  • 关键一步：代入频率特性比较分子分母的相角贡献
  • 中间结果：相角为正即属相位超前校正
  • 卡点：超前与滞后校正的相角符号相反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过由校正环节传函判断超前还是滞后校正
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 本卷考过仅比较转折频率先后而不算相角
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

稳定裕度 频域分析
本卷考法
  • 求给定开环传函在截止频率处的相角裕度
本卷实例
  • 关键一步：由幅值等于1求截止频率再代入相频特性
  • 中间结果：相角裕度等于180度加截止频率处相角
  • 卡点：各串联环节的相角需逐项累加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求给定开环传函在截止频率处的相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
