1一、信号流图求传递函数#

思路
  • 由信号流图用梅森增益公式求 C(s)/R(s)
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图求系统的传递函数
本卷实例
  • 关键一步：先在流图上把所有回路数出来，再找两两互不接触的回路对，回路越多越要按顺序编号避免漏算
  • 关键一步：特征式是 1 减去单回路之和、加上两两互不接触回路乘积之和，符号交替
  • 关键一步：前向通道要按从输入到输出的方向逐条走完，每条通道自己的余子式只包含与它不接触的那些回路
  • 中间结果：分母是同一个特征式，分子是各条前向通道与其余子式乘积之和，最后可以约分
  • 卡点：漏掉两两互不接触项；或把与前向通道接触的回路写进余子式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图求系统的传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、反馈极性未知时的根轨迹增益范围#

思路
  • 开环零极点全在左半平面但反馈极性不明，要分别按负反馈与正反馈列特征方程，取两者稳定域的公共部分
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 反馈极性未知时确定使闭环稳定的根轨迹增益范围
本卷实例
  • 关键一步：极性未知就要把两种情况都算：负反馈的特征方程是一加开环传函，正反馈是一减开环传函
  • 关键一步：展开成多项式后逐项列劳斯表，分别求出各自的稳定增益区间
  • 关键一步：两个区间的公共部分才是「无论极性如何都稳定」的范围，这正是题目要的答案
  • 中间结果：本题展开后是四阶多项式：负反馈时末项为常数加增益，正反馈时为常数减增益
  • 中间结果：劳斯表首列出现两种约束：末项大于零与首列中间项大于零，分别给出增益的上下界
  • 卡点：只按负反馈算；或把正反馈当成负反馈除以负一处理，特征方程的常数项符号弄错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过反馈极性未知时确定使闭环稳定的根轨迹增益范围
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

3三、奈氏判据定稳定增益与幅值裕度#

思路
  • Ⅰ 型三阶开环系统先由相角条件求穿越负实轴处的频率，再令该点幅值小于 1 得稳定增益范围，最后算幅值裕度
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据确定使系统稳定的开环增益范围
本卷实例
  • 关键一步：开环没有右半平面极点，所以闭环稳定的条件是幅相曲线不包围临界点，
  • 关键一步：穿过负实轴的位置由相角等于负一百八十度定出频率，
  • 关键一步：把该频率代进幅频表达式，令幅值小于 1，就得到增益的上界
  • 关键一步：等价于曲线穿过负实轴的那一点落在临界点右侧
  • 关键一步：两个惯性环节的相角加起来正好九十度，用正切乘积关系可一步解出频率
  • 中间结果：临界频率等于两个时间常数乘积的平方根的倒数
  • 中间结果：临界点的幅值等于增益乘两个时间常数之积再除以两者之和，
  • 中间结果：所以稳定条件是增益小于两者之和除以两者之积
  • 卡点：把穿越频率当成两条渐近线的交点直接取；或忘记 Ⅰ 型系统积分环节贡献的九十度相角
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据确定使系统稳定的开环增益范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
稳定裕度 频域分析
本卷考法
  • 计算给定增益下的幅值裕度
本卷实例
  • 关键一步：幅值裕度的分贝值等于临界增益与实际增益之比取常用对数再乘二十
  • 关键一步：本题临界增益与实际增益之比恰好等于六，题面给出的六的对数正是为此准备的
  • 关键一步：幅值裕度为正是稳定（最小相位系统），为零是临界稳定
  • 中间结果：时间常数取 0.5 与 1、增益取 0.5 时，
  • 中间结果：临界增益为 3，比值是 6，对应约 15.6 dB
  • 卡点：把幅值裕度定义成实际增益比临界增益（取倒数）；或忘记乘二十
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过计算给定增益下的幅值裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

4四、开环对数幅频特性渐近线的绘制#

思路
  • 开环含一个零点与三个惯性环节，且增益用穿越频率表示，按转折频率逐段改斜率画渐近线
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制开环对数幅频特性渐近线
本卷实例
  • 关键一步：最低频段只由积分环节决定，斜率是每十倍频程下降二十分贝，高度由增益决定
  • 关键一步：按转折频率从小到大依次改斜率：经过惯性环节下降二十分贝，经过一阶微分环节上升二十分贝
  • 关键一步：本题增益用另一个频率的平方表示，说明这个频率就是幅值穿越频率，
  • 关键一步：画图时要让曲线正好在那里穿过零分贝线
  • 中间结果：四个转折频率的先后顺序已在题面给出，画完可数一数斜率变化次数是否与环节数一致
  • 卡点：改斜率时做替换而不是累加；或把增益表达式当成独立参数，忘了它与穿越频率的约束关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过绘制开环对数幅频特性渐近线
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式

5五、复合输入下由响应反求系统参数#

思路
  • 有用输入是阶跃、扰动是正弦，输出是二者叠加，用稳态值与最大值两个条件反求 p、q、T、k，再求误差
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求有用输入与扰动同时作用时的输出
本卷实例
  • 关键一步：用叠加原理分别求两条通道：从有用输入到输出的传函、从扰动到输出的传函
  • 关键一步：两条通道的分母相同，都是同一个特征多项式，只是分子不同，写出后便于比对
  • 关键一步：总输出是两部分之和，不能先把两个输入相加再乘一个传函
  • 中间结果：阶跃分量给出稳态值，正弦分量给出叠加在稳态值上的等幅纹波
  • 卡点：把扰动直接当成输入的一部分；或忘记两条通道的分母相同这一结构特点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求有用输入与扰动同时作用时的输出
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 由稳态输出值与响应峰值反求系统参数并求稳态误差
本卷实例
  • 关键一步：阶跃输入的稳态值由直流增益决定，可直接写出一个关于参数的方程
  • 关键一步：题给最大值与稳态值之差就是正弦扰动分量造成的纹波幅值，
  • 关键一步：两个条件联立解出时间常数与增益，再按误差定义求稳态误差
  • 关键一步：这给出频率特性在扰动频率处的一个幅值条件
  • 中间结果：峰值 2.326 与稳态值 2 之比略大于 1，
  • 中间结果：说明纹波幅值不大，据此可判断扰动通道在二弧度每秒附近的幅值衰减很强
  • 卡点：把峰值直接当成稳态值；或只用一个条件就试图解出多个参数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过由稳态输出值与响应峰值反求系统参数并求稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

6六、保持裕度不变的串联校正设计#

思路
  • 由对数幅频渐近线反求开环传函，再在保持相角裕度与剪切频率不变的前提下把误差降为十分之一
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环对数幅频特性渐近线反求传递函数与剪切频率
本卷实例
  • 关键一步：低频段斜率定积分环节个数，低频段高度定开环增益，两者要配套使用
  • 关键一步：每个转折频率处斜率变化二十就对应一个一阶环节，变化方向决定是零点还是极点
  • 关键一步：剪切频率就是幅频曲线与零分贝线的交点频率，读图时注意它落在哪一段
  • 中间结果：把写出的传函代回几个转折频率处验算幅值，可以直接发现增益或环节类型是否读错
  • 卡点：低频段高度与增益之间忘记折算积分环节的斜率；或把上升二十的转折当成极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环对数幅频特性渐近线反求传递函数与剪切频率
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
滞后校正 系统校正
本卷考法
  • 设计串联校正装置，使误差降为原来的十分之一且保持相角裕度和剪切频率不变
本卷实例
  • 关键一步：同时要求「提高低频增益」和「不动中高频的幅相特性」，这正是滞后校正的典型适用场合
  • 关键一步：误差降为十分之一需要低频增益提高十倍，也就是零点增益提高二十分贝，
  • 关键一步：把滞后网络的两个转折频率配置得远离剪切频率：
  • 关键一步：而滞后网络的低频增益恰好是衰减系数的倒数
  • 关键一步：一个远低于它，另一个约在它的十分之一附近，以免吃掉相角裕度
  • 中间结果：设计完成后要重新量一次剪切频率和相角裕度，确认与校正前基本一致，误差确实降下来了
