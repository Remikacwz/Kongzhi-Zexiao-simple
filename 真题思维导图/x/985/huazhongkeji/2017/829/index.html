梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式化简结构图求闭环传函
本卷实例
  • 关键一步：找前向通路与各回路
  • 关键一步：按不接触回路写特征式
  • 中间结果：分子为各前向通路与其余子式乘积之和
  • 卡点：回路接触关系判断错导致余子式写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式化简结构图求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断三阶特征方程的稳定状态
本卷实例
  • 关键一步：按降幂排列系数列劳斯表
  • 关键一步：首列出现全零行时用辅助方程求纯虚根
  • 中间结果：首列无符号变化但出现全零行说明临界稳定
  • 卡点：全零行未用辅助方程，直接判定为不稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断三阶特征方程的稳定状态
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

本卷实例

  • 关键一步：有采样开关隔开时分别z变换再相乘
  • 中间结果：各环节等效有开关时才可用梅森公式
  • 卡点：把无开关隔开的连续环节直接相乘后离散
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图

通用考法
  • 本卷考过求含采样开关系统的闭环脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 按定义由响应曲线求超调量
本卷实例
  • 关键一步：先由曲线读出稳态值与峰值
  • 关键一步：按峰值超出稳态值的百分比计算
  • 中间结果：超调量只反映振荡幅值相对量
  • 卡点：把峰值绝对高度当成超调量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过按定义由响应曲线求超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应反求系统传递函数
本卷实例
  • 关键一步：先由响应分离出稳态分量与动态分量
  • 关键一步：对输出取拉氏变换后除以单位阶跃变换
  • 中间结果：零初始条件下传递函数等于输出与输入变换之比
  • 卡点：忽略传递函数定义要求零初始条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应反求系统传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

扰动作用下的稳态误差 稳态误差
本卷考法
  • 求参考输入与扰动同时作用下的稳态误差
本卷实例
  • 关键一步：分别求参考与扰动到误差的传函
  • 关键一步：先判稳再各自用终值定理求分量后叠加
  • 中间结果：扰动误差分量由扰动作用点决定
  • 卡点：遗漏参考输入分量或未判稳就求终值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求参考输入与扰动同时作用下的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

稳定裕度 频域分析
本卷考法
  • 由相角裕度要求反求开环传函中的时间常数
本卷实例
  • 关键一步：写出幅频与相频表达式
  • 关键一步：由相角裕度等于四十五度列相角方程
  • 中间结果：再令幅值等于一定义截止频率，联立解参数
  • 卡点：相角裕度基准一百八十度写成九十度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由相角裕度要求反求开环传函中的时间常数
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

三三、根轨迹与过阻尼/欠阻尼K范围#

思路
  • 由开环传函画根轨迹，求分离点与渐近线，再由实轴与复根分界求过阻尼与欠阻尼K范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画出根轨迹并求分离点
本卷实例
  • 关键一步：标出开环极点与零点
  • 关键一步：求渐近线交点与夹角并确定实轴段
  • 中间结果：根轨迹分支起于极点止于零点或无穷远
  • 卡点：两个极点一个零点时复数部分为圆，需专门判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画出根轨迹并求分离点
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹分界求过阻尼与欠阻尼K范围
本卷实例
  • 关键一步：分离点对应过阻尼与欠阻尼分界
  • 关键一步：由幅值条件求分离点处K值
  • 中间结果：根在负实轴时为过阻尼，共轭复根时为欠阻尼
  • 卡点：分离点K值求出后未回代验证属于根轨迹
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹分界求过阻尼与欠阻尼K范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

四四、串联校正装置与幅值裕度#

思路
  • 由校正前后Bode图相减求校正装置传函，再由相频穿越求校正后幅值裕度
超前校正 系统校正
本卷考法
  • 由校正前后Bode图求串联超前校正装置传函
本卷实例
  • 关键一步：由校正前后对数幅频相减得校正装置特性
  • 关键一步：由转折频率写出超前网络传函
  • 中间结果：校正装置零点在低频、极点在更远处
  • 卡点：相减时把校正前后曲线顺序写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
