1一、信号流图求 C(s)/X(s)10 分#

思路
  • 由信号流图用梅森增益公式求输出节点到中间节点 X 的传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图求中间节点 X(s) 到输出的传递函数
本卷实例
  • 关键一步：先列 R 到 C 与 R 到 X 两个传函，再用其比值求 C/X
  • 关键一步：X 不是源节点，单独对 X 用梅森公式会漏掉公共回路
  • 关键一步：公共分母是同一特征式，两条通道差异只在分子
  • 中间结果：分子保留两条前向通道及其余子式，分母为公共特征式
  • 卡点：直接把 X 当源节点列前向通路，忽略中间变量关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图求中间节点 X(s) 到输出的传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、复合控制把系统由 I 型提高为 III 型10 分#

思路
  • 按前馈通道改写闭环传函，再由等效开环含三个积分环节确定前馈系数
反馈校正与复合控制 系统校正
本卷考法
  • 设计前馈通道使系统型别由 I 型提高到 III 型
本卷实例
  • 关键一步：先求闭环传函，再由闭环与开环关系反解等效开环
  • 关键一步：等效开环中积分环节个数即型别，令其含三个积分
  • 中间结果：前馈系数由等效开环相应系数为零的两个条件确定
  • 卡点：直接在原开环上数积分环节，未换成等效开环
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过设计前馈通道使系统型别由 I 型提高到 III 型
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由等效开环判断系统型别与静态误差系数
本卷实例
  • 关键一步：型别等于开环传递函数中积分环节 s 的个数
  • 关键一步：提高型别可让某种典型输入下的稳态误差变为零
  • 中间结果：由 s 的幂次对齐可列出待定系数的两个方程
  • 卡点：把开环增益大小与型别混淆，误以为加大增益能提高型别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由等效开环判断系统型别与静态误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式

3三、直流电机传递函数参数测定#

思路
  • 由稳态转速定出增益，由一阶响应到达 50% 或 63.2% 的时间定出时间常数
直流电机等机电系统 建模与机电系统
本卷考法
  • 由电枢电压与稳态转速测定直流电机的传递函数
本卷实例
  • 关键一步：把给定的转角传函先化成角速度对电压的一阶传函
  • 关键一步：稳态转速对应一阶环节的直流增益，与时间常数分开确定
  • 中间结果：角速度传函的分子分母系数与待求两个参数一一对应
  • 卡点：把转角传函直接当角速度传函，漏掉一次积分关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由电枢回路电压方程与转矩平衡方程联立
  • 反电动势与转速成正比，电磁转矩与电枢电流成正比
  • 机电时间常数由电气与机械两方面参数共同决定
步骤
  • 写出电枢回路电压平衡方程
  • 写出转矩平衡方程（含负载与粘性摩擦）
  • 消去电枢电流，得到转速或转角对电压的传递函数
通用考法
  • 本卷考过由电枢电压与稳态转速测定直流电机的传递函数
  • 求直流电机转速或位置对电枢电压的传递函数
  • 分析机电时间常数与电气时间常数的数量级关系
常见易错
  • 漏掉反电动势与电磁转矩的耦合项
  • 把电气时间常数与机电时间常数混淆
公式
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由一阶响应曲线上特定时刻的取值反求时间常数
本卷实例
  • 关键一步：一阶响应到达稳态值 63.2% 的时刻即时间常数
  • 关键一步：到达 50% 的时刻与时间常数由指数关系换算
  • 中间结果：由实测时间可解出衰减系数，再由稳态值定出增益
  • 卡点：把 50% 与 63.2% 两个时刻混用，或稳态值未扣除输入幅值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由一阶响应曲线上特定时刻的取值反求时间常数
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式

4四、含右半平面零点的根轨迹与振荡状态15 分#

思路
  • 开环有正零点需画零度根轨迹，由分离点与虚轴交点分界判断三种振荡状态
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 零点为正时改用零度相角条件绘制根轨迹
本卷实例
  • 关键一步：特征方程整理出正反馈形式，改用零度相角条件
  • 关键一步：实轴段判据改用两侧零极点个数之和为偶数
  • 中间结果：渐近线夹角按零度根轨迹的偶数倍规则取
  • 卡点：仍按 180 度相角条件画，实轴段与渐近线全错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过零点为正时改用零度相角条件绘制根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画出根轨迹的实轴段与渐近线
本卷实例
  • 关键一步：先由开环零极点定实轴段与渐近线，再求特殊点
  • 关键一步：渐近线交点由极点之和减零点之和再除以个数差
  • 中间结果：分离点由增益对 s 导数为零的方程解出并筛选
  • 卡点：实轴段判据中零极点个数算错，分离点未经筛选
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画出根轨迹的实轴段与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及对应的临界增益
本卷实例
  • 关键一步：把 s 换成 jω 代入特征方程，令实部虚部同时为零
  • 关键一步：由虚部方程解出交点频率，再由实部方程求临界增益
  • 中间结果：交点频率与临界增益一一对应，等幅振荡就发生在该增益
  • 卡点：只令虚部为零而漏掉实部约束，解出结果不完整
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及对应的临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹分界增益判断无振荡、衰减振荡与等幅振荡
本卷实例
  • 关键一步：根全为负实根时无振荡，出现共轭复根时衰减振荡
  • 关键一步：共轭根落在虚轴上时即等幅振荡，对应临界增益
  • 中间结果：分离点对应无振荡转衰减振荡的增益，虚轴交点对应等幅
  • 卡点：把增益分段顺序记反，或漏掉实根与复根之间的分界
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹分界增益判断无振荡、衰减振荡与等幅振荡
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式

5五、非最小相位系统的幅相曲线与稳定临界 T15 分#

思路
  • 开环有右半平面极点，先画幅相曲线再按奈氏判据求 T 的临界值
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅相曲线与奈奎斯特判据判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数，再数曲线包围临界点的圈数
  • 关键一步：判据用闭环右半平面根数等于开环极点数与包围圈数之差
  • 中间结果：包围与否对应两种稳定性，临界时曲线正好穿过临界点
  • 卡点：漏掉右半平面极点使极点数数错；正负圈数定义搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环幅相曲线与奈奎斯特判据判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 写出幅频与相频表达式并画出幅相曲线大致形状
本卷实例
  • 关键一步：把 s 换成 jω，分别求模与相角随频率的变化
  • 关键一步：由起点、终点与负实轴交点即可勾出曲线走向
  • 中间结果：起点幅值无穷，相角由积分环节与右半平面极点共同决定
  • 卡点：相角累加时漏掉右半平面极点贡献的附加相移
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
