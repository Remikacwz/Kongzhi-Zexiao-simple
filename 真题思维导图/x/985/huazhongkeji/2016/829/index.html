一（1~5）一、简答题（5小问）#

思路
  • 五小问：电路微分方程建模、信号流图化简、由阶跃响应画闭环极点、状态能控能观与输出能控、相平面法适用性判断
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由电路图列写微分方程并求传递函数
本卷实例
  • 关键一步：先按元件伏安关系列各支路微分方程
  • 关键一步：消去中间变量只保留输出与输入
  • 中间结果：整理成高阶微分方程后再取拉氏变换
  • 卡点：电容元件方程漏掉电流与电压导数关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由电路图列写微分方程并求传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式化简信号流图求传递函数
本卷实例
  • 关键一步：找出全部前向通路并标出与之不接触的回路
  • 关键一步：各通路增益乘余子式后求和再除以特征式
  • 中间结果：分母为1减各回路增益加两两不接触回路增益
  • 卡点：前向通路或回路漏找，余子式未剔除接触回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式化简信号流图求传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由三条阶跃响应曲线判断闭环极点位置
本卷实例
  • 关键一步：先由超调量比较各系统的阻尼比
  • 关键一步：再由峰值时间比较各系统的自然频率
  • 中间结果：阻尼比由超调量定，自然频率由峰值时间定
  • 卡点：响应曲线为原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由三条阶跃响应曲线判断闭环极点位置
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
能控性与能观性 状态空间分析
本卷考法
  • 由状态方程判断状态能控性、能观性和输出能控性
本卷实例
  • 关键一步：分别构造能控、能观与输出能控判别阵
  • 关键一步：求秩并与状态维数或输出维数比较
  • 中间结果：判别阵满秩则对应性质成立
  • 卡点：输出能控阵漏乘输出矩阵，与状态能控混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过由状态方程判断状态能控性、能观性和输出能控性
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
相平面法 非线性系统
本卷考法
  • 判断给定结构图系统能否用相平面法分析
本卷实例
  • 关键一步：先数线性部分阶数，再看非线性环节是否适合相平面
  • 关键一步：相平面法通常只适用于一阶或二阶系统
  • 中间结果：高阶系统不能直接用相平面法，需改用描述函数法
  • 卡点：把相平面法适用范围误扩到任意阶系统
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过判断给定结构图系统能否用相平面法分析
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

二二、多输入多输出系统传递函数矩阵#

思路
  • 对两输入两输出结构图分别置零另一输入，用梅森公式求四个传递函数组成矩阵
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求两路输入到两路输出的传递函数并组成矩阵
本卷实例
  • 关键一步：求某输出对某输入时把另一路输入置零
  • 关键一步：对单输入单输出子结构用梅森公式
  • 中间结果：四个传递函数共用同一特征式，分子各自由前向通路定
  • 卡点：多输入同时作用时直接叠加，未先验证系统线性性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求两路输入到两路输出的传递函数并组成矩阵
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

三三、误差约束下 K1 与 K2 的关系#

思路
  • 由结构图求误差传函，按劳斯判据保证稳定，再由斜坡输入稳态误差约束求参数关系
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由误差传函与终值定理求斜坡输入下的稳态误差
本卷实例
  • 关键一步：先写误差传函并确认系统稳定
  • 关键一步：斜坡输入下由终值定理求稳态误差
  • 中间结果：稳态误差与参数乘积成反比
  • 卡点：未判稳就套终值定理，结果可能落在不稳定区
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由误差传函与终值定理求斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 用劳斯判据确定使系统稳定的参数关系
本卷实例
  • 关键一步：由闭环特征方程列劳斯表
  • 关键一步：令首列各元素大于零得参数不等式
  • 中间结果：参数乘积需大于某一下界才同时满足稳定与误差约束
  • 卡点：只列部分首列不等式，漏掉某个约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过用劳斯判据确定使系统稳定的参数关系
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

四四、奈氏曲线判稳#

思路
  • 由已知G1(s)奈氏曲线补全整体开环，数右半平面极点数与包围圈数判稳
频率特性的物理意义与求法 频域分析
本卷考法
  • 由已知奈氏曲线识别 G1(s) 的环节形式
本卷实例
  • 关键一步：由曲线起点、终点与相角范围识别零极点结构
  • 关键一步：写出对应的一阶超前环节形式
  • 中间结果：已知环节与积分环节串联成整体开环
  • 卡点：相角范围读错导致环节类型判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由已知奈氏曲线识别 G1(s) 的环节形式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由奈氏曲线数包围圈数并判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数P
  • 关键一步：再数曲线包围临界点的正负圈数N
  • 中间结果：闭环右半平面根数由P与N共同决定
  • 卡点：含积分环节时未补画无穷大圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由奈氏曲线数包围圈数并判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式

五五、对数幅频、相角裕度与劳斯判据#

思路
  • 画Bode渐近线求相角裕度判稳，再用劳斯判据判稳并解释两种结果差异
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制开环对数渐近幅频特性并求截止频率
本卷实例
  • 关键一步：由型别与开环增益定低频段斜率与高度
  • 关键一步：按转折频率逐段累加斜率
  • 中间结果：在近似截止频率处令幅值等于一求频率
  • 卡点：逐段改斜率时用替换而非累加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过绘制开环对数渐近幅频特性并求截止频率
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
稳定裕度 频域分析
本卷考法
  • 由对数幅频求相角裕度并判断稳定性
本卷实例
  • 关键一步：把近似截止频率代入相频表达式算相角
  • 关键一步：相角裕度等于一百八十度加该相角
  • 中间结果：相角裕度接近零说明系统接近临界稳定
  • 卡点：截止频率与相位穿越频率混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
