1一、用等效变换化简结构图求 C(s)/R(s)#

思路
  • 按引出点后移、比较点前移逐层合并回路，最后化成一个负反馈回路
比较点与引出点的移动 结构图与方框图
本卷考法
  • 用比较点与引出点的移动化简交叉结构图
本卷实例
  • 关键一步：先判断该移出点还是移入点，按等效规则乘除相应环节
  • 关键一步：比较点前移时在移动支路补上流出点与流入点的比值
  • 中间结果：移完后交叉耦合消失，只剩可逐层合并的回路
  • 卡点：移动方向与乘除关系搞反，或把比较点与引出点规则混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过用比较点与引出点的移动化简交叉结构图
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路系统逐层化简求闭环传递函数
本卷实例
  • 关键一步：从最内层回路开始合并，由内向外逐层替换
  • 关键一步：并联环节相加、反馈回路用前向比上一加开环
  • 中间结果：化简到单回路后直接写出闭环传递函数
  • 卡点：化简内环时把外环信号当常数，导致分母丢项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路系统逐层化简求闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2二、非零初始条件下由阶跃响应求传递函数#

思路
  • 题给响应含零输入分量，需先化到零初始条件的阶跃响应再求传函
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由非零初始条件下的阶跃响应分离零输入与零状态
本卷实例
  • 关键一步：传递函数要求零初始条件，先把非零初值造成的自由分量扣除
  • 关键一步：补上阶跃对应的稳态分量可还原零初始条件下的响应
  • 中间结果：响应形式决定系统极点，稳态值决定直流增益
  • 卡点：直接把非零初值响应当零状态响应代入，传函算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由非零初始条件下的阶跃响应分离零输入与零状态
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由阶跃响应曲线或表达式反求系统传递函数
本卷实例
  • 关键一步：由响应中的指数项确定极点，再由稳态值定增益
  • 关键一步：脉冲响应是传函的拉氏反变换，可由传函直接写出
  • 中间结果：传函分母由极点决定，分子由稳态值与零点共同决定
  • 卡点：未判阶数就套二阶公式，或把稳态值当成增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由阶跃响应曲线或表达式反求系统传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

3三、四阶系统根轨迹与主导极点阻尼比#

思路
  • 先画四条渐近线的根轨迹，由虚轴交点定稳定范围，再由等阻尼线定主导极点
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制四阶系统根轨迹的实轴段与渐近线
本卷实例
  • 关键一步：开环极点全在负实轴，先定实轴段与渐近线交点
  • 关键一步：渐近线夹角按四条分支的奇数倍 π 均分
  • 中间结果：分离点由增益对 s 导数为零的方程解出并筛选
  • 卡点：渐近线条数或夹角公式中的系数取错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制四阶系统根轨迹的实轴段与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点求系统稳定的增益范围
本卷实例
  • 关键一步：把 s 换成 jω 代入特征方程，令实部虚部为零
  • 关键一步：交点对应的增益就是稳定范围的边界
  • 中间结果：四条根轨迹与虚轴交于两对共轭点，取正增益边界
  • 卡点：只求一组交点就下结论，漏掉另一条分支
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹与虚轴交点求系统稳定的增益范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由主导极点等阻尼线求满足阻尼比要求的参数
本卷实例
  • 关键一步：等阻尼线是从原点出发与负实轴成固定夹角的射线
  • 关键一步：阻尼比固定时闭环极点实部与虚部之比恒定
  • 中间结果：主导极点落在等阻尼线上，对应一个确定的增益
  • 卡点：把等阻尼线画成垂直线，或忽略非主导极点的影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由主导极点等阻尼线求满足阻尼比要求的参数
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式

4四、非最小相位系统奈奎斯特图与不稳定根数#

思路
  • 开环在虚轴有极点需补画无穷大圆弧，再由奈氏判据数闭环右半平面根
奈奎斯特判据 稳定性分析
本卷考法
  • 含虚轴极点时补画曲线并用奈氏判据判稳
本卷实例
  • 关键一步：开环含虚轴极点，先把幅相曲线补画到无穷大半径
  • 关键一步：数包围临界点圈数与开环右半平面极点数求闭环右根
  • 中间结果：包围圈数与开环右半平面极点数共同决定闭环右根数
  • 卡点：忘记补画无穷大圆弧，或把包围圈数正负号定义搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过含虚轴极点时补画曲线并用奈氏判据判稳
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 计算幅频与相频并画出幅相曲线
本卷实例
  • 关键一步：把 s 换成 jω，分开求模与相角随频率的变化
  • 关键一步：由起点、终点和负实轴交点确定曲线大致走向
  • 中间结果：低频段相角由积分环节与惯性环节共同决定
  • 卡点：求模时漏掉复数分母的取模，或相角漏掉积分环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过计算幅频与相频并画出幅相曲线
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式

5五、由对数幅频渐近线反求传函与相角裕度#

思路
  • 由渐近线转折频率和正弦输出条件定增益，再算两种截止频率与相角裕度
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频渐近线反求系统传递函数
本卷实例
  • 关键一步：由转折频率个数与斜率变化次数判断环节类型
  • 关键一步：用某频率处幅值条件定开环增益
  • 中间结果：低频段斜率定型别，转折点定时间常数
  • 卡点：把渐近线延长线交点当增益而未折算型别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频渐近线反求系统传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 求截止频率与相角裕度并比较近似值误差
本卷实例
  • 关键一步：渐近线交点给出的截止频率偏大，精确值需解幅值方程
  • 关键一步：在截止频率处求相角再加 180 度得相角裕度
  • 中间结果：近似法与精确解法结果相差较大，近似法偏保守
  • 卡点：把近似截止频率当精确值直接用，未说明高估原因
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度

  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过设计状态反馈把闭环极点配置到期望位置
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响

  • 特征多项式比较系数时符号写反

要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界

  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
