1一、结构图求传递函数#

思路
  • 把结构图改画为信号流图，找出全部回路与前向通道，判断互不接触关系，用梅森增益公式求闭环传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图用梅森增益公式求闭环传递函数
本卷实例
  • 关键一步：由结构图逐节点画信号流图
  • 关键一步：找出全部单回路并判断有无互不接触组合
  • 中间结果：特征式由单回路增益与两两乘积组成
  • 中间结果：前向通道的余子式需剔除接触回路
  • 卡点：需回原卷核对图1各环节的连接与反馈极性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图用梅森增益公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、弹簧质量阻尼系统建模与参数辨识#

思路
  • 由牛顿第二定律对质量块列力平衡方程，取拉氏变换得位移对力的传递函数；由阶跃响应的稳态值、超调量与峰值时间分别反求阻尼比、自然频率与三个物理参数。
机械系统建模 建模与机电系统
本卷考法
  • 由弹簧质量阻尼系统列运动方程求传递函数
本卷实例
  • 关键一步：对质量块作受力分析并按牛顿第二定律列力平衡方程
  • 关键一步：取拉氏变换整理成位移对力的传递函数
  • 中间结果：传递函数为二阶振荡环节与比例环节串联
  • 中间结果：分母系数对应质量、阻尼与刚度
  • 卡点：需回原卷核对图2(a)中质量块的受力方向
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过由弹簧质量阻尼系统列运动方程求传递函数
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由阶跃响应曲线反求二阶系统参数
本卷实例
  • 关键一步：从响应曲线读出稳态值与峰值
  • 关键一步：由超调量反求阻尼比，再由峰值时间反求自然频率
  • 中间结果：比例环节不影响动态性能指标
  • 中间结果：阻尼比乘自然频率与自然频率平方给出分母系数
  • 卡点：需回原卷核对图2(b)响应曲线的读数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由阶跃响应曲线反求二阶系统参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间计算阻尼比与自然频率
本卷实例
  • 关键一步：把峰值与稳态值之差比稳态值得超调量
  • 关键一步：由峰值时间公式解出阻尼振荡频率
  • 中间结果：超调量只与阻尼比有关
  • 中间结果：自然频率由峰值时间与阻尼比共同确定
  • 卡点：峰值读数与稳态读数的相对误差会被放大
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与峰值时间计算阻尼比与自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3三、根轨迹、稳定范围与主导极点法#

思路
  • 由前向通路与反馈通路写开环传函，按法则画根轨迹并求渐近线、分离点与虚轴交点定稳定范围；再由调节时间与主导极点条件列相角与幅值方程求阻尼比。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则概略绘制闭环根轨迹图
本卷实例
  • 关键一步：标出开环零点与极点并判断实轴上的根轨迹段
  • 关键一步：求渐近线交点与夹角，再求分离点
  • 中间结果：分支数等于开环极点数且全部指向无穷远
  • 中间结果：分离点方程的解需按实轴段筛选
  • 卡点：分离点方程高次项 OCR 有重复，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则概略绘制闭环根轨迹图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点确定稳定增益范围
本卷实例
  • 关键一步：把 s 等于 jω 代入闭环特征方程
  • 关键一步：令实部与虚部分别为零并联立求解
  • 中间结果：临界增益处出现一对纯虚根
  • 中间结果：稳定范围为临界增益以内的开区间
  • 卡点：需先用劳斯表确认临界条件再写范围
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹与虚轴交点确定稳定增益范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 按主导极点法由调节时间估算阻尼比
本卷实例
  • 关键一步：由二阶系统调节时间公式求出阻尼比乘自然频率
  • 关键一步：把主导极点代入相角条件解出虚部
  • 中间结果：调节时间取百分之二误差带对应系数四点四
  • 中间结果：由幅值条件可反求对应增益
  • 卡点：题中要求主导极点实部相差五倍，须校验近似是否成立
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过按主导极点法由调节时间估算阻尼比
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

4四、串联校正装置选型与参数设计#

思路
  • 由未校正开环传函画对数幅频特性，求原截止频率与相角裕度；分别判断超前与滞后校正能否达到目标，选定最简可行装置后按校正后截止频率与相角裕度要求设计参数。
超前校正 系统校正
本卷考法
  • 判断串联超前校正能否满足相角裕度与截止频率要求
本卷实例
  • 关键一步：求未校正系统在目标截止频率处的相角裕度
  • 关键一步：由所需补偿角判断是否超过单级超前装置上限
  • 中间结果：所需补偿角超出单级上限则不能用超前校正
  • 中间结果：截止频率提高还会带来附加相角损失
  • 卡点：逐年题干首段传函 OCR 残迹，需回原卷核对；已用宝典同段校出未校正传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过判断串联超前校正能否满足相角裕度与截止频率要求
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
滞后校正 系统校正
本卷考法
  • 判断串联滞后校正能否满足给定指标
本卷实例
  • 关键一步：在目标截止频率处求未校正系统相角裕度
  • 关键一步：比较该裕度与指标要求判断滞后法是否可行
  • 中间结果：滞后校正压低截止频率并利用原系统自身相角
  • 中间结果：目标频率处原系统相角不足则滞后法不可行
  • 卡点：滞后网络转折频率须远低于新截止频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过判断串联滞后校正能否满足给定指标
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
滞后-超前校正 系统校正
本卷考法
  • 选定最简可行装置并设计滞后超前校正参数
本卷实例
  • 关键一步：按稳态精度定开环增益、按相角裕度定超前部分参数
  • 关键一步：由幅值衰减量确定滞后部分参数
  • 中间结果：滞后部分负责低频增益、超前部分负责中频裕度
  • 中间结果：校正后截止频率需同时满足两项指标
  • 卡点：两部分的转折频率分布重叠会互相削弱
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 兼顾稳态精度与动态性能，适合指标要求较高的场合
  • 低频段用滞后部分提高增益，中高频段用超前部分提高裕度
  • 设计时先确定超前部分，再确定滞后部分
步骤
  • 按稳态精度要求确定开环增益
  • 选择新的截止频率并计算超前部分参数
  • 计算为把低频增益抬到要求值所需的滞后部分参数
  • 合并写出校正装置并校验
通用考法
  • 本卷考过选定最简可行装置并设计滞后超前校正参数
  • 设计滞后-超前校正装置
  • 说明为何单一校正无法满足指标
  • 分析校正后系统的低频与高频特性
常见易错
  • 先设计滞后部分导致截止频率反复调整
  • 两部分的转折频率分布重叠，互相削弱

5五、正反馈系统的奈奎斯特判据#

思路
  • 正反馈时奈氏判据形式与负反馈不同，先把正反馈化为等效负反馈开环，将幅相曲线旋转一百八十度；再由开环右半平面极点数与曲线对临界点的包围圈数判断闭环右半平面极点数。
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据判断正反馈闭环系统的稳定性
