一一、结构图求 C(s)/R(s) 与 E(s)/R(s)10 分#

思路
  • 由多回路结构图用梅森公式求两条传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求多回路结构图的两条传递函数
本卷实例
  • 关键一步：先列全部回路再写各前向通路及其余子式
  • 中间结果：闭环分母为公共特征式，两条分子不同
  • 卡点：结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输

  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路找漏或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

多回路系统的逐层化简 结构图与方框图
本卷考法

本卷实例
