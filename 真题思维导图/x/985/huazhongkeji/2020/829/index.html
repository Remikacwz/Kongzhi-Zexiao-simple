一一、结构图等效化简求 C(s)/R(s)#

思路
  • 用比较点与引出点移动把结构图等效化简为单回路求传函
比较点与引出点的移动 结构图与方框图
本卷考法
  • 用比较点与引出点移动化简结构图求传函
本卷实例
  • 关键一步：把引出点后移或比较点前移使回路解耦
  • 中间结果：逐级合并串联与反馈等效
  • 卡点：结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过用比较点与引出点移动化简结构图求传函
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 本卷考过移动方向与乘除关系搞反
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 对多回路结构图逐层化简求闭环传函
本卷实例
  • 关键一步：先消去最内层反馈环再向外合并
  • 中间结果：每步等效后各信号关系保持不变
  • 卡点：化简路径不唯一，两种结果应一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过对多回路结构图逐层化简求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过化简内环时把外环信号当成常数
  • 化简内环时把外环的信号当成常数处理

二二、由超调量与稳态误差确定系统参数20 分#

思路
  • 由超调量确定阻尼比、由斜坡稳态误差确定开环参数，联立求 K 与 Kr
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量要求确定阻尼比并反求系统参数
本卷实例
  • 关键一步：由超调量公式反求阻尼比
  • 中间结果：把闭环传函化为标准二阶形式再匹配系数
  • 卡点：参数关系还需与稳态误差条件联立
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量要求确定阻尼比并反求系统参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 本卷考过只满足单项指标就下结论而未交叉验证
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

  • 中间结果：代入给定误差值得到参数关系式
  • 卡点：稳态误差条件需与阻尼比条件联立求解

  • 由稳态误差要求反求开环增益

三三、根轨迹绘制与稳定 Kr 范围#

思路
  • 绘制概略根轨迹并由虚轴交点确定稳定 Kr 范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制三极点无零点的根轨迹
本卷实例
  • 关键一步：先定实轴段与渐近线再求分离点
  • 中间结果：求出分离点后筛选落在根轨迹上的根
  • 卡点：根轨迹大致走向需结合分离点判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制三极点无零点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过渐近线夹角公式中的 2k+1 写成 2k
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

本卷考法

本卷实例

  • 中间结果：令实部虚部分别为零解出交点与临界增益
  • 卡点：临界增益以下的增益区间对应稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹与虚轴交点求使系统稳定的参数范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向

四四、由对数幅频渐近线求传函与相角裕度#

思路
  • 由渐近幅频曲线反求开环传函并计算相角裕度
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频渐近线反求最小相位系统传函
本卷实例
  • 关键一步：由低频段斜率定积分环节个数与开环增益
  • 中间结果：按转折频率依次添加对应典型环节
  • 卡点：幅频渐近线以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型

  • 写出并验证传递函数
通用考法

  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 本卷考过把斜率变化对应的环节阶次判错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

本卷考法

五五、奈氏判据判稳与稳定 K 范围#

思路
  • 由开环传函画幅相曲线并用奈氏判据求稳定 K 范围
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈氏判据求使闭环稳定的参数 K 范围
本卷实例
  • 关键一步：先补画积分环节对应的无穷大圆弧
  • 中间结果：由曲线与负实轴交点定临界频率与增益
  • 卡点：按曲线是否包围负一点判稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈氏判据求使闭环稳定的参数 K 范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过开环含积分环节时未补画无穷大半径圆弧
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

  • 用 w 变换后套用劳斯判据

  • 把稳定条件写成实部小于零而不是模小于 1
