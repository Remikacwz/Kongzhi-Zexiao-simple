1一、控制系统工作原理与方框图#

思路
  • 由结构图分析系统如何按偏差调节，指出被控对象、被控量与给定量，并按信号流向画出方框图
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 指出系统的被控对象、检测变送、控制器与执行器
  • 画出系统的闭环方框图并说明工作过程
本卷实例
  • 关键一步：按被控对象、检测变送、控制器、执行器四类把图中部件对号入座
  • 关键一步：按给定、比较、控制、执行、对象、反馈的顺序连成闭环
  • 关键一步：反馈支路从被控量引回比较点，与给定量相减得到偏差
  • 中间结果：系统以偏差驱动执行器，使输出跟随输入，属按偏差调节的随动系统
  • 卡点：部件名称与信号流向需回原卷核对图1与图2
  • 卡点：本题为随动系统，套用四大环节时按广义反馈系统理解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过指出系统的被控对象、检测变送、控制器与执行器
  • 本卷考过画出系统的闭环方框图并说明工作过程
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半

2二、根轨迹绘制与闭环零极点分布#

思路
  • 先由闭环特征方程分离出与K*无关的固定闭环根，对剩余三阶系统写等效开环画根轨迹；再用阻尼比0.5的等阻尼线求共轭极点与对应增益，画闭环零极点图并算单位斜坡稳态误差
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按等效开环绘制K*从0到正无穷的根轨迹草图
  • 求渐近线交点与实轴夹角
  • 判断实轴上的根轨迹段
本卷实例
  • 关键一步：先求闭环特征方程，发现恒有一个与K*无关的根-2.2，把它单独分离出去
  • 关键一步：对剩余三阶特征方程写等效开环，再按根轨迹法则判断实轴段与渐近线
  • 关键一步：等效开环化简为K*除以s与(s²+4s+5)的乘积，极点为0和-2±j
  • 中间结果：实轴根轨迹段为负无穷到0
  • 中间结果：渐近线交点为负4/3，与实轴正向夹角为60°、180°、300°
  • 卡点：不能直接把G_c乘G_o乘H当开环，必须先分离与K*无关的固定根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按等效开环绘制K*从0到正无穷的根轨迹草图
  • 本卷考过求渐近线交点与实轴夹角
  • 本卷考过判断实轴上的根轨迹段
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹在实轴上的分离点
本卷实例
  • 关键一步：由等效开环把K*写成s的表达式，令其对s的导数为零得到分离点方程
  • 关键一步：解出后按实轴根轨迹段筛选，舍去不在根轨迹上的根
  • 中间结果：分离点方程为3s²+8s+5=0，两个根都落在实轴根轨迹段内
  • 卡点：求出两根后仍要判断哪一个是分离点、哪一个是会合点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹在实轴上的分离点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
出射角与入射角 根轨迹法
本卷考法
  • 求共轭复数极点的起始角（出射角）
本卷实例
  • 关键一步：在复数极点负2加j处写相角条件，累加其余零极点贡献的相角
  • 关键一步：由根轨迹关于实轴对称直接写出另一共轭极点的出射角
  • 中间结果：负2加j处的出射角约为负63.4°，另一极点处为对应正值
  • 卡点：累加相角时不要把这个极点自身的相角算进去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求共轭复数极点的起始角（出射角）
  • 求复数极点的出射角
  • 根据出射角画出根轨迹起始方向
  • 由入射角确定根轨迹终止方向
常见易错
  • 累加相角时把该极点自身的相角也算进去
  • 忘记判断象限导致角度差 180°
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴的交点及临界K*
本卷实例
  • 关键一步：对剩余三阶特征方程列劳斯表，令首列出现零元素得到临界条件
  • 关键一步：由辅助方程解出纯虚根频率与临界K*
  • 中间结果：临界K*对应一对共轭纯虚根，交点频率由辅助方程的二次项定出
  • 卡点：虚轴交点是共轭的一对，只代一个频率会漏掉另一半
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴的交点及临界K*
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由阻尼比0.5的等阻尼线求共轭极点与对应的K*
本卷实例
  • 关键一步：阻尼角是阻尼比的反余弦，把闭环共轭极点设在这条等阻尼射线上
  • 关键一步：把极点表达式代入闭环特征方程，令实部与虚部分别为零联立求解
  • 关键一步：求出共轭极点后再用根之和等于特征方程二次项系数取负来核对
  • 中间结果：虚部方程先定出极点到原点的距离，再回代实部方程求K*
  • 卡点：设共轭极点时不要漏掉与K*无关的固定根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由阻尼比0.5的等阻尼线求共轭极点与对应的K*
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
零极点分布与响应模态 传递函数
本卷考法
  • 按求得的闭环极点与零点画出零极点分布图
本卷实例
  • 关键一步：把闭环特征方程因式分解，逐个标出实数极点、共轭极点与闭环零点
  • 关键一步：共轭极点落在等阻尼射线上，与负实轴的夹角为阻尼角
  • 中间结果：闭环含一个固定实极点、一对指定阻尼比的共轭极点与另一个实极点，分布关于实轴对称
  • 卡点：闭环零点与开环零点不要混；分布图的具体刻度需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过按求得的闭环极点与零点画出零极点分布图
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡信号作用下的稳态误差
本卷实例
  • 关键一步：先写误差传函E(s)/R(s)，确认闭环稳定后才能用终值定理
  • 关键一步：单位斜坡输入的R(s)为s平方分之一，与误差传函相乘后取s趋近0的极限
  • 中间结果：稳态误差只由等效开环的增益项决定，与求得的K*成反比
  • 卡点：写误差传函时漏掉H(s)会得到不同的结果
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位斜坡信号作用下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、由幅相曲线求传递函数与稳定裕度#

思路
  • 由结构图与G_o的幅相曲线判断环节形式，用给定频率处的复数频率特性定出参数；再对开环分别按相角裕度与幅值裕度的要求反求增益K
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由幅相特性曲线判断G_o的环节形式
  • 用给定频率处的复数频率特性定出G_o的参数
本卷实例
  • 关键一步：由相角从0°单调减到-180°判断G_o是二阶环节且不含积分环节
  • 关键一步：用低频幅值或直流增益定出比例系数，再由ω等于根号10处的复数频率特性定阻尼比
  • 中间结果：该处频率特性只有负虚部，联立后可得阻尼比；G_o由比例系数、自然频率与阻尼比确定
  • 卡点：本题给的是幅相曲线而不是Bode图，要按复数频率特性处理；曲线标注需回原卷核对图3(b)
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由幅相特性曲线判断G_o的环节形式
  • 本卷考过用给定频率处的复数频率特性定出G_o的参数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 求相角裕度γ为60°时K的值
  • 求幅值裕度h为20dB时K的值
本卷实例
  • 关键一步：先写开环G(s)为K乘G_o(s)再除s，把积分环节单独列出
  • 关键一步：相角裕度在幅值穿越频率处定义，幅值裕度在相位穿越频率处定义，两个频率分别求
  • 关键一步：由相角裕度列相角方程解出穿越频率，再由幅值条件解出K
  • 中间结果：相角条件整理后得到关于穿越频率的二次方程，用题给参考数据取正根
  • 中间结果：幅值裕度20dB等价于相位穿越频率处开环幅值等于0.1
  • 卡点：二阶环节的相角要用反正切形式逐项累加；反正切值按题给参考数据取，不要自行取整
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）

  • 关键一步：按负倒描述函数上振幅增大的方向判断极限环是否稳定
  • 中间结果：线性部分与负实轴的交点频率即自振频率，该处负实数值决定非线性环节的输入振幅
  • 中间结果：题目问的输出振幅还要按线性环节在该频率处的幅值换算
  • 卡点：输出振幅与描述函数输入振幅之间差一个线性环节的幅值；判断稳定自振要结合两条曲线的走向
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过判断系统是否自振并求输出振幅与频率
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率
