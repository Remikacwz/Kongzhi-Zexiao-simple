一一、结构图与稳态振荡#

思路
  • 由结构图列特征方程，用等幅振荡条件定增益与频率，再由主导极点估算性能并设计前馈
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图列写闭环特征方程
本卷实例
  • 关键一步：按梅森公式写出含时间常数与增益的特征式
  • 中间结果：特征式为三阶多项式
  • 卡点：结构图连接点需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图列写闭环特征方程
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过回路增益符号取错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

劳斯判据 稳定性分析
本卷考法
  • 由等幅振荡条件求增益与振荡频率
本卷实例
  • 关键一步：把纯虚根代入特征式并令实虚部为零
  • 中间结果：解出临界增益与振荡角频率
  • 卡点：振荡频率单位为弧度每秒
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由等幅振荡条件求增益与振荡频率
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过只令实部为零而漏掉虚部条件
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

二二、根轨迹与最佳阻尼比#

思路
  • 由开环传函画根轨迹，求起始角、分离点与虚轴交点，再按最佳阻尼比定增益并分析响应
出射角与入射角 根轨迹法
本卷考法
  • 求复数开环极点的起始角
本卷实例
  • 关键一步：用相角条件减去其余零极点的贡献
  • 中间结果：两条起始角关于实轴对称
  • 卡点：象限判断影响角度取值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求复数开环极点的起始角
  • 求复数极点的出射角
  • 根据出射角画出根轨迹起始方向
  • 由入射角确定根轨迹终止方向
常见易错
  • 本卷考过累加相角时把该极点自身算进去
  • 累加相角时把该极点自身的相角也算进去
  • 忘记判断象限导致角度差 180°

  • 求根轨迹的分离点坐标

三三、奈氏判据与谐振峰值#

思路
  • 由幅相特性反求对象传函，用奈氏判据判稳，再结合稳态误差与谐振指标求参数
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈氏判据判断开环含积分环节时的稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数再算包围圈数
  • 中间结果：幅相曲线穿过负实轴时临界稳定
  • 卡点：包围圈数正负定义需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈氏判据判断开环含积分环节时的稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过含积分环节时未补画无穷大圆弧
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由斜坡输入稳态误差反求时间常数
本卷实例
  • 关键一步：先化为典型一型系统再取速度误差系数
  • 中间结果：时间常数与稳态误差成正比
  • 卡点：速度误差系数与开环增益的关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由斜坡输入稳态误差反求时间常数
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过未判稳就代入终值定理
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
闭环频率特性与性能指标 频域分析
本卷考法
  • 求使稳态输出振幅最大的频率与峰值
本卷实例
  • 关键一步：由闭环传函读出阻尼比与自然频率
  • 中间结果：谐振频率由上述两个参数决定
  • 卡点：最大振幅等于输入幅值乘谐振峰值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过求使稳态输出振幅最大的频率与峰值
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 本卷考过阻尼比大于 0.707 仍套谐振公式
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

思路

由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频特性反求最小相位对象传函
本卷实例
