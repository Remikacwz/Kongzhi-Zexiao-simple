思路

本卷考法

本卷实例

减小稳态误差的措施 稳态误差
本卷考法
  • 设计前馈通道使阶跃输入稳态误差为零
本卷实例
  • 关键一步：令误差传函分子恒零反解前馈器
  • 中间结果：前馈器由两条通路的增益比确定
  • 卡点：前馈接入点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计前馈通道使阶跃输入稳态误差为零
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错

  • 只谈误差减小而不检查稳定性是否被破坏

二二、Bode反求传函与干扰稳态误差25 分#

思路
  • 由对数幅频渐近线反求开环传函，用劳斯判据定临界增益与振荡频率，再求干扰下稳态误差
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频渐近线写出 G1(s)
本卷实例
  • 关键一步：先由低频段斜率定积分环节个数
  • 中间结果：再由转折频率依次写出各典型环节
  • 卡点：转折频率读数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频渐近线写出 G1(s)
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 本卷考过把延长线交点当增益而未折算型别
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

劳斯判据 稳定性分析
本卷考法
  • 由特征式列劳斯表求临界增益
本卷实例
  • 关键一步：写出四阶特征多项式后逐行列劳斯表

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤

  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由特征式列劳斯表求临界增益
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过首列出现零时未用 ε 法处理
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

思路

本卷考法

要点

  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称

  • 实轴段判据中的零极点个数算错
