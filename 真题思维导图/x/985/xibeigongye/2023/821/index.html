二二、根轨迹与参数范围#

思路
  • 由特征多项式画根轨迹，按阻尼比与自然频率约束在复平面标出轨迹段并求参数范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制根轨迹并求分离点
本卷实例
  • 关键一步：由开环零极点确定起点终点与渐近线
  • 中间结果：轨迹复平面部分构成圆弧
  • 卡点：轨迹形状需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制根轨迹并求分离点
  • 按法则绘制根轨迹草图

  • 判断某段实轴是否属于根轨迹

  • 实轴段判据中的零极点个数算错

三三、由幅频折线求传函与稳定范围#

思路
  • 由折线幅频特性反求开环传函，画幅相曲线，再由奈氏判据定稳定增益范围
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由折线幅频特性写出开环传函
本卷实例
  • 关键一步：由低频段斜率与截止频率定积分环节个数与增益
  • 中间结果：传函含一个微分环节与两个积分环节
  • 卡点：转折频率数值需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由折线幅频特性写出开环传函
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 本卷考过各转折频率处的斜率改错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 逆时针包围为正，顺时针为负
步骤

  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
