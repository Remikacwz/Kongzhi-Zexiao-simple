一一、误差传函与前馈补偿#

思路
  • 用梅森公式求误差传函，由劳斯判据与斜坡误差约束定 k 范围，再设计前馈使误差为零
梅森增益公式与信号流图 传递函数
本卷考法
  • 由多回路结构图用梅森公式求误差传函
本卷实例
  • 关键一步：先数回路并找出互不接触的那一对回路
  • 中间结果：误差传函化为三阶有理分式
  • 卡点：结构图与前馈接入点需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由多回路结构图用梅森公式求误差传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过余子式漏掉与通路不接触的回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

误差定义与误差传递函数 稳态误差
本卷考法

本卷实例
  • 关键一步：先确认误差取 R 减 5C 再列通道
  • 中间结果：分子分母都含开环回路增益
  • 卡点：反馈系数 5 的作用点需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法

  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 本卷考过非单位反馈时两种误差定义混用
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求闭环稳定的 k 上界
本卷实例
  • 关键一步：写出三阶特征式后列劳斯表首列
  • 中间结果：稳定条件化为关于 k 的不等式
  • 卡点：特征式系数由回路化简得到
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求闭环稳定的 k 上界
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过首列出现零时未用 ε 法处理
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

减小稳态误差的措施 稳态误差
本卷考法
  • 设计前馈使斜坡输入下稳态误差为零
本卷实例
  • 关键一步：令误差传函分子恒为零反解前馈通道
  • 中间结果：前馈传函由两条通路的增益比确定
  • 卡点：补偿器的可实现性需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计前馈使斜坡输入下稳态误差为零
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 本卷考过只看分子为零而漏查闭环稳定性
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

思路

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法

本卷实例

  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤

  • 比对系数求出 ωn 与 ξ

通用考法
