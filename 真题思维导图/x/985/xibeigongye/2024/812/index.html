1一、函数记录仪方框图与测速反馈#

思路
  • 由各部件传递函数关系画出系统框图，用信号流图求闭环传函；再把闭环化为标准二阶形式求调节时间，并对比加入测速反馈前后阻尼比与超调的变化。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出函数记录仪的被控对象、被控量与操纵量并画系统方框图
本卷实例
  • 关键一步：按各部件输入输出关系把物理量逐个对号入座
  • 中间结果：给定、反馈、放大与执行机构连成按偏差调节的闭环
  • 卡点：函数记录仪工作原理图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指出函数记录仪的被控对象、被控量与操纵量并画系统方框图
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
直流电机等机电系统 建模与机电系统
本卷考法
  • 由电机力矩方程与运动方程建立执行机构的传递函数
本卷实例
  • 关键一步：把力矩平衡关系整理成电机转角的高阶微分方程
  • 中间结果：执行机构化为含机电时间常数的二阶环节
  • 卡点：微分方程中机械惯性项与阻尼项要分别识别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由电枢回路电压方程与转矩平衡方程联立
  • 反电动势与转速成正比，电磁转矩与电枢电流成正比
  • 机电时间常数由电气与机械两方面参数共同决定
步骤
  • 写出电枢回路电压平衡方程
  • 写出转矩平衡方程（含负载与粘性摩擦）
  • 消去电枢电流，得到转速或转角对电压的传递函数
通用考法
  • 本卷考过由电机力矩方程与运动方程建立执行机构的传递函数
  • 求直流电机转速或位置对电枢电压的传递函数
  • 分析机电时间常数与电气时间常数的数量级关系
常见易错
  • 漏掉反电动势与电磁转矩的耦合项
  • 把电气时间常数与机电时间常数混淆

梅森增益公式与信号流图 传递函数
本卷考法
  • 由系统框图列信号流图并用梅森公式求闭环传递函数
本卷实例
  • 关键一步：标出各回路与前向通路并判断是否互不接触
  • 中间结果：特征式由各回路增益相加再补互不接触回路项
  • 卡点：回路增益的符号随反馈极性取负
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由系统框图列信号流图并用梅森公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为标准二阶形式读出阻尼比与自然频率
本卷实例
  • 关键一步：把传递函数分母归一为二次项系数为 1
  • 中间结果：一次项系数与常数项分别对应阻尼比与自然频率
  • 卡点：串联的比例环节不影响动态性能指标
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为标准二阶形式读出阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率求调节时间和超调量
本卷实例
  • 关键一步：按给定误差带选取调节时间的时间常数倍数
  • 中间结果：调节时间与阻尼比和自然频率的乘积成反比
  • 卡点：误差带取 2% 还是 5% 决定时间常数倍数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率求调节时间和超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
反馈校正与复合控制 系统校正
本卷考法
  • 分析测速反馈环节对阻尼比与超调量的作用
本卷实例
  • 关键一步：把测速反馈等效为闭环中新增的阻尼项
  • 中间结果：加入测速反馈后自然频率与阻尼比同时改变
  • 卡点：超调量的增减需按推导结果判断，不能凭直觉
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过分析测速反馈环节对阻尼比与超调量的作用
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

2二、多回路结构图求传函与稳态误差#

思路
  • 由结构图列回路增益并用梅森公式求 C(s)/R(s) 与 E(s)/R(s)；再用劳斯判据定稳定范围，由终值定理把阶跃稳态误差约束转成增益范围；最后以正弦输入的误差频率特性求稳态分量的幅度与相角。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 化简含多条并联前向通路的反馈结构图
本卷实例
  • 关键一步：分别列出各条前向通路与回路增益再整体化简
  • 中间结果：闭环分母由各回路特征式合并得到
  • 卡点：源文答案段注题图宜按负反馈理解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过化简含多条并联前向通路的反馈结构图
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式由信号流图求闭环与误差传递函数
本卷实例
  • 关键一步：先画信号流图再数回路与前向通路
  • 中间结果：特征式含各回路增益及互不接触项
  • 卡点：前向通路的余子式要剔除与其接触的回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式由信号流图求闭环与误差传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 由误差传递函数求给定输入下的稳态误差
本卷实例
  • 关键一步：先判稳再用终值定理求误差极限
  • 中间结果：误差传函可由 1 减去闭环传函得到
  • 卡点：非单位反馈时误差定义要与题设一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由误差传递函数求给定输入下的稳态误差
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由阶跃稳态误差上限反求开环增益范围
本卷实例
  • 关键一步：写出静态误差系数表达式并代入误差上限
  • 中间结果：误差约束给出增益的另一个下界
  • 卡点：稳定范围与误差范围需取交集
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由阶跃稳态误差上限反求开环增益范围
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由正弦输入的频率特性求误差稳态分量的幅度与相角
本卷实例
  • 关键一步：把误差传函中的 s 换为 jω 后按模与相角分解
  • 中间结果：稳态误差幅度等于误差频率特性的模
  • 卡点：相角计算要区分增益大于或小于临界值两种情形
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由正弦输入的频率特性求误差稳态分量的幅度与相角
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

3三、由奈奎斯特图反求传函与参数根轨迹#

思路
  • 由幅相曲线上的低频值与指定频率点联立反求开环传函；再写出以增益为变量的等效开环传函，按法则求渐近线、出射角与分离点；最后由给定闭环极点用幅值条件定增益并求其余极点。
频率特性的物理意义与求法 频域分析
本卷考法
  • 由奈奎斯特图上的特征点反求开环传递函数
本卷实例
  • 关键一步：分别代入低频值与指定频率点的幅值和相角建立方程
  • 中间结果：由两个方程定出二阶环节的增益与阻尼比
  • 卡点：图中曲线标注的是 G 还是 G0 需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示

6六、继电非线性系统相平面分析#

思路
  • 由继电环节与误差定义写出分段误差微分方程，求开关线方程；再分区建立相轨迹方程、判断奇点类型，最后按给定初始条件画相轨迹与输出响应。
相平面法 非线性系统
本卷考法
  • 分区列写误差微分方程并求开关线方程
本卷实例
  • 关键一步：把误差定义为输入减输出后代入继电环节输出
  • 中间结果：开关线由继电特性的分段边界确定
  • 卡点：输入为常值时误差方程右端含输入与误差的组合
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过分区列写误差微分方程并求开关线方程
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

非线性系统的特点 非线性系统
本卷考法
  • 分区间线性化后判断奇点类型
本卷实例
  • 关键一步：在各区求平衡点并对误差方程作线性化
  • 中间结果：由线性化特征根判断奇点类型
  • 卡点：相轨迹分区边界处要按初始条件判断所处区间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法

  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
