1一、由阶跃响应反求传函与稳态误差#

思路
  • 对阶跃响应做拉氏变换反推闭环传函，再按误差传函用终值定理求阶跃与斜坡输入的稳态误差。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应反求闭环传递函数
本卷实例
  • 关键一步：把阶跃响应写成常数项与两个指数项之和
  • 中间结果：由部分分式系数与极点对应定出传函
  • 卡点：常数项对应直流增益，别当成极点贡献
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应反求闭环传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
传递函数的定义与基本性质 传递函数
本卷考法
  • 由传递函数求单位脉冲响应
本卷实例
  • 关键一步：对传递函数做拉氏反变换得脉冲响应
  • 中间结果：单位脉冲响应就是传函的拉氏逆变换
  • 卡点：先确认零初始条件再写传递函数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由传递函数求单位脉冲响应
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由误差传函求阶跃与斜坡输入的稳态误差
本卷实例
  • 关键一步：先判闭环稳定再用终值定理取极限
  • 中间结果：阶跃误差由误差传函直流增益定，斜坡误差由原点展开一次项定
  • 卡点：两种典型输入的误差公式不能混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由误差传函求阶跃与斜坡输入的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

2二、开环频率特性与稳定裕度#

思路
  • 写出幅频相频表达式后逐段叠加画概略伯德图，分别求相角裕度与幅值裕度并判稳。
频率特性的物理意义与求法 频域分析
本卷考法
  • 求开环传递函数的幅频与相频表达式
本卷实例
  • 关键一步：把复变量换成纯虚数后分母有理化
  • 中间结果：幅频为各环节幅值之积，相频为各环节相角之和
  • 卡点：积分环节的相角恒为负九十度，别漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求开环传递函数的幅频与相频表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 按转折频率逐段叠加斜率画概略伯德图
本卷实例
  • 关键一步：由积分环节个数定低频段起始斜率
  • 中间结果：每过一个转折频率斜率按其环节阶数改变
  • 卡点：出现负四十斜率时要判断是两一阶还是一阶振荡
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过按转折频率逐段叠加斜率画概略伯德图
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
稳定裕度 频域分析
本卷考法
  • 求相角裕度与幅值裕度并判断闭环稳定性
本卷实例
  • 关键一步：由幅频等于一求截止频率，由相角等于负一百八十求穿越频率
  • 中间结果：相角裕度与幅值裕度分别在对应频率处折算
  • 卡点：截止频率与相角穿越频率别混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求相角裕度与幅值裕度并判断闭环稳定性
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式

3三、零阶保持器离散系统稳定k范围（含图）#

思路
  • 先求广义对象的z传函与闭环特征方程，再用朱利判据求使特征根都在单位圆内的k范围。
脉冲传递函数 离散控制系统
本卷考法
  • 求含零阶保持器的开环脉冲传递函数
本卷实例
  • 关键一步：把连续部分部分分式化后逐项查z变换表
  • 中间结果：广义对象整理成z的有理分式
  • 卡点：零阶保持器的z减一因子别漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过求含零阶保持器的开环脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)
公式
离散系统稳定性分析 离散控制系统
本卷考法
  • 用朱利判据求离散系统稳定的参数范围
本卷实例
  • 关键一步：写出闭环特征多项式后代入朱利稳定条件
  • 中间结果：由特征多项式在正负一的取值与常数项约束联立
  • 卡点：稳定条件是特征根模小于一，不是实部为负
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过用朱利判据求离散系统稳定的参数范围
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

4四、状态矩阵特征根与对角线规范型#

思路
  • 由特征方程求两个特征根，再解对应特征向量构造变换阵，把状态方程化为对角线规范型。
由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 借位：由特征根与特征向量化对角规范型
本卷实例
  • 关键一步：解特征方程得到两个互异特征根
  • 中间结果：由特征向量按列排成非奇异变换阵
  • 卡点：变换阵必须可逆，特征向量要线性无关
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法
  • 本卷考过借位：由特征根与特征向量化对角规范型
  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反
公式
状态空间表达式的建立 状态空间分析
本卷考法
  • 由给定系统矩阵写状态空间表达式
本卷实例
  • 关键一步：识别状态矩阵、输入矩阵与输出矩阵
  • 中间结果：线性变换后新的三个矩阵由原矩阵变换而得
  • 卡点：同一传函的状态空间实现不唯一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由给定系统矩阵写状态空间表达式
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式

5五、根轨迹绘制与稳定增益范围#

思路
  • 画两重极点系统的根轨迹求渐近线、分离点与虚轴交点，由交点增益定稳定范围并换算尾一型开环增益。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制含重极点的根轨迹草图
本卷实例
  • 关键一步：标出开环极点并判实轴上的根轨迹段
  • 中间结果：渐近线交点为各极点平均值，夹角按极点数计算
  • 卡点：重极点使渐近线条数与夹角都要重算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制含重极点的根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求重极点系统的分离点坐标
本卷实例
  • 关键一步：由分离点方程求解并舍去不在轨迹上的根
  • 中间结果：分离点处的增益由幅值条件回代得到
  • 卡点：重极点处分离点方程有重根，注意取舍
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
