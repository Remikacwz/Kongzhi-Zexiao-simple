1一、频域稳定裕度与串联超前校正#

思路
  • 由开环传函画Bode图求剪切频率、相角裕度与幅值裕度，再按目标相角裕度用超前校正公式定参数
稳定裕度 频域分析
本卷考法
  • 由开环传函求剪切频率与相角、幅值裕度
本卷实例
  • 关键一步：先求开环幅频为1处的剪切频率与相频为-180度的频率
  • 关键一步：相角裕度按180度加剪切频率处相角求，幅值裕度取该处幅值倒数
  • 中间结果：校正前相角裕度低于要求的50度，需用超前环节补相角
  • 卡点：题面传函被OCR打乱，两源比对后按K除以s(0.5s+1)读
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由开环传函求剪切频率与相角、幅值裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
超前校正 系统校正
本卷考法
  • 按目标相角裕度设计串联超前校正装置并求参数
本卷实例
  • 关键一步：由目标裕度减原裕度再加5到10度补偿角得最大超前角
  • 关键一步：令最大超前角频率等于新剪切频率，反求a与T
  • 中间结果：超前环节两转折频率为aT分之一与T分之一
  • 卡点：剪切频率右移带来附加相角损失，补偿角偏小会不达标
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过按目标相角裕度设计串联超前校正装置并求参数
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

2二、测速反馈校正与速度输入稳态误差#

思路
  • 由测速反馈结构写闭环特征方程，对照典型二阶形式定参数，再用终值定理分别求校正前后的速度误差
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由测速反馈结构写闭环特征方程并对照典型二阶形式
本卷实例
  • 关键一步：列测速反馈闭环特征方程，一次项系数含反馈参数
  • 关键一步：与标准二阶的2倍阻尼乘自然频率和自然频率平方逐项对照
  • 中间结果：给定阻尼比等于1可先定出反馈参数，再得自然频率
  • 卡点：参数定出后要回代，别把开环增益当闭环增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由测速反馈结构写闭环特征方程并对照典型二阶形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
反馈校正与复合控制 系统校正
本卷考法
  • 用测速反馈即速度反馈校正改善系统阻尼
本卷实例
  • 关键一步：把速度反馈信号与主反馈在比较点处合成
  • 关键一步：校正后开环分母多出与反馈系数有关的s项
  • 中间结果：测速反馈不提高开环型别，但改变闭环阻尼
  • 卡点：先改变闭环特征方程，须重新判稳后再算误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过用测速反馈即速度反馈校正改善系统阻尼
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 分别求校正前后单位速度输入下的稳态误差
本卷实例
  • 关键一步：先判稳，再求速度误差系数
  • 关键一步：按输入幅值除以速度误差系数得稳态误差
  • 中间结果：校正后速度误差系数变化，稳态误差随之改变
  • 卡点：未判稳直接用终值定理会得到无效结果
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过分别求校正前后单位速度输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、两输入两输出系统的结构图与传递函数矩阵#

思路
  • 由给定微分方程组画模拟结构图，写成矩阵形式后用传递函数矩阵公式求两路输出
状态空间表达式的建立 状态空间分析
本卷考法
  • 由两入两出微分方程组画模拟结构图并写状态空间形式
本卷实例
  • 关键一步：每个状态变量对应一个积分器，按系数连线
  • 关键一步：把微分方程整理成状态导数等于Ax加Bu的形式
  • 中间结果：系数矩阵A为2乘2，输入矩阵B也为2乘2
  • 卡点：两输入两输出时B与C都不是列向量，维数别写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由两入两出微分方程组画模拟结构图并写状态空间形式
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 用传递函数矩阵公式求各输出对输入的传函
本卷实例
  • 关键一步：写Y(s)等于C乘sI减A的逆再乘B乘U(s)
  • 关键一步：先求sI减A的行列式与伴随矩阵
  • 中间结果：两路输出共用同一特征多项式作分母
  • 卡点：求逆时伴随矩阵要转置，符号容易错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过用传递函数矩阵公式求各输出对输入的传函
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

5五、机械与电路网络的传递函数及相似性#

思路
  • 分别对弹簧阻尼机械系统与RC网络列方程求传函，对比两式结构证明形式相同
机械系统建模 建模与机电系统
本卷考法
  • 对弹簧阻尼机械系统列力平衡方程求位移传函
本卷实例
  • 关键一步：对各质量块分别列牛顿第二定律方程
  • 关键一步：取拉氏变换消去中间变量
  • 中间结果：所得传函分子分母同为二阶多项式
  • 卡点：机械系统连接未读图，受力方向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过对弹簧阻尼机械系统列力平衡方程求位移传函
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 用复阻抗法求RC网络输出对输入的传函
本卷实例
  • 关键一步：把电容写成1除以Cs，按串并联分压求传函
  • 关键一步：整理成s的二次多项式之比
  • 中间结果：两传函分母的一次项系数差一个交叉阻容项
  • 卡点：令机械量与电学量对应相等即可证两式形式一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤

  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过用复阻抗法求RC网络输出对输入的传函
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
