2二、微分方程的时域解#

思路
  • 先由特征方程求出齐次解的模态，再按右端指数激励设特解，最后代入两个初始条件联立定常数
零极点分布与响应模态 传递函数
本卷考法
  • 由微分方程特征根写出齐次解的模态
本卷实例
  • 关键一步：令齐次方程对应特征方程为零，解出两个特征根
  • 关键一步：按特征根直接写出指数模态的线性组合
  • 关键一步：右端为指数激励，按同形设特解并代回原方程定系数
  • 中间结果：两个特征根异号，齐次解同时含发散模态与衰减模态
  • 卡点：题面第二个初值条件印成(0)=0，按一阶导为零理解，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由微分方程特征根写出齐次解的模态
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

3三、二阶系统的单位阶跃响应#

思路
  • 由阶跃响应曲线读稳态值、超调量与峰值时间，反求阻尼比与自然频率，再写开环传函并算调节时间
由响应曲线反求传递函数 传递函数
本卷考法
  • 由阶跃响应曲线读指标并反求二阶参数
本卷实例
  • 关键一步：先从曲线上读稳态值、峰值与峰值时刻三个量
  • 关键一步：用超调量反求阻尼比，再由峰值时间反求自然频率
  • 中间结果：曲线有振荡且稳态非零，说明是欠阻尼二阶系统且增益为稳态值
  • 卡点：响应曲线未读图，稳态值、峰值与峰值时刻需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由阶跃响应曲线读指标并反求二阶参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 写闭环标准二阶形式并由单位反馈反推开环传函
本卷实例
  • 关键一步：把求得的阻尼比与自然频率代入标准二阶形式，稳态值定增益
  • 关键一步：单位负反馈下由闭环传函推出开环传函
  • 中间结果：开环在原点有一个极点，分母比闭环分母少一个常数项
  • 卡点：开环与闭环只差单位反馈关系，别把开环增益直接当闭环增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过写闭环标准二阶形式并由单位反馈反推开环传函
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率计算调节时间
本卷实例
  • 关键一步：调节时间与阻尼比乘自然频率成反比，按误差带选系数
  • 关键一步：两条误差带对应两组系数，按题意选用
  • 中间结果：阻尼比与自然频率已由前两问确定，代入即可得两条误差带下的结果
  • 卡点：百分之五与百分之二误差带的系数容易取混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法

  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

4四、含复数极点的根轨迹绘制#

思路
  • 标出开环零极点并判断实轴段，再算渐近线、分离点、出射角与虚轴交点，最后按对称性连成根轨迹
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画出增益由零到无穷的根轨迹
本卷实例
  • 关键一步：先标出全部开环极点，无零点，分支数等于极点个数
  • 关键一步：实轴段用该段右侧零极点总数为奇数判断
  • 中间结果：四条渐近线的交点由极点之和除以极点数得到
  • 卡点：复数极点成对出现，实轴段只在相邻实极点之间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画出增益由零到无穷的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹在实轴上的分离点
本卷实例
  • 关键一步：由特征方程把可变增益表示成 s 的函数，再令导数为零
  • 关键一步：解出驻点后按实轴段判据筛选

  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解

出射角与入射角 根轨迹法
本卷考法
  • 求共轭复数极点的出射角
本卷实例
  • 关键一步：对一个复数极点用相角条件，把其余零极点相角移到等式另一边
  • 关键一步：利用共轭对称性直接写另一极点的出射角
  • 中间结果：出射角由其余各极点贡献的相角累加得到

通用考法

  • 求复数极点的出射角

  • 由入射角确定根轨迹终止方向
常见易错
  • 累加相角时把该极点自身的相角也算进去

5五、输入与扰动共同作用下的稳态误差#

思路
  • 用叠加原理分别求输入通道与扰动通道的误差传函，按终值定理求各自稳态误差后相加
误差定义与误差传递函数 稳态误差
本卷考法
  • 分别写出输入通道与扰动通道的误差传递函数
本卷实例
  • 关键一步：先看清题意中误差取在输入端还是反馈端
  • 关键一步：令另一个输入为零，单独写该通道的误差传函
  • 中间结果：两个通道共用同一个特征多项式，分母一致
  • 卡点：求扰动通道时忘记把参考输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过分别写出输入通道与扰动通道的误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
扰动作用下的稳态误差 稳态误差
本卷考法

  • 关键一步：核对状态变量个数与独立储能元件个数一致
  • 中间结果：输出矩阵由输出与两个状态变量的关系得到
  • 卡点：输出方程里的系数与符号容易抄漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系

  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统

  • 列写各状态变量的一阶微分方程

能控性与能观性 状态空间分析
本卷考法
  • 构造能观性矩阵并用秩判据判断能观性
本卷实例
  • 关键一步：按输出矩阵与系统矩阵的乘积构造能观性矩阵
  • 关键一步：求矩阵的秩并与系统阶数比较
  • 中间结果：两个状态在输出中的系数成比例时能观性矩阵会降秩
  • 卡点：能观性判据与能控性判据的矩阵构造容易互换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过构造能观性矩阵并用秩判据判断能观性
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
