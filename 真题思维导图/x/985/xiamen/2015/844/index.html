1一、由运放模拟电路求闭环传递函数（含图）20 分#

思路
  • 对两级运放的反相输入端分别用虚短虚断列KCL方程，消去级间节点电压后整理得输出与输入之比。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由多级有源运放网络求闭环传递函数
本卷实例
  • 关键一步：对每个运放的反相输入端列KCL方程
  • 中间结果：先消去级间节点电压再合并同类项
  • 卡点：电容复阻抗写成1除以sC，别写成Cs
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由多级有源运放网络求闭环传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法

本卷实例

  • 中间结果：每一级输出写成前级电压的有理分式
  • 卡点：级间接线以图给出，需回原卷核对图

  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过运算放大器有源网络的建模与化简
  • RC 网络或有源滤波器求传递函数

2二、根轨迹绘制、稳定K范围与劳斯验证15 分#

思路
  • 由三个开环极点画180度根轨迹，求渐近线交点与夹角、分离点及虚轴交点，得稳定K范围后列劳斯表验证。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制三个开环极点的根轨迹草图
本卷实例
  • 关键一步：先标出三个极点再判实轴根轨迹段
  • 中间结果：三条渐近线交点由极点之和除以极点数得到
  • 卡点：实轴段右侧零极点个数为奇数才算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制三个开环极点的根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求分离点坐标并筛选在轨迹上的解
本卷实例
  • 关键一步：令分离点方程为零并解出两个坐标
  • 中间结果：两个解需按所在实轴段取舍
  • 卡点：不在根轨迹上的解必须舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求分离点坐标并筛选在轨迹上的解
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界增益
本卷实例
  • 关键一步：把复变量取纯虚数代进闭环特征方程
  • 中间结果：实部虚部分别为零得到交点频率与增益
  • 卡点：零频率那组解要单独说明其含义
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据验证根轨迹得到的K范围
本卷实例
  • 关键一步：对三阶特征方程按降幂列出劳斯表
  • 中间结果：首列各元素均大于零给出一致区间
  • 卡点：系数有缺项时先补零再列
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据验证根轨迹得到的K范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

3三、温度计一阶惯性环节与斜坡输入稳态误差15 分#

思路
  • 由一阶惯性环节一分钟达指示值98%定出时间常数，再把斜坡输入下的误差传函代入终值定理求稳态误差。
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由一阶响应达稳态值的98%反求时间常数
本卷实例
  • 关键一步：把98%代入一阶阶跃响应表达式解时间常数
  • 中间结果：时间常数由达指定百分比所用时间折算
  • 卡点：2%误差带与5%误差带的系数别混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由一阶响应达稳态值的98%反求时间常数
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 写出温度指示值对实际值的误差传函
本卷实例
  • 关键一步：按误差定义写E(s)与R(s)之比
  • 中间结果：误差传函等于1减去指示环节传函
  • 卡点：先确认系统稳定再用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写出温度指示值对实际值的误差传函
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 等速升温斜坡输入下求稳态指示误差
本卷实例
  • 关键一步：把斜坡输入拉氏式乘误差传函后取极限
  • 中间结果：稳态误差由误差传函在原点附近展开得到
  • 卡点：输入斜率单位要与时间常数统一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过等速升温斜坡输入下求稳态指示误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

4四、双积分执行器加比例微分环节的稳定条件（含图）10 分#

思路
  • 把前向通道写成含比例微分环节的开环传函，列闭环特征方程后由劳斯表首列各元素大于零求稳定条件。
典型环节及其特性 传递函数
本卷考法
  • 识别并写出比例微分环节的传递函数
本卷实例
  • 关键一步：把微分作用写成时间常数乘s再加1的形式
  • 中间结果：开环传函分子多出一个一阶微分项
  • 卡点：纯微分环节与一阶微分环节别混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过识别并写出比例微分环节的传递函数
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减

5五、一零点两极点系统的根轨迹与圆轨迹证明（含图）15 分#

思路
  • 标出开环极点与零点画180度根轨迹，求实轴段、渐近线、分离点与虚轴交点，并证明复平面段是圆。
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 用相角与幅值条件分析根轨迹形状
本卷实例
  • 关键一步：把闭环特征方程化成幅值相角条件
  • 中间结果：相角条件决定轨迹的几何形状
  • 卡点：幅值条件只定增益，位置由相角条件定
