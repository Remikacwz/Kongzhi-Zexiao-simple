厦门大学 844 自动控制理论（含现控） 2017 年真题思维导图

985 院校共 11 题

难度：中等　11道大题，覆盖由阶跃响应反求传函与频率特性、二阶系统参数与动态性能、稳态误差与相角裕度及超前校正、运放电路功能分析、滞环继电特性、执行机构饱和的影响、右半平面零点与比例控制稳定范围、简谐振子稳定性与输出反馈、根轨迹与幅值稳定裕度、两质量块弹簧系统建模、由阶跃响应曲线估计动态性能。

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

1一、由单位阶跃响应求传函、频率特性与稳态输出#

思路
  • 把阶跃响应按极点展成指数项之和，反推出闭环传函，再写成频率特性并由终值定理求常数输入的稳态输出。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由实测单位阶跃响应反求闭环传递函数
本卷实例
  • 关键一步：把阶跃响应写成常数项加两个指数项之和
  • 中间结果：各项系数与极点对应拉氏变换后的部分分式
  • 卡点：响应里的常数项对应直流增益别漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由实测单位阶跃响应反求闭环传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由传函写频率特性并求常数输入的稳态输出
本卷实例
  • 关键一步：把复变量换成纯虚数得幅频与相频
  • 中间结果：正弦激励下稳态输出按幅相特性缩放平移
  • 卡点：常数输入时稳态输出取直流增益乘幅值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由传函写频率特性并求常数输入的稳态输出
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

2二、二阶系统的参数确定与动态性能#

思路
  • 由正弦激励下稳态输出的幅值比与相移定出阻尼比和自然频率，再写出单位阶跃响应并推算上升时间与超调量。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由正弦稳态输出反求二阶系统参数
本卷实例
  • 关键一步：比较稳态输出的幅值与相移列出方程
  • 中间结果：相移条件与幅值条件联立解出两个参数
  • 卡点：先把闭环传函化为标准二阶形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由正弦稳态输出反求二阶系统参数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率推算动态性能指标
本卷实例
  • 关键一步：把阻尼比代入超调量表达式
  • 中间结果：上升时间由自然频率与阻尼比共同决定
  • 卡点：欠阻尼上升时间公式的根号项别写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率推算动态性能指标
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3三、稳态误差与相角裕度分析及超前校正#

思路
  • 先由斜坡误差指标定开环增益，再画校正前频率特性看裕度是否达标，若不达标按给定最大补偿角设计超前网络并校验。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡稳态误差要求反求开环增益
本卷实例
  • 关键一步：由速度误差系数与误差上限列不等式
  • 中间结果：开环增益需满足的下界由误差指标给出
  • 卡点：系统型别决定斜坡误差是否有限
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位斜坡稳态误差要求反求开环增益
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
稳定裕度 频域分析
本卷考法
  • 判断校正前相角裕度是否达标
本卷实例
  • 关键一步：由幅频特性等于1求截止频率
  • 中间结果：相角裕度由该频率处相角加180度得
  • 卡点：纯积分环节相角恒为负90度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过判断校正前相角裕度是否达标
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
超前校正 系统校正
本卷考法
  • 按给定最大补偿角设计超前校正网络
本卷实例
  • 关键一步：把最大补偿角安排在新的截止频率处
  • 中间结果：由补偿角反解网络分度系数与时间常数
  • 卡点：设计完要回代核对两项指标
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过按给定最大补偿角设计超前校正网络
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式

4四、运放电路求传函并分析功能（含图）#

思路
  • 对理想运放的两个输入端用虚短虚断列KCL方程，求出输出对输入的传递函数，再由其频段特性判断电路功能。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由运算放大器电路求输入到输出的传函
本卷实例
  • 关键一步：按复阻抗对运放输入端列KCL方程
  • 中间结果：整理成输出比输入的有理分式
  • 卡点：电容与电阻并联时阻抗要取并联值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由运算放大器电路求输入到输出的传函
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 含运放有源网络的功能分析
本卷实例
  • 关键一步：由传函在低频与高频段的增益判断功能
  • 中间结果：通带与阻带位置决定滤波器类型
  • 卡点：电路拓扑以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过含运放有源网络的功能分析
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

5五、滞环两位置继电器特性分析（含图）#

思路
  • 画出含死区与回环的继电静特性，说明回环宽度决定切换阈值，再结合空调温控说明滞环带来的好处。
典型非线性特性及其影响 非线性系统
本卷考法
  • 滞环两位置继电器特性的静特性与作用
本卷实例
  • 关键一步：画出带死区与回环的继电静特性
  • 中间结果：回环宽度决定动作与释放的上下阈值
  • 卡点：滞环越宽切换越少但温度偏差越大
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 饱和特性降低等效增益，可能引起系统不稳定或自振
  • 死区特性使小信号时增益为零，产生稳态误差
  • 间隙特性引起相位滞后，导致波形畸变与自振
  • 继电特性使系统出现持续振荡并可能产生颤振
步骤
  • 识别非线性环节类型
  • 写出其描述函数或分段数学表达式
  • 分析其对等效增益与稳定性的影响
通用考法
  • 本卷考过滞环两位置继电器特性的静特性与作用
  • 分析饱和或死区对系统性能的影响
  • 求典型非线性的描述函数表达式
  • 说明间隙为何容易引起自振
常见易错
  • 认为饱和总是使系统更稳定
  • 忽略死区在原点附近造成的小信号失效
公式
非线性系统的特点 非线性系统
本卷考法
  • 继电特性作为本质非线性对系统的影响
本卷实例
  • 关键一步：先说明继电特性属不连续的本质非线性
  • 中间结果：输出在两个常值之间跳变产生极限环
  • 卡点：滞环特性与饱和特性别混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过继电特性作为本质非线性对系统的影响

  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由幅值稳定裕度求增益的取值范围
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

11十一、由阶跃响应曲线估计动态性能（含图）#

思路
  • 由响应曲线的稳态值定超调基准，读峰值与稳态值之差得超调量，再按正负5%误差带读调节时间与上升时间。
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阶跃响应曲线读动态性能指标
本卷实例
  • 关键一步：由曲线稳态值确定超调量的基准
  • 中间结果：峰值与稳态值之差比稳态值得超调量
  • 卡点：调节时间按正负5%误差带读
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阶跃响应曲线读动态性能指标
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
