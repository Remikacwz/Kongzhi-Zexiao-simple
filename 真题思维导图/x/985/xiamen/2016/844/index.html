1一、洗衣机快洗模式的开环与闭环控制举例10 分#

思路
  • 按是否检测被控量并据其调整动作区分开环与闭环，再在快洗过程里各找一个环节作例子并说明理由。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 以洗衣机快洗模式举例说明开环与闭环控制
本卷实例
  • 关键一步：按是否检测被控量并反馈来划分控制方式
  • 中间结果：开环按预设程序动作，闭环按检测结果调整
  • 卡点：两个例子要落到同一台洗衣机的具体环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过以洗衣机快洗模式举例说明开环与闭环控制
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

3三、根轨迹绘制与阻尼区间、临界阻尼特征根20 分#

思路
  • 画出三个开环极点的根轨迹并求渐近线、分离点与虚轴交点，再由分离点根轨迹增益划分阻尼状态并求临界阻尼时的三个根。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制三个开环极点的根轨迹草图
本卷实例
  • 关键一步：标出三个极点再判实轴根轨迹段
  • 中间结果：渐近线交点为极点之和除以极点数
  • 卡点：渐近线夹角按二k加一乘π除以极点数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制三个开环极点的根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求分离点坐标并舍去不在轨迹上的根
本卷实例
  • 关键一步：由重根条件写出分离点方程
  • 中间结果：整理成一元二次方程得两个候选坐标
  • 卡点：落在实轴轨迹段之外的根要舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求分离点坐标并舍去不在轨迹上的根
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点和临界根轨迹增益
本卷实例
  • 关键一步：把纯虚数代入闭环特征方程
  • 中间结果：实部虚部分别为零解出频率与增益
  • 卡点：交点增益对应稳定范围的端点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点和临界根轨迹增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由分离点增益划分过阻尼与欠阻尼区间
本卷实例
  • 关键一步：先求分离点处的根轨迹增益
  • 中间结果：增益小于分离点值时闭环根为两实根
  • 卡点：临界阻尼对应分离点处的重根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由分离点增益划分过阻尼与欠阻尼区间
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

5五、输入与扰动共同作用下的稳态误差估算（含图）15 分#

思路
  • 分别写出参考输入与扰动到误差的传函，阶跃输入用终值定理、正弦扰动用频率特性幅相法，两分量叠加得总误差。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 参考输入为阶跃时求稳态误差
本卷实例
  • 关键一步：按误差传函写E(s)再取极限
  • 中间结果：阶跃误差由误差传函直流增益决定
  • 卡点：参考输入的幅值系数别漏乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过参考输入为阶跃时求稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 扰动单独作用下的稳态误差
本卷实例

  • 中间结果：扰动误差由扰动处的传函在原点取值
  • 卡点：扰动传函与输入传函别混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过扰动单独作用下的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
