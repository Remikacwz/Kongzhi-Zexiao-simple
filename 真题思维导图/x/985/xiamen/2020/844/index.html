1一、由稳态精度指标确定增益与校正方式#

思路
  • 由最大输出速度与容许误差求速度误差系数下界得最小K，再求该K下稳定裕度并据此选校正方式。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由最大输出速度与位置误差求最小开环增益
本卷实例
  • 关键一步：按速度误差系数等于稳态速度比误差列式
  • 中间结果：先定使闭环稳定的增益范围再与误差要求取交
  • 卡点：误差要求只给下界，还要满足稳定上界
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由最大输出速度与位置误差求最小开环增益
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
稳定裕度 频域分析
本卷考法
  • 求该增益下的相角裕度与幅值裕度
本卷实例
  • 关键一步：由幅频与相频分别求截止频率和穿越频率
  • 中间结果：裕度由对应频率处的幅值相角折算
  • 卡点：相角裕度与幅值裕度对应的频率不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求该增益下的相角裕度与幅值裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
校正的基本概念与性能指标 系统校正
本卷考法
  • 判断应加入超前校正还是滞后校正
本卷实例
  • 关键一步：由相角裕度是否达标与截止频率要求判断
  • 中间结果：需提高相角裕度且截止频率可提高时选超前校正
  • 卡点：选滞后校正会降低截止频率，与动态要求冲突
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过判断应加入超前校正还是滞后校正
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求
公式

2二、二阶振荡环节幅频渐近线与真值之差#

思路
  • 把纯虚数代入二阶环节得真实对数幅频，再按渐近线在转折频率后的斜率写近似值，两者相减得差值。
典型环节的对数频率特性 频域分析
本卷考法
  • 求二阶振荡环节在指定频率处的真实对数幅频
本卷实例
  • 关键一步：把指定频率代入环节的幅频表达式
  • 中间结果：真实幅值由分母实部虚部的模值给出
  • 卡点：低频段幅值近似为一时谐振区误差最大
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例环节是水平线，积分与微分分别是 -20 与 +20 dB/dec 的斜线
  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec
  • 一阶微分环节与惯性环节幅频互为镜像
  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤
  • 把传递函数分解为典型环节乘积
  • 逐环节画出对数幅频渐近线与相频曲线
  • 代数相加得到总特性
通用考法
  • 本卷考过求二阶振荡环节在指定频率处的真实对数幅频
  • 画出某一典型环节的 Bode 图
  • 由 Bode 图识别环节类型
  • 说明转角频率处的幅值与相角
常见易错
  • 把惯性环节高频渐近线的 -20 写成 -40
  • 振荡环节谐振峰位置误当作 ωn
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 比较渐近线与真实对数幅频的差
本卷实例
  • 关键一步：按转折频率后斜率变化写渐近线幅值
  • 中间结果：差值等于渐近线分贝值减真实分贝值
  • 卡点：指定频率按自然频率的倍数取，别按转角频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过比较渐近线与真实对数幅频的差
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式

3三、根轨迹绘制与增益范围#

思路
  • 画三极点根轨迹求渐近线、分离点与虚轴交点，定稳定增益范围并由分离点与虚轴交点定欠阻尼增益区间。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制三极点系统的根轨迹草图
本卷实例
  • 关键一步：标出三个极点并判实轴根轨迹段
  • 中间结果：渐近线交点等于三个极点平均值
  • 卡点：渐近线夹角公式中的二k加一别写成二k
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制三极点系统的根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求分离点坐标并舍去无效解
本卷实例
  • 关键一步：按重根条件列分离点方程
  • 中间结果：解得的两个候选点按实轴根轨迹段取舍
  • 卡点：不在实轴根轨迹段上的根要舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求分离点坐标并舍去无效解
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及稳定增益上界
本卷实例
  • 关键一步：把纯虚数代入闭环特征方程分离实部虚部
  • 中间结果：虚部为零给交点频率，实部为零给临界增益
  • 卡点：零频率那组解要说明其含义
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及稳定增益上界
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由分离点与虚轴交点确定欠阻尼增益区间
本卷实例
  • 关键一步：分离点对应临界阻尼，虚轴交点对应零阻尼
  • 中间结果：欠阻尼对应这两点之间的根轨迹段
  • 卡点：换算成开环增益时要除以尾一型系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由分离点与虚轴交点确定欠阻尼增益区间
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式

4四、报警信号的死区滞环非线性（含图）#

思路
  • 由上下限报警阈值说明误差回升到较小值才解除报警，判断中间环节为带死区与滞环的继电特性并写描述函数。
典型非线性特性及其影响 非线性系统
本卷考法
  • 判断报警环节的非线性类型并画特性
本卷实例
  • 关键一步：按报警置位与复位阈值不同判断存在滞环
  • 中间结果：特性为带死区与回环的两位置继电特性
  • 卡点：置位与复位阈值差决定回环宽度
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 饱和特性降低等效增益，可能引起系统不稳定或自振
  • 死区特性使小信号时增益为零，产生稳态误差
  • 间隙特性引起相位滞后，导致波形畸变与自振
  • 继电特性使系统出现持续振荡并可能产生颤振
步骤
  • 识别非线性环节类型
  • 写出其描述函数或分段数学表达式
  • 分析其对等效增益与稳定性的影响
通用考法
  • 本卷考过判断报警环节的非线性类型并画特性
  • 分析饱和或死区对系统性能的影响
  • 求典型非线性的描述函数表达式
  • 说明间隙为何容易引起自振
常见易错
  • 认为饱和总是使系统更稳定
  • 忽略死区在原点附近造成的小信号失效
公式
描述函数法基础 非线性系统
本卷考法
  • 写出带死区滞环继电特性的描述函数
本卷实例
  • 关键一步：按输入幅值是否越过死区与回环写分段输出
  • 中间结果：描述函数由一次谐波幅值比输入幅值得到
  • 卡点：死区与回环两项要分别计入实部虚部
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过写出带死区滞环继电特性的描述函数
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件
公式

5五、由等幅振荡反求系统参数#

思路
  • 等幅振荡说明闭环有一对纯虚根，把纯虚根代入闭环特征方程令实部虚部分别为零，联立解参数。
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由等幅振荡条件反求传函参数
本卷实例
  • 关键一步：把已知振荡角频率对应的纯虚根代入特征方程
  • 中间结果：实部为零与虚部为零给出两个方程
  • 卡点：零频率解要单独排除，取非零振荡频率那组
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
