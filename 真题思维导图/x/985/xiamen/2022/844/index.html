1一、状态空间实现与参数化能控能观讨论15 分#

思路
  • 由结构图选状态变量写状态空间实现，再按参数k与a的取值讨论能控性与能观性成立条件
状态空间表达式的建立 状态空间分析
本卷考法
  • 由控制系统结构图建立状态空间实现
本卷实例
  • 关键一步：在积分器输出处取状态变量
  • 关键一步：按各环节系数写状态方程与输出方程
  • 中间结果：状态维数等于结构图中积分器个数
  • 卡点：结构图未读图，回路连接与增益需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由控制系统结构图建立状态空间实现
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式
能控性与能观性 状态空间分析
本卷考法
  • 含参数k与a时讨论系统能控性与能观性
本卷实例
  • 关键一步：构造能控性矩阵并求其行列式
  • 关键一步：对参数分类讨论行列式为零与不为零
  • 中间结果：k与a取某些值时矩阵降秩，系统不能控或不能观
  • 卡点：要分别给出能控与能观各自的参数条件，别混在一起
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过含参数k与a时讨论系统能控性与能观性
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

状态反馈与极点配置 状态空间分析
本卷考法
  • 用状态反馈配置极点为给定值求反馈增益
本卷实例
  • 关键一步：设反馈增益行向量并写闭环特征多项式
  • 关键一步：由期望极点展开期望特征多项式并与前者比较系数
  • 中间结果：比较s的同次幂系数得到三个增益方程
  • 卡点：未验证能控性就直接配置极点

  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)

通用考法

  • 分析状态反馈对系统性能的影响

3三、含纯延迟系统的延迟上界与奈氏判稳15 分#

思路
  • 由开环传函画奈氏图，求幅值为1且相角为-180度的临界状态，反求运行磨损参数的上界
含纯延迟环节的系统稳定性 稳定性分析
本卷考法
  • 估算含纯延迟环节系统可允许的延迟上界
本卷实例
  • 关键一步：把延迟环节相角与积分、惯性环节相角合并
  • 关键一步：令总相角为-180度求临界频率
  • 中间结果：延迟相角随频率线性增加，是稳定性的主要限制
  • 卡点：相角按度写、延迟相角含弧度，换算别混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 延迟环节 e^{-τs} 的幅值为 1、相位为 -τω，只恶化相位
  • 延迟会显著缩小稳定域，τ 越大越难稳定
  • 频域判据需用相位裕度扣除延迟引起的附加滞后
步骤
  • 写出含延迟的开环传递函数
  • 分别求幅值与相位表达式
  • 在相频特性中扣除 τω 的滞后量
  • 按稳定裕度或奈氏判据求临界 τ 或临界 K
通用考法
  • 本卷考过估算含纯延迟环节系统可允许的延迟上界
  • 求使系统稳定的最大延迟时间
  • 求含延迟系统的临界开环增益
  • 分析延迟对稳定裕度的影响
常见易错
  • 把延迟环节当成惯性环节处理
  • 相位计算时忘记角度与弧度换算
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据判断延迟变化时系统的稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数P
  • 关键一步：按幅相曲线对负一点的包围圈数判断稳定性
  • 中间结果：临界频率处幅值为1对应参数的临界值
  • 卡点：积分环节需补画无穷大圆弧，否则圈数会数错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据判断延迟变化时系统的稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式

4四、由稳态无差与极点实部要求设计控制器15 分#

思路
  • 用控制器零点对消对象不稳定极点并加积分环节保证稳态无差，再由闭环极点实部要求解增益范围
校正的基本概念与性能指标 系统校正
本卷考法
  • 按稳态无差与无持续振荡要求选定控制器结构
本卷实例
  • 关键一步：先看对象零极点，把不稳定部分对消
  • 关键一步：让开环含积分环节以满足阶跃无差
  • 中间结果：控制器取成比例乘零点再除自身极点，闭环降为二阶
  • 卡点：对消需知道对象零极点，结构图未读图要回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过按稳态无差与无持续振荡要求选定控制器结构
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由阶跃响应稳态无差确定系统所需型别
本卷实例
  • 关键一步：无差要求开环至少为I型
  • 关键一步：数开环原点处极点个数定型别
  • 中间结果：控制器加一个积分环节后系统满足型别要求
  • 卡点：型别看开环原点极点，别与闭环极点混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由阶跃响应稳态无差确定系统所需型别
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 按闭环极点实部约束反求增益取值范围
本卷实例
  • 关键一步：写闭环特征方程并解出两个闭环极点
  • 关键一步：令两个极点实部都满足给定上限并列不等式
  • 中间结果：约束把增益限制在一个区间内
  • 卡点：两根实部要同时满足，别只约束一个根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过按闭环极点实部约束反求增益取值范围
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

5五、由Bode图反求对象并设计控制器15 分#

思路
  • 由谐振峰值与低频段高度反求被控对象传函，再按穿越频率与相角裕度指标设计控制器
闭环频率特性与性能指标 频域分析
本卷考法
  • 由谐振峰值与谐振频率反求二阶对象参数
本卷实例
  • 关键一步：谐振峰值式定阻尼比，谐振频率定自然频率
  • 关键一步：低频段高度定对象增益
  • 中间结果：对象为欠阻尼二阶环节，谐振峰由阻尼比决定
  • 卡点：阻尼比大于0.707时无谐振峰，题给有峰说明阻尼比较小
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过由谐振峰值与谐振频率反求二阶对象参数
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈
公式
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由给出的频域特征反求被控对象传递函数
本卷实例
  • 关键一步：低频段高度按20lgK折算出增益
  • 关键一步：结合转折频率写出标准二阶形式
  • 中间结果：对象传函为增益除以标准二阶分母
  • 卡点：低频段高度要按分贝折算，别直接当增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由给出的频域特征反求被控对象传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
超前校正 系统校正
本卷考法
  • 设计控制器使穿越频率与相角裕度落入给定区间

稳定裕度 频域分析
本卷考法
  • 求校正前后截止频率与相角裕度并校验
本卷实例
  • 关键一步：由幅值为1求校正前截止频率与原相角裕度
  • 关键一步：设计后回代求新截止频率与新裕度
  • 中间结果：校正后截止频率提高、相角裕度增大
  • 卡点：题给截止频率是大于号，属可行区间不是等式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求校正前后截止频率与相角裕度并校验
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

本卷考法
  • 用梅森公式求环轮系统的闭环特征方程

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 每条前向通路的余子式要剔除与它接触的回路

步骤

  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输

  • 本卷考过用梅森公式求环轮系统的闭环特征方程

  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

  • 由极点位置估指标时忽略零点的作用
