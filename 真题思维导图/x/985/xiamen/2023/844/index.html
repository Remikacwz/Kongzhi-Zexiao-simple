思路

电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由含运算放大器的有源电路列写电路方程
本卷实例
  • 关键一步：用虚短虚断列节点电流关系
  • 关键一步：把电容电流写成电容乘电压导数
  • 中间结果：两个电容电压的导数与输入电压、另一电容电压有关
  • 卡点：电路拓扑未读图，运放输入输出接线需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由含运算放大器的有源电路列写电路方程
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错

  • 把反相输入的负号漏掉

2二、参数根轨迹与闭环零极点及动态性能20 分#

思路
  • 把反馈系数看作参变量写开环传函，分三种情况绘根轨迹，再代入具体值求闭环极点与动态性能
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以反馈系数为参变量绘制参数根轨迹
本卷实例
  • 关键一步：把特征方程整理成1加参变量乘某分式等于零的标准形式
  • 关键一步：再按相角条件绘制根轨迹
  • 中间结果：开环附加零点随参变量增大从无穷远向原点移动
  • 卡点：参变量出现在分子，参数根轨迹写法与常规增益根轨迹不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以反馈系数为参变量绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 分析参变量取不同值时附加零点对根轨迹形状的影响
本卷实例
  • 关键一步：比较三种取值下附加零点的位置
  • 关键一步：讨论实轴段、渐近线与分离点的变化
  • 中间结果：参变量在0与1之间时根轨迹为一段圆弧
  • 卡点：附加零点位置变化会改变实轴根轨迹段，别照搬常规结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过分析参变量取不同值时附加零点对根轨迹形状的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征方程求闭环极点并对照标准二阶形式
本卷实例
  • 关键一步：代入给定参数写闭环特征方程
  • 关键一步：由极点位置对照标准形式求阻尼比与自然频率
  • 中间结果：闭环无零点，可用标准二阶公式估算性能
  • 卡点：闭环零点与极点要分别对分子分母求，别只看分母
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征方程求闭环极点并对照标准二阶形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率估算超调量与调节时间
本卷实例
  • 关键一步：用超调量公式代入阻尼比
  • 关键一步：按给定误差带选调节时间系数
  • 中间结果：阻尼比接近1时超调量很小
  • 卡点：两种误差带的调节时间系数容易取混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率估算超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3三、由Bode图反求校正后传函与校正前后裕度15 分#

思路
  • 由校正后Bode图写开环传函，再由超调量与速度误差反求期望开环，两者相除得校正装置
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由校正后开环对数幅频特性写开环传函
本卷实例
  • 关键一步：读低频段高度定型别与增益
  • 关键一步：按各转折频率的斜率变化写典型环节
  • 中间结果：某一频率处幅值为1的条件给出静态增益
  • 卡点：幅频曲线未读图，转折频率需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由校正后开环对数幅频特性写开环传函
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位速度误差反求阻尼比与自然频率的关系
本卷实例
  • 关键一步：写速度误差系数与开环增益的关系
  • 关键一步：把误差指标代入联立求参数
  • 中间结果：二阶系统的速度误差系数与阻尼比成反比
  • 卡点：误差系数对应开环而非闭环
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差

期望特性法与综合法 系统校正
本卷考法
  • 由校正后与期望开环传函相除求校正装置
本卷实例
  • 关键一步：分别写校正后开环与期望二阶开环传函
  • 关键一步：两者相除约分得校正装置传函
  • 中间结果：校正装置含一个积分环节与若干一阶环节
  • 卡点：约分后要核对所得环节是否物理可实现
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 期望特性法直接按指标画出希望的开环对数幅频特性
  • 用期望特性减去未校正特性得到校正装置特性
  • 关键是确定低频段高度、中频段宽度与高频段斜率
  • 中频段斜率一般取 -20 dB/dec 并保持足够宽度
步骤
  • 按稳态要求确定低频段斜率与高度
  • 按相角裕度要求确定中频段宽度与截止频率
  • 按抗噪要求确定高频段斜率
  • 相减求得校正装置并检验可实现性
通用考法
  • 本卷考过由校正后与期望开环传函相除求校正装置
  • 用期望特性法设计校正装置
  • 说明中频段宽度与相角裕度的关系
  • 由校正装置特性反写传递函数
常见易错
  • 期望特性的中频段取窄导致裕度不足
  • 相减后得到的特性不可物理实现却未检查
公式
稳定裕度 频域分析
本卷考法
  • 分别计算校正前后系统的相角裕度
本卷实例
  • 关键一步：求各自幅值为1的截止频率
  • 关键一步：代入相频表达式求相角裕度
  • 中间结果：校正后相角裕度明显提高
  • 卡点：两套传函要各用各的频率，别混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过分别计算校正前后系统的相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

4四、由Bode图与性能指标设计PID串联校正15 分#

思路
  • 由校正前Bode图写开环传函并求截止频率与相角裕度，再按期望二阶指标反求PID参数
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由校正前对数幅频特性写开环传函
本卷实例
  • 关键一步：读转折频率与斜率变化
  • 关键一步：用某点幅值为1定增益
  • 中间结果：开环含一个积分环节与三个惯性环节
  • 卡点：幅频曲线未读图，转折频率需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
