2二、含复数零点系统的根轨迹与稳定域#

思路
  • 由开环零极点定分支数与实轴段，按渐近线、出射角与入射角绘制根轨迹，再把纯虚根代入特征方程求虚轴交点与临界增益，从而确定稳定域
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制含一对共轭复零点的参数根轨迹
本卷实例
  • 关键一步：由开环零点与极点定分支数与实轴上的根轨迹段
  • 中间结果：极点数为三零点数为二，有一条轨迹趋于无穷远
  • 卡点：渐近线夹角与交点要按剩余零极点个数计算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤

  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法

  • 判断某段实轴是否属于根轨迹

  • 实轴段判据中的零极点个数算错

3三、最大相角裕度与滞后校正设计#

思路
  • 把相角写成一个反正切函数求极值得最大裕度对应的频率与增益，再用滞后网络抬高低频增益以减小扰动引起的误差，同时保持剪切频率与相角裕度基本不变
稳定裕度 频域分析
本卷考法
  • 求使相角裕度最大的开环增益并给出该裕度
本卷实例
  • 关键一步：把相角写成一个反正切函数并求其极值条件
  • 中间结果：反正切函数取极值的条件是分子中的频率因子相等
  • 卡点：最大相角裕度处的频率要通过幅频等于一定出增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求使相角裕度最大的开环增益并给出该裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过把ωc与ωg两个频率用反
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

要点
  • 逻辑函数化简可用公式法也可用卡诺图法，卡诺图更适合带约束项的情形
  • 约束项在卡诺图中记为叉，能圈就圈进圈里以取得更大的圈
  • 圈越大项越少，每圈包含的方格数为二的整数次幂
  • 无关项与任意项不产生新的圈，只用来帮助扩大已有的圈

  • 每圈消去取值发生变化的变量，只保留取值不变的变量
