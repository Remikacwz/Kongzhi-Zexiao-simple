一数电一、或与式化简与 555 与 TTL 电压20 分#

思路
  • 三小问各自独立：第一问把逻辑函数与约束条件填卡诺图化最简或与式；第二问说明 555 内部电路所构成电路的功能，并按输入波形画输出波形；第三问按 TTL 门电压传输特性与输入端负载特性判断两种输入组合下 M 点与输出 Y 的电压。
逻辑代数与卡诺图化简 数字逻辑与数字电路
本卷考法
  • 含约束条件的逻辑函数化为最简或与式
本卷实例
  • 关键一步：把约束条件展开为哪些格填叉，再按零格圈最简或与式
  • 中间结果：或与式由若干最大项相与得到，圈的是输出为零的格
  • 卡点：题目要最简或与式而非与或式，圈零还是圈一要看清
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 逻辑函数化简可用公式法也可用卡诺图法，卡诺图更适合带约束项的情形
  • 约束项在卡诺图中记为叉，能圈就圈进圈里以取得更大的圈
  • 圈越大项越少，每圈包含的方格数为二的整数次幂
  • 无关项与任意项不产生新的圈，只用来帮助扩大已有的圈
步骤
  • 把逻辑函数按最小项填入卡诺图，约束条件对应的格填成叉
  • 按二、四、八格成圈，圈内至少含一个未被圈过的一，圈可以重叠
  • 每圈消去取值发生变化的变量，只保留取值不变的变量
  • 把所有圈对应的乘积项或起来得到最简与或式
通用考法
  • 本卷考过含约束条件的逻辑函数化为最简或与式
  • 用卡诺图求最简与或表达式
  • 含约束条件的逻辑函数化简
  • 由最简式反推需要几个门电路
常见易错
  • 本卷考过圈出最简与或式后未按德摩根转成或与式
  • 把约束项当成必须为 1 的项，或漏圈可以用约束项扩大的圈
  • 圈数为二的整数次幂以外的方格数
公式
脉冲波形产生与整形 数字逻辑与数字电路
本卷考法
  • 说明 555 接成电路的功能并按输入画输出波形
本卷实例
  • 关键一步：按两比较器阈值判断输出翻转，再逐步对照输入波形
  • 中间结果：输出波形为整幅脉冲，翻转时刻由两比较器阈值定
  • 卡点：555 内部电路与输入波形以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 555 定时器可用作多谐振荡器、单稳态触发器与施密特触发器
  • 多谐振荡器的输出周期由两个外接电阻与电容决定
  • 单稳态触发器的输出脉宽只与一个外接电阻电容有关
  • 周期矩形波的幅值、周期与占空比是描述它的三个参数
步骤
  • 先判断电路接法是振荡、单稳还是施密特
  • 按接法写出充放电时间常数与相应的时间表达式
  • 代入外部元件参数算出周期或脉宽
  • 由电路结构说明输出波形的功能
通用考法
  • 本卷考过说明 555 接成电路的功能并按输入画输出波形
  • 计算输出脉冲的宽度或振荡周期
  • 说明给定接法的电路功能
  • 由要求脉宽反求外接元件参数
常见易错
  • 本卷考过把施密特触发与单稳触发功能混为一谈
  • 振荡周期与单稳脉宽的公式混用
  • 电容充放电回路看错，导致时间常数少算或多算一个电阻

组合逻辑电路设计 数字逻辑与数字电路
本卷考法
  • 由 TTL 门电压传输与输入负载特性判断各点电压
本卷实例
  • 关键一步：按输入端电流在电阻上的压降定该端电平，再查传输特性定输出
  • 中间结果：电压表内阻与门输入电阻共同决定 M 点实测电压
  • 卡点：电压传输与负载特性曲线以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 组合逻辑的输出只由当前输入决定，不含记忆元件
  • 设计流程是列真值表、写表达式、化简、再映射到给定器件
  • 用译码器或数据选择器实现时，输出写成最小项之和的形式最方便
  • 全加器要考虑低位来的进位，全减器要考虑低位来的借位
步骤
  • 按功能描述列真值表，输入输出个数要与题意一致
  • 写出每个输出的最小项表达式并化简
  • 把表达式改写成给定器件（译码器、数据选择器、与非门）能直接实现的形式
  • 按器件引脚特性追加必要的门电路并把输入端接好
通用考法
  • 本卷考过由 TTL 门电压传输与输入负载特性判断各点电压
  • 用译码器或数据选择器加适当门电路设计指定逻辑功能
  • 仅用与非门实现给定逻辑功能
  • 设计一位全加或全减器
常见易错
  • 本卷考过把悬空端或经电阻接地的端当成固定低电平
  • 控制信号取 0 与取 1 对应的加与减搞反
  • 接器件时忘记译码器的输出是低有效

二数电二、JK 触发器画波形与功能10 分#

思路

触发器与波形分析 数字逻辑与数字电路
本卷考法
  • 由 JK 触发器电路与时钟波形画输出波形
本卷实例
  • 关键一步：先写各 JK 激励方程，再按特性方程逐拍定次态
  • 中间结果：各级状态在时钟边沿同时更新，输出由状态组合得到
  • 卡点：触发器电路与时钟波形以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 触发器具有记忆功能，输出不仅与输入有关还与当前状态有关
  • JK 触发器在 J 与 K 同时为一时翻转，同时为零时保持
  • 边沿触发器的状态只在时钟有效边沿改变，画波形要盯住边沿
  • 不同触发器的特性方程可以互相转换
步骤
  • 写出所用触发器的特性方程
  • 按题意列出激励信号在各时钟周期的取值
  • 逐拍代入特性方程求出状态序列
  • 把状态序列画成波形，注意触发边沿与传输延迟
通用考法
  • 本卷考过由 JK 触发器电路与时钟波形画输出波形
  • 由时钟与激励波形画出输出波形
  • 判断触发器构成的电路功能
  • 由特性方程推导状态转移关系
常见易错
  • 本卷考过把电平触发与边沿触发混用，波形画错位置
  • 把电平触发与边沿触发混为一谈，波形画错位置
  • 忘记 JK 触发器同时置位时的翻转功能
