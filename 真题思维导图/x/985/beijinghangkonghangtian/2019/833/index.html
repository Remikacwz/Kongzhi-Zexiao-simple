1一、机械系统动态方程、结构图与传递函数15 分#

思路
  • 先对两个小车分别列牛顿定律写动态方程，再消元画出系统结构图，最后由结构图用梅森公式求输出对输入的传递函数。
机械系统建模 建模与机电系统
本卷考法
  • 题一1对小车-弹簧-阻尼系统列写动态方程
本卷实例
  • 关键一步：分别对两个小车列牛顿第二定律方程
  • 中间结果：消去中间位移得含输出的动态方程
  • 卡点：系统参数与受力以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数

  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 本卷考过弹簧力与阻尼力的正负方向取反，或漏相互作用项
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项

2二、根轨迹与二阶近似传递函数15 分#

思路
  • 先按根轨迹法则画出三阶系统轨迹并定分离点，再在已知一个闭环极点时作二阶近似，最后用近似模型估算调节时间并判断超调。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 题二1绘制给定三阶开环的闭环根轨迹
本卷实例
  • 关键一步：标三个开环极点并判实轴上的根轨迹段
  • 中间结果：按法则画渐近线与轨迹走向
  • 卡点：分离点位置需结合计算确定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过题二1绘制给定三阶开环的闭环根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴段判据算错，或渐近线交点与倾角写错
  • 实轴段判据中的零极点个数算错

思路

开环对数频率特性的绘制 频域分析
本卷考法
  • 题三1画开环对数渐近幅频特性并求截止频率
本卷实例
  • 关键一步：把开环化为标准时间常数形式并定型别

  • 卡点：转角频率与斜率需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线

稳定裕度 频域分析
本卷考法
  • 题三1由相频特性求相稳定裕度γ
本卷实例
  • 关键一步：在幅频特性上求截止频率
  • 中间结果：代入相频特性求相稳定裕度
  • 卡点：读数精度受特性曲线限制
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过题三1由相频特性求相稳定裕度γ
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过把截止频率与相位穿越频率混用
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

  • 组合逻辑的输出只由当前输入决定，不含记忆元件
  • 设计流程是列真值表、写表达式、化简、再映射到给定器件
  • 用译码器或数据选择器实现时，输出写成最小项之和的形式最方便
  • 全加器要考虑低位来的进位，全减器要考虑低位来的借位
步骤
  • 按功能描述列真值表，输入输出个数要与题意一致
  • 写出每个输出的最小项表达式并化简
  • 把表达式改写成给定器件（译码器、数据选择器、与非门）能直接实现的形式
  • 按器件引脚特性追加必要的门电路并把输入端接好
通用考法
  • 本卷考过题九用74LS283与门电路设计一位8421BCD码十进制加法器
  • 用译码器或数据选择器加适当门电路设计指定逻辑功能
  • 仅用与非门实现给定逻辑功能
  • 设计一位全加或全减器
常见易错
  • 本卷考过未判和是否超过9就直接输出，或加6修正条件写错
  • 控制信号取 0 与取 1 对应的加与减搞反
  • 接器件时忘记译码器的输出是低有效

思路
  • 把通行周期按 10 秒、20 秒、30 秒分段抽象为计数状态，用 74LS161 计数、74LS151 与 74LS175 产生并寄存行人绿灯控制信号。
时序逻辑与计数器 数字逻辑与数字电路
本卷考法
  • 题十用74LS161、74LS151与74LS175设计行人绿灯1的控制电路
本卷实例
  • 关键一步：按10秒、20秒、30秒分段定计数状态
  • 中间结果：用计数器与数据选择器产生绿灯时序
  • 卡点：寄存器状态在周期内须保持，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 时序逻辑的输出由当前输入与电路当前状态共同决定
  • 计数器有同步与异步、加法与减法、二进制与十进制之分
  • 集成计数器可通过置数或清零端改接成任意模数计数器
  • 状态图、状态表与波形图是描述时序电路的三件套
步骤
  • 由电路连接写出各触发器的驱动方程与时钟方程
  • 代入触发器特性方程得到状态方程
  • 列出状态表或状态图，确定电路的计数规律与模数
  • 需要变形时用置数端或清零端把某个状态反馈接回，得到目标模数
通用考法
  • 本卷考过题十用74LS161、74LS151与74LS175设计行人绿灯1的控制电路
  • 分析给定电路的计数规律与模数
  • 用集成计数器设计指定模数的计数器
  • 画出加减计数器的输出波形
常见易错
  • 本卷考过一周期的时序分段与计数值对应错，或按钮信号未锁存
  • 异步清零与同步置数的反馈状态取错
  • 把模数与触发器个数直接等同，忽略反馈接线的作用
