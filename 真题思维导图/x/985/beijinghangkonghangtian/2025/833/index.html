1一、系统结构图与二阶系统参数设计#

思路
  • 由结构图写出闭环传递函数，与标准二阶形式比对，按给定的自然频率与阻尼比解出两个可调参数，再算调节时间并写出超调量计算式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函比对标准二阶形式求自然频率与阻尼比
本卷实例
  • 关键一步：先把闭环传递函数整理成首一标准二阶形式，把分母的平方项系数归一化
  • 关键一步：让一次项系数与常数项分别对应二倍阻尼比乘自然频率与自然频率的平方
  • 关键一步：两个方程两个未知参数，联立即可解出两个可调增益
  • 中间结果：闭环特征式的一次项系数同时含两个参数，常数项只含其中一个参数
  • 卡点：系统结构图未读图，题图中各环节增益与反馈系数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函比对标准二阶形式求自然频率与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 按给定自然频率与阻尼比要求反求两个可调参数
本卷实例
  • 关键一步：把给定的自然频率与阻尼比代入标准形式，得到关于两个参数的方程组
  • 关键一步：解出参数后回代检查闭环极点是否落在要求的等阻尼线上
  • 中间结果：自然频率要求只约束常数项，阻尼比要求同时用到一次项
  • 卡点：只满足自然频率就取值，没有同时满足阻尼比
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过按给定自然频率与阻尼比要求反求两个可调参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 计算二阶系统调节时间并写出超调量计算式
本卷实例
  • 关键一步：调节时间在百分之二误差带下按 4.4 除以阻尼比乘自然频率估算
  • 关键一步：超调量只用阻尼比，按负指数形式的百分数计算式写出
  • 关键一步：题给参考数据是指数为负的圆周率除以根号三的指数值，按表达式直接代入
  • 中间结果：阻尼比取零点五时，超调量指数里的根号一减阻尼比平方与题给数据对应
  • 卡点：百分之二与百分之五误差带的系数容易取混；超调量计算式漏乘百分号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过计算二阶系统调节时间并写出超调量计算式
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

2二、含复数零点系统的根轨迹与稳定域#

思路
  • 标出开环零极点按绘制法则画根轨迹，再用劳斯判据求根轨迹与虚轴的交点，从而确定系统稳定时的增益范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画出含复数零点的根轨迹
本卷实例
  • 关键一步：开环有三个重极点位于原点，三个零点中含一对共轭复零点与一个实零点
  • 关键一步：极点数与零点数相等，分支数等于极点数且没有无穷远渐近线
  • 关键一步：实轴段按该段右侧零极点总数为奇数判断，分离点由增益对复变量的导数为零求
  • 中间结果：分离点方程出现原点处的重根，另有共轭复根要按实轴段判据剔除
  • 卡点：极点数等于零点数时不要画渐近线；复数零点位置需回原卷核对题面
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画出含复数零点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点并确定稳定增益范围
本卷实例
  • 关键一步：写出闭环特征方程，列劳斯表并令首列出现零元素求临界增益
  • 关键一步：由临界增益对应的辅助方程解出纯虚根频率，得到虚轴交点
  • 关键一步：比较临界增益两侧劳斯表首列符号，确定稳定区间在临界值之上还是之下
  • 中间结果：劳斯表首列含增益的二次因子，令它为零即得临界增益
  • 卡点：只代一个频率会漏掉另一组交点；求出临界增益后要回到原题核对增益定义
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点并确定稳定增益范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

3三、非线性系统的相平面分析与描述函数法适用性#

思路
  • 由非线性环节特性写分段线性二阶方程，用解析法求相轨迹并由对称性算运动周期；再判断描述函数法的低通滤波前提是否成立
相平面法 非线性系统
本卷考法
  • 作给定初始条件下的相轨迹并计算运动周期
本卷实例
  • 关键一步：把非线性特性按误差符号分段，写出各区域以误差及其导数为变量的二阶方程
  • 关键一步：用导数乘导数的微分关系把方程化为可分离形式，积分得到各区域的相轨迹二次曲线
  • 关键一步：相轨迹关于坐标原点对称，运动周期等于单段穿越时间的四倍
  • 中间结果：各区域相轨迹是不同类型的二次曲线，开关线上的接点由分段方程对接确定
  • 卡点：非线性特性与系统结构未读图，开关线形状与初始点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过作给定初始条件下的相轨迹并计算运动周期
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆
公式
用描述函数法分析自振 非线性系统
本卷考法
  • 判断描述函数法是否适用于本题系统
本卷实例
  • 关键一步：描述函数法成立的前提是线性部分具有低通滤波特性，能滤掉高次谐波
  • 关键一步：本题线性部分为无阻尼振荡环节，极点位于虚轴，不衰减高次谐波
  • 关键一步：前提不满足时应指出该方法失效，不用负倒描述函数与幅相曲线的交点评判自振
  • 中间结果：线性部分相频在固有频率处发生跳跃，负倒描述函数曲线与其交点的分析不再成立
  • 卡点：若强行套用描述函数法会得出与相平面法互相矛盾的结论，应以适用条件判断为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过判断描述函数法是否适用于本题系统
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率

4四、奈奎斯特判据、幅值裕度与滞后校正#

思路
  • 先画奈氏曲线由包围关系定稳定增益范围，再按幅值裕度要求反求增益，用渐近幅频求穿越频率，最后在增益加倍时用滞后校正把穿越频率拉回
奈奎斯特判据 稳定性分析
本卷考法
  • 画奈氏曲线并由包围关系求稳定增益范围
本卷实例
  • 关键一步：先数开环右半平面极点数得到 P，本题开环极点都在左半平面或原点
  • 关键一步：含一个积分环节，需补画无穷大半径圆弧把起点与原点侧连接
  • 关键一步：令相角为负一百八十度求曲线与负实轴交点，由该点与临界点的相对位置定稳定范围
  • 中间结果：曲线与负实轴交点的幅值随增益线性变化，临界增益由交点落到临界点确定
  • 卡点：积分环节补圆弧的方向容易画错；没有先数 P 就直接判稳
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过画奈氏曲线并由包围关系求稳定增益范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
稳定裕度 频域分析
本卷考法
  • 由幅值裕度要求反求开环增益
本卷实例
  • 关键一步：相位穿越频率由各环节相角之和为负一百八十度解出，与增益无关
  • 关键一步：在该频率处取幅频的倒数得到幅值裕度，按题目要求的倍数建立方程
  • 关键一步：解方程得到增益，并回代检查是否仍在稳定范围内
  • 中间结果：本题幅值裕度以倍数给出，不必再换算成分贝
  • 卡点：幅值裕度取倒数写反；把相位穿越频率与幅值穿越频率混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由幅值裕度要求反求开环增益
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 用渐近幅频求幅值穿越频率

思路
  • 按四进制减一计数列出状态循环与状态转换表，由 JK 触发器特性方程求各触发器的 J、K 激励方程和状态方程，再补上借位输出并画电路。
时序逻辑与计数器 数字逻辑与数字电路
本卷考法
  • 用JK触发器设计带借位输出的四进制减一计数器
本卷实例
  • 关键一步：先按减一计数排出四进制状态循环，再由状态转换表求各触发器的翻转条件
  • 关键一步：把翻转条件与JK特性方程比对得到激励方程，并写出借位输出逻辑
  • 中间结果：源文答案给出的状态循环为00、11、10、01再回到00
  • 卡点：题面写的带错位输出应为借位输出；电路图需回原卷核对触发器与门级接线

触发器与波形分析 数字逻辑与数字电路
本卷考法
  • 由状态转换表求JK触发器的激励方程与状态方程
