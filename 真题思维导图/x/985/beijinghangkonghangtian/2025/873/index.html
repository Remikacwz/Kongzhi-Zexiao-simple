数电一数电一、卡诺图化简与四小问#

思路
  • 一道大题含四个独立小问。第一问把给定最小项与约束项一起填入卡诺图，圈出最简与或式；第二问从逻辑图逐级写中间变量并化简，必要时列真值表复核；第三问按 CB555 外接阈值电压写电容从零充电到阈值的时间并判断功能；第四问按 s 电平判可逆计数器的加减方向，再画出状态经数模转换后的阶梯波形。
逻辑代数与卡诺图化简 数字逻辑与数字电路
本卷考法
  • 含约束条件的卡诺图化简
本卷实例
  • 关键一步：把给定最小项填一，约束条件对应的方格填叉号，再按二四八格成圈
  • 中间结果：四个角上的四个一可圈成一个四格圈，另一对相邻一组成两格圈
  • 卡点：约束条件含两项乘积式，哪些格是叉号要逐项展开核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 逻辑函数化简可用公式法也可用卡诺图法，卡诺图更适合带约束项的情形
  • 约束项在卡诺图中记为叉，能圈就圈进圈里以取得更大的圈
  • 圈越大项越少，每圈包含的方格数为二的整数次幂
  • 无关项与任意项不产生新的圈，只用来帮助扩大已有的圈
步骤
  • 把逻辑函数按最小项填入卡诺图，约束条件对应的格填成叉
  • 按二、四、八格成圈，圈内至少含一个未被圈过的一，圈可以重叠
  • 每圈消去取值发生变化的变量，只保留取值不变的变量
  • 把所有圈对应的乘积项或起来得到最简与或式
通用考法
  • 本卷考过含约束条件的卡诺图化简
  • 用卡诺图求最简与或表达式
  • 含约束条件的逻辑函数化简
  • 由最简式反推需要几个门电路
常见易错
  • 把约束项当成必须为 1 的项，或漏圈可以用约束项扩大的圈
  • 圈数为二的整数次幂以外的方格数

本卷考法

  • 卡点：逻辑图未读图，门的类型与反号位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 设计流程是列真值表、写表达式、化简、再映射到给定器件

  • 写出每个输出的最小项表达式并化简

  • 按器件引脚特性追加必要的门电路并把输入端接好
通用考法

脉冲波形产生与整形 数字逻辑与数字电路
本卷考法
  • 由阈值电压求 CB555 单稳正向脉宽与功能
本卷实例
  • 关键一步：阈值电压低于电源电压，按电容从零充电到阈值的时间写正向脉宽
  • 中间结果：脉宽等于时间常数乘 ln2，时间常数由 100 千欧与 1 微法给出
  • 卡点：题面另给 7500ms，与按元件值算出的脉宽不同量级，含义需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 555 定时器可用作多谐振荡器、单稳态触发器与施密特触发器
  • 多谐振荡器的输出周期由两个外接电阻与电容决定
  • 单稳态触发器的输出脉宽只与一个外接电阻电容有关
  • 周期矩形波的幅值、周期与占空比是描述它的三个参数
步骤
  • 先判断电路接法是振荡、单稳还是施密特
  • 按接法写出充放电时间常数与相应的时间表达式
  • 代入外部元件参数算出周期或脉宽
  • 由电路结构说明输出波形的功能
通用考法
  • 本卷考过由阈值电压求 CB555 单稳正向脉宽与功能
  • 计算输出脉冲的宽度或振荡周期
  • 说明给定接法的电路功能
  • 由要求脉宽反求外接元件参数
常见易错
  • 振荡周期与单稳脉宽的公式混用
  • 电容充放电回路看错，导致时间常数少算或多算一个电阻

数模与模数转换器 数字逻辑与数字电路
本卷考法
  • 计数器输出经数模转换得到阶梯波
本卷实例
  • 关键一步：把两位状态按位权换成模拟电压，状态每变一次输出跳一个台阶
  • 中间结果：相邻台阶相差 2.5 伏，输出随加减计数先升后降
  • 卡点：答案中数模转换表达式残缺，位数与参考电压及波形需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 数模转换的分辨率由位数决定，位数越多最小输出电压越小
  • 转换误差有量化误差、失调误差与增益误差之分
  • 模数转换要经过采样、保持、量化与编码四个环节
  • 转换时间与分辨率互相制约，速度与精度需要折衷
步骤
  • 由位数与满量程算出最小输出增量即分辨率
  • 按绝对误差要求校核位数是否足够
  • 写出理想输出与实际输出的偏差表达式，判断属于哪类误差
  • 需要时可加上失调与增益的补偿措施
通用考法
  • 本卷考过计数器输出经数模转换得到阶梯波
  • 由位数与满量程求分辨率与量化误差
  • 由精度要求反推所需位数
  • 说明各类转换误差的来源与补偿办法
常见易错
  • 分辨率的分母写成二的位数次幂而漏减一
  • 把量化误差写成分辨率本身而不是它的二分之一

数电二数电二、D 触发器波形#

思路
  • 由触发器连接写出各 D 端表达式，逐拍按次态等于 D 求状态转移表，再按时钟节拍把两级状态与输出画成波形。
触发器与波形分析 数字逻辑与数字电路
本卷考法
  • 写 D 触发器激励方程并逐拍求次态
本卷实例
  • 关键一步：写出各 D 端表达式，按次态等于 D 的关系逐拍代入
  • 中间结果：一级 D 端取另一级状态的反，二级 D 端取两级状态的同或
  • 卡点：题面波形名疑为 Q1、Q2 的 OCR 误读，需回原卷核对电路图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 触发器具有记忆功能，输出不仅与输入有关还与当前状态有关
  • JK 触发器在 J 与 K 同时为一时翻转，同时为零时保持
  • 边沿触发器的状态只在时钟有效边沿改变，画波形要盯住边沿
  • 不同触发器的特性方程可以互相转换
步骤
  • 写出所用触发器的特性方程
  • 按题意列出激励信号在各时钟周期的取值
  • 逐拍代入特性方程求出状态序列
  • 把状态序列画成波形，注意触发边沿与传输延迟
通用考法
  • 本卷考过写 D 触发器激励方程并逐拍求次态
  • 由时钟与激励波形画出输出波形
  • 判断触发器构成的电路功能
  • 由特性方程推导状态转移关系
常见易错
  • 把电平触发与边沿触发混为一谈，波形画错位置
  • 忘记 JK 触发器同时置位时的翻转功能
