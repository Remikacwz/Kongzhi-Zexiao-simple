思路
  • G=K(0.4s+1) 除以 s 乘 (s+1) 平方，含一个积分环节，补画无穷大圆弧后按包围临界点圈数判断稳定 K 范围
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据确定使闭环稳定的增益范围
本卷实例
  • 关键一步：补画无穷大圆弧后数曲线包围临界点的圈数
  • 中间结果：开环无右半平面极点时包围圈数为零即稳定
  • 卡点：起点相角由积分环节个数决定，不要画错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤

  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性

  • 由状态表设计四相步进电机驱动逻辑电路
本卷实例
  • 关键一步：把两表按控制信号合成后化简出各相逻辑
  • 中间结果：每相输出由现态与控制信号组合得到
  • 卡点：正反转状态表以表给出，需回原卷核对两表
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 组合逻辑的输出只由当前输入决定，不含记忆元件
  • 设计流程是列真值表、写表达式、化简、再映射到给定器件
  • 用译码器或数据选择器实现时，输出写成最小项之和的形式最方便
  • 全加器要考虑低位来的进位，全减器要考虑低位来的借位
步骤
  • 按功能描述列真值表，输入输出个数要与题意一致
  • 写出每个输出的最小项表达式并化简
  • 把表达式改写成给定器件（译码器、数据选择器、与非门）能直接实现的形式
  • 按器件引脚特性追加必要的门电路并把输入端接好
通用考法
  • 本卷考过由状态表设计四相步进电机驱动逻辑电路
  • 用译码器或数据选择器加适当门电路设计指定逻辑功能
  • 仅用与非门实现给定逻辑功能
  • 设计一位全加或全减器
常见易错
  • 本卷考过控制信号取零与取一对应的转向搞反
  • 控制信号取 0 与取 1 对应的加与减搞反
  • 接器件时忘记译码器的输出是低有效

脉冲波形产生与整形 数字逻辑与数字电路
本卷考法
  • 说明 555 定时器构成多谐振荡器时如何调节振荡周期
本卷实例
  • 关键一步：把 555 接成多谐振荡器由充放电回路定周期
  • 中间结果：输出脉冲频率由外接电阻电容决定
  • 卡点：调外接电阻或电容改变频率以改进给速度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 555 定时器可用作多谐振荡器、单稳态触发器与施密特触发器
  • 多谐振荡器的输出周期由两个外接电阻与电容决定
  • 单稳态触发器的输出脉宽只与一个外接电阻电容有关
  • 周期矩形波的幅值、周期与占空比是描述它的三个参数
步骤
  • 先判断电路接法是振荡、单稳还是施密特
  • 按接法写出充放电时间常数与相应的时间表达式
  • 代入外部元件参数算出周期或脉宽
  • 由电路结构说明输出波形的功能
通用考法
  • 本卷考过说明 555 定时器构成多谐振荡器时如何调节振荡周期
  • 计算输出脉冲的宽度或振荡周期
  • 说明给定接法的电路功能
  • 由要求脉宽反求外接元件参数
常见易错
  • 本卷考过振荡周期与单稳脉宽的公式混用
  • 振荡周期与单稳脉宽的公式混用
  • 电容充放电回路看错，导致时间常数少算或多算一个电阻

时序逻辑与计数器 数字逻辑与数字电路
本卷考法
  • 按四相顺序切换设计可循环的驱动时序
本卷实例
  • 关键一步：按四相顺序排列状态并用逻辑器件产生各相
  • 中间结果：四个状态循环一周完成一个步距序列
  • 卡点：顺时针与逆时针的状态排列方向相反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 时序逻辑的输出由当前输入与电路当前状态共同决定
  • 计数器有同步与异步、加法与减法、二进制与十进制之分
  • 集成计数器可通过置数或清零端改接成任意模数计数器
  • 状态图、状态表与波形图是描述时序电路的三件套
步骤
  • 由电路连接写出各触发器的驱动方程与时钟方程
  • 代入触发器特性方程得到状态方程
  • 列出状态表或状态图，确定电路的计数规律与模数
  • 需要变形时用置数端或清零端把某个状态反馈接回，得到目标模数
通用考法
  • 本卷考过按四相顺序切换设计可循环的驱动时序
  • 分析给定电路的计数规律与模数
  • 用集成计数器设计指定模数的计数器
  • 画出加减计数器的输出波形
常见易错
  • 本卷考过把模数与触发器个数直接等同
  • 异步清零与同步置数的反馈状态取错
  • 把模数与触发器个数直接等同，忽略反馈接线的作用
