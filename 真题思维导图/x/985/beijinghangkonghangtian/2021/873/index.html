一数电一、卡诺图与门电路与 55520 分#

思路
  • 三小问各自独立：第一问把最小项与约束项一起填入四变量卡诺图圈出最简与或式；第二问从 TTL 门电路逐级写中间变量再化简；第三问按 555 外接阈值电压说明功能并写振荡周期与占空比表达式。
逻辑代数与卡诺图化简 数字逻辑与数字电路
本卷考法
  • 含约束项的逻辑函数卡诺图化简
本卷实例
  • 关键一步：把最小项填一、约束项填叉，再按二四八格成圈
  • 中间结果：按格雷码排四变量表，圈出的乘积项再并成最简与或式
  • 卡点：真值表按两半 AB 与 CD 分组给出，填图时行列次序容易串位
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 逻辑函数化简可用公式法也可用卡诺图法，卡诺图更适合带约束项的情形
  • 约束项在卡诺图中记为叉，能圈就圈进圈里以取得更大的圈
  • 圈越大项越少，每圈包含的方格数为二的整数次幂
  • 无关项与任意项不产生新的圈，只用来帮助扩大已有的圈
步骤
  • 把逻辑函数按最小项填入卡诺图，约束条件对应的格填成叉
  • 按二、四、八格成圈，圈内至少含一个未被圈过的一，圈可以重叠
  • 每圈消去取值发生变化的变量，只保留取值不变的变量
  • 把所有圈对应的乘积项或起来得到最简与或式
通用考法
  • 本卷考过含约束项的逻辑函数卡诺图化简
  • 用卡诺图求最简与或表达式
  • 含约束条件的逻辑函数化简
  • 由最简式反推需要几个门电路
常见易错
  • 本卷考过把约束项当成必须为一，或漏圈可用约束项扩大的圈
  • 把约束项当成必须为 1 的项，或漏圈可以用约束项扩大的圈
  • 圈数为二的整数次幂以外的方格数

组合逻辑电路设计 数字逻辑与数字电路
本卷考法
  • 由 TTL 门电路逐级写输出逻辑表达式
本卷实例
  • 关键一步：从输入向输出逐级写各门输出，再按德摩根展开化简
  • 中间结果：两路输出均为若干与非项相与的形式
  • 卡点：两级门的具体接法与线与关系以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 组合逻辑的输出只由当前输入决定，不含记忆元件
  • 设计流程是列真值表、写表达式、化简、再映射到给定器件
  • 用译码器或数据选择器实现时，输出写成最小项之和的形式最方便
  • 全加器要考虑低位来的进位，全减器要考虑低位来的借位
步骤

  • 写出每个输出的最小项表达式并化简
  • 把表达式改写成给定器件（译码器、数据选择器、与非门）能直接实现的形式
  • 按器件引脚特性追加必要的门电路并把输入端接好
通用考法
  • 本卷考过由 TTL 门电路逐级写输出逻辑表达式
  • 用译码器或数据选择器加适当门电路设计指定逻辑功能
  • 仅用与非门实现给定逻辑功能
  • 设计一位全加或全减器
常见易错
  • 本卷考过化简时漏掉门电路输出端的反号
  • 控制信号取 0 与取 1 对应的加与减搞反
  • 接器件时忘记译码器的输出是低有效

脉冲波形产生与整形 数字逻辑与数字电路
本卷考法
  • 由 555 外围阈值电压求振荡频率与占空比
本卷实例

  • 中间结果：充电时间含两电阻之和，放电时间只含单个电阻
  • 卡点：阈值由外接控制电压决定，充放电端点以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 多谐振荡器的输出周期由两个外接电阻与电容决定
  • 单稳态触发器的输出脉宽只与一个外接电阻电容有关
  • 周期矩形波的幅值、周期与占空比是描述它的三个参数
步骤

  • 按接法写出充放电时间常数与相应的时间表达式
  • 代入外部元件参数算出周期或脉宽
  • 由电路结构说明输出波形的功能
通用考法
  • 本卷考过由 555 外围阈值电压求振荡频率与占空比
  • 计算输出脉冲的宽度或振荡周期
  • 说明给定接法的电路功能
  • 由要求脉宽反求外接元件参数
常见易错
  • 本卷考过把振荡周期公式与单稳脉宽公式混用
  • 振荡周期与单稳脉宽的公式混用

二数电二、JK 触发器画波形10 分#

思路
  • 先由 JK 触发器特性方程写次态关系，再按时钟有效边沿和异步置位复位的优先顺序，在给定激励波形下逐拍定出 Q 端电平并连成波形。
触发器与波形分析 数字逻辑与数字电路
本卷考法
  • 由 JK 触发器激励波形画输出波形
本卷实例
  • 关键一步：先按特性方程定次态，再看异步置复位端是否优先
  • 中间结果：每来一个有效时钟边沿，Q 在翻转与保持之间切换
  • 卡点：置复位与时钟边沿的先后以波形给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 触发器具有记忆功能，输出不仅与输入有关还与当前状态有关
  • JK 触发器在 J 与 K 同时为一时翻转，同时为零时保持
  • 边沿触发器的状态只在时钟有效边沿改变，画波形要盯住边沿
  • 不同触发器的特性方程可以互相转换
步骤
  • 写出所用触发器的特性方程
  • 按题意列出激励信号在各时钟周期的取值
  • 逐拍代入特性方程求出状态序列
  • 把状态序列画成波形，注意触发边沿与传输延迟
通用考法
  • 本卷考过由 JK 触发器激励波形画输出波形
  • 由时钟与激励波形画出输出波形
  • 判断触发器构成的电路功能
  • 由特性方程推导状态转移关系
常见易错
  • 本卷考过把边沿触发与电平触发混用，波形画错位置
  • 把电平触发与边沿触发混为一谈，波形画错位置
  • 忘记 JK 触发器同时置位时的翻转功能
