1一、参数根轨迹、分离点与阶跃响应#

思路
  • 由系统结构图求闭环特征式并分离出参数，整理成等效开环传函后绘制参数根轨迹，再用重根条件求分离点及其增益，该增益下闭环出现重极点后求阶跃响应
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 由含参数的闭环特征式整理出等效开环并绘制参数根轨迹
本卷实例
  • 关键一步：由闭环特征式分离出参数，写出等效开环的幅值条件
  • 中间结果：等效开环为参数乘一个零点除以三阶极点因子
  • 卡点：系统结构图以图给出，等效开环零极点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过由含参数的闭环特征式整理出等效开环并绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 本卷考过没有把参数提到分子的标准位置就套一百八十度相角条件
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

2二、非最小相位系统 Nyquist 曲线与稳定性#

思路
  • 开环含右半平面极点，先写幅频与相频表达式，求相角为负一百八十度处的负实轴交点，再按开环右半平面极点数与包围圈数判断闭环稳定性
频率特性的物理意义与求法 频域分析
本卷考法
  • 写出开环幅频与相频表达式并求指定频率处的值
本卷实例
  • 关键一步：把开环写成典型环节乘积，分别累加幅值与相角
  • 中间结果：相频由积分环节与两个一阶环节的相角叠加而成
  • 卡点：开环含右半平面极点，幅相曲线相角范围要覆盖全频段
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过写出开环幅频与相频表达式并求指定频率处的值
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过相角累加时漏掉积分环节的负九十度
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

奈奎斯特判据 稳定性分析
本卷考法
  • 由开环右半平面极点数与包围圈数判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数，再求曲线对临界点的包围情况
  • 中间结果：在相角等于负一百八十度处求曲线与负实轴交点
  • 卡点：开环含积分环节时要在曲线起点补画无穷大半径圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤

  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法

  • 由开环幅相曲线判断闭环稳定性

3三、串联超前校正设计#

思路
  • 先由分段幅频求校正前剪切频率与相角裕度，判断裕度不足后选超前校正，令最大超前角频率落在目标剪切频率上，用该处幅值条件定网络参数
开环对数频率特性的绘制 频域分析
本卷考法
  • 由转折频率分段求校正前剪切频率
本卷实例
  • 关键一步：按低频段高度与各段斜率写出分段幅频近似式
  • 中间结果：剪切频率落在惯性环节转折频率之后，用积分加惯性近似
  • 卡点：剪切频率所在频段要先判断再套近似式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过由转折频率分段求校正前剪切频率
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 本卷考过逐段改斜率时忘记累加而是直接替换
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

稳定裕度 频域分析
本卷考法
  • 求校正前相角裕度并判断是否需要校正
本卷实例
  • 关键一步：把剪切频率代入相频表达式求相角裕度
  • 中间结果：相角裕度由负一百八十度加上该频率处的相角得到
  • 卡点：幅值裕度与相角裕度定义不同，不要混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求校正前相角裕度并判断是否需要校正
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过把幅值裕度与相角裕度两个定义混用
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
