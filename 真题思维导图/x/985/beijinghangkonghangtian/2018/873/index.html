一数电一、卡诺图化简、施密特触发器与 ROM20 分#

思路
  • 三小问各自独立：先用卡诺图对含约束项函数化简，再判施密特触发器电路功能并画输入输出波形，最后由 ROM 阵列写出输出逻辑表达式。
逻辑代数与卡诺图化简 数字逻辑与数字电路
本卷考法
  • 题一1用卡诺图化简含约束条件的四变量逻辑函数
本卷实例
  • 关键一步：把最小项与约束项分别填入四变量卡诺图
  • 中间结果：按最大圈合并乘积项写出最简与或式
  • 卡点：约束条件书写残缺，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 逻辑函数化简可用公式法也可用卡诺图法，卡诺图更适合带约束项的情形
  • 约束项在卡诺图中记为叉，能圈就圈进圈里以取得更大的圈
  • 圈越大项越少，每圈包含的方格数为二的整数次幂
  • 无关项与任意项不产生新的圈，只用来帮助扩大已有的圈
步骤
  • 把逻辑函数按最小项填入卡诺图，约束条件对应的格填成叉
  • 按二、四、八格成圈，圈内至少含一个未被圈过的一，圈可以重叠
  • 每圈消去取值发生变化的变量，只保留取值不变的变量
  • 把所有圈对应的乘积项或起来得到最简与或式
通用考法
  • 本卷考过题一1用卡诺图化简含约束条件的四变量逻辑函数
  • 用卡诺图求最简与或表达式
  • 含约束条件的逻辑函数化简
  • 由最简式反推需要几个门电路
常见易错
  • 本卷考过把约束条件抄错，或漏圈可借约束扩大的圈
  • 把约束项当成必须为 1 的项，或漏圈可以用约束项扩大的圈
  • 圈数为二的整数次幂以外的方格数
公式
脉冲波形产生与整形 数字逻辑与数字电路
本卷考法
  • 题一2由施密特触发器电路写功能并画VI、VO波形
本卷实例
  • 关键一步：由施密特触发器转换电平定输出电压翻转时刻
  • 中间结果：按输入信号幅度与阈值关系连成输出波形
  • 卡点：施密特触发器电路以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 555 定时器可用作多谐振荡器、单稳态触发器与施密特触发器
  • 多谐振荡器的输出周期由两个外接电阻与电容决定
  • 单稳态触发器的输出脉宽只与一个外接电阻电容有关
  • 周期矩形波的幅值、周期与占空比是描述它的三个参数
步骤
  • 先判断电路接法是振荡、单稳还是施密特
  • 按接法写出充放电时间常数与相应的时间表达式
  • 代入外部元件参数算出周期或脉宽
  • 由电路结构说明输出波形的功能
通用考法
  • 本卷考过题一2由施密特触发器电路写功能并画VI、VO波形
  • 计算输出脉冲的宽度或振荡周期
  • 说明给定接法的电路功能
  • 由要求脉宽反求外接元件参数
常见易错
  • 本卷考过上下限阈值方向搞反，或输出电平与门电路参数不对应
  • 振荡周期与单稳脉宽的公式混用
  • 电容充放电回路看错，导致时间常数少算或多算一个电阻
公式
组合逻辑电路设计 数字逻辑与数字电路
本卷考法
  • 题一3由ROM阵列写出输出函数y1、y2的逻辑表达式

  • 中间结果：在或阵列把乘积项相或得y1、y2
  • 卡点：ROM阵列接线以图给出，需回原卷核对图

  • 按器件引脚特性追加必要的门电路并把输入端接好
通用考法
  • 本卷考过题一3由ROM阵列写出输出函数y1、y2的逻辑表达式
  • 用译码器或数据选择器加适当门电路设计指定逻辑功能
  • 仅用与非门实现给定逻辑功能
  • 设计一位全加或全减器
常见易错

二数电二、JK 触发器输出 Q 波形10 分#

思路
  • 由异步置复位端与 JK 激励波形判定每拍的次态，再在 CLK 有效边沿逐拍推 Q 的次态并连成波形。
触发器与波形分析 数字逻辑与数字电路
本卷考法
  • 题二由JK触发器各端波形画输出Q端对应的电压波形
本卷实例
  • 关键一步：先判异步置复位是否有效，无效时再看JK
  • 中间结果：按特性方程逐拍定次态，再连成Q的波形
  • 卡点：触发器电路与输入波形以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 触发器具有记忆功能，输出不仅与输入有关还与当前状态有关
  • JK 触发器在 J 与 K 同时为一时翻转，同时为零时保持
  • 边沿触发器的状态只在时钟有效边沿改变，画波形要盯住边沿
  • 不同触发器的特性方程可以互相转换
步骤
  • 写出所用触发器的特性方程
  • 按题意列出激励信号在各时钟周期的取值
  • 逐拍代入特性方程求出状态序列
  • 把状态序列画成波形，注意触发边沿与传输延迟
通用考法
  • 本卷考过题二由JK触发器各端波形画输出Q端对应的电压波形
  • 由时钟与激励波形画出输出波形
  • 判断触发器构成的电路功能
  • 由特性方程推导状态转移关系
常见易错
  • 本卷考过异步置复位优先于时钟，或边沿触发位置画错
  • 把电平触发与边沿触发混为一谈，波形画错位置
  • 忘记 JK 触发器同时置位时的翻转功能

六控制六、结构图求闭环传递函数15 分#

思路
  • 由结构图先定各独立回路与前向通路，再用梅森公式写总传函，最后以逐层化简复核。
梅森增益公式与信号流图 传递函数
本卷考法
  • 题六由结构图用梅森公式求C(s)/R(s)
本卷实例
  • 关键一步：先定各独立回路增益与前向通路
  • 中间结果：分子为各前向通路与其余子式乘积之和
  • 卡点：结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k

本卷考法
  • 题十2对状态空间表达式设计状态反馈阵配置闭环极点
本卷实例
  • 关键一步：由期望极点写期望特征多项式
  • 中间结果：与闭环特征式逐项比对解出反馈阵
  • 卡点：反馈增益定义与状态顺序需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过题十2对状态空间表达式设计状态反馈阵配置闭环极点
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 本卷考过反馈阵作用位置写错，或期望特征多项式系数错位
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
