3三、开环奈奎斯特曲线绘制与判稳15 分#

思路
  • 先写开环频率特性并处理两个积分环节的无穷大半径补偿，再画完整奈奎斯特曲线，最后按包围圈数判断闭环稳定性。
奈奎斯特判据 稳定性分析
本卷考法
  • 题三画给定开环的奈奎斯特曲线并用判据判断稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数P
  • 中间结果：补画无穷大半径圆弧后数包围原点圈数
  • 卡点：幅相曲线走向需按频率分段描点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过题三画给定开环的奈奎斯特曲线并用判据判断稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错

  • 开环含有积分环节时未补画无穷大半径圆弧

  • 先由 555 外接电阻电容判振荡周期并画输出波形，再用上升沿 JK 触发器设计五分频同步时序电路，写激励方程并画电路。
脉冲波形产生与整形 数字逻辑与数字电路
本卷考法
  • 题九1由555外接参数画输出u0的波形并定振荡周期
本卷实例
  • 关键一步：由555多谐振荡器的充放电路径写周期表达式
  • 中间结果：按两比较器阈值定输出高低电平持续时间
  • 卡点：555接法以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 555 定时器可用作多谐振荡器、单稳态触发器与施密特触发器
  • 多谐振荡器的输出周期由两个外接电阻与电容决定
  • 单稳态触发器的输出脉宽只与一个外接电阻电容有关
  • 周期矩形波的幅值、周期与占空比是描述它的三个参数
步骤
  • 先判断电路接法是振荡、单稳还是施密特
  • 按接法写出充放电时间常数与相应的时间表达式
  • 代入外部元件参数算出周期或脉宽
  • 由电路结构说明输出波形的功能
通用考法
  • 本卷考过题九1由555外接参数画输出u0的波形并定振荡周期
  • 计算输出脉冲的宽度或振荡周期
  • 说明给定接法的电路功能
  • 由要求脉宽反求外接元件参数
常见易错
  • 本卷考过充放电路径与时间常数取错，或阈值记反
  • 振荡周期与单稳脉宽的公式混用
  • 电容充放电回路看错，导致时间常数少算或多算一个电阻

时序逻辑与计数器 数字逻辑与数字电路
本卷考法
  • 题九2用JK触发器设计对u0五分频的同步时序电路
本卷实例
  • 关键一步：画五进制循环的状态转换图
  • 中间结果：由次态/输出卡诺图写各JK激励方程
  • 卡点：激励方程取决于触发器次态表，须逐项核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 时序逻辑的输出由当前输入与电路当前状态共同决定
  • 计数器有同步与异步、加法与减法、二进制与十进制之分
  • 集成计数器可通过置数或清零端改接成任意模数计数器
  • 状态图、状态表与波形图是描述时序电路的三件套
步骤
  • 由电路连接写出各触发器的驱动方程与时钟方程
  • 代入触发器特性方程得到状态方程
  • 列出状态表或状态图，确定电路的计数规律与模数
  • 需要变形时用置数端或清零端把某个状态反馈接回，得到目标模数
通用考法
  • 本卷考过题九2用JK触发器设计对u0五分频的同步时序电路
  • 分析给定电路的计数规律与模数
  • 用集成计数器设计指定模数的计数器
  • 画出加减计数器的输出波形
常见易错
  • 本卷考过状态编码未覆盖五个有效状态，或无自启动
  • 异步清零与同步置数的反馈状态取错
  • 把模数与触发器个数直接等同，忽略反馈接线的作用

触发器与波形分析 数字逻辑与数字电路
本卷考法
  • 题九2写JK触发器的激励方程并画五分频电路
本卷实例
  • 关键一步：由状态表逐位列各触发器次态
  • 中间结果：对照JK特性方程写出各J、K端表达式
  • 卡点：触发器级联方式需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 触发器具有记忆功能，输出不仅与输入有关还与当前状态有关
  • JK 触发器在 J 与 K 同时为一时翻转，同时为零时保持
  • 边沿触发器的状态只在时钟有效边沿改变，画波形要盯住边沿
  • 不同触发器的特性方程可以互相转换
步骤
  • 写出所用触发器的特性方程
  • 按题意列出激励信号在各时钟周期的取值
  • 逐拍代入特性方程求出状态序列
  • 把状态序列画成波形，注意触发边沿与传输延迟
通用考法
  • 本卷考过题九2写JK触发器的激励方程并画五分频电路
  • 由时钟与激励波形画出输出波形
  • 判断触发器构成的电路功能
  • 由特性方程推导状态转移关系
常见易错
  • 本卷考过JK次态表填错，或输出方程漏写
  • 把电平触发与边沿触发混为一谈，波形画错位置
  • 忘记 JK 触发器同时置位时的翻转功能

组合逻辑电路设计 数字逻辑与数字电路
本卷考法
  • 题十按题十表写红绿灯输出的逻辑并加必要门电路
本卷实例
  • 关键一步：按状态表列各状态对应的红绿灯取值
  • 中间结果：用译码输出与门电路组合出红绿信号
  • 卡点：题十表在源文以表格给出，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 组合逻辑的输出只由当前输入决定，不含记忆元件
  • 设计流程是列真值表、写表达式、化简、再映射到给定器件
  • 用译码器或数据选择器实现时，输出写成最小项之和的形式最方便
  • 全加器要考虑低位来的进位，全减器要考虑低位来的借位
步骤
  • 按功能描述列真值表，输入输出个数要与题意一致
  • 写出每个输出的最小项表达式并化简
  • 把表达式改写成给定器件（译码器、数据选择器、与非门）能直接实现的形式
  • 按器件引脚特性追加必要的门电路并把输入端接好
通用考法
  • 本卷考过题十按题十表写红绿灯输出的逻辑并加必要门电路
  • 用译码器或数据选择器加适当门电路设计指定逻辑功能
  • 仅用与非门实现给定逻辑功能
  • 设计一位全加或全减器
常见易错
  • 本卷考过状态与输出对应关系抄错，或使能端漏接
  • 控制信号取 0 与取 1 对应的加与减搞反
  • 接器件时忘记译码器的输出是低有效
