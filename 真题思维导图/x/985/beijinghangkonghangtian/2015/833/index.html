1一、结构图求闭环传函并反求 K1、K215 分#

思路
  • 先按结构图写出闭环传递函数并化为标准二阶形式，再由超调量定阻尼比、由调节时间定自然频率，最后对照系数联立解出两个参数。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由含反馈环节的结构图求闭环传递函数
本卷实例
  • 关键一步：先把结构图按反馈连接化简成闭环传函再与标准式比较
  • 中间结果：闭环特征式化为 s²+K1K2s+K1 的标准二阶形式
  • 卡点：结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由含反馈环节的结构图求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过反馈极性写反导致分母符号出错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环特征式化为标准二阶并读阻尼比与自然频率
本卷实例
  • 关键一步：由超调量公式反求阻尼比，再与标准式系数逐项对照
  • 中间结果：2ξωn 对应一次项系数、ωn² 对应常数项
  • 卡点：调节时间取 5% 误差带，系数勿与 2% 混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环特征式化为标准二阶并读阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过把一次项系数直接当成阻尼比
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

2二、参数根轨迹绘制15 分#

思路
  • 先由开环零极点分布确定根轨迹条数与实轴段，再按分离点、渐近线法则逐步绘制，并说明与虚轴无交点。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制含两个原点极点的根轨迹
本卷实例
  • 关键一步：零极点定位后先判实轴段再求渐近线
  • 中间结果：渐近线交点等于极点之和减零点之和再除以极零个数差
  • 卡点：两个原点极点使渐近线条数等于极点数减零点数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制含两个原点极点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过把重极点只算作一条根轨迹
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹分离点坐标
本卷实例
  • 关键一步：由各零极点倒数之和为零列出分离点方程
  • 中间结果：分离点方程由重根条件整理得到
  • 卡点：得到两根后需筛去不在根轨迹上的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹分离点坐标
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 本卷考过求出方程根后不筛选就全部保留
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

本卷考法
  • 说明根轨迹与虚轴交点情况
本卷实例
  • 关键一步：把 s 换成 jω 代入闭环特征式分别令实部虚部为零
  • 中间结果：本题在正频率下无解，根轨迹不与虚轴相交
  • 卡点：与虚轴无交点时须明确说明，不能略过
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解

3三、最大相位裕度与开环对数频率特性15 分#

思路
  • 先写幅频与相频表达式，再对相角裕度求极值定出截止频率，最后求该频率下的开环增益并画对数幅频渐近线与相频曲线。
频率特性的物理意义与求法 频域分析
本卷考法
  • 写开环幅频与相频表达式
本卷实例
  • 关键一步：把 s 换成 jω 后分别取模与取相角
  • 中间结果：相频为两个一阶环节的 arctan 之差再叠加积分环节相移
  • 卡点：两个原点极点贡献固定负相移，勿漏算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过写开环幅频与相频表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过求幅值时漏掉分母复数的模
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
稳定裕度 频域分析
本卷考法
  • 求使相角裕度最大的截止频率与最大裕度
本卷实例
  • 关键一步：把相角裕度看成频率的函数并令其导数为零
  • 中间结果：极值点落在两个转折频率的几何中点处
  • 卡点：最大裕度处的频率才取作截止频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求使相角裕度最大的截止频率与最大裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过把 ωc 与穿越频率用反
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

通用考法

4四、描述函数法分析自激振荡15 分#

思路
  • 先写线性部分的频率特性与非线性环节的负倒描述函数，再在复平面画两条曲线并按穿越方向判断交点对应的周期运动是否稳定。
描述函数法基础 非线性系统
本卷考法
  • 写继电特性的负倒描述函数
本卷实例
  • 关键一步：由非线性特性先求描述函数再取负倒数
  • 中间结果：负倒描述函数落在负实轴上并随幅值单调变化
  • 卡点：题目给的是死区继电特性，表达式与理想继电不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过写继电特性的负倒描述函数
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 本卷考过把描述函数本身当成负倒描述函数来画
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

用描述函数法分析自振 非线性系统
本卷考法
  • 由两曲线交点判断自振存在性与稳定性
本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
