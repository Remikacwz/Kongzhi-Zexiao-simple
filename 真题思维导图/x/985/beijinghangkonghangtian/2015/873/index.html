一数电一、选择（十小题）10 分#

思路
  • 十道小题各自独立，覆盖触发器分类与特性、移位寄存器、存储器地址线、CMOS 与 TTL 抗扰、施密特触发器、TTL 门电压、比较器、逻辑函数表达式与倒 T 型 D/A，逐题按定义判断。
触发器与波形分析 数字逻辑与数字电路
本卷考法
  • 由触发方式与输入端约束判断触发器特性
本卷实例
  • 关键一步：按各触发器触发方式与输入端约束逐项判断
  • 中间结果：主从与边沿触发的翻转时刻不同
  • 卡点：JK 输入不再有约束指的是无不定状态，不是抗扰更好
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 触发器具有记忆功能，输出不仅与输入有关还与当前状态有关
  • JK 触发器在 J 与 K 同时为一时翻转，同时为零时保持
  • 边沿触发器的状态只在时钟有效边沿改变，画波形要盯住边沿
  • 不同触发器的特性方程可以互相转换
步骤
  • 写出所用触发器的特性方程
  • 按题意列出激励信号在各时钟周期的取值
  • 逐拍代入特性方程求出状态序列
  • 把状态序列画成波形，注意触发边沿与传输延迟
通用考法
  • 本卷考过由触发方式与输入端约束判断触发器特性
  • 由时钟与激励波形画出输出波形
  • 判断触发器构成的电路功能
  • 由特性方程推导状态转移关系
常见易错
  • 本卷考过把电平触发与边沿触发混为一谈
  • 把电平触发与边沿触发混为一谈，波形画错位置
  • 忘记 JK 触发器同时置位时的翻转功能

逻辑代数与卡诺图化简 数字逻辑与数字电路
本卷考法
  • 由逻辑函数判断给定最小项表达式是否正确
本卷实例
  • 关键一步：把各选项还原为最小项集合再与卡诺图核对
  • 中间结果：同一逻辑函数可有多个等价表达式
  • 卡点：含约束项的函数要与约束条件一起判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 逻辑函数化简可用公式法也可用卡诺图法，卡诺图更适合带约束项的情形
  • 约束项在卡诺图中记为叉，能圈就圈进圈里以取得更大的圈
  • 圈越大项越少，每圈包含的方格数为二的整数次幂
  • 无关项与任意项不产生新的圈，只用来帮助扩大已有的圈
步骤
  • 把逻辑函数按最小项填入卡诺图，约束条件对应的格填成叉
  • 按二、四、八格成圈，圈内至少含一个未被圈过的一，圈可以重叠
  • 每圈消去取值发生变化的变量，只保留取值不变的变量
  • 把所有圈对应的乘积项或起来得到最简与或式
通用考法
  • 本卷考过由逻辑函数判断给定最小项表达式是否正确
  • 用卡诺图求最简与或表达式
  • 含约束条件的逻辑函数化简
  • 由最简式反推需要几个门电路
常见易错
  • 本卷考过把约束项漏掉或重复计数
  • 把约束项当成必须为 1 的项，或漏圈可以用约束项扩大的圈
  • 圈数为二的整数次幂以外的方格数

数模与模数转换器 数字逻辑与数字电路
本卷考法
  • 由输入码与参考电压求倒 T 型 D/A 输出
本卷实例
  • 关键一步：先按权值把输入码换算为等效数字量
  • 中间结果：输出模拟电压与输入等效数字量成正比
  • 卡点：倒 T 型网络输出与参考电压极性相反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 数模转换的分辨率由位数决定，位数越多最小输出电压越小
  • 转换误差有量化误差、失调误差与增益误差之分
  • 模数转换要经过采样、保持、量化与编码四个环节
  • 转换时间与分辨率互相制约，速度与精度需要折衷
步骤
  • 由位数与满量程算出最小输出增量即分辨率
  • 按绝对误差要求校核位数是否足够
  • 写出理想输出与实际输出的偏差表达式，判断属于哪类误差
  • 需要时可加上失调与增益的补偿措施
通用考法
  • 本卷考过由输入码与参考电压求倒 T 型 D/A 输出
  • 由位数与满量程求分辨率与量化误差
  • 由精度要求反推所需位数
  • 说明各类转换误差的来源与补偿办法
常见易错
  • 本卷考过分辨率的分母漏减一或量化误差算错
  • 分辨率的分母写成二的位数次幂而漏减一
  • 把量化误差写成分辨率本身而不是它的二分之一

组合逻辑电路设计 数字逻辑与数字电路
本卷考法
  • 由门电路写输出逻辑函数并列真值表
  • 分析三态门工作特点与使能功能
本卷实例
  • 关键一步：逐级写中间节点表达式再合并化简
  • 关键一步：由使能端电平判断门电路处于导通还是高阻
  • 中间结果：两路输出分别为异或与含进位项的组合函数
  • 中间结果：使能有效时数据传到总线，无效时呈高阻
  • 卡点：门电路以图给出，需回原卷核对图
  • 卡点：两个三态门不能同时导通，否则总线冲突
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 组合逻辑的输出只由当前输入决定，不含记忆元件
  • 设计流程是列真值表、写表达式、化简、再映射到给定器件
  • 用译码器或数据选择器实现时，输出写成最小项之和的形式最方便
  • 全加器要考虑低位来的进位，全减器要考虑低位来的借位
步骤
  • 按功能描述列真值表，输入输出个数要与题意一致
  • 写出每个输出的最小项表达式并化简
  • 把表达式改写成给定器件（译码器、数据选择器、与非门）能直接实现的形式
  • 按器件引脚特性追加必要的门电路并把输入端接好
通用考法
  • 本卷考过由门电路写输出逻辑函数并列真值表
  • 本卷考过分析三态门工作特点与使能功能
  • 用译码器或数据选择器加适当门电路设计指定逻辑功能
  • 仅用与非门实现给定逻辑功能
  • 设计一位全加或全减器
常见易错
  • 本卷考过把中间节点表达式当成最终输出
  • 本卷考过把高电平有效与低电平有效的使能条件写反
  • 控制信号取 0 与取 1 对应的加与减搞反
  • 接器件时忘记译码器的输出是低有效

思路

时序逻辑与计数器 数字逻辑与数字电路
本卷考法
  • 由计数顺序设计同步五进制可逆计数器
  • 检查自启动能力并说明无关状态处理
本卷实例
  • 关键一步：列可逆控制端两种取值下的状态转换表
  • 关键一步：把每个无关状态的次态算出来看是否进入循环
  • 中间结果：次态卡诺图以有效状态为核心，无关状态按自启动要求处理
  • 中间结果：只要所有无关状态都在有限拍内进入主循环即自启动
  • 卡点：设计过程要完整写出，注意可逆端决定加或减
  • 卡点：计数顺序以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 时序逻辑的输出由当前输入与电路当前状态共同决定
  • 计数器有同步与异步、加法与减法、二进制与十进制之分
  • 集成计数器可通过置数或清零端改接成任意模数计数器
  • 状态图、状态表与波形图是描述时序电路的三件套
步骤
  • 由电路连接写出各触发器的驱动方程与时钟方程
  • 代入触发器特性方程得到状态方程
  • 列出状态表或状态图，确定电路的计数规律与模数
  • 需要变形时用置数端或清零端把某个状态反馈接回，得到目标模数
通用考法
  • 本卷考过由计数顺序设计同步五进制可逆计数器
  • 本卷考过检查自启动能力并说明无关状态处理
  • 分析给定电路的计数规律与模数
  • 用集成计数器设计指定模数的计数器
  • 画出加减计数器的输出波形
常见易错
  • 本卷考过异步清零与同步置数的反馈状态取错
  • 本卷考过只列有效状态循环而不检查无关状态
  • 异步清零与同步置数的反馈状态取错
  • 把模数与触发器个数直接等同，忽略反馈接线的作用
