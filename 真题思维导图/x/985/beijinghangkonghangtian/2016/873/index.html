一数电一、卡诺图化简与门电路、ROM 与优先编码器20 分#

思路
  • 四小问各自独立：先分别把逻辑图、TTL 门特性、ROM 阵列与优先编码器功能表读清楚，再逐问作答；卡诺图化简是唯一带约束项的代数化简。
逻辑代数与卡诺图化简 数字逻辑与数字电路
本卷考法
  • 题一1由逻辑图写Y1、Y2并用卡诺图化成整体最简式
本卷实例
  • 关键一步：把两路输出的最小项与约束项分别填入四变量卡诺图
  • 中间结果：按二四八格成圈后合并乘积项，得整体最简与或式
  • 卡点：逻辑图在题一1图中给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 逻辑函数化简可用公式法也可用卡诺图法，卡诺图更适合带约束项的情形
  • 约束项在卡诺图中记为叉，能圈就圈进圈里以取得更大的圈
  • 圈越大项越少，每圈包含的方格数为二的整数次幂
  • 无关项与任意项不产生新的圈，只用来帮助扩大已有的圈
步骤
  • 把逻辑函数按最小项填入卡诺图，约束条件对应的格填成叉
  • 按二、四、八格成圈，圈内至少含一个未被圈过的一，圈可以重叠
  • 每圈消去取值发生变化的变量，只保留取值不变的变量
  • 把所有圈对应的乘积项或起来得到最简与或式
通用考法
  • 本卷考过题一1由逻辑图写Y1、Y2并用卡诺图化成整体最简式
  • 用卡诺图求最简与或表达式
  • 含约束条件的逻辑函数化简
  • 由最简式反推需要几个门电路
常见易错
  • 本卷考过把约束项当成必须取1，或漏圈可用约束项扩大的圈
  • 把约束项当成必须为 1 的项，或漏圈可以用约束项扩大的圈
  • 圈数为二的整数次幂以外的方格数

三数电三、触发器输出波形10 分#

思路
  • 先明确触发器类型与时钟有效边沿，再按特性方程在每一拍求出次态，最后按时序连成 Q 的波形。
触发器与波形分析 数字逻辑与数字电路
本卷考法
  • 由题三图的时钟与输入信号画触发器输出Q波形
本卷实例

  • 中间结果：Q在翻转与保持间切换，异步端优先于时钟
  • 卡点：时钟、输入与电路接法以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 触发器具有记忆功能，输出不仅与输入有关还与当前状态有关
  • JK 触发器在 J 与 K 同时为一时翻转，同时为零时保持
  • 边沿触发器的状态只在时钟有效边沿改变，画波形要盯住边沿
  • 不同触发器的特性方程可以互相转换
步骤
  • 写出所用触发器的特性方程
  • 按题意列出激励信号在各时钟周期的取值
  • 逐拍代入特性方程求出状态序列
  • 把状态序列画成波形，注意触发边沿与传输延迟
通用考法
  • 本卷考过由题三图的时钟与输入信号画触发器输出Q波形
  • 由时钟与激励波形画出输出波形
  • 判断触发器构成的电路功能
  • 由特性方程推导状态转移关系
常见易错
  • 本卷考过边沿触发位置画错，异步置复位期间仍按时钟翻转
  • 把电平触发与边沿触发混为一谈，波形画错位置
  • 忘记 JK 触发器同时置位时的翻转功能

通用考法
  • 本卷考过用NE555多谐振荡器产生0.25s周期的时钟

六控制六、结构图求闭环传递函数10 分#

思路
  • 由结构图先用梅森公式数回路与前向通路求传函，再用逐层化简复核。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由题六结构图用梅森公式求C(s)/R(s)
本卷实例
  • 关键一步：先定各回路增益与前向通路，再套梅森公式
  • 中间结果：分母含各回路与不接触回路积，分子为前向通路和
  • 卡点：回路与前向通路接法以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
