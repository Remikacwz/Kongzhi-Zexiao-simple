1一、测速反馈与最简补偿器设计15 分#

思路
  • 先用梅森公式由结构图求闭环传递函数并化为标准二阶，按阻尼比定测速反馈系数并写动态性能公式；再按单位斜坡无稳态误差的要求反求最简补偿器。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由多回路结构图用梅森公式求闭环传递函数
本卷实例
  • 关键一步：先数独立回路与前向通路，再看余子式是否接触
  • 中间结果：闭环分母为 1 减各回路增益之和
  • 卡点：两条回路的公共节点决定是否互相接触
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由多回路结构图用梅森公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过数回路或前向通路时把接触关系找错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函比较系数定阻尼比与自然频率
本卷实例
  • 关键一步：把闭环特征式整理成首一的标准二阶形式
  • 中间结果：一次项系数对应 2ξωn、常数项对应 ωn²
  • 卡点：先由阻尼比要求解出测速反馈系数再读自然频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函比较系数定阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过未把 s² 项系数归一化就套标准式
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 写峰值时间、超调量与调节时间的计算公式
本卷实例
  • 关键一步：把求得的阻尼比与自然频率代入欠阻尼指标公式
  • 中间结果：峰值时间与阻尼振荡频率成反比
  • 卡点：本题只要求写出计算公式，不必代入数值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过写峰值时间、超调量与调节时间的计算公式
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过两种误差带的调节时间系数混用
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

减小稳态误差的措施 稳态误差
本卷考法
  • 设计补偿器使单位斜坡输入下稳态误差为零
本卷实例
  • 关键一步：由误差传递函数在原点附近的行为反求补偿器
  • 中间结果：补偿器需在原点引入一个积分环节
  • 卡点：最简补偿器的阶次要与开环结构相匹配
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计补偿器使单位斜坡输入下稳态误差为零
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 本卷考过只提高增益而未改变系统型别
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

2二、零度根轨迹与振荡收敛范围15 分#

思路
  • 开环含负号因子，先化为零度根轨迹形式，再按法则绘制并求分离点与虚轴交点，最后取使阶跃响应振荡收敛的增益范围。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 含右半平面零点时按零度根轨迹绘制
本卷实例
  • 关键一步：把开环传函整理后确认使用 0 度相角条件
  • 中间结果：实轴段判据由零点极点个数之和的奇偶确定
  • 卡点：分子中的 1-s 提出负号后系统按零度根轨迹处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过含右半平面零点时按零度根轨迹绘制
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 本卷考过仍沿用 180 度相角条件
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

与虚轴的交点及临界参数 根轨迹法
本卷考法

本卷实例

  • 令实部与虚部分别为零，得到两个方程

通用考法

  • 求根轨迹与虚轴的交点及临界增益

  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

3三、对数频率特性与对数稳定判据15 分#

思路
  • 先写开环对数幅频与相频表达式并画渐近线，再用对数稳定判据按截止频率与相位穿越关系分析使闭环稳定的增益范围。
开环对数频率特性的绘制 频域分析
本卷考法
  • 画开环对数幅频渐近特性与相频曲线
本卷实例
  • 关键一步：由开环零极点写出各段斜率与转折频率
  • 中间结果：对数幅频在转折频率处按 -20 分贝每十倍频累加
  • 卡点：非最小相位环节的相频要从 -90 度继续下降
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过画开环对数幅频渐近特性与相频曲线
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 本卷考过低频段高度未乘型别对应的分贝数
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

奈奎斯特判据 稳定性分析
本卷考法
  • 用对数频率稳定判据确定稳定增益范围
本卷实例
  • 关键一步：先数开环右半平面极点数，再看幅频大于零频段内相频穿越次数
  • 中间结果：稳定条件由右极点、正负穿越次数与闭环右极点数的关系给出
  • 卡点：含一个右半平面开环极点时判据形式与最小相位系统不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用对数频率稳定判据确定稳定增益范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过数穿越次数时正负号取反
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

本卷考法

本卷实例

  • 中间结果：相频由各环节相角代数和给出

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差

  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由传递函数写幅频与相频表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过把非最小相位零点当成普通零点处理
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

4四、非线性系统相轨迹绘制15 分#

思路
  • 按继电特性把相平面分为三个区域，各区域写出误差微分方程并求相轨迹表达式，再从给定初值出发分段画到开关线并说明终态。
相平面法 非线性系统
本卷考法
  • 分区写相轨迹微分方程并画概略相轨迹
本卷实例
  • 关键一步：按非线性环节输出把相平面分成三个区域分别积分
  • 中间结果：各区相轨迹分别为水平线、对数曲线与斜线
  • 卡点：从给定初值出发需逐段判断与开关线的交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
