1一、二阶系统指标矛盾分析与测速反馈设计15 分#

思路
  • 由闭环传函比对标准二阶形式求自然频率与阻尼比，说明欠阻尼下调节时间与超调量对增益的依赖方向不同，再用测速反馈额外引入阻尼而不增加零点
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传递函数与标准二阶形式比对求自然频率与阻尼比
本卷实例
  • 关键一步：把开环传函代入负反馈公式得到闭环传函并分母归一化
  • 中间结果：自然频率由常数项开方确定，阻尼比由一次项与自然频率之比确定
  • 卡点：一次项系数含二倍阻尼比乘自然频率，不要漏系数二
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传递函数与标准二阶形式比对求自然频率与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过化为标准形式时忘记把平方项系数归一化
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

2二、零度根轨迹与稳定增益范围15 分#

思路
  • 开环含右半平面零点，整理成零度根轨迹方程后按零度相角条件绘轨迹，由重根条件求分离点，由纯虚根求虚轴交点并确定稳定域与共轭复极点域
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 整理出零度根轨迹方程并按零度相角条件绘制
本卷实例
  • 关键一步：把含非最小相位零点的开环整理成右侧为一的零度形式
  • 中间结果：实轴段按该段右侧零极点个数为偶数判断
  • 卡点：零度根轨迹不能用一百八十度相角条件，实轴判据也不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过整理出零度根轨迹方程并按零度相角条件绘制
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 本卷考过零度根轨迹仍沿用一百八十度相角条件
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

3三、最大相角裕度与滞后校正15 分#

思路
  • 把相角写成一个反正切函数求使裕度最大的剪切频率，再由该处幅值等于一定增益；第二问用滞后网络抬高低频增益减小加速度误差，同时保持剪切频率不变
开环对数频率特性的绘制 频域分析
本卷考法
  • 按转折频率写出分段渐近幅频与相频表达式
本卷实例
  • 关键一步：把开环写成积分、一阶微分与惯性环节的乘积
  • 中间结果：各段斜率由积分环节个数与各转折点逐个累加得到
  • 卡点：逐段改斜率要累加，不要直接替换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过按转折频率写出分段渐近幅频与相频表达式
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 本卷考过逐段改斜率时忘记累加而是直接替换
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

稳定裕度 频域分析
本卷考法
  • 求使相角裕度最大的剪切频率并写出裕度公式
本卷实例
  • 关键一步：把相角表示为反正切之差并令其对频率导数为零
  • 中间结果：相角表达式化为一个反正切函数后由其分母取极值定频率
  • 卡点：先判断剪切频率所在频段，再回代幅频等于一求增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求使相角裕度最大的剪切频率并写出裕度公式
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过把剪切频率与相位穿越频率两个频率用反
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

滞后校正 系统校正
本卷考法
  • 选择滞后校正通过提高低频增益减小稳态误差
本卷实例
  • 关键一步：在保持剪切频率不变的前提下用滞后网络抬高低频增益
  • 中间结果：滞后网络的两个转折频率分别低于剪切频率一定倍数
  • 卡点：转折频率取得过高会把相位滞后带到剪切频率处
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法

  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响

  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 写出输入信号的拉氏变换
