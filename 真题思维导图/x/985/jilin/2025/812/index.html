1一、结构图化简与四种传递函数#

思路
  • 化简方框图求开环传函，再分别求输出与误差对给定、对扰动的四个传递函数，最后画信号流图
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 化简方框图求系统的开环传递函数
本卷实例
  • 关键一步：先把多回路结构按最内层回路化简成等效环节，再往外一层层处理
  • 关键一步：开环传函要把反馈支路断开后从误差点到反馈点整条通路写出来
  • 关键一步：化简时比较点与引出点若需移动，移动后必须补上相应的环节
  • 中间结果：化简完成后通路上的环节依次相乘即得开环传函，可用来核对后续四个闭环传函的分母是否一致
  • 卡点：把闭环传函当开环传函；或在方框图变换时漏掉某个环节导致增益差一个倍数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过化简方框图求系统的开环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求输出与误差对有用输入、对扰动输入的四组传递函数
本卷实例
  • 关键一步：四个传函一一对应：求谁对谁，就把另一个输入置零后重新找通路
  • 关键一步：同一个系统的四组传函分母完全相同，都是同一个特征式，可以只用一套分母然后分别求分子
  • 关键一步：误差取在输入端还是反馈端要先看清题意图上的误差点位置，两种取法差一个反馈系数
  • 中间结果：扰动通道的分子通常比给定通道少一些环节，把两个通道并列写出来对比最清楚
  • 卡点：四个传函的分母写成不同的式子；或求误差传函时忘记在图上确认误差点位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求输出与误差对有用输入、对扰动输入的四组传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图画信号流图
本卷实例
  • 关键一步：信号流图的节点对应结构图中的信号，支路对应方框的传递关系
  • 关键一步：比较点在流图里表现为多条支路汇入同一节点，反馈支路要从输出节点引回
  • 关键一步：同一信号被多处引用时只设一个节点，用多条引出支路表示
  • 中间结果：画完可数回路个数，应与结构图里数出的回路个数一致
  • 卡点：把方框画成节点导致回路数增加；或反馈支路起点接错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由结构图画信号流图
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、含右半平面极点的根轨迹#

思路
  • 开环含一个右半平面极点与一个零点，画根轨迹、求稳定域与持续振荡条件，再由调节时间反求增益与根
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按要求步骤完整地绘制根轨迹
本卷实例
  • 关键一步：先标零极点：一个极点在一、一个在零、零点在负一，实轴段由右侧零极点个数为奇数判定
  • 关键一步：极点比零点多一个，渐近线只有一条，方向沿负实轴，不需要算夹角等分
  • 关键一步：分离点或会合点出现在两个相邻极零点之间，用极点倒数之和等于零点倒数之积的方程求解
  • 中间结果：由于存在右半平面极点，根轨迹起始段在右半平面，必须靠零点把分支拉回左半平面才可能稳定
  • 卡点：忘记右半平面极点也是根轨迹起点；或漏算零点，把渐近线条数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按要求步骤完整地绘制根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求系统稳定的增益范围以及持续振荡时的增益与频率
本卷实例
  • 关键一步：写出闭环特征方程并列劳斯表，首列同号给出增益范围
  • 关键一步：持续振荡对应特征方程有一对纯虚根，把复变量取纯虚数代入，实部虚部分别为零
  • 关键一步：本题特征方程是二次的，令一次项系数为零即得临界增益，虚部方程给出角频率
  • 中间结果：临界增益对应两个特征根落在虚轴上，
  • 中间结果：此时一次项系数为零而常数项为正，恰好满足二阶系统临界稳定的条件
  • 卡点：把临界增益说成使系统失稳的增益；或求出角频率后忘记换算成振荡周期
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求系统稳定的增益范围以及持续振荡时的增益与频率
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由调节时间要求反求增益与该增益下的闭环极点
本卷实例
  • 关键一步：调节时间只由主导极点的实部决定，按百分之二的误差带取四点零除以实部绝对值
  • 关键一步：本题闭环是二阶系统，特征方程一次项系数的一半就是阻尼比乘自然频率，正好是实部绝对值
  • 关键一步：由调节时间解出实部绝对值后，令它等于一次项系数的一半即可解出增益，再代回求根
  • 中间结果：解出的增益使闭环极点为一对共轭复数，实部绝对值等于四分之一的要求值，虚部由常数项决定
  • 卡点：误差带的系数取错；或把调节时间与实部绝对值的倒数关系写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由调节时间要求反求增益与该增益下的闭环极点
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式

3三、二阶系统全指标与扰动误差#

思路
  • 由结构图写闭环传函，算动态指标与复合输入下的稳态误差，再讨论如何降低扰动引起的误差
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求系统的超调量、调节时间与峰值时间
本卷实例
  • 关键一步：环增益与对象增益相乘后写出闭环传函，与标准二阶形式比对得阻尼比与自然频率
  • 关键一步：超调量只由阻尼比决定，题给的三个指数近似值分别对应不同的阻尼比，要挑对那个
  • 关键一步：峰值时间与调节时间都还要用到自然频率，先算阻尼比再算这两个
  • 中间结果：本题阻尼比使超调量指数中正好出现二分之派，直接查题给数据即可，不必自己算指数
  • 卡点：把开环增益直接当闭环增益；或调节时间忘记乘误差带系数，与峰值时间混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求系统的超调量、调节时间与峰值时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求组合输入下系统的稳态误差
本卷实例
  • 关键一步：输入含常数项与斜坡项，先判断型别：开环含一个积分环节，属 Ⅰ 型系统
  • 关键一步：Ⅰ 型系统对阶跃无稳态误差，对斜坡的误差等于斜坡斜率除以速度误差系数
  • 关键一步：速度误差系数由开环传函去掉一个 s 后取低频极限求得，本题结果是很整齐的整数
  • 中间结果：组合输入的稳态误差就是斜坡项单独引起的误差，常数项不贡献误差
  • 卡点：把两项误差相加时忘了阶跃项为零；或速度误差系数忘记把增益乘进去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求组合输入下系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 分析如何降低扰动引起的稳态误差
本卷实例
  • 关键一步：先把扰动到误差的传递函数写出来，令参考输入为零单独分析扰动通道
  • 关键一步：扰动误差的大小由扰动作用点到误差点之间前向通路的增益决定，增益越大误差越小
  • 关键一步：若扰动可测，可在扰动点前面加入前馈补偿装置，理论上能把扰动对输出的影响完全抵消
  • 中间结果：单纯提高增益会同时降低稳定裕度，所以工程上更倾向用补偿而不是一味加大增益
  • 卡点：只提提高增益而不检查稳定性；或把扰动通道与给定通道的传函搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过分析如何降低扰动引起的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式

4四、最小相位系统的对数特性与输出正弦响应#

思路
  • 画开环对数幅相特性，算相角裕度与幅值裕度，再画奈奎斯特图判稳，最后由正弦输入求输出表达式
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制开环对数幅频与相频特性曲线
本卷实例
  • 关键一步：先分解成典型环节：一个积分、一个一阶微分、三个惯性环节，
  • 关键一步：低频段斜率由积分环节定为每十倍频程下降二十分贝，高度由增益决定
  • 关键一步：按转折频率从小到大逐段改斜率，经过一阶微分上升、经过惯性环节下降
  • 关键一步：各自的转折频率要按时间常数倒数写出来
  • 中间结果：本题三个惯性环节的转折频率分散，幅频曲线会有多段折线，画完数一数斜率变化次数应与环节数一致
  • 卡点：改斜率时忘记累加；或把一阶微分的转折方向与惯性环节搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定

本卷考法

本卷实例

  • 关键一步：再按传递函数的分母与分子还原成微分方程：分母对应输出的各阶导，分子对应输入的各阶导
  • 关键一步：本题分子是常数，说明微分方程右端只有输入本身，没有输入的导数项
  • 中间结果：分子为常数与分母二次对应二阶微分方程，输出与其一阶、二阶导数都是系数为一

9九、李雅普诺夫第二法判断开环稳定性#

思路
  • 求平衡状态、用第二法判断稳定性，并讨论李雅普诺夫函数是否唯一

本卷考法

  • 说明李雅普诺夫函数是否唯一
本卷实例
  • 关键一步：平衡状态由状态导数全部为零解出，线性系统只有原点一个平衡点
  • 关键一步：取二次型李雅普诺夫函数，令其导数为负定的已知矩阵，解出李雅普诺夫方程的解阵
  • 关键一步：检查解阵正定：二阶矩阵只要对角线首元素与行列式都大于零即可，正定就说明原点渐近稳定
  • 中间结果：本题系数矩阵的行列式为正、迹为负，特征值都是负实数，与解阵正定的结论一致
  • 中间结果：取不同的正定矩阵作为导数的右端会得到不同的解阵，所以李雅普诺夫函数不是唯一的
  • 卡点：把李雅普诺夫方程里两个解阵的位置弄反导致解阵不对称；
  • 卡点：或把一阶线性系统当成非线性系统去做线性化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论

  • 本卷考过说明李雅普诺夫函数是否唯一
