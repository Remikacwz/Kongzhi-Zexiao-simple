1一、结构图化简、多输入传递函数与信号流图20 分#

思路
  • 先由结构图列各回路与前向通路增益，分别求参考输入与扰动输入下的传函，再据传函画信号流图。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 逐层化简多回路结构图求闭环传函
本卷实例
  • 关键一步：按信号流向由内到外逐层合并等效环节
  • 中间结果：求出的多组传函分母同为闭环特征式
  • 卡点：移动比较点或引出点后漏补相应环节
  • 卡点：结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过逐层化简多回路结构图求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求参考输入与扰动输入到输出的传函
本卷实例
  • 关键一步：求扰动传函时把参考输入置零
  • 中间结果：扰动通路只保留扰动到输出的环节
  • 卡点：两输入同时作用时未验证线性就叠加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求参考输入与扰动输入到输出的传函
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 由化简后的传函绘制信号流图并用梅森公式校验
本卷实例
  • 关键一步：列出全部回路增益与前向通路增益
  • 中间结果：互不接触的回路在特征式中补乘
  • 卡点：余子式中未剔除与通路接触的回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由化简后的传函绘制信号流图并用梅森公式校验
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、开环根轨迹、过阻尼与欠阻尼K范围及稳定范围15 分#

思路
  • 标出开环零极点按法则画根轨迹，用分离点与虚轴交点定临界增益，再按阻尼状态给出K范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制含共轭复极点系统的根轨迹
本卷实例
  • 关键一步：标出零极点后判断实轴根轨迹区间
  • 中间结果：三条分支起于0与一对共轭极点
  • 卡点：渐近线夹角公式中的2k+1写成2k
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制含共轭复极点系统的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
出射角与入射角 根轨迹法
本卷考法
  • 求共轭复极点处的出射角
本卷实例
  • 关键一步：按相角条件反求该极点的出射方向
  • 中间结果：两共轭极点的出射角互为相反数
  • 卡点：累加相角时把该极点自身相角也计入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求共轭复极点处的出射角
  • 求复数极点的出射角
  • 根据出射角画出根轨迹起始方向
  • 由入射角确定根轨迹终止方向
常见易错
  • 累加相角时把该极点自身的相角也算进去
  • 忘记判断象限导致角度差 180°
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹分离点并筛选合理解
本卷实例
  • 关键一步：令开环传函倒数对s的导数为零
  • 中间结果：本题分离点方程无实根，轨迹不进入实轴分离
  • 卡点：求出复根后若不筛选会误判存在分离点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹分离点并筛选合理解
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴的交点及临界增益
本卷实例
  • 关键一步：用劳斯判据首列为零的条件求临界增益
  • 中间结果：虚轴交点与临界增益、振荡频率一一对应
  • 卡点：只代一个频率就下结论，漏掉另一组交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴的交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹判断阻尼状态并给出稳定K范围
本卷实例
  • 关键一步：按闭环极点是否落在实轴上判断阻尼状态
  • 中间结果：根轨迹全部位于左半平面时系统稳定
  • 卡点：把等阻尼线画成了垂直线
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹判断阻尼状态并给出稳定K范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

3三、二阶系统误差系数、阶跃响应指标与加速度输入误差15 分#

思路
  • 由开环传函定系统型别与静态误差系数，化为二阶标准形式求动态指标，再按输入类型判断稳态误差。
系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环传函判断型别并求静态速度误差系数
本卷实例
  • 关键一步：先数开环积分环节个数确定系统型别
  • 中间结果：本题为Ⅰ型系统，速度误差系数为有限值
  • 卡点：把开环增益直接当成速度误差系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由开环传函判断型别并求静态速度误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为二阶标准形式读阻尼比
本卷实例
  • 关键一步：把二次项系数归一后与标准式比对
  • 中间结果：由化简后的传函读出自然频率与阻尼比
  • 卡点：化为标准形式时忘记把s平方项系数归一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为二阶标准形式读阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求欠阻尼阶跃响应的超调量与调节时间
本卷实例
  • 关键一步：按超调量公式与调节时间定义分别计算
  • 中间结果：响应为衰减振荡，两项指标同时受限
  • 卡点：把两种误差带的调节时间系数搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求欠阻尼阶跃响应的超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求加速度输入下Ⅰ型系统的稳态误差
本卷实例
  • 关键一步：按系统型别判断能否跟踪该输入
  • 中间结果：Ⅰ型系统不能跟踪加速度输入
  • 卡点：未判稳就使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求加速度输入下Ⅰ型系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

4四、Bode图绘制、稳定裕度、奈氏曲线与判稳20 分#

思路
  • 由含右半平面极点的开环传函逐段画Bode图，求稳定裕度并画奈氏曲线，再按包围圈数判稳。
开环对数频率特性的绘制 频域分析
本卷考法
  • 按转折频率逐段绘制开环对数渐近幅频特性
本卷实例
  • 关键一步：按各典型环节转折频率依次改变斜率
  • 中间结果：低频段斜率与高度确定型别与增益
  • 卡点：逐段改斜率时忘记在原基础上累加
