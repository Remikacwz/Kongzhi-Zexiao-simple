1一、结构图化简与四组传递函数（含图）#

思路
  • 按结构图信号流向逐层化简求开环传函；再由梅森公式分别求参考输入与扰动输入到输出、误差的四组传递函数；最后画信号流图。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 对多回路结构图逐层化简求开环传函
本卷实例
  • 关键一步：先内环后外环逐层合并
  • 中间结果：开环传函由前向通路与反馈通路组合
  • 卡点：结构图以图给出，回路接线需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过对多回路结构图逐层化简求开环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求参考输入与扰动输入下的输出与误差传函
本卷实例
  • 关键一步：求扰动传函时令参考输入为零
  • 中间结果：四组传函共用同一特征式
  • 卡点：两输入同时作用时不要直接叠加而未验证线性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求参考输入与扰动输入下的输出与误差传函
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式由信号流图求闭环传函
本卷实例
  • 关键一步：列全部回路增益并确认无互不接触回路
  • 中间结果：特征式等于一减各回路增益之和
  • 卡点：余子式要剔除与通路接触的回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式由信号流图求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、开环根轨迹、重根与阻尼角及稳态误差#

思路
  • 按根轨迹法则绘完整根轨迹并求分离点；由分离点条件求重根时的增益；由阻尼角45度作等阻尼线与轨迹求交点及增益；最后由系统型别求斜坡稳态误差。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制含两个零点的根轨迹
本卷实例
  • 关键一步：标开环零极点后判实轴段与渐近线
  • 中间结果：三条分支中两条终止于有限零点
  • 卡点：起始角要按复数极点相角条件求
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制含两个零点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 由分离点方程求重根及对应增益
本卷实例
  • 关键一步：令分子乘分母导数等于分母乘分子导数
  • 中间结果：分离点方程的解需按实轴段筛选
  • 卡点：求增益时要代回幅值条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由分离点方程求重根及对应增益
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由阻尼角作等阻尼线求交点与增益
本卷实例
  • 关键一步：按阻尼角在复平面画等阻尼射线
  • 中间结果：射线与根轨迹交点给出闭环极点
  • 卡点：阻尼角与阻尼比的关系别弄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由阻尼角作等阻尼线求交点与增益
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由系统型别求单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：先按稳定范围确认增益取值
  • 中间结果：开环含积分环节时斜坡误差有限
  • 卡点：未判稳就套用终值定理会出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由系统型别求单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

  • 中间结果：闭环传函分母由回路增益决定
  • 卡点：前馈支路接入点不同会改变传函

典型输入下的稳态误差计算 稳态误差
本卷考法

本卷实例
  • 关键一步：由开环传函求速度误差系数
  • 中间结果：前馈可改变系统的无差度
  • 卡点：要按新的开环传函重算误差系数

劳斯判据 稳定性分析
本卷考法
  • 对含参数闭环特征方程用劳斯判据判稳
本卷实例
  • 关键一步：把给定系数代入特征方程后列劳斯表
  • 中间结果：由首列元素同号判断稳定性
  • 卡点：参数代入后可能缺项要补零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过对含参数闭环特征方程用劳斯判据判稳
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 由前馈补偿分析消除稳态误差的条件
本卷实例
  • 关键一步：令误差传函在给定输入下为零
  • 中间结果：补偿条件与输入形式和对象参数有关
  • 卡点：只谈误差减小而不检查稳定性是否被破坏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过由前馈补偿分析消除稳态误差的条件
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式

4四、描述函数法判断自振并求振幅频率（含图）#

思路
  • 写出非线性环节的负倒描述函数并判断单调性；画线性部分的幅相曲线求相角为负180度处幅值；比较两曲线的相对位置判断是否产生自振，再由交点求振幅与频率。
描述函数法基础 非线性系统
本卷考法
  • 由继电特性描述函数写负倒描述函数
本卷实例
  • 关键一步：按给定描述函数取负倒式
  • 中间结果：负倒描述函数在实轴上单调变化
  • 卡点：画的是负倒描述函数，不是描述函数本身
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过由继电特性描述函数写负倒描述函数
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件
公式
用描述函数法分析自振 非线性系统
本卷考法
  • 用描述函数法判断自振并求振幅与频率
本卷实例
  • 关键一步：求线性部分相角为负180度处的幅值
