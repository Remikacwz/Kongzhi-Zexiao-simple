1一、结构图化简与信号流图#

思路
  • 化简多回路方框图求Y/R与E/R，再由结构图改画信号流图
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 化简多回路方框图求闭环传递函数
本卷实例
  • 关键一步：先按最内层回路化简成等效环节，再逐层向外处理
  • 关键一步：化简时若移动比较点或引出点，移动后要补上相应环节
  • 中间结果：先写出前向通路与各回路增益，再套梅森公式求闭环传函
  • 卡点：把闭环传函误当开环传函；跨回路化简时漏乘某环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过化简多回路方框图求闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图画出系统信号流图
本卷实例
  • 关键一步：结构图的每个信号对应流图一个节点，方框对应有向支路
  • 关键一步：比较点在流图中表现为汇入同一节点的多条支路
  • 中间结果：画完可数回路个数，应与结构图里数出的回路数一致
  • 卡点：把方框画成节点使回路数增加；反馈支路起点接错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图画出系统信号流图
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、含复极点的根轨迹绘制与重根K值#

思路
  • 按法则完整绘制开环根轨迹，求复极点出射角与虚轴交点，再求重根处K值
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制开环根轨迹并写出完整步骤
本卷实例
  • 关键一步：先标零极点并数渐近线条数，判断实轴上的根轨迹区间
  • 关键一步：渐近线交角按(2k+1)/(n-m)取，交点实部用零极点坐标之和比
  • 中间结果：系统无零点、四个极点，n-m=4，渐近线与实轴交于-3
  • 卡点：渐近线交角公式漏写2k+1；实轴区间零极点计数出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制开环根轨迹并写出完整步骤
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
出射角与入射角 根轨迹法
本卷考法
  • 求共轭复数极点的出射角
本卷实例
  • 关键一步：出射角用相角条件反求，减去其余各零极点提供的相角
  • 关键一步：共轭极点出射角关于实轴对称，求得一个另一个取相反数
  • 中间结果：一对共轭复极点的出射角为一对相反角
  • 卡点：累加相角时把该极点自身的相角也算进去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求共轭复数极点的出射角
  • 求复数极点的出射角
  • 根据出射角画出根轨迹起始方向
  • 由入射角确定根轨迹终止方向
常见易错
  • 累加相角时把该极点自身的相角也算进去
  • 忘记判断象限导致角度差 180°
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及对应的临界K
本卷实例
  • 关键一步：把s=jω代入闭环特征方程，令实部与虚部分别为零
  • 关键一步：也可由劳斯表首列出现零求临界K，再用辅助方程求交点
  • 中间结果：临界K对应根轨迹穿越虚轴，交点由辅助方程解出
  • 卡点：只代一组ω漏掉另一组交点；算出K后不回题核对增益定义
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及对应的临界K
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
分离点与会合点 根轨迹法
本卷考法
  • 求系统具有重根时的K值
本卷实例
  • 关键一步：重根即分离点，用dK/ds=0或1/G的导数为零求坐标
  • 关键一步：求出的根要筛选，只保留落在根轨迹上的那个
  • 中间结果：分离点坐标对应的增益即重根K，可由幅值条件回代求得
  • 卡点：求出方程根后不筛选，保留了不在根轨迹上的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求系统具有重根时的K值
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

3三、复合控制消除稳态误差#

思路
  • 由前馈补偿G1与对象G构成误差传函，令输入1+t+t²各次幂系数为零反求a、b
系统型别与静态误差系数 稳态误差
本卷考法
  • 判断系统型别与可跟踪的输入阶次
本卷实例
  • 关键一步：数开环积分环节个数定系统型别，判断原系统能否无差跟踪
  • 关键一步：输入含t²分量，要求系统对加速度分量无静差
  • 中间结果：原开环传函含一个积分环节，属Ⅰ型系统
  • 卡点：把开环增益与静态误差系数混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断系统型别与可跟踪的输入阶次
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求组合输入1+t+t²下的稳态误差
本卷实例
  • 关键一步：误差传函按(1+G1)G/(1+G)写，再乘输入拉氏变换后求极限
  • 关键一步：令误差式中各次幂系数为零，解出待定参数
  • 中间结果：把误差式整理成s的幂级数，低次幂系数分别对应各输入分量
  • 卡点：组合输入时漏掉某一分量；未判稳就使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求组合输入1+t+t²下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 设计前馈补偿G1使系统无静差跟踪给定
本卷实例
  • 关键一步：用前馈通道改变误差传函分子，使其与输入各分量匹配
  • 关键一步：补偿参数由误差分子各次幂系数为零的条件确定
  • 中间结果：前馈补偿不改变闭环特征式，只改变误差传函的分子
  • 卡点：只调整补偿参数而不检查稳定性是否被破坏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计前馈补偿G1使系统无静差跟踪给定
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式

4四、由Bode图求传函、裕度与奈氏判据#

思路
  • 由对数幅频特性低频段与转折频率反求开环传函，算幅值相角裕度，画奈氏曲线判稳
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环对数幅频特性反求传递函数
本卷实例
  • 关键一步：由低频段斜率定系统型别，由低频段高度或延长线定开环增益
  • 关键一步：按各转折频率处斜率的变化依次写出典型环节
  • 中间结果：低频段高度20lg(K/ω)可用于反求K，转折频率对应各时间常数
  • 卡点：把延长线交点直接当增益而未折算型别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环对数幅频特性反求传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 求系统的幅值裕度与相角裕度
本卷实例
  • 关键一步：相角裕度在截止频率处用180°加相角求，幅值裕度在相位穿越频率处取幅值倒数
  • 关键一步：先按幅频曲线估截止频率，再算该频率处相角
  • 中间结果：相位穿越频率处相角为-180°，幅值裕度以分贝表示
  • 卡点：把截止频率与相位穿越频率用反；幅值裕度取倒数方向搞错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求系统的幅值裕度与相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 画奈氏曲线并用奈氏判据判断闭环稳定性
本卷实例
  • 关键一步：最小相位系统先数开环右半平面极点P，再看曲线包围(-1,j0)的圈数

9九、李雅普诺夫第二法判断稳定性#

思路
  • 求平衡状态，构造李雅普诺夫函数用第二法判断渐进稳定并求参数范围
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 用李雅普诺夫第二法判断平衡状态的渐进稳定性
  • 写出一个李雅普诺夫函数
本卷实例
  • 关键一步：令各状态导数为零求平衡状态，本题平衡点为原点
  • 关键一步：选正定二次型作V(x)，求V的导数并使之负定，反推参数范围
  • 中间结果：取V=(x1²+x2²)/2时，V的导数只剩与x2平方有关的项
  • 卡点：只判断V正定就下结论而未检查它的导数；P、Q角色混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
