1一、最小相位系统结构图化简与传函#

思路
  • 化简方框图求五组传递函数，求稳态误差为零时补偿Gc满足的条件，再画信号流图
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 化简多回路方框图求各闭环传递函数
本卷实例
  • 关键一步：按叠加原理分别令R=0与N=0，求各输入到输出的传函
  • 关键一步：先化简内回路再逐层并入外回路
  • 中间结果：五组传函分母同为闭环特征式
  • 卡点：化简时把某条前向通路漏掉
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过化简多回路方框图求各闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求输出与误差对给定输入、对扰动的多组传递函数
本卷实例
  • 关键一步：求谁对谁就把另一个输入置零后重找通路
  • 关键一步：误差传函由E=R-Y推出，也可写成1减输出传函
  • 中间结果：扰动到误差的传函与扰动到输出的传函相差一个负号
  • 卡点：误差取点判断错；扰动传函未置零参考输入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求输出与误差对给定输入、对扰动的多组传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

减小稳态误差的措施 稳态误差
本卷考法
  • 求稳态误差为零时补偿环节Gc应满足的条件
本卷实例
  • 关键一步：写出误差传函并令其分子在稳态极限下为零
  • 关键一步：由分子等于零反解出Gc的表达式
  • 中间结果：补偿条件只含Gc、G2、G3与反馈H1，与扰动无关
  • 卡点：只令给定误差为零而漏掉扰动引起的误差分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过求稳态误差为零时补偿环节Gc应满足的条件
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图画出系统信号流图
本卷实例
  • 关键一步：每个信号设一个节点，方框对应有向支路
  • 关键一步：比较点在流图里是汇入同一节点的多条支路
  • 中间结果：流图的回路个数应与结构图一致
  • 卡点：把方框画成节点；反馈支路起点接错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图画出系统信号流图
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、开环根轨迹、阻尼角与稳定K范围#

思路
  • 完整绘制根轨迹，按阻尼角30°求对应K值，再给出系统稳定时K的范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制开环根轨迹并写出完整步骤
本卷实例
  • 关键一步：先标零极点、数渐近线条数并判断实轴区间
  • 关键一步：渐近线交角按±60°与-180°，交点在实轴-4/3
  • 中间结果：三阶系统无零点，实轴根轨迹区间为(-∞,0]
  • 卡点：分离点求完未用相角条件验证，把非分离点当分离点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制开环根轨迹并写出完整步骤
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
出射角与入射角 根轨迹法
本卷考法
  • 求共轭复数极点的出射角
本卷实例
  • 关键一步：出射角由相角条件反求，扣掉其余零极点贡献的相角
  • 关键一步：一对共轭极点出射角互为相反数并关于实轴对称
  • 中间结果：本题两复极点出射角约为±54.7°
  • 卡点：累加相角时把该极点自身相角也算进去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求共轭复数极点的出射角
  • 求复数极点的出射角
  • 根据出射角画出根轨迹起始方向
  • 由入射角确定根轨迹终止方向
常见易错
  • 累加相角时把该极点自身的相角也算进去
  • 忘记判断象限导致角度差 180°
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求系统稳定时K的取值范围
本卷实例
  • 关键一步：把s=jω代入特征方程求虚轴交点与临界K
  • 关键一步：由根轨迹在虚轴左侧的区间确定稳定域
  • 中间结果：根轨迹穿越虚轴时对应临界K，稳定域为0到该临界值
  • 卡点：只求一个交点漏掉另一组；未核对K定义
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求系统稳定时K的取值范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由给定阻尼角求根轨迹上的闭环极点和K
本卷实例
  • 关键一步：阻尼角30°对应等阻尼线，设s=-根号3倍实部加实部j代入特征方程
  • 关键一步：解出设定极点坐标后回代幅值条件求K
  • 中间结果：等阻尼线与根轨迹交点即为满足阻尼比要求的闭环极点
  • 卡点：把等阻尼线画成垂直线；忽略零点影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由给定阻尼角求根轨迹上的闭环极点和K
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

3三、二阶环节稳定条件与无差补偿#

思路
  • G3=0时由二阶特征式系数全正求稳定条件，再设计G3使斜坡输入稳态误差为零
参数稳定域的确定 稳定性分析
本卷考法
  • 求使闭环系统稳定的参数条件
本卷实例
  • 关键一步：先写出闭环特征多项式，再按二阶系统系数全部为正列条件
  • 关键一步：把K1、T1、K2、T2的取值约束整理成不等式组
  • 中间结果：二阶系统稳定的充要条件是两个系数同号且为正
  • 卡点：只列部分首列元素的不等式而漏掉某个约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求使闭环系统稳定的参数条件
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡输入r(t)=Rt时的稳态误差
本卷实例
  • 关键一步：用梅森公式写出误差传函E/R
  • 关键一步：误差传函乘R/s²后用终值定理求极限
  • 中间结果：误差式分子中含G3项，可通过它抵消斜坡分量
  • 卡点：未判稳就用终值定理；组合输入漏分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求斜坡输入r(t)=Rt时的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

4四、Bode图、稳定裕度与奈氏判据#

思路
  • 对给定传函画Bode图与奈氏图，求幅值相角裕度并用奈氏判据判稳
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制开环对数幅频与相频特性
本卷实例
  • 关键一步：把传函化为典型环节串联形式，先求低频段斜率与高度
  • 关键一步：按各转折频率逐段改变斜率并逐点描相角
  • 中间结果：本题开环为0型，低频段斜率为0，转折频率由分母两个实极点决定
  • 卡点：逐段改斜率时忘记累加而非替换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB

9九、李雅普诺夫第二法证明稳定性#

思路
  • 求平衡点并用李雅普诺夫第二法定性证明渐进稳定，再写出一个李雅普诺夫函数
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 求平衡点并用李雅普诺夫第二法证明稳定性
  • 写出一个李雅普诺夫函数
本卷实例
  • 关键一步：令导数为零解出平衡点，本题为原点
  • 关键一步：选V=ax1²+bx2²，令交叉项系数为零使V的导数负定
  • 中间结果：取a=2、b=1时V=2x1²+x2²，V的导数负定
  • 卡点：只判断V正定而不检查其导数；P、Q角色混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过求平衡点并用李雅普诺夫第二法证明稳定性
  • 本卷考过写出一个李雅普诺夫函数
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数
