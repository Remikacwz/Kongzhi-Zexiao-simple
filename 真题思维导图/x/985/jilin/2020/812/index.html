1一、结构图求参考输入与扰动输入下的四组传递函数#

思路
  • 由结构图列回路与前向通路增益，分别令参考输入与扰动输入单独作用，求四组传函。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 逐层化简含局部反馈的结构图
本卷实例
  • 关键一步：按信号流向由内到外逐层合并
  • 中间结果：求出的四组传函分母同为闭环特征式
  • 卡点：化简内环时把外环信号当成常数处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过逐层化简含局部反馈的结构图
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求扰动输入到输出与误差的传函
本卷实例
  • 关键一步：求扰动传函时把参考输入置零
  • 中间结果：扰动通路只保留扰动到输出与误差的环节
  • 卡点：两输入同时作用时未验证线性就叠加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求扰动输入到输出与误差的传函
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式复核结构图化简结果
本卷实例
  • 关键一步：列出全部回路增益与前向通路增益
  • 中间结果：互不接触的回路在特征式中补乘
  • 卡点：余子式中未剔除与通路接触的回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式复核结构图化简结果
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、由开环传函绘制根轨迹、求稳定K范围并证明轨迹为圆#

思路
  • 标出零点与一对实数极点按法则画根轨迹，用分离点与虚轴交点定稳定范围，再用相角条件证圆。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制含一个零点与两个实数极点的根轨迹
本卷实例
  • 关键一步：标出零极点后判断实轴根轨迹区间
  • 中间结果：两条分支起于两个极点、一条终于零点
  • 卡点：渐近线夹角公式中的2k+1写成2k
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制含一个零点与两个实数极点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹分离点并筛选合理解
本卷实例
  • 关键一步：令开环传函倒数对s的导数为零
  • 中间结果：分离点落在两极点之间的实轴段上
  • 卡点：求出多个根后不筛选，保留了不在轨迹上的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹分离点并筛选合理解
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求使系统稳定的K范围与临界增益
本卷实例
  • 关键一步：用劳斯表首列非负列写稳定条件
  • 中间结果：临界增益对应特征根恰好落在虚轴上
  • 卡点：取交集时把端点是否包含搞错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求使系统稳定的K范围与临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 用相角条件证明根轨迹为圆
本卷实例
  • 关键一步：把复变量代入相角条件后整理实部虚部关系
  • 中间结果：相角条件化简后得到圆的方程
  • 卡点：把相角条件的180度写成0度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过用相角条件证明根轨迹为圆
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式

3三、二阶系统由超调量反求K、动态指标与脉冲输入稳态误差#

思路
  • 由超调量求阻尼比与自然频率进而定K，按二阶公式算时域指标，再判断脉冲输入的稳态误差。
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由给定超调量反求系统参数K
本卷实例
  • 关键一步：由超调量公式反求阻尼比再定自然频率
  • 中间结果：由开环增益与自然频率的关系解出K
  • 卡点：只满足单项指标就下结论，未做交叉验证
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由给定超调量反求系统参数K
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把开环传函化为二阶标准形式
本卷实例
  • 关键一步：把二次项系数归一后与标准式比对
  • 中间结果：由标准式读出自然频率与阻尼比
  • 卡点：把开环增益误当成闭环传函的系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把开环传函化为二阶标准形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求上升时间、峰值时间与调节时间
本卷实例
  • 关键一步：按欠阻尼指标公式分别代入阻尼比与自然频率
  • 中间结果：三个时间指标由阻尼比与自然频率唯一确定
  • 卡点：把峰值时间与上升时间混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求上升时间、峰值时间与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 分析单位脉冲输入下的稳态误差
本卷实例
  • 关键一步：先按系统型别判断该输入下误差是否为零
  • 中间结果：Ⅰ型系统对脉冲输入的稳态误差为零
  • 卡点：源文第三问的输入类型与答案段不一致，答案段自评回忆有误
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过分析单位脉冲输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

4四、Bode图绘制、稳定裕度计算与奈氏判据判稳#

思路
  • 由开环传函逐段画Bode图，求相角与幅值裕度，再画奈氏曲线按包围圈数判断稳定性。
开环对数频率特性的绘制 频域分析
本卷考法
  • 按转折频率逐段绘制开环对数频率特性
本卷实例
  • 关键一步：按各典型环节转折频率依次改变渐近线斜率
  • 中间结果：低频段斜率与高度确定型别与增益
  • 卡点：逐段改斜率时忘记累加而非替换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过按转折频率逐段绘制开环对数频率特性
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
稳定裕度 频域分析
本卷考法
  • 计算相角裕度与幅值裕度
本卷实例
  • 关键一步：相角裕度在幅值穿越频率处按相角求
  • 中间结果：穿越频率处相角与负180度之差即相角裕度
  • 卡点：把幅值穿越频率与相位穿越频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)

  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定

  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
