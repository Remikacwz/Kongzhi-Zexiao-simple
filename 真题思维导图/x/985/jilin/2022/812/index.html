1一、结构图化简与四组传递函数#

思路
  • 化简结构图求闭环传函，分别求Y/R、E/R、Y/N、E/N四组传函，再画信号流图
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 化简方框图求闭环传递函数
本卷实例
  • 关键一步：先化简内回路，再把等效环节并入外回路逐层化简
  • 关键一步：化简完成后用前向通路与回路增益核对特征式
  • 中间结果：四组传递函数的分母同为闭环特征式，可只求一套分母
  • 卡点：化简内环时把外环信号当成常数处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过化简方框图求闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求输出与误差对输入、对扰动的四组传递函数
本卷实例
  • 关键一步：求谁对谁就把另一个输入置零，再重新找前向通路
  • 关键一步：误差取在输入端还是反馈端要先看清图上的误差点位置
  • 中间结果：扰动通道的分子通常比给定通道少若干环节，可并列对比
  • 卡点：求扰动传函时没有把参考输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求输出与误差对输入、对扰动的四组传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图改画系统信号流图
本卷实例
  • 关键一步：每个信号设一个节点，方框对应一条有向支路
  • 关键一步：多处引用的信号仍只设一个节点，用多条引出支路表示
  • 中间结果：画完核对回路个数与结构图数出的回路数
  • 卡点：把方框画成节点使回路条数增加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图改画系统信号流图
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、开环根轨迹绘制、重根与虚轴交点#

思路
  • 按法则完整绘制根轨迹，求重根处K值，再求与虚轴相交时的临界K
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制开环根轨迹并写出完整步骤
本卷实例
  • 关键一步：先标零极点、数渐近线条数，判断实轴上的根轨迹区间
  • 关键一步：三条渐近线的交角按±60°与-180°取，交点在实轴
  • 中间结果：三阶系统无零点，实轴区间为(-∞,-1]与[-0.5,0]两段
  • 卡点：渐近线夹角公式中的2k+1写成2k；实轴区间判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制开环根轨迹并写出完整步骤
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求系统存在重根时的K值
本卷实例
  • 关键一步：重根对应分离点，由1/G对s求导为零或dK/ds=0求坐标
  • 关键一步：求出坐标后代回幅值条件求该点增益K
  • 中间结果：分离点落在实轴上，对应根轨迹增益由幅值条件算出
  • 卡点：求出方程根后不舍去不在根轨迹上的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求系统存在重根时的K值
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求与虚轴相交时的K值
本卷实例
  • 关键一步：把s=jω代入特征方程，实部虚部分别为零联立求解
  • 关键一步：也可由劳斯表首列含K项为零直接求临界K
  • 中间结果：临界K处根轨迹穿越虚轴，对应一对共轭纯虚根
  • 卡点：只代一组ω而漏掉另一组；不核对K与根轨迹增益的换算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求与虚轴相交时的K值
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式

3三、前馈模型的闭环性能与补偿设计#

思路
  • Gc=0时求闭环传函与阶跃性能，再设计Gc使斜坡输入下稳态误差为零
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由前馈模型求闭环传递函数
本卷实例
  • 关键一步：Gc=0时只剩前向通路与单位反馈，按负反馈公式写闭环传函
  • 关键一步：把结果整理成标准二阶形式便于读性能参数
  • 中间结果：闭环传函整理成K/(s²+2s+K)的二阶标准形式
  • 卡点：把负反馈分母写成1-GH；漏掉某条前向通路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由前馈模型求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求阶跃输入下的调节时间与最大超调量
本卷实例
  • 关键一步：先把闭环传函化为二阶标准形式，读出ωn与ξ
  • 关键一步：由ξ与ωn分别代入调节时间与超调量公式
  • 中间结果：比较系数得2ξωn=2、ωn²=K，即ξ=1/根号K
  • 卡点：把两种误差带的调节时间系数搞混；超调量漏乘100%
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求阶跃输入下的调节时间与最大超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡输入下的稳态误差
本卷实例
  • 关键一步：写出误差传函后乘R(s)=1/s²，再用终值定理求极限
  • 关键一步：把误差式分子中含补偿项的部分单独整理
  • 中间结果：误差式分子中含Gc项，可通过分子抵消实现零误差
  • 卡点：未判稳就使用终值定理；输入阶次代入错误
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 设计Gc使系统对斜坡信号无差
本卷实例
  • 关键一步：用前馈补偿Gc改变误差传函分子，令其与斜坡输入匹配
  • 关键一步：令稳态误差表达式为零反解出Gc的表达式
  • 中间结果：本题求得Gc为常数，属按输入补偿的复合控制
  • 卡点：补偿器含高阶微分不可实现却直接采用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计Gc使系统对斜坡信号无差
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式

4四、由Bode图反求传函与奈氏判稳#

思路
  • 题干标明与2021年第四题相同，由对数幅频特性反求传函，算裕度并用奈氏判据判稳
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环对数幅频特性反求传递函数
本卷实例
  • 关键一步：由低频段斜率与高度确定型别与开环增益
  • 关键一步：按各转折频率处斜率变化写出对应典型环节
  • 中间结果：低频段斜率为-20dB/dec且高度20lg(K/ω)可反求K
  • 卡点：把延长线交点直接当增益而未按型别折算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环对数幅频特性反求传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 求幅值裕度与相角裕度
本卷实例
  • 关键一步：截止频率处用180°加相角求相角裕度
  • 关键一步：相位穿越频率处幅值的倒数即幅值裕度
  • 中间结果：最小相位系统相位穿越频率处相角为-180°
  • 卡点：把截止频率与相位穿越频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc

思路
  • 求平衡状态，用李雅普诺夫方程法判稳，并写出一个李雅普诺夫函数
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 用李雅普诺夫第二法判断平衡状态稳定性
  • 写出一个李雅普诺夫函数
本卷实例
  • 关键一步：令导数为零求平衡点，本题平衡点为原点
  • 关键一步：由A^T P+PA=-I解P，判断P的正定性
  • 中间结果：解出P后按正定性判断系统在原点是否渐进稳定
  • 卡点：李雅普诺夫方程中P、Q角色混用；只判P正定而不查V导数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过用李雅普诺夫第二法判断平衡状态稳定性
  • 本卷考过写出一个李雅普诺夫函数
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数
