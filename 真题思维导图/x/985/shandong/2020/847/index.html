1一、结构图与信号流图求传函#

思路
  • 由结构图求C(s)/R(s)与E(s)/R(s)，再由信号流图求C/R与B/A。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图用梅森公式求闭环与误差传递函数
本卷实例
  • 关键一步：标出两条前向通路与两条回路
  • 关键一步：分别写C/R与E/R的余子式
  • 中间结果：E/R由1减闭环传函关系另列
  • 卡点：误差通路符号写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图用梅森公式求闭环与误差传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 结构图化简求多输出传递函数
本卷实例
  • 关键一步：由比较点写误差节点方程
  • 关键一步：由输出点回代消中间变量
  • 中间结果：两路输出共用同一特征式
  • 卡点：比较点移动时乘除因子写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过结构图化简求多输出传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 信号流图求A到B与A到C两路传函
本卷实例
  • 关键一步：分别标出从A到B与A到C的通路
  • 关键一步：共用同一特征式写传递函数
  • 中间结果：B/A等于B/R除以A/R
  • 卡点：两路前向通路找漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过信号流图求A到B与A到C两路传函
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

2二、由阶跃响应求全响应与正弦稳态误差#

思路
  • 由单位阶跃响应反求闭环传函，求非零初值加阶跃输入的全响应，再求正弦输入的稳态误差。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应反求闭环传函与微分方程
本卷实例
  • 关键一步：对响应取拉氏变换除以阶跃变换
  • 关键一步：整理成尾一形式读写
  • 中间结果：闭环分母为两个实极点之积
  • 卡点：响应含常数项时漏减稳态值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应反求闭环传函与微分方程
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 非零初值下求系统全响应
本卷实例
  • 关键一步：对微分方程作非零初值拉氏变换
  • 关键一步：反变换得全响应表达式
  • 中间结果：全响应含初值自由分量与输入强迫分量
  • 卡点：拉氏变换漏掉初值项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过非零初值下求系统全响应
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 写误差传递函数并求正弦输入下的稳态误差
本卷实例
  • 关键一步：由1减闭环传函得误差传函
  • 关键一步：令s为j5求幅值与相角
  • 中间结果：正弦稳态误差为同频正弦量
  • 卡点：忘记把误差相位与输入相位相加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写误差传递函数并求正弦输入下的稳态误差
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由频率特性求正弦输入的幅值和相位
本卷实例
  • 关键一步：把j5代入误差传函求复数
  • 中间结果：复数模为误差幅值、幅角为相移
  • 卡点：复数相角象限判断错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由频率特性求正弦输入的幅值和相位
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

3三、参数根轨迹与性能影响分析#

思路
  • 分别以k与kh为参变量画两族根轨迹，并分析两参数单独增大对稳态与动态性能的影响。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以不同参数为参变量分别绘制参数根轨迹
本卷实例
  • 关键一步：由闭环特征方程整理出等效开环传函
  • 关键一步：分别以k与kh为参变量重列
  • 中间结果：两族根轨迹共用同一特征方程
  • 卡点：整理时参数未完整提到分子
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以不同参数为参变量分别绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制两族根轨迹草图
本卷实例
  • 关键一步：标出各零点极点与实轴根轨迹段
  • 中间结果：一族根轨迹起于复极点
  • 卡点：实轴段判据零极点个数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制两族根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 分析两参数单独增大对稳态与动态性能影响
本卷实例
  • 关键一步：由根轨迹走向判断阻尼与超调变化
  • 关键一步：由开环增益判断稳态性能变化
  • 中间结果：一个参数只改动态性能、另一个兼改稳态
  • 卡点：把两参数作用混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过分析两参数单独增大对稳态与动态性能影响
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

4四、开环幅相特性与奈氏判据稳定域#

思路
  • 画含右半平面极点系统的Bode图与幅相曲线，用奈氏判据确定使系统稳定的kh范围。
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制含右半平面极点系统的开环对数幅频特性
本卷实例
  • 关键一步：由型别与增益定低频段渐近线
  • 关键一步：按转折频率逐段改斜率
  • 中间结果：右半平面极点使相频计算需注意符号
  • 卡点：低频段起始高度漏算型别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过绘制含右半平面极点系统的开环对数幅频特性
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由幅相曲线用奈氏判据确定稳定kh范围
本卷实例
  • 关键一步：先数开环右半平面极点数P
  • 关键一步：按幅相曲线包围负1点的圈数判稳
  • 中间结果：稳定条件由包围圈数等于负P给出
  • 卡点：含积分环节未补画无穷大圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由幅相曲线用奈氏判据确定稳定kh范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤

  • 逐层化简直到只剩一个等效环节
