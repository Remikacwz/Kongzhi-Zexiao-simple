1一、化简题求传递函数12 分#

思路
  • 把多回路结构图等效化简，或用梅森公式分别求前向通路与特征式，得C(s)/R(s)。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由多回路结构图用梅森公式求闭环传递函数
本卷实例
  • 关键一步：标出全部前向通路与各独立回路
  • 关键一步：找互不接触回路对特征式的修正项
  • 中间结果：余子式只保留与该前向通路不接触的回路
  • 卡点：结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由多回路结构图用梅森公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图由内到外逐层等效化简
本卷实例
  • 关键一步：先合并最内层的串联并联与局部反馈
  • 关键一步：再逐层向外归并到单一输入输出
  • 中间结果：化简中保持各比较点与引出点信号关系不变
  • 卡点：交叉比较点移动时乘除因子易写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图由内到外逐层等效化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2二、二阶系统参数β对稳定性与性能的影响18 分#

思路
  • 由结构图求闭环传函，用劳斯判据分析β对稳定性的影响，再由ξ、ωn讨论动态性能与稳态误差。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由含参数结构图列写闭环传递函数
本卷实例
  • 关键一步：把内环反馈支路化简约到前向通道
  • 关键一步：整理成标准二阶闭环传函形式
  • 中间结果：闭环特征式是分母二次多项式
  • 卡点：化简时把β所在支路与增益支路接反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由含参数结构图列写闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断参数β对稳定性的影响
本卷实例
  • 关键一步：按降幂列劳斯表并令首列同号
  • 关键一步：由首列条件反推β的取值范围
  • 中间结果：首列出现零元时须改用辅助方程判断
  • 卡点：只看一项系数就下结论，漏掉另一约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断参数β对稳定性的影响
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函读出ωn与ξ并判断β的影响
本卷实例
  • 关键一步：把闭环分母与标准二阶分母逐项对照
  • 关键一步：由系数关系写出ξ随β的变化
  • 中间结果：ξ与β同向变化而ωn不随β变
  • 卡点：未把二次项系数归一化就直接对照
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函读出ωn与ξ并判断β的影响
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 分析β对超调量与调节时间的影响
本卷实例
  • 关键一步：写出σ%与ts随ξ变化的趋势
  • 关键一步：结合β增大时ξ的变化给出结论
  • 中间结果：σ%与ts都随β增大而减小
  • 卡点：把两种误差带对应的调节时间系数混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过分析β对超调量与调节时间的影响
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡输入及阶跃加斜坡组合输入下的稳态误差
本卷实例
  • 关键一步：由误差传函写出E(s)并先判稳
  • 关键一步：分别代入阶跃与斜坡分量再叠加
  • 中间结果：组合输入误差是两分量分别计算后的和
  • 卡点：组合信号漏掉某一分量或未先判稳
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求斜坡输入及阶跃加斜坡组合输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、正反馈系统根轨迹与稳定范围15 分#

思路
  • 正反馈系统画零度根轨迹，求分离点与虚轴交点，定出使系统稳定的k范围。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 含右半平面开环零点时绘制零度根轨迹
本卷实例
  • 关键一步：按2kπ相角条件判断，不套180度判据
  • 关键一步：标出起点终点与实轴根轨迹段
  • 中间结果：根轨迹复数部分为以实轴上一点为圆心的圆弧
  • 卡点：先判断开环零极点位置再定相角条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过含右半平面开环零点时绘制零度根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点坐标并取舍
本卷实例
  • 关键一步：由1/G对s求导为零列分离点方程
  • 关键一步：把根代回根轨迹段判断是否有效
  • 中间结果：落在实轴根轨迹段内的根才可取
  • 卡点：求出方程根后不筛选，保留无效根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点坐标并取舍
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由虚轴交点求临界参数与稳定范围
本卷实例
  • 关键一步：令s=jw代入闭环特征方程
  • 关键一步：实部虚部分别为零联立解交点与K
  • 中间结果：临界K把稳定范围分成两段需结合实轴判断
  • 卡点：只代一组w就下结论，漏掉原点解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由虚轴交点求临界参数与稳定范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

4四、对数幅频特性与比例微分校正#

思路
  • 画4/[s²(0.2s+1)]的对数幅频曲线并求相角裕度，再串联(s+1)重求ωc与γ并比较中频段形状。
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制开环对数渐近幅频特性
本卷实例
  • 关键一步：由型别与开环增益定低频段斜率与高度
  • 关键一步：遇转折频率逐段改变斜率并累加
  • 中间结果：各段斜率依次累加而不是替换
  • 卡点：低频段起始高度漏算型别的负斜率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过绘制开环对数渐近幅频特性
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
稳定裕度 频域分析
本卷考法
  • 计算相角裕度并判断相对稳定性
本卷实例
  • 关键一步：由幅值条件求幅值穿越频率
  • 关键一步：在穿越频率处累加各环节相角求γ
  • 中间结果：γ为负表示闭环系统不稳定
  • 卡点：把幅值穿越频率与相位穿越频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过计算相角裕度并判断相对稳定性
