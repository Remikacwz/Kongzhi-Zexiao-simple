11、电路网络建模与传函#

思路
  • 对给定 RC 电路画出结构图并求输出对输入的传递函数
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由电路网络求传递函数
本卷实例
  • 关键一步：用复阻抗法把串并联关系写成电压比
  • 关键一步：再按回路电流关系画出结构图
  • 中间结果：传函分母是两电容两电阻组合成的二次多项式
  • 卡点：电路接法只画在题图里，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由电路网络求传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过把电容阻抗误写成Cs
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

22、二阶系统参数与动态指标设计#

思路
  • 由给定反馈系数求阻尼比、自然频率与斜坡稳态误差；再由指标要求反求参数并计算阶跃响应指标
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传递函数求阻尼比与自然频率
本卷实例
  • 关键一步：先把内部反馈化简成等效开环形式，再求闭环特征式
  • 关键一步：与二阶标准式比较系数得到阻尼比与自然频率
  • 中间结果：自然频率由闭环特征式常数项开方得到
  • 卡点：局部反馈只改变一次项系数，不能漏掉这一项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传递函数求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过忽略局部反馈系数对一次项系数的影响
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：先按开环型别写出速度误差系数的极限式
  • 关键一步：再由斜坡误差等于速度误差系数倒数得到结果
  • 中间结果：一型系统斜坡误差只由开环增益与一次项系数决定
  • 卡点：取极限前要先用劳斯判据确认闭环稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过把开环增益与速度误差系数当成同一个量
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与稳态误差要求反求参数并求上升时间
本卷实例
  • 关键一步：由超调量公式反解阻尼比
  • 关键一步：再由一次项系数关系与误差要求联立求两个参数
  • 中间结果：两个未知量由误差关系式与阻尼关系式联立定出
  • 卡点：上升时间公式中的反余弦项不要漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与稳态误差要求反求参数并求上升时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过调节时间使用的误差带没有注明
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

33、根轨迹与稳定增益范围#

思路
  • 对开环含二重原点极点的系统画根轨迹，求稳定增益范围，并由指定闭环极点用幅值条件求增益
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制以根轨迹增益为参变量的根轨迹
本卷实例
  • 关键一步：标出四个开环极点与一个零点并判断实轴段
  • 关键一步：再算渐近线方程与分离点方程
  • 中间结果：本题分离点方程在实轴段上没有满足条件的解
  • 卡点：求出的根要判断是否落在实轴根轨迹区间内
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制以根轨迹增益为参变量的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过分离点方程的根不代回检验
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

本卷考法

  • 本卷考过确定使系统稳定的增益范围
  • 求根轨迹与虚轴的交点及临界增益

44、由伯德图反求传函与相角裕度#

思路
  • 由低频段高度与谐振峰、谐振频率反求二阶对象传函并计算相角裕度
闭环频率特性与性能指标 频域分析
本卷考法
  • 由闭环谐振峰值与谐振频率反求阻尼比与自然频率
本卷实例
  • 关键一步：先由低频段高度读出开环增益
  • 关键一步：再由谐振频率公式与谐振峰值公式联立解出阻尼比与自然频率
  • 中间结果：谐振频率小于自然频率，二者只在阻尼比为零时相等
  • 卡点：修正后的对象参数要代回谐振曲线核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过由闭环谐振峰值与谐振频率反求阻尼比与自然频率
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 本卷考过阻尼比大于零点七零七时仍套用谐振峰值公式
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

稳定裕度 频域分析
本卷考法
  • 计算系统的相角裕度
本卷实例
  • 关键一步：先由幅值条件求出幅值穿越频率
  • 关键一步：再把该频率代入相角表达式求相角裕度
  • 中间结果：相角裕度等于一百八十度加上穿越频率处的相角
  • 卡点：相角表达式中的反正切项要按象限判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度

  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过判断状态反馈能否改变闭环传递函数并说明零极点对消
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 本卷考过把原传函直接约分当作可实现条件而忽略能控性
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

1010、非线性系统平衡点稳定性#

思路
  • 求给定非线性状态方程的平衡点并线性化，判断各平衡点的稳定性
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 用李雅普诺夫第一法分析平衡点稳定性
本卷实例
  • 关键一步：先令状态方程右端为零求出全部平衡点
  • 关键一步：再在平衡点处求雅可比矩阵并看特征值实部符号
  • 中间结果：正弦项使平衡点按kπ成组出现，需分奇偶讨论
  • 卡点：不同平衡点的稳定性不同，要分别给出结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过用李雅普诺夫第一法分析平衡点稳定性
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 本卷考过只分析原点而漏掉其他平衡点
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

本卷实例
  • 关键一步：线性化只反映平衡点小邻域内的稳定性
  • 中间结果：同一系统在部分平衡点稳定、部分不稳定属正常现象

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过说明非线性系统平衡态稳定性的特点
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 本卷考过把线性化结论推广到整个状态空间
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
