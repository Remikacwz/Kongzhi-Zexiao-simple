1一、结构图求传递函数#

思路
  • 由给定结构图求 C(s)/R₁(s)
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由结构图求指定输入到输出的传递函数
本卷实例
  • 关键一步：图中有多个输入时，只保留题目指定的那一个，其余输入一律置零
  • 关键一步：从指定输入到输出逐步化简，嵌套回路由内向外处理
  • 关键一步：化简比较点与引出点时注意支路上环节的位置变化
  • 中间结果：分母是系统特征式，与求其他输入到输出的传函时完全一致
  • 卡点：没有把其余输入置零；或把串联与反馈的等效顺序弄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由结构图求指定输入到输出的传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2二、由给定误差与扰动误差要求定参数#

思路
  • 对象含一个积分环节，串入比例微分环节，由给定输入的稳态误差与扰动输入的稳态误差要求反求两个增益
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由给定输入下的稳态误差要求反求开环增益
本卷实例
  • 关键一步：先数型别：开环含一个积分环节属 Ⅰ 型，斜坡输入下的稳态误差等于斜坡斜率除以速度误差系数
  • 关键一步：速度误差系数等于开环传函去掉一个 s 后取低频极限，本题结果恰好等于对象增益
  • 关键一步：把误差要求代入即可直接解出对象增益，校正装置的时间常数不影响这一项
  • 中间结果：本题给出斜坡输入的误差为一，解出的对象增益为一，是一个非常整齐的数
  • 卡点：把比例微分环节的增益也乘进速度误差系数；或未判稳就用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由给定输入下的稳态误差要求反求开环增益
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 由扰动作用下的稳态误差要求反求校正装置的时间常数
本卷实例
  • 关键一步：令参考输入为零，单独求扰动到误差的传递函数，注意扰动作用点在比较点之后还是之前
  • 关键一步：把扰动信号代入后取低频极限，得到扰动稳态误差的表达式
  • 关键一步：由不等式解出校正装置时间常数的取值范围，注意它出现在分子上时方向正好相反
  • 中间结果：扰动误差的表达式是对象增益与时间常数的组合，两者需同时满足给定输入的误差要求
  • 卡点：把扰动通道与给定通道的传函混用；或解不等式时方向写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过由扰动作用下的稳态误差要求反求校正装置的时间常数
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

3三、根轨迹与无超调增益范围#

思路
  • 对被控对象画根轨迹，求阶跃响应无超调时的增益范围，再由给定闭环极点求斜坡输入的稳态误差
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制增益由零到正无穷变化时的根轨迹
本卷实例
  • 关键一步：先把被控对象写成标准开环形式，标出全部零极点
  • 关键一步：按实轴段判据定出属于根轨迹的实轴区间，再算渐近线、分离点与虚轴交点
  • 关键一步：图上要标出分离点与虚轴交点对应的增益，这两个增益是后面两小问的依据
  • 中间结果：根轨迹的形状完全由开环零极点在实轴上的分布与相对阶数决定，本题需要先看清反馈接在哪
  • 卡点：被控对象只画在结构图里，正文未印，必须先回原卷核对对象传函再画
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制增益由零到正无穷变化时的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 确定使阶跃响应无超调的增益范围
本卷实例
  • 关键一步：无超调对应闭环极点全部落在实轴上，也就是根轨迹还没有离开实轴的那一段
  • 关键一步：这段范围的边界就是分离点对应的增益：增益小于它时所有闭环极点都是实根
  • 关键一步：分离点与虚轴交点之间的增益区间对应衰减振荡，要一并说清楚三段的区别
  • 中间结果：无超调并不等于稳定，增益很小时响应单调但很慢，增益很大时可能是单调发散
  • 卡点：把无超调当成稳定；或只给一个端点不写区间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过确定使阶跃响应无超调的增益范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

4四、含右半平面极点系统的幅相特性与稳定域#

思路
  • 开环含一个右半平面极点与一个零点，画幅相曲线，用奈氏判据分析增益与稳定性的关系，并画伯德图幅频特性
奈奎斯特判据 稳定性分析
本卷考法
  • 绘制开环幅相特性曲线并用奈奎斯特判据分析增益与稳定性的关系
本卷实例
  • 关键一步：先数开环右半平面极点：本题分母有一个 s 减一的因子，所以右半平面极点数为一个
  • 关键一步：求曲线穿过负实轴的位置：令相角等于负一百八十度解出频率
  • 关键一步：按包围圈数与右半平面极点数满足判据关系确定稳定所要求的增益范围
  • 关键一步：该频率处曲线与负实轴交点的坐标正比于增益
  • 中间结果：本题相角条件可化成两个反正切之和等于九十度，用正切乘积等于一可直接解出穿越频率
  • 中间结果：穿越点在负实轴上的坐标恰好等于增益，所以临界增益就是一，增益大于一时系统稳定
  • 卡点：忘记先数右半平面开环极点数，直接套最小相位系统的判据；或把穿越频率算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过绘制开环幅相特性曲线并用奈奎斯特判据分析增益与稳定性的关系
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
典型环节的对数频率特性 频域分析
本卷考法
  • 绘制伯德图的幅频特性曲线
本卷实例
  • 关键一步：先定低频段：分母含一个 s，斜率每十倍频程下降二十分贝
  • 关键一步：分子是一个一阶微分环节，经过它的转折频率时斜率上升二十分贝
  • 关键一步：按转折频率从小到大逐段改斜率，画完用高频段的斜率核对总斜率变化量
  • 关键一步：分母的 s 减一因子转折频率在正实数处，幅频仍按惯性环节处理
  • 中间结果：含右半平面极点时幅频特性与最小相位系统相同，相位特性才有差别，所以幅频图可以照常规画
  • 卡点：把右半平面极点当成不稳定环节在幅频上也做特殊处理；或忘记积分环节的低频斜率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例环节是水平线，积分与微分分别是 -20 与 +20 dB/dec 的斜线
  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec
  • 一阶微分环节与惯性环节幅频互为镜像
  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤
  • 把传递函数分解为典型环节乘积
  • 逐环节画出对数幅频渐近线与相频曲线
  • 代数相加得到总特性
通用考法
  • 本卷考过绘制伯德图的幅频特性曲线
  • 画出某一典型环节的 Bode 图
  • 由 Bode 图识别环节类型
  • 说明转角频率处的幅值与相角
常见易错
  • 把惯性环节高频渐近线的 -20 写成 -40
  • 振荡环节谐振峰位置误当作 ωn

5五、超前校正设计与最大裕度增益#

思路
  • 先按静态速度误差系数确定增益并算出未校正系统的截止频率与相角裕度，再设计串联超前校正；后半题用频率法求使相角裕度最大的增益
超前校正 系统校正
本卷考法
  • 按静态误差系数与相角裕度要求设计串联超前校正装置
本卷实例
  • 关键一步：静态速度误差系数要求直接给出开环增益，因为 Ⅰ 型系统的速度误差系数等于开环增益
  • 关键一步：画出原系统伯德图，求幅值穿越频率并写出相角裕度的计算表达式，判断是否满足要求
  • 关键一步：不满足时按需要的相角增量设计超前网络
  • 关键一步：先定最大超前角与两时间常数之比，再把最大超前角频率安放在新穿越频率
  • 中间结果：本题要求只写详细步骤不算具体结果，所以重点是流程完整、每一步的依据写清楚
  • 卡点：步骤里漏掉校验环节；或把最大超前角出现的频率错当成原系统的穿越频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过按静态误差系数与相角裕度要求设计串联超前校正装置
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性

  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断状态反馈前后与输出反馈后系统能控性、能观性的变化
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
