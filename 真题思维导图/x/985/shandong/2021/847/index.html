思路

本卷实例

  • 由信号流图求 C(s)/R(s)

  • 判断某条回路是否与给定前向通路接触

  • 不接触回路找漏或重复计数

3三、根轨迹绘制与幅值条件求增益#

思路
  • 对开环含二重原点极点的系统画根轨迹，由指定闭环极点用幅值条件求增益，再写出闭环零极点
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制以根轨迹增益为参变量的根轨迹
本卷实例
  • 关键一步：先标出全部开环零极点，按实轴段判据圈定根轨迹区间
  • 关键一步：再算渐近线、分离点与虚轴交点
  • 中间结果：分支数与渐近线条数由开环极点数减零点数决定
  • 卡点：渐近线夹角公式中的2k+1不要写成2k
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制以根轨迹增益为参变量的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹

  • 实轴段判据中的零极点个数算错

思路

开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制开环对数渐近幅频特性曲线
本卷实例
  • 关键一步：由积分环节个数定低频段斜率与起始高度
  • 关键一步：再按各转折频率从小到大逐段增减斜率
  • 中间结果：每经过一个转折频率都在原斜率上叠加加或减二十
  • 卡点：逐段改斜率应累加，不要每段重新起算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤

  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法

  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角

  • 逐段改斜率时忘记累加而非替换

奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅相曲线和右半平面极点数确定稳定增益范围
本卷实例

  • 中间结果：曲线穿过负实轴的位置随开环增益成比例移动

  • 由 Z=N+P 判断闭环稳定性

思路

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
