思路
  • 8个小题分别考控制系统三大要求、维纳控制论思想、前馈与反馈及复合系统、串级控制特点、积分饱和、频域典型输入、描述函数法、经典方法处理MIMO。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出设计控制系统时必须兼顾的三个方面
本卷实例
  • 关键一步：从稳定性、准确性与快速性三个维度归纳
  • 中间结果：三者相互制约，需按具体任务折中取舍
  • 卡点：只答其中一个方面；把快速性归入准确性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指出设计控制系统时必须兼顾的三个方面
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

反馈校正与复合控制 系统校正
本卷考法
  • 说明前馈与反馈各自特点及复合系统改善品质的原因
本卷实例
  • 关键一步：前馈按扰动预测补偿，反馈按偏差纠正
  • 中间结果：前馈补偿已知扰动提高精度，反馈弥补模型误差
  • 卡点：把前馈说成闭环；认为前馈能抑制未知扰动
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过说明前馈与反馈各自特点及复合系统改善品质的原因
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

串级控制系统 过程控制与检测仪表
本卷考法
  • 简述串级控制系统的特点与副回路的作用
本卷实例
  • 关键一步：副回路先抑制进入副环的扰动
  • 中间结果：主副回路分工提高抗扰能力与响应速度
  • 卡点：把副变量选成对主变量影响很小的量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 主回路完成主要指标，副回路快速抑制进入副回路的扰动
  • 副变量应包含尽可能多的剧烈扰动，且对主变量影响要大
  • 副回路要响应快于主回路，一般取主、副时间常数比大于 3
  • 可等效为改善了对象特性，提高了抗扰能力与响应速度
步骤
  • 判断扰动是否需要副回路专门抑制
  • 确定主变量与副变量
  • 说明主、副调节器的型式（一般主回路 PI、副回路 P 或 PI）
  • 画方框图并说明主副回路的信号关系
通用考法
  • 本卷考过简述串级控制系统的特点与副回路的作用
  • 设计串级控制系统并确定主、副变量
  • 说明副回路的作用与适用场合
  • 分析串级相比单回路的优越性
常见易错
  • 把副变量选成对主变量影响很小的量
  • 主副回路的时间常数不匹配，出现共振
PID 控制器与参数整定 系统校正
本卷考法
  • 从物理上解释积分饱和现象产生的原因
本卷实例
  • 关键一步：执行机构限幅使积分器持续累加偏差
  • 中间结果：输出饱和后偏差不能反向消除，退出迟缓
  • 卡点：把积分饱和说成比例增益过大所致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过从物理上解释积分饱和现象产生的原因
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

典型输入信号 基本概念与信号
本卷考法
  • 指出频域分析的典型输入信号并说明选用原因
本卷实例
  • 关键一步：选正弦信号，其频率特性与传函一一对应
  • 中间结果：正弦输入下稳态输出仍为正弦，便于扫描频段
  • 卡点：误答阶跃信号；混淆时域与频域典型输入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 常用典型输入有冲激、阶跃、斜坡、抛物线（加速度）与正弦五类
  • 阶跃信号用于考查快速性与稳定性，斜坡与抛物线用于考查稳态精度
  • 正弦信号用于频域分析，冲激响应就是系统的传递函数
  • 各典型信号的拉氏变换是分析全响应的起点
步骤
  • 按题意写出输入信号的时域表达式
  • 对输入取拉氏变换得到该信号的复域形式
  • 由输入类型判断考查的是动态性能还是稳态精度
  • 把输入代入误差或响应公式计算
通用考法
  • 本卷考过指出频域分析的典型输入信号并说明选用原因
  • 写出典型输入信号的拉氏变换
  • 说明某一典型输入信号用于考查哪类性能
  • 由输入类型判断稳态误差是否为有限值
常见易错
  • 把斜坡与抛物线信号的阶次写错
  • 阶跃的拉氏变换漏掉系数（幅度不为 1 时）

描述函数法基础 非线性系统
本卷考法
  • 说明描述函数法如何产生及其适用条件
本卷实例

  • 中间结果：用描述函数代替非线性环节再套频率法判自振
  • 卡点：把描述函数当成频率的函数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过说明描述函数法如何产生及其适用条件
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

三三、齐次状态方程的解12 分#

思路
  • 由状态方程与初始条件求矩阵指数，得到齐次解。
状态转移矩阵 状态空间分析
本卷考法
  • 由给定状态方程与初始条件求齐次状态方程的解
本卷实例
  • 关键一步：先求状态转移矩阵，再左乘初始状态
  • 中间结果：矩阵指数按状态矩阵的特征值结构展开
  • 卡点：矩阵求逆前不检查行列式是否为零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过由给定状态方程与初始条件求齐次状态方程的解
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错
公式

四四、结构图稳态误差约束求K范围13 分#

思路
  • 先由结构图求误差传递函数，再用终值定理把稳态误差表示为K的不等式。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 化简含局部反馈的结构图求闭环传递函数
本卷实例
  • 关键一步：由内到外逐层化简各回路
  • 中间结果：把回路化简结果代回总结构图
  • 卡点：化简内环时把外环信号当成常数处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过化简含局部反馈的结构图求闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由稳态误差上限反求开环增益K的取值范围
本卷实例
  • 关键一步：按输入为1(t)+2t确定型别与静态误差系数
  • 中间结果：由稳态误差不大于0.5列出K的不等式求交集
  • 卡点：未判稳就使用终值定理；漏掉阶跃分量
  • 卡点：结构以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
