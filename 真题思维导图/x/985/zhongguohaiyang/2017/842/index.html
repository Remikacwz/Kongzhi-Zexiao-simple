自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 用控制理论分析飞机在飞流中保持预定航向的原因
本卷实例
  • 关键一步：把航向控制看作带传感器与执行机构的闭环负反馈系统
  • 中间结果：气流扰动使航向产生偏差，控制器驱动舵面修正偏差
  • 卡点：把扰动直接当成输入；漏掉负反馈消除偏差这一环
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤

  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 画出并说明二阶系统闭环根的位置与单位阶跃响应曲线的关系
本卷实例
  • 关键一步：按阻尼比把闭环根分为欠阻尼、临界、过阻尼、无阻尼与负阻尼
  • 中间结果：左半平面共轭根对应衰减振荡；实根单调；虚轴等幅；右半平面发散
  • 卡点：把等幅振荡与发散振荡的根位置搞反；忘记负阻尼情形
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过画出并说明二阶系统闭环根的位置与单位阶跃响应曲线的关系
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

步骤

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性

奈奎斯特判据 稳定性分析
本卷考法
  • 与劳斯判据比较，说明奈奎斯特判据的特点
本卷实例
  • 关键一步：奈氏判据在频域用开环幅相曲线判断闭环稳定性
  • 中间结果：可判断稳定性并给出稳定裕度，适用于含延迟与高阶系统
  • 卡点：把奈氏判据也说成时域方法；漏掉稳定裕度信息
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过与劳斯判据比较，说明奈奎斯特判据的特点
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

劳斯判据 稳定性分析
本卷考法

本卷实例

  • 中间结果：劳斯判据给出稳定性充要条件但不直接给稳定裕度
  • 卡点：把两种判据适用的系统范围说反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过比较劳斯判据与奈氏判据的分析域与适用范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

2论述减小稳态误差的方法#

思路
  • 从提高开环增益、提高系统型别、采用复合控制三方面论述；前两种可能破坏稳定性，复合控制用前馈补偿既减小误差又不影响稳定性。
减小稳态误差的措施 稳态误差
本卷考法
  • 论述减小系统在给定信号或扰动信号下稳态误差的方法
本卷实例
  • 关键一步：从提高开环增益、提高系统型别、采用复合控制三方面归纳
  • 中间结果：前两种可能使系统不稳定；前馈补偿不影响反馈环稳定性
  • 卡点：只提高增益而不检查稳定性；漏掉前馈（复合控制）方案
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过论述减小系统在给定信号或扰动信号下稳态误差的方法
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
