自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 归纳控制科学研究的基本问题与分支（借位 bc_01）
本卷实例
  • 关键一步：从建模、分析、设计、实现、优化与验证归纳
  • 中间结果：控制科学横跨线性、非线性、鲁棒与智能等分支
  • 卡点：只堆技术名词，漏掉建模到验证的主线
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法

  • 说明检测变送元件在闭环系统中的作用

频率特性的物理意义与求法 频域分析
本卷考法

本卷实例

  • 中间结果：由开环频率响应曲线读取闭环稳定性与性能
  • 卡点：与Bode图、Nyquist图混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性

超前校正 系统校正
本卷考法
  • 判断PD校正的性质并列出其作用特点
本卷实例
  • 关键一步：由PD传递函数看出它提供正相角
  • 中间结果：提高截止频率与相角裕度、改善快速性
  • 卡点：把PD说成能消除稳态误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过判断PD校正的性质并列出其作用特点
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

减小稳态误差的措施 稳态误差
本卷考法
  • 列举减小给定与扰动稳态误差的常用措施
本卷实例
  • 关键一步：从提高型别、增大开环增益、前馈补偿入手
  • 中间结果：各项措施在精度与稳定性之间存在折中
  • 卡点：只答提高增益，不检查稳定性是否被破坏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过列举减小给定与扰动稳态误差的常用措施
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 谈对李雅普诺夫能量法判定稳定性的认识
本卷实例
  • 关键一步：构造正定V函数并考察其导数的定号性
  • 中间结果：无需求解微分方程即可判断平衡点稳定性
  • 卡点：只判断V正定而不检查其导数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过谈对李雅普诺夫能量法判定稳定性的认识
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

二二、频率法串联滞后校正的原理与步骤12 分#

思路
  • 按稳态误差定增益、频域选截止频率、再定滞后网络参数的顺序论述。
滞后校正 系统校正
本卷考法
  • 论述频率法串联滞后校正的原理与设计步骤
本卷实例
  • 关键一步：由稳态误差要求先确定开环增益K
  • 中间结果：按期望相角裕度选定校正后截止频率
  • 卡点：把滞后网络两个转折频率的顺序写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过论述频率法串联滞后校正的原理与设计步骤
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

状态转移矩阵 状态空间分析
本卷考法

本卷实例

  • 中间结果：反变换后写成状态转移矩阵与卷积积分之和
  • 卡点：卷积变量代换写错；漏掉直接传递项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法

  • 求状态转移矩阵

思路

状态空间表达式的建立 状态空间分析
本卷考法

本卷实例

  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统

  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du

能控性与能观性 状态空间分析
本卷考法
  • 用能控性判别矩阵判断登月舱模型是否完全能控
本卷实例
  • 关键一步：构造[B AB A²B]并判断其秩
  • 中间结果：矩阵秩小于状态维数，系统不完全能控
  • 卡点：只算到A^{n-2}B就下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
