本卷考法
  • 简述传递函数阵的最小实现判定方法
本卷实例
  • 关键一步：最小实现 = 既能控又能观的实现（维数最低）
  • 关键一步：先由传递函数阵写出任一实现，再做能控性与能观性分解
  • 关键一步：剔除不可控与不可观部分后剩下的就是最小实现
  • 关键一步：判据：实现 (A,B,C) 的能控性矩阵与能观性矩阵都满秩
  • 中间结果：最小实现维数由传递函数阵的 McMillan 阶数决定
  • 卡点：只答「能控能观」而不给判定方法（要做分解或算秩）
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观

  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型

本卷考法

  • 关键一步：低频高增益保精度、中频 -20dB/dec 保裕度、高频快衰减抗噪
  • 关键一步：再用期望特性减去未校正特性，得到校正装置特性

减小稳态误差的措施 稳态误差
本卷考法
  • 讨论内模原理与经典控制中一阶无静差控制的区别与联系
本卷实例
  • 关键一步：联系：两者都靠「在控制器里内嵌输入信号的模型」实现无差
  • 关键一步：积分环节 1/s 就是阶跃信号的内模
  • 关键一步：区别：内模原理是一般性结论，可推广到正弦等周期信号
  • 关键一步：一阶无静差只是它在阶跃输入下的特例
  • 关键一步：内模原理要求模型精确已知，鲁棒性需另外讨论
  • 中间结果：内模原理适用于任意可建模的周期参考信号，不限于阶跃
  • 卡点：只说「都是积分」而讲不出一般与特例的关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过讨论内模原理与经典控制中一阶无静差控制的区别与联系
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

串联、并联与反馈等效 结构图与方框图
本卷考法
  • 简述反馈控制的优缺点
本卷实例
  • 关键一步：优点：抑制参数漂移与扰动、提高精度、降低对元件精度的要求、改善动态性能
  • 关键一步：缺点：可能引入不稳定、结构复杂成本高、对检测元件精度要求高、存在传感器噪声问题
  • 中间结果：反馈用高增益换取精度，代价是稳定性裕度下降与成本上升
  • 卡点：只列优点不列缺点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法

  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

传递函数的定义与基本性质 传递函数
本卷考法
  • 简述能用传递函数描述的系统具有什么特点
本卷实例
  • 关键一步：线性、定常（时不变）、单输入单输出（或可分离为多个 SI/SO）、零初始条件
  • 关键一步：只能反映输入输出关系，不能反映内部状态
  • 中间结果：前提是线性定常且零初始条件；多输入多输出要用传递函数阵
  • 卡点：漏掉「单输入单输出」或「零初始条件」这两个限制
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过简述能用传递函数描述的系统具有什么特点
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

能控性与能观性 状态空间分析
本卷考法
  • 状态能控性与系统能控性有何区别
本卷实例
  • 关键一步：状态能控性：能否用输入把任意初态在有限时间内驱动到原点（这是标准定义）
  • 关键一步：系统能控性（输出能控性）：能否用输入使「输出」达到任意期望值——比状态能控性弱
  • 关键一步：关系：状态能控 ⇒ 输出能控，反之不成立
  • 中间结果：输出能控只要求输出达到期望值，不要求内部状态可控
  • 卡点：把两者当成同一回事；或把「输出能控」说成「能控」的加强
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过状态能控性与系统能控性有何区别
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

状态空间与传递函数的关系 状态空间分析
本卷考法
  • 简述状态空间方程的非奇异线性变换对系统特征的影响
本卷实例
  • 关键一步：非奇异线性变换是相似变换，「特征值（特征多项式）保持不变」
  • 关键一步：传递函数矩阵、能控性、能观性、稳定性也都不变
  • 关键一步：变化的只是状态变量的物理含义与 A、B、C 的具体数值
  • 中间结果：变换矩阵 P 需非奇异；P 奇异则不是相似变换、特征值会变
  • 卡点：答成「特征值改变」——那就把相似变换与一般变换混了
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过简述状态空间方程的非奇异线性变换对系统特征的影响
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差

本卷考法
  • 用李雅普诺夫稳定性定理证明阻尼弹簧-质量块系统渐近稳定
本卷实例
  • 关键一步：取状态 x₁=q、x₂=q̇，用总机械能作李雅普诺夫函数
  • 关键一步：V=½mq̇²+½kq² 正定
  • 关键一步：求 V̇=mq̇q̈+kqq̇=q̇(mq̈+kq)=q̇(−cq̇)=−cq̇²，负半定
  • 关键一步：V̇=−cq̇² 只在 q̇=0 时为零，要用拉萨尔不变集原理
  • 关键一步：q̇≡0 时由方程得 q≡0，故零是唯一的极限点
  • 关键一步：⇒ 系统渐近稳定；又因 V 径向无界 ⇒ 大范围渐近稳定
  • 中间结果：V̇ 是负半定而不是负定，这一步必须用拉萨尔不变集原理补，不能直接下结论
  • 卡点：V̇ 负半定时直接说「渐近稳定」——逻辑上缺一步，证明题会扣分

  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定

8根轨迹绘制与附加零点的影响#

思路
  • G(s)=kg/(s²(s+2))，按绘制法则画180°根轨迹并由虚轴交点判断稳定性；再加开环零点 s=−1，比较根轨迹走向与稳定性的变化。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制 kg/(s²(s+2)) 的根轨迹并判断稳定性
本卷实例
  • 关键一步：由开环极点与原点重极点确定实轴段、渐近线与分离点
  • 中间结果：三条渐近线的交点与夹角由极点分布算出
  • 卡点：原点为重极点，实轴段与分离点的判断与单极点情形不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制 kg/(s²(s+2)) 的根轨迹并判断稳定性
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
