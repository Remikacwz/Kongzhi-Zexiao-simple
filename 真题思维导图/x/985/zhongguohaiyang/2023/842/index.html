自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 说明控制系统的稳定性与鲁棒性的区别（题面 OCR 作「想定性」，借位 bc_01）
本卷实例
  • 关键一步：稳定性指受扰后能否回到平衡态；鲁棒性指参数或环境变化时能否保持性能
  • 中间结果：稳定性关注平衡点的恢复能力，鲁棒性关注变化条件下的适应能力
  • 卡点：把两者混为一谈；或只描述稳定性而漏掉鲁棒性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过说明控制系统的稳定性与鲁棒性的区别（题面 OCR 作「想定性」，借位 bc_01）
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
零极点分布与响应模态 传递函数
本卷考法
  • 简述传递函数零点与极点对单位阶跃响应的影响规律
本卷实例
  • 关键一步：极点决定响应模态与稳定性，零点改变各模态的权重
  • 中间结果：靠近虚轴的极点响应慢或易振荡；零点增大超调、加快初始上升
  • 卡点：只说零点加快响应而不提它可能带来的超调与振荡
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过简述传递函数零点与极点对单位阶跃响应的影响规律
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

传递函数的定义与基本性质 传递函数
本卷考法
  • 说明为什么只有线性定常系统才有传递函数
本卷实例
  • 关键一步：传函由拉氏变换定义，要求系统满足线性性与定常性且为零初始条件
  • 中间结果：非线性或时变系统无法用一个固定传函描述输入输出关系
  • 卡点：只答「线性」漏掉「定常」与零初始条件两个前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过说明为什么只有线性定常系统才有传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 从根轨迹角度分析高增益控制对单位反馈系统性能的影响
本卷实例
  • 关键一步：看根轨迹随增益增大时闭环极点的移动方向与是否穿越虚轴
  • 中间结果：增益增大响应加快；但极点进入右半平面后系统不稳定、超调增大
  • 卡点：只答「增益越大越好」而忽略稳定性被破坏的临界增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过从根轨迹角度分析高增益控制对单位反馈系统性能的影响
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

串级控制系统 过程控制与检测仪表
本卷考法
  • 简述在何种情形下应用串级控制
本卷实例
  • 关键一步：被控对象滞后大、存在较强扰动或副变量可测时，引入主副两个回路
  • 中间结果：副回路快速抑制进入副环的扰动，主回路保证主变量精度
  • 卡点：把主、副变量选反；或忽略副回路应选响应快的中间变量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 主回路完成主要指标，副回路快速抑制进入副回路的扰动
  • 副变量应包含尽可能多的剧烈扰动，且对主变量影响要大
  • 副回路要响应快于主回路，一般取主、副时间常数比大于 3
  • 可等效为改善了对象特性，提高了抗扰能力与响应速度
步骤
  • 判断扰动是否需要副回路专门抑制
  • 确定主变量与副变量
  • 说明主、副调节器的型式（一般主回路 PI、副回路 P 或 PI）
  • 画方框图并说明主副回路的信号关系
通用考法
  • 本卷考过简述在何种情形下应用串级控制
  • 设计串级控制系统并确定主、副变量
  • 说明副回路的作用与适用场合
  • 分析串级相比单回路的优越性
常见易错
  • 把副变量选成对主变量影响很小的量
  • 主副回路的时间常数不匹配，出现共振
反馈校正与复合控制 系统校正
本卷考法
  • 说明什么是两自由度控制及其适用情况（借位 cr_06）
本卷实例
  • 关键一步：用两个独立控制器分别调节参考信号跟踪与扰动抑制
  • 中间结果：跟踪性能与抗扰性能可分别整定，避免单回路中两者互相牵制
  • 卡点：把两自由度控制当成两个独立反馈回路，忽略两条通道的分工
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过说明什么是两自由度控制及其适用情况（借位 cr_06）
  • 设计反馈校正装置改善被包围环节

  • 分析复合控制对稳态误差的作用
常见易错

  • 忽略反馈校正可能引起的高频噪声放大

  • 中间结果：状态最优滤波器可看作在噪声下按最优准则确定观测器增益

2原点有三个极点的闭环系统稳定性论述#

思路
  • 从幅相曲线与根轨迹两个角度说明：原点三个极点使低频相位迅速滞后，系统只能在某段增益区间内条件稳定，否则不稳定。
奈奎斯特判据 稳定性分析
本卷考法
  • 论述开环传函在原点有三个极点时闭环系统为何要么不稳定、要么条件稳定
本卷实例
  • 关键一步：原点三个极点使低频段相位迅速滞后，幅相曲线先进入不稳定区再穿出
  • 中间结果：闭环稳定只在某段增益区间成立，增益过小或过大都不稳定
  • 卡点：把「条件稳定」说成「无条件稳定」；忽略 Nyquist 判据的 P 与包围数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过论述开环传函在原点有三个极点时闭环系统为何要么不稳定、要么条件稳定
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴的交点确定临界增益并判断稳定区间
本卷实例
  • 关键一步：令 s 等于 jω 代入特征方程，实部虚部分别为零求交点与临界增益
  • 中间结果：根轨迹穿越虚轴的两个方向对应稳定区间的两端
  • 卡点：只代一个 ω 就下结论，漏掉另一组交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹与虚轴的交点确定临界增益并判断稳定区间
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

3结构框图求闭环传递函数#

思路
  • 由多回路结构框图逐层化简求 C(s)/R(s)；若 F(s) 不为零，再分别求扰动通道传函并按线性叠加。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由结构框图求闭环传递函数 C(s)/R(s)（F(s) 等于零时）
本卷实例
  • 关键一步：从内环到外环逐层化简，把并联与反馈支路逐一合并
  • 中间结果：内环化简后的等效环节再代入外环，得到总闭环传函
  • 卡点：结构框图为原卷插图，回路连接与比较点极性需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
