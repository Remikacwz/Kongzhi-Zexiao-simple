思路
  • 8个小题分别考正负反馈的区分与负反馈的意义、相对稳定性指标、二次型最优控制、延迟环节为何是无穷阶系统、积分控制的作用与局限、状态反馈与观测器能否分开设计、串联超前校正的核心、消除非线性自激振荡。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 如何区分正、负反馈，并说明负反馈为何是自动控制系统的重要环节（借位 bd_01）
本卷实例
  • 关键一步：按反馈信号与输入信号极性是否相反、是否减小偏差区分正负反馈
  • 中间结果：负反馈减小偏差，改善稳定性、精度与抗扰能力；正反馈增大偏差
  • 卡点：只按「加号减号」判断而不看反馈对误差的作用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过如何区分正、负反馈，并说明负反馈为何是自动控制系统的重要环节（借位 bd_01）
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

稳定裕度 频域分析
本卷考法
  • 列出刻画系统相对稳定性的指标并简述含义
本卷实例
  • 关键一步：相对稳定性用相角裕度与幅值裕度两个指标衡量
  • 中间结果：相角裕度是增益交界频率处相位距负实轴的余量
  • 卡点：把相角裕度与幅值裕度的定义与对应频率点用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过列出刻画系统相对稳定性的指标并简述含义
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

  • 卡点：把黎卡提方程中各项顺序写错，或只提指标不提求解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 加权阵对状态惩罚越重，闭环响应越快、控制量越大
  • 无限时间问题中黎卡提方程取稳态解

  • 校验闭环稳定性与加权阵的对称正定性

  • 解黎卡提方程求反馈增益阵
  • 分析加权阵变化对响应快慢与控制量的影响
常见易错

典型环节及其特性 传递函数
本卷考法
  • 说明延迟环节的传递函数为何是阶次无穷大的线性正常系统
本卷实例
  • 关键一步：把 e 的负 τs 次幂展开成关于 s 的无穷级数
  • 中间结果：级数含 s 的各阶项，故可视为阶次无穷大的线性环节
  • 卡点：把延迟环节当成有限阶的有理传递函数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过说明延迟环节的传递函数为何是阶次无穷大的线性正常系统
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减

PID 控制器与参数整定 系统校正
本卷考法
  • 说明引入积分控制的目的以及积分控制能否单独使用
本卷实例
  • 关键一步：积分项对误差累积，稳态时提供恒定输出以消除稳态误差
  • 中间结果：单独积分会带来响应慢、易振荡；工程上常与比例、微分配合
  • 卡点：认为积分可以单独使用且不牺牲动态性能
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过说明引入积分控制的目的以及积分控制能否单独使用
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错

  • 积分增益过大导致系统振荡甚至不稳定

通用考法

本卷实例

  • 中间结果：同时需保证不引入过大超调、振荡与高频噪声
  • 卡点：只答「提高相角裕度」而漏掉截止频率选取这一核心
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过说明串联超前校正的核心问题
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

2根轨迹角度分析开环零点与极点对系统品质的影响#

思路
  • 论述开环零极点决定闭环极点运动轨迹，从而影响稳定性、快速性、超调与阻尼；结合根轨迹法则说明零点左移、极点右移的不同效果。
附加开环零极点的影响 根轨迹法
本卷考法
  • 从根轨迹角度分析开环零点、极点对系统品质的影响
本卷实例
  • 关键一步：零点使根轨迹左移并吸引极点，极点使根轨迹右移并排斥
  • 中间结果：合适配置零点可改善稳定性与快速性，附加极点一般降低裕度
  • 卡点：只看渐近线是否移动，忽略分离点与出射角的改变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过从根轨迹角度分析开环零点、极点对系统品质的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 结合根轨迹说明开环零极点变化对动态性能的影响
本卷实例
  • 关键一步：由闭环极点在 s 平面上的位置估算超调与调节时间
  • 中间结果：极点离虚轴越远响应越快；阻尼角决定超调大小
  • 卡点：由极点位置估指标时忽略零点对超调的放大作用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过结合根轨迹说明开环零极点变化对动态性能的影响
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

8含库伦摩擦系统的相平面与稳态误差#

思路
  • 由摩擦力方向把运动方程分两段，在误差相平面上分别积分画相轨迹；再由死区内运动停止的条件求稳态误差。
相平面法 非线性系统
本卷考法
  • 在误差相平面上绘制含库伦摩擦系统的相轨迹
本卷实例
  • 关键一步：按摩擦力的正负把运动方程分成两段，分别积分得相轨迹
  • 中间结果：两段相轨迹在横轴上的两个平衡点附近终止
  • 卡点：摩擦力方向与运动方向的关系；相轨迹图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过在误差相平面上绘制含库伦摩擦系统的相轨迹
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求库伦摩擦系统在阶跃输入下的稳态误差
本卷实例
  • 关键一步：死区内输出不变，稳态由摩擦力与输入的关系确定
  • 中间结果：死区内误差取决于初始偏差是否落在死区范围内
  • 卡点：忽略死区使小偏差时系统不再运动这一非线性特征
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求库伦摩擦系统在阶跃输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
