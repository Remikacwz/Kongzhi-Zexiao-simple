传递函数的定义与基本性质 传递函数
本卷考法
  • 为什么物理性质不同的系统传递函数可能相同，并举例说明（借位 tf_01）
本卷实例
  • 关键一步：从传递函数只由系统结构与参数决定、不反映物理结构入手
  • 中间结果：RLC电网络与弹簧阻尼机械系统可选参数使其二阶传递函数相同
  • 卡点：误以为传递函数能唯一反映物理结构；只答结论不举例
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过为什么物理性质不同的系统传递函数可能相同，并举例说明（借位 tf_01）
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

频率特性的物理意义与求法 频域分析
本卷考法
  • 说明如何用实验方法求取系统的频率特性函数
本卷实例
  • 关键一步：用信号发生器逐点加正弦激励，示波器采集稳态输入输出
  • 中间结果：改变频率测幅值比与相位差，即得幅频与相频特性
  • 卡点：必须在稳态下测量；漏掉逐点变频这一过程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过说明如何用实验方法求取系统的频率特性函数
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

典型非线性特性及其影响 非线性系统
本卷考法
  • 描述典型非线性环节中的滞环（齿隙）特性
本卷实例
  • 关键一步：滞环的正反向特性不重合，输入输出曲线围成一闭合回路
  • 中间结果：该特性增大稳态误差、加剧振荡，甚至导致系统不稳定
  • 卡点：把滞环与死区、饱和特性混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 饱和特性降低等效增益，可能引起系统不稳定或自振
  • 死区特性使小信号时增益为零，产生稳态误差
  • 间隙特性引起相位滞后，导致波形畸变与自振
  • 继电特性使系统出现持续振荡并可能产生颤振
步骤
  • 识别非线性环节类型
  • 写出其描述函数或分段数学表达式
  • 分析其对等效增益与稳定性的影响
通用考法
  • 本卷考过描述典型非线性环节中的滞环（齿隙）特性
  • 分析饱和或死区对系统性能的影响
  • 求典型非线性的描述函数表达式
  • 说明间隙为何容易引起自振
常见易错
  • 认为饱和总是使系统更稳定
  • 忽略死区在原点附近造成的小信号失效

校正的基本概念与性能指标 系统校正
本卷考法
  • 比较有源与无源校正装置的特点，并说明作用是否相同
本卷实例
  • 关键一步：从有无放大器、输入输出阻抗、增益与稳定性三方面对比
  • 中间结果：无源网络只衰减且阻抗不匹配；有源网络增益可调但特性易漂移
  • 卡点：误以为有源与无源校正实现的校正规律不能相同

  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图

  • 把时域指标折算为频域指标

泛函极值与变分法 最优控制
本卷考法
  • 列举经典最优控制设计方法之一：古典变分法
本卷实例
  • 关键一步：把最优控制问题化为泛函极值问题
  • 中间结果：用欧拉-拉格朗日方程与横截条件求极值函数
  • 卡点：边界条件多于两个时漏掉导数端点条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 泛函的极值由欧拉-拉格朗日方程给出，它是变分法的基本必要条件
  • 被积函数不显含自变量时可用首次积分降阶
  • 端点固定的横截条件由给定的边界条件直接给出
步骤
  • 写出被积函数（含状态量、状态量的导数、自变量）
  • 代入欧拉-拉格朗日方程并化简
  • 对被积函数不显含自变量的情形改用首次积分降阶
  • 代入两端边界条件定积分常数，得到极值函数
通用考法
  • 本卷考过列举经典最优控制设计方法之一：古典变分法
  • 求给定泛函在给定边界条件下的极值函数
  • 写出欧拉-拉格朗日方程并化简
  • 说明横截条件的作用
常见易错
  • 边界条件有多个时只用两个，漏掉导数的端点条件
  • 含高阶导数的泛函仍套一阶的欧拉方程

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 协态方程与横截条件由哈密顿函数分别对状态量和终端条件给出
  • 终端自由时横截条件要求终端协态为零

  • 写出协态方程与边界条件，与状态方程联立
  • 求状态与协态的解析解，再回代得最优控制与最优轨线

动态规划与离散最优控制 最优控制
本卷考法
  • 列举经典最优控制设计方法之三：动态规划
本卷实例
  • 关键一步：按贝尔曼最优性原理从终端向前倒推
  • 中间结果：逐拍比较代价函数，得各拍最优控制与最优轨线
  • 卡点：倒推时漏掉当前拍的阶段代价或二次项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离散最优控制按拍倒推，每一拍都把当前代价与剩余代价一起优化
  • 最优性能指标可写成状态二次型的形式，递推求出系数矩阵
  • 最优控制是状态的线性反馈，反馈系数由递推关系逐拍确定
步骤
  • 写出状态方程与性能指标，确认终端项与阶段代价的形式
  • 从最后一拍开始倒推，求该拍的代价函数与最优控制
  • 把结果代入前一拍继续倒推，直到初始拍
  • 得到各拍的最优控制后，沿状态方程正向递推求出最优轨线
通用考法
  • 本卷考过列举经典最优控制设计方法之三：动态规划
  • 用动态规划法求各拍的最优控制与最优轨线
  • 写出倒推过程中的代价函数与最优控制表达式
  • 由给定初值计算最优控制的数值
常见易错
  • 倒推时漏掉当前拍的阶段代价或被控量二次项
  • 求最优控制时忘记把下一拍的状态用状态方程代入当前拍的表达式

广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 说明研究参数根轨迹的意义
本卷实例
  • 关键一步：参数根轨迹研究除开环增益外其他参数变化时闭环极点的移动
  • 中间结果：常规根轨迹只以增益为变量，参数根轨迹可研究时间常数等
  • 卡点：把参数根轨迹与常规根轨迹的变量混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过说明研究参数根轨迹的意义
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

2论述闭环零点极点与性能指标的关系15 分#

思路
  • 从稳定性、动态性能、响应形式三方面说明闭环极点决定响应模态与衰减快慢；闭环零点决定各模态权重并影响超调；再用主导极点与偶极子说明高阶系统的近似。
零极点分布与响应模态 传递函数
本卷考法
  • 论述闭环极点、零点与系统性能指标之间的关系
本卷实例
  • 关键一步：极点位置决定响应模态与衰减速率，零点改变各模态的权重
  • 中间结果：左半平面极点稳定；极点越靠左衰减越快；零点使峰值提前、超调增大
  • 卡点：只讨论极点而忽略闭环零点对超调量的放大作用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过论述闭环极点、零点与系统性能指标之间的关系
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
