描述函数法基础 非线性系统
本卷考法
  • 说明描述函数法与频率特性的关系，解释为什么说频率特性是描述函数法的特例
本卷实例
  • 关键一步：描述函数法只取非线性环节输出的基波分量作等效线性化
  • 中间结果：在正弦输入下等效所得频率特性即描述函数，故频率特性是其特例
  • 卡点：把描述函数当成频率的函数；忽略只取基波这一前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振

滞后校正 系统校正
本卷考法
  • 从抑制高频噪声角度比较各校正形式，说明应选哪种
本卷实例
  • 关键一步：串联滞后校正降低系统高频段增益
  • 中间结果：高频衰减使高频干扰被抑制，且中高频相位基本不变
  • 卡点：把超前校正说成抗噪声好（超前会抬高高频增益）
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过从抑制高频噪声角度比较各校正形式，说明应选哪种
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

传递函数的定义与基本性质 传递函数
本卷考法
  • 由 Y(s)=G(s)U(s) 说明传递函数是否与输入输出有关
本卷实例
  • 关键一步：传递函数在零初始条件下定义为输出与输入拉氏变换之比
  • 中间结果：它只由系统自身结构与参数决定，与输入输出的形式无关
  • 卡点：从表达式含 U(s) 误以为传递函数随输入改变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由 Y(s)=G(s)U(s) 说明传递函数是否与输入输出有关
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

步骤

非线性系统的特点 非线性系统
本卷考法
  • 解释自激振荡，说明它与输入的关系以及线性系统能否发生
本卷实例
  • 关键一步：自激振荡是不加外激励而自行产生的持续等幅振荡
  • 中间结果：与输入无关；是非线性系统特有，线性系统不会自激振荡
  • 卡点：认为线性系统在无输入时也会自激振荡
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过解释自激振荡，说明它与输入的关系以及线性系统能否发生
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定

线性二次型最优控制 最优控制
本卷考法
  • 将二次型性能指标与经典理论性能指标作对比分析
本卷实例
  • 关键一步：二次型指标由状态与控制输入的二次型积分构成，需用优化方法设计
  • 中间结果：经典指标直接描述超调、上升时间、稳态误差等动态响应特性
  • 卡点：把二次型指标与经典性能指标混为一谈，忽略优化方式的差别

  • 加权阵对状态惩罚越重，闭环响应越快、控制量越大

3时不变矩阵微分方程的求解证明14 分#

思路
  • 把方程写成 ẋ−Ax−xAᵀ=0，构造 e^{−At}x(t)e^{−Aᵀt} 并求导，证明其恒为零即该组合为常值矩阵，再由初值定常数得解。
状态转移矩阵 状态空间分析
本卷考法
  • 证明时不变矩阵微分方程 ẋ=Ax+xAᵀ 的解为 e^{At}P₀e^{Aᵀt}
本卷实例
  • 关键一步：构造 e^{−At}x(t)e^{−Aᵀt}，对 t 求导并代入原方程
  • 中间结果：导数恒为零，说明该组合为常值矩阵 C；由 x(0)=P₀ 得 C=P₀
  • 卡点：漏掉左乘 e^{−At}、右乘 e^{−Aᵀt} 这一步；乘积求导遗漏项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过证明时不变矩阵微分方程 ẋ=Ax+xAᵀ 的解为 e^{At}P₀e^{Aᵀt}
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错

本卷实例
  • 关键一步：由 φ(s)=G/(1+G) 解出 G(s)=φ/(1−φ)
