考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 写出协态方程与边界条件，与状态方程联立
  • 求状态与协态的解析解，再回代得最优控制与最优轨线

思路

频率特性的物理意义与求法 频域分析
本卷考法
  • 论述频率响应法的物理含义、工具与应用
本卷实例
  • 关键一步：把正弦稳态响应的幅值与相位看作频率的函数
  • 中间结果：Bode图、Nyquist图与尼柯尔斯图各有适用场合
  • 卡点：把频率响应法当成能精确分析任意非线性系统
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过论述频率响应法的物理含义、工具与应用
  • 求给定传递函数的幅频与相频表达式

  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
