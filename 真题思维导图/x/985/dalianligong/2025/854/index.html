1一、电路网络求传递函数#

思路
  • 由运放或 RC 网络求 Uo(s)/Ui(s)
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由电路结构列写方程并求传递函数
本卷实例
  • 关键一步：先用复阻抗把电容写成电容与 s 乘积的倒数，电阻保持原值，把电路化成纯代数网络
  • 关键一步：有源网络要利用运放虚短虚断，把同相端与反相端的电位关系写成方程
  • 关键一步：多级网络逐级写出输入输出关系再相乘，注意每级的负载效应是否已被后级输入阻抗隔离
  • 中间结果：整理结果时把分子分母都写成 s 的多项式，便于核对量纲与时间常数
  • 卡点：逐级相乘时忽略级间负载；或把运放反相端带来的负号丢掉
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由电路结构列写方程并求传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 求由电路构成的系统的传递函数
本卷实例
  • 关键一步：列节点电流方程或回路电压方程，消去中间电流与中间电压
  • 关键一步：把结果化成输出比输入的比值，再按时间常数归一化
  • 关键一步：可用低频与高频的极限行为自检：低频看电容开路、高频看电容短路
  • 中间结果：若结果是两个时间常数的比，说明该网络是一个一阶环节或比例加惯性环节
  • 卡点：消元时漏掉某个支路；或电容的频率特性方向写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过求由电路构成的系统的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

2二、由信号传递关系画结构图并求传递函数#

思路
  • 题目给出一组信号传递关系式，要求画结构图并求 C(s)/R(s)
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由信号传递关系式画出系统结构图
本卷实例
  • 关键一步：每个中间变量对应结构图中的一个节点，等式右端的每一项对应一条进入该节点的支路
  • 关键一步：带负号的项表示该支路进入比较点时取负号，来自输出的反馈项要从输出节点引回来
  • 关键一步：按 R 到 C 的方向从左到右排列节点，逐式搭出方框与比较点，再补上引出点
  • 中间结果：搭完后数一数比较点个数应与等式个数一致，引出点个数应与被多处引用的信号个数一致
  • 卡点：把反馈支路接在中间节点而不是输出节点；或比较点的正负号写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由信号传递关系式画出系统结构图
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由画出的结构图求闭环传递函数 C(s)/R(s)
本卷实例
  • 关键一步：先识别回路：图中有多层嵌套时，从最内层开始逐层化简，每化简一层就重画一次
  • 关键一步：也可以先按信号流图列回路与前向通道，再用梅森公式一步写出结果
  • 关键一步：化简过程中保持分母是同一个特征式，可以用来检查是否漏回路
  • 中间结果：分母的次数应与系统阶数一致，分子次数不高于分母次数
  • 卡点：从外层往里化简导致重复计入回路；或把比较点与引出点移动时忘记改变支路位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由画出的结构图求闭环传递函数 C(s)/R(s)
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

3三、由阶跃响应反求对象并算全指标#

思路
  • 由 G₁ 的单位阶跃响应反求其传函，再求稳态输出、超调量、峰值时间、调节时间、稳态误差，并设计前馈补偿消扰动
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应反求传递函数
本卷实例
  • 关键一步：响应为常数乘一减指数的形式，说明 G₁ 是一阶环节，指数上的系数就是时间常数的倒数
  • 关键一步：系数乘数就是直流增益，可由响应终值直接读出
  • 关键一步：反求出的传函代回结构图，才能继续算闭环指标
  • 中间结果：本题响应为二乘一减指数形式，时间常数为三分之一秒、直流增益为二
  • 卡点：把指数上的系数当时间常数；或把系数乘数当成闭环增益而不是环节增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应反求传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求超调量、峰值时间与调节时间
本卷实例
  • 关键一步：先把闭环传函化成标准二阶形式读出阻尼比与自然频率
  • 关键一步：超调量只由阻尼比决定，峰值时间与调节时间还要用到自然频率
  • 关键一步：调节时间按百分之五误差带取三点五除以阻尼比与自然频率的乘积
  • 中间结果：若闭环存在闭环零点，超调量会比同阻尼比的纯二阶系统更大，读图核对时要注意
  • 卡点：百分二与百分五误差带的系数用混；或忘记零点对超调量的放大作用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求超调量、峰值时间与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求阶跃输入下的稳态输出与稳态误差
本卷实例
  • 关键一步：稳态输出由闭环传函的直流增益乘输入幅值给出，误差等于输入稳态值减输出稳态值
  • 关键一步：若误差取在输入端，阶跃输入下稳态误差为零的条件是开环至少含一个积分环节
  • 关键一步：输出端的稳态误差与输入端的误差定义不同，要看题目问的是哪一个
  • 中间结果：本题输入为十倍的阶跃信号，输出稳态值可按直流增益直接算，再做差得误差
  • 卡点：把输出稳态值直接当成误差；或未判稳就用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求阶跃输入下的稳态输出与稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
反馈校正与复合控制 系统校正
本卷考法
  • 扰动可测时设计前馈补偿装置消除扰动对输出的影响
本卷实例
  • 关键一步：令参考输入为零，写出扰动到输出的两条支路：一条经对象、一条经补偿装置
  • 关键一步：完全不变性条件是两条支路的传函之和为零，解出补偿装置的传函
  • 关键一步：把补偿装置接到扰动信号引出点与比较点之间，画出带前馈支路的结构图
  • 中间结果：前馈补偿只改变扰动通道，不进入闭环特征方程，所以不影响稳定性
  • 卡点：求补偿装置时没有把参考输入置零；或补偿器不可实现仍直接采用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过扰动可测时设计前馈补偿装置消除扰动对输出的影响
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
公式

4四、调节器变化对根轨迹与响应的影响#

思路
  • 同一被控对象分别配比例调节器与比例微分调节器，画根轨迹、求衰减振荡的增益范围并比较优缺点
根轨迹的绘制法则 根轨迹法
本卷考法
  • 以调节器增益为变量绘制根轨迹
本卷实例
  • 关键一步：把调节器参数提到标准位置写成一加参数乘等效开环传函的形式
  • 关键一步：标出等效开环的零极点后判断实轴段、算渐近线与分离点
  • 关键一步：分离点处的增益对应衰减振荡与单调衰减的分界，实轴段之外的分支进入复平面后开始振荡
  • 中间结果：比例微分调节器会给等效开环增加一个零点，使根轨迹整体左移
  • 卡点：把调节器与被控对象的位置弄反；或求衰减振荡范围时没有把分离点对应的增益算出来
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过以调节器增益为变量绘制根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 确定使闭环阶跃响应为衰减振荡的增益范围
本卷实例
  • 关键一步：衰减振荡对应闭环存在共轭复数极点且实部为负，也就是根轨迹离开实轴之后、穿越虚轴之前的那一段
  • 关键一步：这个范围的下界由分离点处的增益给出，上界由根轨迹与虚轴交点处的增益给出
  • 关键一步：算完后要用阻尼比是否落在零到一之间再核对一次
  • 中间结果：增益在分离点以下时响应单调无振荡，超过虚轴交点后系统失稳
  • 卡点：只给上下界中的一个；或把虚轴交点处的增益与分离点处的增益弄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过确定使闭环阶跃响应为衰减振荡的增益范围

10十、由对数幅频特性反求校正前后传函#

思路

由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频特性曲线求校正前后的开环传递函数与截止频率
本卷实例
  • 关键一步：两条曲线都是渐近线形式，先分别读出低频段斜率与高度，定出型别与增益
  • 关键一步：再按各转折频率处斜率的变化量判断环节类型，逐段写出传函
  • 关键一步：截止频率就是曲线与零分贝线交点的频率，两条曲线分别读一次
  • 中间结果：校正装置本身的传函可由校正前后传函相除得到，也可由校正特性曲线单独读出，两种算法互为校验
  • 卡点：两条曲线混淆，把校正装置的转折频率当成了系统的；或读高度时忘记折算型别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频特性曲线求校正前后的开环传递函数与截止频率
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

稳定裕度 频域分析
本卷考法
  • 计算校正后的相角裕度
本卷实例
  • 关键一步：先由校正后的开环传函求出截止频率，再把它代进相频表达式得到该处的相角
  • 关键一步：相角裕度等于一百八十度加上该相角，为正说明稳定
  • 关键一步：校正前后都算一次，才能说明校正带来的裕度改善
  • 中间结果：截止频率处各环节相角逐个累加，注意积分环节固定贡献负九十度
  • 卡点：把相角裕度写成一百八十度减相角；或把校正前后的截止频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过计算校正后的相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

校正的基本概念与性能指标 系统校正
本卷考法
  • 对比校正前后系统的性能变化
本卷实例
  • 关键一步：校正常用的手段是抬高低频段增益以改善精度、调整中频段形状以改善裕度与快速性
  • 关键一步：对比要看三个量：低频段高度、截止频率位置、相角裕度大小
  • 关键一步：若校正后截止频率右移而裕度仍满足要求，说明快速性与稳定性同时改善

  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷

  • 只盯相角裕度而忽略带宽要求
