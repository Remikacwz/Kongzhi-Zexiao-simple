一一、简答（5 小问）#

思路
  • 概念与结论简答：开环传函类概念、零极点对根轨迹影响、瞬态响应指标、PID 表达式、减小稳态误差措施
传递函数的定义与基本性质 传递函数
本卷考法
  • 第(1)问叙述开环传函、开环增益与根轨迹增益三个概念
本卷实例
  • 关键一步：开环传函是开环系统输出与输入之比，含全部回路信息
  • 关键一步：开环增益对尾一型系数，根轨迹增益对首一型系数
  • 中间结果：三者分别对应开环频率特性、尾一型常数与首一型系数
  • 卡点：把根轨迹增益与开环增益混为一谈；漏掉首一/尾一型前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过第(1)问叙述开环传函、开环增益与根轨迹增益三个概念
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 第(2)问分别说明增加开环零点、极点对根轨迹的影响
本卷实例
  • 关键一步：增加零点把根轨迹向左（稳定侧）吸引，增加极点向右推
  • 关键一步：同时看渐近线重心与实轴段随零极点增减的移动
  • 中间结果：零点使渐近线重心左移，极点使重心右移
  • 卡点：把零点与极点的作用说反；只谈渐近线不谈实轴段变化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过第(2)问分别说明增加开环零点、极点对根轨迹的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 第(3)问写出瞬态响应的概念并列出至少 3 个瞬态性能指标
本卷实例
  • 关键一步：瞬态响应指从初始状态到进入稳态前的过渡过程
  • 关键一步：常用指标有超调量、上升时间、峰值时间、调节时间
  • 中间结果：至少写满 3 个指标才算完整作答
  • 卡点：只给定义不列指标；把稳态误差当成瞬态指标
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过第(3)问写出瞬态响应的概念并列出至少 3 个瞬态性能指标
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
PID 控制器与参数整定 系统校正
本卷考法
  • 第(4)问写出 PID 调节器的传递函数与时域表达式
本卷实例
  • 关键一步：传递函数写成比例、积分、微分三项之和
  • 关键一步：时域表达式对应比例项、积分项与微分项
  • 中间结果：Gc(s) 为 Kp 加 Ki/s 加 Kd 乘 s 的三项结构
  • 卡点：积分项漏 1/s、微分项漏 s；Kp 与 Kd 位置写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过第(4)问写出 PID 调节器的传递函数与时域表达式
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 第(5)问列举降低系统稳态误差的主要措施
本卷实例
  • 关键一步：提高开环增益或增加系统型别（串联积分环节）
  • 关键一步：也可用前馈/复合控制或提高扰动点前的增益
  • 中间结果：先保证闭环稳定，再谈提高增益与型别
  • 卡点：只提高增益而不检查稳定性；忽略扰动作用点位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过第(5)问列举降低系统稳态误差的主要措施
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

二二、结构图化简与梅森公式#

思路
  • 由结构图用逐层化简求 C(s)/R(s)（至少 4 点），再用梅森公式求 E(s)/N(s)
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 第(1)问逐层化简多回路结构图求闭环传函 C(s)/R(s)
本卷实例
  • 关键一步：从最内层回路开始把内环等效成一个环节
  • 关键一步：每化简一层重画结构图，保持节点与回路对应
  • 中间结果：等效化简结果应与梅森公式结果完全一致
  • 卡点：化简内环时把外环信号当常数；比较点正负号写错
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过第(1)问逐层化简多回路结构图求闭环传函 C(s)/R(s)
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 第(2)问用梅森增益公式求扰动误差传函 E(s)/N(s)
本卷实例
  • 关键一步：先画信号流图，逐条列单独回路与前向通路
  • 关键一步：求特征式及各通路余子式后代入梅森公式
  • 中间结果：本题回路互相接触，特征式只含一阶回路项
  • 卡点：余子式漏删与通路接触的回路；回路增益符号写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过第(2)问用梅森增益公式求扰动误差传函 E(s)/N(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 第(2)问求扰动作用下的传函时把参考输入置零
本卷实例
  • 关键一步：求扰动传函令参考输入为零，只保留扰动到误差的通道
  • 关键一步：分别写扰动点前后的前向与反馈通路
  • 中间结果：扰动传函的分子由扰动点到误差的通路增益决定
  • 卡点：未把参考输入置零；把扰动点前后的通路增益弄混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过第(2)问求扰动作用下的传函时把参考输入置零
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

三三、控制器结构选择与参数范围#

思路
  • 在三种控制器结构中选一种，同时满足扰动零误差与斜坡输入误差上界，并确定参数取值范围
扰动作用下的稳态误差 稳态误差
本卷考法
  • 第(a)问由扰动输入下稳态误差为零筛出含积分作用的控制器
本卷实例
  • 关键一步：先写扰动误差传函，再看扰动点后是否有积分环节
  • 关键一步：令 s 趋于零时扰动误差为零，反推控制器需含积分
  • 中间结果：阶跃扰动下零误差要求扰动点后串联积分环节
  • 卡点：求扰动误差时未把参考输入置零；混淆扰动点前与点后
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过第(a)问由扰动输入下稳态误差为零筛出含积分作用的控制器
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 第(b)问由斜坡输入下误差上界反求参数取值范围
本卷实例
  • 关键一步：用终值定理算斜坡误差，前提是闭环稳定
  • 关键一步：由误差不等式解出增益或时间常数的取值范围
  • 中间结果：斜坡误差与开环增益成反比，误差上界给出增益下界
  • 卡点：未判稳就用终值定理；把阶跃误差公式套到斜坡输入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过第(b)问由斜坡输入下误差上界反求参数取值范围
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据确定所选控制器下系统稳定对参数的约束
本卷实例
  • 关键一步：把所选控制器传函代入特征方程并列劳斯表
  • 关键一步：由首列元素全为正解出参数可行区间
  • 中间结果：三种结构中能同时满足两项要求的只有一种
  • 卡点：首列出现零未用 ε 法；漏掉某个首列元素的不等式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据确定所选控制器下系统稳定对参数的约束
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

四四、根轨迹绘制与参数反求#

思路
  • 画闭环根轨迹，判断给定点是否在轨迹上，再由阻尼比反求参数 α
根轨迹的绘制法则 根轨迹法
本卷考法
  • 第(1)问按绘制法则画闭环根轨迹
本卷实例
  • 关键一步：把特征方程整理成等效开环形式 1 加 2αs/(s²+16) 等于零
  • 关键一步：标出等效开环零极点，求实轴段、渐近线、分离点与虚轴交点
  • 中间结果：等效开环为两个共轭极点与原点零点，n-m 等于 1
  • 卡点：参数根轨迹未把 α 提到分子；忘记重算等效开环零极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过第(1)问按绘制法则画闭环根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法

本卷实例

  • 关键一步：再用幅值条件求对应参数是否为非负实数值
  • 中间结果：本题该点落在负实轴根轨迹段上
  • 卡点：把正反馈的零度相角条件与 180 度混用；只代幅值不代相角
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤

  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法

  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

思路

奈奎斯特判据 稳定性分析
本卷考法
  • 由奈氏曲线与临界点关系分段求使闭环稳定的 K 范围
本卷实例
  • 关键一步：把 K 变化看成曲线相对临界点的等比缩放
  • 关键一步：按缩放后曲线的包围情况分段数正穿越与负穿越次数
  • 中间结果：本题开环右半平面极点数 P 为零，稳定要求包围圈数为零
  • 卡点：含积分环节未补画无穷大半径圆弧；包围圈数正负号定义搞反
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由奈氏曲线与临界点关系分段求使闭环稳定的 K 范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

频率特性的物理意义与求法 频域分析
本卷考法
  • 由图读各临界频率处幅值，用于判断曲线是否包围临界点
本卷实例
  • 关键一步：读曲线在相位负 180 度附近与负实轴的交点幅值
  • 关键一步：把交点幅值与 1 比较，判断是否包围临界点
  • 中间结果：交点幅值等于 1 时的 K 即为临界增益

  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差

步骤

  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法

  • 说明频率特性的物理含义

思路

由 Bode 图反求传递函数 频域分析
本卷考法
  • 第(1)问由校正前后的对数幅频曲线分别反求开环传函
本卷实例

  • 关键一步：分别写校正前、校正后传函，再相除得校正装置传函
  • 中间结果：校正后惯性环节转折频率降低，中频段斜率被拉平
  • 卡点：斜率变化为负 40 时误判成一个一阶环节；低频高度未折算型别

  • 关键一步：先求线性部分相角为负 180 度时的交越频率

由传递函数写状态空间表达式 状态空间分析
本卷考法

本卷实例

  • 关键一步：以特征向量组为列构造变换阵，再算变换后的三组矩阵

  • 最小实现要求系统既能控又能观

十十、状态反馈后的能控性与能观性#

思路
  • 给定反馈矩阵 K 先求闭环矩阵，再分别用能控性矩阵与能观性矩阵的秩判定
能控性与能观性 状态空间分析
本卷考法
  • 验证闭环系统 (A-BK, B, C) 的能控性与能观性
本卷实例
  • 关键一步：先算闭环矩阵 A 减 BK，再构造能控性矩阵与能观性矩阵
  • 关键一步：分别求秩并与系统阶数比较得出结论
  • 中间结果：本题两个判据矩阵均满秩，闭环系统同时能控能观
  • 卡点：把能控性判据与能观性判据的矩阵构造搞混；只算到倒数第二项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过验证闭环系统 (A-BK, B, C) 的能控性与能观性
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

本卷考法
  • 说明状态反馈会改变极点、也可能改变能观性，需重新校验
本卷实例
  • 关键一步：状态反馈通过 K 改变闭环特征值，能控性在反馈后不变
  • 关键一步：输出矩阵不变，但能观性可能随闭环矩阵改变

通用考法

  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错

  • 特征多项式比较系数时符号写反
