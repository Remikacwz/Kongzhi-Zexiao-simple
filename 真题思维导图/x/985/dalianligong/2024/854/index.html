1一、简答题：实验建模与传递函数建模#

思路
  • 由正弦实验的幅值比与相位差曲线反求微分方程，再说明基于传递函数定义的实验建模步骤及其优缺点
由 Bode 图反求传递函数 频域分析
本卷考法
  • 第(1)问由正弦实验的幅值比与相位差曲线求系统微分方程
本卷实例
  • 关键一步：把实验曲线近似为比例环节串两个一阶惯性环节再读转折频率
  • 中间结果：低频段高度定比例增益，两个转折频率分别定两个时间常数
  • 卡点：曲线以插图给出，转折频率与低频段高度需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过第(1)问由正弦实验的幅值比与相位差曲线求系统微分方程
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
传递函数的定义与基本性质 传递函数
本卷考法
  • 第(2)问说明传递函数实验建模的步骤与优缺点
本卷实例
  • 关键一步：按施加输入、记录并预处理数据、辨识模型三步概括建模过程
  • 中间结果：传递函数建模前提是零初始条件与各环节运动机理明确
  • 卡点：不要把传递函数建模与频率特性建模的优缺点说反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过第(2)问说明传递函数实验建模的步骤与优缺点
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

2二、求误差传函与抑制负载扰动#

思路
  • 由结构图分别求参考与扰动两通道的误差传函，再用前馈补偿通道使扰动到输出的传递函数为零
误差定义与误差传递函数 稳态误差
本卷考法
  • 第(1)问由结构图求误差对参考输入与负载扰动的传递函数
本卷实例
  • 关键一步：先令扰动为零求参考误差通道，再令参考为零求扰动误差通道
  • 中间结果：总误差写成参考误差项与扰动误差项两项之和
  • 卡点：两种误差定义混用会相差一个反馈环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过第(1)问由结构图求误差对参考输入与负载扰动的传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 第(1)问用叠加原理求多输入作用下系统的输出
本卷实例
  • 关键一步：分别求参考通道与扰动通道各自的前向通路与余子式
  • 中间结果：两个通道共用同一特征式，但前向通路不同
  • 卡点：求扰动传函时忘记把参考输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过第(1)问用叠加原理求多输入作用下系统的输出
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 第(2)问提出及时减小负载扰动影响的方法并画结构图
本卷实例
  • 关键一步：从扰动作用点引入前馈补偿通道使扰动到输出传函为零
  • 中间结果：按不变性原理反解出的补偿器与原系统并联合成
  • 卡点：只提高开环增益能减小误差却可能破坏稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过第(2)问提出及时减小负载扰动影响的方法并画结构图
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

3三、位置控制系统与速度反馈参数#

思路
  • 由结构图写闭环传函化为二阶标准式，用超调量范围反求速度反馈参数，再判断过阻尼并绘响应曲线
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 第(1)问由结构图写闭环传函并读出阻尼比与自然频率
本卷实例
  • 关键一步：按反馈等效化简得开环，再按单位负反馈写闭环特征式
  • 中间结果：自然频率由位置增益决定，阻尼比由位置与速度反馈共同决定
  • 卡点：化标准形式时忘记把二次项系数归一化为 1
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过第(1)问由结构图写闭环传函并读出阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 第(1)问由超调量范围反求速度反馈参数的范围
本卷实例
  • 关键一步：由超调量上限先定阻尼比下限，再由有超调定阻尼比上限
  • 中间结果：两个不等式联立给出速度反馈参数的开区间
  • 卡点：有超调要求欠阻尼，别漏掉阻尼比小于 1 的上界
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过第(1)问由超调量范围反求速度反馈参数的范围
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 第(2)问判断响应是否超调并绘制位置与速度响应曲线
本卷实例
  • 关键一步：代入给定参数求阻尼比，由阻尼比大于 1 判为过阻尼
  • 中间结果：过阻尼下位置响应单调上升，速度响应先升后降
  • 卡点：响应曲线以插图给出，走势需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过第(2)问判断响应是否超调并绘制位置与速度响应曲线
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

4四、参数根轨迹与响应速度调整#

思路
  • 把比例积分控制器与对象合成含 kp 的开环，整理成以 kp 为参数的等效开环画根轨迹，再由主导极点说明如何调整参数加快响应
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 把含控制器增益的闭环特征方程整理成以该增益为参数的等效开环
本卷实例
  • 关键一步：把只含控制器增益的项分离出来作为等效开环的增益部分
  • 中间结果：等效开环比原来多一个开环零点，根轨迹形状随之变化
  • 卡点：整理时没有把参数完整地提到分子位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过把含控制器增益的闭环特征方程整理成以该增益为参数的等效开环
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹说明调整参数使系统响应更快的理由
本卷实例
  • 关键一步：响应速度主要由距离虚轴最近的闭环极点决定
  • 中间结果：参数比值越趋近于 1，主导极点离虚轴越远，过渡过程越短
  • 卡点：只比较渐近线位置而不看主导极点的距离
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹说明调整参数使系统响应更快的理由
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

5五、奈奎斯特判据与条件稳定#

思路
  • 写出开环频率特性画奈氏曲线，用奈氏判据判稳并数右半平面根，再说明串入开环零点使系统有条件稳定的机理
频率特性的物理意义与求法 频域分析
本卷考法
  • 第(1)问写出开环频率特性并分析幅值与相角随频率的变化
本卷实例
  • 关键一步：令 s 等于纯虚变量后分离实部与虚部判断曲线所在象限
  • 中间结果：曲线始终位于左半平面且与负实轴没有交点
  • 卡点：开环含两个积分环节时的起始相角不要漏算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过第(1)问写出开环频率特性并分析幅值与相角随频率的变化
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解

  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错

  • 把能控性判据与能观性判据的矩阵构造搞混
