一一、简答题（3 小问）12 分#

思路
  • 设计指标的分类、带死区 PID 是否线性、理想一阶电路断开后的零输入响应判断
校正的基本概念与性能指标 系统校正
本卷考法
  • 第(1)问列举控制系统设计的主要指标并区分动态与静态
本卷实例
  • 关键一步：按过渡过程品质与稳态精度两类梳理各项指标
  • 中间结果：动态类含超调、峰值时间、上升时间、调节时间
  • 卡点：把稳态误差误归入动态指标；只罗列指标不作分类
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过第(1)问列举控制系统设计的主要指标并区分动态与静态
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求
公式
PID 控制器与参数整定 系统校正
本卷考法
  • 第(2)问判断带死区 PID 是否线性并说明优缺点
本卷实例
  • 关键一步：看死区环节是否满足叠加性与齐次性
  • 中间结果：死区在小信号时输出为零，故属非线性控制器
  • 卡点：误认为 PID 必为线性；只谈优点漏掉小信号失效
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过第(2)问判断带死区 PID 是否线性并说明优缺点
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 第(3)问判断理想一阶电路开关断开后能否维持初始状态
本卷实例
  • 关键一步：零输入响应须由储能元件经闭合回路释放能量
  • 中间结果：开关断开后回路不闭合，电容缺少放电通路
  • 卡点：把理想化当成响应不变；忽略回路通断
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过第(3)问判断理想一阶电路开关断开后能否维持初始状态
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

二二、机械系统微分方程与传递函数10 分#

思路
  • 由弹簧-质量机械系统列微分方程，消去中间位移后求传函
机械系统建模 建模与机电系统
本卷考法
  • 列写小车与弹簧连接的机械系统微分方程
本卷实例
  • 关键一步：对小车列牛顿第二定律并引入节点位移作中间变量
  • 中间结果：消去中间位移后得含弹簧刚度的二阶方程
  • 卡点：弹簧力与阻尼力方向取反；漏掉相互作用反作用项
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过列写小车与弹簧连接的机械系统微分方程
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由机械系统微分方程求位移对力的传递函数
本卷实例
  • 关键一步：零初始条件下作拉氏变换后再消去中间变量
  • 中间结果：传函分母为二阶特征式，分子为等效刚度项
  • 卡点：初始化条件带入变换；消元时漏掉某个输出项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由机械系统微分方程求位移对力的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

三三、结构图扰动误差与前馈补偿15 分#

思路
  • 由结构图求误差传函，用两种输入的稳态误差反求 T、K，再算动态指标并设计前馈
扰动作用下的稳态误差 稳态误差
本卷考法
  • 第(1)问由斜坡与阶跃扰动下的稳态误差反求 T、K
本卷实例
  • 关键一步：先判闭环稳定，再分别令另一输入为零写误差传函
  • 中间结果：斜坡误差与开环增益成反比，阶跃扰动误差等于某时间常数
  • 卡点：求扰动误差未把参考输入置零；未判稳就用终值定理
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过第(1)问由斜坡与阶跃扰动下的稳态误差反求 T、K
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 第(2)问求闭环系统的调节时间与超调量
本卷实例
  • 关键一步：由闭环特征式系数反解阻尼比与自然频率
  • 中间结果：二阶欠阻尼指标只取决于阻尼比与自然频率
  • 卡点：两种误差带的调节时间系数用反；超调量漏乘百分比
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过第(2)问求闭环系统的调节时间与超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
反馈校正与复合控制 系统校正
本卷考法
  • 第(3)问设计前馈控制器使扰动对输出无影响
本卷实例
  • 关键一步：令扰动到输出的分子为零解出前馈通道传函
  • 中间结果：前馈补偿器取扰动通道传函的负倒数形式
  • 卡点：把前馈设计成反馈；求解时漏掉某条前向通路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过第(3)问设计前馈控制器使扰动对输出无影响
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

四四、PD 控制器根轨迹与稳定范围20 分#

思路
  • 含 PD 控制器时绘制 K 变化根轨迹并求稳定范围，再讨论 TD 变化的两种典型根轨迹
根轨迹的绘制法则 根轨迹法
本卷考法
  • 第(1)问 TD=0.1 时绘制随 K 变化的闭环根轨迹
本卷实例
  • 关键一步：把特征方程整理成 1 加 K 乘等效开环等于零
  • 中间结果：先标等效零极点，再定实轴段、渐近线与分离点
  • 卡点：参数未提到分子；实轴段零极点计数算错
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过第(1)问 TD=0.1 时绘制随 K 变化的闭环根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 第(1)问求根轨迹与虚轴交点及稳定 K 范围
本卷实例
  • 关键一步：令 s 为纯虚数代入特征方程，实部虚部分别为零
  • 中间结果：临界增益由劳斯表首列某行取零确定
  • 卡点：只代一个 ω 漏掉另一组解；临界增益未回代核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过第(1)问求根轨迹与虚轴交点及稳定 K 范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 第(2)问以 TD 为参数讨论根轨迹的两种典型变化
本卷实例
  • 关键一步：把 TD 作可变参数提到等效开环分子再比较渐近线
  • 中间结果：TD 跨临界值时渐近线由右半平面移向左半平面
  • 卡点：仍按固定 K 画根轨迹；漏判渐近线重心移动方向
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过第(2)问以 TD 为参数讨论根轨迹的两种典型变化
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

五五、奈氏曲线判稳与最小相位传函18 分#

思路
  • 由给定奈氏曲线分段判稳、概略画相频特性，并反写阶次最小的最小相位传函
奈奎斯特判据 稳定性分析
本卷考法
  • 第(1)问由奈氏曲线与临界点关系分段判断闭环稳定性
本卷实例
  • 关键一步：先数开环右极点 P，再数曲线包围临界点的圈数 N
  • 中间结果：含积分环节时须补画无穷大半径圆弧后再计数
  • 卡点：漏画补线；包围圈数的正负号定义取反
  • 卡点：需回原卷核对图
