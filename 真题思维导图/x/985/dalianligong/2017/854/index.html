一一、结构图传函与扰动不变性#

思路
  • 由结构图用梅森公式求 C/R、C/N 与误差传函，再由扰动不变性确定补偿环节 G5
梅森增益公式与信号流图 传递函数
本卷考法
  • 第(1)问用梅森增益公式求闭环传函 C(s)/R(s) 与扰动传函 C(s)/N(s)
本卷实例
  • 关键一步：先列两条独立回路并判断是否互不接触
  • 关键一步：对每个输出分别找前向通路与余子式再代入公式
  • 中间结果：两条回路互相接触，特征式只含一阶回路项
  • 卡点：余子式漏删接触回路；把扰动前向通路漏掉一条
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过第(1)问用梅森增益公式求闭环传函 C(s)/R(s) 与扰动传函 C(s)/N(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 第(1)问求误差响应 E(s) 时把无关输入置零后叠加
本卷实例
  • 关键一步：分别令扰动为零、参考为零求两路误差
  • 关键一步：把两路结果按线性叠加写成总误差
  • 中间结果：参考通道误差分子含反馈回路项，扰动通道只经前向通路
  • 卡点：两个输入同时存在时直接叠加却不验证线性性；漏掉一路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过第(1)问求误差响应 E(s) 时把无关输入置零后叠加
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

反馈校正与复合控制 系统校正
本卷考法
  • 第(2)问令扰动对输出无影响，反求补偿环节 G5
本卷实例
  • 关键一步：令扰动到输出的传函分子为零
  • 关键一步：解出 G5 使其恰好抵消原扰动通道
  • 中间结果：补偿环节由原扰动通路与主前向通路的比值决定
  • 卡点：把扰动不变性条件写成增益为零；求出的补偿器不可实现却不检查
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过第(2)问令扰动对输出无影响，反求补偿环节 G5
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

二二、二阶系统阻尼调整与稳态输出#

思路
  • 由闭环传函求自然频率与阻尼比，再引入反馈把阻尼比调到 0.8，并求稳态输出的时域形式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 第(1)问由开环传函求自然频率与阻尼比
本卷实例
  • 关键一步：把二阶分母写成标准形式再对照系数
  • 关键一步：由一次项系数与常数项分别定出阻尼比与自然频率
  • 中间结果：两个标准系数恰好定出两个特征量
  • 卡点：未把 s 平方项系数归一；阻尼比与自然频率对应项搞反
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过第(1)问由开环传函求自然频率与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 第(2)问引入反馈保证自然频率不变、把阻尼比提高到 0.8
本卷实例
  • 关键一步：加入反馈后重写特征方程，让常数项保持不变
  • 关键一步：只让一次项系数满足新阻尼比要求，反解反馈环节
  • 中间结果：所求反馈环节为纯微分型，只改变阻尼项
  • 卡点：加入反馈后没检查自然频率是否被改动；反馈极性接反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过第(2)问引入反馈保证自然频率不变、把阻尼比提高到 0.8
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 第(3)问求系统稳态输出的时域表达形式
本卷实例
  • 关键一步：先求闭环直流增益，再由输入幅值定稳态值
  • 关键一步：按欠阻尼二阶系统写含衰减正弦的时域表达式
  • 中间结果：稳态输出为常值，过渡项由阻尼比与自然频率决定
  • 卡点：把稳态值直接当输入幅值；衰减系数漏乘阻尼比
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过第(3)问求系统稳态输出的时域表达形式
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

三三、由等幅振荡条件反求参数#

思路
  • 把闭环特征方程代入纯虚根条件，实部虚部分别为零解出 a 与 K
参数稳定域的确定 稳定性分析
本卷考法
  • 由系统在给定频率产生等幅振荡确定两个参数
本卷实例
  • 关键一步：等幅振荡对应闭环极点落在虚轴上
  • 关键一步：把纯虚根代入特征方程后令实部与虚部同时为零
  • 中间结果：两个方程分别约束常数项与一次项，恰能定出两参数
  • 卡点：只令实部为零；把给定振荡频率当未知量再解一遍
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由系统在给定频率产生等幅振荡确定两个参数
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 把等幅振荡看成根轨迹与虚轴交点，联立求临界参数
本卷实例
  • 关键一步：写出闭环特征多项式并整理成 s 的幂次
  • 关键一步：令 s 为纯虚数后按虚实部分离写成方程组
  • 中间结果：虚部方程给频率条件，实部方程给参数关系
  • 卡点：幂次整理时符号写错；只代一个频率值不验证
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过把等幅振荡看成根轨迹与虚轴交点，联立求临界参数
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

四四、参数根轨迹与附加环节改善稳定#

思路
  • 画以 K 为参变量的根轨迹求稳定范围，并说明附加何种环节可扩大稳定域
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 第(1)问绘制以 K 为参变量的根轨迹图
本卷实例
  • 关键一步：把特征方程整理成等效开环等于负一的标准根轨迹形式
  • 关键一步：标出等效零极点并求实轴段、渐近线与出射角
  • 中间结果：等效开环为三个极点零个零点，实轴段只在一侧
  • 卡点：参数没完整提到分子；零度与 180 度相角条件混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过第(1)问绘制以 K 为参变量的根轨迹图
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 第(1)问求根轨迹与虚轴交点及稳定 K 取值范围
本卷实例

  • 关键一步：解出交点频率与临界增益再由走向定稳定侧
  • 中间结果：根轨迹首次穿越虚轴给出稳定上界
  • 卡点：稳定范围方向写反；漏掉另一组交点

  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过第(1)问求根轨迹与虚轴交点及稳定 K 取值范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

附加开环零极点的影响 根轨迹法
本卷考法
  • 第(2)问说明加入何种环节可提高稳定性使全 K 稳定
本卷实例
  • 关键一步：附加开环零点等于引入微分作用，把根轨迹拉向左半平面
  • 关键一步：零点越多或越靠左，分支越易落在左半平面
  • 中间结果：加入一阶微分环节后无论 K 取何值都稳定
  • 卡点：只谈渐近线左移而忽略分离点变化；把零点与极点作用搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过第(2)问说明加入何种环节可提高稳定性使全 K 稳定
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反

五五、由幅相曲线判稳与求增益范围#

思路
  • 由图给开环幅相曲线判断闭环稳定性，再求闭环稳定时的增益范围
奈奎斯特判据 稳定性分析
本卷考法
  • 第(1)问用奈奎斯特判据判断此时闭环的稳定性
本卷实例
