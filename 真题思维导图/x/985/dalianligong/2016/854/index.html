一一、简答（5 小问）#

思路
  • 概念与结论简答：闭环稳态增益、常值扰动消差、带宽与快慢及抗扰、建模步骤、设计考虑因素
系统型别与静态误差系数 稳态误差
本卷考法
  • 第(1)问讨论反馈控制系统是否都期望闭环稳态增益为 1
本卷实例
  • 关键一步：稳态增益为 1 时输出直接等于输入，便于无差跟踪
  • 关键一步：有差系统为压低误差也常把闭环直流增益调到接近 1
  • 中间结果：结论不能一概而论：取决于系统对角差与稳定性的取舍
  • 卡点：把稳态增益与开环增益混为一谈；忽略无差要求与稳定性冲突
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过第(1)问讨论反馈控制系统是否都期望闭环稳态增益为 1
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

扰动作用下的稳态误差 稳态误差
本卷考法
  • 第(2)问说明消除常值扰动引起稳态误差的方法
本卷实例
  • 关键一步：在扰动作用点前的前向通道或主反馈通道串入积分环节
  • 关键一步：也可用扰动补偿的复合校正抵消扰动影响
  • 中间结果：关键看扰动作用点位置，积分要加在扰动点之前
  • 卡点：积分加在扰动点之后仍留静差；只答加大增益而不提积分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过第(2)问说明消除常值扰动引起稳态误差的方法
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

闭环频率特性与性能指标 频域分析
本卷考法
  • 第(3)问说明系统带宽与响应速度、抗干扰能力的关系
本卷实例
  • 关键一步：带宽越宽，能跟踪的高频分量越多，响应越快
  • 关键一步：带宽越宽对高频噪声与干扰的抑制越弱，抗扰变差
  • 中间结果：带宽在快速性与抗扰性之间是一对矛盾指标
  • 卡点：只答响应快而漏掉抗扰变差；把带宽当成分辨率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过第(3)问说明系统带宽与响应速度、抗干扰能力的关系
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

机械系统建模 建模与机电系统
本卷考法
  • 第(4)问简述建立线性动态数学模型的步骤（借位 md_01）
本卷实例
  • 关键一步：先按物理规律列写各部分的运动方程
  • 关键一步：也可施加测试信号记录响应，再由响应拟合模型并辨识参数
  • 中间结果：机理建模与实验建模两条路可互相补充与校验
  • 卡点：只答列方程而漏参数估计；把建模与仿真混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过第(4)问简述建立线性动态数学模型的步骤（借位 md_01）
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项

校正的基本概念与性能指标 系统校正
本卷考法
  • 第(5)问列举控制系统设计时考虑的主要因素（借位 cr_01）
本卷实例
  • 关键一步：稳定性是前提，保证去除扰动后偏差能收敛
  • 关键一步：在稳定前提下再要求快速性与准确性（稳态精度）
  • 中间结果：三项要求常相互矛盾，需按工艺指标折中
  • 卡点：只谈快与准而不提稳定前提；把三项要求当成互不影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过第(5)问列举控制系统设计时考虑的主要因素（借位 cr_01）
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求

二二、由微分方程组画系统结构图#

思路
  • 对给定微分方程组取拉氏变换，按代数关系逐步连接各环节画出系统结构图
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由给定微分方程组画出系统结构图，参数均为正数
本卷实例
  • 关键一步：对每个微分方程取零初值拉氏变换，整理成输出比输入的环节式
  • 关键一步：按变量间的加减关系把各环节串成比较点与反馈回路
  • 中间结果：每条方程对应一个一阶惯性环节，中间变量充当级间信号
  • 卡点：拉氏变换后未把变量整理成环节比值；比较点正负号接错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由给定微分方程组画出系统结构图，参数均为正数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

三三、结构图参数稳定性与 K5 无静差#

思路
  • 先按结构图求闭环与误差传函，用劳斯判据给稳定条件，再由斜坡无静差定 K5
参数稳定域的确定 稳定性分析
本卷考法
  • 第(1)问给出系统闭环稳定的各参数关系
本卷实例
  • 关键一步：由特征方程列劳斯表，要求首列元素全为正
  • 关键一步：把不等式整理成各参数之间须满足的关系式
  • 中间结果：稳定条件化为一个关于两个参数乘积的主不等式
  • 卡点：漏列某个首列元素不等式；端点是否含零判错
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过第(1)问给出系统闭环稳定的各参数关系
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 第(2)问确定 K5 使系统在斜坡输入下无稳态误差
本卷实例
  • 关键一步：先写误差传函，再用终值定理求斜坡输入下的稳态误差
  • 关键一步：令误差分子的一次项系数为零解出 K5
  • 中间结果：无静差条件消去误差传函分子中的 s 一次项
  • 卡点：未判稳就使用终值定理；误差传函分子分母写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过第(2)问确定 K5 使系统在斜坡输入下无稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 解析用梅森增益公式求闭环传函与误差传函
本卷实例
  • 关键一步：先画信号流图，列出各单独回路与两条前向通路
  • 关键一步：用梅森公式分别写闭环传函与误差传函
  • 中间结果：两条前向通路分别对应主通道与补偿通道
  • 卡点：特征式漏减互不接触回路项；把回路增益当通路增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过解析用梅森增益公式求闭环传函与误差传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

四四、由阶跃响应定参数与调整时间#

思路
  • 把闭环传函化为标准二阶形式，由响应曲线读稳态值与超调量反求三个参数，再算调整时间
由响应曲线反求传递函数 传递函数
本卷考法
  • 第(1)问由单位阶跃响应曲线确定系统参数 K1、K2、K3
本卷实例
  • 关键一步：由响应稳态值定出增益型参数 K3
  • 关键一步：由超调量定阻尼比，再联合峰值时间或稳态值定其余参数
  • 中间结果：阶跃响应图提供稳态值与超调量两个可读量
  • 卡点：把稳态值当成增益而漏掉输入幅值；未判断系统阶数就套二阶公式
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过第(1)问由单位阶跃响应曲线确定系统参数 K1、K2、K3
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化成标准二阶形式并比对系数
本卷实例
  • 关键一步：先把 s 平方项系数归一，再对照标准形式
  • 关键一步：由对照结果建立参数与阻尼比、自然频率的方程
  • 中间结果：系统为典型二阶无零点形式，两个特征量由两个参数决定
  • 卡点：未归一就比对系数；把两倍阻尼比乘积写成单倍
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化成标准二阶形式并比对系数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

本卷实例
