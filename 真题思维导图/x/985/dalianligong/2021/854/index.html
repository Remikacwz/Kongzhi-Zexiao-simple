一一、简答题（5 小问）#

思路
  • 概念辨析：被控对象识别、PID 参数作用、一阶闭环稳定性、数字控制器算法、测量环节近似
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 第(1)问由液位控制系统指认被控对象、被控量与执行机构并判断是否反馈控制
本卷实例
  • 关键一步：按给定到被控量的信号流向逐个指认给定、比较、执行、对象与检测环节
  • 关键一步：只要有检测元件把被控量送回比较点，就是反馈控制系统
  • 中间结果：本题被控对象是水箱（中间容器），被控量是液位高度，执行机构是进水阀
  • 卡点：把被控量与操纵量搞反；把检测元件误当成执行机构
  • 卡点：该题控制系统以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过第(1)问由液位控制系统指认被控对象、被控量与执行机构并判断是否反馈控制
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
PID 控制器与参数整定 系统校正
本卷考法
  • 第(2)问简答 PID 三个参数各自的作用与对系统性能的影响
本卷实例
  • 关键一步：比例管当前误差、积分消除稳态误差、微分预测误差变化趋势
  • 关键一步：分别说明参数增大或减小时对快速性、超调与稳态精度的影响
  • 中间结果：比例项提高快速性但留稳态误差，积分项消差但增大超调，微分项抑制超调但放大噪声
  • 卡点：把积分作用说成超前；或忽略微分对高频噪声的放大
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过第(2)问简答 PID 三个参数各自的作用与对系统性能的影响
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

零极点分布与响应模态 传递函数
本卷考法
  • 第(3)问判断一阶最小相位开环的单位负反馈闭环是否恒稳定并说明理由
本卷实例
  • 关键一步：写出闭环特征方程，由开环一阶最小相位得闭环极点在左半平面
  • 关键一步：用极点实部全为负判断响应收敛，从而说明闭环稳定
  • 中间结果：闭环特征根为负实极点，对应单调衰减模态
  • 卡点：忽略最小相位与增益为正的前提；或把虚轴极点误判为稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过第(3)问判断一阶最小相位开环的单位负反馈闭环是否恒稳定并说明理由
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

数字控制器与最少拍设计 离散控制系统
本卷考法
  • 第(4)问由控制器脉冲传递函数写出可实现的差分控制算法
本卷实例
  • 关键一步：把 U(z)/E(z) 交叉相乘后反变换成时域差分方程
  • 关键一步：整理成当前输出由当前误差与前两拍输出表示的递推形式
  • 中间结果：本题交叉相乘后得当前误差等于前两拍输出之差
  • 卡点：把 z 的正幂与负幂对应时刻搞反；或漏掉初始条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最少拍系统指在典型输入下经过有限拍达到无稳态误差
  • 设计需要满足可实现性与稳定性约束
  • 最少拍系统的闭环脉冲传递函数由输入类型确定
  • 最少拍设计通常导致很大的控制量，需加限制
步骤
  • 确定输入类型及对应的误差传函形式
  • 按无稳态误差要求构造闭环脉冲传递函数
  • 由 D(z)=Φ(z)/[G(z)(1-Φ(z))] 求数字控制器
  • 检验可实现性、稳定性与控制量大小
通用考法
  • 本卷考过第(4)问由控制器脉冲传递函数写出可实现的差分控制算法
  • 设计最少拍数字控制器
  • 比较不同输入类型下的最少拍数
  • 分析最少拍系统存在的问题
常见易错
  • 忽略 D(z) 必须是物理可实现的因果系统
  • 闭环传函构造时未满足稳定性约束条件

误差定义与误差传递函数 稳态误差
本卷考法
  • 第(5)问说明分析时为何把测量环节传函近似为 1、即按单位负反馈处理
本卷实例
  • 关键一步：测量环节为比例环节且增益标定为 1 时，反馈信号等于被控量
  • 关键一步：此时误差可直接取给定与被控量之差，结构简化且便于分析
  • 中间结果：近似为单位负反馈后误差定义唯一，两种误差取法不再有差别
  • 卡点：忽略传感器实际存在增益与时间常数；近似后不检查是否引入误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过第(5)问说明分析时为何把测量环节传函近似为 1、即按单位负反馈处理
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

二二、结构图求闭环与误差传函#

思路
  • 由结构图分别用梅森公式求 C(s)/R(s)，再在 G1=1、G3=0 条件下求 E(s)/R(s)
梅森增益公式与信号流图 传递函数
本卷考法
  • 第(1)问用梅森增益公式求系统闭环传递函数 C(s)/R(s)
本卷实例
  • 关键一步：先把结构图改画成信号流图，逐条列出单独回路与前向通路
  • 关键一步：求特征式与各前向通路的余子式后代入梅森公式
  • 中间结果：本题两条回路互相接触，特征式只保留一阶回路项，不含两两乘积
  • 卡点：余子式里漏删与通路接触的回路；或把回路增益符号写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过第(1)问用梅森增益公式求系统闭环传递函数 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由多回路结构图逐层化简，并与梅森公式结果互相校验
本卷实例
  • 关键一步：从最内层回路开始，把内环化成一个等效环节再参与外层运算
  • 关键一步：每化简一层就重画结构图，保持节点与回路数目对应
  • 中间结果：两种方法得到的特征多项式应完全相同，可用来检查是否漏回路
  • 卡点：内外层顺序反了导致重复计入回路；或比较点正负号写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由多回路结构图逐层化简，并与梅森公式结果互相校验
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
误差定义与误差传递函数 稳态误差
本卷考法
  • 第(2)问在 G1=1、G3=0 条件下求误差传递函数 E(s)/R(s)
本卷实例
  • 关键一步：按误差取在输入端的定义写出 E(s) 等于 R(s) 减 C(s)，再代入化简结构
  • 关键一步：求误差传函时保留参考输入，其余输入置零
  • 中间结果：误差传函分母与闭环传函相同，分子由误差点到输出的前向通路决定
  • 卡点：把误差传函的分子错写成闭环传函的分子；或忘记置零其他输入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过第(2)问在 G1=1、G3=0 条件下求误差传递函数 E(s)/R(s)
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

三三、由阶跃响应指标反求 k 与 α#

思路
  • 由期望阶跃响应读出超调量和峰值时间，反求结构参数 k、α，再讨论它们对响应的影响
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 第(1)问由闭环传函化为标准二阶形式，比对系数写出 k、α 与 ξ、ωn 的关系
本卷实例
  • 关键一步：先把闭环传函的 s² 项系数归一，化成标准二阶形式
  • 关键一步：对照标准形式读出 ωn² 与 2ξωn，建立 k、α 与 ξ、ωn 的方程
  • 中间结果：本题 k 等于 ωn²、2 加 α 等于 2ξωn，参数与两个特征量一一对应
  • 卡点：忘记把 s² 项系数归一；或把 2ξωn 写成 ξωn
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过第(1)问由闭环传函化为标准二阶形式，比对系数写出 k、α 与 ξ、ωn 的关系
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 第(1)问由响应曲线读超调量与峰值时间，联立解出 ξ 与 ωn
本卷实例
  • 关键一步：超调量只由阻尼比决定，先由它解出阻尼比
  • 关键一步：再把阻尼比代进峰值时间公式解出自然频率，最后回代求 k、α
  • 中间结果：超调量与峰值时间两个方程恰能定出 ξ、ωn 两个未知量
  • 卡点：超调量公式漏乘 100；或峰值时间与上升时间公式用混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过第(1)问由响应曲线读超调量与峰值时间，联立解出 ξ 与 ωn
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 第(2)(3)问分析 k 或 α 单独变化对阻尼比与响应形态的影响
本卷实例
  • 关键一步：固定 k 时 ωn 不变，α 只改变阻尼比，据此分阻尼类型讨论
