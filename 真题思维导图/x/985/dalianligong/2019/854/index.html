一一、简答题（5 小问）#

思路
  • 开环闭环对比、传递函数定义、零极点影响、积分环节特性、离散系统稳定条件
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 第(1)问说明开环与闭环控制系统的定义与各自特点
本卷实例
  • 关键一步：从有无反馈回路切入，对比结构与性能差异
  • 中间结果：开环结构简单精度低；闭环精度高但可能振荡
  • 卡点：把开环说成无输入信号；只答定义漏答特点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过第(1)问说明开环与闭环控制系统的定义与各自特点
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
传递函数的定义与基本性质 传递函数
本卷考法
  • 第(2)问叙述线性定常系统传递函数的定义
本卷实例
  • 关键一步：点明零初始条件下输出与输入拉氏变换之比
  • 中间结果：传函只由系统结构与参数决定，与输入形式无关
  • 卡点：漏掉零初始条件这一前提；把输入函数写进定义
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过第(2)问叙述线性定常系统传递函数的定义
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 第(3)问分析增加开环零点与极点对稳定性的影响
本卷实例
  • 关键一步：分别看零点、极点把根轨迹向左还是向右拉
  • 中间结果：零点使根轨迹左移增强稳定，极点右移可能失稳
  • 卡点：零点与极点作用说反；只谈渐近线不谈实轴段
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过第(3)问分析增加开环零点与极点对稳定性的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
频率特性的物理意义与求法 频域分析
本卷考法
  • 第(4)问写出积分环节的传函、频率特性、幅频与相频
本卷实例
  • 关键一步：把复变量换成纯虚数后分别取模与相角
  • 中间结果：幅频与频率成反比，相频恒为负九十度
  • 卡点：模与相角计算漏项；把积分与微分环节特性弄混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过第(4)问写出积分环节的传函、频率特性、幅频与相频
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
离散系统稳定性分析 离散控制系统
本卷考法
  • 第(5)问简述离散控制系统的稳定条件
本卷实例
  • 关键一步：从特征根模值与单位圆的关系说明
  • 中间结果：全部特征根位于单位圆内则系统稳定
  • 卡点：写成实部小于零；把单位圆上的等幅振荡当稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过第(5)问简述离散控制系统的稳定条件
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

二二、RC 电路微分方程、结构图与传函#

思路
  • 由 RC 网络列微分方程、画结构图并求传函 Uo(s)/Ui(s)
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 列写 RC 网络的微分方程与各支路电流电压关系
本卷实例
  • 关键一步：按基尔霍夫定律列方程再消去中间电流变量
  • 中间结果：消元后得二阶微分方程，系数由电阻电容乘积组成
  • 卡点：电容电流与电压关系写反；漏掉某个中间电流
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过列写 RC 网络的微分方程与各支路电流电压关系
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由 RC 网络微分方程画结构图并求传递函数
本卷实例
  • 关键一步：对微分方程取拉氏变换后按环节连接画结构图
  • 中间结果：传函分母为二阶多项式，分子为常数项
  • 卡点：结构图反馈极性画错；梅逊公式漏算回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由 RC 网络微分方程画结构图并求传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

三三、梅逊公式求闭环传递函数#

思路
  • 用梅逊增益公式求多回路结构图的闭环传函 C(s)/R(s)
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅逊公式求复杂结构图的闭环传递函数
本卷实例
  • 关键一步：列全部单独回路、两两不接触回路与前向通路
  • 中间结果：特征式由各回路增益按接触关系组合而成
  • 卡点：不接触回路漏算或重复；余子式未剔除接触回路
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅逊公式求复杂结构图的闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 逐层化简多回路结构图并与梅逊公式结果互证
本卷实例
  • 关键一步：从最内层回路开始逐层等效合并
  • 中间结果：每化简一层重画结构图并保持节点与回路对应
  • 卡点：化简内环时把外环信号当常数；比较点符号写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过逐层化简多回路结构图并与梅逊公式结果互证
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

四四、单位负反馈系统稳定范围与闭环极点#

思路
  • 由结构图写闭环特征多项式，求稳定 Kb 范围，再由已知闭环极点反求 Kb 与其余极点
参数稳定域的确定 稳定性分析
本卷考法
  • 第(1)问求使系统闭环稳定的反馈系数 Kb 取值范围
本卷实例
  • 关键一步：由结构图写闭环特征多项式再列劳斯表
  • 中间结果：稳定条件为劳斯表首列元素全部大于零
  • 卡点：漏列某个首列不等式；取交集时端点判错
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过第(1)问求使系统闭环稳定的反馈系数 Kb 取值范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
劳斯判据 稳定性分析
本卷考法
  • 第(1)(2)问列特征多项式、列劳斯表并由已知极点反求参数
本卷实例
  • 关键一步：把已知闭环极点代入特征方程，再用综合除法降阶
  • 中间结果：由已知根解出一个参数，再由余下二次式求另两根
  • 卡点：代入时符号写错；降阶后漏乘因式的常数项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过第(1)(2)问列特征多项式、列劳斯表并由已知极点反求参数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式

五五、根轨迹与参数 z 的稳定性分析#

思路
  • 先画原系统根轨迹并判稳，再以校正零点位置 z 为参数画根轨迹分析稳定性
根轨迹的绘制法则 根轨迹法
本卷考法
  • 第(1)问绘制未加校正时系统的闭环根轨迹
本卷实例
  • 关键一步：标出开环零极点后按法则求实轴段、渐近线与分离点
  • 中间结果：三条分支起于三个开环极点，渐近线夹角为六十度
  • 卡点：实轴段零极点计数错；分离点方程的根未筛选
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称

  • 第(1)问判断系统的能控性与能观性
本卷实例
  • 关键一步：构造判别矩阵并比较秩与系统阶数
  • 中间结果：秩等于阶数则系统完全能控能观
  • 卡点：判别矩阵构造混淆；只算到 n-2 阶就下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过第(1)问判断系统的能控性与能观性
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

状态空间与传递函数的关系 状态空间分析
本卷考法
  • 第(2)问由状态空间描述求传递函数
本卷实例
  • 关键一步：按输出矩阵乘预解矩阵乘输入矩阵计算传函
  • 中间结果：分母为特征多项式，分子可能发生零极点对消
  • 卡点：漏掉直接传递项；把特征值个数当极点个数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过第(2)问由状态空间描述求传递函数
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

状态反馈与极点配置 状态空间分析
本卷考法
  • 第(3)问判断可否任意配置极点并求状态反馈矩阵
本卷实例
  • 关键一步：先由能控性判断可配置性，再比系数求反馈阵
  • 中间结果：期望特征式与闭环特征式对应系数相等
  • 卡点：未判能控就配置；系数比对时符号写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过第(3)问判断可否任意配置极点并求状态反馈矩阵
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
