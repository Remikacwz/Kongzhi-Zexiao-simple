一一、小车牵引系统的建模与状态空间#

思路
  • 由牵引力、阻力和牛顿第二定律列微分方程，取路程与速度为状态写状态空间表达式并求稳态速度
机械系统建模 建模与机电系统
本卷考法
  • 第(1)问由牵引力、粘性阻力和质量列小车运动微分方程
本卷实例
  • 关键一步：按牛顿第二定律列合力等于质量乘加速度，阻力与速度成正比取负号
  • 关键一步：速度是路程的导数，把两个方程联立成二阶微分方程
  • 中间结果：本题方程可写成加速度等于牵引力减阻尼力再除以质量
  • 卡点：阻尼力方向取反；或把牵引力与路程直接关联
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过第(1)问由牵引力、粘性阻力和质量列小车运动微分方程
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
状态空间表达式的建立 状态空间分析
本卷考法
  • 第(1)问取路程与速度为状态变量写出状态空间表达式
本卷实例
  • 关键一步：取路程与速度为状态，把二阶方程拆成两个一阶方程
  • 关键一步：按矩阵形式写出系统矩阵与输入矩阵，输出取路程时相应行
  • 中间结果：本题系统矩阵为二阶方阵，第二行含阻尼与质量之比
  • 卡点：状态变量个数与阶数不匹配；或输出方程取错状态
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过第(1)问取路程与速度为状态变量写出状态空间表达式
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 第(2)问求系统稳态时的速度值
本卷实例
  • 关键一步：稳态时加速度为零，由运动方程令导数为零
  • 关键一步：解出稳态速度与牵引力和阻尼系数的关系
  • 中间结果：本题速度方程是一阶惯性型，稳态值由外作用除以阻尼系数给出
  • 卡点：把稳态速度当成给定输入值；或忽略阻力项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过第(2)问求系统稳态时的速度值
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

二二、画结构图与扰动稳态误差#

思路
  • 由微分方程组画结构图求输出，再按给定与扰动均为斜坡求使稳态误差为零的参数
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 第(1)问由系统结构图求输出与输入的传递函数
本卷实例
  • 关键一步：识别回路与前向通路，用梅森公式或等效化简求输出对输入的传函
  • 关键一步：把控制器含微分的形式提到分子，保持分母为特征式
  • 中间结果：本题输出传函分子含微分项，分母为二阶特征多项式
  • 卡点：反馈极性取反；或化简时漏掉局部回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过第(1)问由系统结构图求输出与输入的传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由结构图写出扰动到输出的传递函数
本卷实例
  • 关键一步：求扰动通道时把参考输入置零，单独看扰动作用点
  • 关键一步：用叠加原理把输出写成输入项与扰动项之和
  • 中间结果：扰动传函的分子由扰动作用点到输出的前向通路决定
  • 卡点：两个通道混算；或扰动传函分母写成另一个式子
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由结构图写出扰动到输出的传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
扰动作用下的稳态误差 稳态误差
本卷考法
  • 按输入与扰动均为单位斜坡、求使系统稳态误差为零的参数
本卷实例
  • 关键一步：分别写出输入误差与扰动误差，用终值定理求各自稳态值
  • 关键一步：令两部分稳态误差之和为零，解出微分系数参数
  • 中间结果：本题要求输入项与扰动项的稳态误差恰好相互抵消
  • 卡点：只算一个通道的误差；或未先判稳就用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过按输入与扰动均为单位斜坡、求使系统稳态误差为零的参数
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

思路
  • 由三个微分方程求各环节传函与误差传函，用劳斯判据求稳定的参数范围，再按稳态误差要求定范围
状态空间表达式的建立 状态空间分析
本卷考法
  • 第(1)问对微分方程组取拉氏变换求误差传递函数
本卷实例

  • 关键一步：消去中间变量，整理出误差对输入的传递函数
  • 中间结果：本题各环节分别为比例、积分加惯性、惯性环节，可串成开环传函
  • 卡点：零初始条件遗漏；或消元时把反馈变量丢掉
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 写出系统的 A、B、C、D 矩阵

  • 输出方程中漏掉直接传递项 D

劳斯判据 稳定性分析
本卷考法
  • 第(2)问用劳斯判据求系统闭环稳定时增益的范围
本卷实例
  • 关键一步：先写出闭环特征方程并按降幂排列，缺项补零
  • 关键一步：列劳斯表并令首列元素全部大于零，解出增益范围
  • 中间结果：本题只由一个首列元素的正负给出增益上界
  • 卡点：首列出现零不用特殊处理；或漏列某一行
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过第(2)问用劳斯判据求系统闭环稳定时增益的范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

系统型别与静态误差系数 稳态误差
本卷考法
  • 第(3)问由单位阶跃加单位斜坡输入的稳态误差要求求增益范围
本卷实例
  • 关键一步：分别求静态位置误差系数与速度误差系数
  • 关键一步：把阶跃项与斜坡项的稳态误差相加，令其不大于给定上界
  • 中间结果：本题阶跃项无差、误差全部来自斜坡项，给出增益的下界
  • 卡点：把位置误差与速度误差系数混用；或漏掉两项相加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

通用考法
  • 本卷考过第(3)问由单位阶跃加单位斜坡输入的稳态误差要求求增益范围

  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 综合稳定性与稳态误差要求取增益的公共范围
本卷实例
  • 关键一步：把劳斯判据给出的上界与稳态误差给出的下界取交集
  • 关键一步：注意区间端点的开闭由不等式严格性决定
  • 中间结果：本题最终范围为左闭右开区间，两端由两条要求分别给出
  • 卡点：只满足一项要求就下结论；或端点开闭写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差

通用考法

  • 比较不同型别系统的跟踪能力

四四、闭环根轨迹与指定极点求参数#

思路
  • 参数 a 取不同值时画闭环根轨迹，再由给定闭环极点反求增益与另外两个极点
根轨迹的绘制法则 根轨迹法
本卷考法
  • 第(1)问按绘制法则画闭环根轨迹草图
本卷实例
  • 关键一步：标出开环零极点，判断实轴根轨迹段与渐近线位置
  • 关键一步：求分离点并去掉不在根轨迹上的解
  • 中间结果：本题开环有两个重积分极点，渐近线与实轴垂直
  • 卡点：分离点方程的解不筛选；或重极点处理出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过第(1)问按绘制法则画闭环根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 结合根轨迹与虚轴交点分析稳定范围
本卷实例
  • 关键一步：复平面上的根轨迹分支走向决定系统何时失稳
  • 关键一步：分离点与虚轴交点把参数轴分成稳定与不稳定两段
  • 中间结果：本题稳定范围由根轨迹留在左半平面的那一段参数给出
  • 卡点：把分离点误当成虚轴交点；或稳定段判反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
