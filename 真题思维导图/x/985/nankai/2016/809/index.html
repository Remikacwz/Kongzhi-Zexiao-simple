一一、参数根轨迹与性能分析#

思路
  • 结构图含可变参数 a，先画参数根轨迹，再由根轨迹求临界稳定的 a 值、稳定取值范围，以及阶跃响应有超调与无超调时 a 的范围和等幅振荡频率。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以参数 a 为变量画参数根轨迹
本卷实例
  • 关键一步：把特征式整理成一加 a 乘某个传递函数为零的标准形式
  • 中间结果：参数根轨迹的起点与终点由原系统的开环零极点互换
  • 卡点：结构图为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以参数 a 为变量画参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 本卷考过整理时没有把参数完整地提到分子位置
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

本卷考法
  • 由根轨迹与虚轴交点求临界 a 值与稳定范围
本卷实例
  • 关键一步：令特征式为零代入纯虚根求出交点频率与临界 a
  • 中间结果：临界 a 把参数轴划分为稳定的区间
  • 卡点：要取根轨迹落在左半平面的那段对应稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法

  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 本卷考过只代一个 omega 就下结论，漏掉另一组交点
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

本卷实例

二二、参数稳定域与特征值左侧约束#

思路
  • 开环传函含未知常数 a，先列闭环特征式用劳斯判据求稳定 a 的范围，再平移虚轴求特征值全在 s 等于负一左侧的 a 范围。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求使闭环稳定的 a 范围
本卷实例
  • 关键一步：由开环传函写闭环特征式再列劳斯表
  • 中间结果：令劳斯表首列各元同号得 a 的不等式组
  • 卡点：a 与增益出现在同一系数里要分别讨论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求使闭环稳定的 a 范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过系数有缺项时不补零，直接套用判据
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

参数稳定域的确定 稳定性分析
本卷考法

本卷实例

  • 中间结果：在 d 平面按劳斯判据得新的 a 不等式组
  • 卡点：平移后的新特征式系数要重新展开再判
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集

  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法

  • 比较不同参数对稳定域大小的影响
常见易错
  • 本卷考过只列出部分首列元素的不等式，漏掉某个约束
  • 只列出部分首列元素的不等式，漏掉某个约束

三三、延迟系统奈奎斯特稳定范围#

思路
  • 开环为一阶惯性环节串纯延迟，先画奈奎斯特图，再由曲线与负实轴交点求系统稳定时延迟时间 tau 的取值范围。
含纯延迟环节的系统稳定性 稳定性分析
本卷考法
  • 求含纯延迟系统稳定时延迟时间的取值范围
本卷实例
  • 关键一步：纯延迟只改变相位不改变幅值，据此写幅相表达式
  • 中间结果：由曲线与负实轴的临界交点写相位条件
  • 卡点：相位里的 tau 乘 omega 要换算角度与弧度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 延迟环节 e^{-τs} 的幅值为 1、相位为 -τω，只恶化相位
  • 延迟会显著缩小稳定域，τ 越大越难稳定
  • 频域判据需用相位裕度扣除延迟引起的附加滞后
步骤
  • 写出含延迟的开环传递函数
  • 分别求幅值与相位表达式
  • 在相频特性中扣除 τω 的滞后量
  • 按稳定裕度或奈氏判据求临界 τ 或临界 K
通用考法
  • 本卷考过求含纯延迟系统稳定时延迟时间的取值范围
  • 求使系统稳定的最大延迟时间
  • 求含延迟系统的临界开环增益
  • 分析延迟对稳定裕度的影响
常见易错
  • 本卷考过把延迟环节当成惯性环节处理
  • 把延迟环节当成惯性环节处理
  • 相位计算时忘记角度与弧度换算
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由奈奎斯特图判断含延迟闭环系统的稳定性
本卷实例
  • 关键一步：先确认开环无右半平面极点再按包围情况判稳
  • 中间结果：延迟增大使曲线不断卷入临界点
  • 卡点：延迟较大时曲线可能多次包围临界点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由奈奎斯特图判断含延迟闭环系统的稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过没有先数开环右半平面极点数 P
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

四四、采样系统稳定与最少拍控制#

思路
  • 含零阶保持器的离散系统，先求开环脉冲传递函数并用 z 域条件求稳定 K 范围，再按单位斜坡输入的最少拍要求设计数字控制器 D(z)。
脉冲传递函数 离散控制系统
本卷考法
  • 由含零阶保持器的结构图求开环脉冲传递函数
本卷实例
  • 关键一步：把连续部分与零阶保持器乘积整体作 z 变换
  • 中间结果：开环脉冲传函的极点数与连续部分阶数相关
  • 卡点：采样开关位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过由含零阶保持器的结构图求开环脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错

  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)

五五、现代控制问答题#

思路
  • 四问：能控子空间与非奇异变换、离散化对能控能观的影响；完全能控与极点任意配置；观测器极点任意配置的条件；分离定理、状态估计反馈与输出动态补偿器。
能控性与能观性 状态空间分析
本卷考法
  • 第(1)问：判断关于能控子空间与非奇异变换的四个论断
本卷实例
  • 关键一步：逐条判断并用能控能观判据的秩条件说明理由
  • 中间结果：非奇异变换不改变能控性与能观性
  • 卡点：连续系统能控时离散化后可能不能控
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法

  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错

  • 中间结果：输出反馈不改变能观性由对偶关系得到
  • 卡点：输出反馈与状态反馈的证明思路不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过证明经输出反馈后系统能观性不变
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 本卷考过把输出反馈的证明与状态反馈的证明混为一谈
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
