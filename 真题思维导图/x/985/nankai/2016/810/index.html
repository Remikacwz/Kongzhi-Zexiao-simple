二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 第1问：写二阶系统标准形式并讨论阻尼比变化
本卷实例
  • 关键一步：先化为标准二阶形式再按阻尼比分区讨论
  • 中间结果：阻尼比为零时等幅振荡，负值时发散
  • 卡点：阻尼比从负无穷到正无穷需分段说明
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法

本卷考法

本卷实例
  • 关键一步：从提高增益、增加积分环节、复合控制三方面分述
  • 中间结果：提高增益与增加积分环节都会牵动稳定性
  • 卡点：每条措施要同时写出代价，不能只罗列
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤

  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标

  • 由相频特性求 ∠G=-180° 对应的频率 ωg

  • 由裕度符号判断稳定性
