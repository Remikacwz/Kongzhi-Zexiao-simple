一一、根轨迹绘制与稳态误差#

思路
  • 先按法则画 G=K/(s(s+1)(s+4)) 的根轨迹并求分离点与虚轴交点；再由型别与静态速度误差系数求阶跃加斜坡组合输入下的稳态误差
根轨迹的绘制法则 根轨迹法
本卷考法

本卷实例
  • 关键一步：由三个开环极点定实轴段、渐近线与分离点
  • 中间结果：三条轨迹分支起始于极点、终止于无穷远
  • 卡点：渐近线夹角公式分子是二 k 加一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤

  • 按对称性连接各段并标出对应 K 值

思路
  • 先列闭环特征式用劳斯判据求参数稳定范围；再令 s 等于 d 减一平移虚轴，在 d 平面用劳斯判据求特征值全在 s 等于负一左侧的参数范围
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据确定使闭环系统稳定的参数范围
本卷实例

  • 中间结果：令劳斯表首列各元素大于零得参数不等式
  • 卡点：参数出现在首列时要单独讨论其符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理

  • 检查首列符号：全同号则稳定，有变号则数出个数
