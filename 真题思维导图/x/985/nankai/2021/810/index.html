1简答题：线性判断、稳定判据、超前校正、采样保持、稳定增益50 分#

思路
  • 第一题含5个独立简答小题：先按齐次性与叠加性判断两个时域方程；再列举四种稳定性判据；接着叙述串联超前校正步骤；说明采样器与保持器的概念及影响；最后用劳斯判据求单位反馈系统的稳定增益范围。
非线性系统的特点 非线性系统
本卷考法
  • 第1问：判断给定时域方程是线性定常还是非线性系统
本卷实例
  • 关键一步：按齐次性与叠加性逐项检验题给两个方程是否满足
  • 中间结果：含输入平方项与时间乘导数的那个方程不满足叠加性
  • 卡点：时变与非线性是两回事，判据要分别说明
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过第1问：判断给定时域方程是线性定常还是非线性系统
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 本卷考过把含时变系数的方程误判为非线性
  • 本卷考过忽略常数项不影响线性性
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
劳斯判据 稳定性分析
本卷考法
  • 第2问：列举四种判断系统稳定性的方法
本卷实例
  • 关键一步：从时域代数判据与频域判据两类各举出方法
  • 中间结果：可答特征根左半平面、劳斯判据、奈氏判据与相角裕度
  • 卡点：题目要求四种，多答的判据要确认其适用对象
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过第2问：列举四种判断系统稳定性的方法
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过只答连续系统判据而漏掉离散系统的朱利判据
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

超前校正 系统校正
本卷考法
  • 第3问：叙述串联超前校正的设计步骤
本卷实例
  • 关键一步：先由稳态误差定开环增益，再算未校正系统的剪切频率与相角裕度
  • 中间结果：由所需最大超前角反解网络参数再定时间常数
  • 卡点：检验校正后裕度时要重新求剪切频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过第3问：叙述串联超前校正的设计步骤
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 本卷考过补偿角未把剪切频率移动带来的附加滞后算进去
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

采样过程与香农采样定理 离散控制系统
本卷考法
  • 第4问：写出采样器与保持器的概念及对离散系统的影响
本卷实例
  • 关键一步：分别说明采样器的取值功能与零阶保持器保持一个周期的功能
  • 中间结果：保持器带来附加相位滞后，会使系统稳定性下降
  • 卡点：采样周期过小加大计算量，过大则容易失真
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过第4问：写出采样器与保持器的概念及对离散系统的影响
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 本卷考过把保持器的影响说成只改变幅值而不产生相位滞后
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

2梅森公式求闭环传递函数12 分#

思路
  • 由给出的系统结构图用梅森增益公式求闭环传递函数：先数出全部单独回路写特征式，再找前向通路及其余子式，最后按公式求输出比输入。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求多回路结构图的闭环传递函数
本卷实例
  • 关键一步：先标出全部单独回路与前向通路，再找互不接触的回路组合
  • 中间结果：特征式等于一减各回路和加两两互不接触回路乘积
  • 卡点：结构图以插图给出，回路与前向通路需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求多回路结构图的闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路组合漏计或重复计数
  • 本卷考过余子式未剔除与前向通路接触的回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

3二阶系统动态性能与斜坡稳态误差10 分#

思路
  • 该题分两问：先由闭环传递函数求单位阶跃下的动态性能，再由单位斜坡输入求稳态误差。前问要先把传函化成标准二阶形式求阻尼比与自然频率，后问先判稳再用速度误差系数求误差。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函化为标准二阶形式求阻尼比与自然频率
本卷实例
  • 关键一步：把开环传函整理成自然频率平方比上 s 乘 s 加两倍阻尼比自然频率的形式
  • 中间结果：由常数项定自然频率，由 s 项系数定阻尼比
  • 卡点：本题阻尼比很小，属欠阻尼且系统稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函化为标准二阶形式求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过未把 s 平方项系数归一化就对照标准式
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率求峰值时间、超调量与调节时间
本卷实例
  • 关键一步：把阻尼比与自然频率分别代入三个欠阻尼性能指标公式
  • 中间结果：峰值时间与调节时间都由自然频率与阻尼比共同决定
  • 卡点：阻尼比很小时超调量很大，代公式前先确认落在欠阻尼区间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率求峰值时间、超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过调节时间的两种误差带系数混用
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

  • 判断系统型别

  • 把开环增益与静态误差系数混为一谈

本卷实例

  • 中间结果：斜坡输入下的稳态误差与速度误差系数成反比

4根轨迹绘制与稳定增益范围15 分#

思路
  • 按常规根轨迹法则画含一个零点、四个极点的根轨迹，标出实轴段、渐近线、分离点与虚轴交点，再由与虚轴交点确定闭环稳定的根轨迹增益范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画含零点与重极点的四阶系统根轨迹
本卷实例
  • 关键一步：先标开环零极点，再判实轴段、渐近线与分离点
  • 中间结果：本题有四个开环极点一个零点，三条分支趋于无穷
  • 卡点：渐近线交点要按零极点代数和除以极点数之差计算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
