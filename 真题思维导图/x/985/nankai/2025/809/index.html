1一、拉氏变换、反变换与全响应#

思路
  • 三小问：微分方程取拉氏变换求传函、由传函带初值求反变换、由脉冲响应求阶跃响应
传递函数的定义与基本性质 传递函数
本卷考法
  • 对微分方程取拉氏变换并写出系统传递函数
本卷实例
  • 关键一步：传递函数是在零初始条件下输出与输入的拉氏变换之比，所以求传函时初值项要全部置零
  • 关键一步：对每一项求拉氏变换时，导数的变换会带出初值项，写传函时必须把它们划掉
  • 关键一步：整理成输出比输入后，分母就是特征多项式的各次系数
  • 中间结果：本题左端是二阶导数、一阶导数与本项，右端是输入项，传函的分母是二次三项式、分子是常数
  • 卡点：求传函时把初值项留着，导致多出与输入无关的项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过对微分方程取拉氏变换并写出系统传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
零极点分布与响应模态 传递函数
本卷考法
  • 由传递函数求给定初始条件下的响应
本卷实例
  • 关键一步：非零初值下的响应要把初值项移到方程右端当作等效输入
  • 关键一步：本题给出初始输出值与初始导数，等效输入是这两个初值的组合
  • 关键一步：等效输入与传函分母相乘后即为响应的拉氏变换
  • 关键一步：把结果的部分分式展成两个一阶项，反变换得到两个指数模态的叠加
  • 中间结果：本题等效输入的分子是一次的，部分分式后两个系数符号相反，响应在零时刻恰好等于给定初值
  • 卡点：初值只代了输出值忘了导数项；或把自由响应当成零状态响应，结果在零时刻对不上初值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由传递函数求给定初始条件下的响应
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由零状态脉冲响应求阶跃响应并计入初值影响
本卷实例
  • 关键一步：脉冲响应就是传函的拉氏反变换，所以先对给出的脉冲响应做拉氏变换得到传函
  • 关键一步：阶跃响应等于传函乘输入的拉氏变换再反变换，得到零状态分量
  • 关键一步：题目还给了初始条件，必须再加上由初值决定的自由响应分量，两者相加才是完整响应
  • 中间结果：本题传函分子是一次式，说明微分方程右端含输入的一阶导数
  • 中间结果：阶跃输入会在零时刻给状态导数带来一个跳变
  • 中间结果：把零状态分量与自由分量相加后，用零时刻的值与导数的一次跳变关系可以自检
  • 卡点：只给零状态响应而漏掉由初值引起的自由分量；或忽略分子带来的输入导数项，导致零时刻导数对不上
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由零状态脉冲响应求阶跃响应并计入初值影响
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式

2二、结构图化简、信号流图与误差传函#

思路
  • 对同一张结构图用三种方法做三件事：结构图变换求 C/R、画信号流图、梅森公式求 E/R
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 用结构图变换求闭环传递函数
本卷实例
  • 关键一步：先把并联支路合并、把反馈回路化成等效环节，逐层由内向外化简
  • 关键一步：比较点与引出点需要移动时，移动后要相应改变支路上的环节位置
  • 关键一步：每一步化简后重画一次图，避免在旧图上叠加导致接错
  • 中间结果：化简过程中分母始终保持同一个特征式，可用来检查是否漏掉回路
  • 卡点：引出点前移或后移时忘记补上相应环节；或把并联与串联的等效顺序弄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过用结构图变换求闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图画信号流图
本卷实例
  • 关键一步：信号流图里节点代表信号、支路代表传递关系，比较点对应多个支路进入同一节点
  • 关键一步：把每个方框写成一条带增益的支路，把每个比较点写成节点的多路汇合
  • 关键一步：同一信号被多处引用时只画一个节点、引出多条支路，不能重复设节点
  • 中间结果：画完数一数节点数与支路数，应与结构图里的信号和方框一一对应
  • 卡点：把方框画成节点；或反馈支路的起点接错，导致回路数不对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由结构图画信号流图
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求误差传递函数
本卷实例
  • 关键一步：误差传函要把误差点当作输出节点，从输入到误差点重新找前向通道
  • 关键一步：回路与接触关系与求输出传函时相同，分母共用同一个特征式
  • 关键一步：误差点通常不在闭环回路上，它的余子式往往包含若干回路项，这一点与求输出传函不同
  • 中间结果：本题误差传函的分子是一加若干回路增益，分母与输出传函完全一致
  • 卡点：直接拿输出传函当误差传函；或余子式里把与误差通路接触的回路也算进去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求误差传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式

3三、根轨迹与虚轴交点#

思路
  • 三个极点无零点的开环，画根轨迹、求稳定增益范围、求与虚轴相交时的全部极点
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制系统的根轨迹
本卷实例
  • 关键一步：三个开环极点都在实轴上且无零点，实轴上属于根轨迹的段由「右侧零极点个数为奇数」判定
  • 关键一步：渐近线三条，交点等于极点之和除以极点数，夹角按奇数倍一百八十度三等分
  • 关键一步：分离点用各极点倒数之和为零解出，虚轴交点由相角条件求得
  • 中间结果：分离点出现在两个相邻极点之间，另两条分支沿渐近线方向趋向无穷远
  • 卡点：渐近线条数按极点数减零点数算错；或忘记标出与虚轴的交点与对应增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制系统的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求系统稳定时的增益范围
本卷实例
  • 关键一步：写出闭环特征方程后逐项列劳斯表
  • 关键一步：首列各元素必须同号，逐个列出不等式
  • 关键一步：本题首列的一个元素是增益的一次式、另一个是常数减增益，两者相交给出上下界
  • 中间结果：上界由劳斯表首列中间项为零确定，下界由常数项大于零确定
  • 卡点：只列一个不等式；或把上界当成使系统失稳的增益而不是临界增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求系统稳定时的增益范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴相交时的全部极点
本卷实例
  • 关键一步：临界增益下特征方程可因式分解，把与虚轴相交这一条件代入后能提出一个实因式
  • 关键一步：剩下的二次因式给出共轭纯虚根，其绝对值就是角频率
  • 关键一步：题目问的是全部极点，除了虚轴上的两个还要把那个实极点一并写出
  • 中间结果：临界增益代回后特征方程可写成一次因式与二次因式相乘，二次因式系数正好给出共轭纯虚根
  • 卡点：只给虚轴上的两个根而漏掉实极点；或因式分解时符号弄错导致根不全
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴相交时的全部极点
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式

4四、频域画图与串联校正设计#

思路
  • 先画奈氏图与 Bode 图求截止频率和相角裕度，再在给定截止频率与裕度指标下设计串联校正
奈奎斯特判据 稳定性分析
本卷考法
  • 绘制给定开环传函的奈奎斯特图
本卷实例
  • 关键一步：开环含一个积分环节，ω 趋于零时幅值趋于无穷、相角从负九十度起步
  • 关键一步：相角随频率下降，曲线从第三象限穿过负实轴进入第二象限并收向原点
  • 关键一步：数包围圈前要补画无穷大半径圆弧，圆弧方向由绕开原点处极点的方向决定
  • 中间结果：曲线穿过负实轴的位置只与时间常数有关，与增益无关，增益只改变交点离原点的远近
  • 卡点：忘记补画无穷大圆弧；或把积分环节的起始相角写成零度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P

  • 由二阶传函写能控标准型，再求状态转移矩阵并离散化
由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 由传递函数列写能控标准型并写出各系数矩阵
本卷实例
  • 关键一步：本题分子是常数、分母二次，直接项为零，是严真分式
  • 关键一步：系统矩阵取友矩阵形式：第一行是零与一，第二行由分母系数取负后按低阶到高阶排列
  • 关键一步：输入矩阵取第二行是一，输出矩阵取第一列是一
  • 中间结果：写出后可用传函公式回算一次，确认分母系数与给定传函一致
  • 卡点：友矩阵两行的排列顺序写反；或输出矩阵位置放错导致传输关系不对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法

  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反

状态转移矩阵 状态空间分析
本卷考法
  • 求能控标准型的状态转移矩阵
本卷实例
  • 关键一步：状态转移矩阵等于系统矩阵乘负一后加复变量单位阵的逆的拉氏反变换
  • 关键一步：二阶矩阵求逆只需交换对角线元素、改变非对角元素符号再除以行列式
  • 关键一步：本题两个极点都是负实根，逆矩阵各元素部分分式后得到两组指数函数的组合
  • 中间结果：四个元素都由两个指数项组成，在零时刻应回到单位阵，可用来验证
  • 卡点：部分分式时系数算错；或忘记在零时刻代回检查是否等于单位阵
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过求能控标准型的状态转移矩阵
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错

连续系统的离散化 离散控制系统
本卷考法
  • 把能控标准型的状态空间表达式离散化
本卷实例
  • 关键一步：离散状态矩阵就是状态转移矩阵在采样周期处的取值，把每一步的指数项换成含采样周期的形式
  • 关键一步：离散输入矩阵由状态转移矩阵与输入矩阵的乘积在采样周期上积分得到
  • 关键一步：可用系统矩阵的逆乘（状态矩阵减单位阵）后再乘输入矩阵来简化
  • 关键一步：写出后按递推式算一两个采样点，与连续解在采样时刻的值比对即可确认
  • 中间结果：系统矩阵可逆时用逆矩阵的办法最省事，注意逆矩阵要先算行列式再改写各元素位置
  • 卡点：把积分结果写成状态矩阵乘输入矩阵而漏掉减单位阵；或采样周期代错位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离散化状态方程由状态转移矩阵在采样周期处的取值构成
  • 输入矩阵是状态转移矩阵与输入矩阵乘积在采样周期上的积分
  • 带零阶保持器时即按上述积分式离散化，输出矩阵不变
步骤
  • 求连续系统的状态转移矩阵
  • 把采样周期代入得到离散状态矩阵
  • 对输入矩阵做积分得到离散输入矩阵
  • 写出差分形式的离散状态方程并按递推求采样点上的响应
通用考法
  • 本卷考过把能控标准型的状态空间表达式离散化
  • 求连续系统在给定采样周期下的离散化状态方程
  • 由给出的状态响应反求系统矩阵再离散化
  • 计算采样点上的状态与输出序列
常见易错
  • 把采样周期直接当成时间常数代进连续传函
  • 积分上限写成采样周期以外的量，或忘记乘输入矩阵

9九、离散最优控制的动态规划法#

思路
  • 一阶离散状态方程与二次型性能指标，用动态规划法倒推求各拍最优控制与最优轨线
动态规划与离散最优控制 最优控制
本卷考法
  • 用动态规划法求各拍的最优控制与最优轨线
本卷实例
  • 关键一步：从最后一拍开始倒推：先把终端代价写成末拍状态的二次型，再往前把上一拍的控制量求极值
  • 关键一步：求极值时要把下一拍的状态用状态方程代入当前拍的表达式，不能把它当成独立变量
  • 关键一步：本题控制量在代价里是二次的、在状态方程里是一次的，求导后控制量可解成状态的线性函数
  • 中间结果：倒推两拍后，性能指标可写成初始状态平方乘一个系数，控制量与状态的关系也随之确定
  • 中间结果：本题初值取六十一时，各拍的最优控制与状态都是整数，可用这个整齐性核对结果
  • 卡点：倒推时漏掉当前拍的阶段代价；或求极值前没有把下一拍状态代入，导致方程解不出来
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离散最优控制按拍倒推，每一拍都把当前代价与剩余代价一起优化
  • 最优性能指标可写成状态二次型的形式，递推求出系数矩阵
  • 最优控制是状态的线性反馈，反馈系数由递推关系逐拍确定
步骤
  • 写出状态方程与性能指标，确认终端项与阶段代价的形式
  • 从最后一拍开始倒推，求该拍的代价函数与最优控制
  • 把结果代入前一拍继续倒推，直到初始拍
  • 得到各拍的最优控制后，沿状态方程正向递推求出最优轨线
通用考法
  • 本卷考过用动态规划法求各拍的最优控制与最优轨线
  • 用动态规划法求各拍的最优控制与最优轨线
  • 写出倒推过程中的代价函数与最优控制表达式
  • 由给定初值计算最优控制的数值
常见易错
  • 倒推时漏掉当前拍的阶段代价或被控量二次项
  • 求最优控制时忘记把下一拍的状态用状态方程代入当前拍的表达式
