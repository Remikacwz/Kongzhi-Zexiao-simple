南开大学 810 自动控制原理 2025 年真题思维导图

985 院校共 6 题合计 150 分

难度：中等　6 个大题 150 分；第一题 5 个简答横跨传函时域方程、二阶响应存在性、根轨迹、延迟稳定与采样定理，后五题依次考结构图与扰动补偿、二阶系统裕度、根轨迹、对数频率特性、零阶保持器采样系统，知识面宽

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

1、2、3、4、5简答：时域方程、响应存在性、根轨迹、延迟与采样50 分#

思路
  • 五个小问各自独立，分别把传函与微分方程、离散传函与差分方程对应起来；判断给定阶跃响应是否为二阶系统响应；判断实轴根轨迹段并用劳斯表数不稳定极点；分析纯延迟系统对任意延迟都稳定的增益范围；按采样定理由输入最高频率求最低采样频率。
传递函数的定义与基本性质 传递函数
本卷考法
  • 连续传函与微分方程的对应关系
本卷实例
  • 关键一步：由零初始条件下的拉氏变换关系，把输出与输入的比值写成传函，再反推微分方程
  • 中间结果：分母各次幂对应输出导数的各阶系数，分子对应输入导数的各阶系数
  • 卡点：零初始条件是写传函的前提；微分方程与传函的系数顺序容易按升幂抄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过连续传函与微分方程的对应关系
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

z 变换与 z 反变换 离散控制系统
本卷考法
  • 离散传函与差分方程的对应关系
本卷实例
  • 关键一步：对差分方程两边取 z 变换并令零初始条件，输出与输入的 z 变换之比就是离散传函
  • 中间结果：差分方程阶数等于传函分母 z 的最高次幂，各项系数按降幂一一对应
  • 卡点：z 变换的延迟性质会带出超前项；指数中的采样周期 T 不要漏掉
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • z 变换是离散信号的拉氏变换，令 z=e^{Ts} 得到
  • 常用函数的 z 变换要熟记
  • z 反变换可用部分分式法、幂级数法或留数法
  • 左半 s 平面映射到 z 平面单位圆内
步骤
  • 将连续传递函数展开为部分分式
  • 逐项查表做 z 变换
  • 需要时做 z 反变换求时间序列
通用考法
  • 本卷考过离散传函与差分方程的对应关系
  • 求给定函数的 z 变换
  • 求 z 反变换得到采样序列
  • 说明 s 平面与 z 平面的映射关系
常见易错
  • 把 z 变换结果中的 e^{-aT} 写成 e^{-a}
  • 部分分式分解时漏项导致反变换出错

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由给定阶跃响应表达式判断其是否为二阶系统响应
本卷实例
  • 关键一步：把题给响应与二阶欠阻尼标准阶跃响应逐项对照，稳态值、衰减指数、振荡频率与初相都要吻合
  • 中间结果：标准响应中初相由阻尼比的反余弦给出，衰减指数与振荡频率又同时约束两个参数
  • 卡点：四个特征量需同时成立，只用其中两条会误判；零时刻不为零也提示不是零初值标准响应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由给定阶跃响应表达式判断其是否为二阶系统响应
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与上升时间反求二阶系统参数
本卷实例
  • 关键一步：先用超调量公式由给定超调量解出阻尼比，再把阻尼比与上升时间代入上升时间公式求自然频率
  • 中间结果：本题超调量对应一个常用阻尼比，反解后自然频率由上升时间与阻尼比共同确定
  • 卡点：上升时间公式的分子是 pi 减初相，不是峰值时间公式；求出的阻尼比要落在欠阻尼区间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与上升时间反求二阶系统参数
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

根轨迹的绘制法则 根轨迹法
本卷考法
  • 确定实轴上属于根轨迹的线段并画根轨迹
本卷实例
  • 关键一步：逐段数实轴右侧开环零极点的总数，为奇数则该段属于根轨迹
  • 中间结果：本题无开环零点，四个重极点位于原点，实轴上只有负实轴的一段属于根轨迹
  • 卡点：原点处四重极点要按重数计入，否则实轴段会判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过确定实轴上属于根轨迹的线段并画根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

劳斯判据 稳定性分析
本卷考法
  • 用劳斯表数出右半平面闭环极点的个数
本卷实例
  • 关键一步：写出闭环特征方程后列劳斯表，首列符号变化次数就是右半平面极点数
  • 中间结果：特征方程含 s 的四次因子，劳斯表首列会出现零，需要先用 epsilon 法处理
  • 卡点：首列出现零时不能直接停下列表；虚轴上的根要单独说明，不能都算不稳定极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯表数出右半平面闭环极点的个数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

含纯延迟环节的系统稳定性 稳定性分析
本卷考法
  • 求使含纯延迟系统对任意延迟都稳定的开环增益范围
本卷实例
  • 关键一步：延迟环节幅值为一、只附加相位滞后，对任意延迟都稳定等价于幅相曲线起点位于单位圆内
  • 中间结果：无延迟时幅相曲线起点在正实轴，起点到原点的距离由开环增益与静态增益决定
  • 卡点：题面待求量与固定量被 OCR 吃掉，按答案段读作求增益范围、延迟任意，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 延迟环节 e^{-τs} 的幅值为 1、相位为 -τω，只恶化相位
  • 延迟会显著缩小稳定域，τ 越大越难稳定
  • 频域判据需用相位裕度扣除延迟引起的附加滞后
步骤
  • 写出含延迟的开环传递函数
  • 分别求幅值与相位表达式
  • 在相频特性中扣除 τω 的滞后量
  • 按稳定裕度或奈氏判据求临界 τ 或临界 K
通用考法
  • 本卷考过求使含纯延迟系统对任意延迟都稳定的开环增益范围
  • 求使系统稳定的最大延迟时间
  • 求含延迟系统的临界开环增益
  • 分析延迟对稳定裕度的影响
常见易错
  • 把延迟环节当成惯性环节处理
  • 相位计算时忘记角度与弧度换算

奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据分析螺旋形幅相曲线的包围情况
本卷实例
  • 关键一步：先数开环右半平面极点数，再看幅相曲线对临界点的净包围圈数
  • 中间结果：含延迟的幅相曲线是向内旋转的螺旋线，第一次与负实轴的交点决定稳定边界
  • 卡点：无穷大半径圆弧的补画方向容易漏；包围圈数正负号容易写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据分析螺旋形幅相曲线的包围情况
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

采样过程与香农采样定理 离散控制系统
本卷考法
  • 由输入信号最高频率确定最低采样频率
本卷实例
  • 关键一步：先用倍角公式把正弦平方项化成单一频率分量，再找出所有分量中的最高角频率
  • 中间结果：展开后信号含零频、三次与四次分量，最高角频率为四弧度每秒
  • 卡点：答案段把最高频率当成最低采样频率，采样定理要求两倍最高频率，两种读法需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过由输入信号最高频率确定最低采样频率
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

二结构图化简与扰动补偿20 分#

思路
  • 第一问由图求闭环传递函数，第二问分析开环幅频特性何时单调递减，第三问用信号流图求扰动到输出的传函并令其为零，从而解出使扰动对输出无影响的补偿环节。题面含图未读图，按答案段读出的回路与通路结构写。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由含局部反馈的结构图求闭环传递函数
本卷实例
  • 关键一步：先合并串联支路，再把反馈回路化成等效环节，最后写成输出比输入
  • 中间结果：无扰动时开环是积分环节与常数增益的串联，闭环为一阶惯性形式
  • 卡点：题面结构图未读，回路支路与反馈系数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法

  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

典型环节的对数频率特性 频域分析
本卷考法
  • 判断开环幅频特性是否随频率单调递减
本卷实例
  • 关键一步：把开环写成典型环节乘积后，分别写出幅频与相频表达式
  • 中间结果：开环含一个积分环节时幅值与频率成反比，叠加常数增益后仍单调递减
  • 卡点：常数增益只改变幅频曲线高度，不改变单调性；题面参数名被 OCR 吃掉，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例环节是水平线，积分与微分分别是 -20 与 +20 dB/dec 的斜线
  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec
  • 一阶微分环节与惯性环节幅频互为镜像
  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤
  • 把传递函数分解为典型环节乘积
  • 逐环节画出对数幅频渐近线与相频曲线
