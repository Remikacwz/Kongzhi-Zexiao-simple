思路

欠阻尼动态性能指标 时域响应与动态性能
本卷考法

本卷实例
  • 关键一步：由稳、准、快三条基本要求引出时域性能指标
  • 中间结果：上升时间、峰值时间、调节时间与超调量是常用时域指标
  • 卡点：稳态误差属准确性指标，不要混进动态性能指标
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关

二二、微分方程求传函与全响应#

思路
  • 由输入输出微分方程求传递函数与动态指标，再在非零初始条件下求斜坡输入的输出响应拉氏变换。
传递函数的定义与基本性质 传递函数
本卷考法
  • 第1问：由输入输出微分方程求传递函数
本卷实例
  • 关键一步：对微分方程取零初始条件拉氏变换再整理成比值
  • 中间结果：传递函数为标准二阶有理分式形式
  • 卡点：整理时先把输入项移到等号右边
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过第1问：由输入输出微分方程求传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过忽略零初始条件，把初始值带进变换结果
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 第3问：求非零初始条件下斜坡输入的输出响应拉氏变换
本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

本卷考法

本卷实例

  • 卡点：反解出增益后要回代校验系统是否稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤

  • 写出输入信号的拉氏变换

  • 必要时按叠加原理分别计算各分量

常见易错

  • 未判稳就使用终值定理

  • 关键一步：按不变性原理令对应误差传函的分子为零反解补偿器
  • 中间结果：给定补偿与扰动补偿分别由两条通道传函反解
  • 卡点：补偿器要检查是否物理可实现
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过第2、3问：设计补偿器使给定与扰动单独作用时稳态误差为零

  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 本卷考过忽略反馈校正可能引起的高频噪声放大
