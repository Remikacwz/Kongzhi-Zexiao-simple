传递函数的定义与基本性质 传递函数
本卷考法
  • 第1问：简述传递函数的概念及其性质
本卷实例
  • 关键一步：从零初始条件下输出与输入拉氏变换之比定义传递函数
  • 中间结果：传递函数是复变量 s 的有理真分式
  • 卡点：性质要答到只由结构与参数决定、不反映内部信息
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法

  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错

  • 忽略“零初始条件”这一前提，把初始值带进变换结果

减小稳态误差的措施 稳态误差
本卷考法
  • 第2问：简述两种减小稳态误差的方法
本卷实例
  • 关键一步：从开环增益、系统型别、串联校正与前馈四条路答
  • 中间结果：提高增益或增加积分环节可减小误差但影响稳定
  • 卡点：答两种即可，多答要有序且各自说清代价
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
