1一、闭环传函与参数稳定域#

思路
  • 由开环传函写闭环传函，列劳斯表得到使系统稳定的两个参数不等式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由开环传函求单位负反馈系统的闭环传函
本卷实例
  • 关键一步：按单位负反馈把闭环传函写成开环比上一加开环
  • 中间结果：整理分母时把各项按 s 的降幂排列
  • 卡点：分子含 s 的一次项，别与分母的常数项混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由开环传函求单位负反馈系统的闭环传函
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过把负反馈的分母写成 1 减开环传函
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

劳斯判据 稳定性分析
本卷考法
  • 列劳斯表判断含两个参数时系统的稳定性
本卷实例
  • 关键一步：写出三阶特征式后逐行列劳斯表
  • 中间结果：首列全正等价于两个参数的两个不等式
  • 卡点：参数作分母时要单独讨论其符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过列劳斯表判断含两个参数时系统的稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过系数有缺项时不补零就直接套判据
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

本卷考法
  • 求使系统稳定的两个参数的取值范围
本卷实例

  • 中间结果：两个不等式分别给出参数上界与下界，取交集

2二、根轨迹绘制与稳定域#

思路
  • 三个实极点无零点，绘根轨迹，求分离点与虚轴交点，从而给出稳定增益范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制三个实极点系统的根轨迹
本卷实例
  • 关键一步：先标出三个开环极点并判各实轴段是否属于根轨迹
  • 中间结果：三条分支都趋向无穷远，渐近线交点在极点平均处
  • 卡点：实轴段按右侧实零极点数为奇数来判，不是偶数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制三个实极点系统的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴段判据中的零极点个数算错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

本卷考法

本卷实例

  • 求根轨迹的分离点坐标

  • 判断解的取舍

  • 求出方程根后不筛选，保留了不在根轨迹上的解

本卷实例

3三、对数频率特性与串联超前校正#

思路
  • 由稳态误差反求增益，画对数渐近线求截止频率与裕度，因指标要求更高而设计超前校正
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡下的稳态误差反求开环增益
本卷实例
  • 关键一步：一型系统速度误差系数等于开环增益，据此换出增益
  • 中间结果：回代特征式确认该增益下系统稳定
  • 卡点：题干开的开环传函漏印增益，按答案段补上再算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法

  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过把开环增益与速度误差系数混为一谈
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
