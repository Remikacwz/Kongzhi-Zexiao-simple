1简答题：频域参数、校正方式、稳定裕度、线性判断、谐振峰值50 分#

思路
  • 第一题含5个独立简答小题：先解释开环截止频率、穿越频率与闭环带宽；再简述四种常用校正方式；说明稳定裕度的定义与幅值裕度的物理意义；判断题给五个方程的类型；最后求使正弦输出幅值最大的输入频率。
频率特性的物理意义与求法 频域分析
本卷考法
  • 第1问：解释开环截止频率与穿越频率的定义
本卷实例
  • 关键一步：分别从幅值为一与相角为负一百八十度两个条件给出定义
  • 中间结果：两个频率分别对应幅频曲线与相频曲线上的特征点
  • 卡点：题面末尾为 OCR 噪声，含义按标准定义理解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过第1问：解释开环截止频率与穿越频率的定义
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过把截止频率与相位穿越频率的定义互换
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

非线性系统的特点 非线性系统
本卷考法
  • 第4问：判断五个方程是线性定常、线性时变还是非线性
本卷实例
  • 关键一步：先看是否满足齐次性与叠加性，再看系数是否含时间
  • 中间结果：系数含时间的为线性时变，含变量高次项或乘积的为非线性
  • 卡点：常数项不影响线性性，含时间因子才会造成时变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过第4问：判断五个方程是线性定常、线性时变还是非线性
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错

  • 把非线性环节线性化后直接沿用线性理论的全部结论
