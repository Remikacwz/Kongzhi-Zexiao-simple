1一、信号流图与稳定域、误差#

思路
  • 由系统结构图画信号流图，分别求参考与扰动传函，再由闭环特征方程定稳定增益范围与稳态误差
梅森增益公式与信号流图 传递函数
本卷考法
  • 由系统结构图画信号流图并用梅森公式求闭环传函
本卷实例
  • 关键一步：把方框与比较点改画成节点与带增益的有向支路
  • 中间结果：先数清回路数与其间的接触关系，再写特征式
  • 卡点：系统结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由系统结构图画信号流图并用梅森公式求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过把互不接触回路漏掉或重复计入
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

本卷考法
  • 分别求参考输入与扰动输入到输出的传递函数
本卷实例

  • 中间结果：两种输入共用同一个特征式，差别只在前向通路
  • 卡点：题干印的环节参数与答案段编号不一致，需回原卷核对图

要点

  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤

  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

劳斯判据 稳定性分析
本卷考法
  • 由闭环特征方程列劳斯表求稳定增益范围
本卷实例
  • 关键一步：把整理好的闭环特征式逐项填入劳斯表
  • 中间结果：首列两个含参元素都大于零，给出增益区间
  • 卡点：常数项里也含增益，不能当成常值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由闭环特征方程列劳斯表求稳定增益范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过只列一个不等式，漏掉常数项大于零
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

本卷实例

  • 中间结果：型别决定阶跃分量是否为零，斜坡分量与增益成反比

  • 求给定输入下的稳态误差

  • 比较不同型别系统的跟踪能力

  • 未判稳就使用终值定理

2二、根轨迹、出射角与临界极点#

思路
  • 对象含一对共轭复极点，绘根轨迹时重点求出射角、渐近线与虚轴交点，临界增益下求全部闭环极点
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制含共轭复极点的根轨迹
本卷实例
  • 关键一步：先在 s 平面标出实极点与一对共轭复极点
  • 中间结果：实轴段只在最左实极点左侧，三条分支沿渐近线趋于无穷
  • 卡点：复极点对的实部相同，渐近线交点要按三个极点求和
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制含共轭复极点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过渐近线条数按极点数减零点数算错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

出射角与入射角 根轨迹法
本卷考法
  • 求共轭复极点的出射角
本卷实例
  • 关键一步：对出射极点列相角条件，减去其他零极点贡献的相角
  • 中间结果：一对共轭极点的出射角互为相反数
  • 卡点：出射角标在复极点附近，别与渐近线夹角混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 入射角是根轨迹进入开环零点的方向

  • 求复数极点的出射角

  • 由入射角确定根轨迹终止方向
常见易错
  • 本卷考过累加相角时把该极点自身的相角也算进去
  • 累加相角时把该极点自身的相角也算进去

开环对数频率特性的绘制 频域分析

稳定裕度 频域分析
本卷考法
  • 求相角裕度
本卷实例
  • 关键一步：把截止频率代入相频表达式求相角裕度
  • 中间结果：相角裕度等于一百八十度加上该点的相角
  • 卡点：裕度不足时先看是相位不够还是幅值衰减不够
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求相角裕度

  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错

  • 把 ωc 与 ωg 两个频率用反

  • 非最小相位系统仍用同一判据

脉冲传递函数 离散控制系统
本卷考法
