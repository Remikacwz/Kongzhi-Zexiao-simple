1、2、3、4、5简答：判据选择、系统分类、校正识别与连续离散稳定#

思路
  • 概念题，分别考判据选择、线性时变与非线性判别、图中校正环节识别、连续与离散稳定 K 范围、校正方式分类
劳斯判据 稳定性分析
本卷考法
  • 只给闭环特征方程系数时选劳斯判据
本卷实例
  • 关键一步：按已知条件区分代数判据与频率判据
  • 中间结果：系数已知对应劳斯判据，频率数据对应奈奎斯特判据
  • 卡点：两种已知条件对应两种判据，容易答反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过只给闭环特征方程系数时选劳斯判据
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过把只给频率数据的场合也答成劳斯判据
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 只给开环对数频率响应数据时选奈奎斯特判据
本卷实例
  • 关键一步：由只给频率数据判断应选用频域判据
  • 中间结果：频率数据对应频域判据，无需特征方程
  • 卡点：答判据时要同时给出判据名称与依据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过只给开环对数频率响应数据时选奈奎斯特判据
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过把奈奎斯特判据与对数频率判据的适用条件混淆
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

非线性系统的特点 非线性系统
本卷考法
  • 由微分方程判别线性时变、时不变与非线性系统
本卷实例
  • 关键一步：逐式检验叠加原理并看系数是否显含时间 t
  • 中间结果：系数含 t 为线性时变，含非线性项为非线性
  • 卡点：非线性与时变是两回事，不要混判
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过由微分方程判别线性时变、时不变与非线性系统
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 本卷考过把含时变系数的线性方程误判为非线性
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
校正的基本概念与性能指标 系统校正
本卷考法
  • 说出串联、反馈、前馈与复合四种校正方式
本卷实例
  • 关键一步：按校正装置在系统中的连接位置分类
  • 中间结果：分为串联、反馈、前馈与复合校正四类
  • 卡点：复合校正是串联与反馈或前馈的组合
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过说出串联、反馈、前馈与复合四种校正方式
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 本卷考过漏答前馈校正或复合校正
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求

反馈校正与复合控制 系统校正
本卷考法
  • 在图中指认反馈、串联与前馈校正环节
本卷实例
  • 关键一步：沿误差点与反馈通路区分各校正环节接入位置
  • 中间结果：同时含串联与反馈或前馈即为复合校正
  • 卡点：校正结构以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过在图中指认反馈、串联与前馈校正环节
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 本卷考过把前馈校正环节与反馈校正环节的位置认反
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

参数稳定域的确定 稳定性分析
本卷考法
  • 由闭环特征方程求连续系统稳定的 K 范围
本卷实例
  • 关键一步：列劳斯表并令首列各元素大于零
  • 中间结果：取各不等式交集得到 K 的稳定范围
  • 卡点：开环结构以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由闭环特征方程求连续系统稳定的 K 范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 本卷考过只列部分首列元素不等式，漏掉约束
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

离散系统稳定性分析 离散控制系统
本卷考法
  • 由 z 域特征式求离散系统稳定的 K 范围
本卷实例
  • 关键一步：把闭环特征式化成 z 多项式再用朱利判据
  • 中间结果：特征根全在单位圆内，据此得 K 的上界
  • 卡点：问对任意采样周期都稳定须对 T 作极限讨论
  • 卡点：离散结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过由 z 域特征式求离散系统稳定的 K 范围
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 本卷考过把离散稳定条件写成极点实部小于零
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

二结构图求闭环与误差传递函数#

思路
  • 由结构图画信号流图，用梅森增益公式分别求输出与误差对输入的传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求闭环传递函数 C(s)/R(s)
本卷实例
  • 关键一步：由结构图画信号流图，数通路与互不接触组
  • 中间结果：分子为前向通路增益乘余子式之和
  • 卡点：结构图以图给出，回路需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求闭环传递函数 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过余子式中未剔除与前向通路接触的回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 求误差对输入的传递函数 E(s)/R(s)
本卷实例
  • 关键一步：在误差点列信号关系并用梅森公式求解
  • 中间结果：误差传函与闭环传函分母同为特征式
  • 卡点：误差点位置以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过求误差对输入的传递函数 E(s)/R(s)
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 本卷考过非单位反馈时两种误差定义混用
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

三二阶系统谐振频率与超调量#

思路
  • 先求谐振频率存在时阻尼比的范围与谐振频率表达式，再由谐振峰值求超调量
闭环频率特性与性能指标 频域分析
本卷考法
  • 求二阶系统谐振频率存在的条件与谐振频率
本卷实例
  • 关键一步：对闭环幅频求导取极值，令谐振频率平方为正
  • 中间结果：谐振频率由阻尼比与自然频率共同表示
  • 卡点：先判断阻尼比落在哪个区间再代公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过求二阶系统谐振频率存在的条件与谐振频率
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 本卷考过阻尼比大于 0.707 时仍套用谐振频率公式
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把二阶闭环传函化为标准形式读出阻尼比
本卷实例
  • 关键一步：将给定分母与标准二阶形式逐项对应
  • 中间结果：由系数比对定出阻尼比与自然频率
  • 卡点：题面传函含 OCR 多出符号，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把二阶闭环传函化为标准形式读出阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过化标准形式时忘记把平方项系数归一化
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由谐振峰值求二阶系统的超调量
本卷实例
  • 关键一步：由谐振峰值反求阻尼比再算超调量
  • 中间结果：超调量只由阻尼比确定
  • 卡点：题问的是第一问阻尼比对应的超调量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
