一一、简答题#

思路

本卷考法

本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 振荡次数与 ξ 直接相关

  • 用超调量公式先求 ξ

  • 必要时计算振荡次数

五五、幅相特性与奈氏判稳#

思路
  • 开环传函含一阶微分与两个惯性环节：第1问绘幅相特性曲线，第2问用奈奎斯特判据判断稳定性。
频率特性的物理意义与求法 频域分析
本卷考法
  • 第1问：求幅频与相频表达式并绘幅相特性曲线
本卷实例
  • 关键一步：写出实部虚部后消去频率得轨迹
  • 中间结果：曲线与负实轴有无交点决定判稳
  • 卡点：要算清起点终点与可能的极值点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)

稳定裕度 频域分析
