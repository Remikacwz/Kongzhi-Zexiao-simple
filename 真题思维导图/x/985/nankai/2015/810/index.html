减小稳态误差的措施 稳态误差
本卷考法
  • 第1问：述减小或消除稳态误差的方法
本卷实例
  • 关键一步：从提高开环增益、增加积分环节与复合控制三方面分述
  • 中间结果：提高增益可降误差但受稳定性限制
  • 卡点：增加积分环节会降低相角裕度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过第1问：述减小或消除稳态误差的方法
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错

  • 只谈误差减小而不检查稳定性是否被破坏

奈奎斯特判据 稳定性分析
本卷考法
  • 第4问：述奈奎斯特稳定判据的概念
本卷实例
  • 关键一步：先数开环右半平面极点数再数曲线绕临界点的圈数
  • 中间结果：闭环右半平面极点数由这两个量共同决定
  • 卡点：开环含积分环节时须补画虚轴绕行圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法

  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况

  • 开环含有积分环节时未补画无穷大半径圆弧

五五、奈奎斯特图与稳定性#

思路
  • 开环传函含一个右半平面极点、k 给定，先画奈奎斯特图判断单位反馈闭环稳定性，再讨论 k 减小的影响并求临界 k。
奈奎斯特判据 稳定性分析
本卷考法
  • 由奈奎斯特图判断闭环稳定性并求临界 k
本卷实例
  • 关键一步：先数开环右半平面极点数再数曲线包围次数
  • 中间结果：k 变化使曲线相位不变、各点模成比例变化
  • 卡点：临界 k 由曲线穿过负实轴临界点确定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由奈奎斯特图判断闭环稳定性并求临界 k
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过把包围圈数的正负号定义搞反
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

频率特性的物理意义与求法 频域分析
本卷考法
  • 写出开环频率特性并估算奈奎斯特图走向
本卷实例
  • 关键一步：令 s 等于 j omega 代入开环传函分离实部与虚部
  • 中间结果：曲线起点与终点分别由积分环节与相对阶决定
  • 卡点：右半平面极点使低频段相角起始位置特殊
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过写出开环频率特性并估算奈奎斯特图走向
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过相角累加时漏掉积分环节的负 90 度
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

六六、离散系统稳定判定#

思路
  • 由采样系统结构图，先求开环脉冲传递函数，再写闭环特征方程并用 z 域稳定条件判断系统稳定性。
脉冲传递函数 离散控制系统
本卷考法
  • 由结构图求含零阶保持器的开环脉冲传递函数
本卷实例
  • 关键一步：对连续部分与零阶保持器的乘积整体作 z 变换
  • 中间结果：开环脉冲传函由部分分式分解后逐项查表得到
  • 卡点：采样开关位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过由结构图求含零阶保持器的开环脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 本卷考过把两个无采样开关隔开的连续环节直接相乘
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)

七七、串联校正设计#

思路
  • 单位负反馈系统给定开环增益与相角裕度、幅值裕度要求，按超前校正步骤先算未校正裕度，再定补偿角与网络参数并检验。
超前校正 系统校正
本卷考法
  • 按相角裕度与幅值裕度要求设计串联超前校正网络
本卷实例
  • 关键一步：先由开环增益要求定增益，再算未校正系统的剪切频率与相角裕度
  • 中间结果：由所需最大超前角反解网络参数与时间常数
  • 卡点：校正后要重新求剪切频率检验裕度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过按相角裕度与幅值裕度要求设计串联超前校正网络
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 本卷考过补偿角未把剪切频率移动带来的附加滞后算进去
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

稳定裕度 频域分析
本卷考法
  • 求系统的相角裕度与幅值裕度并检验指标
本卷实例
  • 关键一步：由幅值穿越频率与相位穿越频率分别求两个裕度
  • 中间结果：相角裕度由幅值穿越频率处的相角决定
  • 卡点：幅值裕度以分贝表示时要取倒数再换算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求系统的相角裕度与幅值裕度并检验指标
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过幅值裕度取倒数未取，导致结论反了
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
