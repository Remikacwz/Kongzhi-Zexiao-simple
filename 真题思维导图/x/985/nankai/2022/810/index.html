1简答题：零极点影响、线性判断、PI 控制、频域参数#

思路
  • 第一题含4个独立简答小题：先分析闭环零点、非主导极点与零极点对消对时间响应的影响；再用叠加性判断题给分段函数是否线性；接着说明比例积分控制的作用与实现；最后列举频域分析常用参数并说明定义。
零极点分布与响应模态 传递函数
本卷考法
  • 第1问：分析闭环零极点对系统时间响应特性的影响
本卷实例
  • 关键一步：分别讨论闭环零点、非主导极点与零极点对消三种情形
  • 中间结果：闭环零点使响应加快、超调增大，非主导极点作用相反
  • 卡点：零点越靠近虚轴，对响应的影响越显著
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过第1问：分析闭环零极点对系统时间响应特性的影响
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 本卷考过只看极点分布而忽略零点对模态权重的影响
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 第1问：说明闭环附加零点与主导极点对性能的作用
本卷实例
  • 关键一步：用主导极点概念判断哪些闭环极点可以忽略
  • 中间结果：彼此接近的闭环零极点会对消，系统可降阶
  • 卡点：能否降阶要看零极点距离与该极点的留数大小
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过第1问：说明闭环附加零点与主导极点对性能的作用
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 本卷考过忽略零点对超调量的放大作用
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

非线性系统的特点 非线性系统
本卷考法
  • 第2问：判断题给分段函数描述的系统是否线性
本卷实例
  • 关键一步：分别检验齐次性与叠加性两个条件是否成立
  • 中间结果：题给系统在分段点处不满足叠加性
  • 卡点：要用具体输入举例说明不满足叠加性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过第2问：判断题给分段函数描述的系统是否线性
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 本卷考过把不满足叠加性的系统仍当作线性系统
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
PID 控制器与参数整定 系统校正
本卷考法
  • 第3问：分析比例积分控制对系统的影响与作用方式
本卷实例
  • 关键一步：分别说明比例项与积分项各自对偏差信号的作用
  • 中间结果：积分项提高系统型别、消除静差但可能降低裕度
  • 卡点：积分时间常数越大，积分作用越弱
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过第3问：分析比例积分控制对系统的影响与作用方式
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 本卷考过把积分作用的强弱与积分时间常数的关系说反
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

稳定裕度 频域分析
本卷考法
  • 第4问：列举频域分析常用参数并说明定义与作用
本卷实例
  • 关键一步：从幅频与相频两个角度列出常用特征量
  • 中间结果：相角裕度与幅值裕度分别定义在剪切频率与穿越频率处
  • 卡点：参数要连同定义式与物理意义一起作答
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过第4问：列举频域分析常用参数并说明定义与作用
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过把截止频率与相位穿越频率的定义混用
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

梅森增益公式与信号流图 传递函数

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤

  • 代入公式求总传输
通用考法

  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错

  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路

串联、并联与反馈等效 结构图与方框图
本卷考法

本卷实例

通用考法

3二阶系统参数与动态性能#

思路
  • 系统框图给出待定时间常数。第一问按阻尼比要求反求参数；第二、三问在若干参数组合下求峰值时间、超调量与调节时间，并比较改变阻尼与附加零点对特性的影响。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函标准形式确定阻尼比与自然频率
本卷实例
  • 关键一步：把闭环传函化为二阶标准形式后再逐项对照系数
  • 中间结果：s 项系数等于两倍阻尼比乘自然频率，常数项等于自然频率平方
  • 卡点：本题自然频率由常数项给出，参数组合较特殊
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函标准形式确定阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过未归一化 s 平方项系数就对照标准式
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

  • 最少拍系统的闭环脉冲传递函数由输入类型确定
  • 最少拍设计通常导致很大的控制量，需加限制
