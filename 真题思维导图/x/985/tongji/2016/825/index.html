1一、锅炉液位控制系统方框图10 分#

思路
  • 由锅炉液位控制系统示意图写出控制方框图，并说明各组成部分的作用
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 写出控制方框图并指认各环节功能
本卷实例
  • 关键一步：按给定值、被控量、执行器与测量反馈梳理闭环
  • 中间结果：逐环节说明变送、调节、执行与被控对象作用
  • 卡点：系统示意图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过写出控制方框图并指认各环节功能
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过只画方框图而不说明各环节作用
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 指出被控对象、被控量与操纵量
本卷实例
  • 关键一步：由锅炉液位工艺确定被控量为液位
  • 中间结果：操纵量为调节阀开度并指出主要扰动
  • 卡点：工艺流程图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过指出被控对象、被控量与操纵量
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 本卷考过把被控量与操纵量搞反
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半

2二、机械系统微分方程与传函10 分#

思路
  • 以重力平衡点为初始点列机械系统运动方程，消去中间变量求传递函数
机械系统建模 建模与机电系统
本卷考法
  • 列写含重力平衡的机械系统微分方程
本卷实例
  • 关键一步：以平衡点为原点列合力等于质量乘加速度
  • 中间结果：整理成输入 F 到输出 y 的微分方程
  • 卡点：受力图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过列写含重力平衡的机械系统微分方程
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 本卷考过受力方向容易写反
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由微分方程求输入到输出的传递函数
本卷实例
  • 关键一步：对微分方程两端作拉氏变换
  • 中间结果：整理成输出比输入的有理分式
  • 卡点：方程系数需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由微分方程求输入到输出的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过零初始条件之外仍把初值带入变换
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

3三、由阶跃响应求二阶传函与调节时间#

思路
  • 由单位阶跃响应曲线读超调量与峰值时间，反求二阶传函参数再算调节时间
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由阶跃响应求二阶系统阻尼比与自然频率
本卷实例
  • 关键一步：由超调量与峰值时间公式联立求阻尼比与自然频率
  • 中间结果：代入增益得闭环传递函数
  • 卡点：响应曲线读数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由阶跃响应求二阶系统阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过把 s 平方项系数未归一化就读参数
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 计算给定误差带下的调节时间
本卷实例
  • 关键一步：按题目给定误差带选调节时间公式
  • 中间结果：由阻尼比与自然频率算出调节时间
  • 卡点：误差带要求需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过计算给定误差带下的调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过把两种误差带的调节时间系数搞混
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由阶跃响应曲线反求二阶传递函数
本卷实例
  • 关键一步：先由稳态值确定增益
  • 中间结果：再由峰值与超调量确定动态参数
  • 卡点：曲线坐标需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由阶跃响应曲线反求二阶传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 本卷考过未判断系统阶数就直接套用二阶公式
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

4四、由闭环传函求开环、根轨迹与阻尼比15 分#

思路
  • 由闭环传函反求开环传函，画根轨迹并求阻尼比 0.707 对应的增益
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由闭环传递函数反求开环传递函数
本卷实例
  • 关键一步：由闭环传函等于 G 除以 1 加 G 解出 G
  • 中间结果：整理成开环有理分式
  • 卡点：闭环表达式需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由闭环传递函数反求开环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过负反馈分母写成 1 加 GH 时符号取反
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制闭环系统根轨迹
本卷实例
  • 关键一步：找出开环零点与极点并定分支数
  • 中间结果：按渐近线与实轴段画轨迹
  • 卡点：开环零极点需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制闭环系统根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴段判据的零极点个数算错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式

本卷考法

5五、正弦输入下的稳态输出20 分#

思路
  • 由单位反馈开环传函求闭环频率特性，再按正弦输入的幅值与相角写稳态输出
频率特性的物理意义与求法 频域分析
本卷考法
  • 由开环传函求闭环频率特性并算正弦稳态输出
本卷实例
  • 关键一步：先求闭环传函再代入 s 等于 jω
  • 中间结果：算输入频率处的幅值与相角
  • 卡点：输入幅值与频率需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由开环传函求闭环频率特性并算正弦稳态输出
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过相角累加时漏掉环节的负相角
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

6六、由幅相曲线判断闭环稳定性15 分#

思路
  • 按给定 P 值数奈氏曲线包围临界点圈数，分别判断三条幅相曲线的闭环稳定性
奈奎斯特判据 稳定性分析
本卷考法
  • 由幅相曲线和开环右半平面极点数判断闭环稳定性
本卷实例
  • 关键一步：先读 P 再数曲线对临界点的包围次数
  • 中间结果：按闭环右极点数等于 P 减两倍包围次数判稳
  • 卡点：三条曲线需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
