思路

传递函数的定义与基本性质 传递函数
本卷考法
  • 判断传递函数定义中零初始条件是否必要
本卷实例
  • 关键一步：传递函数须在零初始条件下定义
  • 中间结果：为输出与输入拉氏变换之比
  • 卡点：把非零初始条件下的响应比误当传递函数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过判断传递函数定义中零初始条件是否必要
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 判断一阶系统阶跃响应是否有超调
本卷实例
  • 关键一步：一阶系统只有一个实极点
  • 中间结果：阶跃响应单调上升、无超调
  • 卡点：把过阻尼二阶与一阶的结论混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过判断一阶系统阶跃响应是否有超调
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

频率特性的物理意义与求法 频域分析
本卷考法
  • 判断频率响应的定义是否为稳态正弦响应
本卷实例
  • 关键一步：频率响应指正弦输入下的稳态响应
  • 中间结果：由幅值比与相位差描述
  • 卡点：把瞬态过程也算进频率响应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过判断频率响应的定义是否为稳态正弦响应
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

劳斯判据 稳定性分析
本卷考法
  • 判断稳定性与动态性能各应采用的时域或频域方法
  • 判断稳定性是否只由闭环极点位置决定
本卷实例
  • 关键一步：稳定性取决于闭环极点在 s 平面的位置
  • 中间结果：时域与频域方法都可用于性能分析
  • 卡点：误以为稳定性由输入信号决定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过判断稳定性与动态性能各应采用的时域或频域方法
  • 本卷考过判断稳定性是否只由闭环极点位置决定
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 判断根轨迹分支数与闭环特征方程根数的关系
本卷实例
  • 关键一步：分支数等于闭环特征根数目
  • 中间结果：也等于开环零点数与极点数中的较大者
  • 卡点：把分支数直接等同于开环极点数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过判断根轨迹分支数与闭环特征方程根数的关系
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

本卷实例

  • 中间结果：有利于改善动态性能与稳定度

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法

  • 分析为何某系统需要引入零点
常见易错

  • 把附加零点的影响与附加极点的影响搞反
