1一、RLC电路网络求传递函数#

思路
  • 列KVL、KCL或复阻抗分压，求电容电压对输入电压的传递函数
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由RLC串联电路求电容电压对输入电压的传递函数
本卷实例
  • 关键一步：把电感写成Ls、电容写成1比Cs后用分压公式
  • 中间结果：传递函数为二阶形式，对应RLC振荡环节
  • 卡点：复阻抗法把电容阻抗误写成Cs；忽略后级负载效应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由RLC串联电路求电容电压对输入电压的传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式

2二、机械系统传递函数#

思路
  • 对小车列牛顿方程，由弹簧力与反力关系消去中间变量，求位移对力的传函
机械系统建模 建模与机电系统
本卷考法
  • 由弹簧连接的机械系统列方程求位移对输入力的传递函数
本卷实例
  • 关键一步：对小车列牛顿方程并用弹簧串并联关系消去中间位移
  • 中间结果：等效刚度为两弹簧刚度乘积除以两刚度之和
  • 卡点：弹簧串并联等效刚度公式记反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过由弹簧连接的机械系统列方程求位移对输入力的传递函数
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式

3三、稳定性方法综述与六阶系统判稳#

思路
  • 先列举至少4种稳定性判据，再对六阶特征方程用劳斯表判稳并识别纯虚根
劳斯判据 稳定性分析
本卷考法
  • 列举不少于4种判断系统稳定性的方法
  • 用劳斯判据判断六阶系统稳定性并识别纯虚根
本卷实例
  • 关键一步：列劳斯表，首列出现整行为零时用辅助方程求根
  • 中间结果：首列无变号但存在纯虚根，系统为临界稳定
  • 卡点：首列出现整行为零时未用辅助方程，直接判稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过列举不少于4种判断系统稳定性的方法
  • 本卷考过用劳斯判据判断六阶系统稳定性并识别纯虚根
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
赫尔维茨判据 稳定性分析
本卷考法
  • 把赫尔维茨判据作为稳定性判定方法之一列出
本卷实例
  • 关键一步：用特征方程系数构造赫尔维茨行列式判断稳定性
  • 中间结果：赫尔维茨与劳斯判据结论一致，均依据右半平面根个数
  • 卡点：行列式构造时系数下标写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由特征方程系数构造赫尔维茨行列式
  • 各阶主子式全部大于零 ⇔ 系统稳定
  • 与劳斯判据等价，适合阶数较低时使用
步骤
  • 由特征方程系数写出赫尔维茨行列式
  • 依次计算各阶主子式
  • 令全部主子式大于零得到稳定条件
通用考法
  • 本卷考过把赫尔维茨判据作为稳定性判定方法之一列出
  • 用赫尔维茨判据判断稳定性
  • 比较两种代数判据的适用场合
常见易错
  • 行列式构造时系数下标写错
  • 只验证到二阶主子式就下结论

4四、可控性与状态反馈稳定化#

思路
  • 辨析可控与稳定无必然联系，说明不稳定但可控的系统可用状态反馈任意配置极点
能控性与能观性 状态空间分析
本卷考法
  • 说明系统可控与稳定是两个相互独立的概念
本卷实例
  • 关键一步：举能控判别阵满秩但特征值含正实部的反例
  • 中间结果：可控性只反映能否配置极点，不代表极点已在左半平面
  • 卡点：把可控当成稳定，误以为能控就稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过说明系统可控与稳定是两个相互独立的概念
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
状态反馈与极点配置 状态空间分析
本卷考法
  • 说明不稳定系统在可控时可用状态反馈任意配置极点使其稳定
本卷实例
  • 关键一步：由可控性保证极点可任意配置，取期望左半平面极点求反馈阵
  • 中间结果：状态反馈可改变系统矩阵特征值，从而改变稳定性
  • 卡点：未验证能控性就断言能通过状态反馈稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过说明不稳定系统在可控时可用状态反馈任意配置极点使其稳定
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
公式

  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征方程求阻尼比与自然频率
本卷实例
  • 关键一步：把二阶特征方程系数与标准形式逐项对应
  • 中间结果：阻尼比由一次项系数、自然频率由常数项分别确定
  • 卡点：未把s平方项系数归一化就套标准形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征方程求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：先判稳再用终值定理或静态速度误差系数求误差
  • 中间结果：Ⅰ型系统的斜坡误差与开环增益成反比
  • 卡点：未判稳就用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
由性能指标要求反求参数 时域响应与动态性能

本卷实例

  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式

  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由指定的阻尼比与稳态误差反求系统参数

  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

6六、Nyquist判稳与纯延迟系统稳定范围#

思路
  • 画开环Nyquist曲线判稳，再对含延迟系统画Bode并求使闭环稳定的延迟上限
奈奎斯特判据 稳定性分析
本卷考法
  • 画开环Nyquist曲线并由奈氏判据判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数P，再数曲线包围负实轴段次数
  • 中间结果：与负实轴交点的坐标由令虚部为零解出
  • 卡点：未写出与坐标轴交点坐标，或P数错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过画开环Nyquist曲线并由奈氏判据判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
含纯延迟环节的系统稳定性 稳定性分析
本卷考法
  • 分析含纯延迟系统在给定延迟下的稳定性
  • 求使闭环稳定的延迟时间范围
本卷实例
  • 关键一步：延迟只改变相频、不改变幅频
  • 关键一步：令截止频率处相角大于负180度求延迟上限
  • 中间结果：稳定条件化为相角裕度对延迟的约束不等式
  • 卡点：把延迟环节当成惯性环节；角度与弧度换算出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 延迟环节 e^{-τs} 的幅值为 1、相位为 -τω，只恶化相位
  • 延迟会显著缩小稳定域，τ 越大越难稳定
  • 频域判据需用相位裕度扣除延迟引起的附加滞后
步骤
  • 写出含延迟的开环传递函数
  • 分别求幅值与相位表达式
  • 在相频特性中扣除 τω 的滞后量
  • 按稳定裕度或奈氏判据求临界 τ 或临界 K
通用考法

  • 卡点：把有限终点与渐近线方向搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过由根轨迹起点与有限终点确定开环零极点分布
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
