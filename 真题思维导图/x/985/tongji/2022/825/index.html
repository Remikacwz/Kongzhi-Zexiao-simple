1一、电路网络求传递函数10 分#

思路
  • 按复阻抗串并联关系或列KVL、KCL方程，求输出电压对输入电压的传递函数
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由无源电路网络求输出电压与输入电压的传递函数
本卷实例
  • 关键一步：把电感写成Ls、电容写成1比Cs后按复阻抗串并联化简
  • 中间结果：输出支路为电感、电容与一电阻并联后再与另一电阻分压
  • 卡点：复阻抗法把电容阻抗误写成Cs；含运放时忘用虚短虚断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由无源电路网络求输出电压与输入电压的传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

2二、机械系统的微分方程组与传递函数#

思路
  • 分别对两质量块列牛顿方程，整理成以两位移为变量的方程组，再求u到y传函
机械系统建模 建模与机电系统
本卷考法
  • 由弹簧阻尼连接的两质量块系统列运动微分方程并求传递函数
本卷实例
  • 关键一步：分别对两质量块列牛顿第二定律方程
  • 关键一步：两方程通过弹簧力与阻尼力相互耦合
  • 中间结果：相互作用力方向相反、大小相等，联立消去中间量
  • 卡点：相互作用力方向取反；漏掉某一质量块的惯性项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过由弹簧阻尼连接的两质量块系统列运动微分方程并求传递函数
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
状态空间表达式的建立 状态空间分析
本卷考法
  • 以两质量块位移为状态变量写出系统运动的微分方程组
本卷实例
  • 关键一步：选两位移作状态变量后整理成一阶微分方程组
  • 中间结果：状态维数为4，对应两个二阶方程
  • 卡点：状态变量个数与方程阶数不匹配
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过以两质量块位移为状态变量写出系统运动的微分方程组
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

3三、劳斯判据判断特征方程稳定性10 分#

思路
  • 对两个给定特征方程分别列劳斯表，判断稳定性并数右半平面根个数
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断给定特征方程的稳定性并指出右半平面根个数
本卷实例
  • 关键一步：按特征方程次数列劳斯表并数首列变号次数
  • 中间结果：首列变号次数等于右半平面特征根个数
  • 卡点：首列出现零时未用ε法或辅助方程处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断给定特征方程的稳定性并指出右半平面根个数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式

本卷考法

5五、稳态误差与动态指标联合选参15 分#

思路
  • 由斜坡误差定增益下界，再由超调量与调节时间定阻尼比与自然频率，联立选K与T
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡下的稳态误差要求反求开环增益
本卷实例
  • 关键一步：按Ⅰ型系统用速度误差系数写出斜坡误差与增益关系
  • 中间结果：斜坡误差等于1比Kv，可反解出K的取值下界
  • 卡点：未先判稳就用终值定理求误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位斜坡下的稳态误差要求反求开环增益
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与调节时间要求确定阻尼比与自然频率
本卷实例
  • 关键一步：由超调量公式反解阻尼比、由调节时间公式反解自然频率
  • 中间结果：两个指标分别给出阻尼比与自然频率的约束
  • 卡点：两种误差带的调节时间系数取混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与调节时间要求确定阻尼比与自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 联立误差与动态指标选出一组可行的增益与时间常数
本卷实例
  • 关键一步：把闭环传函化为标准二阶形式后比对系数
  • 中间结果：K与T由阻尼比和自然频率的关系式联立确定
  • 卡点：只满足单项指标就下结论，未做交叉验证
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过联立误差与动态指标选出一组可行的增益与时间常数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式

开环对数频率特性的绘制 频域分析
本卷考法
  • 概略绘制系统的对数渐近幅频特性曲线
本卷实例
  • 关键一步：把传函化为标准形式并找出各转折频率
  • 中间结果：由积分或微分环节与惯性环节叠加确定各段斜率
  • 卡点：转折频率处斜率变化量记错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过概略绘制系统的对数渐近幅频特性曲线
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
闭环频率特性与性能指标 频域分析
本卷考法
  • 判断系统是否存在谐振峰值并求谐振频率
本卷实例
  • 关键一步：由阻尼比是否小于0.707判断谐振是否存在
  • 中间结果：用谐振频率公式代入阻尼比与自然频率
  • 卡点：阻尼比大于0.707时仍套用谐振峰值公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过判断系统是否存在谐振峰值并求谐振频率
