思路

自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断稳定性由系统本身还是外部输入决定
  • 判断反馈控制是按偏差还是按输入调节
本卷实例
  • 关键一步：稳定性是系统自身固有属性
  • 中间结果：与输入输出形式无关
  • 卡点：把输入幅值变化误当成改变稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断稳定性由系统本身还是外部输入决定
  • 本卷考过判断反馈控制是按偏差还是按输入调节
  • 指出系统的被控对象、被控量与操纵量

  • 只画方框图而不指认环节，或反之，漏答一半
闭环频率特性与性能指标 频域分析
本卷考法
  • 指出 Bode 图上二阶系统误差最大值对应的频率
本卷实例
  • 关键一步：误差峰值对应闭环幅频谐振峰
  • 中间结果：峰值出现在自然频率附近
  • 卡点：把谐振峰位置误判成截止频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤

  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过指出 Bode 图上二阶系统误差最大值对应的频率
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量

常见易错

奈奎斯特判据 稳定性分析
本卷考法
  • 用开环右半平面极点数与半穿越数判断闭环稳定
本卷实例
  • 关键一步：先数开环右半平面极点数 P
  • 中间结果：按 Z 等于 P 减两倍穿越差判稳
  • 卡点：半穿越的正负方向容易判反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用开环右半平面极点数与半穿越数判断闭环稳定
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

频率特性的物理意义与求法 频域分析
本卷考法
  • 判断频域分析法主要依据稳态幅频与相频
本卷实例
  • 关键一步：频域法用正弦稳态幅值比与相位差
  • 中间结果：据此同时研究稳态与动态性能
  • 卡点：误以为频域法只反映瞬态特性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过判断频域分析法主要依据稳态幅频与相频
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
劳斯判据 稳定性分析
本卷考法
  • 判断闭环极点不含右半平面与渐近稳定、BIBO 稳定的关系
本卷实例
  • 关键一步：先检查闭环极点是否都在左半平面
  • 中间结果：极点不含右半平面时输出有界
  • 卡点：本项借位 st_01 因知识库无 BIBO 专条
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过判断闭环极点不含右半平面与渐近稳定、BIBO 稳定的关系
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

离散系统稳定性分析 离散控制系统
本卷考法

本卷实例

  • 中间结果：单调收敛还要求极点为正实数
  • 卡点：把单位圆内都当成单调收敛
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过判断 Z 域稳定且单调收敛的极点位置条件
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

离散系统的动态性能与极点分布 离散控制系统
本卷考法
  • 判断采样周期变大对离散系统稳定性的影响
本卷实例
  • 关键一步：T 增大使离散极点靠近单位圆边界
  • 中间结果：稳定裕度变小、稳定性变差
  • 卡点：本题第8小题以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点在 z 平面上的位置决定响应形式
  • 极点越靠近原点衰减越快，越靠近单位圆振荡越强
  • 极点的幅角决定振荡频率，幅值决定衰减速度
  • 采样周期增大会使动态性能变差甚至不稳定
步骤
  • 求闭环脉冲传递函数的极点
  • 按极点在单位圆内的位置判断响应形式
  • 由极点的模与幅角估算衰减与振荡频率
  • 与连续系统指标对应关系相互校验
通用考法
  • 本卷考过判断采样周期变大对离散系统稳定性的影响
  • 由闭环极点分布判断动态性能
  • 与连续域指标互相换算
  • 说明采样周期对动态性能的影响
常见易错

  • 忽略单位圆上极点对应等幅振荡

滞后校正 系统校正
本卷考法
  • 指出滞后校正利用高频幅值衰减换取稳定裕度
本卷实例
  • 关键一步：滞后网络在高频段衰减增益
  • 中间结果：低频增益不变而稳定裕度提高
  • 卡点：把滞后与超前的相角作用搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过指出滞后校正利用高频幅值衰减换取稳定裕度
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
