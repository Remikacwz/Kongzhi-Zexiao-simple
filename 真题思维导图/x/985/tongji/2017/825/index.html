1一、工业炉温控制系统分析#

思路
  • 由工业炉温控制系统示意图说明工作原理，指认被控对象、被控量与给定量并画方框图
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出系统的被控对象、被控量与给定量
本卷实例
  • 关键一步：由热电偶测炉温并与给定电压比较
  • 中间结果：按偏差经放大与执行机构调加热功率
  • 卡点：系统示意图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量

  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错

  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

  • 中间结果：逐环节说明信号传递关系

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 补偿导线把冷端从现场延长到控制室，但它不能消除冷端温度的影响

  • 查热电特性表时需要线性插值

  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过设计状态反馈增益阵配置闭环极点
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 本卷考过特征多项式比较系数时符号写反
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
