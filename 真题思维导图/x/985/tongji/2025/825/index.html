1一、生活系统的闭环控制建模#

思路
  • 把人眼识路看作闭环控制系统，指出四个环节并画方框图
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 指出系统的被控对象、检测变送、控制器与执行器
  • 画出系统的闭环控制方框图
本卷实例
  • 关键一步：按四大环节对号入座
  • 关键一步：被控量是要维持的工艺变量，这里是人走的路线或方向；给出参考的是环境中的路标
  • 关键一步：方框图按给定、比较、控制、执行、对象、反馈的顺序串起来，反馈支路从被控量回到比较点
  • 关键一步：眼睛相当于检测变送，大脑相当于控制器，肢体相当于执行器，行进方向相当于被控对象
  • 中间结果：这类题的难点不在计算，而在把生活语言的每个动作对应到工程术语，对应错一个后面全错
  • 卡点：把眼睛当成执行器或把大脑当成检测环节；或方框图漏掉反馈支路就不是闭环了
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过指出系统的被控对象、检测变送、控制器与执行器
  • 本卷考过画出系统的闭环控制方框图
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半

2二、由微分方程写可观测标准型#

思路
  • 由二阶微分方程求传函，再写成可观测标准型的状态空间表达式
由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 由微分方程或传递函数写出可观测标准型实现
本卷实例
  • 关键一步：先在零初始条件下取拉氏变换，得到分子是一次的真分式传函
  • 关键一步：分母首一化后把各次系数按升幂或降幂填入系统矩阵的相应位置，分子系数填入输入向量
  • 关键一步：可观测标准型的输出矩阵取成只取出第一个状态，本题输出矩阵第一个元素为 1、其余为零
  • 中间结果：分母是二次三项式、分子是一次多项式，系统矩阵是二阶
  • 中间结果：输入向量两维，写出后可用传函公式回算校验
  • 卡点：分子分母系数填错行；或把可观测标准型与能控标准型混淆，两者互为对偶形式，填法正好转置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法
  • 本卷考过由微分方程或传递函数写出可观测标准型实现
  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反

3三、劳斯判据定稳定域与斜坡误差#

思路
  • 由劳斯判据求稳定增益范围，再按型别求单位斜坡下的稳态误差
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据确定系统稳定时的增益取值范围
本卷实例
  • 关键一步：写出闭环特征方程，把含增益的项展开后逐项整理成系数多项式
  • 关键一步：列劳斯表时首列所有元素必须同号，逐个列出不等式
  • 关键一步：本题分子的零点进入特征方程的常数项与一次项，使不等式退化为对增益的单一符号要求
  • 中间结果：整理后可发现劳斯表首列的两个约束合并成一个，也就是只要增益为正系统就稳定
  • 卡点：只列部分首列不等式；或把开环增益与特征方程系数混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据确定系统稳定时的增益取值范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：先数积分环节个数确定型别，本题分母含一个 s，属 Ⅰ 型系统
  • 关键一步：求静态速度误差系数时要保留分子常数项，它是把型别折算后乘进来的增益
  • 关键一步：稳态误差等于斜坡幅度除以速度误差系数，本题结果是一个与增益成反比的表达式
  • 中间结果：开环分子是增益乘一个一次因式，求极限后速度误差系数等于增益乘零点常数再除以分母常数
  • 卡点：未判稳就代终值定理；或求速度误差系数时把 s 乘错位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

4四、奈奎斯特圆与闭环稳定条件#

思路
  • 证明一类特殊开环的奈奎斯特图是圆，并分 aᵢ 全正与部分为负讨论稳定条件
奈奎斯特判据 稳定性分析
本卷考法
  • 证明给定开环传递函数的奈奎斯特图是圆
  • 分情形给出闭环稳定的条件
本卷实例
  • 关键一步：把每个因式写成分子分母同为一次的形式
  • 关键一步：模为一的乘积仍是一，因此开环传函的轨迹上每一点到点的距离都等于常数，轨迹必落在圆上
  • 关键一步：圆的圆心由常数项决定、半径由增益决定，位置关系由此确定
  • 关键一步：s 取纯虚数时分子与分母的模相等，每个因式的模都是一
  • 中间结果：aᵢ 全为正时开环没有右半平面极点
  • 中间结果：aᵢ 中有负数时右半平面开环极点数等于负数的个数
  • 中间结果：闭环稳定要求临界点落在圆外，即常数加一大于增益的绝对值
  • 中间结果：临界点须落在圆内并满足对应的包围圈数要求
  • 卡点：证明圆时只算两个特殊频率点就下结论；或讨论稳定条件时忘记先数右半平面开环极点数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过证明给定开环传递函数的奈奎斯特图是圆
  • 本卷考过分情形给出闭环稳定的条件
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式

5五、由误差响应与性能指标反求参数#

思路
  • 同一被控对象，两小问分别由误差响应表达式与阶跃指标反求增益与极点参数
误差定义与误差传递函数 稳态误差
本卷考法
  • 由单位阶跃下的误差响应表达式反求系统参数
本卷实例
  • 关键一步：误差响应是误差传函乘输入的拉氏反变换，先把它拉氏变换成 s 的有理分式
  • 关键一步：再乘 s 除掉输入因子，即得误差传函的有理分式形式
  • 关键一步：把误差传函与由开环传函写出的一加开环分之一逐项比较系数，解出增益与极点参数
  • 中间结果：本题误差响应的两个指数项对应误差传函的两个实极点，系数比较后得到一组很整齐的参数
  • 卡点：忘记乘以 s 这一步，直接把误差响应当成误差传函；或把误差传函写成开环传函本身
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由单位阶跃下的误差响应表达式反求系统参数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由峰值时间与超调量反求系统参数
本卷实例
  • 关键一步：超调量只由阻尼比决定，先由超调量公式反解阻尼比
  • 关键一步：再由峰值时间公式与已求出的阻尼比解出自然频率
  • 关键一步：闭环传函的增益等于自然频率的平方，极点参数等于二倍阻尼比乘自然频率
  • 中间结果：超调量按给定倍数取指数后反解阻尼比
  • 中间结果：本题阻尼比与自然频率都是整齐的数，代回可核对峰值时间
  • 卡点：把超调量公式里的指数写反；或先解自然频率再用超调量，导致迭代
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由峰值时间与超调量反求系统参数
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

6六、频域定义与由对数幅频求裕度#

思路
  • 先默写频率特性与三个频域指标的定义，再由给定对数幅频渐近线求传函、画相频并计算裕度
频率特性的物理意义与求法 频域分析
本卷考法
  • 给出线性定常系统频域特性的定义与各频域指标的定义
本卷实例
  • 关键一步：频率特性是传递函数中把复变量替换成纯虚数后得到的复变函数，反映系统对正弦输入的稳态响应
  • 关键一步：截止频率是开环幅值等于一处对应的频率，相角裕度是该频率处相角与负一百八十度的差
  • 关键一步：幅值裕度是相位等于负一百八十度处幅值的倒数，用分贝表示时取负二十倍对数
  • 中间结果：几个定义要写成一句话，含「在什么频率处、量的是什么、与什么相减」，不含公式的口述容易丢分
  • 卡点：把截止频率与相位穿越频率用反；或幅值裕度忘记取倒数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过给出线性定常系统频域特性的定义与各频域指标的定义
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环对数幅频渐近线求传递函数并概略画相频特性
本卷实例
  • 关键一步：低频段斜率定型别、高度定增益，转折频率处的斜率变化定环节类型
  • 关键一步：最小相位系统的相频特性可由各环节相角累加得到，注意积分环节固定贡献负九十度
  • 关键一步：画相频时按转折频率分段，用每段趋近的相角值定位
  • 中间结果：题面给出的反正切数值就是为读传递函数与算裕度准备的，正好对应某个转折频率处的相角
  • 卡点：最小相位系统的相频也可由渐近线直接推，但不要忘记积分环节的相位起点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤

  • 关键一步：令特征方程中的复变量取纯虚数，把结果的实部与虚部分别置零得到两个方程
  • 关键一步：由虚部方程解出角频率，再由实部方程解出对应的增益
  • 关键一步：也可用劳斯判据令首列出现零行，两种方法互相印证
  • 中间结果：本题特征方程可整理成两个因式相乘的形式，一个因式给出负实根，另一个给出共轭纯虚根
  • 卡点：只代一个频率漏掉另一组根；或求出角频率后忘记同时给出对应的增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求位于虚轴上的特征根及对应的增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
