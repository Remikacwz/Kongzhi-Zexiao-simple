1一、机电调速系统闭环与有差性#

思路
  • 由机电调速系统示意图判反馈连线与闭环方框图，并定性判断常值输入下的稳态误差
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出系统的被控对象、被控量与反馈量
本卷实例
  • 关键一步：按给定电压与测速反馈电压比较得到偏差
  • 中间结果：偏差经放大后驱动电动机与发电机
  • 卡点：连线图与方框图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指出系统的被控对象、被控量与反馈量
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把被控量与操纵量或反馈量搞反
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
转速负反馈单闭环调速系统 电力拖动与运动控制
本卷考法
  • 判断常值输入下转速闭环是否为零稳态误差
本卷实例
  • 关键一步：常值输入下转速恒定，反馈电压与给定电压间存在偏差
  • 中间结果：放大器前端电压为非零恒定值
  • 卡点：有差结论依赖反馈通道稳态关系，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 被控量是转速，反馈量是测速发电机输出电压
  • 属于有差系统，稳态时偏差 e=U_n*−U_n 必须不为零才能维持输出
  • 闭环后稳态速降减小为开环的 1/(1+K) 倍
  • 闭环放大倍数 K 越大，静差率越小，但稳定性越差
步骤

  • 按信号流向画出给定、比较、放大、变换器、电动机、测速反馈各环节
  • 写出稳态关系式并求闭环静特性
  • 比较开环与闭环的稳态速降
通用考法
  • 本卷考过判断常值输入下转速闭环是否为零稳态误差
  • 指出系统的被控量与反馈量
  • 画出系统结构框图
  • 解释稳态时偏差不为零的原因
  • 计算闭环稳态速降并比较开环

思路

5五、奈氏图与稳定性判别#

思路
  • 画出开环奈氏图，数右半平面极点数并判断闭环稳定性，再比较不同开环形式
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环奈氏图判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数 P
  • 中间结果：再数曲线包围临界点的圈数
  • 卡点：开环含右半平面极点，P 值数错会翻转结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
