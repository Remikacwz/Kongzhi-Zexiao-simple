1一、反馈清除扰动偏差的工程实例10 分#

思路
  • 举一工程实例，指出被控对象与扰动，说明闭环如何消除扰动偏差并画方框图
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 给出一个通过闭环控制清除扰动输出偏差的实际工程实例
  • 简述其工作原理并绘出闭环控制方框图
本卷实例
  • 关键一步：选锅炉液位或炉温等含扰动的被控对象作实例
  • 关键一步：按给定、比较、调节、执行、对象、反馈串成闭环
  • 中间结果：扰动经反馈回路引回输入端与给定值比较，靠偏差驱动调节器
  • 卡点：只画方框图不指认环节，或漏画反馈支路使闭环不成立
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过给出一个通过闭环控制清除扰动输出偏差的实际工程实例
  • 本卷考过简述其工作原理并绘出闭环控制方框图
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

2二、汽车悬架系统建模与正弦稳态输出#

思路
  • 对车厢列牛顿方程求 X比R，再由频率特性求正弦激励下的稳态输出
机械系统建模 建模与机电系统
本卷考法
  • 由弹簧阻尼质量系统的受力分析求位移对路面激励的传递函数
本卷实例
  • 关键一步：以车厢为对象列质量乘加速度等于弹簧力加阻尼力
  • 关键一步：弹簧力与阻尼力都取路面与车厢的相对量
  • 中间结果：传递函数为二阶形式，分子为一次项、分母为二次多项式
  • 卡点：弹簧力与阻尼力方向取反；漏掉相对速度项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过由弹簧阻尼质量系统的受力分析求位移对路面激励的传递函数
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由传递函数求幅频与相频，再求正弦输入下的稳态输出
本卷实例
  • 关键一步：令s等于jω分别求幅频与相频
  • 关键一步：稳态输出幅值为输入幅值乘幅频、相角加相频
  • 中间结果：指定频率处先算幅值与相角，再合成稳态正弦
  • 卡点：忘记把输入幅值0.1乘进稳态输出幅值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由传递函数求幅频与相频，再求正弦输入下的稳态输出
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

3三、劳斯判据求K的稳定范围#

思路
  • 由闭环特征方程列劳斯表，令首列全正求K的稳定范围
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求使闭环系统稳定的增益K范围
本卷实例
  • 关键一步：写出D(s)等于1加G(s)后列劳斯表
  • 关键一步：由高阶多项式按次数逐行填写劳斯表
  • 中间结果：特征方程为含K的五次多项式，首列含K的一次式
  • 卡点：首列出现纯K项时别漏掉K大于零这一约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求使闭环系统稳定的增益K范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 确定稳定时增益参数K的取值上界
本卷实例
  • 关键一步：令劳斯表首列各元素都大于零，取各不等式交集
  • 中间结果：K的范围由首列两个含K的不等式共同确定
  • 卡点：只取一个不等式就下结论，漏掉另一个端点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过确定稳定时增益参数K的取值上界
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式

4四、奈氏判据判断非最小相位系统稳定性#

思路
  • 先求幅相特性，再由开环右半平面极点数P与包围圈数判断闭环稳定性
奈奎斯特判据 稳定性分析
本卷考法
  • 绘出开环幅相曲线并根据奈氏判据判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数P
  • 关键一步：再数幅相曲线对负实轴段的包围次数
  • 中间结果：开环含一个右半平面极点，故P等于1
  • 卡点：把一个右半平面极点当成稳定极点，导致P数错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过绘出开环幅相曲线并根据奈氏判据判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
频率特性的物理意义与求法 频域分析

  • 中间结果：幅相曲线起点与终点幅角随频率连续变化

  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示

5五、复合控制系统的型别与前馈参数#

思路
  • 用梅森公式求误差传函，按Ⅲ型系统令低阶误差系数为零解前馈参数，再由极点判响应
系统型别与静态误差系数 稳态误差
本卷考法
  • 按系统型别要求反求前馈补偿参数a与b
本卷实例
  • 关键一步：写出误差传函，按Ⅲ型系统要求前两阶误差系数为零
  • 中间结果：令误差传函分子s一次项与二次项为零，得两个方程
  • 卡点：系统型别看误差传函低频段s的最低次幂，别数错积分环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过按系统型别要求反求前馈补偿参数a与b
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
反馈校正与复合控制 系统校正
本卷考法
  • 分析前馈补偿对系统型别与稳态误差的作用
本卷实例
  • 关键一步：用梅森公式写出含前馈通路的闭环与误差传函
  • 中间结果：前馈通道在误差传函分子中引入s的幂次，从而提高型别
  • 卡点：求误差传函时漏掉前馈支路的贡献
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过分析前馈补偿对系统型别与稳态误差的作用
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 由三个闭环极点判断单位阶跃响应的形式
本卷实例
  • 关键一步：比较远离虚轴的实极点与一对共轭复极点的距离
  • 中间结果：共轭复极点实部小、靠近虚轴，可作主导极点
  • 卡点：不判断主导极点就直接按最高阶次下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过由三个闭环极点判断单位阶跃响应的形式
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

6六、由闭环传函反求开环并分析Bode#

思路
  • 由Φ等于G比(1加G)反解G，再画Bode图并读幅值、相角与穿越频率
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由单位负反馈的闭环传递函数反求开环传递函数
本卷实例
  • 关键一步：用G等于Φ比(1减Φ)整理，约去分子分母公因式
  • 中间结果：开环为带一个积分与两个惯性环节的形式
  • 卡点：化简约分时把零极点对消掉，导致型别判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由单位负反馈的闭环传递函数反求开环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制开环对数渐近幅频特性并读某频率处的幅值与相角
