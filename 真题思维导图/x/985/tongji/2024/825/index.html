1一、智能车闭环控制系统简答#

思路
  • 举一个智能车闭环实例，说明闭环控制原理并画出方框图
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 举智能车闭环控制实例并解释闭环控制原理
  • 指出被控对象、被控量与检测反馈元件
本卷实例
  • 关键一步：选智能车位置或转速闭环，明确给定量与反馈量
  • 中间结果：比较给定量与反馈量得偏差，经控制器驱动执行机构
  • 卡点：只画方框图不指认环节会漏分，框图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过举智能车闭环控制实例并解释闭环控制原理
  • 本卷考过指出被控对象、被控量与检测反馈元件
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

2二、运放RC网络传函与超前滞后判别#

思路
  • 列运放电路方程求传函，再由零极点位置判别超前或滞后
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由运放RC网络求输出电压对输入电压的传递函数
本卷实例
  • 关键一步：用虚短虚断列节点电流方程，整理成s的有理分式
  • 中间结果：传函分子分母均为一阶，含一个零点和一个极点
  • 卡点：电容阻抗写成Cs或漏掉反相输入的负号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由运放RC网络求输出电压对输入电压的传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
校正的基本概念与性能指标 系统校正
本卷考法
  • 由传函分子分母一次项系数判别超前或滞后
本卷实例
  • 关键一步：比较分子一次项时间常数与分母时间常数的相对大小
  • 中间结果：由一次项系数比较确定零极点相对位置后判类型
  • 卡点：超前与滞后的判据记反，或忽略网络负号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过由传函分子分母一次项系数判别超前或滞后
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求

3三、对象传函稳定性与临界振荡分析#

思路
  • 先列稳定性判据，再求闭环传函并用劳斯判据定k范围与临界频率
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由给定G(s)求单位负反馈闭环传递函数
本卷实例
  • 关键一步：按C/R等于G除以一加G代入给定G(s)整理
  • 中间结果：闭环特征式为三阶多项式，系数含待定k
  • 卡点：负反馈分母写成1减G导致符号反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由给定G(s)求单位负反馈闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求k的稳定范围
  • 由辅助方程求临界根与振荡频率
本卷实例
  • 关键一步：补齐缺项，列三阶劳斯表，令首列各项大于零
  • 中间结果：由首列不等式交集得k的稳定区间
  • 卡点：首列出现零时不用辅助方程，漏掉临界根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求k的稳定范围
  • 本卷考过由辅助方程求临界根与振荡频率
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 确定使系统稳定的参数上下界
本卷实例
  • 关键一步：把劳斯表首列每个元素都写成k的不等式
  • 中间结果：多条不等式取交集确定k范围
  • 卡点：漏掉某条不等式，把稳定域取大
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过确定使系统稳定的参数上下界
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
赫尔维茨判据 稳定性分析
本卷考法
  • 把赫尔维茨判据作为稳定性方法之一列出
本卷实例
  • 关键一步：把赫尔维茨行列式条件作为列举行之一记忆
  • 中间结果：时域代数判据与劳斯判据可互相印证
  • 卡点：只答劳斯判据而漏掉其它稳定性方法
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由特征方程系数构造赫尔维茨行列式
  • 各阶主子式全部大于零 ⇔ 系统稳定
  • 与劳斯判据等价，适合阶数较低时使用
步骤
  • 由特征方程系数写出赫尔维茨行列式
  • 依次计算各阶主子式
  • 令全部主子式大于零得到稳定条件
通用考法
  • 本卷考过把赫尔维茨判据作为稳定性方法之一列出
  • 用赫尔维茨判据判断稳定性
  • 比较两种代数判据的适用场合
常见易错
  • 行列式构造时系数下标写错
  • 只验证到二阶主子式就下结论

4四、奈奎斯特图与稳定k范围#

思路
  • 画开环幅相曲线，由起终点与负实轴交点配合奈氏判据定k范围
频率特性的物理意义与求法 频域分析
本卷考法
  • 求开环传函的幅频相频表达式及起终点
本卷实例
  • 关键一步：令s等于jω，分别求幅值与相角随ω的变化
  • 中间结果：由分子分母阶次差确定无穷远幅值与相角
  • 卡点：相角累加时漏掉重根的180度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求开环传函的幅频相频表达式及起终点
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
本卷实例
  • 关键一步：先数开环右半平面极点数P，再看曲线包围负一点的圈数
  • 中间结果：曲线与负实轴交点决定临界增益
  • 卡点：积分环节未补画无穷大圆弧，或包围圈数正负记反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环幅相曲线判断闭环稳定性
  • 本卷考过求使闭环稳定的开环增益范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

5五、稳态误差与正弦稳态响应#

思路
  • 先判稳，再用静态误差系数求组合输入误差，最后用频率特性求正弦稳态误差
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求r(t)=1+t下系统的稳态误差
  • 比较不同k值时系统的稳定性与误差
本卷实例
  • 关键一步：先由劳斯判据判稳，再按系统型别分别求阶跃与斜坡误差
  • 中间结果：组合输入的稳态误差为各分量误差之和
  • 卡点：k较小时系统可能不稳定，不能直接套终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求r(t)=1+t下系统的稳态误差
  • 本卷考过比较不同k值时系统的稳定性与误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
