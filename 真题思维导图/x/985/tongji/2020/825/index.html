思路

自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断控制系统与多变量控制系统的基本概念
本卷实例
  • 关键一步：控制系统是被控对象与控制器的整体
  • 中间结果：多变量指多输入或多输出
  • 卡点：把多回路与多变量混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断控制系统与多变量控制系统的基本概念
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由开环传函写单位负反馈闭环特征方程
本卷实例
  • 关键一步：按一加开环作分母求闭环
  • 中间结果：令闭环分母为零得特征方程
  • 卡点：把负反馈分母写成一减开环
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由开环传函写单位负反馈闭环特征方程
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 判断一阶系统极点位置与响应速度的关系
本卷实例
  • 关键一步：极点越靠近虚轴响应越慢
  • 中间结果：越靠近原点则响应速度越慢
  • 卡点：把极点靠近原点误判为精度更高
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过判断一阶系统极点位置与响应速度的关系
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 判断根轨迹起止、分支数与实轴段等基本说法
本卷实例
  • 关键一步：根轨迹起于开环极点止于开环零点
  • 中间结果：实轴段在奇数个开环零极点左侧
  • 卡点：把根轨迹条数等同于开环极点数
  • 卡点：本题第5小题选项以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过判断根轨迹起止、分支数与实轴段等基本说法
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环传函化为尾一标准型求开环增益
本卷实例
  • 关键一步：先把各环节化为尾一标准形式
  • 中间结果：常系数乘积即开环增益
  • 卡点：把时间常数倒数当成增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由开环传函化为尾一标准型求开环增益
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求组合输入下的稳态误差
本卷实例
  • 关键一步：按型别分别算阶跃、斜坡与加速度分量
  • 中间结果：各分量叠加得总稳态误差
  • 卡点：输入含加速度项时漏掉分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求组合输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 分析增益变化对自然频率与阻尼比的影响
本卷实例
  • 关键一步：把传函化为二阶标准形式
  • 中间结果：由系数关系得两参数随增益变化的趋势
  • 卡点：标准形式归一化时漏除二次项系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过分析增益变化对自然频率与阻尼比的影响
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

非线性系统的特点 非线性系统
本卷考法
  • 判断线性定常系统平衡点的个数
本卷实例
  • 关键一步：线性定常系统平衡点由方程定出
  • 中间结果：若状态矩阵非奇异则平衡点唯一
  • 卡点：把非线性系统多平衡点的结论搬过来
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过判断线性定常系统平衡点的个数
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
稳定裕度 频域分析
本卷考法
  • 指出相角裕度对应的时域性能指标
本卷实例
  • 关键一步：相角裕度与阻尼比正相关
  • 中间结果：阻尼比决定超调量
  • 卡点：把相角裕度与调节时间直接对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过指出相角裕度对应的时域性能指标
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

本卷考法

本卷实例

  • 中间结果：比较哪个在给定频率处超前最大
  • 卡点：把最大超前角频率公式记错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤

  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过由超前角要求判断最大相位超前对应的校正装置
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

能控性与能观性 状态空间分析
本卷考法
  • 判断状态反馈与输出反馈对能控性能观性的影响
本卷实例
  • 关键一步：状态反馈不改变能控性
  • 中间结果：输出反馈保持能控性与能观性
  • 卡点：误以为状态反馈改变能控性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤

  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断状态反馈与输出反馈对能控性能观性的影响

  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解

  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

用描述函数法分析自振 非线性系统
本卷考法
  • 判断线性系统能否产生自激振荡及极限环与稳定的关系
本卷实例
  • 关键一步：自激振荡是非线性系统特有现象
  • 中间结果：极限环包围平衡点时该平衡点不稳定
  • 卡点：把极限环与李雅普诺夫稳定混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
