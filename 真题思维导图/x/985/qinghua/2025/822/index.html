1一、机电耦合系统的传递函数#

思路
  • 电磁场中的滑杆受电磁力驱动、又受弹簧与阻尼约束，求输入电压到位置输出的传递函数
直流电机等机电系统 建模与机电系统
本卷考法
  • 由机电耦合系统列写运动方程求传递函数
本卷实例
  • 关键一步：电学方程与力学方程要分别列：电学是电压平衡，力学是牛顿第二定律
  • 关键一步：电路中同时存在运动产生的反电动势，它正比于速度；
  • 关键一步：把电流用电学方程表示后代入力学方程，得到只含位置与电压的二阶微分方程
  • 关键一步：力学中同时存在电流产生的电磁力，它正比于电流
  • 中间结果：反电动势与电磁力互为共轭，这一对耦合项正是机电系统建模的关键
  • 中间结果：消去电流后，阻尼系数上会多出一项由电磁力引起的等效阻尼，
  • 中间结果：它正比于磁感应强度与导轨间距的平方再除以电阻
  • 卡点：忘记反电动势或电磁力其中一项；或把电磁力写成与速度成正比，实际上它正比于电流
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由电枢回路电压方程与转矩平衡方程联立
  • 反电动势与转速成正比，电磁转矩与电枢电流成正比
  • 机电时间常数由电气与机械两方面参数共同决定
步骤
  • 写出电枢回路电压平衡方程
  • 写出转矩平衡方程（含负载与粘性摩擦）
  • 消去电枢电流，得到转速或转角对电压的传递函数
通用考法
  • 本卷考过由机电耦合系统列写运动方程求传递函数
  • 求直流电机转速或位置对电枢电压的传递函数
  • 分析机电时间常数与电气时间常数的数量级关系
常见易错
  • 漏掉反电动势与电磁转矩的耦合项
  • 把电气时间常数与机电时间常数混淆
公式
机械系统建模 建模与机电系统
本卷考法
  • 由机械系统的受力分析写出运动方程
本卷实例
  • 关键一步：滑杆受到的外力有电磁力、弹簧恢复力和阻尼力三个，把所有力按方向写进牛顿第二定律
  • 关键一步：弹簧力与位移成正比、阻尼力与速度成正比，符号都与运动方向相反
  • 关键一步：整理成含质量、阻尼、刚度三个系数的二阶微分方程后取零初始条件的拉氏变换
  • 中间结果：传递函数的分母是二阶特征多项式，分子是常数，
  • 中间结果：系统属于无零点的二阶过阻尼或欠阻尼环节，取决于参数取值
  • 卡点：力的正负号写错；或漏掉弹簧或阻尼器中的一项，导致分辨率与固有频率都算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过由机械系统的受力分析写出运动方程
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项

2二、无反馈与有反馈系统的稳态与过渡过程#

思路
  • 由系统结构分别求无反馈与有反馈情形下的稳态输出，以及无反馈时达到稳态值百分之九十五所需的时间
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 求一阶或二阶系统无反馈时的稳态输出与达到指定百分比的时间
本卷实例
  • 关键一步：稳态值由传递函数的直流增益乘输入幅值给出，先看系统是否稳定再谈稳态
  • 关键一步：一阶系统达到百分之九十五稳态值的时间等于三倍时间常数，这一条要记住
  • 关键一步：无反馈时前向通路的增益就是系统的直流增益，有反馈后要按闭环传函重新算直流增益
  • 中间结果：加入反馈后闭环直流增益等于开环增益除以一加开环增益，稳态值会明显下降但精度与抗扰能力提高
  • 卡点：把无反馈时的稳态值当成开环增益；或把百分之九十五对应的时间常数倍数记成二倍或四倍
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过求一阶或二阶系统无反馈时的稳态输出与达到指定百分比的时间
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
零极点分布与响应模态 传递函数
本卷考法
  • 由传递函数的极点分布写出响应的模态并求过渡过程时间
本卷实例
  • 关键一步：过渡过程的快慢由最靠近虚轴的极点决定，时间常数的倒数就是该极点的实部绝对值
  • 关键一步：若系统含有多个极点，要按主导极点估算，其余快速衰减的分量可以先忽略
  • 关键一步：无反馈时极点位置由对象本身决定，加反馈后极点位置会移动，过渡过程时间也随之改变
  • 中间结果：反馈通常使闭环极点左移，响应加快；
  • 中间结果：但增益过大时会进入振荡甚至失稳，这一点要与稳态值的改善一起权衡
  • 卡点：只看稳态值不看过渡过程；或忽略主导极点的判断，用最远极点算时间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由传递函数的极点分布写出响应的模态并求过渡过程时间
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零
公式

3三、奈奎斯特判据与增益裕量#

思路
  • 开环含一个积分环节与一个二重极点，用奈氏判据判稳并求增益裕量
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据判断含积分环节系统闭环的稳定性
本卷实例
  • 关键一步：先数右半平面开环极点：本题没有，所以判据简化为曲线是否包围临界点
  • 关键一步：含积分环节时曲线在低频段幅值趋于无穷，必须补画无穷大半径圆弧后才能数包围圈数
  • 关键一步：把曲线与负实轴的交点位置与临界点比较，交点落在临界点右侧就说明不包围，闭环稳定
  • 中间结果：本题曲线穿越负实轴的幅值小于一，因此曲线不包围临界点，闭环稳定
  • 卡点：忘记补画无穷大圆弧；或把穿越点的幅值算错导致稳定性结论反了
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据判断含积分环节系统闭环的稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
稳定裕度 频域分析
本卷考法
  • 求相位穿越频率处的增益裕量
本卷实例
  • 关键一步：令相频等于负一百八十度解出相位穿越频率，本题二重极点贡献两倍的反切角，正好凑成九十度
  • 关键一步：把该频率代进幅频表达式得到穿越点的幅值
  • 关键一步：增益裕量是穿越点幅值的倒数，换算成分贝要取二十倍常用对数
  • 中间结果：本题穿越频率为二弧度每秒，该处幅值为零点六二五，增益裕量为一点六，约合四分贝
  • 卡点：增益裕量忘记取倒数；或把穿越频率与幅值穿越频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求相位穿越频率处的增益裕量
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式

4四、复合输入下的稳态误差#

思路
  • 参考输入是斜坡、扰动是负的阶跃，求两者共同作用下的稳态误差
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求参考输入引起的稳态误差
本卷实例
  • 关键一步：先判断系统型别：开环积分环节的个数决定能无差跟踪哪种输入
  • 关键一步：斜坡输入下的误差等于斜率除以速度误差系数，速度误差系数由开环传函去掉一个 s 后取低频极限
  • 关键一步：误差定义要先确认取在输入端还是反馈端
  • 中间结果：本题参考通道的稳态误差是一个与开环增益成反比的常数
  • 卡点：未判稳就代终值定理；或把速度误差系数与开环增益混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求参考输入引起的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动引起的稳态误差并与参考输入的误差叠加
本卷实例
  • 关键一步：令参考输入为零，从扰动作用点写到误差点的传递函数再乘扰动信号取终值
  • 关键一步：扰动为负的阶跃，符号要在结果里体现出来
  • 中间结果：扰动误差与参考误差的符号往往相反，
  • 中间结果：两者叠加后总误差可能比单看某一项小很多，必须分别算完再相加
  • 卡点：把扰动误差和参考误差混在一起算；或漏掉扰动前面的负号导致相加方向错误
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求扰动引起的稳态误差并与参考输入的误差叠加
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式

5五、开环幅频相频特性与剪切频率#

思路
  • 开环为增益乘一个一阶微分、一个积分、一个二阶振荡环节与一个惯性环节，画特性曲线并求剪切频率
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制开环系统的幅频与相频特性曲线
本卷实例
  • 关键一步：先把二阶因子因式分解成两个一次因式，本题两个转折频率都是整数，画图会方便很多
  • 关键一步：低频段斜率由积分环节决定，高度由开环增益决定，再按转折频率从小到大逐段改斜率
  • 关键一步：相频曲线按各环节相角累加，注意一阶微分贡献正相角、二阶因子贡献两倍的负相角
  • 中间结果：本题转折频率分布较散，幅频曲线会出现多段折线，画完要数清每一段斜率变化量与环节的对应关系
  • 卡点：二阶因子没有分解就按一个转折频率画；或高频段斜率算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过绘制开环系统的幅频与相频特性曲线
  • 绘制开环对数渐近幅频特性
