1、2、3、4、5一、简答：最小实现、状态转移与对偶#

思路
  • 五个独立小问：最小实现的条件；矩阵指数乘积 e^At·e^Bt 与 e^(A+B)t 是否恒等；二阶欠阻尼系统调节时间定义及阻尼比与超调量关系（源文注同2020年一(1)）；180°与0°根轨迹实轴段判据；对偶原理及其与原系统能控能观性的关系。
由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 说明最小实现的定义与条件
本卷实例
  • 关键一步：先要求实现能控且能观，再在同类实现中取维数最低者
  • 中间结果：最小实现是传函矩阵维数最低的能控且能观实现
  • 卡点：把能控能观与最小实现混为一谈，缺任一性都不合格
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法
  • 本卷考过说明最小实现的定义与条件
  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反

状态转移矩阵 状态空间分析
本卷考法
  • 判断矩阵指数乘积与和矩阵指数是否恒等
本卷实例
  • 关键一步：把两矩阵指数乘积的恒等条件归结为 A 与 B 是否可交换
  • 中间结果：仅当 AB 等于 BA 时恒等成立，否则一般不成立
  • 卡点：误用标量指数律；矩阵乘法次序不可交换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过判断矩阵指数乘积与和矩阵指数是否恒等
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 叙述调节时间定义并写阻尼比与超调量关系
本卷实例
  • 关键一步：以响应进入并保持在终值误差带内的最短时间定义调节时间
  • 中间结果：超调量随阻尼比增大而减小，由指数式决定
  • 卡点：误差带取 2% 还是 5% 要按题意；超调量公式漏乘 100%
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过叙述调节时间定义并写阻尼比与超调量关系
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

根轨迹的绘制法则 根轨迹法
本卷考法
  • 叙述 180°与 0°根轨迹实轴段判据
本卷实例
  • 关键一步：数某点右侧开环实数零极点个数之和，按奇偶判断实轴段
  • 中间结果：180°根轨迹取奇数，0°根轨迹取偶数
  • 卡点：两种判据的奇偶条件写反；零极点计数漏数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过叙述 180°与 0°根轨迹实轴段判据
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

本卷实例

  • 中间结果：零度根轨迹与 180°根轨迹的实轴判据奇偶恰好相反
  • 卡点：零度根轨迹仍沿用 180°相角条件；起点终点判断出错

能控性与能观性 状态空间分析
本卷考法
  • 叙述对偶原理并说明能控能观的对应关系
本卷实例
  • 关键一步：把原系统 A 转置、B 与 C 互换且转置得到对偶系统
  • 中间结果：对偶系统的能控性对应原系统能观性，反之亦然
  • 卡点：只转置矩阵而不交换 B、C；对应关系写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过叙述对偶原理并说明能控能观的对应关系
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

二二、信号流图与梅森公式#

思路
  • 由两个受控方程写出各支路传递关系，画出信号流图，再用梅森增益公式分别求 C/R 与 F/R；含两条前向通道与一条反馈回路，注意不接触回路的余子式。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由受控方程组画信号流图并用梅森公式求传函
本卷实例
  • 关键一步：先由方程写出 F/E 与 B/C 两条支路传函，再据流图列前向通道与回路
  • 中间结果：两条前向通道各有一条余子式，回路增益为负的乘积
  • 卡点：余子式要剔除与通路接触的回路；OCR 变量写串需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由受控方程组画信号流图并用梅森公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

三三、RLC 网络与参数根轨迹#

思路
  • 由图写出 RLC 电路输出电压对输入的传函，代入 LC=1、RC=K 得含参数 K 的二阶系统；再画参数根轨迹，由分离点与临界参数判断单位阶跃响应振荡的收敛性。题面含图未读图。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由 RLC 电路网络求输出电压对输入的传函
本卷实例
  • 关键一步：用复阻抗列出分压关系并化简为 s 的有理分式
  • 中间结果：分母为二阶特征多项式，系数由 L、C、R 组成
  • 卡点：电容阻抗误写成 Cs；电路连接方式需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由 RLC 电路网络求输出电压对输入的传函
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

分离点与会合点 根轨迹法
本卷考法
  • 求实轴上的分离点及该点对应的临界参数
本卷实例
  • 关键一步：由各开环极点向分离点的幅角之和等于奇数倍 180°列方程
  • 中间结果：所求两根中只有一个落在实轴根轨迹段上
  • 卡点：保留不在根轨迹上的根；分离点参数要用幅值条件另算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求实轴上的分离点及该点对应的临界参数
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹判断单位阶跃响应振荡是否收敛
本卷实例
  • 关键一步：看闭环极点随 K 增大在复平面上的走向，判断是否进入左半平面
  • 中间结果：K 小于分离点对应值时为一对共轭复根，振荡收敛
  • 卡点：只凭图形判断不代临界参数；振荡与单调的分界在分离点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标

  • 增益增大一般使系统响应加快但振荡加剧
步骤

  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法

  • 分析提高增益对性能的影响
常见易错

  • 由极点位置估指标时忽略零点的作用

四四、串联校正（源文标注不全）#

思路
  • 先按给定指标验算未校正二阶系统的阻尼比、超调量与调节时间，再判断组合输入下稳态误差能否达到要求；随后设计串联超前或滞后校正并画 Bode 图说明改善效果。源文标注本题不全。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由开环传函化为二阶标准形式求阻尼比与自然频率
本卷实例

状态反馈解耦 状态空间分析
本卷考法
  • 设计积分解耦，求反馈增益阵并写解耦后方程
本卷实例
  • 关键一步：按 c 乘 A 的 l 次方乘 B 首次非零的最小 l 定相对阶，再构造解耦矩阵
  • 中间结果：解耦矩阵非奇异时可取反馈阵为负的逆乘 L，输入变换阵取逆，解耦后传函阵为对角阵

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 解耦的目标是让每个输出只被对应的一个输入控制，闭环传递函数矩阵成为对角阵
  • 用输入变换加状态反馈控制律 u 等于负 Kx 加 Fv 实现解耦
  • 解耦矩阵由各通道输出的相对阶与输入矩阵组成，非奇异时才能解耦
  • 解耦后闭环传函矩阵的对角元由配置的极点决定，非对角元为零

  • 逐个求各输出的相对阶，即输出导数中首次出现输入的阶数减一
  • 用各通道的相对阶对应的行组成解耦矩阵，并检查其是否非奇异
  • 由解耦矩阵的逆求出输入变换矩阵，再由各通道系数求出状态反馈矩阵
  • 写出闭环传递函数矩阵，校验是否已对角化并满足期望极点

八八、饱和非线性相平面与稳态误差#

思路
  • 由结构图写出饱和非线性的分段特性与误差方程，在相平面上分三段画相轨迹并判断奇点性质，判断稳定性并求稳态误差。题面含图未读图。
典型非线性特性及其影响 非线性系统
本卷考法
  • 由结构图写出饱和非线性的分段输入输出关系
本卷实例
  • 关键一步：按误差绝对值是否超过线性区边界把特性分成三段
  • 中间结果：线性区输出等于误差本身，两侧区输出为常值
  • 卡点：饱和分界与限幅值需回原卷核对图；不要与死区混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 饱和特性降低等效增益，可能引起系统不稳定或自振
  • 死区特性使小信号时增益为零，产生稳态误差
  • 间隙特性引起相位滞后，导致波形畸变与自振
  • 继电特性使系统出现持续振荡并可能产生颤振
步骤
  • 识别非线性环节类型
  • 写出其描述函数或分段数学表达式
  • 分析其对等效增益与稳定性的影响
通用考法
  • 本卷考过由结构图写出饱和非线性的分段输入输出关系
  • 分析饱和或死区对系统性能的影响
  • 求典型非线性的描述函数表达式
  • 说明间隙为何容易引起自振
常见易错
  • 认为饱和总是使系统更稳定
  • 忽略死区在原点附近造成的小信号失效

相平面法 非线性系统
本卷考法
  • 按误差区间画相轨迹并判断奇点与稳态误差
本卷实例
  • 关键一步：把误差二阶微分方程写成一阶相轨迹斜率方程，分区求奇点
  • 中间结果：线性区奇点为稳定焦点，两侧区无奇点但有渐近线
  • 卡点：相轨迹斜率分子分母易写反；初始误差与初速需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过按误差区间画相轨迹并判断奇点与稳态误差
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆
