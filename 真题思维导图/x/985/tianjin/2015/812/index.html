天津大学 812 自动控制理论（含现控） 2015 年真题思维导图

985 院校共 7 题

难度：中等偏上　共7个大题：一为质量块-阻尼器建模与位移反馈设计；二为参数根轨迹选择与主导极点；三为单位加速度输入下的超前校正；四为限幅非线性相平面与最大阶跃幅值；五为能控标准型与不可观实现；六为能控能观判别与积分型解耦；七为李雅普诺夫第二法判定原点稳定性。经典与现代控制并重，第一、四题含图，源文未印分值。

一一、质量块-阻尼器建模与位移反馈设计#

思路
  • 先按牛顿第二定律列质量块-阻尼器运动微分方程，再写位移对推力的传递函数与方框图；进一步用前馈加反馈校正使重力扰动下无静差，并给出调节器参数稳定范围
机械系统建模 建模与机电系统
本卷考法
  • 由质量块-阻尼器受力分析列写运动微分方程
本卷实例
  • 关键一步：对质量块取隔离体，按牛顿第二定律列方程
  • 中间结果：得含惯性、阻尼与重力的二阶微分方程
  • 卡点：阻尼力方向与位移导数符号写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过由质量块-阻尼器受力分析列写运动微分方程
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 本卷考过把重力扰动项漏掉或与推力合并
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由机械系统微分方程求位移对推力的传递函数
本卷实例
  • 关键一步：对微分方程在零初始条件下作拉氏变换
  • 中间结果：得位移对控制推力的传递函数与方框图
  • 卡点：未分离重力扰动通道，两路传函混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由机械系统微分方程求位移对推力的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过零初始条件不成立就直接作拉氏变换
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 分析重力扰动下不产生稳态位移误差的条件
本卷实例
  • 关键一步：写扰动到位移的传函，令其直流增益为零
  • 中间结果：扰动误差系数为零时扰动不产生静差
  • 卡点：用终值定理前未先判系统稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过分析重力扰动下不产生稳态位移误差的条件
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 本卷考过只按参考输入算稳态误差，漏掉扰动通道
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
反馈校正与复合控制 系统校正
本卷考法
  • 用前馈校正构成复合控制以抵消重力扰动
本卷实例
  • 关键一步：在扰动点引入前馈通道使扰动被直接补偿
  • 中间结果：前馈加反馈的复合控制兼顾跟踪与抗扰
  • 卡点：前馈通道传函与扰动通道量纲不匹配
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过用前馈校正构成复合控制以抵消重力扰动
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 本卷考过试图仅用偏差反馈完全消除扰动静差
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求调节器参数使闭环系统稳定的取值范围
本卷实例
  • 关键一步：由闭环特征方程系数列稳定条件不等式
  • 中间结果：解不等式组得调节器增益的稳定区间
  • 卡点：区间端点是否可取判断错误
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求调节器参数使闭环系统稳定的取值范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 本卷考过只列特征方程不判首列元素符号
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

二二、参数根轨迹选择与主导极点判别#

思路
  • 在两组参数中选使闭环共轭极点实部等于给定值者，画根轨迹并用幅值条件反求增益；再判断该对共轭极点能否成为主导极点
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画出含可变参数的系统根轨迹
本卷实例
  • 关键一步：标出开环极点与含参数的开环零点
  • 中间结果：比较两组参数下的实轴段与渐近线交点
  • 卡点：渐近线交点计算时符号取错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画出含可变参数的系统根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过根轨迹条数未按开环极点数与零点数之差确定
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 由分离点方程求根轨迹在实轴上的分离点
本卷实例
  • 关键一步：令增益对位移的导数为零解分离点方程
  • 中间结果：实轴根轨迹段内的分离点才有效
  • 卡点：把不在根轨迹上的解也保留
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由分离点方程求根轨迹在实轴上的分离点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 本卷考过分离点是否落在根轨迹实轴段上判错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由希望闭环极点实部反求增益的取值
本卷实例
  • 关键一步：由根之和关系先求第三个闭环极点
  • 中间结果：再用幅值条件反求增益取值
  • 卡点：根之和关系符号用错导致第三个根错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由希望闭环极点实部反求增益的取值
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 本卷考过只用共轭极点求增益，漏掉第三个闭环根
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 判断该对共轭闭环极点能否成为主导极点
本卷实例
  • 关键一步：检查其余闭环极点与闭环零点是否构成偶极子
  • 中间结果：存在偶极子对消时该对极点可主导响应
  • 卡点：把远离虚轴的极点误当成主导极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过判断该对共轭闭环极点能否成为主导极点
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 本卷考过只比实部大小，不查零点与极点对消
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

三三、单位加速度输入下的超前校正#

思路
  • 设计超前校正装置的参数，使单位加速度输入的稳态误差、零分贝穿越斜率和幅值穿越频率及相角裕度满足要求；再画校正后对数幅频特性并据中频段估算调节时间
超前校正 系统校正
本卷考法
  • 按稳态误差与相角裕度要求设计超前校正装置
本卷实例
  • 关键一步：由稳态误差定增益，按相角裕度定最大超前角
  • 中间结果：由最大超前角反解校正装置的参数取值
  • 卡点：校正后截止频率改变，未迭代校验
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过按稳态误差与相角裕度要求设计超前校正装置
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 本卷考过最大超前角按所需裕度直接取，未留余量
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位加速度输入稳态误差要求确定开环增益
本卷实例
  • 关键一步：按系统型别写出稳态误差与开环增益关系式
  • 中间结果：由误差指标反求满足要求的开环增益
  • 卡点：系统型别判断错误导致误差公式选错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位加速度输入稳态误差要求确定开环增益
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过把加速度输入按速度误差系数计算
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制校正后系统的对数幅频渐近特性
本卷实例
  • 关键一步：按开环极零点定转折频率并分段画渐近线
  • 中间结果：中频段以指定斜率穿越零分贝线
  • 卡点：校正装置与固有部分的斜率叠加算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤

本卷考法
  • 用积分型解耦条件求反馈阵与前馈阵
本卷实例
  • 关键一步：求各输出的解耦指数并组解耦矩阵

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
