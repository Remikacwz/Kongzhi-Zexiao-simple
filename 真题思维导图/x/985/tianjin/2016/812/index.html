天津大学 812 自动控制理论（含现控） 2016 年真题思维导图

985 院校共 7 题

难度：中等偏上　共7个大题：一为方框图建模、传函与稳定性；二为能控能观判别与全维状态观测器；三为含参数系统的根轨迹与降阶估算；四为由幅相特性反求传函并用奈奎斯特判据判稳；五为继电非线性系统的描述函数分析；六为由对数幅频特性求传函并设计串联校正；七为状态空间传函、对偶、对角化与输出反馈镇定。经典、现代与非线性并重，含图题多，源文未印分值。

一一、方框图状态空间、传函与稳定性#

思路
  • 由系统方框图列写状态空间表达式，再用梅森增益公式求闭环传递函数，最后由特征方程判断系统稳定性
状态空间表达式的建立 状态空间分析
本卷考法
  • 由系统方框图列写状态空间表达式
本卷实例
  • 关键一步：按每个积分器的输出取一个状态变量
  • 中间结果：由方框图列写一阶微分方程组再写矩阵形式
  • 卡点：反馈支路符号与状态变量对应写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由系统方框图列写状态空间表达式
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 本卷考过状态变量选取不当导致方程不自洽
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求系统的闭环传递函数
本卷实例
  • 关键一步：画信号流图并标出前向通路与独立回路
  • 中间结果：算特征式与前向通路余子式后求和
  • 卡点：两两不接触回路的组合项漏乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求系统的闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过回路增益与前向通路增益符号取错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
劳斯判据 稳定性分析
本卷考法
  • 列劳斯表判断闭环系统是否稳定
本卷实例
  • 关键一步：由闭环特征方程系数列劳斯表
  • 中间结果：观察首列元素符号判断右半平面根个数
  • 卡点：只算第一列不查是否出现零元素
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过列劳斯表判断闭环系统是否稳定
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过劳斯表某行首列出现零元素时未处理
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

二二、能控能观判别与全维状态观测器#

思路
  • 给定二阶状态空间描述，判断能控性与能观性；再按期望极点设计全维状态观测器并写出观测器方程
能控性与能观性 状态空间分析
本卷考法
  • 构造能控性与能观性矩阵判断系统秩
本卷实例
  • 关键一步：分别写出能控阵与能观阵并求秩
  • 中间结果：两阵均满秩时系统既可控又可观
  • 卡点：把能控与能观条件互换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过构造能控性与能观性矩阵判断系统秩
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 本卷考过二阶系统判别阵的行列式算错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
状态观测器设计 状态空间分析
本卷考法
  • 按期望极点设计全维状态观测器
本卷实例
  • 关键一步：引入观测器增益阵后写观测器特征方程
  • 中间结果：令其与期望多项式系数相等解增益阵
  • 卡点：观测器方程中输出误差项符号写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态观测器用输出与输入重构状态，前提是系统能观
  • 极点配置法与龙伯格观测器是两种常用形式
  • 观测器误差动态由 A-LC 的特征值决定
  • 观测器极点通常取得比系统极点快若干倍
步骤
  • 验证系统能观性
  • 写出观测器方程并求误差动态矩阵
  • 按期望特征多项式比较系数求出 L
  • 校验观测器收敛速度是否合适
通用考法
  • 本卷考过按期望极点设计全维状态观测器
  • 设计全维状态观测器
  • 由期望观测器极点求反馈增益阵 L
  • 分析观测器与状态反馈组合后的系统极点
常见易错
  • 本卷考过观测器特征多项式与期望式比较时符号错
  • 把观测器增益阵写成了状态反馈增益阵的形式
  • 忽略观测器极点过快会放大噪声

三三、含参数系统的根轨迹与降阶估算#

思路
  • 画含参数系统的根轨迹并求稳定参数范围；由给定闭环极点反求参数与其余极点；再用主导极点降阶估算超调量与调节时间
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画出含参数系统的根轨迹
本卷实例
  • 关键一步：标出开环极点并算实轴段与渐近线
  • 中间结果：按参数由零到无穷画出根轨迹
  • 卡点：分离点与渐近线交点混为一处
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画出含参数系统的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过渐近线条数与夹角公式用错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界参数
本卷实例
  • 关键一步：令特征方程中实部与虚部分别为零
  • 中间结果：解出交点频率与对应的临界参数值
  • 卡点：只解出频率未解对应参数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界参数
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 本卷考过代入虚轴后实部虚部方程联立解错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由给定闭环极点反求参数与其余极点
本卷实例
  • 关键一步：把已知闭环极点代入特征方程求参数
  • 中间结果：再对特征多项式降阶求另外两个根
  • 卡点：求出的根未与已知根核对根之和
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由给定闭环极点反求参数与其余极点
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 本卷考过长除法分解特征多项式时系数算错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 用闭环主导极点把系统降为二阶模型
本卷实例
  • 关键一步：比较各闭环极点实部并取最靠近虚轴者
  • 中间结果：保留主导极点对写二阶标准形式
  • 卡点：降阶时漏掉闭环零点对响应的影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过用闭环主导极点把系统降为二阶模型
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 本卷考过把非主导极点误当作主导极点
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由降阶二阶模型估算超调量与调节时间
本卷实例
  • 关键一步：由二阶标准形式读出阻尼比与自然频率
  • 中间结果：代入超调量与调节时间公式估算
  • 卡点：忽略降阶近似的适用条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由降阶二阶模型估算超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过误差带系数与阻尼比自然频率对应错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

四四、由幅相特性求传函与奈氏判据#

思路
  • 由给定幅相特性曲线反求开环传递函数，求系统的幅值裕度，并用奈奎斯特判据判断闭环稳定性
频率特性的物理意义与求法 频域分析
本卷考法
  • 由幅相特性曲线反求开环传递函数
本卷实例
  • 关键一步：由低频相位与转折判断系统型别与极点形式
  • 中间结果：用给定频率点的幅值相位条件定各参数
  • 卡点：把幅相曲线的幅值与相角对应点取错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由幅相特性曲线反求开环传递函数
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过低频相位未用来判断积分环节个数
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
稳定裕度 频域分析
本卷考法
  • 由幅相曲线与负实轴交点求幅值裕度
本卷实例
  • 关键一步：求曲线与负实轴交点对应的幅值
  • 中间结果：用幅值裕度定义取该幅值的倒数
  • 卡点：把幅值裕度与相位裕度定义混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
