1、2、3、4一、简答：基本要求、带宽、输出反馈与凯莱-哈密顿#

思路
  • 四个独立简答小问：自动控制系统的基本要求与考察指标；带宽频率的定义及其对性能的影响；静态输出反馈为何不能任意配置极点；用凯莱-哈密顿定理求状态转移矩阵的步骤。
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 叙述自动控制系统的基本要求及通常考察的动稳态性能指标
本卷实例
  • 关键一步：按稳、准、快三个方面概括基本要求
  • 中间结果：列出超调量、调节时间与稳态误差等指标
  • 卡点：把稳定性要求排除在基本要求之外
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过叙述自动控制系统的基本要求及通常考察的动稳态性能指标
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过只答动态指标漏答稳态精度指标
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

闭环频率特性与性能指标 频域分析
本卷考法
  • 叙述带宽频率的定义及带宽大小对系统性能的影响
本卷实例

  • 中间结果：带宽大则响应快但易引入高频噪声
  • 卡点：把开环谐振与闭环带宽混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过叙述带宽频率的定义及带宽大小对系统性能的影响
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错

  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

二二、根轨迹、稳定范围与降阶估算#

思路
  • 对 G=K/[s(s+2)(s+5)] 画根轨迹并求分离点、渐近线与虚轴交点，定稳定K范围与振荡收敛范围；再由 s=-6 为闭环极点反求增益与其余极点，用主导极点降阶估算调节时间与超调。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画出系统根轨迹并求渐近线与实轴段
本卷实例
  • 关键一步：确定开环极点数与零点数之差得渐近线数
  • 中间结果：得三条渐近线的交点与夹角
  • 卡点：实轴根轨迹段判据零极点个数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画出系统根轨迹并求渐近线与实轴段
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过渐近线夹角公式中的2k+1写成2k
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

三三、结构图建模与能控能观判别#

思路
  • 由三阶系统结构图以 x1、x2、x3 为状态变量列状态空间表达式，并判断系统的能控性与能观性。
状态空间表达式的建立 状态空间分析
本卷考法
  • 由三阶系统结构图列写状态空间表达式
本卷实例
  • 关键一步：由各积分环节输入输出关系列微分方程
  • 中间结果：整理成含输入矩阵的矩阵形式
  • 卡点：输出方程漏掉直接传递项D
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
