1、2、3、4、5、6一、简答：稳定域、主导极点与标准型#

思路
  • 六个独立小问：讨论含参数 a 的特征方程稳定、临界稳定与不稳定条件；降低或消除稳态误差的措施；主导极点的概念、作用与判定条件；二重根系统的约当标准型步骤与能控条件；三阶最小实现的参数条件；状态反馈实现积分解耦的条件。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据讨论含参数 a 的特征方程稳定性
本卷实例
  • 关键一步：按降幂列劳斯表，令首列元素大于零解出 a 的范围
  • 中间结果：首列含 a 的元素给出稳定的上界，等号处为临界稳定
  • 卡点：系数缺项要补零；临界稳定与不稳定的分界要写清
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据讨论含参数 a 的特征方程稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

参数稳定域的确定 稳定性分析
本卷考法
  • 求使系统稳定、临界稳定的参数范围
本卷实例
  • 关键一步：把劳斯表首列各不等式联立，取交集得到稳定域
  • 中间结果：参数取端点时出现纯虚根，对应临界稳定
  • 卡点：只列部分首列不等式漏约束；端点是否包含搞错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求使系统稳定、临界稳定的参数范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

减小稳态误差的措施 稳态误差
本卷考法
  • 列举降低或消除稳态误差的常用措施
本卷实例
  • 关键一步：从提高开环增益、增加积分环节、提高型别等途径归纳
  • 中间结果：提高型别可消除某类输入的稳态误差，但影响稳定性
  • 卡点：只谈误差减小而不检查稳定性；把前馈与反馈作用混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过列举降低或消除稳态误差的常用措施
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 叙述主导极点的概念、作用与判定条件
本卷实例
  • 关键一步：主导极点是距虚轴最近且附近无闭环零点的闭环极点
  • 中间结果：其余极点实部距虚轴距离是主导极点的五倍以上可忽略
  • 卡点：只按距离判断而不管留数大小；忽略靠近的闭环零点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过叙述主导极点的概念、作用与判定条件
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 写二重根系统约当标准型的变换步骤
本卷实例
  • 关键一步：由二重根对应的广义特征向量关系构造线性变换阵
  • 中间结果：变换后系统矩阵呈约当型，二重根对应一个约当块
  • 卡点：广义特征向量次序写错；约当块与单根块混排
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 常用能控标准型、能观标准型与对角标准型

  • 最小实现要求系统既能控又能观
步骤

  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法

  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反

状态空间与传递函数的关系 状态空间分析
本卷考法
  • 求三阶最小实现时零极点对消应满足的条件
本卷实例
  • 关键一步：最小实现为三阶等价于传函分子分母没有公因式
  • 中间结果：即分子零点不出现在分母极点中，得到参数的不等式条件
  • 卡点：只验能控能观而不检查是否发生零极点对消
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过求三阶最小实现时零极点对消应满足的条件
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

能控性与能观性 状态空间分析
本卷考法
  • 说明约当型系统的能控条件
本卷实例
  • 关键一步：对约当型检验能控性矩阵是否满秩，重根对应块要单独判断
  • 中间结果：每个约当块最后一行输入矩阵元素不为零是能控条件
  • 卡点：只对系统矩阵判秩而漏看输入矩阵在约当块中的位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过说明约当型系统的能控条件
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

状态反馈解耦 状态空间分析
本卷考法
  • 说明状态反馈实现积分解耦的条件
本卷实例
  • 关键一步：由输出矩阵各行构造结构特性向量并组成解耦矩阵
  • 中间结果：解耦矩阵非奇异是状态反馈可解耦的充要条件
  • 卡点：把相对阶取成输入首次出现的阶数本身；矩阵奇异仍硬解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 解耦的目标是让每个输出只被对应的一个输入控制，闭环传递函数矩阵成为对角阵
  • 用输入变换加状态反馈控制律 u 等于负 Kx 加 Fv 实现解耦
  • 解耦矩阵由各通道输出的相对阶与输入矩阵组成，非奇异时才能解耦
  • 解耦后闭环传函矩阵的对角元由配置的极点决定，非对角元为零
步骤
  • 逐个求各输出的相对阶，即输出导数中首次出现输入的阶数减一
  • 用各通道的相对阶对应的行组成解耦矩阵，并检查其是否非奇异
  • 由解耦矩阵的逆求出输入变换矩阵，再由各通道系数求出状态反馈矩阵
  • 写出闭环传递函数矩阵，校验是否已对角化并满足期望极点
通用考法
  • 本卷考过说明状态反馈实现积分解耦的条件
  • 证明系统能通过输入变换与状态反馈实现解耦
  • 求解耦矩阵与状态反馈阵并写出闭环传递函数矩阵
  • 分析解耦后各通道的极点是否可任意配置
常见易错
  • 相对阶取成输出导数首次出现输入的阶数本身，差一阶
  • 解耦矩阵奇异时仍硬求解，忽略解耦条件不满足

思路

状态转移矩阵 状态空间分析
本卷考法

本卷实例

通用考法

  • 求状态转移矩阵

  • 用性质验证转移矩阵是否正确
常见易错

广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 把含参数系统化为等效开环画参数根轨迹
本卷实例
  • 关键一步：由特征方程把参数项提到标准位置得到等效开环
  • 中间结果：等效开环的极点分布随参数 a 的取值分实根与共轭复根
  • 卡点：参数未完整提取；a 不同区间要分别讨论极点位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l

  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法

  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错

  • 零度根轨迹仍沿用 180° 相角条件

稳定裕度 频域分析
本卷考法
  • 由截止频率与相角裕度校验校正后系统
本卷实例
  • 关键一步：先由幅值条件算截止频率，再代入相频特性求相位裕度
  • 中间结果：校验应同时满足截止频率与相角裕度两项要求
  • 卡点：幅值与相角条件要联立而不是各自独立求解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由截止频率与相角裕度校验校正后系统
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过用李雅普诺夫第一法即线性化判断平衡点稳定性
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过说明非线性系统需按平衡点分别讨论稳定性
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
