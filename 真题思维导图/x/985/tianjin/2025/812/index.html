思路
  • 六个独立小问：写状态空间系统的对偶系统并说明传递函数矩阵关系；叙述李雅普诺夫意义下稳定与一致稳定；说明状态反馈零极点对消的产生条件；画三阶开环的对数幅频渐近线并用劳斯判据定稳定增益范围；分析纯延迟对稳定性的影响；说明闭环零点对动态响应的作用。
状态空间表达式的建立 状态空间分析
本卷考法
  • 写给定状态空间系统的对偶系统
本卷实例
  • 关键一步：把原系统的系统矩阵转置作为新系统矩阵，输入与输出矩阵互换位置
  • 关键一步：对偶系统的输入矩阵取原输出矩阵的转置，输出矩阵取原输入矩阵的转置
  • 中间结果：原系统与对偶系统的矩阵在结构上互为转置关系
  • 卡点：原卷题面给出的系统矩阵被 OCR 丢失，只剩待求文字，需回原卷核对矩阵
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过写给定状态空间系统的对偶系统
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

状态空间与传递函数的关系 状态空间分析
本卷考法
  • 说明原系统与对偶系统的传递函数矩阵关系
本卷实例
  • 关键一步：分别写出原系统与对偶系统的传递函数矩阵表达式
  • 关键一步：对原系统传函矩阵整体转置后与对偶系统传函矩阵逐项对照
  • 中间结果：单输入单输出时传函是标量，转置不变；多变量时两者互为转置
  • 卡点：矩阵转置时乘积次序要反过来，容易只转置各矩阵而忘记交换顺序
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过说明原系统与对偶系统的传递函数矩阵关系
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 叙述李雅普诺夫意义下的稳定与一致稳定定义
本卷实例
  • 关键一步：用 ε 与 δ 的语言描述受扰运动始终不超出给定邻域
  • 关键一步：再看 δ 的选取是否与初始时刻无关，无关即一致稳定
  • 中间结果：稳定定义中的 δ 一般还依赖初始时刻，一致稳定要求与初始时刻无关
  • 卡点：把渐近稳定当成李雅普诺夫稳定；一致稳定是稳定定义的加强而非另一定义
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过叙述李雅普诺夫意义下的稳定与一致稳定定义
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

状态反馈与极点配置 状态空间分析
本卷考法
  • 说明状态反馈零极点对消的产生条件
本卷实例
  • 关键一步：状态反馈只改变闭环极点、不改变原系统零点
  • 关键一步：当反馈配置出的某个闭环极点恰好落在原系统零点上就对消
  • 中间结果：原系统无零点，或配置出的极点与原零点都不重合时，不发生零极点对消
  • 卡点：把零点也当成可被状态反馈任意配置的量；对消会掩盖不能控或不能观模态
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过说明状态反馈零极点对消的产生条件
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反

开环对数频率特性的绘制 频域分析
本卷考法
  • 画三阶开环系统的对数幅频渐近线
本卷实例
  • 关键一步：把传函写成典型环节乘积，由积分环节个数定低频段斜率
  • 关键一步：按转折频率从小到大逐段叠加斜率变化，画出渐近线
  • 中间结果：本题含一个积分环节与两个惯性环节，转折频率分别为三分之一与二分之一弧度每秒
  • 卡点：增益 K 未定，曲线只上下平移，形状与转折频率不随 K 改变；曲线图需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过画三阶开环系统的对数幅频渐近线
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

参数稳定域的确定 稳定性分析
本卷考法
  • 由劳斯判据求使闭环稳定的增益范围
本卷实例
  • 关键一步：写出闭环特征方程并按降幂排列，列出劳斯表
  • 关键一步：令劳斯表首列各元素同号，解出增益的不等式组
  • 中间结果：特征方程由三次多项式加常数增益项组成；临界增益对应首列元素为零
  • 卡点：系数缺项要补零；增益上界来自首列中含增益的那个元素
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由劳斯判据求使闭环稳定的增益范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

含纯延迟环节的系统稳定性 稳定性分析
本卷考法
  • 分析纯延迟环节对系统稳定性的影响
本卷实例
  • 关键一步：延迟环节幅值为一，只在相频特性上叠加一个与频率成正比的滞后
  • 关键一步：相位曲线整体下移使相位裕度减小，延迟增大到使裕度转负时系统失稳
  • 中间结果：稳定性由幅值与相位两条件共同决定，延迟只改变相位条件
  • 卡点：把延迟当成惯性环节；角度与弧度换算容易出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 延迟环节 e^{-τs} 的幅值为 1、相位为 -τω，只恶化相位
  • 延迟会显著缩小稳定域，τ 越大越难稳定
  • 频域判据需用相位裕度扣除延迟引起的附加滞后
步骤
  • 写出含延迟的开环传递函数
  • 分别求幅值与相位表达式
  • 在相频特性中扣除 τω 的滞后量
  • 按稳定裕度或奈氏判据求临界 τ 或临界 K
通用考法
  • 本卷考过分析纯延迟环节对系统稳定性的影响
  • 求使系统稳定的最大延迟时间
  • 求含延迟系统的临界开环增益
  • 分析延迟对稳定裕度的影响
常见易错
  • 把延迟环节当成惯性环节处理
  • 相位计算时忘记角度与弧度换算

零极点分布与响应模态 传递函数
本卷考法
  • 说明闭环零点对动态响应的作用
本卷实例
  • 关键一步：闭环零点不改变响应所含模态，但改变各模态的加权系数
  • 关键一步：由零点相对极点的位置判断它增强还是削弱某个模态
  • 中间结果：零点靠近虚轴时会显著加大超调与振荡，远离虚轴则影响减弱
  • 卡点：只讨论极点而忽略零点；把闭环零点与开环零点的影响混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过说明闭环零点对动态响应的作用
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

二二、传函的对角标准型与状态变量图#

思路
  • 已知三阶真分式传函，先做部分分式展开写出对角标准型状态空间实现，再由对角型的积分器链画出系统状态变量图。
由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 由传函写对角标准型并画状态变量图
本卷实例
  • 关键一步：把传函做部分分式展开，每个一阶实极点对应一个对角元
  • 关键一步：按对角标准型把极点填入系统矩阵对角线，由留数写出输出矩阵
  • 关键一步：状态变量图按积分器链画，各积分器之间按对角型结构连线
  • 中间结果：本题分母有三个互异实极点，适合对角标准型；三个留数分别决定输出矩阵三个元素
  • 卡点：重极点时对角型要换成约旦型；图中反馈与前馈系数需回原卷核对结构图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法
  • 本卷考过由传函写对角标准型并画状态变量图
  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反

三三、机械平移系统的建模与二阶响应#

思路
  • 由机械平移系统的力和位移关系列写运动微分方程求传函，对照二阶标准形式写出阻尼比与自然频率，再由阶跃输入的终值求稳态位移。题面含图未读图。
机械系统建模 建模与机电系统
本卷考法
  • 由机械平移系统列写运动方程并求传函
本卷实例
  • 关键一步：按受力分析列写质量、阻尼、弹簧三项合力等于外力
  • 关键一步：对微分方程取零初始条件的拉氏变换，写出位移对力的传函
  • 中间结果：传函分母是二阶特征多项式，分子为常数；参数由质量、阻尼和弹性系数组成
  • 卡点：阻尼力与弹簧力的正负方向容易取反；各元件连接方式需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过由机械平移系统列写运动方程并求传函
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由传函对照二阶标准形式写阻尼比与自然频率
本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 微分项提供超前相位改善动态性能但对噪声敏感

八八、非线性系统的相轨迹与扰动稳态误差#

思路
  • 非线性环节为饱和特性，按误差的三个区间分段列写误差微分方程，在相平面上画各区相轨迹并判断奇点类型；加入阶跃扰动后各区间方程的常数项平移，据此比较稳态误差。题面含图未读图。
典型非线性特性及其影响 非线性系统
本卷考法
  • 由结构图识别饱和非线性并分段写特性
本卷实例
  • 关键一步：按误差绝对值是否超过线性区边界把非线性环节输出分成三段
  • 关键一步：线性区输出等于误差本身，两侧区域输出为常值
  • 中间结果：分段边界是误差绝对值等于一的两条竖线，各段等效增益分别为零与一
  • 卡点：饱和特性的分界与输出限幅值需回原卷核对图；不要与死区特性混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 饱和特性降低等效增益，可能引起系统不稳定或自振
  • 死区特性使小信号时增益为零，产生稳态误差
  • 间隙特性引起相位滞后，导致波形畸变与自振
  • 继电特性使系统出现持续振荡并可能产生颤振
步骤
  • 识别非线性环节类型
  • 写出其描述函数或分段数学表达式
  • 分析其对等效增益与稳定性的影响

  • 本卷考过由结构图识别饱和非线性并分段写特性
  • 分析饱和或死区对系统性能的影响
  • 求典型非线性的描述函数表达式
  • 说明间隙为何容易引起自振

本卷考法
