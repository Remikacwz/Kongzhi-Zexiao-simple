1~8一、简答题：状态空间与稳定域40 分#

思路
  • 八个独立小问：由状态空间求传函并说明能控能观与零极点对消的关系；输出反馈可镇定的充要条件；李雅普诺夫第二法判大范围渐近稳定的条件及与平衡点个数的关系；两系统负反馈互联的闭环状态方程；劳斯判据求参数a的稳定域；由超调量与调节时间反求阻尼比与自然频率；由稳定性先决条件确定单位斜坡稳态误差范围；最小相位与非最小相位的判别。
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由状态空间求传递函数并说明其与能控能观性的关系
本卷实例
  • 关键一步：写 C(sI−A)⁻¹b，再看分子分母是否有零极点相消
  • 中间结果：存在零极点对消则系统不完全能控或不能观
  • 卡点：忘记约分，直接由传函阶数判断能控能观
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过由状态空间求传递函数并说明其与能控能观性的关系
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

能控性与能观性 状态空间分析
本卷考法
  • 写出线性定常系统输出反馈可镇定的充要条件
本卷实例
  • 关键一步：对系统作能控能观结构分解，检查能控且能观子系统
  • 中间结果：能控能观子系统可镇定、其余子系统渐近稳定时可镇定
  • 卡点：把状态反馈可镇定条件直接当成输出反馈的条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过写出线性定常系统输出反馈可镇定的充要条件
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 叙述李雅普诺夫第二法判大范围渐近稳定的条件
本卷实例
  • 关键一步：构造正定 V(x)，令 V̇ 负定或半负定且除原点外不恒为零
  • 中间结果：再加径向无界条件即得大范围渐近稳定
  • 卡点：只验 V 正定不查 V̇ 定号；与平衡点个数关系漏答
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过叙述李雅普诺夫第二法判大范围渐近稳定的条件
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

状态空间表达式的建立 状态空间分析
本卷考法
  • 写出两子系统负反馈互联后的闭环状态空间表达式
本卷实例
  • 关键一步：把反馈支路输出 C₂x₂ 代入前向子系统的输入
  • 中间结果：闭环 A 阵为分块矩阵，前向块含 −B₁C₂ 耦合项
  • 卡点：反馈符号与 B、C 的维数对应写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过写出两子系统负反馈互联后的闭环状态空间表达式
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

劳斯判据 稳定性分析
本卷考法
  • 列劳斯表求系统稳定时参数 a 的取值范围
本卷实例
  • 关键一步：按特征方程系数列劳斯表，令首列各元素同号
  • 中间结果：由 s²、s¹ 两行系数大于零联立取交集
  • 卡点：漏取首列某个元素的符号约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过列劳斯表求系统稳定时参数 a 的取值范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求参数稳定域并确定端点开闭
本卷实例
  • 关键一步：把劳斯表首列不等式联立，取其交集
  • 中间结果：稳定域为参数 a 的一个开区间
  • 卡点：端点是否包含判断错误
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求参数稳定域并确定端点开闭
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量求阻尼比、由调节时间求自然频率
本卷实例
  • 关键一步：由超调量公式反解 ξ，再代入 ts 与 ξωn 的关系式
  • 中间结果：按 2% 误差带取 ts≈4.4/(ξωn)
  • 卡点：调节时间系数按 2% 还是 5% 取错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量求阻尼比、由调节时间求自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由两项性能指标要求反求系统参数
本卷实例
  • 关键一步：先由超调量定 ξ，再由调节时间定 ξωn
  • 中间结果：两式联立可唯一确定 ξ 与 ωn
  • 卡点：只满足单项指标就下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由两项性能指标要求反求系统参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

系统型别与静态误差系数 稳态误差
本卷考法
  • 先判稳再写单位斜坡输入的静态速度误差系数
本卷实例
  • 关键一步：劳斯判据先定 K 的稳定区间，再写 Kv 与 ess=1/Kv
  • 中间结果：ess 随 K 单调变化，对稳定区间两端取值即得范围
  • 卡点：未判稳就用终值定理；系统型别判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过先判稳再写单位斜坡输入的静态速度误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

最小相位系统与非最小相位系统 频域分析
本卷考法
  • 说明最小相位与非最小相位系统的区别并判别给定传函
本卷实例
  • 关键一步：检查所有零极点是否位于左半平面（离散为单位圆内）
  • 中间结果：纯延迟只改变相位不移动零极点，是否计入需按定义讨论
  • 卡点：把右半平面极点与右半平面零点混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过说明最小相位与非最小相位系统的区别并判别给定传函
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈

2二、方框图双输入求传递函数10 分#

思路
  • 系统方框图含参考输入与扰动两个输入。先画信号流图，用梅森增益公式分别求 C(s)/R(s) 与 C(s)/N(s)：两路分母相同，求扰动传函时把参考输入置零。题面以图给出。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由系统方框图用梅森公式求输出对参考输入的传函
本卷实例
  • 关键一步：先画信号流图，标出全部前向通道与回路
  • 中间结果：分别列各前向通道增益与对应余子式
  • 卡点：不接触回路找漏；余子式未剔除接触回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由系统方框图用梅森公式求输出对参考输入的传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求参考输入与扰动作用下的输出传递函数
本卷实例
  • 关键一步：求扰动传函时把参考输入置零，单独沿扰动通路列写
  • 中间结果：两路传函分母相同、分子由各自前向通道决定
  • 卡点：直接把两个输入叠加；扰动通路前向通道找错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求参考输入与扰动作用下的输出传递函数
  • 求扰动引起的输出或误差

7七、状态反馈与全维观测器20 分#

思路
  • 线性定常系统 ẋ=Ax+Bu、y=Cx。第(1)问写直接状态反馈 u=Kx+v 的闭环状态空间表达式；第(2)问写全维观测器方程，并以 x 与观测误差 e 为状态重构闭环；第(3)问证明两种方案的传递函数矩阵相同。
状态反馈与极点配置 状态空间分析
本卷考法
  • 写出直接状态反馈 u=Kx+v 的闭环状态空间表达式
本卷实例
  • 关键一步：把 u=Kx+v 代入状态方程，合并 x 的系数
  • 中间结果：闭环 A 阵为 A+BK，输出方程不变
  • 卡点：未验证能控性就直接做极点配置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K

  • 分析状态反馈对系统性能的影响
