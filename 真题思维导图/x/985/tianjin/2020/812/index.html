欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 叙述二阶欠阻尼系统调节时间定义及阻尼比与超调量关系
本卷实例
  • 关键一步：按响应进入终值正负5%误差带定义调节时间
  • 中间结果：超调量随阻尼比增大而减小
  • 卡点：超调量公式中漏乘100%
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数

奈奎斯特判据 稳定性分析
本卷考法
  • 简述奈奎斯特稳定判据并说明包围圈数与开环右半平面极点数关系
本卷实例
  • 关键一步：以开环右半平面极点数P为基准
  • 中间结果：由曲线包围临界点的圈数判断闭环稳定性
  • 卡点：把包围圈数的正负号定义搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过简述奈奎斯特稳定判据并说明包围圈数与开环右半平面极点数关系
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过没有先数开环右半平面极点数P
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点

  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验

  • 分析超前校正的局限性

思路
  • 将含参数的开环传函整理为等效标准根轨迹，画 k 从零到正无穷的根轨迹并求分离点与虚轴交点，定系统稳定与单位阶跃振荡收敛的 k 取值范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 把含参数传函整理成等效开环后画根轨迹
本卷实例
  • 关键一步：由闭环特征方程整理出等效开环形式
  • 中间结果：按等效开环的三个极点画根轨迹
  • 卡点：等效开环与原开环的极点混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过把含参数传函整理成等效开环后画根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过整理时未把参数完整提到分子位置
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

  • 求根轨迹的分离点坐标

  • 判断解的取舍

  • 求出方程根后不筛选，保留了不在根轨迹上的解

思路

本卷考法

七七、非线性系统相平面与最大稳态误差#

思路
  • 由含非线性环节的系统结构图列写误差方程，按开关线分区间画相平面相轨迹，判断系统稳定性并求最大稳态误差。
典型非线性特性及其影响 非线性系统
本卷考法
  • 由结构图写出非线性环节的分段输出关系与开关线
本卷实例
  • 关键一步：按非线性环节输入所在区间分三段
  • 中间结果：得各分区对应的误差微分方程
  • 卡点：开关线方程符号取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 饱和特性降低等效增益，可能引起系统不稳定或自振
  • 死区特性使小信号时增益为零，产生稳态误差
  • 间隙特性引起相位滞后，导致波形畸变与自振
  • 继电特性使系统出现持续振荡并可能产生颤振
步骤
  • 识别非线性环节类型
  • 写出其描述函数或分段数学表达式
