1、2、3、4一、简答：主导极点、频段设计、标准型与李雅普诺夫#

思路
  • 四个独立简答小问：主导极点的概念与存在条件；反馈系统低中高频段的划分与控制目的；能控、能观与约旦标准型的特点及适用范围；平衡状态在李雅普诺夫意义下稳定、渐近稳定与大范围稳定的判别准则。
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 叙述主导极点概念及应满足的条件，说明系统并非都有主导极点
本卷实例
  • 关键一步：按主导极点定义列出两条存在条件
  • 中间结果：得极点实部比值与零点分布两项判据
  • 卡点：忽略附近无其他零极点这一量化条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过叙述主导极点概念及应满足的条件，说明系统并非都有主导极点
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 本卷考过把主导极点只等同于距虚轴最近的极点
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

期望特性法与综合法 系统校正
本卷考法
  • 叙述低中高频段的划分标准及低频高增益、高频低增益的目的
本卷实例
  • 关键一步：按转折频率与穿越频率划分低中高频段
  • 中间结果：低频段对应稳态精度、中频段对应稳定与快速性
  • 卡点：中频段设计未同时兼顾截止频率与相角裕度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 期望特性法直接按指标画出希望的开环对数幅频特性
  • 用期望特性减去未校正特性得到校正装置特性
  • 关键是确定低频段高度、中频段宽度与高频段斜率
  • 中频段斜率一般取 -20 dB/dec 并保持足够宽度
步骤
  • 按稳态要求确定低频段斜率与高度
  • 按相角裕度要求确定中频段宽度与截止频率
  • 按抗噪要求确定高频段斜率
  • 相减求得校正装置并检验可实现性
通用考法
  • 本卷考过叙述低中高频段的划分标准及低频高增益、高频低增益的目的
  • 用期望特性法设计校正装置
  • 说明中频段宽度与相角裕度的关系
  • 由校正装置特性反写传递函数
常见易错
  • 本卷考过把中频段设计只归结为增益大小
  • 期望特性的中频段取窄导致裕度不足
  • 相减后得到的特性不可物理实现却未检查

由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 比较能控、能观与约旦标准型的特点及各自适用范围
本卷实例
  • 关键一步：从状态矩阵结构区分三类标准型
  • 中间结果：能控型末行为分母系数、能观型为其对偶
  • 卡点：约旦标准型适用范围写成仅完全能控系统
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法
  • 本卷考过比较能控、能观与约旦标准型的特点及各自适用范围
  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 本卷考过把约旦标准型也说成只适用于能控或能观系统
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反

李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 叙述平衡状态在李雅普诺夫意义下稳定、渐近稳定与大范围稳定的准则
本卷实例
  • 关键一步：从平衡状态的邻域出发定义稳定与渐近稳定
  • 中间结果：大范围渐近稳定要求全部初始状态出发的轨线收敛
  • 卡点：大范围稳定还需状态无限增长时范数趋于无穷
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过叙述平衡状态在李雅普诺夫意义下稳定、渐近稳定与大范围稳定的准则
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 本卷考过把渐近稳定与大范围渐近稳定的条件混为一谈
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

思路
  • 由质量-弹簧-阻尼系统受力分析列微分方程，并由衰减振荡条件确定质量、阻尼与刚度关系；再由有源放大器电路求传递函数并画对数频率特性。
机械系统建模 建模与机电系统
本卷考法

本卷实例

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由衰减振荡条件确定质量、阻尼与刚度参数满足的不等式
本卷实例
  • 关键一步：由二阶系统标准形式写出阻尼比表达式
  • 中间结果：衰减振荡对应阻尼比小于1的参数不等式
  • 卡点：未先化为标准形式就直接比较系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由衰减振荡条件确定质量、阻尼与刚度参数满足的不等式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过把衰减振荡条件误写成阻尼比大于一
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

三三、根轨迹绘制与稳定K范围#

思路
  • 对 G=k/[s(s+2)(s+3)] 按绘制法则画 K:0到正无穷的根轨迹，求分离点、渐近线与虚轴交点，据临界增益定稳定范围，并由-5为闭环极点反求增益与其余极点。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画出三个开环极点无零点的系统根轨迹
本卷实例
  • 关键一步：标出开环极点并确定渐近线条数与夹角
  • 中间结果：得三条奔向无穷远的渐近线
  • 卡点：渐近线交点计算符号取错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画出三个开环极点无零点的系统根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴根轨迹段的零极点个数算错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

分离点与会合点 根轨迹法
本卷考法
  • 由分离点方程求实轴上的分离点并取舍
本卷实例
  • 关键一步：对特征方程用增益对s求导为零求驻点
  • 中间结果：得两个候选分离点后筛去无效解
  • 卡点：候选解未经实轴段判据筛选
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤

  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由分离点方程求实轴上的分离点并取舍
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍

  • 由给定 A、B、C 求能控性与能观性判别阵并判断秩；再分析不可控模态与不可观模态存在时，状态反馈与观测器组合的极点能否任意配置。
能控性与能观性 状态空间分析
本卷考法
  • 构造能控性与能观性矩阵并判断系统是否完全能控能观
本卷实例
  • 关键一步：分别计算能控性矩阵与能观性矩阵的秩
  • 中间结果：秩小于状态维数判为不完全能控能观
  • 卡点：只列矩阵不求秩就下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解

  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解

  • 本卷考过把能控性判据与能观性判据的矩阵构造搞混
  • 只算到 A^{n-2}B 就下结论

本卷考法
  • 分析不可控模态存在时状态反馈极点配置的可行性
本卷实例
  • 关键一步：找出不可控模态对应的特征值
  • 中间结果：不可控模态极点不能被状态反馈改变
  • 卡点：把可配置极点个数与状态维数直接等同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性

  • 求闭环系统特征多项式 det(sI-A+BK)

八八、饱和非线性相平面与稳定性#

思路
  • 由含饱和非线性环节的系统结构图列写误差方程与开关线，在相平面分区间画相轨迹并判断奇点性质，从而判断系统稳定性。
典型非线性特性及其影响 非线性系统
本卷考法
  • 由结构图写出饱和非线性环节的分段输入输出关系
本卷实例
  • 关键一步：按输入绝对值与限幅值的关系分三段
  • 中间结果：得饱和特性的分段线性表达式
  • 卡点：分区边界条件写反导致相轨迹接错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 饱和特性降低等效增益，可能引起系统不稳定或自振
  • 死区特性使小信号时增益为零，产生稳态误差
  • 间隙特性引起相位滞后，导致波形畸变与自振
  • 继电特性使系统出现持续振荡并可能产生颤振
步骤
  • 识别非线性环节类型
  • 写出其描述函数或分段数学表达式
  • 分析其对等效增益与稳定性的影响
通用考法
  • 本卷考过由结构图写出饱和非线性环节的分段输入输出关系
  • 分析饱和或死区对系统性能的影响
  • 求典型非线性的描述函数表达式
  • 说明间隙为何容易引起自振
常见易错
  • 本卷考过认为饱和总是使系统更稳定
  • 认为饱和总是使系统更稳定
  • 忽略死区在原点附近造成的小信号失效

相平面法 非线性系统
本卷考法
  • 分区间绘制相轨迹并判断奇点类型与稳定性
本卷实例
  • 关键一步：由误差方程消去时间得相轨迹斜率方程
  • 中间结果：各区求得中心点或稳定节点等奇点
  • 卡点：由相轨迹判断收敛性时看错开关线
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过分区间绘制相轨迹并判断奇点类型与稳定性
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 本卷考过相轨迹斜率公式分子分母写反
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆
