一一、方框图状态空间与稳定参数范围#

思路
  • 由系统方框图列写状态空间表达式并判断能控性、能观性；再求使闭环系统稳定的参数取值范围
状态空间表达式的建立 状态空间分析
本卷考法
  • 由系统方框图列写状态空间表达式
本卷实例
  • 关键一步：按方框图中每个积分器输出编号取状态变量
  • 中间结果：列写一阶方程组并整理成矩阵形式
  • 卡点：反馈增益未随状态变量进入系统矩阵
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由系统方框图列写状态空间表达式
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 本卷考过按积分器取状态变量时变量顺序颠倒
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

能控性与能观性 状态空间分析
本卷考法
  • 由系统矩阵判断系统的能控性与能观性
本卷实例
  • 关键一步：分别构造能控性矩阵与能观性矩阵
  • 中间结果：由判别阵行列式是否为零判断可控可观
  • 卡点：只看数值不看含参数行列式的零点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过由系统矩阵判断系统的能控性与能观性
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 本卷考过含参数系统的判别阵秩讨论不完整
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

参数稳定域的确定 稳定性分析
本卷考法
  • 求使闭环系统稳定的参数取值范围
本卷实例
  • 关键一步：由特征方程系数列劳斯表并令首列为正
  • 中间结果：解不等式组得参数的开区间范围
  • 卡点：区间端点是否可取未单独校验
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求使闭环系统稳定的参数取值范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 本卷考过劳斯表首列不等式的组合遗漏
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

二二、李雅普诺夫第二法与状态反馈极点配置#

思路
  • 对给定二阶系统用李雅普诺夫第二法在零输入下判断稳定性；再用状态反馈把闭环极点配置到期望位置
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 用李雅普诺夫第二法判断系统稳定性
本卷实例
  • 关键一步：选二次型候选函数并求其沿轨线的导数
  • 中间结果：由导数半正定且不恒为零判定原点稳定性
  • 卡点：函数正定性与导数定号性判断颠倒
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过用李雅普诺夫第二法判断系统稳定性
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 本卷考过候选函数的导数符号判断错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

状态反馈与极点配置 状态空间分析
本卷考法
  • 用状态反馈把闭环极点配置到期望位置
本卷实例
  • 关键一步：先验证能控性再设状态反馈增益向量
  • 中间结果：令闭环特征多项式与期望多项式系数相等
  • 卡点：解方程组时增益分量顺序颠倒
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过用状态反馈把闭环极点配置到期望位置
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 本卷考过期望多项式展开时系数对应错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反

三三、根轨迹绘制与降阶估算#

思路
  • 画出增益由零到无穷的根轨迹；由给定闭环极点求增益与另外两个极点；再用主导极点降阶估算调节时间与超调量
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画出根轨迹的大致走向
本卷实例
  • 关键一步：标出开环极零点并判断实轴上根轨迹段
  • 中间结果：算渐近线交点与夹角定根轨迹走向
  • 卡点：根轨迹的起点与终点方向画反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画出根轨迹的大致走向
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴根轨迹段的判定正负号用错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由给定闭环极点反求增益与其余极点
本卷实例
  • 关键一步：把已知闭环极点代入特征方程求增益
  • 中间结果：用长除法降阶求另外两个闭环极点
  • 卡点：求出的极点未按根之和校验
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由给定闭环极点反求增益与其余极点
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 本卷考过长除法降阶时余式处理错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 用闭环主导极点对系统降阶
本卷实例
  • 关键一步：比较各闭环极点实部找出主导极点对
  • 中间结果：保留主导极点对写二阶标准形式
  • 卡点：未确认其余极点确实远离虚轴
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过用闭环主导极点对系统降阶
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 本卷考过把靠近虚轴的极点当非主导极点舍去
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由降阶二阶模型估算调节时间与超调量
本卷实例
  • 关键一步：由二阶标准形式读出阻尼比与自然频率
  • 中间结果：代入超调量与调节时间公式估算
  • 卡点：忽略闭环零点后直接套二阶公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由降阶二阶模型估算调节时间与超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过误差带对应系数取值用错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

四四、由对数幅频求传函与奈氏判据#

思路
  • 由给定开环对数幅频特性曲线反求传递函数；画奈奎斯特曲线并标出与实轴虚轴的交点；再用奈奎斯特判据判断闭环稳定性
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频特性曲线反求开环传递函数
本卷实例
  • 关键一步：由低频段斜率与高度定系统型别和增益
  • 中间结果：由各转折频率定相应的时间常数
  • 卡点：转折处斜率变化量对应几阶环节写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频特性曲线反求开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 本卷考过低频段斜率与系统型别对应关系弄错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 画奈奎斯特曲线并求与实轴虚轴的交点
本卷实例
  • 关键一步：求频率趋近两端时的幅值与相角
  • 中间结果：令实部或虚部为零求曲线与坐标轴交点
  • 卡点：交点对应的频率求解不完整
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过画奈奎斯特曲线并求与实轴虚轴的交点
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过频率趋于零与无穷时的幅相趋势判断错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据判断闭环稳定性
本卷实例
  • 关键一步：数曲线包围临界点的圈数与开环右极点数
  • 中间结果：由两者关系得闭环右半平面极点数
  • 卡点：曲线是否包围临界点判断错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
