1、2、3、4、5一、简答：二阶指标、状态响应与反馈配置#

思路
  • 五个独立小问：典型二阶系统上升时间、调节时间与超调量公式；初态已知时单位脉冲输入的状态响应；幅值裕度与相位裕度的定义；状态反馈结构图与任意配置极点的充要条件；能测性判别与能测性分解步骤。
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 写典型二阶系统上升时间、调节时间与超调量公式
本卷实例
  • 关键一步：先由阻尼比与自然频率写出各指标公式中出现的角量
  • 中间结果：上升时间与 arctanξ 有关，超调量只由阻尼比决定
  • 卡点：调节时间系数取 3.5 还是 3.0 要看误差带；超调量漏乘 100%
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过写典型二阶系统上升时间、调节时间与超调量公式
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由二阶标准形式明确阻尼比与自然频率的地位
本卷实例
  • 关键一步：把闭环传函写成标准二阶形式，再对照指标公式使用
  • 中间结果：各公式都以阻尼比与自然频率为参数，需先由传函把它们定出
  • 卡点：把开环增益当成闭环直流增益；标准形式未首一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由二阶标准形式明确阻尼比与自然频率的地位
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

本卷考法

本卷实例
  • 关键一步：用状态转移矩阵写出零输入项与卷积积分零状态项之和

  • 卡点：卷积积分上下限与变量代换易错；漏掉零输入分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 用性质验证转移矩阵是否正确

稳定裕度 频域分析
本卷考法
  • 概述幅值裕度与相位裕度的定义
本卷实例
  • 关键一步：在开环幅相曲线上分别找负实轴交点和单位圆交点
  • 中间结果：幅值裕度由负实轴交点到原点的距离倒数给出
  • 卡点：把幅值裕度写成该交点幅值本身而不是其倒数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过概述幅值裕度与相位裕度的定义
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

状态反馈与极点配置 状态空间分析
本卷考法
  • 画状态反馈结构图并说明任意配置极点的条件
本卷实例
  • 关键一步：把 u 等于 v 减 Fx 的反馈通道接在状态变量到输入之间画结构图
  • 中间结果：任意配置极点的充要条件是系统完全能控
  • 卡点：把充要条件误写成能观；反馈极性或变量对应画错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法

  • 分析状态反馈对系统性能的影响

  • 特征多项式比较系数时符号写反

二二、非线性系统平衡点的稳定性#

思路
  • 先由状态方程解出全部平衡点，再在平衡点处求雅可比矩阵做线性化，用特征值实部符号判断各平衡点的稳定性，属李雅普诺夫第一法（间接法）。
非线性系统的特点 非线性系统
本卷考法
  • 说明非线性系统稳定性分析为何要分平衡点讨论
本卷实例
  • 关键一步：先令状态导数同时为零解出全部平衡点，再逐点分析
  • 中间结果：不同平衡点的稳定性可以完全不同，必须分别判断
  • 卡点：把非线性系统当成线性系统整体判稳；漏掉部分平衡点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过说明非线性系统稳定性分析为何要分平衡点讨论
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 用线性化即李雅普诺夫第一法判断平衡点稳定性
本卷实例
  • 关键一步：在平衡点求雅可比矩阵，用其线性化系统近似原系统
  • 中间结果：特征值实部全负则渐近稳定，存在正实部则不稳定
  • 卡点：雅可比矩阵元素求偏导时变量对应错；临界情形需另判
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过用线性化即李雅普诺夫第一法判断平衡点稳定性
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

三三、含右半平面极点的根轨迹#

思路
  • 由开环传函写闭环特征方程，按根轨迹法则画图；再由实轴段、渐近线、分离点与虚轴交点确定闭环稳定时 K 的取值范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画含右半平面开环极点的根轨迹
本卷实例
  • 关键一步：先定开环极点零点个数与渐近线条数，再判实轴段与分离点
  • 中间结果：开环有一个右半平面极点，根轨迹起点分布与之对应
  • 卡点：实轴段判据中右侧零极点个数算错；渐近线夹角公式写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画含右半平面开环极点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及闭环稳定时 K 的范围
本卷实例
  • 关键一步：用劳斯表令首列含 K 的元素为零求得临界 K，再代回求交点
  • 中间结果：临界参数对应根轨迹穿过虚轴时的增益
  • 卡点：只代一个频率漏解；稳定区间方向要结合根轨迹走向判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及闭环稳定时 K 的范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

四四、非线性系统相平面与描述函数#

思路
  • 先由结构图写饱和非线性输出与误差方程，按误差区间画相轨迹并判断稳态误差；再用描述函数法画出负倒描述函数与线性部分幅相曲线，判断系统稳定性。题面含图未读图。
相平面法 非线性系统
本卷考法
  • 按误差区间画相轨迹并分析是否存在稳态误差
本卷实例
  • 关键一步：把误差微分方程化为一阶相轨迹斜率方程，分区求奇点与渐近线
  • 中间结果：线性区奇点为稳定焦点，两侧区方程退化为常值渐近线
  • 卡点：相轨迹斜率分子分母写反；初始条件需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过按误差区间画相轨迹并分析是否存在稳态误差
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

用描述函数法分析自振 非线性系统
本卷考法
  • 用描述函数法判断非线性系统是否自振
本卷实例
  • 关键一步：在同图上画负倒描述函数曲线与线性部分幅相曲线，看是否相交
  • 中间结果：两曲线相交则可能存在自持振荡，还要判振幅方向是否稳定
  • 卡点：画的是描述函数本身而不是负倒描述函数；未标注振幅方向
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过用描述函数法判断非线性系统是否自振
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率

稳定裕度 频域分析
本卷考法
  • 求校正前后的相位裕度并比较
本卷实例
  • 关键一步：先由幅值条件求截止频率，再代入相频特性算相位裕度
  • 中间结果：校正后中频段以 -20dB/dec 穿越横轴，裕度明显提高
  • 卡点：截止频率变化后相角要重算；相位裕度方向算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求校正前后的相位裕度并比较
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

思路
  • 由结构图写出原系统传递函数矩阵与反馈校正结构，求闭环传递函数矩阵表达式；再按给定期望对角矩阵反解前馈加状态反馈的校正矩阵。题面含图未读图。
状态反馈解耦 状态空间分析
本卷考法
  • 求前馈加状态反馈解耦系统的闭环传函矩阵
本卷实例
  • 关键一步：由结构图写 u 等于 Gc 乘 r 减 y 与 y 等于 Gp 乘 u 两式并消元
  • 中间结果：闭环传函阵为单位阵加 GpGc 之逆乘 GpGc
  • 卡点：矩阵乘法次序不能交换；连接方式需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 解耦的目标是让每个输出只被对应的一个输入控制，闭环传递函数矩阵成为对角阵
  • 用输入变换加状态反馈控制律 u 等于负 Kx 加 Fv 实现解耦
  • 解耦矩阵由各通道输出的相对阶与输入矩阵组成，非奇异时才能解耦
  • 解耦后闭环传函矩阵的对角元由配置的极点决定，非对角元为零
步骤
  • 逐个求各输出的相对阶，即输出导数中首次出现输入的阶数减一
  • 用各通道的相对阶对应的行组成解耦矩阵，并检查其是否非奇异
  • 由解耦矩阵的逆求出输入变换矩阵，再由各通道系数求出状态反馈矩阵
  • 写出闭环传递函数矩阵，校验是否已对角化并满足期望极点
通用考法
  • 本卷考过求前馈加状态反馈解耦系统的闭环传函矩阵
  • 证明系统能通过输入变换与状态反馈实现解耦
  • 求解耦矩阵与状态反馈阵并写出闭环传递函数矩阵
  • 分析解耦后各通道的极点是否可任意配置
常见易错
  • 相对阶取成输出导数首次出现输入的阶数本身，差一阶
  • 解耦矩阵奇异时仍硬求解，忽略解耦条件不满足

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过按期望对角矩阵反解前馈加反馈校正矩阵
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
