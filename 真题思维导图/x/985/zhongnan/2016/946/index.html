1选择题：基本要求、传递函数、稳态误差与采样20 分#

思路
  • 五道判断：控制系统基本要求的表述、反馈系统稳态误差是否为零、传递函数是否与输入有关、恒值与随动系统的重点、采样周期的影响
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断控制系统稳准快与相对稳定性等基本要求的表述（第1小题）
  • 区分恒值控制系统与随动系统的分析设计重点（第4小题）
本卷实例
  • 关键一步：逐句对照稳定性、快速性与稳态误差的要求
  • 中间结果：第1小题把响应速度强调得过头，忽略了阻尼与超调
  • 卡点：响应速度并非越快越好，须兼顾相对稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断控制系统稳准快与相对稳定性等基本要求的表述（第1小题）
  • 本卷考过区分恒值控制系统与随动系统的分析设计重点（第4小题）
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
系统型别与静态误差系数 稳态误差
本卷考法
  • 判断反馈控制系统稳态误差是否恒为零（第2小题）
本卷实例
  • 关键一步：由系统型别与输入形式决定稳态误差是否为零
  • 中间结果：0型系统在阶跃输入下稳态误差并不为零
  • 卡点：勿把所有反馈系统都当成无差系统
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断反馈控制系统稳态误差是否恒为零（第2小题）
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
传递函数的定义与基本性质 传递函数
本卷考法
  • 判断传递函数是否与输入量形式有关（第3小题）
本卷实例
  • 关键一步：回到传递函数只由结构与参数决定这一性质
  • 中间结果：传递函数与输入量形式无关
  • 卡点：题干说与输入有关，属定性错误
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过判断传递函数是否与输入量形式有关（第3小题）
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
采样过程与香农采样定理 离散控制系统
本卷考法
  • 判断采样周期对控制效果与计算负担的影响（第5小题）
本卷实例
  • 关键一步：权衡采样频率带来的信息量与计算负担
  • 中间结果：采样周期过小会增加不必要的计算负担
  • 卡点：采样周期越小并非各项性能都更优
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过判断采样周期对控制效果与计算负担的影响（第5小题）
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

2简答：减小稳态误差的措施与大范围稳定20 分#

思路
  • 两小问：从增益、积分环节与复合控制角度谈减小稳态误差的措施；比较大范围稳定与小范围稳定的定义与差别
减小稳态误差的措施 稳态误差
本卷考法
  • 列举减小或消除控制系统稳态误差的主要措施（第1小问）
本卷实例
  • 关键一步：从提高开环增益、增加积分环节、引入前馈三条路想
  • 中间结果：提高增益可降误差但受稳定性约束
  • 卡点：只提增大增益而不谈对稳定性的影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过列举减小或消除控制系统稳态误差的主要措施（第1小问）
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式
非线性系统的特点 非线性系统
本卷考法
  • 说明大范围稳定与小范围稳定的定义及差别（第2小问）
本卷实例
  • 关键一步：用初始偏差能否任意大来区分两种稳定
  • 中间结果：大范围稳定要求任意有界扰动都能恢复
  • 卡点：小范围稳定允许的初始偏差有范围限制
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过说明大范围稳定与小范围稳定的定义及差别（第2小问）
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定

梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求输出传函与误差传函
本卷实例
  • 关键一步：辨认前向通路、回路以及是否互不接触
  • 中间结果：两传函共用同一特征式，前向通路不同
  • 卡点：误差传函前向通路与输出传函不同，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求输出传函与误差传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

4根轨迹：复数部分为圆与阻尼判别20 分#

思路
  • 开环含两个极点两个零点，画根轨迹并证明复数部分是圆，由闭环极点性质判断三种阻尼对应的 k 范围与响应快慢
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制含两个开环零点与两个极点的根轨迹
本卷实例
  • 关键一步：标出实轴根轨迹段与分离点后判断两支走向
  • 中间结果：无渐近线，两支起于极点止于零点
  • 卡点：两个极点两个零点时渐近线条数为零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制含两个开环零点与两个极点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点并筛选在根轨迹上的解
本卷实例
  • 关键一步：令 dK/ds 为零解出候选分离点
  • 中间结果：两支在实轴上的相遇点即分离点
  • 卡点：解出不满足相角条件的根要舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点并筛选在根轨迹上的解
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由闭环极点在复平面的位置判断阻尼状态的 k 范围
本卷实例
  • 关键一步：把临界阻尼对应到两个相等的负实极点
  • 中间结果：两边界 k 之间为欠阻尼，之外为过阻尼
  • 卡点：过阻尼分小 k 与大 k 两段，勿只取一段
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由闭环极点在复平面的位置判断阻尼状态的 k 范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 用阻尼比说明三种响应形态与响应速度
本卷实例
  • 关键一步：由闭环特征根虚实判断阻尼比所处范围

  • 中间结果：交点对应等幅周期运动的条件
  • 卡点：稳定周期运动由稳定区边界判定，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过由线性部分与负倒特性交点划分稳定与不稳定区
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率
