1选择题：控制方式、线性叠加、保持器与离散模型20 分#

思路
  • 五道判断：开环控制是否具备修正能力、反馈系统稳态误差是否恒零、线性系统是否满足叠加与齐次、零阶保持器的使用、离散系统的数学模型
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断开环控制是否具有自动修正偏差和抗干扰能力（第1小题）
本卷实例
  • 关键一步：由输出是否参与控制作用判断有无修正能力
  • 中间结果：开环控制无反向联系，输出不影响控制作用
  • 卡点：开环控制对外扰不具备自我修正能力
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断开环控制是否具有自动修正偏差和抗干扰能力（第1小题）
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
系统型别与静态误差系数 稳态误差
本卷考法
  • 判断反馈控制系统稳态误差是否恒为零（第2小题）
本卷实例
  • 关键一步：由系统型别与输入形式判断稳态误差是否为零
  • 中间结果：一型系统跟踪斜坡仍有有限误差
  • 卡点：有差系统的稳态误差由型别与增益共同决定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断反馈控制系统稳态误差是否恒为零（第2小题）
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 判断线性系统是否满足叠加原理与齐次性（第3小题）
本卷实例
  • 关键一步：用多个输入同时作用的输出是否等于分别作用之和来判断
  • 中间结果：线性系统同时满足叠加性与齐次性
  • 卡点：叠加与齐次是两个条件，缺一不可
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过判断线性系统是否满足叠加原理与齐次性（第3小题）
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

采样过程与香农采样定理 离散控制系统
本卷考法
  • 判断零阶保持器在数字控制系统中的使用（第4小题）
  • 判断离散系统的数学模型是差分方程还是微分方程（第5小题）
本卷实例
  • 关键一步：由保持器的实现难度和离散系统的差分特性判断
  • 中间结果：数字控制普遍采用零阶保持器
  • 卡点：离散系统数学模型一般用差分方程而非微分方程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过判断零阶保持器在数字控制系统中的使用（第4小题）
  • 本卷考过判断离散系统的数学模型是差分方程还是微分方程（第5小题）
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

2简答：阻尼比对阶跃响应的影响与带宽20 分#

思路
  • 两小问：不同阻尼比下二阶系统阶跃响应的形态，以及阻尼比增大对超调量的影响；带宽频率与带宽的定义及其与响应速度的关系
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 说明不同阻尼比下二阶系统阶跃响应的形态（第1小问）
本卷实例
  • 关键一步：由阻尼比区间判断特征根是实根还是共轭复根
  • 中间结果：欠阻尼振荡收敛、过阻尼单调收敛
  • 卡点：零阻尼对应等幅振荡，不要与欠阻尼混同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过说明不同阻尼比下二阶系统阶跃响应的形态（第1小问）
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 说明欠阻尼下增大阻尼比对超调量的影响（第1小问）
本卷实例
  • 关键一步：由超调量随阻尼比单调下降来判断
  • 中间结果：阻尼比增大，超调量随之减小
  • 卡点：超调减小不等于响应速度同步变快
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过说明欠阻尼下增大阻尼比对超调量的影响（第1小问）
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
闭环频率特性与性能指标 频域分析
本卷考法
  • 写出带宽频率与带宽的定义并说明与响应速度的关系（第2小问）
本卷实例
  • 关键一步：从闭环幅频降到零频值约七成处定义带宽频率
  • 中间结果：带宽越大，上升时间越短、响应越快
  • 卡点：带宽大带来快速性的同时也更易通过高频噪声
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过写出带宽频率与带宽的定义并说明与响应速度的关系（第2小问）
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

思路

劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据分析内反馈对系统稳定性的影响
本卷实例
  • 关键一步：先写含内反馈的闭环特征方程再列劳斯表
  • 中间结果：内反馈改变了特征式的二次项系数

8饱和非线性：临界增益与自振判定#

思路
  • 饱和非线性描述函数含反三角函数，画负倒特性与线性部分幅相曲线；由临界相角条件求 K 临界值，再判定给定增益下是否存在稳定自振并列写求振幅的方程
描述函数法基础 非线性系统
本卷考法
  • 分析饱和非线性描述函数的负倒特性随振幅的变化
本卷实例
  • 关键一步：把负倒描述函数化为随振幅由负一趋向负无穷的形式
  • 中间结果：负倒特性起始于负实轴上负一点
  • 卡点：振幅趋大时负倒特性向负无穷延伸
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过分析饱和非线性描述函数的负倒特性随振幅的变化
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

本卷考法
  • 由负倒特性与线性部分幅相曲线是否相交判断自振
本卷实例
  • 关键一步：先求相角为负一百八十度处的频率与幅值
  • 中间结果：临界增益由交点处的幅值条件确定

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过由负倒特性与线性部分幅相曲线是否相交判断自振
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率
