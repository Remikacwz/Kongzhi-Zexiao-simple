1简答：PD控制与测速反馈的比较#

思路
  • 比较PD控制与测速反馈对阻尼和稳态误差的不同影响，并说明PD控制放大高频噪声的局限
PID 控制器与参数整定 系统校正
本卷考法
  • 比较PD控制与测速反馈对阻尼、超调与稳态误差的影响
本卷实例
  • 关键一步：从PD使阻尼增大、不影响常值稳态误差切入
  • 中间结果：PD允许选取较高开环增益以减小稳态误差
  • 卡点：PD对高频噪声敏感，输入端噪声大时不宜单用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过比较PD控制与测速反馈对阻尼、超调与稳态误差的影响
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式
反馈校正与复合控制 系统校正
本卷考法
  • 说明测速反馈如何增大阻尼并改善动态性能
本卷实例
  • 关键一步：把输出速度信号反馈到输入端与误差信号比较
  • 中间结果：测速反馈增大阻尼但会降低开环增益
  • 卡点：开环增益下降可能使稳态误差增大
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过说明测速反馈如何增大阻尼并改善动态性能
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

2带宽频率与带宽的定义及对响应的影响#

思路
  • 给出带宽频率和带宽的定义，分析正弦带宽大于带宽频率时输出的变化及带宽与响应速度的关系
闭环频率特性与性能指标 频域分析
本卷考法
  • 给出带宽与带宽频率定义并说明带宽对响应速度的影响
本卷实例
  • 关键一步：由闭环幅频降到零频值的零点七零七倍确定带宽频率
  • 中间结果：带宽越大响应越快、调节时间越短
  • 卡点：带宽频率是闭环指标，不是开环截止频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过给出带宽与带宽频率定义并说明带宽对响应速度的影响
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

3结构图：梅森求传函与前馈补偿设计#

思路
  • 多回路结构图：用梅森公式求 C/R 与 C/N，再设计 Gn(s) 使输出不受扰动影响
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求多回路结构图的 C/R 与 C/N
本卷实例
  • 关键一步：分别标出两条前向通路与全部独立回路
  • 中间结果：两传递函数分母相同、分子由各自通路决定
  • 卡点：同一回路可能只与前向通路之一接触
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求多回路结构图的 C/R 与 C/N
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 在扰动作用下单独求 C/N，再作叠加或补偿设计
本卷实例
  • 关键一步：求扰动通道传函时把参考输入置零
  • 中间结果：扰动经两条并联通路到达输出端
  • 卡点：两输入叠加前须确认系统为线性系统
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过在扰动作用下单独求 C/N，再作叠加或补偿设计
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

4二阶系统指标反求与方案比较#

思路
  • 先由稳态误差求增益范围，再由超调量与调节时间反求阻尼比与自然频率，最后比较两种改善方案
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由斜坡输入稳态误差要求反求开环增益范围
本卷实例
  • 关键一步：先判稳，再由静态速度误差系数写误差条件
  • 中间结果：一型系统稳态误差与速度误差系数成倒数关系
  • 卡点：未判稳就用终值定理会得到无效结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由斜坡输入稳态误差要求反求开环增益范围
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征式求阻尼比与自然频率
本卷实例
  • 关键一步：把闭环特征式整理成二阶标准形式
  • 中间结果：比较系数得到自然频率与阻尼比
  • 卡点：s 平方项系数要先归一化再比较
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征式求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率求超调量和调节时间
本卷实例
  • 关键一步：先由闭环特征式读出阻尼比与自然频率
  • 中间结果：再代入欠阻尼二阶系统指标公式
  • 卡点：调节时间系数要与题给误差带对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率求超调量和调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

5奈氏判据与非最小相位系统#

思路
  • 由开环传函求幅相表达式，绘制奈奎斯特曲线并用判据判稳，分析增益增大时曲线与性能的变化
频率特性的物理意义与求法 频域分析
本卷考法
  • 求给定传递函数的幅频、相频、实部与虚部表达式
本卷实例
  • 关键一步：把 s 换成 j 乘 omega 后按实部虚部整理
  • 中间结果：有理化后分母为实多项式、分子分实虚部
  • 卡点：分子含一阶微分环节，相角要单独累加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求给定传递函数的幅频、相频、实部与虚部表达式

步骤
  • 判断系统是否存在极限环并确定其稳定性
  • 分析非线性环节参数对自振幅值频率的影响
  • 通过调整线性部分增益或加入校正削弱自振
  • 重新分析确认自振消除或幅值达标
通用考法
  • 本卷考过设计串联环节使系统产生自振并分析参数影响
  • 提出消除自振的工程措施
  • 分析增益变化对极限环幅值的影响
  • 比较不同方案对稳定性与动态性能的利弊
常见易错
  • 仅调整增益而不检查是否引入新的自振点
  • 把不稳定极限环误判为可观测的自振
