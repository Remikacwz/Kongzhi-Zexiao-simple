1、2、3判断题：频率特性与稳定性基本概念#

思路
  • 三道判断题分别考频率特性三个频段的物理含义、稳定系统阶跃响应是否收敛到零、线性与非线性稳定性的差别
开环对数频率特性的绘制 频域分析
本卷考法
  • 判断「低频段表征动态性能、中频段表征稳态性能、高频段表征抗噪」的说法对错
本卷实例
  • 关键一步：正确对应是：低频段表征稳态性能（增益大小决定稳态误差）
  • 关键一步：中频段表征动态性能（穿越频率与相角裕度决定超调与快速性）
  • 关键一步：高频段表征抗高频干扰能力
  • 中间结果：题干的说法把低频段与中频段的含义对调了 → 判断为错
  • 卡点：不逐段核对就凭印象判对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过判断「低频段表征动态性能、中频段表征稳态性能、高频段表征抗噪」的说法对错
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 判断「稳定系统在单位阶跃输入下输出逐渐收敛至零」是否正确
本卷实例
  • 关键一步：阶跃输入的稳态输出是非零常值（等于直流增益），不是零
  • 关键一步：收敛到零只发生在脉冲输入或零输入响应
  • 中间结果：题干的说法错在把阶跃响应的稳态值当成 0
  • 卡点：把「指数项衰减到零」与「输出收敛到零」混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过判断「稳定系统在单位阶跃输入下输出逐渐收敛至零」是否正确
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

非线性系统的特点 非线性系统
本卷考法
  • 判断「线性系统稳定性与初值输入无关、非线性系统有关」是否正确
本卷实例
  • 关键一步：线性定常系统的稳定性由特征值决定，与初值和输入无关（这是正的）
  • 关键一步：非线性系统只有局部稳定性概念，确实与初值、输入幅值有关（也是正的）
  • 中间结果：整句判断为对
  • 卡点：只看到前半句对就直接判对，没有核后半句
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过判断「线性系统稳定性与初值输入无关、非线性系统有关」是否正确
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定

4、5判断题：校正与微分控制#

思路
  • 两道判断题分别考滞后校正的作用机理、微分控制的适用范围与噪声敏感性
滞后校正 系统校正
本卷考法
  • 判断「滞后校正利用高频幅值衰减使截止频率下降从而获得相角裕度」是否正确
本卷实例
  • 关键一步：滞后校正的核心机理：高频段幅值衰减使截止频率左移
  • 关键一步：在新的（更低的）截止频率处相角裕度变大
  • 关键一步：同时低频增益不受影响，稳态精度得以保留
  • 中间结果：整句判断为对
  • 卡点：把机理记成「利用相位超前」，那是超前校正
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过判断「滞后校正利用高频幅值衰减使截止频率下降从而获得相角裕度」是否正确
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
PID 控制器与参数整定 系统校正
本卷考法
  • 判断「微分控制只作用于动态过程、对稳态无影响、对噪声敏感、不宜单独串联」是否正确
本卷实例
  • 关键一步：微分项 s 在稳态（s→0）时贡献为零 → 确实只影响动态过程
  • 关键一步：微分对高频噪声放大明显 → 噪声敏感
  • 关键一步：单独微分会让高频增益趋于无穷、且对常值误差毫无改善 → 不能单独串联
  • 关键一步：四条都成立 → 判断为对
  • 中间结果：s→0 时微分项为零，故对稳态无影响；高频段幅值随 ω 上升放大噪声
  • 卡点：只记住「微分改善动态」，忽略噪声与不能单独使用这两条
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过判断「微分控制只作用于动态过程、对稳态无影响、对噪声敏感、不宜单独串联」是否正确
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

6、7简答：稳定裕度与采样系统优缺点#

思路
  • 两道简答：稳定裕度的含义与设计时如何考虑；采样/数字控制相比连续模拟控制的优缺点
稳定裕度 频域分析
本卷考法
  • 简述相角裕度和幅值裕度的含义，并说明设计系统时如何考虑
本卷实例
  • 关键一步：含义：γ 与 Kg 分别衡量系统在幅值穿越频率与相位穿越频率处距离临界稳定还有多少余量
  • 关键一步：设计时：一般取 γ 在 30°~60°、Kg 不小于 6~10 dB，兼顾快速性与平稳性
  • 关键一步：γ 过小 → 超调大、振荡强；γ 过大 → 响应慢；Kg 主要防止参数漂移导致失稳
  • 中间结果：γ 在幅值穿越频率处度量，Kg 在相位穿越频率处度量，两者频率不同
  • 卡点：只给定义不答「如何考虑」，简答题要两部分都答
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过简述相角裕度和幅值裕度的含义，并说明设计系统时如何考虑
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
采样过程与香农采样定理 离散控制系统
本卷考法
  • 说明采样控制系统与数字控制系统相比连续模拟控制系统的优缺点
本卷实例
  • 关键一步：优点：软件实现、参数修改灵活，易实现状态反馈等复杂算法
  • 关键一步：抗漂移无温漂，便于联网与数据记录，硬件通用成本低
  • 关键一步：缺点：存在采样与量化误差，响应滞后一个采样周期
  • 关键一步：高频段受采样定理限制，需抗混叠滤波，对对象高频特性敏感
  • 中间结果：数字控制本质是离散化：按采样时刻计算、一拍内保持，故有量化误差
  • 卡点：只谈优点不谈缺点；题目问的是「优缺点」
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过说明采样控制系统与数字控制系统相比连续模拟控制系统的优缺点
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

电路网络与有源网络建模 建模与机电系统

  • 求运算电路的输出表达式
