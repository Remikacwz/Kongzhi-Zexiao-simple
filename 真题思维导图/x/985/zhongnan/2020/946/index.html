1选择题：传函性质、无静差、微分积分作用、离散稳定性与描述函数20 分#

思路
  • 五道判断：传函只取决于结构与参数、无稳态误差的条件、微分与积分环节的适用频段与作用、采样周期与增益对离散稳定、描述函数的基波含义
传递函数的定义与基本性质 传递函数
本卷考法
  • 判断传递函数是否与输入信号的形式有关（第1小题）
本卷实例
  • 关键一步：回到传函的定义：零初始条件下只由系统参数决定
  • 中间结果：传函只反映系统结构与参数，与输入形式无关
  • 卡点：题干把“与输入形式有关”当正确表述，整句判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过判断传递函数是否与输入信号的形式有关（第1小题）
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
反馈校正与复合控制 系统校正
本卷考法
  • 判断要使任意输入与扰动下都无稳态误差需在反馈环节加什么（第2小题）
本卷实例
  • 关键一步：从前馈补偿的不变性原理判断能否消除全部稳态误差
  • 中间结果：前馈可抑制可测扰动，但难对任意扰动都做到零静差
  • 卡点：前馈装置只与系统环节有关，不能保证任意输入无误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过判断要使任意输入与扰动下都无稳态误差需在反馈环节加什么（第2小题）
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

PID 控制器与参数整定 系统校正
本卷考法
  • 判断微分环节与积分环节的适用频段及其对动静态性能的作用（第3小题）
本卷实例
  • 关键一步：把低频段与稳态性能、中频段与动态性能分别对应
  • 中间结果：微分改善动态性能、积分改善稳态性能，题述写反
  • 卡点：积分降低稳态误差，但可能加大超调并影响稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过判断微分环节与积分环节的适用频段及其对动静态性能的作用（第3小题）
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

离散系统稳定性分析 离散控制系统
本卷考法
  • 判断采样周期与开环增益变化对离散系统稳定性的影响（第4小题）
本卷实例
  • 关键一步：由极点须落在单位圆内判断增益与采样周期的影响方向
  • 中间结果：K 增大或 T 加长都会使离散系统稳定性变差
  • 卡点：离散稳定的判据是极点模小于1，不是实部小于零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过判断采样周期与开环增益变化对离散系统稳定性的影响（第4小题）
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

描述函数法基础 非线性系统
本卷考法
  • 判断描述函数反映基波分量、可等效为复数增益放大器（第5小题）
本卷实例
  • 关键一步：把描述函数理解为非线性环节对基波的等效复增益
  • 中间结果：忽略高次谐波后描述函数相当于一个复增益环节
  • 卡点：描述函数是基波近似，题句表述正确
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过判断描述函数反映基波分量、可等效为复数增益放大器（第5小题）
  • 求饱和、死区、继电特性等典型非线性的描述函数

  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

2简答：闭环主导极点与非线性模型线性化条件20 分#

思路
  • 两小问：闭环主导极点的定义与选择方法（第1问）；小偏差法将非线性模型线性化的条件与步骤（第2问）
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 说明闭环主导极点的定义及高阶系统降阶时如何选取主导极点
本卷实例
  • 关键一步：由距虚轴最近且附近无闭环零点的极点主导响应来定义
  • 中间结果：选留主导极点后略去远于主导极点六倍以上的零极点
  • 卡点：选留的主导零点数不宜超过主导极点数，否则估算失真
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过说明闭环主导极点的定义及高阶系统降阶时如何选取主导极点
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

3结构图：由阶跃响应反求Kv与T15 分#

思路
  • 由结构图(a)与单位阶跃响应(b)、稳态位置误差为零，反求开环增益 Kv 与时间常数 T
系统型别与静态误差系数 稳态误差
本卷考法
  • 由稳态位置误差为零判断系统型别并确定开环增益
本卷实例
  • 关键一步：ess=0 要求位置误差系数为无穷大，据此定积分环节个数
  • 中间结果：系统须含一个积分环节，开环增益由稳态输出值确定
  • 卡点：型别判错会使位置误差系数与题意互相矛盾
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由稳态位置误差为零判断系统型别并确定开环增益
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由阶跃响应终值与初值联立求 Kv 与 T（终值定理与初值定理）
本卷实例
  • 关键一步：对输出与输出导数分别取终值定理和初值定理
  • 中间结果：终值给出开环增益，初始斜率给出时间常数
  • 卡点：用终值定理前须先确认闭环系统稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由阶跃响应终值与初值联立求 Kv 与 T（终值定理与初值定理）
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

  • 由实验阶跃响应曲线求传递函数

4二阶系统：指标计算与PD控制的性能改善15 分#

思路
  • G(s)=k/[s(s+a)]：(1)求阻尼比、超调量、自然频率与各项时域指标；(2)引入比例微分控制后求自然频率与斜坡稳态误差；(3)分析比例微分控制的性能改善
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函化为标准二阶形式求 ωn 与阻尼比（第(1)问）
本卷实例
  • 关键一步：先由单位负反馈写出闭环特征式，再与 s²+2ξωn s+ωn² 对照
  • 中间结果：2ξωn=a、ωn²=k，稳定要求 a>0 且 k>0
  • 卡点：未把 s² 项系数归一化就直接读参数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函化为标准二阶形式求 ωn 与阻尼比（第(1)问）
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由 ξ、ωn 计算超调量、调节时间、上升时间与峰值时间（第(1)问）
本卷实例
  • 关键一步：各指标统一用 ξ 与 ωn 的解析式表示
  • 中间结果：tr 与 tp 都含 ωn 与根号下(1-ξ²)，σ% 只与 ξ 有关
