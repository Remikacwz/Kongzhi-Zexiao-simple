1选择题：基本概念、根轨迹、保持器与校正#

思路
  • 五道判断：控制系统基本要求、根轨迹能给出什么信息、一阶保持器特性、频率特性与描述函数、超前与滞后校正的效果
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断对控制系统稳、准、快与相对稳定性等基本要求的表述
本卷实例
  • 关键一步：逐句对照稳定性、快速性与稳态误差的基本要求
  • 中间结果：题干把稳、快、准并列为实用系统必须具备的要求
  • 卡点：第1句表述正确，不要因出现绝对稳定性就误判
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断对控制系统稳、准、快与相对稳定性等基本要求的表述
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 判断根轨迹能否直接给出闭环时间响应的全部信息
本卷实例
  • 关键一步：由根轨迹只给出闭环极点位置来推断响应模态
  • 中间结果：根轨迹只定极点，不能直接给出全部时间响应
  • 卡点：题说可直接给出全部信息，属以偏概全
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过判断根轨迹能否直接给出闭环时间响应的全部信息
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

采样过程与香农采样定理 离散控制系统
本卷考法
  • 判断一阶保持器与零阶保持器的复现精度与纹波特性
本卷实例
  • 关键一步：比较零阶与一阶保持器的频率特性和相位滞后
  • 中间结果：一阶保持器精度较高但高频分量与纹波更大
  • 卡点：一阶保持器并不能减小纹波，题述方向相反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过判断一阶保持器与零阶保持器的复现精度与纹波特性
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

频率特性的物理意义与求法 频域分析
本卷考法
  • 说明线性系统频率特性所反映的物理含义
本卷实例
  • 关键一步：从正弦稳态输出与输入的幅值相位比来理解频率特性
  • 中间结果：频率特性描述同频稳态分量的幅值相位变化
  • 卡点：题干限定在稳态输出，注意非线性部分另作描述
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过说明线性系统频率特性所反映的物理含义
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
描述函数法基础 非线性系统
本卷考法
  • 说明描述函数所反映的基波分量含义
本卷实例
  • 关键一步：把描述函数理解为非线性系统正弦响应的基波描述
  • 中间结果：描述函数反映基波幅值相位相对输入的变化
  • 卡点：描述函数是基波近似，不能与线性频率特性等同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过说明描述函数所反映的基波分量含义
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件
公式
超前校正 系统校正
本卷考法
  • 判断串联超前校正对截止频率、带宽与响应速度的影响
本卷实例
  • 关键一步：由超前校正提升截止频率来推断带宽与响应变化
  • 中间结果：超前校正使截止频率与带宽增大、响应加快
  • 卡点：该分句正确，但要与下一句滞后校正区分开
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过判断串联超前校正对截止频率、带宽与响应速度的影响
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
滞后校正 系统校正
本卷考法
  • 判断串联滞后校正对稳态精度与动态性能的影响
本卷实例
  • 关键一步：由滞后校正降低截止频率分析其动态影响
  • 中间结果：滞后校正提高稳态精度但会改变动态性能
  • 卡点：滞后校正并非不改变动态性能，整句为错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过判断串联滞后校正对稳态精度与动态性能的影响
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

2简答：闭环主导极点与附加开环零点#

思路
  • 两小问：闭环主导极点的定义与使高阶系统只保留一对主导极点的方法；附加开环负实数零点对系统性能的影响
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 叙述闭环主导极点的定义及使高阶系统只保留一对主导极点的方法
本卷实例
  • 关键一步：按距虚轴最近、周边无闭环零点且远离其他极点来定主导极点
  • 中间结果：可用偶极子对消或使非主导极点远离虚轴
  • 卡点：定义三项条件缺一不可，不能只看离虚轴最近
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过叙述闭环主导极点的定义及使高阶系统只保留一对主导极点的方法
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 说明系统附加开环负实数零点后性能如何变化
本卷实例
  • 关键一步：由附加零点使根轨迹向负实轴弯曲判断性能变化
  • 中间结果：根轨迹左弯使闭环极点左移、快速性改善
  • 卡点：零点靠近原点时影响更大，要按位置分情况
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过说明系统附加开环负实数零点后性能如何变化
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反

3结构图：梅森求传函与前馈补偿#

思路
  • 随动系统结构图：先求 C/R 与 C/N，再设计前馈 Gn(s) 实现扰动不变性，最后判断控制方式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求多回路结构图的传递函数
本卷实例
  • 关键一步：标出各前向通路、独立回路以及不接触回路组合
  • 中间结果：特征式由各回路增益与不接触回路乘积组成
  • 卡点：两条回路有公共节点时不能计入不接触组
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求多回路结构图的传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 在参考输入与扰动同时作用下分别求 C/R 和 C/N
本卷实例
  • 关键一步：求扰动通道的 C/N 时把参考输入置零
  • 中间结果：扰动通道前向通路含补偿器与对象两段
  • 卡点：两输入叠加前须确认系统为线性系统
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过在参考输入与扰动同时作用下分别求 C/R 和 C/N
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
反馈校正与复合控制 系统校正
本卷考法
  • 设计前馈补偿器使输出不受扰动影响并说明控制方式
本卷实例
  • 关键一步：令扰动通道 C/N 的分子为零反解前馈补偿器
  • 中间结果：所求补偿器含微分环节，属前馈复合控制
  • 卡点：理想微分难实现，还要检查物理可实现性
  • 卡点：系统结构以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤

本卷考法

  • 描述函数是输入幅值的函数，与频率无关

用描述函数法分析自振 非线性系统
本卷考法
  • 由负倒描述函数与线性部分曲线的交点判断自振并求频率
本卷实例
  • 关键一步：在复平面画出负倒描述函数曲线与线性部分幅相曲线
  • 中间结果：两曲线交点对应自振频率与振幅
  • 卡点：交点处要按振幅增大方向判断自振是否稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过由负倒描述函数与线性部分曲线的交点判断自振并求频率
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率
