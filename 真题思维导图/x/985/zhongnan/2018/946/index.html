1选择题：恒定值/随动、型别、反馈误差、主导极点、离散极点20 分#

思路
  • 五道判断：恒定值与随动系统的重点、系统型别与稳态误差、反馈系统稳态误差、主导极点降阶、离散闭环极点分布
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断恒定值系统与随动系统的分析设计重点（第1小题）
本卷实例
  • 关键一步：从两类系统的被控量与输入特点区分侧重
  • 中间结果：恒定值侧重抗扰动，随动侧重跟随
  • 卡点：两者目标不同，不能混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断恒定值系统与随动系统的分析设计重点（第1小题）
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
系统型别与静态误差系数 稳态误差
本卷考法
  • 判断提高系统型别与稳态误差、控制精度的关系（第2小题）
本卷实例
  • 关键一步：由型别定义联系静态误差系数
  • 中间结果：提高型别一般提高精度、减小稳态误差
  • 卡点：题干把二者的关系说反了
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断提高系统型别与稳态误差、控制精度的关系（第2小题）
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 判断反馈系统的稳态误差是否恒为零（第3小题）
本卷实例
  • 关键一步：稳态误差由系统型别与输入形式共同决定
  • 中间结果：0型系统在阶跃输入下误差不为零
  • 卡点：反馈只能减小而不能消除所有稳态误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过判断反馈系统的稳态误差是否恒为零（第3小题）
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 判断用主导极点法把高阶系统降阶的条件与可行性（第4小题）
本卷实例
  • 关键一步：看是否存在远离虚轴、权重大的主导极点
  • 中间结果：多数高阶系统可近似为一、两个极点
  • 卡点：近虚轴的零点会破坏降阶近似
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过判断用主导极点法把高阶系统降阶的条件与可行性（第4小题）
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

离散系统稳定性分析 离散控制系统
本卷考法
  • 判断离散系统闭环极点在z平面的分布（第5小题）
本卷实例
  • 关键一步：稳定条件是全部闭环极点位于单位圆内
  • 中间结果：右半单位圆内并非稳定的充要条件
  • 卡点：勿把连续系统右半平面条件套到z平面
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过判断离散系统闭环极点在z平面的分布（第5小题）
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

2简答题：改善二阶性能的方法与描述函数法条件20 分#

思路
  • 两小问：比较比例-微分控制与测速反馈改善二阶系统性能的机理与差异；列出描述函数法的应用条件
PID 控制器与参数整定 系统校正
本卷考法
  • 比较比例-微分控制与测速反馈改善二阶性能的机理（第1小问）
本卷实例
  • 关键一步：从附加闭环零点与改变开环增益两条路比较
  • 中间结果：PD引入闭环零点，测速反馈只改增益
  • 卡点：两者对稳态误差的影响相反，易混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过比较比例-微分控制与测速反馈改善二阶性能的机理（第1小问）
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 用阻尼比说明两种方法对超调与振荡的抑制（第1小问）
本卷实例
  • 关键一步：两种方法都等效增大系统的阻尼比
  • 中间结果：测速反馈不引入闭环零点
  • 卡点：PD的微分作用对噪声敏感
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过用阻尼比说明两种方法对超调与振荡的抑制（第1小问）
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

描述函数法基础 非线性系统
本卷考法
  • 列举描述函数法的适用条件（第2小问）
本卷实例
  • 关键一步：从单非线性环节、奇对称、低通三条件回答
  • 中间结果：线性部分需具较好低通滤波特性
  • 卡点：多个非线性环节要先化简合并
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过列举描述函数法的适用条件（第2小问）
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

3结构图：由超调与峰值时间反求参数并算动态指标15 分#

思路
  • 由结构图求闭环传函，用超调量、峰值时间与稳态输出反求K1、K2与a，再算上升时间与调节时间
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图用梅森公式求闭环传函（第(1)问）
本卷实例
  • 关键一步：辨认前向通路与反馈回路再套梅森公式
  • 中间结果：闭环传函为含K1K2与a的二阶形式
  • 卡点：结构连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图用梅森公式求闭环传函（第(1)问）
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量、峰值时间与稳态输出反求参数（第(1)问）
本卷实例
  • 关键一步：由超调量定阻尼比、峰值时间定自然频率
  • 中间结果：稳态输出锁定增益K1
  • 卡点：三个条件须联立求解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量、峰值时间与稳态输出反求参数（第(1)问）
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 计算上升时间与调节时间（第(2)问）
本卷实例
  • 关键一步：套欠阻尼二阶系统的指标公式
  • 中间结果：上升时间由阻尼角与阻尼振荡角频率决定
  • 卡点：调节时间按±5%误差带取3/(ξωn)
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过计算上升时间与调节时间（第(2)问）
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

4稳态误差：劳斯判据定K范围与调节时间定主导极点15 分#

思路
  • 由稳态误差要求联合劳斯判据求K范围，再由调节时间确定一对闭环主导极点
劳斯判据 稳定性分析
本卷考法
  • 用劳斯表求使系统稳定的K范围（第(1)问）
本卷实例
  • 关键一步：写特征方程并按劳斯表逐行展开
  • 中间结果：稳定条件为0<K<3
  • 卡点：必要条件与充分条件都要满足
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯表求使系统稳定的K范围（第(1)问）
  • 判断给定系统的稳定性
