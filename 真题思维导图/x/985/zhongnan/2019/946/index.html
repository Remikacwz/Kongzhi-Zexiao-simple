1选择题：反馈方式、带宽衰减、恒值随动、微分噪声与描述函数20 分#

思路
  • 五道判断：反馈控制的正负反馈、带宽频率与输出衰减、恒值/随动系统设计重点、微分器对噪声的放大、描述函数法的适用与局限
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断反馈控制是采用正反馈还是负反馈（第1小题）
  • 指出恒值系统与随动系统各自的分析设计重点（第3小题）
本卷实例
  • 关键一步：由“利用偏差进行控制”反推反馈极性
  • 关键一步：比较恒值与随动系统对扰动与跟随的侧重
  • 中间结果：反馈控制以负反馈构成闭环，靠偏差纠正偏离
  • 中间结果：恒值系统重抗扰，随动系统重跟随的快与准
  • 卡点：第1小题把负反馈写成正反馈，整句判为错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断反馈控制是采用正反馈还是负反馈（第1小题）
  • 本卷考过指出恒值系统与随动系统各自的分析设计重点（第3小题）
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
闭环频率特性与性能指标 频域分析
本卷考法
  • 由带宽频率的定义判断输入频率高低与输出衰减的关系（第2小题）
本卷实例
  • 关键一步：用闭环幅频下降到低频值以下3dB处的频率定义带宽
  • 中间结果：高于带宽频率时输出才明显衰减，题述把高低频写反
  • 卡点：带宽是闭环幅频指标，勿与开环截止频率混同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过由带宽频率的定义判断输入频率高低与输出衰减的关系（第2小题）
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

PID 控制器与参数整定 系统校正
本卷考法
  • 判断输入端存在较强高频噪声时是否宜用比例-微分控制（第4小题）
本卷实例
  • 关键一步：由微分作用放大高频分量来判断噪声影响
  • 中间结果：微分项对高频噪声的放大更显著，强噪声下不宜采用
  • 卡点：该句方向正确，与微分改善动态性能并不矛盾
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过判断输入端存在较强高频噪声时是否宜用比例-微分控制（第4小题）
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

描述函数法基础 非线性系统
本卷考法
  • 判断描述函数法能否给出系统时间响应的确切信息（第5小题）
本卷实例
  • 关键一步：由描述函数只取基波近似推断它能给出什么结论
  • 中间结果：描述函数法可估自振频率与幅值，难给时间响应确切信息
  • 卡点：题干称能给出确切信息，与基波近似的性质相矛盾
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过判断描述函数法能否给出系统时间响应的确切信息（第5小题）
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

2简答：零阶保持器的选用与采样数字控制系统的优点20 分#

思路
  • 两小问：数字控制系统为何普遍采用零阶保持器（第1问）；相比连续模拟控制系统，采样与数字控制系统有哪些优点（第2问）
采样过程与香农采样定理 离散控制系统
本卷考法
  • 说明数字控制系统中普遍采用零阶保持器而不采用一阶/高阶保持器的原因
本卷实例
  • 关键一步：比较各阶保持器的复现精度、高频分量与相角滞后
  • 中间结果：一阶与高阶保持器精度高，但高频分量与纹波大、相角滞后大
  • 卡点：相角滞后越大对稳定性越不利，故宁用零阶保持器
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过说明数字控制系统中普遍采用零阶保持器而不采用一阶/高阶保持器的原因
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

3结构图：等效变换或梅森公式求闭环传函10 分#

思路
  • 由三回路结构图，用结构图等效变换或梅森增益公式求闭环传递函数 C(s)/R(s)
梅森增益公式与信号流图 传递函数
本卷考法
  • 由多回路结构图用梅森增益公式求闭环传递函数 C(s)/R(s)
本卷实例
  • 关键一步：先找出全部单独回路与前向通路，再写特征式与各余子式
  • 中间结果：三条单独回路中有两条互不接触，特征式含其乘积项
  • 卡点：两前向通路的余子式不同，第2条要剔除与它接触的回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由多回路结构图用梅森增益公式求闭环传递函数 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 用逐层化简多回路结构图的方法求闭环传递函数
本卷实例
  • 关键一步：从最内环开始等效，再逐层向外合并
  • 中间结果：内环化为等效环节后，外侧回路按串并联继续化简
  • 卡点：化简内环时勿把外环的信号当成常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤

  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过用逐层化简多回路结构图的方法求闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错

4结构图：测速反馈与PI控制的参数反求与振荡条件20 分#

思路
  • (a)测速反馈：由阻尼比与斜坡稳态误差反求 K、T 并算调节时间与超调量；(b)PI控制：由持续振荡频率反求 K、T 并给无持续振荡条件
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由含测速反馈与PI控制的闭环传函化为典型二阶形式求 ωn 与 ξ
本卷实例
  • 关键一步：分别写出两种结构图的开环与闭环传函，与标准二阶式系数对照
  • 中间结果：测速反馈使 2ξωn=2+T、ωn²=k；PI结构分母含可约的 s² 项
  • 卡点：PI控制下分子含 s 的一次项，化简时勿丢项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由含测速反馈与PI控制的闭环传函化为典型二阶形式求 ωn 与 ξ
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由阻尼比与单位斜坡稳态误差两个条件反求系统参数 K 与 T（第(1)问）
本卷实例
  • 关键一步：把 ess=1/Kv 化为参数方程，与 ξ 的表达式联立求解
  • 中间结果：两式均为 K、T 的有理式，联立后化为可解的方程组
  • 卡点：未先判稳就套稳态误差公式容易得错解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由阻尼比与单位斜坡稳态误差两个条件反求系统参数 K 与 T（第(1)问）
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由求得的 ξ、ωn 计算调节时间与超调量（第(1)问）
本卷实例
  • 关键一步：调节时间按 ts=3/(ξωn)（5%误差带）估算
  • 中间结果：σ%=exp(-πξ/根号下(1-ξ²))×100%
  • 卡点：误差带取 5% 还是 2% 直接改变调节时间系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
