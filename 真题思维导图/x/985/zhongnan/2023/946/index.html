1选择题：基本概念、主导极点、微分控制与校正20 分#

思路
  • 五道判断：定值与随动系统侧重点、主导极点近似、微分控制作用、增益与稳态误差、描述函数法的能力
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断定值控制系统与随动系统分析设计的侧重点
本卷实例
  • 关键一步：分别指出两类系统的主要矛盾与设计目标
  • 中间结果：定值系统重抗扰、随动系统重跟踪的快速性与准确性
  • 卡点：两类系统的侧重点不同，该句表述正确
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断定值控制系统与随动系统分析设计的侧重点
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 判断高阶系统是否都必须调成共轭主导极点
本卷实例
  • 关键一步：由主导极点近似成立的条件判断该说法是否普适
  • 中间结果：有主导极点时可用二阶指标估算，但并非必须
  • 卡点：高阶系统不应一律设计成一对主导极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过判断高阶系统是否都必须调成共轭主导极点
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

PID 控制器与参数整定 系统校正
本卷考法
  • 判断微分控制对动态与稳态过程的作用及噪声敏感性
本卷实例
  • 关键一步：分别分析微分项对动态响应和稳态误差的作用
  • 中间结果：微分只改善动态过程，对稳态过程没有影响
  • 卡点：微分放大高频噪声，整句前半段为错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过判断微分控制对动态与稳态过程的作用及噪声敏感性
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

减小稳态误差的措施 稳态误差
本卷考法
  • 分析减少开环增益对稳态误差与相对稳定性的影响
本卷实例
  • 关键一步：由开环增益与稳态误差、稳定裕度的关系判断
  • 中间结果：减小开环增益通常使稳态误差增大
  • 卡点：题述减小增益可减小误差，方向恰好相反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过分析减少开环增益对稳态误差与相对稳定性的影响
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

本卷实例

  • 中间结果：描述函数法不受阶次限制，但不能给确切时间响应
  • 卡点：该句后半段说可给时间响应，为错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤

常见易错

  • 忽略一次谐波近似带来的误差条件

2简答：采样定理与二阶系统阶跃响应20 分#

思路
  • 两小问：香农采样定理及采样周期选择对稳定性的影响；不同阻尼比下二阶系统极点与阶跃响应形态
采样过程与香农采样定理 离散控制系统
本卷考法
  • 叙述香农采样定理并说明采样周期选择的影响因素
本卷实例
  • 关键一步：由信号最高频率给出采样角频率的下界
  • 中间结果：采样周期还应考虑对象时间常数与实现成本
  • 卡点：采样定理是采样角频率不小于最高频率的两倍
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过叙述香农采样定理并说明采样周期选择的影响因素
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

离散系统稳定性分析 离散控制系统

  • 中间结果：采样周期增大时系统稳定性变差
  • 卡点：同一系统采样周期不同，稳定域也不同

常见易错

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 按阻尼比取值讨论二阶系统闭环极点的位置
本卷实例
  • 关键一步：分别写出零阻尼、欠阻尼与过阻尼时极点的形式
  • 中间结果：零阻尼为纯虚根，欠阻尼为共轭复根，过阻尼为两实根
  • 卡点：临界阻尼也属两个相等的负实根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过按阻尼比取值讨论二阶系统闭环极点的位置
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 说明阻尼比增大时阶跃响应超调量的变化趋势
本卷实例
  • 关键一步：由超调量随阻尼比增大而减小的规律作答
  • 中间结果：欠阻尼下增大阻尼比，超调量减小
  • 卡点：该结论只对欠阻尼范围成立，不能推广
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过说明阻尼比增大时阶跃响应超调量的变化趋势
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3结构图：信号流图与梅森公式15 分#

思路
  • 由结构图画信号流图，用梅森公式求 C/R 与 C/N，再由输出不受扰动影响的条件反求补偿环节
梅森增益公式与信号流图 传递函数
本卷考法
  • 画信号流图并用梅森公式求多回路系统传递函数
本卷实例
  • 关键一步：先由结构图画出信号流图再数前向通路与回路
  • 中间结果：特征式由各回路增益与两两不接触项组成
  • 卡点：信号流图节点顺序要与结构图一一对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过画信号流图并用梅森公式求多回路系统传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求参考输入与扰动作用下的传递函数 C/R 与 C/N
本卷实例

  • 中间结果：两传递函数分母相同、分子由各自通路决定
  • 卡点：扰动通路可能含两条并联前向通路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 求扰动的传递函数时令参考输入为零

  • 令 N(s)=0，求输入到输出的传递函数

通用考法

  • 求扰动传函时没有把参考输入置零

反馈校正与复合控制 系统校正
本卷考法
  • 由输出不受扰动影响的条件反求补偿环节
本卷实例
  • 关键一步：令扰动通道传递函数的分子恒为零
  • 中间结果：所得条件即前馈补偿器应满足的关系
  • 卡点：系统结构以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件

8描述函数法分析非线性自振#

思路
  • 由非线性环节描述函数判断 K=1 时是否自振并求振幅频率，再由不自振条件确定增益范围
描述函数法基础 非线性系统
本卷考法
  • 写出给定非线性环节的描述函数并判断其单调性
本卷实例
  • 关键一步：按基波分量积分求出描述函数表达式
  • 中间结果：负倒描述函数随振幅增大而单调变化
  • 卡点：非线性结构以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过写出给定非线性环节的描述函数并判断其单调性
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

用描述函数法分析自振 非线性系统
本卷考法
  • 由负倒描述函数与线性部分曲线判断是否自振
本卷实例
  • 关键一步：在同一复平面画两条曲线并求交点
  • 中间结果：有交点则存在自振，交点对应频率与振幅
  • 卡点：要按振幅增大方向判断自振是否稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过由负倒描述函数与线性部分曲线判断是否自振
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率

非线性系统的稳定性与改善 非线性系统
本卷考法
  • 由系统不自振的条件确定增益的取值范围
本卷实例
  • 关键一步：调整增益使线性部分曲线与负倒曲线无交点
  • 中间结果：增益小于使两曲线相切时的临界值即不自振
  • 卡点：临界值处为不稳定极限环，边界要按开区间取
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 非线性系统只有局部稳定性概念，与初始条件有关
  • 极限环的稳定性可由相轨迹收敛或发散判断
  • 减小非线性影响可用加大线性部分增益或引入校正
  • 用描述函数或相平面结果指导参数选择
步骤
  • 判断系统是否存在极限环并确定其稳定性
  • 分析非线性环节参数对自振幅值频率的影响
  • 通过调整线性部分增益或加入校正削弱自振
  • 重新分析确认自振消除或幅值达标
通用考法
  • 本卷考过由系统不自振的条件确定增益的取值范围
  • 提出消除自振的工程措施
  • 分析增益变化对极限环幅值的影响
  • 比较不同方案对稳定性与动态性能的利弊
常见易错
  • 仅调整增益而不检查是否引入新的自振点
  • 把不稳定极限环误判为可观测的自振
