1一、卡车单轮悬架系统建模#

思路
  • 对车轮与车身分别受力分析列机械系统运动方程，拉氏变换后消去中间变量，求 Y1(s)/X(s) 与 Y2(s)/X(s) 两个传递函数
机械系统建模 建模与机电系统
本卷考法
  • 对弹簧-质量-阻尼悬架系统列运动方程并求 Y1(s)/X(s) 与 Y2(s)/X(s)
本卷实例
  • 关键一步：分别对车身质量与车轮质量列牛顿第二定律，弹簧力按相对位移写
  • 关键一步：阻尼力按相对速度写，且同时作用在两个质块上、方向相反
  • 关键一步：拉氏变换后得到两个代数方程再消去中间变量
  • 中间结果：两个方程含车身质量、车轮质量、两个刚度、一个阻尼与三个位移
  • 中间结果：两式相除可先得到两个输出的比值再回代
  • 卡点：多质量系统漏掉相互作用力的反作用项
  • 卡点：把阻尼力当成只与单一变量有关
  • 卡点：悬架结构以图 1 给出，具体连接关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过对弹簧-质量-阻尼悬架系统列运动方程并求 Y1(s)/X(s) 与 Y2(s)/X(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项

2二、三种方法分析稳定性与 Z-N 整定#

思路
  • 三阶惯性环节串联单位反馈：先用劳斯、根轨迹、奈奎斯特三种方法判稳并求稳定域，再用 P、PI、PID 与闭环 Z-N 临界比例度法整定参数
劳斯判据 稳定性分析
本卷考法
  • 用三种不同方法分析三阶系统的闭环稳定性并求稳定范围
本卷实例
  • 关键一步：劳斯法：展开三阶特征方程，令首列全为正列稳定域
  • 关键一步：根轨迹法：三个极点都在左半平面，由与虚轴交点定临界增益
  • 关键一步：奈奎斯特法：令虚部为零求穿越频率，再令实部等于负一求临界增益
  • 中间结果：特征方程为三次多项式，一次项系数与常数项含增益 k
  • 中间结果：三种方法应给出同一个临界增益
  • 卡点：只把各项系数为正当充要条件
  • 卡点：根轨迹法没有求虚轴交点就下结论
  • 卡点：奈奎斯特法不数右半平面极点数就直接判
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用三种不同方法分析三阶系统的闭环稳定性并求稳定范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
PID 控制器与参数整定 系统校正
本卷考法
  • 用闭环齐格勒-尼科尔斯法分别整定 P、PI、PID 参数
本卷实例
  • 关键一步：先由劳斯或奈奎斯特法求临界比例增益与临界振荡周期
  • 关键一步：振荡周期由临界角频率按 2π 换算，不能直接用角频率
  • 关键一步：再按 P、PI、PID 三组不同系数公式算各控制器参数
  • 中间结果：临界角频率处特征方程有一对纯虚根
  • 中间结果：三种控制器都以同一临界增益和临界周期为基准
  • 卡点：把临界周期与临界角频率直接用反了
  • 卡点：把公式里的积分时间当积分增益直接填
  • 卡点：把 Z-N 开环反应曲线法公式套到闭环临界比例度法上
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过用闭环齐格勒-尼科尔斯法分别整定 P、PI、PID 参数
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

3三、Bode 图法设计 P、I、PI 控制器#

思路
  • 被控对象为两个一阶环节之积：指标要求相角裕度不低于 60 度、阶跃稳态误差不超过百分之五、带宽尽量大；分别设计 P、I、PI 三类控制器并比较闭环零点配置
稳定裕度 频域分析
本卷考法
  • 用 Bode 图法设计比例控制器并分析能否同时满足相角裕度与稳态误差指标
本卷实例
  • 关键一步：由稳态误差要求先反求开环增益下限
  • 关键一步：再由相角裕度要求幅值为 1 处的相角条件反求增益上限
  • 关键一步：两个方向对增益的要求若矛盾，指标就无法同时满足
  • 中间结果：零型系统阶跃误差由 1 除以 1 加位置误差系数给出
  • 中间结果：相角裕度条件先定截止频率，再由幅值条件给出对应增益
  • 卡点：只看幅值条件不看相角条件
  • 卡点：把增益上下限求反，未分辨哪个是矛盾点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过用 Bode 图法设计比例控制器并分析能否同时满足相角裕度与稳态误差指标
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
稳定裕度 频域分析
本卷考法
  • 设计积分控制器并计算校正后的过零频率
本卷实例

本卷考法

本卷实例

  • 卡点：比较两种零点位置时忘记回答需要折衷的指标

4四、串联系统的状态空间、状态响应与能控能观#

思路
  • 两个子系统按 u2 等于 y1 串联成三阶系统：先列状态空间表达式，再求单位阶跃下的状态与输出响应，最后判能控能观并求不可控不可观子系统的特征值
状态空间表达式的建立 状态空间分析
本卷考法
  • 由两个子系统的串联关系列写三阶系统的状态空间表达式
本卷实例
  • 关键一步：把串联条件 u2 等于 y1 代入子系统方程，消去中间变量
  • 关键一步：整理成状态导数等于 A 乘状态加 B 乘输入的标准形式
  • 关键一步：状态按三个状态变量排列，输出取第二个子系统的输出
  • 中间结果：A 为三阶方阵，第三行出现由前一个子系统输出引入的耦合项
  • 中间结果：B 只有第二行非零，C 只对第三个状态取值
  • 卡点：状态变量个数与系统阶数不匹配
  • 卡点：输出方程漏掉直接传递项或把输出状态取错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由两个子系统的串联关系列写三阶系统的状态空间表达式
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式
状态转移矩阵 状态空间分析
本卷考法
  • 求给定初态下单位阶跃输入的状态响应与输出响应
本卷实例
  • 关键一步：先求状态转移矩阵，注意特征值有重根时要用含 t 的形式
  • 关键一步：状态响应等于零输入项加零状态卷积项
  • 关键一步：最后按输出方程取出所需的那一个分量
  • 中间结果：状态矩阵的特征值含一个二重根，转移矩阵中出现含 t 的项
  • 中间结果：零输入项由转移矩阵乘初态得到，零状态项对输入矩阵做卷积
  • 卡点：特征值有重根时仍套互异公式，丢掉含 t 的项
  • 卡点：卷积积分变量代换写错
  • 卡点：把初态代入后忘记再乘转移矩阵
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过求给定初态下单位阶跃输入的状态响应与输出响应
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错
公式
能控性与能观性 状态空间分析
本卷考法
  • 分析三个系统的能控性与能观性并求不可控不可观子系统的特征值
本卷实例
  • 关键一步：分别构造能控性矩阵与能观性矩阵，看秩是否等于维数
  • 关键一步：用 PBH 判据逐特征值检查，找出不能控或不能观的那一个
  • 关键一步：按秩亏对应的特征值写出不可控、不可观子系统的特征值
  • 中间结果：能控性矩阵由 B、AB、A 的平方乘 B 组成
  • 中间结果：能观性矩阵由 C、CA、CA 的平方组成
  • 中间结果：某个特征值处矩阵降秩，即为不可控不可观的模态
  • 卡点：只算到 A 的 n 减 2 次幂就下结论
  • 卡点：把能控性矩阵与能观性矩阵的构造顺序搞混
  • 卡点：求出的特征值没有回到子系统维数上核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
