一一、含扰动多回路系统误差表达式#

思路
  • 对给定与扰动分别置零，用梅森公式求两个误差分量后叠加成总误差表达式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求多回路系统的特征式
本卷实例
  • 关键一步：先找全部独立回路
  • 关键一步：再找两两不接触的回路组合
  • 中间结果：特征式由回路增益与不接触乘积构成
  • 卡点：结构图以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求多回路系统的特征式
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路漏找或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

二二、由稳态误差定参数与二阶动态指标#

思路
  • 由单位速度信号下的稳态误差关系确定特征方程参数，再把无零点二阶系统化标准式求超调量与调节时间
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位速度输入下的稳态误差反求参数
本卷实例
  • 关键一步：按系统型别写出速度误差系数的表达式
  • 关键一步：再由给定稳态误差值反求参数
  • 中间结果：一型系统速度误差系数等于开环增益
  • 卡点：误差值与题给输出关系要先对应好
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位速度输入下的稳态误差反求参数
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过未判断闭环稳定就用终值定理
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

三三、参数根轨迹、过阻尼范围与闭环传函#

思路
  • 把特征方程整理成以参数 a 为变量的根轨迹，用韦达定理证部分轨迹为圆，再由过阻尼与最大阻尼振动频率定参数
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以参数 a 为变量画闭环根轨迹
本卷实例
  • 关键一步：把特征方程写成 1 加 a 乘等效开环为零
  • 关键一步：再按等效开环的极零点画轨迹
  • 中间结果：等效开环只有一个零点一对极点
  • 卡点：分离点需求解对参数求导为零的方程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法

  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 本卷考过整理时没有把参数完整提到分子位置
  • 整理时没有把参数完整地提到分子位置

四四、奈氏判据、参数稳定性与校正设计#

思路

奈奎斯特判据 稳定性分析
本卷考法
  • 由含双积分环节的开环幅相曲线判稳
本卷实例
  • 关键一步：起点相位由两个积分环节决定
  • 关键一步：补画无穷小半圆并判绕行方向
  • 中间结果：曲线在无穷远处的相角为负 270 度
  • 卡点：包围圈数按负实轴穿越次数计
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由含双积分环节的开环幅相曲线判稳
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过补画无穷小圆弧时绕行方向或角度写错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
