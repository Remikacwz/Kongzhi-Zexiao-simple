1一、储罐液位对象的建模与线性化#

思路
  • 由质量守恒列非线性方程，在平衡点线性化得增量方程与传递函数，再算指定频率处的幅值与相位
非线性模型的线性化 建模与机电系统
本卷考法
  • 建立以入口流量为输入、液位为输出的非线性微分方程并在平衡点线性化
本卷实例
  • 关键一步：列质量守恒时把液体当作不可压缩介质：进流量减出流量等于罐内质量的变化率
  • 关键一步：出口流量＝出口流速×截面积×密度
  • 关键一步：出口流速用托里拆利关系与液位高度挂钩，这是非线性来源
  • 关键一步：在平衡点处把非线性项按一阶泰勒展开，用平衡关系把常数项消掉，剩下的就是增量方程
  • 中间结果：非线性方程：罐内质量的变化率等于入口与出口质量流量之差
  • 中间结果：线性化时间常数由出口流量对液位的偏导除以截面积决定
  • 中间结果：罐越细高、出口越大，时间常数越小
  • 卡点：漏掉出口流量对液位的偏导这一项，把对象当成纯积分环节；或线性化时没在平衡点消常数项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 在工作点附近作泰勒展开并忽略高阶项
  • 线性化模型只在小偏差范围内有效
  • 必须先求出平衡工作点
步骤
  • 由静态方程求平衡工作点
  • 在工作点处求偏导得到增量系数
  • 写出以增量表示的线性化方程
通用考法
  • 本卷考过建立以入口流量为输入、液位为输出的非线性微分方程并在平衡点线性化
  • 对非线性微分方程在平衡点处线性化
  • 写出小偏差线性化模型的传递函数
常见易错
  • 未先求平衡点就直接展开
  • 把增量符号去掉后与原始变量混用
公式
被控对象的动态特性 过程控制与检测仪表
本卷考法
  • 写出液位对象的传递函数并说明是自衡还是非自衡
本卷实例
  • 关键一步：线性化后的增量方程是一阶常微分方程，写成标准形式即可直接读出一阶环节的增益与时间常数
  • 关键一步：增益量纲是液位除以质量流量，不要漏写单位
  • 关键一步：平衡点的取值要先由稳态关系算出出口流速，才能代进线性化系数
  • 中间结果：由稳态数据自检：出口流速＝入口质量流量/(密度×出口截面积)
  • 中间结果：该值应与托里拆利公式给出的结果吻合
  • 卡点：液位对象是自衡对象，出口流量随液位升高而增大，会自行重新平衡，不能按非自衡对象写
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 用放大系数 K、时间常数 T、纯滞后 τ 三个参数描述对象
  • 自衡对象受扰动后能自行重新平衡，非自衡对象不能
  • 多容对象由多个一阶环节串联而成，容量滞后大
  • 纯滞后只使响应推迟，不改变最终稳态值
步骤
  • 由阶跃响应曲线读出放大系数、时间常数与纯滞后时间
  • 判断对象是否自衡、是否多容
  • 写出对象的传递函数
  • 用终值定理求稳态值
通用考法
  • 本卷考过写出液位对象的传递函数并说明是自衡还是非自衡
  • 由响应曲线写出对象传递函数
  • 求阶跃输入下的稳态值并说明与哪些因素有关
  • 判断对象是否具有纯滞后
常见易错
  • 把纯滞后当成时间常数一起处理
  • 放大系数的量纲与单位漏写

频率特性的物理意义与求法 频域分析
本卷考法
  • 计算指定频率下频率特性的幅值与相位
本卷实例
  • 关键一步：一阶环节的幅频是直流增益除以根号下「一加转折频率比的平方」，相频是负的反正切
  • 关键一步：先算时间常数与频率的乘积 τω
  • 关键一步：若远小于 1，幅值近似为直流增益、相位接近零
  • 中间结果：本题时间常数约 0.045 s、转速频率 0.022 rad/s
  • 中间结果：两者乘积约千分之一，幅值近似直流增益、相位近零
  • 卡点：把频率特性的幅值当成增益直接填，忘记它是频率的函数；或角度与弧度混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过计算指定频率下频率特性的幅值与相位
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

2二、含右半平面极点的奈奎斯特判据#

思路
  • 开环在小右半平面有极点，画围线时不能只看曲线本身；引入速度反馈后零极点分布改变，需重新推导稳定条件
奈奎斯特判据 稳定性分析
本卷考法
  • 绘制奈奎斯特围线并用判据判断闭环稳定性
  • 引入速度反馈后推导闭环稳定的条件
本卷实例
  • 关键一步：开环有右半平面极点，必须先数出 P
  • 关键一步：再用 Z=N+P 判稳，不能沿用「不包围就稳定」
  • 关键一步：奈奎斯特围线要绕开虚轴上的极点（若开环含积分环节），绕行方向决定补画的圆弧走向
  • 关键一步：引入速度反馈后会多出一个零点，零极点分布与前一小问不同，P 可能改变，必须重新数一遍
  • 中间结果：稳定条件的形式通常是「增益小于某个临界值」这类不等式，由曲线与负实轴交点位置给出
  • 卡点：不数 P 就下结论；或加了速度反馈后仍沿用第一问的围线与 P 值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过绘制奈奎斯特围线并用判据判断闭环稳定性
  • 本卷考过引入速度反馈后推导闭环稳定的条件
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

3三、含纯滞后的 PID 控制器整定#

思路
  • 对象 20/[s(s+2)]·e^{−τs}：先用根轨迹看纯 P 的稳定性，再由临界振荡条件反求 τ 与 kp，最后用 Z-N 与 λ 两种方法整定
根轨迹的绘制法则 根轨迹法
本卷考法
  • 用根轨迹法分析纯比例控制器下闭环系统的稳定性
本卷实例
  • 关键一步：无滞后时特征方程是二阶，两根实部恒为负
  • 关键一步：故加大比例增益只会从过阻尼变欠阻尼，不会失稳
  • 关键一步：判断二阶系统的稳定性只需看特征方程两个系数是否同号，不必画完整根轨迹
  • 关键一步：这一步的结论正好解释了为什么必须引入纯滞后才可能出现等幅振荡
  • 中间结果：τ=0 时闭环特征方程为 s²+2s+20k_p=0
  • 中间结果：两根为 s=−1±√(1−20k_p)，实部恒为 −1
  • 中间结果：20k_p<1 为两个负实根，20k_p>1 为左半平面共轭复根
  • 卡点：以为加大增益一定会失稳，套用三阶及以上系统才有的临界增益结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过用根轨迹法分析纯比例控制器下闭环系统的稳定性
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
含纯延迟环节的系统稳定性 稳定性分析
本卷考法
  • 由临界振荡的周期反求纯滞后时间与临界比例增益
本卷实例
  • 关键一步：等幅振荡意味着闭环极点在虚轴上，把 s=jω 代入特征方程
  • 关键一步：振荡周期先换成角频率，再由相角条件解出滞后时间
  • 关键一步：幅值条件定出临界比例增益，它是后面 Z-N 整定的基准
  • 中间结果：周期与角频率是倒数乘 2π 的关系；相角条件是「对象相角加上滞后相角等于 −180°」
  • 卡点：周期与角频率的换算写反；或算滞后时间时把角度与弧度混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 延迟环节 e^{-τs} 的幅值为 1、相位为 -τω，只恶化相位
  • 延迟会显著缩小稳定域，τ 越大越难稳定
  • 频域判据需用相位裕度扣除延迟引起的附加滞后
步骤
  • 写出含延迟的开环传递函数
  • 分别求幅值与相位表达式
  • 在相频特性中扣除 τω 的滞后量
  • 按稳定裕度或奈氏判据求临界 τ 或临界 K
通用考法
  • 本卷考过由临界振荡的周期反求纯滞后时间与临界比例增益
  • 求使系统稳定的最大延迟时间
  • 求含延迟系统的临界开环增益
  • 分析延迟对稳定裕度的影响
常见易错
  • 把延迟环节当成惯性环节处理
  • 相位计算时忘记角度与弧度换算
公式
PID 控制器与参数整定 系统校正
本卷考法
  • 用齐格勒-尼科尔斯法整定 P、PI、PID 参数
  • 用 λ 整定法整定 PD 控制器
本卷实例
  • 关键一步：Z-N 闭环整定以临界增益与临界周期为基准，P、PI、PID 三组公式的比例系数不同
  • 关键一步：积分时间、微分时间算出后还要换算成控制器里的积分增益、微分增益，不要直接填时间
  • 关键一步：λ 整定法要让闭环等效成一阶惯性环节
  • 关键一步：λ 由过渡过程时间反推，误差带 2% 时约取四倍 λ
  • 中间结果：λ 整定误差带不同系数不同：2% 约 4λ、5% 约 3λ
  • 中间结果：选错系数会让设计结果差三成以上
  • 卡点：把积分时间当积分增益；或把 λ 与闭环等效时间常数搞混，没有由过渡过程时间先定 λ
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过用齐格勒-尼科尔斯法整定 P、PI、PID 参数
  • 本卷考过用 λ 整定法整定 PD 控制器
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

4四、状态响应与输出的极值#

思路
  • 二阶系统有两个相等特征值，状态转移矩阵含 t 项；求状态响应后再回答输出在整个运行期间有无最大最小值
状态转移矩阵 状态空间分析
本卷考法
  • 求给定初始状态与阶跃输入下的状态响应表达式
  • 判断输出是否存在最大值与最小值
本卷实例
  • 关键一步：先求特征值；两个特征值相等时不能只写对角阵
  • 关键一步：状态转移矩阵要含「指数×单位阵＋(A−λI)×t」的形式
  • 关键一步：状态响应分零输入与零状态两部分：零输入项由状态转移矩阵乘初态得到，零状态项由卷积积分得到
  • 关键一步：输出是否单调或是否有极值，要看输出表达式对时间的导数符号，而不是只看状态变量
  • 中间结果：本题两个特征值都是 −2，状态转移矩阵里会出现 t 与指数相乘的项
  • 中间结果：初态取负值时零输入项与零状态项反向抵消，输出可能只有单调变化的一段
  • 卡点：特征值相等时仍套互异公式，会丢掉带 t 的项
  • 卡点：问极值时不能只说单调，要判断最大值是否可达
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过求给定初始状态与阶跃输入下的状态响应表达式
  • 本卷考过判断输出是否存在最大值与最小值
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错
公式

5五、参数对能控能观与稳定性的影响及观测器设计#

思路
  • 含参数 a 的二阶系统，逐项讨论能控性、能观性、BIBO 稳定性、李雅普诺夫稳定与渐近稳定，再设计最小维观测器
能控性与能观性 状态空间分析
本卷考法
  • 分析参数对系统能控性与能观性的影响
本卷实例
  • 关键一步：二阶系统只需构造能控性矩阵与能观性矩阵，行列式为零的那个参数值就是失去能控或能观的分界点
  • 关键一步：能控与能观的分界点通常不重合，要分别列出来，不能只算一个
  • 关键一步：判断时把含参数的表达式写成 a 的一次式，解出使行列式为零的 a 即可
  • 中间结果：能控性矩阵与能观性矩阵都在 a 取某个特定值时降秩，两处的 a 值不同
  • 卡点：只验一个矩阵就下结论；或把秩判据里的矩阵构造顺序写错，维数对不上
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态

6六、最小实现与能观性的证明#

思路
  • 两道理论证明：最小实现之间互相等价；能控的系统一定可以配出使系统能观的输出矩阵
由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 证明同一传递函数的两个最小实现必相互等价
本卷实例
  • 关键一步：最小实现的定义是三要素：能控、能观、维数最低，两个实现维数相同是证明的起点
  • 关键一步：证明的关键是构造两实现之间的线性变换矩阵，用能控性矩阵与能观性矩阵的满秩性说明该矩阵可逆
  • 关键一步：等价性只要求相似变换存在，不需要两个实现的具体形式相同
  • 中间结果：变换矩阵常取「实现一的能控阵乘实现二的能观阵的逆」
  • 中间结果：这两个矩阵都满秩才能保证变换可逆
  • 卡点：只说明维数相同就当成等价；或证明中用到能控性、能观性却不说明为什么可以用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型

  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反

本卷考法
  • 证明能控的系统总能构造出使系统能观的输出矩阵
本卷实例
  • 关键一步：能控保证存在非奇异变换把系统化成能控标准型，在标准型下输出矩阵可以逐项选取
  • 关键一步：能观性要求能观性矩阵满秩，在能控标准型下它的行列式是输出矩阵各分量的组合
