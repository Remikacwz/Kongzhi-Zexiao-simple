一一、多回路结构图求传递函数20 分#

思路
  • 由给定动态结构图标出全部独立回路与前向通路，用梅森增益公式求闭环传递函数，必要时用逐层化简互验
梅森增益公式与信号流图 传递函数
本卷考法
  • 由多回路动态结构图求闭环传递函数
本卷实例
  • 关键一步：先标出全部独立回路增益，再确定各前向通路
  • 关键一步：按回路与通路的接触关系写特征式和余子式
  • 中间结果：分母为 1 减回路增益和加不接触回路乘积
  • 中间结果：分子为各前向通路与其余子式乘积之和
  • 卡点：结构图以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由多回路动态结构图求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路漏找或重复，余子式剔除错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 用逐层化简法处理多回路结构图
本卷实例
  • 关键一步：从最内层反馈回路开始逐层等效成单个环节
  • 中间结果：等效环节的分子分母由内外层增益组合构成
  • 卡点：比较点与引出点交叉时移动规则易混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过用逐层化简法处理多回路结构图
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过化简内环时把外环输入当成常值
  • 化简内环时把外环的信号当成常数处理

二二、含扰动的二阶系统参数与时域指标25 分#

思路
  • 由结构图分别写参考输入与扰动通道的闭环传函，用稳态输出和瞬时最大值反求对象参数，再算二阶时域指标与正弦稳态幅值极值
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求参考输入与扰动作用下的闭环传函
本卷实例
  • 关键一步：对扰动通道单独画等效结构图并令参考输入为零
  • 中间结果：总输出等于输入通道响应与扰动通道响应之和
  • 卡点：两个输入同时作用时须分别独立求解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求参考输入与扰动作用下的闭环传函
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 本卷考过求扰动传函时未把参考输入置零
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由稳态输出与瞬时最大值反求二阶对象参数
本卷实例
  • 关键一步：先由稳态关系定开环增益，再由超调关系定阻尼比
  • 关键一步：由峰值时刻与自然频率关系解出时间常数
  • 中间结果：二阶闭环标准式的阻尼比与自然频率由两条件联立确定
  • 卡点：参数间存在耦合，须按可解顺序逐步回代
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由稳态输出与瞬时最大值反求二阶对象参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 本卷考过把稳态值当成输入幅值直接代入
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求超调量、峰值时间与调节时间
本卷实例
  • 关键一步：由阻尼比和自然频率代入三个指标公式
  • 中间结果：超调量只由阻尼比决定，时间指标还含自然频率
  • 卡点：误差带取 2% 还是 5% 要先看清题意
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求超调量、峰值时间与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过调节时间误差带系数用错，峰值时间混用
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求正弦输入下输出幅值最大时对应的频率
本卷实例
  • 关键一步：写出闭环幅频表达式，对频率求导并令导数为零
  • 中间结果：最大幅值出现在闭环谐振频率处
  • 卡点：求导后须舍去无物理意义的负频率根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求正弦输入下输出幅值最大时对应的频率
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过把闭环幅频峰值当成开环截止频率
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式

三三、根轨迹临界参数与组合输入稳态误差25 分#

思路
  • 由根轨迹图定开环零极点，用幅相条件求临界增益与分离点；再由闭环极点实部条件定增益，并核算组合输入下的稳态误差约束
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点求临界根轨迹增益
本卷实例
  • 关键一步：令闭环特征方程中的实部与虚部分别为零
  • 关键一步：联立解出交点频率和临界增益
  • 中间结果：增益大于临界值时闭环极点全部位于左半平面
  • 卡点：临界增益须回到原题核对根轨迹增益的定义
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹与虚轴交点求临界根轨迹增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 本卷考过只代一组虚轴频率，漏掉另一组交点
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
分离点与会合点 根轨迹法
本卷考法
  • 由分离点求临界阻尼时的闭环传函
本卷实例
  • 关键一步：用分离点方程求重根位置，再由幅值条件定增益
  • 中间结果：临界阻尼对应根轨迹在实轴上的分离点
  • 卡点：分离点方程的根须逐一代回根轨迹判据检验
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由分离点求临界阻尼时的闭环传函
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 本卷考过解出分离点后未筛除不在根轨迹上的解
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由闭环极点实部要求反求根轨迹增益
本卷实例
  • 关键一步：设定共轭闭环极点并代入相角条件求虚部
  • 关键一步：再用幅值条件算出对应增益
  • 中间结果：闭环极点实部固定后，虚部与增益由相角模值两条件定出
  • 卡点：相角条件中零点与极点夹角须逐项累加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由闭环极点实部要求反求根轨迹增益
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 本卷考过只按实部条件定增益，未复核模值条件
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求多项式组合输入下的稳态误差约束
本卷实例
  • 关键一步：先判系统型别，再按输入各次幂分项写稳态误差
  • 关键一步：对无法跟踪的分量令其系数为零
  • 中间结果：误差约束化为对输入各阶导系数的线性不等式
  • 卡点：组合输入中高阶分量可能直接决定系数取值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求多项式组合输入下的稳态误差约束
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过忽略加速度分量对 I 型系统误差为无穷大
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

四四、由相频特性反求传函与串联超前校正20 分#

思路
  • 由相频表达式识别最小相位环节并写出开环传函，用截止频率处幅值为 1 与相角裕度条件求参数；再加串联超前环节，按校正后截止频率处的幅相条件列方程
稳定裕度 频域分析
本卷考法
  • 由相角裕度要求反求最小相位开环传函
本卷实例
  • 关键一步：由相频表达式设出标准环节串联形式
  • 关键一步：在截止频率处联立幅值为 1 和相角裕度条件
  • 中间结果：最小相位环节的转折频率由给定相频表达式识别
  • 卡点：相角裕度是 180 度加截止频率处的相角
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由相角裕度要求反求最小相位开环传函
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过截止频率与相位穿越频率用反
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
超前校正 系统校正
本卷考法
  • 设计串联超前环节把相角裕度提高到 60 度
本卷实例
