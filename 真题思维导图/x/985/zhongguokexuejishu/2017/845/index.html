一一、结构图求传函与二阶时域频域响应25 分#

思路
  • 用梅森公式求闭环传函，化为二阶标准式读阻尼比与自然频率算超调量和调节时间；再由闭环幅相在输入频率处求正弦稳态输出
梅森增益公式与信号流图 传递函数
本卷考法
  • 由动态结构图用梅森公式求闭环传递函数
本卷实例
  • 关键一步：找出全部独立回路与前向通路
  • 关键一步：按接触关系写特征式和各通路余子式
  • 中间结果：闭环传函分母为二阶，分子为常数
  • 卡点：结构图以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由动态结构图用梅森公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路漏找或重复，余子式剔除错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由闭环传函标准式求超调量与调节时间
本卷实例
  • 关键一步：把闭环传函化为标准二阶形式
  • 关键一步：读阻尼比与自然频率后代入指标公式
  • 中间结果：超调量只由阻尼比决定，调节时间还含自然频率
  • 卡点：时间指标须先确认误差带系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由闭环传函标准式求超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过未把 s 平方项系数归一化就读阻尼比
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

频率特性的物理意义与求法 频域分析
本卷考法
  • 求正弦输入下系统的稳态输出响应
本卷实例
  • 关键一步：把输入频率代入闭环幅频和相频
  • 关键一步：按同频正弦写出稳态输出幅值与相角
  • 中间结果：稳态输出幅值等于输入幅值乘闭环幅频
  • 卡点：相角由闭环相频决定，不要漏掉积分环节的负相角
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求正弦输入下系统的稳态输出响应
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过把幅频与相频在输入频率处取值搞混
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

二二、以时间常数为参数的根轨迹与过阻尼范围30 分#

思路
  • 把时间常数化为等效开环传函，按参数正负分别画零度与 180 度根轨迹；由分离点定过阻尼范围，由阻尼比表达式求极小值及稳态误差
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以时间常数为参数绘制零度与 180 度根轨迹
本卷实例
  • 关键一步：把含时间常数的项归并成等效开环传函
  • 关键一步：按参数小于零与大于零分别套零度与 180 度法则
  • 中间结果：等效开环的极点与零点决定根轨迹形状
  • 卡点：参数根轨迹的等效开环形式须整理规范，图需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以时间常数为参数绘制零度与 180 度根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 本卷考过正负参数对应两类相角条件，混用会多画或少画半支
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 求系统为过阻尼时时间常数的取值范围
本卷实例
  • 关键一步：过阻尼对应闭环两个不等的负实根
  • 关键一步：由分离点对应的临界参数夹出过阻尼区间
  • 中间结果：分离点两侧分别对应过阻尼与欠阻尼
  • 卡点：正负参数各有一段过阻尼区间，不可只写一段
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过求系统为过阻尼时时间常数的取值范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 本卷考过把稳定范围与过阻尼范围当成同一区间
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求最小阻尼比时单位阶跃输入下的稳态误差
本卷实例
  • 关键一步：由阻尼比表达式求极小值点对应的时间常数
  • 关键一步：在该参数下写开环传函并用终值定理求误差
  • 中间结果：阻尼比极小值由对参数求导并令导数为零得到
  • 卡点：求导前先把阻尼比写成参数的显函数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求最小阻尼比时单位阶跃输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过未先判稳就代入稳态误差公式
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

三三、由渐近对数幅频特性设计二阶环节15 分#

思路
  • 由低频段高度定增益，由中频段和高频段的渐近线误差要求定转折频率，使中高频分界频率尽可能大
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由给定渐近对数幅频特性反求环节传递函数
本卷实例
  • 关键一步：由低频段高度定增益
  • 关键一步：按各段斜率变化确定零点与极点转折频率
  • 中间结果：环节由两个惯性环节和一个一阶微分环节组成
  • 卡点：渐近线位置以扫描图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由给定渐近对数幅频特性反求环节传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 本卷考过把延长线交点误当增益而未折算型别
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
期望特性法与综合法 系统校正
本卷考法
  • 用期望特性法确定转折频率并让中高频分界尽可能大
本卷实例
  • 关键一步：由给定幅值误差条件反推低频与中频转折频率关系
  • 关键一步：在满足误差约束下让高频转折频率尽量大
  • 中间结果：转折频率由分贝误差与斜率差联立解出
  • 卡点：误差条件与斜率差必须对应同一频段
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 期望特性法直接按指标画出希望的开环对数幅频特性
  • 用期望特性减去未校正特性得到校正装置特性
  • 关键是确定低频段高度、中频段宽度与高频段斜率
  • 中频段斜率一般取 -20 dB/dec 并保持足够宽度
步骤
  • 按稳态要求确定低频段斜率与高度
  • 按相角裕度要求确定中频段宽度与截止频率
  • 按抗噪要求确定高频段斜率
  • 相减求得校正装置并检验可实现性
通用考法
  • 本卷考过用期望特性法确定转折频率并让中高频分界尽可能大
  • 用期望特性法设计校正装置
  • 说明中频段宽度与相角裕度的关系
  • 由校正装置特性反写传递函数
常见易错
  • 本卷考过只满足一个误差条件就下结论
  • 期望特性的中频段取窄导致裕度不足
  • 相减后得到的特性不可物理实现却未检查

四四、相角裕度求开环增益与幅值裕度20 分#

思路
  • 由相角裕度条件求截止频率，再由幅值条件求增益；由相角穿越求幅值裕度
稳定裕度 频域分析
本卷考法
  • 由相角裕度反求开环增益并计算幅值裕度
本卷实例
  • 关键一步：由相角等于负 180 度加裕度求截止频率
  • 关键一步：由截止频率处幅值为 1 求开环增益
  • 中间结果：相位穿越频率由相角等于负 180 度单独求出
  • 卡点：两个特征频率分别对应不同的相角条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由相角裕度反求开环增益并计算幅值裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过题面印 s 加减 2 而答案段按 s 加 2 自洽，须以答案段为准
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

五五、参数对能控能观与稳定性的影响及极点配置25 分#

思路
  • 写状态空间矩阵，用能控能观判别矩阵定临界参数；由特征方程与传函判两种稳定性；对两种参数分别作能控性分解或极点配置
能控性与能观性 状态空间分析
本卷考法
  • 分析参数对能控性与能观性的影响
本卷实例
  • 关键一步：把方程写成状态空间矩阵形式
  • 关键一步：分别构造能控性与能观性判别矩阵并求行列式
  • 中间结果：参数取特定值时能控矩阵降秩，另一值使能观矩阵降秩
  • 卡点：源文方程缺少导数点，按答案段补成状态方程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过分析参数对能控性与能观性的影响
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 本卷考过能控性矩阵与能观性矩阵构造混淆
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 判断参数变化时系统的渐近稳定性
本卷实例
  • 关键一步：求特征方程并检查两个特征值实部符号
  • 中间结果：特征方程一次项系数符号固定，系统不是渐近稳定
  • 卡点：渐近稳定要求全部特征值位于左半平面
