1一、直流电机传动系统建模与闭环设计#

思路
  • 分别以励磁电压和电枢电压为输入建立直流电机方框图与传递函数，忽略电气时间常数降阶，再构成闭环算稳态误差并选控制器型别
直流电机等机电系统 建模与机电系统
本卷考法
  • 分别建立磁场控制与电枢控制直流电机的方框图与传递函数
本卷实例
  • 关键一步：按电磁转矩、反电动势、机械运动与积分依次列写各环节关系
  • 关键一步：磁场控制时电枢电流视为常数，电枢控制时励磁电流视为常数，使模型线性化
  • 中间结果：传函分母含电气时间常数与机电时间常数两个一阶因子
  • 中间结果：忽略电气时间常数后降为一阶因子与积分环节串联
  • 卡点：漏掉反电动势与电磁转矩的耦合项；两时间常数数量级搞反；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由电枢回路电压方程与转矩平衡方程联立
  • 反电动势与转速成正比，电磁转矩与电枢电流成正比
  • 机电时间常数由电气与机械两方面参数共同决定
步骤
  • 写出电枢回路电压平衡方程
  • 写出转矩平衡方程（含负载与粘性摩擦）
  • 消去电枢电流，得到转速或转角对电压的传递函数
通用考法
  • 本卷考过分别建立磁场控制与电枢控制直流电机的方框图与传递函数
  • 求直流电机转速或位置对电枢电压的传递函数
  • 分析机电时间常数与电气时间常数的数量级关系
常见易错
  • 漏掉反电动势与电磁转矩的耦合项
  • 把电气时间常数与机电时间常数混淆

系统型别与静态误差系数 稳态误差
本卷考法
  • 判断单位负反馈电枢控制系统的型别并分析阶跃下的稳态误差
本卷实例
  • 关键一步：写等效开环传函，数积分环节个数定型别
  • 关键一步：一型系统对阶跃输入稳态误差为零
  • 中间结果：电枢控制闭环等效开环为一型
  • 中间结果：阶跃误差为零，速度误差为有限值
  • 卡点：把开环增益与静态误差系数混为一谈；数错积分环节个数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断单位负反馈电枢控制系统的型别并分析阶跃下的稳态误差
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 说明无稳态位置误差地跟踪速度信号所需的改进措施
本卷实例
  • 关键一步：跟踪速度信号需把开环型别提高到二型
  • 关键一步：单纯增加积分环节会降低稳定裕度，须配合零点
  • 中间结果：提高型别可消除速度信号的位置误差
  • 中间结果：引入零点可补偿积分带来的相位滞后
  • 卡点：只谈误差减小不检查稳定性；把增加积分的影响单一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过说明无稳态位置误差地跟踪速度信号所需的改进措施
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

PID 控制器与参数整定 系统校正
本卷考法
  • 确定应采用的串联控制器类型并说明理由
本卷实例
  • 关键一步：积分作用可提高型别，比例作用提供零点改善稳定
  • 关键一步：两者合成即比例积分控制器
  • 中间结果：PI 控制器同时兼顾型别与相位
  • 中间结果：闭环稳态误差为零且系统仍稳定
  • 卡点：把 PI 的相位影响说成超前；积分增益过大引起振荡
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过确定应采用的串联控制器类型并说明理由
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

2二、含 PD 补偿的频域分析与设计#

思路
  • 先画最小相位开环的奈奎斯特图判稳并求增益范围，再用 Bode 图法设计 PD 补偿满足误差、截止频率与相角裕度，最后判断小时间常数环节能否忽略
奈奎斯特判据 稳定性分析
本卷考法
  • 画最小相位开环的奈奎斯特图并判断闭环稳定性
本卷实例
  • 关键一步：先求相位穿越频率使虚部为零，得与负实轴交点幅值
  • 关键一步：开环无右半平面极点，交点在负一临界点右侧即稳定
  • 中间结果：稳定条件化为开环增益小于两时间常数之和除以乘积
  • 中间结果：临界值由交点幅值方程解出
  • 卡点：不先数 P 就套判据；相位穿越频率求错；把临界点位置判反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过画最小相位开环的奈奎斯特图并判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
稳定裕度 频域分析
本卷考法
  • 由稳态误差、截止频率与相角裕度三项指标设计 PD 补偿
本卷实例
  • 关键一步：由速度误差要求定开环增益下限
  • 关键一步：在指定截止频率处由幅值条件定微分时间常数，再验证相角裕度
  • 中间结果：增益下限由速度误差限得到
  • 中间结果：补偿后相角裕度满足大于 60 度的要求
  • 卡点：补偿角漏算附加相角损失；把截止频率与穿越频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由稳态误差、截止频率与相角裕度三项指标设计 PD 补偿
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
超前校正 系统校正
本卷考法
  • 用 Bode 图法设计 PD 形式的串联超前补偿并说明抑制高频噪声的办法
本卷实例
  • 关键一步：PD 补偿提供超前相角，抵消原系统的相位滞后
  • 关键一步：对高频噪声敏感时，在微分环节前串联低通滤波器
  • 中间结果：补偿传函为一阶微分形式
  • 中间结果：引入低通后高频增益被压低，噪声放大被抑制
  • 卡点：把 PD 当滞后校正设计；只提高增益不看裕度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过用 Bode 图法设计 PD 形式的串联超前补偿并说明抑制高频噪声的办法
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 判断时间常数很小的惯性环节能否被忽略
本卷实例
  • 关键一步：比较该环节时间常数与系统过渡过程时间的数量级
  • 关键一步：时间常数远小于过渡过程时间时该极点远离虚轴，可按主导极点忽略
  • 中间结果：该惯性环节的阶跃过渡时间约为三倍时间常数
  • 中间结果：相对设计指标很小，故可忽略
  • 卡点：只看时间常数大小不折算过渡时间；忽略零点对近似的影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过判断时间常数很小的惯性环节能否被忽略
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

3三、一阶对象根轨迹法 PI 设计#

思路
  • 先由开环阶跃输出曲线测量增益、时间常数与过渡时间，再按超调量与稳态误差要求用根轨迹法设计 PI 控制器并校核过渡时间
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由开环阶跃输出曲线测量一阶对象的增益、时间常数与过渡时间
本卷实例
  • 关键一步：稳态值除以输入幅值得增益
  • 关键一步：由曲线上升到 63.2% 稳态值的时刻读时间常数，过渡时间取四倍时间常数
  • 中间结果：输出曲线单调上升，无超调
  • 中间结果：98% 稳态值对应过渡时间约为四倍时间常数
  • 卡点：把 63.2% 时刻记成 50%；增益不为一时直接读稳态值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由开环阶跃输出曲线测量一阶对象的增益、时间常数与过渡时间
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量指标确定阻尼比并取闭环极点
本卷实例
  • 关键一步：由相对超调量小于 5% 解出阻尼比
  • 关键一步：由过渡时间指标反解阻尼乘自然频率，确定闭环共轭极点位置
  • 中间结果：阻尼角为反余弦阻尼比，取略小于其上限的值留裕量
  • 中间结果：闭环极点实部由过渡时间与阻尼乘自然频率共同确定
  • 卡点：只满足超调量不看过渡时间；把误差带系数用错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量指标确定阻尼比并取闭环极点
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 用根轨迹法设计 PI 控制器零点位置并求比例与积分增益

状态反馈与极点配置 状态空间分析
本卷考法
  • 说明估计状态反馈在增广系统中的实现
本卷实例
  • 关键一步：反馈用估计状态而非真实状态，形成观测器与反馈串接
  • 关键一步：增广矩阵含原状态矩阵、反馈项与观测器增益项
  • 中间结果：估计误差与状态反馈动态在增广矩阵中按块出现
  • 中间结果：控制量由估计状态线性组合生成
  • 卡点：把估计状态反馈当作真实状态反馈；分块矩阵写错阶数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过说明估计状态反馈在增广系统中的实现
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
