一一、多回路结构图求传递函数#

思路
  • 由结构图列独立回路与前向通路，用梅森公式统一求闭环传函 C(s)/R(s)
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求多回路系统的闭环传递函数
本卷实例
  • 关键一步：先标出全部独立回路与前向通路
  • 关键一步：再按接触关系写出特征式和各余子式
  • 中间结果：闭环分母由两个局部回路的增益组合决定
  • 卡点：结构图以插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求多回路系统的闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路漏找或重复导致特征式出错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 按逐层化简法复核多回路结构
本卷实例
  • 关键一步：先把最内层局部反馈等效为单环节
  • 关键一步：再逐层向外串并联
  • 中间结果：逐层等效的传函可用来校验梅森结果
  • 卡点：交叉比较点移动时乘除方向容易取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过按逐层化简法复核多回路结构
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过化简内环时误把外环信号当常数处理
  • 化简内环时把外环的信号当成常数处理

二二、由频率响应定参数与二阶性能指标#

思路
  • 由指定频率处的幅值比与相位差反求开环参数，再把闭环化为标准二阶式求动态指标与谐振峰值
频率特性的物理意义与求法 频域分析
本卷考法
  • 由指定频率处的幅值比与相位差反求开环参数
本卷实例
  • 关键一步：写出闭环幅频相频并把 s 换成 j 倍频率
  • 关键一步：在指定频率处代入题给的幅值比与相位差
  • 中间结果：两个条件恰好给出两个待定参数
  • 卡点：闭环相角的符号容易漏掉
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由指定频率处的幅值比与相位差反求开环参数
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过幅频取模时漏掉分母复数整体取模
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 计算单位阶跃下的超调量与调节时间
本卷实例
  • 关键一步：把闭环传函化为标准二阶形式
  • 关键一步：由阻尼比与自然频率代入指标公式
  • 中间结果：超调量只与阻尼比有关，调节时间还与自然频率有关
  • 卡点：调节时间的误差带系数要按题给取
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过计算单位阶跃下的超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过没把 s 平方项系数归一化就读阻尼比
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
闭环频率特性与性能指标 频域分析
本卷考法
  • 求闭环幅值最大时的频率与幅值
本卷实例
  • 关键一步：令闭环幅频对频率的导数等于零
  • 关键一步：解出谐振频率后代回求峰值
  • 中间结果：谐振峰只出现在欠阻尼区
  • 卡点：谐振峰值公式有阻尼比适用区间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过求闭环幅值最大时的频率与幅值
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 本卷考过把开环谐振与闭环谐振混为一谈
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位阶跃输入下的稳态误差
本卷实例
  • 关键一步：先用特征方程判稳
  • 关键一步：再由系统型别与静态误差系数求误差
  • 中间结果：一型系统跟随阶跃时误差为有限值
  • 卡点：开环含积分环节时误差系数取法要对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位阶跃输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过未判断闭环稳定就直接用终值定理
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

三三、含零点参数根轨迹与主导极点化简#

思路
  • 把特征方程整理成含参根轨迹形式，按增益正负分别画正反向根轨迹；由已知极点求其余极点，再判可否降阶
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以开环增益为变量绘制正反向根轨迹
本卷实例
  • 关键一步：把闭环特征方程整理成 1 加 K 乘开环为零的形式
  • 关键一步：按增益正负分别用 180 度与 0 度相角条件
  • 中间结果：负增益对应的轨迹是零度根轨迹
  • 卡点：正反两段的分支起点终点要分别标注
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以开环增益为变量绘制正反向根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 本卷考过负增益段的零度根轨迹仍套用 180 度相角条件
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则求渐近线与分离点
本卷实例
  • 关键一步：先数开环极零点个数再算渐近线交点与夹角
  • 关键一步：由分离点方程求实轴上的分歧点
  • 中间结果：渐近线条数等于极点数减零点数
  • 卡点：求出的分离点须筛掉不在轨迹上的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则求渐近线与分离点
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过渐近线夹角公式把 2k+1 写成 2k
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

四四、稳定裕度计算与串联超前校正#

思路
  • 按开环幅相求截止频率与相角裕度，再按相角裕度差额设计串联超前校正并回代校验
稳定裕度 频域分析
本卷考法
  • 求截止频率、相角裕度与幅值裕度
本卷实例
  • 关键一步：令开环幅频等于 1 解截止频率
  • 关键一步：再按相频在截止频率处求相角裕度
  • 中间结果：幅相曲线不与负实轴相交时幅值裕度为无穷大
  • 卡点：积分环节使低频起始相角为负 90 度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求截止频率、相角裕度与幅值裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过把截止频率与相位穿越频率两个频率用反
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
超前校正 系统校正
本卷考法
