1一、两级 RC 网络建模与状态空间30 分#

思路
  • 由基尔霍夫定律与电容电流关系画动态结构图，以两电容电压为状态变量列状态空间方程，再用梅森公式求传递函数
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由两级 RC 网络列写微分方程并建立动态结构图
本卷实例
  • 关键一步：对每个节点用 KCL 写电流关系，对电容用电流等于电容乘电压变化率
  • 关键一步：把方程拉氏变换后按中间变量 i1、v、i2 串成结构图
  • 中间结果：两级 RC 含两个储能元件，系统为二阶
  • 中间结果：各支路电流电压关系可由变换后的方程读出
  • 卡点：两级耦合关系写错；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由两级 RC 网络列写微分方程并建立动态结构图
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

状态空间表达式的建立 状态空间分析
本卷考法
  • 选取两电容两端电压为状态变量建立状态空间方程
本卷实例
  • 关键一步：对每个电容节点列 KCL 得两个一阶微分方程
  • 关键一步：整理成状态方程与输出方程的矩阵形式
  • 中间结果：状态矩阵含电阻与电容的组合参数
  • 中间结果：输出取第二级电容电压
  • 卡点：状态变量个数与储能元件数不等；输出方程漏写直通项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过选取两电容两端电压为状态变量建立状态空间方程
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

梅森增益公式与信号流图 传递函数
本卷考法
  • 分别由动态结构图与状态空间方程求传递函数并互验
本卷实例
  • 关键一步：由结构图找前向通路与回路，用梅森公式写特征式与余子式
  • 关键一步：由状态空间独立算一遍同样的传递函数作校验
  • 中间结果：两种方法应得到相同的二阶传递函数
  • 中间结果：分母由两回路与不接触回路组合而成
  • 卡点：不接触回路漏算；矩阵求逆展开时符号写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过分别由动态结构图与状态空间方程求传递函数并互验
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、由闭环根轨迹反求参数25 分#

思路
  • 由给定闭环根轨迹反推开环零极点与根轨迹增益，用分离点求临界阻尼，再由闭环极点实部与稳态误差约束定输入系数范围
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点确定使系统稳定的根轨迹增益范围
本卷实例
  • 关键一步：把 s 等于 jω 代入特征方程，令实部虚部同时为零
  • 关键一步：解出交点频率与对应增益，增益大于该值时为稳定
  • 中间结果：交点位于虚轴，临界增益由两方程联立得到
  • 中间结果：开环零极点可由分离点与交点条件反推
  • 卡点：只代一个 ω 漏另一组解；求出增益后未回原题核对参数定义
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹与虚轴交点确定使系统稳定的根轨迹增益范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
分离点与会合点 根轨迹法
本卷考法
  • 求临界阻尼时的闭环传递函数
本卷实例
  • 关键一步：临界阻尼对应实轴上的分离点，令增益对位移的导数为零求分离点
  • 关键一步：由幅值条件求分离点处的增益，再写闭环传函
  • 中间结果：分离点处闭环有一对相等实根
  • 中间结果：闭环特征多项式可由开环零极点与增益组合得到
  • 卡点：分离点方程解出后不筛选，保留了不在根轨迹上的根；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求临界阻尼时的闭环传递函数
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 要求闭环极点实部都为负七，反求根轨迹增益
本卷实例
  • 关键一步：由闭环特征多项式两根之和等于二倍实部，建立关于增益的方程
  • 关键一步：解出增益后再定共轭极点的虚部
  • 中间结果：闭环极点写成指定实部加减虚部的形式
  • 中间结果：由根之和与根之积可定出虚部
  • 卡点：实部与实根混淆；根之和取反号时符号写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过要求闭环极点实部都为负七，反求根轨迹增益
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由稳态误差限确定输入多项式各项系数的取值范围
本卷实例
  • 关键一步：先由开环传函求静态位置、速度、加速度误差系数
  • 关键一步：把组合输入误差按各分量与对应误差系数之比叠加并套上限
  • 中间结果：系统为一型，位置误差系数发散、加速度误差系数为零
  • 中间结果：组合输入中只有速度分量受误差限约束
  • 卡点：未判稳就用终值定理；组合输入漏掉某一分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由稳态误差限确定输入多项式各项系数的取值范围
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、由阶跃响应反求参数与谐振25 分#

思路
  • 由稳态值与峰值定超调量和阻尼比，由峰值时间定自然频率，再反求对象参数、算斜坡误差与谐振指标
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由阶跃稳态值与峰值反求二阶系统参数
本卷实例
  • 关键一步：由稳态值与峰值算超调量，解出阻尼比
  • 关键一步：由峰值时间关系解出自然频率，再反求对象增益与时间常数
  • 中间结果：超调量与阻尼比一一对应，已知峰值时间后自然频率唯一
  • 中间结果：对象为一阶惯性乘积分环节，闭环标准式为二阶
  • 卡点：把稳态值当增益漏掉输入幅值；只满足单项指标不交叉验证
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由阶跃稳态值与峰值反求二阶系统参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求单位阶跃响应下的调节时间等时域指标
本卷实例
  • 关键一步：由阻尼比与自然频率按所选误差带取调节时间系数
  • 关键一步：调节时间由误差带系数除以阻尼乘自然频率得到
  • 中间结果：2% 误差带系数为四，5% 误差带系数为三
  • 中间结果：本题按 2% 误差带取值
  • 卡点：两种误差带系数搞混；把峰值时间当调节时间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求单位阶跃响应下的调节时间等时域指标
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

  • 卡点：未判稳就用终值定理；把斜坡误差公式套成阶跃

  • 比较不同型别系统的跟踪能力

闭环频率特性与性能指标 频域分析
本卷考法
  • 判断正弦输入下有无谐振并求谐振频率与峰值
本卷实例
  • 关键一步：由阻尼比是否小于 0.707 判断有无谐振峰
  • 关键一步：用谐振频率与谐振峰值公式计算指标
  • 中间结果：阻尼比较小时闭环幅频出现谐振峰
  • 中间结果：谐振峰值等于闭环幅频在谐振频率处的值
  • 卡点：阻尼比偏大仍套谐振公式；把开环与闭环谐振混为一谈；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间

本卷实例

  • 关键一步：把闭环极点配到左半平面即得渐近稳定

  • 中间结果：任意左半平面极点组均可配置

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性

  • 先验证系统能控
