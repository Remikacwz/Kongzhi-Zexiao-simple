思路

由电路或机械系统求传递函数 传递函数
本卷考法
  • 由实际物理装置求输入输出传递函数 Q(s)/T(s)
本卷实例　P1 图1、图2
  • 关键一步：两幅图是两个子系统，各自按物理定律列方程后再串联消元，不能直接相乘

3Nyquist 判据及证明15 分#

思路
  • 证明题要顺着「辐角原理 → 映射曲线 → Z=N+P」的逻辑链写，不能只背结论
奈奎斯特判据 稳定性分析
本卷考法
  • 简述 Nyquist 判据并用辐角原理证明
本卷实例　P1
  • 关键一步：证明的骨架是辐角原理：F(s) 在围线内零点数 − 极点数 = 曲线绕原点的圈数
  • 关键一步：取 F(s)=1+G(s)H(s)，把绕原点圈数换算成绕 (−1,j0) 的圈数
  • 关键一步：由此得 Z=N+P
  • 中间结果：F(s) 的极点就是开环极点（P 的来源），零点就是闭环极点（Z 的含义）
  • 卡点：只写结论不解释 P 为什么是开环右半平面极点数，证明题拿不到分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过简述 Nyquist 判据并用辐角原理证明
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

本卷考法

本卷实例　P2 图5、图6

5稳定裕度与串联校正15 分#

思路
  • 第 1 问由 ωc=1 反求 K 再算 γ；第 2 问 Mr 限制本质是阻尼比限制，用超前校正把 γ 抬起来
稳定裕度 频域分析
本卷考法
  • 由剪切频率求开环增益 K 与相位裕度
本卷实例　P2
  • 关键一步：ωc 的定义就是 |G0(jωc)|=1，把 ωc=1 代进幅值式直接解出 K
  • 关键一步：再把该 ωc 代进相频式求 ∠G，γ=180°+∠G
  • 中间结果：G0(s)=K/(s(√3s+1)(0.01s+1))
  • 中间结果：在 ω=1 处 |G0(j)|=K/(1·2·√(1+0.0001))≈K/2
  • 卡点：√3s 项在 ω=1 处是 √3·j 不是 j，模要取 2 不是 1
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度

  • 卡点：符号判反会把稳定/不稳定极限环对调
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 非线性系统只有局部稳定性概念，与初始条件有关
  • 极限环的稳定性可由相轨迹收敛或发散判断
  • 减小非线性影响可用加大线性部分增益或引入校正
  • 用描述函数或相平面结果指导参数选择
步骤
  • 判断系统是否存在极限环并确定其稳定性
  • 分析非线性环节参数对自振幅值频率的影响
  • 通过调整线性部分增益或加入校正削弱自振
  • 重新分析确认自振消除或幅值达标
通用考法
  • 本卷考过判断是否存在极限环
  • 提出消除自振的工程措施
  • 分析增益变化对极限环幅值的影响
  • 比较不同方案对稳定性与动态性能的利弊
常见易错
  • 仅调整增益而不检查是否引入新的自振点
  • 把不稳定极限环误判为可观测的自振

10状态反馈与观测器15 分#

思路
  • 先判能控，再按 ξ、ωn 写期望极点，比较特征多项式解 K；观测器极点取 -10、-10 求 L
状态反馈与极点配置 状态空间分析
本卷考法
  • 由 ξ、ωn 折算期望极点并设计状态反馈 K
本卷实例　P3
  • 关键一步：A=[[0,1],[0,−1]]、B=[0,1]ᵀ 是能控标准型，可直接套极点配置公式
  • 关键一步：ξ=√2/2、ωn=√2 → 期望极点 s=−1±j1
  • 中间结果：期望特征多项式 (s+1)²+1 = s²+2s+2
  • 中间结果：再与 det(sI−A+BK) 比对求 K
  • 卡点：A 的第二行是 −1 不是 0，比对系数时容易漏掉这个常数项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法

常见易错
  • 未验证能控性就直接做极点配置

本卷考法

能控性与能观性 状态空间分析
本卷考法
  • 动手前先验证能控性
本卷实例　P3
  • 关键一步：算 Qc=[B AB] 的行列式，非零才可以说极点可任意配置
  • 中间结果：A=[[0,1],[0,−1]]、B=[0,1]ᵀ，Qc=[B AB] 为二阶方阵
  • 卡点：Qc 的秩等于系统阶数才完全能控；秩亏时不能任意配置极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过动手前先验证能控性
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
