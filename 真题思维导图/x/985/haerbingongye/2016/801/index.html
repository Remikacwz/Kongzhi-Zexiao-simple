一一、双惯量机械系统建模#

思路
  • 对转子与负载分别列转动动力学方程，两者通过扭转弹簧与粘性阻尼耦合，消去中间转角得输出对输入转矩的传递函数。
机械系统建模 建模与机电系统
本卷考法
  • 两惯量经扭转弹簧与阻尼耦合的机械系统建模
本卷实例
  • 关键一步：对转子与负载分别列力矩平衡方程
  • 中间结果：耦合项为刚度乘转角差加阻尼乘角速度差
  • 卡点：机械示意图以插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过两惯量经扭转弹簧与阻尼耦合的机械系统建模
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 本卷考过两质量系统漏掉相互作用力的反作用项
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 求两个输出转角对输入转矩的传递函数
本卷实例
  • 关键一步：对两个方程取拉氏变换后消去负载转角
  • 中间结果：两个传函分母相同而分子阶次不同
  • 卡点：从转矩到两转角的传函要分别消元
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过求两个输出转角对输入转矩的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过消元时漏掉一路耦合项
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

二二、二阶系统指标可行性与极点区域#

思路
  • 把闭环传函化为标准二阶形式，将峰值时间与超调量要求化为对阻尼比和自然频率的约束，再判断两约束区域是否有交集。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由开环增益求闭环阻尼比与自然频率
本卷实例
  • 关键一步：由闭环特征方程与标准二阶形式对比系数
  • 中间结果：自然频率与增益有关，阻尼比由开环参数决定
  • 卡点：开环含积分环节时闭环为二阶
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由开环增益求闭环阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过把开环增益误当成闭环特征多项式系数
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由峰值时间与超调量要求定极点可行区域
本卷实例
  • 关键一步：超调量只约束阻尼比，峰值时间约束自然频率
  • 中间结果：极点须落在等阻尼线与等自然频率线围成的区域
  • 卡点：两项指标同时满足的区域取交集
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由峰值时间与超调量要求定极点可行区域
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过两种指标对应的区域边界画反
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 判断能否选到增益同时满足两项指标
本卷实例
  • 关键一步：由超调量定阻尼比下界，再由峰值时间定增益可行域
  • 中间结果：两可行域无交集则不存在合适增益
  • 卡点：可行域为空时要说明理由
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过判断能否选到增益同时满足两项指标
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 本卷考过只满足单项指标就下结论
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

三三、非最小相位系统频域绘制与判稳#

思路
  • 开环含右半平面极点，按转折频率逐段画渐近对数幅频与相频特性，再由幅相曲线包围临界点情况用 Nyquist 判据判稳。
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制含右半平面极点的开环渐近对数频率特性
本卷实例
  • 关键一步：按各转折频率顺次修改幅频渐近线斜率
  • 中间结果：低频段斜率由积分环节个数决定
  • 卡点：含右半平面极点时相频起点不在零度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过绘制含右半平面极点的开环渐近对数频率特性
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 本卷考过逐段改斜率时忘记累加而直接替换
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
最小相位系统与非最小相位系统 频域分析
本卷考法
  • 识别非最小相位系统的频率特性特征
本卷实例
  • 关键一步：由传函符号判断是否存在右半平面极点或零点
  • 中间结果：非最小相位环节带来额外相位滞后
  • 卡点：相位变化方向与最小相位系统相反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过识别非最小相位系统的频率特性特征
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 本卷考过把右半平面极点当作左半平面极点处理
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈
奈奎斯特判据 稳定性分析
本卷考法
  • 由 Nyquist 图判别含右半平面极点系统的稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数再数曲线包围临界点圈数
  • 中间结果：由 Z 等于 P 减二倍圈数得闭环右半平面极点数
  • 卡点：幅相曲线形状以插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由 Nyquist 图判别含右半平面极点系统的稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过数开环右半平面极点数时漏算
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

四四、含偶极子控制器系统的根轨迹分析#

思路
  • 把对象与控制器传函相乘得开环传函，按根轨迹法则画渐近线并求复极点的出射角与入射角，再讨论增益对稳定性与性能的影响。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画多极点系统的根轨迹
本卷实例
  • 关键一步：由开环极点数与零点数确定渐近线条数与夹角
  • 中间结果：实轴上根轨迹段按右侧实数零极点个数奇偶判定
  • 卡点：开环含重极点，出射角要按重数处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画多极点系统的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过渐近线条数与夹角计算错误
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
出射角与入射角 根轨迹法
本卷考法
  • 求复极点的出射角与复零点的入射角
本卷实例
  • 关键一步：按相角条件列出各零极点贡献的相角
  • 中间结果：出射角等于一百八十度加零点相角减其他极点相角
  • 卡点：重极点的出射角要再除以重数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求复极点的出射角与复零点的入射角
  • 求复数极点的出射角
  • 根据出射角画出根轨迹起始方向
  • 由入射角确定根轨迹终止方向
常见易错
  • 本卷考过各向量相角累加时符号写错
  • 累加相角时把该极点自身的相角也算进去
  • 忘记判断象限导致角度差 180°

五五、由实验Bode图设计PD控制器#

思路

思路
  • 为消除转速误差引入误差积分状态，先把增广系统按期望极点配置状态反馈，再按观测器极点为转速设计观测器并画完整结构框图。
