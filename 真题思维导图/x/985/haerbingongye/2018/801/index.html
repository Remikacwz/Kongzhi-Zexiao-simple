1一、倒立摆建模与线性化15 分#

思路
  • 把倒立摆视为绕支点转动的刚体，小偏差角下对支点列力矩平衡方程；再取小角度近似线性化，最后作零初始拉氏变换求传递函数并分解零极点。
机械系统建模 建模与机电系统
本卷考法
  • 对倒立摆一类摆动系统按转动定律列力矩平衡方程
本卷实例
  • 关键一步：选转角θ为广义坐标，对支点列转动方程
  • 中间结果：方程含 sinθ 项，小偏差下近似为 θ
  • 卡点：倒立摆结构示意以插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过对倒立摆一类摆动系统按转动定律列力矩平衡方程
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 本卷考过漏掉重力恢复力矩或把转动惯量写成质量
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项

2二、PI控制系统的参数稳定域15 分#

思路
  • 由 PI 控制系统结构图写出闭环特征方程，用劳斯判据列出首列各元非负的不等式组，在 K–K1 平面上画出满足全部不等式的参数区域。
劳斯判据 稳定性分析
本卷考法
  • 由闭环特征方程用劳斯判据判断稳定性
本卷实例
  • 关键一步：先由结构图写出闭环特征多项式
  • 中间结果：劳斯表首列全同号是稳定的充要条件
  • 卡点：含两个参数时边界需逐条分段讨论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由闭环特征方程用劳斯判据判断稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过系数有缺项时不补零直接排劳斯表
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

3三、PID控制系统的参数根轨迹15 分#

思路
  • 把闭环特征方程整理成含可调增益 K 的等效开环形式，按根轨迹法则确定实轴段、分支方向、出射角与入射角，并求与虚轴交点及临界增益。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以可调增益为参变量绘制广义根轨迹
本卷实例
  • 关键一步：把特征方程整理成 1+K 乘等效开环为零的形式
  • 中间结果：等效开环的零点对应系统开环极点
  • 卡点：PID 的积分与微分项固定，只 K 变动
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以可调增益为参变量绘制广义根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 本卷考过整理时没有把参数完整地提到分子位置
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

根轨迹的绘制法则 根轨迹法

  • 卡点：分支起于开环极点、止于开环零点或无穷远

  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称

4四、按性能指标设计校正装置15 分#

思路
  • 按超调量与调整时间要求折算期望闭环极点，用零极点对消思想配置校正装置 Gc(s) 的 K、z、p，使闭环极点落在期望位置并满足两项时域指标。
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量与调节时间要求反求期望闭环极点
本卷实例
  • 关键一步：由超调量定阻尼比、由调节时间定自然频率
  • 中间结果：期望闭环极点由阻尼比与自然频率共同确定
  • 卡点：调节时间系数要与题给误差带对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足

  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错

  • 只满足单项指标就下结论，未做交叉验证

本卷考法

本卷实例

  • 中间结果：对消后被控对象降阶为期望形式
  • 卡点：对消近似成立需保证该极点的主导性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤

  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过用附加开环零极点对消原系统不利极点
