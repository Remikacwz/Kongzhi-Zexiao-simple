1一、信号流图求传函与稳态误差15 分#

思路
  • 先按信号流图用梅森公式求闭环传递函数；再由特征方程用劳斯判据判稳；最后分别求给定与扰动作用下的稳态误差并按叠加原理相加。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图用梅森公式求闭环传递函数
本卷实例
  • 关键一步：先标出各独立回路与前向通路，确认有几条前向通路
  • 中间结果：特征式等于 1 减各回路增益和加两两不接触项
  • 卡点：信号流图以插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图用梅森公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路找漏或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
劳斯判据 稳定性分析
本卷考法
  • 由闭环特征方程用劳斯判据判断稳定性
本卷实例
  • 关键一步：把闭环特征多项式写成降幂排列
  • 中间结果：特征多项式全部系数同号是稳定必要条件
  • 卡点：含参数时首列出现零需改用 ε 法
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由闭环特征方程用劳斯判据判断稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过系数缺项时未补零就排劳斯表
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求给定输入与扰动共同作用下的稳态误差
本卷实例
  • 关键一步：分别令扰动为零、参考输入为零各求一次误差
  • 中间结果：总误差为给定与扰动两个分量相加
  • 卡点：扰动传函求法与给定传函不同，勿混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求给定输入与扰动共同作用下的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 本卷考过扰动误差漏掉负号或输入分量
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

2二、由极点分布求超调与过渡时间15 分#

思路
  • 由极点分布图读出闭环极点的实部与虚部，反求阻尼比与自然频率，再代入二阶系统超调量与调节时间公式。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由极点位置反求阻尼比与自然频率
本卷实例
  • 关键一步：极点实部的绝对值等于阻尼比乘自然频率
  • 中间结果：由实部与虚部之比确定阻尼比
  • 卡点：极点分布图以插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由极点位置反求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过未先化为标准二阶形式
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求欠阻尼二阶系统超调量与过渡过程时间
本卷实例
  • 关键一步：超调量与调节时间都用阻尼比和自然频率表示
  • 中间结果：调节时间按题给误差带取对应系数
  • 卡点：调节时间系数与误差带大小一一对应，勿套错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求欠阻尼二阶系统超调量与过渡过程时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过两种误差带的调节时间系数搞混
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3三、参数根轨迹绘制与特征点15 分#

思路
  • 把特征方程整理成含参变量 T 的等效开环形式，按根轨迹法则确定起点、终点、分离点、出射角与虚轴交点。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以时间常数 T 为参变量画参数根轨迹
本卷实例
  • 关键一步：把含参数项以外的部分移到等式另一边作等效开环
  • 中间结果：等效开环的零点对应原系统的开环极点
  • 卡点：等效开环零点易与原系统开环极点混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以时间常数 T 为参变量画参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 本卷考过未把方程整理成 1 加 T 乘等效开环的形式
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点与会合点
本卷实例
  • 关键一步：令等效开环传函对 s 的导数为零求重根
  • 中间结果：解出的根要逐一验证是否落在根轨迹上
  • 卡点：复数重根常需舍去不用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点与会合点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 本卷考过只解重根方程未剔除不在轨迹上的解
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
出射角与入射角 根轨迹法
本卷考法
  • 求复极点的出射角
本卷实例
  • 关键一步：按相角条件列出各零极点指向待求点的相角
  • 中间结果：出射角等于一百八十度加零点相角减极点相角
  • 卡点：需先判明哪些极点位于复平面
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求复极点的出射角
  • 求复数极点的出射角
  • 根据出射角画出根轨迹起始方向
  • 由入射角确定根轨迹终止方向
常见易错
  • 本卷考过各向量相角累加时符号写错
  • 累加相角时把该极点自身的相角也算进去
  • 忘记判断象限导致角度差 180°

4四、Nyquist图求增益与纯延迟临界值15 分#

思路
  • 无延迟时在给定开环幅相曲线上找相角为负一百八十度的点，由该点幅值反求增益；有延迟时令相角裕度为零求临界延迟。
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环 Nyquist 图反求系统增益
本卷实例
  • 关键一步：在幅相曲线上找相角为负一百八十度的点
  • 中间结果：该点幅值与增益的关系可反求增益
  • 卡点：开环 Nyquist 图以插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环 Nyquist 图反求系统增益
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过曲线与负实轴交点位置读错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
含纯延迟环节的系统稳定性 稳定性分析
本卷考法
  • 求使含延迟系统临界稳定的延迟时间
本卷实例
  • 关键一步：令相角裕度为零建立延迟与频率的方程
  • 中间结果：先由幅值条件求剪切频率再代回相角条件
  • 卡点：延迟相位随频率线性增长，勿当惯性环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 延迟环节 e^{-τs} 的幅值为 1、相位为 -τω，只恶化相位
  • 延迟会显著缩小稳定域，τ 越大越难稳定
  • 频域判据需用相位裕度扣除延迟引起的附加滞后
步骤
  • 写出含延迟的开环传递函数
  • 分别求幅值与相位表达式
  • 在相频特性中扣除 τω 的滞后量
  • 按稳定裕度或奈氏判据求临界 τ 或临界 K
通用考法
  • 本卷考过求使含延迟系统临界稳定的延迟时间
  • 求使系统稳定的最大延迟时间
  • 求含延迟系统的临界开环增益
  • 分析延迟对稳定裕度的影响
常见易错
  • 本卷考过相位计算忘记角度与弧度换算
  • 把延迟环节当成惯性环节处理
  • 相位计算时忘记角度与弧度换算
公式

5五、串联超前校正设计与无源实现15 分#

思路
  • 先由速度误差系数要求定校正增益，再由剪切频率与相角裕度要求算所需超前角并设计超前网络，最后写出无源网络元件与时间常数的关系。
系统型别与静态误差系数 稳态误差
本卷考法
  • 由速度误差系数要求确定校正装置增益
本卷实例
  • 关键一步：令 s 趋于零求 s 乘校正后开环传函的极限
  • 中间结果：由误差系数要求反求串联校正增益
  • 卡点：先满足稳态精度再设计动态校正
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由速度误差系数要求确定校正装置增益
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 本卷考过求速度误差系数时漏乘开环增益
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
超前校正 系统校正
本卷考法
  • 设计串联超前校正使相角裕度与剪切频率达标
本卷实例
  • 关键一步：由要求剪切频率处原系统相角求需超前角
  • 中间结果：由最大超前角公式定参数 a 与时间常数 T
  • 卡点：校正后剪切频率右移，需迭代校验
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
