1电磁-机械系统建模15 分#

思路
  • 电磁线圈产生力 f=Kf·i，运动件又产生反电动势 e=Ke·dy/dt，两个方程联立才能消去电流 i
直流电机等机电系统 建模与机电系统
本卷考法
  • 由衔铁位移控制系统画方框图并求传递函数
本卷实例
  • 关键一步：从线圈欧姆定律入手，把反电动势写进电压平衡式
  • 中间结果：电磁力与电流的转换构成电到力的支路
  • 卡点：原卷图为插图未读，线圈与衔铁连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 反电动势与转速成正比，电磁转矩与电枢电流成正比
  • 机电时间常数由电气与机械两方面参数共同决定
步骤

通用考法

  • 漏掉反电动势与电磁转矩的耦合项

2复合控制与不变性15 分#

思路
  • 输入与扰动都是斜坡 Bt，要 ess=0 就必须同时满足输入不变性与扰动不变性，由此解出 Kd
扰动作用下的稳态误差 稳态误差
本卷考法
  • 输入与扰动同为斜坡时求稳态误差表达式
本卷实例
  • 关键一步：把参考与扰动两条误差通道分别用终值定理作极限
  • 中间结果：稳态误差写成输入幅值与两个误差分量之和
  • 卡点：要把扰动通道的稳态分量一并计入总误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过输入与扰动同为斜坡时求稳态误差表达式
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 本卷考过把扰动误差直接当作总误差，遗漏输入分量
  • 把扰动误差直接当作总误差，遗漏输入分量

本卷考法

本卷实例

3根轨迹与临界稳定15 分#

思路
  • G=K/((s+4)(s²+2s+2)) 一个实极点加一对复极点，n-m=3；临界稳定＝根轨迹与虚轴相交
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制闭环系统根轨迹图
本卷实例
  • 关键一步：由开环极点定实轴段、渐近线夹角与交点
  • 中间结果：三条渐近线交于极点实部均值，夹角按奇数等分
  • 卡点：实轴段按右数奇数个零极点判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制闭环系统根轨迹图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过复极点的出射角算错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求使系统临界稳定的 K 值
本卷实例
  • 关键一步：闭环特征式列劳斯表，令首列出现零元或全零行求临界
  • 中间结果：临界增益由首列元素为零的条件确定
  • 卡点：虚轴交点成对出现，频率取完两组再定位极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求使系统临界稳定的 K 值
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 本卷考过只代一个 ω 漏掉另一组交点
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

出射角与入射角 根轨迹法
本卷考法
  • 由出射角判断复极点处根轨迹的起始方向
本卷实例
  • 关键一步：在复极点处用相角条件补齐各矢量夹角求出射角
  • 中间结果：出射角由其余极点张角与目标相角之和反推得到
  • 卡点：共轭极点出射角互为相反数，符号不要写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过由出射角判断复极点处根轨迹的起始方向
  • 求复数极点的出射角
  • 根据出射角画出根轨迹起始方向
  • 由入射角确定根轨迹终止方向
常见易错
  • 累加相角时把该极点自身的相角也算进去
  • 忘记判断象限导致角度差 180°

4Nyquist 判据判稳15 分#

思路
  • G=8/(s(s+1)(s²+7)) 开环无右半平面极点（P=0），关键是补画积分环节的无穷大圆弧
奈奎斯特判据 稳定性分析
本卷考法
  • 用 Nyquist 判据判定闭环稳定性
  • 不稳定时指出右半平面极点个数
本卷实例
  • 关键一步：先数开环右半平面极点数，再数曲线对临界点的包围圈数
  • 中间结果：开环无右半平面极点时由包围圈数定右半平面极点数
  • 卡点：积分环节需补画无穷大圆弧，方向不能画错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用 Nyquist 判据判定闭环稳定性
  • 本卷考过不稳定时指出右半平面极点个数
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过没有先数开环右半平面极点数 P
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

频率特性的物理意义与求法 频域分析
本卷考法
  • 由 G(s) 写出幅频与相频表达式以作幅相曲线
本卷实例
  • 关键一步：把各典型环节写成幅值相乘、相角相加的形式
  • 中间结果：低频段相位与高频段终值相位决定曲线的走向
  • 卡点：平方因子在小频率处相位翻转要分段讨论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤

  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由 G(s) 写出幅频与相频表达式以作幅相曲线
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错

5谐振峰值与频带指标15 分#

思路
  • 闭环谐振峰值 Mr 与谐振频率 ωr 是闭环频率特性参数，先反求 ξ、ωn 再定 K、a
闭环频率特性与性能指标 频域分析
本卷考法
  • 由 Mr=1.04 与 ωr=41.55 反求 K 和 a
  • 求频带宽度 ωb
本卷实例
  • 关键一步：由谐振峰值关系式反解阻尼比，再由谐振频率定自然频率
  • 中间结果：谐振频率由自然频率与阻尼比的关系式反解
  • 卡点：谐振峰值公式只适用于阻尼比小于零点七零七
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
