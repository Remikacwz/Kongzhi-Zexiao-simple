1一、皮带轮传动系统求传函15 分#

思路
  • 轮 1、轮 2 分别列转动动力学方程，利用皮带无滑动时线速度相等建立转角与转矩的传递关系，消去中间量得 θ2(s)/M(s)。
机械系统建模 建模与机电系统
本卷考法
  • 对两个皮带轮分别列转动方程求传函
本卷实例
  • 关键一步：分别对两轮写转矩减阻力矩等于 J 乘角加速度
  • 中间结果：用转矩关系与线速度相等消去轮 1 转角
  • 卡点：皮带传动关系以插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过对两个皮带轮分别列转动方程求传函
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 本卷考过转矩与半径或转角的传递关系写反
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 整理出输出转角对输入转矩的传递函数
本卷实例
  • 关键一步：对两个转动方程同时取拉氏变换
  • 中间结果：分母为两轮转动惯量与阻尼折算后的二阶式
  • 卡点：转动惯量折算到同一轴，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过整理出输出转角对输入转矩的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

2二、由主导极点配置求增益与反馈系数15 分#

思路
  • 由结构图写开环 G(s) 含增益 k1 与反馈系数 α，令闭环主导极点 s=-3±3j，先用相角条件求 α，再用幅值条件求 k1。
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 用相角条件求反馈系数 α
本卷实例
  • 关键一步：把待定极点代入开环零极点验证相角条件
  • 中间结果：由各向量相角之差解出反馈系数 α
  • 卡点：开环零极点分布以插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过用相角条件求反馈系数 α
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 本卷考过各极点与零点相角逐项累加时符号写错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 用幅值条件求增益 k1
本卷实例
  • 关键一步：写出模值条件，根轨迹增益等于各距离之积
  • 中间结果：把根轨迹增益按传函整理换算成开环增益
  • 卡点：根轨迹增益与开环增益的比例系数易算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过用幅值条件求增益 k1
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 本卷考过模值条件中漏乘某段极点距离
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

3三、组合正弦输入的稳态误差15 分#

思路
  • 先由闭环传函求误差传函 Φe(s)=1-Φ(s)，再对两个正弦分量分别用频率特性求稳态误差分量，最后叠加。
误差定义与误差传递函数 稳态误差
本卷考法
  • 写出单位负反馈系统的误差传递函数
本卷实例
  • 关键一步：由误差传函等于 1 减闭环传函写出表达式
  • 中间结果：化简得分子分母均为一阶因式的有理分式
  • 卡点：求稳态误差前先确认闭环系统稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写出单位负反馈系统的误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 本卷考过非单位反馈时误用 E 等于 R 减 C
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 对每个正弦分量用幅频相频求稳态误差
本卷实例
  • 关键一步：分别代两个角频率求误差频率特性的幅值与相角
  • 中间结果：每个分量误差为同频率的正弦量
  • 卡点：初相应计入相频后再写稳态误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过对每个正弦分量用幅频相频求稳态误差
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过两个频率分量混用同一组幅值与相角
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式

4四、由根轨迹重极点求闭环传函15 分#

思路
  • 由根轨迹与反馈通道零极点写出 H(s) 与 G(s)，闭环特征方程存在重根时用 D(s)=0 与导数为零求重根与增益，再代入求闭环传函。
分离点与会合点 根轨迹法
本卷考法
  • 由闭环特征方程的重根求根轨迹增益
本卷实例
  • 关键一步：重根处同时满足特征方程与导数为零
  • 中间结果：由重根位置解出根轨迹增益
  • 卡点：反馈通道零极点分布为插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由闭环特征方程的重根求根轨迹增益
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 本卷考过只令特征方程为零而未用重根导数条件
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 由开环与反馈通道传函写闭环传递函数
本卷实例
  • 关键一步：按前向通路除以 1 加开环乘积写闭环传函
  • 中间结果：把根轨迹增益按比例换算成前向增益后代入
  • 卡点：前向传函由根轨迹反推，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由开环与反馈通道传函写闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过反馈通道传函未计入闭环分母
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式

5五、Nyquist 判稳与 Bode 图绘制15 分#

思路
  • 开环 G(s)=6(s+1)/[s²(s-1)]，按 Nyquist 判据数包围圈数得右半平面闭环极点数；再由转折频率与斜率画渐近 Bode 图。
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅相曲线判断闭环稳定性并数右半平面极点数
本卷实例
  • 关键一步：先数开环右半平面极点数，再数曲线包围临界点圈数
  • 中间结果：由 Z 等于 P 减 2N 得闭环右半平面极点数
  • 卡点：开环含右半平面极点时包围方向易判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环幅相曲线判断闭环稳定性并数右半平面极点数
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过含积分环节时未补画无穷大半径圆弧
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制开环渐近幅频与相频特性
本卷实例
  • 关键一步：按转折频率列出各段斜率与对应高度
  • 中间结果：低频段斜率与起始高度由积分环节和增益确定
  • 卡点：幅相曲线形状以插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过绘制开环渐近幅频与相频特性
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 本卷考过逐段改斜率时忘记累加而直接替换
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

6六、静态速度误差与串联超前校正15 分#

思路
  • 先用静态速度误差系数 100 定校正装置增益，再在原系统上提高剪切频率并求所需超前角，设计超前网络参数并校验相角裕度。
系统型别与静态误差系数 稳态误差
本卷考法
  • 由静态速度误差系数要求确定校正装置增益
本卷实例
  • 关键一步：令 s 趋于零求 s 乘校正后开环传函的极限
  • 中间结果：由误差系数要求反求串联校正增益
  • 卡点：先满足稳态精度再设计动态校正
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由静态速度误差系数要求确定校正装置增益
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
