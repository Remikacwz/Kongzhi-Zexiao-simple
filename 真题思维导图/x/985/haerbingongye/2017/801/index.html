1一、机电系统建模与方框图15 分#

思路
  • 由电网络方程与机械运动方程联立消去电流得位置对电压的传递函数，再按方程结构画出系统方框图。
直流电机等机电系统 建模与机电系统
本卷考法
  • 机电耦合系统列方程求传递函数
本卷实例
  • 关键一步：电路回路方程与机械力矩平衡方程联立
  • 中间结果：反电动势与电磁力把电与机械两方程耦合
  • 卡点：机电系统示意图以插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由电枢回路电压方程与转矩平衡方程联立
  • 反电动势与转速成正比，电磁转矩与电枢电流成正比
  • 机电时间常数由电气与机械两方面参数共同决定
步骤
  • 写出电枢回路电压平衡方程
  • 写出转矩平衡方程（含负载与粘性摩擦）
  • 消去电枢电流，得到转速或转角对电压的传递函数
通用考法
  • 本卷考过机电耦合系统列方程求传递函数
  • 求直流电机转速或位置对电枢电压的传递函数
  • 分析机电时间常数与电气时间常数的数量级关系
常见易错
  • 本卷考过漏掉反电动势或电磁力的耦合项
  • 漏掉反电动势与电磁转矩的耦合项
  • 把电气时间常数与机电时间常数混淆
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 消去中间电流变量求输出对输入的传递函数
本卷实例
  • 关键一步：对两个方程取拉氏变换后消去电流变量
  • 中间结果：分母为电感质量等参数构成的三阶式
  • 卡点：输入处放大器倍数要保留
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过消去中间电流变量求输出对输入的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过零初始条件说漏
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 按方程组信号流向画系统方框图
本卷实例
  • 关键一步：每个方程对应一个相加点与一个积分环节
  • 中间结果：耦合项画成前馈或反馈支路
  • 卡点：方框图以插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过按方程组信号流向画系统方框图
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过反馈极性画反
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、参数选择满足误差与动态指标15 分#

思路
  • 由结构图写闭环传函，把稳态误差要求化为增益关系，再由阻尼比与调节时间要求定另一参数，最后取交集。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由斜坡输入稳态误差要求约束参数
本卷实例
  • 关键一步：由速度误差系数等于斜坡误差的倒数建立不等式
  • 中间结果：稳态误差要求给出增益与反馈系数的关系
  • 卡点：先确认闭环系统稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由斜坡输入稳态误差要求约束参数
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过求速度误差系数时漏乘开环增益
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函求阻尼比与自然频率
本卷实例
  • 关键一步：与标准二阶形式逐项对比系数
  • 中间结果：阻尼比由一次项系数与自然频率之比决定
  • 卡点：开环增益影响自然频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过未把 s 平方项系数归一化
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由调节时间要求反求参数
本卷实例
  • 关键一步：调节时间与阻尼比乘自然频率成反比
  • 中间结果：按给定误差带取对应系数列方程
  • 卡点：与阻尼比要求联合求解后取交集
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由调节时间要求反求参数
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过两种误差带对应的调节时间系数搞混
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式

3三、根轨迹法校正满足多项指标15 分#

思路
  • 把稳态误差要求化为开环增益要求，再由超调量与调节时间确定希望主导极点，用根轨迹法配置合适的零极点使轨迹通过该点。
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 用根轨迹法由希望主导极点设计校正
本卷实例
  • 关键一步：由超调量与调节时间定希望主导极点
  • 中间结果：原根轨迹不过该点需加校正零极点
  • 卡点：校正零极点要靠近，折中稳态与动态
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过用根轨迹法由希望主导极点设计校正
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 本卷考过希望主导极点的相角条件未校验
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法

本卷实例
  • 关键一步：由超调量反求阻尼比，由调节时间反求自然频率
  • 中间结果：希望极点实部为负阻尼比乘自然频率
  • 卡点：加速度误差要求还要同时满足开环增益

  • 振荡次数与 ξ 直接相关
步骤

  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量和调节时间确定希望极点位置
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过调节时间系数套错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

4四、根轨迹绘制与临界参数15 分#

思路
  • 对象为两个共轭复极点对，按绘制法则画根轨迹，令闭环特征方程出现纯虚根求临界增益，再对分离点用重根条件求增益与阻尼比。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制无实极点四阶系统的根轨迹
本卷实例
  • 关键一步：由极点数与零点数确定渐近线夹角
  • 中间结果：复极点出射角按相角条件求
  • 卡点：四阶系统根轨迹对称于实轴
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制无实极点四阶系统的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过渐近线与出射角计算错误
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点求临界开环增益
本卷实例
  • 关键一步：令 s 等于 jω 代入闭环特征方程
  • 中间结果：分离实部虚部为零解出频率与参数
  • 卡点：与虚轴交点处的增益即临界增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹与虚轴交点求临界开环增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 本卷考过把根轨迹增益与开环增益换算搞反
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
分离点与会合点 根轨迹法
本卷考法
  • 由分离点条件求对应参数与阻尼比
本卷实例
  • 关键一步：令闭环特征方程与其导数同时为零
  • 中间结果：分离点处对应重根，可求阻尼比
  • 卡点：分离点可能成对出现在实轴上
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由分离点条件求对应参数与阻尼比
  • 求根轨迹的分离点坐标

  • 卡点：临界情形下一阶线性化不能判定稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过非线性系统平衡点附近线性化的适用性
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 本卷考过忽略线性化只反映邻域性质
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定

10十、能控性判别与结构分解15 分#

思路
  • 先由能控判别阵的秩判断能控性，若不控则求变换矩阵把系统按能控性分解为能控与不能控两个子系统。
能控性与能观性 状态空间分析
本卷考法
  • 由能控判别阵的秩判别系统能控性
本卷实例
  • 关键一步：由 B、AB、A 平方 B 组成能控判别阵
  • 中间结果：判别阵秩小于系统阶数即为不完全能控
  • 卡点：秩亏时要找线性无关列确定变换阵
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过由能控判别阵的秩判别系统能控性
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 本卷考过判别阵按列还是按行构造搞反
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
