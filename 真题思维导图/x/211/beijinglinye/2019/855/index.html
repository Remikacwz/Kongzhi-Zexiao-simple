一一、信号流图求传递函数#

思路
  • 由结构图的信号流图数清独立回路、前向通路与相互接触关系，用梅森增益公式写出 C(s)/R(s)。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图数回路与前向通路，用梅森公式求传函
本卷实例
  • 关键一步：先数独立回路并判断两两之间是否接触
  • 关键一步：再写特征式与各前向通路的余子式
  • 中间结果：特征式含四条独立回路
  • 中间结果：分子为唯一前向通路乘其余子式
  • 卡点：回路增益正负号与接触关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图数回路与前向通路，用梅森公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

二二、给定与扰动共同作用下的稳态误差及稳定K范围#

思路
  • 先求输入与扰动分别作用下的误差传函并叠加得稳态误差；再列闭环特征方程的劳斯表，求使系统稳定的 K 取值范围。
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动 n(t) 单独作用下的稳态误差
本卷实例
  • 关键一步：令参考输入为零，单独求扰动到误差的传函
  • 中间结果：扰动误差由终值定理求得
  • 卡点：局部反馈化简后的等效传函须核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求扰动 n(t) 单独作用下的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由闭环特征方程求使系统稳定的 K 范围
本卷实例
  • 关键一步：把闭环特征方程降幂排列后列劳斯表
  • 中间结果：首列含 K 的一次式，稳定条件化为 K 的上界不等式
  • 卡点：闭环传函由结构图化简得出，须核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由闭环特征方程求使系统稳定的 K 范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

三三、根轨迹绘制与稳定K范围#

思路
  • 求开环极点、实轴根轨迹段、渐近线与出射角，画 0<K<∞ 的闭环根轨迹；再由与虚轴交点求稳定 K 范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制 0<K<∞ 的闭环根轨迹
本卷实例
  • 关键一步：先求开环极点并判断实轴上的根轨迹段
  • 中间结果：渐近线交点与夹角由开环极点数确定
  • 卡点：复数极点的出射角方向须核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制 0<K<∞ 的闭环根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点确定稳定 K 范围
本卷实例
  • 关键一步：列劳斯表并令首列元素为零求临界 K
  • 中间结果：交点频率由代回特征方程解得
  • 卡点：临界 K 须代回原特征方程复核
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹与虚轴交点确定稳定 K 范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

四四、正弦输入下的稳态误差#

思路
  • 写出闭环误差传函，求其在输入角频率处的幅值与相角，按频率特性写出正弦稳态误差的表达式。
误差定义与误差传递函数 稳态误差
本卷考法
  • 写出误差传递函数并求其频率特性
本卷实例
  • 关键一步：由闭环传函写出误差传函并取 s 等于 jω
  • 中间结果：误差传函在输入频率处的幅相即误差幅值与相位
  • 卡点：须先确认闭环稳定再使用频率特性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写出误差传递函数并求其频率特性
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求指定频率处误差传函的幅值与相角
本卷实例
  • 关键一步：把输入角频率代入误差传函取模与相角
  • 中间结果：正弦误差幅值为输入幅值乘误差幅频
  • 卡点：相角累加别漏积分环节的负九十度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求指定频率处误差传函的幅值与相角
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式

五五、奈氏判据确定稳定K范围#

思路
  • 求开环幅相曲线的起点、终点与实轴交点，按奈氏判据列包围条件，确定使闭环稳定的 K 范围。
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅相曲线用奈氏判据求稳定 K 范围
本卷实例
  • 关键一步：先数开环右半平面极点数并求曲线与负实轴交点
  • 中间结果：实轴交点横坐标随 K 线性缩放
  • 卡点：相角随频率的走向须核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环幅相曲线用奈氏判据求稳定 K 范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式

六六、Bode图、对数稳定判据与相角裕度#

思路
  • 按低频段斜率与各转折频率画对数幅频渐近线，求截止频率与相角裕度，并用对数稳定判据判稳。
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制开环对数渐近幅频特性
本卷实例
  • 关键一步：按低频段斜率与各转折频率逐段改斜率
  • 中间结果：转折频率处斜率依次累加
  • 卡点：低频段起始高度须按系统型别折算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过绘制开环对数渐近幅频特性
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

稳定裕度 频域分析
本卷考法
  • 求截止频率与相角裕度
本卷实例
  • 关键一步：令对数幅频为零求截止频率后算相角裕度
  • 中间结果：相角裕度为一百八十度加截止频率处相角
  • 卡点：相角裕度为负说明闭环不稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求截止频率与相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

七七、离散系统脉冲传函与稳定条件#

思路
  • 由含零阶保持器的开环通道求开环脉冲传函，再求闭环脉冲传函；令闭环特征根模小于一，证明稳定条件。
脉冲传递函数 离散控制系统
本卷考法
  • 求开环与闭环脉冲传递函数
本卷实例
  • 关键一步：把零阶保持器与连续环节合并后作 z 变换
  • 中间结果：开环 G(z) 分母含 e 的负采样周期次幂
  • 卡点：零阶保持器不能漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
