一一、单项选择题20 分#

思路
  • 十道选择逐题独立：稳态误差说法、稳定性前提、开环与反馈控制依据、闭环特征方程、相角裕度对应时域指标、劳斯判据、型别与无穷误差、校正装置类型、最大超前角、二型系统组合输入的稳态误差。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 比较开环与反馈控制方式并区分其控制依据
本卷实例
  • 关键一步：稳定性是系统正常工作的先决条件
  • 关键一步：开环按给定量、反馈按偏差控制
  • 中间结果：两种控制方式的依据要一一对应
  • 卡点：把开环与反馈的控制依据写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过比较开环与反馈控制方式并区分其控制依据
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
传递函数的定义与基本性质 传递函数
本卷考法
  • 由负反馈开环传函写出闭环特征方程
本卷实例
  • 关键一步：负反馈闭环分母取一加开环传函
  • 中间结果：特征方程由分母多项式置零得到
  • 卡点：负反馈分母误写成一减开环传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由负反馈开环传函写出闭环特征方程
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

稳定裕度 频域分析
本卷考法
  • 指出相角裕度所对应的时域性能指标
本卷实例
  • 关键一步：相角裕度表征相对稳定性并关联超调量
  • 中间结果：裕度减小时阶跃响应超调量总体增大
  • 卡点：把相角裕度与稳态误差直接对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过指出相角裕度所对应的时域性能指标
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
劳斯判据 稳定性分析
本卷考法
  • 由三阶特征方程用劳斯表判断稳定性
本卷实例
  • 关键一步：按特征方程系数列劳斯表看首列符号
  • 中间结果：首列各元同号时闭环稳定
  • 卡点：首列出现零元时未用辅助方程处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由三阶特征方程用劳斯表判断稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

系统型别与静态误差系数 稳态误差
本卷考法
  • 由型别判断一型系统跟踪斜坡输入时的误差
本卷实例
  • 关键一步：先数开环积分环节个数定系统型别
  • 关键一步：一型系统跟踪斜坡有有限非零误差
  • 中间结果：型别决定误差对给定输入是否发散
  • 卡点：把一型系统的斜坡误差当成零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由型别判断一型系统跟踪斜坡输入时的误差
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 分析增大开环增益与增加积分环节对误差和稳定的影响
本卷实例
  • 关键一步：增大增益减小误差却降低相对稳定性
  • 关键一步：增加积分环节消误差同时可能破坏稳定
  • 中间结果：精度与稳定性之间需要折中考虑
  • 卡点：只答误差减小而漏答稳定性变差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过分析增大开环增益与增加积分环节对误差和稳定的影响
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求二型系统在阶跃、斜坡与抛物线组合输入下的误差
本卷实例
  • 关键一步：按组合输入各分量分别套静态误差系数
  • 中间结果：含 s 平方项的系统按二型系统处理
  • 卡点：组合输入时漏掉抛物线分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求二型系统在阶跃、斜坡与抛物线组合输入下的误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

滞后校正 系统校正
本卷考法
  • 由串联校正装置传函判断其属于滞后校正
本卷实例
  • 关键一步：化为时间常数形式比较零点与极点转折频率
  • 中间结果：极点转折频率低于零点时呈滞后特性
  • 卡点：把超前与滞后的判据方向记反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过由串联校正装置传函判断其属于滞后校正
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

超前校正 系统校正
本卷考法
  • 比较各超前装置在指定频率处提供的超前角大小
本卷实例
  • 关键一步：代入最大超前角所在几何中点频率计算
  • 中间结果：最大超前角由两转折频率之比决定
  • 卡点：只看分子时间常数而不比较转折频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过比较各超前装置在指定频率处提供的超前角大小
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

误差定义与误差传递函数 稳态误差
本卷考法
  • 判断稳态误差非零是否等同于系统存在误差
本卷实例
  • 关键一步：稳态误差是过渡结束后的残余偏差量
  • 中间结果：误差非零只说明系统属于有差系统
  • 卡点：把误差非零误解为系统发生故障
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过判断稳态误差非零是否等同于系统存在误差
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 判断一阶系统时间常数增大对响应快慢的影响
本卷实例
  • 关键一步：时间常数对应闭环极点离虚轴距离的倒数
  • 中间结果：时间常数越大过渡过程越慢
  • 卡点：把时间常数与响应速度说成正比
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
