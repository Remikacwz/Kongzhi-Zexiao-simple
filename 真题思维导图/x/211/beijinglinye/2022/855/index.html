一一、简答题20 分#

思路
  • 四问分别答开环与闭环控制的优缺点、稳态误差的概念与类型、四种由开环传函判别闭环稳定性的方法、积分环节的频率特性与极坐标图。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 比较开环与闭环控制系统的优缺点
本卷实例
  • 关键一步：按精度、抗扰、结构与成本逐项对比
  • 关键一步：闭环靠偏差控制换取精度与抗扰
  • 中间结果：闭环精度高、抗扰强但结构与调试复杂
  • 卡点：答题须同时给优点与缺点，别只答一面
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过比较开环与闭环控制系统的优缺点
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
误差定义与误差传递函数 稳态误差
本卷考法
  • 说明稳态误差的概念及其类型
本卷实例
  • 关键一步：把稳态误差定义为过渡结束后的残余偏差
  • 中间结果：按给定值误差与扰动误差两类归纳
  • 卡点：稳态误差是有差系统的固有量，别与动态误差混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过说明稳态误差的概念及其类型
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

劳斯判据 稳定性分析
本卷考法
  • 列举劳斯判据作为由开环传函判稳的方法之一
本卷实例
  • 关键一步：把特征方程系数排成劳斯表看首列符号
  • 中间结果：首列全同号则闭环稳定
  • 卡点：系数有缺项须补零后再列劳斯表
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过列举劳斯判据作为由开环传函判稳的方法之一
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
赫尔维茨判据 稳定性分析
本卷考法
  • 列举赫尔维茨判据作为由开环传函判稳的方法之一
本卷实例
  • 关键一步：由特征方程系数构造赫尔维茨行列式
  • 中间结果：各阶主子式均大于零时系统稳定
  • 卡点：判据只需检验到比阶数小一阶的主子式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由特征方程系数构造赫尔维茨行列式
  • 各阶主子式全部大于零 ⇔ 系统稳定
  • 与劳斯判据等价，适合阶数较低时使用
步骤
  • 由特征方程系数写出赫尔维茨行列式
  • 依次计算各阶主子式
  • 令全部主子式大于零得到稳定条件
通用考法
  • 本卷考过列举赫尔维茨判据作为由开环传函判稳的方法之一
  • 用赫尔维茨判据判断稳定性
  • 比较两种代数判据的适用场合
常见易错
  • 行列式构造时系数下标写错
  • 只验证到二阶主子式就下结论

奈奎斯特判据 稳定性分析
本卷考法
  • 列举奈奎斯特判据作为由开环传函判稳的方法之一
本卷实例
  • 关键一步：画开环幅相曲线并数包围临界点的圈数
  • 中间结果：先数开环右半平面极点数再套包围关系
  • 卡点：开环含积分环节时须补画无穷大圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过列举奈奎斯特判据作为由开环传函判稳的方法之一
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 列举根轨迹法作为由开环传函判稳的方法之一
本卷实例
  • 关键一步：由开环零极点画根轨迹看分支所在半平面
  • 中间结果：根轨迹全部位于左半平面时闭环稳定
  • 卡点：有分支进入右半平面即不稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过列举根轨迹法作为由开环传函判稳的方法之一
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

频率特性的物理意义与求法 频域分析
本卷考法
  • 说明积分环节的频率特性并画极坐标图
本卷实例
  • 关键一步：写出积分环节的幅频与相频表达式
  • 中间结果：幅频与频率成反比、相角恒为负九十度
  • 卡点：极坐标图是沿负虚轴指向原点的直线
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过说明积分环节的频率特性并画极坐标图
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

二二、填空题20 分#

思路
  • 十空覆盖全响应分量、Bode 与奈氏图对应、根轨迹相同条件、积分环节幅频、抛物线输入稳态误差、一阶系统相角裕度与幅值裕量、开闭环稳定性关系、极点位置与响应速度、校正环节类型。
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 填空1：写全响应包含的两个分量
本卷实例
  • 关键一步：把线性系统全响应按来源拆成两部分
  • 中间结果：分别对应暂态分量与稳态分量
  • 卡点：暂态分量由极点决定，稳态分量由输入形式决定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过填空1：写全响应包含的两个分量
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 填空5：求组合开环传函在抛物线输入下的稳态误差
本卷实例
  • 关键一步：先判系统型别再套对应静态误差系数
  • 中间结果：误差由误差传函零频极限与输入变换共同决定
  • 卡点：开环含 s 平方项时应按二型系统处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤

  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量

  • 输入为组合信号时漏掉某一分量

稳定裕度 频域分析
本卷考法
  • 填空6、9：求一阶开环系统的相角裕度与幅值裕量
本卷实例
  • 关键一步：相角裕度由剪切频率处相角算
  • 关键一步：幅值裕量由相位穿越频率处幅值取倒数
  • 中间结果：一阶开环的相角恒为负九十度
  • 卡点：幅值裕量为无穷说明曲线不穿越负实轴
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
