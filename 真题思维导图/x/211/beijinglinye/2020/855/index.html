一一、信号流图求传递函数15 分#

思路
  • 由结构图的信号流图数清四条回路与两两不接触回路，用梅森增益公式写出 C(s)/R(s)。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图用梅森公式求闭环传函
本卷实例
  • 关键一步：先数独立回路并找两两不接触回路
  • 中间结果：特征式含四条回路与一对不接触回路
  • 卡点：比较点极性须回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图用梅森公式求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

二二、典型输入下的稳态误差10 分#

思路
  • 由闭环传函求误差传函，按输入的阶跃、斜坡、抛物线三个分量分别算稳态误差再叠加。
系统型别与静态误差系数 稳态误差
本卷考法
  • 判断系统型别并求各静态误差系数
本卷实例
  • 关键一步：先由开环传函数积分环节个数定型别
  • 中间结果：型别决定各分量稳态误差是否为零
  • 卡点：须先判稳再用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断系统型别并求各静态误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求组合多项式输入下的总稳态误差
本卷实例
  • 关键一步：把输入拆成阶跃、斜坡、抛物线三项分别求
  • 中间结果：总误差为三个分量稳态误差之和
  • 卡点：抛物线分量的误差可能发散
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求组合多项式输入下的总稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

三三、由微分方程求响应与动态指标10 分#

思路
  • 由微分方程写传递函数，化为二阶标准形式求阻尼比与自然频率，再求脉冲、阶跃响应与各项动态指标。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由微分方程化为二阶标准形式并读阻尼比
本卷实例
  • 关键一步：把传递函数分母首项系数归一化后对比标准式
  • 中间结果：特征多项式对应无阻尼自然频率与阻尼比
  • 卡点：别把开环增益当成闭环标准式系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由微分方程化为二阶标准形式并读阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求超调量、峰值时间与调整时间
本卷实例
  • 关键一步：由阻尼比与自然频率代入二阶指标公式
  • 中间结果：超调量只由阻尼比决定
  • 卡点：调整时间取百分之五还是二误差带须看题意
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求超调量、峰值时间与调整时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

四四、等幅振荡确定系统参数15 分#

思路
  • 由阶跃响应等幅振荡知闭环有一对纯虚极点，列劳斯表令临界行首元为零求参数。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求临界振荡条件下的参数
本卷实例
  • 关键一步：先写闭环特征方程并列劳斯表
  • 中间结果：临界行首元为零对应一对纯虚根
  • 卡点：参数须代回特征方程复核
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求临界振荡条件下的参数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由虚轴交点频率确定待定参数
本卷实例
  • 关键一步：把纯虚根代回特征方程分离实部与虚部
  • 中间结果：实部虚部两式联立解出两个参数
  • 卡点：别漏掉非零这一约束条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由虚轴交点频率确定待定参数
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

五五、闭环极点判断与给定阻尼比10 分#

思路
  • 把候选点代入相角条件或特征方程判断是否为闭环极点；再由给定阻尼比用极点关系式求闭环极点。
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 用相角条件判断给定点是否为闭环极点
本卷实例
  • 关键一步：把候选点代入开环相角条件检验
  • 中间结果：或直接代入闭环特征方程验证
  • 卡点：闭环极点须同时满足幅值与相角条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过用相角条件判断给定点是否为闭环极点
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

六六、根轨迹绘制与稳定K*范围15 分#

思路
  • 求开环极点、渐近线与分离点，画 K* 从零到无穷的根轨迹；再由与虚轴交点定稳定 K* 范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制 K* 从零到无穷的根轨迹
本卷实例
  • 关键一步：先标开环极点并求实轴根轨迹段
  • 中间结果：渐近线交点在实轴负半轴
  • 卡点：分离点取舍须核对根轨迹图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制 K* 从零到无穷的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

七七、奈氏判据确定稳定K范围15 分#

思路
  • 求开环幅相曲线的起点、终点与负实轴交点，按奈氏判据列包围条件确定使闭环稳定的 K 范围。
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅相曲线用奈氏判据求稳定 K 范围
本卷实例
  • 关键一步：先数开环右半平面极点数并求曲线与负实轴交点
  • 中间结果：负实轴交点坐标随 K 线性缩放
  • 卡点：曲线随频率的走向须核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环幅相曲线用奈氏判据求稳定 K 范围

稳定裕度 频域分析
本卷考法
  • 求相角裕度与幅值裕度并判稳
本卷实例
  • 关键一步：令对数幅频为零求截止频率处相角裕度
  • 中间结果：再由相频穿越负一百八十度处求幅值裕度
  • 卡点：幅值裕度小于一说明闭环不稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求相角裕度与幅值裕度并判稳
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
