一一、梅森增益公式求传递函数#

思路
  • 由结构图的信号流图数清独立回路、两两不接触回路与前向通路，用梅森增益公式写出 C(s)/R(s)；再由无稳态误差要求确定待定参数或补偿环节。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图数回路与前向通路，用梅森公式求传递函数
本卷实例
  • 关键一步：先数独立回路并检查两两是否接触
  • 关键一步：再写特征式与各前向通路的余子式
  • 中间结果：特征式含四条回路与一对两两不接触回路
  • 中间结果：分子为唯一前向通路乘其余子式
  • 卡点：题面含原卷插图，回路条数与增益符号需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图数回路与前向通路，用梅森公式求传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

减小稳态误差的措施 稳态误差
本卷考法
  • 由无稳态误差要求反求待定参数或补偿环节
本卷实例
  • 关键一步：先写误差传递函数再令其零频极限为零
  • 中间结果：条件化为待定参数满足的一个代数等式
  • 卡点：源文该问为参考题，题意须回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过由无稳态误差要求反求待定参数或补偿环节
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

二二、闭环极点判断与稳定性#

思路
  • 以开环传函写出闭环特征方程，把候选点代入相角条件或特征方程判断其是否为闭环极点；再由特征方程系数条件判断系统的稳定性。
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 用根轨迹相角条件判断给定点是否为闭环极点
本卷实例
  • 关键一步：把候选点代入开环相角条件检验是否满足百八十度
  • 关键一步：或直接代入闭环特征方程验证
  • 中间结果：候选点不满足相角条件即不是闭环极点
  • 卡点：题面缺「二」标题，据同册答案段判为第二块
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过用根轨迹相角条件判断给定点是否为闭环极点
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

参数稳定域的确定 稳定性分析
本卷考法
  • 由闭环特征方程求使系统稳定的参数范围
本卷实例
  • 关键一步：写出闭环特征方程后按各系数为正定稳定条件
  • 中间结果：稳定条件化为对开环增益的不等式
  • 卡点：开环增益符号与参数定义须回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由闭环特征方程求使系统稳定的参数范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

三三、由单位阶跃响应求二阶开环传函#

思路
  • 由响应曲线读超调量、由调节时间反推阻尼比与自然频率，再按典型二阶系统写闭环传函并反推开环传递函数。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由阶跃响应曲线与性能指标反求二阶系统传函
本卷实例
  • 关键一步：先由曲线读超调量再按性能公式反解参数
  • 中间结果：闭环传函化为含阻尼比与自然频率的标准形式
  • 卡点：曲线读数须回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由阶跃响应曲线与性能指标反求二阶系统传函
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与调节时间反求阻尼比与自然频率
本卷实例
  • 关键一步：超调量只由阻尼比决定，先解阻尼比
  • 中间结果：再由调节时间公式解出自然频率
  • 卡点：调节时间取5%还是2%误差带须核对题面
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与调节时间反求阻尼比与自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

四四、由 Bode 图求开环传函#

思路
  • 由对数幅频特性的低频段高度与各转折频率确定开环增益与各典型环节，写出最小相位系统的开环传递函数。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频特性曲线反求最小相位系统传函
本卷实例
  • 关键一步：由各转折频率确定一阶环节的时间常数
  • 中间结果：低频段高度给出开环增益
  • 卡点：转折频率与低频高度须回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频特性曲线反求最小相位系统传函
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

五五、由奈奎斯特曲线求稳定 k* 范围#

思路
  • 由给定的奈奎斯特曲线与已知 k*，按各特征频率点处的幅值缩放关系列不等式，确定闭环稳定时 k* 的取值范围。
奈奎斯特判据 稳定性分析
本卷考法
  • 由奈奎斯特曲线求使闭环稳定的开环增益范围
本卷实例
  • 关键一步：按已知增益把曲线各点幅值换算到待求增益下
  • 中间结果：稳定条件化为各特征点幅值大小的一组不等式
  • 卡点：题面图为示意，穿越点幅值须回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由奈奎斯特曲线求使闭环稳定的开环增益范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据确定使系统稳定的反馈参数范围
本卷实例
  • 关键一步：把闭环特征方程降幂排列后列劳斯表
  • 中间结果：首列各元素含待求反馈参数
  • 卡点：首列元素须保持全部同号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤

  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法

  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

七七、极点配置与给定/扰动无稳态误差补偿#

思路
  • 由期望闭环极点代入特征方程求待定增益；再设计前向通道补偿 G1(s) 与 G2(s)，分别实现给定输入与扰动输入下无稳态误差。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由期望闭环极点位置求系统待定增益
本卷实例
  • 关键一步：把期望极点代入闭环特征方程并令其成立
  • 中间结果：比较实部与虚部得到关于待定增益的方程
  • 卡点：一对共轭极点对应两个方程都要满足
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由期望闭环极点位置求系统待定增益
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

减小稳态误差的措施 稳态误差
本卷考法
  • 设计补偿环节使给定输入单独作用下无稳态误差
本卷实例
  • 关键一步：写出给定输入的误差传函并令其满足无静差条件
  • 中间结果：补偿环节由误差传函的分子结构反推
  • 卡点：补偿通道与反馈通道接法须回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计补偿环节使给定输入单独作用下无稳态误差
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

扰动作用下的稳态误差 稳态误差
本卷考法
  • 设计补偿环节使扰动单独作用下无扰动误差
本卷实例
  • 关键一步：令给定为零，单独求扰动到误差的传递函数
  • 中间结果：令扰动误差传函恒为零反解补偿环节
  • 卡点：别把给定通道的增益混进扰动误差传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过设计补偿环节使扰动单独作用下无扰动误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
