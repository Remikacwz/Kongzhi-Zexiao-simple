本卷考法

本卷实例

  • 中间结果：只有线性定常系统才能用传递函数或脉冲响应完整表征

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）

劳斯判据 稳定性分析
本卷考法
  • 判断9考劳斯判据的结论及其与奈奎斯特判据的关系
本卷实例
  • 关键一步：两种判据面对同一特征方程，比较的是同一右半平面极点数
  • 中间结果：代数判据与频域判据给出的稳定结论应当一致
  • 卡点：不要把判据方法不同误当成结论可以相反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过判断9考劳斯判据的结论及其与奈奎斯特判据的关系
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

奈奎斯特判据 稳定性分析
本卷考法
  • 判断9从频域判据角度核对稳定结论是否一致
本卷实例
  • 关键一步：由开环幅相曲线按包围圈数判断闭环右半平面极点数
  • 中间结果：奈奎斯特判据与劳斯判据对同一系统给出相同的稳定性
  • 卡点：忘记补画虚轴上极点对应的绕行会算错包围圈数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过判断9从频域判据角度核对稳定结论是否一致
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据

  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过判断10考连续系统稳定时离散化后能否保持稳定
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

梅森增益公式与信号流图 传递函数
本卷考法
  • 选择3判断信号流图中源节点的定义
本卷实例
  • 关键一步：看节点上只有输入支路还是只有输出支路
  • 中间结果：源节点只有信号输出，阱节点只有信号输入
  • 卡点：输入点与只有输出支路是同一表述，容易读反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
