一（1~4）一、填空：响应求传函、裕度与状态空间#

思路
  • 四空分别考线性系统响应叠加、最大相角裕度、状态方程镇定性/能观性与状态转移矩阵反求。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应与稳态值反求系统传递函数（第 1 空）
本卷实例
  • 关键一步：由单位阶跃响应的稳态值与输入幅值之比得闭环增益
  • 中间结果：传递函数由 h(t) 的拉氏变换与阶跃输入拉氏变换之比得到
  • 卡点：把响应稳态值当成时间常数，或漏掉输入幅值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应与稳态值反求系统传递函数（第 1 空）
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 求矩形脉冲输入下线性系统的零初始输出（第 1 空）
本卷实例
  • 关键一步：把矩形脉冲分解为两个阶跃叠加，利用线性系统叠加原理
  • 中间结果：输出为 h(t) 与其延迟 h(t-1) 之差再乘脉冲幅值
  • 卡点：只求零状态响应忽略延迟项，或把脉冲当冲激
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过求矩形脉冲输入下线性系统的零初始输出（第 1 空）
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

稳定裕度 频域分析
本卷考法
  • 求使相角裕度最大时的开环增益 K 与最大裕度（第 2 空）
本卷实例
  • 关键一步：先写相频表达式，求相角裕度取最大时的截止频率
  • 中间结果：由反正切式配方求极大值，再由幅值条件定 K
  • 卡点：把相角裕度公式中的 180 度基准弄错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求使相角裕度最大时的开环增益 K 与最大裕度（第 2 空）
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

能控性与能观性 状态空间分析
本卷考法
  • 判断状态方程渐近稳定条件与系统可观测条件（第 3 空）
本卷实例
  • 关键一步：由状态矩阵特征值实部全负得渐近稳定，由能观性矩阵满秩得可观
  • 中间结果：由特征值实部全负列 a 约束，由能观性矩阵行列式非零列另一约束
  • 卡点：只算特征方程不检查能观性矩阵的行列式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断状态方程渐近稳定条件与系统可观测条件（第 3 空）
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

状态转移矩阵 状态空间分析
本卷考法
  • 由状态转移矩阵反求系统矩阵 A（第 4 空）
本卷实例
  • 关键一步：对状态转移矩阵在 t 等于 0 处求导得系统矩阵 A
  • 中间结果：矩阵逐元素求导后取 t 等于 0 即可读出 A 各元素
  • 卡点：对矩阵逐元素求导时漏项或符号出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过由状态转移矩阵反求系统矩阵 A（第 4 空）
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错
公式
连续系统的离散化 离散控制系统
本卷考法
  • 求 T 等于 ln2 时的离散化系统矩阵（第 4 空）
本卷实例
  • 关键一步：离散化矩阵为 e 的 AT 次方，把 T 代入状态转移矩阵
  • 中间结果：T 等于 ln2 代回后指数项化简为 1/2 的幂次
  • 卡点：把 ln2 当成 1.2，或直接代时间常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离散化状态方程由状态转移矩阵在采样周期处的取值构成
  • 输入矩阵是状态转移矩阵与输入矩阵乘积在采样周期上的积分
  • 带零阶保持器时即按上述积分式离散化，输出矩阵不变
步骤
  • 求连续系统的状态转移矩阵
  • 把采样周期代入得到离散状态矩阵
  • 对输入矩阵做积分得到离散输入矩阵
  • 写出差分形式的离散状态方程并按递推求采样点上的响应
通用考法
  • 本卷考过求 T 等于 ln2 时的离散化系统矩阵（第 4 空）
  • 求连续系统在给定采样周期下的离散化状态方程
  • 由给出的状态响应反求系统矩阵再离散化
  • 计算采样点上的状态与输出序列
常见易错
  • 把采样周期直接当成时间常数代进连续传函
  • 积分上限写成采样周期以外的量，或忘记乘输入矩阵

二二、结构图求 C(s)/R(s)、C(s)/N(s) 与扰动不变性#

思路
  • 按梅森公式分别求参考输入与扰动输入传函，再由不变性条件求补偿关系。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式化简多回路结构图（第 1、2 问）
本卷实例
  • 关键一步：先列全部回路增益与不接触组合，再写两条前向通路
  • 中间结果：特征式为回路贡献的组合，分子为前向通路乘余子式之和
  • 卡点：余子式中未剔除与前向通路接触的回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式化简多回路结构图（第 1、2 问）
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求参考输入与扰动输入分别作用下的传函及扰动不变性条件（第 1~3 问）
本卷实例
  • 关键一步：求扰动传函时把参考输入置零，分别列回路与通路
  • 关键一步：令扰动传函恒为零，得前向通道与反馈通道的匹配条件
  • 中间结果：C/R 与 C/N 分母相同，分子由各自通路决定
  • 卡点：两个输入同时存在时直接叠加却未验证线性性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求参考输入与扰动输入分别作用下的传函及扰动不变性条件（第 1~3 问）
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

三三、比例负反馈校正对二阶系统性能的影响#

思路
  • 由结构图与阶跃响应曲线求原系统及校正后闭环传函、kp 与调节时间，再定性比较。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由结构图求原系统闭环传函并由响应曲线定参数（第 1、2 问）
本卷实例
  • 关键一步：由阶跃响应超调量与峰值定阻尼比，再由响应求自然频率
  • 中间结果：原系统闭环传函分母为标准二阶形式，kp 由闭环增益匹配
  • 卡点：化为标准二阶形式时忘记把 s² 项系数归一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由结构图求原系统闭环传函并由响应曲线定参数（第 1、2 问）
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由闭环传函求 5% 误差带的调节时间（第 1、2 问）
本卷实例
  • 关键一步：按阻尼比与自然频率套 5% 误差带调节时间近似公式
  • 中间结果：原系统与校正后系统的调节时间由各自阻尼比与自然频率算出
  • 卡点：把 2% 与 5% 误差带的调节时间系数搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由闭环传函求 5% 误差带的调节时间（第 1、2 问）
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
反馈校正与复合控制 系统校正
本卷考法
  • 分析比例负反馈校正对系统性能的影响（第 3 问）
本卷实例
  • 关键一步：比例负反馈降低环路增益、提高阻尼，牺牲稳态精度换平稳性
  • 中间结果：由校正后阻尼比与环路增益的变化分别讨论动态与稳态性能
  • 卡点：只说响应变快或变慢，未同时说明稳态精度变化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过分析比例负反馈校正对系统性能的影响（第 3 问）
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

四四、根轨迹绘制、共轭极点定位与主导极点条件#

思路
  • 按法则绘制根轨迹，由实部条件定 K 与极点，再由主导极点距离比求 K 范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制 K 从 0 到无穷大的闭环根轨迹（第 1 问）

思路

本卷考法

本卷实例
