合肥工业大学 834 自动控制原理（含现控） 2025 年真题思维导图

211 院校共 10 题

难度：中等　10 题 150 分；前八问是填空式小概念（阶跃响应、脉冲响应、右半平面极点个数、正弦稳态、离散输出、非线性平衡点、能控标准型、能否镇定），后九题是结构图、根轨迹、串联校正、离散、描述函数与状态空间，覆盖面广但每题篇幅不大

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

1、2、3、4、5、6、7、8一、填空式小问（八问）#

思路
  • 八个相互独立的小问，每问只考一步结论：一阶阶跃响应、脉冲响应、右半平面极点个数、正弦稳态输出、离散输出与调节时间、非线性平衡点类型、能控标准型、能否状态反馈镇定
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由一阶微分方程求单位阶跃响应
本卷实例
  • 关键一步：先把方程化成标准一阶形式：时间常数等于一次项系数除以常数项系数
  • 关键一步：直流增益等于右端系数除以常数项系数
  • 关键一步：一阶单位阶跃响应是一减指数形式，指数上的系数是时间常数的倒数
  • 关键一步：把时间常数与增益代进标准形式即可写出响应表达式
  • 中间结果：本题增益较大而时间常数很小，响应很快趋于稳态值，稳态值等于直流增益
  • 卡点：时间常数与增益位置写反；或忘记把方程一阶项系数归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由一阶微分方程求单位阶跃响应
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

零极点分布与响应模态 传递函数
本卷考法
  • 由开环传函求闭环单位脉冲响应
本卷实例
  • 关键一步：单位脉冲响应就是闭环传递函数的拉氏反变换，先由开环写出单位负反馈的闭环传函
  • 关键一步：把闭环传函做部分分式分解，极点给出指数项、零点给出各项系数
  • 关键一步：反变换后得到指数衰减项之和，可用初值定理核对零时刻的值
  • 中间结果：本题闭环有两个实极点，脉冲响应是两个指数项之差，不含振荡项
  • 卡点：把开环传函当闭环传函；或部分分式时把极点代入的对象搞错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由开环传函求闭环单位脉冲响应
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据确定系统在右半平面闭环极点的个数
本卷实例
  • 关键一步：逐项列劳斯表，缺项必须补零后再计算
  • 关键一步：首列符号改变的次数就是右半平面闭环极点的个数
  • 关键一步：首列出现零元素时要用无穷小量代替后继续判断符号
  • 中间结果：本题特征方程是六阶的，首列会出现一次符号变化，说明右半平面只有一个极点
  • 卡点：数的是首列元素的正负个数而不是符号变化次数；或首列出现零时直接下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据确定系统在右半平面闭环极点的个数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

频率特性的物理意义与求法 频域分析
本卷考法
  • 求正弦输入下的稳态输出表达式
本卷实例
  • 关键一步：稳态输出仍是同频正弦，幅值等于输入幅值乘该频率处的幅值，相位加上该频率处的相角
  • 关键一步：把输入频率代进传函得到复数，分别取模与相角
  • 关键一步：本题是一阶环节，幅值按根号下的一加平方项算，相角是负的反正切
  • 中间结果：输入幅值为根号二、频率为二，输出幅值对应为一阶环节在该频率处的放大倍数
  • 卡点：把频率与时间常数混用；或相角漏掉负号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求正弦输入下的稳态输出表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

离散系统的动态性能与极点分布 离散控制系统
本卷考法
  • 求离散系统指定拍数的输出值并估算调节时间
本卷实例
  • 关键一步：输出 z 变换等于闭环脉冲传函乘输入的 z 变换，再做长除法取商的系数即为各拍输出
  • 关键一步：闭环传函分母只含 z 的平方，说明系统是二阶的，输出序列要递推两拍才能起步
  • 关键一步：调节时间按闭环极点在单位圆内距原点的远近估算，极点越靠近原点衰减越快
  • 中间结果：本题闭环传函分母为 z 平方、分子含一个零点，输出序列会出现逐拍累加的特征
  • 卡点：把 z 的负幂次展开方向弄反；或忽略增益 K 对序列数值的影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点在 z 平面上的位置决定响应形式
  • 极点越靠近原点衰减越快，越靠近单位圆振荡越强
  • 极点的幅角决定振荡频率，幅值决定衰减速度
  • 采样周期增大会使动态性能变差甚至不稳定
步骤
  • 求闭环脉冲传递函数的极点
  • 按极点在单位圆内的位置判断响应形式
  • 由极点的模与幅角估算衰减与振荡频率
  • 与连续系统指标对应关系相互校验
通用考法
  • 本卷考过求离散系统指定拍数的输出值并估算调节时间
  • 由闭环极点分布判断动态性能
  • 与连续域指标互相换算
  • 说明采样周期对动态性能的影响
常见易错
  • 把 z 平面极点当作 s 平面极点直接读阻尼比
  • 忽略单位圆上极点对应等幅振荡

相平面法 非线性系统
本卷考法
  • 求非线性系统的平衡点并判断平衡类型
本卷实例
  • 关键一步：平衡点由状态导数同时为零解出，本题把速度项置零后方程退化，解只有一个点
  • 关键一步：在平衡点处对非线性函数做线性化，把含平方的阻尼项按常数处理
  • 关键一步：按线性化后特征根的实部与根的类型判断是节点、焦点还是鞍点
  • 中间结果：本题线性化后的阻尼系数由平衡点位置决定，特征方程的两个根实部都为负，属稳定型
  • 卡点：忘记对含平方的阻尼项线性化而直接代初值；或把平衡点类型与全局稳定性混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过求非线性系统的平衡点并判断平衡类型
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆
公式
由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 把给定状态空间表达式化成能控标准型
本卷实例
  • 关键一步：先判断能控性，能控时才存在能控标准型，变换矩阵由能控性矩阵构造
  • 关键一步：能控标准型的系统矩阵是友矩阵，最后一行为特征多项式系数取负后按低阶到高阶排列
  • 关键一步：变换后的输入矩阵取末行是一，输出矩阵由原输出矩阵与变换矩阵的乘积给出
  • 中间结果：本题系统矩阵只有两个状态，能控性矩阵可逆，变换后特征多项式系数直接来自原矩阵的迹与行列式
  • 卡点：变换矩阵取反导致友矩阵系数错位；或没有先验证能控性就做变换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法
  • 本卷考过把给定状态空间表达式化成能控标准型
  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反
公式
能控性与能观性 状态空间分析
本卷考法
  • 判断多输入多输出系统能否用状态反馈镇定
本卷实例
  • 关键一步：先把系统矩阵化成上三角或按特征值分块，直接读出全部特征值
  • 关键一步：构造能控性矩阵求秩，秩小于状态维数说明存在不能控模态
  • 关键一步：不能控模态的特征值实部全为负时系统可镇定，只要有一个非负就不能镇定
  • 中间结果：本题系统矩阵是分块上三角形式，特征值就在对角线上，重复出现的正特征值决定了能否镇定
  • 卡点：把可镇定与完全能控混为一谈；或算秩时忘了输入矩阵是多列的
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断多输入多输出系统能否用状态反馈镇定
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

9九、由结构图求闭环传函（图 1）#

思路
  • 由给定结构图求 C(s)/R(s)
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由结构图化简求闭环传递函数
本卷实例
  • 关键一步：先找出全部回路与两两互不接触的回路，把特征式写完整
  • 关键一步：从输入到输出找前向通道，通道上环节依次相乘
  • 关键一步：比较点的正负号要在写方程时体现，不能只连线不写号
  • 中间结果：化简结果的分母是同一个特征式，与求扰动传函时的分母一致
  • 卡点：漏掉互不接触回路项；或比较点符号写错导致分子差一个负号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由结构图化简求闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

10十、稳定增益范围与复合输入稳态误差（图 2）#

思路
  • 结构图先求闭环稳定时增益范围，再由给定与扰动共同作用下的稳态误差反求增益
参数稳定域的确定 稳定性分析
本卷考法
  • 求使闭环系统稳定的增益取值范围
本卷实例
  • 关键一步：写出闭环特征方程后列劳斯表，首列各元素同号即稳定
  • 关键一步：本题特征方程含增益的一次项，首列给出增益的上下界
  • 关键一步：稳定域是不等式组的交集，端点对应临界稳定
  • 中间结果：下界由常数项大于零给出，上界由首列中间项为零确定
  • 卡点：只列一个不等式；或把端点当作属于稳定域
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求使闭环系统稳定的增益取值范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响

  • 关键一步：速度误差系数由把 z 减一的因子乘上开环脉冲传函后取极限得到
  • 关键一步：把已定增益代入算出两项误差后相加
  • 中间结果：开环含一个 z 等于一的极点时阶跃项无误差，总误差就等于斜坡项贡献
  • 卡点：用连续系统的静态误差系数公式；或忘记两项要相加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差由输入类型与开环脉冲传函中 z=1 处极点的个数决定
  • 型别由 G(z)H(z) 中 z=1 处极点的重数确定
  • 用终值定理求稳态误差，前提是系统稳定
  • 采样周期也影响稳态误差大小
步骤
  • 求误差脉冲传递函数

  • 分析采样周期变化对误差的影响
