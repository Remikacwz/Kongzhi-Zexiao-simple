1一、填空题（9小题）#

思路
  • 9个填空小题各自独立，覆盖动态指标、响应反求传函、阻尼比、劳斯判据、裕度、滞后校正、相平面、能控能观与离散稳定性
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 第一题第1小题：由一阶闭环传函求误差带5%时的调节时间
本卷实例
  • 关键一步：先把闭环传函化成一阶标准形式，读出时间常数
  • 中间结果：按5%误差带取调节时间与时间常数的倍数关系
  • 卡点：把5%误差带的系数与2%误差带的系数记混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过第一题第1小题：由一阶闭环传函求误差带5%时的调节时间
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

由响应曲线反求传递函数 传递函数
本卷考法
  • 第一题第2小题：由单位阶跃响应表达式反求闭环传函
本卷实例
  • 关键一步：把响应各指数项拉氏变换相加，再除以阶跃输入的拉氏变换
  • 中间结果：分母因式分解后得到两个实极点对应的一阶环节乘积
  • 卡点：漏掉响应中常数项对应的一阶极点，分母阶数写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过第一题第2小题：由单位阶跃响应表达式反求闭环传函
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 第一题第3小题：由单位负反馈开环传函与给定阻尼比求参数
本卷实例
  • 关键一步：写出二阶闭环特征方程并与标准二阶形式逐项对应
  • 中间结果：由一次项系数与阻尼比先解自然频率，再对应常数项求参数
  • 卡点：两源对开环分母印法不一致，需回原卷核对后再代入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过第一题第3小题：由单位负反馈开环传函与给定阻尼比求参数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

劳斯判据 稳定性分析
本卷考法
  • 第一题第4小题：用劳斯表判断右半平面闭环极点个数
本卷实例
  • 关键一步：首列出现零时用正的小量替代，继续把劳斯表列完
  • 中间结果：首列符号变化次数就是右半平面闭环极点个数
  • 卡点：首列出现零就判稳定，没有继续使用小量法
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过第一题第4小题：用劳斯表判断右半平面闭环极点个数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

稳定裕度 频域分析
本卷考法
  • 第一题第5小题：回答稳定一阶、二阶系统的幅值裕度
本卷实例
  • 关键一步：从幅相曲线是否与负实轴相交入手判断幅值裕度
  • 中间结果：一阶、二阶系统的相频不穿越负180度，幅值裕度无有限值
  • 卡点：把幅值裕度与相角裕度的定义和几何含义混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过第一题第5小题：回答稳定一阶、二阶系统的幅值裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

滞后校正 系统校正
本卷考法
  • 第一题第6小题：确定滞后校正装置截止频率的设置位置
本卷实例
  • 关键一步：在未校正相频曲线上找相角裕度并留出6度相位余量
  • 中间结果：截止频率取希望相角裕度加6度对应的那个频率
  • 卡点：直接在原截止频率处加相角而忽略相频曲线形状
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过第一题第6小题：确定滞后校正装置截止频率的设置位置
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

相平面法 非线性系统
本卷考法

本卷实例

  • 中间结果：相轨迹为向奇点收敛的对数螺线，属稳定焦点

  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤

  • 由等倾线法或解析法求相轨迹斜率

通用考法

  • 分析极限环的存在与形态

能控性与能观性 状态空间分析
本卷考法
  • 第一题第8小题：对块对角状态方程分析能控性与能观性
本卷实例
  • 关键一步：按对角块分组，检查输入阵与输出阵对应分量是否为零
  • 中间结果：输入阵为零而输出阵非零的状态不可控但可观测
  • 卡点：逐列观察时漏掉块内耦合分量导致能控性判断错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过第一题第8小题：对块对角状态方程分析能控性与能观性
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

2二、结构图求闭环传递函数#

思路
  • 由结构图画信号流图，找出全部单独回路与前向通路后用梅森公式求C(s)/R(s)
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图画信号流图并用梅森增益公式求闭环传函
本卷实例
  • 关键一步：把比较点与引出点对应成节点，逐个找出前向通路与单独回路
  • 中间结果：特征式由各回路增益及两两不接触回路乘积组成
  • 卡点：余子式未剔除与通路接触的回路，不接触回路找漏或重复
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图画信号流图并用梅森增益公式求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

劳斯判据 稳定性分析

步骤
