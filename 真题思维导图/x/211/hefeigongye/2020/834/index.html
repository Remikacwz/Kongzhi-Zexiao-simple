1一、填空题（9小题）#

思路
  • 9个填空小题各自独立，覆盖非线性判别、一阶调节时间、脉冲响应反求传函、最小实现、能控标准型、离散稳定、数字控制器实现、主导极点化简与相轨迹类型
非线性系统的特点 非线性系统
本卷考法
  • 第一题第1小题：判断给定微分方程描述的系统是否为非线性
本卷实例
  • 关键一步：检查方程中是否出现变量乘积或变量平方项
  • 中间结果：含变量相乘或高次项即判为非线性系统
  • 卡点：只看到时变系数就误判为非线性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过第一题第1小题：判断给定微分方程描述的系统是否为非线性
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 第一题第2小题：由一阶传函与误差带求调节时间
本卷实例
  • 关键一步：读出时间常数并按给定误差带选倍数
  • 中间结果：误差带越小所需调节时间越长
  • 卡点：把时间常数与调节时间当成同一个量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过第一题第2小题：由一阶传函与误差带求调节时间
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

由响应曲线反求传递函数 传递函数
本卷考法
  • 第一题第3小题：由二阶脉冲响应表达式反求传递函数
本卷实例
  • 关键一步：把响应各指数与正弦项拉氏变换后相加
  • 中间结果：合并后分母对应二阶特征多项式
  • 卡点：未判断系统阶数就直接套二阶公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过第一题第3小题：由二阶脉冲响应表达式反求传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

状态空间与传递函数的关系 状态空间分析
本卷考法
  • 第一题第4小题：判断给定状态空间方程是否为最小实现
本卷实例
  • 关键一步：由状态空间求传递函数并检查有无零极点对消
  • 中间结果：存在零极点对消则不是最小实现
  • 卡点：把特征值个数与传函极点数直接等同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过第一题第4小题：判断给定状态空间方程是否为最小实现
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 第一题第5小题：把给定状态方程化为能控标准型
本卷实例
  • 关键一步：先求特征多项式再按系数排能控标准型
  • 中间结果：变换后输入矩阵取最简形式
  • 卡点：友矩阵中系数符号写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法
  • 本卷考过第一题第5小题：把给定状态方程化为能控标准型
  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反

离散系统稳定性分析 离散控制系统
本卷考法
  • 第一题第6小题：判断离散状态方程是否渐近稳定
本卷实例
  • 关键一步：求状态矩阵特征值并比较其模与一的大小
  • 中间结果：所有特征值模小于一时系统渐近稳定
  • 卡点：把连续系统实部判据套到离散系统上
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过第一题第6小题：判断离散状态方程是否渐近稳定
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

数字控制器与最少拍设计 离散控制系统
本卷考法
  • 第一题第7小题：由数字控制器脉冲传函写可实现的算法程序
本卷实例
  • 关键一步：把D(z)/E(z)化为z的负幂有理式再交叉相乘
  • 中间结果：整理成当前输出与历史输入输出的差分方程
  • 卡点：忽略控制器必须物理可实现这一前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最少拍系统指在典型输入下经过有限拍达到无稳态误差
  • 设计需要满足可实现性与稳定性约束
  • 最少拍系统的闭环脉冲传递函数由输入类型确定
  • 最少拍设计通常导致很大的控制量，需加限制
步骤
  • 确定输入类型及对应的误差传函形式
  • 按无稳态误差要求构造闭环脉冲传递函数
  • 由 D(z)=Φ(z)/[G(z)(1-Φ(z))] 求数字控制器
  • 检验可实现性、稳定性与控制量大小
通用考法
  • 本卷考过第一题第7小题：由数字控制器脉冲传函写可实现的算法程序
  • 设计最少拍数字控制器
  • 比较不同输入类型下的最少拍数
  • 分析最少拍系统存在的问题
常见易错
  • 忽略 D(z) 必须是物理可实现的因果系统
  • 闭环传函构造时未满足稳定性约束条件

2二、结构图求闭环传函#

思路
  • 由多回路结构图画信号流图，用梅森公式求闭环传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 第二题：由结构图求闭环传递函数C(s)/R(s)
本卷实例
  • 关键一步：画信号流图并列出回路与前向通路
  • 中间结果：按梅森公式把回路增益代入特征式
  • 卡点：不接触回路找漏或重复；结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过第二题：由结构图求闭环传递函数C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

3三、稳定参数范围与输入扰动稳态误差#

思路
  • 先由劳斯判据求两参数稳定域，再分别求斜坡输入与负阶跃扰动下的稳态误差
参数稳定域的确定 稳定性分析
本卷考法
  • 第三题第1问：求系统稳定时K与Kt的取值范围
本卷实例
  • 关键一步：列劳斯表并令首列各元素同号
  • 中间结果：解不等式组取交集得两参数稳定域
  • 卡点：只列出部分首列元素的不等式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过第三题第1问：求系统稳定时K与Kt的取值范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 第三题第2问：求输入斜坡下系统的稳态误差
本卷实例
  • 关键一步：先判稳再按型别求静态速度误差系数
  • 中间结果：斜坡误差由输入斜率与开环增益之比给出
  • 卡点：输入为斜坡时误代入阶跃误差公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
