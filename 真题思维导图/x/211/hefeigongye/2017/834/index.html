合肥工业大学 834 自动控制原理（含现控） 2017 年真题思维导图

难度：中等偏难　9道大题；第一题为7个填空小题共10空并成一块，其余八道综合题覆盖多入多出结构图、测速反馈、双向根轨迹、PI频率法校正、采样系统、描述函数法与状态空间设计；题面多含原卷插图

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

1一、填空题（7小题10空）20 分#

思路
  • 7道填空小题各自独立，覆盖控制方式与静差、峰值反求、斜坡稳态误差、模值条件、稳定裕度、z域初终值与平衡状态稳定性
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 由图1速度控制系统判断控制方式与有无静差
本卷实例
  • 关键一步：看图判断是否含积分环节与反馈通道，据此定控制方式
  • 中间结果：只有比例环节时对阶跃输入存在稳态误差，属有静差系统
  • 卡点：把开环控制与闭环控制的判断依据记反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过由图1速度控制系统判断控制方式与有无静差
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由二阶开环传函求ωn与ξ并化为标准形式
本卷实例
  • 关键一步：先把开环传函写成K/[s(Ts+1)]形式再与标准二阶开环对比
  • 中间结果：标准形式中2ξωn对应一次项系数，ωn平方对应常数项
  • 卡点：未把分母s项系数归一化就直接读参数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由二阶开环传函求ωn与ξ并化为标准形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由输入幅值与超调量求单位阶跃响应最大值
本卷实例
  • 关键一步：先求稳态值，再用超调量定义求得峰值
  • 中间结果：输出最大值等于稳态值乘以1加超调量
  • 卡点：把输入幅值漏乘，或把峰值时间与调节时间混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由输入幅值与超调量求单位阶跃响应最大值
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由闭环传函一般形式求单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：先由闭环传函写误差传函，再用终值定理取s趋于零的极限
  • 中间结果：误差传函分子最低次项系数与常数项之比即稳态误差
  • 卡点：未判稳就直接使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由闭环传函一般形式求单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由闭环主导极点实部要求用模值条件求根轨迹增益
本卷实例
  • 关键一步：先验证给定实部点是否为主导极点，再令s为负1加减jω代入特征方程
  • 中间结果：令特征方程实部与虚部分别为零可解出ω与K*
  • 卡点：直接把实部为负1的实极点当主导极点而未验证
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由闭环主导极点实部要求用模值条件求根轨迹增益
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
稳定裕度 频域分析
本卷考法
  • 由实验频率特性数据求相角裕度并反求增益
本卷实例
  • 关键一步：先在数据表找幅值为1的频率，取其相角与负180度之差
  • 中间结果：增益改变只平移幅频曲线，据目标裕度反求新增益
  • 卡点：把相角裕度公式写成180度减相角
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由实验频率特性数据求相角裕度并反求增益
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
z 变换与 z 反变换 离散控制系统
本卷考法
  • 由z变换式用初值定理求序列初值
本卷实例
  • 关键一步：对E(z)取z趋于无穷的极限得e(0)
  • 中间结果：初值即为E(z)在z趋于无穷时的极限
  • 卡点：把初值定理写成z趋于零的极限
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • z 变换是离散信号的拉氏变换，令 z=e^{Ts} 得到
  • 常用函数的 z 变换要熟记
  • z 反变换可用部分分式法、幂级数法或留数法
  • 左半 s 平面映射到 z 平面单位圆内
步骤
  • 将连续传递函数展开为部分分式
  • 逐项查表做 z 变换
  • 需要时做 z 反变换求时间序列
通用考法
  • 本卷考过由z变换式用初值定理求序列初值
  • 求给定函数的 z 变换
  • 求 z 反变换得到采样序列
  • 说明 s 平面与 z 平面的映射关系
常见易错
  • 把 z 变换结果中的 e^{-aT} 写成 e^{-a}
  • 部分分式分解时漏项导致反变换出错

离散系统的稳态误差 离散控制系统
本卷考法
  • 由z变换式用终值定理求序列终值
本卷实例
  • 关键一步：先检查E(z)极点是否都在单位圆内，再取(z-1)E(z)的极限
  • 中间结果：极点均在单位圆内时终值等于z趋于1的极限
  • 卡点：未判稳就取终值，或极限中漏乘(z-1)
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差由输入类型与开环脉冲传函中 z=1 处极点的个数决定
  • 型别由 G(z)H(z) 中 z=1 处极点的重数确定
  • 用终值定理求稳态误差，前提是系统稳定
  • 采样周期也影响稳态误差大小
步骤
  • 求误差脉冲传递函数
  • 数出 z=1 处极点重数确定型别
  • 查表或用终值定理求稳态误差
  • 分析采样周期变化对误差的影响
通用考法
  • 本卷考过由z变换式用终值定理求序列终值
  • 求离散系统在典型输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 分析采样周期对稳态精度的影响
常见易错
  • 直接用 s 域静态误差系数公式处理离散系统
  • 未判稳就用终值定理

李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 由状态方程系数矩阵判断原点平衡状态的稳定性
本卷实例
  • 关键一步：写出特征方程并列劳斯表，由第一列符号判断
  • 中间结果：结合α大于零的条件看第一列是否出现变号
  • 卡点：特征方程系数展开符号写错导致判据反向
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过由状态方程系数矩阵判断原点平衡状态的稳定性
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

2二、关联系统求传递函数矩阵12 分#

思路
  • 由两个相互关联系统的结构图列公共回路与特征式，再按不同输入输出对分别找前向通路求传函矩阵
梅森增益公式与信号流图 传递函数
本卷考法
  • 由关联多回路结构图用梅森增益公式求传递函数
本卷实例
  • 关键一步：先列公共回路与特征式，再按不同输入输出对分别找前向通路
  • 中间结果：四个传递函数共用同一个特征式，区别在各对的前向通路
  • 卡点：不同输入输出对的前向通路混用导致传函挂错通道
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由关联多回路结构图用梅森增益公式求传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 多输入多输出系统求各通道传递函数
本卷实例
  • 关键一步：求某通道时把其余输入置零，逐对分别列写
  • 中间结果：各通道传函组成传递函数矩阵
  • 卡点：未分别置零就把多个输入直接叠加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过多输入多输出系统求各通道传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
