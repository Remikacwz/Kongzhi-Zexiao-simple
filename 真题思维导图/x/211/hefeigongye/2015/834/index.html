1一、填空题（8小题10空）#

思路
  • 8道填空小题各自独立，覆盖一阶响应指标、主导极点、根轨迹、Bode低频段、超前角、相平面、离散稳定与线性化稳定
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由图1的单位脉冲响应反求单位阶跃响应并判断超调量
本卷实例
  • 关键一步：单位阶跃响应是单位脉冲响应的积分，先定性判断响应单调还是振荡
  • 中间结果：脉冲响应曲线与时间轴所围面积等于阶跃响应稳态值
  • 卡点：脉冲响应图形未读，单调性与积分关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由图1的单位脉冲响应反求单位阶跃响应并判断超调量
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 由高阶闭环传函的零极点分布确定闭环主导极点
本卷实例
  • 关键一步：先求特征方程根，再比较各极点距虚轴远近并识别偶极子
  • 中间结果：距虚轴最近且附近无零点的极点才是主导极点
  • 卡点：只取距虚轴最近的极点而忽略与零点构成的偶极子对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过由高阶闭环传函的零极点分布确定闭环主导极点
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
分离点与会合点 根轨迹法
本卷考法
  • 由根轨迹图确定出现重极点处的根轨迹增益
本卷实例
  • 关键一步：在根轨迹图上找到分离点或会合点，再用模值条件求增益
  • 中间结果：重极点出现在实轴分离点，增益为该点到各零极点距离之积
  • 卡点：分离点坐标需从图2读取，具体位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由根轨迹图确定出现重极点处的根轨迹增益
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点求系统稳定的增益取值范围
本卷实例
  • 关键一步：令s=jω代入闭环特征方程，分离实部虚部求交点与临界增益
  • 中间结果：虚轴交点对应临界增益，稳定范围由增益穿越临界点的方向确定
  • 卡点：漏掉另一组对称交点导致稳定区间写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹与虚轴交点求系统稳定的增益取值范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 写出I型系统开环对数幅频特性低频段的渐近线斜率
本卷实例
  • 关键一步：由系统型别v直接写出低频段斜率负20v分贝每十倍频程
  • 中间结果：每增加一个积分环节低频段斜率再降低20分贝每十倍频程
  • 卡点：把低频段斜率与高频段斜率混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过写出I型系统开环对数幅频特性低频段的渐近线斜率
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
超前校正 系统校正
本卷考法
  • 由超前校正装置传函求提供的最大超前角
本卷实例
  • 关键一步：先把传函整理成k乘(aTs加1)/(Ts加1)标准形式读出a
  • 中间结果：最大超前角出现在两转折频率几何中点，φm等于arcsin((a-1)/(a+1))
  • 卡点：未把分子化成(aTs加1)形式就取a，或分母系数未归一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过由超前校正装置传函求提供的最大超前角
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
相平面法 非线性系统
本卷考法
  • 由相轨迹方程求等倾线方程并读振荡角频率
本卷实例
  • 关键一步：对相轨迹方程两边关于x求导，令dxdot/dx等于α得等倾线斜率式
  • 中间结果：相轨迹为椭圆时ωn由方程中xdot平方项与x平方项的系数比确定
  • 卡点：求导时漏掉链式法则，把xdot当作与x无关的量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过由相轨迹方程求等倾线方程并读振荡角频率
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆
公式
离散系统稳定性分析 离散控制系统
本卷考法
  • 由离散系统脉冲传函的极点位置判断稳定性
本卷实例
  • 关键一步：令特征方程D(z)等于零求根，比较各根模与1的大小
  • 中间结果：所有极点模小于1才稳定，有模大于1的极点则不稳定
  • 卡点：把离散稳定判据写成极点实部小于零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过由离散系统脉冲传函的极点位置判断稳定性
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒
公式
非线性系统的特点 非线性系统
本卷考法
  • 由线性化模型特征根判断原非线性系统小偏差下的稳定性
本卷实例
  • 关键一步：先对非线性系统在平衡点线性化，再按线性特征根实部符号判定
  • 中间结果：线性化系统特征根均具负实部时原系统在该平衡点渐近稳定
  • 卡点：把线性化结论无条件外推到偏差较大的情形
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过由线性化模型特征根判断原非线性系统小偏差下的稳定性
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定

2二、结构图求闭环传递函数#

思路
  • 由结构图画信号流图，找出全部单独回路与前向通路后用梅森增益公式求C(s)/R(s)
梅森增益公式与信号流图 传递函数
本卷考法
  • 由含交叉反馈的多回路结构图用梅森增益公式求闭环传函
本卷实例
  • 关键一步：把结构图整理成信号流图，逐条列出单独回路与前向通路
  • 中间结果：特征式含三个单回路及两两不接触回路L1L3的乘积项
  • 卡点：第二条通路余子式未剔除与其接触的回路L2
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由含交叉反馈的多回路结构图用梅森增益公式求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路交叉反馈结构图的逐层等效化简
本卷实例
  • 关键一步：从最内环开始等效，再把等效结果与其余回路依次合并
  • 中间结果：逐层化简后系统化为单回路加前向通路的标准形式
  • 卡点：化简内环时把外环信号当作常数处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路交叉反馈结构图的逐层等效化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

3三、误差反求参数与阶跃响应#

思路
  • 先由误差信号反求单位反馈开环参数，再按二阶系统求阶跃响应动态指标与稳态输出
误差定义与误差传递函数 稳态误差
本卷考法
  • 由给定误差信号反求单位反馈系统的误差传递函数并确定K、T
本卷实例
  • 关键一步：对e(t)取拉氏变换得E(s)，再由误差传函与已知形式对比系数
  • 中间结果：E(s)与1/s之比化为s的有理式后即可与含K、T的误差传函对齐
  • 卡点：非单位反馈时误用单位反馈的误差传函定义
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
