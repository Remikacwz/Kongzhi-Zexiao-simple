合肥工业大学 834 自动控制原理（含现控） 2016 年真题思维导图

211 院校共 9 题

难度：中等　9道大题；第一题为7个填空小题共10空并成一块，其余八道综合题覆盖结构图化简、超调与稳态误差、双向根轨迹、Bode裕度与校正、采样系统、描述函数与相平面、状态空间与观测器；题面多含原卷插图

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

1一、填空题（7小题10空）#

思路
  • 7道填空小题各自独立，覆盖系统分类、一阶调节时间、主导极点与稳态误差、稳定参数域、频率特性、离散终值与能控性条件
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 按输入信号变化规律判断控制系统的类型
本卷实例
  • 关键一步：按输入是常值、随时间任意变化还是按预定程序变化分类
  • 中间结果：定值系统输入为常值，随动与程序系统输入随时间变化
  • 卡点：把随动控制系统与程序控制系统的输入特征混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过按输入信号变化规律判断控制系统的类型
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由一阶系统微分方程求时间常数与调节时间
本卷实例
  • 关键一步：对微分方程取拉氏变换求传函并整理成K/(Ts+1)标准形式
  • 中间结果：时间常数取特征根倒数绝对值，5%调节时间约为3T
  • 卡点：未先把2s+6归一化就直接取时间常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由一阶系统微分方程求时间常数与调节时间
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 由闭环零极点分布判断偶极子并写简化传函
本卷实例
  • 关键一步：求全部闭环极点与零点，找与零点靠得很近的极点作偶极子对消
  • 中间结果：消去偶极子后保留距虚轴最近的共轭主导极点对
  • 卡点：把距虚轴近但不构成偶极子的极点也消去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过由闭环零极点分布判断偶极子并写简化传函
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求简化后系统在单位阶跃输入下的稳态误差
本卷实例
  • 关键一步：由简化传函求开环传函并判断型别，再选对应静态误差系数
  • 中间结果：含一个积分环节的有差系统对阶跃输入稳态误差为零
  • 卡点：未判断系统是否稳定就直接算稳态误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求简化后系统在单位阶跃输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求使系统稳定时参数τ的取值范围
本卷实例
  • 关键一步：写出闭环特征方程并列劳斯表，令第一列各元素同号
  • 中间结果：由第一列不等式解出τ下界并保留k大于零的前提
  • 卡点：首列出现零时未用ε法，或漏掉某个首列元素的不等式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求使系统稳定时参数τ的取值范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由闭环频率特性判断正弦输入下输出的相位与旋转方向
本卷实例
  • 关键一步：把闭环传函中s换成jω，求ω等于1处的幅值与相角
  • 中间结果：幅值为1时x-y轨迹为单位圆，相角随ω增大而减小则顺时针
  • 卡点：按开环而非闭环频率特性判断相位方向
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由闭环频率特性判断正弦输入下输出的相位与旋转方向
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由频率特性条件反求阻尼比并计算单位阶跃响应超调量
本卷实例
  • 关键一步：先由幅频与相频特性各列一个方程求出ωn与ξ
  • 中间结果：把求得的阻尼比代入欠阻尼二阶系统超调量公式
  • 卡点：把相频特性反正切的象限判断错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由频率特性条件反求阻尼比并计算单位阶跃响应超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
离散系统的稳态误差 离散控制系统
本卷考法
  • 由z域表达式用终值定理求离散序列的终值
本卷实例
  • 关键一步：先检查E(z)极点是否都在单位圆内，再用终值定理取极限
  • 中间结果：终值等于(z-1)E(z)当z趋于1时的极限
  • 卡点：未判稳就取极限，或极限中漏乘(z-1)
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差由输入类型与开环脉冲传函中 z=1 处极点的个数决定
  • 型别由 G(z)H(z) 中 z=1 处极点的重数确定
  • 用终值定理求稳态误差，前提是系统稳定
  • 采样周期也影响稳态误差大小
步骤
  • 求误差脉冲传递函数
  • 数出 z=1 处极点重数确定型别
  • 查表或用终值定理求稳态误差
  • 分析采样周期变化对误差的影响
通用考法
  • 本卷考过由z域表达式用终值定理求离散序列的终值
  • 求离散系统在典型输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 分析采样周期对稳态精度的影响
常见易错
  • 直接用 s 域静态误差系数公式处理离散系统
  • 未判稳就用终值定理
公式
能控性与能观性 状态空间分析
本卷考法
  • 由状态反馈可任意配置极点的条件求参数a应满足的关系
本卷实例
  • 关键一步：写出能控性矩阵并令其行列式不为零
  • 中间结果：能控性矩阵满秩是状态反馈任意配置极点的充要条件
  • 卡点：把能控性矩阵写成能观性矩阵
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过由状态反馈可任意配置极点的条件求参数a应满足的关系
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式

2二、结构图求闭环与误差传函#

思路
  • 由结构图画信号流图，按输出与误差两个终点分别列前向通路和回路，用梅森公式求C(s)/R(s)与E(s)/R(s)
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图用梅森增益公式分别求C(s)/R(s)与E(s)/R(s)
本卷实例
  • 关键一步：把结构图整理成信号流图，按输出与误差两个终点分别列前向通路
  • 中间结果：两条前向通路与三条回路的接触关系决定各自的余子式
  • 卡点：两两不接触回路L1L2的乘积项漏写
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图用梅森增益公式分别求C(s)/R(s)与E(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 多输入作用下分别求输出与误差对参考输入的传递函数
本卷实例
  • 关键一步：求某一输入传函时把其余输入置零，逐个单独分析
  • 中间结果：误差传函可由1减闭环传函或直接用梅森公式以E为终点求得
  • 卡点：两种输入同时作用时直接叠加而未分别置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过多输入作用下分别求输出与误差对参考输入的传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

3三、结构图定超调与稳态误差参数#

思路
  • 先等效局部反馈写出开环传函，再由超调量上限定阻尼比范围反求参数，最后按斜坡稳态误差上限反求前向增益
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 含局部反馈的结构图等效化简求开环传递函数
本卷实例
  • 关键一步：先把局部反馈的G2/(1加aG2)等效，再与G1、G3串接
  • 中间结果：化简后系统化为带一个积分环节的典型二阶开环形式
  • 卡点：局部反馈等效时把aG2的正负号取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
