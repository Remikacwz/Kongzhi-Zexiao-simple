思路

由 Bode 图反求传递函数 频域分析
本卷考法
  • 由最小相位系统的对数幅频特性求子系统传递函数
本卷实例
  • 关键一步：由低频段斜率定系统型别与开环增益
  • 中间结果：由转折频率的斜率变化识别一阶环节
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤

  • 由低频段高度或延长线确定增益 K

  • 写出并验证传递函数

  • 检验候选传递函数与曲线是否吻合

  • 把延长线交点误当作增益值而未折算型别

思路
  • 由超调量与调节时间求阻尼比和自然频率，再反求时间常数与开环增益并写出闭环与误差传函

本卷考法

本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化

  • 把两种误差带的调节时间系数搞混

  • 超调量公式中漏乘 100%

3劳斯判据与稳态误差#

思路
  • 列劳斯表定 K 范围，再由斜坡误差要求求 K，最后归纳减小稳态误差的措施
劳斯判据 稳定性分析
本卷考法
  • 列劳斯表判断使系统稳定的增益范围
本卷实例
  • 关键一步：写出闭环特征方程后按劳斯表逐行计算
  • 中间结果：首列元素全为正对应稳定
  • 卡点：首列出现零时要用小正数替换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过列劳斯表判断使系统稳定的增益范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过系数有缺项时未补零就套用判据
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

减小稳态误差的措施 稳态误差
本卷考法
  • 列举减小稳态误差的常用措施
本卷实例
  • 关键一步：从提高增益、加积分环节与复合控制等角度归纳
  • 中间结果：措施需与系统稳定性一并权衡
  • 卡点：答措施要分输入误差与扰动误差两类
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过列举减小稳态误差的常用措施
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 本卷考过只谈误差减小而不检查稳定性是否被破坏
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

4零度根轨迹与稳定性#

思路
  • 把开环写成含负号的形式后画零度根轨迹，据根轨迹是否进入右半平面判断稳定性
广义根轨迹与参数根轨迹 根轨迹法
本卷考法

本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤

  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法

  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别

  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过说明系统稳定与相对稳定的含义
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过把稳定性与稳定裕度两个概念混为一谈
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

能控性与能观性 状态空间分析
本卷考法
  • 简述线性定常系统能控性的条件
本卷实例
  • 关键一步：能控性矩阵的秩等于状态变量个数
  • 中间结果：秩判据是最常用的能控性条件
  • 卡点：系统矩阵维度要与秩作比较
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过简述线性定常系统能控性的条件
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 本卷考过只算到倒数第二个矩阵就下结论
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

附加开环零极点的影响 根轨迹法
本卷考法
  • 说明增加开环极点对根轨迹与稳定性的影响
本卷实例
  • 关键一步：从分支数、渐近线方向与实轴段变化分析
  • 中间结果：附加极点一般使根轨迹右移、稳定性变差
  • 卡点：结论要区分极点落在左半还是右半平面
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过说明增加开环极点对根轨迹与稳定性的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 本卷考过把附加开环极点与附加开环零点的影响搞反
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
