1一、电路与方框图综合#

思路
  • 先由电路图逐个写出各环节的复阻抗与传递函数，再用方框图等效或梅森公式求闭环传递函数，最后令特征方程各系数满足劳斯判据求元件系数约束
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由电路结构求各环节传递函数G1至G4
本卷实例
  • 关键一步：按复阻抗写出元件的分压或分流关系，再对应方框图支路写出环节传函
  • 中间结果：G1与G4由电阻电容并联关系得到，G3为一个积分环节
  • 卡点：电路图未读图，元件串并联关系需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由电路结构求各环节传递函数G1至G4
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求多回路方框图的闭环传函
本卷实例
  • 关键一步：先数清独立回路与前向通路，再按不接触回路写余子式
  • 中间结果：特征式按单回路与两两不接触逐层累加得到
  • 卡点：方框图未读图，比较点引出的支路条数容易漏乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求多回路方框图的闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
劳斯判据 稳定性分析
本卷考法
  • 列劳斯表判断闭环稳定并给出元件系数约束
本卷实例
  • 关键一步：由闭环特征方程按降幂排列，再逐行交叉相减列劳斯表
  • 中间结果：首列各元素含元件参数，令首列同号得到不等式组
  • 卡点：元件参数符号未在源文标明，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过列劳斯表判断闭环稳定并给出元件系数约束
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 把首列同号条件化成元件系数的稳定域
本卷实例
  • 关键一步：令劳斯表首列每个元素大于零，再取各不等式解集的交集
  • 中间结果：稳定域边界对应特征根落在虚轴上
  • 卡点：易只列首列某一项而漏掉其余约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过把首列同号条件化成元件系数的稳定域
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

2二、二阶系统时域指标与稳态误差#

思路
  • 把给定闭环传函化成二阶标准形式读出自然频率与阻尼比，按性能指标公式求调节时间，再对斜坡输入用静态误差系数求稳态误差，最后讨论各参数对误差的影响
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由给定闭环传函读出自然频率与阻尼比
本卷实例
  • 关键一步：把分母首项系数归一化，再与标准二阶形式逐项比较系数
  • 中间结果：自然频率与阻尼比由分母的常数项和一次项系数表示
  • 卡点：Φ(s)含待定k1、k2、T1、T2，需先代入给定值再归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由给定闭环传函读出自然频率与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 按百分之五误差带求调节时间并判断超调
本卷实例
  • 关键一步：先算阻尼比判断是否欠阻尼，再按对应近似公式求调节时间
  • 中间结果：调节时间与阻尼比和自然频率的乘积成反比
  • 卡点：响应曲线为原卷插图未读，振荡次数需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过按百分之五误差带求调节时间并判断超调
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡输入下系统的稳态误差
本卷实例
  • 关键一步：先用终值定理写出误差传函在零频附近的极限
  • 中间结果：误差系数取决于开环系统型别与开环增益
  • 卡点：用终值定理前需先确认闭环稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求斜坡输入下系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 分析四个参数分别增大时对稳态误差的影响
本卷实例
  • 关键一步：把静态误差系数写成四个参数的显式表达式，再逐个判断增减
  • 中间结果：误差随开环增益增大而减小，随时间常数增大而增大
  • 卡点：个别参数同时影响增益与型别，需分情况讨论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过分析四个参数分别增大时对稳态误差的影响
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

3三、三阶系统根轨迹与主导极点#

思路
  • 由斜坡输入下稳态误差为常数判断系统型别，写出开环极点配置，按绘制法则画根轨迹，用虚轴交点求临界增益，最后由极点位置讨论主导极点
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画三阶系统的常规根轨迹
本卷实例
  • 关键一步：由开环极点确定实轴上的根轨迹段与渐近线方向
  • 中间结果：三条渐近线交于极点实部均值，夹角按奇数等分
  • 卡点：源文只给P1与P2，第三个极点由斜坡误差条件定为原点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画三阶系统的常规根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点求临界增益
本卷实例
  • 关键一步：把s等于jω代入特征方程，分离实部与虚部并联立
  • 中间结果：交点频率与临界增益由两个实方程共同确定
  • 卡点：算出的负频率要舍去，只保留物理角频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹与虚轴交点求临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 求阶跃响应衰减振荡对应的增益范围
本卷实例
  • 关键一步：衰减振荡要求一对共轭复根实部为负，对应根从分离点到虚轴之间
  • 中间结果：增益下界对应分离点，上界对应虚轴交点
  • 卡点：分离点增益与虚轴交点增益需分别求，不能混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过求阶跃响应衰减振荡对应的增益范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 由三个闭环极点位置判断主导极点
本卷实例
  • 关键一步：比较各极点到虚轴的距离，找靠得最近且附近无零点对消的极点
  • 中间结果：第三个极点为负五时，比较它与另两极点实部的大小
  • 卡点：偶极子是否对消会改变判断，需回原卷核对题意
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
