1反馈系统误差与扰动传函#

思路
  • 由两个环节的传函求闭环传函与误差传函，分别求参考输入与扰动单独作用下的稳态误差并合成
误差定义与误差传递函数 稳态误差
本卷考法

本卷实例
  • 关键一步：由误差定义先写出误差点的信号关系
  • 中间结果：误差传函分母与闭环特征式相同
  • 卡点：无
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤

  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限

  • 写出误差传递函数

常见易错

  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

思路

本卷考法

本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
