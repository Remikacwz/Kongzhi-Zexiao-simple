一一、由增益调整局限谈控制结构改善14 分#

思路
  • 由开环传函化闭环标准二阶形式，说明K、T与阻尼比、自然频率的牵制关系，再提出加微分负反馈或PID以改变控制结构
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由开环传函写闭环标准二阶形式并分析阻尼比与自然频率随K的变化
本卷实例
  • 关键一步：把闭环传函化为标准二阶形式，写出阻尼比与自然频率的表达式
  • 中间结果：T不变时增大K使自然频率升高而阻尼比下降，快与稳互相牵制
  • 卡点：本题以定性叙述为主，不要只写结论而漏掉推演
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由开环传函写闭环标准二阶形式并分析阻尼比与自然频率随K的变化
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

校正的基本概念与性能指标 系统校正
本卷考法
  • 说明单纯调增益的局限并给出改变控制结构的方案
本卷实例
  • 关键一步：从改变系统结构入手，而不是继续调整开环增益
  • 中间结果：引入微分负反馈可只提高阻尼比而不压低自然频率
  • 卡点：所提方案要能说明为何可同时改善快速性与振荡性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距

通用考法
  • 本卷考过说明单纯调增益的局限并给出改变控制结构的方案
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求

二二、结构图正弦输入的稳态输出12 分#

思路
  • 先由结构图求闭环传函，写出频率特性后在输入频率处取幅值与相角，按正弦稳态法则合成输出
频率特性的物理意义与求法 频域分析
本卷考法
  • 由闭环频率特性求给定正弦输入的稳态输出
本卷实例
  • 关键一步：用闭环传函在输入频率处求幅频值与相频值
  • 中间结果：稳态输出仍是同频正弦，幅值和相位按频率特性折算
  • 卡点：求稳态输出用的是闭环频率特性，不是开环；结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由闭环频率特性求给定正弦输入的稳态输出
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

三三、结构图求传函与二阶动态指标20 分#

思路
  • 由含局部反馈的结构图求开环与闭环传函，再与标准二阶比较由阻尼比反求参数，最后算超调量与调节时间
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由多回路结构图逐层化简求开环与闭环传函
本卷实例
  • 关键一步：从内环向外逐层等效，写出开环与闭环传函
  • 中间结果：闭环传函分母为二阶多项式，其系数含反馈参数
  • 卡点：化简内环时不要改动外环的信号关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由多回路结构图逐层化简求开环与闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 与标准二阶形式比较由阻尼比反求参数
本卷实例
  • 关键一步：把闭环传函分母与标准二阶分母逐项比较
  • 中间结果：由阻尼比要求列出含待求参数的方程
  • 卡点：化标准形式时先把二次项系数归一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 本卷考过与标准二阶形式比较由阻尼比反求参数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率求超调量和调节时间
本卷实例
  • 关键一步：先由系数关系解出自然频率再代入指标公式
  • 中间结果：超调量只取决于阻尼比，调节时间还与自然频率有关
  • 卡点：两种误差带的调节时间系数别混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率求超调量和调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

四四、劳斯判据判断稳定性与右半平面根数12 分#

思路
  • 对给定特征方程列劳斯表，由首列符号变化次数判断不稳定根个数并给出结论
劳斯判据 稳定性分析
本卷考法
  • 列劳斯表判断稳定性并数出右半平面根的数目
本卷实例
  • 关键一步：按劳斯表规则逐行递推，注意补零与首列符号变化
  • 中间结果：首列符号改变的次数即右半平面根的个数
  • 卡点：系数有缺项时先补零再列劳斯表
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过列劳斯表判断稳定性并数出右半平面根的数目
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以τ为参变量建立等效开环传函并画根轨迹
本卷实例
  • 关键一步：把含τ的项整理成等效开环传函写进幅相条件
  • 中间结果：等效系统的极点与零点决定轨迹分支走向
  • 卡点：整理时要把参变量完整提到分子位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以τ为参变量建立等效开环传函并画根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则确定实轴段与渐近线
本卷实例
  • 关键一步：先标零极点再判断实轴上的根轨迹段
  • 中间结果：极点数为二、零点数为一，仅两条分支
  • 卡点：渐近线夹角公式分子用二k加一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则确定实轴段与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

分离点与会合点 根轨迹法
本卷考法
  • 求分离点并说明复数轨迹为圆
本卷实例
  • 关键一步：由分离点方程解出候选点再按实轴段取舍
  • 中间结果：复数分支可由韦达定理化为圆的方程
  • 卡点：解出的候选点要回轨迹上核对取舍
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

通用考法

  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

六六、由单位阶跃响应求频率特性12 分#

思路
  • 先判断所给阶跃响应并非零状态响应，据其模态反推零状态响应与闭环传函，再换成频率特性
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由全响应分离出零状态响应
本卷实例
  • 关键一步：由响应初值与终值判断是否含非零初始状态
  • 中间结果：初始状态只改变各模态系数、不改变模态本身
  • 卡点：不要漏掉由初值决定的自由响应分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
