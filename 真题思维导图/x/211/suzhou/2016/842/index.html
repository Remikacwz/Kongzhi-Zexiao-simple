一一、水箱液位控制系统组成与方框图16 分#

思路
  • 由浮子、电位器、电机与阀门理清液位反馈关系，指认被控量、传感器、执行器与扰动并画方块图
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指认被控量、传感器、执行器与扰动并说明工作过程
本卷实例
  • 关键一步：先分清给定液位与实际液位的比较环节
  • 中间结果：液位偏差经放大驱动电机改变阀门开度
  • 卡点：水箱液位流程以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指认被控量、传感器、执行器与扰动并说明工作过程
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

二二、结构图正弦组合输入的稳态输出12 分#

思路
  • 先求闭环传函与频率特性，再按叠加原理在两个频率处分别取幅值与相角合成稳态输出
频率特性的物理意义与求法 频域分析
本卷考法
  • 由闭环频率特性求两个正弦分量叠加后的稳态输出
本卷实例
  • 关键一步：对每个输入频率分别查频率特性的幅值与相角
  • 中间结果：稳态输出为两个同频正弦分量之和
  • 卡点：组合输入要逐分量折算再相加；系统结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由闭环频率特性求两个正弦分量叠加后的稳态输出
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式

三三、无超调且调节时间最短的参数确定14 分#

思路
  • 由无超调要求取临界阻尼，写出闭环标准二阶形式，由系数关系解出参数与最短调节时间
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由无超调要求判断系统应取临界阻尼
本卷实例
  • 关键一步：把闭环传函化为标准二阶形式并令阻尼比等于一
  • 中间结果：由分母一次项系数定出自然频率
  • 卡点：先归一化二次项系数再比较系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由无超调要求判断系统应取临界阻尼
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由无超调与最短调节时间要求反求参数
本卷实例
  • 关键一步：由闭环极点全为重实根写出特征多项式
  • 中间结果：重根位置由标准二阶分母的系数确定
  • 卡点：临界阻尼的调节时间不能用欠阻尼公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由无超调与最短调节时间要求反求参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式

四四、多回路结构图化简求传函12 分#

思路
  • 用比较点与引出点的等效移动简化交叉结构，再逐层合并内环与外环写出闭环传函
比较点与引出点的移动 结构图与方框图
本卷考法
  • 用比较点与引出点移动化简交叉结构图
本卷实例
  • 关键一步：先把跨接的比较点或引出点移到便于合并的位置
  • 中间结果：移动后结构化为若干串并联与局部反馈
  • 卡点：移动方向与乘除关系别搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过用比较点与引出点移动化简交叉结构图
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由多回路结构图逐层化简求闭环传函
本卷实例
  • 关键一步：从最内层回路开始等效再逐层向外合并
  • 中间结果：每合并一层回路数减少一个
  • 卡点：化简内环时不要改动外环信号关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由多回路结构图逐层化简求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 把化简后的串联、并联与反馈支路按等效规则合并
本卷实例
  • 关键一步：分别按串联相乘、并联相加、反馈取前向比一加减回路
  • 中间结果：各局部等效结果再串接成总传函
  • 卡点：负反馈分母写成一加回路增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过把化简后的串联、并联与反馈支路按等效规则合并
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式

五五、参数a变化下的根轨迹与稳定范围16 分#

思路
  • 由闭环特征方程写出以a为参变量的等效开环传函，按绘制法则画根轨迹，再由与虚轴交点求稳定范围
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以a为参变量整理等效开环传函
本卷实例
  • 关键一步：把含a的项整理成等效开环传函写进幅相条件
  • 中间结果：等效系统的零极点与原系统不同
  • 卡点：参变量要完整提到分子位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以a为参变量整理等效开环传函
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则确定分支数、实轴段与渐近线
本卷实例
  • 关键一步：先标零极点再判断实轴上的根轨迹段
  • 中间结果：三条分支均趋于无穷远，需算渐近线交点与夹角
  • 卡点：渐近线夹角公式分子用二k加一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则确定分支数、实轴段与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点求使系统稳定的参数范围
本卷实例
  • 关键一步：令纯虚根代入特征方程分离实部与虚部
  • 中间结果：穿越频率与临界参数由方程组同时解出
  • 卡点：只代一个频率可能漏掉另一组交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹与虚轴交点求使系统稳定的参数范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式

六六、奈氏图、稳定裕度与稳定性判断20 分#

思路
  • 由开环传函画奈氏曲线，求幅值穿越频率与相位穿越频率得相角裕度和幅值裕度，再用判据判断稳定性
频率特性的物理意义与求法 频域分析
本卷考法
  • 求开环幅相频率特性并描出关键点
本卷实例
  • 关键一步：以s换纯虚变量后分离实部与虚部
  • 中间结果：起点幅值无穷、终点趋于原点
  • 卡点：相位终值要与积分环节个数一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求开环幅相频率特性并描出关键点
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
稳定裕度 频域分析
本卷考法
  • 求相角裕度与幅值裕度
本卷实例
  • 关键一步：分别由幅值条件和相角条件求两个穿越频率
  • 中间结果：相角裕度与幅值裕度分别由两个频率处的值定义
  • 卡点：两个穿越频率别用反，幅值裕度要取倒数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求相角裕度与幅值裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
