一一、水温控制系统组成与方框图#

思路
  • 由蒸汽加热与冷水流量扰动两条通道理清复合控制关系，指认被控对象、被控量与控制装置并绘制程序框图
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指认被控对象、被控量与控制装置并说明复合控制的工作过程
本卷实例
  • 关键一步：先分清给定温度反馈通道与冷水流量顺馈通道
  • 中间结果：温度偏高时控制器关小蒸汽阀门
  • 中间结果：冷水流量作为主要扰动量经流量计测量后顺馈补偿
  • 卡点：水温控制流程以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指认被控对象、被控量与控制装置并说明复合控制的工作过程
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

二二、结构图化简求闭环传函#

思路
  • 比较点与引出点存在交叉，先按等效移动整理成串并联与局部反馈，再逐层合并求C(s)/R(s)
比较点与引出点的移动 结构图与方框图
本卷考法
  • 用比较点或引出点移动化简含交叉连接的结构图
本卷实例
  • 关键一步：先把跨接的引出点移到便于合并的位置
  • 中间结果：移动后结构化为两个前向通道与一个局部反馈
  • 卡点：移动方向与乘除关系别搞反；本题结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过用比较点或引出点移动化简含交叉连接的结构图
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 从内层回路向外逐层合并求闭环传递函数
本卷实例
  • 关键一步：从最内层反馈回路开始等效再向外合并
  • 中间结果：每合并一层回路数减少一个
  • 卡点：化简内环时不要改动外环信号关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过从内层回路向外逐层合并求闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 把化简后的串并联与反馈支路按等效规则合并
本卷实例
  • 关键一步：串联相乘、并联相加、负反馈取前向比一加回路
  • 中间结果：两个前向通道并联后与局部反馈组成总传函
  • 卡点：负反馈分母写成一加回路增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过把化简后的串并联与反馈支路按等效规则合并
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

三三、静态误差系数法求稳态误差#

思路
  • 先判稳并化成尾1标准型确定型别，再用位置与速度误差系数分别求阶跃、斜坡输入下的稳态误差
系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环传函判断系统型别并求静态位置与速度误差系数
本卷实例
  • 关键一步：把开环传函化成尾1标准型后数积分环节个数
  • 中间结果：静态误差系数由开环增益与型别共同决定
  • 卡点：把开环增益与静态误差系数混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由开环传函判断系统型别并求静态位置与速度误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡与单位阶跃输入下的稳态误差
本卷实例
  • 关键一步：分别用速度误差系数与位置误差系数求两个输入分量
  • 中间结果：两个典型输入分量的稳态误差相互独立
  • 卡点：求误差前先确认闭环系统稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位斜坡与单位阶跃输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

四四、两质量弹簧阻尼系统状态空间方程#

思路
  • 分别对M1、M2列牛顿第二定律，选位移与速度为状态变量，整理成一阶状态方程与输出方程
机械系统建模 建模与机电系统
本卷考法
  • 两质量块经弹簧阻尼连接系统的受力分析与建模
本卷实例
  • 关键一步：对每个质量块分别列牛顿第二定律并保留相互作用力的反作用项
  • 中间结果：两质量块的耦合体现在弹簧与阻尼器的相对位移和相对速度上
  • 卡点：阻尼力与弹簧力的正负方向取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过两质量块经弹簧阻尼连接系统的受力分析与建模
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
状态空间表达式的建立 状态空间分析
本卷考法
  • 选位移与速度作状态变量写出四阶状态空间表达式
本卷实例
  • 关键一步：以位移和速度为一对状态变量把二阶方程降成一阶
  • 中间结果：状态向量取两个位移与两个速度共四个分量
  • 卡点：状态变量个数要与系统阶数一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过选位移与速度作状态变量写出四阶状态空间表达式
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

五五、劳斯判据求极点位于指定垂线左侧的K范围#

思路
  • 把闭环特征方程作变量平移，使新变量代表极点到指定垂线的水平距离，再对新方程用劳斯判据列不等式求K范围
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断闭环特征根是否都位于指定垂线左侧
本卷实例
  • 关键一步：先把s替换成新变量加指定垂线坐标做变量平移
  • 中间结果：平移后特征方程的常数项与一次项共同限定K范围
  • 卡点：平移方向写反会得到相反的参数区间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断闭环特征根是否都位于指定垂线左侧
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由劳斯表首列各元大于零求参数K的稳定域
本卷实例
  • 关键一步：令劳斯表首列每个元素大于零再取交集
  • 中间结果：两个边界不等式给出的K区间需同时满足
  • 卡点：只列部分首列元素会漏掉一个约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由劳斯表首列各元大于零求参数K的稳定域
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

六六、根轨迹法确定系统稳定的K范围#

思路
  • 由开环零极点画180度根轨迹，求分离点、出射角与虚轴交点，再由根轨迹全部位于左半平面的条件确定K范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则确定根轨迹分支数、实轴段与渐近线
本卷实例
  • 关键一步：先标开环零极点再判断实轴上的根轨迹段
  • 中间结果：三条分支全部趋向无穷远
  • 卡点：渐近线夹角公式中的二k加一写成二k
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则确定根轨迹分支数、实轴段与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点或会合点
本卷实例
  • 关键一步：由闭环特征方程写出K的显式表达式再令导数为零
  • 中间结果：解出的根要回到实轴段上筛选
  • 卡点：保留了不在根轨迹上的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点或会合点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

出射角与入射角 根轨迹法
本卷考法
  • 求复数极点的出射角以确定根轨迹起始方向
本卷实例
  • 关键一步：由相角条件累加其他零极点对该极点的相角
  • 中间结果：一对共轭极点的出射角互为相反数
  • 卡点：累加相角时不要把该极点自身的相角算进去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求复数极点的出射角以确定根轨迹起始方向
  • 求复数极点的出射角
  • 根据出射角画出根轨迹起始方向
  • 由入射角确定根轨迹终止方向
常见易错
  • 累加相角时把该极点自身的相角也算进去
  • 忘记判断象限导致角度差 180°

思路

频率特性的物理意义与求法 频域分析
本卷考法
  • 求给定传函的频率特性并计算其与负实轴的交点
本卷实例
  • 关键一步：令虚部为零求穿越负实轴的频率再代回实部
  • 中间结果：开环传函为I型三阶系统，低频幅值趋于无穷大
  • 卡点：求幅值时忘记分母复数取模后再相除
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法

  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅相曲线用奈奎斯特判据求稳定的K范围
本卷实例
  • 关键一步：先数开环右半平面极点数P再判曲线包围临界点的情况
  • 中间结果：曲线与负实轴的交点落在负一以左时闭环不稳定
  • 卡点：开环含积分环节时未补画无穷大半径圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环幅相曲线用奈奎斯特判据求稳定的K范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

稳定裕度 频域分析
本卷考法
  • 求系统的相角裕度与幅值裕度并判断稳定性
本卷实例
  • 关键一步：由幅值条件求截止频率、由相角条件求相位穿越频率
  • 中间结果：相角裕度由截止频率处相角与负180度之差确定
  • 卡点：把截止频率与相位穿越频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求系统的相角裕度与幅值裕度并判断稳定性
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
