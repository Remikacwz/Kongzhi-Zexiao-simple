11、炉温控制系统组成与方框图#

思路
  • 由热电偶测温、给定电压比较、放大驱动电机与调压器执行理清反馈关系，指认控制量与反馈量并画方块图
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指认控制量、反馈量与被控对象并说明工作过程
本卷实例
  • 关键一步：先分清给定电压与炉温测量电压，再由偏差信号串起各环节
  • 中间结果：热电偶把炉温转成电压反馈回比较点形成负反馈
  • 卡点：炉温控制系统以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指认控制量、反馈量与被控对象并说明工作过程
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

22、用方块图化简法求闭环传函#

思路
  • 反复移动比较点与引出点把复杂多回路结构图逐步等效，从内到外合并求闭环传递函数
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由多回路结构图逐层化简求闭环传函
本卷实例
  • 关键一步：从最内层回路开始等效再逐层向外合并
  • 中间结果：每合并一层回路数减少一个
  • 卡点：方块图以图给出，回路条数与接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由多回路结构图逐层化简求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
比较点与引出点的移动 结构图与方框图
本卷考法
  • 移动比较点与引出点使回路结构便于化简
本卷实例
  • 关键一步：移动点前后要保证信号关系完全等效
  • 中间结果：移动后同一支路增益需按乘除关系补偿
  • 卡点：引出点与比较点的移动规则不同，别混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过移动比较点与引出点使回路结构便于化简
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 用串联并联与反馈等效合并各环节
本卷实例
  • 关键一步：先把串联与并联支路合并成单个环节
  • 中间结果：负反馈回路的等效传函分母为1加回路增益
  • 卡点：负反馈分母别写成1减回路增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过用串联并联与反馈等效合并各环节
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

33、由阶跃响应曲线定参数并求稳态误差#

思路
  • 由结构图写闭环传函并与阶跃响应曲线对照，用超调量与峰值时间定阻尼比与自然频率，再求待定参数与稳态误差
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由结构图写闭环传函并定阻尼比与自然频率
本卷实例
  • 关键一步：先由结构图求闭环传函再化成标准二阶形式
  • 中间结果：闭环特征方程系数与阻尼比、自然频率对应
  • 卡点：化为标准形式时要把二阶项系数归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由结构图写闭环传函并定阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阶跃响应曲线的超调量与峰值时间反求参数
本卷实例
  • 关键一步：从曲线上读出稳态值与峰值再算超调量
  • 中间结果：超调量定阻尼比，峰值时间再定自然频率
  • 卡点：峰值时间不能与上升时间混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阶跃响应曲线的超调量与峰值时间反求参数
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡输入下的稳态误差
本卷实例
  • 关键一步：先判稳再由误差传函和终值定理求误差
  • 中间结果：型别与开环增益共同决定斜坡误差
  • 卡点：未判稳就用终值定理会出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

44、劳斯判据判断右半平面与虚轴根#

思路
  • 对五阶特征方程列劳斯表，出现全零行时用辅助方程求虚轴根，再由首列变号判断右半平面根数
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据分析右半平面与虚轴上的特征根
本卷实例
  • 关键一步：列劳斯表遇到全零行时用辅助方程求根
  • 中间结果：由首列变号次数判断右半平面根个数
  • 卡点：全零行说明有关于原点对称的根，不能直接停算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据分析右半平面与虚轴上的特征根
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

55、参数a变化下的根轨迹#

思路
  • 由闭环特征方程反解以a为参变量的等效开环传函，画根轨迹并求分离点与虚轴交点，据此定无实数极点的条件
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以a为参变量绘制参数根轨迹
本卷实例
  • 关键一步：由闭环特征方程反解出含a的等效开环传递函数
  • 中间结果：等效开环传函的零极点决定根轨迹形状
  • 卡点：参数要完整提到分子，否则起点终点会判反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以a为参变量绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则画根轨迹并求渐近线与实轴段
本卷实例
  • 关键一步：先标开环零极点再判实轴上的根轨迹段
  • 中间结果：无开环零点时三条分支都趋于无穷远
  • 卡点：渐近线夹角公式分子用二k加一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则画根轨迹并求渐近线与实轴段
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求分离点并据此判断复根区间
本卷实例
  • 关键一步：由分离点方程解出两个分离点并取舍
  • 中间结果：两分离点之间根轨迹离开实轴、三根均为复根
  • 卡点：参数落在两分离点之外时会存在实极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求分离点并据此判断复根区间
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

66、奈氏图与奈奎斯特判据判稳#

思路
  • 由开环传函求幅相特性关键点并画奈氏曲线，按开环右半平面极点数与曲线包围情况判断闭环稳定性
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数P，再读曲线包围圈数
  • 中间结果：由包围圈数判据式得到右半平面闭环根数
  • 卡点：包围圈数的正负号定义别搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性

  • 用终值定理求稳态误差，前提是系统稳定
  • 采样周期也影响稳态误差大小
步骤
  • 求误差脉冲传递函数
  • 数出 z=1 处极点重数确定型别
  • 查表或用终值定理求稳态误差
  • 分析采样周期变化对误差的影响
通用考法
  • 本卷考过求单位阶跃响应下的稳态值
  • 求离散系统在典型输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 分析采样周期对稳态精度的影响
常见易错
  • 直接用 s 域静态误差系数公式处理离散系统
  • 未判稳就用终值定理
