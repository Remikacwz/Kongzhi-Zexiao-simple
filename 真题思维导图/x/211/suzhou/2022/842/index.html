1一、热水器控制系统组成与前馈补偿#

思路
  • 由冷水、调节阀、热交换器与温度检测理清闭环关系，指认被控量、控制器与执行器，并用流量前馈消除扰动
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指认被控量、控制器、执行器并画原理方框图
本卷实例
  • 关键一步：先分清给定温度与热水温度测量值，再按偏差信号串起各环节
  • 中间结果：温度经检测反馈回比较点形成闭环控制
  • 卡点：热交换器流程以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指认被控量、控制器、执行器并画原理方框图
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
前馈与比值控制 过程控制与检测仪表
本卷考法
  • 用前馈补偿消除二次热水流量扰动的影响
本卷实例
  • 关键一步：把流量计测得的扰动信号经补偿器送到控制器输入端
  • 中间结果：扰动增大时补偿量相应增大以维持出口温度
  • 卡点：前馈补偿不改变闭环稳定性，但要与反馈控制配合
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 前馈按扰动直接补偿，属于开环控制，不改变原回路稳定性
  • 完全不变性条件要求前馈通道传递函数等于扰动通道与调节通道之比的倒数
  • 比值控制保持两个流量成给定比例，常用开环比值与双闭环比值
  • 前馈与反馈组合成复合控制系统
步骤
  • 写出扰动通道与调节通道的传递函数
  • 按不变性条件求前馈补偿器
  • 对两个需配比的量确定比值系数与乘除环节位置
  • 画出复合或比值控制系统方框图
通用考法
  • 本卷考过用前馈补偿消除二次热水流量扰动的影响
  • 求前馈补偿器使扰动对被控量不产生影响
  • 设计比值控制系统并计算比值系数
  • 说明前馈为什么不影响稳定性
常见易错
  • 前馈补偿器求出含高阶微分、不可实现却直接采用
  • 比值系数没有换算成仪表量程

2二、结构图化简求闭环与扰动传函#

思路
  • 分别以给定输入和扰动为输入化简多回路结构图，用梅森公式写两条通道的传递函数并互相校验
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求C(s)/R(s)与C(s)/N(s)
本卷实例
  • 关键一步：先找全部回路并判断不接触情况，再列各前向通路
  • 中间结果：两路传函共用同一特征式，分子按各自前向通路写
  • 卡点：求扰动传函时要把参考输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求C(s)/R(s)与C(s)/N(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由多回路结构图逐层化简求闭环传函
本卷实例
  • 关键一步：从最内层回路开始等效，再逐层向外合并
  • 中间结果：每合并一层回路数减少一个
  • 卡点：化简内环时不要改动外环的信号关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由多回路结构图逐层化简求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求扰动作用下的输出传递函数
本卷实例
  • 关键一步：单独令扰动为输入、参考输入置零再化简
  • 中间结果：扰动通道传函的分子由扰点到输出的通路构成
  • 卡点：两个输入同时存在时先分别求再叠加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求扰动作用下的输出传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式

3三、闭环极点在垂线左侧的参数范围#

思路
  • 由结构图写闭环特征方程，作s等于s1减一的平移把相对稳定条件化为原点稳定条件，再用劳斯判据求参量范围
劳斯判据 稳定性分析
本卷考法
  • 对平移后的特征方程列劳斯表判断稳定性
本卷实例
  • 关键一步：作变量平移后重新整理特征方程再列劳斯表
  • 中间结果：首列各元素含待求参数
  • 卡点：首列出现零时要用辅助方程或小量法处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过对平移后的特征方程列劳斯表判断稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求闭环极点全部位于给定垂线左侧的参数范围
本卷实例
  • 关键一步：把相对稳定条件化为平移后系统的原点稳定条件
  • 中间结果：参数范围由首列各元素不等式取交集得到
  • 卡点：端点是否包含要看不等式是否严格
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求闭环极点全部位于给定垂线左侧的参数范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式

4四、两质量弹簧阻尼系统状态空间方程#

思路
  • 分别对两质量块作受力分析列牛顿第二定律，取两位移与两速度为状态变量写成矩阵形式
状态空间表达式的建立 状态空间分析
本卷考法
  • 由机械系统列写状态空间表达式
本卷实例
  • 关键一步：先对每个质量块列力平衡方程再化为一阶方程组
  • 中间结果：取两质量块位移与速度共四个状态变量
  • 卡点：弹簧与阻尼器作用在二质量之间，符号要成对出现
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由机械系统列写状态空间表达式
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式
机械系统建模 建模与机电系统
本卷考法
  • 由两质量弹簧阻尼系统列力学方程
本卷实例
  • 关键一步：先定各质量块位移正方向再写相互作用力
  • 中间结果：二质量通过弹簧与阻尼器耦合
  • 卡点：阻尼力与弹簧力的正负方向易取反，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过由两质量弹簧阻尼系统列力学方程
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式

5五、由状态反馈极点反求能控标准型#

思路
  • 按能控标准型设未知系数，加入给定状态反馈后写闭环特征多项式，再令它等于期望极点多项式比较系数
状态反馈与极点配置 状态空间分析
本卷考法
  • 由状态反馈增益与期望极点反求原系统参数
本卷实例
  • 关键一步：先写能控标准型下加入状态反馈后的闭环特征多项式
  • 中间结果：令其与期望极点展开式相等比较同次幂系数
  • 卡点：反馈为负反馈时矩阵中反馈项符号别写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过由状态反馈增益与期望极点反求原系统参数
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
公式
由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 按能控标准型设原系统的A与b
本卷实例
  • 关键一步：把未知系数按能控标准型位置摆进A与b
  • 中间结果：末行为特征多项式系数取负
  • 卡点：友矩阵中系数符号写反会整体错位
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法
  • 本卷考过按能控标准型设原系统的A与b
  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反

6六、离散系统静态误差系数与稳态误差#

思路
  • 由结构图求开环脉冲传函，先判闭环稳定性，再判型别、求静态误差系数并代入输入求稳态误差
离散系统的稳态误差 离散控制系统
本卷考法
  • 求离散系统静态误差系数与稳态误差
本卷实例
  • 关键一步：先由开环脉冲传函判型别再套静态误差系数公式
  • 中间结果：组合输入按各分量分别求误差后相加
  • 卡点：未判稳就用终值定理会得到错误结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差由输入类型与开环脉冲传函中 z=1 处极点的个数决定
  • 型别由 G(z)H(z) 中 z=1 处极点的重数确定
  • 用终值定理求稳态误差，前提是系统稳定
  • 采样周期也影响稳态误差大小
步骤
  • 求误差脉冲传递函数
  • 数出 z=1 处极点重数确定型别
  • 查表或用终值定理求稳态误差
  • 分析采样周期变化对误差的影响
通用考法
  • 本卷考过求离散系统静态误差系数与稳态误差
  • 求离散系统在典型输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 分析采样周期对稳态精度的影响
常见易错
