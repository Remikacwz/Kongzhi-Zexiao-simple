1一、电炉温度控制系统组成与方框图#

思路
  • 由给定电压、热电偶检测、放大与电机执行理清反馈关系，指认各环节并画闭环方框图
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指认被控对象、被控量、执行与检测环节并画方框图
本卷实例
  • 关键一步：先分清给定电压与炉温测量电压，再按偏差信号串起各环节
  • 中间结果：热电偶把炉温转成电压并反馈回比较点形成负反馈
  • 卡点：原理示意图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指认被控对象、被控量、执行与检测环节并画方框图
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

2二、电网络与机械系统相同数学模型#

思路
  • 对电网络用复阻抗法求传函，对机械系统作力分析列方程求传函，再比较分子分母结构
由电路或机械系统求传递函数 传递函数
本卷考法
  • 分别求RLC网络与弹簧质量阻尼系统的传递函数
本卷实例
  • 关键一步：电网络用复阻抗法、机械系统按力平衡列方程
  • 中间结果：两系统输出对输入的传递函数化成同型分式
  • 卡点：电网络图与机械系统图均以图给出，元件接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过分别求RLC网络与弹簧质量阻尼系统的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
机械系统建模 建模与机电系统
本卷考法

本卷实例

  • 中间结果：得到含位移及其一阶二阶导数的耦合微分方程组
  • 卡点：阻尼力与弹簧力的方向易取反，需回原卷核对图

  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数

  • 两质量块经弹簧阻尼连接的系统建模

  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项

3三、由单位阶跃响应求动态性能指标#

思路
  • 把给定阶跃响应与标准二阶欠阻尼响应对照，定出阻尼比与自然频率，再代入各指标公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由给定的单位阶跃响应解析式反求系统参数
本卷实例
  • 关键一步：把响应与标准二阶欠阻尼响应逐项对照
  • 中间结果：由指数衰减率与振荡角频率联立求阻尼比与自然频率
  • 卡点：先判断确属欠阻尼再套二阶公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由给定的单位阶跃响应解析式反求系统参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由响应式求阻尼比与自然频率
本卷实例
  • 关键一步：对照标准式读出衰减系数与有阻尼振荡频率
  • 中间结果：两式联立解出阻尼比与自然频率
  • 卡点：标准式分母根号项易与系数混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由响应式求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求超调量、峰值时间与调节时间
本卷实例
  • 关键一步：先由阻尼比与自然频率代入各指标公式
  • 中间结果：超调量只与阻尼比有关，峰值时间与自然频率有关
  • 卡点：调节时间两种误差带的系数别用混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求超调量、峰值时间与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

4四、劳斯判据判断系统稳定性#

思路
  • 对五阶特征方程列劳斯表，首列出现零时用正无穷小量替代，由变号次数判断右半平面根数
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断五阶系统稳定性并数右半平面根数
本卷实例
  • 关键一步：按特征方程系数列劳斯表，首列出现零用正无穷小量代替
  • 中间结果：由首列变号次数确定右半平面特征根个数
  • 卡点：首列为零时不能直接下结论，要按小量趋近零的正负判
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断五阶系统稳定性并数右半平面根数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式

5五、参数b变化下的根轨迹#

思路
  • 把闭环特征方程整理成以b为参变量的等效开环传函，再按法则画根轨迹的特殊点
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以b为参变量绘制参数根轨迹
本卷实例
  • 关键一步：由闭环特征方程反解出含b的等效开环传递函数
  • 中间结果：等效开环传函的零极点决定根轨迹起点与终点
  • 卡点：参数要完整提到分子，否则起点终点会判反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以b为参变量绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制根轨迹并确定渐近线与实轴段
本卷实例
  • 关键一步：先标开环零极点再判断实轴上的根轨迹段
  • 中间结果：渐近线交点为极点之和减零点之和再除以条数
  • 卡点：渐近线夹角公式分子用二k加一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制根轨迹并确定渐近线与实轴段
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点
本卷实例
  • 关键一步：由分离点方程联立求解并舍去不在根轨迹上的根
  • 中间结果：分离点对应的参数取值为正
  • 卡点：解出后要回到根轨迹上核对取舍
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
出射角与入射角 根轨迹法
本卷考法
  • 求复数极点的出射角
本卷实例
  • 关键一步：按出射角公式累加其余零极点对该极点的相角
  • 中间结果：出射方向决定根轨迹离开复极点的走向
  • 卡点：累加时不含该极点自身的相角
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求复数极点的出射角
  • 求复数极点的出射角
