1一、控制系统组成与稳态误差改善#

思路
  • 先按信号流向补全闭环框图并指认各组成环节，再分析稳态误差无法消除的原因，从提高系统型别或加入补偿环节的角度给出改善方案
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 补全控制系统的功能框图并指认各组成环节
本卷实例
  • 关键一步：按给定、比较、控制、执行、对象、检测的顺序把框图补成闭环
  • 关键一步：把每个方框对应到题面列出的实物元件
  • 中间结果：按信号流向可把框图缺口逐个对应到被控对象、检测元件与执行环节
  • 中间结果：控制器位于偏差信号之后、执行环节之前
  • 卡点：原卷框图为插图，未读图，控制器、执行元件与检测元件的实际位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过补全控制系统的功能框图并指认各组成环节
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
减小稳态误差的措施 稳态误差
本卷考法
  • 分析稳态误差无法消除的原因并给出改善措施
本卷实例
  • 关键一步：先判断误差是否由系统型别不足造成，再看单纯改变增益能否消除
  • 关键一步：若比例控制无法消除，则从提高型别或加入补偿环节入手
  • 中间结果：提高型别能消除对应输入的稳态误差，但会改变闭环稳定性
  • 中间结果：加入积分或前馈补偿可在兼顾稳定性的前提下减小误差
  • 卡点：只回答提高增益或简单加入积分而不校验稳定性，方案不完整
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过分析稳态误差无法消除的原因并给出改善措施
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式

2二、结构图化简求传递函数#

思路
  • 从最内层回路开始逐层化简，必要时先移动比较点或引出点，也可改画信号流图用梅森公式求 C(s)/R(s)
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 用串联、并联与反馈等效公式逐级化简结构图
本卷实例
  • 关键一步：识别环节间的串并联关系，对每个反馈环套用 G/(1+GH)
  • 中间结果：每化掉一个内环，等效环节就并入上一层
  • 卡点：结构图为原卷插图，未读图，反馈极性与连接方式需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过用串联、并联与反馈等效公式逐级化简结构图
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
比较点与引出点的移动 结构图与方框图
本卷考法
  • 移动比较点或引出点使结构图便于化简
本卷实例
  • 关键一步：按移动前后各支路变量关系不变的原则，比较点前移用除、引出点后移用除
  • 中间结果：移动后原来交叉的回路变成可逐层化简的嵌套回路
  • 卡点：移动方向与乘除关系容易搞反，需回原卷核对比较点与引出点编号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过移动比较点或引出点使结构图便于化简
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 对多回路系统从内到外逐层化简求闭环传函
本卷实例
  • 关键一步：先求最内层回路的闭环传函并替换该内环
  • 关键一步：再对外层重复化简直到只剩单回路
  • 中间结果：逐层化简后的单回路分母与梅森公式的特征式一致，可互校
  • 卡点：化简内环时不要把外环信号当常数，否则会漏掉耦合项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过对多回路系统从内到外逐层化简求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图改画信号流图并用梅森公式求传函
本卷实例
  • 关键一步：数清全部独立回路并找出从输入到输出的前向通路
  • 关键一步：对每条通路剔除与它接触的回路后写出余子式
  • 中间结果：特征式按单回路、两两不接触回路的顺序分层累加
  • 卡点：回路条数与前向通路需要回原卷核对图，比较点引出多条支路时容易漏乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图改画信号流图并用梅森公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式

3三、电气系统与机械系统建模及相似性#

思路
  • 分别用复阻抗法求电路的传函、用牛顿第二定律求机械系统的传函，再把两式化成同一形式比较其相似之处
由电路或机械系统求传递函数 传递函数
本卷考法
  • 分别求电路与机械系统的传递函数并比较相似性
本卷实例
  • 关键一步：电路按复阻抗分压列式，机械系统对运动部件列力平衡方程
  • 关键一步：两式取拉氏变换后整理成输出比输入
  • 中间结果：电路与机械系统都化成一阶惯性环节，说明两者存在相似性
  • 卡点：逐年把所求传函方向印成 Ui/Uo，宝典同题印 Uo/Ui，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过分别求电路与机械系统的传递函数并比较相似性
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 用复阻抗法求 RC 电路的传递函数
本卷实例
  • 关键一步：把电容阻抗写成 1/(Cs)，按串联分压写出输出与输入的关系
  • 中间结果：按复阻抗分压整理后电路传函是一个一阶有理式
  • 卡点：原卷电路图未读，元件串并联方式需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过用复阻抗法求 RC 电路的传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
机械系统建模 建模与机电系统
本卷考法
  • 由弹簧阻尼机械系统的力平衡求位移传函
本卷实例
  • 关键一步：选定位移正方向，逐项写出弹簧力与阻尼力
  • 关键一步：按牛顿第二定律列方程并取拉氏变换
  • 中间结果：机械传函同样是一阶惯性环节，时间常数由阻尼与刚度之比决定
  • 卡点：原卷机械图未读，弹簧与阻尼的连接位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过由弹簧阻尼机械系统的力平衡求位移传函
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项

4四、劳斯判据与半平面极点、虚根统计#

思路
  • 把特征方程按降幂排列并列出劳斯表，由首列符号变化次数统计右半平面根数，由全零行对应的辅助方程求虚根
劳斯判据 稳定性分析
本卷考法
  • 用劳斯表首列符号与全零行统计极点分布
本卷实例
  • 关键一步：先把五次多项式按降幂排列，缺项补零后列劳斯表
  • 关键一步：再看首列是否全部同号，若变号则按顺序数清符号变化次数
  • 中间结果：首列符号变化次数给出右半平面根数；若某行全零，取上一行构造辅助方程求虚根
  • 卡点：逐年题面印求后半平面极点数和虚根数，后半平面非教材标准表述
  • 卡点：宝典同题印左半平面，需回原卷核对所统计的半平面
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯表首列符号与全零行统计极点分布
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式

5五、根轨迹绘制与分离点取舍#

思路
  • 由开环传函读出零极点，按根轨迹法则写起点终点、实轴段与渐近线，再由 dK/ds=0 求分离点并筛去不在根轨迹上的根
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则写出根轨迹起点终点、实轴段与渐近线
本卷实例
  • 关键一步：把开环分母分解为一阶与二阶因子，读出全部开环极点
  • 关键一步：极点个数减零点个数即为趋向无穷远的分支数与渐近线条数
  • 中间结果：实轴根轨迹段由该段右侧开环零极点总数为奇数判定
  • 中间结果：渐近线交点取全部开环极点之和除以极点数与零点数之差
  • 卡点：原卷只给传函未附额外图；渐近线夹角公式中的 2k+1 不要写成 2k
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
