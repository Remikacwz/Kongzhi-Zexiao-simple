一一、由微分方程组画系统结构图#

思路
  • 对微分方程组在零初始条件下取拉氏变换，整理出各中间变量之间的传递关系，再按信号流向连接成结构图
传递函数的定义与基本性质 传递函数
本卷考法
  • 由微分方程组在零初始条件下求各变量之间的传递关系
本卷实例
  • 关键一步：先对各微分方程取拉氏变换并利用零初始条件
  • 中间结果：三个方程分别给出误差、输出与反馈量之间的传递关系
  • 卡点：把初始条件直接代入会破坏零初始条件前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由微分方程组在零初始条件下求各变量之间的传递关系
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 按各变量传递关系连接成系统结构图
本卷实例
  • 关键一步：先定比较点再沿信号流向把各环节串接起来
  • 中间结果：反馈量b由输出c经反馈通道送回比较点
  • 卡点：题要求标明各传递函数与中间变量，漏标会失分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过按各变量传递关系连接成系统结构图
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

二二、梅森增益公式求C(s)/R(s)#

思路
  • 按梅森增益公式找全部前向通道与单独回路，写特征式与余子式后求闭环传函
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式由结构图求闭环传递函数
本卷实例
  • 关键一步：先列出所有单独回路并判断回路之间是否接触
  • 中间结果：两条前向通道各自与那个局部回路都不接触
  • 卡点：余子式中未剔除与通路接触的回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式由结构图求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 识别多回路结构中的前向通道与反馈回路
本卷实例
  • 关键一步：沿信号流向从输入到输出找全部前向通道
  • 中间结果：只有一个局部反馈回路改变特征式
  • 卡点：把回路增益与前向通道增益混在一起
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过识别多回路结构中的前向通道与反馈回路
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

三三、阶跃斜坡与抛物线组合输入下的稳态误差#

思路
  • 先由闭环特征方程判稳，再按型别用静态误差系数分别求三种输入分量的误差并叠加
系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环传函判断系统型别并求静态误差系数
本卷实例
  • 关键一步：把开环传函化成尾1标准型再数积分环节个数
  • 中间结果：开环传函含两个积分环节，型别由此确定
  • 卡点：数错积分环节个数导致型别判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由开环传函判断系统型别并求静态误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求阶跃、斜坡与抛物线组合输入下的稳态误差
本卷实例
  • 关键一步：把组合输入拆成三种典型分量分别求误差再叠加
  • 中间结果：各分量误差是否有限取决于系统型别
  • 卡点：输入为组合信号时漏掉某一分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求阶跃、斜坡与抛物线组合输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

四四、两质量弹簧阻尼系统状态空间方程#

思路
  • 对两质量块分别列牛顿第二定律，选位移与速度为状态变量，整理成四阶状态空间表达式
机械系统建模 建模与机电系统
本卷考法
  • 两质量块经弹簧与阻尼器连接系统的受力分析
本卷实例
  • 关键一步：对每个质量块分别列牛顿第二定律并保留相互作用力
  • 中间结果：弹簧与阻尼器的相对位移和相对速度出现在两个方程中
  • 卡点：阻尼力与弹簧力的正负方向取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过两质量块经弹簧与阻尼器连接系统的受力分析
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
状态空间表达式的建立 状态空间分析
本卷考法
  • 选位移与速度作状态变量写出状态空间表达式
本卷实例
  • 关键一步：把两个二阶方程降为一阶方程组并按输出要求写C矩阵
  • 中间结果：状态向量由两个位移与两个速度组成
  • 卡点：状态变量个数与系统阶数不匹配
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过选位移与速度作状态变量写出状态空间表达式
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

五五、参数根轨迹与稳定范围#

思路
  • 由开环零极点按法则画K星从零到正无穷的根轨迹，求分离点、出射角与虚轴交点后确定稳定的K星范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则确定根轨迹的分支数、实轴段与渐近线
本卷实例
  • 关键一步：先标开环零极点再判断实轴上的根轨迹段
  • 中间结果：三条分支全部趋向无穷远，渐近线夹角为六十度与一百八十度
  • 卡点：渐近线夹角公式分子用二k加一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则确定根轨迹的分支数、实轴段与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 判断该参数根轨迹是否存在分离点
本卷实例
  • 关键一步：由特征方程写出增益表达式后令其导数为零
  • 中间结果：解出的候选根不在实轴根轨迹上应舍去
  • 卡点：求出方程根后不筛选就保留
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过判断该参数根轨迹是否存在分离点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
出射角与入射角 根轨迹法
本卷考法
  • 求复数极点的出射角确定根轨迹起始方向
本卷实例
  • 关键一步：由相角条件累加其他零极点对该极点的相角
  • 中间结果：一对共轭极点的出射角互为相反数
  • 卡点：累加相角时把该极点自身的相角也算进去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求复数极点的出射角确定根轨迹起始方向
  • 求复数极点的出射角
  • 根据出射角画出根轨迹起始方向
  • 由入射角确定根轨迹终止方向
常见易错
  • 累加相角时把该极点自身的相角也算进去
  • 忘记判断象限导致角度差 180°
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴的交点及临界增益
本卷实例
  • 关键一步：令特征方程出现纯虚根并分离实部与虚部联立
  • 中间结果：虚轴交点对应的增益就是稳定的临界值
  • 卡点：只代一个频率可能漏掉另一组交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴的交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

六六、奈奎斯特图与稳定T范围#

思路
  • 写出开环频率特性并画奈氏图，按参数T的不同区间讨论与负实轴的交点和包围数，由Z等于P减二N确定稳定的T范围
奈奎斯特判据 稳定性分析
本卷考法
