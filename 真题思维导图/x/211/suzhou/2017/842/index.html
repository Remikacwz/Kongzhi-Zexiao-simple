一一、热交换系统组成与方框图16 分#

思路
  • 由热电偶测温、比较器、控制器与蒸汽阀门理清温度反馈关系，指认传感器、被控量与执行器并画方块图
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指认温度传感器、被控量、执行器并说明工作过程
本卷实例
  • 关键一步：先分清期望温度与实际温度的给定与反馈通道
  • 中间结果：温度偏差经控制器改变蒸汽阀门开度
  • 卡点：热交换器流程以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指认温度传感器、被控量、执行器并说明工作过程
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

二二、输入与扰动同时作用下的稳态误差13 分#

思路
  • 分别令参考输入与扰动单独作用，用终值定理求各自的稳态误差再按叠加原理相加
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动作用下的稳态误差
本卷实例
  • 关键一步：令参考输入为零，先写误差对扰动的传递函数
  • 中间结果：扰动误差由扰动幅度与扰动通道传函的直流增益决定
  • 卡点：求扰动误差时不能套用静态误差系数法
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求扰动作用下的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求参考输入作用下的稳态误差
本卷实例
  • 关键一步：先判稳再由型别与静态误差系数求输入误差
  • 中间结果：输入误差分量与扰动误差分量分属两条通道
  • 卡点：用终值定理前要先判稳；系统结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求参考输入作用下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

三三、二阶系统动态指标及参数变化分析15 分#

思路
  • 由开环传函化闭环标准二阶形式，由系数关系解出阻尼比与自然频率，算峰值时间、调节时间与超调量，再比较参数变化后的走向
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函求阻尼比与自然频率
本卷实例
  • 关键一步：把闭环分母化为标准二阶形式再比较系数
  • 中间结果：阻尼比与自然频率由开环增益与时间参数共同决定
  • 卡点：化标准形式时先归一化二次项系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 计算峰值时间、调节时间与超调量并分析参数影响
本卷实例
  • 关键一步：先由阻尼比与自然频率求峰值时间与调节时间
  • 中间结果：超调量只随阻尼比变化
  • 卡点：调节时间的误差带要与题目给定的一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过计算峰值时间、调节时间与超调量并分析参数影响
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

四四、结构图化简求传函13 分#

思路
  • 用比较点与引出点的等效移动处理交叉结构，再逐层合并各回路求出闭环传函
比较点与引出点的移动 结构图与方框图
本卷考法
  • 用比较点与引出点移动化简交叉结构图
本卷实例
  • 关键一步：先把跨接点移到便于合并的位置
  • 中间结果：移动后结构化为若干串并联与局部反馈
  • 卡点：移动方向与乘除关系别搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过用比较点与引出点移动化简交叉结构图
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由多回路结构图逐层化简求闭环传函
本卷实例
  • 关键一步：从最内层回路开始等效再向外合并
  • 中间结果：每合并一层回路数减少一个
  • 卡点：化简内环时不要改动外环信号关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由多回路结构图逐层化简求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 把化简后的串并联与反馈支路按等效规则合并
本卷实例
  • 关键一步：分别按串联相乘、并联相加、反馈取前向比一加减回路
  • 中间结果：各局部等效结果再串接成总传函
  • 卡点：负反馈分母写成一加回路增益；本题结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过把化简后的串并联与反馈支路按等效规则合并
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

五五、根轨迹绘制及复平面圆特性16 分#

思路
  • 由开环零极点按法则画根轨迹，再由闭环特征方程消参证明复数分支为圆
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则确定分支数、实轴段与渐近线
本卷实例
  • 关键一步：先标开环零极点再判断实轴上的根轨迹段
  • 中间结果：一条分支终止于零点，另一条趋于无穷远
  • 卡点：渐近线夹角公式分子用二k加一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则确定分支数、实轴段与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点与会合点
本卷实例
  • 关键一步：由闭环特征方程写出增益表达式再令其导数为零
  • 中间结果：候选分离点需回到实轴段上筛选
  • 卡点：解出后要按实轴段取舍
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点与会合点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 判断根轨迹是否穿越虚轴
本卷实例
  • 关键一步：令纯虚根代入特征方程分离实部与虚部
  • 中间结果：本例方程组无正频率解，轨迹不穿越虚轴
  • 卡点：只代一个频率可能漏掉另一组交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过判断根轨迹是否穿越虚轴
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式

六六、开环对数频率特性与相角裕度16 分#

思路
  • 由开环传函按典型环节叠加画对数幅频渐近线，再由幅值条件求截止频率进而算相角裕度并判断稳定性
开环对数频率特性的绘制 频域分析
本卷考法
  • 按转折频率逐段绘制开环对数幅频特性
本卷实例
  • 关键一步：先由积分环节个数定低频段斜率再逐段改斜率
  • 中间结果：幅频特性在三个转折频率处依次变化
  • 卡点：低频段起始高度要与型别和增益一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过按转折频率逐段绘制开环对数幅频特性
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
