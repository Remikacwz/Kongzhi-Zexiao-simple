1一、结构图化简求闭环传递函数15 分#

思路
  • 按比较点与引出点把多回路结构图拆成可合并的小块，先用串联并联与反馈等效逐层化简，再用梅森增益公式校验结果。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 用逐层化简法求多回路系统的闭环传递函数
本卷实例
  • 关键一步：先合并内环，再逐层向外合并到输入端
  • 中间结果：外层反馈的分母随内环化简结果同步更新
  • 卡点：化简内环时把外层信号当常数会出错
  • 卡点：图1支路与比较点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过用逐层化简法求多回路系统的闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 用串联并联与反馈等效公式合并各支路
本卷实例
  • 关键一步：按比较点与引出点把结构图拆成可合并的小块
  • 中间结果：负反馈合并时分母取 1 加回路传递函数
  • 卡点：负反馈分母误写成 1 减回路传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过用串联并联与反馈等效公式合并各支路
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式校验化简得到的闭环传函
本卷实例
  • 关键一步：列出全部回路与前向通路，写出特征式
  • 中间结果：四个回路两两接触时特征式只取回路之和
  • 卡点：两两不接触回路少算或重复计数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式校验化简得到的闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、结构图与扰动下的稳态误差15 分#

思路
  • 分别令参考输入与扰动单独作用，写出各自的误差传递函数，按典型输入求稳态误差后叠加，再分析各增益对两种误差的相反影响。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 第(1)问求 r(t)=t、D(t)=0.5×1(t) 下的误差
本卷实例
  • 关键一步：分别令单一输入作用，求误差后再按叠加定理相加
  • 中间结果：速度输入误差由速度误差系数倒数给出
  • 卡点：非单位幅值的扰动要乘上输入幅值再计算
  • 卡点：图3扰动作用点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过第(1)问求 r(t)=t、D(t)=0.5×1(t) 下的误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 第(1)问单独求阶跃扰动作用下的稳态误差
本卷实例
  • 关键一步：令参考输入为零，写扰动到输出的传递函数
  • 中间结果：扰动误差的符号为负，反映误差定义方向
  • 卡点：扰动误差与输入误差方向不同，符号易漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过第(1)问单独求阶跃扰动作用下的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 第(2)问分析调整K1、K2、K3对两种误差的影响
本卷实例
  • 关键一步：先写出误差表达式再对增益逐项求变化趋势
  • 中间结果：减小输入误差与减小扰动误差对增益的要求相反
  • 卡点：只调一个参数往往顾此失彼，需兼顾稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过第(2)问分析调整K1、K2、K3对两种误差的影响
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

3三、由动态指标反求参数与改善动态性能15 分#

思路
  • 由结构图写出闭环传函并化为二阶标准形式，利用5%误差带调节时间与超调量两个条件反求K1、K2，再从提高自然频率与提高阻尼比两个方向给出改善措施。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环结构图写出标准二阶形式并读阻尼比
本卷实例
  • 关键一步：把闭环传函分母首项归一化后与标准式比较系数
  • 中间结果：自然频率与阻尼比由分母一次项和常数项表示
  • 卡点：结构图含参数，写分母时容易漏乘反馈支路
  • 卡点：图4反馈支路连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环结构图写出标准二阶形式并读阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由调节时间与超调量反求阻尼比和自然频率
本卷实例
  • 关键一步：由超调量查阻尼比，再由调节时间求自然频率
  • 中间结果：5% 误差带下调节时间与阻尼比自然频率成反比
  • 卡点：误差带不同调节时间公式的系数会不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由调节时间与超调量反求阻尼比和自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 第(2)问给出至少两种提高动态性能的方法
本卷实例
  • 关键一步：从增大自然频率和提高阻尼比两个方向提出方案
  • 中间结果：增大K1抬高自然频率，增大K2提高阻尼比
  • 卡点：提高快速性的同时要防止超调量变大
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过第(2)问给出至少两种提高动态性能的方法
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

4四、含可变参数的根轨迹绘制15 分#

思路
  • 把闭环特征方程中含参数K的项分离出来写成等效开环传递函数，再按常规根轨迹法则画分支、实轴段、渐近线、分离点与虚轴交点。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 把闭环特征方程整理为等效开环形式再画根轨迹
本卷实例
  • 关键一步：从特征方程中分离含K的项写成等效开环传函
  • 中间结果：等效开环的极点与零点决定根轨迹起止点
  • 卡点：参数不是开环增益，幅值条件对应的临界值需另求
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过把闭环特征方程整理为等效开环形式再画根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画根轨迹的分支、实轴段与渐近线
本卷实例
  • 关键一步：先定开环零极点，再判实轴段与渐近线方向
  • 中间结果：三条分支中两条沿渐近线趋于无穷
  • 卡点：渐近线夹角公式中共轭分支数容易数错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画根轨迹的分支、实轴段与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点并舍去不在根轨迹上的解
本卷实例
  • 关键一步：用分离点方程求根后代回原特征方程检验
  • 中间结果：三个候选根中只有一个落在根轨迹上
  • 卡点：分离点方程两边同乘会引入增根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式

  • 判断系统能控性以确认极点可任意配置

  • 构造能观性矩阵并求秩
