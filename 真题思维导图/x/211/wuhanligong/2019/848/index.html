11、由方程组画系统框图与逐层化简#

思路
  • 由所给信号关系式画出系统框图，再按引出点后移、并联合并与反馈内环化简逐层求闭环传递函数。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 用逐层化简法求多回路系统闭环传函
本卷实例
  • 关键一步：先合并内环再逐层向外合并到输入端
  • 中间结果：外层反馈的分母随内环化简同步更新
  • 卡点：化简内环时把外层信号当常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过用逐层化简法求多回路系统闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 用串联并联与反馈等效合并各支路
本卷实例
  • 关键一步：按比较点与引出点把结构图拆成可合并小块
  • 中间结果：前向通路与反馈通路分别合并后再闭环
  • 卡点：负反馈分母误写成 1 减回路传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过用串联并联与反馈等效合并各支路
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

比较点与引出点的移动 结构图与方框图
本卷考法
  • 用引出点后移把交叉连接化为可合并形式
本卷实例
  • 关键一步：引出点后移时按移动方向补乘或补除环节
  • 中间结果：移动后新增支路增益按规则补上
  • 卡点：引出点与比较点的移动规则混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过用引出点后移把交叉连接化为可合并形式
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用

22、输入与扰动共同作用下的稳态误差#

思路
  • 误差取 R 减 C，对输入与扰动分别求误差传函，用终值定理求斜坡作用下的稳态误差，再由补偿增益使输入引起的稳态误差为零。
误差定义与误差传递函数 稳态误差
本卷考法
  • 按 R 减 C 定义写输入与误差传递函数
本卷实例
  • 关键一步：用 1 减闭环传函写误差传函
  • 中间结果：输入与扰动分别置零单独求误差
  • 卡点：非单位反馈时两种误差定义混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过按 R 减 C 定义写输入与误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由终值定理求输入引起的稳态误差
本卷实例
  • 关键一步：先判稳再把斜坡输入代入终值定理
  • 中间结果：误差系数法结果与终值定理结果一致
  • 卡点：未判稳就使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由终值定理求输入引起的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动单独作用引起的稳态误差
本卷实例
  • 关键一步：求扰动误差传函时把参考输入置零
  • 中间结果：扰动误差与输入误差按线性叠加
  • 卡点：把扰动误差直接当作总误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求扰动单独作用引起的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

33、测速反馈对稳定与动稳态性能的影响#

思路
  • 由闭环特征方程列劳斯表讨论测速反馈系数对稳定性的影响，再由闭环传函化为二阶标准形式分析阻尼比与斜坡稳态误差。
劳斯判据 稳定性分析
本卷考法
  • 由闭环特征方程列劳斯表讨论参数影响
本卷实例
  • 关键一步：列劳斯表并令首列各项大于零
  • 中间结果：参数为零时出现全零行对应纯虚根
  • 卡点：三阶系统漏掉常数项的正负约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由闭环特征方程列劳斯表讨论参数影响
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函化为二阶标准形式求阻尼比
本卷实例
  • 关键一步：由特征式系数对应 wn 与阻尼比
  • 中间结果：阻尼比随测速反馈系数单调增大
  • 卡点：化为标准形式时忘记把 s 平方项系数归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函化为二阶标准形式求阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比分区讨论阶跃响应超调与振荡
本卷实例
  • 关键一步：欠阻尼有超调、临界与过阻尼单调上升
  • 中间结果：阻尼比越大超调越小但响应变慢
  • 卡点：把两种误差带的调节时间系数搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比分区讨论阶跃响应超调与振荡
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

44、含开环零点根轨迹与稳定增益范围#

思路
  • 由 1+G(s)=0 列特征方程，画含开环零点根轨迹，求分离点与虚轴交点，再由根全部位于左半平面确定稳定增益范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则求根轨迹起点终点分支数与实轴段
本卷实例
  • 关键一步：数开环极点与零点个数定分支数
  • 中间结果：实轴段按右侧实零极点总数为奇数判定
  • 卡点：实轴段判据零极点个数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则求根轨迹起点终点分支数与实轴段
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 由增益对 s 求导为零求分离点并取舍
本卷实例
  • 关键一步：把增益整理成 s 的显函数再求导
  • 中间结果：分离点须落在实轴根轨迹段上
  • 卡点：求出方程根后不筛选保留无效解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由增益对 s 求导为零求分离点并取舍
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 令 s 等于 jw 求根轨迹与虚轴交点
本卷实例
  • 关键一步：实部虚部分别为零联立求解
  • 中间结果：虚轴交点处对应临界增益
  • 卡点：只代一组频率漏掉另一组交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
