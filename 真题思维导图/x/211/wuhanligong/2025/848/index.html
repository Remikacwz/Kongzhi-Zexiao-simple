1一、信号流图与梅森公式#

思路
  • 由系统结构图先画出信号流图，标出各独立回路与前向通路，用梅森公式分别求输出对参考输入和输出对Q(s)的传递函数，再将两式相除得到C(s)/Q(s)。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图画信号流图并用梅森公式求闭环传函
本卷实例
  • 关键一步：先按结构图补全信号流图的节点与支路，再数清独立回路
  • 中间结果：特征式由独立回路与两两不接触回路逐项累加得到
  • 卡点：结构图未读图，比较点与引出点引出的支路数需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图画信号流图并用梅森公式求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 两输入下分别求传函再相比得C(s)/Q(s)
本卷实例
  • 关键一步：令另一输入为零，分别求出输出对两个输入的传递函数
  • 中间结果：两式相除消去公共输入，得到C(s)与Q(s)之间的传递关系
  • 卡点：Q(s)支路的正负号容易漏，需回原卷图1核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过两输入下分别求传函再相比得C(s)/Q(s)
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错

  • 求扰动传函时没有把参考输入置零

2二、二阶系统时域指标与速度反馈#

思路
  • 由图写出闭环传递函数并化为二阶标准形式，由给定阻尼比确定待求参数；再在Δ=0.05误差带下求各项动态性能指标；最后说明速度反馈对动态性能与稳态误差的影响。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函化为二阶标准形式并由阻尼比确定k
本卷实例
  • 关键一步：把闭环传函分母首项归一化后与二阶标准形式逐项比较系数
  • 中间结果：自然频率与阻尼比由分母常数项和一次项系数共同表示
  • 卡点：图2未读图，前向通路增益与反馈支路结构需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函化为二阶标准形式并由阻尼比确定k
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 在Δ=0.05误差带下求动态性能指标
本卷实例
  • 关键一步：先由阻尼比判断欠阻尼，再按误差带代入对应近似公式
  • 中间结果：峰值时间、上升时间与调节时间都由自然频率和阻尼比决定
  • 卡点：源文只写Δ=0.05，未指明具体指标名称，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过在Δ=0.05误差带下求动态性能指标
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

反馈校正与复合控制 系统校正
本卷考法
  • 说明速度反馈对动态性能与稳态误差的优缺点
本卷实例
  • 关键一步：从阻尼改善与稳态误差变化两方面比较加与不加速度反馈
  • 中间结果：速度反馈相当于增大等效阻尼，同时降低开环增益
  • 卡点：容易只答动态性能改善而漏答稳态误差变大
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过说明速度反馈对动态性能与稳态误差的优缺点
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

3三、参数稳定域与输入扰动稳态误差#

思路
  • 由图写出开环传递函数和闭环特征方程，用劳斯判据列稳定条件；再分别在单位斜坡输入与单位阶跃扰动下求稳态误差并叠加，令总误差不超过给定值；联立两组不等式求a与k的范围。
劳斯判据 稳定性分析
本卷考法
  • 对四阶特征方程列劳斯表求稳定条件
本卷实例
  • 关键一步：把特征方程按降幂排列后逐行交叉相减列劳斯表
  • 中间结果：首列各元素含参数a与k，令首列同号得到不等式组
  • 卡点：首列含分式时整理容易丢掉分母的符号约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过对四阶特征方程列劳斯表求稳定条件
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 把劳斯表首列同号条件化为a与k的稳定域
本卷实例
  • 关键一步：令劳斯表首列每个元素大于零，再取各不等式解集的交集
  • 中间结果：稳定域边界对应首列某项变号为零的等式
  • 卡点：容易只保留一个不等式而漏掉其余约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过把劳斯表首列同号条件化为a与k的稳定域
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：先由开环传函的积分环节个数判断系统型别
  • 中间结果：斜坡输入的稳态误差由静态速度误差系数的倒数给出
  • 卡点：使用终值定理前需先确认闭环稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

扰动作用下的稳态误差 稳态误差
本卷考法
  • 求单位阶跃扰动下的稳态误差并叠加
本卷实例
  • 关键一步：令参考输入为零，单独写扰动到误差的传递函数
  • 中间结果：阶跃扰动误差由扰动作用点之前的增益决定
  • 卡点：扰动误差与输入误差要分开计算后再叠加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤

  • 与输入引起的误差叠加
通用考法
  • 本卷考过求单位阶跃扰动下的稳态误差并叠加
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

4四、以a为变量的参数根轨迹#

思路
  • 由闭环特征方程把参数a提到标准位置得到等效开环传函，令s为复数代入特征方程证明虚部根轨迹为圆；k=4时按绘制法则画以a为变量的参数根轨迹，求分离点与虚轴交点。
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 由闭环特征方程证明虚部根轨迹为圆
本卷实例
  • 关键一步：令s为复数代入闭环特征方程，分离实部与虚部
  • 中间结果：消去可变参数后得到以原点为圆心的圆方程
  • 卡点：变量a不能当作固定量直接消去，需保留其与根的关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过由闭环特征方程证明虚部根轨迹为圆
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 把参数a提到标准位置写等效开环传函
本卷实例
  • 关键一步：从闭环特征方程分离含参数a的项，写成等效开环形式
  • 中间结果：等效开环传函的极点与零点决定参数根轨迹的起止点
  • 卡点：参数不是开环增益，幅值条件对应的临界值需另求
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过把参数a提到标准位置写等效开环传函
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画以a为变量的参数根轨迹
本卷实例
  • 关键一步：先定分支数与起止点，再画实轴段、渐近线与分离点
  • 中间结果：两条分支分别终止于开环零点与无穷远处
  • 卡点：参数根轨迹的起止点与常规根轨迹相反，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n

10十、串联校正与反馈校正综合#

思路
  • 由静态速度误差要求确定开环增益最小值；串联给定网络后按转折频率重新求剪切频率与穿越频率，计算相角裕度和幅值裕度并判断校正类型；最后引入负反馈，以反馈系数为参数画根轨迹，找同时满足超调与稳态误差要求的反馈系数。
系统型别与静态误差系数 稳态误差
本卷考法
  • 由静态速度误差系数确定开环增益最小值
本卷实例
  • 关键一步：先由开环传函写静态速度误差系数与开环增益的关系
  • 中间结果：斜坡输入下的稳态误差与开环增益成反比
  • 卡点：由误差要求定出的增益还需用稳定裕度复验
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由静态速度误差系数确定开环增益最小值
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
稳定裕度 频域分析
本卷考法
  • 求串联校正前后的相角裕度与幅值裕度
本卷实例
  • 关键一步：校正后按转折频率重新分段求剪切频率与穿越频率
  • 中间结果：超前网络的零点先行作用，使中频段相位提前
  • 卡点：校正前后剪切频率不同，两项裕度需分别计算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求串联校正前后的相角裕度与幅值裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

超前校正 系统校正
本卷考法
  • 由给定校正网络判断超前校正并说明作用
本卷实例
  • 关键一步：比较校正网络分子与分母时间常数的大小判断零极点先后
  • 中间结果：零点转折频率低于极点转折频率时呈现相位超前
  • 卡点：超前校正抬高高频段，可能削弱噪声抑制能力
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 会使截止频率提高，响应加快

  • 最大超前角不超过 60°，否则噪声放大明显

  • 设计串联超前校正装置

  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

减小稳态误差的措施 稳态误差
本卷考法
  • 说明加反馈后阶跃输入稳态误差为零的原因
本卷实例
  • 关键一步：由反馈校正后的开环传函判断系统型别是否提高
  • 中间结果：开环含积分环节时阶跃输入下的静态位置误差系数为无穷
  • 卡点：闭环稳定是稳态误差结论成立的前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过说明加反馈后阶跃输入稳态误差为零的原因
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
