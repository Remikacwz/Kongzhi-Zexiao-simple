1一、电路建模与动态结构图求传函15 分#

思路
  • 由电路列节点电流与电压关系，消元得方程与动态结构图，再用梅森增益公式求 U2(s)/U1(s)。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由RLC电路列复阻抗方程求U2(s)/U1(s)
本卷实例
  • 关键一步：用电容阻抗1比Cs与电感阻抗Ls把电路写成代数式
  • 中间结果：先列节点电流与电压关系，再消去中间变量
  • 卡点：电路以图给出，需回原卷核对图
  • 卡点：复阻抗法别把电容阻抗写成Cs
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由RLC电路列复阻抗方程求U2(s)/U1(s)
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式校验化简所得传递函数
本卷实例
  • 关键一步：数清回路并找齐前向通路后写特征式
  • 中间结果：回路两两接触时特征式只含回路之和
  • 卡点：不接触回路漏算或重复计数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项

  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触

  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

本卷考法
  • 讨论局部反馈系数a变化时稳定域的变化
本卷实例
  • 关键一步：由劳斯首列大于零列出参数不等式组

  • 区间端点通常对应临界稳定，即根落在虚轴上

步骤

  • 比较不同参数对稳定域大小的影响
常见易错

  • 取交集时把端点是否包含搞错

劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断三阶闭环系统的稳定性
本卷实例
  • 关键一步：由闭环特征方程逐行列劳斯表
  • 中间结果：首列各项同号时系统才稳定
  • 卡点：系数缺项时不补零会误判
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断三阶闭环系统的稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由阶跃响应单调上升判断闭环极点均为负实根
本卷实例
  • 关键一步：令特征方程根不进入复平面
  • 中间结果：单调条件对应极点判别式非负
  • 卡点：把无超调简单等同于阻尼比大于零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由阶跃响应单调上升判断闭环极点均为负实根
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

零极点分布与响应模态 传递函数
本卷考法

本卷实例

  • 中间结果：实根对应单调项，复根对应振荡项
  • 卡点：忽略零点对振荡模态的削弱作用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤

  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由闭环极点分布判断阶跃响应是否单调
  • 由极点分布写出响应的大致形式

常见易错

4四、以参数z的根轨迹15 分#

思路
  • 把含z的闭环特征方程整理成 1+z·G_eq(s)=0 的等效形式，按参数根轨迹法则画轨迹并分析稳定性和动态性能。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以z为变量绘制参数根轨迹并分析稳定性
本卷实例
  • 关键一步：把特征方程化成1加z乘等效开环的形式
  • 中间结果：等效开环的极点由原分母与零点重组
  • 卡点：参数未完整提到分子会画错起点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以z为变量绘制参数根轨迹并分析稳定性
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
