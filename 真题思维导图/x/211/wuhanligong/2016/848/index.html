一一、结构图求开环传函与二阶参数15 分#

思路
  • 由含局部反馈的结构图求开环传函，再化为标准二阶形式，用 ωn 与 ξ 反求结构参数a和K。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由含局部反馈与积分环节的结构图求开环传函
本卷实例
  • 关键一步：先化简局部反馈内环再串入积分环节
  • 中间结果：开环传函分母为(10a+1)s²加s
  • 卡点：局部反馈信号方向弄反会使分母符号错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由含局部反馈与积分环节的结构图求开环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为标准二阶形式求ωn与ξ
本卷实例
  • 关键一步：写出闭环特征式并与标准二阶系数对比
  • 中间结果：标准式中ωn²与2ξωn分别对应两系数
  • 卡点：忘记把s²项系数归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为标准二阶形式求ωn与ξ
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由ωn与ξ反求结构参数a和K
本卷实例
  • 关键一步：用两个系数等式联立解a与K
  • 中间结果：两式分别含10k与10a加1
  • 卡点：只满足一个指标就下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由ωn与ξ反求结构参数a和K
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

二二、劳斯判据求稳定增益范围15 分#

思路
  • 对 G(s)=K(s+2)/(s(s+1)(s²+2s+2)) 展开闭环特征方程，用劳斯判据求稳定增益范围。
劳斯判据 稳定性分析
本卷考法
  • 由四阶特征方程用劳斯判据求稳定K范围
本卷实例
  • 关键一步：展开分母后逐行列劳斯表
  • 中间结果：特征式为s⁴加3s³加4s²加(k+2)s加2k
  • 卡点：中间行首项为零时不会用ε法
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由四阶特征方程用劳斯判据求稳定K范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 解劳斯首列不等式组求K的稳定区间
本卷实例
  • 关键一步：联立三组不等式后取交集
  • 中间结果：稳定上界由首列两个元素共同限制
  • 卡点：取交集时漏掉一个非零约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过解劳斯首列不等式组求K的稳定区间
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

四四、含重极点的根轨迹与稳定性15 分#

思路
  • 对 G(s)=K/(s²(s+2)(s+5)) 按根轨迹法则绘制并判断系统是否始终不稳定。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制含原点重极点的根轨迹草图
本卷实例
  • 关键一步：先定起点为原点两重极点再定渐近线
  • 中间结果：四条分支、渐近线夹角为45度系
  • 卡点：重极点处的分支数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制含原点重极点的根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式

五五、由幅值裕度反求增益15 分#

思路
  • 对 G(s)=K/(s(s²+s+100)) 由相角条件求相位穿越频率，再由20分贝幅值裕度反求K。
稳定裕度 频域分析
本卷考法
  • 由幅值裕度20分贝反求开环增益K
本卷实例
  • 关键一步：先令相频为负180度求相位穿越频率
  • 中间结果：穿越频率处幅值等于0.1的条件式
  • 卡点：把ωc与ωg两个频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性

传递函数的定义与基本性质 传递函数
本卷考法
  • 由微分方程写出传递函数
本卷实例
  • 关键一步：对方程两边作零初始条件下的拉氏变换
  • 中间结果：输出与输入拉氏变换之比即传函
  • 卡点：未用零初始条件会把初值带入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由微分方程写出传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
