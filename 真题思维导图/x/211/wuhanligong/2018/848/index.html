武汉理工大学 848 自动控制原理（含现控） 2018 年真题思维导图

211 院校共 10 题

难度：中等　全卷10题（一~十）。覆盖二端口网络负载效应、斜坡稳态误差反求增益、劳斯判据全零行与特征根、含右半平面零点的零度根轨迹、奈氏曲线起点象限讨论、开环对数幅频与稳定裕度、滞后校正、离散系统动态性能、由传函建立状态空间并做状态反馈、由结构图求状态方程与能控能观；含图题多。

一一、二端口网络求传函与负载效应#

思路
  • 由二端口网络结构图列电容电流与电压关系，消元求 Uo/Ui，再与两级一阶网络直接相乘的结果比较，由负载效应说明二者不能等同。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由二端口RC网络结构图求电压比传函
本卷实例
  • 关键一步：电流经电容的关系列微积分方程再取拉氏变换
  • 中间结果：消去中间电流得二阶有理分式
  • 卡点：复阻抗法别把电容阻抗写成Cs
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由二端口RC网络结构图求电压比传函
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法

本卷实例

  • 中间结果：两电容电流经同一节点电阻耦合
  • 卡点：漏掉前级输出对后级输入的影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过列写两电容电流与节点电压关系式
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足

串联、并联与反馈等效 结构图与方框图
本卷考法
  • 判断后级网络是否改变前级输出而破坏串联相乘
本卷实例
  • 关键一步：比较级联乘积与整体传函是否相等
  • 中间结果：两式分母仅差电容耦合项
  • 卡点：把无源网络串联直接当传函相乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

二二、斜坡稳态误差反求增益与闭环传函#

思路
  • 对开环传函 k/[s(s+2)] 用静态速度误差系数法由稳态误差反求增益，再写单位负反馈闭环传函并由终值定理求阶跃输出稳态值。
系统型别与静态误差系数 稳态误差
本卷考法
  • 由单位斜坡稳态误差反求静态速度误差系数
本卷实例
  • 关键一步：先写出静态速度误差系数表达式
  • 中间结果：速度误差系数与稳态误差互为倒数
  • 卡点：未先判稳就套用静态误差系数法
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由单位斜坡稳态误差反求静态速度误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 把给定稳态误差代入误差系数式反解开环增益
本卷实例
  • 关键一步：把给定稳态误差代入误差系数式反解增益
  • 中间结果：得到开环增益后再写闭环传函
  • 卡点：组合输入时漏掉某一输入分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过把给定稳态误差代入误差系数式反解开环增益
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

串联、并联与反馈等效 结构图与方框图
本卷考法

本卷实例

三三、劳斯判据全零行与特征根#

思路
  • 对七阶特征方程列劳斯表，遇全零行用辅助方程求导后的系数替换，据首列变号判不稳定，再由辅助方程与余式分解求全部特征根。
劳斯判据 稳定性分析
本卷考法
  • 七阶特征方程劳斯表全零行处理
本卷实例
  • 关键一步：全零行用辅助方程求导后的系数替换
  • 中间结果：首列变号两次说明有两个正根
  • 卡点：首列为零后未用 ε 法继续算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过七阶特征方程劳斯表全零行处理
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
零极点分布与响应模态 传递函数
本卷考法
  • 由辅助方程与余式分解求全部特征根
本卷实例
  • 关键一步：辅助方程的根即一对共轭特征根
  • 中间结果：原特征式可分解为辅助式乘余式
  • 卡点：漏掉共轭根的另一半
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由辅助方程与余式分解求全部特征根
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零
公式

四四、零度根轨迹绘制#

思路
  • 由 1-G(s)=0 判定应画零度根轨迹，再按起点终点、实轴段、渐近线、分离点与虚轴交点逐步绘制。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 由特征方程形式判断应绘制零度根轨迹
本卷实例
  • 关键一步：把特征方程整理成一减 G 等于零
  • 中间结果：相角条件取 360 度的整数倍
  • 卡点：零度根轨迹仍套 180 度相角条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过由特征方程形式判断应绘制零度根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则求根轨迹分支数与渐近线
本卷实例
  • 关键一步：数开环极点数 n 与零点数 m 定分支
  • 中间结果：渐近线交点在极零点重心处
  • 卡点：实轴段判据零极点个数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则求根轨迹分支数与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 由增益对 s 求导为零求分离点并取舍
本卷实例
  • 关键一步：把增益写成 s 的显函数再求导
  • 中间结果：分离点须落在实轴根轨迹段上
  • 卡点：求出方程根后不筛选保留无效解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由增益对 s 求导为零求分离点并取舍
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 令 s 等于 jw 代入特征方程求虚轴交点
本卷实例
  • 关键一步：实部虚部分别为零联立求解
  • 中间结果：临界增益对应根轨迹穿越虚轴处
  • 卡点：只代一组频率漏掉另一组交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过令 s 等于 jw 代入特征方程求虚轴交点
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

五五、奈氏曲线与参数对稳定性的影响#

思路
  • 对 G(s)=(τ1 s+1)/[s^2(τ2 s+1)] 求开环幅频与相频，按 τ1 与 τ2 大小分三种情形讨论奈氏曲线起点象限与包围次数，判闭环稳定性。
频率特性的物理意义与求法 频域分析
本卷考法
  • 由传函求开环幅频与相频表达式
本卷实例
  • 关键一步：令 s 等于 jw 后分离幅值与相角

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法

  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
