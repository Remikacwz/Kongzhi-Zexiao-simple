一一、信号流图与梅森公式15 分#

思路
  • 把结构图的比较点与引出点转成信号流图节点与支路，用梅森增益公式求 C(s)/R(s)。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图画信号流图并用梅森公式求传函
本卷实例
  • 关键一步：把比较点与引出点转成节点和支路
  • 中间结果：回路为两条且无两两不接触项
  • 卡点：前向通路与回路的接触关系判断错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图画信号流图并用梅森公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由多回路结构图逐层化简求C(s)/R(s)
本卷实例
  • 关键一步：先合并内环再逐步向输入端化简
  • 中间结果：闭环分母为1加两条回路增益
  • 卡点：化简时把某条支路增益方向乘反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由多回路结构图逐层化简求C(s)/R(s)
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 用串联并联与反馈等效校验梅森结果
本卷实例
  • 关键一步：按比较点与引出点拆成可合并的小块
  • 中间结果：三条前向通路增益相加为分子
  • 卡点：负反馈分母误写成1减回路传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过用串联并联与反馈等效校验梅森结果
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

二二、组合输入下的稳态误差15 分#

思路
  • 对 G(s)=10/(s+2)，把 r(t)=2+sin2t 拆成直流与正弦分量，分别用终值定理与频率特性求稳态误差后叠加。
误差定义与误差传递函数 稳态误差
本卷考法
  • 求单位负反馈系统的误差传递函数
本卷实例
  • 关键一步：写出误差对输入的传递函数1加G(s)
  • 中间结果：闭环特征式为s加12
  • 卡点：未判稳就使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过求单位负反馈系统的误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求直流分量输入下的稳态误差
本卷实例
  • 关键一步：把阶跃分量代入终值定理
  • 中间结果：误差传递函数在s趋于零处的取值决定直流误差
  • 卡点：组合输入时漏掉某一分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求直流分量输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求正弦输入下的稳态误差幅值与相角
本卷实例
  • 关键一步：把误差传函换成频率特性后算模与相角
  • 中间结果：正弦分量的误差仍是同频正弦量
  • 卡点：忘记用误差传函而误用开环传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求正弦输入下的稳态误差幅值与相角
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

三三、纯虚根条件求特征方程参数15 分#

思路
  • 把 s=±j1 代入闭环特征方程，令实部与虚部分别为零，联立求K与Z。
劳斯判据 稳定性分析
本卷考法
  • 由纯虚根条件求特征方程参数K与Z
本卷实例
  • 关键一步：把s等于j1代入特征方程分离实虚部
  • 中间结果：特征式为s⁴加30s³加100s²加ks加kz
  • 卡点：只代一个根会漏掉共轭根的方程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由纯虚根条件求特征方程参数K与Z
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由临界纯虚根确定稳定边界参数
本卷实例
  • 关键一步：联立实部与虚部两方程求解
  • 中间结果：两方程分别给出k与z
  • 卡点：把纯虚根当作稳定点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由临界纯虚根确定稳定边界参数
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

参数稳定域的确定 稳定性分析
本卷考法
  • 用参数稳定域观点核对临界参数
本卷实例
  • 关键一步：用劳斯全零行对应辅助方程
  • 中间结果：辅助方程给出ω平方与kz的关系
  • 卡点：全零行处理时系数抄错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上

步骤

  • 检查端点是否为临界稳定
通用考法
  • 本卷考过用参数稳定域观点核对临界参数
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

四四、参数根轨迹与虚轴交点15 分#

思路
  • 把含K的特征方程整理成 1+K(s+4)/(s(s+1)²)=0，画参数根轨迹并求虚轴交点处的闭环零极点表达式。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以K为变量绘制参数根轨迹
本卷实例
  • 关键一步：把特征方程整理成1加K乘等效开环
  • 中间结果：等效开环为K(s+4)比s(s+1)²
  • 卡点：参数未完整提到分子会画错起点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以K为变量绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

本卷考法
  • 按法则绘制含一个开环零点的根轨迹
本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制含一个开环零点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

五五、奈奎斯特图与稳定裕度适用条件15 分#

思路

奈奎斯特判据 稳定性分析
本卷考法
  • 由奈奎斯特图判断含右半平面零点系统的稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数再数包围次数
  • 中间结果：开环无右半平面极点，看是否包围负1点
  • 卡点：未补画无穷大半径圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由奈奎斯特图判断含右半平面零点系统的稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过由采样周期判断系统稳定裕量的变化
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

  • 状态变量的个数等于系统阶数，选取不唯一
