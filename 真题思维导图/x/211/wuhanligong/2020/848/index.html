一一、信号流图与梅森公式求输出#

思路
  • 由方框图画出信号流图，分别求参考输入与扰动到输出的前向通路与余子式，用梅森公式叠加得总输出。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求多输入系统的总输出
本卷实例
  • 关键一步：分别对参考输入与扰动列前向通路
  • 中间结果：特征式由回路增益与两两不接触回路组成
  • 卡点：不接触回路漏算或重复计数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求多输入系统的总输出
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求参考输入与扰动到输出的传函
本卷实例
  • 关键一步：求一路传函时把另一路输入置零
  • 中间结果：总输出为两路传函分别乘输入后相加
  • 卡点：两个输入同时存在时未验证线性性就直接叠加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求参考输入与扰动到输出的传函
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

多回路系统的逐层化简 结构图与方框图
本卷考法
  • 把方框图逐层化简为信号流图
本卷实例
  • 关键一步：按支路信号流向确定各节点与增益
  • 中间结果：三条回路均两两接触故特征式只取回路之和
  • 卡点：化简内环时把外层信号当常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

二二、组合输入与正弦扰动下的稳态误差#

思路
  • 误差取 R 减 C，对阶跃加斜坡输入用终值定理求稳态误差；对正弦扰动改用频率特性求稳态误差的幅值相移后再叠加。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由终值定理求阶跃加斜坡输入的稳态误差
本卷实例
  • 关键一步：组合输入拆成阶跃与斜坡分别求误差
  • 中间结果：终值定理前先判闭环系统稳定
  • 卡点：组合输入时漏掉某一输入分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由终值定理求阶跃加斜坡输入的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动单独作用引起的稳态误差
本卷实例
  • 关键一步：求扰动误差传函时把参考输入置零
  • 中间结果：扰动误差与输入误差按线性叠加
  • 卡点：把扰动误差直接当作总误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求扰动单独作用引起的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

频率特性的物理意义与求法 频域分析
本卷考法
  • 用频率特性求正弦扰动的稳态误差
本卷实例
  • 关键一步：把正弦扰动频率代入误差传函求模与相角
  • 中间结果：稳态误差为同频正弦输出幅值相移形式
  • 卡点：求幅值时忘记把分母复数取模后再相除
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过用频率特性求正弦扰动的稳态误差
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

三三、由动态指标反求参数与测速反馈稳态误差#

思路
  • 把闭环传函化为二阶标准形式，由超调量与调节时间求阻尼比与自然频率，再反解结构参数，并由误差传函分析测速反馈对斜坡稳态误差的影响。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函化为二阶标准形式求 wn 与阻尼比
本卷实例
  • 关键一步：把开环传函写成 wn 平方比 s 乘 s 加两倍阻尼 wn 的形式
  • 中间结果：由给定超调量反求阻尼比
  • 卡点：化为标准形式时忘记把 s 平方项系数归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函化为二阶标准形式求 wn 与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法

本卷实例
  • 关键一步：由调节时间式解自然频率
  • 中间结果：再回代阻尼比关系式解结构参数
  • 卡点：只满足单项指标就下结论未做交叉验证
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤

  • 在参数平面上画出各不等式的可行域

  • 回代验证全部指标是否满足
通用考法

  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

四四、零度根轨迹与稳定增益范围#

思路
  • 由 1-G(s)=0 判定应画零度根轨迹，按法则分析起点终点与实轴段，令 s 等于 jw 求虚轴交点并划分稳定增益范围。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 由正反馈特征方程判断应画零度根轨迹
本卷实例
  • 关键一步：把特征方程整理成一减 G 等于零
  • 中间结果：相角条件取 360 度的整数倍
  • 卡点：零度根轨迹仍套 180 度相角条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过由正反馈特征方程判断应画零度根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则求根轨迹起点终点与实轴段
本卷实例
  • 关键一步：数开环极点与零点个数定分支数
  • 中间结果：实轴段按右侧实零极点总数为偶数判定
  • 卡点：实轴段判据零极点个数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则求根轨迹起点终点与实轴段
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 令 s 等于 jw 求虚轴交点与临界增益
本卷实例
