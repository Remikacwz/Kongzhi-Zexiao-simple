1一、由方程组画结构图求传递函数#

思路
  • 把五个方程各自对应的环节按信号流向串接成结构图，再逐层合并小回路；也可画出信号流图后用梅森公式求输出对输入的传递函数。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由五个代数微分方程逐层化简求 C(s)/R(s)
本卷实例
  • 关键一步：把每个方程对应的环节画成方框并按信号流向串接
  • 中间结果：各环节含积分、比例与微分支路，需先拉氏变换
  • 卡点：微分支路与反馈支路的正负号需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由五个代数微分方程逐层化简求 C(s)/R(s)
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 列独立回路与前向通路，用梅森公式校验化简结果
本卷实例
  • 关键一步：先数清独立回路，写出特征式后再加前向通路
  • 中间结果：各回路互不接触时特征式取 1 减回路增益之和
  • 卡点：回路增益的正负号与微分支路容易抄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过列独立回路与前向通路，用梅森公式校验化简结果
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、主导极点降阶与阶跃响应对比#

思路
  • 先由零极点分布判断主导极点，按增益不变原则把三阶系统降为等效一阶模型，再分别求简化前后系统的单位阶跃响应并比较调节时间。
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 用主导极点把三阶系统降为等效一阶模型
本卷实例
  • 关键一步：比较各极点到虚轴的距离，保留离虚轴最近的极点
  • 中间结果：降阶前后增益要保持不变，否则响应幅值会偏
  • 卡点：只留主导极点而漏掉增益修正是本题常见错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过用主导极点把三阶系统降为等效一阶模型
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
零极点分布与响应模态 传递函数
本卷考法
  • 由零极点分布说明主导极点为何能近似原系统
本卷实例
  • 关键一步：比较各极点对应响应分量的衰减快慢
  • 中间结果：远离虚轴的极点分量衰减很快，可近似忽略
  • 卡点：零点靠近主导极点会削弱其权重，近似需谨慎
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由零极点分布说明主导极点为何能近似原系统
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零
公式
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 求简化前后单位阶跃响应并按误差带比较调节时间
本卷实例
  • 关键一步：由一阶响应表达式按给定误差带反解调节时间
  • 中间结果：简化前后响应均单调上升，调节时间差别很小
  • 卡点：误差带取 5% 还是 2% 会改变结果，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过求简化前后单位阶跃响应并按误差带比较调节时间
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

3三、输入与扰动共同作用下的稳态误差#

思路
  • 由结构图写出开环传递函数并判断型别，分别对参考输入与扰动作用求误差传递函数，按典型输入求稳态误差后叠加，再从物理与环节两个角度比较两种误差。
系统型别与静态误差系数 稳态误差
本卷考法
  • 判断系统型别并写出两种作用下的静态误差系数
本卷实例
  • 关键一步：数开环传函中积分环节个数以确定系统型别
  • 中间结果：对参考输入为 II 型，对扰动作用为 I 型
  • 卡点：同一系统对两种作用的型别不同，易混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断系统型别并写出两种作用下的静态误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 第(1)(2)问求阶跃与速度输入下的稳态误差
本卷实例
  • 关键一步：第(1)(2)问分别代入静态位置与速度误差系数
  • 中间结果：阶跃输入误差为零，速度输入误差由速度误差系数决定
  • 卡点：使用终值定理前必须先确认闭环系统稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过第(1)(2)问求阶跃与速度输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 第(2)问单独求单位速度扰动作用下的稳态误差
本卷实例
  • 关键一步：令参考输入为零，写出扰动到误差的传递函数
  • 中间结果：扰动误差与扰动作用点前后的增益有关
  • 卡点：扰动误差容易只算一项，漏掉输入分量的叠加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过第(2)问单独求单位速度扰动作用下的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 第(3)问从环节角度对比输入误差与扰动误差
本卷实例
  • 关键一步：分别写出误差对参考输入与对扰动的传递函数
  • 中间结果：两者分母相同、分子不同，反映作用点差异
  • 卡点：结构图未读，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过第(3)问从环节角度对比输入误差与扰动误差
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

4四、常规根轨迹与阻尼比最小点#

思路
  • 按绘制法则画常规根轨迹，求分离点与虚轴交点；再作过原点的等阻尼线与根轨迹相切，由切点求阻尼比最小处的闭环极点和开环增益。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则画根轨迹的起点终点、实轴段与渐近线
本卷实例
  • 关键一步：先定开环极点与零点，再画实轴段和渐近线
  • 中间结果：本题两支根轨迹一支终止于零点、一支趋于无穷
  • 卡点：渐近线与实轴的交点和夹角容易算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则画根轨迹的起点终点、实轴段与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点并取舍
本卷实例
  • 关键一步：用分离点方程求出候选根再代回检验
  • 中间结果：两个候选根中只有一个落在根轨迹上
  • 卡点：求出两根后不筛选，会保留不在根轨迹上的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点并取舍
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴的交点及对应增益
本卷实例
  • 关键一步：把 s=jω 代入闭环特征方程并分离实部虚部
  • 中间结果：交点处实部与虚部同时为零，解出 ω 与增益
  • 卡点：可能解出增益为负的伪解，需要舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴的交点及对应增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
