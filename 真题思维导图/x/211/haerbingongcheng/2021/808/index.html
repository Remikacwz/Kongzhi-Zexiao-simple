1一、由结构图绘制信号流图并用梅森公式求传函（原卷图）15 分#

思路
  • 由结构图选定节点与支路增益改画信号流图，逐条列出回路并找出互不接触回路组合写特征式，再对输入到输出的前向通路取余子式代入梅森公式。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图改画信号流图，列全部回路与不接触回路并用梅森公式求闭环传函
本卷实例
  • 关键一步：先把结构图各环节等效为有向支路，再逐条找出全部独立回路
  • 中间结果：特征式等于一减回路增益之和再加互不接触回路增益乘积
  • 卡点：结构图为原卷插图，回路条数、不接触判断与支路增益需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图改画信号流图，列全部回路与不接触回路并用梅森公式求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 按串联、并联与反馈等效把结构图正画为信号流图
本卷实例
  • 关键一步：按信号流向从输入到输出逐级标出各节点变量
  • 中间结果：同一节点进出支路增益相乘后叠加得到该节点方程
  • 卡点：反馈支路极性决定回路增益正负号，需对照原卷图核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过按串联、并联与反馈等效把结构图正画为信号流图
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、由阶跃响应曲线反求二阶传函（原卷图）10 分#

思路
  • 由响应曲线的初值与稳态值用初值、终值定理定出分子系数与常数项比值，再由超调量关系反解阻尼比与自然频率，从而确定其余未知参数。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应曲线与部分已知系数反求二阶传函未知参数
本卷实例
  • 关键一步：用初值定理读响应在零时刻的值，用终值定理读稳态值
  • 中间结果：由稳态值定出常数项比值，由初值定出最高次分子系数
  • 卡点：响应曲线关键点坐标取自原卷插图，需回原卷核对读数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应曲线与部分已知系数反求二阶传函未知参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时刻关系反解阻尼比与自然频率
本卷实例
  • 关键一步：把闭环传函化为标准二阶形式后套用超调量公式
  • 中间结果：由超调量得到阻尼比，再由峰值时间得到自然频率
  • 卡点：零时刻响应不为零，读超调量要先减去初始值再除以稳态值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与峰值时刻关系反解阻尼比与自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

思路
  • 先由结构图写闭环特征方程并令其等于期望特征多项式，对比系数求反馈增益；再令一路增益为零，由误差传递函数在阶跃下稳态为零的条件设计补偿环节。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由含两个反馈系数的结构图写出闭环特征方程
本卷实例

  • 中间结果：闭环特征方程的二次项系数含两级反馈增益的乘积
  • 卡点：结构图为原卷插图，反馈接入点与内外环关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 把期望闭环极点写成特征多项式并与实际特征方程对比求增益
本卷实例
  • 关键一步：由期望共轭极点直接写出期望特征多项式
  • 中间结果：令实际特征方程与期望特征方程同次幂系数对应相等
  • 卡点：期望极点为共轭复根，其模的平方等于常数项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 指标之间往往相互制约，需权衡取舍

  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域

  • 回代验证全部指标是否满足
通用考法

  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现

  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

减小稳态误差的措施 稳态误差
本卷考法
  • 设计补偿环节使单位阶跃输入下稳态误差为零
本卷实例
  • 关键一步：先判稳再对误差传函用终值定理并令其极限为零
  • 中间结果：误差传函在原点解析且分子常数项为零是零误差条件
  • 卡点：补偿环节须物理可实现，纯微分不能单独作为串联环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计补偿环节使单位阶跃输入下稳态误差为零
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

4四、四阶系统根轨迹绘制与分离点验证15 分#

思路
  • 按绘制法则求开环零极点、实轴段、渐近线与分离点，用相角条件验证分离点；再由劳斯表求根轨迹与虚轴交点及临界增益。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制含一对共轭复数极点的四阶系统根轨迹
本卷实例
  • 关键一步：先标出开环零极点并判断实轴上属于根轨迹的区间
  • 中间结果：四条渐近线交于实轴，夹角按奇数倍除以极点数差取
  • 卡点：复数极点出射角要先算其余零极点对该点的相角贡献
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制含一对共轭复数极点的四阶系统根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求分离点并用相角条件验证其确在根轨迹上
本卷实例
  • 关键一步：由分子分母多项式导数交叉相乘消去增益得分离点方程
  • 中间结果：分离点方程的解须代回判断是否落在实轴根轨迹段上
  • 卡点：求出的复根不是实轴分离点，验证要代回相角条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求分离点并用相角条件验证其确在根轨迹上
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由劳斯表求根轨迹与虚轴交点及临界增益
本卷实例
  • 关键一步：由特征方程列劳斯表并令含增益的首列元素为零
  • 中间结果：由出现全零行的那一行辅助多项式解交点频率
  • 卡点：临界增益须与该行辅助方程联立求解，不能只看首列为零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由劳斯表求根轨迹与虚轴交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

5五、奈奎斯特判据确定稳定条件15 分#

思路
  • 写出开环幅频、相频特性，求相角为负一百八十度时的幅值与穿越频率，再按开环右半平面极点数与包围圈数的关系列出增益与时间常数的稳定条件。
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据确定含一个积分环节系统闭环稳定的参数条件
本卷实例
  • 关键一步：先数开环右半平面极点数，再看幅相曲线对临界点的包围情况
  • 中间结果：相位穿越点的幅值小于一对应稳定，由此列出参数不等式
  • 卡点：开环含积分环节时须补画无穷大半径圆弧后再数包围圈数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据确定含一个积分环节系统闭环稳定的参数条件
  • 由开环幅相曲线判断闭环稳定性
