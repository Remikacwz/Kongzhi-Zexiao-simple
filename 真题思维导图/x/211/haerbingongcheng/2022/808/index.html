1一、双输入双输出系统补全结构图并求输出（原文图1）15 分#

思路
  • 由给出的方程组反解各支路关系补画结构图，再分别对两路输入用叠加或梅森公式求两个输出表达式。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 双输入双输出系统分别求两路输入到两路输出的传递关系
本卷实例
  • 关键一步：求某一输出时把另一路输入置零后按单输入系统处理
  • 中间结果：两个输出共用同一特征式，分子由各自前向通路与余子式决定
  • 卡点：结构图为原卷插图，缺失支路的接入点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过双输入双输出系统分别求两路输入到两路输出的传递关系
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求多输入系统的各条前向通路与余子式
本卷实例
  • 关键一步：先按补全后的信号流图列出全部独立回路求特征式
  • 中间结果：每条输入输出对对应一条前向通路及其余子式
  • 卡点：互不接触回路的乘积项容易漏乘或重复计数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求多输入系统的各条前向通路与余子式
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、由稳态误差与无超调确定开环放大倍数（原文图2）10 分#

思路
  • 由结构图写开环传函判断型别，用斜坡稳态误差上界得增益下限；再由阶跃无超调对应过阻尼在根轨迹上得增益上限，取交集。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡稳态误差不大于给定值反求开环增益范围
本卷实例
  • 关键一步：先由开环传函的积分环节个数判断系统型别
  • 中间结果：一型系统的速度误差系数等于开环增益除以时间常数乘积
  • 卡点：求稳态误差前必须先由劳斯判据确认系统稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位斜坡稳态误差不大于给定值反求开环增益范围
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由阶跃响应无超调确定过阻尼对应的增益范围
本卷实例
  • 关键一步：无超调等价于闭环极点为两个负实根，处于根轨迹分离点以内
  • 中间结果：分离点对应的增益就是过阻尼范围的临界值
  • 卡点：结构图为原卷插图，开环极点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由阶跃响应无超调确定过阻尼对应的增益范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

3三、扰动误差与输入误差及补偿环节影响（原文图3）10 分#

思路
  • 按结构图分别求扰动到误差、输入到误差的传函，代入扰动与输入信号用终值定理求误差；再比较引入微分环节前后误差表达式说明其影响。
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求给定扰动信号作用下系统的稳态误差
本卷实例
  • 关键一步：求扰动误差传函时令参考输入为零
  • 中间结果：由终值定理对误差传函乘扰动拉氏变换求极限
  • 卡点：结构图为原卷插图，扰动注入点与回路增益需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求给定扰动信号作用下系统的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

4四、参数h正负两种情况的根轨迹与参数范围（原文图4）15 分#

思路
  • 把特征方程整理成含参数 h 的根轨迹形式，h 大于零与小于零分别对应零度与常规根轨迹；再按稳态值与欠阻尼要求求 h、K 范围。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以 h 为可变参数分别绘制零度与常规根轨迹
本卷实例
  • 关键一步：把参数整理到分子后按 h 的正负选择相角条件
  • 中间结果：h 大于零用零度相角条件，h 小于零用一百八十度相角条件
  • 卡点：参数根轨迹的实轴段判据与常规根轨迹不同，需按零极点差判
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以 h 为可变参数分别绘制零度与常规根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 求两种根轨迹的渐近线、实轴段与分离点
本卷实例
  • 关键一步：分别标出开环零极点后逐条应用绘制法则
  • 中间结果：由分离点方程的解结合实轴段筛选有效分离点
  • 卡点：舍去的根仍要说明理由，不能只保留一个解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过求两种根轨迹的渐近线、实轴段与分离点
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由与虚轴交点确定稳定与欠阻尼的临界参数
本卷实例
  • 关键一步：把虚轴点代入后令特征方程实部虚部分别为零
  • 中间结果：解出的参数值对应根轨迹穿越虚轴的临界点
  • 卡点：稳态值为二的条件用于定开环增益，与稳定条件要分开用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由与虚轴交点确定稳定与欠阻尼的临界参数
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式

5五、由奈奎斯特图反求结构与参数（原文图5）15 分#

思路
  • 由奈奎斯特曲线低频段相位定积分环节数与惯性环节数，由与负实轴交点定穿越频率与截距；再由稳态误差与正弦稳态幅值条件解出增益与时间常数。
奈奎斯特判据 稳定性分析
本卷考法
  • 由奈奎斯特图反推开环结构并判断闭环稳定
本卷实例
  • 关键一步：由低频段起点相位判断积分环节个数
  • 中间结果：高频段相位变化量对应惯性环节个数
  • 卡点：曲线为原卷插图，穿越点位置与包围方向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由奈奎斯特图反推开环结构并判断闭环稳定
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由开环频率特性求与负实轴交点频率和实轴截距
本卷实例
  • 关键一步：令虚部为零解出穿越频率再代入实部求截距
  • 中间结果：截距等于各惯性环节时间常数之和乘开环增益
  • 卡点：相角累加时积分环节与各惯性环节的贡献不能漏项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由开环频率特性求与负实轴交点频率和实轴截距
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
