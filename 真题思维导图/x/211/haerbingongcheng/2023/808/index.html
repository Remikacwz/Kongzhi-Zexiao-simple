1一、结构图化简与信号流图回路增益（原卷图）#

思路
  • 用比较点与引出点的移动把结构图逐步化简得闭环传函；再把化简前后结构改画成信号流图，逐条写出回路增益与前向通路。
比较点与引出点的移动 结构图与方框图
本卷考法
  • 用比较点与引出点移动化简多回路结构图
本卷实例
  • 关键一步：按比较点后移、引出点前移的规则逐步消去交叉连接
  • 中间结果：每次移动后新支路增益等于被移环节传函或其倒数
  • 卡点：结构图为原卷插图，移动次序与支路增减需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过用比较点与引出点移动化简多回路结构图
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
梅森增益公式与信号流图 传递函数
本卷考法
  • 绘制信号流图并写出各回路增益与前向通路
本卷实例
  • 关键一步：按节点与支路增益改画信号流图后逐条列出回路
  • 中间结果：无互不接触回路时特征式为一减各回路增益之和
  • 卡点：回路增益的正负号由反馈极性决定，易与正反馈混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过绘制信号流图并写出各回路增益与前向通路
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、速度反馈与前馈补偿参数设计（原文图2）#

思路
  • 设速度反馈为微分形式写闭环特征方程，按超调量与峰值时间求阻尼比和自然频率定增益与反馈系数；再令扰动到输出的传函恒为零解出前馈补偿环节。
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间要求反求二阶系统增益与速度反馈系数
本卷实例
  • 关键一步：把闭环特征方程化为标准二阶形式再与指标对应
  • 中间结果：由超调量定阻尼比，由峰值时间定自然频率
  • 卡点：速度反馈系数与开环增益由两个指标联立确定，不能只用一个
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量与峰值时间要求反求二阶系统增益与速度反馈系数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求扰动作用下的传递函数并实现扰动不变性
本卷实例
  • 关键一步：求扰动传函时令参考输入为零，把前馈支路并入前向通路
  • 中间结果：令扰动传函的分子多项式恒为零即得补偿条件
  • 卡点：结构图为原卷插图，扰动注入点与前馈接入点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法

  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

减小稳态误差的措施 稳态误差
本卷考法
  • 设计前馈补偿器实现系统对扰动的完全不变性
本卷实例
  • 关键一步：把扰动主通路与前馈支路整理成可相消的形式
  • 中间结果：补偿环节由扰动传函分子的各项系数为零反求
  • 卡点：求出的前馈环节可能含高阶微分，需说明可实现性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计前馈补偿器实现系统对扰动的完全不变性
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

3三、开环对数幅频特性与动态误差（原卷图）#

思路
  • 把开环传函化为尾一标准型，按各转折频率逐段画渐近对数幅频特性；再把误差传函展开成幂级数求动态误差系数，代入给定输入及其各阶导数得动态误差。
开环对数频率特性的绘制 频域分析
本卷考法
  • 按尾一标准型逐段绘制开环对数渐近幅频特性
本卷实例
  • 关键一步：先由低频段斜率与高度定系统型别与开环增益
  • 中间结果：每过一个转折频率斜率按该环节阶次改变
  • 卡点：斜率逐段累加而非替换，低频段起始高度勿漏型别修正
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过按尾一标准型逐段绘制开环对数渐近幅频特性
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 由误差传递函数的长除法求动态误差系数
本卷实例
  • 关键一步：把误差传函在原点附近展开成变量 s 的幂级数
  • 中间结果：幂级数各次幂系数即动态误差系数
  • 卡点：动态误差用于误差随时间变化的场合，与静态误差不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由误差传递函数的长除法求动态误差系数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

4四、含右半平面极点系统的根轨迹与稳定范围#

思路
  • 标出开环零极点并判断实轴段，求渐近线、分离点与出射角；列劳斯表令首列同号求穿越虚轴的两组临界增益，从而得稳定范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制含一个右半平面极点的非最小相位系统根轨迹
本卷实例
  • 关键一步：先按实轴段判据找出属于根轨迹的实轴区间
  • 中间结果：渐近线夹角由极点数减零点数确定
  • 卡点：开环有右半平面极点时稳定性判据需按奈奎斯特重新理解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制含一个右半平面极点的非最小相位系统根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求分离点并用根轨迹条件舍去无效解
本卷实例
  • 关键一步：由分子分母导数交叉相乘得分离点方程
  • 中间结果：方程的解中只有落在根轨迹上的才是真正分离点
  • 卡点：解出复根要说明不在实轴上故舍去，不能直接丢弃
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求分离点并用根轨迹条件舍去无效解
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由劳斯表求与虚轴交点及两组临界增益
本卷实例
  • 关键一步：由特征方程列劳斯表并令含增益的首列元素为零
  • 中间结果：由出现全零行的辅助多项式解出交点频率
  • 卡点：临界增益有两个，稳定区可能在两临界值之间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由劳斯表求与虚轴交点及两组临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

5五、由开环幅频特性与相角裕度反求传函（原卷图）#

思路
  • 由折线幅频特性低频段与转折频率写出含待定环节数的开环传函通式，结合相角裕度大于四十五度判断各环节相位构成并定出环节数，再写闭环传函。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环对数幅频特性折线反求传递函数
本卷实例
  • 关键一步：由低频段斜率定积分环节个数与开环增益
  • 中间结果：按各转折频率处的斜率改变量配置相应环节
  • 卡点：转折频率取自原卷插图，需回原卷核对折线与坐标
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环对数幅频特性折线反求传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

11十一、李雅普诺夫意义下稳定与渐近稳定范围#

思路
  • 对第一个系统求特征值并检查零特征值对应的约当块阶数，判断是否李雅普诺夫意义下稳定；对第二个系统列特征多项式后用劳斯判据求渐近稳定时参数范围。
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 判断原点是否为李雅普诺夫意义下稳定
本卷实例
  • 关键一步：先求系统矩阵特征值再检查零实部根的约当块阶数
  • 中间结果：零特征值为最小多项式单根才满足李雅普诺夫稳定
  • 卡点：零特征值对应二阶约当块时解含时间增长项，故不稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数

  • 判断函数与导数的正负定性

12十二、状态反馈极点配置与状态观测器设计#

思路
  • 先由能控判别矩阵判断能否配置指定极点，对可控子系统设增益阵对比期望特征多项式求反馈增益；再用能观判别矩阵判断能否设计观测器，对可观子系统对比期望特征多项式求观测器增益。
状态反馈与极点配置 状态空间分析
本卷考法
  • 判断能否通过状态反馈配置极点并求反馈增益矩阵
本卷实例

  • 中间结果：对可控子系统展开闭环特征多项式与期望式对比系数
  • 卡点：系统不完全能控时不可控模态的极点无法移动，须先行分解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤

  • 比较系数解出反馈增益阵 K
