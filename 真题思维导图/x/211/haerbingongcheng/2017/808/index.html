1一、信号流图与多输入传递函数15 分#

思路
  • 按三回路结构图绘制信号流图，分别令两输入之一为零求各自到输出的传递函数，再用梅森公式取前向通路与余子式写出表达式。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由三回路结构图绘制信号流图并用梅森公式求多输入传函
本卷实例
  • 关键一步：先找全部回路并标出互不接触回路对
  • 中间结果：两输入通道共用同一特征式
  • 卡点：余子式只删与所选前向通路接触的回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由三回路结构图绘制信号流图并用梅森公式求多输入传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求每个输入到输出的传递函数并按叠加写总输出
本卷实例
  • 关键一步：求某通道时把另一输入置零
  • 中间结果：总输出为两通道响应之和
  • 卡点：两输入同时作用仍须满足线性叠加条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求每个输入到输出的传递函数并按叠加写总输出
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

2二、复合输入与扰动稳态误差10 分#

思路
  • 写出参考输入通道与扰动通道的误差传函，并判系统稳定；再分别对阶跃、斜坡与正弦分量求稳态响应并叠加。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求阶跃与斜坡组合输入下的稳态误差
本卷实例
  • 关键一步：按线性分别求各输入分量的稳态误差
  • 中间结果：型别决定哪些分量误差为零
  • 卡点：组合输入不可整体套单一误差系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求阶跃与斜坡组合输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 判断扰动通道误差是否为零并写扰动传函
本卷实例
  • 关键一步：把参考输入置零后求扰动到误差的传函
  • 中间结果：扰动误差传函分子是否含原点因子决定零误差
  • 卡点：扰动作用点不同会改变误差传函结构
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过判断扰动通道误差是否为零并写扰动传函
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 写出给定误差定义下的误差传递函数
本卷实例
  • 关键一步：按误差等于参考减输出列写传函
  • 中间结果：误差传函等于一减闭环传函
  • 卡点：非单位反馈时误差定义不同结果会变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写出给定误差定义下的误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

3三、结构不稳定系统的结构改造15 分#

思路
  • 由缺项特征方程说明调参无法稳定；再分别用串联一阶微分环节补全 s 项、用局部反馈破坏积分环节，说明两种结构改造的作用。
反馈校正与复合控制 系统校正
本卷考法
  • 用局部反馈校正破坏原系统结构以改善稳定性
本卷实例
  • 关键一步：用反馈包围积分环节改变开环传函极点分布
  • 中间结果：局部反馈后特征方程补上缺失的 s 项
  • 卡点：反馈极性决定改造后是否稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过用局部反馈校正破坏原系统结构以改善稳定性
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
公式
PID 控制器与参数整定 系统校正
本卷考法
  • 用比例微分环节改变系统阻尼与动态性能
本卷实例
  • 关键一步：串联一阶微分环节给特征方程补项
  • 中间结果：微分作用增大系统阻尼并提高响应速度
  • 卡点：微分作用过强会放大高频噪声
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过用比例微分环节改变系统阻尼与动态性能
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由特征方程缺项说明结构不稳定的判据
本卷实例
  • 关键一步：检查特征方程各项系数是否齐全
  • 中间结果：缺项时无论怎样调参都难以稳定
  • 卡点：缺项与系数符号错误要区分开
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由特征方程缺项说明结构不稳定的判据
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

4四、双参数根轨迹15 分#

思路
  • 先写含两参数的开环传函，固定其中一个参数把另一个提到根轨迹增益位置分别绘制；按零点位置与极点个数讨论实轴段、渐近线与分离点。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 分别以两个参数为变量讨论参数根轨迹的画法
本卷实例
  • 关键一步：固定一个参数把特征方程整理成等效开环形式
  • 中间结果：等效开环零点位置随固定参数改变
  • 卡点：两参数分别变化须分情况讨论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过分别以两个参数为变量讨论参数根轨迹的画法
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则确定参数根轨迹的实轴段、渐近线与分离点
本卷实例
  • 关键一步：先画开环零极点并判断实轴轨迹段
  • 中间结果：渐近线交点由极点与零点重心之差决定
  • 卡点：零点跨过极点时实轴段会改变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则确定参数根轨迹的实轴段、渐近线与分离点
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 讨论开环零点位置变化对根轨迹形状与稳定性的影响
本卷实例
  • 关键一步：比较零点在不同区间的轨迹分支走向
  • 中间结果：零点位置改变会移动分离点与渐近线
  • 卡点：只看渐近线移动方向不足以判稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过讨论开环零点位置变化对根轨迹形状与稳定性的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反

5五、相角裕度反求延迟时间15 分#

思路
  • 由结构图写含延迟的开环频率特性，先由幅值条件求截止频率，再把相角裕度表达式中的延迟项分离，反解延迟时间。
稳定裕度 频域分析
本卷考法
  • 由给定相角裕度与结构图反求延迟时间
本卷实例
  • 关键一步：先由幅频特性等于一求截止频率
  • 中间结果：相角裕度等于一百八十度加截止频率处相角
  • 卡点：延迟项相位要与频率和弧度换算一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由给定相角裕度与结构图反求延迟时间
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
