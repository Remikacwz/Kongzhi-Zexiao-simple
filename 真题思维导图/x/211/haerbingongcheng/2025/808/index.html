1一、双入双出系统信号流图与传函（图1）#

思路
  • 按结构图选定节点画出信号流图并标出各支路增益，再用梅森公式列出全部回路、找出两两不接触回路写出特征式；分别对两条输入到输出的前向通路取余子式，得到两个传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由双入双出结构图画信号流图并用梅森公式求传函
本卷实例
  • 关键一步：先找齐全部独立回路，再挑出彼此不接触的回路组合
  • 中间结果：特征式等于一减各回路增益之和再加不接触回路乘积项
  • 卡点：信号流图为原卷插图，节点编号与支路增益需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由双入双出结构图画信号流图并用梅森公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、结构图劳斯判据与相对稳定度（图2）#

思路

串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图求闭环传递函数并写出特征方程
本卷实例
  • 关键一步：先按串联、并联与反馈等效把结构图化到单个闭环
  • 中间结果：闭环特征方程由开环传函的分母多项式加分子多项式得到
  • 卡点：结构图为原卷插图，各环节时间常数与反馈极性需核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节

常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求使系统稳定的开环增益范围
本卷实例
  • 关键一步：把特征方程按降幂排列后逐行列写劳斯表并令首列同号
  • 中间结果：首列含 k 的元素给出关于开环增益的一次不等式
  • 卡点：劳斯表中作分母的参量要单独讨论其正负，不能默认大于零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求使系统稳定的开环增益范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

参数稳定域的确定 稳定性分析
本卷考法
  • 把 s=z-1 代入特征方程求极点全在 s=-1 左侧的 k 范围
本卷实例
  • 关键一步：令 s=z-1 平移虚轴，对关于 z 的特征方程重新列劳斯表
  • 中间结果：平移后常数项与首列元素给出两条关于 k 的不等式
  • 卡点：相对稳定度边界是 s=-1 垂线，平移后判据针对 z 平面虚轴
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过把 s=z-1 代入特征方程求极点全在 s=-1 左侧的 k 范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

减小稳态误差的措施 稳态误差
本卷考法
  • 用前馈补偿实现扰动不变性并说明其不影响稳定性
本卷实例
  • 关键一步：把前馈支路的贡献整理成能与扰动主通路相消的形式
  • 中间结果：不变性条件由扰动传函分子各项系数为零给出
  • 卡点：补偿器若含高阶微分项要判断物理可实现性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过用前馈补偿实现扰动不变性并说明其不影响稳定性
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

  • 比较不同型别系统的跟踪能力

  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量

4四、单位负反馈系统根轨迹绘制#

思路
  • 先由开环极点与零点确定分支数、实轴根轨迹段，再算渐近线交点与夹角；由重根条件求分离点，由复数极点相角条件求出射角，最后令 s=jω 求虚轴交点与临界增益。
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 由开环传函判断 180° 根轨迹并写出幅值相角条件
本卷实例
  • 关键一步：先由开环零极点个数差定分支与渐近线，再按 180° 相角条件画分支
  • 中间结果：幅值条件用于定某点对应的开环增益，相角条件用于判断点是否在轨迹上
  • 卡点：分母是二阶环节的平方，四个开环极点要按两对重合极点计入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过由开环传函判断 180° 根轨迹并写出幅值相角条件
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则画四阶系统根轨迹草图
本卷实例
  • 关键一步：先按实轴段判据定出实轴上的根轨迹区间，再补渐近线
  • 中间结果：渐近线条数等于极点数减零点数，夹角按奇数等分公式给出
  • 卡点：实轴段判据要以该段右侧开环零极点总数为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则画四阶系统根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
