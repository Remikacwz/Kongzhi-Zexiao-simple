1一、结构图化简与信号流图求传函（原卷图）#

思路
  • 先按等效变换与比较点引出点移动化简结构图求闭环传函，再把结构改画为信号流图用梅森公式求误差传函。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图画信号流图并用梅森公式求回路增益与误差传函
本卷实例
  • 关键一步：把结构图按节点与支路改画成信号流图，逐条列出前向通路与回路
  • 中间结果：无互不接触回路时特征式为一减各回路增益之和
  • 中间结果：误差传函为前向通路乘余子式再除以特征式
  • 卡点：支路增益与反馈极性取自原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图画信号流图并用梅森公式求回路增益与误差传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 用结构图化简方法逐步求出闭环传递函数
本卷实例
  • 关键一步：先化简最内环再逐层向外，把多回路化成单回路
  • 中间结果：内环化简为前向通道除以一加减内环回路增益
  • 卡点：比较点与引出点可移动方向不同，接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过用结构图化简方法逐步求出闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2二、误差传递函数与无差度补偿设计#

思路
  • 由结构图写闭环与误差传递函数，按无差度要求令低阶误差项系数为零反求补偿参数。
误差定义与误差传递函数 稳态误差
本卷考法
  • 由闭环传函写误差传函并按无差度要求确定补偿参数
本卷实例
  • 关键一步：先写闭环传函，再用一减闭环传函得误差传函
  • 中间结果：误差传函分子中低阶s项系数为零即提高无差度
  • 卡点：逐年题面把无差度阶数印乱，需回原卷核对目标型别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由闭环传函写误差传函并按无差度要求确定补偿参数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 判断补偿后系统型别并说明能无差跟踪的输入信号种类
本卷实例
  • 关键一步：数误差传函在原点处的极点重数确定系统型别
  • 中间结果：v型系统对阶数低于v的典型输入稳态误差为零
  • 卡点：典型输入只有阶跃、速度、加速度三类，不能任意外推
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断补偿后系统型别并说明能无差跟踪的输入信号种类
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式

3三、PD控制与测速反馈改善二阶系统（原卷图）#

思路
  • 分别画出比例微分控制与测速反馈两种结构图，推导等效阻尼比并从稳态与噪声角度对比优缺点。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由两种校正结构图推导等效阻尼比表达式
本卷实例
  • 关键一步：把闭环特征方程化为标准二阶形式再与阻尼比对应
  • 中间结果：两种校正都只增大阻尼项而不改变无阻尼自然频率
  • 卡点：两种校正的接入点不同，结构图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由两种校正结构图推导等效阻尼比表达式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 比较比例微分控制引入的闭环零点与测速反馈的优缺点
本卷实例
  • 关键一步：从开环增益、稳态误差与高频噪声三方面逐项对比
  • 中间结果：比例微分控制引入实零点使响应加快但超调略增
  • 卡点：微分输入为误差信号、能量低，与测速反馈作用不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过比较比例微分控制引入的闭环零点与测速反馈的优缺点
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

4四、零度根轨迹绘制与稳定范围（原卷图）#

思路
  • 开环含负号时化为等效正反馈画零度根轨迹，再由分离点、虚轴交点与稳态值确定参数范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画出根轨迹并写出主要步骤
本卷实例
  • 关键一步：先定实轴上的轨迹段与渐近线，再求分离点与虚轴交点
  • 中间结果：分离点由对增益求导为零的方程解出
  • 卡点：轨迹起点终点与渐近线取自原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画出根轨迹并写出主要步骤
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 把含负号的等效开环化为零度根轨迹并证明部分轨迹是圆弧
本卷实例
  • 关键一步：把开环传函整理成等效正反馈形式后按零度相角条件处理
  • 中间结果：由特征方程实部虚部分离消去增益可得轨迹方程
  • 卡点：零度根轨迹用二kπ相角条件，不能沿用一百八十度条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过把含负号的等效开环化为零度根轨迹并证明部分轨迹是圆弧
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹求单位阶跃稳态值并确定欠阻尼稳定时的参数范围
本卷实例
  • 关键一步：先用终值定理求稳态值，再由虚轴交点与分离点夹出参数范围
  • 中间结果：稳定范围由根轨迹落在左半平面与欠阻尼条件共同决定
  • 卡点：终值定理须先判稳，欠阻尼段取复根分支对应区间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹求单位阶跃稳态值并确定欠阻尼稳定时的参数范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

5五、奈奎斯特判据与谐振峰值（原卷图）#

思路
  • 先由开环右半平面极点用奈奎斯特判据分档定稳定范围，再由幅相条件反求参数与谐振角频率。
奈奎斯特判据 稳定性分析
本卷考法
  • 开环含一个右半平面极点时用奈奎斯特判据确定稳定参数范围
本卷实例
  • 关键一步：先数开环右半平面极点数，再由幅相曲线求包围原点圈数
  • 中间结果：由Z等于P减二N判断稳定、不稳定与临界三种情形
  • 卡点：含积分环节要补画无穷大半径圆弧
  • 卡点：奈奎斯特曲线需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过开环含一个右半平面极点时用奈奎斯特判据确定稳定参数范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由闭环幅值与相角的两个条件反求开环参数
本卷实例
  • 关键一步：把闭环频率特性在指定频率处的幅值与相角写成两个方程
  • 中间结果：振幅相等给幅值方程，落后九十度给相角方程
  • 卡点：求幅值要先对分母复数取模，漏掉共轭会算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由闭环幅值与相角的两个条件反求开环参数
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
闭环频率特性与性能指标 频域分析
本卷考法
  • 求输出振幅最大时的角频率与谐振峰值

10十、由状态转移矩阵反求A与输出响应#

思路
  • 先由状态转移矩阵与其逆的关系还原矩阵，再对时间求导取零时刻得A，最后用卷积积分求输出。
状态转移矩阵 状态空间分析
本卷考法
  • 由状态转移矩阵求系统矩阵A并计算给定输入下的输出响应
本卷实例
  • 关键一步：利用转置与逆的关系还原状态转移矩阵再对时间求导取零
  • 中间结果：零初值时状态为零状态卷积积分，输出由输出行乘状态得到
  • 卡点：先还原矩阵再求导，直接在逆矩阵上求导会错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法

  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错

11十一、状态反馈与状态观测器设计#

思路
  • 由对象传函写能控标准型，先按闭环期望特征式定状态反馈阵，再按观测器期望极点定观测器增益阵。
状态反馈与极点配置 状态空间分析
本卷考法
  • 按期望闭环极点设计状态反馈增益阵
本卷实例
  • 关键一步：先写能控标准型，再令闭环特征式与期望特征式逐项相等
  • 中间结果：状态反馈不改变零点，闭环传函出现零极点对消
  • 卡点：设计前须验证能控性，并注意期望式阶数与对象一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式

  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过按期望闭环极点设计状态反馈增益阵
