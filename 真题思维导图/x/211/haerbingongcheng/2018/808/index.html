1一、结构图求闭环与误差传函#

思路
  • 由结构图改画信号流图，列全部回路与互不接触回路写特征式，用梅森公式分别求闭环传函 C(s)/R(s) 与误差传函 E(s)/R(s)。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图列全部回路并用梅森公式求闭环传函
本卷实例
  • 关键一步：先找出全部回路并标出互不接触回路对
  • 中间结果：闭环传函与误差传函共用同一特征式
  • 卡点：求误差传函时前向通路与余子式需重列
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图列全部回路并用梅森公式求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 按输出端误差定义写出误差传递函数
本卷实例
  • 关键一步：误差取参考输入 R 与输出 C 之差
  • 中间结果：误差通道含负号增益，由两条前向通路叠加
  • 卡点：输入端与输出端定义误差结果相差一个环节
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过按输出端误差定义写出误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

2二、由阶跃响应与静态误差反求参数#

思路
  • 设含积分环节的开环通用形式，由终值定理求闭环稳态值定增益，再由初值定理与阶跃响应初始斜率联立求型别与时间常数。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应曲线反求开环传函与类型参数
本卷实例
  • 关键一步：先设含积分环节的开环通用形式再比对响应
  • 中间结果：闭环稳态值与初始斜率各自给出一个约束
  • 卡点：型别不同会使初始斜率约束形式不同
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应曲线反求开环传函与类型参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由静态位置误差为零判断开环积分环节个数
本卷实例
  • 关键一步：位置误差为零说明开环至少含一个积分环节
  • 中间结果：系统型别与开环积分环节数保持一致
  • 卡点：型别判读需与开环积分环节数逐一核对
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由静态位置误差为零判断开环积分环节个数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为二阶标准形式读取特征参数
本卷实例
  • 关键一步：化标准形式前先把 s 平方项系数归一
  • 中间结果：阻尼比与自然频率由分母系数直接读出
  • 卡点：开环增益并不等于闭环传函的系数
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为二阶标准形式读取特征参数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

3三、扰动稳态误差与误差为零补偿#

思路
  • 先用梅森公式写扰动误差传函并判断系统稳定，再由终值定理求斜坡扰动引起的稳态误差；最后按输出端误差为零的条件反求补偿系数。
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求斜坡扰动作用下的稳态误差
本卷实例
  • 关键一步：求扰动误差时必须把参考输入置零
  • 中间结果：扰动误差传函的分母即系统特征式
  • 卡点：未判稳直接套终值定理会使结论失效
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求斜坡扰动作用下的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 设计补偿器使斜坡输入下稳态误差为零
本卷实例
  • 关键一步：令误差传函分子在 s 趋于零时为零
  • 中间结果：补偿系数由误差传函分子的常数项平衡确定
  • 卡点：补偿后仍要重新检查闭环稳定性
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计补偿器使斜坡输入下稳态误差为零
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

4四、参数根轨迹与有阻尼振荡范围#

思路
  • 由结构图写开环传函并按参数根轨迹法则画 k1 的轨迹，用分离点方程定分离与会合点，再由阻尼比约束给出有阻尼振荡的参数范围，最后按抛物线输入求稳态误差。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以 k1 为参变量绘制参数根轨迹
本卷实例
  • 关键一步：先把含参项提到分子成标准根轨迹形式
  • 中间结果：开环含两个积分环节与一个开环零点
  • 卡点：参数未完整提到分子会使轨迹形状判错
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以 k1 为参变量绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由分离点与阻尼条件确定有阻尼振荡范围
本卷实例
  • 关键一步：分离点处二阶特征根相等对应临界情况
  • 中间结果：实轴上的轨迹段位于两相邻开环极点之间
  • 卡点：分离点方程的解需筛掉不在轨迹上的根
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由分离点与阻尼条件确定有阻尼振荡范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由静态加速度误差系数求抛物线输入稳态误差
本卷实例
  • 关键一步：先由 k1 定开环增益再求加速度误差系数
  • 中间结果：误差系数由开环传递函数的低频增益给出
  • 卡点：误用速度误差公式会得到错误量纲
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由静态加速度误差系数求抛物线输入稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

5五、奈氏判据与特征根区域约束#

思路
  • 由开环频率特性求相位穿越频率，按奈氏判据由幅值条件定临界增益；再把虚轴平移化为新开环，用同一判据定闭环极点位于指定直线左侧的增益范围。
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅相曲线与奈氏判据定稳定增益范围
本卷实例
  • 关键一步：先数开环右半平面极点数
  • 中间结果：相位穿越频率处幅值为一对应临界增益
  • 卡点：开环无积分环节故无需补画无穷大圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环幅相曲线与奈氏判据定稳定增益范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
参数稳定域的确定 稳定性分析
本卷考法

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过构造能控与能观判别阵并用秩判断性质
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
