1一、由方程组绘结构图求传函#

思路
  • 把三个方程逐步化为以中间变量表示的方框，按信号流向绘出结构图，再用梅森公式或结构图化简求闭环传函。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 按串联并联与反馈关系化简结构图求闭环传函
本卷实例
  • 关键一步：先把方程整理成各变量之间的因果关系再画方框
  • 中间结果：回路增益由反馈通道与前向通道之积给出
  • 卡点：负反馈分母符号写成 1 减会改变结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过按串联并联与反馈关系化简结构图求闭环传函
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 把多回路结构图逐层化简为单一传递函数
本卷实例
  • 关键一步：从最内环开始逐层等效化简
  • 中间结果：每化简一层就把比较点与引出点并入等效环节
  • 卡点：化简内环时把外环信号当成常数会出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过把多回路结构图逐层化简为单一传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图转信号流图并用梅森公式核对结果
本卷实例
  • 关键一步：分别找出全部前向通路与独立回路
  • 中间结果：无双回路互不接触时特征式只含一次项
  • 卡点：余子式漏掉与通路接触的回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图转信号流图并用梅森公式核对结果
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、用劳斯表辅助方程解高次方程#

思路
  • 对六次多项式列劳斯表，出现全零行时用上一行构造辅助方程，求辅助方程根后再用长除法降阶，得到其余根。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯表全零行与辅助方程求解高次特征方程
本卷实例
  • 关键一步：全零行出现说明存在关于原点对称的根
  • 中间结果：辅助方程对 s 求导后回填劳斯表下一行
  • 卡点：系数缺项时未补零会使劳斯表错位
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯表全零行与辅助方程求解高次特征方程
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由辅助方程与长除法求全部特征根
本卷实例
  • 关键一步：辅助方程给出成对的对称根，长除法得剩余因子
  • 中间结果：降阶后的二次方程可直接求根
  • 卡点：长除法常数项抄错会使余数不为零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由辅助方程与长除法求全部特征根
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

3三、根轨迹与主导极点及稳态误差#

思路
  • 按根轨迹法则画三极点系统轨迹并求与虚轴交点判稳，由阻尼比线用相角条件求闭环极点再用幅值条件定增益，用根之和求第三个极点判断主导性，最后求斜坡稳态误差。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 画三极点系统的 180 度根轨迹并判稳定范围
本卷实例
  • 关键一步：先定实轴段与渐近线再画曲线走向
  • 中间结果：与虚轴交点由劳斯判据或幅值条件求得
  • 卡点：分离点与渐近线交点不可混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过画三极点系统的 180 度根轨迹并判稳定范围
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 用根之和求第三个极点并判断主导极点
本卷实例
  • 关键一步：用根之和由已知共轭极点反求实极点
  • 中间结果：实极点距虚轴远于共轭极点五倍才可忽略
  • 卡点：只看距离不看留数会误判主导性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过用根之和求第三个极点并判断主导极点
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由阻尼比要求在根轨迹上确定闭环极点
本卷实例
  • 关键一步：阻尼角线与根轨迹的交点即满足阻尼比
  • 中间结果：相角条件定交点位置、幅值条件定增益
  • 卡点：试根范围未取在实轴段会得到假解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由阻尼比要求在根轨迹上确定闭环极点
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡输入下闭环系统的稳态误差
本卷实例
  • 关键一步：先由闭环误差传函再用终值定理
  • 中间结果：误差系数由开环传递函数低频增益确定
  • 卡点：未判稳就套终值定理会使结论失效
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求斜坡输入下闭环系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

4四、测速反馈与比例微分控制对比#

思路
  • 分别写出测速反馈与比例微分两种结构下的等效开环与闭环特征方程，令阻尼比与自然频率相同得参数关系，再用静态误差系数比较单位斜坡稳态误差并分析原因。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由两种校正结构的特征方程比对阻尼比与自然频率
本卷实例
  • 关键一步：先分别写两种结构的等效开环传函
  • 中间结果：阻尼比与自然频率相同给出参数相等关系
  • 卡点：测速反馈会改变自然频率而比例微分不会
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由两种校正结构的特征方程比对阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

PID 控制器与参数整定 系统校正
本卷考法
  • 分析比例微分与测速反馈对动态性能的不同作用
本卷实例
  • 关键一步：微分作用等效于增加阻尼但会放大高频噪声
  • 中间结果：比例微分不改变自然频率、测速反馈会降低它
  • 卡点：微分增益过大反而放大噪声与振荡
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分

  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤

  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du

  • 由物理系统列写状态空间表达式

10十、能控能观与能控性指数及镇定#

思路
  • 构造能控与能观判别阵用秩判断性质，由能控阵各列与 B 的线性相关性求能控性指数，再看不能控模态特征值是否具有负实部判断能否镇定。
能控性与能观性 状态空间分析
本卷考法
  • 构造能控能观判别阵并计算能控性指数
本卷实例
  • 关键一步：能控阵按列拼 B 与各次 A 乘 B
  • 中间结果：能控性指数为能控阵中线性无关的列数
  • 卡点：能观阵按行拼 C 与 C 乘 A 不可记反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过构造能控能观判别阵并计算能控性指数
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
状态反馈与极点配置 状态空间分析
本卷考法
  • 由不能控部分的特征值判断系统能否镇定
本卷实例
  • 关键一步：检查不能控模态特征值是否都具有负实部
  • 中间结果：不能控且含正实部特征值则系统无法镇定
  • 卡点：能控不等于可镇定，须先分能控子空间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过由不能控部分的特征值判断系统能否镇定
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反

思路

  • 中间结果：观测器增益由 A 减 G 乘 C 的特征多项式确定

  • 观测器误差动态由 A-LC 的特征值决定
