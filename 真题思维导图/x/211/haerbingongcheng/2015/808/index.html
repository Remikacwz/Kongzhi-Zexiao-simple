1一、结构图绘信号流图与稳定条件15 分#

思路
  • 由结构图改画信号流图，列全部回路与不接触回路写特征式，用梅森公式求闭环传函；再由特征方程系数约束求 T1、T2 的稳定范围。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图绘制信号流图并用梅森增益公式求闭环传递函数
本卷实例
  • 关键一步：先按信号流向把各环节等效为有向支路
  • 中间结果：特征式等于一减回路增益之和
  • 卡点：结构图为原卷插图，回路与支路增益需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图绘制信号流图并用梅森增益公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 按串联、并联与反馈等效把多回路结构图化简为信号流图
本卷实例
  • 关键一步：按信号流向从输入到输出逐级标出节点变量
  • 中间结果：同一节点进出支路增益相乘后叠加
  • 卡点：反馈支路极性决定回路增益正负号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过按串联、并联与反馈等效把多回路结构图化简为信号流图
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由闭环特征方程各项系数约束求参数 T1 与 T2 的稳定范围
本卷实例
  • 关键一步：先由梅森公式结果写出闭环特征多项式
  • 中间结果：特征式常数项为负，需使各项系数同号
  • 卡点：二阶系统还须校验中间项不为零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由闭环特征方程各项系数约束求参数 T1 与 T2 的稳定范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

2二、劳斯判据与斜坡输入最小稳态误差10 分#

思路
  • 先列劳斯表求使闭环稳定的开环增益上界，再由静态速度误差系数与斜坡输入误差关系写出误差表达式，在稳定边界取最小值。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断三阶系统稳定并求开环增益范围
本卷实例
  • 关键一步：按闭环特征方程列三行劳斯表
  • 中间结果：首列元素均大于零对应增益上界
  • 卡点：求得增益上界后须回到单位负反馈条件复核
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断三阶系统稳定并求开环增益范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡输入下的稳态误差并说明其随开环增益的变化
本卷实例
  • 关键一步：先判稳再对误差传函用终值定理
  • 中间结果：误差与静态速度误差系数成反比
  • 卡点：斜坡幅值倍率在误差表达式中不可漏掉
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求斜坡输入下的稳态误差并说明其随开环增益的变化
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环传函数积分环节个数并求静态速度误差系数
本卷实例
  • 关键一步：化为标准形式后数原点处极点个数定系统型别
  • 中间结果：静态速度误差系数等于型别对应的极限
  • 卡点：型别与开环增益的乘积关系容易混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由开环传函数积分环节个数并求静态速度误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式

3三、特征根区域约束与参数范围10 分#

思路
  • 化闭环传函为标准二阶形式读取阻尼比约束；再把特征根位于 s=-1 左侧的条件用坐标平移化为新特征方程系数约束，联立求 K、T 范围。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为二阶标准形式并由阻尼比约束确定参数关系
本卷实例
  • 关键一步：先由闭环特征方程提取自然频率与阻尼比关系
  • 中间结果：阻尼比只与 K 与 T 的乘积有关
  • 卡点：阻尼比下界对应等阻尼线与负实轴夹角
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为二阶标准形式并由阻尼比约束确定参数关系
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式

  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组

  • 检查端点是否为临界稳定
通用考法

  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由特征根区域与阻尼比双重要求联立求参数取值范围
本卷实例
  • 关键一步：把两个约束分别写成 K 与 T 的不等式
  • 中间结果：取交集时注意可行域的开闭端点
  • 卡点：在 K-T 坐标系内需标出可行区域边界
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由特征根区域与阻尼比双重要求联立求参数取值范围
  • 由超调量和调节时间要求设计开环增益与阻尼

  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

4四、参数根轨迹与附加闭环零点超调15 分#

思路
  • 由结构图写开环传函并按根轨迹法则绘参数 k 的轨迹，用分离点与虚轴交点定形状；再求 k=10 闭环极点并解释附加闭环零点引起的超调。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画出含一个开环零点的二阶系统根轨迹
本卷实例
  • 关键一步：先标出开环零极点并判断实轴上的轨迹段
  • 中间结果：分离点由开环极点与零点倒数和为零给出
  • 卡点：分离点求出后须在图上验证落在实轴轨迹段内
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画出含一个开环零点的二阶系统根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 用分离点方程求根轨迹分离与会合点并取舍
本卷实例
  • 关键一步：把特征方程化为增益的显式表达式后求导
  • 中间结果：导数为零的根中只保留满足相角条件者
  • 卡点：分离点可能无实数解，须回代验证
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过用分离点方程求根轨迹分离与会合点并取舍
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由给定增益下的闭环极点位置分析系统动态性能
本卷实例
  • 关键一步：把闭环特征方程因式分解求两个闭环极点
  • 中间结果：两个极点均为负实数时系统过阻尼
  • 卡点：极点分布不能直接决定超调，还须看闭环零点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由给定增益下的闭环极点位置分析系统动态性能
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响

10十、能控性、渐近稳定与可镇定10 分#

思路
  • 由能控判别阵的秩判断能控性；求状态矩阵特征值判断渐近稳定；再按不稳定模态能否被控制判断可镇定性。
能控性与能观性 状态空间分析
本卷考法
  • 构造能控判别阵并用秩判断系统完全能控性
本卷实例
  • 关键一步：按 B、AB、A 平方 B 依次乘出判别阵
  • 中间结果：比较判别阵秩与状态维数
  • 卡点：多输入时判别阵列数随之增加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过构造能控判别阵并用秩判断系统完全能控性
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 由状态矩阵特征值判断渐近稳定性并讨论可镇定
本卷实例

  • 中间结果：存在正实部特征值即非渐近稳定

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数

  • 据此得出稳定性结论

11十一、基于观测器的状态反馈设计#

思路
  • 先验能控能观，再由期望极点分别配置状态反馈矩阵 K 与观测器增益矩阵 L，最后按分离原理写闭环状态空间描述。
状态反馈与极点配置 状态空间分析
本卷考法
  • 用极点配置求状态反馈矩阵使闭环极点到达期望位置
本卷实例
  • 关键一步：写出含反馈增益的闭环特征多项式
  • 中间结果：与期望特征多项式比较系数求解
  • 卡点：配置前必须验证系统能控
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过用极点配置求状态反馈矩阵使闭环极点到达期望位置
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
公式

  • 设计全维状态观测器
