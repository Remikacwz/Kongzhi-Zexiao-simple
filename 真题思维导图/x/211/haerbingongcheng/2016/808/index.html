1一、两相互联系系统求输出15 分#

思路
  • 由结构图分别写出两输入两输出系统的信号流图，按梅森公式求四个通道的传递函数，再由线性叠加写出各输出的完整表达式。
梅森增益公式与信号流图 传递函数
本卷考法
  • 对两输入两输出系统分别求各输入到各输出的传递函数
本卷实例
  • 关键一步：按输入输出对找出全部前向通路
  • 中间结果：各通道共用同一特征式
  • 卡点：互不接触回路对余子式的影响需逐通道判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过对两输入两输出系统分别求各输入到各输出的传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求多输入作用下系统的输出并验证叠加原理的适用条件
本卷实例
  • 关键一步：把一个输入置零后单独求该通道输出
  • 中间结果：总输出为各输入通道输出之和
  • 卡点：叠加前须确认系统为线性系统
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求多输入作用下系统的输出并验证叠加原理的适用条件
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

2二、由阶跃响应曲线反求开环传函15 分#

思路
  • 由响应曲线读取稳态值、峰值时间与超调量，先定闭环增益再反解阻尼比与自然频率，最后用负反馈关系求开环传函。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应曲线的稳态值与峰值反求系统传递函数
本卷实例
  • 关键一步：先由稳态值确定闭环传函的直流增益
  • 中间结果：由超调量与峰值时间联立求阻尼比与自然频率
  • 卡点：开环传函由闭环传函除以一减闭环传函得到
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应曲线的稳态值与峰值反求系统传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间反解阻尼比和自然频率
本卷实例
  • 关键一步：套用二阶欠阻尼超调量公式
  • 中间结果：峰值时间与阻尼自然频率成反比
  • 卡点：读曲线时峰值与稳态值须先扣除起始偏置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与峰值时间反解阻尼比和自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为标准二阶形式读取特征参数
本卷实例
  • 关键一步：将闭环传函分母配成标准二阶三项式
  • 中间结果：自然频率等于常数项开平方
  • 卡点：分子增益不等于一，须单独提取
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为标准二阶形式读取特征参数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

3三、误差为零设计与正弦稳态误差15 分#

思路
  • 分别令参考输入与扰动单独作用求误差传函，令两者稳态误差之和为零解出补偿参数；再代入给定参数求正弦输入下的稳态误差。
误差定义与误差传递函数 稳态误差
本卷考法
  • 分别写出参考输入与扰动作用下的误差传递函数
本卷实例
  • 关键一步：先按结构图分清给定误差与被控量误差
  • 中间结果：扰动误差传函须把参考输入置零后求
  • 卡点：两种误差定义混用会差一个反馈通道
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过分别写出参考输入与扰动作用下的误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 由扰动误差与给定误差之和为零设计补偿参数
本卷实例
  • 关键一步：分别对两个误差传函用终值定理
  • 中间结果：稳态误差和为零给出补偿参数的方程
  • 卡点：扰动为斜坡延迟形式时需先做时移
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过由扰动误差与给定误差之和为零设计补偿参数
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求正弦输入下的稳态误差幅值与相位
本卷实例
  • 关键一步：用频率特性直接代正弦频率求误差相量
  • 中间结果：稳态误差为同频正弦量
  • 卡点：正弦输入下误差不趋于常数而是同频振荡
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求正弦输入下的稳态误差幅值与相位
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

4四、参量根轨迹与临界增益15 分#

思路
  • 把开环传函中变化的参数提到根轨迹增益位置，以参数为变量按广义根轨迹法则绘制；再由虚轴交点求临界值并讨论参数对稳定性的影响。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以开环零点位置参数为变量绘制参数根轨迹
本卷实例
  • 关键一步：把特征方程整理成以参数为增益的等效开环形式
  • 中间结果：等效开环极点为原系统的非参变量部分
  • 卡点：参数出现在分子还是分母决定轨迹方向
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以开环零点位置参数为变量绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点求参数临界值
本卷实例
  • 关键一步：令特征方程含纯虚根后分离实虚部
  • 中间结果：实虚部同时为零给出频率与参数
  • 卡点：虚轴交点处须判轨迹穿越方向
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹与虚轴交点求参数临界值
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 讨论开环零点位置参数变化对系统稳定性的影响
本卷实例
  • 关键一步：比较不同参数下根轨迹是否全部落在左半平面
  • 中间结果：零点位置变化会改变渐近线与分离点
  • 卡点：闭环稳定性须整体看轨迹而非只看分离点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过讨论开环零点位置参数变化对系统稳定性的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反

5五、奈奎斯特判据求临界增益10 分#

思路
  • 画三个相同惯性环节串联的幅相曲线，由奈奎斯特判据在曲线过负实轴处取临界条件求增益；再比较时间常数改变后曲线与临界点的关系。
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据求三个惯性环节串联的临界开环增益
本卷实例
  • 关键一步：求幅相曲线与负实轴交点及其幅值
  • 中间结果：临界增益使交点幅值等于一
  • 卡点：开环无右半平面极点时包围圈数须为零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
