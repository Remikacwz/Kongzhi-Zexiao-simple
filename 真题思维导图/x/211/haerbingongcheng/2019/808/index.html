1一、复杂信号流图与稳定条件#

思路
  • 由系统框图改画信号流图，找出全部回路并确认无互不接触回路写特征式，用梅森公式求闭环传函，再由特征方程各项系数同号求 T1、T2 的稳定范围。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图列全部回路并用梅森公式求闭环传函
本卷实例
  • 关键一步：逐条找遍全部独立回路并注意方向
  • 中间结果：特征式由一减去各回路增益之和构成
  • 卡点：回路重复计数会使特征式多出冗项
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图列全部回路并用梅森公式求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

参数稳定域的确定 稳定性分析
本卷考法
  • 由闭环特征方程系数同号求两参数的稳定范围
本卷实例

  • 中间结果：稳定条件化为关于 T1、T2 的两个不等式
  • 卡点：常数项为负时判据方向要相应变号
  • 卡点：需回原卷核对图

2二、由稳态误差为零反求参数15 分#

思路
  • 由结构图写闭环传函与误差传函，先判断闭环稳定，再用终值定理让斜坡输入下误差为零，反求参数 b。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由斜坡输入下稳态误差为零反求待定参数
本卷实例
  • 关键一步：先由误差传函写出含参数的稳态误差表达式
  • 中间结果：误差为零要求误差传函分子的一次项系数为零
  • 卡点：未判稳直接套终值定理结论不可靠
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由斜坡输入下稳态误差为零反求待定参数
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 按输出端误差定义写误差传函
本卷实例
  • 关键一步：误差取输入减输出，误差传函为一减闭环传函
  • 中间结果：误差传函分子保留参数 a 与 b 的信息
  • 卡点：输入端与输出端误差定义相差一个环节
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过按输出端误差定义写误差传函
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

系统型别与静态误差系数 稳态误差
本卷考法
  • 由闭环特征方程判断系统稳定的前提
本卷实例
  • 关键一步：二阶特征方程只需各项系数同号
  • 中间结果：时间常数大于零是使用终值定理的前提
  • 卡点：稳定前提不成立时求出的参数无意义
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由闭环特征方程判断系统稳定的前提
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

3三、特征根区域约束与参数范围15 分#

思路
  • 化闭环传函为二阶标准形式得到阻尼比约束，再把特征根位于 s=-1 左侧的条件用坐标平移化为新特征方程系数约束，联立求 K、T 范围。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函读出自然频率与阻尼比表达式
本卷实例
  • 关键一步：先化二阶标准形式再对照系数
  • 中间结果：阻尼比与自然频率由 K 与 T 组合给出
  • 卡点：未归一化 s 平方项会读出错误阻尼比
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函读出自然频率与阻尼比表达式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由阻尼比与区域双重要求联立求参数可行域
本卷实例

4四、根轨迹绘制与临界增益15 分#

思路
  • 按根轨迹法则画三极点系统的 180 度根轨迹，由重极点确定分离点、由渐近线确定走向，再用劳斯判据或幅值条件求与虚轴交点得临界增益。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画含重极点的三阶系统根轨迹
本卷实例
  • 关键一步：先数开环零极点并判断实轴上的轨迹段
  • 中间结果：三条渐近线交于三极点的平均位置
  • 卡点：实轴段判据的零极点个数容易算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画含重极点的三阶系统根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 由重极点直接判定根轨迹的分离与会合点
本卷实例
  • 关键一步：重极点本身即为根轨迹的分离点
  • 中间结果：分离点处两条轨迹相切后分开
  • 卡点：分离点方程的解需筛掉不在轨迹上的根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由重极点直接判定根轨迹的分离与会合点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由劳斯表出现全零行求与虚轴交点及临界增益
本卷实例
  • 关键一步：令劳斯表首列某行为零对应临界增益
  • 中间结果：辅助方程给出虚轴交点的频率
  • 卡点：只取一个交点会漏掉对称的另一组
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解

  • 得到 K 后没有回到原题核对参数定义

5五、相角裕度最大时的增益10 分#

思路
  • 写出开环频率特性的相角表达式，令相角裕度最大即相角取极大，用不等式取等条件定截止频率，再由幅值条件求增益。
稳定裕度 频域分析
本卷考法
  • 求使相角裕度最大时的截止频率与开环增益
本卷实例
  • 关键一步：把相角表达式整理成可用均值不等式取极大的形式
  • 中间结果：相角取极值对应其分母函数取极小的频率
  • 卡点：截止频率与相位穿越频率不可混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求使相角裕度最大时的截止频率与开环增益
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
