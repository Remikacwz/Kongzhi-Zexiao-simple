一1一1、劳斯判据求稳定K值8 分#

思路
  • 对给定三阶特征方程列劳斯表，由首列严格同号求K范围
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求三阶系统稳定时K的取值范围
本卷实例
  • 关键一步：特征多项式按降幂排列后交叉相减列劳斯表
  • 中间结果：首列各元同号时系统稳定
  • 卡点：首列出现零元要改用辅助方程处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求三阶系统稳定时K的取值范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过列劳斯表时缺项未补零
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

一2一2、奈氏判据判断稳定性与K范围8 分#

思路
  • 由最小相位系统奈氏图数包围圈数判稳，再按增益缩放反求稳定区间
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅相曲线用奈氏判据判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数P再看曲线包围情况
  • 中间结果：包围圈数与P的关系决定闭环稳定性
  • 卡点：幅相曲线形状未读图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤

  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环幅相曲线用奈氏判据判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过开环含积分环节时未补画无穷大半径圆弧
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

一3一3、开环传函的幅频与相频特性8 分#

思路
  • 把s换成jω后分别取模与取相角，写出幅频和相频表达式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由开环传函求幅频特性与相频特性表达式
本卷实例
  • 关键一步：把复变量替换为jω后分母有理化再分离模与角
  • 中间结果：幅频等于分子模比分母模
  • 卡点：积分环节贡献固定的负九十度相移
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤

  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由开环传函求幅频特性与相频特性表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过求幅值时忘记分母复数取模后再相除
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

一4一4、描述函数法判断自振与消振8 分#

思路
  • 按负倒描述函数轨迹与奈氏曲线的交点性质判断自振，再讨论增益影响
用描述函数法分析自振 非线性系统
本卷考法
  • 由两条轨迹判断是否存在稳定自振荡
本卷实例
  • 关键一步：按负倒描述函数上的振幅增大方向判断穿越性质
  • 中间结果：由不稳定区穿入稳定区的交点对应稳定自振
  • 卡点：两处轨迹交点需分别判定，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过由两条轨迹判断是否存在稳定自振荡
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 本卷考过未标注振幅增大方向就下结论
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率
公式
非线性系统的稳定性与改善 非线性系统
本卷考法
  • 说明改变增益能否消除自振
本卷实例
  • 关键一步：讨论增益变化使线性曲线整体上下移动的效果
  • 中间结果：增益减小到一定程度可使交点消失
  • 卡点：消振后还要复核系统的动态性能
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 极限环的稳定性可由相轨迹收敛或发散判断
  • 减小非线性影响可用加大线性部分增益或引入校正
  • 用描述函数或相平面结果指导参数选择
步骤

  • 分析非线性环节参数对自振幅值频率的影响
  • 通过调整线性部分增益或加入校正削弱自振
  • 重新分析确认自振消除或幅值达标
通用考法

  • 提出消除自振的工程措施
  • 分析增益变化对极限环幅值的影响
  • 比较不同方案对稳定性与动态性能的利弊
常见易错
  • 本卷考过只调增益而不检查是否引入新的自振点
  • 仅调整增益而不检查是否引入新的自振点
  • 把不稳定极限环误判为可观测的自振
