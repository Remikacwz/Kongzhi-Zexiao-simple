一一、简答题：控制基本概念15 分#

思路
  • 从极点配置、反馈、三频段、减小稳态误差与基本性能要求五个概念分别作答
状态反馈与极点配置 状态空间分析
本卷考法
  • 简述极点配置的含义与实现途径
本卷实例
  • 关键一步：从引入反馈改变闭环极点位置这一角度表述
  • 中间结果：实现途径可为状态反馈或输出反馈
  • 卡点：概念题无图无数值，注意写在答题纸上
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过简述极点配置的含义与实现途径
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 本卷考过把极点配置与单纯调增益混为一谈
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
公式
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 说明反馈的含义与控制作用
  • 答出自动控制系统的三项基本性能要求
本卷实例
  • 关键一步：按输出量回送输入端与给定值比较来描述反馈
  • 中间结果：三项要求为稳定性、准确性、快速性
  • 卡点：两小问要分别作答，避免只答其中一项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过说明反馈的含义与控制作用
  • 本卷考过答出自动控制系统的三项基本性能要求
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把反馈量与被控量说成同一个量
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
开环对数频率特性的绘制 频域分析
本卷考法
  • 说明开环对数幅频三频段与系统性能的对应关系
本卷实例
  • 关键一步：按低频、中频、高频分段对应稳态、动态与抗扰
  • 中间结果：中频段形状决定动态平稳性与快速性
  • 卡点：三频段划分要与转折频率对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过说明开环对数幅频三频段与系统性能的对应关系
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 本卷考过把高频段的作用说成提升稳态精度
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

减小稳态误差的措施 稳态误差
本卷考法
  • 列举减小稳态误差的常用措施
本卷实例
  • 关键一步：从提高增益、增加积分环节与补偿三方面作答
  • 中间结果：提高开环增益可降误差，但会压低稳定裕度
  • 卡点：措施需与系统型别对应，别只答一种手段
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过列举减小稳态误差的常用措施
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 本卷考过只提高开环增益而不检查稳定性
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

二1二1、结构图求闭环传递函数10 分#

思路
  • 按结构图逐层化简，或用梅森增益公式直接求闭环传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求多回路结构图的闭环传函
本卷实例
  • 关键一步：先列全部独立回路并判断有无互不接触回路
  • 中间结果：特征式只含单回路项，无二阶项
  • 卡点：结构图未读图，回路增益需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求多回路结构图的闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过余子式没剔除与前向通路接触的回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式

二2二2、劳斯判据求稳定K范围10 分#

思路
  • 写出闭环特征多项式列劳斯表，由首列严格同号求稳定K范围
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求闭环稳定时K的取值范围
本卷实例
  • 关键一步：把开环传函通分化成闭环特征多项式再列劳斯表
  • 中间结果：首列各项严格为正才保证稳定

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理

  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求闭环稳定时K的取值范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过系数有缺项时没补零就直接列表
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

二3二3、描述函数法判断自振10 分#

思路
  • 把线性部分频率特性与负倒描述函数画在同一复平面，按交点判自振
用描述函数法分析自振 非线性系统
本卷考法
  • 用描述函数法判断是否自振并求振幅与频率
本卷实例
  • 关键一步：在同一复平面上画线性部分与负倒描述函数找交点
  • 中间结果：交点坐标对应自振的振幅与频率
  • 卡点：奈氏曲线形状未读图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过用描述函数法判断是否自振并求振幅与频率
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 本卷考过画的是描述函数本身而不是负倒描述函数
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率

  • 把描述函数当成频率的函数
