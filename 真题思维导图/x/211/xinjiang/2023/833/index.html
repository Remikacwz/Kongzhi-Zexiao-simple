1一、系统结构图求闭环传函10 分#

思路
  • 数出全部回路与前向通路，用梅森增益公式求闭环传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求两前向通路结构图的闭环传函
本卷实例
  • 关键一步：先列全部回路并判断有无互不接触回路，再对每条前向通路写余子式
  • 中间结果：特征式只含单回路项，无二阶项
  • 卡点：结构图未读图，回路增益与比较点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求两前向通路结构图的闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过余子式没有剔除与前向通路接触的回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 用逐层化简核对多回路结构图结果
本卷实例
  • 关键一步：从最内环开始把局部反馈化成一个等效环节
  • 中间结果：逐层化简结果应与梅森公式一致
  • 卡点：化简顺序不同时中间式子形式会变但结果相同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过用逐层化简核对多回路结构图结果
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过化简内环时把外环信号当成常数处理
  • 化简内环时把外环的信号当成常数处理

  • 化为标准形式时忘记把 s² 项系数归一化
