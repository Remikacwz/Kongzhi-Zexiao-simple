一1一1、型别阶次与开环频率特性10 分#

思路
  • 由开环传函读型别、阶次、零点极点与开环增益，再把复变量换成jω写出幅频与相频
传递函数的定义与基本性质 传递函数
本卷考法
  • 由开环传函指出系统型别、阶数、零点与极点
本卷实例
  • 关键一步：分母最高次定阶数，分子分母根数定零点极点个数
  • 中间结果：开环增益为各串联环节增益之积
  • 卡点：型别按积分环节个数数，不是按阶数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由开环传函指出系统型别、阶数、零点与极点
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过把开环零点与闭环零点混同
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环传函判断系统型别并求开环增益
本卷实例
  • 关键一步：由s因子个数定系统型别
  • 中间结果：开环增益由传函标准形式中的常数比给出
  • 卡点：零极点要用标准形式读出，先化成时间常数形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由开环传函判断系统型别并求开环增益
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 本卷考过把开环增益与静态误差系数混为一谈
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求开环幅频特性与相频特性表达式
本卷实例
  • 关键一步：把jω代入后分别取模与取相角
  • 中间结果：幅频等于分子各环节模之积除以分母模之积
  • 卡点：分母复数要先取模再相除，不能逐项约分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求开环幅频特性与相频特性表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过相角累加时漏掉积分环节的负九十度
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

一2一2、奈氏判据判断稳定性与K范围6 分#

思路
  • 先数开环右半平面极点数P，再由幅相曲线包围原点情况判断闭环稳定性，并按增益缩放求稳定K区间
奈奎斯特判据 稳定性分析
本卷考法
  • 由最小相位系统奈氏图判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数P，再看曲线包围情况
  • 中间结果：闭环右半平面极点数由P与包围圈数共同决定
  • 卡点：幅相曲线以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由最小相位系统奈氏图判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过开环含积分环节时未补画无穷大半径圆弧
  • 本卷考过未先数P就数包围圈数
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由奈氏判据反求使闭环稳定的开环增益范围
本卷实例
  • 关键一步：把曲线按增益比例整体缩放后逐段考察包围数
  • 中间结果：稳定增益区间可能分成若干段
  • 卡点：端点是否包含要按曲线穿越方式确定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由奈氏判据反求使闭环稳定的开环增益范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 本卷考过只按单一穿越点写不等式而漏另一段
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式

一3一3、描述函数法判断自振与增益影响6 分#

思路
  • 按负倒描述函数与奈氏曲线的交点性质及振幅增大方向判断自振，再讨论增益增减对稳定性的影响
用描述函数法分析自振 非线性系统
本卷考法
  • 由负倒描述函数与奈氏曲线的交点判断自持振荡
本卷实例
  • 关键一步：由负倒描述函数上振幅增大的方向判断交点性质
  • 中间结果：由不稳定区穿入稳定区的交点对应稳定自振
  • 卡点：两条曲线以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过由负倒描述函数与奈氏曲线的交点判断自持振荡
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 本卷考过未标注振幅增大方向就直接下结论
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率
公式
非线性系统的稳定性与改善 非线性系统
本卷考法
  • 分析增大或减小线性部分增益对稳定性的影响
本卷实例
  • 关键一步：讨论增益变化使线性曲线整体上移或下移的效果
  • 中间结果：增益过大或过小都会改变交点是否存在
  • 卡点：还要说明消振后动态性能是否满足要求
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 非线性系统只有局部稳定性概念，与初始条件有关
  • 极限环的稳定性可由相轨迹收敛或发散判断
  • 减小非线性影响可用加大线性部分增益或引入校正
  • 用描述函数或相平面结果指导参数选择
步骤
  • 判断系统是否存在极限环并确定其稳定性
  • 分析非线性环节参数对自振幅值频率的影响
  • 通过调整线性部分增益或加入校正削弱自振
  • 重新分析确认自振消除或幅值达标
通用考法
  • 本卷考过分析增大或减小线性部分增益对稳定性的影响
  • 提出消除自振的工程措施
  • 分析增益变化对极限环幅值的影响
  • 比较不同方案对稳定性与动态性能的利弊
常见易错
  • 本卷考过只调增益而不检查是否引入新的自振点
  • 仅调整增益而不检查是否引入新的自振点
  • 把不稳定极限环误判为可观测的自振

二1二1、由阶跃响应求闭环传递函数6 分#

思路
  • 由阶跃响应的稳态值与指数项写出输出拉氏变换，再按单位阶跃输入反求闭环传递函数
由响应曲线反求传递函数 传递函数
本卷考法
  • 由给定单位阶跃响应函数求系统闭环传递函数
本卷实例
  • 关键一步：把响应分成稳态分量与暂态分量再逐项取拉氏变换
  • 中间结果：输出拉氏变换与输入拉氏变换之比即闭环传函
  • 卡点：指数项符号两源OCR不一致，取自洽的衰减形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由给定单位阶跃响应函数求系统闭环传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数

  • 本卷考过未检查初值是否为零就直接做拉氏变换
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

二2二2、结构图求闭环传递函数8 分#

思路
  • 由梅森公式找全部前向通路与独立回路写特征式，再用逐层化简核对闭环传函
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求结构图的闭环传递函数
本卷实例
  • 关键一步：先找全部独立回路与前向通路，再写特征式
  • 中间结果：存在两两不接触回路时特征式保留二阶项
  • 卡点：结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求结构图的闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路找漏或重复计数
  • 本卷考过余子式未剔除与通路接触的回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 逐层化简多回路结构图核对闭环传函
本卷实例
  • 关键一步：由内到外把每一层反馈内环等效为单个环节
  • 中间结果：逐层化简结果应与梅森公式结论一致
  • 卡点：比较点移动后支路增益要相应补偿
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联

  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法

  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过化简内环时把外环的信号当成常数
  • 化简内环时把外环的信号当成常数处理

二3二3、劳斯判据求稳定K范围8 分#

思路
  • 由开环传函写闭环特征多项式，列劳斯表，由首列各元同号解出K的取值范围
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求系统稳定时K的取值范围
本卷实例
  • 关键一步：开环含右半平面极点，须列1加G(s)H(s)等于零的闭环特征方程
  • 中间结果：首列各元同号给出K的不等式组
  • 卡点：开环不稳定时不能只由开环极点位置判稳
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求系统稳定时K的取值范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
