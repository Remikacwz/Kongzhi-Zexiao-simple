1一、判断题：稳定性与控制基本概念#

思路
  • 判断稳定性影响因素、自振是否非线性特有、传递函数能否描述离散系统三个命题
非线性系统的特点 非线性系统
本卷考法
  • 判断自振运动是否非线性系统特有现象
本卷实例
  • 关键一步：自振由非线性环节引起，线性系统不会自持振荡
  • 中间结果：线性系统临界稳定只产生等幅振荡，不是自激振荡
  • 卡点：命题表述简略，需逐条回原卷核对原句
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过判断自振运动是否非线性系统特有现象
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 本卷考过把线性系统的等幅振荡当成自振
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
传递函数的定义与基本性质 传递函数
本卷考法
  • 判断传递函数能否用来描述离散系统
本卷实例
  • 关键一步：传递函数基于连续系统拉氏变换定义，离散系统用脉冲传函
  • 中间结果：离散系统的输入输出关系应写成z域脉冲传递函数
  • 卡点：注意区分传递函数与脉冲传递函数的适用对象
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过判断传递函数能否用来描述离散系统
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过把连续系统的传递函数直接套到离散系统
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
劳斯判据 稳定性分析
本卷考法
  • 说明稳定性由结构决定，与输入扰动无关（借位 st_01）
本卷实例
  • 关键一步：稳定性是系统固有属性，只由结构与参数决定
  • 中间结果：输入和扰动大小不改变闭环极点在复平面上的位置
  • 卡点：命题把输入扰动也列入影响因素，属干扰项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过说明稳定性由结构决定，与输入扰动无关（借位 st_01）
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过把输入或扰动的大小当作稳定性影响因素
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

2二、平衡状态与李雅普诺夫判稳8 分#

思路
  • 由非线性状态方程组求平衡点，取正定二次型函数作李雅普诺夫函数，由其导数负定判断渐近稳定
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 由状态方程求平衡点并用李雅普诺夫第二法判稳
本卷实例
  • 关键一步：令两个状态导数同时为零解出平衡状态
  • 中间结果：取关于状态的二次型正定函数，其沿轨线导数化为负定
  • 卡点：判断大范围渐近稳定还要看状态趋于无穷时函数是否趋向无穷
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过由状态方程求平衡点并用李雅普诺夫第二法判稳
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 本卷考过只验证李雅普诺夫函数正定而漏查其导数
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

3三、电路网络求传递函数8 分#

思路
  • 对含两个电容与电阻的无源网络列电流电压方程，经拉氏变换消去中间变量求 Uc 对 Ur 的传函
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由多电容电阻网络列复频域方程求 Uc(s)/Ur(s)
本卷实例
  • 关键一步：按电容电流与电压关系列方程，再对时间取拉氏变换
  • 中间结果：中间变量为两电容支路电流，消元后得到有理分式
  • 卡点：电路以图给出，元件连接与电流方向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由多电容电阻网络列复频域方程求 Uc(s)/Ur(s)
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过把电容阻抗误写成 Cs 导致方程出错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 对含多电容电阻的无源网络建立电路方程
本卷实例
  • 关键一步：对节点列电流关系，对回路列电压关系
  • 中间结果：电容与电阻在复频域写成阻抗形式参与分压
  • 卡点：消元时漏掉某一支路电流会少一个方程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过对含多电容电阻的无源网络建立电路方程
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 本卷考过电容电压与电流关系写反
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

4四、离散系统闭环脉冲传函#

思路
  • 按采样开关位置逐级写离散化方程，用消元或梅森公式求闭环脉冲传递函数
脉冲传递函数 离散控制系统
本卷考法
  • 由离散系统框图求闭环脉冲传递函数
本卷实例
  • 关键一步：把每个采样开关后的连续环节单独取z变换，再按框图化简
  • 中间结果：闭环脉冲传函写成前向z传函除以一加开环z传函
  • 卡点：采样开关位置以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过由离散系统框图求闭环脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 本卷考过连续环节之间无采样开关时直接相乘取z变换
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)

思路
  • 选电感电流与电容电压作状态变量，列写电路方程并整理成状态空间表达式
状态空间表达式的建立 状态空间分析
本卷考法
  • 由电路图选状态变量并建立状态空间表达式
本卷实例
  • 关键一步：选储能元件上的电流与电压作为状态变量

  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由电路图选状态变量并建立状态空间表达式
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 本卷考过状态变量个数与独立储能元件数不一致
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

6六、状态转移矩阵与状态响应8 分#

思路
  • 由两组已知初始状态与对应响应反求状态转移矩阵，再代入新初值求状态响应
状态转移矩阵 状态空间分析
本卷考法
  • 由两组响应反求状态转移矩阵并计算给定初值下的状态
本卷实例
  • 关键一步：把两组解按矩阵形式并列，右乘初值矩阵的逆得到转移矩阵
  • 中间结果：转移矩阵由两组线性无关响应按列拼成的矩阵确定
  • 卡点：初值矩阵须可逆，否则要另找线性无关的两组条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过由两组响应反求状态转移矩阵并计算给定初值下的状态
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 本卷考过初值矩阵不可逆时仍直接求逆
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错

7七、状态反馈极点配置20 分#

思路
  • 先由能控性矩阵判断能否任意配置极点，再设状态反馈增益阵由期望特征多项式比较系数求反馈阵
能控性与能观性 状态空间分析
本卷考法
  • 由能控性矩阵判别能否任意配置极点
本卷实例
  • 关键一步：计算能控性矩阵的秩，满秩说明可任意配置极点
  • 中间结果：二阶系统能控性矩阵由输入矩阵与其和状态矩阵乘积组成
  • 卡点：能控性判据的矩阵构造与能观性判据不要混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过由能控性矩阵判别能否任意配置极点
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 本卷考过只算到能控性矩阵前几列就下结论
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
状态反馈与极点配置 状态空间分析
本卷考法
  • 按给定闭环极点求状态反馈增益阵并画结构图
本卷实例
  • 关键一步：由闭环特征多项式与期望多项式逐项比较系数
  • 中间结果：反馈增益阵各分量由两多项式的系数差确定
  • 卡点：结构图未读图，反馈引入点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
