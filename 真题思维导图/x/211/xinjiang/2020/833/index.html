一一、填空题：控制基本概念#

思路
  • 填空题覆盖状态空间组成、稳定裕度、极限环、零极点对消、分离点、相位裕度与二阶超调等基本概念
状态空间表达式的建立 状态空间分析
本卷考法
  • 答状态空间表达式由哪两部分构成
本卷实例
  • 关键一步：状态空间表达式由状态方程和输出方程构成
  • 中间结果：状态方程描述状态变量的一阶导数关系
  • 卡点：该空是回忆版中唯一明确考概念的一空
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过答状态空间表达式由哪两部分构成
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 本卷考过把状态方程与输出方程的作用混同
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

稳定裕度 频域分析
本卷考法
  • 答线性定常系统稳定时幅值裕度的取值范围
本卷实例
  • 关键一步：系统稳定时幅值裕度大于零分贝
  • 中间结果：幅值裕度表示开环增益还能放大的倍数
  • 卡点：幅值裕度在相位穿越频率处定义
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过答线性定常系统稳定时幅值裕度的取值范围
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过把幅值裕度的分贝表示与倍数表示混用
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

非线性系统的特点 非线性系统
本卷考法
  • 答非线性系统独有的运动状态
本卷实例
  • 关键一步：极限环是线性系统不会出现的运动状态
  • 中间结果：非线性系统的稳定性与初始条件有关
  • 卡点：自持振荡对应相平面上的极限环
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过答非线性系统独有的运动状态

  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 本卷考过把非线性与线性系统的结论直接等同
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 答单入单出系统零极点对消对应的系统属性
本卷实例
  • 关键一步：从状态空间实现是否为最小来实现判断
  • 中间结果：零极点对消意味着系统不完全能控或不完全能观
  • 卡点：被对消的极点仍会出现在状态空间中
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过答单入单出系统零极点对消对应的系统属性
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 本卷考过把零极点对消与系统阶数直接等同
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

分离点与会合点 根轨迹法
本卷考法
  • 答实轴上两个极点之间根轨迹的特征点
本卷实例
  • 关键一步：两极点之间的根轨迹段上会出现分离点
  • 中间结果：分离点位置由增益取极值处确定
  • 卡点：分离点是否在根轨迹上要按实轴段判据核实
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过答实轴上两个极点之间根轨迹的特征点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 本卷考过把分离点与会合点当作同一概念
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 答阻尼比减小时最大超调量的变化趋势
本卷实例
  • 关键一步：欠阻尼下阻尼比越小超调量越大
  • 中间结果：超调量只由阻尼比决定
  • 卡点：该空要求填变化趋势而非具体数值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过答阻尼比减小时最大超调量的变化趋势
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错

  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

思路

频率特性的物理意义与求法 频域分析
本卷考法
  • 判断频率分析法是否只分析幅频特性
本卷实例
  • 关键一步：频率特性同时包含幅频与相频两部分
  • 中间结果：只看幅频会丢失相位对系统的影响
  • 卡点：按频率特性定义该说法不完整，应判为错误
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过判断频率分析法是否只分析幅频特性
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过把频率特性只理解成幅频特性
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

劳斯判据 稳定性分析
本卷考法
  • 答线性定常系统稳定的充要条件
本卷实例

  • 中间结果：特征根全具负实部则系统稳定
  • 卡点：稳定性只由结构参数决定，与输入无关
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过答线性定常系统稳定的充要条件
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过把开环极点与闭环极点混用
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
