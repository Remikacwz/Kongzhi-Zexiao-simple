思路

传递函数的定义与基本性质 传递函数
本卷考法
  • 判断哪类系统可以用传递函数描述
本卷实例
  • 关键一步：由传递函数基于线性定常与零初始条件这一前提逐项排除
  • 中间结果：只有线性定常系统能用传递函数描述
  • 卡点：四个选项的干扰性都强，要按前提逐项排除
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过判断哪类系统可以用传递函数描述
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过把时变或非线性系统也归入传递函数适用范围
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法

本卷实例

  • 中间结果：阻尼比等于零对应无阻尼等幅振荡
  • 卡点：四个选项分属不同区间，判断前先记牢
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由阻尼比取值判断系统所处状态
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过把无阻尼与欠阻尼的取值区间搞混
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

本卷考法

本卷实例

  • 中间结果：超调量随阻尼比增大而减小
  • 卡点：区间端点是否包含要按严格不等号判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 振荡次数与 ξ 直接相关
步骤

  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法

  • 分析 ωn 变化时各指标如何变化
常见易错

  • 把两种误差带的调节时间系数搞混

滞后校正 系统校正
本卷考法
  • 选出既改善稳态性能又不牺牲动态性能的校正方式
本卷实例
  • 关键一步：比较超前、滞后与滞后超前校正在各频段的作用
  • 中间结果：滞后校正靠压低高频增益提高稳态精度
  • 卡点：校正方式的取舍要同时兼顾两条性能
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过选出既改善稳态性能又不牺牲动态性能的校正方式
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 本卷考过把滞后校正说成会明显加快响应

自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 答出自动控制系统的三项基本性能要求
  • 列举基本控制方式与闭环系统的组成环节
本卷实例
  • 关键一步：按稳定、准确、快速三方面答性能要求
  • 中间结果：基本控制方式分开环与闭环两类
  • 卡点：闭环组成要答全对象、执行、放大、测量、比较与校正元件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过答出自动控制系统的三项基本性能要求
  • 本卷考过列举基本控制方式与闭环系统的组成环节
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把被控量与操纵量混为一谈
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
