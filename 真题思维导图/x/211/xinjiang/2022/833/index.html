二1二1、由零极点分布求开环传函并画根轨迹#

思路
  • 由零极点分布图写出开环传函，再按绘制法则画根轨迹并判断实轴段
传递函数的定义与基本性质 传递函数
本卷考法
  • 由零极点分布写出开环传递函数
本卷实例
  • 关键一步：零点写成分子一次因式、极点写成分母一次因式并配增益
  • 中间结果：开环极点数决定根轨迹分支数
  • 卡点：零极点分布以图给出，位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由零极点分布写出开环传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过把零极点写成因式时分子分母颠倒
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

二3二3、非线性系统稳定性与增益调节#

思路
  • 由负倒描述函数与线性部分幅相曲线的交点判断稳定性，再讨论调整增益能否消除自振
用描述函数法分析自振 非线性系统
本卷考法
  • 用描述函数法判断非线性系统是否稳定并分析自振
本卷实例
  • 关键一步：由两曲线交点及穿越方向判断是否存在稳定自振
  • 中间结果：曲线由稳定区穿出对应不稳定自振点
  • 卡点：需回原卷核对图以确认两曲线相对位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过用描述函数法判断非线性系统是否稳定并分析自振
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 本卷考过未标出幅值增大方向就判断交点稳定性
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率

二4二4、二阶响应曲线读动态指标#

思路
  • 由典型二阶系统阶跃响应曲线读峰值与峰值时间，求超调量
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阶跃响应曲线读超调量与峰值时间
本卷实例
  • 关键一步：先读稳态值与峰值，再算相对超调并按峰值时刻取峰值时间
  • 中间结果：曲线振荡越强对应阻尼比越小
  • 卡点：响应曲线以图给出，读数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阶跃响应曲线读超调量与峰值时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过把峰值时间当成上升时间读取
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

二5二5、电机调速系统输入与执行环节#

思路
  • 由电机调速系统图指认给定输入与执行环节，并判断系统反馈结构
转速负反馈单闭环调速系统 电力拖动与运动控制
本卷考法
  • 指认转速负反馈调速系统的输入与执行环节
本卷实例
  • 关键一步：按给定电压到电动机再到转速的传递关系划分输入与执行环节
  • 中间结果：执行环节含触发、整流与电动机等功率部件
  • 卡点：系统图未读图，各环节代号需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 被控量是转速，反馈量是测速发电机输出电压
  • 属于有差系统，稳态时偏差 e=U_n*−U_n 必须不为零才能维持输出
  • 闭环后稳态速降减小为开环的 1/(1+K) 倍
  • 闭环放大倍数 K 越大，静差率越小，但稳定性越差
步骤
  • 确定被控制量与反馈量
  • 按信号流向画出给定、比较、放大、变换器、电动机、测速反馈各环节
  • 写出稳态关系式并求闭环静特性
