1一、RLC无源网络求传函与状态方程#

思路
  • 先对RLC无源网络用复阻抗列回路方程并消去中间电流求传递函数，再选两个电容电压为状态变量，利用电容电流方程与KCL整理成状态空间表达式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由RLC无源网络的复阻抗模型求Uc2(s)/U(s)
本卷实例
  • 关键一步：对两电容节点列KCL并消去中间支路电流
  • 中间结果：整理得分子分母同阶的含s有理分式
  • 卡点：网络连接以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由RLC无源网络的复阻抗模型求Uc2(s)/U(s)
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过把电容复阻抗误写成Cs而不是1/(Cs)
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

2二、二阶系统闭环传函、动态指标与稳态误差#

思路
  • 由结构图化简求闭环传函并对比标准二阶形式；由阻尼比求参数τ、超调量与调节时间；再对组合输入用终值定理分别求阶跃与斜坡分量的稳态误差后相加
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图化简求闭环传递函数
本卷实例
  • 关键一步：先求前向通路与反馈通路的乘积GH
  • 中间结果：按1+GH写分母并整理得闭环传函
  • 卡点：开环增益与时间常数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由结构图化简求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过把负反馈分母写成1-GH
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

二阶系统标准形式与阻尼比 时域响应与动态性能

本卷实例

  • 中间结果：由阻尼项系数解出待定时间常数
  • 卡点：自然频率由开环参数决定，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤

  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由给定阻尼比反求结构参数τ

  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置

  • 化为标准形式时忘记把 s² 项系数归一化

本卷实例

3三、三阶系统根轨迹与主导极点降阶#

思路
  • 由结构图取等效开环传函画根轨迹，求分离点与虚轴交点；由欠阻尼条件取对应增益区间；再由等阻尼线与根轨迹交点用主导极点降阶求闭环传递函数
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画三阶系统180度根轨迹
本卷实例
  • 关键一步：先定开环零极点与实轴根轨迹段
  • 中间结果：由渐近线夹角与交点补全轨迹草图
  • 卡点：等效开环传函需从结构图核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画三阶系统180度根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴段判据中零极点个数算错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

思路

由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频特性反求开环传递函数
本卷实例

  • 中间结果：再按各转折频率补上对应环节
  • 卡点：渐近线标注以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节

  • 写出并验证传递函数

  • 检验候选传递函数与曲线是否吻合

  • 把延长线交点误当作增益值而未折算型别

稳定裕度 频域分析
本卷考法
  • 计算截止频率与相角裕度并判稳
本卷实例
  • 关键一步：由幅值为1的条件解出截止频率
  • 中间结果：相角裕度等于180度加该处相角
  • 卡点：相角计算需按转折频率逐段累加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
