2二、二阶系统动态指标与稳态误差设计#

思路
  • 由闭环传函对比二阶标准形式读出自然频率与阻尼比；用超调量公式反求阻尼比，再用单位斜坡稳态误差经终值定理求静态速度误差系数，反求开环增益与阻尼参数；最后在误差通道引入可调补偿项抵消输入极点使稳态误差为零
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函对比二阶标准形式求阻尼比与自然频率
本卷实例
  • 关键一步：把闭环传函分母与标准二阶形式逐项比较，读出阻尼项与自然频率
  • 中间结果：自然频率由开环增益开方得到，阻尼比由阻尼项与自然频率之比得到
  • 卡点：图2反馈结构与补偿项接入点未读图，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函对比二阶标准形式求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由给定超调量反求阻尼比并判断欠阻尼
本卷实例
  • 关键一步：把超调量参数代入超调量公式，由给定值反解阻尼比
  • 中间结果：反解出的阻尼比落在零与一之间，系统为欠阻尼
  • 卡点：反解时需舍去不在欠阻尼范围内的根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由给定超调量反求阻尼比并判断欠阻尼
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 用终值定理由单位斜坡稳态误差反求参数
本卷实例
  • 关键一步：写出误差传函乘单位斜坡拉氏变换后取s趋于零的极限
  • 中间结果：该极限等于静态速度误差系数的倒数
  • 卡点：用终值定理前需先确认闭环系统稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过用终值定理由单位斜坡稳态误差反求参数
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 设计补偿项使单位斜坡下稳态误差为零
本卷实例
  • 关键一步：在误差通道引入可调补偿项，使误差传函分子出现s因子
  • 中间结果：补偿参数取原阻尼项数值时输入极点被抵消
  • 卡点：补偿后须校验闭环仍稳定，并回原卷核对接入位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计补偿项使单位斜坡下稳态误差为零
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

3三、三阶系统根轨迹与闭环极点#

思路
  • 由开环传函按180度根轨迹绘制法则画根轨迹，求出分离点与虚轴交点；由闭环根为左半平面共轭复根的条件取两交点之间的根轨迹段定出衰减振荡的增益范围；再由已知一个闭环实极点用幅值条件求出对应增益，并通过闭环特征多项式分解求其余两个极点
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画三阶系统180度根轨迹
本卷实例
  • 关键一步：标出开环极点，判断实轴根轨迹段并求渐近线交点与夹角
  • 中间结果：三条渐近线交于开环极点实部的均值，夹角按奇数等分
  • 卡点：分离点方程的两个根需按实轴段判据筛选取舍
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画三阶系统180度根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点及其对应增益
本卷实例
  • 关键一步：由幅值条件写出增益关于s的表达式，令其导数为零得分离点方程
  • 中间结果：分离点处增益是衰减振荡的增益下界
  • 卡点：方程的解要代回实轴段判据，不在根轨迹上的根舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点及其对应增益
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界增益
本卷实例

  • 中间结果：交点处增益是系统稳定的临界上界

步骤

  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法

  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

  • 增益增大一般使系统响应加快但振荡加剧

  • 由幅值条件求出交点对应的参数

  • 本卷考过由分离点与虚轴交点确定衰减振荡的增益范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错

  • 由极点位置估指标时忽略零点的作用

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 由已知闭环极点用幅值条件求增益并求其余极点
本卷实例
  • 关键一步：把已知闭环根代入幅值条件求增益，再用特征多项式除法求其余根
  • 中间结果：已知根落在实轴根轨迹段上，故可直接用幅值条件
  • 卡点：求其余根时除以已知根多项式后要核对三项系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过由已知闭环极点用幅值条件求增益并求其余极点
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

7七、非线性状态方程的李雅普诺夫稳定性#

思路
  • 先令两个状态导数同时为零求出平衡点，在平衡点求偏导得到线性化方程，用李雅普诺夫第一法由特征值判断局部稳定性；再构造二次型函数并沿原非线性方程求导，由函数正定与导数负定判断大范围渐近稳定，并讨论参数符号的影响
非线性模型的线性化 建模与机电系统
本卷考法
  • 在平衡点处对非线性状态方程作小偏差线性化
本卷实例
  • 关键一步：令两个状态导数同时为零求平衡点，再在平衡点处求偏导得线性化矩阵
  • 中间结果：线性化矩阵为反对称形式，特征方程只含特征值平方项与常数项
  • 卡点：需先确认平衡点是否唯一，再判断线性化模型适用范围

步骤

李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 用第一法与第二法判断系统稳定性
本卷实例
  • 关键一步：第一法解线性化系统特征值判局部稳定；第二法构造二次型函数并沿轨迹求导
  • 中间结果：取交叉项系数使导数中一次项相消，只剩高次项决定符号
  • 卡点：第一法在特征值实部为零时失效，需改用第二法判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过用第一法与第二法判断系统稳定性
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数
