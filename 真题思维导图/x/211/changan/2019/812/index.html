1一、RLC网络求传函与状态方程15 分#

思路
  • 先用复阻抗法对RLC网络列回路方程消去中间电流求出输出对输入的传函，再以电感电流和电容电压为状态变量按KCL与元件关系列状态方程。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由RLC无源网络列复阻抗方程求Uo与Ui之比
本卷实例
  • 关键一步：对两个回路列KVL并消去中间支路电流
  • 中间结果：输出分压关系与输入回路阻抗联立整理
  • 卡点：网络连接以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由RLC无源网络列复阻抗方程求Uo与Ui之比
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过把电容复阻抗误写成Cs而不是1/(Cs)
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

状态空间表达式的建立 状态空间分析
本卷考法

本卷实例

  • 中间结果：消去非状态量得两状态一输入模型
  • 卡点：状态变量定义以原卷印刷为准

  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du

  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵

  • 状态变量个数与系统阶数不匹配

2二、方框图求闭环传函与二阶动态指标#

思路
  • 先用回路化简或梅逊公式求闭环传函，再化为标准二阶形式读最佳阻尼比对应的参数，按指标公式求超调量与调节时间，最后求组合输入下的稳态误差。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由多回路方框图逐层化简求闭环传函
本卷实例
  • 关键一步：先求内环等效传函再化简外环
  • 中间结果：整理成标准二阶分母的分式
  • 卡点：方框图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由多回路方框图逐层化简求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过化简内环时把外环信号当成常数处理
  • 化简内环时把外环的信号当成常数处理
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由最佳阻尼比条件反求时间常数tau
本卷实例
  • 关键一步：把分母s平方项系数归一后对照标准形式
  • 中间结果：令阻尼比等于最佳值反解tau
  • 卡点：最佳阻尼比数值以题面为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由最佳阻尼比条件反求时间常数tau
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过未把s平方项系数归一化就对照标准形式
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率求超调量和调节时间
本卷实例
  • 关键一步：由标准二阶分母读出阻尼比与自然频率
  • 中间结果：分别代入超调量与5%调节时间公式
  • 卡点：误差带取5%以题面为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率求超调量和调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过峰值时间与调节时间的公式混用
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求阶跃与斜坡组合输入下的稳态误差
本卷实例
  • 关键一步：先判稳再对误差传函用终值定理
  • 中间结果：把两个分量的拉氏像分别代入误差式
  • 卡点：输入幅度以题面印刷为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求阶跃与斜坡组合输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过输入为组合信号时漏掉某一分量
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、信号流图梅逊公式求传递函数#

思路
  • 在系统图上找出全部独立回路与两两不接触回路，写特征式，再列出全部前向通路及余子式，按梅逊公式求总传输。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由系统图用梅逊增益公式求闭环传函
本卷实例
  • 关键一步：列出全部独立回路写特征式delta
  • 中间结果：分别写各前向通路增益与余子式
  • 卡点：回路与前向通路以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤

  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由系统图用梅逊增益公式求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过余子式中未剔除与通路接触的回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

4四、根轨迹绘制与振荡衰减Kg范围#

思路
  • 先写开环极点零点、实轴段与渐近线并求分离点与虚轴交点，再按根轨迹穿越情况给出稳定范围，进一步由共轭极点条件给出振荡衰减范围，最后用一已知闭环极点求其余极点。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画三极点系统根轨迹草图
本卷实例
  • 关键一步：列出开环极点并判定实轴上的轨迹段
  • 中间结果：按渐近线条数、夹角与交点画走向
  • 卡点：根轨迹形状以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画三极点系统根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过渐近线夹角公式中的2k加1写成2k
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

5五、由Bode图求开环传函与相角裕度#

思路
  • 由对数幅频特性的低频段斜率与高度定系统型别与增益，按转折频率写出开环传函；再求幅值穿越频率与相角裕度，最后考察比例环节增益变化对裕度的影响。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频特性曲线反求开环传递函数
本卷实例
  • 关键一步：由低频段斜率与高度定型别和增益
  • 中间结果：按各转折频率写出各典型环节
  • 卡点：转折频率以题面印刷为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
