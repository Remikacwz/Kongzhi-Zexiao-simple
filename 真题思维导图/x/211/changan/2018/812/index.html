1一、有源电路求传递函数#

思路
  • 按运放虚短虚断把两输入端电位取相等，对中间节点列KCL消去节点电压，整理得输出对输入的传递函数。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由含运放的RC有源电路用复阻抗关系求传函
本卷实例
  • 关键一步：由虚短虚断认定两输入端电位相等
  • 中间结果：对中间节点列KCL并消去节点电压
  • 卡点：电路连接以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由含运放的RC有源电路用复阻抗关系求传函
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过把电容复阻抗写成Cs而不是1/(Cs)
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 有源网络建模时用虚短与虚断列节点方程
本卷实例
  • 关键一步：把运放两输入端电位取相等后再列电流方程
  • 中间结果：联立节点方程整理为Uo与Ui之比
  • 卡点：反馈支路接法以原卷插图为准

2二、方框图求闭环传函与二阶动态指标#

思路
  • 先用回路化简或梅逊公式求闭环传函，再化为标准二阶形式读阻尼比与自然频率，按指标公式求调节时间，最后用误差传函求组合输入下的稳态误差。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由多回路方框图逐层化简求闭环传函
本卷实例
  • 关键一步：先求内环等效传函再化简外环
  • 中间结果：整理成分子为自然频率平方的分式
  • 卡点：方框图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由多回路方框图逐层化简求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过化简内环时把外环的信号当成常数
  • 化简内环时把外环的信号当成常数处理
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为标准二阶形式读阻尼比
本卷实例
  • 关键一步：把分母s平方项系数归一后对照标准形式
  • 中间结果：由对应项系数关系反解时间常数tau
  • 卡点：参数字母写法以原卷印刷为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为标准二阶形式读阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过未把s平方项系数归一化就对照标准形式
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率计算调节时间
本卷实例
  • 关键一步：由标准二阶分母读出阻尼比与自然频率
  • 中间结果：把两者代入5%误差带调节时间公式
  • 卡点：本题按5%误差带计算，勿混用2%
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率计算调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过5%误差带的调节时间系数取错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求阶跃与斜坡组合输入下的稳态误差
本卷实例
  • 关键一步：先判定闭环稳定性再对误差传函用终值定理
  • 中间结果：把阶跃与斜坡的拉氏像分别代入误差式
  • 卡点：输入幅度以题面印刷为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求阶跃与斜坡组合输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过组合信号漏掉斜坡分量对应的误差项
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、劳斯判据判断闭环稳定k范围#

思路
  • 由开环传函写出闭环特征多项式，列劳斯表，考察首列各元符号是否可能同号，从而给出使闭环稳定的参数条件。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯表首列符号判断含参系统稳定性
本卷实例
  • 关键一步：由闭环特征方程列出劳斯表
  • 中间结果：写出首列含k的各元表达式
  • 卡点：特征方程以题面印刷为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯表首列符号判断含参系统稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过特征多项式系数缺项时不补零直接排表
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由劳斯表首列不等式讨论参数稳定域
本卷实例
  • 关键一步：把首列各元大于零写成不等式组
  • 中间结果：检验该不等式组是否存在公共解
  • 卡点：k的符号约定以题面为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由劳斯表首列不等式讨论参数稳定域
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 本卷考过只取部分首列元的不等式而漏掉约束
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

4四、根轨迹绘制与闭环稳定k范围#

思路
  • 先写开环极点零点、实轴段与渐近线，再求分离点，最后令s=jω代入特征方程求虚轴交点与临界增益，由轨迹穿越情况给出稳定k范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画重极点系统的根轨迹草图
本卷实例
  • 关键一步：列出开环极点并判定实轴上的轨迹段
  • 中间结果：按渐近线条数与夹角画出走向
  • 卡点：根轨迹形状以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画重极点系统的根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴段判据中的零极点个数算错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式

5五、奈奎斯特曲线绘制与稳定性判断#

思路
  • 写出开环幅频与相频表达式，取omega从零到无穷描出幅相曲线，再按开环右半平面极点数与包围圈数用奈奎斯特判据判断闭环稳定性。
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅相曲线按奈奎斯特判据判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数P
  • 中间结果：由omega从零到无穷的幅相走向判断包围情况
  • 卡点：曲线形状以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
