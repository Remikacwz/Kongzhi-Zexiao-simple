1一、RLC无源网络求传函与状态方程20 分#

思路
  • 先用复阻抗法对RLC网络列回路方程并消去中间电流，求出输出对输入的传递函数；再以电感电流和电容电压为状态变量，按电容电流方程与KCL整理状态空间表达式。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由RLC无源网络列复阻抗方程求Uo(s)/Ui(s)
本卷实例
  • 关键一步：对两个回路列KVL并消去中间支路电流
  • 中间结果：输出端分压关系与输入回路阻抗联立后整理
  • 卡点：网络连接以原卷插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由RLC无源网络列复阻抗方程求Uo(s)/Ui(s)
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过把电容复阻抗误写成Cs而不是1/(Cs)
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

2二、信号流图梅逊增益公式求总传输10 分#

思路
  • 先数清信号流图中的全部回路与互不接触回路，再找前向通路并写出各余子式，最后代入梅逊公式求总传输。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图用梅逊公式求C(s)/R(s)
本卷实例
  • 关键一步：标出全部回路并判断哪些两两不接触
  • 中间结果：前向通路只有一条且与全部回路接触
  • 卡点：支路增益与回路方向以原卷插图为准，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图用梅逊公式求C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过互不接触回路找漏或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

3三、方框图稳定性与速度输入稳态误差15 分#

思路
  • 由方框图求开环传递函数并写闭环特征方程，用劳斯判据求稳定K范围；再用速度误差系数与稳态误差指标求K范围，最后取两段范围的交集。
参数稳定域的确定 稳定性分析
本卷考法
  • 用劳斯判据求使系统稳定的参数范围
本卷实例
  • 关键一步：由闭环特征方程列劳斯表
  • 中间结果：首列元素全部大于零给出一组K不等式
  • 卡点：特征方程系数需按方框图核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过用劳斯判据求使系统稳定的参数范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 本卷考过首列出现零元时未用ε法处理
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

本卷考法

本卷实例

  • 按型别选择对应的静态误差系数公式

4四、速度反馈内环与二阶动态指标15 分#

思路
  • 先求含速度反馈内环的等效开环与闭环传递函数，再与无速度反馈时对比标准二阶形式，由阻尼比求超调量和调节时间，最后由最佳阻尼比条件反求反馈系数。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由含局部速度反馈的方框图求闭环传函
本卷实例
  • 关键一步：先化简内环再求外环等效开环
  • 中间结果：闭环分母由前向通路与反馈通路组合
  • 卡点：内环反馈极性以原卷图为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由含局部速度反馈的方框图求闭环传函
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过把负反馈分母写成1-GH
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
