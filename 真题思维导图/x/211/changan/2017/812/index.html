1一、由微分方程组建立方框图并求传函15 分#

思路
  • 对给定微分方程组在零初始条件下作拉氏变换，按变量关系绘制系统方框图，再用梅逊公式求闭环传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由变量关系图用梅逊公式求闭环传函
本卷实例
  • 关键一步：对微分方程组逐式作拉氏变换并整理变量关系
  • 中间结果：画方框图后确定前向通路与各回路
  • 卡点：变量关系以逐年试题段为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由变量关系图用梅逊公式求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过互不接触回路找漏或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

本卷实例

2二、由动态指标求结构参数与误差传函15 分#

思路
  • 由结构图写闭环特征方程与误差传递函数；由超调量指标求阻尼比，由稳态误差条件求开环增益，再由标准二阶形式求时间常数与调节时间，最后引入Kc使斜坡误差为零。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由超调量指标反求二阶系统阻尼比
本卷实例
  • 关键一步：由结构图写含参数K1K2的闭环特征式
  • 中间结果：与标准二阶形式逐项比较得参数关系
  • 卡点：结构参数定义需按原卷图核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由超调量指标反求二阶系统阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过化标准形式时未归一s平方项系数
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

思路

本卷考法

本卷实例

  • 检查首列符号：全同号则稳定，有变号则数出个数

  • 系数有缺项时不补零，直接套用判据

思路
  • 把开环传函中含参数a的项分离出来，整理成等效开环形式；按参数根轨迹法则确定起点终点、实轴段与分离点，再画出以a为变量的根轨迹。

  • 卡点：等效开环形式需与原特征方程等价
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

5五、由开环Bode图求校正装置与相角裕度15 分#

思路
  • 由未校正与校正后两条对数幅频特性曲线的低频段和转折频率分别写出开环传函，相减得校正装置传函；再按校正后开环幅频为1求剪切频率并算相角裕度。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由两条Bode图反求未校正与校正后开环传函
本卷实例
  • 关键一步：由低频段斜率定型别、由高度定增益
  • 中间结果：按转折频率依次补上对应环节
  • 卡点：两条曲线均以原卷插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
