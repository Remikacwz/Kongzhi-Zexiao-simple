1一、结构图求闭环传递函数10 分#

思路
  • 在结构图上标出全部独立回路与前向通路，用梅逊公式写出特征式与各通路余子式，整理成输出对输入的闭环传函。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由多回路结构图逐步化简求闭环传函
本卷实例
  • 关键一步：先求各内环等效传函再合并并联支路
  • 中间结果：整理成分子为各前向通路之和的分式
  • 卡点：结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由多回路结构图逐步化简求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过化简内环时把外环信号当成常数
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅逊增益公式列回路与前向通路求总传输
本卷实例
  • 关键一步：列出独立回路并写特征式
  • 中间结果：依次写各前向通路增益与余子式
  • 卡点：回路接触关系以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅逊增益公式列回路与前向通路求总传输
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路找漏或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、网络求传递函数10 分#

思路
  • 对含运放的网络用虚短虚断取输入端电位，列出各节点电流方程消去中间电压，整理得输出对输入的传递函数。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由网络复阻抗关系求Uo与Ui之比
本卷实例
  • 关键一步：把各元件写成复阻抗后列节点方程
  • 中间结果：消去中间节点电压整理为传函
  • 卡点：网络结构以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由网络复阻抗关系求Uo与Ui之比
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过复阻抗法中电容阻抗写成Cs
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

3三、零极点形式与参数根轨迹判稳10 分#

思路
  • 先把开环传函化为零极点形式，再以增益为变量整理等效根轨迹方程，按法则画轨迹并求虚轴交点，由交点给出临界稳定条件和增益范围。
传递函数的定义与基本性质 传递函数
本卷考法
  • 把开环传函整理为零极点形式并指出阶数
本卷实例
  • 关键一步：把各因式写成时间常数形式再归一
  • 中间结果：指出极点零点个数与系统阶数
  • 卡点：系数取值以题面印刷为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过把开环传函整理为零极点形式并指出阶数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过分母按升幂抄写导致系数顺序颠倒
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式

本卷考法

本卷实例

  • 方法是用等效开环传递函数把参数提到标准位置

  • 把 α 以外部分视为等效开环传递函数

  • 注意相角条件是否变成 0°

  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 本卷考过整理时没有把参数完整提到分子位置
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

4四、二阶系统参数与扰动补偿15 分#

思路
  • 由闭环特征方程对照标准二阶形式求增益与反馈系数，判稳后用终值定理求斜坡输入下的稳态误差，最后令扰动到输出的传函为零求补偿器。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由标准二阶形式与给定阻尼比求增益和反馈系数
本卷实例
  • 关键一步：由结构图写闭环特征方程并对照标准形式
  • 中间结果：由对应系数相等解出增益与反馈系数
  • 卡点：阻尼比与自然频率以题面为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由标准二阶形式与给定阻尼比求增益和反馈系数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过把开环增益误当成闭环传递函数的系数
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

本卷考法

本卷实例

常见易错
  • 本卷考过未判稳就使用终值定理
  • 未判稳就使用终值定理
