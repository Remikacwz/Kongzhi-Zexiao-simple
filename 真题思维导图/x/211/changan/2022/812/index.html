2二、二阶系统临界稳定、超调量与无稳态误差条件#

思路
  • 由方框图写闭环特征方程，前馈环节为零时用劳斯判据求临界增益；由超调量指标定阻尼比后与特征方程系数比对求增益；再令误差传函恒为零求所需前馈环节
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求系统临界稳定时的增益
本卷实例
  • 关键一步：写出闭环特征方程并补全缺项
  • 中间结果：令劳斯表首列某元素为零求临界增益
  • 卡点：临界振荡频率需由辅助方程核验
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求系统临界稳定时的增益
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过首列出现零后仍按常规继续算
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量指标求阻尼比与主导极点增益
本卷实例
  • 关键一步：由给定超调量反解阻尼比
  • 中间结果：按主导极点位置与特征多项式系数比对
  • 卡点：主极点与第三个闭环根的距离需核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量指标求阻尼比与主导极点增益
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过超调量公式中漏乘100%
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

减小稳态误差的措施 稳态误差
本卷考法
  • 求使系统无稳态误差所需的前馈环节
本卷实例
  • 关键一步：写出误差传函并令其分子恒为零
  • 中间结果：解出前馈环节与对象参数的关系式
  • 卡点：前馈不改变闭环特征方程，稳定性不变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过求使系统无稳态误差所需的前馈环节
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 本卷考过只谈误差为零而不检查闭环稳定性
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

3三、四阶系统根轨迹与稳定K范围#

思路
  • 由单位反馈开环传函按根轨迹法则画四阶系统根轨迹，求渐近线、分离点与虚轴交点，再由劳斯判据得系统稳定时增益的取值范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画四阶系统根轨迹
本卷实例
  • 关键一步：标出四重开环极点并求渐近线交点
  • 中间结果：由夹角公式补全四条渐近线
  • 卡点：实轴根轨迹段判据需逐段核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画四阶系统根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过渐近线夹角公式中的2k+1写成2k
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式

4四、Bode图绘制与串联滞后校正的稳定性分析#

思路
  • 分别写出校正前与校正装置的幅频相频表达式并画渐近幅频特性；由幅值为1求各自截止频率、由该处相角求相角裕度；再比较校正前后的稳定性
开环对数频率特性的绘制 频域分析
本卷考法
  • 画校正前后的开环对数渐近幅频特性
本卷实例
  • 关键一步：由各转折频率逐段叠加斜率
  • 中间结果：得到两条折线型渐近幅频曲线
  • 卡点：转折频率处的斜率变化需逐段核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过画校正前后的开环对数渐近幅频特性
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 本卷考过逐段改斜率时忘记累加而是替换
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

稳定裕度 频域分析
本卷考法
  • 计算校正前后的截止频率与相角裕度
本卷实例
  • 关键一步：由幅值为1的条件分别解出两截止频率
  • 中间结果：按相频表达式累加各环节相角
  • 卡点：估算频率处的相角需按题面精度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过计算校正前后的截止频率与相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过把截止频率与相位穿越频率用反
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
