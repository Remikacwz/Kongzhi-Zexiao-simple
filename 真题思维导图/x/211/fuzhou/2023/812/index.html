1一、由传递关系画结构图并求传函#

思路
  • 把三条代数关系式整理成环节框图，用等效变换分别求参考输入与扰动输入的传递函数
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 用串联并联与反馈等效化简结构图求传函
本卷实例
  • 关键一步：先把每个关系式画成一个环节再按信号流向连接
  • 中间结果：结构图化简后分别得到两条输入到输出的通路
  • 卡点：反馈极性决定分母用加还是用减
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过用串联并联与反馈等效化简结构图求传函
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求参考输入与扰动输入作用下的传递函数
本卷实例
  • 关键一步：求扰动传函时令参考输入为零
  • 中间结果：两个输入的传函分母相同分子不同
  • 卡点：多输入时应分别求再叠加，不能直接相加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求参考输入与扰动输入作用下的传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

2二、高阶系统降阶与指标反求参数#

思路
  • 由超调量与峰值时间求标准二阶参数，再把高阶闭环特征方程分解出一对主导极点因式比较系数定a、K
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 把含主导极点对的高阶系统近似降为二阶
本卷实例
  • 关键一步：把闭环特征方程分解成主导极点对与实极点因式
  • 中间结果：忽略远处实极点的依据是它距虚轴更远
  • 卡点：降阶前要确认主导极点对的留数占主要成分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过把含主导极点对的高阶系统近似降为二阶
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间求阻尼比与自然频率
本卷实例
  • 关键一步：由超调量公式反求阻尼比，再由峰值时间求自然频率
  • 中间结果：两个指标联立可唯一确定标准二阶参数
  • 卡点：峰值时间与调节时间的公式别混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与峰值时间求阻尼比与自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由性能指标反求高阶系统的开环参数
本卷实例
  • 关键一步：把标准二阶特征式与分解后的方程逐项比较
  • 中间结果：比较系数得到含a与K的方程组
  • 卡点：方程有多组解时要回代检验哪组满足主导极点假设
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由性能指标反求高阶系统的开环参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

3三、复合输入下的稳态误差#

思路
  • 分别求参考输入与扰动输入引起的误差，利用叠加原理相加得到总稳态误差
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡参考输入下系统的稳态误差
本卷实例
  • 关键一步：先判断系统型别再选对应的静态误差系数
  • 中间结果：斜坡误差与速度误差系数成反比
  • 卡点：组合输入要按分量分别求误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求斜坡参考输入下系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求阶跃扰动输入引起的稳态误差
本卷实例
  • 关键一步：写出扰动误差传函并令参考输入为零
  • 中间结果：由终值定理求扰动误差的稳态值
  • 卡点：扰动误差与参考误差要相加才是总误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求阶跃扰动输入引起的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式

4四、由共轭极点与阻尼角求参数#

思路
  • 由阻尼角确定阻尼比，写出共轭极点对因式，与闭环特征方程比较系数求k、a及实数极点
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由阻尼角和极点位置确定闭环二阶参数
本卷实例
  • 关键一步：阻尼角的正切与阻尼比满足固定三角关系
  • 中间结果：由极点的实部与虚部写出对应的二次因式
  • 卡点：阻尼角是极点与负实轴夹角，别与相角裕度混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由阻尼角和极点位置确定闭环二阶参数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
零极点分布与响应模态 传递函数
本卷考法
  • 由特征方程因式分解求全部闭环极点
本卷实例
  • 关键一步：将二次因式与一次因式相乘展开后比较系数
  • 中间结果：由常数项与一次项分别解出待定参数
  • 卡点：比较系数前要把特征方程整理成首一形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由特征方程因式分解求全部闭环极点
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

5五、参数根轨迹分离点与实根条件#

思路
  • 把特征方程整理成以k为增益的参数根轨迹，求分离点条件定a，再由全为实根的条件求开环增益
分离点与会合点 根轨迹法
本卷考法
  • 求参数根轨迹的分离点并筛选有效解
本卷实例
  • 关键一步：把特征方程整理成等效开环后对参数求导
  • 中间结果：分离点方程的解要落在实轴根轨迹段内
  • 卡点：求导后得到的解必须代回检验是否在根轨迹上
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求参数根轨迹的分离点并筛选有效解
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画含参数系统的根轨迹草图
本卷实例
  • 关键一步：先按参数大小分区间讨论实轴上根轨迹段
  • 中间结果：渐近线条数与夹角由开环零极点个数差决定
  • 卡点：参数取值不同根轨迹形状不同，要分情况画
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画含参数系统的根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹上实根条件确定开环增益
本卷实例
  • 关键一步：三个特征根都为实数对应根轨迹在实轴上的会合
  • 中间结果：由分离点处参数值反求对应的开环增益
  • 卡点：开环增益与根轨迹增益相差一个零极点系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹上实根条件确定开环增益
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

6六、由裕度与闭环幅频求参数及稳态输出#

思路
  • 由相角裕度条件与闭环幅频条件联立求a、K，再由闭环频率特性求正弦输入的稳态输出
稳定裕度 频域分析
本卷考法
