1一、机电系统建模与信号流图#

思路
  • 把电学方程与力学方程联立，先画结构图再画信号流图，用梅森公式求闭环传递函数
直流电机等机电系统 建模与机电系统
本卷考法
  • 由电学与力学耦合方程列写机电系统模型
本卷实例
  • 关键一步：把电路方程与机械运动方程联立消去中间变量
  • 中间结果：反电动势与电磁力把电路量与机械量耦合起来
  • 卡点：题面只给方程组未给接图，元件连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由电枢回路电压方程与转矩平衡方程联立
  • 反电动势与转速成正比，电磁转矩与电枢电流成正比
  • 机电时间常数由电气与机械两方面参数共同决定
步骤
  • 写出电枢回路电压平衡方程
  • 写出转矩平衡方程（含负载与粘性摩擦）
  • 消去电枢电流，得到转速或转角对电压的传递函数
通用考法
  • 本卷考过由电学与力学耦合方程列写机电系统模型
  • 求直流电机转速或位置对电枢电压的传递函数
  • 分析机电时间常数与电气时间常数的数量级关系
常见易错
  • 漏掉反电动势与电磁转矩的耦合项
  • 把电气时间常数与机电时间常数混淆
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 由方程组画信号流图并用梅森公式求传函
本卷实例
  • 关键一步：先把每个方程画成节点与支路关系再合并
  • 中间结果：回路增益与前向通路增益分别相乘
  • 卡点：不接触回路要单独成项，别漏乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由方程组画信号流图并用梅森公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图化简求闭环传递函数
本卷实例
  • 关键一步：按串联相乘、并联相加、反馈一加回路增益逐层合并
  • 中间结果：回路增益由反馈通道与前向支路相乘得到
  • 卡点：反馈极性决定分母用加还是用减
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由结构图化简求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、由阶跃响应求动态指标#

思路
  • 给定带比例微分环节的二阶系统阶跃响应表达式，先求稳态值，再按定义求峰值时间、超调量与调节时间
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由给定阶跃响应求超调量、峰值时间与调节时间
本卷实例
  • 关键一步：先求稳态值，再由响应导数等于零定峰值时间
  • 中间结果：超调量由峰值与稳态值之差除以稳态值得到
  • 卡点：该响应不是标准二阶，不能直接套用二阶指标公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由给定阶跃响应求超调量、峰值时间与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 试将给定响应与标准二阶阶跃响应比较
本卷实例
  • 关键一步：对照标准式分别检验包络系数与初相
  • 中间结果：两处分别给出的阻尼比不相同，说明非典型二阶
  • 卡点：非典型系统只能按定义逐项求动态指标
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过试将给定响应与标准二阶阶跃响应比较
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式

4四、劳斯判据判虚根与非负实部极点#

思路
  • 由开环传函写六阶闭环特征方程，列劳斯表，数首列变号次数并由辅助方程判断纯虚根
劳斯判据 稳定性分析
本卷考法
  • 用劳斯表判断纯虚根个数与右半平面极点数
本卷实例
  • 关键一步：列劳斯表后数首列变号次数得右半平面根数
  • 中间结果：未出现辅助方程说明不存在纯虚根
  • 卡点：首列出现零或系数缺项时要补零或按辅助方程处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯表判断纯虚根个数与右半平面极点数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式

5五、参数根轨迹与最大超调#

思路
  • 把特征方程整理成参数根轨迹形式，用绘制法则画根轨迹并求分离点，再由等阻尼线与根轨迹相切求最大超调点
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 把含待求参数的特征方程整理成参数根轨迹形式
本卷实例
  • 关键一步：把含参数项并入根轨迹增益写出等效开环
  • 中间结果：等效开环零点为负二与负三，极点为0与负一
  • 卡点：参数根轨迹仍用180度相角条件，别用零度条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过把含待求参数的特征方程整理成参数根轨迹形式
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画参数根轨迹
本卷实例
  • 关键一步：先定实轴段与渐近线，再定复平面形状
  • 中间结果：零极点个数相同，故无渐近线
  • 卡点：实轴段判据数的是该段右侧实数零极点的个数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画参数根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求分离点与会合点并筛选有效解
本卷实例
  • 关键一步：由相角条件或幅值条件关于参数求导
  • 中间结果：分离点方程解出两个实解
  • 卡点：只保留落在实轴根轨迹段内的那个解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求分离点与会合点并筛选有效解
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹确定欠阻尼范围与最大超调对应参数
