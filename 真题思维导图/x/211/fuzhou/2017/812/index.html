1一、信号流图与梅森公式#

思路
  • 由三个环节方程画信号流图，识别独立回路与前向通路，用梅森公式求闭环传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 由环节方程组画信号流图并用梅森公式求传函
本卷实例
  • 关键一步：按方程把输入、中间变量与输出连成节点与支路
  • 中间结果：三条独立回路且均与前向通路接触
  • 卡点：回路正负号由方程中的加减号决定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由环节方程组画信号流图并用梅森公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由反馈环节等效化简求闭环传函
本卷实例
  • 关键一步：把反馈通道的增益写成负值
  • 中间结果：分母为一加各回路增益之和
  • 卡点：反馈极性取正会多出一个符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由反馈环节等效化简求闭环传函
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路系统的逐层化简
本卷实例
  • 关键一步：先合并内环再算外环
  • 中间结果：三条回路两两接触，特征式无高阶项
  • 卡点：前向通路与回路的接触关系要逐个判
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路系统的逐层化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2二、由响应分量反求传函并求另一系统响应#

思路
  • 由给定阶跃响应的指数项与衰减振荡项对应出闭环极点，写出特征多项式比较系数定参数，再对第二个传函做部分分式分解求阶跃响应
由响应曲线反求传递函数 传递函数
本卷考法
  • 由阶跃响应分量反求闭环特征多项式
本卷实例
  • 关键一步：由各响应分量对应极点写出特征多项式
  • 中间结果：比较系数解出三个时间常数
  • 卡点：分子含一阶微分项会改变各分量权重
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由阶跃响应分量反求闭环特征多项式
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 由极点分布写响应的各模态
本卷实例
  • 关键一步：实极点对应指数项、共轭极点对应衰减振荡项
  • 中间结果：三个极点分别由响应各分量定出
  • 卡点：零点位置影响各模态的系数大小
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过由极点分布写响应的各模态
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 用部分分式分解求单位阶跃响应
本卷实例
  • 关键一步：把闭环传函乘输入拉氏变换后作部分分式
  • 中间结果：各分量系数由留数公式求出
  • 卡点：共轭极点对应的两个系数要互为共轭
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过用部分分式分解求单位阶跃响应
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

3三、平移后劳斯判据判极点分布#

思路
  • 把竖线条件平移变换成对新变量原点的条件，作s等于s1减3的平移后用劳斯表数右半平面根数，反推原系统在指定竖线左侧的极点数
劳斯判据 稳定性分析
本卷考法
  • 用劳斯表判断平移后右半平面极点个数
本卷实例
  • 关键一步：作水平平移把目标竖线变为新虚轴
  • 中间结果：劳斯表首列变号次数即右半平面根数
  • 卡点：平移后各项系数要重新展开不能沿用原式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯表判断平移后右半平面极点个数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式

4四、三阶系统根轨迹绘制#

思路
  • 由开环传函定起点终点、实轴段与渐近线，再求分离点、虚轴交点与复数极点出射角，按法则画根轨迹
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则绘制三阶系统根轨迹
本卷实例
  • 关键一步：先定实轴段与渐近线的夹角和重心
  • 中间结果：三条根轨迹起于三个开环极点终于无穷远
  • 卡点：实轴段判据数的是该段右侧实数零极点个数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则绘制三阶系统根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求实轴上的分离点
本卷实例
  • 关键一步：令特征多项式对增益的导数为零
  • 中间结果：解出两个实根并取落在轨迹段上的
  • 卡点：求出的根要筛掉不在根轨迹上的
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求实轴上的分离点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
出射角与入射角 根轨迹法
本卷考法
  • 求复数极点的出射角
本卷实例
  • 关键一步：累加其余零极点对该极点的相角
  • 中间结果：共轭极点出射角关于实轴对称
  • 卡点：该极点自身的相角不能计入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求复数极点的出射角
  • 求复数极点的出射角
  • 根据出射角画出根轨迹起始方向
  • 由入射角确定根轨迹终止方向
常见易错
  • 累加相角时把该极点自身的相角也算进去
  • 忘记判断象限导致角度差 180°
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界增益
本卷实例
  • 关键一步：令s等于jω代入三阶闭环特征方程
  • 中间结果：临界增益由劳斯表中副对角项乘积给出
  • 卡点：只代一个频率会漏掉对称的另一交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式

5五、闭环幅频最大值与谐振频率#

思路
  • 由闭环传函写出幅频平方表达式，令其对频率的导数为零求谐振频率，再回代求最大幅值
闭环频率特性与性能指标 频域分析
本卷考法
  • 求闭环幅频最大值及其对应频率
本卷实例
  • 关键一步：令幅频平方对频率的导数为零
  • 中间结果：谐振频率由高次方程的有效实根确定
  • 卡点：要排除零根与复数根，只取正实频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过求闭环幅频最大值及其对应频率
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求给定闭环传函的幅频表达式
本卷实例
  • 关键一步：分子取模、分母取模后再相除
  • 中间结果：幅频写成频率的有理分式
  • 卡点：分母实部虚部的位置不能写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

10十、描述函数法适用性与低通滤波#

思路
  • 画三个线性环节的对数幅频特性，比较高频段衰减速度，按描述函数法要求线性部分具有良好低通滤波特性来判定哪个系统分析更准
描述函数法基础 非线性系统
本卷考法
  • 说明描述函数法的适用条件与低通滤波假设
本卷实例
  • 关键一步：比较三个线性部分高频段衰减斜率
  • 中间结果：高频衰减越快低通滤波特性越好
  • 卡点：描述函数法只取一次谐波，高次谐波须被滤掉
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式

  • 与线性部分特性联立判断自振

  • 指出描述函数与频率特性的区别
