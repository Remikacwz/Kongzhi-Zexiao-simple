1一、微分方程组建模与结构图#

思路
  • 由六个微分方程按变量因果顺序画结构图，再用比较点与引出点移动化简，最后由梅森公式求闭环传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 由微分方程组画结构图并用梅森公式求传函
本卷实例
  • 关键一步：把六个方程按变量关系连成节点与支路
  • 中间结果：特征式含五个两两接触的回路
  • 卡点：五条回路均与前向通路接触，余子式取1
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由微分方程组画结构图并用梅森公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
比较点与引出点的移动 结构图与方框图
本卷考法
  • 用比较点与引出点移动化简结构图
本卷实例
  • 关键一步：把方程中的和式对应到比较点位置
  • 中间结果：每个方程对应一个单环节支路
  • 卡点：移动引出点时乘除的补偿因子易漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过用比较点与引出点移动化简结构图
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简求闭环传函
本卷实例
  • 关键一步：先合并并联支路再消去内环
  • 中间结果：分母为一减各回路增益之和
  • 卡点：多条回路不完全独立时不能简单相加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2二、时域指标与正弦扰动稳态误差#

思路
  • 由结构图写开环与闭环传函，化为标准二阶求超调量与调节时间，再按叠加原理分别求给定与正弦扰动引起的稳态误差
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由闭环传函求超调量、调节时间与峰值时间
本卷实例
  • 关键一步：化为标准二阶后读阻尼比与自然频率
  • 中间结果：由阻尼比与自然频率套三个指标公式
  • 卡点：调节时间的误差带系数与峰值时间别混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由闭环传函求超调量、调节时间与峰值时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为标准二阶形式
本卷实例
  • 关键一步：把二次项系数归一后比较各项系数
  • 中间结果：自然频率的平方等于常数项
  • 卡点：开环增益不能直接当闭环传函系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为标准二阶形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求阶跃输入下的稳态误差
本卷实例
  • 关键一步：先判断系统型别再求静态误差系数
  • 中间结果：阶跃误差由位置误差系数决定
  • 卡点：不能未判稳就直接用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求阶跃输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求正弦扰动作用下稳态误差的幅值与相位
本卷实例
  • 关键一步：写扰动误差传函并代入频率为3的正弦点
  • 中间结果：误差为与扰动同频的正弦量
  • 卡点：正弦误差不能用终值定理直接求
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求正弦扰动作用下稳态误差的幅值与相位
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

3三、根轨迹分离点公式证明#

思路
  • 由闭环特征方程在重根处同时为零与一阶导数为零，两边取对数后求导，推出分离点处极零点倒数和相等
分离点与会合点 根轨迹法
本卷考法
  • 证明根轨迹分离点满足的倒数和公式
本卷实例
  • 关键一步：重根处令特征方程与其一阶导数同时为零
  • 中间结果：对特征多项式取对数后再求导
  • 卡点：重根条件必须同时用两个方程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过证明根轨迹分离点满足的倒数和公式
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 说明分离点仍须满足根轨迹的幅值与相角条件
本卷实例
  • 关键一步：分离点也是根轨迹上的点即满足两个基本条件
  • 中间结果：参数取极值时对应重根
  • 卡点：只用一个条件会得到必要不充分的结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过说明分离点仍须满足根轨迹的幅值与相角条件
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画四阶系统根轨迹
本卷实例
  • 关键一步：先定实轴段、渐近线与复数极点出射角
  • 中间结果：渐近线与实轴交点由开环零极点重心确定
  • 卡点：复数极点出射角要逐项累加各相角
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画四阶系统根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及稳定参数范围
本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

通用考法
  • 本卷考过求根轨迹与虚轴交点及稳定参数范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由输出无衰减振荡定闭环传函
本卷实例
  • 关键一步：无振荡要求特征根均为负实数
  • 中间结果：重根出现在分离点对应的参数取值处
  • 卡点：分离点参数要回代开环传函再写闭环
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
