1一、信号流图与多输入传递函数#

思路
  • 由六个微分方程定各变量的因果关系，画结构框图或信号流图，用梅森公式分别求参考输入与两个扰动输入的传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 由微分方程组画信号流图并用梅森公式求传函
本卷实例
  • 关键一步：按变量因果顺序把六个方程连成节点与支路
  • 中间结果：特征式由一个前向通路与两个回路叠加
  • 卡点：回路均与前向通路接触，余子式取为1
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由微分方程组画信号流图并用梅森公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 先画结构框图再用等效化简求闭环传函
本卷实例
  • 关键一步：按串联相乘、反馈取一加回路增益逐层合并
  • 中间结果：三条通道共用同一特征式分母
  • 卡点：反馈极性决定分母取加还是取减
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过先画结构框图再用等效化简求闭环传函
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求参考输入与两个扰动输入的传函
本卷实例
  • 关键一步：求某通道时把其余输入置零再算
  • 中间结果：参考输入与第一扰动的分子传函相同
  • 卡点：第二扰动的前向通路带负号，易漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求参考输入与两个扰动输入的传函
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

2二、由阶跃响应曲线求开环传递函数#

思路
  • 由二阶系统单位阶跃响应曲线的稳态值与峰值读出增益与阻尼比，再由峰值时间联立求出自然频率，反求两个时间常数
由响应曲线反求传递函数 传递函数
本卷考法
  • 由实验阶跃响应曲线求开环传函及参数
本卷实例
  • 关键一步：由曲线读稳态值与超调量
  • 中间结果：先由稳态值之比定开环增益
  • 卡点：须先确认为单位负反馈二阶系统
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由实验阶跃响应曲线求开环传函及参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间反求阻尼比与自然频率
本卷实例
  • 关键一步：用超调量公式与峰值时间公式联立
  • 中间结果：解出阻尼比与自然频率
  • 卡点：超调量公式中指数与百分比别写混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与峰值时间反求阻尼比与自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环特征方程化为标准二阶形式
本卷实例
  • 关键一步：比较两时间常数之和与积的对应关系
  • 中间结果：两时间常数由根之和与根之积确定
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环特征方程化为标准二阶形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

3三、劳斯与赫尔维茨求稳定域及垂线左根#

思路
  • 由开环传函写三阶闭环特征方程，用赫尔维茨判据求稳定参数范围，令纯虚根求等幅振荡点，再作平移变换求根位于指定垂线左侧的条件
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求使系统稳定的参数范围
本卷实例
  • 关键一步：列劳斯表并令首列前两元均大于零
  • 中间结果：稳定条件化为一元一次不等式
  • 卡点：系数无缺项仍要逐项检查首列
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求使系统稳定的参数范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求等幅振荡点及根位于垂线左侧的参数范围
本卷实例
  • 关键一步：令s等于jω代入特征方程分离实部虚部
  • 中间结果：纯虚根对应临界参数值
  • 卡点：平移变换后一次项与常数项都要改
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求等幅振荡点及根位于垂线左侧的参数范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
赫尔维茨判据 稳定性分析
本卷考法
  • 用三阶赫尔维茨判据替代劳斯表判断稳定
本卷实例
  • 关键一步：写出二阶与三阶主子式并令其大于零
  • 中间结果：两个不等式取交集得参数区间
  • 卡点：只验部分主子式会漏约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由特征方程系数构造赫尔维茨行列式
  • 各阶主子式全部大于零 ⇔ 系统稳定
  • 与劳斯判据等价，适合阶数较低时使用
步骤
  • 由特征方程系数写出赫尔维茨行列式
  • 依次计算各阶主子式
  • 令全部主子式大于零得到稳定条件
通用考法
  • 本卷考过用三阶赫尔维茨判据替代劳斯表判断稳定
  • 用赫尔维茨判据判断稳定性
  • 比较两种代数判据的适用场合
常见易错
  • 行列式构造时系数下标写错
  • 只验证到二阶主子式就下结论
公式

4四、零度根轨迹与圆轨迹证明#

思路
  • 由方框图写开环传函，识别右半平面零点引起的零度根轨迹，按法则画轨迹、求分离点，用相角条件证明轨迹为圆并求稳定参数范围
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 画含右半平面零点的零度根轨迹
本卷实例
  • 关键一步：先把开环传函整理成含参数的等效形式
  • 中间结果：开环零点在右半平面使轨迹为零度型
  • 卡点：零度根轨迹用0度相角条件不是180度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过画含右半平面零点的零度根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则定实轴段与渐近线
本卷实例
  • 关键一步：按实轴段右侧实数零极点个数判归属
  • 中间结果：实轴轨迹段为两个区间
  • 卡点：渐近线重心与夹角的符号易取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则定实轴段与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求分离点坐标并筛除无效解
本卷实例
  • 关键一步：令闭环特征方程对参数求导为零
  • 中间结果：分离点方程解出两个实根
  • 卡点：须回代检验哪个根落在轨迹段上
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求分离点坐标并筛除无效解
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由虚轴交点求临界参数与稳定范围
本卷实例
  • 关键一步：令s等于jω代入闭环特征方程
  • 中间结果：临界增益对应轨迹穿轴点
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法

思路
  • 由非线性结构图写等效线性部分，画负倒描述函数与线性部分幅相曲线，由两曲线相交求自振条件、振幅与频率
描述函数法基础 非线性系统
本卷考法
  • 求给定非线性环节的负倒描述函数
本卷实例
  • 关键一步：把描述函数取倒数化成便于判单调的形式
  • 中间结果：负倒描述函数是实变量A的实函数
  • 卡点：要画负倒描述函数而不是描述函数本身
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式

  • 与线性部分特性联立判断自振
通用考法

  • 忽略一次谐波近似带来的误差条件
