1一、信号流图与梅森公式#

思路
  • 由系统结构图先画信号流图，标出各回路与前向通路，再用梅森公式求误差传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图先画信号流图再用梅森公式求传递函数
本卷实例
  • 关键一步：逐个环节确定节点与支路，标出全部回路
  • 中间结果：回路增益、前向通路增益与余子式分别列出
  • 卡点：不接触回路要单独成项，别漏乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图先画信号流图再用梅森公式求传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图的逐层化简与交叉反馈处理
本卷实例
  • 关键一步：先理清各反馈环的嵌套关系再逐层化简
  • 中间结果：内环化简结果作为外环的一个环节代入
  • 卡点：结构图以图给出，回路条数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图的逐层化简与交叉反馈处理
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2二、含纯延迟根轨迹与稳定范围#

思路
  • 含纯延迟的开环先用一阶惯性近似，再按根轨迹法则绘制并求与虚轴交点
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画含延迟近似后的根轨迹草图
本卷实例
  • 关键一步：写出等效开环的零极点并判断实轴根轨迹段
  • 中间结果：确定渐近线条数、夹角与分离点后画大致走向
  • 卡点：实轴段判据数的是该段右侧实数零极点个数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画含延迟近似后的根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及使系统稳定的临界增益
本卷实例
  • 关键一步：把s=jw代入闭环特征方程并分离实部虚部
  • 中间结果：由实部虚部同时为零解出交点频率与临界增益
  • 卡点：解出后要回到原题核对K与K星的定义差异
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及使系统稳定的临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
含纯延迟环节的系统稳定性 稳定性分析
本卷考法
  • 纯延迟环节近似后对系统稳定范围的影响
本卷实例
  • 关键一步：把指数延迟用一阶惯性环节近似再作分析
  • 中间结果：近似阶次越高根轨迹越接近真实延迟系统
  • 卡点：近似式只在低频段可信，高频结论需谨慎
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 延迟环节 e^{-τs} 的幅值为 1、相位为 -τω，只恶化相位
  • 延迟会显著缩小稳定域，τ 越大越难稳定
  • 频域判据需用相位裕度扣除延迟引起的附加滞后
步骤
  • 写出含延迟的开环传递函数
  • 分别求幅值与相位表达式
  • 在相频特性中扣除 τω 的滞后量
  • 按稳定裕度或奈氏判据求临界 τ 或临界 K
通用考法
  • 本卷考过纯延迟环节近似后对系统稳定范围的影响
  • 求使系统稳定的最大延迟时间
  • 求含延迟系统的临界开环增益
  • 分析延迟对稳定裕度的影响
常见易错
  • 把延迟环节当成惯性环节处理
  • 相位计算时忘记角度与弧度换算
公式

3三、由阶跃响应求正弦稳态输出#

思路
  • 把给定的非零初始条件阶跃响应分离出零状态部分，反求传函后再求正弦输入的稳态输出
由响应曲线反求传递函数 传递函数
本卷考法
  • 由阶跃响应表达式反求系统的传递函数
本卷实例
  • 关键一步：对阶跃响应作拉氏变换并与标准二阶形式比较
  • 中间结果：由响应系数确定自然频率、阻尼比与增益
  • 卡点：非零初始条件使响应含自由分量，需先分离零状态部分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由阶跃响应表达式反求系统的传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由传递函数求正弦输入的稳态输出幅值与相角
本卷实例
  • 关键一步：把s=jw代入传函分别求幅频与相频
  • 中间结果：稳态输出幅值为输入幅值乘幅频，相角叠加相频
  • 卡点：输入含初相时相角要一并累加，别只算幅值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由传递函数求正弦输入的稳态输出幅值与相角
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式

4四、二阶系统动态性能与稳态误差#

思路
  • 由结构图写闭环传函并化为标准二阶，按定义求动态指标与斜坡稳态误差
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由闭环标准二阶参数求超调量与调节时间
本卷实例
  • 关键一步：先把闭环传函化为标准二阶形式提取阻尼比
  • 中间结果：再由阻尼比算出超调量与指定误差带的调节时间
  • 卡点：两种误差带的调节时间系数不同，别混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由闭环标准二阶参数求超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由给定阻尼比反求反馈通道的待定参数
本卷实例
  • 关键一步：比较标准二阶的一次项系数建立方程
  • 中间结果：由阻尼比方程解出待定参数b
  • 卡点：反馈参数出现在一次项，别误配到常数项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由给定阻尼比反求反馈通道的待定参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡输入下闭环系统的稳态误差
本卷实例
  • 关键一步：先判断系统型别与开环增益再套稳态误差公式
  • 中间结果：误差系数由开环传函的低频段结构决定
  • 卡点：未判稳就使用终值定理会得到无意义结果
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位斜坡输入下闭环系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

5五、闭环主导极点与动态指标#

思路
  • 由给定闭环极点代入特征方程求开环增益，再用主导极点对估算超调与调节时间
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 判断给定闭环极点能否作为主导极点并估算性能
本卷实例
  • 关键一步：比较各闭环极点到虚轴的距离与留数大小
  • 中间结果：主导极点对决定响应主模态，其余极点影响较小
  • 卡点：第三个极点距虚轴不够远时不能简单忽略
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过判断给定闭环极点能否作为主导极点并估算性能
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
零极点分布与响应模态 传递函数
本卷考法
  • 由闭环极点位置写出响应的大致模态
本卷实例
  • 关键一步：由极点实部判断收敛快慢，虚部判断振荡
  • 中间结果：极点对对应二阶振荡模态，实极点对应单调模态
  • 卡点：零点位置会改变各模态权重，不能只看极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由闭环极点位置写出响应的大致模态
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
