1一、信号流图与梅森公式#

思路
  • 由系统结构图先画出信号流图，标注各支路增益与独立回路，再用梅森增益公式求闭环传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 由控制系统图求信号流图并用梅森公式求闭环传函
本卷实例
  • 关键一步：先把方框图的环节与汇点改画成信号流图的节点与有向支路
  • 中间结果：特征式按独立回路及两两不接触回路逐层累加
  • 卡点：方框图未读图，回路条数与比较点引出支路需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由控制系统图求信号流图并用梅森公式求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

3三、由阶跃响应反求模型与时域指标#

思路
  • 先由单位阶跃响应反求开环传递函数并写出闭环传函，再用终值定理求斜坡输入下的稳态输出与稳态误差，最后用闭环主导极点估计调节时间
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应反求开环传函G0(s)
本卷实例
  • 关键一步：对阶跃响应作拉普拉斯变换，再除以输入的1/s得到G0
  • 中间结果：响应中的指数衰减项对应一阶惯性环节的极点
  • 卡点：逐年OCR把指数衰减系数读成5，宝典印2.5，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应反求开环传函G0(s)
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡输入下的稳态输出与稳态误差
本卷实例
  • 关键一步：用终值定理求误差传函乘输入后s趋于零的极限
  • 中间结果：系统型别决定斜坡误差是有限值还是无穷
  • 卡点：用终值定理前需先确认闭环系统稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求斜坡输入下的稳态输出与稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 由已知闭环根用主导极点估计调节时间
本卷实例
  • 关键一步：由已知闭环根分解闭环特征多项式，找出主导复极点对
  • 中间结果：远离虚轴的实极点可与邻近零点近似构成偶极子
  • 卡点：降阶前需确认被略去的极点确实次要
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过由已知闭环根用主导极点估计调节时间
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 按5%误差带用二阶近似式估计调节时间
本卷实例
  • 关键一步：取主导极点实部的绝对值作为衰减系数
  • 中间结果：调节时间与主导极点实部绝对值成反比
  • 卡点：不同误差带的公式常数不同，需按题给误差带选取
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过按5%误差带用二阶近似式估计调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

5五、奈奎斯特判据与稳定域#

思路
  • 由开环传递函数写出幅频与相频特性，画奈奎斯特曲线并求与负实轴的交点，再按判据由穿越条件列出使闭环稳定的增益范围
频率特性的物理意义与求法 频域分析
本卷考法
  • 由开环传函求幅频与相频表达式
本卷实例
  • 关键一步：把传递函数中的s替换为jω再按模与相角分解
  • 中间结果：各因式的模相乘除、相角相加减
  • 卡点：分母各环节的模需全部保留，不能只写积分环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由开环传函求幅频与相频表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据求使系统稳定的k范围
本卷实例
  • 关键一步：令s等于jω代入开环传函，找相角为负180度的频率
  • 中间结果：曲线与负实轴交点对应临界穿越条件
  • 卡点：开环含虚轴极点时需补画无穷大圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据求使系统稳定的k范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 把奈奎斯特穿越条件化成k的稳定区间
本卷实例
  • 关键一步：由负实轴交点坐标列出增益的临界不等式
  • 中间结果：开环无右半平面极点时临界点须位于负一之右
  • 卡点：区间端点处系统临界稳定，需说明开闭
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过把奈奎斯特穿越条件化成k的稳定区间
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

6六、滞后校正与Bode图#

思路
  • 按校正后截止频率要求确定滞后校正装置的参数，写出校正后开环传递函数，再分别绘制校正前后的渐近对数幅频特性并求校正前截止频率
滞后校正 系统校正
本卷考法
  • 确定滞后校正装置Gc(s)并写出校正后开环传函
本卷实例
  • 关键一步：按校正后截止频率要求反推校正装置的零极点与增益
  • 中间结果：滞后校正的零点转折频率高于极点转折频率
  • 卡点：校正装置图像未读图，转折频率需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过确定滞后校正装置Gc(s)并写出校正后开环传函
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 分别绘制校正前后的开环对数幅频特性
本卷实例
  • 关键一步：按各环节转折频率从小到大排列，逐段叠加斜率
  • 中间结果：低频段斜率由积分环节个数决定
  • 卡点：校正前后转折频率不同，需分别列写
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过分别绘制校正前后的开环对数幅频特性
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
稳定裕度 频域分析
本卷考法
  • 求校正前的截止频率ωc0
本卷实例
  • 关键一步：令校正前幅频特性等于1，反求对应频率
  • 中间结果：截止频率落在哪一段决定采用哪段渐近线
  • 卡点：需先判断截止频率所在频段再列方程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求校正前的截止频率ωc0
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

7七、离散系统脉冲传函与稳定域#

思路
  • 按零阶保持器的采样结构求广义被控对象的z变换，写出闭环脉冲传递函数，再由闭环特征方程根在单位圆内的条件求稳定k范围
连续系统的离散化 离散控制系统
本卷考法
  • 含零阶保持器的连续部分离散化
本卷实例
  • 关键一步：把连续传函乘零阶保持器后一起作z变换
  • 中间结果：零阶保持器对应z域的一个一减z负一次方因子
  • 卡点：采样开关位置影响连续部分能否先合并再离散
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
