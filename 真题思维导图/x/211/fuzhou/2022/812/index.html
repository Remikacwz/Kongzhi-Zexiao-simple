1一、多回路信号流图与梅森公式#

思路
  • 由多回路结构图先画信号流图，找出三条回路与两条前向通路再用梅森公式求传函
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图用梅森公式求闭环传递函数
本卷实例
  • 关键一步：分别列出三条回路增益与各前向通路增益
  • 中间结果：两两不接触回路只取其中一组，代入特征式
  • 卡点：不接触回路的乘积项容易漏写或重复
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图用梅森公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 含多条交错反馈回路的系统逐层化简
本卷实例
  • 关键一步：先按嵌套层次把交错回路拆开再分别化简
  • 中间结果：内层回路增益作为整体参与外层化简
  • 卡点：结构图以图给出，回路连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过含多条交错反馈回路的系统逐层化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2二、三阶系统稳定性与动态响应#

思路
  • 由结构图求开环传函列劳斯表判稳，再由闭环极点求输出响应、稳态误差与调节时间
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求使三阶系统稳定的反馈参数范围
本卷实例
  • 关键一步：由结构图写开环传函再列闭环特征方程
  • 中间结果：劳斯表首列两式同号给出参数下界
  • 卡点：三阶系统还要检查常数项非零这个隐含条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求使三阶系统稳定的反馈参数范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 由闭环极点分布用主导极点法估算调节时间
本卷实例
  • 关键一步：比较各极点距虚轴距离找出主导极点对
  • 中间结果：把闭环传函写成主导极点对与剩余极点之积
  • 卡点：相距不足五倍时忽略远极点会带来较大误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过由闭环极点分布用主导极点法估算调节时间
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位阶跃输入下高阶系统的稳态误差
本卷实例
  • 关键一步：先由闭环传函求稳态值再与输入幅值相减
  • 中间结果：稳态误差由终值定理求极限得到
  • 卡点：终值定理使用前必须先确认系统稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位阶跃输入下高阶系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

3三、极点配置与扰动误差不变性#

思路
  • 由期望极点写期望特征多项式并比较系数定K、T，再分别令参考与扰动误差传函为零设计补偿环节
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由期望闭环极点反求结构图中的待定参数
本卷实例
  • 关键一步：把期望极点写成二次因式与闭环特征式比较系数
  • 中间结果：由一次项与常数项对应关系解出两个待定参数
  • 卡点：比较系数时别把回路增益写成闭环增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由期望闭环极点反求结构图中的待定参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求参考输入与扰动分别作用下的传递函数
本卷实例
  • 关键一步：求扰动传函时把参考输入置零
  • 中间结果：两个输入的输出可分别求出后再叠加
  • 卡点：不能默认两路输入可直接叠加而不说明线性条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求参考输入与扰动分别作用下的传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 通过设计前向通道使扰动稳态误差恒为零
本卷实例
  • 关键一步：写出扰动误差传函并令其分子为零
  • 中间结果：由分子为零反解出补偿环节的传递函数
  • 卡点：求得的补偿环节要检查是否物理可实现
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过通过设计前向通道使扰动稳态误差恒为零
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

5五、参数根轨迹与系统降阶#

思路
  • 把含待定参数的特征方程整理成参数根轨迹形式，画根轨迹求分离点，再由指定实部闭环极点降阶
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以含参数的项为根轨迹增益绘制参数根轨迹
本卷实例
  • 关键一步：把参数项完整提到分子位置写出等效开环
  • 中间结果：有效开环零点与极点决定根轨迹形状
  • 卡点：参数根轨迹仍用180度相角条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以含参数的项为根轨迹增益绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画三阶系统的参数根轨迹草图
本卷实例
  • 关键一步：先定实轴上根轨迹段与渐近线
  • 中间结果：分离点由等效开环对参数求导得到
  • 卡点：求出分离点后要筛掉不在根轨迹上的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画三阶系统的参数根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
高阶系统的降阶与主导极点 时域响应与动态性能

6六、频率指标反求参数与正弦稳态输出#

思路
  • 由相角裕度与截止频率条件联立求K、T，再代入频率特性求正弦输入的稳态输出
稳定裕度 频域分析
本卷考法
  • 由相角裕度与截止频率条件反求开环参数
本卷实例
  • 关键一步：在截止频率处幅值等于一、相角裕度等于给定值

  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈氏判据求使闭环稳定的增益范围

常见易错

  • 把包围圈数的正负号定义搞反
