1一、结构图求闭环与误差传递函数#

思路
  • 按比较点与反馈通道逐层化简结构图，分别由输出节点与误差节点写闭环传函和误差传函。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由多回路结构图求闭环传递函数
本卷实例
  • 关键一步：先化简内环再用外环反馈关系
  • 中间结果：闭环分母为 1 加开环回路增益
  • 卡点：题1图为原卷插图，回路走向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由多回路结构图求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 逐层化简含局部反馈的多回路系统
本卷实例
  • 关键一步：把比较点与引出点按移动规则重组再合并
  • 中间结果：化简后得到单一前向通道与反馈通道
  • 卡点：化简内环时把外环信号当成常数处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过逐层化简含局部反馈的多回路系统
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
误差定义与误差传递函数 稳态误差
本卷考法
  • 写误差节点到输入的误差传递函数
本卷实例
  • 关键一步：从误差节点沿前向与反馈通道写 E 对 R 的关系
  • 中间结果：误差传函的分母与闭环传函相同
  • 卡点：非单位反馈时两种误差定义混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写误差节点到输入的误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)

2二、由非零初值阶跃响应反求传递函数15 分#

思路
  • 把给定响应分解为零输入与零状态两部分，由初值定自由响应系数，再对应阶跃输入写出传递函数。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由非零初值下的阶跃响应反求系统传递函数
本卷实例
  • 关键一步：先由响应及其导数在零时刻的值定初值系数
  • 中间结果：扣除零输入分量后得到零状态阶跃响应
  • 卡点：未判断系统阶数就直接套用二阶公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由非零初值下的阶跃响应反求系统传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 把全响应分解为零输入响应与零状态响应
本卷实例
  • 关键一步：由解的结构写出自由项与强迫项
  • 中间结果：初值条件用来确定两个待定系数
  • 卡点：只求零状态响应而漏掉初值决定的自由响应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过把全响应分解为零输入响应与零状态响应
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

3三、以时间常数为变量的参数根轨迹15 分#

思路
  • 把含 T 的特征方程整理成 1 加 T 倍等效开环等于零，按参数根轨迹法则画 T 从零到无穷的轨迹并判稳。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以时间常数为变量绘制参数根轨迹
本卷实例
  • 关键一步：把含 T 的项整体提出来构造等效开环
  • 中间结果：等效开环的极点零点由原系统系数决定
  • 卡点：整理时参数没有完整提到分子就套法则
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以时间常数为变量绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按实轴段与渐近线法则绘制参数根轨迹草图
本卷实例
  • 关键一步：由等效开环零极点定实轴轨迹与渐近线
  • 中间结果：轨迹随 T 增大从一个极点出发趋向零点
  • 卡点：实轴段判据中的零极点个数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按实轴段与渐近线法则绘制参数根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点判断参数变化下的稳定性
本卷实例
  • 关键一步：令特征方程实部虚部同时为零求交点
  • 中间结果：交点处对应 T 的临界值划分稳定区间
  • 卡点：得到临界值后没有回原题核对参数定义
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹与虚轴交点判断参数变化下的稳定性
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

4四、非最小相位系统的奈奎斯特判据#

思路
  • 把开环传函代 s 等于 jω 写幅相表达式，画完整幅相曲线并补画无穷大圆弧，再按包围次数判稳。
频率特性的物理意义与求法 频域分析
本卷考法
  • 求非最小相位系统的幅频与相频表达式
本卷实例
  • 关键一步：分子含负号项时分段讨论相角变化
  • 中间结果：幅相曲线起终点由分子分母阶数决定
  • 卡点：相角累加时漏掉右半平面零点的影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求非最小相位系统的幅频与相频表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由幅相曲线包围原点的次数判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数 P 再求包围圈数 N
  • 中间结果：闭环稳定要求 Z 等于 P 减 2N 为零
  • 卡点：把包围圈数的正负号定义搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由幅相曲线包围原点的次数判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式

5五、零阶保持器离散系统的双域稳定性分析15 分#

思路
  • 先由连续部分与零阶保持器求脉冲传函，在 z 平面用模小于 1、在 w 平面用劳斯判据分析稳定性并求 K 范围。
采样过程与香农采样定理 离散控制系统
本卷考法
  • 由连续传函与零阶保持器求脉冲传递函数
本卷实例
  • 关键一步：把零阶保持器与连续部分合并后作 z 变换
  • 中间结果：脉冲传函分母含 z 减 1 与 z 减指数项
  • 卡点：忽略零阶保持器带来的相位滞后
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过由连续传函与零阶保持器求脉冲传递函数
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后
公式
离散系统稳定性分析 离散控制系统
本卷考法
  • 分别在 z 域与 w 域判断离散系统稳定性
本卷实例
  • 关键一步：z 域看特征根是否在单位圆内，w 域作双线性变换后列劳斯表
  • 中间结果：两种判据应给出同一稳定 K 范围
  • 卡点：w 变换公式记错导致映射关系颠倒
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
