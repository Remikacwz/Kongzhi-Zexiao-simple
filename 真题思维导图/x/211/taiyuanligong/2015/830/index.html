1一、弹簧质量系统的运动方程与传函20 分#

思路
  • 对两质量块分别列牛顿第二定律方程，拉氏变换后联立消去中间位移，解出位移对外力的传递函数。
机械系统建模 建模与机电系统
本卷考法
  • 对含两质量块与两弹簧的平动系统列力平衡方程
本卷实例
  • 关键一步：按弹簧力实际方向分别对两质量块列牛二方程
  • 中间结果：两方程含两个位移未知量，必须联立才能消元
  • 卡点：题1图为原卷插图，弹簧串接方式需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过对含两质量块与两弹簧的平动系统列力平衡方程
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项

本卷实例

  • 中间结果：传函分母为含m1m2的四次多项式，分子为k1
  • 卡点：弹簧力与阻尼力的正负方向取反会使耦合项出错

  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律

  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程

通用考法
  • 本卷考过由机械系统微分方程求位移对力的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错

2二、由速度响应反求传函与动态指标20 分#

思路
  • 由单位速度响应反求闭环传函，化为标准二阶形式读阻尼比与自然频率，再算上升时间与超调量。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位速度响应反求系统传递函数
本卷实例
  • 关键一步：对速度响应取拉氏变换后除以斜坡输入的1/s平方
  • 中间结果：闭环传函化为(3s+2)/((s+1)(s+2))的形式
  • 卡点：忽略零初始条件前提会把初值带进变换结果
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位速度响应反求系统传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征式读出自然频率与阻尼比
本卷实例
  • 关键一步：把分母与标准二阶形式逐项比较系数
  • 中间结果：一次项系数对应2倍阻尼比乘自然频率
  • 卡点：二次项系数未归一化就套标准形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征式读出自然频率与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率计算上升时间与超调量
本卷实例
  • 关键一步：先判阻尼比大于1为过阻尼，再按相应公式求上升时间
  • 中间结果：过阻尼时超调量为零，上升时间用近似公式
  • 卡点：峰值时间与上升时间的公式容易混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率计算上升时间与超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3三、由闭环传函反求开环的奈氏判稳20 分#

思路
  • 由单位反馈关系由闭环传函反求开环传函，写幅频相频并按a与b相对大小分段画奈氏曲线判稳。
传递函数的定义与基本性质 传递函数
本卷考法
  • 由闭环传函与单位反馈关系反求开环传函
本卷实例
  • 关键一步：用开环等于闭环除以(1减闭环)由闭环反推开环
  • 中间结果：开环整理成k(1+bs)/[s平方(1+as)]形式
  • 卡点：分母1减闭环的符号写反会得到错误开环
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由闭环传函与单位反馈关系反求开环传函
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求开环传函的幅频与相频表达式
本卷实例
  • 关键一步：分子分母各环节取模相乘、相角相加
  • 中间结果：低频幅值趋于无穷，相角起点随a、b大小而变
  • 卡点：相角累加时漏掉积分环节对应的负180度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求开环传函的幅频与相频表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由幅相曲线在不同a、b区间判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数，再看曲线包围情况
  • 中间结果：相角先减后增与先增后减对应两种包围情况
  • 卡点：开环含积分环节时未补画无穷大半径圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由幅相曲线在不同a、b区间判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式

4四、饱和非线性系统的描述函数分析20 分#

思路
  • 对线性部分与饱和非线性描述函数联立，用负倒描述函数曲线与奈氏曲线交点判断稳定性并求自振。
描述函数法基础 非线性系统
本卷考法
  • 由饱和非线性环节写出其描述函数
本卷实例
  • 关键一步：写出饱和特性的描述函数并整理成标准形式
  • 中间结果：A等于a时负倒描述函数取端点值，A趋于无穷时趋于负无穷
  • 卡点：把描述函数当成频率的函数来处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过由饱和非线性环节写出其描述函数
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件
公式
用描述函数法分析自振 非线性系统
本卷考法
  • 由线性部分与负倒描述函数交点求自振
本卷实例
  • 关键一步：令线性部分幅值与负倒描述函数相等联立求交点
  • 中间结果：先由相角负180度定出线性部分的穿越频率
  • 卡点：画的是描述函数本身而不是负倒描述函数
  • 卡点：题4图为原卷插图，非线性环节接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过由线性部分与负倒描述函数交点求自振
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率

5五、无阻尼与前馈校正设计20 分#

思路
  • 由结构图列特征方程，用劳斯判据求临界增益使系统无阻尼，再由斜坡无差条件反解前馈校正装置。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求系统稳定范围与临界增益
本卷实例
  • 关键一步：列劳斯表并令首列元素都大于零求增益范围
  • 中间结果：落在稳定边界上的增益使系统有一对纯虚根
  • 卡点：只列部分首列元素的不等式会漏掉约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求系统稳定范围与临界增益
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 设计前馈补偿器实现斜坡输入无稳态误差
本卷实例
  • 关键一步：由误差传函写成前向通路形式再令稳态误差为零
  • 中间结果：无差条件化为前馈传函与开环参数的关系式
  • 卡点：只盯误差减小而不检查稳定性是否被破坏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计前馈补偿器实现斜坡输入无稳态误差
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
