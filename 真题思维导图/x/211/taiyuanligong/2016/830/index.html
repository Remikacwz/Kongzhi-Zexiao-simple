1一、结构图化简与信号流图求传函#

思路
  • 先用串联、并联与反馈规则逐层化简结构图求传函，再画信号流图用梅逊公式独立验证。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图化简求闭环传递函数
本卷实例
  • 关键一步：按串联、并联、反馈三种连接逐层等效化简
  • 中间结果：化简结果含前向通道与各回路的组合项
  • 卡点：负反馈的分母写成1减积会把符号弄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由结构图化简求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
比较点与引出点的移动 结构图与方框图
本卷考法
  • 化简含交叉比较点的结构图
本卷实例
  • 关键一步：把交叉的比较点或引出点按规则移动后再化简
  • 中间结果：移动比较点会引入环节的乘除补偿因子
  • 卡点：移动方向与乘除关系容易搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过化简含交叉比较点的结构图
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
梅森增益公式与信号流图 传递函数
本卷考法
  • 画信号流图并用梅逊公式求传函
本卷实例
  • 关键一步：由结构图标出全部独立回路与前向通路
  • 中间结果：各回路互不接触，特征式只需累加各回路增益
  • 卡点：不接触回路找漏或重复计数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过画信号流图并用梅逊公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、高阶系统降阶与稳态误差#

思路
  • 由闭环特征方程求三根，用主导极点把系统降为二阶估算指标，再判稳并算速度输入下的稳态误差。
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 用主导极点把三阶系统降为二阶
本卷实例
  • 关键一步：比较非主导极点与主导极点的实部距离判断能否忽略
  • 中间结果：三根中一对复根主导，另一实根远离虚轴可忽略
  • 卡点：忽略非主导极点时未验证其距离足够远
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过用主导极点把三阶系统降为二阶
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由等效二阶参数估算超调量与调整时间
本卷实例
  • 关键一步：由主导极点的实部与虚部反算阻尼比和自然频率
  • 中间结果：超调量只由阻尼比决定，调整时间与实部成反比
  • 卡点：两种误差带的调整时间系数容易混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由等效二阶参数估算超调量与调整时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位速度输入下的稳态误差
本卷实例
  • 关键一步：先判闭环稳定再用速度误差系数求误差
  • 中间结果：速度误差系数等于开环传函去掉积分环节的直流增益
  • 卡点：未判稳就使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位速度输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、正反馈根轨迹与圆形证明#

思路
  • 由开环传函提出负号判定为正反馈零度根轨迹，按法则画轨迹并令特征根s=-a+jb证明为圆。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 判定并绘制正反馈系统的零度根轨迹
本卷实例
  • 关键一步：把开环传函提负号化为正反馈形式再按零度条件画
  • 中间结果：系统实际为正反馈，对应零度根轨迹而非180度
  • 卡点：零度根轨迹仍沿用180度相角条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过判定并绘制正反馈系统的零度根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 画实轴段、分离点与虚轴交点
本卷实例
  • 关键一步：由零极点分布画实轴段并求分离点方程
  • 中间结果：分离点方程为一元二次，解出两个分离点
  • 卡点：实轴段判据中的零极点个数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过画实轴段、分离点与虚轴交点
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 由幅相条件证明根轨迹为圆
本卷实例
  • 关键一步：令特征方程中的s取负a加jb并令实部虚部都为零
  • 中间结果：消去k后得圆方程，圆心与半径随之确定
  • 卡点：令s取负a加jb时实部虚部的符号写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过由幅相条件证明根轨迹为圆
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

4四、由Bode渐近线求传函与相角裕量#

思路
  • 由图(a)(b)的转折频率与低频段高度分别写出开环传函，再由渐近线求截止频率并算相角裕量。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频渐近线反求开环传函
本卷实例
  • 关键一步：由转折频率写各典型环节，由低频段高度定增益
  • 中间结果：两图分别为无积分环节与含一个积分环节的开环
  • 卡点：把延长线交点误当增益值而未折算型别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频渐近线反求开环传函
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 由求得传函计算相角裕量
本卷实例
  • 关键一步：由幅频渐近线求截止频率再代入相频求相角
  • 中间结果：相角裕量等于截止频率处相角加180度
  • 卡点：把截止频率与相位穿越频率两个频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由求得传函计算相角裕量
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

5五、采样系统的脉冲传函与稳定条件#

思路
  • 对含零阶保持器的连续部分求z变换得开环与闭环脉冲传函，由特征根在单位圆内求K、T关系，再由阶跃误差定K。
脉冲传递函数 离散控制系统
本卷考法
  • 求含零阶保持器的开环与闭环脉冲传函
本卷实例
  • 关键一步：对连续部分作部分分式后查z变换表求G(z)
  • 中间结果：开环脉冲传函化为含e的负2T次与K的有理式
  • 卡点：忘记把零阶保持器计入脉冲传递函数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过求含零阶保持器的开环与闭环脉冲传函
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
