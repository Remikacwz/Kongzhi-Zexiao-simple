1一、两级RC电路的结构图与传函20 分#

思路

电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由两级RC滤波网络串联电路求传递函数
本卷实例
  • 关键一步：对每个RC环节列复阻抗下的分压或电流关系
  • 中间结果：两环节串联传函为二阶，分母含耦合项R1C2
  • 卡点：复阻抗法把电容阻抗误写成Cs而非1/(Cs)
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤

  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法

  • 求运算电路的输出表达式
常见易错

  • 把反相输入的负号漏掉

2二、由误差函数反求参数与稳态误差20 分#

思路
  • 对给出的误差函数取拉氏变换并除以阶跃输入得误差传函，比较标准二阶形式求参数，再判稳求稳态误差与动态过程。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由误差函数反求误差传递函数
本卷实例
  • 关键一步：对误差函数取拉氏变换后除以阶跃输入的1/s
  • 中间结果：误差传函化为s(s+4.8)/(s平方+4.8s+4)形式
  • 卡点：把误差传函与闭环传函混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由误差函数反求误差传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由误差传函特征式读出参数并判断阻尼
本卷实例
  • 关键一步：把分母与标准二阶形式逐项比较系数
  • 中间结果：一次项系数对应2ξωn，常数项对应ωn平方
  • 卡点：二次项系数未归一化就套标准形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由误差传函特征式读出参数并判断阻尼
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由稳态误差定义与终值定理求ess
本卷实例
  • 关键一步：先判闭环稳定再用终值定理或直接取时间极限
  • 中间结果：误差函数两个指数项均衰减，稳态误差趋于零
  • 卡点：未判稳就使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由稳态误差定义与终值定理求ess
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、二重极点根轨迹与附加零点影响20 分#

思路
  • 按法则画含原点二重极点的根轨迹并判稳，再加入开环零点z=-a，分a的区间讨论渐近线交点与稳定性。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制含原点二重极点与一实极点的根轨迹
本卷实例
  • 关键一步：标出原点二重极点与负实极点，判实轴段与渐近线
  • 中间结果：渐近线交于负三分之一，夹角为±60度与180度
  • 卡点：原点为二重极点时实轴段判据须按重数计数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制含原点二重极点与一实极点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹判断系统稳定并求虚轴交点
本卷实例
  • 关键一步：由特征方程列劳斯表判断k大于零时有无右半平面根
  • 中间结果：特征式缺常数项，k大于零时系统不稳定
  • 卡点：只代一个ω就下结论，漏掉另一组交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹判断系统稳定并求虚轴交点
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 讨论增加开环零点z=-a对根轨迹的影响
本卷实例
  • 关键一步：分a大于1、等于1、介于0与1、小于0四种区间讨论
  • 中间结果：渐近线交点位置随a移动决定根轨迹是否进入左半平面
  • 卡点：只讨论渐近线位置而忽略分离点变化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过讨论增加开环零点z=-a对根轨迹的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反

4四、六阶系统劳斯判据与特征根20 分#

思路
  • 对六阶特征方程列劳斯表，出现全零行时用辅助方程求导替代，数首列变号次数得右半平面根数，再分解求出全部特征根。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判定右半平面特征根数并求全部根
本卷实例
  • 关键一步：列劳斯表，出现全零行时用辅助方程求导替换该行
  • 关键一步：数首列元素变号次数即为右半平面根的个数
  • 关键一步：对辅助方程与商式因式分解求出其余根
  • 中间结果：首列变号两次，右半平面有两个闭环特征根
  • 卡点：系数有缺项时不补零就直接套用判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判定右半平面特征根数并求全部根
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式

5五、相平面法分析非线性系统20 分#

思路
  • 由系统方程消去时间得相轨迹微分方程，按非线性符号分区积分，画开关线并讨论β不同取值下相轨迹的收敛性。
相平面法 非线性系统
本卷考法
  • 用相平面法画相轨迹并分析奇点
本卷实例
  • 关键一步：由系统方程消去时间得到相轨迹的斜率方程
  • 中间结果：分区积分得抛物线族相轨迹，开关线为斜率含β的直线
  • 卡点：相轨迹斜率公式中分子分母写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过用相平面法画相轨迹并分析奇点
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆
公式
典型非线性特性及其影响 非线性系统
本卷考法
  • 分析继电特性与微分反馈对相轨迹的影响
本卷实例
  • 关键一步：按非线性输出符号分区写两段相轨迹方程
  • 中间结果：β为零时相轨迹闭合，β不为零时相轨迹收敛
  • 卡点：认为饱和或继电特性总使系统更稳定
  • 卡点：题5图非线性环节接法为原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 饱和特性降低等效增益，可能引起系统不稳定或自振
  • 死区特性使小信号时增益为零，产生稳态误差
  • 间隙特性引起相位滞后，导致波形畸变与自振
  • 继电特性使系统出现持续振荡并可能产生颤振
步骤
  • 识别非线性环节类型
  • 写出其描述函数或分段数学表达式
  • 分析其对等效增益与稳定性的影响
通用考法
  • 本卷考过分析继电特性与微分反馈对相轨迹的影响
  • 分析饱和或死区对系统性能的影响
  • 求典型非线性的描述函数表达式
  • 说明间隙为何容易引起自振
常见易错
  • 认为饱和总是使系统更稳定
  • 忽略死区在原点附近造成的小信号失效

6六、BIBO稳定判断与最小实现20 分#

思路
  • 对传递函数分子分母因式分解，先判断极点分布是否BIBO稳定，再消去公因子并写出能控标准型得最小实现。
零极点分布与响应模态 传递函数
本卷考法
  • 由极点分布判断系统响应是否收敛
本卷实例
  • 关键一步：把分母因式分解求出全部极点并看右半平面是否有极点
  • 中间结果：存在右半平面极点时传递函数对应的系统不稳定
  • 卡点：只看极点分布就断言收敛，忽略零点对消的影响
