1一、结构图转信号流图与梅逊公式10 分#

思路
  • 先把结构图的比较点与引出点化为信号流图节点，再找回路与前向通路用梅逊公式求传函。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图先画信号流图再用梅逊公式求传函
本卷实例
  • 关键一步：按比较点与引出点标节点并把增益标在支路上
  • 中间结果：独立回路表现为四个环节乘积的负值
  • 卡点：题1图为原卷插图，回路接触关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图先画信号流图再用梅逊公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 把多回路结构图等效化简后再求闭环传函
本卷实例
  • 关键一步：先判各回路反馈极性再写回路增益
  • 中间结果：无两两不接触回路时分母为 1 减各回路增益
  • 卡点：反馈极性取反导致分母符号错误
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过把多回路结构图等效化简后再求闭环传函
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、劳斯判据确定时间常数范围10 分#

思路
  • 由系统结构图写闭环特征方程，列劳斯表并令首列元素大于零解出时间常数范围。
劳斯判据 稳定性分析
本卷考法
  • 列劳斯表求使闭环稳定的参数范围
本卷实例
  • 关键一步：由特征方程按降幂排列写出劳斯表前两行
  • 中间结果：首列含有参数 τ 的一次表达式
  • 卡点：题2图为原卷插图，开环传函结构需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过列劳斯表求使闭环稳定的参数范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由首列不等式取交集确定参数 τ 的取值范围
本卷实例
  • 关键一步：把每个首列元素大于零化为 τ 的不等式
  • 中间结果：各不等式取交集得到 τ 的下界
  • 卡点：漏掉某个首列元素的不等式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由首列不等式取交集确定参数 τ 的取值范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

3三、二阶系统指标反求参数与稳态误差15 分#

思路
  • 由超调量与峰值时间解阻尼比和自然频率，比较闭环特征式系数求 K1、K2，再由速度误差系数求斜坡误差。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函化为标准二阶形式读阻尼比与自然频率
本卷实例
  • 关键一步：先按超调量公式反解阻尼比
  • 中间结果：峰值时间与自然频率的乘积为常数
  • 卡点：二次项系数未归一化就套标准形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函化为标准二阶形式读阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由给定动态指标反求系统参数
本卷实例
  • 关键一步：用阻尼比与自然频率写出期望特征式
  • 中间结果：比较系数得到两个增益的联立方程
  • 卡点：峰值时间与上升时间的公式混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由给定动态指标反求系统参数
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡输入下的稳态误差
本卷实例
  • 关键一步：先求速度误差系数再取输入幅值除以它
  • 中间结果：误差与开环增益成反比
  • 卡点：未判稳就直接用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

4四、三阶系统根轨迹出射角与虚轴交点15 分#

思路
  • 由开环极点写渐近线、分离点与出射角，再令特征方程实部虚部为零求与虚轴交点与临界增益。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制三阶系统根轨迹草图
本卷实例
  • 关键一步：由开环零极点个数定渐近线中心与夹角
  • 中间结果：实轴段位于负实轴从原点到负无穷
  • 卡点：渐近线夹角公式中的奇数系数写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制三阶系统根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点与会合点坐标
本卷实例
  • 关键一步：令开环传函分母对 s 求导为零得分离点方程
  • 中间结果：分离点方程为一元二次且两根均在负实轴
  • 卡点：求出根后不筛选而保留了区间外的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点与会合点坐标
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

本卷考法

  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求复数极点的出射角
  • 求复数极点的出射角

5五、含延迟环节系统的奈氏图与稳定增益范围15 分#

思路
  • 把延迟环节写成 jω 的指数形式，画幅相曲线并求与负实轴交点，再用奈奎斯特判据定稳定增益上限。
频率特性的物理意义与求法 频域分析
本卷考法
  • 求含指数延迟环节的幅频与相频表达式
本卷实例
  • 关键一步：延迟环节幅值为 1、相角为负 ω 乘延迟时间
  • 中间结果：幅频表达式与不带延迟时完全相同
  • 卡点：把延迟环节当成惯性环节处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求含指数延迟环节的幅频与相频表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法

本卷实例
