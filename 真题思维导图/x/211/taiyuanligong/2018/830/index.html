太原理工大学 830 自动控制原理（含现控） 2018 年真题思维导图

211 院校共 7 题合计 150 分

难度：中等　卷面印 1~6 题各 20 分、第 7 题 30 分，合计 150。自控部分：信号流图多输入增益、扰动与斜坡双误差下的控制器选择、由闭环反求开环并算稳定裕度、含参数根轨迹绘制与圆形证明、零阶保持器采样系统；现控部分：由状态转移矩阵求 A、状态反馈改造传递函数。题面含多幅插图。

1一、信号流图与梅逊公式求多输入增益20 分#

思路
  • 由结构图画信号流图，找全独立回路与前向通路，R 与 R1 非源节点时先求中间传函再相乘。
梅森增益公式与信号流图 传递函数
本卷考法
  • 对含多个输入的信号流图用梅逊公式求 Y/R 与 Y1/R1
本卷实例
  • 关键一步：先找全部独立回路并判断哪两组互不接触
  • 中间结果：四组独立回路增益中有一组为三环节乘积
  • 卡点：题1图为原卷插图，回路接触关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过对含多个输入的信号流图用梅逊公式求 Y/R 与 Y1/R1
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 多输入同时作用时分别求各自的传递通道
本卷实例
  • 关键一步：把 Y/R1 与 Y1/Y 分别求出后再相乘
  • 中间结果：R 与 R1 都不是源节点，不能直接套梅逊公式
  • 卡点：令某一输入为零时误把其支路一并删掉
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过多输入同时作用时分别求各自的传递通道
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

2二、扰动与斜坡误差下的控制器择优20 分#

思路
  • 分别写扰动误差与斜坡误差传函，先由阶跃扰动零误差定需含积分环节，再用劳斯判据与误差要求筛选控制器。
扰动作用下的稳态误差 稳态误差
本卷考法
  • 由扰动传函求阶跃扰动下的稳态误差并要求为零
本卷实例
  • 关键一步：令参考输入为零，单独写扰动到误差的传函
  • 中间结果：阶跃扰动下误差为零要求前向通道含积分环节
  • 卡点：求扰动传函时没有把参考输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过由扰动传函求阶跃扰动下的稳态误差并要求为零
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由斜坡输入下的误差上限反求开环增益下界
本卷实例
  • 关键一步：用速度误差系数把误差不等式化为增益不等式
  • 中间结果：斜坡误差与开环增益成反比，增益越大误差越小
  • 卡点：未判稳就用终值定理求稳态误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由斜坡输入下的误差上限反求开环增益下界
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据检验所选控制器下的闭环稳定性
本卷实例
  • 关键一步：列劳斯表并令首列元素同号得到增益区间
  • 中间结果：含一个积分的控制器稳定区间与误差要求可能冲突
  • 卡点：只算误差不验稳定会选到不稳定方案
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据检验所选控制器下的闭环稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 在三种给定控制器结构中择优满足双重误差要求
本卷实例
  • 关键一步：比较三种结构的型别与积分环节数排除不满足项
  • 中间结果：常数增益控制器无法消除阶跃扰动误差
  • 卡点：只满足误差要求而忽略稳定裕度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过在三种给定控制器结构中择优满足双重误差要求
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式

3三、由闭环传函反求开环与稳定裕度20 分#

思路
  • 由单位反馈关系反求开环，按幅值条件与相角条件分别求截止频率与穿越频率，再由裕量要求反解增益。
传递函数的定义与基本性质 传递函数
本卷考法
  • 由闭环传函用开环闭环关系反求开环传函
本卷实例
  • 关键一步：把闭环写成 G/(1+G) 后解出开环表达式
  • 中间结果：闭环分母减 1 得到开环的分母结构
  • 卡点：负反馈分母写成 1 减 G 会得到错误开环
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由闭环传函用开环闭环关系反求开环传函
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 把开环传函代 s 等于 jω 求幅频与相频表达式
本卷实例
  • 关键一步：分子分母分别取模相乘相除，各环节相角相加
  • 中间结果：幅频分母含 ω 与两个一阶环节模的乘积
  • 卡点：相角累加时漏掉积分环节的负 90 度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过把开环传函代 s 等于 jω 求幅频与相频表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
稳定裕度 频域分析
本卷考法
  • 由截止频率与穿越频率计算相角裕量和幅值裕量
本卷实例
  • 关键一步：先令幅值等于 1 求截止频率再代回相角
  • 中间结果：相角裕量等于相角加 180 度，幅值裕量取倒数再取分贝
  • 卡点：把截止频率与穿越频率两个频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由截止频率与穿越频率计算相角裕量和幅值裕量
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式

4四、闭环传函的参数根轨迹与圆形证明20 分#

思路
  • 把特征方程整理成含 k 的根轨迹形式，按法则求极点零点、分离点与渐近线，再证轨迹满足圆方程。
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 把闭环特征方程整理成 1 加 k 倍开环等于零的形式
本卷实例
  • 关键一步：把含 k 的项整体提到分子得到等效开环传函
  • 中间结果：等效开环的极点零点由原闭环参数 a、b 决定
  • 卡点：参数没有完整提到分子就套根轨迹法则
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过把闭环特征方程整理成 1 加 k 倍开环等于零的形式
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制参数根轨迹并证明 a 大于 b 时轨迹为圆
本卷实例
  • 关键一步：数实轴段右侧开环零极点个数判断实轴轨迹
  • 中间结果：代入 s 等于负 m 加 jn 后整理出圆方程
  • 卡点：渐近线公式在没有渐近线时仍强行套用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制参数根轨迹并证明 a 大于 b 时轨迹为圆
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 由分离点方程分 a 与 b 大小关系讨论分离点
本卷实例
  • 关键一步：令等效开环传函对 s 求导为零得到分离点方程
  • 中间结果：分离点坐标含根号 a 方减 ab，需分类讨论
  • 卡点：把不在根轨迹上的根也当作分离点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
