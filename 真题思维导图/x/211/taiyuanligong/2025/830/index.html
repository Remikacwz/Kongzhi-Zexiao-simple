1一、控制系统结构图与工作原理#

思路
  • 由题图给出的物理系统确定被控量与操纵量，按给定、比较、控制、执行、对象、检测六个环节逐一指认实物，再按信号流向连成闭环方框图，说明系统靠被控量偏差经控制器改变调节阀开度来维持被控量恒定。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 由物理系统图指认环节、画闭环方框图并说明工作过程
本卷实例
  • 关键一步：按信号流向逐个找出给定、比较、控制、执行、对象与检测六个环节
  • 中间结果：被控量与操纵量确定后，闭环方框图由这六个环节首尾相接
  • 卡点：系统结构图为原卷插图，环节实物与信号流向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过由物理系统图指认环节、画闭环方框图并说明工作过程
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

2二、二阶系统阶跃响应与稳态误差#

思路
  • 由单位阶跃响应曲线读出超调量与峰值时间，先用超调量公式反求阻尼比，再由峰值时间反求自然频率，写出标准二阶闭环传递函数，最后按误差定义求单位阶跃输入下的稳态误差。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由阶跃响应的超调量与峰值时间反求二阶传递函数
本卷实例
  • 关键一步：从曲线读出稳态值、超调量与峰值时间，判断为欠阻尼二阶系统
  • 中间结果：超调量只与阻尼比有关，峰值时间与自然频率成反比
  • 卡点：阶跃响应曲线为原卷插图，超调量与峰值时间读数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由阶跃响应的超调量与峰值时间反求二阶传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 用动态性能指标公式由曲线读数求阻尼比与自然频率
本卷实例
  • 关键一步：用超调量公式先解出阻尼比，再代入峰值时间公式求自然频率
  • 中间结果：阻尼比与自然频率确定后，各项时域指标随之固定
  • 卡点：超调量公式漏乘百分之百会令阻尼比偏小
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过用动态性能指标公式由曲线读数求阻尼比与自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为标准二阶形式并写出闭环极点
本卷实例
  • 关键一步：将闭环传函分母首项归一化，再与标准二阶形式逐项比较系数
  • 中间结果：分母一次项给出阻尼比与自然频率的乘积，常数项给出自然频率平方
  • 卡点：化为标准形式时忘记把首项系数归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为标准二阶形式并写出闭环极点
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位负反馈系统在单位阶跃输入下的稳态误差
本卷实例
  • 关键一步：用终值定理把误差传函与阶跃输入相乘后取零频极限
  • 中间结果：误差等于输入减输出，闭环直流增益决定阶跃输入下的误差
  • 卡点：取极限前需先由特征方程确认闭环稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位负反馈系统在单位阶跃输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、根轨迹绘制、稳定性分析与附加零点#

思路
  • 先由开环传函写出极点分布与实轴根轨迹段，用渐近线与分离点公式定根轨迹形状，再列劳斯表判断稳定性；引入开环零点后重新计算渐近线与分离点，并按零点位置参数的取值分段讨论根轨迹移动方向与稳定性。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画开环含重极点的根轨迹草图
本卷实例
  • 关键一步：标出两个原点极点与一个负实极点，再判断实轴上的根轨迹段
  • 中间结果：渐近线交点在极点实部均值处，夹角按分支数奇数等分
  • 卡点：原点为二重极点，实轴段判据要按重数计数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画开环含重极点的根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 判断根轨迹与虚轴有无交点及临界增益
本卷实例
  • 关键一步：由闭环特征方程列劳斯表，令首列为零求临界条件
  • 中间结果：特征方程缺一次项，劳斯表首列出现含增益的负号项
  • 卡点：不能只凭极点分布断言不稳定，需由劳斯表确认
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过判断根轨迹与虚轴有无交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断三阶系统随增益变化的稳定性
本卷实例
  • 关键一步：把闭环特征方程按降幂排列后逐行交叉相减列劳斯表
  • 中间结果：缺项位置补零后，首列符号决定右半平面极点数
  • 卡点：缺项不补零会误判首列的符号变化次数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断三阶系统随增益变化的稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 按零点参数分段讨论根轨迹形状与稳定性变化
本卷实例
  • 关键一步：增加零点后先重算渐近线交点与夹角，再判断实轴上的根轨迹段
  • 中间结果：零点参数分区间取值时，分离点的实虚性随之改变
  • 卡点：零点参数不同区间要分别讨论，不能合并成一个结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过按零点参数分段讨论根轨迹形状与稳定性变化
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反

4四、奈奎斯特判据判断稳定性#

思路
  • 先由最小相位条件确定开环右半平面极点数为零，再对幅相曲线补画无穷大半径圆弧，数出曲线对临界点的净包围圈数，代入奈奎斯特判据判断闭环是否稳定。
奈奎斯特判据 稳定性分析
本卷考法
  • 由最小相位系统的幅相曲线判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数，再数曲线绕临界点的净包围圈数
  • 中间结果：两量代入判据关系式即得右半平面闭环极点数
  • 卡点：奈奎斯特曲线为原卷插图，补画圆弧与包围方向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由最小相位系统的幅相曲线判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
最小相位系统与非最小相位系统 频域分析
本卷考法
  • 利用最小相位条件确定开环右半平面极点数
本卷实例
  • 关键一步：由最小相位判定开环零点与极点都在左半平面
  • 中间结果：开环右半平面极点数为零，判据简化为只数包围圈数
  • 卡点：把最小相位与开环右半平面极点数为零混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位

5五、离散系统的脉冲传递函数与稳态误差#

思路

6六、状态转移矩阵、系统矩阵与李雅普诺夫函数#

状态转移矩阵 状态空间分析
本卷考法
  • 由两组初始状态与响应求状态转移矩阵和系统矩阵

  • 中间结果：初始状态矩阵可逆，左乘其逆得转移矩阵，其在零点导数为系统矩阵
