1一、二自由度机械系统的微分方程与传递函数#

思路
  • 对两个质量块分别列牛顿第二定律方程，取拉氏变换后消去中间变量，解出两个位移对力的传递函数。
机械系统建模 建模与机电系统
本卷考法
  • 对含弹簧与阻尼器的两质量系统列微分方程
本卷实例
  • 关键一步：按各质量块所受弹簧力与阻尼力的实际方向列力平衡式
  • 中间结果：两方程都含位移的两个未知量，必须联立才能消元
  • 卡点：机械系统图为原卷插图，弹簧阻尼的串并联方式需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过对含弹簧与阻尼器的两质量系统列微分方程
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由机械系统的微分方程求位移对力的传递函数
本卷实例
  • 关键一步：把两个时域方程变换到 s 域后写成矩阵再消元
  • 中间结果：两个传递函数分母相同，分子由各支路的弹簧阻尼组合决定
  • 卡点：把阻尼力方向与弹簧力方向取反会令耦合项符号出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由机械系统的微分方程求位移对力的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

2二、由阻尼比与斜坡误差反求二阶系统参数#

思路
  • 由结构图化简得闭环传函并化为标准二阶形式，用阻尼比与斜坡误差两条件解出参数与动态指标。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由系统结构图化简求闭环传递函数
本卷实例
  • 关键一步：把局部反馈与串联支路逐层等效后写出闭环传函
  • 中间结果：闭环特征式化为 s 平方加含 k 与 tau 的一次项再加 k
  • 卡点：系统结构图为原卷插图，反馈支路的接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由系统结构图化简求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 将闭环传函化为标准二阶形式读出阻尼比与自然频率
本卷实例
  • 关键一步：把分母与标准二阶形式逐项比较系数
  • 中间结果：一次项系数对应两倍阻尼比乘自然频率，常数项对应其平方
  • 卡点：忘记把二次项系数归一化就直接套标准二阶形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过将闭环传函化为标准二阶形式读出阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率计算超调量与调节时间
本卷实例
  • 关键一步：先由阻尼比求超调量，再按误差带系数求调节时间
  • 中间结果：超调量只取决于阻尼比，调节时间与自然频率成反比
  • 卡点：两种误差带的调节时间系数容易混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率计算超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡响应的误差值反求开环参数
本卷实例
  • 关键一步：由误差等于速度误差系数倒数建立与系统参数的方程
  • 中间结果：速度误差系数等于开环传函去掉积分环节后的直流增益
  • 卡点：用终值定理前必须先确认闭环系统稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位斜坡响应的误差值反求开环参数
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、以参数 a 为变量的根轨迹与分离点#

思路
  • 把特征方程整理成等效开环形式，由分离点方程的判别式符号分出 a 的三个区间再画根轨迹。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画含重极点与一个零点的根轨迹
本卷实例
  • 关键一步：标出原点二重极点与负实极点，判断实轴上的根轨迹段
  • 中间结果：渐近线交点在极点实部均值处，夹角按分支数等分
  • 卡点：原点为二重极点，实轴段判据要按重数计数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画含重极点与一个零点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 由分离点方程的判别式确定分离点个数与参数范围
本卷实例
  • 关键一步：令增益对 s 的导数为零得分离点方程，再求其判别式
  • 中间结果：判别式大于零、等于零、小于零分别对应两个、一个、无实数分离点
  • 卡点：求出的根要代回检验是否落在根轨迹上
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由分离点方程的判别式确定分离点个数与参数范围
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以 a 为参变量作参数根轨迹并分段讨论
本卷实例
  • 关键一步：把含 a 的项整理到等效开环的分子上再按增益变化画轨迹
  • 中间结果：a 的三个区间对应渐近线交点位于右半平面、原点与左半平面
  • 卡点：参数根轨迹不能沿用普通根轨迹的零点位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以 a 为参变量作参数根轨迹并分段讨论
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

4四、非最小相位系统的奈奎斯特曲线与频率特性#

思路
  • 写出幅频相频表达式并按起点终点画奈氏曲线，再由幅相条件与斜坡误差反求时间常数与增益。
频率特性的物理意义与求法 频域分析
本卷考法
  • 求开环传函的幅频与相频表达式并判断曲线走向
本卷实例
  • 关键一步：分子分母各环节取模相乘、相角相加，再分析两个极端频率
  • 中间结果：低频段幅值趋于无穷、相角较负，高频段幅值趋于零
  • 卡点：相角累加时漏掉积分环节对应的负九十度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求开环传函的幅频与相频表达式并判断曲线走向
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
最小相位系统与非最小相位系统 频域分析
本卷考法
  • 由分子零点判断系统为非最小相位并分析相位特点
本卷实例
  • 关键一步：识别分子中新出现的零点位于右半平面
  • 中间结果：该零点使相角比同幅频的最小相位系统多滞后一段
  • 卡点：把右半平面零点与右半平面极点混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过由分子零点判断系统为非最小相位并分析相位特点
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈
奈奎斯特判据 稳定性分析
本卷考法
  • 由幅相曲线判断闭环稳定性并确定临界条件
本卷实例
  • 关键一步：先数开环右半平面极点数，再看曲线对临界点的包围情况
  • 中间结果：曲线形状决定稳定所需的时间常数与增益关系
  • 卡点：开环含积分环节时未补画无穷大半径圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
