一一、结构图与扰动补偿、稳定域25 分#

思路
  • 由方框图分别求开环、给定与扰动通道的闭环传函和误差传函；列闭环特征方程用劳斯判据求 k 稳定区间；由单位斜坡稳态误差要求列不等式；最后令扰动到输出传函为零反解前馈控制器并判断可实现性。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求给定与扰动分别作用时的闭环传函和误差传函
本卷实例
  • 关键一步：求某一输入通道传函时把另一输入置零
  • 关键一步：按结构图分别列出给定前向通路与扰动前向通路
  • 中间结果：两个通道共享同一闭环特征多项式，仅分子不同
  • 卡点：求扰动传函时未把参考输入置零
  • 卡点：结构图为原卷插图，反馈极性需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求给定与扰动分别作用时的闭环传函和误差传函
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求闭环系统对参数 k 的稳定区间
本卷实例
  • 关键一步：由闭环特征方程整理成 k 的多项式
  • 关键一步：列劳斯表并令首列元素同号
  • 中间结果：k 的稳定区间由几个不等式取交集得到
  • 卡点：特征方程缺项时未补零
  • 卡点：把不等式端点是否包含写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求闭环系统对参数 k 的稳定区间
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡稳态误差上限反求参数 k 范围
本卷实例
  • 关键一步：先按系统型别写出速度误差系数
  • 关键一步：把稳态误差表示成 k 的函数后代入不等式
  • 中间结果：满足误差上限的 k 区间需与稳定区间取交集
  • 卡点：未判稳就使用稳态误差公式
  • 卡点：把斜坡输入稳态误差与阶跃输入公式混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位斜坡稳态误差上限反求参数 k 范围
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
反馈校正与复合控制 系统校正
本卷考法
  • 设计前馈控制器使扰动对输出的影响为零并讨论可实现性
本卷实例
  • 关键一步：写出扰动到输出的传函并令其分子为零
  • 关键一步：反解前馈控制器的传递函数
  • 中间结果：前馈控制器为扰动通道与给定通道相应环节之比
  • 卡点：求出的前馈控制器可能含纯微分而物理不可实现
  • 卡点：未说明实现的近似条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过设计前馈控制器使扰动对输出的影响为零并讨论可实现性
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

二二、单回路比例积分控制20 分#

思路
  • 比例控制时闭环为一阶系统，由调节时间反求 k 并求单位阶跃稳态误差；积分控制时闭环成二阶系统，先由终值定理求稳态误差，再由调节时间和超调量条件确定 k 范围。
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由一阶闭环系统的调节时间要求反求比例增益
本卷实例
  • 关键一步：写出比例控制时的闭环一阶传函
  • 关键一步：按百分之五误差带的调节时间公式反解时间常数
  • 中间结果：比例增益由闭环时间常数与对象时间常数的关系确定
  • 卡点：把百分之五误差带的系数当成百分之二
  • 卡点：忽略控制器与对象串联后的时间常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由一阶闭环系统的调节时间要求反求比例增益
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

  • 中间结果：有积分环节时单位阶跃稳态误差为零
  • 卡点：未判稳就代入终值定理
  • 卡点：把一阶对象加比例控制误判为无差系统

  • 求给定输入下的稳态误差

  • 比较不同型别系统的跟踪能力

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由积分控制下的闭环特征式读取阻尼比与自然频率
本卷实例
  • 关键一步：把闭环特征多项式整理成二阶标准形
  • 关键一步：对照一次项与常数项读出两个参数
  • 中间结果：积分增益同时影响阻尼比与自然频率
  • 卡点：未把最高次项系数归一
  • 卡点：把对象时间常数与积分时间常数混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由积分控制下的闭环特征式读取阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量上限求积分增益的取值范围
本卷实例
  • 关键一步：由超调量公式反解阻尼比下限
  • 关键一步：把阻尼比与积分增益的关系代入得不等式
  • 中间结果：超调量小于百分之四点三对应阻尼比大于零点七零七
  • 卡点：超调量公式中漏乘百分之百
  • 卡点：把阻尼比不等号方向写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量上限求积分增益的取值范围
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

三三、机电系统建模与响应15 分#

思路
  • 由牛顿第二定律对质量块列微分方程并整理成传递函数；由终值定理求单位阶跃输入下的稳态值；把新增质量视为质量参数变化，重新求阻尼比后代入超调量公式。
机械系统建模 建模与机电系统
本卷考法
  • 由机械系统受力图列写微分方程并求传递函数
本卷实例
  • 关键一步：按牛顿第二定律写出质量块所受合力等于质量乘加速度
  • 关键一步：把弹簧力与阻尼力按位移和速度方向列式
  • 中间结果：微分方程经拉氏变换得质量乘 s 平方加阻尼乘 s 加刚度的分母
  • 卡点：弹簧力与阻尼力正负号取反
  • 卡点：图中受力方向与质量块连接方式需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过由机械系统受力图列写微分方程并求传递函数
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项

本卷考法

本卷考法

本卷实例

  • 关键一步：比较特征根的模与一的大小

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤

  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过由闭环特征方程的根判断离散系统稳定性
  • 判断离散系统是否稳定

  • 用 w 变换后套用劳斯判据
常见易错

  • w 变换公式记错导致映射关系颠倒
