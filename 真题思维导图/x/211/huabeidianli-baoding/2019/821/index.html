一一、比例与积分控制下的稳态误差与动态性能17 分#

思路
  • 对同一对象分别采用比例与积分控制器，比较稳态误差与动态指标，并由超调量要求反求积分增益范围，最后选择改善调节时间的典型环节。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函化标准二阶形式求阻尼比与自然频率
本卷实例
  • 关键一步：把s平方项系数归一化
  • 关键一步：与标准二阶形式比对系数
  • 中间结果：ξ与ωn由控制器参数决定
  • 卡点：未归一化就读出ξ与ωn
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函化标准二阶形式求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求单位阶跃下的超调量与调节时间
本卷实例
  • 关键一步：由ξ与ωn代入指标公式
  • 关键一步：按误差带取调节时间系数
  • 中间结果：动态指标随控制器参数变化
  • 卡点：两种误差带的系数混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求单位阶跃下的超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求比例与积分控制下单位阶跃的稳态误差
本卷实例
  • 关键一步：先判稳再比较开环型别
  • 关键一步：比例控制误差有限，积分控制消除阶跃误差
  • 中间结果：误差与开环静态增益相关
  • 卡点：未判稳直接代入误差公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求比例与积分控制下单位阶跃的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量小于给定值反求积分增益k的范围
本卷实例
  • 关键一步：把超调量要求转为阻尼比下界
  • 关键一步：再代入ξ与k的关系解不等式
  • 中间结果：超调量约束化为k的区间
  • 卡点：把阻尼比不等号方向取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量小于给定值反求积分增益k的范围
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

PID 控制器与参数整定 系统校正
本卷考法
  • 选择能改善调节时间的典型环节
本卷实例
  • 关键一步：比较比例与积分控制对响应速度的作用
  • 关键一步：引PI并引入零点改变闭环极点
  • 中间结果：增加零点可缩短调节时间
  • 卡点：把PI的相位影响说成超前
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过选择能改善调节时间的典型环节
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

二二、延迟近似前馈补偿与稳定域22 分#

思路
  • 先把两个含延迟对象按近似公式化为无纯延迟形式，再分别用比例与积分控制器求闭环传函、稳定域与稳态误差，最后设计前馈控制器实现扰动不变性。
典型环节及其特性 传递函数
本卷考法
  • 按近似公式把两个含延迟对象化为无纯延迟形式
本卷实例
  • 关键一步：分别识别k、τ、T与n
  • 关键一步：由n1T1等于nT加τ确定等效时间常数
  • 中间结果：两个延迟对象都化为惯性环节
  • 卡点：n1取整方向用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过按近似公式把两个含延迟对象化为无纯延迟形式
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减
公式
串联、并联与反馈等效 结构图与方框图
本卷考法

本卷实例

  • 卡点：分母误写成1减开环
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

步骤

  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由前向通道与反馈通道求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

三三、机械系统建模与初值终值定理#

思路
  • 由弹簧阻尼机械系统的三个力平衡方程消元求局部与总传递函数，再用初值定理和终值定理求阶跃响应的初值与稳态值并画响应草图。
机械系统建模 建模与机电系统
本卷考法
  • 由弹簧阻尼机械系统列三个力平衡方程
本卷实例
  • 关键一步：对三个质量点分别列力平衡
  • 关键一步：消去中间位移量xi
  • 中间结果：力F由相对位移与相对速度表示
  • 卡点：阻尼力与弹簧力正负方向取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过由弹簧阻尼机械系统列三个力平衡方程
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式

  • 卡点：把位移与力之比的关系写反
