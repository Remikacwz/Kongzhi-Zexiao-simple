一一、锅炉给水控制系统35 分#

思路
  • 由原理图和方框图分别求开环、给定与扰动通道的闭环传函、特征方程和误差传函；代入题给参数用劳斯判据分析稳定性，并由终值定理求单位阶跃输入下的稳态误差；最后说明前馈环节 Gf 的扰动补偿作用。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由锅炉给水控制系统的方框图求开环与闭环传函及特征方程
本卷实例
  • 关键一步：按信号流向找出主反馈回路与局部回路
  • 关键一步：逐层化简后写出开环传函和闭环特征方程
  • 中间结果：闭环特征方程为开环传函分母加分子
  • 卡点：原理图与方框图为原卷插图，信号流向需回原卷核对图
  • 卡点：主蒸汽流量扰动的作用点容易看错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由锅炉给水控制系统的方框图求开环与闭环传函及特征方程
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求给定输入和扰动输入下的闭环传函与误差传函
本卷实例
  • 关键一步：求某一通道传函时把另一输入置零
  • 关键一步：按梅森公式分别列给定与扰动的前向通路和回路
  • 中间结果：两个通道的闭环特征式相同，分子反映各自输入通路
  • 卡点：求扰动传函时未把给定输入置零
  • 卡点：把误差传函与输出传函混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求给定输入和扰动输入下的闭环传函与误差传函
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

劳斯判据 稳定性分析
本卷考法
  • 代入题给参数用劳斯判据分析闭环稳定性
本卷实例
  • 关键一步：把题给 Gc1、Gc2、Gv、Go 代入特征方程
  • 关键一步：列劳斯表并检查首列符号
  • 中间结果：特征方程全部系数同号且劳斯表首列无变号时闭环稳定
  • 卡点：参数量纲或时间常数漏乘
  • 卡点：分子分母未整理成降幂多项式就列劳斯表
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过代入题给参数用劳斯判据分析闭环稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求给定单位阶跃输入且扰动为零时的稳态误差
本卷实例
  • 关键一步：先确认系统稳定，写出误差传函
  • 关键一步：用终值定理求单位阶跃输入下的稳态误差
  • 中间结果：有积分环节时单位阶跃输入稳态误差为零
  • 卡点：未判稳就使用终值定理
  • 卡点：把误差定义取成输出与给定之差而非给定与反馈之差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求给定单位阶跃输入且扰动为零时的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

反馈校正与复合控制 系统校正
本卷考法
  • 说明前馈控制器 Gf 在锅炉给水控制中的作用
本卷实例
  • 关键一步：指出 Gf 从可测扰动引出前馈补偿信号
  • 关键一步：令扰动到输出的传函为零反推补偿关系
  • 中间结果：前馈补偿不影响闭环特征方程，只改变扰动通道传函
  • 卡点：把前馈补偿说成反馈校正
  • 卡点：忽略补偿器物理可实现性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过说明前馈控制器 Gf 在锅炉给水控制中的作用
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

二二、RLC电路建模与响应25 分#

思路
  • 由 KVL 和元件伏安关系列微分方程并求传递函数；化为二阶标准形求自然频率与阻尼比，据此计算单位阶跃响应的峰值、稳态值和调节时间；最后按阻尼比不小于一定值求电阻范围。
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由 RLC 电路列微分方程并求传递函数
本卷实例
  • 关键一步：按 KVL 写输入电压等于电感电压、电阻电压与电容电压之和
  • 关键一步：把电容电流与电容电压的导数关系代入消去电流
  • 中间结果：消元后得到以电容电压为输出的二阶微分方程
  • 卡点：把电容阻抗与电感阻抗的复频域表达式写反
  • 卡点：电路连接方式为原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由 RLC 电路列微分方程并求传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由二阶传递函数求阻尼比与自然频率
本卷实例
  • 关键一步：把传递函数分母整理成二阶标准形
  • 关键一步：由一次项系数和常数项读出两个参数
  • 中间结果：阻尼比等于电阻项与两倍自然频率之比
  • 卡点：未先把 s 平方项系数归一
  • 卡点：把自然频率与谐振频率混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由二阶传递函数求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 计算单位阶跃响应的峰值、稳态值和调节时间
本卷实例
  • 关键一步：由阻尼比判断是欠阻尼还是过阻尼
  • 关键一步：按相应公式算峰值时间、超调量和调节时间
  • 中间结果：稳态值等于传递函数在零频处的增益
  • 卡点：把峰值时间与上升时间混用
  • 卡点：调节时间误差带百分比不同导致系数取错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过计算单位阶跃响应的峰值、稳态值和调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

典型环节的对数频率特性 频域分析
本卷考法

本卷实例

  • 关键一步：按低频渐近线、转角频率和高频渐近线画草图
  • 中间结果：高频段斜率为负四十并伴随谐振峰

  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec

通用考法
  • 本卷考过绘制二阶 RLC 电路传递函数的 Bode 草图
  • 画出某一典型环节的 Bode 图
  • 由 Bode 图识别环节类型
  • 说明转角频率处的幅值与相角
常见易错
  • 把惯性环节高频渐近线的 -20 写成 -40
  • 振荡环节谐振峰位置误当作 ωn

三三、储气罐压力控制与奈奎斯特25 分#

思路
  • 由压力控制系统方框图求开环传函，按比例控制画奈奎斯特曲线并用判据求 k 稳定区间；比例积分控制时分解出比例与积分环节画 Bode 并判断超前或滞后，再由曲线求幅值裕量；最后设计前馈补偿消除出口流量对输出的影响。
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环奈奎斯特曲线求比例控制下参数 k 的稳定区间
本卷实例
  • 关键一步：写出比例控制时的开环传函
  • 关键一步：画曲线并判断其对负一临界点的包围情况
  • 中间结果：k 的稳定区间由曲线与负实轴交点位置确定
  • 卡点：开环含惯性环节但无积分环节，右半平面极点数需先数清
  • 卡点：曲线草图为原卷要求绘制，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环奈奎斯特曲线求比例控制下参数 k 的稳定区间
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
典型环节的对数频率特性 频域分析
本卷考法
  • 画比例积分控制器的 Bode 图并判断超前或滞后特性
本卷实例

  • 卡点：把积分环节的负九十度说成正九十度
  • 卡点：把比例增益当成转折频率

  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec

本卷考法

本卷实例
  • 关键一步：令线性部分频率特性等于负倒描述函数
  • 关键一步：把题给自振频率与振幅代入后分离实部与虚部

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A

  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率
