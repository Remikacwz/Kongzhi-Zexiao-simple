一一、选择题#

思路
  • 五道选择题分别考查传递函数的基本性质、单位负反馈一阶系统的调节时间、串联超前校正装置的识别、控制系统的分类以及由二阶系统闭环极点求超调量。
传递函数的定义与基本性质 传递函数
本卷考法
  • 判断关于传递函数性质的叙述是否正确
本卷实例
  • 关键一步：回顾传递函数以零初始条件为前提
  • 关键一步：区分传递函数只反映外部关系不反映内部结构
  • 中间结果：传递函数仅对线性定常系统且零初始条件下成立
  • 卡点：把传递函数能描述的范围扩大到任意系统
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过判断关于传递函数性质的叙述是否正确
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由一阶单位负反馈系统的开环传函估算调节时间
本卷实例
  • 关键一步：把闭环传函化为一阶惯性形式
  • 关键一步：按百分之五误差带取三倍时间常数
  • 中间结果：调节时间由闭环时间常数决定
  • 卡点：把调节时间的误差带系数记错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由一阶单位负反馈系统的开环传函估算调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

超前校正 系统校正
本卷考法
  • 从给定传递函数中识别串联超前校正装置
本卷实例
  • 关键一步：比较零极点转折频率的位置关系
  • 关键一步：零点频率小于极点频率且具有正相移者为超前
  • 中间结果：超前网络在低频段增益低、相位超前
  • 卡点：把滞后网络误判为超前网络
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过从给定传递函数中识别串联超前校正装置
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 按结构形式判断控制系统的分类方式
本卷实例
  • 关键一步：区分按结构形式与按其他标准分类
  • 关键一步：识记开环、闭环与复合系统的划分
  • 中间结果：按结构形式分为开环、闭环与复合控制系统
  • 卡点：把按输入类型划分与按结构形式划分混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过按结构形式判断控制系统的分类方式
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由二阶系统闭环极点求阻尼比并估算超调量
本卷实例
  • 关键一步：由共轭极点实部与虚部求阻尼比
  • 关键一步：代入超调量公式估算百分比
  • 中间结果：阻尼比由极点位置唯一确定
  • 卡点：把无零点条件误当成可忽略阻尼比
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由二阶系统闭环极点求阻尼比并估算超调量
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

二二、填空题#

思路
  • 四道填空题分别考查由闭环传函判断稳定性、由对数幅频特性反求环节传函、由特征方程判断特征根分布以及由二阶系统单位阶跃响应求阻尼比与自然频率。
劳斯判据 稳定性分析
本卷考法
  • 由给定闭环传递函数判断系统是否稳定
本卷实例
  • 关键一步：写出闭环特征方程并按降幂排列
  • 关键一步：列劳斯表检查首列符号
  • 中间结果：特征方程系数出现异号即可判定不稳定
  • 卡点：系数缺项未补零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由给定闭环传递函数判断系统是否稳定
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

由 Bode 图反求传递函数 频域分析
本卷考法
  • 由环节的对数幅频特性曲线写出其传递函数
本卷实例
  • 关键一步：由低频段高度与斜率确定增益与型别
  • 关键一步：由转折频率个数确定时间常数
  • 中间结果：环节传函由低频增益与各转折频率确定
  • 卡点：把转折频率处斜率变化与对应环节阶次对应错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由环节的对数幅频特性曲线写出其传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

三三、延迟系统响应与降阶#

思路
  • 由含延迟一阶对象的单位阶跃响应曲线读出指定时刻与幅值，再按近似公式把延迟对象化为无纯延迟形式，最后串联积分环节用劳斯判据求稳定参数范围。
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由含延迟一阶对象的单位阶跃响应曲线求指定时刻与幅值
本卷实例
  • 关键一步：写出一阶惯性加延迟的阶跃响应表达式
  • 关键一步：按给定幅值百分比反解对应时刻
  • 中间结果：响应曲线由稳态值、时间常数与延迟时间共同确定
  • 卡点：响应曲线为原卷插图，t1、t2、y2的标注位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由含延迟一阶对象的单位阶跃响应曲线求指定时刻与幅值
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
典型环节及其特性 传递函数
本卷考法
  • 按近似公式把含纯延迟对象化为无纯延迟形式
本卷实例
  • 关键一步：识别对象为k e^-τs除以(Ts+1)^n
  • 关键一步：由n1T1约等于nT加τ确定降阶参数
  • 中间结果：近似后延迟被并入等效时间常数
  • 卡点：n1取整时四舍五入方向用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过按近似公式把含纯延迟对象化为无纯延迟形式
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
