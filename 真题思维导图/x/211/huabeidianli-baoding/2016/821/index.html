一一、参数根轨迹绘制#

思路
  • 以τ为可变参数整理闭环特征方程，写出等效开环传函，按根轨迹法则求实轴段、渐近线、分离点、出射角与虚轴交点，讨论τ变化时根轨迹的形状。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 把τ变化的问题整理成以τ为参数的参数根轨迹
本卷实例
  • 关键一步：由1加G(s)等于零整理出τ的显式表达式
  • 关键一步：把τ提到分子位置写出等效开环传函
  • 中间结果：等效开环传函的分母为不含τ的多项式
  • 卡点：未把参数完整提到分子位置
  • 卡点：参数根轨迹仍沿用普通180度相角条件的画法
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过把τ变化的问题整理成以τ为参数的参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按根轨迹法则求实轴段、渐近线与分离点
本卷实例
  • 关键一步：数实轴段右侧零极点个数判断实轴根轨迹
  • 关键一步：按渐近线夹角与交点公式求渐近线
  • 中间结果：渐近线的交点与夹角由零极点分布确定
  • 卡点：实轴段判据中零极点个数算错
  • 卡点：渐近线夹角公式中2k加1写成2k
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按根轨迹法则求实轴段、渐近线与分离点
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 用重根条件求根轨迹的分离点并取舍
本卷实例
  • 关键一步：对闭环特征方程用重根条件列方程
  • 关键一步：解出候选点后按是否落在实轴根轨迹上取舍
  • 中间结果：分离点满足关于d的代数方程
  • 卡点：求出根后不筛选保留了不在根轨迹上的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过用重根条件求根轨迹的分离点并取舍
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
出射角与入射角 根轨迹法
本卷考法
  • 求复数极点的出射角并判断根轨迹起始方向
本卷实例
  • 关键一步：按相角条件累加其余零极点对该极点的相角
  • 关键一步：由180度减去累加值得出射角
  • 中间结果：出射角由各零极点相角之代数和确定
  • 卡点：累加相角时把该极点自身的相角也算进去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求复数极点的出射角并判断根轨迹起始方向
  • 求复数极点的出射角
  • 根据出射角画出根轨迹起始方向
  • 由入射角确定根轨迹终止方向
常见易错
  • 累加相角时把该极点自身的相角也算进去
  • 忘记判断象限导致角度差 180°
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴的交点及对应的临界参数
本卷实例
  • 关键一步：令s等于jω代入特征方程并分离实部虚部
  • 关键一步：联立两式解出交点频率与临界参数
  • 中间结果：临界参数对应一对纯虚根
  • 卡点：只代一个频率就下结论漏掉另一组交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴的交点及对应的临界参数
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

二二、一阶对象降阶与PI参数反求#

思路
  • 由给定一阶对象单位阶跃响应曲线读出增益与时间常数，按近似公式降阶，再写出含PI控制的闭环传函，由静差为零、超调量与调节时间要求反求kp与ki。
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由一阶系统单位阶跃响应曲线求放大系数与时间常数
本卷实例
  • 关键一步：由稳态值确定放大系数
  • 关键一步：由到达百分之六十三点二对应时刻读时间常数
  • 中间结果：一阶对象传函由稳态值与时间常数确定
  • 卡点：把百分之六十三点二对应时刻记成百分之五十对应时刻
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由一阶系统单位阶跃响应曲线求放大系数与时间常数
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 按题给近似公式对高阶惯性对象降阶
本卷实例
  • 关键一步：识别对象为k除以(Ts+1)^n的形式
  • 关键一步：由n1T1约等于nT确定降阶参数
  • 中间结果：降阶后对象为低阶惯性环节
  • 卡点：忽略闭环零点对动态性能的影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过按题给近似公式对高阶惯性对象降阶
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量小于百分之二十确定阻尼比下界
本卷实例
  • 关键一步：由超调量公式反解阻尼比
  • 关键一步：取临界超调量对应阻尼比为边界
  • 中间结果：超调量给定值对应一个确定的阻尼比下界
  • 卡点：超调量公式漏乘百分之百
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量小于百分之二十确定阻尼比下界
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 联立超调量与调节时间约束反求kp与ki
本卷实例
  • 关键一步：把两个指标分别写成关于kp与ki的不等式
  • 关键一步：取交集并整理成两参数的数学关系
  • 中间结果：两指标对kp与ki的变化方向相反需折中
  • 卡点：只满足单项指标就下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过联立超调量与调节时间约束反求kp与ki
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由系统的稳态误差为零说明开环须含积分环节
本卷实例
  • 关键一步：判断系统型别与输入类型的关系
  • 关键一步：令静态位置误差系数趋于无穷
  • 中间结果：I型系统跟踪阶跃输入时静差为零
  • 卡点：未先判稳就使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由系统的稳态误差为零说明开环须含积分环节
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

三三、双水箱液位系统结构图#

思路
  • 由两个水箱的进出水量平衡关系列写微分方程，消去中间变量得到输入输出关系，再按信号流向把两个一阶环节连成系统结构图。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 由两个水箱组成的液位系统绘制系统结构图
本卷实例
  • 关键一步：分别对两个水箱列写进水量与出水量的平衡方程
  • 关键一步：把第一个水箱的液位作为第二个水箱的输入逐级连接
  • 中间结果：系统结构图由两个一阶惯性环节串联构成
  • 卡点：水箱的进水量与出水量关系写反
  • 卡点：液位系统为原卷插图，管路与阀门位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过由两个水箱组成的液位系统绘制系统结构图
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 按串联与反馈等效关系整理所画结构图
本卷实例
  • 关键一步：判断两个水箱之间是串联还是带局部反馈
  • 关键一步：按信号流向连接各环节的输入与输出
  • 中间结果：整体结构图体现前级液位对后级流量的作用
  • 卡点：把前一个水箱的出水当成后一个水箱的进水时方向连反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
