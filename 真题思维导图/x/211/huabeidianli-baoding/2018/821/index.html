一一、填空题30 分#

思路
  • 八个空覆盖劳斯判据、特征方程、稳态误差、二阶指标、频率特性、脉冲传函、状态空间与状态转移矩阵，逐空按定义或公式直接求解。
劳斯判据 稳定性分析
本卷考法
  • 由闭环特征多项式列劳斯表数右半平面特征根个数
本卷实例
  • 关键一步：写出闭环特征多项式并按降幂排列
  • 关键一步：列劳斯表数首列符号变化次数
  • 中间结果：右半平面根数等于劳斯表首列变号次数
  • 卡点：首列出现零时未用ε法处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由闭环特征多项式列劳斯表数右半平面特征根个数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

传递函数的定义与基本性质 传递函数
本卷考法
  • 由开环传递函数写单位负反馈系统的特征方程
本卷实例
  • 关键一步：令1加开环传函为零并通分
  • 关键一步：按降幂整理成多项式
  • 中间结果：特征方程为开环分母与分子之和式
  • 卡点：把开环分母直接当成特征方程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由开环传递函数写单位负反馈系统的特征方程
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法

  • 由闭环传递函数求 ωn 与 ξ

频率特性的物理意义与求法 频域分析
本卷考法
  • 由开环传递函数求幅频特性与相频特性表达式
本卷实例
  • 关键一步：令s等于jω
  • 关键一步：分子分母分别取模与相角
  • 中间结果：幅频为两复数模之比，相频为相角之差
  • 卡点：相角累加时漏掉环节符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由开环传递函数求幅频特性与相频特性表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

思路

本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤

  • 令 N(s)=0，求输入到输出的传递函数

  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
