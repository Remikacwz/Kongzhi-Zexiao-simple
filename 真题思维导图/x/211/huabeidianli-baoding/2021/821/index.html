华北电力大学(保定) 821 自动控制理论（含现控） 2021 年真题思维导图

难度：中等偏上　八道大题覆盖结构图与扰动补偿、稳定性与零极点对消、多回路稳态误差、Bode图反求传函、离散系统、状态空间建模、能控能观与极点配置、非线性平衡点稳定；方框图与曲线图较多，图题只写结构性步骤，具体拓扑需回原卷核对。

一一、结构图与扰动补偿、二阶指标20 分#

思路
  • 由方框图分别写开环及扰动通道传函；令扰动到输出传函为零定 G4；再把给定通道化为二阶标准形，用超调量与调节时间反求 k、k3，最后按阻尼比不小于 1 定 k 范围。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 由方框图求扰动作用下输出与误差传函，并设计补偿使扰动影响为零
本卷实例
  • 关键一步：按扰动单独作用把参考输入置零，理清扰动到输出的各条通路
  • 关键一步：由梅森公式或逐层化简写出扰动传函
  • 中间结果：令扰动到输出传函的分子为零，得到补偿环节应满足的关系式
  • 卡点：方框图为原卷插图，补偿点与反馈极性需回原卷核对图
  • 卡点：把扰动传函与给定传函的输入置零条件弄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过由方框图求扰动作用下输出与误差传函，并设计补偿使扰动影响为零
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
反馈校正与复合控制 系统校正
本卷考法
  • 按不变性原理确定前馈补偿环节 G4 的传递函数
本卷实例
  • 关键一步：把扰动到输出的传函写成两条前向通路之比
  • 关键一步：令其分子恒为零反推 G4 的表达式
  • 中间结果：补偿环节由扰动通道与给定通道对应环节的比值确定
  • 卡点：前馈补偿器可能含微分或超前项，需说明物理可实现性
  • 卡点：图题未读图，具体通路增益需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过按不变性原理确定前馈补偿环节 G4 的传递函数
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函化为二阶标准形，读取无阻尼自然频率与阻尼比
本卷实例
  • 关键一步：把闭环特征多项式与 s 平方加两倍阻尼乘自然频率 s 加自然频率平方对照
  • 关键一步：由常数项与一次项系数分别读出两个参数
  • 中间结果：一次项系数对应两倍阻尼乘自然频率，常数项对应自然频率平方
  • 卡点：未把 s 平方项系数归一就直接对照
  • 卡点：把开环增益与闭环常数项混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函化为二阶标准形，读取无阻尼自然频率与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由最大超调量和调节时间要求反求 k 与 k3
本卷实例
  • 关键一步：由超调量指标先定阻尼比，再由调节时间指标定自然频率
  • 关键一步：把得到的阻尼比和自然频率回代系数关系解参数
  • 中间结果：二阶系统两个待求参数分别由阻尼比关系与自然频率关系确定
  • 卡点：调节时间的误差带百分比不同会改变公式系数；题目取百分之五
  • 卡点：最后单调收敛条件为阻尼比不小于 1，方向不能写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由最大超调量和调节时间要求反求 k 与 k3
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式

二二、稳定性与零极点对消20 分#

思路
  • 先写 G0 与 H 串联后的开环传函，注意零极点对消；再列闭环特征方程用劳斯判据求稳定范围；第三问令 s=s1−1 将虚轴平移至 s=−1，对新特征式再用劳斯判据。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断不同 G0 与 H 组合下闭环系统的稳定性
本卷实例
  • 关键一步：先写出闭环特征多项式，按降幂排列并补齐缺项
  • 关键一步：列劳斯表，令首列各项同号求参数范围
  • 中间结果：首列元素的不等式组决定使系统稳定的参数区间
  • 卡点：零极点对消后系统阶数下降，判稳对象随之改变
  • 卡点：首列出现零时需用无穷小量法处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断不同 G0 与 H 组合下闭环系统的稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求闭环特征根全部位于 s 等于负一垂线左侧的参数范围
本卷实例
  • 关键一步：令新变量等于原变量加一，把边界垂线平移到虚轴
  • 关键一步：把代换后的特征方程整理成新变量的多项式
  • 中间结果：平移后系统稳定的参数范围即原根全部位于给定垂线左侧的条件
  • 卡点：代换方向写成新变量减一会把边界移到另一侧
  • 卡点：平移后仍需补零列劳斯表
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求闭环特征根全部位于 s 等于负一垂线左侧的参数范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
零极点分布与响应模态 传递函数
本卷考法
  • 分析开环零极点对消对输入输出稳定与内部稳定的影响
本卷实例
  • 关键一步：比较约简前后特征方程的根
  • 关键一步：区分传递函数极点与系统全部状态模态
  • 中间结果：对消掉的不稳定极点不出现在输入输出传函中，但影响内部稳定
  • 卡点：把传递函数稳定等同于状态稳定
  • 卡点：图题未读图，G0 与 H 的连接方式需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过分析开环零极点对消对输入输出稳定与内部稳定的影响
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

三三、多回路系统与稳态误差20 分#

思路
  • 按反馈等效求开环与闭环传函及特征方程，用劳斯判据求 K 范围；由已知闭环极点代入特征方程求 K，再做多项式除法求其余极点；最后由误差传函按组合输入求稳态误差与稳态输出。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 逐层化简含局部反馈的方框图并整理闭环特征方程
本卷实例
  • 关键一步：把最内层反馈环等效成一个环节
  • 关键一步：由外到内逐层合并，写出开环传函
  • 中间结果：闭环特征方程由化简后的开环传函分母加分子得到
  • 卡点：内外环层次与引出点支路需回原卷核对图
  • 卡点：化简时漏乘某条支路增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过逐层化简含局部反馈的方框图并整理闭环特征方程
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
劳斯判据 稳定性分析
本卷考法
  • 求使该多回路系统稳定的参数 K 取值范围
本卷实例
  • 关键一步：把闭环特征方程按 K 合并同类项
  • 关键一步：列劳斯表并由首列同号列不等式组
  • 中间结果：稳定范围由劳斯表首列若干线性不等式取交集确定
  • 卡点：把 K 的范围端点开闭写错
  • 卡点：未先确认特征方程次数与缺项情况
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过求使该多回路系统稳定的参数 K 取值范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由误差传递函数计算组合输入下的稳态误差与稳态输出
本卷实例
  • 关键一步：先确认系统在所求参数下稳定，再用终值定理
  • 关键一步：把组合输入拆成阶跃与斜坡分量分别求误差
  • 中间结果：稳态输出等于输入稳态值减去稳态误差
  • 卡点：未判稳就代入终值定理
  • 卡点：组合输入漏掉其中某一分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由误差传递函数计算组合输入下的稳态误差与稳态输出
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

四四、Bode图反求传函与裕度20 分#

思路
  • 由低频段斜率与过点确定系统型别和增益，按转折频率补上零极点写出开环传函；由传函表达式画相频曲线并求剪切频率和相角裕度；判稳后由误差系数求给定输入的稳态误差。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由最小相位系统 Bode 图反求开环传递函数
本卷实例
