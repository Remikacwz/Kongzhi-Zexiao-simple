一一、方框图化简、多输入传函与参数稳定域35 分#

思路
  • 先由虚框内四个环节按回路结构写出对象等效传函与开环传函，再分别令参考输入与扰动单独作用求四个传函；最后由闭环特征方程列劳斯表定控制器参数范围，并按组合输入求稳态误差。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由方框图求对象等效传函与开环传函
本卷实例
  • 关键一步：按回路增益与互不接触关系写出特征式
  • 关键一步：把四个环节代入特征式并整理成真分式
  • 中间结果：对象由两个惯性环节串联构成
  • 中间结果：开环传函由控制器与对象串联相乘得到
  • 卡点：需回原卷核对图一虚框内环节的连接方式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由方框图求对象等效传函与开环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

多输入与扰动作用下的传递函数 结构图与方框图

本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤

  • 令 N(s)=0，求输入到输出的传递函数

通用考法

常见易错

  • 求扰动传函时没有把参考输入置零

二二、奈氏判稳、串联校正与局部反馈校正30 分#

思路
  • 按给定参数写开环传函画奈氏曲线并用奈氏判据判稳；再由校正后开环特性求剪切频率与相角裕量并判超前或滞后作用；最后按局部反馈等效求稳态误差与超调量。
奈奎斯特判据 稳定性分析
本卷考法
  • 画开环奈氏曲线并用奈奎斯特判据判别闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数 P
  • 关键一步：再数曲线对临界点的包围圈数 N，由 Z 等于 P 加 N 求闭环右半极点数
  • 中间结果：开环含两个积分环节，曲线位于负实轴附近
  • 中间结果：曲线经过临界点时系统临界稳定
  • 卡点：需回原卷核对图二中局部反馈与校正环节的接入位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过画开环奈氏曲线并用奈奎斯特判据判别闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

开环对数频率特性的绘制 频域分析
本卷考法
  • 画校正后开环伯德图并计算剪切频率
本卷实例
  • 关键一步：由低频段斜率定型别，由转折频率逐段叠加斜率
  • 关键一步：令幅值等于一解出剪切频率
  • 中间结果：低频段延长线与零分贝线交点给出增益
  • 中间结果：一阶微分环节使中频段相位抬高
  • 卡点：需回原卷核对图二中校正环节所在回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过画校正后开环伯德图并计算剪切频率
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

稳定裕度 频域分析
本卷考法
  • 计算相角裕量并判断超前或滞后校正作用
本卷实例
  • 关键一步：在剪切频率处代入相频表达式求相角裕量
  • 关键一步：由校正网络在全频段的相角正负判断作用
  • 中间结果：相角裕量为一百八十度加剪切频率处相角
  • 中间结果：校正网络相角为正即为超前作用
  • 卡点：剪切频率须由校正后开环特性确定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过计算相角裕量并判断超前或滞后校正作用
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由等效二阶系统计算超调量
本卷实例
  • 关键一步：由标准二阶形式读出阻尼比
  • 关键一步：代入超调量公式估算超调量
  • 中间结果：超调量只由阻尼比决定
  • 中间结果：自然频率由等效开环参数确定

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤

  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由等效二阶系统计算超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

思路

李雅普诺夫稳定性分析 状态空间分析
本卷考法

本卷实例

  • 关键一步：在平衡状态处求雅可比矩阵并求特征值
  • 中间结果：雅可比矩阵特征值为一对纯虚根

通用考法

常见易错
  • 仅调整增益而不检查是否引入新的自振点
