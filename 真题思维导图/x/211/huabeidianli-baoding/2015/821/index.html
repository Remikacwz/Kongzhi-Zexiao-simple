一一、结构图补偿与延迟近似#

思路
  • 由结构图选补偿装置使静态误差为零并改善调节时间，再用给定近似公式把含延迟对象降为无延迟形式，最后用劳斯判据确定补偿参数的稳定范围。
减小稳态误差的措施 稳态误差
本卷考法
  • 选择补偿装置Gc(s)使单位阶跃静差为零并减小调节时间
本卷实例
  • 关键一步：由静差为零判断补偿装置须含积分环节
  • 关键一步：由调节时间要求判断需改变开环增益或阻尼
  • 中间结果：补偿后开环含一个积分环节
  • 中间结果：闭环阻尼比与自然频率随补偿参数变化
  • 卡点：结构图为原卷插图，被控对象与反馈极性需回原卷核对图
  • 卡点：把补偿装置的最简结构与串联校正类型混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过选择补偿装置Gc(s)使单位阶跃静差为零并减小调节时间
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式
典型环节及其特性 传递函数
本卷考法
  • 按题给近似公式把含延迟的被控对象化为无延迟的惯性环节
本卷实例
  • 关键一步：把延迟加惯性写成ke^-τs除以(Ts+1)^n的形式
  • 关键一步：由n1T1约等于nT+τ及取整规则确定n1与T1
  • 中间结果：近似后对象阶数下降，延迟被并入时间常数
  • 卡点：四舍五入取整规则用错导致n1偏差
  • 卡点：近似公式中τ与t符号相似易抄错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过按题给近似公式把含延迟的被控对象化为无延迟的惯性环节
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求使近似后系统稳定的补偿参数范围
本卷实例
  • 关键一步：写出闭环特征方程并整理成降幂多项式
  • 关键一步：列劳斯表并要求首列同号
  • 中间结果：稳定条件化为关于补偿参数的不等式组
  • 卡点：系数缺项未补零
  • 卡点：选伪代码方案时未先给出特征方程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求使近似后系统稳定的补偿参数范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由调节时间要求分析补偿参数对系统快速性的影响
本卷实例
  • 关键一步：把闭环特征方程一次项与常数项对应到阻尼与自然频率
  • 关键一步：由调节时间与实部成反比判断参数变化方向
  • 中间结果：调节时间随闭环实部绝对值增大而减小
  • 卡点：忽略延迟环节使实际调节时间大于计算值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由调节时间要求分析补偿参数对系统快速性的影响
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式

二二、扰动补偿与物理可实现性#

思路
  • 由多回路结构图分别求扰动到输出的传函，令其为零求不变性补偿Gf(s)，再由分子阶次高于分母判断物理不可实现，最后用初值与终值定理画补偿输出曲线。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 由结构图求扰动R2到输出的传函并令其为零求补偿Gf(s)
本卷实例
  • 关键一步：把参考输入置零只保留扰动通道
  • 关键一步：按梅森公式写出扰动到输出的传函
  • 中间结果：扰动传函分子含Gf与G01之积加G02
  • 中间结果：令分子为零即得不变性条件
  • 卡点：求扰动传函时未把参考输入置零
  • 卡点：回路增益与通路增益混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过由结构图求扰动R2到输出的传函并令其为零求补偿Gf(s)
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
反馈校正与复合控制 系统校正
本卷考法
  • 由扰动不变性条件求前馈补偿器Gf(s)的表达式
本卷实例
  • 关键一步：令扰动误差传函为零解出Gf(s)
  • 关键一步：检查所得Gf(s)是否物理可实现
  • 中间结果：Gf(s)由两条对象通道之比决定
  • 卡点：把前馈补偿与反馈校正混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过由扰动不变性条件求前馈补偿器Gf(s)的表达式
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
公式
传递函数的定义与基本性质 传递函数
本卷考法
  • 由分子阶次高于分母阶次证明Gf(s)物理不可实现
本卷实例
  • 关键一步：比较Gf(s)分子与分母的阶数
  • 关键一步：从因果性与所需微分阶次说明不可实现
  • 中间结果：分子阶次高于分母时反变换含冲激的导数项
  • 卡点：只比较系数大小而未比较分子分母阶次
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由分子阶次高于分母阶次证明Gf(s)物理不可实现
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 用初值定理与终值定理求补偿输出曲线的初值与终值
本卷实例
  • 关键一步：先作部分分式展开再逐项反变换
  • 关键一步：用s趋于无穷与s趋于零求初值与终值
  • 中间结果：输出含冲激与指数衰减两类分量
  • 中间结果：初值可能无穷而终值为有限常数
  • 卡点：终值定理须先确认极点不在右半平面
  • 卡点：把冲激项的初值当成有限值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过用初值定理与终值定理求补偿输出曲线的初值与终值
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

三三、二阶指标反求kp与ki#

思路
  • 先用给定近似公式把二阶对象降阶，写出含PI控制的开环传函，再由静差为零、超调量和调节时间要求联立求kp与ki的范围及关系。
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 按近似公式把二阶对象降阶为一阶惯性环节
本卷实例
  • 关键一步：识别对象为k除以(Ts+1)^n的形式
  • 关键一步：由nT约等于n1T1确定降阶后的时间常数
  • 中间结果：降阶后对象为一阶，便于按典型二阶公式估算
  • 卡点：忽略闭环零点对动态性能的影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过按近似公式把二阶对象降阶为一阶惯性环节
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 写出含PI控制器的闭环传函并化为二阶标准形
本卷实例
  • 关键一步：先写开环传函再求闭环传函
  • 关键一步：把分母整理成s平方加2阻尼自然频率s加自然频率平方
  • 中间结果：阻尼比与自然频率均由kp、ki表示
  • 卡点：未把s平方项系数归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过写出含PI控制器的闭环传函并化为二阶标准形
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量小于百分之二十确定阻尼比下界
本卷实例
  • 关键一步：由超调量公式反解阻尼比
  • 关键一步：取临界超调量对应的阻尼比为边界
  • 中间结果：超调量给定值对应一个确定的阻尼比下界
  • 卡点：超调量公式漏乘百分之百或角度用错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn

本卷考法
  • 用零阶保持器法按给定步距求对象离散状态方程
本卷实例
  • 关键一步：按题给近似式求状态转移矩阵
  • 关键一步：按题给近似式求输入矩阵
  • 中间结果：离散状态方程由近似后的状态矩阵与输入矩阵给出
  • 卡点：积分上限写成采样周期以外的量
  • 卡点：离散化时漏乘输入矩阵
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离散化状态方程由状态转移矩阵在采样周期处的取值构成
  • 输入矩阵是状态转移矩阵与输入矩阵乘积在采样周期上的积分
  • 带零阶保持器时即按上述积分式离散化，输出矩阵不变
步骤
  • 求连续系统的状态转移矩阵
  • 把采样周期代入得到离散状态矩阵
  • 对输入矩阵做积分得到离散输入矩阵
  • 写出差分形式的离散状态方程并按递推求采样点上的响应
通用考法
  • 本卷考过用零阶保持器法按给定步距求对象离散状态方程
  • 求连续系统在给定采样周期下的离散化状态方程
  • 由给出的状态响应反求系统矩阵再离散化
  • 计算采样点上的状态与输出序列
常见易错
  • 把采样周期直接当成时间常数代进连续传函
  • 积分上限写成采样周期以外的量，或忘记乘输入矩阵
