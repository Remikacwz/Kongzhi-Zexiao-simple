一一、机械位移系统建模与不振荡条件12 分#

思路
  • 由牛顿第二定律列机械位移系统微分方程并整理为传递函数，再由系统不振荡条件确定阻尼系数的取值范围。
机械系统建模 建模与机电系统
本卷考法
  • 由牛顿第二定律列弹簧质量阻尼系统微分方程
本卷实例
  • 关键一步：把合力写成输入力减弹簧力再减阻尼力
  • 关键一步：按质量乘加速度列方程
  • 中间结果：得到二阶线性微分方程
  • 卡点：阻尼力与弹簧力方向取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过由牛顿第二定律列弹簧质量阻尼系统微分方程
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
传递函数的定义与基本性质 传递函数
本卷考法
  • 由微分方程在零初始条件下求传递函数
本卷实例
  • 关键一步：对方程两边取拉氏变换
  • 关键一步：按输出比输入整理成s的有理分式
  • 中间结果：分母由质量弹簧阻尼参数组成
  • 卡点：未用零初始条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由微分方程在零初始条件下求传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由不振荡条件确定阻尼系数的取值范围
本卷实例
  • 关键一步：把特征方程化标准二阶形式
  • 关键一步：要求阻尼比大于等于1
  • 中间结果：不振荡条件化为f的不等式
  • 卡点：把临界阻尼与欠阻尼边界取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由不振荡条件确定阻尼系数的取值范围
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

二二、方框图闭环传函与动态性能15 分#

思路
  • 由单位负反馈方框图求闭环传递函数，化为标准二阶形式求调节时间与超调量，并由超调量要求确定积分增益并画响应草图。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 求单位负反馈系统的闭环传递函数
本卷实例
  • 关键一步：写出前向通道与反馈通道
  • 关键一步：按分母1加开环整理闭环传函
  • 中间结果：闭环为二阶系统形式
  • 卡点：分母误写成1减开环
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过求单位负反馈系统的闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求单位阶跃输入下系统的调节时间
本卷实例
  • 关键一步：由阻尼比与自然频率确定误差带系数
  • 关键一步：按对应误差带代入调节时间公式
  • 中间结果：调节时间只由ξ与ωn之积决定
  • 卡点：把两种误差带的系数混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法

  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用

三三、多回路化简与扰动稳态误差30 分#

思路
  • 化简多回路方框图求开环与特征方程并判稳，再分别在参考输入与扰动单独作用下求闭环与误差传函，最后求两者同时作用下的稳态误差并设计消除扰动的控制器。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由多回路方框图化简求开环传递函数与特征方程
本卷实例
  • 关键一步：先化简内环再串外环
  • 关键一步：按比较点信号关系写出开环传函
  • 中间结果：特征方程由开环传函分母加分子得到
  • 卡点：化简内环时把外环信号当常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由多回路方框图化简求开环传递函数与特征方程
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断系统稳定性
本卷实例
  • 关键一步：由特征多项式列劳斯表
  • 关键一步：检查首列元素是否全同号
  • 中间结果：首列全同号对应闭环稳定
  • 卡点：系数缺项时未补零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断系统稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求参考输入与扰动单独作用下的闭环传递函数
本卷实例

  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求参考输入与扰动单独作用下的闭环传递函数

  • 分析满足扰动不变性的补偿条件
常见易错

  • 求扰动传函时没有把参考输入置零

误差定义与误差传递函数 稳态误差
本卷考法
  • 写出参考输入与扰动作用下的误差传递函数
本卷实例
  • 关键一步：按误差定义写E(s)与R(s)、N(s)的关系
  • 关键一步：非单位反馈时注意反馈通道的影响
  • 中间结果：误差传函分为参考通道与扰动通道
  • 卡点：两种误差定义混用导致差一个H(s)
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写出参考输入与扰动作用下的误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

扰动作用下的稳态误差 稳态误差
本卷考法
  • 求参考输入与扰动同时作用下的稳态误差
本卷实例
  • 关键一步：先判稳再按终值定理取极限
  • 关键一步：分别求参考分量与扰动分量后求和
  • 中间结果：总误差为两个分量之和
  • 卡点：把扰动误差当成总误差，漏掉输入分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求参考输入与扰动同时作用下的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

反馈校正与复合控制 系统校正
本卷考法
  • 重新设计控制器使扰动对输出的影响完全消除
本卷实例
  • 关键一步：令扰动到输出的传函为零
  • 关键一步：由该条件解出待设计控制器的表达式
  • 中间结果：控制器由扰动通道传函的倒数给出
  • 卡点：只让某条通路为零而漏掉分母
