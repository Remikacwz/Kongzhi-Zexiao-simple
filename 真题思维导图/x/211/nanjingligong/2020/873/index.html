1第1题 机械系统建模求传函#

思路
  • 对弹簧质量阻尼系统分别列牛顿第二定律，作拉氏变换消去中间变量，求输出位移对输入位移的传递函数。题面含图未读图。
机械系统建模 建模与机电系统
本卷考法
  • 弹簧质量阻尼系统求位移对输入的传函
本卷实例
  • 关键一步：对各质量块列牛顿第二定律并作拉氏变换
  • 中间结果：阻尼力与弹簧力按相对位移写
  • 卡点：阻尼力与弹簧力正负方向取反；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过弹簧质量阻尼系统求位移对输入的传函
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项

2第2题 扰动作用下的稳态误差#

思路
  • 由结构图分别求参考输入引起的误差与扰动引起的误差，检验系统稳定性后用终值定理，再把两个分量叠加得总稳态误差。题面含图未读图。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 在参考输入与扰动同时作用下求误差
本卷实例
  • 关键一步：分别令单路作用求误差再叠加
  • 中间结果：误差由输入分量与扰动分量组成
  • 卡点：求扰动传函时未把参考输入置零；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过在参考输入与扰动同时作用下求误差
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

  • 卡点：把扰动误差直接当作总误差

  • 扰动误差取决于扰动作用点到误差点的传递函数

步骤

  • 代入扰动信号求稳态值

通用考法
  • 本卷考过求扰动引起的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

本卷考法
  • 求参考输入下的稳态误差
本卷实例

  • 中间结果：误差分量由输入类型与系统型别决定
  • 卡点：输入为组合信号时漏掉某一分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

3第3题 测速反馈校正参数与调节时间#

思路
  • 由速度误差系数要求与闭环阻尼比要求分别列方程，联立求两个反馈参数；再按阻尼比与自然频率求调节时间。题面含图未读图。
系统型别与静态误差系数 稳态误差
本卷考法
  • 由速度误差系数要求列方程
本卷实例
  • 关键一步：按开环型别写静态速度误差系数
  • 中间结果：速度误差系数给出两参数的一个关系
  • 卡点：把开环增益与静态误差系数混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由速度误差系数要求列方程
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环阻尼比求反馈系数
本卷实例
  • 关键一步：把闭环特征式化为标准二阶式比较系数
  • 中间结果：阻尼比条件给出另一个关系式
  • 卡点：未先把s平方项系数归一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环阻尼比求反馈系数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率求调节时间
本卷实例
  • 关键一步：按给定误差带代入调节时间公式
  • 中间结果：调节时间与阻尼比和自然频率成反比
  • 卡点：把两种误差带的调节时间系数搞混；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数

  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错

  • 峰值时间与上升时间混用

4第4题 以时间常数为参变量的根轨迹#

思路
  • 把特征方程整理成以时间常数τ为参变量的等效根轨迹方程，按绘制法则画出τ从零到无穷变化的根轨迹草图。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以时间常数τ为参变量绘制参数根轨迹
本卷实例
  • 关键一步：把特征方程整理成1加τ乘某式等于零
  • 中间结果：等效系统的开环零极点由整理结果读出
  • 卡点：整理时未把参数完整提到分子位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以时间常数τ为参变量绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画参数根轨迹草图
本卷实例
  • 关键一步：用渐近线、实轴段与分离点定形状
  • 中间结果：根轨迹起于等效开环极点止于等效开环零点
  • 卡点：实轴段判据中的零极点个数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画参数根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

5第5题 由幅相曲线反求传函并判稳#

思路
  • 由三阶最小相位系统的幅相曲线形状与已知特征点反求开环传函，再由最小相位条件确定形式，最后用奈氏判据判断给定增益下的稳定性。题面含图未读图。
频率特性的物理意义与求法 频域分析
本卷考法
  • 由给定幅相曲线与特征点反求开环传函
本卷实例
  • 关键一步：由曲线形状定环节类型再按已知点定参数
  • 中间结果：开环含一个积分环节与两个惯性环节
  • 卡点：把曲线上的已知点与频率对应错；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由给定幅相曲线与特征点反求开环传函
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
最小相位系统与非最小相位系统 频域分析
本卷考法
  • 利用最小相位条件确定传函形式
本卷实例
  • 关键一步：由最小相位排除右半平面零极点
  • 中间结果：传函形式由低频与高频段渐近行为确定
  • 卡点：以为幅频特性可唯一确定传递函数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过利用最小相位条件确定传函形式
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈
奈奎斯特判据 稳定性分析

思路
  • 先由状态方程求平衡状态，再构造正定函数并求沿轨线的导数，由导数负定判断平衡状态的稳定性。
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 用李雅普诺夫第二法判断非线性系统平衡状态稳定性
本卷实例
  • 关键一步：构造正定函数并求沿轨线导数的符号
  • 中间结果：导数负定说明平衡状态渐近稳定
  • 卡点：只判函数正定而未检查其导数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法

  • 分析非线性系统的稳定性范围

  • 只判断 V 正定就下结论而未检查导数

本卷实例
  • 关键一步：先由方程求平衡状态再作稳定性判断
  • 中间结果：非线性系统可能有多个平衡状态
  • 卡点：把平衡状态稳定与系统稳定混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过说明非线性系统稳定性分析的特点
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
