1第1题 多回路结构图求传函#

思路
  • 由结构图按梅森公式列前向通路与各独立回路求 Y(s)/R(s)；各回路两两均接触时特征式只含回路增益一次项。题面含图未读图。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式由结构图求闭环传递函数
本卷实例
  • 关键一步：按前向通路与各独立回路列分子和特征式
  • 中间结果：各回路两两均接触，特征式只含单回路项
  • 卡点：反馈极性或回路接触判断错；结构图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式由结构图求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层等效化简
本卷实例
  • 关键一步：从最内层反馈环起逐层化简
  • 中间结果：化简后只剩一条主前向通路与几条回路
  • 卡点：漏掉交叉回路会使特征式少项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层等效化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2第2题 脉冲响应与阶跃稳态误差#

思路
  • 由两环节串联写开环传函，作部分分式后拉氏反变换得单位脉冲响应；再写闭环传函由终值定理求阶跃稳态输出，最后按误差传递函数反求满足误差限的增益。
传递函数的定义与基本性质 传递函数
本卷考法
  • 由开环传函拉氏反变换求单位脉冲响应
本卷实例
  • 关键一步：先将传函部分分式分解再逐项反变换
  • 中间结果：脉冲响应为两条衰减指数项的代数和
  • 卡点：部分分式系数符号写反导致响应全错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由开环传函拉氏反变换求单位脉冲响应
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由终值定理求阶跃输入下的稳态输出
本卷实例
  • 关键一步：先判断闭环稳定再对输出取终值
  • 中间结果：稳态输出等于输入幅值乘闭环直流增益
  • 卡点：系统未判稳就使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由终值定理求阶跃输入下的稳态输出
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 由误差传递函数反求满足误差限的增益
本卷实例
  • 关键一步：写出误差传函并代入误差限解增益
  • 中间结果：误差限化成关于增益的一次方程
  • 卡点：非单位反馈时误差定义选错致差一个环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过由误差传递函数反求满足误差限的增益
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

3第3题 斜坡误差与劳斯判据联立#

思路
  • 开环为三阶Ⅰ型，按速度误差系数写斜坡稳态误差要求得增益下界；再由闭环特征方程用劳斯判据求稳定域，两个条件取交集判断是否存在满足的增益。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由速度误差系数写斜坡稳态误差要求
本卷实例
  • 关键一步：按Ⅰ型系统写速度误差系数并代入误差限
  • 中间结果：误差要求化为对增益的下界约束
  • 卡点：把斜坡误差与阶跃误差公式混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由速度误差系数写斜坡稳态误差要求
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求闭环稳定的增益范围
本卷实例
  • 关键一步：列劳斯表并令首列元素均为正
  • 中间结果：稳定条件给出增益的上界
  • 卡点：系数有缺项时未补零就直接套判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求闭环稳定的增益范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 比较误差与稳定的两个不等式判断是否有解
本卷实例
  • 关键一步：把误差下界与稳定上界在同一数轴上取交集
  • 中间结果：两区间无交集说明不存在满足条件的增益
  • 卡点：只报稳定范围而漏答误差条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过比较误差与稳定的两个不等式判断是否有解
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

4第4题 参数根轨迹两问#

思路
  • 先由闭环特征方程分离出以增益为变量的等效开环传函，按法则画 0→∞ 根轨迹并求分离点与虚轴交点；再由两个临界增益写出衰减振荡区间。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 由特征方程整理出以开环增益为变量的参数根轨迹
本卷实例
  • 关键一步：把特征方程整理成一加等效开环等于零的形式
  • 中间结果：等效开环为增益除以含重极点的多项式
  • 卡点：参数未完整提到分子位置导致根轨迹形状错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过由特征方程整理出以开环增益为变量的参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则画含重极点的根轨迹
本卷实例
  • 关键一步：定实轴段、渐近线夹角与渐近线交点
  • 中间结果：三条分支起于原点与重极点处
  • 卡点：把重极点当成两个独立极点重复计数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则画含重极点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求分离点并由幅值条件定临界增益
本卷实例
  • 关键一步：由极点倒数和列分离点方程再回代幅值条件
  • 中间结果：分离点处给出一个临界增益
  • 卡点：不筛选就直接保留方程的重根解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求分离点并由幅值条件定临界增益
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由虚轴交点求等幅振荡的临界增益
本卷实例
  • 关键一步：令s=jω代入特征方程实部虚部分别为零
  • 中间结果：虚轴交点频率与另一临界增益联立得到
  • 卡点：只代一个频率值就下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由虚轴交点求等幅振荡的临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式

5第5题 含延迟系统的幅值裕度#

思路
  • 含纯延迟的开环传函写幅相后，由虚部为零求与实轴交点频率，再由幅值裕度大于 2 的条件反求增益上界。
含纯延迟环节的系统稳定性 稳定性分析
本卷考法
  • 求含纯延迟系统的相位穿越频率与临界增益
本卷实例
  • 关键一步：延迟环节相角为频率乘延迟时间取负
  • 中间结果：与实轴交点的频率由余弦为零确定
  • 卡点：把延迟环节当成惯性环节处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 延迟环节 e^{-τs} 的幅值为 1、相位为 -τω，只恶化相位
  • 延迟会显著缩小稳定域，τ 越大越难稳定
  • 频域判据需用相位裕度扣除延迟引起的附加滞后
步骤
  • 写出含延迟的开环传递函数
  • 分别求幅值与相位表达式
  • 在相频特性中扣除 τω 的滞后量
  • 按稳定裕度或奈氏判据求临界 τ 或临界 K
通用考法
  • 本卷考过求含纯延迟系统的相位穿越频率与临界增益
  • 求使系统稳定的最大延迟时间
  • 求含延迟系统的临界开环增益
  • 分析延迟对稳定裕度的影响
常见易错
  • 把延迟环节当成惯性环节处理
  • 相位计算时忘记角度与弧度换算

  • 幅频特性表示各频率正弦输入下的幅值放大倍数

稳定裕度 频域分析
本卷考法
  • 由幅值裕度要求反求增益上界
本卷实例
  • 关键一步：先求穿越频率处幅值再按裕度定义列式
  • 中间结果：裕度大于二化为增益小于某常数
  • 卡点：幅值裕度取倒数方向弄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由幅值裕度要求反求增益上界
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

思路

  • 中间结果：负倒轨迹沿负实轴随幅值单调移动

思路
  • 由给定状态矩阵、输入矩阵与输出矩阵求传函；再由传函写能控标准型；在能控标准型上用状态反馈比较特征式配置指定极点。
状态空间与传递函数的关系 状态空间分析
本卷考法

本卷实例

  • 中间结果：传函为真分式，分母为状态矩阵特征多项式

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法

  • 由状态空间表达式求传递函数

  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

思路

状态空间表达式的建立 状态空间分析
本卷考法

本卷实例

  • 中间结果：状态方程含速度项、线性阻尼项与非线性平方项
