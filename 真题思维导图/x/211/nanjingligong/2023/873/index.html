1第1题 信号流图与梅森公式求传函#

思路
  • 由方程组确定各变量之间的输入输出关系，按源节点 x1、阱节点 x6 画信号流图；再用梅森公式求总传函，注意找出全部独立回路与不接触回路。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由方程组画信号流图并用梅森公式求传函
本卷实例
  • 关键一步：按变量依赖关系逐支连线并标出各支路增益
  • 中间结果：找出三个独立回路并识别互不接触的回路对
  • 卡点：不接触回路找漏导致特征式少一项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由方程组画信号流图并用梅森公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
传递函数的定义与基本性质 传递函数
本卷考法
  • 由代数关系确定各支路增益
本卷实例
  • 关键一步：把方程组每个等式改写成一条支路关系
  • 中间结果：两条前向通路分别过 a-b-c-d-e 与 f-d-e
  • 卡点：源节点与阱节点选错导致通路遗漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由代数关系确定各支路增益
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

2第2题 多输入作用下的稳态误差#

思路
  • 分别求参考输入与扰动输入到误差的传函；参考输入用终值定理求稳态误差，扰动为正弦量须改用频率特性求稳态响应。
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动引起的稳态误差
本卷实例
  • 关键一步：求扰动误差时把参考输入置零
  • 中间结果：扰动通道传函分子为零则扰动误差为零
  • 卡点：把扰动引起的误差直接当作总误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求扰动引起的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求参考与扰动两条通道的传函
本卷实例
  • 关键一步：按叠加原理分别求两条通道的误差传函
  • 中间结果：总稳态误差为两个分量之和
  • 卡点：未验证系统线性性就直接叠加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求参考与扰动两条通道的传函
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 正弦扰动下的稳态误差用频率特性求
本卷实例
  • 关键一步：对正弦扰动改用频率特性而非终值定理
  • 中间结果：高频正弦扰动被系统大幅衰减
  • 卡点：对正弦输入误用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过正弦扰动下的稳态误差用频率特性求
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式

3第3题 根轨迹四问与主导极点#

思路
  • 按根轨迹法则画 0→∞ 根轨迹；由分离点与虚轴交点定阻尼振荡和等幅振荡的 K 范围与频率；再由给定阻尼比求主导极点并比较系数定 K。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制 K 从0到+∞变化的根轨迹
本卷实例
  • 关键一步：由三个开环极点定分支数、实轴段与渐近线
  • 中间结果：确定三条渐近线的交点与夹角
  • 卡点：实轴段判据中零极点个数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制 K 从0到+∞变化的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 由分离点求阻尼振荡响应的临界增益
本卷实例
  • 关键一步：解分离点方程并用幅值条件回代求 K
  • 中间结果：由分离点方程定出两个分离点及临界增益
  • 卡点：把不在根轨迹上的根也当成分离点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由分离点求阻尼振荡响应的临界增益
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求与虚轴交点及持续等幅振荡参数
本卷实例
  • 关键一步：令 s=jω 代入特征方程分离实部虚部
  • 中间结果：由虚部为零解出交点角频率与临界增益
  • 卡点：只代一个 ω 就下结论而漏掉另一组
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求与虚轴交点及持续等幅振荡参数
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由阻尼比确定主导极点与 K 值
本卷实例
  • 关键一步：由阻尼比0.5写主导复极点并设第三个实极点
  • 中间结果：由根之和与系数比较解出 a、b 及 K
  • 卡点：复数极点须成对代入且满足根之和
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由阻尼比确定主导极点与 K 值
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 判断系统是否存在主导极点
本卷实例
  • 关键一步：比较两个近原点极点与远离极点的距离
  • 中间结果：近原点的一对复极点为主导极点
  • 卡点：只看极点距离而不看其留数大小
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过判断系统是否存在主导极点
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

4第4题 串联环节改造系统型别#

思路
  • 先按结构图写校正后闭环传函，再反求等效开环传函；令等效开环分母只保留 s³ 项，消去 s²、s 项，联立解出 a、b 使系统变为 III 型。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由结构图逐层化简求等效开环传函
本卷实例
  • 关键一步：由闭环传函反求等效开环 G=Φ/(1-Φ)
  • 中间结果：等效开环分母含 s、s²、s³ 三项
  • 卡点：结构图未读图，串联环节接入位置需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由结构图逐层化简求等效开环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
系统型别与静态误差系数 稳态误差
本卷考法
  • 由型别定义确定分母积分环节重数
本卷实例
  • 关键一步：III 型要求等效开环分母只保留 s³ 项
  • 中间结果：令 s²、s 项系数为零得两个方程
  • 卡点：型别由分母积分环节重数决定，不看分子
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由型别定义确定分母积分环节重数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 通过串联环节提高系统型别减小误差
本卷实例
  • 关键一步：用串联环节消去分母低次项以提升型别
  • 中间结果：令两个低次项系数为零联立解出 a、b
  • 卡点：提高型别会改变稳定性须一并检查
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差

9第9题 状态反馈极点配置可行性#

思路
  • 先构造能控性矩阵判能控；能控则设状态反馈 K，比较 A-BK 特征多项式与期望极点多项式求 K；不可控则说明理由。
能控性与能观性 状态空间分析
本卷考法
  • 构造能控性矩阵判断极点可否任意配置
本卷实例
  • 关键一步：用 B、AB、A²B 构造能控性矩阵并求秩
  • 中间结果：三阶满秩说明闭环极点可任意配置
  • 卡点：只算到 A^{n-2}B 就下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩

  • 不可控或不可观时进一步做结构分解
通用考法

  • 对不可控系统进行结构分解

10第10题 非线性系统李雅普诺夫第二法#

思路
  • 取正定二次型 V=x1²+x2²，沿系统轨迹求导；由 a>0 判断导数半负定，再验证其除原点外不恒为零，结合径向无界得大范围渐近稳定。
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 构造李雅普诺夫函数判断渐近稳定
本卷实例
  • 关键一步：取 V=x1²+x2² 并沿系统轨迹求 V̇
  • 中间结果：沿轨迹求导后化为仅含 x2 平方的半负定式
  • 卡点：只看 V 正定而不验证 V̇ 除原点外不恒为零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过构造李雅普诺夫函数判断渐近稳定
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错

  • 只判断 V 正定就下结论而未检查导数
