1第1题 结构图求闭环与误差传函15 分#

思路
  • 先用梅森公式由前向通路与独立回路求 C(s)/R(s)；再按误差定义 E=R-C 或直接用梅森公式求 E(s)/R(s)，注意两式共用同一特征式。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图用梅森公式求闭环传函
本卷实例
  • 关键一步：按前向通路与独立回路列梅森公式的分子与特征式
  • 中间结果：四条回路存在两两不接触项，特征式含回路增益乘积
  • 卡点：结构图未读图，回路接触关系与反馈极性需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图用梅森公式求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简求传函
本卷实例
  • 关键一步：从最内层反馈回路起逐层等效化简
  • 中间结果：内环等效后可清楚看出各前向通路
  • 卡点：化简时漏掉交叉反馈支路导致分母少项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简求传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
误差定义与误差传递函数 稳态误差
本卷考法
  • 由误差定义写出 E(s)/R(s)
本卷实例
  • 关键一步：先明确 E=R-C 再由 C/R 反推误差传函
  • 中间结果：误差传函与闭环传函共用同一特征式
  • 卡点：非单位反馈时两种误差定义相差一个反馈环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由误差定义写出 E(s)/R(s)
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

2第2题 由阶跃响应曲线反求二阶参数15 分#

思路
  • 由反应曲线读出超调量、峰值时间与稳态输出，联立求阻尼比与自然频率；再按结构图设闭环典型二阶形式，比较系数求 K1、K2、a。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应曲线反求二阶系统参数
本卷实例
  • 关键一步：把曲线上的超调量与峰值时间翻译成 ξ、ωn 的方程
  • 中间结果：稳态输出对应闭环直流增益，可先去 K1
  • 卡点：响应曲线未读图，峰值与时间刻度需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应曲线反求二阶系统参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量和峰值时间反求阻尼比与自然频率
本卷实例
  • 关键一步：联立超调量公式与峰值时间公式解出 ξ 与 ωn
  • 中间结果：ξ 只由超调量确定，ωn 再代入峰值时间式
  • 卡点：超调量公式漏乘100%或调节时间系数代入错误
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量和峰值时间反求阻尼比与自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为典型二阶形式比较系数
本卷实例
  • 关键一步：按结构图设 K1K2/(s²+as+K2) 与标准形式对照
  • 中间结果：闭环特征式系数与 ξ、ωn 的表达式对应
  • 卡点：未先把 s² 项系数归一化就直接比对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为典型二阶形式比较系数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

3第3题 由特征方程与稳态误差反求开环传函15 分#

思路
  • 单位阶跃误差为零判定为Ⅰ型系统；按开环无零点设 K/[s(s+p)(s+q)]，展开闭环特征式后与原特征方程比较系数求开环传函。
系统型别与静态误差系数 稳态误差
本卷考法
  • 由阶跃误差为零判定系统型别
本卷实例
  • 关键一步：阶跃输入稳态误差为零说明开环含一个积分环节
  • 中间结果：系统为Ⅰ型，静态位置误差系数趋于无穷
  • 卡点：须排除二阶无积分环节的退化情形
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由阶跃误差为零判定系统型别
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由稳态误差条件反求开环结构
本卷实例
  • 关键一步：由型别设开环传函结构再用系数比较定参数
  • 中间结果：开环为积分环节乘两个一阶环节
  • 卡点：开环增益与静态误差系数不是同一个量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由稳态误差条件反求开环结构
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
传递函数的定义与基本性质 传递函数
本卷考法
  • 由开环无零点条件确定传函形式
本卷实例
  • 关键一步：按无零点设分子为常数 K
  • 中间结果：闭环特征式由 1+G=0 展开得到
  • 卡点：未注意开环与闭环特征方程的对应关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由开环无零点条件确定传函形式
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

4第4题 根轨迹绘制与最小阻尼比15 分#

思路
  • 先由结构图写出开环传函及闭环特征方程；按根轨迹法则画 0→∞ 根轨迹；再由分离/会合点求临界增益，由原点作切线求最小阻尼比的极点与 K。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制 0→∞ 根轨迹
本卷实例
  • 关键一步：由开环零极点确定实轴段、渐近线与分支数
  • 中间结果：两条分支起于开环极点，终于零点与无穷远
  • 卡点：实轴段判据中零极点个数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制 0→∞ 根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 由分离点与会合点求临界增益
本卷实例
  • 关键一步：用分离点方程求 d 并用幅值条件回代筛选
  • 中间结果：两个临界增益把实轴与复轴响应对应起来
  • 卡点：不筛选就保留不在根轨迹上的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由分离点与会合点求临界增益
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由最小阻尼比确定对应极点与增益
本卷实例
  • 关键一步：由原点向根轨迹圆作切线确定最大阻尼角
  • 中间结果：切点对应最小阻尼比的闭环极点
  • 卡点：把等阻尼线当成垂直线处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由最小阻尼比确定对应极点与增益
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

5第5题 由奈氏图反求参数及相位穿越频率15 分#

思路
  • 令 s=jω 写出开环实部与虚部；由低频实轴截距和相位穿越条件分别建立方程，求系统参数及 ωx、a 与 k、T1、T2、T3 的关系。

  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求线性部分的幅相曲线
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

思路

能控性与能观性 状态空间分析
本卷考法

本卷实例

  • 中间结果：秩等于阶数2，系统完全能观

  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变

10第10题 非线性系统李雅普诺夫稳定性#

思路
  • 先由状态方程求平衡点；再在平衡点处求雅可比矩阵做一次近似，或用李雅普诺夫函数；由特征值实部或函数导数符号判定平衡状态稳定性。
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 用一次近似或李雅普诺夫函数判非线性系统稳定性
本卷实例
  • 关键一步：在原点处求一次近似矩阵并求特征值
  • 中间结果：一次近似矩阵为对角阵，特征值 -a、-b
  • 卡点：只判断李雅普诺夫函数正定而漏检其导数符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过用一次近似或李雅普诺夫函数判非线性系统稳定性
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
