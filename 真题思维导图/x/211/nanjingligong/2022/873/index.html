1第1题 微分方程组绘制结构图与稳定K范围#

思路
  • 先把微分方程组逐式整理成 s 域代数关系，按信号流向画结构图；用梅森公式写出闭环特征式，列劳斯表由首列全正求使系统稳定的 K 范围。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由微分方程组画结构图并用梅森公式写特征式
本卷实例
  • 关键一步：把各微分方程整理成 s 域后按信号流向连线
  • 中间结果：回路 L1、L2 与特征式 Δ=1-L1-L2
  • 卡点：结构图未读图，反馈极性与连线需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由微分方程组画结构图并用梅森公式写特征式
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
劳斯判据 稳定性分析
本卷考法
  • 列劳斯表判断闭环系统稳定性
本卷实例
  • 关键一步：把闭环特征式按降幂排列后列劳斯表
  • 中间结果：首列含 K 的代数式必须全部大于零
  • 卡点：系数有缺项时不补零就直接套劳斯判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过列劳斯表判断闭环系统稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由首列不等式求稳定 K 范围
本卷实例
  • 关键一步：取劳斯表首列各不等式的交集得稳定范围
  • 中间结果：稳定边界对应首列元素恰为零的临界 K
  • 卡点：只保留部分不等式而漏掉其他约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由首列不等式求稳定 K 范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

2第2题 由阻尼比取β与扰动不变性校正#

思路
  • 先按结构图求闭环特征式并令其等于典型二阶形式，由 ζ=0.707 求 β；再把参考输入置零求扰动到输出的传函，令其分子为零解出校正环节。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求扰动到输出的传函并令其为零
本卷实例
  • 关键一步：求扰动传函时把参考输入置零
  • 中间结果：用梅森公式写 C(s)/N(s) 并令分子为零
  • 卡点：把扰动引起的误差与总误差混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求扰动到输出的传函并令其为零
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环特征式对照典型二阶形式
本卷实例
  • 关键一步：由 ζ=0.707 令一次项系数等于 2ζωn
  • 中间结果：比较系数分别解出 ωn 与 β
  • 卡点：未先把 s² 项系数归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环特征式对照典型二阶形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
反馈校正与复合控制 系统校正
本卷考法
  • 由扰动不变性条件求补偿环节
本卷实例
  • 关键一步：令扰动传函分子为零解出 Gc(s)
  • 中间结果：补偿环节含微分项时需检查物理可实现性
  • 卡点：只看扰动不变性而不检查闭环稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过由扰动不变性条件求补偿环节
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

3第3题 由幅相曲线反求传函并求正弦稳态误差#

思路
  • 由幅相曲线的低频实部、与虚轴交点及给定点值设二阶无零点开环并联立求参数；再写误差传函，按频率特性求正弦输入下的稳态误差幅值与相角。
频率特性的物理意义与求法 频域分析
本卷考法
  • 由幅相曲线特征点反求开环参数
本卷实例
  • 关键一步：把低频实部与虚轴交点写成 a、b、k 的方程
  • 中间结果：由给定 j√2 点值联立定出开环参数
  • 卡点：幅相曲线未读图，特征点坐标需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由幅相曲线特征点反求开环参数
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 由 E/R=1-Φ(s) 求误差传递函数
本卷实例
  • 关键一步：由闭环传函反推误差传函 E/R=1-Φ
  • 中间结果：误差传函分子分母同为二阶
  • 卡点：非单位反馈时误差定义相差一个反馈环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由 E/R=1-Φ(s) 求误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求正弦输入下的稳态误差
本卷实例
  • 关键一步：把 s=j2 代入误差传函求幅值与相角
  • 中间结果：稳态误差为与输入同频的正弦量
  • 卡点：未先判稳就直接代入频率响应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求正弦输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

4第4题 根轨迹法确定PD校正参数并重绘根轨迹#

思路
  • 由超调量与调节时间求 ζ、ωn 及期望闭环极点，用根之和确定第三个极点；比较校正后特征式系数得 Kp、KD；再按等效开环重绘 0→∞ 根轨迹。
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量与调节时间求 ζ、ωn
本卷实例
  • 关键一步：超调量定 ζ、调节时间定 ωn
  • 中间结果：由 ζ 与 ωn 写出期望主导极点位置
  • 卡点：两项指标须交叉验证而不是各取一支
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量与调节时间求 ζ、ωn
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由期望闭环极点确定校正参数
本卷实例
  • 关键一步：用根之和确定第三个闭环极点
  • 中间结果：比较特征式系数得 Kp、KD
  • 卡点：把校正环节参数与开环增益混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由期望闭环极点确定校正参数
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制校正后 0→∞ 根轨迹
本卷实例
  • 关键一步：写校正后等效开环的零极点与渐近线
  • 中间结果：起点为两个原点极点与一个 -10 极点
  • 卡点：分离点方程求解后未筛选在轨迹上的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制校正后 0→∞ 根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

5第5题 保持截止频率提升相角裕度#

思路
  • 设串联环节后写出新开环的幅频与相频；由 ωc 不变列幅值条件，由相角裕度提高 45° 列相角条件，联立求 K、T。
稳定裕度 频域分析
本卷考法
  • 由幅值与相角条件列相角裕度方程
