1第1题 两输入结构图求传函10 分#

思路
  • 由结构图按梅森公式列前向通路与独立回路求 C(s)/R1(s)；再令 R2 单独作用求 C(s)/R2(s)，两路输入各自置零处理。题面含图未读图。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式分别求两路输入到输出的传函
本卷实例
  • 关键一步：按两条输入通路分别列前向通路与余子式
  • 中间结果：两路输入共用同一特征式，回路接触关系一致
  • 卡点：未把另一输入置零就叠加；回路接触关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式分别求两路输入到输出的传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简求输出传函
本卷实例
  • 关键一步：从最内层反馈回路起逐层等效化简
  • 中间结果：内环等效后各前向通路与回路清晰可数
  • 卡点：化简漏掉交叉反馈支路会使特征式少项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简求输出传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求两路参考输入各自的传递函数
本卷实例
  • 关键一步：对每一路输入单独置零另一路再求传函
  • 中间结果：总输出为两路响应的线性叠加
  • 卡点：两个输入同时作用时未验证线性就直接相加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求两路参考输入各自的传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

2第2题 由阶跃响应求性能与扰动补偿20 分#

思路
  • 由 G1 的单位阶跃响应式反求一阶环节，再按非标准反馈结构写闭环传函，化为二阶标准形式读阻尼比与自然频率；扰动补偿用叠加法令扰动到输出通路的分子为零。题面含图未读图。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函化为二阶标准形式读阻尼比与自然频率
本卷实例
  • 关键一步：先写闭环传函再归一分母首项系数
  • 中间结果：分母一次项系数对应二倍阻尼比乘自然频率
  • 卡点：本题非标准单位负反馈，直接套典型二阶公式会偏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函化为二阶标准形式读阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求稳态输出、超调量与调节时间
本卷实例
  • 关键一步：把曲线上的指标翻译成阻尼比与自然频率方程
  • 中间结果：超调量仅由阻尼比确定，与自然频率无关
  • 卡点：调节时间误差带取5%与2%时系数不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求稳态输出、超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求可测阶跃扰动作用下系统的稳态误差
本卷实例
  • 关键一步：令参考输入为零再求扰动到输出的传函
  • 中间结果：扰动误差由扰动通路的低频增益决定
  • 卡点：把扰动误差与参考输入引起的误差混在一起算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求可测阶跃扰动作用下系统的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
反馈校正与复合控制 系统校正
本卷考法
  • 设计前馈补偿器消除扰动对稳态输出的影响
本卷实例
  • 关键一步：令扰动到输出的传函分子恒为零解补偿器
  • 中间结果：补偿器为带大时间常数惯性环节的微分近似
  • 卡点：纯微分不可实现，须串大时间常数惯性环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过设计前馈补偿器消除扰动对稳态输出的影响
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

3第3题 由闭环极点反求开环传函10 分#

思路
  • 三阶二型且仅一个开环零点，按型别设含 s² 分母与一次零点的开环形式；由闭环特征根构造期望特征多项式，比较系数定极点位置与增益。
系统型别与静态误差系数 稳态误差
本卷考法
  • 由二型系统判定开环含两个积分环节
本卷实例
  • 关键一步：按系统型别把开环分母设成含s²因子的形式
  • 中间结果：开环分母为s²乘一个一阶实极点环节
  • 卡点：把开环增益与二型系统的静态误差系数混同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由二型系统判定开环含两个积分环节
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
传递函数的定义与基本性质 传递函数
本卷考法
  • 按开环零点与阶数写出传递函数形式
本卷实例
  • 关键一步：仅一个开环零点故分子取一次因式
  • 中间结果：开环传函由两个积分环节与一个实极点组成
  • 卡点：未按零点s=-1写分子导致形式不符
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过按开环零点与阶数写出传递函数形式
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
零极点分布与响应模态 传递函数
本卷考法
  • 由闭环特征根构造期望特征多项式
本卷实例
  • 关键一步：由一对共轭根与一个实根写出三阶期望多项式
  • 中间结果：期望多项式含与共轭根虚部平方相关的常数项
  • 卡点：把特征值实部当作根直接写而漏掉共轭对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由闭环特征根构造期望特征多项式
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

4第4题 由奈氏曲线反求开环参数20 分#

思路
  • 令 s=jω 写开环幅相，由曲线与负实轴交点相位 -180° 定一个时间常数，再由另一频率点的相角与幅值条件列方程，联立解出 a、b、c。题面含图未读图。
频率特性的物理意义与求法 频域分析
本卷考法
  • 令s=jω分离开环频率特性的实部与虚部
本卷实例
  • 关键一步：代入jω后按实部与虚部分别整理
  • 中间结果：幅值与相角都写成频率和三个参数的函数
  • 卡点：相角累加时漏掉积分环节的-90度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过令s=jω分离开环频率特性的实部与虚部
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由奈氏曲线与负实轴交点读相位穿越条件
本卷实例
  • 关键一步：曲线交负实轴处相角为-180度
  • 中间结果：交点频率给出一个时间常数等式
  • 卡点：把穿越点幅值误当作系统的幅值裕度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由奈氏曲线与负实轴交点读相位穿越条件
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
