1第1题 结构图三问与状态空间#

思路
  • 由结构图用梅森公式分别求 Y1(s)/R1(s) 与单路 R2 作用下的 Y2(s)；再以 X1、X2 为状态变量列写状态空间模型并由状态矩阵求特征方程。题面含图未读图。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求两路输入到输出的传函
本卷实例
  • 关键一步：按两条输入通路分别列前向通道与余子式
  • 中间结果：两路共用同一特征式，特征式含互不接触对乘积
  • 卡点：互不接触回路对漏算致特征式少项；结构图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求两路输入到输出的传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求多路输入作用下输出表达式
本卷实例
  • 关键一步：分别令单路输入作用再把各响应叠加
  • 中间结果：输出为两路输入各自贡献之和
  • 卡点：求某路传函时未把另一路输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求多路输入作用下输出表达式
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
状态空间表达式的建立 状态空间分析
本卷考法
  • 由结构图选状态变量列写状态空间模型
本卷实例
  • 关键一步：按积分器前后取状态写一阶微分方程
  • 中间结果：状态矩阵由各回路增益组合而成
  • 卡点：状态变量个数与积分器数目不匹配
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由结构图选状态变量列写状态空间模型
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

2第2题 由动态指标反求参数与误差#

思路
  • 由结构图写开环与闭环传函并化为二阶标准形式，由超调量与峰值时间解阻尼比与自然频率，再反求增益与微分时间常数，最后按型别求斜坡稳态误差。题面含图未读图。
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间反求阻尼比与自然频率
本卷实例
  • 关键一步：超调量式先定阻尼比，峰值时间式再定自然频率
  • 中间结果：阻尼比只由超调量确定，与自然频率无关
  • 卡点：超调量公式漏乘百分号或峰值时间系数用错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与峰值时间反求阻尼比与自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由动态指标反求开环增益与微分时间常数
本卷实例
  • 关键一步：把闭环标准形式系数与元件参数对应
  • 中间结果：一次项系数定微分时间常数，常数项定增益
  • 卡点：未先把闭环分母首项系数归一就比较系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由动态指标反求开环增益与微分时间常数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡输入下的稳态误差
本卷实例
  • 关键一步：按开环型别写速度误差系数
  • 中间结果：斜坡误差为输入斜率除以速度误差系数
  • 卡点：把输入斜率漏乘进误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3第3题 根轨迹三问与极点区域#

思路
  • 先求渐近线与分离点、虚轴交点，画 0→∞ 根轨迹；再作 s=s1-0.5 平移求极点位于垂线左侧的增益范围，并用阻尼角条件求另一上界，取交集。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 画三极点无零点根轨迹的渐近线与实轴段
本卷实例
  • 关键一步：由零极点差算渐近线条数、夹角与交点
  • 中间结果：三条分支交于实轴上一点并趋向无穷远
  • 卡点：渐近线夹角公式中二k加一写成二k
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过画三极点无零点根轨迹的渐近线与实轴段
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求分离点坐标并筛选有效解
本卷实例
  • 关键一步：由各极点倒数和列出分离点方程
  • 中间结果：方程给出两个实根，舍去不在根轨迹上的解
  • 卡点：保留了不在根轨迹实轴段上的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求分离点坐标并筛选有效解
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由虚轴交点求临界增益与频率
本卷实例
  • 关键一步：令s=jω代入特征方程实部虚部分别为零
  • 中间结果：交点频率与临界增益由方程组解出
  • 卡点：只代一个频率值就下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由虚轴交点求临界增益与频率
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由极点垂线位置与阻尼比确定增益范围
本卷实例
  • 关键一步：先平移坐标求半平面约束再按阻尼角设共轭根
  • 中间结果：两个约束分别给出增益区间的上下界
  • 卡点：把等阻尼线当成垂直线处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由极点垂线位置与阻尼比确定增益范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

4第4题 含纯延迟系统的奈氏判据#

思路
  • 含纯延迟的开环幅相曲线与实轴有无数交点；求第一次穿越实轴的频率与幅值，由奈氏判据的包围条件确定闭环稳定的增益范围。
含纯延迟环节的系统稳定性 稳定性分析
本卷考法
  • 求含纯延迟系统的第一次实轴穿越与临界增益
本卷实例
  • 关键一步：由虚部为零求穿越频率再由幅值条件定临界增益
  • 中间结果：穿越频率由延迟时间的余弦零点确定
  • 卡点：把延迟环节当成惯性环节处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 延迟环节 e^{-τs} 的幅值为 1、相位为 -τω，只恶化相位
  • 延迟会显著缩小稳定域，τ 越大越难稳定
  • 频域判据需用相位裕度扣除延迟引起的附加滞后
步骤
  • 写出含延迟的开环传递函数
  • 分别求幅值与相位表达式
  • 在相频特性中扣除 τω 的滞后量
  • 按稳定裕度或奈氏判据求临界 τ 或临界 K
通用考法
  • 本卷考过求含纯延迟系统的第一次实轴穿越与临界增益
  • 求使系统稳定的最大延迟时间
  • 求含延迟系统的临界开环增益
  • 分析延迟对稳定裕度的影响
常见易错
  • 把延迟环节当成惯性环节处理
  • 相位计算时忘记角度与弧度换算
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 写含延迟开环的幅相表达式并分离实虚部
本卷实例
  • 关键一步：用欧拉公式把延迟指数项展开成三角式
  • 中间结果：幅相曲线随频率增大呈螺旋状趋于原点
  • 卡点：相角累加时漏掉积分环节的负90度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过写含延迟开环的幅相表达式并分离实虚部
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由奈氏判据判断闭环稳定所需的增益条件

  • 把非线性环节与线性部分联立求等效开环；由线性部分与负倒描述函数轨迹的相对位置分稳定、不稳定与周期运动；相交时由幅值条件求振幅、由相角条件求频率。题面含图未读图。
描述函数法基础 非线性系统
本卷考法
  • 由给定描述函数写负倒描述函数轨迹
本卷实例
  • 关键一步：对描述函数取负倒数并求出幅值范围端点
  • 中间结果：负倒轨迹在负实轴上一段区间内变化
  • 卡点：把描述函数与负倒描述函数的横轴含义搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过由给定描述函数写负倒描述函数轨迹
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件
公式
用描述函数法分析自振 非线性系统
本卷考法
  • 由两曲线交点求稳定周期运动的振幅与频率
本卷实例
  • 关键一步：令线性部分曲线与负倒轨迹相交定出交点
  • 中间结果：交点频率为周期运动频率，幅值条件定振幅
  • 卡点：未判幅值增大方向就下极限环稳定结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过由两曲线交点求稳定周期运动的振幅与频率
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求线性部分的幅相特性与临界交点
本卷实例
  • 关键一步：代jω分离实部虚部并求相角为负180度处
  • 中间结果：线性部分与负实轴交点的频率与幅值
  • 卡点：求线性部分相角时漏掉积分环节负90度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求线性部分的幅相特性与临界交点
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

10第10题 离散系统判稳与阶跃响应#

思路
  • 含零阶保持器的采样系统由连续部分 z 变换求开环脉冲传函与闭环特征方程；按给定采样周期用朱利判据或根模判稳求增益范围；再由闭环脉冲传函做幂级数展开求单位阶跃响应与稳态误差。题面含图未读图。
脉冲传递函数 离散控制系统
本卷考法
  • 求含零阶保持器的开环脉冲传递函数
本卷实例
  • 关键一步：把连续部分按重极点拆项后逐项作z变换
  • 中间结果：开环脉冲传函分子分母化为低次多项式
  • 卡点：漏乘零阶保持器的1减z负一次因子
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过求含零阶保持器的开环脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)
公式
离散系统稳定性分析 离散控制系统
本卷考法
  • 由闭环特征方程求离散系统的稳定增益范围
本卷实例
  • 关键一步：对特征多项式作朱利判据或w变换后列劳斯表
  • 中间结果：稳定条件给出一组关于增益的不等式
  • 卡点：把稳定条件写成实部小于零而非模小于一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过由闭环特征方程求离散系统的稳定增益范围
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

离散系统的动态性能与极点分布 离散控制系统
本卷考法
  • 由闭环脉冲传函求单位阶跃响应序列
本卷实例
  • 关键一步：把输出像函数按z的负幂次长除展开
  • 中间结果：输出序列前几拍给出响应形态与稳态值
  • 卡点：长除时初始拍对应关系错位
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点在 z 平面上的位置决定响应形式
  • 极点越靠近原点衰减越快，越靠近单位圆振荡越强
  • 极点的幅角决定振荡频率，幅值决定衰减速度
  • 采样周期增大会使动态性能变差甚至不稳定
步骤
  • 求闭环脉冲传递函数的极点
  • 按极点在单位圆内的位置判断响应形式
  • 由极点的模与幅角估算衰减与振荡频率
  • 与连续系统指标对应关系相互校验
通用考法
  • 本卷考过由闭环脉冲传函求单位阶跃响应序列
  • 由闭环极点分布判断动态性能
  • 与连续域指标互相换算
  • 说明采样周期对动态性能的影响
常见易错
  • 把 z 平面极点当作 s 平面极点直接读阻尼比
  • 忽略单位圆上极点对应等幅振荡

离散系统的稳态误差 离散控制系统
本卷考法
  • 求单位阶跃输入下的闭环稳态误差
本卷实例
  • 关键一步：由误差脉冲传函按终值定理取极限
  • 中间结果：闭环含积分性质使阶跃稳态误差为零
  • 卡点：系统未判稳就使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差由输入类型与开环脉冲传函中 z=1 处极点的个数决定
  • 型别由 G(z)H(z) 中 z=1 处极点的重数确定
  • 用终值定理求稳态误差，前提是系统稳定
  • 采样周期也影响稳态误差大小
步骤
  • 求误差脉冲传递函数
  • 数出 z=1 处极点重数确定型别
  • 查表或用终值定理求稳态误差
  • 分析采样周期变化对误差的影响
通用考法
  • 本卷考过求单位阶跃输入下的闭环稳态误差
  • 求离散系统在典型输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 分析采样周期对稳态精度的影响
常见易错
  • 直接用 s 域静态误差系数公式处理离散系统
  • 未判稳就用终值定理
