1第1题 二阶系统斜坡响应反求模型#

思路
  • 先由单位斜坡响应曲线读出稳态误差与某一时刻的输出斜率，确定系统型别与开环增益；再按无零点二阶开环写出闭环标准形式，由响应单调性判断阻尼比范围；最后把曲线时间刻度条件与参数关系联立。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位斜坡响应曲线反求无零点二阶传函
本卷实例
  • 关键一步：把曲线稳态段的误差值和给定时刻的斜率翻译成传函参数条件
  • 中间结果：闭环写成典型二阶形式，曲线特征量对应参数方程
  • 卡点：响应曲线未读图，稳态误差值与时间刻度需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位斜坡响应曲线反求无零点二阶传函
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化成典型二阶形式并判断阻尼状态
本卷实例
  • 关键一步：由无零点开环设标准二阶闭环分母并逐项比对参数
  • 中间结果：闭环极点位置由阻尼比与自然频率共同确定
  • 卡点：曲线无振荡只能限定阻尼比范围，不能直接读出具体数值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化成典型二阶形式并判断阻尼状态
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力

2第2题 稳态误差与闭环极点约束反求#

思路
  • 先把单位负反馈斜坡稳态误差要求化为系统型别与速度误差系数条件；再按三阶开环常用形式设含待定时间常数的传函；最后把指定闭环极点代入特征方程，按实部虚部联立求参数。
系统型别与静态误差系数 稳态误差
本卷考法
  • 由斜坡稳态误差确定系统型别和速度误差系数
本卷实例
  • 关键一步：把稳态误差指标直接换成对静态速度误差系数的要求
  • 中间结果：有限斜坡误差对应Ⅰ型系统，开环含一个积分环节
  • 卡点：须先明确单位负反馈才可直接用误差系数倒数关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由斜坡稳态误差确定系统型别和速度误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

3第3题 多回路系统稳定条件与动态指标#

思路
  • 先按方框图逐层化简求开环传函，再写闭环特征方程用劳斯判据得参数稳定条件；第二问在给定参数下由超调量与调节时间指标反求阻尼比和自然频率，最后回代确定待定参数。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由多回路结构图逐层化简求开环传函
本卷实例
  • 关键一步：从最内层反馈回路开始，把内环等效为一个环节
  • 中间结果：开环传函化为典型环节的乘积形式，含局部反馈的影响
  • 卡点：结构图未读图，反馈极性与支路连接需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由多回路结构图逐层化简求开环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
劳斯判据 稳定性分析
本卷考法
  • 列写闭环特征方程并用劳斯判据判稳
本卷实例
  • 关键一步：按降幂排列闭环特征方程，缺项补零后列劳斯表
  • 中间结果：首列各元素均大于零等价于参数稳定条件
  • 卡点：参数为正这一条件不能替代劳斯表首列的全部约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过列写闭环特征方程并用劳斯判据判稳
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 把劳斯表首列不等式化成参数稳定域
本卷实例
  • 关键一步：令劳斯表首列每个元素大于零并取各不等式交集
  • 中间结果：稳定域边界对应闭环极点落在虚轴上的临界情况
  • 卡点：容易只保留部分不等式而漏掉其他约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过把劳斯表首列不等式化成参数稳定域
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式

通用考法

常见易错

4第4题 含延迟环节的奈氏稳定判据#

思路
  • 先从奈氏图读出开环传函的型别与若干特征点，写出二阶开环模型；再乘以延迟环节后按幅值不变、相位附加滞后处理；最后用奈氏判据要求曲线不包围临界点，解出延迟时间的稳定范围。
频率特性的物理意义与求法 频域分析
本卷考法
  • 由奈氏图特征点读取二阶环节的幅值与相角
本卷实例
  • 关键一步：把图中低频与某一频率点的复数值分别写成幅值和相角条件
  • 中间结果：开环传函的增益与时间常数由这些特征点联立确定
  • 卡点：奈氏图为原卷插图未读，特征点坐标需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
