1第1题 多回路结构图求传函#

思路
  • 由结构图用梅森增益公式求闭环传递函数：先找前向通路与各回路增益，再判断互不接触回路对写特征式；题面含图未读图。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式由多回路结构图求闭环传函
本卷实例
  • 关键一步：分别列出各前向通路与三条回路增益
  • 中间结果：两条前向通路共用同一特征式
  • 卡点：互不接触回路对漏算致特征式少项；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式由多回路结构图求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图的逐层化简
本卷实例
  • 关键一步：按回路嵌套顺序由内环向外环化简
  • 中间结果：逐层化简后化为单回路形式
  • 卡点：化简内环时把外环信号当成常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图的逐层化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2第2题 两级RC移相电路频率特性#

思路
  • 先按复阻抗列电路方程求传递函数，再写幅频与相频表达式；第二问由相移为负90度定RC关系，再代入求幅值衰减倍数；题面含图未读图。
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由两级RC网络列方程求传递函数
本卷实例
  • 关键一步：用复阻抗写分压或节点电流方程
  • 中间结果：传函分母为s的二次多项式
  • 卡点：电容复阻抗误写成Cs
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由两级RC网络列方程求传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由传递函数写幅频相频并求指定频率处幅值
本卷实例
  • 关键一步：把s换成jω后分离模与相角
  • 中间结果：相移负90度对应分母实部为零
  • 卡点：相角累加时漏掉环节相位移；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由传递函数写幅频相频并求指定频率处幅值
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

3第3题 由结构图与稳态误差反求二阶参数#

思路
  • 由结构图写闭环特征式并化为二阶标准形式，分别求ωn与ξ；再由ξ值与斜坡稳态误差限反解待求参数。题面含图未读图。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 含局部反馈的结构图求闭环传函
本卷实例
  • 关键一步：先写内环等效再串入前向通道
  • 中间结果：内环反馈给特征式引入附加一次项
  • 卡点：负反馈分母写成1减GH
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过含局部反馈的结构图求闭环传函
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征式求ωn与ξ
本卷实例
  • 关键一步：把闭环分母化为首一标准二阶式
  • 中间结果：常数项为ωn平方，一次项系数为2ξωn
  • 卡点：未先把s平方项系数归一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征式求ωn与ξ
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由阻尼比与稳态误差反求元件参数
本卷实例
  • 关键一步：用ξ条件与误差条件分别列方程
  • 中间结果：两条件联立定出待求参数
  • 卡点：只满足单项指标就下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由阻尼比与稳态误差反求元件参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：按系统型别写速度误差系数
  • 中间结果：斜坡误差等于输入斜率除以速度误差系数
  • 卡点：把输入斜率漏乘进误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

奈奎斯特判据 稳定性分析
本卷考法
  • 用奈氏判据确定闭环稳定的开环增益范围
本卷实例
  • 关键一步：先数开环右半平面极点数再判包围关系
  • 中间结果：稳定要求交点幅值落在临界点右侧
  • 卡点：把包围圈数正负号定义搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈氏判据确定闭环稳定的开环增益范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求各参数单独变化时的稳定域
本卷实例
  • 关键一步：把交点幅值条件化为关于待求参数的不等式
  • 中间结果：三种情形分别给出增益或时间常数范围
  • 卡点：只列一个不等式漏掉参数大于零的约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求各参数单独变化时的稳定域
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

5第5题 串联滞后校正设计#

思路
  • 由静态速度误差系数要求定开环增益，再求未校正系统相角裕度，选滞后网络在指定截止频率处提供衰减与少量滞后相角，由衰减量定网络参数并校验裕度。题面含图未读图。
滞后校正 系统校正
本卷考法
  • 设计串联滞后校正装置满足相角裕度与截止频率
本卷实例
  • 关键一步：先按裕度要求选校正后截止频率再让滞后网络提供衰减
  • 中间结果：滞后网络两个转折频率都取在截止频率左侧
  • 卡点：转折频率取得过高致相位滞后抵消增益改善；需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过设计串联滞后校正装置满足相角裕度与截止频率
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
稳定裕度 频域分析
本卷考法
  • 校验校正后相角裕度是否满足要求
本卷实例
  • 关键一步：求校正后截止频率处相角再算裕度
  • 中间结果：相角裕度为180度减该处相角
