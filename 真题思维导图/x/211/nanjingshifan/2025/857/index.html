1校正装置类型判断#

思路
  • 由传递函数形式比较网络高频与低频增益，判断属于超前还是滞后校正
滞后校正 系统校正
本卷考法
  • 由传递函数形式判断校正网络的类型
本卷实例
  • 关键一步：比较网络高频增益与低频增益的大小关系
  • 中间结果：相频是两段反正切之差，其正负由参数与一的大小定
  • 卡点：参数与一的大小关系决定超前或滞后，别只看结构
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过由传递函数形式判断校正网络的类型
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 本卷考过把滞后网络的两个转折频率顺序写反
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

2二阶反馈系统稳定性#

思路
  • 写出含参数a、k的闭环特征式，用劳斯判据讨论参数取值与闭环稳定性的关系
劳斯判据 稳定性分析
本卷考法
  • 讨论参数a、k取值与闭环稳定性的关系
本卷实例
  • 关键一步：先写闭环特征式再列劳斯表
  • 中间结果：首列各元素全部大于零是对应的稳定条件
  • 卡点：两个参数要联立判断，不能只盯其中一个
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过讨论参数a、k取值与闭环稳定性的关系
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过系数有缺项时不补零就直接套用判据
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

3传递函数的决定因素#

思路
  • 回到传递函数定义，明确其只由系统本身的结构与参数决定
传递函数的定义与基本性质 传递函数
本卷考法
  • 说明传递函数由系统的哪些因素决定
本卷实例
  • 关键一步：由传递函数定义出发看其与输入和初值是否有关
  • 中间结果：传递函数只描述系统自身的固有特性
  • 卡点：传递函数与输入信号形式和初始条件无关
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过说明传递函数由系统的哪些因素决定
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过忽略零初始条件这一前提
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

  • 把斜坡与抛物线信号的阶次写错

6幅频与相频特性#

思路
  • 令s取纯虚数，分别对复数取模与取相角得到幅频和相频表达式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由传递函数求幅频特性与相频特性表达式
本卷实例
  • 关键一步：把s换成纯虚数后对分子分母分别取模
  • 中间结果：分母的模为各环节模的乘积
  • 卡点：分母含正实部极点，幅角要按象限正确取值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤

  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
