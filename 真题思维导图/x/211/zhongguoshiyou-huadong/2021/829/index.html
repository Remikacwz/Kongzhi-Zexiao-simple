思路

传递函数的定义与基本性质 传递函数
本卷考法
  • 第(1)小问：分别举例写出时域、频域、复域中的数学模型
本卷实例
  • 关键一步：时域写微分方程、状态空间表达式或差分方程并各举一例
  • 关键一步：复域写传递函数，频域写频率特性，两者由 s=jω 相互联系
  • 中间结果：同一系统的三种模型可互相转换
  • 中间结果：频域模型是复域模型在 s=jω 上的取值
  • 卡点：只写模型名称不举具体例子，简答题难以拿分
  • 卡点：把频域模型与复域模型混为一谈，漏掉代入 s=jω 这一步
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过第(1)小问：分别举例写出时域、频域、复域中的数学模型
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

非线性系统的特点 非线性系统
本卷考法

  • 第(2)小问：说明非线性系统的运动特点
本卷实例
  • 关键一步：根本区别在于系统中是否存在非线性环节、是否满足叠加原理
  • 关键一步：运动特点从未知数：稳定性分析复杂、可能存在自激振荡、频率响应畸变
  • 中间结果：线性系统正弦输入下稳态输出仍是同频正弦，非线性系统会产生高次谐波
  • 卡点：只答不满足叠加原理，漏掉自激振荡与频率响应畸变两个特点

  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法

  • 本卷考过第(2)小问：说明非线性系统的运动特点

思路

梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图用梅森增益公式求 C(s)/R(s)
本卷实例
  • 关键一步：先列全部独立回路并写出特征式 Δ=1−ΣL+ΣLL−…
  • 关键一步：再找从 R 到 C 的全部前向通路，逐条写增益与余子式
  • 关键一步：按 C/R=ΣPkΔk/Δ 合并
  • 中间结果：特征式含一条两两不接触回路之积项
  • 中间结果：前向通路四条，余子式均为 1
  • 卡点：不接触回路找漏或重复计数；余子式中未剔除与前向通路接触的回路
  • 卡点：信号流图未读图，回路与前向通路增益需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图用梅森增益公式求 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

4四、根轨迹绘制与稳定范围15 分#

思路

根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制根轨迹草图并指出渐近线
本卷实例

  • 关键一步：按实轴段判据确定根轨迹所在的实轴区间
  • 关键一步：由分离点方程求分离点并对解作取舍
  • 中间结果：三条分支全部趋向无穷远，渐近线交点在实轴上
  • 中间结果：分离点方程解出一取一舍
  • 卡点：实轴段判据中右方零极点个数算错；分离点求出后不筛选
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤

  • 计算渐近线交点与夹角

  • 按对称性连接各段并标出对应 K 值
通用考法

  • 按法则绘制根轨迹草图

与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及系统稳定的 K* 范围
本卷实例
  • 关键一步：由闭环特征方程列劳斯表，令某行首元为零求临界 K*
  • 关键一步：由辅助方程解出虚轴交点频率
  • 关键一步：结合根轨迹走向写出稳定区间

11十一、李雅普诺夫矩阵方程证明10 分#

思路
  • 证明线性定常系统零平衡状态渐近稳定的充分条件是对任意正定对称 Q 存在正定对称 P 满足 AᵀP+PA=−Q
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 用李雅普诺夫矩阵方程证明系统渐近稳定
本卷实例
  • 关键一步：充分性：取 V(x)=xᵀPx，沿轨线求导得 V̇=xᵀ(AᵀP+PA)x=−xᵀQx
  • 关键一步：由 P、Q 正定得 V 正定、V̇ 负定，据定理得渐近稳定
  • 关键一步：必要性：取 P 为 e^{Aᵀt}Qe^{At} 的积分，由渐近稳定证积分收敛且 P 正定
  • 中间结果：V̇ 的负定性完全由 Q 的正定性保证
  • 中间结果：必要性的关键是对矩阵指数积分存在性
  • 卡点：只判 P 正定而忘记 Q 必须正定；把 P、Q 的角色写反
  • 卡点：必要性构造中忽略 A 特征值必须有负实部
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过用李雅普诺夫矩阵方程证明系统渐近稳定
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数
