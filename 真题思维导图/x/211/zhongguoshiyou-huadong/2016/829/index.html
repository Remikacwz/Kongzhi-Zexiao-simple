中国石油大学(华东) 829 自动控制原理 2016 年真题思维导图

难度：中等　十二道大题：一为五小问基本概念（扰动开环控制、PD对二阶系统影响、离散稳态误差因素、非奇异变换不变量、状态与输出渐近稳定关系）；二无源网络建模；三结构图求C/R与C/N；四参数根轨迹与阻尼比；五由对数幅频曲线反求传函并分析滞后校正；六描述函数法自振；七采样系统脉冲传函与稳定范围；八传递函数并联实现与模拟结构图；九状态转移矩阵与状态响应；十能控性判断与能控标准型/分解；十一李雅普诺夫法判稳定；十二状态反馈极点配置。

1一、简答题（5小问）20 分#

思路
  • 五小问基本概念：扰动开环控制的优缺点、PD对典型二阶系统性能的影响、离散系统稳态误差的影响因素、非奇异线性变换的不变量、状态与输出渐近稳定的关系
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 第(1)小问：分析基于扰动的开环控制方式优点和缺点
本卷实例
  • 关键一步：抓住开环无反馈这一前提，从结构与精度两方面谈
  • 关键一步：区分按扰动补偿与按给定补偿两种开环方式
  • 中间结果：开环无法自动修正偏差，精度依赖标定与元件
  • 卡点：只答开环缺点不答优点，或把闭环结论套到开环
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过第(1)小问：分析基于扰动的开环控制方式优点和缺点
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
PID 控制器与参数整定 系统校正
本卷考法
  • 第(2)小问：说明比例微分控制对典型二阶系统性能的影响
本卷实例
  • 关键一步：PD在误差变化速度上产生阻尼作用
  • 关键一步：微分项等效引入闭环实零点，加快上升
  • 中间结果：PD基本不改变开环增益与无阻尼自然频率
  • 卡点：误答PD降低超调，忽略实零点使超调量增大
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过第(2)小问：说明比例微分控制对典型二阶系统性能的影响
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式
离散系统的稳态误差 离散控制系统
本卷考法
  • 第(3)小问：指出线性定常离散系统稳态误差的相关因素
本卷实例
  • 关键一步：从系统型别与开环增益入手分析稳态误差
  • 关键一步：叠加输入序列类型与采样周期的影响
  • 中间结果：离散稳态误差由结构参数与采样周期共同决定
  • 卡点：只答开环增益，漏掉采样周期与输入类型
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差由输入类型与开环脉冲传函中 z=1 处极点的个数决定
  • 型别由 G(z)H(z) 中 z=1 处极点的重数确定
  • 用终值定理求稳态误差，前提是系统稳定
  • 采样周期也影响稳态误差大小
步骤
  • 求误差脉冲传递函数
  • 数出 z=1 处极点重数确定型别
  • 查表或用终值定理求稳态误差
  • 分析采样周期变化对误差的影响
通用考法
  • 本卷考过第(3)小问：指出线性定常离散系统稳态误差的相关因素
  • 求离散系统在典型输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 分析采样周期对稳态精度的影响
常见易错
  • 直接用 s 域静态误差系数公式处理离散系统
  • 未判稳就用终值定理

能控性与能观性 状态空间分析
本卷考法
  • 第(4)小问：说明状态变量非奇异线性变换下不变的系统性质
本卷实例
  • 关键一步：非奇异变换相当于换一组状态基底
  • 关键一步：据此判断能控、能观、稳定与传函矩阵是否改变
  • 中间结果：变换后A、B、C改变但特征值与传函矩阵不变
  • 卡点：把状态空间的数值当成固有属性，答成A阵不变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过第(4)小问：说明状态变量非奇异线性变换下不变的系统性质
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 第(5)小问：分析状态渐近稳定与输出渐近稳定的关系
本卷实例
  • 关键一步：由内部稳定性与外部稳定性的区别切入
  • 关键一步：用传函零极点对消解释输出稳而状态不稳
  • 中间结果：状态渐近稳定可推出输出渐近稳定，反之未必
  • 卡点：忽略零极点对消，误把两者当成等价条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过第(5)小问：分析状态渐近稳定与输出渐近稳定的关系
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

2二、无源网络求传递函数10 分#

思路
  • 无源网络按复阻抗法列串并联关系，求 U_o(s)/U_i(s)
由电路或机械系统求传递函数 传递函数
本卷考法
  • 对无源网络用复阻抗法串并联求传递函数
本卷实例
  • 关键一步：把电阻、电感、电容写成复阻抗并串并联化简
  • 关键一步：按分压关系列输出对输入的比值
  • 中间结果：结果先化成s的有理分式再通分合并
  • 卡点：电容阻抗误写为Cs；分压方向取反
  • 卡点：网络图未读图，元件连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过对无源网络用复阻抗法串并联求传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

3三、结构图求C/R与C/N10 分#

思路
  • 含给定输入与扰动双输入的结构图，分别求 C(s)/R(s) 与 C(s)/N(s)
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求给定输入与扰动分别作用下的闭环传递函数
本卷实例
  • 关键一步：求扰动传函时把参考输入置零
  • 关键一步：分别沿结构图找前向通路与回路
  • 中间结果：两路分母相同，分子由各自前向通路决定
  • 卡点：两输入同时存在时直接叠加而未分别置零
  • 卡点：结构图未读图，反馈支路需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求给定输入与扰动分别作用下的闭环传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求 C(s)/R(s) 与 C(s)/N(s)
本卷实例
  • 关键一步：先列全部独立回路写出特征式Δ
  • 关键一步：逐条写前向通路增益与余子式再合并
  • 中间结果：特征式含两两不接触回路之积项
  • 卡点：不接触回路找漏或重复计数
  • 卡点：结构图未读图，回路增益需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求 C(s)/R(s) 与 C(s)/N(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

4四、参数根轨迹与阻尼比15 分#

思路
  • 含参数a的三阶系统：绘制参数根轨迹，求衰减振荡的a范围，并由阻尼比0.5求a及全部闭环极点
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以闭环特征方程中的参数a为变量绘制参数根轨迹
本卷实例
  • 关键一步：由特征方程整理出等效开环传递函数
  • 关键一步：把待变参数完整地提到等效开环增益位置
  • 中间结果：等效开环极点为0、−1、−2，无开环零点
  • 卡点：整理时未把参数提到分子；仍沿用180°相角条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以闭环特征方程中的参数a为变量绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制参数根轨迹草图并求特殊点
本卷实例
  • 关键一步：标开环极点并判断实轴上的根轨迹区间
  • 关键一步：求分离点与虚轴交点作为草图关键点
  • 中间结果：三条分支均趋于无穷远，无有限零点
  • 卡点：实轴段判据算错；分离点求出后不筛选
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制参数根轨迹草图并求特殊点
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由阻尼比0.5确定主导极点并求参数与第三根
本卷实例
  • 关键一步：由ξ=0.5写出一对共轭主导极点的参数形式
  • 关键一步：回代特征方程分离实部虚部求a
  • 关键一步：用根之和关系求第三根
  • 中间结果：共轭主极点落在与负实轴成60°的射线上
  • 卡点：等阻尼线画成垂直线；回代后未分离实部虚部
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
