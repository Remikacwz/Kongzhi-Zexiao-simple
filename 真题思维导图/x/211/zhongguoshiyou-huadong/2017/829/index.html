1一、简答题（5小问）20 分#

思路
  • 五小问基本概念：控制系统性能要求的三个方面、减小扰动稳态误差的措施、根轨迹的两个条件、开环三频段、最小实现系统的特点
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 第(1)小问：写出控制系统性能要求的三个方面并指出首要工作条件
本卷实例
  • 关键一步：把性能要求归纳为稳定性、快速性、准确性
  • 关键一步：由稳定的前提地位判断其为首要工作条件
  • 中间结果：三者分别对应工程上的稳、快、准要求
  • 卡点：把快速性当成首要条件；漏答准确性一项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过第(1)小问：写出控制系统性能要求的三个方面并指出首要工作条件
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
减小稳态误差的措施 稳态误差
本卷考法
  • 第(2)小问：说明减小扰动作用下稳态误差的措施
本卷实例
  • 关键一步：从扰动作用点之前增设积分环节入手
  • 关键一步：结合提高该点前向增益与串级、复合控制
  • 中间结果：只有扰动作用点之前的增益才影响扰动误差
  • 卡点：在扰动点之后加积分环节，对扰动误差不起作用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过第(2)小问：说明减小扰动作用下稳态误差的措施
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 第(3)小问：指出根轨迹方程的幅值条件与相角条件及其充要性
本卷实例
  • 关键一步：分别写出幅值条件与相角条件的表达式
  • 关键一步：由相角条件判断其是否为充分必要条件
  • 中间结果：幅值条件用于求增益，相角条件用于判断点是否在轨迹上
  • 卡点：把相角条件的180°误写成0°；混淆两个条件的用途
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过第(3)小问：指出根轨迹方程的幅值条件与相角条件及其充要性
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

开环对数频率特性的绘制 频域分析
本卷考法
  • 第(4)小问：说明开环三频段与闭环性能的对应关系
本卷实例
  • 关键一步：低频段对应稳态精度，中频段对应动态性能
  • 关键一步：高频段对应系统抗高频干扰能力
  • 中间结果：三频段理论仅适用于单位负反馈最小相位系统
  • 卡点：漏答高频段抗扰作用；把中频段说成只影响稳态
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过第(4)小问：说明开环三频段与闭环性能的对应关系
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

状态空间与传递函数的关系 状态空间分析
本卷考法
  • 第(5)小问：说明最小实现系统的定义及其能控能观特点
本卷实例
  • 关键一步：由状态变量个数最少且无零极点对消定义最小实现
  • 关键一步：据此说明其同时完全能控与完全能观
  • 中间结果：传函无零极点对消即对应最小实现
  • 卡点：能控与能观两条只答一条；漏掉无零极点对消条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过第(5)小问：说明最小实现系统的定义及其能控能观特点
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

2二、RC无源网络求传递函数10 分#

思路
  • RC无源网络电路给定，按复阻抗法串并联求 U_c(s)/U_i(s)
由电路或机械系统求传递函数 传递函数
本卷考法
  • 对RC无源网络用复阻抗法求传递函数
本卷实例
  • 关键一步：把两个RC环节写成复阻抗并区分串并联
  • 关键一步：按分压关系列输出对输入的比
  • 中间结果：分母比分子多一项由中间节点分流引入的s项
  • 卡点：电容阻抗误写为Cs；串并联判断反了
  • 卡点：电路图未读图，元件连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过对RC无源网络用复阻抗法求传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

3三、闭环特征根约束与斜坡误差求K范围10 分#

思路
  • 单位负反馈开环传函G(s)=24K/[s(s+4)(s+6)]：要求闭环特征根实部均小于−1且单位斜坡误差小于1，求K范围
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据确定闭环特征根实部约束下的K范围
本卷实例
  • 关键一步：把开环传函化首1标准型写闭环特征方程
  • 关键一步：作坐标平移把实部约束变成新系统的稳定条件
  • 关键一步：对新特征方程列劳斯表求K区间
  • 中间结果：平移后新特征方程的常数项含24K−15
  • 卡点：平移时忘记替换全部s项；只列一条不等式就下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据确定闭环特征根实部约束下的K范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求稳定性与误差多个约束同时满足的参数范围
本卷实例
  • 关键一步：分别列出稳定约束与误差约束给出的K区间
  • 关键一步：把各区间取交集作为最终允许范围
  • 中间结果：参数稳定域由多条不等式共同界定
  • 卡点：只列部分首列元素的不等式；端点开闭取错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求稳定性与误差多个约束同时满足的参数范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡稳态误差要求反求开环增益范围
本卷实例
  • 关键一步：按系统型别写出速度误差系数
  • 关键一步：令误差表达式小于给定上界解出K的下限
  • 中间结果：I型系统斜坡误差为速度误差系数的倒数乘幅值
  • 卡点：未判稳就用静态误差系数；把阶跃公式套到斜坡
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位斜坡稳态误差要求反求开环增益范围
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

4四、根轨迹与稳态误差约束15 分#

思路
  • 单位负反馈G(s)=K*/[s(0.2s+1)(0.5s+1)]：绘制根轨迹，求稳定K范围，并由斜坡误差小于0.5求K范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画出三阶系统根轨迹草图
本卷实例
  • 关键一步：标开环极点并确定实轴上的根轨迹段
  • 关键一步：求渐近线、分离点与虚轴交点
  • 中间结果：n−m=3，三条分支均趋向无穷远
  • 卡点：渐近线夹角写成2k而非2k+1；分离点不筛选
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画出三阶系统根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及系统稳定时的K范围
本卷实例
  • 关键一步：由闭环特征方程列劳斯表，令临界行首元为零
  • 关键一步：构造辅助方程解出虚轴交点频率
