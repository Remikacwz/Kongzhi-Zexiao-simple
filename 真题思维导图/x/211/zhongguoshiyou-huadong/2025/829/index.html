1一、机理分析法与实验辨识法#

思路
  • 分别说明两类建模途径的原理：机理分析法从系统内部物理机理出发列写方程，实验辨识法从实测输入输出数据出发确定等效模型。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 说明机理分析法依据物理定律列方程建立模型
本卷实例
  • 关键一步：把被控对象看作白箱，用基尔霍夫定律或牛顿定律列写原始方程
  • 中间结果：所得模型具有明确物理意义，参数可直接对应实际元件
  • 卡点：易只答建立模型而不点明依据物理机理这一根本来源
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过说明机理分析法依据物理定律列方程建立模型
  • 给定 RLC 网络求 U_o(s)/U_i(s)

2二、比例微分控制器的作用#

思路
  • 从比例微分控制器引入超前相位与等效开环零点入手，说明其对稳定性、动态性能和噪声敏感度的影响。
PID 控制器与参数整定 系统校正
本卷考法
  • 说明比例微分控制对系统稳定性与动态性能的影响
本卷实例
  • 关键一步：写出比例微分控制器的复频域表达式，识别其相位超前特性
  • 中间结果：微分项相当于增加一个开环零点，使相角裕度提高、动态性能改善
  • 卡点：微分作用放大高频噪声，易只答改善性能而漏掉这一代价
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过说明比例微分控制对系统稳定性与动态性能的影响
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

3三、描述函数的概念#

思路
  • 先给出描述函数的定义，再从自变量是输入幅值还是频率这一点说明它与线性系统频率特性的区别。
描述函数法基础 非线性系统
本卷考法
  • 叙述描述函数的定义并比较其与线性频率特性的区别
本卷实例
  • 关键一步：对非线性环节加正弦输入，取其输出一次谐波与输入正弦的复数比
  • 中间结果：描述函数是输入幅值A的函数，与频率无关
  • 卡点：线性系统频率特性随频率变化，二者自变量容易答反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过叙述描述函数的定义并比较其与线性频率特性的区别
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

4四、离散系统稳定条件#

思路
  • 由z域特征方程给出稳定的充要条件，再列举开环增益、零极点分布、传输延迟与采样周期等影响因素。
离散系统稳定性分析 离散控制系统
本卷考法
  • 写出离散系统稳定的充要条件并说明影响因素
本卷实例
  • 关键一步：写出闭环脉冲传递函数的特征方程，把稳定问题化为根的分布问题
  • 中间结果：全部特征根位于z平面单位圆内即模小于1时系统稳定
  • 卡点：条件写成实部小于零是常见错误，开环增益与采样周期等都会影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过写出离散系统稳定的充要条件并说明影响因素
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

5五、能观性的概念#

思路
  • 由有限观测时间内输出能否唯一确定初始状态给出能观性定义，再说明初始状态确定后可由状态转移方程推出各时刻状态。
能控性与能观性 状态空间分析
本卷考法
  • 叙述能观性定义并解释为何要确定初始状态
本卷实例
  • 关键一步：把能观性表述为由有限时间内的输出唯一确定初始状态
  • 中间结果：初始状态一旦确定，配合已知输入即可由状态转移方程递推各时刻状态
  • 卡点：能观性针对初始状态与输出，能控性针对输入驱动，判据矩阵容易互换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过叙述能观性定义并解释为何要确定初始状态
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

传递函数的定义与基本性质 传递函数
本卷考法
  • 由微分方程求传递函数并说明零初始条件
本卷实例
  • 关键一步：对微分方程两边取拉氏变换，把全部初始条件置零
  • 中间结果：输出与输入的拉氏变换之比即为所求传递函数
  • 卡点：忽略零初始条件前提会把初值带入变换结果
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由微分方程求传递函数并说明零初始条件
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

7七、二阶系统动态性能与稳态误差#

思路
  • 由图2所示单位反馈二阶系统写出开环与闭环传函，化标准形式读出自然频率与阻尼比，再算动态指标与斜坡稳态误差；第二问由给定阻尼比反求开环增益。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函化标准形式求自然频率与阻尼比
本卷实例
  • 关键一步：把闭环传函分母首项系数归一化，再与标准二阶形式逐项比对系数
  • 中间结果：代入K=4、T=1后分母为s平方加s加4，可读出自然频率与阻尼比
  • 卡点：图2为原卷框图未读，前向通道与反馈结构需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函化标准形式求自然频率与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 按百分之五误差带求调节时间与超调量
本卷实例
  • 关键一步：先由阻尼比判断是否欠阻尼，再按对应近似公式求调节时间与超调量
  • 中间结果：调节时间与阻尼比和自然频率的乘积成反比
  • 卡点：两种误差带的调节时间系数不同，取错会整体偏差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过按百分之五误差带求调节时间与超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡输入下系统稳态误差
本卷实例
  • 关键一步：先判稳，再写出开环型别与静态速度误差系数
  • 中间结果：单位斜坡误差系数是开环增益与型别共同决定的有限值
