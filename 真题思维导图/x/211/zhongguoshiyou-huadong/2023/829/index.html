1一、简答题（基本概念五问）20 分#

思路
  • 五小问：线性连续系统稳定充要条件与三种判稳方法、串联校正装置类型与特点、最小实现步骤、状态观测器存在条件、采样定理
劳斯判据 稳定性分析
本卷考法
  • 说明线性连续系统稳定的充要条件并列出三种判稳方法
本卷实例
  • 关键一步：充要条件是闭环特征方程的所有根均具有负实部
  • 关键一步：三种方法可答劳斯（赫尔维茨）判据、奈奎斯特判据、根轨迹法
  • 关键一步：也可答频域相角裕度与幅值裕度判据
  • 中间结果：代数判据不需解根，频域判据由开环特性判断闭环稳定性
  • 卡点：只答方法名称不写判据内容；把开环特征根当闭环特征根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过说明线性连续系统稳定的充要条件并列出三种判稳方法
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

超前校正 系统校正
本卷考法
  • 判断给定串联校正装置的类型并说明其特点
本卷实例
  • 关键一步：由校正装置传递函数两个转折频率的大小关系判断类型的超前或滞后
  • 关键一步：分子时间常数大于分母时间常数为超前校正
  • 关键一步：说明超前校正在中频段提供正相角，提高相角裕度与快速性
  • 中间结果：该装置为串联超前校正
  • 中间结果：超前校正抬高截止频率、降低抗高频干扰能力
  • 卡点：两转折频率倒数比较方向搞反，把超前判成滞后
  • 卡点：校正装置传递函数在 OCR 流中残缺，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过判断给定串联校正装置的类型并说明其特点
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

状态观测器设计 状态空间分析
本卷考法
  • 说明状态观测器存在的充分必要条件
本卷实例

  • 关键一步：若系统完全能观则观测器极点可任意配置
  • 中间结果：不能观子系统稳定是观测器存在的条件，不是任意配极点的条件

  • 极点配置法与龙伯格观测器是两种常用形式
  • 观测器误差动态由 A-LC 的特征值决定
  • 观测器极点通常取得比系统极点快若干倍

  • 按期望特征多项式比较系数求出 L
  • 校验观测器收敛速度是否合适
通用考法
  • 本卷考过说明状态观测器存在的充分必要条件
  • 设计全维状态观测器
  • 由期望观测器极点求反馈增益阵 L
  • 分析观测器与状态反馈组合后的系统极点
常见易错
  • 把观测器增益阵写成了状态反馈增益阵的形式

采样过程与香农采样定理 离散控制系统
本卷考法
  • 叙述采样周期应遵守的定理及其内容
本卷实例
  • 关键一步：答香农采样定理
  • 关键一步：若输入信号最高角频率为 ωn，则采样角频率须满足 ωs≥2ωn
  • 关键一步：等价写为采样周期 T≤2π/(2ωn)
  • 中间结果：采样定理给出无失真恢复原信号的最低采样频率

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法

  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

思路

梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图用梅森增益公式或等效化简求 C(s)/R(s)
本卷实例
  • 关键一步：先列全部独立回路并写出特征式 Δ=1−ΣL+ΣLL−…
  • 关键一步：以 R 为输入找前向通路并写余子式
  • 关键一步：按 C/R=ΣPkΔk/Δ 合并
  • 中间结果：特征式与两个输入通道共用同一个分母
  • 中间结果：前向通路只有一条且与部分回路接触
  • 卡点：不接触回路找漏或重复计数；余子式中未剔除与通路接触的回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图用梅森增益公式或等效化简求 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

3三、由阶跃响应指标反求参数与稳态误差10 分#

思路
  • 结构图给定：求开环与闭环传函，由超调量 16.3%、调节时间 1.93s 定 K 与 τ，再求 r(t)=1.5t 的稳态误差
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量与调节时间要求反求系统参数
本卷实例
  • 关键一步：由结构图写出开环与闭环传函，整理成标准二阶形式
  • 关键一步：由超调量按 ξ 与 σ% 关系求阻尼比，由调节时间求 ωn
  • 关键一步：把 ξ、ωn 与结构图参数对应解出 K 与 τ
  • 中间结果：σ%=16.3% 对应 ξ≈0.5，ts 公式给出 ωn
  • 中间结果：闭环特征式系数与标准二阶系数逐项对应
  • 卡点：调节时间公式的误差带系数 3.5 与 4.4 用混；未把闭环传函归一化
  • 卡点：结构图未读图，反馈与增益位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量与调节时间要求反求系统参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求给定斜坡输入下的稳态误差
本卷实例
  • 关键一步：先判闭环稳定性，再判系统型别
  • 关键一步：Ⅰ型系统对斜坡输入的稳态误差由 ess=输入速度/静态速度误差系数求
  • 关键一步：把第(2)问定出的参数代入计算
  • 中间结果：闭环稳定是使用终值定理的前提
  • 中间结果：Ⅰ型系统斜坡误差为有限值

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 稳态误差由系统型别与输入类型共同决定

通用考法

  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

4四、参数根轨迹与稳态误差约束15 分#

思路
  • 结构图含参数 a：绘制 a 从 0 到∞的根轨迹，求稳定 a 范围，并由加速度输入稳态误差小于 0.3 确定 a 范围
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以参数 a 为变量绘制参数根轨迹
本卷实例
  • 关键一步：由闭环特征方程分离出参数 a，整理成 1+a·G_eq(s)=0 的等效开环形式
  • 关键一步：把 a 完整提到分子位置，确定等效开环的零极点
  • 关键一步：按常规根轨迹法则绘制
  • 中间结果：参数根轨迹的等效开环零点极点与原开环不同
  • 中间结果：a 的取值方向决定根轨迹的起点与终点
  • 卡点：整理等效开环时没有把参数完整提到分子；把参数根轨迹当常规根轨迹
  • 卡点：结构图未读图，等效开环需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
