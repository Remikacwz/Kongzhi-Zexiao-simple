中国石油大学(华东) 829 自动控制原理 2019 年真题思维导图

211 院校共 12 题合计 150 分

难度：中等　十二道大题：一为五小问基本概念（开环零极点影响、PID参数影响、古典稳定与李雅普诺夫稳定、对偶系统、Bode各频段作用）；二结构图求闭环传函；三由抛物线输入稳态误差求K范围；四参数b根轨迹与闭环动态指标；五开环传函的对数幅频、相角裕度与斜坡误差；六描述函数法求自振并讨论K的影响；七采样系统脉冲传函与组合输入误差；八模拟结构图与传递函数矩阵；九状态方程的状态响应；十可控标准型实现与能观条件；十一李雅普诺夫判稳；十二状态反馈能否改变传递函数并求增益阵。

1一、简答题（5小问）20 分#

思路
  • 五小问基本概念：开环零极点对性能影响、PID参数影响、古典稳定与李雅普诺夫稳定、对偶系统与对偶原理、Bode各频段作用
附加开环零极点的影响 根轨迹法
本卷考法
  • 第(1)小问：从时域角度分析增加开环零极点对系统性能的影响
本卷实例
  • 关键一步：附加零点使根轨迹左移、加快响应
  • 关键一步：附加极点使根轨迹右移、降低快速性
  • 中间结果：零极点改变根轨迹形状进而影响动态性能
  • 卡点：把附加零点与附加极点的影响搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过第(1)小问：从时域角度分析增加开环零极点对系统性能的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
PID 控制器与参数整定 系统校正
本卷考法
  • 第(2)小问：说明PID控制器三个参数对系统性能的影响
本卷实例
  • 关键一步：比例增益影响快速性与稳态误差
  • 关键一步：积分项消除稳态误差但降低稳定性
  • 关键一步：微分项提供超前阻尼但放大噪声
  • 中间结果：三个参数对稳定、准确、快速三方面的影响不同
  • 卡点：把积分项说成超前作用，或忽略微分对噪声的放大
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过第(2)小问：说明PID控制器三个参数对系统性能的影响
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 第(3)小问：比较古典控制稳定性与李雅普诺夫稳定的联系与区别
本卷实例
  • 关键一步：古典稳定针对线性定常系统闭环极点
  • 关键一步：李雅普诺夫稳定针对平衡状态
  • 中间结果：线性定常系统两者结论一致，非线性系统只能用后者
  • 卡点：把李雅普诺夫意义下的稳定与渐近稳定混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过第(3)小问：比较古典控制稳定性与李雅普诺夫稳定的联系与区别
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

能控性与能观性 状态空间分析
本卷考法
  • 第(4)小问：说明什么是对偶系统并简述对偶原理
本卷实例
  • 关键一步：对偶系统满足状态矩阵转置、输入与输出矩阵互换
  • 关键一步：对偶原理把能控性与能观性互相转换
  • 中间结果：对偶系统的传递函数矩阵互为转置
  • 卡点：只答对偶定义，漏答对偶原理的能控能观对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过第(4)小问：说明什么是对偶系统并简述对偶原理
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 第(5)小问：说明Bode图中各频段对系统性能的影响
本卷实例
  • 关键一步：低频段反映稳态精度与型别
  • 关键一步：中频段决定稳定性与动态性能
  • 关键一步：高频段影响抗噪声能力
  • 中间结果：三段频段分别对应准确、稳定、抗扰三方面
  • 卡点：把中频段与高频段的作用说反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过第(5)小问：说明Bode图中各频段对系统性能的影响
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

2二、结构图求闭环传递函数10 分#

思路
  • 由控制系统结构图求闭环传递函数C(s)/R(s)
比较点与引出点的移动 结构图与方框图
本卷考法
  • 用比较点与引出点的移动规则化简系统结构图
本卷实例
  • 关键一步：依次合并串联、并联与局部反馈
  • 关键一步：化简为单回路后套用闭环传函公式
  • 中间结果：等效变换前后输入输出关系不变
  • 卡点：结构图未读图，反馈支路与交叉点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过用比较点与引出点的移动规则化简系统结构图
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求闭环传递函数
本卷实例
  • 关键一步：先列全部独立回路写出特征式
  • 关键一步：再逐条写前向通路增益与余子式
  • 中间结果：分子为各前向通路增益与余子式乘积之和
  • 卡点：不接触回路找漏或重复计数
  • 卡点：结构图未读图，回路增益需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式

3三、由抛物线输入稳态误差求K范围10 分#

思路
  • 系统在抛物线输入r(t)=t²下的稳态误差小于0.5，反求满足要求的K范围
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由典型输入下的稳态误差要求反求开环增益范围
本卷实例
  • 关键一步：先判断系统型别与稳定性
  • 关键一步：用加速度误差系数写稳态误差表达式
  • 中间结果：误差约束化为关于K的不等式
  • 卡点：未判稳就使用终值定理，或型别数错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由典型输入下的稳态误差要求反求开环增益范围
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由结构图确定系统型别与静态误差系数
本卷实例
  • 关键一步：数开环积分环节个数定系统型别
  • 关键一步：写静态加速度误差系数
  • 中间结果：型别决定系统能否跟踪抛物线输入
  • 卡点：把开环增益与静态误差系数混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由结构图确定系统型别与静态误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式

4四、参数根轨迹与闭环动态指标15 分#

思路
  • 开环传函含参数b，绘制b从0到无穷的根轨迹，并求b=2时的闭环传函与动态指标
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以参数b为变量整理等效开环传函并绘制参数根轨迹
本卷实例
  • 关键一步：把含参数项提到分子写成等效开环形式
  • 关键一步：按绘制法则画参数根轨迹
  • 中间结果：参数根轨迹起点为等效开环极点
  • 卡点：整理时未把参数完整提到分子位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以参数b为变量整理等效开环传函并绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由参数根轨迹求b=2时的闭环极点与动态性能
本卷实例
  • 关键一步：把b=2代入闭环特征方程求根
  • 关键一步：由闭环极点位置估算超调量等指标
  • 中间结果：闭环传函分母由特征方程因式分解得到
  • 卡点：由极点位置估指标时忽略闭环零点的作用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由参数根轨迹求b=2时的闭环极点与动态性能
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响

本卷考法

本卷实例

  • 关键一步：设K并展开闭环特征式与期望特征式比对系数

  • 状态反馈不改变系统的零点

  • 分析状态反馈对系统性能的影响

  • 特征多项式比较系数时符号写反
