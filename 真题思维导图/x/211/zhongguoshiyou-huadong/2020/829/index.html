1一、简答题（5小问）20 分#

思路
  • 五小问基本概念：传递函数定义与典型环节、扰动前增积分环节影响、滞后校正特性、状态反馈对能控能观影响、状态与输出稳定性区别
传递函数的定义与基本性质 传递函数
本卷考法
  • 第(1)小问：说明传递函数的定义并写出至少3个典型环节
本卷实例
  • 关键一步：指出传递函数在零初始条件下的定义
  • 关键一步：说明只适用于线性定常系统
  • 中间结果：传递函数是输出与输入拉氏变换之比
  • 卡点：忽略零初始条件这一前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过第(1)小问：说明传递函数的定义并写出至少3个典型环节
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
典型环节及其特性 传递函数
本卷考法
  • 第(1)小问：写出至少3个典型环节的传递函数
本卷实例
  • 关键一步：列举比例、积分、惯性、微分等典型环节
  • 关键一步：写出各环节的传递函数表达式
  • 中间结果：典型环节包括比例、积分、惯性、一阶微分等
  • 卡点：把一阶微分环节与纯微分环节混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过第(1)小问：写出至少3个典型环节的传递函数
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 第(2)小问：分析扰动作用点前增加积分环节对系统性能的影响
本卷实例
  • 关键一步：积分环节提高系统型别
  • 关键一步：使扰动引起的稳态误差减小或消除
  • 中间结果：提高型别可消除常值扰动误差
  • 卡点：只谈误差减小而不检查稳定性是否被破坏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过第(2)小问：分析扰动作用点前增加积分环节对系统性能的影响
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式
滞后校正 系统校正
本卷考法
  • 第(3)小问：说明滞后校正利用的特性及其对截止频率、相角裕度的影响
本卷实例
  • 关键一步：利用高频幅值衰减特性压低中频段增益
  • 关键一步：截止频率左移使相角裕度增大
  • 中间结果：滞后校正牺牲快速性换取稳定裕度
  • 卡点：把滞后网络转折频率顺序写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过第(3)小问：说明滞后校正利用的特性及其对截止频率、相角裕度的影响
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
状态反馈与极点配置 状态空间分析
本卷考法
  • 第(4)小问：分析状态反馈控制对系统能控性、能观性的影响
本卷实例
  • 关键一步：状态反馈不改变系统的能控性
  • 关键一步：状态反馈可能改变能观性
  • 中间结果：状态反馈保持能控性，能观性可能被改变
  • 卡点：误答状态反馈可同时改变能控性与能观性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过第(4)小问：分析状态反馈控制对系统能控性、能观性的影响
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
公式
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 第(5)小问：说明状态稳定性与输出稳定性的区别
本卷实例
  • 关键一步：状态稳定性关注内部状态收敛
  • 关键一步：输出稳定性只看输出响应是否有界
  • 中间结果：零极点对消时状态不稳定但输出可能稳定
  • 卡点：忽略零极点对消，把两者当成等价条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过第(5)小问：说明状态稳定性与输出稳定性的区别
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

2二、由电路求传递函数10 分#

思路
  • 由理想元件组成的电路，求输出电压对输入电压的传递函数
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由电路网络求传递函数Uo(s)/Ui(s)
本卷实例
  • 关键一步：用复阻抗法列写电路方程
  • 关键一步：消去中间变量得到输出与输入之比
  • 中间结果：电容阻抗为1/(sC)，电感阻抗为sL
  • 卡点：复阻抗法把电容阻抗误写成sC
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由电路网络求传递函数Uo(s)/Ui(s)
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 用节点或回路法列写电路方程建模
本卷实例
  • 关键一步：列写节点电流或回路电压方程
  • 关键一步：整理为传递函数形式
  • 中间结果：传递函数分母由电路的时间常数决定
  • 卡点：电路图未读图，元件连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体

  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过用节点或回路法列写电路方程建模

3三、结构图等幅振荡与稳态误差10 分#

思路
  • 由结构图求单位阶跃响应出现等幅振荡的K，并在K=10时求给定与扰动下的稳态误差
劳斯判据 稳定性分析
本卷考法
  • 第(1)小问：求使单位阶跃响应出现等幅振荡的K值
本卷实例
  • 关键一步：列写闭环特征方程
  • 关键一步：令特征根为纯虚根求临界K
  • 中间结果：等幅振荡对应特征根落在虚轴上
  • 卡点：把等幅振荡条件误当成实部小于零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过第(1)小问：求使单位阶跃响应出现等幅振荡的K值
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 第(2)小问：分别求给定输入与扰动作用下的稳态误差
本卷实例
  • 关键一步：求误差传递函数
  • 关键一步：用终值定理分别计算两个输入的误差
  • 中间结果：两路误差分母相同、分子由各自前向通路决定
  • 卡点：求扰动误差时没把参考输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过第(2)小问：分别求给定输入与扰动作用下的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

4四、根轨迹绘制与阻尼比闭环极点15 分#

思路
  • 由结构图绘制K从0到无穷的根轨迹，求稳定K范围及阻尼比0.5时的闭环极点
根轨迹的绘制法则 根轨迹法
本卷考法
  • 第(1)小问：按绘制法则画出闭环系统的根轨迹
本卷实例
  • 关键一步：确定开环零极点并标注起点终点与渐近线
  • 关键一步：判实轴段、分离点与虚轴交点
  • 中间结果：根轨迹条数等于开环极点数
  • 卡点：实轴段判据零极点个数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过第(1)小问：按绘制法则画出闭环系统的根轨迹
  • 按法则绘制根轨迹草图

思路

李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 求平衡点并构造李雅普诺夫函数判断稳定性
本卷实例
  • 关键一步：令状态导数为零求平衡状态
  • 关键一步：取正定V函数并求其沿轨线的导数
  • 中间结果：V导数负定则平衡点渐近稳定
  • 卡点：只判断V正定而未检查其导数的定号性
  • 卡点：状态方程题面被OCR吞，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过求平衡点并构造李雅普诺夫函数判断稳定性
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数
