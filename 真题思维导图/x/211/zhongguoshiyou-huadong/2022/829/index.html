1一、简答题（基本概念五问）20 分#

思路
  • 五小问：附加左半平面开环零点的影响、截止频率、超前一滞后校正区别、非线性特征、分离原理
附加开环零极点的影响 根轨迹法
本卷考法
  • 说明附加左半平面开环零点对系统根轨迹的影响
本卷实例
  • 关键一步：附加左半平面零点使根轨迹向 s 左半平面弯曲，渐近线重心左移
  • 关键一步：零点吸引根轨迹分支，改善系统相对稳定性与快速性
  • 中间结果：零点的存在改变了相角条件与渐近线条数
  • 卡点：只答根轨迹左移，漏掉对渐近线与分离点的具体影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过说明附加左半平面开环零点对系统根轨迹的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
稳定裕度 频域分析
本卷考法
  • 说明截止频率的定义及其对系统性能的影响
本卷实例
  • 关键一步：截止频率是开环对数幅频特性 L(ω)=0dB 对应的频率
  • 关键一步：ωc 越大响应越快但可能引起振荡，越小则快速性变差
  • 中间结果：截止频率与带宽、动态响应速度正相关
  • 卡点：把截止频率与相位穿越频率 ωg 混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过说明截止频率的定义及其对系统性能的影响
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
超前校正 系统校正
本卷考法
  • 比较串联超前校正与串联滞后校正的区别
本卷实例
  • 关键一步：超前校正利用超前网络的相位超前提高相角裕度与快速性
  • 关键一步：滞后校正利用高频衰减提高低频增益、改善稳态精度但降低响应速度
  • 中间结果：超前校正抬高截止频率，滞后校正降低截止频率
  • 卡点：把两种校正对截止频率的影响方向答反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过比较串联超前校正与串联滞后校正的区别
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
非线性系统的特点 非线性系统
本卷考法
  • 说明非线性系统的基本特征
本卷实例
  • 关键一步：不满足叠加原理、可能存在多个平衡点
  • 关键一步：可能出现自激振荡、频率响应畸变甚至混沌
  • 中间结果：非线性系统不能沿用线性系统的全部结论
  • 卡点：只答不满足叠加原理，特点列举不全
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过说明非线性系统的基本特征
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
状态观测器设计 状态空间分析
本卷考法
  • 简述现代控制理论中的分离原理
本卷实例
  • 关键一步：对完全能控能观的系统，状态反馈与状态观测器可分别独立设计
  • 关键一步：再把两者组合成一个闭环系统，闭环极点为二者极点之和
  • 中间结果：分离原理成立的前提是系统既完全能控又完全能观
  • 卡点：没有强调「完全能控能观」这一前提条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态观测器用输出与输入重构状态，前提是系统能观
  • 极点配置法与龙伯格观测器是两种常用形式
  • 观测器误差动态由 A-LC 的特征值决定
  • 观测器极点通常取得比系统极点快若干倍
步骤
  • 验证系统能观性
  • 写出观测器方程并求误差动态矩阵
  • 按期望特征多项式比较系数求出 L
  • 校验观测器收敛速度是否合适
通用考法
  • 本卷考过简述现代控制理论中的分离原理
  • 设计全维状态观测器
  • 由期望观测器极点求反馈增益阵 L
  • 分析观测器与状态反馈组合后的系统极点
常见易错
  • 把观测器增益阵写成了状态反馈增益阵的形式
  • 忽略观测器极点过快会放大噪声

2二、梅森公式求闭环传递函数10 分#

思路
  • 由结构图求 C(s)/R(s)，解析给出三条回路与一条前向通路
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图用梅森增益公式求 C(s)/R(s)
本卷实例
  • 关键一步：先列全部独立回路并写出特征式 Δ=1−ΣL+ΣLL−…
  • 关键一步：再找从 R 到 C 的前向通路，逐条写增益与余子式
  • 关键一步：按 C/R=ΣPkΔk/Δ 合并
  • 中间结果：回路共有三条，前向通路只有一条且与各回路均接触
  • 中间结果：特征式分母是全回路增益之和
  • 卡点：不接触回路找漏或重复计数；把回路增益写成前向通路增益
  • 卡点：结构图未读图，回路与前向通路增益需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图用梅森增益公式求 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

3三、提高系统阻尼比10 分#

思路
  • 反馈通道 H(s)=Kt·s，确定 Kt 使系统阻尼比提高到 ξ1
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由给定阻尼比要求设计反馈通道参数
本卷实例
  • 关键一步：先由结构图写出闭环特征方程并整理成标准二阶形式
  • 关键一步：让 s 项系数与 2ξ1ωn 对应，与原阻尼比项联立
  • 关键一步：解出含 ωn、K 与两阻尼比的 Kt 表达式
  • 中间结果：输出反馈速度信号相当于给系统增加阻尼项
  • 中间结果：Kt 与阻尼比增量成正比、与开环增益成反比
  • 卡点：结构图未读图，反馈通道接入点与系数需回原卷核对图
  • 卡点：把开环阻尼比直接当闭环阻尼比代入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由给定阻尼比要求设计反馈通道参数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

4四、根轨迹绘制与稳定范围15 分#

思路
  • G(s)=K*/[s(s²+3s+9)]：绘制根轨迹并确定闭环稳定的 K* 范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制根轨迹并指出渐近线与出射角
本卷实例
  • 关键一步：标开环极点 0 与一对共轭复极点，算 n−m=3 条渐近线
  • 关键一步：按实轴段判据确定实轴上的根轨迹区间
  • 关键一步：由相角条件求共轭复极点的出射角
  • 中间结果：三条分支全部趋向无穷远，渐近线交点在实轴上 −1
  • 中间结果：共轭复极点出射角为一对相反角
  • 卡点：出射角累加相角时把该极点自身的相角也算进去
  • 卡点：复极点出射角未判象限导致差 180°
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制根轨迹并指出渐近线与出射角
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及系统稳定的 K* 范围
本卷实例
  • 关键一步：由闭环特征方程列劳斯表，令首元为零求临界 K*
  • 关键一步：由辅助方程解出虚轴交点频率
  • 关键一步：写出稳定区间
  • 中间结果：劳斯表首元为零对应根轨迹穿越虚轴
  • 中间结果：临界增益把稳定区间与不稳定区间分开
  • 卡点：只取一组交点漏掉另一组；得到 K* 后未回原题核对增益定义
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及系统稳定的 K* 范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式

5五、由对数幅频图反求滞后-超前校正15 分#

思路
  • 最小相位系统校正前(图a)与校正后(图b)对数幅频特性给定，校正前后开环增益不变：求校正方式与 Gc(s)、校正后稳定增益范围、K=1 时的相角裕度
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由校正前后对数幅频特性反求校正装置传递函数
本卷实例
  • 关键一步：分别从两图读出转折频率与低频段高度，写出校正前 L0(ω) 与校正后 L(ω)
  • 关键一步：由 Lc(ω)=L(ω)−L0(ω) 得到校正装置幅频特性
  • 关键一步：按转折频率处斜率变化写出 Gc(s) 并判断校正方式
  • 中间结果：校正装置在高低频段各有一个转折频率，呈滞后-超前特性
  • 中间结果：校正前后开环增益不变，低频段高度相同
  • 卡点：把延长线交点误当增益而未折算型别；斜率变化为 −40 时误判为一阶环节
  • 卡点：校正前后特性图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别

12十二、不能控系统的状态反馈极点配置10 分#

思路
  • 已知系统动态方程，问能否用 u=−kx 使闭环特征值为 −2、−2、−1，若能则求 k
能控性与能观性 状态空间分析
本卷考法
  • 判断系统能控性并进行结构分解
本卷实例
  • 关键一步：由 [B AB A²B] 求能控性矩阵的秩
  • 关键一步：把原状态方程化为能控性分解的标准形式，分离能控与不能控子系统
  • 关键一步：由不能控子系统的特征值判断系统是否可镇定
  • 中间结果：能控性矩阵不满秩，系统不完全能控
  • 中间结果：不能控极点为 −1，位于 s 左半平面，系统可镇定但极点不能全部任意配置
  • 卡点：只算到 A^{n−2}B 就下结论；未做分解直接列特征方程求 k
  • 卡点：原题状态空间表达式在 OCR 流中残缺，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解

  • 对不可控系统进行结构分解

本卷考法

本卷实例
  • 关键一步：只对能控子空间设反馈增益，写出其特征多项式
  • 关键一步：与期望特征式 (s+2)² 逐项比较系数求增益
  • 关键一步：把子空间增益变换回原坐标系，不能控极点保持不可改
  • 中间结果：不能控极点 −1 恰好等于期望极点之一，因此仍可实现题设闭环极点
  • 中间结果：可配置的增益分量唯一确定，含不能控状态的增益分量为任意值
  • 卡点：未先验证能控性就配极点；系数比对时符号写反
  • 卡点：把不完全能控系统当成可任意配置极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K

  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响

  • 特征多项式比较系数时符号写反
