一一、电路与机械系统的相似建模20 分#

思路
  • 分别对电路列复阻抗分压关系、对机械系统作多点受力分析列运动方程，再比较两系统传函形式说明相似性。
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由R-C网络用复阻抗求输出对输入的传递函数
本卷实例
  • 关键一步：按串联分压关系写两电容分压后的输出表达式
  • 中间结果：传函为二阶有理分式且系数由R、C组合决定
  • 卡点：电路图未读图，元件连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由R-C网络用复阻抗求输出对输入的传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
机械系统建模 建模与机电系统
本卷考法
  • 由弹簧-质量-阻尼系统受力分析求位移传函
本卷实例
  • 关键一步：分别对中间质量块与输出点列力平衡方程
  • 中间结果：消去中间位移后得到位移对输入的传函
  • 卡点：多点受力分析漏掉相互作用力的反作用项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过由弹簧-质量-阻尼系统受力分析求位移传函
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 比较电路与机械系统传函的相似关系
本卷实例
  • 关键一步：把两系统传函的系数逐项对应起来
  • 中间结果：电阻与弹性系数倒数、电容与阻尼系数对应时模型相同
  • 卡点：只比形式上是否同型而不看系数物理量对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过比较电路与机械系统传函的相似关系
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

二二、梅森公式求传函与由Bode图反求传函20 分#

思路
  • 第1问按结构图数回路与前向通路用梅森公式写传函；第2问由最小相位系统对数幅频的低频段高度与转折频率反写传函。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由多回路结构图用梅森公式求闭环传函
本卷实例
  • 关键一步：标出各单独回路与前向通路并写特征式
  • 中间结果：互不接触回路的乘积项计入特征式
  • 卡点：结构图未读图，回路与前向通路需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由多回路结构图用梅森公式求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频特性曲线反求最小相位系统传函
本卷实例
  • 关键一步：由低频段斜率定型别、由高度定增益
  • 中间结果：转折频率对应各一阶环节的时间常数
  • 卡点：把延长线交点误当增益值而未折算型别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频特性曲线反求最小相位系统传函
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式

三三、由闭环传函求静态误差系数与稳态误差20 分#

思路
  • 先把闭环传函化为开环传函，再按型别写出静态位置与速度误差系数，最后求阶跃和斜坡输入下的稳态误差。
系统型别与静态误差系数 稳态误差
本卷考法
  • 由闭环传函反推开环传函并判别系统型别
本卷实例
  • 关键一步：由闭环传函与开环传函的关系解出开环传函
  • 中间结果：开环分母含积分环节个数决定系统型别
  • 卡点：把闭环增益误当成开环增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由闭环传函反推开环传函并判别系统型别
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位阶跃与单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：按型别选用静态位置或速度误差系数公式
  • 中间结果：阶跃误差与斜坡误差由不同误差系数决定
  • 卡点：未判稳就直接使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位阶跃与单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 由误差传函理解静态误差系数
本卷实例
  • 关键一步：写出误差传函并取s趋于零的极限
  • 中间结果：误差系数是误差传函低频极限的组合
  • 卡点：非单位反馈时两种误差定义混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由误差传函理解静态误差系数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式

四四、二阶指标、斜坡误差与扰动不变性20 分#

思路
  • 由结构图求闭环传函，按标准二阶条件定参数并算动态指标与斜坡误差，再由扰动传函分子为零确定补偿器。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由结构图求闭环传函并对照标准二阶形式
本卷实例
  • 关键一步：列闭环特征方程后与标准式系数对齐
  • 中间结果：两个待定参数分别由自然频率和阻尼比确定
  • 卡点：结构图未读图，反馈系数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由结构图求闭环传函并对照标准二阶形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率算超调量和调整时间
本卷实例
  • 关键一步：按给定误差带选取调整时间的系数
  • 中间结果：超调量只由阻尼比决定
  • 卡点：把两种误差带的调节时间系数搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率算超调量和调整时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求扰动传函并令其为零确定补偿器
本卷实例

  • 中间结果：扰动传函分子为零即可实现扰动不变性
  • 卡点：求扰动传函时没有把参考输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

五五、以根轨迹增益为变量的根轨迹与增益范围20 分#

思路

根轨迹的绘制法则 根轨迹法
