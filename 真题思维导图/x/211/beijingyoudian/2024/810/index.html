1一、微分方程全响应与传递函数25 分#

思路
  • 由带初始值的二阶微分方程在单位阶跃输入下求输出全响应；再由方程在零初始条件下求系统传递函数。
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由微分方程与初始条件求系统的全响应
本卷实例
  • 关键一步：对微分方程逐项取拉氏变换，把两个初始值并入变换式
  • 关键一步：解出输出象函数后部分分式展开并取拉氏反变换
  • 中间结果：输出象函数含输入项与由初值产生的附加项
  • 卡点：只求零状态响应会漏掉初值决定的自由响应；初值符号易代错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由微分方程与初始条件求系统的全响应
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上
公式
传递函数的定义与基本性质 传递函数
本卷考法
  • 由微分方程求系统的传递函数
本卷实例
  • 关键一步：去掉初值项，按零初始条件对微分方程取拉氏变换
  • 关键一步：整理成输出象函数与输入象函数之比
  • 中间结果：传函分母为微分方程左端对应的特征多项式
  • 卡点：把带初值的全响应象函数直接当传函；忽略零初始前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由微分方程求系统的传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

2二、闭环稳定条件与临界增益25 分#

思路
  • 由给定闭环传函反推开环传函，用奈奎斯特判据讨论闭环稳定时增益与三个时间常数的关系；再求临界稳定的增益极值及该增益处的开环传函。
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据讨论闭环稳定的参数条件
本卷实例
  • 关键一步：由闭环传函反推开环传函，分别写幅频与相频
  • 关键一步：由相频等于负一百八十度求穿越频率，比较该处幅值与一
  • 中间结果：穿越频率由三个时间常数之和与乘积之比的开方给出
  • 卡点：忘记先数开环右半平面极点数；穿越频率处幅值比较方向搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据讨论闭环稳定的参数条件
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求临界稳定时开环增益的极值
本卷实例
  • 关键一步：令穿越频率处开环幅值等于一
  • 关键一步：解出临界增益关于三个时间常数的表达式
  • 中间结果：临界增益由三个时间常数在穿越频率处的幅值乘积给出
  • 卡点：把增益极值与系统型别混同；漏掉幅值条件的开方
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求临界稳定时开环增益的极值
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由闭环传函反推开环传递函数
本卷实例
  • 关键一步：按单位负反馈关系把闭环写成开环比上一加开环
  • 关键一步：反解出开环传函
  • 中间结果：开环传函分母为时间常数一阶环节的乘积，分子为增益
  • 卡点：反馈极性判断错导致分母符号反；代入临界增益时漏项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由闭环传函反推开环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

3三、参数对模态与快速性的影响25 分#

思路
  • 由结构图写闭环传函并化为标准二阶，讨论参数K、b对运动模态与稳定性的影响；再分析固定K时b对超调与调节时间的取舍，最后求斜坡稳态误差。
零极点分布与响应模态 传递函数
本卷考法
  • 由闭环极点讨论参数对系统运动模态的影响
本卷实例
  • 关键一步：把闭环传函化为标准二阶形式，写出阻尼比与自然频率
  • 关键一步：看实部即衰减模态与参数K、b的关系
  • 中间结果：衰减模态由阻尼比乘自然频率决定，与K乘b成正比
  • 卡点：只写极点位置不写与参数的关系；把运动模态与自然频率混同
  • 卡点：系统结构图为原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由闭环极点讨论参数对系统运动模态的影响
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零
公式
劳斯判据 稳定性分析
本卷考法
  • 由闭环特征方程用代数判据求稳定条件
本卷实例
  • 关键一步：写闭环特征方程，按降幂排列并补零
  • 关键一步：列判据式，令一次项与常数项系数同号
  • 中间结果：稳定条件化为K大于零且b大于零
  • 卡点：系数有缺项时不补零；只解一个系数符号就下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由闭环特征方程用代数判据求稳定条件
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 分析参数对阶跃响应快速性与超调的影响
本卷实例
  • 关键一步：固定K后自然频率不变，只有阻尼比随b变化
  • 关键一步：按调节时间与超调量公式看阻尼比变化的方向
  • 中间结果：b增大使阻尼比增大，调节时间与超调量同时减小
  • 卡点：只看超调不看调节时间；把阻尼比与自然频率的变化混在一起
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过分析参数对阶跃响应快速性与超调的影响
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 求单位斜坡输入下的静态误差系数与稳态误差
本卷实例
  • 关键一步：写开环传函，数积分环节个数定系统型别
  • 关键一步：由速度误差系数取斜坡输入下的稳态误差
  • 中间结果：速度误差系数由开环增益与反馈参数之比给出
  • 卡点：未判稳就用终值定理；把开环增益直接当速度误差系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过求单位斜坡输入下的静态误差系数与稳态误差
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

4四、根轨迹绘制与性能选参25 分#

思路
  • 三阶开环传函无零点，按法则画根轨迹并求渐近线、分离点、出射角与虚轴交点；再由超调量和调节时间要求圈出闭环极点的可行区域，选取根轨迹增益。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制三阶系统的根轨迹
本卷实例
  • 关键一步：由开环极点定分支数与实轴上的根轨迹段
  • 关键一步：写渐近线交点与夹角
  • 中间结果：三条分支趋于无穷远，渐近线交点在实轴左侧
  • 卡点：实轴段判据的零极点个数算错；渐近线夹角公式写成2k
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制三阶系统的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点与会合点
本卷实例
  • 关键一步：对等效开环的分子分母多项式写分离点方程
  • 关键一步：逐一判断候选根是否落在实轴根轨迹段上
  • 中间结果：本题候选根均不在实轴根轨迹段上，需全部舍去
  • 卡点：本题根轨迹无实轴分离点，误保留候选根会多画
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点与会合点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益

思路

频率特性的物理意义与求法 频域分析
本卷考法
  • 由开环传函写幅频、相频、实频与虚频特性
本卷实例

  • 中间结果：实频与虚频都是频率的有理分式

奈奎斯特判据 稳定性分析
本卷考法
  • 绘制开环幅相曲线并用奈奎斯特判据判稳
本卷实例
  • 关键一步：求频率趋于零与无穷时的幅值与相角，定曲线起终点
  • 关键一步：按相角变化判断曲线是否包围负一实轴点
  • 中间结果：开环无右半平面极点，曲线不包围负一实轴点则闭环稳定

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过绘制开环幅相曲线并用奈奎斯特判据判稳
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况

  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
