1一、火炮跟踪系统工作原理与校正器15 分#

思路
  • 按输入、反馈比较、放大校正、执行环节梳理火炮跟踪系统的调节过程，再由微分方程是否满足线性定常前提判断系统性质。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 叙述位置随动控制系统的工作原理与各环节作用
本卷实例
  • 关键一步：按给定输入、反馈比较、放大校正、执行驱动顺序梳理
  • 中间结果：输入为角度、输出为火炮转角，构成角度负反馈跟踪系统
  • 卡点：方框图未读图，比较点与反馈支路需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过叙述位置随动控制系统的工作原理与各环节作用
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
校正的基本概念与性能指标 系统校正
本卷考法
  • 说明校正器在跟踪系统中的位置与作用
本卷实例
  • 关键一步：校正器串入前向通路以改善动态性能
  • 中间结果：校正后跟踪精度提高、动态性能改善
  • 卡点：把校正器的作用与反馈元件的作用混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过说明校正器在跟踪系统中的位置与作用
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求
公式
传递函数的定义与基本性质 传递函数
本卷考法
  • 由微分方程能否拉氏变换判断系统线性定常性
本卷实例
  • 关键一步：先看方程是否满足可拉氏变换的线性定常前提
  • 中间结果：方程含常数项且需零初始条件，写不出传递函数
  • 卡点：忽略传递函数只对线性定常系统成立这一前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由微分方程能否拉氏变换判断系统线性定常性
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式

2二、电路系统的结构图与传递函数20 分#

思路
  • 由电容与电阻的复阻抗关系对电路列节点电流方程，画出对应结构图，再按分压或电流关系求输出与输入的传递函数。
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由电阻电容网络列方程求传递函数
本卷实例
  • 关键一步：按复阻抗写节点电流或分压关系式
  • 中间结果：输出与输入之比化为含两个一阶环节的二阶有理分式
  • 卡点：电路图未读图，元件连接拓补需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由电阻电容网络列方程求传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由电路结构列写系统传递函数并画结构图
本卷实例
  • 关键一步：把电容阻抗取为1/(Cs)与电阻阻抗一并代入网络方程
  • 中间结果：由电流分配关系可反推各级电压的传递关系
  • 卡点：复阻抗法把电容阻抗误写成Cs或漏掉负号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由电路结构列写系统传递函数并画结构图
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式

3三、控制器选型与动态性能指标20 分#

思路
  • 先由位置稳态误差为零确定控制器须含积分环节，再把闭环化为标准二阶，由超调量定阻尼比下界、由调节时间最短在两种可选时间常数中择优，并计算控制器参数。
系统型别与静态误差系数 稳态误差
本卷考法
  • 由位置稳态误差为零确定系统应具有的型别
本卷实例
  • 关键一步：位置误差为零要求开环至少含一个积分环节
  • 中间结果：所选控制器须带1/s环节即含纯积分
  • 卡点：只看误差有限而漏掉为零需积分环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由位置稳态误差为零确定系统应具有的型别
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为标准二阶并读阻尼比
本卷实例
  • 关键一步：闭环特征方程二次项系数归一化后对照标准式
  • 中间结果：阻尼比与自然频率由控制器参数与对象参数共同决定
  • 卡点：未归一化直接读系数导致阻尼比错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为标准二阶并读阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量定阻尼比并比较调节时间取最短
本卷实例
  • 关键一步：由超调量公式反解阻尼比下界
  • 中间结果：调节时间与自然频率成反比，故取较大自然频率对应的时间常数
  • 卡点：两个候选时间常数对应的调节时间大小比较反了
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量定阻尼比并比较调节时间取最短
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
PID 控制器与参数整定 系统校正
本卷考法
  • 在比例、比例积分、超前滞后三种控制器中选型
本卷实例
  • 关键一步：按无位置误差要求排除纯比例与无积分的控制器
  • 中间结果：选比例积分控制器并使其零点与对象极点对消
  • 卡点：选型只比动态性能而忘记稳态误差前置条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过在比例、比例积分、超前滞后三种控制器中选型
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式

4四、由根轨迹反求传函与附加零点#

思路
  • 由根轨迹图上开环极点的位置与条数反写开环传函形式，再增加开环零点后重画根轨迹并分析零点对稳定性和动态性能的影响。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 由根轨迹图读开环极零点并写传函形式
本卷实例
  • 关键一步：从根轨迹起点读出开环极点位置与重数
  • 中间结果：开环传函分母含原点重根与一个负实极点
  • 卡点：根轨迹图未读图，极点位置与重数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过由根轨迹图读开环极零点并写传函形式
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 判断附加零点后根轨迹有无分离点
本卷实例
  • 关键一步：写出分离点方程并筛去不在根轨迹上的解
  • 中间结果：所得二次方程无实根故无有效分离点
  • 卡点：不筛选就直接保留方程的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过判断附加零点后根轨迹有无分离点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求附加零点后根轨迹与虚轴的交点
本卷实例
  • 关键一步：令特征方程中s为jω并使实虚部同时为零
  • 中间结果：代入后方程组无正频率解，轨迹不与虚轴相交
  • 卡点：只代入一个频率就下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求附加零点后根轨迹与虚轴的交点
