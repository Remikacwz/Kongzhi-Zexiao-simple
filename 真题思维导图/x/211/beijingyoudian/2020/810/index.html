1一、系统线性定常性判断与线性化15 分#

思路
  • 把微分方程整理成输入输出的线性组合形式，按是否满足叠加原理判断线性定常性，再通过变量变换消除恒定项使其线性化。
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由微分方程判断系统线性定常性并说明理由
本卷实例
  • 关键一步：检查方程中是否含输入输出的恒定常数项
  • 中间结果：存在恒定项时叠加原理不成立即非线性
  • 卡点：只看方程阶次就断言系统线性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由微分方程判断系统线性定常性并说明理由
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上
公式
非线性模型的线性化 建模与机电系统
本卷考法
  • 通过变量变换把含恒定项的方程化为线性
本卷实例
  • 关键一步：引入平衡工作点偏差变量消去常数项
  • 中间结果：以偏差量表示后方程化为线性定常形式
  • 卡点：未先求平衡点就直接作线性化展开
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 在工作点附近作泰勒展开并忽略高阶项
  • 线性化模型只在小偏差范围内有效
  • 必须先求出平衡工作点
步骤
  • 由静态方程求平衡工作点
  • 在工作点处求偏导得到增量系数
  • 写出以增量表示的线性化方程
通用考法
  • 本卷考过通过变量变换把含恒定项的方程化为线性
  • 对非线性微分方程在平衡点处线性化
  • 写出小偏差线性化模型的传递函数
常见易错
  • 未先求平衡点就直接展开
  • 把增量符号去掉后与原始变量混用

2二、由闭环极点求二阶参数、传函与阶跃响应15 分#

思路
  • 由给定闭环极点写特征方程并与标准二阶形式对齐求自然频率、阻尼比与时间常数，再由放大倍数写传函并求阶跃响应。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环极点求自然频率、阻尼比与时间常数
本卷实例
  • 关键一步：由极点写特征方程并与标准式系数对齐
  • 中间结果：极点实部绝对值决定衰减系数与阻尼比
  • 卡点：把有阻尼自然频率与自然频率混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环极点求自然频率、阻尼比与时间常数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
零极点分布与响应模态 传递函数
本卷考法
  • 由极点分布写传函与响应模态
本卷实例
  • 关键一步：按共轭极点写二阶传函的分母因式
  • 中间结果：极点实部正负决定响应是否收敛
  • 卡点：只看极点分布就断定响应振荡
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由极点分布写传函与响应模态
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求单位阶跃作用下的输出响应表达式
本卷实例
  • 关键一步：部分分式分解后逐项求拉氏反变换
  • 中间结果：响应含衰减振荡项与恒定的稳态分量
  • 卡点：忽略分子零点或增益导致的初值跳变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求单位阶跃作用下的输出响应表达式
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3三、结构图化简求闭环传递函数20 分#

思路
  • 按串联、并联、反馈等效规则先化并联支路，再逐层化简含交叉反馈的多回路结构图，最终写出闭环传递函数。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 合并并联支路并化反馈回路求闭环传函
本卷实例
  • 关键一步：把两并联前向支路先相加合并
  • 中间结果：反馈回路等效为前向除以1加回路增益
  • 卡点：负反馈的分母误写成1-GH
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过合并并联支路并化反馈回路求闭环传函
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由多回路结构图逐层化简求总传函
本卷实例
  • 关键一步：从最内层回路开始向外逐层化简
  • 中间结果：每化一层内环后前向与反馈随之更新
  • 卡点：化简内环时把外环的信号当成常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由多回路结构图逐层化简求总传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式核对结构图化简结果
本卷实例
  • 关键一步：列出结构图的全部回路与前向通路
  • 中间结果：特征式含各独立回路增益与不接触项
  • 卡点：不接触回路找漏或重复计数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式核对结构图化简结果
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

4四、劳斯判据、静态误差系数与斜坡稳态误差25 分#

思路
  • 列劳斯表由首列大于零求稳定增益范围，再按系统型别写各静态误差系数并求单位斜坡下的稳态误差与满足要求的增益。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求使系统稳定的增益范围
本卷实例
  • 关键一步：按特征方程系数逐行列写劳斯表
  • 中间结果：由首列各元素大于零列出增益不等式
  • 卡点：系数有缺项时不补零直接套用判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求使系统稳定的增益范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 求静态位置、速度与加速度误差系数
本卷实例
  • 关键一步：按系统型别写各静态误差系数的极限式
  • 中间结果：一型系统的静态位置误差系数为无穷
  • 卡点：把开环增益与静态误差系数混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过求静态位置、速度与加速度误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡稳态误差要求反求开环增益
本卷实例
  • 关键一步：用速度误差系数与输入幅值列误差等式
  • 中间结果：稳态误差与开环增益成反比
  • 卡点：未先判稳就使用终值定理求误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位斜坡稳态误差要求反求开环增益
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

5五、根轨迹绘制、分离点与指定阻尼比极点25 分#

思路
  • 由开环零极点画根轨迹求分离点并算对应增益，再由指定阻尼比作等阻尼线求与轨迹交点得闭环极点。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画含零点系统的根轨迹
本卷实例
  • 关键一步：先定实轴根轨迹段与渐近线
  • 中间结果：含零点时轨迹复数部分可能呈圆或圆弧
  • 卡点：实轴段判据中零极点个数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画含零点系统的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
