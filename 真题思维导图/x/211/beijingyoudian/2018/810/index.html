1一、RC滤波网络建模与阶跃响应20 分#

思路
  • 对两级RC网络按复阻抗与电流关系列回路方程，消去中间变量得微分方程与传函，再取RC=1化分式求单位阶跃响应。
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 两级RC滤波网络列回路方程求输出对输入传函
本卷实例
  • 关键一步：按两电容分压与串联电流关系列回路方程
  • 中间结果：消去中间节点电位后得到二阶微分方程
  • 卡点：网络图未读图，元件串并联关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过两级RC滤波网络列回路方程求输出对输入传函
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由电路网络求传递函数并写出对应微分方程
本卷实例
  • 关键一步：用复阻抗写出两回路电压与电流关系
  • 中间结果：传函分母为R²C²s²+3RCs+1的二阶有理式
  • 卡点：把电容阻抗误写成Cs而不是1/(sC)
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由电路网络求传递函数并写出对应微分方程
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由传函对照标准二阶形式并用部分分式求阶跃响应
本卷实例
  • 关键一步：把输出写成部分分式后逐项求拉氏反变换
  • 中间结果：两个不相等实极点对应两个衰减指数项
  • 卡点：部分分式系数正负号与留数取值容易写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由传函对照标准二阶形式并用部分分式求阶跃响应
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

2二、由特征方程反求开环传函与主导极点降阶20 分#

思路
  • 由特征方程与阶跃无差条件定开环传函，再由闭环极点实部间距判断主导极点并把高阶系统降为二阶估算动态指标。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位阶跃稳态误差为零反推开环增益
本卷实例
  • 关键一步：由阶跃误差为零要求开环低频段含积分环节
  • 中间结果：开环传函分母保留积分因子并定出增益
  • 卡点：未先判稳就使用终值定理求稳态误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位阶跃稳态误差为零反推开环增益
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由特征方程与误差条件反求开环传递函数
本卷实例
  • 关键一步：由闭环特征方程与无零点条件反分开环
  • 中间结果：开环形式由分母因式与一个积分环节组成
  • 卡点：漏掉无零点条件导致开环多出一个零点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由特征方程与误差条件反求开环传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 按闭环极点实部比值判断主导极点并降阶
本卷实例
  • 关键一步：比较各闭环极点实部的相对大小
  • 中间结果：远离虚轴的极点对应模态可近似略去
  • 卡点：只看极点距离而不管该模态留数大小
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过按闭环极点实部比值判断主导极点并降阶
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由降阶后的二阶系统算超调量与调整时间
本卷实例
  • 关键一步：按给定误差带选取调节时间公式系数
  • 中间结果：超调量只由阻尼比决定与自然频率无关
  • 卡点：把两种误差带的调节时间系数搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由降阶后的二阶系统算超调量与调整时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式

3三、根轨迹绘制与去掉极点后的变化30 分#

思路
  • 由开环极点画根轨迹求渐近线、分离点与虚轴交点，再去掉一个极点重画并比较轨迹变化对系统稳定度的影响。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画三极点根轨迹并求渐近线
本卷实例
  • 关键一步：先数开环极点个数再定渐近线条数与夹角
  • 中间结果：三条分支趋于无穷远渐近线与实轴交于重心
  • 卡点：渐近线夹角公式中的2k+1写成2k
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画三极点根轨迹并求渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 由分离点方程求根轨迹分离点坐标
本卷实例
  • 关键一步：写各极点到分离点距离倒数和为零的方程
  • 中间结果：分离点必落在实轴根轨迹段上
  • 卡点：解出方程根后不筛选保留了不在轨迹上的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由分离点方程求根轨迹分离点坐标
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界增益
本卷实例
  • 关键一步：令特征方程中s=jω并使实虚部同时为零
  • 中间结果：除ω=0外还有一对纯虚根对应临界增益
  • 卡点：只代一个频率就下结论漏掉另一组交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 分析去掉一个开环极点对根轨迹与稳定度的影响
本卷实例
  • 关键一步：比较去掉极点前后的开环极点分布
  • 中间结果：去极点后轨迹分支数与渐近线随之改变
  • 卡点：把附加零点与附加极点的影响搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过分析去掉一个开环极点对根轨迹与稳定度的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反

4四、劳斯判据、无阻尼振荡频率与组合输入稳态误差20 分#

思路
  • 列劳斯表由首列大于零定稳定增益范围，由临界行辅助方程求无阻尼振荡频率，再按型别求组合输入下的稳态误差。
劳斯判据 稳定性分析
本卷考法
  • 列劳斯表求使系统稳定的开环增益范围
本卷实例
  • 关键一步：按特征方程系数逐行列写劳斯表
  • 中间结果：由首列各元素大于零联立增益不等式
  • 卡点：系数缺项时不补零直接套用劳斯判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过列劳斯表求使系统稳定的开环增益范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
