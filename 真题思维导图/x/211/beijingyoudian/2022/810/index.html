一一、水温开环控制系统的闭环设计20 分#

思路
  • 在开环加热系统上引入温度测量与反馈，画出闭环温度控制系统结构图，指认被控量、被控对象、执行机构与测量环节，并说明阀门开度随温差变化的调节过程。
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 设计闭环温度控制系统并指认各环节
本卷实例
  • 关键一步：引入温度计测量水温并与给定值比较后控制蒸汽阀门
  • 中间结果：构成以水温为被控量、水为被控对象的闭环系统
  • 卡点：原理图未读图，加热器与阀门位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过设计闭环温度控制系统并指认各环节
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 说明闭环温度控制系统的工作过程与调节原理
本卷实例
  • 关键一步：由测量-比较-执行-再测量构成闭环调节回路
  • 中间结果：水温低于给定值时温差增大、阀门开度增大
  • 卡点：把被控量水温与被控对象水混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过说明闭环温度控制系统的工作过程与调节原理
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

二二、信号流图与多输入传递函数20 分#

思路
  • 先把结构图改画为信号流图，再用梅森增益公式分别求两对输入输出通道的传递函数，注意两通道共用同一特征式。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图用梅森公式求多输入传函
本卷实例
  • 关键一步：先列出全部单独回路与两两不接触回路写特征式
  • 中间结果：两输入通道共用同一特征式，前向通路各不相同
  • 卡点：不接触回路找漏或余子式未剔除接触回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图用梅森公式求多输入传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求多输入多输出通道的传递函数
本卷实例
  • 关键一步：求某通道时把其余输入置零
  • 中间结果：输出为各输入通道传函的线性叠加
  • 卡点：结构图未读图，回路与注入点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求多输入多输出通道的传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 化简含交叉反馈的多回路结构图
本卷实例
  • 关键一步：由内到外逐层化简局部反馈环
  • 中间结果：化简后得到等效前向通路与反馈通路
  • 卡点：化简内环时把外环信号当成常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过化简含交叉反馈的多回路结构图
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

三三、静态误差系数与扰动响应25 分#

思路
  • 先由开环传函求各静态误差系数与典型输入稳态误差，再单独求扰动到输出的传函并反变换得c(t)，最后由扰动通道传函零频值判断能否消除扰动误差。
系统型别与静态误差系数 稳态误差
本卷考法
  • 求静态位置、速度误差系数与单位位置、速度误差
本卷实例
  • 关键一步：按开环传函在s趋于零的极限求各静态系数
  • 中间结果：一型系统位置误差为零、速度误差为有限值
  • 卡点：把开环增益与静态误差系数混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过求静态位置、速度误差系数与单位位置、速度误差
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 分析扰动引起的输出与能否消除扰动误差
本卷实例
  • 关键一步：令参考输入为零单独求扰动到输出的传函
  • 中间结果：扰动稳态输出为零则扰动误差可被消除
  • 卡点：求扰动传函时没有把参考输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过分析扰动引起的输出与能否消除扰动误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

四四、轮椅速度控制系统稳定与动态指标20 分#

思路
  • 先由闭环特征方程列劳斯表求使系统稳定的增益范围，再按给定调节时间用主导极点近似与闭环极点之和关系定出增益并求闭环特征根。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求使系统稳定的增益范围
本卷实例
  • 关键一步：把三阶特征方程列劳斯表并令首列各元大于零
  • 中间结果：稳定范围化为增益的双侧不等式
  • 卡点：漏掉倒数第二个首列元的不等式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求使系统稳定的增益范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由调节时间要求确定主导极点实部
本卷实例
  • 关键一步：由调节时间公式反解阻尼比与自然频率的乘积
  • 中间结果：主导极点实部由调节时间唯一确定
  • 卡点：调节时间误差带取百分之二时系数用4而非3
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由调节时间要求确定主导极点实部
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 用闭环极点之和定第三个极点并求特征根
本卷实例
  • 关键一步：由闭环极点之和等于开环极点之和求第三极点
  • 中间结果：比较特征多项式系数解出增益与一对共轭极点
  • 卡点：主导极点近似后未回代校验高阶项影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过用闭环极点之和定第三个极点并求特征根
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

五五、带钢热轧张力系统根轨迹25 分#

思路
  • 由结构图写以Ka为参变量的等效开环传函，按渐近线、分离点、实轴段与虚轴交点四步绘制根轨迹。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制四阶系统根轨迹草图
本卷实例
  • 关键一步：由开环零极点定渐近线交点与实轴段
  • 中间结果：渐近线条数与夹角由开环极点零点数之差决定
  • 卡点：实轴段奇偶判据方向弄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制四阶系统根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错

奈奎斯特判据 稳定性分析
本卷考法
  • 用奈氏判据由包围圈数判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数再数半次负穿越
  • 中间结果：由Z=P-2N得右半平面闭环极点数判定稳定性
  • 卡点：非最小相位系统仍套用最小相位结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈氏判据由包围圈数判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

稳定裕度 频域分析
本卷考法
  • 由相角裕度要求反求串联增益
本卷实例
  • 关键一步：令相角裕度等于目标值解出截止频率
  • 中间结果：增益由幅值条件在该截止频率处唯一确定
  • 卡点：把截止频率与相位穿越频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由相角裕度要求反求串联增益
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
