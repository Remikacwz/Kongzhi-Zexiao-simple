1一、直流电机调速系统结构图与传函20 分#

思路
  • 按电枢回路电压平衡、电机力矩平衡、反电势与测速反馈各环节方程画系统结构图，再用梅森公式求转速对输入的传函。
直流电机等机电系统 建模与机电系统
本卷考法
  • 由直流电机各环节方程建立系统结构图
本卷实例
  • 关键一步：分别写电枢电压平衡方程与电机力矩平衡方程
  • 中间结果：反电势回路与测速反馈各形成一条独立回路
  • 卡点：漏掉反电动势与电磁转矩的耦合项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由电枢回路电压方程与转矩平衡方程联立
  • 反电动势与转速成正比，电磁转矩与电枢电流成正比
  • 机电时间常数由电气与机械两方面参数共同决定
步骤
  • 写出电枢回路电压平衡方程
  • 写出转矩平衡方程（含负载与粘性摩擦）
  • 消去电枢电流，得到转速或转角对电压的传递函数
通用考法
  • 本卷考过由直流电机各环节方程建立系统结构图
  • 求直流电机转速或位置对电枢电压的传递函数
  • 分析机电时间常数与电气时间常数的数量级关系
常见易错
  • 漏掉反电动势与电磁转矩的耦合项
  • 把电气时间常数与机电时间常数混淆
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求转速对输入的传函
本卷实例
  • 关键一步：数出前向通路与两条独立回路
  • 中间结果：特征式为1减去各回路增益之和
  • 卡点：余子式中未剔除与通路接触的回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求转速对输入的传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由多环系统结构图求闭环传函
本卷实例
  • 关键一步：按信号流向逐层写输出与反馈关系
  • 中间结果：闭环分母含反电势与测速反馈两项
  • 卡点：化简内环时把外环的信号当成常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由多环系统结构图求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2二、一阶温度计时间常数与线性升温稳态误差20 分#

思路
  • 由一阶系统阶跃响应达到95%所需时间定时间常数，再求10%到90%的上升时间与线性升温下的稳态指示误差。
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由达到稳态95%的时间求一阶系统时间常数
本卷实例
  • 关键一步：按一阶阶跃响应指数式代入给定百分比
  • 中间结果：时间常数与达到95%的时间成定比
  • 卡点：把63.2%对应时刻记成50%对应时刻
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由达到稳态95%的时间求一阶系统时间常数
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 求一阶系统从10%变化到90%所需时间
本卷实例
  • 关键一步：分别求两个百分比对应时刻再相减
  • 中间结果：上升时间由两个对数项之差与时间常数决定
  • 卡点：直接按时间常数乘常数而不代入对数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 线性升温输入下求温度计的稳态指示误差
本卷实例
  • 关键一步：把线性升温折算成等速斜坡输入
  • 中间结果：稳态误差与速度误差系数成反比
  • 卡点：未先判稳就使用终值定理求误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过线性升温输入下求温度计的稳态指示误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由闭环一阶传函反推开环传函并判定型别
本卷实例
  • 关键一步：由闭环传函与开环传函关系解出开环
  • 中间结果：开环含一个积分环节为一型系统
  • 卡点：把闭环增益误当成开环增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由闭环一阶传函反推开环传函并判定型别
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式

3三、结构图等效变换求闭环与误差传函20 分#

思路
  • 按比较点与引出点移动规则逐层化简多回路结构图，分别求输出对输入与误差对输入的传递函数。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图等效变换求闭环传递函数
本卷实例
  • 关键一步：先合并并联支路再逐层化简反馈回路
  • 中间结果：闭环分母出现两回路增益之和
  • 卡点：负反馈的分母误写成1-GH
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由结构图等效变换求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
比较点与引出点的移动 结构图与方框图
本卷考法
  • 移动比较点或引出点化简交叉结构图
本卷实例
  • 关键一步：把中间引出点前移或比较点后移
  • 中间结果：移动后被跨接支路增益作相应补偿
  • 卡点：移动方向与乘除关系搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过移动比较点或引出点化简交叉结构图
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
误差定义与误差传递函数 稳态误差
本卷考法
  • 由R与C传函求误差对输入的传递函数
本卷实例
  • 关键一步：按误差定义写E=R-C再代入闭环传函
  • 中间结果：误差传函与闭环传函共用同一分母
  • 卡点：非单位反馈时两种误差定义混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由R与C传函求误差对输入的传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式

4四、二阶系统按阻尼比选参与动态指标25 分#

思路
  • 由结构图写闭环特征方程，按给定阻尼比定参数，再分别对不加与加零点两种情形计算二阶动态性能指标。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征方程对照标准二阶形式定参数
本卷实例
  • 关键一步：把闭环特征方程s²项系数归一化
  • 中间结果：由ζ与ωn条件解出待定放大倍数
  • 卡点：归一化时把开环增益误当闭环系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征方程对照标准二阶形式定参数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由ζ与ωn算峰值上升调整时间与超调量
本卷实例
  • 关键一步：按给定误差带选取调整时间公式系数
  • 中间结果：峰值时间与上升时间由有阻尼频率决定
  • 卡点：峰值时间与上升时间混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由ζ与ωn算峰值上升调整时间与超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 分析增加比例微分环节引入零点对动态指标的影响
本卷实例
  • 关键一步：比较加零点前后闭环传函的差别
  • 中间结果：附加零点使超调与响应速度同时变化
  • 卡点：只用标准二阶公式而不考虑零点作用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
