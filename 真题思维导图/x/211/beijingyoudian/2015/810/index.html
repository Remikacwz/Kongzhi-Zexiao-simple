1一、电炉箱恒温系统组成与反馈量指认20 分#

思路
  • 按给定、反馈、比较、放大、执行环节梳理调温过程，再由炉温偏差的大小与方向判断各物理量的角色。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 说明恒温控制系统的工作过程与各环节作用
本卷实例
  • 关键一步：按给定、反馈比较、放大、执行的顺序梳理调节过程
  • 中间结果：炉温偏低或偏高时偏差电压极性相反、电动机正反转
  • 卡点：原理图未读图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过说明恒温控制系统的工作过程与各环节作用
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由原理图抽象出给定、比较、放大、执行与反馈的框图
本卷实例
  • 关键一步：把热电偶测量电压与给定电压比较后送入放大执行环节
  • 中间结果：炉温为被控制量、实际炉温为反馈量、环境温度为扰动量
  • 卡点：把给定量与反馈量的位置写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由原理图抽象出给定、比较、放大、执行与反馈的框图
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、多回路结构图的信号流图与梅森公式20 分#

思路
  • 先按结构图逐环节标出节点与支路得信号流图，再数独立回路、找前向通路并用梅森公式写传函。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图数回路与前向通路并用梅森公式求传函
本卷实例
  • 关键一步：按结构图的节点与支路关系画信号流图并标支路增益
  • 中间结果：独立回路数与互不接触关系决定特征式的各项
  • 卡点：结构图未读图，回路与前向通路需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图数回路与前向通路并用梅森公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路系统的逐层化简与回路识别
本卷实例
  • 关键一步：先认内环再处理外环，或直接用梅森公式
  • 中间结果：特征式为1减各回路增益加不接触回路乘积
  • 卡点：不接触回路找漏或重复计数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路系统的逐层化简与回路识别
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

串联、并联与反馈等效 结构图与方框图

  • 中间结果：闭环时间常数因加入反馈而改变
  • 卡点：结构图未读图，反馈极性需回原卷核对图

一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 求一阶系统脉冲响应与时间常数
本卷实例
  • 关键一步：把一阶传函写成分母含时间常数的一次式
  • 中间结果：开环与闭环时间常数之比由开环增益决定
  • 卡点：把脉冲响应与阶跃响应的时间常数混同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过求一阶系统脉冲响应与时间常数
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
典型环节及其特性 传递函数
本卷考法
  • 由传函辨识一阶惯性环节并读时间常数
本卷实例
  • 关键一步：化为分母常数项为1的标准形式再读系数
  • 中间结果：时间常数只出现在分母一次项系数上
  • 卡点：把增益误当成时间常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过由传函辨识一阶惯性环节并读时间常数
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减

4四、随动系统二阶指标与斜坡稳态误差15 分#

思路
  • 把闭环化为标准二阶，由超调量与峰值时间联立解增益与速度反馈系数，再由参数算动态指标与斜坡误差。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由结构图求闭环传函并化为标准二阶形式
本卷实例
  • 关键一步：写出闭环特征方程后把二次项系数归一化
  • 中间结果：阻尼比与自然频率由增益和反馈系数共同决定
  • 卡点：结构图未读图，反馈支路系数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由结构图求闭环传函并化为标准二阶形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间反求增益和反馈系数
本卷实例
  • 关键一步：由超调量解阻尼比、由峰值时间解自然频率
  • 中间结果：两式联立可定出两个待求参数
  • 卡点：超调量公式中漏乘100%导致阻尼比解错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量与峰值时间反求增益和反馈系数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率计算上升时间和调整时间
本卷实例
  • 关键一步：按给定误差带选择调整时间的系数
  • 中间结果：上升时间与调整时间均由阻尼比和自然频率组合得到
  • 卡点：把两种误差带的调整时间系数搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率计算上升时间和调整时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

  • 本卷考过求单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
