1一、冰箱温度闭环系统与环节指认#

思路
  • 把冰箱看作恒值温度闭环，从给定温度经检测、比较、放大到压缩机，再沿被控对象回到检测端，按环节指认实物并用流程图把信号流串起来
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 说明冰箱温度闭环的工作过程并画出系统流程图
  • 指出控制量、执行元件、测量元件与被控对象
本卷实例
  • 关键一步：从恒值控制入手：被控量是箱内温度，操纵量是压缩机的接通与断开
  • 关键一步：按给定、比较、控制、执行、对象、检测的顺序把信号流串成闭环再画流程图
  • 中间结果：控制量是压缩机通断这一开关量，被控对象是冰箱体
  • 中间结果：测量元件用温度传感器，执行元件用压缩机
  • 卡点：控制量与执行元件容易混：控制量是通断指令，执行元件是压缩机本身
  • 卡点：图1只给冰箱结构示意，比较放大环节的具体画法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过说明冰箱温度闭环的工作过程并画出系统流程图
  • 本卷考过指出控制量、执行元件、测量元件与被控对象
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

2二、由闭环特征方程反推开环传函与时域指标#

思路
  • 由单位反馈下闭环特征式等于一加开环传函，配合无零点与阶跃无差条件定出开环传函；再由已知闭环极点分解特征式，用主导极点法算二阶动态指标
传递函数的定义与基本性质 传递函数
本卷考法
  • 由闭环特征方程和系统无零点条件写出开环传递函数
本卷实例
  • 关键一步：单位反馈时闭环特征式等于一加开环传函，无零点说明开环分子只能是常数
  • 关键一步：阶跃输入下稳态误差为零要求开环含积分环节，据此把特征式拆出 s 因式
  • 中间结果：把特征式写成 s 乘二次多项式再加开环增益常数的形式，常数项即增益
  • 中间结果：开环分母的二次因式与特征式去掉常数项后的部分相同
  • 卡点：直接拿特征式减一当开环传函会得到含零点的分式，与无零点和无差条件都不符
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由闭环特征方程和系统无零点条件写出开环传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由阶跃无差判断系统型别并求静态速度误差系数
本卷实例
  • 关键一步：阶跃输入下稳态误差为零说明系统至少是Ⅰ型，按含一个积分环节处理
  • 关键一步：静态速度误差系数由开环传函乘一个 s 后取 s 趋于零的极限求得
  • 中间结果：阶跃无差定下开环分母含 s，同时把开环增益的取值一并定出
  • 卡点：型别只看开环中积分环节个数，不要用闭环特征式的最高次幂去判
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由阶跃无差判断系统型别并求静态速度误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡输入下系统的稳态误差
本卷实例
  • 关键一步：先确认闭环稳定再使用终值定理，Ⅰ型系统的斜坡误差由速度误差系数决定
  • 关键一步：速度误差系数与斜坡误差互为倒数，注意分子分母不要写反
  • 中间结果：速度误差系数由开环传函去掉一个 s 后取低频极限，分母常数项决定其大小
  • 卡点：本题阶跃无差而斜坡有差，正说明系统只是一型而不是二型
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位斜坡输入下系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 用长除法分离已知极点并把闭环化成二阶标准形式
本卷实例
  • 关键一步：已知一个闭环极点时先用长除法把它从特征式中分离，得到剩余二次因式
  • 关键一步：把剩余二次式与二阶标准形式逐项比对，读出阻尼比与自然频率
  • 中间结果：剩余二次因式的判别式为负，说明另一对闭环极点是一对共轭复根
  • 卡点：分离出的实极点与复极点对实部之比用于判断能否当主导极点处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过用长除法分离已知极点并把闭环化成二阶标准形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求超调量与百分之二误差带下的调整时间
本卷实例
  • 关键一步：超调量只取决于阻尼比，由标准形式读出阻尼比后代入指数式
  • 关键一步：调整时间在百分之二误差带下取四点四除以实部绝对值
  • 中间结果：本题阻尼比使超调量指数中恰好出现圆周率，可直接查用题给或常用数值
  • 中间结果：实部绝对值等于阻尼比乘自然频率，与调整时间公式对应
  • 卡点：高阶系统中实极点使实际超调略小于纯二阶值，主导极点法只是近似
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求超调量与百分之二误差带下的调整时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3三、含反馈环节的根轨迹与附加零点#

思路
  • 先由结构写出以 k 星为参变量的开环传函并整理成标准根轨迹形式，再按起点终点、实轴段、渐近线、分离点与虚轴交点顺序画草图；第二问讨论在前向通道加入一个左半平面零点后各条法则的结果如何变化
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 写出以 k 星为参变量的开环传函并整理成标准根轨迹方程
本卷实例
  • 关键一步：把反馈环节与对象一起写出开环传函，再整理成一加 k 星乘开环为零的形式
  • 关键一步：常规根轨迹用一百八十度相角条件，只有正反馈才换成零度条件
  • 中间结果：开环极点由前向通道与反馈环节的极点共同组成，分支数等于极点总数
  • 卡点：前向通道的具体零极点在原卷图2中，逐年试题册未印出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过写出以 k 星为参变量的开环传函并整理成标准根轨迹方程
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按起点终点、实轴段与渐近线法则绘制根轨迹草图
本卷实例
  • 关键一步：根轨迹起于全部开环极点、终于开环零点或无穷远，先标点再判实轴段
  • 关键一步：实轴段判据是看该段右侧的零极点总数是否为奇数
  • 中间结果：三个极点且无零点时渐近线有三条，交点在实轴上，夹角按三等分圆周
  • 卡点：反馈环节贡献的极点也要计入开环极点总数，漏计会少一条分支
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按起点终点、实轴段与渐近线法则绘制根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹在实轴上的分离点并筛选合理解
本卷实例
  • 关键一步：分离点满足开环传函对 s 的导数为零，化为分子分母乘积的导数方程求解
  • 关键一步：解出的驻点必须落在实轴根轨迹段上才保留，其余舍去
  • 中间结果：本题分离点方程是二次的，两个根中只有一个位于实轴根轨迹段内
  • 卡点：原卷图2未读，开环零极点具体位置需回原卷核对后再列同一形式的方程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹在实轴上的分离点并筛选合理解
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴的交点及对应的临界参数
本卷实例
  • 关键一步：令 s 取纯虚数代入闭环特征方程，实部与虚部分别为零联立求解
  • 关键一步：也可列劳斯表令首列出现零，再由辅助方程解出角频率
  • 中间结果：无零点时临界参数由劳斯表首列首次为零的条件给出，对应一对纯虚根
  • 卡点：加入零点后劳斯表首列恒为正，根轨迹与虚轴没有交点，结论与无零点时相反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向

常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

附加开环零极点的影响 根轨迹法
本卷考法
  • 说明在前向通道加入一个零点后根轨迹形状的变化
本卷实例
  • 关键一步：零点加入后开环零点数由零变一，一条分支终止于该零点，其余分支趋于无穷远
  • 关键一步：实轴段与渐近线都要按新的零极点重新判断，轨迹整体向左半平面偏移
  • 中间结果：附加零点改变渐近线的交点与夹角，也改变各分支在实轴上的分布
  • 卡点：原开环零极点位置未印在试题册上，偏移方向需回原卷核对图后确认
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向

通用考法

  • 分析为何某系统需要引入零点

  • 把附加零点的影响与附加极点的影响搞反

4四、串联超前校正设计#

思路

系统型别与静态误差系数 稳态误差
本卷考法
  • 由单位斜坡静态误差系数要求反求开环增益
本卷实例
  • 关键一步：静态速度误差系数由开环传函乘 s 后取低频极限得到，与开环增益成正比
  • 关键一步：把系数要求写成关于开环增益的不等式，再取满足要求的最小方便值
  • 中间结果：速度误差系数与开环增益的比值由对象分母的常数项决定
  • 卡点：开环增益定下后会影响穿越频率与相角裕度，后续校正都必须沿用这个取值

  • 代入求值

稳定裕度 频域分析
本卷考法
  • 计算未校正系统的相角裕度并确定所需补偿相角
本卷实例
  • 关键一步：相角裕度等于一百八十度加幅值穿越频率处的相角，先定穿越频率再累加各环节相角
  • 关键一步：由目标相角裕度减去未校正相角裕度得到需要补偿的相角
  • 中间结果：题给的反正切参考数据用于在穿越频率处累加各典型环节的相角
  • 卡点：题面条件二十倍对数一项按幅值裕度不小于十分贝理解，原处排版存疑需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过计算未校正系统的相角裕度并确定所需补偿相角
  • 求系统的相角裕度与幅值裕度

  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

校正的基本概念与性能指标 系统校正
本卷考法

超前校正 系统校正
本卷考法
  • 设计串联超前校正装置的衰减系数、零点与极点
本卷实例
  • 关键一步：由所需最大超前角用反正弦公式求出衰减系数，再令两转折频率的几何中点等于新穿越频率
  • 关键一步：由衰减系数与新穿越频率分别定出超前环节的两个时间常数
  • 中间结果：题给的四次方根与平方根参考数据用于计算新穿越频率和两个时间常数
  • 中间结果：校正环节是零点时间常数比极点时间常数大衰减系数倍的一阶超前网络
  • 卡点：参数算出后要按校正后开环重画 Bode 图并核对相角裕度与幅值裕度两项指标
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过设计串联超前校正装置的衰减系数、零点与极点
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
