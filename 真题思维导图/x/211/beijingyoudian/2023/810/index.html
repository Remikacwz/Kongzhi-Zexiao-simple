1一、位置随动系统建模与传递函数25 分#

思路
  • 先由电位器量程与电压范围算传递系数、由运放电路算两级放大器系数，再由电枢回路方程求直流电动机传函，最后画结构图并用梅森公式求位置传函。
直流电机等机电系统 建模与机电系统
本卷考法
  • 由电枢回路与转矩方程求直流电动机传函
本卷实例
  • 关键一步：列电枢回路电压方程并联立电磁转矩与转动方程
  • 中间结果：反电势与电磁转矩的耦合项一并消去后得输入输出关系
  • 卡点：漏掉反电动势或把电气时间常数与机电时间常数混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由电枢回路电压方程与转矩平衡方程联立
  • 反电动势与转速成正比，电磁转矩与电枢电流成正比
  • 机电时间常数由电气与机械两方面参数共同决定
步骤
  • 写出电枢回路电压平衡方程
  • 写出转矩平衡方程（含负载与粘性摩擦）
  • 消去电枢电流，得到转速或转角对电压的传递函数
通用考法
  • 本卷考过由电枢回路与转矩方程求直流电动机传函
  • 求直流电机转速或位置对电枢电压的传递函数
  • 分析机电时间常数与电气时间常数的数量级关系
常见易错
  • 漏掉反电动势与电磁转矩的耦合项
  • 把电气时间常数与机电时间常数混淆
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 绘制含测速反馈的多回路系统结构图
本卷实例
  • 关键一步：按各环节输入输出关系逐级连接并标反馈极性
  • 中间结果：局部测速反馈与主反馈构成多回路结构
  • 卡点：原理图未读图，电动机与测速机连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过绘制含测速反馈的多回路系统结构图
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求位置随动系统的传递函数
本卷实例
  • 关键一步：数出两条单独回路并写特征式与前向通路
  • 中间结果：两回路互不接触时特征式含其乘积项
  • 卡点：把前向通路增益写成回路增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求位置随动系统的传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、复合校正与系统型别提升25 分#

思路
  • 按结构图等效变换求闭环传函，再写误差传函并由斜坡输入稳态误差为零定前馈参数，最后令误差传函分子低次项为零使系统型别提升并写等效开环传函。
反馈校正与复合控制 系统校正
本卷考法
  • 设计前馈补偿装置使给定输入误差为零
本卷实例
  • 关键一步：在前馈支路引入输入的一阶与二阶导数项
  • 中间结果：前馈补偿器为输入量与输入量导数的线性组合
  • 卡点：前馈补偿器含高阶微分不可实现却直接采用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过设计前馈补偿装置使给定输入误差为零
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 用结构图等效变换求闭环传递函数
本卷实例
  • 关键一步：按比较点与引出点移动规则合并前馈与主通路
  • 中间结果：闭环传函分子含前馈项、分母保持不变
  • 卡点：把前馈支路与反馈支路混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过用结构图等效变换求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由斜坡输入稳态误差为零反求前馈参数
本卷实例
  • 关键一步：对误差传函取s趋于零极限并令其为零
  • 中间结果：误差传函的常数项为零给出一个参数条件
  • 卡点：只让误差有限而不为零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由斜坡输入稳态误差为零反求前馈参数
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由误差传函分子低次项为零判断系统型别提升
本卷实例
  • 关键一步：令误差传函分子s的一次项与常数项同时为零
  • 中间结果：开环传函分母s幂次增加、系统型别提高
  • 卡点：型别提升后未回代校验稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由误差传函分子低次项为零判断系统型别提升
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式

3三、由阶跃响应反求系统参数25 分#

思路
  • 由阶跃响应初始斜率与稳态值写出闭环传函形式，再由稳态误差为零定积分环节，比较系数求出参数。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由阶跃响应初始斜率与稳态值反求传函
本卷实例
  • 关键一步：用终值定理与初值定理把响应特征对应到传函
  • 中间结果：闭环传函由响应稳态值与初始斜率共同确定
  • 卡点：未判断系统阶数就直接套用二阶公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由阶跃响应初始斜率与稳态值反求传函
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

4四、圆根轨迹与最小阻尼比25 分#

思路
  • 按开环极点与零点画根轨迹，用坐标代入特征方程消参证明轨迹为圆，再由等阻尼线与圆相切求阻尼比最小时的根轨迹增益与闭环传函。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制含一个零点两个极点的根轨迹
本卷实例
  • 关键一步：定实轴段、渐近线与起始走向
  • 中间结果：轨迹自两极点出发、终止于零点与无穷远
  • 卡点：实轴段奇偶判据方向弄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制含一个零点两个极点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求分离点或判断轨迹不入虚轴
本卷实例
  • 关键一步：由dK/ds为零写方程并筛选有效根
  • 中间结果：轨迹全程位于左半平面、与虚轴无交点
  • 卡点：不筛选就保留不在根轨迹上的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求分离点或判断轨迹不入虚轴
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由等阻尼线与根轨迹相切求最小阻尼比参数
本卷实例
  • 关键一步：等阻尼线与根轨迹相切处对应阻尼比最小
  • 中间结果：切点坐标由几何关系定出再代入幅值条件求增益
  • 卡点：把等阻尼线画成垂直线或阻尼比方向取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

稳定裕度 频域分析
本卷考法
  • 求截止频率与相位裕度并判断稳定性
本卷实例
  • 关键一步：由幅值等于1求截止频率再代入相频
  • 中间结果：相位裕度由截止频率处相角的余量决定
  • 卡点：把截止频率与相位穿越频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求截止频率与相位裕度并判断稳定性
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

6六、串联滞后-超前校正设计25 分#

思路
  • 由校正后对数幅频折线反求校正后开环传函并与原传函作比得校正装置传函，判断为滞后-超前校正，再画装置折线并算校正前后相角裕度。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由校正后对数幅频折线反求开环传函
本卷实例
  • 关键一步：读低频段斜率与高度并逐段列转折频率环节

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别

  • 每个转折频率对应一个一阶或二阶环节

  • 写出并验证传递函数
通用考法

  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
