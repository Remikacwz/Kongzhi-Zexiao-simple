1一、反馈控制系统的组成与方框图15 分#

思路
  • 描述人洗澡时用手试水温直到合适的反馈过程，指出适宜水温为输入、实际水温为输出、大脑为控制装置、热水器为被控对象。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 由人体洗澡调温过程指出输入、输出、控制装置与被控对象
本卷实例
  • 关键一步：把实际水温与人体适宜水温之差作为偏差信号
  • 关键一步：大脑作比较与决策、手作执行，热水器为被控对象
  • 中间结果：输入为适宜水温，输出为实际水温，被控对象为热水器
  • 卡点：控制装置是大脑而不是手，手只是执行机构
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过由人体洗澡调温过程指出输入、输出、控制装置与被控对象
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

2二、二阶系统指标反求参数与稳态误差18 分#

思路
  • 由控制框图写闭环传递函数，按超调量与峰值时间反求 ξ、ωn 与 K、A，再算上升时间、调节时间并判断稳定后求单位阶跃下的稳态误差。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由二阶闭环传函化标准形式求阻尼比与自然频率
本卷实例
  • 关键一步：写出闭环传函并整理成标准二阶形式
  • 关键一步：与 ωn² 和 2ξωn 逐项比较读参数
  • 中间结果：闭环特征多项式为 s² 加 (1 加 Ak)s 加 k
  • 卡点：分母 s² 项系数需先归一化再读参数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由二阶闭环传函化标准形式求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间联立反求 K 和 A
本卷实例
  • 关键一步：用超调量公式与峰值时间公式联立解 ξ 与 ωn
  • 关键一步：把 ξ、ωn 代回特征多项式系数关系求 K 与 A
  • 中间结果：超调量只决定阻尼比，峰值时间同时含 ωn
  • 卡点：两个指标先独立解 ξ 与 ωn，再联立解 K 与 A，顺序别乱
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量与峰值时间联立反求 K 和 A
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由 ξ 与 ωn 计算上升时间与调节时间
本卷实例
  • 关键一步：把阻尼比与自然频率代入上升时间公式
  • 关键一步：调节时间按百分之五和百分之二两种误差带分别计算
  • 中间结果：上升时间公式含反余弦阻尼比的相角
  • 卡点：两种误差带的调节时间系数不同，别混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由 ξ 与 ωn 计算上升时间与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 判断稳定后求单位阶跃输入下的稳态误差
本卷实例
  • 关键一步：先用特征根或劳斯判据确认闭环稳定
  • 关键一步：写出误差传函后用终值定理求稳态误差
  • 中间结果：单位阶跃输入下稳态误差取决于开环是否含积分环节
  • 卡点：未判稳就用终值定理会得到错误结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过判断稳定后求单位阶跃输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、非最小相位系统的奈奎斯特判据15 分#

思路
  • 由开环传函写幅频与相频表达式画奈奎斯特曲线，数开环右半平面极点数与净包围圈数，求闭环右半平面极点数并判稳。
频率特性的物理意义与求法 频域分析
本卷考法
  • 由开环传函写幅频相频并画概略奈奎斯特曲线
本卷实例
  • 关键一步：令 s 等于 jω 代入，实部虚部分开后写幅值与相角
  • 关键一步：取 ω 趋于零与无穷大确定起止点
  • 中间结果：开环含一个积分环节与一个右半平面极点，相角自负270度起
  • 卡点：右半平面极点使相角计算需按第四象限取值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由开环传函写幅频相频并画概略奈奎斯特曲线
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由奈奎斯特曲线数包围圈数求右半平面闭环极点数
本卷实例
  • 关键一步：先数开环右半平面极点数 P
  • 关键一步：由 Z 等于 P 减 2N 求右半平面闭环极点数
  • 中间结果：曲线与负实轴的交点决定包围圈数
  • 卡点：半圈要按正负分别计入净圈数，别只数整圈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由奈奎斯特曲线数包围圈数求右半平面闭环极点数
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
最小相位系统与非最小相位系统 频域分析
本卷考法
  • 识别开环含右半平面极点的非最小相位系统
本卷实例
  • 关键一步：由开环分母 Ts 减 1 判断存在右半平面极点
  • 关键一步：非最小相位系统的相角变化范围与最小相位不同
  • 中间结果：相频表达式为负90度减180度再与反正切组合的形式
  • 卡点：不能只凭幅频曲线唯一确定非最小相位系统的传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过识别开环含右半平面极点的非最小相位系统
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈

4四、串联滞后校正与截止频率15 分#

思路
  • 由校正装置传递函数识别滞后校正，画校正前后对数幅频特性，分段求校正前后截止频率，再由相频表达式求相角裕量。
滞后校正 系统校正
本卷考法
  • 识别串联滞后校正并分析其频率特性
本卷实例
  • 关键一步：由 Go(s) 分子零点在极点右侧判断为滞后校正
  • 关键一步：写出校正后开环传函并找出各转折频率
  • 中间结果：滞后校正以牺牲带宽换取低频增益提高
  • 卡点：校正装置里 b 小于一，转折频率顺序别写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过识别串联滞后校正并分析其频率特性
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制校正前后对数幅频特性并逐段定斜率
本卷实例
  • 关键一步：由开环传函确定低频段斜率与高度
  • 关键一步：按各转折频率依次改变渐近线斜率
  • 中间结果：校正后低频段高度提高、截止频率左移
  • 卡点：逐段改斜率是累加不是替换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过绘制校正前后对数幅频特性并逐段定斜率
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
稳定裕度 频域分析
本卷考法
  • 求校正前后截止频率与相角裕量
本卷实例
  • 关键一步：分段假设截止频率所在区间，令幅值等于一求解
  • 关键一步：代入相频表达式求相角裕量
  • 中间结果：校正前相角裕量很小甚至为负，校正后应满足指标要求
  • 卡点：假设的截止频率区间要与解出的结果自洽
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

通用考法
  • 本卷考过用零阶保持器把连续状态方程离散化
  • 求连续系统在给定采样周期下的离散化状态方程
  • 由给出的状态响应反求系统矩阵再离散化
  • 计算采样点上的状态与输出序列
常见易错
  • 把采样周期直接当成时间常数代进连续传函
  • 积分上限写成采样周期以外的量，或忘记乘输入矩阵
