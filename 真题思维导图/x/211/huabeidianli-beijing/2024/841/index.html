1一、反馈控制原理举例15 分#

思路
  • 从日常活动中找闭环控制实例，指认给定、被控对象、输出量与控制装置，并按信号流向画控制方框图
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 举例说明反馈控制原理并指认控制系统各环节
本卷实例
  • 关键一步：选一个含检测与比较的日常闭环实例，按给定、比较、控制、对象、检测串环
  • 中间结果：方框图由给定、比较、控制装置、被控对象与反馈通道构成
  • 卡点：被控对象与控制装置易混，须逐项指认输入信号、被控对象、输出量、控制装置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过举例说明反馈控制原理并指认控制系统各环节
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

2二、齿轮系运动微分方程15 分#

思路
  • 两齿轮线速度与传递功率相等，先对各轴用动静法列方程，再消去中间变量得输入到输出的微分方程
机械系统建模 建模与机电系统
本卷考法
  • 由齿轮传动关系与转动惯量列写机械系统运动微分方程
本卷实例
  • 关键一步：由线速度相等得两轴转速关系，由功率相等得两轴转矩关系
  • 中间结果：对各齿轮用动静法列转动方程，含转动惯量、粘性摩擦与负载转矩
  • 卡点：消去中间变量后要折算到输出轴，图(a)图(b)需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过由齿轮传动关系与转动惯量列写机械系统运动微分方程
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项

3三、Bode反求传函、根轨迹与超前校正15 分#

思路
  • 由幅频图反求传函，画根轨迹定稳定增益，再比较校正前后的截止频率与相角裕量
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环对数幅频特性反求传递函数
本卷实例
  • 关键一步：由低频段斜率定型别，两个转折频率定两个惯性环节的时间常数
  • 中间结果：开环传函写成含积分环节与两个一阶环节的比例形式
  • 卡点：幅频曲线的读数与转折频率需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环对数幅频特性反求传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制开环增益变化时的系统根轨迹
本卷实例
  • 关键一步：由三个开环极点确定实轴根轨迹区间与渐近线
  • 中间结果：分离点方程给出实轴上的分离与会合位置
  • 卡点：渐近线与分离点都要先算，根轨迹草图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制开环增益变化时的系统根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由虚轴交点求系统稳定时的增益范围
本卷实例
  • 关键一步：令特征方程中s等于jω，实部虚部分别为零联立求临界增益
  • 中间结果：临界频率与临界增益由两个实数方程唯一确定
  • 卡点：稳定范围是开区间，端点临界增益不能取
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由虚轴交点求系统稳定时的增益范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
超前校正 系统校正
本卷考法
  • 由给定超前校正环节比较校正前后的截止频率与相角裕量
本卷实例
  • 关键一步：把校正环节写成超前网络标准形，分别对校正前后令幅值等于1求频率
  • 中间结果：校正前后各自求出截止频率与该频率处的相角裕量
  • 卡点：比较的是同一指标，两处截止频率不能混用，转折频率别漏乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过由给定超前校正环节比较校正前后的截止频率与相角裕量
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式

4四、开环幅相曲线与奈奎斯特判据15 分#

思路
  • 开环含一个右半平面极点，先画奈氏曲线并求与负实轴交点，再由P与包围数分析增益对稳定性的影响
频率特性的物理意义与求法 频域分析
本卷考法
  • 由开环传函绘制奈奎斯特曲线并求与负实轴的交点
本卷实例
  • 关键一步：写幅频相频表达式，取频率趋于零、趋于无穷与相角为负180度三点定走向
  • 中间结果：曲线与负实轴的交点幅值含增益与两个时间常数之积
  • 卡点：初始相角与穿越方向易混，曲线草图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由开环传函绘制奈奎斯特曲线并求与负实轴的交点
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据分析增益对闭环稳定性的影响
本卷实例
  • 关键一步：先数开环右半平面极点数P，再按曲线与临界点位置数包围圈数
  • 中间结果：交点落在负一临界点两侧，分别对应不稳定与稳定两种结论
  • 卡点：含右半平面极点时P不为零，不能按最小相位系统直接判
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据分析增益对闭环稳定性的影响
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式

5五、离散系统脉冲传函与稳态误差15 分#

思路
  • 含零阶保持器的采样系统先求脉冲传函与特征方程，用朱利判据定稳定域、终值定理求误差范围
脉冲传递函数 离散控制系统
本卷考法
  • 由含零阶保持器的采样系统求开环脉冲传函
本卷实例
  • 关键一步：对保持器与对象乘积作部分分式展开后查z变换表
  • 中间结果：开环脉冲传函在z等于1处有一重极点，分子为一次多项式
  • 卡点：零阶保持器与采样周期必须代入，否则分子系数会错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过由含零阶保持器的采样系统求开环脉冲传函
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)
公式
离散系统稳定性分析 离散控制系统
本卷考法
  • 由闭环特征方程用朱利判据求增益稳定区间
本卷实例
  • 关键一步：代二阶朱利稳定条件列出不等式组，解增益上下限
  • 中间结果：稳定区间为开区间，由三个不等式共同确定
  • 卡点：朱利判据三个条件要同时满足，漏一个会把稳定域放大
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过由闭环特征方程用朱利判据求增益稳定区间
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒
公式
离散系统的稳态误差 离散控制系统
本卷考法
  • 由终值定理求复合输入下的稳态误差并反求增益区间
本卷实例
  • 关键一步：输入含阶跃与斜坡，写出静态位置与速度误差系数求稳态误差
  • 中间结果：阶跃分量无差，只有斜坡分量贡献稳态误差
  • 卡点：误差要求区间要与稳定区间取交集，且端点不取
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差由输入类型与开环脉冲传函中 z=1 处极点的个数决定
  • 型别由 G(z)H(z) 中 z=1 处极点的重数确定
  • 用终值定理求稳态误差，前提是系统稳定
  • 采样周期也影响稳态误差大小
步骤
  • 求误差脉冲传递函数
  • 数出 z=1 处极点重数确定型别
  • 查表或用终值定理求稳态误差
