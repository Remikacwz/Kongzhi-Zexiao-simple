1一、反馈控制系统的组成与方框图15 分#

思路
  • 用系统方块图表示司机沿给定路线行驶的反馈过程，指出给定路线为输入、实际路线为输出、驾驶员与方向盘为控制装置、汽车为被控对象，并画出闭环方框图。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 由人类驾驶活动指出输入量、输出量、控制装置与被控对象并画方框图
本卷实例
  • 关键一步：把给定路线与实际路线之差作为偏差信号，经驾驶员判断后操纵方向盘
  • 关键一步：按给定、比较、控制、对象、反馈的顺序连成闭环方框图
  • 中间结果：输入为给定路线，输出为实际路线，控制装置为驾驶员与方向盘，被控对象为汽车
  • 卡点：方框图比较点与反馈引出点位置需回原卷核对题意
  • 卡点：被控量是汽车实际路线，别写成方向盘转角
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过由人类驾驶活动指出输入量、输出量、控制装置与被控对象并画方框图
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

2二、由微分方程求稳态误差条件20 分#

思路
  • 由三个微分方程消去中间变量求闭环传递函数与特征方程，先用劳斯判据保证稳定，再由终值定理求 r(t)=100+t 下的稳态误差，反解 K1 的取值条件。
传递函数的定义与基本性质 传递函数
本卷考法
  • 由微分方程组消去中间变量求闭环传递函数
本卷实例
  • 关键一步：对三个微分方程分别取拉氏变换并整理成传递函数
  • 关键一步：消去 U(s) 与 B(s) 得到 C(s)/R(s)
  • 中间结果：闭环传函分母为 (T1 s²+T2 s)(T3 s+1) 加 K1 K2
  • 卡点：题目反馈量是 b(t) 不是 c(t)，别与输出量混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由微分方程组消去中间变量求闭环传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 用劳斯判据求使闭环系统稳定的参数范围
本卷实例
  • 关键一步：列劳斯表并令首列各元素都取正值
  • 关键一步：由首列不等式解出 K1 的上界约束
  • 中间结果：稳定条件化为 K1 K2 T1 小于 T1 加 T2 T3
  • 卡点：求稳态误差前必须先判稳，否则终值定理不成立
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过用劳斯判据求使闭环系统稳定的参数范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 在稳定前提下由终值定理求稳态误差并反解增益
本卷实例
  • 关键一步：写出误差传函 E(s)/R(s) 等于 1 减 B(s)/R(s)
  • 关键一步：代入 r(t) 等于 100 加 t 的拉氏变换后用终值定理
  • 中间结果：稳态误差化为 T2 除以 K1 K2，令其不大于 ξ0
  • 卡点：K1 的上界与下界两个不等式必须取交集
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过在稳定前提下由终值定理求稳态误差并反解增益
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、开环幅相曲线与奈奎斯特判据15 分#

思路
  • 由开环传函写出幅频与相频表达式，确定起止点与相角走势画概略幅相曲线，再数开环右半平面极点数与包围圈数判断闭环稳定性。
频率特性的物理意义与求法 频域分析
本卷考法
  • 由开环传函写幅频相频表达式并画概略幅相曲线
本卷实例
  • 关键一步：令 s 等于 jω 代入，分别写出幅值与相角表达式
  • 关键一步：取 ω 趋于零与无穷大确定曲线起止点和相角走向
  • 中间结果：开环分母有两个积分环节，低频幅值趋于无穷、相角自负180度起
  • 卡点：两个积分环节的相角起止不能按一个积分环节估算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由开环传函写幅频相频表达式并画概略幅相曲线
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由幅相曲线数包围圈数并用奈奎斯特判据判稳
本卷实例
  • 关键一步：先数开环右半平面极点数 P 与曲线包围临界点的净圈数 N
  • 关键一步：由 Z 等于 P 减 2N 得右半平面闭环极点数
  • 中间结果：开环无右半平面极点，曲线包围临界点故闭环极点数不为零
  • 卡点：两个积分环节需补画无穷大半径圆弧，绕行方向别画反
  • 卡点：源文幅相曲线以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由幅相曲线数包围圈数并用奈奎斯特判据判稳
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

4四、相角裕度与两级超前校正20 分#

思路
  • 先由开环传函求截止频率与相角裕度判稳，再写出两级超前网络的传递函数，按校正后相角裕度与静态加速度误差系数要求核对参数并画对数幅频曲线。
稳定裕度 频域分析
本卷考法
  • 由开环传函求截止频率与相角裕度并判断稳定性
本卷实例
  • 关键一步：令幅值等于一解出截止频率
  • 关键一步：把截止频率代入相频表达式求相角裕度
  • 中间结果：相角裕度按180度加相角计算，其正负决定稳定性
  • 卡点：截止频率由幅频等于一确定，别与相角穿越频率混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由开环传函求截止频率与相角裕度并判断稳定性
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
超前校正 系统校正
本卷考法
  • 分析两级超前网络串联校正的传递函数与相角提升
本卷实例
  • 关键一步：用复阻抗法分别写每级 RC 超前网络的传递函数
  • 关键一步：两级串联后再乘增益，相角为两级相加
  • 中间结果：校正装置为同一超前环节平方后乘增益 K1
  • 卡点：源文解析指出该两级超前校正不能同时满足相角裕度与 Ka 要求
  • 卡点：校正网络电路图为原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过分析两级超前网络串联校正的传递函数与相角提升
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制校正前后系统的对数幅频特性曲线
本卷实例
  • 关键一步：先写校正前后开环传函，再按各转折频率分段
  • 关键一步：逐段累加斜率变化画出渐近幅频特性
  • 中间结果：斜率变化由超前环节的转折频率决定，横轴需标出各转角
  • 卡点：改斜率要累加而不是替换，低频段高度别漏乘型别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过绘制校正前后系统的对数幅频特性曲线
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由静态加速度误差系数要求确定开环增益
本卷实例
  • 关键一步：由开环传函的型别写出 Ka 表达式
  • 关键一步：令 Ka 等于题目给值即可反解增益约束
  • 中间结果：系统为二型，Ka 由开环增益与各时间常数共同决定
  • 卡点：Ka 与开环增益不是同一个量，别直接把增益当 Ka
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由静态加速度误差系数要求确定开环增益
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

5五、离散系统开环与闭环脉冲传递函数15 分#

思路

脉冲传递函数 离散控制系统
本卷考法
  • 由离散结构图求开环与闭环脉冲传递函数
本卷实例
  • 关键一步：先标出采样开关位置，确定哪几个连续环节可合并
  • 关键一步：对可合并部分整体取 z 变换得 G(z)，再按反馈关系写闭环
  • 中间结果：开环脉冲传函为连续部分串零阶保持器后的 z 变换
  • 卡点：无采样开关隔开的连续环节才能整体取 z 变换
  • 卡点：结构图中采样开关位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过由离散结构图求开环与闭环脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)

z 变换与 z 反变换 离散控制系统
本卷考法
  • 求含 s² 与惯性环节的 z 变换
本卷实例
  • 关键一步：把零阶保持器因子拆成两项再取 z 变换
  • 关键一步：用部分分式把 s²(s+a) 的倒数分解后逐个查表
  • 中间结果：零阶保持器的 e 指数项在 z 域对应负幂移位因子
  • 卡点：部分分式分解易漏项，最终应化为 z 的有理分式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • z 变换是离散信号的拉氏变换，令 z=e^{Ts} 得到
  • 常用函数的 z 变换要熟记
  • z 反变换可用部分分式法、幂级数法或留数法
  • 左半 s 平面映射到 z 平面单位圆内
步骤
  • 将连续传递函数展开为部分分式
  • 逐项查表做 z 变换
  • 需要时做 z 反变换求时间序列
通用考法
  • 本卷考过求含 s² 与惯性环节的 z 变换
  • 求给定函数的 z 变换
  • 求 z 反变换得到采样序列
  • 说明 s 平面与 z 平面的映射关系
常见易错
  • 把 z 变换结果中的 e^{-aT} 写成 e^{-a}
  • 部分分式分解时漏项导致反变换出错

6六、描述函数法分析自振15 分#

思路
  • 求理想继电特性的负倒描述函数，与线性部分幅相曲线画在同一复平面，按 A 增大方向判断稳定自振点并求振幅与频率。
描述函数法基础 非线性系统
本卷考法
  • 由理想继电特性的描述函数求负倒描述函数
本卷实例
  • 关键一步：对描述函数 N(A) 取倒数后再取负
  • 关键一步：令 A 趋于零与无穷大确定线段的两个端点
  • 中间结果：负倒描述函数为负实轴上随 A 单调变化的一段
  • 卡点：线性部分的连接关系含结构图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过由理想继电特性的描述函数求负倒描述函数
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件
公式
用描述函数法分析自振 非线性系统
本卷考法
  • 由两条曲线交点判定自振并求振幅与频率
本卷实例
  • 关键一步：在同一复平面画线性部分幅相曲线与负倒描述函数曲线
  • 关键一步：按 A 增大方向判断交点是否为稳定穿越
  • 中间结果：线性部分与负实轴交点幅值即负倒描述函数的对应取值
  • 卡点：稳定自振要由不稳定区穿入稳定区，不能只看有交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过由两条曲线交点判定自振并求振幅与频率
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率
