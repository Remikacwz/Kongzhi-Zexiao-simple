1一、反馈控制系统的组成与方框图15 分#

思路
  • 描述人进行羽毛球运动时的负反馈控制过程，画出原理方框图，指出预期球况与期望位姿为输入、实际位姿为输出、大脑为控制装置、四肢和球拍为被控对象。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 由羽毛球运动过程指出输入、输出、控制装置与被控对象
本卷实例
  • 关键一步：把期望球况与实际位姿之差作为偏差信号
  • 关键一步：大脑作比较决策，四肢与球拍为执行并带动被控对象
  • 中间结果：输入为预期球况与期望位姿，输出为实际位姿
  • 卡点：被控对象是四肢和球拍，别写成羽毛球
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过由羽毛球运动过程指出输入、输出、控制装置与被控对象
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

2二、稳态误差为零的证明与充分条件20 分#

思路
  • 由误差定义写误差传递函数，在系统稳定前提下用终值定理证明阶跃输入稳态误差为零；再对加速度输入令误差表达式极限为零，给出对闭环传函分子系数的充分条件。
误差定义与误差传递函数 稳态误差
本卷考法
  • 写出误差传递函数并证明阶跃输入下稳态误差为零
本卷实例
  • 关键一步：由误差定义写 E(s)/R(s) 等于 1 减 Φ(s)
  • 关键一步：用终值定理求 s 趋于零时的稳态误差
  • 中间结果：1 减 Φ(s) 的分母为题给闭环特征多项式，分子含 s 的一次幂
  • 卡点：用终值定理前需说明系统稳定这一前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写出误差传递函数并证明阶跃输入下稳态误差为零
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由系统型别分析加速度输入下的稳态误差
本卷实例
  • 关键一步：写出加速度误差系数 Ka 的极限表达式
  • 关键一步：令 Ka 为无穷大或使稳态误差表达式分子为零
  • 中间结果：欲使加速度输入下误差为零，需开环至少含三个积分环节
  • 卡点：充分条件要让误差表达式分子为零，别把系统型别判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由系统型别分析加速度输入下的稳态误差
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 在1问基础上求加速度输入下误差为零的充分条件
本卷实例
  • 关键一步：把加速度输入的拉氏变换代入误差表达式
  • 关键一步：令整理后表达式的极限为零，读出对分子系数的要求
  • 中间结果：充分条件化为闭环传函分子若干低次项系数同时为零
  • 卡点：充分条件不唯一，答出一组并说明理由即可
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过在1问基础上求加速度输入下误差为零的充分条件
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、由正弦稳态响应求参数与动态性能15 分#

思路
  • 由正弦输入输出的幅值比与相角差写出频率特性方程，求阻尼比与自然频率并判断稳定性，再计算单位阶跃下的各项动态性能指标。
频率特性的物理意义与求法 频域分析
本卷考法
  • 由正弦稳态响应的幅值与相角写幅频相频关系
本卷实例
  • 关键一步：把 r(t) 与 c(t) 的幅值比作为该频率处的幅频值
  • 关键一步：把输出相对输入的相角差作为该频率处的相频值
  • 中间结果：正弦稳态下把 s 换成 jω 得频率特性表达式
  • 卡点：输入频率由正弦信号的角频率确定，别代错 ω
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由正弦稳态响应的幅值与相角写幅频相频关系
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由幅频相频两个条件联立求阻尼比与自然频率
本卷实例
  • 关键一步：写出闭环传函并令 s 等于 jω 得频率特性
  • 关键一步：由幅值条件与相角条件列两个方程联立求解
  • 中间结果：开环传函化标准形式后 ωn² 与 2ξωn 为待定参数
  • 卡点：幅值条件与相角条件要同时满足，别只用一个
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由幅频相频两个条件联立求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率计算各项动态性能指标
本卷实例
  • 关键一步：按超调量公式算σ百分之，按定义算上升时间与峰值时间
  • 关键一步：调节时间按百分之五误差带的公式计算
  • 中间结果：欠阻尼下上升时间由反余弦阻尼比与自然频率共同决定
  • 卡点：上升时间与峰值时间公式不同，别混用相位角
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率计算各项动态性能指标
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

4四、状态反馈不改变能控性与极点配置20 分#

思路
  • 先证明引入状态反馈后能控性矩阵与原矩阵互为初等变换、秩不变；再对给定系统构造状态反馈矩阵，注意不可控极点须包含在理想极点中。
能控性与能观性 状态空间分析
本卷考法
  • 证明状态反馈不改变能控性并判断系统能控性
本卷实例
  • 关键一步：比较状态反馈前后的能控性矩阵，说明二者互为初等变换
  • 关键一步：构造能控性矩阵 B AB A²B 并求秩
  • 中间结果：引入状态反馈后能控性矩阵的每一列都由原列线性组合得到
  • 卡点：本题系统不完全能控，不可控极点对应特征值需先找出
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过证明状态反馈不改变能控性并判断系统能控性
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
状态反馈与极点配置 状态空间分析
本卷考法
  • 按理想极点构造状态反馈矩阵
本卷实例
  • 关键一步：先确认哪些理想极点可由状态反馈配置
  • 关键一步：把系统矩阵代入 A 加 BK 后比较特征多项式系数
  • 中间结果：期望特征多项式为 (s 加一)(s 加二)² 的展开式
  • 卡点：不可控极点必须包含在理想极点中，否则无解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过按理想极点构造状态反馈矩阵
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反

5五、离散系统闭环脉冲传函、稳定性与输出序列15 分#

思路
  • 先求开环 z 变换并写闭环脉冲传函，用 w 变换把特征方程化到 w 域后用劳斯判据判稳，再用长除法求前几拍采样输出序列。
脉冲传递函数 离散控制系统
本卷考法
  • 求含零阶保持器的闭环脉冲传递函数
本卷实例
  • 关键一步：先求开环 ZOH 与连续部分的 z 变换 G(z)
  • 关键一步：按单位负反馈关系写闭环脉冲传函
  • 中间结果：闭环脉冲传函分母为 1 加 G(z)，分子为 G(z)
  • 卡点：零阶保持器要与后续连续环节合并取 z 变换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过求含零阶保持器的闭环脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)
公式
离散系统稳定性分析 离散控制系统
本卷考法
  • 用 w 变换与劳斯判据判别离散系统稳定
本卷实例
  • 关键一步：把 z 等于 (w 加一)/(w 减一) 代入特征方程
  • 关键一步：对 w 域特征多项式列劳斯表判稳
  • 中间结果：变换后特征多项式各系数同号则可判稳
  • 卡点：w 变换后要重新整理成 w 的多项式再列劳斯表
