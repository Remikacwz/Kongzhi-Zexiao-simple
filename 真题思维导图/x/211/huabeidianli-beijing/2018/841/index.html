1一、锅炉汽包水位控制系统工作过程与方框图#

思路
  • 按汽包液位给定值与实际液位偏差说明给水阀调节的过程，指出被控对象与被控量，并画出系统方框图。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出锅炉水位系统的被控对象、被控量与检测变送作用
本卷实例
  • 关键一步：由汽包液位与给定值之差判断偏差
  • 关键一步：把变送器、调节器、执行阀、汽包连成闭环
  • 中间结果：被控量为汽包液位、操纵量为给水流量
  • 卡点：系统原理示意图接线需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指出锅炉水位系统的被控对象、被控量与检测变送作用
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把被控量与操纵量搞反
  • 本卷考过只画方框图不指认环节作用
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 说明蒸汽与给水扰动下水位的调节过程
本卷实例
  • 关键一步：分别分析蒸汽负荷与给水压力扰动下的液位变化
  • 关键一步：由偏差方向确定开大或关小给水阀
  • 中间结果：调节器在偏差出现后立即动作使液位复原
  • 卡点：扰动作用点与调节阀方向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过说明蒸汽与给水扰动下水位的调节过程
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 本卷考过只做定性描述不说明偏差方向
  • 本卷考过不区分两类扰动的作用
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半

2二、高阶系统单位阶跃响应#

思路
  • 把闭环传函做部分分式分解，再逐项拉氏反变换得到单位阶跃响应，注意附加零点对响应模态的影响。
零极点分布与响应模态 传递函数
本卷考法
  • 由含零点的三阶闭环传函判断响应模态
本卷实例
  • 关键一步：把分母因式分解并找出主导极点
  • 关键一步：结合分子零点判断各模态的系数
  • 中间结果：响应由衰减指数项与衰减振荡项组合
  • 卡点：部分分式系数需按留数逐项核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由含零点的三阶闭环传函判断响应模态
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 本卷考过只看极点分布忽略零点权重
  • 本卷考过把分母因式根直接当输出幅值
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由闭环传函求单位阶跃响应的时域表达式
本卷实例
  • 关键一步：把C(s)=Φ(s)乘1/s做部分分式展开
  • 关键一步：逐项拉氏反变换得时间响应
  • 中间结果：零初始条件下只含零状态响应
  • 卡点：留数系数与分母因式需逐项核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由闭环传函求单位阶跃响应的时域表达式
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 本卷考过部分分式分解时漏项
  • 本卷考过把主导极点降阶近似用于本题
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

3三、纯虚根条件与根轨迹绘制#

思路
  • 把s=jω代入闭环特征方程分离实虚部求临界k*与z，再按根轨迹法则绘图，最后由根位于左半平面得衰减振荡范围。
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由纯虚根条件求临界增益与零点参数
本卷实例
  • 关键一步：把s=jω代入D(s)并令实部虚部为零
  • 关键一步：联立两式解出k*与z
  • 中间结果：闭环特征方程在虚轴上有共轭纯虚根
  • 卡点：联立方程的解需回代原特征方程验证
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由纯虚根条件求临界增益与零点参数
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 本卷考过只代一个ω漏掉另一组交点
  • 本卷考过分离实虚部时符号写错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制k*变化时的闭环根轨迹
本卷实例
  • 关键一步：标出开环极点与零点定实轴根轨迹段
  • 关键一步：按n与m之差求渐近线倾角与交点
  • 中间结果：根轨迹四条分支中三条趋于无穷远
  • 卡点：分离点与渐近线需按法则逐项核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制k*变化时的闭环根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴段判据的零极点个数算错
  • 本卷考过渐近线夹角公式写成2k
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹求衰减振荡对应的参数范围
本卷实例
  • 关键一步：找出根轨迹位于左半平面的参数区间
  • 关键一步：由虚轴交点确定临界增益
  • 中间结果：参数区间由根轨迹与虚轴的两个交点夹出
  • 卡点：区间端点是否含需按题意核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹求衰减振荡对应的参数范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 本卷考过把等阻尼线画成垂直线
  • 本卷考过只看交点忽略根所在半平面
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

4四、概略开环幅相曲线与奈氏判稳#

思路
  • 令s=jω求幅频与相频表达式，按趋势画概略幅相曲线，先数开环右半平面极点数P再用奈氏判据判稳。
频率特性的物理意义与求法 频域分析
本卷考法
  • 求含一个积分与两个惯性环节的幅频相频表达式
本卷实例
  • 关键一步：令s=jω代入并分离模与相角
  • 关键一步：按ω趋于0与无穷分析曲线起止
  • 中间结果：曲线在第三象限趋于原点且不与实轴相交
  • 卡点：曲线形状与渐近趋势需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求含一个积分与两个惯性环节的幅频相频表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过相角累加时漏掉积分环节的-90度
  • 本卷考过幅值取模时忘记分母开方
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由概略幅相曲线分析闭环稳定性
本卷实例
  • 关键一步：先由开环传函定P再数包围(-1,j0)的圈数N
  • 关键一步：按Z=P-2N判断闭环右根个数
  • 中间结果：临界情况取决于曲线与负实轴交点幅值
  • 卡点：(-1,j0)点相对曲线的位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由概略幅相曲线分析闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过没有先数开环右半平面极点数P
  • 本卷考过包围圈数N的正负号定义取反
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

5五、题面缺失（两源同印缺）#

思路
  • 逐年试题册与宝典同年试题段均只印「五、缺。」，无题干、无分值、答案段也无第五题解答，故保留第五题号占位并如实缺。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 该题题面缺失，仅存题号与一个缺字
本卷实例
  • 关键一步：核对逐年与宝典两源均只印五、缺
  • 关键一步：保留题号占位不臆造题干
  • 中间结果：本卷第五题仅存题号与一个缺字

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条

  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
