1一、二阶系统四种阻尼下的阶跃响应#

思路
  • 由给定二阶闭环传递函数化标准形式，分别讨论零阻尼、欠阻尼、临界阻尼和过阻尼四种情况，写出单位阶跃响应并在复平面上标出特征根位置。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由给定二阶闭环传函化标准形式并判断四种阻尼类型
本卷实例
  • 关键一步：把分母写成 T²s²+2ξTs+1 的标准形式
  • 关键一步：分别令 ξ 等于零、介于零和一之间、等于一、大于一，对应四种阻尼
  • 关键一步：与标准二阶传函逐项比对，得到阻尼比 ξ 与自然频率
  • 中间结果：四种阻尼对应特征根分别为共轭纯虚根、左半平面共轭复根、二重负实根和两个互异负实根
  • 卡点：分母 s² 项系数为 T²，必须先归一化再读取参数；特征根位置与响应草图需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由给定二阶闭环传函化标准形式并判断四种阻尼类型
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
零极点分布与响应模态 传递函数
本卷考法
  • 由特征根位置判断响应模态并画阶跃响应草图
本卷实例
  • 关键一步：先解闭环特征方程得到特征根
  • 关键一步：按实根、重根、共轭虚根、共轭复根分类写响应的指数项或振荡项
  • 中间结果：无阻尼响应含等幅振荡项，过阻尼响应为两个衰减指数项叠加，临界阻尼出现 t 乘衰减指数项
  • 卡点：四种响应草图的振荡次数和过渡形状依赖原卷插图，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由特征根位置判断响应模态并画阶跃响应草图
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

2二、开环幅相曲线与奈奎斯特判据#

思路
  • 由开环传递函数写出幅频和相频表达式，确定低频、高频及与负实轴的交点，绘制概略幅相曲线，再用奈奎斯特判据判断闭环稳定性。
频率特性的物理意义与求法 频域分析
本卷考法
  • 由开环传函求幅频相频并绘制概略幅相曲线
本卷实例
  • 关键一步：令 s 等于 jω 代入开环传函，分别求幅值和相角随频率变化的表达式
  • 关键一步：取 ω 趋于零、无穷大以及相角等于负一百八十度三个位置确定曲线走向
  • 中间结果：低频段幅值趋于无穷、相角从负二百七十度附近出发，高频段幅值趋于零、相角回到负九十度
  • 卡点：开环含三个积分环节，相角起止方向容易与最小相位系统混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由开环传函求幅频相频并绘制概略幅相曲线
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数 P 与曲线对临界点的净包围圈数 N
  • 关键一步：由 Z 等于 N 加 P 判断右半平面闭环极点数
  • 中间结果：开环无右半平面极点，原点处积分环节需补画无穷大半径圆弧
  • 中间结果：曲线与负实轴的交点用于判断是否包围临界点
  • 卡点：补画圆弧的绕行方向容易漏画或画反，导致包围圈数多数一圈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

3三、采样系统闭环脉冲传递函数#

思路
  • 按结构图中采样开关的位置标记采样前后信号，列写各点关系并消去中间变量，求出闭环脉冲传递函数。
脉冲传递函数 离散控制系统
本卷考法
  • 按采样开关位置列写离散闭环脉冲传递函数
本卷实例
  • 关键一步：先把每个采样开关前后的信号分别标记
  • 关键一步：前向通路各环节的采样信号相乘，反馈通路采样信号与输出采样信号的 z 变换相乘
  • 关键一步：对采样后的信号取 z 变换，再按结构图代数关系消去中间变量
  • 中间结果：闭环脉冲传递函数分母为一加前向与反馈采样传递函数之积，分子为前向通路各环节采样传递函数之积
  • 卡点：连续环节之间若有采样开关，不能直接合并；图中采样开关位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过按采样开关位置列写离散闭环脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)
公式

4四、描述函数法分析自振#

思路
  • 求非线性环节的负倒描述函数，与线性部分的幅相曲线画在同一复平面，按曲线走向判断稳定、不稳定和周期运动三种参数范围，再求稳定周期运动的振幅与频率。
描述函数法基础 非线性系统
本卷考法
  • 由给定描述函数求负倒描述函数并分析幅值变化
本卷实例
  • 关键一步：把描述函数 N(A) 取倒数后取负，整理成随幅值 A 单调变化的表达式
  • 关键一步：分别令 A 趋于零和趋于无穷大，确定负倒描述函数线段的两个端点
  • 中间结果：负倒描述函数为负实轴上从负二分之一到负一的一段线段
  • 卡点：题干中描述函数和线性部分的连接关系含原卷结构图，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过由给定描述函数求负倒描述函数并分析幅值变化
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件
公式
用描述函数法分析自振 非线性系统
本卷考法
  • 由两曲线交点确定自振及极限环稳定性
本卷实例
  • 关键一步：在同一复平面画出线性部分的幅相曲线
  • 关键一步：再画负倒描述函数曲线，按幅值 A 增大方向判断交点是否稳定穿越
  • 中间结果：线性部分在负实轴的截距随 k 增大而移动，对应无交点、稳定交点和被包围三种情形
  • 卡点：稳定周期运动要按负倒曲线由不稳定区穿入稳定区的方向判断，不能只看交点是否存在
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过由两曲线交点确定自振及极限环稳定性
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率
公式

5五、电路状态空间建模与传递函数#

思路
  • 按题目指定选取两个电容电压为状态变量，由电容电流关系和回路电压关系列写状态方程与输出方程，再在零初始条件下由状态空间表达式求传递函数。
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由电容电阻网络列写状态方程所需的电路关系
本卷实例
  • 关键一步：对电容用电流与电压的微分关系，利用串联电容电流相等得到两个电容电压导数之间的关系
  • 关键一步：对回路列 KVL，把非状态量用状态变量和输入表示
  • 中间结果：串联电容的电流相等给出两电容电压导数之间的比例关系
  • 卡点：电路图为原卷插图，元件连接与电压参考方向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由电容电阻网络列写状态方程所需的电路关系
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
状态空间表达式的建立 状态空间分析
本卷考法
  • 选取电容电压为状态变量列写状态空间表达式
本卷实例
  • 关键一步：整理每个状态变量的一阶微分方程
  • 关键一步：写成矩阵形式 x导数等于 A x 加 B u，输出方程写成 C x
  • 中间结果：二阶电路对应两个状态变量，A 为二阶矩阵，B 为二行一列矩阵，输出取两电容电压之和
  • 卡点：输出方程中 C 矩阵的符号和源文 OCR 印残的系数需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过选取电容电压为状态变量列写状态空间表达式
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由状态空间表达式求零初始条件下的传递函数
本卷实例
  • 关键一步：代入由状态空间求传递函数的公式，即 C 乘 sI 减 A 的逆再乘 B
  • 关键一步：也可用复阻抗分压关系独立求一次，与矩阵结果互相校验
  • 中间结果：电路分压关系给出的传函与状态空间公式应一致，可直接检验矩阵元素是否写对
  • 卡点：题目明确零初始条件，不要混入初值；源文矩阵符号需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D

思路

能控性与能观性 状态空间分析

本卷实例

7七、李雅普诺夫第二法判断稳定性#

思路
  • 求系统平衡点，按题目给定的二次型函数沿系统轨迹求导，判断函数及其导数的符号性质，再结合大范围条件说明平衡状态的稳定性。
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 选取二次型李雅普诺夫函数判断平衡状态稳定性
本卷实例
  • 关键一步：先令状态导数等于零求平衡点，再沿状态方程求给定函数对时间的导数
  • 关键一步：判断函数正定且导数在除原点外不恒为零，结合不变集说明渐近稳定
  • 中间结果：求导后交叉项相消，只剩负的 x2 平方项，在 x2 等于零的轴上导数为零
  • 卡点：源文把该导数的负半定性误写成负定，需按拉萨尔不变集补充论证；V 趋于无穷的条件也要检查
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过选取二次型李雅普诺夫函数判断平衡状态稳定性
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数
