1一、输入与扰动共同作用下的稳态误差15 分#

思路
  • 先分别求参考输入与两路扰动单独作用下的误差传递函数，判稳后用终值定理求各稳态误差，再由线性系统叠加原理合成总误差。
误差定义与误差传递函数 稳态误差
本卷考法
  • 写参考输入与扰动各自作用的误差传函
本卷实例
  • 关键一步：由结构图分别列E(s)/R(s)与E(s)/N(s)
  • 关键一步：求极限前先判闭环特征根实部为负
  • 中间结果：三路误差传函的分母同为闭环特征式
  • 卡点：两路扰动的作用点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写参考输入与扰动各自作用的误差传函
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 本卷考过未判稳就直接用终值定理求极限
  • 本卷考过把扰动引起的误差当成总误差
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 计算阶跃与斜坡参考输入下的稳态误差
本卷实例
  • 关键一步：按开环传函的积分环节个数定系统型别
  • 关键一步：对斜坡输入按速度误差系数求有限误差
  • 中间结果：阶跃输入下的误差由静态位置误差系数判断
  • 卡点：参考输入为斜坡时需先确认闭环系统稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过计算阶跃与斜坡参考输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过把阶跃输入的误差按速度误差公式代入
  • 本卷考过组合输入时漏掉某一分量
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求两路扰动单独作用与共同作用下的稳态误差
本卷实例
  • 关键一步：把参考输入置零再求每路扰动引起的误差
  • 关键一步：按叠加原理把各路误差代数相加
  • 中间结果：n1斜坡与n2阶跃扰动对应不同的误差系数
  • 卡点：扰动进入系统的位置不同需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求两路扰动单独作用与共同作用下的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 本卷考过两路扰动通道的传函分子写反
  • 本卷考过叠加前未逐一验证系统稳定
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

2二、矩阵特征值与不能观条件15 分#

思路
  • 先由特征方程det(λI-A)=0求三阶矩阵的特征值，再按能观判别阵不满秩构造三组使系统不能观的C行向量。
能控性与能观性 状态空间分析
本卷考法
  • 求使系统不能观的三组C1、C2、C3取值
本卷实例
  • 关键一步：写出能观判别阵并令其行列式为零
  • 关键一步：用PBH判据在某个特征值处验证不满秩
  • 中间结果：满足C1、C2、C3线性关系的取值均可
  • 卡点：三组取值不能全零且需互不相同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过求使系统不能观的三组C1、C2、C3取值
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 本卷考过能观判别阵的列序写反
  • 本卷考过只在一个特征值处验证秩
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
零极点分布与响应模态 传递函数
本卷考法
  • 由特征方程求三阶系统的特征根
本卷实例
  • 关键一步：按det(λI-A)=0展开三阶行列式
  • 关键一步：分解因式后逐项读出特征根
  • 中间结果：友矩阵的特征多项式可直接对照系数写出
  • 卡点：特征方程展开后需核对常数项符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由特征方程求三阶系统的特征根
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 本卷考过特征多项式符号写错导致根错
  • 本卷考过把重根当成两个不同根
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

3三、由频率特性定义证明稳态输出15 分#

思路
  • 把余弦输入写成拉氏变换，对闭环传函在极点jω处取留数，得到两个共轭稳态分量并合并成幅值-相角形式。
频率特性的物理意义与求法 频域分析
本卷考法
  • 用频率特性定义证明余弦输入下的稳态输出
本卷实例
  • 关键一步：把余弦输入化为共轭指数并做拉氏变换
  • 关键一步：取jω与-jω两处留数得稳态分量
  • 中间结果：两分量合并后出现Φ(jω)的幅值与相角
  • 卡点：需先声明闭环系统稳定才能只取稳态项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过用频率特性定义证明余弦输入下的稳态输出
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过把瞬态分量并入稳态输出
  • 本卷考过幅值与相角的对应关系写反
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
传递函数的定义与基本性质 传递函数
本卷考法
  • 写出闭环传递函数与频率特性的对应关系
本卷实例
  • 关键一步：把s=jω代入Φ(s)得分频与相频
  • 关键一步：按复数乘除法则合并模与幅角
  • 中间结果：稳态输出幅值等于输入幅值乘幅频值
  • 卡点：正负频率分量的共轭关系易漏写
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过写出闭环传递函数与频率特性的对应关系
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过漏掉Φ(jω)的相角项
  • 本卷考过复数相乘时模与幅角合并出错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式

4四、电网络状态空间表达式20 分#

思路
  • 以两电容电压和两电感电流为状态变量，按KCL与KVL列微分方程并消去中间变量，整理成四阶状态方程与输出方程。
状态空间表达式的建立 状态空间分析
本卷考法
  • 由四阶电网络列写状态空间表达式
本卷实例
  • 关键一步：取uC1、uC2、i1、i2为四个状态变量
  • 关键一步：按KCL与KVL列方程并消去非状态量
  • 中间结果：状态矩阵为四阶并含R、L、C组合
  • 卡点：网络拓扑与输出端口需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由四阶电网络列写状态空间表达式
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 本卷考过状态变量个数与储能元件数不符
  • 本卷考过输出方程漏写直接传递项D
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由电路网络方程求状态空间模型
本卷实例

  • 关键一步：把导数项系数归一到左边化为状态方程
  • 中间结果：输出y由两电容电压组合构成
  • 卡点：元件连接与电流方向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 含运放的网络使用虚短与虚断两个条件

  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由电路网络方程求状态空间模型
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 本卷考过含电感时忘记列磁链微分关系
  • 本卷考过电流参考方向取反致符号出错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

5五、渐进状态观测器与观测方程15 分#

思路
  • 由全维状态观测器的渐进结构图写出含修正项G(y-ŷ)的观测方程，说明其工作原理并把方程整理成矩阵形式。
状态观测器设计 状态空间分析
本卷考法
  • 由渐进状态结构图写出观测方程
本卷实例
  • 关键一步：按x̂·=Ax̂+Bu+G(y-ŷ)列写观测方程
  • 关键一步：把y-ŷ用Cx-Cx̂代入后并项
  • 中间结果：观测器的闭环特征式由A-GC决定
  • 卡点：结构图引出点与反馈极性需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态观测器用输出与输入重构状态，前提是系统能观
  • 极点配置法与龙伯格观测器是两种常用形式
  • 观测器误差动态由 A-LC 的特征值决定
  • 观测器极点通常取得比系统极点快若干倍
步骤
  • 验证系统能观性
  • 写出观测器方程并求误差动态矩阵
  • 按期望特征多项式比较系数求出 L
  • 校验观测器收敛速度是否合适
通用考法
  • 本卷考过由渐进状态结构图写出观测方程
  • 设计全维状态观测器
  • 由期望观测器极点求反馈增益阵 L
  • 分析观测器与状态反馈组合后的系统极点
常见易错
  • 本卷考过观测方程漏掉修正项G(y-ŷ)
  • 本卷考过把G写成与状态反馈K相同形式
  • 把观测器增益阵写成了状态反馈增益阵的形式
  • 忽略观测器极点过快会放大噪声
公式
能控性与能观性 状态空间分析
本卷考法
  • 判断系统完全能观以说明可设计观测器
本卷实例
  • 关键一步：构造能观判别阵并计算其秩
  • 关键一步：秩等于系统阶数时判定极点可任意配置
  • 中间结果：能观判别阵满秩为设计观测器的前提
  • 卡点：判别阵中C与A的相乘顺序不可颠倒
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
