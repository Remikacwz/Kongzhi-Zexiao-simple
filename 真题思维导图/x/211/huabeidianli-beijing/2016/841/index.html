2二、参数根轨迹与衰减振荡K范围#

思路
  • 把特征方程整理成以k为变量的等效开环传函，判断根轨迹类型后由虚轴交点与分离点定衰减振荡区间。

本卷考法

本卷实例

  • 关键一步：由等效传函的相角条件判断是零度根轨迹
  • 中间结果：等效开环含一个极点与两个零点
  • 卡点：开环含负号时相角条件易误当180度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 注意相角条件是否变成 0°

  • 整理时没有把参数完整地提到分子位置

思路

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统

4四、开环幅相曲线与奈奎斯特判据#

思路
  • 求开环幅频相频表达式与渐近线，画奈氏曲线后用Z=P-2N判断闭环稳定性。
频率特性的物理意义与求法 频域分析
本卷考法
  • 求开环传函的幅频相频表达式与渐近线
本卷实例
  • 关键一步：令s=jω代入并分离实部与虚部
  • 中间结果：给出ω→0+、转折频率与∞处的趋势
  • 卡点：振荡环节在转折频率处相角跳变180度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤

  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求开环传函的幅频相频表达式与渐近线
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错

  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

本卷考法

本卷实例

  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤

  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法

  • 由开环幅相曲线判断闭环稳定性
