1一、水温控制系统工作过程与方框图#

思路
  • 以热水温度为被控量、热交换器为被控对象，按偏差闭环并叠加冷水流量顺馈补偿，画出复合控制系统方框图。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 由水温控制系统指认被控对象、控制装置并说明控制原理
本卷实例
  • 关键一步：以热水温度为目标反推被控对象与控制装置
  • 关键一步：把按偏差闭环与按扰动顺馈叠加为复合控制
  • 中间结果：温度控制器调节阀门开度改变蒸汽量
  • 中间结果：冷水流量经流量计作顺馈补偿信号
  • 卡点：原理图与方框图连线需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过由水温控制系统指认被控对象、控制装置并说明控制原理
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把蒸汽阀门等执行器误当成被控对象
  • 本卷考过漏掉冷水流量这一主要扰动及顺馈补偿
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 指出系统的被控量、操纵量与主要扰动量
本卷实例
  • 关键一步：按工艺要求确定被控量为热水温度
  • 中间结果：操纵量为蒸汽流量、主要扰动为冷水流量
  • 卡点：扰动通道是否需前馈补偿依题意判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤

2二、二阶系统四种阻尼单位阶跃响应#

思路
  • 写出标准二阶闭环传函，按阻尼比ξ的四种取值分别求单位阶跃响应，并画极点分布图与响应曲线。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 推导无阻尼、欠阻尼、临界阻尼、过阻尼的阶跃响应
本卷实例
  • 关键一步：把闭环传函写成ωn与ξ的标准形式再按ξ分类
  • 关键一步：由特征根实部与虚部看是否振荡
  • 中间结果：四种情况极点依次在虚轴、左半复平面、负实重根、两负实根
  • 卡点：四条响应曲线与四种极点分布对应易混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过推导无阻尼、欠阻尼、临界阻尼、过阻尼的阶跃响应
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过未把s²项系数归一化就套二阶公式
  • 本卷考过混淆临界阻尼与过阻尼的极点位置
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
零极点分布与响应模态 传递函数
本卷考法
  • 由闭环极点分布写出响应模态并判断收敛与振荡
本卷实例
  • 关键一步：极点实部决定衰减快慢、虚部决定振荡频率
  • 中间结果：虚轴上极点对应等幅振荡
  • 卡点：临界与过阻尼都无超调但响应快慢不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由闭环极点分布写出响应模态并判断收敛与振荡
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 本卷考过只看极点就断定振荡而忽略零点影响
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

3三、带虚轴极点系统的奈氏曲线与判稳#

思路
  • 把开环传函代入s=jω求幅相表达式，补画无穷大半径圆弧后按奈氏判据判断闭环稳定性。
频率特性的物理意义与求法 频域分析
本卷考法
  • 求开环传递函数的幅频、相频表达式并画奈氏曲线
本卷实例
  • 关键一步：令s=jω代入开环传函，分别求模与相角
  • 中间结果：给出ω→0+与ω→∞的幅值相角趋势
  • 卡点：虚轴极点处相角跳变与圆弧需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求开环传递函数的幅频、相频表达式并画奈氏曲线
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过求幅值时忘记把分母复数取模后再相除
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由幅相曲线用奈奎斯特判据判断闭环稳定性
本卷实例
  • 关键一步：先数P，再由曲线包围(-1,j0)次数定N
  • 中间结果：用Z=P-2N得右半平面闭环极点数
  • 卡点：积分环节补画的无穷大圆弧方向易取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由幅相曲线用奈奎斯特判据判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过未先数开环右半平面极点数P
  • 本卷考过把包围圈数正负号定义搞反
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

4四、两种串联校正网络比较与相角裕度#

思路
  • 由校正网络转折频率写出Gc(s)，与G0相乘后求截止频率和相角裕度，比较两种校正的稳定性。
超前校正 系统校正
本卷考法
  • 分析超前校正网络对截止频率与相角裕度的作用
本卷实例
  • 关键一步：由转折频率写超前校正传函并与G0相乘
  • 中间结果：校正后高频段幅频抬高使截止频率右移
  • 卡点：两种校正网络参数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过分析超前校正网络对截止频率与相角裕度的作用
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 本卷考过补偿角未计入截止频率变化带来的相角损失
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

5五、立方非线性描述函数与系统判稳#

思路
  • 按正弦输入求立方非线性的描述函数，再比较负倒描述函数与线性部分奈氏曲线判断自振。
描述函数法基础 非线性系统
本卷考法
  • 求奇对称非线性特性y=x³的描述函数
本卷实例
  • 关键一步：取正弦输入求输出基波分量再除以幅值A
  • 中间结果：N(A)为实数并随A单调增大
  • 卡点：高次谐波被忽略的适用条件需说明
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过求奇对称非线性特性y=x³的描述函数
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
