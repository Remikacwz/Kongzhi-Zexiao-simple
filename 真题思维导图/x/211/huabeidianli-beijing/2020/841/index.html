1一、电动机转速控制系统工作原理与方框图#

思路
  • 说明转速给定与测速反馈的偏差经控制器、功放驱动直流电机调速的工作过程，并画出控制原理方框图。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出转速控制系统的被控对象、被控量与各部件作用
本卷实例
  • 关键一步：由给定电压与测速电压之差判断偏差方向
  • 关键一步：把比较、控制器、功放、电机、测速连成闭环
  • 中间结果：测速发电机把转速转换为反馈电压
  • 卡点：系统接线与部件名称需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法

  • 画出给定系统的闭环方框图并说明工作过程

  • 本卷考过只画方框图不指认环节作用

  • 只画方框图而不指认环节，或反之，漏答一半

2二、随动系统结构图与稳态误差条件#

思路
  • 由微分方程组画动态结构图，求闭环误差传函并按终值定理写出稳态误差表达式，由误差上界反求K1条件。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由微分方程组画出随动系统动态结构图
本卷实例
  • 关键一步：逐式做拉氏变换并按因果顺序连接各环节
  • 关键一步：先化简反馈内环再合并前向通路
  • 中间结果：结构图含一个局部反馈内环
  • 卡点：比较点与引出点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由微分方程组画出随动系统动态结构图
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过三个环节的输入输出关系接反
  • 本卷考过内环化简时把外环信号当常数
  • 化简内环时把外环的信号当成常数处理
误差定义与误差传递函数 稳态误差
本卷考法
  • 写随动系统的误差传递函数
本卷实例
  • 关键一步：把误差定义为给定与反馈之差
  • 关键一步：按结构图列E(s)/R(s)传函
  • 中间结果：误差传函分母为闭环特征式
  • 卡点：误差定义取e=r-c还是e=r-b需按题意核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写随动系统的误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响

  • 本卷考过非单位反馈时误用单位反馈定义
  • 本卷考过未判稳就直接用终值定理
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

典型输入下的稳态误差计算 稳态误差

3三、参数根轨迹求等效开环传函#

思路
  • 把含k的闭环特征方程整理成1+kG*(s)=0的形式，提出等效开环传函，再按根轨迹法则绘制并分析。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 由闭环特征方程求参数根轨迹的等效开环传函
本卷实例
  • 关键一步：把D(s)按含k与不含k分成两组
  • 关键一步：相除后整理成1+kG*(s)的标准形式
  • 中间结果：等效开环传函含一个零点与三个极点
  • 卡点：等效开环传函的零极点位置需按D(s)核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过由闭环特征方程求参数根轨迹的等效开环传函
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 本卷考过没把参数完整提到分子位置
  • 本卷考过零度根轨迹仍用180度相角条件
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制以k为参数的根轨迹草图
本卷实例
  • 关键一步：标出等效开环零极点并定实轴根轨迹段
  • 关键一步：按n与m之差求渐近线倾角和交点
  • 中间结果：参数根轨迹的走向由等效开环零极点决定
  • 卡点：分离点与虚轴交点需联立方程核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤

  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制以k为参数的根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴段判据的零极点个数算错
  • 本卷考过渐近线条数与夹角搞错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

4四、由对数幅频特性求校正环节与传函#

思路
  • 由校正环节低频段幅值为0dB与两处转折频率写出其传函，再按L0的低频斜率与高度求校正前传函，相乘得校正后传函。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频特性反求校正环节的传递函数
本卷实例
  • 关键一步：由低频段斜率与高度定型别与增益
  • 关键一步：按各转折频率依次写出环节
  • 中间结果：校正环节由超前网络的两个转折频率构成
  • 卡点：转折频率读数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频特性反求校正环节的传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 本卷考过把延长线交点当增益未折算型别
  • 本卷考过折射频率处斜率变化判断错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

校正的基本概念与性能指标 系统校正
本卷考法
  • 由相频特性判断校正方式为超前校正
本卷实例
  • 关键一步：由校正环节相角始终为正判断超前
  • 关键一步：比较校正前后截止频率与裕度变化

步骤

通用考法
  • 本卷考过由相频特性判断校正方式为超前校正
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错

  • 本卷考过只比较幅值就下结论
  • 把截止频率与相位穿越频率混用

5五、奈奎斯特曲线与稳定K范围#

思路
  • 求开环幅相表达式与曲线趋势，画奈氏曲线按Z=P-2N判K=3时的稳定性，再求临界K得稳定范围。
频率特性的物理意义与求法 频域分析
本卷考法
  • 求开环传递函数的幅频与相频表达式
本卷实例
  • 关键一步：令s=jω代入并分离幅频与相频
  • 关键一步：按转折频率分段讨论曲线趋势
  • 中间结果：曲线起于负虚轴无穷远、止于原点
  • 卡点：曲线穿越实轴的位置需按幅相式核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求开环传递函数的幅频与相频表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过相角累加时漏掉积分环节的-90度
  • 本卷考过幅值取模时忘记分母开方
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由奈氏曲线判断K=3时闭环稳定性

思路
