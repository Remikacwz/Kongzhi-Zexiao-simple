1一、选择题（1 至 10）20 分#

思路
  • 十道选择逐题独立：一阶调节时间、闭环极点主导性、最佳阻尼比超调、传递函数性质、阶跃稳态误差为常数判型别、一阶相频与频率响应定义、II 型低频斜率、采样周期对稳定域影响、差分方程求脉冲传函。
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由一阶传递函数与阶跃输入幅值求调节时间
本卷实例
  • 关键一步：先把传递函数化成时间常数形式读出时间常数
  • 关键一步：输入幅值只改稳态值，不改变调节时间
  • 中间结果：调节时间只由时间常数和误差带决定，与输入幅值无关
  • 卡点：误按 5% 误差带取三倍时间常数，与本卷其他小题的误差带混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由一阶传递函数与阶跃输入幅值求调节时间
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 说明闭环极点离虚轴的远近对动态过程影响的大小
本卷实例
  • 关键一步：离虚轴越近的极点实部绝对值越小、暂态项衰减越慢
  • 关键一步：衰减慢的分量在响应中占比大，主导动态过程
  • 中间结果：越靠近虚轴的闭环极点对动态过程影响越大
  • 卡点：把虚轴与实轴混淆，误答离实轴越近影响越大
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过说明闭环极点离虚轴的远近对动态过程影响的大小
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由最佳阻尼比判断欠阻尼二阶系统的超调量
本卷实例
  • 关键一步：超调量只由阻尼比决定，把二分之根号二代入欠阻尼超调公式
  • 中间结果：最佳阻尼比对应一个小超调量而非零
  • 卡点：把最佳阻尼比当成无阻尼或临界阻尼，误答超调为零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由最佳阻尼比判断欠阻尼二阶系统的超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
传递函数的定义与基本性质 传递函数
本卷考法
  • 判断传递函数是否随输入量的形式与大小改变
本卷实例
  • 关键一步：传递函数在零初始条件下由系统结构与参数定义
  • 中间结果：与输入量的形式和大小都无关，只取决于系统本身
  • 卡点：漏掉零初始条件这一前提，误以为输入会改变传递函数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过判断传递函数是否随输入量的形式与大小改变
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由阶跃输入下稳态误差为常数反推系统型别
本卷实例
  • 关键一步：阶跃输入误差为有限常数说明位置误差系数有限且非零
  • 中间结果：零型系统对阶跃输入误差为有限常数，高型别系统误差为零
  • 卡点：把有限常数误当成零，或未排除高阶别系统
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由阶跃输入下稳态误差为常数反推系统型别
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

频率特性的物理意义与求法 频域分析
本卷考法
  • 求一阶环节在指定频率处的相频值
  • 指出正弦输入下输出的稳态分量即频率响应
本卷实例
  • 关键一步：把 jω 代入传递函数，分母一阶环节的相角取负反正切
  • 关键一步：频率响应取正弦输入下输出的稳态分量
  • 中间结果：一阶环节相角随频率单调变负，暂态分量不属于频率响应
  • 卡点：把相频与幅频写反，或把暂态分量也算进频率响应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求一阶环节在指定频率处的相频值
  • 本卷考过指出正弦输入下输出的稳态分量即频率响应
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 由系统型别判断对数幅频低频段渐近线的斜率
本卷实例
  • 关键一步：低频段渐近线斜率等于负二十乘以开环积分环节个数
  • 中间结果：低频段斜率按每型负二十分贝规律累加，型别越高越陡
  • 卡点：把型别数与斜率倍数的对应关系记错，与 I 型斜率混记
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过由系统型别判断对数幅频低频段渐近线的斜率
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

离散系统稳定性分析 离散控制系统
本卷考法
  • 判断增大采样周期对开环增益稳定范围的影响
本卷实例
  • 关键一步：采样周期增大使离散系统保持的信息减少、稳定性变差
  • 中间结果：开环增益的稳定范围随采样周期增大而缩小
  • 卡点：把采样周期越小越好简单化，忽略保持信息与物理实现两方面
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过判断增大采样周期对开环增益稳定范围的影响
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒
公式
脉冲传递函数 离散控制系统
本卷考法
  • 由离散差分方程求脉冲传递函数
本卷实例
  • 关键一步：对方程两边取 z 变换，按移位定理处理各阶差分
  • 关键一步：整理成输出比输入的 z 有理分式
  • 中间结果：分子分母按 z 的降幂排列，系数由移位项对应读得
  • 卡点：移位定理的初始条件处理错，或分子分母的系数顺序颠倒
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过由离散差分方程求脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)

2二、发动机怠速控制系统用梅森公式求传函10 分#

思路
  • 怠速控制系统结构图含参考输入通道。答案先数出六条单独回路且两两均有公共节点，再找两条前向通路，用梅森公式求 Y(s)/R(s)。题面含图未读图。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图或信号流图用梅森公式求闭环传递函数
本卷实例
  • 关键一步：先数出全部单独回路写出特征式，再找前向通路及特征余子式
  • 关键一步：本题六条回路两两均有公共节点，无互不接触回路
  • 中间结果：特征式为 1 减全部单独回路增益之和，分子为各前向通路乘对应余子式
  • 卡点：题面含图未读图，回路条数与支路接法需回原卷核对图；或漏写回路增益的负号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图或信号流图用梅森公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 化简含多条交叉回路的怠速控制系统方框图
本卷实例
  • 关键一步：辨清各回路的公共节点，判断有无互不接触回路
  • 关键一步：回路较多时直接用梅森公式比逐层移动更稳
  • 中间结果：公共节点多使回路两两接触，特征式只保留一次项
  • 卡点：结构图拓扑需回原卷核对图；或把不接触回路重复计数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过化简含多条交叉回路的怠速控制系统方框图
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
