1一、选择题（1 至 10）30 分#

思路
  • 十道选择逐题独立：两种误差带调节时间比较、一阶系统斜坡稳态误差、劳斯判据判正实部根、由加速度误差反求型别与增益、实轴段左右侧判据、I 型低频斜率与增益对 Bode 图的影响、校正装置类型、连续与采样系统稳定根位置。
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 比较同一系统在 5% 与 2% 误差带下的调节时间
本卷实例
  • 关键一步：调节时间与误差带有关，误差带越小所需时间越长
  • 关键一步：5% 误差带取三倍时间常数，2% 误差带取四倍
  • 中间结果：同一系统按 2% 误差带算得的调节时间更长
  • 卡点：把两种误差带的系数记反，得出相反的结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过比较同一系统在 5% 与 2% 误差带下的调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求一阶系统在斜坡输入下的稳态误差
本卷实例
  • 关键一步：先由特征方程判断一阶系统稳定
  • 关键一步：零型系统对斜坡输入的误差随输入斜率增大
  • 中间结果：稳态误差由误差传函零频值与输入斜率共同决定
  • 卡点：未判稳就用终值定理；或把斜坡输入的误差公式写成阶跃的
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求一阶系统在斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
劳斯判据 稳定性分析
本卷考法
  • 由劳斯判据判断四阶特征方程正实部根的个数
本卷实例
  • 关键一步：列劳斯表后数第一列符号改变的次数
  • 中间结果：第一列符号改变次数即正实部特征根个数
  • 卡点：缺项未补零；或把符号改变次数与系统阶数混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由劳斯判据判断四阶特征方程正实部根的个数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由加速度输入下的稳态误差反求系统型别与开环增益
本卷实例
  • 关键一步：加速度输入误差为有限值说明系统为二型
  • 关键一步：误差等于加速度误差系数的倒数
  • 中间结果：二型系统加速度误差系数与开环增益对应
  • 卡点：型别判错导致选错误差系数；或把倒数关系写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由加速度输入下的稳态误差反求系统型别与开环增益
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 由实轴上根轨迹段判断某点左侧或右侧零极点个数之和
本卷实例
  • 关键一步：实轴段属于根轨迹的充要条件是右侧实零极点个数之和为奇数
  • 中间结果：该结论对一百八十度根轨迹成立，零度根轨迹取偶数
  • 卡点：把左右侧方向与奇偶判据对应关系弄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过由实轴上根轨迹段判断某点左侧或右侧零极点个数之和
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 由 I 型系统低频段斜率判断传递函数形式
  • 分析减小开环增益对幅频与相频曲线的影响
本卷实例
  • 关键一步：I 型系统低频段斜率为负二十，看积分环节个数
  • 关键一步：增益只使幅频曲线上下平移，相频与增益无关
  • 中间结果：减小开环增益幅频曲线下移，相频曲线不变
  • 卡点：把幅频曲线的上下移动与相频变化混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过由 I 型系统低频段斜率判断传递函数形式
  • 本卷考过分析减小开环增益对幅频与相频曲线的影响
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
滞后-超前校正 系统校正
本卷考法
  • 由串联校正装置的传递函数判断其类型
本卷实例
  • 关键一步：把转折频率按从小到大排列，看相角先滞后还是先超前
  • 关键一步：先滞后再超前对应滞后超前校正
  • 中间结果：分子两个一阶微分、分母两个惯性环节构成滞后超前网络
  • 卡点：把滞后超前与超前滞后两种类型说反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 兼顾稳态精度与动态性能，适合指标要求较高的场合
  • 低频段用滞后部分提高增益，中高频段用超前部分提高裕度
  • 设计时先确定超前部分，再确定滞后部分
步骤
  • 按稳态精度要求确定开环增益
  • 选择新的截止频率并计算超前部分参数
  • 计算为把低频增益抬到要求值所需的滞后部分参数
  • 合并写出校正装置并校验
通用考法
  • 本卷考过由串联校正装置的传递函数判断其类型
  • 设计滞后-超前校正装置
  • 说明为何单一校正无法满足指标
  • 分析校正后系统的低频与高频特性
常见易错
  • 先设计滞后部分导致截止频率反复调整
  • 两部分的转折频率分布重叠，互相削弱
公式
离散系统稳定性分析 离散控制系统
本卷考法
  • 指出连续与采样系统稳定特征根各自分布的区域
本卷实例
  • 关键一步：连续系统稳定要求特征根位于 s 平面左半开平面
  • 关键一步：采样系统稳定要求特征根位于 z 平面单位圆内
  • 中间结果：两种系统稳定域在各自平面上分别是左半平面与单位圆内
  • 卡点：把单位圆内与单位圆外说反，或与虚轴左右混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过指出连续与采样系统稳定特征根各自分布的区域
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

2二、反馈系统结构图与稳定度#

思路
  • 反馈控制系统结构图含三条闭合回路。第 1 问用梅森公式求闭环传递函数；第 2 问求使系统具有给定稳定度的增益取值。题面含图未读图。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图用梅森公式求闭环传递函数
本卷实例
  • 关键一步：数出三条单独回路写出特征式，再找前向通路与余子式
  • 关键一步：各回路间无互不接触回路，特征式只保留一次项
  • 中间结果：闭环传递函数分子为前向通路增益，分母为特征式
  • 卡点：题面含图未读图，回路条数与支路接法需回原卷核对图；或漏写负号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图用梅森公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

通用考法

参数稳定域的确定 稳定性分析
本卷考法
  • 确定使系统具有指定稳定度的参数取值范围
本卷实例
  • 关键一步：由劳斯表首列不等式取交集得参数下限
  • 关键一步：稳定度越大对增益下界要求越高
  • 中间结果：增益只要大于某一下限即满足稳定度要求
  • 卡点：只列部分首列元素的不等式；或把交集端点是否包含弄错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过确定使系统具有指定稳定度的参数取值范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过画奈氏曲线并用奈奎斯特判据判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

稳定裕度 频域分析
本卷考法
  • 求校正前后系统的相角裕度并比较
本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）

  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
