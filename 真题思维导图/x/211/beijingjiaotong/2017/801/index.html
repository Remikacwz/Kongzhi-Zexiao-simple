1一、填空题（1 至 10）20 分#

思路
  • 十道填空逐题独立。
零极点分布与响应模态 传递函数
本卷考法
  • 由闭环传递函数求单位脉冲响应
本卷实例
  • 关键一步：单位脉冲响应是传递函数的拉氏反变换
  • 关键一步：先部分分式展开再逐项反变换
  • 中间结果：响应为指数衰减项的组合
  • 卡点：把单位阶跃响应当成脉冲响应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由闭环传递函数求单位脉冲响应
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零
公式
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 求一阶系统在 2% 误差带下的调节时间
本卷实例
  • 关键一步：把 5/(s+2) 化成 2.5/(0.5s+1) 读出时间常数
  • 关键一步：按二百分之一误差带取四倍时间常数
  • 中间结果：时间常数为零点五秒
  • 卡点：把分子增益当成时间常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过求一阶系统在 2% 误差带下的调节时间
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 说明根轨迹上点的充要条件
  • 比较根轨迹法与频域法的临界位置
本卷实例
  • 关键一步：根轨迹上的点必须满足相角条件，幅值条件只用于定增益
  • 关键一步：根轨迹法临界点在虚轴，频域法临界点在负一 j0
  • 中间结果：相角条件是根轨迹的充要条件
  • 卡点：把相角条件与幅值条件的用途弄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过说明根轨迹上点的充要条件
  • 本卷考过比较根轨迹法与频域法的临界位置
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 写出正反馈系统实轴上存在根轨迹的条件
本卷实例
  • 关键一步：正反馈对应零度根轨迹，相角条件为 2kπ
  • 关键一步：实轴某段右侧开环实数零极点个数之和为偶数
  • 中间结果：零度根轨迹实轴段判据与 180 度相反
  • 卡点：零度根轨迹仍沿用 180 度实轴段判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过写出正反馈系统实轴上存在根轨迹的条件
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由幅相曲线不包围负一 j0 判断开环右半平面极点数
本卷实例
  • 关键一步：由 Z 等于 P 减二 N 且闭环稳定即 Z 为零
  • 关键一步：曲线不包围负一 j0 则 N 为零，故要求 P 为零
  • 中间结果：开环右半平面极点数为零
  • 卡点：把包围圈数的符号定义弄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由幅相曲线不包围负一 j0 判断开环右半平面极点数
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
稳定裕度 频域分析
本卷考法
  • 指出表征系统相对稳定性的两种裕度
本卷实例
  • 关键一步：相对稳定性由相角裕度与幅值裕度共同度量
  • 关键一步：相角裕度定义在剪切频率处、幅值裕度定义在相位穿越频率处
  • 中间结果：两个裕度分别对应两个特殊频率
  • 卡点：把两个裕度对应的频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过指出表征系统相对稳定性的两种裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
超前校正 系统校正
本卷考法
  • 由校正环节传递函数判断超前或滞后
本卷实例
  • 关键一步：分子零点转折频率高于分母极点转折频率时相角为正
  • 关键一步：零度小于一使环节呈超前特性
  • 中间结果：该环节为超前校正环节
  • 卡点：把超前与滞后校正的零极点位置说反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过由校正环节传递函数判断超前或滞后
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
离散系统的动态性能与极点分布 离散控制系统
本卷考法
  • 说明采样系统极点位置与暂态衰减快慢的关系
本卷实例
  • 关键一步：采样系统响应按极点模的 k 次方衰减
  • 关键一步：极点越靠近原点模越小、衰减越快
  • 中间结果：原点附近的极点对应快速衰减
  • 卡点：误按 s 平面实部大小判断收敛速度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点在 z 平面上的位置决定响应形式
  • 极点越靠近原点衰减越快，越靠近单位圆振荡越强
  • 极点的幅角决定振荡频率，幅值决定衰减速度
  • 采样周期增大会使动态性能变差甚至不稳定
步骤
  • 求闭环脉冲传递函数的极点
  • 按极点在单位圆内的位置判断响应形式
  • 由极点的模与幅角估算衰减与振荡频率
  • 与连续系统指标对应关系相互校验
通用考法
  • 本卷考过说明采样系统极点位置与暂态衰减快慢的关系
  • 由闭环极点分布判断动态性能
  • 与连续域指标互相换算
  • 说明采样周期对动态性能的影响
常见易错
  • 把 z 平面极点当作 s 平面极点直接读阻尼比
  • 忽略单位圆上极点对应等幅振荡
公式
采样过程与香农采样定理 离散控制系统
本卷考法
  • 写出零阶保持器的传递函数
本卷实例
  • 关键一步：零阶保持器把采样值保持一个采样周期
  • 关键一步：时域为两个阶跃函数之差，拉氏变换为一减 e 负 Ts 除以 s
  • 中间结果：传递函数为一减 e 负 Ts 再除以 s
  • 卡点：与一阶保持器的传递函数混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过写出零阶保持器的传递函数
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

2二、电网络建模与结构图化简20 分#

思路
  • 给出描述电网络动态特性的微分方程组，要求以 ur 为输入、uc 为输出，依次选取 i1、u、i2 为中间变量建立动态结构图，并用结构图化简法求 Uc(s)/Ur(s)。题面含图未读图。
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由电路微分方程组建立动态结构图
本卷实例
  • 关键一步：把四个方程分别画成以中间变量为节点的运算框图
  • 关键一步：按输入输出关系依次串接
  • 中间结果：每个方程对应一个相加点或积分环节
  • 卡点：电路方程符号需回原卷核对图；或电容电流方向取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由电路微分方程组建立动态结构图
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图用化简法求输入输出传递函数
本卷实例
  • 关键一步：结构图先用逐层化简合并，再核对前向通路
  • 关键一步：反馈回路按 1 加回路增益处理
  • 中间结果：化简结果为两个二次多项式之比
  • 卡点：引出点与比较点交叉时移动规则用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图用化简法求输入输出传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 化简含局部反馈的多回路结构图
本卷实例
  • 关键一步：先化内环为等效环节再合并外环
  • 中间结果：多次化简后分母阶次逐步提高
  • 卡点：把内环以外的信号当成常数处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
