1一、填空题（1 至 10）30 分#

思路
  • 十道填空逐题独立：由零极点分布求二阶超调；P、I 的含义；由传函形式辨识超前校正；采样稳定性与采样周期的关系；增加积分环节对稳态误差的作用；增加开环增益时对数幅频与相频的变化；增加开环零点根轨迹弯曲方向与稳定性；不稳定惯性环节幅相曲线形状与象限；劳斯表全零行对应特征根情形；z 域稳定充要条件。
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由闭环零极点分布图求欠阻尼二阶超调
本卷实例
  • 关键一步：由极点与负实轴夹角求得阻尼比再算超调
  • 中间结果：夹角六十度对应阻尼比零点五与给定超调
  • 卡点：把阻尼角与阻尼比直接混用；分布图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由闭环零极点分布图求欠阻尼二阶超调
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

PID 控制器与参数整定 系统校正
本卷考法
  • 指出 P、I 分别代表比例与积分环节
本卷实例
  • 关键一步：按环节名称与作用对应写出英文缩写含义
  • 中间结果：P 为比例、I 为积分
  • 卡点：把 I 误答成微分环节 D
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过指出 P、I 分别代表比例与积分环节
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式
超前校正 系统校正
本卷考法
  • 由传函形式辨识超前校正装置
本卷实例
  • 关键一步：比较零点与极点时间常数的大小判断超前或滞后
  • 中间结果：零点在极点左侧属超前校正
  • 卡点：超前与滞后的时间常数关系记反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过由传函形式辨识超前校正装置
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
离散系统稳定性分析 离散控制系统
本卷考法
  • 判断采样系统稳定性与采样周期的关系
本卷实例
  • 关键一步：比较采样周期变化对允许增益范围的影响
  • 中间结果：采样周期增大使稳定范围缩小
  • 卡点：把采样周期与稳定范围看成同向变化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过判断采样系统稳定性与采样周期的关系
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 说明增加前向通道积分环节对稳态误差的作用
本卷实例
  • 关键一步：积分环节提高系统型别从而降低稳态误差
  • 中间结果：型别提高一阶，跟踪给定输入的误差减小
  • 卡点：忽略积分环节对稳定性的不利影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过说明增加前向通道积分环节对稳态误差的作用
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 判断增加开环增益时对数幅频与相频的变化
本卷实例
  • 关键一步：增益只抬升幅频曲线、不改变相频表达式
  • 中间结果：幅频上移而相频保持不变
  • 卡点：误答相频也随之上移
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过判断增加开环增益时对数幅频与相频的变化
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

附加开环零极点的影响 根轨迹法
本卷考法
  • 说明增加开环零点对根轨迹与稳定性的影响
本卷实例
  • 关键一步：附加左半平面零点使根轨迹向左弯曲
  • 中间结果：根轨迹左移对稳定性有利
  • 卡点：把零点与极点的作用搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过说明增加开环零点对根轨迹与稳定性的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
频率特性的物理意义与求法 频域分析
本卷考法
  • 判断不稳定惯性环节幅相曲线的形状与象限
本卷实例
  • 关键一步：写相频表达式判断取值范围落在第三象限
  • 中间结果：幅相曲线为半圆且位于第三象限
  • 卡点：把极点为正的环节当成最小相位处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过判断不稳定惯性环节幅相曲线的形状与象限
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
劳斯判据 稳定性分析
本卷考法
  • 说明劳斯表出现全零行时特征根的可能情形
本卷实例
  • 关键一步：全零行说明存在关于原点对称的根
  • 中间结果：可能为符号相反的实根或共轭虚根等
  • 卡点：只答一种情形而漏掉其它组合
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过说明劳斯表出现全零行时特征根的可能情形
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

2二、结构图化简与特征根配置#

思路
  • 结构图含内环反馈。第1问按比较点移动与串并联化简求 C(s)/R(s)；第2问由闭环特征方程按指定两特征根比较系数求两参数；第3问代入得闭环传函，部分分式展开后拉氏反变换求单位阶跃输出。题面含图未读图。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 逐层化简含内环的多回路结构图
本卷实例
  • 关键一步：先合内环再合外环，避免把外环信号当常数
  • 中间结果：闭环传函分母为一加内外环开环乘积
  • 卡点：化简内环时把外环信号当常数；结构需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过逐层化简含内环的多回路结构图
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由指定闭环特征根反求开环参数
本卷实例
  • 关键一步：把期望两特征根写成特征多项式与特征式比较系数
  • 中间结果：一次项与常数项各给一个参数方程
  • 卡点：特征式未首一化就比较系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由指定闭环特征根反求开环参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由闭环传函部分分式展开求单位阶跃全响应
本卷实例
  • 关键一步：把输出分解为若干一阶极点项后进行拉氏反变换
  • 中间结果：反变换得到含指数项的时间响应表达式
  • 卡点：部分分式系数未回代校验导致响应对不上稳态值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由闭环传函部分分式展开求单位阶跃全响应
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计扰动补偿环节实现扰动误差不变性
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
