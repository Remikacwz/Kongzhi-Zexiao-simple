1一、结构图化简求传递函数#

思路
  • 系统动态结构图给出，要求用结构图化简法求闭环传递函数 C(s)/R(s)。题面含图未读图。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由多回路结构图用梅森公式或逐层化简求闭环传递函数
本卷实例
  • 关键一步：先数出全部单独回路与前向通路
  • 关键一步：判断回路之间是否互不接触再写特征式
  • 中间结果：特征式为 1 减全部单独回路增益之和
  • 卡点：结构拓扑需回原卷核对图；或回路数漏算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由多回路结构图用梅森公式或逐层化简求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 化简含局部反馈的多回路结构图
本卷实例
  • 关键一步：按内环到外环顺序逐层合并
  • 关键一步：比较点与引出点移动保持信号等效
  • 中间结果：内环等效后闭分母出现 1 加回路增益
  • 卡点：化简内环时把外环信号当常数处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过化简含局部反馈的多回路结构图
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2二、PI 控制器稳定性与时域指标#

思路
  • 某系统动态结构图引入 PI 控制器。第 1 问设 kp、kI 均大于 0，求使闭环稳定的取值范围；第 2 问取 kp 等于 kI 等于 8，求单位阶跃下的超调量、5% 调节时间与稳态误差。题面含图未读图。
参数稳定域的确定 稳定性分析
本卷考法
  • 求使含 PI 控制器闭环系统稳定的参数范围
本卷实例
  • 关键一步：写出含 kp、kI 的闭环特征方程
  • 关键一步：用劳斯判据列出首列元素全部大于零的不等式组
  • 中间结果：特征方程一次项含 kp、常数项含 kI
  • 卡点：漏掉 PI 控制器比例项引入的 s 一次项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求使含 PI 控制器闭环系统稳定的参数范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由闭环传递函数求超调量与调节时间
本卷实例
  • 关键一步：PI 参数代入后开环积分环节与对象极点对消，闭环降为二阶
  • 关键一步：化为标准二阶形式读阻尼比与自然频率
  • 中间结果：化简后闭环为无零点二阶系统
  • 卡点：5% 误差带调节时间系数用成 2% 的
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由闭环传递函数求超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位阶跃输入下的稳态误差
本卷实例
  • 关键一步：先判稳再用终值定理或静态误差系数求误差
  • 中间结果：含积分环节时阶跃误差为零
  • 卡点：未判稳就套终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位阶跃输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征方程读阻尼比与自然频率
本卷实例
  • 关键一步：把特征方程最高次项系数归一化后对应标准形式
  • 中间结果：一次项系数为二倍阻尼比乘自然频率
  • 卡点：未归一化就直接读系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征方程读阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

3三、误差传函与系统型别#

思路
  • 系统含 G1 与 G2 两个环节，r(t) 与 n(t) 分别为参考输入与扰动输入。第 1 问求误差传函 Gre 与 Gne；第 2 问判断是否存在 n1、n2 使无扰动单位斜坡稳态误差为零并求 n1 加 n2 上限；第 3 问两输入均为阶跃时求 E(s) 并在最低阶次下取零稳态误差。题面含图未读图。
误差定义与误差传递函数 稳态误差
本卷考法
  • 分别写出参考输入与扰动输入到误差的传递函数
本卷实例
  • 关键一步：令扰动为零求参考误差传函，令参考为零求扰动误差传函
  • 关键一步：按结构图回路增益写分母
  • 中间结果：两传函共用同一特征式作分母
  • 卡点：反馈极性需回原卷核对图；或两种误差定义混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过分别写出参考输入与扰动输入到误差的传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
典型输入下的稳态误差计算 稳态误差
本卷考法

本卷实例

  • 关键一步：由误差传函低频阶次读 n1 加 n2 下限
  • 中间结果：斜坡零误差给出 n1 加 n2 大于等于二
  • 卡点：漏掉组合输入中的某一分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由斜坡输入稳态误差为零反求积分环节个数
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 在满足零稳态误差前提下取系统阶次最低
本卷实例
  • 关键一步：零误差下限与特征多项式不缺项上限取交
  • 关键一步：两端约束夹出唯一次数组合
  • 中间结果：阶次最低时取 n1 等于一、n2 等于零
  • 卡点：只满足零误差却未检查闭环特征式是否缺项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过在满足零稳态误差前提下取系统阶次最低
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

4四、根轨迹与极点实部约束#

思路
  • 单位负反馈开环为 K(s+1)/(s²(0.2s+1))。第 1 问绘制闭环根轨迹；第 2 问确定使闭环稳定且全部闭环极点实部绝对值都大于 1 的 K 范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画根轨迹并写实轴段与渐近线
本卷实例
  • 关键一步：由极点零点分布定分支数、实轴段与渐近线
  • 关键一步：两条渐近线在实轴上交于零极点重心
  • 中间结果：开环有两个原点极点、一个实极点与一个实零点
  • 卡点：实轴段右侧零极点个数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画根轨迹并写实轴段与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹分离点并筛选有效解
本卷实例
  • 关键一步：由 dK/ds 等于零建立分离点方程
  • 关键一步：舍去不落在实轴根轨迹段上的复根
  • 中间结果：分离点方程解为共轭复根，全部舍去
  • 卡点：未筛选就保留复数解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹分离点并筛选有效解
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界增益
本卷实例
  • 关键一步：把纯虚变量代入闭环特征方程，实部虚部分别为零联立
  • 中间结果：交点只有原点，临界增益为零
  • 卡点：只代一个频率值就下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解

8八、采样系统单位阶跃响应#

思路
  • 闭环采样系统结构图给出，ZOH 为零阶保持器，采样周期 T 等于 0.5 秒，求系统单位阶跃响应并写出前 3 项。题面含图未读图。
脉冲传递函数 离散控制系统
本卷考法
  • 由连续环节与零阶保持器求脉冲传递函数
本卷实例
  • 关键一步：把连续部分作部分分式展开，逐项查 z 变换表
  • 关键一步：把零阶保持器的一减 z 负一次方因子乘在结果上
  • 中间结果：部分分式展开为 s 平方分之一、s 分之一与 s 加一分之一
  • 卡点：把无采样开关隔开的两个连续环节直接相乘取变换；或忘记零阶保持器
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过由连续环节与零阶保持器求脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)
公式
z 变换与 z 反变换 离散控制系统
本卷考法
  • 求 z 域响应序列的前几项
本卷实例
  • 关键一步：用长除法把闭环输出 z 传函展开成 z 的负幂级数
  • 关键一步：负幂级数的系数即采样时刻的响应序列
  • 中间结果：各级系数对应零时刻起的输出采样值
  • 卡点：部分分式分解漏项导致反变换出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • z 变换是离散信号的拉氏变换，令 z=e^{Ts} 得到
  • 常用函数的 z 变换要熟记
  • z 反变换可用部分分式法、幂级数法或留数法
  • 左半 s 平面映射到 z 平面单位圆内
步骤
  • 将连续传递函数展开为部分分式
  • 逐项查表做 z 变换
  • 需要时做 z 反变换求时间序列
通用考法
  • 本卷考过求 z 域响应序列的前几项
  • 求给定函数的 z 变换
  • 求 z 反变换得到采样序列
  • 说明 s 平面与 z 平面的映射关系
常见易错
  • 把 z 变换结果中的 e^{-aT} 写成 e^{-a}
  • 部分分式分解时漏项导致反变换出错
公式
离散系统的动态性能与极点分布 离散控制系统
本卷考法
  • 由闭环极点分布判断响应收敛性与形态
本卷实例
  • 关键一步：特征根模小于一系统稳定，模越小衰减越快
  • 中间结果：闭环两极点均为模小于一的正实根，响应单调收敛
  • 卡点：把 z 平面极点当 s 平面极点直接读阻尼比
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点在 z 平面上的位置决定响应形式
  • 极点越靠近原点衰减越快，越靠近单位圆振荡越强
  • 极点的幅角决定振荡频率，幅值决定衰减速度
  • 采样周期增大会使动态性能变差甚至不稳定
步骤
  • 求闭环脉冲传递函数的极点
  • 按极点在单位圆内的位置判断响应形式
  • 由极点的模与幅角估算衰减与振荡频率
  • 与连续系统指标对应关系相互校验
通用考法
  • 本卷考过由闭环极点分布判断响应收敛性与形态
  • 由闭环极点分布判断动态性能
  • 与连续域指标互相换算
  • 说明采样周期对动态性能的影响
常见易错
  • 把 z 平面极点当作 s 平面极点直接读阻尼比
  • 忽略单位圆上极点对应等幅振荡
