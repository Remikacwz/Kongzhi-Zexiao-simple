1一、选择题（1 至 9）27 分#

思路
  • 九道选择逐题独立：由阶跃响应求脉冲响应、一阶系统阶跃稳态误差、附加开环零点后的稳定范围、劳斯表数正实部根、根轨迹相角条件含义、指定频率处相频值、不稳定一阶系统相角走向、校正装置类型、比例反馈包围惯性的等效参数。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应求单位脉冲响应
本卷实例
  • 关键一步：单位脉冲响应等于单位阶跃响应的导数
  • 中间结果：对给定阶跃响应逐项求导后合并同类项
  • 卡点：忘记对时间求导而直接照抄响应式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应求单位脉冲响应
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 求一阶系统单位阶跃输入下的稳态误差
本卷实例
  • 关键一步：先由闭环特征方程确认系统稳定
  • 关键一步：再代入静态位置误差系数求误差
  • 中间结果：稳态误差与开环直流增益有关
  • 卡点：未先判稳就直接使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过求一阶系统单位阶跃输入下的稳态误差
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 分析附加开环零点对闭环稳定范围的影响
本卷实例
  • 关键一步：把附加零点写进开环传函后列闭环特征方程
  • 关键一步：用劳斯判据求零点位置的稳定条件
  • 中间结果：附加零点使稳定范围对零点位置产生约束
  • 卡点：把附加零点当成附加极点处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过分析附加开环零点对闭环稳定范围的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
劳斯判据 稳定性分析
本卷考法
  • 用劳斯表判断四阶特征方程正实部根个数
本卷实例
  • 关键一步：列劳斯表并数首列的符号改变次数
  • 中间结果：符号改变次数等于正实部特征根个数
  • 卡点：系数缺项未补零导致劳斯表列错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯表判断四阶特征方程正实部根个数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 解释根轨迹相角条件与幅值条件各自的作用
本卷实例
  • 关键一步：相角条件用于确定根的位置
  • 关键一步：幅值条件用于确定对应的增益大小
  • 中间结果：满足相角条件的点落在根轨迹上
  • 卡点：把相角条件与幅值条件的用途说反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过解释根轨迹相角条件与幅值条件各自的作用
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求指定频率处闭环系统的相频特性值
  • 判断右半平面极点一阶系统的相角走向
本卷实例
  • 关键一步：把 s 换为 jω 后取虚部与实部之比反正切
  • 关键一步：一阶不稳定系统的时间常数为负
  • 中间结果：相频表达式由各典型环节相角叠加
  • 卡点：相位所在象限判断错误
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求指定频率处闭环系统的相频特性值
  • 本卷考过判断右半平面极点一阶系统的相角走向
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
滞后校正 系统校正
本卷考法
  • 由校正装置传函判断其属于滞后校正
本卷实例
  • 关键一步：化为时间常数形式比较分子分母一次项系数
  • 中间结果：分母一次项系数大于分子时呈滞后特性
  • 卡点：把滞后与超前的判据方向弄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过由校正装置传函判断其属于滞后校正
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 比例反馈包围惯性环节后分析等效时间常数与快速性
本卷实例
  • 关键一步：把反馈支路与惯性环节合并求等效传函
  • 中间结果：等效时间常数缩小使快速性变好
  • 卡点：把时间常数与快速性的变化方向说反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过比例反馈包围惯性环节后分析等效时间常数与快速性
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、填空题（Z 平面稳定）3 分#

思路
  • 一空考查离散系统稳定的充要条件，即闭环特征根在 z 平面上的分布区域。
离散系统稳定性分析 离散控制系统
本卷考法
  • 指出离散系统稳定时特征根在 z 平面的分布
本卷实例
  • 关键一步：离散系统稳定要求特征根全在 z 平面单位圆内
  • 中间结果：单位圆内对应连续域左半平面的稳定域
  • 卡点：把稳定域误写成单位圆外
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过指出离散系统稳定时特征根在 z 平面的分布
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

3三、微分方程组建模与结构图化简#

思路
  • 对各微分方程取拉氏变换画出子结构图，逐层消去中间变量求闭环传函；再按给定输入用终值定理求稳态误差并反解参数范围。
传递函数的定义与基本性质 传递函数
本卷考法
  • 由微分方程组取拉氏变换写出各环节传函
本卷实例
  • 关键一步：零初始条件下逐式取拉氏变换
  • 关键一步：把每式整理成环节比值形式
  • 中间结果：各子环节串联后得到开环传函
  • 卡点：漏掉交叉反馈支路的负号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由微分方程组取拉氏变换写出各环节传函
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 逐层化简含局部反馈的结构图求闭环传函
本卷实例
  • 关键一步：从最内环开始把反馈环等效为单个环节
  • 中间结果：化简后得到输出对输入的单一闭环形式
  • 卡点：内环化简时把外环信号当作常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过逐层化简含局部反馈的结构图求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由终值定理求给定输入下的稳态误差表达式
本卷实例
  • 关键一步：先判稳再写误差传函
  • 关键一步：对组合输入分别取低频极限
  • 中间结果：稳态误差化为含待求参数的有理式
  • 卡点：组合输入时漏掉常数项分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由终值定理求给定输入下的稳态误差表达式
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
