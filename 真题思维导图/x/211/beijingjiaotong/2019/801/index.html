北京交通大学 801 控制原理 2019 年真题思维导图

难度：中等　六大题：七道填空、含反馈通道的参数整定、根轨迹与稳态误差、由校正前后幅频反求校正装置、含可更换环节的频率与稳态误差分析、零阶保持采样系统稳态误差；根轨迹与频域为主，多题附原卷插图。

1一、填空题（1 至 7）21 分#

思路
  • 七道填空逐题独立：传递函数是否随输入形式与大小改变；一阶系统 2% 误差带调节时间；斜坡输入下稳态无差所需最低型别；串联超前校正最大超前角极限；采样周期增大对稳定范围的影响；离散系统稳定充要条件；零阶保持器传函。
传递函数的定义与基本性质 传递函数
本卷考法
  • 判断传递函数是否随输入量的形式与大小改变
本卷实例
  • 关键一步：传递函数在零初始条件下由系统结构与参数定义
  • 中间结果：与输入量的形式和大小都无关
  • 卡点：漏掉零初始条件这一前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过判断传递函数是否随输入量的形式与大小改变
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由一阶传递函数与误差带求调节时间
本卷实例
  • 关键一步：把传递函数化成时间常数形式读出时间常数
  • 中间结果：2% 误差带调节时间取四倍时间常数
  • 卡点：与 5% 误差带的三倍时间常数系数混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由一阶传递函数与误差带求调节时间
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

系统型别与静态误差系数 稳态误差
本卷考法
  • 由稳态误差为有限值判断系统所需最低型别
本卷实例
  • 关键一步：斜坡输入误差有限说明速度误差系数非零有限
  • 中间结果：满足条件的最低型别为 II 型
  • 卡点：把误差有限误当成误差为零而不区分型别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由稳态误差为有限值判断系统所需最低型别
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
超前校正 系统校正
本卷考法
  • 求串联超前校正可提供的最大超前角极限
本卷实例
  • 关键一步：写出超前网络相角表达式并对频率求极值
  • 中间结果：最大超前角由分度系数唯一决定
  • 卡点：极值点频率公式记错导致极限值算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过求串联超前校正可提供的最大超前角极限
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

离散系统稳定性分析 离散控制系统
本卷考法
  • 判断采样周期增大对开环增益稳定范围的影响
本卷实例
  • 关键一步：定性比较采样周期变化对相角裕度与允许增益的影响
  • 中间结果：采样周期增大使稳定范围缩小
  • 卡点：把采样周期越小越好一概而论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过判断采样周期增大对开环增益稳定范围的影响
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒
公式
采样过程与香农采样定理 离散控制系统
本卷考法
  • 写零阶保持器的传递函数
本卷实例
  • 关键一步：零阶保持器把采样值保持一个采样周期分别求变换
  • 中间结果：结果为含时延因子的一阶分式
  • 卡点：把零阶保持器与一阶保持器混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过写零阶保持器的传递函数
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

2二、由超调与调节时间要求确定 K1#

思路
  • 结构图含反馈通道 H(s)。第1问 H 为零时化闭环二阶标准型，由超调与调节时间约束得阻尼比与实部下限，检验没有可达的 K1；第2问引入微分反馈后重新对比标准型求满足要求的参数。题面含图未读图。
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由两项时域指标反求前向与反馈参数
本卷实例
  • 关键一步：把闭环传函化二阶标准型读出阻尼比与实部
  • 关键一步：把指标要求折算为阻尼比和实部下限
  • 中间结果：两约束联立后判断是否存在满足的参数
  • 卡点：只满足单项指标就下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由两项时域指标反求前向与反馈参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调要求确定阻尼比下限
本卷实例
  • 关键一步：给定超调量反解阻尼比
  • 中间结果：超调越小所需阻尼比越大
  • 卡点：误差带系数用错导致调节时间约束方向反了
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调要求确定阻尼比下限
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 化简反馈通道含微分环节的闭环结构图
本卷实例
  • 关键一步：按反馈等效公式写闭环分母为一加开环传函
  • 中间结果：反馈通道的微分项进入闭环一次项系数
  • 卡点：反馈极性或分母符号写错；结构接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过化简反馈通道含微分环节的闭环结构图
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

3三、根轨迹、稳态误差与另一极点#

思路
  • 开环为 K 除三阶多项式。第1问按一百八十度根轨迹法则画 K 从零到无穷的根轨迹；第2问由 I 型速度误差系数求稳态误差上限对应的 K 下界再与稳定域取交；第3问把已知闭环极点代入特征方程定 K 后长除求另两极点。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则画无零点三阶系统根轨迹
本卷实例
  • 关键一步：定分支数、实轴段、渐近线交点与夹角
  • 关键一步：再求分离点与虚轴交点补全
  • 中间结果：三条渐近线在实轴上交于极点和的三分之一
  • 卡点：实轴段判据中零极点个数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则画无零点三阶系统根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 由分离点方程求分离点坐标
本卷实例
  • 关键一步：对相邻极点列相角互补方程求解
  • 中间结果：求得两个根后按落在实轴段上筛选
  • 卡点：求出根后不筛选就全部采用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由分离点方程求分离点坐标
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由劳斯表首列为零求虚轴交点与临界增益
本卷实例
  • 关键一步：列特征式劳斯表，令首列某元素为零
  • 中间结果：临界增益与交点频率由辅助方程联立得到
  • 卡点：只取一组解而漏掉另一组
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由劳斯表首列为零求虚轴交点与临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
