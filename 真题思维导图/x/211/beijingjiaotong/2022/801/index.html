北京交通大学 801 控制原理 2022 年真题思维导图

211 院校共 6 题

难度：中等偏难　第一题 10 道选择覆盖根轨迹判据、校正网络、误差改善与离散稳定性；第二题梅森公式求传函；第三题由幅频曲线反求模型、奈氏图与滞后校正比较；第四题含附加零点根轨迹、主导极点与性能指标；第五题为采样系统稳定域与输出序列；第六题奈氏图、劳斯判据与双输入稳态输出，综合性强且多题附原卷插图。

1一、选择题（1 至 10）30 分#

思路
  • 十道选择逐题独立：正反馈实轴段判据、PI 传递函数、超前校正参数范围、相角条件充要性、减小稳态误差的措施、劳斯判据判正实部根、附加零点对根轨迹影响、极坐标与对数坐标对应、采样周期与增益对稳定性影响。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 由正反馈系统实轴上存在根轨迹的条件选择答案
本卷实例
  • 关键一步：正反馈对应零度根轨迹，实轴段右侧零极点个数之和取偶数
  • 中间结果：零度根轨迹的相角条件是总相角为零度的整数倍
  • 卡点：仍按一百八十度根轨迹取奇数，把正反馈与负反馈判据混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过由正反馈系统实轴上存在根轨迹的条件选择答案
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
PID 控制器与参数整定 系统校正
本卷考法
  • 指出 PI 的含义并写出其传递函数
本卷实例
  • 关键一步：PI 指比例积分环节，输出由比例项与积分项相加
  • 中间结果：传递函数为比例增益乘上一加积分时间常数的倒数
  • 卡点：把 PI 与 PD 的环节名称和传递函数形式混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过指出 PI 的含义并写出其传递函数
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式
超前校正 系统校正
本卷考法
  • 由超前校正网络的相角特性确定参数的取值范围
本卷实例
  • 关键一步：超前校正网络的相角为正，零点比极点更靠近原点
  • 中间结果：分度系数落在零到一之间时相角才为正
  • 卡点：把超前与滞后的分度系数范围记反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过由超前校正网络的相角特性确定参数的取值范围
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 判断满足相角条件的点是否落在根轨迹上
本卷实例
  • 关键一步：根轨迹同时要求相角条件与幅值条件成立
  • 关键一步：相角条件用于确定轨迹形状，是必要条件之一
  • 中间结果：满足相角条件的点还需幅值条件定出对应参数
  • 卡点：把相角条件当成充要条件，忽略幅值条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过判断满足相角条件的点是否落在根轨迹上
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 辨别哪些环节不能减小稳态误差或不能改善稳态精度
本卷实例
  • 关键一步：积分环节、复合校正与增大开环增益均可减小稳态误差
  • 关键一步：微分控制只改善动态性能，不减小稳态误差
  • 中间结果：改善稳态精度的措施集中在提高型别与低频增益
  • 卡点：把改善动态性能的微分环节也当成减小误差的措施
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过辨别哪些环节不能减小稳态误差或不能改善稳态精度
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式
劳斯判据 稳定性分析
本卷考法
  • 由劳斯判据判断闭环特征方程正实部根的个数
本卷实例
  • 关键一步：列劳斯表后数第一列符号改变的次数
  • 中间结果：第一列符号改变次数即右半平面特征根个数
  • 卡点：缺项未补零；或把符号改变的次数与系统阶数混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由劳斯判据判断闭环特征方程正实部根的个数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 说明增加开环零点对根轨迹弯曲方向与稳定性的影响
本卷实例
  • 关键一步：附加开环零点使根轨迹向虚轴左侧方向弯曲
  • 关键一步：分支左移使稳定性改善
  • 中间结果：零点越靠近虚轴，对根轨迹的吸引与左移作用越明显
  • 卡点：把附加零点的作用与附加极点说反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过说明增加开环零点对根轨迹弯曲方向与稳定性的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
典型环节的对数频率特性 频域分析
本卷考法
  • 判断极坐标图与对数坐标图的对应关系是否正确
本卷实例
  • 关键一步：单位圆对应零分贝线，负实轴对应负一百八十度线
  • 关键一步：单位圆内对应负分贝
  • 中间结果：虚轴不对应对数坐标的零度线，该说法不正确
  • 卡点：把虚轴与单位圆对应的坐标线张冠李戴
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例环节是水平线，积分与微分分别是 -20 与 +20 dB/dec 的斜线
  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec
  • 一阶微分环节与惯性环节幅频互为镜像
  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤
  • 把传递函数分解为典型环节乘积
  • 逐环节画出对数幅频渐近线与相频曲线
  • 代数相加得到总特性
通用考法
  • 本卷考过判断极坐标图与对数坐标图的对应关系是否正确
  • 画出某一典型环节的 Bode 图
  • 由 Bode 图识别环节类型
  • 说明转角频率处的幅值与相角
常见易错
  • 把惯性环节高频渐近线的 -20 写成 -40
  • 振荡环节谐振峰位置误当作 ωn
公式
离散系统稳定性分析 离散控制系统
本卷考法
  • 判断采样周期与开环增益同时变化时系统的稳定性
本卷实例
  • 关键一步：开环增益超过临界值时系统不稳定
  • 关键一步：采样周期增大使临界增益下降
  • 中间结果：增益增大与周期增大都使系统趋于不稳定
  • 卡点：把两者对稳定性的影响方向说反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过判断采样周期与开环增益同时变化时系统的稳定性
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

2二、结构框图用梅森公式求传函#

思路
  • 结构框图含交叉回路。先数出全部单独回路并找出互不接触回路，写特征式，再找前向通路与余子式，用梅森公式求 C1(s)/R1(s)。题面含图未读图。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构框图用梅森公式求闭环传递函数
本卷实例
  • 关键一步：先列出全部单独回路，再判断有无互不接触回路
  • 关键一步：三条回路中有一对互不接触，特征式要加该对乘积项
  • 中间结果：特征式为 1 减全部回路增益之和再加互不接触回路乘积
  • 卡点：题面含图未读图，回路条数与支路接法需回原卷核对图；或漏掉互不接触项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构框图用梅森公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 化简含多条交叉回路的方框图
本卷实例
  • 关键一步：辨清比较点与引出点的交错关系，判断回路是否接触
  • 关键一步：交叉回路直接套梅森公式比逐层移动更稳
  • 中间结果：一对回路无公共节点，其乘积项进入特征式
  • 卡点：把互不接触回路找漏或重复；结构拓扑需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过化简含多条交叉回路的方框图
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

3三、由幅频曲线求模型并比较校正影响#

本卷考法

思路

奈奎斯特判据 稳定性分析
本卷考法
  • 由开环频率特性粗略画奈氏图并求坐标轴交点距离
本卷实例
  • 关键一步：把对象分解为实部虚部求与实轴虚轴的交点
  • 关键一步：按频率从零到无穷的走向勾画曲线

  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负

  • 由 Z=N+P 判断闭环稳定性
