1一、结构图化简求双输入传函15 分#

思路
  • 结构图含交叉比较点与 R、N 两个输入。第1问令 N 为零，比较点前移化简求 C(s)/R(s)；第2问令 R 为零求 C(s)/N(s)。题面含图未读图。
比较点与引出点的移动 结构图与方框图
本卷考法
  • 比较点前移化简含交叉比较点的结构图
本卷实例
  • 关键一步：把第二个比较点前移消去交叉支路再按串联合并
  • 关键一步：求扰动传函时把参考输入置零
  • 中间结果：化简后闭环分母为两回路增益之和再加一
  • 卡点：比较点移动时乘除关系易反；支路接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过比较点前移化简含交叉比较点的结构图
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求参考输入与扰动作用下的输出传函
本卷实例
  • 关键一步：用叠加原理把两输入分别置零后各自求解
  • 中间结果：两个传函共用同一闭环特征式作分母
  • 卡点：未把另一输入置零就叠加；回路拓扑需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求参考输入与扰动作用下的输出传函
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

2二、按稳态误差与主导极点指标定参数20 分#

思路
  • 结构图含速度反馈。先求开环传函判 I 型，由斜坡稳态误差为幅值 30% 得两参数关系；再化闭环二阶标准型，用阻尼比 0.707 与 5% 调节时间约束联立求解。题面含图未读图。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由斜坡输入下稳态误差的给定比例反求参数关系
本卷实例
  • 关键一步：I 型速度误差系数取 s 趋于零时的 sG(s)
  • 关键一步：稳态误差等于斜坡幅值除以速度误差系数
  • 中间结果：误差条件化为 2 加 K1K2 与 K1 的比值关系
  • 卡点：把误差写成绝对值或漏乘输入幅值；反馈接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由斜坡输入下稳态误差的给定比例反求参数关系
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量与调节时间双指标反求开环参数
本卷实例
  • 关键一步：把闭环传函化为二阶标准形式读出阻尼比与自然频率
  • 关键一步：把两指标折算成阻尼比与实部约束
  • 中间结果：两指标给出关于两参数的不等式组
  • 卡点：只满足单项指标；或误用 2% 误差带的调节时间系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量与调节时间双指标反求开环参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比判断欠阻尼二阶系统超调是否达标
本卷实例
  • 关键一步：超调量只由阻尼比决定，按欠阻尼公式代入
  • 中间结果：阻尼比不小于给定值时超调满足要求
  • 卡点：把调节时间与超调混用同一误差带系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比判断欠阻尼二阶系统超调是否达标
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3三、由阶跃响应反求二阶传函参数20 分#

思路
  • 开环为两惯性环节串联的单位负反馈系统。由阶跃响应稳态终值定闭环增益求 K；由超调量定阻尼比、峰值时间定自然频率，联立解出两时间常数。题面含图未读图。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应曲线反求开环传递函数与参数
本卷实例
  • 关键一步：阶跃响应稳态值等于闭环增益 K 除以一加 K
  • 关键一步：峰值时间与超调量分别定自然频率与阻尼比
  • 中间结果：闭环增益先定 K，再由两动态指标反解时间常数
  • 卡点：输入幅值不为一时未折算稳态值；曲线读数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应曲线反求开环传递函数与参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由二阶特征式系数与自然频率阻尼比的对应关系求解

广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 开环含右半平面零点时改画零度根轨迹
本卷实例
  • 关键一步：把开环整理成标准形式后判断相角条件用零度而非一百八十度
  • 中间结果：实轴段按右侧开环零极点个数为偶数判定
  • 卡点：仍按一百八十度相角条件判实轴段
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过开环含右半平面零点时改画零度根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

分离点与会合点 根轨迹法
本卷考法
  • 由相角条件列分离点方程并筛选有效解
本卷实例
  • 关键一步：对分离点处相邻极点零点列相角互补方程
  • 中间结果：求得两个根后只保留落在根轨迹上者
  • 卡点：两个根不筛选全收；分离点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由相角条件列分离点方程并筛选有效解
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由虚轴交点求临界增益与稳定范围
本卷实例
  • 关键一步：令特征方程实部虚部分别为零联立求交点频率与增益
  • 中间结果：交点增益给出稳定区间的端点
  • 卡点：只取一个交点漏掉另一组；稳定域方向判反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
