一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由一阶传递函数的时间常数求调节时间
本卷实例
  • 关键一步：先把一阶环节化成时间常数形式读出 T，再按 2% 误差带取四倍 T
  • 关键一步：输入幅值只改稳态值，不影响调节时间
  • 中间结果：一阶系统响应单调无振荡，调节时间只由时间常数决定
  • 卡点：误按 5% 误差带取三倍时间常数，与其他小题的误差带混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由一阶传递函数的时间常数求调节时间
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环极点位置或开环参数写出阻尼比与自然频率
本卷实例
  • 关键一步：由一对共轭极点的实部与虚部分别读出阻尼比乘自然频率、自然频率
  • 关键一步：第 3 题增益变化时先看阻尼比与自然频率各自如何随增益改变
  • 中间结果：极点实部绝对值等于阻尼比乘自然频率，虚部含自然频率与阻尼比
  • 卡点：把极点实部直接当成自然频率；或忘记最高次项系数要先归一化
  • 卡点：题 2 的共轭极点由原卷插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环极点位置或开环参数写出阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率计算或比较调节时间、峰值时间与超调量
本卷实例
  • 关键一步：超调量只由阻尼比决定，峰值时间与调节时间还要用到自然频率
  • 关键一步：比较增益影响时抓住阻尼比乘自然频率这个乘积是否变化
  • 中间结果：调节时间近似反比于阻尼比乘自然频率，峰值时间近似反比于自然频率
  • 卡点：两种误差带的调节时间系数混用；或把超调量随阻尼比的变化方向说反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率计算或比较调节时间、峰值时间与超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

劳斯判据 稳定性分析
本卷考法
  • 列劳斯表求使三阶系统稳定的增益范围
本卷实例
  • 关键一步：写出闭环特征方程后按降幂排列表，缺项补零
  • 关键一步：首列全部同号给出增益范围，边界值使首列出现零
  • 中间结果：本题特征方程为三阶，首列第三行含增益，令其大于零即得上界
  • 卡点：只写首列同号而不说明边界处首列为零；或系数缺项未补零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过列劳斯表求使三阶系统稳定的增益范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

根轨迹的绘制法则 根轨迹法
本卷考法
  • 用实轴段判据判断某段实轴是否属于根轨迹
本卷实例
  • 关键一步：看某点右侧实轴上开环实数零极点总个数是否为奇数
  • 关键一步：复数零极点不参与实轴段计数，只有实数零极点计入
  • 中间结果：奇偶性由右侧实数零极点个数决定，与左侧无关
  • 卡点：把重极点只算一次；或把复数零极点也计入右侧个数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过用实轴段判据判断某段实轴是否属于根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 说明根轨迹相角条件与幅值条件各自的作用和充要性
本卷实例
  • 关键一步：相角条件画出轨迹形状，幅值条件给出该点对应的参数值
  • 关键一步：同时满足两个条件的点才落在根轨迹上
  • 中间结果：只满足相角条件的点不能确定参数，需再用幅值条件定值
  • 卡点：把相角条件的判定与幅值条件混用；或把常规根轨迹的相角条件写成零度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过说明根轨迹相角条件与幅值条件各自的作用和充要性
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

频率特性的物理意义与求法 频域分析
本卷考法
  • 求一阶系统在正弦输入下的稳态输出表达式
本卷实例
  • 关键一步：稳态输出与输入同频，幅值乘幅频值、相位加相频值
  • 关键一步：把工作频率代入传递函数求模与相角，再乘输入幅值
  • 中间结果：一阶环节的相角为负的反正切，输出相位滞后于输入
  • 卡点：忘记输出幅值要乘输入幅值；或把相频的符号写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求一阶系统在正弦输入下的稳态输出表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

典型环节的对数频率特性 频域分析
本卷考法
  • 说明理想积分环节与不稳定一阶环节的对数频率特性
本卷实例
  • 关键一步：积分环节的对数幅频是一条斜率为负二十的直线
  • 关键一步：不稳定一阶环节的相频随频率从负一百八十度升到负九十度
  • 中间结果：积分环节在双对数坐标下幅频为直线，相频恒为负九十度
  • 卡点：把理想积分环节的幅频当成折线；或不稳定一阶环节的相频起止方向写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤

  • 代数相加得到总特性
通用考法
  • 本卷考过说明理想积分环节与不稳定一阶环节的对数频率特性
  • 画出某一典型环节的 Bode 图
  • 由 Bode 图识别环节类型
  • 说明转角频率处的幅值与相角
常见易错
  • 把惯性环节高频渐近线的 -20 写成 -40
  • 振荡环节谐振峰位置误当作 ωn

稳定裕度 频域分析
本卷考法
  • 由转折频率与相频判断相角裕度的正负
本卷实例
  • 关键一步：先分解出各典型环节，按转折频率确定低频段与各段斜率
  • 关键一步：相角裕度取正还是负，看相频在幅值穿越频率处是否高于负一百八十度
  • 中间结果：一阶微分环节的相角为正，惯性环节为负，二者叠加决定相频走势
  • 卡点：把转折频率的个数或位置数错；或相角裕度正负与稳定性的对应关系弄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由转折频率与相频判断相角裕度的正负
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图用梅森公式求总传输
本卷实例
  • 关键一步：先数出全部单独回路，写出特征式；两条回路有公共节点，只保留一次项

要点

  • 本卷考过由结构图用梅森公式求总传输
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

多输入与扰动作用下的传递函数 结构图与方框图
本卷考法

  • 由对数幅频渐近线读出型别、增益与转折频率
本卷实例
  • 关键一步：低频段延长线过零分贝处的频率与增益的关系给出开环增益
  • 关键一步：两个转折频率都对应惯性环节，斜率各减二十
  • 中间结果：低频段延长线在指定频率处的高度可直接换算开环增益
  • 卡点：低频段延长线与零分贝交点需回原卷核对图；或把转折频率当成交点频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频渐近线读出型别、增益与转折频率
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

稳定裕度 频域分析
本卷考法
  • 用抓大放小近似求开环截止频率与相角裕度
本卷实例
  • 关键一步：由幅值等于一列方程，在截止频率所在频段保留起主导作用的环节
  • 关键一步：把截止频率代入相频并加一百八十度得到相角裕度，同时判其正负
  • 中间结果：近似求得的截止频率略偏大，实际相角裕度与近似值相差很小
  • 卡点：截止频率所在频段判断错误导致保留环节选错；或相角裕度正负与稳定性关系弄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过用抓大放小近似求开环截止频率与相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

奈奎斯特判据 稳定性分析
本卷考法
  • 用频率法判断最小相位系统闭环稳定性
本卷实例
  • 关键一步：最小相位系统开环无右半平面极点，相角裕度与幅值裕度同号即可判稳
  • 关键一步：分别由幅值穿越频率与相位穿越频率求两个裕度并比较符号
  • 中间结果：若相角裕度为零且幅值裕度为无穷，则曲线穿过临界点，属临界稳定
  • 卡点：把幅值裕度取倒数后的符号弄反；或忽略近似计算带来的误差未说明实际趋势
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用频率法判断最小相位系统闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
