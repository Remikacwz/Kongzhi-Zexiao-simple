大连海事大学 805 自动控制理论（含现控） 2020 年真题思维导图

一一、填空题#

思路
  • 十个小空考反馈本质、状态空间、对偶、系统型别、离散极点与频率特性。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 填写反馈控制的本质
本卷实例
  • 关键一步：从按偏差进行控制这一核心作答
  • 中间结果：反馈控制的本质是用偏差消除偏差
  • 卡点：把开环控制的作用答成反馈本质
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过填写反馈控制的本质
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
状态空间表达式的建立 状态空间分析
本卷考法
  • 填写状态空间表达式的两个组成方程
本卷实例
  • 关键一步：从状态方程与输出方程作答
  • 中间结果：状态方程与输出方程共同构成状态空间描述
  • 卡点：把两个方程写成一个
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过填写状态空间表达式的两个组成方程
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式
能控性与能观性 状态空间分析
本卷考法
  • 填写对偶系统的传递函数矩阵（借位）
本卷实例
  • 关键一步：对偶系统把原传递函数矩阵取转置
  • 中间结果：对偶系统的传函矩阵等于原矩阵的转置
  • 卡点：漏取转置写成原矩阵本身
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过填写对偶系统的传递函数矩阵（借位）
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 填写I型系统的定义
本卷实例
  • 关键一步：按开环传函中纯积分环节的个数判别
  • 中间结果：开环传函含一个纯积分环节即为I型系统
  • 卡点：把积分环节个数与型别编号错位
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过填写I型系统的定义
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 填写非奇异变换下保持不变的系统特征
本卷实例
  • 关键一步：从特征值、传函矩阵与能控能观作答
  • 中间结果：非奇异变换不改变特征值与传函矩阵
  • 卡点：以为变换会改变传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过填写非奇异变换下保持不变的系统特征
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消
公式
相平面法 非线性系统
本卷考法
  • 填写特征根分布对应的奇点类型
本卷实例
  • 关键一步：按实部正负与是否共轭分类
  • 中间结果：一正一负实根为鞍点，负实部共轭复根为稳定焦点
  • 卡点：把稳定焦点与鞍点写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过填写特征根分布对应的奇点类型
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆
公式
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 填写根轨迹起点、终点与无穷远条数
本卷实例
  • 关键一步：按幅值条件与相角条件判断根走向
  • 中间结果：起于开环极点，止于开环零点或无穷远
  • 卡点：把起点与终点写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过填写根轨迹起点、终点与无穷远条数
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
离散系统的动态性能与极点分布 离散控制系统
本卷考法
  • 按离散系统闭环极点位置填写脉冲序列形式
本卷实例
  • 关键一步：按极点在单位圆内、圆外、圆上分别判断
  • 中间结果：圆外发散，圆上等幅振荡，越靠近原点收敛越快
  • 卡点：把极点模的大小与收敛快慢关系写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点在 z 平面上的位置决定响应形式
  • 极点越靠近原点衰减越快，越靠近单位圆振荡越强
  • 极点的幅角决定振荡频率，幅值决定衰减速度
  • 采样周期增大会使动态性能变差甚至不稳定
步骤
  • 求闭环脉冲传递函数的极点
  • 按极点在单位圆内的位置判断响应形式
  • 由极点的模与幅角估算衰减与振荡频率
  • 与连续系统指标对应关系相互校验
通用考法
  • 本卷考过按离散系统闭环极点位置填写脉冲序列形式
  • 由闭环极点分布判断动态性能
  • 与连续域指标互相换算
  • 说明采样周期对动态性能的影响
常见易错
  • 把 z 平面极点当作 s 平面极点直接读阻尼比
  • 忽略单位圆上极点对应等幅振荡
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由最小相位系统的相频函数反写开环传函
本卷实例
  • 关键一步：把相频分解为典型环节相角之和
  • 中间结果：每一项相角对应一个一阶环节或积分环节
  • 卡点：把微分环节与惯性环节位置写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由最小相位系统的相频函数反写开环传函
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式

二二、选择题#

思路
  • 五道单选覆盖对数频率特性、离散稳定、描述函数、随动系统与实轴根轨迹。
典型环节的对数频率特性 频域分析
本卷考法
  • 由开环传函判断对数幅频在转折频率处的斜率变化
本卷实例
  • 关键一步：先列转折频率再逐段累加斜率
  • 中间结果：该频率处斜率按一阶微分环节方向抬升
  • 卡点：把斜率变化量当替换而非累加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例环节是水平线，积分与微分分别是 -20 与 +20 dB/dec 的斜线
  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec
  • 一阶微分环节与惯性环节幅频互为镜像
  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤
  • 把传递函数分解为典型环节乘积
  • 逐环节画出对数幅频渐近线与相频曲线
  • 代数相加得到总特性
通用考法
  • 本卷考过由开环传函判断对数幅频在转折频率处的斜率变化
  • 画出某一典型环节的 Bode 图
  • 由 Bode 图识别环节类型
  • 说明转角频率处的幅值与相角
常见易错
  • 把惯性环节高频渐近线的 -20 写成 -40
  • 振荡环节谐振峰位置误当作 ωn
公式
离散系统稳定性分析 离散控制系统
本卷考法
  • 由离散闭环特征根判断系统稳定性
本卷实例
  • 关键一步：分别求各特征根的模并与1比较
  • 中间结果：所有根模均小于1则系统稳定
  • 卡点：把稳定条件写成实部小于0
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过由离散闭环特征根判断系统稳定性
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒
公式
描述函数法基础 非线性系统
本卷考法
  • 由描述函数法选择使稳态性能最佳的惯性环节
本卷实例
  • 关键一步：比较各线性部分在交点处的幅值大小
  • 中间结果：交点处幅值越小则自振振幅越小、精度越高
  • 卡点：按增益大小而非交点位置选择
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
