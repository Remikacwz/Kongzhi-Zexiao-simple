大连海事大学 805 自动控制理论（含现控） 2017 年真题思维导图

思路
  • 十四个小空分别考基本概念、根轨迹、频率特性、非线性、离散与状态空间。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 填写自动控制系统三个基本要求
本卷实例
  • 关键一步：从稳定性、准确性、快速性三方面作答
  • 中间结果：三项要求分别对应稳定、精度与响应速度
  • 卡点：把快速性与准确性两项要求写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过填写自动控制系统三个基本要求
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 填写根轨迹的起点、终点与趋于无穷远的条数
本卷实例
  • 关键一步：由幅值条件与相角条件判断根的走向
  • 中间结果：起点为开环极点，终点为开环零点或无穷远
  • 卡点：把起点与终点写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过填写根轨迹的起点、终点与趋于无穷远的条数
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

频率特性的物理意义与求法 频域分析
本卷考法
  • 由开环传函与正弦输入求输出稳态分量的幅值
本卷实例
  • 关键一步：稳态幅值等于输入幅值乘幅频特性在该频率处的取值
  • 中间结果：闭环幅频特性由开环传函按单位负反馈写出
  • 卡点：忘记乘输入幅值或把频率代错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由开环传函与正弦输入求输出稳态分量的幅值
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 判断含右半平面零点的负反馈系统对应哪种根轨迹
本卷实例
  • 关键一步：由开环传函分子常数项符号判断相角条件
  • 中间结果：分子含正号常数项时相角条件取 360 度整数倍
  • 卡点：零度根轨迹仍沿用 180 度相角条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过判断含右半平面零点的负反馈系统对应哪种根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
稳定裕度 频域分析
本卷考法
  • 求给定开环传函的幅值裕度
本卷实例
  • 关键一步：先求相位穿越频率再取幅频特性的倒数
  • 中间结果：幅值裕度等于幅频特性在相位穿越频率处的倒数
  • 卡点：漏判相位穿越频率不存在时幅值裕度为无穷
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求给定开环传函的幅值裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
最小相位系统与非最小相位系统 频域分析
本卷考法
  • 填写最小相位系统的定义
本卷实例
  • 关键一步：从开环零点与极点的半平面位置判断
  • 中间结果：最小相位要求零极点全部位于左半平面
  • 卡点：把右半平面极点与右半平面零点混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过填写最小相位系统的定义
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈
相平面法 非线性系统
本卷考法
  • 由特征根分布填写相平面奇点类型
本卷实例
  • 关键一步：按特征根实部正负与是否共轭判断奇点
  • 中间结果：一正一负实根对应鞍点，正实部共轭复根对应不稳定焦点
  • 卡点：把实部符号与焦点或结点类型对应反了
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过由特征根分布填写相平面奇点类型
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

离散系统的动态性能与极点分布 离散控制系统
本卷考法
  • 按闭环实数极点位置填写离散系统脉冲序列形式
本卷实例
  • 关键一步：按极点在单位圆内、圆外、圆上分别判断响应形式
  • 中间结果：单位圆外对应发散，单位圆上对应等幅振荡
  • 卡点：把单位圆内与单位圆外对应的响应形式写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点在 z 平面上的位置决定响应形式
  • 极点越靠近原点衰减越快，越靠近单位圆振荡越强
  • 极点的幅角决定振荡频率，幅值决定衰减速度
  • 采样周期增大会使动态性能变差甚至不稳定
步骤
  • 求闭环脉冲传递函数的极点
  • 按极点在单位圆内的位置判断响应形式
  • 由极点的模与幅角估算衰减与振荡频率
  • 与连续系统指标对应关系相互校验
通用考法
  • 本卷考过按闭环实数极点位置填写离散系统脉冲序列形式
  • 由闭环极点分布判断动态性能
  • 与连续域指标互相换算
  • 说明采样周期对动态性能的影响
常见易错
  • 把 z 平面极点当作 s 平面极点直接读阻尼比
  • 忽略单位圆上极点对应等幅振荡

采样过程与香农采样定理 离散控制系统
本卷考法
  • 填写零阶保持器的三大特性
本卷实例
  • 关键一步：从幅频低通与相频滞后两方面作答
  • 中间结果：零阶保持器具有低通、相位滞后与时间滞后三个特点
  • 卡点：把零阶保持器当成理想保持器而漏掉相位滞后
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过填写零阶保持器的三大特性
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

状态空间表达式的建立 状态空间分析

  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过填写状态空间表达式的两个组成方程
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

状态空间与传递函数的关系 状态空间分析
本卷考法
