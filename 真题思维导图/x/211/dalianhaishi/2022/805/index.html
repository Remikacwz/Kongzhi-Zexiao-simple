一一、填空题（10个空）#

思路
  • 逐空回忆二阶标准形式、奈奎斯特判据、频率特性、相平面与 s-z 映射的基本结论。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由开环传函求闭环系统的无阻尼振荡频率与阻尼比
本卷实例
  • 关键一步：先按单位负反馈写出闭环传函再与标准二阶形式比较
  • 中间结果：自然频率由常数项开方，阻尼比由一次项系数除以二倍自然频率
  • 卡点：逐年印开环增益 46，宝典与答案均为 16，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由开环传函求闭环系统的无阻尼振荡频率与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

奈奎斯特判据 稳定性分析
本卷考法
  • 叙述奈奎斯特判据并写出闭环稳定条件
本卷实例
  • 关键一步：先数清开环右半平面极点数 P
  • 中间结果：闭环稳定等价于包围圈数与 P 之和为零
  • 卡点：忘记先数 P，或把包围圈数的正负号定义搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过叙述奈奎斯特判据并写出闭环稳定条件
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

频率特性的物理意义与求法 频域分析
本卷考法
  • 由一阶传函与正弦输入求稳态分量幅值
本卷实例
  • 关键一步：幅值放大倍数等于幅频特性在输入频率处的取值
  • 中间结果：稳态幅值等于输入幅值乘该频率的幅频值
  • 卡点：忽略输入幅值或把输入频率当成了转折频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由一阶传函与正弦输入求稳态分量幅值
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由最小相位系统相频特性反写开环传递函数
本卷实例
  • 关键一步：按 -90° 与两个 arctan 项确定积分环节与两个一阶环节
  • 中间结果：分母含积分环节，分子分母各有一个一阶环节
  • 卡点：把分子与分母的两个一阶环节归属搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由最小相位系统相频特性反写开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

相平面法 非线性系统
本卷考法
  • 由特征根判断相平面奇点类型
本卷实例
  • 关键一步：异号实根对应鞍点，正实部共轭根对应不稳定焦点
  • 中间结果：实部符号决定稳定与否，虚部有无决定焦点或结点
  • 卡点：把鞍点与不稳定结点混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过由特征根判断相平面奇点类型
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

z 变换与 z 反变换 离散控制系统
本卷考法
  • 写出 s 平面右半平面与虚轴在 z 平面的对应
本卷实例
  • 关键一步：用 z 等于 e 的 Ts 次方这一映射关系
  • 中间结果：右半平面对应单位圆外，虚轴对应单位圆
  • 卡点：把单位圆内外对应关系搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • z 变换是离散信号的拉氏变换，令 z=e^{Ts} 得到
  • 常用函数的 z 变换要熟记
  • z 反变换可用部分分式法、幂级数法或留数法
  • 左半 s 平面映射到 z 平面单位圆内
步骤
  • 将连续传递函数展开为部分分式
  • 逐项查表做 z 变换
  • 需要时做 z 反变换求时间序列
通用考法
  • 本卷考过写出 s 平面右半平面与虚轴在 z 平面的对应
  • 求给定函数的 z 变换
  • 求 z 反变换得到采样序列
  • 说明 s 平面与 z 平面的映射关系
常见易错
  • 把 z 变换结果中的 e^{-aT} 写成 e^{-a}
  • 部分分式分解时漏项导致反变换出错

采样过程与香农采样定理 离散控制系统
本卷考法
  • 说出零阶保持器的三个特性
本卷实例
  • 关键一步：从低通滤波、时间滞后与相角滞后三方面作答
  • 中间结果：零阶保持器带来约半个采样周期的平均滞后
  • 卡点：只答出两条而漏掉相角滞后性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过说出零阶保持器的三个特性
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

传递函数的定义与基本性质 传递函数
本卷考法
  • 说出线性控制系统的两个主要特点
本卷实例
  • 关键一步：从线性系统定义出发，齐次性与叠加性合称线性
  • 中间结果：线性系统满足叠加原理
  • 卡点：与传递函数只由结构与参数决定的性质混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过说出线性控制系统的两个主要特点
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

能控性与能观性 状态空间分析
本卷考法
  • 对偶系统的传递矩阵与非奇异变换的不变性质（借位：库内无对偶专条）
本卷实例
  • 关键一步：对偶系统把 A 转置、B 与 C 互换，则传递矩阵取转置
  • 中间结果：非奇异变换只换状态坐标，不改变特征值、传函与能控能观性
  • 卡点：把对偶变换与相似变换的作用混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过对偶系统的传递矩阵与非奇异变换的不变性质（借位：库内无对偶专条）
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

二二、梅森增益公式求传递函数#

思路
  • 由信号流图找全部回路与所有互不接触回路组合，写出特征式与各前向通路余子式。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图用梅森增益公式求 C(s)/R(s)
本卷实例
  • 关键一步：先找全部回路并列出所有互不接触回路组合
  • 中间结果：特征式为 1-ΣL+ΣLL，结果为 ΣPΔ/Δ
  • 卡点：信号流图为原卷插图，回路与前向通路需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图用梅森增益公式求 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

三三、机电系统参数辨识#

思路
  • 列机械系统运动方程得传函，再由阶跃响应曲线的稳态值、超调量与峰值时间反求 m、k、μ。
机械系统建模 建模与机电系统
本卷考法
  • 由质量-弹簧-阻尼系统列方程并求位移对力的传函
本卷实例
  • 关键一步：按牛顿第二定律写入力减阻尼力减弹簧力等于质量乘加速度
  • 中间结果：传递函数分母为 m s² 加 μ s 加 k
  • 卡点：机电系统图为原卷插图，受力方向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过由质量-弹簧-阻尼系统列方程并求位移对力的传函
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由响应曲线的超调量与峰值时间求阻尼比与自然频率
本卷实例
  • 关键一步：超调量只由阻尼比决定，先定阻尼比再由峰值时间定自然频率
  • 中间结果：超调量与峰值时间分别给出阻尼比和自然频率的方程
  • 卡点：响应曲线为原卷插图，稳态值与峰值需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
