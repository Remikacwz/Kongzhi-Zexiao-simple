大连海事大学 805 自动控制理论（含现控） 2018 年真题思维导图

211 院校共 14 题

难度：中等　全卷14个大题：卷一9个填空、卷二5个选择，其余覆盖劳斯判据、根轨迹、奈氏判据、Bode图、离散系统、相平面、描述函数与状态空间。按中文大题号一~十四成题，多题配原卷插图；两源均未印分值。

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

一一、填空题#

思路
  • 九个小空分别考基本概念、根轨迹、频率特性、非线性、离散与状态空间。
相平面法 非线性系统
本卷考法
  • 填写特征根分布对应的相平面奇点类型
本卷实例
  • 关键一步：按特征根实部正负与是否为共轭复根分类
  • 中间结果：一正一负实根对应鞍点，正实部共轭复根为不稳定焦点
  • 卡点：把鞍点与不稳定焦点写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过填写特征根分布对应的相平面奇点类型
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆
公式
脉冲传递函数 离散控制系统
本卷考法
  • 填写采样系统的两种数学模型
本卷实例
  • 关键一步：从时域差分方程与复域脉冲传递函数两方面作答
  • 中间结果：差分方程与脉冲传递函数都是采样系统的模型
  • 卡点：只写差分方程而漏掉脉冲传递函数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过填写采样系统的两种数学模型
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)
公式
能控性与能观性 状态空间分析
本卷考法
  • 填写对偶系统的传递函数矩阵（借位）
本卷实例
  • 关键一步：对偶系统把原传递函数矩阵取转置
  • 中间结果：对偶系统的传函矩阵等于原矩阵的转置
  • 卡点：漏取转置写成原矩阵本身
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过填写对偶系统的传递函数矩阵（借位）
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 填写根轨迹起点、终点与无穷远条数
本卷实例
  • 关键一步：按幅值条件与相角条件判断根的走向
  • 中间结果：起于开环极点，止于开环零点或无穷远
  • 卡点：把起点与终点写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过填写根轨迹起点、终点与无穷远条数
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 判断含右半平面零点的负反馈系统根轨迹相角
本卷实例
  • 关键一步：由分子常数项符号判断相角条件
  • 中间结果：分子含正号常数项时用零度相角条件
  • 卡点：零度根轨迹仍套用180度相角条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过判断含右半平面零点的负反馈系统根轨迹相角
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由正弦输入与传函求输出稳态分量幅值
本卷实例
  • 关键一步：稳态幅值等于输入幅值乘幅频特性在该频率的值
  • 中间结果：把正弦频率代入闭环幅频特性再乘输入幅值
  • 卡点：漏乘输入幅值或把频率代错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由正弦输入与传函求输出稳态分量幅值
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 填写非奇异变换下保持不变的系统特征（借位）
本卷实例
  • 关键一步：从特征值与传递函数矩阵两方面作答
  • 中间结果：非奇异变换不改特征值与传函矩阵
  • 卡点：把非奇异变换当成会改变传函的一般变换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过填写非奇异变换下保持不变的系统特征（借位）
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消
公式
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 填写自动控制系统的基本要求
本卷实例
  • 关键一步：从稳定性、快速性与准确性三方面作答
  • 中间结果：三项基本要求分别对应稳定、响应速度与精度
  • 卡点：把快速性与准确性两项写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过填写自动控制系统的基本要求
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

二二、选择题#

思路
  • 五道单选覆盖对数频率特性、离散稳定、描述函数、随动系统与实轴根轨迹。
典型环节的对数频率特性 频域分析
本卷考法
  • 由开环传函判断转折频率处对数幅频斜率变化
本卷实例
  • 关键一步：先列各转折频率再逐段累加斜率
  • 中间结果：该频率处斜率按一阶微分环节方向抬升20
  • 卡点：把斜率变化量当替换而非累加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例环节是水平线，积分与微分分别是 -20 与 +20 dB/dec 的斜线
  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec
  • 一阶微分环节与惯性环节幅频互为镜像
  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤
  • 把传递函数分解为典型环节乘积
  • 逐环节画出对数幅频渐近线与相频曲线
  • 代数相加得到总特性
通用考法
  • 本卷考过由开环传函判断转折频率处对数幅频斜率变化
  • 画出某一典型环节的 Bode 图
  • 由 Bode 图识别环节类型
  • 说明转角频率处的幅值与相角
常见易错
  • 把惯性环节高频渐近线的 -20 写成 -40
  • 振荡环节谐振峰位置误当作 ωn

离散系统稳定性分析 离散控制系统
本卷考法
  • 由离散闭环特征根模值判断系统稳定性
本卷实例
  • 关键一步：分别求各特征根的模并与1比较
  • 中间结果：所有根模均小于1则系统稳定
  • 卡点：把z平面稳定条件写成实部小于0
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过由离散闭环特征根模值判断系统稳定性
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒
公式
描述函数法基础 非线性系统
本卷考法
  • 由描述函数法比较不同线性部分的准确度
本卷实例
  • 关键一步：比较线性部分低通滤波能力高低
  • 中间结果：惯性越大低通滤波越强，一次谐波假设越准
  • 卡点：按线性部分增益大小而非滤波能力选择
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过由描述函数法比较不同线性部分的准确度
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件
公式
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断给定系统是否属于随动系统
本卷实例
  • 关键一步：按被控量是否随输入变化来判别
  • 中间结果：随动系统的输出需跟随不断变化的给定量
