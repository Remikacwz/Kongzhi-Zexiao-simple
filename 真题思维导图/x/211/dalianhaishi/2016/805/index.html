11、两输入两输出结构图求传函#

思路
  • 分别令其余输入为零，用梅森公式求两条通道的传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由两输入两输出结构图求 Y1(s)/R1(s)
本卷实例
  • 关键一步：先找全部回路与互不接触组合，再列前向通路
  • 中间结果：两条传函共用同一特征式，各自分子取对应前向通路
  • 卡点：方框图连接为原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由两输入两输出结构图求 Y1(s)/R1(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 把两输入拆开分别置零后用叠加原理求各通道传函
本卷实例
  • 关键一步：每次只保留一个输入，其余输入置零
  • 中间结果：输出为两输入各自贡献的线性叠加
  • 卡点：求其中一个通道时未把另一输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过把两输入拆开分别置零后用叠加原理求各通道传函
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

22、劳斯判据求稳定 K 范围#

思路
  • 列闭环特征方程，用劳斯判据列首列不等式并取交集。
劳斯判据 稳定性分析
本卷考法
  • 对四阶特征方程列劳斯表判断稳定性
本卷实例
  • 关键一步：先补齐特征方程的缺项再列劳斯表
  • 中间结果：首列变号次数等于右半平面闭环极点数
  • 卡点：特征方程缺项时不补零就直接套用判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过对四阶特征方程列劳斯表判断稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由劳斯表首列全大于零求稳定 K 范围
本卷实例
  • 关键一步：逐行列出首列元素的不等式后取交集
  • 中间结果：稳定域为各不等式解集的公共区间
  • 卡点：只列部分首列元素的不等式
  • 卡点：取交集时端点是否包含搞错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由劳斯表首列全大于零求稳定 K 范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

33、由阶跃响应求二阶动态性能#

思路
  • 从响应表达式读出衰减系数与振荡频率，再换算阻尼比与自然频率。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由阶跃响应表达式求自然频率与阻尼比
本卷实例
  • 关键一步：把指数衰减系数与正弦频率对应到阻尼比和自然频率
  • 中间结果：衰减系数与振荡频率分别对应两个方程
  • 卡点：把衰减指数绝对值的两倍误当成阻尼比与自然频率乘积
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由阶跃响应表达式求自然频率与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求欠阻尼系统的超调量、峰值时间与调节时间
本卷实例
  • 关键一步：峰值时间由阻尼振荡角频率取 π 得到
  • 中间结果：超调量只由阻尼比决定，时间指标与自然频率成反比
  • 卡点：调节时间两种误差带系数混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求欠阻尼系统的超调量、峰值时间与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

44、二阶系统稳态输出与动态性能#

思路
  • 由一阶环节阶跃响应反求传函，再按闭环标准式求各指标。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由一阶环节单位阶跃响应反求其传递函数
本卷实例
  • 关键一步：阶跃响应求导得冲激响应，再作拉氏变换得环节传函
  • 中间结果：环节传函为增益比时间常数加一的一阶形式
  • 卡点：对阶跃响应求导时漏掉稳态分量对导数的影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由一阶环节单位阶跃响应反求其传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求给定输入下的系统稳态输出与稳态误差
本卷实例
  • 关键一步：用终值定理前先确认闭环系统稳定
  • 中间结果：稳态输出由闭环传函在零频处的值乘输入幅值得到

55、根轨迹与重根、纯虚根 K 值#

思路
  • 按根轨迹法则画图，再由分离点和虚轴交点求临界增益。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制含一个右半平面零点的系统根轨迹草图
本卷实例
  • 关键一步：先定零极点与实轴段，再求渐近线与分离点
  • 中间结果：极点数与零点数之差决定渐近线条数
  • 卡点：把零点位于右半平面误判为最小相位系统
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制含一个右半平面零点的系统根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 由分离点方程求使系统产生重根的 K 值
本卷实例
  • 关键一步：令特征方程对 s 的导数为零求分离点
  • 中间结果：分离点处特征方程有重根，对应一个临界增益
  • 卡点：求出方程的根后不筛选就全部采用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过由分离点方程求使系统产生重根的 K 值
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

  • 得到 K 后没有回到原题核对参数定义

66、奈奎斯特判据判断三系统稳定性#

思路
  • 数开环右半平面极点数与曲线对临界点的包围圈数。
奈奎斯特判据 稳定性分析
本卷考法

  • 未验证能控性就直接做极点配置
