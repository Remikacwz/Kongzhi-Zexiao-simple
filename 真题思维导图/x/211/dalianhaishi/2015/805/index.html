11、结构图求参考与扰动传递函数#

思路
  • 分别令干扰与参考输入为零，再各用梅森公式求一条通道的传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由多回路结构图用梅森增益公式求 C(s)/R(s)
本卷实例
  • 关键一步：先列全部回路并判互不接触组合，再列前向通路
  • 中间结果：特征式含三条回路与一对互不接触回路的乘积项
  • 卡点：方框图连接为原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由多回路结构图用梅森增益公式求 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

多输入与扰动作用下的传递函数 结构图与方框图
本卷考法

本卷实例

  • 中间结果：两条传函共用同一特征式，分子各取对应前向通道
  • 卡点：求扰动传函时容易忘记把参考输入置零

  • 求扰动的传递函数时令参考输入为零

步骤

  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法

  • 求扰动传函时没有把参考输入置零

22、二阶系统动态性能与稳态误差#

思路
  • 先由给定阶跃响应反求环节传函，再化闭环为标准二阶式求各指标。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由一阶环节的单位阶跃响应反求其传递函数
本卷实例
  • 关键一步：阶跃响应求导得到冲激响应，再作拉氏变换得环节传函
  • 中间结果：环节传函为增益比时间常数加一的一阶形式
  • 卡点：对阶跃响应求导时漏掉稳态分量对导数的影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由一阶环节的单位阶跃响应反求其传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由闭环传函求稳态输出、超调量与调节时间
本卷实例
  • 关键一步：把闭环分母配成标准二阶式读出自然频率与阻尼比
  • 中间结果：超调量只与阻尼比有关，调节时间与阻尼比和自然频率乘积成反比
  • 卡点：两种误差带的调节时间系数用混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由闭环传函求稳态输出、超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求给定输入作用下的系统稳态误差
本卷实例
  • 关键一步：用终值定理前先确认闭环系统稳定
  • 中间结果：误差传函由参考输入减去反馈量后与参考输入之比得到
  • 卡点：误差定义含反馈系数时漏乘该系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求给定输入作用下的系统稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

33、稳态误差为零的 Ki 设计#

思路
  • 写出误差传递函数，把斜坡输入的终值条件代入后令其为零。
误差定义与误差传递函数 稳态误差
本卷考法
  • 按误差定义为参考减输出写出误差传递函数
本卷实例
  • 关键一步：用闭环传函构造误差传函，误差取参考输入减输出
  • 中间结果：误差传函等于一减去闭环传函
  • 卡点：误差取参考减输出还是参考减反馈容易混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过按误差定义为参考减输出写出误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 由斜坡输入稳态误差为零反求前馈参数
本卷实例
  • 关键一步：把误差传函在 s 趋于零处的极限置零再解参数
  • 中间结果：待求参数由误差传函常数项为零这一条件确定
  • 卡点：未先判稳就直接使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过由斜坡输入稳态误差为零反求前馈参数
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

44、根轨迹绘制与稳定放大倍数范围#

思路
  • 按根轨迹法则画图，再由虚轴交点或劳斯判据定稳定范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制参数由零到无穷的 180 度根轨迹草图
本卷实例
  • 关键一步：先定开环零极点与实轴段，再求渐近线与分离点
  • 中间结果：极点数为三、零点数为零时有三条分支与三条渐近线
  • 卡点：实轴段取奇数的判据用错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制参数由零到无穷的 180 度根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
出射角与入射角 根轨迹法
本卷考法
  • 求复数开环极点的出射角
本卷实例
  • 关键一步：用相角条件列式累加相角，累加时不含该极点自身
  • 中间结果：一对共轭复数极点的出射角关于实轴对称
  • 卡点：累加相角时把该极点自身也计入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求复数开环极点的出射角
  • 求复数极点的出射角
  • 根据出射角画出根轨迹起始方向
  • 由入射角确定根轨迹终止方向
常见易错
  • 累加相角时把该极点自身的相角也算进去
  • 忘记判断象限导致角度差 180°

与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点并确定稳定放大倍数范围
本卷实例
  • 关键一步：把 s 等于 jω 代入特征方程，或令劳斯表首列元素为零
  • 中间结果：临界增益对应一对纯虚根，稳定区取两临界值之间
  • 卡点：只解出一组虚轴交点就下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点并确定稳定放大倍数范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

55、开环幅相曲线判稳#

思路
  • 数开环右半平面极点数与奈氏曲线对临界点的包围圈数。
奈奎斯特判据 稳定性分析
本卷考法
  • 由四条开环幅相曲线分别判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数，再数曲线包围临界点的圈数
  • 中间结果：闭环右半平面极点数由开环极点数减二倍圈数给出
  • 卡点：把包围圈数的正负号定义搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由四条开环幅相曲线分别判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

最小相位系统与非最小相位系统 频域分析
本卷考法
  • 指出非最小相位系统仅凭幅相曲线无法判稳
本卷实例
  • 关键一步：从右半平面极点或零点判断系统是否最小相位
  • 中间结果：非最小相位时开环右半平面极点数未知，判据失效
  • 卡点：把右半平面极点与右半平面零点混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过指出非最小相位系统仅凭幅相曲线无法判稳
