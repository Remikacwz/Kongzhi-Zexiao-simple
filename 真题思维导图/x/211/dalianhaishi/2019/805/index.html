一一、填空题#

思路

广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 由开环传函零点位置判断应画多少度根轨迹
本卷实例
  • 关键一步：由分子常数项与零点半平面位置判相角条件
  • 中间结果：零点在右半平面时用零度相角条件
  • 卡点：零度根轨迹仍按180度规则画
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过由开环传函零点位置判断应画多少度根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

频率特性的物理意义与求法 频域分析
本卷考法
  • 由正弦输入与传函求输出稳态分量幅值
本卷实例
  • 关键一步：稳态幅值等于输入幅值乘幅频特性在该频率的值
  • 中间结果：把正弦频率代入开环幅频特性再乘输入幅值
  • 卡点：漏乘输入幅值或把频率代错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由正弦输入与传函求输出稳态分量幅值
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
稳定裕度 频域分析
本卷考法
  • 由开环传函求幅值裕度
本卷实例
  • 关键一步：先求相位穿越频率再取该处幅频的倒数
  • 中间结果：幅值裕度等于相位穿越频率处幅频的倒数
  • 卡点：本题开环传函两源均缺，无法定值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由开环传函求幅值裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 填写对自动控制系统的基本要求
本卷实例
  • 关键一步：从稳定性、准确性、快速性三方面作答
  • 中间结果：三方面分别对应稳定、精度与响应速度
  • 卡点：漏答快速性或准确性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过填写对自动控制系统的基本要求
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
描述函数法基础 非线性系统
本卷考法
  • 填写非线性环节1比p的描述函数表现
本卷实例
  • 关键一步：把描述函数视为输入幅值的实函数
  • 中间结果：该描述函数等效为一个比例放大器
  • 卡点：把描述函数当成频率的函数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过填写非线性环节1比p的描述函数表现
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

状态空间表达式的建立 状态空间分析
本卷考法
  • 填写状态空间表达式的两个组成方程
本卷实例
  • 关键一步：从状态方程与输出方程两部分作答
  • 中间结果：状态方程描述状态变化，输出方程描述输出
  • 卡点：把状态方程与输出方程混为一个
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过填写状态空间表达式的两个组成方程
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式
相平面法 非线性系统
本卷考法
  • 填写特征根分布对应的相平面奇点类型
本卷实例
  • 关键一步：按实部正负与是否共轭分类
  • 中间结果：一正一负实根为鞍点，正实部共轭复根为不稳定焦点
  • 卡点：两类奇点写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过填写特征根分布对应的相平面奇点类型
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆
公式
采样过程与香农采样定理 离散控制系统
本卷考法
  • 填写零阶保持器的三个特性
本卷实例
  • 关键一步：从幅频低通与相频滞后两方面作答
  • 中间结果：具有低通滤波、时间滞后与相位滞后三个特点
  • 卡点：漏掉相位滞后这一条
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过填写零阶保持器的三个特性
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

状态空间与传递函数的关系 状态空间分析
本卷考法
  • 填写非奇异变换下不变的系统特征
本卷实例
  • 关键一步：从特征值、传递函数与能控能观三方面作答
  • 中间结果：特征值、传函矩阵与能控能观性均不变
  • 卡点：只答特征值而漏掉能控能观
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过填写非奇异变换下不变的系统特征
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消
公式
能控性与能观性 状态空间分析
本卷考法
  • 填写给定状态空间表达式的对偶系统（借位）
本卷实例
  • 关键一步：把系统矩阵转置并互换输入输出矩阵
  • 中间结果：对偶系统把B与C的角色互换
  • 卡点：忘记对系统矩阵取转置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过填写给定状态空间表达式的对偶系统（借位）
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

根轨迹的绘制法则 根轨迹法
本卷考法
  • 由正反馈系统开环传函判断闭环根轨迹形状
本卷实例
  • 关键一步：先判断正反馈对应零度根轨迹
  • 中间结果：零度根轨迹实轴段右侧零极点个数为偶数
  • 卡点：仍按180度根轨迹判实轴段
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过由正反馈系统开环传函判断闭环根轨迹形状
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

典型环节的对数频率特性 频域分析
本卷考法
  • 由开环传函判断某频率处对数幅频斜率变化
本卷实例
  • 关键一步：先列转折频率再逐段累加斜率
  • 中间结果：该频率处斜率按对应环节方向改变
  • 卡点：把斜率变化量当替换而非累加

十十、描述函数法求稳定条件与自振#

思路
  • 画负倒描述函数与线性部分幅相曲线，由交点判断周期运动与稳定条件。

本卷考法
  • 用描述函数法求稳定与周期运动的K范围
本卷实例
  • 关键一步：把负倒描述函数与线性部分幅相曲线画同一平面
  • 中间结果：由两条曲线交点判断周期运动与K临界
  • 卡点：未标A增大方向就判周期运动稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过用描述函数法求稳定与周期运动的K范围
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率
