1一、简答·减小或消除稳态误差的措施#

思路
  • 从稳态误差的来源入手，按开环增益不足与系统型别不够两类情形分别给出措施，并说明各措施的代价。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 试述稳定性基本概念并区分线性与非线性系统的稳定决定因素
本卷实例
  • 关键一步：先由扰动消失后能否回到原平衡状态界定稳定性
  • 关键一步：再按线性与非线性分别讨论稳定性的决定因素
  • 中间结果：线性系统的稳定性只由自身结构与参数决定
  • 中间结果：非线性系统可有多个平衡状态，还与输入和初值有关
  • 卡点：把线性系统的稳定性误说成与输入或初值有关
  • 卡点：只答稳定性定义而漏掉两类系统决定因素的对比
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过试述稳定性基本概念并区分线性与非线性系统的稳定决定因素
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
减小稳态误差的措施 稳态误差
本卷考法
  • 列举减小或消除稳态误差的常用措施
本卷实例
  • 关键一步：先判断误差来自开环增益偏小还是系统型别偏低
  • 中间结果：可归结为提高增益、增加积分、前馈补偿与扰动补偿四类
  • 卡点：只答提高增益而漏掉稳定性代价，或漏掉复合控制方案
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过列举减小或消除稳态误差的常用措施
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

2二、机电系统建模与状态空间#

思路
  • 按电与机械两部分分别列写线圈电压方程和质量块受力方程，把反电动势与电磁力作为耦合项，消去中间变量求传递函数，再按指定状态变量列写状态空间表达式。
直流电机等机电系统 建模与机电系统
本卷考法
  • 列线圈电压方程与质量块受力方程并联立
本卷实例
  • 关键一步：把反电动势与电磁力两个耦合项分别写进电气与机械方程
  • 中间结果：消去线圈电流后得到输入电压到输出位置的微分方程
  • 卡点：耦合系数 k2 同时出现在两个方程中，正负号容易取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由电枢回路电压方程与转矩平衡方程联立
  • 反电动势与转速成正比，电磁转矩与电枢电流成正比
  • 机电时间常数由电气与机械两方面参数共同决定
步骤
  • 写出电枢回路电压平衡方程
  • 写出转矩平衡方程（含负载与粘性摩擦）
  • 消去电枢电流，得到转速或转角对电压的传递函数
通用考法
  • 本卷考过列线圈电压方程与质量块受力方程并联立
  • 求直流电机转速或位置对电枢电压的传递函数
  • 分析机电时间常数与电气时间常数的数量级关系
常见易错
  • 漏掉反电动势与电磁转矩的耦合项
  • 把电气时间常数与机电时间常数混淆
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由机电系统的微分方程求 X(s)/U(s)
本卷实例
  • 关键一步：对含运算放大器的电路部分先按虚短虚断化简
  • 中间结果：传递函数分母由电气与机械两组参数共同组成
  • 卡点：运算放大器增益 F 的作用位置未读图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由机电系统的微分方程求 X(s)/U(s)
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
状态空间表达式的建立 状态空间分析
本卷考法
  • 按指定状态变量列写状态空间表达式
本卷实例
  • 关键一步：把题给的 z1、z2、z3 直接取作三个状态变量
  • 中间结果：由三个一阶微分方程整理出 A、B、C 矩阵
  • 卡点：输出取位置 x，输出方程只需保留含 z1 的一项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过按指定状态变量列写状态空间表达式
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

3三、结构图参数确定与复合控制#

思路
  • 由超调量确定阻尼比，由斜坡稳态误差确定开环增益关系，联立求出结构参数；再用梅森增益公式写出闭环传递函数，最后按不变性原理设计前馈增益 k3。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由超调量反求二阶系统的阻尼比
本卷实例
  • 关键一步：把闭环传递函数化成标准二阶形式后逐项比对系数
  • 中间结果：超调量只与阻尼比有关，可先由超调量定出阻尼比
  • 卡点：结构图未读图，前向通路与反馈支路增益需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由超调量反求二阶系统的阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 用斜坡稳态误差条件求结构参数
本卷实例
  • 关键一步：写出误差传递函数并判断系统型别，再选斜坡误差公式
  • 中间结果：斜坡误差与开环增益成反比，可给出增益关系式
  • 卡点：用终值定理前要先确认前馈增益取零时系统稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过用斜坡稳态误差条件求结构参数
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求闭环传递函数
本卷实例
  • 关键一步：先找全部前向通路与独立回路，再逐个写余子式
  • 中间结果：前馈支路存在时前向通路由一条增加为两条
  • 卡点：前馈支路与回路是否接触决定余子式，容易漏减
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
反馈校正与复合控制 系统校正
本卷考法
  • 设计前馈增益使斜坡输入下无稳态误差
本卷实例
  • 关键一步：按不变性原理列写前馈补偿器需要满足的条件
  • 中间结果：前馈只改变误差通路，不改变闭环特征方程
  • 卡点：解出的补偿器可能含微分，需检查其可实现性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过设计前馈增益使斜坡输入下无稳态误差
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
公式

4四、根轨迹绘制与稳定范围#

思路
  • 先标出开环零极点并判断实轴上的根轨迹段，按法则画渐近线与根轨迹，再令 s 等于 jω 代入特征方程求虚轴交点与临界增益，由此给出稳定范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画 k* 由零到无穷的根轨迹
本卷实例
  • 关键一步：先确定开环零极点，再按右侧奇数判据定实轴根轨迹段
  • 中间结果：极点与零点个数之差给出渐近线条数与实轴交点
  • 卡点：开环极点实部为正，渐近线交点需重新计算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画 k* 由零到无穷的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点以确定稳定范围
本卷实例
  • 关键一步：把 s 等于 jω 代入闭环特征方程并分离实部与虚部
  • 中间结果：由两个实方程联立解出交点频率与临界增益
  • 卡点：解出的负频率要舍去，稳定范围取两临界增益之间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点以确定稳定范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
