传递函数的定义与基本性质 传递函数
本卷考法
  • 第1、2空写传递函数定义并指出数学模型只取决于结构与参数
本卷实例
  • 关键一步：抓住零初始条件与输出输入拉氏变换之比这两个要点
  • 中间结果：传递函数由系统结构与参数决定，与输入和初始条件无关
  • 卡点：忽略零初始条件会把初始值带进变换结果
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过第1、2空写传递函数定义并指出数学模型只取决于结构与参数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

劳斯判据 稳定性分析
本卷考法
  • 第3空回答线性系统稳定的充要条件
本卷实例
  • 关键一步：从闭环特征根的位置给出充要条件
  • 中间结果：闭环特征根全部位于 s 左半平面
  • 卡点：把充要条件说成开环极点都在左半平面
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过第3空回答线性系统稳定的充要条件
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

本卷考法

本卷实例
  • 关键一步：由超调量与阻尼比成反比入手
  • 中间结果：增大阻尼比可以减小超调量
  • 卡点：把增大阻尼说成减小阻尼
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过第4空回答减小二阶欠阻尼系统超调量的措施
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

奈奎斯特判据 稳定性分析
本卷考法
  • 第6空指出奈氏判据公式中 R 的含义
本卷实例
  • 关键一步：把公式中的 R 对应到曲线的包围圈数
  • 中间结果：R 指曲线对负一临界点的正负穿越次数
  • 卡点：把正负穿越次数与开环右半平面极点数搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过第6空指出奈氏判据公式中 R 的含义
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

采样过程与香农采样定理 离散控制系统
本卷考法
  • 第8空说明保持器要解决的问题
本卷实例
  • 关键一步：从离散信号与连续信号之间的转换切入

  • 卡点：把保持器与采样开关的作用说反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过第8空说明保持器要解决的问题
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

非线性系统的特点 非线性系统
本卷考法
  • 第10空列举非线性系统区别于线性系统的特点
本卷实例
  • 关键一步：从稳定性与频率响应两方面归纳
  • 中间结果：非线性系统稳定性分析复杂且可能出现自持振荡
  • 卡点：认为非线性系统一定不稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过第10空列举非线性系统区别于线性系统的特点
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定

状态反馈解耦 状态空间分析
本卷考法
  • 第13空说明解耦系统对角化传递函数矩阵的条件
本卷实例
  • 关键一步：从解耦矩阵的非奇异条件入手
  • 中间结果：解耦要求传递函数矩阵可化为对角形且解耦矩阵非奇异
  • 卡点：解耦矩阵奇异时仍硬求解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 解耦的目标是让每个输出只被对应的一个输入控制，闭环传递函数矩阵成为对角阵
  • 用输入变换加状态反馈控制律 u 等于负 Kx 加 Fv 实现解耦
  • 解耦矩阵由各通道输出的相对阶与输入矩阵组成，非奇异时才能解耦
  • 解耦后闭环传函矩阵的对角元由配置的极点决定，非对角元为零
步骤
  • 逐个求各输出的相对阶，即输出导数中首次出现输入的阶数减一
  • 用各通道的相对阶对应的行组成解耦矩阵，并检查其是否非奇异
  • 由解耦矩阵的逆求出输入变换矩阵，再由各通道系数求出状态反馈矩阵
  • 写出闭环传递函数矩阵，校验是否已对角化并满足期望极点
通用考法
  • 本卷考过第13空说明解耦系统对角化传递函数矩阵的条件
  • 证明系统能通过输入变换与状态反馈实现解耦
  • 求解耦矩阵与状态反馈阵并写出闭环传递函数矩阵
  • 分析解耦后各通道的极点是否可任意配置
常见易错
  • 相对阶取成输出导数首次出现输入的阶数本身，差一阶
  • 解耦矩阵奇异时仍硬求解，忽略解耦条件不满足
