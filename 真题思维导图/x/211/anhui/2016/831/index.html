1一、多回路结构图求闭环传函#

思路
  • 把结构图改画为信号流图，找出三条独立回路与从R到C的前向通路，用梅森增益公式求Φ(s)=C(s)/R(s)。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由多回路结构图用梅森公式求Φ(s)=C(s)/R(s)
本卷实例
  • 关键一步：先数回路写特征式，再数前向通路及其余子式
  • 中间结果：两条回路互不接触，特征式含不接触回路乘积修正
  • 卡点：不接触回路容易漏计，结构图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由多回路结构图用梅森公式求Φ(s)=C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简
本卷实例
  • 关键一步：从最内层反馈环开始等效再向外合并
  • 中间结果：化简后分母含三条回路增益与二次修正项
  • 卡点：比较点与引出点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 串联、并联与反馈等效
本卷实例
  • 关键一步：把并联支路先相加，再套负反馈公式
  • 中间结果：前向通路可写成两个并联环节之和
  • 卡点：负反馈分母写成1加GH而不是1减GH
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过串联、并联与反馈等效
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、二阶系统阶数阻尼与阶跃响应#

思路
  • 先写闭环传函与特征方程判断阶数与稳定性，再化为二阶标准形式求阻尼比并判断是否存在振荡周期，最后部分分式反变换求单位阶跃响应。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 第(1)(2)问由闭环传函求阶数与阻尼比
本卷实例
  • 关键一步：先写闭环特征方程，再把传函化为二阶标准形式
  • 中间结果：由ωn平方与二倍ξωn两个关系解阻尼比
  • 卡点：不能直接用开环传函，必须先求闭环
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过第(1)(2)问由闭环传函求阶数与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
劳斯判据 稳定性分析
本卷考法
  • 第(1)问判断闭环系统稳定性
本卷实例
  • 关键一步：求闭环特征根或列劳斯表检查首列
  • 中间结果：两个特征根均为负实根时系统稳定
  • 卡点：开环有右半平面极点不影响闭环判稳结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过第(1)问判断闭环系统稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 第(2)问判断是否存在振荡周期与频率
本卷实例
  • 关键一步：阻尼比大于等于1时响应单调，无振荡周期
  • 中间结果：过阻尼时响应由两个实指数模态叠加
  • 卡点：一见二阶就套欠阻尼公式会答错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过第(2)问判断是否存在振荡周期与频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 第(3)问求单位阶跃响应
本卷实例
  • 关键一步：部分分式展开后逐项拉氏反变换
  • 中间结果：响应等于1加两个衰减指数项的组合
  • 卡点：部分分式系数可用留数法，注意稳态项为1
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过第(3)问求单位阶跃响应
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

4四、含初值的二阶系统阶跃响应#

思路
  • 由闭环传函写二阶微分方程，作带初值的拉氏变换，把初值项移到方程右端，分离零状态与零输入分量后反变换。
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由闭环传函与初值c(0)=-1、ċ(0)=0求单位阶跃全响应
本卷实例
  • 关键一步：对微分方程作带初值拉氏变换，初值项移到右端
  • 中间结果：C(s)由零状态项与含初值的零输入项叠加
  • 卡点：初值项符号易错，分子出现s的一次项与常数项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由闭环传函与初值c(0)=-1、ċ(0)=0求单位阶跃全响应
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

思路

反馈校正与复合控制 系统校正

  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用

减小稳态误差的措施 稳态误差
本卷考法
  • 设计串联校正Gc2使阶跃跟踪误差为零
本卷实例
  • 关键一步：跟踪阶跃无差要求系统至少为一型，取Gc2含积分环节
  • 中间结果：串联校正后开环型别提升，稳态误差为零
  • 卡点：提升型别后要重新检查稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计串联校正Gc2使阶跃跟踪误差为零
  • 分析提高开环增益对误差与稳定性的双重影响

  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

劳斯判据 稳定性分析

  • 检查首列符号：全同号则稳定，有变号则数出个数
