1一、含延迟环节的奈氏曲线与稳定τ范围15 分#

思路
  • 先由传函写出幅频与相频表达式，再令幅值等于1求出幅值穿越频率，把该处相角大于-180度作为稳定条件，解出延迟时间τ的范围。
含纯延迟环节的系统稳定性 稳定性分析
本卷考法
  • 含延迟环节的奈氏判据求最大延迟τ
本卷实例
  • 关键一步：分别写出幅频表达式与含-ωτ的相频表达式
  • 中间结果：令幅值等于1求出幅值穿越频率再代入相频
  • 卡点：奈氏曲线以原卷插图给出，刻度需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 延迟环节 e^{-τs} 的幅值为 1、相位为 -τω，只恶化相位
  • 延迟会显著缩小稳定域，τ 越大越难稳定
  • 频域判据需用相位裕度扣除延迟引起的附加滞后
步骤
  • 写出含延迟的开环传递函数
  • 分别求幅值与相位表达式
  • 在相频特性中扣除 τω 的滞后量
  • 按稳定裕度或奈氏判据求临界 τ 或临界 K
通用考法
  • 本卷考过含延迟环节的奈氏判据求最大延迟τ
  • 求使系统稳定的最大延迟时间
  • 求含延迟系统的临界开环增益
  • 分析延迟对稳定裕度的影响
常见易错
  • 本卷考过延迟相角的度与弧度换算写错，导致不等式方向反
  • 把延迟环节当成惯性环节处理
  • 相位计算时忘记角度与弧度换算
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅相曲线判闭环系统稳定
本卷实例
  • 关键一步：按开环右半平面极点数P与包围圈数判稳
  • 中间结果：幅值穿越点处相角与-180度的差值决定稳定边界
  • 卡点：曲线走向与穿越方向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环幅相曲线判闭环系统稳定
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过先数开环右半平面极点数再判包围，顺序颠倒
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求含延迟环节的幅频与相频表达式
本卷实例
  • 关键一步：把延迟因子的相角写成-ωτ并与其他环节相角相加
  • 中间结果：幅值只由各环节模值乘积决定，延迟不影响幅值
  • 卡点：延迟时间符号与其单位需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求含延迟环节的幅频与相频表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过相角累加时漏掉延迟项或积分环节的-90度
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

2二、画幅频渐近线并求截止频率15 分#

思路
  • 把传函化成标准时间常数形式，按型别定低频段斜率，按各转角频率逐段累加斜率，再由幅值等于1的条件求截止频率。
开环对数频率特性的绘制 频域分析
本卷考法
  • 由传函绘制开环对数渐近幅频特性
本卷实例
  • 关键一步：把传函化成标准时间常数形式再定型别与起始斜率
  • 中间结果：按各转角频率依次累加斜率得到各段斜率
  • 卡点：渐近线低频段高度与转折点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过由传函绘制开环对数渐近幅频特性
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 本卷考过逐段改斜率时用替换而非累加
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
典型环节的对数频率特性 频域分析
本卷考法
  • 识别各典型环节的转角频率与斜率贡献
本卷实例
  • 关键一步：把每个环节写成(τs+1)或(1+τs)形式读出转角频率
  • 中间结果：各环节的斜率贡献按类型分别计入，再逐段累加
  • 卡点：各环节参数辨识需回原卷核对数值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例环节是水平线，积分与微分分别是 -20 与 +20 dB/dec 的斜线
  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec
  • 一阶微分环节与惯性环节幅频互为镜像
  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤
  • 把传递函数分解为典型环节乘积
  • 逐环节画出对数幅频渐近线与相频曲线
  • 代数相加得到总特性
通用考法
  • 本卷考过识别各典型环节的转角频率与斜率贡献
  • 画出某一典型环节的 Bode 图
  • 由 Bode 图识别环节类型
  • 说明转角频率处的幅值与相角
常见易错
  • 本卷考过把一阶微分环节与惯性环节的斜率符号写反
  • 把惯性环节高频渐近线的 -20 写成 -40
  • 振荡环节谐振峰位置误当作 ωn

3三、正反馈系统零度根轨迹与稳定K*范围15 分#

思路
  • 正反馈取0度相角条件，求渐近线、出射角与虚轴交点，再由虚轴交点处的临界增益定出稳定范围。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 正反馈系统的零度根轨迹绘制
本卷实例
  • 关键一步：正反馈取2kπ相角条件，渐近线夹角改为2kπ除以(n-m)
  • 中间结果：实轴根轨迹段按右侧零极点个数为偶数的判据确定
  • 卡点：开环传函分子分母系数OCR残损，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过正反馈系统的零度根轨迹绘制
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 本卷考过零度根轨迹仍按180度相角条件处理
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则求渐近线与实轴根轨迹段
本卷实例
  • 关键一步：先标开环零极点再定实轴段与渐近线交点
  • 中间结果：三条开环极点一条开环零点时渐近线夹角由法则给出
  • 卡点：极点与零点的具体数值需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则求渐近线与实轴根轨迹段
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过渐近线夹角公式里的2k写成2k+1
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求分离汇合点并判断取舍
本卷实例
  • 关键一步：由dK*/ds等于0得方程并求出候选根
  • 中间结果：候选点需用相角条件回代才能确认是否在根轨迹上
  • 卡点：复数根是否在根轨迹上需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求分离汇合点并判断取舍
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 本卷考过解出方程根后不筛选，保留不在根轨迹上的解
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界K*
本卷实例
  • 关键一步：把s=jω代入闭环特征方程并分离实部与虚部
  • 中间结果：特征方程含K*的一次项，与虚部方程联立可解
  • 卡点：临界增益对应的交点需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界K*
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 本卷考过只代一组点导致漏掉另一组虚轴交点
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

4四、劳斯判据求τ与K范围及s=-1左侧极点范围15 分#

思路
  • 先由结构图写闭环特征方程并列劳斯表求稳定域；再作变量平移s=z-1，对平移后的多项式重新列劳斯表，求极点全部位于s=-1左侧的K*范围。
参数稳定域的确定 稳定性分析
本卷考法
  • 由结构图求使系统稳定的τ与K范围
本卷实例
  • 关键一步：由结构图写闭环特征方程再列劳斯表
  • 中间结果：首列各元素同号给出τ与K*的联立不等式组
  • 卡点：结构图以原卷插图给出，反馈极性需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由结构图求使系统稳定的τ与K范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 本卷考过列劳斯表时首列含参数，漏掉某个不等式
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
劳斯判据 稳定性分析
本卷考法
  • 用变量平移求极点位于s=-1左侧的K*范围
本卷实例
  • 关键一步：令s=z-1代入特征方程得关于z的新多项式
  • 中间结果：对新多项式列出劳斯表并要求首列同号
  • 卡点：平移后各项系数需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用变量平移求极点位于s=-1左侧的K*范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
