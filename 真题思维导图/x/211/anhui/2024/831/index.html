1一、运放电路求传递函数#

思路
  • 由含运放的电路图，用虚短虚断列KCL方程消去中间电压，整理成s多项式之比。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由含运算放大器的电路图求传递函数 G(s)=Vo(s)/Vi(s)
本卷实例
  • 关键一步：对运放输入节点与中间节点写KCL，借虚短虚断减少未知量
  • 中间结果：消元后分子分母均为s多项式，系数由RC乘积组合而成
  • 卡点：电路仅以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由含运算放大器的电路图求传递函数 G(s)=Vo(s)/Vi(s)
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 有源网络建模，按复阻抗列写运算电路方程
本卷实例
  • 关键一步：把电容写成1/(sC)后按复阻抗分压与节点法列式
  • 中间结果：整理后得到s的二次有理式，含两个RC时间常数乘积
  • 卡点：反相端与虚地条件易漏，负号方向要统一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过有源网络建模，按复阻抗列写运算电路方程
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式

2二、结构图求闭环传递函数#

思路
  • 先把结构图改画成信号流图，用梅森公式求C(s)/R(s)，或按串并联与局部反馈逐层化简。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图先画信号流图再用梅森增益公式求闭环传函
本卷实例
  • 关键一步：标出全部回路与前向通路，判断哪些回路互不接触
  • 中间结果：特征式为1减各回路增益之和再加两两不接触回路乘积
  • 卡点：结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图先画信号流图再用梅森增益公式求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 含局部反馈的多环节结构图逐层化简
本卷实例
  • 关键一步：先合并串并联支路与内环，再套总反馈公式
  • 中间结果：闭环分母为1±开环传函，分子为前向通路乘积
  • 卡点：反馈极性决定分母正负号，别整体取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过含局部反馈的多环节结构图逐层化简
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

3三、根轨迹与主导极点动态指标#

思路
  • 按法则画三阶根轨迹，由分离点与虚轴交点定衰减振荡K范围；再令阻尼比0.5求主导极点估指标。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制 G=k/[s(s+1)(s+2)] 的三阶根轨迹
本卷实例
  • 关键一步：标出三个开环极点，实轴段取右侧零极点个数之和为奇数处
  • 中间结果：三条渐近线交于实部均值，夹角为±60°与180°
  • 卡点：渐近线夹角分子为2k+1，别写成2k
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制 G=k/[s(s+1)(s+2)] 的三阶根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹分离点及其对应的根轨迹增益
本卷实例
  • 关键一步：由1/G对s求导为零得分离点方程3s²+6s+2=0
  • 中间结果：落在实轴段(-1,0)内的那个根才是有效分离点
  • 卡点：另一根不在根轨迹上，必须舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹分离点及其对应的根轨迹增益
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及使输出振荡的临界增益
本卷实例
  • 关键一步：把s=jω代入三阶闭环特征方程，实部虚部分别为零
  • 中间结果：虚部方程解交点频率，实部方程解临界K
  • 卡点：上下半虚轴各有一组共轭交点，切勿漏一组
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及使输出振荡的临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由阻尼比0.5的等阻尼线确定主导极点与K
本卷实例
  • 关键一步：设s=σ(-1+j√3)回代特征方程，分离实部虚部联立
  • 中间结果：虚部方程定σ，实部方程定K，第三极点由根和求出
  • 卡点：先确认第三极点远离虚轴才能作主导极点近似
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由阻尼比0.5的等阻尼线确定主导极点与K
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由主导极点的ξ与ωn估算上升、峰值、超调与调节时间
本卷实例
  • 关键一步：把主导极点写成-ξωn±jωn√(1-ξ²)，读出ξ与ωn
  • 中间结果：四个指标分别由ξ、ωn代入二阶标准公式得到
  • 卡点：两种误差带的调节时间系数别混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由主导极点的ξ与ωn估算上升、峰值、超调与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 判断第三个闭环极点能否忽略并作二阶近似
本卷实例
  • 关键一步：比较第三极点与共轭极点实部的大小，取实部小者为主导
  • 中间结果：第三极点实部远大于共轭极点实部时可作二阶近似
  • 卡点：近似前要看该极点留数权重是否足够小
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过判断第三个闭环极点能否忽略并作二阶近似
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

4四、奈氏判据与正弦稳态误差#

思路
  • 先数开环右半平面极点数P，绘极坐标图判包围求稳定K范围；再求正弦输入下的稳态误差。
奈奎斯特判据 稳定性分析
本卷考法
  • 开环含一个右半平面极点时用奈奎斯特判据判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点个数P，再由Z=P-2(N+-N-)判断
  • 中间结果：曲线与负实轴交点位置给出临界增益所在处
  • 卡点：P不为零，不能套用P等于零时的简化包围式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过开环含一个右半平面极点时用奈奎斯特判据判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由误差频率特性求正弦输入下的稳态误差表达式
本卷实例
  • 关键一步：写出误差传函1/(1+G)，把s=jω代入求幅值与相角
  • 中间结果：稳态误差为同频正弦，幅值乘误差幅频、相角叠加
  • 卡点：相角要累计误差传函的总相角，别只取G的相角
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性

10十、能控标准型与状态反馈极点配置#

思路
  • 先化能控标准型，再验能控性，用期望特征多项式与闭环特征式比较系数求反馈阵。
由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 把给定状态空间表达式化为能控标准型
本卷实例
  • 关键一步：先求原系统特征多项式系数，再按友矩阵规则写标准型
  • 中间结果：变换阵由能控性矩阵与友矩阵能控性矩阵相乘求逆得到
  • 卡点：系统矩阵的重复特征值会带来变换阵退化，须先验秩
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观

本卷考法
  • 设计状态反馈使闭环特征值为-1、-2与-2
本卷实例
  • 关键一步：先验证能控性，再写期望特征多项式(s+1)(s+2)²
  • 中间结果：比较det(sI-A+BK)与期望多项式系数解出增益阵
  • 卡点：重根-2对应一个约当块，反馈后仍不可对角化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法

  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
