1一、运放电路建模与组合校正参数15 分#

思路
  • 对含理想运放的电路用虚短虚断列节点电流方程，画出结构框图并写各环节传函；由闭环特征式用劳斯判据求电阻R的稳定范围；再令主导极点阻尼比等于0.5反求R。
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 对含理想运放的电路列方程求各环节传函
本卷实例
  • 关键一步：设运放两输入端等电位、输入电流为零，再按节点列电流方程
  • 中间结果：各节点方程消元后得到含积分与惯性环节的传函
  • 卡点：电路图与元件连接需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过对含理想运放的电路列方程求各环节传函
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由有源网络求传递函数并画出系统结构框图
本卷实例
  • 关键一步：先写每个运放级的传函，再按信号流向串接成框图
  • 中间结果：框图含一个积分环节与两个惯性环节
  • 卡点：反相输入端的负号不能漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由有源网络求传递函数并画出系统结构框图
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
劳斯判据 稳定性分析
本卷考法
  • 第(2)问由闭环特征式用劳斯判据求电阻R的稳定范围
本卷实例
  • 关键一步：把闭环分母整理成含R的三次多项式再列劳斯表
  • 中间结果：首列全正给出R的下界
  • 卡点：系数含R，解不等式时勿把R当常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过第(2)问由闭环特征式用劳斯判据求电阻R的稳定范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 第(3)问由主导极点阻尼比0.5确定闭环极点的方向
本卷实例
  • 关键一步：阻尼比0.5对应极点与负实轴夹角60度，极点取负a加减根号3乘aj
  • 中间结果：把该极点代入等效开环的相角条件解出a
  • 卡点：用主导极点近似前先确认另两个极点远离虚轴
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过第(3)问由主导极点阻尼比0.5确定闭环极点的方向
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

2二、结构图求闭环传递函数15 分#

思路
  • 找出结构图的全部独立回路与从输入到输出的前向通路，按下接触回路组合写出特征式，用梅森增益公式求闭环传函。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由多回路结构图用梅森公式求C(s)/R(s)
本卷实例
  • 关键一步：先求全部独立回路与两两不接触回路得特征式
  • 中间结果：两条前向通路的余子式都含1减G3G4
  • 卡点：不接触回路组合易漏，特征式的符号别写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由多回路结构图用梅森公式求C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 逐层化简含局部反馈的多回路结构图
本卷实例
  • 关键一步：由内向外逐环等效，把内环闭环传函替换为单环节
  • 中间结果：外层化为两个等效环节并联后再加总反馈
  • 卡点：比较点与引出点位置需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过逐层化简含局部反馈的多回路结构图
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

3三、参数根轨迹与最小阻尼比15 分#

思路
  • 把特征方程整理成以k为参变量的等效开环，按绘制法则画根轨迹；由衰减振荡条件取两分离点之间的k范围；再由原点作等阻尼线与根轨迹相切求最小阻尼比对应的k与极点。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 以k为参变量画等效开环的根轨迹草图
本卷实例
  • 关键一步：先写等效开环并标出开环零点与两个开环极点
  • 中间结果：渐近线交点在实轴正半轴，实轴根轨迹分两段
  • 卡点：极点比零点多一个，渐近线只有一条
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过以k为参变量画等效开环的根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点并由分离点定临界k
本卷实例
  • 关键一步：由三个开环零极点的倒数方程解出分离点坐标
  • 中间结果：两个分离点分别对应两个临界k值
  • 卡点：不在根轨迹上的根要舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点并由分离点定临界k
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 第(3)问由阻尼比条件在根轨迹上求最小阻尼比的k与极点
本卷实例
  • 关键一步：从原点作等阻尼线与根轨迹相切，切点即最小阻尼比对应极点
  • 中间结果：切点对应一对共轭复极点
  • 卡点：等阻尼线不是垂直线，其角度由阻尼比的反余弦给出
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过第(3)问由阻尼比条件在根轨迹上求最小阻尼比的k与极点
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

4四、由对数幅频曲线反求传函并求稳态误差15 分#

思路
  • 由渐近幅频曲线反求开环传函，写误差传递函数，把正弦输入频率代入误差频率特性求幅值与相角，得稳态误差输出。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频渐近曲线反求开环传函
本卷实例
  • 关键一步：由低频段高度为零分贝定增益，由转折频率定时间常数
  • 中间结果：开环为一个积分环节串联一个惯性环节
  • 卡点：低频段高度对应的是k比ω的型别项而非k本身
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频渐近曲线反求开环传函
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 写出单位反馈系统的误差传函并用频率法求稳态误差输出
本卷实例
  • 关键一步：误差传函取1除(1加G(s))，再把s等于jω代入
  • 中间结果：误差幅频乘输入幅值、误差相频加输入相位
  • 卡点：本题求的是误差输出e(t)而非输出c(t)
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写出单位反馈系统的误差传函并用频率法求稳态误差输出
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由频率特性求正弦输入的稳态误差响应
本卷实例
  • 关键一步：稳态幅值为输入幅值乘误差幅频，相位为输入相位加误差相频
  • 中间结果：只在输入角频率处对误差频率特性取值
  • 卡点：求幅值要取模，相角累加别漏符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数

要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控

  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
