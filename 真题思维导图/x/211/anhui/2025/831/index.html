1一、运放有源网络求传函与控制器作用#

思路
  • 对含运算放大器的有源网络用虚短与虚断条件列写微分方程，先求Uo(s)/Ui(s)，再由该电路的频率特性分析它作为控制器时对系统性能的改善。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由含运放的RC有源网络列方程求Uo(s)/Ui(s)
本卷实例
  • 关键一步：利用理想运放虚短虚断，把两个电容与电阻的电流关系代入KCL列方程
  • 中间结果：化简得含s平方项与1/s项的输出输入比，分母只有一个积分环节
  • 卡点：电路图未读图，电容电阻的连接与反馈支路需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由含运放的RC有源网络列方程求Uo(s)/Ui(s)
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 用虚短与虚断条件对运放有源网络建模
本卷实例
  • 关键一步：先设运放两输入端电位相等、输入电流为零，再按节点电流列方程
  • 中间结果：方程消去中间电流变量后得到只含输入输出的二阶微分方程
  • 卡点：虚短虚断只在理想运放闭环负反馈时成立，勿漏此前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过用虚短与虚断条件对运放有源网络建模
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

校正的基本概念与性能指标 系统校正
本卷考法

本卷实例

  • 中间结果：该网络对低频与高频都呈高增益、对中间频段呈衰减
  • 卡点：改善方面属开放问答，具体表述需回原卷与答案核对

  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系

通用考法
  • 本卷考过说明该有源网络作为控制器时对系统性能的改善
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求

2二、结构图求闭环传递函数#

思路
  • 把控制系统结构图改画为信号流图，找出全部独立回路与从输入到输出的前向通路，用梅森增益公式求G(s)=C(s)/R(s)。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求结构图的闭环传递函数
本卷实例
  • 关键一步：先找出全部独立回路求特征式，再数清前向通路并写各自余子式
  • 中间结果：本题只有一条独立回路，多数前向通路的余子式为1
  • 卡点：有一条带负号的前向通路容易漏数，需回原卷核对结构图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求结构图的闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 对含局部反馈的多回路结构图逐层化简
本卷实例
  • 关键一步：从最内层反馈环开始，先求内环闭环传函再替换为等效环节
  • 中间结果：内环等效后外层化为单回路，可直接套反馈公式
  • 卡点：结构图未读图，比较点与引出点位置需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过对含局部反馈的多回路结构图逐层化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

3三、误差时域响应反求输入参数#

思路
  • 由单位反馈写出误差传递函数，代入多项式输入的拉氏变换，部分分式展开后取拉氏反变换得到含暂态的误差表达式，再代入给定时刻与误差值反求输入参数。
误差定义与误差传递函数 稳态误差
本卷考法
  • 写出单位反馈系统的误差传递函数并求误差拉氏变换
本卷实例
  • 关键一步：误差传递函数取1/(1+G0(s))，再乘输入的拉氏变换
  • 中间结果：误差拉氏变换的部分分式含1/s平方、1/s与二次复根项
  • 卡点：源文用输入端误差定义，需先确认误差取在何处
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写出单位反馈系统的误差传递函数并求误差拉氏变换
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 用拉氏反变换求含自由分量与强迫分量的误差全响应
本卷实例
  • 关键一步：对误差拉氏变换做部分分式分解，逐项反变换后叠加
  • 中间结果：反变换含斜坡项、常数项与指数衰减乘正余弦的暂态项
  • 卡点：二次复根项配凑三角函数时系数容易配错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过用拉氏反变换求含自由分量与强迫分量的误差全响应
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 识别欠阻尼衰减振荡项并在给定时刻取值
本卷实例
  • 关键一步：把复根项配方成带衰减因子的欠阻尼标准形式
  • 中间结果：衰减因子由闭环极点实部给出，振荡频率为阻尼振荡频率
  • 卡点：给定时刻的参考数据用于暂态项，不能只代稳态分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过识别欠阻尼衰减振荡项并在给定时刻取值
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式

4四、根轨迹绘制与阻尼比约束下的k范围#

思路
  • 由开环零极点按绘制法则画根轨迹，求渐近线、分离点、出射角与虚轴交点得稳定上界；再在s平面画给定阻尼比对应的等阻尼线，求它与根轨迹的交点得到满足阻尼比要求的k下界，取两者交集。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画四阶系统的根轨迹草图
本卷实例
  • 关键一步：先标出四个开环极点并判断实轴上属于根轨迹的区间
  • 中间结果：四条渐近线交于极点实部均值，夹角为四等分方向
  • 卡点：复极点对s平方+4s+10的实部虚部需回原卷核对系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画四阶系统的根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点求临界增益与稳定范围
本卷实例
  • 关键一步：把s等于jω代入特征方程，令实部与虚部分别为零
  • 中间结果：由虚部方程解出交点频率，再由实部方程得临界增益
  • 卡点：只保留正的角频率，负频率解舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹与虚轴交点求临界增益与稳定范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由给定阻尼比在根轨迹上求对应参数范围
本卷实例
  • 关键一步：在s平面画给定角度的等阻尼线，求其与根轨迹的交点
  • 中间结果：交点对应根轨迹的切点，给出满足阻尼比条件的k下界
  • 卡点：阻尼比小于给定值对应等阻尼线内侧，方向不能取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由给定阻尼比在根轨迹上求对应参数范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
