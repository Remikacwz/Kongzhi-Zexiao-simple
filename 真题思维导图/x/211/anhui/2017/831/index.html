1一、结构图求闭环传函#

思路
  • 源文仅存图1与G(s)=C(s)/R(s)；据同册答案段回内容对齐，按结构图数回路与前向通路，用梅森增益公式求闭环传函。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由图1结构图用梅森公式求G(s)=C(s)/R(s)
本卷实例
  • 关键一步：先数独立回路写特征式，再数前向通路及其余子式
  • 中间结果：三条回路均与各前向通路接触，特征式无二次修正
  • 卡点：题干文字源文丢失，结构图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由图1结构图用梅森公式求G(s)=C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简
本卷实例
  • 关键一步：从最内层反馈环开始等效再向外合并
  • 中间结果：化简后分母含三条回路增益之和
  • 卡点：比较点与引出点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 串联、并联与反馈等效
本卷实例
  • 关键一步：把并联支路相加后再套反馈公式
  • 中间结果：前向通路中有增益为1的直通支路
  • 卡点：直通支路易漏数，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过串联、并联与反馈等效
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、结构图系统稳定域与等幅振荡15 分#

思路
  • 由结构图写闭环特征多项式，第(1)问列劳斯表求稳定K范围；第(2)问令s1=s+1作坐标平移，把特征根位于s=-1左侧转化为s1右半平面判据；第(3)问令s=jω求等幅振荡K与频率。
劳斯判据 稳定性分析
本卷考法
  • 第(1)问用劳斯判据求系统稳定的K范围
本卷实例
  • 关键一步：由结构图写三阶闭环特征多项式并列劳斯表
  • 中间结果：首列含K的一次式，令首列全正取交集
  • 卡点：系数缺项时先补零再排劳斯表
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过第(1)问用劳斯判据求系统稳定的K范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 第(2)问求特征根全位于s=-1左侧的K值
本卷实例
  • 关键一步：令s1=s+1作坐标平移，把边界s=-1移到虚轴
  • 中间结果：平移后特征式常数项含K减8
  • 卡点：平移后判据仍针对s1右半平面，勿看原s
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过第(2)问求特征根全位于s=-1左侧的K值
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 第(3)问求等幅振荡的K值与振荡频率
本卷实例
  • 关键一步：令s=jω代入特征方程，实部与虚部分别为零
  • 中间结果：由劳斯表全零行构造辅助方程得频率
  • 卡点：等幅振荡对应纯虚根，不是临界阻尼
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过第(3)问求等幅振荡的K值与振荡频率
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式

3三、由单位阶跃响应反求闭环传函15 分#

思路
  • 先由给定阶跃响应求零时刻值与导数值，分离出零输入分量；再由零状态阶跃响应作拉氏变换，除以输入拉氏变换得闭环传函。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由含初值的单位阶跃响应反求闭环传函φ(s)
本卷实例
  • 关键一步：先由C(t)求c(0)与ċ(0)，分离零输入与零状态分量
  • 中间结果：零状态响应由两个衰减指数项与稳态项组成
  • 卡点：题目文字只印C(t)，初值条件需据答案段自洽补读
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由含初值的单位阶跃响应反求闭环传函φ(s)
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 含非零初值响应的零输入与零状态分解
本卷实例
  • 关键一步：把给定响应写成零状态响应与零输入响应之和
  • 中间结果：零输入分量由c(0)与ċ(0)确定两个指数项系数
  • 卡点：初值判断错会导致零状态响应提取错误
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过含非零初值响应的零输入与零状态分解
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上
公式
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由阶跃响应求闭环传函
本卷实例
  • 关键一步：对零状态单位阶跃响应作拉氏变换再乘s
  • 中间结果：传函分母由两个衰减指数对应的一阶极点构成
  • 卡点：单位阶跃响应乘s才是闭环传函反变换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由阶跃响应求闭环传函
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

4四、参数根轨迹与振荡K范围15 分#

思路
  • 把特征方程整理成1加K(s+1)除以s平方(s+10)等于零的等效开环形式，按180度根轨迹绘制法则画根轨迹，再由过渡过程为振荡对应复极点区间求K范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 由特征方程整理等效开环并画根轨迹
本卷实例
  • 关键一步：把含K项提到分子，写成1加K G0(s)等于零
  • 中间结果：等效开环有重极点0、极点-10与零点-1
  • 卡点：渐近线条数为极点数减零点数，勿数错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过由特征方程整理等效开环并画根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹分离点及对应K值
本卷实例
  • 关键一步：由分离点方程求坐标并筛选在根轨迹上的解
  • 中间结果：两个分离点均落在实轴根轨迹段内
  • 卡点：分离点处K由幅值条件回代求
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹分离点及对应K值
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹判断过渡过程为振荡的K范围
本卷实例
  • 关键一步：振荡对应闭环极点为离开实轴的共轭复根
  • 中间结果：由分离点与另一分界点把K范围分成两段
  • 卡点：K范围可能两段，勿只取靠近原点的一段
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹判断过渡过程为振荡的K范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

与虚轴的交点及临界参数 根轨迹法
本卷考法

本卷考法

  • 卡点：提升型别后需重新检查闭环稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计串联校正Gcr(s)使阶跃跟踪误差为零

常见易错

  • 把增加积分环节的影响单一化，忽略超调

思路

本卷考法
  • 由采样系统信号流图求闭环脉冲传函
本卷实例
