1一、用梅森公式求闭环传递函数15 分#

思路
  • 读结构图数独立回路与前向通路，写出特征式与各前向通路的余子式，再用梅森增益公式合并得闭环传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求C(s)/R(s)
本卷实例
  • 关键一步：先数回路写特征式，再逐个前向通路求余子式
  • 中间结果：多条回路两两接触，特征式不含二次修正项
  • 卡点：结构图以原卷插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路的余子式找漏或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 含交叉反馈的多回路结构图化简
本卷实例
  • 关键一步：从最内层反馈环开始等效再逐层向外合并
  • 中间结果：合并后分母含各独立回路增益之和
  • 卡点：比较点与引出点的位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过含交叉反馈的多回路结构图化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过局部反馈化简时漏掉外环的影响
  • 化简内环时把外环的信号当成常数处理
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 串联并联与反馈的等效
本卷实例
  • 关键一步：把并联支路相加后再套用反馈公式
  • 中间结果：四条前向通路中有一条经过反馈支路
  • 卡点：各支路走向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过串联并联与反馈的等效
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过负反馈的分母写成1减回路增益
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、电网络与机械系统相同数学模型15 分#

思路
  • 分别对电网络用复阻抗法、对机械系统列力平衡方程，求出各自的传递函数，再化为同一标准形式比较系数，说明两者数学模型相同。
机械系统建模 建模与机电系统
本卷考法
  • 机械系统列运动方程求传递函数
本卷实例
  • 关键一步：分别对两个质量块列力平衡方程
  • 中间结果：机械系统传函的分母同电网络形式一致
  • 卡点：机械系统以原卷插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过机械系统列运动方程求传递函数
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 本卷考过两质量块相互作用力的反作用项漏写
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 电网络用复阻抗法求传递函数
本卷实例
  • 关键一步：用复阻抗分压写输出电压与输入电压之比
  • 中间结果：整理后分子分母均为两个一阶环节的乘积
  • 卡点：电路以原卷插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过电网络用复阻抗法求传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 本卷考过含电容分压时把阻抗关系写反
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

由电路或机械系统求传递函数 传递函数
本卷考法
  • 由电路或机械系统求传函并比较
本卷实例
  • 关键一步：把两个子系统的传函化为同一标准形式再比较系数
  • 中间结果：对应系数相等即可判定两系统数学模型相同
  • 卡点：各元件参数与连接方式需回原卷核对

步骤

  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由电路或机械系统求传函并比较
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数

  • 复阻抗法把电容阻抗误写成 Cs

3三、心脏起搏器二阶系统参数与心速响应15 分#

思路
  • 由结构图求闭环传函并化为二阶标准形式，按给定阻尼比反解起博器增益；再由阻尼比与自然频率求接通后某时刻心速与瞬时最大心速。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由结构图化为二阶标准形式
本卷实例
  • 关键一步：写出闭环传函并化为标准二阶形式
  • 中间结果：由给定阻尼比反解起博器增益
  • 卡点：反馈环与积分环节的连接方式需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由结构图化为二阶标准形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过未把s平方项系数归一化就套标准式
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率求心速响应
本卷实例
  • 关键一步：按欠阻尼二阶系统的指标计算稳态值与峰值
  • 中间结果：把期望心速折算为输入信号的幅值
  • 卡点：心速单位与时间点需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率求心速响应
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过峰值时间与上升时间混用
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

4四、反应堆位置控制系统稳定K与τ范围15 分#

思路
  • 由结构图写闭环特征方程，列劳斯表求功率放大器增益的稳定范围；再把传感器传函代入特征方程，重新列劳斯表求时间常数τ的稳定范围。
参数稳定域的确定 稳定性分析
本卷考法
  • 求使系统稳定的功率放大器增益K范围
本卷实例
  • 关键一步：由结构图写闭环特征方程并列劳斯表
  • 中间结果：首列各元素同号给出K的上下界
  • 卡点：结构图与增益换算系数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求使系统稳定的功率放大器增益K范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 本卷考过整理不等式时漏掉某个首列元素
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求传感器时间常数τ范围
本卷实例
  • 关键一步：把传感器传函代入特征方程后重新列劳斯表
  • 中间结果：τ的稳定域由首列各不等式联立给出
  • 卡点：传感器时间常数的取值需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求传感器时间常数τ范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过把时间常数当作增益直接代入首列
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
