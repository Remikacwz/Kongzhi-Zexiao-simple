1一、质量弹簧阻尼系统建模与状态空间#

思路
  • 对质量块用牛顿第二定律列写运动微分方程，拉氏变换求Y(s)/F(s)；再按单位负反馈闭环关系由Φ(s)反求开环G0(s)；最后取位移与速度作状态变量列状态空间表达式。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由弹簧质量阻尼系统列运动方程求Y(s)/F(s)
本卷实例
  • 关键一步：对质量块列牛顿第二定律，弹簧力与阻尼力按位移速度反号
  • 中间结果：拉氏变换后分母为ms平方加f1倍s加k1加k2
  • 卡点：两弹簧并接在质量块同一侧，劲度系数直接相加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由弹簧质量阻尼系统列运动方程求Y(s)/F(s)
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

串联、并联与反馈等效 结构图与方框图

本卷实例

  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、含初值的二阶系统全响应与衰减振荡#

思路
  • 由闭环传函写系统微分方程，用带初值的拉氏变换分出零状态与零输入响应求单位阶跃全响应；再将分母与二阶标准形式对照，由阻尼比小于1求k范围。
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由微分方程与初始条件求含自由分量的阶跃全响应
本卷实例
  • 关键一步：对方程作带初值的拉氏变换，把初值项移到方程右端
  • 中间结果：C(s)分成零状态项与由位移初值和速度初值决定的零输入项
  • 卡点：拉氏变换时勿漏位移初值与速度初值带来的常数项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由微分方程与初始条件求含自由分量的阶跃全响应
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 第(2)问由闭环特征式求阻尼比小于1的k范围
本卷实例
  • 关键一步：把分母与标准式对照，由一次项系数读出二倍ξωn
  • 中间结果：ωn平方等于2k，二倍ξωn等于3
  • 卡点：衰减振荡对应阻尼比在0与1之间，解出的是k下界
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过第(2)问由闭环特征式求阻尼比小于1的k范围
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

3三、结构图求闭环传递函数#

思路
  • 把结构图改画为信号流图，找出全部独立回路与从R到C的前向通路，用梅森增益公式求Φ(s)=C(s)/R(s)。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图找回路与前向通路用梅森公式求C(s)/R(s)
本卷实例
  • 关键一步：先数独立回路求特征式，再数R到C的前向通路及余子式
  • 中间结果：三条回路两两相交，特征式为1减三条回路增益之和
  • 卡点：有一条前向通路增益为1，容易漏数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图找回路与前向通路用梅森公式求C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 用结构图逐层化简法求多回路系统的闭环传函
本卷实例
  • 关键一步：从最内层反馈环开始等效，再向外逐层合并
  • 中间结果：化简后分母出现1加2倍G1加G1G2
  • 卡点：比较点与引出点位置需回原卷核对结构图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过用结构图逐层化简法求多回路系统的闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

4四、由对数幅频曲线反求传函并求稳态输出#

思路
  • 由对数幅频渐近曲线的低频段斜率判型别、由低频段高度与转折频率定增益和时间常数，反求开环传函；再求闭环频率特性，代入正弦输入频率得稳态输出幅值与相移。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频渐近曲线反求最小相位系统开环传函
本卷实例
  • 关键一步：由低频段斜率定型别，由高度定增益、转折频率定时间常数
  • 中间结果：曲线对应一个积分环节串联一个惯性环节
  • 卡点：转折频率读数需回原卷核对曲线图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频渐近曲线反求最小相位系统开环传函
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由闭环频率特性求正弦输入的稳态输出
本卷实例
  • 关键一步：稳态幅值为输入幅值乘闭环幅频，相位为输入相位加闭环相频
  • 中间结果：只需把输入角频率代入闭环频率特性求模与相角
  • 卡点：应代入闭环频率特性而非开环，容易混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由闭环频率特性求正弦输入的稳态输出
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

5五、稳态误差与根轨迹#

思路
  • 第(1)问先由劳斯判据求稳定增益上界，再求静态速度误差系数并把误差上限化成增益下界；第(2)问以k为参变量按绘制法则画根轨迹，求渐近线、分离点、出射角与虚轴交点。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 第(1)问Ⅰ型系统单位斜坡输入下由误差要求反求增益范围
本卷实例
  • 关键一步：先判稳，再由sG(s)在s趋于0的极限求速度误差系数
  • 中间结果：速度误差系数为k比6，误差上限化成对k的不等式
  • 卡点：未判稳直接用终值定理会漏掉稳定上界
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过第(1)问Ⅰ型系统单位斜坡输入下由误差要求反求增益范围

  • 连续环节串联时若中间没有采样开关，不能直接相乘

  • 本卷考过由含零阶保持器的采样结构图求开环脉冲传函

10十、能控能观判别与能控性分解#

思路
  • 分别构造能控性矩阵与能观性矩阵并求秩，判定系统不完全能控、完全能观后，按能控性分解并写出能控子系统的状态空间表达式。
能控性与能观性 状态空间分析
本卷考法
  • 判别能控性与能观性并对不完全能控系统作能控性分解
本卷实例
  • 关键一步：构造能控阵B、AB、A平方B与能观阵并分别求秩
  • 中间结果：能控阵秩小于3故不完全能控，能观阵满秩
  • 卡点：分解时补齐的列向量要与已选列线性无关
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判别能控性与能观性并对不完全能控系统作能控性分解
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
