1一、一阶系统含零点的动态性能指标15 分#

思路
  • 由微分方程写传函，用部分分式求单位阶跃响应，再按定义求上升时间、调节时间与延迟时间。
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 求一阶系统单位阶跃响应的上升时间与调节时间
本卷实例
  • 关键一步：先由稳态值的10%与90%两点解出上升时间
  • 中间结果：响应含稳态项与一个指数衰减项，时间常数仍为T
  • 卡点：零点使响应有跳跃，不能直接套无零点的一阶公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过求一阶系统单位阶跃响应的上升时间与调节时间
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
零极点分布与响应模态 传递函数
本卷考法
  • 由传函零点判断阶跃响应起点的跳变
本卷实例
  • 关键一步：分子含一阶微分项，对应输出含输入的比例加微分分量
  • 中间结果：响应起点由分子与分母常数项之比决定
  • 卡点：零点位置影响响应起点但不改变时间常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由传函零点判断阶跃响应起点的跳变
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零
公式

2二、位置随动系统结构图与传函15 分#

思路
  • 由原理方块图逐个环节写传函，按信号流向画结构图，再用结构图化简求闭环传递函数。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指认位置随动系统的被控量、检测元件与执行元件并画结构图
本卷实例
  • 关键一步：按给定转角、电位器误差、放大、电机与测速反馈列环节
  • 中间结果：系统为角度随动，反馈量取测速发电机输出电压
  • 卡点：被控量与操纵量别搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指认位置随动系统的被控量、检测元件与执行元件并画结构图
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
直流电机等机电系统 建模与机电系统
本卷考法
  • 由直流电机与测速发电机求机电系统传函
本卷实例
  • 关键一步：忽略电枢电感，电机近似为一阶惯性环节
  • 中间结果：电机传函为比例系数除以时间常数乘s加1，测速机为比例环节
  • 卡点：机电时间常数与电气时间常数别混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由电枢回路电压方程与转矩平衡方程联立
  • 反电动势与转速成正比，电磁转矩与电枢电流成正比
  • 机电时间常数由电气与机械两方面参数共同决定
步骤
  • 写出电枢回路电压平衡方程
  • 写出转矩平衡方程（含负载与粘性摩擦）
  • 消去电枢电流，得到转速或转角对电压的传递函数
通用考法
  • 本卷考过由直流电机与测速发电机求机电系统传函
  • 求直流电机转速或位置对电枢电压的传递函数
  • 分析机电时间常数与电气时间常数的数量级关系
常见易错
  • 漏掉反电动势与电磁转矩的耦合项
  • 把电气时间常数与机电时间常数混淆
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 把多环节结构图逐层化简求闭环传函
本卷实例
  • 关键一步：先合并局部反馈成等效环节，再套总反馈公式
  • 中间结果：闭环分母出现时间常数乘s平方与一次项、常数项
  • 卡点：测速反馈极性为负，分母一次项系数为正
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过把多环节结构图逐层化简求闭环传函
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式

3三、由阶跃响应反求系统参数15 分#

思路
  • 由结构图写闭环传函，利用稳态位置误差为零确定积分环节个数，再由稳态值确定增益，最后由响应形式定时间常数。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应曲线反求系统参数
本卷实例
  • 关键一步：先由响应稳态值读闭环增益，再由响应形状判断积分与时间常数
  • 中间结果：型别由稳态误差为零反推，时间常数由极点位置反推
  • 卡点：响应曲线需回原卷核对读数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应曲线反求系统参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由稳态位置误差为零确定积分环节个数
本卷实例
  • 关键一步：对阶跃输入稳态误差为零要求系统型别不低于1
  • 中间结果：误差传函含s的型别次幂因子
  • 卡点：型别取值由误差条件给出，不能凭空取1
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由稳态位置误差为零确定积分环节个数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由阶跃响应与误差要求联立确定系统参数
本卷实例
  • 关键一步：用终值定理把误差为零与输出稳态值写成两个方程
  • 中间结果：联立后可定出增益与型别的组合
  • 卡点：增益与型别存在两组可能的组合，需说明参数不能唯一定值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由阶跃响应与误差要求联立确定系统参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式

4四、四阶系统根轨迹与衰减振荡范围15 分#

思路
  • 按绘制法则画四阶系统根轨迹，求实轴段、渐近线、分离点、出射角与虚轴交点；再由闭环出现一对共轭复根的条件求K*范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制四阶系统闭环根轨迹
本卷实例
  • 关键一步：先标出四个开环极点并判断实轴上的根轨迹段
  • 中间结果：四条渐近线交于极点实部均值，夹角为四等分方向
  • 卡点：复极点对的出射角要单独用相角条件求
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制四阶系统闭环根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点与会合点
本卷实例
  • 关键一步：由根轨迹增益对s求导为零得分离点方程
  • 中间结果：实轴上的那个根是实际分离点
  • 卡点：另两个共轭根不在根轨迹上，要舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点与会合点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
出射角与入射角 根轨迹法
本卷考法
  • 求复数开环极点的出射角
本卷实例
  • 关键一步：用相角条件累加其余零极点的相角，不把自己算进去
  • 中间结果：两个复极点的出射角关于实轴对称
  • 卡点：累加时该极点自身的相角要排除
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求复数开环极点的出射角
  • 求复数极点的出射角
  • 根据出射角画出根轨迹起始方向
  • 由入射角确定根轨迹终止方向
常见易错
  • 累加相角时把该极点自身的相角也算进去
  • 忘记判断象限导致角度差 180°
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴的交点及临界增益
本卷实例
  • 关键一步：令s等于jω代入特征方程，实部与虚部分别为零
  • 中间结果：由虚部方程解出交点频率，由实部方程解临界增益
  • 卡点：ω为零的根对应分离点，不是稳定性边界
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴的交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益

  • 卡点：增益分量顺序要与状态变量顺序对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过配置闭环极点求状态反馈增益阵
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反

思路
  • 先按输出阵构造变换阵把系统分为可观测与不可观测部分，对可观测子系统配置极点到给定位置设计降维观测器，再变换回原坐标写观测器方程。
能控性与能观性 状态空间分析
本卷考法
  • 构造能观性矩阵并判断能否设计降维观测器
本卷实例
  • 关键一步：按输出阵及它乘状态矩阵各次幂构造能观性矩阵并求秩
  • 中间结果：输出阵秩为1，观测器维数为系统阶数减1
  • 卡点：降维观测器维数由系统阶数减输出阵秩确定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过构造能观性矩阵并判断能否设计降维观测器
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 分析观测器与状态反馈组合后的系统极点
常见易错
  • 把观测器增益阵写成了状态反馈增益阵的形式
