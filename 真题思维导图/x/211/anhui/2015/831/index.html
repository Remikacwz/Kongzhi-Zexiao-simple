安徽大学 831 控制原理 2015 年真题思维导图

211 院校共 10 题合计 150 分

难度：中等　全卷十题每题15分，依次为多输入结构图求输出、由结构与阶跃响应图求闭环传函、含初值的二阶系统全响应、斜坡与扰动同时作用下的稳态误差、根轨迹绘制与无超调K范围、由幅频相位条件反求开环传函、由对数幅频曲线反求传函与相角裕度、由开环传函画幅相曲线并用奈氏判据判稳、复合控制前馈补偿器设计、采样系统稳态误差与稳定T范围。均为计算题，无选择填空；第1、2、4、7、8、9、10题含原卷插图，卷面每题头印15分。

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

1一、多输入结构图求输出15 分#

思路
  • 分别把参考输入与扰动输入单独作用，用梅森增益公式求R到C与N到C两条传函，再按线性叠加写出总输出C(s)。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由图1结构图找回路与前向通路求C(s)/R(s)与C(s)/N(s)
本卷实例
  • 关键一步：先数全部独立回路写特征式，再数每个输入到输出的前向通路
  • 中间结果：有两条回路不相接触，特征式需加不接触回路增益乘积
  • 卡点：不接触回路容易漏计，结构图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由图1结构图找回路与前向通路求C(s)/R(s)与C(s)/N(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • R(s)与N(s)同时作用时分别求两条通道传函再叠加
本卷实例
  • 关键一步：求任一通道时把另一输入置零，最后代数相加
  • 中间结果：总输出等于两条通道传函分别乘各自输入之和
  • 卡点：不能把两个输入当作一条前向通路直接相加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过R(s)与N(s)同时作用时分别求两条通道传函再叠加
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简
本卷实例
  • 关键一步：从最内层反馈环开始等效，再向外层合并
  • 中间结果：化简后分母为1加回路增益加不接触修正项
  • 卡点：比较点与引出点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2二、由结构与阶跃响应图求闭环传函15 分#

思路
  • 把结构图化为闭环形式，再由单位阶跃响应曲线的稳态值、超调量和峰值时间读出增益、阻尼比与无阻尼自然频率。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由结构图与阶跃响应曲线(a)(b)反求闭环传函
本卷实例
  • 关键一步：先由稳态值定增益，再由超调量定阻尼比、由峰值时间定自然频率
  • 中间结果：响应为欠阻尼二阶，曲线第一个峰对应峰值时间
  • 卡点：曲线读数与结构图参数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由结构图与阶跃响应曲线(a)(b)反求闭环传函
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为二阶标准形式求ωn与ξ
本卷实例
  • 关键一步：比较分母一次项得二倍ξωn，比较常数项得ωn平方
  • 中间结果：两个方程联立解出阻尼比与自然频率
  • 卡点：先把s平方项系数归一化再对照标准式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为二阶标准形式求ωn与ξ
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 用超调量与峰值时间求二阶动态指标
本卷实例
  • 关键一步：由超调量公式反解阻尼比，再由峰值时间公式解自然频率
  • 中间结果：过阻尼时无峰值，需先判断响应类型
  • 卡点：超调量公式中不要漏乘百分之百
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过用超调量与峰值时间求二阶动态指标
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3三、含初值的二阶系统全响应15 分#

思路
  • 第(1)问对传函做部分分式反变换求脉冲与阶跃响应；第(2)问对微分方程作带初值的拉氏变换，分离零状态与零输入分量后反变换。
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 第(2)问由闭环传函与初值c(0)=-1、ċ(0)=0求阶跃全响应
本卷实例
  • 关键一步：对微分方程作带初值拉氏变换，把初值项移到方程右端
  • 中间结果：C(s)由零状态项与由两个初值决定的零输入项组成
  • 卡点：带初值变换勿漏位移初值与速度初值的常数项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过第(2)问由闭环传函与初值c(0)=-1、ċ(0)=0求阶跃全响应
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上
公式
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 第(1)问由闭环传函求单位脉冲与单位阶跃响应
本卷实例
  • 关键一步：脉冲响应直接对传函反变换，阶跃响应再乘1/s
  • 中间结果：分母可分解为两个一阶实极点，部分分式逐项反变换
  • 卡点：脉冲响应不用再乘输入拉氏变换，勿多做一步
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过第(1)问由闭环传函求单位脉冲与单位阶跃响应
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
零极点分布与响应模态 传递函数
本卷考法
  • 由极点分布判断响应模态
本卷实例
  • 关键一步：两个负实极点对应两个衰减指数项
  • 中间结果：全响应为稳态值加两个衰减模态的线性组合
  • 卡点：零输入与零状态分量分别求再叠加，不要混在一式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由极点分布判断响应模态
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

4四、输入与扰动同时作用的稳态误差15 分#

思路
  • 先判稳，再分别求参考输入与扰动输入到误差的传递函数，用终值定理求各自误差分量后叠加。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • r(t)=t·1(t)作用下的稳态误差分量
本卷实例
  • 关键一步：先判稳，再由误差传函求终值
  • 中间结果：斜坡输入误差由速度误差系数决定
  • 卡点：未判稳不能直接用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过r(t)=t·1(t)作用下的稳态误差分量
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • n(t)=0.3·1(t)作用下的扰动误差分量
本卷实例
  • 关键一步：求扰动到误差的传函时把参考输入置零
  • 中间结果：扰动误差分量在s趋于0处的极限
  • 卡点：扰动通道不能漏，否则总误差偏小
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过n(t)=0.3·1(t)作用下的扰动误差分量
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 两个输入同时作用时按线性叠加求总误差
本卷实例
  • 关键一步：分别算两个分量后在时域相加
  • 中间结果：总误差为输入误差与扰动误差的代数和
  • 卡点：结构图需回原卷核对图

  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加

  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
