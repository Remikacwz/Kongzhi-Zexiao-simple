211 院校共 10 题合计 150 分

1一、机械系统建模与阶跃响应求参数15 分#

思路
  • 先由物块受力分析列运动微分方程并整理为二阶标准形式，再由阶跃响应曲线的峰值时间与超调量求阻尼比、自然频率，最后分离出质量、弹簧刚度与阻尼系数。
机械系统建模 建模与机电系统
本卷考法
  • 由阶跃力作用下的响应曲线求机械系统参数
本卷实例
  • 关键一步：先由受力分析列物块的运动微分方程
  • 中间结果：整理成二阶系统标准形式后由稳态值定弹簧刚度
  • 卡点：响应曲线以原卷插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过由阶跃力作用下的响应曲线求机械系统参数
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 本卷考过阻尼力与弹簧力的正负方向取反
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项

  • 卡点：曲线上的峰值与稳态读数需回原卷核对图

2二、结构图求闭环传递函数15 分#

思路
  • 读结构图数独立回路与前向通路，用梅森增益公式写特征式与各余子式，合并得闭环传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求C(s)/R(s)
本卷实例
  • 关键一步：先数回路写特征式，再逐个前向通路求余子式
  • 中间结果：三条回路两两接触，特征式不含二次修正项
  • 卡点：结构图以原卷插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路的余子式找漏或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

多回路系统的逐层化简 结构图与方框图
本卷考法

  • 每个内环先化成一个等效环节，再参与外层的串并联

串联、并联与反馈等效 结构图与方框图
本卷考法
  • 串联并联与反馈的等效
本卷实例
  • 关键一步：把并联支路相加后再套用反馈公式
  • 中间结果：有增益为1的直通支路时易漏数
  • 卡点：直通支路走向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 分别套用串联、并联或反馈等效公式

通用考法

3三、根轨迹绘制与衰减振荡K值15 分#

思路
  • 按根轨迹法则求渐近线、分离点、出射角与虚轴交点并作图；再由阻尼比小于1的条件确定衰减振荡对应的开环增益，并判断是否存在单调运动。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则概略绘制根轨迹
本卷实例
  • 关键一步：先标开环零极点再定实轴段与渐近线
  • 中间结果：四条开环极点两条复数极点，出射角按相角条件求
  • 卡点：根轨迹形状需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则概略绘制根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴段判据中零极点个数算错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

4四、奈氏曲线判稳与动态性能及正弦稳态误差15 分#

思路
  • 由奈氏曲线上的已知点识别闭环二阶系统参数，按欠阻尼指标求最大输出与阶跃稳态误差；再用频率特性对正弦输入求稳态误差。
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅相曲线判断闭环稳定
本卷实例
  • 关键一步：按P与包围圈数判闭环稳定
  • 中间结果：曲线与负实轴的交点给出稳定边界
  • 卡点：奈氏曲线以原卷插图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环幅相曲线判断闭环稳定
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 本卷考过先数开环右半平面极点数再判包围，顺序颠倒
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

闭环频率特性与性能指标 频域分析
本卷考法
  • 由闭环幅频特性求谐振峰值与动态指标
本卷实例
  • 关键一步：由曲线上已知频率点的幅相识别闭环传函形式
  • 中间结果：再由二阶系统关系估算谐振峰值与超调量
  • 卡点：曲线标注的频率与幅值需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
