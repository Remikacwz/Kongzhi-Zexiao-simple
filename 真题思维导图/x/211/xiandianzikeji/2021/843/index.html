1一、单项选择题：基本概念与典型环节20 分#

思路
  • 20 分 10 小题逐题辨析控制系统基本概念、典型环节作用与稳定性判据，抓定义与结论的反例。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断控制系统正常工作的前提及开环不稳定时闭环的稳定性
本卷实例
  • 关键一步：明确稳定性是所有性能分析的前提
  • 中间结果：开环稳定与闭环稳定之间没有必然联系
  • 卡点：负反馈可能使开环不稳定系统稳定，也可能不能
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断控制系统正常工作的前提及开环不稳定时闭环的稳定性
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
典型输入信号 基本概念与信号
本卷考法
  • 判断脉冲、阶跃、斜坡、加速度信号之间的积分关系
本卷实例
  • 关键一步：按阶次由低到高理清典型输入信号的关系
  • 中间结果：斜坡响应等于阶跃响应的积分
  • 卡点：传递函数是单位脉冲响应的拉氏变换，不是阶跃响应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 常用典型输入有冲激、阶跃、斜坡、抛物线（加速度）与正弦五类
  • 阶跃信号用于考查快速性与稳定性，斜坡与抛物线用于考查稳态精度
  • 正弦信号用于频域分析，冲激响应就是系统的传递函数
  • 各典型信号的拉氏变换是分析全响应的起点
步骤
  • 按题意写出输入信号的时域表达式
  • 对输入取拉氏变换得到该信号的复域形式
  • 由输入类型判断考查的是动态性能还是稳态精度
  • 把输入代入误差或响应公式计算
通用考法
  • 本卷考过判断脉冲、阶跃、斜坡、加速度信号之间的积分关系
  • 写出典型输入信号的拉氏变换
  • 说明某一典型输入信号用于考查哪类性能
  • 由输入类型判断稳态误差是否为有限值
常见易错
  • 把斜坡与抛物线信号的阶次写错
  • 阶跃的拉氏变换漏掉系数（幅度不为 1 时）

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传递函数化为标准二阶形式求自然频率
本卷实例
  • 关键一步：先把二次项系数归一为 1
  • 中间结果：常数项开方给出自然频率
  • 卡点：分子上的开环增益不影响阻尼比与自然频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传递函数化为标准二阶形式求自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

滞后校正 系统校正
本卷考法
  • 由滞后校正网络传函的系数关系判断参数取值
本卷实例
  • 关键一步：比较分子与分母一次项系数的大小
  • 中间结果：分子一次项系数小于分母时网络呈滞后特性
  • 卡点：参数取值范围要与滞后网络定义对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过由滞后校正网络传函的系数关系判断参数取值
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

减小稳态误差的措施 稳态误差
本卷考法
  • 指出能有效消除稳态误差的典型环节
本卷实例
  • 关键一步：按能否提高系统型别来判断
  • 中间结果：积分环节可提高型别从而消除稳态误差
  • 卡点：比例、微分环节不改变系统型别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过指出能有效消除稳态误差的典型环节
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式
用描述函数法分析自振 非线性系统
本卷考法
  • 判断极限环频率与幅值分别由哪条曲线的交点给出
本卷实例
  • 关键一步：分清负倒描述函数与线性环节幅相曲线
  • 中间结果：振荡频率由线性环节对应交点频率确定
  • 卡点：振幅由非线性负倒曲线交点处振幅确定，勿混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过判断极限环频率与幅值分别由哪条曲线的交点给出
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率

思路

高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 判断增加一个闭环极点对超调量与调节时间的影响
本卷实例
  • 关键一步：按新增极点距虚轴远近分主导与非主导
  • 中间结果：靠近虚轴的极点使超调与调节时间增大
  • 卡点：远离虚轴的极点可用主导极点法近似忽略
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过判断增加一个闭环极点对超调量与调节时间的影响
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

频率特性的物理意义与求法 频域分析
本卷考法
  • 说明三频段与闭环系统性能的对应关系
本卷实例
  • 关键一步：按低频、中频、高频逐段判断
  • 中间结果：低频段定稳态误差、中频段定动态性能
  • 卡点：高频段反映抗高频干扰能力，勿混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过说明三频段与闭环系统性能的对应关系
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式

本卷考法
  • 判断静态误差系数法计算稳态误差的适用条件
本卷实例

  • 中间结果：稳态误差只与输入幅值及开环增益有关
  • 卡点：未判稳就套误差系数法会得到错误结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

通用考法
  • 本卷考过判断静态误差系数法计算稳态误差的适用条件
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

根轨迹的绘制法则 根轨迹法
本卷考法
  • 指出具有工程意义的根轨迹基本法则
本卷实例
  • 关键一步：区分实轴段、渐近线、分离点与虚轴交点
  • 中间结果：先由实轴段与渐近线定走向再算特殊点
  • 卡点：不要漏掉起点终点法则的作用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过指出具有工程意义的根轨迹基本法则
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

反馈校正与复合控制 系统校正
本卷考法
  • 判断局部反馈校正的特点与校正效果
本卷实例
  • 关键一步：按减小时间常数、降低参数敏感度逐项判断
  • 中间结果：局部反馈提高稳定性但会降低增益
  • 卡点：选错误项时注意增益是升是降
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件

通用考法
  • 本卷考过判断局部反馈校正的特点与校正效果
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

离散系统的动态性能与极点分布 离散控制系统
本卷考法
  • 由采样系统的极点分布判断暂态性能
本卷实例
  • 关键一步：把极点模与 1 比较并看象限
  • 中间结果：单位圆上的极点对应等幅振荡
  • 卡点：极点位于第二、三象限是连续系统的结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点在 z 平面上的位置决定响应形式
  • 极点越靠近原点衰减越快，越靠近单位圆振荡越强
  • 极点的幅角决定振荡频率，幅值决定衰减速度
  • 采样周期增大会使动态性能变差甚至不稳定
步骤

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）

  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg

  • 由裕度符号判断稳定性
