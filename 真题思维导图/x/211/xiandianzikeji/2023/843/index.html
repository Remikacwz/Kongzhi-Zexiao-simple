1一、填空题：概念与典型特性22 分#

思路
  • 8 小空逐空查概念：网络类型判定、主导极点与偶极子、相轨迹形状、带宽与谐振峰值、采样定理、校正环节作用与典型非线性。
滞后校正 系统校正
本卷考法
  • 由校正网络传函的系数关系判断是否滞后校正
本卷实例
  • 关键一步：比较分子与分母一次项系数的大小
  • 中间结果：分子一次项系数小于分母即为滞后网络
  • 卡点：滞后与超前只看两转折频率的相对大小
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过由校正网络传函的系数关系判断是否滞后校正
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法

本卷实例

  • 中间结果：相距很近的零极点对构成偶极子
  • 卡点：偶极子对响应影响小但不能当作完全抵消
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤

  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法

  • 说明某极点能否忽略的理由

闭环频率特性与性能指标 频域分析
本卷考法
  • 判断带宽与谐振峰值对平稳性的影响方向
本卷实例
  • 关键一步：由闭环幅频特性看谐振峰高低
  • 中间结果：谐振峰值越大平稳性越差
  • 卡点：带宽增大提高快速性但抗噪性下降
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过判断带宽与谐振峰值对平稳性的影响方向
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

采样过程与香农采样定理 离散控制系统
本卷考法
  • 由信号最高频率确定等周期采样周期
本卷实例
  • 关键一步：按采样定理取采样角频率大于两倍最高频率
  • 中间结果：采样周期需小于最高频率对应周期的一半
  • 卡点：两倍关系是大于等于，等号临界不实用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过由信号最高频率确定等周期采样周期
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

滞后-超前校正 系统校正
本卷考法
  • 列举滞后-超前校正的积极作用
本卷实例
  • 关键一步：分别指出滞后段改善稳态、超前段改善动态
  • 中间结果：两段转角频率错开时互不削弱
  • 卡点：两段转角若重叠会互相抵消作用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 兼顾稳态精度与动态性能，适合指标要求较高的场合
  • 低频段用滞后部分提高增益，中高频段用超前部分提高裕度
  • 设计时先确定超前部分，再确定滞后部分
步骤
  • 按稳态精度要求确定开环增益
  • 选择新的截止频率并计算超前部分参数
  • 计算为把低频增益抬到要求值所需的滞后部分参数
  • 合并写出校正装置并校验
通用考法
  • 本卷考过列举滞后-超前校正的积极作用
  • 设计滞后-超前校正装置
  • 说明为何单一校正无法满足指标
  • 分析校正后系统的低频与高频特性
常见易错
  • 先设计滞后部分导致截止频率反复调整
  • 两部分的转折频率分布重叠，互相削弱

典型非线性特性及其影响 非线性系统
本卷考法
  • 绘制至少三类本质非线性特性的输入输出关系图
本卷实例
  • 关键一步：列出饱和、死区、间隙等典型特性
  • 中间结果：各特性均以分段折线表示
  • 卡点：图上要标清坐标轴，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 饱和特性降低等效增益，可能引起系统不稳定或自振
  • 死区特性使小信号时增益为零，产生稳态误差
  • 间隙特性引起相位滞后，导致波形畸变与自振
  • 继电特性使系统出现持续振荡并可能产生颤振
步骤
  • 识别非线性环节类型
  • 写出其描述函数或分段数学表达式
  • 分析其对等效增益与稳定性的影响
通用考法
  • 本卷考过绘制至少三类本质非线性特性的输入输出关系图
  • 分析饱和或死区对系统性能的影响
  • 求典型非线性的描述函数表达式
  • 说明间隙为何容易引起自振
常见易错
  • 认为饱和总是使系统更稳定
  • 忽略死区在原点附近造成的小信号失效

PID 控制器与参数整定 系统校正
本卷考法
  • 画出用有源网络实现的 PID 校正装置原理图
本卷实例
  • 关键一步：按比例、积分、微分三条并联通路画运放电路
  • 中间结果：输入端三条支路分别对应 P、I、D 作用

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过画出用有源网络实现的 PID 校正装置原理图
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错

  • 积分增益过大导致系统振荡甚至不稳定

思路

本卷考法

  • 判断反馈极性对分母符号的影响
