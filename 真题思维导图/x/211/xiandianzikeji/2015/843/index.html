思路

广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 判断开环传函对应零度根轨迹的相角条件
本卷实例
  • 关键一步：把正反馈结构归到零度根轨迹
  • 中间结果：幅值条件不变、相角条件改为 0 度
  • 卡点：分母出现 (2-s) 一类因子时易与常规根轨迹混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过判断开环传函对应零度根轨迹的相角条件
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

减小稳态误差的措施 稳态误差
本卷考法
  • 指出对提高系统稳定性没有效果的措施
本卷实例
  • 关键一步：按环节对根轨迹走向的作用逐项排除
  • 中间结果：增加开环极点会使根轨迹右弯
  • 卡点：降低开环增益与超前校正均能提高稳定裕度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过指出对提高系统稳定性没有效果的措施
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 辨析负反馈对稳定性与动态性能的作用
本卷实例
  • 关键一步：把系统固有稳定性与扰动响应分开看
  • 中间结果：负反馈不改变系统固有稳定性
  • 卡点：负反馈能抑制扰动但不保证闭环稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过辨析负反馈对稳定性与动态性能的作用
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
闭环频率特性与性能指标 频域分析
本卷考法
  • 由闭环幅频振荡指标判断动态性能变化
本卷实例
  • 关键一步：把谐振峰值与超调量的单调关系对应起来
  • 中间结果：谐振峰值增大对应超调量增大
  • 卡点：谐振峰值同时影响快速性，勿只看单一指标
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过由闭环幅频振荡指标判断动态性能变化
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

采样过程与香农采样定理 离散控制系统
本卷考法

本卷实例

  • 中间结果：附加滞后使相角裕度下降
  • 卡点：保持器不改变采样时刻的幅值关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过判断零阶保持器对采样系统稳定性的影响
  • 由信号最高频率确定采样周期

  • 说明零阶保持器的频率特性
常见易错

  • 忽略零阶保持器带来的相位滞后

2二、双项选择题：稳定性与根轨迹综合20 分#

思路

劳斯判据 稳定性分析
本卷考法
  • 判断增幅振荡系统的稳定性与稳态误差
本卷实例
  • 关键一步：按响应发散判断不稳定
  • 中间结果：不稳定系统的稳态误差无界
  • 卡点：增幅振荡对应发散而非临界稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过判断增幅振荡系统的稳定性与稳态误差
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 判断根轨迹幅值条件与相角条件的作用
本卷实例
  • 关键一步：把相角条件作为根轨迹存在条件
  • 中间结果：相角条件是充要条件、幅值条件定增益
  • 卡点：幅值条件只能求增益，不能判定在轨
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过判断根轨迹幅值条件与相角条件的作用
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

稳定裕度 频域分析
本卷考法
  • 由相角裕度与幅值裕度判断等幅振荡
本卷实例
  • 关键一步：等幅振荡对应相角裕度为 0、幅值裕度为 1
  • 中间结果：幅值裕度用 dB 表示时对应 0 dB
  • 卡点：相角穿越与幅值穿越两个频率勿混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由相角裕度与幅值裕度判断等幅振荡
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

  • 分析采样周期对稳态精度的影响
