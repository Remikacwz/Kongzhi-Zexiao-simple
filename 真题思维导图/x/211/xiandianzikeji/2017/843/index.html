1一、单项选择题：基本概念与频域校正20 分#

思路
  • 10 小题覆盖控制目标、闭环传函、稳态速度误差、根轨迹终点、滞后校正与采样极点。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出控制系统正常工作的首要条件
本卷实例
  • 关键一步：把稳定性放在精度与快速性之前
  • 中间结果：稳定是系统工作的基础
  • 卡点：精度与快速性以稳定为前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指出控制系统正常工作的首要条件
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由单位负反馈开环传函写闭环传函
本卷实例
  • 关键一步：按开环比 1 加开环组合
  • 中间结果：闭环分母为 1 加开环传函
  • 卡点：分子仍为开环传函的分子
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由单位负反馈开环传函写闭环传函
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 说明稳态速度误差的含义
本卷实例
  • 关键一步：从位置误差随时间的变化理解
  • 中间结果：速度误差是位置稳态偏差
  • 卡点：勿把它当成输入与输出的速度差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过说明稳态速度误差的含义
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 判断根轨迹的终止位置
本卷实例
  • 关键一步：根轨迹终止于开环零点或无穷远
  • 中间结果：终点由开环零点个数决定
  • 卡点：起点才是开环极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过判断根轨迹的终止位置
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
滞后校正 系统校正
本卷考法
  • 由滞后校正网络确定参数范围
本卷实例
  • 关键一步：比较分子分母一次项系数
  • 中间结果：分子转折频率高于分母时才滞后
  • 卡点：参数范围是 0 到 1
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过由滞后校正网络确定参数范围
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
稳定裕度 频域分析
本卷考法
  • 由开环传函求相角裕量表达式
本卷实例
  • 关键一步：令幅值为 1 求截止频率
  • 中间结果：相角裕度为 180 度加相角
  • 卡点：积分环节贡献 -90 度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由开环传函求相角裕量表达式
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
离散系统的动态性能与极点分布 离散控制系统
本卷考法
  • 由采样闭环极点判断暂态分量性质
本卷实例
  • 关键一步：比较极点模与 1 并看相角
  • 中间结果：模小于 1 且共轭对应衰减振荡
  • 卡点：采样极点不能直接读阻尼比
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点在 z 平面上的位置决定响应形式
  • 极点越靠近原点衰减越快，越靠近单位圆振荡越强
  • 极点的幅角决定振荡频率，幅值决定衰减速度
  • 采样周期增大会使动态性能变差甚至不稳定
步骤
  • 求闭环脉冲传递函数的极点
  • 按极点在单位圆内的位置判断响应形式
  • 由极点的模与幅角估算衰减与振荡频率
  • 与连续系统指标对应关系相互校验
通用考法
  • 本卷考过由采样闭环极点判断暂态分量性质
  • 由闭环极点分布判断动态性能
  • 与连续域指标互相换算
  • 说明采样周期对动态性能的影响
常见易错
  • 把 z 平面极点当作 s 平面极点直接读阻尼比
  • 忽略单位圆上极点对应等幅振荡
公式

本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

通用考法

常见易错

  • 求扰动传函时没有把参考输入置零

劳斯判据 稳定性分析
本卷考法
  • 判断闭环系统的稳定性类别
本卷实例
  • 关键一步：求闭环极点位置再分类
  • 中间结果：极点均在左半平面为渐近稳定
  • 卡点：输入输出稳定与渐近稳定需区分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过判断闭环系统的稳定性类别
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
