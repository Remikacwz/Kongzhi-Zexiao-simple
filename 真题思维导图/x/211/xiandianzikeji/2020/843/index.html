1一、单项选择题：基本概念与稳定性20 分#

思路
  • 10 小题覆盖负反馈作用、控制理论对象、开环装置、闭环组成、稳定必要条件、稳态精度与广义根轨迹。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断负反馈作用、控制理论对象与组成要素
本卷实例
  • 关键一步：从反馈信息是否回送判断控制方式
  • 中间结果：经典控制理论研究线性定常系统
  • 卡点：测量元件是闭环必不可少的
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断负反馈作用、控制理论对象与组成要素
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
劳斯判据 稳定性分析
本卷考法
  • 判断高阶系统稳定的必要条件与反馈影响
本卷实例
  • 关键一步：特征方程系数同号只是必要条件
  • 中间结果：闭环稳定性看闭环特征根
  • 卡点：开环不稳定时闭环未必不稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过判断高阶系统稳定的必要条件与反馈影响
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

系统型别与静态误差系数 稳态误差
本卷考法
  • 分析稳态精度的决定因素与速度误差含义
本卷实例

  • 中间结果：速度误差指位置随时间的偏差
  • 卡点：型别与输入阶次要匹配
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤

  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过分析稳态精度的决定因素与速度误差含义
  • 判断系统型别

  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈

广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 判断给定开环传函是否对应广义根轨迹
本卷实例
  • 关键一步：参数不只在开环增益位置时属广义
  • 中间结果：广义根轨迹需重排特征方程
  • 卡点：零度与 180 度条件要区分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过判断给定开环传函是否对应广义根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

频率特性的物理意义与求法 频域分析
本卷考法
  • 说明频率响应法特点并求正弦稳态输出
本卷实例
  • 关键一步：频率特性反映对不同频率正弦的响应
  • 中间结果：稳态输出幅值与相角由频率特性定
  • 卡点：先判稳再谈稳态输出
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过说明频率响应法特点并求正弦稳态输出
  • 求给定传递函数的幅频与相频表达式

  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

采样过程与香农采样定理 离散控制系统
本卷考法
  • 由信号最高频率判断采样频率是否可行
本卷实例
  • 关键一步：采样频率须大于最高频率的两倍
  • 中间结果：由最高频率定最低采样频率
  • 卡点：低于两倍会发生频谱混叠
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过由信号最高频率判断采样频率是否可行
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

超前校正 系统校正
本卷考法
  • 列举超前校正的积极作用
本卷实例
  • 关键一步：超前校正提高相角裕度
  • 中间结果：中频段变宽改善平稳性

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤

  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过列举超前校正的积极作用
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

稳定裕度 频域分析
本卷考法
  • 分析增益裕量的性质
本卷实例
  • 关键一步：增益裕量可在开环 Bode 图上读取
  • 中间结果：增益裕量可以为无穷大
  • 卡点：调整时间与增益裕量无直接关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
