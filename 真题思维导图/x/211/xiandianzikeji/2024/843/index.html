1一、直流位置随动系统建模与参数反求20 分#

思路
  • 按电位器、放大器、电机与减速器逐级建立环节传函，画出结构框图并合成开环传函；再由误差电压曲线的初值与峰值超调反求电位器系数、电机增益与时间常数。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出位置随动系统的被控对象、被控量与操纵量并画结构框图
本卷实例
  • 关键一步：按给定轴与输出轴的偏差电压确定比较环节
  • 中间结果：给定、放大、电机、减速器与反馈连成位置闭环
  • 卡点：系统原理图与误差电压曲线需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指出位置随动系统的被控对象、被控量与操纵量并画结构框图
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由各环节传函逐级合成开环传递函数
本卷实例
  • 关键一步：把串联环节相乘并接入单位反馈
  • 中间结果：开环为含减速比与总增益的积分惯性环节
  • 卡点：减速比要按两齿轮齿数之比取
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由各环节传函逐级合成开环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
直流电机等机电系统 建模与机电系统
本卷考法
  • 由电机方程与减速器建立执行机构模型
本卷实例
  • 关键一步：把电机转速与转角关系写成一阶惯性环节
  • 中间结果：减速器使输出角按齿数比缩小
  • 卡点：电机传递系数与时间常数要分别辨认
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由电枢回路电压方程与转矩平衡方程联立
  • 反电动势与转速成正比，电磁转矩与电枢电流成正比
  • 机电时间常数由电气与机械两方面参数共同决定
步骤
  • 写出电枢回路电压平衡方程
  • 写出转矩平衡方程（含负载与粘性摩擦）
  • 消去电枢电流，得到转速或转角对电压的传递函数
通用考法
  • 本卷考过由电机方程与减速器建立执行机构模型
  • 求直流电机转速或位置对电枢电压的传递函数
  • 分析机电时间常数与电气时间常数的数量级关系
常见易错
  • 漏掉反电动势与电磁转矩的耦合项
  • 把电气时间常数与机电时间常数混淆

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征方程化为标准二阶形式求阻尼比与自然频率
本卷实例
  • 关键一步：把闭环特征方程的二次项系数归一
  • 中间结果：一次项与常数项分别给出阻尼比和自然频率
  • 卡点：开环增益与减速比会同时影响自然频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征方程化为标准二阶形式求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由误差电压曲线的峰值与稳态值反求二阶参数
本卷实例
  • 关键一步：由曲线读出稳态值与峰值算超调量
  • 中间结果：由超调量反解阻尼比再联合自然频率求参数
  • 卡点：曲线峰值电压与输出角度需按电位器系数换算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由误差电压曲线的峰值与稳态值反求二阶参数
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

2二、PD控制器参数平面的稳定域与阻尼分区15 分#

思路
  • 先由结构图求闭环特征方程，用劳斯判据写出稳定域；再把特征方程化为标准二阶形式，按阻尼比等于 1、大于 1、小于 1 把参数平面划分成临界阻尼轨迹、过阻尼区与欠阻尼区。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据写出 PD 参数满足的稳定条件
本卷实例
  • 关键一步：把闭环特征方程按比例与微分系数整理
  • 中间结果：首列元素给出两个参数均大于零的条件
  • 卡点：含二次积分环节时劳斯表首列结构要重新排
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据写出 PD 参数满足的稳定条件
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 在参数平面上确定稳定区域与不稳定区域
本卷实例
  • 关键一步：把劳斯条件画成参数平面上的半平面交集
  • 中间结果：稳定域边界由两条坐标轴围成第一象限
  • 卡点：边界是否包含端点在图上要单独说明
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过在参数平面上确定稳定区域与不稳定区域
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由标准二阶形式写出阻尼比与参数的关系式
本卷实例
  • 关键一步：把闭环特征方程与标准形式逐项对照
  • 中间结果：阻尼比由微分系数与比例系数的方根之比决定
  • 卡点：比例系数在常数项中，取方根后量纲要对齐
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由标准二阶形式写出阻尼比与参数的关系式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

PID 控制器与参数整定 系统校正
本卷考法
  • 按阻尼比取值把参数平面划分为过阻尼、临界与欠阻尼区
本卷实例
  • 关键一步：令阻尼比分别等于 1、大于 1 和小于 1
  • 中间结果：临界阻尼轨迹为参数平面上的一条抛物线
  • 卡点：过阻尼与欠阻尼区域分布在临界轨迹两侧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过按阻尼比取值把参数平面划分为过阻尼、临界与欠阻尼区
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

3三、圆根轨迹证明与由起始角反求参数20 分#

思路
  • 写出闭环特征方程，用韦达定理证明共轭复根的模为常数，从而根轨迹是以原点为圆心的圆弧；再由起始角与切线斜率的几何关系反求参数；最后按参数值标出起点终点并画根轨迹。
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 由特征方程与相角条件判断根轨迹的几何形状
本卷实例
  • 关键一步：设共轭复根并写出根之和与根之积
  • 中间结果：根之积为常数说明复根到原点距离不变
  • 卡点：要用参数大于给定值说明起点终点均为复数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过由特征方程与相角条件判断根轨迹的几何形状
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则确定根轨迹的起点、终点与走向
本卷实例
  • 关键一步：分别令增益为零与无穷求起点和终点
  • 中间结果：起点为开环极点，终点为开环零点
  • 卡点：分子分母均为二次时两支轨迹都趋于有限零点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则确定根轨迹的起点、终点与走向
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
出射角与入射角 根轨迹法
本卷考法
  • 由起始角与切线斜率的几何关系反求参数
本卷实例
  • 关键一步：在起始极点处把出射方向写成切线斜率
  • 中间结果：圆上切线与半径垂直给出斜率约束
  • 卡点：出射角大于 180 度时要换算到等效的负角
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
