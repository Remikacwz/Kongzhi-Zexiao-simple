1一、选择题：经典控制综合辨析#

思路
  • 15 小题逐题辨析研究对象、稳定性必要条件、典型环节作用、根轨迹类型与采样系统基本概念。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断经典控制理论的研究对象与主要控制方式
本卷实例
  • 关键一步：明确经典控制以线性定常单变量系统为对象
  • 中间结果：自动控制理论主要研究闭环控制系统
  • 卡点：状态空间法属现代控制内容，勿混入经典理论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断经典控制理论的研究对象与主要控制方式
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
直流电机等机电系统 建模与机电系统
本卷考法
  • 判断直流电动机系统忽略电感后的近似阶数
本卷实例
  • 关键一步：同时列写电气方程与机械运动方程
  • 中间结果：忽略电感后电气方程退化为比例关系
  • 卡点：反电动势与电磁转矩的耦合项不能漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由电枢回路电压方程与转矩平衡方程联立
  • 反电动势与转速成正比，电磁转矩与电枢电流成正比
  • 机电时间常数由电气与机械两方面参数共同决定
步骤
  • 写出电枢回路电压平衡方程
  • 写出转矩平衡方程（含负载与粘性摩擦）
  • 消去电枢电流，得到转速或转角对电压的传递函数
通用考法
  • 本卷考过判断直流电动机系统忽略电感后的近似阶数
  • 求直流电机转速或位置对电枢电压的传递函数
  • 分析机电时间常数与电气时间常数的数量级关系
常见易错
  • 漏掉反电动势与电磁转矩的耦合项
  • 把电气时间常数与机电时间常数混淆

减小稳态误差的措施 稳态误差
本卷考法
  • 指出能消除稳态误差的典型环节
本卷实例
  • 关键一步：按能否提高系统型别判断
  • 中间结果：积分环节可提高型别从而消除稳态误差
  • 卡点：比例与微分环节不改变系统型别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过指出能消除稳态误差的典型环节
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 判断影响超调量的闭环因素
本卷实例
  • 关键一步：区分闭环零点与极点对响应的影响
  • 中间结果：闭环零点和极点共同影响超调量
  • 卡点：二阶系统开环增益变化不一定改变超调量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过判断影响超调量的闭环因素
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

描述函数法基础 非线性系统
本卷考法
  • 判断描述函数法的适用条件与结论范围
本卷实例
  • 关键一步：确认一次谐波近似与低通滤波条件
  • 中间结果：描述函数法可判稳定与自振但不能定量求暂态
  • 卡点：它不只适用于非线性系统，线性系统也可作特例
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过判断描述函数法的适用条件与结论范围
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件
公式
相平面法 非线性系统
本卷考法
  • 由开环传函判断相轨迹奇点类型与起点
本卷实例
  • 关键一步：由闭环特征根在复平面上的位置判奇点类型
  • 中间结果：左半平面共轭复根对应稳定焦点
  • 卡点：相轨迹起点由初始条件与外作用共同决定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过由开环传函判断相轨迹奇点类型与起点
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 判断开环传函对应的根轨迹类型
本卷实例
  • 关键一步：按相角条件是 0 度还是 180 度判断
  • 中间结果：含非最小相位环节且只有一个时为常规根轨迹
  • 卡点：两个非最小相位环节又回到常规根轨迹
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过判断开环传函对应的根轨迹类型
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
采样过程与香农采样定理 离散控制系统
本卷考法
  • 判断零阶保持器对系统稳定性的影响
本卷实例
  • 关键一步：把零阶保持器看成带相位滞后的环节
  • 中间结果：零阶保持器产生负相移使稳定性变差
  • 卡点：零阶保持器不改变系统的型别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过判断零阶保持器对系统稳定性的影响
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后
公式
离散系统的动态性能与极点分布 离散控制系统
本卷考法
  • 由采样系统极点位置判断暂态分量特性
本卷实例
  • 关键一步：把极点模与 1 比较
  • 中间结果：模大于 1 的极点对应发散振荡分量
  • 卡点：模等于 1 对应等幅振荡而非发散
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点在 z 平面上的位置决定响应形式
  • 极点越靠近原点衰减越快，越靠近单位圆振荡越强
  • 极点的幅角决定振荡频率，幅值决定衰减速度
  • 采样周期增大会使动态性能变差甚至不稳定
步骤
  • 求闭环脉冲传递函数的极点
  • 按极点在单位圆内的位置判断响应形式
  • 由极点的模与幅角估算衰减与振荡频率
  • 与连续系统指标对应关系相互校验
通用考法
  • 本卷考过由采样系统极点位置判断暂态分量特性
  • 由闭环极点分布判断动态性能
  • 与连续域指标互相换算
  • 说明采样周期对动态性能的影响
常见易错
  • 把 z 平面极点当作 s 平面极点直接读阻尼比
  • 忽略单位圆上极点对应等幅振荡

2二、结构图变换法求传递函数#

思路
  • 观察比较点与引出点的位置关系，按移动法则逐层化简，或用梅森公式对信号流图整体求解。
比较点与引出点的移动 结构图与方框图
本卷考法
  • 移动比较点或引出点以消除交叉连接
本卷实例
  • 关键一步：判断交叉点属于比较点移动还是引出点移动
  • 中间结果：移动后支路增益按乘除规则补上
  • 卡点：移动方向与乘除关系不能搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过移动比较点或引出点以消除交叉连接
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 对多回路结构图逐层化简求总传函
本卷实例
  • 关键一步：先化简最内层局部反馈再向外逐层合并
  • 中间结果：化简内环时外环信号需当变量保留
  • 卡点：不能把外环信号当常数处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过对多回路结构图逐层化简求总传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由串联、并联与反馈等效合成传递函数
本卷实例
  • 关键一步：分清反馈极性写出分母加减
  • 中间结果：负反馈分母为 1 加回路增益
  • 卡点：并联环节相减时符号要取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由串联、并联与反馈等效合成传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

3三、由阶跃响应反求传函与动态指标#

思路
  • 由输出时域表达式分解出稳态与瞬态分量，反求闭环传函并化为标准二阶形式，再求超调、峰值与调节时间。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应表达式反求闭环传递函数
本卷实例
  • 关键一步：把响应中的衰减正弦项配成标准二阶瞬态形式
  • 中间结果：由稳态值、衰减系数与振荡角频率还原传函
  • 卡点：注意化简时正弦项的相位与幅值要合并
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
