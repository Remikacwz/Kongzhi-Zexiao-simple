江南大学 807 自动控制理论（含现控） 2015 年真题思维导图

211 院校共 8 题

难度：中等　全卷 8 道大题：一为 5 个简析小题，二至八各为一道综合题——结构图与二阶指标反求、根轨迹与最小阻尼比、含延迟系统的奈氏判稳、伯德图与串联滞后校正、描述函数与自激振荡、离散系统脉冲传函与稳定范围、复合控制不变性与指标反求。第二、三、四、五、六、七、八题题面含原卷插图。

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

一一、简析题（5 小问）#

思路
  • 5 个短答小题：阻尼比变化对二阶系统性能的影响、奈奎斯特判据如何判稳、三阶系统稳定条件与截止频率、香农采样定理与离散稳态误差、离散与连续系统的区别及稳定充要条件。
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 分析自然频率不变时增大阻尼比对动态指标的影响
本卷实例
  • 关键一步：从二阶各性能指标公式逐项看阻尼比的作用趋势
  • 中间结果：超调量与调节时间随阻尼比增大而减小
  • 卡点：上升时间与峰值时间反而随阻尼比增大而变长，方向别写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过分析自然频率不变时增大阻尼比对动态指标的影响
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

奈奎斯特判据 稳定性分析
本卷考法
  • 叙述奈奎斯特判据的幅角原理与判稳思路
本卷实例
  • 关键一步：由开环右半平面极点数和曲线包围临界点的圈数推闭环
  • 中间结果：闭环稳定要求右半平面闭环极点数减为零
  • 卡点：虚轴小半圆的绕行补画容易漏，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过叙述奈奎斯特判据的幅角原理与判稳思路
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

参数稳定域的确定 稳定性分析
本卷考法
  • 求开环传函为三阶缺项系统时稳定对 K 与 T 的要求
本卷实例
  • 关键一步：写闭环特征方程并列出劳斯表首列
  • 中间结果：特征方程缺一次项导致稳定条件很强
  • 卡点：缺项时劳斯表要补零再判，不能直接套系数为正
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求开环传函为三阶缺项系统时稳定对 K 与 T 的要求
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

开环对数频率特性的绘制 频域分析
本卷考法
  • 由低频段延长线与型别求截止频率
本卷实例
  • 关键一步：按低频段斜率与转折频率逐段写出幅频近似式
  • 中间结果：截止频率由幅值等于一的条件解出
  • 卡点：剪切频率与相位穿越频率含义不同，勿混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过由低频段延长线与型别求截止频率
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

采样过程与香农采样定理 离散控制系统
本卷考法
  • 叙述香农采样定理并写出不失真采样条件
本卷实例
  • 关键一步：把采样频率与输入信号的最高频率作比较
  • 中间结果：采样频率须不低于最高频率的两倍
  • 卡点：是两倍关系，别记成二者相等即可
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过叙述香农采样定理并写出不失真采样条件
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

离散系统的稳态误差 离散控制系统
本卷考法
  • 说明采样系统稳态误差与哪些因素有关
本卷实例
  • 关键一步：从开环增益和采样周期两个方面找影响因素
  • 中间结果：增益提高或周期缩短都能减小稳态误差
  • 卡点：还要兼顾稳定性，不能单说提高增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差由输入类型与开环脉冲传函中 z=1 处极点的个数决定
  • 型别由 G(z)H(z) 中 z=1 处极点的重数确定
  • 用终值定理求稳态误差，前提是系统稳定
  • 采样周期也影响稳态误差大小
步骤
  • 求误差脉冲传递函数
  • 数出 z=1 处极点重数确定型别
  • 查表或用终值定理求稳态误差
  • 分析采样周期变化对误差的影响
通用考法
  • 本卷考过说明采样系统稳态误差与哪些因素有关
  • 求离散系统在典型输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 分析采样周期对稳态精度的影响
常见易错
  • 直接用 s 域静态误差系数公式处理离散系统
  • 未判稳就用终值定理

离散系统稳定性分析 离散控制系统
本卷考法
  • 对比离散与连续系统的特征并给稳定充要条件
本卷实例
  • 关键一步：分别从信号形式、数学模型、实现方式三方面对比
  • 中间结果：离散系统稳定要求闭环极点全在单位圆内
  • 卡点：离散看模小于一，连续看实部小于零，二者别混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过对比离散与连续系统的特征并给稳定充要条件
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

二二、结构图化简与二阶指标反求（4 小问）#

思路
  • 由结构图求闭环传函，按 K1、K2 的不同取值求超调量、调节时间和斜坡稳态误差；再由给定阻尼比与稳态误差反求参数；末问分析引入局部反馈 K2 倍 s 对动态与稳态性能的影响。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图用梅森公式求闭环传递函数
本卷实例
  • 关键一步：先列回路增益与前向通路再写特征式
  • 中间结果：闭环传函可整理成标准二阶形式
  • 卡点：回路增益的正负号要与负反馈极性一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图用梅森公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：先按开环积分环节个数判断系统型别
  • 中间结果：一型系统的斜坡误差等于速度误差系数的倒数
  • 卡点：输入为 0.5t 时不要漏掉幅度系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由给定阻尼比反求局部反馈系数
本卷实例
  • 关键一步：把标准式阻尼比表达式与题目给定值相等
  • 中间结果：解出反馈系数后系统阻尼比被抬高
  • 卡点：回代时还要检查系统是否仍满足稳定条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由给定阻尼比反求局部反馈系数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 分析加入局部反馈支路对系统的影响
本卷实例
  • 关键一步：把局部反馈并入内环后重新化简闭环
  • 中间结果：局部反馈提高阻尼比因而动态性能变好
  • 卡点：稳态误差同时变大，好与坏要分别说清
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过分析加入局部反馈支路对系统的影响
  • 三环及以上系统求闭环传递函数
