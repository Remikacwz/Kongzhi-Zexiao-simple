江南大学 807 自动控制理论（含现控） 2017 年真题思维导图

211 院校共 8 题

难度：中等偏难　全卷 8 道大题：一为 5 个简答小题，二至八各为一道综合题——由阶跃响应反求传函与指标、参数根轨迹与恒稳定条件、奈氏判稳与最大相位裕度、非线性系统自持振荡、离散系统稳定范围与稳态误差、状态空间能控能观与极点配置、复合控制不变性与指标反求。第一、四、五、六、七、八题题面含原卷插图。

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

一一、简答题（5 小题）#

思路
  • 五个短答小题：由结构图等效求两个传递函数、参数稳定域与稳态误差条件的交集、正弦输入下的稳态输出、比例反馈对一阶系统快速性的影响、非线性方程的奇点类型与相轨迹形态。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 把框图等效化简后求两个传递函数
本卷实例
  • 关键一步：按串联并联与反馈等效逐层化简结构图
  • 中间结果：比较简化前后两图得到待求传函
  • 卡点：结构图以图片给出，等效路径需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过把框图等效化简后求两个传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求使三阶系统稳定的参数范围
本卷实例
  • 关键一步：写闭环特征方程并按劳斯判据列首列不等式
  • 中间结果：特征方程缺常数项以外的项要补零
  • 卡点：首列不等式要逐行取交集，别漏约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求使三阶系统稳定的参数范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由稳态误差上界反求开环增益下界
本卷实例
  • 关键一步：一型系统的速度误差系数取开环传函的低频极限
  • 中间结果：令单位斜坡误差不大于一得增益下界
  • 卡点：误差条件要与稳定条件取交集才是最终范围
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由稳态误差上界反求开环增益下界
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求正弦输入下系统的稳态输出表达式
本卷实例
  • 关键一步：求闭环频率特性在该角频率处的幅值与相角
  • 中间结果：输出为同频正弦，幅值按幅频特性折算
  • 卡点：相位是滞后，正弦里的负号不要丢
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求正弦输入下系统的稳态输出表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 分析比例反馈对一阶系统快速性的影响
本卷实例
  • 关键一步：写出反馈后等效时间常数的表达式
  • 中间结果：时间常数变小说明动态响应加快
  • 卡点：快速性提高的同时增益被压低，需要补偿
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过分析比例反馈对一阶系统快速性的影响
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

相平面法 非线性系统
本卷考法
  • 求非线性方程的奇点类型与相轨迹形态
本卷实例
  • 关键一步：令导数为零求奇点再解特征根
  • 中间结果：特征根为带负实部的共轭复根时奇点是稳定焦点
  • 卡点：相轨迹以图片给出，收敛形态需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过求非线性方程的奇点类型与相轨迹形态
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

二二、由阶跃响应反求传函与指标#

思路
  • 给出无零点二阶系统的单位阶跃响应表达式，求调节时间和超调量、反求闭环传递函数，并求静态速度误差系数与单位斜坡输入的稳态误差。
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阶跃响应表达式求调节时间与超调量
本卷实例
  • 关键一步：把响应与标准二阶阶跃响应式对照读出参数
  • 中间结果：代入指标公式得到调节时间与超调量
  • 卡点：调节时间按题目允许的百分之五误差带取系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阶跃响应表达式求调节时间与超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应反求闭环传递函数
本卷实例
  • 关键一步：把响应写成含阻尼比与自然频率的标准形式
  • 中间结果：由标准式系数直接写出闭环传函
  • 卡点：响应里的幅值与相角要与标准式系数一一对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应反求闭环传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

系统型别与静态误差系数 稳态误差
本卷考法
  • 求静态速度误差系数
本卷实例
  • 关键一步：由闭环传函反推开环传递函数
  • 中间结果：一型系统的速度误差系数即开环增益
  • 卡点：先确认系统稳定再求误差系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过求静态速度误差系数

  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

三三、参数根轨迹与恒稳定条件15 分#

思路
  • 含参数 τ 的开环传函，画该参数取定值时的根轨迹大致图形并标出渐近线与出射角，再求使闭环系统对全部正增益都稳定的参数范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制含参数系统的根轨迹草图
本卷实例
  • 关键一步：标零极点并画渐近线和实轴上的根轨迹段
  • 中间结果：渐近线夹角按奇数的二倍加一除以极点数
  • 卡点：渐近线位置与实轴段方向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制含参数系统的根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
出射角与入射角 根轨迹法
本卷考法
  • 求复数极点的出射角
本卷实例
  • 关键一步：按相角条件累加其余零极点对该极点的相角
  • 中间结果：出射角等于一百八十度减去其余相角之和
  • 卡点：累加时不要把这个极点自身的相角算进去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求复数极点的出射角
  • 求复数极点的出射角
  • 根据出射角画出根轨迹起始方向
  • 由入射角确定根轨迹终止方向
常见易错
  • 累加相角时把该极点自身的相角也算进去
  • 忘记判断象限导致角度差 180°
公式
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 把问题化为以给定参数为变量的根轨迹
本卷实例
  • 关键一步：把待研究参数整理到根轨迹增益的位置
  • 中间结果：等效开环传函的极点即原系统的闭环特征根
  • 卡点：整理时参数要完整提到分子，别留在分母
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l

思路

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域

  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求组合输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
