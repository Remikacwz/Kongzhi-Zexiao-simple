点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

1、2、3、4、5、6、7、8、9一、填空题（10 空）20 分#

思路
  • 9 个小题共 10 空，覆盖学科史、由脉冲响应求传函、二阶系统自然频率、减小稳态误差的措施、附加零点的作用、正弦稳态相位、低频段增益、相位裕量定义、离散输出 z 变换，逐空写教材结论。
传递函数的定义与基本性质 传递函数
本卷考法
  • 由单位脉冲响应直接取拉氏变换求传递函数
本卷实例
  • 关键一步：传递函数就是单位脉冲响应的拉氏变换
  • 中间结果：把负指数函数变到 s 域得到一阶惯性型分式
  • 卡点：逐年印 g(t)≥e^{-t}，据宝典应为等号，按等号理解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由单位脉冲响应直接取拉氏变换求传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由二阶闭环传函求无阻尼自然振荡频率
本卷实例
  • 关键一步：先把 s 平方项系数归一，再与二阶标准式对照
  • 中间结果：分母常数项对应自然振荡频率的平方
  • 卡点：分子常数不是自然频率平方，别把 25 当成它
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由二阶闭环传函求无阻尼自然振荡频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

减小稳态误差的措施 稳态误差
本卷考法
  • 写出减小给定输入稳态误差的两种措施
本卷实例
  • 关键一步：从提高开环增益与增加积分环节两个方向考虑
  • 中间结果：两种措施分别减小误差并提高系统型别
  • 卡点：提高开环增益受稳定性限制，要同时说明前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过写出减小给定输入稳态误差的两种措施
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

附加开环零极点的影响 根轨迹法
本卷考法
  • 说明开环极点不变时增加负实数零点的作用
本卷实例
  • 关键一步：从根轨迹左移判断附加零点对相对稳定性的作用
  • 中间结果：附加左半实轴零点使根轨迹左移、动态性能改善
  • 卡点：要区分附加零点与附加极点的作用方向相反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过说明开环极点不变时增加负实数零点的作用
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
频率特性的物理意义与求法 频域分析
本卷考法
  • 由闭环相移求正弦输入下的稳态输出相位
本卷实例
  • 关键一步：把输入初相与闭环相频在该频率处的相角相加
  • 中间结果：输出相位是输入初相与相移的代数和
  • 卡点：相移前有负号表示滞后，代数和时别丢符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由闭环相移求正弦输入下的稳态输出相位
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 由低频段延长线与频率轴交点求开环增益
本卷实例
  • 关键一步：一型系统低频段斜率为负二十分贝每十倍频
  • 中间结果：交点频率数值即开环增益，无需再折算
  • 卡点：该结论只对一型最小相位系统成立
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过由低频段延长线与频率轴交点求开环增益
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

稳定裕度 频域分析
本卷考法
  • 叙述相位裕量的定义及其对应的临界状态
本卷实例
  • 关键一步：从截止频率处再滞后多少度达到负一百八十度理解
  • 中间结果：相位再滞后该角度时系统处于临界稳定
  • 卡点：别把相位裕量与幅值裕量的临界条件写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过叙述相位裕量的定义及其对应的临界状态
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

脉冲传递函数 离散控制系统
本卷考法
  • 由线性离散系统结构图写出输出的 z 变换
本卷实例
  • 关键一步：按采样开关位置定开环与反馈通道的脉冲传函
  • 中间结果：输出 z 变换等于闭环脉冲传函乘输入 z 变换
  • 卡点：结构图以图给出，采样开关与反馈点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过由线性离散系统结构图写出输出的 z 变换
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)

二二、信号流图与传递函数（15 分）15 分#

思路
  • 由结构图先转画信号流图，再用梅森增益公式分别求参考到输出与扰动到输出的传函；求扰动传函时把参考输入置零。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图画信号流图并用梅森公式求传函
本卷实例
  • 关键一步：把方框写成支路、比较点写成节点得到信号流图
  • 中间结果：由全部回路与前向通路写出特征式与余子式
  • 卡点：结构图以图给出，回路与前向通路条数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图画信号流图并用梅森公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 由扰动作用单独求扰动到输出的传递函数
本卷实例
  • 关键一步：求扰动传函时先把参考输入置零
  • 中间结果：扰动通道传函与参考通道共用同一特征式
  • 卡点：两个输入必须分别置零后再叠加，不能同时代入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过由扰动作用单独求扰动到输出的传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

三三、结构图误差系数与指标反求#

思路
  • 先由结构图写出开环传函，再求三个静态误差系数与闭环传函；由超调量、调节时间反解二阶参数得到两个增益；最后对组合输入用叠加法求稳态误差。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图化简求闭环传递函数
本卷实例
  • 关键一步：按串联与反馈等效把内环先并成等效环节
  • 中间结果：闭环传函分母即该环的闭环特征多项式
  • 卡点：结构图以图给出，反馈极性需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由结构图化简求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环传函求静态位置、速度与加速度误差系数
本卷实例
  • 关键一步：先按积分环节个数确定系统型别
  • 中间结果：一型系统的位置误差系数为无穷、速度系数有限
  • 卡点：型别没判对会使三个误差系数全错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关

七七、饱和非线性的描述函数法#

思路
  • 先求出线性部分的等效传函与幅相特性，再写出饱和特性的负倒描述函数并看其随幅值的变化范围；比较两曲线判断有无交点，进而定不自激的增益范围。
描述函数法基础 非线性系统
本卷考法
  • 写饱和特性描述函数并求其负倒数
本卷实例
  • 关键一步：把给定描述函数取负倒数并整理成随幅值变化的函数
  • 中间结果：幅值从边界增大时负倒函数由有限值趋于负无穷
  • 卡点：非线性结构图以图给出，线性部分串接关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过写饱和特性描述函数并求其负倒数
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

用描述函数法分析自振 非线性系统
本卷考法
  • 由曲线有无交点判断是否存在自激振荡
本卷实例
  • 关键一步：比较线性部分奈氏曲线与负倒描述函数的实部范围
  • 中间结果：交点实部绝对值大于负倒曲线起点时两线无交点
  • 卡点：两条曲线的起点与终点范围要画全才能判交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过由曲线有无交点判断是否存在自激振荡
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率
