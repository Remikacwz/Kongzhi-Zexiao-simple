江南大学 807 自动控制理论（含现控） 2024 年真题思维导图

211 院校共 9 题

难度：中等　全卷九道大题：五空填空、结构图信号流图与双输入输出、结构图二阶指标与稳态误差、三阶系统根轨迹与主导极点、非最小相位奈氏判稳、串联校正判据与设计、描述函数法自振、离散系统脉冲传函与稳定、状态空间能控能观与极点配置。结构图与曲线多以插图给出，仅填空题印15分。

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

1一、填空题（五空）15 分#

思路
  • 按每空条件分别用状态空间、一阶响应、频率特性、非线性奇点与状态全响应求结果。
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由前向状态空间与反馈通道求闭环传递函数
本卷实例
  • 关键一步：先由前向状态方程求前向通道传函
  • 关键一步：再与反馈通道按负反馈结构合成闭环传函
  • 中间结果：前向通道传函分母为二阶特征多项式
  • 卡点：反馈通道为微分方程，勿把微分符号当增益，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过由前向状态空间与反馈通道求闭环传递函数
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消
公式
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由一阶系统单位阶跃曲线反求闭环传递函数
本卷实例
  • 关键一步：由阶跃曲线读取稳态值与调节时间反求时间常数
  • 中间结果：一阶系统闭环传函形式为一比时间常数乘一加一
  • 卡点：阶跃曲线以图给出，读数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由一阶系统单位阶跃曲线反求闭环传递函数
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求正弦输入下单位负反馈系统的稳态误差
本卷实例
  • 关键一步：先求误差传函在正弦频率处的幅值与相角
  • 中间结果：正弦稳态误差等于幅频乘输入幅值、相位相加
  • 卡点：输入为正弦信号不能用终值定理直接求误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求正弦输入下单位负反馈系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
相平面法 非线性系统
本卷考法
  • 判断二阶非线性系统奇点的类型
本卷实例
  • 关键一步：令速度与加速度为零求奇点再在奇点处线性化
  • 中间结果：线性化特征根为纯虚根时奇点为中心点
  • 卡点：方程含乘积项，线性化时勿漏交叉项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过判断二阶非线性系统奇点的类型
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆
公式
状态转移矩阵 状态空间分析
本卷考法
  • 由状态方程与初值求单位阶跃下的全响应
本卷实例
  • 关键一步：先求状态转移矩阵再套非齐次全响应公式
  • 中间结果：全响应等于零输入响应加零状态响应
  • 卡点：初值为非零向量，零输入项不能省略
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过由状态方程与初值求单位阶跃下的全响应
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错

二二、信号流图与双输入下的输出#

思路
  • 由结构图画信号流图，再用梅森公式分别求参考输入与扰动到输出的传函。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图画信号流图并用梅森公式求传函
本卷实例
  • 关键一步：按结构图标出各回路与前向通路
  • 关键一步：写特征式时剔除与通路接触的回路
  • 中间结果：特征式含三条回路的乘积项一项
  • 卡点：结构图以图给出，回路接触关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图画信号流图并用梅森公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求参考输入与扰动共同作用下的系统输出
本卷实例
  • 关键一步：分别令参考输入与扰动之一为零求两条传函
  • 中间结果：总输出为两输入各自作用结果之和
  • 卡点：求扰动传函时须把参考输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求参考输入与扰动共同作用下的系统输出
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式

三三、二阶指标与稳态误差#

思路
  • 先由结构图写闭环特征式化为标准二阶形式，再按阻尼比与斜坡误差条件联立求参数。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函求阻尼比与无阻尼自然频率
本卷实例
  • 关键一步：由结构图写闭环传函并化为标准二阶形式
  • 中间结果：特征式常数项对应自然频率平方、一次项对应阻尼比
  • 卡点：结构图以图给出，内反馈系数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函求阻尼比与无阻尼自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡稳态误差条件反求反馈参数
本卷实例
  • 关键一步：判稳后由误差传函求单位斜坡下的误差
  • 中间结果：斜坡误差等于速度误差系数的倒数
  • 卡点：反求参数前先确认闭环稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位斜坡稳态误差条件反求反馈参数
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由阻尼比与误差指标联立反求两个参数
本卷实例
  • 关键一步：把阻尼比与误差两条件写成关于两参数的方程
  • 中间结果：两方程联立可解出两个待定参数
  • 卡点：参数解出后代回特征式复核稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由阻尼比与误差指标联立反求两个参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

四四、根轨迹与主导极点#

思路
  • 按绘制法则画三阶根轨迹求分离点与虚轴交点，再用主导极点法按阻尼比反求增益。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画三阶系统根轨迹草图
本卷实例
  • 关键一步：先写等效开环传函再标零极点与实轴段
  • 中间结果：三条分支渐近线交角为六十度与一百八十度
  • 卡点：附加环节改变等效开环，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画三阶系统根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹分离点及对应的临界增益
本卷实例
  • 关键一步：由分离点方程求根并筛选在根轨迹上的点
  • 中间结果：分离点处对应增益由幅值条件给出
  • 卡点：分离点方程多根只保留实轴根轨迹段内的
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹分离点及对应的临界增益
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点确定衰减振荡范围
本卷实例
  • 关键一步：令特征方程中 s 等于 jω 解出交点与临界增益

  • 开环含有积分环节时未补画无穷大半径圆弧

  • 卡点：终值定理要求闭环稳定，否则结果不成立
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差由输入类型与开环脉冲传函中 z=1 处极点的个数决定
  • 型别由 G(z)H(z) 中 z=1 处极点的重数确定
  • 用终值定理求稳态误差，前提是系统稳定
  • 采样周期也影响稳态误差大小
步骤
  • 求误差脉冲传递函数
  • 数出 z=1 处极点重数确定型别
  • 查表或用终值定理求稳态误差
  • 分析采样周期变化对误差的影响

九九、状态空间能控能观与极点配置#

思路
  • 先由能控能观判别矩阵行列式求参数条件，再用状态反馈极点配置求反馈增益阵。
能控性与能观性 状态空间分析
本卷考法
  • 由能控能观判别矩阵行列式求参数满足条件
本卷实例
  • 关键一步：分别构造能控与能观判别矩阵并求行列式
  • 中间结果：行列式非零的条件给出参数满足的关系式
  • 卡点：能控与能观两个判别矩阵勿互相写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过由能控能观判别矩阵行列式求参数满足条件
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

本卷考法
  • 用状态反馈把闭环极点配置到指定位置
本卷实例
  • 关键一步：先验证能控再用期望极点写特征多项式
  • 中间结果：比较系数得到状态反馈增益阵各元素

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法

  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
