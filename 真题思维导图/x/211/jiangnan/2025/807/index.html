自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 按输入信号变化规律写出控制系统三大分类
本卷实例
  • 关键一步：从给定信号随时间的不同变化形式区分三类系统
  • 中间结果：三个分类名称按输入信号变化规律并列写出
  • 卡点：填空原句只留前半句，空位未印出，需回原卷核对横线位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过按输入信号变化规律写出控制系统三大分类
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

本卷考法
  • 由低频段渐近线斜率判断系统型别
本卷实例
  • 关键一步：低频段每下降二十 dB 每十倍频对应开环积分环节增加一阶
  • 中间结果：斜率依次对应一型、二型、三型系统
  • 卡点：题干印成在 ωc 处取值，按低频渐近线理解更合题意

  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法

  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

  • 用 w 变换后套用劳斯判据

离散系统的动态性能与极点分布 离散控制系统
本卷考法
  • 说明 z 域闭环极点位置对动态性能的影响
本卷实例
  • 关键一步：把极点向 z 平面原点靠近看成动态响应加快
  • 中间结果：极点越靠近原点，振荡衰减越快、调节越短
  • 卡点：靠近原点也可能放大高频噪声，不能只追求快
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点在 z 平面上的位置决定响应形式
  • 极点越靠近原点衰减越快，越靠近单位圆振荡越强
  • 极点的幅角决定振荡频率，幅值决定衰减速度
  • 采样周期增大会使动态性能变差甚至不稳定
步骤
  • 求闭环脉冲传递函数的极点
  • 按极点在单位圆内的位置判断响应形式
  • 由极点的模与幅角估算衰减与振荡频率
  • 与连续系统指标对应关系相互校验
通用考法
  • 本卷考过说明 z 域闭环极点位置对动态性能的影响
  • 由闭环极点分布判断动态性能
  • 与连续域指标互相换算
  • 说明采样周期对动态性能的影响
常见易错
  • 把 z 平面极点当作 s 平面极点直接读阻尼比
  • 忽略单位圆上极点对应等幅振荡

超前校正 系统校正
本卷考法
  • 写出超前校正利用的物理量及其带宽特点
本卷实例
  • 关键一步：超前校正靠校正装置本身提供的超前相角抬升裕度
  • 中间结果：超前校正把剪切频率右移，从而获得更大带宽
  • 卡点：超前角受元件限制，通常不超过约五十度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过写出超前校正利用的物理量及其带宽特点
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

滞后校正 系统校正
本卷考法
  • 写出滞后校正利用的物理量
本卷实例
  • 关键一步：滞后校正利用原系统在中低频段已有的相角裕度
  • 中间结果：滞后校正靠降低剪切频率保留原有的相角储备
  • 卡点：与超前校正相反，滞后校正换来裕度但牺牲带宽
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过写出滞后校正利用的物理量
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

6二、简答题（线性与非线性振荡）#

思路
  • 从产生机理、振幅与频率的决定因素、是否依赖初始条件与外部激励三方面，对比线性等幅振荡与非线性自激振荡。
非线性系统的特点 非线性系统
本卷考法
  • 对比线性等幅振荡与非线性自激振荡的机理
本卷实例
  • 关键一步：从振荡由固有频率还是非线性特性决定切入对比
  • 中间结果：线性等幅振荡对应临界稳定，由系统固有特性决定
  • 卡点：简答要落到差异，不能只分别描述两种现象
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过对比线性等幅振荡与非线性自激振荡的机理
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
非线性系统的稳定性与改善 非线性系统
本卷考法
  • 说明非线性自激振荡的振幅与频率特征
本卷实例
  • 关键一步：自振由内部非线性能量积累维持，不靠外部驱动
  • 中间结果：自振振幅与频率由非线性环节和线性部分共同约束
  • 卡点：线性系统在无外部周期激励时不会自持等幅振荡
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 非线性系统只有局部稳定性概念，与初始条件有关
  • 极限环的稳定性可由相轨迹收敛或发散判断
  • 减小非线性影响可用加大线性部分增益或引入校正
  • 用描述函数或相平面结果指导参数选择
步骤
  • 判断系统是否存在极限环并确定其稳定性
  • 分析非线性环节参数对自振幅值频率的影响
  • 通过调整线性部分增益或加入校正削弱自振
  • 重新分析确认自振消除或幅值达标
通用考法
  • 本卷考过说明非线性自激振荡的振幅与频率特征
  • 提出消除自振的工程措施
  • 分析增益变化对极限环幅值的影响
  • 比较不同方案对稳定性与动态性能的利弊
常见易错
  • 仅调整增益而不检查是否引入新的自振点
  • 把不稳定极限环误判为可观测的自振

8四、劳斯判据与参考及扰动稳态误差（图 2）#

多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 由结构图分别求参考与扰动到误差的传函
