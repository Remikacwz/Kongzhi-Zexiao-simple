江南大学 807 自动控制理论（含现控） 2020 年真题思维导图

211 院校共 10 题

难度：中等偏难　全卷 10 道大题：一为 5 小问填空，二至十覆盖结构图与传函、二阶指标、根轨迹、频域裕度与延迟、校正选型、非线性自振、离散系统、复合控制与状态空间。一、二、三、四、五、六、七、八、九、十题面含原卷插图。

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

一一、填空题（5小题）#

思路
  • 由闭环传函写微分方程、化典型反馈结构求G(s)与H(s)、由输出表达式反求闭环传函、读正弦输入下稳态输出角频率、写非线性方程等倾线方程。
传递函数的定义与基本性质 传递函数
本卷考法
  • 由闭环传递函数反写系统微分方程
本卷实例
  • 关键一步：把传函化为分母乘输出等于分子乘输入
  • 中间结果：作拉氏反变换即得时域微分方程
  • 卡点：零初始条件这一前提不要丢
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由闭环传递函数反写系统微分方程
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 把结构图化为典型反馈形式求G(s)与H(s)
本卷实例
  • 关键一步：按串联反馈等效把框图整理成标准形式
  • 中间结果：比较标准前向通道与前向环节定出G与H
  • 卡点：反馈极性决定分母中的加减号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过把结构图化为典型反馈形式求G(s)与H(s)
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由输出响应表达式反求闭环传函
本卷实例
  • 关键一步：对输出与其导数项作拉氏变换
  • 中间结果：整理成输出比输入的闭环传函
  • 卡点：注意稳态分量与瞬态分量系数的对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由输出响应表达式反求闭环传函
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由正弦输入读稳态输出的角频率
本卷实例
  • 关键一步：线性定常系统稳态输出与输入同频
  • 中间结果：角频率直接取自输入的正弦项
  • 卡点：只有幅值与相位会被系统改变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由正弦输入读稳态输出的角频率
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
相平面法 非线性系统
本卷考法
  • 由非线性方程写等倾线方程
本卷实例
  • 关键一步：把二阶方程化为相轨迹斜率表达式
  • 中间结果：令斜率等于给定常数即得等倾线
  • 卡点：斜率是导数之比，不要写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过由非线性方程写等倾线方程
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆
公式

二二、由脉冲响应方程组画结构图并求传函#

思路
  • 已知以中间变量表示的脉冲响应方程组，画系统结构图与信号流图，再求总传递函数C(s)/R(s)。
状态空间表达式的建立 状态空间分析
本卷考法
  • 由微分方程组画系统结构图与信号流图
本卷实例
  • 关键一步：把每个方程按输入输出关系画成环节
  • 中间结果：按中间变量的联系把各环节串接成图
  • 卡点：中间变量个数要与方程个数对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由微分方程组画系统结构图与信号流图
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求总传递函数
本卷实例
  • 关键一步：由结构图列全部回路与前向通路
  • 中间结果：前向通路与余子式之比给出总传函
  • 卡点：不接触回路的余子式不要漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求总传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式

三三、二阶系统指标与局部反馈影响#

思路
  • 含局部反馈K2s的结构图，分别在K2=0与K2=1时求调节时间与斜坡稳态误差，再按给定阻尼比与误差反求K1、K2并分析局部反馈的影响。
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 在给定参数下求调节时间与稳态误差
本卷实例
  • 关键一步：把闭环传函化为二阶标准式读出阻尼比与自然频率
  • 中间结果：按调节时间公式与误差系数分别计算
  • 卡点：调节时间要按题目指定的误差带取系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过在给定参数下求调节时间与稳态误差
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 加入局部反馈后的闭环极点分析
本卷实例
  • 关键一步：比较局部反馈前后闭环特征方程
  • 中间结果：局部反馈改变的是阻尼而主要不是型别
  • 卡点：稳态误差可能因增益变化而改变方向
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过加入局部反馈后的闭环极点分析
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由阻尼比与稳态误差反求K1与K2
本卷实例
  • 关键一步：由阻尼比条件与误差条件联立方程组
  • 中间结果：解方程组得到两个反馈系数
  • 卡点：两个条件要同时满足，不能只代其中一个
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由阻尼比与稳态误差反求K1与K2
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式

四四、根轨迹与阻尼比·调节时间约束#

思路
  • 单位负反馈开环 G(s)=K*/[s(s+4)]，画根轨迹，求给定阻尼比下的闭环极点，再由阻尼比与调节时间约束求开环增益范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制二阶系统根轨迹
本卷实例
  • 关键一步：标出开环极零点并判断实轴根轨迹段
  • 中间结果：写出分离点与渐近线要素
  • 卡点：分离点与虚轴交点是两类不同临界点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制二阶系统根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由给定阻尼比求闭环极点及增益
本卷实例
  • 关键一步：沿等阻尼线把闭环特征方程与标准式对照
  • 中间结果：解出自然频率后写出闭环极点
  • 卡点：等阻尼线不是垂直线，勿画错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由给定阻尼比求闭环极点及增益
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与调节时间约束反求增益范围
本卷实例
  • 关键一步：由调节时间要求解出自然频率下界
  • 中间结果：再与阻尼比条件一起换算为增益范围
  • 卡点：两个指标给出的边界方向可能相反，需取交集
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 型别由 G(z)H(z) 中 z=1 处极点的重数确定

  • 分析采样周期变化对误差的影响

十十、状态反馈与极点配置·观测#

思路
  • 给定状态方程与输出方程，判断能否用反馈矩阵k把极点配置到给定位置并求解，再在状态不可测量的条件下讨论其他配置方法。
状态反馈与极点配置 状态空间分析
本卷考法
  • 判断极点可配置性并求状态反馈增益
本卷实例
  • 关键一步：先由能控性矩阵的秩判断系统是否完全能控
  • 中间结果：设反馈增益阵并比较期望与闭环特征多项式
  • 卡点：未验证能控性就下结论是可配置性判据的常见错误
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过判断极点可配置性并求状态反馈增益
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
