江南大学 807 自动控制理论（含现控） 2022 年真题思维导图

211 院校共 8 题

难度：中等　全卷 8 大题：第 1 题为 5 个短答式小题，覆盖由阶跃响应反求传函、正弦稳态输出、组合输入稳态误差、能控标准型、奇点类型；第 2 至 8 题为计算综合——三阶根轨迹与重极点、奈氏曲线与参数稳定域、由 Bode 图反求传函与校正、离散脉冲传函与稳定范围、复合控制前馈不变性与二阶指标、死区继电特性的描述函数法、状态空间建模与主导极点法极点配置。第 2 至 8 题题面含原卷插图。

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

1、2、3、4、5一、填空题（5 小题）#

思路
  • 五个小题分别考由阶跃响应反求传函、正弦输入的稳态输出、组合输入下的稳态误差、由传函写能控标准型、非线性方程的奇点类型，各写结论与简要依据。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应反求系统传递函数
本卷实例
  • 关键一步：对阶跃响应取拉氏变换再除以阶跃输入的象函数
  • 中间结果：响应的一阶指数形式对应一阶惯性环节
  • 卡点：阶跃响应稳态值为 1 时才可直接按输出比输入反求
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应反求系统传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

频率特性的物理意义与求法 频域分析
本卷考法
  • 由闭环传函求正弦输入的稳态输出
本卷实例
  • 关键一步：把 s 换成 jω 代入闭环传函求该频率的幅值与相角
  • 中间结果：稳态输出幅值等于输入幅值乘幅频
  • 卡点：相角正负号要与反正切所在象限一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由闭环传函求正弦输入的稳态输出
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环传函判系统型别并写静态误差系数
本卷实例
  • 关键一步：按开环传函中积分环节个数确定系统型别
  • 中间结果：本题为二型，速度误差系数无穷、加速度系数有限
  • 卡点：分子含一阶微分环节不改变型别判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由开环传函判系统型别并写静态误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据先确认闭环系统稳定
本卷实例
  • 关键一步：由开环传函写出闭环特征方程并列劳斯表
  • 中间结果：首列各元素同号时闭环稳定
  • 卡点：特征方程系数有缺项时要用零补位再列
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据先确认闭环系统稳定
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 对组合输入用叠加法求稳态误差
本卷实例
  • 关键一步：把输入拆成阶跃、斜坡、加速度三项分别求误差
  • 中间结果：阶跃与斜坡分量误差为零，只剩加速度分量
  • 卡点：先判稳再用静态误差系数法，顺序不能颠倒
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过对组合输入用叠加法求稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 由闭环传函写能控标准型状态空间表达式
本卷实例
  • 关键一步：按首一降幂形式把分母系数排成友矩阵
  • 中间结果：输出矩阵由分子系数从高到低补齐
  • 卡点：分子比传函低一阶时要在前面补一个零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法
  • 本卷考过由闭环传函写能控标准型状态空间表达式
  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反

相平面法 非线性系统
本卷考法
  • 由二阶非线性微分方程求平衡点与奇点类型
本卷实例
  • 关键一步：先令导数为零求平衡点，再在平衡点处线性化
  • 中间结果：线性化特征根为共轭复根且实部为正
  • 卡点：先把方程化成两个一阶方程再写相轨迹斜率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过由二阶非线性微分方程求平衡点与奇点类型
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

二二、三阶系统根轨迹与重极点#

思路
  • 由结构图写开环传函，按法则画根轨迹，用分离点求衰减振荡的增益区间；重极点时用根之和求第三个闭环极点并写闭环传函。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则画三阶无零点的根轨迹
本卷实例
  • 关键一步：由三个开环极点定实轴段与渐近线夹角
  • 中间结果：三条渐近线交于极点实部的平均值
  • 卡点：结构图以图给出，开环传函需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则画三阶无零点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 用分离点方程求根轨迹分离点与重极点
本卷实例
  • 关键一步：对三个极点倒数之和等于零的方程求根
  • 中间结果：只保留落在实轴根轨迹段上的那个根
  • 卡点：另一个根不在根轨迹上，必须舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过用分离点方程求根轨迹分离点与重极点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界增益
本卷实例
  • 关键一步：把 s 换成 jω 代入特征方程分离实虚部
  • 中间结果：由辅助方程解出交点频率与临界开环增益
  • 卡点：劳斯表出现全零行时才用辅助方程求交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 用分离点界定衰减振荡的开环增益范围
本卷实例
  • 关键一步：把根轨迹增益换算成开环增益再定区间
  • 中间结果：区间下端由分离点增益、上端由临界增益给出
  • 卡点：开环增益与根轨迹增益差一个比例，换算别反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过用分离点界定衰减振荡的开环增益范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

三三、奈氏曲线与参数稳定范围#

思路
  • 由结构图写开环传函并求幅频相频，画奈氏曲线找穿越负实轴的位置；再按开环右半平面极点数用奈奎斯特判据求参数 a 的稳定范围。

  • 中间结果：幅频为分子模比分母模，相频由各环节相角累加
  • 卡点：要保留频率趋于零与趋于无穷时的极限走向

  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义

奈奎斯特判据 稳定性分析
本卷考法
  • 画开环奈氏曲线并用奈奎斯特判据判稳定
