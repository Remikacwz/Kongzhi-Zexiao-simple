江南大学 807 自动控制理论（含现控） 2016 年真题思维导图

211 院校共 8 题

难度：中等　全卷 8 道大题：一为 4 个简析小题，二至八各为一道综合题——结构图闭环传函与指标反求、根轨迹与温度控制系统、非最小相位奈氏判稳、串联校正装置比较、非线性系统与描述函数、计算机控制系统离散化、状态空间稳定性与观测器。第二、三、五、六、七、八题题面含原卷插图。

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

一一、简析题（4 小问）#

思路
  • 四个短答小题：双输入双输出系统的各路子传函与传递函数矩阵、五种阻尼比下二阶系统阶跃响应曲线、含绝对值非线性方程的平衡点与稳定性、由状态空间表达式求传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求双输入双输出系统的子传递函数
本卷实例
  • 关键一步：分别写出四条前向通路与全部回路
  • 中间结果：四路子传函共用同一特征式
  • 卡点：求某一路传函时其余输入要置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求双输入双输出系统的子传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 由多输入结构图整理系统传递函数矩阵
本卷实例
  • 关键一步：把各子传函按输入输出对号入座排列
  • 中间结果：矩阵元素为输出对相应输入的传函
  • 卡点：两个输入同时存在时不能直接叠加而未验证线性性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过由多输入结构图整理系统传递函数矩阵
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 画二阶系统五种阻尼比下的阶跃响应曲线
本卷实例
  • 关键一步：按阻尼比与一的大小关系分成五种情形
  • 中间结果：从小到大依次为过阻尼、临界、欠阻尼、无阻尼、发散
  • 卡点：阻尼比为负一时发散，别与无阻尼等幅振荡混同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过画二阶系统五种阻尼比下的阶跃响应曲线
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
相平面法 非线性系统
本卷考法
  • 确定非线性方程平衡点并判断其稳定性
本卷实例
  • 关键一步：令速度与加速度均为零解出平衡点坐标
  • 中间结果：按状态变量正负分两段写线性化方程
  • 卡点：含绝对值必须分段讨论，不能只取一支
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过确定非线性方程平衡点并判断其稳定性
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆
公式
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由状态空间表达式求系统传递函数
本卷实例
  • 关键一步：直接计算输出矩阵乘预解矩阵再乘输入矩阵
  • 中间结果：分母是特征多项式，分子由零极点关系决定
  • 卡点：状态空间式里没有直接传递项，别多写 D
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过由状态空间表达式求系统传递函数
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

二二、结构图闭环传函与指标反求#

思路
  • 由结构图用梅森公式求闭环传函，在给定阻尼比下反求反馈系数，再求峰值时间、调节时间、超调量与组合输入下的稳态误差。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图求闭环传递函数
本卷实例
  • 关键一步：由方框图列出回路增益与前向通路
  • 中间结果：整理后得到标准二阶闭环形式
  • 卡点：回路增益符号要与负反馈的极性一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由给定阻尼比反求反馈系数
本卷实例
  • 关键一步：令标准式阻尼比等于题目给定值
  • 中间结果：解出反馈系数并回代闭环分母
  • 卡点：回代后要检查分子增益是否被一并改变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由给定阻尼比反求反馈系数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 计算峰值时间、调节时间与超调量
本卷实例
  • 关键一步：由分母读出自然频率与阻尼比
  • 中间结果：分别代入峰值、调节时间与超调公式
  • 卡点：调节时间取百分之五误差带的系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过计算峰值时间、调节时间与超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求组合输入下的稳态误差
本卷实例
  • 关键一步：把输入拆成阶跃与斜坡两个分量
  • 中间结果：一型系统的阶跃误差为零、斜坡误差有限
  • 卡点：组合输入要把各分量的误差相加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求组合输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

三三、根轨迹与温度控制系统#

思路
  • 温度控制系统用根轨迹法求满足超调要求的开环增益，再求阶跃响应的调节时间；末问对参考与扰动同时作用用静态误差系数法求稳态误差。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制温度控制系统的根轨迹概略图
本卷实例
  • 关键一步：标出开环极点并按法则画渐近线
  • 中间结果：分离点与虚轴交点一并标在图上
  • 卡点：开环极点位置由结构图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制温度控制系统的根轨迹概略图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由超调要求用根轨迹法确定开环增益
本卷实例
  • 关键一步：由超调量反算阻尼比并画等阻尼线
  • 中间结果：等阻尼线与根轨迹的交点对应所求增益
  • 卡点：由交点取幅值条件时不要漏掉开环根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由超调要求用根轨迹法确定开环增益
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 用主导极点法求阶跃响应的调节时间
本卷实例
  • 关键一步：把系统近似为一对主导共轭极点
  • 中间结果：调节时间由主导极点的实部绝对值决定
  • 卡点：忽略非主导极点前要比较其实部距离与留数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过用主导极点法求阶跃响应的调节时间
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求参考与扰动共同作用下的稳态误差
本卷实例
  • 关键一步：参考与扰动分别作用后再叠加

本卷实例
  • 关键一步：写出系统矩阵并求其特征值
  • 中间结果：特征值实部全为负则系统渐近稳定
  • 卡点：要先写出正确的系统矩阵再求特征值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论

能控性与能观性 状态空间分析
本卷考法
  • 用秩判据判断系统的能观性
本卷实例
  • 关键一步：构造由输出矩阵与其乘系统矩阵堆叠的矩阵
  • 中间结果：该矩阵满秩则系统能观
  • 卡点：能观判据与能控判据的构造方式不同，别互换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过用秩判据判断系统的能观性
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

状态观测器设计 状态空间分析
本卷考法
  • 按期望极点设计全维状态观测器
本卷实例
  • 关键一步：令期望特征多项式与含增益阵的实际式相等
  • 中间结果：比较同次幂系数解出观测器增益
  • 卡点：观测器增益与状态反馈增益形式不同，符号别弄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态观测器用输出与输入重构状态，前提是系统能观
  • 极点配置法与龙伯格观测器是两种常用形式
  • 观测器误差动态由 A-LC 的特征值决定
  • 观测器极点通常取得比系统极点快若干倍
步骤
  • 验证系统能观性
  • 写出观测器方程并求误差动态矩阵
  • 按期望特征多项式比较系数求出 L
  • 校验观测器收敛速度是否合适
通用考法
  • 本卷考过按期望极点设计全维状态观测器
  • 设计全维状态观测器
  • 由期望观测器极点求反馈增益阵 L
  • 分析观测器与状态反馈组合后的系统极点
常见易错
  • 把观测器增益阵写成了状态反馈增益阵的形式
  • 忽略观测器极点过快会放大噪声
