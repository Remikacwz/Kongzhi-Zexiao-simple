一一、信号流图与梅森公式求闭环传函#

思路
  • 已知系统方框图，先画信号流图，再用梅森增益公式求闭环传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由方框图画信号流图并用梅森公式求闭环传函
本卷实例
  • 关键一步：由方框图逐点标出节点与支路，再列全部回路与前向通路
  • 中间结果：闭环传函由前向通路与其余子式之比给出
  • 卡点：回路或前向通路容易漏计，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由方框图画信号流图并用梅森公式求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 结构图等效与梅森公式两条路线互相印证
本卷实例
  • 关键一步：先按串联并联反馈等效粗算闭环结构
  • 中间结果：两种路线结果应一致，可互相校验
  • 卡点：不接触回路的余子式不要混入接触项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过结构图等效与梅森公式两条路线互相印证
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式

二二、根轨迹与欠阻尼增益范围#

思路
  • 开环 G(s)=k/[s(s+2)]，画根轨迹、按给定阻尼比求闭环根、再由超调量上界求开环增益范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制二阶系统根轨迹草图
本卷实例
  • 关键一步：标出开环零极点并判断实轴上的根轨迹段
  • 中间结果：两个极点一支分离点，渐近线为两条垂线
  • 卡点：分离点要与虚轴交点区分，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制二阶系统根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由给定阻尼比求闭环极点位置
本卷实例
  • 关键一步：把闭环特征方程对照二阶标准式读出自然频率
  • 中间结果：由阻尼比与自然频率组合出共轭极点
  • 卡点：阻尼比小于一时才有一对共轭复根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由给定阻尼比求闭环极点位置
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量上界反求开环增益范围
本卷实例
  • 关键一步：由超调量公式解出阻尼比下界
  • 中间结果：再把阻尼比下界换算为增益的上下界
  • 卡点：还要同时满足欠阻尼条件，勿只取一侧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量上界反求开环增益范围
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式

三三、稳态误差与无超调条件求K#

思路
  • 含未知增益K的单位反馈三阶系统，分别由斜坡稳态误差上界、阶跃输出无超调两个条件求K的取值。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由斜坡输入稳态误差上界反求开环增益下界
本卷实例
  • 关键一步：先判稳再套速度误差系数与误差的倒数关系
  • 中间结果：误差上界化为增益下界
  • 卡点：未判稳就用终值定理是常见失分点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由斜坡输入稳态误差上界反求开环增益下界
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 由输出无超调确定增益上界
本卷实例
  • 关键一步：无超调等价于闭环特征根全为负实根
  • 中间结果：用分离点或重根条件求出临界增益
  • 卡点：只取实数根，复根会产生振荡超调
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过由输出无超调确定增益上界
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式

四四、奈奎斯特与伯德图判稳#

思路
  • 开环含一积分与一阶微分环节，由给定幅频曲线画相频与奈奎斯特曲线，并分析增益变化对稳定性的影响。
频率特性的物理意义与求法 频域分析
本卷考法
  • 由传函写出幅频与相频表达式
本卷实例
  • 关键一步：对分子分母分别取模与取相角后相减
  • 中间结果：低频段相位趋近负九十度
  • 卡点：积分环节带来的固定相位滞后不要漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由传函写出幅频与相频表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由奈奎斯特曲线判断闭环稳定性
本卷实例
  • 关键一步：补画积分环节对应的无穷大半径圆弧
  • 中间结果：按包围临界点的圈数与开环右半极点数判定
  • 卡点：两个积分环节的补画方向最易出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由奈奎斯特曲线判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 由幅频折线斜率变化识别环节并比较时间常数
本卷实例
  • 关键一步：按各转折频率处斜率变化判断一阶环节个数
  • 中间结果：由相频渐近行为定出T1大于T2
  • 卡点：最小相位系统的幅频与相频一一对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过由幅频折线斜率变化识别环节并比较时间常数
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式

五五、校正环节识别与选型#

思路
  • 由三个给定的校正环节幅频特性写出各自传递函数，并按稳态误差减小且动态响应变快的要求选型。
校正的基本概念与性能指标 系统校正
本卷考法
  • 由幅频特性识别校正环节类型
本卷实例
  • 关键一步：从低频与高频段增益关系判断超前还是滞后
  • 中间结果：转折频率比即为校正器参数
  • 卡点：三个图对应的转折频率不要张冠李戴
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过由幅频特性识别校正环节类型
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求
公式
滞后校正 系统校正
本卷考法
  • 按稳态与动态双要求选择校正装置
本卷实例
  • 关键一步：在提高低频增益与保持相位裕度之间权衡
  • 中间结果：滞后校正在抬高低频增益时不显著损裕度
  • 卡点：动态响应变快与滞后校正的减速作用相矛盾
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过按稳态与动态双要求选择校正装置
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
