一一、稳态误差·传函反求·相平面等倾线#

思路
  • 三个独立小题：斜坡输入下一阶系统稳态误差、由二阶系统误差与极点反求开环传函、写非线性相轨迹的等倾线方程。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡输入下一阶系统的稳态误差
本卷实例
  • 关键一步：把一阶传函写成开环形式判型别
  • 中间结果：斜坡误差由速度误差系数之倒数给出
  • 卡点：先确认系统稳定再谈稳态误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求斜坡输入下一阶系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由稳态误差与闭环极点反求开环传函
本卷实例
  • 关键一步：设开环为零极点形式并写闭环特征方程
  • 中间结果：用误差条件与极点条件联立解出参数
  • 卡点：系统型别要与误差为有限常数这一条对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由稳态误差与闭环极点反求开环传函
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
相平面法 非线性系统
本卷考法
  • 写出非线性系统的等倾线方程
本卷实例
  • 关键一步：把二阶非线性方程化为相轨迹斜率表达式
  • 中间结果：令斜率等于给定常数即得等倾线
  • 卡点：相轨迹斜率是导数之比，勿写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过写出非线性系统的等倾线方程
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆
公式

二二、双输入双输出信号流图与梅森公式#

思路
  • 双输入双输出系统结构图，画信号流图并用梅森公式求两个输入到各自输出的传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 多输入多输出系统用梅森公式求传函
本卷实例
  • 关键一步：分别对每个输入求前向通路与回路集合
  • 中间结果：其余输入置零后再用梅森公式
  • 卡点：两个通道的回路集合不同，不能混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过多输入多输出系统用梅森公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图的逐层化简
本卷实例
  • 关键一步：先化简内环再向外逐层合并
  • 中间结果：注意交叉反馈不能按简单串联处理
  • 卡点：简化内环时不要把外环信号当常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图的逐层化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

三三、二阶系统阻尼条件·指标反求·稳态误差#

思路
  • 给定二阶系统结构图，求欠阻尼条件、由超调量与峰值时间反求K和τ、再求组合输入下的稳态误差。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由结构图写闭环特征方程并给欠阻尼条件
本卷实例
  • 关键一步：把闭环特征方程对照二阶标准式
  • 中间结果：欠阻尼对应阻尼比在零与一之间
  • 卡点：闭环自然频率与开环参数要写清对应关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由结构图写闭环特征方程并给欠阻尼条件
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间反求两个参数
本卷实例
  • 关键一步：先由超调量定阻尼比再由峰值时间定自然频率
  • 中间结果：把已求指标回代解出结构与参数
  • 卡点：峰值时间公式只适用于欠阻尼二阶系统
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量与峰值时间反求两个参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式

四四、根轨迹与衰减振荡增益范围#

思路
  • 开环 G(s)=K/[s(0.5s+1)(0.25s+1)]，画根轨迹概略图，求系统响应为衰减振荡时的K范围与重极点时的闭环传函。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制三阶系统根轨迹概略图
本卷实例
  • 关键一步：标出三个开环极点与实轴根轨迹段
  • 中间结果：三条渐近线的交点与夹角按法则计算
  • 卡点：渐近线夹角公式中的二倍加一不要写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制三阶系统根轨迹概略图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹求衰减振荡的增益范围
本卷实例
  • 关键一步：衰减振荡对应复数极点且实部为负
  • 中间结果：临界增益由根轨迹与虚轴交点确定
  • 卡点：要同时排除过阻尼与不稳定两段
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹求衰减振荡的增益范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
分离点与会合点 根轨迹法
本卷考法
  • 求重极点对应的闭环传递函数
本卷实例
  • 关键一步：由分离点条件解出重根位置与临界增益
  • 中间结果：把重根代入闭环特征方程写出传函
  • 卡点：求出的根要筛选，舍去不在根轨迹上的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求重极点对应的闭环传递函数
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式

五五、奈奎斯特判稳与K范围#

思路
  • 开环 G(s)=K(s+3)/[3s(s-1)]，画奈奎斯特曲线并求单位负反馈下闭环稳定时的K取值范围。
奈奎斯特判据 稳定性分析
本卷考法
  • 含右半平面极点的系统用奈奎斯特判据判稳
本卷实例
  • 关键一步：先数开环右半平面极点数P
  • 中间结果：再补画积分环节圆弧并数包围次数
  • 卡点：把包围圈数的正负号定义搞反是常见错误
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过含右半平面极点的系统用奈奎斯特判据判稳
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 写出幅频与相频表达式并描点
本卷实例
