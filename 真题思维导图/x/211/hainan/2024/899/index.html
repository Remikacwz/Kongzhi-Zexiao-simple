一一、填空题（五小问）#

思路
  • 五个小空依次考单位速度下的稳态误差、由脉冲响应反求传函、校正装置类型、对数幅频中频段的物理意义与传递函数成立的前提
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位速度信号作用下的稳态误差
本卷实例
  • 关键一步：先由闭环特征方程判稳，再由静态速度误差系数求稳态误差
  • 中间结果：开环有一个积分环节，属 I 型系统，速度误差系数等于开环增益
  • 卡点：未判稳就直接套用误差公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位速度信号作用下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位脉冲响应反求系统传递函数
本卷实例
  • 关键一步：单位脉冲响应的拉氏变换即闭环传递函数，再按单位负反馈关系反求开环传函
  • 中间结果：脉冲响应的各指数项对应拉氏变换的部分分式，通分后合并
  • 卡点：把脉冲响应直接当开环传函，漏掉由闭环反求开环这一步
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位脉冲响应反求系统传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

滞后校正 系统校正
本卷考法
  • 由传递函数形式判断串联校正装置的类型
本卷实例
  • 关键一步：比较分子分母的转折频率，由相频特性恒为负判断为滞后特性
  • 中间结果：分子转折频率高于分母转折频率，故相角整体滞后
  • 卡点：把时间常数比大于一判成超前校正
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过由传递函数形式判断串联校正装置的类型
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

  • 中间结果：中频段的斜率与宽度决定动态性能与稳定裕度
  • 卡点：把中频段的结论错挂到低频段上

  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤

  • 画出未校正系统的 Bode 图

通用考法

  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错

传递函数的定义与基本性质 传递函数
本卷考法
  • 填空说明传递函数成立的前提条件
本卷实例
  • 关键一步：由定义明确传递函数只对线性定常系统且零初始条件下成立
  • 中间结果：取输出与输入拉氏变换之比，初始条件须全部为零
  • 卡点：只答线性系统，漏掉定常与零初始条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过填空说明传递函数成立的前提条件
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

二1二1、梅森公式求传函#

思路
  • 由结构图改画信号流图，数清全部独立回路与前向通路，按梅森增益公式求闭环传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求多回路系统的闭环传递函数
本卷实例
  • 关键一步：先由系统结构图改画信号流图，再标出全部独立回路与前向通路
  • 中间结果：特征式按单回路与两两不接触回路逐层累加，各前向通路另求其余子式
  • 卡点：余子式中未剔除与前向通路接触的回路
  • 卡点：结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求多回路系统的闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

二2二2、二阶系统参数与动态指标#

思路
  • 由含参数的闭环传函化为标准二阶形式，按给定阻尼比与自然频率反求增益与反馈系数，再逐项算动态指标
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由给定阻尼比与自然频率反求开环增益与反馈系数
本卷实例
  • 关键一步：把闭环特征式与标准二阶形式逐项对应，列出两个方程联立
  • 中间结果：自然频率的平方等于开环增益，一次项系数由反馈系数决定
  • 卡点：未先把特征式化为首一标准形式就直接对系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由给定阻尼比与自然频率反求开环增益与反馈系数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率求上升时间、峰值时间、超调量与调节时间
本卷实例
  • 关键一步：上升时间与峰值时间由阻尼角和自然频率决定，超调量只由阻尼比决定
  • 中间结果：调节时间按百分之五与百分之二两种误差带分别取不同系数
  • 卡点：两种误差带的调节时间系数混用，或把上升时间与峰值时间公式用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率求上升时间、峰值时间、超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

三三、稳定条件与加速度稳态误差#

思路
  • 由闭环三次特征式列劳斯表求稳定条件，再由静态加速度误差系数求加速度输入下的稳态误差
劳斯判据 稳定性分析
本卷考法
  • 求使三阶系统稳定的参数条件
本卷实例
  • 关键一步：列劳斯表，令首列全部为正，得到参数之间的不等式
  • 中间结果：稳定条件化为时间常数之间的大小关系
  • 卡点：首列出现参数为零的边界时未单独讨论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过求使三阶系统稳定的参数条件
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

四四、根轨迹绘制与极点反求#

思路
  • 按绘制法则画根轨迹并求分离点、渐近线与虚轴交点，再由已知一个闭环极点用幅值条件反求增益与其余极点
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画三阶系统根轨迹

奈奎斯特判据 稳定性分析
本卷考法
  • 由奈氏曲线与负实轴的交点判断稳定、临界与不稳定的增益范围
本卷实例
  • 关键一步：先数开环右半平面极点数，再由曲线包围临界点的情况写判据
  • 中间结果：交点在负实轴上的位置与负一的关系决定三种增益边界
  • 卡点：开环含积分环节时未补画无穷大半径圆弧

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数

  • 由 Z=N+P 判断闭环稳定性

本卷考法

  • 幅值裕度取倒数未取，导致结论反了
