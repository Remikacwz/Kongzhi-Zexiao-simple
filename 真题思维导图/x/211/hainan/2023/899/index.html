一一、填空题（五小问）15 分#

思路
  • 五个小空依次考单位阶跃下的稳态误差、由阶跃响应求脉冲响应、正反馈反求开环传函、一阶系统时间常数的含义与串联校正装置类型判断。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位负反馈系统在单位阶跃输入下的稳态误差
本卷实例
  • 关键一步：先由开环传函判系统型别，再按静态误差系数写稳态误差
  • 中间结果：开环含一个积分环节属I型系统，阶跃输入的稳态误差为零
  • 卡点：未先判稳就直接套用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位负反馈系统在单位阶跃输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应求系统的单位脉冲响应
本卷实例
  • 关键一步：单位脉冲响应等于单位阶跃响应对时间求导，逐项求导即可
  • 中间结果：阶跃响应中的指数项与幂乘指数项分别对应脉冲响应的两项
  • 卡点：把阶跃响应本身当作脉冲响应直接写出
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应求系统的单位脉冲响应
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由单位正反馈的闭环传函反求开环传函
本卷实例
  • 关键一步：按正反馈等效关系写出闭环与开环传函的代数式再反解
  • 中间结果：正反馈分母取一减开环传函，整理后开环传函用闭环传函表示
  • 卡点：正反馈的分母写成1加开环传函，与负反馈混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由单位正反馈的闭环传函反求开环传函
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 说明典型一阶系统时间常数对应的输出百分比
本卷实例
  • 关键一步：由一阶阶跃响应达到稳态值63.2%所需时间定义时间常数
  • 中间结果：时间常数与5%误差带的调节时间成3倍关系，可互相换算
  • 卡点：把输出达到稳态值一半所对应的时刻记成时间常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过说明典型一阶系统时间常数对应的输出百分比
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
超前校正 系统校正
本卷考法
  • 由传递函数形式判断串联校正装置的类型
本卷实例
  • 关键一步：比较分子零点与分母极点的位置，由相频整体超前判断
  • 中间结果：分子时间常数大于分母时间常数且系数a>1时为超前特性
  • 卡点：把参数a与滞后校正的取值方向搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过由传递函数形式判断串联校正装置的类型
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

二二、建模题：结构图求传函20 分#

思路
  • 由系统结构图改画信号流图，数清全部独立回路与前向通路，用梅森增益公式求闭环传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求多回路系统的传递函数
本卷实例
  • 关键一步：先由结构图改画信号流图，再标出全部独立回路与前向通路
  • 中间结果：特征式按单回路与两两不接触回路逐层累加，各通路另求余子式
  • 卡点：系统结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求多回路系统的传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

三三、PI控制系统的稳定K范围25 分#

思路
  • 先把PI控制器与被控对象相乘得开环传函并列劳斯表求稳定K范围；再用s=-2的垂线作变量代换，把极点位置约束化为新系统的稳定条件求另一K范围。
劳斯判据 稳定性分析
本卷考法
  • 列劳斯表求闭环系统稳定时K的取值范围（第(1)问）
本卷实例
  • 关键一步：写出闭环特征方程后列劳斯表，令首列全部为正
  • 中间结果：稳定条件化为K的上界与下界两个不等式再取交集
  • 卡点：首列出现参数为零的边界时未单独讨论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过列劳斯表求闭环系统稳定时K的取值范围（第(1)问）
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由闭环极点实部上限求K的范围（第(2)问）
本卷实例
  • 关键一步：令复变量加2作代换，把极点左移条件化为新系统的稳定条件
  • 中间结果：代换后按劳斯判据得K的另一个上界
  • 卡点：控制结构图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由闭环极点实部上限求K的范围（第(2)问）
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式

四四、积分控制器参数与动态指标20 分#

思路
  • 由输出最大值与峰值时间反求二阶系统的阻尼比与自然频率，据此定积分控制器系数与反馈系数；再逐项算上升时间与两种误差带的调节时间。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间反求二阶系统参数（第(1)问）
本卷实例
  • 关键一步：把闭环传函化为标准二阶形式，再与标准式逐项对应
  • 中间结果：阻尼比由超调量确定，自然频率与阻尼比共同决定峰值时间
  • 卡点：未把二阶项系数归一化就直接对标准形式系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由超调量与峰值时间反求二阶系统参数（第(1)问）
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求上升时间与两种误差带下的调节时间（第(2)问）
本卷实例
  • 关键一步：上升时间由阻尼角与自然频率定，调节时间按误差带取系数
  • 中间结果：5%与2%两种误差带的调节时间系数不同，须分别计算
  • 卡点：把峰值时间与上升时间的公式用反
  • 卡点：系统框图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求上升时间与两种误差带下的调节时间（第(2)问）
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

五五、根轨迹绘制与起始角25 分#

思路
  • 按绘制法则画出四阶系统的根轨迹并求复数极点的起始角，再由与虚轴交点得稳定时K*的取值范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画四阶系统的根轨迹（第(1)问）
本卷实例
  • 关键一步：先把开环传函写成首一因式，标出全部开环极点与实轴段
  • 中间结果：渐近线交于极点实部之和，夹角由极点数与零点数之差决定
  • 卡点：实轴根轨迹段判据中的零极点个数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画四阶系统的根轨迹（第(1)问）
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
出射角与入射角 根轨迹法
本卷考法
  • 求非实轴开环极点的起始角（第(1)问）
本卷实例
  • 关键一步：对复数极点用相角条件列起始角方程，累加其余零极点的相角
  • 中间结果：起始角由其余零极点到该极点的向量相角之和再加180度得到
  • 卡点：累加相角时把该极点自身的相角也算进去了
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
