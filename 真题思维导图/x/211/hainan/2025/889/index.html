1一、填空题（四小问）#

思路
  • 逐个小题按定义作答：先由微分方程求传递函数，再判断偶极子，说明I控制器改善稳态性能的频段，最后写出离散系统的数学工具。
传递函数的定义与基本性质 传递函数
本卷考法
  • 由微分方程求系统传递函数
本卷实例
  • 关键一步：零初始条件下对微分方程两边取拉氏变换，再整理成输出与输入之比
  • 中间结果：把各阶导数系数搬到s的降幂多项式，分母首项系数保持原值
  • 卡点：先声明零初始条件，初始值不能带进拉氏变换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由微分方程求系统传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
零极点分布与响应模态 传递函数
本卷考法
  • 判断一对零极点能否构成偶极子
本卷实例
  • 关键一步：比较这对零极点的间距与各自到原点的距离，看模值是否远大于间距
  • 中间结果：模值远大于相对距离时，这对零极点可按偶极子近似处理
  • 卡点：不能只凭零极点靠近就下结论，还要比较模值与距离的量级
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过判断一对零极点能否构成偶极子
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

PID 控制器与参数整定 系统校正
本卷考法
  • 说明I控制器改善稳态性能的作用频段
本卷实例
  • 关键一步：从积分作用改变低频段斜率、进而影响稳态误差的角度作答
  • 中间结果：积分项主要作用于低频段，但会引入相位滞后
  • 卡点：I控制器需与比例环节配合，单独使用可能影响稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过说明I控制器改善稳态性能的作用频段
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

z 变换与 z 反变换 离散控制系统
本卷考法
  • 说明离散系统常用的数学工具
本卷实例
  • 关键一步：由采样信号的拉氏变换引出z变换，明确其又称采样拉氏变换
  • 中间结果：令z与e的Ts次方对应，把s平面映射到z平面
  • 卡点：映射关系中的T是采样周期，书写时不能漏掉
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • z 变换是离散信号的拉氏变换，令 z=e^{Ts} 得到
  • 常用函数的 z 变换要熟记
  • z 反变换可用部分分式法、幂级数法或留数法
  • 左半 s 平面映射到 z 平面单位圆内
步骤
  • 将连续传递函数展开为部分分式
  • 逐项查表做 z 变换
  • 需要时做 z 反变换求时间序列
通用考法
  • 本卷考过说明离散系统常用的数学工具
  • 求给定函数的 z 变换
  • 求 z 反变换得到采样序列
  • 说明 s 平面与 z 平面的映射关系
常见易错
  • 把 z 变换结果中的 e^{-aT} 写成 e^{-a}
  • 部分分式分解时漏项导致反变换出错

2二、用梅森公式求传递函数#

思路
  • 由结构图改画信号流图，数清全部独立回路与前向通路，按梅森增益公式求闭环传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求多回路系统传递函数
本卷实例
  • 关键一步：先由系统结构图改画信号流图，再标出全部独立回路与前向通路
  • 中间结果：特征式按单回路与两两不接触回路逐层累加，各通路另求余子式
  • 卡点：原卷图1未读，回路数、前向通路增益与接触关系需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求多回路系统传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

3三、稳定性与组合输入稳态误差#

思路
  • 先由闭环特征方程判断稳定性，再按输入分解求稳态误差，最后从提高增益和增加积分环节两方面讨论减小误差的措施。
赫尔维茨判据 稳定性分析
本卷考法
  • 用赫尔维茨判据判断闭环系统稳定性
本卷实例
  • 关键一步：由闭环特征方程写出赫尔维茨行列式，检查各阶主子式符号
  • 中间结果：三阶特征方程只需构造到三阶行列式，系数全正只是必要条件
  • 卡点：不能只验证二阶主子式，必须检查全部阶数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由特征方程系数构造赫尔维茨行列式
  • 各阶主子式全部大于零 ⇔ 系统稳定
  • 与劳斯判据等价，适合阶数较低时使用
步骤
  • 由特征方程系数写出赫尔维茨行列式
  • 依次计算各阶主子式
  • 令全部主子式大于零得到稳定条件
通用考法
  • 本卷考过用赫尔维茨判据判断闭环系统稳定性
  • 用赫尔维茨判据判断稳定性
  • 比较两种代数判据的适用场合
常见易错
  • 行列式构造时系数下标写错
  • 只验证到二阶主子式就下结论

系统型别与静态误差系数 稳态误差
本卷考法
  • 判断系统型别并写出相应静态误差系数
本卷实例
  • 关键一步：先数开环传函中积分环节个数，确定系统型别
  • 中间结果：输入含加速度分量时，需要加速度误差系数参与判断
  • 卡点：开环增益与静态误差系数不是同一概念，不能混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断系统型别并写出相应静态误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求阶跃、斜坡与加速度组合输入下的稳态误差
本卷实例
  • 关键一步：按叠加原理把输入拆成阶跃、斜坡和加速度三个分量分别处理
  • 中间结果：各分量依据系统型别选用对应误差系数，低型别对高阶输入的误差不是有限值
  • 卡点：先确认系统稳定再使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求阶跃、斜坡与加速度组合输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

减小稳态误差的措施 稳态误差
本卷考法
  • 分析减小和消除稳态误差的可行措施
本卷实例
  • 关键一步：从提高开环增益与增加积分环节两方面入手，并校验稳定性
  • 中间结果：增加积分环节可提高型别，但会带来相位滞后与超调增大
  • 卡点：只提高增益而不检查稳定性，可能使系统失稳
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过分析减小和消除稳态误差的可行措施
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

4四、根轨迹与降阶动态性能#

思路
  • 由开环传函画根轨迹并求临界增益，判断稳定范围；再用主导极点概念降阶为二阶系统，按给定阻尼比与极点坐标计算动态指标。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画三阶系统根轨迹
本卷实例
  • 关键一步：先把开环传函化为首一因式，标出全部开环极点与实轴根轨迹段
  • 中间结果：三条渐近线交于极点实部均值，夹角由极点数与零点数之差确定
  • 卡点：开环传函中的0.5s加1需先归一化，否则极点位置会数错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画三阶系统根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹分离点并筛选合理解
本卷实例
  • 关键一步：由特征方程解出K关于s的表达式，再令dK比ds为零
  • 中间结果：分离点方程为一元二次方程，求出的根要按实轴段判据筛选
  • 卡点：落在非根轨迹实轴段上的根必须舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹分离点并筛选合理解
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界增益
本卷实例
  • 关键一步：令s等于jω代入特征方程，并令实部与虚部分别为零
  • 中间结果：虚部方程先给出交点频率，实部方程再给出临界增益
  • 卡点：ω等于零的平凡解需排除，只保留正频率交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向

5五、Bode图反求传函与加速度误差#

思路
  • 先由对数幅频渐近线的低频段斜率与转折频率识别系统型别和典型环节，再写出开环传函，最后按加速度输入求稳态误差。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由Bode图反求最小相位系统开环传函
本卷实例
  • 关键一步：先看低频段渐近线斜率确定积分环节个数，再按各转折频率处的斜率变化判断环节类型
  • 中间结果：低频段斜率与高度分别提供型别和增益信息，剪切频率条件用于校验
  • 卡点：原卷图2未读，转折频率、低频段高度与剪切频率位置需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由Bode图反求最小相位系统开环传函
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

6六、状态转移矩阵#

思路
  • 利用零输入响应关系把两组初值与对应响应排成矩阵，通过右乘初值矩阵的逆求状态转移矩阵。
状态转移矩阵 状态空间分析
本卷考法
  • 由两组零输入响应求状态转移矩阵
本卷实例
  • 关键一步：把两个时刻响应向量按列排成矩阵，再把两个初值向量按列排成矩阵
  • 中间结果：由响应与初值的乘积关系，状态转移矩阵为响应矩阵右乘初值矩阵的逆
  • 卡点：先检查两个初值向量组成的矩阵行列式非零；题末插图未读，若图中有补充条件需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法

  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
