1系统组成与流程图#

思路
  • 由结构图画出流程图，并区分被控对象、控制器、执行器三个角色
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由控制系统图画出流程图
本卷实例
  • 关键一步：流程图与方框图的区别在于：流程图按「能量/物料流向」画，方框图按「信号流向」画
  • 关键一步：先找出给定、测量、比较、控制、执行、对象六个环节，再按物料走向串起来
  • 中间结果：流程图的节点是装置或设备，连线表示物料与能量流向
  • 中间结果：按物料走向把六个环节串成一条链，图中不含信号比较点
  • 卡点：直接把方框图当流程图交，两者不是一回事
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由控制系统图画出流程图
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 判断被控对象、控制器与执行器
本卷实例
  • 关键一步：执行器是「直接改变操纵量」的那个装置（如调节阀、电机）
  • 关键一步：控制器是产生控制信号的那部分；被控对象是最终要控制其输出的设备
  • 中间结果：按「谁产生控制信号、谁改变操纵量、谁被控制」三者分工判断
  • 中间结果：调节阀直接改变燃料或流量，属执行器；控制器输出控制信号
  • 卡点：把执行器与控制器混为一谈；或把检测变送器当成控制器
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤

  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法

  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半

2根轨迹与阻尼比反求极点#

思路
  • G=K*/(s(s²+4s+4))=K*/(s(s+2)²)，n−m=3；第 3 问要求由 ξ=√2/2 反求共轭闭环极点
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制 K* 从 0→∞ 的根轨迹图
本卷实例
  • 关键一步：开环极点：0、−2（二重），无零点 → n=3、m=0
  • 关键一步：渐近线 3 条，交点 σa=(0−2−2)/3=−4/3，夹角 ±60°、180°
  • 中间结果：−2 是二重极点 → 根轨迹在该点附近有分离点，需要单独求
  • 卡点：把二重极点当成一个极点，n 数错导致渐近线条数错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制 K* 从 0→∞ 的根轨迹图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求系统稳定时 K* 的取值范围
本卷实例
  • 关键一步：由开环极点写出闭环特征方程并按降幂整理
  • 中间结果：特征方程含 K*，按劳斯表首列元素大于零列出不等式
  • 卡点：开环有重极点，根轨迹起点与渐近线要按重数处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求系统稳定时 K* 的取值范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 本卷考过只代一个 ω 漏掉另一组交点
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 求存在 ξ=√2/2 的共轭闭环极点时的闭环极点
本卷实例
  • 关键一步：ξ=√2/2 → 阻尼角 β=45°，故实部与虚部绝对值相等：设 s=−σ+jσ
  • 关键一步：把 s 代入特征方程 s(s+2)²+K*=0，令实部虚部同时为零，解出 σ 与 K*
  • 关键一步：两个共轭根就是 −σ±jσ
  • 中间结果：特征方程展开：s³+4s²+4s+K*=0；代入 s=−σ+jσ 后分离实虚部联立
  • 卡点：只求出 σ 不求出 K*；题目问的是「闭环极点」，要给出具体坐标
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过求存在 ξ=√2/2 的共轭闭环极点时的闭环极点
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

滞后校正 系统校正
本卷考法
  • 设计滞后校正装置 Gp=(Ts+1)/(βTs+1) 满足相角裕度与相位滞后要求
本卷实例
  • 关键一步：滞后网络在低频段增益为 1、高频段衰减 1/β；转折频率 1/T 与 1/(βT)
  • 关键一步：题目给了设计准则 β=1/(T·ωc′)，ωc′ 为校正后截止频率
  • 关键一步：该式是把最大相位滞后控制在 −6° 的经验公式
  • 关键一步：先由 γ′=45° 定出新的 ωc′，再代准则式求 T、β 并校验
  • 中间结果：本题 β<1（题面写 0<β<1），与教材 β>1 的写法相反
  • 中间结果：按题面定义走，不要把常见教材公式套反
  • 卡点：β 的定义与教材相反时照抄教材公式，结果全错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过设计滞后校正装置 Gp=(Ts+1)/(βTs+1) 满足相角裕度与相位滞后要求
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

4状态空间标准型#

思路
  • G(s)=(s²+6s+8)/(s²+4s+3)，分子分母同阶 → 存在直接项 D，要分别写可控标准型与对角型
由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 写出可控标准型动态方程
  • 写出对角型动态方程
本卷实例
  • 关键一步：先做长除法分出直接项：G(s)=1+(2s+5)/(s²+4s+3)，故 D=1
  • 关键一步：分母 s²+4s+3=(s+1)(s+3) 两个互异实根 → 可对角化
  • 关键一步：可控标准型：A 为友矩阵 [[0,1],[−3,−4]]，B=[0,1]ᵀ
  • 关键一步：C 由余项分子系数给出，D=1
  • 关键一步：对角型：A=diag(−1,−3)，B=[1,1]ᵀ，C 由部分分式系数给出，D=1
  • 中间结果：余项 (2s+5)/((s+1)(s+3)) 做部分分式分解成两项
  • 中间结果：两个留数就是对应对角型输出矩阵的两个系数
  • 卡点：分子分母同阶时忘记分离直接项 D，导致状态维数与 D 都错
  • 卡点：题目括注「A 为酉矩阵」应理解为「标准型矩阵」（友矩阵/对角阵），不是严格意义上的酉矩阵
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法
  • 本卷考过写出可控标准型动态方程
  • 本卷考过写出对角型动态方程
  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反

5离散系统误差与稳定域#

思路
  • 三问：求闭环误差脉冲传递函数 → 求稳定 K 范围 → 单位斜坡下 ess<0.1 对应的 K 范围
脉冲传递函数 离散控制系统
本卷考法
  • 求闭环误差脉冲传递函数
本卷实例
  • 关键一步：误差脉冲传函 Φe(z)=E(z)/R(z) 的写法取决于采样开关位置
  • 关键一步：一般形式 Φe=1/(1+GH(z))（单位反馈时）
  • 中间结果：误差脉冲传函的分子由反馈通道结构决定，单位反馈时最简
  • 中间结果：连续环节之间无采样开关时要先合并再取 z 变换
  • 卡点：两个连续环节中间无采样开关时直接相乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过求闭环误差脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
