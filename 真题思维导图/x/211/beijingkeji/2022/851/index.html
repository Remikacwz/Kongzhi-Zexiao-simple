一（1-9）一、选择填空题#

思路
  • 第1至9小题依次考开环增益、由单位脉冲响应求闭环传函、二阶欠阻尼系统谐振与超调关系、参数根轨迹等效开环传函、三系统稳态误差与抗高频干扰比较、采样周期对离散稳定的影响、最小相位与稳定性的关系、由频率表求稳定裕度、串联控制器抗高频干扰，以概念判断与简单计算为主。
系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环传函基本环节形式求开环增益
本卷实例
  • 关键一步：把开环传函化为各基本环节时间常数形式
  • 关键一步：各环节比例系数相乘即为开环增益
  • 中间结果：分母各时间常数项归一时分子系数之积等于开环增益
  • 卡点：把分子常数直接当成开环增益会忽略环节系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由开环传函基本环节形式求开环增益
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位脉冲响应求闭环传递函数
本卷实例
  • 关键一步：对脉冲响应求拉氏变换
  • 关键一步：利用脉冲响应等于闭环传函的拉氏逆变换
  • 中间结果：共轭复根对应二阶振荡环节的拉氏变换
  • 卡点：正弦项与余弦项拉氏变换形式不同，需按相角拆开
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位脉冲响应求闭环传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
闭环频率特性与性能指标 频域分析
本卷考法
  • 判断二阶欠阻尼系统谐振与超调的关系
本卷实例
  • 关键一步：写出谐振频率与超调量随阻尼比的变化规律
  • 关键一步：按阻尼比区间比较两者出现条件
  • 中间结果：谐振要求阻尼比小于零点七零七，超调要求阻尼比大于零
  • 卡点：存在超调不一定存在谐振，两者条件宽严不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过判断二阶欠阻尼系统谐振与超调的关系
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 求以参数为变量的等效开环传递函数
本卷实例
  • 关键一步：写出含参数的闭环特征方程
  • 关键一步：把参数相关项与不相关项分离后作比值
  • 中间结果：等效开环传函分母为参数取零时的特征多项式
  • 卡点：参数未完整提到分子会改变根轨迹形状
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过求以参数为变量的等效开环传递函数
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 比较不同结构系统对单位斜坡输入的稳态误差
本卷实例
  • 关键一步：分别判断三个系统的型别与开环增益
  • 关键一步：型别越高斜坡误差越小，同型别比较增益
  • 中间结果：斜坡输入下误差与静态速度误差系数成反比
  • 卡点：抗高频干扰能力由高频段幅值决定，不能只看低频误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过比较不同结构系统对单位斜坡输入的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

采样过程与香农采样定理 离散控制系统
本卷考法
  • 分析采样周期变化对离散系统稳定性的影响
本卷实例
  • 关键一步：增大采样周期会丢失更多连续信号信息
  • 关键一步：把连续系统极点映射到z平面观察稳定性变化
  • 中间结果：采样周期增大使稳定域内参数范围缩小
  • 卡点：采样的相位滞后与稳定性关系容易判反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过分析采样周期变化对离散系统稳定性的影响
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后
公式
最小相位系统与非最小相位系统 频域分析
本卷考法
  • 判断最小相位系统与稳定性的关系
本卷实例
  • 关键一步：由开环零极点是否都在左半平面判断最小相位
  • 关键一步：稳定性由闭环极点位置独立决定
  • 中间结果：最小相位与稳定性是两个独立概念
  • 卡点：把非最小相位与不稳定等同会判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过判断最小相位系统与稳定性的关系
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈
稳定裕度 频域分析
本卷考法
  • 由频率特性表求相位裕度并计算增益调整倍数
本卷实例
  • 关键一步：找幅值等于一处的频率与相角求相位裕度
  • 关键一步：由给定幅值裕度要求反求幅值应放大或缩小倍数
  • 中间结果：幅值裕度分贝值对应幅值的倒数
  • 卡点：相位穿越频率与剪切频率在表中位置容易取错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由频率特性表求相位裕度并计算增益调整倍数
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
PID 控制器与参数整定 系统校正
本卷考法
  • 选择能有效抑制高频干扰的串联控制器
本卷实例
  • 关键一步：比较各控制器在高频段的幅频衰减能力
  • 关键一步：积分分离控制可在低频保留积分、高频削弱积分
  • 中间结果：高频段增益越低抗高频干扰能力越强
  • 卡点：只比较低频段积分作用会选错控制器
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过选择能有效抑制高频干扰的串联控制器
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

二二、结构图求总输出表达式#

思路
  • 由结构图分别对参考输入和扰动输入列出全部前向通路，数清独立回路与不接触回路写特征式，用梅森增益公式求各通道传函后叠加得到总输出。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求多输入系统的总输出
本卷实例
  • 关键一步：分别对参考输入和扰动输入列出全部前向通路
  • 关键一步：数清独立回路与不接触回路写特征式
  • 中间结果：两输入共用同一特征式，输出为两通道传函的叠加
  • 卡点：结构图为原卷插图，回路与通路条数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求多输入系统的总输出
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求多输入作用下的输出叠加表达式
本卷实例
  • 关键一步：把每个输入单独作用时其余输入置零
  • 关键一步：分别求出各通道传函后再叠加
  • 中间结果：总输出等于各输入通道传函与对应输入乘积之和
  • 卡点：扰动作用点不同会使前向通路与符号不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求多输入作用下的输出叠加表达式
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 按多回路逐层化简结构图
本卷实例
  • 关键一步：从最内层反馈环开始合并等效环节
  • 关键一步：逐层向外化简并与梅森公式结果互校
  • 中间结果：逐层化简结果应与梅森增益公式一致
  • 卡点：内外环层次与引出点支路需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

七七、离散系统脉冲传函与稳态误差#

思路
  • 由离散结构图对连续部分作z变换求开环脉冲传函；由闭环特征根是否在单位圆内判断稳定性；再由误差脉冲传函对阶跃加斜坡输入用终值定理求稳态误差。
脉冲传递函数 离散控制系统
本卷考法
  • 由离散结构图求开环脉冲传函
本卷实例
  • 关键一步：对连续部分作z变换并乘采样开关与保持器系数
  • 关键一步：整理成z的有理分式
  • 中间结果：开环脉冲传函分母含z减一的相应次幂
  • 卡点：提示公式中的z变换对需按给定项选用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置

八八、非线性系统相平面分析#

思路
  • 令微分方程中的导数项为零求平衡状态，在各平衡点处线性化并求特征根判断类型；再按类型与等倾线法概略绘制各平衡点附近的相轨迹。
相平面法 非线性系统
本卷考法
  • 求非线性系统的平衡状态并判断其类型
本卷实例
  • 关键一步：令微分方程中的导数项为零求平衡状态
  • 关键一步：在各平衡点处线性化求特征根
  • 中间结果：特征根为异号实根对应鞍点，共轭复根对应焦点
  • 卡点：微分方程形式以宝典段x两阶导减x一阶导减2x加2x三次方等于零为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过求非线性系统的平衡状态并判断其类型
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆
