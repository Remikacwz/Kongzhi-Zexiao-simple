一（1-12）一、选择填空题（12小题）#

思路
  • 逐空查基本概念与常用判据，覆盖稳定范围、PID作用、一阶响应、附加零点、根轨迹条件、峰值时间、离散极点、最小相位、奈氏稳定、误差排序、双线性变换、描述函数自振条件
劳斯判据 稳定性分析
本卷考法
  • 由闭环特征方程求使系统稳定的k范围
本卷实例
  • 关键一步：按s幂次列劳斯表并令首列各元大于零
  • 中间结果：首列不等式给出k的范围
  • 卡点：缺项时未补零再列劳斯表
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由闭环特征方程求使系统稳定的k范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

PID 控制器与参数整定 系统校正
本卷考法
  • 说明PID中积分环节改善的是哪类性能
本卷实例
  • 关键一步：积分环节提高系统的型别
  • 中间结果：型别提高使稳态误差减小，但快速性不改善
  • 卡点：把积分作用说成改善快速性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过说明PID中积分环节改善的是哪类性能
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由一阶系统的单位斜坡响应反求阶跃响应
本卷实例
  • 关键一步：由斜坡响应减去其稳态项得阶跃分量
  • 中间结果：阶跃响应写成含指数衰减的形式
  • 卡点：把时间常数从指数系数上读错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由一阶系统的单位斜坡响应反求阶跃响应
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

本卷考法

本卷实例

  • 中间结果：根轨迹左移令响应加快、超调增大
  • 卡点：把附加零点与附加极点的影响搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过判断附加稳定开环零点对响应速度的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 判断关于根轨迹相角与幅值条件的表述
本卷实例
  • 关键一步：相角条件决定某点是否在根轨迹上
  • 中间结果：只有相角与幅值条件同时满足才对应某K
  • 卡点：把两个条件的用途混在一起
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过判断关于根轨迹相角与幅值条件的表述
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由含远离虚轴极点的闭环传函估算峰值时间
本卷实例
  • 关键一步：用主导极点把高阶分母近似为二阶
  • 中间结果：峰值时间由ωn与ζ按标准式求出
  • 卡点：忽略远离虚轴的极点前未验证主导性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由含远离虚轴极点的闭环传函估算峰值时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

离散系统的动态性能与极点分布 离散控制系统

  • 中间结果：一对共轭且模小于1的极点对应振荡收敛
  • 卡点：把z平面极点当s平面极点直接读阻尼比
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 极点越靠近原点衰减越快，越靠近单位圆振荡越强
  • 极点的幅角决定振荡频率，幅值决定衰减速度
  • 采样周期增大会使动态性能变差甚至不稳定

  • 与连续系统指标对应关系相互校验
通用考法
  • 本卷考过由z平面闭环极点位置判断动态响应类型
  • 由闭环极点分布判断动态性能
  • 与连续域指标互相换算
  • 说明采样周期对动态性能的影响
常见易错
  • 把 z 平面极点当作 s 平面极点直接读阻尼比
  • 忽略单位圆上极点对应等幅振荡

奈奎斯特判据 稳定性分析
本卷考法
  • 由奈氏图判断闭环稳定时的增益范围
本卷实例
  • 关键一步：按曲线包围负1点的情况列条件
  • 中间结果：由包围条件得到g取值区间
  • 卡点：开环含积分环节时未补画无穷大圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由奈氏图判断闭环稳定时的增益范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

用描述函数法分析自振 非线性系统
本卷考法
  • 说明描述函数法判自激振荡的条件
本卷实例
  • 关键一步：把负倒描述函数与线性部分奈氏曲线画在同一复平面
  • 中间结果：两曲线交点对应自振频率与振幅
  • 卡点：未标注A增大的方向就判断交点稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过说明描述函数法判自激振荡的条件
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率

二二、结构图求C(s)/R(s)与E(s)/R(s)并判稳#

思路
  • 由结构图求C(s)/R(s)与误差传函，再列闭环特征方程用劳斯判据判稳
梅森增益公式与信号流图 传递函数
本卷考法
  • 由多回路结构图求闭环传函与误差传函
