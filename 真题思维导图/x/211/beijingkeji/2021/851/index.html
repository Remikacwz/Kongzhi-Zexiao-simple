一（1-9）一、选择填空题#

思路
  • 第1至9小题依次考传递函数定义、二阶系统调节时间、高阶系统近似峰值时间、一阶脉冲响应初值、稳定性定义、PI校正环节、闭环稳定条件、给定竖线右侧的根个数和相轨迹焦点条件，以概念判断与简单计算为主。
传递函数的定义与基本性质 传递函数
本卷考法
  • 判断关于传递函数定义与性质的错误说法
本卷实例
  • 关键一步：从零初始条件、线性定常、单输入单输出三方面逐项核对
  • 关键一步：抓住传递函数由系统结构与参数决定这一要点
  • 中间结果：传递函数只由系统本身的结构与参数决定
  • 卡点：把非零初始条件下的响应也当作传递函数定义会判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过判断关于传递函数定义与性质的错误说法
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 判断二阶系统延迟时间与调节时间说法正误
本卷实例
  • 关键一步：先写出延迟时间与调节时间的常用估算式
  • 关键一步：按分母含阻尼比与自然频率的乘积判断反比关系
  • 中间结果：增大自然频率或阻尼比都会缩短调节时间
  • 卡点：延迟时间与上升时间系数不同，不能套同一估算式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过判断二阶系统延迟时间与调节时间说法正误
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 由远离虚轴极点可忽略近似为二阶系统
本卷实例
  • 关键一步：比较各极点与虚轴距离，舍去实部绝对值大的远极点
  • 关键一步：保留共轭主导极点构成近似闭环传递函数
  • 中间结果：近似传函分母为二次多项式，可读出自然频率与阻尼比
  • 卡点：被舍极点需比主导极点远离虚轴数倍才可忽略
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过由远离虚轴极点可忽略近似为二阶系统
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 求一阶系统单位脉冲响应在零时刻的取值
本卷实例
  • 关键一步：对闭环传函取拉氏逆变换得单位脉冲响应
  • 关键一步：再令时间趋于零求初值
  • 中间结果：一阶系统脉冲响应为指数衰减函数
  • 卡点：题面问初值而非初始斜率，两者取法不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过求一阶系统单位脉冲响应在零时刻的取值
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断动态过程衰减趋于常数对应的系统稳定性
本卷实例
  • 关键一步：由扰动后动态过程是否收敛判断稳定性
  • 关键一步：衰减并趋于常数对应渐近稳定
  • 中间结果：稳定系统的抗扰动能力由动态过程收敛性体现
  • 卡点：把收敛到常数与等幅振荡混同会判错稳定类型
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断动态过程衰减趋于常数对应的系统稳定性
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
PID 控制器与参数整定 系统校正
本卷考法
  • 判断PI调节器属于哪类串联校正环节
本卷实例
  • 关键一步：写出PI控制器含比例与积分项的表达式
  • 关键一步：分析积分项在低频段引入的相位滞后
  • 中间结果：积分作用使控制器相位为负，属滞后校正
  • 卡点：把PI的相位影响误说成超前会选错校正类型
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过判断PI调节器属于哪类串联校正环节
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判定稳定条件与给定竖线右侧的根数
本卷实例
  • 关键一步：先写出闭环特征方程并检查系数是否全为正
  • 关键一步：数实部大于给定值的根数前先作变量平移
  • 中间结果：平移后新特征方程的右半根数就是原方程该竖线右侧的根数
  • 卡点：平移方向写反会把右侧根数算成左侧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判定稳定条件与给定竖线右侧的根数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
相平面法 非线性系统
本卷考法
  • 由二阶微分方程求相轨迹方程并判断焦点稳定性
本卷实例
  • 关键一步：消去时间得相轨迹微分方程
  • 关键一步：由特征根实部与虚部判断奇点类型
  • 中间结果：特征根为共轭复根且实部为负时对应稳定焦点
  • 卡点：把稳定焦点条件写成实部为正会判反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过由二阶微分方程求相轨迹方程并判断焦点稳定性
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

二二、结构图求参考与误差传递函数#

思路
  • 由结构图标出各独立回路和两两不接触关系，用梅森增益公式写出特征式；分别求输出对参考输入的前向通路及余子式，再用单位负反馈关系写出误差传函。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求多回路系统的输出传函
本卷实例
  • 关键一步：数清独立回路并写出各回路增益
  • 关键一步：判断是否存在两两不接触回路并计算特征式
  • 中间结果：特征式由1加各回路增益再减不接触回路增益积组成
  • 卡点：结构图为原卷插图，回路条数与反馈极性需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求多回路系统的输出传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 由闭环输出传函求误差对参考输入的传函
本卷实例
  • 关键一步：按误差定义写出误差与参考输入的拉氏关系
  • 关键一步：代入已求得的闭环输出传函整理
  • 中间结果：单位负反馈下误差传函等于1减闭环输出传函
  • 卡点：误差定义分输入减输出与输入减反馈，非单位反馈时需区分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由闭环输出传函求误差对参考输入的传函
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式

三三、由阶跃响应曲线求参数与调节时间#

思路
  • 由结构图写闭环传函，对照标准二阶形式用单位阶跃响应曲线的峰值时间与超调量反求两个参数，再按给定误差带求调节时间。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应曲线反求结构图参数
本卷实例
  • 关键一步：读曲线峰值时间与超调量两个特征量
  • 关键一步：把它们与闭环传函的阻尼比和自然频率对应
  • 中间结果：两个特征量分别约束阻尼比和自然频率
  • 卡点：曲线为原卷插图，峰值与稳态值需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应曲线反求结构图参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式

奈奎斯特判据 稳定性分析
本卷考法
  • 用奈氏判据判别闭环系统稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数
  • 关键一步：由曲线包围临界点的圈数求闭环右半极点数
  • 中间结果：闭环右半极点数为开环右半极点数减两倍包围圈数
  • 卡点：含积分环节时需补画无穷大半径圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈氏判据判别闭环系统稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

七七、局部反馈校正与最小相位系统#

思路
  • 先说明最小相位系统的定义，再由校正前后幅频特性低频与高频重合、中频段按要求穿越零分贝线的条件，用期望特性法反求局部反馈校正装置传函。
最小相位系统与非最小相位系统 频域分析
本卷考法
  • 说明最小相位系统的定义与判别
本卷实例
  • 关键一步：从开环传函零极点是否都在左半平面判断
  • 关键一步：比较同幅频下相位滞后的最小性

  • 卡点：把闭环零点位置误当作最小相位的判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向

九九、非线性系统描述函数与自激振荡#

描述函数法基础 非线性系统

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
