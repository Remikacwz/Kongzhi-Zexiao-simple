一（1-8）一、选择填空题#

思路
  • 第1至8小题依次考PID的时域表达式、由校正装置零极点转折频率判断校正类型、z域到w域的双线性变换式、含纯延迟系统的稳定范围、无阻尼二阶方程的奇点类型与等倾线、主导极点判据、根轨迹基本概念判断、以及描述函数法对线性部分低通性的要求。
PID 控制器与参数整定 系统校正
本卷考法
  • 写出PID控制器的时域表达式
本卷实例
  • 关键一步：按比例、积分、微分三项叠加写时域关系
  • 关键一步：明确积分项对应误差的累积作用
  • 中间结果：PID时域式为比例项加积分项加微分项
  • 卡点：微分项针对误差求导而不是对输出求导
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过写出PID控制器的时域表达式
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式
滞后校正 系统校正
本卷考法
  • 由校正装置分子分母转折频率判断校正类型
本卷实例
  • 关键一步：写出校正装置的零点与极点转折频率
  • 关键一步：比较零点与极点转折频率的大小
  • 中间结果：α小于一时零点转折频率低于极点转折频率
  • 卡点：把滞后网络与超前网络的零极点位置记反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过由校正装置分子分母转折频率判断校正类型
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

离散系统稳定性分析 离散控制系统
本卷考法
  • 写出由z平面到w平面的双线性变换式
本卷实例
  • 关键一步：由w等于z减一比z加一变形
  • 关键一步：解出用w表示z的表达式
  • 中间结果：该变换把单位圆内映射到左半平面
  • 卡点：分子分母的加减号写反会颠倒映射
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过写出由z平面到w平面的双线性变换式
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

含纯延迟环节的系统稳定性 稳定性分析
本卷考法
  • 求含纯延迟环节的系统稳定时增益范围
本卷实例
  • 关键一步：把延迟环节写成幅值为一、相角滞后的形式
  • 关键一步：令相频等于负一百八十度求临界频率
  • 中间结果：临界频率处幅值等于一给出临界增益
  • 卡点：延迟相角要按弧度与角度正确换算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 延迟环节 e^{-τs} 的幅值为 1、相位为 -τω，只恶化相位
  • 延迟会显著缩小稳定域，τ 越大越难稳定
  • 频域判据需用相位裕度扣除延迟引起的附加滞后
步骤
  • 写出含延迟的开环传递函数
  • 分别求幅值与相位表达式
  • 在相频特性中扣除 τω 的滞后量
  • 按稳定裕度或奈氏判据求临界 τ 或临界 K
通用考法
  • 本卷考过求含纯延迟环节的系统稳定时增益范围
  • 求使系统稳定的最大延迟时间
  • 求含延迟系统的临界开环增益
  • 分析延迟对稳定裕度的影响
常见易错
  • 把延迟环节当成惯性环节处理
  • 相位计算时忘记角度与弧度换算
公式
相平面法 非线性系统
本卷考法
  • 求无阻尼二阶方程的奇点类型与等倾线方程
本卷实例
  • 关键一步：由特征方程解出共轭纯虚根
  • 关键一步：把速度对位移的导数代入运动方程消去时间
  • 中间结果：特征根为共轭纯虚根时奇点为中心点
  • 卡点：等倾线方程里的斜率符号容易写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过求无阻尼二阶方程的奇点类型与等倾线方程
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 判断关于主导极点的错误说法
本卷实例
  • 关键一步：核对主导极点定义中与虚轴距离的倍数条件
  • 关键一步：核对主导极点可以是单实极点或共轭复数极点
  • 中间结果：只限单实极点或一对共轭复数极点的说法不成立
  • 卡点：忽略零点对主导极点近似的影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过判断关于主导极点的错误说法
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 判断关于根轨迹基本概念的错误说法
本卷实例
  • 关键一步：核对零度根轨迹对应的参数变化范围
  • 关键一步：核对相角条件与闭环极点的关系
  • 中间结果：满足相角条件还须满足幅值条件才是闭环极点
  • 卡点：把正反馈零度条件与负反馈一百八十度条件混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过判断关于根轨迹基本概念的错误说法
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

描述函数法基础 非线性系统
本卷考法
  • 判断描述函数法分析对线性部分的要求
本卷实例
  • 关键一步：比较三个线性部分低频增益与高频衰减速度
  • 关键一步：低通特性越好一次谐波近似越精确
  • 中间结果：线性部分低通滤波性能越好描述函数法越精确
  • 卡点：只看低频增益而不看高频衰减会选错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过判断描述函数法分析对线性部分的要求
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

二（1-2）二、负反馈极性与电压调节问答10 分#

思路
  • 两个问答题：一为负反馈极性接反的后果并结合直流电动机调速系统说明；二为由两个电压调节系统的结构与静差判断负载时端电压能否维持给定值。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 分析负反馈极性接反后的反馈性质与后果
本卷实例
  • 关键一步：按反馈极性判断反馈量是增强还是削弱偏差
  • 关键一步：结合直流电动机调速系统说明转速失控过程
  • 中间结果：负反馈接反变成正反馈，系统失去稳定
  • 卡点：只答不稳定而不结合调速系统说明会答不全
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过分析负反馈极性接反后的反馈性质与后果
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由系统型别判断电压调节系统的稳态端电压
本卷实例
  • 关键一步：比较两个系统的结构有无积分环节
  • 关键一步：由型别判断稳态偏差是否为零
  • 中间结果：含伺服执行机构使系统无静差、端电压可维持
  • 卡点：有静差系统的偏差随负载变化而非零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由系统型别判断电压调节系统的稳态端电压
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

三三、由方程组画结构图求闭环传函#

思路
  • 由四个代数方程确定各变量间的传递关系，画出系统结构框图，再用梅森增益公式数回路、写特征式与余子式求闭环传函。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求闭环传递函数
本卷实例
  • 关键一步：由方程组画出结构图并标出前向通路
  • 关键一步：数独立回路并判断两两不接触情况
  • 中间结果：共三条回路，特征式由1减各回路增益得到
  • 卡点：结构图由方程组导出，连线需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由方程组逐层化简多回路系统
本卷实例
