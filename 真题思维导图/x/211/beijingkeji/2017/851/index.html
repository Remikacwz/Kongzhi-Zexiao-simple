一一、结构图多输入输出传函#

思路
  • 结构图有三个输入输出通道，要用梅森公式分别求输出对参考、输出对扰动及误差对参考与扰动的四组传函，再叠加。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求C(s)/R(s)、C(s)/N(s)与总输出C(s)
本卷实例
  • 关键一步：先找全部回路与前向通路，再套梅森公式分别求两路传函
  • 中间结果：分母由各回路增益与不接触回路积组成
  • 卡点：结构图交叉比较点与多输入位置以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求C(s)/R(s)、C(s)/N(s)与总输出C(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路漏计，余子式未剔除接触回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

二二、劳斯判据求稳定 T 范围#

思路
  • 先把开环特征方程写成标准形式，再列劳斯表，由首列全为正解出稳定参数区间。
劳斯判据 稳定性分析
本卷考法
  • 求开环为10(s+1)/[s(Ts+1)²]时使系统稳定的T范围
本卷实例
  • 关键一步：写闭环特征方程并列劳斯表
  • 中间结果：特征多项式为三阶，系数含T²与T
  • 卡点：T本身大于零，解不等式时勿漏符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过求开环为10(s+1)/[s(Ts+1)²]时使系统稳定的T范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过系数有缺项时不补零，或首列出现零未用ε法
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由劳斯表首列不等式求参数区间
本卷实例
  • 关键一步：令劳斯表首列各项大于零求交集
  • 中间结果：稳定域为关于T的一个开区间
  • 卡点：端点T对应临界稳定，不在稳定区间内
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由劳斯表首列不等式求参数区间
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 本卷考过只列部分首列元素不等式
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

三三、根轨迹绘制#

思路
  • 按根轨迹法则画图：开环零点-1、两个重极点0与-100，需确定实轴段、渐近线与分离点。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制k(s+1)/[s²(s+100)]的根轨迹
本卷实例
  • 关键一步：标零点-1与极点0、0、-100，判实轴段与渐近线
  • 中间结果：实轴根轨迹段为[-100,-1]，渐近线交于中点
  • 卡点：有一对重极点，起始角与分离方向需单独说明
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制k(s+1)/[s²(s+100)]的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴根轨迹段判据中零极点个数算错，渐近线夹角公式记错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法

本卷实例
  • 关键一步：由dK/ds=0求分离点
  • 中间结果：候选点中含位于重极点处的解
  • 卡点：s=0对应重极点处，需判断是否落在根轨迹上
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 求根轨迹的分离点坐标

  • 判断解的取舍

四四、扰动与参考共同作用下的稳态误差#

思路
  • 扰动和参考同时作用时分别求各自的误差分量再叠加；改变控制器或对象后要先判稳再看能否用终值定理。
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求单位阶跃扰动单独作用下的稳态误差
本卷实例
  • 关键一步：令R=0写E(s)/N(s)，再用终值定理
  • 中间结果：扰动误差传函分母含控制器与对象乘积
  • 卡点：扰动作用点与误差取出点的相对位置以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求单位阶跃扰动单独作用下的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 本卷考过把扰动误差直接当作总误差，遗漏输入分量
  • 把扰动误差直接当作总误差，遗漏输入分量

五五、由阶跃响应求参数与测速反馈#

思路
  • 由响应曲线读超调量与峰值时间求二阶参数，再由结构图关系写闭环传函，并用测速反馈改变阻尼比。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由开环单位阶跃响应曲线求k、ξ、ωn
本卷实例
  • 关键一步：由曲线读超调量与峰值时间反求阻尼比与自然频率
  • 中间结果：响应曲线为欠阻尼振荡，可读超调与峰值时刻
  • 卡点：响应曲线与系统结构图均以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）

  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

本卷实例

思路
  • 把继电特性描述函数与线性部分频率特性画在同一复平面，由两者交点判断自激振荡并求振幅与频率。
描述函数法基础 非线性系统
本卷考法
  • 写理想继电特性描述函数N(A)=4M/(πA)并绘负倒描述函数曲线
本卷实例
  • 关键一步：按描述函数定义对非线性输出取基波分量
  • 中间结果：负倒描述函数为负实轴上的射线
  • 卡点：负倒描述函数的虚实部要分别说明
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤

  • 与线性部分特性联立判断自振

  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
