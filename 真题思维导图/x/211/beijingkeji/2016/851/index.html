PID 控制器与参数整定 系统校正
本卷考法
  • 第1题写PID控制器的时域表达式与传递函数
本卷实例
  • 关键一步：按比例、积分、微分三项并列写时域关系
  • 中间结果：逐项拉氏变换得并联形式的传递函数
  • 卡点：源文第1题横线处留空，按标准PID形式作答
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过第1题写PID控制器的时域表达式与传递函数
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 本卷考过把积分项与微分项位置写反，或系数对应错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

频率特性的物理意义与求法 频域分析
本卷考法
  • 第2题写开环幅频特性与相频特性表达式
本卷实例
  • 关键一步：把s=jω代入三个环节串联式分别取模与相角
  • 中间结果：幅值相乘、相角相加，含一个积分环节的-90°
  • 卡点：三个典型环节串联，勿把幅频写成各项相加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过第2题写开环幅频特性与相频特性表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 本卷考过求模时漏掉分母各惯性环节的模，相角漏积分项
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

传递函数的定义与基本性质 传递函数
本卷考法
  • 第3题由单位脉冲响应求系统传递函数
本卷实例
  • 关键一步：对脉冲响应逐项作拉氏变换
  • 中间结果：两个一阶项通分后得二阶有理分式
  • 卡点：源文第3题等号右侧OCR缺失，按答案段补全题干
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过第3题由单位脉冲响应求系统传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过把指数项系数直接当极点，漏掉对应分母
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 第4题填自动控制系统性能要求的三个方面及最基本要求
本卷实例
  • 关键一步：按稳定性、快速性、准确性三方面作答
  • 中间结果：三个方面中稳定性是最基本要求
  • 卡点：该知识点无专用ref，借位bc_01，已在备注说明
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过第4题填自动控制系统性能要求的三个方面及最基本要求
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把快速性当成最基本要求，或漏写准确性
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
含纯延迟环节的系统稳定性 稳定性分析
本卷考法
  • 第5题判延迟环节ω由0到正无穷的开环幅相曲线形状
本卷实例
  • 关键一步：延迟环节幅值恒为一、相角随频率线性下降
  • 中间结果：幅相曲线为单位圆
  • 卡点：记住是单位圆而非半圆，相角连续减小
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 延迟环节 e^{-τs} 的幅值为 1、相位为 -τω，只恶化相位
  • 延迟会显著缩小稳定域，τ 越大越难稳定
  • 频域判据需用相位裕度扣除延迟引起的附加滞后
步骤
  • 写出含延迟的开环传递函数
  • 分别求幅值与相位表达式
  • 在相频特性中扣除 τω 的滞后量
  • 按稳定裕度或奈氏判据求临界 τ 或临界 K
通用考法
  • 本卷考过第5题判延迟环节ω由0到正无穷的开环幅相曲线形状
  • 求使系统稳定的最大延迟时间
  • 求含延迟系统的临界开环增益
  • 分析延迟对稳定裕度的影响
常见易错
  • 本卷考过把延迟环节当成幅值随频率衰减的环节
  • 把延迟环节当成惯性环节处理
  • 相位计算时忘记角度与弧度换算

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由型别与静态速度误差系数写出稳态误差由大到小的排序
本卷实例
  • 关键一步：Ⅰ型系统斜坡误差与速度误差系数成反比
  • 中间结果：速度误差系数越大稳态误差越小
  • 卡点：比较前应先判稳，再代入典型输入误差公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤

  • 写出输入信号的拉氏变换

  • 比较不同型别系统的跟踪能力

思路

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把七幅闭环极点分布与七幅二阶系统单位阶跃响应一一对应
本卷实例

  • 中间结果：等幅、衰减振荡、临界、过阻尼与发散各有对应
  • 卡点：极点分布图与响应图均为图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定

  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型

零极点分布与响应模态 传递函数
本卷考法

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由闭环极点分布判断响应模态是单调还是振荡、是否收敛
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错

  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间求二阶系统阻尼比与自然频率
本卷实例

  • 中间结果：两式都含阻尼比与自然频率，需联立

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法

  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围

八八、相角裕度与滞后校正设计#

思路
  • 先求原系统相角裕度并判稳，再按相频要求设计滞后校正装置，最后合并并画校正后对数幅频特性。
稳定裕度 频域分析
本卷考法
  • 求开环系统的相角裕度并判断稳定性
本卷实例
  • 关键一步：由幅频渐近线交点求截止频率，再代入相频
  • 中间结果：相角裕度小于零与劳斯判据结论应一致
  • 卡点：幅频特性图与转折频率以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求开环系统的相角裕度并判断稳定性
  • 求系统的相角裕度与幅值裕度

  • 分析增益变化对裕度的影响
常见易错

  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
