一（1-9）一、填空题#

思路
  • 第1至9小题依次考一阶测温时间常数、由阶跃响应求闭环频率特性、由闭环极点求自然频率与阻尼比、根轨迹相角条件、正弦输入稳态输出、串联滞后校正装置参数、PI控制器作用、s平面到z平面映射、奇点类型与等倾线方程。
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由一阶系统达到稳态值百分之九十八的时间求时间常数
本卷实例
  • 关键一步：写出一阶系统单位阶跃响应表达式
  • 关键一步：令响应达到稳态值给定时限所需的比例条件解出时间常数
  • 中间结果：达到给定百分比所需时间与时间常数成正比
  • 卡点：把百分比对应的指数写成正值会得到错误结果
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由一阶系统达到稳态值百分之九十八的时间求时间常数
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应求闭环传递函数与频率特性
本卷实例
  • 关键一步：对阶跃响应求导或取拉氏变换得闭环传函
  • 关键一步：把s换成jω写闭环频率特性
  • 中间结果：响应含两个衰减指数项，对应两个一阶环节
  • 卡点：由阶跃响应反求时易漏掉稳态项的拉氏变换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应求闭环传递函数与频率特性
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环极点实虚部求自然频率与阻尼比
本卷实例
  • 关键一步：由极点实部等于负阻尼比乘自然频率
  • 关键一步：由虚部等于自然频率乘根号下一减阻尼比平方
  • 中间结果：两式联立可分别解出阻尼比与自然频率
  • 卡点：极点图需回原卷核对图，虚部根号项容易漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环极点实虚部求自然频率与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 判断满足根轨迹相角条件与幅值条件的点
本卷实例
  • 关键一步：相角条件用于判断某点是否在根轨迹上
  • 关键一步：幅值条件用于求该点对应的增益
  • 中间结果：满足相角条件是点位于根轨迹上的充要条件
  • 卡点：把相角条件与幅值条件的用途互换会选错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过判断满足根轨迹相角条件与幅值条件的点
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途

频率特性的物理意义与求法 频域分析
本卷考法
  • 求一阶系统在正弦输入下的稳态输出
本卷实例
  • 关键一步：把闭环传函中的s换成jω得频率特性
  • 关键一步：按幅值相乘相位相加写出同频正弦稳态输出
  • 中间结果：稳态输出幅值为输入幅值乘频率特性在该频率的模
  • 卡点：相位为负的反正切项容易漏掉负号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求一阶系统在正弦输入下的稳态输出
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
滞后校正 系统校正
本卷考法
  • 判断串联滞后校正装置的参数与相频特性
本卷实例
  • 关键一步：写出滞后网络传函并分析分子分母转折频率关系
  • 关键一步：求最大滞后相角及其对应频率
  • 中间结果：滞后网络分子转折频率高于分母故相频为负
  • 卡点：参数取值范围与最大相角公式容易记反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过判断串联滞后校正装置的参数与相频特性
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
PID 控制器与参数整定 系统校正
本卷考法
  • 判断PI控制器各组成部分对系统的作用
本卷实例
  • 关键一步：积分部分提高型别以改善稳态精度
  • 关键一步：比例部分影响动态性能与稳定性
  • 中间结果：积分作用会增大相位滞后而不利于动态性能
  • 卡点：认为只要采用PI控制稳态误差就为零是错的
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过判断PI控制器各组成部分对系统的作用
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

z 变换与 z 反变换 离散控制系统
本卷考法
  • 由s平面点映射到z平面判断单位圆外区域
本卷实例
  • 关键一步：按z等于e的sT次方分解为模与幅角
  • 关键一步：模由实部决定幅角由虚部决定
  • 中间结果：实部大于零时模大于一，点落在单位圆外
  • 卡点：把单位圆外对应实部小于零会判反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • z 变换是离散信号的拉氏变换，令 z=e^{Ts} 得到
  • 常用函数的 z 变换要熟记
  • z 反变换可用部分分式法、幂级数法或留数法
  • 左半 s 平面映射到 z 平面单位圆内
步骤
  • 将连续传递函数展开为部分分式
  • 逐项查表做 z 变换
  • 需要时做 z 反变换求时间序列
通用考法
  • 本卷考过由s平面点映射到z平面判断单位圆外区域
  • 求给定函数的 z 变换
  • 求 z 反变换得到采样序列
  • 说明 s 平面与 z 平面的映射关系
常见易错
  • 把 z 变换结果中的 e^{-aT} 写成 e^{-a}
  • 部分分式分解时漏项导致反变换出错

相平面法 非线性系统
本卷考法
  • 判断给定二阶系统奇点类型并写等倾线方程
本卷实例
  • 关键一步：先求奇点并作变量平移
  • 关键一步：由线性化特征根判断奇点类型
  • 中间结果：特征根为共轭复根且实部为负对应稳定焦点
  • 卡点：等倾线方程由相轨迹斜率等于常数整理得到
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过判断给定二阶系统奇点类型并写等倾线方程
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

二二、由微分方程画结构图并求传函#

思路
  • 对微分方程组逐式在零初始条件下取拉氏变换，按变量关系用比较点和积分环节连接成结构图；再分别令参考输入与扰动输入单独作用，求两个通道的传递函数。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由微分方程组绘制系统结构图
本卷实例
  • 关键一步：对每个微分方程在零初始条件下取拉氏变换
  • 关键一步：按变量关系用比较点和积分环节连接
  • 中间结果：结构图回路数由方程中变量相互引用关系决定
  • 卡点：结构图题面需回原卷核对，逐年OCR缺第1小问
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由微分方程组绘制系统结构图
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求系统对参考输入与扰动输入的传递函数
本卷实例
  • 关键一步：分别令参考输入与扰动输入单独作用
  • 关键一步：从输入到输出找前向通路并共用特征式
  • 中间结果：两通道传函分母相同，差别在前向通路
  • 卡点：扰动作用点与反馈支路的连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求系统对参考输入与扰动输入的传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式

三三、劳斯判据与主导极点估算#

思路
  • 由开环传函写闭环特征方程，用劳斯判据判断稳定性；作变量平移后用新特征方程数变号次数求给定竖线右侧的根数；再由极点分布确定主导极点并估算动态性能指标。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断稳定性及实部大于某值的根数
本卷实例
  • 关键一步：先由特征方程列劳斯表判稳
  • 关键一步：再作变量平移后用新特征方程数变号次数
  • 中间结果：平移后劳斯表首列变号次数等于该竖线右侧的根数
  • 卡点：平移量与数根区间的方向要对应，写反会数错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分

  • 极限环的稳定性可由相轨迹收敛或发散判断
  • 减小非线性影响可用加大线性部分增益或引入校正
  • 用描述函数或相平面结果指导参数选择
步骤
  • 判断系统是否存在极限环并确定其稳定性
  • 分析非线性环节参数对自振幅值频率的影响
  • 通过调整线性部分增益或加入校正削弱自振
  • 重新分析确认自振消除或幅值达标
通用考法
  • 本卷考过分析串联校正装置后自激振荡的变化
  • 提出消除自振的工程措施
  • 分析增益变化对极限环幅值的影响
  • 比较不同方案对稳定性与动态性能的利弊
常见易错
  • 仅调整增益而不检查是否引入新的自振点
  • 把不稳定极限环误判为可观测的自振
