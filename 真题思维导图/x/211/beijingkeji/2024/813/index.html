传递函数的定义与基本性质 传递函数
本卷考法
  • 由开环传函化为尾一标准型求开环增益
本卷实例
  • 关键一步：把各环节写成时间常数形式，常数项归一
  • 关键一步：分子各环节常数项乘积与分母各环节常数项乘积之比即开环增益
  • 中间结果：开环增益为分子常数项与分母常数项之比的量值
  • 卡点：只取分子首项系数当增益；把开环增益与根轨迹增益混同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由开环传函化为尾一标准型求开环增益
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 比较三个频率大小并判断谐振是否存在的阻尼比条件
本卷实例
  • 关键一步：写谐振频率与有阻尼自然频率的表达式
  • 关键一步：由谐振频率根号内为正得阻尼比条件
  • 中间结果：阻尼比小于二分之根号二时谐振存在，无阻尼频率最大
  • 卡点：把有阻尼自然频率与谐振频率的大小关系记反；忽略谐振存在前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过比较三个频率大小并判断谐振是否存在的阻尼比条件
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 由开环传函求零度根轨迹的根轨迹增益
本卷实例
  • 关键一步：把特征方程整理成零度根轨迹的一减等效开环等于零形式
  • 关键一步：由等效开环的常数项写出根轨迹增益
  • 中间结果：零度根轨迹增益与原开环参数的符号关系由整理方式决定
  • 卡点：仍沿用一百八十度根轨迹条件；参数未完整提到分子位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过由开环传函求零度根轨迹的根轨迹增益
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

频率特性的物理意义与求法 频域分析
本卷考法
  • 由奈奎斯特图低频段相位判断时间常数大小关系
本卷实例
  • 关键一步：写开环相频，低频段以积分环节负九十度为基础
  • 关键一步：比较零点与惯性极点相角对总相位的贡献
  • 中间结果：低频相位偏向正侧说明零点时间常数相对最大
  • 卡点：零极点相角的贡献方向易搞反；奈氏图为原卷插图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由奈奎斯特图低频段相位判断时间常数大小关系
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

减小稳态误差的措施 稳态误差
本卷考法
  • 判断各措施对系统精度是否有改善作用
本卷实例
  • 关键一步：分别看积分、增益、微分与补偿对稳态误差的作用
  • 关键一步：微分只改变动态过程，不改变稳态精度
  • 中间结果：改善精度靠提高型别或增益，微分环节无直接作用
  • 卡点：把微分环节与积分环节的作用混淆；误以为微分能消除稳态误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过判断各措施对系统精度是否有改善作用
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

采样过程与香农采样定理 离散控制系统
本卷考法
  • 分析零阶保持器对开环与闭环极点的影响
本卷实例
  • 关键一步：写出零阶保持器的传递函数并并入开环
  • 关键一步：比较加入前后的开环与闭环特征方程
  • 中间结果：零阶保持器保持开环极点不变而改变闭环极点
  • 卡点：把保持器当成纯延迟只改相位；混淆开环与闭环极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过分析零阶保持器对开环与闭环极点的影响
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

信号采样与频谱的基本概念 基本概念与信号
本卷考法
  • 由采样定理判断给定信号能否无失真复原
本卷实例
  • 关键一步：由采样信号的角频率确定采样频率
  • 关键一步：要求被复原信号的最高角频率不超过采样频率的一半
  • 中间结果：只有最高频率不超过一半采样频率的选项可复原
  • 卡点：把采样定理的两倍关系记成相等；把最高频率与频谱延拓周期混同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 周期信号可展开为傅里叶级数，各次谐波的幅值构成频谱
  • 冲激采样信号的频谱是原信号频谱的周期延拓
  • 频谱延拓的周期由采样频率决定，不重叠才能由理想低通恢复原信号
  • 恢复用的理想低通截止频率取在采样频率的一半处
步骤
  • 先求连续信号的频谱或按给定波形求谐波幅值
  • 按采样频率写出延拓后频谱的周期与各次副本的位置
  • 检查最高频率是否小于采样频率的一半，判断能否无失真恢复
  • 需要恢复时选取截止频率与增益合适的理想低通滤波器
通用考法
  • 本卷考过由采样定理判断给定信号能否无失真复原
  • 由采样频率判断给定信号能否无失真恢复
  • 写出冲激采样后信号的频谱表达式
  • 确定恢复滤波器的截止频率
常见易错
  • 把采样定理里的两倍关系记成相等，或漏掉两倍
  • 把最高频率与频谱延拓的周期混为一谈

由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位脉冲响应求闭环传递函数
本卷实例
  • 关键一步：单位脉冲响应与传递函数互为拉氏变换对
  • 关键一步：对各指数项取拉氏变换再通分
  • 中间结果：闭环传函为两个一阶环节之和通分后的有理分式
  • 卡点：把脉冲响应当阶跃响应；通分时系数配错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数

  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位脉冲响应求闭环传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

超前校正 系统校正
本卷考法
  • 由超前校正装置写传函并列最大超前角与对应频率
本卷实例
  • 关键一步：写超前网络的标准形式并令分子分母各为一个时间常数环节
  • 关键一步：按最大超前角公式与对应频率公式代入
  • 中间结果：最大超前角只与分度系数有关，对应频率为两转折频率的几何平均
  • 卡点：把最大超前角公式里的分子分母写反；分度系数取小于一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过由超前校正装置写传函并列最大超前角与对应频率
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

三三、结构图求闭环传递函数#

思路
  • 由系统结构图绘信号流图，找出全部独立回路并写特征式；再数前向通路与余子式，用梅森增益公式写出闭环传函。题面含图未读图。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求多回路系统的闭环传函
本卷实例
  • 关键一步：由结构图数独立回路并写各回路增益
  • 关键一步：列前向通路及对应余子式后代入梅森公式
  • 中间结果：特征式由各回路增益及两两不接触回路的乘积组成
  • 卡点：结构图为原卷插图，回路条数与反馈极性需回原卷核对图；余子式漏项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统

  • 用劳斯判据求系统稳定的K范围
本卷实例
  • 关键一步：由开环传函写闭环特征方程
  • 关键一步：列劳斯表并令首列各元素大于零
  • 中间结果：稳定K范围由两个首列不等式共同确定
  • 卡点：只解一个不等式漏掉另一半；常数项零界不考虑
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求系统稳定的K范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

稳定裕度 频域分析
本卷考法
  • 由幅频与相频求相角裕度
本卷实例
  • 关键一步：把截止频率代入相频
  • 关键一步：用一百八十度加相频得相角裕度
  • 中间结果：校正前相角裕度由两个 arctan 之差表示
  • 卡点：把截止频率与相位穿越频率用反；arctan 合并方向错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由幅频与相频求相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

  • 由校正环节 Bode 图写传函并判断校正类型
