本卷考法

本卷实例
  • 关键一步：写出单位脉冲响应的拉氏变换，得到单位负反馈下的闭环传递函数
  • 关键一步：按单位负反馈关系由闭环传函反解开环传函
  • 中间结果：闭环传函是两个一阶环节之和，通分后为一个有理分式
  • 卡点：反解时开环分母可能出现一次项系数为负的情形，按原题给定的数据整理即可

要点

  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤

本卷实例

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由单位阶跃响应的振荡形态判断二阶阻尼比
本卷实例
  • 关键一步：按二阶系统阻尼比取值区间把响应分成单调、衰减振荡、等幅振荡和发散几类
  • 关键一步：由题给响应曲线的形态定位阻尼比所在区间
  • 中间结果：无阻尼与临界阻尼分别对应特征根落在虚轴上和负实轴上的重根
  • 卡点：把衰减振荡与等幅振荡混同会取错阻尼比区间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由单位阶跃响应的振荡形态判断二阶阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

频率特性的物理意义与求法 频域分析
本卷考法
  • 求线性定常系统在正弦输入下的稳态输出
本卷实例
  • 关键一步：先由单位负反馈写出闭环传函，再把 s 换成 jω 得闭环频率特性
  • 关键一步：在输入频率处求幅频与相频，按幅值相乘、相位相加写稳态输出
  • 中间结果：稳态输出为与输入同频率的正弦量，幅值和初相由闭环频率特性在输入频率处的取值决定
  • 卡点：要在闭环传函上取频率特性，误用开环传函会算错幅值和相位
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求线性定常系统在正弦输入下的稳态输出
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

减小稳态误差的措施 稳态误差
本卷考法
  • 说明积分作用消除稳态误差的代价
本卷实例
  • 关键一步：积分环节使系统型别提高，对应典型输入的稳态误差减小甚至为零
  • 关键一步：同一积分环节增大相位滞后，使稳定裕度下降
  • 中间结果：积分作用在提高准确度的同时削弱稳定性，需要与其他校正方式配合
  • 卡点：只写积分改善稳态性能而漏掉它对稳定性不利的一面
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过说明积分作用消除稳态误差的代价
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

PID 控制器与参数整定 系统校正
本卷考法
  • 由积分时间与微分时间的极限判断控制器简化形式
本卷实例
  • 关键一步：写出 PID 控制器含比例、积分、微分三项的标准表达式
  • 关键一步：令积分时间趋于无穷使积分项消失，令微分时间为零使微分项消失
  • 中间结果：两项分别退掉后控制器只剩下与偏差成比例的一项
  • 卡点：积分时间位于分母，取无穷时积分项才消失，容易与微分时间取零的作用混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过由积分时间与微分时间的极限判断控制器简化形式
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

采样过程与香农采样定理 离散控制系统
本卷考法
  • 分析零阶保持器对采样系统稳定性的影响
本卷实例
  • 关键一步：零阶保持器在采样间隔内保持信号不变，等效引入滞后
  • 关键一步：滞后使相位特性整体下移，相位裕度减小
  • 中间结果：保持器低频幅值接近一，高频衰减并带来附加相位滞后
  • 卡点：只看幅频而不看附加相位滞后，会把稳定性变化的方向判反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过分析零阶保持器对采样系统稳定性的影响
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

  • 说明 s 平面与 z 平面的映射关系
常见易错

描述函数法基础 非线性系统
本卷考法
  • 由继电器描述函数求其负倒特性
本卷实例
  • 关键一步：对题给描述函数取负倒数，写成关于输入振幅的表达式
  • 关键一步：分析振幅趋于零与无穷时负倒特性的走向
  • 中间结果：负倒描述函数落在负实轴上，随振幅变化沿轴移动
  • 卡点：描述函数只随输入振幅变化，误写成频率的函数会失去意义
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过由继电器描述函数求其负倒特性
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

用描述函数法分析自振 非线性系统
本卷考法
  • 由线性部分相位穿越条件确定自激振荡频率
本卷实例
  • 关键一步：写出线性部分的相频特性，令相角等于负一百八十度定出穿越频率
  • 关键一步：再检查该频率处的幅值与负倒描述特性是否相交以确认自振
  • 中间结果：自振频率只由线性部分的相位条件决定，与描述函数的振幅无关
  • 卡点：负倒特性与幅相曲线相交才可能有自振，只算出穿越频率不足以判定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
