一由信号流图求多路传递函数#

思路
  • 按信号流图找出全部回路与前向通路，判断各通路与回路的接触关系，代入梅森公式分别求五个输入到输出的传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图求多路传递函数
本卷实例
  • 关键一步：按回路与前向通路分别列增益并判断接触
  • 中间结果：五个传函共用同一特征式，仅分子前向通路不同
  • 卡点：流图连接以原图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图求多路传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

  • 中间结果：特征式与输入无关，分子随输入位置改变
  • 卡点：初值 e(0+)、i(0+) 也按独立输入处理

二含初值的二阶系统全响应#

思路
  • 由结构图求闭环传函并化为标准二阶形式，结合误差初值换算输出初值，再对含初值的 s 域方程取拉氏反变换求时间响应。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函读出阻尼比与自然频率
本卷实例
  • 关键一步：把二阶项系数归一后对照标准形式
  • 中间结果：系统为欠阻尼，响应含衰减振荡项
  • 卡点：须先由误差初值换算出输出初值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函读出阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由微分方程与初值求系统全响应
本卷实例
  • 关键一步：对含初值的微分方程逐项取拉氏变换
  • 中间结果：响应由初值决定的自由项与输入决定的强迫项组成
  • 卡点：求误差响应时注意 e 与 c 的定义关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由微分方程与初值求系统全响应
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

三延迟系统零度根轨迹#

思路
  • 先用一阶 Pade 近似把延迟环节有理化，写出等效开环传函，再按零度根轨迹的条件绘制并求分离点。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 绘制含延迟近似环节的零度根轨迹
本卷实例
  • 关键一步：把延迟环节近似为有理分式后合并零极点
  • 中间结果：近似后等效开环含一个右半平面零点
  • 卡点：零度与常规根轨迹的相角条件不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过绘制含延迟近似环节的零度根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

四含右半平面零极点的奈氏判稳#

思路
  • 分 a 的两个取值写出开环传函，求幅频相频表达式并画奈氏曲线，按开环右半平面极点数与曲线包围临界点情况判稳。
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅相曲线判断闭环稳定性
本卷实例
  • 关键一步：数开环右半平面极点数 P 并统计包围圈数
  • 中间结果：包围圈数由相位穿越频率处幅值与一比较确定
  • 卡点：积分环节处须补画无穷大半径圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环幅相曲线判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

本卷考法

本卷实例

  • 幅频特性表示各频率正弦输入下的幅值放大倍数

通用考法

  • 求给定传递函数的幅频与相频表达式

  • 说明频率特性的物理含义

五由 Bode 图反求传函与稳定裕度#

思路
  • 由渐近幅频的斜率变化确定系统型别、转折频率与增益，写出开环传函；再求相角裕量并代入组合输入求稳态误差。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频曲线反求开环传递函数
本卷实例
  • 关键一步：由低频段斜率定型别、由转折频率写环节
  • 中间结果：低频高度与各转折频率共同确定增益
  • 卡点：转折频率处斜率变化量对应环节重数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频曲线反求开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

稳定裕度 频域分析
本卷考法
  • 求相角裕量并判断系统稳定性
本卷实例
  • 关键一步：先由幅值条件求截止频率再算相角裕量
  • 中间结果：相角裕量由一百八十度加截止频率处相角给出
  • 卡点：截止频率不能直接取某一个转折频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
