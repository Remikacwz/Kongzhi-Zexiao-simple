一力学系统与电路系统的相似性证明20 分#

思路
  • 分别对弹簧质量阻尼系统与 RLC 网络列时域或复阻抗方程，求出两者输入输出传函并化成同一形式，从而证明两系统相似。
机械系统建模 建模与机电系统
本卷考法
  • 对弹簧质量阻尼系统列力平衡方程
本卷实例
  • 关键一步：对各质量块分别列牛顿第二定律方程
  • 中间结果：相邻弹簧阻尼力按位移差写出
  • 卡点：阻尼力与弹簧力的方向易写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过对弹簧质量阻尼系统列力平衡方程
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 用复阻抗法求 RLC 网络传递函数
本卷实例
  • 关键一步：把电容电感写成复阻抗后按串并联分压
  • 中间结果：网络传函与机械系统传函形式一致
  • 卡点：电容阻抗写成 1/(sC) 而非 sC
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过用复阻抗法求 RLC 网络传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由物理系统求传递函数并比较相似性
本卷实例
  • 关键一步：把两系统传函都整理成分子分母多项式比
  • 中间结果：两个二阶传函的系数结构一一对应
  • 卡点：比较相似性时须把系数按同一物理量归位
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由物理系统求传递函数并比较相似性
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

二闭环特征方程的参数根轨迹20 分#

思路
  • 由闭环特征方程写出等效开环传函，按绘制法则作根轨迹并求分离点与临界增益；再令分离点方程只有唯一非零解确定参数 a。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 由闭环特征方程作等效根轨迹
本卷实例
  • 关键一步：把含参项移到分子并整理成 K 乘开环传函
  • 中间结果：等效开环含二重原点极点与一个零点
  • 卡点：实轴段判据以零极点交替关系为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过由闭环特征方程作等效根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求分离点坐标并确定参数取值
本卷实例
  • 关键一步：由分离点方程判别式为零求参数
  • 中间结果：满足唯一非零分离点条件的参数需筛根
  • 卡点：零分离点与零极点相消的情形须舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求分离点坐标并确定参数取值
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹划分响应单调与振荡的增益区间
本卷实例
  • 关键一步：由闭环极点落在实轴或复平面判断响应形态
  • 中间结果：两分离点把增益轴分成三段
  • 卡点：闭环零点也影响单调性，源文答案有自注
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹划分响应单调与振荡的增益区间
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式

三非最小相位系统的奈氏与 Bode 判稳20 分#

思路
  • 由闭环特征方程求临界稳定的 Kh，再把该值代入开环传函求幅相表达式与对数频率特性，按非最小相位环节的相位特点画图并判稳。
频率特性的物理意义与求法 频域分析
本卷考法
  • 求非最小相位开环系统的幅频与相频
本卷实例
  • 关键一步：把负号环节写成 1-s 后分段求相角
  • 中间结果：幅频单调减而相角单调增
  • 卡点：相角范围须重新按象限判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求非最小相位开环系统的幅频与相频
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
最小相位系统与非最小相位系统 频域分析
本卷考法
  • 识别非最小相位环节并分析相位特点
本卷实例
  • 关键一步：比较同幅频下最小与非最小相位的相频
  • 中间结果：右半平面极点使相位变化方向相反
  • 卡点：右半平面极点与零点对相位影响不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过识别非最小相位环节并分析相位特点
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅相曲线判断闭环临界稳定
本卷实例
  • 关键一步：求曲线与负实轴交点并看是否过临界点
  • 中间结果：临界稳定的 Kh 由特征方程虚根条件给出
  • 卡点：须先数清开环右半平面极点数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环幅相曲线判断闭环临界稳定
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 画开环对数频率特性并读截止频率
本卷实例
  • 关键一步：低频段用渐近线、高频段按转折频率改斜率
  • 中间结果：幅值穿越频率与相角穿越频率相等
  • 卡点：非最小相位系统相位从负一百八十度方向起算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过画开环对数频率特性并读截止频率
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

四由幅相特性反求传函与稳定范围15 分#

思路
  • 由幅相曲线低频段积分环节数与高频段相位走向确定零极点个数，写出传函形式并判断时间常数大小顺序；再按临界点位置分析增益对稳定性的影响。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由幅相特性反求最小相位系统传函
本卷实例
  • 关键一步：由低频相位定积分环节数、由高频相位定阶次差
  • 中间结果：传函为三极点两零点且时间常数依次减小
  • 卡点：曲线以原图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由幅相特性反求最小相位系统传函
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由幅频与相频的极值点判断零极点分布
本卷实例
  • 关键一步：相位先减后增说明存在一对相邻零点极点
  • 中间结果：零极点交替分布决定相位转折方向
  • 卡点：相位极值点不等于转折频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由幅频与相频的极值点判断零极点分布
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
