一由信号流图求闭环传函并画结构图#

思路
  • 按信号流图用梅森公式求闭环传函，再把传函分解为典型环节并还原成结构框图。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图求闭环传递函数
本卷实例
  • 关键一步：用梅森公式列出回路与前向通路
  • 中间结果：四条回路两两接触，无互不接触项
  • 卡点：流图连接以原图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由传递函数画系统结构框图
本卷实例
  • 关键一步：把传函分解为典型环节再按信号流向连接
  • 中间结果：闭环结构含前向通道与单位反馈
  • 卡点：结构图不唯一，须与源文方程一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由传递函数画系统结构框图
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

二一阶系统调节时间与正弦输入全响应#

思路
  • 由闭环传函化为一阶标准形式求时间常数与调节时间；再对正弦输入取拉氏变换，用部分分式反变换求全响应。
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由一阶闭环传函求调节时间
本卷实例
  • 关键一步：把闭环传函写成标准一阶形式读时间常数
  • 中间结果：调节时间与时间常数成正比
  • 卡点：百分之五与百分之二误差带系数不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由一阶闭环传函求调节时间
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 求正弦输入下的一阶系统全响应
本卷实例
  • 关键一步：对输入相角先做时移再取拉氏变换
  • 中间结果：响应含稳态正弦项与衰减自由项
  • 卡点：只求稳态解会漏掉自由响应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过求正弦输入下的一阶系统全响应
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

三采样系统稳定域与稳态误差约束#

思路
  • 由含零阶保持器与延迟环节的结构图求开环脉冲传函，用朱利判据求稳定增益范围，再由稳态误差要求解增益下界并讨论可解条件。
脉冲传递函数 离散控制系统
本卷考法
  • 求含保持器与延迟环节的脉冲传函
本卷实例
  • 关键一步：延迟环节在 z 域对应 z 的负幂
  • 中间结果：开环脉冲传函分母含 z 的方次
  • 卡点：保持器与连续部分须整体离散
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过求含保持器与延迟环节的脉冲传函
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)

离散系统稳定性分析 离散控制系统
本卷考法
  • 用朱利判据求采样系统稳定增益范围
本卷实例
  • 关键一步：由闭环特征方程列朱利表并写不等式组
  • 中间结果：稳定条件落在增益与采样周期的乘积上
  • 卡点：朱利表的首末元素顺序易写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过用朱利判据求采样系统稳定增益范围
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

离散系统的稳态误差 离散控制系统
本卷考法
  • 由稳态误差要求反求增益下界
本卷实例
  • 关键一步：对组合输入用终值定理求稳态误差
  • 中间结果：稳态误差与增益成反比
  • 卡点：求解前须先满足稳定性上界
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差由输入类型与开环脉冲传函中 z=1 处极点的个数决定
  • 型别由 G(z)H(z) 中 z=1 处极点的重数确定
  • 用终值定理求稳态误差，前提是系统稳定
  • 采样周期也影响稳态误差大小
步骤
  • 求误差脉冲传递函数
  • 数出 z=1 处极点重数确定型别
  • 查表或用终值定理求稳态误差
  • 分析采样周期变化对误差的影响
通用考法
  • 本卷考过由稳态误差要求反求增益下界
  • 求离散系统在典型输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 分析采样周期对稳态精度的影响
常见易错
  • 直接用 s 域静态误差系数公式处理离散系统
  • 未判稳就用终值定理

四状态方程稳定性、能控性与极点配置#

思路
  • 由状态方程写矩阵并求特征值判断渐近与输出稳定性，再构造能控性矩阵判能控，最后直接对原系统用待定增益法配置极点。
状态空间表达式的建立 状态空间分析
本卷考法
  • 由状态方程写出 A、b、c 矩阵
本卷实例
  • 关键一步：按状态方程系数直接读矩阵
  • 中间结果：输出矩阵由输出方程系数给出
  • 卡点：注意第二式与第一式的耦合关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由状态方程写出 A、b、c 矩阵
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式
能控性与能观性 状态空间分析
本卷考法
  • 判断系统的能控性
本卷实例
  • 关键一步：求能控性判别矩阵的秩
  • 中间结果：判别矩阵满秩说明系统完全能控
  • 卡点：秩不足时不能任意配置极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断系统的能控性
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
状态反馈与极点配置 状态空间分析
本卷考法
  • 用状态反馈配置极点
本卷实例
  • 关键一步：比较反馈后特征多项式与期望多项式
  • 中间结果：直接代原系统矩阵求解增益向量
  • 卡点：不能先化能控标准型再配置，二者不等效
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过用状态反馈配置极点
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
公式
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由特征值与传函极点判断系统稳定性
本卷实例
  • 关键一步：分别求 A 的特征值与传函极点
  • 中间结果：存在正实部极点时输出不稳定
  • 卡点：状态不稳定不等于输出不稳定，须看对消
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过由特征值与传函极点判断系统稳定性
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

五由根轨迹反求传函与附加零点影响#

思路
  • 由根轨迹图读出开环零极点并写出开环传函，从而得闭环传函；再增加一个负实零点，重新画根轨迹并讨论稳定性变化。
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 由根轨迹图反求闭环传函
本卷实例
  • 关键一步：由根轨迹起点定开环极点、由终点定零点
  • 中间结果：开环传函由零极点与增益构成
  • 卡点：根轨迹图以原图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过由根轨迹图反求闭环传函
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制增加开环零点后的根轨迹
本卷实例
