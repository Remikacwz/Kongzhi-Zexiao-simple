思路
  • 把五个信号关系式按因果顺序连成结构图，注意 R 与 N 两个输入及 X1 反馈支路；再用梅森公式或代数消元求输入与干扰各自的闭环传函。
梅森增益公式与信号流图 传递函数
本卷考法

本卷实例

  • 中间结果：从 R 到 C 有三条前向通道，单独回路两个且互不接触
  • 卡点：X1 反馈支路的接入点易画错，连错会改变回路个数

  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤

  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k

  • 不接触回路找漏或重复计数

思路

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法

本卷实例

  • 中间结果：闭环分母一次项含速度反馈系数，常数项与二次项不含
  • 卡点：需回原卷核对图 2 内环反馈支路的接入点与极性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
