一由方程组画信号流图并用梅森公式求传函#

思路
  • 把五个信号方程整理成因果链，画信号流图或结构图；找出所有前向通道与回路，判断两两是否接触，代入梅森公式求闭环传函。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由方程组对应系统画信号流图并用梅森公式求闭环传函
本卷实例
  • 关键一步：按方程把每个 x 表示为上游信号组合后再连线
  • 中间结果：从 R 到 C 有三条前向通道，单独回路两个且互不接触
  • 卡点：三条前向通道与两个回路的接触关系容易数错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由方程组对应系统画信号流图并用梅森公式求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路找漏或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

二速度反馈系统传函与阻尼稳态指标反求参数#

思路
  • 由题图化简内环速度反馈求闭环传函，对照二阶标准形式写阻尼比与自然频率；由阶跃稳态值不超过给定值和阻尼增加给定值的双条件列三个参数的方程，再代入其中一个参数解出其余取值。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由含内环速度反馈的结构图求闭环传函并化二阶标准形式
本卷实例
  • 关键一步：先化简内环负反馈支路，再按单回路写闭环分母
  • 中间结果：闭环分母一次项含两个参数的乘积，常数项含另两个参数的乘积
  • 卡点：需回原卷核对图 2 内环反馈的接入点与反馈系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由含内环速度反馈的结构图求闭环传函并化二阶标准形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错

  • 化为标准形式时忘记把 s² 项系数归一化

稳定裕度 频域分析
本卷考法
  • 由给定频率处的幅值与相角列出两个方程
本卷实例
  • 关键一步：把频率等于一处的幅值与相角条件分别代入频率特性
  • 中间结果：相角条件化为两个时间常数乘积等于一，幅值条件给出二者之和
  • 卡点：相角为负一百八十度对应该频率处虚部为零，注意分母实部符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
