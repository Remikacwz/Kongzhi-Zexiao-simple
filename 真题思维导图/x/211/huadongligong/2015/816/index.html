二由闭环传函与初值求全响应及动态指标#

思路
  • 由闭环传函写出微分方程并代入非零初值做拉氏变换求全响应；再化为二阶标准形式读出自然频率与阻尼比，按过阻尼情况给出超调量与调节时间。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法

本卷实例

  • 中间结果：阻尼比大于一，系统无超调
  • 卡点：过阻尼时超调公式不适用，σ% 直接为零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角

  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法

  • 本卷考过判断阻尼比大于一时为过阻尼响应

三由闭环特征方程作根轨迹并求参数范围#

思路
  • 把特征方程整理成 1+K(s+1)/[s²(s+a)]=0 的等效开环形式，按法则绘根轨迹；再由分离点与虚轴交点求响应单调或振荡的 K 范围，并讨论只有一个非零分离点时 a 的取值。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 对含一零点两极点的等效开环画根轨迹
本卷实例
  • 关键一步：先把特征方程整理成 1+K(s+1)/[s²(s+a)]=0
  • 中间结果：有两条趋于无穷的轨迹分支
  • 卡点：a=10 与 a=9 时开环极点位置不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过对含一零点两极点的等效开环画根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴段判据中零极点个数算错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
