一由方程组绘制结构图并求三路闭环传函#

思路
  • 由五个信号方程按因果顺序连成结构图，找出两个回路及各自接触关系；再分别令 R、N1、N2 单独作用，用梅森公式求 C/R、C/N1、C/N2。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由含两回路与两个干扰的方程组用梅森公式求传函
本卷实例
  • 关键一步：按方程把 x1 至 x5 依次表示为上游信号组合
  • 中间结果：两个回路，求不同输出时前向通道不同
  • 卡点：N2 的符号为负，回路增益别丢负号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由含两回路与两个干扰的方程组用梅森公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过不接触回路找漏或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

二阶系统标准形式与阻尼比 时域响应与动态性能

  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤

  • 按 ξ 的取值判断响应类型
通用考法

三PID 控制器对根轨迹形状与性能的影响#

思路
  • 在 Gc=1 与串联 PID 两种情况下分别写出等效开环传函，按法则绘根轨迹并求分离点与虚轴交点；再比较引入 PID 零点后根轨迹左移与稳定性的变化。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 分别对两种开环传函绘根轨迹
本卷实例
  • 关键一步：先写出两种情况下等效开环的零极点
  • 中间结果：无零点时渐近线夹角为正负九十度
  • 卡点：PID 引入零点与极点，原极点个数改变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过分别对两种开环传函绘根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错

  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

思路

频率特性的物理意义与求法 频域分析
本卷考法
  • 求含右半平面零极点的幅频与相频表达式
本卷实例
  • 关键一步：把传函写成典型环节再算幅值与相角
  • 中间结果：起点幅值无穷、相角负二百七十度

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
