一由方程组画信号流图并用梅森公式求传函#

思路
  • 把四个信号方程按因果顺序连成信号流图，找出单回路与互不接触回路，再找前向通道并判断其与各回路的接触关系，代入梅森公式求闭环传函。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由四个信号方程画信号流图并用梅森公式求闭环传函
本卷实例
  • 关键一步：按方程把 Y、M、E、D 依次表示为上游信号组合后再连线
  • 中间结果：单回路有四个，其中一对互不接触，前向通道有两条
  • 卡点：两条前向通道与各回路的接触关系不同，余子式取值不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由四个信号方程画信号流图并用梅森公式求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错

  • 本卷考过余子式中未剔除与通路接触的回路
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路

思路

本卷实例

三由正弦稳态响应定参数并判稳求相角裕度#

思路
  • 由结构图求闭环传函，把正弦稳态响应的幅值与相移代入频率特性反求两个结构参数；画出幅相曲线用奈氏判据判稳，再由幅值等于一求截止频率及相角裕度。
频率特性的物理意义与求法 频域分析
本卷考法

  • 相频特性表示输出相对输入的相位差

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负

  • 由 Z=N+P 判断闭环稳定性
