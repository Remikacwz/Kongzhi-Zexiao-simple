1一、弹簧-质块-阻尼器建模与动态指标#

思路
  • 对质块作受力分析列写运动方程，取拉氏变换求传递函数；由阶跃响应的稳态值定弹簧刚度，再由阻尼比与调节时间定自然频率，最后解出质量与阻尼系数。
机械系统建模 建模与机电系统
本卷考法
  • 由弹簧、质量、阻尼元件列写质块的运动方程
本卷实例
  • 关键一步：对质块选定正方向作受力分析，把弹簧力、阻尼力与外力合成为合力
  • 关键一步：弹簧力由两端位移差决定，阻尼力由两端速度差决定
  • 中间结果：整理得到质量乘加速度加阻尼力加弹簧力等于外力的二阶方程
  • 卡点：图 a 为原卷插图，质块连接方式与正方向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 依据牛顿第二定律或达朗贝尔原理列方程
  • 三种基本元件：质量 m、粘性阻尼 f、弹簧 k
  • 同一方向取正，反向取负，逐项列出合力
步骤
  • 选定正方向并作受力分析
  • 分别写出质量、阻尼、弹簧对应的力
  • 按 F=ma 列写运动方程
  • 取拉氏变换整理成传递函数
通用考法
  • 本卷考过由弹簧、质量、阻尼元件列写质块的运动方程
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 两质量块经弹簧阻尼连接的系统建模
常见易错
  • 阻尼力与弹簧力的正负方向取反
  • 多质量系统漏掉相互作用力的反作用项
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 对机械系统运动方程取拉氏变换求位移对力的传递函数
本卷实例
  • 关键一步：在零初始条件下对方程两端做拉氏变换，把外力与位移整理成比值
  • 中间结果：传递函数化为一个比例环节串联一个二阶标准形式
  • 卡点：分母常数项对应弹簧刚度除以质量，别把刚度与增益混写
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过对机械系统运动方程取拉氏变换求位移对力的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把机械系统传函化成标准二阶形式并比对出阻尼比与自然频率
本卷实例
  • 关键一步：把分母二次项系数归一化，再与标准形式逐项比对
  • 中间结果：一次项系数给出两倍阻尼比乘自然频率，常数项给出自然频率平方
  • 卡点：题给阻尼比用来配合调节时间定自然频率，不要与开环增益混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把机械系统传函化成标准二阶形式并比对出阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阶跃响应的稳态值与调节时间反求自然频率
本卷实例
  • 关键一步：由图 b 读出稳态位移，用终值定理把稳态值表示为外力幅值除以弹簧刚度
  • 关键一步：调节时间按百分之二误差带，与阻尼比乘自然频率成反比
  • 中间结果：稳态值定出弹簧刚度，再由调节时间与阻尼比联立解出自然频率
  • 卡点：图 b 为原卷插图，稳态值与调节时间读数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤

  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阶跃响应的稳态值与调节时间反求自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

2二、结构图系统的时域响应与稳态误差#

思路
  • 由前向通道单位阶跃响应反求 G1，与 G2 按反馈等效求闭环传函；用终值定理求稳态输出，再按二阶近似求超调量与调节时间，并求单位阶跃下的稳态误差。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由前向通道的单位阶跃响应反求该通道传递函数
本卷实例
  • 关键一步：单位阶跃响应的拉氏变换等于输入 1/s 乘前向通道传函，据此反解
  • 中间结果：响应含一个指数衰减项，对应前向通道是一个一阶惯性环节
  • 卡点：响应前带常数系数，反求传函时容易把分子系数带错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由前向通道的单位阶跃响应反求该通道传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图按单位负反馈等效求闭环传递函数
本卷实例
  • 关键一步：识别前向通道与反馈通道，按负反馈公式写出前向除以一加回路增益
  • 中间结果：闭环分母化为二次多项式，闭环另带一个一阶零点
  • 卡点：结构图 图 2 为原卷插图，反馈极性与比较点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由结构图按单位负反馈等效求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 闭环含零点时用主导极点近似为二阶系统
本卷实例
  • 关键一步：闭环分母为二阶而分子带零点，属于非标准二阶系统
  • 关键一步：按主导极点把分母当作标准二阶形式近似，零点留待修正
  • 中间结果：由分母系数比对得到阻尼比与自然频率的近似值
  • 卡点：零点会增大超调，直接套标准二阶公式会偏小
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过闭环含零点时用主导极点近似为二阶系统
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求阶跃输入下系统的稳态输出与稳态误差
本卷实例
  • 关键一步：先用劳斯表确认闭环稳定，再对相应传递函数使用终值定理
  • 关键一步：稳态输出取闭环传函直流增益乘输入幅值，稳态误差取误差传函直流增益乘幅值
  • 中间结果：两个小问都归结为求某个传递函数在 s 趋于零时的极限
  • 卡点：稳态输出用闭环传函，稳态误差用误差传函，两者别用同一个
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求阶跃输入下系统的稳态输出与稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、由闭环特征方程作根轨迹#

思路
  • 把闭环特征方程整理成 1 加 K 乘等效开环等于零，按绘制法则作出根轨迹；由分离点处的增益确定单调与阻尼振荡的分界，再由分离点方程重根条件讨论 a 取值。
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 把闭环特征方程化成以增益为可变参数的根轨迹标准形式
本卷实例
  • 关键一步：把特征方程中的增益项单独提出，整理成一加增益乘等效开环等于零
  • 中间结果：等效开环以负一为零点，以零和负 a 为极点
  • 卡点：移项时增益前的符号要对齐，否则零点位置会写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过把闭环特征方程化成以增益为可变参数的根轨迹标准形式
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 标出开环零极点并求渐近线与实轴上的根轨迹段
本卷实例
  • 关键一步：先标出零点与极点，再按某段右侧零极点总数为奇数判断实轴段
  • 中间结果：渐近线交点由极点之和减零点之和再除以极点数与零点数之差
  • 卡点：a 等于十时原点为二重极点，实轴判据要把两条分支都计入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过标出开环零极点并求渐近线与实轴上的根轨迹段
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角

常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

7七、描述函数法分析非线性系统#

思路
  • 把非线性环节与线性环节组成的闭环改写成 1 加 N(A) 乘等效线性部分等于零的形式，求负倒描述函数与线性部分频率特性的交点，由交点和增益比较判断自振与稳定性。
描述函数法基础 非线性系统
本卷考法
  • 由继电特性求描述函数与负倒描述函数
本卷实例
  • 关键一步：按给定幅值的继电特性写出描述函数为四倍幅值除以圆周率乘振幅
  • 关键一步：对描述函数取负倒数，判断它随振幅增大时的变动方向
  • 中间结果：负倒描述函数落在负实轴上，振幅增大时向负无穷方向移动
  • 卡点：非线性环节为原卷插图，幅值与特性类型需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过由继电特性求描述函数与负倒描述函数
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

用描述函数法分析自振 非线性系统
本卷考法
  • 由交点判断自振存在性与稳定方向并求自振参数
本卷实例
  • 关键一步：非线性与线性不是简单串联，先由闭环特征多项式构造等效线性环节
  • 关键一步：比较线性部分在负实轴上的交点与负倒描述函数曲线是否相交
  • 中间结果：交点的振荡频率由线性部分相角为负一百八十度的条件给出
  • 卡点：要标出振幅增大时负倒描述函数的走向，否则极限环稳定性会判反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过由交点判断自振存在性与稳定方向并求自振参数
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率

8八、系统串接、能控性分解与状态反馈#

思路
  • 以 y1 等于 u2 串接两个 SISO 系统得到三阶增广状态空间表达式；构造能控性矩阵判断不完全能控并做能控性分解；再对可控子系统按期望极点配置状态反馈。
状态空间表达式的建立 状态空间分析
本卷考法
  • 把两个系统按输出输入串接建立增广状态方程
本卷实例
  • 关键一步：令第二个系统的输入等于第一个系统的输出并代入，拼成三阶方程组
  • 中间结果：增广系统为三阶，输入只有第一个系统的输入，第二个方程含耦合项
  • 卡点：状态变量顺序要与矩阵分块一致，否则耦合项位置会写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过把两个系统按输出输入串接建立增广状态方程
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

能控性与能观性 状态空间分析
本卷考法
  • 构造能控性矩阵判秩并作能控性分解
本卷实例
  • 关键一步：取输入矩阵及其与系统矩阵的乘积组成能控性矩阵，作变换看秩
  • 关键一步：取能控性矩阵的线性无关列构成变换阵，把系统分为能控与不能控两块
  • 中间结果：秩小于三说明系统不完全能控，不能控子系统的特征值由变换后矩阵的末块给出
  • 卡点：变换阵取法不唯一，但列要满秩且张成能控子空间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过构造能控性矩阵判秩并作能控性分解
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

状态反馈与极点配置 状态空间分析
本卷考法
  • 对能控子系统设计状态反馈使系统极点等于期望值
本卷实例
  • 关键一步：不能控模态无法由反馈改变，先确认它包含在期望极点集合内
  • 关键一步：对能控二阶子系统设反馈阵，令闭环特征多项式等于期望多项式
  • 中间结果：由二次多项式的一次项与常数项系数比出两个反馈增益
  • 卡点：配置后要按可逆变换把子系统的增益换算回原坐标
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过对能控子系统设计状态反馈使系统极点等于期望值
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
