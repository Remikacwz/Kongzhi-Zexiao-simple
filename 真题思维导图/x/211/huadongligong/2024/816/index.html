一一、由方程组画信号流图并用梅森公式求传函15 分#

思路
  • 把五个信号方程按因果关系画成信号流图，找出三个两两接触的回路与各前向通道，判断通路与回路的接触关系，代入梅森公式求闭环传函。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号方程组画信号流图并用梅森公式求传函
本卷实例
  • 关键一步：按方程把各中间信号依次表示为上游信号的组合再连线
  • 关键一步：列出全部回路并判断两两是否接触
  • 中间结果：共三条回路且两两接触，无互不接触项
  • 中间结果：共五条前向通道，其中一条的余子式含单回路项
  • 卡点：源文方程组含 OCR 箭头残迹，需回原卷核对各变量关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号方程组画信号流图并用梅森公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

二二、参数变化对稳定性、动态性能与稳态误差的影响20 分#

思路
  • 由结构图化简求闭环传函并化为标准二阶形式，由阻尼系数随参数变化判断稳定性与超调量、调节时间的变化趋势；再由开环传函求速度误差系数，判断参数对斜坡输入稳态误差的影响。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由含局部反馈的结构图求闭环传递函数
本卷实例
  • 关键一步：先化简局部反馈再与串联环节相乘
  • 关键一步：把结果整理成标准二阶形式
  • 中间结果：闭环特征方程的二阶项系数与参数有关
  • 中间结果：结构图含两个积分环节与一个反馈系数
  • 卡点：需回原卷核对图1中反馈系数的接入位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由含局部反馈的结构图求闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 判断参数增大对阻尼比与动态性能的影响
本卷实例
  • 关键一步：由标准二阶形式的系数读出阻尼比与自然频率
  • 关键一步：分析该参数增大时阻尼比的单调变化
  • 中间结果：参数增大使阻尼比增大、超调量减小
  • 中间结果：调节时间与阻尼比乘自然频率成反比
  • 卡点：自然频率也可能随参数变化，须同时看两者
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过判断参数增大对阻尼比与动态性能的影响
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

系统型别与静态误差系数 稳态误差
本卷考法
  • 求速度误差系数并分析参数对斜坡输入稳态误差的影响
本卷实例
  • 关键一步：由开环传函求速度误差系数
  • 关键一步：按稳态误差等于输入幅值除以速度误差系数分析
  • 中间结果：系统为一型系统，对斜坡输入有差
  • 中间结果：速度误差系数与该参数成反比
  • 卡点：须在稳定前提下讨论误差随参数的变化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过求速度误差系数并分析参数对斜坡输入稳态误差的影响
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

三三、圆轨迹根轨迹、临界参数与调节时间求复根20 分#

思路
  • 由开环传函按法则画根轨迹并证其为圆；由特征方程与虚轴交点求系统稳定条件和临界增益、振荡频率；再由调节时间确定复根实部，代入特征方程求增益与虚部。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制含一个右半平面极点的根轨迹并判断实轴段
本卷实例
  • 关键一步：标出开环零极点并判断实轴上的根轨迹段
  • 关键一步：求渐近线、分离点与虚轴交点
  • 中间结果：实轴段为负无穷到零点的区间与零到正极点区间
  • 中间结果：两分支在实轴上分离后进入复平面
  • 卡点：分离点方程的解须按实轴段筛选
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制含一个右半平面极点的根轨迹并判断实轴段
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界增益与振荡频率
本卷实例
  • 关键一步：把 s 等于 jω 代入闭环特征方程
  • 关键一步：令实部与虚部分别为零并联立求解
  • 中间结果：临界增益对应一对纯虚根
  • 中间结果：临界增益之上系统稳定
  • 卡点：只取到一组非零解时仍要说明另一组对应原点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界增益与振荡频率
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由调节时间要求确定复根实部并反求增益
本卷实例
  • 关键一步：由调节时间公式算出复根实部大小
  • 关键一步：把复根代入特征方程，由实部虚部分别对应系数
  • 中间结果：复根实部与调节时间成反比
  • 中间结果：增益由实部与虚部平方和给出
  • 卡点：调节时间用百分之五误差带对应系数三点五
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由调节时间要求确定复根实部并反求增益
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

四四、非最小相位系统奈氏分析与参数求解20 分#

思路
  • 由开环传函画奈氏曲线，按相位穿越频率判断曲线是否包围临界点，分参数范围讨论稳定性；再由相角、幅值和斜坡稳态误差三个条件联立求系统参数与频率特性。
奈奎斯特判据 稳定性分析
本卷考法
  • 画非最小相位系统奈氏曲线并分参数讨论稳定性
本卷实例
  • 关键一步：求开环右半平面极点数并与曲线包围临界点圈数代入 Z 等于 P 加 N
  • 关键一步：由相位穿越频率处幅值是否大于一判断包围
  • 中间结果：开环无右半平面极点，故包围即不稳定
  • 中间结果：相位穿越频率由令相角等于负一百八十度求得
  • 卡点：右半平面零点使相频曲线与一般惯性环节走向不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过画非最小相位系统奈氏曲线并分参数讨论稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

最小相位系统与非最小相位系统 频域分析
本卷考法
  • 分析非最小相位零点对奈氏曲线与稳定性的影响
本卷实例
  • 关键一步：比较同幅频特性的最小与非最小相位系统相频曲线
  • 关键一步：非最小相位系统相位滞后更大
  • 中间结果：右半平面零点使相位范围明显下移
  • 中间结果：相同幅值条件下更易包围临界点
  • 卡点：勿把右半平面零点与右半平面极点混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过分析非最小相位零点对奈氏曲线与稳定性的影响
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈
系统型别与静态误差系数 稳态误差

五五、由闭环对数幅频特性反求开环传函与增益调整20 分#

思路
  • 由闭环对数幅频特性读出开环型别、转折频率与低频高度写出闭环传函；再由闭环与开环关系反解开环传函并识别典型环节；最后按给定相角裕度求截止频率并反求开环增益。
闭环频率特性与性能指标 频域分析
本卷考法
  • 由闭环对数幅频特性曲线反求闭环与开环传函
本卷实例
  • 关键一步：由起始斜率定型别、由转折频率写闭环传函

本卷实例
  • 关键一步：每个积分器输出取作一个状态变量
  • 关键一步：按状态方程与输出方程连接比例支路与求和点
  • 中间结果：状态反馈增益接在积分器前的求和点
  • 中间结果：输出由状态变量经输出矩阵组合得到
  • 卡点：漏画某条前向支路会使变量维数对不上
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过按状态方程与输出方程画状态变量图
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
