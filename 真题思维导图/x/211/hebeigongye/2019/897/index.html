一1一1、运放电路求传递函数5 分#

思路
  • 由虚短虚断列出节点关系，逐级求运放电路的传递函数。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由含运放的网络列节点方程求输出电压对输入的传递函数
本卷实例
  • 关键一步：用虚短虚断把各级运放输入输出关系写成代数式
  • 中间结果：两级反相组态相乘得到总传函
  • 卡点：每条反馈支路阻抗按复阻抗法求
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由含运放的网络列节点方程求输出电压对输入的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 把运放反相输入组态的传函写成反馈阻抗与输入阻抗之比
本卷实例
  • 关键一步：反相端输入时增益为反馈阻抗与输入阻抗之比
  • 中间结果：级联时两级传函相乘
  • 卡点：勿漏反相组态带来的负号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过把运放反相输入组态的传函写成反馈阻抗与输入阻抗之比
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

一2一2、PID传递函数及参数对输出的影响5 分#

思路
  • 写出PID传函并逐项说明比例系数与积分时间常数变化对闭环性能的作用。
PID 控制器与参数整定 系统校正
本卷考法
  • 写出PID传递函数并说明比例与积分参数对系统的影响
本卷实例
  • 关键一步：把PID写成比例加积分加微分三项之和
  • 中间结果：比例项提高增益，积分项提升型别
  • 卡点：积分时间常数越小积分作用越强
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过写出PID传递函数并说明比例与积分参数对系统的影响
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式

一3一3、状态观测器的目的、与状态反馈的区别与条件5 分#

思路
  • 说明构造观测器的目的、与状态反馈的差别以及可构造条件。
状态观测器设计 状态空间分析
本卷考法
  • 说明状态观测器的作用与可配置极点的条件
本卷实例
  • 关键一步：从状态不可直接测量出发说明需重构状态
  • 中间结果：观测器误差动态由观测器极点决定
  • 卡点：观测器极点应比状态反馈极点更快
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态观测器用输出与输入重构状态，前提是系统能观
  • 极点配置法与龙伯格观测器是两种常用形式
  • 观测器误差动态由 A-LC 的特征值决定
  • 观测器极点通常取得比系统极点快若干倍
步骤
  • 验证系统能观性
  • 写出观测器方程并求误差动态矩阵
  • 按期望特征多项式比较系数求出 L
  • 校验观测器收敛速度是否合适
通用考法
  • 本卷考过说明状态观测器的作用与可配置极点的条件
  • 设计全维状态观测器
  • 由期望观测器极点求反馈增益阵 L
  • 分析观测器与状态反馈组合后的系统极点
常见易错
  • 把观测器增益阵写成了状态反馈增益阵的形式
  • 忽略观测器极点过快会放大噪声
公式
状态反馈与极点配置 状态空间分析
本卷考法
  • 对比状态反馈与观测器在极点配置对象上的区别
本卷实例
  • 关键一步：状态反馈配置闭环极点，观测器配置误差极点
  • 中间结果：两者的可配置条件分别对应能控与能观
  • 卡点：勿把观测器增益与状态反馈增益混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过对比状态反馈与观测器在极点配置对象上的区别
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
公式

二二、复合控制系统的扰动不变性与动态指标10 分#

思路
  • 由扰动完全不变确定前馈通道，再由超调量与峰值时间反求前向增益。
扰动作用下的稳态误差 稳态误差
本卷考法
  • 令扰动到输出的传函为零，求满足扰动不变性的前馈装置
本卷实例
  • 关键一步：把参考输入置零，写扰动到输出的传函
  • 中间结果：前馈装置需抵消扰动通道的传函
  • 卡点：求扰动传函时勿把参考输入留在式中
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过令扰动到输出的传函为零，求满足扰动不变性的前馈装置
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 由结构图写出扰动作用下的输出与误差传递函数
本卷实例
  • 关键一步：按多输入叠加分别写给定与扰动通道
  • 中间结果：两条通道的代数和构成总误差
  • 卡点：勿漏扰动作用点后的环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过由结构图写出扰动作用下的输出与误差传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
反馈校正与复合控制 系统校正
本卷考法
  • 用前馈补偿实现扰动不变性并说明其不影响闭环稳定
本卷实例
  • 关键一步：前馈通道抵消扰动通路，不进入闭环特征方程
  • 中间结果：补偿条件由两通道传函相等给出
  • 卡点：前馈补偿器若含高阶微分则不可实现
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过用前馈补偿实现扰动不变性并说明其不影响闭环稳定
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间两个指标反求阻尼比与自然频率
本卷实例
  • 关键一步：由超调量定阻尼比，再由峰值时间定自然频率
  • 中间结果：两指标联合确定二阶系统参数
  • 卡点：勿把峰值时间当调节时间代入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与峰值时间两个指标反求阻尼比与自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

三三、由闭环重根与等幅振荡条件反求开环传函并求阶跃响应15 分#

思路
  • 由 I 型三阶无零点的结构设开环传函，用闭环重根与临界振荡条件定参数，再求阶跃响应。
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由等幅振荡的频率定根轨迹与虚轴的交点及临界增益
本卷实例
  • 关键一步：把 s 用虚轴频率代入特征方程分离实虚部
  • 中间结果：临界振荡频率给出根轨迹与虚轴交点
  • 卡点：勿只代一个频率而漏掉共轭的另一交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由等幅振荡的频率定根轨迹与虚轴的交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 由闭环重根条件确定三阶系统开环传函的未定参数
本卷实例
  • 关键一步：重根处特征多项式与其导数同为零
  • 中间结果：重根与振荡条件联立定出结构参数
  • 卡点：I 型三阶无零点即三个极点含一个原点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过由闭环重根条件确定三阶系统开环传函的未定参数
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由重根对应的闭环极点求单位阶跃响应
本卷实例
  • 关键一步：由特征根写部分分式再反变换
  • 中间结果：重根使响应出现时间乘指数的项
  • 卡点：重根需按多重极点规则分解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型

思路

本卷考法

本卷实例

  • 中间结果：交点频率为自振角频率、对应振幅为自振幅值
  • 卡点：必须标注振幅增大方向判断自振稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过由负倒描述函数与线性部分传函的交点求自振参数

  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率
