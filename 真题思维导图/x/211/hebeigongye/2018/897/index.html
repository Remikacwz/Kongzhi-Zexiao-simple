一一、填空题：脉冲响应、单调条件与Bode反求25 分#

思路
  • 三空分别考由闭环传函求时域响应、二阶系统单调条件、由对数幅频渐近线反求传函。
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由单位反馈闭环传函部分分式展开，反求单位脉冲与阶跃响应
本卷实例
  • 关键一步：先由开环传函求闭环传函，再作部分分式反变换
  • 中间结果：闭环特征根为两个负实根，响应单调收敛
  • 卡点：勿漏乘输入信号的拉氏变换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由单位反馈闭环传函部分分式展开，反求单位脉冲与阶跃响应
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
零极点分布与响应模态 传递函数
本卷考法
  • 由闭环极点分布判断响应是单调还是振荡并写出模态
本卷实例
  • 关键一步：比较两个实极点的位置，判断为过阻尼
  • 中间结果：响应由两个衰减指数项叠加
  • 卡点：实极点对应单调模态，共轭复根才振荡
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由闭环极点分布判断响应是单调还是振荡并写出模态
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征方程化标准形式，令阻尼比不小于一，反求增益范围
本卷实例
  • 关键一步：把闭环特征方程与二阶标准式逐项比对
  • 中间结果：阻尼比与增益的平方根成正比
  • 卡点：先判系数为正再列阻尼比条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征方程化标准形式，令阻尼比不小于一，反求增益范围
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由低频段高度定增益，由转折频率与斜率变化定环节
本卷实例
  • 关键一步：先读低频渐近线斜率与高度定型别与增益
  • 中间结果：每个转折频率对应一个一阶环节
  • 卡点：斜率变化负四十要写成两个重极点
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由低频段高度定增益，由转折频率与斜率变化定环节
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式

二1二1、幅频相频表达式与滞后环节条件5 分#

思路
  • 列写一阶微分环节的幅频、相频表达式，并由滞后网络标准形式给出参数条件。
频率特性的物理意义与求法 频域分析
本卷考法
  • 写出该环节的幅频与相频解析式并化简相角差
本卷实例
  • 关键一步：把分子分母分别取模再相除，相角相减
  • 中间结果：幅频为两个一阶环节模之比
  • 卡点：相角化简用反正切差角公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过写出该环节的幅频与相频解析式并化简相角差
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
滞后校正 系统校正
本卷考法
  • 对照滞后网络标准式，指出两时间常数应满足的关系
本卷实例
  • 关键一步：把给定传函与滞后网络标准式逐项对应
  • 中间结果：把给定传函对应到滞后网络的分子分母时间常数
  • 卡点：区分滞后与超前看两个时间常数的相对大小
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过对照滞后网络标准式，指出两时间常数应满足的关系
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式

二2二2、线性传函与非线性描述函数的异同5 分#

思路
  • 比较传递函数与描述函数的定义基础、适用对象与相互替代关系。
描述函数法基础 非线性系统
本卷考法
  • 比较描述函数与传递函数的定义、适用条件与分析方法
本卷实例
  • 关键一步：从两者都基于频率响应但定义对象不同切入
  • 中间结果：描述函数只适用于特定非线性环节串联线性部分
  • 卡点：描述函数不是频率的函数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过比较描述函数与传递函数的定义、适用条件与分析方法
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件
公式
非线性系统的特点 非线性系统
本卷考法
  • 说明线性元件无描述函数、非线性元件无传递函数的本质原因
本卷实例
  • 关键一步：从叠加原理是否成立判断两种工具能否使用
  • 中间结果：传递函数依赖线性时不变前提
  • 卡点：勿把非线性系统一概说成不稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过说明线性元件无描述函数、非线性元件无传递函数的本质原因
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定

三三、非最小相位系统的奈氏判稳与PD控制器15 分#

思路
  • 开环含右半平面极点，先补画无穷大圆弧并按公式判稳，再串联PD后重求稳定增益范围。
奈奎斯特判据 稳定性分析
本卷考法
  • 对含右半平面极点的开环作奈氏判据，补画绕行圆弧
本卷实例
  • 关键一步：按开环右半平面极点数与包围圈数计算闭环右半平面极点数
  • 中间结果：幅相曲线与负实轴有无交点决定是否穿越
  • 卡点：含积分或右半平面极点时勿漏补画无穷大圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过对含右半平面极点的开环作奈氏判据，补画绕行圆弧
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由开环传函写出幅频相频，分析幅相曲线走向与交点
本卷实例
  • 关键一步：分别求幅值单调性与相角范围，再画大致走向
  • 中间结果：低频起于负实轴方向的无穷远
  • 卡点：相角计算勿漏积分环节的负九十度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由开环传函写出幅频相频，分析幅相曲线走向与交点
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
PID 控制器与参数整定 系统校正
本卷考法
  • 串联PD控制器后重写开环传函，再用奈氏判据求稳定增益范围
本卷实例
  • 关键一步：把PD写成比例微分形式乘进开环传函
  • 中间结果：微分项引入开环零点改变幅相曲线形状
  • 卡点：零点使幅相曲线相位抬升，勿沿用原曲线
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过串联PD控制器后重写开环传函，再用奈氏判据求稳定增益范围
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式

四四、状态空间对角化、状态转移矩阵与能控能观20 分#

思路
  • 用可逆变换把二阶系统对角化，再求矩阵指数并判断能控能观。
