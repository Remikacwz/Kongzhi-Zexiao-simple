一一、填空：阶跃响应反求传函、能控能观与标准型#

思路
  • 五空分别考阶跃响应反求开环、能控能观条件与能控标准Ⅰ型及特征值。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应反求开环传递函数
本卷实例
  • 关键一步：由响应分量写出闭环传函的极点
  • 中间结果：再由闭环与开环关系反解开环传函
  • 卡点：响应含常数项需先分离稳态分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应反求开环传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由单位负反馈关系把闭环传函化为开环传函
本卷实例
  • 关键一步：用开环等于闭环除以一减闭环的公式
  • 中间结果：开环传函由闭环分母与分子之差给出
  • 卡点：反馈极性不同公式符号不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由单位负反馈关系把闭环传函化为开环传函
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
能控性与能观性 状态空间分析
本卷考法
  • 由能控且能观要求确定待定参数范围
本卷实例
  • 关键一步：分别构造能控与能观判别矩阵
  • 中间结果：令两判别矩阵行列式均不为零
  • 卡点：注意是排除使秩降为不满的取值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过由能控且能观要求确定待定参数范围
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 写能控标准Ⅰ型并说明坐标变换下传函不变
本卷实例
  • 关键一步：按特征多项式系数构造友矩阵与输出阵
  • 中间结果：约旦标准型变换不改变输入输出传函
  • 卡点：特征值由特征方程直接读出
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法
  • 本卷考过写能控标准Ⅰ型并说明坐标变换下传函不变
  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反

二二、由方程组画结构图并求闭环传函#

思路
  • 按方程组连出结构图，用梅森公式写闭环传函。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由系统方程组画结构方框图并用梅森公式求闭环传函
本卷实例
  • 关键一步：按方程组逐条连出各环节与反馈通路
  • 中间结果：回路与不接触回路代入梅森公式
  • 卡点：比较点符号与反馈极性勿画错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由系统方程组画结构方框图并用梅森公式求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 化简含四个回路的系统结构图
本卷实例
  • 关键一步：按回路枚举写出特征式
  • 中间结果：闭环传函为前向通路增益除以特征式
  • 卡点：注意两回路是否互不接触
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过化简含四个回路的系统结构图
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

三三、闭环稳定条件与输入及扰动下的稳态误差#

思路
  • 先由劳斯判据求稳定条件，再分别算给定与扰动误差。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求闭环稳定的参数条件
本卷实例
  • 关键一步：由闭环特征方程列劳斯表
  • 中间结果：令劳斯表首列全大于零得参数范围
  • 卡点：结合增益取值的实际意义
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求闭环稳定的参数条件
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由稳态误差终值要求反求开环增益
本卷实例
  • 关键一步：写误差传函并用终值定理求极限
  • 中间结果：令误差极限等于给定值解出增益
  • 卡点：先判稳再算稳态误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由稳态误差终值要求反求开环增益
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动单独作用下的稳态误差
本卷实例
  • 关键一步：令参考输入为零求扰动误差传函
  • 中间结果：扰动误差由扰动点到误差点的传函给出
  • 卡点：需回原卷核对图确认扰动作用点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求扰动单独作用下的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式

四四、由幅相曲线与对数幅频曲线反求传函#

思路
  • 由图(a)幅相曲线与图(b)对数幅频渐近线分别反求传函。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频渐近特性反求传递函数
本卷实例
  • 关键一步：由低频段斜率定积分环节个数与增益
  • 中间结果：按各转折频率处斜率变化定环节类型
  • 卡点：转折频率处斜率是累加而非替换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频渐近特性反求传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 由开环对数幅频特性确定各转折频率
本卷实例
  • 关键一步：从最低频段起逐段累加斜率
  • 中间结果：由交点频率解出各时间常数
  • 卡点：低频起始高度需乘型别修正
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过由开环对数幅频特性确定各转折频率
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 由幅相频率特性曲线反求二阶传函参数
本卷实例
  • 关键一步：由图读取低频幅值与谐振点相位
  • 中间结果：由幅值与相位条件联立解出参数
  • 卡点：需回原卷核对图读取曲线数值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由幅相频率特性曲线反求二阶传函参数
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

五五、状态响应表达式的证明#

思路
  • 由零初值卷积积分出发，用分部积分证阶跃与斜坡响应式。
状态转移矩阵 状态空间分析
本卷考法
  • 证明阶跃与斜坡输入下状态响应的解析式
本卷实例
  • 关键一步：由零初值状态响应写成卷积积分
  • 中间结果：对积分作分部积分化为矩阵指数形式
  • 卡点：矩阵求逆需保证其可逆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
