二1二1、开环增益对闭环性能的影响#

思路
  • 从稳态精度、动态性能与稳定性三方面分析增大开环增益的双重影响。
减小稳态误差的措施 稳态误差
本卷考法
  • 分析提高开环增益对稳态误差与动态性能的双重影响
本卷实例
  • 关键一步：分别从误差系数与阻尼比两条线分析
  • 中间结果：增益提高降低稳态误差但减小阻尼比
  • 卡点：不能只看精度而忽略稳定性恶化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过分析提高开环增益对稳态误差与动态性能的双重影响
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
