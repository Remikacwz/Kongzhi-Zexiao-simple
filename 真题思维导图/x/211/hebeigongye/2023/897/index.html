一一、填空：传函反求、正弦稳态与实现形式#

思路
  • 四个小空分别由阶跃响应反求开环传函与稳态误差、由正弦稳态输出反求参数、写能观二型与对角线型实现、由超调量反求峰值时间与谐振峰值。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由阶跃响应反求系统开环传递函数
本卷实例
  • 关键一步：把输出响应作拉氏变换并与典型输入响应形式对照
  • 中间结果：响应含时间一次项说明开环含积分环节，指数项对应一阶环节
  • 卡点：单位反馈时开环传函由闭环传函按反馈公式反解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由阶跃响应反求系统开环传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求组合输入下系统的稳态误差
本卷实例
  • 关键一步：把输入分解为阶跃与斜坡分量分别求稳态误差后叠加
  • 中间结果：误差系数由开环传函在原点处的行为确定
  • 卡点：组合输入要分别计算两个分量，不能只算一次
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求组合输入下系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

频率特性的物理意义与求法 频域分析
本卷考法
  • 由正弦稳态输出反求系统参数
本卷实例
  • 关键一步：稳态输出幅值与相角分别由频率特性的模和相角给出
  • 中间结果：输出相角滞后输入 90 度，可用于判断积分环节的贡献
  • 卡点：正弦输入的角频率要代入频率特性，不能当作阶跃处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由正弦稳态输出反求系统参数
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

由传递函数写状态空间表达式 状态空间分析
本卷考法

本卷实例

  • 中间结果：对角线型由传递函数部分分式展开得到，极点即对角元
  • 卡点：对角线型要求极点为互异实数，重极点时须用约当型
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量反求阻尼比与峰值时间
本卷实例
  • 关键一步：由超调量公式反解阻尼比，再用闭环分母系数求自然频率
  • 中间结果：峰值时间由阻尼振荡角频率决定
  • 卡点：峰值时间的分母是自然频率乘根号内一减阻尼比平方
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量反求阻尼比与峰值时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
闭环频率特性与性能指标 频域分析
本卷考法
  • 由阻尼比求闭环谐振峰值
本卷实例
  • 关键一步：谐振峰值按阻尼比的表达式计算，只适用于欠阻尼
  • 中间结果：阻尼比越小谐振峰值越大
  • 卡点：阻尼比大于等于 0.707 时不出现谐振峰，公式不再适用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过由阻尼比求闭环谐振峰值
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

二1二1、非线性系统的奇点及类型#

思路
  • 按绝对值符号分段把方程化为线性形式，由特征根判断奇点类型。
相平面法 非线性系统
本卷考法
  • 确定非线性方程奇点位置并判断其类型
本卷实例
  • 关键一步：按状态正负把含绝对值的方程分段化为线性方程
  • 中间结果：正半轴特征根为纯虚数对应中心点，负半轴为一正一负实根对应鞍点
  • 卡点：绝对值使方程分段，必须分正负两种情况分别讨论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过确定非线性方程奇点位置并判断其类型
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由传递函数矩阵与状态空间实现的关系核对实现是否正确
本卷实例
  • 关键一步：用所求实现的传递函数矩阵与原矩阵逐元素核对
  • 中间结果：同一传递函数矩阵的实现不唯一，但传递函数矩阵必须相同
  • 卡点：不同实现之间用可逆线性变换联系，维数必须一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过由传递函数矩阵与状态空间实现的关系核对实现是否正确
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

二3二3、由对数幅频曲线求相位裕度#

思路
  • 由渐近线反求开环传函与剪切频率，再由相频求相位裕度并判稳。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环对数幅频曲线反求传递函数与剪切频率
本卷实例
  • 关键一步：由低频段斜率定型别，由转折频率写各环节，再由某点幅值定增益
  • 中间结果：幅频曲线过零分贝处的频率即为剪切频率
  • 卡点：曲线以图给出，转折频率与低频段高度需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环对数幅频曲线反求传递函数与剪切频率
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 由剪切频率与相频求相位裕度并判断稳定性
本卷实例
  • 关键一步：相位裕度等于 180 度加剪切频率处的相角
  • 中间结果：相位裕度大于零即闭环稳定
  • 卡点：相角计算要累加积分环节与各惯性环节的贡献
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由剪切频率与相频求相位裕度并判断稳定性
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

二4二4、由误差与裕度要求选择校正方式#

思路
  • 先算原系统的静态误差系数与相角裕度，比较截止频率要求判断应提高截止频率还是降低截止频率，据此选超前或滞后校正。
校正的基本概念与性能指标 系统校正
本卷考法
  • 由稳态误差与相角裕度要求判断原系统的欠缺
本卷实例
  • 关键一步：分别算出原系统误差系数与相角裕度，与要求比较
  • 中间结果：原系统相角裕度不足时应考虑提高裕度的校正方式
