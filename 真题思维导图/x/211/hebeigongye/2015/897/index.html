一1一1、稳态误差与稳定性的关系5 分#

思路
  • 由误差定义判断误差无穷大是否意味着闭环不稳定。
误差定义与误差传递函数 稳态误差
本卷考法
  • 说明稳态误差与闭环稳定性之间无固定对应关系
本卷实例
  • 关键一步：由误差极限定义判断误差仅反映复现精度
  • 中间结果：误差无穷大时系统仍可能稳定
  • 卡点：勿把误差大小当作稳定性判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过说明稳态误差与闭环稳定性之间无固定对应关系
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 从被控量与期望值之差说明稳态误差的含义
本卷实例
  • 关键一步：用输出实际值与期望值之差定义误差
  • 中间结果：误差由系统结构与输入类型共同决定
  • 卡点：不同误差定义会改变误差表达式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过从被控量与期望值之差说明稳态误差的含义
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

一2一2、传递函数实现与状态空间传函的唯一性5 分#

思路
  • 区分由状态空间求传函唯一、而传函的实现不唯一。
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 判断由状态空间表达式求得的传递函数是否唯一
本卷实例
  • 关键一步：给定 A、B、C、D 后传函由预解矩阵乘积唯一确定
  • 中间结果：一个传函可对应无穷多状态空间实现
  • 卡点：勿把实现不唯一误当成传函不唯一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过判断由状态空间表达式求得的传递函数是否唯一
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消
公式
传递函数的定义与基本性质 传递函数
本卷考法
  • 说明传递函数描述的是零初始条件下的输入输出关系
本卷实例
  • 关键一步：明确传函定义以零初始条件为前提
  • 中间结果：外部等价不要求内部状态结构相同
  • 卡点：内部结构不同但外部传函可相同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过说明传递函数描述的是零初始条件下的输入输出关系
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式

一3一3、串联滞后校正装置及其作用5 分#

思路
  • 写出滞后网络传函并说明其压低截止频率改善相角裕度。
滞后校正 系统校正
本卷考法
  • 写出串联滞后校正网络的传递函数
本卷实例
  • 关键一步：按分子时间常数小于分母写出滞后网络
  • 中间结果：低频增益保持、高频幅值被衰减
  • 卡点：两个转折频率写反会变成超前网络
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过写出串联滞后校正网络的传递函数
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
校正的基本概念与性能指标 系统校正
本卷考法
  • 说明滞后校正改善动态性能的机理
本卷实例
  • 关键一步：用高频段衰减换取相角裕度提升
  • 中间结果：截止频率左移使响应速度有所下降
  • 卡点：注意快速性与裕度之间的折衷
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过说明滞后校正改善动态性能的机理
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求
公式

二二、输入与扰动共同作用下的稳态误差15 分#

思路
  • 分别求给定与扰动两路误差，按叠加反求前馈系数。
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动作用下的稳态误差并处理参考输入置零
本卷实例
  • 关键一步：求扰动误差时把参考输入通道置零
  • 中间结果：扰动误差由扰动点到误差点的传函决定
  • 卡点：勿把扰动误差直接当成总误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求扰动作用下的稳态误差并处理参考输入置零
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 结构图含两路输入时分别列写传递函数
本卷实例
  • 关键一步：按叠加原理分别追踪两路信号通路
  • 中间结果：总误差为给定误差与扰动误差之和
  • 卡点：叠加前需确认系统为线性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过结构图含两路输入时分别列写传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由斜坡输入的稳态误差限反求前馈系数
本卷实例
  • 关键一步：用终值定理写出组合误差的极限式
  • 中间结果：令组合误差极限为零可定前馈系数
  • 卡点：先判断稳定再用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由斜坡输入的稳态误差限反求前馈系数
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

三1三1、奈奎斯特曲线与闭环稳定条件10 分#

思路
  • 由开环传函画奈氏曲线，按两个时间常数大小判断包围情况。
奈奎斯特判据 稳定性分析
本卷考法
  • 由幅相曲线判断含积分环节系统的闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数再补画辅助线
  • 中间结果：曲线对负实轴的穿越决定闭环稳定条件
  • 卡点：含积分环节须补画无穷大半径圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由幅相曲线判断含积分环节系统的闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 由开环传函写出幅相频率特性
本卷实例
  • 关键一步：由幅频与相频表达式考察起止段
  • 中间结果：曲线所在象限由两个时间常数大小决定
  • 卡点：参数大小关系改变时曲线形状不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过由开环传函写出幅相频率特性
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式

三2三2、由正弦稳态输出反求二阶参数5 分#

思路
  • 用闭环幅频等于幅值比、相频等于相位差联立求参数。
频率特性的物理意义与求法 频域分析
本卷考法
  • 由正弦输入的幅值比与相位差反求系统参数
本卷实例
  • 关键一步：写出闭环幅频与相频并代入给定频率
  • 中间结果：幅值比为一、相位差为四十五度
  • 卡点：相位差正负与超前滞后关系勿反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
