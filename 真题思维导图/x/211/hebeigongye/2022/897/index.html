一一、填空题：传函反求、校正判别与实现形式#

思路
  • 三个小空分别由阶跃响应反求传函与斜坡稳态误差、判别校正网络超前或滞后、由约当实现写出另一种实现形式并定参数。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由阶跃响应曲线反求系统传递函数
本卷实例
  • 关键一步：把阶跃响应各分量作拉氏变换并整理成有理分式
  • 关键一步：由响应含时间一次项判断系统有积分环节
  • 中间结果：响应由阶跃分量与指数分量组成，对应传函分母可分解
  • 卡点：先取拉氏变换再化简，直接看时域曲线容易漏掉积分环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由阶跃响应曲线反求系统传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由阶跃响应反求传函后计算斜坡输入下稳态误差
本卷实例
  • 关键一步：先从响应反求闭环传函，再写出误差传函用终值定理
  • 中间结果：闭环特征方程含原点根时系统临界稳定，斜坡误差终值发散
  • 卡点：用终值定理前要先判断系统是否稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由阶跃响应反求传函后计算斜坡输入下稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

滞后校正 系统校正
本卷考法
  • 由转折频率与高低频增益判别校正网络类型
本卷实例
  • 关键一步：写出校正网络的两个转折频率并比较其倒数大小
  • 中间结果：高频段幅值小于低频段幅值时为滞后网络
  • 卡点：判别依据是高频增益被衰减还是被提升，不是转折频率的绝对大小
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过由转折频率与高低频增益判别校正网络类型
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

本卷实例

  • 中间结果：两种实现描述同一传函，系数由分母与分子的对应项确定
  • 卡点：约当型与能控型之间要用传递函数作桥梁，不能直接比对矩阵元素
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 最小实现要求系统既能控又能观

  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法

  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反

二1二1、采样周期的选取原则#

思路
  • 说明采样周期应满足香农采样定理，并兼顾信息损失与计算负担。
采样过程与香农采样定理 离散控制系统
本卷考法
  • 说明离散系统采样周期的选取原则与理由
本卷实例
  • 关键一步：采样频率要大于信号有效频谱最高频率的两倍
  • 中间结果：周期过大损失信息并降低动态性能，周期过小增加计算负担
  • 卡点：采样定理比较的是角频率的两倍关系，别写成周期相等
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过说明离散系统采样周期的选取原则与理由
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

二2二2、超前校正表达式与作用#

思路
  • 写出超前校正网络表达式，并说明其对剪切频率、相角裕度与抗干扰的影响。
超前校正 系统校正
本卷考法
  • 写出超前校正装置表达式并说明其作用
本卷实例
  • 关键一步：超前网络写成一加 aTs 除以一加 Ts 的形式，其中 a 大于一
  • 中间结果：超前校正提高剪切频率与相角裕度，不改变稳态精度
  • 卡点：超前校正抬高高频段增益，抗干扰能力会下降
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过写出超前校正装置表达式并说明其作用
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

二3二3、以电路变量为状态变量列状态方程#

思路
  • 由电感伏安关系与电容电流关系把状态导数表示成状态与输入的线性组合，先用电阻串并联消去非状态变量。
状态空间表达式的建立 状态空间分析
本卷考法
  • 以指定电流与电容电压为状态变量列写电路状态方程
本卷实例
  • 关键一步：用电感与电容的伏安关系把状态导数写成状态与输入的组合
  • 中间结果：先由电阻串并联关系消去非状态变量再整理成矩阵形式
  • 卡点：状态变量选的是指定电流与电压，不是随意选取
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过以指定电流与电容电压为状态变量列写电路状态方程
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

二4二4、稳态输出与动态指标#

思路
  • 由结构图求闭环传函，对照二阶标准形式读出阻尼比与自然频率，再算稳态输出、峰值时间与超调量。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函求自然频率与阻尼比
本卷实例
  • 关键一步：把闭环分母与二阶标准形式逐项对照，常数项开方得自然频率
  • 中间结果：一次项系数与自然频率之比的一半即为阻尼比
  • 卡点：要先把分母二次项系数归一化再对照标准形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函求自然频率与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率求峰值时间与超调量
本卷实例
  • 关键一步：峰值时间由阻尼振荡角频率决定，超调量只与阻尼比有关
  • 中间结果：阻尼比在零到一之间才属欠阻尼，公式才适用
  • 卡点：超调量公式中的指数含阻尼比与圆周率，别漏掉根号项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率求峰值时间与超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

二5二5、调节时间缩短与增益保持#

思路
  • 由调节时间与时间常数成正比先定出新的闭环时间常数，再由总增益不变给反馈增益与前向增益一个约束。
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由一阶系统调节时间与时间常数的关系反求时间常数
本卷实例
  • 关键一步：一阶系统调节时间近似等于三倍时间常数
