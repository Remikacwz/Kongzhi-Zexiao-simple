1一、RLC频响与二阶系统性能指标#

思路
  • 由RLC电路在给定频率处的幅值与相角反求传递函数；再由二阶闭环传递函数分母与标准形式对照，读出自然频率与阻尼比后求谐振频率与谐振峰值
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由RLC电路的频率特性反求系统传递函数
本卷实例
  • 关键一步：按电路结构列出以元件参数表示的传递函数形式
  • 关键一步：把给定角频率处的幅值与相角条件代入，建立待定参数方程
  • 中间结果：源文给出角频率10rad/s处幅值为1、相角为负90度
  • 卡点：RLC电路为原卷插图，元件串并联关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由RLC电路的频率特性反求系统传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

由响应曲线反求传递函数 传递函数
本卷考法
  • 由指定频率点的幅值与相角反求传递函数参数
本卷实例
  • 关键一步：幅值与相角各提供一个条件，与待定元件参数个数对应后联立求解
  • 中间结果：相角为负90度可用来判断积分环节或一阶微分环节的个数
  • 卡点：频率点幅值两种源文的印法不一致，取值需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由指定频率点的幅值与相角反求传递函数参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传递函数系数求自然频率与阻尼比
本卷实例
  • 关键一步：把分母与二阶标准形式逐项对照，常数项开方得自然频率
  • 关键一步：一次项系数与自然频率之比的一半即为阻尼比
  • 中间结果：分母一次项系数为1、常数项为25，据此可得自然频率与阻尼比
  • 卡点：阻尼比小于1才属欠阻尼，才能继续求谐振频率与谐振峰值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传递函数系数求自然频率与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

闭环频率特性与性能指标 频域分析
本卷考法
  • 由阻尼比与自然频率求谐振频率与谐振峰值
本卷实例
  • 关键一步：谐振频率在自然频率基础上乘根号内一减二倍阻尼比平方
  • 关键一步：谐振峰值按阻尼比的表达式计算，只对欠阻尼有定义
  • 中间结果：阻尼比很小时根号内的量为正，谐振频率略小于自然频率
  • 卡点：阻尼比大于等于0.707时不出现谐振峰，公式不再适用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过由阻尼比与自然频率求谐振频率与谐振峰值
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

2二、稳态误差条件与基本概念简答#

思路
  • 四个小问分别考闭环系统在典型输入下稳态误差为零的条件、描述函数的定义与近似性、经典稳定性与李雅普诺夫稳定性的区别、以及能控性定义与零极点对消的关系
系统型别与静态误差系数 稳态误差
本卷考法
  • 判断典型输入下稳态误差为零所需系统型别
本卷实例
  • 关键一步：把闭环传递函数写成一般有理式后，看开环等效含几个积分环节
  • 关键一步：阶跃、斜坡与加速度输入分别对应零阶、一阶与二阶无差度
  • 中间结果：稳态误差是否为零取决于开环增益中积分环节的个数
  • 卡点：判别的是开环型别而非闭环分母次数，需按误差传递函数理解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断典型输入下稳态误差为零所需系统型别
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 说明不同典型输入下稳态误差为零的条件
本卷实例
  • 关键一步：分别取阶跃、斜坡与加速度输入，用终值定理考察误差传递函数
  • 中间结果：加速度输入要求开环至少含两个积分环节
  • 卡点：终值定理使用前需确认系统稳定，否则结论不成立
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过说明不同典型输入下稳态误差为零的条件
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

描述函数法基础 非线性系统
本卷考法
  • 说明描述函数的定义与近似原因
本卷实例
  • 关键一步：描述函数是正弦输入下非线性环节基波分量与输入正弦的复数比
  • 中间结果：只取基波而忽略高次谐波，因此得到的结果是近似的
  • 卡点：描述函数依赖输入幅值，不要写成频率的函数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过说明描述函数的定义与近似原因
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 辨析经典稳定性与李雅普诺夫稳定性的适用范围
本卷实例
  • 关键一步：经典稳定性从输入输出关系出发，主要针对线性定常系统
  • 关键一步：李雅普诺夫稳定性从状态空间内部出发，可用于非线性与时变系统
  • 中间结果：两者的稳定概念与适用对象不同，判据不能直接互换
  • 卡点：不要把李雅普诺夫意义上的稳定与输出有界混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过辨析经典稳定性与李雅普诺夫稳定性的适用范围
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

能控性与能观性 状态空间分析
本卷考法
  • 说明能控性定义及零极点对消的影响
本卷实例
  • 关键一步：能控性指存在控制使任意初态在有限时间到达指定状态
  • 关键一步：传递函数实现中出现零极点对消会丢失内部模态
  • 中间结果：对消后系统的能控性由被约去的模态决定
  • 卡点：能控性针对状态空间实现，不能只从约简后的传函判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过说明能控性定义及零极点对消的影响
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

3三、误差计算与内反馈对稳定性的影响#

思路
  • 先用终值定理分别计算参考输入与扰动输入引起的稳态误差，再讨论内反馈环节参数变化时闭环特征方程与稳定性的走向
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求阶跃加斜坡参考输入下的稳态误差
本卷实例
  • 关键一步：把参考输入拆成阶跃与斜坡两部分，分别乘对应误差传递函数后取终值相加
  • 中间结果：两部分按系统型别取相应误差系数，量纲不同需分开累加
  • 卡点：输入含斜坡时静态速度误差系数起主要作用，型别判错会使结果整体错位
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查

  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求阶跃加斜坡参考输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动输入作用下的稳态误差
本卷实例
  • 关键一步：从扰动作用点写到输出或误差的传递函数，再对单位阶跃扰动取终值
  • 中间结果：扰动误差与参考误差的传递路径不同，需分别列写
  • 卡点：扰动入口位置要看结构图，逐层化简易漏支路，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求扰动输入作用下的稳态误差
  • 求扰动引起的稳态误差

  • 卡点：从重极点出发的多条分支可能同时穿越，不能只取其中一条

  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤

  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向

  • 求根轨迹与虚轴的交点及临界增益

  • 判断根轨迹穿越虚轴的方向
常见易错

  • 得到 K 后没有回到原题核对参数定义

9九、单位脉冲响应与全维状态观测器设计#

思路
  • 由传递函数求单位脉冲响应及其一阶导，再选定一种状态空间实现，按期望极点配置全维观测器反馈阵并写出观测器方程
零极点分布与响应模态 传递函数
本卷考法
  • 由传递函数的极点分布求单位脉冲响应
本卷实例
  • 关键一步：单位脉冲输入时输出等于传递函数本身，做部分分式展开后查表反变换
  • 中间结果：分母极点为原点与负实轴上的一个实极点，响应含常数项与指数衰减项
  • 卡点：脉冲响应是零状态响应，初值需用初值定理核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过由传递函数的极点分布求单位脉冲响应
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

线性微分方程的时域求解与全响应 基本概念与信号
本卷考法

本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端

  • 检查求得的解在零时刻是否等于给定初值
通用考法

  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应

常见易错
