一一、填空：稳态误差、传函、正弦稳态、判稳、采样、延迟稳定#

思路
  • 六空分别用稳态误差、状态空间求传函、正弦稳态幅相、奈氏判稳、采样定理与延迟稳定条件求解。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡稳态误差要求反求开环增益范围
本卷实例
  • 关键一步：判稳后由静态速度误差系数写出误差与其倒数关系
  • 中间结果：斜坡误差等于静态速度误差系数的倒数
  • 卡点：误差限是不等式，解出的是增益下界
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位斜坡稳态误差要求反求开环增益范围
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由状态空间表达式求输入到输出的传递函数
本卷实例
  • 关键一步：先求 sI 减 A 的逆矩阵再乘 B 与 C
  • 中间结果：传函分母为二阶特征多项式、分子为一阶多项式
  • 卡点：输出只取状态第二分量，勿写成全状态线性组合
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过由状态空间表达式求输入到输出的传递函数
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

频率特性的物理意义与求法 频域分析
本卷考法
  • 由正弦输入的幅值与相位条件反求系统参数
本卷实例
  • 关键一步：写出闭环幅频与相频表达式并代入给定频率
  • 中间结果：幅值相等对应幅频等于一、相位差九十度对应相角
  • 卡点：相位差的正负号与超前滞后关系勿反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由正弦输入的幅值与相位条件反求系统参数
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

奈奎斯特判据 稳定性分析
本卷考法
  • 由幅相曲线判断含积分环节系统的稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数再按型别补画辅助线
  • 中间结果：判别式由包围圈数与该极点数之差给出
  • 卡点：幅相曲线以图给出，包围圈数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由幅相曲线判断含积分环节系统的稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

采样过程与香农采样定理 离散控制系统
本卷考法
  • 写出香农采样定理对采样频率的要求
本卷实例
  • 关键一步：把采样定理表述为采样频率不低于最高频率的两倍
  • 中间结果：临界采样频率等于信号最高频率的两倍
  • 卡点：是最高频率而非最高角频率，注意两倍关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过写出香农采样定理对采样频率的要求
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后

含纯延迟环节的系统稳定性 稳定性分析
本卷考法
  • 求含纯延迟环节系统闭环稳定的增益范围
本卷实例
  • 关键一步：由相位条件求相位穿越频率再代入幅值条件
  • 中间结果：稳定条件由幅值小于一整理成增益的不等式
  • 卡点：相位计算别忘了弧度与角度换算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 延迟环节 e^{-τs} 的幅值为 1、相位为 -τω，只恶化相位
  • 延迟会显著缩小稳定域，τ 越大越难稳定
  • 频域判据需用相位裕度扣除延迟引起的附加滞后
步骤
  • 写出含延迟的开环传递函数
  • 分别求幅值与相位表达式
  • 在相频特性中扣除 τω 的滞后量
  • 按稳定裕度或奈氏判据求临界 τ 或临界 K
通用考法
  • 本卷考过求含纯延迟环节系统闭环稳定的增益范围
  • 求使系统稳定的最大延迟时间
  • 求含延迟系统的临界开环增益
  • 分析延迟对稳定裕度的影响
常见易错
  • 把延迟环节当成惯性环节处理
  • 相位计算时忘记角度与弧度换算

二1二1、非线性系统的特征#

思路
  • 从叠加性、多稳态、自激振荡等方面说明非线性系统与线性系统的本质差别。
非线性系统的特点 非线性系统
本卷考法
  • 说明非线性系统与线性系统的本质差别与特有现象
本卷实例
  • 关键一步：按叠加性、稳定性、自振、响应对照逐条比较
  • 中间结果：非线性不满足叠加原理且可能存在多个平衡点
  • 卡点：勿把线性化后的结论无条件搬到非线性系统
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过说明非线性系统与线性系统的本质差别与特有现象
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定

二2二2、状态反馈条件与状态观测器#

思路
  • 说明状态反馈的可控性条件与目的，以及状态观测器的作用，并指出二者的配合关系。
状态反馈与极点配置 状态空间分析
本卷考法
  • 说明系统进行状态反馈的条件与目的
本卷实例
  • 关键一步：指出状态反馈的前提是系统可控且状态可获取
  • 中间结果：状态反馈通过调整输入改善稳定性与动态性能

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过说明系统进行状态反馈的条件与目的
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反

  • 说明状态观测器的目的及与状态反馈的联系

劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求闭环稳定的增益范围
本卷实例
  • 关键一步：列三阶特征方程的劳斯表并令首列为正
  • 中间结果：首列含参数元素为零给出稳定上界
  • 卡点：注意误差要求与稳定要求可能互相矛盾
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理

  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法

  • 首列出现 0 后仍按常规继续算，未用 ε 法

二4二4、描述函数法求自激振荡#

思路
  • 由非线性描述函数负倒曲线与线性部分幅相曲线求交点，解出自振振幅与频率。
描述函数法基础 非线性系统
本卷考法
  • 由给定描述函数求负倒描述函数并画曲线
本卷实例
  • 关键一步：把描述函数取负倒数并分析随振幅变化的方向
  • 中间结果：负倒描述函数为一条沿实轴变化的轨迹
  • 卡点：起点与终点要按振幅趋近零与无穷分别判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关

  • 用性质验证转移矩阵是否正确
