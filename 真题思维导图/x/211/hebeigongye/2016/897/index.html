一1一1、时域与频域的性能衡量指标5 分#

思路
  • 分别从时域与频域给出平稳性和快速性的常用指标。
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 列举衡量平稳性与快速性的时域指标
本卷实例
  • 关键一步：平稳性看超调量、快速性看调节时间
  • 中间结果：时域指标由阶跃响应特征量定义
  • 卡点：区分平稳性与快速性各自对应的量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过列举衡量平稳性与快速性的时域指标
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
闭环频率特性与性能指标 频域分析
本卷考法
  • 列举衡量平稳性与快速性的频域指标
本卷实例
  • 关键一步：平稳性用谐振峰值、快速性用带宽频率
  • 中间结果：频域指标与闭环幅频曲线形状相关
  • 卡点：勿把开环谐振与闭环谐振混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过列举衡量平稳性与快速性的频域指标
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈
公式

一2一2、闭环稳定性的含义5 分#

思路
  • 从扰动后能否恢复平衡给出闭环稳定性定义与代数判据。
劳斯判据 稳定性分析
本卷考法
  • 说明闭环稳定性的含义并给出线性系统的充要条件
本卷实例
  • 关键一步：从受扰后能否恢复原平衡状态刻画稳定
  • 中间结果：线性系统稳定的充要条件是特征根均具负实部
  • 卡点：注意是全部特征根而非部分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过说明闭环稳定性的含义并给出线性系统的充要条件
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式

一3一3、液位控制系统的组成与调节5 分#

思路
  • 指认测量、比较、执行环节并说明提高液位的措施。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指认液位控制系统的各功能环节
本卷实例
  • 关键一步：按测量、比较、执行顺序拆解控制回路
  • 中间结果：浮子测水位、连杆作比较、定位器驱动阀
  • 卡点：勿把被控量与操纵量相互混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指认液位控制系统的各功能环节
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 说明提高给定液位应采取的措施
本卷实例
  • 关键一步：把期望水位设定为更高的参考值
  • 中间结果：系统通过误差驱动调节阀改变进水量
  • 卡点：需回原卷核对图确认管路结构
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过说明提高给定液位应采取的措施
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半

二二、结构图求系统输出10 分#

思路
  • 用梅森公式分别求两路输入到输出的传函后叠加。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求多回路系统的输出
本卷实例
  • 关键一步：先枚举全部回路并求出特征式
  • 中间结果：各路余子式分别去掉与之接触的回路
  • 卡点：前向通道与回路增益勿相互混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求多回路系统的输出
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求两个输入分别作用时的输出并叠加
本卷实例
  • 关键一步：对每个输入分别求其到输出的传函
  • 中间结果：总输出为两路分量的线性叠加
  • 卡点：需回原卷核对图确认回路连接
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求两个输入分别作用时的输出并叠加
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 化简含三个回路的系统结构图
本卷实例
  • 关键一步：先合并互不接触回路的乘积项
  • 中间结果：特征式等于一减各回路和再加互不接触积
  • 卡点：互不接触回路识别错误会算错特征式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过化简含三个回路的系统结构图
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

三三、以 K 为变量的根轨迹与无振荡条件15 分#

思路
  • 把特征方程整理成根轨迹形式，画轨迹并讨论无振荡的取值。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以 K 为变量绘制根轨迹
本卷实例
  • 关键一步：把参数 K 提到分子配成根轨迹形式
  • 中间结果：开环含一个零点与三个极点
  • 卡点：整理时参数须完整提到分子位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以 K 为变量绘制根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则求实轴段、渐近线与分离点
本卷实例
  • 关键一步：按零极点个数定实轴段与渐近线
  • 中间结果：分离点与渐近线交点由法则给出
  • 卡点：起始角计算勿把该极点自身相角算入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则求实轴段、渐近线与分离点
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 讨论闭环阶跃响应无振荡的 K 条件
本卷实例
  • 关键一步：把无振荡对应为全部闭环根落在负实轴
  • 中间结果：仅当分离点处增益取值才可能全为实根
  • 卡点：三个实根重合仍会产生超调, 未必无振荡
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过讨论闭环阶跃响应无振荡的 K 条件
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式

四四、奈氏判稳、相角裕度与正弦稳态输出20 分#

思路
  • 由开环传函补画辅助线判稳，再由裕度与频率特性求输出。
奈奎斯特判据 稳定性分析
本卷考法
  • 由奈氏曲线判断含两个积分环节系统的稳定性
本卷实例
  • 关键一步：按型别补画无穷大半径辅助圆弧
  • 中间结果：包围圈数代入判据得右半平面闭环极点数
  • 卡点：须先数开环位于右半平面的极点数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由奈氏曲线判断含两个积分环节系统的稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
稳定裕度 频域分析
本卷考法

思路

本卷考法

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤

  • 构造能观性矩阵并求秩

  • 不可控或不可观时进一步做结构分解

  • 对不可控系统进行结构分解
