一一、填空题：正弦稳态与附加零极点影响#

思路
  • 三个小空分别考一阶系统的正弦稳态输出、开环附加零极点对动态调节品质的影响、由持续振荡条件反求参数。
频率特性的物理意义与求法 频域分析
本卷考法
  • 求一阶系统在正弦输入下的稳态输出
本卷实例
  • 关键一步：把正弦输入的角频率代入频率特性，取幅值与相角
  • 关键一步：稳态输出为同频正弦，幅值和相位由频率特性决定
  • 中间结果：开环传函化为闭环后取 s 等于 jω 得幅频与相频
  • 卡点：输入含初相，稳态输出相角要把输入初相一并计入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求一阶系统在正弦输入下的稳态输出
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 判断附加一对开环零极点对动态调节品质的影响
本卷实例
  • 关键一步：比较零点与极点谁离虚轴更近，靠近虚轴者作用占主导
  • 中间结果：零点更靠近虚轴时零点作用强于极点，动态品质变好
  • 卡点：比较的是到虚轴的距离，不是零点与极点之间的间隔
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过判断附加一对开环零极点对动态调节品质的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由持续振荡条件反求系统参数
本卷实例
  • 关键一步：持续振荡即特征方程有纯虚根，令 s 等于 jω 代入后按实部虚部分列
  • 中间结果：虚部方程给出振荡角频率，实部方程给出待求参数
  • 卡点：实部与虚部两个方程要同时满足，只代一个条件解不出来
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由持续振荡条件反求系统参数
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

二1二1、相平面相轨迹的方向与穿越#

思路
  • 由相轨迹斜率式判断横轴上下运动方向，并由横轴处斜率趋于无穷说明相轨迹垂直穿越横轴。
相平面法 非线性系统
本卷考法
  • 说明相轨迹在横轴上下运动方向及是否垂直穿越横轴
本卷实例
  • 关键一步：相轨迹斜率等于状态导数之比，横轴上分母趋于零故斜率为无穷
  • 关键一步：横轴上下状态导数符号相反，故运动方向一左一右
  • 中间结果：非奇点处相轨迹垂直穿越横轴，奇点处可任意角度穿越
  • 卡点：奇点位置斜率不定，不能套用垂直穿越的结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过说明相轨迹在横轴上下运动方向及是否垂直穿越横轴
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

二2二2、由相位裕度反求开环增益#

思路
  • 写出相频特性，由相位裕度确定剪切频率，再由幅值条件等于一列方程求增益。
稳定裕度 频域分析
本卷考法
  • 由给定相位裕度反求开环增益
本卷实例
  • 关键一步：相位裕度等于 180 度加剪切频率处相角，先定出剪切频率
  • 关键一步：剪切频率处开环幅值等于一，据此列增益方程
  • 中间结果：相频由两个转折环节的反正切与积分环节相位叠加
  • 卡点：积分环节贡献负 90 度相位，累加时别漏项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由给定相位裕度反求开环增益
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式

二3二3、结构图参数对动态与稳态性能的影响#

思路
  • 由结构图求闭环传函并与二阶标准形式对照，阻尼参数影响动态性能，另一参数影响稳态误差。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函对照二阶标准形式说明参数对动态性能的影响
本卷实例
  • 关键一步：把闭环传函分母与二阶标准形式对照，一次项系数对应阻尼与自然频率乘积
  • 中间结果：阻尼参数增大使阻尼比增大、调节时间减小
  • 卡点：调节时间按百分之五误差带近似取 3.5 除以阻尼与自然频率之积
  • 卡点：结构以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函对照二阶标准形式说明参数对动态性能的影响
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由误差传函说明参数对稳态性能的影响
本卷实例
  • 关键一步：写出误差传函，用终值定理考查单位阶跃下的稳态误差
  • 中间结果：稳态误差只与其中一个参数有关，增大该参数可减小误差
  • 卡点：用终值定理前必须先确认闭环系统稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由误差传函说明参数对稳态性能的影响
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

二4二4、由状态转移矩阵求系统矩阵#

思路
  • 利用系统矩阵等于状态转移矩阵在零时刻的导数。
状态转移矩阵 状态空间分析
本卷考法
  • 由已知状态转移矩阵反求系统矩阵
本卷实例
  • 关键一步：系统矩阵等于状态转移矩阵对时间求导后在零时刻取值
  • 中间结果：矩阵元素中带时间因子的项求导后代入零时刻即可保留
  • 卡点：必须先求导再代零时刻，直接读矩阵系数会出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过由已知状态转移矩阵反求系统矩阵
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错

二5二5、由对数幅频特性反求开环传函#

思路
  • 由低频段斜率定型别，由转折频率定各环节时间常数，再由剪切频率处幅值为一确定增益。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环对数幅频渐近线反求传递函数
本卷实例
  • 关键一步：低频段斜率给出积分环节个数，转折频率给出惯性环节时间常数
  • 中间结果：剪切频率处幅值为零分贝，据此列方程求增益
  • 卡点：曲线以图给出，转折频率与低频段高度需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环对数幅频渐近线反求传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

三三、输入与扰动下的稳态误差#

思路
  • 分别写出输入与扰动到误差的传递函数，用终值定理按题给稳态误差条件反求增益与内反馈参数。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求多输入与扰动作用下的误差传递函数
本卷实例
  • 关键一步：求扰动误差时把参考输入置零，分别列两路到误差的通路
  • 中间结果：误差传函按梅森公式由前向通路与回路增益写出
  • 卡点：扰动作用点前后信号关系不同，叠加时不能只看一条通路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求多输入与扰动作用下的误差传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
典型输入下的稳态误差计算 稳态误差
本卷考法

本卷实例
  • 关键一步：加速度输入下对误差传函取终值定理，得到与内反馈参数的关系
  • 中间结果：令输入引起的误差为零可先定出内反馈参数
  • 卡点：先判稳再用终值定理，否则结论不成立
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差

步骤

  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变

  • 不可控或不可观时进一步做结构分解

九九、状态反馈极点配置的可行性#

思路
  • 由原传函零点与目标传函零点是否一致判断，关键是状态反馈不改变零点且要求系统能控，并注意零极点对消。
状态反馈与极点配置 状态空间分析
本卷考法
  • 判断能否用状态反馈把极点配置到给定位置
本卷实例
  • 关键一步：先由能控性判据确认极点可配置，再把目标极点取作期望特征值
  • 中间结果：目标传函要求把极点配置到与保留零点相应的位置
  • 卡点：状态反馈不能改变零点，目标零点必须与原系统一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过判断能否用状态反馈把极点配置到给定位置
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反

  • 按公式求 G(s)=C(sI-A)^{-1}B+D

  • 比较不同实现对应的传递函数是否相同
常见易错
