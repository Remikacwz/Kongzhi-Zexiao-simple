1电路网络建模#

思路
  • 由图给电路网络的复阻抗列分压关系，先求传递函数，再由拉氏反变换写出微分方程
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由 RC 电路图写出微分方程和传递函数
本卷实例
  • 关键一步：把电容写成复阻抗 1/(Cs)，先合并并联支路再按复阻抗分压列式
  • 中间结果：电容阻抗写 1/(Cs)，先把并联支路合并成等效阻抗
  • 中间结果：输出电压取自并联支路，按串联分压比例列 Uc(s)/Ur(s)
  • 卡点：电容复阻抗取 1/(Cs) 而非 Cs
  • 卡点：并联支路要先化简，不能把 R1 与电容直接按串联分压
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由 RC 电路图写出微分方程和传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 本卷考过把电容复阻抗误写成 Cs，或把并联支路直接按串联处理
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

由电路或机械系统求传递函数 传递函数
本卷考法
  • 由电路微分方程求传递函数
本卷实例
  • 关键一步：对已列出的电路微分方程取零初始条件拉氏变换
  • 关键一步：按输出与输入拉氏变换之比整理传函
  • 中间结果：电路网络先用复阻抗法在 s 域列分压式，再整理成 s 的有理分式
  • 卡点：电容复阻抗取 1/(Cs) 而非 Cs，并联支路阻抗先合并再分压
  • 卡点：系统图为原卷插图，元件连接与参照方向需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由电路微分方程求传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错

  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

2二阶系统指标反求参数#

思路
  • 四问：求 Φ(s) → 由 ξ、ωn 反求 k 与 β → 求 td 与 ts(2%) → 求斜坡输入下的 ess
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图求闭环传递函数 Φ(s)
本卷实例
  • 关键一步：围绕误差点列方程，按比较点和引出点逐步消去中间变量
  • 中间结果：先把给定阻尼比与自然频率代入标准二阶形式定结构
  • 卡点：结构图未读，反馈支路与增益正负号需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由结构图求闭环传递函数 Φ(s)
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过把负反馈的分母写成 1-GH
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由 ξ=0.707、ωn=2 反求 k 与 β
本卷实例
  • 关键一步：把 Φ(s) 化成标准二阶形式，逐项比对得 2ξωn 与 ωn²，解出未知参数
  • 关键一步：β=arccos ξ 是阻尼角
  • 中间结果：题给 ξ=0.707、ωn=2，与 2ξωn、ωn² 逐项对齐
  • 中间结果：β 是阻尼角，由 cos β=ξ 反求
  • 卡点：化为标准形式时忘记把 s² 项系数归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由 ξ=0.707、ωn=2 反求 k 与 β
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 求延迟时间 td 与调节时间 ts(Δ=2%)
本卷实例
  • 关键一步：由已定阻尼比与自然频率直接代入二阶系统延迟时间与调节时间公式
  • 中间结果：延迟时间与上升时间同量级，调节时间按 2% 误差带取四倍时间常数
  • 卡点：调节时间系数随误差带不同而变，勿套用 5% 误差带的系数
  • 卡点：第二题结构图未读，反馈支路增益需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过求延迟时间 td 与调节时间 ts(Δ=2%)
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过用 5% 误差带的系数 3.5
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

典型输入下的稳态误差计算 稳态误差
本卷考法
  • r(t)=2×1(t) 时求稳态误差 ess
本卷实例
  • 关键一步：先由闭环传函判断系统型别，再按阶跃输入取误差终值
  • 中间结果：阶跃输入下的稳态误差由静态位置误差系数决定
  • 卡点：输入幅值为 2，写误差系数时勿漏掉输入幅值

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换

通用考法

  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过把稳态值当成了增益而漏掉输入幅值
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3根轨迹与系统分类#

思路
  • 画 kr 从 0→∞ 的根轨迹、求稳定 kr 范围；第 3 问是概念题（按信号类型给控制系统分类）
根轨迹的绘制法则 根轨迹法
本卷考法
  • 画出 kr 从 0→∞ 的根轨迹
本卷实例
  • 关键一步：由开环极点定实轴段、渐近线、分离点等根轨迹关键要素
  • 中间结果：无开环零点时渐近线夹角按奇数等分
  • 卡点：开环传函与极点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过画出 kr 从 0→∞ 的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过实轴段判据中的零极点个数算错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求系统稳定时 kr 的取值范围
本卷实例
  • 关键一步：把 s 等于 jω 代入闭环特征方程并分离实部与虚部
  • 关键一步：由虚轴交点对应的增益定稳定区间端点
  • 中间结果：分离虚部方程解出角频率，再代回实部方程求临界增益
  • 卡点：实轴根轨迹段的走向决定哪一段增益对应稳定
  • 卡点：第三题结构图未读，开环极点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求系统稳定时 kr 的取值范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 本卷考过只代一个 ω 漏掉另一组交点
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

误差定义与误差传递函数 稳态误差
本卷考法
  • 按信号类型给自动控制系统分类
本卷实例
  • 关键一步：按给定信号类型分三类：恒值（定值）控制系统、随动（伺服）系统、程序控制系统
  • 关键一步：恒值系统的给定是常数；随动系统给定随时间任意变化；程序控制系统给定按预定规律变化
  • 中间结果：分类依据是给定值的变化规律，不是输出量的变化规律
  • 中间结果：三类名称要与按反馈结构分的开环、闭环、复合区分开
  • 卡点：把「随动」与「程序控制」混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过按信号类型给自动控制系统分类
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

4由对数幅频特性反求传函#

思路
  • 最小相位系统，由图读低频段斜率与转折频率写出 G(s)，再求截止频率 ωc
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环对数幅频特性求 G(s)，并求截止频率 ωc
本卷实例
  • 关键一步：低频段斜率定型别 v、低频段高度或延长线交点定增益 K
  • 关键一步：每个转折频率对应一个环节，按斜率变化定类型
  • 关键一步：−20 是惯性、+20 是一阶微分、−40 多为振荡
  • 关键一步：ωc 由渐近线穿越 0dB 的位置解出
  • 中间结果：先写成 G(s)=K·Π(τis+1)/s^v 的待定形式，再逐段定参数
  • 中间结果：ωc 由各段渐近线方程依次试算，取真正落在该段的解
  • 卡点：延长线交点没折算型别就当增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环对数幅频特性求 G(s)，并求截止频率 ωc
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

5由频率特性表格读稳定裕度#

思路
  • 题目给的是 ω 从 2 到 10 的一组 |G| 与 ∠G 数值表，没有解析式，只能插值读数
稳定裕度 频域分析
本卷考法
  • 根据给定频率特性数据求相角裕度与幅值裕度
本卷实例
  • 关键一步：先在表里找 |G|=1 的 ω → 该处 ∠G 代入 γ=180°+∠G 得相角裕度
  • 关键一步：再找 ∠G=−180° 的 ω → 该处 |G| 代入 Kg=−20lg|G| 得幅值裕度
  • 关键一步：表里没有正好相等的点 → 要在相邻两点间做线性插值
  • 中间结果：表中 |G| 从 1.5（ω=7）降到 1（ω=8）
  • 中间结果：说明 ωc 恰在 ω=8 附近，数值上可直接读

思路
  • 由原卷五幅开环幅相曲线分别读取右半平面开环极点数与绕临界点的包围圈数，用 Z=P−2N− 判断闭环稳定性及右半平面闭环极点数。
奈奎斯特判据 稳定性分析
本卷考法
  • 由五幅开环幅相曲线分别判断闭环稳定性及不稳定根个数
本卷实例

8状态方程的解#

思路

状态转移矩阵 状态空间分析
本卷考法
  • 给定初值与阶跃输入，求状态方程的解
本卷实例
  • 关键一步：A 是幂零矩阵（A²=0），级数截断得 e^{At}=I+At
  • 关键一步：即 [[1,t],[0,1]]，比求逆再反变换更快
  • 关键一步：全解 x(t)=e^{At}x(0)+∫₀ᵗe^{A(t−τ)}Bu(τ)dτ
  • 关键一步：卷积项要真正积出来，不能只写符号
  • 中间结果：e^{At}x(0) = [[1,t],[0,1]]·[1,1]ᵀ = [1+t, 1]ᵀ
  • 中间结果：卷积项含 t²/2，说明输入作用下状态是 t 的二次增长
  • 卡点：没识别出 A²=0，硬算矩阵指数反而易错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果

  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错

思路

能控性与能观性 状态空间分析
本卷考法
  • 判断系统能控性与能观性
本卷实例

  • 关键一步：能控性矩阵 [B AB] 秩至多为 1，小于阶数 2，故不可控

  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变

  • 构造能观性矩阵并求秩

  • 把能控性判据与能观性判据的矩阵构造搞混
