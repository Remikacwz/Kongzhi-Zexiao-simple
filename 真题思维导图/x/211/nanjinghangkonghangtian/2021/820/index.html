思路

电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由RC网络用复阻抗列KCL与KVL求U2比U1
本卷实例
  • 关键一步：把电容写成1/(Cs)，在s域按节点列电流方程
  • 中间结果：两网孔方程消去中间电流后整理成分式传函

  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值

  • 求运算电路的输出表达式

本卷考法

本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节

常见易错

  • 并联环节相减时符号取反

劳斯判据 稳定性分析
本卷考法
  • 列劳斯表讨论R1R2C1C2对系统稳定性的影响
本卷实例
  • 关键一步：取传函分母写特征多项式并列劳斯表
  • 中间结果：首列两式均大于零故系统稳定
  • 卡点：分母含多个RC乘积，比较系数时勿漏项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过列劳斯表讨论R1R2C1C2对系统稳定性的影响
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

本卷实例

  • 中间结果：C(s)分母为(s+1)(s+2)，PD提供s+5零点

减小稳态误差的措施 稳态误差
本卷考法
  • 设计前馈F(s)使斜坡输入稳态误差为零
本卷实例
  • 关键一步：令误差传函分子在s趋于0时为零反解F(s)
  • 中间结果：前馈项与误差通道按完全补偿条件配对
  • 卡点：F(s)含微分项，须检查物理可实现性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计前馈F(s)使斜坡输入稳态误差为零
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

三主导极点法设计反馈通道H(s)#

思路
  • 由超调量与调节时间要求定出期望闭环主导极点，再用远极点假设构造期望特征多项式，与1加GH比较系数求出反馈通道H(s)
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由σ%与ts反求闭环主导极点的阻尼比与自然频率
本卷实例
  • 关键一步：由超调量公式定阻尼比，再由ts定ξωn
  • 中间结果：σ%=4.3%对应ξ约0.707，ts=3s定ωn
  • 卡点：调节时间按Δ=±5%取3除以ξωn
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由σ%与ts反求闭环主导极点的阻尼比与自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环极点位置写出二阶系统标准形式参数
本卷实例
  • 关键一步：把主导极点写成负实部与虚部对应的标准形式
  • 中间结果：由极点实部与虚部定出ξ与ωn
  • 卡点：化标准形式前须把s²项系数归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环极点位置写出二阶系统标准形式参数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

思路

根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制开环传递函数K(s+1)比s(s-1)的闭环根轨迹
本卷实例
  • 关键一步：先标开环零极点并判实轴上的根轨迹段
  • 中间结果：两条分支起于0与1，终于-1与无穷远
  • 卡点：开环含右半平面极点，实轴段判据要数右侧零极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制开环传递函数K(s+1)比s(s-1)的闭环根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

  • 由已知A与全响应反求B矩阵，构造能控性矩阵判断能控性，对不完全能控系统按能控子空间作线性变换完成能控分解
状态转移矩阵 状态空间分析
本卷考法
  • 由A求状态转移矩阵并用全响应反求B矩阵
本卷实例
  • 关键一步：先求(sI-A)逆的拉氏反变换得e^At
  • 中间结果：零初值全响应写成卷积积分形式
  • 卡点：B待定，需把已知x(t)与卷积式逐项比对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过由A求状态转移矩阵并用全响应反求B矩阵
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错
公式
能控性与能观性 状态空间分析
本卷考法
  • 由能控性矩阵判能控性并作能控分解
本卷实例
  • 关键一步：构造B与AB并列成矩阵判秩，不满秩则不完全能控
  • 中间结果：取B为第一列构造非奇异变换阵
  • 卡点：变换阵须非奇异，否则分解无效
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过由能控性矩阵判能控性并作能控分解
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

十位置随动系统状态反馈与输出反馈15 分#

思路
  • 由题给能控标准型、极点距原点3、李雅普诺夫方程与输出能量积分确定对象参数，设计状态反馈满足调节时间要求，再比较输出反馈能否达到同样性能
状态反馈与极点配置 状态空间分析
本卷考法
  • 设计状态反馈使单位阶跃响应满足ts要求
本卷实例
  • 关键一步：由闭环二阶无零点与极点距原点3定期望极点
  • 中间结果：能控标准型下反馈增益由特征多项式系数比较得到
  • 卡点：宝典段此题无答案段，配置结果需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过设计状态反馈使单位阶跃响应满足ts要求
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
公式
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 用李雅普诺夫方程与输出能量积分定系统参数
本卷实例
  • 关键一步：用A转置P加PA等于负C转置C与输出能量积分2.25定参数
  • 中间结果：李雅普诺夫方程给出正定对称矩阵P
  • 卡点：该题无答案段，求解路径据题面条件推定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过用李雅普诺夫方程与输出能量积分定系统参数
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 分析输出反馈能否达到状态反馈的性能指标
本卷实例
  • 关键一步：输出反馈受输出维数限制，可配置极点数目有限
  • 中间结果：单输出反馈最多约束一个闭环极点
  • 卡点：不能达到时需给出尽量接近指标的设计
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过分析输出反馈能否达到状态反馈的性能指标
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
