1第1题 由结构图求系统误差表达式#

思路
  • 把结构图转为信号流图，找出各回路与不接触回路，用梅森公式写由R到E的误差传函。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图画信号流图并用梅森公式求误差传函
本卷实例
  • 关键一步：由结构图确定由输入到误差的各前向通路
  • 中间结果：总特征式为1减各回路增益之和
  • 卡点：结构图未读图，回路与支路需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图画信号流图并用梅森公式求误差传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 写出误差传递函数E(s)比R(s)
本卷实例
  • 关键一步：用叠加原理分别写给定与扰动到误差的传函
  • 中间结果：单位负反馈时误差为给定减输出
  • 卡点：非单位反馈时两种误差定义混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写出误差传递函数E(s)比R(s)
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

2第2题 含参数极点的根轨迹与动态性能#

思路
  • 先由闭环特征方程定出使系统稳定的参数条件，再在该条件下画根轨迹，讨论分离点与虚轴交点并分析动态性能。
劳斯判据 稳定性分析
本卷考法
  • 先由闭环特征方程确定系统稳定的参数条件
本卷实例
  • 关键一步：由1加开环传函写闭环特征方程并列劳斯表
  • 中间结果：劳斯表首列含参数p1与K星
  • 卡点：系数缺项未补零直接套判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过先由闭环特征方程确定系统稳定的参数条件
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

根轨迹的绘制法则 根轨迹法
本卷考法
  • 在稳定条件下绘制根轨迹
本卷实例
  • 关键一步：由开环零极点定分支数、实轴段与渐近线
  • 中间结果：一零点三极点的根轨迹有两条渐近线
  • 卡点：渐近线夹角公式中的2k加1写成2k
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过在稳定条件下绘制根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

分离点与会合点 根轨迹法
本卷考法
  • 求分离点并讨论其个数
本卷实例
  • 关键一步：用分离点方程判别式讨论根的分布
  • 中间结果：分离点个数随参数取值分三种情况
  • 卡点：把求出的共轭复根也当分离点保留
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求分离点并讨论其个数
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

本卷实例

  • 令实部与虚部分别为零，得到两个方程

  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过判断根轨迹是否穿越虚轴
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向

由根轨迹分析性能与确定参数 根轨迹法

4第4题 由根轨迹与稳态误差重新设计比例环节#

思路
  • 按参数变化的根轨迹确定可选参数范围，再由给定输入下的稳态误差要求重新选取比例校正环节。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 由参数变化绘制根轨迹
本卷实例
  • 关键一步：把含参数项整理成标准根轨迹形式
  • 中间结果：参数变化时根轨迹形状随之改变
  • 卡点：未把参数提到分子位置就套用规则
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过由参数变化绘制根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由斜坡输入求稳态误差
本卷实例
  • 关键一步：对斜坡输入用终值定理求稳态误差
  • 中间结果：稳态误差与开环增益成反比
  • 卡点：未判稳就使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由斜坡输入求稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

减小稳态误差的措施 稳态误差
本卷考法
  • 重新设计比例环节使给定输入稳态误差为零
本卷实例
  • 关键一步：重新选校正环节使等效开环分母含积分环节
  • 中间结果：给定输入误差为零要求系统提高型别
  • 卡点：结构图未读图，校正环节接入位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过重新设计比例环节使给定输入稳态误差为零
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

5第5题 由示波器幅相条件反求参数与谐振峰值#

思路
  • 把示波器读出的幅值比与相位差写成频率特性方程，反求系统参数；再由闭环传函求谐振频率与谐振峰值。
频率特性的物理意义与求法 频域分析
本卷考法
  • 由示波器幅值与相位差反求系统参数
本卷实例
  • 关键一步：把幅值比与相位差条件写成频率特性的幅相方程
  • 中间结果：相位差负90度对应特征式实部为零
  • 卡点：相位差符号与串联环节数对应看错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由示波器幅值与相位差反求系统参数
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式

本卷考法
  • 判断配置极点后系统的能观性
本卷实例

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断配置极点后系统的能观性
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
