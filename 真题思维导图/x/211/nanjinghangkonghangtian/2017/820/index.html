一多输入扰动系统的总输出C(s)15 分#

思路
  • 图1有参考输入与三个扰动输入，分别求各输入到系统输出的传递函数，再用叠加原理合成总输出C(s)
梅森增益公式与信号流图 传递函数
本卷考法
  • 分别求参考输入与各扰动输入到输出C(s)的传递函数
本卷实例
  • 关键一步：对每个输入单独判前向通路并把其余输入置零
  • 中间结果：扰动通道共用同一特征式Δ
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过分别求参考输入与各扰动输入到输出C(s)的传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 用叠加原理把各输入的响应合成为总输出
本卷实例
  • 关键一步：各分量传函分母相同而分子不同
  • 中间结果：总输出等于各输入与对应传函乘积之和
  • 卡点：勿把不同前向通路的余子式混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过用叠加原理把各输入的响应合成为总输出
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

二二阶系统动态指标与测速反馈及正弦稳态15 分#

思路
  • 由单位阶跃稳态输出为1和最大瞬时值为1.4定参数K与a并算动态指标，引入测速反馈后重算超调量，再求正弦输入下的稳态输出
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由超调量反求阻尼比并写出闭环标准形
本卷实例
  • 关键一步：由最大瞬时值相对稳态值求超调量
  • 中间结果：闭环特征方程含K与a两个参数
  • 卡点：稳态输出为1给出一个参数关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由超调量反求阻尼比并写出闭环标准形
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 分别求未加与加测速反馈两种情况的超调量
本卷实例
  • 关键一步：按新的阻尼比与自然频率重算超调量
  • 中间结果：加测速反馈后阻尼比增大
  • 卡点：峰值时间公式中的自然频率取闭环值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过分别求未加与加测速反馈两种情况的超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求输入为2加1.38倍正弦时系统的稳态输出
本卷实例
  • 关键一步：把输入拆成常值与正弦分别求稳态分量
  • 中间结果：正弦分量幅相由闭环频率特性决定
  • 卡点：频率特性须取闭环而非开环
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求输入为2加1.38倍正弦时系统的稳态输出
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

参数稳定域的确定 稳定性分析
本卷考法

本卷实例

步骤

  • 比较不同参数对稳定域大小的影响
常见易错

  • 取交集时把端点是否包含搞错

由响应曲线反求传递函数 传递函数

广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以时间常数T为参数绘制闭环根轨迹
本卷实例
  • 关键一步：把含参数kg的项整理成标准根轨迹形式
  • 中间结果：根轨迹起于一对共轭极点终于原点
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以时间常数T为参数绘制闭环根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

五由幅相曲线求传函并设计校正装置15 分#

思路
  • 由幅相曲线上的B点读模值与相角反求开环传函，再按相角裕度45度与斜坡误差降为原值一半两个条件解出校正装置的参数
频率特性的物理意义与求法 频域分析
本卷考法
  • 由幅相曲线特征点反求含积分环节的一阶系统开环传函
本卷实例
  • 关键一步：由相角范围判断含一个积分环节与一个惯性环节
  • 中间结果：两条件联立定出增益与时间常数
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由幅相曲线特征点反求含积分环节的一阶系统开环传函
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
期望特性法与综合法 系统校正
本卷考法
  • 按型别与阶数不变确定校正装置的结构
本卷实例
  • 关键一步：由条件令校正装置的一个零点对被控对象极点实现对消
  • 中间结果：对消后校正后开环的阶数降低
  • 卡点：对消后须重新计算开环增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 期望特性法直接按指标画出希望的开环对数幅频特性
  • 用期望特性减去未校正特性得到校正装置特性
  • 关键是确定低频段高度、中频段宽度与高频段斜率
  • 中频段斜率一般取 -20 dB/dec 并保持足够宽度
步骤
  • 按稳态要求确定低频段斜率与高度
  • 按相角裕度要求确定中频段宽度与截止频率
  • 按抗噪要求确定高频段斜率
  • 相减求得校正装置并检验可实现性
通用考法
  • 本卷考过按型别与阶数不变确定校正装置的结构
  • 用期望特性法设计校正装置
  • 说明中频段宽度与相角裕度的关系
  • 由校正装置特性反写传递函数
常见易错
  • 期望特性的中频段取窄导致裕度不足
  • 相减后得到的特性不可物理实现却未检查

稳定裕度 频域分析
