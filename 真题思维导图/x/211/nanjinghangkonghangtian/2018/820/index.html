一信号流图与梅森公式15 分#

思路
  • 由结构图画出信号流图，数清单独回路与两两互不接触回路，用梅森增益公式写出C(s)对R(s)的传函
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图转信号流图后用梅森公式求C(s)/R(s)
本卷实例
  • 关键一步：先标出全部单独回路及其增益，再找两两互不接触回路
  • 中间结果：回路总数与互不接触对决定特征式Δ的项数
  • 卡点：结构以图给出，回路拓扑需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图转信号流图后用梅森公式求C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

串联、并联与反馈等效 结构图与方框图
本卷考法
  • 把各方框与反馈支路整理成流图的前向通路与回路支路
本卷实例
  • 关键一步：按信号流向确定前向通路并写出其余子式
  • 中间结果：前向通路与各回路是否接触决定余子式取值
  • 卡点：接触关系判错会让余子式多乘或漏乘回路项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过把各方框与反馈支路整理成流图的前向通路与回路支路
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

二测速反馈对稳定与动态15 分#

思路
  • 由结构图写闭环传函，用劳斯判据看反馈系数对稳定性的影响，再按二阶标准形式与终值定理分析动态和斜坡稳态
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据分析反馈系数β对闭环稳定性的影响
本卷实例
  • 关键一步：写出闭环特征方程后列劳斯表，看首列符号随β的变化
  • 中间结果：闭环特征式为二阶，首列两项均含β
  • 卡点：β=0时首列出现零，属临界稳定要单独说明
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据分析反馈系数β对闭环稳定性的影响
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征式与典型二阶形式对比求ζ与ωn随β的变化
本卷实例
  • 关键一步：把特征式与s²+2ζωn s+ωn²逐项对照
  • 中间结果：ωn不变而ζ随β增大而增大
  • 卡点：不要把开环增益当成闭环特征式系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征式与典型二阶形式对比求ζ与ωn随β的变化
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

本卷考法

本卷实例

  • 中间结果：斜坡误差表示成开环增益与β的函数
  • 卡点：Ⅰ型系统斜坡误差为有限值，勿套阶跃公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤

  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法

  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量

三复合控制前馈补偿设计15 分#

思路
  • 由给定输出响应反求前向通道参数与反馈系数，再用前馈补偿通道实现阶跃给定下的无差跟踪
PID 控制器与参数整定 系统校正
本卷考法
  • 由给定输出响应确定PI控制器的比例与积分参数
本卷实例
  • 关键一步：把目标响应与含PI环节的闭环传函对照定参数
  • 中间结果：PI参数由闭环极点与增益匹配得到
  • 卡点：积分作用提高系统型别，需同时核对稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过由给定输出响应确定PI控制器的比例与积分参数
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定

本卷考法

本卷实例

  • 中间结果：Gf(s)由前向通道与反馈通道传函之比确定

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过按复合控制求前馈补偿器使输出无差跟踪给定信号
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

稳定裕度 频域分析
本卷考法
  • 读开环幅相曲线求临界增益与相角裕度
本卷实例
  • 关键一步：在幅相曲线上找幅值为1与相角为-180°的位置
  • 中间结果：相角裕度由截止频率处相角与-180°之差给出
  • 卡点：幅值裕度与相角裕度对应的频率勿用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法

  • 中间结果：离散状态矩阵由A与采样周期T共同决定
  • 卡点：积分区间是0到T，勿漏乘输入矩阵B
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 离散化状态方程由状态转移矩阵在采样周期处的取值构成
  • 输入矩阵是状态转移矩阵与输入矩阵乘积在采样周期上的积分

本卷考法
  • 求使离散化系统既能控又能观的采样周期T取值范围
本卷实例
  • 关键一步：分别写能控与能观判别矩阵的秩条件
  • 中间结果：T的禁值由判别矩阵降秩的周期点给出
  • 卡点：能控与能观条件要取交集，端点开闭要交代
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过求使离散化系统既能控又能观的采样周期T取值范围
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
