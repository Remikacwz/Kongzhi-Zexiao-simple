一结构图求闭环传函#

思路
  • 由结构图逐步化简或画信号流图用梅森公式求闭环传函C(s)/R(s)
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图或信号流图用梅森公式求闭环传函
本卷实例
  • 关键一步：数清单独回路与两两互不接触回路
  • 中间结果：特征式Δ由回路增益及其互不接触乘积组成
  • 卡点：结构以图给出，回路拓扑需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图或信号流图用梅森公式求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 按串联、并联与反馈逐层化简多回路结构图
本卷实例
  • 关键一步：从最内环开始化简再逐层向外
  • 中间结果：内环化简结果作为外环的一个环节
  • 卡点：化简内环时勿把外环信号当常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过按串联、并联与反馈逐层化简多回路结构图
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

二由性能指标反求参数#

思路
  • 由飞机自动控制结构图写闭环传函，令ωn=6、ξ=1反求k与kt，再按临界阻尼计算调节时间与超调量
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由ωn与ξ要求反求结构参数k与kt
本卷实例
  • 关键一步：把闭环特征式化为标准二阶形式后比较系数
  • 中间结果：k与kt分别由ωn和阻尼项确定
  • 卡点：只满足单项指标就下结论，需交叉验证
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由ωn与ξ要求反求结构参数k与kt
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 按ζ=1计算单位阶跃响应的调节时间与超调量
本卷实例
  • 关键一步：临界阻尼无超调，调节时间由闭环实极点决定
  • 中间结果：σ%为零，ts按5%误差带估算
  • 卡点：ζ=1时峰值时间公式不适用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过按ζ=1计算单位阶跃响应的调节时间与超调量
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

三根轨迹与闭环极点估算#

思路
  • 由Ⅰ型系统条件与开环极点作根轨迹，再将s=-5代入特征式求其余极点，用主导极点估算单位阶跃的ess与σ%
根轨迹的绘制法则 根轨迹法
本卷考法
  • 由开环极点按法则绘制根轨迹并求关键参数
本卷实例
  • 关键一步：先定实轴段、渐近线与分离点
  • 中间结果：分离点由dK/ds=0求得
  • 卡点：实轴段判据与渐近线夹角公式勿写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过由开环极点按法则绘制根轨迹并求关键参数
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

四劳斯判据求特征根#

思路
  • 对给定四次特征方程列劳斯表判断稳定性，出现全零行时用辅助方程求根，进而解出全部特征根
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断稳定性并处理全零行
本卷实例
  • 关键一步：全零行用上一行系数构造辅助方程求导继续
  • 中间结果：辅助方程的根给出一对对称特征根
  • 卡点：全零行不能直接判临界，需由辅助方程定根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断稳定性并处理全零行
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

五由幅相曲线设计校正#

思路
  • 由典型环节幅相曲线拼出开环传函，按稳态误差与相角裕度要求设计Gc，再在保持截止频率下追加串联校正降低斜坡误差
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由多个典型环节的幅相曲线反求开环传递函数
本卷实例
  • 关键一步：按各环节幅相特征与相角之和定型别与增益
  • 中间结果：开环传函由典型环节相乘组成
  • 卡点：半圆幅相曲线对应一阶环节，勿误判为振荡环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由多个典型环节的幅相曲线反求开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

校正的基本概念与性能指标 系统校正
本卷考法
  • 把稳态误差与相角裕度要求折算为校正设计指标
本卷实例
  • 关键一步：先由无差要求定系统型别，再按裕度选校正方式
  • 中间结果：校正装置须兼顾低频精度与中频裕度
  • 卡点：截止频率与相角裕度两个指标要同时满足
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过把稳态误差与相角裕度要求折算为校正设计指标
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求

减小稳态误差的措施 稳态误差
本卷考法
  • 设计串联校正使斜坡稳态误差降低到给定比例
本卷实例
  • 关键一步：在保持ωc不变的前提下提高低频增益
  • 中间结果：斜坡误差与开环增益成反比
  • 卡点：提高增益会压缩相角裕度，须校核γ降幅
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计串联校正使斜坡稳态误差降低到给定比例
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

六幅相特性与奈氏判据#

思路
  • 由开环传函画幅相特性概略图，注意开环含一个右半平面极点，再用奈氏判据由P、N确定闭环稳定性
频率特性的物理意义与求法 频域分析
本卷考法
  • 求开环幅相特性概略图并分析起点与终点
本卷实例
  • 关键一步：由低频段型别定起点、由相对阶定终点相角
  • 中间结果：曲线在实轴上的穿越点由虚部为零求得
  • 卡点：分母含负常数项，开环存在RHP极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
