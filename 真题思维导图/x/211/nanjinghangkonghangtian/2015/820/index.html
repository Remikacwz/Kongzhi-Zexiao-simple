一梅森公式求C(s)/R(s)与E(s)/R(s)15 分#

思路
  • 按图1结构图画出信号流图，找全前向通路与各回路，用梅森增益公式分别求出输出与误差的传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图转信号流图后用梅森公式求C(s)/R(s)
  • 再由E(s)/R(s)等于1减C(s)/R(s)求误差传函
本卷实例
  • 关键一步：先标出两条前向通路并判断回路间是否互不接触
  • 关键一步：写出特征式Δ与各通路余子式Δk
  • 中间结果：输出传函与误差传函共用同一分母Δ
  • 中间结果：误差传函可由输出传函取1减得到
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图转信号流图后用梅森公式求C(s)/R(s)
  • 本卷考过再由E(s)/R(s)等于1减C(s)/R(s)求误差传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

二反馈控制系统按指标选Kf与K215 分#

思路
  • 由单位斜坡稳态误差、闭环阻尼比与调节时间三条指标列出关于Kf与K2的不等式组，取可行解后回代验证稳定性
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡输入稳态误差不超过0.35列第一个不等式
本卷实例
  • 关键一步：先用终值定理把斜坡误差写成Kf与K2的表达式
  • 中间结果：误差表达式只含K2与2/Kf两项
  • 卡点：非单位反馈时误差定义需先统一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位斜坡输入稳态误差不超过0.35列第一个不等式
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由调节时间ts不超过3秒给出第三个不等式
本卷实例
  • 关键一步：按5%误差带取ts等于3除以阻尼比与自然频率之积
  • 中间结果：调节时间约束与阻尼比约束联立成不等式组
  • 卡点：三式取交集后再回代验证稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法

  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

三劳斯稳定判据与全零行求全部特征根15 分#

思路
  • 先用特征方程系数是否变号快速判定不稳定，再列劳斯表遇全零行时用辅助函数求导补行，最后分解因式求出全部特征根
劳斯判据 稳定性分析
本卷考法
  • 用劳斯表判断五阶系统稳定性并给出正实部根个数
本卷实例
  • 关键一步：先看系数是否变号快速判定不稳定
  • 中间结果：劳斯表出现全零行须取辅助函数求导补行
  • 卡点：辅助函数与因式分解要对应检查
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯表判断五阶系统稳定性并给出正实部根个数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

零极点分布与响应模态 传递函数
本卷考法
  • 因式分解特征多项式求全部闭环特征根
本卷实例
  • 关键一步：把高次多项式按对称项分组分解为低次因式之积
  • 中间结果：分解结果同时含实根与纯虚根两类模态
  • 卡点：每个因式都必须回代原方程验证
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过因式分解特征多项式求全部闭环特征根
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零
