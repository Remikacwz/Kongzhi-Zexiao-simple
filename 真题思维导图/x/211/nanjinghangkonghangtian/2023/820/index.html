一（1~5）不定项选择：基本概念与状态空间#

思路
  • 五道不定项选择分别辨析零初始条件与增益作用、1型系统误差与低频段、中频段与带宽、非最小相位与根轨迹、能控能观与李雅普诺夫方法
传递函数的定义与基本性质 传递函数
本卷考法
  • 辨析零初始条件的含义与开环闭环增益的不同作用
本卷实例
  • 关键一步：逐项判断零初始条件、误差系数、增益与积分环节说法
  • 中间结果：零初始条件要求输入与输出各阶导数在t=0为零
  • 卡点：增大闭环增益不等于增大开环增益，快速性看后者
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过辨析零初始条件的含义与开环闭环增益的不同作用
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 辨析1型系统斜坡误差与低频段对稳态性能的作用
本卷实例
  • 关键一步：由1型系统单位斜坡误差等于1反推开环增益为1
  • 中间结果：1型系统闭环分母常数项由开环常数项决定
  • 卡点：开环对数幅频低频段决定稳态误差而非中高频段
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过辨析1型系统斜坡误差与低频段对稳态性能的作用
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

闭环频率特性与性能指标 频域分析
本卷考法
  • 辨析中频段宽度、带宽频率与开环增益的关系
本卷实例
  • 关键一步：由闭环幅频特性定义带宽频率
  • 中间结果：中频段以-20dB/dec穿越0dB且越宽动态性能越好
  • 卡点：自然频率相同不代表开环增益相同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过辨析中频段宽度、带宽频率与开环增益的关系
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈
公式
最小相位系统与非最小相位系统 频域分析
本卷考法
  • 辨析非最小相位系统与根轨迹、相频特性
本卷实例
  • 关键一步：由相频特性判断是否存在右半平面零点
  • 中间结果：低频段仅比例环节而相频为180°说明存在非最小相位环节
  • 卡点：含右半平面零点时仍按常规根轨迹绘制
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过辨析非最小相位系统与根轨迹、相频特性
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈
能控性与能观性 状态空间分析
本卷考法
  • 按约当标准型判断状态变量的能控性与能观性
本卷实例
  • 关键一步：按输入与输出矩阵中对应元素判断各状态
  • 中间结果：重特征值只对应一个约当块时该状态可控
  • 卡点：既可控又可观的状态取两类判据的交集
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过按约当标准型判断状态变量的能控性与能观性
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

状态反馈与极点配置 状态空间分析
本卷考法
  • 辨析输出反馈与状态反馈配置极点的条件
本卷实例
  • 关键一步：比较状态反馈与输出反馈可调参数的维数
  • 中间结果：输出反馈任意配置极点要求系统可控且可观
  • 卡点：观测器反馈与直接状态反馈的响应并非每一时刻相等
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过辨析输出反馈与状态反馈配置极点的条件
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反

李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 辨析李雅普诺夫方法与不可控系统能否镇定
本卷实例
  • 关键一步：判断不可控子空间是否稳定以决定能否镇定
  • 中间结果：李雅普诺夫方法既能判稳也能用于控制器设计
  • 卡点：不可控但不可控状态稳定时系统仍可镇定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过辨析李雅普诺夫方法与不可控系统能否镇定
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

二结构图信号流图与梅森公式#

思路
  • 由控制系统结构图画出信号流图，列回路与前向通道，用梅森增益公式求闭环传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图信号流图用梅森公式求C(s)比R(s)
本卷实例
  • 关键一步：列全部回路、前向通道及其余子式
  • 中间结果：特征式为1减各回路增益之和
  • 卡点：第二条前向通道与第一、二条回路均接触
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图信号流图用梅森公式求C(s)比R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 逐层化简结构图核对梅森公式结果
本卷实例
  • 关键一步：从最内层比较点与引出点开始等效
  • 中间结果：多回路化简后分母为各回路增益组合
  • 卡点：化简内环时外环信号不能当常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过逐层化简结构图核对梅森公式结果
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

三随动系统典型环节辨识与示波器波形分析#

思路
  • 由示波器波形判断校正与反馈环节属于何种典型环节，用叠加原理分别求给定与扰动作用下的输出与误差，题面条件矛盾处按结构定性分析
典型环节及其特性 传递函数
本卷考法
  • 由稳态波形判断Gc与Gf属于何种典型环节
本卷实例
  • 关键一步：由稳态信号是否为零或为斜坡判断环节含积分与否
  • 中间结果：误差稳态为零要求前向通道含积分环节
  • 卡点：由t=0.2时刻的值反推时间常数需回原卷读图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过由稳态波形判断Gc与Gf属于何种典型环节
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减

反馈校正与复合控制 系统校正
本卷考法
  • 分析校正与反馈环节对跟踪和扰动误差的作用
本卷实例
  • 关键一步：对输入与扰动分别用叠加原理求输出
  • 中间结果：扰动误差与给定误差的传函结构不同
  • 卡点：断开反馈时的响应只能用于辨识对象
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过分析校正与反馈环节对跟踪和扰动误差的作用
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
