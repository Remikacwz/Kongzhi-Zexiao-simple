河海大学 827 自动控制理论（含现控） 2018 年真题思维导图

211 院校共 7 题合计 150 分

难度：中等　全卷分选择、填空、计算三大题：10 道选择与 10 道填空共 80 分，5 道计算题每题 14 分；覆盖基本组成与环节、传递函数与梅逊公式、劳斯与奈氏判据、根轨迹、正弦稳态输出与扰动不变性。

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

一一、选择题（基本组成、环节与判据）40 分#

思路
  • 10 道概念选择覆盖系统辨识、基本组成元件、典型环节串联、由微分方程求传函、梅逊公式、一阶系统稳态值、二阶动态指标与频率特性求法，按各问考点逐条判定。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由已知输入输出确定系统结构与参数（第1问）
本卷实例
  • 关键一步：按已知输入输出反求系统模型属系统辨识的思路
  • 中间结果：先定阶数与结构形式再定参数
  • 卡点：勿与最优设计、系统分析等概念混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由已知输入输出确定系统结构与参数（第1问）
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出比较元件与执行元件的作用（第2、3问）
本卷实例
  • 关键一步：按元件在闭环中承担的运算或驱动功能判断
  • 中间结果：对多个信号求加减的元件为比较元件
  • 卡点：执行元件直接操作被控对象、与放大元件区分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指出比较元件与执行元件的作用（第2、3问）
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
典型环节及其特性 传递函数
本卷考法
  • 判断给定环节可看成哪些典型环节串联（第4问）
本卷实例
  • 关键一步：把传函拆成常数项、微分项与积分项之积
  • 中间结果：各项依次对应比例、微分与积分环节
  • 卡点：含 1/s 项为积分环节而非惯性环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过判断给定环节可看成哪些典型环节串联（第4问）
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减
公式
传递函数的定义与基本性质 传递函数
本卷考法
  • 由微分方程写出系统的传递函数（第5问）
本卷实例
  • 关键一步：在零初始条件下对微分方程两边取拉氏变换
  • 中间结果：传函为输出与输入拉氏变换在零初值下的比值
  • 卡点：分子分母系数次序勿写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由微分方程写出系统的传递函数（第5问）
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 指出梅逊公式的主要用途（第6问）
本卷实例
  • 关键一步：由梅逊公式求解的是输入到输出的传递函数
  • 中间结果：梅逊公式用于结构图或信号流图的传函化简
  • 卡点：勿与判断稳定性、求根轨迹的判据混答
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过指出梅逊公式的主要用途（第6问）
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 判断一阶系统放大系数减小时稳态值如何变（第7问）
本卷实例
  • 关键一步：由一阶系统阶跃响应的稳态值等于输入与增益之积
  • 中间结果：增益越小、同一输入下的输出稳态值越小
  • 卡点：稳态值与时间常数无关，须区分两者
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过判断一阶系统放大系数减小时稳态值如何变（第7问）
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 指出二阶欠阻尼中只与阻尼比有关的指标（第8问）
本卷实例
  • 关键一步：逐项比较各动态指标公式含哪些参数
  • 中间结果：最大超调量只由阻尼比决定、与自然频率无关
  • 卡点：上升时间、峰值时间还依赖自然频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过指出二阶欠阻尼中只与阻尼比有关的指标（第8问）
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 说明实验测幅频特性时改变的输入量并求给定幅值（第9、10问）
本卷实例
  • 关键一步：实验法靠连续改变输入信号频率测对应输出幅值
  • 中间结果：把给定频率代入幅频表达式即可求该点幅值
  • 卡点：求幅值时须先写出频率特性再取模
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过说明实验测幅频特性时改变的输入量并求给定幅值（第9、10问）
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

最小相位系统与非最小相位系统 频域分析
本卷考法
  • 填出最小相位系统判稳所需的频率特性（第3问）
本卷实例
  • 关键一步：由最小相位系统幅频与相频的确定关系判断
  • 中间结果：最小相位系统只知开环幅频特性即可判稳
  • 卡点：非最小相位系统不适用此结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过填出最小相位系统判稳所需的频率特性（第3问）
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函求阻尼比与自然频率
本卷实例
  • 关键一步：把闭环传函化为二阶标准形式并比较系数
  • 中间结果：阻尼比由一次项系数与自然频率共同定出
  • 卡点：结构图以图给出，反馈增益需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
