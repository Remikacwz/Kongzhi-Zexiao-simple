1一、理想运放有源网络求传递函数#

思路
  • 对理想运放电路用虚短虚断列电流关系，把各支路写成复阻抗，整理出输入输出传递函数。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 用复阻抗法求理想运放有源网络的传递函数
本卷实例
  • 关键一步：按虚短虚断列节点电流关系，再用复阻抗表示各元件
  • 关键一步：把输入输出关系整理成两个一阶环节相乘再除以一个积分因子
  • 中间结果：整理结果含两个时间常数与一个纯积分环节
  • 卡点：运放电路以图给出，反馈支路接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过用复阻抗法求理想运放有源网络的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由有源网络电路列写输出与输入的传递关系
本卷实例
  • 关键一步：把反馈支路阻抗与输入支路阻抗分别写成复阻抗
  • 关键一步：按运放两端虚短列方程消去中间节点电压
  • 中间结果：输入输出关系由两条支路阻抗之比决定
  • 卡点：多级放大要注意级间是否引入反馈，不能直接相乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由有源网络电路列写输出与输入的传递关系
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式

2二、双输入作用下用梅森公式求输出#

思路
  • 分别对参考输入与扰动用梅森公式求两条传函，再按线性系统叠加原理合成总输出。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式分别求参考输入与扰动到输出的传函
本卷实例
  • 关键一步：对参考输入和扰动分别找前向通路与全部回路
  • 关键一步：分别写出两条前向通路的余子式与公共特征式
  • 中间结果：两条前向通路的余子式由与之不接触的回路构成
  • 卡点：结构图以图给出，通路接触关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式分别求参考输入与扰动到输出的传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 用叠加原理写出双输入共同作用下的系统输出
本卷实例
  • 关键一步：分别令另一输入为零，各求一个传递函数
  • 关键一步：把两个输入各自作用的结果相加得到总输出
  • 中间结果：总输出等于两个输入各自传函作用结果之和
  • 卡点：求扰动传函时要把参考输入置零，不能漏项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过用叠加原理写出双输入共同作用下的系统输出
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

3三、斜坡输入与干扰下稳态误差及不变性#

思路
  • 写误差传函求斜坡输入下的稳态误差，再由总误差为零的条件解出补偿参数之间的关系。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡参考输入下单闭环系统的稳态误差
本卷实例
  • 关键一步：判稳后写出误差传函，用终值定理求斜坡输入下的误差
  • 关键一步：把输入幅值代入误差表达式整理成增益的函数
  • 中间结果：斜坡误差与开环系统在原点处极点的重数有关
  • 卡点：误差为组合信号时要按分量分别计算再相加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求斜坡参考输入下单闭环系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求斜坡扰动单独作用下的稳态误差
本卷实例
  • 关键一步：把参考输入置零，求扰动到误差的传递函数
  • 关键一步：按扰动作用点前向通路与回路的增益化简传函
  • 中间结果：扰动误差与扰动作用点前向通路的增益有关
  • 卡点：结构图以图给出，扰动接入点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求斜坡扰动单独作用下的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 由误差等于零的条件求补偿参数应满足的关系
本卷实例
  • 关键一步：让总误差表达式的分子为零，解出两个参数的关系
  • 关键一步：回到系统特征方程检查该参数下闭环是否稳定
  • 中间结果：补偿参数取特定关系时斜坡误差被完全补偿
  • 卡点：零误差是理想条件，实际还要检查系统是否稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过由误差等于零的条件求补偿参数应满足的关系
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式

4四、增益与微分环节变化下的根轨迹与性能#

思路
  • 按绘制法则画根轨迹求渐近线与分离点，加入微分环节后重新绘制，并对比说明对性能的影响。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画三阶系统根轨迹并求渐近线与分离点
本卷实例
  • 关键一步：标出零极点，判断实轴根轨迹段与渐近线夹角
  • 关键一步：由分离点方程求解并筛选落在根轨迹上的解
  • 中间结果：三条分支按渐近线夹角六十度等分圆周方向延伸
  • 卡点：分离点方程可能有多个根，要按实轴区段筛选
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画三阶系统根轨迹并求渐近线与分离点
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点和分离点求增益取值范围
本卷实例
  • 关键一步：令特征方程中 s 等于 jω 解出临界频率与临界增益
  • 关键一步：由分离点处的增益与虚轴交点处的增益夹出所需范围
  • 中间结果：衰减振荡对应轨迹离开实轴之后且尚未穿越虚轴
  • 卡点：参数范围要同时满足衰减振荡与稳定两个条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹与虚轴交点和分离点求增益取值范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 分析串联微分环节对根轨迹形状与系统性能的影响
本卷实例
  • 关键一步：对比加零点前后渐近线交点与分离点的移动方向
  • 关键一步：由轨迹左移或弯曲判断对稳定性与快速性的作用
  • 中间结果：附加零点使轨迹向左弯，有利于稳定与提高响应速度
  • 卡点：附加零点的影响与附加极点方向相反，不要记混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过分析串联微分环节对根轨迹形状与系统性能的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反

5五、由Bode图求传函、相角裕度与斜坡误差#

思路
  • 由Bode图低频段与转折频率反求传函，再算截止频率处的相角裕度与斜坡输入下的稳态误差。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由Bode图读出转折频率与截止频率反求开环传函
本卷实例
  • 关键一步：按低频段斜率定系统型别，按低频段高度定开环增益
  • 关键一步：按各转折频率处的斜率变化量确定环节类型与时间常数
  • 中间结果：传函由一个积分、一个微分和两个惯性环节串联组成
  • 卡点：Bode图以插图给出，转折频率数值需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
