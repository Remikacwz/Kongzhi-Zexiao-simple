1一、结构图求传递函数15 分#

思路
  • 按结构图找独立回路与前向通路，用梅森公式写出输入到输出的传递函数。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求结构图的输入到输出传递函数
本卷实例
  • 关键一步：按结构图找独立回路与前向通路并写各自余子式
  • 中间结果：特征式含两两互不接触回路的乘积项
  • 卡点：结构图以图给出，回路接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求结构图的输入到输出传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、参考与扰动双输入稳态误差15 分#

思路
  • 分别对参考输入与扰动求误差传函，用终值定理算阶跃误差再按限值条件解参数。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求参考输入单独作用下的阶跃稳态误差并反求参数
本卷实例
  • 关键一步：判稳后写误差传函用终值定理求阶跃误差
  • 中间结果：阶跃误差为零要求误差传函在原点留数为零
  • 卡点：参考输入单独作用时须把扰动置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求参考输入单独作用下的阶跃稳态误差并反求参数
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动单独作用下的稳态误差并反求参数
本卷实例
  • 关键一步：扰动作用时令参考输入为零求扰动到误差传函
  • 中间结果：扰动误差由扰动到误差传函在原点取值决定
  • 卡点：扰动接入点与结构图有关，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求扰动单独作用下的稳态误差并反求参数
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 用叠加原理写出双输入共同作用下的误差
本卷实例
  • 关键一步：把参考输入与扰动各自作用的误差结果相加
  • 中间结果：双输入系统的总误差为两分量之和
  • 卡点：叠加原理只对线性系统成立
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过用叠加原理写出双输入共同作用下的误差
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

3三、相位裕度反求阻尼比15 分#

思路
  • 由相角裕度条件求截止频率与增益，再由闭环特征式对照二阶标准形式求阻尼比。
稳定裕度 频域分析
本卷考法
  • 由相角裕度条件求截止频率并反求开环增益
本卷实例
  • 关键一步：由相角裕度条件写出截止频率处的相角关系
  • 中间结果：相角裕度等于一百八十度加相频在截止频率的取值
  • 卡点：截止频率与自然频率是两个不同量勿混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由相角裕度条件求截止频率并反求开环增益
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征式对照标准二阶形式求阻尼比
本卷实例
  • 关键一步：由开环传函写出闭环特征式并对照标准形式
  • 中间结果：阻尼比由特征式一次项与自然频率的关系给出
  • 卡点：化标准形式时须把二次项系数归一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征式对照标准二阶形式求阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

4四、稳定范围与根轨迹15 分#

思路
  • 先由劳斯判据求闭环稳定增益范围，再按绘制法则画根轨迹求渐近线与起始角。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求系统闭环稳定的增益范围
本卷实例
  • 关键一步：列特征方程劳斯表并令首列元素为正
  • 中间结果：稳定上界由首列含增益元素为零给出
  • 卡点：特征方程缺项时按零补齐再列劳斯表
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求系统闭环稳定的增益范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画三阶系统根轨迹的草图
本卷实例
  • 关键一步：标出开环零极点并判断实轴根轨迹段
  • 中间结果：三条分支渐近线交角由极点数与零点数之差给出
  • 卡点：轨迹从开环极点出发、终止于零点或无穷远
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画三阶系统根轨迹的草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点与会合点
本卷实例
  • 关键一步：由分离点方程求根再筛选落在轨迹上的解
  • 中间结果：分离点处对应增益由幅值条件给出
  • 卡点：求出的根必须落在实轴根轨迹段内
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点与会合点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
出射角与入射角 根轨迹法
本卷考法
  • 求共轭复数极点的出射角
本卷实例
  • 关键一步：对复数极点按相角条件写射角方程
  • 中间结果：出射角由其余零极点相角的代数和给出
  • 卡点：累加相角时勿把该极点自身的相角算进去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 出射角是根轨迹离开开环极点的方向
  • 入射角是根轨迹进入开环零点的方向
  • 计算时需代入相角条件并逐项累加各零极点贡献的相角
  • 共轭复数极点的出射角互为相反数
步骤
  • 取待求极点（或零点）为参考点
  • 写出相角条件并代入该点
  • 把其余零极点的相角移到等式右边累加
  • 求反正切得到出射角或入射角
通用考法
  • 本卷考过求共轭复数极点的出射角
  • 求复数极点的出射角
  • 根据出射角画出根轨迹起始方向
  • 由入射角确定根轨迹终止方向
常见易错
  • 累加相角时把该极点自身的相角也算进去
  • 忘记判断象限导致角度差 180°

与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴的交点及临界增益
本卷实例
  • 关键一步：令特征方程中 s 等于 jω 求频率与临界增益
  • 中间结果：临界增益与穿越频率成对出现
  • 卡点：轨迹始终在左半平面时范围以劳斯表结论为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴的交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

5五、正弦输入下的稳态输出10 分#

思路
  • 求闭环传函并代入正弦频率得幅频与相频，再按输入幅值与初相写出稳态输出。
频率特性的物理意义与求法 频域分析
本卷考法
  • 由闭环频率特性求正弦输入下的稳态输出
本卷实例
  • 关键一步：先由开环传函求闭环传函再代 jω 得幅相特性
  • 中间结果：正弦稳态输出幅值等于幅频乘输入幅值
  • 卡点：相位要加上输入初相，勿只写滞后角
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由闭环频率特性求正弦输入下的稳态输出
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
