1一、参考输入与扰动下单闭环系统稳态误差#

思路
  • 先判闭环稳定，再分别求参考输入与扰动到误差的传递函数，按输入类型用终值定理算稳态误差。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位阶跃参考输入下单闭环系统的稳态误差
本卷实例
  • 关键一步：先判闭环稳定，再由误差传函在零频处的取值求误差
  • 中间结果：参考输入下误差为零与否由开环积分环节的个数决定
  • 卡点：误差传函与输出传函口径不同，不要混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位阶跃参考输入下单闭环系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动单独作用下的稳态误差
本卷实例
  • 关键一步：把参考输入置零，写出扰动到误差的传递函数
  • 关键一步：按扰动作用点的通路上各环节增益化简传函
  • 中间结果：扰动误差的大小取决于扰动作用点到误差通路的总增益
  • 卡点：结构图以图给出，扰动接入点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求扰动单独作用下的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求正弦扰动下稳态误差的幅值与相位
本卷实例
  • 关键一步：将误差对扰动的传函代入 jω 求其频率特性
  • 关键一步：在输入正弦的角频率处读出幅值比与相位差
  • 中间结果：稳态误差为同频正弦量，幅相由频率特性在输入频率处定
  • 卡点：输入角频率的数值要从图中读，不要漏掉单位
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求正弦扰动下稳态误差的幅值与相位
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

2二、由开环频率特性反求传函并判稳定#

思路
  • 由频率特性曲线低频段定积分环节个数与增益，写出最小相位传函，再用奈奎斯特判据判闭环稳定性。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环频率特性曲线反求最小相位系统传递函数
本卷实例
  • 关键一步：由低频段相角定积分环节个数，再由低频段幅值定增益
  • 关键一步：按曲线与负实轴的关系补出增补线以判断型别
  • 中间结果：增补线落在负实轴外侧说明开环含有两个积分环节
  • 卡点：频率特性图以图给出，各段斜率需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环频率特性曲线反求最小相位系统传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据判断单位负反馈系统的闭环稳定性
本卷实例
  • 关键一步：数清开环右半平面极点数，再判曲线包围临界的圈数
  • 关键一步：按包围圈数与右半平面极点数比较得出闭环稳定性
  • 中间结果：包围圈数与开环右半平面极点数相等时闭环稳定
  • 卡点：含积分环节时不要忘记补画无穷大半径圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据判断单位负反馈系统的闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

3三、正负反馈下参数稳定域（劳斯判据）#

思路
  • 分别写出单位负反馈与单位正反馈的闭环特征方程，用劳斯判据求两组参数的稳定取值范围。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求正反馈与负反馈下参数的稳定范围
本卷实例
  • 关键一步：写出闭环特征方程，注意正反馈时反馈项取加号
  • 关键一步：列劳斯表并令首列各元素同号得到参数约束
  • 中间结果：二阶系统的稳定条件归结为两个系数同时为正
  • 卡点：单位正反馈的特征方程与负反馈相差一个符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求正反馈与负反馈下参数的稳定范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 把劳斯判据结果整理成双参数平面上的稳定域
本卷实例
  • 关键一步：把两个不等式的边界曲线画在参数平面上并取公共区域
  • 关键一步：回到原不等式判断稳定域边界是否包含端点
  • 中间结果：稳定域边界由劳斯表首列元素等于零的曲线构成
  • 卡点：只列部分首列元素的不等式会漏掉一条约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过把劳斯判据结果整理成双参数平面上的稳定域
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式

4四、结构图闭环传函与临界阻尼条件#

思路
  • 用梅森公式求闭环传函，再把分母与标准二阶形式对照，由判别式为零导出临界阻尼条件。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求多回路结构图的闭环传递函数
本卷实例
  • 关键一步：找出两条局部反馈回路并判断它们是否接触
  • 关键一步：按梅森公式写出特征式与前向通路的余子式
  • 中间结果：特征式为各回路增益之和再补上互不接触回路的乘积
  • 卡点：结构图以图给出，回路接触关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求多回路结构图的闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征方程的判别式为零确定临界阻尼条件
本卷实例
  • 关键一步：把闭环传函分母与标准二阶形式对照写出阻尼比与自然频率
  • 关键一步：令特征方程判别式为零即得临界阻尼时两参数的关系
  • 中间结果：临界阻尼对应特征方程有两个相等的负实根
  • 卡点：临界阻尼是判别式为零，与欠阻尼区间的端点一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征方程的判别式为零确定临界阻尼条件
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式

5五、以增益为参变量的零度根轨迹与欠阻尼范围#

思路
  • 把特征方程整理成等效开环形式，画零度根轨迹，再由交点与分离点确定稳定与欠阻尼范围。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 把特征方程整理成等效开环形式绘制零度参数根轨迹
本卷实例
  • 关键一步：把含参项移到一侧写成等效开环传函并判断相角条件
  • 关键一步：按等效开环的零点极点画零度根轨迹
  • 中间结果：等效开环有一个零点与一对重极点，轨迹为圆心在零点附近的圆
  • 卡点：参数在特征方程一次项系数里，须先整理成标准根轨迹形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过把特征方程整理成等效开环形式绘制零度参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点及分离点确定稳定与欠阻尼范围
本卷实例
  • 关键一步：令特征方程中 s 等于 jω 分离实部虚部求交点参数
  • 关键一步：由分离点处参数与虚轴交点处参数夹出所需范围
  • 中间结果：分离点处的参数对应轨迹离开实轴，是振荡的起点
  • 卡点：求出的分离点若不在根轨迹上应舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
