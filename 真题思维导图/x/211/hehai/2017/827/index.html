河海大学 827 自动控制理论（含现控） 2017 年真题思维导图

211 院校共 7 题合计 150 分

难度：中等　全卷分选择、填空、计算三大题：10 道选择、9 道填空共 80 分，5 道计算题每题 14 分；覆盖反馈基本概念、劳斯与奈氏判据、校正类型、零度与参数根轨迹、Bode 图反求传函及串联校正设计。

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

一一、选择题（反馈概念、判据与根轨迹）40 分#

思路
  • 10 道概念选择覆盖负反馈作用、附加零极点影响、劳斯与奈氏判据、系统型别、零度根轨迹、稳定裕度与校正装置识别，按各问考点逐条判定。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断采用负反馈后对稳定性与动态性能的影响（第1问）
本卷实例
  • 关键一步：从负反馈改变闭环极点与抗扰能力两方面判断
  • 中间结果：负反馈不保证闭环一定稳定、也未必改善动态性能
  • 卡点：选项把改善性能说成必然，须逐项甄别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断采用负反馈后对稳定性与动态性能的影响（第1问）
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
附加开环零极点的影响 根轨迹法
本卷考法
  • 指出提高稳定性没有效果的措施（第2问）
本卷实例
  • 关键一步：比较附加开环极点与零点对根轨迹走向的影响
  • 中间结果：附加开环极点使根轨迹右移、不利于稳定性
  • 卡点：勿把引入超前校正误当成增加极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过指出提高稳定性没有效果的措施（第2问）
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断三阶特征方程的稳定性（第3问）
本卷实例
  • 关键一步：列劳斯表观察首列是否出现全零行
  • 中间结果：出现全零行说明存在纯虚根、系统临界稳定
  • 卡点：全零行须用辅助方程继续判别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断三阶特征方程的稳定性（第3问）
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由抛物线输入的稳态误差判断系统型别（第4问）
本卷实例
  • 关键一步：由输入信号的阶次与稳态误差是否有限判断型别
  • 中间结果：抛物线输入下误差为无穷说明系统型别低于二阶
  • 卡点：注意区分型别不足与系统本身不稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由抛物线输入的稳态误差判断系统型别（第4问）
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 判断何种情况下应绘制零度根轨迹（第5问）
本卷实例
  • 关键一步：由根轨迹方程的相角条件为 0 度还是 180 度判断
  • 中间结果：正反馈或根轨迹方程标准形式为 +1 时用零度根轨迹
  • 卡点：须与常规 180 度根轨迹的判据区分开
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过判断何种情况下应绘制零度根轨迹（第5问）
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
稳定裕度 频域分析
本卷考法
  • 相角裕度对应的时域指标与最小相位系统判稳（第6、7问）
本卷实例
  • 关键一步：由相角裕度大小判断超调趋势、由两个裕度共同判稳
  • 中间结果：相角裕度大对应超调小；两裕度均大于零才稳定
  • 卡点：只知相角裕度为正不能推出幅值裕度也大于零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过相角裕度对应的时域指标与最小相位系统判稳（第6、7问）
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅频特性图判断不稳定的系统（第8问）
本卷实例
  • 关键一步：由开环幅相曲线包围临界点的圈数配合开环右极点判稳
  • 中间结果：系统不稳定对应 Z=P-2N 大于零
  • 卡点：系统①至③的曲线以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环幅频特性图判断不稳定的系统（第8问）
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
滞后校正 系统校正
本卷考法
  • 由校正装置传函判断其类型（第9问）
本卷实例
  • 关键一步：比较分子分母时间常数判断超前或滞后特性
  • 中间结果：零转角频率低于极点转角频率时为滞后校正
  • 卡点：题中 10 与 100 两个时间常数易看反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过由校正装置传函判断其类型（第9问）
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
超前校正 系统校正
本卷考法
  • 判断何者能在给定频率提供最大相位超前角（第10问）
本卷实例
  • 关键一步：对每个候选环节写相角表达式并代入给定频率比较
  • 中间结果：最大相位超前角出现在两转角频率的几何中点
  • 卡点：四个选项分母时间常数不同，须逐一计算相角
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过判断何者能在给定频率提供最大相位超前角（第10问）
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

传递函数的定义与基本性质 传递函数
本卷考法
  • 填出传递函数定义与一、二阶系统标准形式（第2、4问）
本卷实例
  • 关键一步：由零初始条件下输出与输入拉氏变换之比写定义式
  • 中间结果：系统数学模型由自身结构和参数决定、与外作用无关
  • 卡点：写标准形式时二次项系数需归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过填出传递函数定义与一、二阶系统标准形式（第2、4问）
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

劳斯判据 稳定性分析
本卷考法
  • 填出经典控制理论中判断线性系统稳定性的代数方法（第3问）
本卷实例
  • 关键一步：由特征方程系数直接判别稳定性
  • 中间结果：代数判据常用劳斯稳定判据
  • 卡点：勿把根轨迹法当作代数判据填入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

本卷考法
  • 由单位斜坡稳态误差要求确定开环增益
本卷实例
  • 关键一步：写误差传函并用终值定理把误差要求化为对增益的约束
  • 中间结果：增益下限由误差指标定出
  • 卡点：须先判稳再使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位斜坡稳态误差要求确定开环增益
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

超前校正 系统校正
本卷考法
  • 按最大超前角法设计串联超前校正装置
本卷实例
  • 关键一步：由期望裕度与未校正裕度之差并留余量定补偿角
  • 中间结果：最大超前角频率处原系统幅值应等于网络的幅值补偿量
  • 卡点：计算补偿角时须留出截止频率移动带来的相角余量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过按最大超前角法设计串联超前校正装置
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

稳定裕度 频域分析
本卷考法
  • 校核校正后系统的相角裕度与幅值裕度
本卷实例
  • 关键一步：在校正后截止频率与相位穿越频率处分别求两个裕度
  • 中间结果：校正后裕度不小于指标要求即合格
  • 卡点：须用校正后的开环传函重新求穿越频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过校核校正后系统的相角裕度与幅值裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
