河海大学 827 自动控制理论（含现控） 2016 年真题思维导图

211 院校共 7 题合计 150 分

难度：中等　全卷分选择、填空、计算三大题：10 道选择与 10 道填空共 80 分，5 道计算题每题 14 分；覆盖劳斯判据、静态误差、校正类型、频率特性、二阶响应与根轨迹，计算题多配结构图或渐近线图。

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

一一、选择题（稳定性、误差与校正概念）40 分#

思路
  • 10 道概念选择集中在劳斯判据判稳与临界稳定、静态误差、校正装置类型、实轴根轨迹与速度反馈传感器，按各问归属的考点逐条判定。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判稳定、临界稳定增益与右半平面根个数（第1~3问）
本卷实例
  • 关键一步：对给定特征方程列劳斯表并数首列符号变化
  • 中间结果：首列全为正则稳定，出现零元素对应临界稳定
  • 卡点：第3问逐年特征式 OCR 成 5s²+c+2，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判稳定、临界稳定增益与右半平面根个数（第1~3问）
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过首列出现零行时漏用辅助方程继续判别
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 判断为提高稳定性应如何调整增益（第7问）
本卷实例
  • 关键一步：由增益变化使根轨迹左右移动看其对稳定性的影响
  • 中间结果：降低开环增益使部分闭环极点左移、稳定性改善
  • 卡点：稳态精度与稳定性对增益的要求相反，须辨明题干前提
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过判断为提高稳定性应如何调整增益（第7问）
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由单位反馈开环传函求单位阶跃下的位置误差（第4问）
本卷实例
  • 关键一步：先判闭环稳定再求静态位置误差系数
  • 中间结果：0 型系统的位置误差由开环静态增益决定
  • 卡点：须把开环传函与闭环特征式区分开，勿混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由单位反馈开环传函求单位阶跃下的位置误差（第4问）
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 写出稳态误差 ess 与误差信号 E(s) 的关系（第6问）
本卷实例
  • 关键一步：用终值定理写出 ess 的极限表达式
  • 中间结果：ess 由 s 趋于 0 时 sE(s) 的极限给出
  • 卡点：四个选项的极限变量不同，须辨明 s 趋于 0 还是趋于无穷
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写出稳态误差 ess 与误差信号 E(s) 的关系（第6问）
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
滞后校正 系统校正
本卷考法
  • 由校正装置传函判断其属超前还是滞后校正（第5问）
本卷实例
  • 关键一步：比较校正环节零点与极点的相对位置
  • 中间结果：零点在极点左侧为滞后校正、右侧为超前校正
  • 卡点：传函中时间常数 1 与 10 易看反，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过由校正装置传函判断其属超前还是滞后校正（第5问）
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
公式
超前校正 系统校正
本卷考法
  • 判断相位超前校正装置奈氏曲线的形状（第8问）
本卷实例
  • 关键一步：写出超前环节幅相表达式看其低频到高频的相角范围
  • 中间结果：超前环节幅相曲线位于上半平面且为半圆
  • 卡点：须结合最大超前角所在频率判断曲线范围
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过判断相位超前校正装置奈氏曲线的形状（第8问）
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 由开环传函判断实轴上的根轨迹段（第9问）
本卷实例
  • 关键一步：用实轴某段右侧开环零极点总数为奇数定该段是否在根轨迹上
  • 中间结果：含原点极点时实轴根轨迹段的端点由零极点位置定出
  • 卡点：选项给出开区间写法，端点是否含需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过由开环传函判断实轴上的根轨迹段（第9问）
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
转速负反馈单闭环调速系统 电力拖动与运动控制
本卷考法
  • 指出直流调速系统中霍尔传感器提供的反馈量（第10问）
本卷实例
  • 关键一步：由传感器测得的物理量判断它在闭环中作何种反馈
  • 中间结果：测速元件的反馈量对应电动机转速
  • 卡点：本题为电力拖动基本概念，取自调速系统一节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 被控量是转速，反馈量是测速发电机输出电压
  • 属于有差系统，稳态时偏差 e=U_n*−U_n 必须不为零才能维持输出
  • 闭环后稳态速降减小为开环的 1/(1+K) 倍
  • 闭环放大倍数 K 越大，静差率越小，但稳定性越差
步骤
  • 确定被控制量与反馈量
  • 按信号流向画出给定、比较、放大、变换器、电动机、测速反馈各环节
  • 写出稳态关系式并求闭环静特性
  • 比较开环与闭环的稳态速降
通用考法
  • 本卷考过指出直流调速系统中霍尔传感器提供的反馈量（第10问）
  • 指出系统的被控量与反馈量
  • 画出系统结构框图
  • 解释稳态时偏差不为零的原因
  • 计算闭环稳态速降并比较开环
常见易错
  • 误以为有差系统稳态可以做到零偏差
  • 把被控量与反馈量混为一谈
  • 求闭环静特性时漏掉 (1+K) 因子
公式

二二、填空题（基本概念、环节特性与误差）40 分#

思路
  • 10 道填空覆盖一阶斜坡误差、二阶临界振荡、惯性环节、滞后校正条件、对数幅频斜率、反馈控制系统、传递函数定义、线性化精度与最小相位系统判稳。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求一阶系统在单位斜坡输入下的稳态误差（第1、8问）
本卷实例
  • 关键一步：写出误差传函后用终值定理求斜坡输入下的极限
  • 中间结果：一阶系统斜坡误差为常数，与时间常数成比例
  • 卡点：代入前须先确认系统稳定，勿漏代输入的拉氏变换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求一阶系统在单位斜坡输入下的稳态误差（第1、8问）
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由特征方程求系统产生临界振荡时的参数（第2问）
本卷实例
  • 关键一步：把特征方程对照二阶标准形式比较系数
  • 中间结果：临界振荡对应阻尼比为零、特征根为一对纯虚数
  • 卡点：特征式 OCR 缺前文，需回原卷核对题干条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由特征方程求系统产生临界振荡时的参数（第2问）
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
典型环节及其特性 传递函数
本卷考法
  • 说明惯性环节的响应特点（第3问）
本卷实例
  • 关键一步：由一阶环节传函写阶跃响应看其单调上升特性
  • 中间结果：输出按指数规律上升、上升快慢由时间常数决定
  • 卡点：须与纯微分、纯积分环节的特点区分开
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过说明惯性环节的响应特点（第3问）
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减
公式
滞后校正 系统校正
本卷考法
  • 指出校正装置作滞后校正时应满足的参数条件（第4问）
本卷实例
  • 关键一步：对照滞后校正标准形式比较分子分母的时间常数
  • 中间结果：滞后校正要求系数使零点位于极点靠近原点的一侧
  • 卡点：题目给出三个不等号选项，须按滞后定义择一
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
