河海大学 827 自动控制理论（含现控） 2019 年真题思维导图

一一、选择题（负反馈、稳定性与根轨迹概念）40 分#

思路
  • 10 道概念选择覆盖负反馈作用、提高稳定性的措施、劳斯判据、型别与稳态误差、零度根轨迹条件、传递函数性质、主导极点、开环增益、根轨迹起点与相角裕度对应关系。
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断采用负反馈连接后对稳定性与动态性能的影响（第1问）
本卷实例
  • 关键一步：把负反馈对误差、结构参数与扰动的作用逐一对照选项
  • 中间结果：负反馈只有配合合适结构与参数才改善性能
  • 卡点：选项含夸大表述，需按负反馈实际作用辨别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断采用负反馈连接后对稳定性与动态性能的影响（第1问）
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 本卷考过把负反馈的作用说成无条件改善性能
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
附加开环零极点的影响 根轨迹法
本卷考法
  • 判断增加开环零极点能否提高系统稳定性（第2问）
本卷实例
  • 关键一步：由零极点位置变化看根轨迹整体左移还是右移
  • 中间结果：增开环零点通常利于稳定，增开环极点作用相反
  • 卡点：四种措施作用方向不同，需逐项归因
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过判断增加开环零极点能否提高系统稳定性（第2问）
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
超前校正 系统校正
本卷考法
  • 判断串联超前校正对稳定性的作用（第2问）
本卷实例
  • 关键一步：写出超前环节相角超前量并与原系统比较
  • 中间结果：超前校正靠相位超前提高稳定裕度
  • 卡点：超前效果受最大超前角频率处幅值影响
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过判断串联超前校正对稳定性的作用（第2问）
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断给定三次特征方程的系统状态（第3问）
本卷实例
  • 关键一步：对 D(s)=s³+2s²+3s+6 列劳斯表并检查首列符号
  • 中间结果：首列出现零元素且辅助方程给出纯虚根，对应临界稳定
  • 卡点：首列为零时须用辅助方程继续判定，勿直接判稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断给定三次特征方程的系统状态（第3问）
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过系数无缺项就不补零，忽略零行对应纯虚根
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由稳态误差判断型别，并求开环增益（第4、8问）
本卷实例
  • 关键一步：由 ess 是否有限定型别，再把开环传函化成标准形式读增益
  • 中间结果：抛物线输入下 ess 无穷说明型别低于二阶；增益由常数项之比给出
  • 卡点：开环增益不是分子常数本身，须化成尾一标准形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由稳态误差判断型别，并求开环增益（第4、8问）
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 判断何种情形下应绘制零度根轨迹（第5问）
本卷实例
  • 关键一步：由相角条件区分正反馈、负反馈与参数根轨迹
  • 中间结果：正反馈及部分参数根轨迹对应零度相角条件
  • 卡点：标准形式下 G(s)H(s)=+1 才用零度条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过判断何种情形下应绘制零度根轨迹（第5问）
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
传递函数的定义与基本性质 传递函数
本卷考法
  • 辨别关于传递函数性质的错误说法（第6问）
本卷实例
  • 关键一步：逐项核对传递函数的适用条件、定义前提与极点意义
  • 中间结果：传递函数由系统结构与参数确定，与输入和扰动无关
  • 卡点：零点极点、真分式等表述易被替换成相近说法
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过辨别关于传递函数性质的错误说法（第6问）
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 判断主导闭环极点靠近虚轴对动态性能的影响（第7问）
本卷实例
  • 关键一步：由极点实部绝对值与调节时间的关系判断响应快慢
  • 中间结果：主导极点越靠近虚轴，实部越小，响应越慢
  • 卡点：准确度与响应速度是两个指标，勿混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过判断主导闭环极点靠近虚轴对动态性能的影响（第7问）
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 由根轨迹起点位置反推系统所含环节（第9问）
本卷实例
  • 关键一步：根轨迹起点对应开环极点，两个起点在原点即两原点极点
  • 中间结果：原点处两个开环极点对应两个积分环节
  • 卡点：理想微分环节对应零点而非起点，两者勿混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过由根轨迹起点位置反推系统所含环节（第9问）
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
稳定裕度 频域分析
本卷考法
  • 指出相角裕度对应的时域性能指标（第10问）
本卷实例
  • 关键一步：由相角裕度与超调量、调节时间的定性关系对应选项
  • 中间结果：相角裕度主要影响超调量等相对稳定性指标
  • 卡点：峰值时间与调整时间由更长的时间尺度决定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过指出相角裕度对应的时域性能指标（第10问）
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

反馈校正与复合控制 系统校正
本卷考法
  • 填出复合控制两种前馈补偿的划分依据（第2问）
本卷实例
  • 关键一步：按补偿信号取自输入还是扰动区分前馈形式
