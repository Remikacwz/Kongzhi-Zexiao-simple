一一、选择题（型别、离散稳定性与相轨迹概念）20 分#

思路
  • 4 道概念选择覆盖型别与阶跃误差、离散系统闭环稳定性、开环闭环传函关系与特征方程、线性系统相轨迹的奇点类型。
系统型别与静态误差系数 稳态误差
本卷考法
  • 判断几型系统对阶跃输入的稳态误差不为零（第1问）
本卷实例
  • 关键一步：由型别与阶跃输入下 ess 的关系判断哪一型仍有差
  • 中间结果：0 型系统跟踪阶跃有差，I 型及以上稳态误差为零
  • 卡点：题目前提是闭环稳定，须先排除不稳定情形
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断几型系统对阶跃输入的稳态误差不为零（第1问）
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

离散系统稳定性分析 离散控制系统
本卷考法
  • 由闭环脉冲传函判断离散系统稳定性（第2问）
本卷实例
  • 关键一步：解特征方程求极点模值并与单位圆比较
  • 中间结果：两极点模值均大于 1 时系统不稳定
  • 卡点：离散稳定判据看模是否小于 1，不是看实部
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过由闭环脉冲传函判断离散系统稳定性（第2问）
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

传递函数的定义与基本性质 传递函数
本卷考法
  • 辨别开环与闭环传函零点极点及特征方程表述（第3问）
本卷实例
  • 关键一步：逐项核对开环、闭环传函与特征方程的定义
  • 中间结果：闭环特征方程由 1 加开环传函等于零给出
  • 卡点：开环零点与闭环零点一般不重合，勿想当然
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过辨别开环与闭环传函零点极点及特征方程表述（第3问）
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

相平面法 非线性系统
本卷考法
  • 判断线性系统不可能出现的相轨迹类型（第4问）
本卷实例
  • 关键一步：由线性二阶系统奇点类型排除非线性特有的极限环
  • 中间结果：极限环只出现在非线性系统，线性系统不可能出现
  • 卡点：中心点与稳定焦点属线性系统可有的奇点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过判断线性系统不可能出现的相轨迹类型（第4问）
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

二1二1、二阶系统参数、静态误差与组合输入稳态误差20 分#

思路
  • 由结构图化简得闭环特征方程，求阻尼比、自然频率与参数关系；再按型别求三个静态误差系数，最后把组合输入分解后求总静态误差。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由结构图闭环特征式求阻尼比与自然频率的关系（第(1)问）
本卷实例
  • 关键一步：先化简结构图得闭环特征方程再对照标准二阶形式
  • 中间结果：阻尼比与自然频率由回路参数组合表达
  • 卡点：结构以图给出，前向与反馈通道接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由结构图闭环特征式求阻尼比与自然频率的关系（第(1)问）
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

劳斯判据 稳定性分析
本卷考法
  • 由劳斯判据给出系统稳定时参数应满足的条件（第(1)问）
本卷实例
  • 关键一步：对闭环特征方程列劳斯表并令首列全正
  • 中间结果：参数不等式由首列各元素大于零联立给出
  • 卡点：参数含负号时要特别注意不等式方向
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由劳斯判据给出系统稳定时参数应满足的条件（第(1)问）
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求组合输入信号下系统的静态误差（第(3)问）
本卷实例

二2二2、闭环稳定范围与根轨迹重实根条件15 分#

思路
  • 对含参结构图先由劳斯判据求闭环稳定时增益范围，再画以增益为参变量的根轨迹，并用分离点条件求特征根为重实根时的取值。
参数稳定域的确定 稳定性分析
本卷考法
  • 用劳斯判据求闭环稳定时的参数取值范围（第(1)问）
本卷实例
  • 关键一步：列劳斯表并由首列全正联立参数不等式
  • 中间结果：稳定域由多个不等式取交集给出
  • 卡点：端点是否包含要看不等式是否严格
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过用劳斯判据求闭环稳定时的参数取值范围（第(1)问）
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制以增益为参变量的根轨迹草图（第(2)问）
本卷实例
  • 关键一步：由开环零极点定分支数、渐近线与实轴段
  • 中间结果：根轨迹分支数等于开环极点个数
  • 卡点：结构以图给出，开环零极点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制以增益为参变量的根轨迹草图（第(2)问）
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

分离点与会合点 根轨迹法
本卷考法
  • 求特征根为重实根时的参数取值（第(2)问）
本卷实例
  • 关键一步：重实根对应根轨迹的分离点或会合点
  • 中间结果：分离点处特征方程有二重实根
  • 卡点：分离点方程的解要筛掉不在根轨迹上的
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求特征根为重实根时的参数取值（第(2)问）
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

二3二3、由正弦稳态输出反求闭环传函15 分#

思路
  • 已知开环传函形式与正弦输入下的稳态输出，用输出输入的幅值比与相角差定出开环参数，再按单位反馈关系写出闭环传函与闭环输出。
频率特性的物理意义与求法 频域分析
本卷考法
  • 由正弦稳态输出求闭环频率特性的幅值与相角（第3题）
本卷实例
  • 关键一步：把输入与输出写成同一频率的正弦量并比较幅值与相角
  • 中间结果：幅值比给出闭环幅频，相角差给出闭环相频
  • 卡点：须用闭环传函而非开环传函求稳态输出
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
