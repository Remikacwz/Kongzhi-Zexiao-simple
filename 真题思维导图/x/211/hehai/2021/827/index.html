1一、复阻抗分压求电路网络传递函数#

思路
  • 对含电阻电感电容的网络用复阻抗分压写出输出与输入之比，再把结果整理成标准有理分式。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 用复阻抗分压法求阻容网络输出电压对输入电压的传函
本卷实例
  • 关键一步：把电容写成复阻抗，先化简并联支路再按分压写出输出
  • 关键一步：把分压结果整理成含一个二阶分母与一阶分子的标准分式
  • 中间结果：分母与分子的一次项系数由电阻电容组合共同决定
  • 卡点：元件串并联接法与取样端口以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过用复阻抗分压法求阻容网络输出电压对输入电压的传函
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过电容的复阻抗不要写成Cs，应写成1/(sC)
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

2二、梅森公式求信号流图传递函数#

思路
  • 用梅森增益公式，先列全部回路与互不接触回路写特征式，再分别列两条前向通路及其余子式。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求信号流图两对节点间的传递函数
本卷实例
  • 关键一步：先找出全部独立回路以及两两互不接触的回路组合
  • 关键一步：两条前向通路的余子式分别只含与之不接触的回路
  • 中间结果：特征式由各回路增益之和再补上互不接触回路的乘积构成
  • 卡点：信号流图以图给出，回路接触关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求信号流图两对节点间的传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

3三、由闭环特征方程判振荡稳定与单调收敛#

思路
  • 写出闭环特征方程并与标准二阶形式对照，求出阻尼比随增益的变化，再按响应类型反解增益范围。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征方程求阻尼比表达式并判断振荡与单调范围
本卷实例
  • 关键一步：与标准二阶形式对照，用系数比写出阻尼比与自然频率
  • 关键一步：把响应类型归结为阻尼比与一的大小关系，再反解增益
  • 中间结果：振荡稳定要求阻尼比在零与一之间，单调收敛要求阻尼比不小于一
  • 卡点：源文只印了振荡一问，单调收敛一问须据同年宝典补出
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征方程求阻尼比表达式并判断振荡与单调范围
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

4四、相平面法求奇点类型与相轨迹#

思路
  • 令速度与加速度为零解出奇点，在奇点处线性化，由特征根判断类型并据此画相轨迹。
相平面法 非线性系统
本卷考法
  • 由非线性微分方程求奇点并在奇点处线性化判类型
本卷实例
  • 关键一步：令速度与加速度为零解出奇点，再在奇点处作小偏差线性化
  • 关键一步：由线性化系统的特征根实部符号判断奇点类型
  • 中间结果：特征根为共轭复根且实部为正时对应不稳定焦点，实根异号时对应鞍点
  • 卡点：相轨迹草图需按奇点类型分区绘制，不能只标出奇点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过由非线性微分方程求奇点并在奇点处线性化判类型
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆
公式

5五、最大相角裕度及其对应增益与Bode图#

思路
  • 用极值法求最大相角裕度及其对应频率，再按该频率绘制开环渐近幅频曲线。
稳定裕度 频域分析
本卷考法
  • 求使相角裕度最大的截止频率及对应的开环增益
本卷实例
  • 关键一步：写出相角裕度关于频率的表达式并对频率求极值
  • 关键一步：令相角裕度对频率的导数为零可得最大裕度处的频率
  • 中间结果：最大裕度处的增益由幅值条件在该频率处等于一定出
  • 卡点：增益由幅值条件定出，不要把最大裕度当成增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求使相角裕度最大的截止频率及对应的开环增益
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 按转折频率逐段绘制开环渐近对数幅频特性曲线
本卷实例
  • 关键一步：先按积分环节个数与增益定低频段渐近线的高度与斜率
  • 关键一步：各转折频率处按一阶微分或惯性环节累加斜率变化
  • 中间结果：低频段延长线过某一分贝值，转折频率由时间常数取倒数得到
  • 卡点：低频段延长线交点与截止频率的读法容易混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过按转折频率逐段绘制开环渐近对数幅频特性曲线
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

6六、劳斯判据、根轨迹与稳态误差和正弦稳态误差#

思路
  • 由开环传函写特征方程用劳斯判据定稳定域，再处理根轨迹、阶跃与正弦稳态误差。
劳斯判据 稳定性分析
本卷考法
  • 列劳斯表求系统稳定的增益范围与临界振荡参数
本卷实例
  • 关键一步：由开环传函写出闭环特征方程，按降幂排好系数列劳斯表
  • 关键一步：令劳斯表首列各元素同号即可得稳定的增益区间
  • 中间结果：使首列某元素为零的增益对应临界稳定，可代回辅助方程求振荡频率
  • 卡点：首列出现零元素对应临界稳定，不要直接判为不稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过列劳斯表求系统稳定的增益范围与临界振荡参数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画根轨迹并求渐近线与分离点
本卷实例
  • 关键一步：标出开环零点极点，判断实轴上哪些区段属于根轨迹
  • 关键一步：计算渐近线交点与夹角，再由分离点方程求分离点
  • 中间结果：渐近线交点由极点之和减零点之和再除以两者条数之差
  • 卡点：算出分离点后要检验是否落在根轨迹上再取用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画根轨迹并求渐近线与分离点
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位阶跃下的误差上限反求开环增益的允许下限
本卷实例
  • 关键一步：先判稳，再把误差要求写成对开环增益的一次不等式
  • 关键一步：把误差条件与稳定条件放在同一增益区间里取交集
  • 中间结果：阶跃误差与开环增益成反比，要求越小则增益下限越高
  • 卡点：误差条件与稳定条件是两条独立约束，缺一不可
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位阶跃下的误差上限反求开环增益的允许下限
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求正弦输入下稳态误差的幅值与相位
本卷实例
  • 关键一步：把 s 换成 jω 求误差传递函数的幅频与相频特性
  • 关键一步：代入输入正弦的角频率读出幅值比与相位差
  • 中间结果：稳态误差仍是同频率正弦量，幅值与相位由误差频率特性定
  • 卡点：代入频率时要与输入正弦的角频率一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求正弦输入下稳态误差的幅值与相位
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

7七、采样系统开环脉冲传函与斜坡稳态误差#

思路
  • 对连续部分整体做 z 变换求开环脉冲传函，再判稳并用终值定理证明斜坡误差。
脉冲传递函数 离散控制系统
本卷考法
  • 含零阶保持器的采样系统求开环脉冲传递函数
本卷实例
  • 关键一步：对连续部分整体做 z 变换，注意保持器与各环节的采样位置
  • 关键一步：把部分分式展开后逐项查 z 变换表再合并
  • 中间结果：开环脉冲传函分母的 z 多项式阶次由连续部分阶数定
  • 卡点：采样开关与保持器位置以图给出，需回原卷核对图
  • 卡点：零阶保持器要与连续部分一起做变换，不能单独拆开
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过含零阶保持器的采样系统求开环脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)
公式
离散系统的稳态误差 离散控制系统
本卷考法
  • 用终值定理证明斜坡输入下稳态误差等于增益倒数
本卷实例
  • 关键一步：先由闭环特征根判稳，再对误差脉冲传函用终值定理
  • 关键一步：把开环脉冲传函在一处的取值代入误差公式
  • 中间结果：斜坡误差与开环脉冲传函在一处的极点重数有关
  • 卡点：未判稳就使用终值定理会得到无意义的稳态值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差由输入类型与开环脉冲传函中 z=1 处极点的个数决定
  • 型别由 G(z)H(z) 中 z=1 处极点的重数确定
  • 用终值定理求稳态误差，前提是系统稳定
  • 采样周期也影响稳态误差大小
步骤
  • 求误差脉冲传递函数
  • 数出 z=1 处极点重数确定型别
  • 查表或用终值定理求稳态误差
  • 分析采样周期变化对误差的影响
通用考法
  • 本卷考过用终值定理证明斜坡输入下稳态误差等于增益倒数
  • 求离散系统在典型输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 分析采样周期对稳态精度的影响
常见易错
  • 直接用 s 域静态误差系数公式处理离散系统
  • 未判稳就用终值定理

8八、描述函数法判自激振荡与振荡频率#

思路
  • 把并联比例环节并入描述函数，画两轨迹找交点，由交点求自激振荡频率与参数关系。
描述函数法基础 非线性系统
本卷考法
  • 把并联比例环节并入描述函数求等效非线性特性
本卷实例
  • 关键一步：按描述函数定义把并联环节的描述函数相加
  • 关键一步：等效后取负倒数并分析随振幅变化的走向
  • 中间结果：等效负倒描述函数随振幅的移动方向由其对振幅的求导符号定
  • 卡点：描述函数只是振幅的函数，写成频率的函数会判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过把并联比例环节并入描述函数求等效非线性特性
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件
公式
用描述函数法分析自振 非线性系统
本卷考法
  • 由两轨迹交点判断自激振荡并求振荡频率
本卷实例
  • 关键一步：求线性部分相位为负一百八十度处的频率与该处幅值
  • 关键一步：比较交点位置判断是否存在自激振荡及其稳定性
  • 中间结果：两轨迹相交时交点频率与振幅对应自振参数
  • 卡点：非线性环节组态以图给出，需回原卷核对图
  • 卡点：不标振幅增大方向容易把稳定自振判反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过由两轨迹交点判断自激振荡并求振荡频率
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率
