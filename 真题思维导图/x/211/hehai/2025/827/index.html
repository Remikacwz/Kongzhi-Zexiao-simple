1一、电路网络求传递函数与渐近幅频特性#

思路
  • 对含电阻与电容的电路用复阻抗分压写出 Uo(s)/Ui(s)，整理成典型环节乘积后，再逐段确定转折频率与斜率变化，画出渐近对数幅频特性曲线。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 用复阻抗分压法求阻容网络的传递函数
本卷实例
  • 关键一步：把电容写成复阻抗，先化简混联支路得到分压关系
  • 关键一步：把分压结果整理成含一阶因子的标准有理分式
  • 中间结果：传递函数可整理成低频增益与两个转折频率的形式
  • 卡点：图1为原卷插图，元件串并联接法与取样端口需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过用复阻抗分压法求阻容网络的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 由传递函数逐段绘制渐近对数幅频特性曲线
本卷实例
  • 关键一步：把传函分解为典型环节乘积，先定最低频段渐近线
  • 关键一步：按转折频率从小到大逐段改变渐近线斜率
  • 中间结果：画图前要先确定低频段高度与各转折频率在频率轴上的次序
  • 卡点：转折频率相互大小与每段斜率变化量需回原卷配图核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过由传递函数逐段绘制渐近对数幅频特性曲线
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec

2二、稳态误差与劳斯判据求增益范围#

思路
  • 先由闭环特征方程列劳斯表得到稳定增益范围与等幅振荡的临界增益，再由静态位置误差系数写出稳态误差与增益的关系式，最后判断误差要求与稳定条件能否同时成立。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据定稳定域并求等幅振荡参数
本卷实例
  • 关键一步：写出闭环特征方程并整理成四次多项式降幂排列
  • 关键一步：列劳斯表，令首列各元素同号得到稳定域
  • 中间结果：使首列某元素为零的增益对应临界稳定，可代回辅助方程求振荡频率
  • 卡点：等幅振荡对应首列恰为零的临界增益，不要与稳定域的普通取值混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据定稳定域并求等幅振荡参数
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 判定系统型别并求静态位置误差系数
本卷实例
  • 关键一步：数出开环传函中积分环节的个数为零，判为零型系统
  • 关键一步：令 s 趋于零求静态位置误差系数
  • 中间结果：静态位置误差系数等于开环增益除以各时间常数之积
  • 卡点：误差条件给出的增益下界与稳定域可能没有公共区间
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判定系统型别并求静态位置误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由阶跃输入下的误差上界反求开环增益
本卷实例
  • 关键一步：写出单位阶跃下稳态误差与位置误差系数的关系式
  • 关键一步：把误差上界代入后解出关于增益的不等式
  • 中间结果：误差要求等价为对开环增益的一个下界约束
  • 卡点：必须把误差条件与稳定条件放在同一个增益区间里取交集
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由阶跃输入下的误差上界反求开环增益
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、根轨迹绘制与稳定增益范围#

思路
  • 由开环极点在实轴上的分布按绘制法则作根轨迹，求出与虚轴的交点即临界增益，从而写出使系统稳定的开环增益范围。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画出三阶无零点系统的根轨迹
本卷实例
  • 关键一步：标出全部开环极点并判断实轴上的根轨迹段走向
  • 关键一步：计算渐近线交点、夹角与实轴上的分离点
  • 中间结果：根轨迹分支数等于开环极点数，三条分支关于实轴对称
  • 卡点：重极点附近的分离点需由幅值条件反求对应的增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画出三阶无零点系统的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点对应的临界增益
本卷实例
  • 关键一步：令 s 等于 jω 代入闭环特征方程
  • 关键一步：分别令实部与虚部为零解出频率与临界增益
  • 中间结果：交点频率由虚部方程给出，临界增益由实部方程给出
  • 卡点：穿越方向决定稳定区间取交点左侧还是右侧，需结合实轴段判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点对应的临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式

4四、由渐近幅频特性反求开环传函#

思路
  • 由低频段斜率确定系统型别、由低频段高度确定开环增益，再按各转折频率处的斜率变化识别零极点，写出最小相位开环传递函数。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由渐近对数幅频特性曲线反求最小相位传函
本卷实例
  • 关键一步：读最低频段斜率定系统型别，读低频段高度定开环增益
  • 关键一步：按转折频率处斜率变化量识别惯性或一阶微分环节
  • 中间结果：各转折频率与斜率变化量共同确定零极点的个数和位置
  • 卡点：图2为原卷插图，低频段高度与四个转折频率数值需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由渐近对数幅频特性曲线反求最小相位传函
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
典型环节的对数频率特性 频域分析
本卷考法
  • 由渐近线特征识别典型环节并写频率特性
本卷实例
  • 关键一步：对照典型环节的渐近线斜率判断环节类型
  • 关键一步：由转折频率写出对应环节的时间常数
  • 中间结果：最小相位系统的幅频特性与零极点位置一一对应
  • 卡点：两个惯性环节与一个振荡环节的渐近线形状相近，需按曲线细节区分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例环节是水平线，积分与微分分别是 -20 与 +20 dB/dec 的斜线
  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec
  • 一阶微分环节与惯性环节幅频互为镜像
  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤
  • 把传递函数分解为典型环节乘积
  • 逐环节画出对数幅频渐近线与相频曲线
  • 代数相加得到总特性
通用考法
  • 本卷考过由渐近线特征识别典型环节并写频率特性
  • 画出某一典型环节的 Bode 图
  • 由 Bode 图识别环节类型
  • 说明转角频率处的幅值与相角
常见易错
  • 把惯性环节高频渐近线的 -20 写成 -40
  • 振荡环节谐振峰位置误当作 ωn

5五、采样系统脉冲传函、稳定性与稳态误差#

思路
  • 按采样开关与保持器位置求闭环脉冲传递函数，解特征方程判断稳定性，最后按阶跃、斜坡、加速度三个输入分量用终值定理求稳态误差并叠加。
脉冲传递函数 离散控制系统
本卷考法
  • 按采样结构求闭环脉冲传递函数
本卷实例
  • 关键一步：对含零阶保持器的连续部分整体做 z 变换，串联环节不能直接相乘
  • 关键一步：按反馈结构写出闭环脉冲传递函数
  • 中间结果：闭环脉冲传函的分母由各回路脉冲传函的组合构成
  • 卡点：图3为原卷插图，采样开关、保持器与局部反馈的接入点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过按采样结构求闭环脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)
公式
离散系统稳定性分析 离散控制系统
本卷考法
  • 由闭环特征根判断采样系统的稳定性
本卷实例

思路

描述函数法基础 非线性系统
本卷考法

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数

  • 忽略一次谐波近似带来的误差条件
