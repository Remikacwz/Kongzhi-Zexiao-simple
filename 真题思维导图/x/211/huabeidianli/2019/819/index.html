1一、方框图建模与稳态误差分析#

思路
  • 由闭环阶跃响应反求前向通道，求静态误差系数与稳态误差，再用劳斯判据判稳
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应反求系统的传递函数
本卷实例
  • 关键一步：把响应拉氏变换与单位阶跃传函对应比较
  • 中间结果：由响应极点与稳态值定前向通道传函
  • 卡点：未判断系统阶数就套用二阶公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应反求系统的传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 求位置、速度与加速度误差系数
本卷实例
  • 关键一步：按系统型别分别取开环传函的对应极限
  • 中间结果：型别决定各误差系数是否有限
  • 卡点：把开环增益与速度误差系数混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过求位置、速度与加速度误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位阶跃输入下系统的稳态误差
本卷实例
  • 关键一步：由误差传函与输入形式取极限求误差
  • 中间结果：型别足够时阶跃输入下的误差为零
  • 卡点：未判稳就使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位阶跃输入下系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯稳定判据判断闭环系统的稳定性
本卷实例
  • 关键一步：列劳斯表并检查首列的符号变化次数
  • 中间结果：首列出现负号则闭环系统不稳定
  • 卡点：特征多项式系数缺项时未补零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯稳定判据判断闭环系统的稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式

2二、根轨迹绘制与附加环节影响#

思路
  • 画根轨迹求单调收敛的增益范围，证明圆特性，再加积分或微分环节重画
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制含一个零点两个极点的根轨迹草图
本卷实例
  • 关键一步：由零极点分布定实轴段与分离点位置
  • 中间结果：分支数与终点由零极点个数差决定
  • 卡点：渐近线夹角公式中把2k加1写成2k
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制含一个零点两个极点的根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 求输出单调收敛对应的增益取值范围
本卷实例
  • 关键一步：找使全部闭环极点为实数的增益区间
  • 中间结果：单调收敛要求不存在共轭复数极点
  • 卡点：把临界稳定点当成单调收敛的边界
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过求输出单调收敛对应的增益取值范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
分离点与会合点 根轨迹法
本卷考法
  • 证明复平面上的部分根轨迹为圆
本卷实例
  • 关键一步：由相角条件消去得到圆的方程
  • 中间结果：圆上满足相角条件的点落在根轨迹上
  • 卡点：求出方程后未筛去不在根轨迹上的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过证明复平面上的部分根轨迹为圆
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 分析串联积分或微分环节后的根轨迹变化
本卷实例
  • 关键一步：把新环节并入开环后重定零极点分布
  • 中间结果：积分环节右移渐近线、微分环节左移
  • 卡点：把附加零点与附加极点的影响搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过分析串联积分或微分环节后的根轨迹变化
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反

3三、方框图传函与扰动补偿#

思路
  • 由结构图求传函，分析扰动不变性条件与通过补偿改善稳定性的可能性
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 化简含局部反馈与补偿环节的多回路结构图
本卷实例
  • 关键一步：由内到外逐层化简求出系统总传函
  • 中间结果：总传函由前向通路与反馈通路共同决定
  • 卡点：化简内环时把外环的信号当常数处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过化简含局部反馈与补偿环节的多回路结构图
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
减小稳态误差的措施 稳态误差
本卷考法
  • 分析能否通过补偿使扰动对输出不产生影响
本卷实例
  • 关键一步：令扰动到输出的传函分子为零反解补偿器
  • 中间结果：条件由扰动作用点前后环节的比值确定
  • 卡点：把消扰动条件与消给定误差条件混谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过分析能否通过补偿使扰动对输出不产生影响
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 分析闭环不稳定时能否通过补偿使其稳定
本卷实例
  • 关键一步：把补偿器并入闭环特征方程看极点位置
  • 中间结果：稳定性由闭环极点是否全在左半平面决定
  • 卡点：只调整增益而不检查闭环的极点分布
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过分析闭环不稳定时能否通过补偿使其稳定
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式

4四、Bode反求与稳定裕度及稳态误差#

思路
  • 由对数幅频曲线反求传函，算剪切频率与相角裕量，再求组合输入的稳态误差
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由最小相位系统对数幅频曲线反求传函
本卷实例
  • 关键一步：由各段斜率变化识别对应的典型环节
  • 中间结果：低频段的高度确定系统的开环增益
  • 卡点：把延长线的交点误当作增益未折算型别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由最小相位系统对数幅频曲线反求传函
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制系统的开环对数相频特性曲线
本卷实例
  • 关键一步：由各环节相角叠加画出相频曲线
  • 中间结果：相频曲线在转折频率处发生折转
  • 卡点：相角累加时漏掉积分环节的负90度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB

8八、传递函数矩阵与标准型实现#

思路
  • 由双输入双输出结构图求传函矩阵，再写能控与能观标准型实现
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 求双输入双输出系统的传递函数矩阵
本卷实例
  • 关键一步：分别把其余输入置零求各通道的传函
  • 中间结果：传函矩阵各元分母相同而分子不同
  • 卡点：漏掉输入输出通道的排列顺序
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过求双输入双输出系统的传递函数矩阵
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消
公式
由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 由传递函数矩阵写四维能控标准型与能观标准型
本卷实例
  • 关键一步：按最小公分母分离直接项后填友矩阵
  • 中间结果：能控标准型为块友矩阵形式、能观为其对偶
  • 卡点：友矩阵系数符号与分块顺序易错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法
  • 本卷考过由传递函数矩阵写四维能控标准型与能观标准型
  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反
