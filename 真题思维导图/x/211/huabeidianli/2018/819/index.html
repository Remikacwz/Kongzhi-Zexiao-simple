1一、方框图判稳与扰动误差补偿#

思路
  • 由方框图求各通道传函，判稳后用终值定理求给定与扰动稳态误差，再定前馈补偿器
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求给定输入与扰动分别作用下的闭环传递函数
本卷实例
  • 关键一步：分别把另一输入置零后再按结构图化简
  • 中间结果：两条通道传函分母相同、分子不同
  • 卡点：方框图以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求给定输入与扰动分别作用下的闭环传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
劳斯判据 稳定性分析
本卷考法
  • 判断该控制系统的稳定性
本卷实例
  • 关键一步：求闭环特征方程后再列劳斯表
  • 中间结果：首列元素符号决定系统是否稳定
  • 卡点：特征多项式有缺项时未补零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过判断该控制系统的稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求阶跃输入3乘1(t)作用下的稳态误差
本卷实例
  • 关键一步：先判稳再把输入代入误差传函取终值
  • 中间结果：误差传函由给定与反馈通路共同决定
  • 卡点：未判稳就套用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求阶跃输入3乘1(t)作用下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动2t乘1(t)作用下的稳态误差
本卷实例
  • 关键一步：把扰动作用点当输入、给定置零求误差传函
  • 中间结果：扰动误差由误差传函的零极点分布确定
  • 卡点：求扰动传函时没有把给定置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求扰动2t乘1(t)作用下的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 设计前馈补偿器使扰动引起的稳态误差恒为零
本卷实例
  • 关键一步：令扰动到误差的传函恒为零反解补偿器
  • 中间结果：补偿器由扰动作用点前后的环节比值确定
  • 卡点：把消扰动条件与消给定误差条件混谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计前馈补偿器使扰动引起的稳态误差恒为零
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

2二、Bode反求与奈氏判稳及根轨迹#

思路
  • 由Bode图低频段与转折频率反求开环传函，用奈氏判据判稳，再画参数根轨迹复核
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频与相频曲线反求开环传递函数
本卷实例
  • 关键一步：由低频斜率定型别、由转折频率定位环节
  • 中间结果：开环含两个积分环节与一个右半平面一阶环节
  • 卡点：非最小相位环节的相角方向易写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频与相频曲线反求开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据分析闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数再数包围圈数
  • 中间结果：由开环右半平面极点数算闭环右半平面极点数
  • 卡点：积分环节未补画无穷大半径圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据分析闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制增益从零到正无穷变化的根轨迹草图
本卷实例
  • 关键一步：由开环零极点定实轴段、渐近线与出射角
  • 中间结果：分支数与终点由零极点个数差决定
  • 卡点：实轴段判据中的零极点个数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制增益从零到正无穷变化的根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

3三、参数根轨迹与稳定域#

思路
  • 把参数提到分子化为等效开环，画参数根轨迹求稳定域与单调衰减区间
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以参数a为变量绘制广义根轨迹
本卷实例
  • 关键一步：把特征方程整理成参数a在分子的一次式
  • 中间结果：等效开环的零极点由整理后表达式给出
  • 卡点：整理时未把参数完整提到分子
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以参数a为变量绘制广义根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点求稳定的临界参数
本卷实例
  • 关键一步：令闭环特征方程代入s=jw分离实虚部
  • 中间结果：临界参数由实部与虚部两组方程联立解出
  • 卡点：只代一个w就下结论，漏掉另一组解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹与虚轴交点求稳定的临界参数
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 求输出单调衰减与特征根实部受限对应的参数区间
本卷实例
  • 关键一步：把实轴条件与距虚轴条件写成不等式
  • 中间结果：各条件取交集给出参数的取值区间
  • 卡点：把复根出现当成单调衰减的边界
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过求输出单调衰减与特征根实部受限对应的参数区间
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 确定使闭环稳定的参数取值范围
本卷实例
  • 关键一步：用劳斯判据列首列不等式后取交集
  • 中间结果：稳定域上界由临界参数确定
  • 卡点：取交集时把端点是否包含搞错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过确定使闭环稳定的参数取值范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

4四、Bode反求与稳定裕度#

思路
  • 由最小相位系统对数幅频曲线反求传函，再算剪切频率与相角裕量
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由最小相位系统对数幅频曲线求开环传函
本卷实例
  • 关键一步：由各段斜率变化识别对应的一阶与积分环节
  • 中间结果：低频段高度确定开环增益
