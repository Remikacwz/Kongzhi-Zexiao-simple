1一、电路建模与二阶响应#

思路
  • 由电路列微分方程求传递函数并化为二阶标准形，读出阻尼比与自然频率，再求正弦输入下的稳态输出。
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由电路结构列微分方程组并求输入输出传递函数
本卷实例
  • 关键一步：用基尔霍夫定律与元件伏安关系列微分方程组
  • 关键一步：消去中间变量得输入输出传函
  • 中间结果：传函分母含电感电容决定的二阶项
  • 卡点：源文元件参数与欠阻尼提示矛盾，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由电路结构列微分方程组并求输入输出传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
由电路或机械系统求传递函数 传递函数
本卷考法

本卷实例

  • 中间结果：传函为标准二阶有理式
  • 卡点：各元件参数代入顺序易错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过把电路微分方程组整理为标准传递函数形式
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传递函数化为标准二阶形式读出阻尼比与自然频率
本卷实例
  • 关键一步：把分母 s 平方项系数归一化
  • 关键一步：与标准式逐项对应
  • 中间结果：自然频率由常数项开方得到，阻尼比由一次项得到
  • 卡点：源文阻尼比与欠阻尼提示不符，属数据矛盾
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传递函数化为标准二阶形式读出阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

频率特性的物理意义与求法 频域分析

本卷实例

  • 关键一步：按幅值比与相角差写稳态输出
  • 中间结果：稳态输出为同频正弦，幅值与相位由频率特性决定

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示

  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求闭环频率特性表达式及正弦输入下的稳态输出
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

2二、方框图与扰动抑制条件#

思路
  • 由方框图求误差传函与开环传函，令扰动通道输出传函为零求抑制扰动应满足的条件。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式写多回路系统的误差与开环传递函数
本卷实例
  • 关键一步：枚举全部回路并判断接触关系
  • 关键一步：列特征式与前向通路余子式
  • 中间结果：误差传函分子为不接触部分的组合
  • 卡点：源图回路增益OCR有误，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式写多回路系统的误差与开环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式

  • 卡点：求扰动误差时须把参考输入置零

  • 由结构图写出误差传递函数

通用考法
  • 本卷考过分别写出给定输入与扰动作用下的误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)

奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据判断闭环系统的稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数 P
  • 关键一步：再看曲线包围临界点的情况定 Z
  • 中间结果：不包围临界点时闭环稳定
  • 卡点：包围圈数正负号的定义易搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据判断闭环系统的稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求给定复合输入下的稳态误差
本卷实例

  • 中间结果：输入含阶跃与斜坡分量，须分别求误差分量
  • 卡点：组合信号漏掉某一分量会少算误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法

  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

通用考法

  • 求扰动引起的稳态误差

根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制增益变化时闭环系统的根轨迹
本卷实例
  • 关键一步：由零极点定实轴区间、渐近线与分离点
  • 中间结果：三条根轨迹全部终止于无穷远
  • 卡点：与虚轴交点须先算，图需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制增益变化时闭环系统的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹

8八、状态空间稳定性与反馈极点配置#

思路
  • 求系统平衡点并用李雅普诺夫第一法判稳，再设计状态反馈配置极点，求反馈后传函并比较能控能观性变化。
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 求平衡点并用李雅普诺夫第一法判断稳定性
本卷实例
  • 关键一步：令状态导数为零求平衡点
  • 关键一步：求状态矩阵特征值并看实部符号
  • 中间结果：三个特征值均具负实部，平衡点渐近稳定
  • 卡点：第一法判局部稳定性，非线性时不能直接外推
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定

  • 据此得出稳定性结论
