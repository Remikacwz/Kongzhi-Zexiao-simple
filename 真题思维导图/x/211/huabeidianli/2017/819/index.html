1一、方框图传函与扰动消除#

思路
  • 由方框图求各通道传递函数，再令扰动到输出的传函为零求补偿器Gc
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求参考输入与扰动分别作用下的传递函数
本卷实例
  • 关键一步：分别把另一输入置零后用梅森公式
  • 中间结果：两通道分母相同而分子不同
  • 卡点：扰动通道要把扰动作用点当作输入源
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求参考输入与扰动分别作用下的传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 写误差传函并分析扰动对误差的影响
本卷实例
  • 关键一步：按误差等于给定减反馈列写表达式
  • 中间结果：误差传函由前向与反馈通路共同决定
  • 卡点：非单位反馈时误差定义取错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写误差传函并分析扰动对误差的影响
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 求消除扰动对输出影响的补偿器传递函数
本卷实例
  • 关键一步：令扰动到输出的传函分子为零反解Gc
  • 中间结果：补偿器与扰动作用点前的环节成反比
  • 卡点：把消扰动条件与消误差条件混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过求消除扰动对输出影响的补偿器传递函数
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

2二、根轨迹与劳斯稳定域#

思路
  • 画根轨迹草图求稳定增益，用劳斯判据定单调衰减范围，再分析附加零点对稳定的影响
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制含共轭复数极点的根轨迹草图
本卷实例
  • 关键一步：先定零极点分布再画渐近线与出射角
  • 中间结果：三条分支均终止于无穷远处
  • 卡点：复数极点的出射角未按相角条件算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制含共轭复数极点的根轨迹草图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求系统稳定的增益范围
本卷实例
  • 关键一步：列劳斯表并令首列元素全部为正
  • 中间结果：稳定域由两个不等式取交集
  • 卡点：缺项时未补零直接列劳斯表
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求系统稳定的增益范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹分析阶跃响应单调衰减对应的增益
本卷实例
  • 关键一步：找使全部闭环极点为实数的增益上界
  • 中间结果：单调衰减要求不存在共轭复根
  • 卡点：把临界稳定点当成单调衰减的边界
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹分析阶跃响应单调衰减对应的增益
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 分析附加开环零点对根轨迹与稳定性的影响
本卷实例
  • 关键一步：把附加零点并入开环后重列特征方程
  • 中间结果：零点使根轨迹左移并改变稳定域
  • 卡点：只看渐近线移动而忽略分离点变化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过分析附加开环零点对根轨迹与稳定性的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反

3三、参数根轨迹与积分环节作用#

思路
  • 由闭环特征方程求参数T稳定域，画以T为参数的根轨迹，再分析串联积分环节的影响
参数稳定域的确定 稳定性分析
本卷考法
  • 求系统稳定、临界与不稳定对应的参数T范围
本卷实例
  • 关键一步：由特征方程列劳斯表写出T的不等式
  • 中间结果：首列变号的边界给出临界T值
  • 卡点：把临界稳定误判为稳定区间内部
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求系统稳定、临界与不稳定对应的参数T范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以时间常数T为参数绘制系统的根轨迹草图
本卷实例
  • 关键一步：把特征方程整理成参数T在分子的形式
  • 中间结果：等效开环的零点与极点由整理结果给出
  • 卡点：整理时未把参数完整提到分子
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以时间常数T为参数绘制系统的根轨迹草图
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

4四、描述函数法分析周期运动#

思路
  • 由非线性环节求负倒描述函数范围，与线性部分幅相曲线比较，求稳定范围与周期运动参数
描述函数法基础 非线性系统
本卷考法
  • 求非线性环节的负倒描述函数及其取值范围
本卷实例
  • 关键一步：把描述函数取负倒数并分析其单调性
  • 中间结果：负倒描述函数落在负实轴的一段区间
  • 卡点：把描述函数当作频率的函数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过求非线性环节的负倒描述函数及其取值范围
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件
公式
用描述函数法分析自振 非线性系统
本卷考法
  • 由负倒描述函数与线性部分交点判断自振
本卷实例
  • 关键一步：令两曲线相交并核对相角条件
  • 中间结果：交点频率与振幅即为周期运动参数
  • 卡点：未标振幅增大方向无法判断自振稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过由负倒描述函数与线性部分交点判断自振
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率
公式
非线性系统的特点 非线性系统
本卷考法
  • 说明增益变化对非线性系统稳定性的影响
本卷实例

  • 求带全维观测器的闭环系统传递函数
本卷实例
  • 关键一步：把观测器状态与原系统状态联立成增广方程
  • 中间结果：传函的零点与极点会出现对消
  • 卡点：把观测器极点与传函极点关系混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过求带全维观测器的闭环系统传递函数
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 判断带观测器闭环系统的外部稳定性
本卷实例
  • 关键一步：由传函剩余极点的实部判断BIBO稳定
  • 中间结果：存在零极点对消时以剩余极点判稳
  • 卡点：把外部稳定等同于全部极点稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过判断带观测器闭环系统的外部稳定性
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数
