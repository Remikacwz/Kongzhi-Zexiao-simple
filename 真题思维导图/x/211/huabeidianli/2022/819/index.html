难度：中等　全卷九题，经典控制七题加现代控制两题。覆盖方框图与扰动无差、根轨迹与时域指标、采样系统差分方程、描述函数自振、Bode反求与奈奎斯特判稳、能控标准型与状态反馈、李雅普诺夫判据、机械减震系统建模与状态转移矩阵、状态空间稳定性与观测器。卷面逐题印分值。

1一、方框图与扰动无差条件#

思路
  • 对多回路方框图分别求开环、闭环与误差传递函数，再令扰动通道误差为零求补偿条件。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由多回路方框图求开环传递函数 B(s)/E(s)
本卷实例
  • 关键一步：按信号流向辨识各回路与比较点，自内向外逐层化简
  • 关键一步：先断开扰动支路再求主通道开环传函
  • 中间结果：开环传函为前向通路各环节与反馈通道之积
  • 卡点：源图回路编号与比较点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由多回路方框图求开环传递函数 B(s)/E(s)
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别在给定输入或扰动单独作用下求闭环传递函数
本卷实例
  • 关键一步：求某一通道时把另一输入置零，逐条列前向通路
  • 中间结果：两通道共用同一闭环特征式，分子由各自通路决定
  • 卡点：扰动通道未把参考输入置零会多算一条通路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别在给定输入或扰动单独作用下求闭环传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 按误差定义写出输入与扰动下的误差传递函数
本卷实例
  • 关键一步：以给定减反馈定义误差，再分别求两通道误差传函
  • 中间结果：误差传函的分母为闭环特征式
  • 卡点：源文答案段该式OCR错排，需按定义重列
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过按误差定义写出输入与扰动下的误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求使扰动作用下动静态无差的补偿环节条件
本卷实例
  • 关键一步：令扰动通道误差传函恒为零并列方程
  • 关键一步：解出补偿环节应满足的传递函数关系
  • 中间结果：补偿条件由两条前向通路的增益相消给出
  • 卡点：源文把 Gj 与 Gf 混写，符号需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求使扰动作用下动静态无差的补偿环节条件
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

2二、根轨迹与时域指标约束#

思路
  • 由开环传函画根轨迹并用虚轴交点求稳定范围；再由超调量与调节时间两个指标反求增益区间。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按根轨迹法则绘制三阶系统的根轨迹概略图
本卷实例
  • 关键一步：由开环零极点定实轴区间、渐近线与出射角
  • 中间结果：开环含一对共轭复极点，需先算出射角
  • 卡点：共轭极点的出射角易漏负号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按根轨迹法则绘制三阶系统的根轨迹概略图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 令特征方程中 s 取 jω 求虚轴交点与临界增益
本卷实例
  • 关键一步：把 s 等于 jω 代入闭环特征方程
  • 关键一步：实部虚部分别为零后联立求解
  • 中间结果：虚轴交点对应系统稳定的增益上界
  • 卡点：虚轴交点频率与开环自然频率不是同一个量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过令特征方程中 s 取 jω 求虚轴交点与临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹落在左半平面的区段判断稳定参数范围
本卷实例
  • 关键一步：把稳定要求对应到根轨迹位于左半平面的参数区间
  • 中间结果：稳定范围为由零到临界增益的开区间
  • 卡点：原点处根轨迹起点对应的增益边界易写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹落在左半平面的区段判断稳定参数范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量与调节时间双指标反求增益取值范围
本卷实例
  • 关键一步：由超调量条件定阻尼比下限
  • 关键一步：由调节时间下限约束极点实部
  • 中间结果：两不等式在 s 平面上围出一角形可行域
  • 卡点：两个不等号方向易取反，须逐项验证
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量与调节时间双指标反求增益取值范围
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式

3三、采样系统差分方程与稳定范围#

思路
  • 由数字控制器脉冲传函写差分方程；再把保持器与对象合并求脉冲传函，用双线性变换与劳斯判据求稳定增益范围。
数字控制器与最少拍设计 离散控制系统
本卷考法
  • 由数字控制器的 z 传递函数写出其差分方程
本卷实例
  • 关键一步：把 D(z) 化为 z 负幂有理式
  • 关键一步：交叉相乘后逐项作 z 反变换
  • 中间结果：差分方程由输出与输入相邻拍的组合构成
  • 卡点：z 负幂对应延迟拍数，符号易漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最少拍系统指在典型输入下经过有限拍达到无稳态误差
  • 设计需要满足可实现性与稳定性约束
  • 最少拍系统的闭环脉冲传递函数由输入类型确定
  • 最少拍设计通常导致很大的控制量，需加限制
步骤
  • 确定输入类型及对应的误差传函形式
  • 按无稳态误差要求构造闭环脉冲传递函数
  • 由 D(z)=Φ(z)/[G(z)(1-Φ(z))] 求数字控制器
  • 检验可实现性、稳定性与控制量大小
通用考法
  • 本卷考过由数字控制器的 z 传递函数写出其差分方程
  • 设计最少拍数字控制器
  • 比较不同输入类型下的最少拍数
  • 分析最少拍系统存在的问题
常见易错
  • 忽略 D(z) 必须是物理可实现的因果系统
  • 闭环传函构造时未满足稳定性约束条件
公式
脉冲传递函数 离散控制系统
本卷考法
  • 求含零阶保持器的开环与闭环脉冲传递函数
本卷实例
  • 关键一步：把零阶保持器与连续对象合并作 z 变换
  • 关键一步：按单位负反馈写闭环脉冲传函
  • 中间结果：开环脉冲传函在 z 等于一处出现重极点
  • 卡点：控制器比例系数在环内相乘，别漏乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过求含零阶保持器的开环与闭环脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)
公式
离散系统稳定性分析 离散控制系统
本卷考法
  • 用双线性变换与劳斯判据求离散系统稳定增益范围
本卷实例
  • 关键一步：令 z 等于 (w 加一)/(w 减一) 化到 w 域
  • 关键一步：对 w 域多项式列劳斯表
  • 中间结果：稳定条件化为各首列元素同号的一组不等式
  • 卡点：变换后须重新整理成 w 的降幂多项式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过用双线性变换与劳斯判据求离散系统稳定增益范围
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒
公式

4四、描述函数法判断自振荡#

思路
  • 由理想继电特性的负倒描述函数与线性部分频率特性求交点，判断是否存在稳定自振并分析增益对振幅的影响。
描述函数法基础 非线性系统
本卷考法
  • 由非线性描述函数求负倒描述函数及其走向
本卷实例
  • 关键一步：对给定描述函数取负倒数写成随振幅变化的量
  • 中间结果：理想继电特性的负倒描述函数落在负实轴上
  • 卡点：描述函数只随振幅变化，不是频率的函数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
