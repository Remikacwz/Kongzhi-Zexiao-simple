1一、双容水箱液位控制系统#

思路
  • 由双容水箱方框图逐层化简求开环传函与特征方程，再分别令另一输入为零求两通道传函
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由双容水箱液位控制系统方框图逐层化简求开环传函
本卷实例
  • 关键一步：按信号流向找出内外回路与各比较点，自内向外逐层化简
  • 中间结果：开环传函为内回路化简结果与主通道各环节的乘积
  • 卡点：原理图与方框图为原卷插图，信号流向与扰动作用点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由双容水箱液位控制系统方框图逐层化简求开环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求给定输入与扰动输入作用下的闭环传函与误差传函
本卷实例
  • 关键一步：求某一通道传函时把另一输入置零，用梅森公式列前向通路与回路
  • 中间结果：两通道闭环特征式相同，分子由各自输入通路决定
  • 卡点：求扰动通道时未把给定输入置零，误差定义也易取错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求给定输入与扰动输入作用下的闭环传函与误差传函
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 写误差传函并区分给定误差与扰动误差
本卷实例
  • 关键一步：按误差等于给定减反馈写出误差传函
  • 中间结果：误差传函与闭环传函共用同一特征式
  • 卡点：扰动下的误差传函与输出传函相差一个反馈环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写误差传函并区分给定误差与扰动误差
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

2二、单回路系统与超调量约束#

思路
  • 由开环传函写闭环二阶标准形，用超调量与衰减振荡条件求增益范围；再加微分反馈后判断恒稳定性
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函化二阶标准形式读出阻尼比与自然频率
本卷实例
  • 关键一步：把闭环分母配成标准二阶形式，写出阻尼比与自然频率表达式
  • 中间结果：阻尼比与增益的平方根成反比
  • 卡点：分母s平方项系数为10，必须先归一化再读参数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函化二阶标准形式读出阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量小于4.3%与衰减振荡条件确定增益范围
本卷实例
  • 关键一步：由超调量公式得阻尼比下限，再由衰减振荡得阻尼比上限
  • 中间结果：两个不等式联立得增益的开区间
  • 卡点：只写超调量条件会漏掉衰减振荡要求的另一侧边界
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量小于4.3%与衰减振荡条件确定增益范围
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
劳斯判据 稳定性分析
本卷考法
  • 加入微分反馈后判断系统是否恒稳定
本卷实例
  • 关键一步：写出含微分环节的开环传函，用劳斯判据或奈氏判据判稳
  • 中间结果：闭环特征方程各项系数对任意正增益恒同号
  • 卡点：分子微分环节使相频曲线不过负实轴，不能误判为不稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过加入微分反馈后判断系统是否恒稳定
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式

3三、串级系统等效与根轨迹#

思路
  • 先求内回路等效传函，再串成外回路；由分离点与虚轴交点求稳定区间并求阶跃误差
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 求虚线框内回路的等效传递函数
本卷实例
  • 关键一步：按负反馈等效公式写出内回路闭环传函并化到最简
  • 中间结果：内回路等效为一个一阶惯性环节
  • 卡点：内回路反馈通道H2需回原卷核对图，源文该处OCR有掉字
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过求虚线框内回路的等效传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制外回路增益变化时的根轨迹概略图
本卷实例
  • 关键一步：写出外回路等效开环的零点与极点，定实轴根轨迹区间
  • 中间结果：三条根轨迹，其中两条终止于无穷远，分离角为九十度
  • 卡点：渐近线交点与分离点都要先算，根轨迹草图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制外回路增益变化时的根轨迹概略图
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由虚轴交点求增益的稳定区间
本卷实例
  • 关键一步：令特征方程中s等于jω，实部虚部分别为零联立求临界增益
  • 中间结果：由临界频率与临界增益给出稳定开区间
  • 卡点：两次根轨迹的零极点不同，临界增益不能互相套用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由虚轴交点求增益的稳定区间
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位阶跃输入下的稳态误差
本卷实例
  • 关键一步：先确认系统型别与稳定性，再查静态位置误差系数
  • 中间结果：外回路含积分环节时单位阶跃稳态误差为零
  • 卡点：需先判稳再求误差，型别判断不能只看控制器
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位阶跃输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

4四、Bode图反求与串联校正#

思路
  • 由校正前后两条对数幅频曲线分别反求传函，相除得校正环节；再由校正环节相频范围判断超前或滞后
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由校正前后对数幅频特性分别反求开环传函与校正后传函
本卷实例
  • 关键一步：由低频段高度定增益，由转折频率定各环节并写出传函
  • 中间结果：校正后传函比原传函多一个积分与一个一阶微分环节
  • 卡点：两条幅频曲线的转折频率需回原卷核对图，读数易错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由校正前后对数幅频特性分别反求开环传函与校正后传函
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
滞后校正 系统校正
本卷考法
  • 判断校正环节为超前还是滞后并说明依据
本卷实例
  • 关键一步：由校正环节相频表达式看相位随频率的变化方向
  • 中间结果：相角始终为负，属滞后环节
  • 卡点：把含积分环节的校正误判为超前，需看相位符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过判断校正环节为超前还是滞后并说明依据
  • 设计串联滞后校正装置
