1一、反馈系统稳定性与正弦稳态误差#

思路
  • 由方框图写闭环传函与特征方程并判稳，求根位于s=-1左侧的k范围，再求正弦稳态误差
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由方框图求闭环传函并用特征根判断系统稳定性
本卷实例
  • 关键一步：写出闭环传递函数后取分母为零得特征方程
  • 中间结果：稳定性由特征方程根的实部符号决定
  • 卡点：反馈极性取反会把特征方程写成1减GH
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由方框图求闭环传函并用特征根判断系统稳定性
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据判断系统稳定并求根全在s=-1左侧的k范围
本卷实例
  • 关键一步：令s加1作平移再对新特征方程列劳斯表
  • 中间结果：平移后首列元素同号即为根位于竖线左侧的条件
  • 卡点：平移方向取反会把左半平面条件写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据判断系统稳定并求根全在s=-1左侧的k范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由劳斯表首列不等式求参数的稳定域
本卷实例
  • 关键一步：把首列各元素写成关于k的不等式组再取交集
  • 中间结果：稳定域为若干不等式的公共区间
  • 卡点：漏掉最简单的一个不等式会使区间取大
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由劳斯表首列不等式求参数的稳定域
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求正弦输入下系统的稳态误差ess
本卷实例
  • 关键一步：先写出误差传递函数再令s等于j2代入
  • 中间结果：稳态误差为与输入同频的正弦量
  • 卡点：正弦输入不能用终值定理，须用频率特性求幅相
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求正弦输入下系统的稳态误差ess
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

2二、零度根轨迹与响应形态#

思路
  • 以K为参数画根轨迹，求临界增益与稳定范围，再由分离点增益判断五种阶跃响应形态
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以K为参数绘制含右半平面零点的零度根轨迹
本卷实例
  • 关键一步：按1加GH等于零整理出参数K的一次式再定根轨迹类型
  • 中间结果：相角条件为零度，实轴根轨迹区间随之改变
  • 卡点：把零度根轨迹仍按180度相角条件画
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以K为参数绘制含右半平面零点的零度根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则确定根轨迹的分支数、渐近线与实轴段
本卷实例
  • 关键一步：先标出开环零极点再据此判断实轴段
  • 中间结果：两条分支，其中一条起点在无穷远处
  • 卡点：起点在无穷远的分支容易被漏画
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则确定根轨迹的分支数、渐近线与实轴段
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及系统临界增益
本卷实例
  • 关键一步：令s等于jω代入特征方程后实部虚部分别为零
  • 中间结果：临界增益由虚部方程的一组解给出
  • 卡点：只代一个ω会漏掉另一组虚轴交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及系统临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹分离点增益判断阶跃响应的五种形态
本卷实例
  • 关键一步：把分离点坐标代回幅值条件求对应K
  • 中间结果：由阻尼比符号划出单调与振荡的分界
  • 卡点：分离点方程的解要先筛选再代回
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹分离点增益判断阶跃响应的五种形态
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

3三、多输入方框图与前馈补偿#

思路
  • 用梅森公式求四个通道传函，再分析前馈调节器抑制扰动的作用及对稳定性的影响
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求给定与扰动两输入作用下的四个传递函数
本卷实例
  • 关键一步：求某通道传函时把另一输入置零
  • 中间结果：两通道共用同一闭环特征式
  • 卡点：求扰动通道时未将给定输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求给定与扰动两输入作用下的四个传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 写误差传函并区分给定误差与扰动误差
本卷实例
  • 关键一步：按误差等于给定减反馈写误差传函
  • 中间结果：误差传函与输出传函共用特征式
  • 卡点：扰动误差与输出传函差一个反馈环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写误差传函并区分给定误差与扰动误差
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 说明前馈调节器抑制扰动的作用及对稳定性的影响
本卷实例
  • 关键一步：令扰动到误差的传函为零反解前馈通道
  • 中间结果：前馈加在回路外不改变闭环特征方程
  • 卡点：把前馈当成反馈会误判其影响稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过说明前馈调节器抑制扰动的作用及对稳定性的影响
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式

4四、Bode反求与滞后校正#

思路
  • 由开环幅频曲线反求传函并判稳，求剪切频率与相角裕量，分析串联校正环节特性
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环对数幅频特性曲线反求开环传递函数
本卷实例
  • 关键一步：由低频段斜率定积分环节数，由转折频率定各环节
  • 中间结果：反求传函分母按转折频率依次写出
  • 卡点：低频段高度需折算型别才是增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环对数幅频特性曲线反求开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 求剪切频率并计算相角裕量
本卷实例
  • 关键一步：令幅值等于1解出剪切频率再代入相频
  • 中间结果：相角裕量为180度加剪切频率处的相角
  • 卡点：剪切频率与相位穿越频率不可互换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
