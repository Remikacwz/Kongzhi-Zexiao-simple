1一、方框图与扰动无影响条件#

思路
  • 用梅森公式求输入与扰动两通道的闭环传函和特征方程，再令扰动通道传函为零求补偿环节。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式写多回路系统的闭环传递函数与特征式
本卷实例
  • 关键一步：找出全部回路并判断两两是否接触
  • 关键一步：列特征式与前向通路的余子式
  • 中间结果：特征式等于一减去各回路增益之和
  • 卡点：源图回路编号与接触关系需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式写多回路系统的闭环传递函数与特征式
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 把多回路结构图按信号流向逐层等效
本卷实例
  • 关键一步：区分局部反馈回路与主通路，自内向外等效
  • 中间结果：等效后化为两条前向通路与三个回路
  • 卡点：回路增益正负号需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过把多回路结构图按信号流向逐层等效
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求给定输入与扰动输入作用下的闭环传递函数
本卷实例
  • 关键一步：求某通道时把另一输入置零再列前向通路
  • 中间结果：两通道分母相同而分子由各自通路决定
  • 卡点：扰动通道前向通路的方向与符号易取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求给定输入与扰动输入作用下的闭环传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

2二、电网络建模与阶跃响应#

思路
  • 由 RLC 电路的串并联阻抗求传递函数，代入参数后用拉氏反变换求阶跃响应。
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由两级 RC 网络的串并联关系求输入输出传递函数
本卷实例
  • 关键一步：用复阻抗写出各支路并联阻抗
  • 关键一步：按分压关系写输出电压比
  • 中间结果：传递函数分母含两个电容决定的状态量
  • 卡点：电路图元件编号需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由两级 RC 网络的串并联关系求输入输出传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 把电路阻抗表达式整理为标准传递函数形式
本卷实例
  • 关键一步：通分整理成 s 的降幂有理分式
  • 中间结果：代入参数后分母为二阶多项式
  • 卡点：分母各项系数并项时易出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过把电路阻抗表达式整理为标准传递函数形式
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由二阶传递函数求单位阶跃输入下的输出响应
本卷实例
  • 关键一步：把输出响应拆成部分分式再逐项反变换
  • 中间结果：响应由稳态项与两个衰减指数项叠加
  • 卡点：第2问末尾印成响应等于零，疑为OCR误植
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由二阶传递函数求单位阶跃输入下的输出响应
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

3三、参数稳定域、斜坡误差与根轨迹#

思路
  • 由结构图求开环传函与闭环特征方程，用劳斯判据写参数稳定条件，再求斜坡误差并绘制根轨迹。
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 由结构图求开环传函并写含参数的闭环特征方程
本卷实例
  • 关键一步：按信号流向把内回路等效后再与主通路串联
  • 中间结果：特征方程为二阶且系数含增益与时间常数
  • 卡点：反馈通道为积分环节，型别判断易错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过由结构图求开环传函并写含参数的闭环特征方程
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
参数稳定域的确定 稳定性分析
本卷考法
  • 用劳斯判据写出参数满足的稳定取值关系
本卷实例
  • 关键一步：列劳斯表并要求首列各元为正
  • 中间结果：稳定条件化为一组乘积大于零的不等式
  • 卡点：参数均大于零的前提要一并说明
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过用劳斯判据写出参数满足的稳定取值关系
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求一型系统在单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：先由开环传函判断系统型别
  • 关键一步：再用静态速度误差系数求误差
  • 中间结果：误差由开环增益与积分时间常数组成
  • 卡点：须在稳定前提下才能用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求一型系统在单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 参数取定值后绘制增益变化时的根轨迹
本卷实例
  • 关键一步：求等效开环零点与极点
  • 关键一步：定实轴区间、渐近线与分离点
  • 中间结果：两条根轨迹中一条终止于无穷远
  • 卡点：等效开环零点来自反馈通道，别漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过参数取定值后绘制增益变化时的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

4四、根轨迹与稳定裕度#

思路
  • 由结构图求开环传函，用根轨迹与虚轴交点判稳，再计算幅值裕量与相角裕量。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制含一个开环零点的三阶系统根轨迹
本卷实例
  • 关键一步：由零极点定实轴区间、渐近线与分离点
  • 中间结果：三条根轨迹中两条趋于无穷远
  • 卡点：分离点方程的各根需舍去不在轨迹上的
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制含一个开环零点的三阶系统根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由虚轴交点求使系统稳定的增益范围
本卷实例
  • 关键一步：把 s 等于 jω 代入闭环特征方程
  • 关键一步：实部虚部分别为零后联立
  • 中间结果：除原点外没有其他虚轴交点
  • 卡点：根轨迹不过虚轴时稳定范围为全增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由虚轴交点求使系统稳定的增益范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
稳定裕度 频域分析
本卷考法
  • 求幅值裕量与相角裕量并判断稳定性
本卷实例
  • 关键一步：由相频等于负一百八十度求幅值穿越频率
