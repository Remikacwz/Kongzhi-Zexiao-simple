思路
  • 五道填空各自独立：一阶系统正弦稳态输出、高阶闭环传函降阶、闭环稳态位置误差、含参数系统的稳定条件、滞后校正利用的特性
频率特性的物理意义与求法 频域分析
本卷考法
  • 求一阶系统在正弦输入下的稳态输出表达式
本卷实例
  • 关键一步：单位反馈下闭环传函等于 G/(1+G)，先写出闭环
  • 关键一步：把输入角频率代入闭环频率特性求模与相角
  • 关键一步：稳态输出是幅值乘模、相位加相角的同频正弦
  • 中间结果：闭环传函化成一个一阶惯性环节的形式
  • 中间结果：把 ω 代入后有复数的模与相角两个结果
  • 卡点：把开环传函当闭环传函代入
  • 卡点：只求幅值不写相角，或角度与弧度混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求一阶系统在正弦输入下的稳态输出表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 由闭环偶极子与主导极点概念写出降阶后的传递函数
本卷实例
  • 关键一步：先找相距很近的零点与极点构成偶极子
  • 关键一步：偶极子可整体略去，再保留主导极点对应的二阶环节
  • 关键一步：略去时用闭环直流增益不变确定保留系数
  • 中间结果：分子零点与一个实极点靠得很近，构成偶极子
  • 中间结果：保留靠近虚轴的共轭极点对应的二阶因式
  • 卡点：只按极点距离判断而不看偶极子
  • 卡点：降阶后忘记保持直流增益不变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过由闭环偶极子与主导极点概念写出降阶后的传递函数
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由闭环传函求单位阶跃输入下的稳态位置误差
本卷实例
  • 关键一步：先由闭环传函反求开环传函
  • 关键一步：按开环积分环节个数判断系统型别
  • 关键一步：零型系统在阶跃输入下的误差由静态位置误差系数决定
  • 中间结果：开环等于闭环传函除以 1 减闭环传函
  • 中间结果：按型别选择位置误差或速度误差公式
  • 卡点：直接用闭环传函套静态误差系数
  • 卡点：未判稳就用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由闭环传函求单位阶跃输入下的稳态位置误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

劳斯判据 稳定性分析
本卷考法
  • 由含参数的开环传函求闭环稳定的条件
本卷实例
  • 关键一步：先写出闭环特征方程并整理成 s 的多项式
  • 关键一步：用劳斯判据或二阶系统系数同号列不等式
  • 关键一步：解出含参数项的稳定范围
  • 中间结果：特征方程整理后二次项与一次项系数都含参数
  • 中间结果：二阶系统稳定的充要条件是各项系数同号
  • 卡点：把所有系数为正直接当成充要条件而漏项
  • 卡点：把开环传函的分母直接当特征方程
  • 卡点：题面变量记法与答案段混用，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由含参数的开环传函求闭环稳定的条件
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
滞后校正 系统校正
本卷考法
  • 指出滞后校正装置所利用的频率特性
本卷实例
  • 关键一步：滞后网络的幅值在中高频段衰减
  • 关键一步：它主要利用高频幅值衰减特性来压低截止频率
  • 关键一步：截止频率下降使相角裕度增大
  • 中间结果：把滞后网络写成 (bTs+1)/(Ts+1)，b 小于 1
  • 中间结果：看它在中高频段对幅值的衰减作用
  • 卡点：答成相角超前
  • 卡点：把利用高频幅值衰减与提高低频增益混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过指出滞后校正装置所利用的频率特性
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

3三、梅森公式求传递函数#

思路
  • 给出方框图，用梅森增益公式求 C(s)/R(s)；须先列全部回路与互不接触回路对
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式由方框图求 C(s)/R(s)
本卷实例
  • 关键一步：先列全部单回路增益，再找两两互不接触的回路对
  • 关键一步：写特征式，只算到实际存在的互不接触阶数
  • 关键一步：各前向通路乘自己的余子式后求和
  • 中间结果：方框图含 6 个回路与若干互不接触回路对
  • 中间结果：特征式为 1 加回路增益和再加互不接触乘积
  • 卡点：互不接触回路漏算或重复
  • 卡点：余子式里保留与前向通路接触的回路
  • 卡点：方框图只画在图里，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式由方框图求 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

4四、方框图参数对动态与稳态性能的影响#

思路
  • 含 k1、k2 的方框图：先化简求闭环传函并化为标准二阶形式，再分别讨论动态性能、单位速度下的稳态性能与组合输入下的稳态误差
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 分析参数 k1、k2 对系统动态性能的影响
本卷实例
  • 关键一步：先化简方框图，把闭环化为标准二阶形式
  • 关键一步：读出自振角频率与阻尼比同 k1、k2 的关系
  • 关键一步：再按这两个参数对超调量与调节时间的影响作答
  • 中间结果：开环形如 20k1 除以 s 乘 (s+4k2)
  • 中间结果：自振角频率主要由 k1 决定，阻尼比由 k2 与 k1 之比决定
  • 卡点：把开环增益误当自振角频率
  • 卡点：只定性说变大变小而不说明经由哪个参数传导
  • 卡点：方框图只画在图 3，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过分析参数 k1、k2 对系统动态性能的影响
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求阶跃与斜坡组合输入下输出端的稳态误差
本卷实例
  • 关键一步：把组合输入分解为阶跃与斜坡两个分量分别求误差
  • 关键一步：阶跃分量在 Ⅰ 型系统下误差为零，斜坡分量按 Kv 计算
  • 关键一步：输出端误差等于各分量稳态误差之和
  • 中间结果：输入分解为 2 倍阶跃与 5 倍斜坡
  • 中间结果：斜坡分量误差等于 5 除以 Kv，阶跃分量误差为零
  • 卡点：只算其中一个分量
  • 卡点：把输入端误差与输出端误差混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过求输出 c(t) 的自振振幅与自振频率
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率

思路

由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环对数幅频特性曲线求开环传函 G0(s)
本卷实例
  • 关键一步：由低频段斜率与高度定型别与开环增益
  • 关键一步：按各转折频率处的斜率变化量确定一阶环节
  • 关键一步：把环节串起来写出 G0(s) 并用已知点核算增益
  • 中间结果：低频段斜率对应一个积分环节，转折频率在 1 与 10 处
  • 中间结果：按低频段高度与增益的关系确定放大系数
  • 卡点：把延长线交点当增益而未折算型别
  • 卡点：斜率变化 −40 dB 直接写成一阶环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环对数幅频特性曲线求开环传函 G0(s)
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

滞后校正 系统校正
本卷考法
  • 设计串联滞后校正装置使校正后截止频率为指定值
本卷实例
  • 关键一步：把滞后装置写成 (bTs+1)/(Ts+1)，b 小于 1
  • 关键一步：令校正后在指定截止频率处幅值为 1，用抓大放小近似定 b
  • 关键一步：再按滞后装置的转折频率远小于新截止频率来选 T
  • 中间结果：校正后传函等于 G0 与滞后装置之积
  • 中间结果：幅值条件给出 b 的近似值，T 由转折频率与截止频率之比定
  • 卡点：把滞后网络转折频率取得过高，相位滞后抵消增益改善
  • 卡点：把分子分母两个转折频率顺序写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过设计串联滞后校正装置使校正后截止频率为指定值
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

校正的基本概念与性能指标 系统校正
本卷考法
  • 分析所设计的滞后校正装置对系统闭环性能的影响
本卷实例
  • 关键一步：从稳定性、准确性、快速性三个方面分别说明
  • 关键一步：滞后校正压低截止频率使相角裕度增大、稳定性改善
  • 关键一步：低频增益不变故稳态误差不变，但响应速度变慢
  • 中间结果：校正装置在中高频衰减、低频增益基本不变
  • 中间结果：截止频率下降对应调节时间变长
  • 卡点：只答稳定性改善而漏掉准确性不变与快速性下降
  • 卡点：把滞后校正说成能减小稳态误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 校正是在系统中引入附加装置以改善性能
  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过分析所设计的滞后校正装置对系统闭环性能的影响
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错
  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求
