1、2、3、4、5一、填空题（5 空·每空 3 分）15 分#

思路
  • 五道填空各自独立：相频特性写法、二阶系统阶跃响应、相平面渐近线、纯延迟系统的稳定边界、稳态误差；每空都只考一步结论，难点全在陷阱
频率特性的物理意义与求法 频域分析
本卷考法
  • 写出开环传递函数的相频特性表达式
本卷实例
  • 关键一步：相频特性是各环节相角的代数和，把每个因式单独取相角再相加
  • 关键一步：分母 (4s−1) 含右半平面根 s=1/4
  • 关键一步：它的相角为 180°−arctan(4ω)，不能按惯性环节写成 −arctan(4ω)
  • 关键一步：用它自检：ω→0 时分母只剩 −1 与 s，相角应趋于 +90°
  • 中间结果：φ(ω)=90°+arctan(ω/5)+arctan(4ω)−arctan(2ω)
  • 卡点：把 (4s−1) 当普通惯性环节会让相频曲线平移 180°
  • 卡点：从低频段符号即可看出不对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过写出开环传递函数的相频特性表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传递函数 φ(s)=(s+2)/(s²+2s+1) 求单位阶跃响应
本卷实例
  • 关键一步：分母 s²+2s+1 是完全平方 (s+1)²
  • 关键一步：闭环为两个相等实极点，属临界阻尼 ξ=1
  • 关键一步：二重极点做部分分式要写全 A/s、B/(s+1)、C/(s+1)² 三项
  • 关键一步：漏项会丢掉 t·e^{−t} 这类项
  • 关键一步：先用终值定理定 c(∞)=Φ(0)=2，可以对最后的时间项做交叉验证
  • 中间结果：把 C(s) 按二重极点展开成三项部分分式
  • 中间结果：反变换后除指数项外还要带一项 t·e^{−t}
  • 卡点：只写两项部分分式，漏掉 t·e^{−t} 项
  • 卡点：或把重根当成两个不同实极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传递函数 φ(s)=(s+2)/(s²+2s+1) 求单位阶跃响应
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

相平面法 非线性系统
本卷考法
  • 写出二阶线性系统相轨迹的渐近线
本卷实例
  • 关键一步：无输入系统的相轨迹由特征根决定
  • 关键一步：s²+3s+2=(s+1)(s+2)，相异负实根对应稳定节点
  • 关键一步：每个特征根 λ 都对应一条过原点的直线解 ẋ=λx，这条直线就是相轨迹的渐近线
  • 关键一步：先判奇点类型（稳定节点、稳定焦点、鞍点），渐近线只在节点情形才存在
  • 中间结果：渐近线为 ẋ=−x 与 ẋ=−2x 两条
  • 卡点：只挑一条写；或把「渐近线」理解成时间响应曲线上的水平渐近线，跑到 x–t 平面去答
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过写出二阶线性系统相轨迹的渐近线
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

含纯延迟环节的系统稳定性 稳定性分析
本卷考法
  • 求使含纯延迟环节的系统闭环稳定的延迟 τ 取值范围
本卷实例
  • 关键一步：临界条件：把 s=jω 代入 G(jω)=−1
  • 关键一步：幅值 |G₀(jω)|=1 与相角 ∠G₀(jω)−τω=−180° 须同时成立
  • 关键一步：非延迟部分是一阶环节，幅值随 ω 单调下降，所以幅值条件先定出唯一的临界 ω
  • 关键一步：再把这个 ω 代进相角条件解出临界的 τ，取值范围是 0<τ<临界值
  • 中间结果：分母 OCR 作 2s+11，但与分子 √5 搭配时 ω=1 处 |G|=1
  • 中间结果：这说明分母更可能是 2s+1，须回原卷核对常数项
  • 中间结果：按分母 2s+1：临界相角条件为 −arctan2−τ=−π
  • 中间结果：由它反解临界 τ，再据此给出 τ 的稳定区间
  • 卡点：若分母是 2s+11，幅值最大仅 √5/11<1，临界条件无法满足
  • 卡点：此时任何 τ 都稳定；两种读法结论相反，须回原卷核对常数项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 延迟环节 e^{-τs} 的幅值为 1、相位为 -τω，只恶化相位
  • 延迟会显著缩小稳定域，τ 越大越难稳定
  • 频域判据需用相位裕度扣除延迟引起的附加滞后
步骤
  • 写出含延迟的开环传递函数
  • 分别求幅值与相位表达式
  • 在相频特性中扣除 τω 的滞后量
  • 按稳定裕度或奈氏判据求临界 τ 或临界 K
通用考法
  • 本卷考过求使含纯延迟环节的系统闭环稳定的延迟 τ 取值范围
  • 求使系统稳定的最大延迟时间
  • 求含延迟系统的临界开环增益
  • 分析延迟对稳定裕度的影响
常见易错
  • 把延迟环节当成惯性环节处理
  • 相位计算时忘记角度与弧度换算

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位负反馈系统在斜坡输入下的稳态误差
本卷实例
  • 关键一步：先数型别：分母只有一个 s 且是一次幂，属 Ⅰ 型，斜坡输入用静态速度误差系数 Kv
  • 关键一步：Kv=lim(s→0) sG(s)，分母两个惯性环节在 s→0 时都趋于 1
  • 关键一步：再按 ess=v₀/Kv 代入斜坡幅度 10
  • 关键一步：判稳要在用终值定理之前做，这是这类题最容易漏的一步
  • 中间结果：ess = v₀/Kv，把本题斜坡幅度与静态速度误差系数代进去即可
  • 中间结果：代入前先判稳：本题 K=10 时劳斯表变号，算出的值实际无意义（见卡点）
  • 卡点：K=10 时劳斯首列出现变号，闭环不稳定（K 需更小才稳定）
  • 卡点：严格说此时稳态误差无意义，填空值只是按公式算得
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位负反馈系统在斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

2二、电路系统的方框图与传递函数15 分#

思路
  • 由电路列复阻抗方程，先画出以 i₁、i₂、u₃ 为中间变量的方框图，再消元求 u₂/u₁
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由电路列写方程并画出以中间变量为节点的方框图
本卷实例
  • 关键一步：电容写成 1/(Cs)、电阻保留 R，全部按复阻抗列节点或回路代数方程
  • 关键一步：一个方程对应一个相加点：把每个待求量整理成「输入量乘以某环节」的形式再搭方框
  • 关键一步：电流经过串联元件的先后次序要和电路拓扑一致，中间变量要逐个出现，不能跳级
  • 中间结果：典型结构中会出现两个并联支路的反相相加，注意比较点的正负号
  • 卡点：先求出总传递函数再回头补画方框图——题目要的是以中间变量为节点的结构图，必须逐方程搭
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由电路列写方程并画出以中间变量为节点的方框图
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 求电路的传递函数 u₂(s)/u₁(s)
本卷实例
  • 关键一步：列完方程组后逐个消去 i₁、i₂、u₃，只留下 u₁ 与 u₂ 的比值
  • 关键一步：分子分母同乘各时间常数，整理成 s 的多项式形式便于核对量纲
  • 关键一步：结果应与按复阻抗分压直接算出的表达式一致，可用来验证消元过程
  • 中间结果：按节点列 KCL、按支路写伏安关系，得到含节点电压与支路电流的方程组
  • 中间结果：逐个代换消去中间量，最后只剩 u₁ 与 u₂，写成 s 的多项式比
  • 中间结果：分母阶数由电容与电感个数决定，具体系数需回原卷核对电路接法
  • 卡点：电容与电阻串并联关系看错；或消元时正负号丢失
  • 卡点：本题电路以图给出，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过求电路的传递函数 u₂(s)/u₁(s)
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

3三、由结构图求闭环与误差传递函数15 分#

思路
  • 同一张结构图求两个传函：先求 C/R，再按误差定义求 E/R；图中有 4 个单回路，另有 1 对互不接触回路
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求多回路系统的 C(s)/R(s)
本卷实例
  • 关键一步：先把所有单回路数与两两互不接触的回路对列全，本图是 4 个单回路加 1 对互不接触回路
  • 关键一步：特征式 Δ=1−ΣL_a+ΣL_aL_b，只算到两两互不接触
  • 关键一步：本图没有三个互不接触的回路，只保留到二阶项
  • 关键一步：前向通道 P₁ 走主通路，它的余子式 Δ₁ 只由与该通路不接触的回路组成
  • 中间结果：Δ 的分母形态是 1+四个回路增益之和+互不接触回路乘积，核对时先看 Δ 再乘前向通道
  • 卡点：互不接触回路漏乘或重复计入；余子式里把与前向通道接触的回路也算进去，导致 Δ₁ 偏大
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求多回路系统的 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 求误差传递函数 E(s)/R(s)
本卷实例
  • 关键一步：先按题意确定误差取在输入端还是反馈端，这一步决定公式里有没有反馈通道的 H(s)
  • 关键一步：把从误差点出发到输出 C 的那部分当作前向通道，重新套一次梅森公式
  • 关键一步：回路两两不接触关系与求 C/R 时完全相同，分母共用同一个 Δ
  • 中间结果：本题 E/R 的分子是 1 加上若干回路增益（对应误差点不经过的那几条回路）
  • 卡点：直接把 C/R 的结果当成 E/R；或两种误差定义混用，结果差一个反馈系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法

  • 中间结果：闭环为 9/(s²+3s+9)，对照标准二阶式读出 ωn 与 ξ
  • 中间结果：再由 ωr=ωn√(1−2ξ²) 与 Mr=1/(2ξ√(1−ξ²)) 求谐振参数
  • 卡点：ξ 大于 0.707 时仍套谐振公式（此时不存在谐振峰）；或把开环谐振与闭环谐振搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过求使稳态输出幅值最大的输入频率及该最大幅值
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

思路
  • 开环为 (10s²+s+10)/[s(s²−1)]，分母可分解出 s−1 这个右半平面极点，必须按 Z=N+P 判稳
频率特性的物理意义与求法 频域分析
本卷考法
  • 绘制开环传递函数的奈奎斯特曲线
本卷实例
  • 关键一步：先把分母因式分解：s(s²−1)=s(s−1)(s+1)
  • 关键一步：认出 s=1 是右半平面极点
  • 关键一步：ω 从小到大的起点由积分环节 s 决定，幅值趋于无穷、相角从 −90° 附近出发
  • 关键一步：画出整段走向并标出与负实轴的交点位置，后面数包围圈数全靠它
  • 中间结果：分子是二次、分母是三次，故 ω→∞ 时曲线以 1/ω 的速率收向原点
  • 卡点：不分解分母就直接画，漏掉右半平面极点；或含积分环节时忘记补画无穷大半径的圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过绘制开环传递函数的奈奎斯特曲线
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据判断闭环稳定性
本卷实例
  • 关键一步：第一步先数开环右半平面极点数 P
  • 关键一步：分解后 s−1 贡献一个 P；不能沿用 P=0 的套路
  • 关键一步：稳定要求 Z=N+P=0，即包围圈数 N 必须为 −1
  • 关键一步：也就是曲线顺时针绕过 (−1,j0) 恰好一圈
  • 关键一步：积分环节在原点，数包围前要先把无穷大半径的圆弧补上
  • 中间结果：P=1 意味着这条曲线即使看着不围着 (−1,j0)，也不能直接判稳定，必须数圈数
  • 卡点：默认 P=0 只看曲线是否包围；或顺时针、逆时针的正负号定义记反，结论正好相反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

9九、描述函数法分析自激振荡#

思路
  • 非线性环节描述函数 N(A)=e^{−2A}，线性部分由图给出；用负倒描述函数与 G(jω) 的交点判断自振
用描述函数法分析自振 非线性系统
本卷考法
  • 分析系统周期运动的稳定性
  • 确定自激振荡的振幅与频率
本卷实例
  • 关键一步：自振条件是把线性部分与负倒描述函数放在同一张复平面上看有没有交点
  • 关键一步：由 N(A)=e^{−2A} 得 −1/N(A)=−e^{2A}
  • 关键一步：它是负实轴上随 A 增大向左远离原点的线
  • 关键一步：交点同时给出振幅与频率，稳定性还要看两条曲线穿越时的方向
  • 中间结果：联立时先用相角条件定出频率 ω，再把 ω 代入幅值条件解振幅 A
  • 卡点：把描述函数当作传递函数整体代入闭环；或 −1/N(A) 的方向画反，稳定性结论颠倒
  • 卡点：本题线性部分的传递函数只画在图 5 里，具体振幅与频率需回原卷核对后才能定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过分析系统周期运动的稳定性
  • 本卷考过确定自激振荡的振幅与频率
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率

思路
  • 最小相位系统 G₀=10/[s(s+2)]：由 ess≤0.1 定增益，由 γ≥50° 与截止频率范围选校正形式并定 kc、T₁、T₂，最后画三条对数幅相特性
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由稳态误差要求确定开环增益
本卷实例
  • 关键一步：先判型别：分母有一个 s，属 Ⅰ 型，斜坡输入下的稳态误差是 1/Kv
  • 关键一步：由 ess≤0.1 得 Kv≥10，据此定出增益 kc 的下限
  • 关键一步：增益抬高后相角裕度会下降，这正是后面必须加校正装置的原因
  • 中间结果：未经校正时增益取 10，对应开环 10/[s(s+2)]，相角裕度明显不足
  • 卡点：只满足误差要求就收工，没有意识到增益与相角裕度是互相牵扯的
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由稳态误差要求确定开环增益
  • 求给定输入下的稳态误差

  • 比较不同型别系统的跟踪能力

  • 关键一步：ωc′ 须落在题目给的 1～4 rad/s 区间内

  • 卡点：不定 ωc′ 就直接套公式

  • 最大超前角不超过 60°，否则噪声放大明显
