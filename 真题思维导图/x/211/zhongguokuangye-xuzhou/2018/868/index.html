中国矿业大学(徐州) 868 自动控制原理 2018 年真题思维导图

211 院校共 4 题合计 50 分

难度：中等　复试卷（2018 复试试题十），共 4 题：一由结构图求闭环传递函数 C(s)/R(s)、二由系统框图与单位斜坡稳态误差约束求K并求二阶动态指标、三画以参数k为变化参量的根轨迹、四由开环传函画对数幅频特性求截止频率与相角裕度并选择校正方式。一、二题依附原卷插图。4题的逐题分值全部印出 10/10/10/20=50。

点击节点展开/折叠　·　滚轮缩放　·　拖拽平移

一一、结构图求闭环传递函数 C(s)/R(s)10 分#

思路
  • 用结构变换或梅逊公式由结构图求 C(s)/R(s)，先找前向通路与回路再合并。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图用梅逊增益公式求闭环传递函数
本卷实例
  • 关键一步：先找出全部前向通路与单独回路并判断是否接触
  • 中间结果：按梅逊公式把前向通路增益与余子式合并
  • 卡点：不接触回路找漏或重复计数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图用梅逊增益公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 用结构变换逐层化简多回路系统
本卷实例
  • 关键一步：由内到外逐层化简各回路后再合并
  • 中间结果：化简结果应与梅逊公式所得一致
  • 卡点：化简内环时把外环信号当成常数处理
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过用结构变换逐层化简多回路系统
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

二二、稳态误差约束求K与动态指标10 分#

思路
  • 先由稳态误差约束反求开环增益K，再把开环化为标准二阶形式求动态指标。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡输入下的稳态误差为 0.2 反求开环增益K
本卷实例
  • 关键一步：把稳态误差表示为K的函数并令其等于 0.2
  • 中间结果：解出K后把开环传函整理成标准二阶形式
  • 卡点：未判稳就使用终值定理
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位斜坡输入下的稳态误差为 0.2 反求开环增益K
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由开环传函的系数求阻尼比与自然频率
本卷实例
  • 关键一步：把开环化为自然频率平方比上 s 乘 s 加二倍阻尼自然频率
  • 中间结果：由常数项与一次项系数分别解出自然频率与阻尼比
  • 卡点：把开环增益误当成闭环传函的系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由开环传函的系数求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率求峰值时间、超调量与调节时间
本卷实例
  • 关键一步：分别代入峰值时间、超调量与调节时间公式
  • 中间结果：三项指标由阻尼比与自然频率共同决定
  • 卡点：两种误差带的调节时间系数搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率求峰值时间、超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式

三三、以参数k为变化参量的根轨迹10 分#

思路
  • 把闭环特征方程整理成以参数k为参变量的根轨迹方程，按法则绘根轨迹并求分离点。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 画以参数k为变化参量的根轨迹
本卷实例
  • 关键一步：把特征方程整理成根轨迹方程的标准形式并把k提到分子
  • 中间结果：按参数根轨迹的相角条件确定起点、终点与走向
  • 卡点：整理时没有把参数完整地提到分子位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过画以参数k为变化参量的根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按根轨迹法则确定分支数、实轴段与渐近线
本卷实例
  • 关键一步：由开环零极点分布画实轴段并定渐近线
  • 中间结果：分支数等于极点数，渐近线按公式定夹角与交点
  • 卡点：实轴段判据中的零极点个数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按根轨迹法则确定分支数、实轴段与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点与会合点
本卷实例
  • 关键一步：由重根条件或对参数求导为零列方程
  • 中间结果：筛掉不在根轨迹上的解，取有效的分离点与会合点
  • 卡点：求出方程根后不筛选，保留不在根轨迹上的解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点与会合点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式

四四、对数幅频特性与相角裕度及校正方式20 分#

思路
  • 由开环传函画对数渐近幅频特性，求截止频率与相角裕度，再据目标裕度选择校正方式并写步骤。
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制给定开环传函的对数渐近幅频特性
本卷实例
  • 关键一步：按低频段斜率与高度定起点，再按各转折频率逐段改斜率
  • 中间结果：逐段累加得到各转折频率处的幅值
  • 卡点：逐段改斜率时忘记累加而非替换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过绘制给定开环传函的对数渐近幅频特性
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
稳定裕度 频域分析
本卷考法
  • 求系统的截止频率与相角裕度
本卷实例
  • 关键一步：由渐近线求出截止频率后计算该频率处相角
  • 中间结果：相角裕度等于一百八十度加截止频率处的相角
  • 卡点：把 ωc 与 ωg 两个频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求系统的截止频率与相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
滞后校正 系统校正
本卷考法
  • 选择能提高稳定性并满足相角裕度要求的校正方式并写步骤
本卷实例
  • 关键一步：比较校正前后截止频率与相角裕度确定应采用滞后校正
  • 中间结果：按目标相角裕度确定新的截止频率与滞后网络参数
  • 卡点：把滞后网络的两个转折频率顺序写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过选择能提高稳定性并满足相角裕度要求的校正方式并写步骤
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善
