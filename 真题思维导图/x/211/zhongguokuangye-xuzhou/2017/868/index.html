中国矿业大学(徐州) 868 自动控制原理 2017 年真题思维导图

211 院校共 5 题

难度：中等　复试卷（2017 复试试题九），共 5 题：一求扰动传递函数 C(s)/N(s)、二由单位阶跃响应曲线反求阻尼比与自然频率并写开环与闭环传函、三用劳斯判据定稳定K范围、四绘奈氏曲线并用判据判稳、五由Bode图反求校正前传函并设计串联超前校正。一、二、四、五题依附原卷插图。分值仅一、四印了10分，其余三题未印。

一一、求扰动传递函数 C(s)/N(s)10 分#

思路
  • 令参考输入为零，只保留扰动通道，用结构变换或梅逊公式求扰动到输出的传递函数。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求扰动作用下的传递函数 C(s)/N(s)
本卷实例
  • 关键一步：把参考输入置零，仅保留扰动作用点与输出通道
  • 中间结果：按扰动到输出的前向通路与回路化简出传递函数
  • 卡点：求扰动传函时没有把参考输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求扰动作用下的传递函数 C(s)/N(s)
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 化简含两条前向通路与局部反馈的结构图
本卷实例
  • 关键一步：由内到外逐层化简各回路，再合并并联支路
  • 中间结果：把化简结果代回总图并整理成单一分式
  • 卡点：化简内环时把外环信号当成常数处理
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过化简含两条前向通路与局部反馈的结构图
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

二二、由阶跃响应曲线反求二阶参数#

思路
  • 由阶跃响应曲线的峰值与稳态值求超调量进而求阻尼比，再由峰值时间求自然频率，最后写开环与闭环传函。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由单位阶跃响应曲线求阻尼比与自然频率
本卷实例
  • 关键一步：由曲线峰值与稳态值先算最大超调量再求阻尼比
  • 中间结果：把峰值时刻代入峰值时间公式求自然频率
  • 卡点：把稳态值当成 1 而未按超调量定义计算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由单位阶跃响应曲线求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由响应曲线读取超调量与峰值时间
本卷实例
  • 关键一步：按曲线读峰值、稳态值与峰值时刻
  • 中间结果：超调量只与阻尼比有关，峰值时间还依赖自然频率
  • 卡点：峰值时间与上升时间混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由响应曲线读取超调量与峰值时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由响应指标反求开环与闭环传递函数
本卷实例
  • 关键一步：先按 ζ 与 ωn 写闭环标准式，再反推开环式
  • 中间结果：开环为自然频率平方比上 s 乘 s 加二倍阻尼自然频率
  • 卡点：未判断系统阶数就直接套用二阶公式
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由响应指标反求开环与闭环传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

三三、劳斯判据定稳定K范围#

思路
  • 由开环传函写闭环特征方程，整理成标准多项式后列劳斯表，令首列同号求K的范围。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据确定系统稳定时K的取值范围
本卷实例
  • 关键一步：把开环传函代回闭环特征方程并整理成标准多项式
  • 中间结果：列劳斯表，按首列符号变化判断根分布
  • 卡点：系数有缺项时不补零就直接套用劳斯判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据确定系统稳定时K的取值范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由劳斯表首列不等式求参数稳定域
本卷实例
  • 关键一步：令首列各元素同号得到关于K的不等式组
  • 中间结果：取各不等式交集得到K的稳定范围
  • 卡点：只列部分首列元素的不等式，漏掉某个约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由劳斯表首列不等式求参数稳定域
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式

四四、绘奈氏曲线并用判据判稳10 分#

思路
  • 写出开环频率特性，补画无穷大半径圆弧后作奈氏曲线，数开环右半极点数与包围圈数判稳。
频率特性的物理意义与求法 频域分析
本卷考法
  • 写出给定开环传函的幅频与相频表达式
本卷实例
  • 关键一步：把 s 换成 jω 后分别取模与取相角
  • 中间结果：两个积分环节贡献负一百八十度，惯性环节贡献负反正切
  • 卡点：相角累加时漏掉积分环节的负九十度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过写出给定开环传函的幅频与相频表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 由开环幅相曲线与奈奎斯特判据判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数 P，再数曲线包围临界点的圈数
  • 中间结果：按 Z 等于 P 减 N 得到闭环右半根数判断稳定性
  • 卡点：开环含积分环节时未补画无穷大半径圆弧
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环幅相曲线与奈奎斯特判据判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式

五五、由Bode图反求传函并设计超前校正#

思路
  • 先由渐近幅频特性反求校正前传函并求相角裕度，再按目标裕度与截止频率设计串联超前校正。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环对数幅频渐近线反求校正前传递函数
本卷实例
  • 关键一步：由低频段斜率与高度定型别与增益
  • 中间结果：读出各转折频率后写成典型环节的乘积
  • 卡点：把延长线交点误当作增益值而未折算型别
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环对数幅频渐近线反求校正前传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 由截止频率求校正前系统的相角裕度
本卷实例
  • 关键一步：由幅频特性求截止频率，再算该频率处的相角
  • 中间结果：相角裕度等于一百八十度加截止频率处的相角
  • 卡点：把截止频率与相位穿越频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由截止频率求校正前系统的相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
超前校正 系统校正
本卷考法
  • 设计串联超前校正装置使相角裕度与截止频率达标
本卷实例
  • 关键一步：按目标相角裕度确定所需超前角并与截止频率要求协调
  • 中间结果：由超前网络的最大超前角公式确定网络参数与转折频率
  • 卡点：计算补偿角时忽略截止频率变化带来的附加相角损失
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过设计串联超前校正装置使相角裕度与截止频率达标
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
