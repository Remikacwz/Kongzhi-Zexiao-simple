劳斯判据 稳定性分析
本卷考法
  • 判断给定的闭环极点、特征方程或阶跃响应对应的系统是否稳定
本卷实例
  • 关键一步：稳定的充要条件是闭环极点全在左半平面
  • 关键一步：对三次特征方程列劳斯表，检查首列符号是否变号
  • 关键一步：有两个选项含右半平面极点或发散项，可先排除
  • 中间结果：对 s³+0.5s²+4s+20 列劳斯表，看首列是否变号
  • 中间结果：另一选项的阶跃响应含负指数衰减项，属收敛过程
  • 卡点：只看特征方程系数是否齐全就判稳，漏掉首列变号
  • 卡点：把衰减的阶跃响应误判为不稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过判断给定的闭环极点、特征方程或阶跃响应对应的系统是否稳定
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

系统型别与静态误差系数 稳态误差
本卷考法
  • 由开环传递函数求静态位置误差系数 kp
本卷实例
  • 关键一步：kp 等于 G(s)H(s) 在 s 趋于 0 时的极限
  • 关键一步：先数开环在原点有几个积分环节定型别
  • 关键一步：按型别判断 kp 是有限值还是发散
  • 中间结果：开环分母含一个 s，属 Ⅰ 型系统
  • 中间结果：按 lim(s→0) GH 的形式写出表达式再代值
  • 卡点：把 kp 与 Kv 或开环增益混为一谈
  • 卡点：未注意分母的 s 就套有限值公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由开环传递函数求静态位置误差系数 kp
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 用主导极点概念把三阶闭环传递函数降阶
本卷实例
  • 关键一步：先比较各极点到虚轴的距离，找最靠近虚轴的主导极点
  • 关键一步：把远离虚轴的极点当非主导极点略去
  • 关键一步：略去时用闭环增益不变确定保留系数
  • 中间结果：分母可看成 (s+100) 与 (s²+2s+4) 的乘积
  • 中间结果：保留共轭复极点对应的二阶因式
  • 卡点：只按极点距离判断，忽略零点对超调量的影响
  • 卡点：略去极点后没保持闭环增益不变
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤

  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过用主导极点概念把三阶闭环传递函数降阶
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小

最小相位系统与非最小相位系统 频域分析
本卷考法
  • 判断给定传递函数是否为最小相位系统
本卷实例
  • 关键一步：最小相位要求全部零点与极点都在左半平面
  • 关键一步：含纯延迟环节的系统也不是最小相位
  • 关键一步：逐项检查分子零点与分母极点的实部符号
  • 中间结果：个别选项含右半平面零点或极点
  • 中间结果：另一选项含纯延迟环节，直接排除
  • 卡点：只查极点不查零点
  • 卡点：把含延迟环节的系统误当作最小相位
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过判断给定传递函数是否为最小相位系统
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈
超前校正 系统校正
本卷考法
  • 从给定超前网络中选出在指定频率提供最大相位超前角的装置
本卷实例
  • 关键一步：超前网络 Gc=(aTs+1)/(Ts+1) 最大超前角在中心频率处
  • 关键一步：中心频率等于 1 除以根号 a 乘 T
  • 关键一步：令中心频率等于题给频率再比较各选项
  • 中间结果：把每个选项写成 (aTs+1)/(Ts+1) 读出 a 与 T
  • 中间结果：代入中心频率条件逐项筛选
  • 卡点：把超前网络的分子分母零点极点顺序看反
  • 卡点：只比转折频率而不看中心频率位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过从给定超前网络中选出在指定频率提供最大相位超前角的装置
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

  • 中间结果：两者低频增益相同，故稳态值不变
  • 卡点：把附加极点当成附加零点，认为超调增大
  • 卡点：只看极点个数不看极点位置

广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 由含参数 a 的特征方程写出以 a 为变量的等效开环传函
本卷实例
  • 关键一步：把闭环特征方程按含 a 与不含 a 分成两部分
  • 关键一步：把含 a 的项整理成 a 乘某个分式的形式
  • 关键一步：令该分式乘 a 作等效开环传函，画 a 从 0 到正无穷的根轨迹
  • 中间结果：特征方程为 s(s²+2s+2)+s+a=0
  • 中间结果：移项后等效开环传函形如 a 除以一个 s 的多项式
  • 卡点：没有把参数 a 完整提到分子位置
  • 卡点：把等效开环传函误写成闭环传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过由含参数 a 的特征方程写出以 a 为变量的等效开环传函
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

附加开环零极点的影响 根轨迹法
本卷考法
  • 判断哪种措施不能提高系统稳定性
本卷实例
  • 关键一步：逐项把措施折算成对开环零极点或相位的影响
  • 关键一步：增加开环积分环节会再带来 90 度相位滞后
  • 关键一步：PD 控制、开环零点与超前校正都能提供超前相角
  • 中间结果：逐个分析各选项对相位裕度或根轨迹走向的作用
  • 中间结果：再看它对稳定性是有利还是不利
  • 卡点：把增加积分环节当成既改善稳态又提高稳定性
  • 卡点：混淆超前校正与滞后校正的作用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过判断哪种措施不能提高系统稳定性
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
频率特性的物理意义与求法 频域分析
本卷考法
  • 写出含延迟与不稳定惯性环节的传递函数的相频特性
本卷实例
  • 关键一步：相频特性等于各典型环节相角的代数和
  • 关键一步：分母 (2s−1) 含右半平面极点，不能按惯性环节写相角
  • 关键一步：先把它改写成 (−1)(1−2s) 再取相角，延迟环节贡献 −0.1ω 相位
  • 中间结果：把传递函数整理成带负号的稳定惯性环节形式
  • 中间结果：积分环节贡献 −90 度，改写成以 π 为单位
  • 卡点：把 (2s−1) 当普通惯性环节，相位少算 180 度
  • 卡点：延迟环节的相位忘记带负号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过写出含延迟与不稳定惯性环节的传递函数的相频特性
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
