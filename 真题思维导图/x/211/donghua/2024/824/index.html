1、2、3、4、5、6、7、8、9、10一、选择题：反馈、稳定性与校正20 分#

思路
  • 十道选择覆盖反馈优点、结构图求传函、极点配置条件、校正装置对带宽影响、稳定临界增益、动态指标定义与稳定裕度判据
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 判断反馈控制系统相对开环系统的主要优点
本卷实例
  • 关键一步：反馈通过偏差检测与修正，使输出对参数变化和扰动不敏感
  • 中间结果：反馈系统控制精度高，但结构与调参更复杂
  • 卡点：把反馈的优点说成结构简单或成本更低
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过判断反馈控制系统相对开环系统的主要优点
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图选项求闭环传递函数
本卷实例
  • 关键一步：先按串联、并联、反馈等效化简，再对照四个选项
  • 中间结果：负反馈闭环分母取 1 加开环传函
  • 卡点：把负反馈的分母写成 1 减开环传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由结构图选项求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
状态反馈与极点配置 状态空间分析
本卷考法
  • 判断状态反馈能任意配置极点的充要条件
本卷实例
  • 关键一步：由状态反馈改变闭环特征值，前提是系统完全能控
  • 中间结果：极点配置不改变能控性，但可能改变能观性
  • 卡点：把可镇定或完全能观误当成任意配置极点的充要条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过判断状态反馈能任意配置极点的充要条件
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
公式
超前校正 系统校正
本卷考法
  • 判断超前校正对截止频率与带宽的影响
本卷实例
  • 关键一步：超前校正提高相角裕度，使截止频率与带宽都增大
  • 中间结果：超前校正用中高频段幅值换取快速性
  • 卡点：把超前与滞后对截止频率的影响记反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过判断超前校正对截止频率与带宽的影响
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
公式
滞后校正 系统校正
本卷考法
  • 判断滞后校正对截止频率与带宽的影响
本卷实例
  • 关键一步：滞后校正以降低截止频率换取相角裕度，带宽随之减小
  • 中间结果：滞后校正改善稳态精度但牺牲快速性
  • 卡点：以为滞后校正也会增大带宽
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过判断滞后校正对截止频率与带宽的影响
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响
常见易错
  • 把滞后网络的两个转折频率顺序写反
  • 转折频率取得过高导致相位滞后抵消了增益改善

参数稳定域的确定 稳定性分析
本卷考法
  • 求使闭环系统稳定的最大增益
本卷实例
  • 关键一步：由结构图写闭环特征式，用劳斯首列全正或临界条件求临界增益
  • 中间结果：临界增益处系统出现在虚轴上的闭环极点
  • 卡点：稳定性选项以图给出，须回原卷核对开环结构与参数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求使闭环系统稳定的最大增益
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 辨析峰值时间、上升时间与超调量的定义
本卷实例
  • 关键一步：峰值时间为首次到达第一个峰值的时间，上升时间按终值百分比定义
  • 中间结果：超调量公式只对典型欠阻尼二阶成立，非典型系统须按实际响应算
  • 卡点：把上升时间与调节时间的定义搞混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过辨析峰值时间、上升时间与超调量的定义
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
稳定裕度 频域分析
本卷考法
  • 判断用相角裕度与幅值裕度表示稳定的条件
本卷实例
  • 关键一步：最小相位系统稳定要求相角裕度大于零且幅值裕度大于一
  • 中间结果：幅值裕度用绝对值大于一或分贝大于零来表示
  • 卡点：把两个裕度的判别方向记反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过判断用相角裕度与幅值裕度表示稳定的条件
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式

二二、系统等幅振荡与主导极点20 分#

思路
  • 先由劳斯判据求等幅振荡增益，再分析斜坡无差的参数关系，最后用闭环主导极点估算超调量与调节时间
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据确定系统产生等幅振荡时的增益
本卷实例
  • 关键一步：列劳斯表，令某行首列元素为零并写出辅助方程
  • 中间结果：辅助方程的根即为等幅振荡频率对应的纯虚根
  • 卡点：只令首列为零而不解辅助方程，读不出振荡频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据确定系统产生等幅振荡时的增益
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 说明等幅振荡点与根轨迹和虚轴交点的对应关系
本卷实例
  • 关键一步：等幅振荡对应根轨迹与虚轴的交点，该点增益为临界增益
  • 中间结果：交点频率即等幅振荡的角频率
  • 卡点：把等幅振荡与不稳定发散相混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过说明等幅振荡点与根轨迹和虚轴交点的对应关系
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 分析使系统成为一阶无差系统的参数关系
本卷实例
  • 关键一步：由误差传函分子在原点的零点条件确定型别与参数关系
  • 中间结果：斜坡输入无差要求误差传函在原点有二重零点
  • 卡点：只数积分环节个数，忽略参数还需满足关系式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过分析使系统成为一阶无差系统的参数关系
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 用闭环主导极点估算超调量与调节时间
本卷实例
  • 关键一步：先判断非主导极点实部是否远大于主导极点，再按二阶公式估算
  • 中间结果：主导极点对离虚轴最近，其余极点影响可近似忽略
  • 卡点：忽略零点或远极点对超调量的放大作用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过用闭环主导极点估算超调量与调节时间
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
欠阻尼动态性能指标 时域响应与动态性能

  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过由频率特性判断对给定频率正弦噪声的抑制能力
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

奈奎斯特判据 稳定性分析
本卷考法
  • 由开环传函绘制奈氏曲线并判断稳定性
本卷实例
  • 关键一步：令 s 等于 jω 算关键频率点，注意非最小相位环节的相角
  • 中间结果：判稳需先数开环右半平面极点数再看包围圈数
  • 卡点：开环含积分环节时未补画无穷大半径圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过由开环传函绘制奈氏曲线并判断稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

根轨迹的绘制法则 根轨迹法
本卷考法
  • 由反求的开环传函绘制根轨迹并判断形状
本卷实例
  • 关键一步：求开环零点极点、渐近线与分离点，判断复数分支形状
  • 中间结果：两极点一零点时复数分支为圆弧或直线

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角

  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过由反求的开环传函绘制根轨迹并判断形状
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
