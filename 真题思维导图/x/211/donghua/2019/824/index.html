一一、水位控制系统建模与结构图25 分#

思路
  • 由各环节的增益与传函先画系统结构图，再求前向通道、开环与闭环传函，最后按型别判断阶跃无静差
直流电机等机电系统 建模与机电系统
本卷考法
  • 由直流电动机、阀门与水箱环节分别求传递函数
本卷实例
  • 关键一步：把电机、阀门、水箱各自写成时间常数与增益形式
  • 中间结果：检测装置增益带负号进入比较点
  • 卡点：机电时间常数与电气时间常数不要混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由电枢回路电压方程与转矩平衡方程联立
  • 反电动势与转速成正比，电磁转矩与电枢电流成正比
  • 机电时间常数由电气与机械两方面参数共同决定
步骤
  • 写出电枢回路电压平衡方程
  • 写出转矩平衡方程（含负载与粘性摩擦）
  • 消去电枢电流，得到转速或转角对电压的传递函数
通用考法
  • 本卷考过由直流电动机、阀门与水箱环节分别求传递函数
  • 求直流电机转速或位置对电枢电压的传递函数
  • 分析机电时间常数与电气时间常数的数量级关系
常见易错
  • 本卷考过漏掉反电动势与电磁转矩的耦合项
  • 漏掉反电动势与电磁转矩的耦合项
  • 把电气时间常数与机电时间常数混淆

二二、稳态误差与调节器选择10 分#

思路
  • 按指令减输出定义误差并写误差传函，先算给定增益下的阶跃稳态误差，再由误差为零的要求选取调节器
误差定义与误差传递函数 稳态误差
本卷考法
  • 按指令减输出定义误差并写出误差传函
本卷实例
  • 关键一步：由结构图把误差表示成输入信号的传函
  • 中间结果：误差传函的分母为一加开环传函
  • 卡点：未判稳就直接用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过按指令减输出定义误差并写出误差传函
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 本卷考过非单位反馈时两种误差定义混用
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

典型输入下的稳态误差计算 稳态误差
本卷考法

本卷实例

  • 中间结果：零型系统的阶跃误差为有限值
  • 卡点：输入含多个分量时不能只算一段
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法

  • 求给定输入下的稳态误差

  • 比较不同型别系统的跟踪能力

  • 本卷考过把静态位置误差系数与增益混为一谈
  • 未判稳就使用终值定理

减小稳态误差的措施 稳态误差
本卷考法
  • 选择调节器使阶跃输入的稳态误差为零
本卷实例
  • 关键一步：引入积分环节把系统提高一个型别
  • 中间结果：调节器含原点极点即可消去阶跃误差
  • 卡点：单纯提高增益无法把有限误差降为零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过选择调节器使阶跃输入的稳态误差为零
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 本卷考过只加大增益却未检查稳定性是否被破坏
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

参数稳定域的确定 稳定性分析
本卷考法

  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定

  • 比较不同参数对稳定域大小的影响

  • 只列出部分首列元素的不等式，漏掉某个约束

四四、调速系统控制器与根轨迹校正25 分#

思路
  • 按阻尼比、超调量与峰值时间定主导极点并选控制器形式，再讨论比例、比例积分与超前校正的适用性
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由阻尼比、超调量与峰值时间确定主导极点
本卷实例

  • 卡点：指标之间可能互相矛盾需先判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法

  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错

  • 只满足单项指标就下结论，未做交叉验证
