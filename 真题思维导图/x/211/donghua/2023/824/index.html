一选择题：极点配置、校正装置与稳定性#

思路
  • 四道选择覆盖极点配置的影响、有源校正装置识别、线性定常系统稳定性的决定因素与幅相曲线对应传函
状态反馈与极点配置 状态空间分析
本卷考法
  • 判断配置极点会直接影响系统的哪些性质
本卷实例
  • 关键一步：由状态反馈改变 A 减 B K 的特征值来实现极点配置
  • 中间结果：极点配置不改变能控性，但可能改变能观性
  • 卡点：配置极点的目的是改变稳定性而不是可观性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法

  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响

  • 未验证能控性就直接做极点配置

劳斯判据 稳定性分析
本卷考法
  • 说明线性定常系统的稳定性由什么因素决定
本卷实例

  • 中间结果：稳定性只取决于系统自身的结构与参数
  • 卡点：稳定性与参考输入、初始条件和外部扰动都无关
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤

  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法

  • 系数有缺项时不补零，直接套用判据

  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤

  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法

本卷考法

本卷实例

  • 中间结果：由对照得到阻尼比、自然频率以及与相位角的对应关系
  • 卡点：响应式中的相位角与阻尼比有固定关系，不是自由参数

  • β=arccos ξ 是极点与负实轴的夹角

  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法

传递函数的定义与基本性质 传递函数
本卷考法
  • 由阻尼比与自然频率写出开环与闭环传递函数
本卷实例

  • 中间结果：闭环特征式为 s 平方加二倍阻尼乘自然频率乘 s 加一
  • 卡点：开环传函要写成含自然频率平方与阻尼项的典型形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤

  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法

  • 忽略“零初始条件”这一前提，把初始值带进变换结果
