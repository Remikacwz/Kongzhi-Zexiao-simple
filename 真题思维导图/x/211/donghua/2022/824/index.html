一选择题：稳定性、校正与传递函数#

思路
  • 七道选择覆盖卷积求响应、稳定性含义、校正与增益、稳定裕度、稳态误差、纯滞后与传递函数适用性
传递函数的定义与基本性质 传递函数
本卷考法
  • 用卷积运算说明线性定常系统对任意输入响应的求法
  • 说明传递函数被广泛采用的原因
本卷实例
  • 关键一步：指出卷积求响应成立的前提是系统线性定常
  • 中间结果：线性定常系统的输出等于脉冲响应与输入的卷积
  • 卡点：非线性或时变系统不满足叠加原理，不能用卷积
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过用卷积运算说明线性定常系统对任意输入响应的求法
  • 本卷考过说明传递函数被广泛采用的原因
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过把卷积法用于非线性或时变系统
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

劳斯判据 稳定性分析
本卷考法
  • 判断关于控制系统稳定性的正确表述
本卷实例
  • 关键一步：由稳定性定义看响应的自由分量是否随时间衰减
  • 中间结果：稳定系统的响应与初始条件无关，最终趋于受迫分量
  • 卡点：稳定不等于无静差，有静差系统仍可稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过判断关于控制系统稳定性的正确表述
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过把稳定与稳态误差趋近于零混为一谈
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

校正的基本概念与性能指标 系统校正
本卷考法
  • 在快速性与稳定性达标但控制精度欠佳时选择合适措施
本卷实例
  • 关键一步：分析增大开环增益对稳态误差与相角裕度的双重影响
  • 中间结果：超前与滞后校正都提高相角裕度，反而降低开环增益
  • 卡点：要求提高精度时应继续增大开环增益而不是加校正
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 串联校正、反馈校正与复合校正是三种基本形式
  • 时域指标与频域指标存在对应关系
  • 校正通常以相角裕度、开环增益与穿越频率为目标
步骤
  • 由指标要求确定目标相角裕度与穿越频率
  • 画出未校正系统的 Bode 图
  • 比较未校正特性与目标要求的差距
  • 选择校正方式并计算校正装置参数
通用考法
  • 本卷考过在快速性与稳定性达标但控制精度欠佳时选择合适措施
  • 说明串联校正与反馈校正的适用场合
  • 把时域指标折算为频域指标
  • 分析未校正系统的主要缺陷
常见易错

  • 把截止频率与相位穿越频率混用
  • 只盯相角裕度而忽略带宽要求

减小稳态误差的措施 稳态误差
本卷考法
  • 判断哪种措施不能减小稳态误差
本卷实例
  • 关键一步：逐个分析积分、增益与微分环节对稳态误差的作用
  • 中间结果：增加积分环节与提高开环增益可减小或消除稳态误差
  • 卡点：微分环节属高通作用，改善动态但不影响稳态误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过判断哪种措施不能减小稳态误差
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 本卷考过只谈误差减小而不检查稳定性是否被破坏
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

稳定裕度 频域分析
本卷考法
  • 判断频域稳定裕度在时域中对应哪个量
本卷实例
  • 关键一步：由相角裕度与谐振峰值的近似关系联系时域指标
  • 中间结果：相角裕度决定谐振峰值，进而影响超调量
  • 卡点：稳定裕度对应超调量，不是调节时间或稳态误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过判断频域稳定裕度在时域中对应哪个量
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 本卷考过把相角裕度与幅值裕度的作用搞混
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

含纯延迟环节的系统稳定性 稳定性分析
本卷考法
  • 说明纯滞后环节对闭环系统稳定性不利的原因
本卷实例
  • 关键一步：分析纯滞后环节的相位滞后随频率线性增大
  • 中间结果：纯滞后模长恒为一，只带来相位滞后不衰减幅值
  • 卡点：纯滞后是线性环节，选项说它非线性是错的
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 延迟环节 e^{-τs} 的幅值为 1、相位为 -τω，只恶化相位
  • 延迟会显著缩小稳定域，τ 越大越难稳定
  • 频域判据需用相位裕度扣除延迟引起的附加滞后
步骤
  • 写出含延迟的开环传递函数
  • 分别求幅值与相位表达式
  • 在相频特性中扣除 τω 的滞后量
  • 按稳定裕度或奈氏判据求临界 τ 或临界 K
通用考法
  • 本卷考过说明纯滞后环节对闭环系统稳定性不利的原因
  • 求使系统稳定的最大延迟时间

  • 分析延迟对稳定裕度的影响
常见易错
  • 本卷考过把延迟环节当成惯性环节处理
  • 把延迟环节当成惯性环节处理

本卷考法

本卷实例

  • 中间结果：原系统闭环阻尼比与自然频率由两个指标联立确定
  • 卡点：反求要用闭环指标，不要误用开环参数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤

  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
