一简答题：根轨迹、稳定性与基本概念#

思路

根轨迹的绘制法则 根轨迹法
本卷考法
  • 用渐近线夹角与交点的变化说明增加开环零极点对稳定性的影响
本卷实例
  • 关键一步：先写出渐近线夹角与交点公式，再看零极点增减如何改变它们
  • 中间结果：增加左半平面零点使渐近线左移、条数减少
  • 卡点：增加正实部零点时根轨迹未必向左，要分情况讨论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过用渐近线夹角与交点的变化说明增加开环零极点对稳定性的影响
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过渐近线夹角公式中的 2k+1 写成 2k
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

附加开环零极点的影响 根轨迹法
本卷考法
  • 说明增加开环零点或极点分别对闭环稳定性的影响
本卷实例
  • 关键一步：分别讨论增加零点和增加极点后根轨迹的走向
  • 中间结果：零点使根轨迹向左弯曲、极点使根轨迹向右弯曲
  • 卡点：零点若在右半平面，结论会反转，必须看零点位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法

  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 本卷考过把附加零点与附加极点的影响搞反
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
参数稳定域的确定 稳定性分析
本卷考法
  • 判断开环增益 K 与时间常数 T 变化时系统是否会引起不稳定
本卷实例

  • 中间结果：原系统在 K、T 为正实数时恒稳定，与取值无关
  • 卡点：原卷此题传函有 OCR 讹字，写结论需回原卷核对

含纯延迟环节的系统稳定性 稳定性分析
本卷考法
  • 分析加入纯延迟环节后 K、T 变化对闭环稳定性的影响
本卷实例
  • 关键一步：由幅值条件求剪切频率，再代入相角条件算相角裕度
  • 中间结果：延迟使相角随频率线性滞后，裕度随 K 增大而减小
  • 卡点：角度与弧度换算不能混；题面有讹字需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 延迟环节 e^{-τs} 的幅值为 1、相位为 -τω，只恶化相位
  • 延迟会显著缩小稳定域，τ 越大越难稳定
  • 频域判据需用相位裕度扣除延迟引起的附加滞后
步骤
  • 写出含延迟的开环传递函数
  • 分别求幅值与相位表达式
  • 在相频特性中扣除 τω 的滞后量
  • 按稳定裕度或奈氏判据求临界 τ 或临界 K
通用考法
  • 本卷考过分析加入纯延迟环节后 K、T 变化对闭环稳定性的影响
  • 求使系统稳定的最大延迟时间
  • 求含延迟系统的临界开环增益
  • 分析延迟对稳定裕度的影响
常见易错
  • 本卷考过把延迟环节当成惯性环节处理
  • 把延迟环节当成惯性环节处理
  • 相位计算时忘记角度与弧度换算

PID 控制器与参数整定 系统校正
本卷考法
  • 说明 PI 控制器对系统型别、稳态与动态性能的作用
本卷实例
  • 关键一步：指出 PI 在原点加极点、在左半平面加零点，提升系统型别
  • 中间结果：积分提高稳态精度，零点缓和极点对稳定性的不利影响
  • 卡点：PI 会降低相角裕度，要与滞后校正的作用区分开
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法

  • 说明微分项对噪声的影响
常见易错

  • 把 PI 的相位影响说成超前

滞后校正 系统校正
本卷考法
  • 比较滞后校正与 PI 控制器对动、静态性能改变效果的不同
本卷实例
  • 关键一步：比较两者对系统型别、截止频率与相角裕度的不同作用
  • 中间结果：滞后校正靠高频衰减降低截止频率并提高相角裕度
  • 卡点：PI 提升型别，滞后校正不改变型别，效果并不一样
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 滞后校正利用高频段幅值衰减提高相角裕度
  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数
通用考法
  • 本卷考过比较滞后校正与 PI 控制器对动、静态性能改变效果的不同
  • 设计串联滞后校正装置
  • 比较超前与滞后校正的效果差异
  • 分析滞后校正对响应速度的影响

  • 把滞后网络的两个转折频率顺序写反

  • 首列出现 0 时需用 ε 法或乘辅助多项式处理

  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数

思路

梅森增益公式与信号流图 传递函数
本卷考法
  • 由多回路结构图数出前向通路与回路，用梅森公式求传递函数
本卷实例

  • 中间结果：特征式等于一减各回路和加两两不接触回路积
  • 卡点：两条回路相互接触时不能计入不接触组

  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项

  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输

  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路

误差定义与误差传递函数 稳态误差
本卷考法
  • 在同一结构图上求误差对输入的传递函数 E(s)/R(s)
本卷实例
  • 关键一步：把误差点当作输出，另数一条前向通路求 E 对 R 的传函
