一一、由无源电路求传递函数#

思路
  • 按复阻抗法对无源电路列节点或回路方程，消去中间量求 uo/ui 的传函
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由无源电路求输出电压对输入电压的传函
本卷实例
  • 关键一步：用复阻抗把电路化成纯代数网络
  • 中间结果：按分压或节点方程消去中间电压
  • 卡点：电路图为扫描图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由无源电路求输出电压对输入电压的传函
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过电容与电感复阻抗形式写混
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式

本卷考法

  • 中间结果：无源网络只需基尔霍夫定律

思路

梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图用梅森公式求闭环传递函数
本卷实例
  • 关键一步：先列全回路再列前向通路
  • 中间结果：特征式含单一回路项与两两乘积项
  • 卡点：结构图为扫描图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤

  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法

  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过互不接触回路找漏或重复计数
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

三三、由动态指标求闭环极点可行域10 分#

思路
  • 把峰值时间、超调量与调节时间要求翻译成阻尼比与实部虚部约束，在复平面画出极点可行域并取一组参数
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由峰值时间超调量与调节时间求参数可行域
本卷实例
  • 关键一步：把三个时域指标分别写成阻尼比与实部约束
  • 中间结果：可行域由等阻尼线与等实部线围成
  • 卡点：取值范围边界是否取等需按题意
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由峰值时间超调量与调节时间求参数可行域
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 本卷考过只满足单项指标就下结论未交叉验证
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 用欠阻尼公式把峰值时间与超调量写成参数关系
本卷实例
  • 关键一步：先由超调量定阻尼比再由峰值时间定自然频率
  • 中间结果：调节时间只约束闭环极点实部
  • 卡点：三条边界线要分别画在复平面上
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过用欠阻尼公式把峰值时间与超调量写成参数关系
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过峰值时间与上升时间混用
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

四四、根轨迹与超前校正器25 分#

思路
  • 先按常规方法画根轨迹，再加入超前校正器重画，最后用虚轴交点求稳定增益范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画含开环零点系统的根轨迹
本卷实例
  • 关键一步：先标零极点再定实轴段与渐近线
  • 中间结果：根轨迹起始于开环极点终止于零点或无穷远
  • 卡点：校正前后根轨迹对比需按图确认
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画含开环零点系统的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过渐近线条数与夹角算错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
超前校正 系统校正
本卷考法
  • 说明超前校正器对根轨迹与稳定性的影响
本卷实例
  • 关键一步：把校正器零点与极点分别加进开环传函
  • 中间结果：附加零点把根轨迹向左拉
  • 卡点：校正器参数需使闭环极点落在期望位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过说明超前校正器对根轨迹与稳定性的影响
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 本卷考过超前角与截止频率变化带来的相角损失算漏
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反
