一一、由闭环极点反求开环传递函数15 分#

思路
  • 由闭环特征值之和与积反推开环传函的极点配置，再写成时间常数形式
传递函数的定义与基本性质 传递函数
本卷考法
  • 由闭环极点与开环零点反写开环传递函数
本卷实例
  • 关键一步：写出期望闭环特征多项式并与特征值对应
  • 中间结果：由二阶型别确定开环含两个积分环节
  • 卡点：题目给的是三阶二型，型别决定分母幂次
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由闭环极点与开环零点反写开环传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过时间常数形式与尾一形式互换时系数写错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
零极点分布与响应模态 传递函数
本卷考法
  • 用闭环极点分布反推开环零极点并校核增益
本卷实例
  • 关键一步：由闭环极点与已知开环零点配齐开环极点
  • 中间结果：开环极点总和由特征值之和约束
  • 卡点：需回代闭环特征方程验证
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 极点决定响应由哪些模态组成，零点决定各模态的权重
  • 左半平面极点对应衰减，右半平面对应发散，虚轴对应等幅振荡
  • 离虚轴最近的极点为主导极点，主导响应的形状
  • 共轭复极点产生振荡，实极点产生单调分量
步骤
  • 求特征方程得到全部闭环极点
  • 按实数/共轭复数分类，写出对应模态
  • 找出主导极点对，近似为低阶系统
  • 结合零点判断各模态权重大小
通用考法
  • 本卷考过用闭环极点分布反推开环零极点并校核增益
  • 由极点分布写出响应的大致形式
  • 判断系统是单调还是振荡、是否收敛
  • 用主导极点概念把高阶系统近似为二阶系统
常见易错
  • 本卷考过把闭环极点直接当成开环极点
  • 只看极点分布就断定振荡，忽略零点引起的模态权重为零

二二、由阶跃响应求传函与脉冲响应10 分#

思路
  • 由阶跃响应分离稳态项与暂态项，反求传递函数，再作拉氏逆变换得脉冲响应
由响应曲线反求传递函数 传递函数
本卷考法
  • 由给定阶跃响应解析式反求系统传递函数
本卷实例
  • 关键一步：先分离响应的稳态分量与暂态分量
  • 中间结果：暂态指数项对应闭环极点
  • 卡点：需保证所求传函在零初始条件下成立
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由给定阶跃响应解析式反求系统传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 本卷考过把稳态值当增益而漏掉输入幅值
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由传函求单位脉冲响应并说明零状态条件
本卷实例
  • 关键一步：单位脉冲响应对应传函的拉氏逆变换
  • 中间结果：部分分式展开后逐项取逆变换
  • 卡点：响应表达式含常数项需按初值定理确认
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由传函求单位脉冲响应并说明零状态条件
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 本卷考过只求零状态响应而漏掉由初值决定的自由响应
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

三三、由超调量反求系统增益10 分#

思路
  • 由最大超调量先求阻尼比，再由增益与阻尼比关系反解另一超调量对应的增益
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由开环增益与阻尼比关系建立超调量方程
本卷实例
  • 关键一步：写出闭环特征方程并化为标准二阶形式
  • 中间结果：阻尼比与开环增益存在单调对应
  • 卡点：参数定义须按题中所给开环传函确认
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由开环增益与阻尼比关系建立超调量方程
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过开环增益误当成闭环传函系数
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由两个超调量条件联立反求所需增益
本卷实例
  • 关键一步：先由首个超调量定出参考增益关系
  • 中间结果：再用第二个超调量反解阻尼比
  • 卡点：增益解需为正且系统稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由两个超调量条件联立反求所需增益
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 本卷考过只满足一个条件未检查另一条件
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

思路
  • 由结构图求开环传函，按型别算加速度误差系数，再用劳斯判据求参数稳定范围
系统型别与静态误差系数 稳态误差
本卷考法

本卷实例
  • 关键一步：先数开环积分环节个数定系统型别
  • 中间结果：加速度误差系数由开环传函低频渐近决定

  • 把开环增益与静态误差系数混为一谈

六六、三阶系统根轨迹与稳定范围20 分#

思路

根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画三阶无零点根轨迹
本卷实例
  • 关键一步：先标开环极点并算渐近线
  • 中间结果：三条渐近线夹角为六十度与一百八十度
