一一、由结构图求传递函数15 分#

思路
  • 按方框图先化简内环与并联支路，再用梅森公式求 C(s)/R(s)
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式列回路与前向通路求闭环传函
本卷实例
  • 关键一步：数清 5 个回路与 2 条前向通路再写特征式
  • 中间结果：各回路增益分别带负号相加得特征式
  • 卡点：结构图为扫描图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式列回路与前向通路求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过互不接触回路漏算导致特征式少项
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 逐层化简多回路结构图并与梅森结果互验
本卷实例
  • 关键一步：先合并最内层反馈环再串并联合并
  • 中间结果：化简结果与梅森式结构一致
  • 卡点：合并顺序不同易漏交叉反馈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过逐层化简多回路结构图并与梅森结果互验
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过化简内环时误把外环信号当常数
  • 化简内环时把外环的信号当成常数处理

二二、由运算电路求传递函数15 分#

思路
  • 按虚短虚断列两个运放级联的复阻抗方程，消去中间电压得 C(s)/R(s)
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由两级运算放大器电路求输入输出传函
本卷实例
  • 关键一步：对每一级运放分别用虚短虚断写约束式
  • 中间结果：第一级输出为反相积分形式
  • 卡点：电路拓扑为扫描图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由两级运算放大器电路求输入输出传函
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过电容复阻抗写错或漏掉反相端负号
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 借位：把运算电路归入有源网络建模
本卷实例
  • 关键一步：先写出级间电压再用第二级约束消去
  • 中间结果：化简后得到含一个积分的二阶传函
  • 卡点：需按图中反馈电容确定积分时间常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过借位：把运算电路归入有源网络建模
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 本卷考过忽略两级运放之间的负载效应
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

三三、复合控制与前馈补偿的稳态误差20 分#

思路
  • 先判稳再算无前馈时的斜坡误差，加入前馈后重算，最后由抛物线误差终值为零定参数
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 分别求单位斜坡输入下加前馈前后的稳态误差
本卷实例
  • 关键一步：先由开环传函判断型别与稳定性
  • 中间结果：无前馈时误差由速度误差系数决定
  • 卡点：误差定义取在输入端，需按题意确认
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过分别求单位斜坡输入下加前馈前后的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过未判稳就直接用终值定理
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 由抛物线输入下误差终值为零反求前馈参数
本卷实例
  • 关键一步：写出含前馈的误差传函再取极限
  • 中间结果：令极限分子常数与二次项同时为零
  • 卡点：两参数需联立两个条件才能定出
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过由抛物线输入下误差终值为零反求前馈参数
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 本卷考过只列误差表达式未令其极限为零
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式
反馈校正与复合控制 系统校正
本卷考法
  • 说明前馈补偿器如何实现给定信号不变性
本卷实例
  • 关键一步：比较加前馈前后误差传函的零点变化
  • 中间结果：合适前馈可抵消原系统误差主导项
  • 卡点：前馈只改误差通道，不影响稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过说明前馈补偿器如何实现给定信号不变性
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 本卷考过把前馈写成含高阶微分形式却不检查可实现性
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
公式

四四、二阶系统参数与暂态指标20 分#

思路
  • 由闭环传函对照二阶标准式读参数；按公式算超调与调节时间；再由超调要求反解增益
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由给定 K、T 求阻尼比与自然频率
本卷实例
  • 关键一步：把闭环传函化为二阶标准形式
  • 中间结果：一次项系数对应 2ζωn，常数项对应 ωn 平方
  • 卡点：系统结构为扫描图，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由给定 K、T 求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过未把闭环传函首项系数归一化
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由 ζ 与 ωn 计算超调量和调节时间
本卷实例
  • 关键一步：先算阻尼振荡频率再套动态指标公式
  • 中间结果：超调量只与阻尼比有关
  • 卡点：调节时间要注明所取误差带
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由 ζ 与 ωn 计算超调量和调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过两种误差带的调节时间系数混用
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量要求反求满足条件的开环增益
本卷实例
  • 关键一步：由超调量反解所需阻尼比
  • 中间结果：阻尼比与增益满足单调关系
  • 卡点：解出的增益需回代验证稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量要求反求满足条件的开环增益
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 本卷考过反解时把阻尼比与增益关系方向搞反
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

五五、两系统稳定性判别14 分#

思路
  • 分别写出两图的特征方程，用劳斯判据判断首列符号或直接解根位置
劳斯判据 稳定性分析
本卷考法
  • 对两个系统分别列劳斯表判别稳定性
本卷实例
  • 关键一步：由方框图写出各自的开环传函与特征方程
  • 中间结果：第一系统首列全正故稳定
  • 卡点：第二系统含正反馈内环，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过对两个系统分别列劳斯表判别稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过系数缺项时不补零直接排表
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由内环正负反馈等效简化再列特征方程
本卷实例
  • 关键一步：先化简内环求等效开环传函
  • 中间结果：等效特征方程出现负系数项
  • 卡点：内环反馈极性需按原图确认
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由内环正负反馈等效简化再列特征方程
  • 多环节系统求闭环传递函数
