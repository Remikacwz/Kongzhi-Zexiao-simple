1一、李雅普诺夫稳定性概念与红绿灯控制方式#

思路
  • 两小问：(1)纯概念，要求用 ε-δ 语言说清李雅普诺夫意义下稳定与渐近稳定的定义差异；(2)开放应用题，要求从控制方式角度陈述分时段定时控制与相邻路口协调控制两类方案
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 简述李雅普诺夫意义下稳定与渐近稳定的定义与区别
本卷实例
  • 关键一步：用 ε-δ 语言叙述稳定：初值充分靠近平衡点，轨线始终不越出给定邻域
  • 关键一步：渐近稳定在稳定基础上再加一条：t 趋于无穷时轨线收敛到平衡点
  • 中间结果：稳定只保证轨线有界，渐近稳定才要求收敛到平衡点
  • 卡点：把稳定与渐近稳定当成一回事，忽略稳定并不要求收敛
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过简述李雅普诺夫意义下稳定与渐近稳定的定义与区别
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数
公式
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 从控制方式角度陈述两类红绿灯控制方案
本卷实例
  • 关键一步：定时控制：按高峰、平峰、低谷事先整定各方向绿灯时长，属按时间表的开环控制
  • 关键一步：协调控制：测量两路口间车辆平均通行时间并据此调整配时，实现主干道绿波
  • 中间结果：分时段方案改变的是绿灯时长这一控制量；协调方案靠相位差把相邻路口配时联动
  • 卡点：题面称当前路口绿灯则下一路口也绿灯，答案却按红灯对红灯作答，两处口径不一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过从控制方式角度陈述两类红绿灯控制方案
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

2二、能控性与能观性判据#

思路
  • 两小问：先用约当/对角规范型的直接判据逐块判断能控能观，再用秩判据求二阶层面的能控且能观条件
能控性与能观性 状态空间分析
本卷考法
  • 用规范型直接判据判断约当型与对角型状态变量的能控性与能观性
  • 用能控性、能观性矩阵的秩判断系统在什么条件下能控且能观
本卷实例
  • 关键一步：第一问按块判：约当块看 B 的末行、C 的首列，对角块看 B 各行与 C 各列是否为零
  • 关键一步：第二问分别构造 Qc=[b Ab] 与 Qo=[c; cA]，令两行列式同时非零
  • 中间结果：各块先分别得出能控能观结论，再看是否所有块同时满足
  • 中间结果：第二问的能控能观条件化为 Qc、Qo 两个二阶行列式均不为零
  • 卡点：第一问只看 B 末行不看 C 首列，会漏判不能观
  • 卡点：A、B、C 两源 OCR 均有错位，具体元素需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过用规范型直接判据判断约当型与对角型状态变量的能控性与能观性
  • 本卷考过用能控性、能观性矩阵的秩判断系统在什么条件下能控且能观
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

3三、状态反馈极点配置、全维观测器与分离定理#

思路
  • 同一三阶对象两小问：能控标准型下直接用系数差求状态反馈 K；再由 A−LC 特征式比对求观测器 L；最后简述分离定理
状态反馈与极点配置 状态空间分析
本卷考法
  • 由期望闭环极点确定状态反馈增益阵 K
本卷实例
  • 关键一步：对象已是能控标准型，可直接设 K=[k1 k2 k3] 并写 det(λI−A+bK)
  • 关键一步：把期望极点多项式 (λ+4)[(λ+1)²+3] 展开，与原特征式同幂系数比对
  • 中间结果：K 各分量等于期望特征式系数减原特征式对应系数
  • 卡点：特征多项式比较系数时符号写反；未确认能控就直接配极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过由期望闭环极点确定状态反馈增益阵 K
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
公式
状态观测器设计 状态空间分析
本卷考法
  • 设计全维观测器使特征值均为 −2
  • 简述分离定理的意义
本卷实例
  • 关键一步：观测器误差动态由 A−LC 决定，先写出 det(sI−A+LC)
  • 关键一步：把期望特征式 (s+2)³ 与它逐项比对解出 L
  • 关键一步：分离定理：系统能控能观时，极点配置与观测器设计可独立进行
  • 中间结果：L 只经输出矩阵 C 作用于误差动态，不改变输入通路
  • 卡点：把观测器增益 L 写成状态反馈增益 K 的形式
  • 卡点：先算能观性矩阵确认能观，再设计观测器
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态观测器用输出与输入重构状态，前提是系统能观
  • 极点配置法与龙伯格观测器是两种常用形式
  • 观测器误差动态由 A-LC 的特征值决定
  • 观测器极点通常取得比系统极点快若干倍
步骤
  • 验证系统能观性
  • 写出观测器方程并求误差动态矩阵
  • 按期望特征多项式比较系数求出 L
  • 校验观测器收敛速度是否合适
通用考法
  • 本卷考过设计全维观测器使特征值均为 −2
  • 本卷考过简述分离定理的意义
  • 设计全维状态观测器
  • 由期望观测器极点求反馈增益阵 L
  • 分析观测器与状态反馈组合后的系统极点
常见易错
  • 把观测器增益阵写成了状态反馈增益阵的形式
  • 忽略观测器极点过快会放大噪声

4四、劳斯判据与极点左移约束10 分#

思路
  • 开环 K/[s(0.1s+1)(0.25s+1)]，要求所有闭环特征根在 s=−1 左侧，需先作坐标平移再用劳斯判据
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据确定使全部闭环特征根位于 s=−1 左侧的 K 范围
本卷实例
  • 关键一步：先写出闭环特征式 D(s)=s(0.1s+1)(0.25s+1)+K 并整理成多项式
  • 关键一步：作坐标平移 s=s1−1，把特征根在 −1 左侧化为 s1 的稳定问题
  • 关键一步：对平移后多项式列劳斯表，令首列各元素同号
  • 中间结果：平移后特征式仍含待定 K，劳斯表首列元素也含 K
  • 卡点：平移时代数式整理易错；漏掉劳斯表首列中某个含 K 的约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据确定使全部闭环特征根位于 s=−1 左侧的 K 范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由劳斯表首列不等式求参数 K 的取值范围
本卷实例
  • 关键一步：把劳斯表首列每个元素都写成关于 K 的代数式，令其全部大于零
  • 关键一步：联立这些不等式取交集，得 K 的开区间
  • 中间结果：上下界分别来自首列两个不同的含 K 元素
  • 卡点：只列一个约束就下结论；端点是否包含判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由劳斯表首列不等式求参数 K 的取值范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

5五、静态误差系数与稳态误差10 分#

思路
  • 开环 1/[s(0.1s+1)]，先判稳再求三类静态误差系数，最后对组合输入 a0+a1 t+a2 t²/2 求各分量与总误差
系统型别与静态误差系数 稳态误差
本卷考法
  • 求系统的静态位置、速度、加速度误差系数 Kp、Kv、Ka
本卷实例
  • 关键一步：先由闭环特征式判断系统稳定，再按型别求三个静态误差系数
  • 关键一步：三个系数分别取 s→0 时 G、sG、s²G 的极限
  • 中间结果：开环含一个积分环节属 I 型系统，Kp 发散、Ka 为零
  • 卡点：未判稳就套静态误差系数公式；把开环增益直接当成 Kv
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过求系统的静态位置、速度、加速度误差系数 Kp、Kv、Ka
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求组合输入下的各分量稳态误差与总稳态误差
本卷实例
  • 关键一步：组合输入按叠加原理拆成阶跃、斜坡、抛物线三项分别求误差
  • 关键一步：各分量分别用 a0/(1+Kp)、a1/Kv、a2/Ka 计算
  • 关键一步：任一非零分量发散则总稳态误差即为无穷
  • 中间结果：三项误差逐项对应静态误差系数，总误差是三项之和
  • 卡点：组合信号漏掉某一分量；I 型系统算阶跃误差时误用速度误差公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求组合输入下的各分量稳态误差与总稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

6六、梅森公式求传递函数20 分#

思路
  • 由结构图用梅森公式求 C/R：先列全部独立回路并判断两两不接触，再列前向通路及余子式
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图列出独立回路与前向通道，用梅森增益公式求闭环传递函数
本卷实例
  • 关键一步：先数清全部独立回路 L_i 及其增益，并找出两两互不接触的回路组合
  • 关键一步：再列每条前向通路 P_i，其余子式要剔除与该通路接触的回路
  • 关键一步：按 Δ=1−ΣL+ΣLL−… 与 C/R=ΣP_iΔ_i/Δ 组合
  • 中间结果：分母由全部回路及其不接触组合构成，分子是各前向通路乘余子式之和
  • 卡点：不接触回路找漏或重复；余子式未剔除接触回路

8八、奈奎斯特判据20 分#

思路
  • 开环 K(τs+1)/[s(Ts−1)]，含一个右半平面极点，需画奈氏曲线并分 τk 小于 1、大于 1、等于 1 讨论
奈奎斯特判据 稳定性分析
本卷考法
  • 画出 G(jω) 奈奎斯特曲线并用奈氏判据判断闭环稳定性
  • 用奈氏判据写出稳定、不稳定、临界稳定时 K 与 τ 的范围
本卷实例
  • 关键一步：先由开环传函数清右半平面极点数 P，含积分环节时在低频端补画无穷大圆弧
  • 关键一步：写出 |G(jω)| 与 ∠G(jω)，求曲线与负实轴交点及该处幅值
  • 关键一步：按包围 (−1,j0) 的圈数用 Z=P−2N 判断闭环右半平面极点数
  • 中间结果：曲线起点、终点趋势与穿越负实轴的位置是判稳关键
  • 中间结果：临界状态出现在曲线恰好通过 (−1,j0) 时
  • 卡点：积分环节未补画圆弧；包围圈数正负号搞反
  • 卡点：答案把该开环极点写成左半平面，与 P=1 矛盾，实为右半平面极点
  • 卡点：奈氏图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过画出 G(jω) 奈奎斯特曲线并用奈氏判据判断闭环稳定性
  • 本卷考过用奈氏判据写出稳定、不稳定、临界稳定时 K 与 τ 的范围

  • 求使闭环稳定的开环增益范围

  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

思路

滞后校正 系统校正
本卷考法
  • 设计串联滞后校正装置使系统满足稳态误差与相角裕度要求
本卷实例
  • 关键一步：先由斜坡稳态误差要求定出开环增益，再算未校正系统的截止频率与相角裕度
  • 关键一步：按相角裕度加补偿角定校正后截止频率，由 20lg b+20lg|G|=0 求 b
  • 关键一步：由 1/(bT) 取校正后截止频率的十分之一左右定时间常数 T
  • 中间结果：滞后网络 Gc=(bTs+1)/(Ts+1)，b 小于 1，两个转折频率一高一低
  • 卡点：滞后网络两个转折频率顺序写反；转折频率取高使相位滞后抵消增益改善
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 会使截止频率降低，响应变慢
  • 转折频率要远低于新的截止频率以免引入过多相位滞后
  • 可同时提高低频增益改善稳态精度
步骤
  • 确定满足相角裕度要求的新截止频率
  • 由未校正系统在该频率处的幅值确定衰减量
  • 由衰减量求滞后网络的参数 β
  • 取转折频率低于新截止频率一个数量级，写出传递函数

本卷考法
  • 求校正前后系统的截止频率与相角裕度并验证是否达标
本卷实例
  • 关键一步：在幅频 0 dB 处取截止频率，代入相频算 γ=180°+∠G(jωc)
