一(1)一(1)、状态空间线性变换与传函不变性#

思路
  • 考查坐标变换下状态空间表达式的形式变化，以及传递函数矩阵为什么不随之改变
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 写出状态向量线性变换 x=Px̄ 后的状态空间表达式
本卷实例
  • 关键一步：把 x=Px̄ 代入原方程，再左乘 P⁻¹ 消去 P
  • 关键一步：得到 Ā=P⁻¹AP、B̄=P⁻¹B、C̄=CP、D̄=D 四式
  • 关键一步：变换只改内部状态描述，不改输入输出关系
  • 中间结果：Ā 与 A 相似，特征值相同，所以稳定性判断不受变换影响
  • 卡点：把 P 的方向用反（写成 x̄=Px），四个矩阵全错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过写出状态向量线性变换 x=Px̄ 后的状态空间表达式
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消
公式
状态空间表达式的建立 状态空间分析
本卷考法
  • 证明变换后传递函数矩阵不变
本卷实例
  • 关键一步：直接算 C̄(sI−Ā)⁻¹B̄+D̄，核心是把逆矩阵展开
  • 关键一步：用 (sI−P⁻¹AP)⁻¹=P⁻¹(sI−A)⁻¹P 把 P 与 P⁻¹ 约掉
  • 中间结果：对 (sI−Ā)⁻¹ 用相似变换恒等式，写成 P⁻¹(sI−A)⁻¹P
  • 中间结果：代入后 P 与 P⁻¹ 首尾相消，只剩原系统的 C(sI−A)⁻¹B
  • 卡点：只写一句「相似变换不改变传递函数」而不给推导，证明题拿不到分
  • 卡点：宝典只在一(b)6分、二(2)7分、三(1)6分、三(2)12分等小问标分
  • 卡点：逐年源未标任何分值，两源出入，本卷板块分值一律留空
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过证明变换后传递函数矩阵不变
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

一(2)一(2)、李雅普诺夫稳定性的含义#

思路
  • 纯概念题，要求说清「李雅普诺夫意义下渐近稳定」与「大范围渐近稳定」两个定义的差别
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 简述李雅普诺夫意义下渐近稳定与大范围渐近稳定的含义
本卷实例
  • 关键一步：李雅普诺夫意义下稳定：初值充分靠近平衡点，解永远不跑出给定的邻域（有界）
  • 关键一步：渐近稳定：在稳定的基础上，t→∞ 时解收敛到平衡点
  • 关键一步：大范围渐近稳定：对状态空间的任意初始状态都渐近稳定（即吸引域是全空间）
  • 中间结果：稳定只保证有界；渐近稳定再加收敛到平衡点
  • 中间结果：大范围渐近稳定把吸引域扩大到整个状态空间
  • 卡点：把「稳定」与「渐近稳定」当成一回事——稳定只要求有界，不要求收敛
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过简述李雅普诺夫意义下渐近稳定与大范围渐近稳定的含义
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

二二、由闭环传函写微分方程与约当标准型#

思路
  • G(s)=(s²+5s−3)/((s−1)²(s+2))；先由分母写微分方程，再按重根拆成约当标准型
传递函数的定义与基本性质 传递函数
本卷考法
  • 由闭环传递函数写出常微分方程表达式
本卷实例
  • 关键一步：分母多项式对应各阶导数、分子多项式对应输入的导数组合，交叉相乘后还原
  • 中间结果：分母 (s−1)²(s+2) 展开为 s³−3s+2
  • 中间结果：分子 s²+5s−3，交叉相乘后两边阶次逐项对应
  • 卡点：分母有 (s−1)² 重根，展开时容易漏项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由闭环传递函数写出常微分方程表达式
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 写出约当标准型状态空间表达式
本卷实例
  • 关键一步：重根 s=1（二重）对应一个 2×2 约当块 [[1,1],[0,1]]
  • 关键一步：单根 s=−2 只对应一个 1×1 约当块
  • 关键一步：各块按对角线拼接成 A，B 与约当块结构配套，C 由分子系数确定
  • 中间结果：G 是真分式但分子阶数与分母差 1，直接项 D=0
  • 卡点：约当块的 1 写在对角线上方（不是下方）
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法
  • 本卷考过写出约当标准型状态空间表达式
  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反

三三、状态转移矩阵与状态方程解18 分#

思路
  • A=[[0,1],[−1,−2]]，初值 x(0)=[1,−2]ᵀ，u=1(t)；用 (sI−A)⁻¹ 拉氏反变换求 Φ(t)，再用卷积积分求全解
状态转移矩阵 状态空间分析
本卷考法
  • 用拉氏反变换求状态转移矩阵 Φ(t)
  • 给定 u(t)=1(t) 求状态方程解
本卷实例
  • 关键一步：先求 (sI−A)⁻¹ 并做部分分式
  • 关键一步：再逐项查表反变换，得 Φ(t)=L⁻¹[(sI−A)⁻¹]
  • 关键一步：全解 x(t)=Φ(t)x(0)+∫₀ᵗΦ(t−τ)Bu(τ)dτ，两部分都要算
  • 中间结果：题目已给关键公式 L⁻¹[1/(s+a)]=e^{−at}
  • 中间结果：以及 L⁻¹[1/(s+a)²]=t·e^{−at}，可直接查用
  • 中间结果：A 的特征值为 −1（二重），Φ(t) 里会出现 te^{−t} 项
  • 卡点：卷积积分中变量代换写错；或忘记把初值代进去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过用拉氏反变换求状态转移矩阵 Φ(t)
  • 本卷考过给定 u(t)=1(t) 求状态方程解
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错

四四、能控标准型与状态反馈/观测器#

思路
  • 三阶系统，一题三问：判能控并写能控标准型 → 状态反馈配置极点到 −10,−6,−4 → 观测器极点到 −6,−6,−6
能控性与能观性 状态空间分析
本卷考法
  • 判断系统是否能控，能控则写出能控标准型
本卷实例
  • 关键一步：先由 B、AB、A²B 堆成能控性矩阵，满秩后再做变换
  • 关键一步：把能控性矩阵本身取作变换阵 P，可化成能控标准型
  • 中间结果：三阶系统要补算 A²B，得到三阶判别方阵
  • 中间结果：变换后 B 阵化为 [1,0,0]ᵀ 形式，A、C 随 P 同步变换
  • 卡点：三阶系统只算到 A^{n−1}B 就停，判别矩阵不满三列
  • 卡点：做变换前先确认能控性矩阵满秩，否则 P 不可逆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断系统是否能控，能控则写出能控标准型
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 本卷考过只算到 A^{n-2}B 就下结论
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
状态反馈与极点配置 状态空间分析
本卷考法
  • 设计状态反馈使闭环极点为 −10、−6、−4
本卷实例
  • 关键一步：期望特征多项式为 (s+10)(s+6)(s+4)
  • 关键一步：把它展开后与 det(sI−A+BK) 逐项比对求 K
  • 关键一步：A 不是能控标准型时，要么先做变换，要么直接解方程组
  • 中间结果：期望特征式展开成三次多项式，系数是 K 分量的线性式
  • 中间结果：det(sI−A+BK) 与期望式同幂系数相等，得三元一次方程组
  • 卡点：未先验证能控性就直接配极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过设计状态反馈使闭环极点为 −10、−6、−4
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
公式
状态观测器设计 状态空间分析
本卷考法
  • 设计状态观测器使极点为 −6、−6、−6
本卷实例
  • 关键一步：观测器误差动态由 A−LC 决定
  • 关键一步：把 (s+6)³ 与 det(sI−A+LC) 逐项比对求 L
  • 关键一步：极点全取同一个值（三重根）说明要求观测器足够快且响应无振荡
  • 中间结果：期望观测器特征式 (s+6)³ 与 det(sI−A+LC) 系数逐项相等
  • 中间结果：观测器增益 L 只通过 A−LC 影响误差动态，与 B 无关
  • 卡点：把观测器增益 L 写成状态反馈增益 K 的形式
  • 卡点：逐年与宝典答案都判该三阶系统能观性矩阵秩为 1
  • 卡点：据此称观测器极点无法配置，与本实例口径不一致，待核
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态观测器用输出与输入重构状态，前提是系统能观
  • 极点配置法与龙伯格观测器是两种常用形式
  • 观测器误差动态由 A-LC 的特征值决定
  • 观测器极点通常取得比系统极点快若干倍
步骤
  • 验证系统能观性
  • 写出观测器方程并求误差动态矩阵
  • 按期望特征多项式比较系数求出 L
  • 校验观测器收敛速度是否合适
通用考法
  • 本卷考过设计状态观测器使极点为 −6、−6、−6
  • 设计全维状态观测器
  • 由期望观测器极点求反馈增益阵 L
  • 分析观测器与状态反馈组合后的系统极点
常见易错
  • 把观测器增益阵写成了状态反馈增益阵的形式
  • 忽略观测器极点过快会放大噪声

五五、电路系统建模#

思路
  • 给定 C₁、C₂、R₁、R₂ 与初值（i(0)=0.1A、uc(0)=0.1V），要求先化微分方程再求 uc/ur
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 对两电容电阻网络列 KCL/KVL 方程并化成微分方程
本卷实例
  • 关键一步：先用复阻抗或直接列两个节点的 KCL，消去非输出变量
  • 关键一步：题目明确要求「先化成微分表达式」，所以必须写出时域微分方程这一步，不能直接给 s 域比值
  • 中间结果：电路含两个电容，传函分母一般为 s 的二次式
