1一、电炉温度控制系统方块图与工作过程#

思路
  • 两小问：由电炉温度控制系统原理示意图画方块图并指认被控对象、被控量与各部件作用，再叙述恒温工作过程
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出电炉温度控制系统的被控对象、被控量与各环节作用
  • 画出闭环方块图并说明负反馈工作过程
本卷实例
  • 关键一步：按原理图找给定、被控对象与检测执行环节
  • 关键一步：以热电偶作检测、电机与调压器作执行构成闭环
  • 中间结果：被控对象是电炉、被控量是炉温，给定量为设定电压
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指出电炉温度控制系统的被控对象、被控量与各环节作用
  • 本卷考过画出闭环方块图并说明负反馈工作过程
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 指出系统的被控量、操纵量与扰动量
  • 说明系统保持炉温恒定的工作过程
本卷实例
  • 关键一步：把测量炉温的热电偶电压与给定电压反极性比较得偏差
  • 关键一步：偏差经放大驱动电机与减速器调压从而调节炉温
  • 中间结果：偏差为零时系统进入平衡，炉温维持恒定
  • 卡点：检测环节与执行环节接反会使反馈极性写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过指出系统的被控量、操纵量与扰动量
  • 本卷考过说明系统保持炉温恒定的工作过程
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半

2二、信号流图与梅森公式求传递函数#

思路
  • 由系统结构图先画信号流图，再用梅森增益公式求闭环传递函数 C(s)/R(s)
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图画出信号流图并标出各支路增益
  • 用梅森公式列回路、前向通路与余子式求 C/R
本卷实例
  • 关键一步：把结构图每个方框、比较点、引出点映射成信号流图的支路与节点
  • 关键一步：找出全部独立回路并判断两两不接触的回路
  • 中间结果：特征式 Δ 由全部回路增益与两两不接触回路增益组成
  • 卡点：不接触回路找漏或重复计数，余子式未剔除接触回路
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图画出信号流图并标出各支路增益
  • 本卷考过用梅森公式列回路、前向通路与余子式求 C/R
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

3三、由正弦稳态反求二阶系统参数与调节时间#

思路
  • 结构图为二阶系统：由 r=2sin t 的稳态输出求 ζ、ωn，再求 r=1(t) 时进入稳态的时间
频率特性的物理意义与求法 频域分析
本卷考法
  • 由正弦输入的稳态输出幅值比与相角差写出频率特性方程
本卷实例
  • 关键一步：正弦稳态下幅值比为 1、相角差为 −45°
  • 关键一步：令 ω=1 代入二阶闭环频率特性列两个方程
  • 中间结果：幅值与相角两个方程联立可定出 ζ 与 ωn
  • 卡点：把闭环频率特性的分子分母与二阶标准形式对应错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由正弦输入的稳态输出幅值比与相角差写出频率特性方程
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传递函数化为二阶标准形式求 ζ 与 ωn
本卷实例
  • 关键一步：分母写成 s²+2ζωn s+ωn² 后与系数逐项对应
  • 中间结果：ωn 与 ζ 由分母两个系数唯一定出
  • 卡点：忘记把 s² 项系数归一化就比对系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传递函数化为二阶标准形式求 ζ 与 ωn
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由 ζ、ωn 求单位阶跃响应的调节时间
本卷实例
  • 关键一步：按给定误差带选取调节时间公式 ts=4/(ζωn)
  • 中间结果：误差带不同时公式系数在 3 与 4 之间取
  • 卡点：两种误差带的系数搞混，未先确认 Δ 取值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由 ζ、ωn 求单位阶跃响应的调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

4四、参数根轨迹与稳态误差求 a 范围#

思路
  • 开环 (s+a)/[s(s+1)²]，a 从 0→∞ 作参数根轨迹；再由 r=1.2t 的稳态误差约束求 a 范围
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以开环零点位置参数 a 为变量作广义根轨迹
本卷实例
  • 关键一步：把 a 显式提出写成 1+a·[1/(s(s+1)²)] 的等效开环形式
  • 关键一步：按等效开环的零极点画 a 变化的根轨迹
  • 中间结果：等效开环极点决定根轨迹起点，a→∞ 时趋于等效零点
  • 卡点：整理时未把参数完整提到分子，起点终点判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以开环零点位置参数 a 为变量作广义根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点以定临界参数 a
本卷实例
  • 关键一步：闭环特征式取 s(s+1)²+a 整理成 s³+2s²+2s+a
  • 关键一步：令 s=jω 后分别令实部与虚部为零
  • 中间结果：由 ω 与 a 的联立方程得临界参数与交点频率
  • 卡点：只取 ω=0 的平凡解，漏掉非零解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点以定临界参数 a
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • I 型系统在斜坡输入下的稳态误差约束反求 a
本卷实例
  • 关键一步：速度误差系数 Kv=lim sG(s)，斜坡误差 ess=1.2/Kv
  • 关键一步：由 ess≤0.6 这一个不等式得 a 的下界
  • 中间结果：稳态误差约束给出下界，根轨迹给出稳定上界
  • 卡点：未把稳态误差下界与稳定上界取交集
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过I 型系统在斜坡输入下的稳态误差约束反求 a
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

5五、由开环频率特性求转折频率与闭环二阶参数#

思路
  • 由图(a)(b)读开环频率特性求 ω1、ω2、ω3，再写传函求闭环阻尼比与无阻尼自然振荡角频率
开环对数频率特性的绘制 频域分析
本卷考法
  • 由对数渐近幅频特性读出转折频率与低频段斜率
本卷实例
  • 关键一步：低频段斜率为 −20dB/dec 判为 I 型系统
  • 关键一步：由斜率变化点读转折频率 ω1 与 ω2
  • 中间结果：两个转折频率的几何中项给出第三个频率
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过由对数渐近幅频特性读出转折频率与低频段斜率
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由频率特性图反写开环传递函数 G(s)
本卷实例
  • 关键一步：用 A 点频率 ω=2 与相角条件代入幅相特性
  • 关键一步：解出 k 与转折频率关系后写回 G(s)
  • 中间结果：开环传函化成 k/[s(s/ω2+1)] 形式
  • 卡点：把转折频率与低频增益的对应关系搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
