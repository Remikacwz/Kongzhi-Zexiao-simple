1一、轧钢过程结构图与传递函数#

思路
  • 由轧钢过程示意图画出系统结构图，求前向通道传递函数与闭环传递函数
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 由轧钢过程原理示意图指认给定量、被控量与反馈量并画结构图
本卷实例
  • 关键一步：以钢板位置为被控量、电动机转速为操纵量划分各环节
  • 中间结果：结构图含电动机、齿轮箱、钢板与转速、位置反馈通道
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过由轧钢过程原理示意图指认给定量、被控量与反馈量并画结构图
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
转速负反馈单闭环调速系统 电力拖动与运动控制
本卷考法
  • 借位：按单闭环调速系统结构写出各环节传函并画闭环结构图
本卷实例
  • 关键一步：把二相感应电动机与齿轮箱分别用一阶惯性环节表示
  • 中间结果：传动比与反馈系数一起出现在闭环传递函数分母中
  • 卡点：把被控量与反馈量混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 被控量是转速，反馈量是测速发电机输出电压
  • 属于有差系统，稳态时偏差 e=U_n*−U_n 必须不为零才能维持输出
  • 闭环后稳态速降减小为开环的 1/(1+K) 倍
  • 闭环放大倍数 K 越大，静差率越小，但稳定性越差
步骤
  • 确定被控制量与反馈量
  • 按信号流向画出给定、比较、放大、变换器、电动机、测速反馈各环节
  • 写出稳态关系式并求闭环静特性
  • 比较开环与闭环的稳态速降
通用考法
  • 本卷考过借位：按单闭环调速系统结构写出各环节传函并画闭环结构图
  • 指出系统的被控量与反馈量
  • 画出系统结构框图
  • 解释稳态时偏差不为零的原因
  • 计算闭环稳态速降并比较开环
常见易错
  • 误以为有差系统稳态可以做到零偏差
  • 把被控量与反馈量混为一谈
  • 求闭环静特性时漏掉 (1+K) 因子
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图按串联与负反馈等效写出前向通道与闭环传递函数
本卷实例
  • 关键一步：先写前向通道各环节的乘积，再套用负反馈闭环公式
  • 中间结果：闭环分母为 1 加上前向通道与反馈通道的乘积
  • 卡点：负反馈系统分母误写成 1 减 GH
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由结构图按串联与负反馈等效写出前向通道与闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、二阶系统超调与稳态误差求参数#

思路
  • 由单位阶跃超调量求阻尼比，再由斜坡稳态误差求参数，并设计输入前馈使斜坡误差为零
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量 16.3% 反求二阶系统的阻尼比
本卷实例
  • 关键一步：由超调量公式解出阻尼比 ζ
  • 中间结果：超调量指标只给出 ζ，还需结合特征式定 ωn
  • 卡点：超调量公式中漏乘百分之百
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量 16.3% 反求二阶系统的阻尼比
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由结构图写闭环特征多项式并与二阶标准形式对应
本卷实例
  • 关键一步：把闭环传函分母归一到 s 平方加 2ζωn s 加 ωn 平方
  • 中间结果：ζ 与 ωn 同时由 k、k_t 两个参数决定
  • 卡点：未把 s 平方项系数归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由结构图写闭环特征多项式并与二阶标准形式对应
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡输入下稳态误差 0.25 反求速度误差系数进而定参数
本卷实例
  • 关键一步：I 型系统稳态误差等于速度误差系数的倒数
  • 中间结果：求得的参数需同时满足超调量与稳态误差两项要求
  • 卡点：未先判稳就代入稳态误差公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位斜坡输入下稳态误差 0.25 反求速度误差系数进而定参数
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
反馈校正与复合控制 系统校正
本卷考法
  • 设计输入前馈参数使单位斜坡输入下系统稳态误差为零
本卷实例
  • 关键一步：令加入前馈后误差传函分子的 s 一次项系数为零
  • 中间结果：前馈参数只出现在误差传函分子，不改变闭环极点
  • 卡点：误认为前馈参数会影响系统稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过设计输入前馈参数使单位斜坡输入下系统稳态误差为零
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
公式

3三、Kp-KD 参数平面与稳定域#

思路
  • 由系统结构图写闭环特征方程，在 Kp-KD 参数平面上划分不稳定区、稳定区与不同阻尼状态区域
劳斯判据 稳定性分析
本卷考法
  • 由闭环特征方程用劳斯判据写出使系统稳定的参数不等式
本卷实例
  • 关键一步：把特征式按 s 的幂次整理后列写劳斯表
  • 中间结果：稳定条件化为 Kp 与 KD 的联立不等式
  • 卡点：系数有缺项时未补零就直接套判据
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由闭环特征方程用劳斯判据写出使系统稳定的参数不等式
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 在 Kp-KD 平面上画出稳定域边界并标明可行区域
本卷实例
  • 关键一步：令劳斯表首列元素等于零得到稳定域边界曲线
  • 中间结果：稳定域是各边界围成的公共区域
  • 卡点：取交集时把端点是否包含搞错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过在 Kp-KD 平面上画出稳定域边界并标明可行区域
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由阻尼比等于 1 的轨迹区分过阻尼与欠阻尼区域
本卷实例
  • 关键一步：令特征方程判别式等于零得到临界阻尼轨迹
  • 中间结果：阻尼比等于 1 的轨迹把稳定域分成两片
  • 卡点：把过阻尼与欠阻尼区域的位置画反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由阻尼比等于 1 的轨迹区分过阻尼与欠阻尼区域
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

4四、Bode 与 Nyquist 及稳定裕度#

思路
  • 对给定开环传函画 Bode 与 Nyquist 曲线，判断闭环稳定性并求相角裕度与幅值裕度
开环对数频率特性的绘制 频域分析
本卷考法
  • 画含两个积分环节和两个转折频率的开环对数渐近幅频、相频曲线
本卷实例
  • 关键一步：低频段斜率由积分环节个数定为每十倍频程负 40 分贝
  • 中间结果：按各转折频率逐段累加斜率的改变量
  • 卡点：低频段起始高度漏乘型别因子
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过画含两个积分环节和两个转折频率的开环对数渐近幅频、相频曲线
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 画开环 Nyquist 曲线并按开环右半平面极点数判断闭环稳定性
本卷实例
  • 关键一步：补画无穷大半径圆弧后再看曲线对负一 j0 点的包围
  • 中间结果：补画圆弧的方向由积分环节个数与符号决定
  • 卡点：含积分环节时未补画无穷大圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过画开环 Nyquist 曲线并按开环右半平面极点数判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

稳定裕度 频域分析
本卷考法
  • 由截止频率与相位穿越频率计算相角裕度和幅值裕度
本卷实例
  • 关键一步：由幅频等于 1 求截止频率，代入相频表达式得相角裕度
  • 中间结果：幅值裕度取相位负 180 度处幅值的倒数
  • 卡点：把相角裕度与幅值裕度的定义用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由截止频率与相位穿越频率计算相角裕度和幅值裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

脉冲传递函数 离散控制系统
本卷考法
  • 由零阶保持器与连续环节写脉冲传函并反解数字控制器 D(z)
本卷实例
  • 关键一步：先求连续部分加零阶保持器的 z 变换，再代入闭环关系
  • 中间结果：闭环脉冲传函分母含 z 减 e 的负 T 次方因式
  • 卡点：把无采样开关隔开的连续环节直接相乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图

通用考法
  • 本卷考过由零阶保持器与连续环节写脉冲传函并反解数字控制器 D(z)

  • 由连续传递函数求脉冲传递函数
常见易错

  • 忘记把零阶保持器计入 G(z)

6六、相平面法画相轨迹#

思路
  • 对含继电非线性与局部反馈的系统，在误差相平面上分区列运动方程、求开关线并画相轨迹
相平面法 非线性系统
本卷考法
  • 按非线性分区列写相轨迹微分方程并画单位阶跃响应的相轨迹
本卷实例
  • 关键一步：由系统方程写出误差的一阶、二阶导数关系并按误差符号分区
  • 中间结果：各区的相轨迹为抛物线族，需用初始条件定积分常数
  • 卡点：相轨迹斜率公式中分子与分母写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过按非线性分区列写相轨迹微分方程并画单位阶跃响应的相轨迹
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态

  • 把相轨迹与根轨迹混淆

7七、状态空间可控可观分解与传递函数#

思路
  • 对四阶状态空间表达式判各状态可控性与可观测性，作分解规范形求变换阵，再由传递函数矩阵属性求传函
能控性与能观性 状态空间分析
本卷考法
  • 判各状态的可控可观性并用非奇异变换作控制与观测分解规范形
本卷实例
  • 关键一步：构造可控性与可观性判别矩阵，取线性无关行或列组成变换阵
  • 中间结果：变换后状态按可控可观四部分分块，B 阵只有可控块非零
  • 卡点：判别矩阵秩的判定与分块维数不一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判各状态的可控可观性并用非奇异变换作控制与观测分解规范形
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由状态空间表达式的特征值与零极点对消情况写出传递函数
本卷实例

  • 同一传递函数对应的状态空间实现不唯一

  • 由状态空间表达式求传递函数

  • 比较不同实现对应的传递函数是否相同

  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消
