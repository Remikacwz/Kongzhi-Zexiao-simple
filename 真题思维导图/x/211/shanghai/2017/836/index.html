1一、液位控制系统工作原理与方块图15 分#

思路
  • 由液位自动控制系统原理示意图说明系统工作原理并画出系统方块图
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指出液位系统的被控对象、被控量与操纵量
  • 画出闭环方块图并说明负反馈工作过程
本卷实例
  • 关键一步：以浮子、变阻器、电机、控制阀构成闭环控制
  • 关键一步：说明液位偏差如何经执行机构改变进水流量
  • 中间结果：被控量为液位，操纵量为进水流量
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指出液位系统的被控对象、被控量与操纵量
  • 本卷考过画出闭环方块图并说明负反馈工作过程
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 说明液位过程控制系统的工作原理并划分基本环节
本卷实例
  • 关键一步：液位升高时浮子上移、变阻器下移使电机输入降低
  • 关键一步：控制阀开度减小使流量降低，液位回落至平衡
  • 中间结果：执行机构动作方向与偏差相反，属负反馈调节
  • 卡点：被控量与操纵量搞反会使动作方向写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过说明液位过程控制系统的工作原理并划分基本环节
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半

2二、采样系统求输出 C(z)20 分#

思路
  • 由含 R、N、D1、D2 的采样系统结构图，求系统输出 C(z) 的表达式
脉冲传递函数 离散控制系统
本卷考法
  • 由采样开关位置写各通道脉冲传递函数并综合成 C(z)
本卷实例
  • 关键一步：对结构图各支路取 z 变换后列 C(z)、B2(z)、E(z) 三个关系式
  • 关键一步：消去中间变量得 C(z) 的分式表达式
  • 中间结果：C(z) 由参考通道与扰动通道两部分叠加
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过由采样开关位置写各通道脉冲传递函数并综合成 C(z)
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求参考输入与扰动同时作用下系统的输出表达式
本卷实例
  • 关键一步：由 B2 与 E 两式逐步消元，再代入 C(z) 表达式
  • 关键一步：把各通道输出在 z 域线性叠加
  • 中间结果：分母含 1 加上回路脉冲传函的因式
  • 卡点：求扰动通道时未把参考输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求参考输入与扰动同时作用下系统的输出表达式
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式

3三、阻容四端网络求传递函数#

思路
  • 由阻容四端网络用复阻抗法列方程，再经框图化简求传递函数 U2(s)/U1(s)
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由阻容网络用复阻抗法求传递函数
本卷实例
  • 关键一步：把电容写成 1/(Cs) 的复阻抗后按串并联关系化简网络
  • 关键一步：按分压或网孔方程写出 U2/U1
  • 中间结果：结果的分子与分母都是 s 的多项式
  • 卡点：复阻抗法把电容阻抗误写成 Cs
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由阻容网络用复阻抗法求传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • RC 四端网络的建模与等效化简
本卷实例
  • 关键一步：列节点或回路方程，或直接用阻抗分压关系
  • 关键一步：把结果整理成以各 RC 乘积为系数的标准形式
  • 中间结果：分母含 R1R2C1C2s² 等项
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过RC 四端网络的建模与等效化简
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 把网络拆成多个环节框图后逐层化简
本卷实例
  • 关键一步：按网络结构画框图层层消去中间变量
  • 关键一步：合并串联与反馈支路后得总传递函数
  • 中间结果：化简过程中中间变量应被完全消去
  • 卡点：化简时把外环信号当成常数处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过把网络拆成多个环节框图后逐层化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

4四、参数 β 对稳定性与稳态性能的影响#

思路
  • 结构图含局部反馈参数 β，分析 β 对系统稳定性的影响及 r=at 下对稳态性能的影响
参数稳定域的确定 稳定性分析
本卷考法
  • 由闭环特征式判断使系统稳定的参数 β 范围
本卷实例
  • 关键一步：化简得开环传函后写闭环特征式，整理成二阶特征方程
  • 关键一步：由二阶系统两个系数均为正判稳定性
  • 中间结果：稳定条件给出参数 β 的下界
  • 卡点：漏掉特征式常数项为正这一约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由闭环特征式判断使系统稳定的参数 β 范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 分析 β 变化对阻尼比、超调量与调节时间的影响
本卷实例
  • 关键一步：由特征式系数对应得阻尼比与 β 的线性关系
  • 关键一步：据此说明 β 增大时超调下降、峰值时间增大
  • 中间结果：自然振荡角频率与 β 无关，只有阻尼比随 β 变
  • 卡点：把阻尼比与 β 的关系方向写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过分析 β 变化对阻尼比、超调量与调节时间的影响
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡输入下的稳态误差并分析 β 的影响
本卷实例
  • 关键一步：I 型系统用速度误差系数求稳态误差
  • 关键一步：把稳态误差写成含 β 的表达式后判断单调性
  • 中间结果：稳态误差与 β 成正比
  • 卡点：未先判稳就套静态误差系数法
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求斜坡输入下的稳态误差并分析 β 的影响
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

5五、根轨迹求临界参数与主导极点#

思路
  • 开环 k/[s(0.01s+1)(0.02s+1)]，求临界 k、衰减振荡 k 范围与 ζ=0.707 时的各极点
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制三阶无零点系统的根轨迹并求分离点
本卷实例
  • 关键一步：读开环极点 0、−50、−100，无零点，n−m=3
  • 关键一步：列分离点方程解出实轴上的汇合点
  • 中间结果：渐近线夹角为 ±60° 与 180°，交点在负实轴上
  • 卡点：分离点方程解出多个根后未按实轴段筛选
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制三阶无零点系统的根轨迹并求分离点
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点求临界稳定 k
本卷实例
  • 关键一步：把闭环特征式化成整系数三次多项式后令 s=jω
  • 关键一步：实部与虚部分别为零联立求解
  • 中间结果：非零解给出虚轴交点频率与临界 k
  • 卡点：遗漏 ω=0 或非零解中的一组
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定

6六、开环频率特性绘制与奈氏判稳#

思路
  • 开环 G(s)=k(2s+1)/[s²(s+1)]，k=1 时画幅频特性，k 未知时用奈氏图分析稳定的 k 范围
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制含两个积分环节系统的渐近对数幅频特性
本卷实例
  • 关键一步：分母 s² 使低频段斜率为 −40dB/dec，零点转折频率在 0.5
  • 关键一步：逐段改变斜率画出渐近幅频特性
  • 中间结果：0.5 到 1 之间斜率为 −20dB/dec，1 以后回到 −40dB/dec
  • 卡点：逐段改斜率时忘记累加而非替换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化

  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法

  • 绘制开环对数渐近幅频特性

常见易错

  • 低频段起始高度没有乘上型别的 -20v dB/dec

奈奎斯特判据 稳定性分析
本卷考法
  • 作奈氏图并分析使闭环稳定的 k 范围
本卷实例
  • 关键一步：开环有两个积分环节，需补画无穷大半径的增补圆弧
  • 关键一步：由 Z=P−2N 判断闭环右半平面极点数
  • 中间结果：增补圆弧与负实轴的交点决定稳定边界
  • 卡点：含积分环节时未补画无穷大圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过作奈氏图并分析使闭环稳定的 k 范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

能控性与能观性 状态空间分析
本卷考法
  • 判断极点配置后闭环系统的可观测性
本卷实例
  • 关键一步：用闭环矩阵 A+bK 与输出矩阵 C 构造能观性判别矩阵

  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解

  • 把能控性判据与能观性判据的矩阵构造搞混
