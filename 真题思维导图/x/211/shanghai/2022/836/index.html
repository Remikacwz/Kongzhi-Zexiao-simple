1一、能控性与能观性概念#

思路
  • 纯概念题，要求用状态可控与状态可观测的语言说明两个定义及其区别
能控性与能观性 状态空间分析
本卷考法
  • 简述系统能控性与能观性的概念
本卷实例
  • 关键一步：能控性：存在容许控制，使任意初始状态在有限时间内转移到指定终点
  • 关键一步：能观性：由有限时间内的输出能唯一确定系统的初始状态
  • 中间结果：能控性看输入对状态的支配能力，能观性看输出对初始状态的反映能力
  • 卡点：把能控性说成能改变输出；个别教材区分能达性，需说明二者等价的条件
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过简述系统能控性与能观性的概念
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

2二、并联分解求约当标准型#

思路
  • 传递函数 (3s²+4s−2)/(s−3)³，三重极点 s=3；用部分分式展开成并联形式再写约当标准型
由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 由传递函数用并联分解写出约当标准型状态空间表达式
本卷实例
  • 关键一步：先按重极点 (s−3)³ 做部分分式展开，求三个待定系数
  • 关键一步：重根按 C1/(s−3)³+C2/(s−3)²+C3/(s−3) 排列，对应一个三阶约当块
  • 关键一步：由展开式直接写出 A、B、C
  • 中间结果：三重极点对应一个 3×3 约当块，对角线上一排为 1
  • 中间结果：待定系数按从高次到低次成为输出矩阵元素
  • 卡点：重根部分分式求导公式漏阶乘；约当块中 1 写到对角线下方
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法
  • 本卷考过由传递函数用并联分解写出约当标准型状态空间表达式
  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反

3三、状态转移矩阵与状态响应#

思路
  • A=[[0,1],[−6,−5]]、b=[1,0]ᵀ、x(0)=[−1,0]ᵀ、u=−2·1(t)；先用 (sI−A)⁻¹ 反变换求 Φ(t)，再用卷积公式求全解
状态转移矩阵 状态空间分析
本卷考法
  • 用拉普拉斯反变换求状态转移矩阵 Φ(t)
  • 求给定输入与初值下的状态响应 x(t)
本卷实例
  • 关键一步：先求 (sI−A)⁻¹ 并做部分分式，逐项查表反变换得 Φ(t)
  • 关键一步：全解 x(t)=Φ(t)x(0)+∫Φ(t−τ)bu(τ)dτ，两部分都要算
  • 中间结果：A 的特征值为 −2、−3，Φ(t) 由 e^{−2t}、e^{−3t} 两种模态组成
  • 卡点：卷积积分变量代换写错；忘记把初值代入零输入分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过用拉普拉斯反变换求状态转移矩阵 Φ(t)
  • 本卷考过求给定输入与初值下的状态响应 x(t)
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错

思路

  • 卡点：分子有常数项时直接传递项处理错；友矩阵系数符号写反

  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反

状态反馈与极点配置 状态空间分析
本卷考法
  • 设计状态反馈增益阵 K 使闭环极点为 −1、−2±j
本卷实例
  • 关键一步：在能控标准型下设 K=[k1 k2 k3]，写出 det(λI−A+bK)
  • 关键一步：把期望特征式 (λ+1)(λ²+4λ+5) 展开后与它逐项比对求 K
  • 中间结果：能控标准型下闭环特征式系数与 K 分量一一对应
  • 卡点：未先确认能控就配极点；系数比对时符号写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过设计状态反馈增益阵 K 使闭环极点为 −1、−2±j
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
公式
状态观测器设计 状态空间分析
本卷考法
  • 设计全维观测器使其极点为三重 −3
本卷实例
  • 关键一步：先算能观性矩阵确认能观，再设 L=[l1 l2 l3]ᵀ 写出 det(λI−A+LC)
  • 关键一步：把期望特征式 (λ+3)³ 展开后逐项比对求 L
  • 中间结果：观测器增益只通过 A−LC 改变误差动态，与输入矩阵无关
  • 卡点：把观测器增益 L 与状态反馈增益 K 的矩阵形式混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 极点配置法与龙伯格观测器是两种常用形式
  • 观测器误差动态由 A-LC 的特征值决定
  • 观测器极点通常取得比系统极点快若干倍
步骤
  • 验证系统能观性
  • 写出观测器方程并求误差动态矩阵
  • 按期望特征多项式比较系数求出 L
  • 校验观测器收敛速度是否合适
通用考法

  • 设计全维状态观测器
  • 由期望观测器极点求反馈增益阵 L
  • 分析观测器与状态反馈组合后的系统极点
常见易错
  • 把观测器增益阵写成了状态反馈增益阵的形式
  • 忽略观测器极点过快会放大噪声

5五、梅森公式求传递函数#

思路
  • 由信号流图求 C/R：先列四个独立回路并找两两不接触回路，再列三条前向通道及其余子式
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图用梅森增益公式求闭环传递函数
本卷实例
  • 关键一步：先列全部独立回路并找出两两互不接触的组合
  • 关键一步：再列每条前向通路 P_i，余子式需剔除与该通路接触的回路
  • 关键一步：按 Δ=1−ΣL+ΣLL−… 与 C/R=ΣP_iΔ_i/Δ 组合
  • 中间结果：存在一对互不接触回路，Δ 中要加上它们的乘积项
  • 卡点：不接触回路找漏或重复；余子式未剔除接触回路
  • 卡点：信号流图未读图，回路数与支路增益需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图用梅森增益公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

6六、离散系统稳定性与 w 变换#

思路
  • 已知闭环脉冲传函，用 w=(z+1)/(z−1) 变换后套劳斯判据求稳定 K 范围
离散系统稳定性分析 离散控制系统
本卷考法
  • 用 w 变换把离散特征方程化为 s 域形式，再用劳斯判据求稳定 K 范围
本卷实例
  • 关键一步：先写出闭环特征方程 D(z)=0，再把 z=(w+1)/(w−1) 代入
  • 关键一步：整理出关于 w 的多项式，列劳斯表并令首列各项同号
  • 关键一步：解出三个不等式取交集得稳定区间
  • 中间结果：w 变换把单位圆内映射到 w 左半平面，稳定条件变为首列全正
  • 卡点：w 变换公式记反；只列部分首列不等式，漏掉某个约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过用 w 变换把离散特征方程化为 s 域形式，再用劳斯判据求稳定 K 范围
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

7七、奈奎斯特判据#

思路
  • 开环 4(s+3)/[s(s−1)]，含一个右半平面极点 P=1；画奈氏曲线并由 Z=P−2N 判稳
奈奎斯特判据 稳定性分析
本卷考法
  • 画 G(jω) 奈奎斯特曲线并用奈氏判据判断系统稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数 P；含积分环节时在低频端补画无穷大圆弧
  • 关键一步：写出 P(ω)、Q(ω) 或 |G|、∠G，求曲线与负实轴交点
  • 关键一步：由包围 (−1,j0) 的正负穿越次数算 N，用 Z=P−2N 判断
  • 中间结果：曲线在 ω→0⁺ 与 ω→∞ 的走向及穿越负实轴的位置是判稳关键
  • 卡点：积分环节未补画圆弧；包围圈数正负号搞反
  • 卡点：奈氏曲线需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过画 G(jω) 奈奎斯特曲线并用奈氏判据判断系统稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

8八、根轨迹与临界增益#

思路
  • 开环 K/[s(0.01s+1)(0.02s+1)]，三个极点、无零点；绘制根轨迹并求虚轴交点对应的临界 K
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按根轨迹法则写出渐近线、实轴段等绘制步骤
本卷实例
  • 关键一步：先化成 K*/[s(s+100)(s+50)] 形式读出极点与 K 的换算关系
  • 关键一步：由 n−m=3 算渐近线条数、夹角及实轴交点，并判实轴根轨迹段
  • 中间结果：三条分支都趋于无穷远；渐近线与实轴交点由三极点平均值给出
  • 卡点：把 K* 与原题 K 的倍率关系漏掉，临界值就会差一个系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角

稳定裕度 频域分析
本卷考法
  • 求校正前后系统的截止频率与相角裕度并检验
本卷实例
  • 关键一步：在 0 dB 处读截止频率，代入相频算 γ=180°+∠G(jωc)
  • 关键一步：把 Gc 与 G 相乘得校正后开环，按同一流程复核 γ
  • 中间结果：校正后截止频率明显下移，相角裕度抬到要求值以上
  • 卡点：ωc 与 ωg 混用；只看相角裕度不校验 Kv 是否仍满足
  • 卡点：校正前后 Bode 图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求校正前后系统的截止频率与相角裕度并检验
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
