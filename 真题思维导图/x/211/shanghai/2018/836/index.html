1一、热交换系统结构图与传递函数20 分#

思路
  • 由热交换系统原理图、框图与数据画出系统结构图，并求输出对输入的传递函数
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 由热交换系统原理图画出闭环结构图并指认被控对象与各环节
本卷实例
  • 关键一步：以热交换器为被控对象，按测量、比较与执行元件划分环节
  • 中间结果：结构图含给定温度、温度控制器、调节阀、热交换器与温度反馈
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过由热交换系统原理图画出闭环结构图并指认被控对象与各环节
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半
过程控制系统的组成与设计步骤 过程控制与检测仪表
本卷考法
  • 按过程控制系统组成说明热交换系统的工作过程并划分基本环节
本卷实例
  • 关键一步：蒸汽流量作为操纵量，出口热水温度作为被控量
  • 中间结果：冷水流量变化是主要扰动，可作为顺馈补偿信号
  • 卡点：把被控量与操纵量写反会导致整题失分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 四大环节：被控对象、检测变送、控制器、执行器
  • 被控量是工艺上要维持的变量，操纵量是控制器输出所控制的变量
  • 扰动是影响被控量但不可控的变量
  • 设计步骤：定方案 → 选仪表 → 定参数 → 投运整定
步骤
  • 从工艺描述中找出被控量、操纵量与主要扰动
  • 判断扰动是否需要专门抑制（决定要不要加副回路）
  • 选择控制方案并画原理图与方框图
  • 说明系统的工作过程
通用考法
  • 本卷考过按过程控制系统组成说明热交换系统的工作过程并划分基本环节
  • 指出系统的被控量、操纵量与扰动量
  • 设计满足工艺要求的控制系统并画出原理图及方框图
  • 说明系统的工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图不画原理图（或反之），漏答一半
传递函数的定义与基本性质 传递函数
本卷考法
  • 由热交换过程各环节关系写出输出温度对输入的传递函数
本卷实例
  • 关键一步：按能量平衡列写微分方程，再在零初始条件下取拉氏变换
  • 中间结果：传递函数分母阶数由系统储能环节个数决定
  • 卡点：忽略零初始条件这一前提直接写传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由热交换过程各环节关系写出输出温度对输入的传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

2二、复合控制前馈参数与稳态误差#

思路
  • 含前馈补偿的复合控制系统，按给定信号下误差为零求前馈参数，再讨论不同输入下的稳态误差
反馈校正与复合控制 系统校正
本卷考法
  • 求前馈补偿器 Gc(s) 的参数使给定信号下系统满足不变性
本卷实例
  • 关键一步：写出误差传递函数并令其分子在原点附近的低次项系数为零
  • 中间结果：联立 T1+T2-K2a=0 与 1-K2b=0 可确定 a、b
  • 卡点：求出前馈参数后未回代检验闭环稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过求前馈补偿器 Gc(s) 的参数使给定信号下系统满足不变性
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 分析前馈补偿对提高给定信号跟踪精度的作用与局限
本卷实例
  • 关键一步：比较加入前馈前后误差传函分子的对应项是否被消去
  • 中间结果：前馈只改变误差传函分子，不移动闭环极点
  • 卡点：误以为前馈补偿会改变系统稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过分析前馈补偿对提高给定信号跟踪精度的作用与局限
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 分别计算阶跃、斜坡与抛物线输入下复合系统的稳态误差
本卷实例
  • 关键一步：对三种典型输入分别用终值定理求稳态误差极限
  • 中间结果：抛物线输入下仅当前馈参数取特例值误差才为零
  • 卡点：未先判稳就使用终值定理求误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过分别计算阶跃、斜坡与抛物线输入下复合系统的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

3三、参数根轨迹与等阻尼线#

思路
  • 系统含 K1 与 a 两个可变参数，分别作以 K1、a 为变量的根轨迹，求无超调、临界稳定与 ζ=0.707 的参数
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 把含参数 a 或 K1 的闭环特征方程整理成参数根轨迹标准形式
本卷实例
  • 关键一步：选定变化参数后把特征方程改写成 1 加参数乘 F(s) 等于零
  • 中间结果：参数根轨迹的起点与终点随所选参数的不同而互换
  • 卡点：整理时未把参数完整地提到分子位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过把含参数 a 或 K1 的闭环特征方程整理成参数根轨迹标准形式
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点求临界稳定时的 K1 值
本卷实例
  • 关键一步：令 s 等于 jω 代入闭环特征式并分离实部与虚部
  • 中间结果：虚轴交点频率与临界参数由实部、虚部两式联立给出
  • 卡点：漏掉 ω 等于零这一组解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹与虚轴交点求临界稳定时的 K1 值
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹实轴分离点确定系统无超调时的 K1 取值
本卷实例
  • 关键一步：无超调对应闭环全为实根，在分离点处用幅值条件定参数
  • 中间结果：临界阻尼状态是单调响应与振荡响应的分界
  • 卡点：把分离点处的参数值与临界稳定参数值混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹实轴分离点确定系统无超调时的 K1 取值
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 用等阻尼线在参数根轨迹上求 ζ=0.707 对应的 a 值
本卷实例
  • 关键一步：设闭环复极点为负 ζωn 加减 jωn 根号下 1 减 ζ 平方
  • 中间结果：等阻尼线与根轨迹的交点即所求的一对闭环极点
  • 卡点：把等阻尼线画成垂直线导致参数求错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过用等阻尼线在参数根轨迹上求 ζ=0.707 对应的 a 值
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式

4四、幅相特性与最小相位及稳定 K 范围#

思路
  • 对 G1 与 G2 两个开环传递函数画幅相曲线，判断最小相位系统并求各自稳定时的 K 范围
频率特性的物理意义与求法 频域分析
本卷考法
  • 由开环传递函数写出幅频、相频表达式并描点画幅相曲线
本卷实例
  • 关键一步：分别计算 ω 趋于零、转折频率处与 ω 趋于无穷时的幅值和相角
  • 中间结果：含右半平面极点的 G2 与 G1 的起始相角不同
  • 卡点：求幅值时未对分母复数先取模
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由开环传递函数写出幅频、相频表达式并描点画幅相曲线
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
最小相位系统与非最小相位系统 频域分析
本卷考法
  • 比较两个开环传递函数的零极点位置判断是否为最小相位系统
本卷实例
  • 关键一步：检查传递函数是否存在右半平面的零点或极点
