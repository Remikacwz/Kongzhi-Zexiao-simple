1一、晶体管稳压电源控制框图与变量指认#

思路
  • 由晶体管稳压电源电路图画出控制框图，并指出给定量、被控量、反馈量与扰动量
自动控制系统的基本组成与控制方式 基本概念与信号
本卷考法
  • 指认稳压电源系统的给定量、被控量、反馈量与扰动量
  • 画出晶体管稳压电源电路的闭环控制框图
本卷实例
  • 关键一步：以稳压管稳压值为给定量、负载电压为被控量
  • 关键一步：整流输出电压的波动为扰动量，采样电压为反馈量
  • 中间结果：反馈量与给定量比较后经调整管调节输出电压
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环系统按给定、比较、放大、执行、对象、检测六个环节串联成环
  • 按有无反馈分为开环、闭环与复合控制；按给定信号分为恒值、随动与程序控制
  • 检测变送元件把被控量转换成可比较的信号，是反馈通道的入口
  • 控制系统的基本要求是稳、准、快三条
步骤
  • 从工艺或物理描述里找出被控量与操纵量
  • 逐个指认给定、比较、控制、执行、对象与检测六个环节对应的实物
  • 按信号流向把环节串成闭环方框图
  • 说明系统靠什么维持被控量等于给定量
通用考法
  • 本卷考过指认稳压电源系统的给定量、被控量、反馈量与扰动量
  • 本卷考过画出晶体管稳压电源电路的闭环控制框图
  • 指出系统的被控对象、被控量与操纵量
  • 说明检测变送元件在闭环系统中的作用
  • 画出给定系统的闭环方框图并说明工作过程
常见易错
  • 把被控量与操纵量搞反
  • 只画方框图而不指认环节，或反之，漏答一半

2二、前馈校正实现给定信号不变性#

思路
  • 已知系统方块图，要求 r(t)=t²/2 作用下稳态误差为零，求前馈校正参数 a、b
减小稳态误差的措施 稳态误差
本卷考法
  • 由给定信号下的不变性列稳态误差为零的约束方程
  • 把误差传函在原点展开并令低次项系数为零
本卷实例
  • 关键一步：写出 E(s)=R(s)[1−Φ(s)] 并对 r=t²/2 取 s→0 的极限
  • 关键一步：令展开式分子各低次项系数为零
  • 中间结果：得到关于前馈参数 a、b 的两个约束方程
  • 卡点：只令常数项为零，漏掉 s 的一次项约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过由给定信号下的不变性列稳态误差为零的约束方程
  • 本卷考过把误差传函在原点展开并令低次项系数为零
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式
反馈校正与复合控制 系统校正
本卷考法
  • 用前馈补偿器实现给定信号下的不变性并求补偿参数
本卷实例
  • 关键一步：把前馈校正项并入闭环传函，使 1−Φ(s) 在原点有足够重零点
  • 关键一步：由两个约束方程联立定出补偿系数
  • 中间结果：前馈补偿只改变传递零点，不影响闭环稳定性
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过用前馈补偿器实现给定信号下的不变性并求补偿参数
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大

3三、微分方程建模、闭环传函与奈氏判稳#

思路
  • 由微分方程画系统框图并求闭环传函，再求 r=1+t 下 ess 不超过 ε0 的条件，最后作奈氏图判稳
传递函数的定义与基本性质 传递函数
本卷考法
  • 由微分方程与反馈关系求各环节传函并综合成闭环传函
本卷实例
  • 关键一步：对三个微分方程分别取拉氏变换，消去中间变量 b
  • 关键一步：把结果整理成含 K1、K2、T1、T2 的闭环传函
  • 中间结果：闭环特征式为三次多项式
  • 卡点：三阶特征式整理时漏乘或漏项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由微分方程与反馈关系求各环节传函并综合成闭环传函
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由 ess≤ε0 求反馈系数 K2 应满足的条件
本卷实例
  • 关键一步：r(t)=1+t 属组合输入，用 E(s) 的 s→0 极限求 ess
  • 关键一步：由 ess≤ε0 得 K2 这一参数的下界
  • 中间结果：稳态误差约束与稳定约束分别给 K2 的下界与上界
  • 卡点：只算阶跃分量，漏掉斜坡分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由 ess≤ε0 求反馈系数 K2 应满足的条件
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 作奈氏图并结合劳斯判据判断闭环稳定性
本卷实例
  • 关键一步：开环为 I 型三阶系统，相位穿越频率处幅值含 K1K2 因子
  • 关键一步：由幅值不超过 1 判闭环稳定，同时列劳斯表校核
  • 中间结果：稳定条件给出 K2 的上界
  • 卡点：含积分环节时未补画无穷大半径圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过作奈氏图并结合劳斯判据判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式

4四、描述函数法分析非线性系统自振#

思路
  • 非线性环节与 G(s)=k/[s(s+1)²] 串联，画负倒描述函数与幅相曲线，求存在稳定自振的 k 值范围
描述函数法基础 非线性系统
本卷考法
  • 求负倒描述函数并分析其随幅值 A 的变化规律
本卷实例
  • 关键一步：由非线性环节的 N(A) 写出负倒描述函数并整理成分式
  • 关键一步：判断该分式随 A 增大是单调增还是单调减
  • 中间结果：负倒描述函数的变化范围给出可能与幅相曲线相交的区间
  • 卡点：把 N(A) 当成负倒描述函数直接画
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过求负倒描述函数并分析其随幅值 A 的变化规律
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件
公式
用描述函数法分析自振 非线性系统
本卷考法
  • 由负倒描述函数与幅相曲线的交点求稳定自振的 k 范围
本卷实例
  • 关键一步：求 G(jω) 相位为 −180° 的频率与该频率处的幅值
  • 关键一步：按交点落在负倒描述函数区间内列不等式
  • 中间结果：不等式联立后给出 k 的开区间
  • 卡点：未标注 A 增大方向就判自振稳定性
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过由负倒描述函数与幅相曲线的交点求稳定自振的 k 范围
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率
公式

5五、串联校正装置设计与相角裕量#

思路
  • 固有 G0=1/[s(50s+1)(0.2s+1)]，由校正后对数幅频特性求 Gc(s)，算相角裕量增量并判断装置类型
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由校正后对数幅频特性反求开环传函并作商得 Gc(s)
本卷实例
  • 关键一步：按转折频率写校正后 G(s) 的零极点形式
  • 关键一步：由截止频率处幅值为 1 定增益，再算 Gc=G/G0
  • 中间结果：Gc 的分子分母由校正前后零极点相除得到
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由校正后对数幅频特性反求开环传函并作商得 Gc(s)
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 算校正前后的相角裕量及其增量
本卷实例
  • 关键一步：由开环幅值为 1 分别求校正前后的截止频率
  • 关键一步：代入相频表达式算各自的相角裕量
  • 中间结果：校正前后相角裕量之差即所求增量
  • 卡点：把相位穿越频率当成截止频率代入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过算校正前后的相角裕量及其增量
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
滞后-超前校正 系统校正
本卷考法
  • 判断校正装置类型并说明其功用
本卷实例
