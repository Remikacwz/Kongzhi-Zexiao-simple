1一、传递函数与线性变换不变性8 分#

思路
  • 由状态空间表达式求 G(s)=C(sI−A)⁻¹B+D，并证明非奇异线性变换不改变传递函数
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由状态空间表达式求传递函数 G(s)
  • 证明非奇异线性变换后传递函数矩阵不变
本卷实例
  • 关键一步：第一问直接按 G(s)=C(sI−A)⁻¹B+D 计算矩阵求逆再相乘
  • 关键一步：第二问代入变换后矩阵，用 (P⁻¹AP) 的逆拆成 P⁻¹(sI−A)⁻¹P
  • 关键一步：让首尾的 P 与 P⁻¹ 相消，即得与原系统相同的 G(s)
  • 中间结果：关键恒等式是 (sI−P⁻¹AP)⁻¹=P⁻¹(sI−A)⁻¹P
  • 中间结果：变换只改变内部状态描述，输入输出关系保持不变
  • 卡点：只写相似变换不改变传递函数而不给推导，证明题难拿分
  • 卡点：把 P 的作用方向写反，四个矩阵全错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过由状态空间表达式求传递函数 G(s)
  • 本卷考过证明非奇异线性变换后传递函数矩阵不变
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

2二、对角标准型与状态空间结构图12 分#

思路
  • G(s)=(2s²+6s+6)/[(s+1)(s+2)(s+3)]，部分分式展开成三个一阶并联，写出对角标准型并画结构图
由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 由传递函数写对角标准型状态空间表达式并绘制状态空间结构图
本卷实例
  • 关键一步：先做部分分式展开成 A/(s+1)+B/(s+2)+C/(s+3)
  • 关键一步：通分后按同幂系数列三个方程解出 A、B、C
  • 关键一步：以三个实极点为对角元写 A，输入与输出矩阵由展开系数定
  • 中间结果：三个互异实极点对应 3×3 对角阵，无约当块
  • 中间结果：结构图是三路一阶并联再求和
  • 卡点：部分分式系数解错；结构图未读图，支路连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法
  • 本卷考过由传递函数写对角标准型状态空间表达式并绘制状态空间结构图
  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反

3三、状态转移矩阵与李雅普诺夫第二法10 分#

思路
  • A=[[0,2],[−1,b]]：第一问 b=−2 时求 Φ(t)；第二问 u=0 时用李雅普诺夫第二法讨论渐近稳定性
状态转移矩阵 状态空间分析
本卷考法
  • 求给定系统在 b=−2 时的状态转移矩阵 Φ(t)
本卷实例
  • 关键一步：写出 sI−A 并求逆，得到含 (s+1)²+1 的有理矩阵
  • 关键一步：用 e^{−t}sin t、e^{−t}cos t 两条反变换公式逐项求逆变换
  • 中间结果：特征值为 −1±j，Φ(t) 含 e^{−t}sin t 与 e^{−t}cos t 项
  • 卡点：矩阵求逆时忘记检查行列式；把共轭复根对应的时间函数写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过求给定系统在 b=−2 时的状态转移矩阵 Φ(t)
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错
公式
李雅普诺夫稳定性分析 状态空间分析
本卷考法
  • 用李雅普诺夫第二法讨论系统渐近稳定性
本卷实例
  • 关键一步：取 Q=I 为正定，设对称正定阵 P 并代入方程 AᵀP+PA=−Q
  • 关键一步：按对应元素相等解出 P 的三个独立元素
  • 关键一步：判 P 的两个顺序主子式是否都大于零，得参数 b 的范围
  • 中间结果：方程给出一组关于 P 元素与 b 的代数方程
  • 中间结果：P 取 [m1 m2; m2 m4]，只需三个独立元素
  • 卡点：只判 P 正定而忘记 Q 必须取正定；把 P、Q 的角色写反
  • 卡点：本题须用李雅普诺夫方法，只由特征值符号下结论不给分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 第一法通过线性化系统的特征值判断原系统的局部稳定性
  • 第二法用李雅普诺夫函数直接判断稳定性，无需解方程
  • 李雅普诺夫函数正定且其导数为负定则渐近稳定
  • 线性定常系统中李雅普诺夫方程有正定解等价于系统稳定
步骤
  • 选取或构造李雅普诺夫函数
  • 沿系统轨迹求其对时间的导数
  • 判断函数与导数的正负定性
  • 据此得出稳定性结论
通用考法
  • 本卷考过用李雅普诺夫第二法讨论系统渐近稳定性
  • 用李雅普诺夫方程判断系统稳定性
  • 构造李雅普诺夫函数证明渐近稳定
  • 分析非线性系统的稳定性范围
常见易错
  • 李雅普诺夫方程中 P、Q 的角色混用
  • 只判断 V 正定就下结论而未检查导数

4四、能控标准型、状态反馈与全维观测器20 分#

思路
  • 三阶 A、b、c 给定：先判能控并化能控标准型，再配极点 −1、−2、−4，最后判能观并配观测器极点 −1、−2、−3
能控性与能观性 状态空间分析
本卷考法
  • 判断系统能控性并写出能控标准型状态空间表达式
本卷实例
  • 关键一步：由 [b Ab A²b] 堆成能控性矩阵求秩，满秩后再做相似变换
  • 关键一步：变换阵 P 由 qᵀ、qᵀA、qᵀA² 堆成，qᵀ 是能控性矩阵求逆的末行
  • 中间结果：变换后 A 化为友矩阵、b 化为 [0,0,1]ᵀ 的能控标准型
  • 卡点：三阶系统只算到 Ab 就下结论；变换阵 P 取错方向
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断系统能控性并写出能控标准型状态空间表达式
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混
公式
状态反馈与极点配置 状态空间分析
本卷考法
  • 求状态反馈向量 K 使闭环极点为 −1、−2、−4
本卷实例
  • 关键一步：在能控标准型下设 K=[k1 k2 k3]、u=−Kx+v，写出 det(sI−A+bK)
  • 关键一步：把期望特征式 (s+1)(s+2)(s+4) 展开后与它逐项比对求 K
  • 中间结果：能控标准型下闭环特征式各幂系数与 K 分量成线性对应
  • 卡点：未先验证能控性就配极点；系数比对时符号写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过求状态反馈向量 K 使闭环极点为 −1、−2、−4
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反
公式
状态观测器设计 状态空间分析
本卷考法
  • 判断能否设计全维观测器并把极点配到 −1、−2、−3
本卷实例
  • 关键一步：先算能观性矩阵 [c; cA; cA²] 的秩，确能观后才可任意配观测器极点
  • 关键一步：设 H 为三维列向量，写出 det(sI−A+HC) 并与期望特征式比对求 H
  • 中间结果：能观性矩阵满秩是观测器极点可任意配置的前提
  • 卡点：没有先判能观就设计观测器；把 H 的矩阵形式写成 K 的形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态观测器用输出与输入重构状态，前提是系统能观
  • 极点配置法与龙伯格观测器是两种常用形式
  • 观测器误差动态由 A-LC 的特征值决定
  • 观测器极点通常取得比系统极点快若干倍
步骤
  • 验证系统能观性
  • 写出观测器方程并求误差动态矩阵
  • 按期望特征多项式比较系数求出 L
  • 校验观测器收敛速度是否合适
通用考法
  • 本卷考过判断能否设计全维观测器并把极点配到 −1、−2、−3
  • 设计全维状态观测器
  • 由期望观测器极点求反馈增益阵 L
  • 分析观测器与状态反馈组合后的系统极点
常见易错

  • 忽略观测器极点过快会放大噪声

5五、梅森公式与扰动不变性补偿20 分#

思路
  • 由结构图求 C/N 与 C/R，并设计 G2(s) 使扰动对输出无影响
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图用梅森公式或结构图化简求 C(s)/N(s) 与 C(s)/R(s)
本卷实例
  • 关键一步：先列全部独立回路并求特征式 Δ=1−ΣL+ΣLL−…
  • 关键一步：分别以 N 与 R 为输入列前向通路及余子式
  • 关键一步：求扰动传函时把参考输入置零，反之亦然
  • 中间结果：C/N 含并联直通项，C/R 只由参考通路决定
  • 卡点：求一个输入的传递函数时忘记把另一个输入置零
  • 卡点：结构图未读图，回路与支路增益需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图用梅森公式或结构图化简求 C(s)/N(s) 与 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 设计补偿环节 G2(s) 使扰动对输出无影响
本卷实例
  • 关键一步：令扰动传函 C(s)/N(s)=0，把分子各项组合成关于 G2 的方程
  • 关键一步：解出 G2(s) 的表达式，再检查其物理可实现性
  • 中间结果：不变性条件是扰动通路的分子（含 Δ 项与并联项）整体为零
  • 卡点：只令某一条支路为零，忽略直通项；解出的 G2 若含纯微分不可实现需说明
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过设计补偿环节 G2(s) 使扰动对输出无影响
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

6六、根轨迹与稳定范围20 分#

思路
  • 题面给结构图，闭环特征方程可整理为等效开环 G(s)=k(s+0.25)/[(s+0.75)²(s−1.4)]；求根轨迹与稳定 K 范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 由闭环特征方程整理等效开环并绘制根轨迹
本卷实例
  • 关键一步：把闭环特征方程整理成 1+k·G_eq(s)=0 的等效开环形式
  • 关键一步：读出开环极点 −0.75（二重）、1.4 与零点 −0.25，算渐近线与实轴交点
  • 关键一步：判实轴根轨迹段并画草图
  • 中间结果：等效开环有一个右半平面极点 1.4，是条件稳定系统
  • 卡点：整理等效开环时没有把 k 完整提到分子；实轴段判据算错
  • 卡点：结构图未读图，等效开环需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
