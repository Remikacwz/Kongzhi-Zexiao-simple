1RC 网络的动态结构图与传递函数#

思路
  • RC 网络：画动态结构图、求 U0 对 Ur 的传递函数，并讨论 R 与 C1、C2 取值是否影响稳定性
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 用复阻抗法列 RC 网络的电路方程并求传递函数
本卷实例
  • 关键一步：按电容电流关系列 KCL 方程与回路方程再作拉氏变换
  • 中间结果：消去中间电流变量得到输出对输入的有理分式
  • 卡点：网络结构以图给出，元件连接方式需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过用复阻抗法列 RC 网络的电路方程并求传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由 RC 网络求输出对输入的传递函数
本卷实例
  • 关键一步：零初始条件下对电路微分方程两边取拉氏变换
  • 中间结果：整理成 s 的多项式之比，分母即特征多项式
  • 卡点：网络初始状态为零才能把微分方程直接化为代数方程
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由 RC 网络求输出对输入的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
劳斯判据 稳定性分析
本卷考法
  • 讨论元件取值是否影响 RC 网络的稳定性
本卷实例
  • 关键一步：看特征多项式各项系数是否全部为正
  • 中间结果：二阶系统系数全为正则极点都落在左半平面
  • 卡点：结论取决于元件取值的正负而不是大小
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过讨论元件取值是否影响 RC 网络的稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

2由误差响应反求系统参数#

思路
  • 已知单位阶跃下的误差响应 e(t) 为两个指数之和，反求结构图中的 K、p、a、b
误差定义与误差传递函数 稳态误差
本卷考法
  • 由误差响应 e(t) 求误差传递函数并反推闭环传函
本卷实例
  • 关键一步：对 e(t) 作拉氏变换得到误差传递函数
  • 中间结果：由闭环传函等于一减误差传函得到闭环传函
  • 卡点：误差响应是单位阶跃下的，须先除以 1/s 才是误差传函
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由误差响应 e(t) 求误差传递函数并反推闭环传函
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 对照给定结构形式的闭环传函确定待定参数
本卷实例
  • 关键一步：用终值定理由稳态误差定出开环增益
  • 中间结果：把两个闭环传函的系数逐项对照
  • 卡点：题给闭环传函含 s 的幂次 p，须先判断 p 的取值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过对照给定结构形式的闭环传函确定待定参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

3根轨迹上的点、闭环根与稳定范围#

思路
  • G(s)=K 除以三个一阶因子之积：证明给定点在根轨迹上，由一根求其余根与增益，再求稳定时增益范围
根轨迹的基本概念与幅相条件 根轨迹法
本卷考法
  • 用相角条件证明给定点是否在根轨迹上
本卷实例
  • 关键一步：把各开环零极点指向该点的相角按相角条件累加
  • 中间结果：相角总和为 180 度的奇数倍时点在轨迹上
  • 卡点：相位计算须区分各矢量所在象限，否则会差 360 度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹是开环某一参数由 0 变到无穷时闭环极点在 s 平面上的移动轨迹
  • 同时满足相角条件与幅值条件的 s 才是根轨迹上的点
  • 相角条件决定根轨迹的形状，幅值条件决定对应的参数值
  • 常规根轨迹以开环增益 K 为可变参数
步骤
  • 写出以 K 为参变量的闭环特征方程
  • 整理成 1+KG₀(s)=0 的标准形式
  • 用相角条件判断某点是否在根轨迹上
通用考法
  • 本卷考过用相角条件证明给定点是否在根轨迹上
  • 判断给定点是否在根轨迹上
  • 由幅值条件求该点对应的 K
  • 说明相角条件与幅值条件各自的作用
常见易错
  • 把相角条件的 180° 写成 0°（正反馈时才用 0°）
  • 用幅值条件判点，搞混两个条件的用途
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 由已知的一个闭环根求其余闭环根
本卷实例
  • 关键一步：共轭根成对出现，再用根之和等于常数求第三个根
  • 中间结果：闭环特征方程三次项系数给出全部根之和
  • 卡点：三次项系数归一后根之和才等于开环极点之和的相反数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过由已知的一个闭环根求其余闭环根
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求使闭环系统稳定的开环增益范围
本卷实例
  • 关键一步：用劳斯判据令劳斯表首列元素全部为正
  • 中间结果：特征方程首列含增益，解出两个端点后取交集
  • 卡点：端点处系统临界稳定，稳定区间不取等号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求使闭环系统稳定的开环增益范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式

4奈氏图绘制与奈氏判据#

思路
  • G(s)=K(s/3+1)/[s(s-1)]：画 K 给定时的奈氏图并判稳，再讨论增益对稳定性的影响并求临界增益
频率特性的物理意义与求法 频域分析
本卷考法
  • 写出开环幅相特性的实部与虚部表达式
本卷实例
  • 关键一步：把 s 换成 jω 代入开环传函并分离实部与虚部
  • 中间结果：求出曲线与实轴和虚轴的交点以定形状
  • 卡点：含积分环节，起点相角要单独处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过写出开环幅相特性的实部与虚部表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据判断闭环稳定性并求临界增益
本卷实例
  • 关键一步：先数开环右半平面极点数，再看曲线包围临界点的圈数
  • 中间结果：由曲线与负实轴交点求临界开环增益
  • 卡点：该开环有一个右半平面极点，不能只数包围圈数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据判断闭环稳定性并求临界增益
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式

5Bode 图反求传函与串联校正25 分#

思路
  • 由给定的对数幅频特性写原系统传函并求相角裕度，写出校正装置传函，再写校正后传函并用劳斯判据判稳
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频特性渐近线写出开环传递函数
本卷实例
  • 关键一步：由低频段高度求开环增益，由各段斜率变化定环节
  • 中间结果：转折频率处斜率变化负 20 或正 20 各对应一阶环节
  • 卡点：Bode 图以图给出，转折频率与高度需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频特性渐近线写出开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 由幅值穿越频率求原系统的相角裕度并判稳
本卷实例
  • 关键一步：把穿越频率代入相频特性求相角裕度
  • 中间结果：相角裕度大于零判为稳定
  • 卡点：穿越频率已给定，勿与转折频率混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
