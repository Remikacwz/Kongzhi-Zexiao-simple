一一、由微分方程组与结构求传递函数#

思路
  • 由给出的两个一阶微分方程与方框图求中间传递函数，再化简得闭环传递函数
传递函数的定义与基本性质 传递函数
本卷考法
  • 由微分方程在零初始条件下写传递函数
本卷实例
  • 关键一步：对两个微分方程分别取拉氏变换
  • 中间结果：得到中间环节的传递函数形式
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由微分方程在零初始条件下写传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过忽略零初始条件把初值带进变换
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

多回路系统的逐层化简 结构图与方框图
本卷考法

本卷实例

  • 中间结果：分母为开环乘积加一的二阶多项式
  • 卡点：比较点与引出点位置易看错，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤

  • 把内环替换为等效环节

常见易错

  • 化简内环时把外环的信号当成常数处理

思路
  • 由 G1 的阶跃响应反求其传函，化简闭环后求稳态输出、超调与调节时间，并用定义法求稳态误差
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法

本卷实例

  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角

  • 按 ξ 的取值判断响应类型
通用考法

  • 在 s 平面上标出闭环极点的位置

三三、根轨迹与稳定范围、无超调及阻尼比取值#

思路
  • 闭环特征方程等效为参数根轨迹，画根轨迹求稳定 K 范围，再由无超调与阻尼比条件求 K
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制以 K 为参数的三极点根轨迹
本卷实例
  • 关键一步：由特征方程反写等效开环传函定零极点
  • 中间结果：实轴段与渐近线由极点分布确定
  • 卡点：根轨迹草图须与方程一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制以 K 为参数的三极点根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 本卷考过渐近线夹角公式中的系数写错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
