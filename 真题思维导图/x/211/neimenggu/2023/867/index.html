1有源网络的传递函数15 分#

思路
  • 有源网络（含运放与 RC 元件）：用复阻抗法与虚短虚断求系统传递函数 G(s)
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 用虚短虚断与复阻抗法求有源网络的传递函数
本卷实例
  • 关键一步：用虚短虚断判断运放两输入端的电位与电流关系
  • 中间结果：把电容写成 1 除以 sC 后用分压与并联关系列式
  • 卡点：网络结构以图给出，运放接法与反馈元件需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过用虚短虚断与复阻抗法求有源网络的传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

由电路或机械系统求传递函数 传递函数
本卷考法

本卷实例

  • 卡点：分子分母都含 s 的一次项，不能把常数项丢掉
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由有源网络求输出对输入的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错

  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

2结构图极点配置与前馈设计20 分#

思路
  • 已知系统结构图：由期望闭环极点求 K1、K2，再设计前馈 G(s) 使单位阶跃输入下稳态误差为零
反馈校正与复合控制 系统校正
本卷考法
  • 用局部反馈与复合控制实现极点配置与不变性
本卷实例
  • 关键一步：写出含增益 K1、K2 的闭环特征方程
  • 中间结果：前馈加入不改变闭环稳定性，只影响误差
  • 卡点：结构图以图给出，K1、K2 的接入位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过用局部反馈与复合控制实现极点配置与不变性
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环特征方程与期望极点展开式比较系数
本卷实例
  • 关键一步：由期望共轭极点展开成二阶特征多项式
  • 中间结果：与含增益的特征多项式逐项比较解出增益
  • 卡点：期望极点的实部与虚部符号易在展开时写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环特征方程与期望极点展开式比较系数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

减小稳态误差的措施 稳态误差
本卷考法
  • 设计前馈补偿器使单位阶跃下稳态误差为零
本卷实例
  • 关键一步：令闭环误差传递函数的分子在 s 等于零处为零
  • 中间结果：由此反解前馈通道传函的形式
  • 卡点：前馈不影响稳定性，但设计后仍要复核闭环稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计前馈补偿器使单位阶跃下稳态误差为零
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

3根轨迹绘制与阻尼特性分析20 分#

思路
  • 给定控制系统结构图：画根轨迹并分析增益取值对系统阻尼特性（欠阻尼、过阻尼）的影响
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画出系统的根轨迹
本卷实例
  • 关键一步：先定实轴轨迹段与渐近线，再定轨迹走向
  • 中间结果：由开环零极点分布画出根轨迹草图
  • 卡点：结构图以图给出，开环零极点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画出系统的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点并求对应的临界增益
本卷实例

  • 中间结果：把分离点代入幅值条件得临界增益
  • 卡点：分离点方程可能有多解，要按在轨迹上取舍
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点并求对应的临界增益
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由增益取值判断系统的阻尼特性
本卷实例
  • 关键一步：由闭环极点实部与虚部判断欠阻尼或过阻尼
  • 中间结果：两个分离点把增益分成三段阻尼状态
  • 卡点：临界阻尼对应分离点处的增益，要单独说明

  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响

  • 由极点位置估指标时忽略零点的作用

4开环幅相曲线与奈氏判据20 分#

思路
  • G(s)=10(s²-2s+5)/[(s+3)(s+0.5)]：画开环幅相特性曲线并用奈奎斯特判据判断闭环稳定性
频率特性的物理意义与求法 频域分析
本卷考法
  • 写出开环幅相特性并求其与实轴的交点
本卷实例
  • 关键一步：把 s 换成 jω 代入并令虚部为零求穿越频率
  • 中间结果：再由实部表达式读出该频率处的实部值
  • 卡点：传递函数含右半平面零点，幅相曲线走向易判反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过写出开环幅相特性并求其与实轴的交点
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
最小相位系统与非最小相位系统 频域分析
本卷考法
  • 判断系统是否最小相位并说明对相位的影响
本卷实例
  • 关键一步：判断分子二次式是否有右半平面零点
  • 中间结果：有右半平面零点时相位滞后更大
  • 卡点：不能只看幅频特性就断定系统类型
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过判断系统是否最小相位并说明对相位的影响
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据判断闭环系统稳定性
本卷实例
  • 关键一步：数开环右半平面极点数并看曲线包围临界点情况
  • 中间结果：由闭环右半平面极点数公式判断稳定性
  • 卡点：穿越次数要区分正穿越与负穿越
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据判断闭环系统稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

5串联校正与相角裕量25 分#

思路
  • 单位负反馈 G(s)=2000/[s(s+2)(s+20)] 加串联校正后开环对数幅频渐近线：写校正装置、判类型、画渐近线、算相角裕量
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由校正后的对数幅频渐近线写出开环传递函数
本卷实例
  • 关键一步：由各段斜率变化定出校正后传函的转折频率
  • 中间结果：由低频段高度或截止频率条件求开环增益
  • 卡点：校正后渐近线以图给出，转折频率需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
