一1一1、一阶系统阶跃响应随增益变化10 分#

思路
  • G(s)=K/(Ts+1)：画不同放大倍数 K 下的单位阶跃响应曲线并比较各自特点
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由一阶传函画单位阶跃响应曲线并比较不同 K
本卷实例
  • 关键一步：对 K/(Ts+1) 乘 1/s 后取拉氏反变换
  • 中间结果：响应为按指数规律趋近终值 K 的曲线
  • 卡点：放大倍数只改变终值，不改变时间常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由一阶传函画单位阶跃响应曲线并比较不同 K
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 本卷考过把不同 K 的曲线误画成不同时间常数
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
典型环节及其特性 传递函数
本卷考法
  • 识别一阶惯性环节并写出其时间常数
本卷实例
  • 关键一步：由传函分母写出惯性时间常数 T
  • 中间结果：一阶惯性环节的转角频率为 1/T
  • 卡点：增益 K 不进入时间常数，只影响曲线高度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过识别一阶惯性环节并写出其时间常数
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 本卷考过把惯性环节与积分环节混为一谈
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减

一2一2、截止频率对动态性能的影响10 分#

思路
  • 比较闭环截止频率增大时峰值时间与调整时间的变化，并说明对动态性能的影响
闭环频率特性与性能指标 频域分析
本卷考法
  • 说明闭环带宽与响应速度、峰值时间的关系
本卷实例
  • 关键一步：由闭环幅频特性看带宽随截止频率的变化
  • 中间结果：带宽越大则系统响应越快
  • 卡点：带宽过大易放大高频噪声
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性
步骤
  • 由开环频率特性求闭环频率特性
  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过说明闭环带宽与响应速度、峰值时间的关系
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 本卷考过把开环截止频率与闭环带宽混为一谈
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 定性判断峰值时间与调整时间随带宽的变化
本卷实例
  • 关键一步：用带宽与时间尺度成反比的规律作比较
  • 中间结果：截止频率增大时两指标均减小
  • 卡点：题面未给具体数值，只作趋势判断
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过定性判断峰值时间与调整时间随带宽的变化
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过把峰值时间与上升时间混用
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

一3一3、一阶环节的状态变量图10 分#

思路
  • 画 G(s)=1/(Ts+1) 的状态变量图，并说明状态变量图由哪几类图形符号组成
状态空间表达式的建立 状态空间分析
本卷考法
  • 由一阶传递函数画状态变量图
本卷实例
  • 关键一步：把 1/(Ts+1) 写成积分器加反馈的连接
  • 中间结果：用积分器、比例器与加法器搭成一阶结构
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由一阶传递函数画状态变量图
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 本卷考过状态变量个数与系统阶数不符
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式
由传递函数写状态空间表达式 状态空间分析
本卷考法
  • 说明状态变量图所用图形符号的种类
本卷实例
  • 关键一步：按信号流向把各符号连成有向图
  • 中间结果：常用符号为加法器、积分器、比例器与连接线
  • 卡点：符号种类以本题要求为准
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 同一传递函数可对应无穷多个状态空间实现
  • 常用能控标准型、能观标准型与对角标准型
  • 能控标准型的 A 阵为友矩阵形式
  • 最小实现要求系统既能控又能观
步骤
  • 把传递函数化为真分式，分离直接项 D
  • 按标准型规则写出 A、B、C、D
  • 必要时用线性变换换成其他标准型
通用考法
  • 本卷考过说明状态变量图所用图形符号的种类
  • 由传递函数写出能控标准型
  • 由传递函数写出能观标准型
  • 判断给定的实现是否为最小实现
常见易错
  • 本卷考过漏数连接线而只报加法器与积分器
  • 真分式化分时直接项 D 处理错误
  • 友矩阵中系数符号写反

二1二1、复合校正前馈补偿设计10 分#

思路
  • 复合校正系统 N(s) 为负载扰动，设计前馈补偿装置使系统输出不受扰动影响
反馈校正与复合控制 系统校正
本卷考法
  • 设计前馈补偿器实现扰动不变性
本卷实例
  • 关键一步：令扰动到输出的传递函数恒等于零
  • 中间结果：解出补偿装置关于各环节参数的表达式
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过设计前馈补偿器实现扰动不变性
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 本卷考过补偿器含高阶微分却直接采用
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 由扰动传函分析扰动对输出的影响
本卷实例
  • 关键一步：分别列给定与扰动两条传递通道
  • 中间结果：扰动通道的分子就是补偿设计的目标
  • 卡点：两输入同时存在须用叠加原理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过由扰动传函分析扰动对输出的影响
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 本卷考过求扰动传函时未把参考输入置零
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

二2二2、闭环特征根实部约束求K范围#

思路
  • G(s)=K/[s(1+0.33s)(1+0.107s)]，要求闭环特征根实部均小于 -1，求 K 的取值范围
参数稳定域的确定 稳定性分析
本卷考法
  • 求使闭环极点都位于指定竖线左侧的参数范围
本卷实例
  • 关键一步：令 s 等于新变量减一，把边界竖线映射为虚轴
  • 中间结果：得到以新变量为自变量的特征多项式
  • 卡点：需对全部系数不等式取交集
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求使闭环极点都位于指定竖线左侧的参数范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 本卷考过把 s 换成新变量后忘记回代检验
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据确定参数稳定域
本卷实例
  • 关键一步：对变换后的特征式列劳斯表
  • 中间结果：首列各元素同号给出参数上下限
  • 卡点：端点处为临界稳定，稳定区间不取等号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理

  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据确定参数稳定域
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过首列出现零时未用小扰动法
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

思路

根轨迹的绘制法则 根轨迹法

要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
