一一、液位系统建模与结构图传函15 分#

思路
  • 先由流量平衡列写水槽水位与流入量的微分方程，据微分方程画出方块图并求传递函数；再由给定结构图求另一路传递函数
传递函数的定义与基本性质 传递函数
本卷考法
  • 由液位系统的微分方程求传递函数
本卷实例
  • 关键一步：对流量平衡微分方程在零初始条件下作拉氏变换
  • 中间结果：整理后得到液位对流入量的比值
  • 卡点：液阻与液容定义式易列反，对象参数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由液位系统的微分方程求传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由微分方程画出液位系统的方块图
本卷实例
  • 关键一步：把微分方程各项对应成环节并连接成闭环
  • 中间结果：进水流量与液位反馈构成一阶闭环结构
  • 卡点：方块图须与微分方程各项一一对应，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由微分方程画出液位系统的方块图
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求给定结构图的传递函数
本卷实例
  • 关键一步：由信号流图找全部回路与前向通路
  • 中间结果：特征式由各回路增益及不接触回路乘积组成
  • 卡点：不接触回路与余子式须逐一核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求给定结构图的传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式

二二、由阶跃响应反求传函与正弦稳态15 分#

思路
  • 由单位阶跃响应表达式先求单位脉冲响应与传递函数，再把正弦输入的频率代入传递函数求稳态响应
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应求单位脉冲响应
  • 反求系统的传递函数
本卷实例
  • 关键一步：零初始条件下单位脉冲响应等于阶跃响应的导数
  • 中间结果：对脉冲响应作拉氏变换即得传递函数
  • 卡点：阶跃响应初值须为零才能用求导法
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应求单位脉冲响应
  • 本卷考过反求系统的传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 求正弦输入下系统的稳态响应
本卷实例
  • 关键一步：把 jω 代入传递函数求该频率处的幅值与相角
  • 中间结果：稳态响应为同频正弦，幅值和相角由频率特性决定
  • 卡点：求稳态响应前须确认系统稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求正弦输入下系统的稳态响应
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式

三三、根轨迹绘制与比例微分影响20 分#

思路
  • 对开环 G0 绘制参数 K 变化时的根轨迹并判断稳定性；再加入比例微分控制器后重绘根轨迹，说明附加开环零点对稳定性的影响
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则绘制含重极点系统的根轨迹
本卷实例
  • 关键一步：先标开环零极点并确定实轴根轨迹段与渐近线
  • 中间结果：渐近线交点和夹角由开环极点与零点分布求出
  • 卡点：重极点处的分离点须用重根条件求
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则绘制含重极点系统的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 判断参数变化时系统是否稳定
本卷实例
  • 关键一步：求根轨迹与虚轴交点及对应临界参数
  • 中间结果：根轨迹是否全部位于左半平面决定闭环稳定性
  • 卡点：不能仅凭极点起点位置下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过判断参数变化时系统是否稳定
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 说明加比例微分环节引入开环零点的影响
本卷实例
  • 关键一步：比较加减零点前后实轴根轨迹段与渐近线方向
  • 中间结果：附加开环零点使根轨迹向左弯曲，稳定性改善
  • 卡点：零点位置若不在实轴根轨迹段上则影响有限
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过说明加比例微分环节引入开环零点的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反

四四、劳斯判据与稳态误差系数20 分#

思路
  • 由含内反馈的系统结构图写闭环特征方程，用劳斯判据分析内反馈对稳定性的影响；再求三类静态误差系数并计算典型输入下的稳态误差
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据分析内反馈对系统稳定性的影响
本卷实例
  • 关键一步：由结构图写闭环特征方程并列出劳斯表
  • 中间结果：劳斯表首列符号随内反馈系数变化
  • 卡点：内反馈引入的零点易与开环极点混，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据分析内反馈对系统稳定性的影响
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 求静态位置、速度与加速度误差系数
本卷实例
  • 关键一步：先判系统型别，再由开环传递函数在原点附近取极限
  • 中间结果：三个静态误差系数由开环传函在原点附近的幂次项决定
  • 卡点：型别数错会使三个系数全部出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过求静态位置、速度与加速度误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位阶跃、斜坡与加速度输入下的稳态误差
本卷实例
  • 关键一步：按系统型别套用典型输入下的稳态误差公式
  • 中间结果：各输入下误差由对应静态误差系数决定
  • 卡点：须先判稳，不稳定时讨论稳态误差无意义
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位阶跃、斜坡与加速度输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

五五、由 Bode 图反求传函与相频特性20 分#

思路
  • 由最小相位系统开环对数幅频渐近特性读出型别、增益与各转折频率，写出传递函数；再由各环节相频叠加绘制相频特性曲线
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频渐近特性反求最小相位传递函数
本卷实例
  • 关键一步：低频段斜率定积分环节数，高度定开环增益
  • 中间结果：各转折频率处斜率升降对应一阶环节的零点或极点
  • 卡点：低频段延长线交点须按型别折算，读数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
