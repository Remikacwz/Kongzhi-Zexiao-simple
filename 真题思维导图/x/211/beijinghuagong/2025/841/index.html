1一、多输入方框图的闭环传递函数#

思路
  • 图1为双输入控制系统，用叠加原理分别令另一输入为零，把方框图逐层化简或列信号流图用梅森公式，分别求两条输入到输出的闭环传递函数。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别令R2与R1为零，求两条输入到输出的闭环传函
本卷实例
  • 关键一步：先按叠加原理把双输入问题拆成两个单输入问题
  • 中间结果：两条输入通道各自的前向通路与回路结构不同
  • 卡点：方框图未读图，比较点与引出点位置需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别令R2与R1为零，求两条输入到输出的闭环传函
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

多回路系统的逐层化简 结构图与方框图
本卷考法
  • 对多回路方框图逐层化简求等效闭环传函
本卷实例
  • 关键一步：从最内层回路开始，把内环化成等效环节
  • 中间结果：化简后分别得到两条输入的前向与反馈通道
  • 卡点：令某个输入为零时，被断开的支路容易漏掉
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过对多回路方框图逐层化简求等效闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式写前向通路与余子式求双输入传函
本卷实例
  • 关键一步：先数清独立回路与两两不接触回路，再写特征式
  • 中间结果：两条输入对应不同的前向通路增益
  • 卡点：不同输入的前向通路不能混入同一个余子式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式写前向通路与余子式求双输入传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、最小相位系统Bode图、稳定裕度与Nyquist判稳#

思路
  • 由图2渐近对数幅频特性读出型别、增益与转折频率写出最小相位模型G1(s)，按剪切频率求相角裕度γ；由γ要求反求串联增益k；画Nyquist曲线并数包围圈判稳；再用Gc(s)=k(1+0.5s)构成闭环，由超调量定阻尼比并求k与调节时间。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由渐近对数幅频特性曲线写出最小相位G1(s)
本卷实例
  • 关键一步：低频段斜率定积分环节个数，高度定开环增益
  • 中间结果：各转折频率逐段对应一阶环节的时间常数
  • 卡点：图2曲线未读图，转折频率与低频高度需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由渐近对数幅频特性曲线写出最小相位G1(s)
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 由G1的相频求剪切频率处的相角裕度γ
本卷实例
  • 关键一步：先由幅频曲线零分贝点确定剪切频率
  • 中间结果：在该频率读相角，按180度加相角得γ
  • 卡点：剪切频率与相位穿越频率是两个不同频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由G1的相频求剪切频率处的相角裕度γ
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

奈奎斯特判据 稳定性分析
本卷考法
  • 画Nyquist曲线并按包围圈数判断闭环稳定
本卷实例
  • 关键一步：先数开环在右半平面的极点个数P
  • 中间结果：曲线对负1点的净包围圈数N与P相加得Z
  • 卡点：小半圆绕行方向与曲线画法需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过画Nyquist曲线并按包围圈数判断闭环稳定
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

由性能指标要求反求参数 时域响应与动态性能

  • 由超调量指标反求阻尼比，再定增益k与调节时间
本卷实例
  • 关键一步：由超调量公式反解阻尼比ξ
  • 中间结果：把闭环特征方程与标准二阶形式逐项比对
  • 卡点：G1(s)的阶次与零点影响需回原卷核对图2
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量指标反求阻尼比，再定增益k与调节时间
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 按百分之二误差带求欠阻尼系统的调节时间
本卷实例
  • 关键一步：先由闭环极点读出阻尼比与自然频率
  • 中间结果：调节时间与阻尼比和自然频率的乘积成反比
  • 卡点：误差带取百分之二时用对应的调节时间系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过按百分之二误差带求欠阻尼系统的调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3三、含参四阶特征方程的劳斯判据#

思路
  • 闭环传递函数分母为含参数T的四阶特征多项式，按降幂排列补缺项后列劳斯表，令首列元素全部同号，取各不等式解集的交集得T的稳定范围。
劳斯判据 稳定性分析
本卷考法
  • 对含参T的四阶特征方程列劳斯表判稳
本卷实例
  • 关键一步：把特征多项式按降幂排列，缺项补零后列劳斯表
  • 中间结果：首列各元素含参数T，令其全部大于零
  • 卡点：某行首元为零时需用ε法或辅助多项式处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过对含参T的四阶特征方程列劳斯表判稳
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 把劳斯表首列同号条件化为T的稳定范围
本卷实例
  • 关键一步：取各不等式解集的交集得到T的允许区间
  • 中间结果：稳定边界对应特征根落在虚轴上的T值
  • 卡点：只令某一行首元为正会漏掉其余约束
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过把劳斯表首列同号条件化为T的稳定范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

4四、结构图极点配置与零稳态误差#

思路
  • 图3结构含增益参数k1、k2，先由给定闭环极点写期望特征多项式，与含参数的实际闭环特征方程比较系数求出k1、k2；再令R(s)单独作用时误差的稳态值为零，反求G1(s)应具有的结构。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由给定闭环极点反求结构图的增益k1与k2
本卷实例
  • 关键一步：把闭环特征方程整理成含k1、k2的形式
  • 中间结果：与由给定极点写出的期望多项式逐项比对系数
  • 卡点：图3结构未读图，k1、k2所在支路位置需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 由A的特征值与特征向量求状态转移矩阵，代入初始条件求x(t)；再用状态反馈u等于负Kx把闭环极点配置到负2二重根，比较系数求反馈阵K；最后按采样周期T离散化，分析能控能观与稳定性的保持条件。
状态转移矩阵 状态空间分析
本卷考法
  • 由特征值与特征向量求状态转移矩阵并求x(t)
本卷实例
  • 关键一步：按特征分解写出矩阵指数，或用拉氏反变换求转移矩阵
  • 中间结果：x(t)由状态转移矩阵作用在初始状态上得到
  • 卡点：A的特征向量含复数，需回原卷核对共轭配对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过由特征值与特征向量求状态转移矩阵并求x(t)
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错

状态反馈与极点配置 状态空间分析
本卷考法
  • 设计状态反馈把闭环极点配置到负2二重根
本卷实例
  • 关键一步：先验证能控性，再由期望极点写特征多项式
  • 中间结果：令闭环特征多项式与期望多项式系数相等解出K
  • 卡点：反馈增益符号容易整体取反，需代回验算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态反馈 u=-Kx+v 可任意配置闭环极点，前提是系统完全能控
  • 状态反馈不改变系统的零点
  • 极点配置通过比较期望与实际的闭环特征多项式求解 K
  • 状态反馈可能改变能观性
步骤
  • 先验证系统能控
  • 写出希望配置的极点并求期望特征多项式
  • 求闭环系统特征多项式 det(sI-A+BK)
  • 比较系数解出反馈增益阵 K
通用考法
  • 本卷考过设计状态反馈把闭环极点配置到负2二重根
  • 设计状态反馈使闭环极点位于指定位置
  • 判断给定极点是否可通过状态反馈配置
  • 分析状态反馈对系统性能的影响
常见易错
  • 未验证能控性就直接做极点配置
  • 特征多项式比较系数时符号写反

连续系统的离散化 离散控制系统
本卷考法
  • 求使离散化后能控能观性保持的采样周期T
本卷实例
  • 关键一步：写出离散状态矩阵并构造离散能控、能观矩阵
  • 中间结果：矩阵在采样周期取某些值时会降秩
  • 卡点：离散化可能使能控能观性发生退化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离散化状态方程由状态转移矩阵在采样周期处的取值构成
  • 输入矩阵是状态转移矩阵与输入矩阵乘积在采样周期上的积分
  • 带零阶保持器时即按上述积分式离散化，输出矩阵不变
步骤
  • 求连续系统的状态转移矩阵
  • 把采样周期代入得到离散状态矩阵
  • 对输入矩阵做积分得到离散输入矩阵
  • 写出差分形式的离散状态方程并按递推求采样点上的响应
通用考法
  • 本卷考过求使离散化后能控能观性保持的采样周期T
  • 求连续系统在给定采样周期下的离散化状态方程
  • 由给出的状态响应反求系统矩阵再离散化
  • 计算采样点上的状态与输出序列
常见易错
  • 把采样周期直接当成时间常数代进连续传函
  • 积分上限写成采样周期以外的量，或忘记乘输入矩阵

能控性与能观性 状态空间分析
本卷考法
  • 分析离散化后能控能观性是否保持
本卷实例
  • 关键一步：用离散状态矩阵重新构造两个判别矩阵
  • 中间结果：能控与能观对采样周期的要求可能不同
  • 卡点：源文只给连续系统数据，离散化方式需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过分析离散化后能控能观性是否保持
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
常见易错
  • 只算到 A^{n-2}B 就下结论
  • 把能控性判据与能观性判据的矩阵构造搞混

离散系统稳定性分析 离散控制系统
本卷考法
  • 分析采样周期T对离散系统稳定性的影响
本卷实例
  • 关键一步：比较离散化后特征根的模与单位圆的关系
  • 中间结果：稳定要求特征根全部落在z平面单位圆内
  • 卡点：采样周期增大使特征根向单位圆靠近
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过分析采样周期T对离散系统稳定性的影响
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒

采样过程与香农采样定理 离散控制系统
本卷考法
  • 说明工程上采样周期选择的一般原则
本卷实例
  • 关键一步：按信号带宽与香农采样定理给出采样周期上限
  • 中间结果：兼顾数字实现与稳定性、能控能观的要求
  • 卡点：源文问是否具有一般性，需回原卷核对题意侧重
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 采样把连续信号变成脉冲序列，采样周期 T 是关键参数
  • 采样定理要求采样频率不低于信号最高频率的两倍
  • 采样频率不足会产生频率混叠
  • 零阶保持器把离散信号恢复为连续信号，并引入半个采样周期的延迟
步骤
  • 确定信号最高频率或系统带宽
  • 按采样定理确定采样频率与采样周期上限
  • 必要时加入前置滤波器抑制混叠
通用考法
  • 本卷考过说明工程上采样周期选择的一般原则
  • 由信号最高频率确定采样周期
  • 判断给定采样频率是否满足采样定理
  • 说明零阶保持器的频率特性
常见易错
  • 把采样定理写成采样周期不大于信号周期即可
  • 忽略零阶保持器带来的相位滞后
