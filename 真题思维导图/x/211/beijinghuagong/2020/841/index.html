串联、并联与反馈等效 结构图与方框图
本卷考法

本卷实例

  • 中间结果：方框图按串联与反馈等效后得闭环传函

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

思路

广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以参数a为变量绘制参数根轨迹
本卷实例
  • 关键一步：把含a项整理成以a为增益的等效开环
  • 中间结果：a大于零按180度轨迹、a小于零按零度轨迹
  • 卡点：正负参数对应不同相角条件，不能混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以参数a为变量绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

四四、方框图稳定性与不变性补偿#

思路
  • 由图3方框图写闭环特征方程求稳定条件，再求使斜坡输入稳态误差为零的补偿器
劳斯判据 稳定性分析
本卷考法
  • 由方框图写闭环特征方程并用劳斯判据求稳定条件
本卷实例
  • 关键一步：用梅森公式或等效化简写闭环特征多项式
  • 中间结果：稳定条件由劳斯表首列各项为正给出
  • 卡点：各环节时间常数与增益的对应需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由方框图写闭环特征方程并用劳斯判据求稳定条件
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 设计补偿器使斜坡输入下稳态误差为零
本卷实例
  • 关键一步：由误差传函令常数项与一次项同时为零
  • 中间结果：令误差传函分子低次项系数为零可提高无差度
  • 卡点：提高无差度可能降低稳定裕度，须回验稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计补偿器使斜坡输入下稳态误差为零
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

五五、Bode图、相角裕度与微分环节作用#

思路

开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制含积分环节系统的开环对数渐近幅频特性
本卷实例
  • 关键一步：由低频段斜率定积分环节个数与增益
  • 中间结果：按各转折频率逐段改变斜率
  • 卡点：低频段起始高度与型别的对应不能只读交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过绘制含积分环节系统的开环对数渐近幅频特性
  • 绘制开环对数渐近幅频特性
