一一、无源网络与运放电路求传递函数#

思路
  • 两个电路图分别求传递函数：无源 RLC 网络用复阻抗分压；含运算放大器的网络用虚短虚断列节点方程
由电路或机械系统求传递函数 传递函数
本卷考法
  • 用复阻抗法求 RLC 网络的传递函数
本卷实例
  • 关键一步：把电容电感表示为复阻抗后按串联分压列式
  • 中间结果：传递函数为输出支路阻抗除以总阻抗
  • 卡点：元件连接与分压节点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过用复阻抗法求 RLC 网络的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由运算放大器电路求传递函数
本卷实例
  • 关键一步：利用虚短与虚断条件建立节点电流方程
  • 中间结果：反馈支路阻抗与输入支路阻抗之比决定传递函数
  • 卡点：反相输入的负号与含电容支路整理易漏
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由运算放大器电路求传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

二二、结构图多输入闭环传递函数#

思路
  • 对同一结构图分别求输出对给定输入的闭环传函，以及输出对两个独立输入信号的传递函数
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求输出对给定输入的闭环传函
本卷实例
  • 关键一步：数清全部独立回路与前向通路并写特征余子式
  • 中间结果：特征式由回路增益与不接触回路乘积组成
  • 卡点：不接触回路易漏或重复计数，需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求输出对给定输入的闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求多输入系统中输出对各输入的传递函数
本卷实例
  • 关键一步：分别令其余输入为零，逐路求前向通路与余子式
  • 中间结果：各路传函分母相同、分子即对应前向通路增益
  • 卡点：求某一路时未把另一个输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求多输入系统中输出对各输入的传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

三三、由超调量与稳态误差设计参数#

思路
  • 由给定超调量反求阻尼比，再由斜坡输入稳态误差定开环增益与结构参数；最后在给定通道串入控制器使斜坡输入下稳态误差为零
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由超调量与稳态误差要求反求结构参数
本卷实例
  • 关键一步：先由超调量反求阻尼比，再由稳态误差确定开环增益
  • 中间结果：两个指标分别对应阻尼比与增益两个待求参数
  • 卡点：只满足单项指标就下结论，须两指标交叉验证
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由超调量与稳态误差要求反求结构参数
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量指标反求二阶系统阻尼比
本卷实例
  • 关键一步：把超调量要求代入欠阻尼二阶超调量公式反解
  • 中间结果：由超调量可解出唯一的欠阻尼阻尼比
  • 卡点：超调量公式漏乘百分之百会差两个数量级
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量指标反求二阶系统阻尼比
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 设计控制器使斜坡输入下稳态误差为零
本卷实例
  • 关键一步：提高系统型别使速度误差系数趋于无穷
  • 中间结果：在给定通道串入积分环节可消除斜坡稳态误差
  • 卡点：增加积分环节会降低稳定裕度，须兼顾稳定性
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计控制器使斜坡输入下稳态误差为零
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式

四四、含右半平面零点的根轨迹与闭环传函#

思路
  • 开环含一个右半平面零点，先绘参数 K 变化的根轨迹并求虚轴交点定稳定范围；再由已知闭环极点用幅值条件定参数并写闭环传递函数
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制含右半平面零点的根轨迹
本卷实例
  • 关键一步：由开环零极点定分支数、实轴段与渐近线方向
  • 中间结果：非最小相位系统的根轨迹可能先向右再折返
  • 卡点：右半平面零点使形状复杂，须逐段按法则判
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制含右半平面零点的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由根轨迹与虚轴交点确定使系统稳定的参数范围
本卷实例
  • 关键一步：把 s 等于 jω 代入闭环特征方程并分离实部虚部
  • 中间结果：由实部与虚部两个方程联立求临界参数与交点频率
  • 卡点：只解出一个频率会漏掉另一组交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由根轨迹与虚轴交点确定使系统稳定的参数范围
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由已知闭环极点确定参数并写闭环传递函数
本卷实例
  • 关键一步：用幅值条件求该极点对应的参数值
  • 中间结果：将参数回代后由开环传函写出闭环传函
  • 卡点：由极点求参数用幅值条件，勿与相角条件混
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由已知闭环极点确定参数并写闭环传递函数
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

五五、由对数频率特性反求传函与判稳#

思路
  • 题面只给一张对数频率特性图，据同册答案段应为由幅频特性反求开环传递函数，再求剪切频率与相位穿越频率判断稳定性
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频特性反求开环传递函数
本卷实例
  • 关键一步：低频段斜率定积分环节数，低频高度定开环增益
  • 中间结果：各转折频率处斜率升降对应一阶环节
  • 卡点：原题只给图，低频高度与转折频率需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频特性反求开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 求剪切频率与相位穿越频率并判断稳定性
本卷实例
  • 关键一步：分别在幅值为一与相角为负一百八十度处求频率
  • 中间结果：比较两频率大小判断系统是否稳定
  • 卡点：相位穿越频率用于判稳，勿与剪切频率混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求剪切频率与相位穿越频率并判断稳定性
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

六六、奈奎斯特判据判断 II 型系统稳定性#

思路
  • II 型系统开环幅相曲线含两个积分环节，须补画无穷大半径圆弧，再由幅相曲线对负实轴的包围情况用奈氏判据判断闭环稳定性
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据判断 II 型系统稳定性
本卷实例
  • 关键一步：开环含两个积分环节时先补画无穷大半径圆弧
  • 中间结果：由闭环极点数等于开环极点数减两倍包围圈数判断
  • 卡点：补画圆弧要跨过正实轴方向，勿漏算包围圈数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据判断 II 型系统稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

  • 求开环或闭环脉冲传递函数
