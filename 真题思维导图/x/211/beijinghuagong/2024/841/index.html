1一、由闭环传函与初始条件求输出响应#

思路
  • 由闭环传递函数写出微分方程，代入非零初始条件作拉氏变换，解出 C(s) 后取拉氏反变换得 c(t)。
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由微分方程与初始条件求系统全响应
本卷实例
  • 关键一步：把闭环传函化为微分方程再作拉氏变换
  • 关键一步：把非零初始值代入微分定理
  • 中间结果：C(s) 的分子含初始条件项，分母为特征多项式
  • 卡点：初始条件为零时才能直接用传函求响应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由微分方程与初始条件求系统全响应
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

2二、由结构图求闭环传递函数#

思路
  • 对给定结构图先逐层化简，或直接画信号流图用梅森增益公式求 Y(s)/R(s)。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求结构图的闭环传递函数
本卷实例
  • 关键一步：独立回路有两条且互不接触
  • 关键一步：前向通路各有对应的余子式
  • 中间结果：特征式为两回路的代数和
  • 中间结果：分子为两条前向通路乘余子式之和
  • 卡点：题面含图未读图，回路增益与支路方向需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求结构图的闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

多回路系统的逐层化简 结构图与方框图
本卷考法

本卷实例
  • 关键一步：从内环开始把反馈环等效为单个环节
  • 中间结果：化简后得到输入到输出的单回路形式
  • 卡点：比较点与引出点的移动规则易混用

  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法

3三、以 a 为参数的根轨迹与等幅振荡条件#

思路
  • 把闭环特征方程整理成以 a 为可变参数的等效开环形式，按 K 的区间讨论实轴段、渐近线、分离点与起始角；再由指定角频率的等幅振荡条件确定 K 与 a。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以参数 a 为变量绘制参数根轨迹
本卷实例
  • 关键一步：把特征方程中不含 a 的项除到一边做等效开环
  • 中间结果：等效开环的零极点随 K 的区间变化
  • 卡点：参数根轨迹的相角条件仍是一百八十度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以参数 a 为变量绘制参数根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 分 K 区间画实轴段、渐近线与起始角
本卷实例
  • 关键一步：按开环零极点数目定分支数与渐近线夹角
  • 中间结果：实轴段由右侧零极点个数奇偶判定
  • 卡点：K 大于一与小于一时开环极点分布不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过分 K 区间画实轴段、渐近线与起始角
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求分离点并按是否落在实轴段取舍
本卷实例
  • 关键一步：由特征方程令增益对 s 的导数为零
  • 中间结果：分离点位置含 K，需按 K 区间分类讨论
  • 卡点：K 超过临界值时分离点方程无实根
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求分离点并按是否落在实轴段取舍
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 由等幅振荡条件求 K 与 a 及虚轴交点
本卷实例
  • 关键一步：令闭环特征方程的一对根落在虚轴上
  • 中间结果：由劳斯表辅助方程得振荡频率与参数关系
  • 卡点：虚轴交点频率须与题给振荡角频率一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过由等幅振荡条件求 K 与 a 及虚轴交点
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

4四、由结构图与阶跃响应求 K、v、T、a#

思路
  • 由结构图写闭环传函，先由稳态位置误差为零确定积分环节个数，再由阶跃响应稳态值定增益，最后由超调量与峰值时间反求阻尼比、自然频率与各时间常数。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由阶跃响应曲线与稳态值反求系统参数
本卷实例
  • 关键一步：由响应稳态值确定比例增益
  • 中间结果：闭环传函化为标准二阶形式再比系数
  • 卡点：响应曲线读数须回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由阶跃响应曲线与稳态值反求系统参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为标准二阶形式并与响应比对
本卷实例
  • 关键一步：按标准二阶形式分离阻尼比与自然频率
  • 中间结果：系数关系给出时间常数与参数的方程组
  • 卡点：二次项系数须先归一化再比对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定

步骤

  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为标准二阶形式并与响应比对
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间反求阻尼比与自然频率
本卷实例
  • 关键一步：超调量只与阻尼比有关，先解阻尼比
  • 中间结果：峰值时间公式给出自然频率
  • 卡点：比例环节不改变按百分比定义的动态指标
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与峰值时间反求阻尼比与自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

5五、由 Bode 图反求传函、稳定裕度与延时影响#

思路
  • 由最小相位系统 Bode 图读低频高度与各转折频率写开环传函；再算相角裕度与幅值裕度，用频域法求临界增益，并分析串联延时环节对稳定性的影响与允许延时上限。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由 Bode 图读转折频率与低频高度求最小相位传函
本卷实例
  • 关键一步：低频段斜率定积分环节个数与增益
  • 中间结果：每处负二十转折对应一个惯性环节
  • 卡点：转折频率与低频高度须回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
