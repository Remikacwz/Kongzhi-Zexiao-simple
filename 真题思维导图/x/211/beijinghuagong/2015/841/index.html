一一、无源网络求传递函数15 分#

思路
  • 图 1 为无源阻容网络，用电容的 s 域复阻抗与分压关系列写输出电压与输入电压之比
由电路或机械系统求传递函数 传递函数
本卷考法
  • 用复阻抗法求无源网络的传递函数
本卷实例
  • 关键一步：把电容表示为 1/(sC) 的复阻抗，按分压原理列式
  • 中间结果：分子为并联支路等效阻抗，分母为串联总阻抗
  • 卡点：网络拓扑与元件连接方式需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过用复阻抗法求无源网络的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

二二、由阶跃响应反求传函与稳定性15 分#

思路
  • 单位反馈系统阶跃响应已知，先求单位脉冲响应，再由响应关系反求开环传递函数，最后用闭环特征方程判断稳定性（第 1、2 小问据答案段补）
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应求单位脉冲响应
  • 由响应反求开环传递函数
本卷实例
  • 关键一步：零初始条件下单位脉冲响应等于阶跃响应的导数
  • 中间结果：对阶跃响应拉氏变换并除以 1/s 得闭环传函，再由闭环与开环关系反解
  • 卡点：响应表达式中含发散项，反求后须核实系统是否稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应求单位脉冲响应
  • 本卷考过由响应反求开环传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
劳斯判据 稳定性分析
本卷考法
  • 由闭环特征方程用劳斯判据判断稳定性
本卷实例
  • 关键一步：由闭环传递函数分母写出特征方程并检查各项系数符号
  • 中间结果：一次项或常数项出现负号时由劳斯判据必要条件即可判定
  • 卡点：不能仅凭极点表达式手算，须落到劳斯表首列符号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过由闭环特征方程用劳斯判据判断稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

三三、双系统根轨迹绘制与闭环极点相同20 分#

思路
  • 对图 (a)(b) 两个结构图分别以 k、p 为变量写出等效开环并绘根轨迹；再由两系统闭环极点完全相同令特征多项式对应系数相等求解
根轨迹的绘制法则 根轨迹法
本卷考法
  • 分别以 k、p 为变量绘制根轨迹
  • 确定分支数、实轴段与渐近线
本卷实例
  • 关键一步：写出各系统的开环零极点并据法则逐条绘制
  • 中间结果：两组结构图的开环极点分布不同，须分别判实轴段
  • 卡点：结构图与等效开环推导需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过分别以 k、p 为变量绘制根轨迹
  • 本卷考过确定分支数、实轴段与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点并舍去不在轨迹上的根
本卷实例
  • 关键一步：把特征方程整理成参数为 K 的显式后令 dK/ds 等于零
  • 中间结果：解出的候选根须用实轴段判据筛选
  • 卡点：不筛选会保留不在根轨迹上的伪分离点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点并舍去不在轨迹上的根
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由两系统闭环极点完全相同反求参数关系
本卷实例
  • 关键一步：分别写两系统闭环特征多项式并令同次幂系数相等
  • 中间结果：极点相同等价于两组特征多项式成比例且首项一致
  • 卡点：只比较一个系数不能保证全部极点相同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由两系统闭环极点完全相同反求参数关系
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征方程比对标准二阶形式求阻尼比与自然频率
本卷实例
  • 关键一步：把闭环特征方程与标准二阶特征式逐项比对
  • 中间结果：常数项对应自然频率平方，一次项系数对应二倍阻尼乘积
  • 卡点：参数绝对值变化对阻尼比的影响方向易说反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征方程比对标准二阶形式求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 分别求单位阶跃与单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：先确认闭环稳定，再对误差传递函数用终值定理
  • 中间结果：阶跃输入误差为零，斜坡输入误差与参数比值有关
  • 卡点：斜坡输入须带 s 平方因子，不能套用阶跃误差公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过分别求单位阶跃与单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

五五、Bode 图绘制与比例微分校正20 分#

思路
  • 已知开环传递函数，绘对数渐近幅频特性并求相位裕度；串联比例微分环节后再绘并求相位裕度，最后说明其稳定性影响
开环对数频率特性的绘制 频域分析
本卷考法
  • 绘制含积分环节系统的开环对数渐近幅频特性
本卷实例
  • 关键一步：由低频段斜率定积分环节个数，由指定频率处高度定增益
  • 中间结果：各转折频率处按正负二十分贝每十倍频逐段改斜率
  • 卡点：低频段起始高度与型别必须对应，不能只读交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过绘制含积分环节系统的开环对数渐近幅频特性
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
稳定裕度 频域分析
本卷考法
  • 由截止频率处相角求相位裕度
本卷实例
  • 关键一步：由幅频渐近线穿过零分贝求截止频率
  • 中间结果：相位裕度等于一百八十度加该频率处的开环相角
  • 卡点：截止频率与相位穿越频率不是同一频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由截止频率处相角求相位裕度
  • 求系统的相角裕度与幅值裕度
