1一、结构图求传递函数与状态空间方程#

思路
  • 图1为多回路系统结构图，用梅森公式数回路、写前向通路与余子式求闭环传递函数；再在各积分器输出端设状态变量，列写一阶微分方程组并整理成矩阵形式的状态空间表达式。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求多回路系统的闭环传递函数
本卷实例
  • 关键一步：先数清全部独立回路并写出特征式
  • 中间结果：前向通路与其余子式分别列出后代入梅森公式
  • 卡点：回路数与通路数须回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求多回路系统的闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简求等效传递函数
本卷实例
  • 关键一步：从最内层回路开始把内环化为等效环节
  • 中间结果：化简后得到前向通道与反馈通道各一条
  • 卡点：比较点与引出点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简求等效传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
状态空间表达式的建立 状态空间分析
本卷考法
  • 由结构图列写状态空间方程
本卷实例
  • 关键一步：在每个积分器输出端设状态变量写其一阶导数
  • 中间结果：输出方程可能含输入直通项，D 不为零
  • 卡点：输出是否含直通项需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由结构图列写状态空间方程
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

2二、前馈补偿与二阶系统稳态和动态指标#

思路
  • 图2为含前馈补偿 Fr(s) 的复合控制系统，先写误差传递函数并令单位加速度输入下稳态误差为零解出前馈参数；再令前馈为零，把闭环特征方程比对标准二阶形式求阻尼比与自然频率，最后由百分之五误差带求调节时间。
反馈校正与复合控制 系统校正
本卷考法
  • 由前馈补偿器求加速度输入下稳态误差为零的参数
本卷实例
  • 关键一步：把误差传递函数写成含前馈补偿器的表达式
  • 中间结果：令误差分子中 s 的低次项系数为零
  • 卡点：前馈通道位置与符号需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过由前馈补偿器求加速度输入下稳态误差为零的参数
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位加速度输入下的稳态误差并令其为零
本卷实例
  • 关键一步：先判稳再用终值定理求加速度输入的稳态值
  • 中间结果：对误差传递函数取 s 趋于零的极限
  • 卡点：未判稳就取极限会得到无效结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位加速度输入下的稳态误差并令其为零
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征方程比对标准二阶形式求阻尼比与自然频率
本卷实例
  • 关键一步：把闭环特征多项式与标准二阶特征式逐项比对
  • 中间结果：常数项开方得自然频率，一次项系数定阻尼比
  • 卡点：二次项系数须先归一化再比对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征方程比对标准二阶形式求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由百分之五误差带求欠阻尼二阶系统的调节时间
本卷实例
  • 关键一步：先由阻尼比与自然频率读出衰减因子
  • 中间结果：调节时间与阻尼比和自然频率的乘积成反比
  • 卡点：百分之五与百分之二误差带所用系数不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由百分之五误差带求欠阻尼二阶系统的调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

3三、最小相位系统幅频曲线反求传函与相角裕度#

思路
  • 由图3幅频渐近特性读低频段斜率与高度确定系统型别和开环增益，按各转折频率逐段写出最小相位传递函数；再在剪切频率处求相角裕度。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由幅频渐近特性曲线反求最小相位传递函数
本卷实例
  • 关键一步：低频段斜率定积分环节个数，高度定开环增益
  • 中间结果：转折频率处斜率升或降二十分贝每十倍频
  • 卡点：转折频率与低频高度需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由幅频渐近特性曲线反求最小相位传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 由传递函数在剪切频率处求相角裕度
本卷实例
  • 关键一步：先由幅频曲线零分贝点确定剪切频率
  • 中间结果：相角裕度等于一百八十度加该频率处的相角
  • 卡点：剪切频率与相位穿越频率不是同一频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由传递函数在剪切频率处求相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

思路

闭环频率特性与性能指标 频域分析
本卷考法

  • 谐振频率 ωr 与峰值时间相关

步骤

  • 读出谐振峰值、谐振频率与带宽
  • 按经验公式估计超调量与调节时间
通用考法
  • 本卷考过由给定频率处闭环幅值与相角反求二阶系统参数
  • 由闭环幅频特性求谐振峰值与带宽
  • 由 Mr 估算超调量
  • 分析带宽与响应速度的关系
常见易错
  • 当 ξ>0.707 时仍套用谐振峰值公式
  • 把开环谐振与闭环谐振混为一谈

5五、结构图状态空间建模、极点配置与观测器#

思路
  • 图5结构图先列写状态方程与输出方程，判能控能观后由期望极点写特征多项式，与实际闭环特征多项式比对求状态反馈阵；再由观测器误差动态矩阵配置期望极点求观测器增益。
状态空间表达式的建立 状态空间分析
本卷考法
  • 由结构图列写状态空间方程
