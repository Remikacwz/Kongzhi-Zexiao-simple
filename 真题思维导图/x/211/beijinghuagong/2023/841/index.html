1一、由状态方程画方块图并求传递函数#

思路
  • 由给定的三个状态方程变量关系，把每个方程改写成一阶微分方程或代数关系式，逐式画出积分器、求和点与增益支路构成方块图；再由方块图用梅森公式求 C(s)/R(s)。
状态空间表达式的建立 状态空间分析
本卷考法
  • 由状态方程与输出关系反画系统方块图
本卷实例
  • 关键一步：把每个方程改写成一阶微分或代数关系式
  • 中间结果：每个一阶导数式对应一个积分器
  • 卡点：各方程中变量符号须回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由状态方程与输出关系反画系统方块图
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D

串联、并联与反馈等效 结构图与方框图
本卷考法
  • 按状态方程的因果关系把各环节连成方块图
本卷实例
  • 关键一步：按输入到状态的因果顺序连接各环节
  • 中间结果：求和点汇入各状态量的代数和
  • 卡点：反馈支路的正负号易与原方程写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过按状态方程的因果关系把各环节连成方块图
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求闭环传递函数
本卷实例
  • 关键一步：由方块图数清回路并找前向通路
  • 中间结果：回路特征式由状态反馈构成、无两两不接触回路
  • 卡点：回路增益的符号易写反导致特征式错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、二阶系统参数辨识、稳态输出与等幅振荡#

思路
  • 由图2输出曲线读超调量与峰值时间反求阻尼比与自然频率，据此求未知参数并写单位阶跃响应表达式；再由闭环频率特性求正弦输入的稳态输出；设计比例控制器使输入与扰动共同作用下的稳态误差绝对值达标；最后令闭环特征方程根落到虚轴上求等幅振荡时的参数。
由响应曲线反求传递函数 传递函数
本卷考法
  • 由阶跃响应曲线求阻尼比、自然频率与未知参数
本卷实例
  • 关键一步：从曲线读超调量与峰值时间
  • 中间结果：由超调量反解阻尼比、由峰值时间反解自然频率
  • 卡点：曲线读数须回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由阶跃响应曲线求阻尼比、自然频率与未知参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 把闭环传函化为标准二阶形式求参数
本卷实例
  • 关键一步：把闭环传递函数化为标准二阶形式
  • 中间结果：比对系数得时间常数与增益
  • 卡点：二次项系数须先归一化再比对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过把闭环传函化为标准二阶形式求参数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错

  • 把开环增益误当成闭环传递函数的系数

频率特性的物理意义与求法 频域分析
本卷考法
  • 求正弦输入下系统的稳态输出
本卷实例
  • 关键一步：令 s 等于虚轴频率求闭环频率特性
  • 中间结果：稳态输出幅值为输入幅值乘幅频
  • 卡点：输出相角等于相频且须换算为角度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求正弦输入下系统的稳态输出
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°

扰动作用下的稳态误差 稳态误差
本卷考法
  • 设计比例控制器使输入与扰动共同作用下误差达标
本卷实例
  • 关键一步：分别求输入与扰动引起的稳态误差再叠加
  • 中间结果：由误差绝对值上限反解控制器增益下限
  • 卡点：两路误差符号相反，须先判方向
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过设计比例控制器使输入与扰动共同作用下误差达标
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

3三、根轨迹绘制、无超调范围与复根圆弧#

思路
  • 把开环传函化为标准零极点形式画根轨迹；由闭环极点全为实数确定单位阶跃响应无超调的增益范围；将闭环特征方程根设为复根并消去增益，证明复根轨迹为圆并求圆心半径；再由阻尼比最小即阻尼角最大确定与圆相切的闭环极点。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画开环系统的根轨迹
本卷实例
  • 关键一步：标出开环极点与零点并判断实轴根轨迹段
  • 中间结果：渐近线交点与夹角由零极点数目确定
  • 卡点：开环零极点须按源文表达式核算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画开环系统的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
