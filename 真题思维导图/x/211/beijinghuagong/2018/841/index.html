一一、无源网络求传函与典型环节#

思路
  • 图1为无源阻容网络，用复阻抗按分压关系列写传函，再判断环节类型并说明其作用
由电路或机械系统求传递函数 传递函数
本卷考法
  • 用复阻抗法求无源网络的传递函数
本卷实例
  • 关键一步：把电容写成1/(sC)复阻抗后按分压列式
  • 中间结果：传函为输出支路阻抗比串联总阻抗
  • 卡点：网络元件连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过用复阻抗法求无源网络的传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

典型环节及其特性 传递函数
本卷考法
  • 由传函判断典型环节并说明其作用
本卷实例
  • 关键一步：把传函化为标准形式再与典型环节对照
  • 中间结果：输出与输入呈积分关系，属积分环节
  • 卡点：积分作用应落到提高型别与稳态精度
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 六种典型环节：比例、积分、微分、惯性、振荡、延迟
  • 惯性环节由时间常数 T 描述，T 越小响应越快
  • 振荡环节由自然频率 ωn 与阻尼比 ξ 共同描述
  • 延迟环节只改变相位，不改变幅值
步骤
  • 把传递函数分解为若干典型环节的乘积
  • 逐环节写出幅频与相频表达式
  • 按环节类型判断对系统性能的影响
通用考法
  • 本卷考过由传函判断典型环节并说明其作用
  • 指出给定传递函数由哪些典型环节串联组成
  • 由阶跃响应曲线或 Bode 图识别环节类型
  • 比较两个系统的时间常数大小
常见易错
  • 把一阶微分环节 (τs+1) 与纯微分环节 s 混为一谈
  • 把延迟环节的相位滞后误当作幅值衰减

二二、由方框图求闭环传递函数#

思路
  • 图2为多回路负反馈方框图，用梅森增益公式整理回路与前向通路后合并
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求多回路方框图的传函
本卷实例
  • 关键一步：先数清全部独立回路并区分不接触回路
  • 中间结果：特征式为1减回路增益和加不接触回路乘积
  • 卡点：不接触回路易漏计或重复，须逐对核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求多回路方框图的传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

三三、根轨迹绘制与由阻尼比定参数#

思路
  • 由图3结构图写开环传函并画根轨迹，再由阻尼比0.5的阻尼角射线定闭环极点与增益
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画根轨迹：分支数、实轴段与渐近线
本卷实例
  • 关键一步：写开环零极点并按法则逐条绘制
  • 中间结果：无开环零点，三条分支均趋于无穷远
  • 卡点：结构图等效开环需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画根轨迹：分支数、实轴段与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界增益
本卷实例
  • 关键一步：把s=jω代入闭环特征方程分实虚部
  • 中间结果：由虚部方程定振荡频率再回代定增益
  • 卡点：只代一个ω会漏掉另一组交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由给定阻尼比确定闭环极点与对应增益
本卷实例
  • 关键一步：用阻尼角射线与根轨迹相交定闭环极点
  • 中间结果：阻尼比为0.5时阻尼角为60度
  • 卡点：交点须落在根轨迹上，增益用幅值条件回代
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由给定阻尼比确定闭环极点与对应增益
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

四四、由Bode图反求传函与相角裕度#

思路
  • 由图4对数渐近幅频特性反求开环传函并求相角裕度，再分析幅频曲线右移后的新传函
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数渐近幅频特性反求开环传递函数
本卷实例
  • 关键一步：由低频段斜率和转折频率定环节与时间常数
  • 中间结果：低频段高度折算型别后定开环增益
  • 卡点：延长线交点不能直接当增益，须按型别折算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数渐近幅频特性反求开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 由截止频率处相角求相角裕度
本卷实例
  • 关键一步：由幅频渐近线过零分贝定截止频率
  • 中间结果：相角裕度等于180度加该处开环相角
  • 卡点：截止频率与相位穿越频率不能混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由截止频率处相角求相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

五五、状态转移矩阵、离散化与状态响应#

思路
  • 由A阵求状态转移矩阵，再离散化求G与H，最后求单位阶跃输入下的状态解
状态转移矩阵 状态空间分析
本卷考法
  • 由系统矩阵求状态转移矩阵并求输入下的状态响应
本卷实例
  • 关键一步：先求(sI-A)的逆再作拉氏反变换
  • 中间结果：矩阵含重特征值1，转移矩阵出现t乘指数项
  • 卡点：重特征值须带t项，不能只写指数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态转移矩阵 e^{At} 描述零输入下状态随时间的演化
  • 可从 (sI-A)^{-1} 求拉氏反变换得到
  • 满足 e^{A\cdot0}=I 且可逆
  • 含输入时用卷积积分写出全响应
步骤
  • 计算 (sI-A)^{-1}
  • 求拉氏反变换得到 e^{At}
  • 代入全响应公式求状态与输出
  • 用初值条件校验结果
通用考法
  • 本卷考过由系统矩阵求状态转移矩阵并求输入下的状态响应
  • 求状态转移矩阵
  • 求给定初始条件下的状态与输出响应
  • 用性质验证转移矩阵是否正确
常见易错
  • 矩阵求逆时忘记检查行列式是否为零
  • 卷积积分中变量代换写错
公式
连续系统的离散化 离散控制系统
本卷考法
  • 按采样周期把连续状态方程离散化为G和H
本卷实例
  • 关键一步：用状态转移矩阵和输入积分式求离散矩阵
  • 中间结果：G为T时刻转移矩阵，H为转移矩阵乘B的积分
  • 卡点：积分上限是采样周期且须右乘输入矩阵
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离散化状态方程由状态转移矩阵在采样周期处的取值构成
  • 输入矩阵是状态转移矩阵与输入矩阵乘积在采样周期上的积分
  • 带零阶保持器时即按上述积分式离散化，输出矩阵不变
步骤
  • 求连续系统的状态转移矩阵
  • 把采样周期代入得到离散状态矩阵
  • 对输入矩阵做积分得到离散输入矩阵
  • 写出差分形式的离散状态方程并按递推求采样点上的响应
通用考法
  • 本卷考过按采样周期把连续状态方程离散化为G和H
  • 求连续系统在给定采样周期下的离散化状态方程
  • 由给出的状态响应反求系统矩阵再离散化
  • 计算采样点上的状态与输出序列
常见易错
  • 把采样周期直接当成时间常数代进连续传函
  • 积分上限写成采样周期以外的量，或忘记乘输入矩阵

六六、由调节时间要求反求反馈与前置参数#

思路
  • 图5为一阶对象加反馈K2与前置增益Kp，按调节时间降为0.1倍且总增益不变反求两参数
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由方框图写闭环传函并分析反馈对时间常数的影响
本卷实例

  • 卡点：反馈极性与开环增益的对应关系易写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 判断反馈极性对分母符号的影响

  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
