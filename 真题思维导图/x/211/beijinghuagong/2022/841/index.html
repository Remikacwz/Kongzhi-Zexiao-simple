1一、多输入结构图传函与由响应反求传函#

思路
  • 图1为含参考输入与扰动输入的复合结构，先令扰动为零用梅森公式求 C(s)/R(s)；再令扰动到输出的传递函数为零反求前馈通道 G0(s)；最后由给定零初始响应 Q(t) 取拉氏变换反求 G0(s)。
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式求参考输入到输出的闭环传函
本卷实例
  • 关键一步：先数清全部独立回路并找出不接触回路
  • 中间结果：特征式含一对两两不接触回路的乘积项
  • 卡点：回路与通路数目须回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式求参考输入到输出的闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

2二、扰动稳态误差、等幅振荡与奈奎斯特判稳#

思路
  • 由图2结构写扰动误差传递函数，用终值定理反求使扰动稳态误差为设定值的前馈增益并回代劳斯判据校验；令参考输入下闭环等幅振荡求临界增益与振荡频率；最后画开环幅频特性曲线并用奈奎斯特判据按增益分段讨论稳定性与不稳定根数。
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动作用下稳态误差并反求前馈增益
本卷实例
  • 关键一步：令参考输入为零写扰动到误差的传递函数
  • 中间结果：用终值定理求该误差的稳态值
  • 卡点：求得增益须回代判稳校验是否可行
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求扰动作用下稳态误差并反求前馈增益
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据校验反求增益下系统的稳定性
本卷实例
  • 关键一步：由闭环特征方程按降幂排列列劳斯表
  • 中间结果：首列元素均大于零才使系统稳定
  • 卡点：系数缺项须补零后再列表
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据校验反求增益下系统的稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

本卷考法

本卷实例

  • 中间结果：低频段斜率由型别决定、高度由增益决定
  • 卡点：各转折频率处斜率变化量勿漏累加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积

通用考法

  • 由低频段斜率与高度判断型别与增益
常见易错

  • 低频段起始高度没有乘上型别的 -20v dB/dec

奈奎斯特判据 稳定性分析
本卷考法
  • 按包围圈数判断闭环稳定与不稳定根数
本卷实例
  • 关键一步：先数开环在右半平面的极点数
  • 中间结果：净包围圈数加右半平面极点数得闭环右半平面根数
  • 卡点：开环无积分环节时不必补大圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过按包围圈数判断闭环稳定与不稳定根数
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

3三、根轨迹绘制与由超调量定参求调节时间#

思路
  • 由图3结构得开环传递函数，按法则画以增益k为变量的根轨迹，求渐近线、实轴段、分离点与虚轴交点；再由超调量要求定出阻尼比，令闭环极点落在等阻尼线上与根轨迹相交求k，按二阶近似求调节时间。
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画以增益k为变量的根轨迹
本卷实例
  • 关键一步：先标开环零极点并判断实轴上的根轨迹段
  • 中间结果：渐近线条数与夹角由零极点数目差确定
  • 卡点：开环极点与零点须回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画以增益k为变量的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k

本卷考法

  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
