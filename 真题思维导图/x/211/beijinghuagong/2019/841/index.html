一一、由信号流图求闭环传递函数#

思路
  • 图1为多回路信号流图，用梅森增益公式写各回路、前向通路与余子式后求总传函
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求信号流图的闭环传函
本卷实例
  • 关键一步：先找出全部回路并判断两两是否接触
  • 中间结果：全部回路均接触时特征式只含各回路增益项
  • 卡点：回路漏计会让特征式少项，结论跟着错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求信号流图的闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

二二、二阶系统稳定性与稳态误差系数#

思路
  • 图2为含内反馈Kf的系统，写开环与闭环传函分析其稳定性影响，求静态误差系数，再在Kf=0.5时求阶跃与加速度输入的稳态误差
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据分析内反馈系数对系统稳定性的影响
本卷实例
  • 关键一步：由闭环特征方程检查一次项与常数项符号
  • 中间结果：二阶系统稳定的充要条件是两个系数均为正
  • 卡点：内反馈同时影响一次项与常数项，须联立看
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据分析内反馈系数对系统稳定性的影响
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
系统型别与静态误差系数 稳态误差
本卷考法

本卷实例

  • 中间结果：零型系统的速度与加速度误差系数均为零
  • 卡点：误差系数由开环传函定，不能用闭环传函算
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过求系统的静态位置、速度与加速度误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求阶跃与加速度输入下的稳态误差
本卷实例
  • 关键一步：按型别判断输入能否被跟踪再取误差极限
  • 中间结果：零型系统跟踪加速度信号时误差趋于无穷
  • 卡点：未判稳就取极限会得到无意义结果
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求阶跃与加速度输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

三三、由状态图求传函并列写状态空间#

思路
  • 由图3状态图用拉氏变换列写中间变量关系求系统传函，再选状态变量写状态空间表达式
状态空间表达式的建立 状态空间分析
本卷考法
  • 由状态图选状态变量列写状态空间表达式
本卷实例
  • 关键一步：在各积分器输出端设状态并写其一阶导数
  • 中间结果：输出方程由状态量与输入量的组合给出
  • 卡点：支路系数与耦合符号需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 状态方程为一阶微分方程组，输出方程是状态与输入的代数关系
  • 状态变量的个数等于系统阶数，选取不唯一
  • 状态空间描述可同时刻画内部状态与外部输出
  • 可处理多输入多输出系统
步骤
  • 确定系统阶数并选取状态变量
  • 列写各状态变量的一阶微分方程
  • 写成矩阵形式 x'=Ax+Bu 与 y=Cx+Du
通用考法
  • 本卷考过由状态图选状态变量列写状态空间表达式
  • 由物理系统列写状态空间表达式
  • 判断状态变量选取是否合理
  • 写出系统的 A、B、C、D 矩阵
常见易错
  • 状态变量个数与系统阶数不匹配
  • 输出方程中漏掉直接传递项 D
公式
状态空间与传递函数的关系 状态空间分析
本卷考法
  • 由状态图写系统传递函数
本卷实例
  • 关键一步：用梅森公式或消元法由结构图求传函
  • 中间结果：传函分母对应状态矩阵的特征多项式
  • 卡点：须先消去中间变量再写输入输出关系
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由状态空间求传递函数为 C(sI-A)^{-1}B+D
  • 传递函数只反映能控能观子系统，含零极点对消
  • 系统的特征值等于传递函数的极点
  • 同一传递函数对应的状态空间实现不唯一
步骤
  • 计算 (sI-A)^{-1}
  • 按公式求 G(s)=C(sI-A)^{-1}B+D
  • 与已知传递函数比对，判断是否发生零极点对消
通用考法
  • 本卷考过由状态图写系统传递函数
  • 由状态空间表达式求传递函数
  • 判断状态空间实现是否存在零极点对消
  • 比较不同实现对应的传递函数是否相同
常见易错
  • 漏掉直接传递项 D
  • 把特征值个数与传递函数极点数直接等同而不检查对消

四四、根轨迹绘制与最小阻尼比参数#

思路
  • 对给定开环传函画根轨迹，再由阻尼比最小的条件（阻尼角最大）求切点处的闭环极点与增益
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则画出给定开环传函的根轨迹
本卷实例
  • 关键一步：写开环零极点并判实轴段与渐近线
  • 中间结果：分离点由dK/ds为零结合实轴段筛选
  • 卡点：分离点方程的解须代回实轴段检验
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则画出给定开环传函的根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法

本卷实例

  • 中间结果：分离点满足dK/ds等于零
  • 卡点：不在根轨迹上的根必须舍去

  • 分离点必满足 dK/ds=0

  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点坐标
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由最小阻尼比求闭环极点与增益
本卷实例
  • 关键一步：阻尼角最大对应阻尼比线与轨迹相切
  • 中间结果：由切点几何关系求出闭环极点坐标
  • 卡点：切点须落在根轨迹上，增益回代特征方程求
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

五五、稳定裕度与串联超前校正#

思路
  • 对给定开环传函求相角裕度与幅值裕度，再串联超前校正环节后重求，并比较校正前后的裕度变化
稳定裕度 频域分析
本卷考法
  • 求开环系统的相角裕度与幅值裕度
本卷实例
  • 关键一步：由幅频条件定截止频率、由相频条件定穿越频率
  • 中间结果：相角裕度取180度加截止频率处相角
  • 卡点：两个频率用反会让裕度结论整体出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求开环系统的相角裕度与幅值裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式
超前校正 系统校正
本卷考法
  • 分析串联超前校正对相角裕度与稳定性的改善
本卷实例
  • 关键一步：校正环节在截止频率附近提供超前相角
  • 中间结果：校正后截止频率提高、相角裕度由负转正
  • 卡点：超前环节会抬高幅频，须重新求截止频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过分析串联超前校正对相角裕度与稳定性的改善
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
  • 分析超前校正的局限性
常见易错
  • 计算补偿角时忽略截止频率变化带来的附加相角损失
  • α 的取值与超前角公式方向取反

六六、能控能观、状态反馈与全维观测器#

思路
  • 先判能控能观，再求使系统不完全能观的状态反馈阵，随后作极点配置、设计全维观测器并求闭环稳态误差
能控性与能观性 状态空间分析
本卷考法
  • 判断能控能观性并分析状态反馈对能观性的影响
本卷实例
  • 关键一步：构造能控与能观判别阵并计算秩
  • 中间结果：状态反馈不改变能控性但会改变能观性
  • 卡点：使能观判别阵降秩的反馈阵由行列式为零解出
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 能控性指能否用输入在有限时间内把任意初始状态驱动到原点
  • 能观性指能否由输出在有限时间内确定初始状态
  • 用能控性矩阵与能观性矩阵的秩判断
  • 能控性与能观性经非奇异线性变换保持不变
步骤
  • 构造能控性矩阵并求秩
  • 构造能观性矩阵并求秩
  • 与系统阶数 n 比较得出结论
  • 不可控或不可观时进一步做结构分解
通用考法
  • 本卷考过判断能控能观性并分析状态反馈对能观性的影响
  • 判断系统的能控性与能观性
  • 求使系统能观的参数取值
  • 对不可控系统进行结构分解
