1一、直流调速系统结构图与传递函数10 分#

思路
  • 按各单元传递关系从给定到转速画结构图，再用梅森公式求闭环传函。
直流电机等机电系统 建模与机电系统
本卷考法
  • 由直流电机各单元关系建立调速系统模型
本卷实例
  • 关键一步：先写出各单元输入输出关系再按信号流向连接
  • 中间结果：电机环节同时含电枢电压与负载扰动
  • 卡点：反电动势与负载的耦合项容易漏掉
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 由电枢回路电压方程与转矩平衡方程联立
  • 反电动势与转速成正比，电磁转矩与电枢电流成正比
  • 机电时间常数由电气与机械两方面参数共同决定
步骤
  • 写出电枢回路电压平衡方程
  • 写出转矩平衡方程（含负载与粘性摩擦）
  • 消去电枢电流，得到转速或转角对电压的传递函数
通用考法
  • 本卷考过由直流电机各单元关系建立调速系统模型
  • 求直流电机转速或位置对电枢电压的传递函数
  • 分析机电时间常数与电气时间常数的数量级关系
常见易错
  • 漏掉反电动势与电磁转矩的耦合项
  • 把电气时间常数与机电时间常数混淆
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简求闭环传函
本卷实例
  • 关键一步：先化简由测速反馈形成的内回路
  • 中间结果：内回路化简后化为单回路系统
  • 卡点：化简内环时把外环信号当成常数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简求闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 串联并联与反馈等效求总传函
本卷实例
  • 关键一步：按梅森公式数前向通路与回路
  • 中间结果：闭环分母为一加回路增益
  • 卡点：负反馈分母里一与回路增益的符号写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过串联并联与反馈等效求总传函
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

2二、结构图求两输出表达式15 分#

思路
  • 对两个输入分别用梅森公式求两输出通道传函，再叠加写出表达式。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求两输入到两输出的四个通道传函
本卷实例
  • 关键一步：求某一路时把另一路输入置零
  • 中间结果：四个通道共用同一回路特征式
  • 卡点：结构图交叉点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求两输入到两输出的四个通道传函
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式列四通道的回路与余子式
本卷实例
  • 关键一步：逐条列出各前向通路及其余子式
  • 中间结果：特征式含四条回路与两两不接触项
  • 卡点：余子式漏项导致某通道增益不全
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式列四通道的回路与余子式
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式

3三、二阶模拟电路响应与衰减振荡范围15 分#

思路
  • 由模拟电路写闭环传函，给定电阻下判阻尼画响应，再按衰减振荡求电阻范围。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由二阶模拟电路求闭环传函
本卷实例
  • 关键一步：按虚短虚断列各级运放方程
  • 中间结果：闭环传函化为标准二阶形式
  • 卡点：各级运放元件连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由二阶模拟电路求闭环传函
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 含运放与 RC 网络的有源电路建模
本卷实例
  • 关键一步：消去中间节点电压得输入输出关系
  • 中间结果：分母二次项系数含反馈电阻
  • 卡点：电容复阻抗误写成 Cs 会全盘皆错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过含运放与 RC 网络的有源电路建模
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由电路参数计算阻尼比并判断响应形态
本卷实例
  • 关键一步：令标准二阶系数与电路常数一一对应
  • 中间结果：阻尼比随可调电阻变化
  • 卡点：把阻尼比与自然频率互换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由电路参数计算阻尼比并判断响应形态
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式

4四、由超调与截止频率反求增益时间常数10 分#

思路
  • 由超调定阻尼比，再由截止频率条件列增益与时间常数方程联立求解。
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量要求确定阻尼比
本卷实例
  • 关键一步：对超调公式取对数解出阻尼比
  • 中间结果：阻尼比落在欠阻尼区间
  • 卡点：超调公式指数项的符号写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量要求确定阻尼比
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环标准形式联系开环参数
本卷实例
  • 关键一步：写出闭环特征方程并比对标准形式
  • 中间结果：自然频率由开环增益与时间常数定
  • 卡点：二次项系数未归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环标准形式联系开环参数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
稳定裕度 频域分析
本卷考法
  • 由开环幅值穿越频率条件列方程
本卷实例
  • 关键一步：对开环幅频写穿越条件的近似式
  • 中间结果：该条件给出增益与时间常数的一个约束
  • 卡点：近似前提是否成立未检验
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由开环幅值穿越频率条件列方程
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式

5五、PD 控制器带宽与相角裕度设计10 分#

思路
  • 写 PD 校正后开环传函，用闭环带宽近似截止频率定增益，再由相角裕度定微分时间。
PID 控制器与参数整定 系统校正
本卷考法
  • 设计 PD 控制器满足带宽与裕度指标
本卷实例
  • 关键一步：写出校正后开环并画其渐近幅频
  • 中间结果：增益使穿越频率落在带宽中点附近
  • 卡点：微分时间取得过大放大高频噪声
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例项提高快速性但存在稳态误差
  • 积分项消除稳态误差但降低稳定性、增大超调
  • 微分项提供超前相位改善动态性能但对噪声敏感
  • PD 相当于超前校正，PI 相当于滞后校正
步骤
  • 按误差类型选择需要引入的环节
  • 先调比例再调积分最后调微分
  • 用稳定裕度或性能指标校验并微调
通用考法
  • 本卷考过设计 PD 控制器满足带宽与裕度指标
  • 设计 PID 控制器满足给定指标
  • 分析各参数变化对系统性能的影响
  • 说明微分项对噪声的影响
常见易错
  • 把 PI 的相位影响说成超前
  • 积分增益过大导致系统振荡甚至不稳定
公式
稳定裕度 频域分析
本卷考法
  • 由相角裕度要求反求微分时间常数
本卷实例
  • 关键一步：在穿越频率处令相角裕度等于给定值
  • 中间结果：相角裕度条件给出一个微分时间
  • 卡点：把开环相角裕度算成闭环相角
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）

  • 关键一步：把给定频率对到校正后开环幅值上
  • 中间结果：高频段开环幅值近似等于闭环幅值
  • 卡点：把开环幅值分贝数直接当衰减倍数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 谐振峰值 Mr 越大振荡越强，通常要求 Mr 在 1.1 到 1.5 之间
  • 谐振频率 ωr 与峰值时间相关
  • 带宽频率 ωb 越大响应越快但抗噪能力下降
  • 由等 M 圆与等 N 圆可由开环频率特性求闭环特性

  • 由开环频率特性求闭环频率特性

  • 按经验公式估计超调量与调节时间
通用考法

  • 由闭环幅频特性求谐振峰值与带宽

  • 分析带宽与响应速度的关系

11十一、二阶系统等倾线与相轨迹斜率10 分#

思路
  • 把二阶方程化为相平面方程，令等倾线斜率与相轨迹斜率相等解出直线斜率。
相平面法 非线性系统
本卷考法
  • 求等倾线斜率等于相轨迹斜率时的直线斜率
本卷实例
  • 关键一步：先用相轨迹斜率表示等倾线方程
  • 中间结果：令两斜率相等得一关于斜率的二次方程
  • 卡点：等倾线斜率与相轨迹斜率混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过求等倾线斜率等于相轨迹斜率时的直线斜率
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

思路
  • 按采样开关位置写误差与输出通道的 z 域关系，消去中间变量求闭环脉冲传函。
脉冲传递函数 离散控制系统
本卷考法
  • 按采样开关位置推闭环脉冲传递函数
本卷实例
  • 关键一步：先写误差与输出的 z 域关系式
  • 中间结果：闭环传函分母为一加开环脉冲传函
  • 卡点：无采样开关分隔的环节不能直接连乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过按采样开关位置推闭环脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)
