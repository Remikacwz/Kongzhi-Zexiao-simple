1一、无源电网络求传递函数10 分#

思路
  • 用复阻抗法对无源 RC 网络列分压关系，消去中间电量求 Uo(s)/Ui(s)。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由无源 RC 网络求电压传递函数
本卷实例
  • 关键一步：把电容写成 1/(sC) 后按分压列式
  • 中间结果：两节 RC 支路合并成一个等效阻抗
  • 卡点：元件连接与标注需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由无源 RC 网络求电压传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过电容复阻抗误写成 Cs 会使量纲出错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 对无源双端口网络逐级列关系
本卷实例
  • 关键一步：先定输出级再向前推输入关系
  • 中间结果：回路电流法与节点法二者选一
  • 卡点：电阻编号在本卷有重复需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过对无源双端口网络逐级列关系
  • RC 网络或有源滤波器求传递函数

  • 本卷考过忽略后级负载效应而直接串乘各级

2二、结构图求闭环传递函数10 分#

思路
  • 用梅森公式求前向通路增益与各回路增益，再写 C(s)/R(s)。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图写闭环传递函数
本卷实例
  • 关键一步：先数回路再定两两不接触项
  • 中间结果：特征式含回路增益与不接触乘积
  • 卡点：结构图交叉点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图写闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 本卷考过把前向通路增益错当回路增益
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简
本卷实例
  • 关键一步：由内到外逐层消去中间变量
  • 中间结果：每层化简后分母出现新的反馈项
  • 卡点：比较点与引出点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 本卷考过化内环时把外环信号当成常数
  • 化简内环时把外环的信号当成常数处理

3三、由单位阶跃响应反求二阶参数15 分#

思路
  • 把响应各项对应到闭环极点，识别振荡分量，反求阻尼比与自然频率。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由响应分量定二阶系统阻尼比
本卷实例
  • 关键一步：把响应由拉氏反变换还原成闭环根
  • 中间结果：一对共轭复根给出 ωn 与 ζ
  • 卡点：响应常数项含稳态分量须先分离
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由响应分量定二阶系统阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过化为标准形式时未归一化二次项
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 按包络衰减求系统调节时间
本卷实例
  • 关键一步：先由超调量定阻尼比
  • 中间结果：再由包络进入误差带算调节时间
  • 卡点：过阻尼时无峰值时间公式可直接套
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过按包络衰减求系统调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 本卷考过超调量与调节时间的系数搞混
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由阶跃响应表达式辨识系统
本卷实例
  • 关键一步：由终值先定稳态分量
  • 中间结果：余下振荡项对应于一对极点
  • 卡点：响应指数的各系数需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由阶跃响应表达式辨识系统
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 本卷考过把稳态值直接当成系统增益
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值

4四、结构图斜坡稳态误差约束10 分#

思路
  • 由结构图写开环传函，按型别求速度误差系数，代入斜坡误差约束反求 K1 范围。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由斜坡误差上界反求开环增益范围
本卷实例

  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤

通用考法

  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 本卷考过未判闭环稳定就套终值定理
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量

6六、结构图参数确定与扰动不变性15 分#
