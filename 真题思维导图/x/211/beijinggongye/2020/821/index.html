1一、运放电路求传递函数10 分#

思路
  • 按虚短虚断对多级运放逐级列输入输出关系，消去中间电压求传递函数。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由含运放的 RC 网络求传递函数
本卷实例
  • 关键一步：逐级列虚短虚断关系式
  • 中间结果：各级输入输出关系相消
  • 卡点：运放级联与元件取值需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由含运放的 RC 网络求传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 本卷考过运放电路未使用虚短虚断条件
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 多级有源网络逐级建模
本卷实例
  • 关键一步：先写末级输出与输入关系
  • 中间结果：中间级呈比例或积分形式
  • 卡点：电阻电容编号需回原卷核对图

  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体

  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法

2二、由微分方程求闭环与误差传函15 分#

思路
  • 先由零初始微分方程取拉氏变换得各环节传函，再按结构图组合求闭环与误差传函。
传递函数的定义与基本性质 传递函数
本卷考法
  • 由微分方程写各环节传递函数
本卷实例
  • 关键一步：对零初始微分方程取拉氏变换
  • 中间结果：得前向环节与反馈环节传函
  • 卡点：微分方程系数需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由微分方程写各环节传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过初始条件非零时直接套零初始公式
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 由结构图组合求闭环传递函数
本卷实例
  • 关键一步：把各环节传函按结构组合
  • 中间结果：闭环分母为 1 加开环乘积
  • 卡点：比较点极性需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过由结构图组合求闭环传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 本卷考过负反馈分母错写成 1-GH
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 求误差对参考输入的传递函数
本卷实例
  • 关键一步：按结构图写 E 与 R 的关系
  • 中间结果：误差传函分母同闭环特征式
  • 卡点：误差引出点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过求误差对参考输入的传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 本卷考过误差定义选取不当差一个 H(s)
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定

3三、参数稳定范围与阶跃响应15 分#

思路
  • 写含反馈系数的闭环特征方程，用劳斯判据求稳定范围，再代入给定根求响应。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求反馈系数范围
本卷实例
  • 关键一步：写含参数的闭环特征方程
  • 中间结果：由首列同号得参数下界
  • 卡点：参数符号假设需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求反馈系数范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 本卷考过劳斯表首列含参未按不等式讨论
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由给定闭环根反求待定参数
本卷实例
  • 关键一步：把给定根代入特征方程
  • 中间结果：余下二次因式可解另两根
  • 卡点：给定根的位置需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由给定闭环根反求待定参数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过代入根后未与其余根联立
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由闭环传函求单位阶跃响应表达式
本卷实例
  • 关键一步：把 C(s) 写成部分分式
  • 中间结果：各项反变换得时间响应
  • 卡点：极点与留数需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由闭环传函求单位阶跃响应表达式
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 本卷考过部分分式分解时漏项
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上

思路

扰动作用下的稳态误差 稳态误差
