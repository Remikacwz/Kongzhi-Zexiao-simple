1一、运放电路求传递函数10 分#

思路
  • 多级运放电路按虚短虚断逐级列方程，消去中间电压求 Uo(s)/Ui(s)。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由含运放的 RC 网络求 Uo(s)/Ui(s)
本卷实例
  • 关键一步：按虚短虚断对每个运放列输入输出关系
  • 中间结果：逐级得到中间电压的反相比例式
  • 卡点：运放级联的元件连接需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由含运放的 RC 网络求 Uo(s)/Ui(s)
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 多级有源网络逐级建模
本卷实例
  • 关键一步：先写最末级输出与末级输入的关系
  • 中间结果：中间级呈积分或比例的形式
  • 卡点：电容复阻抗误写成 Cs 会全盘皆错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过多级有源网络逐级建模
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

2二、多输入系统的输出表达式10 分#

思路
  • 对 R(s) 与 N(s) 分别用梅森公式求通道传函，再叠加写出 C(s)。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求参考输入与扰动到输出的传递函数
本卷实例
  • 关键一步：求一路传函时把另一路输入置零
  • 中间结果：两路共用同一回路特征式
  • 卡点：结构图回路与注入点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求参考输入与扰动到输出的传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式写回路增益与特征式
本卷实例
  • 关键一步：数出两条回路并判断是否接触
  • 中间结果：特征式含两回路互不接触乘积项
  • 卡点：把前向通路增益当成回路增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式写回路增益与特征式
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式

3三、结构图稳态误差与前馈校正15 分#

思路
  • 先判型别求斜坡误差，再令误差传函在斜坡下终值为零反求前馈装置。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由开环传函求单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：先判稳再对误差传函用终值定理
  • 中间结果：速度误差系数由低频段极限定出
  • 卡点：未判稳就套终值定理会得错值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由开环传函求单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 设计前置校正装置使给定信号稳态误差为零
本卷实例
  • 关键一步：写出误差传函并令斜坡分量系数为零
  • 中间结果：前馈装置须含正幂次 s 项
  • 卡点：前馈注入点位置在结构图中需核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计前置校正装置使给定信号稳态误差为零
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式

4四、由阶跃响应曲线反求参数10 分#

思路
  • 由闭环传函定稳态值与超调，再由曲线读峰值时间和峰值反求 K、a、b。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环特征方程写标准二阶形式
本卷实例
  • 关键一步：对特征方程二次项系数归一化
  • 中间结果：阻尼比与自然频率由特征系数确定
  • 卡点：稳态值需用终值定理而非直接读曲线
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征方程写标准二阶形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间反求阻尼比和自然频率
本卷实例
  • 关键一步：两式联立先解阻尼比再解自然频率
  • 中间结果：峰值时间与超调各给出一个约束
  • 卡点：超调量公式中漏乘百分号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与峰值时间反求阻尼比和自然频率
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由响应曲线反求传递函数 传递函数
本卷考法
  • 由实验阶跃响应曲线辨识系统参数
本卷实例
  • 关键一步：先由稳态输出确定增益比
  • 中间结果：响应曲线给出超调与峰值时刻
  • 卡点：响应曲线为原卷插图，数值需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由实验阶跃响应曲线辨识系统参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式

5五、参数根轨迹与衰减振荡范围10 分#

思路
  • 把 a 提到分子化为参数根轨迹，画渐近线、分离点与虚轴交点，取衰减振荡区间。
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以系数 a 为参变量绘制广义根轨迹
本卷实例
  • 关键一步：整理成 1 加 a 乘等效开环为零的形式
  • 中间结果：等效开环含一个三重极点
  • 卡点：参数未完整提到分子会导致根轨迹错位
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以系数 a 为参变量绘制广义根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
分离点与会合点 根轨迹法
本卷考法
  • 求参数根轨迹的分离点与会合点
本卷实例
  • 关键一步：由增益对 s 求导为零解分离点坐标
  • 中间结果：分离点对应一个临界 a 值
  • 卡点：解出的根未筛选掉非根轨迹点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求参数根轨迹的分离点与会合点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由闭环极点位置确定衰减振荡的参数范围
本卷实例
  • 关键一步：取分离点与虚轴交点之间的 a 区间
  • 中间结果：区间为开区间且由两个临界值夹定
  • 卡点：把等阻尼线误当成垂直线
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由闭环极点位置确定衰减振荡的参数范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

6六、结构图稳定范围与实部限制15 分#

思路
  • 由结构图写闭环特征方程，用劳斯判据求稳定 K 范围，再平移求实部上界。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求使系统稳定的参数范围
本卷实例
  • 关键一步：写全特征方程并按劳斯表逐行计算
  • 中间结果：首列各元素同号给出 K 的上下界
