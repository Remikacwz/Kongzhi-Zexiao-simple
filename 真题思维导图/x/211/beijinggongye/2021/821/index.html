1一、电网络传递函数与超前特性15 分#

思路
  • 由两级 RC 并联分压列复阻抗方程求输出电压对输入电压的传函；由分子分母零极点位置定超前条件；再按转折频率画对数幅频与相频草图。题面含图未读图。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由两级 RC 并联网络列复阻抗方程求传递函数
本卷实例
  • 关键一步：用复阻抗写分压比，上臂R2与C2并联、下臂R1与C1并联
  • 关键一步：整理成分子含一阶微分项、分母含一阶惯性项的形式
  • 中间结果：分子为一阶微分项、分母为一阶惯性项，比值即超前网络
  • 卡点：网络图未读图，两级 RC 的串并联接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由两级 RC 并联网络列复阻抗方程求传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
典型环节的对数频率特性 频域分析
本卷考法
  • 作出超前网络的对数幅频与相频草图
本卷实例
  • 关键一步：按两个转折频率把幅频分成三段渐近线
  • 关键一步：在转折频率区间内相角为正
  • 中间结果：幅频先平后升，相频在中间频段为正
  • 卡点：两个转折频率由 RC 乘积决定，取值顺序易写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例环节是水平线，积分与微分分别是 -20 与 +20 dB/dec 的斜线
  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec
  • 一阶微分环节与惯性环节幅频互为镜像
  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤
  • 把传递函数分解为典型环节乘积
  • 逐环节画出对数幅频渐近线与相频曲线
  • 代数相加得到总特性
通用考法
  • 本卷考过作出超前网络的对数幅频与相频草图
  • 画出某一典型环节的 Bode 图
  • 由 Bode 图识别环节类型
  • 说明转角频率处的幅值与相角
常见易错
  • 把惯性环节高频渐近线的 -20 写成 -40
  • 振荡环节谐振峰位置误当作 ωn

2二、多输入系统的输出表达式10 分#

思路
  • 结构图含两条闭合回路；对给定输入与扰动分别用梅森公式求通道传函，再用叠加写 C(s)。题面含图未读图。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求给定输入与扰动分别作用时的闭环传递函数并叠加
本卷实例
  • 关键一步：分别令另一输入为零，写单通道闭环传函
  • 中间结果：C(s) 为两条通道输出之和，共用同一特征式
  • 卡点：结构图未读图，回路条数与扰动注入点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求给定输入与扰动分别作用时的闭环传递函数并叠加
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式写回路增益、特征式与前向通路余子式
本卷实例
  • 关键一步：先数独立回路并判断两两是否接触
  • 关键一步：余子式只剔除与该前向通路接触的回路
  • 中间结果：特征式为 1 减回路增益之和加互不接触回路乘积
  • 卡点：回路接触关系判错会使余子式漏项，图需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式写回路增益、特征式与前向通路余子式
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 求一阶系统单位阶跃响应的表达式与调节时间
本卷实例
  • 关键一步：零初始下把传函与 1/s 相乘，再部分分式反变换
  • 中间结果：响应为 1 减一个指数衰减项
  • 卡点：调节时间按 5% 还是 2% 误差带取系数易取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法

  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值

4四、结构图化简与待定参数10 分#

思路
  • 由结构图写 E(s) 到 C(s) 的前向通道传函，与给定目标式逐项比较系数，解出 K1、K2 与 H(s)。题面含图未读图。
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 用串联、并联与反馈等效求前向通道传递函数
本卷实例
  • 关键一步：把内环按负反馈等效化简，再与外环节串联
  • 中间结果：前向通道传函写成分式，分子分母含待定参数
  • 卡点：反馈极性写错会使分母符号与目标式不符
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过用串联、并联与反馈等效求前向通道传递函数
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反
公式
多回路系统的逐层化简 结构图与方框图
本卷考法

本卷实例

  • 中间结果：得到关于 K1、K2 与 H(s) 的代数方程组
  • 卡点：结构图未读图，内环取出点位置需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果

  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

5五、斜坡稳态误差与前馈补偿15 分#

思路
  • 先按前馈为零求系统型别与速度误差系数得稳态误差；再令误差分量对消，反解前馈环节的结构。题面含图未读图。
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡输入下的稳态误差并判断系统型别
本卷实例
  • 关键一步：先判稳再用终值定理求稳态误差
  • 中间结果：斜坡误差为速度误差系数的倒数
  • 卡点：未判稳就取终值，或把斜坡误差写成阶跃误差
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求斜坡输入下的稳态误差并判断系统型别
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
减小稳态误差的措施 稳态误差
本卷考法
  • 设计前馈环节使斜坡输入的稳态误差为零
本卷实例
  • 关键一步：令误差传函在 s 趋于零时的极限为零
  • 中间结果：由误差对消条件反解前馈环节的结构形式
  • 卡点：结构图未读图，前馈注入点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计前馈环节使斜坡输入的稳态误差为零
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调
公式

6六、二阶系统指标反求参数15 分#

思路
  • 由前馈为零时闭环化标准二阶，用超调量定阻尼比、用速度误差定反馈系数；再由误差传函令斜坡稳态误差为零求前馈参数。题面含图未读图。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由结构图化闭环传递函数并求自然频率与阻尼比
本卷实例
  • 关键一步：把闭环特征式与 s²+2ξωn s+ωn² 逐项对照
  • 中间结果：常数项与开环增益对应，一次项含速度反馈系数
  • 卡点：结构图未读图，反馈通道接法需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由结构图化闭环传递函数并求自然频率与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法

  • 先写开环相频，令相角对频率的一阶导数为零求最大相角对应频率；再由幅值条件定增益，最后写出最大相角裕度表达式。
稳定裕度 频域分析
本卷考法
  • 求使相角裕度最大的增益与最大相角裕度表达式
本卷实例
  • 关键一步：由相频对频率求导为零定最大相角处频率
  • 关键一步：再由该频率处幅频为一反解增益
  • 中间结果：最大相角裕度等于两个一阶微分环节相角之差
  • 卡点：忘记先按剪切频率定义定增益，直接读相频
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求使相角裕度最大的增益与最大相角裕度表达式
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

11十一、误差方程与奇点类型10 分#

思路
  • 由闭环结构写误差满足的二阶微分方程，化为相平面方程后由特征根判奇点类型。题面含图未读图。
相平面法 非线性系统
本卷考法
  • 以误差为运动变量写系统方程并判断奇点类型
本卷实例
  • 关键一步：由误差等于输入减输出消去输出，得误差的二阶微分方程
  • 中间结果：特征根为共轭复根时奇点为焦点，为负实根时为节点
  • 卡点：判别式正负与奇点类型对应关系写反，图需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相平面以误差及其导数为坐标，适用于一、二阶非线性系统
  • 相轨迹的斜率由系统微分方程直接给出
  • 奇点对应系统的平衡状态，奇点类型决定局部行为
  • 极限环对应相平面上的孤立闭曲线
步骤
  • 写出以误差及其导数表示的二阶微分方程
  • 由等倾线法或解析法求相轨迹斜率
  • 画出各区域相轨迹并判断奇点类型
  • 由是否存在闭曲线判断极限环与自振
通用考法
  • 本卷考过以误差为运动变量写系统方程并判断奇点类型
  • 画出给定初始条件下的相轨迹
  • 判断奇点类型与稳定性
  • 分析极限环的存在与形态
常见易错
  • 相轨迹斜率公式中分子分母写反
  • 把相轨迹与根轨迹混淆

12十二、采样间隔取值范围10 分#

思路
  • 由连续部分与零阶保持器求开环脉冲传函，再列闭环特征方程用离散稳定判据解采样间隔的范围。题面含图未读图。
脉冲传递函数 离散控制系统
本卷考法
  • 由连续环节与零阶保持器求开环脉冲传递函数
本卷实例
  • 关键一步：先把连续部分部分分式展开再逐项查 z 变换表
  • 中间结果：脉冲传函分子分母均含 e 的负 T 次幂
  • 卡点：忘记零阶保持器带来的因子 (z-1)/z
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 脉冲传递函数是零初始条件下输出与输入 z 变换之比
  • 连续环节串联时若中间没有采样开关，不能直接相乘
  • 闭环脉冲传递函数的写法取决于采样开关的位置
  • G(z)=Z[G(s)] 中的保持器要一并计入
步骤
  • 确定采样开关位置并画出离散化结构图
  • 对包含保持器的连续部分整体做 z 变换
  • 按串并联或反馈等效写出脉冲传递函数
通用考法
  • 本卷考过由连续环节与零阶保持器求开环脉冲传递函数
  • 求开环或闭环脉冲传递函数
  • 比较不同采样开关位置对结果的影响
  • 由连续传递函数求脉冲传递函数
常见易错
  • 把两个无采样开关隔开的连续环节直接相乘
  • 忘记把零阶保持器计入 G(z)
公式
离散系统稳定性分析 离散控制系统
本卷考法
  • 判断采样间隔变化时离散系统的稳定性范围
本卷实例
  • 关键一步：由闭环特征方程列朱利判据或 w 变换后劳斯判据
  • 中间结果：稳定条件整理成含 e 的负 T 次幂的不等式
  • 卡点：把稳定条件写成实部小于零而不是模小于 1
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环脉冲传函的极点全部位于 z 平面单位圆内则稳定
  • 可直接求解特征根，也可用朱里判据或 w 变换后套劳斯判据
  • w 变换把单位圆内映射到左半平面
  • 采样周期增大会使稳定性变差
步骤
  • 写出闭环脉冲传递函数的特征方程
  • 选择方法：求根、朱里判据或 w 变换后用劳斯判据
  • 对含参数的系统求使稳定成立的参数范围
  • 必要时分析采样周期对稳定域的影响
通用考法
  • 本卷考过判断采样间隔变化时离散系统的稳定性范围
  • 判断离散系统是否稳定
  • 求使系统稳定的采样周期或增益范围
  • 用 w 变换后套用劳斯判据
常见易错
  • 把稳定条件写成实部小于零而不是模小于 1
  • w 变换公式记错导致映射关系颠倒
