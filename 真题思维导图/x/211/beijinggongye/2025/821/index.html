1一、电路复阻抗求传递函数#

思路
  • 对电路图按复阻抗法列出分压或节点方程，消去中间变量后整理成输出与输入的比值
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由电路图用复阻抗法求 Uo(s)/Ui(s)
本卷实例
  • 关键一步：把各元件换成复阻抗，按分压或节点电流列方程
  • 中间结果：比值由两个 s 多项式相除给出，阶次随储能元件个数升高
  • 卡点：电路拓扑未读图，元件串并联方式需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由电路图用复阻抗法求 Uo(s)/Ui(s)
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 把电路网络整理为输出对输入的网络函数
本卷实例
  • 关键一步：判断无源还是有源网络后选择分压法或虚短虚断
  • 中间结果：网络函数分母为表征网络结构的 s 多项式
  • 卡点：若含运放，负号与反馈支路需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过把电路网络整理为输出对输入的网络函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

2二、方框图求闭环传递函数#

思路
  • 两小问各给一个方框图，先判断回路层数，再用逐层化简或梅森公式写出 C(s)/R(s)
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 用逐层化简求多回路方框图的闭环传函
本卷实例
  • 关键一步：先定最内环，把内环化成等效环节后再向外化简
  • 中间结果：每化一环绕过一个比较点，最终化成单回路
  • 卡点：比较点引出的支路条数容易漏乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过用逐层化简求多回路方框图的闭环传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式数前向通路与独立回路
本卷实例
  • 关键一步：先列出全部回路，再按两两不接触逐层写特征式
  • 中间结果：特征式由单回路、两两不接触与三三不接触项累加
  • 卡点：余子式里要剔除与通路接触的回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式数前向通路与独立回路
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 把串联、并联与反馈环节等效合并
本卷实例
  • 关键一步：按串联相乘、并联相加、反馈取前向比一加开环
  • 中间结果：等效环节的分子分母次数由参与合并的环节决定
  • 卡点：反馈等效时分清正负反馈与 H(s) 的位置
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过把串联、并联与反馈环节等效合并
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

3三、R 与 N 同时作用下的误差#

思路
  • 用叠加原理分别求 R 到误差与 N 到误差的传递函数，再代入给定输入与扰动信号取终值
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求 R 与 N 到误差的传递函数
本卷实例
  • 关键一步：用叠加原理，每次只保留一个输入并令另一个为零
  • 中间结果：总误差为给定误差与扰动误差的代数和
  • 卡点：求扰动通道时容易忘记把参考输入置零
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求 R 与 N 到误差的传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 写出误差定义下的误差传递函数
本卷实例
  • 关键一步：按题意确定误差取在输入端还是反馈端
  • 中间结果：误差传函由前向通路与反馈通路共同决定
  • 卡点：非单位反馈时两种误差定义相差一个反馈环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写出误差定义下的误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动作用引起的稳态误差
本卷实例
  • 关键一步：令参考输入为零，写出扰动到误差的传函再取终值
  • 中间结果：扰动稳态误差取决于扰动点前的前向增益
  • 卡点：扰动与给定引起的误差需分别算再叠加
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求扰动作用引起的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

4四、由阶跃响应反求二阶系统参数#

思路
  • 对阶跃响应取拉氏变换再除以 1/s 得闭环传函，归一化后读出自然频率与阻尼比，最后按组合输入求稳态误差
由响应曲线反求传递函数 传递函数
本卷考法
  • 由阶跃响应表达式反求闭环传函
本卷实例
  • 关键一步：对响应取拉氏变换再除以阶跃输入的 1/s
  • 中间结果：分母由响应中两个衰减指数对应的一阶因式相乘
  • 卡点：稳态值不是一时不能直接把终值当作增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由阶跃响应表达式反求闭环传函
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函读出阻尼比与自然频率
本卷实例
  • 关键一步：把分母首项系数归一化后与标准二阶形式比对系数
  • 中间结果：两个闭环极点都落在负实轴上，阻尼比大于一
  • 卡点：阻尼比大于一时属过阻尼，不能套欠阻尼指标公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函读出阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求阶跃与斜坡组合输入下的稳态误差
本卷实例
  • 关键一步：分别算阶跃分量与斜坡分量引起的误差再叠加
  • 中间结果：误差传函含因子 s，斜坡分量对应有限速度误差
  • 卡点：用终值定理前要先确认闭环极点都在左半平面
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求阶跃与斜坡组合输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

5五、临界增益与极点实部限制#

思路
  • 先由等幅振荡条件求临界 K，再把虚轴平移到 s 等于负二后重列劳斯表，由首列同号求 K 的范围
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求等幅振荡对应的临界 K
本卷实例
  • 关键一步：列闭环特征方程的劳斯表并令首列某元素为零
  • 中间结果：临界 K 对应特征根落在虚轴上
  • 卡点：等幅振荡是临界稳定，不是渐近稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求等幅振荡对应的临界 K
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 移位后求闭环极点实部小于负二的 K 范围
本卷实例
  • 关键一步：令新变量等于原变量加二，把边界平移到虚轴再列劳斯表
  • 中间结果：移位后的首列同号条件对应原极点的实部限制
