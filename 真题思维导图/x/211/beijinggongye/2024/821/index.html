1一、无源校正网络的传函与频率特性10 分#

思路
  • 由电阻电容网络按复阻抗分压写传递函数，再令 s 为 jω 得频率特性并画对数幅频特性草图。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由无源电阻电容网络求传递函数
本卷实例
  • 关键一步：按复阻抗写分压比或列节点电流方程
  • 中间结果：传函为含一个零点的反相比例形式
  • 卡点：网络图未读图，元件连接拓补需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由无源电阻电容网络求传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
频率特性的物理意义与求法 频域分析
本卷考法
  • 把网络传函中的 s 换为 jω 写频率特性
本卷实例
  • 关键一步：把传函中 s 代换为 jω 并整理实部与虚部
  • 中间结果：频率特性呈纯虚数叠加一个实常数
  • 卡点：电容复阻抗误写成 Cs 或漏掉负号
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过把网络传函中的 s 换为 jω 写频率特性
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
典型环节的对数频率特性 频域分析
本卷考法
  • 由网络传函画对数幅频特性草图
本卷实例
  • 关键一步：先定低频渐近线斜率与高度
  • 关键一步：再按转折频率逐段改变斜率
  • 中间结果：草图为负二十与零斜率两段折线
  • 卡点：转折频率处斜率改变方向记反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例环节是水平线，积分与微分分别是 -20 与 +20 dB/dec 的斜线
  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec
  • 一阶微分环节与惯性环节幅频互为镜像
  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤
  • 把传递函数分解为典型环节乘积
  • 逐环节画出对数幅频渐近线与相频曲线
  • 代数相加得到总特性
通用考法
  • 本卷考过由网络传函画对数幅频特性草图
  • 画出某一典型环节的 Bode 图
  • 由 Bode 图识别环节类型
  • 说明转角频率处的幅值与相角
常见易错
  • 把惯性环节高频渐近线的 -20 写成 -40
  • 振荡环节谐振峰位置误当作 ωn

2二、多输入系统的输出表达式10 分#

思路
  • 对给定参考输入与扰动分别用梅森公式求通道传函，回路与特征式相同，再叠加写出输出表达式。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 分别求参考输入与扰动到输出的传递函数
本卷实例
  • 关键一步：求一个通道时把另一个输入置零
  • 中间结果：两通道共用同一特征式
  • 卡点：结构图未读图，回路与注入点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过分别求参考输入与扰动到输出的传递函数
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式写回路增益与特征式
本卷实例
  • 关键一步：数出两条单独回路并判断是否接触
  • 中间结果：特征式含两回路互不接触的乘积项
  • 卡点：把前向通路增益当成回路增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式写回路增益与特征式
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

3三、二阶系统阻尼比与动态性能10 分#

思路
  • 由结构图写闭环传函化为标准二阶，按给定阻尼比反求开环增益，再算超调量与调节时间。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函化为标准二阶并按阻尼比反求增益
本卷实例
  • 关键一步：把闭环特征方程二次项系数归一化
  • 关键一步：对照标准式读阻尼比表达式
  • 中间结果：阻尼比与开环增益呈线性关系
  • 卡点：未归一化直接读系数导致阻尼比错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函化为标准二阶并按阻尼比反求增益
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率算超调量与调节时间
本卷实例
  • 关键一步：代入欠阻尼超调量与调节时间公式
  • 中间结果：两指标由同一对参数决定
  • 卡点：调节时间误差带取百分之五时系数用三点五
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率算超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

4四、稳定范围与单位斜坡稳态误差10 分#

思路
  • 由结构图写三阶闭环特征方程，列劳斯表求稳定参数范围；再由速度误差系数求单位斜坡输入下的稳态误差。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯表求使三阶系统稳定的参数范围
本卷实例
  • 关键一步：列劳斯表并令首列元素同号
  • 中间结果：稳定条件化为参数的不等式组
  • 卡点：首列元素为零时不作辅助方程处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯表求使三阶系统稳定的参数范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求系统稳定时两个参数的取值域
本卷实例
  • 关键一步：把劳斯表首列各元写成参数表达式
  • 中间结果：稳定域为参数平面内一个楔形区域
  • 卡点：漏掉最后一个首列元的不等式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求系统稳定时两个参数的取值域
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位斜坡输入下的稳态误差
本卷实例
  • 关键一步：由速度误差系数取开环零频一阶极限
  • 中间结果：斜坡误差等于斜坡幅值除以速度误差系数
  • 卡点：未判稳就使用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位斜坡输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

5五、由幅频折线反求校正前后传函15 分#

思路
  • 由校正前后对数幅频折线读转折频率与低频段高度，分别反求校正前后开环传函，作比值得校正装置传函，再算前后相角裕度并比较性能。
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频折线反求校正前后开环传函
本卷实例
  • 关键一步：先读低频段斜率定型别与增益
  • 关键一步：再按各转折频率逐段写惯性或微分环节
  • 中间结果：校正前后传函低频段相同、中高频转折不同
  • 卡点：折线图未读图，转折频率与低频高度需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频折线反求校正前后开环传函
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
稳定裕度 频域分析
本卷考法
  • 计算校正前后系统的相角裕度
本卷实例
  • 关键一步：由折线求各截止频率再代入相频表达式
  • 中间结果：校正前裕度为负、校正后显著提高
  • 卡点：截止频率取自折线需逐段求解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg

思路

脉冲传递函数 离散控制系统
本卷考法

本卷实例

  • 中间结果：脉冲传函分母为二次多项式
