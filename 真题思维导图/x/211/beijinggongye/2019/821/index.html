1一、含初值的微分方程时域求解10 分#

思路
  • 由闭环传函写微分方程，对含初值方程作拉氏变换，再反变换求全响应。
线性微分方程的时域求解与全响应 基本概念与信号
本卷考法
  • 由微分方程与初值求系统全响应
本卷实例
  • 关键一步：对含初值方程作拉氏变换
  • 中间结果：把 C(s) 分解为部分分式
  • 卡点：初值的正负号需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 全响应由零输入响应与零状态响应两部分叠加而成
  • 零输入响应的形式由特征根决定，系数由初始条件定
  • 零状态响应用卷积或拉氏变换法求，也可查典型输入的响应表
  • 初值条件要区分零时刻前后的跳变，含输入导数项的方程会在零时刻产生跳变
步骤
  • 写出微分方程并取拉氏变换，把初始条件作为等效输入移到等号右端
  • 分别求零输入解与零状态解，再相加得全响应
  • 用初始条件定常数，必要时用终值核对稳态值
  • 检查求得的解在零时刻是否等于给定初值
通用考法
  • 本卷考过由微分方程与初值求系统全响应
  • 由微分方程与初始条件求系统的全响应
  • 分别求零输入响应与零状态响应
  • 判断给定初值下响应是否单调或是否有极值
常见易错
  • 本卷考过只求零状态响应而漏掉初值自由分量
  • 只求零状态响应而漏掉由初值决定的自由响应
  • 分子含输入导数时忽略零时刻的跳变，导致初值对不上
公式
传递函数的定义与基本性质 传递函数
本卷考法
  • 由传递函数反写系统微分方程
本卷实例
  • 关键一步：分母对应输出各阶导数
  • 中间结果：分子对应输入各阶导数
  • 卡点：传函系数抄写需按升幂核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由传递函数反写系统微分方程
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 本卷考过忽略零初始条件这一前提
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒

思路

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 求扰动的传递函数时令参考输入为零

  • 分析满足扰动不变性的补偿条件
常见易错

  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零

  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性

  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用

3三、由性能指标反求结构图参数20 分#

思路
  • 由结构图写闭环特征式，用超调、峰值时间与稳态值三个条件联立求 K、a、b。
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法

本卷实例
  • 关键一步：对特征方程作归一化处理
  • 中间结果：由系数得 ωn 与 ζ
  • 卡点：结构图参数定义需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环特征方程写标准二阶形式
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 本卷考过未把二次项系数归一化
  • 化为标准形式时忘记把 s² 项系数归一化
