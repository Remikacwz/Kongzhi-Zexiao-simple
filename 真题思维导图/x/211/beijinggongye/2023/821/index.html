1一、无源网络的传递函数10 分#

思路
  • 由电阻电容网络按节点电压或复阻抗分压列方程，整理成输出电压对输入电压的传递函数。题面含图未读图。
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由无源电阻电容网络求传递函数
本卷实例
  • 关键一步：按节点列电流方程或写复阻抗分压比
  • 中间结果：传函分子含一阶微分项、分母含一阶惯性项
  • 卡点：网络图未读图，元件拓补需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由无源电阻电容网络求传递函数
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式

2二、多输入系统的输出表达式10 分#

思路
  • 对给定输入与扰动分别用梅森公式求通道传函，回路与特征式相同，再叠加写输出表达式。题面含图未读图。
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法
  • 求给定输入与扰动分别作用时的输出并叠加
本卷实例
  • 关键一步：分别令另一输入为零写单通道传函
  • 中间结果：输出为给定项与扰动项之和，共用同一特征式
  • 卡点：未把另一输入置零，结构图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 线性系统可用叠加原理，每次只保留一个输入
  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法
  • 本卷考过求给定输入与扰动分别作用时的输出并叠加
  • 求扰动引起的输出或误差
  • 分析满足扰动不变性的补偿条件
常见易错
  • 两个输入同时存在时直接叠加却未验证系统的线性性
  • 求扰动传函时没有把参考输入置零
公式
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森公式写回路增益与特征式
本卷实例
  • 关键一步：数出两条单独回路并判断互不接触
  • 中间结果：特征式等于一加两条回路增益之和
  • 卡点：把前向通路增益与回路增益混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森公式写回路增益与特征式
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益

3三、二阶系统性能指标10 分#

思路
  • 由微分方程写传递函数并化标准二阶，读阻尼比与自然频率后代入公式求超调量与调节时间。
传递函数的定义与基本性质 传递函数
本卷考法
  • 由线性微分方程写系统传递函数
本卷实例
  • 关键一步：零初始下对方程两边取拉氏变换
  • 中间结果：传函分母系数与微分方程系数一致
  • 卡点：忽略零初始条件，把初值带进变换结果
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 定义：零初始条件下，输出与输入的拉氏变换之比 G(s)=C(s)/R(s)
  • 只由系统结构与参数决定，与输入形式无关
  • 分母为特征多项式，其根是极点；分子的根是零点
  • 工程可实现系统必为真分式（分子阶数 ≤ 分母阶数）
步骤
  • 对微分方程两边取拉氏变换，初始条件全部置零
  • 把输出项移到左边、输入项移到右边
  • 整理成 C(s)/R(s) 的降幂形式
通用考法
  • 本卷考过由线性微分方程写系统传递函数
  • 由微分方程直接写出传递函数
  • 指出系统的阶数、极点个数与零点个数
  • 判断给定分式能否作为实际系统的传递函数
常见易错
  • 忽略“零初始条件”这一前提，把初始值带进变换结果
  • 分子分母系数按升幂抄写导致顺序颠倒
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由传递函数求无阻尼自然频率与阻尼比
本卷实例
  • 关键一步：把分母首项系数归一化后与标准式对照
  • 中间结果：由常数项和一次项分别得自然频率与阻尼比
  • 卡点：未归一化就直接读系数导致自然频率错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由传递函数求无阻尼自然频率与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率计算超调量与调节时间
本卷实例
  • 关键一步：套超调量公式与 5% 误差带的调节时间公式
  • 中间结果：超调量与调节时间由同一对参数决定
  • 卡点：调节时间的两种误差带系数取反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率计算超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式

4四、船舶航向扰动影响与补偿15 分#

思路
  • 先求扰动到输出的传函，由终值定理算风力造成的稳态航向偏差；再求给定通道传函，设计舵输入使偏差归零。题面含图未读图。
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求持续风力扰动引起的稳态输出偏差
本卷实例
  • 关键一步：令给定为零，写扰动到输出的传函
  • 关键一步：由终值定理取零频极限
  • 中间结果：稳态偏差正比于扰动幅值与扰动通道低频增益
  • 卡点：把扰动引起的输出偏差与误差传函混为一谈
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求持续风力扰动引起的稳态输出偏差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
多输入与扰动作用下的传递函数 结构图与方框图
本卷考法

本卷实例
  • 关键一步：两通道特征式相同，分子只差注入点到输出的通路
  • 中间结果：给定通道传函含方向舵增益
  • 卡点：结构图未读图，扰动注入点需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点

  • 求扰动的传递函数时令参考输入为零
  • 扰动误差与输入误差分别计算后再叠加
步骤
  • 令 R(s)=0，求扰动到输出的传递函数
  • 令 N(s)=0，求输入到输出的传递函数
  • 按题目要求叠加或单独分析
通用考法

公式
减小稳态误差的措施 稳态误差
本卷考法
  • 设计附加控制输入使扰动引起的偏差归零
本卷实例
  • 关键一步：令给定通道与扰动通道的稳态输出大小相等方向相反
  • 中间结果：附加输入为与扰动同型、幅值按稳态增益折算的信号
  • 卡点：只做定性说明而未给可实现的控制量形式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 提高开环增益可减小有差系统的误差，但会削弱稳定性
  • 增加积分环节可提高型别，代价是相位滞后与超调增大
  • 采用复合控制或前馈补偿可在不影响稳定性的前提下减小误差
  • 采用扰动补偿可提高扰动不变性
步骤
  • 判断误差来源是输入型别不足还是增益太小
  • 按需选择提高增益、增加积分或加入补偿器
  • 校验补偿后系统仍然稳定
  • 重新计算稳态误差确认达标
通用考法
  • 本卷考过设计附加控制输入使扰动引起的偏差归零
  • 分析提高开环增益对误差与稳定性的双重影响
  • 设计前馈补偿器实现给定信号不变性
  • 说明为何单纯提高增益不可行
常见易错
  • 只谈误差减小而不检查稳定性是否被破坏
  • 把增加积分环节的影响单一化，忽略超调

5五、稳定范围与稳态误差范围15 分#

思路
  • 由开环传函写闭环特征方程，列劳斯表求稳定增益范围；再按斜坡输入稳态误差要求解增益范围并与稳定范围取交集。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求含右半平面零点的系统稳定增益范围
本卷实例
  • 关键一步：整理闭环特征方程后列劳斯表并令首列同号
  • 中间结果：由两个首列不等式得增益的上下界
  • 卡点：分子含一阶反号项，展开特征方程时符号写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求含右半平面零点的系统稳定增益范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 确定同时满足稳定与精度要求的增益范围
本卷实例
  • 关键一步：把稳态误差不等式与稳定范围取交集
  • 中间结果：误差要求给出增益下界，稳定要求给出上界
  • 卡点：取交集时端点是否包含弄错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过确定同时满足稳定与精度要求的增益范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求斜坡输入下稳态误差并反求增益范围
本卷实例
  • 关键一步：先判稳再由终值定理写误差与增益的关系
  • 中间结果：稳态误差与开环增益成反比
  • 卡点：由误差不等式反解增益后未与稳定范围取交集
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
