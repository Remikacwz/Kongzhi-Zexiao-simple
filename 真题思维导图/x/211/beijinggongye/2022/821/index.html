1一、运放电路的传递函数与阶跃响应10 分#

思路
  • 逐级列运放虚短虚断关系求闭环传函，化成标准二阶后求超调量与调节时间并画响应曲线。题面含图未读图。
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由含多个运算放大器的电路求传递函数
本卷实例
  • 关键一步：逐级写虚短虚断与节点电流方程
  • 关键一步：把中间级输出代回得闭环传函
  • 中间结果：整理为标准二阶，自然频率与阻尼比由 RC 及电阻比确定
  • 卡点：反相输入的负号漏掉，电路图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由含多个运算放大器的电路求传递函数
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函系数求无阻尼自然频率与阻尼比
本卷实例
  • 关键一步：把分母与 s²+2ξωn s+ωn² 逐项对照
  • 中间结果：由常数项开方得自然频率，由一次项系数定阻尼比
  • 卡点：分母首项未归一化就直接读系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函系数求无阻尼自然频率与阻尼比
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由阻尼比与自然频率计算超调量与调节时间并画曲线
本卷实例
  • 关键一步：代入超调量公式与调节时间公式
  • 关键一步：按 5% 误差带取三倍半除以阻尼乘自然频率
  • 中间结果：得到超调量与调节时间用于描点作图
  • 卡点：两种误差带的调节时间系数混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由阻尼比与自然频率计算超调量与调节时间并画曲线
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

2二、飞机俯仰角控制系统的传递函数10 分#

思路
  • 由结构图画信号流图，用梅森公式数回路、判断互不接触、写特征式与前向通路余子式。题面含图未读图。
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图用梅森公式求俯仰角对输入的传递函数
本卷实例
  • 关键一步：数出三条回路并找出互不接触的一对
  • 中间结果：特征式含互不接触回路增益乘积项
  • 卡点：互不接触回路乘积项漏写，结构图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图用梅森公式求俯仰角对输入的传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 用逐层化简核对梅森公式所得的传递函数
本卷实例
  • 关键一步：先把内环等效为一个环节再与外环串联
  • 中间结果：化简结果与梅森公式所得分式一致
  • 卡点：化简内环时把外环信号当常数处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过用逐层化简核对梅森公式所得的传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

3三、给定与扰动同时作用下的稳态误差10 分#

思路
  • 分别求误差对给定输入与对扰动的传函，再令两输入同时作用，用终值定理叠加求稳态误差。题面含图未读图。
扰动作用下的稳态误差 稳态误差
本卷考法
  • 求扰动输入引起的稳态误差分量
本卷实例
  • 关键一步：令给定输入为零，写扰动到误差的传递函数
  • 中间结果：扰动误差与扰动幅值和扰动通道低频增益有关
  • 卡点：未把给定输入置零，结构图需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过求扰动输入引起的稳态误差分量
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求给定输入引起的稳态误差并与扰动分量叠加
本卷实例
  • 关键一步：由终值定理分别求给定与扰动两个分量
  • 中间结果：总稳态误差为两个分量的代数和
  • 卡点：把扰动误差方向的正负号弄错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求给定输入引起的稳态误差并与扰动分量叠加
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式

5五、参数稳定域与垂线左侧根10 分#

思路
  • 先列劳斯表求稳定时的增益范围；再令原变量等于新变量减一，把稳定边界平移到虚轴，对代换后方程列劳斯表求增益范围。
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求系统稳定时的开环增益范围
本卷实例
  • 关键一步：列劳斯表并令首列各元素同号
  • 中间结果：由首列不等式交集得增益的取值范围
  • 卡点：系数缺项未补零导致劳斯表列错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求系统稳定时的开环增益范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求闭环特征根全部位于给定垂线左侧的增益范围
本卷实例
  • 关键一步：令新变量等于原变量加一，把垂线平移到虚轴
  • 关键一步：对代换后方程列劳斯表
  • 中间结果：稳定度要求转化为代换后劳斯表首列的不等式组
  • 卡点：代换展开时符号写错，或漏掉常数项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求闭环特征根全部位于给定垂线左侧的增益范围

思路

描述函数法基础 非线性系统
本卷考法

  • 卡点：把描述函数当成频率的函数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数

用描述函数法分析自振 非线性系统
本卷考法
  • 用描述函数法求自振频率、振幅并判断自振性质
本卷实例

  • 关键一步：由交点附近振幅变化方向判自振稳定性
  • 中间结果：交点频率为自振频率，交点为自振振幅

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定

  • 未标注 A 的增大方向就判断稳定性
