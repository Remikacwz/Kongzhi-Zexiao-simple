1一、输入与扰动下的稳态误差#

思路
  • 由结构图写闭环特征方程，先用劳斯判据判断稳定性，再讨论输入与扰动分别作用下的稳态误差
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据先判断系统稳定性
本卷实例
  • 关键一步：写出闭环特征多项式，补齐缺项后列劳斯表
  • 中间结果：首列出现两次变号说明有两个右半平面闭环根
  • 卡点：系统不稳定时不存在稳态误差，不能再用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据先判断系统稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

典型输入下的稳态误差计算 稳态误差
本卷考法
  • 讨论输入 r(t)=5t 下稳态误差是否存在
本卷实例
  • 关键一步：先判稳，再判断系统型别与斜坡输入的误差
  • 中间结果：系统不稳定时该问没有有限的稳态误差
  • 卡点：不能跳过判稳直接套静态误差系数公式
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过讨论输入 r(t)=5t 下稳态误差是否存在
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

扰动作用下的稳态误差 稳态误差
本卷考法
  • 讨论扰动 n(t)=3t^2 下稳态误差是否存在
本卷实例
  • 关键一步：把参考输入置零，由扰动到误差的传函分析
  • 中间结果：扰动误差受扰动作用点前后积分环节影响
  • 卡点：总误差要分别考虑输入分量与扰动分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过讨论扰动 n(t)=3t^2 下稳态误差是否存在
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

本卷考法

本卷实例

  • 卡点：题面 G1 的写法 OCR 作 G1(s)/s，需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关

  • 数错积分环节个数导致型别判错

2二、结构图等效变换求传递函数#

思路
  • 按比较点与引出点移动规则逐步化简结构图求 C(s)/R(s)，再用梅森增益公式检验结果
比较点与引出点的移动 结构图与方框图
本卷考法
  • 用比较点与引出点移动化简交叉结构
本卷实例
  • 关键一步：识别交叉处引出点，前移或后移使回路解耦
  • 中间结果：移动后对应支路增益作倒数补偿
  • 卡点：多路交叉来回移动容易漏掉某条支路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过用比较点与引出点移动化简交叉结构
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路系统逐层化简求闭环传递函数
本卷实例
  • 关键一步：先化简内环，再把结果代入外环
  • 中间结果：分母出现 1 减各回路增益的组合项
  • 卡点：每条回路增益符号要与反馈极性对应
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路系统逐层化简求闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式检验等效化简结果
本卷实例
  • 关键一步：列出全部回路与互不接触回路组，再列前向通路
  • 中间结果：特征式与分子由回路组和前向通路贡献组成
  • 卡点：题要求等效变换，梅森公式只能用来校验
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式检验等效化简结果
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
串联、并联与反馈等效 结构图与方框图
本卷考法
  • 用串联、并联与反馈等效做局部化简
本卷实例
  • 关键一步：串联相乘、并联相加后再接反馈
  • 中间结果：局部反馈化简用前向除以一加回路增益
  • 卡点：负反馈分母符号别写成 1 减回路增益
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 串联环节相乘，并联环节相加（同向）或相减（反向）
  • 负反馈等效为 G/(1+GH)，正反馈为 G/(1-GH)
  • 反馈等效的前提是单回路、无交叉
步骤
  • 识别环节之间的连接方式
  • 分别套用串联、并联或反馈等效公式
  • 逐层化简直到只剩一个等效环节
通用考法
  • 本卷考过用串联、并联与反馈等效做局部化简
  • 多环节系统求闭环传递函数
  • 判断反馈极性对分母符号的影响
常见易错
  • 把负反馈的分母写成 1-GH
  • 并联环节相减时符号取反

3三、根轨迹与反馈零点的影响#

思路
  • 先画 G(s)=k/[s^2(s+1)(s+4)] 的根轨迹并判稳，再令 H(s)=s+0.3 引入开环零点重画，比较稳定性变化
根轨迹的绘制法则 根轨迹法
本卷考法
  • 画含两个积分环节的四阶系统根轨迹
本卷实例
  • 关键一步：由四个开环极点定分支、渐近线交点与夹角
  • 中间结果：实轴根轨迹段由右侧零极点个数为奇数判定
  • 卡点：两个原点极点使渐近线夹角与出射方向较特殊
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过画含两个积分环节的四阶系统根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求分离点并筛选有效解
本卷实例
  • 关键一步：令闭环特征方程对 k 的导数为零得分离点方程
  • 中间结果：候选根要回代判断是否真的落在根轨迹上
  • 卡点：别把不在根轨迹上的候选根写进结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求分离点并筛选有效解
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 用劳斯判据判断根轨迹是否穿越虚轴
本卷实例
  • 关键一步：把特征方程列劳斯表，看首列是否存在零
  • 中间结果：k 大于零时首列含负项，说明根轨迹不穿虚轴
  • 卡点：辅助方程只在劳斯表首列出现零时才使用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过用劳斯判据判断根轨迹是否穿越虚轴
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 分析引入开环零点 H(s)=s+0.3 对稳定性的影响
本卷实例
  • 关键一步：把 H(s) 乘入开环后在分子增加一个左半平面零点
  • 中间结果：附加零点把根轨迹吸引左移，稳定范围由空变有
  • 卡点：零点位置要回原卷核对，别与极点位置搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过分析引入开环零点 H(s)=s+0.3 对稳定性的影响
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹确定使系统稳定的 k 范围
本卷实例
  • 关键一步：令劳斯表首列全部大于零求 k 的交集
  • 中间结果：引入零点后稳定范围变为有限的 k 区间
  • 卡点：临界 k 对应纯虚根，属临界稳定要单独说明
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆

8八、描述函数法分析自振#

思路
  • 由死区继电描述函数画负倒特性曲线，与线性部分奈奎斯特曲线比较判断自振，校正后重新化简等效线性环节再判断
描述函数法基础 非线性系统
本卷考法
  • 求死区继电特性的描述函数与负倒数
本卷实例
  • 关键一步：按死区继电特性代入描述函数公式并化简
  • 中间结果：负倒特性随振幅增大先增后减，存在极值点
  • 卡点：极值点位置与门槛、幅值参数的关系要按原题代入
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过求死区继电特性的描述函数与负倒数
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

用描述函数法分析自振 非线性系统
本卷考法
  • 由负倒特性与线性部分曲线判断自振
本卷实例
  • 关键一步：画两条曲线，看是否有交点以及穿越方向
  • 中间结果：无交点时系统稳定，不存在自激振荡
  • 卡点：画的是负倒特性而不是描述函数，方向容易搞反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 自振条件为 G(jω)N(A)=-1，即线性部分特性与负倒描述函数曲线相交
  • 交点给出自振频率 ω 与自振幅值 A
  • 负倒描述函数曲线上幅值增大的方向决定自振是否稳定
  • 交点处两条曲线的走向关系决定极限环稳定性
步骤
  • 求线性部分的频率特性 G(jω)
  • 求非线性环节的负倒描述函数 -1/N(A) 并确定 A 的增大方向
  • 在同一复平面上画两条曲线并求交点
  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A
通用考法
  • 本卷考过由负倒特性与线性部分曲线判断自振
  • 判断系统是否产生自持振荡
  • 求自振频率与自振幅值
  • 分析参数变化对自振的影响
常见易错
  • 画的是 N(A) 而不是负倒描述函数 -1/N(A)
  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率

非线性系统的稳定性与改善 非线性系统
本卷考法

本卷实例

  • 中间结果：校正后等效线性部分降阶，曲线不再与负倒特性相交

步骤

  • 分析非线性环节参数对自振幅值频率的影响
  • 通过调整线性部分增益或加入校正削弱自振
  • 重新分析确认自振消除或幅值达标
通用考法
  • 本卷考过分析校正后系统自振是否消除
  • 提出消除自振的工程措施

  • 比较不同方案对稳定性与动态性能的利弊
常见易错
  • 仅调整增益而不检查是否引入新的自振点
