1一、抛物线输入稳态误差与稳定K范围#

思路
  • 由结构图写开环传函，列劳斯表求闭环稳定K范围，再按r(t)=t²的ess要求求K范围并取交
系统型别与静态误差系数 稳态误差
本卷考法
  • 判断系统型别并写出静态加速度误差系数
本卷实例
  • 关键一步：由开环传函分母积分环节个数确定系统型别
  • 中间结果：型别决定抛物线输入下的误差是否为有限值
  • 卡点：数错积分环节个数导致系统型别判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过判断系统型别并写出静态加速度误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由r(t)=t²下ess小于0.5的要求反求K范围
本卷实例
  • 关键一步：按抛物线输入把ess写成加速度误差系数倒数
  • 中间结果：ess不等式化为关于K的不等式
  • 卡点：未先判稳就把误差结论与稳定域取交集
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由r(t)=t²下ess小于0.5的要求反求K范围
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求闭环稳定K范围
本卷实例
  • 关键一步：由闭环特征方程列劳斯表并令首列大于零
  • 中间结果：首列各元不等式给出稳定K区间
  • 卡点：系数有缺项时未补零再列劳斯表
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求闭环稳定K范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法

2二、结构图求闭环传函#

思路
  • 由结构图画信号流图，列前向通路与各回路后用梅森增益公式求C(s)/R(s)
梅森增益公式与信号流图 传递函数
本卷考法
  • 由信号流图列前向通路与回路求C(s)/R(s)
本卷实例
  • 关键一步：先画信号流图并标出所有单独回路
  • 中间结果：特征式由单独回路与互不接触回路组成
  • 卡点：余子式里没有剔除与通路接触的回路
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由信号流图列前向通路与回路求C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 含多回路结构图逐层化简求传函
本卷实例
  • 关键一步：从最内环开始合并再逐步向外化简
  • 中间结果：每次合并把内环等效为单个环节
  • 卡点：比较点与引出点移动时乘除关系弄反
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过含多回路结构图逐层化简求传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

3三、由结构图与阶跃响应求参数#

思路
  • 由结构图写闭环传函解析式，从响应曲线读超调量与峰值时间反求ξ、ωn，再由稳态值定增益并回代求参数
由响应曲线反求传递函数 传递函数
本卷考法
  • 由结构图与阶跃响应曲线求参数a、k1、k2
本卷实例
  • 关键一步：先由结构图写出闭环传函的解析形式
  • 中间结果：闭环传函可整理为增益乘二阶标准形式
  • 卡点：未把闭环增益与二阶参数分开处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由结构图与阶跃响应曲线求参数a、k1、k2
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间反求ξ与ωn
本卷实例
  • 关键一步：从响应曲线读出超调量与峰值时间
  • 中间结果：由σ%与tp公式反解阻尼比与自然频率
  • 卡点：响应曲线纵坐标读数未先减去稳态值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与峰值时间反求ξ与ωn
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
由性能指标要求反求参数 时域响应与动态性能
本卷考法
  • 由稳态值定增益并回代求a与k2
本卷实例
  • 关键一步：用终值定理把稳态输出与增益对应
  • 中间结果：由特征方程系数与ξ、ωn关系求a与k2
  • 卡点：只满足动态指标却漏掉稳态值约束
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量要求给出 ξ 的下界，调节时间要求给出 ξωn 的下界
  • 多个指标同时给出时需求参数可同时满足的公共区域
  • 指标之间往往相互制约，需权衡取舍
步骤
  • 把每个指标要求翻译成对 ξ 或 ωn 的不等式
  • 在参数平面上画出各不等式的可行域
  • 取交集并选取合适的参数值
  • 回代验证全部指标是否满足
通用考法
  • 本卷考过由稳态值定增益并回代求a与k2
  • 由超调量和调节时间要求设计开环增益与阻尼
  • 求满足指标要求的参数取值范围
  • 判断给定指标组合是否可实现
常见易错
  • 只满足单项指标就下结论，未做交叉验证
  • 把 ξ 的可行域方向取反

4四、根轨迹及反馈通道附加零点#

思路
  • 对G(s)=k*/[s²(s+2)(s+5)]画180度根轨迹；反馈通道改为H(s)=1+2s后等效开环增加零点，重画并比较
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制含两个原点重极点的四阶根轨迹
本卷实例
  • 关键一步：先标开环零极点并判断实轴上根轨迹段
  • 中间结果：渐近线交点与夹角由四阶系统确定
  • 卡点：重极点处分支数与出射方向判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制含两个原点重极点的四阶根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹的分离点并取舍
本卷实例
  • 关键一步：由分离点方程求出候选根坐标
  • 中间结果：候选中只有落在实轴段上的有效
  • 卡点：求出的根未回代验证是否在轨迹上
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹的分离点并取舍
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界增益
本卷实例
  • 关键一步：令s等于jω代入特征方程分离实虚部
  • 中间结果：由劳斯全零行与辅助方程定交点
  • 卡点：漏掉辅助方程给出的共轭虚轴交点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
附加开环零极点的影响 根轨迹法
本卷考法
  • 分析反馈通道引入零点后根轨迹的变化
本卷实例
  • 关键一步：把H(s)并入开环后重新确定零极点
  • 中间结果：附加零点使实轴段与渐近线随之改变
  • 卡点：把反馈通道零点误当成闭环零点处理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 增加开环零点使根轨迹左移，改善稳定性
  • 增加开环极点使根轨迹右移，恶化稳定性
  • 附加零点会改变分离点位置与渐近线走向
  • 增加极点还可能是系统结构不稳定
步骤
  • 对比增加前后零极点分布
  • 重新判断实轴段与渐近线
  • 分析根轨迹整体移动方向
  • 据此说明对稳定性和动态性能的影响
通用考法
  • 本卷考过分析反馈通道引入零点后根轨迹的变化
  • 说明附加零点对根轨迹形状的影响
  • 判断增加极点后系统是否仍稳定
  • 分析为何某系统需要引入零点
常见易错
  • 只讨论渐近线是否左移右移，忽略分离点变化
  • 把附加零点的影响与附加极点的影响搞反

5五、奈奎斯特曲线与判稳#

思路
  • 对G(s)=K(0.33s+1)/[s(s-1)]写幅相表达式，求与实轴交点后画奈氏曲线，用Z等于P减2N判断闭环稳定性
频率特性的物理意义与求法 频域分析
本卷考法
  • 求G(s)=K(0.33s+1)/[s(s-1)]的幅频与相频表达式
本卷实例
  • 关键一步：令s等于jω后分离实部与虚部
  • 中间结果：幅值与相角都表示为ω的函数
  • 卡点：求幅值时忘记对分母复数取模
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
