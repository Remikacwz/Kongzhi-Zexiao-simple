1一、参数T根轨迹与稳定范围#

思路
  • 把含T项整理成等效开环传函，按参数根轨迹法则作图，再求稳定范围与指定极点对应的T
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以时间常数T为参变量绘制等效根轨迹
本卷实例
  • 关键一步：把闭环特征方程中含T的项整理到分子，写成等效开环传函
  • 中间结果：等效开环出现零点与极点，由此确定分支数与渐近线
  • 卡点：参数未完整提到分子就套用常规根轨迹法则
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以时间常数T为参变量绘制等效根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点对应的临界参数
本卷实例
  • 关键一步：令特征方程中s等于jω，实部与虚部分别为零
  • 中间结果：解得临界参数与对应的虚轴交点频率
  • 卡点：漏掉另一组虚轴交点只代一个频率下结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点对应的临界参数
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由指定的一个闭环极点反求参数
本卷实例
  • 关键一步：把指定极点坐标直接代入闭环特征方程
  • 中间结果：由特征方程一次式解出参数值
  • 卡点：把参数误当成根轨迹增益直接用幅值条件求
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由指定的一个闭环极点反求参数
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式

2二、稳定K范围与稳态误差#

思路
  • 由开环传函写闭环特征方程，用劳斯判据定K范围，再由稳态误差与极点位置要求求K
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求单位负反馈系统的稳定K范围
本卷实例
  • 关键一步：写闭环特征方程并补齐缺项后列劳斯表
  • 中间结果：首列各项大于零给出K的上下界
  • 卡点：只列部分首列元素就下稳定性结论
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求单位负反馈系统的稳定K范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由组合输入下稳态误差上界反求K范围
本卷实例
  • 关键一步：写误差传函并用终值定理求组合输入下的误差极限
  • 中间结果：稳态误差表达式与开环增益成反比
  • 卡点：未判稳就用终值定理，或漏掉组合信号的某一分量
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由组合输入下稳态误差上界反求K范围
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 求闭环极点全部位于指定竖线左侧的K范围
本卷实例
  • 关键一步：对特征方程作变量平移，把竖线左侧问题化为虚轴稳定性问题
  • 中间结果：对平移后的特征方程再次使用劳斯判据
  • 卡点：平移方向写反或端点是否包含判断错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过求闭环极点全部位于指定竖线左侧的K范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式

3三、结构图求传递函数#

思路
  • 由结构图画信号流图，找回路与前向通路后用梅森公式求C(s)/R(s)
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图画信号流图并用梅森增益公式求传函
本卷实例
  • 关键一步：把比较点与引出点画成信号流图节点，标出两条前向通路
  • 中间结果：两个回路无两两不接触项，特征式直接写出
  • 卡点：把与通路接触的回路写进余子式导致结果多乘
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图画信号流图并用梅森增益公式求传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
比较点与引出点的移动 结构图与方框图
本卷考法
  • 识别比较点与引出点的移动关系化简结构图
本卷实例
  • 关键一步：把交叉反馈中的引出点前移或后移使回路解耦
  • 中间结果：化简后得到含两条前向通路的并联结构
  • 卡点：引出点移动时乘除关系用反，支路增益和连线需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过识别比较点与引出点的移动关系化简结构图
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用

4四、由正弦稳态响应求振荡环节#

思路
  • 由输入输出正弦信号的幅值比和相位差列幅频、相频方程，再反求二阶振荡环节参数
频率特性的物理意义与求法 频域分析
本卷考法
  • 由正弦稳态响应写幅频与相频特性方程
本卷实例
  • 关键一步：令频率特性在给定频率处的幅值比和相位差等于测量值
  • 中间结果：幅值比方程与相位差方程联立确定两个未知参数
  • 卡点：忘记把输入信号幅值代进幅值比，或相角符号写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过由正弦稳态响应写幅频与相频特性方程
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由幅频与相频条件反求阻尼比和自然频率
本卷实例
  • 关键一步：把二阶振荡环节传函写成标准形式再代入频率条件
  • 中间结果：由两个频率条件解出自然频率与阻尼比
  • 卡点：把阻尼比定义式与频率特性分母的对应关系写错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由幅频与相频条件反求阻尼比和自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式

5五、由相角裕度反求开环增益#

思路
  • 写出相频表达式并令相角裕度等于给定值求截止频率，再由幅值条件求增益
稳定裕度 频域分析
本卷考法
  • 由相角裕度要求反求开环增益
本卷实例
  • 关键一步：先由相角裕度等于给定值解出截止频率
  • 中间结果：把截止频率代入幅值等于1的条件解出增益
  • 卡点：截止频率与相位穿越频率混用，或相角符号取反，角度需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由相角裕度要求反求开环增益
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据
公式

6六、串联超前与速度反馈校正#

思路
  • 先按给定相角裕度和截止频率设计超前网络，再用速度反馈把阻尼比提高到超调要求
超前校正 系统校正
本卷考法
  • 设计串联超前校正网络满足相角裕度与截止频率
本卷实例
  • 关键一步：由需要补偿的相角求分度系数，再按截止频率定时间常数
  • 中间结果：校正装置写成含零极点的一阶超前网络
  • 卡点：计算补偿角时忽略截止频率提高带来的相角损失
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超前校正利用相位超前特性提高相角裕度
  • 会使截止频率提高，响应加快
  • 最大超前角出现在两个转折频率的几何中点
  • 最大超前角不超过 60°，否则噪声放大明显
步骤
  • 由未校正系统的相角裕度差额确定所需最大超前角
  • 由最大超前角公式求 α
  • 由 α 与目标截止频率求两个转折频率
  • 写出校正装置传递函数并校验
通用考法
  • 本卷考过设计串联超前校正网络满足相角裕度与截止频率
  • 设计串联超前校正装置
  • 计算校正后的相角裕度与截止频率
