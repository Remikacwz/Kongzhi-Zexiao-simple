1一、结构图求闭环传递函数#

思路
  • 由控制系统结构图列单独回路与前向通路，用梅森增益公式求C(s)/R(s)
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图列回路与前向通路求C(s)/R(s)
本卷实例
  • 关键一步：先画信号流图并标出两条单独回路
  • 中间结果：用梅森公式代入各回路与前向通路增益
  • 卡点：余子式中未剔除与通路接触的回路
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图列回路与前向通路求C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简
本卷实例
  • 关键一步：从最内环开始合并再逐步向外化简
  • 中间结果：每次把内环等效为单个环节
  • 卡点：比较点与引出点移动时乘除关系弄反
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2二、二阶系统指标、反馈校正与根轨迹#

思路
  • 由开环传函求闭环标准二阶形式算超调与调节时间，再引入反馈校正环节使ts达标并算超调，最后借根轨迹定性说明调节时间减小
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函求阻尼比与自然频率
本卷实例
  • 关键一步：把闭环分母与标准二阶式对应系数
  • 中间结果：由系数关系解出ζ与ωn
  • 卡点：未把s平方项系数归一化
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由ζ与ωn计算超调量与调节时间
本卷实例
  • 关键一步：按给定误差带选调节时间公式
  • 中间结果：超调量由阻尼比按指数式算出
  • 卡点：两种误差带的调节时间系数混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由ζ与ωn计算超调量与调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%
公式
反馈校正与复合控制 系统校正
本卷考法
  • 由调节时间指标确定反馈校正环节参数
本卷实例
  • 关键一步：把校正环节参数引入闭环特征方程
  • 中间结果：令等效阻尼比与ωn满足指标反解参数
  • 卡点：求参数时未复核超调是否同时达标
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 反馈校正可改变被包围环节的特性，抑制参数波动
  • 局部反馈能降低时间常数、提高响应速度
  • 复合控制通过前馈补偿实现给定或扰动不变性
  • 前馈不改变闭环稳定性，可与反馈叠加使用
步骤
  • 确定被包围的环节与反馈通道传递函数
  • 写出等效后的传递函数
  • 按不变性原理列写前馈补偿器条件
  • 求解补偿器并校验可实现性
通用考法
  • 本卷考过由调节时间指标确定反馈校正环节参数
  • 设计反馈校正装置改善被包围环节
  • 求前馈补偿器实现不变性
  • 分析复合控制对稳态误差的作用
常见易错
  • 前馈补偿器求出的表达式含高阶微分，不可实现却直接采用
  • 忽略反馈校正可能引起的高频噪声放大
公式
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以校正参数为变量作根轨迹说明调节时间减小
本卷实例
  • 关键一步：把含校正参数的项整理成标准根轨迹形式
  • 中间结果：由根实部绝对值增大说明响应加快
  • 卡点：整理时参数未完整提到分子位置
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以校正参数为变量作根轨迹说明调节时间减小
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件

3三、误差传函与扰动稳态误差不变性#

思路
  • 由结构图求给定与扰动分别作用下的误差传函，再令扰动稳态误差为零解出补偿环节
误差定义与误差传递函数 稳态误差
本卷考法
  • 写出给定输入与扰动输入下的误差传函
本卷实例
  • 关键一步：分别令另一输入为零后列误差传函
  • 中间结果：非单位反馈时按定义计误差
  • 卡点：两种误差定义混用导致结果差一个反馈环节
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过写出给定输入与扰动输入下的误差传函
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
扰动作用下的稳态误差 稳态误差
本卷考法
  • 由扰动误差传函求阶跃扰动下的稳态误差
本卷实例
  • 关键一步：先判稳再用终值定理求扰动误差极限
  • 中间结果：误差极限与扰动通路各环节增益有关
  • 卡点：把扰动误差直接当作系统总误差
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 扰动误差与输入误差必须分开计算再叠加
  • 扰动误差取决于扰动作用点到误差点的传递函数
  • 增大扰动点前的增益可减小扰动误差
步骤
  • 令参考输入为零，求扰动到误差的传递函数
  • 代入扰动信号求稳态值
  • 与输入引起的误差叠加
通用考法
  • 本卷考过由扰动误差传函求阶跃扰动下的稳态误差
  • 求扰动引起的稳态误差
  • 比较扰动与输入对误差的不同影响
  • 分析提高前向增益的作用
常见易错
  • 把扰动误差直接当作总误差，遗漏输入分量
  • 求扰动传函时没有把参考输入置零

4四、非最小相位系统幅相曲线与奈氏判据#

思路
  • 由开环传函画幅相频率特性曲线，数右半平面开环极点数后按奈奎斯特判据列包围条件求稳定K范围
频率特性的物理意义与求法 频域分析
本卷考法
  • 计算并绘制开环幅相频率特性曲线
本卷实例
  • 关键一步：把jω代入传函求幅值与相角表达式
  • 中间结果：求曲线与负实轴的交点及起始终止点
  • 卡点：取模时忘记把分母复数化
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过计算并绘制开环幅相频率特性曲线
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据求闭环稳定时的K范围
本卷实例
  • 关键一步：先数开环右半平面极点数
  • 中间结果：按包围负1点情况写Z等于零的条件
  • 卡点：含积分环节时未补画虚轴绕行圆弧
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据求闭环稳定时的K范围
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
最小相位系统与非最小相位系统 频域分析
本卷考法
  • 判断非最小相位对幅相曲线的影响
本卷实例
  • 关键一步：由右半平面极点判断相角变化趋势
  • 中间结果：相角范围改变使包围情况与最小相位不同
  • 卡点：把右半平面极点与右半平面零点混淆
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 最小相位系统：全部零点极点都在左半平面
  • 同类系统中最小相位系统的相位滞后最小
  • 非最小相位系统幅频特性相同但相位滞后更大
  • 含右半平面零点时阶跃响应出现初始反向
步骤
  • 检查零点实部符号判断是否最小相位
  • 比较同幅频特性的两类系统的相频曲线
  • 分析右半平面零点对时域响应的影响
通用考法
  • 本卷考过判断非最小相位对幅相曲线的影响
  • 判断系统是否最小相位
  • 解释阶跃响应初始反向的原因
  • 说明仅由幅频曲线能否唯一确定传递函数
常见易错
  • 以为幅频特性可以唯一确定传递函数
  • 把右半平面极点与右半平面零点混为一谈

5五、由相频特性反求传函并作超前校正#

思路
