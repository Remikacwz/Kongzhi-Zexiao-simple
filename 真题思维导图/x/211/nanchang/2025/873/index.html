1一、电路网络求传递函数#

思路
  • 由无源 RC 网络按复阻抗法列 KCL 与 KVL 方程，消去电容与电阻上的中间电流变量，整理得到输出电压与输入电压之比
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由 RC 网络复阻抗列 KCL 与 KVL 求 Uo(s) 比 Ui(s)
本卷实例
  • 关键一步：把电容按复阻抗写成 1/(Cs)，再对节点列电流方程
  • 中间结果：用 KCL 与 KVL 消去两条电容支路与电阻上的中间电流
  • 卡点：图 1 为原卷电路图未读图，元件串并联关系需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由 RC 网络复阻抗列 KCL 与 KVL 求 Uo(s) 比 Ui(s)
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

2二、一阶系统时间常数与斜坡稳态误差#

思路
  • 由一阶系统达到 95% 对应 3 倍时间常数读出 T，再写单位反馈误差传递函数，对线性升温输入用终值定理求稳态误差
一阶系统的单位阶跃响应 时域响应与动态性能
本卷考法
  • 由一阶系统达到 95% 的时刻求时间常数 T
本卷实例
  • 关键一步：一阶响应单调无振荡，5% 误差带对应 3 倍时间常数
  • 中间结果：测量时刻与时间常数成固定倍数关系
  • 卡点：别把 63.2% 对应的时刻与 95% 对应的时刻混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 一阶系统只有一个时间常数 T，响应单调无振荡
  • 经过一个 T 达到稳态值的 63.2%，3T 达到 95%，4T 达到 98%
  • 调节时间按误差带取 3T（5%）或 4T（2%）
步骤
  • 把传递函数化为标准形式 1/(Ts+1)
  • 读出时间常数 T
  • 按误差带要求给出调节时间
通用考法
  • 本卷考过由一阶系统达到 95% 的时刻求时间常数 T
  • 求一阶系统的调节时间与上升时间
  • 由响应曲线求时间常数
  • 比较不同时间常数下响应快慢
常见易错
  • 把 63.2% 对应的时刻记成 50% 对应的时刻
  • 增益 K 不为 1 时仍直接读稳态值
公式
误差定义与误差传递函数 稳态误差
本卷考法
  • 由闭环传函写出单位反馈的误差传递函数
本卷实例
  • 关键一步：单位反馈下误差传函等于 1 减闭环传函
  • 中间结果：误差传函分子含一个 s，对阶跃输入无静差
  • 卡点：写误差传函前要先确认系统为一阶稳定系统
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由闭环传函写出单位反馈的误差传递函数
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求水温线性升温输入下的稳态误差
本卷实例
  • 关键一步：把每秒升温率写成斜坡输入，再用终值定理求误差极限
  • 中间结果：稳态误差与升温速率及时间常数成正比
  • 卡点：终值定理只能在闭环稳定时使用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求水温线性升温输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、四阶系统根轨迹与稳定增益范围#

思路
  • 由两对重开环极点定出根轨迹分支、实轴段与渐近线，求分离点和虚轴交点，再由劳斯判据给出稳定增益范围
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画两对重极点的闭环根轨迹
本卷实例
  • 关键一步：由开环极点定分支数，再定渐近线交点与夹角
  • 中间结果：实轴根轨迹段由右侧零极点总数为奇数判定
  • 卡点：两对重极点使渐近线夹角与单极点情形不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画两对重极点的闭环根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹在实轴上的分离点
本卷实例
  • 关键一步：令闭环特征方程对增益求导为零得到分离点方程
  • 中间结果：分离点方程按重根拆开后得到候选根
  • 卡点：候选根要回代根轨迹筛选，不在轨迹上的舍去
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹在实轴上的分离点
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界增益
本卷实例
  • 关键一步：把 s 等于 jω 代入特征方程，分离实部与虚部联立
  • 中间结果：临界增益由劳斯表首列元素为零的等式给出
  • 卡点：负频率要舍去，只保留物理角频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹判断系统稳定所需的增益范围
本卷实例
  • 关键一步：闭环极点全在左半平面才稳定，对应增益介于分离点与虚轴交点之间
  • 中间结果：稳定区间由两个临界增益围成
  • 卡点：要区分稳定区间与增益的全部正实范围
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹判断系统稳定所需的增益范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用

参数稳定域的确定 稳定性分析
本卷考法
  • 由特征方程首列同号确定稳定增益域
本卷实例
  • 关键一步：把特征方程按降幂排列后逐行交叉相减列劳斯表
  • 中间结果：首列各元素含增益，令其同号得到不等式组
  • 卡点：漏掉首列某一元素会放大稳定范围
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由特征方程首列同号确定稳定增益域
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

4四、Bode 图绘制与串联微分环节#

思路
  • 把开环分解为积分与惯性等典型环节，逐段叠加斜率画渐近幅频与相频并判断稳定性；再串联 s+1 相当于附加开环零点，比较前后裕度与稳定性
典型环节的对数频率特性 频域分析
本卷考法
  • 识别开环中的积分与惯性环节并画典型环节特性
本卷实例
  • 关键一步：由时间常数取倒数定出惯性环节的转折频率
  • 中间结果：积分环节给低频负斜率，惯性环节在高频再降斜率
  • 卡点：惯性环节高频渐近线斜率容易误写成两倍
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 比例环节是水平线，积分与微分分别是 -20 与 +20 dB/dec 的斜线
  • 惯性环节转角频率为 1/T，高频段渐近线斜率为 -20 dB/dec
  • 一阶微分环节与惯性环节幅频互为镜像
  • 振荡环节在 ωn 附近出现谐振峰，ξ 越小峰越高
步骤
  • 把传递函数分解为典型环节乘积
  • 逐环节画出对数幅频渐近线与相频曲线
  • 代数相加得到总特性
通用考法
  • 本卷考过识别开环中的积分与惯性环节并画典型环节特性
  • 画出某一典型环节的 Bode 图
  • 由 Bode 图识别环节类型
  • 说明转角频率处的幅值与相角
常见易错
  • 把惯性环节高频渐近线的 -20 写成 -40
  • 振荡环节谐振峰位置误当作 ωn
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 逐段叠加斜率绘制开环对数渐近幅频特性
本卷实例
  • 关键一步：从低频段斜率与高度出发，每过一个转折频率叠加斜率
  • 中间结果：幅频为分段折线，相频由各环节相角相加
  • 卡点：改斜率时要累加而不是替换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过逐段叠加斜率绘制开环对数渐近幅频特性
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角

9九、范德波尔方程的描述函数分析#

思路
  • 先把范德波尔方程中的非线性阻尼项移到等号右边并写成一阶方程组，分离出等效线性部分；再把该非线性项用描述函数 N(A) 表示，与线性部分按自振条件 N(A)G(jω) 等于负一联立，由实部条件定频率、虚部条件定振幅。
非线性系统的特点 非线性系统
本卷考法
  • 区分范德波尔方程中的线性主部与非线性阻尼项
本卷实例
  • 关键一步：把 ẍ+x 看作线性主体，ε(x²-1)ẋ 移到右边作非线性输入
  • 中间结果：等效线性部分的分母出现 s² 与 -εs 项
  • 卡点：取状态变量时非线性项只进一个方程，符号易写反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 不满足叠加原理，输出与初始条件、输入幅值都有关
  • 可能出现自持振荡即极限环
  • 响应可能对初始条件敏感，出现跳跃谐振
  • 线性系统的稳定性概念需要推广为局部稳定性
步骤
  • 确认系统含明显非线性环节
  • 判断该非线性是本质非线性还是可线性化的弱非线性
  • 按非线性分析方法选择描述函数法或相平面法
通用考法
  • 本卷考过区分范德波尔方程中的线性主部与非线性阻尼项
  • 说明非线性系统与线性系统的本质差别
  • 指出同步振荡、跳跃谐振等特有现象
  • 判断某系统应选用哪种分析方法
常见易错
  • 把非线性环节线性化后直接沿用线性理论的全部结论
  • 认为非线性系统一定不稳定
描述函数法基础 非线性系统
本卷考法
  • 把非线性阻尼项等效为描述函数 N(A)
本卷实例
  • 关键一步：对非线性项做一次谐波近似，按 x=A cos(ωt) 代入求 N(A)
  • 中间结果：描述函数只与振幅 A 有关，且可能带虚部
  • 卡点：题目给的 N(A) 含 jω 与 A²，别把 ω 当自变量混进 A
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 描述函数是非线性环节在正弦输入下的等效复放大倍数
  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
步骤
  • 写出非线性环节在正弦输入下的输出表达式
  • 取输出的一次谐波分量求基波幅值与相位
  • 按定义求描述函数 N(A)
  • 与线性部分特性联立判断自振
通用考法
  • 本卷考过把非线性阻尼项等效为描述函数 N(A)
  • 求饱和、死区、继电特性等典型非线性的描述函数
  • 说明描述函数法的适用条件
  • 指出描述函数与频率特性的区别
常见易错
  • 把描述函数当成频率的函数
  • 忽略一次谐波近似带来的误差条件

本卷考法
  • 用描述函数法判断周期运动并求自振振幅与频率
本卷实例

  • 中间结果：实部方程给自振频率，虚部方程给自振振幅

  • 交点处两条曲线的走向关系决定极限环稳定性

  • 由交点处的走向判断自振是否存在且稳定，读出 ω 与 A

  • 未标注 A 的增大方向就判断稳定性
  • 把交点频率当成截止频率
