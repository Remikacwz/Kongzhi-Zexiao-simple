1一、RC 网络求传递函数#

思路
  • 按复阻抗法对中间节点列 KCL 与 KVL，消去电容电流与节点电压，整理得输出电压与输入电压之比
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由无源 RC 网络列节点电流方程求 Uo(s) 与 Ui(s) 之比
本卷实例
  • 关键一步：把电容按复阻抗写成 1/(Cs)，对中间节点列 KCL
  • 中间结果：节点电压先用输入电压与两条电容支路电流表示
  • 卡点：图 1 元件串并联关系需回原卷核对，两电容不能当串联
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由无源 RC 网络列节点电流方程求 Uo(s) 与 Ui(s) 之比
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件

  • 中间结果：消去中间电流后整理成含 R、C 的一阶分式
  • 卡点：输出端取压方向决定正负号，需回原卷核对图

2二、四阶根轨迹与稳定 K 范围#

思路
  • 由开环极点定根轨迹分支、实轴段与渐近线，用分离点和虚轴交点求临界 K，再由劳斯判据给出稳定域
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按绘制法则画四阶系统的概略根轨迹
本卷实例
  • 关键一步：由四个开环极点定分支数、实轴段与渐近线
  • 中间结果：渐近线交点是极点实部平均值，夹角按 n-m 均分
  • 卡点：一对共轭复极点使渐近线与出射角计算易出错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按绘制法则画四阶系统的概略根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 利用题给分离点 -4.6 划分根轨迹实轴段
本卷实例
  • 关键一步：把分离点当作重根代入闭环特征方程求临界 K
  • 中间结果：分离点处特征方程出现重根，可用导数条件校验
  • 卡点：分离点是否在根轨迹上要回代幅值条件确认
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过利用题给分离点 -4.6 划分根轨迹实轴段
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界增益
本卷实例
  • 关键一步：将 s=jω 代入闭环特征方程，分离实部虚部联立
  • 中间结果：虚轴交点由辅助方程给出，临界 K 由劳斯首列定
  • 卡点：负频率要舍去，只保留物理角频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界增益
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由根轨迹判断闭环根落在负实轴时的 K 范围
本卷实例
  • 关键一步：沿实轴根轨迹段找闭环根落在负实轴的 K 区间
  • 中间结果：临界 K 对应分离点或实轴段端点处的重根
  • 卡点：负实轴根区间与全稳定区间不是同一个集合
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由根轨迹判断闭环根落在负实轴时的 K 范围
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 由劳斯判据首列同号确定稳定 K 范围
本卷实例
  • 关键一步：把闭环特征方程按降幂排列后列劳斯表
  • 中间结果：首列各元素含 K，令其全部大于零得不等式组
  • 卡点：漏掉首列某一元素会放大稳定范围
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过由劳斯判据首列同号确定稳定 K 范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错

3三、极坐标图与奈奎斯特判据#

思路
  • 写开环频率特性的幅频与相频，画极坐标图求与负实轴交点，再由奈奎斯特判据与劳斯判据判断稳定性
频率特性的物理意义与求法 频域分析
本卷考法
  • 求开环传递函数的幅频与相频表达式
本卷实例
  • 关键一步：令 s=jω，分别取模与相角得到频率特性
  • 中间结果：低频幅值无穷大，相角由积分与惯性环节叠加
  • 卡点：分母复数取模时别漏掉积分环节的幅值贡献
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 频率特性是传递函数中令 s=jω 得到的复变函数
  • 幅频特性表示各频率正弦输入下的幅值放大倍数
  • 相频特性表示输出相对输入的相位差
  • 频率特性可用幅相曲线、Bode 图或尼柯尔斯图表示
步骤
  • 由传递函数令 s=jω 得到 G(jω)
  • 分别求出幅值 |G(jω)| 与相角 ∠G(jω)
  • 按需要绘制幅相曲线或对数频率特性
通用考法
  • 本卷考过求开环传递函数的幅频与相频表达式
  • 求给定传递函数的幅频与相频表达式
  • 计算某频率处的幅值与相角
  • 说明频率特性的物理含义
常见易错
  • 求幅值时忘记把分母复数取模后再相除
  • 相角累加时漏掉积分环节的 -90°
公式
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据判断稳定性与右半平面极点数
本卷实例
  • 关键一步：先数开环右半平面极点数 P，再数曲线对 -1 的包围
  • 中间结果：闭环右半平面极点数由 Z 等于 P 减 2N 给出
  • 卡点：开环含积分环节时需补画无穷大半径圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据判断稳定性与右半平面极点数
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P

4四、串联滞后校正与相角裕度#

思路
  • 由校正后与校正装置图分别写开环传函，相除得校正前传函；再由剪切频率处相角求校正后相角裕度
开环对数频率特性的绘制 频域分析
本卷考法
  • 由校正前后转折频率写出开环对数幅频特性
本卷实例
  • 关键一步：从低频段斜率和高度出发，逐个转折频率叠加斜率
  • 中间结果：校正后开环比校正前多一个零点与一个极点
  • 卡点：转折频率与时间常数互为倒数，别抄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过由校正前后转折频率写出开环对数幅频特性
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
  • 逐段改斜率时忘记累加而非替换
  • 低频段起始高度没有乘上型别的 -20v dB/dec
公式
稳定裕度 频域分析
本卷考法
  • 由剪切频率处相角计算校正后相角裕度
本卷实例
  • 关键一步：令开环幅值等于一求剪切频率，再算该处相角裕度
  • 中间结果：相角裕度为 180 度加开环在剪切频率处的相角
  • 卡点：剪切频率与相位穿越频率是两个不同频率
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过由剪切频率处相角计算校正后相角裕度
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
