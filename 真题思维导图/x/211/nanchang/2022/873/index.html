南昌大学 873 自动控制原理 2022 年真题思维导图

难度：中等　全卷 8 题，覆盖多回路结构图梅森公式、输入下的稳态误差、根轨迹与主导极点求调节时间、极坐标图与奈奎斯特判据、离散系统稳定性与采样响应、数字控制器 D(z) 设计、执行机构饱和影响、由 Bode 图反求校正环节。第一大题头与第二大题头印 15 分，第三、四大题只印小问分，第五至八题未印分值。

1一、结构图求传递函数 C(s)/R(s)15 分#

思路
  • 用梅森增益公式列出全部独立回路、互不接触回路对与各前向通路，求 C(s) 与 R(s) 之比
梅森增益公式与信号流图 传递函数
本卷考法
  • 列回路增益、不接触回路组与前向通路求 C(s)/R(s)
本卷实例
  • 关键一步：先找齐三条回路，再找互相不接触的回路对
  • 中间结果：特征式含回路对乘积项，分子是两条前向通路贡献
  • 卡点：回路是否有公共节点决定是否计入不接触项
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过列回路增益、不接触回路组与前向通路求 C(s)/R(s)
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 用梅森公式求多回路系统的闭环传递函数
本卷实例
  • 关键一步：按回路与前向通路逐项写出特征式与余子式
  • 中间结果：分子为各前向通路乘对应余子式后求和
  • 卡点：结构图未读图，回路连接与交叉关系需回原卷核对
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过用梅森公式求多回路系统的闭环传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理
比较点与引出点的移动 结构图与方框图
本卷考法
  • 按比较点与引出点移动规则化简交叉结构
本卷实例
  • 关键一步：把交叉处引出点前移或后移使回路解耦
  • 中间结果：移动后对应支路增益作倒数补偿
  • 卡点：移动方向与乘除关系搞反会导致结果差一个环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 移动的判据：移动前后各支路变量关系必须保持不变
  • 比较点前移要除以所跨环节，后移要乘以所跨环节
  • 引出点前移要乘以所跨环节，后移要除以所跨环节
步骤
  • 确定要移动的点和跨越的环节
  • 按“前移用除、后移用乘”的规则补上等效环节
  • 检查移动后与原结构是否等价
通用考法
  • 本卷考过按比较点与引出点移动规则化简交叉结构
  • 化简含交叉比较点或引出点的结构图
  • 判断某次移动是否正确
常见易错
  • 移动方向与乘除关系搞反
  • 引出点与比较点的移动规则混用

2二、输入下的稳态误差15 分#

思路
  • 由结构图写误差传递函数，先用劳斯判据判稳，再用终值定理求 1+t 与 t^2 输入下的稳态误差
误差定义与误差传递函数 稳态误差
本卷考法
  • 由结构图写误差传递函数 E(s)/R(s)
本卷实例
  • 关键一步：在误差点断开，按前向通路与回路列梅森公式
  • 中间结果：误差传函分母为 1 加开环传递函数
  • 卡点：非单位反馈时误差定义与偏差定义差一个反馈环节
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 误差有两种定义：输入端 E(s)=R(s)-C(s) 与 E(s)=R(s)-B(s)，须看清题意
  • 误差传递函数由结构决定
  • 单位反馈时两种定义等价
步骤
  • 按题意确定误差取在输入端还是反馈端
  • 由结构图写出误差传递函数
  • 乘输入后取 s→0 的极限
通用考法
  • 本卷考过由结构图写误差传递函数 E(s)/R(s)
  • 写出误差传递函数
  • 说明不同误差定义对结果的影响
常见易错
  • 非单位反馈时两种误差定义混用导致结果差一个 H(s)
  • 忘记先判断系统是否稳定
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求 1+t 与 t^2 输入下的稳态误差
本卷实例
  • 关键一步：把输入拆成阶跃与斜坡或加速度分量分别求误差
  • 中间结果：误差系数决定各输入分量的稳态贡献
  • 卡点：用终值定理前必须先判断系统稳定
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求 1+t 与 t^2 输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式
公式
劳斯判据 稳定性分析
本卷考法
  • 对误差传函分母作劳斯判据判断稳定性
本卷实例
  • 关键一步：整理闭环特征多项式后列劳斯表
  • 中间结果：劳斯表首列全部为正则闭环稳定
  • 卡点：三阶多项式缺项时先补零再列表
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过对误差传函分母作劳斯判据判断稳定性
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
系统型别与静态误差系数 稳态误差
本卷考法
  • 由系统型别判断各静态误差系数
本卷实例
  • 关键一步：数开环传函中积分环节个数定系统型别
  • 中间结果：Ⅰ型系统位置误差系数无穷、加速度误差系数为零
  • 卡点：别把开环增益直接当成速度误差系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤
  • 把开环传递函数写成分式，数出 s 的幂次即型别
  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过由系统型别判断各静态误差系数
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错

3三、根轨迹与主导极点求调节时间#

思路
  • 画三阶系统根轨迹并求临界 K，由已知一个闭环极点用综合除法求其余极点，再用主导极点近似二阶求调节时间
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则画三阶系统根轨迹并求分离点
本卷实例
  • 关键一步：由三个开环极点定分支、实轴段与三条渐近线
  • 中间结果：渐近线交点与夹角由极点和个数算出
  • 卡点：分离点方程三个根中只有落在根轨迹上的才保留
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则画三阶系统根轨迹并求分离点
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点及临界 K
本卷实例
  • 关键一步：把 s=jω 代入特征方程或令劳斯首列为零
  • 中间结果：临界 K 与虚轴交点频率由辅助方程给出
  • 卡点：K 等于零对应的原点交点要与临界交点区分
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点及临界 K
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由已知一个闭环极点反求其余两个闭环极点
本卷实例
  • 关键一步：把已知根从闭环特征多项式中除出二次因式
  • 中间结果：二次因式给出一对共轭复数极点
  • 卡点：已知根要代回特征方程核对 K 值是否一致
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由已知一个闭环极点反求其余两个闭环极点
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
高阶系统的降阶与主导极点 时域响应与动态性能
本卷考法
  • 利用主导极点把三阶系统降为二阶系统
本卷实例
  • 关键一步：比较闭环极点实部大小，保留靠近虚轴的一对共轭极点
  • 中间结果：远极点对应时间常数很小，可略去其暂态分量
  • 卡点：降阶近似要求主导极点附近没有开环零点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 离虚轴最近的极点起主导作用，其余极点对应快速衰减分量
  • 闭环零点会增大超调、缩短峰值时间
  • 极点实部相差 5 倍以上时可按主导极点降阶
步骤
  • 求出全部闭环极点并按距虚轴远近排序
  • 用主导极点对近似为二阶系统
  • 用零点修正式修正超调量与峰值时间
通用考法
  • 本卷考过利用主导极点把三阶系统降为二阶系统
  • 把高阶系统近似为二阶系统并估算性能指标
  • 判断附加闭环零点对超调量的影响
  • 说明某极点能否忽略的理由
常见易错
  • 忽略零点对超调量的放大作用
  • 只看极点距离而不管该极点的留数大小
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由近似二阶系统参数计算调节时间
本卷实例
  • 关键一步：由保留极点写出等效阻尼比与自然频率
  • 中间结果：调节时间按误差带取 3 或 4 除以阻尼比乘自然频率
  • 卡点：题给 -3.63 是远离虚轴的极点，不是主导极点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由近似二阶系统参数计算调节时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

4四、极坐标图与奈奎斯特判据#

思路
  • 求开环频率特性与奈奎斯特曲线，由与负实轴交点确定包围情况，判稳并指出右半平面闭环极点数
频率特性的物理意义与求法 频域分析
本卷考法
  • 求开环频率特性的幅频相频并画奈奎斯特图
本卷实例
  • 关键一步：令 s=jω，写出幅值和相角的表达式
  • 中间结果：曲线起点在低频无穷远，终点幅值趋于零
  • 卡点：与负实轴交点要令相角等于负 180 度求解

  • 极限环的稳定性可由相轨迹收敛或发散判断
  • 减小非线性影响可用加大线性部分增益或引入校正
  • 用描述函数或相平面结果指导参数选择
步骤
  • 判断系统是否存在极限环并确定其稳定性
  • 分析非线性环节参数对自振幅值频率的影响
  • 通过调整线性部分增益或加入校正削弱自振
  • 重新分析确认自振消除或幅值达标
通用考法
  • 本卷考过比较图 A 与图 B 的结构差异并分析改善方向
  • 提出消除自振的工程措施
  • 分析增益变化对极限环幅值的影响
  • 比较不同方案对稳定性与动态性能的利弊
常见易错
  • 仅调整增益而不检查是否引入新的自振点
  • 把不稳定极限环误判为可观测的自振

8八、由 Bode 图反求校正环节与裕量#

思路
  • 由校正前后开环对数幅频特性相减得校正环节特性并反求传函，在各自剪切频率处算相角裕度，再比较性能变化
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由校正前后 Bode 图相减反求校正环节传递函数
本卷实例
  • 关键一步：由转折频率与高频段斜率写出校正前后传函形式
  • 中间结果：校正环节等于校正后传函除以校正前传函
  • 卡点：低频段高度要换算成开环增益，不能直接读分贝值
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由校正前后 Bode 图相减反求校正环节传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节

开环对数频率特性的绘制 频域分析
本卷考法
  • 画校正前后的开环对数幅频特性
本卷实例
  • 关键一步：从低频段斜率与高度出发逐段叠加斜率
  • 中间结果：校正后低频段多一个积分环节，斜率降低
  • 卡点：校正前为 0 型、校正后为 Ⅰ型，低频段不同
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤

稳定裕度 频域分析
本卷考法
  • 求校正前后的相角裕量并比较
本卷实例
  • 关键一步：在各自零分贝频率处取相角再加 180 度
  • 中间结果：校正前后剪切频率不同，需分别计算相角裕度
  • 卡点：剪切频率与转折频率不要混用
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg
  • 分别代入公式求相角裕度与幅值裕度
  • 由裕度符号判断稳定性
通用考法
  • 本卷考过求校正前后的相角裕量并比较
  • 求系统的相角裕度与幅值裕度
  • 由裕度要求反求开环增益
  • 分析增益变化对裕度的影响
常见易错
  • 把 ωc 与 ωg 两个频率用反
  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

本卷考法

本卷实例

  • 中间结果：0 型变 Ⅰ型后阶跃输入由有静差变无静差
  • 卡点：型别提高会降低快速性，性能变化要两面说明
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 型别 v 由开环传递函数中积分环节的个数决定
  • 0 型有位置误差、Ⅰ型有速度误差、Ⅱ型有加速度误差
  • 静态误差系数只与开环传递函数有关
步骤

  • 按型别选择对应的静态误差系数公式
  • 代入求值
通用考法
  • 本卷考过说明校正使系统型别提高对稳态误差的影响
  • 判断系统型别
  • 求静态位置、速度、加速度误差系数
  • 分析增加积分环节对精度的影响
常见易错
  • 把开环增益与静态误差系数混为一谈
  • 数错积分环节个数导致型别判错
