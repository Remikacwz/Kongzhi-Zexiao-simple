1一、二阶系统参数与斜坡误差10 分#

思路
  • 由结构图写闭环传函并化为标准二阶形式，联立阻尼比与单位斜坡稳态误差两个条件求参数
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函对比标准二阶形式求阻尼比与自然频率
本卷实例
  • 关键一步：把闭环传函整理成标准二阶形式，与给定阻尼比对应
  • 中间结果：自然频率与阻尼比均用待定参数k、τ表达
  • 卡点：结构图由插图给出，闭环传函需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函对比标准二阶形式求阻尼比与自然频率
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 由单位斜坡稳态误差要求反求系统参数
本卷实例
  • 关键一步：写误差传函并用终值定理求斜坡误差极限
  • 中间结果：误差极限化为含k与τ的代数方程并与阻尼比条件联立
  • 卡点：未先判稳就用终值定理
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过由单位斜坡稳态误差要求反求系统参数
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

2二、结构图求传递函数#

思路
  • 由结构图画信号流图，数清前向通路与单独回路后用梅森增益公式求 C(s)/R(s)
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求结构图的闭环传递函数
本卷实例
  • 关键一步：把比较点与引出点画成信号流图节点
  • 中间结果：数清前向通路与单独回路后再写特征式
  • 卡点：结构图连线与回路构成需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求结构图的闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简后再求传递函数
本卷实例
  • 关键一步：先化简局部反馈内环再合并串并联支路
  • 中间结果：内环等效环节作为外环的前向通路
  • 卡点：内外环信号交叉时化简顺序易错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简后再求传递函数
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

3三、由阶跃响应辨识二阶系统#

思路
  • 从单位阶跃响应曲线读取超调量与峰值时间，反求阻尼比和自然频率后写开环传函
由响应曲线反求传递函数 传递函数
本卷考法
  • 由单位阶跃响应曲线反求开环传递函数
本卷实例
  • 关键一步：从响应曲线读出超调量与峰值时间
  • 中间结果：由两个特征量反求阻尼比与自然频率
  • 卡点：响应曲线由插图给出，读数需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由单位阶跃响应曲线反求开环传递函数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 由超调量与峰值时间反求二阶系统参数
本卷实例
  • 关键一步：由超调量公式反解阻尼比
  • 中间结果：峰值时间与自然频率满足含阻尼比的根式关系
  • 卡点：超调量公式漏乘百分之百导致阻尼比偏大
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过由超调量与峰值时间反求二阶系统参数
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

4四、参数a的广义根轨迹#

思路
  • 把变参数a整理到等效开环分子，按参数根轨迹法则作图，再求分离点与虚轴交点
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以参数a为变量绘制广义根轨迹
本卷实例
  • 关键一步：把含a的项整理到分子形成等效开环
  • 中间结果：等效开环为含积分环节与重极点的形式
  • 卡点：参数未完整提到分子位置就套常规根轨迹法则
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以参数a为变量绘制广义根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
根轨迹的绘制法则 根轨迹法
本卷考法
  • 按法则求分支数、实轴段与渐近线
本卷实例
  • 关键一步：由等效开环零极点定分支与渐近线夹角
  • 中间结果：实轴段由右侧零极点个数奇偶判定
  • 卡点：重极点处分支数与出射方向易判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过按法则求分支数、实轴段与渐近线
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求参数根轨迹的分离点坐标
本卷实例
  • 关键一步：对等效开环用分离点方程求解
  • 中间结果：解得候选根后按是否在根轨迹上取舍
  • 卡点：求出根后不筛选直接保留全部解
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求参数根轨迹的分离点坐标
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式
公式
与虚轴的交点及临界参数 根轨迹法
本卷考法
  • 求根轨迹与虚轴交点对应的参数a
本卷实例
  • 关键一步：令s等于jω代入闭环特征方程分离实虚部
  • 中间结果：由虚部定交点频率、由实部定临界参数
  • 卡点：只代一组交点漏掉共轭另一组
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 根轨迹与虚轴的交点对应系统临界稳定
  • 可用劳斯判据令首列为零，或令 s=jω 代入特征方程求解
  • 交点处的 K 是使系统稳定的临界增益
步骤
  • 把 s=jω 代入闭环特征方程
  • 令实部与虚部分别为零，得到两个方程
  • 联立解出 ω 与 K
  • 结合实轴段信息确定根轨迹穿越方向
通用考法
  • 本卷考过求根轨迹与虚轴交点对应的参数a
  • 求根轨迹与虚轴的交点及临界增益
  • 确定系统稳定时 K 的取值范围
  • 判断根轨迹穿越虚轴的方向
常见易错
  • 只代一个 ω 就下结论，漏掉另一组交点
  • 得到 K 后没有回到原题核对参数定义

5五、由Bode图反求传函与判稳#

思路
  • 由渐近幅频特性低频段高度与各转折频率写传函，再算相角裕度判断闭环稳定性
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由开环对数幅频特性反求传递函数
本卷实例
  • 关键一步：由低频段高度定增益、由斜率变化定环节
  • 中间结果：传函由一阶微分与多个一阶惯性环节串联
  • 卡点：渐近线转折频率需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由开环对数幅频特性反求传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 读开环对数渐近幅频特性判断型别与增益
