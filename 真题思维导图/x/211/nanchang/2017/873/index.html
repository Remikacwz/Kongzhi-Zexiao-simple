1一、结构图求传递函数#

思路
  • 由结构图画信号流图，数清前向通路与单独回路后用梅森增益公式求Y(s)/R(s)
梅森增益公式与信号流图 传递函数
本卷考法
  • 用梅森增益公式求结构图的闭环传递函数
本卷实例
  • 关键一步：把比较点与引出点画成信号流图节点
  • 中间结果：题中系统有两条前向通路与四个单独闭合回路
  • 卡点：回路与不接触回路数错会使特征式漏项
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过用梅森增益公式求结构图的闭环传递函数
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简后再求传函
本卷实例
  • 关键一步：先化简局部反馈内环再合并串并联支路
  • 中间结果：内环等效环节作为外环的前向通路
  • 卡点：内外环信号交叉时化简顺序容易弄反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简后再求传函
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

2二、劳斯判据与组合输入稳态误差#

思路
  • 由结构图写闭环特征式，列劳斯表求τ的稳定范围，再按1加t加t²/2的三项分别求稳态误差并判断τ增大时误差走向
劳斯判据 稳定性分析
本卷考法
  • 用劳斯判据求使系统稳定的参数τ范围
本卷实例
  • 关键一步：由闭环特征式列劳斯表并令首列各元大于零
  • 中间结果：首列条件化为关于τ的不等式组
  • 卡点：漏掉某个首列元素的不等式导致结论不全
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 特征方程各项系数全为正只是必要条件，不充分
  • 劳斯表首列元素全部同号 ⇔ 系统稳定
  • 首列符号变化次数等于右半平面闭环极点数
  • 首列出现 0 时需用 ε 法或乘辅助多项式处理
步骤
  • 写出闭环特征方程并整理成降幂排列
  • 若某次幂系数缺项，该项补零
  • 列劳斯表：前两行为系数，之后各行按交叉相减
  • 检查首列符号：全同号则稳定，有变号则数出个数
通用考法
  • 本卷考过用劳斯判据求使系统稳定的参数τ范围
  • 判断给定系统的稳定性
  • 指出右半平面闭环极点的个数
  • 求使系统稳定的参数范围
常见易错
  • 系数有缺项时不补零，直接套用判据
  • 首列出现 0 后仍按常规继续算，未用 ε 法
公式
参数稳定域的确定 稳定性分析
本卷考法
  • 确定临界稳定状态下的τ值范围
本卷实例
  • 关键一步：令首列中可能变号的元素取零求临界值
  • 中间结果：临界τ由首列某个含τ元素为零给出
  • 卡点：把临界稳定点误当成稳定区间的内点
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳定条件是一组关于参数的不等式
  • 区间端点通常对应临界稳定，即根落在虚轴上
  • 稳定域是不等式组的交集
步骤
  • 由劳斯表首列各元素大于零列出不等式组
  • 逐个解不等式并取交集
  • 检查端点是否为临界稳定
通用考法
  • 本卷考过确定临界稳定状态下的τ值范围
  • 求使系统稳定的参数上界或下界
  • 判断某参数取值是否满足稳定要求
  • 比较不同参数对稳定域大小的影响
常见易错
  • 只列出部分首列元素的不等式，漏掉某个约束
  • 取交集时把端点是否包含搞错
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 对1加t加t²/2的组合输入分别求三项稳态误差
本卷实例
  • 关键一步：把组合输入拆成阶跃、斜坡、抛物线三项分别求
  • 中间结果：总误差由三项误差按线性叠加得到
  • 卡点：组合输入漏掉某一分量会使误差结论偏小
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过对1加t加t²/2的组合输入分别求三项稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

3三、二阶系统动态性能指标#

思路
  • 将给定闭环传函化为标准二阶形式求ωn，再套超调量、调节时间与峰值时间公式比较两组参数
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由给定闭环传函对照标准二阶形式求ωn与ξ
本卷实例
  • 关键一步：把闭环传函分母化为标准二阶系数形式
  • 中间结果：由s一次项系数与常数项解出ωn
  • 卡点：未按s²项系数归一化就直接读ωn
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由给定闭环传函对照标准二阶形式求ωn与ξ
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
欠阻尼动态性能指标 时域响应与动态性能
本卷考法
  • 分别求两组ξ与T下超调量、调节时间与峰值时间
本卷实例
  • 关键一步：先由T与ξ算ωn再逐项套性能指标公式
  • 中间结果：三个指标只由ξ与ωn两个量决定
  • 卡点：调节时间两种误差带系数的含义记混
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 超调量只由 ξ 决定，与 ωn 无关
  • 峰值时间、上升时间、调节时间都与 ωn 成反比
  • 调节时间与 ξωn 的乘积成反比，ξωn 是衰减因子
  • 振荡次数与 ξ 直接相关
步骤
  • 由标准形式读出 ξ 与 ωn
  • 用超调量公式先求 ξ
  • 依次代入峰值时间、调节时间、上升时间公式
  • 必要时计算振荡次数
通用考法
  • 本卷考过分别求两组ξ与T下超调量、调节时间与峰值时间
  • 给定 ξ 与 ωn 求全部动态性能指标
  • 由超调量要求确定 ξ 的取值范围
  • 分析 ωn 变化时各指标如何变化
常见易错
  • 把两种误差带的调节时间系数搞混
  • 峰值时间与上升时间混用
  • 超调量公式中漏乘 100%

4四、根轨迹与劳斯判据互证#

思路
  • 对G(s)H(s)等于K(s+1)除以s(s-3)按180度根轨迹法则作图，由虚轴交点求稳定K范围，再用劳斯表互证
根轨迹的绘制法则 根轨迹法
本卷考法
  • 绘制含右半平面开环极点的180度根轨迹
本卷实例
  • 关键一步：先标零极点并判断实轴上的根轨迹段
  • 中间结果：渐近线交点由零极点坐标均值确定
  • 卡点：实轴段判据里右侧零极点个数算错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 起于开环极点、终于开环零点（无穷远零点），分支数等于极点数 n
  • 实轴上某段右侧的零极点总数为奇数时，该段属于根轨迹
  • 渐近线条数为 n-m，交点在实轴上，与实轴夹角等分 360°
  • 根轨迹关于实轴对称
步骤
  • 标出全部开环零极点并判断实轴上的根轨迹段
  • 计算渐近线交点与夹角
  • 求出分离点、出射角、与虚轴交点
  • 按对称性连接各段并标出对应 K 值
通用考法
  • 本卷考过绘制含右半平面开环极点的180度根轨迹
  • 按法则绘制根轨迹草图
  • 指出渐近线条数与夹角
  • 判断某段实轴是否属于根轨迹
常见易错
  • 实轴段判据中的零极点个数算错
  • 渐近线夹角公式中的 2k+1 写成 2k
公式
分离点与会合点 根轨迹法
本卷考法
  • 求根轨迹分离点并舍去无效根
本卷实例
  • 关键一步：对根轨迹方程用分离点条件求候选根
  • 中间结果：两个候选根只有一个真正落在根轨迹上
  • 卡点：求出根后不筛选直接把全部解保留
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 分离点是根轨迹离开实轴或相汇的点，对应特征方程的重根
  • 分离点必满足 dK/ds=0
  • 用试探法求解代数方程时要注意舍去不在根轨迹上的根
步骤
  • 由幅值条件解出 K 关于 s 的表达式
  • 令 dK/ds=0 得分离点方程
  • 解方程并用实轴段判据筛选
  • 代回求分离点处的 K 值
通用考法
  • 本卷考过求根轨迹分离点并舍去无效根
  • 求根轨迹的分离点坐标
  • 确定分离点处的临界增益
  • 判断解的取舍
常见易错
  • 求出方程根后不筛选，保留了不在根轨迹上的解
  • 用 dK/ds=0 却未化成 K 的显式表达式

5五、奈奎斯特判据与相角裕度#

思路
  • 画K除以s(s+1)的奈氏曲线判稳，由2t加2输入误差要求定K，再求截止频率与相角裕度
奈奎斯特判据 稳定性分析
本卷考法
  • 用奈奎斯特判据判断闭环稳定性
本卷实例
  • 关键一步：先数开环右半平面极点数P再画幅相曲线
  • 中间结果：由包围圈数按Z等于P减2N判断闭环极点
  • 卡点：含积分环节时未补画无穷大半径圆弧
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环稳定 ⇔ Z=N+P，其中 Z 为右半平面闭环极点数
  • P 为开环右半平面极点数，须先数清楚
  • N 为开环幅相曲线绕 (-1,j0) 点的净包围圈数
  • 逆时针包围为正，顺时针为负
步骤
  • 先求开环极点，数出右半平面个数 P
  • 绘制开环幅相特性曲线（或利用 Bode 图判稳）
  • 数出曲线对 (-1,j0) 点的包围圈数 N
  • 由 Z=N+P 判断闭环稳定性
通用考法
  • 本卷考过用奈奎斯特判据判断闭环稳定性
  • 由开环幅相曲线判断闭环稳定性
  • 求使闭环稳定的开环增益范围
  • 判断补画虚轴绕行后曲线的包围情况
常见易错
  • 开环含有积分环节时未补画无穷大半径圆弧
  • 把包围圈数的正负号定义搞反
  • 没有先数开环右半平面极点数 P
公式
典型输入下的稳态误差计算 稳态误差
本卷考法

稳定裕度 频域分析
本卷考法
  • 求满足误差要求后的相角裕度γ
本卷实例
  • 关键一步：在幅值等于1处求截止频率再累加相角
  • 中间结果：γ由180度加开环在截止频率处相角给出
  • 卡点：截止频率与相位穿越频率两个频率用反
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 相角裕度 γ 在幅值穿越频率 ωc 处定义，γ=180°+∠G(jωc)
  • 幅值裕度 Kg 在相位穿越频率 ωg 处定义，单位可为分贝
  • γ>0 且 Kg>1 时闭环稳定（最小相位系统）
  • γ 主要影响超调，ωc 主要影响响应速度
步骤
  • 由幅频特性求 |G|=1 对应的穿越频率 ωc
  • 由相频特性求 ∠G=-180° 对应的频率 ωg

  • 由裕度符号判断稳定性

  • 求系统的相角裕度与幅值裕度

  • 幅值裕度取倒数未取，导致结论反了
  • 非最小相位系统仍用同一判据

思路

描述函数法基础 非线性系统
本卷考法
  • 写出带死区继电特性的描述函数N(A)
本卷实例
  • 关键一步：按输入输出分段关系积一次谐波系数
  • 中间结果：N(A)为振幅A的实函数且含根式因子

考点详解（要点 / 步骤 / 公式 / 考法 / 易错）

  • 描述函数是输入幅值的函数，与频率无关
  • 只适用于非线性环节输入近似为正弦、线性部分具有低通滤波特性的系统
  • 描述函数法用来判断自振的存在与参数
