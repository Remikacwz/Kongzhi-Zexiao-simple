1一、电网络求电压传递函数#

思路
  • 用复阻抗法对电网络列回路或节点方程，消去中间变量得Uc(s)/Ur(s)
由电路或机械系统求传递函数 传递函数
本卷考法
  • 由电网络用复阻抗法求输出电压与输入电压之比
本卷实例
  • 关键一步：写出电容与电感的复阻抗并列回路方程
  • 中间结果：消去中间电流后整理成传函
  • 卡点：把电容阻抗误写成Cs
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 电路用复阻抗法：电阻 R、电感 Ls、电容 1/(Cs)
  • 机械平移系统三种元件：质量 m、阻尼 f、弹簧 k
  • 先列物理定律方程，再消去中间变量
  • 列方程的依据：KCL/KVL 或牛顿第二定律
步骤
  • 画出复阻抗等效电路或受力分析图
  • 按 KVL/KCL 或牛顿第二定律列出微分方程组
  • 消去中间变量，得到只含输入输出的方程
  • 取拉氏变换并整理成 C(s)/R(s)
通用考法
  • 本卷考过由电网络用复阻抗法求输出电压与输入电压之比
  • 给定 RLC 网络求 U_o(s)/U_i(s)
  • 弹簧-质量-阻尼系统求位移对力的传递函数
  • 含运算放大器的有源网络求传递函数
常见易错
  • 复阻抗法把电容阻抗误写成 Cs
  • 机械系统阻尼力与弹簧力的正负方向取反
  • 运放电路忘记使用虚短与虚断条件
公式
电路网络与有源网络建模 建模与机电系统
本卷考法
  • 由含多储能元件的网络建立传函模型
本卷实例
  • 关键一步：按基尔霍夫定律列方程并化成s域形式
  • 中间结果：合并同类项后写成两项之比
  • 卡点：列方程时漏掉某个储能元件的电压
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 无源网络用复阻抗分压或节点法
  • 含运放的网络使用虚短与虚断两个条件
  • 有源滤波器与 RC 网络是常见载体
步骤
  • 画出复阻抗等效电路
  • 用分压公式或节点电流方程列写关系
  • 整理为输出与输入的比值
通用考法
  • 本卷考过由含多储能元件的网络建立传函模型
  • RC 网络或有源滤波器求传递函数
  • 求运算电路的输出表达式
常见易错
  • 含运放时忽略虚短虚断导致方程数不足
  • 把反相输入的负号漏掉

2二、系统结构图求闭环传递函数#

思路
  • 由结构图化简或用梅森增益公式求C(s)/R(s)
梅森增益公式与信号流图 传递函数
本卷考法
  • 由结构图列前向通路与回路求闭环传函
本卷实例
  • 关键一步：先画信号流图并标出全部单独回路
  • 中间结果：用梅森增益公式代入各增益求和
  • 卡点：余子式里没有剔除与通路接触的回路
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 信号流图适合处理多回路、比较点复杂系统
  • 特征式 Δ=1-ΣL+ΣLL-ΣLLL+…
  • 每条前向通路的余子式要剔除与它接触的回路
  • 不接触回路才会计入高阶乘积项
步骤
  • 由结构图改画信号流图，标出各节点
  • 找出全部单独回路，求特征式 Δ
  • 找出全部前向通路 P_k
  • 对每条通路求余子式 Δ_k
  • 代入公式求总传输
通用考法
  • 本卷考过由结构图列前向通路与回路求闭环传函
  • 由信号流图求 C(s)/R(s)
  • 结构图先用梅森公式化简再作性能分析
  • 判断某条回路是否与给定前向通路接触
常见易错
  • 不接触回路找漏或重复计数
  • 余子式中未剔除与通路接触的回路
  • 把前向通路的增益写成了回路增益
公式
多回路系统的逐层化简 结构图与方框图
本卷考法
  • 多回路结构图逐层化简
本卷实例
  • 关键一步：从最内环开始合并再逐步向外化简
  • 中间结果：每次合并把内环等效为单个环节
  • 卡点：比较点与引出点的移动规则混用
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 从最内层回路开始，逐层向外化简
  • 每个内环先化成一个等效环节，再参与外层的串并联
  • 化简顺序错误会导致式子繁琐但仍可得到正确结果
步骤
  • 标出内环并求其闭环传递函数
  • 把内环替换为等效环节
  • 对新的结构图重复上述步骤，直到单回路
  • 最后求整个系统的闭环传递函数
通用考法
  • 本卷考过多回路结构图逐层化简
  • 三环及以上系统求闭环传递函数
  • 含局部反馈的系统化简
常见易错
  • 化简内环时把外环的信号当成常数处理

3三、由阶跃输出求二阶参数与稳态误差#

思路
  • 由图2阶跃输出读超调与峰值时间反求阻尼比与自然频率，再由图1结构图定K与a，最后求组合输入的稳态误差
由响应曲线反求传递函数 传递函数
本卷考法
  • 由阶跃响应曲线读性能指标并反求传函参数
本卷实例
  • 关键一步：由超调量求阻尼比、由峰值时间求自然频率
  • 中间结果：把参数回代结构图传函得待定系数
  • 卡点：未判断系统阶数就直接套二阶公式
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态值决定增益 K
  • 超调量只由阻尼比 ξ 决定
  • 峰值时间与振荡频率共同确定 ωn
  • 时间常数由响应达到稳态值 63.2% 的时刻给出
步骤
  • 从曲线上读出稳态值、超调量、峰值时间或时间常数
  • 判断系统是一阶还是二阶（看有无振荡）
  • 由超调量反求 ξ，再由峰值时间反求 ωn
  • 写出标准形式并补上增益
通用考法
  • 本卷考过由阶跃响应曲线读性能指标并反求传函参数
  • 由实验阶跃响应曲线求传递函数
  • 由给出的性能指标反求参数
常见易错
  • 未判断系统阶数就直接套用二阶公式
  • 把稳态值当成了增益而漏掉输入幅值
公式
二阶系统标准形式与阻尼比 时域响应与动态性能
本卷考法
  • 由闭环传函写标准二阶形式确定参数
本卷实例
  • 关键一步：分母系数与2ζωn、ωn平方对应相等
  • 中间结果：由等式解出K与a
  • 卡点：归一化时漏除s平方项系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 标准形式由自然频率 ωn 与阻尼比 ξ 两个参数确定
  • ξ>1 过阻尼、ξ=1 临界阻尼、0<ξ<1 欠阻尼、ξ=0 无阻尼
  • 闭环极点位置只由 ξωn 与 ωn√(1-ξ²) 决定
  • β=arccos ξ 是极点与负实轴的夹角
步骤
  • 把闭环传递函数化成标准二阶形式
  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法
  • 本卷考过由闭环传函写标准二阶形式确定参数
  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼
  • 在 s 平面上标出闭环极点的位置
常见易错
  • 化为标准形式时忘记把 s² 项系数归一化
  • 把开环增益误当成闭环传递函数的系数
公式
典型输入下的稳态误差计算 稳态误差
本卷考法
  • 求单位阶跃加斜坡组合输入下的稳态误差
本卷实例
  • 关键一步：先判稳再用静态误差系数叠加各分量
  • 中间结果：由型别判断斜坡分量的误差是否为有限值
  • 卡点：未判稳就直接套静态误差系数
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 稳态误差由系统型别与输入类型共同决定
  • 0 型对阶跃有差、Ⅰ型对斜坡有差、Ⅱ型对加速度有差
  • 低型别系统对高阶输入的误差为无穷大
步骤
  • 判断系统型别并联立稳定性检查
  • 写出输入信号的拉氏变换
  • 用终值定理求 e_ss，或直接查表
  • 必要时按叠加原理分别计算各分量
通用考法
  • 本卷考过求单位阶跃加斜坡组合输入下的稳态误差
  • 求给定输入下的稳态误差
  • 由稳态误差要求反求开环增益
  • 比较不同型别系统的跟踪能力
常见易错
  • 未判稳就使用终值定理
  • 输入为组合信号时漏掉某一分量
  • Ⅰ型系统求阶跃误差时误代入速度误差公式

4四、参数根轨迹与临界阻尼闭环传函#

思路
  • 以K为参数画闭环根轨迹，再由ζ等于1的临界阻尼条件求闭环传递函数
广义根轨迹与参数根轨迹 根轨迹法
本卷考法
  • 以增益K为参数绘制闭环根轨迹
本卷实例
  • 关键一步：把特征方程整理成含K项与不含K项之比的形式
  • 中间结果：按根轨迹法则确定各段形状与走向
  • 卡点：参数未完整提到分子位置
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 可变参数不是开环增益时称为参数根轨迹
  • 方法是用等效开环传递函数把参数提到标准位置
  • 正反馈系统或零度根轨迹的相角条件是 0°+360°l
步骤
  • 把特征方程整理成 1+αG*(s)=0 的形式
  • 把 α 以外部分视为等效开环传递函数
  • 按常规根轨迹法则绘制
  • 注意相角条件是否变成 0°
通用考法
  • 本卷考过以增益K为参数绘制闭环根轨迹
  • 以时间常数或其他参数为变量绘制根轨迹
  • 绘制正反馈系统的零度根轨迹
  • 比较零度与 180 度根轨迹的差别
常见易错
  • 整理时没有把参数完整地提到分子位置
  • 零度根轨迹仍沿用 180° 相角条件
公式
由根轨迹分析性能与确定参数 根轨迹法
本卷考法
  • 由ζ等于1的条件确定闭环极点位置
本卷实例
  • 关键一步：临界阻尼对应特征方程有重实根
  • 中间结果：由判别式为零或根与系数关系求根
  • 卡点：把临界阻尼对应的重根位置判错
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 闭环极点位置直接决定 ξ、ωn 与动态指标
  • 等阻尼线是从原点出发的射线，等 ωn 线是以原点为心的圆
  • 给定阻尼比要求时，极点落在等阻尼线上
  • 增益增大一般使系统响应加快但振荡加剧
步骤
  • 在 s 平面上画出等阻尼线或等 ωn 圆
  • 求其与根轨迹的交点
  • 由幅值条件求出交点对应的参数
  • 由极点位置估算动态性能
通用考法
  • 本卷考过由ζ等于1的条件确定闭环极点位置
  • 求满足给定阻尼比的参数值
  • 由闭环极点位置估算超调量与调节时间
  • 分析提高增益对性能的影响
常见易错
  • 把等阻尼线画成了垂直线
  • 由极点位置估指标时忽略零点的作用
公式
二阶系统标准形式与阻尼比 时域响应与动态性能

步骤

  • 比对系数求出 ωn 与 ξ
  • 写出闭环极点表达式
  • 按 ξ 的取值判断响应类型
通用考法

  • 由闭环传递函数求 ωn 与 ξ
  • 判断响应是过阻尼还是欠阻尼

5五、由Bode图反求传函并算裕度#

思路
  • 由对数幅频渐近线斜率变化识别转折频率并写出传函，再算截止频率与相角裕度
由 Bode 图反求传递函数 频域分析
本卷考法
  • 由对数幅频特性反求开环传递函数
本卷实例
  • 关键一步：由各段斜率变化点确定转折频率
  • 中间结果：由低频段斜率与高度确定型别与增益
  • 卡点：把延长线交点误当增益值而未折算型别
  • 卡点：需回原卷核对图
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 低频段斜率给出积分环节个数即系统型别
  • 低频段高度或延长线与 0 dB 交点给出开环增益
  • 每个转折频率对应一个一阶或二阶环节
  • 斜率变化 -20 对应惯性环节，+20 对应一阶微分，-40 可能是振荡环节
步骤
  • 读低频段斜率确定型别 v
  • 由低频段高度或延长线确定增益 K
  • 逐个读出转折频率并判断对应环节类型
  • 结合相频曲线与谐振峰判定二阶环节参数
  • 写出并验证传递函数
通用考法
  • 本卷考过由对数幅频特性反求开环传递函数
  • 由给定 Bode 图写出传递函数
  • 由实验频率特性辨识系统模型
  • 检验候选传递函数与曲线是否吻合
常见易错
  • 把延长线交点误当作增益值而未折算型别
  • 斜率变化为 -40 时直接写成一阶环节
公式
开环对数频率特性的绘制 频域分析
本卷考法
  • 由渐近线斜率计算截止频率
本卷实例
  • 关键一步：在最靠近截止频率的频段用幅值等于1列式
  • 中间结果：抓大放小后解出截止频率
  • 卡点：逐段改斜率时忘记累加而非替换
考点详解（要点 / 步骤 / 公式 / 考法 / 易错）
要点
  • 熟记 lg2≈0.3、lg5≈0.7、20lg2≈6dB
  • 从低频段开始逐段按各环节转折频率改变斜率
  • 低频段斜率由系统型别决定，高度由开环增益决定
  • 每经过一个转折频率斜率就叠加该环节的斜率变化
步骤
  • 把开环传递函数写成典型环节的标准乘积
  • 确定系统型别与开环增益，画出最低频段渐近线
  • 按转折频率从小到大逐段改斜率
  • 逐点叠加得到幅频与相频曲线
通用考法
  • 本卷考过由渐近线斜率计算截止频率
  • 绘制开环对数渐近幅频特性
  • 计算指定频率处的幅值与相角
  • 由低频段斜率与高度判断型别与增益
常见易错
